Riemannian Geometry: Curvature and Geodesics

Motivation

Riemannian geometry generalizes the study of curved spaces beyond Euclidean geometry, providing the mathematical framework for Einstein's general relativity and modern differential geometry. It studies smooth manifolds equipped with a metric that allows measurement of lengths, angles, and volumes, enabling the definition of curvature—a fundamental invariant that characterizes the local and global geometry of a space.

Definitions

Riemannian Metric: A smooth assignment of an inner product \(g_p\) on each tangent space \(T_pM\) of a manifold \(M\), varying smoothly with \(p\). In local coordinates \((x^1, \ldots, x^n)\): \[g = \sum_{i,j=1}^n g_{ij} \, dx^i \otimes dx^j\]

Levi-Civita Connection: The unique torsion-free connection \(\nabla\) compatible with the metric, satisfying: \[X(g(Y,Z)) = g(\nabla_X Y, Z) + g(Y, \nabla_X Z)\]

Riemann Curvature Tensor: Defined by: \[R(X,Y)Z = \nabla_X \nabla_Y Z - \nabla_Y \nabla_X Z - \nabla_{[X,Y]} Z\] In components: \(R^l_{ijk} = \partial_i \Gamma^l_{jk} - \partial_j \Gamma^l_{ik} + \Gamma^l_{im}\Gamma^m_{jk} - \Gamma^l_{jm}\Gamma^m_{ik}\)

Sectional Curvature: For a 2-plane \(\sigma = \text{span}\{X,Y\}\) in \(T_pM\): \[K(\sigma) = \frac{\langle R(X,Y)Y, X \rangle}{|X|^2|Y|^2 - \langle X,Y \rangle^2}\]

Theorem and Proof

Theorem (Gauss-Bonnet): Let \(M\) be a compact, oriented 2-dimensional Riemannian manifold without boundary. Then: \[\int_M K \, dA = 2\pi \chi(M)\] where \(K\) is the Gaussian curvature and \(\chi(M) = 2 - 2g\) is the Euler characteristic.

Proof Sketch: The proof uses the fact that the curvature form \(\Omega = K \, dA\) is the exterior derivative of a connection 1-form. By triangulating \(M\) and applying Stokes' theorem on each triangle, the boundary terms cancel and the sum of angle defects equals \(2\pi\) times the Euler characteristic. For a geodesic triangle with interior angles \(\alpha, \beta, \gamma\): \[\alpha + \beta + \gamma = \pi + \int_{\Delta} K \, dA\] Summing over a triangulation with \(V\) vertices, \(E\) edges, and \(F\) faces gives the result. ∎

Notation Guide

  • \(g_{ij}\) — metric tensor components
  • \(\Gamma^k_{ij}\) — Christoffel symbols (connection coefficients)
  • \(R^l_{ijk}\) — Riemann curvature tensor components
  • \(\text{Ric}_{ij} = R^k_{ikj}\) — Ricci curvature tensor
  • \(R = g^{ij}\text{Ric}_{ij}\) — scalar curvature
  • \(\nabla_X Y\) — covariant derivative of \(Y\) along \(X\)

    """Geodesic equations on unit sphere."""
    theta, phi, dtheta, dphi = y
    ddtheta = np.sin(theta) * np.cos(theta) * dphi**2
    ddphi = -2 * (np.cos(theta) / np.sin(theta)) * dtheta * dphi
    return np.array([dtheta, dphi, ddtheta, ddphi])

def rk4_integrate(f, y0, t):
    """4th order Runge-Kutta integration."""
    n = len(t)
    y = np.zeros((n, len(y0)))
    y[0] = y0
    for i in range(n-1):
        h = t[i+1] - t[i]
        k1 = f(y[i], t[i])
        k2 = f(y[i] + 0.5*h*k1, t[i] + 0.5*h)
        k3 = f(y[i] + 0.5*h*k2, t[i] + 0.5*h)
        k4 = f(y[i] + h*k3, t[i+1])
        y[i+1] = y[i] + (h/6) * (k1 + 2*k2 + 2*k3 + k4)
    return y

Lie Groups and Their Lie Algebras

Motivation

Lie groups are smooth manifolds that are also groups, with the group operations being smooth maps. They provide the natural framework for studying continuous symmetries in mathematics and physics. From the rotation group SO(3) in classical mechanics to the gauge groups of quantum field theory, Lie groups are ubiquitous in modern science.

Definitions

Lie Group: A smooth manifold \(G\) equipped with group operations \(m: G \times G \to G\) (multiplication) and \(i: G \to G\) (inverse) that are smooth maps.

Lie Algebra: The tangent space \(\mathfrak{g} = T_eG\) at the identity \(e \in G\), equipped with the Lie bracket \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\).

Exponential Map: \(\exp: \mathfrak{g} \to G\) defined by \(\exp(X) = \gamma(1)\) where \(\gamma\) is the unique one-parameter subgroup with \(\gamma'(0) = X\).

Theorem and Proof

Theorem (Lie Group-Lie Algebra Correspondence): There is a one-to-one correspondence between connected, simply connected Lie groups and finite-dimensional Lie algebras.

Proof Sketch: The proof uses Ado's theorem, which states that every finite-dimensional Lie algebra has a faithful finite-dimensional representation. This allows us to realize \(\mathfrak{g}\) as a subalgebra of \(\mathfrak{gl}(n, \mathbb{R})\). The corresponding Lie group is then constructed as the subgroup of \(\text{GL}(n, \mathbb{R})\) generated by \(\exp(\mathfrak{g})\). The universal covering space construction gives the simply connected group. ∎

Notation Guide

  • \(G\) — Lie group
  • \(\mathfrak{g}\) — Lie algebra of \(G\)
  • \(\exp: \mathfrak{g} \to G\) — exponential map
  • \([X, Y]\) — Lie bracket
  • \(SO(n)\) — special orthogonal group (rotations)
  • \(SU(n)\) — special unitary group

import numpy as np
from scipy.linalg import expm

def so3_lie_algebra_element(ax, ay, az):
    """Create element of so(3) from axis-angle representation."""
    return np.array([[0, -az, ay],
                     [az, 0, -ax],
                     [-ay, ax, 0]])

def so3_bracket(X, Y):
    """Lie bracket on so(3): [X,Y] = XY - YX"""
    return X @ Y - Y @ X

def SO3_rotation(axis, angle):
    """Create rotation matrix in SO(3) using Rodrigues' formula."""
    axis = np.array(axis) / np.linalg.norm(axis)
    K = so3_lie_algebra_element(*axis)
    I = np.eye(3)
    R = I + np.sin(angle) * K + (1 - np.cos(angle)) * (K @ K)
    return R

Algebraic Topology: Homotopy Groups

Motivation

Algebraic topology studies topological spaces by associating algebraic invariants that capture their essential features. While homology groups capture "holes" of various dimensions, homotopy groups provide a more refined invariant that captures the structure of continuous maps from spheres into a space.

Definitions

Homotopy: Maps \(f, g: X \to Y\) are homotopic (written \(f \simeq g\)) if there exists a continuous \(H: X \times [0,1] \to Y\) with \(H(x,0) = f(x)\) and \(H(x,1) = g(x)\).

n-th Homotopy Group: For a pointed space \((X, x_0)\): \[\pi_n(X, x_0) = [(S^n, s_0), (X, x_0)]\] the set of homotopy classes of basepoint-preserving maps from \(S^n\) to \(X\). For \(n \geq 2\), \(\pi_n\) is abelian.

Eilenberg-MacLane Space: A space \(K(G, n)\) such that \(\pi_n(K(G,n)) \cong G\) and \(\pi_k(K(G,n)) = 0\) for \(k \neq n\).

Theorem and Proof

Theorem (Hurewicz Isomorphism): Let \(X\) be an \((n-1)\)-connected space. Then: \[\pi_n(X) \cong H_n(X; \mathbb{Z})\] where the isomorphism is given by the Hurewicz map \(h: \pi_n(X) \to H_n(X)\).

Proof Sketch: The proof proceeds by induction on \(n\). For \(n = 1\), this is the classical Hurewicz theorem relating the abelianization of \(\pi_1\) to \(H_1\). For \(n \geq 2\), one uses the fact that an \((n-1)\)-connected space is homotopy equivalent to a CW complex with no cells in dimensions \(< n\). ∎

Notation Guide

  • \(\pi_n(X, x_0)\) — n-th homotopy group
  • \(S^n\) — n-dimensional sphere
  • \(f \simeq g\) — f is homotopic to g
  • \([f]\) — homotopy class of map f
  • \(H_n(X; G)\) — n-th homology with coefficients in G
  • \(\Omega X\) — loop space of X

Control Theory: Stability and Optimal Control

Real-World Motivation

Control theory provides the mathematical foundation for engineering systems that need to maintain desired behavior despite disturbances. From autopilot systems in aircraft to temperature regulation in buildings, from robotic manipulators to economic policy design, control theory enables precise manipulation of dynamical systems.

Definitions

State-Space System: A linear time-invariant (LTI) system is described by: \[\dot{x}(t) = Ax(t) + Bu(t)\] \[y(t) = Cx(t) + Du(t)\]

Controllability: The pair \((A, B)\) is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists a control \(u(t)\) that drives the system from \(x_0\) to \(x_f\) in finite time.

Observability: The pair \((A, C)\) is observable if the initial state \(x(0)\) can be uniquely determined from the output \(y(t)\) over a finite time interval.

Theorem and Proof

Theorem (Kalman Controllability): The pair \((A, B)\) is controllable if and only if the controllability matrix: \[\mathcal{C} = [B \; AB \; A^2B \; \cdots \; A^{n-1}B]\] has full row rank (rank \(n\)).

Proof: The solution to \(\dot{x} = Ax + Bu\) with \(x(0) = x_0\) is: \[x(t) = e^{At}x_0 + \int_0^t e^{A(t-\tau)}Bu(\tau) \, d\tau\] By the Cayley-Hamilton theorem, \(e^{At}\) can be expressed as a polynomial in \(A\) of degree at most \(n-1\). Therefore, the reachable states are precisely the column space of \(\mathcal{C}\). ∎

Notation Guide

  • \(A \in \mathbb{R}^{n \times n}\) — state matrix
  • \(B \in \mathbb{R}^{n \times m}\) — input matrix
  • \(C \in \mathbb{R}^{p \times n}\) — output matrix
  • \(\mathcal{C}\) — controllability matrix
  • \(\mathcal{O}\) — observability matrix
  • \(K\) — feedback gain matrix

Python Code

import numpy as np
from scipy.linalg import solve_continuous_are, eig
from scipy.integrate import odeint

def check_controllability(A, B):
    """Check controllability using Kalman rank condition."""
    n = A.shape[0]
    C = B
    for i in range(1, n):
        C = np.hstack([C, np.linalg.matrix_power(A, i) @ B])
    rank = np.linalg.matrix_rank(C)
    return rank == n, rank, C

def lqr_controller(A, B, Q, R):
    """Design LQR controller. Returns optimal gain K."""
    P = solve_continuous_are(A, B, Q, R)
    K = np.linalg.inv(R) @ B.T @ P
    return K, P

Financial Mathematics: Option Pricing and Black-Scholes

Real-World Motivation

Financial mathematics provides the theoretical foundation for modern quantitative finance, enabling the pricing of derivatives, risk management, and investment strategies. The Black-Scholes model revolutionized finance by providing a closed-form solution for European option pricing, earning Myron Scholes and Robert Merton the 1997 Nobel Prize in Economics.

Definitions

Geometric Brownian Motion: The stock price \(S_t\) follows: \[dS_t = \mu S_t \, dt + \sigma S_t \, dW_t\] where \(\mu\) is the drift, \(\sigma\) is the volatility, and \(W_t\) is standard Brownian motion.

European Call Option: A contract giving the holder the right (but not obligation) to buy an asset at strike price \(K\) at maturity \(T\). The payoff is \(\max(S_T - K, 0)\).

Risk-Neutral Measure: A probability measure \(\mathbb{Q}\) under which the discounted asset price \(e^{-rt}S_t\) is a martingale.

Theorem and Proof

Theorem (Black-Scholes Formula): The price of a European call option on a non-dividend-paying stock is: \[C(S, t) = S N(d_1) - K e^{-r(T-t)} N(d_2)\] where: \[d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}\] \[d_2 = d_1 - \sigma\sqrt{T-t}\]

Proof Sketch: Under the risk-neutral measure \(\mathbb{Q}\), the stock price follows: \[dS_t = rS_t \, dt + \sigma S_t \, dW_t^\mathbb{Q}\] By Itô's lemma, \(\ln(S_T)\) is normally distributed. The option price is the discounted expected payoff: \[C = e^{-rT} \mathbb{E}^\mathbb{Q}[\max(S_T - K, 0)]\] Computing this expectation yields the formula. ∎

Notation Guide

  • \(S_t\) — asset price at time t
  • \(K\) — strike price
  • \(T\) — maturity time
  • \(r\) — risk-free interest rate
  • \(\sigma\) — volatility
  • \(N(x)\) — standard normal CDF
  • \(W_t\) — Brownian motion

Python Code

import numpy as np
from scipy.stats import norm
from scipy.optimize import brentq

def black_scholes_call(S, K, T, r, sigma):
    """Black-Scholes formula for European call option."""
    if T == 0:
        return max(S - K, 0)
    
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return call_price

def black_scholes_put(S, K, T, r, sigma):
    """Black-Scholes formula for European put option."""
    call = black_scholes_call(S, K, T, r, sigma)
    put = call - S + K * np.exp(-r * T)
    return put

def implied_volatility(market_price, S, K, T, r, option_type='call'):
    """Calculate implied volatility using Brent's method."""
    def objective(sigma):
        if option_type == 'call':
            return black_scholes_call(S, K, T, r, sigma) - market_price
        else:
            return black_scholes_put(S, K, T, r, sigma) - market_price
    
    try:
        iv = brentq(objective, 1e-6, 5.0)
        return iv
    except ValueError:
        return None

Cryptography: Lattice-Based Cryptography and Learning With Errors

Real-World Motivation

Lattice-based cryptography has emerged as a leading candidate for post-quantum cryptography—cryptographic systems that remain secure against attacks by quantum computers. Unlike RSA and elliptic curve cryptography, which can be broken by Shor's algorithm on a quantum computer, lattice problems appear to resist quantum attacks.

Definitions

Lattice: A discrete additive subgroup of \(\mathbb{R}^n\). Given linearly independent basis vectors \(\mathbf{b}_1, \ldots, \mathbf{b}_n \in \mathbb{R}^n\): \[\mathcal{L} = \left\{\sum_{i=1}^n z_i \mathbf{b}_i : z_i \in \mathbb{Z}\right\}\]

Shortest Vector Problem (SVP): Given a lattice basis \(\mathbf{B}\), find the shortest non-zero vector \(\mathbf{v} \in \mathcal{L}\).

Learning With Errors (LWE): Given \(m\) samples \((\mathbf{a}_i, b_i)\) where \(\mathbf{a}_i \in \mathbb{Z}_q^n\) are uniform and \(b_i = \langle \mathbf{a}_i, \mathbf{s} \rangle + e_i \pmod{q}\) for secret \(\mathbf{s}\) and small error \(e_i\), distinguish from uniform.

Theorem and Proof

Theorem (Regev's Reduction): For appropriate parameters, solving the LWE problem is at least as hard as quantumly approximating the shortest vector problem (SVP) on arbitrary \(n\)-dimensional lattices.

Proof Sketch: The proof uses a quantum reduction that:

  1. Starts with an LWE oracle that distinguishes LWE samples from uniform
  2. Uses the LWE oracle to construct a quantum algorithm that generates Gaussian superpositions over the dual lattice
  3. Uses quantum Fourier sampling to obtain short vectors in the primal lattice
The quantum aspect is essential—the reduction does not work classically. ∎

Notation Guide

  • \(\mathcal{L}\) — lattice
  • \(\mathbf{B} = [\mathbf{b}_1, \ldots, \mathbf{b}_n]\) — basis matrix
  • \(\lambda_1(\mathcal{L})\) — length of shortest non-zero vector
  • \(\mathbf{s}\) — secret vector in LWE
  • \(e \leftarrow \chi\) — error sampled from distribution \(\chi\)
  • \(\mathbb{Z}_q\) — integers modulo \(q\)

Python Code

import numpy as np

def generate_lwe_instance(n, q, m, error_std=1.0):
    """Generate an LWE instance."""
    s = np.random.randint(0, q, size=n)
    A = np.random.randint(0, q, size=(m, n))
    e = np.round(np.random.normal(0, error_std, size=m)).astype(int)
    b = (A @ s + e) % q
    return A, b, s, e

def gram_schmidt(B):
    """Compute Gram-Schmidt orthogonalization of basis B."""
    n = B.shape[1]
    B_star = B.astype(float).copy()
    mu = np.zeros((n, n))
    
    for i in range(n):
        for j in range(i):
            mu[i, j] = np.dot(B[:, i], B_star[:, j]) / np.dot(B_star[:, j], B_star[:, j])
            B_star[:, i] -= mu[i, j] * B_star[:, j]
    
    return B_star, mu

def lll_reduction(B, delta=0.75):
    """Lenstra-Lenstra-Lovász lattice basis reduction."""
    B = B.astype(float).copy()
    n = B.shape[1]
    
    k = 1
    while k < n:
        B_star, mu = gram_schmidt(B)
        
        # Size reduction
        for j in range(k-1, -1, -1):
            if abs(mu[k, j]) > 0.5:
                B[:, k] = B[:, k] - round(mu[k, j]) * B[:, j]
        
        # Check Lovász condition
        B_star, mu = gram_schmidt(B)
        lhs = np.dot(B_star[:, k], B_star[:, k])
        rhs = (delta - mu[k, k-1]**2) * np.dot(B_star[:, k-1], B_star[:, k-1])
        
        if lhs >= rhs:
            k += 1
        else:
            B[:, [k, k-1]] = B[:, [k-1, k]]
            k = max(k-1, 1)
    
    return B

Knot Theory: Invariants and the Jones Polynomial

Historical Context

Knot theory began in the 19th century with Lord Kelvin's theory that atoms were knotted vortices in the ether. While this physical model was abandoned, the mathematical study of knots flourished. The field gained new impetus in 1984 when Vaughan Jones discovered the Jones polynomial, a powerful knot invariant that led to his Fields Medal in 1990.

Definitions

Knot: An embedding of \(S^1\) into \(\mathbb{R}^3\) (or \(S^3\)). Two knots are equivalent if one can be continuously deformed into the other without cutting or passing through itself.

Reidemeister Moves: Three local moves on knot diagrams that generate all ambient isotopies:

  • Type I: Add/remove a twist
  • Type II: Add/remove two crossings
  • Type III: Slide a strand over a crossing

Kauffman Bracket: A Laurent polynomial \(\langle D \rangle\) defined recursively on link diagrams.

Theorem and Proof

Theorem (Jones Polynomial): There exists a unique invariant \(V_L(t) \in \mathbb{Z}[t^{1/2}, t^{-1/2}]\) for oriented links \(L\) satisfying:

  1. \(V_{\bigcirc}(t) = 1\) for the unknot
  2. The skein relation: \(t^{-1}V_{L_+} - tV_{L_-} = (t^{1/2} - t^{-1/2})V_{L_0}\)

Proof Sketch: The Jones polynomial is derived from the Kauffman bracket via: \[V_L(t) = ((-A)^{-3w(D)}) \langle D \rangle |_{A = t^{-1/4}}\] where \(w(D)\) is the writhe of the diagram. The normalization ensures invariance under Reidemeister move I. ∎

Notation Guide

  • \(K, L\) — knot or link
  • \(D\) — knot diagram
  • \(\langle D \rangle\) — Kauffman bracket
  • \(V_L(t)\) — Jones polynomial
  • \(w(D)\) — writhe (signed crossing number)

Operator Algebras: C*-Algebras and the GNS Construction

Historical Context

Operator algebras emerged from John von Neumann's work on quantum mechanics in the 1930s. Seeking a rigorous mathematical foundation for quantum observables, von Neumann introduced rings of operators (now called von Neumann algebras). Around the same time, Israel Gelfand and Mark Naimark developed the theory of C*-algebras.

Definitions

C*-Algebra: A Banach algebra \(\mathcal{A}\) over \(\mathbb{C}\) with an involution \(^* : \mathcal{A} \to \mathcal{A}\) satisfying:

  • \((a^*)^* = a\) (involution)
  • \((ab)^* = b^*a^*\) (anti-multiplicative)
  • \(||a^*a|| = ||a||^2\) (C*-identity)

State: A positive linear functional \(\phi: \mathcal{A} \to \mathbb{C}\) with \(||\phi|| = 1\).

Representation: A *-homomorphism \(\pi: \mathcal{A} \to \mathcal{B}(\mathcal{H})\) where \(\mathcal{H}\) is a Hilbert space.

Theorem and Proof

Theorem (Gelfand-Naimark-Segal Construction): Let \(\mathcal{A}\) be a C*-algebra and \(\phi\) a state on \(\mathcal{A}\). Then there exists:

  • A Hilbert space \(\mathcal{H}_\phi\)
  • A representation \(\pi_\phi: \mathcal{A} \to \mathcal{B}(\mathcal{H}_\phi)\)
  • A cyclic vector \(\xi_\phi \in \mathcal{H}_\phi\) such that \(\phi(a) = \langle \pi_\phi(a)\xi_\phi, \xi_\phi \rangle\)

Proof:

  1. Define a sesquilinear form on \(\mathcal{A}\) by \(\langle a, b \rangle_\phi = \phi(b^*a)\).
  2. Let \(\mathcal{N}_\phi = \{a \in \mathcal{A} : \phi(a^*a) = 0\}\). By Cauchy-Schwarz, \(\mathcal{N}_\phi\) is a left ideal.
  3. Form the quotient \(\mathcal{A}/\mathcal{N}_\phi\) and complete to get \(\mathcal{H}_\phi\).
  4. Define \(\pi_\phi(a)([b]) = [ab]\). This is well-defined since \(\mathcal{N}_\phi\) is a left ideal.
∎

Notation Guide

  • \(\mathcal{A}\) — C*-algebra
  • \(a^*\) — adjoint of element a
  • \(\mathcal{B}(\mathcal{H})\) — bounded operators on Hilbert space
  • \(\phi, \psi\) — states
  • \(\pi\) — representation
  • \(\mathcal{H}_\phi\) — GNS Hilbert space

Python Code

import numpy as np
from numpy.linalg import norm, eigvals

def matrix_adjoint(a):
    """C*-algebra involution: conjugate transpose."""
    return a.conj().T

def check_cstar_identity(a):
    """Verify the C*-identity: ||a*a|| = ||a||^2"""
    a_star = matrix_adjoint(a)
    a_star_a = a_star @ a
    
    lhs = norm(a_star_a, 2)
    rhs = norm(a, 2)**2
    
    return np.isclose(lhs, rhs)

def state_on_matrix_algebra(rho, a):
    """Evaluate state phi on element a: phi(a) = tr(rho * a)"""
    return np.trace(rho @ a)

def is_density_matrix(rho, atol=1e-10):
    """Check if rho is a valid density matrix (quantum state)."""
    if not np.all(eigvals(rho) >= -atol):
        return False
    if not np.isclose(np.trace(rho), 1.0):
        return False
    if not np.allclose(rho, rho.conj().T):
        return False
    return True

Category Theory: Universal Properties and Limits

Historical Context

Category theory was introduced by Samuel Eilenberg and Saunders Mac Lane in 1945 as a framework for studying natural transformations in algebraic topology. What began as a technical tool has evolved into a foundational language for mathematics, providing a unifying perspective across algebra, geometry, logic, and computer science.

Definitions

Category: A category \(\mathcal{C}\) consists of:

  • A collection of objects \(\text{Ob}(\mathcal{C})\)
  • For each pair of objects \(X, Y\), a set of morphisms \(\text{Hom}(X, Y)\)
  • A composition operation \(\circ: \text{Hom}(Y, Z) \times \text{Hom}(X, Y) \to \text{Hom}(X, Z)\)
  • Identity morphisms \(\text{id}_X \in \text{Hom}(X, X)\)
satisfying associativity and identity axioms.

Functor: A map \(F: \mathcal{C} \to \mathcal{D}\) between categories preserving composition and identities.

Natural Transformation: A map \(\alpha: F \Rightarrow G\) between functors assigning to each object \(X\) a morphism \(\alpha_X: F(X) \to G(X)\) such that for all \(f: X \to Y\): \[\alpha_Y \circ F(f) = G(f) \circ \alpha_X\]

Theorem and Proof

Theorem (Yoneda Lemma): Let \(F: \mathcal{C}^{\text{op}} \to \text{Set}\) be a functor and \(X \in \mathcal{C}\). Then: \[\text{Nat}(\text{Hom}(-, X), F) \cong F(X)\] naturally in both \(X\) and \(F\).

Proof Sketch: Given a natural transformation \(\alpha: \text{Hom}(-, X) \Rightarrow F\), evaluate at \(X\) to get \(\alpha_X: \text{Hom}(X, X) \to F(X)\). Map \(\alpha\) to \(\alpha_X(\text{id}_X) \in F(X)\). Conversely, given \(x \in F(X)\), define \(\alpha_Y(f) = F(f)(x)\) for \(f: Y \to X\). One verifies these are inverse natural isomorphisms. ∎

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\) — categories
  • \(X, Y, Z\) — objects
  • \(f: X \to Y\) — morphism
  • \(\text{Hom}(X, Y)\) — hom-set
  • \(F, G\) — functors
  • \(\alpha: F \Rightarrow G\) — natural transformation
  • \(\text{Nat}(F, G)\) — set of natural transformations

from functools import reduce

class Category:
    """Abstract base class for categories."""

        """Return the set of objects in this category."""
        raise NotImplementedError
    
    def hom(self, X, Y) -> Set:
        """Return the set of morphisms from X to Y."""
        raise NotImplementedError

        """Compose morphisms: return f ∘ g."""
        return lambda x: f(g(x))
    
    def id_morphism(self, X):
        """Return the identity morphism on X."""
        return lambda x: x

class SetCategory(Category):
    """The category of sets and functions."""
    
    def __init__(self, sets=None):
        self._sets = sets or set()
    
    def objects(self):
        return self._sets

        """All functions from X to Y (represented as a description)."""
        return f"Hom({X}, {Y}) = Y^X"
    
    @staticmethod
    def compose(f: Callable[[U], V], g: Callable[[T], U]) -> Callable[[T], V]:
        """Function composition."""
        return lambda x: f(g(x))

    def __init__(self, name: str, obj_map: Dict, mor_map: Dict):
        self.name = name
        self.obj_map = obj_map
        self.mor_map = mor_map

        """Apply functor to an object."""
        return self.obj_map.get(X, f"F({X})")
    
    def map_morphism(self, f):
        """Apply functor to a morphism."""
        return self.mor_map.get(f, f"F({f})")

    def __init__(self, name: str, components: Dict):
        self.name = name
        self.components = components
    
    def component_at(self, X):
        """Get the component of the natural transformation at X."""
        return self.components.get(X, f"α_{X}")

Tropical Geometry: Combinatorial Algebraic Geometry

Historical Context

Tropical geometry is a relatively new field that emerged in the late 1990s and early 2000s, though its roots trace back to the work of Imre Simon on max-plus algebras in the 1970s. The term "tropical" was coined by French mathematicians in honor of Brazilian mathematician Imre Simon. Tropical geometry provides a piecewise-linear shadow of algebraic geometry, transforming complex algebraic varieties into simpler polyhedral complexes that retain important geometric information.

Definitions

Tropical Semiring: The set \(\mathbb{T} = \mathbb{R} \cup \{-\infty\}\) with operations: \[x \oplus y = \max(x, y)\] \[x \odot y = x + y\] The additive identity is \(-\infty\) and the multiplicative identity is \(0\).

Tropical Polynomial: A function \(f: \mathbb{R}^n \to \mathbb{R}\) of the form: \[f(x) = \bigoplus_{i} (a_i \odot x^{\odot m_i}) = \max_i (a_i + \langle m_i, x \rangle)\] where \(a_i \in \mathbb{R}\) and \(m_i \in \mathbb{N}^n\).

Tropical Hypersurface: The set where a tropical polynomial is not smooth (where the maximum is attained by at least two terms): \[V(f) = \{x \in \mathbb{R}^n : \text{the max in } f(x) \text{ is attained at least twice}\}\]

Theorem and Proof

Theorem (Fundamental Theorem of Tropical Geometry): Let \(K\) be an algebraically closed field with a non-archimedean valuation \(\text{val}: K^* \to \mathbb{R}\). Let \(I \subseteq K[x_1, \ldots, x_n]\) be an ideal and \(X = V(I)\) its variety. Then: \[\text{Trop}(X) = \overline{\text{val}(X)} = \bigcap_{f \in I} \text{Trop}(V(f))\] where \(\text{Trop}(X)\) is the tropicalization of \(X\).

Proof Sketch: The key insight is that the valuation map transforms algebraic operations into tropical operations. For a polynomial \(f = \sum c_\alpha x^\alpha\), the valuation of \(f\) at a point \(p\) with \(\text{val}(p) = w\) satisfies: \[\text{val}(f(p)) \geq \min_\alpha (\text{val}(c_\alpha) + \langle \alpha, w \rangle)\] with equality when the minimum is unique. The tropical variety captures where this minimum is not unique, corresponding to the non-archimedean amoeba of the algebraic variety. ∎

Notation Guide

  • \(\mathbb{T}\) — tropical semiring
  • \(\oplus\) — tropical addition (max)
  • \(\odot\) — tropical multiplication (plus)
  • \(x^{\odot n}\) — tropical power (nx)
  • \(V(f)\) — tropical hypersurface of \(f\)
  • \(\text{Trop}(X)\) — tropicalization of variety \(X\)
  • \(\text{val}\) — valuation

import numpy as np
import matplotlib.pyplot as plt

def tropical_add(x, y):
    """Tropical addition: x ⊕ y = max(x, y)"""
    return max(x, y)

def tropical_mult(x, y):
    """Tropical multiplication: x ⊙ y = x + y"""
    return x + y

def tropical_polyval(coeffs, exponents, x):
    """
    Evaluate tropical polynomial.
    coeffs: list of coefficients a_i
    exponents: list of exponents m_i
    x: point at which to evaluate
    
    f(x) = max_i (a_i + m_i * x)
    """
    values = [a + m * x for a, m in zip(coeffs, exponents)]
    return max(values)

def tropical_hypersurface_1d(coeffs, exponents, x_range):
    """
    Find tropical hypersurface (points where max is attained twice).
    For 1D case, these are the 'breakpoints' where two terms are equal.
    """
    breakpoints = []
    n = len(coeffs)
    
    # Find where pairs of terms are equal
    for i in range(n):
        for j in range(i+1, n):
            # a_i + m_i * x = a_j + m_j * x
            # x = (a_j - a_i) / (m_i - m_j)  if m_i != m_j
            if exponents[i] != exponents[j]:
                x_bp = (coeffs[j] - coeffs[i]) / (exponents[i] - exponents[j])
                if x_range[0] <= x_bp <= x_range[1]:
                    breakpoints.append(x_bp)
    
    return sorted(set(breakpoints))

📜 Math History: The Development of Modern Algebra

The 19th century witnessed a profound transformation in mathematics, as the field evolved from a collection of computational techniques into a rigorous deductive science. At the heart of this transformation was the development of modern algebra, which reoriented mathematics away from the study of specific numbers and equations toward the study of abstract structures and their properties.

The story begins with the work of Évariste Galois (1811–1832), whose short but brilliant career laid the foundations for group theory. Galois developed his theory to answer a classical question: when can polynomial equations be solved by radicals? His ingenious insight was to associate to each polynomial equation a group of permutations of its roots—the Galois group—and to show that the equation is solvable by radicals if and only if this group is "solvable" in a technical sense. Tragically, Galois died in a duel at age 20, but his manuscripts, published posthumously by Liouville in 1846, would revolutionize mathematics.

Meanwhile, in Britain, George Boole (1815–1864) was developing an algebra of logic that would prove equally transformative. In his 1854 work "An Investigation of the Laws of Thought," Boole showed that logical reasoning could be reduced to algebraic manipulation, creating what we now call Boolean algebra. This work, initially motivated by philosophical questions about the nature of thought, would find unexpected applications in the 20th century as the foundation of digital circuit design and computer science.

The unification of these disparate threads came through the work of mathematicians like Richard Dedekind (1831–1916) and Leopold Kronecker (1823–1891), who developed the theory of ideals and algebraic number fields. Dedekind, in particular, introduced the concept of an ideal to restore unique factorization in rings of algebraic integers, where it generally fails. His abstract approach, emphasizing structures and mappings over computational formulas, set the template for modern algebra.

The culmination of this development came with the publication of Bartel van der Waerden's "Moderne Algebra" in 1930, based on lectures by Emmy Noether (1882–1935) and Emil Artin (1898–1962). Noether, widely regarded as the most important woman in the history of mathematics, developed the axiomatic approach that defines modern algebra. Her insight was that the most fruitful perspective comes from studying abstract structures—groups, rings, fields, ideals—and the homomorphisms between them, rather than focusing on specific examples.

This shift from the particular to the general, from computation to structure, from formulas to mappings, represents one of the most significant conceptual advances in the history of mathematics. It enabled the development of algebraic topology, algebraic geometry, and category theory in the 20th century, and continues to shape mathematics today.

🧩 Problem Corner

Putnam Competition Problem (1992 B6)

Problem: Let \(S\) be a set of \(n\) distinct real numbers. Let \(A_S\) be the set of all numbers that can be expressed as averages of two distinct elements of \(S\). What is the minimum possible size of \(A_S\)?

💡 Hint

Consider the case where \(S\) is an arithmetic progression. What is the size of \(A_S\) in this case? Then try to prove that this is indeed the minimum by showing that any set must produce at least this many distinct averages.

📖 Solution

Answer: The minimum possible size of \(A_S\) is \(2n - 3\).

Solution:

First, we show that \(2n - 3\) is achievable. Let \(S = \{1, 2, \ldots, n\}\). The averages of distinct elements are: \[\frac{i + j}{2} : 1 \leq i < j \leq n\} The smallest average is \(\frac{1+2}{2} = \frac{3}{2}\) and the largest is \(\frac{(n-1)+n}{2} = \frac{2n-1}{2}\).

All averages of the form \(\frac{k}{2}\) for \(k = 3, 4, \ldots, 2n-1\) are achieved:

  • For odd \(k = 2m+1\): average of \(m\) and \(m+1\)
  • For even \(k = 2m\): average of \(m-1\) and \(m+1\) (when \(m \geq 2\))
This gives exactly \(2n - 3\) distinct values.

Now we prove this is minimal. Let \(S = \{x_1 < x_2 < \cdots < x_n\}\). Consider the \(n-1\) averages: \[\frac{x_1 + x_2}{2} < \frac{x_1 + x_3}{2} < \cdots < \frac{x_1 + x_n}{2}\] These are all distinct since \(x_2 < x_3 < \cdots < x_n\).

Similarly, consider the \(n-1\) averages: \[\frac{x_1 + x_n}{2} < \frac{x_2 + x_n}{2} < \cdots < \frac{x_{n-1} + x_n}{2}\] These are also all distinct.

The only overlap between these two sets is \(\frac{x_1 + x_n}{2}\). Therefore: \[|A_S| \geq (n-1) + (n-1) - 1 = 2n - 3\]

This completes the proof that the minimum size of \(A_S\) is \(2n - 3\). ∎

🎨 Visualization of the Day: The Mandelbrot Set

Today's visualization explores the Mandelbrot set, one of the most famous and beautiful objects in mathematics. The Mandelbrot set is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits intricate self-similar structure at all scales, with miniature copies of the full set appearing throughout. The coloring in typical visualizations represents how quickly points outside the set diverge.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until divergence for point c.
    Returns max_iter if the point is in (or appears to be in) the Mandelbrot set.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[mask] = i
    
    return M

# Generate Mandelbrot set
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

print("Computing Mandelbrot set...")
M = mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100)

# Create visualization
fig, ax = plt.subplots(figsize=(12, 9))

# Use a colormap for the iteration counts

               cmap='hot', origin='lower', interpolation='bilinear')

ax.set_xlabel('Re(c)', fontsize=12)
ax.set_ylabel('Im(c)', fontsize=12)
ax.set_title('The Mandelbrot Set', fontsize=16)

# Add colorbar

Mathematical Significance: The Mandelbrot set connects to deep questions in complex dynamics. The boundary of the set marks the transition between order and chaos in the iteration of quadratic polynomials. Each point in the interior corresponds to a polynomial with an attracting periodic cycle, while the boundary points exhibit sensitive dependence on initial conditions—small changes in \(c\) can dramatically change the behavior of the iteration.
