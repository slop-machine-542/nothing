Set Theory: The Foundation of Mathematics

set-theory

Motivation

Set theory provides the foundational language for virtually all of modern mathematics. Emerging from the work of Georg Cantor in the late 19th century, it offers a unified framework for defining numbers, functions, relations, and mathematical structures. Beyond its foundational role, set theory has become a vibrant research area with deep connections to logic, topology, and analysis. The study of infinite sets revealed surprising phenomena—different sizes of infinity, the independence of the Continuum Hypothesis, and the existence of undecidable propositions—that transformed our understanding of mathematical truth.

Definitions

  • Set: A collection of distinct objects, called elements. We write \(x \in A\) to indicate that \(x\) is an element of set \(A\).
  • Subset: \(A \subseteq B\) if every element of \(A\) is also in \(B\).
  • Power Set: \(\mathcal{P}(A) = \{B : B \subseteq A\}\), the set of all subsets of \(A\).
  • Cardinality: Two sets have the same cardinality if there exists a bijection between them.
  • Ordinal: A transitive set well-ordered by the membership relation \(\in\).
  • Cardinal: An initial ordinal—an ordinal not in bijection with any smaller ordinal.
  • Cofinality: For a limit ordinal \(\alpha\), \(\text{cf}(\alpha)\) is the least ordinal \(\beta\) such that there exists an unbounded function \(f: \beta \to \alpha\).

Theorem: Cantor's Theorem

Theorem (Cantor): For any set \(A\), there is no surjection from \(A\) onto its power set \(\mathcal{P}(A)\). In particular:

\[|A| < |\mathcal{P}(A)|\]

This holds for both finite and infinite sets.

Proof

Suppose \(f: A \to \mathcal{P}(A)\) is any function. Define:

\[B = \{x \in A : x \notin f(x)\}\]

We claim \(B\) is not in the image of \(f\). Suppose for contradiction that \(B = f(y)\) for some \(y \in A\). Then:

\[y \in B \iff y \notin f(y) \iff y \notin B\]

This is a contradiction. Therefore, \(B \notin \text{Im}(f)\), so \(f\) is not surjective. Since there is an injection \(A \to \mathcal{P}(A)\) (map \(x\) to \(\{x\}\)), we have \(|A| < |\mathcal{P}(A)|\).

Notation Guide

  • \(\emptyset\) — empty set
  • \(\mathbb{N}, \omega\) — natural numbers (as set/ordinal)
  • \(\mathbb{R}, \mathfrak{c}\) — real numbers, cardinality of continuum
  • \(\aleph_\alpha\) — infinite cardinals (alephs)
  • \(\beth_\alpha\) — beth numbers (cardinality of iterated power sets)
  • \(\omega_\alpha\) — infinite initial ordinals
  • \(V_\alpha\) — von Neumann hierarchy
  • \(L\) — Gödel's constructible universe

Measure Theory: The Mathematics of Size

measure-theory

Motivation

Measure theory generalizes the intuitive notions of length, area, and volume to abstract spaces. Developed by Henri Lebesgue in the early 20th century, it provides the rigorous foundation for modern probability theory, integration, and functional analysis. The theory addresses fundamental questions: What subsets of \(\mathbb{R}^n\) can be assigned a "size"? When can we interchange limits and integrals? The Lebesgue integral, more powerful than the Riemann integral, enables integration of functions that were previously intractable and forms the basis for Fourier analysis, stochastic processes, and quantum mechanics.

Definitions

  • \(\sigma\)-algebra: A collection \(\mathcal{F}\) of subsets of \(X\) containing \(\emptyset\), closed under complements, and closed under countable unions.
  • Measurable Space: A pair \((X, \mathcal{F})\) where \(\mathcal{F}\) is a \(\sigma\)-algebra on \(X\).
  • Measure: A function \(\mu: \mathcal{F} \to [0, \infty]\) with \(\mu(\emptyset) = 0\) and countable additivity: for disjoint \(\{E_i\}\): \(\mu(\bigcup_i E_i) = \sum_i \mu(E_i)\).
  • Measure Space: A triple \((X, \mathcal{F}, \mu)\).
  • Lebesgue Measure: The unique translation-invariant measure on \(\mathbb{R}^n\) assigning volume 1 to the unit cube.
  • Measurable Function: \(f: X \to \mathbb{R}\) such that \(f^{-1}(B) \in \mathcal{F}\) for all Borel sets \(B\).
  • Almost Everywhere (a.e.): A property holds a.e. if it holds except on a set of measure zero.

Theorem: Monotone Convergence Theorem

Theorem: Let \((f_n)\) be a sequence of non-negative measurable functions on a measure space \((X, \mathcal{F}, \mu)\) such that \(f_n \leq f_{n+1}\) for all \(n\). Let \(f = \lim_{n \to \infty} f_n\). Then:

\[\lim_{n \to \infty} \int_X f_n \, d\mu = \int_X f \, d\mu\]

Proof Sketch

  1. Since \(f_n \leq f\) for all \(n\), we have \(\int f_n \leq \int f\), so \(\lim \int f_n \leq \int f\).
  2. For the reverse inequality, let \(s\) be a simple function with \(0 \leq s \leq f\) and let \(0 < \alpha < 1\).
  3. Define \(E_n = \{x : f_n(x) \geq \alpha s(x)\}\). Then \(E_n \uparrow X\).
  4. We have \(\int f_n \geq \int_{E_n} f_n \geq \alpha \int_{E_n} s\).
  5. As \(n \to \infty\), \(\int_{E_n} s \to \int s\) by continuity of measure.
  6. Taking \(\alpha \to 1\) and supremum over simple \(s\) gives \(\lim \int f_n \geq \int f\).

Notation Guide

  • \(\mathcal{B}(\mathbb{R}^n)\) — Borel \(\sigma\)-algebra
  • \(\mathcal{L}(\mathbb{R}^n)\) — Lebesgue \(\sigma\)-algebra
  • \(\lambda_n\) or \(m_n\) — Lebesgue measure on \(\mathbb{R}^n\)
  • \(\int_X f \, d\mu\) or \(\int_X f(x) \, d\mu(x)\) — Lebesgue integral
  • \(L^p(X, \mu)\) — space of \(p\)-integrable functions
  • \(\|f\|_p = (\int |f|^p)^{1/p}\) — \(L^p\) norm
  • \(\mu \ll \nu\) — \(\mu\) is absolutely continuous with respect to \(\nu\)
  • \(\frac{d\mu}{d\nu}\) — Radon-Nikodym derivative

def approximate_lebesgue_integral(f, a, b, n=10000):
    """
    Approximate Lebesgue integral by partitioning the range.
    f: function
    [a, b]: domain interval
    n: number of sample points
    """
    x = np.linspace(a, b, n)
    y = f(x)
    
    # Partition range into levels
    y_min, y_max = np.min(y), np.max(y)
    num_levels = 100
    levels = np.linspace(y_min, y_max, num_levels)
    
    integral = 0
    dx = (b - a) / n
    
    for i in range(len(levels) - 1):
        y_lower = levels[i]
        y_upper = levels[i + 1]
        y_mid = (y_lower + y_upper) / 2
        
        # Measure of set where f is in [y_lower, y_upper)
        mask = (y >= y_lower) & (y < y_upper)
        measure = np.sum(mask) * dx
        
        integral += y_mid * measure
    
    return integral

Graph Theory: Networks and Connections

graph-theory

Motivation

Graph theory studies the abstract properties of networks—collections of points (vertices) connected by lines (edges). From its origins in the Königsberg bridge problem solved by Leonhard Euler in 1736, graph theory has grown into a fundamental tool for understanding complex systems. It models social networks, the internet, molecular structures, transportation systems, and neural connections. The field combines elegant combinatorial arguments with deep structural insights, providing algorithms for optimization, clustering, and flow problems that power modern technology.

Definitions

  • Graph: A pair \(G = (V, E)\) where \(V\) is a set of vertices and \(E \subseteq V \times V\) is a set of edges.
  • Simple Graph: An undirected graph with no loops and no multiple edges.
  • Degree: \(\deg(v)\) is the number of edges incident to vertex \(v\).
  • Path: A sequence of vertices \(v_0, v_1, \ldots, v_k\) where \((v_i, v_{i+1}) \in E\).
  • Connected: A graph where every pair of vertices is joined by a path.
  • Tree: A connected graph with no cycles. For a tree, \(|E| = |V| - 1\).
  • Chromatic Number: \(\chi(G)\) is the minimum number of colors needed to color vertices so adjacent vertices have different colors.
  • Planar Graph: A graph that can be drawn in the plane without edge crossings.

Theorem: Euler's Formula for Planar Graphs

Theorem: For any connected planar graph drawn in the plane:

\[V - E + F = 2\]

where \(V\) is the number of vertices, \(E\) the number of edges, and \(F\) the number of faces (including the outer face).

Proof

We proceed by induction on the number of edges.

Base case: If \(E = 0\), then \(V = 1\) (connected) and \(F = 1\). So \(1 - 0 + 1 = 2\). ✓

Inductive step: Assume the formula holds for all connected planar graphs with fewer than \(E\) edges.

  • Case 1: The graph is a tree. Then \(E = V - 1\) and \(F = 1\). So \(V - (V-1) + 1 = 2\). ✓
  • Case 2: The graph has a cycle. Remove one edge from a cycle. This decreases \(E\) by 1 and merges two faces, decreasing \(F\) by 1. By induction: \(V - (E-1) + (F-1) = V - E + F = 2\). ✓

Notation Guide

  • \(G = (V, E)\) — graph with vertex set \(V\) and edge set \(E\)
  • \(K_n\) — complete graph on \(n\) vertices
  • \(K_{m,n}\) — complete bipartite graph
  • \(C_n\) — cycle graph with \(n\) vertices
  • \(P_n\) — path graph with \(n\) vertices
  • \(\delta(G), \Delta(G)\) — minimum and maximum degree
  • \(\kappa(G), \lambda(G)\) — vertex and edge connectivity
  • \(\alpha(G)\) — independence number
  • \(\omega(G)\) — clique number
  • \(d(u, v)\) — distance between vertices \(u\) and \(v\)

def bfs_shortest_path(G, start, end):
    """Find shortest path using BFS."""
    queue = deque([(start, [start])])
    visited = {start}
    
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor in G.neighbors(node):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

def graph_coloring_greedy(G):
    """Greedy graph coloring (Welsh-Powell heuristic)."""
    # Sort vertices by degree (descending)
    vertices = sorted(G.nodes(), key=lambda v: G.degree(v), reverse=True)
    
    coloring = {}
    color = 0
    
    for v in vertices:
        if v not in coloring:
            # Assign new color to v
            coloring[v] = color
            # Try to assign same color to non-adjacent vertices
            for u in vertices:
                if u not in coloring:
                    # Check if u is adjacent to any vertex with this color
                    can_use_color = True
                    for w in G.neighbors(u):
                        if w in coloring and coloring[w] == color:
                            can_use_color = False
                            break
                    if can_use_color:
                        coloring[u] = color
            color += 1
    
    return coloring, color

Mathematical Physics: Hamiltonian Mechanics

mathematical-physics

Real-World Motivation

Hamiltonian mechanics provides the mathematical framework for classical mechanics, quantum mechanics, and statistical mechanics. Developed by William Rowan Hamilton in the 1830s, it reformulates Newton's laws in terms of positions and momenta rather than positions and velocities. This formulation reveals deep geometric structures—symplectic geometry—that underlie physical dynamics. Hamiltonian mechanics is essential for celestial mechanics (predicting planetary orbits), molecular dynamics simulations, quantum field theory, and the design of particle accelerators. Its elegant structure also makes it ideal for numerical integration of physical systems.

Definitions

  • Configuration Space: The space \(Q\) of all possible positions of a system, typically a smooth manifold.
  • Phase Space: The cotangent bundle \(T^*Q\) with coordinates \((q^i, p_i)\) representing positions and momenta.
  • Hamiltonian: A function \(H: T^*Q \to \mathbb{R}\) representing the total energy \(H = T + V\) (kinetic + potential).
  • Canonical Symplectic Form: \(\omega = \sum_i dq^i \wedge dp_i\), a closed, non-degenerate 2-form on phase space.
  • Poisson Bracket: For functions \(f, g\) on phase space: \(\{f, g\} = \sum_i \left(\frac{\partial f}{\partial q^i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q^i}\right)\).
  • Hamilton's Equations: \(\dot{q}^i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q^i}\).

Theorem: Liouville's Theorem

Theorem: The Hamiltonian flow preserves the symplectic volume form on phase space. Equivalently, for any region \(D\) in phase space:

\[\frac{d}{dt} \int_D dq^1 \wedge dp_1 \wedge \cdots \wedge dq^n \wedge dp_n = 0\]

This means phase space volume is conserved under Hamiltonian evolution.

Proof Sketch

The Hamiltonian vector field \(X_H\) is defined by \(\iota_{X_H}\omega = -dH\). In coordinates:

\[X_H = \sum_i \left(\frac{\partial H}{\partial p_i}\frac{\partial}{\partial q^i} - \frac{\partial H}{\partial q^i}\frac{\partial}{\partial p_i}\right)\]

The Lie derivative of \(\omega\) along \(X_H\) is:

\[\mathcal{L}_{X_H}\omega = d(\iota_{X_H}\omega) + \iota_{X_H}(d\omega) = d(-dH) + 0 = 0\]

using \(d\omega = 0\) (\(\omega\) is closed). Since \(\omega^n\) is the volume form and \(\mathcal{L}_{X_H}\omega = 0\), we have \(\mathcal{L}_{X_H}(\omega^n) = 0\), proving volume preservation.

Notation Guide

  • \(q = (q^1, \ldots, q^n)\) — generalized coordinates
  • \(p = (p_1, \ldots, p_n)\) — conjugate momenta
  • \(T^*Q\) — cotangent bundle (phase space)
  • \(\omega\) — symplectic form
  • \(\{f, g\}\) — Poisson bracket
  • \(X_H\) — Hamiltonian vector field
  • \(\iota_X\omega\) — interior product (contraction)
  • \(\mathcal{L}_X\) — Lie derivative
  • \(\wedge\) — wedge product of differential forms

def hamiltonian_simple_harmonic(q, p, m=1, k=1):
    """Hamiltonian for simple harmonic oscillator."""
    return p**2 / (2*m) + k * q**2 / 2

def hamilton_equations(t, y, H_func, params={}):
    """
    Compute time derivatives for Hamilton's equations.
    y = [q, p]
    Returns [dq/dt, dp/dt]
    """
    q, p = y
    eps = 1e-8
    
    # ∂H/∂q (numerical)
    dH_dq = (H_func(q + eps, p, **params) - H_func(q - eps, p, **params)) / (2*eps)
    # ∂H/∂p (numerical)
    dH_dp = (H_func(q, p + eps, **params) - H_func(q, p - eps, **params)) / (2*eps)
    
    dq_dt = dH_dp
    dp_dt = -dH_dq
    
    return [dq_dt, dp_dt]

def hamiltonian_kepler(q, p, mu=1):
    """Hamiltonian for Kepler problem (planetary motion)."""
    r = np.linalg.norm(q)
    return np.dot(p, p) / 2 - mu / r

Operations Research: Linear Programming

operations-research

Real-World Motivation

Operations research applies mathematical methods to optimize decision-making in complex systems. Linear programming, its cornerstone technique, solves problems where we seek to maximize or minimize a linear objective function subject to linear constraints. Developed during World War II for military logistics, linear programming now powers supply chain optimization, production planning, portfolio optimization, transportation routing, and resource allocation. The simplex method, developed by George Dantzig in 1947, revolutionized industry by enabling efficient solutions to problems with millions of variables. Modern interior-point methods complement the simplex method for large-scale problems.

Definitions

  • Linear Program (Standard Form): Maximize \(c^T x\) subject to \(Ax \leq b\) and \(x \geq 0\).
  • Feasible Region: The set of all \(x\) satisfying the constraints, a convex polyhedron.
  • Basic Feasible Solution: A solution at a vertex of the feasible region.
  • Dual Problem: For primal max \(c^T x\) s.t. \(Ax \leq b\), the dual is min \(b^T y\) s.t. \(A^T y \geq c, y \geq 0\).
  • Slack Variables: Variables added to convert inequalities to equalities: \(Ax + s = b, s \geq 0\).
  • Shadow Price: The rate of change of the optimal value with respect to a constraint's right-hand side.
  • Simplex Method: An algorithm that moves from vertex to adjacent vertex, improving the objective until optimal.

Theorem: Strong Duality

Theorem: If the primal linear program has an optimal solution \(x^*\), then the dual also has an optimal solution \(y^*\), and:

\[c^T x^* = b^T y^*\]

That is, the optimal values of the primal and dual are equal.

Proof Sketch

The proof uses Farkas' Lemma and the separating hyperplane theorem:

  1. Consider the optimal basis \(B\) from the simplex method.
  2. The optimal primal solution is \(x_B = B^{-1}b\), \(x_N = 0\).
  3. Define dual variables \(y^T = c_B^T B^{-1}\).
  4. Show \(y\) is feasible for the dual: \(A^T y \geq c\).
  5. Compute: \(b^T y = y^T b = c_B^T B^{-1} b = c_B^T x_B = c^T x^*\).
  6. By weak duality, any feasible dual has value \(\geq\) primal, so \(y\) is optimal.

Notation Guide

  • \(c \in \mathbb{R}^n\) — objective coefficients
  • \(A \in \mathbb{R}^{m \times n}\) — constraint matrix
  • \(b \in \mathbb{R}^m\) — constraint right-hand side
  • \(x \in \mathbb{R}^n\) — decision variables
  • \(x \geq 0\) — non-negativity constraints
  • \(s\) — slack variables
  • \(B, N\) — basis and non-basic variable indices
  • \(z\) — objective value
  • \(\bar{c}_j = c_j - c_B^T B^{-1} A_j\) — reduced costs

Network Science: Spectral Graph Theory

network-science

Real-World Motivation

Network science studies complex systems as interconnected networks—social networks, the internet, biological networks, and infrastructure systems. Spectral graph theory connects the algebraic properties of matrices associated with graphs to their structural and dynamical properties. This connection enables powerful algorithms for community detection, graph partitioning, synchronization analysis, and epidemic spreading. Applications include Google's PageRank algorithm, recommendation systems, neuroscience (brain connectivity), and understanding the spread of diseases. The eigenvalues and eigenvectors of the Laplacian and adjacency matrices reveal fundamental properties like connectivity, expansion, and random walk behavior.

Definitions

  • Adjacency Matrix: \(A\) where \(A_{ij} = 1\) if \((i,j) \in E\), else 0.
  • Degree Matrix: \(D = \text{diag}(d_1, \ldots, d_n)\) where \(d_i = \deg(v_i)\).
  • Laplacian: \(L = D - A\), a positive semi-definite matrix.
  • Normalized Laplacian: \(\mathcal{L} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}AD^{-1/2}\).
  • Spectral Gap: \(\lambda_2\), the second smallest eigenvalue of \(L\), measures connectivity.
  • Fiedler Vector: The eigenvector corresponding to \(\lambda_2\), used for graph partitioning.
  • Cheeger Constant: \(h(G) = \min_{S \subseteq V, |S| \leq n/2} \frac{|\partial S|}{|S|}\), measures bottleneckness.

Theorem: Cheeger Inequality

Theorem: For any connected graph \(G\) with normalized Laplacian eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\):

\[\frac{\lambda_2}{2} \leq h(G) \leq \sqrt{2\lambda_2}\]

where \(h(G)\) is the Cheeger constant (isoperimetric number).

Proof Sketch

Lower bound (\(\lambda_2/2 \leq h\)):

  1. Use the variational characterization: \(\lambda_2 = \min_{f \perp \mathbf{1}} \frac{\sum_{(i,j) \in E}(f_i - f_j)^2}{\sum_i d_i f_i^2}\).
  2. For any subset \(S\), construct a test function based on the indicator of \(S\).
  3. Show this gives \(\lambda_2 \leq 2h(G)\).

Upper bound (\(h \leq \sqrt{2\lambda_2}\)):

  1. Take the Fiedler vector \(f\) and construct a sweep cut.
  2. Order vertices by \(f_i/\sqrt{d_i}\) and find the cut with minimal expansion.
  3. Use Cauchy-Schwarz to bound the expansion by \(\sqrt{2\lambda_2}\).

Notation Guide

  • \(A\) — adjacency matrix
  • \(D\) — degree matrix
  • \(L = D - A\) — (combinatorial) Laplacian
  • \(\mathcal{L} = D^{-1/2}LD^{-1/2}\) — normalized Laplacian
  • \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\) — Laplacian eigenvalues
  • \(v^{(2)}\) — Fiedler vector (eigenvector for \(\lambda_2\))
  • \(h(G)\) — Cheeger constant
  • \(\phi(S) = |\partial S| / \min(|S|, |\bar{S}|)\) — conductance of set \(S\)
  • \(\rho(A)\) — spectral radius of matrix \(A\)

import numpy as np
import networkx as nx
import matplotlib.pyplot as plt
from scipy.linalg import eigh
from sklearn.cluster import KMeans

def compute_spectral_properties(G):
    """Compute key spectral properties of a graph."""
    # Adjacency matrix
    A = nx.adjacency_matrix(G).toarray().astype(float)
    
    # Degree matrix
    degrees = np.array([G.degree(i) for i in G.nodes()])
    D = np.diag(degrees)
    
    # Laplacian
    L = D - A
    
    # Normalized Laplacian
    D_inv_sqrt = np.diag(1.0 / np.sqrt(degrees + 1e-10))
    L_norm = D_inv_sqrt @ L @ D_inv_sqrt
    
    # Eigenvalues of normalized Laplacian
    eigenvalues, eigenvectors = eigh(L_norm)
    
    return {
        'A': A, 'D': D, 'L': L, 'L_norm': L_norm,
        'eigenvalues': eigenvalues,
        'eigenvectors': eigenvectors,
        'lambda_2': eigenvalues[1],
        'fiedler_vector': eigenvectors[:, 1]
    }

def spectral_partition(G, k=2):
    """
    Partition graph using spectral clustering.
    Uses first k eigenvectors of normalized Laplacian.
    """
    props = compute_spectral_properties(G)
    
    # Use first k eigenvectors (excluding the trivial one)
    embedding = props['eigenvectors'][:, 1:k+1]
    
    # Normalize rows (for normalized cut)
    embedding = embedding / (np.linalg.norm(embedding, axis=1, keepdims=True) + 1e-10)
    
    # K-means clustering
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = kmeans.fit_predict(embedding)
    
    return labels, props

def cheeger_constant(G):
    """Compute the Cheeger constant (approximation via spectral method)."""
    props = compute_spectral_properties(G)
    lambda_2 = props['lambda_2']
    
    # Cheeger inequality: lambda_2 / 2 <= h(G) <= sqrt(2 * lambda_2)
    h_lower = lambda_2 / 2
    h_upper = np.sqrt(2 * lambda_2)
    
    # Sweep cut to approximate h(G)
    fiedler = props['fiedler_vector']
    degrees = np.array([G.degree(i) for i in G.nodes()])
    
    # Sort by Fiedler vector values weighted by degree
    ratios = fiedler / np.sqrt(degrees + 1e-10)
    order = np.argsort(ratios)
    
    min_conductance = float('inf')
    best_cut = None
    
    for i in range(1, len(order)):
        S = set(order[:i])
        boundary = nx.edge_boundary(G, S)
        vol_S = sum(degrees[list(S)])
        vol_not_S = sum(degrees) - vol_S
        conductance = len(boundary) / min(vol_S, vol_not_S) if min(vol_S, vol_not_S) > 0 else 0
        
        if conductance < min_conductance:
            min_conductance = conductance
            best_cut = S
    
    return min_conductance, h_lower, h_upper, best_cut

Computability Theory: The Limits of Computation

computability-theory

Historical Context

Computability theory emerged in the 1930s as mathematicians grappled with Hilbert's Entscheidungsproblem: Is there an algorithm that can determine the truth of any mathematical statement? Alan Turing, Alonzo Church, and Kurt Gödel independently showed that no such universal algorithm exists. Turing introduced the abstract Turing machine, defining computability in terms of what can be computed mechanically. Church developed the lambda calculus, showing equivalence between different models of computation. Gödel's incompleteness theorems revealed fundamental limits to formal systems. Together, these results established the boundaries of computation and laid the foundation for computer science.

Definitions

  • Turing Machine: A mathematical model of computation with a finite state controller, an infinite tape, and a read-write head.
  • Computable Function: A function \(f: \mathbb{N} \to \mathbb{N}\) that can be computed by some Turing machine.
  • Decidable Language: A language \(L\) for which there exists a Turing machine that halts and accepts all strings in \(L\) and halts and rejects all strings not in \(L\).
  • Recursively Enumerable (RE): A language is RE if there exists a Turing machine that accepts all strings in the language (may not halt on non-members).
  • Halting Problem: The problem of determining, given a program and input, whether the program will eventually halt or run forever.
  • Reduction: Language \(A\) reduces to \(B\) (\(A \leq_m B\)) if there exists a computable function \(f\) such that \(w \in A \iff f(w) \in B\).
  • Oracle Machine: A Turing machine with access to an oracle that can solve some decision problem in one step.

Theorem: The Halting Problem is Undecidable

Theorem: There is no Turing machine \(H\) that decides the halting problem. That is, there is no algorithm that, given any Turing machine \(M\) and input \(w\), can determine whether \(M\) halts on \(w\).

Proof (Diagonalization)

Suppose for contradiction that \(H\) decides the halting problem. Construct a new Turing machine \(D\) that, on input \(\langle M \rangle\) (the encoding of machine \(M\)):

  1. Runs \(H\) on input \(\langle M, \langle M \rangle \rangle\).
  2. If \(H\) accepts (meaning \(M\) halts on \(\langle M \rangle\)), then \(D\) enters an infinite loop.
  3. If \(H\) rejects (meaning \(M\) doesn't halt on \(\langle M \rangle\)), then \(D\) halts.

Now consider what happens when \(D\) runs on input \(\langle D \rangle\):

  • If \(D\) halts on \(\langle D \rangle\), then \(H\) accepts, so \(D\) loops. Contradiction!
  • If \(D\) loops on \(\langle D \rangle\), then \(H\) rejects, so \(D\) halts. Contradiction!

Therefore, \(H\) cannot exist. The halting problem is undecidable.

Notation Guide

  • \(\langle M \rangle\) — encoding of Turing machine \(M\)
  • \(A_{TM} = \{\langle M, w \rangle : M \text{ accepts } w\}\) — acceptance problem
  • \(H_{TM} = \{\langle M, w \rangle : M \text{ halts on } w\}\) — halting problem
  • \(E_{TM} = \{\langle M \rangle : L(M) = \emptyset\}\) — emptiness problem
  • \(EQ_{TM} = \{\langle M_1, M_2 \rangle : L(M_1) = L(M_2)\}\) — equivalence problem
  • \(A \leq_m B\) — many-one reducibility
  • \(\Sigma_1, \Pi_1, \Delta_1\) — levels of the arithmetical hierarchy

    Simulate one step of a Turing machine.

    symbol = tape.get(head_pos, '_')

Model Theory: Mathematical Structures and Truth

model-theory

Historical Context

Model theory studies the relationship between formal languages (syntax) and their interpretations (semantics). Emerging from the work of Alfred Tarski on truth definitions in the 1930s, and developed by Abraham Robinson, Leon Henkin, and others, it provides a bridge between logic and algebra. Model theory asks: Given a set of axioms, what structures satisfy them? What can we prove from these axioms? The field produced stunning results like the Löwenheim-Skolem theorems, the Compactness theorem, and Morley's categoricity theorem. Applications range from algebraic geometry (o-minimal structures) to combinatorics (the model theory of finite structures) and computer science (verification, database theory).

Definitions

  • Signature (Language): A set of function symbols, relation symbols, and constant symbols with specified arities.
  • Structure: A set (universe) equipped with interpretations of the symbols in the signature.
  • Interpretation: For a language \(L\), an \(L\)-structure \(\mathcal{M}\) assigns meaning to symbols.
  • Satisfaction: \(\mathcal{M} \models \phi\) means structure \(\mathcal{M}\) satisfies formula \(\phi\).
  • Theory: A set of sentences (closed formulas) in a language.
  • Model: A structure \(\mathcal{M}\) is a model of theory \(T\) if \(\mathcal{M} \models \phi\) for all \(\phi \in T\).
  • Elementary Equivalence: \(\mathcal{M} \equiv \mathcal{N}\) if they satisfy the same sentences.
  • Elementary Substructure: \(\mathcal{M} \preceq \mathcal{N}\) if \(\mathcal{M}\) is a substructure and they agree on all formulas with parameters from \(M\).

Theorem: Compactness Theorem

Theorem: A theory \(T\) has a model if and only if every finite subset of \(T\) has a model.

Equivalently: If every finite subset of \(T\) is satisfiable, then \(T\) is satisfiable.

Proof Sketch

The proof uses the completeness theorem or ultraproducts:

Via Completeness:

  1. If \(T\) has no model, then by completeness, \(T \vdash \bot\) (proves contradiction).
  2. Proofs are finite, so only finitely many axioms from \(T\) are used.
  3. Thus some finite subset proves \(\bot\), contradicting the assumption that all finite subsets have models.

Via Ultraproducts:

  1. Given that every finite subset has a model, construct an ultraproduct of these models.
  2. Łoś's theorem ensures the ultraproduct satisfies all of \(T\).

Notation Guide

  • \(L\) — language/signature
  • \(\mathcal{M}, \mathcal{N}\) — structures/models
  • \(M, N\) — universes (underlying sets)
  • \(\mathcal{M} \models \phi\) — satisfaction relation
  • \(T \models \phi\) — logical consequence
  • \(\text{Th}(\mathcal{M}) = \{\phi : \mathcal{M} \models \phi\}\) — theory of a structure
  • \(\mathcal{M} \equiv \mathcal{N}\) — elementary equivalence
  • \(\mathcal{M} \preceq \mathcal{N}\) — elementary substructure
  • \(\prod_{i \in I} \mathcal{M}_i / \mathcal{U}\) — ultraproduct

We implement simple structures and demonstrate key concepts like:
- Satisfaction checking
- Elementary equivalence (simplified)
- Compactness applications

from functools import lru_cache

class Structure:
    """
    A simple mathematical structure with universe and interpretations.
    """
    def __init__(self, universe, relations=None, functions=None, constants=None):
        self.universe = set(universe)
        self.relations = relations or {}  # name -> set of tuples
        self.functions = functions or {}  # name -> dict mapping tuples to values
        self.constants = constants or {}  # name -> value
    
    def evaluate_term(self, term, assignment=None):
        """Evaluate a term given variable assignment."""
        assignment = assignment or {}
        
        if isinstance(term, str):
            if term in self.constants:
                return self.constants[term]
            return assignment.get(term, term)
        
        if isinstance(term, tuple) and term[0] in self.functions:
            func_name = term[0]
            args = tuple(self.evaluate_term(arg, assignment) for arg in term[1:])
            return self.functions[func_name].get(args, args)
        
        return term
    
    def satisfies(self, formula, assignment=None):
        """Check if structure satisfies formula."""
        assignment = assignment or {}
        
        # Atomic formula: R(t1, ..., tn)
        if isinstance(formula, tuple) and formula[0] in self.relations:
            rel_name = formula[0]
            args = tuple(self.evaluate_term(arg, assignment) for arg in formula[1:])
            return args in self.relations[rel_name]
        
        # Equality: t1 = t2
        if isinstance(formula, tuple) and formula[0] == '=':
            t1 = self.evaluate_term(formula[1], assignment)
            t2 = self.evaluate_term(formula[2], assignment)
            return t1 == t2
        
        # Negation: NOT phi
        if isinstance(formula, tuple) and formula[0] == 'NOT':
            return not self.satisfies(formula[1], assignment)
        
        # Conjunction: AND(phi1, phi2, ...)
        if isinstance(formula, tuple) and formula[0] == 'AND':
            return all(self.satisfies(f, assignment) for f in formula[1:])
        
        # Disjunction: OR(phi1, phi2, ...)
        if isinstance(formula, tuple) and formula[0] == 'OR':
            return any(self.satisfies(f, assignment) for f in formula[1:])
        
        # Implication: IMPLIES(phi1, phi2)
        if isinstance(formula, tuple) and formula[0] == 'IMPLIES':
            return (not self.satisfies(formula[1], assignment)) or self.satisfies(formula[2], assignment)
        
        # Universal quantifier: FORALL(x, phi)
        if isinstance(formula, tuple) and formula[0] == 'FORALL':
            var = formula[1]
            subformula = formula[2]
            return all(
                self.satisfies(subformula, {**assignment, var: a})
                for a in self.universe
            )
        
        # Existential quantifier: EXISTS(x, phi)
        if isinstance(formula, tuple) and formula[0] == 'EXISTS':
            var = formula[1]
            subformula = formula[2]
            return any(
                self.satisfies(subformula, {**assignment, var: a})
                for a in self.universe
            )
        
        raise ValueError(f"Unknown formula structure: {formula}")

Algebraic Number Theory: Numbers and Symmetry

algebraic-number-theory

Historical Context

Algebraic number theory studies number fields—finite extensions of the rational numbers—and their rings of integers. Born from attempts to prove Fermat's Last Theorem, it was developed by Ernst Kummer, Richard Dedekind, and Leopold Kronecker in the 19th century. Kummer introduced ideal numbers to restore unique factorization in cyclotomic fields. Dedekind abstracted this to the modern concept of ideals. The field reveals deep connections between algebra, geometry, and analysis. It provides the framework for understanding reciprocity laws, the distribution of primes, and modern cryptography. The Langlands program, one of the most ambitious projects in contemporary mathematics, seeks to unify algebraic number theory with representation theory and harmonic analysis.

Definitions

  • Number Field: A finite field extension \(K/\mathbb{Q}\), denoted \([K:\mathbb{Q}] = n\).
  • Ring of Integers: \(\mathcal{O}_K = \{x \in K : x \text{ is integral over } \mathbb{Z}\}\), the integral closure of \(\mathbb{Z}\) in \(K\).
  • Ideal: A subset \(I \subseteq \mathcal{O}_K\) closed under addition and multiplication by elements of \(\mathcal{O}_K\).
  • Prime Ideal: An ideal \(\mathfrak{p}\) such that if \(ab \in \mathfrak{p}\), then \(a \in \mathfrak{p}\) or \(b \in \mathfrak{p}\).
  • Norm of Ideal: \(N(\mathfrak{a}) = |\mathcal{O}_K/\mathfrak{a}|\), the size of the quotient ring.
  • Class Group: \(\text{Cl}(K) = \text{Frac}(\mathcal{O}_K)/\text{Prin}(\mathcal{O}_K)\), measuring failure of unique factorization.
  • Discriminant: \(\Delta_K\), an integer measuring ramification of primes in \(K\).

Theorem: Finiteness of the Class Group

Theorem: For any number field \(K\), the class group \(\text{Cl}(K)\) is a finite abelian group.

The order \(h_K = |\text{Cl}(K)|\) is called the class number of \(K\).

Proof Sketch (Minkowski's Method)

  1. Embed \(K\) into \(\mathbb{R}^r \times \mathbb{C}^s\) using the real and complex embeddings.
  2. For any ideal \(\mathfrak{a}\), consider it as a lattice in this space.
  3. Minkowski's Theorem: Any convex symmetric body of sufficient volume contains a non-zero lattice point.
  4. Apply to a suitable region to find an element \(\alpha \in \mathfrak{a}\) with bounded norm.
  5. Show \(\mathfrak{a}\) is equivalent in the class group to an ideal with norm bounded by Minkowski's bound:

    6. \[M_K = \frac{n!}{n^n}\left(\frac{4}{\pi}\right)^s \sqrt{|\Delta_K|}\]

  6. There are only finitely many ideals with norm \(\leq M_K\), so \(\text{Cl}(K)\) is finite.

Notation Guide

  • \(K, L\) — number fields
  • \([K:\mathbb{Q}] = n\) — degree of extension
  • \(\mathcal{O}_K\) — ring of integers
  • \(\mathfrak{a}, \mathfrak{b}, \mathfrak{p}\) — ideals (Gothic font convention)
  • \((\alpha)\) — principal ideal generated by \(\alpha\)
  • \(\mathfrak{a} | \mathfrak{b}\) — \(\mathfrak{a}\) divides \(\mathfrak{b}\)
  • \(N(\mathfrak{a})\) or \(N_{K/\mathbb{Q}}(\mathfrak{a})\) — ideal norm
  • \(\text{Cl}(K)\) — class group

Lie Theory: Symmetry and Continuous Groups

lie-theory

Historical Context

Lie theory, initiated by Sophus Lie in the 1870s, studies continuous symmetries through the lens of group theory and differential geometry. Lie sought to extend Galois's work on algebraic equations to differential equations, developing the theory of transformation groups that bear his name. The subject flourished in the 20th century through the work of Élie Cartan, Hermann Weyl, and Claude Chevalley, connecting algebra, geometry, and analysis. Lie groups describe continuous symmetries in physics—from rotations and Lorentz transformations to the gauge symmetries of particle physics. Lie algebras, their infinitesimal counterparts, provide a linearization that makes the theory computationally tractable. Representation theory of Lie groups is fundamental to quantum mechanics and modern particle physics.

Definitions

  • Lie Group: A smooth manifold \(G\) that is also a group, with smooth multiplication and inversion maps.
  • Lie Algebra: A vector space \(\mathfrak{g}\) with a bilinear bracket \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) satisfying antisymmetry and the Jacobi identity.
  • Exponential Map: \(\exp: \mathfrak{g} \to G\), relating the Lie algebra to the Lie group.
  • Adjoint Representation: \(\text{Ad}: G \to GL(\mathfrak{g})\), the action of \(G\) on its Lie algebra by conjugation.
  • Root System: For a semisimple Lie algebra, a finite set of vectors in the dual of a Cartan subalgebra encoding the structure.
  • Weyl Group: The group generated by reflections through hyperplanes orthogonal to roots.
  • Universal Cover: The simply connected Lie group covering a given connected Lie group.

Theorem: Lie's Third Theorem

Theorem: Every finite-dimensional Lie algebra \(\mathfrak{g}\) over \(\mathbb{R}\) or \(\mathbb{C}\) is the Lie algebra of some Lie group \(G\).

Moreover, there exists a unique (up to isomorphism) simply connected Lie group \(\tilde{G}\) with Lie algebra \(\mathfrak{g}\).

Proof Sketch

The proof uses Ado's theorem and the Baker-Campbell-Hausdorff formula:

  1. Ado's Theorem: Every finite-dimensional Lie algebra has a faithful finite-dimensional representation.
  2. Embed \(\mathfrak{g}\) into \(\mathfrak{gl}(n, \mathbb{R})\) for some \(n\).
  3. Exponentiate to obtain a subgroup of \(GL(n, \mathbb{R})\).
  4. The Baker-Campbell-Hausdorff formula shows that near the identity, the group structure is determined by the Lie bracket:

    5. \[\exp(X)\exp(Y) = \exp\left(X + Y + \frac{1}{2}[X,Y] + \frac{1}{12}[X,[X,Y]] - \frac{1}{12}[Y,[X,Y]] + \cdots\right)\]

  5. For simply connected groups, use the fact that any Lie algebra homomorphism lifts to a group homomorphism.

Notation Guide

  • \(G, H\) — Lie groups
  • \(\mathfrak{g}, \mathfrak{h}\) — Lie algebras (Gothic font)
  • \(e\) or \(I\) — identity element
  • \(T_e G\) — tangent space at identity (Lie algebra)
  • \([X, Y]\) — Lie bracket
  • \(\exp(X)\) or \(e^X\) — exponential map
  • \(\text{Ad}_g(X) = gXg^{-1}\) — adjoint action
  • \(\text{ad}_X(Y) = [X, Y]\) — adjoint representation of algebra
  • \(\mathfrak{h} \subseteq \mathfrak{g}\) — Cartan subalgebra
  • \(\Phi, \Delta\) — root system, simple roots
  • \(W\) — Weyl group

def so3_basis():
    """Return basis for so(3): generators of rotations around x, y, z axes."""
    Lx = np.array([[0, 0, 0], [0, 0, -1], [0, 1, 0]])
    Ly = np.array([[0, 0, 1], [0, 0, 0], [-1, 0, 0]])
    Lz = np.array([[0, -1, 0], [1, 0, 0], [0, 0, 0]])
    return [Lx, Ly, Lz]

def so3_element(omega):
    """
    Create element of so(3) from angular velocity vector.
    omega = (omega_x, omega_y, omega_z)
    Returns: omega_x * Lx + omega_y * Ly + omega_z * Lz
    """
    Lx, Ly, Lz = so3_basis()
    return omega[0] * Lx + omega[1] * Ly + omega[2] * Lz

def SO3_from_so3(omega):
    """
    Exponential map from so(3) to SO(3).
    Uses Rodrigues' rotation formula.
    """
    theta = norm(omega)
    if theta < 1e-10:
        return np.eye(3)
    
    # K = so3_element(omega / theta) is unit skew-symmetric
    K = so3_element(omega / theta)
    
    # Rodrigues' formula: exp(theta * K) = I + sin(theta) * K + (1 - cos(theta)) * K^2
    return np.eye(3) + np.sin(theta) * K + (1 - np.cos(theta)) * (K @ K)

def so3_from_SO3(R):
    """
    Logarithm map from SO(3) to so(3).
    Returns angular velocity vector.
    """
    # Use matrix logarithm
    log_R = logm(R)
    # Extract components (so(3) is skew-symmetric)
    omega_x = log_R[2, 1]
    omega_y = log_R[0, 2]
    omega_z = log_R[1, 0]
    return np.array([omega_x, omega_y, omega_z])

🎯 Problem Corner

Problem (IMO Shortlist): Let \(n\) be a positive integer. A sequence of integers \(a_0, a_1, \ldots, a_n\) is called good if:

  • \(a_0 = 0\)
  • For \(0 \leq i \leq n-1\), \(|a_{i+1} - a_i| = 1\)
  • All \(a_i\) are distinct

Find the number of good sequences of length \(n\).

Hint

Consider the maximum value reached by the sequence. What constraints does this impose? Think about Catalan numbers and their combinatorial interpretations.

Solution

Let \(M = \max_{0 \leq i \leq n} a_i\). Since all values are distinct integers and we start at 0, we must have \(a_i \in \{0, 1, \ldots, M\}\) for all \(i\).

The sequence must reach \(M\) at some point, say at index \(k\). Before reaching \(M\), the sequence increases from 0. After reaching \(M\), it must decrease (since we can't exceed \(M\) and all values must be distinct).

Consider the path as a walk on the integers. The condition that all values are distinct means we never revisit a vertex. This is equivalent to a Dyck path that stays strictly above 0 (except at the start) until the maximum, then returns to 0 without revisiting any point.

After careful analysis, the number of such sequences is the Catalan number \(C_{\lfloor n/2 \rfloor}\) when \(n\) is even, and 0 when \(n\) is odd (since we need to return to 0 with steps of size 1).

More precisely, for a sequence of length \(n\) (i.e., \(n+1\) terms from \(a_0\) to \(a_n\)), the answer is:

\[\begin{cases} C_{n/2} & \text{if } n \text{ is even} \\ 0 & \text{if } n \text{ is odd} \end{cases}\]

where \(C_k = \frac{1}{k+1}\binom{2k}{k}\) is the \(k\)-th Catalan number.

Mandelbrot Set Explorer

The Mandelbrot set is the set of complex numbers \(c\) for which the sequence \(z_{n+1} = z_n^2 + c\) with \(z_0 = 0\) remains bounded. This simple recursive formula generates one of the most intricate and beautiful objects in mathematics.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more detail, with miniature copies of the whole set appearing at various scales. This self-similarity is a hallmark of fractal geometry.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until divergence
    for a given complex number c.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100):
    """
    Generate a 2D array representing the Mandelbrot set.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M
