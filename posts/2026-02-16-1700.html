1. Algebraic Topology: The Fundamental Group

Motivation

How can we distinguish topological spaces? The fundamental group, introduced by Poincaré, captures "holes" in a space by studying loops. It transforms topological questions into algebraic ones, making them more tractable.

Definitions

Definition. A path in \(X\) is a continuous map \(\gamma: [0,1] \to X\). A loop is a path with \(\gamma(0) = \gamma(1) = x_0\).

Definition. Two paths \(\gamma_0, \gamma_1\) are homotopic

Definition. The fundamental group \(\pi_1(X, x_0)\) is the set of homotopy classes of loops based at \(x_0\), with operation induced by path concatenation.

Theorem & Proof

Fundamental Group of the Circle. \(\pi_1(S^1, 1) \cong \mathbb{Z}\).

Proof. Define the winding number map \(\phi: \pi_1(S^1, 1) \to \mathbb{Z}\) by lifting loops to paths in \(\mathbb{R}\) via the covering map \(p: \mathbb{R} \to S^1\), \(p(t) = e^{2\pi i t}\).

For loop \(\gamma\) in \(S^1\), lift to \(\tilde{\gamma}: [0,1] \to \mathbb{R}\) with \(p \circ \tilde{\gamma} = \gamma\) and \(\tilde{\gamma}(0) = 0\). Define \(\phi([\gamma]) = \tilde{\gamma}(1) \in \mathbb{Z}\).

This is well-defined (homotopic loops have same endpoint), a homomorphism (concatenation adds lifts), surjective (loops winding \(n\) times), and injective (different integers give non-homotopic loops). ∎

Notation Guide

  • \(\pi_1(X, x_0)\) — fundamental group
  • \(S^1\) — unit circle
  • \(\simeq\) — homotopic
  • \([\gamma]\) — homotopy class of path \(\gamma\)
  • \(p: \tilde{X} \to X\) — covering map

Python Code

import numpy as np
import matplotlib.pyplot as plt

def winding_number(path, center=0):
    """
    Compute winding number of a closed path around center.
    Path is array of complex numbers.
    """
    # Shift to center
    path = np.array(path) - center
    
    # Compute change in argument
    angles = np.angle(path)
    
    # Unwrap to handle branch cuts
    angles = np.unwrap(angles)
    
    # Total change in angle divided by 2π
    total_change = angles[-1] - angles[0]
    
    # For closed paths, this should be 2π * integer
    return round(total_change / (2 * np.pi))

def generate_loop(n_windings, n_points=1000):
    """Generate a loop winding n times around origin"""
    t = np.linspace(0, 2*np.pi, n_points)
    # Add some perturbation to make it interesting
    r = 1 + 0.1 * np.sin(5*t)
    z = r * np.exp(1j * n_windings * t)
    return z

# Test winding numbers
for n in [-2, -1, 0, 1, 2, 3]:
    loop = generate_loop(n)
    computed = winding_number(loop)
    print(f"True winding: {n:2d}, Computed: {computed:2d}, Match: {n == computed}")

# Visualize different loops
fig, axes = plt.subplots(2, 3, figsize=(12, 8))
for idx, n in enumerate([-2, -1, 0, 1, 2, 3]):
    ax = axes[idx // 3, idx % 3]
    loop = generate_loop(n)
    ax.plot(loop.real, loop.imag, 'b-', linewidth=2)
    ax.plot(0, 0, 'ro', markersize=10)
    ax.set_aspect('equal')
    ax.set_title(f'Winding number = {n}')
    ax.grid(True)
plt.tight_layout()
plt.savefig('/tmp/winding_numbers.png', dpi=150)
print("\nVisualization saved")

2. Game Theory: Nash Equilibrium

Motivation

In strategic interactions, what constitutes a "solution"? John Nash's concept of equilibrium—where no player can benefit by unilaterally changing strategy—provides the foundation for analyzing competitive and cooperative behavior across economics, biology, and political science.

Definitions

Definition. A normal form game is \(\langle N, (A_i), (u_i) \rangle\) where \(N\) is the set of players, \(A_i\) is player \(i\)'s action set, and \(u_i: A \to \mathbb{R}\) is the payoff function.

Definition. A mixed strategy \(\sigma_i\) is a probability distribution over \(A_i\).

Definition. A Nash equilibrium is a strategy profile \(\sigma^* = (\sigma_1^*, \ldots, \sigma_n^*)\) such that for all \(i\) and all \(\sigma_i\):

\[u_i(\sigma_i^*, \sigma_{-i}^*) \geq u_i(\sigma_i, \sigma_{-i}^*)\]

Theorem & Proof

Nash's Existence Theorem. Every finite normal-form game has at least one Nash equilibrium in mixed strategies.

Proof Sketch. Define the best response correspondence \(BR_i(\sigma_{-i}) = \arg\max_{\sigma_i} u_i(\sigma_i, \sigma_{-i})\). The product correspondence \(BR = BR_1 \times \cdots \times BR_n\) maps the strategy simplex to itself.

By Brouwer's fixed point theorem (or Kakutani's for the correspondence), \(BR\) has a fixed point. At this point, each player is playing a best response to others' strategies—a Nash equilibrium. ∎

Notation Guide

  • \(N\) — set of players
  • \(A_i\) — action set for player \(i\)
  • \(\sigma_{-i}\) — strategies of all players except \(i\)
  • \(BR_i\) — best response correspondence
  • \(\Delta(A_i)\) — set of mixed strategies

Python Code

import numpy as np
from scipy.optimize import minimize

def find_nash_equilibrium_2x2(payoff_A, payoff_B):
    """
    Find Nash equilibrium for 2x2 bimatrix game.
    payoff_A[i,j] = payoff to player A when A plays i, B plays j
    """
    # For 2x2 game, parameterize mixed strategies
    # Player A plays action 0 with prob p, action 1 with prob 1-p
    # Player B plays action 0 with prob q, action 1 with prob 1-q
    
    def expected_payoff_A(p, q):
        return p * (q * payoff_A[0,0] + (1-q) * payoff_A[0,1]) + \
               (1-p) * (q * payoff_A[1,0] + (1-q) * payoff_A[1,1])
    
    def expected_payoff_B(p, q):
        return q * (p * payoff_B[0,0] + (1-p) * payoff_B[1,0]) + \
               (1-q) * (p * payoff_B[0,1] + (1-p) * payoff_B[1,1])
    
    # Find equilibrium by solving indifference conditions
    # At equilibrium, each player is indifferent between actions played with positive prob
    
    # If both mix: A's payoff from action 0 = payoff from action 1
    # q * a00 + (1-q) * a01 = q * a10 + (1-q) * a11
    a00, a01, a10, a11 = payoff_A.flatten()
    b00, b01, b10, b11 = payoff_B.flatten()
    
    # Solve for q that makes A indifferent
    if (a00 - a10 + a11 - a01) != 0:
        q_star = (a11 - a01) / (a00 - a10 + a11 - a01)
    else:
        q_star = None
    
    # Solve for p that makes B indifferent  
    if (b00 - b01 + b11 - b10) != 0:
        p_star = (b11 - b01) / (b00 - b01 + b11 - b10)
    else:
        p_star = None
    
    return p_star, q_star

# Example: Prisoner's Dilemma
#         Cooperate    Defect
# Cooperate  (-1,-1)   (-3, 0)
# Defect      (0,-3)   (-2,-2)
payoff_A = np.array([[-1, -3], [0, -2]])
payoff_B = np.array([[-1, 0], [-3, -2]])

p, q = find_nash_equilibrium_2x2(payoff_A, payoff_B)
print(f"Prisoner's Dilemma:")
print(f"Player A plays Cooperate with prob: {p}")
print(f"Player B plays Cooperate with prob: {q}")
print(f"Nash equilibrium: Both defect (p=0, q=0)")

# Example: Matching Pennies (zero-sum)
payoff_A = np.array([[1, -1], [-1, 1]])
payoff_B = np.array([[-1, 1], [1, -1]])
p, q = find_nash_equilibrium_2x2(payoff_A, payoff_B)
print(f"\nMatching Pennies:")
print(f"Player A plays Heads with prob: {p}")
print(f"Player B plays Heads with prob: {q}")
print(f"Nash equilibrium: Both randomize 50/50")

3. Algebraic Geometry: Elliptic Curves

Motivation

Elliptic curves are the simplest non-trivial algebraic varieties with rich structure. They underpin modern cryptography (ECC), were essential in proving Fermat's Last Theorem, and connect number theory, geometry, and complex analysis.

Definitions

Definition. An elliptic curve over field \(K\) is a smooth projective curve of genus 1 with a specified point \(O\). In Weierstrass form:

\[y^2 = x^3 + ax + b\]

with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\) ensuring smoothness.

Definition. The chord-tangent group law: for points \(P, Q\) on \(E\), draw line through them (tangent if \(P=Q\)), find third intersection \(R\), reflect over x-axis to get \(P + Q\).

Theorem & Proof

Group Structure. The points on an elliptic curve form an abelian group under the chord-tangent law, with identity \(O\) (point at infinity).

Proof Sketch. Associativity is the hard part—can be shown via the Cayley-Bacharach theorem or by identifying with the Picard group. Commutativity follows from symmetry of the construction. Inverses exist by reflection. ∎

Notation Guide

  • \(E\) — elliptic curve
  • \(E(K)\) — K-rational points
  • \(O\) — point at infinity (identity)
  • \(\Delta\) — discriminant
  • \([n]P\) — n-fold addition of P

Python Code

import numpy as np
import matplotlib.pyplot as plt

class EllipticCurve:
    def __init__(self, a, b):
        self.a = a
        self.b = b
        # Check smoothness
        discriminant = -16 * (4*a**3 + 27*b**2)
        if discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
    
    def is_on_curve(self, x, y):
        """Check if point (x,y) is on the curve"""
        return y**2 == x**3 + self.a * x + self.b
    
    def add_points(self, P, Q):
        """
        Add two points on the curve.
        Points are tuples (x, y) or None for point at infinity.
        """
        # Identity cases
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # Check if on curve
        assert self.is_on_curve(x1, y1)
        assert self.is_on_curve(x2, y2)
        
        # P + (-P) = O
        if x1 == x2 and y1 == -y2:
            return None
        
        # Compute slope
        if x1 == x2:  # P == Q (point doubling)
            m = (3*x1**2 + self.a) / (2*y1)
        else:  # P != Q
            m = (y2 - y1) / (x2 - x1)
        
        # Compute result
        x3 = m**2 - x1 - x2
        y3 = m*(x1 - x3) - y1
        
        return (x3, y3)
    
    def scalar_mult(self, n, P):
        """Compute n*P using double-and-add"""
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add_points(result, addend)
            addend = self.add_points(addend, addend)
            n >>= 1
        
        return result

# Example: y^2 = x^3 - x + 1
E = EllipticCurve(-1, 1)

# Base point
P = (0, 1)
print(f"P = {P}, on curve: {E.is_on_curve(*P)}")

# Compute multiples
for n in range(1, 6):
    nP = E.scalar_mult(n, P)
    print(f"{n}P = {nP}")

# Plot the curve
x = np.linspace(-2, 3, 1000)
y_squared = x**3 - x + 1
# Only plot where y^2 >= 0
mask = y_squared >= 0
x_pos = x[mask]
y_pos = np.sqrt(y_squared[mask])
y_neg = -y_pos

plt.figure(figsize=(10, 8))
plt.plot(x_pos, y_pos, 'b-', linewidth=2)
plt.plot(x_pos, y_neg, 'b-', linewidth=2)
plt.plot(*P, 'ro', markersize=10, label='P')
plt.axhline(y=0, color='k', linewidth=0.5)
plt.axvline(x=0, color='k', linewidth=0.5)
plt.grid(True, alpha=0.3)
plt.title('Elliptic Curve: y² = x³ - x + 1')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.savefig('/tmp/elliptic_curve.png', dpi=150)
print("\nCurve visualization saved")

1. Cryptography: Elliptic Curve Diffie-Hellman

Motivation

The Diffie-Hellman key exchange allows two parties to establish a shared secret over an insecure channel. Elliptic Curve Diffie-Hellman (ECDH) achieves equivalent security to classical DH with much smaller key sizes, making it ideal for constrained devices.

Definitions

Definition. The Elliptic Curve Discrete Logarithm Problem (ECDLP): given points \(P\) and \(Q = [n]P\) on \(E(\mathbb{F}_q)\), find \(n\).

Definition. The ECDH protocol: Alice sends \([a]G\), Bob sends \([b]G\), shared secret is \([ab]G\).

Theorem & Proof

Security of ECDH. Breaking ECDH is equivalent to solving the Computational Diffie-Hellman (CDH) problem on elliptic curves.

Proof Sketch. An adversary sees \(G, [a]G, [b]G\) and wants \([ab]G\). If they can solve ECDLP, they find \(a\) or \(b\) and compute \([ab]G\). Conversely, an algorithm solving CDH can potentially solve ECDLP via reduction (though this is not a tight equivalence). ∎

Notation Guide

  • \(G\) — generator (base point)
  • \(n\) — private key
  • \([n]G\) — public key
  • \(\mathbb{F}_q\) — finite field with q elements

Python Code

import hashlib
import secrets

class ECPoint:
    """Point on elliptic curve over finite field"""
    def __init__(self, x, y, curve):
        self.x = x % curve.p
        self.y = y % curve.p
        self.curve = curve
        self.infinity = False
    
    @classmethod
    def infinity(cls, curve):
        p = cls(0, 0, curve)
        p.infinity = True
        return p
    
    def __add__(self, other):
        if self.infinity:
            return other
        if other.infinity:
            return self
        
        p = self.curve.p
        
        if self.x == other.x and (self.y + other.y) % p == 0:
            return ECPoint.infinity(self.curve)
        
        if self.x == other.x and self.y == other.y:
            # Point doubling
            lam = (3 * self.x**2 + self.curve.a) * pow(2 * self.y, -1, p) % p
        else:
            # Point addition
            lam = (other.y - self.y) * pow(other.x - self.x, -1, p) % p
        
        x3 = (lam**2 - self.x - other.x) % p
        y3 = (lam * (self.x - x3) - self.y) % p
        
        return ECPoint(x3, y3, self.curve)
    
    def __rmul__(self, n):
        """Scalar multiplication"""
        result = ECPoint.infinity(self.curve)
        addend = self
        
        while n > 0:
            if n & 1:
                result = result + addend
            addend = addend + addend
            n >>= 1
        
        return result

class EllipticCurveFinite:
    """Elliptic curve over finite field"""
    def __init__(self, a, b, p):
        self.a = a
        self.b = b
        self.p = p

# Curve25519-like parameters (simplified)
curve = EllipticCurveFinite(486662, 1, 2**255 - 19)

# Base point (simplified for demonstration)
G = ECPoint(9, 1478161944758954479102059356840998688726460613461, curve)

def ecdh_key_exchange():
    """Demonstrate ECDH key exchange"""
    # Alice generates key pair
    a = secrets.randbelow(curve.p)
    A = a * G
    
    # Bob generates key pair
    b = secrets.randbelow(curve.p)
    B = b * G
    
    # Alice computes shared secret
    shared_alice = a * B
    
    # Bob computes shared secret
    shared_bob = b * A
    
    # Should be equal
    assert shared_alice.x == shared_bob.x
    
    return shared_alice.x

2. Auction Theory: The Vickrey Auction

Motivation

How should we design auctions to achieve efficient outcomes? William Vickrey's 1961 analysis of second-price auctions revealed surprising properties about truthful bidding, earning him the 1996 Nobel Prize in Economics.

Definitions

Definition. In a second-price sealed-bid auction (Vickrey auction), the highest bidder wins but pays the second-highest bid.

Definition. A mechanism is strategyproof (dominant-strategy incentive-compatible) if truthful bidding is optimal regardless of others' strategies.

Theorem & Proof

Vickrey's Theorem. In a second-price auction, bidding one's true valuation is a dominant strategy.

Proof. Consider bidder \(i\) with valuation \(v_i\) considering bid \(b_i\). Let \(b_{(1)}^{-i}\) be the highest bid among other bidders.

Case 1: \(v_i > b_{(1)}^{-i}\). Truthful bidding wins, payoff \(v_i - b_{(1)}^{-i} > 0\). Underbidding risks losing (payoff 0). Overbidding doesn't change price.

Case 2: \(v_i < b_{(1)}^{-i}\). Truthful bidding loses, payoff 0. Overbidding risks winning with negative payoff. Underbidding still loses.

Case 3: \(v_i = b_{(1)}^{-i}\). Indifferent. ∎

Notation Guide

  • \(v_i\) — true valuation of bidder \(i\)
  • \(b_i\) — bid submitted by bidder \(i\)
  • \(b_{(1)}^{-i}\) — highest bid excluding \(i\)
  • DSIC — Dominant Strategy Incentive Compatible

Python Code

import numpy as np

def vickrey_auction(bids):
    """
    Run second-price sealed-bid auction.
    Returns (winner_index, price_paid).
    """
    if len(bids) < 2:
        return None, 0
    
    # Find winner and second highest bid
    sorted_bids = sorted(enumerate(bids), key=lambda x: x[1], reverse=True)
    winner = sorted_bids[0][0]
    price = sorted_bids[1][1]  # Second highest
    
    return winner, price

def simulate_auction(valuations, strategies):
    """
    Simulate auction with given strategies.
    strategies[i](v) = bid for valuation v
    """
    bids = [strategies[i](valuations[i]) for i in range(len(valuations))]
    winner, price = vickrey_auction(bids)
    
    if winner is None:
        return None, 0, [0] * len(valuations)
    
    # Calculate payoffs
    payoffs = [0] * len(valuations)
    payoffs[winner] = valuations[winner] - price
    
    return winner, price, payoffs

# Demonstrate incentive compatibility
np.random.seed(42)
n_bidders = 5
valuations = np.random.uniform(0, 100, n_bidders)

print("Valuations:", valuations.round(2))

# Truthful bidding
truthful_strategies = [lambda v, i=i: v for i in range(n_bidders)]
winner, price, payoffs = simulate_auction(valuations, truthful_strategies)
print(f"\nTruthful bidding:")
print(f"  Winner: Bidder {winner} (val={valuations[winner]:.2f})")
print(f"  Price paid: {price:.2f}")
print(f"  Winner payoff: {payoffs[winner]:.2f}")

# What if winner had underbid?
underbid_strategies = [lambda v, i=i: v if i != winner else v * 0.8 
                       for i in range(n_bidders)]
_, _, payoffs_under = simulate_auction(valuations, underbid_strategies)
print(f"\nIf winner underbid by 20%:")
print(f"  Winner payoff: {payoffs_under[winner]:.2f}")
print(f"  Underbidding is {'worse' if payoffs_under[winner] < payoffs[winner] else 'better'}")

# What if winner had overbid?
overbid_strategies = [lambda v, i=i: v if i != winner else v * 1.2 
                      for i in range(n_bidders)]
_, _, payoffs_over = simulate_auction(valuations, overbid_strategies)
print(f"\nIf winner overbid by 20%:")
print(f"  Winner payoff: {payoffs_over[winner]:.2f}")
print(f"  Same payoff (as expected)")

3. Network Security: Zero-Knowledge Proofs

Motivation

How can you prove you know a secret without revealing it? Zero-knowledge proofs, introduced by Goldwasser, Micali, and Rackoff in 1985, enable exactly this paradoxical capability with profound implications for privacy and authentication.

Definitions

Definition. A zero-knowledge proof is an interactive protocol where a prover convinces a verifier that a statement is true, revealing nothing beyond the statement's validity.

Definition. A protocol has completeness if honest prover convinces honest verifier of true statements; soundness if cheating prover can only convince with negligible probability.

Theorem & Proof

Schnorr's Protocol. For cyclic group \(G = \langle g \rangle\) of prime order \(q\), there exists a zero-knowledge proof of knowledge of discrete log.

Protocol. Prover knows \(x\) with \(h = g^x\). Commitment: \(t = g^r\) for random \(r\). Challenge: verifier sends \(c\). Response: \(s = r + cx \pmod{q}\). Verifier checks \(g^s = t \cdot h^c\).

Proof of ZK. Simulator generates random \(s\), \(c\), sets \(t = g^s / h^c\). Distribution is identical to real protocol since \(c\) is uniform. ∎

Notation Guide

  • \(g\) — generator of cyclic group
  • \(h = g^x\) — public key
  • \(x\) — private key (witness)
  • \(r\) — random nonce
  • \(c\) — challenge

Python Code

import hashlib
import secrets

def schnorr_proof(p, q, g, h, x):
    """
    Schnorr's zero-knowledge proof of knowledge of discrete log.
    Prover knows x such that h = g^x mod p.
    """
    # Commitment phase
    r = secrets.randbelow(q)
    t = pow(g, r, p)
    
    # Challenge (in real protocol, verifier sends this)
    # Using Fiat-Shamir heuristic for non-interactive version
    challenge_data = f"{g},{h},{t}".encode()
    c = int(hashlib.sha256(challenge_data).hexdigest(), 16) % q
    
    # Response
    s = (r + c * x) % q
    
    return t, c, s

def schnorr_verify(p, q, g, h, t, c, s):
    """Verify Schnorr proof"""
    # Check: g^s == t * h^c (mod p)
    left = pow(g, s, p)
    right = (t * pow(h, c, p)) % p
    return left == right

# Example parameters (small for demonstration)
p = 23  # Prime
q = 11  # Order of subgroup  
g = 2   # Generator

# Prover's secret
x = 6
h = pow(g, x, p)  # Public key

print(f"Public parameters: p={p}, q={q}, g={g}")
print(f"Prover's public key: h = g^x mod p = {h}")
print(f"Prover's secret: x = {x} (kept private)")

# Generate proof
t, c, s = schnorr_proof(p, q, g, h, x)
print(f"\nProof generated:")
print(f"  Commitment t = {t}")
print(f"  Challenge c = {c}")
print(f"  Response s = {s}")

# Verify
is_valid = schnorr_verify(p, q, g, h, t, c, s)
print(f"\nVerification: {'PASSED' if is_valid else 'FAILED'}")

# Demonstrate zero-knowledge: simulate without knowing x
def simulate_proof(p, q, g, h):
    """Simulate a proof without knowing x"""
    s = secrets.randbelow(q)
    c = secrets.randbelow(q)
    t = (pow(g, s, p) * pow(pow(h, c, p), -1, p)) % p
    return t, c, s

sim_t, sim_c, sim_s = simulate_proof(p, q, g, h)
sim_valid = schnorr_verify(p, q, g, h, sim_t, sim_c, sim_s)
print(f"\nSimulated proof verification: {'PASSED' if sim_valid else 'FAILED'}")
print("(Simulation produces indistinguishable transcripts)")

1. The Poincaré Conjecture

Historical Context

Henri Poincaré posed this problem in 1904: "Is every simply connected, closed 3-manifold homeomorphic to the 3-sphere?" It became one of the seven Millennium Prize Problems. After a false proof by Perelman in 2002-2003 (which was actually correct), the conjecture was finally resolved, earning Perelman the Fields Medal (which he declined) and the $1 million Millennium Prize (also declined).

Definitions

Definition. A manifold\u003c/em> is a space locally homeomorphic to \(\mathbb{R}^n\). A closed manifold is compact without boundary.

Definition. A space is simply connected if every loop can be continuously contracted to a point (\(\pi_1 = 0\)).

Theorem & Proof

Poincaré Conjecture (Perelman's Theorem). Every simply connected, closed 3-manifold is homeomorphic to \(S^3\).

Proof Sketch. Perelman used Hamilton's Ricci flow, which evolves a Riemannian metric by \(\frac{\partial g}{\partial t} = -2\text{Ric}(g)\). Singularities form, but Perelman showed they can be surgically removed, eventually yielding a round metric on \(S^3\). ∎

Notation Guide

  • \(M^3\) — 3-dimensional manifold
  • \(S^3\) — 3-sphere
  • \(g\) — Riemannian metric
  • Ric\((g)\) — Ricci curvature tensor

Python Code

import numpy as np
import matplotlib.pyplot as plt

def is_loop_contractible_on_sphere(path, tolerance=1e-6):
    """
    Check if a path on S^2 can be contracted (simplified check).
    On S^2, any closed loop can be contracted.
    """
    # Check if path is closed
    if np.linalg.norm(path[0] - path[-1]) > tolerance:
        return False
    
    # Check if path stays on sphere
    radii = np.linalg.norm(path, axis=1)
    on_sphere = np.all(np.abs(radii - 1) < tolerance)
    
    # On S^2, all closed loops are contractible
    return on_sphere

2. Evolutionary Game Theory

Historical Context

John Maynard Smith introduced evolutionary game theory in 1973, applying game-theoretic concepts to biological evolution. The key insight: strategies are inherited traits, and payoffs represent fitness. The central concept of Evolutionarily Stable Strategy (ESS) explains why certain behaviors persist in animal populations.

Definitions

Definition. A strategy \(x^*\) is an ESS if for all \(y \neq x^*\), either \(u(x^*, x^*) > u(y, x^*)\) or both \(u(x^*, x^*) = u(y, x^*)\) and \(u(x^*, y) > u(y, y)\).

Definition. The replicator dynamics describe how strategy frequencies change:

\[\dot{x}_i = x_i(u(e_i, x) - u(x, x))\]

Theorem & Proof

ESS Stability. If \(x^*\) is an ESS, it is asymptotically stable under replicator dynamics.

Proof. Consider the relative entropy (Kullback-Leibler divergence) as Lyapunov function: \[V(x) = \sum_i x_i^* \ln\frac{x_i^*}{x_i}\]

For ESS \(x^*\), one can show \(\dot{V}(x) < 0\) for \(x\) near \(x^*\), proving asymptotic stability. ∎

Notation Guide

  • ESS — Evolutionarily Stable Strategy
  • \(u(x, y)\) — payoff to x-playing mutant in y-population
  • \(e_i\) — pure strategy i (unit vector)
  • \(x_i\) — frequency of strategy i

Python Code

import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def replicator_dynamics(t, x, payoff_matrix):
    """
    Compute dx/dt for replicator dynamics.
    x: strategy frequencies (must sum to 1)
    """
    # Ensure normalization
    x = np.maximum(x, 0)
    x = x / np.sum(x)
    
    # Expected payoff for each pure strategy
    u = payoff_matrix @ x
    
    # Average payoff in population
    u_avg = x @ u
    
    # Replicator equation
    dxdt = x * (u - u_avg)
    
    return dxdt

def simulate_hawk_dove(b=3, c=2, t_span=(0, 20)):
    """
    Simulate Hawk-Dove game.
    Payoff matrix:
              Hawk    Dove
    Hawk    (b-c)/2   b
    Dove      0      b/2
    """
    # Payoff matrix (row player)
    payoff = np.array([[(b - c) / 2, b],
                       [0, b / 2]])
    
    # Simulate from various initial conditions
    fig, ax = plt.subplots(figsize=(10, 6))
    
    for x0_hawk in [0.1, 0.3, 0.5, 0.7, 0.9]:
        x0 = np.array([x0_hawk, 1 - x0_hawk])
        
        sol = solve_ivp(
            lambda t, x: replicator_dynamics(t, x, payoff),
            t_span, x0, dense_output=True
        )
        
        t = np.linspace(t_span[0], t_span[1], 200)
        x = sol.sol(t)
        
        ax.plot(t, x[0], label=f'Initial Hawk: {x0_hawk}')
    
    # Mark ESS
    ess_hawk = b / c
    ax.axhline(y=ess_hawk, color='r', linestyle='--', 
               label=f'ESS: Hawk = {ess_hawk:.2f}')
    
    ax.set_xlabel('Time')
    ax.set_ylabel('Frequency of Hawk')
    ax.set_title(f'Hawk-Dove Game (b={b}, c={c})')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    return fig

3. Homotopy Type Theory

Historical Context

Vladimir Voevodsky's 2006 Fields Medal work on motivic cohomology led him to question the foundations of mathematics. In 2010, he announced the Univalent Foundations program, developing homotopy type theory (HoTT) as a new foundation where types are spaces and equality is a path. This connects topology, logic, and computer science in profound ways.

Definitions

Definition. In HoTT, the identity type \(Id_A(a,b)\) represents paths from \(a\) to \(b\) in type \(A\).

Definition. The univalence axiom states that \((A = B) \simeq (A \simeq B)\): equivalent types are equal.

Theorem & Proof

Univalence Implies Function Extensionality. If \(f, g: A \to B\) and \(f(a) = g(a)\) for all \(a\), then \(f = g\).

Proof Sketch. Consider the type family \(P(x) = (f(x) = g(x))\). By assumption, \(\prod_{x:A} P(x)\) is inhabited. Using univalence and properties of identity types, this implies \(f = g\). ∎

Notation Guide

  • \(Id_A(a,b)\) or \(a =_A b\) — identity type
  • \(\simeq\) — equivalence of types
  • \(\prod_{x:A} B(x)\) — dependent product (Π-type)
  • \(\sum_{x:A} B(x)\) — dependent sum (Σ-type)

Python Code

from typing import Any, Callable, List, Union

@dataclass
class Path:
    """Represents a path (equality witness) between two points."""
    start: Any
    end: Any
    # In real HoTT, this would carry homotopical information
    
class Type:
    """Represents a type (space) in HoTT."""
    def __init__(self, name: str, elements: List[Any]):
        self.name = name
        self.elements = elements
        # Identity types for each pair
        self.paths = {}
    
    def add_path(self, a, b, path: Path):
        """Add a path (proof of equality) between a and b."""
        self.paths[(a, b)] = path
    
    def are_equal(self, a, b) -> bool:
        """Check if there's a path from a to b (propositional equality)."""
        return (a, b) in self.paths or a == b

class Equivalence:
    """Represents an equivalence between types (isomorphism up to homotopy)."""
    def __init__(self, source: Type, target: Type, 
                 forward: Callable, backward: Callable):
        self.source = source
        self.target = target
        self.forward = forward
        self.backward = backward

def univalence_principle(A: Type, B: Type, equiv: Equivalence) -> Path:
    """
    Univalence axiom: equivalence of types implies equality.
    In HoTT: (A ≃ B) → (A = B)
    """
    # This "creates" a path between types from an equivalence
    return Path(A, B)

4. Mechanism Design: The Revelation Principle

Historical Context

Leo Hurwicz founded mechanism design theory in the 1960s, asking how to design economic institutions that achieve desired outcomes when participants have private information. The revelation principle, developed by Gibbard (1973), Myerson (1979), and others, shows that any mechanism can be transformed into an equivalent direct mechanism where truth-telling is optimal. Hurwicz, Maskin, and Myerson shared the 2007 Nobel Prize for this work.

Definitions

Definition. A social choice function \(f: \Theta \to X\) maps type profiles to outcomes.

Definition. A direct mechanism\u003c/em> asks agents to report types directly and implements \(f(\hat{\theta})\).

Definition. \(f\) is truthfully implementable if truth-telling is a Bayesian Nash equilibrium.

Theorem & Proof

Revelation Principle. If a social choice function \(f\) can be implemented by any mechanism, it can be implemented by a direct mechanism where truth-telling is optimal.

Proof. Let \((M, g)\) implement \(f\) with equilibrium strategies \(\sigma^*\). Construct direct mechanism: ask for types \(\theta_i\), play \(\sigma_i^*(\theta_i)\) in original mechanism, output \(g(m)\). If agent could profitably lie in direct mechanism, they could have profitably deviated in original—a contradiction. ∎

Notation Guide

  • \(\Theta_i\) — type space of agent \(i\)
  • \(M_i\) — message space
  • \(g: M \to X\) — outcome function
  • \(\sigma_i: \Theta_i \to M_i\) — strategy

Python Code

def construct_direct_mechanism(original_mechanism, equilibrium_strategies, type_spaces):
    """
    Apply revelation principle: convert any mechanism to direct mechanism.
    
    Original: agents send messages m_i = sigma_i(theta_i)
    Direct: agents report theta_i, mechanism computes m_i = sigma_i(theta_i),
           then applies original outcome function
    """

        # Compute equilibrium messages
        messages = {
            i: equilibrium_strategies[i](reported_types[i])

        return original_mechanism.evaluate(messages)

📜 Math History

John Nash: A Beautiful Mind

John Forbes Nash Jr. was born on June 13, 1928, in Bluefield, West Virginia. His father was an electrical engineer, his mother a teacher. Even as a child, Nash showed exceptional mathematical ability, conducting electrical and chemistry experiments in his room.

Nash attended Carnegie Institute of Technology (now Carnegie Mellon) on a full scholarship, initially studying chemical engineering before switching to mathematics. His professors recognized his genius—one wrote a recommendation letter consisting of a single sentence: "This man is a genius."

At Princeton for graduate school, Nash was part of an extraordinary cohort that included John Milnor and Lloyd Shapley. He avoided classes, preferring to explore his own ideas. In 1950, at age 21, he completed his 28-page doctoral dissertation on non-cooperative games, introducing what would become known as the Nash equilibrium.

Nash's insight was deceptively simple: in any finite game, there exists a set of strategies where no player can benefit by unilaterally changing strategy. This concept revolutionized economics, providing a general solution concept for strategic interaction. Before Nash, economists analyzed only zero-sum games or specific examples.

In the 1950s, Nash made fundamental contributions to differential geometry and partial differential equations, embedding theorems that are still used today. But his personal life was unraveling. In 1959, he began showing signs of mental illness—paranoid schizophrenia. He resigned from MIT and spent years in psychiatric hospitals.

The following decades were tragic. Nash wandered Europe, was arrested, and struggled with delusions. Yet mathematics remained his anchor. Gradually, in the 1990s, he recovered, attributing his improvement partly to changing treatment approaches and partly to his own decision to reject delusional thinking.

In 1994, Nash shared the Nobel Prize in Economics with John Harsanyi and Reinhard Selten. Sylvia Nasar's 1998 biography "A Beautiful Mind" and the subsequent film brought his story to millions. Nash died in a car accident in 2015, returning from receiving the Abel Prize—mathematics' highest honor—for his work on nonlinear partial differential equations. His legacy endures in every economic model, every auction design, and every analysis of strategic behavior.

🧩 Problem Corner

Problem (IMO 2002 Shortlist). Let \(n\) be a positive integer. A game is played on a board consisting of a row of \(2n + 1\) squares. Initially, all squares are empty. Players alternately place a stone in an empty square. The game ends when there are \(n + 1\) stones on the board, at which point the player who has placed more stones in the center square wins. Determine which player has a winning strategy.

💡 Hint

Consider pairing strategy. The second player can use symmetry to neutralize the first player's moves, except for the crucial center square.

✅ Solution

The second player has a winning strategy.

Number the squares \(-n, -(n-1), \ldots, -1, 0, 1, \ldots, n\). Square 0 is the center.

The second player uses the following strategy: whenever the first player places a stone in square \(k\), the second player places a stone in square \(-k\).

This pairing strategy ensures that after each of the second player's moves, the configuration is symmetric about the center.

Key observation: The center square 0 is unpaired. If the first player ever plays in the center, the second player plays anywhere (say, square 1), and the first player cannot respond symmetrically.

However, the second player can ensure they place at least as many stones in the center as the first player: if the first player plays in center, the second player plays elsewhere; if the first player plays elsewhere, the second player mirrors.

Since there are \(n+1\) stones total and the second player makes the last move (move \(n+1\)), they can guarantee at least \(\lceil (n+1)/2 \rceil\) stones in the center, winning the game. ∎

🎨 Visualization of the Day

The Möbius Strip and Klein Bottle

The Möbius strip is the simplest non-orientable surface—a surface with only one side. Gluing two Möbius strips along their boundaries produces a Klein bottle, a closed surface that cannot be embedded in 3D space without self-intersection. These visualizations reveal the strange beauty of topology.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def mobius_strip(u, v, R=2):
    """
    Parametric Möbius strip.
    u in [0, 2π], v in [-1, 1]
    """
    x = (R + v * np.cos(u/2)) * np.cos(u)
    y = (R + v * np.cos(u/2)) * np.sin(u)
    z = v * np.sin(u/2)
    return x, y, z

def klein_bottle(u, v, a=2):
    """
    Parametric Klein bottle (figure-8 immersion).
    u, v in [0, 2π]
    """
    x = (a + np.cos(u/2)*np.sin(v) - np.sin(u/2)*np.sin(2*v)) * np.cos(u)
    y = (a + np.cos(u/2)*np.sin(v) - np.sin(u/2)*np.sin(2*v)) * np.sin(u)
    z = np.sin(u/2)*np.sin(v) + np.cos(u/2)*np.sin(2*v)
    return x, y, z
