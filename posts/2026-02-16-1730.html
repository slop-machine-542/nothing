Pure Math Deep-Dives

1. Measure-Theoretic Foundations

Motivation: Not all subsets of \(\mathbb{R}\) can be assigned a meaningful "size." Measure theory provides the rigorous foundation for probability.

Definitions

  • \(\sigma\)-algebra:\(\mathcal{F} \subseteq \mathcal{P}(\Omega)\) closed under complements and countable unions
  • Measure:\(\mu: \mathcal{F} \to [0, \infty]\) with \(\mu(\emptyset) = 0\) and countable additivity
  • Probability measure:\(P(\Omega) = 1\)
  • Borel \(\sigma\)-algebra:\(\mathcal{B}(\mathbb{R})\) generated by open sets

Theorem (Carathéodory Extension)

A countably additive set function on an algebra extends uniquely to a measure on the generated \(\sigma\)-algebra.

Proof Sketch

Define outer measure \(\mu^*(A) = \inf\{\sum \mu(A_n) : A \subseteq \bigcup A_n\}\). A set \(E\) is measurable if \(\mu^*(A) = \mu^*(A \cap E) + \mu^*(A \cap E^c)\) for all \(A\). Show measurable sets form a \(\sigma\)-algebra and \(\mu^*\) is a measure there. \(\square\)

Notation Guide

  • \((\Omega, \mathcal{F}, P)\): Probability space
  • \(\mathcal{B}(\mathbb{R}^n)\): Borel sets in \(\mathbb{R}^n\)
  • \(\lambda\): Lebesgue measure
  • \(\sigma(X)\): \(\sigma\)-algebra generated by random variable \(X\)

Python Code

import numpy as np
from scipy import stats

class SimpleProbabilitySpace:
    """Simple finite probability space implementation."""
    
    def __init__(self, outcomes, probabilities):
        """
        outcomes: list of outcomes
        probabilities: corresponding probabilities
        """
        self.outcomes = outcomes
        self.probabilities = np.array(probabilities)
        assert np.isclose(np.sum(self.probabilities), 1.0)
        assert np.all(self.probabilities >= 0)
    
    def measure(self, event):
        """Compute probability of an event (subset of outcomes)."""
        indices = [self.outcomes.index(o) for o in event if o in self.outcomes]
        return np.sum(self.probabilities[indices])
    
    def expectation(self, random_variable):
        """E[X] = sum X(omega) * P(omega)"""
        return np.sum(random_variable * self.probabilities)

# Example: Fair die
outcomes = [1, 2, 3, 4, 5, 6]
probabilities = [1/6] * 6
space = SimpleProbabilitySpace(outcomes, probabilities)

# Random variable: X(omega) = omega
X = np.array(outcomes)
print(f"E[X] for fair die: {space.expectation(X):.4f}")

# Event: even number
event = [2, 4, 6]
print(f"P(even): {space.measure(event):.4f}")

2. The Law of Large Numbers

Motivation: Why do sample averages converge to expected values? The LLN provides rigorous foundations for statistical inference.

Definitions

  • Convergence almost surely:\(X_n \xrightarrow{a.s.} X\) means \(P(\lim X_n = X) = 1\)
  • Convergence in probability:\(X_n \xrightarrow{P} X\) means \(P(|X_n - X| > \epsilon) \to 0\)
  • i.i.d.: Independent and identically distributed

Theorem (Strong Law of Large Numbers)

Let \(X_1, X_2, \ldots\) be i.i.d. with \(\mathbb{E}[|X_1|] < \infty\). Then:

\[\frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{a.s.} \mathbb{E}[X_1]\]

Proof (Sketch, assuming finite 4th moment)

Assume \(\mu = 0\) and \(\mathbb{E}[X^4] < \infty\). Compute: \[\mathbb{E}\left[\left(\sum_{i=1}^n X_i\right)^4\right] = n\mathbb{E}[X^4] + 3n(n-1)\mathbb{E}[X^2]^2 = O(n^2)\] By Chebyshev, \(P(|S_n/n| > \epsilon) = O(1/n^2)\). Since \(\sum 1/n^2 < \infty\), Borel-Cantelli gives a.s. convergence. \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def demonstrate_lln(distribution, expected_value, n_max=10000, n_trials=100):
    """
    Demonstrate Law of Large Numbers visually.
    """
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))
    
    # Single trajectory
    samples = distribution(n_max)
    cumulative_means = np.cumsum(samples) / np.arange(1, n_max + 1)
    
    axes[0].plot(range(1, n_max + 1), cumulative_means, alpha=0.7)
    axes[0].axhline(y=expected_value, color='r', linestyle='--', label=f'E[X] = {expected_value}')
    axes[0].set_xlabel('n')
    axes[0].set_ylabel('Sample Mean')
    axes[0].set_title('Single Trajectory: Sample Mean vs n')
    axes[0].legend()
    axes[0].set_xscale('log')
    axes[0].grid(True)
    
    # Multiple trajectories
    for _ in range(n_trials):
        samples = distribution(n_max)
        cumulative_means = np.cumsum(samples) / np.arange(1, n_max + 1)
        axes[1].plot(range(1, n_max + 1), cumulative_means, alpha=0.1, color='blue')
    
    axes[1].axhline(y=expected_value, color='r', linestyle='--', linewidth=2)
    axes[1].set_xlabel('n')
    axes[1].set_ylabel('Sample Mean')

3. The Central Limit Theorem

Motivation: Why does the normal distribution appear everywhere? The CLT explains the universality of the bell curve.

Definitions

  • Convergence in distribution:\(X_n \xrightarrow{d} X\) means \(F_{X_n}(x) \to F_X(x)\) at continuity points
  • Characteristic function:\(\phi_X(t) = \mathbb{E}[e^{itX}]\)
  • Standard normal:\(Z \sim N(0,1)\) with density \(\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\)

Theorem (Lindeberg-Lévy CLT)

Let \(X_1, X_2, \ldots\) be i.i.d. with \(\mathbb{E}[X_i] = \mu\) and \(\text{Var}(X_i) = \sigma^2 \u003c \infty\). Then:

\[\frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)\]

Proof (Characteristic Function Method)

Let \(Y_i = (X_i - \mu)/\sigma\) and \(Z_n = \frac{1}{\sqrt{n}}\sum Y_i\). Then: \[\phi_{Z_n}(t) = \phi_{Y_1}(t/\sqrt{n})^n\] Using Taylor expansion: \(\phi_{Y_1}(t) = 1 - t^2/2 + o(t^2)\), so: \[\phi_{Z_n}(t) = \left(1 - \frac{t^2}{2n} + o(1/n)\right)^n \to e^{-t^2/2}\] This is the characteristic function of \(N(0,1)\). By Lévy's continuity theorem, \(Z_n \xrightarrow{d} N(0,1)\). \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

def demonstrate_clt(distribution, n_values=[1, 2, 5, 10, 30, 100], n_samples=10000):
    """
    Demonstrate Central Limit Theorem.
    Shows how sum of n i.i.d. variables approaches normal.
    """
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))
    axes = axes.flatten()
    
    for idx, n in enumerate(n_values):
        # Generate n_samples sums of n random variables
        samples = np.array([np.sum(distribution(n)) for _ in range(n_samples)])
        
        # Standardize
        samples = (samples - np.mean(samples)) / np.std(samples)
        
        # Plot histogram

        # Plot standard normal

        axes[idx].plot(x, stats.norm.pdf(x), 'r-', lw=2, label='N(0,1)')
        
        axes[idx].set_title(f'n = {n}')
        axes[idx].set_xlabel('Standardized Sum')
        axes[idx].set_ylabel('Density')
        axes[idx].legend()
        axes[idx].set_xlim(-4, 4)
    
    plt.tight_layout()
    plt.savefig('central_limit_theorem.png', dpi=150)
    plt.show()

Applied Math Deep-Dives

1. Markov Chain Monte Carlo

Real-world motivation: Many high-dimensional integrals and Bayesian posterior distributions are intractable analytically. MCMC provides a way to sample from complex distributions.

Definitions

  • Markov chain:\(P(X_{n+1} = y | X_n = x, \ldots) = P(X_{n+1} = y | X_n = x) = P(x, y)\)
  • Stationary distribution:\(\pi\) satisfies \(\pi P = \pi\)
  • Detailed balance:\(\pi(x)P(x,y) = \pi(y)P(y,x)\)
  • Metropolis-Hastings: Proposal \(q\), accept with probability \(\min(1, \frac{\pi(y)q(y,x)}{\pi(x)q(x,y)})\)

Theorem (Metropolis-Hastings Convergence)

If the Markov chain is irreducible and aperiodic, then \(X_n \xrightarrow{d} \pi\) regardless of initial state.

Proof Sketch

Detailed balance implies \(\pi\) is stationary. Irreducibility and aperiodicity imply uniqueness of stationary distribution and convergence. \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def metropolis_hastings(target_pdf, proposal_sampler, proposal_pdf, 
                         x0, n_samples, burn_in=1000):
    """
    Metropolis-Hastings MCMC sampler.
    
    target_pdf: function to sample from (up to normalization)
    proposal_sampler: function(x) -> proposed next state
    proposal_pdf: function(x, y) -> density of proposing y from x
    """
    samples = []
    x = x0
    
    for i in range(n_samples + burn_in):
        # Propose
        y = proposal_sampler(x)
        
        # Acceptance probability
        if proposal_pdf(x, y) > 0:
            alpha = min(1, (target_pdf(y) * proposal_pdf(y, x)) / 
                           (target_pdf(x) * proposal_pdf(x, y)))
        else:
            alpha = 0
        
        # Accept/reject
        if np.random.random() < alpha:
            x = y
        
        if i >= burn_in:
            samples.append(x)
    
    return np.array(samples)

# Example: Sample from mixture of Gaussians
def mixture_pdf(x):
    """Target: 0.3*N(-2, 0.5) + 0.7*N(2, 1)"""
    return 0.3 * np.exp(-(x + 2)**2 / (2 * 0.5)) / np.sqrt(np.pi) + \\
           0.7 * np.exp(-(x - 2)**2 / 2) / np.sqrt(2 * np.pi)

def gaussian_proposal_sampler(x, sigma=1.0):
    return np.random.normal(x, sigma)

def gaussian_proposal_pdf(x, y, sigma=1.0):
    return np.exp(-(y - x)**2 / (2 * sigma**2)) / np.sqrt(2 * np.pi * sigma**2)

# Run MCMC
samples = metropolis_hastings(
    mixture_pdf,
    gaussian_proposal_sampler,
    gaussian_proposal_pdf,
    x0=0,
    n_samples=10000,
    burn_in=1000
)

print(f"Sample mean: {np.mean(samples):.3f}")
print(f"Sample std: {np.std(samples):.3f}")
print(f"Acceptance rate: {len(np.unique(samples)) / len(samples):.3f}")

2. Stochastic Gradient Descent

Real-world motivation: Training machine learning models on massive datasets requires optimization methods that work with random subsets of data.

Definitions

  • Objective:\(f(x) = \frac{1}{n}\sum_{i=1}^n f_i(x)\)
  • SGD update:\(x_{k+1} = x_k - \eta_k \nabla f_{i_k}(x_k)\)\) where \(i_k\) random
  • Learning rate:\(\eta_k\), often \(\eta_k = \eta_0 / (1 + \lambda k)\)
  • Strong convexity:\(f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2\)

Theorem (SGD Convergence)

For strongly convex \(f\) with bounded gradients \(\mathbb{E}[\|\nabla f_i(x)\|^2] \leq G^2\), using \(\eta_k = \frac{1}{\mu k}\):

\[\mathbb{E}[f(x_k)] - f(x^*) \leq \frac{G^2}{2\mu k}\]

Proof Sketch

From strong convexity and the update rule: \[\|x_{k+1} - x^*\|^2 \leq (1 - \eta_k\mu)\|x_k - x^*\|^2 + \eta_k^2 G^2\] Taking expectations and telescoping gives the result. \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def sgd(objective_func, gradient_func, x0, data, n_iterations=1000, 
        batch_size=1, learning_rate_schedule='decay', initial_lr=0.1):
    """
    Stochastic Gradient Descent.
    
    gradient_func(x, batch_data) returns gradient estimate
    """
    x = x0.copy()
    trajectory = [x.copy()]
    n = len(data)
    
    for k in range(1, n_iterations + 1):
        # Sample batch
        batch_indices = np.random.choice(n, batch_size, replace=False)
        batch = data[batch_indices]
        
        # Learning rate
        if learning_rate_schedule == 'decay':
            lr = initial_lr / (1 + 0.01 * k)
        elif learning_rate_schedule == 'constant':
            lr = initial_lr
        else:
            lr = initial_lr / np.sqrt(k)
        
        # Update
        grad = gradient_func(x, batch)
        x = x - lr * grad
        trajectory.append(x.copy())
    
    return np.array(trajectory)

# Example: Linear regression
def linear_regression_objective(w, X, y):
    """Least squares: (1/n) * ||Xw - y||^2"""
    return np.mean((X @ w - y)**2)

def linear_regression_gradient(w, batch):
    """SGD gradient for linear regression."""
    X_batch, y_batch = batch[:, :-1], batch[:, -1]
    n = len(X_batch)
    return (2/n) * X_batch.T @ (X_batch @ w - y_batch)

# Generate synthetic data
np.random.seed(42)
n_samples = 1000
X = np.random.randn(n_samples, 5)
true_w = np.array([1, -2, 3, -1, 0.5])
y = X @ true_w + 0.1 * np.random.randn(n_samples)
data = np.column_stack([X, y])

# Run SGD
w0 = np.zeros(5)
trajectory = sgd(None, linear_regression_gradient, w0, data, 
                 n_iterations=500, batch_size=10)

print(f"True weights: {true_w}")
print(f"Estimated weights: {trajectory[-1]}")
print(f"Final objective: {linear_regression_objective(trajectory[-1], X, y):.6f}")

3. Option Pricing and the Black-Scholes Model

Real-world motivation: Financial derivatives require precise pricing models. The Black-Scholes framework revolutionized finance and earned its creators the Nobel Prize in Economics.

Definitions

  • Geometric Brownian Motion:\(dS_t = \mu S_t dt + \sigma S_t dW_t\)
  • European call option: Payoff \(\max(S_T - K, 0)\) at time \(T\)
  • Risk-neutral measure:\(Q\) under which \(e^{-rt}S_t\) is a martingale
  • Implied volatility:\(\sigma_{imp}\) such that BS price equals market price

Theorem (Black-Scholes Formula)

The price of a European call option is:

\[C = S_0 N(d_1) - Ke^{-rT}N(d_2)\]

where: \[d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}\]

Proof Sketch

Under risk-neutral measure, \(S_T = S_0 \exp((r - \sigma^2/2)T + \sigma W_T)\). The option price is: \[C = e^{-rT}\mathbb{E}^Q[\max(S_T - K, 0)]\] Computing this expectation using the log-normal distribution of \(S_T\) yields the formula. \(\square\)

Python Code

import numpy as np
from scipy.stats import norm

def black_scholes_call(S, K, T, r, sigma):
    """
    Black-Scholes price for European call option.
    
    S: current stock price
    K: strike price
    T: time to maturity
    r: risk-free rate
    sigma: volatility
    """
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return call_price

def black_scholes_put(S, K, T, r, sigma):
    """Black-Scholes price for European put option (put-call parity)."""
    call = black_scholes_call(S, K, T, r, sigma)
    return call - S + K * np.exp(-r * T)

def monte_carlo_option_price(S, K, T, r, sigma, n_simulations=100000, option_type='call'):
    """
    Monte Carlo pricing using risk-neutral simulation.
    """
    # Simulate terminal stock prices
    Z = np.random.standard_normal(n_simulations)
    S_T = S * np.exp((r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    
    # Compute payoffs
    if option_type == 'call':
        payoffs = np.maximum(S_T - K, 0)
    else:
        payoffs = np.maximum(K - S_T, 0)
    
    # Discount and return
    price = np.exp(-r * T) * np.mean(payoffs)
    std_error = np.exp(-r * T) * np.std(payoffs) / np.sqrt(n_simulations)
    
    return price, std_error

# Example
S, K, T, r, sigma = 100, 100, 1, 0.05, 0.2
bs_price = black_scholes_call(S, K, T, r, sigma)
mc_price, mc_error = monte_carlo_option_price(S, K, T, r, sigma)

print(f"Black-Scholes price: {bs_price:.4f}")
print(f"Monte Carlo price: {mc_price:.4f} ± {mc_error:.4f}")

Special Topics

1. Martingales and Stopping Times

Historical context: Joseph Doob developed the systematic theory of martingales in the 1940s-50s, building on earlier work by Paul Lévy. Martingales became fundamental to probability, finance, and ergodic theory.

Definitions

  • Filtration:\(\{\mathcal{F}_n\}\) increasing sequence of \(\sigma\)-algebras
  • Martingale:\(\mathbb{E}[X_{n+1} | \mathcal{F}_n] = X_n\)
  • Stopping time:\(\tau\) where \(\{\tau \leq n\} \in \mathcal{F}_n\)
  • Submartingale:\(\mathbb{E}[X_{n+1} | \mathcal{F}_n] \geq X_n\)

Theorem (Optional Stopping)

For a martingale \((X_n)\) and bounded stopping time \(\tau\): \(\mathbb{E}[X_\tau] = \mathbb{E}[X_0]\).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def simple_random_walk(n_steps, p=0.5):
    """Generate simple symmetric random walk."""
    steps = 2 * (np.random.random(n_steps) < p) - 1
    return np.cumsum(steps)

def stopping_time_simulation(n_simulations=10000, threshold=10):
    """
    Simulate gambler's ruin with stopping time.
    Stop when wealth reaches +threshold or -threshold.
    """
    stopping_times = []
    final_values = []
    
    for _ in range(n_simulations):
        wealth = 0
        time = 0
        while abs(wealth) < threshold and time < 10000:
            wealth += 2 * (np.random.random() < 0.5) - 1
            time += 1
        stopping_times.append(time)
        final_values.append(wealth)
    
    return stopping_times, final_values

# Simulate
times, values = stopping_time_simulation()
print(f"Average stopping time: {np.mean(times):.2f}")
print(f"P(reach +10): {np.mean([v == 10 for v in values]):.4f}")
print(f"P(reach -10): {np.mean([v == -10 for v in values]):.4f}")

# Verify optional stopping (should be 0 for fair game)
print(f"Expected final value: {np.mean(values):.4f}")

2. Large Deviations Theory

Historical context: Cramér's 1938 work on the asymptotic behavior of tail probabilities founded large deviations theory. Varadhan's 1966 Donsker-Varadhan theory and his 2007 Abel Prize recognized the field's maturity.

Definitions

  • Rate function:\(I(x) \geq 0\), convex, lower semicontinuous
  • Log-moment generating function:\(\Lambda(t) = \log \mathbb{E}[e^{tX}]\)
  • Fenchel-Legendre transform:\(\Lambda^*(x) = \sup_t(tx - \Lambda(t))\)

Theorem (Cramér's Theorem)

For i.i.d. \((X_n)\) with finite MGF in a neighborhood of 0:

\[\lim_{n \to \infty} \frac{1}{n} \log P(\frac{1}{n}\sum_{i=1}^n X_i \geq x) = -\Lambda^*(x)\]

for \(x > \mathbb{E}[X_1]\).

Python Code

import numpy as np
from scipy.optimize import minimize_scalar

def log_mgf(t, distribution_samples):
    """Estimate log moment generating function."""
    return np.log(np.mean(np.exp(t * distribution_samples)))

def rate_function(x, distribution_samples, t_range=(-10, 10)):
    """
    Compute rate function I(x) using Legendre-Fenchel transform.
    I(x) = sup_t(tx - Lambda(t))
    """
    def objective(t):
        return -(t * x - log_mgf(t, distribution_samples))
    
    result = minimize_scalar(objective, bounds=t_range, method='bounded')
    return -result.fun

# Example: Large deviations for Bernoulli(0.5)
np.random.seed(42)
samples = np.random.binomial(1, 0.5, 100000)

# Compute rate function at various points
x_values = np.linspace(0.6, 0.9, 10)
rate_values = [rate_function(x, samples) for x in x_values]

# Compare with empirical tail probabilities
n = 100
empirical_rates = []
for x in x_values:
    # P(S_n/n >= x)
    tail_prob = np.mean([np.mean(np.random.binomial(1, 0.5, n)) >= x 
                         for _ in range(10000)])
    if tail_prob > 0:
        empirical_rates.append(-np.log(tail_prob) / n)
    else:
        empirical_rates.append(np.inf)

print("x\t\tI(x) (estimated)\tEmpirical rate")
for x, r, e in zip(x_values, rate_values, empirical_rates):
    if e != np.inf:
        print(f"{x:.2f}\t\t{r:.4f}\t\t{e:.4f}")
    else:
        print(f"{x:.2f}\t\t{r:.4f}\t\tinf")

3. Random Matrix Theory

Historical context: Wigner introduced random matrices in the 1950s to model heavy nuclei energy levels. The field exploded with connections to number theory (Montgomery-Dyson), combinatorics, and machine learning.

Definitions

  • Wigner matrix:\(M = \frac{1}{\sqrt{n}}(A + A^T)\) where \(A_{ij}\) i.i.d.
  • Empirical spectral distribution:\(\mu_n = \frac{1}{n}\sum_{i=1}^n \delta_{\lambda_i}\)
  • Semicircle law:\(\rho(x) = \frac{1}{2\pi}\sqrt{4-x^2}\) for \(|x| \leq 2\)

Theorem (Wigner's Semicircle Law)

For a Wigner matrix with finite moments, the empirical spectral distribution converges to the semicircle law:

\[\mu_n \xrightarrow{d} \mu_{sc}\]

Python Code

import numpy as np
import matplotlib.pyplot as plt

def generate_wigner_matrix(n, distribution='gaussian'):
    """Generate n x n Wigner matrix."""
    if distribution == 'gaussian':
        A = np.random.randn(n, n)
    elif distribution == 'bernoulli':
        A = 2 * (np.random.random((n, n)) < 0.5) - 1
    
    # Symmetrize
    M = (A + A.T) / np.sqrt(2 * n)
    return M

def semicircle_pdf(x):
    """Semicircle distribution PDF."""
    mask = np.abs(x) <= 2
    result = np.zeros_like(x)
    result[mask] = np.sqrt(4 - x[mask]**2) / (2 * np.pi)
    return result

def demonstrate_semicircle_law(n_values=[50, 100, 500, 1000]):
    """Show convergence to semicircle law."""
    fig, axes = plt.subplots(2, 2, figsize=(12, 10))
    axes = axes.flatten()
    
    x = np.linspace(-3, 3, 1000)
    
    for idx, n in enumerate(n_values):
        M = generate_wigner_matrix(n)
        eigenvalues = np.linalg.eigvalsh(M)
        
        axes[idx].hist(eigenvalues, bins=30, density=True, alpha=0.7, label='Empirical')
        axes[idx].plot(x, semicircle_pdf(x), 'r-', lw=2, label='Semicircle')
        axes[idx].set_title(f'n = {n}')
        axes[idx].set_xlabel('Eigenvalue')
        axes[idx].set_ylabel('Density')
        axes[idx].legend()
        axes[idx].set_xlim(-3, 3)
    
    plt.tight_layout()
    plt.savefig('semicircle_law.png', dpi=150)
    plt.show()

# Example: Marchenko-Pastur law for sample covariance
def marchenko_pastur_pdf(x, gamma):
    """
    Marchenko-Pastur distribution for sample covariance matrices.
    gamma = p/n (aspect ratio)
    """
    lambda_plus = (1 + np.sqrt(gamma))**2
    lambda_minus = (1 - np.sqrt(gamma))**2
    
    mask = (x >= lambda_minus) & (x <= lambda_plus)
    result = np.zeros_like(x)
    result[mask] = np.sqrt((lambda_plus - x[mask]) * (x[mask] - lambda_minus)) / (2 * np.pi * gamma * x[mask])
    return result

print("Demonstrating Wigner's Semicircle Law:")
demonstrate_semicircle_law()

4. Percolation Theory

Historical context: Broadbent and Hammersley introduced percolation in 1957 to model fluid flow through porous media. The field revealed deep connections to statistical mechanics and conformal field theory, culminating in Smirnov's 2001 proof of conformal invariance for critical percolation.

Definitions

\u003cul>
  • Site percolation: Each site of lattice is open with probability \(p\)
  • Cluster: Connected component of open sites
  • Percolation probability:\(\theta(p) = P(\text{origin in infinite cluster})\)
  • Critical probability:\(p_c = \inf\{p : \theta(p) > 0\}\)

    • Theorem (Kesten, 1980)

    \[p_c(\mathbb{Z}^2) = \frac{1}{2}\]

    For 2D site percolation on the square lattice.

    Python Code

    import numpy as np
import matplotlib.pyplot as plt
from scipy.ndimage import label

def generate_percolation_grid(n, p):
    """Generate n x n site percolation configuration."""
    return np.random.random((n, n)) < p

def find_clusters(grid):
    """Find connected clusters using scipy.ndimage.label."""
    labeled_array, num_features = label(grid)
    return labeled_array, num_features

def has_spanning_cluster(grid):
    """Check if there's a cluster spanning left-right or top-bottom."""
    clusters, _ = find_clusters(grid)
    
    # Check left-right spanning
    left_sites = set(clusters[:, 0])
    right_sites = set(clusters[:, -1])
    if left_sites & right_sites - {0}:  # Exclude background (0)
        return True
    
    # Check top-bottom spanning
    top_sites = set(clusters[0, :])
    bottom_sites = set(clusters[-1, :])
    if top_sites & bottom_sites - {0}:
        return True
    
    return False

def estimate_critical_probability(n=100, n_trials=100, p_values=None):
    """Estimate percolation probability for various p."""
    if p_values is None:
        p_values = np.linspace(0.3, 0.7, 20)
    
    percolation_probs = []
    for p in p_values:
        count = sum(has_spanning_cluster(generate_percolation_grid(n, p)) 
                    for _ in range(n_trials))
        percolation_probs.append(count / n_trials)
    
    return p_values, percolation_probs

# Simulate

    Math History

    Probability theory's journey from gambling puzzles to rigorous mathematics spans centuries. Cardano's "Liber de Ludo Aleae" (c. 1564, published 1663) contained early calculations of dice probabilities, but the field truly began with the 1654 correspondence between Pascal and Fermat on the "problem of points"—how to fairly divide stakes in an interrupted game. Their solution established the concept of expected value.

    Huygens' "De Ratiociniis in Ludo Aleae" (1657) was the first probability textbook. The Bernoulli family made foundational contributions: Jacob's "Ars Conjectandi" (1713) proved the first law of large numbers, while Daniel developed utility theory. De Moivre discovered the normal distribution as an approximation to the binomial (1733), and Laplace's "Théorie Analytique des Probabilités" (1812) systematized the field.

    The 20th century brought measure theory to probability through the work of Borel, Lebesgue, and Kolmogorov. Kolmogorov's "Grundbegriffe" (1933) axiomatically founded modern probability theory using measure theory. This enabled rigorous treatment of stochastic processes: Brownian motion (Wiener, Lévy), martingales (Doob), and Markov processes. The interplay with physics (Einstein, Smoluchowski on Brownian motion) and later with finance (Black, Scholes, Merton) drove practical applications.

    Contemporary probability theory spans pure and applied domains: random matrix theory connects to quantum physics and number theory; percolation theory to materials science; concentration inequalities to machine learning. The field has evolved from calculating gambling odds to providing the mathematical language of uncertainty in science, engineering, and finance.

    Problem Corner

    Problem (Putnam 2002 B2): Consider a polyhedron with at least five faces such that exactly three edges emerge from each of its vertices. Two players play the following game: Each player, in turn, signs his or her name on a previously unsigned face. The winner is the player who first succeeds in signing three faces that share a common vertex. Prove that the first player always has a winning strategy.

    Hint

    Use the probabilistic method or strategy stealing. Consider what happens if the first player picks any face and then mirrors the second player's moves appropriately.

    Solution

    We use a strategy-stealing argument. Suppose, for contradiction, that the second player has a winning strategy.

    The first player picks any face \(F_1\). Whatever face \(F_2\) the second player picks in response, the first player now "forgets" about \(F_1\) and pretends to be the second player in a new game where \(F_2\) was the first move.

    Since we assumed the second player has a winning strategy, our first player (now playing as "second") can force a win. But this means the original first player wins, contradicting the assumption.

    Therefore, the second player cannot have a winning strategy. Since the game cannot end in a draw (finite game, no draws possible), the first player must have a winning strategy. \(\square\)

    Visualization of the Day

    Brownian motion, the random movement of particles suspended in fluid, was mathematically described by Wiener and Lévy. Its fractal nature and self-similarity make it a beautiful object of study.

    import numpy as np
import matplotlib.pyplot as plt

def brownian_motion(n_steps, n_dimensions=2, dt=0.01):
    """
    Generate Brownian motion path.
    """
    dW = np.random.randn(n_steps, n_dimensions) * np.sqrt(dt)
    W = np.cumsum(dW, axis=0)
    return W

def visualize_brownian_motion():
    """
    Create artistic visualization of Brownian motion.
    """
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    
    # 2D Brownian motion with multiple paths
    ax1 = axes[0]
    for i in range(5):
        path = brownian_motion(10000, 2)
        ax1.plot(path[:, 0], path[:, 1], alpha=0.6, linewidth=0.5)
    ax1.set_aspect('equal')
    ax1.set_title('2D Brownian Motion Paths')
    ax1.set_xlabel('X')
    ax1.set_ylabel('Y')
    
    # Time series of 1D Brownian motion
    ax2 = axes[1]
    t = np.linspace(0, 10, 10000)
    for i in range(3):
        W = brownian_motion(10000, 1, dt=0.001)
        ax2.plot(t, W, alpha=0.7)
    ax2.set_title('1D Brownian Motion')
    ax2.set_xlabel('Time')
    ax2.set_ylabel('Position')
    ax2.grid(True)
    
    # Scaling property demonstration
    ax3 = axes[2]
    # Brownian motion is self-similar: W(at) ~ sqrt(a) W(t)
    W = brownian_motion(5000, 1, dt=0.001)[:, 0]
    t = np.arange(len(W))
    
    ax3.plot(t, W, 'b-', alpha=0.5, label='W(t)')
    ax3.plot(t * 4, W * 2, 'r-', alpha=0.5, label='2W(t/4) ~ W(t)')
    ax3.set_title('Self-Similarity: W(at) ~ √a W(t)')
    ax3.set_xlabel('Time')
    ax3.set_ylabel('Position')
    ax3.legend()
    
    plt.tight_layout()
    plt.savefig('brownian_motion.png', dpi=150)
    plt.show()

visualize_brownian_motion()
