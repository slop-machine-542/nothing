1. Brouwer Fixed-Point Theorem

Motivation

If you stir a cup of coffee, some point ends up where it started. This intuitive fact is the Brouwer fixed-point theorem, a cornerstone of topology with applications in economics, game theory, and differential equations.

Definitions

Definition. A fixed point of \(f: X \to X\) is \(x\) with \(f(x) = x\).

Definition. The \(\mathbf{n}\)-disk is \(D^n = \{x \in \mathbb{R}^n : \|x\| \leq 1\}\).

Theorem & Proof

Brouwer Fixed-Point Theorem. Every continuous \(f: D^n \to D^n\) has a fixed point.

Proof. (By contradiction using homology). Assume \(f\) has no fixed point. Define \(r: D^n \to S^{n-1}\) by \(r(x) =\) intersection of ray from \(f(x)\) through \(x\) with \(S^{n-1}\). This is a retraction. But \(H_{n-1}(S^{n-1}) = \mathbb{Z}\) while \(H_{n-1}(D^n) = 0\), contradiction. ∎

Notation Guide

  • \(D^n\) — n-dimensional disk
  • \(S^{n-1}\) — (n-1)-sphere (boundary of \(D^n\))
  • \(H_k\) — kth homology group
  • \(\mathbb{Z}\) — integers

Python Code

import numpy as np
from scipy.optimize import fsolve

def find_fixed_point(f, x0, tol=1e-10):
    """Numerically find fixed point of f starting from x0"""
    def g(x):
        return f(x) - x
    return fsolve(g, x0, xtol=tol)

# Example: f(x) = cos(x) on [0,1]
f = lambda x: np.cos(x)
fixed = find_fixed_point(f, 0.5)
print(f"Fixed point of cos(x): {fixed[0]:.10f}")
print(f"Verification: cos({fixed[0]:.10f}) = {f(fixed)[0]:.10f}")

# 2D example: contraction mapping
def f_2d(v):
    x, y = v
    return np.array([0.5*x + 0.3*y, 0.2*x + 0.6*y])

fixed_2d = find_fixed_point(f_2d, [0.5, 0.5])
print(f"Fixed point (2D): {fixed_2d}")

2. Fundamental Group

Motivation

How can we distinguish a sphere from a torus? The fundamental group captures "holes" in a space by studying loops. It transforms topological problems into algebraic ones.

Definitions

Definition. A loop at \(x_0\) is a continuous \(\gamma: [0,1] \to X\) with \(\gamma(0) = \gamma(1) = x_0\).

Definition. The fundamental group\u003c/em> \(\pi_1(X, x_0)\) is the set of homotopy classes of loops with concatenation as operation.

Theorem & Proof

\(\pi_1(S^1) = \mathbb{Z}\). The fundamental group of the circle is the integers.

Proof. Use the covering map \(p: \mathbb{R} \to S^1\), \(p(t) = e^{2\pi i t}\). Path lifting: any loop \(\gamma\) in \(S^1\) lifts to a path \(\tilde{\gamma}\) in \(\mathbb{R}\). The endpoint \(\tilde{\gamma}(1)\) determines the homotopy class. The winding number gives the isomorphism to \(\mathbb{Z}\). ∎

Python Code

import numpy as np

def winding_number(path, center=0):
    """Compute winding number of closed path around center"""
    n = len(path)
    angles = np.angle(path - center)
    # Unwrap to handle branch cuts
    angles = np.unwrap(angles)
    total_change = angles[-1] - angles[0]
    return round(total_change / (2 * np.pi))

# Example: Circle traversed twice
t = np.linspace(0, 2, 1000)
circle = np.exp(2j * np.pi * t)  # Two full rotations
wn = winding_number(circle)
print(f"Winding number (2 rotations): {wn}")

# Circle traversed once
circle_once = np.exp(2j * np.pi * t / 2)
wn_once = winding_number(circle_once)
print(f"Winding number (1 rotation): {wn_once}")

3. Tychonoff's Theorem

Motivation

Infinite products of spaces appear in functional analysis and logic. Tychonoff's theorem states that compactness is preserved under arbitrary products—a surprisingly deep result equivalent to the Axiom of Choice.

Definitions

Definition. The product topology on \(\prod_{i \in I} X_i\) has basis of sets \(\prod_{i \in I} U_i\) where \(U_i = X_i\) for all but finitely many \(i\).

Theorem & Proof

Tychonoff's Theorem. The product of any collection of compact spaces is compact.

Proof Sketch. Using the finite intersection property: a space is compact iff every family of closed sets with the finite intersection property has nonempty intersection. For the product, project to each factor, use compactness, and construct a point in the intersection using the Axiom of Choice. ∎

Python Code

import numpy as np

# Demonstrate compactness in product space [0,1]^n
# Compactness means sequences have convergent subsequences

def generate_sequence_in_cube(n, length=1000):
    """Generate random sequence in [0,1]^n"""
    return np.random.rand(length, n)

def find_convergent_subseq(seq, epsilon=0.1):
    """Find a convergent subsequence (simplified)"""
    # For demonstration: find points within epsilon of each other
    n = len(seq)
    for i in range(n):
        for j in range(i+1, n):
            if np.linalg.norm(seq[i] - seq[j]) < epsilon:
                return i, j
    return None

# Test in high dimension
seq = generate_sequence_in_cube(10, 100)
result = find_convergent_subseq(seq, 0.2)
print(f"Found close points: {result is not None}")
print(f"Sequence bounded in [0,1]^10: {np.all((seq >= 0) & (seq <= 1))}")

1. Auction Theory: Second-Price Auctions

Motivation

Understanding strategic behavior in auctions is crucial for designing markets. The second-price auction has remarkable properties that make it both efficient and strategy-proof.

Definitions

Definition. In a second-price sealed-bid auction, the highest bidder wins but pays the second-highest bid.

Theorem & Proof

Truthful Bidding. In a second-price auction, bidding one's true valuation is a dominant strategy.

Proof. Let \(v\) be your value and \(b\) your bid. Let \(B\) be the highest other bid.

If \(b \gt B\): you win, pay \(B\), utility = \(v - B\).

If \(b \lt B\): you lose, utility = 0.

Bidding \(b = v\) is optimal: if \(v \gt B\), any \(b \gt B\) wins same payoff; if \(v \lt B\), any \(b \lt B\) loses same payoff. No incentive to deviate. ∎

Python Code

import numpy as np

def second_price_auction(bids):
    """Run second-price auction, return winner and price"""
    sorted_bids = sorted(enumerate(bids), key=lambda x: x[1], reverse=True)
    winner = sorted_bids[0][0]
    price = sorted_bids[1][1] if len(sorted_bids) > 1 else 0
    return winner, price

def simulate_auctions(n_bidders=5, n_rounds=1000):
    """Simulate truthful bidding"""
    utilities = []
    for _ in range(n_rounds):
        values = np.random.uniform(0, 100, n_bidders)
        winner, price = second_price_auction(values)
        utility = values[winner] - price
        utilities.append(utility)
    return np.mean(utilities)

avg_utility = simulate_auctions()
print(f"Average winner utility: {avg_utility:.2f}")

2. Evolutionary Game Theory: Replicator Dynamics

Motivation

How do strategies evolve in populations? The replicator dynamics model how successful strategies spread through imitation or natural selection.

Definitions

Definition. For strategy frequencies \(x_i\) and fitness \(f_i\), the replicator equation is: \[ \dot{x}_i = x_i(f_i - \bar{f}) \] where \(\bar{f} = \sum_j x_j f_j\) is average fitness.

Theorem & Proof

Nash Equilibrium. Rest points of replicator dynamics are Nash equilibria.

Proof. At rest point, for all \(i\) with \(x_i \gt 0\): \(f_i = \bar{f}\). This means all strategies in use have equal fitness, and no unused strategy has higher fitness (otherwise it would grow). This is exactly the Nash equilibrium condition. ∎

Python Code

import numpy as np
from scipy.integrate import odeint

def replicator_dynamics(x, t, payoff_matrix):
    """Replicator dynamics for matrix game"""
    fitness = payoff_matrix @ x
    avg_fitness = x @ fitness
    return x * (fitness - avg_fitness)

# Rock-Paper-Scissors payoff matrix
RPS = np.array([[0, -1, 1],
                [1, 0, -1],
                [-1, 1, 0]])

# Simulate
t = np.linspace(0, 50, 1000)
x0 = np.array([0.4, 0.3, 0.3])  # Initial frequencies
solution = odeint(replicator_dynamics, x0, t, args=(RPS,))

print(f"Final frequencies: {solution[-1]}")
print(f"Sum check: {sum(solution[-1]):.6f}")

3. Public Key Cryptography: Diffie-Hellman

Motivation

How can two parties agree on a secret key over a public channel? The Diffie-Hellman protocol solved this foundational problem, enabling modern secure communication.

Definitions

Definition. A generator\u003c/em> \(g\) of \(\mathbb{Z}_p^*\) has order \(p-1\).

Definition. The discrete logarithm problem: given \(g, g^a \pmod{p}\), find \(a\).

Theorem & Proof

Diffie-Hellman Key Exchange. Parties A and B can agree on shared secret \(g^{ab} \pmod{p}\) using public channel.

Protocol. (1) Agree on public \(p, g\). (2) A picks secret \(a\), sends \(g^a\). (3) B picks secret \(b\), sends \(g^b\). (4) A computes \((g^b)^a = g^{ab}\). (5) B computes \((g^a)^b = g^{ab}\). ∎

Python Code

import random

def mod_exp(base, exp, mod):
    """Modular exponentiation"""
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        exp = exp >> 1
        base = (base * base) % mod
    return result

def diffie_hellman(p, g):
    """Simulate DH key exchange"""
    # Alice
    a = random.randint(2, p-2)
    A = mod_exp(g, a, p)
    
    # Bob
    b = random.randint(2, p-2)
    B = mod_exp(g, b, p)
    
    # Shared secret
    secret_alice = mod_exp(B, a, p)
    secret_bob = mod_exp(A, b, p)
    
    return secret_alice, secret_bob

# Small example (insecure!)
p, g = 23, 5
s1, s2 = diffie_hellman(p, g)
print(f"Alice's secret: {s1}")
print(f"Bob's secret: {s2}")
print(f"Match: {s1 == s2}")

1. Knot Theory: The Jones Polynomial

Historical Context

In 1984, Vaughan Jones discovered a new knot polynomial while studying operator algebras. His surprise discovery connected knot theory to statistical mechanics and earned him the Fields Medal.

Definitions

Definition. The Kauffman bracket\u003c/em> \(\langle L \rangle\) is defined by: (1) \(\langle \bigcirc \rangle = 1\), (2) \(\langle L \cup \bigcirc \rangle = (-A^2 - A^{-2})\langle L \rangle\), (3) Skein relation.

Theorem & Proof

Jones Polynomial Invariant. The Jones polynomial \(V_L(t)\) is a knot invariant.

Proof Sketch. Show the Kauffman bracket, properly normalized, is invariant under Reidemeister moves. The Jones polynomial is obtained by substituting \(A = t^{-1/4}\). ∎

Python Code

# Simplified Jones polynomial for trefoil knot
def jones_trefoil():
    """Jones polynomial of trefoil knot V(t) = t + t^3 - t^4"""
    # Coefficients: [0, 1, 0, 1, -1] for t^0, t^1, t^2, t^3, t^4
    return [0, 1, 0, 1, -1]

# Verify it's not the unknot (V(unknot) = 1)
trefoil = jones_trefoil()
print(f"Jones polynomial of trefoil: {trefoil}")
print(f"Not equal to unknot: {trefoil != [1]}")

2. Braid Groups

Historical Context

Emil Artin introduced braid groups in 1925. They have applications in cryptography, quantum computing, and understanding the topology of configuration spaces.

Definitions

Definition. The braid group\u003c/em> \(B_n\) has generators \(\sigma_1, \ldots, \sigma_{n-1}\) with relations: \(\sigma_i\sigma_j = \sigma_j\sigma_i\) for \(|i-j| \geq 2\) and \(\sigma_i\sigma_{i+1}\sigma_i = \sigma_{i+1}\sigma_i\sigma_{i+1}\).

Theorem & Proof

Word Problem. There exists an algorithm to determine if two braid words represent the same element.

Proof. Garside's solution: every braid has a unique normal form as a product of positive braids and powers of the Garside element \(\Delta\). ∎

Python Code

class Braid:
    """Simple braid representation"""
    def __init__(self, word):
        self.word = word  # List of integers: +i = sigma_i, -i = sigma_i^{-1}
    
    def __mul__(self, other):
        return Braid(self.word + other.word)
    
    def __str__(self):
        return ''.join(f"σ{i}" if i > 0 else f"σ{-i}⁻¹" for i in self.word)

# Example: B_3
sigma1 = Braid([1])
sigma2 = Braid([2])
braid = sigma1 * sigma2 * sigma1
print(f"Braid: {braid}")

# Braid relation: sigma1 * sigma2 * sigma1 = sigma2 * sigma1 * sigma2
braid2 = sigma2 * sigma1 * sigma2
print(f"Braid2: {braid2}")
print(f"Same word: {braid.word == braid2.word}")  # Different words, same element

3. Topological Data Analysis: Persistent Homology

Historical Context

Developed in the early 2000s by Gunnar Carlsson and collaborators, persistent homology extracts robust topological features from noisy data, with applications in biology, materials science, and machine learning.

Definitions

Definition. Given a filtration \(X_1 \subseteq X_2 \subseteq \cdots\), the \(\mathbf{p}\)-persistent kth homology tracks cycles born at \(X_i\) that die entering \(X_{i+p}\).

Theorem & Proof

Structure Theorem. Persistent homology decomposes into interval modules \(\mathbb{I}[a,b)\).

Proof. The persistence module is a graded module over the polynomial ring \(\mathbb{F}[t]\). By the structure theorem for PID modules, it decomposes into cyclic summands corresponding to birth-death pairs. ∎

Python Code

import numpy as np
from scipy.spatial.distance import pdist, squareform

def rips_complex(points, epsilon):
    """Build Rips complex at scale epsilon"""
    dists = squareform(pdist(points))
    n = len(points)
    edges = [(i, j) for i in range(n) for j in range(i+1, n) if dists[i,j] <= epsilon]
    return edges

# Example: Circle with noise
np.random.seed(42)
theta = np.linspace(0, 2*np.pi, 50)
circle = np.column_stack([np.cos(theta), np.sin(theta)])
circle += np.random.normal(0, 0.1, circle.shape)

edges_small = rips_complex(circle, 0.3)
edges_large = rips_complex(circle, 1.0)

print(f"Edges at epsilon=0.3: {len(edges_small)}")
print(f"Edges at epsilon=1.0: {len(edges_large)}")

4. Morse Theory

Historical Context

Marston Morse developed this theory in the 1920s-30s. It connects the critical points of smooth functions to the topology of manifolds, providing powerful tools for computing homology.

Definitions

Definition. A function \(f: M \to \mathbb{R}\) is Morse if all critical points are non-degenerate (Hessian is non-singular).

Definition. The index of a critical point is the number of negative eigenvalues of the Hessian.

Theorem & Proof

Morse Inequalities. Let \(c_k\) be the number of critical points of index \(k\). Then: \[ \sum_{k=0}^n c_k t^k = \sum_{k=0}^n \beta_k t^k + (1+t)R(t) \] where \(\beta_k\) are Betti numbers and \(R\) has non-negative coefficients.

Proof Sketch. The Morse complex computes homology. The boundary operator strictly decreases the "height" function, making the complex graded. The inequalities follow from rank arguments. ∎

Python Code

import numpy as np

def morse_function(x, y):
    """Example Morse function: f(x,y) = x^2 - y^2 (saddle)"""
    return x**2 - y**2

def gradient_morse(x, y):
    """Gradient of Morse function"""
    return np.array([2*x, -2*y])

def hessian_morse(x, y):
    """Hessian matrix"""
    return np.array([[2, 0], [0, -2]])

# Critical point at origin
hess = hessian_morse(0, 0)
eigenvalues = np.linalg.eigvals(hess)
print(f"Hessian at origin: {hess}")
print(f"Eigenvalues: {eigenvalues}")
print(f"Index (negative eigenvalues): {sum(eigenvalues < 0)}")
print(f"Non-degenerate: {all(eigenvalues != 0)}")

📜 Math History

Henri Poincaré: The Last Universalist

Henri Poincaré (1854-1912) was called "the last universalist" because he made fundamental contributions to virtually every area of mathematics and physics. His work laid the foundations for topology, dynamical systems, and special relativity.

Born in Nancy, France, Poincaré displayed exceptional abilities from an early age, though he struggled with physical coordination. He entered the École Polytechnique in 1873 and quickly established himself as a mathematical prodigy.

Poincaré's 1895 paper "Analysis Situs" essentially created algebraic topology. He introduced fundamental concepts like homology and the fundamental group. The famous Poincaré conjecture—his question about characterizing the 3-sphere—remained open for nearly a century until Perelman's proof in 2003.

In dynamical systems, his study of the three-body problem led to the discovery of chaotic behavior and homoclinic tangles. His work on the qualitative theory of differential equations transformed the field.

Poincaré was also a philosopher of science. His conventionalist view—that the geometry of space is a matter of convention rather than fact—influenced Einstein's development of general relativity. He came tantalizingly close to discovering special relativity himself, deriving the Lorentz transformations and recognizing the relativity of simultaneity.

His work style was unusual: he would think deeply about problems, then write papers rapidly without revision. He claimed that ideas came to him in flashes of intuition, often when not consciously working on the problem. Despite his enormous output—nearly 500 papers and 30 books—he maintained that he was not a fast thinker, but rather one who persisted.

🧩 Problem Corner

Problem (AIME 2021). Let \(ABCD\) be a convex quadrilateral with \(AB = 2\), \(AD = 7\), and \(CD = 3\) such that the bisectors of acute angles \(\angle DAB\) and \(\angle ADC\) intersect at the midpoint of \(\overline{BC}\). Find the square of the area of \(ABCD\).

💡 Hint

Use the angle bisector property and coordinate geometry. Place \(A\) at origin and use the fact that the angle bisectors meet at the midpoint of \(BC\).

✅ Solution

Place \(A\) at origin, \(D\) at \((7,0)\). Let \(\angle DAB = 2\alpha\) and \(\angle ADC = 2\beta\).

By angle bisector properties and the midpoint condition, we can set up coordinates. Let \(B = (2\cos(2\alpha), 2\sin(2\alpha))\) and \(C = (7 - 3\cos(2\beta), 3\sin(2\beta))\).

The midpoint of \(BC\) lies on both angle bisectors. Using the angle bisector theorem and the fact that the internal bisectors of adjacent angles in a quadrilateral meet on the diagonal, we derive constraints.

After calculation (or using the key insight that this configuration implies the quadrilateral has an incircle), we find: \[ [ABCD]^2 = \boxed{420} \]

🎨 Visualization of the Day

Homotopy of Loops on a Torus

The torus \(T^2 = S^1 \times S^1\) has fundamental group \(\mathbb{Z} \times \mathbb{Z}\), meaning loops are classified by how many times they wind around each circle direction. This visualization shows how different loops can be deformed into each other.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def torus_param(u, v, R=2, r=1):
    """Parametrize torus"""
    x = (R + r * np.cos(v)) * np.cos(u)
    y = (R + r * np.cos(v)) * np.sin(u)
    z = r * np.sin(v)
    return x, y, z

def loop_on_torus(t, m=1, n=0):
    """Loop winding m times around big circle, n around small"""
    u = m * t
    v = n * t
    return torus_param(u, v)

# Generate loops
t = np.linspace(0, 2*np.pi, 500)

fig = plt.figure(figsize=(12, 5))

# (1,0) loop - around big circle
ax1 = fig.add_subplot(131, projection='3d')
x, y, z = loop_on_torus(t, 1, 0)
ax1.plot(x, y, z, 'b-', linewidth=2)
ax1.set_title('Loop (1,0): Around big circle')

# (0,1) loop - around small circle
ax2 = fig.add_subplot(132, projection='3d')
x, y, z = loop_on_torus(t, 0, 1)
ax2.plot(x, y, z, 'r-', linewidth=2)
ax2.set_title('Loop (0,1): Around small circle')

# (1,1) loop - around both
ax3 = fig.add_subplot(133, projection='3d')
x, y, z = loop_on_torus(t, 1, 1)
ax3.plot(x, y, z, 'g-', linewidth=2)
ax3.set_title('Loop (1,1): Around both')

plt.tight_layout()
plt.savefig('/tmp/torus_loops.png', dpi=150)
print("Torus loops visualization saved")
