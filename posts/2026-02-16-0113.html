1. Topology: The Fundamental Group

Introduction

Algebraic topology bridges the gap between topology and algebra by associating algebraic structures to topological spaces. The fundamental group, introduced by Henri Poincaré in 1895, is the simplest and most important of these invariants. It captures information about "holes" in a space by studying loops that cannot be continuously contracted to a point.

The fundamental group distinguishes spaces like the sphere (simply connected) from the torus (has one "essential" loop in each direction). This algebraic invariant revolutionized topology and remains essential in modern geometry and physics.

Notation Guide

  • X — a topological space
  • x0 in X — base point
  • gamma: [0,1] to X — a path in X
  • gamma(0) = gamma(1) = x0 — a loop based at x0
  • π₁(X, x0) — fundamental group of X at x0
  • [gamma] — homotopy class of path γ
  • gamma * eta — concatenation of paths
  • gamma-1(t) = gamma(1-t) — reverse path
  • simeq — homotopy equivalence
Definition: The Fundamental Group

Let X be a topological space and x0 in X. The fundamental group π₁(X, x0) is the set of homotopy classes of loops based at x0, with the group operation induced by path concatenation:

[gamma] cdot [eta] = [gamma * eta]

where (gamma * eta)(t) = begincases gamma(2t) & 0 leq t leq 1/2 \\ eta(2t-1) & 1/2 leq t leq 1 endcases

Theorem: Fundamental Group is Indeed a Group

π₁(X, x0) forms a group under path concatenation:

  1. Associativity: [gamma] cdot ([eta] cdot [omega]) = ([gamma] cdot [eta]) cdot [omega]
  2. Identity: The constant loop e(t) = x0 satisfies [e] cdot [gamma] = [gamma] cdot [e] = [gamma]
  3. Inverses: [gamma] cdot [gamma-1] = [gamma-1] cdot [gamma] = [e]
Proof Sketch

Associativity: We need (gamma * eta) * omega simeq gamma * (eta * omega). Both paths traverse γ, eta, ω in order, just at different speeds. A linear reparameterization gives the homotopy.

Identity: The concatenation gamma * e traverses γ at double speed, then sits at x0. This is homotopic to γ via:

H(t,s) = begincases gamma(2t/1+s) & 0 leq t leq 1+s/2 \\ x0 & 1+s/2 leq t leq 1 endcases

Inverses: gamma * gamma-1 goes out along γ and back. This is homotopic to the constant loop by "pulling in" the path:

H(t,s) = begincases gamma(2t(1-s)) & 0 leq t leq 1/2 \\ gamma((2-2t)(1-s)) & 1/2 leq t leq 1 endcases

At s=0 this is gamma * gamma-1; at s=1 it's the constant loop.

Theorem: Fundamental Group of the Circle

π₁(S1, 1) ≅ ℤ

The isomorphism sends [gamma] to the winding number of γ around the circle.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class FundamentalGroup:
    """
    Exploring the fundamental group through computational examples.
    """
    
    @staticmethod
    def circle_loop(t, n=1):
        """
        A loop on the circle winding n times.
        
        Parameters:
        -----------
        t : array-like
            Parameter in [0, 1]
        n : int
            Winding number (can be negative for opposite orientation)
        
        Returns:
        --------
        (x, y) coordinates on the unit circle
        """
        theta = 2 * np.pi * n * t
        return np.cos(theta), np.sin(theta)
    
    @staticmethod
    def torus_loop(t, m=1, n=1):
        """
        A loop on the torus winding m times around the major circle
        and n times around the minor circle.
        
        Parameters:
        -----------
        t : array-like
            Parameter in [0, 1]
        m, n : int
            Winding numbers for the two generators
        
        Returns:
        --------
        (x, y, z) coordinates on the torus
        """
        R = 3  # Major radius
        r = 1  # Minor radius
        
        theta = 2 * np.pi * m * t  # Around major circle
        phi = 2 * np.pi * n * t    # Around minor circle
        
        x = (R + r * np.cos(phi)) * np.cos(theta)
        y = (R + r * np.cos(phi)) * np.sin(theta)
        z = r * np.sin(phi)
        
        return x, y, z
    
    @staticmethod
    def compute_winding_number(z_values):
        """
        Compute the winding number of a closed curve around the origin.
        Uses the argument principle.
        """
        # Compute change in argument
        angles = np.angle(z_values)
        
        # Unwrap to handle branch cuts
        angles = np.unwrap(angles)
        
        # Total change divided by 2π
        total_change = angles[-1] - angles[0]
        winding = total_change / (2 * np.pi)
        
        return round(winding)

2. Number Theory: The Law of Quadratic Reciprocity

Introduction

The Law of Quadratic Reciprocity, first proved by Gauss in 1796, is one of the most beautiful and profound theorems in number theory. It reveals a surprising symmetry in the solvability of quadratic ≅ruences modulo different primes.

Given an odd prime p and integer a not divisible by p, we ask: does x2 equiv a pmodp have a solution? The Legendre symbol (a/p) encodes this information. Quadratic reciprocity tells us how (p/q) relates to (q/p) for distinct odd primes p and q.

Notation Guide

  • (a/p) — Legendre symbol
  • (a/p) = 1 — a is a quadratic residue mod p
  • (a/p) = -1 — a is a quadratic non-residue mod p
  • (a/p) = 0 — p mid a
  • a equiv b pmodp — ≅ruence modulo p
  • p^* = (-1)(p-1)/2 p — the "dual" of p
Definition: Legendre Symbol

For an odd prime p and integer a:

(a/p) = begincases 1 & if a equiv x2 pmodp for some x notequiv 0 pmodp \\ -1 & if a notequiv x2 pmodp for all x \\ 0 & if p mid a endcases

Euler's Criterion

For an odd prime p and integer a with p nmid a:

(a/p) equiv a(p-1)/2 pmodp

The Law of Quadratic Reciprocity

Let p and q be distinct odd primes. Then:

(p/q)(q/p) = (-1)fracp-12 cdot q-1/2

Equivalently:

  • If p equiv 1 pmod4 or q equiv 1 pmod4, then (p/q) = (q/p)
  • If p equiv q equiv 3 pmod4, then (p/q) = -(q/p)
Supplementary Laws

(-1/p) = (-1)(p-1)/2 = begincases 1 & if p equiv 1 pmod4 \\ -1 & if p equiv 3 pmod4 endcases

(2/p) = (-1)(p2-1)/8 = begincases 1 & if p equiv 1, 7 pmod8 \\ -1 & if p equiv 3, 5 pmod8 endcases

Proof Sketch (Gauss's Third Proof via Gauss Sums)

Step 1: Define the Gauss sum for an odd prime p:

gp = sumk=0p-1 (k/p) zetapk

where zetap = e2pi i/p is a primitive p-th root of unity.

Step 2: Compute |gp|2 = gp cdot gp̄ = p.

Step 3: For another odd prime q, consider gpq pmodq in the ring ℤ[zetap]:

gpq equiv sumk=0p-1 (k/p)q zetapqk = sumk=0p-1 (k/p) zetapqk = (q/p) gp pmodq

Step 4: Using gp2 = p^* = (-1)(p-1)/2p:

gpq-1 = (gp2)(q-1)/2 = (p^*)(q-1)/2 equiv (p^*/q) pmodq

Step 5: Combining: (q/p) gp equiv gpq = gp cdot gpq-1 equiv gp (p^*/q) pmodq

Step 6: Since gp is invertible, (q/p) = (p^*/q) = ((-1)(p-1)/2p/q) = (-1/q)(p-1)/2(p/q)

Step 7: Using the supplementary law for -1:

(q/p) = (-1)fracq-12 cdot p-1/2 (p/q)

which gives the reciprocity law.

Python Implementation

def legendre_symbol(a, p):
    """
    Compute the Legendre symbol (a/p) using Euler's criterion.
    """
    if p == 2:
        raise ValueError("p must be odd")
    
    a = a % p
    if a == 0:
        return 0
    
    # Euler's criterion: (a/p) ≡ a^((p-1)/2) (mod p)
    result = pow(a, (p - 1) // 2, p)
    return 1 if result == 1 else -1

def quadratic_reciprocity(p, q):
    """
    Apply the law of quadratic reciprocity.
    Returns (p/q) * (q/p) which equals (-1)^(((p-1)/2)*((q-1)/2))
    """
    # Compute the sign
    exp = ((p - 1) // 2) * ((q - 1) // 2)
    return (-1) ** exp

3. Abstract Algebra: The Sylow Theorems

Introduction

The Sylow theorems, proved by Peter Ludwig Mejdell Sylow in 1872, are fundamental results in finite group theory. They provide a partial converse to Lagrange's theorem and give deep structural information about finite groups, particularly regarding the existence and conjugacy of subgroups of prime power order.

These theorems are essential tools for classifying finite groups and understanding their internal structure. They show that for any prime power dividing the order of a group, there exists a subgroup of that order, and provide constraints on how many such subgroups can exist.

Notation Guide

  • |G| — order (cardinality) of group G
  • p — a prime number
  • pn mid |G| — pn divides |G|
  • np — number of Sylow p-subgroups
  • NG(H) — normalizer of H in G
  • H trianglelefteq G — H is normal in G
  • gHg-1 — conjugate of H by g
Definition: Sylow p-Subgroup

Let G be a finite group with |G| = pn m where p is prime and p nmid m. A Sylow p-subgroup of G is a subgroup of order pn.

The Sylow Theorems

Let G be a finite group with |G| = pn m where p is prime and p nmid m.

First Sylow Theorem (Existence): G has at least one Sylow p-subgroup.

Second Sylow Theorem (Conjugacy): All Sylow p-subgroups of G are conjugate. If P and Q are Sylow p-subgroups, then Q = gPg-1 for some g in G.

Third Sylow Theorem (Counting): The number np of Sylow p-subgroups satisfies:

  1. np equiv 1 pmodp
  2. np mid m
Proof of First Sylow Theorem (Existence)

Step 1: Consider the set Omega of all subsets of G with pn elements. The size is:

|Omega| = binompn mpn

Step 2: By Lucas' theorem or direct computation, p nmid binompn mpn.

Step 3: G acts on Omega by left multiplication: g cdot X = gX = \gx : x in X\.

Step 4: Since p nmid |Omega|, there exists an orbit O with p nmid |O|.

Step 5: By the orbit-stabilizer theorem, |O| = |G|/|GX| where GX is the stabilizer of X in O.

Step 6: Since |G| = pn m and p nmid |O|, we have pn mid |GX|.

Step 7: For any x in X, the map GX to X given by g mapsto gx is injective. Thus |GX| leq |X| = pn.

Step 8: Combining: |GX| = pn, so GX is a Sylow p-subgroup. ∎

Python Implementation

import math

def prime_factorization(n):
    """Return prime factorization as {p: exponent}."""
    factors = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors

def sylow_constraints(order):
    """
    Compute the constraints on the number of Sylow p-subgroups
    for each prime dividing the group order.
    """
    factors = prime_factorization(order)
    constraints = {}
    
    for p, n in factors.items():
        p_power = p ** n
        m = order // p_power
        
        # n_p must satisfy:
        # 1. n_p ≡ 1 (mod p)
        # 2. n_p | m
        
        divisors = []
        for i in range(1, int(math.sqrt(m)) + 1):
            if m % i == 0:
                divisors.append(i)
                if i != m // i:
                    divisors.append(m // i)
        
        valid_n_p = sorted([d for d in divisors if d % p == 1])
        
        constraints[p] = {
            'sylow_order': p_power,
            'm': m,
            'possible_n_p': valid_n_p
        }
    
    return constraints

1. Calculus: Stokes' Theorem

Introduction

Stokes' theorem is one of the crowning achievements of vector calculus, generalizing the fundamental theorem of calculus to higher dimensions. It relates the integral of a differential form over the boundary of a manifold to the integral of its exterior derivative over the whole manifold.

In its classical form, Stokes' theorem states that the circulation of a vector field around a closed curve equals the flux of the curl through any surface bounded by that curve.

Notation Guide

  • M — an oriented n-dimensional manifold with boundary
  • partial M — the boundary of M
  • ω — a differential (n-1)-form
  • domega — exterior derivative of ω
  • F = (F1, F2, F3) — vector field
  • nabla times F — curl of F
Classical Stokes' Theorem

Let S be a piecewise smooth, oriented surface in ℝ3 with piecewise smooth boundary curve partial S. Let F be a vector field with continuous partial derivatives on an open region containing S. Then:

ointpartial S F cdot dr = iintS (nabla times F) cdot dS

where the orientation of partial S is induced by the orientation of S (right-hand rule).

General Stokes' Theorem

Let M be a compact, oriented n-dimensional manifold with boundary partial M. Let ω be a smooth (n-1)-form on M. Then:

intM domega = intpartial M omega

Python Implementation

import numpy as np

class StokesTheorem:
    """
    Computational exploration of Stokes' Theorem.
    """
    
    @staticmethod
    def curl(F, x, y, z, h=1e-5):
        """
        Compute curl of vector field F = (F1, F2, F3) at point (x,y,z).
        """
        F1, F2, F3 = F
        
        # Partial derivatives using central differences
        def partial_x(F_i, x, y, z):
            return (F_i(x + h, y, z) - F_i(x - h, y, z)) / (2 * h)
        
        def partial_y(F_i, x, y, z):
            return (F_i(x, y + h, z) - F_i(x, y - h, z)) / (2 * h)
        
        def partial_z(F_i, x, y, z):
            return (F_i(x, y, z + h) - F_i(x, y, z - h)) / (2 * h)
        
        # curl F = (∂F3/∂y - ∂F2/∂z, ∂F1/∂z - ∂F3/∂x, ∂F2/∂x - ∂F1/∂y)
        curl_x = partial_y(F3, x, y, z) - partial_z(F2, x, y, z)
        curl_y = partial_z(F1, x, y, z) - partial_x(F3, x, y, z)
        curl_z = partial_x(F2, x, y, z) - partial_y(F1, x, y, z)
        
        return np.array([curl_x, curl_y, curl_z])
    
    @staticmethod
    def line_integral(F, curve, t_vals):
        """
        Compute line integral ∫ F · dr along a parameterized curve.
        """
        dt = t_vals[1] - t_vals[0]
        integral = 0
        
        for t in t_vals[:-1]:
            r = curve(t)
            r_next = curve(t + dt)
            dr = r_next - r
            
            F_val = F(r[0], r[1], r[2])
            integral += np.dot(F_val, dr)
        
        return integral

2. Mathematical Physics: Fourier Analysis

Introduction

Fourier analysis, developed by Joseph Fourier in the early 19th century, reveals that any periodic function can be decomposed into a sum of sinusoidal components. This profound insight connects time-domain and frequency-domain representations, with applications spanning physics, engineering, signal processing, and pure mathematics.

Notation Guide

  • f(t) — function in time domain
  • f̂(xi) or F(omega) — Fourier transform
  • omega = 2pi xi — angular frequency
  • eitheta = costheta + isintheta — Euler's formula
  • L2(ℝ) — space of square-integrable functions
Fourier Series

Let f: ℝ to ℂ be a periodic function with period 2pi that is square-integrable on [-pi, pi]. Then:

f(t) = sumn=-inftyinfty cn eint

where the Fourier coefficients are:

cn = 1/2pi int-pipi f(t) e-int\,dt

Fourier Transform

For f in L1(ℝ) cap L2(ℝ):

f̂(xi) = int-inftyinfty f(t) e-2pi i xi t\,dt

Inverse transform:

f(t) = int-inftyinfty f̂(xi) e2pi i xi t\,dxi

Plancherel's Theorem

The Fourier transform preserves the L² norm:

int-inftyinfty |f(t)|2\,dt = int-inftyinfty |f̂(xi)|2\,dxi

This is the mathematical statement of energy conservation between time and frequency domains.

Python Implementation

import numpy as np

class FourierAnalysis:
    """
    Computational Fourier analysis implementation.
    """
    
    @staticmethod
    def dft(x):
        """
        Discrete Fourier Transform (naive O(n²) implementation).
        X[k] = Σ_{n=0}^{N-1} x[n] * e^(-2πikn/N)
        """
        N = len(x)
        X = np.zeros(N, dtype=complex)
        
        for k in range(N):
            for n in range(N):
                X[k] += x[n] * np.exp(-2j * np.pi * k * n / N)
        
        return X
    
    @staticmethod
    def fft(x):
        """
        Fast Fourier Transform (Cooley-Tukey algorithm).
        O(n log n) complexity.
        """
        x = np.asarray(x, dtype=complex)
        N = len(x)
        
        if N <= 1:
            return x
        
        # Ensure N is power of 2
        if N % 2 != 0:
            next_pow2 = 2**int(np.ceil(np.log2(N)))
            x = np.pad(x, (0, next_pow2 - N))
            N = next_pow2
        
        # Recursive FFT
        even = FourierAnalysis.fft(x[0::2])
        odd = FourierAnalysis.fft(x[1::2])
        
        T = np.exp(-2j * np.pi * np.arange(N//2) / N) * odd
        
        return np.concatenate([even + T, even - T])

3. Information Theory: Shannon Entropy

Introduction

Claude Shannon's 1948 paper "A Mathematical Theory of Communication" founded information theory and introduced entropy as a measure of uncertainty or information content. This concept, borrowed from statistical mechanics, quantifies the average amount of information produced by a probabilistic source.

Notation Guide

  • X — a random variable
  • X — alphabet (set of possible values)
  • p(x) = P(X = x) — probability mass function
  • H(X) — Shannon entropy of X
  • H(X|Y) — conditional entropy
  • I(X;Y) — mutual information
  • log — logarithm (base 2 for bits, base e for nats)
Definition: Shannon Entropy

For a discrete random variable X with probability mass function p(x) on alphabet X:

H(X) = -sumx in X p(x) log p(x) = mathbbE[-log p(X)]

where we define 0 log 0 = 0. The units are bits if log is base 2, nats if base e.

Properties of Entropy
  1. Non-negativity: H(X) geq 0 with equality iff X is deterministic
  2. Upper bound: H(X) leq log |X| with equality iff uniform distribution
  3. Chain rule: H(X,Y) = H(X) + H(Y|X)
  4. Conditioning reduces entropy: H(X|Y) leq H(X)
  5. Subadditivity: H(X,Y) leq H(X) + H(Y)

Python Implementation

import numpy as np
from collections import Counter

class InformationTheory:
    """
    Information theory calculations and demonstrations.
    """
    
    @staticmethod
    def entropy(probs, base=2):
        """
        Compute Shannon entropy H(X) = -Σ p(x) log p(x).
        """
        probs = np.array(probs)
        probs = probs[probs > 0]  # Remove zeros
        
        log_func = np.log2 if base == 2 else np.log
        return -np.sum(probs * log_func(probs))
    
    @staticmethod
    def mutual_information(joint_probs, base=2):
        """
        Compute mutual information I(X;Y).
        """
        joint = np.array(joint_probs)
        
        # Marginals
        p_x = np.sum(joint, axis=1)
        p_y = np.sum(joint, axis=0)
        
        # I(X;Y) = Σ P(x,y) log(P(x,y)/(P(x)P(y)))
        log_func = np.log2 if base == 2 else np.log
        
        mi = 0
        for i in range(len(p_x)):
            for j in range(len(p_y)):
                if joint[i,j] > 0:
                    mi += joint[i,j] * log_func(joint[i,j] / (p_x[i] * p_y[j]))
        
        return mi

1. Goldbach Conjecture

Introduction

Proposed by Christian Goldbach in a 1742 letter to Leonhard Euler, the Goldbach conjecture is one of the oldest and best-known unsolved problems in number theory. It states that every even integer greater than 2 can be expressed as the sum of two prime numbers.

Notation Guide

  • ℙ — set of prime numbers
  • p, q — prime numbers
  • n = p + q — Goldbach partition
  • G(n) — number of Goldbach partitions of n
  • pi(x) — prime-counting function
Goldbach's Strong Conjecture

Every even integer n > 2 can be expressed as the sum of two primes:

n = p + q

where p, q in ℙ.

Goldbach's Weak Conjecture (Proved)

Every odd number greater than 5 can be expressed as the sum of three primes:

n = p + q + r

Status: Proved by Harald Helfgott in 2013.

Python Implementation

from sympy import isprime, primerange

def goldbach_partitions(n):
    """
    Find all Goldbach partitions of even n.
    Returns list of (p, q) pairs where p + q = n and p ≤ q.
    """
    if n <= 2 or n % 2 != 0:
        return []
    
    partitions = []
    for p in range(2, n // 2 + 1):
        if isprime(p) and isprime(n - p):
            partitions.append((p, n - p))
    
    return partitions

def count_goldbach_partitions(n):
    """Count number of Goldbach partitions (G(n))."""
    return len(goldbach_partitions(n))

2. Collatz Conjecture

Introduction

The Collatz conjecture, also known as the 3n+1 problem or the Ulam conjecture, is a deceptively simple unsolved problem in number theory. Proposed by Lothar Collatz in 1937, it asks whether iterating a simple arithmetic function always eventually reaches 1, regardless of the starting number.

Notation Guide

  • f(n) — Collatz function
  • nk — k-th iterate
  • sigma(n) — total stopping time
  • h(n) — height (maximum value reached)
The Collatz Function

Define f: ℤ^+ to ℤ^+ by:

f(n) = begincases n/2 & if n equiv 0 pmod2 \\ 3n + 1 & if n equiv 1 pmod2 endcases

The Collatz Conjecture

For every positive integer n, there exists k such that:

f(k)(n) = 1

where f(k) denotes the k-fold iteration of f.

Python Implementation

def collatz(n):
    """
    Generate Collatz sequence starting from n.
    Returns the sequence until it reaches 1.
    """
    sequence = [n]
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        sequence.append(n)
    return sequence

def collatz_stopping_time(n):
    """Return the number of steps to reach 1."""
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        steps += 1
    return steps

def collatz_height(n):
    """Return the maximum value reached."""
    max_val = n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        max_val = max(max_val, n)
    return max_val

3. p-adic Numbers

Introduction

The p-adic numbers, introduced by Kurt Hensel in 1897, provide an alternative completion of the rational numbers distinct from the real numbers. While real numbers are constructed using the usual absolute value, p-adic numbers use the p-adic absolute value based on divisibility by a prime p.

Notation Guide

  • p — a prime number
  • nup(n) — p-adic valuation (highest power of p dividing n)
  • |x|p — p-adic absolute value
  • dp(x,y) = |x-y|p — p-adic metric
  • ℚp — field of p-adic numbers
  • ℤp — ring of p-adic integers
p-adic Valuation

For a non-zero integer n, the p-adic valuation nup(n) is the highest power of p dividing n:

n = pnup(n) cdot m where p nmid m

For a rational number x = a/b:

nup(x) = nup(a) - nup(b)

By convention, nup(0) = +infty.

p-adic Absolute Value

The p-adic absolute value is defined as:

|x|p = p-nup(x)

for x neq 0, and |0|p = 0.

Properties:

  1. |x|p geq 0 with equality iff x = 0
  2. |xy|p = |x|p |y|p
  3. Strong triangle inequality: |x + y|p leq max(|x|p, |y|p)
Ostrowski's Theorem

Every non-trivial absolute value on ℚ is equivalent to either:

  1. The usual absolute value |cdot|_infty (giving ℝ)
  2. The p-adic absolute value |cdot|p for some prime p (giving ℚp)

Python Implementation

from fractions import Fraction

def p_adic_valuation(n, p):
    """
    Compute the p-adic valuation ν_p(n).
    Returns the highest power of p dividing n.
    """
    if n == 0:
        return float('inf')
    
    n = abs(n)
    valuation = 0
    while n % p == 0:
        n //= p
        valuation += 1
    return valuation

def p_adic_valuation_rational(x, p):
    """
    Compute ν_p(a/b) = ν_p(a) - ν_p(b).
    """
    if x == 0:
        return float('inf')
    
    frac = Fraction(x).limit_denominator()
    return p_adic_valuation(frac.numerator, p) - p_adic_valuation(frac.denominator, p)

def p_adic_absolute_value(x, p):
    """
    Compute the p-adic absolute value |x|_p = p^(-ν_p(x)).
    """
    if x == 0:
        return 0
    return p ** (-p_adic_valuation_rational(x, p))

4. Twin Prime Conjecture

Introduction

The Twin Prime Conjecture states that there are infinitely many pairs of primes that differ by 2, such as (3, 5), (5, 7), (11, 13), and (17, 19). This is one of the oldest unsolved problems in number theory, dating back to the ancient Greeks.

Notation Guide

  • π₂(x) — twin prime counting function
  • pi(x) — prime counting function
  • C2 — twin prime constant
  • pn — the n-th prime
  • dn = pn+1 - pn — prime gap
Twin Prime Conjecture

There are infinitely many primes p such that p + 2 is also prime. Equivalently:

π₂(x) to infty as x to infty

where π₂(x) = #\p leq x : p and p+2 are both prime\.

Hardy-Littlewood Conjecture

The number of twin prime pairs up to x is asymptotically:

π₂(x) sim 2C2 x/(log x)2

where C2 is the twin prime constant:

C2 = prodp geq 3 p(p-2)/(p-1)2 approx 0.6601618158...

Zhang's Theorem (2013)

liminfn to infty (pn+1 - pn) < 70,000,000

There are infinitely many pairs of primes with gap at most 70 million.

Current best unconditional bound: 246 (Polymath8a + Maynard)

Python Implementation

from sympy import isprime, primerange, primepi
import numpy as np

def is_twin_prime(p):
    """Check if p is part of a twin prime pair."""
    return isprime(p) and (isprime(p - 2) or isprime(p + 2))

def twin_prime_pairs(limit):
    """Generate all twin prime pairs (p, p+2) with p+2 ≤ limit."""
    pairs = []
    for p in primerange(3, limit + 1):
        if isprime(p + 2):
            pairs.append((p, p + 2))
    return pairs

def pi_2(x):
    """Count twin prime pairs (p, p+2) with p+2 ≤ x."""
    return len(twin_prime_pairs(x))

📜 A Brief History of Mathematics

Ancient Period (3000 BCE - 500 CE)

Babylonians and Egyptians (3000-500 BCE): Developed practical mathematics for astronomy, construction, and commerce. The Babylonians used base-60 number systems and solved quadratic equations. The Egyptians calculated areas and volumes, as seen in the Rhind Papyrus.

Greek Mathematics (600 BCE - 400 CE): The golden age of pure mathematics. Thales introduced deductive reasoning. Pythagoras and his school discovered irrational numbers. Euclid's "Elements" systematized geometry. Archimedes made groundbreaking contributions to calculus concepts. Diophantus pioneered algebra with his study of equations.

Medieval Period (500-1500 CE)

Islamic Golden Age (750-1258): Scholars preserved and extended Greek knowledge. Al-Khwarizmi's "Algebra" gave the subject its name. Omar Khayyam solved cubic equations geometrically. Arabic numerals and decimal notation spread to Europe.

Indian Mathematics: Developed the decimal place-value system with zero. Brahmagupta gave rules for arithmetic with zero and negative numbers. Madhava discovered infinite series for trigonometric functions, anticipating calculus by centuries.

Early Modern Period (1500-1800)

Renaissance and Scientific Revolution: Cardano published solutions to cubic and quartic equations. Viète introduced symbolic algebra. Descartes unified algebra and geometry with coordinate systems. Newton and Leibniz independently developed calculus.

18th Century: Euler was the most prolific mathematician in history, making foundational contributions to analysis, number theory, graph theory, and topology. Lagrange and Laplace advanced celestial mechanics and analysis.

Modern Period (1800-Present)

19th Century: Gauss crowned the "Prince of Mathematicians" with contributions to number theory, algebra, statistics, and differential geometry. Galois founded group theory. Riemann revolutionized geometry. Cantor created set theory, opening questions about infinity. Non-Euclidean geometries challenged Euclidean dominance.

20th Century: Hilbert's problems guided mathematical research. Gödel's incompleteness theorems set fundamental limits. Bourbaki attempted to rebuild mathematics from set theory. Category theory emerged as a unifying framework. Computers transformed both pure and applied mathematics.

21st Century: The Langlands program connects number theory and representation theory. Computer-assisted proofs (like the Four Color Theorem and Kepler conjecture) raise philosophical questions. Machine learning creates new conjectures and approaches. The Polymath project demonstrates collaborative online mathematics.
