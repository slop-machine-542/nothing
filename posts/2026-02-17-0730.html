1. Baire Category Theorem and Complete Metric Spaces

The Baire Category Theorem is a fundamental result in analysis and topology that reveals the structure of complete metric spaces. It states that in a complete metric space, the intersection of countably many dense open sets is dense.

Theorem (Baire Category Theorem): Let \((X, d)\) be a complete metric space. If \(\{U_n\}_{n=1}^{\infty}\) is a sequence of dense open sets in \(X\), then \(\bigcap_{n=1}^{\infty} U_n\) is dense in \(X\).
Proof: Let \(V\) be any non-empty open set in \(X\). We must show \(V \cap \bigcap_{n=1}^{\infty} U_n \neq \emptyset\). Since \(U_1\) is dense, \(V \cap U_1\) is non-empty and open. Choose a closed ball \(\overline{B}(x_1, r_1) \subseteq V \cap U_1\) with \(r_1 < 1\). Inductively, since \(U_{n+1}\) is dense, \(B(x_n, r_n) \cap U_{n+1}\) is non-empty and open. Choose \(\overline{B}(x_{n+1}, r_{n+1}) \subseteq B(x_n, r_n) \cap U_{n+1}\) with \(r_{n+1} < 1/(n+1)\). The sequence \(\{x_n\}\) is Cauchy since \(d(x_m, x_n) < 1/n\) for \(m > n\). By completeness, \(x_n \to x\). Since \(x \in \overline{B}(x_n, r_n)\) for all \(n\), we have \(x \in V \cap \bigcap_{n=1}^{\infty} U_n\).

Notation: A set is meager (or of first category) if it is a countable union of nowhere dense sets. A set is comeager (or residual) if its complement is meager. The theorem implies that complete metric spaces are not meager in themselves.

# Python: Exploring Baire Category concepts
import numpy as np

def is_dense_in_interval(S, interval=(0, 1), epsilon=0.01):
    """
    Check if set S is epsilon-dense in interval.
    S should be a list of points.
    """
    x = np.linspace(interval[0], interval[1], 1000)
    for point in x:
        if all(abs(point - s) > epsilon for s in S):
            return False
    return True

def construct_dense_open_in_cantor_set(n):
    """
    Construct a dense open set in the complement of Cantor set.
    Returns the union of intervals removed at stage n.
    """
    # Cantor set construction: at stage n, we have 2^n intervals
    # The removed middle thirds form open dense sets in [0,1]\C
    intervals = [(0, 1)]
    removed = []
    
    for stage in range(n):
        new_intervals = []
        for a, b in intervals:
            mid1 = a + (b - a) / 3
            mid2 = a + 2 * (b - a) / 3
            removed.append((mid1, mid2))
            new_intervals.extend([(a, mid1), (mid2, b)])
        intervals = new_intervals
    
    return removed

2. The Open Mapping Theorem in Functional Analysis

The Open Mapping Theorem (also known as the Banach-Schauder theorem) establishes that surjective continuous linear operators between Banach spaces are open maps.

Theorem (Open Mapping): Let \(X\) and \(Y\) be Banach spaces. If \(T: X \to Y\) is a surjective bounded linear operator, then \(T\) is an open map (maps open sets to open sets).
Proof Outline: (1) Show \(T(B_X)\) contains a neighborhood of 0 in \(Y\), where \(B_X\) is the unit ball. Use Baire Category: \(Y = \bigcup_{n=1}^{\infty} n\overline{T(B_X)}\), so some \(n\overline{T(B_X)}\) has non-empty interior. (2) By scaling, \(\overline{T(B_X)}\) contains a ball around 0. (3) Use the completeness of \(X\) to show \(T(B_X)\) itself contains a ball. (4) For any open \(U \subseteq X\) and \(y = T(x) \in T(U)\), find a ball around \(y\) contained in \(T(U)\).

Notation: A Banach space is a complete normed vector space. \(B_X = \{x \in X : \|x\| < 1\}\) denotes the open unit ball. A map is open if the image of every open set is open.

# Python: Open Mapping Theorem and linear operators
import numpy as np
from numpy.linalg import norm, cond

def is_open_mapping_approximation(T, test_points=1000):
    """
    Numerically check if a linear operator T is 'open' by examining
    how it maps small balls.
    """
    n = T.shape[1]  # Input dimension
    m = T.shape[0]  # Output dimension
    
    # Generate random points in unit ball
    points = np.random.randn(test_points, n)
    points = points / np.linalg.norm(points, axis=1, keepdims=True)
    points *= np.random.uniform(0, 1, (test_points, 1)) ** (1/n)
    
    # Map through T
    mapped = points @ T.T
    
    # Check if mapped points fill a neighborhood of 0
    distances = np.linalg.norm(mapped, axis=1)
    min_radius = np.min(distances[distances > 0.001])
    max_radius = np.max(distances)
    
    return {
        'min_radius': min_radius,
        'max_radius': max_radius,
        'condition_number': cond(T),
        'is_surjective_approx': min_radius < 0.1  # Heuristic
    }

# Example 1: Surjective operator (open mapping applies)
T_surjective = np.array([[1, 0], [0, 1], [1, 1]], dtype=float)
result1 = is_open_mapping_approximation(T_surjective)
print("Surjective operator (onto R^2 from R^3 projection):")
print(f"  Condition number: {result1['condition_number']:.4f}")

# Example 2: Invertible square matrix

3. Galois Theory and the Insolvability of the Quintic

Galois Theory establishes a profound connection between field extensions and group theory, providing criteria for when polynomial equations can be solved by radicals.

Theorem (Galois Criterion for Solvability): A polynomial \(f(x) \in F[x]\) is solvable by radicals if and only if its Galois group \(Gal(f)\) is a solvable group.
Abel-Ruffini Theorem: There exist polynomials of degree 5 (quintics) that are not solvable by radicals.
Proof Sketch: Consider \(f(x) = x^5 - x + 1\). Its Galois group over \(\mathbb{Q}\) is \(S_5\), the symmetric group on 5 elements. For \(n \geq 5\), \(S_n\) is not solvable because its only normal subgroup is \(A_n\) (alternating group), and \(A_n\) is simple (no non-trivial normal subgroups) for \(n \geq 5\). Since \(A_5\) is not abelian, the composition series cannot have all abelian factors. Therefore, \(S_5\) is not solvable, and the polynomial cannot be solved by radicals.

Notation: A group is solvable if it has a composition series where all factor groups are abelian. The Galois group \(Gal(E/F)\) is the group of field automorphisms of \(E\) that fix \(F\) pointwise.

# Python: Exploring Galois groups computationally
import numpy as np
from itertools import permutations

def apply_permutation_to_roots(perm, roots):
    """Apply a permutation to a list of roots."""
    return [roots[perm[i]] for i in range(len(roots))]

def is_automorphism_over_Q(perm, roots, relations):
    """
    Check if a permutation preserves algebraic relations over Q.
    relations: list of polynomial relations that roots satisfy.
    """
    permuted_roots = apply_permutation_to_roots(perm, roots)
    
    for relation in relations:
        # Evaluate relation on original roots
        original_val = relation(roots)
        # Evaluate on permuted roots
        permuted_val = relation(permuted_roots)
        if abs(original_val - permuted_val) > 1e-10:
            return False
    return True

def galois_group_of_cyclotomic(n):
    """
    The Galois group of Q(ζ_n)/Q is isomorphic to (Z/nZ)*.
    Returns the group structure.
    """
    # Units modulo n
    units = [k for k in range(1, n) if np.gcd(k, n) == 1]
    
    # Group operation is multiplication modulo n
    def multiply(a, b):
        return (a * b) % n
    
    # Check group properties
    print(f"Cyclotomic field Q(ζ_{n})")
    print(f"Galois group isomorphic to (Z/{n}Z)* = {units}")
    print(f"Order of group: {len(units)} = φ({n})")
    
    # Find generators (primitive roots)
    phi_n = len(units)
    generators = []
    for g in units:
        generated = set()
        current = 1
        for _ in range(phi_n):
            generated.add(current)
            current = multiply(current, g)
        if len(generated) == phi_n:
            generators.append(g)
    
    print(f"Generators: {generators}")
    return units

1. Markov Chains and Stationary Distributions

A Markov chain is a stochastic process where the future state depends only on the present state, not on the past. Formally, \(P(X_{n+1} = j | X_n = i, X_{n-1}, \ldots, X_0) = P(X_{n+1} = j | X_n = i) = p_{ij}\).

Theorem (Fundamental Theorem of Markov Chains): For an irreducible, aperiodic Markov chain on a finite state space, there exists a unique stationary distribution \(\pi\) such that \(\pi P = \pi\). Moreover, for any initial distribution, \(P(X_n = j) \to \pi_j\) as \(n \to \infty\).
Proof Sketch: (1) Irreducibility ensures the chain can reach any state from any other state. (2) Aperiodicity prevents cyclic behavior. (3) By the Perron-Frobenius theorem, the transition matrix \(P\) has a unique largest eigenvalue \(\lambda_1 = 1\) with positive eigenvector \(\pi\). (4) All other eigenvalues satisfy \(|\lambda_i| < 1\). (5) Writing any initial distribution in the eigenbasis shows convergence to \(\pi\).

Notation: \(\pi\) is a row vector called the stationary distribution. A chain is irreducible if all states communicate. It is aperiodic if \(\gcd\{n : p_{ii}^{(n)} > 0\} = 1\) for all \(i\).

# Python: Markov chains and PageRank
import numpy as np

def create_transition_matrix(links, n_pages):
    """
    Create transition matrix for web graph.
    links: list of (from, to) tuples
    """
    P = np.zeros((n_pages, n_pages))
    out_degree = np.zeros(n_pages)
    
    for src, dst in links:
        out_degree[src] += 1
    
    for src, dst in links:
        if out_degree[src] > 0:
            P[src, dst] = 1.0 / out_degree[src]
    
    # Handle dangling nodes (pages with no out-links)
    for i in range(n_pages):
        if out_degree[i] == 0:
            P[i, :] = 1.0 / n_pages
    
    return P

def pagerank(P, damping=0.85, tol=1e-10, max_iter=1000):
    """
    Compute PageRank using power iteration.
    P: transition matrix
    damping: probability of following a link (vs random jump)
    """
    n = P.shape[0]
    
    # Modified transition matrix with damping
    M = damping * P + (1 - damping) * np.ones((n, n)) / n
    
    # Power iteration
    pi = np.ones(n) / n  # Uniform initial distribution
    
    for _ in range(max_iter):
        pi_new = pi @ M
        if np.linalg.norm(pi_new - pi, 1) < tol:
            break
        pi = pi_new
    
    return pi

# Example: Small web graph
# 0 -> 1, 0 -> 2
# 1 -> 2
# 2 -> 0, 2 -> 1
# 3 -> 0, 3 -> 2 (dangling node if no out-links)
links = [(0, 1), (0, 2), (1, 2), (2, 0), (2, 1), (3, 0), (3, 2)]
P = create_transition_matrix(links, 4)

print("Transition Matrix P:")
print(P)

# Compute stationary distribution directly (eigenvector method)
eigenvalues, eigenvectors = np.linalg.eig(P.T)
stationary_idx = np.argmin(np.abs(eigenvalues - 1))
stationary = eigenvectors[:, stationary_idx].real
stationary = stationary / np.sum(stationary)
print(f"\nStationary distribution (eigenvector): {stationary}")

# Compute PageRank
pr = pagerank(P, damping=0.85)
print(f"PageRank: {pr}")

# Verify: pi * P should equal pi
print(f"\nVerification (pi @ P - pi): {np.linalg.norm(stationary @ P - stationary)}")

2. Shannon's Information Theory and Channel Capacity

Information theory, founded by Claude Shannon in 1948, quantifies information and establishes fundamental limits on data compression and transmission.

Theorem (Shannon's Source Coding): For a source with entropy \(H(X)\), the average number of bits per symbol needed for lossless encoding satisfies \(L \geq H(X)\), and this bound is achievable.
Theorem (Channel Capacity): The capacity of a discrete memoryless channel is \(C = \max_{p(x)} I(X;Y)\), where \(I(X;Y) = H(X) - H(X|Y)\) is the mutual information. Reliable communication is possible at any rate \(R < C\) and impossible for \(R > C\).
Proof Sketch (Achievability): Random coding argument. Generate \(2^{nR}\) codewords of length \(n\) i.i.d. according to \(p(x)\). To decode, find the unique codeword jointly typical with the received sequence. By the asymptotic equipartition property, the probability of error vanishes as \(n \to \infty\) if \(R < C\).

Notation: \(H(X) = -\sum p(x) \log p(x)\) is Shannon entropy. \(I(X;Y)\) is mutual information. The binary entropy function is \(H_2(p) = -p\log p - (1-p)\log(1-p)\).

# Python: Information theory fundamentals
import numpy as np

def entropy(p):
    """Shannon entropy H(X) = -sum p(x) log p(x)"""
    p = np.array(p)
    p = p[p > 0]  # Remove zeros to avoid log(0)
    return -np.sum(p * np.log2(p))

def conditional_entropy(p_xy):
    """
    H(Y|X) = -sum_{x,y} p(x,y) log p(y|x)
    p_xy: joint distribution as 2D array
    """
    p_x = np.sum(p_xy, axis=1, keepdims=True)
    p_y_given_x = p_xy / (p_x + 1e-10)
    return -np.sum(p_xy * np.log2(p_y_given_x + 1e-10))

def mutual_information(p_xy):
    """
    I(X;Y) = H(X) + H(Y) - H(X,Y)
    """
    p_x = np.sum(p_xy, axis=1)
    p_y = np.sum(p_xy, axis=0)
    h_x = entropy(p_x)
    h_y = entropy(p_y)
    h_xy = entropy(p_xy.flatten())
    return h_x + h_y - h_xy

def binary_entropy(p):
    """H_2(p) = -p log p - (1-p) log(1-p)"""
    if p <= 0 or p >= 1:
        return 0
    return -p * np.log2(p) - (1-p) * np.log2(1-p)

def binary_symmetric_channel_capacity(error_prob):
    """
    Capacity of BSC with error probability p.
    C = 1 - H_2(p)
    """
    return 1 - binary_entropy(error_prob)

# Example 1: Entropy of a fair coin vs biased coin

3. Linear Programming and the Simplex Method

Linear programming optimizes a linear objective function subject to linear equality and inequality constraints. The standard form is: minimize \(c^T x\) subject to \(Ax = b\), \(x \geq 0\).

Theorem (Strong Duality): If the primal problem has an optimal solution \(x^*\), then the dual problem has an optimal solution \(y^*\) with \(c^T x^* = b^T y^*\).
Theorem (Complementary Slackness): Optimal solutions \(x^*\) and \(y^*\) satisfy: (1) \(y_i^* = 0\) if the \(i\)-th primal constraint is not tight, and (2) \(x_j^* = 0\) if the \(j\)-th dual constraint is not tight.
Proof of Strong Duality: Consider the Lagrangian \(L(x, y) = c^T x + y^T(b - Ax)\). The dual function is \(g(y) = \inf_x L(x, y)\). For feasible \(x\) and \(y\) with \(A^T y \leq c\), we have \(c^T x \geq y^T A x = y^T b\), establishing weak duality. Strong duality follows from the separating hyperplane theorem applied to convex sets in the constraint space.

Notation: The dual problem is: maximize \(b^T y\) subject to \(A^T y \leq c\). A constraint is tight (active) if equality holds at the optimum.

# Python: Linear Programming with scipy
import numpy as np
from scipy.optimize import linprog

def solve_lp_example():
    """
    Example: Maximize profit from producing two products.
    Product A: $40 profit, 2 hours labor, 1 unit material
    Product B: $30 profit, 1 hour labor, 1 unit material
    Constraints: 100 hours labor, 80 units material
    """
    # Objective: maximize 40A + 30B => minimize -40A - 30B
    c = [-40, -30]
    
    # Inequality constraints: Ax <= b
    # 2A + B <= 100 (labor)
    # A + B <= 80 (material)
    A_ub = [[2, 1], [1, 1]]
    b_ub = [100, 80]
    
    # Bounds: A, B >= 0
    bounds = [(0, None), (0, None)]
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    print("Linear Programming Solution:")
    print(f"Optimal production: A = {result.x[0]:.2f}, B = {result.x[1]:.2f}")
    print(f"Maximum profit: ${-result.fun:.2f}")
    print(f"Labor used: {2*result.x[0] + result.x[1]:.2f}/100 hours")
    print(f"Material used: {result.x[0] + result.x[1]:.2f}/80 units")
    
    return result

result = solve_lp_example()

1. The Nash Equilibrium in Game Theory

A Nash equilibrium is a set of strategies where no player can benefit by unilaterally changing their strategy. Named after John Nash, it is the central solution concept in non-cooperative game theory.

Theorem (Nash, 1950): Every finite game has at least one Nash equilibrium in mixed strategies.
Proof Sketch: Define the best response correspondence \(BR_i(s_{-i})\) for each player as the set of strategies that maximize their payoff given others' strategies. Consider the product correspondence \(BR(s) = BR_1(s_{-1}) \times \cdots \times BR_n(s_{-n})\). By Kakutani's fixed point theorem, this correspondence has a fixed point, which is a Nash equilibrium. Kakutani's theorem applies because: (1) the strategy space is compact and convex, (2) \(BR(s)\) is non-empty and convex, and (3) the graph is closed.

Notation: \(s_{-i}\) denotes the strategies of all players except \(i\). A mixed strategy is a probability distribution over pure strategies.

# Python: Computing Nash Equilibria
import numpy as np
from scipy.optimize import minimize

def compute_nash_equilibrium_2x2(A, B):
    """
    Compute Nash equilibrium for 2-player 2x2 game.
    A: payoff matrix for player 1
    B: payoff matrix for player 2
    Returns: (p, q) where p is row player strategy, q is column player strategy
    """
    # For 2x2 games, we can solve analytically
    # Player 1 plays row 1 with probability p
    # Player 2 plays column 1 with probability q
    
    # Player 1 is indifferent when expected payoffs are equal
    # p * A[0,0] + (1-p) * A[1,0] = p * A[0,1] + (1-p) * A[1,1]
    # Solving for q...
    
    # Check for pure strategy equilibria first
    equilibria = []
    
    # Check all pure strategy combinations
    for i in [0, 1]:
        for j in [0, 1]:
            # Is (i,j) a Nash equilibrium?
            # Player 1 shouldn't want to deviate
            payoff_1_current = A[i, j]
            payoff_1_deviate = A[1-i, j]
            
            # Player 2 shouldn't want to deviate
            payoff_2_current = B[i, j]
            payoff_2_deviate = B[i, 1-j]
            
            if payoff_1_current >= payoff_1_deviate and payoff_2_current >= payoff_2_deviate:
                p = 1.0 if i == 0 else 0.0
                q = 1.0 if j == 0 else 0.0
                equilibria.append((p, q, 'pure'))
    
    # Check for mixed strategy equilibrium
    # Player 1's indifference condition
    denom_q = (A[0,0] - A[0,1] - A[1,0] + A[1,1])
    if abs(denom_q) > 1e-10:
        q = (A[1,1] - A[1,0]) / denom_q
        if 0 < q < 1:
            # Player 2's indifference condition
            denom_p = (B[0,0] - B[1,0] - B[0,1] + B[1,1])
            if abs(denom_p) > 1e-10:
                p = (B[1,1] - B[0,1]) / denom_p
                if 0 < p < 1:
                    equilibria.append((p, q, 'mixed'))
    
    return equilibria

2. Knot Theory and the Jones Polynomial

Knot theory studies embeddings of circles in 3-dimensional space. The Jones polynomial, discovered by Vaughan Jones in 1984, is a powerful invariant that distinguishes many knots.

Theorem (Jones): There exists a unique polynomial invariant \(V_K(t)\) for oriented knots and links satisfying:
(1) \(V_{\text{unknot}}(t) = 1\)
(2) Skein relation: \(t^{-1}V_{L_+}(t) - tV_{L_-}(t) = (t^{1/2} - t^{-1/2})V_{L_0}(t)\)
Proof Sketch: The skein relation allows recursive computation by resolving crossings. Start with any diagram and repeatedly apply the relation to reduce the number of crossings. The process terminates because the unknot has no crossings. One must verify that the result is independent of the order of resolution (Reidemeister moves), which follows from checking invariance under the three Reidemeister moves.

Notation: \(L_+, L_-, L_0\) represent three links identical except at one crossing (positive, negative, and smoothed). The skein relation connects these three variants algebraically.

    """Convert Laurent polynomial coefficients to string."""

3. Ramsey Theory: Order from Chaos

Ramsey theory states that complete disorder is impossible. In any sufficiently large system, there must exist some ordered substructure.

Theorem (Ramsey's Theorem): For any positive integers \(r, s\), there exists a least integer \(R(r, s)\) such that any graph with at least \(R(r, s)\) vertices contains either a clique of size \(r\) or an independent set of size \(s\).
Theorem (Van der Waerden): For any positive integers \(k\) and \(r\), there exists some number \(N = W(k, r)\) such that if the integers \(\{1, 2, \ldots, N\}\) are colored with \(r\) colors, then there exists a monochromatic arithmetic progression of length \(k\).
Proof of Ramsey's Theorem (by induction): Base case: \(R(2, s) = s\) and \(R(r, 2) = r\). Inductive step: Show \(R(r, s) \leq R(r-1, s) + R(r, s-1)\). Consider a vertex \(v\) in a graph with \(R(r-1, s) + R(r, s-1)\) vertices. Either \(v\) has at least \(R(r-1, s)\) neighbors or at least \(R(r, s-1)\) non-neighbors. In the first case, the neighbors contain either a clique of size \(r-1\) (which with \(v\) makes \(r\)) or an independent set of size \(s\). The second case is symmetric.

Notation: \(R(r, s)\) is the Ramsey number. Known values include \(R(3, 3) = 6\) and \(R(4, 4) = 18\). \(R(5, 5)\) is unknown but between 43 and 48.

# Python: Ramsey Theory demonstrations
import numpy as np
import itertools

def find_monochromatic_triangle(graph, coloring):
    """
    Find a monochromatic triangle in an edge-colored graph.
    Returns the triangle if found, None otherwise.
    """
    n = len(graph)
    for i, j, k in itertools.combinations(range(n), 3):
        if graph[i][j] and graph[j][k] and graph[i][k]:
            # Check if triangle is monochromatic
            colors = {coloring[(min(i,j), max(i,j))],
                     coloring[(min(j,k), max(j,k))],
                     coloring[(min(i,k), max(i,k))]}
            if len(colors) == 1:
                return (i, j, k, colors.pop())
    return None

def find_arithmetic_progression(sequence, length):
    """Find arithmetic progression of given length in sequence."""
    n = len(sequence)
    for start in range(n):
        for diff in range(1, (n - start) // (length - 1) + 1):
            ap = [start + i * diff for i in range(length)]
            if all(ap[i] < n for i in range(length)):
                values = [sequence[i] for i in ap]
                if len(set(values)) == 1:  # Monochromatic
                    return ap, values[0]
    return None, None

4. The Banach-Tarski Paradox

The Banach-Tarski paradox states that a solid ball in 3D space can be decomposed into finitely many pieces and reassembled into two identical copies of the original ball.

Theorem (Banach-Tarski, 1924): Given a solid ball in \(\mathbb{R}^3\), there exists a decomposition of the ball into finitely many disjoint subsets which can be reassembled (using only rigid motions) into two identical copies of the original ball.
Proof Sketch: (1) Use the axiom of choice to select one representative from each orbit of the free group \(F_2\) acting on the sphere. (2) The group \(F_2\) (free group on 2 generators) can be paradoxically decomposed: there exist disjoint subsets \(A, B, C, D\) such that \(F_2 = A \cup B = C \cup D = A \cup C\) after appropriate group actions. (3) Transfer this paradox to the sphere using the group action. (4) Extend to the ball using radial decomposition. The key is that the pieces are non-measurable and cannot be physically constructed.

Notation: A free group \(F_2\) on generators \(a, b\) consists of all reduced words in \(a, b, a^{-1}, b^{-1}\). A decomposition is paradoxical if it can be rearranged to form two copies of the original set.

# Python: Exploring the free group F_2 and paradoxical decompositions
from collections import deque

def reduce_word(word):
    """Reduce a word in the free group by canceling inverse pairs."""
    stack = []
    for char in word:
        if stack and stack[-1] == inverse(char):
            stack.pop()
        else:
            stack.append(char)
    return ''.join(stack)

def inverse(char):
    """Return the inverse of a generator."""
    inv_map = {'a': 'A', 'A': 'a', 'b': 'B', 'B': 'b'}
    return inv_map[char]

def multiply_words(w1, w2):
    """Multiply two words in the free group."""
    return reduce_word(w1 + w2)
