Elliptic Curves: The Intersection of Algebra, Geometry, and Number Theory

elliptic-curves

Motivation

Elliptic curves are among the most fascinating objects in mathematics, appearing at the intersection of algebra, geometry, analysis, and number theory. An elliptic curve is a smooth cubic curve with a specified base point, and it carries a natural group structure that makes it both a geometric object and an algebraic one. The study of elliptic curves led to the proof of Fermat's Last Theorem, underlies modern cryptography, and contains some of the deepest open problems in mathematics, including the Birch and Swinnerton-Dyer conjecture.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point \(O\). Over a field \(K\) with char\((K) \neq 2, 3\), it can be written in Weierstrass form: \(y^2 = x^3 + ax + b\) with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Group Law: For points \(P, Q\) on an elliptic curve, define \(P + Q\) as the reflection of the third intersection point of line \(PQ\) with the curve, across the x-axis.
  • Point at Infinity: The base point \(O = [0:1:0]\) in projective coordinates, serving as the identity element.
  • j-invariant: \(j(E) = 1728 \frac{4a^3}{4a^3 + 27b^2}\), classifying elliptic curves up to isomorphism over algebraically closed fields.
  • Torsion Points: Points of finite order in the group structure; for an elliptic curve over \(\mathbb{Q}\), the torsion subgroup is finite (Mazur's theorem).

Theorem: The Group Structure of Elliptic Curves

Theorem (Poincaré, 1901): Let \(E\) be an elliptic curve defined over a field \(K\). The set of \(K\)-rational points \(E(K)\) forms an abelian group under the chord-tangent law, with the point at infinity as identity.

Theorem (Mordell-Weil): For an elliptic curve \(E\) over \(\mathbb{Q}\), the group \(E(\mathbb{Q})\) is finitely generated. That is:

\[E(\mathbb{Q}) \cong E(\mathbb{Q})_{\text{tors}} \times \mathbb{Z}^r\]

where \(E(\mathbb{Q})_{\text{tors}}\) is the finite torsion subgroup and \(r\) is the rank of \(E\).

Proof of Associativity Sketch

The associativity of the group law is non-trivial. One elegant proof uses the fact that elliptic curves are isomorphic to their Jacobian varieties. Alternatively, one can use the Riemann-Roch theorem: for points \(P, Q, R\) on \(E\), both \((P + Q) + R\) and \(P + (Q + R)\) are the unique point \(S\) such that there exists a rational function with divisor \((P) + (Q) + (R) - 3(O) - (S) + (O)\).

Notation Guide

  • \(E\): Elliptic curve
  • \(E(K)\): Set of \(K\)-rational points on \(E\)
  • \(O\) or \(\mathcal{O}\): Point at infinity (identity)
  • \([n]P\): The nth multiple of point \(P\) under the group law
  • \(E[n]\): n-torsion subgroup \(\{P \in E : [n]P = O\}\)
  • \(j(E)\): j-invariant of the curve
  • \(\Delta\): Discriminant (vanishes iff the curve is singular)

class EllipticCurvePoint:
    """Represents a point on an elliptic curve y^2 = x^3 + ax + b."""
    
    def __init__(self, x, y, a, b, infinity=False):
        self.x = x
        self.y = y
        self.a = a
        self.b = b
        self.infinity = infinity
        
        if not infinity:
            # Verify point is on curve
            assert y**2 == x**3 + a*x + b, "Point not on curve"
    
    def __add__(self, other):
        """Group law: chord-tangent method."""
        if self.infinity:
            return other
        if other.infinity:
            return self
        if self.x == other.x and self.y != other.y:
            return EllipticCurvePoint(None, None, self.a, self.b, infinity=True)
        
        # Calculate slope
        if self.x == other.x and self.y == other.y:
            # Point doubling: tangent line
            if self.y == 0:
                return EllipticCurvePoint(None, None, self.a, self.b, infinity=True)
            m = (3 * self.x**2 + self.a) / (2 * self.y)
        else:
            # Point addition: chord line
            m = (other.y - self.y) / (other.x - self.x)
        
        # Calculate new point
        x3 = m**2 - self.x - other.x
        y3 = m * (self.x - x3) - self.y
        
        return EllipticCurvePoint(x3, y3, self.a, self.b)
    
    def __rmul__(self, n):
        """Scalar multiplication using double-and-add."""
        result = EllipticCurvePoint(None, None, self.a, self.b, infinity=True)
        addend = self
        while n > 0:
            if n & 1:
                result = result + addend
            addend = addend + addend
            n >>= 1
        return result
    
    def __repr__(self):
        if self.infinity:
            return "O (point at infinity)"
        return f"({self.x:.4f}, {self.y:.4f})"

The Yoneda Lemma: Understanding Objects Through Their Relationships

category-theory

Motivation

How do we truly understand a mathematical object? The Yoneda lemma, one of the most profound results in category theory, tells us that an object is completely determined by its relationships to other objects. Rather than looking inside an object, we study the morphisms into or out of it. This perspective shift unifies concepts across algebra, topology, and geometry, and provides a powerful tool for translating between different mathematical worlds.

Definitions

  • Category: A collection of objects and morphisms (arrows) between them, with composition and identity morphisms satisfying associativity and identity laws.
  • Functor: A structure-preserving map between categories, taking objects to objects and morphisms to morphisms.
  • Natural Transformation: A morphism between functors; for functors \(F, G: \mathcal{C} \to \mathcal{D}\), a natural transformation \(\eta: F \Rightarrow G\) assigns to each object \(X\) a morphism \(\eta_X: F(X) \to G(X)\) such that all naturality squares commute.
  • Representable Functor: A functor \(F: \mathcal{C}^{op} \to \mathbf{Set}\) is representable if \(F \cong \text{Hom}(-, X)\) for some object \(X\).
  • Yoneda Embedding: The functor \(y: \mathcal{C} \to [\mathcal{C}^{op}, \mathbf{Set}]\) sending \(X \mapsto \text{Hom}(-, X)\).

Theorem: The Yoneda Lemma

Theorem (Yoneda, 1954): Let \(\mathcal{C}\) be a locally small category, \(F: \mathcal{C}^{op} \to \mathbf{Set}\) a functor, and \(X \in \mathcal{C}\) an object. Then there is a natural isomorphism:

\[\text{Nat}(\text{Hom}(-, X), F) \cong F(X)\]

Explicitly, natural transformations from the representable functor \(\text{Hom}(-, X)\) to \(F\) are in bijection with elements of \(F(X)\).

Corollary (Yoneda Embedding): The functor \(y: \mathcal{C} \to [\mathcal{C}^{op}, \mathbf{Set}]\) is fully faithful. Hence:

\[\text{Hom}(X, Y) \cong \text{Nat}(\text{Hom}(-, X), \text{Hom}(-, Y))\]

Proof Sketch

Given \(\alpha: \text{Hom}(-, X) \Rightarrow F\), evaluate at \(X\) to get \(\alpha_X: \text{Hom}(X, X) \to F(X)\). Map \(\alpha\) to \(\alpha_X(\text{id}_X) \in F(X)\).

Conversely, given \(u \in F(X)\), define \(\alpha_Y: \text{Hom}(Y, X) \to F(Y)\) by \(f \mapsto F(f)(u)\). Naturality follows from functoriality of \(F\).

These maps are inverse: starting with \(u\), we get \(\alpha\) with \(\alpha_X(\text{id}_X) = F(\text{id}_X)(u) = u\). Starting with \(\alpha\), naturality of \(\alpha\) ensures we recover the original transformation.

Notation Guide

  • \(\mathcal{C}\): A category
  • \(\mathcal{C}^{op}\): The opposite category (arrows reversed)
  • \(\text{Hom}(X, Y)\) or \(\mathcal{C}(X, Y)\): Set of morphisms from \(X\) to \(Y\)
  • \([\mathcal{C}, \mathcal{D}]\): Category of functors from \(\mathcal{C}\) to \(\mathcal{D}\)
  • \(\text{Nat}(F, G)\): Natural transformations from \(F\) to \(G\)
  • \(y(X) = \text{Hom}(-, X)\): Yoneda embedding
  • \(\Rightarrow\): Natural transformation between functors

We demonstrate how objects are determined by their "outgoing probes."

from typing import Callable, Dict, Any, Set
from dataclasses import dataclass
from functools import partial

@dataclass(frozen=True)
class Morphism:
    """Represents a morphism in a category."""
    source: str
    target: str
    name: str
    
    def compose(self, other: 'Morphism') -> 'Morphism':
        """Compose morphisms: self ∘ other (do other first, then self)."""
        if other.target != self.source:
            raise ValueError("Cannot compose: target mismatch")
        return Morphism(other.source, self.target, f"{self.name}∘{other.name}")

class MiniCategory:
    """A small category for demonstration."""
    
    def __init__(self):
        self.objects: Set[str] = set()
        self.morphisms: Dict[str, Morphism] = {}
        self.hom: Dict[tuple, Set[str]] = {}  # (A, B) -> set of morphism names
    
    def add_object(self, name: str):
        self.objects.add(name)
        self.hom[(name, name)] = self.hom.get((name, name), set())
        # Add identity
        id_morph = Morphism(name, name, f"id_{name}")
        self.morphisms[f"id_{name}"] = id_morph
        self.hom[(name, name)].add(f"id_{name}")
    
    def add_morphism(self, name: str, source: str, target: str):
        self.morphisms[name] = Morphism(source, target, name)
        key = (source, target)
        if key not in self.hom:
            self.hom[key] = set()
        self.hom[key].add(name)
    
    def hom_set(self, source: str, target: str) -> Set[str]:
        """Return all morphisms from source to target."""
        return self.hom.get((source, target), set())
    
    def representable_functor(self, X: str) -> Dict[str, Set[str]]:
        """
        Compute Hom(-, X): the contravariant representable functor at X.
        Returns a dict mapping each object Y to Hom(Y, X).
        """
        result = {}
        for Y in self.objects:
            result[Y] = self.hom_set(Y, X)
        return result
    
    def yoneda_check(self, X: str, Y: str) -> bool:
        """
        Verify Yoneda: Hom(X, Y) should correspond to 
        natural transformations Hom(-, X) => Hom(-, Y).
        For finite categories, we can enumerate and compare.
        """
        hom_XY = self.hom_set(X, Y)
        
        # The Yoneda embedding is fully faithful
        # |Hom(X, Y)| = |Nat(Hom(-,X), Hom(-,Y))|
        
        # For each f in Hom(X,Y), we get a natural transformation
        # by precomposition: Hom(Z, X) --f∘--> Hom(Z, Y)
        
        print(f"Yoneda check for objects {X} and {Y}:")
        print(f"  |Hom({X}, {Y})| = {len(hom_XY)}")
        
        # Each morphism f: X -> Y induces a natural transformation
        # α_Z: Hom(Z, X) -> Hom(Z, Y) given by g ↦ f ∘ g
        natural_transforms = []
        for f_name in hom_XY:
            f = self.morphisms[f_name]
            # Build the natural transformation
            components = {}
            for Z in self.objects:
                # Map Hom(Z, X) to Hom(Z, Y) by post-composition with f
                hom_ZX = self.hom_set(Z, X)
                hom_ZY = self.hom_set(Z, Y)
                component = {}
                for g_name in hom_ZX:
                    g = self.morphisms[g_name]
                    # f ∘ g: Z -> Y
                    fg_name = f"{f_name}∘{g_name}"
                    if fg_name in [m.name for m in self.morphisms.values()]:
                        component[g_name] = fg_name
                components[Z] = component
            natural_transforms.append((f_name, components))
        
        print(f"  Induced natural transformations: {len(natural_transforms)}")
        return len(natural_transforms) == len(hom_XY)

p-adic Analysis: Completing the Rationals Differently

number-theory

Motivation

The real numbers are constructed by completing the rationals with respect to the usual absolute value metric. But what if we use a different notion of distance? For each prime \(p\), the p-adic absolute value measures how divisible a number is by \(p\). Completing \(\mathbb{Q}\) with respect to this metric yields the p-adic numbers \(\mathbb{Q}_p\), a field with remarkable properties: every point in a p-adic disk is its center, triangles are isosceles, and series converge when their terms approach zero. p-adic analysis has profound applications in number theory, including the proof of Fermat's Last Theorem.

Definitions

  • p-adic Valuation: For \(n \in \mathbb{Z}\), \(v_p(n) = k\) where \(p^k \mid n\) but \(p^{k+1} \nmid n\). For \(x = a/b \in \mathbb{Q}\), \(v_p(x) = v_p(a) - v_p(b)\).
  • p-adic Absolute Value: \(|x|_p = p^{-v_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\). Satisfies the strong triangle inequality: \(|x + y|_p \leq \max(|x|_p, |y|_p)\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).
  • p-adic Integers \(\mathbb{Z}_p\): \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\} = \{x \in \mathbb{Q}_p : v_p(x) \geq 0\}\).
  • Ostrowski's Theorem: Every non-trivial absolute value on \(\mathbb{Q}\) is equivalent to either the usual absolute value or a p-adic absolute value.

Theorem: Hensel's Lemma

Theorem (Hensel's Lemma): Let \(f(x) \in \mathbb{Z}_p[x]\) be a polynomial. If there exists \(a_0 \in \mathbb{Z}_p\) such that:

\[|f(a_0)|_p < |f'(a_0)|_p^2\]

then there exists a unique \(a \in \mathbb{Z}_p\) such that \(f(a) = 0\) and \(|a - a_0|_p < |f'(a_0)|_p\).

Simple Form: If \(f(a_0) \equiv 0 \pmod{p}\) and \(f'(a_0) \not\equiv 0 \pmod{p}\), then there exists \(a \in \mathbb{Z}_p\) with \(a \equiv a_0 \pmod{p}\) and \(f(a) = 0\).

Proof Sketch

Construct a sequence by Newton's method: \(a_{n+1} = a_n - \frac{f(a_n)}{f'(a_n)}\). The condition ensures this is well-defined in \(\mathbb{Z}_p\) and converges. The strong triangle inequality shows \(|a_{n+1} - a_n|_p \to 0\), and since \(\mathbb{Q}_p\) is complete, the limit exists and satisfies \(f(a) = 0\).

Notation Guide

  • \(v_p(x)\): p-adic valuation of \(x\)
  • \(|x|_p = p^{-v_p(x)}\): p-adic absolute value
  • \(\mathbb{Q}_p\): Field of p-adic numbers
  • \(\mathbb{Z}_p\): Ring of p-adic integers (not to be confused with \(\mathbb{Z}/p\mathbb{Z}\))
  • \(\mathbb{Z}_p^\times\): Units in \(\mathbb{Z}_p\) (elements with \(|x|_p = 1\))
  • \(a + p^n\mathbb{Z}_p\): Closed ball of radius \(p^{-n}\) centered at \(a\)

from fractions import Fraction
import math

def padic_valuation(n: int, p: int) -> int:
    """Compute the p-adic valuation v_p(n) for integer n."""
    if n == 0:
        return float('inf')
    n = abs(n)
    k = 0
    while n % p == 0:
        n //= p
        k += 1
    return k

def padic_abs(x: Fraction, p: int) -> float:
    """Compute the p-adic absolute value |x|_p."""
    if x == 0:
        return 0.0
    num_val = padic_valuation(x.numerator, p)
    den_val = padic_valuation(x.denominator, p)
    return p ** (den_val - num_val)

def padic_expansion(x: Fraction, p: int, precision: int = 20) -> list:
    """
    Compute the p-adic expansion of a rational number.
    Returns coefficients [a_0, a_1, ..., a_n] where x = sum a_i * p^i
    with 0 <= a_i < p.
    """
    if x == 0:
        return [0]
    
    # Normalize to p-adic integer if possible
    v = padic_valuation(x.numerator, p) - padic_valuation(x.denominator, p)
    
    # Work with x * p^(-v) which is a unit
    x_normalized = x * (p ** (-v))
    
    coefficients = []
    current = Fraction(x_normalized)
    
    for _ in range(precision):
        # a_i = current mod p
        a_i = int(current) % p
        coefficients.append(a_i)
        current = (current - a_i) / p
        if current == 0:
            break
    
    return v, coefficients

Compressed Sensing: Recovering Signals from Few Measurements

compressed-sensing

Motivation

Traditional signal processing follows the Nyquist-Shannon sampling theorem: to recover a signal, you must sample at least twice its highest frequency. But what if the signal is sparse—mostly zeros in some basis? Compressed sensing, developed by Candès, Tao, and Romberg in the mid-2000s, shows that sparse signals can be recovered from far fewer measurements than Nyquist requires. This revolutionizes MRI imaging, where fewer scans mean faster diagnosis and less patient discomfort.

Definitions

  • Sparsity: A vector \(x \in \mathbb{R}^n\) is \(k\)-sparse if it has at most \(k\) non-zero entries. The sparsity is \(\|x\|_0 = |\{i : x_i \neq 0\}|\).
  • Measurement Matrix: An \(m \times n\) matrix \(\Phi\) with \(m \ll n\) that maps the signal to measurements \(y = \Phi x\).
  • Restricted Isometry Property (RIP): \(\Phi\) satisfies RIP of order \(k\) if there exists \(\delta_k \in (0,1)\) such that for all \(k\)-sparse \(x\): \[(1 - \delta_k)\|x\|_2^2 \leq \|\Phi x\|_2^2 \leq (1 + \delta_k)\|x\|_2^2\]
  • Basis Pursuit: The convex optimization \(\min \|x\|_1\) subject to \(\Phi x = y\), which recovers sparse solutions.
  • Coherence: \(\mu(\Phi) = \max_{i \neq j} |\langle \phi_i, \phi_j \rangle|\), measuring how similar the columns of \(\Phi\) are.

Theorem: Exact Recovery via Basis Pursuit

Theorem (Candès-Tao, 2005): Suppose \(\Phi\) satisfies RIP of order \(2k\) with \(\delta_{2k} < \sqrt{2} - 1\). Let \(x\) be \(k\)-sparse and \(y = \Phi x\). Then the solution \(\hat{x}\) to basis pursuit:

\[\hat{x} = \arg\min_{z} \|z\|_1 \quad \text{subject to} \quad \Phi z = y\]

satisfies \(\hat{x} = x\). That is, exact recovery is achieved.

Theorem (Noisy Case): If \(y = \Phi x + e\) with \(\|e\|_2 \leq \epsilon\), then the solution to:

\[\min \|z\|_1 \quad \text{s.t.} \quad \|\Phi z - y\|_2 \leq \epsilon\]

satisfies \(\|\hat{x} - x\|_2 \leq C \epsilon\) for some constant \(C\).

Notation Guide

  • \(\|x\|_0\): "\(\ell_0\) norm" (count of non-zeros, not actually a norm)

def basis_pursuit(Phi, y):
    """
    Solve min ||x||_1 subject to Phi @ x = y using linear programming.
    """
    m, n = Phi.shape
    
    # Convert to standard form: min c^T z subject to A z = b, z >= 0
    # x = u - v where u, v >= 0, so |x| = u + v
    # Variable: z = [u; v] in R^{2n}
    
    c = np.ones(2 * n)  # Minimize sum of u + v
    
    # Equality constraint: Phi(u - v) = y
    A_eq = np.hstack([Phi, -Phi])
    b_eq = y
    
    # Bounds: u, v >= 0
    bounds = [(0, None) for _ in range(2 * n)]
    
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if result.success:
        z = result.x
        x = z[:n] - z[n:]
        return x
    else:
        return None

def omp(Phi, y, k):
    """
    Orthogonal Matching Pursuit - greedy algorithm for sparse recovery.
    """
    m, n = Phi.shape
    residual = y.copy()
    support = []
    
    for _ in range(k):
        # Find column most correlated with residual
        correlations = np.abs(Phi.T @ residual)
        new_index = np.argmax(correlations)
        support.append(new_index)
        
        # Solve least squares on selected support
        Phi_S = Phi[:, support]
        x_S = np.linalg.lstsq(Phi_S, y, rcond=None)[0]
        
        # Update residual
        residual = y - Phi_S @ x_S
    
    # Build full solution
    x = np.zeros(n)
    x[support] = x_S
    return x, support

Optimal Transport: The Mathematics of Moving Mass

optimal-transport

Motivation

How do you efficiently move a pile of sand to fill a hole? This seemingly simple question, posed by Gaspard Monge in 1781, launched the field of optimal transport. The problem asks for the most cost-effective way to transform one probability distribution into another. After languishing for two centuries, optimal transport experienced a renaissance in the 1990s, finding applications in economics, fluid mechanics, machine learning (Wasserstein GANs), and even the study of Ricci curvature in metric measure spaces.

Definitions

  • Transport Plan: A coupling \(\gamma\) of probability measures \(\mu\) and \(\nu\) on spaces \(X\) and \(Y\), i.e., a measure on \(X \times Y\) with marginals \(\mu\) and \(\nu\).
  • Monge Problem: Minimize \(\int_X c(x, T(x)) d\mu(x)\) over transport maps \(T: X \to Y\) with \(T_\#\mu = \nu\).
  • Kantorovich Problem: Minimize \(\int_{X \times Y} c(x, y) d\gamma(x,y)\) over couplings \(\gamma \in \Pi(\mu, \nu)\).
  • Wasserstein Distance: For \(p \geq 1\), \(W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu,\nu)} \int |x-y|^p d\gamma\right)^{1/p}\).
  • c-concave Function: \(\varphi: X \to \mathbb{R}\) is c-concave if \(\varphi(x) = \inf_{y \in Y}(c(x,y) - \psi(y))\) for some \(\psi\).

Theorem: The Kantorovich Duality

Theorem (Kantorovich Duality): Let \(\mu, \nu\) be probability measures on Polish spaces \(X, Y\), and \(c: X \times Y \to [0, \infty]\) lower semicontinuous. Then:

\[\inf_{\gamma \in \Pi(\mu,\nu)} \int c \, d\gamma = \sup_{(\varphi, \psi) \in \Phi_c} \left(\int \varphi \, d\mu + \int \psi \, d\nu\right)\]

where \(\Phi_c = \{(\varphi, \psi) : \varphi(x) + \psi(y) \leq c(x,y)\}\).

Theorem (Brenier, 1987): When \(X = Y = \mathbb{R}^n\), \(c(x,y) = |x-y|^2/2\), and \(\mu\) is absolutely continuous, the optimal transport map exists, is unique, and has the form \(T = \nabla \varphi\) for a convex function \(\varphi\).

Proof Sketch (Duality)

The Kantorovich problem is a linear program in infinite dimensions. The dual variables \((\varphi, \psi)\) can be interpreted as prices: \(\varphi(x)\) is the price at source \(x\), \(\psi(y)\) is the price at destination \(y\). The constraint \(\varphi(x) + \psi(y) \leq c(x,y)\) ensures no arbitrage. Strong duality holds under mild conditions, and the optimal \(\gamma\) is supported on the set where \(\varphi(x) + \psi(y) = c(x,y)\).

Notation Guide

  • \(\Pi(\mu, \nu)\): Set of couplings (transport plans) between \(\mu\) and \(\nu\)
  • \(T_\#\mu\): Pushforward measure, \((T_\#\mu)(A) = \mu(T^{-1}(A))\)
  • \(W_p(\mu, \nu)\): p-Wasserstein distance
  • \(\mathcal{P}_p(X)\): Space of probability measures with finite p-th moment
  • \(\varphi^c(y) = \inf_x(c(x,y) - \varphi(x))\): c-transform of \(\varphi\)
  • \(\partial^c\varphi\): c-subdifferential of \(\varphi\)

import numpy as np
from scipy.optimize import linprog
from scipy.spatial.distance import cdist

def discrete_optimal_transport(mu, nu, C):
    """
    Solve the discrete optimal transport problem using linear programming.
    
    Parameters:
    -----------
    mu : array of shape (m,)
        Source distribution (sums to 1)
    nu : array of shape (n,)
        Target distribution (sums to 1)
    C : array of shape (m, n)
        Cost matrix, C[i,j] = cost of transporting from i to j
    
    Returns:
    --------
    gamma : array of shape (m, n)
        Optimal transport plan
    cost : float
        Total transport cost
    """
    m, n = C.shape
    
    # Flatten the problem: variable x represents vec(gamma)
    c = C.flatten()
    
    # Equality constraints: row sums = mu, column sums = nu
    # A_eq @ x = b_eq
    A_row = np.zeros((m, m * n))
    for i in range(m):
        A_row[i, i*n:(i+1)*n] = 1
    
    A_col = np.zeros((n, m * n))
    for j in range(n):
        A_col[j, j::n] = 1
    
    A_eq = np.vstack([A_row, A_col])
    b_eq = np.hstack([mu, nu])
    
    # Bounds: x >= 0
    bounds = [(0, None) for _ in range(m * n)]
    
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if result.success:
        gamma = result.x.reshape(m, n)
        cost = result.fun
        return gamma, cost
    else:
        return None, None

def wasserstein_distance_1d(mu_samples, nu_samples, p=1):
    """
    Compute 1D Wasserstein distance using sorting (very efficient).
    """
    mu_sorted = np.sort(mu_samples)
    nu_sorted = np.sort(nu_samples)
    
    # Empirical CDFs
    n = len(mu_samples)
    m = len(nu_samples)
    
    # For empirical measures, W_p^p = (1/n) sum |X_(i) - Y_(i)|^p
    # after sorting (for equal sample sizes)
    if n == m:
        return (np.sum(np.abs(mu_sorted - nu_sorted)**p) / n)**(1/p)
    else:
        # Use quantile matching
        quantiles = np.linspace(0, 1, max(n, m))
        mu_quantiles = np.interp(quantiles, np.linspace(0, 1, n), mu_sorted)
        nu_quantiles = np.interp(quantiles, np.linspace(0, 1, m), nu_sorted)
        return (np.mean(np.abs(mu_quantiles - nu_quantiles)**p))**(1/p)

def sinkhorn_knopp(mu, nu, C, reg=0.1, num_iter=1000):
    """
    Compute entropic-regularized OT using Sinkhorn-Knopp algorithm.
    Much faster than LP for large problems.
    """
    m, n = C.shape
    K = np.exp(-C / reg)
    
    u = np.ones(m)
    v = np.ones(n)
    
    for _ in range(num_iter):
        u = mu / (K @ v)
        v = nu / (K.T @ u)
    
    gamma = np.diag(u) @ K @ np.diag(v)
    cost = np.sum(gamma * C)
    return gamma, cost

Control Theory: Steering Dynamical Systems

control-theory

Motivation

How do you land a rocket, stabilize an aircraft, or regulate a chemical reactor? Control theory provides the mathematical framework for steering dynamical systems to desired states. From the steam governor of James Watt to modern autonomous vehicles, control theory bridges pure mathematics (differential equations, linear algebra, optimization) with engineering practice. The field addresses fundamental questions: Is the system controllable? Can we stabilize it? What's the optimal control strategy?

Definitions

  • State-Space System: \(\dot{x} = Ax + Bu\) (linear time-invariant), where \(x \in \mathbb{R}^n\) is the state, \(u \in \mathbb{R}^m\) is the control input, \(A\) is the system matrix, and \(B\) is the input matrix.
  • Controllability: The system is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists a control \(u(t)\) that drives the system from \(x_0\) to \(x_f\) in finite time.
  • Controllability Matrix: \(\mathcal{C} = [B \, AB \, A^2B \, \cdots \, A^{n-1}B]\).
  • Observability: The ability to determine the internal state from output measurements \(y = Cx + Du\).
  • Stabilizability: All unstable modes are controllable (can be stabilized by feedback).

Theorem: The Kalman Controllability Criterion

Theorem (Kalman, 1960): The linear system \(\dot{x} = Ax + Bu\) is controllable if and only if the controllability matrix has full rank:

\[\text{rank}([B \, AB \, A^2B \, \cdots \, A^{n-1}B]) = n\]

Theorem (Pole Placement): If \((A, B)\) is controllable, then for any set of \(n\) complex numbers \(\{\lambda_1, \ldots, \lambda_n\}\) closed under conjugation, there exists a feedback matrix \(K\) such that \(A - BK\) has eigenvalues \(\{\lambda_1, \ldots, \lambda_n\}\).

Theorem (LQR Optimal Control): For the system \(\dot{x} = Ax + Bu\) with cost \(J = \int_0^\infty (x^T Q x + u^T R u) dt\), the optimal control is \(u = -Kx\) where \(K = R^{-1}B^T P\) and \(P\) satisfies the Algebraic Riccati Equation:

\[A^T P + PA - PBR^{-1}B^T P + Q = 0\]

Proof Sketch (Controllability)

The solution to \(\dot{x} = Ax + Bu\) with \(x(0) = x_0\) is:

\[x(t) = e^{At}x_0 + \int_0^t e^{A(t-\tau)}Bu(\tau)d\tau\]

By the Cayley-Hamilton theorem, \(e^{At}\) can be expressed as a linear combination of \(\{I, A, \ldots, A^{n-1}\}\). Thus the reachable set is the column space of \(\mathcal{C}\). Full rank means any state is reachable.

Notation Guide

  • \(x \in \mathbb{R}^n\): State vector
  • \(u \in \mathbb{R}^m\): Control input vector
  • \(y \in \mathbb{R}^p\): Output/measurement vector
  • \(A \in \mathbb{R}^{n \times n}\): System dynamics matrix
  • \(B \in \mathbb{R}^{n \times m}\): Input matrix
  • \(C \in \mathbb{R}^{p \times n}\): Output matrix
  • \(\mathcal{C}\): Controllability matrix
  • \(\mathcal{O}\): Observability matrix \([C^T, (CA)^T, \ldots]^T\)

from scipy.linalg import solve_continuous_are, eig, expm

def controllability_matrix(A, B):
    """Compute the controllability matrix [B, AB, A^2B, ..., A^(n-1)B]."""
    n = A.shape[0]
    C = B
    for i in range(1, n):
        C = np.hstack([C, np.linalg.matrix_power(A, i) @ B])
    return C

def is_controllable(A, B):
    """Check if (A, B) is controllable using Kalman rank condition."""
    C = controllability_matrix(A, B)
    return np.linalg.matrix_rank(C) == A.shape[0]

def lqr_controller(A, B, Q, R):
    """
    Solve the continuous-time LQR problem.
    Returns the optimal gain matrix K.
    """
    # Solve the Algebraic Riccati Equation
    P = solve_continuous_are(A, B, Q, R)
    # Compute optimal gain
    K = np.linalg.inv(R) @ B.T @ P
    return K, P

def place_poles(A, B, desired_poles):
    """
    Place poles at desired locations using Ackermann's formula
    (simplified version for single input).
    """
    n = A.shape[0]
    C = controllability_matrix(A, B)
    
    # Check controllability
    if np.linalg.matrix_rank(C) < n:
        raise ValueError("System is not controllable")
    
    # Compute desired characteristic polynomial
    desired_char_poly = np.poly(desired_poles)
    
    # Ackermann's formula: K = [0, ..., 0, 1] * C^(-1) * phi(A)
    # where phi is the desired characteristic polynomial
    phi_A = np.zeros((n, n))
    for i, coeff in enumerate(desired_char_poly[1:]):  # Skip leading 1
        phi_A += coeff * np.linalg.matrix_power(A, n - 1 - i)
    phi_A += np.linalg.matrix_power(A, n)
    
    K = np.zeros((B.shape[1], n))
    e_n = np.zeros(n)
    e_n[-1] = 1
    K = e_n @ np.linalg.inv(C) @ phi_A
    
    return K

Surreal Numbers: A Universe of Numbers

surreal-numbers

Historical Context

In the early 1970s, mathematician John Conway discovered a vast number system while analyzing combinatorial games. Donald Knuth dubbed them "surreal numbers" in his 1974 novella, and the name stuck. The surreal numbers form a proper class (larger than any set) that contains all real numbers, all ordinal numbers, and infinitely many quantities in between. They provide the most complete ordered field ever discovered—every ordered field embeds into the surreals.

Definitions

  • Surreal Number: Defined recursively as \(x = \{X_L | X_R\}\) where \(X_L\) and \(X_R\) are sets of previously constructed surreals, with every element of \(X_L\) less than every element of \(X_R\).
  • Comparison: \(x \leq y\) iff no \(x_R \leq y\) and \(x \leq\) no \(y_L\).
  • Addition: \(x + y = \{X_L + y, x + Y_L | X_R + y, x + Y_R\}\).
  • Multiplication: Defined recursively using the formula for \((x - x_L)(y - y_L)\) etc.
  • Birthday: The ordinal at which a surreal number is created; \(\mathbf{On}\) denotes the class of all ordinals.

Theorem: The Surreal Numbers Form a Real Closed Field

Theorem (Conway): The class of surreal numbers \(\mathbf{No}\) with the operations of addition and multiplication forms a real closed field. Specifically:

  1. \(\mathbf{No}\) is an ordered field.
  2. Every positive surreal has a square root in \(\mathbf{No}\).
  3. Every odd-degree polynomial over \(\mathbf{No}\) has a root in \(\mathbf{No}\).
  4. \(\mathbf{No}\) contains all real numbers and all ordinal numbers.

Theorem (Universality): Every ordered field embeds into \(\mathbf{No}\). Moreover, \(\mathbf{No}\) is the unique (up to isomorphism) homogeneous universal ordered field of cardinality \(\mathbf{On}\).

Notation Guide

  • \(\mathbf{No}\): The class of surreal numbers
  • \(\{L | R\}\): Surreal number with left set \(L\) and right set \(R\)
  • \(x^L, x^R\): Typical elements of left and right sets of \(x\)
  • \(\omega\): The first infinite surreal (birthday \(\omega\))
  • \(\varepsilon = \omega^{-1} = \{0 | 1, 1/2, 1/4, \ldots\}\): An infinitesimal
  • \(\mathbf{On}\): The class of ordinal numbers

class Surreal:
    """
    A simplified implementation of surreal numbers.
    For practical computation, we work with dyadic rationals and simple infinities.
    """
    
    def __init__(self, left: Set['Surreal'], right: Set['Surreal'], name: str = ""):
        self.left = frozenset(left)
        self.right = frozenset(right)
        self.name = name
        self._value = None  # For simple cases, store the real value
    
    def __le__(self, other: 'Surreal') -> bool:
        """x <= y iff no x_R <= y and x <= no y_L."""
        for xR in self.right:
            if xR <= other:
                return False
        for yL in other.left:
            if self <= yL:
                return False
        return True
    
    def __lt__(self, other: 'Surreal') -> bool:
        return self <= other and not (other <= self)
    
    def __eq__(self, other) -> bool:
        if not isinstance(other, Surreal):
            return False
        return self <= other and other <= self
    
    def __hash__(self):
        return hash((self.left, self.right))
    
    def __repr__(self):
        if self.name:
            return self.name
        left_str = ", ".join(str(x) for x in self.left) if self.left else ""
        right_str = ", ".join(str(x) for x in self.right) if self.right else ""
        return f"{{{left_str}|{right_str}}}"
    
    def __add__(self, other: 'Surreal') -> 'Surreal':
        """x + y = {x^L + y, x + y^L | x^R + y, x + y^R}."""
        new_left = set()
        new_right = set()
        
        for xL in self.left:
            new_left.add(xL + other)
        for yL in other.left:
            new_left.add(self + yL)
        for xR in self.right:
            new_right.add(xR + other)
        for yR in other.right:
            new_right.add(self + yR)
        
        return Surreal(new_left, new_right)
    
    def __neg__(self) -> 'Surreal':
        """Negation: -{L|R} = {-R|-L}."""
        return Surreal({-x for x in self.right}, {-x for x in self.left})
    
    def __sub__(self, other: 'Surreal') -> 'Surreal':

Tropical Geometry: The Geometry of the Minimum

tropical-geometry

Historical Context

Tropical geometry emerged in the 1980s from the work of Brazilian mathematician Imre Simon (hence "tropical"—a nod to Brazil) and independently in the Soviet Union. The field studies algebraic varieties over the tropical semiring, where addition is replaced by minimum (or maximum) and multiplication by addition. Surprisingly, this degenerate limit of classical algebraic geometry preserves rich combinatorial structures and connects to diverse areas: enumerative geometry, optimization, phylogenetics, and even economics. Tropical geometry provides a piecewise-linear shadow of algebraic geometry that is often easier to compute while retaining essential information.

Definitions

  • Tropical Semiring \(\mathbb{T}\): \(\mathbb{R} \cup \{\infty\}\) with operations \(a \oplus b = \min(a, b)\) and \(a \odot b = a + b\). The additive identity is \(\infty\), multiplicative identity is \(0\).
  • Tropical Polynomial: A function of the form \(f(x) = \bigoplus_{i} (a_i \odot x^{\odot i}) = \min_i(a_i + i \cdot x)\).
  • Tropical Hypersurface: The set where a tropical polynomial is not linear (achieved by at least two terms simultaneously).
  • Amoeba: The image of an algebraic variety under the log-absolute map \(\text{Log}: (\mathbb{C}^*)^n \to \mathbb{R}^n\), \(\text{Log}(z_1, \ldots, z_n) = (\log|z_1|, \ldots, \log|z_n|)\).
  • Tropical Limit: As \(t \to \infty\), the amoeba of \(\{f_t = 0\}\) converges to the tropical variety, where \(f_t = \sum_i a_i t^{b_i} z^i\).

Theorem: The Fundamental Theorem of Tropical Geometry

Theorem (Kapranov, 2000): Let \(K\) be an algebraically closed field with non-Archimedean valuation \(\text{val}: K^* \to \mathbb{R}\). For a polynomial \(f = \sum_{\alpha} c_\alpha x^\alpha \in K[x_1, \ldots, x_n]\), define its tropicalization:

\[\text{trop}(f)(w) = \min_\alpha(\text{val}(c_\alpha) + \alpha \cdot w)\]

Then the tropical hypersurface equals:

\[\text{trop}(V(f)) = \{w \in \mathbb{R}^n : \text{trop}(f)(w) \text{ is achieved by at least two terms}\}\]

Theorem (Structure): Tropical varieties are finite unions of polyhedra forming polyhedral complexes. They are connected in codimension 1 and satisfy a balancing condition at each codimension-1 face.

Notation Guide

  • \(\mathbb{T}\) or \(\mathbb{T}\mathbb{R}\): Tropical semiring
  • \(\oplus\): Tropical addition (minimum)
  • \(\odot\): Tropical multiplication (usual addition)
  • \(x^{\odot n} = n \cdot x\): Tropical exponentiation
  • \(\text{trop}(V)\): Tropicalization of variety \(V\)
  • \(\text{val}\): Non-Archimedean valuation
  • \(\mathcal{A}_t\): Amoeba with base \(t\)

Ramsey Theory: Finding Order in Chaos

ramsey-theory

Historical Context

In 1928, Frank Ramsey proved a theorem about logical systems that had a surprising combinatorial consequence: complete disorder is impossible. No matter how you color the edges of a large enough complete graph, you cannot avoid creating monochromatic cliques. This launched Ramsey theory, which studies conditions under which order must appear. The field has grown to encompass graph theory, number theory, geometry, and logic. Its famous results include van der Waerden's theorem on arithmetic progressions, the Hales-Jewett theorem, and Szemerédi's theorem—each asserting that structure is unavoidable in sufficiently large configurations.

Definitions

  • Ramsey Number \(R(s, t)\): The smallest \(n\) such that every red-blue coloring of edges of \(K_n\) contains a red \(K_s\) or a blue \(K_t\).
  • Graph Ramsey Number \(R(G, H)\): The smallest \(n\) such that any red-blue coloring of \(K_n\) contains a red copy of \(G\) or a blue copy of \(H\).
  • Hypergraph Ramsey Number: Generalization to uniform hypergraphs (edges are \(r\)-tuples of vertices).
  • Van der Waerden Number \(W(k, r)\): The smallest \(n\) such that any \(r\)-coloring of \(\{1, \ldots, n\}\) contains a monochromatic arithmetic progression of length \(k\).
  • Szemerédi's Regularity Lemma: Any large graph can be partitioned into a bounded number of quasi-random bipartite graphs.

Theorem: Ramsey's Theorem

Theorem (Ramsey, 1930): For any positive integers \(s, t \geq 2\), there exists a least positive integer \(R(s, t)\) such that every red-blue edge coloring of the complete graph on \(R(s, t)\) vertices contains either a red \(K_s\) or a blue \(K_t\).

Bounds: For diagonal Ramsey numbers \(R(s) = R(s, s)\):

\[\frac{s}{e\sqrt{2}} \cdot 2^{s/2} < R(s) < 4^{s-1}\]

Theorem (Van der Waerden, 1927): For any positive integers \(k\) and \(r\), there exists a least integer \(W(k, r)\) such that any coloring of \(\{1, 2, \ldots, W(k, r)\}\) with \(r\) colors contains a monochromatic arithmetic progression of length \(k\).

Theorem (Szemerédi, 1975): Any subset of integers with positive upper density contains arbitrarily long arithmetic progressions.

Proof of Ramsey's Theorem (Inductive)

Base case: \(R(2, t) = t\) and \(R(s, 2) = s\) are trivial.

Inductive step: Show \(R(s, t) \leq R(s-1, t) + R(s, t-1)\).

Consider any vertex \(v\) in a 2-colored \(K_n\) with \(n = R(s-1, t) + R(s, t-1)\). Either \(v\) has at least \(R(s-1, t)\) red neighbors or at least \(R(s, t-1)\) blue neighbors (pigeonhole principle). In the first case, the red neighbors contain a red \(K_{s-1}\) (giving red \(K_s\) with \(v\)) or a blue \(K_t\). The second case is symmetric.

Notation Guide

  • \(R(s, t)\): Ramsey number for red \(K_s\) or blue \(K_t\)
  • \(K_n\): Complete graph on \(n\) vertices
  • \(W(k, r)\): Van der Waerden number for AP of length \(k\) with \(r\) colors
  • \(r_k(n)\): Largest subset of \(\{1, \ldots, n\}\) with no \(k\)-term AP
  • \(K_{r}^{(s)}\): Complete \(s\)-uniform hypergraph on \(r\) vertices
  • \(R^{(s)}(t_1, \ldots, t_k)\): Hypergraph Ramsey number

def ramsey_bound_simple(s, t):
    """
    Compute the simple upper bound: R(s,t) <= R(s-1,t) + R(s,t-1).
    Base cases: R(2,t) = t, R(s,2) = s.
    """
    # Memoization
    memo = {}
    
    def R(s, t):
        if s == 2:
            return t
        if t == 2:
            return s
        if (s, t) in memo:
            return memo[(s, t)]
        
        result = R(s - 1, t) + R(s, t - 1)

        return result
    
    return R(s, t)

def find_monochromatic_clique(adj_matrix, color, k):
    """
    Find a monochromatic k-clique of given color in the coloring.
    adj_matrix[i][j] = 0 (red) or 1 (blue) for i < j.
    Returns the clique vertices or None.
    """
    n = len(adj_matrix)
    
    # Check all subsets of size k
    for subset in itertools.combinations(range(n), k):
        is_clique = True
        for i, j in itertools.combinations(subset, 2):
            u, v = min(i, j), max(i, j)
            if adj_matrix[u][v] != color:
                is_clique = False
                break
        if is_clique:
            return list(subset)
    return None

            ap = [start + i * diff for i in range(k)]
            if all(idx < n for idx in ap):
                return ap
    return None

The Jones Polynomial: Knot Theory Meets Physics

knot-theory

Historical Context

In 1984, Vaughan Jones made a discovery that revolutionized knot theory and earned him the Fields Medal. While studying operator algebras (von Neumann algebras), Jones stumbled upon a new polynomial invariant of knots and links. Unlike the classical Alexander polynomial discovered in the 1920s, the Jones polynomial could distinguish a knot from its mirror image and detected subtle chirality properties. The discovery sparked connections between knot theory, statistical mechanics, quantum field theory, and quantum computing. The Jones polynomial was later understood through quantum groups and topological quantum field theory, exemplifying the deep unity of mathematics and physics.

Definitions

  • Knot: An embedding of \(S^1\) into \(\mathbb{R}^3\) or \(S^3\). A link is a disjoint union of knots.
  • Knot Diagram: A planar projection of a knot with crossing information (over/under).
  • Reidemeister Moves: Three local moves that generate all ambient isotopies of knots.
  • Kauffman Bracket \(\langle D \rangle\): A Laurent polynomial defined on link diagrams by: \(\langle \bigcirc \rangle = 1\), \(\langle D \cup \bigcirc \rangle = (-A^2 - A^{-2})\langle D \rangle\), and skein relations at crossings.
  • Jones Polynomial \(V_K(t)\): Obtained from the Kauffman bracket by normalization and the substitution \(A = t^{-1/4}\).

Theorem: The Jones Polynomial is a Knot Invariant

Theorem (Jones, 1984): There exists a unique invariant \(V_L(t)\) of oriented links satisfying:

  1. \(V_{\text{unknot}}(t) = 1\)
  2. The skein relation: \(t^{-1}V_{L_+}(t) - tV_{L_-}(t) = (t^{1/2} - t^{-1/2})V_{L_0}(t)\)

where \(L_+, L_-, L_0\) are links differing at a single crossing as shown:

\[L_+ = \begin{array}{c} \nearrow \nwarrow \\ \searrow \swarrow \end{array}, \quad L_- = \begin{array}{c} \nwarrow \nearrow \\ \swarrow \searrow \end{array}, \quad L_0 = \begin{array}{c} | \quad | \\ | \quad | \end{array}\]

Theorem (Kauffman, 1987): The Jones polynomial can be computed via the Kauffman bracket:

\[V_K(t) = ((-A)^{-3w(D)}\langle D \rangle)|_{A = t^{-1/4}}\]

where \(w(D)\) is the writhe of the diagram.

Proof Sketch (Invariance)

The Kauffman bracket is invariant under Reidemeister moves II and III but not I. The writhe transforms predictably under Reidemeister I, and the factor \((-A)^{-3w(D)}\) exactly compensates. Since Reidemeister moves generate knot isotopy, the normalized bracket (the Jones polynomial) is a knot invariant.

Notation Guide

  • \(V_K(t)\): Jones polynomial of knot \(K\)
  • \(\langle D \rangle\): Kauffman bracket of diagram \(D\)
  • \(w(D)\): Writhe (signed crossing number) of oriented diagram
  • \(A\): Variable in Kauffman bracket (related to \(t\) by \(A = t^{-1/4}\))
  • \(d = -A^2 - A^{-2}\): Loop value in bracket polynomial
  • \(\Delta_K(t)\): Alexander polynomial (classical invariant)

The Birth of Modern Algebra: Évariste Galois and the Theory of Equations

In the early hours of May 30, 1832, a young Frenchman named Évariste Galois was shot in a duel. He died the next day at age 20, leaving behind mathematical papers that would revolutionize algebra and earn him recognition as one of the most original mathematicians in history.

Galois's story is the stuff of legend: a brilliant but troubled youth, expelled from school, imprisoned for republican activities, and killed in a duel whose circumstances remain mysterious (possibly over a woman, possibly politically motivated). But the true drama lies in his mathematics.

The central problem of algebra in Galois's time was the solvability of polynomial equations. We learn in school that quadratic equations \(ax^2 + bx + c = 0\) have solutions given by the quadratic formula. In the 16th century, Italian mathematicians discovered similar formulas for cubic and quartic equations. But for two centuries, the quintic equation resisted all attempts at solution.

Galois's insight was to study not the solutions themselves, but the symmetries among them. To a polynomial equation, he associated a group—now called the Galois group—consisting of all permutations of the roots that preserve algebraic relations. He proved that the equation is solvable by radicals (using only addition, subtraction, multiplication, division, and root extraction) if and only if this group has a special structure: it must be a "solvable" group.

The general quintic has Galois group \(S_5\), the symmetric group on 5 elements. Galois showed that \(S_5\) is not solvable—its composition factors include the simple group \(A_5\), which has no nontrivial normal subgroups. Therefore, there can be no general formula for solving quintic equations by radicals.

Galois submitted his work to the Paris Academy of Sciences twice. The first memoir was lost by Cauchy. The second was misplaced by Fourier, who died shortly after receiving it. A third version reached Poisson, who returned it as "incomprehensible." The night before the duel, knowing he might die, Galois wrote a letter to his friend Auguste Chevalier, summarizing his ideas and asking that they be published.

His wish was granted. Liouville published Galois's papers in 1846, and the mathematical world slowly grasped their significance. Group theory was born. The abstract study of symmetry, structure, and algebraic systems that characterizes modern algebra all traces back to that desperate night in 1832.

Today, Galois theory stands as a cornerstone of abstract algebra, connecting field theory, group theory, and the theory of equations. It has applications in cryptography, coding theory, and algebraic geometry. The very notion of a "group"—perhaps the most important structure in all of mathematics—emerged from Galois's attempt to understand when polynomial equations can be solved.

Galois's life reminds us that mathematics is a human endeavor, driven by passion, tragedy, and the relentless pursuit of understanding. His legacy lives on every time a student learns that there is no quintic formula—and discovers the beautiful theory that explains why.

IMO Shortlist Problem: Geometry

Problem: Let \(ABC\) be an acute triangle with circumcircle \(\Gamma\). Let \(D\) and \(E\) be points on segments \(AB\) and \(AC\) respectively such that \(BD = CE\). Let \(P\) be the second intersection point of the circumcircles of triangles \(ADE\) and \(ABC\). Prove that \(P\) lies on the perpendicular bisector of segment \(DE\).

Hint

Consider the spiral similarity centered at \(P\) that sends \(B\) to \(C\). Show that this spiral similarity also sends \(D\) to \(E\). What does this imply about the distances \(PD\) and \(PE\)?

Solution

Since \(P\) lies on both circumcircles, we have:

\[\angle APD = \angle AED \quad \text{and} \quad \angle APB = \angle ACB\]

From the cyclic quadrilateral \(ADPE\), the spiral similarity at \(P\) sending \(D\) to \(E\) also sends \(A\) to a point on line \(AE\). Similarly, from cyclic quadrilateral \(ABPC\), the spiral similarity at \(P\) sending \(B\) to \(C\) sends \(A\) to a point on line \(AC\).

Since \(BD = CE\), and the spiral similarities have the same angle (both equal to \(\angle APB = \angle ACB\)), the ratio of the spiral similarity sending \(B\) to \(C\) equals the ratio sending \(D\) to \(E\).

Therefore, the same spiral similarity centered at \(P\) sends \(B\) to \(C\) and \(D\) to \(E\). This means:

\[\frac{PB}{PC} = \frac{PD}{PE} \quad \text{and} \quad \angle BPD = \angle CPE\]

From the spiral similarity, triangles \(PBD\) and \(PCE\) are similar (SAS similarity: \(PB/PC = PD/PE\) and \(\angle BPD = \angle CPE\)).

Since \(BD = CE\) by hypothesis, the similarity ratio gives us \(PD = PE\).

Therefore, \(P\) lies on the perpendicular bisector of \(DE\). ∎

The Mandelbrot set is one of the most famous mathematical objects, discovered by Benoit Mandelbrot in 1980. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate patterns, self-similar structures, and miniature copies of the whole set. The visualization below demonstrates how to render the Mandelbrot set, coloring points based on how quickly they escape to infinity.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until escape for a given complex number c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            # Smooth coloring using log-log scale
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(2)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[mask] = max_iter
    return M
