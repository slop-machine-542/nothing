Modular Forms: The Symmetry of Lattices

modular-forms

Motivation

Modular forms are complex-analytic functions with remarkable symmetry properties that encode deep arithmetic information. They emerged from the study of elliptic functions in the 19th century and have become central to modern number theory, connecting to Fermat's Last Theorem, the Langlands program, and string theory.

Definitions

  • Modular Group: \\(\\Gamma = \\text{SL}_2(\\mathbb{Z})\\)
  • Upper Half-Plane: \\(\\mathbb{H} = \\{z \\in \\mathbb{C} : \\text{Im}(z) > 0\\}\\)
  • Modular Form of Weight \\(k\\): A holomorphic function \\(f: \\mathbb{H} \\to \\mathbb{C}\\) satisfying \\(f(\\gamma z) = (cz+d)^k f(z)\\) for all \\(\\gamma \\in \\Gamma\\).
  • \\(q\\)-expansion: \\(f(z) = \\sum_{n=0}^{\\infty} a_n q^n\\) where \\(q = e^{2\\pi i z}\\).

Theorem: The Dimension Formula

Theorem: Let \\(M_k(\\Gamma)\\) denote the space of modular forms of weight \\(k\\). Then:

\\[\\dim_{\\mathbb{C}} M_k(\\Gamma) = \\begin{cases} \\lfloor k/12 \\rfloor & \\text{if } k \\equiv 2 \\pmod{12} \\\\ \\lfloor k/12 \\rfloor + 1 & \\text{otherwise} \\end{cases}\\]

Notation Guide

  • \\(\\Gamma\\) — the modular group
  • \\(\\mathbb{H}\\) — upper half-plane
  • \\(M_k(\\Gamma)\\) — space of modular forms of weight \\(k\\)
  • \\(S_k(\\Gamma)\\) — subspace of cusp forms
  • \\(E_k\\) — Eisenstein series of weight \\(k\\)
  • \\(\\Delta\\) — modular discriminant

import numpy as np

def sigma_k(n, k):
    """Compute sum of k-th powers of divisors of n."""
    return sum(d**k for d in range(1, n+1) if n % d == 0)

def eisenstein_series_4(z, terms=20):
    """Compute E_4(z) = 1 + 240 * sum_{n>=1} sigma_3(n) * q^n."""
    q = np.exp(2j * np.pi * z)
    result = 1.0
    for n in range(1, terms + 1):
        result += 240 * sigma_k(n, 3) * (q ** n)
    return result

Riemann Surfaces: One-Dimensional Complex Manifolds

riemann-surfaces

Motivation

Riemann surfaces provide the geometric foundation for complex analysis. Introduced by Bernhard Riemann in 1851, they unify the theory of multi-valued complex functions and provide the natural domain for studying algebraic curves and complex dynamics.

Definitions

  • Riemann Surface: A one-dimensional complex manifold: a Hausdorff space \\(X\\) with holomorphic transition maps.
  • Holomorphic Map: A continuous map \\(f: X \\to Y\\) with holomorphic local representations.
  • Genus: The number of "holes" in a compact Riemann surface.
  • Meromorphic Function: A holomorphic map \\(f: X \\to \\mathbb{C} \\cup \\{\\infty\\}\\).

Theorem: Riemann-Roch Theorem

Theorem (Riemann-Roch): Let \\(X\\) be a compact Riemann surface of genus \\(g\\), and let \\(D\\) be a divisor on \\(X\\). Then:

\\[\\ell(D) - \\ell(K - D) = \\deg(D) + 1 - g\\]

Notation Guide

  • \\(X\\) — Riemann surface
  • \\(g\\) — genus of the surface
  • \\(\\mathcal{O}_X\\) — sheaf of holomorphic functions
  • \\(K\\) — canonical divisor
  • \\(\\ell(D) = \\dim H^0(X, \\mathcal{O}_X(D))\\)

Hodge Theory: Harmonic Forms on Manifolds

hodge-theory

Motivation

Hodge theory, developed by W.V.D. Hodge in the 1930s, provides a profound connection between analysis, topology, and algebraic geometry on complex manifolds. It shows that the topology of a compact Kähler manifold is constrained by its complex structure.

Definitions

  • Riemannian Metric: A smooth inner product \\(g\\) on the tangent bundle.
  • Hodge Star: An operator \\(\\star: \\Omega^k(M) \\to \\Omega^{n-k}(M)\\).
  • Codifferential: \\(d^* = (-1)^{n(k+1)+1} \\star d \\star\\).
  • Laplacian: \\(\\Delta = dd^* + d^*d\\).
  • Harmonic Form: A form \\(\\alpha\\) with \\(\\Delta \\alpha = 0\\).

Theorem: Hodge Decomposition

Theorem (Hodge): Let \\(M\\) be a compact oriented Riemannian manifold. Then:

\\[\\Omega^k(M) = \\mathcal{H}^k(M) \\oplus d(\\Omega^{k-1}(M)) \\oplus d^*(\\Omega^{k+1}(M))\\]

Consequently: \\(H^k_{\\text{dR}}(M) \\cong \\mathcal{H}^k(M)\\).

Notation Guide

  • \\(\\Omega^k(M)\\) — space of smooth \\(k\\)-forms
  • \\(\\mathcal{H}^k(M)\\) — space of harmonic \\(k\\)-forms
  • \\(H^k_{\\text{dR}}(M)\\) — \\(k\\)-th de Rham cohomology
  • \\(\\star\\) — Hodge star operator
  • \\(\\Delta\\) — Laplace-de Rham operator

Python Code

import numpy as np

def discrete_laplacian_1d(n):
    """Construct discrete Laplacian on a circle."""
    main_diag = 2 * np.ones(n)
    off_diag = -np.ones(n-1)
    L = np.diag(main_diag) + np.diag(off_diag, 1) + np.diag(off_diag, -1)
    L[0, -1] = L[-1, 0] = -1
    return L

def hodge_theory_demo():
    """Demonstrate Hodge theory on S^1."""
    n = 100
    L = discrete_laplacian_1d(n)
    eigenvalues, eigenvectors = np.linalg.eigh(L)
    
    print("Eigenvalues (first 10):", eigenvalues[:10])
    harmonic_dim = np.sum(np.abs(eigenvalues) < 1e-10)
    print(f"Harmonic dimension: {harmonic_dim} (matches H^0(S^1))")
    
    # Hodge decomposition
    f = np.random.randn(n)
    f_harmonic = np.mean(f) * np.ones(n)
    f_orthog = f - f_harmonic
    print(f"Orthogonality: {np.dot(f_harmonic, f_orthog):.2e}")

Zero-Knowledge Proofs: Cryptographic Protocols

cryptographic-protocols

Real-World Motivation

Zero-knowledge proofs allow one party to prove to another that a statement is true without revealing any information beyond the validity of the statement itself. This has profound applications in blockchain privacy (Zcash), secure authentication, and electronic voting.

Definitions

  • Interactive Proof System: A protocol between prover \\(P\\) and verifier \\(V\\).
  • Zero-Knowledge: The proof reveals nothing beyond validity.
  • Completeness: True statements are accepted.
  • Soundness: False statements are rejected with high probability.

Theorem: Schnorr's Protocol

Theorem: Let \\(G\\) be a cyclic group of prime order \\(q\\). The Schnorr protocol for proving knowledge of \\(x\\) such that \\(y = g^x\\) is a perfect zero-knowledge proof of knowledge.

Protocol: (1) Prover sends \\(t = g^r\\), (2) Verifier sends challenge \\(c\\), (3) Prover sends \\(s = r + cx\\), (4) Verifier checks \\(g^s = t \\cdot y^c\\).

Notation Guide

  • \\(G\\) — cyclic group of prime order \\(q\\)
  • \\(g\\) — generator
  • \\(x\\) — secret (private key)
  • \\(y = g^x\\) — public key
  • \\(r\\) — prover's nonce
  • \\(c\\) — verifier's challenge
  • \\(s = r + cx\\) — response

Python Code

import random

def mod_exp(base, exp, mod):
    """Compute (base^exp) % mod efficiently."""
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        exp >>= 1
        base = (base * base) % mod
    return result

class SchnorrZK:
    def __init__(self, p, q, g):
        self.p, self.q, self.g = p, q, g
    
    def prove(self, x):
        """Generate ZK proof of knowledge of x where y = g^x."""
        y = mod_exp(self.g, x, self.p)
        r = random.randint(1, self.q - 1)
        t = mod_exp(self.g, r, self.p)
        c = random.randint(1, self.q - 1)  # Challenge
        s = (r + c * x) % self.q
        return (t, c, s), y
    
    def verify(self, proof, y):
        """Verify the ZK proof."""
        t, c, s = proof
        lhs = mod_exp(self.g, s, self.p)
        rhs = (t * mod_exp(y, c, self.p)) % self.p
        return lhs == rhs

# Demo with small parameters
zk = SchnorrZK(p=23, q=11, g=2)
x = 7  # Private key
proof, y = zk.prove(x)
print(f"Public key: {y}")
print(f"Proof verified: {zk.verify(proof, y)}")

Stochastic Differential Equations in Mathematical Finance

mathematical-finance

Real-World Motivation

SDEs provide the mathematical framework for modeling financial markets where asset prices exhibit random fluctuations. The Black-Scholes-Merton model uses SDEs to price options and revolutionized the derivatives industry.

Definitions

  • Wiener Process: A continuous-time stochastic process \\(W_t\\) with \\(W_t - W_s \\sim \\mathcal{N}(0, t-s)\\).
  • SDE: An equation \\(dX_t = \\mu(X_t, t)dt + \\sigma(X_t, t)dW_t\\).
  • Itô Integral: The stochastic integral \\(\\int_0^t H_s dW_s\\).
  • Geometric Brownian Motion: \\(dS_t = \\mu S_t dt + \\sigma S_t dW_t\\).

Theorem: Itô's Lemma

Theorem (Itô, 1944): Let \\(X_t\\) satisfy \\(dX_t = \\mu_t dt + \\sigma_t dW_t\\) and let \\(f \\in C^{2,1}\\). Then:

\\[df = \\left(\\frac{\\partial f}{\\partial t} + \\mu_t \\frac{\\partial f}{\\partial x} + \\frac{1}{2}\\sigma_t^2 \\frac{\\partial^2 f}{\\partial x^2}\\right)dt + \\sigma_t \\frac{\\partial f}{\\partial x} dW_t\\]

Notation Guide

  • \\(W_t\\) — Wiener process
  • \\(\\mu\\) — drift coefficient
  • \\(\\sigma\\) — volatility
  • \\(S_t\\) — asset price
  • \\(dW_t\\) — Wiener increment
  • \\(\\langle X \\rangle_t\\) — quadratic variation

import numpy as np
import matplotlib.pyplot as plt

def simulate_gbm(S0, mu, sigma, T, N, num_paths=10):
    """Simulate Geometric Brownian Motion."""
    dt = T / N
    t = np.linspace(0, T, N+1)
    dW = np.random.randn(num_paths, N) * np.sqrt(dt)
    W = np.concatenate([np.zeros((num_paths, 1)), np.cumsum(dW, axis=1)], axis=1)
    S = S0 * np.exp((mu - 0.5*sigma**2)*t + sigma*W)
    return t, S

Phylogenetic Trees: Algebraic Methods in Computational Biology

computational-biology

Real-World Motivation

Phylogenetics reconstructs evolutionary relationships from genetic sequence data. The mathematics involves combinatorics, algebra (group-based models), and statistics. These methods have revolutionized our understanding of the tree of life.

Definitions

  • Phylogenetic Tree: A tree \\(T = (V, E)\\) with leaves labeled by taxa.
  • Newick Format: Parenthetical notation for trees.
  • Substitution Model: A continuous-time Markov chain on nucleotides.
  • Jukes-Cantor Model: Simplest model with equal substitution rates.

Theorem: Jukes-Cantor Correction

Theorem: Under the Jukes-Cantor model, the expected number of substitutions per site is:

\\[d = -\\frac{3}{4} \\ln\\left(1 - \\frac{4}{3}p\\right)\\]

where \\(p\\) is the observed proportion of differing sites.

Notation Guide

  • \\(T = (V, E)\\) — phylogenetic tree
  • \\(\\mathcal{L}(T)\\) — leaf nodes
  • \\(Q\\) — rate matrix
  • \\(P(t) = e^{Qt}\\) — transition matrix
  • \\(d_{JC}\\) — Jukes-Cantor distance
  • \\(p\\) — p-distance

Python Code

import numpy as np

def jukes_cantor_distance(p):
    """Compute Jukes-Cantor corrected distance."""
    if p >= 0.75:
        return float('inf')
    return -0.75 * np.log(1 - 4*p/3)

def simulate_jukes_cantor(seq_length, time, alpha=1.0):
    """Simulate DNA sequence evolution."""
    bases = ['A', 'C', 'G', 'T']
    seq = np.random.choice(bases, size=seq_length)
    p_same = 0.25 + 0.75 * np.exp(-4 * alpha * time)
    
    new_seq = []
    for base in seq:
        if np.random.random() < p_same:
            new_seq.append(base)
        else:
            other = [b for b in bases if b != base]
            new_seq.append(np.random.choice(other))
    return ''.join(new_seq)

def p_distance(seq1, seq2):
    """Compute proportion of differing sites."""
    return sum(a != b for a, b in zip(seq1, seq2)) / len(seq1)

def count_trees(n):
    """Count unrooted binary trees: (2n-5)!!"""
    if n < 3:
        return 1
    result = 1
    for k in range(1, 2*n - 4, 2):
        result *= k
    return result

# Demo
print("Jukes-Cantor correction:")
for p in [0.1, 0.2, 0.3, 0.5]:
    print(f"  p={p:.1f}: d={jukes_cantor_distance(p):.4f}")

print("\nNumber of phylogenetic trees:")
for n in range(3, 11):
    print(f"  n={n}: {count_trees(n):,} trees")

Fuzzy Logic: Degrees of Truth

fuzzy-logic

Historical Context

Fuzzy logic was introduced by Lotfi Zadeh in 1965 at UC Berkeley. Unlike Boolean logic where statements are strictly true (1) or false (0), fuzzy logic allows degrees of truth in [0,1]. Applications include control systems, decision making, and AI.

Definitions

  • Fuzzy Set: A set \\(A\\) defined by membership function \\(\\mu_A: X \\to [0,1]\\).
  • Fuzzy Union: \\(\\mu_{A \\cup B}(x) = \\max(\\mu_A(x), \\mu_B(x))\\).
  • Fuzzy Intersection: \\(\\mu_{A \\cap B}(x) = \\min(\\mu_A(x), \\mu_B(x))\\).
  • t-norm: A binary operation \\(\\otimes: [0,1]^2 \\to [0,1]\\).

Theorem: Representation of Fuzzy Connectives

Theorem (Ling, 1965): A continuous t-norm \\(\\otimes\\) is Archimedean iff there exists a continuous, strictly decreasing \\(f: [0,1] \\to [0, \\infty]\\) with \\(f(1) = 0\\) such that \\(x \\otimes y = f^{-1}(f(x) + f(y))\\).

Notation Guide

  • \\(\\mu_A(x)\\) — membership function
  • \\(\\vee\\) — fuzzy union (max)
  • \\(\\wedge\\) — fuzzy intersection (min)
  • \\(\\otimes\\) — t-norm
  • \\(\\oplus\\) — t-conorm

import numpy as np
import matplotlib.pyplot as plt

class FuzzySet:
    def __init__(self, mu, domain=(0, 10)):
        self.mu = mu
        self.domain = domain
    
    def __call__(self, x):
        return self.mu(x)
    
    def union(self, other):
        return FuzzySet(lambda x: max(self.mu(x), other.mu(x)))
    
    def intersection(self, other):
        return FuzzySet(lambda x: min(self.mu(x), other.mu(x)))
    
    def complement(self):
        return FuzzySet(lambda x: 1 - self.mu(x))

def triangular(a, b, c):
    def mu(x):
        if x <= a or x >= c:
            return 0.0
        elif a < x <= b:
            return (x - a) / (b - a)
        else:
            return (c - x) / (c - b)
    return mu

Topological Data Analysis: Persistent Homology

topological-data-analysis

Historical Context

TDA emerged in the early 2000s pioneered by Gunnar Carlsson and Herbert Edelsbrunner. Persistent homology detects topological features (components, holes, voids) in data at multiple scales, filtering out noise while capturing meaningful structure.

Definitions

  • Simplicial Complex: A set of simplices closed under taking faces.
  • Vietoris-Rips Complex: \\(VR_\\epsilon(X)\\) contains a simplex for points with pairwise distance \\(< \\epsilon\\).
  • Persistent Homology: Tracks how homology changes as \\(\\epsilon\\) varies.
  • Barcode: Visual representation of persistent homology.

Theorem: Stability of Persistence Diagrams

Theorem (Cohen-Steiner, Edelsbrunner, Harer, 2007): Let \\(X, Y\\) be finite metric spaces. The bottleneck distance between their persistence diagrams satisfies:

\\[d_B(\\text{dgm}(X), \\text{dgm}(Y)) \\leq 2 \\cdot d_{GH}(X, Y)\\]

where \\(d_{GH}\\) is the Gromov-Hausdorff distance.

Notation Guide

  • \\(VR_\\epsilon(X)\\) — Vietoris-Rips complex
  • \\(H_k(X)\\) — \\(k\\)-th homology group
  • \\(\\beta_k\\) — \\(k\\)-th Betti number
  • \\(\\text{dgm}\\) — persistence diagram
  • \\(d_B\\) — bottleneck distance
  • \\(d_{GH}\\) — Gromov-Hausdorff distance

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import pdist, squareform

def vietoris_rips_complex(points, epsilon):
    """Build VR complex (simplified: return edges only)."""
    n = len(points)
    dists = squareform(pdist(points))
    edges = [(i, j) for i in range(n) for j in range(i+1, n) if dists[i,j] < epsilon]
    return edges

def compute_betti_0(points, epsilon):
    """Compute number of connected components (Betti-0)."""
    n = len(points)
    dists = squareform(pdist(points))
    parent = list(range(n))
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    
    def union(x, y):
        px, py = find(x), find(y)
        if px != py:
            parent[px] = py
    
    for i in range(n):
        for j in range(i+1, n):
            if dists[i,j] < epsilon:
                union(i, j)
    
    return len(set(find(i) for i in range(n)))

Automated Theorem Proving: From Logic to Code

automated-theorem-proving

Historical Context

Automated theorem proving (ATP) emerged from the work of logicians like Church, Turing, and Robinson in the mid-20th century. The resolution principle (Robinson, 1965) and later SAT solvers have transformed formal verification of hardware, software, and mathematical proofs.

Definitions

  • First-Order Logic: Logic with quantifiers \\(\\forall, \\exists\\) over non-logical objects.
  • Resolution: A refutation-complete inference rule for first-order logic.
  • SAT Problem: Determining if a propositional formula has a satisfying assignment.
  • SMT Solver: Satisfiability Modulo Theories — extends SAT with background theories.

Theorem: Resolution is Refutation-Complete

Theorem (Robinson, 1965): For a set of clauses \\(S\\) in first-order logic, \\(S\\) is unsatisfiable if and only if there exists a resolution refutation of \\(S\\).

Resolution Rule: From clauses \\((A \\lor L)\\) and \\((B \\lor \\neg L)\\), infer \\((A \\lor B)\\).

Notation Guide

  • \\(\\forall, \\exists\\) — universal and existential quantifiers
  • \\(\\vdash\\) — syntactic entailment (proves)
  • \\(\\models\\) — semantic entailment (entails)
  • \\(\\square\\) — empty clause (contradiction)
  • \\(mgu\\) — most general unifier
  • \\(CNF\\) — conjunctive normal form

Python Code

from itertools import combinations

def resolve(c1, c2):
    """Apply resolution rule to two clauses."""
    # Convert to sets of literals
    literals1 = set(c1) if isinstance(c1, (list, tuple)) else {c1}
    literals2 = set(c2) if isinstance(c2, (list, tuple)) else {c2}
    
    # Look for complementary literals
    for l1 in literals1:
        for l2 in literals2:
            if l1 == f"not({l2})" or l2 == f"not({l1})":
                # Found complementary pair
                new_clause = (literals1 - {l1}) | (literals2 - {l2})
                return tuple(new_clause) if new_clause else "EMPTY"
    return None

def resolution_theorem_prover(clauses, max_iterations=100):
    """Simple resolution theorem prover."""
    clauses = set(tuple(c) if isinstance(c, list) else (c,) for c in clauses)
    
    for iteration in range(max_iterations):
        new_clauses = set()
        
        for c1, c2 in combinations(clauses, 2):
            resolvent = resolve(c1, c2)
            if resolvent == "EMPTY":
                return True, iteration + 1  # Found contradiction
            if resolvent and resolvent not in clauses:
                new_clauses.add(resolvent)
        
        if not new_clauses:
            return False, iteration + 1  # No new clauses
        
        clauses |= new_clauses
    
    return None, max_iterations  # Timeout

# Example: Prove (A -> B) AND A implies B
# CNF: (not A or B) AND A AND not B (negated conclusion)
clauses = [
    ("not(A)", "B"),  # A -> B
    ("A",),           # A
    ("not(B)",)       # not B (negated conclusion)
]

result, steps = resolution_theorem_prover(clauses)
print(f"Theorem proved: {result} in {steps} steps")

Maryam Mirzakhani: The First Female Fields Medalist

maryam-mirzakhani

Historical Context

Maryam Mirzakhani (1977-2017) was an Iranian mathematician and professor at Stanford University. In 2014, she became the first woman and the first Iranian to be awarded the Fields Medal for her outstanding contributions to the dynamics and geometry of Riemann surfaces and their moduli spaces.

Key Contributions

  • Teichmüller Dynamics: Proved that the number of simple closed geodesics of length \\(\\leq L\\) on a hyperbolic surface grows like \\(L^{6g-6}\\).
  • Moduli Spaces: Established a connection between the geometry of moduli space and the dynamics of billiards in polygons.
  • Earthquake Theory: Advanced understanding of Thurston's earthquake deformations of hyperbolic surfaces.
  • Weil-Petersson Volumes: Computed volumes of moduli spaces using recursive formulas.

Theorem: Growth of Simple Closed Geodesics

Theorem (Mirzakhani, 2008): Let \\(S\\) be a hyperbolic surface of genus \\(g\\) with \\(n\\) punctures. The number \\(s(L)\\) of simple closed geodesics of length at most \\(L\\) satisfies:

\\[s(L) \\sim n(S) \\cdot L^{6g-6+2n}\\]

as \\(L \\to \\infty\\), where \\(n(S)\\) is a constant depending only on the topology of \\(S\\).

Legacy

Mirzakhani's work bridges several areas of mathematics: hyperbolic geometry, ergodic theory, and symplectic geometry. Her approach of using the dynamics of moduli space to understand geometric problems has inspired a new generation of mathematicians. She died of breast cancer in 2017 at the age of 40, leaving behind a profound mathematical legacy.

📜 Math History: The Development of Abstract Algebra

The emergence of abstract algebra in the 19th and early 20th centuries represents one of the most profound shifts in mathematical thinking. Where earlier mathematicians had studied specific number systems and equations, the abstract algebraists sought to understand the underlying structures that governed algebraic operations themselves.

The story begins with the work of Évariste Galois in the 1830s. Galois, who would die in a duel at age 20, developed what we now call Galois theory to study the solvability of polynomial equations. His key insight was to associate a group—a collection of symmetries—to each equation, and to show that the structure of this group determined whether the equation could be solved by radicals. Though his contemporaries found his work nearly incomprehensible, it would later be recognized as revolutionary.

In the mid-19th century, Arthur Cayley and others began to recognize that groups appeared throughout mathematics—not just in the theory of equations, but in geometry, number theory, and crystallography. The notion of an abstract group, defined by axioms rather than by a specific representation, gradually took shape. By the 1870s, Camille Jordan's Traité des substitutions had systematized the theory.

The study of rings and ideals emerged from the work of Richard Dedekind in the 1870s. Seeking to understand the failure of unique factorization in certain number fields, Dedekind introduced the concept of an ideal—a subset of a ring that behaves like a "virtual number." This allowed him to restore unique factorization at the level of ideals, a technique that remains fundamental in algebraic number theory.

The final abstraction came in the early 20th century through the work of Emmy Noether. Noether's approach was radically structural: she studied algebraic objects not by their elements but by their mappings and relationships. Her famous dictum, "Es steht alles schon bei Dedekind" ("It's all already in Dedekind"), understated her own contributions. Noether's abstract approach to ring theory, module theory, and representation theory transformed mathematics. Her students and collaborators spread her vision throughout the mathematical world.

By the 1930s, the structural perspective had been codified in the works of Bartel van der Waerden, whose Moderne Algebra became the definitive textbook. The abstract approach had won, setting the stage for the explosive growth of algebra in the second half of the 20th century and its applications to physics, computer science, and cryptography.

🧩 Problem Corner

Putnam 2024 Problem B5

Let \\(n\\) be a positive integer. A Latin square of order \\(n\\) is an \\(n \\times n\\) array filled with \\(n\\) different symbols, each occurring exactly once in each row and exactly once in each column. Let \\(L(n)\\) denote the number of Latin squares of order \\(n\\).

Prove that \\(L(n) \\geq n! \\cdot (n-1)! \\cdot \\cdots \\cdot 1!\\) for all \\(n \\geq 1\\).

Hint

Consider constructing Latin squares row by row. Use the fact that the permanent of a matrix with non-negative entries is at least the product of the row sums divided by appropriate factors. Alternatively, think about the greedy algorithm for constructing Latin squares.

Solution

We prove this by induction on \\(n\\).

Base case: For \\(n = 1\\), we have \\(L(1) = 1 = 1!\\).

Inductive step: Assume the result holds for \\(n-1\\). We construct Latin squares of order \\(n\\) by filling rows greedily.

For the first row, we have \\(n!\\) choices (any permutation of \\(\\{1, \\ldots, n\\}\\)).

Given the first \\(k-1\\) rows, we need to fill row \\(k\\). Each column has \\(k-1\\) symbols already used, so there are \\(n-k+1\\) available symbols per column. The question becomes: how many ways to choose one available symbol from each column, with no repeats?

This is equivalent to counting perfect matchings in a bipartite graph where left vertices represent columns and right vertices represent symbols, with edges representing availability. By Hall's marriage theorem, a perfect matching exists. Moreover, the number of perfect matchings is at least \\((n-k+1)!\\).

To see this, note that we can greedily assign symbols: for column 1, we have \\(n-k+1\\) choices; for column 2, at least \\(n-k\\) choices remain; and so on. This gives at least \\((n-k+1)!\\) ways to fill row \\(k\\).

Multiplying over all rows: \\(L(n) \\geq n! \\cdot (n-1)! \\cdot \\cdots \\cdot 1!\\).

Bifurcation Diagram: The Route to Chaos

The bifurcation diagram of the logistic map \\(x_{n+1} = r x_n (1 - x_n)\\) is one of the most iconic images in dynamical systems. It shows how a simple nonlinear system can exhibit increasingly complex behavior as a parameter is varied, culminating in chaos.

The diagram reveals period-doubling cascades, where stable fixed points give way to stable 2-cycles, then 4-cycles, and so on, accumulating at the onset of chaos around \\(r \\approx 3.57\\). Within the chaotic region, windows of periodic behavior appear, including the prominent period-3 window.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def logistic_map(r, x0, n_iter=1000, n_plot=100):
    """Generate iterations of the logistic map."""
    x = x0
    # Transient
    for _ in range(n_iter - n_plot):
        x = r * x * (1 - x)
    # Collect points
    points = []
    for _ in range(n_plot):
        x = r * x * (1 - x)
        points.append(x)
    return points

# Generate bifurcation diagram
r_values = np.linspace(2.5, 4.0, 2000)
r_plot = []
x_plot = []

for r in r_values:
    points = logistic_map(r, 0.5, n_iter=1000, n_plot=100)
    r_plot.extend([r] * len(points))
    x_plot.extend(points)

plt.figure(figsize=(12, 8))
plt.scatter(r_plot, x_plot, s=0.1, c='black', alpha=0.5)
plt.xlabel('Parameter r')
plt.ylabel('x')
plt.title('Bifurcation Diagram of the Logistic Map')
plt.grid(True, alpha=0.3)
plt.xlim(2.5, 4.0)
plt.savefig('bifurcation_diagram.png', dpi=150, bbox_inches='tight')
plt.close()

print("Bifurcation diagram saved as 'bifurcation_diagram.png'")
