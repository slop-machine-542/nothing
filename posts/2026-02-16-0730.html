1. Commutative Algebra: Hilbert's Nullstellensatz

Commutative algebra studies commutative rings and their ideals, with deep connections to algebraic geometry. Hilbert's Nullstellensatz establishes a fundamental correspondence between algebra (ideals of polynomial rings) and geometry (algebraic varieties).

Notation: Let \(k\) be an algebraically closed field (e.g., \(\mathbb{C}\)), and let \(k[x_1, \ldots, x_n]\) be the polynomial ring in \(n\) variables over \(k\). For an ideal \(I \subseteq k[x_1, \ldots, x_n]\), define the variety:

\[V(I) = \{(a_1, \ldots, a_n) \in k^n : f(a_1, \ldots, a_n) = 0 \text{ for all } f \in I\}\]

For a subset \(X \subseteq k^n\), define the ideal:

\[I(X) = \{f \in k[x_1, \ldots, x_n] : f(a_1, \ldots, a_n) = 0 \text{ for all } (a_1, \ldots, a_n) \in X\}\]
Theorem (Hilbert's Nullstellensatz): Let \(k\) be an algebraically closed field and \(I\) be an ideal of \(k[x_1, \ldots, x_n]\). Then: \[I(V(I)) = \sqrt{I}\] where \(\sqrt{I} = \{f : f^m \in I \text{ for some } m > 0\}\) is the radical of \(I\).
Proof Sketch: The proof uses the "Rabinowitsch trick":

(\(\supseteq\)): If \(f \in \sqrt{I}\), then \(f^m \in I\) for some \(m\). For any \(p \in V(I)\), we have \(f^m(p) = 0\), so \(f(p) = 0\). Thus \(f \in I(V(I))\).

(\(\subseteq\)): Suppose \(f \in I(V(I))\). Introduce a new variable \(y\) and consider the ideal \(J = I + (1 - yf) \subseteq k[x_1, \ldots, x_n, y]\).

Claim: \(V(J) = \emptyset\).
If \((a_1, \ldots, a_n, b) \in V(J)\), then \(g(a_1, \ldots, a_n) = 0\) for all \(g \in I\), so \((a_1, \ldots, a_n) \in V(I)\). Since \(f \in I(V(I))\), we have \(f(a_1, \ldots, a_n) = 0\). But then \(1 - bf(a_1, \ldots, a_n) = 1 \neq 0\), contradiction.

By the weak Nullstellensatz, \(J = k[x_1, \ldots, x_n, y]\). Thus \(1 \in J\), so: \[1 = \sum_{i} g_i h_i + (1 - yf)h\] where \(g_i \in I\) and \(h_i, h \in k[x_1, \ldots, x_n, y]\).

Substitute \(y = 1/f\) and clear denominators to get \(f^m \in I\) for some \(m\). ∎

Python Implementation:

from sympy import symbols, groebner, Poly, expand
from sympy.abc import x, y, z

def variety_membership(polynomials, point):
    """
    Check if a point belongs to the variety of an ideal.
    
    Args:
        polynomials: List of polynomials defining the ideal
        point: Dictionary mapping variables to values
    
    Returns:
        True if point is in V(I), False otherwise
    """
    for poly in polynomials:
        # Substitute point into polynomial
        value = poly.subs(point)
        if value != 0:
            return False
    return True

def ideal_membership(polynomial, generators, variables):
    """
    Check if a polynomial is in the ideal using Groebner basis.
    
    Args:
        polynomial: The polynomial to test
        generators: List of generators of the ideal
        variables: List of variables
    
    Returns:
        True if polynomial is in the ideal
    """
    G = groebner(generators, *variables)
    return G.reduce(polynomial)[1] == 0

2. Real Analysis: The Weierstrass Approximation Theorem

The Weierstrass Approximation Theorem states that any continuous function on a closed interval can be uniformly approximated by polynomials. This is a foundational result connecting continuous and polynomial functions.

Theorem (Weierstrass Approximation): Let \(f: [a, b] \to \mathbb{R}\) be continuous. For every \(\epsilon > 0\), there exists a polynomial \(P\) such that: \[|f(x) - P(x)| < \epsilon \text{ for all } x \in [a, b]\] Equivalently, polynomials are dense in \(C([a, b])\) with respect to the uniform norm.
Proof (Bernstein's probabilistic approach):

Assume \([a, b] = [0, 1]\) (general case follows by linear change of variables). Define the Bernstein polynomials: \[B_n(f)(x) = \sum_{k=0}^{n} \binom{n}{k} f\left(\frac{k}{n}\right) x^k (1-x)^{n-k}\]

Key observation: This is the expected value of \(f(S_n/n)\) where \(S_n\) is a binomial random variable with parameters \(n\) and \(x\).

By the law of large numbers, \(S_n/n \to x\) in probability. Since \(f\) is continuous on \([0,1]\), it is uniformly continuous and bounded.

For any \(\epsilon > 0\), choose \(\delta > 0\) such that \(|x - y| < \delta\) implies \(|f(x) - f(y)| < \epsilon/2\). Let \(M = \sup|f|\).

Split the sum: \[|B_n(f)(x) - f(x)| \leq \sum_{|k/n - x| < \delta} + \sum_{|k/n - x| \geq \delta}\]

The first sum is \(< \epsilon/2\) by uniform continuity. The second sum is bounded by Chebyshev's inequality: \[\mathbb{P}\left(\left|\frac{S_n}{n} - x\right| \geq \delta\right) \leq \frac{x(1-x)}{n\delta^2} \leq \frac{1}{4n\delta^2}\]

For \(n > \frac{2M}{\epsilon \delta^2}\), the second sum \(< \epsilon/2\). Thus \(|B_n(f)(x) - f(x)| < \epsilon\). ∎

Python Implementation:

import numpy as np
import matplotlib.pyplot as plt
from scipy.special import comb

def bernstein_poly(f, n, x):
    """
    Compute the n-th Bernstein polynomial approximation of f at x.
    
    Args:
        f: Function to approximate
        n: Degree of Bernstein polynomial
        x: Point(s) at which to evaluate (scalar or array)
    
    Returns:
        Value of B_n(f)(x)
    """
    x = np.atleast_1d(x)
    result = np.zeros_like(x, dtype=float)
    
    for k in range(n + 1):
        coeff = comb(n, k, exact=True)
        fk = f(k / n)
        result += coeff * fk * (x ** k) * ((1 - x) ** (n - k))
    
    return result if len(result) > 1 else result[0]

# Example: Approximate f(x) = |x - 0.5| on [0, 1]
def f(x):
    return np.abs(x - 0.5)

# Plot approximations

for n in [5, 10, 20, 50]:

    plt.plot(x, y_approx, '--', label=f'B_{n}(f)')

3. Algebraic Number Theory: The Ring of Integers in Quadratic Fields

Algebraic number theory studies number fields (finite extensions of \(\mathbb{Q}\)) and their rings of integers. Quadratic fields provide an accessible entry point with rich structure.

Notation: Let \(d \neq 1\) be a squarefree integer. The quadratic field is \(\mathbb{Q}(\sqrt{d}) = \{a + b\sqrt{d} : a, b \in \mathbb{Q}\}\).

An element \(\alpha\) is an algebraic integer if it satisfies a monic polynomial with integer coefficients.

Theorem (Ring of Integers): The ring of integers \(\mathcal{O}_K\) of \(K = \mathbb{Q}(\sqrt{d})\) is: \[\mathcal{O}_K = \begin{cases} \mathbb{Z}[\sqrt{d}] & \text{if } d \equiv 2, 3 \pmod{4} \\ \mathbb{Z}\left[\frac{1 + \sqrt{d}}{2}\right] & \text{if } d \equiv 1 \pmod{4} \end{cases}\]
Proof: Let \(\alpha = a + b\sqrt{d}\) with \(a, b \in \mathbb{Q}\). The minimal polynomial of \(\alpha\) over \(\mathbb{Q}\) is: \[m_\alpha(x) = x^2 - 2ax + (a^2 - db^2)\]

For \(\alpha\) to be an algebraic integer, this must have integer coefficients:
1. \(2a \in \mathbb{Z}\)
2. \(a^2 - db^2 \in \mathbb{Z}\)

Case 1: \(a \in \mathbb{Z}\). Then \(db^2 \in \mathbb{Z}\). Since \(d\) is squarefree, \(b \in \mathbb{Z}\). Thus \(\alpha \in \mathbb{Z}[\sqrt{d}]\).

Case 2: \(a = k + \frac{1}{2}\) for \(k \in \mathbb{Z}\). Then \(4(a^2 - db^2) = (2k+1)^2 - 4db^2 \in \mathbb{Z}\).
This requires \(4db^2 \in \mathbb{Z}\). Write \(b = \frac{m}{2}\) with \(m\) odd.
Then \(dm^2 \equiv 1 \pmod{4}\), which requires \(d \equiv 1 \pmod{4}\).

In this case, \(\alpha = k + \frac{1}{2} + \frac{m\sqrt{d}}{2} = k + m\cdot\frac{1+\sqrt{d}}{2} - \frac{m-1}{2}\).
Since \(m\) is odd, \(\alpha \in \mathbb{Z}\left[\frac{1+\sqrt{d}}{2}\right]\). ∎

Python Implementation:

import sympy as sp
from sympy import sqrt, Rational, symbols, Poly

def ring_of_integers_basis(d):
    """
    Return the basis for the ring of integers of Q(sqrt(d)).
    
    Args:
        d: Squarefree integer
    
    Returns:
        List of basis elements
    """
    if d % 4 in [2, 3]:
        return [1, sqrt(d)]
    else:  # d % 4 == 1
        return [1, (1 + sqrt(d))/2]

def is_algebraic_integer(alpha, d):
    """
    Check if alpha = a + b*sqrt(d) is an algebraic integer.
    
    Args:
        alpha: Tuple (a, b) representing a + b*sqrt(d)
        d: Squarefree integer
    
    Returns:
        True if alpha is an algebraic integer
    """
    a, b = alpha
    
    # Compute minimal polynomial coefficients
    # x^2 - 2*a*x + (a^2 - d*b^2)
    coeff1 = 2 * a  # must be integer
    coeff0 = a**2 - d * b**2  # must be integer
    
    # Check if both are integers
    if not (isinstance(coeff1, (int, sp.Integer)) and 
            isinstance(coeff0, (int, sp.Integer))):
        return False
    
    # Additional check for half-integers
    if coeff1 % 2 != 0:  # a is half-integer
        return d % 4 == 1
    
    return True

    print(f"Q(sqrt({d:3d})): {form}")

1. Numerical Linear Algebra: The QR Algorithm for Eigenvalues

The QR algorithm is one of the most important methods for computing all eigenvalues of a matrix. It iteratively decomposes a matrix into orthogonal and upper triangular factors, converging to a Schur form.

Notation: For a matrix \(A \in \mathbb{C}^{n \times n}\), the QR decomposition is \(A = QR\) where \(Q\) is unitary (\(Q^*Q = I\)) and \(R\) is upper triangular.

Theorem (QR Algorithm Convergence): Let \(A\) have eigenvalues satisfying \(|\lambda_1| > |\lambda_2| > \cdots > |\lambda_n|\). The QR algorithm with iterates \(A_{k+1} = R_k Q_k\) where \(A_k = Q_k R_k\) converges to an upper triangular matrix with eigenvalues on the diagonal.
Proof Sketch:

Define \(P_k = Q_0 Q_1 \cdots Q_k\) and \(U_k = R_k R_{k-1} \cdots R_0\). Then: \[A^k = P_k U_k\]

This is the QR decomposition of \(A^k\). Now use the power method intuition: columns of \(A^k\) converge to the dominant eigenvector direction.

More precisely, if \(A = X \Lambda X^{-1}\) is the eigenvalue decomposition, then: \[A^k = X \Lambda^k X^{-1}\]

Under the eigenvalue ordering assumption, the columns of \(A^k\) become increasingly aligned with the eigenvectors. The QR decomposition captures this alignment, forcing \(A_k = P_{k-1}^* A P_{k-1}\) toward upper triangular form. ∎

Python Implementation:

import numpy as np

def qr_algorithm(A, max_iter=100, tol=1e-10, shift='wilkinson'):
    """
    Compute eigenvalues using the QR algorithm with shifts.
    
    Args:
        A: Square matrix (will be modified)
        max_iter: Maximum iterations
        tol: Convergence tolerance
        shift: 'none', 'rayleigh', or 'wilkinson'
    
    Returns:
        eigenvalues: Array of eigenvalues
        iterations: Number of iterations performed
    """
    n = A.shape[0]
    Ak = A.copy().astype(float)
    
    # Reduce to Hessenberg form first (for efficiency)
    Ak = hessenberg_reduction(Ak)
    
    eigenvalues = np.zeros(n, dtype=complex)
    remaining = n
    iterations = 0
    
    for _ in range(max_iter):
        if remaining <= 0:
            break
        
        iterations += 1
        
        # Check for convergence of bottom-right element
        if remaining > 1 and abs(Ak[remaining-1, remaining-2]) < tol:
            eigenvalues[remaining-1] = Ak[remaining-1, remaining-1]
            remaining -= 1
            Ak = Ak[:remaining, :remaining]
            continue
        
        # Check for 2x2 block convergence
        if remaining > 2 and abs(Ak[remaining-2, remaining-3]) < tol:
            # Solve 2x2 block
            block = Ak[remaining-2:remaining, remaining-2:remaining]
            eigs = np.linalg.eigvals(block)
            eigenvalues[remaining-2:remaining] = eigs
            remaining -= 2
            Ak = Ak[:remaining, :remaining]
            continue
        
        # Compute shift
        if shift == 'none':
            mu = 0
        elif shift == 'rayleigh':
            mu = Ak[remaining-1, remaining-1]
        elif shift == 'wilkinson':
            # Wilkinson shift
            if remaining >= 2:
                sub = Ak[remaining-2:remaining, remaining-2:remaining]
                eigs = np.linalg.eigvals(sub)
                # Choose eigenvalue closest to bottom-right
                mu = eigs[np.argmin(np.abs(eigs - Ak[remaining-1, remaining-1]))]
            else:
                mu = Ak[remaining-1, remaining-1]
        
        # QR step with shift
        Q, R = np.linalg.qr(Ak - mu * np.eye(remaining))
        Ak = R @ Q + mu * np.eye(remaining)
    
    # Extract remaining eigenvalues
    for i in range(remaining):
        eigenvalues[i] = Ak[i, i]
    
    return eigenvalues, iterations

def hessenberg_reduction(A):
    """Reduce matrix to upper Hessenberg form using Householder reflections."""
    n = A.shape[0]
    H = A.copy().astype(float)
    
    for k in range(n - 2):
        x = H[k+1:, k].copy()
        e1 = np.zeros_like(x)
        e1[0] = np.sign(x[0]) * np.linalg.norm(x)
        v = x + e1
        v = v / np.linalg.norm(v)
        
        H[k+1:, k:] -= 2.0 * np.outer(v, v @ H[k+1:, k:])
        H[:, k+1:] -= 2.0 * np.outer(H[:, k+1:] @ v, v)
    
    return H

# Example: Test on random symmetric matrix
np.random.seed(42)
n = 5
A = np.random.randn(n, n)
A = A + A.T  # Make symmetric

eigvals_qr, iters = qr_algorithm(A, max_iter=1000, shift='wilkinson')
eigvals_numpy = np.linalg.eigvals(A)

print("QR Algorithm Results:")
print(f"Iterations: {iters}")
print(f"Computed eigenvalues: {np.sort(eigvals_qr)}")
print(f"NumPy eigenvalues:    {np.sort(eigvals_numpy)}")
print(f"Maximum error: {np.max(np.abs(np.sort(eigvals_qr) - np.sort(eigvals_numpy))):.2e}")

2. Partial Differential Equations: The Method of Characteristics

The method of characteristics reduces first-order PDEs to systems of ODEs along special curves (characteristics). It's fundamental for solving transport equations and conservation laws.

Notation: Consider the first-order linear PDE: \[a(x, y) u_x + b(x, y) u_y = c(x, y) u + d(x, y)\] with initial data on a curve \(\Gamma\).

Theorem (Method of Characteristics): The solution to the first-order PDE can be found by solving the characteristic ODEs: \[\frac{dx}{dt} = a(x, y), \quad \frac{dy}{dt} = b(x, y), \quad \frac{du}{dt} = c(x, y) u + d(x, y)\] where \(t\) parameterizes the characteristic curves.
Derivation:

Consider a curve \((x(t), y(t))\) in the domain. Along this curve: \[\frac{du}{dt} = u_x \frac{dx}{dt} + u_y \frac{dy}{dt}\]

If we choose: \[\frac{dx}{dt} = a(x, y), \quad \frac{dy}{dt} = b(x, y)\]

Then: \[\frac{du}{dt} = a u_x + b u_y = c u + d\]

This is an ODE along the characteristic curve. The PDE reduces to solving ODEs along curves that "carry" the initial data forward. The solution at any point is found by following the characteristic back to the initial curve. ∎

Python Implementation:

import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

def solve_transport_equation(u0, a, x_range, t_range, nx=100, nt=100):
    """
    Solve the transport equation u_t + a*u_x = 0 using method of characteristics.
    
    Args:
        u0: Initial condition function u0(x)
        a: Wave speed (constant)
        x_range: (x_min, x_max)
        t_range: (t_min, t_max)
        nx, nt: Number of grid points
    
    Returns:
        x, t, u: Solution grid
    """
    x = np.linspace(x_range[0], x_range[1], nx)
    t = np.linspace(t_range[0], t_range[1], nt)
    X, T = np.meshgrid(x, t)
    
    # Solution: u(x, t) = u0(x - a*t)
    U = np.zeros_like(X)
    for i in range(nt):
        for j in range(nx):
            x_char = X[i, j] - a * T[i, j]
            U[i, j] = u0(x_char)
    
    return X, T, U

def solve_burgers_inviscid(u0, x_range, t_range, nx=200, nt=100):
    """
    Solve the inviscid Burgers equation u_t + u*u_x = 0.
    
    For Burgers' equation, characteristics are straight lines with slope
    determined by initial data: x = x0 + u0(x0)*t
    """
    x = np.linspace(x_range[0], x_range[1], nx)
    t = np.linspace(t_range[0], t_range[1], nt)
    
    U = np.zeros((nt, nx))
    
    for i, ti in enumerate(t):
        for j, xj in enumerate(x):
            # Find x0 such that xj = x0 + u0(x0)*ti
            # This requires solving a nonlinear equation
            from scipy.optimize import fsolve
            
            def char_eq(x0):
                return x0 + u0(x0) * ti - xj
            
            # Initial guess
            x0_guess = xj
            try:
                x0 = fsolve(char_eq, x0_guess)[0]
                U[i, j] = u0(x0)
            except:
                U[i, j] = np.nan
    
    return x, t, U

3. Wavelet Theory: The Haar Wavelet Transform

Wavelets provide localized time-frequency analysis, overcoming limitations of the Fourier transform. The Haar wavelet is the simplest wavelet, using step functions to decompose signals.

Notation: The Haar mother wavelet is: \[\psi(x) = \begin{cases} 1 & 0 \leq x < \frac{1}{2} \\ -1 & \frac{1}{2} \leq x < 1 \\ 0 & \text{otherwise} \end{cases}\]

The scaling function is: \[\phi(x) = \begin{cases} 1 & 0 \leq x < 1 \\ 0 & \text{otherwise} \end{cases}\]

Dilated and translated versions: \(\psi_{j,k}(x) = 2^{j/2} \psi(2^j x - k)\)

Theorem (Haar Wavelet Decomposition): Any function \(f \in L^2([0,1])\) can be decomposed as: \[f(x) = a_0 \phi(x) + \sum_{j=0}^{\infty} \sum_{k=0}^{2^j-1} d_{j,k} \psi_{j,k}(x)\] where \(a_0 = \int_0^1 f(x) dx\) and \(d_{j,k} = \int_0^1 f(x) \psi_{j,k}(x) dx\).
Proof of Orthonormality:

We show \(\{\psi_{j,k}\}\) forms an orthonormal set. For the inner product: \[\langle \psi_{j,k}, \psi_{j',k'} \rangle = \int_0^1 \psi_{j,k}(x) \psi_{j',k'}(x) dx\]

Case 1: \(j = j'\). The supports of \(\psi_{j,k}\) and \(\psi_{j,k'}\) are disjoint unless \(k = k'\). Thus: \[\langle \psi_{j,k}, \psi_{j,k'} \rangle = \delta_{k,k'}\]

Case 2: \(j \neq j'\). Assume \(j < j'\). The function \(\psi_{j',k'}\) oscillates twice as fast and is supported within either the positive or negative lobe of \(\psi_{j,k}\). Since \(\psi_{j',k'}\) has zero mean: \[\int_{k/2^j}^{(k+1/2)/2^j} \psi_{j',k'}(x) dx = 0\] \[\int_{(k+1/2)/2^j}^{(k+1)/2^j} \psi_{j',k'}(x) dx = 0\]

Therefore \(\langle \psi_{j,k}, \psi_{j',k'} \rangle = 0\). ∎

import numpy as np
import pywt
import matplotlib.pyplot as plt

def haar_wavelet(x):
    """Haar mother wavelet."""
    result = np.zeros_like(x)
    result[(x >= 0) & (x < 0.5)] = 1
    result[(x >= 0.5) & (x < 1)] = -1
    return result

def haar_scaling(x):
    """Haar scaling function."""
    result = np.zeros_like(x)
    result[(x >= 0) & (x < 1)] = 1
    return result

def haar_decomposition(signal):
    """
    Perform 1D Haar wavelet decomposition.
    
    Args:
        signal: 1D array (length must be power of 2)
    
    Returns:
        approximation, details: Decomposition coefficients
    """
    n = len(signal)
    if n % 2 != 0:
        raise ValueError("Signal length must be even")
    
    # Approximation coefficients (averages)
    approx = (signal[0::2] + signal[1::2]) / np.sqrt(2)
    
    # Detail coefficients (differences)
    detail = (signal[0::2] - signal[1::2]) / np.sqrt(2)
    
    return approx, detail

def haar_reconstruction(approx, detail):
    """Reconstruct signal from Haar coefficients."""
    n = len(approx)
    signal = np.zeros(2 * n)
    
    signal[0::2] = (approx + detail) / np.sqrt(2)
    signal[1::2] = (approx - detail) / np.sqrt(2)
    
    return signal

1. Coding Theory: Reed-Solomon Error Correction

Reed-Solomon codes are non-binary cyclic error-correcting codes used in CDs, DVDs, QR codes, and satellite communications. They can correct burst errors efficiently.

Notation: A Reed-Solomon code \(RS(n, k)\) over \(\mathbb{F}_q\) has: - Block length: \(n = q - 1\) - Message length: \(k\) - Minimum distance: \(d = n - k + 1\) (MDS property) - Error correction capability: \(t = \lfloor (n-k)/2 \rfloor\)

Theorem (Reed-Solomon MDS Property): Reed-Solomon codes meet the Singleton bound with equality: \[d = n - k + 1\] making them Maximum Distance Separable (MDS) codes.
Proof: The RS code is constructed by evaluating polynomials of degree \(< k\) at \(n\) distinct points \(\alpha_1, \ldots, \alpha_n \in \mathbb{F}_q\).

A codeword is \((p(\alpha_1), \ldots, p(\alpha_n))\) where \(p\) has degree \(< k\).

A nonzero polynomial of degree \(< k\) has at most \(k-1\) roots. Therefore, any nonzero codeword has at least \(n - (k-1) = n - k + 1\) nonzero entries.

Thus the minimum Hamming weight (and distance) is \(d \geq n - k + 1\).

By the Singleton bound: \(d \leq n - k + 1\).

Therefore \(d = n - k + 1\). ∎

Python Implementation:

import numpy as np
from numpy.polynomial import polynomial as P

class ReedSolomon:
    """
    Reed-Solomon encoder/decoder over GF(2^m).
    """
    
    def __init__(self, n, k, field_exp=8):
        """
        Initialize RS(n, k) code.
        
        Args:
            n: Block length (must be 2^m - 1 for some m)
            k: Message length
            field_exp: Field exponent (default 8 for GF(256))
        """
        self.n = n
        self.k = k
        self.t = (n - k) // 2  # Error correction capability
        self.field_exp = field_exp
        self.field_size = 2 ** field_exp
        
        # Primitive polynomial for GF(256): x^8 + x^4 + x^3 + x^2 + 1
        self.prim_poly = 0b100011101
        
        # Generate field elements
        self.alpha = self._generate_field()
        
    def _generate_field(self):
        """Generate powers of primitive element."""
        alpha = [1]
        for i in range(1, self.field_size):
            alpha.append(self._gf_mul(alpha[-1], 2))
        return alpha
    
    def _gf_mul(self, a, b):
        """Multiply in GF(2^m)."""
        result = 0
        for i in range(self.field_exp):
            if b & (1 << i):
                result ^= a << i
        
        # Reduce modulo primitive polynomial
        for i in range(self.field_exp * 2 - 2, self.field_exp - 1, -1):
            if result & (1 << i):
                result ^= self.prim_poly << (i - self.field_exp)
        
        return result & (self.field_size - 1)
    
    def _gf_inv(self, a):
        """Multiplicative inverse in GF(2^m)."""
        if a == 0:
            raise ValueError("Division by zero")
        # Fermat's little theorem: a^(-1) = a^(2^m - 2)
        result = 1
        power = self.field_size - 2
        base = a
        while power > 0:
            if power & 1:
                result = self._gf_mul(result, base)
            base = self._gf_mul(base, base)
            power >>= 1
        return result
    
    def encode(self, message):
        """
        Encode message using Reed-Solomon.
        
        Args:
            message: List of k elements in GF(2^m)
        
        Returns:
            Codeword of length n
        """
        if len(message) != self.k:
            raise ValueError(f"Message must have length {self.k}")
        
        # Systematic encoding: message + parity
        # Use polynomial evaluation for simplicity
        codeword = []
        for i in range(self.n):
            # Evaluate polynomial at alpha^i
            point = self.alpha[i % (self.field_size - 1)]
            value = 0
            for j, coeff in enumerate(message):
                value ^= self._gf_mul(coeff, self._gf_pow(point, j))
            codeword.append(value)
        
        return codeword
    
    def _gf_pow(self, a, n):
        """Compute a^n in GF(2^m)."""
        result = 1
        for _ in range(n):
            result = self._gf_mul(result, a)
        return result
    
    def decode_berlekamp_massey(self, received):
        """
        Decode using Berlekamp-Massey algorithm (simplified).
        
        Args:
            received: Received word (possibly with errors)
        
        Returns:
            Decoded message or None if uncorrectable
        """
        # This is a simplified placeholder
        # Full implementation requires syndrome computation,
        # Berlekamp-Massey, Chien search, and Forney algorithm
        
        # For demonstration, just return first k symbols
        return received[:self.k]

2. Elliptic Curve Cryptography: The Group Law

Elliptic curves provide the mathematical foundation for modern cryptography. The group structure on elliptic curve points enables the Diffie-Hellman key exchange and digital signatures.

Notation: An elliptic curve over a field \(K\) is defined by the Weierstrass equation: \[E: y^2 = x^3 + ax + b\] where \(\Delta = -16(4a^3 + 27b^2) \neq 0\) (ensures nonsingularity).

Theorem (Elliptic Curve Group Law): The set of points \(E(K)\) together with a point at infinity \(\mathcal{O}\) forms an abelian group under the chord-and-tangent rule:
  • Identity: \(P + \mathcal{O} = P\) for all \(P\)
  • Inverse: If \(P = (x, y)\), then \(-P = (x, -y)\)
  • Addition: For \(P \neq Q\), draw line through \(P\) and \(Q\), find third intersection \(R\), then \(P + Q = -R\)
  • Doubling: For \(P = Q\), use the tangent line at \(P\)
Explicit Formulas:

Let \(P = (x_1, y_1)\) and \(Q = (x_2, y_2)\) with \(P \neq -Q\).

Slope: \[\lambda = \begin{cases} \frac{y_2 - y_1}{x_2 - x_1} & P \neq Q \\ \frac{3x_1^2 + a}{2y_1} & P = Q \end{cases}\]

Sum \(P + Q = (x_3, y_3)\): \[x_3 = \lambda^2 - x_1 - x_2\] \[y_3 = \lambda(x_1 - x_3) - y_1\]

Verification: Substituting into the curve equation verifies that \((x_3, y_3)\) lies on \(E\). Associativity follows from the Cayley-Bacharach theorem in algebraic geometry. ∎

Python Implementation:

class EllipticCurve:
    """
    Elliptic curve over a finite field F_p.
    Curve equation: y^2 = x^3 + ax + b (mod p)
    """
    
    def __init__(self, a, b, p):
        """
        Initialize elliptic curve.
        
        Args:
            a, b: Curve coefficients
            p: Prime field characteristic
        """
        self.a = a
        self.b = b
        self.p = p
        
        # Check discriminant
        discriminant = (-16 * (4 * a**3 + 27 * b**2)) % p
        if discriminant == 0:
            raise ValueError("Curve is singular")
    
    def is_on_curve(self, point):
        """Check if point is on the curve."""
        if point is None:  # Point at infinity
            return True
        x, y = point
        return (y * y - x**3 - self.a * x - self.b) % self.p == 0
    
    def add(self, P, Q):
        """
        Add two points on the curve.
        
        Args:
            P, Q: Points (x, y) or None for point at infinity
        
        Returns:
            P + Q
        """
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # P + (-P) = O
        if x1 == x2 and (y1 + y2) % self.p == 0:
            return None
        
        # Compute slope
        if x1 != x2:
            # Point addition
            lam = ((y2 - y1) * pow(x2 - x1, -1, self.p)) % self.p
        else:
            # Point doubling
            lam = ((3 * x1**2 + self.a) * pow(2 * y1, -1, self.p)) % self.p
        
        # Compute result
        x3 = (lam**2 - x1 - x2) % self.p
        y3 = (lam * (x1 - x3) - y1) % self.p
        
        return (x3, y3)
    
    def scalar_mult(self, k, P):
        """
        Compute k*P using double-and-add.
        
        Args:
            k: Scalar (positive integer)
            P: Point on curve
        
        Returns:
            k*P
        """
        if k < 0:
            raise ValueError("Negative scalar not supported")
        if k == 0 or P is None:
            return None
        
        result = None
        addend = P
        
        while k:
            if k & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            k >>= 1
        
        return result
    
    def find_points(self):
        """Find all points on the curve (for small p)."""
        points = [None]  # Point at infinity
        for x in range(self.p):
            rhs = (x**3 + self.a * x + self.b) % self.p
            # Check if rhs is quadratic residue
            for y in range(self.p):
                if (y * y) % self.p == rhs:
                    points.append((x, y))
        return points

3. Analytic Number Theory: The Prime Number Theorem

The Prime Number Theorem describes the asymptotic distribution of prime numbers, one of the most celebrated results in mathematics.

Notation: Let \(\pi(x)\) denote the number of primes less than or equal to \(x\).

Theorem (Prime Number Theorem): \[\lim_{x \to \infty} \frac{\pi(x)}{x / \ln x} = 1\] Equivalently, \(\pi(x) \sim \frac{x}{\ln x}\) as \(x \to \infty\).
Sketch (via Complex Analysis):

The proof uses the Riemann zeta function: \[\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s} = \prod_p \frac{1}{1 - p^{-s}}\]

Key steps:
1. Define \(\psi(x) = \sum_{p^k \leq x} \ln p\) (Chebyshev function)
2. Show \(\psi(x) \sim x\) implies PNT
3. Use Perron's formula to express \(\psi(x)\) as a contour integral:
\[\psi(x) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \left(-\frac{\zeta'(s)}{\zeta(s)}\right) \frac{x^s}{s} ds\]

4. Move contour to the left, picking up residues at poles of \(\zeta'/\zeta\)
5. The pole at \(s = 1\) contributes \(x\)
6. The zero-free region of \(\zeta(s)\) for \(\text{Re}(s) \geq 1\) ensures no other contributions dominate

Hadamard and de la Vallée Poussin independently proved in 1896 that \(\zeta(1 + it) \neq 0\) for all \(t \neq 0\), establishing the PNT. ∎

4. The Four Color Theorem and Graph Coloring

The Four Color Theorem states that any planar graph can be colored with at most four colors. This was the first major theorem proved using a computer.

Notation: A proper k-coloring of a graph \(G = (V, E)\) is a function \(c: V \to \{1, \ldots, k\}\) such that \(c(u) \neq c(v)\) whenever \(\{u, v\} \in E\). The chromatic number \(\chi(G)\) is the minimum \(k\) for which a proper \(k\)-coloring exists.

Theorem (Four Color Theorem): Every planar graph \(G\) satisfies: \[\chi(G) \leq 4\]
Historical Context and Approach:

The theorem was proved by Appel and Haken in 1976, and later simplified by Robertson, Sanders, Seymour, and Thomas in 1997.

Key ideas:
1. Unavoidable set: Every planar graph contains one of 633 (later reduced) "configurations"
2. Reducibility: Each configuration can be replaced by a smaller graph preserving 4-colorability
3. Discharging method: Assign charge to vertices based on degree, redistribute according to rules, show some configuration must have positive charge

The computer-assisted proof checked that every configuration is reducible and that the set is unavoidable. ∎

import networkx as nx

def is_valid_coloring(G, coloring):
    """Check if a coloring is valid."""
    for u, v in G.edges():
        if coloring[u] == coloring[v]:
            return False
    return True

def greedy_coloring(G, order=None):
    """
    Greedy graph coloring algorithm.
    
    Args:
        G: NetworkX graph
        order: Vertex ordering (default: sorted by degree)
    
    Returns:
        Dictionary mapping vertices to colors
    """
    if order is None:
        # Order by descending degree
        order = sorted(G.nodes(), key=lambda v: G.degree(v), reverse=True)
    
    coloring = {}
    
    for v in order:
        # Find colors used by neighbors
        neighbor_colors = {coloring[u] for u in G.neighbors(v) if u in coloring}
        
        # Assign smallest available color
        color = 1
        while color in neighbor_colors:
            color += 1
        coloring[v] = color
    
    return coloring

def welsh_powell_coloring(G):
    """Welsh-Powell coloring (greedy with degree ordering)."""
    return greedy_coloring(G)

def dsatur_coloring(G):
    """
    DSatur (Brelaz) coloring algorithm.
    At each step, color the vertex with highest saturation degree.
    """
    if len(G) == 0:
        return {}
    
    coloring = {}
    uncolored = set(G.nodes())
    
    # Saturation degree = number of different colors in neighborhood
    def saturation_degree(v):
        return len({coloring[u] for u in G.neighbors(v) if u in coloring})
    
    while uncolored:
        # Find vertex with maximum saturation degree (break ties by degree)
        v = max(uncolored, key=lambda x: (saturation_degree(x), G.degree(x)))
        
        # Assign smallest available color
        neighbor_colors = {coloring[u] for u in G.neighbors(v) if u in coloring}
        color = 1
        while color in neighbor_colors:
            color += 1
        
        coloring[v] = color
        uncolored.remove(v)
    
    return coloring

📜 Math History

The Development of Modern Set Theory: From Cantor to Cohen

The foundations of modern set theory were established through a series of revolutionary discoveries in the late 19th and early 20th centuries:

  • 1874 — Georg Cantor proves that the real numbers are uncountable, establishing different sizes of infinity. His diagonal argument becomes a cornerstone of mathematical logic.
  • 1883 — Cantor introduces transfinite ordinal and cardinal numbers, extending arithmetic beyond the finite. This work meets resistance from contemporaries like Kronecker but gradually gains acceptance.
  • 1900 — David Hilbert includes the Continuum Hypothesis as the first problem in his famous list of 23 problems for the 20th century.
  • 1902 — Bertrand Russell discovers his paradox, showing that naive set comprehension leads to contradictions. This prompts the development of axiomatic set theories.
  • 1908 — Ernst Zermelo proposes the first axiomatization of set theory (Zermelo set theory), later refined by Abraham Fraenkel to become ZFC (Zermelo-Fraenkel with Choice).
  • 1931 — Kurt Gödel proves his incompleteness theorems, showing that any consistent formal system containing arithmetic cannot prove its own consistency.
  • 1940 — Gödel proves that the Continuum Hypothesis is consistent with ZFC set theory, showing it cannot be disproved.
  • 1963 — Paul Cohen invents the method of forcing and proves that the negation of CH is also consistent with ZFC, establishing the independence of the Continuum Hypothesis.

Cohen's forcing technique revolutionized set theory, providing a general method for proving independence results. His work earned him the Fields Medal in 1966, one of the few awarded for work in mathematical logic.
