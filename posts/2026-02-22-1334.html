Approximation Theory: The Art of Getting Close

approximation-theory

Motivation

How well can we approximate a complicated function by a simpler one? This fundamental question underlies approximation theory, which studies how functions can be approximated by polynomials, rational functions, splines, and other simpler classes. The field has profound connections to numerical analysis (solving differential equations), signal processing (filter design), and machine learning (neural networks as universal approximators). Key results include the Weierstrass approximation theorem, Chebyshev's equioscillation theorem, and the theory of best approximation in normed spaces.

Definitions

  • Best Approximation: Given a function \(f\) and a subspace \(S\) of a normed space, \(p^* \\\in S\) is a best approximation if \(\|f - p^*\| = \\inf_{p \\in S} \|f - p\|\).
  • Chebyshev Polynomials: Defined by \(T_n(x) = \\cos(n \\arccos x)\) for \(x \\in [-1, 1]\). They satisfy the recurrence \(T_{n+1}(x) = 2xT_n(x) - T_{n-1}(x)\) with \(T_0 = 1\), \(T_1 = x\).
  • Modulus of Continuity: \(\omega(f, \\delta) = \\sup_{|x-y| \\leq \\delta} |f(x) - f(y)|\), measuring how fast \(f\) can change.
  • Jackson's Theorem: Bounds the best polynomial approximation error in terms of the modulus of continuity.
  • Bernstein Polynomials: \(B_n(f, x) = \\sum_{k=0}^n f(k/n) \\binom{n}{k} x^k (1-x)^{n-k}\), providing a constructive proof of Weierstrass's theorem.

Theorem: Chebyshev Equioscillation Theorem

Theorem (Chebyshev Equioscillation): Let \(f \\in C[a,b]\) and let \(P_n\) be the space of polynomials of degree at most \(n\). Then \(p^* \\in P_n\) is the unique best approximation to \(f\) in the uniform norm if and only if there exist \(n+2\) points \(a \\leq x_0 < x_1 < \\cdots < x_{n+1} \\leq b\) such that:

\[f(x_i) - p^*(x_i) = (-1)^i \\sigma \|f - p^*\|_\\infty, \\quad i = 0, 1, \\ldots, n+1\]

where \(\sigma = \\pm 1\) is fixed. That is, the error oscillates between \(\pm \|f - p^*\|_\\infty\) at \(n+2\) consecutive points.

Proof Sketch

The proof has two parts. For necessity: if the error doesn't equioscillate at \(n+2\) points, we can construct a better approximation by adjusting the polynomial to reduce the maximum error. For sufficiency: if \(p^*\) equioscillates and \(q\) is any other polynomial in \(P_n\), then \(p^* - q\) must change sign at the \(n+1\) intervals between equioscillation points, implying \(p^* = q\) (since a degree \(n\) polynomial can't have \(n+1\) roots unless it's zero).

Notation Guide

  • \(\|f\|_\\infty = \\sup_{x \\in [a,b]} |f(x)|\): Uniform (supremum) norm
  • \(\|f\|_2 = \\left(\\int_a^b |f(x)|^2 dx\\right)^{1/2}\): L² norm
  • \(E_n(f) = \\inf_{p \\in P_n} \|f - p\|_\\infty\): Best uniform approximation error
  • \(T_n(x)\): Chebyshev polynomial of the first kind, degree \(n\)
  • \(U_n(x)\): Chebyshev polynomial of the second kind
  • \(\\omega(f, \\delta)\): Modulus of continuity
  • \(B_n(f, x)\): Bernstein polynomial of degree \(n\)

    """Generate n Chebyshev nodes in [a, b]."""
    k = np.arange(n)

Algebraic Curves: The Geometry of Polynomial Equations

algebraic-curves

Motivation

What can we learn about solutions to polynomial equations by studying their geometric properties? Algebraic curves—solutions to polynomial equations in two variables—form one of the oldest and richest subjects in mathematics. From the ancient Greeks' study of conic sections to Fermat's Last Theorem and modern cryptography, curves have fascinated mathematicians for millennia. The theory connects algebra (rings of functions), geometry (Riemann surfaces), and number theory (rational points). The classification of curves by genus reveals deep connections to topology and complex analysis.

Definitions

  • Affine Algebraic Curve: The zero set \(C = \\{(x,y) \\in \\mathbb{A}^2 : f(x,y) = 0\\}\) for a polynomial \(f \\in k[x,y]\).
  • Projective Curve: The zero set of a homogeneous polynomial \(F(X,Y,Z) = 0\) in \(\mathbb{P}^2\). Every affine curve embeds in a projective curve.
  • Genus: For a smooth projective curve over \(\mathbb{C}\), the genus \(g\) is the number of "holes" in the corresponding Riemann surface. For a plane curve of degree \(d\) with only ordinary singularities: \(g = (d-1)(d-2)/2 - \\sum \\delta_P\).
  • Divisor: A formal sum \(D = \\sum n_P P\) where \(P\) are points on the curve and \(n_P \\in \\mathbb{Z}\). The degree is \(\deg(D) = \\sum n_P\).
  • Riemann-Roch Space: \(L(D) = \\{f \\in k(C)^* : \\text{div}(f) + D \\geq 0\\} \\cup \\{0\\}\), the space of functions with poles bounded by \(D\).

Theorem: The Riemann-Roch Theorem

Theorem (Riemann-Roch): Let \(C\) be a smooth projective curve of genus \(g\) over an algebraically closed field, and let \(K\) be a canonical divisor. For any divisor \(D\):

\[\\ell(D) - \\ell(K - D) = \\deg(D) + 1 - g\]

where \(\ell(D) = \\dim L(D)\) is the dimension of the Riemann-Roch space.

Corollary (Riemann's Inequality): For any divisor \(D\) with \(\deg(D) \\geq 0\):

\[\\ell(D) \\geq \\deg(D) + 1 - g\]

Corollary: If \(\deg(D) > 2g - 2\), then \(\ell(D) = \\deg(D) + 1 - g\).

Proof Sketch

The proof proceeds in several stages. First, one shows that the theorem holds for the zero divisor (using that \(\ell(0) = 1\) and \(\ell(K) = g\)). Then one proves that if the theorem holds for \(D\), it holds for \(D + P\) and \(D - P\) for any point \(P\). This is done by analyzing the exact sequence \(0 \\to L(D) \\to L(D+P) \\to k \\to 0\) and its analogue for \(K-D\). Since any divisor can be reached from \(0\) by adding and subtracting points, the theorem follows for all divisors.

Notation Guide

  • \(k(C)\): Function field of the curve \(C\)
  • \(\\text{div}(f)\): Divisor of zeros and poles of \(f\)
  • \((f)_0\), \((f)_\\infty\): Divisors of zeros and poles
  • \(K\) or \(K_C\): Canonical divisor (divisor of a differential)
  • \(g = g(C)\): Genus of the curve
  • \(\\ell(D)\): Dimension of \(L(D)\)
  • \(\\text{Cl}(C)\): Divisor class group (Picard group)
  • \(J(C)\): Jacobian variety (\(\text{Pic}^0(C)\))

Fourier Analysis: Decomposing Functions into Waves

fourier-analysis

Motivation

Can any function be written as a sum of simple waves? Fourier analysis answers this question affirmatively, showing that periodic functions can be decomposed into sines and cosines, and general functions into continuous superpositions. This revolutionary insight, developed by Joseph Fourier in his 1822 treatise on heat conduction, underlies modern signal processing, quantum mechanics, partial differential equations, and data compression (JPEG, MP3). The Fourier transform converts convolution to multiplication, making it indispensable for solving differential equations and analyzing linear time-invariant systems.

Definitions

  • Fourier Series: For a \(2\\pi\)-periodic function \(f\): \(f(x) = \\sum_{n=-\\infty}^{\\infty} \\hat{f}(n) e^{inx}\) where \(\hat{f}(n) = \\frac{1}{2\\pi} \\int_0^{2\\pi} f(x) e^{-inx} dx\).
  • Fourier Transform: For \(f \\in L^1(\\mathbb{R})\): \(\hat{f}(\\xi) = \\int_{-\\infty}^{\\infty} f(x) e^{-2\\pi i x \\xi} dx\).
  • Convolution: \((f * g)(x) = \\int_{-\\infty}^{\\infty} f(y) g(x-y) dy\). The Fourier transform satisfies \(\widehat{f * g} = \\hat{f} \\cdot \\hat{g}\).
  • Plancherel's Theorem: \(\|f\|_{L^2} = \|\hat{f}\|_{L^2}\), i.e., the Fourier transform preserves the \(L^2\) norm (up to constants).
  • Uncertainty Principle: A function and its Fourier transform cannot both be sharply localized. Precisely: \(\|x f\|_2 \|\\xi \\hat{f}\|_2 \\geq \\frac{1}{4\\pi} \|f\|_2^2\).

Theorem: Fourier Inversion Theorem

Theorem (Fourier Inversion): If \(f \\in L^1(\\mathbb{R})\) and \(\hat{f} \\in L^1(\\mathbb{R})\), then for almost every \(x\):

\[f(x) = \\int_{-\\infty}^{\\infty} \\hat{f}(\\xi) e^{2\\pi i x \\xi} d\\xi\]

If \(f\) is also continuous, this holds for all \(x\).

Plancherel's Formula: For \(f \\in L^1(\\mathbb{R}) \\cap L^2(\\mathbb{R})\):

\[\\int_{-\\infty}^{\\infty} |f(x)|^2 dx = \\int_{-\\infty}^{\\infty} |\\hat{f}(\\xi)|^2 d\\xi\]

Proof Sketch

The proof uses an approximation argument. Define the Gauss kernel \(G_t(x) = \\frac{1}{\\sqrt{4\\pi t}} e^{-x^2/(4t)}\) with \(\widehat{G_t}(\\xi) = e^{-4\\pi^2 t \\xi^2}\). For \(f \\in L^1\), the convolution \(f * G_t\) converges to \(f\) as \(t \\to 0\). But \(f * G_t = \\int \\hat{f}(\\xi) e^{-4\\pi^2 t \\xi^2} e^{2\\pi i x \\xi} d\\xi\) by Fubini's theorem. As \(t \\to 0\), the Gaussian factor approaches 1, yielding the inversion formula.

Notation Guide

  • \(\hat{f}(\\xi)\) or \(\mathcal{F}[f](\\xi)\): Fourier transform
  • \(\check{f}(x)\) or \(\mathcal{F}^{-1}[f](x)\): Inverse Fourier transform
  • \(f * g\): Convolution of \(f\) and \(g\)
  • \(\\hat{f}(n)\): Fourier coefficient for periodic functions
  • \(L^1(\\mathbb{R})\), \(L^2(\\mathbb{R})\): Lebesgue spaces
  • \(\mathcal{S}(\\mathbb{R})\): Schwartz space (rapidly decreasing functions)
  • \(\delta\): Dirac delta distribution

def fourier_series_coeffs(f, n_terms, period=2*np.pi):
    """
    Compute Fourier series coefficients for a periodic function.
    Returns a_n and b_n for cosine and sine terms.
    """
    N = 1000  # Sampling points
    x = np.linspace(0, period, N, endpoint=False)
    y = f(x)
    
    # Compute coefficients using FFT
    coeffs = fft(y) / N
    
    a_n = 2 * np.real(coeffs[:n_terms])
    b_n = -2 * np.imag(coeffs[:n_terms])
    a_n[0] = coeffs[0].real  # DC component
    
    return a_n, b_n

def fourier_series_approx(x, a_n, b_n, period=2*np.pi):
    """Evaluate Fourier series at points x."""
    result = np.zeros_like(x)
    n_terms = len(a_n)
    
    for n in range(n_terms):
        if n == 0:
            result += a_n[0] / 2
        else:
            result += a_n[n] * np.cos(2*np.pi*n*x/period)
            result += b_n[n] * np.sin(2*np.pi*n*x/period)
    
    return result

Quantum Cryptography: Unbreakable Security from Physics

quantum-cryptography

Real-World Motivation

How can we communicate securely in a world where quantum computers threaten to break all current encryption? Quantum cryptography offers a solution based on the fundamental laws of physics rather than computational assumptions. The most mature application is Quantum Key Distribution (QKD), which allows two parties to generate a shared secret key with security guaranteed by quantum mechanics—specifically, the no-cloning theorem and the fact that measurement disturbs quantum states. Any eavesdropping attempt necessarily introduces detectable errors. China has already deployed QKD networks spanning thousands of kilometers, and satellite-based QKD is operational.

Definitions

  • Qubit: A quantum bit, represented as a unit vector in \(\mathbb{C}^2\): \(|\\psi\\rangle = \\alpha|0\\rangle + \\beta|1\\rangle\) where \(|\\alpha|^2 + |\\beta|^2 = 1\).
  • No-Cloning Theorem: It is impossible to create an identical copy of an arbitrary unknown quantum state. Formally, there is no unitary \(U\) such that \(U(|\\psi\\rangle \\otimes |0\\rangle) = |\\psi\\rangle \\otimes |\\psi\\rangle\) for all \(|\\psi\\rangle\).
  • BB84 Protocol: The first QKD protocol, developed by Bennett and Brassard in 1984. Alice sends qubits in one of four states (two bases), Bob measures in randomly chosen bases, and they keep only the bits where bases match.
  • Quantum Channel: A communication channel that transmits quantum states, typically using photons (polarization or phase encoding).
  • Quantum Bit Error Rate (QBER): The fraction of bits that differ between Alice and Bob. An elevated QBER indicates eavesdropping.

Theorem: Security of BB84

Theorem (BB84 Security): If the quantum bit error rate (QBER) is below approximately 11%, Alice and Bob can distill a secret key using error correction and privacy amplification. The secret key rate \(R\) satisfies:

\[R \\geq I(A:B) - \\chi(A:E)\]

where \(I(A:B)\) is the classical mutual information between Alice and Bob, and \(\chi(A:E)\) is the Holevo information between Alice and Eve.

Shor-Preskill Security Proof: BB84 is secure against arbitrary attacks (including coherent attacks) when the QBER is below about 11%.

Proof Sketch

The security proof uses the fact that Eve's information is bounded by the disturbance she causes. If Eve measures the quantum states, she must choose a basis; when her basis differs from Alice's, she introduces errors. The amount of information Eve can have about the key is bounded by the error rate through the Holevo bound. Privacy amplification (using universal hash functions) can then reduce Eve's information to an arbitrarily small amount at the cost of shortening the key.

Notation Guide

  • \(|0\\rangle\), \(|1\\rangle\): Computational basis states
  • \(|+\\rangle = \\frac{1}{\\sqrt{2}}(|0\\rangle + |1\\rangle)\), \(|-\\rangle = \\frac{1}{\\sqrt{2}}(|0\\rangle - |1\\rangle)\): Hadamard basis
  • \(\\rho\): Density matrix representing a quantum state
  • \(\\chi(A:E)\): Holevo information, upper bound on classical information extractable from quantum states
  • \(I(A:B)\): Mutual information between Alice and Bob
  • \(H(X)\): Shannon entropy of random variable \(X\)
  • \(H(X|Y)\): Conditional entropy

    """Simulate quantum measurement in given basis."""
    probs = [np.abs(np.vdot(b, state))**2 for b in basis]
    return np.random.choice([0, 1], p=probs)

def bb84_protocol(n_bits, eavesdrop=False, eve_error_rate=0.1):
    """
    Simulate BB84 quantum key distribution protocol.
    Returns: alice_key, bob_key, qber, eve_knowledge
    """
    # Alice prepares random bits and bases
    alice_bits = randint(0, 2, n_bits)
    alice_bases = randint(0, 2, n_bits)  # 0 = Z, 1 = X
    
    # Alice prepares states
    states = []
    for bit, basis in zip(alice_bits, alice_bases):
        if basis == 0:  # Z basis
            states.append(ket0 if bit == 0 else ket1)
        else:  # X basis
            states.append(ket_plus if bit == 0 else ket_minus)
    
    # Eve's attack (if enabled)
    if eavesdrop:
        for i in range(n_bits):
            if rand() < eve_error_rate:  # Eve measures this qubit
                eve_basis = randint(0, 2)
                basis = Z_basis if eve_basis == 0 else X_basis
                _ = measure(states[i], basis)  # Eve's measurement disturbs state
                # State collapses to basis state, introducing errors
                states[i] = basis[0] if rand() < 0.5 else basis[1]
    
    # Bob measures in random bases
    bob_bases = randint(0, 2, n_bits)
    bob_results = []
    for state, basis_choice in zip(states, bob_bases):
        basis = Z_basis if basis_choice == 0 else X_basis
        bob_results.append(measure(state, basis))
    
    # Basis reconciliation: keep only matching bases
    matching = alice_bases == bob_bases
    alice_sifted = alice_bits[matching]
    bob_sifted = np.array(bob_results)[matching]
    
    # Error estimation (using subset)
    check_size = min(len(alice_sifted) // 4, 100)
    check_indices = np.random.choice(len(alice_sifted), check_size, replace=False)
    errors = np.sum(alice_sifted[check_indices] != bob_sifted[check_indices])
    qber = errors / check_size if check_size > 0 else 0
    
    # Remaining key after error estimation
    remaining = np.setdiff1d(np.arange(len(alice_sifted)), check_indices)
    alice_key = alice_sifted[remaining]
    bob_key = bob_sifted[remaining]
    
    return alice_key, bob_key, qber

Bifurcation Theory: When Small Changes Cause Big Shifts

bifurcation-theory

Real-World Motivation

Why do sudden dramatic changes occur when parameters vary smoothly? Bifurcation theory studies how the qualitative behavior of dynamical systems changes as parameters are varied. Applications span climate science (tipping points in ecosystems), engineering (structural collapse), biology (population dynamics, neuron firing), and economics (market crashes). The "butterfly effect" and tipping points in climate change are manifestations of bifurcations. Understanding bifurcations helps predict catastrophic transitions and design systems that avoid unwanted sudden changes.

Definitions

  • Bifurcation: A qualitative change in the dynamics of a system as a parameter crosses a critical value.
  • Fixed Point: A point \(x^*\) where \(f(x^*) = 0\) (for \(\dot{x} = f(x)\)).
  • Stability: A fixed point is stable if trajectories starting nearby converge to it; unstable if they diverge.
  • Saddle-Node Bifurcation: Two fixed points (one stable, one unstable) collide and annihilate: \(\dot{x} = r - x^2\).
  • Transcritical Bifurcation: Two fixed points exchange stability: \(\dot{x} = rx - x^2\).
  • Pitchfork Bifurcation: One fixed point splits into three (supercritical: \(\dot{x} = rx - x^3\); subcritical: \(\dot{x} = rx + x^3\)).
  • Hopf Bifurcation: A fixed point loses stability and a limit cycle is born.

Theorem: Normal Forms and Bifurcation Classification

Theorem (Saddle-Node Bifurcation): Consider \(\dot{x} = f(x, r)\) with a non-hyperbolic fixed point at \((x^*, r_c)\). If:

\[\\frac{\\partial f}{\\partial r} \\bigg|_{(x^*, r_c)} \\neq 0, \\quad \\frac{\\partial^2 f}{\\partial x^2} \\bigg|_{(x^*, r_c)} \\neq 0\]

then the system is locally topologically equivalent to the normal form \(\dot{x} = r - x^2\) (or \(\dot{x} = r + x^2\)).

Theorem (Hopf Bifurcation): For a system \(\dot{x} = f(x, r)\) in \(\mathbb{R}^2\), if at \(r = r_c\) the Jacobian has eigenvalues \(\lambda = \\alpha(r) \\pm i\\beta(r)\) with \(\alpha(r_c) = 0\), \(\beta(r_c) \\neq 0\), and \(\\frac{d\\alpha}{dr}\\big|_{r_c} \\neq 0\), then a Hopf bifurcation occurs.

Proof Sketch

The proof uses center manifold theory and normal form reduction. Near a bifurcation point, the dynamics can be reduced to a lower-dimensional center manifold capturing the essential behavior. Taylor expansion and coordinate changes transform the system into the simplest (normal) form that preserves the topological structure. The conditions ensure the bifurcation is "generic"—small perturbations don't change its qualitative nature.

Notation Guide

  • \(\dot{x} = dx/dt\): Time derivative
  • \(x^*\): Fixed point (equilibrium)
  • \(r\) or \(\mu\): Bifurcation parameter
  • \(r_c\): Critical bifurcation value
  • \(Df(x^*)\): Jacobian matrix at fixed point
  • \(\\lambda\): Eigenvalue of Jacobian
  • \(W^s\), \(W^u\): Stable and unstable manifolds
  • \(\\mu\): Lyapunov coefficient (determines Hopf bifurcation type)

def find_fixed_points(f, r, x_range=(-2, 2)):
    """Find fixed points numerically."""
    x_test = np.linspace(x_range[0], x_range[1], 1000)
    fixed_points = []
    for x0 in x_test:
        try:
            x_fp = fsolve(f, x0, args=(r,))[0]
            if abs(f(x_fp, r)) < 1e-6:
                # Check stability
                eps = 1e-8
                df = (f(x_fp + eps, r) - f(x_fp - eps, r)) / (2*eps)
                stability = 'stable' if df < 0 else 'unstable'
                # Avoid duplicates
                if not any(abs(x_fp - fp[0]) < 1e-4 for fp in fixed_points):
                    fixed_points.append((x_fp, stability))
        except:
            pass
    return fixed_points

Monte Carlo Methods: Randomness as a Computational Tool

monte-carlo-methods

Real-World Motivation

How can randomness help solve deterministic problems? Monte Carlo methods use random sampling to approximate quantities that are difficult or impossible to compute exactly. These methods revolutionized physics (neutron transport simulations at Los Alamos), finance (option pricing), optimization (simulated annealing), and machine learning (Bayesian inference, reinforcement learning). When the dimension of a problem is high, Monte Carlo methods often outperform deterministic methods—the error decreases as \(O(1/\\sqrt{n})\) regardless of dimension, while grid-based methods suffer from the curse of dimensionality.

Definitions

  • Monte Carlo Integration: Approximate \(\int_D f(x) dx\) by \(\frac{|D|}{n} \\sum_{i=1}^n f(X_i)\) where \(X_i\) are uniform random samples from \(D\).
  • Law of Large Numbers: The sample mean converges to the expected value: \(\frac{1}{n}\\sum_{i=1}^n X_i \\to \\mathbb{E}[X]\) as \(n \\to \\infty\).
  • Central Limit Theorem: The error in Monte Carlo estimation is approximately normal with standard deviation \(\sigma/\\sqrt{n}\).
  • Importance Sampling: Sample from a distribution \(g\) that gives more weight to important regions: \(\mathbb{E}_f[h(X)] = \\mathbb{E}_g[h(X)f(X)/g(X)]\).
  • Markov Chain Monte Carlo (MCMC): Generate correlated samples from a target distribution using a Markov chain (Metropolis-Hastings, Gibbs sampling).
  • Quasi-Monte Carlo: Use deterministic low-discrepancy sequences instead of random samples for faster convergence.

Theorem: Monte Carlo Convergence

Theorem (Monte Carlo Error Bound): Let \(I = \\int_{[0,1]^d} f(x) dx\) and \(\hat{I}_n = \\frac{1}{n}\\sum_{i=1}^n f(X_i)\) where \(X_i \\sim U([0,1]^d)\) i.i.d. Then:

\[\\mathbb{E}[(\\hat{I}_n - I)^2] = \\frac{\\text{Var}(f)}{n}\]

By Chebyshev's inequality, for any \(\epsilon > 0\):

\[P(|\\hat{I}_n - I| \\geq \\epsilon) \\leq \\frac{\\text{Var}(f)}{n\\epsilon^2}\]

Central Limit Theorem: As \(n \\to \\infty\):

\[\\sqrt{n}(\\hat{I}_n - I) \\xrightarrow{d} N(0, \\sigma^2_f)\]

where \(\sigma^2_f = \\text{Var}(f)\).

Proof Sketch

The mean squared error result follows from \(\mathbb{E}[\\hat{I}_n] = I\) (unbiasedness) and \(\text{Var}(\\hat{I}_n) = \\text{Var}(f)/n\) (since samples are independent). The CLT follows from the classical central limit theorem applied to i.i.d. random variables \(f(X_i)\). The key insight is that the convergence rate \(O(1/\\sqrt{n})\) is independent of dimension \(d\), unlike deterministic quadrature.

Notation Guide

  • \(\\hat{I}_n\): Monte Carlo estimate with \(n\) samples
  • \(\\mathbb{E}[X]\): Expected value of random variable \(X\)
  • \(\\text{Var}(X) = \\mathbb{E}[(X - \\mathbb{E}[X])^2]\): Variance
  • \(\\sigma\): Standard deviation
  • \(X \\sim U(D)\): \(X\) uniformly distributed on \(D\)
  • \(\\pi(x)\): Target probability density
  • \(K(x, y)\): Markov transition kernel
  • \(\\tau_{\\text{mix}}\): Mixing time of Markov chain

    """
    Monte Carlo integration of f over domain.
    domain = [(a1, b1), (a2, b2), ...] for each dimension.

Integer Programming: Optimization with Discrete Decisions

integer-programming

Historical Context

Integer programming emerged from the need to model real-world decisions that must be whole numbers—how many trucks to buy, which facilities to open, how to schedule flights. While linear programming (continuous variables) was solved in the 1940s by Dantzig's simplex method, the discrete nature of integer programming makes it fundamentally harder. The field took off in the 1960s with the development of branch-and-bound methods and cutting planes. Today, modern solvers like CPLEX and Gurobi can solve problems with millions of variables, underpinning logistics, finance, and operations research.

Definitions

  • Integer Linear Program (ILP): Minimize \(c^T x\) subject to \(Ax \\leq b\), \(x \\geq 0\), \(x \\in \\mathbb{Z}^n\).
  • Mixed Integer Program (MIP): Some variables are continuous, others integer.
  • Binary Variables: Variables restricted to \(\{0, 1\\}\), used for yes/no decisions.
  • LP Relaxation: The linear program obtained by dropping integrality constraints, providing a lower bound.
  • Branch-and-Bound: Systematically divide the problem (branch) and use bounds to prune subproblems (bound).
  • Cutting Planes: Add constraints that cut off fractional solutions without removing integer feasible solutions.

Theorem: Complexity and Approximation

Theorem (NP-Completeness): Integer linear programming is NP-complete. The decision problem "does there exist a feasible integer solution?" is NP-complete, even with just binary variables.

Theorem (LP Relaxation Bound): Let \(z_{IP}\) be the optimal integer value and \(z_{LP}\) the LP relaxation value. For a minimization problem:

\[z_{LP} \\leq z_{IP}\]

Theorem (Total Unimodularity): If \(A\) is totally unimodular (every square submatrix has determinant \(-1, 0,\) or \(1\)) and \(b\) is integer, then the LP relaxation has an integer optimal solution.

Proof Sketch (Total Unimodularity)

If \(A\) is totally unimodular and the basis matrix \(B\) is invertible, then \(\\det(B) = \\pm 1\). By Cramer's rule, \(B^{-1}\) has integer entries. Since the basic solution is \(x_B = B^{-1}b\) and \(b\) is integer, \(x_B\) is integer. Thus every vertex of the feasible region is integer, so the LP optimum is achieved at an integer point.

Notation Guide

  • \(c \\in \\mathbb{R}^n\): Objective function coefficients
  • \(A \\in \\mathbb{R}^{m \\times n}\): Constraint matrix
  • \(b \\in \\mathbb{R}^m\): Right-hand side vector
  • \(x \\in \\mathbb{Z}^n\): Integer decision variables
  • \(z^*\): Optimal objective value
  • \(P = \\{x : Ax \\leq b\\}\): Polyhedron (feasible region)
  • \(P_I = \\text{conv}(P \\cap \\mathbb{Z}^n)\): Integer hull

def solve_knapsack_branch_bound(values, weights, capacity):
    """
    Solve 0/1 knapsack using branch and bound.
    Returns best value and selected items.
    """
    n = len(values)
    best_value = 0
    best_selection = []
    
    # Sort by value/weight ratio
    ratios = values / weights
    order = np.argsort(-ratios)
    
    def bound(selection, current_weight, current_value, idx):
        """Compute upper bound using fractional knapsack."""
        if current_weight > capacity:
            return 0
        
        bound_val = current_value
        remaining = capacity - current_weight
        
        for i in range(idx, n):
            item = order[i]
            if weights[item] <= remaining:
                bound_val += values[item]
                remaining -= weights[item]
            else:
                bound_val += values[item] * (remaining / weights[item])
                break
        
        return bound_val
    
    def branch(selection, current_weight, current_value, idx):
        nonlocal best_value, best_selection
        
        if idx == n:
            if current_value > best_value:
                best_value = current_value
                best_selection = selection.copy()
            return
        
        # Prune if bound is worse than best
        if bound(selection, current_weight, current_value, idx) <= best_value:
            return
        
        item = order[idx]
        
        # Branch: include item
        if current_weight + weights[item] <= capacity:
            selection.append(item)
            branch(selection, current_weight + weights[item], 
                   current_value + values[item], idx + 1)
            selection.pop()
        
        # Branch: exclude item
        branch(selection, current_weight, current_value, idx + 1)
    
    branch([], 0, 0, 0)
    return best_value, best_selection

Singularity Theory: Understanding Critical Points

singularity-theory

Historical Context

Singularity theory studies how small changes in parameters can cause dramatic changes in the structure of solutions to equations. The field emerged from the work of Hassler Whitney on mappings of the plane (1950s) and René Thom's catastrophe theory (1960s), which promised to explain sudden changes in biological and social systems. While some applications were oversold, the mathematical core—classifying degenerate critical points of functions—has become essential in differential topology, algebraic geometry, and applications to optics, robotics, and computer vision.

Definitions

  • Critical Point: For \(f: \\mathbb{R}^n \\to \\mathbb{R}\), a point \(p\) where \(\nabla f(p) = 0\).
  • Non-Degenerate Critical Point: The Hessian matrix \(H_{ij} = \\frac{\\partial^2 f}{\\partial x_i \\partial x_j}\) is non-singular at \(p\).
  • Morse Function: A function with only non-degenerate critical points.
  • Singularity: A critical point where the Hessian is singular (degenerate).
  • Catastrophe: A sudden change in the behavior of a system as parameters cross a bifurcation set.
  • Corank: The corank of a critical point is \(n - \\text{rank}(H)\), measuring the degree of degeneracy.

Theorem: Morse Lemma and Classification

Theorem (Morse Lemma): Let \(f: \\mathbb{R}^n \\to \\mathbb{R}\) have a non-degenerate critical point at \(p\) with index \(\\lambda\) (number of negative eigenvalues of Hessian). Then there exist coordinates such that:

\[f(x) = f(p) - x_1^2 - \\cdots - x_\\lambda^2 + x_{\\lambda+1}^2 + \\cdots + x_n^2\]

Theorem (Splitting Lemma): Near a degenerate critical point, \(f\) can be written as:

\[f(x, y) = Q(x) + g(y)\]

where \(Q\) is a non-degenerate quadratic form and \(g\) has vanishing quadratic part.

Thom's Classification: For families with at most 4 parameters, there are only 7 elementary catastrophes: fold, cusp, swallowtail, butterfly, hyperbolic umbilic, elliptic umbilic, and parabolic umbilic.

Proof Sketch (Morse Lemma)

The proof uses the fundamental theorem of calculus to write \(f(x) - f(p) = \\sum x_i g_i(x)\) where \(g_i(0) = \\frac{\\partial f}{\\partial x_i}(0) = 0\). Applying the same trick to \(g_i\) gives \(f(x) - f(p) = \\sum x_i x_j h_{ij}(x)\). By symmetry, we can assume \(h_{ij} = h_{ji}\). Since the Hessian is non-degenerate, we can diagonalize by completing squares inductively, yielding the canonical form.

Notation Guide

  • \(\nabla f\): Gradient of \(f\)
  • \(H_f\) or \(\\nabla^2 f\): Hessian matrix
  • \(\\lambda\): Morse index (number of negative eigenvalues)
  • \(\\text{corank}(f)\): Corank of Hessian at critical point
  • \(\\text{codim}(f)\): Codimension of singularity
  • \(A_k, D_k, E_6, E_7, E_8\): ADE classification of simple singularities
  • \(\\mu\): Milnor number (dimension of local algebra)

def gradient(f, x, h=1e-5):
    """Numerical gradient using central differences."""
    n = len(x)
    grad = np.zeros(n)
    for i in range(n):
        x_plus = x.copy()
        x_minus = x.copy()
        x_plus[i] += h
        x_minus[i] -= h
        grad[i] = (f(x_plus) - f(x_minus)) / (2*h)
    return grad

def hessian(f, x, h=1e-5):
    """Numerical Hessian using central differences."""
    n = len(x)
    H = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            x_pp = x.copy()
            x_pm = x.copy()
            x_mp = x.copy()
            x_mm = x.copy()
            x_pp[i] += h; x_pp[j] += h
            x_pm[i] += h; x_pm[j] -= h
            x_mp[i] -= h; x_mp[j] += h
            x_mm[i] -= h; x_mm[j] -= h
            H[i, j] = (f(x_pp) - f(x_pm) - f(x_mp) + f(x_mm)) / (4*h**2)
    return H

Symmetry and Conservation Laws: Noether's Theorem

noether

Historical Context

In 1918, Emmy Noether published a theorem that would become one of the most important results in mathematical physics. Working at Göttingen under David Hilbert and Felix Klein, she proved that every continuous symmetry of a physical system corresponds to a conserved quantity. Time translation symmetry implies energy conservation; spatial translation symmetry implies momentum conservation; rotational symmetry implies angular momentum conservation. Einstein wrote that Noether's theorem was "penetrating mathematical thinking." Her work unified conservation laws with the geometric structure of physical theories, forming the foundation of modern theoretical physics.

Definitions

  • Lagrangian: \(L(q, \\dot{q}, t)\), a function where the equations of motion are given by the Euler-Lagrange equations: \(\frac{d}{dt}\\frac{\\partial L}{\\partial \\dot{q}} = \\frac{\\partial L}{\\partial q}\).
  • Action: \(S = \\int L dt\), the integral of the Lagrangian over time. The principle of least action states that physical paths extremize \(S\).
  • Symmetry: A transformation that leaves the action invariant (or changes it by at most a boundary term).
  • Noether Charge: The conserved quantity associated with a continuous symmetry: \(Q = \\sum_i p_i \\delta q_i - f\) where \(p_i = \\frac{\\partial L}{\\partial \\dot{q}_i}\).
  • Conserved Current: For field theories, \(j^\\mu\) satisfying \(\\partial_\\mu j^\\mu = 0\).

Theorem: Noether's Theorem

Theorem (Noether's First Theorem): If the action is invariant under a continuous symmetry transformation with parameter \(\\epsilon\), then the quantity:

\[Q = \\sum_i \\frac{\\partial L}{\\partial \\dot{q}_i} \\frac{\\delta q_i}{\\delta \\epsilon}\]

is conserved along solutions of the equations of motion: \(\frac{dQ}{dt} = 0\).

Correspondences:

  • Time translation: \(Q = H\) (Hamiltonian/energy)
  • Space translation: \(Q = p\) (momentum)
  • Rotation: \(Q = L\) (angular momentum)
  • Phase rotation (quantum): \(Q = N\) (particle number)

Proof Sketch

Consider a variation \(\delta q_i = \\epsilon f_i(q, \\dot{q}, t)\) that leaves the Lagrangian invariant up to a total derivative: \(\delta L = \\epsilon \\frac{dF}{dt}\). Using the Euler-Lagrange equations and the definition of canonical momentum \(p_i = \\frac{\\partial L}{\\partial \\dot{q}_i}\), we compute \(\frac{d}{dt}(\\sum p_i \\delta q_i - F) = 0\). This shows \(Q = \\sum p_i f_i - F\) is conserved.

Notation Guide

  • \(L\): Lagrangian
  • \(S = \\int L dt\): Action
  • \(q_i\): Generalized coordinates
  • \(\\dot{q}_i = dq_i/dt\): Generalized velocities
  • \(p_i = \\frac{\\partial L}{\\partial \\dot{q}_i}\): Canonical momentum
  • \(H = \\sum p_i \\dot{q}_i - L\): Hamiltonian
  • \(\\delta q_i\): Variation of coordinates
  • \(Q\): Noether charge (conserved quantity)
  • \(j^\\mu\): Conserved current (field theory)

📜 Math History

The Birth of Modern Algebra: From Cardano to Galois

The solution of polynomial equations stands as one of the great narratives in mathematical history, spanning four centuries and culminating in the creation of modern algebra. In 1545, Gerolamo Cardano published "Ars Magna," revealing methods for solving cubic and quartic equations that had been discovered by Tartaglia and Ferrari. The cubic formula, complicated as it is, showed that radicals could express solutions to degree-three equations. Mathematicians naturally wondered: could quintic equations be solved similarly?

For nearly three centuries, this question remained open. Lagrange analyzed the problem systematically in 1770, showing that the solution methods for lower degrees relied on specific symmetries that failed for the quintic. Paolo Ruffini claimed a proof of unsolvability in 1799, though gaps remained. The complete answer came in 1824 from a young Norwegian mathematician, Niels Henrik Abel, who proved that the general quintic cannot be solved by radicals.

Yet Abel's theorem left questions unanswered. Which equations could be solved? What distinguished solvable from unsolvable cases? Évariste Galois, a brilliant and tragic French mathematician, answered these questions in the early 1830s. Working feverishly before his death in a duel at age 20, Galois developed a theory connecting equations to groups of permutations. He showed that an equation is solvable by radicals precisely when its Galois group is solvable—a concept he invented.

Galois's work was nearly lost; his papers were rejected or ignored until Liouville published them in 1846. By then, the seeds of group theory had taken root. What began as a tool for analyzing equations became one of the fundamental structures of modern mathematics, with applications across geometry, number theory, physics, and cryptography. The quest to solve equations had created an entirely new mathematical universe.

Solution:

Define \(g(x) = f'(x) - f(x)\). Then:

\[g'(x) = f''(x) - f'(x) \\geq f(x) - f'(x) = -g(x)\]

So \(g'(x) + g(x) \\geq 0\), which means \((e^x g(x))' \\geq 0\).

Therefore \(e^x g(x) \\geq e^0 g(0) = f'(0) - f(0) = 1\), giving us \(g(x) \\geq e^{-x}\).

Now define \(h(x) = e^{-x}f(x)\). Then:

\[h'(x) = e^{-x}(f'(x) - f(x)) = e^{-x}g(x) \\geq e^{-2x}\]

Integrating from 0 to \(x\):

\[h(x) - h(0) \\geq \\int_0^x e^{-2t} dt = \\frac{1 - e^{-2x}}{2}\]

\[h(x) \\geq \\frac{1 - e^{-2x}}{2}\]

Multiplying by \(e^x\):

\[f(x) \\geq \\frac{e^x - e^{-x}}{2} = \\sinh(x)\]

Newton Fractals: Roots as Attractors

Newton's method for finding roots of polynomials creates stunning fractal patterns when applied to complex numbers. Python Code

import numpy as np
import matplotlib.pyplot as plt

def newton_fractal(poly_roots, width=800, height=800, max_iter=50, tol=1e-6):
    """
    Generate Newton fractal for a polynomial with given roots.
    
    Parameters:
    -----------
    poly_roots : list of complex
        Roots of the polynomial
    width, height : int
        Image dimensions
    max_iter : int
        Maximum Newton iterations
    tol : float
        Convergence tolerance
    """
    # Construct polynomial from roots: p(z) = ∏(z - r_i)
    # p'(z) = p(z) · Σ 1/(z - r_i)
    roots = np.array(poly_roots)
    n_roots = len(roots)
    
    # Create grid in complex plane
    x = np.linspace(-2, 2, width)
    y = np.linspace(-2, 2, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j*Y
    
    # Track which root each point converges to
    root_index = np.full(Z.shape, -1, dtype=int)
    iterations = np.zeros(Z.shape, dtype=int)
    
    for i in range(max_iter):
        # Evaluate polynomial and derivative
        # p(z) = ∏(z - r_k)
        p = np.ones_like(Z)
        for r in roots:
            p *= (Z - r)
        
        # p'(z)/p(z) = Σ 1/(z - r_k)
        p_prime_over_p = np.zeros_like(Z)
        for r in roots:
            p_prime_over_p += 1.0 / (Z - r)
        
        # Newton step: z_new = z - p(z)/p'(z)
        Z_new = Z - 1.0 / p_prime_over_p
        
        # Check convergence
        for j, r in enumerate(roots):
            converged = np.abs(Z - r) < tol
            root_index[converged & (root_index == -1)] = j
            iterations[converged & (iterations == 0)] = i
        
        Z = Z_new
    
    return root_index, iterations

# Example: Cubic polynomial with roots at 1, -0.5+0.866i, -0.5-0.866i

roots = [1, -0.5 + 0.866j, -0.5 - 0.866j]
