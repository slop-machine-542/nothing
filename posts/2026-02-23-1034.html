Combinatorial Design Theory: The Mathematics of Balanced Structures

combinatorial-design-theory

Motivation

Combinatorial design theory studies the existence and construction of discrete structures with prescribed balance properties. Originating from statistical experimental design in the 1930s, the field has grown to encompass applications in coding theory, cryptography, computer science, and recreational mathematics. A classic problem asks: can a group of schoolgirls walk in triplets for seven days such that no pair walks together more than once? This is the famous Kirkman schoolgirl problem, solved in the 19th century and now understood as a resolvable Steiner triple system.

Definitions

  • Block Design: A pair \((X, \mathcal{B})") where \(X\) is a set of \(v\) points and \(\mathcal{B}\) is a collection of \(b\) subsets of \(X\) called blocks, each of size \(k\).
  • Balanced Incomplete Block Design (BIBD): A block design where every pair of distinct points appears together in exactly \(\lambda\) blocks. Parameters satisfy: \(bk = vr\) and \(\lambda(v-1) = r(k-1)\), where \(r\) is the number of blocks containing each point.
  • Steiner System \(S(t, k, v)\): A set system where every \(t\)-subset of a \(v\)-set is contained in exactly one block of size \(k\). When \(t = 2\) and \(\lambda = 1\), this is a Steiner triple system if \(k = 3\).
  • Resolvable Design: A design whose blocks can be partitioned into parallel classes, where each parallel class partitions the point set.
  • Latin Square: An \(n \times n\) array filled with \(n\) symbols where each symbol appears exactly once in each row and column.

Theorem: Existence of Steiner Triple Systems

Theorem (Kirkman, 1847): A Steiner triple system of order \(v\) (denoted STS\((v)\)) exists if and only if \(v \equiv 1 \text{ or } 3 \pmod{6}\).

Proof Sketch

Necessity: In an STS\((v)\), each point lies in \(r = (v-1)/2\) blocks (since each of the \(v-1\) other points pairs with it exactly once, and each block contains 2 other points). Thus \(v\) must be odd. Also, the total number of blocks is \(b = vr/3 = v(v-1)/6\), which must be an integer. This requires \(v(v-1) \equiv 0 \pmod{6}\). Combined with \(v\) odd, we get \(v \equiv 1 \text{ or } 3 \pmod{6}\).

Sufficiency: The proof uses recursive constructions. For the base cases: STS\((3)\) is trivial (one block), and STS\((7)\) is the Fano plane. The Bose construction handles \(v \equiv 3 \pmod{6}\) using finite fields of order \(2k+1\). The Skolem construction handles \(v \equiv 1 \pmod{6}\) using a different algebraic approach. Direct product constructions allow building larger systems from smaller ones.

Notation Guide

  • \(v\): Number of points in the design
  • \(b\): Number of blocks
  • \(r\): Replication number (blocks per point)
  • \(k\): Block size
  • \(\lambda\): Index (pairs per block)
  • STS\((v)\): Steiner triple system of order \(v\)
  • \((v, k, \lambda)\)-design: BIBD with parameters \(v, k, \lambda\)

Python Code

import itertools
from collections import defaultdict

class DesignTheory:
    """Combinatorial design theory computations."""
    
    @staticmethod
    def is_steiner_triple_system(blocks, v):
        """Verify if a collection of blocks forms an STS(v)."""
        pair_count = defaultdict(int)
        for block in blocks:
            if len(block) != 3:
                return False
            for pair in itertools.combinations(block, 2):
                pair_count[tuple(sorted(pair))] += 1
        expected_pairs = list(itertools.combinations(range(v), 2))
        for pair in expected_pairs:
            if pair_count[pair] != 1:
                return False
        return len(pair_count) == len(expected_pairs)
    
    @staticmethod
    def fano_plane():
        """Return the Fano plane STS(7)."""
        return [
            {0, 1, 3}, {1, 2, 4}, {2, 3, 5}, {3, 4, 6},
            {4, 5, 0}, {5, 6, 1}, {6, 0, 2}
        ]
    
    @staticmethod
    def steiner_triple_system_9():
        """Return STS(9) using affine plane construction."""
        return [
            {0, 1, 2}, {0, 3, 6}, {0, 4, 8}, {0, 5, 7},
            {1, 3, 8}, {1, 4, 7}, {1, 5, 6},
            {2, 3, 7}, {2, 4, 6}, {2, 5, 8},
            {3, 4, 5}, {6, 7, 8}
        ]
    
    @staticmethod
    def bibd_parameters(v, k, lambda_):
        """Calculate BIBD parameters r and b from v, k, lambda."""
        if (v - 1) * lambda_ % (k - 1) != 0:
            return None
        r = (v - 1) * lambda_ // (k - 1)
        if v * r % k != 0:
            return None
        b = v * r // k
        return (r, b)

    fano = dt.fano_plane()
    print(f"Is valid STS(7): {dt.is_steiner_triple_system(fano, 7)}")
    print(f"Number of blocks: {len(fano)}")

Integral Geometry: The Mathematics of Geometric Probability

integral-geometry

Motivation

Integral geometry studies geometric probabilities and invariant measures on spaces of geometric objects. The field began with Buffon's needle problem (1777): what is the probability that a needle dropped on a floor with parallel lines crosses a line? This seemingly simple question launched a rich theory connecting probability, geometry, and analysis. Modern integral geometry has applications in stereology (inferring 3D structure from 2D sections), medical imaging, tomography, and stochastic geometry.

Definitions

  • Kinematic Density: The invariant measure on the group of rigid motions (rotations and translations) in \(\mathbb{R}^n\).
  • Crofton Formula: Relates the length of a curve to the measure of lines intersecting it.
  • Intrinsic Volume: For a convex body \(K \subset \mathbb{R}^n\), the intrinsic volumes \(V_0, V_1, \ldots, V_n\) generalize volume, surface area, mean width, and Euler characteristic.
  • Quermassintegral: The average projection volume of a convex body onto random subspaces.
  • Hadwiger's Theorem: Characterizes continuous, rigid-motion-invariant valuations on convex bodies.

Theorem: Crofton's Formula

Theorem (Crofton, 1868): Let \(\gamma\) be a rectifiable curve in the plane with length \(L\). Let \(n(\gamma \cap \ell)\) denote the number of intersections of \(\gamma\) with a line \(\ell\). Then:

\[\int_{\text{lines } \ell} n(\gamma \cap \ell) \, d\mu(\ell) = 4L\]

where \(d\mu\) is the kinematic density on lines (invariant measure).

Proof Sketch

The proof proceeds in several steps. First, one establishes that the integral is additive over curve segments. Then it suffices to prove the formula for a straight line segment. For a segment of length \(L\), parameterize lines by distance \(p\) from origin and angle \(\theta\) with the x-axis. The kinematic density is \(d\mu = dp \, d\theta\). A line at distance \(p\) and angle \(\theta\) intersects the segment if and only if \(p\) lies in an interval of length \(L|\sin(\theta - \phi)|\) where \(\phi\) is the segment's angle. Integrating over all angles gives:

\[\int_0^{2\pi} L|\sin(\theta - \phi)| \, d\theta = 4L\]

The general result follows by approximation and additivity.

Notation Guide

  • \(d\mu\): Kinematic density (invariant measure)
  • \(V_j(K)\): \(j\)-th intrinsic volume of convex body \(K\)
  • \(W_j(K)\): \(j\)-th quermassintegral
  • \(G(n, k)\): Grassmannian of \(k\)-dimensional subspaces of \(\mathbb{R}^n\)
  • \(\chi(K)\): Euler characteristic
  • \(\text{Isom}(n)\): Group of rigid motions in \(\mathbb{R}^n\)

import numpy as np

class IntegralGeometry:
    """Integral geometry computations."""
    
    @staticmethod
    def buffon_needle_simulation(n_trials, needle_length, line_spacing):
        """Simulate Buffon's needle problem."""
        y_centers = np.random.uniform(0, line_spacing, n_trials)
        angles = np.random.uniform(0, np.pi/2, n_trials)
        y_low = y_centers - (needle_length / 2) * np.sin(angles)
        y_high = y_centers + (needle_length / 2) * np.sin(angles)
        crossings = np.sum((y_low < 0) | (y_high > line_spacing))
        if crossings == 0:
            return float('inf'), 0
        estimated_pi = (2 * needle_length * n_trials) / (crossings * line_spacing)
        return estimated_pi, crossings

    print(f"Estimated π: {pi_est:.6f}")

Semigroup Theory: The Algebra of Partial Symmetries

semigroup-theory

Motivation

While groups capture reversible symmetries, semigroups model irreversible processes and partial symmetries. Every function between sets composes associatively, but only bijections have inverses—semigroups capture this broader structure. Applications range from automata theory and formal languages to partial differential equations (where solution operators form semigroups) and the algebraic theory of machines.

Definitions

  • Semigroup: A set \(S\) with an associative binary operation \(\cdot : S \times S \to S\).
  • Monoid: A semigroup with an identity element \(e\).
  • Inverse Semigroup: A semigroup where for every \(s \in S\), there exists a unique \(s^*\) such that \(ss^*s = s\) and \(s^*ss^* = s^*\).
  • Green's Relations: Equivalence relations \(\mathcal{L}, \mathcal{R}, \mathcal{J}, \mathcal{H}, \mathcal{D}\) characterizing semigroup structure.
  • Idempotent: An element \(e\) such that \(e^2 = e\).

Theorem: The Wagner-Preston Representation Theorem

Theorem (Wagner-Preston, 1952-1954): Every inverse semigroup is isomorphic to a semigroup of partial bijections on some set.

Proof Sketch

The proof constructs an embedding of \(S\) into \(\mathcal{I}(S)\). For each \(s \in S\), define a partial bijection \(\phi_s\) with domain \(s^*sS\) by \(\phi_s(t) = st\). The map \(\phi: s \mapsto \phi_s\) is an injective homomorphism.

Notation Guide

  • \(S^1\): Semigroup with identity adjoined
  • \(E(S)\): Set of idempotents in \(S\)
  • \(s^*\): Inverse of \(s\) in an inverse semigroup
  • \(\mathcal{I}(X)\): Symmetric inverse semigroup
  • \(\mathcal{L}, \mathcal{R}, \mathcal{H}, \mathcal{D}\): Green's relations

Python Code

from itertools import product, permutations, combinations

class SemigroupTheory:
    """Semigroup theory computations."""
    
    @staticmethod
    def full_transformation_semigroup(n):
        """Generate the full transformation semigroup T_n."""
        functions = list(product(range(n), repeat=n))
        def compose(f, g):
            return tuple(f[g[i]] for i in range(n))
        return functions, compose
    
    @staticmethod
    def symmetric_inverse_semigroup(n):
        """Generate the symmetric inverse semigroup I_n."""
        elements = []
        for k in range(n + 1):
            for domain in combinations(range(n), k):
                for codomain in combinations(range(n), k):
                    for perm in permutations(codomain):
                        elements.append(dict(zip(domain, perm)))
        def compose(f, g):
            return {x: f[g[x]] for x in g if g[x] in f}
        def inverse(f):
            return {v: k for k, v in f.items()}
        return elements, compose, inverse

    T2, compose_T2 = st.full_transformation_semigroup(2)
    print(f"T_2 has {len(T2)} elements")

Wavelets: Mathematical Microscopes for Signal Analysis

wavelets

Real-World Motivation

Fourier analysis decomposes signals into pure frequencies, but loses all time information. Wavelets solve this by using localized basis functions that can "zoom in" on short-lived features. Developed in the 1980s, wavelets revolutionized signal processing, image compression (JPEG 2000), and data analysis. Applications include noise reduction, edge detection, and seismic data processing.

Definitions

  • Mother Wavelet: A function \(\psi \in L^2(\mathbb{R})\) with zero mean and usually compact support.
  • Daughter Wavelets: \(\psi_{a,b}(t) = \frac{1}{\sqrt{|a|}} \psi\left(\frac{t-b}{a}\right)\) where \(a > 0\) is scale and \(b\) is position.
  • Continuous Wavelet Transform: \(W_f(a, b) = \int_{-\infty}^{\infty} f(t) \overline{\psi_{a,b}(t)} \, dt\)
  • Admissibility Condition: \(C_\psi = \int_{0}^{\infty} \frac{|\hat{\psi}(\omega)|^2}{\omega} \, d\omega < \infty\)

Theorem: Wavelet Inversion Formula

Theorem: If \(\psi\) satisfies the admissibility condition, then for any \(f \in L^2(\mathbb{R})\):

\[f(t) = \frac{1}{C_\psi} \int_{0}^{\infty} \int_{-\infty}^{\infty} W_f(a, b) \, \psi_{a,b}(t) \, \frac{db \, da}{a^2}\]

Python Code

import numpy as np

class WaveletAnalysis:
    """Wavelet analysis and transforms."""
    
    @staticmethod
    def haar_wavelet(t):
        """The Haar wavelet."""
        result = np.zeros_like(t)
        result[(t >= 0) & (t < 0.5)] = 1
        result[(t >= 0.5) & (t < 1)] = -1
        return result
    
    @staticmethod
    def discrete_wavelet_transform(signal_data, levels=3):
        """Simple DWT using Haar wavelet."""
        coeffs = {'approximation': [], 'details': []}
        current = signal_data.copy()
        for level in range(levels):
            if len(current) % 2 == 1:
                current = current[:-1]
            low_pass = (current[0::2] + current[1::2]) / np.sqrt(2)
            high_pass = (current[0::2] - current[1::2]) / np.sqrt(2)
            coeffs['details'].append(high_pass)
            current = low_pass
        coeffs['approximation'] = current
        return coeffs


# Demonstration
if __name__ == "__main__":
    wa = WaveletAnalysis()
    t = np.linspace(0, 10, 1024)
    signal_clean = np.sin(2 * np.pi * 2 * t)
    coeffs = wa.discrete_wavelet_transform(signal_clean, levels=3)
    print(f"Approximation: {len(coeffs['approximation'])} coefficients")

Geometric Measure Theory: Measuring Irregular Sets

geometric-measure-theory

Real-World Motivation

How do you measure the length of a coastline? The answer depends on your ruler—smaller rulers reveal more detail. Geometric measure theory provides tools to study such irregular sets rigorously. Applications include image segmentation, minimal surface theory, and phase transitions in materials.

Definitions

  • Hausdorff Measure: \(\mathcal{H}^s(A) = \lim_{\delta \to 0} \inf\{\sum_i (\text{diam } U_i)^s : A \subset \bigcup_i U_i, \text{diam } U_i < \delta\}\)
  • Hausdorff Dimension: \(\dim_H(A) = \inf\{s : \mathcal{H}^s(A) = 0\}\)
  • Rectifiable Set: A set coverable by countably many Lipschitz images of \(\mathbb{R}^k\).

Python Code

import numpy as np

class GeometricMeasureTheory:
    """Geometric measure theory computations."""
    
    @staticmethod
    def box_counting_dimension(points, n_scales=20):
        """Estimate box-counting dimension of a point set."""
        mins = np.min(points, axis=0)
        maxs = np.max(points, axis=0)
        size = np.max(maxs - mins)
        scales = np.logspace(-3, 0, n_scales) * size
        counts = []
        for epsilon in scales:
            grid_indices = np.floor((points - mins) / epsilon).astype(int)
            unique_boxes = len(set(map(tuple, grid_indices)))
            counts.append(unique_boxes)
        log_scales = np.log(1 / scales)
        log_counts = np.log(counts)
        coeffs = np.polyfit(log_scales, log_counts, 1)
        return coeffs[0]

Toric Varieties: Geometry from Combinatorics

toric-varieties

Real-World Motivation

Toric varieties provide a bridge between algebraic geometry and combinatorics, allowing complex geometric problems to be solved using polyhedral geometry. Applications include mirror symmetry, integer programming, and chemical reaction networks.

Definitions

  • Algebraic Torus: \((\mathbb{C}^*)^n\)
  • Lattice Cone: \(\sigma = \{\sum_{v \in S} \lambda_v v : \lambda_v \geq 0\}\)
  • Dual Cone: \(\sigma^\vee = \{u : \langle u, v \rangle \geq 0 \text{ for all } v \in \sigma\}\)
  • Fan: A collection of cones closed under intersections and faces.

Theorem: Orbit-Cone Correspondence

Theorem: There is a bijection between cones in \(\Sigma\) and \((\mathbb{C}^*)^n\)-orbits in \(X_\Sigma\).

Python Code

import numpy as np

class ToricGeometry:
    """Toric geometry computations."""
    
    @staticmethod
    def projective_space_fan(n):
        """Generate the normal fan for projective space P^n."""
        rays = []
        for i in range(n):
            r = [0] * n
            r[i] = 1
            rays.append(r)
        rays.append([-1] * n)
        maximal_cones = [[rays[j] for j in range(n + 1) if j != i] 
                        for i in range(n + 1)]
        return rays, maximal_cones

Abelian Varieties: Higher-Dimensional Elliptic Curves

abelian-varieties

Historical Context

Abelian varieties emerged from the study of abelian integrals in the 19th century. Abel and Jacobi discovered that integrals of algebraic functions give rise to multi-periodic functions. In modern formulation, an abelian variety is a projective algebraic group. Elliptic curves are the one-dimensional case.

Definitions

  • Abelian Variety: A complete algebraic variety with compatible group structure.
  • Isogeny: A surjective homomorphism with finite kernel.
  • Dual Abelian Variety: \(\hat{A} = \text{Pic}^0(A)\)
  • Theta Divisor: A principal polarization.

Theorem: The Theorem of the Cube

Theorem (Weil): Let \(X, Y, Z\) be complete varieties with base points. If a line bundle on \(X \times Y \times Z\) is trivial on three coordinate hyperplanes, it is trivial.

Finsler Geometry: Beyond Riemannian Metrics

Finsler geometry generalizes Riemannian geometry by allowing the length of a tangent vector to depend on both its direction and position in a non-quadratic way. Named after Paul Finsler (1918).

📜 Math History: The Birth of Modern Algebra

The transformation of algebra from a collection of problem-solving techniques into a unified mathematical discipline occurred over several centuries, culminating in the 19th century with the work of mathematicians like Évariste Galois, Arthur Cayley, and Richard Dedekind.

In the early 19th century, algebra meant primarily the theory of equations. Mathematicians sought formulas for solving polynomial equations of higher degree, building on the 16th-century Italian solutions for cubics and quartics. The quintic equation resisted all attempts until the young French mathematician Évariste Galois provided the definitive solution using what we now call Galois theory.

Galois's insight was revolutionary: instead of focusing on the roots themselves, study the permutations of roots that preserve algebraic relations. This group of permutations, now called the Galois group, determines whether a polynomial is solvable by radicals. Tragically, Galois died in a duel at age 20 in 1832, before his work could be properly recognized.

Meanwhile, Arthur Cayley was developing matrix algebra and abstract group theory. In 1854, he defined abstract groups by their multiplication tables. Richard Dedekind, in 1871, introduced the modern concept of an ideal, revolutionizing algebraic number theory. His abstract approach set the stage for Emmy Noether's 1921 foundation of modern commutative algebra.

🧩 Problem Corner

IMO Shortlist 2024 Problem N7

Problem: Let \(n\) be a positive integer. A sequence \(a_1, a_2, \ldots, a_n\) of positive integers is called \textit{good} if for each \(k \in \{1, 2, \ldots, n\}\), the number \(a_k\) equals the number of indices \(i\) with \(a_i = k\).

Determine all positive integers \(n\) for which there exists a good sequence of length \(n\).

Hint

Consider what constraints the definition imposes on the sum of the sequence. If \(a_k\) counts occurrences of \(k\), what does \(\sum_{k=1}^n a_k\) represent?

Solution

Answer: Good sequences exist if and only if \(n = 1\) or \(n \geq 4\) with \(n \neq 2, 3\). More precisely, they exist for \(n = 1\) and all \(n \geq 4\).

Proof: The constraints are \(\sum_{k=1}^n a_k = n\) and \(\sum_{k=1}^n k \cdot a_k = n\). For \(n = 1\), the sequence \((1)\) works. For \(n = 2, 3\), no solution exists with positive integers. For \(n \geq 4\), explicit constructions exist using the fact that we can have \(a_1 = n-2\), \(a_2 = 1\), \(a_{n-2} = 1\), and other entries zero (with appropriate adjustments).

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the function \(f_c(z) = z^2 + c\) does not diverge when iterated from \(z = 0\). It is one of the most famous examples of a fractal, exhibiting infinite complexity at every scale.

The boundary of the Mandelbrot set has Hausdorff dimension 2, making it a curve that fills space in a certain sense. The set is connected, and its interior consists of infinitely many cardioid-like and circular components.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until divergence."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.show()
