Symmetric Functions and Schur Polynomials

symmetric-functions

Motivation

Symmetric functions encode deep structural information about algebraic systems. They appear in representation theory (characters of symmetric and general linear groups), algebraic geometry (cohomology of Grassmannians), and combinatorics (enumeration of plane partitions). The ring of symmetric functions provides a unified framework for understanding classical results in these areas, with Schur polynomials serving as the fundamental basis that connects algebraic, geometric, and combinatorial phenomena.

Definitions

  • Symmetric Function: A formal power series \(f(x_1, x_2, \ldots) \in \mathbb{Q}[[x_1, x_2, \ldots]]\) invariant under any permutation of variables.
  • Partition: A weakly decreasing sequence \(\lambda = (\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_k > 0)\) of positive integers. We write \(|\lambda| = \sum_i \lambda_i\).
  • Young Diagram: The left-justified array of boxes with \(\lambda_i\) boxes in row \(i\).
  • Semistandard Young Tableau (SSYT): A filling of a Young diagram with positive integers that weakly increase along rows and strictly increase down columns.
  • Schur Polynomial: For a partition \(\lambda\) with at most \(n\) parts: \[s_\lambda(x_1, \ldots, x_n) = \sum_{T \in SSYT(\lambda)} x^T\] where \(x^T = \prod_i x_i^{\text{(number of } i\text{'s in } T)}\).

Theorem: The Jacobi-Trudi Identity

Theorem: For any partition \(\lambda = (\lambda_1, \ldots, \lambda_k)\), the Schur polynomial can be expressed as a determinant of complete homogeneous symmetric functions \(h_m\):

\[s_\lambda = \det(h_{\lambda_i - i + j})_{1 \leq i, j \leq k}\]

where \(h_m = 0\) for \(m < 0\) and \(h_0 = 1\). Equivalently, in terms of elementary symmetric functions \(e_m\):

\[s_{\lambda'} = \det(e_{\lambda_i - i + j})_{1 \leq i, j \leq k}\]

where \(\lambda'\) is the conjugate partition.

Proof Sketch

The proof uses the Lindström-Gessel-Viennot lemma on non-intersecting lattice paths. Consider lattice paths from \(A_i = (-i, i)\) to \(B_j = (\lambda_j - j, \infty)\). The generating function for paths from \(A_i\) to \(B_j\) is \(h_{\lambda_j - j + i}\). The non-intersecting condition corresponds to semistandard Young tableaux of shape \(\lambda\). The determinant formula counts these non-intersecting path families, giving the Schur polynomial.

Alternatively, one can use the bialternant formula: \[s_\lambda(x_1, \ldots, x_n) = \frac{\det(x_i^{\lambda_j + n - j})_{i,j}}{\det(x_i^{n-j})_{i,j}} = \frac{a_{\lambda + \delta}}{a_\delta}\] where \(a_\mu\) is the alternant \(\sum_{w \in S_n} \text{sgn}(w) x^{w(\mu)}\) and \(\delta = (n-1, n-2, \ldots, 0)\). Expanding this ratio yields the determinant formula.

Notation Guide

  • \(\lambda \vdash n\): \(\lambda\) is a partition of \(n\)
  • \(\lambda'\): Conjugate partition (transpose of Young diagram)
  • \(h_m\): Complete homogeneous symmetric function of degree \(m\)
  • \(e_m\): Elementary symmetric function of degree \(m\)
  • \(s_\lambda\): Schur function indexed by partition \(\lambda\)
  • \(\Lambda\): Ring of symmetric functions

Python Implementation

import itertools
from fractions import Fraction
from collections import Counter

def partitions_of_n(n):
    """Generate all partitions of n in reverse lexicographic order."""
    if n == 0:
        yield ()
        return
    for k in range(1, n + 1):
        for rest in partitions_of_n(n - k):
            if not rest or k >= rest[0]:
                yield (k,) + rest

def conjugate_partition(lambda_):
    """Compute the conjugate partition."""
    if not lambda_:
        return ()
    result = []
    for i in range(lambda_[0]):
        count = sum(1 for part in lambda_ if part > i)
        result.append(count)
    return tuple(result)

def semistandard_young_tableaux(lambda_, max_entry=None):
    """Generate all SSYT of shape lambda."""
    if not lambda_:
        yield {}
        return
    if max_entry is None:
        max_entry = sum(lambda_)
    cells = [(i, j) for i in range(len(lambda_)) for j in range(lambda_[i])]
    
    def is_valid_fill(shape, fill):
        rows = len(shape)
        for i in range(rows):
            for j in range(shape[i]):
                if j > 0 and fill[(i, j)] < fill[(i, j-1)]:
                    return False
                if i > 0 and j < shape[i-1] and fill[(i, j)] <= fill[(i-1, j)]:
                    return False
        return True
    
    def backtrack(idx, current_fill):
        if idx == len(cells):
            if is_valid_fill(lambda_, current_fill):
                yield dict(current_fill)
            return
        i, j = cells[idx]
        min_val = 1
        if j > 0:
            min_val = current_fill[(i, j-1)]
        if i > 0 and j < lambda_[i-1]:
            min_val = max(min_val, current_fill[(i-1, j)] + 1)
        for val in range(min_val, max_entry + 1):
            current_fill[(i, j)] = val
            yield from backtrack(idx + 1, current_fill)
            del current_fill[(i, j)]
    
    yield from backtrack(0, {})

def schur_polynomial(lambda_, variables):
    """Compute the Schur polynomial s_lambda."""
    n = len(variables)
    result = Counter()
    for tableau in semistandard_young_tableaux(lambda_, max_entry=n):
        exponents = [0] * n
        for (i, j), val in tableau.items():
            exponents[val - 1] += 1
        result[tuple(exponents)] += 1
    return dict(result)

# Example

variables = ['x', 'y', 'z']

Class Field Theory: The Theory of Abelian Extensions

class-field-theory

Motivation

Class field theory is one of the major achievements of 20th-century mathematics, providing a complete description of all abelian extensions of number fields and function fields. It generalizes the Kronecker-Weber theorem (which states that every abelian extension of \(\mathbb{Q}\) is contained in a cyclotomic field) to arbitrary number fields.

Theorem: The Main Theorem of Class Field Theory

Theorem: Let \(K\) be a number field and \(\mathfrak{m}\) a modulus.

  1. Existence: For every open subgroup \(H\) of \(C_K\) of finite index, there exists a unique abelian extension \(L/K\) with \(N_{L/K}(C_L) = H\).
  2. Artin Reciprocity: For any abelian \(L/K\): \(C_K / N_{L/K}(C_L) \cong \text{Gal}(L/K)\)

Python Implementation

import math

def euler_phi(n):
    """Euler's totient function."""
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

def kronecker_weber_extension(n):
    """Abelian extension Q(ζ_n)/Q."""
    return {
        'conductor': n,
        'degree': euler_phi(n),
        'galois_group': f"(Z/{n}Z)^×",
        'description': f"Q(ζ_{n})"
    }

print("Class Field Theory: Kronecker-Weber Theorem")
print("=" * 50)
for n in [3, 4, 5, 7, 8, 12]:
    ext = kronecker_weber_extension(n)
    print(f"n = {n}: {ext['description']}, degree = {ext['degree']}")

Graph Neural Networks: Learning on Structured Data

graph-neural-networks

Real-World Motivation

Many real-world datasets have natural graph structure: social networks, molecular structures, traffic networks, and knowledge graphs. GNNs generalize deep learning to non-Euclidean domains.

Theorem: Universal Approximation for GNNs

Theorem: Let \(f: \mathcal{G} \to \mathbb{R}^d\) be a continuous graph isomorphism-invariant function. For any \(\epsilon > 0\), there exists a message-passing GNN such that \(\|f(G) - \text{GNN}(G)\| < \epsilon\).

Python Implementation

import numpy as np

class Graph:
    def __init__(self, num_nodes, edges, features=None):
        self.n = num_nodes
        self.edges = edges
        self.adj = np.zeros((num_nodes, num_nodes))
        for u, v in edges:
            self.adj[u, v] = self.adj[v, u] = 1
        self.features = features or np.eye(num_nodes)
    
    def normalized_laplacian(self):
        A_tilde = self.adj + np.eye(self.n)
        D = np.sum(A_tilde, axis=1)
        D_inv_sqrt = np.diag(1.0 / np.sqrt(D + 1e-8))
        return D_inv_sqrt @ A_tilde @ D_inv_sqrt

class GCNLayer:
    def __init__(self, input_dim, output_dim):
        self.W = np.random.randn(input_dim, output_dim) * 0.01
        self.b = np.zeros(output_dim)
    
    def forward(self, X, A_tilde):
        return np.maximum(A_tilde @ X @ self.W + self.b, 0)

# Example
edges = [(0, 1), (0, 2), (1, 2), (2, 3)]
graph = Graph(4, edges, np.random.randn(4, 8))
layer = GCNLayer(8, 16)
output = layer.forward(graph.features, graph.normalized_laplacian())
print(f"GNN output shape: {output.shape}")

Auction Theory: Strategic Bidding and Mechanism Design

auction-theory

Theorem: The Revenue Equivalence Theorem

Theorem: For any efficient auction where the item goes to the highest valuation bidder and \(v=0\) bidders pay nothing, the expected revenue is the same for all such mechanisms.

\[\mathbb{E}[p_i(v_i)] = \int_0^{\bar{v}} y_i(v) \phi_i(v) f_i(v) dv\]

Python Implementation

import numpy as np
from scipy.stats import uniform

class Auction:
    def __init__(self, n_bidders, dist):
        self.n = n_bidders
        self.dist = dist
    
    def simulate(self, trials=50000):
        revenues = []
        for _ in range(trials):
            values = self.dist.rvs(self.n)
            winner, payment = self.run_auction(values)
            revenues.append(payment)
        return np.mean(revenues)

class FirstPriceAuction(Auction):
    def run_auction(self, values):
        bids = [(self.n - 1) / self.n * v for v in values]
        winner = np.argmax(bids)
        return winner, bids[winner]

class SecondPriceAuction(Auction):
    def run_auction(self, values):
        winner = np.argmax(values)
        sorted_vals = np.sort(values)[::-1]
        return winner, sorted_vals[1] if len(sorted_vals) > 1 else 0

# Compare
n = 5
dist = uniform(0, 1)
fp = FirstPriceAuction(n, dist)
sp = SecondPriceAuction(n, dist)
print("Auction Theory: Revenue Equivalence")
print("=" * 50)
print(f"First-price revenue: {fp.simulate():.4f}")
print(f"Second-price revenue: {sp.simulate():.4f}")
print("\nBoth converge to the same expected revenue!")

Epidemic Modeling: From SIR to Network Dynamics

epidemic-modeling

Theorem: Final Size Relation

Theorem: In the SIR model, the final epidemic size \(R_\infty\) satisfies: \[R_\infty = S_0 \left(1 - e^{-R_0 \cdot R_\infty / N}\right)\]

Python Implementation

import numpy as np
from scipy.integrate import odeint
from scipy.optimize import fsolve

class SIRModel:
    def __init__(self, beta, gamma, N):
        self.beta = beta
        self.gamma = gamma
        self.N = N
        self.R0 = beta * N / gamma
    
    def derivatives(self, state, t):
        S, I, R = state
        dSdt = -self.beta * S * I
        dIdt = self.beta * S * I - self.gamma * I
        dRdt = self.gamma * I
        return [dSdt, dIdt, dRdt]
    
    def final_size(self):
        def equation(R_inf):
            return R_inf - self.N * (1 - np.exp(-self.R0 * R_inf / self.N))
        return fsolve(equation, self.N * 0.5)[0]

# Example
N = 10000
beta = 0.0000004
gamma = 0.1
sir = SIRModel(beta, gamma, N)

print("=" * 50)
print(f"R₀ = {sir.R0:.2f}")
print(f"Herd immunity threshold: {(1 - 1/sir.R0)*100:.1f}%")
print(f"Final size: {sir.final_size():.0f} ({sir.final_size()/N*100:.1f}%)")

Surreal Numbers: A Universe of Numbers

surreal-numbers

Theorem: The Simplicity Theorem

Theorem: If \(L\) and \(R\) are sets of surreal numbers with every element of \(L\) less than every element of \(R\), then there exists a unique simplest surreal number \(x = \{L | R\}\) satisfying \(L < x < R\).

Python Implementation

from fractions import Fraction

class SurrealNumber:
    def __init__(self, left=None, right=None, birthday=0):
        self.left = set(left) if left else set()
        self.right = set(right) if right else set()
        self.birthday = birthday
        self._value = None
    
    def _get_value(self):
        if self._value is None:
            self._value = self._compute_value()
        return self._value
    
    def _compute_value(self):
        if not self.left and not self.right:
            return Fraction(0)
        left_max = max((x._get_value() for x in self.left), default=None) if self.left else None
        right_min = min((x._get_value() for x in self.right), default=None) if self.right else None
        if left_max is None:
            return Fraction(0) if right_min > 0 else right_min - 1
        if right_min is None:
            return Fraction(0) if left_max < 0 else left_max + 1
        if left_max < 0 < right_min:
            return Fraction(0)
        return (left_max + right_min) / 2
    
    def __str__(self):
        return f"Surreal({self._get_value()})"

# Create basic surreals
zero = SurrealNumber(set(), set(), 0)
one = SurrealNumber({zero}, set(), 1)
minus_one = SurrealNumber(set(), {zero}, 1)

print("Surreal Numbers")
print("=" * 50)
print(f"0 = {zero}")
print(f"1 = {one}")
print(f"-1 = {minus_one}")
print("\nAll real numbers are surreal numbers!")

from itertools import permutations, combinations

def contains_pattern(pi, sigma):
    """Check if pi contains sigma as a pattern."""
    n, k = len(pi), len(sigma)
    if k > n:
        return False
    for indices in combinations(range(n), k):
        subseq = [pi[i] for i in indices]
        if same_relative_order(subseq, sigma):

def same_relative_order(seq, pattern):
    """Check if seq has same relative order as pattern."""
    def rank_order(s):
        sorted_s = sorted(s)
        return [sorted_s.index(x) for x in s]
    return rank_order(seq) == rank_order(pattern)

Matroid Theory: Abstraction of Independence

matroid-theory

Theorem: The Matroid Greedy Algorithm Optimality

Theorem: The greedy algorithm finds a maximum-weight basis for any weight function if and only if the structure is a matroid.

Python Implementation

class Matroid:
    def __init__(self, ground_set):
        self.E = frozenset(ground_set)
    
    def is_independent(self, subset):
        raise NotImplementedError
    
    def greedy_basis(self, weights):
        sorted_elements = sorted(self.E, key=lambda e: weights.get(e, 0), reverse=True)
        basis = set()
        for e in sorted_elements:
            if self.is_independent(basis | {e}):
                basis.add(e)
        return basis

class UniformMatroid(Matroid):
    def __init__(self, n, r):
        super().__init__(set(range(n)))
        self.r = r
    
    def is_independent(self, subset):
        return len(subset) <= self.r

📜 Math History

The Birth of Modern Algebra: From Cardano to Galois

The solution of polynomial equations stands as one of the great threads in mathematical history, weaving through Renaissance Italy, Enlightenment Europe, and Revolutionary France. In 1545, Gerolamo Cardano published "Ars Magna," containing the formula for solving cubic equations—a result he learned from Niccolò Tartaglia under an oath of secrecy. The quartic formula followed shortly after, discovered by Cardano's student Lodovico Ferrari.

For nearly three centuries, mathematicians sought a quintic formula. The breakthrough came from two young geniuses working independently. In 1824, Niels Henrik Abel, a Norwegian mathematician who died at 26, proved that no general solution exists for quintic equations using radicals. This settled a question that had tantalized mathematicians since the Renaissance.

But the deeper understanding came from Évariste Galois, who was killed in a duel at age 20 in 1832. Galois's revolutionary insight was to associate a group (now called the Galois group) with each polynomial equation. The structure of this group determines whether the equation is solvable by radicals. A polynomial is solvable by radicals if and only if its Galois group is a solvable group—a concept that Galois himself defined.

Galois's work, published posthumously by Joseph Liouville in 1846, laid the foundation for group theory and modern abstract algebra. What began as a search for formulas became the study of symmetry and structure, transforming mathematics forever. The Galois correspondence between field extensions and subgroups remains a cornerstone of algebra, connecting number theory, geometry, and algebra in profound ways.

🎯 Problem Corner

IMO Shortlist Problem

Problem: Let \(n\) be a positive integer. A sequence of integers \(a_1, a_2, \ldots, a_n\) is called good if:

  • \(a_1 + a_2 + \cdots + a_n = 0\)
  • \(|a_i| \leq i\) for all \(i = 1, 2, \ldots, n\)

Determine the number of good sequences.

Hint

Consider the transformation \(b_i = a_i + i\). What constraints does this place on \(b_i\)? How does the sum condition translate?

Solution

Define \(b_i = a_i + i\). Then \(0 \leq b_i \leq 2i\) and: \[\sum_{i=1}^n b_i = \sum_{i=1}^n a_i + \sum_{i=1}^n i = 0 + \frac{n(n+1)}{2} = \frac{n(n+1)}{2}\]

Let \(c_i = b_i - (i-1)\) for \(i \geq 1\) (with \(c_1 = b_1\)). Then \(c_i \geq 0\) and we need: \[\sum_{i=1}^n c_i = \frac{n(n+1)}{2} - \sum_{i=1}^n (i-1) = \frac{n(n+1)}{2} - \frac{n(n-1)}{2} = n\]

The constraints become \(0 \leq c_i \leq i+1\). Using stars and bars with inclusion-exclusion, the number of solutions is: \[\binom{2n-1}{n-1} - \binom{2n-1}{n-2} = \frac{1}{n+1}\binom{2n}{n} = C_n\]

the \(n\)-th Catalan number!

The Mandelbrot Set: Boundary of Chaos

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) (starting with \(z_0 = 0\)) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the whole set.

The main cardioid and period-2 bulb are the largest components, but infinitely many smaller bulbs exist, each corresponding to different periodic behaviors. The set is connected, but its boundary has Hausdorff dimension 2, making it a fractal of remarkable complexity.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until escape."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create a grid of complex numbers
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
plt.show()
