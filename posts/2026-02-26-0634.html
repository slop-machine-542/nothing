Sheaf Cohomology: Measuring Global Obstructions

Motivation: In topology and geometry, we often want to understand global properties of spaces by studying local data. Sheaf cohomology provides the precise language for measuring when local data can be patched together globally. It unifies diverse areas including algebraic geometry, complex analysis, and differential geometry.

Definitions

  • Presheaf: A contravariant functor \\(\\mathcal{F}: \\text{Open}(X)^{op} \\to \\text{Ab}\\) assigning an abelian group to each open set.
  • Sheaf: A presheaf satisfying the gluing axiom: compatible local sections glue uniquely to a global section.
  • Stalk: \\(\\mathcal{F}_x = \\varinjlim_{U \\ni x} \\mathcal{F}(U)\\), the colimit over neighborhoods of \\(x\\).
  • Sheaf Cohomology: The right derived functors \\(H^i(X, \\mathcal{F}) = R^i\\Gamma(X, \\mathcal{F})\\) of the global section functor.

Theorem: Leray's Theorem

Theorem: Let \\(\\mathcal{U} = \\{U_i\\}_{i \\in I}\\) be an open cover of \\(X\\) such that \\(H^q(U_{i_0} \\cap \\cdots \\cap U_{i_p}, \\mathcal{F}) = 0\\) for all \\(q > 0\\) and all finite intersections. Then: \\[H^p(\\mathcal{U}, \\mathcal{F}) \\cong H^p(X, \\mathcal{F})\\] where \\(H^p(\\mathcal{U}, \\mathcal{F})\\) denotes \\v{C}ech cohomology.

Proof Sketch: The proof constructs a double complex from the \\v{C}ech resolution and the injective resolution of \\(\\mathcal{F}\\). The acyclicity condition ensures that the spectral sequence degenerates, yielding the isomorphism. Key steps involve:

  1. Constructing the \\v{C}ech complex \\(\\check{C}^\\bullet(\\mathcal{U}, \\mathcal{F})\\)
  2. Showing that acyclic sheaves have trivial higher cohomology
  3. Applying the spectral sequence of a double complex
  4. Using the fact that \\v{C}ech cohomology agrees with derived functor cohomology for acyclic covers

Notation Guide

  • \\(\\Gamma(X, \\mathcal{F})\\): Global sections of \\(\\mathcal{F}\\)
  • \\(H^i(X, \\mathcal{F})\\): i-th sheaf cohomology group
  • \\(\\mathcal{F}|_U\\): Restriction of \\(\\mathcal{F}\\) to \\(U\\)
  • \\(\\check{H}^p(\\mathcal{U}, \\mathcal{F})\\): \\v{C}ech cohomology

import numpy as np
from itertools import combinations

class SheafCohomology:
    """
    Simplified model for computing sheaf cohomology on a simplicial complex.
    """
    def __init__(self, simplices, sections):
        """
        simplices: list of sets representing open sets
        sections: dict mapping simplex index to abelian group of sections
        """
        self.simplices = simplices
        self.sections = sections
        self.n = len(simplices)
    
    def intersection(self, indices):
        """Compute intersection of simplices."""
        if not indices:
            return set()
        result = self.simplices[indices[0]]
        for i in indices[1:]:
            result = result.intersection(self.simplices[i])
        return result
    
    def cech_boundary(self, cochain, p):
        """
        Compute the \\v{C}ech coboundary operator.
        delta: C^p -> C^{p+1}
        """
        result = {}
        for indices, value in cochain.items():
            for i in range(self.n):
                if i not in indices:
                    new_indices = tuple(sorted(indices + (i,)))
                    sign = (-1)**sum(1 for j in indices if j < i)
                    if new_indices not in result:
                        result[new_indices] = 0
                    result[new_indices] += sign * value
        return result
    
    def compute_cohomology_rank(self, p):
        """
        Compute rank of p-th cohomology group (simplified).
        Returns dimension of H^p = ker(delta^p) / im(delta^{p-1})
        """
        # This is a simplified demonstration
        # Real computation requires linear algebra over the section groups
        print(f"Computing H^{p} for sheaf with {self.n} open sets")
        return max(0, self.n - p - 1)  # Simplified placeholder

Hodge Theory: Harmonic Forms and Topology

Motivation: Hodge theory establishes a profound connection between analysis (solutions to differential equations) and topology (the shape of spaces). It shows that on compact Riemannian manifolds, every cohomology class has a unique harmonic representative, providing a powerful bridge between differential geometry and algebraic topology.

Definitions

  • Riemannian Metric: A smooth family of inner products \\(g_p: T_pM \\times T_pM \\to \\mathbb{R}\\) on the tangent spaces.
  • Hodge Star: The operator \\(*: \\Omega^k(M) \\to \\Omega^{n-k}(M)\\) defined by \\(\\alpha \\wedge *\\beta = \\langle \\alpha, \\beta \\rangle \\text{vol}\\).
  • Codifferential: \\(\\delta = (-1)^{n(k+1)+1} * d *: \\Omega^k(M) \\to \\Omega^{k-1}(M)\\).
  • Laplacian: \\(\\Delta = d\\delta + \\delta d: \\Omega^k(M) \\to \\Omega^k(M)\\).
  • Harmonic Form: A form \\(\\omega\\) with \\(\\Delta \\omega = 0\\).

Theorem: Hodge Decomposition Theorem

Theorem: Let \\(M\\) be a compact oriented Riemannian manifold. Then: \\[\\Omega^k(M) = \\mathcal{H}^k(M) \\oplus \\text{im}(d) \\oplus \\text{im}(\\delta)\\] where \\(\\mathcal{H}^k(M) = \\ker(\\Delta)\\) is the space of harmonic k-forms. Moreover: \\[H^k_{dR}(M) \\cong \\mathcal{H}^k(M)\\] giving a canonical isomorphism between de Rham cohomology and harmonic forms.

Proof Sketch: The proof relies on elliptic operator theory:

  1. Show that \\(\\Delta\\) is an elliptic, self-adjoint operator
  2. Use the theory of elliptic operators: \\(\\ker(\\Delta)\\) is finite-dimensional
  3. Prove the orthogonal decomposition using integration by parts
  4. Show that \\(\\ker(\\Delta) = \\ker(d) \\cap \\ker(\\delta)\\)
  5. Establish that each cohomology class has a unique harmonic representative

Notation Guide

  • \\(\\Omega^k(M)\\): Space of smooth k-forms on \\(M\\)
  • \\(\\mathcal{H}^k(M)\\): Space of harmonic k-forms
  • \\(H^k_{dR}(M)\\): k-th de Rham cohomology group
  • \\(*\\): Hodge star operator
  • \\(\\langle \\cdot, \\cdot \\rangle\\): Inner product on forms

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import eigsh

class HodgeTheory:
    """
    Computational Hodge theory on simplicial complexes.
    """
    def __init__(self, vertices, edges, faces=None):
        """
        vertices: list of vertex coordinates
        edges: list of (i,j) pairs
        faces: list of (i,j,k) triples (optional)
        """
        self.vertices = np.array(vertices)
        self.edges = edges
        self.faces = faces or []
        self.n_vertices = len(vertices)
        self.n_edges = len(edges)
        self.n_faces = len(self.faces)
    
    def build_boundary_operators(self):
        """Build boundary operator matrices."""
        # d_0: C_0 -> C_1 (vertex to edge)
        d0 = np.zeros((self.n_edges, self.n_vertices))
        for i, (v1, v2) in enumerate(self.edges):
            d0[i, v1] = -1
            d0[i, v2] = 1
        
        # d_1: C_1 -> C_2 (edge to face)
        if self.n_faces > 0:
            d1 = np.zeros((self.n_faces, self.n_edges))
            for i, (v1, v2, v3) in enumerate(self.faces):
                # Find edges in the face
                e1 = self.edges.index(tuple(sorted([v1, v2])))
                e2 = self.edges.index(tuple(sorted([v2, v3])))
                e3 = self.edges.index(tuple(sorted([v3, v1])))
                d1[i, e1] = 1
                d1[i, e2] = 1
                d1[i, e3] = 1
        else:
            d1 = np.zeros((1, self.n_edges))
        
        return d0, d1
    
    def hodge_laplacian_0(self):
        """Compute 0-form Laplacian (graph Laplacian)."""
        d0, _ = self.build_boundary_operators()
        # L_0 = d_0^T d_0
        return d0.T @ d0
    
    def hodge_laplacian_1(self):
        """Compute 1-form Laplacian."""
        d0, d1 = self.build_boundary_operators()
        # L_1 = d_0 d_0^T + d_1^T d_1
        return d0 @ d0.T + d1.T @ d1
    
    def harmonic_0_forms(self):
        """Find harmonic 0-forms (kernel of L_0)."""
        L0 = self.hodge_laplacian_0()
        eigenvalues, eigenvectors = np.linalg.eigh(L0)
        # Harmonic forms correspond to zero eigenvalues
        harmonic_mask = np.abs(eigenvalues) < 1e-10
        return eigenvectors[:, harmonic_mask]
    
    def betti_numbers(self):
        """Compute Betti numbers using Hodge theory."""
        L0 = self.hodge_laplacian_0()
        L1 = self.hodge_laplacian_1()
        
        eigenvalues_0 = np.linalg.eigvalsh(L0)
        eigenvalues_1 = np.linalg.eigvalsh(L1)
        
        b0 = np.sum(np.abs(eigenvalues_0) < 1e-10)
        b1 = np.sum(np.abs(eigenvalues_1) < 1e-10)
        
        return b0, b1

Scheme Theory: Modern Algebraic Geometry

Motivation: Scheme theory, developed by Alexander Grothendieck in the 1960s, revolutionized algebraic geometry by providing a unified framework that incorporates both classical algebraic varieties and arithmetic geometry. Schemes allow us to study solutions to polynomial equations over any ring, not just fields, enabling powerful new techniques in number theory and geometry.

Definitions

  • Affine Scheme: \\(\\text{Spec}(A)\\), the set of prime ideals of a commutative ring \\(A\\), equipped with the Zariski topology and structure sheaf.
  • Structure Sheaf: For an affine scheme \\(\\text{Spec}(A)\\), \\(\\mathcal{O}_{\\text{Spec}(A)}(D(f)) = A_f\\), the localization of \\(A\\) at \\(f\\).
  • Scheme: A locally ringed space \\((X, \\mathcal{O}_X)\\) that is locally isomorphic to an affine scheme.
  • Morphism of Schemes: A morphism of locally ringed spaces \\((f, f^\\#): (X, \\mathcal{O}_X) \\to (Y, \\mathcal{O}_Y)\\).

Theorem: Serre's GAGA

Theorem (Géométrie Algébrique et Géométrie Analytique): Let \\(X\\) be a proper scheme over \\(\\mathbb{C}\\). The functor \\(\\mathcal{F} \\mapsto \\mathcal{F}^{an}\\) from coherent algebraic sheaves on \\(X\\) to coherent analytic sheaves on \\(X^{an}\\) is an equivalence of categories. Moreover: \\[H^i(X, \\mathcal{F}) \\cong H^i(X^{an}, \\mathcal{F}^{an})\\] for all \\(i \\geq 0\\).

Significance: This theorem establishes a deep connection between algebraic and analytic geometry, showing that for proper varieties, the algebraic and analytic categories are essentially equivalent.

Notation Guide

  • \\(\\text{Spec}(A)\\): Spectrum of ring \\(A\\)
  • \\(\\mathfrak{p}\\): Prime ideal
  • \\(A_f\\): Localization of \\(A\\) at \\(f\\)
  • \\(\\mathcal{O}_X\\): Structure sheaf of scheme \\(X\\)
  • \\(X^{an}\\): Analytification of \\(X\\)

        """
        Zariski closed sets are V(I) = {p in Spec(A) : I subset of p}.

        topology = {}
        for ideal in self.prime_ideals:
            # V(ideal) = all primes containing ideal
            closed_set = [p for p in self.prime_ideals 
                         if all(g in p for g in ideal)]

                return 'Z[1/2] (integers with 2 inverted)'
            elif open_set == 'D(6)':

Neural Network Theory: Universal Approximation and Optimization

Motivation: Deep learning has revolutionized artificial intelligence, but understanding why neural networks work so well requires deep mathematical analysis. The theory connects approximation theory, optimization, and statistical learning to explain the remarkable success of neural networks in practice.

Definitions

  • Neural Network: A function \\(f_\\theta: \\mathbb{R}^d \\to \\mathbb{R}^k\\) composed of layers \\(f(x) = W_L \\sigma(W_{L-1} \\sigma(\\cdots \\sigma(W_1 x + b_1) \\cdots ) + b_{L-1}) + b_L\\).
  • Activation Function: A non-linear function \\(\\sigma: \\mathbb{R} \\to \\mathbb{R}\\) (e.g., ReLU \\(\\sigma(x) = \\max(0, x)\\), sigmoid).
  • Loss Function: \\(L(\\theta) = \\mathbb{E}_{(x,y) \\sim \\mathcal{D}}[\\ell(f_\\theta(x), y)]\\) measuring prediction error.
  • Gradient Descent: \\(\\theta_{t+1} = \\theta_t - \\eta \\nabla L(\\theta_t)\\), iterative optimization algorithm.

Theorem: Universal Approximation Theorem

Theorem (Cybenko, 1989; Hornik, 1991): Let \\(\\sigma\\) be a non-constant, bounded, continuous activation function. For any compact \\(K \\subset \\mathbb{R}^d\\), any continuous \\(f: K \\to \\mathbb{R}\\), and any \\(\\epsilon > 0\\), there exists a single-hidden-layer neural network \\(f_\\theta\\) such that: \\[\\sup_{x \\in K} |f(x) - f_\\theta(x)| < \\epsilon\\]

Proof Sketch: The proof uses the Hahn-Banach theorem and properties of the Fourier transform:

  1. Show that the set of neural network functions is dense in \\(C(K)\\)
  2. Use the Riesz representation theorem: if the closure weren't all of \\(C(K)\\), there would exist a non-zero measure \\(\\mu\\) orthogonal to all neural networks
  3. Show that \\(\\int \\sigma(w \\cdot x + b) d\\mu(x) = 0\\) for all \\(w, b\\) implies \\(\\mu = 0\\)
  4. This uses the properties of \\(\\sigma\\) and the Fourier transform

Notation Guide

  • \\(W_l\\): Weight matrix at layer \\(l\\)
  • \\(b_l\\): Bias vector at layer \\(l\\)
  • \\(\\sigma\\): Activation function (applied element-wise)
  • \\(\\theta = \\{(W_l, b_l)\\}\\): Network parameters
  • \\(\\eta\\): Learning rate

import numpy as np
import matplotlib.pyplot as plt

class NeuralNetwork:
    """
    Simple fully-connected neural network.
    """
    def __init__(self, layer_sizes):
        """
        layer_sizes: list of layer dimensions [input, hidden1, ..., output]
        """
        self.layer_sizes = layer_sizes
        self.num_layers = len(layer_sizes)
        self.params = self._initialize_params()
    
    def _initialize_params(self):
        """Initialize weights with Xavier initialization."""
        params = {}
        for i in range(1, self.num_layers):
            # Xavier initialization: variance = 2 / (n_in + n_out)
            scale = np.sqrt(2.0 / (self.layer_sizes[i-1] + self.layer_sizes[i]))
            params[f'W{i}'] = np.random.randn(self.layer_sizes[i], self.layer_sizes[i-1]) * scale
            params[f'b{i}'] = np.zeros((self.layer_sizes[i], 1))
        return params
    
    def relu(self, x):
        """ReLU activation: max(0, x)"""
        return np.maximum(0, x)
    
    def relu_derivative(self, x):
        """Derivative of ReLU."""
        return (x > 0).astype(float)
    
    def forward(self, x):
        """Forward pass through the network."""
        cache = {'A0': x}
        a = x
        for i in range(1, self.num_layers):
            z = self.params[f'W{i}'] @ a + self.params[f'b{i}']
            if i < self.num_layers - 1:
                a = self.relu(z)
            else:
                a = z  # Linear output
            cache[f'Z{i}'] = z
            cache[f'A{i}'] = a
        return a, cache
    
    def backward(self, y, cache):
        """Backward pass (backpropagation)."""
        m = y.shape[1]
        grads = {}
        
        # Output layer gradient
        da = cache[f'A{self.num_layers-1}'] - y
        
        for i in range(self.num_layers - 1, 0, -1):
            dz = da if i == self.num_layers - 1 else da * self.relu_derivative(cache[f'Z{i}'])
            grads[f'dW{i}'] = (1/m) * dz @ cache[f'A{i-1}'].T
            grads[f'db{i}'] = (1/m) * np.sum(dz, axis=1, keepdims=True)
            da = self.params[f'W{i}'].T @ dz
        
        return grads
    
    def update_params(self, grads, learning_rate):
        """Gradient descent update."""
        for i in range(1, self.num_layers):
            self.params[f'W{i}'] -= learning_rate * grads[f'dW{i}']
            self.params[f'b{i}'] -= learning_rate * grads[f'db{i}']
    
    def train(self, X, y, epochs=1000, learning_rate=0.01, verbose=True):
        """Train the network."""
        losses = []
        for epoch in range(epochs):
            # Forward pass
            output, cache = self.forward(X)
            
            # Compute loss (MSE)
            loss = np.mean((output - y) ** 2)
            losses.append(loss)
            
            # Backward pass
            grads = self.backward(y, cache)
            
            # Update parameters
            self.update_params(grads, learning_rate)
            
            if verbose and epoch % 100 == 0:
                print(f"Epoch {epoch}: Loss = {loss:.6f}")
        
        return losses

Epidemiological Modeling: SIR and Beyond

Motivation: Mathematical epidemiology provides crucial tools for understanding and controlling infectious diseases. The COVID-19 pandemic demonstrated the vital importance of mathematical models in public health decision-making, from predicting hospital capacity needs to evaluating intervention strategies.

Definitions

  • SIR Model: Compartmental model dividing population into Susceptible (S), Infected (I), and Recovered (R).
  • Basic Reproduction Number \\(\\mathcal{R}_0\\): Expected number of secondary infections from one infected individual in a fully susceptible population.
  • Force of Infection: \\(\\lambda = \\beta I / N\\), the rate at which susceptible individuals become infected.
  • SEIR Model: Extension with Exposed (E) compartment for latent period.

Theorem: Threshold Theorem

Theorem (Kermack-McKendrick): For the SIR model with initial conditions \\(S(0) \\approx N\\), \\(I(0) > 0\\) small:

  1. If \\(\\mathcal{R}_0 \\leq 1\\), the disease dies out: \\(I(t) \\to 0\\) as \\(t \\to \\infty\\).
  2. If \\(\\mathcal{R}_0 > 1\\), an epidemic occurs with final size \\(R_\\infty\\) satisfying: \\[R_\\infty = 1 - e^{-\\mathcal{R}_0 R_\\infty}\\]

Proof Sketch: From the SIR equations: \\[\\frac{dI}{dS} = -1 + \\frac{\\gamma}{\\beta S}\\] Integrating from \\(S_0\\) to \\(S_\\infty\\): \\[I_\\infty - I_0 = -(S_\\infty - S_0) + \\frac{\\gamma}{\\beta} \\ln\\frac{S_\\infty}{S_0}\\] Since \\(I_\\infty = 0\\) and \\(S_0 \\approx N\\), we obtain the final size relation.

Notation Guide

  • \\(\\beta\\): Transmission rate
  • \\(\\gamma\\): Recovery rate
  • \\(\\mathcal{R}_0 = \\beta / \\gamma\\): Basic reproduction number
  • \\(N = S + I + R\\): Total population
  • \\(S_\\infty, R_\\infty\\): Final susceptible and recovered fractions

    SIR epidemiological model.
    """

        """
        beta: transmission rate
        gamma: recovery rate
        N: total population
        """
        self.beta = beta
        self.gamma = gamma
        self.N = N

    def deriv(self, y, t):
        """
        SIR differential equations.
        dS/dt = -beta * S * I / N
        dI/dt = beta * S * I / N - gamma * I
        dR/dt = gamma * I
        """
        S, I, R = y
        dSdt = -self.beta * S * I / self.N
        dIdt = self.beta * S * I / self.N - self.gamma * I
        dRdt = self.gamma * I
        return [dSdt, dIdt, dRdt]
    
    def solve(self, S0, I0, R0, t):
        """Solve the SIR model."""
        y0 = [S0, I0, R0]
        solution = odeint(self.deriv, y0, t)
        return solution
    
    def final_size(self):
        """
        Compute final epidemic size using the implicit equation:
        R_inf = 1 - exp(-R0 * R_inf)
        """
        from scipy.optimize import fsolve
        def equation(R_inf):
            return R_inf - (1 - np.exp(-self.R0 * R_inf))
        
        R_inf = fsolve(equation, 0.5)[0]
        return R_inf
    
    def herd_immunity_threshold(self):
        """Compute herd immunity threshold: 1 - 1/R0."""
        if self.R0 <= 1:
            return 0
        return 1 - 1 / self.R0
    
    def peak_infection(self, S0, I0):
        """
        Compute peak infection time and magnitude.
        Peak occurs when S = gamma/beta = N/R0.
        """
        S_peak = self.N / self.R0
        if S0 <= S_peak:
            return 0, I0  # Already past peak
        
        # I_peak = I0 + S0 - S_peak + (gamma/beta) * ln(S_peak/S0)
        I_peak = I0 + S0 - S_peak + (self.gamma/self.beta) * np.log(S_peak/S0)
        return S_peak, I_peak

class SEIRModel(SIRModel):
    """
    SEIR model with exposed (latent) compartment.
    """
    def __init__(self, beta, gamma, sigma, N):
        """
        sigma: rate of progression from exposed to infected
        """
        super().__init__(beta, gamma, N)
        self.sigma = sigma
    
    def deriv(self, y, t):
        """
        SEIR differential equations.
        """
        S, E, I, R = y
        dSdt = -self.beta * S * I / self.N
        dEdt = self.beta * S * I / self.N - self.sigma * E
        dIdt = self.sigma * E - self.gamma * I
        dRdt = self.gamma * I
        return [dSdt, dEdt, dIdt, dRdt]
    
    def solve(self, S0, E0, I0, R0, t):
        """Solve the SEIR model."""
        y0 = [S0, E0, I0, R0]
        solution = odeint(self.deriv, y0, t)
        return solution

Portfolio Optimization: Modern Portfolio Theory

Motivation: Harry Markowitz's Modern Portfolio Theory (MPT), for which he received the 1990 Nobel Prize in Economics, revolutionized investment management by providing a mathematical framework for constructing optimal portfolios. The theory quantifies the trade-off between risk and return, enabling rational investment decisions.

Definitions

  • Portfolio: A vector \\(w \\in \\mathbb{R}^n\\) where \\(w_i\\) is the weight of asset \\(i\\), with \\(\\sum_i w_i = 1\\).
  • Expected Return: \\(\\mu_w = w^T \\mu = \\sum_i w_i \\mu_i\\) where \\(\\mu_i = \\mathbb{E}[R_i]\\).
  • Portfolio Variance: \\(\\sigma_w^2 = w^T \\Sigma w = \\sum_{i,j} w_i w_j \\sigma_{ij}\\) where \\(\\Sigma\\) is the covariance matrix.
  • Sharpe Ratio: \\(S = \\frac{\\mu_w - r_f}{\\sigma_w}\\), measuring risk-adjusted return.
  • Efficient Frontier: The set of portfolios maximizing expected return for a given level of risk.

Theorem: Two-Fund Theorem

Theorem: Any portfolio on the efficient frontier can be constructed as a linear combination of any two distinct efficient portfolios (funds). Specifically, if \\(w_1\\) and \\(w_2\\) are efficient portfolios, then: \\[w_\\alpha = \\alpha w_1 + (1-\\alpha) w_2\\] is also efficient for any \\(\\alpha \\in \\mathbb{R}\\).

Proof Sketch: The efficient frontier is characterized by solving: \\[\\min_w \\frac{1}{2} w^T \\Sigma w \\quad \\text{s.t.} \\quad w^T \\mu = \\mu_0, \\quad w^T \\mathbf{1} = 1\\] Using Lagrange multipliers: \\[\\mathcal{L} = \\frac{1}{2} w^T \\Sigma w - \\lambda_1(w^T \\mu - \\mu_0) - \\lambda_2(w^T \\mathbf{1} - 1)\\] The solution \\(w^* = \\lambda_1 \\Sigma^{-1} \\mu + \\lambda_2 \\Sigma^{-1} \\mathbf{1}\\) shows that all efficient portfolios lie in the two-dimensional subspace spanned by \\(\\Sigma^{-1} \\mu\\) and \\(\\Sigma^{-1} \\mathbf{1}\\).

Notation Guide

  • \\(\\mu\\): Vector of expected returns
  • \\(\\Sigma\\): Covariance matrix of returns
  • \\(w\\): Portfolio weight vector
  • \\(r_f\\): Risk-free rate
  • \\(\\sigma_w\\): Portfolio standard deviation (risk)

import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

class PortfolioOptimizer:
    """
    Modern Portfolio Theory implementation.
    """
    def __init__(self, expected_returns, cov_matrix, risk_free_rate=0.02):
        """
        expected_returns: array of expected returns for each asset
        cov_matrix: covariance matrix of returns
        risk_free_rate: risk-free rate (annual)
        """
        self.mu = np.array(expected_returns)
        self.Sigma = np.array(cov_matrix)
        self.n_assets = len(expected_returns)
        self.rf = risk_free_rate
    
    def portfolio_return(self, weights):
        """Calculate portfolio expected return."""
        return np.dot(weights, self.mu)
    
    def portfolio_variance(self, weights):
        """Calculate portfolio variance."""
        return np.dot(weights.T, np.dot(self.Sigma, weights))
    
    def portfolio_risk(self, weights):
        """Calculate portfolio standard deviation."""
        return np.sqrt(self.portfolio_variance(weights))
    
    def sharpe_ratio(self, weights):
        """Calculate Sharpe ratio."""
        excess_return = self.portfolio_return(weights) - self.rf
        return excess_return / self.portfolio_risk(weights)
    
    def min_variance_portfolio(self):
        """Find minimum variance portfolio."""
        constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        bounds = tuple((0, 1) for _ in range(self.n_assets))
        x0 = np.array([1.0/self.n_assets] * self.n_assets)
        
        result = minimize(self.portfolio_variance, x0,
                         method='SLSQP', bounds=bounds, constraints=constraints)
        return result.x
    
    def max_sharpe_portfolio(self):
        """Find maximum Sharpe ratio portfolio."""
        def neg_sharpe(w):
            return -self.sharpe_ratio(w)
        
        constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        bounds = tuple((0, 1) for _ in range(self.n_assets))
        x0 = np.array([1.0/self.n_assets] * self.n_assets)
        
        result = minimize(neg_sharpe, x0,
                         method='SLSQP', bounds=bounds, constraints=constraints)
        return result.x
    
    def efficient_frontier(self, n_points=100):
        """Generate efficient frontier."""
        target_returns = np.linspace(self.mu.min(), self.mu.max(), n_points)
        efficient_portfolios = []
        
        for target in target_returns:
            # Minimize variance subject to target return
            constraints = [
                {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
                {'type': 'eq', 'fun': lambda w: self.portfolio_return(w) - target}
            ]
            bounds = tuple((0, 1) for _ in range(self.n_assets))
            x0 = np.array([1.0/self.n_assets] * self.n_assets)
            
            result = minimize(self.portfolio_variance, x0,
                            method='SLSQP', bounds=bounds, constraints=constraints)
            
            if result.success:
                efficient_portfolios.append({
                    'return': target,
                    'risk': self.portfolio_risk(result.x),
                    'weights': result.x
                })
        
        return efficient_portfolios

Fermat's Last Theorem: From Diophantus to Wiles

Historical Context: In 1637, Pierre de Fermat wrote in the margin of his copy of Diophantus' Arithmetica that he had a "truly marvelous proof" that the equation \\(a^n + b^n = c^n\\) has no solutions in positive integers for \\(n > 2\\). This simple statement became the most famous unsolved problem in mathematics for over 350 years, until Andrew Wiles announced his proof in 1993.

Definitions

  • Fermat Equation: \\(x^n + y^n = z^n\\) for integers \\(n \\geq 3\\).
  • Elliptic Curve: A smooth cubic curve with a group structure, typically written as \\(y^2 = x^3 + ax + b\\).
  • Modular Form: A holomorphic function on the upper half-plane satisfying specific transformation properties under \\(\\text{SL}(2, \\mathbb{Z})\\).
  • Frey Curve: An elliptic curve \\(y^2 = x(x - a^n)(x + b^n)\\) associated to a hypothetical Fermat solution.

Theorem: Fermat's Last Theorem

Theorem (Wiles, 1995): For any integer \\(n \\geq 3\\), there are no positive integers \\(a, b, c\\) such that: \\[a^n + b^n = c^n\\]

Proof Strategy: Wiles proved the semistable case of the Taniyama-Shimura-Weil conjecture (now the modularity theorem):

  1. Assume a counterexample \\(a^p + b^p = c^p\\) exists for prime \\(p \\geq 5\\)
  2. Frey (1984) constructed an associated elliptic curve with unusual properties
  3. Ribet (1986) proved that this curve would not be modular
  4. Wiles (1995) proved that all semistable elliptic curves are modular
  5. Contradiction! Therefore no counterexample exists

Notation Guide

  • \\(\\mathbb{H}\\): Upper half-plane \\(\\{z \\in \\mathbb{C} : \\text{Im}(z) > 0\\}\\)
  • \\(\\Gamma_0(N)\\): Congruence subgroup of \\(\\text{SL}(2, \\mathbb{Z})\\)
  • \\(f(\\tau)\\): Modular form as function of \\(\\tau \\in \\mathbb{H}\\)
  • \\(L(E, s)\\): L-function of elliptic curve \\(E\\)

The Riemann Hypothesis: The Crown Jewel of Mathematics

Historical Context: In 1859, Bernhard Riemann published his only paper on number theory, "On the Number of Primes Less Than a Given Magnitude." In it, he introduced the Riemann zeta function and made a conjecture about the location of its non-trivial zeros. This hypothesis, now one of the seven Millennium Prize Problems, has profound implications for the distribution of prime numbers.

Definitions

  • Riemann Zeta Function: \\(\\zeta(s) = \\sum_{n=1}^\\infty \\frac{1}{n^s} = \\prod_p \\frac{1}{1-p^{-s}}\\) for \\(\\text{Re}(s) > 1\\).
  • Trivial Zeros: \\(\\zeta(-2n) = 0\\) for all positive integers \\(n\\).
  • Non-trivial Zeros: Zeros in the critical strip \\(0 < \\text{Re}(s) < 1\\).
  • Critical Line: The line \\(\\text{Re}(s) = \\frac{1}{2}\\).
  • Möbius Function: \\(\\mu(n)\\) is \\((-1)^k\\) if \\(n\\) is a product of \\(k\\) distinct primes, 0 otherwise.

Theorem: The Riemann Hypothesis

Conjecture (Riemann, 1859): All non-trivial zeros of the Riemann zeta function have real part equal to \\(\\frac{1}{2}\\). That is, if \\(\\zeta(s) = 0\\) with \\(0 < \\text{Re}(s) < 1\\), then: \\[\\text{Re}(s) = \\frac{1}{2}\\]

Equivalent Formulations:

  1. \\(\\pi(x) = \\text{Li}(x) + O(\\sqrt{x} \\log x)\\) where \\(\\pi(x)\\) counts primes \\(\\leq x\\)
  2. \\(\\sum_{n \\leq x} \\mu(n) = O(x^{1/2 + \\epsilon})\\) for all \\(\\epsilon > 0\\)
  3. The error term in the prime number theorem is minimal

Notation Guide

  • \\(\\zeta(s)\\): Riemann zeta function
  • \\(\\Gamma(s)\\): Gamma function (analytic continuation)
  • \\(\\xi(s)\\): Riemann xi function (symmetric version)
  • \\(\\text{Li}(x) = \\int_2^x \\frac{dt}{\\log t}\\): Logarithmic integral
  • \\(\\pi(x)\\): Prime counting function

The Langlands Program: A Grand Unified Theory of Mathematics

Historical Context: In 1967, Robert Langlands wrote a 17-page letter to André Weil outlining a series of conjectures that would revolutionize number theory and representation theory. The Langlands Program proposes deep connections between number theory, algebraic geometry, and harmonic analysis—often described as a "grand unified theory" of mathematics.

Definitions

  • Automorphic Form: A function on a Lie group satisfying specific invariance and growth conditions, generalizing modular forms.
  • Galois Representation: A homomorphism \\(\\rho: G_{\\mathbb{Q}} \\to \\text{GL}_n(\\overline{\\mathbb{Q}}_\\ell)\\) from the absolute Galois group.
  • L-function: A Dirichlet series \\(L(s, \\pi) = \\sum_{n=1}^\\infty \\frac{a_n}{n^s}\\) encoding arithmetic information.
  • Langlands Dual Group: For a reductive group \\(G\\), its dual \\(^LG\\) encodes representation-theoretic information.

Theorem: Local Langlands Correspondence

Theorem (Harris-Taylor, Henniart; Local Langlands): Let \\(F\\) be a non-archimedean local field (e.g., \\(\\mathbb{Q}_p\\)). There is a natural bijection between:

  1. Irreducible admissible representations of \\(\\text{GL}_n(F)\\)
  2. n-dimensional Frobenius-semisimple Weil-Deligne representations of the Weil group \\(W_F\\)
This correspondence preserves L-factors and \\(\\epsilon\\)-factors.

Significance: The Langlands Program encompasses:

  • Class field theory (abelian case, proven)
  • Modularity of elliptic curves (proven by Wiles et al.)
  • Functoriality principle (relating automorphic forms on different groups)
  • Geometric Langlands (connection to quantum field theory)

Notation Guide

  • \\(G_F = \\text{Gal}(\\overline{F}/F)\\): Absolute Galois group
  • \\(\\text{GL}_n\\): General linear group
  • \\(\\pi\\): Automorphic representation
  • \\(\\rho\\): Galois representation
  • \\(L(s, \\pi)\\): Automorphic L-function

def hecke_operator_fourier(n, fourier_coeffs):
    """
    Compute the action of the Hecke operator T_n on a modular form.
    For f(z) = sum_{m} a_m q^m, T_n f = sum_{m} b_m q^m where
    b_m = sum_{d|gcd(m,n)} d^{k-1} a_{mn/d^2}
    """
    result = {}
    max_m = len(fourier_coeffs)
    
    for m in range(1, max_m):
        b_m = 0
        # Sum over divisors of gcd(m, n)
        gcd_mn = sp.gcd(m, n)
        for d in sp.divisors(gcd_mn):
            idx = (m * n) // (d * d)
            if idx < max_m:
                b_m += d**(11) * fourier_coeffs.get(idx, 0)  # k=12 for Delta

The ABC Conjecture: Deep Connections in Diophantine Geometry

Historical Context: Proposed by Joseph Oesterlé and David Masser in 1985, the ABC conjecture is a simple-to-state but profound conjecture about the relationship between the prime factors of three integers satisfying \\(a + b = c\\). Despite its elementary appearance, it implies many famous theorems and conjectures in number theory, including Fermat's Last Theorem for sufficiently large exponents.

Definitions

  • Radical: For a positive integer \\(n\\), \\(\\text{rad}(n) = \\prod_{p|n} p\\), the product of distinct prime factors.
  • ABC Triple: A triple \\((a, b, c)\\) of coprime positive integers with \\(a + b = c\\).
  • Quality: \\(q(a, b, c) = \\frac{\\log c}{\\log \\text{rad}(abc)}\\).
  • ABC Conjecture: For any \\(\\epsilon > 0\\), there are only finitely many ABC triples with \\(q(a, b, c) > 1 + \\epsilon\\).

Theorem: Consequences of ABC

Theorem: If the ABC conjecture is true, then:

  1. Fermat's Last Theorem holds for all sufficiently large exponents \\(n\\)
  2. The Wieferich prime conjecture: there are infinitely many primes \\(p\\) with \\(2^{p-1} \\not\\equiv 1 \\pmod{p^2}\\)
  3. The Erdős–Woods conjecture about consecutive integers with restricted prime factors
  4. Roth's theorem on Diophantine approximation (with effective bounds)

Notation Guide

  • \\(\\text{rad}(n)\\): Radical of \\(n\\)

  • \\(q(a, b, c)\\): Quality of ABC triple

def abc_quality(a, b, c):
    """
    Compute the quality of an ABC triple (a, b, c).
    q(a,b,c) = log(c) / log(rad(abc))
    """
    if a + b != c:

IMO Shortlist Problem

Problem: Let \\(n\\) be a positive integer. A sequence \\(a_0, a_1, \\ldots, a_n\\) of integers is called good if it satisfies the following conditions:

  • \\(a_0 = 0\\)
  • For each \\(i\\) with \\(1 \\leq i \\leq n\\), we have \\(|a_i - a_{i-1}| = 1\\)
  • There do not exist indices \\(0 \\leq i < j < k \\leq n\\) such that \\(a_i = a_k\\) and \\(a_j = a_i + 1\\)

Determine the number of good sequences for a given \\(n\\).

💡 Hint

Consider the path interpretation: each good sequence corresponds to a walk on the integers starting at 0, taking steps of \\(\\pm 1\\), with a restriction on certain patterns. The third condition forbids a "peak" pattern where the walk goes up, then returns to the same level, then goes up again. This is related to Catalan-like counting. Try small cases: \\(n = 1, 2, 3, 4\\) and look for a pattern.

✅ Solution

The answer is the \\(n\\)-th Catalan number \\(C_n = \\frac{1}{n+1}\\binom{2n}{n}\\).

Proof:

First, we reinterpret the condition. The third condition says there is no pattern where we go from height \\(h\\) to \\(h+1\\), then return to \\(h\\), then go to \\(h+1\\) again. This is equivalent to saying that once we return to a level, we never exceed that level again.

Consider the partial sums \\(s_k = a_k\\). The condition implies that the sequence of maxima \\(M_k = \\max_{0 \\leq i \\leq k} a_i\\) is non-decreasing and increases by exactly 1 each time we set a new maximum.

We can establish a bijection with Dyck paths (paths from \\((0,0)\\) to \\((2n, 0)\\) using steps \\((1,1)\\) and \\((1,-1)\\) that never go below the x-axis). Given a good sequence, we construct a Dyck path by encoding \\(+1\\) steps as up-steps and \\(-1\\) steps as down-steps, but with a twist: we insert an up-step at the beginning and a down-step at the end, and modify the path to ensure it ends at 0.

Alternatively, we can verify that good sequences satisfy the same recurrence as Catalan numbers. Let \\(g_n\\) be the number of good sequences of length \\(n\\). For \\(n \\geq 1\\), consider the first return to 0 (if any). If the sequence never returns to 0 after starting, it must stay positive, and there's exactly one such sequence: \\(0, 1, 2, \\ldots, n\\). Otherwise, let \\(2k\\) be the first return time. The part before the return forms a good sequence of length \\(k\\) (shifted and scaled), and the part after forms a good sequence of length \\(n-k\\). This gives: \\[g_n = g_0 g_{n-1} + g_1 g_{n-2} + \\cdots + g_{n-1} g_0 + 1\\] where the \\(+1\\) accounts for the never-returning case. With \\(g_0 = 1\\), this is the Catalan recurrence.

Therefore, \\(g_n = C_n = \\frac{1}{n+1}\\binom{2n}{n}\\).

🎨 Visualization of the Day: Julia Sets

The Julia set is a fractal associated with complex dynamics. For a complex quadratic polynomial \\(f_c(z) = z^2 + c\\), the filled Julia set consists of points whose orbits remain bounded under iteration. The boundary of this set forms the Julia set itself—a fractal with intricate self-similar structure.

Unlike the Mandelbrot set (which lives in the parameter space), each Julia set corresponds to a specific parameter \\(c\\). When \\(c\\) is in the Mandelbrot set, the Julia set is connected; otherwise, it is a Cantor set of disconnected points.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def julia_set(c, xlim=(-2, 2), ylim=(-2, 2), resolution=800, max_iter=100):
    """
    Compute the Julia set for f(z) = z^2 + c.
    
    Parameters:
    -----------
    c : complex
        Complex parameter
    xlim, ylim : tuple
        Bounds for the complex plane
    resolution : int
        Number of points in each dimension
    max_iter : int
        Maximum number of iterations
    
    Returns:
    --------
    2D array of iteration counts
    """
    # Create grid of complex numbers
    x = np.linspace(xlim[0], xlim[1], resolution)
    y = np.linspace(ylim[0], ylim[1], resolution)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Initialize iteration count array
    iterations = np.zeros(Z.shape, dtype=int)
    mask = np.ones(Z.shape, dtype=bool)
    
    # Iterate
    for i in range(max_iter):
        # Only iterate points that haven't escaped yet
        Z[mask] = Z[mask]**2 + c
        
        # Check which points have escaped (|z| > 2)
        escaped = np.abs(Z) > 2
        
        # Record iteration count for newly escaped points
        new_escape = escaped & mask
        iterations[new_escape] = i
        
        # Update mask
        mask &= ~escaped
        
        # Stop if all points have escaped
        if not np.any(mask):
            break
    
    # Points that never escaped get max_iter
    iterations[mask] = max_iter
    
    return iterations
