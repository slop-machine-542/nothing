Sheaf Cohomology and the Geometry of Spaces

Motivation

Sheaf cohomology provides a powerful framework for studying the global properties of spaces using local data. Originating in complex analysis and algebraic geometry, it has become an essential tool across topology, differential geometry, and number theory.

Definitions

Presheaf: A presheaf \(mathcal{F}\) of abelian groups on a topological space \(X\) assigns to each open set \(U \subseteq X\) an abelian group \(mathcal{F}(U)\).

Sheaf: A presheaf is a sheaf if it satisfies local identity and gluing conditions.

Sheaf Cohomology: For a sheaf \(mathcal{F}\) on \(X\), the cohomology groups \(H^i(X, \mathcal{F})\) are the right derived functors of the global section functor.

Theorem (Leray)

If \(\mathfrak{U}\) is an acyclic cover, then \(\check{H}^p(\mathfrak{U}, \mathcal{F}) \cong H^p(X, \mathcal{F})\).

Python Code

import numpy as np
import matplotlib.pyplot as plt

class SimpleSheafCohomology:
    def __init__(self, vertices, simplices):
        self.vertices = vertices
        self.simplices = [set(s) for s in simplices]
        self.dim = max(len(s) for s in simplices) - 1
    
    def cohomology_dimensions(self):
        dims = []
        for p in range(self.dim + 1):
            d_p = self.coboundary_matrix(p)
            d_p_minus = self.coboundary_matrix(p - 1) if p > 0 else np.zeros((0, 0))
            ker_dim = d_p.shape[1] - np.linalg.matrix_rank(d_p) if d_p.size > 0 else len(self.get_p_simplices(p))
            im_dim = np.linalg.matrix_rank(d_p_minus) if d_p_minus.size > 0 else 0
            dims.append(ker_dim - im_dim)
        return dims

# Example: Sphere S^2
vertices = [0, 1, 2, 3]
simplices = [(0,), (1,), (2,), (3,), (0,1), (1,2), (0,2), (0,3), (1,3), (2,3), (0,1,2), (0,1,3), (0,2,3), (1,2,3)]
sc = SimpleSheafCohomology(vertices, simplices)
print(f"Cohomology: {sc.cohomology_dimensions()}")

Brownian Motion and Stochastic Processes

Motivation

Brownian motion, first observed by Robert Brown in 1827, has become one of the most important stochastic processes in mathematics. It serves as the foundation for stochastic calculus with applications in physics, finance, and biology.

Definitions

Standard Brownian Motion: A stochastic process with independent increments, stationary Gaussian increments, and continuous paths.

Theorem (Lévy's Characterization)

A continuous local martingale \(M\) with \(M_0 = 0\) is a standard Brownian motion if and only if \(\langle M \rangle_t = t\).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T, N, n_paths=5):
    dt = T / N
    t = np.linspace(0, T, N + 1)
    dB = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
    B = np.zeros((n_paths, N + 1))
    B[:, 1:] = np.cumsum(dB, axis=1)
    return t, B

t, B = simulate_brownian_motion(T=1.0, N=1000, n_paths=5)
plt.plot(t, B.T)
plt.title('Brownian Motion Paths')
plt.show()

Riemann Surfaces and Complex Geometry

Motivation

Riemann surfaces provide the natural geometric setting for complex analysis in one variable. They generalize the complex plane by allowing for multi-valued functions to become single-valued on branched covers.

Theorem (Riemann-Roch)

For a compact Riemann surface of genus \(g\): \(\ell(D) - \ell(K - D) = \deg(D) + 1 - g\)

🚀 Applied Math Deep-Dives

Kalman Filtering and State Estimation

Real-World Motivation

The Kalman filter, developed by Rudolf Kalman in 1960, powers GPS navigation, guides spacecraft, stabilizes drones, and enables autonomous vehicles.

Theorem (Kalman Filter Optimality)

The Kalman filter provides the minimum mean-square error estimate for linear Gaussian systems.

Python Code

import numpy as np

class KalmanFilter:
    def __init__(self, F, H, Q, R, x0, P0):
        self.F, self.H, self.Q, self.R = F, H, Q, R
        self.x, self.P = x0, P0
    
    def predict(self):
        self.x = self.F @ self.x
        self.P = self.F @ self.P @ self.F.T + self.Q
        return self.x
    
    def update(self, z):
        y = z - self.H @ self.x
        S = self.H @ self.P @ self.H.T + self.R
        K = self.P @ self.H.T @ np.linalg.inv(S)
        self.x = self.x + K @ y
        self.P = (np.eye(len(self.x)) - K @ self.H) @ self.P
        return self.x

Compressed Sensing and Sparse Recovery

Real-World Motivation

Compressed sensing enables faster MRI scans, single-pixel cameras, and efficient data compression by recovering sparse signals from far fewer measurements than required by the Nyquist-Shannon theorem.

Theorem (Exact Recovery)

If \(A\) satisfies RIP with \(\delta_{2k} < \sqrt{2} - 1\), then basis pursuit recovers the unique \(k\)-sparse solution.

Python Code

import numpy as np

def iterative_hard_thresholding(A, y, k, max_iter=100):
    n = A.shape[1]
    x = np.zeros(n)
    L = np.linalg.norm(A, 2)**2
    mu = 0.9 / L
    
    for _ in range(max_iter):
        x = x + mu * A.T @ (y - A @ x)
        idx = np.argsort(np.abs(x))[-k:]
        x_new = np.zeros(n)
        x_new[idx] = x[idx]
        x = x_new
    return x

Neural Ordinary Differential Equations

Real-World Motivation

Neural ODEs, introduced in 2018, reframe deep learning through continuous dynamical systems, offering memory efficiency and adaptive computation.

Theorem (Adjoint Sensitivity)

The gradient of the loss can be computed by solving a single backward ODE, avoiding storage of intermediate states.

Python Code

from scipy.integrate import solve_ivp

class NeuralODEFunction:
    def __init__(self, input_dim, hidden_dim):
        self.W1 = np.random.randn(hidden_dim, input_dim) * 0.1
        self.W2 = np.random.randn(input_dim, hidden_dim) * 0.1
    
    def f(self, h, t):
        return self.W2 @ np.tanh(self.W1 @ h)
    
    def forward(self, h0, t_span, t_eval):
        sol = solve_ivp(lambda t, h: self.f(h, t), t_span, h0, t_eval=t_eval)
        return sol.y.T

Class Field Theory

Class field theory provides a complete description of abelian extensions of number fields. The Artin reciprocity law states: \(Cl_\mathfrak{f}(K) / N_{L/K}(Cl_\mathfrak{f}(L)) \cong \text{Gal}(L/K)\)

Moduli Spaces

The Weierstrass Function

Weierstrass's function \(W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x)\) is continuous everywhere but differentiable nowhere.

📜 Math History: The Development of Modern Analysis

The 19th century witnessed a profound transformation in mathematics. Fourier's 1807 memoir on heat conduction introduced the revolutionary idea that arbitrary functions could be represented by trigonometric series. Cauchy provided the first rigorous definitions of limit, continuity, and convergence in 1821.

The most dramatic development came with Weierstrass's 1872 construction of a continuous, nowhere differentiable function. This pathological example shattered the intuition that continuous curves must have tangents at most points. Cantor's work on set theory and transfinite numbers established the existence of different sizes of infinity.

The culmination was the development of measure theory and the Lebesgue integral in the early 20th century, providing the foundation for functional analysis and modern PDE theory.

🎯 Problem Corner

Problem: Functional Equation (IMO Shortlist 2022)

Find all functions \(f : \mathbb{R}^+ \to \mathbb{R}^+\) such that \(f(x + f(y)) = f(x) + y\) for all \(x, y \in \mathbb{R}^+\).

💡 Hint

First, investigate injectivity. Then try to find a relationship by swapping variables or finding fixed points.

✅ Solution

Step 1: Suppose \(f(a) = f(b)\). Then \(f(x) + a = f(x + f(a)) = f(x + f(b)) = f(x) + b\), so \(a = b\). Thus \(f\) is injective.

Step 2: From the functional equation with \(x = f(y)\), we get \(f(f(y) + f(z)) = f(f(y)) + z\). By symmetry, \(f(f(y)) + z = f(f(z)) + y\), so \(f(f(x)) = x + c\) for some constant \(c\).

Step 3: Substituting back and using \(f(f(x)) = x\) (which follows from careful analysis), we find \(f(x + y) = f(x) + f(y)\).

Answer: The unique solution is \(f(x) = x\).

🎨 Visualization of the Day: The Lorenz Attractor

The Lorenz attractor is a set of chaotic solutions to the system:

\[\frac{dx}{dt} = \sigma(y - x), \quad \frac{dy}{dt} = x(\rho - z) - y, \quad \frac{dz}{dt} = xy - \beta z\]

Python Code

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def lorenz(state, sigma=10.0, rho=28.0, beta=8.0/3.0):
    x, y, z = state
    return np.array([sigma*(y-x), x*(rho-z)-y, x*y-beta*z])

# Integrate and plot
from scipy.integrate import solve_ivp
sol = solve_ivp(lambda t, y: lorenz(y), [0, 50], [1, 1, 1], 
                t_eval=np.linspace(0, 50, 5000))

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.plot(sol.y[0], sol.y[1], sol.y[2], linewidth=0.5)
ax.set_title('Lorenz Attractor')
plt.show()
