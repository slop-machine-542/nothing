Random Matrix Theory: Universality in the Spectrum

Tags: random-matrix-theory probability linear-algebra

Motivation

Random Matrix Theory (RMT) emerged from Eugene Wigner's work in nuclear physics during the 1950s. Wigner observed that the energy levels of heavy nuclei exhibit statistical patterns remarkably similar to the eigenvalues of random matrices. This discovery led to a profound insight: the statistical properties of complex quantum systems are universal, depending only on symmetry classes rather than specific details. Today, RMT finds applications in quantum chaos, number theory, wireless communications, and machine learning.

Definitions

A random matrix is a matrix whose entries are random variables drawn from a probability distribution. The Gaussian Unitary Ensemble (GUE) consists of \( n \times n \) Hermitian matrices with independent (up to symmetry) Gaussian entries.

The empirical spectral distribution of a matrix \( M \) with eigenvalues \( \lambda_1, \ldots, \lambda_n \) is the probability measure \( \mu_n = \frac{1}{n} \sum_{i=1}^n \delta_{\lambda_i} \).

The Wigner semicircle law describes the limiting distribution of eigenvalues for large Wigner matrices.

Theorem and Proof

Theorem (Wigner's Semicircle Law): Let \( M_n \) be an \( n \times n \) Wigner matrix with entries satisfying \( \mathbb{E}[M_{ij}] = 0 \), \( \mathbb{E}[|M_{ij}|^2] = 1/n \) for \( i \neq j \), and bounded higher moments. Then as \( n \to \infty \), the empirical spectral distribution converges weakly almost surely to the semicircle distribution with density:

\[ \rho(x) = \frac{1}{2\pi} \sqrt{4 - x^2} \cdot \mathbf{1}_{|x| \leq 2} \]

Notation Guide

  • \( M_n \) — \( n \times n \) random matrix
  • \( \lambda_i \) — eigenvalues of the matrix
  • \( \mu_n \) — empirical spectral distribution
  • \( \rho(x) \) — density of the limiting distribution
  • \( C_k \) — Catalan numbers
  • \( \text{tr} \) — matrix trace

Python Code

import numpy as np
import matplotlib.pyplot as plt

def generate_wigner_matrix(n, sigma=1.0):
    upper = np.random.normal(0, sigma/np.sqrt(n), size=(n, n))
    M = upper + upper.T
    np.fill_diagonal(M, np.random.normal(0, sigma*np.sqrt(2/n), size=n))
    return M

def semicircle_pdf(x):
    x = np.array(x)
    result = np.zeros_like(x, dtype=float)
    mask = np.abs(x) <= 2
    result[mask] = np.sqrt(4 - x[mask]**2) / (2 * np.pi)
    return result

# Generate and analyze Wigner matrices
n_values = [100, 500, 1000]
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

for idx, n in enumerate(n_values):
    all_eigenvalues = []
    for _ in range(50):
        M = generate_wigner_matrix(n)
        eigenvalues = np.linalg.eigvalsh(M)
        all_eigenvalues.extend(eigenvalues)
    
    axes[idx].hist(all_eigenvalues, bins=50, density=True, alpha=0.7, label=f'n={n}')
    x = np.linspace(-2.1, 2.1, 1000)
    axes[idx].plot(x, semicircle_pdf(x), 'r-', linewidth=2, label='Semicircle law')
    axes[idx].set_xlabel('Eigenvalue')
    axes[idx].set_ylabel('Density')
    axes[idx].legend()
    axes[idx].set_title(f'Wigner Matrix (n={n})')

plt.tight_layout()
plt.savefig('wigner_semicircle.png', dpi=150)
plt.show()

Stochastic Calculus: Itô's Lemma and SDEs

Tags: stochastic-calculus probability analysis

Motivation

Stochastic calculus extends ordinary calculus to handle random processes, most notably Brownian motion. Itô's calculus, developed by Kiyoshi Itô in the 1940s, provides the mathematical foundation for modern quantitative finance, statistical physics, and stochastic control.

Definitions

A standard Brownian motion \( W_t \) is a continuous stochastic process with \( W_0 = 0 \), independent increments, and \( W_t - W_s \sim \mathcal{N}(0, t-s) \) for \( t > s \).

Theorem and Proof

Theorem (Itô's Lemma): Let \( X_t \) be an Itô process and \( f \in C^{2,1}(\mathbb{R} \times [0, \infty)) \). Then \( Y_t = f(X_t, t) \) is also an Itô process, and:

\[ df(X_t, t) = \frac{\partial f}{\partial t} dt + \frac{\partial f}{\partial x} dX_t + \frac{1}{2} \frac{\partial^2 f}{\partial x^2} (dX_t)^2 \]

Python Code

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T, N, n_paths=5):
    dt = T / N
    t = np.linspace(0, T, N+1)
    dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
    W = np.zeros((n_paths, N+1))
    W[:, 1:] = np.cumsum(dW, axis=1)
    return t, W

# Simulate and plot Brownian motion
t, W = simulate_brownian_motion(T=1, N=1000, n_paths=5)
for i in range(5):
    plt.plot(t, W[i], alpha=0.7)
plt.xlabel('Time')
plt.ylabel('$W_t$')
plt.title('Standard Brownian Motion')
plt.grid(True, alpha=0.3)
plt.savefig('brownian_motion.png', dpi=150)
plt.show()

Operator Algebras: C*-Algebras and the Gelfand-Naimark Theorem

Tags: operator-algebras functional-analysis algebra

Motivation

Operator algebras provide a framework for studying infinite-dimensional linear algebra through the lens of topology. C*-algebras, introduced by Gelfand and Naimark in the 1940s, emerged from the study of algebras of bounded operators on Hilbert spaces.

Theorem and Proof

Theorem (Gelfand-Naimark): Every C*-algebra is isometrically *-isomorphic to a norm-closed *-subalgebra of \( \mathcal{B}(\mathcal{H}) \) for some Hilbert space \( \mathcal{H} \).

Python Code

import numpy as np

class CStarAlgebraElement:
    def __init__(self, matrix):
        self.matrix = np.array(matrix, dtype=complex)
        self.n = self.matrix.shape[0]
    
    def adjoint(self):
        return CStarAlgebraElement(self.matrix.conj().T)
    
    def norm(self):
        return np.linalg.norm(self.matrix, ord=2)

# Verify C*-identity: ||a* a|| = ||a||^2
A = np.random.randn(3, 3) + 1j * np.random.randn(3, 3)
a = CStarAlgebraElement(A)
a_star = a.adjoint()
a_star_a = a_star * a

print(f"||a* a|| = {a_star_a.norm():.6f}")
print(f"||a||^2 = {a.norm()**2:.6f}")

Optimal Transport: From Monge to Kantorovich

Tags: optimal-transport optimization analysis

Motivation

Optimal transport theory, originating with Monge in 1781 and revolutionized by Kantorovich in the 1940s, studies the most efficient way to move mass from one distribution to another.

Theorem and Proof

Theorem (Kantorovich Duality): For lower semicontinuous cost \( c \geq 0 \):

\[ \inf_{\pi \in \Pi(\mu, \nu)} \int c \, d\pi = \sup_{(\phi, \psi)} \left\{ \int \phi \, d\mu + \int \psi \, d\nu : \phi(x) + \psi(y) \leq c(x, y) \right\} \]

Python Code

import numpy as np
from scipy.optimize import linprog

def discrete_optimal_transport(mu, nu, cost_matrix):
    m, n = cost_matrix.shape
    c = cost_matrix.flatten()
    
    A_row = np.kron(np.eye(m), np.ones((1, n)))
    A_col = np.kron(np.ones((1, m)), np.eye(n))
    A_eq = np.vstack([A_row, A_col])
    b_eq = np.concatenate([mu, nu])
    
    bounds = [(0, None) for _ in range(m * n)]
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    plan = result.x.reshape(m, n)
    return plan, result.fun

# Example usage
mu = np.array([0.5, 0.5])
nu = np.array([0.3, 0.7])
C = np.array([[1, 2], [3, 1]])

plan, cost = discrete_optimal_transport(mu, nu, C)
print(f"Optimal cost: {cost:.4f}")
print(f"Transport plan:\n{plan}")

Reinforcement Learning: Bellman Equations and Q-Learning

Tags: reinforcement-learning machine-learning optimization

Theorem and Proof

Theorem (Bellman Optimality): The optimal value function \( V^* \) satisfies:

\[ V^*(s) = \max_a \sum_{s'} P(s'|s, a) [R(s, a, s') + \gamma V^*(s')] \]

Python Code

import numpy as np

def q_learning(env, n_episodes=1000, alpha=0.1, gamma=0.95, epsilon=0.1):
    Q = np.zeros((env.n_states, env.n_actions))
    
    for episode in range(n_episodes):
        state = env.reset()
        done = False
        
        while not done:
            if np.random.random() < epsilon:
                action = np.random.randint(env.n_actions)
            else:
                action = np.argmax(Q[state])
            
            next_state, reward, done = env.step(action)
            Q[state, action] += alpha * (reward + gamma * np.max(Q[next_state]) - Q[state, action])
            state = next_state
    
    return Q, np.argmax(Q, axis=1)

Computational Biology: Phylogenetic Tree Reconstruction

Tags: computational-biology statistics algorithms

Theorem and Proof

Theorem (Jukes-Cantor Distance Correction): Under the Jukes-Cantor model, if the observed fraction of differing sites is \( p \), then:

\[ d = -\frac{3}{4} \ln\left(1 - \frac{4p}{3}\right) \]

Python Code

import numpy as np

def jukes_cantor_distance(seq1, seq2):
    seq1, seq2 = np.array(seq1), np.array(seq2)
    p = np.mean(seq1 != seq2)
    
    if p >= 0.75:
        return np.inf
    if p == 0:
        return 0.0
    
    return -0.75 * np.log(1 - 4*p/3)

# Example
seq_a = np.random.choice(['A', 'C', 'G', 'T'], size=100)
seq_b = np.random.choice(['A', 'C', 'G', 'T'], size=100)
distance = jukes_cantor_distance(seq_a, seq_b)
print(f"Jukes-Cantor distance: {distance:.4f}")

📜 Math History: The Development of Modern Probability Theory

The modern theory of probability emerged from a curious blend of gambling problems and deep philosophical questions about chance and determinism. While games of chance have existed for millennia, a mathematical theory of probability only crystallized in the mid-17th century through the correspondence between Blaise Pascal and Pierre de Fermat.

The famous "problem of points" asked how to fairly divide the stakes in an interrupted game of chance. Suppose two players are flipping a coin, with the first to reach 10 points winning the pot. If the game is interrupted when one player has 7 points and the other 5, how should the money be divided? Pascal and Fermat's solution—counting the possible future outcomes and weighting them equally—established the foundation of mathematical expectation.

Christiaan Huygens published the first book on probability theory in 1657, "De Ratiociniis in Ludo Aleae" (On Reasoning in Games of Chance), systematizing these ideas. Jacob Bernoulli's "Ars Conjectandi" (1713) took a revolutionary step by extending probability beyond games of chance to what he called "civil, moral, and economic affairs." His Law of Large Numbers provided the theoretical justification for using observed frequencies to estimate underlying probabilities—a cornerstone of statistical inference.

The 18th century saw probability applied to demography, astronomy, and jurisprudence. Abraham de Moivre discovered the normal distribution as an approximation to the binomial, and Thomas Bayes posthumously published his theorem on inverse probability in 1763. The 19th century brought the work of Laplace, who applied probability to celestial mechanics and developed the method of least squares.

Yet probability remained somewhat mathematically suspect until the 20th century. David Hilbert's sixth problem called for axioms of probability, and Andrey Kolmogorov answered decisively in 1933 with his measure-theoretic foundations. By treating probability as a measure space with total measure 1, Kolmogorov connected probability to the rich theory of integration and functional analysis, enabling the rigorous development of stochastic processes.

Today, probability theory stands as one of mathematics' most vibrant fields, with applications spanning physics (quantum mechanics, statistical mechanics), biology (population genetics, epidemiology), economics (financial mathematics), computer science (machine learning, randomized algorithms), and engineering (signal processing, control theory). From Pascal's gambling problems to modern quantitative finance, the journey of probability theory illustrates how the deepest mathematics often emerges from the most practical questions.

🎯 Problem Corner

Putnam Competition Problem (1992 B6)

Four points are chosen independently and uniformly at random on the surface of a sphere. What is the probability that the center of the sphere lies inside the tetrahedron formed by these four points?

Hint

Consider the relationship between the center being inside the tetrahedron and the hemispheres determined by the points. Use symmetry and the fact that for any three points on a sphere, they determine a unique hemisphere containing them.

Solution

Answer: \( \frac{1}{8} \)

Solution: Let the four points be \( A, B, C, D \). The center \( O \) lies inside the tetrahedron \( ABCD \) if and only if the four points do not all lie on any hemisphere.

To see this: If all four points lie on some hemisphere, then there exists a plane through \( O \) with all points on one side, so \( O \) is outside the convex hull. Conversely, if \( O \) is outside the tetrahedron, there exists a separating plane through \( O \), placing all points on one hemisphere.

The probability that all four points lie on some closed hemisphere is \( \frac{7}{8} \) (a known result by Wendel, 1962). Therefore:

\[ P(O \text{ inside tetrahedron}) = 1 - \frac{7}{8} = \frac{1}{8} \]

The general formula for \( n \) random points on \( S^{d-1} \) is \( 2^{-n+1} \sum_{k=d}^{n-1} \binom{n-1}{k} \). For \( n=4, d=3 \), this gives \( \frac{1}{8} \). ∎

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is perhaps the most famous fractal in mathematics. It is defined as the set of complex numbers \( c \) for which the iteration \( z_{n+1} = z_n^2 + c \) with \( z_0 = 0 \) remains bounded.

Mathematical Definition

\[ \mathcal{M} = \{ c \in \mathbb{C} : \sup_{n \geq 0} |z_n| < \infty \text{ where } z_{n+1} = z_n^2 + c, z_0 = 0 \} \]

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate patterns, including miniature copies of the entire set.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until divergence."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid of complex numbers
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C, max_iter=80)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
plt.show()
