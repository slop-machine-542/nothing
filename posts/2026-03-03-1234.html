1. Commutative Algebra: Primary Decomposition

Motivation

Just as integers factor uniquely into primes, ideals in Noetherian rings admit a decomposition into primary ideals. This fundamental theorem, proved by Emmy Noether in 1921, generalizes the fundamental theorem of arithmetic and provides crucial structural information about rings. Primary decomposition is essential in algebraic geometry, where it corresponds to decomposing algebraic varieties into irreducible components.

Definitions

Let \(R\) be a commutative ring with unity.

  • Prime Ideal: An ideal \(\mathfrak{p}\) such that if \(ab \in \mathfrak{p}\), then \(a \in \mathfrak{p}\) or \(b \in \mathfrak{p}\).
  • Primary Ideal: An ideal \(\mathfrak{q}\) such that if \(ab \in \mathfrak{q}\) and \(a \notin \mathfrak{q}\), then \(b^n \in \mathfrak{q}\) for some \(n \geq 1\).
  • Radical of an Ideal: \(\sqrt{I} = \{r \in R : r^n \in I \text{ for some } n \geq 1\}\).
  • Noetherian Ring: A ring satisfying the ascending chain condition on ideals.

Theorem: Lasker-Noether Primary Decomposition

Theorem: Let \(R\) be a Noetherian ring and \(I\) a proper ideal of \(R\). Then there exist primary ideals \(\mathfrak{q}_1, \ldots, \mathfrak{q}_n\) such that:

\[I = \mathfrak{q}_1 \cap \mathfrak{q}_2 \cap \cdots \cap \mathfrak{q}_n\]

Moreover, if the decomposition is irredundant (no \(\mathfrak{q}_i\) contains the intersection of the others) and the radicals \(\mathfrak{p}_i = \sqrt{\mathfrak{q}_i}\) are distinct, then the set \(\{\mathfrak{p}_1, \ldots, \mathfrak{p}_n\}\) is uniquely determined.

Proof Sketch

Step 1: An ideal is irreducible if it cannot be written as the intersection of two strictly larger ideals. In a Noetherian ring, every ideal is a finite intersection of irreducible ideals (otherwise, construct an infinite ascending chain).

Step 2: Show that every irreducible ideal is primary. If \(\mathfrak{q}\) is irreducible and \(ab \in \mathfrak{q}\) with \(a \notin \mathfrak{q}\), consider the chain of ideals \((\mathfrak{q} : b) \subseteq (\mathfrak{q} : b^2) \subseteq \cdots\). By the ascending chain condition, \((\mathfrak{q} : b^n) = (\mathfrak{q} : b^{n+1})\) for some \(n\).

Step 3: Prove that \(\mathfrak{q} = (\mathfrak{q} + (a)) \cap (\mathfrak{q} + (b^n))\). Since \(a \notin \mathfrak{q}\) and \(\mathfrak{q}\) is irreducible, we must have \(\mathfrak{q} = \mathfrak{q} + (b^n)\), so \(b^n \in \mathfrak{q}\).

Step 4: For uniqueness of associated primes, show that \(\mathfrak{p}_i\) is the radical of \((I : x)\) for some \(x \notin I\), making it independent of the decomposition. ∎

Notation Guide

  • \(\sqrt{I}\): Radical of ideal \(I\)
  • \((I : J)\): Ideal quotient \(\{r \in R : rJ \subseteq I\}\)
  • \(\text{Ass}(I)\): Set of associated primes
  • \(\mathfrak{p}\)-primary: Primary ideal with radical \(\mathfrak{p}\)

2. Number Theory: Quadratic Reciprocity

Motivation

Given an odd prime \(p\), which integers are perfect squares modulo \(p\)? This seemingly simple question has profound implications for cryptography, coding theory, and the structure of number fields. The law of quadratic reciprocity, first conjectured by Euler and proved by Gauss, provides a beautiful and efficient way to determine whether a number is a quadratic residue modulo another.

Definitions

  • Quadratic Residue: An integer \(a\) is a quadratic residue mod \(p\) if there exists \(x\) such that \(x^2 \equiv a \pmod{p}\).
  • Legendre Symbol: \(\left(\frac{a}{p}\right) = \begin{cases} 1 & \text{if } a \text{ is QR mod } p \\ -1 & \text{if } a \text{ is QNR mod } p \\ 0 & \text{if } p \mid a \end{cases}\)
  • Jacobi Symbol: Generalization of the Legendre symbol for composite moduli.

Theorem: Law of Quadratic Reciprocity

Theorem: Let \(p\) and \(q\) be distinct odd primes. Then:

\[\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{(p-1)(q-1)}{4}}\]

Equivalently:

\[\left(\frac{p}{q}\right) = \begin{cases} \left(\frac{q}{p}\right) & \text{if } p \equiv 1 \text{ or } q \equiv 1 \pmod{4} \\ -\left(\frac{q}{p}\right) & \text{if } p \equiv q \equiv 3 \pmod{4} \end{cases}\]

Proof Sketch (Gauss's Third Proof)

Step 1 (Gauss's Lemma): For an odd prime \(p\) and \(a\) coprime to \(p\), consider the residues \(a, 2a, \ldots, \frac{p-1}{2}a\) modulo \(p\). Let \(n\) be the number of these that exceed \(p/2\). Then \(\left(\frac{a}{p}\right) = (-1)^n\).

Step 2: Apply Gauss's lemma to \(a = q\). Count the number of integers in \(\{q, 2q, \ldots, \frac{p-1}{2}q\}\) that exceed \(p/2\).

Step 3: Using lattice point counting, show that \(n \equiv \sum_{k=1}^{(p-1)/2} \left\lfloor \frac{kq}{p} \right\rfloor \pmod{2}\).

Step 4: The sum counts lattice points under the line \(y = \frac{q}{p}x\) in the rectangle \([0, p/2] \times [0, q/2]\). By symmetry, exchanging \(p\) and \(q\) gives the complementary count. The total number of interior lattice points is \(\frac{(p-1)(q-1)}{4}\), yielding the reciprocity law. ∎

Notation Guide

  • \(\left(\frac{a}{p}\right)\): Legendre symbol
  • \(\mathbb{F}_p^*\): Multiplicative group of integers mod \(p\)
  • \(a \equiv b \pmod{n}\): Congruence modulo \(n\)
  • \(\phi(n)\): Euler's totient function

def legendre_symbol(a, p):
    """
    Compute the Legendre symbol (a/p) using Euler's criterion.
    Returns: 1 if a is QR mod p, -1 if QNR, 0 if p divides a.
    """
    if p == 2:
        raise ValueError("p must be odd")
    if a % p == 0:
        return 0
    # Euler's criterion: (a/p) ≡ a^((p-1)/2) (mod p)
    result = pow(a, (p - 1) // 2, p)
    return 1 if result == 1 else -1

def quadratic_reciprocity(p, q):
    """
    Verify quadratic reciprocity for odd primes p and q.
    """
    if p == 2 or q == 2 or p % 2 == 0 or q % 2 == 0:
        raise ValueError("Both p and q must be odd primes")
    
    left_side = legendre_symbol(p, q) * legendre_symbol(q, p)
    right_side = (-1) ** ((p - 1) * (q - 1) // 4)
    
    return left_side == right_side

def find_quadratic_residues(p):
    """Find all quadratic residues modulo prime p."""
    residues = set()
    for x in range(1, (p - 1) // 2 + 1):
        residues.add((x * x) % p)
    return sorted(residues)

3. Algebraic Combinatorics: Young Tableaux and the Robinson-Schensted Correspondence

Motivation

How many ways can we arrange numbers in a grid with increasing rows and columns? These arrangements, called Young tableaux, appear throughout mathematics—from representation theory to algebraic geometry. The Robinson-Schensted correspondence provides a remarkable bijection between permutations and pairs of standard Young tableaux, revealing deep connections between combinatorics and algebra.

Definitions

  • Partition: A sequence \(\lambda = (\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_k > 0)\) of positive integers.
  • Young Diagram: Left-justified rows of boxes with \(\lambda_i\) boxes in row \(i\).
  • Standard Young Tableau: A filling of a Young diagram with \(1, 2, \ldots, n\) such that rows and columns increase.
  • Hook Length: For a box, the number of boxes to the right in its row, below in its column, plus one for the box itself.

Theorem: Hook Length Formula

Theorem: The number of standard Young tableaux of shape \(\lambda\) (where \(n = |\lambda|\)) is:

\[f^\lambda = \frac{n!}{\prod_{\text{boxes } b} h(b)}\]

where \(h(b)\) is the hook length of box \(b\).

Proof Sketch

Step 1 (Probabilistic Method): Consider a random ordering of the numbers \(1, \ldots, n\). The probability that this ordering produces a valid SYT of shape \(\lambda\) when inserted via the RSK algorithm equals \(f^\lambda / n!\).

Step 2 (Hook Walk): Greene, Nijenhuis, and Wilf introduced an elegant probabilistic proof. Define a "hook walk" starting from a random corner and moving to random boxes in the hook until reaching a corner.

Step 3: Show that the probability of reaching a particular corner equals \(1/h(b)\) where \(b\) is the starting box. The product formula follows by induction. ∎

Notation Guide

  • \(\lambda \vdash n\): \(\lambda\) is a partition of \(n\)
  • \(f^\lambda\): Number of SYT of shape \(\lambda\)
  • \(h(b)\): Hook length of box \(b\)
  • \(S_n\): Symmetric group on \(n\) elements

from math import factorial
from functools import lru_cache

def hook_lengths(shape):
    """
    Compute hook lengths for a Young diagram.
    shape: list of row lengths, e.g., [3, 2, 1] for partition (3,2,1)
    """
    hooks = []
    for i, row_len in enumerate(shape):
        row_hooks = []
        for j in range(row_len):
            # Count boxes to the right
            right = row_len - j - 1
            # Count boxes below
            below = sum(1 for k in range(i + 1, len(shape)) if shape[k] > j)
            # Hook length
            hook = right + below + 1
            row_hooks.append(hook)
        hooks.append(row_hooks)
    return hooks

def hook_length_formula(shape):
    """
    Compute the number of standard Young tableaux of given shape.
    """
    n = sum(shape)
    hooks = hook_lengths(shape)
    denominator = 1
    for row in hooks:
        for h in row:
            denominator *= h
    return factorial(n) // denominator

def robinson_schensted_insertion(tableau, x):
    """
    Insert element x into a Young tableau using row insertion.
    Returns the new tableau and the position where insertion terminated.
    """
    if not tableau:
        return [[x]], (0, 0)
    
    # Find the first row where x can be inserted
    for i, row in enumerate(tableau):
        if not row or x > row[-1]:
            # Append to end of row
            new_row = row + [x]
            new_tableau = tableau[:i] + [new_row] + tableau[i+1:]
            return new_tableau, (i, len(row))
        else:
            # Find the leftmost element > x
            for j, y in enumerate(row):
                if y > x:
                    # Bump y and continue
                    new_row = row[:j] + [x] + row[j+1:]
                    new_tableau = tableau[:i] + [new_row] + tableau[i+1:]
                    # Recursively insert y into next row
                    if i + 1 >= len(new_tableau):
                        new_tableau.append([y])
                        return new_tableau, (i + 1, 0)
                    else:
                        rest, pos = robinson_schensted_insertion(new_tableau[i+1:], y)
                        new_tableau = new_tableau[:i+1] + rest
                        return new_tableau, pos
    
    # If we get here, add new row
    return tableau + [[x]], (len(tableau), 0)

def rsk_correspondence(perm):
    """
    Apply the Robinson-Schensted correspondence to a permutation.
    Returns (P, Q) where P is the insertion tableau and Q is the recording tableau.
    """
    P = []
    Q = []
    
    for i, x in enumerate(perm, 1):
        P, pos = robinson_schensted_insertion(P, x)
        # Insert i into Q at the same position
        row, col = pos
        while len(Q) <= row:
            Q.append([])
        Q[row].insert(col, i)
    
    return P, Q

def demonstrate_rsk():
    """Demonstrate the Robinson-Schensted correspondence."""
    print("Robinson-Schensted Correspondence")
    print("=" * 60)
    
    # Example permutation
    perm = [3, 1, 4, 2, 5]
    print(f"\nPermutation: {perm}")
    
    P, Q = rsk_correspondence(perm)
    print("\nInsertion tableau P:")
    for row in P:
        print(f"  {row}")
    
    print("\nRecording tableau Q:")
    for row in Q:
        print(f"  {row}")
    
    # Hook length formula examples
    print("\n\nHook Length Formula Examples:")
    shapes = [[3, 2, 1], [4, 3, 2, 1], [5], [2, 2, 2]]
    for shape in shapes:
        hooks = hook_lengths(shape)
        count = hook_length_formula(shape)
        print(f"\nShape {shape}:")
        print(f"  Hook lengths:")
        for row in hooks:
            print(f"    {row}")
        print(f"  Number of SYT: {count}")

if __name__ == "__main__":
    demonstrate_rsk()

1. Stochastic Processes: The Wiener Process and Brownian Motion

Real-World Motivation

In 1827, botanist Robert Brown observed pollen grains suspended in water executing erratic, jittery motion. This phenomenon, now understood as the result of countless molecular collisions, became the prototypical example of a stochastic process. Today, Brownian motion models everything from stock prices in financial mathematics to diffusion in physics and population genetics in biology.

Definitions

  • Stochastic Process: A collection of random variables \(\{X_t : t \in T\}\) indexed by time.
  • Wiener Process: A continuous-time stochastic process \(\{W_t : t \geq 0\}\) satisfying:
    • \(W_0 = 0\)
    • Independent increments: \(W_t - W_s\) is independent of \(\{W_u : u \leq s\}\) for \(s < t\)
    • Stationary increments: \(W_t - W_s \sim N(0, t-s)\)
    • Continuous sample paths
  • Filtration: An increasing family of \(\sigma\)-algebras \(\{\mathcal{F}_t\}\) representing information available at time \(t\).

Theorem: Existence and Uniqueness of Wiener Measure

Theorem (Wiener, 1923): There exists a unique probability measure \(W\) on the space \(C[0,1]\) of continuous functions such that for any \(0 = t_0 < t_1 < \cdots < t_n \leq 1\) and Borel sets \(B_1, \ldots, B_n\):

\[W(\{f : f(t_i) - f(t_{i-1}) \in B_i \text{ for all } i\}) = \prod_{i=1}^{n} \frac{1}{\sqrt{2\pi(t_i - t_{i-1})}} \int_{B_i} e^{-\frac{x^2}{2(t_i-t_{i-1})}} dx\]

Proof Sketch

Step 1 (Finite-Dimensional Distributions): Define the finite-dimensional distributions using the Gaussian density specified above. Verify consistency using the Chapman-Kolmogorov equation.

Step 2 (Kolmogorov Extension): Apply the Kolmogorov extension theorem to obtain a process on the product space \(\mathbb{R}^{[0,1]}\) with the specified finite-dimensional distributions.

Step 3 (Continuity of Paths): Apply Kolmogorov's continuity criterion: if \(E[|X_t - X_s|^\alpha] \leq C|t-s|^{1+\beta}\) for some \(\alpha, \beta > 0\), then there exists a continuous modification. For Brownian motion with \(\alpha = 4\):

\[E[(W_t - W_s)^4] = 3(t-s)^2\]

satisfying the condition with \(\beta = 1\). ∎

Notation Guide

  • \(W_t\): Wiener process at time \(t\)
  • \(N(\mu, \sigma^2)\): Normal distribution
  • \(\mathcal{F}_t\): Filtration at time \(t\)
  • \(dW_t\): Wiener process differential (for stochastic calculus)

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T=1.0, N=1000, n_paths=5, seed=None):
    """
    Simulate sample paths of Brownian motion.
    
    Parameters:
    -----------
    T : float
        Final time
    N : int
        Number of time steps
    n_paths : int
        Number of paths to simulate
    seed : int, optional
        Random seed for reproducibility
    
    Returns:
    --------
    t : array
        Time points
    W : array
        Brownian paths (n_paths × N)
    """
    if seed is not None:
        np.random.seed(seed)
    
    dt = T / N
    t = np.linspace(0, T, N)
    
    # Generate increments: dW ~ N(0, dt)
    dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N - 1))
    
    # Cumulative sum to get W
    W = np.zeros((n_paths, N))
    W[:, 1:] = np.cumsum(dW, axis=1)
    
    return t, W

def brownian_bridge(T=1.0, N=1000, a=0, b=0, seed=None):
    """
    Simulate a Brownian bridge from (0,a) to (T,b).
    
    A Brownian bridge is a Brownian motion conditioned to return to b at time T.
    """
    if seed is not None:
        np.random.seed(seed)
    
    dt = T / N
    t = np.linspace(0, T, N)
    
    # Standard Brownian motion
    dW = np.random.normal(0, np.sqrt(dt), size=N - 1)
    W = np.zeros(N)
    W[1:] = np.cumsum(dW)
    
    # Transform to bridge: B_t = W_t - (t/T) * W_T + a + (t/T)*(b-a)
    B = W - (t / T) * W[-1] + a + (t / T) * (b - a)
    
    return t, B

def geometric_brownian_motion(S0, mu, sigma, T=1.0, N=1000, n_paths=5, seed=None):
    """
    Simulate geometric Brownian motion (used in Black-Scholes model).
    
    dS_t = mu * S_t * dt + sigma * S_t * dW_t
    S_t = S0 * exp((mu - sigma²/2)t + sigma * W_t)
    """
    if seed is not None:
        np.random.seed(seed)
    
    dt = T / N
    t = np.linspace(0, T, N)
    
    dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N - 1))
    W = np.zeros((n_paths, N))
    W[:, 1:] = np.cumsum(dW, axis=1)
    
    # GBM formula
    S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
    
    return t, S

2. Mathematical Biology: The Lotka-Volterra Equations

Real-World Motivation

Why do predator and prey populations oscillate in nature? In the 1920s, Alfred Lotka and Vito Volterra independently developed a mathematical model explaining the cyclic dynamics observed in ecosystems like the Adriatic Sea, where shark populations rose during World War I when fishing decreased. These equations became foundational in theoretical ecology and have applications in economics, epidemiology, and chemical kinetics.

Definitions

  • Prey Population: \(x(t)\) represents the number of prey (e.g., rabbits) at time \(t\).
  • Predator Population: \(y(t)\) represents the number of predators (e.g., foxes) at time \(t\).
  • Growth Rate: \(\alpha\): intrinsic growth rate of prey in absence of predators.
  • Predation Rate: \(\beta\): rate at which predators consume prey.
  • Efficiency: \(\delta\): efficiency of turning predated prey into predators.
  • Death Rate: \(\gamma\): natural death rate of predators.

Theorem: Conservation Law for Lotka-Volterra

Theorem: For the Lotka-Volterra system:

\[\begin{cases} \frac{dx}{dt} = \alpha x - \beta xy \\ \frac{dy}{dt} = \delta xy - \gamma y \end{cases}\]

the quantity:

\[H(x, y) = \delta x + \beta y - \gamma \ln x - \alpha \ln y\]

is conserved along trajectories (i.e., \(\frac{dH}{dt} = 0\)).

Proof

Compute the time derivative of \(H\):

\[\frac{dH}{dt} = \frac{\partial H}{\partial x}\frac{dx}{dt} + \frac{\partial H}{\partial y}\frac{dy}{dt}\]

\[= \left(\delta - \frac{\gamma}{x}\right)(\alpha x - \beta xy) + \left(\beta - \frac{\alpha}{y}\right)(\delta xy - \gamma y)\]

Expand the first term:

\[= \delta\alpha x - \delta\beta xy - \gamma\alpha + \gamma\beta y\]

Expand the second term:

\[+ \beta\delta xy - \beta\gamma y - \alpha\delta x + \alpha\gamma\]

All terms cancel, leaving \(\frac{dH}{dt} = 0\). ∎

Notation Guide

  • \(x(t)\): Prey population at time \(t\)
  • \(y(t)\): Predator population at time \(t\)
  • \(\alpha, \beta, \gamma, \delta\): Model parameters
  • \(H(x,y)\): Hamiltonian/conserved quantity
  • \((\gamma/\delta, \alpha/\beta)\): Equilibrium point

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

def lotka_volterra(Z, t, alpha, beta, gamma, delta):
    """
    Lotka-Volterra predator-prey model.
    
    Parameters:
    -----------
    Z : array [x, y]
        x = prey population, y = predator population
    t : float
        Time
    alpha, beta, gamma, delta : float
        Model parameters
    
    Returns:
    --------
    [dx/dt, dy/dt]
    """
    x, y = Z
    dxdt = alpha * x - beta * x * y
    dydt = delta * x * y - gamma * y
    return [dxdt, dydt]

def conserved_quantity(x, y, alpha, beta, gamma, delta):
    """
    Compute the conserved quantity H(x,y).
    """
    return delta * x + beta * y - gamma * np.log(x) - alpha * np.log(y)

def equilibrium_point(alpha, beta, gamma, delta):
    """
    Compute the equilibrium point (x*, y*).
    """
    x_star = gamma / delta
    y_star = alpha / beta
    return x_star, y_star

def simulate_lotka_volterra(x0, y0, alpha, beta, gamma, delta, t_max=50, n_points=10000):

    Z0 = [x0, y0]
    
    solution = odeint(lotka_volterra, Z0, t, args=(alpha, beta, gamma, delta))
    x, y = solution.T
    
    return t, x, y

3. Coding Theory: Reed-Solomon Codes

Real-World Motivation

Every CD, DVD, QR code, and deep-space transmission relies on error-correcting codes to recover data corrupted by noise. Reed-Solomon codes, invented in 1960 at MIT Lincoln Laboratory, are among the most widely used error-correcting codes. They power everything from satellite communications to RAID storage systems, enabling reliable data transmission even when significant portions of the message are lost or corrupted.

Definitions

  • Finite Field: \(\mathbb{F}_q\): a field with \(q = p^m\) elements where \(p\) is prime.
  • Reed-Solomon Code: For a finite field \(\mathbb{F}_q\), distinct elements \(\alpha_1, \ldots, \alpha_n \in \mathbb{F}_q\), and parameters \(k \leq n\), the RS code is:

\[\text{RS}(n, k) = \{(f(\alpha_1), \ldots, f(\alpha_n)) : f \in \mathbb{F}_q[x], \deg(f) < k\}\]

  • Minimum Distance: \(d = n - k + 1\): the minimum Hamming distance between codewords.
  • Generator Matrix: The \(k \times n\) matrix \(G\) where \(G_{ij} = \alpha_j^{i-1}\).

Theorem: Reed-Solomon Error Correction Capability

Theorem: A Reed-Solomon code with parameters \((n, k)\) over \(\mathbb{F}_q\) has:

  • Length: \(n\)
  • Dimension: \(k\)
  • Minimum distance: \(d = n - k + 1\) (MDS property)

It can correct up to \(t = \lfloor (n-k)/2 \rfloor\) errors or \(n - k\) erasures.

Proof Sketch

Step 1 (MDS Property): Two distinct polynomials of degree \(< k\) can agree at most \(k-1\) points. Therefore, two distinct codewords differ in at least \(n - (k-1) = n - k + 1\) positions.

Step 2 (Singleton Bound): For any linear code, \(d \leq n - k + 1\). Since RS codes achieve this bound, they are Maximum Distance Separable (MDS).

Step 3 (Error Correction): By the standard bound for linear codes, a code with minimum distance \(d\) can correct \(\lfloor (d-1)/2 \rfloor\) errors. For RS codes:

\[t = \left\lfloor \frac{n-k+1-1}{2} \right\rfloor = \left\lfloor \frac{n-k}{2} \right\rfloor\]

For erasures (known error positions), we can correct up to \(d-1 = n-k\) erasures. ∎

Notation Guide

  • \(\mathbb{F}_q\): Finite field with \(q\) elements
  • \([n, k, d]_q\): Linear code of length \(n\), dimension \(k\), distance \(d\) over \(\mathbb{F}_q\)
  • \(d_H(x, y)\): Hamming distance between vectors
  • \(w(x)\): Hamming weight (number of non-zero entries)

import numpy as np
from functools import reduce

def gf_add(a, b, p=2, m=8):
    """Addition in GF(p^m) - same as XOR for p=2."""
    return a ^ b

def gf_mult(a, b, p=2, m=8, primitive_poly=0x11d):
    """
    Multiplication in GF(2^m) using Russian peasant algorithm.
    Default: GF(256) with primitive polynomial x^8 + x^4 + x^3 + x^2 + 1
    """
    result = 0
    for i in range(m):
        if b & 1:
            result ^= a
        b >>= 1
        carry = a & 0x80
        a <<= 1
        if carry:
            a ^= primitive_poly & 0xff
    return result & 0xff

def gf_pow(a, n, p=2, m=8):
    """Compute a^n in GF(p^m)."""
    result = 1
    base = a
    while n > 0:
        if n & 1:
            result = gf_mult(result, base)
        base = gf_mult(base, base)
        n >>= 1
    return result

def gf_inv(a, p=2, m=8):
    """Multiplicative inverse in GF(2^m) using Fermat's little theorem: a^(2^m-2) = a^(-1)."""
    if a == 0:
        raise ValueError("Zero has no multiplicative inverse")
    return gf_pow(a, (1 << m) - 2)

def rs_encode(message, n, k, alpha=2):
    """
    Encode a message using Reed-Solomon.
    
    message: list of k elements in GF(256)
    n: codeword length
    k: message length
    alpha: primitive element
    
    Returns: codeword of length n
    """
    if len(message) != k:
        raise ValueError(f"Message length must be {k}")
    
    # Evaluate polynomial f(x) = m_0 + m_1*x + ... + m_{k-1}*x^{k-1}
    # at points alpha^0, alpha^1, ..., alpha^{n-1}
    codeword = []
    for i in range(n):
        x = gf_pow(alpha, i)
        # Evaluate polynomial at x
        value = 0
        for j, coeff in enumerate(message):
            value = gf_add(value, gf_mult(coeff, gf_pow(x, j)))
        codeword.append(value)
    
    return codeword

Fermat's Last Theorem: From Marginal Note to Millennium

Historical Context

In 1637, Pierre de Fermat wrote in the margin of his copy of Diophantus's Arithmetica that he had discovered a "truly marvelous proof" that the equation \(a^n + b^n = c^n\) has no solutions in positive integers for \(n > 2\), but the margin was too small to contain it. This casual note launched a 358-year quest that became the most famous problem in mathematics.

Fermat himself proved the case \(n = 4\) using his method of infinite descent. Euler proved \(n = 3\) in 1770, though his proof had a gap later filled by Legendre. Dirichlet and Legendre proved \(n = 5\) in 1825, and Lamé proved \(n = 7\) in 1839. The 19th century saw Sophie Germain's innovative approach for certain classes of exponents, and Kummer's development of ideal theory to handle regular primes.

The modern approach began with the Taniyama-Shimura conjecture, proposed in the 1950s, which suggested a deep connection between elliptic curves and modular forms. In 1984, Gerhard Frey showed that a counterexample to Fermat's Last Theorem would yield an elliptic curve that violated this conjecture. Ken Ribet proved this connection in 1986, showing that the Taniyama-Shimura conjecture implies Fermat's Last Theorem.

Andrew Wiles, working in secret for seven years, announced a proof in 1993. A gap was discovered, but with Richard Taylor's help, Wiles completed the proof in 1994. The proof, published in 1995, established the modularity theorem for semistable elliptic curves and finally settled Fermat's claim.

Definitions

  • Fermat Equation: \(x^n + y^n = z^n\) for integers \(n > 2\).
  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point, typically given by \(y^2 = x^3 + ax + b\).
  • Modular Form: A holomorphic function on the upper half-plane satisfying specific transformation properties under the modular group.
  • Frey Curve: Given a solution to \(a^p + b^p = c^p\), the elliptic curve \(y^2 = x(x - a^p)(x + b^p)\).

Theorem: Fermat's Last Theorem (Wiles, 1994)

Theorem: For any integer \(n > 2\), there exist no positive integers \(a, b, c\) such that:

\[a^n + b^n = c^n\]

Proof Strategy

Step 1 (Reduction): It suffices to prove the theorem for \(n = p\) where \(p\) is an odd prime. If \(n = ab\) and \(x^n + y^n = z^n\), then \((x^a)^b + (y^a)^b = (z^a)^b\).

Step 2 (Frey's Construction): Suppose \(a^p + b^p = c^p\) with \(p \geq 5\). The Frey curve \(E: y^2 = x(x - a^p)(x + b^p)\) has discriminant \(\Delta = 16(abc)^{2p}\), which is a perfect \(p\)th power up to factors of 2.

Step 3 (Ribet's Theorem): The Frey curve is semistable and its Galois representation is irreducible. Ribet proved that such a curve cannot be modular.

Step 4 (Wiles's Theorem): Wiles proved that every semistable elliptic curve over \(\mathbb{Q}\) is modular. This contradiction establishes Fermat's Last Theorem. ∎

Notation Guide

  • \(\mathbb{Q}\): Field of rational numbers
  • \(\mathbb{Z}\): Ring of integers
  • \(\Gamma_0(N)\): Congruence subgroup of \(SL_2(\mathbb{Z})\)
  • \(L(E, s)\): L-function of elliptic curve \(E\)
  • \(\rho_E\): Galois representation associated to \(E\)

📜 Math History: The Development of Abstract Algebra

The emergence of abstract algebra in the 19th and early 20th centuries represents one of the most profound shifts in mathematical thinking. Before this transformation, algebra was primarily concerned with solving equations—finding unknown quantities that satisfied specific conditions. The shift to abstract algebra, pioneered by mathematicians like Évariste Galois, Richard Dedekind, David Hilbert, and Emmy Noether, redefined algebra as the study of algebraic structures themselves.

The story begins with the solution of polynomial equations. Mathematicians had known since antiquity how to solve linear and quadratic equations. The cubic and quartic equations were solved in 16th-century Italy by del Ferro, Tartaglia, Cardano, and Ferrari. But the quintic equation resisted all attempts. In 1799, Paolo Ruffini sketched a proof that the general quintic could not be solved by radicals, though his argument had gaps. It was Évariste Galois, in the early 1830s, who provided the complete solution.

Galois's insight was revolutionary: instead of studying the roots directly, study the permutations of the roots that preserve algebraic relationships. These permutations form a group, now called the Galois group, and the structure of this group determines whether the equation is solvable. Galois died in a duel at age 20, but his work, published posthumously in 1846, laid the foundation for group theory.

In the mid-19th century, mathematicians began recognizing similar patterns across different domains. Arthur Cayley and others developed matrix algebra. William Rowan Hamilton discovered quaternions, extending complex numbers to four dimensions. Hermann Grassmann developed his "extension theory," anticipating modern linear algebra and exterior algebra. These developments showed that algebraic operations could be defined on abstract objects without reference to numbers.

Richard Dedekind was instrumental in the transition to abstraction. In his work on algebraic number theory, he introduced ideals—collections of numbers that behave like numbers themselves—providing a foundation for modern ring theory. He also gave the first rigorous definition of real numbers via Dedekind cuts, showing that even the most concrete mathematical objects could be constructed abstractly.

The modern axiomatic approach crystallized in the early 20th century. David Hilbert's work on the foundations of geometry showed that mathematical structures could be defined purely by axioms, independent of any intuitive interpretation. Emmy Noether, working in Göttingen in the 1920s, unified the emerging field with her abstract approach to ring theory and ideal theory. Her 1921 paper "Idealtheorie in Ringbereichen" established the foundation for modern commutative algebra, including the ascending chain condition and primary decomposition.

Noether's influence extended through her students and collaborators. Her approach—focusing on the structural properties of algebraic systems rather than computational techniques—became the dominant paradigm. Bartel van der Waerden's 1930 textbook Moderne Algebra, based on lectures by Noether and Emil Artin, codified the abstract approach and became the standard reference for generations of mathematicians.

The abstraction of algebra had profound consequences. It unified previously disparate areas of mathematics: number theory, geometry, and analysis all found expression in algebraic terms. It enabled the development of modern algebraic geometry, algebraic topology, and category theory. And it provided the language for 20th-century physics, from quantum mechanics to gauge theory. What began as a study of solving equations became the study of structure itself—a transformation that exemplifies the power of mathematical abstraction.

Problem: An Algebraic Number Theory Challenge

Problem: Let \(p\) be an odd prime. Define the set:

\[S_p = \left\{a \in \{1, 2, \ldots, p-1\} : \left(\frac{a}{p}\right) = 1\right\}\]

where \(\left(\frac{a}{p}\right)\) is the Legendre symbol. Prove that:

\[\sum_{a \in S_p} a = \frac{p(p-1)}{4}\]

Click for Hint

Consider the sum of all quadratic residues and the sum of all quadratic non-residues. Use the fact that the product of two quadratic residues is a quadratic residue, and that \(-1\) times a quadratic residue is a quadratic non-residue when \(p \equiv 3 \pmod{4}\). Also, recall that the sum of all elements in \(\mathbb{F}_p^*\) is \(0\).

Click for Solution

Solution:

Let \(QR\) denote the set of quadratic residues and \(QNR\) the set of quadratic non-residues in \(\{1, 2, \ldots, p-1\}\). Both sets have size \(\frac{p-1}{2}\).

Let \(S_{QR} = \sum_{a \in QR} a\) and \(S_{QNR} = \sum_{a \in QNR} a\).

Since \(QR \cup QNR = \{1, 2, \ldots, p-1\}\), we have:

\[S_{QR} + S_{QNR} = \sum_{k=1}^{p-1} k = \frac{(p-1)p}{2}\]

Now, let \(g\) be a primitive root modulo \(p\). Then:

\[QR = \{g^{2k} : k = 0, 1, \ldots, \frac{p-3}{2}\}\]

\[QNR = \{g^{2k+1} : k = 0, 1, \ldots, \frac{p-3}{2}\}\]

Consider the map \(x \mapsto gx \pmod{p}\). This maps \(QR\) bijectively to \(QNR\) and \(QNR\) bijectively to \(QR\).

Therefore:

\[g \cdot S_{QR} \equiv S_{QNR} \pmod{p}\]

\[g \cdot S_{QNR} \equiv S_{QR} \pmod{p}\]

Adding these: \((g+1)(S_{QR} + S_{QNR}) \equiv 2S_{QR} + 2S_{QNR} \pmod{p}\), which is consistent.

Subtracting: \((g-1)(S_{QR} - S_{QNR}) \equiv S_{QNR} - S_{QR} = -(S_{QR} - S_{QNR}) \pmod{p}\)

So \((g-1+1)(S_{QR} - S_{QNR}) \equiv 0\), i.e., \(g(S_{QR} - S_{QNR}) \equiv 0\).

Since \(g \not\equiv 0\), we get \(S_{QR} \equiv S_{QNR} \pmod{p}\).

Combined with \(S_{QR} + S_{QNR} = \frac{p(p-1)}{2}\), we have:

\[2S_{QR} = \frac{p(p-1)}{2}\]

\[S_{QR} = \frac{p(p-1)}{4}\]

∎

The Modular Group and the Farey Tessellation

The modular group \(PSL(2, \mathbb{Z})\) acts on the upper half-plane by Möbius transformations, producing one of the most beautiful structures in mathematics: the Farey tessellation. This infinite tiling by ideal triangles reveals deep connections between number theory, geometry, and group theory.

The Farey tessellation is constructed by starting with the ideal triangle with vertices at \(0, 1, \infty\) on the real line, then reflecting across its sides to generate new triangles. The resulting pattern has remarkable properties: the vertices of triangles correspond to rational numbers in lowest terms, and two fractions \(a/b\) and \(c/d\) are connected by an edge if and only if \(|ad - bc| = 1\).

import numpy as np
import matplotlib.pyplot as plt
from fractions import Fraction
import matplotlib.patches as patches

def farey_sequence(n):
    """
    Generate the Farey sequence of order n.
    Returns list of Fractions between 0 and 1.
    """
    sequence = [Fraction(0, 1), Fraction(1, 1)]
    
    for i in range(2, n + 1):
        new_sequence = [sequence[0]]
        for j in range(len(sequence) - 1):
            a, b = sequence[j], sequence[j + 1]
            # Mediant
            if b.denominator + a.denominator == i:
                mediant = Fraction(a.numerator + b.numerator, 
                                   a.denominator + b.denominator)
                new_sequence.extend([mediant, b])
            else:
                new_sequence.append(b)
        sequence = new_sequence
    
    return sequence

def draw_farey_tessellation(max_denominator=20, y_max=2):
    """
    Draw the Farey tessellation of the upper half-plane.
    """
    fig, ax = plt.subplots(figsize=(16, 10))
    
    # Generate Farey sequence
    farey = farey_sequence(max_denominator)
    
    # Draw geodesics (semicircles) between adjacent fractions
    for i in range(len(farey) - 1):
        a, b = farey[i], farey[i + 1]
        
        # Semicircle from a to b
        center = float(a + b) / 2
        radius = float(b - a) / 2
        
        if radius > 0:
            theta = np.linspace(0, np.pi, 100)
            x = center + radius * np.cos(theta)
            y = radius * np.sin(theta)
            ax.plot(x, y, 'b-', alpha=0.6, linewidth=0.8)
    
    # Add vertical lines at integers
    for k in range(int(farey[-1].numerator / farey[-1].denominator) + 2):
        ax.plot([k, k], [0, y_max], 'b-', alpha=0.6, linewidth=0.8)
    
    # Mark rational points on real axis
    for f in farey:
        if f.denominator <= 5:  # Only label simple fractions
            ax.plot(float(f), 0, 'ro', markersize=3)
            ax.annotate(str(f), xy=(float(f), 0), xytext=(float(f), -0.15),
                       fontsize=8, ha='center')
    
    ax.set_xlim(-0.5, 1.5)
    ax.set_ylim(-0.3, y_max)
    ax.set_aspect('equal')
    ax.set_xlabel('Re(z)')
    ax.set_ylabel('Im(z)')
    ax.set_title(f'Farey Tessellation (order ≤ {max_denominator})')
    ax.grid(True, alpha=0.3)
    
    # Remove top and right spines
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    
    plt.tight_layout()
    plt.savefig('farey_tessellation.png', dpi=150, bbox_inches='tight')
    print(f"Farey tessellation saved to farey_tessellation.png")
    
    return fig, ax

def modular_group_action(z, a, b, c, d):
    """
    Apply Möbius transformation: f(z) = (az + b) / (cz + d)
    where a, b, c, d are integers with ad - bc = 1.
    """
    numerator = (a * z.real + b) + 1j * a * z.imag
    denominator = (c * z.real + d) + 1j * c * z.imag
    return numerator / denominator

def demonstrate_modular_group():
    """Demonstrate the action of the modular group."""
    print("Modular Group PSL(2, Z)")
    print("=" * 60)
    print("\nGenerators:")
    print("  S: z ↦ -1/z  (inversion)")
    print("  T: z ↦ z + 1  (translation)")
    
    # Test on a point
    z = 0.5 + 0.8j
    print(f"\nExample: z = {z}")
    
    # S transformation
    Sz = -1/z
    print(f"  S(z) = -1/z = {Sz:.4f}")
    
    # T transformation
    Tz = z + 1
    print(f"  T(z) = z + 1 = {Tz:.4f}")
    
    # Combined
    STz = -1/(z + 1)
    print(f"  ST(z) = -1/(z+1) = {STz:.4f}")

def visualize_fundamental_domain():
    """
    Visualize the fundamental domain of the modular group.
    """
    fig, ax = plt.subplots(figsize=(12, 10))
    
    # Fundamental domain: |z| > 1, |Re(z)| < 1/2, Im(z) > 0
    theta = np.linspace(np.pi/3, 2*np.pi/3, 100)
    arc_x = np.cos(theta)
    arc_y = np.sin(theta)
    
    # Draw boundary
    ax.plot(arc_x, arc_y, 'r-', linewidth=2, label='Fundamental domain boundary')
    ax.plot([-0.5, -0.5], [np.sqrt(3)/2, 3], 'r-', linewidth=2)
    ax.plot([0.5, 0.5], [np.sqrt(3)/2, 3], 'r-', linewidth=2)
    ax.plot([-0.5, 0.5], [3, 3], 'r-', linewidth=2)
    
    # Fill the domain
    from matplotlib.patches import Polygon
    domain_points = list(zip(arc_x, arc_y)) + [(0.5, 3), (-0.5, 3)]
    domain = Polygon(domain_points, alpha=0.3, facecolor='yellow', edgecolor='red')
    ax.add_patch(domain)
    
    ax.set_xlim(-2, 2)
    ax.set_ylim(0, 3.5)
    ax.set_aspect('equal')
    ax.set_xlabel('Re(z)')
    ax.set_ylabel('Im(z)')
    ax.set_title('Fundamental Domain of PSL(2, Z)')
    ax.legend()
    ax.grid(True, alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('fundamental_domain.png', dpi=150, bbox_inches='tight')
    print("\nFundamental domain saved to fundamental_domain.png")

if __name__ == "__main__":
