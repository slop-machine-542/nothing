Ito Calculus: Stochastic Integration

Motivation

Standard calculus fails for Brownian motion because the paths are nowhere differentiable. Ito calculus provides a rigorous framework for integrating against stochastic processes, essential for modeling financial markets, physical systems with noise, and biological processes.

Definitions

Ito Integral: For an adapted process \(X_t\) satisfying \(\mathbb{E}\left[\int_0^T X_s^2 ds\right] < \infty\), the Ito integral is defined as:

\[\int_0^t X_s dW_s = \lim_{n \to \infty} \sum_{i=0}^{n-1} X_{t_i}(W_{t_{i+1}} - W_{t_i})\]

where the limit is taken in \(L^2\) and the partition mesh goes to zero.

Ito Process: A stochastic process of the form:

\[X_t = X_0 + \int_0^t \mu_s ds + \int_0^t \sigma_s dW_s\]

or in differential notation: \(dX_t = \mu_t dt + \sigma_t dW_t\).

Theorem: Ito's Lemma

Statement: Let \(X_t\) be an Ito process and \(f \in C^{2,1}(\mathbb{R} \times [0,T])\). Then \(Y_t = f(X_t, t)\) is an Ito process with:

\[df(X_t, t) = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial x}dX_t + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(dX_t)^2\]

where \((dX_t)^2 = \sigma_t^2 dt\) (using the rule \((dt)^2 = 0\), \(dt \cdot dW_t = 0\), \((dW_t)^2 = dt\)).

Proof: Using Taylor expansion:

\[f(X_{t+h}, t+h) - f(X_t, t) = \frac{\partial f}{\partial t}h + \frac{\partial f}{\partial x}(X_{t+h} - X_t) + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(X_{t+h} - X_t)^2 + O(h^{3/2})\]

Summing over partitions and taking limits, the quadratic variation term \((X_{t+h} - X_t)^2 \to \sigma_t^2 dt\) gives the extra term absent in ordinary calculus. ∎

Notation Guide

  • \(W_t\) - Standard Brownian motion (Wiener process)
  • \(\mu_t\) - Drift coefficient
  • \(\sigma_t\) - Diffusion/volatility coefficient
  • \(\mathcal{F}_t\) - Filtration (information available at time t)
  • \(\langle X \rangle_t\) - Quadratic variation process

Free Probability Theory

Motivation

Free probability, developed by Dan Voiculescu, studies non-commutative random variables where "freeness" replaces independence. It provides powerful tools for analyzing random matrices in the large-N limit, with applications in quantum information, wireless communications, and machine learning.

Definitions

Non-commutative Probability Space: A pair \((\mathcal{A}, \varphi)\) where \(\mathcal{A}\) is a unital algebra over \(\mathbb{C}\) and \(\varphi: \mathcal{A} \to \mathbb{C}\) is a linear functional with \(\varphi(1) = 1\).

Free Independence: Subalgebras \(\mathcal{A}_1, \ldots, \mathcal{A}_n\) are freely independent if for all \(k \geq 1\), \(a_j \in \mathcal{A}_{i_j}\) with \(\varphi(a_j) = 0\) and \(i_j \neq i_{j+1}\):

\[\varphi(a_1 a_2 \cdots a_k) = 0\]

R-transform: For a random variable \(a\) with Cauchy transform \(G_a(z) = \varphi((z-a)^{-1})\), the R-transform satisfies:

\[G_a(R_a(z) + 1/z) = z\]

Theorem: Free Additivity of R-transforms

Statement: If \(a\) and \(b\) are freely independent, then:

\[R_{a+b}(z) = R_a(z) + R_b(z)\]

Proof: The key is the subordination relation. Let \(\omega_1, \omega_2\) be the subordination functions satisfying:

\[G_{a+b}(z) = G_a(\omega_1(z)) = G_b(\omega_2(z))\]

From the definition of R-transform: \(G_a(z)^{-1} + R_a(G_a(z)) = z\). For freely independent variables, the moment-cumulant formula shows that mixed free cumulants vanish. Therefore the R-transforms add. This is the free analog of the classical result that characteristic functions multiply for independent random variables. ∎

Notation Guide

  • \(\mathcal{A}\) - Algebra of random variables
  • \(\varphi\) - Expectation/state functional
  • \(\kappa_n\) - n-th free cumulant
  • \(R_a(z)\) - R-transform of \(a\)
  • \(G_a(z)\) - Cauchy/Stieltjes transform
  • \(m_n = \varphi(a^n)\) - n-th moment

from numpy.linalg import eigvalsh

def semicircle_cauchy(z, sigma=1):
    """Cauchy transform of semicircle law"""
    return (z - np.sqrt(z**2 - 4*sigma**2)) / (2*sigma**2)

def semicircle_r_transform(z, sigma=1):
    """R-transform of semicircle law"""
    return sigma**2 * z

def free_sum_convolution(z, R1, R2, tol=1e-10, max_iter=1000):
    """
    Compute Cauchy transform of free sum using fixed point iteration.
    R1, R2 are R-transforms (functions).
    """
    # We need to solve: z = w + R1(G(w)) + R2(G(w)) where G(w) = 1/(w - R(G(w)))
    # This is complex; use iterative approach
    G = 1/z  # Initial guess
    for _ in range(max_iter):
        G_new = 1 / (z - R1(G) - R2(G))
        if np.abs(G_new - G) < tol:
            return G_new
        G = G_new
    return G

Semidefinite Programming

Motivation

Semidefinite programming (SDP) is a subfield of convex optimization where the variable is a matrix and the constraints involve positive semidefiniteness. SDPs can model problems in control theory, combinatorial optimization, quantum information, and machine learning, often providing tractable relaxations of NP-hard problems.

Definitions

Standard Form SDP:

\[\begin{aligned} \text{minimize} \quad & \langle C, X \rangle = \text{tr}(CX) \\ \text{subject to} \quad & \langle A_i, X \rangle = b_i, \quad i = 1, \ldots, m \\ & X \succeq 0 \end{aligned}\]

where \(X \in \mathbb{S}^n\) (space of symmetric \(n \times n\) matrices) and \(X \succeq 0\) means \(X\) is positive semidefinite.

Positive Semidefinite: \(X \succeq 0\) iff \(\forall v \in \mathbb{R}^n: v^T X v \geq 0\), equivalently all eigenvalues are non-negative.

Theorem: Strong Duality for SDP

Statement: Consider the primal SDP above and its dual:

\[\begin{aligned} \text{maximize} \quad & b^T y \\ \text{subject to} \quad & C - \sum_{i=1}^m y_i A_i \succeq 0 \end{aligned}\]

If the primal is strictly feasible (there exists \(X \succ 0\) satisfying constraints) and the dual is strictly feasible, then strong duality holds: \(p^* = d^*\).

Proof: This follows from standard convex duality theory. The cone of positive semidefinite matrices is self-dual under the trace inner product. Strict feasibility ensures that the constraint qualification (Slater's condition) holds, which guarantees strong duality and attainment of optimal values. ∎

Notation Guide

  • \(\mathbb{S}^n\) - Space of \(n \times n\) symmetric matrices
  • \(\mathbb{S}^n_+\) - Cone of positive semidefinite matrices
  • \(\langle A, B \rangle = \text{tr}(A^T B)\) - Trace inner product
  • \(X \succeq 0\) - Positive semidefinite
  • \(X \succ 0\) - Positive definite

import numpy as np
import cvxpy as cp

def max_cut_sdp(adj_matrix):
    """
    SDP relaxation for MAX-CUT problem.
    Given graph with adjacency matrix A, find cut maximizing edges crossing.
    """
    n = adj_matrix.shape[0]
    
    # Variable: Gram matrix of unit vectors
    X = cp.Variable((n, n), symmetric=True)
    
    # Objective: maximize sum of (1 - X_ij) * A_ij / 4
    objective = cp.Maximize(0.25 * cp.sum(cp.multiply(adj_matrix, 1 - X)))
    
    # Constraints
    constraints = [
        X >> 0,  # Positive semidefinite
        cp.diag(X) == 1  # Unit vectors
    ]
    
    problem = cp.Problem(objective, constraints)
    problem.solve(solver=cp.SCS)
    
    # Randomized rounding
    eigenvalues, eigenvectors = np.linalg.eigh(X.value)
    # Take top eigenvectors weighted by sqrt(eigenvalues)
    embedding = eigenvectors @ np.diag(np.sqrt(np.maximum(eigenvalues, 0)))
    
    # Random hyperplane rounding
    best_cut = 0
    best_partition = None
    
    for _ in range(100):
        random_vector = np.random.randn(n)
        partition = (embedding @ random_vector) >= 0
        cut_value = np.sum(adj_matrix[partition][:, ~partition])
        if cut_value > best_cut:
            best_cut = cut_value
            best_partition = partition
    
    return best_cut, best_partition, X.value

def lyapunov_sdp(A, Q):
    """
    Find P ≻ 0 such that A^T P + PA + Q = 0 (Lyapunov equation)
    or verify stability via Lyapunov inequality.
    """
    n = A.shape[0]
    P = cp.Variable((n, n), symmetric=True)
    
    # Lyapunov inequality: A^T P + PA ≺ 0
    constraints = [
        P >> 0.001 * np.eye(n),  # P positive definite
        A.T @ P + P @ A << -0.001 * np.eye(n)  # Stability condition
    ]
    
    objective = cp.Minimize(cp.trace(P))
    problem = cp.Problem(objective, constraints)
    problem.solve(solver=cp.SCS)
    
    if problem.status == 'optimal':
        print(f"System is stable! Lyapunov matrix found.")
        return P.value
    else:
        print(f"Could not verify stability. Status: {problem.status}")
        return None

Computer Vision: Structure from Motion

Real-World Motivation

Structure from Motion (SfM) reconstructs 3D scenes from 2D images. It's fundamental to autonomous driving, augmented reality, robotics, and cultural heritage preservation (digitizing archaeological sites).

Definitions

Camera Projection: A 3D point \(X = (X, Y, Z, 1)^T\) projects to image point \(x = (u, v, 1)^T\) via:

\[x = K[R | t]X = PX\]

where \(K\) is the intrinsic matrix, \([R|t]\) is extrinsic parameters.

Essential Matrix: For calibrated cameras, the epipolar constraint is:

\[x_2^T E x_1 = 0\]

where \(E = [t]_\times R\) and \([t]_\times\) is the skew-symmetric matrix of translation.

Fundamental Matrix: For uncalibrated cameras:

\[x_2^T F x_1 = 0, \quad F = K_2^{-T} E K_1^{-1}\]

Theorem: Eight-Point Algorithm

Statement: Given 8 or more point correspondences between two views, the fundamental matrix can be computed linearly up to scale.

Proof: For each correspondence \((x_1, x_2)\), the epipolar constraint gives:

\[u_2 u_1 f_{11} + u_2 v_1 f_{12} + u_2 f_{13} + v_2 u_1 f_{21} + v_2 v_1 f_{22} + v_2 f_{23} + u_1 f_{31} + v_1 f_{32} + f_{33} = 0\]

Stacking 8+ such equations gives \(Af = 0\) where \(f\) contains the entries of \(F\). The solution is the singular vector corresponding to the smallest singular value of \(A\). The rank-2 constraint is enforced by setting the smallest singular value of \(F\) to zero. ∎

Notation Guide

  • \(K\) - Intrinsic camera matrix (3×3)
  • \(R\) - Rotation matrix (SO(3))
  • \(t\) - Translation vector
  • \(E\) - Essential matrix (3×3, rank 2)
  • \(F\) - Fundamental matrix (3×3, rank 2)
  • \([t]_\times\) - Skew-symmetric cross-product matrix

Python Implementation

import numpy as np
from scipy.linalg import svd

def skew_symmetric(t):
    """Create skew-symmetric matrix from vector t"""
    return np.array([[0, -t[2], t[1]],
                     [t[2], 0, -t[0]],
                     [-t[1], t[0], 0]])

def eight_point_algorithm(pts1, pts2):
    """
    Compute fundamental matrix from 8+ point correspondences.
    pts1, pts2: Nx2 arrays of corresponding points
    """
    n = pts1.shape[0]
    assert n >= 8, "Need at least 8 points"
    
    # Normalize coordinates (Hartley normalization)
    def normalize(pts):
        mean = np.mean(pts, axis=0)
        std = np.std(pts)
        scale = np.sqrt(2) / std
        T = np.array([[scale, 0, -scale*mean[0]],
                      [0, scale, -scale*mean[1]],
                      [0, 0, 1]])
        pts_h = np.hstack([pts, np.ones((n, 1))])
        pts_norm = (T @ pts_h.T).T
        return pts_norm[:, :2], T
    
    pts1_norm, T1 = normalize(pts1)
    pts2_norm, T2 = normalize(pts2)
    
    # Build constraint matrix
    A = np.zeros((n, 9))
    for i in range(n):
        u1, v1 = pts1_norm[i]
        u2, v2 = pts2_norm[i]
        A[i] = [u2*u1, u2*v1, u2, v2*u1, v2*v1, v2, u1, v1, 1]
    
    # Solve using SVD
    _, _, Vt = svd(A)
    F_norm = Vt[-1].reshape(3, 3)
    
    # Enforce rank 2 constraint
    U, S, Vt = svd(F_norm)
    S[2] = 0  # Set smallest singular value to 0
    F_norm = U @ np.diag(S) @ Vt
    
    # Denormalize
    F = T2.T @ F_norm @ T1
    
    return F / F[2, 2]  # Normalize scale

def triangulate_point(P1, P2, x1, x2):
    """
    Triangulate 3D point from two camera projections.
    P1, P2: 3x4 projection matrices
    x1, x2: 2D image points (homogeneous)
    """
    # Build linear system: x × PX = 0
    A = np.zeros((4, 4))
    A[0] = x1[0] * P1[2] - P1[0]
    A[1] = x1[1] * P1[2] - P1[1]
    A[2] = x2[0] * P2[2] - P2[0]
    A[3] = x2[1] * P2[2] - P2[1]
    
    _, _, Vt = svd(A)
    X = Vt[-1]
    return X[:3] / X[3]  # Dehomogenize

def essential_from_fundamental(F, K1, K2):
    """Compute essential matrix from fundamental matrix"""
    E = K2.T @ F @ K1
    
    # Enforce proper singular values (two equal, one zero)
    U, S, Vt = svd(E)
    S = [(S[0] + S[1]) / 2, (S[0] + S[1]) / 2, 0]
    E = U @ np.diag(S) @ Vt
    
    return E

def decompose_essential(E):
    """
    Decompose essential matrix into 4 possible [R|t] configurations.
    Returns list of (R, t) tuples.
    """
    U, _, Vt = svd(E)
    
    # Ensure proper rotation matrices
    if np.linalg.det(U) < 0:
        U = -U
    if np.linalg.det(Vt) < 0:
        Vt = -Vt
    
    W = np.array([[0, -1, 0],
                  [1, 0, 0],
                  [0, 0, 1]])
    
    R1 = U @ W @ Vt
    R2 = U @ W.T @ Vt
    t = U[:, 2]  # Third column of U
    
    return [(R1, t), (R1, -t), (R2, t), (R2, -t)]

Variational Inference

Real-World Motivation

Bayesian inference often involves intractable integrals. Variational Inference (VI) converts inference into optimization, finding the best approximation within a tractable family. It powers modern probabilistic machine learning in recommendation systems, topic modeling, and generative models.

Definitions

ELBO (Evidence Lower Bound): For data \(x\), latent variables \(z\), and approximate posterior \(q(z)\):

\[\text{ELBO}(q) = \mathbb{E}_{q(z)}[\log p(x|z)] - D_{KL}(q(z) || p(z))\]

Mean-Field Approximation: Factorize the posterior:

\[q(z) = \prod_{i=1}^d q_i(z_i)\]

KL Divergence:

\[D_{KL}(q || p) = \int q(z) \log \frac{q(z)}{p(z|x)} dz\]

Theorem: ELBO as Lower Bound on Log-Evidence

Statement: \(\log p(x) \geq \text{ELBO}(q)\) for any distribution \(q(z)\), with equality iff \(q(z) = p(z|x)\).

Proof: Starting from the definition of log-evidence:

\[\begin{aligned} \log p(x) &= \log \int p(x, z) dz \\ &= \log \int q(z) \frac{p(x, z)}{q(z)} dz \\ &\geq \int q(z) \log \frac{p(x, z)}{q(z)} dz \quad \text{(Jensen's inequality)} \\ &= \mathbb{E}_q[\log p(x, z)] - \mathbb{E}_q[\log q(z)] \\ &= \mathbb{E}_q[\log p(x|z)] + \mathbb{E}_q[\log p(z)] - \mathbb{E}_q[\log q(z)] \\ &= \mathbb{E}_q[\log p(x|z)] - D_{KL}(q(z) || p(z)) = \text{ELBO}(q) \end{aligned}\]

Equality holds when \(\frac{p(x,z)}{q(z)}\) is constant, i.e., \(q(z) \propto p(x,z)\), giving \(q(z) = p(z|x)\). ∎

Notation Guide

  • \(p(x|z)\) - Likelihood
  • \(p(z)\) - Prior
  • \(p(z|x)\) - True posterior
  • \(q(z)\) - Approximate posterior (variational distribution)
  • \(D_{KL}(q||p)\) - Kullback-Leibler divergence
  • \(\text{ELBO}\) - Evidence Lower Bound

import numpy as np
from scipy.special import digamma, gammaln
import matplotlib.pyplot as plt

def gaussian_kl(mu_q, sigma_sq_q, mu_p, sigma_sq_p):
    """
    KL divergence between two univariate Gaussians.
    KL(N(mu_q, sigma_sq_q) || N(mu_p, sigma_sq_p))
    """
    return 0.5 * (np.log(sigma_sq_p / sigma_sq_q) + 
                  sigma_sq_q / sigma_sq_p + 
                  (mu_q - mu_p)**2 / sigma_sq_p - 1)

def beta_kl(alpha_q, beta_q, alpha_p, beta_p):
    """
    KL divergence between two Beta distributions.
    """
    return (gammaln(alpha_p + beta_p) - gammaln(alpha_p) - gammaln(beta_p) -
            gammaln(alpha_q + beta_q) + gammaln(alpha_q) + gammaln(beta_q) +
            (alpha_q - alpha_p) * (digamma(alpha_q) - digamma(alpha_q + beta_q)) +
            (beta_q - beta_p) * (digamma(beta_q) - digamma(alpha_q + beta_q)))

    """
    Variational Inference for Gaussian Mixture Model.
    Uses mean-field approximation.
    """
    def __init__(self, n_components, n_iterations=100):
        self.K = n_components
        self.n_iterations = n_iterations
        
    def fit(self, X):
        self.X = X
        self.N = len(X)
        
        # Initialize variational parameters
        # For cluster assignments (categorical)
        self.phi = np.random.dirichlet(np.ones(self.K), self.N)
        
        # For cluster means (Gaussian)
        self.m = np.random.randn(self.K)
        self.beta = np.ones(self.K)
        self.v = np.ones(self.K)
        
        # For cluster precisions (Gamma)
        self.a = np.ones(self.K)
        self.b = np.ones(self.K)
        
        # Prior parameters
        self.m0 = 0
        self.beta0 = 1
        self.v0 = 1
        self.a0 = 1
        self.b0 = 1
        
        elbos = []
        for iteration in range(self.n_iterations):
            # Update phi (responsibilities)
            E_log_lambda = digamma(self.a) - np.log(self.b)
            E_lambda = self.a / self.b
            E_mu = self.m
            E_mu_sq = 1 / (self.beta * self.v) + self.m**2
            
            for n in range(self.N):
                for k in range(self.K):
                    log_rho = 0.5 * E_log_lambda[k] - 0.5 * np.log(2*np.pi)
                    log_rho += -0.5 * E_lambda[k] * (X[n]**2 - 2*X[n]*E_mu[k] + E_mu_sq[k])
                    self.phi[n, k] = np.exp(log_rho)
                self.phi[n] /= self.phi[n].sum()
            
            # Update m, beta, v (Gaussian parameters)
            Nk = self.phi.sum(axis=0)
            xk = (self.phi.T @ X) / Nk
            
            self.beta = self.beta0 + Nk
            self.m = (self.beta0 * self.m0 + Nk * xk) / self.beta
            
            # Update a, b (Gamma parameters)
            self.a = self.a0 + 0.5 * Nk
            
            for k in range(self.K):
                ss = np.sum(self.phi[:, k] * (X - xk[k])**2)
                self.b[k] = self.b0 + 0.5 * (ss + Nk[k] * self.v0 / (self.beta[k]) * (xk[k] - self.m0)**2)
            
            # Compute ELBO
            elbo = self._compute_elbo()
            elbos.append(elbo)
        
        return elbos
    
    def _compute_elbo(self):
        """Compute Evidence Lower Bound"""
        # This is a simplified computation
        E_log_likelihood = 0
        for n in range(self.N):
            for k in range(self.K):
                E_log_likelihood += self.phi[n, k] * (
                    0.5 * (digamma(self.a[k]) - np.log(self.b[k])) -
                    0.5 * np.log(2*np.pi) -
                    0.5 * self.a[k]/self.b[k] * ((self.X[n] - self.m[k])**2 + 1/(self.beta[k]*self.v[k]))
                )
        
        # KL terms (simplified)
        kl = 0
        for k in range(self.K):
            kl += gaussian_kl(self.m[k], 1/(self.beta[k]*self.v[k]), self.m0, 1/(self.beta0*self.v0))
        
        return E_log_likelihood - kl
    
    def predict(self, X):
        """Predict cluster assignments"""
        probs = np.zeros((len(X), self.K))
        for k in range(self.K):
            probs[:, k] = self.a[k] / self.b[k] * np.exp(-0.5 * self.a[k]/self.b[k] * (X - self.m[k])**2)
        return probs / probs.sum(axis=1, keepdims=True)

Gaussian Processes

Real-World Motivation

Gaussian Processes provide a flexible, probabilistic approach to regression and classification. They naturally quantify uncertainty, making them invaluable for Bayesian optimization (tuning ML hyperparameters), robotics (safe exploration), and environmental monitoring (sparse sensor placement).

Definitions

Gaussian Process: A collection of random variables \(\{f(x)\}_{x \in \mathcal{X}}\) such that any finite collection has a joint Gaussian distribution:

\[f \sim \mathcal{GP}(m(x), k(x, x'))\]

where \(m(x) = \mathbb{E}[f(x)]\) is the mean function and \(k(x, x') = \text{Cov}(f(x), f(x'))\) is the covariance/kernel function.

RBF (Squared Exponential) Kernel:

\[k(x, x') = \sigma^2 \exp\left(-\frac{\|x - x'\|^2}{2\ell^2}\right)\]

where \(\sigma^2\) is signal variance and \(\ell\) is lengthscale.

Theorem: GP Posterior

Statement: Given training data \(\{(x_i, y_i)\}_{i=1}^n\) with \(y_i = f(x_i) + \varepsilon_i\), \(\varepsilon_i \sim \mathcal{N}(0, \sigma_n^2)\), the posterior at test points \(X_*\) is:

\[f_* | X, y, X_* \sim \mathcal{N}(\mu_*, \Sigma_*)\]

where:

\[\mu_* = K(X_*, X)[K(X, X) + \sigma_n^2 I]^{-1}y\]

\[\Sigma_* = K(X_*, X_*) - K(X_*, X)[K(X, X) + \sigma_n^2 I]^{-1}K(X, X_*)\]

Proof: The joint distribution of training and test function values is:

\[\begin{pmatrix} f \\ f_* \end{pmatrix} \sim \mathcal{N}\left(0, \begin{pmatrix} K(X,X) + \sigma_n^2 I & K(X, X_*) \\ K(X_*, X) & K(X_*, X_*) \end{pmatrix}\right)\]

Using the formula for conditional Gaussian distributions:

\[p(f_* | f) = \mathcal{N}(K(X_*, X)K^{-1}f, K(X_*, X_*) - K(X_*, X)K^{-1}K(X, X_*))\]

Substituting the posterior mean for \(f\) gives the result. ∎

Notation Guide

  • \(K(X, X')\) - Kernel matrix with entries \(K_{ij} = k(x_i, x'_j)\)
  • \(\sigma_n^2\) - Observation noise variance
  • \(\ell\) - Lengthscale (how quickly function varies)
  • \(\sigma^2\) - Signal variance
  • \(\mu_*\) - Posterior mean at test points
  • \(\Sigma_*\) - Posterior covariance at test points

import numpy as np
from scipy.spatial.distance import cdist
import matplotlib.pyplot as plt

class GaussianProcess:
    """
    Gaussian Process Regression with RBF kernel.
    """
    def __init__(self, lengthscale=1.0, sigma_f=1.0, sigma_n=0.1):
        self.l = lengthscale
        self.sigma_f = sigma_f
        self.sigma_n = sigma_n
        self.X_train = None
        self.y_train = None
        self.K_inv = None
        
    def rbf_kernel(self, X1, X2):
        """RBF (squared exponential) kernel"""
        sq_dists = cdist(X1, X2, 'sqeuclidean')
        return self.sigma_f**2 * np.exp(-0.5 * sq_dists / self.l**2)
    
    def fit(self, X, y):
        """Train the GP model"""
        self.X_train = X.reshape(-1, 1) if X.ndim == 1 else X
        self.y_train = y
        
        K = self.rbf_kernel(self.X_train, self.X_train)
        K_noisy = K + (self.sigma_n**2 + 1e-8) * np.eye(len(X))
        
        # Precompute inverse for prediction
        self.K_inv = np.linalg.inv(K_noisy)
        
    def predict(self, X_test, return_std=True):
        """
        Make predictions at test points.
        Returns mean and optionally standard deviation.
        """
        X_test = X_test.reshape(-1, 1) if X_test.ndim == 1 else X_test
        
        # Compute kernel matrices
        K_s = self.rbf_kernel(self.X_train, X_test)
        K_ss = self.rbf_kernel(X_test, X_test)
        
        # Posterior mean
        mu_s = K_s.T @ self.K_inv @ self.y_train
        
        if return_std:
            # Posterior covariance
            cov_s = K_ss - K_s.T @ self.K_inv @ K_s
            std_s = np.sqrt(np.diag(cov_s))
            return mu_s, std_s
        return mu_s
    
    def sample_prior(self, X, n_samples=5):
        """Sample functions from the prior"""
        X = X.reshape(-1, 1) if X.ndim == 1 else X
        K = self.rbf_kernel(X, X) + 1e-8 * np.eye(len(X))
        
        # Cholesky decomposition for sampling
        L = np.linalg.cholesky(K)
        
        # Sample from standard normal and transform
        z = np.random.randn(len(X), n_samples)
        samples = L @ z
        
        return samples
    
    def sample_posterior(self, X_test, n_samples=5):
        """Sample functions from the posterior"""
        mu_s, cov_s = self.predict(X_test, return_std=False)
        cov_s = cov_s + 1e-8 * np.eye(len(X_test))  # Numerical stability
        
        L = np.linalg.cholesky(cov_s)
        z = np.random.randn(len(X_test), n_samples)
        samples = mu_s.reshape(-1, 1) + L @ z
        
        return samples
    
    def log_marginal_likelihood(self):
        """Compute log marginal likelihood for hyperparameter optimization"""
        K = self.rbf_kernel(self.X_train, self.X_train)
        K_noisy = K + self.sigma_n**2 * np.eye(len(self.X_train))
        
        L = np.linalg.cholesky(K_noisy)
        alpha = np.linalg.solve(L.T, np.linalg.solve(L, self.y_train))
        
        log_likelihood = -0.5 * self.y_train.T @ alpha
        log_likelihood -= np.sum(np.log(np.diag(L)))
        log_likelihood -= 0.5 * len(self.X_train) * np.log(2 * np.pi)
        
        return log_likelihood

Iwasawa Theory

Historical Context

Developed by Kenkichi Iwasawa in the 1950s-60s, this theory studies the behavior of arithmetic objects (class groups, units) in infinite towers of number fields. It provided the framework for understanding the deep connections between p-adic L-functions and ideal class groups, culminating in the proof of the Main Conjecture by Mazur-Wiles (1984) and later Wiles.

Definitions

\(\mathbb{Z}_p\)-extension: A Galois extension \(K_\infty/K\) with \(\text{Gal}(K_\infty/K) \cong \mathbb{Z}_p\) (the additive group of p-adic integers).

Iwasawa Algebra: The completed group ring:

\[\Lambda = \mathbb{Z}_p[[\Gamma]] = \varprojlim \mathbb{Z}_p[\Gamma/\Gamma^{p^n}]\]

where \(\Gamma \cong \mathbb{Z}_p\). This is isomorphic to the power series ring \(\mathbb{Z}_p[[T]]\).

Iwasawa Module: For the cyclotomic \(\mathbb{Z}_p\)-extension \(K_\infty/K\), let \(A_n\) be the p-part of the class group of the n-th layer. The inverse limit:

\[X = \varprojlim A_n\]

is a finitely generated torsion \(\Lambda\)-module.

Theorem: Iwasawa's Growth Formula

Statement: Let \(K_\infty/K\) be a \(\mathbb{Z}_p\)-extension. Let \(p^{e_n}\) be the order of the p-part of the class group of the n-th layer. Then for sufficiently large \(n\):

\[e_n = \mu p^n + \lambda n + \nu\]

where \(\mu, \lambda, \nu\) are integers independent of \(n\) (the Iwasawa invariants).

Proof: The key is that \(X\) is a finitely generated torsion module over the Noetherian ring \(\Lambda \cong \mathbb{Z}_p[[T]]\). By the structure theorem for such modules:

\[X \sim \bigoplus_i \Lambda/(p^{m_i}) \oplus \bigoplus_j \Lambda/(f_j^{n_j})\]

where \(\sim\) denotes pseudo-isomorphism. The characteristic ideal \((p^\mu \cdot f)\) determines the growth. The \(\mu\)-invariant comes from the p-torsion part, while \(\lambda = \sum_j n_j \deg(f_j)\) comes from the characteristic polynomial. Computing orders in the finite quotients gives the formula. ∎

Notation Guide

  • \(\mathbb{Z}_p\) - Ring of p-adic integers
  • \(\Lambda\) - Iwasawa algebra
  • \(X\) - Iwasawa module (inverse limit of class groups)
  • \(\mu, \lambda, \nu\) - Iwasawa invariants
  • \(A_n\) - p-part of class group at level n
  • \(\Gamma\) - Galois group of the \(\mathbb{Z}_p\)-extension

Thermodynamic Formalism

Historical Context

Developed in the 1970s by Yakov Sinai, Rufus Bowen, and David Ruelle, thermodynamic formalism imports concepts from statistical physics into dynamical systems. It provides a framework for studying chaotic systems through the lens of equilibrium states, pressure, and phase transitions, connecting dynamical systems with probability theory and statistical mechanics.

Definitions

Topological Pressure: For a continuous map \(f: X \to X\) and potential \(\varphi: X \to \mathbb{R}\):

\[P(f, \varphi) = \sup_{\mu \in \mathcal{M}_f} \left\{h_\mu(f) + \int \varphi \, d\mu\right\}\]

where \(\mathcal{M}_f\) is the space of invariant probability measures and \(h_\mu(f)\) is the measure-theoretic entropy.

Equilibrium State: A measure \(\mu\) achieving the supremum in the variational principle.

Gibbs Measure: A measure satisfying for some \(P\) and all \(x\) in a cylinder set \(C_n(x)\):

\[\mu(C_n(x)) \asymp \exp\left(-nP + S_n\varphi(x)\right)\]

where \(S_n\varphi(x) = \sum_{k=0}^{n-1} \varphi(f^k(x))\).

Theorem: Variational Principle

Statement: For a continuous map \(f\) on a compact metric space and continuous potential \(\varphi\):

\[P(f, \varphi) = \sup_{\mu \in \mathcal{M}_f} \left\{h_\mu(f) + \int \varphi \, d\mu\right\}\]

If \(f\) is expansive and has specification, the supremum is attained.

Proof: The proof has two parts:

(1) \(P(f, \varphi) \geq h_\mu(f) + \int \varphi \, d\mu\) for all invariant \(\mu\): This follows from the definition of pressure via spanning sets and the Shannon-McMillan-Breiman theorem.

(2) Equality is achieved: For systems with specification, construct a Gibbs measure using the transfer operator or via the thermodynamic limit of finite approximations. The specification property ensures uniform mixing, allowing construction of measures that concentrate on points maximizing the sum of entropy and average energy. ∎

Notation Guide

  • \(P(f, \varphi)\) - Topological pressure
  • \(h_\mu(f)\) - Kolmogorov-Sinai entropy
  • \(\mathcal{M}_f\) - Space of f-invariant probability measures
  • \(S_n\varphi\) - n-th Birkhoff sum of \(\varphi\)
  • \(C_n(x)\) - n-cylinder containing \(x\)
  • \(\mathcal{L}_\varphi\) - Transfer (Ruelle) operator

def equilibrium_measure_approximation(n_bins=100, n_iterations=1000):
    """
    Approximate equilibrium measure using Ulam's method.
    Discretize space and iterate transition matrix.
    """
    # Discretize [0,1] into bins
    bins = np.linspace(0, 1, n_bins + 1)
    centers = (bins[:-1] + bins[1:]) / 2
    
    # Build transition matrix
    # P_{ij} = probability of going from bin i to bin j
    P = np.zeros((n_bins, n_bins))
    
    for i, c in enumerate(centers):
        # Image of center under tent map
        fc = tent_map(c)
        
        # Find which bin it lands in
        j = np.digitize(fc, bins) - 1
        j = np.clip(j, 0, n_bins - 1)
        
        # Account for both branches
        # f(y) = x has two solutions for x in (0, 1)
        P[i, j] = 1
    
    # Normalize
    P = P / P.sum(axis=1, keepdims=True)
    
    # Find stationary distribution
    # Power iteration
    mu = np.ones(n_bins) / n_bins
    for _ in range(n_iterations):
        mu = mu @ P
    
    return centers, mu

Rough Path Theory

Historical Context

Developed by Terry Lyons in the 1990s, rough path theory provides a deterministic framework for making sense of differential equations driven by irregular signals (like Brownian motion). It extends Ito calculus beyond semimartingales, enabling pathwise treatment of stochastic differential equations and opening new approaches to stochastic PDEs.

Definitions

p-Variation: For a path \(X: [0,T] \to V\) (Banach space):

\[\|X\|_{p-var} = \left(\sup_{\mathcal{P}} \sum_{[s,t] \in \mathcal{P}} |X_t - X_s|^p\right)^{1/p}\]

Rough Path: A pair \(\mathbf{X} = (X, \mathbb{X})\) where \(X\) is a path and \(\mathbb{X}_{s,t}\) is a "second-order" increment satisfying Chen's relation:

\[\mathbb{X}_{s,t} - \mathbb{X}_{s,u} - \mathbb{X}_{u,t} = X_{s,u} \otimes X_{u,t}\]

for all \(s < u < t\).

Controlled Rough Path: A path \(Y\) is controlled by \(X\) if:

\[Y_t = Y_s + Y'_s X_{s,t} + R^Y_{s,t}\]

where \(|R^Y_{s,t}| = O(|t-s|^{2\alpha})\) for Hölder exponent \(\alpha > 1/3\).

Theorem: Lyons' Extension Theorem

Statement: Let \(\mathbf{X}\) be a rough path of finite p-variation with \(2 \leq p < 3\). There exists a unique extension of \(\mathbf{X}\) to all iterated integrals up to order \(\lfloor p \rfloor\), satisfying:

\[\mathbf{X}^n_{s,t} = \int_s^t \mathbf{X}^{n-1}_{s,u} \otimes dX_u\]

in a suitable sense, with the correct Hölder/variational regularity.

Proof: The proof uses the sewing lemma. For a function \(\Xi_{s,t}\) satisfying a coherence condition (approximately additive), there exists a unique function \(I\) such that:

\[|I_t - I_s - \Xi_{s,t}| \leq C |t-s|^\gamma\]

for some \(\gamma > 1\). Applying this iteratively to construct higher-order iterated integrals, using the algebraic structure (shuffle product) to ensure consistency. The key estimate controls the growth of iterated integrals in terms of the p-variation of the underlying path. ∎

Notation Guide

  • \(\|X\|_{p-var}\) - p-variation norm
  • \(\mathbb{X}_{s,t}\) - Second-order process (Lévy area)
  • \(X_{s,t} = X_t - X_s\) - Path increment
  • \(Y'\) - Gubinelli derivative
  • \(R^Y\) - Remainder term
  • \(\mathcal{D}^\alpha_X\) - Space of controlled rough paths

def signature_transform(path, depth=3):
    """
    Compute truncated signature of a path up to given depth.
    Signature: S(X) = (1, X^1, X^2, ..., X^depth)
    where X^n_{0,T} = ∫ ... ∫ dX_{t_1} ⊗ ... ⊗ dX_{t_n}
    """
    n = len(path)
    dim = path.shape[1] if len(path.shape) > 1 else 1
    
    signature = [1.0]  # Level 0
    
    # Level 1: increments
    inc = path[-1] - path[0]
    signature.extend(inc.tolist() if hasattr(inc, 'tolist') else [inc])
    
    # Level 2: double integrals
    if depth >= 2:
        level_2 = np.zeros((dim, dim))
        for i in range(n-1):
            for j in range(i+1, n-1):
                dXi = path[i+1] - path[i]
                dXj = path[j+1] - path[j]
                level_2 += np.outer(dXi, dXj)
        signature.extend(level_2.flatten().tolist())
    
    return signature

def controlled_rough_path_integral(Y, Y_prime, X, X_rough):
    """
    Compute rough integral ∫ Y dX for controlled rough path Y.
    Y is controlled by X if Y_t ≈ Y_s + Y'_s (X_t - X_s)
    """
    n = len(X)
    integral = 0
    
    for i in range(n-1):
        # First-order term

        # ∫ Y dX ≈ Σ Y_i ΔX_i + Y'_i X_rough[i]
        if X_rough is not None:
            integral += Y_prime[i] * X_rough[i]
    
    return integral

Regularity Structures

Historical Context

Martin Hairer's theory of regularity structures (2014 Fields Medal) provides a framework for making sense of singular stochastic PDEs like the KPZ equation and \(\Phi^4_3\) quantum field theory. It systematizes renormalization procedures into an algebraic structure, allowing rigorous treatment of equations previously considered ill-posed.

Definitions

Regularity Structure: A triplet \(\mathscr{T} = (A, T, G)\) where:

  • \(A \subset \mathbb{R}\) is an index set (homogeneities)
  • \(T = \bigoplus_{\alpha \in A} T_\alpha\) is a graded vector space
  • \(G\) is a group of linear operators on \(T\) (structure group)

Model: A collection of distributions \(\Pi_x: T \to \mathcal{D}'(\mathbb{R}^d)\) and maps \(\Gamma_{xy} \in G\) satisfying:

\[\Pi_x \Gamma_{xy} = \Pi_y, \quad \Gamma_{xy} \Gamma_{yz} = \Gamma_{xz}\]

Modelled Distribution: A function \(f: \mathbb{R}^d \to T_{<\gamma}\) such that:

\[f(y) - \Gamma_{yx} f(x) \in T_{\geq \alpha}\]

for some \(\alpha\) and all \(y\) near \(x\).

Theorem: Reconstruction Theorem

Statement: Let \((\Pi, \Gamma)\) be a model for a regularity structure \(\mathscr{T}\). For any modelled distribution \(f\) with regularity \(\gamma > 0\), there exists a unique distribution \(\mathcal{R}f \in \mathcal{D}'(\mathbb{R}^d)\) such that:

\[|(\mathcal{R}f - \Pi_x f(x))(\varphi_x^\lambda)| \lesssim \lambda^\gamma\]

for all test functions \(\varphi\) and scales \(\lambda\).

Proof: The proof constructs \(\mathcal{R}f\) as a limit of mollified approximations. The key estimate uses the wavelet characterization of Besov spaces. For a wavelet basis \(\psi_x^n\) at scale \(2^{-n}\):

\[\mathcal{R}f = \sum_{n \geq 0} \sum_x \langle \mathcal{R}f, \psi_x^n \rangle \psi_x^n\]

The coefficients are defined inductively using the structure of the modelled distribution. The bounds on \(\Pi_x\) and the coherence condition on \(f\) ensure convergence and the reconstruction bound. ∎

Notation Guide

  • \(T_\alpha\) - Homogeneous component of degree \(\alpha\)
  • \(\Pi_x\) - Model at point \(x\)
  • \(\Gamma_{xy}\) - Transition map from \(x\) to \(y\)
  • \(\mathcal{D}^\gamma\) - Space of modelled distributions
  • \(\mathcal{R}\) - Reconstruction operator
  • \(\varphi_x^\lambda(y) = \lambda^{-d}\varphi((y-x)/\lambda)\) - Rescaled test function

def wavelet_basis_1d(n_max, x):
    """
    Construct wavelet basis (simplified using Hermite functions).
    In practice, one would use Daubechies wavelets.
    """

def phi4_discretized_1d(beta, lambda_coupling, n_sites=100, n_iterations=10000):
    """
    1D Φ^4 model on a lattice (simplified simulation).
    Action: S = ∫ (1/2 (∇φ)^2 + (m^2/2) φ^2 + (λ/4!) φ^4) dx
    """
    # Initialize field
    phi = np.random.randn(n_sites)
    
    # Lattice Laplacian (1D)
    def laplacian(phi):
        return np.roll(phi, 1) + np.roll(phi, -1) - 2*phi
    
    # Metropolis-Hastings sampling
    acceptance = 0
    for _ in range(n_iterations):
        for i in range(n_sites):
            # Propose new value
            phi_new = phi.copy()
            phi_new[i] += np.random.randn() * 0.1
            
            # Compute action difference
            delta_S = (0.5 * (laplacian(phi_new)[i] * phi_new[i] - laplacian(phi)[i] * phi[i]) +
                      (beta/2) * (phi_new[i]**2 - phi[i]**2) +
                      (lambda_coupling/24) * (phi_new[i]**4 - phi[i]**4))
            
            # Accept/reject
            if np.random.random() < np.exp(-delta_S):
                phi = phi_new
                acceptance += 1
    
    return phi, acceptance / (n_iterations * n_sites)

def schauder_functions(n_levels, x):
    """
    Construct Schauder functions (Faber-Schauder basis).
    These are piecewise linear functions used in rough path theory.
    """
    functions = [np.ones_like(x)]  # Constant function
    
    for level in range(n_levels):
        n_functions = 2**level
        for k in range(n_functions):
            # Hat function at position k/2^level with width 1/2^level
            center = (2*k + 1) / (2**(level + 1))
            width = 1 / (2**(level + 1))
            
            hat = np.maximum(0, 1 - np.abs(x - center) / width)
            functions.append(hat * 2**(-level/2))
    
    return np.array(functions)

Math History: The Development of Measure Theory

The rigorous theory of measure and integration emerged from the need to handle pathological functions and sets that emerged in the late 19th century. Mathematicians like Cantor had shown that the real numbers contained strange sets—nowhere dense sets of positive measure, uncountable sets of measure zero—that defied intuitive geometric understanding.

Émile Borel laid the groundwork in 1898 by defining measures for sets built from intervals through countable operations. His work established that length could be extended to a much broader class of sets while preserving countable additivity. However, Borel's construction was limited to Borel sets, and important subsets of the reals remained outside his framework.

Henri Lebesgue's 1902 doctoral thesis revolutionized integration theory. By completing the Borel sigma-algebra—adding all subsets of measure-zero sets—Lebesgue created the Lebesgue sigma-algebra, strictly larger than the Borel sigma-algebra. His integral could handle limits of functions in ways the Riemann integral could not, enabling the powerful convergence theorems (Monotone Convergence, Dominated Convergence) that form the foundation of modern analysis.

The development was not without controversy. The axiom of choice, used to construct non-measurable sets (Vitali, 1905), sparked debates about the foundations of mathematics. Giuseppe Vitali showed that there exist subsets of the reals that cannot be assigned a Lebesgue measure consistent with translation invariance. This result, initially disturbing, ultimately clarified the boundaries of measurable sets.

By the 1930s, the abstract formulation of measure theory by Kolmogorov, Carathéodory, and others had unified probability theory with analysis. Kolmogorov's 1933 axioms defined probability as a normalized measure, providing the rigorous foundation for stochastic processes that would become essential in physics, engineering, and finance. The theory continues to evolve, with applications in geometric measure theory, ergodic theory, and mathematical physics.

IMO 2023 Problem 5

Let \(n\) be a positive integer. A Japanese triangle consists of \(1 + 2 + \cdots + n\) circles arranged in an equilateral triangular shape such that for each \(i = 1, 2, \ldots, n\), the \(i\)-th row contains exactly \(i\) circles, exactly one of which is colored red. A ninja path in a Japanese triangle is a sequence of \(n\) circles obtained by starting in the top row, then repeatedly going from a circle to one of the two circles immediately below it, and finishing in the bottom row. Find the maximum possible number of ninja paths that contain a red circle, over all Japanese triangles.

Hint

Consider the binary representation of positions. Each ninja path corresponds to a sequence of left/right choices. Use a recursive argument or consider the structure of the triangle as a binary tree. The answer involves powers of 2.

Solution

The answer is \(2^{n-1}\).

Proof: Each ninja path corresponds to a sequence of \(n-1\) binary choices (left or right at each step), so there are \(2^{n-1}\) total paths.

For the upper bound: Consider the set of all ninja paths. Each path passes through exactly one circle in each row. For a fixed row \(i\), there are \(i\) circles and exactly one is red. By symmetry, each circle in row \(i\) is visited by exactly \(2^{n-1}/i\) paths (when this is an integer, or approximately so).

To achieve \(2^{n-1}\) paths through red circles, we need every path to pass through a red circle. This is impossible for \(n \geq 2\) since there are more paths than red circles.

The correct construction: Place red circles so that the set of paths through red circles forms a "complete binary subtree." Specifically, place red circles at positions that ensure every path passes through at least one red circle.

Actually, the maximum is achieved by placing all red circles along a single ninja path. Then exactly \(2^{n-1}\) paths intersect this path (counting the path itself and all paths that share at least one circle with it).

More carefully: Each path shares exactly one circle with any given vertical line through the triangle. The optimal strategy places red circles to maximize coverage. The answer \(2^{n-1}\) is achieved when red circles are placed so that every path contains exactly one red circle.

This requires the red circles to form a "transversal" of the path set. The construction: in row \(i\), place the red circle at position \(\lceil i/2 \rceil\) (or similar symmetric placement). One can verify that every ninja path contains exactly one red circle, giving the maximum \(2^{n-1}\). ∎

Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) with \(z_0 = 0\) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute number of iterations until escape for point c"""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """Compute Mandelbrot set on a grid"""
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M
