Complex Dynamics and the Mandelbrot Set

Motivation

Complex dynamics studies the iteration of holomorphic functions, revealing intricate fractal structures that emerge from simple iterative processes. The field bridges complex analysis, topology, and dynamical systems, producing some of the most visually stunning objects in mathematics. The Mandelbrot set, in particular, has captured public imagination while remaining an active area of research with deep connections to hyperbolic geometry and renormalization theory.

Definitions

Julia Set: For a rational function \(f : \widehat{\mathbb{C}} \to \widehat{\mathbb{C}}\), the filled Julia set \(K(f)\) is the set of points with bounded forward orbit. The Julia set \(J(f) = \partial K(f)\) is the boundary of this set.

Fatou Set: The complement of the Julia set, where the iterates of \(f\) form a normal family. The Fatou set is open and consists of domains where the dynamics are stable.

Mandelbrot Set: The set \(\mathcal{M} = \{c \in \mathbb{C} : \text{the sequence } z_{n+1} = z_n^2 + c \text{ remains bounded}\}\). Equivalently, \(\mathcal{M} = \{c : 0 \in K(f_c)\}\) where \(f_c(z) = z^2 + c\).

Hyperbolic Component: A connected component of the interior of \(\mathcal{M}\) where the corresponding quadratic polynomial has an attracting periodic cycle.

Theorem and Proof

Theorem (Douady-Hubbard, 1980s): The Mandelbrot set \(\mathcal{M}\) is connected.

Proof Sketch: The proof uses the Böttcher coordinate near infinity. For \(|z|\) large, the map \(f_c(z) = z^2 + c\) behaves like \(z \mapsto z^2\). There exists a conformal map \(\phi_c\) conjugating \(f_c\) to \(z \mapsto z^2\) on a neighborhood of infinity: \(\phi_c(f_c(z)) = (\phi_c(z))^2\).

The Böttcher coordinate can be written as \(\phi_c(z) = \lim_{n \to \infty} (f_c^n(z))^{1/2^n}\). The Green's function \(G_c(z) = \log|\phi_c(z)|\) measures the escape rate.

Define \(\Phi(c) = \phi_c(c)\) for \(c \in \mathbb{C} \setminus \mathcal{M}\). This map is analytic, and one shows that \(\Phi : \mathbb{C} \setminus \mathcal{M} \to \mathbb{C} \setminus \overline{\mathbb{D}}\) is a conformal isomorphism. Since \(\mathbb{C} \setminus \overline{\mathbb{D}}\) is connected and \(\Phi\) is a homeomorphism, \(\mathbb{C} \setminus \mathcal{M}\) is connected, hence \(\mathcal{M}\) is connected.

Notation Guide

  • \(\widehat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}\) — Riemann sphere
  • \(f^n\) — \(n\)-th iterate of \(f\)
  • \(K(f)\) — filled Julia set
  • \(J(f)\) — Julia set
  • \(\phi_c\) — Böttcher coordinate
  • \(G_c(z)\) — Green's function (escape rate)

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot_set(width, height, x_min=-2.5, x_max=1.0, y_min=-1.25, y_max=1.25, max_iter=100):
    """
    Compute the Mandelbrot set.
    For each c, iterate z_{n+1} = z_n^2 + c starting from z_0 = 0.
    """
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j * Y
    
    Z = np.zeros_like(C)
    iterations = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        mask_new = np.abs(Z) <= 2
        iterations[~mask_new & (iterations == 0)] = i
        mask = mask_new
    
    iterations[mask] = max_iter
    return iterations

def julia_set(c, width, height, x_min=-2, x_max=2, y_min=-2, y_max=2, max_iter=100):

    Compute the Julia set for parameter c.
    Iterate z_{n+1} = z_n^2 + c for each starting point z_0.
    """

    y = np.linspace(y_min, y_max, height)

        mask_new = np.abs(Z) <= 2
        iterations[~mask_new & (iterations == 0)] = i
        mask = mask_new
    
    iterations[mask] = max_iter
    return iterations

Ergodic Theory and Dynamical Systems

Motivation

Ergodic theory studies dynamical systems with an invariant measure, connecting statistical mechanics to pure mathematics. It answers questions about the long-term behavior of systems: Does time average equal space average? Do trajectories visit all regions with the right frequency? These questions, originating in Boltzmann's ergodic hypothesis, have profound implications for number theory (uniform distribution), geometry (geodesic flows), and probability theory.

Definitions

Measure-Preserving System: A quadruple \((X, \mathcal{B}, \mu, T)\) where \((X, \mathcal{B}, \mu)\) is a probability space and \(T : X \to X\) is a measurable map satisfying \(\mu(T^{-1}(A)) = \mu(A)\) for all measurable \(A\).

Ergodicity: A measure-preserving system is ergodic if every invariant measurable set has measure 0 or 1. Equivalently, the only \(L^2\) functions satisfying \(f \circ T = f\) almost everywhere are constants.

Mixing: A stronger property than ergodicity: \(\lim_{n \to \infty} \mu(T^{-n}(A) \cap B) = \mu(A)\mu(B)\) for all measurable sets \(A, B\).

Entropy: The Kolmogorov-Sinai entropy \(h_\mu(T)\) measures the information production rate of the system. For a partition \(\mathcal{P}\), \(h_\mu(T, \mathcal{P}) = \lim_{n \to \infty} \frac{1}{n} H\left(\bigvee_{i=0}^{n-1} T^{-i}\mathcal{P}\right)\).

Theorem and Proof

Birkhoff's Ergodic Theorem: Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(f \in L^1(\mu)\). Then the time averages converge almost everywhere: \[\lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x)) = \mathbb{E}[f | \mathcal{I}](x)\] where \(\mathcal{I}\) is the \(\sigma\)-algebra of invariant sets. If the system is ergodic, this equals \(\int f \, d\mu\) almost everywhere.

Proof Sketch: Define the maximal function \(f^*(x) = \sup_{n \geq 1} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x))\). The key is the maximal inequality: for any \(\lambda > 0\), \[\mu(\{x : f^*(x) > \lambda\}) \leq \frac{1}{\lambda} \int_{f^* > \lambda} f \, d\mu\]

Let \(g = f - \mathbb{E}[f|\mathcal{I}]\). Then \(\mathbb{E}[g|\mathcal{I}] = 0\). For any \(\epsilon > 0\), define \(g_\epsilon = g + \epsilon\). One shows that \(\limsup_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} g(T^k(x)) \leq 0\) almost everywhere by applying the maximal inequality to truncated versions of \(g_\epsilon\).

Applying the same argument to \(-g\) gives the reverse inequality, establishing convergence to 0. For ergodic systems, \(\mathcal{I}\) is trivial, so \(\mathbb{E}[f|\mathcal{I}] = \int f \, d\mu\).

Notation Guide

  • \(T^{-1}(A)\) — preimage of set \(A\)
  • \(L^1(\mu)\) — space of integrable functions
  • \(\mathbb{E}[f|\mathcal{I}]\) — conditional expectation
  • \(h_\mu(T)\) — measure-theoretic entropy
  • \(H(\mathcal{P}) = -\sum_{P \in \mathcal{P}} \mu(P) \log \mu(P)\) — Shannon entropy

import numpy as np
import matplotlib.pyplot as plt

def circle_rotation(theta, alpha, n_iter):
    """
    Circle rotation: T(x) = x + alpha (mod 1)
    This is ergodic iff alpha is irrational.
    """
    trajectory = np.zeros(n_iter)
    x = theta
    for i in range(n_iter):
        trajectory[i] = x
        x = (x + alpha) % 1.0
    return trajectory

def doubling_map(x, n_iter):
    """
    Doubling map: T(x) = 2x (mod 1)
    This is mixing and has entropy log(2).
    """
    trajectory = np.zeros(n_iter)
    for i in range(n_iter):
        trajectory[i] = x
        x = (2 * x) % 1.0
    return trajectory

def bernoulli_shift(p, n_iter, sequence_length=1000):
    """
    Bernoulli shift on binary sequences.
    T(x_0, x_1, x_2, ...) = (x_1, x_2, x_3, ...)
    """
    # Generate random sequence
    sequence = (np.random.random(sequence_length) < p).astype(int)
    
    # Compute time average of first coordinate
    time_avg = np.cumsum(sequence) / np.arange(1, len(sequence) + 1)
    return time_avg

def continued_fraction_expansion(alpha, n_terms=20):
    """
    Compute continued fraction expansion [a0; a1, a2, ...] of alpha.
    Related to the Gauss map T(x) = {1/x} (fractional part).
    """
    coeffs = []
    x = alpha
    for _ in range(n_terms):
        a = int(x)
        coeffs.append(a)
        if abs(x - a) < 1e-10:
            break
        x = 1.0 / (x - a)
    return coeffs

Homotopy Groups and Algebraic Topology

Motivation

Homotopy groups provide a systematic way to classify topological spaces based on the behavior of spheres mapped into them. While homology groups capture "holes" of various dimensions, homotopy groups capture more subtle information about the complexity of paths and higher-dimensional spheres. The fundamental group \(\pi_1\) classifies covering spaces, while higher homotopy groups \(\pi_n\) for \(n \geq 2\) are abelian and connect to vector bundles, characteristic classes, and stable homotopy theory.

Definitions

Homotopy: Maps \(f, g : X \to Y\) are homotopic (\(f \simeq g\)) if there exists a continuous \(H : X \times [0,1] \to Y\) with \(H(x,0) = f(x)\) and \(H(x,1) = g(x)\).

nth Homotopy Group: \(\pi_n(X, x_0)\) is the set of homotopy classes of maps \((I^n, \partial I^n) \to (X, x_0)\), or equivalently maps \(S^n \to X\) sending a basepoint to \(x_0\). The group operation is concatenation for \(n = 1\) and higher-dimensional analogues for \(n \geq 2\).

Simply Connected: A space is simply connected if it is path-connected and \(\pi_1(X) = 0\).

Weak Homotopy Equivalence: A map \(f : X \to Y\) inducing isomorphisms on all \(\pi_n\) for all basepoints.

Theorem and Proof

Hurewicz Theorem: Let \(X\) be an \((n-1)\)-connected space (\(\pi_k(X) = 0\) for \(k < n\)) with \(n \geq 2\). Then \(\tilde{H}_k(X) = 0\) for \(k < n\) and the Hurewicz map \(h : \pi_n(X) \to H_n(X)\) is an isomorphism.

Proof Sketch: The Hurewicz map sends a homotopy class \([f : S^n \to X]\) to the homology class \(f_*[S^n]\) where \([S^n]\) is the fundamental class of the sphere.

For the case \(n = 1\), the Hurewicz theorem states that \(h : \pi_1(X)^{ab} \to H_1(X)\) is an isomorphism, where \(\pi_1(X)^{ab}\) is the abelianization.

For \(n \geq 2\), the proof proceeds by induction using the long exact sequence of a fibration. Consider the path space fibration \(\Omega X \to PX \to X\) where \(PX\) is contractible. The homotopy exact sequence gives \(\pi_k(\Omega X) \cong \pi_{k+1}(X)\).

If \(X\) is \((n-1)\)-connected, then \(\Omega X\) is \((n-2)\)-connected. By induction, the Hurewicz map for \(\Omega X\) is an isomorphism in dimension \(n-1\). Using the relationship between the homology of \(X\) and \(\Omega X\) via the Serre spectral sequence, one establishes that \(h : \pi_n(X) \to H_n(X)\) is an isomorphism.

Notation Guide

  • \(\pi_n(X, x_0)\) — nth homotopy group
  • \(\Omega X\) — loop space of \(X\)
  • \(\Sigma X\) — suspension of \(X\)
  • \([X, Y]\) — set of homotopy classes of maps
  • \(h : \pi_n(X) \to H_n(X)\) — Hurewicz homomorphism
  • \(K(G, n)\) — Eilenberg-MacLane space

Reinforcement Learning and Markov Decision Processes

Real-World Motivation

Reinforcement learning (RL) powers systems from game-playing AI (AlphaGo, AlphaZero) to robotics control, autonomous vehicles, and recommendation systems. Unlike supervised learning, RL agents learn through interaction with an environment, receiving rewards or penalties for their actions. The mathematical foundation rests on Markov Decision Processes (MDPs) and Bellman equations, with deep connections to dynamic programming, optimal control, and stochastic approximation.

Definitions

Markov Decision Process: A tuple \((\mathcal{S}, \mathcal{A}, P, R, \gamma)\) where \(\mathcal{S}\) is the state space, \(\mathcal{A}\) is the action space, \(P(s'|s,a)\) is the transition probability, \(R(s,a)\) is the reward function, and \(\gamma \in [0,1)\) is the discount factor.

Policy: A mapping \(\pi : \mathcal{S} \to \Delta(\mathcal{A})\) from states to probability distributions over actions. A deterministic policy selects a single action: \(\pi(s) = a\).

Value Function: The expected cumulative reward starting from state \(s\) and following policy \(\pi\): \[V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t) \bigg| s_0 = s, \pi\right]\]

Q-Function: The expected cumulative reward starting from state \(s\), taking action \(a\), then following \(\pi\): \[Q^\pi(s,a) = R(s,a) + \gamma \mathbb{E}_{s' \sim P(\cdot|s,a)}[V^\pi(s')]\]

Theorem and Proof

Bellman Optimality Equation: The optimal value function \(V^*\) satisfies: \[V^*(s) = \max_{a \in \mathcal{A}} \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \right]\]

Furthermore, \(V^*\) is the unique solution to this equation, and the optimal policy \(\pi^*\) is given by: \[\pi^*(s) = \arg\max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \right]\]

Proof Sketch: Define the Bellman optimality operator \(\mathcal{T}^* : V \mapsto \max_a [R(\cdot, a) + \gamma P(\cdot| \cdot, a)V]\). We show \(\mathcal{T}^*\) is a contraction in the sup norm:

\[\|\mathcal{T}^* V - \mathcal{T}^* W\|_\infty \leq \gamma \|V - W\|_\infty\]

This follows because: \[\|\max_a f(a) - \max_a g(a)\| \leq \max_a \|f(a) - g(a)\|\]

By the Banach fixed-point theorem, \(\mathcal{T}^*\) has a unique fixed point. One verifies that \(V^*\) (the value of the optimal policy) satisfies \(V^* = \mathcal{T}^* V^*\) by considering the first step and the remaining trajectory. Conversely, any fixed point must equal \(V^*\) by optimality principles.

Notation Guide

  • \(\mathcal{S}, \mathcal{A}\) — state and action spaces
  • \(P(s'|s,a)\) — transition probability
  • \(\gamma\) — discount factor
  • \(V^\pi(s)\) — value function under policy \(\pi\)
  • \(Q^\pi(s,a)\) — action-value function
  • \(\mathcal{T}^\pi, \mathcal{T}^*\) — Bellman operators

class GridWorld:
    """
    Simple grid world MDP.
    Agent navigates from start to goal, avoiding obstacles.
    """
    def __init__(self, size=5):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4  # up, down, left, right
        
        # Define rewards
        self.rewards = np.zeros((size, size))
        self.rewards[size-1, size-1] = 1.0  # Goal
        self.rewards[2, 2] = -1.0  # Obstacle
        
    def state_to_pos(self, s):
        return s // self.size, s % self.size
    
    def pos_to_state(self, i, j):
        return i * self.size + j
    
    def get_transition(self, s, a):
        """Get next state distribution for (s, a)."""
        i, j = self.state_to_pos(s)
        
        # Actions: 0=up, 1=down, 2=left, 3=right
        moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        di, dj = moves[a]
        ni, nj = i + di, j + dj
        
        # Check bounds
        if 0 <= ni < self.size and 0 <= nj < self.size:
            return self.pos_to_state(ni, nj)
        return s  # Stay in place if out of bounds
    
    def value_iteration(self, gamma=0.9, theta=1e-6):
        """Solve MDP using value iteration."""
        V = np.zeros(self.n_states)
        
        while True:
            delta = 0
            for s in range(self.n_states):
                i, j = self.state_to_pos(s)
                v = V[s]
                
                # Compute Q-values for all actions
                Q = np.zeros(self.n_actions)
                for a in range(self.n_actions):
                    s_next = self.get_transition(s, a)
                    i_next, j_next = self.state_to_pos(s_next)
                    Q[a] = self.rewards[i_next, j_next] + gamma * V[s_next]
                
                V[s] = np.max(Q)
                delta = max(delta, abs(v - V[s]))
            
            if delta < theta:
                break
        
        # Extract optimal policy
        policy = np.zeros(self.n_states, dtype=int)
        for s in range(self.n_states):
            Q = np.zeros(self.n_actions)
            for a in range(self.n_actions):
                s_next = self.get_transition(s, a)
                i_next, j_next = self.state_to_pos(s_next)
                Q[a] = self.rewards[i_next, j_next] + gamma * V[s_next]
            policy[s] = np.argmax(Q)
        
        return V, policy

def q_learning(env, n_episodes=1000, alpha=0.1, gamma=0.9, epsilon=0.1):
    """
    Q-learning: off-policy temporal difference control.
    """
    Q = np.zeros((env.n_states, env.n_actions))
    
    for episode in range(n_episodes):
        s = 0  # Start state
        
        while True:
            # Epsilon-greedy action selection
            if np.random.random() < epsilon:
                a = np.random.randint(env.n_actions)
            else:
                a = np.argmax(Q[s])
            
            # Take action
            s_next = env.get_transition(s, a)
            i_next, j_next = env.state_to_pos(s_next)
            r = env.rewards[i_next, j_next]
            
            # Q-learning update
            Q[s, a] += alpha * (r + gamma * np.max(Q[s_next]) - Q[s, a])
            
            s = s_next
            
            # Terminal state
            if (i_next, j_next) == (env.size-1, env.size-1):
                break
    
    policy = np.argmax(Q, axis=1)
    return Q, policy

Computational Topology and Persistent Homology

Real-World Motivation

Computational topology extracts robust topological features from noisy data, with applications in material science (pore structure analysis), neuroscience (brain connectivity), genomics (chromosome structure), and machine learning (topological data analysis). Unlike geometric methods that depend on precise measurements, topological features like connected components, holes, and voids are invariant under continuous deformations, making them highly robust to noise and sampling variations.

Definitions

Simplicial Complex: A collection \(K\) of simplices (vertices, edges, triangles, tetrahedra) such that every face of a simplex in \(K\) is in \(K\), and the intersection of any two simplices is a face of both.

Vietoris-Rips Complex: For a metric space \((X, d)\) and scale \(\epsilon > 0\), the Rips complex \(VR_\epsilon(X)\) has a simplex for every finite subset of \(X\) with diameter \(< \epsilon\).

Persistent Homology: Given a filtration \(\emptyset = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_n = K\), persistent homology tracks the birth and death of homology classes as the filtration parameter increases. A class born at \(K_i\) and dying at \(K_j\) has persistence \(j - i\).

Barcode: A graphical representation of persistent homology where each interval \([b, d)\) represents a topological feature born at \(b\) and dying at \(d\).

Theorem and Proof

Stability Theorem (Cohen-Steiner, Edelsbrunner, Harer, 2007): Let \(f, g : X \to \mathbb{R}\) be tame functions on a triangulable space. The bottleneck distance between their persistence diagrams is bounded by the difference of the functions: \[d_B(\text{Dgm}(f), \text{Dgm}(g)) \leq \|f - g\|_\infty\]

Proof Sketch: The proof uses the interleaving of sublevel set filtrations. For functions with \(\|f - g\|_\infty \leq \epsilon\), we have inclusions: \[f^{-1}(-\infty, a] \subseteq g^{-1}(-\infty, a+\epsilon] \subseteq f^{-1}(-\infty, a+2\epsilon]\]

This \(\epsilon\)-interleaving induces maps on homology that commute with the structure maps of the persistence modules. The algebraic stability theorem states that if two persistence modules are \(\epsilon\)-interleaved, then their persistence diagrams are at bottleneck distance at most \(\epsilon\).

The bottleneck distance is defined as the minimum, over all bijections \(\gamma\) between the diagrams (including points at infinity), of the maximum distance between matched points. The stability result ensures that small perturbations in the input data produce only small changes in the topological summary.

Notation Guide

  • \(VR_\epsilon(X)\) — Vietoris-Rips complex at scale \(\epsilon\)
  • \(H_k(K)\) — k-th homology group of complex \(K\)
  • \(\beta_k = \dim H_k\) — k-th Betti number
  • \([b, d)\) — persistence interval (birth, death)
  • \(d_B\) — bottleneck distance between diagrams
  • \(d_W\) — Wasserstein distance

import numpy as np

from scipy.spatial.distance import pdist, squareform

def rips_complex(points, epsilon):
    """
    Construct Vietoris-Rips complex at scale epsilon.
    Returns adjacency matrix and list of simplices.
    """
    n = len(points)
    distances = squareform(pdist(points))
    
    # Edges: pairs with distance < epsilon
    edges = []
    for i in range(n):
        for j in range(i+1, n):
            if distances[i, j] < epsilon:
                edges.append((i, j))
    
    # Triangles: triples where all edges exist
    triangles = []
    for i in range(n):
        for j in range(i+1, n):
            for k in range(j+1, n):
                if (distances[i,j] < epsilon and 
                    distances[j,k] < epsilon and 
                    distances[i,k] < epsilon):
                    triangles.append((i, j, k))
    
    return edges, triangles, distances

def compute_betti_0(edges, n_vertices):
    """
    Compute β₀ (number of connected components) using Union-Find.
    """
    parent = list(range(n_vertices))
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    
    def union(x, y):
        px, py = find(x), find(y)
        if px != py:
            parent[px] = py
    
    for i, j in edges:
        union(i, j)
    
    # Count unique roots
    components = len(set(find(i) for i in range(n_vertices)))
    return components

def compute_betti_1(n_vertices, edges, triangles):
    """
    Compute β₁ (number of 1-dimensional holes).
    β₁ = |E| - |V| + |C| - rank(boundary of triangles)
    For small examples, we use a simplified calculation.
    """
    if not edges:
        return 0
    
    # Euler characteristic: χ = V - E + T = β₀ - β₁ + β₂
    # For planar graphs: β₁ = E - V + β₀
    beta_0 = compute_betti_0(edges, n_vertices)
    beta_1 = len(edges) - n_vertices + beta_0
    
    # Subtract contributions from filled triangles
    # Each triangle reduces β₁ by 1 if it fills a cycle
    beta_1 = max(0, beta_1 - len(triangles))
    
    return beta_1

def persistent_homology_0(points, max_epsilon=2.0, n_steps=50):
    """
    Compute 0-dimensional persistent homology (connected components).
    Returns birth times for each component.
    """
    distances = squareform(pdist(points))
    n = len(points)
    
    epsilons = np.linspace(0, max_epsilon, n_steps)
    betti_0_history = []
    
    for eps in epsilons:
        edges = [(i, j) for i in range(n) for j in range(i+1, n) 
                 if distances[i, j] < eps]
        beta_0 = compute_betti_0(edges, n)
        betti_0_history.append(beta_0)
    
    return epsilons, betti_0_history

Statistical Learning Theory and Generalization Bounds

Real-World Motivation

Statistical learning theory provides the mathematical foundations for understanding when and why machine learning models generalize from training data to unseen examples. As deep neural networks with millions of parameters can perfectly memorize training data yet still generalize well, classical statistical theory based on parameter counting fails. Modern learning theory develops new frameworks—Rademacher complexity, PAC-Bayes bounds, and uniform convergence—to explain this phenomenon and guide the design of learning algorithms.

Definitions

Risk: The expected loss of a hypothesis \(h\) under the true data distribution \(\mathcal{D}\): \[R(h) = \mathbb{E}_{(x,y) \sim \mathcal{D}}[L(h(x), y)]\]

Empirical Risk: The average loss on a training sample \(S = \{(x_i, y_i)\}_{i=1}^n\): \[\hat{R}_S(h) = \frac{1}{n} \sum_{i=1}^n L(h(x_i), y_i)\]

Rademacher Complexity: For a hypothesis class \(\mathcal{H}\) and sample \(S\): \[\hat{\mathfrak{R}}_S(\mathcal{H}) = \mathbb{E}_\sigma \left[\sup_{h \in \mathcal{H}} \frac{1}{n} \sum_{i=1}^n \sigma_i h(x_i)\right]\] where \(\sigma_i \in \{-1, +1\}\) are Rademacher random variables.

VC Dimension: The largest set that can be shattered by \(\mathcal{H}\). A set is shattered if \(\mathcal{H}\) can realize all possible labelings.

Theorem and Proof

Generalization Bound via Rademacher Complexity: With probability at least \(1 - \delta\) over the draw of sample \(S\) of size \(n\): \[\sup_{h \in \mathcal{H}} |R(h) - \hat{R}_S(h)| \leq 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\log(1/\delta)}{2n}}\]

For binary classification with loss bounded by 1, with probability at least \(1 - \delta\): \[R(h) \leq \hat{R}_S(h) + 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\log(1/\delta)}{2n}}\]

Proof Sketch: The proof uses symmetrization. Let \(S'\) be a ghost sample (independent copy of \(S\)). By Jensen's inequality: \[\mathbb{E}_S\left[\sup_{h \in \mathcal{H}} (R(h) - \hat{R}_S(h))\right] \leq \mathbb{E}_{S,S'}\left[\sup_{h \in \mathcal{H}} (\hat{R}_{S'}(h) - \hat{R}_S(h))\right]\]

The difference \(\hat{R}_{S'}(h) - \hat{R}_S(h)\) can be written as: \[\frac{1}{n} \sum_{i=1}^n \frac{1}{n} \sum_{j=1}^n (L(h(x'_j), y'_j) - L(h(x_i), y_i))\]

Introducing Rademacher variables \(\sigma_i\) and using that \((x_i, y_i)\) and \((x'_i, y'_i)\) are i.i.d.: \[\mathbb{E}_{S,S'}\left[\sup_h \frac{1}{n} \sum_{i=1}^n \sigma_i (L(h(x'_i), y'_i) - L(h(x_i), y_i))\right] \leq 2\mathfrak{R}_n(\mathcal{H})\]

McDiarmid's inequality provides the concentration bound to obtain the high-probability statement.

Notation Guide

  • \(R(h)\) — true risk (expected loss)
  • \(\hat{R}_S(h)\) — empirical risk
  • \(\mathfrak{R}_n(\mathcal{H})\) — Rademacher complexity
  • \(\text{VC}(\mathcal{H})\) — VC dimension
  • \(L(h(x), y)\) — loss function
  • \(\mathcal{H}\) — hypothesis class

def empirical_rademacher_complexity(X, hypothesis_class, n_samples=100):
    """
    Estimate Rademacher complexity for a hypothesis class.
    
    For a function class F, the empirical Rademacher complexity is:
    R̂_S(F) = E_σ[sup_{f ∈ F} (1/n) Σ σ_i f(x_i)]
    """
    n = len(X)
    complexities = []
    
    for _ in range(n_samples):
        # Generate Rademacher random variables
        sigma = np.random.choice([-1, 1], size=n)
        
        # For a simple hypothesis class (linear classifiers through origin),
        # the supremum is achieved by aligning with sigma
        max_correlation = 0
        for h in hypothesis_class:
            predictions = h(X)
            correlation = np.mean(sigma * predictions)
            max_correlation = max(max_correlation, correlation)
        
        complexities.append(max_correlation)
    
    return np.mean(complexities)

def generate_linear_classifiers(n_classifiers, d):
    """Generate random linear classifiers."""
    weights = np.random.randn(n_classifiers, d)
    weights = weights / np.linalg.norm(weights, axis=1, keepdims=True)
    
    def make_classifier(w):
        return lambda X: np.sign(X @ w)
    
    return [make_classifier(w) for w in weights]

def vc_dimension_bound(n, d_vc, delta=0.05):
    """
    VC generalization bound:
    R(h) ≤ R̂_S(h) + O(sqrt((d_VC log(n/d_VC) + log(1/δ))/n))
    """
    if n <= d_vc:
        return float('inf')
    return np.sqrt((d_vc * np.log(n / d_vc) + np.log(1/delta)) / n)

def rademacher_bound(n, rad_complexity, delta=0.05):
    """
    Rademacher complexity generalization bound.
    """
    return 2 * rad_complexity + np.sqrt(np.log(1/delta) / (2 * n))

Class Field Theory and Abelian Extensions

Historical Context

Class field theory, developed in the early 20th century by Hilbert, Takagi, Artin, and Hasse, represents one of the crowning achievements of algebraic number theory. It provides a complete description of all abelian extensions of a number field (or local field) in terms of the arithmetic of the base field itself. The theory establishes a correspondence between abelian extensions and generalized ideal class groups (or idele class groups), with the Artin reciprocity map serving as the bridge. This "class field" philosophy—that extensions are classified by data intrinsic to the base field—has inspired vast generalizations, including the Langlands program.

Definitions

Ray Class Group: For a modulus \(\mathfrak{m}\) (a formal product of places), the ray class group \(\text{Cl}_\mathfrak{m}(K)\) is the quotient of fractional ideals coprime to \(\mathfrak{m}\) by principal ideals generated by elements congruent to 1 modulo \(\mathfrak{m}\).

Artin Map: For an abelian extension \(L/K\) and unramified prime \(\mathfrak{p}\) of \(K\), the Artin symbol \(\left(\frac{L/K}{\mathfrak{p}}\right) \in \text{Gal}(L/K)\) is the Frobenius automorphism. Extended multiplicatively to all ideals, this gives the Artin map \(\psi_{L/K} : I_K^\mathfrak{m} \to \text{Gal}(L/K)\).

Hilbert Class Field: The maximal unramified abelian extension \(H\) of \(K\). Its Galois group \(\text{Gal}(H/K) \cong \text{Cl}(K)\), the ideal class group.

Theorem and Proof

Artin Reciprocity Law: Let \(L/K\) be an abelian extension of number fields with conductor \(\mathfrak{f}\). The Artin map induces an isomorphism: \[\text{Cl}_\mathfrak{f}(K) / N_{L/K}(\text{Cl}_\mathfrak{f}(L)) \cong \text{Gal}(L/K)\]

In particular, for the Hilbert class field \(H\): \[\text{Cl}(K) \cong \text{Gal}(H/K)\]

Proof Sketch: The proof proceeds through several stages. First, one establishes the existence of ray class fields: for each modulus \(\mathfrak{m}\), there exists a unique abelian extension \(K_\mathfrak{m}/K\) such that the Artin map gives \(\text{Cl}_\mathfrak{m}(K) \cong \text{Gal}(K_\mathfrak{m}/K)\).

The key analytic ingredient is the first and second inequalities: \[[I_K^\mathfrak{m} : P_K^\mathfrak{m} \cdot N_{L/K}(I_L^\mathfrak{m})] \leq [L : K] \leq [I_K^\mathfrak{m} : P_K^\mathfrak{m} \cdot N_{L/K}(I_L^\mathfrak{m})]\]

The first inequality uses properties of Artin \(L\)-functions and the non-vanishing of \(L(1, \chi)\) for non-principal characters. The second inequality uses Kummer theory or cohomological methods. When they coincide, the Artin map is an isomorphism.

Notation Guide

  • \(\text{Cl}(K)\) — ideal class group of \(K\)
  • \(\text{Cl}_\mathfrak{m}(K)\) — ray class group modulo \(\mathfrak{m}\)
  • \(\left(\frac{L/K}{\mathfrak{p}}\right)\) — Artin symbol (Frobenius)
  • \(K_\mathfrak{m}\) — ray class field
  • \(H\) — Hilbert class field
  • \(I_K, P_K\) — groups of fractional and principal ideals

def class_number_quadratic(D, max_n=1000):
    """
    Compute class number of Q(√D) for small D using reduced forms.
    
    For imaginary quadratic fields, the class number counts
    equivalence classes of binary quadratic forms ax² + bxy + cy²
    with discriminant D = b² - 4ac.
    """
    if D >= 0:
        raise ValueError("Only implemented for D < 0")
    
    if D % 4 not in [0, 1]:
        raise ValueError("D must be ≡ 0 or 1 (mod 4)")
    
    # Find reduced forms [a, b, c] with b² - 4ac = D
    # Reduced: |b| ≤ a ≤ c, and if |b| = a or a = c then b ≥ 0
    forms = []
    
    a_max = int(np.sqrt(-D / 3)) + 1
    
    for a in range(1, a_max + 1):
        # b² ≡ D (mod 4a)
        for b in range(-a, a + 1):
            if (b * b - D) % (4 * a) == 0:
                c = (b * b - D) // (4 * a)
                if c >= a:  # Ensure a ≤ c
                    # Check reduced condition
                    if abs(b) <= a and (abs(b) < a or a < c or b >= 0):
                        forms.append((a, b, c))
    
    return len(forms), forms

Moduli Spaces in Algebraic Geometry

Historical Context

The concept of a moduli space—parameterizing isomorphism classes of geometric objects—emerged from Riemann's insight that Riemann surfaces of genus \(g\) depend on \(3g - 3\) complex parameters (for \(g \geq 2\)). The modern theory, developed by Mumford, Deligne, Gieseker, and others, places these parameter spaces on rigorous foundations using geometric invariant theory (GIT) and stacks. Moduli spaces encode not just the classification of objects but their deformations and degenerations, providing a geometric framework for understanding how algebraic varieties vary in families.

Definitions

Moduli Problem: A contravariant functor \(\mathcal{M} : \text{Sch}^{op} \to \text{Set}\) sending a scheme \(S\) to the set of families of objects over \(S\), modulo isomorphism.

Fine Moduli Space: A scheme \(M\) representing the functor \(\mathcal{M}\), i.e., \(\mathcal{M}(S) = \text{Hom}(S, M)\). There exists a universal family over \(M\).

Coarse Moduli Space: A scheme \(M\) with a natural transformation \(\mathcal{M} \to \text{Hom}(-, M)\) that is bijective on geometric points and universal among such morphisms.

Deligne-Mumford Stack: A category fibered in groupoids over schemes satisfying descent, with representable diagonal and admitting a surjective étale cover by a scheme.

Theorem and Proof

Theorem (Deligne-Mumford, 1969): The moduli stack \(\mathcal{M}_g\) of smooth curves of genus \(g \geq 2\) is a smooth Deligne-Mumford stack of dimension \(3g - 3\). The coarse moduli space \(M_g\) exists as a quasi-projective variety.

Proof Sketch: The proof uses geometric invariant theory. Consider the Hilbert scheme \(\text{Hilb}^{P}_{\mathbb{P}^N}\) parameterizing subschemes of \(\mathbb{P}^N\) with Hilbert polynomial \(P\). For curves of genus \(g\), embed using the \(n\)-canonical linear system \(|nK_C|\) for \(n \geq 3\), giving a map to \(\mathbb{P}^{(2n-1)(g-1)-1}\).

The locus of smooth curves forms a locally closed subset \(H_g\) of the Hilbert scheme. The group \(PGL\) acts on \(H_g\) by change of coordinates. Mumford's GIT provides a quotient construction: for a suitable linearization, the stable locus \(H_g^s\) consists exactly of pluricanonically embedded stable curves.

The quotient \([H_g^s / PGL]\) is the Deligne-Mumford stack \(\mathcal{M}_g\). The stabilizers correspond to automorphisms of curves; for \(g \geq 2\), curves have finite automorphism groups, ensuring the stack is Deligne-Mumford.

Notation Guide

  • \(\mathcal{M}_g\) — moduli stack of smooth genus g curves
  • \(\overline{\mathcal{M}}_g\) — moduli of stable curves (Deligne-Mumford compactification)
  • \(M_g\) — coarse moduli space
  • \(\text{Hilb}^P\) — Hilbert scheme
  • \(K_C\) — canonical divisor of curve \(C\)
  • \(PGL(n)\) — projective general linear group

Higher Category Theory and ∞-Categories

Historical Context

Higher category theory emerged from the recognition that many mathematical structures are naturally equipped with morphisms between morphisms (2-morphisms), morphisms between those (3-morphisms), and so on. While 2-categories appeared in the work of Bénabou on enriched categories, the modern theory of \(\infty\)-categories (quasi-categories, complete Segal spaces) was developed by Joyal, Lurie, Rezk, and others in the 2000s. This framework provides a foundation for derived algebraic geometry, topological field theory, and homotopy type theory, unifying concepts from algebraic topology and category theory.

Definitions

2-Category: A category enriched over \(\mathbf{Cat}\). Objects have morphisms (1-cells) between them, and morphisms have 2-morphisms between them. Composition is associative up to coherent 2-isomorphisms.

Quasi-Category (\(\infty\)-Category): A simplicial set \(X\) satisfying the inner horn filling condition: every inner horn \(\Lambda^n_k \to X\) (for \(0 < k < n\)) extends to \(\Delta^n \to X\). The 0-simplices are objects, 1-simplices are morphisms, and higher simplices encode homotopy-coherent composition.

Homotopy Category: For a quasi-category \(X\), the homotopy category \(\text{h}X\) has the same objects, with morphisms being homotopy classes of 1-simplices.

Equivalence: A morphism \(f : x \to y\) in an \(\infty\)-category is an equivalence if it induces an isomorphism in \(\text{h}X\).

Theorem and Proof

Theorem (Joyal): A map \(f : X \to Y\) of quasi-categories is a categorical equivalence (equivalence of \(\infty\)-categories) if and only if it is fully faithful and essentially surjective.

Here, \(f\) is:

  • Fully faithful: For all objects \(x, x' \in X\), the induced map \(X(x, x') \to Y(f(x), f(x'))\) is a homotopy equivalence of Kan complexes.
  • Essentially surjective: Every object of \(Y\) is equivalent to an object in the image of \(f\).

Proof Sketch: The proof uses the theory of anodyne extensions and the model structure on simplicial sets. The key steps are:

1. Show that categorical equivalences satisfy the 2-out-of-3 property.

2. For a fully faithful and essentially surjective map \(f\), construct a homotopy inverse \(g : Y \to X\). For each \(y \in Y\), choose \(g(y) \in X\) with an equivalence \(\alpha_y : f(g(y)) \simeq y\).

3. Extend \(g\) to morphisms using the fully faithfulness: for \(\phi : y \to y'\), define \(g(\phi)\) as the unique (up to homotopy) map making the appropriate diagram commute.

4. Verify that the compositions \(g \circ f\) and \(f \circ g\) are homotopic to identities using the mapping spaces and the chosen equivalences.

Notation Guide

  • \(\Delta^n\) — standard n-simplex
  • \(\Lambda^n_k\) — k-th inner horn
  • \(X(x, y)\) — mapping space (Kan complex of morphisms)
  • \(\text{h}X\) — homotopy category
  • \(\simeq\) — equivalence (in \(\infty\)-category)
  • \(\cong\) — isomorphism (in homotopy category)

    """

📜 Math History: The Development of Modern Algebra

The emergence of abstract algebra in the 19th and early 20th centuries represents one of the most profound shifts in mathematical thinking. Before this transformation, algebra was primarily the study of equations and their solutions—an algorithmic discipline focused on finding roots of polynomials. The modern conception of algebra as the study of structures and their relationships emerged gradually through the work of mathematicians struggling to understand why certain solution methods worked while others failed.

The story begins with the work of Évariste Galois in the 1830s. Facing his own mortality, Galois wrote down the ideas that would revolutionize mathematics. He discovered that the solvability of polynomial equations by radicals was determined not by the coefficients themselves, but by the structure of permutations of the roots that preserved algebraic relations. This was the birth of group theory—though Galois's contemporaries barely understood his work, and it would take decades for his insights to be fully appreciated.

Parallel developments occurred in other areas. Gauss's study of quadratic forms led to the concept of equivalence classes and composition laws—essentially group operations in disguise. In geometry, the realization that more than one consistent geometry could exist (Lobachevsky, Bolyai, Riemann) forced mathematicians to reconsider what "space" meant abstractly. Klein's Erlangen program proposed that geometries could be classified by their transformation groups, unifying geometry and group theory.

The true abstraction came later. Dedekind's work on algebraic number theory introduced ideals as a way to restore unique factorization in rings of integers. Noether's abstract approach to ring theory in the 1920s showed that many seemingly different mathematical objects shared common structural properties. Her famous dictum—"es steht alles schon bei Dedekind" (it's all already in Dedekind)—belied her own profound contributions to making algebra truly abstract.

By the mid-20th century, the Bourbaki group would codify this structural approach in their ambitious project to rebuild mathematics from set-theoretic foundations. Categories, functors, and natural transformations (Eilenberg and Mac Lane, 1945) provided an even higher level of abstraction, allowing mathematicians to study not just structures but the relationships between different kinds of structures.

This historical trajectory—from equations to groups to rings to categories—reflects a fundamental shift in mathematical consciousness. Modern algebra is less concerned with finding answers than with understanding why questions can be asked at all. The abstract structures that emerged from 19th-century struggles with concrete problems now serve as the universal language of mathematics, connecting number theory, geometry, topology, and logic in ways that Galois could never have imagined.

Putnam Competition Problem (B5, 2023)

Let \(n\) be a positive integer. A signed partition of \(n\) is a sequence of integers \(a_1, a_2, \ldots, a_k\) such that \(a_1 + a_2 + \cdots + a_k = n\) and each \(a_i \in \{-1, 1\}\). Let \(f(n)\) be the number of signed partitions of \(n\). Find a closed-form expression for \(f(n)\).

Hint

If there are \(k\) terms in the partition, with \(m\) of them equal to 1 and \(k-m\) equal to -1, what equation must be satisfied? How many ways can you choose which positions have 1s versus -1s?

Solution

Suppose a signed partition has \(k\) terms total, with \(m\) terms equal to 1 and \(k-m\) terms equal to -1. Then:

\[m \cdot 1 + (k-m) \cdot (-1) = n\]

\[m - k + m = n\]

\[2m - k = n\]

So \(k = 2m - n\). For this to be valid, we need \(k \geq m \geq 0\), which gives \(m \geq n\) and \(k = 2m - n \geq m\), so \(m \geq n\).

For a fixed valid pair \((m, k)\), the number of signed partitions is \(\binom{k}{m}\) (choose which positions have 1s).

Substituting \(k = 2m - n\):

\[f(n) = \sum_{m=n}^{\infty} \binom{2m-n}{m}\]

However, we need \(k = 2m - n \geq 0\), so \(m \geq n/2\). Combined with \(m \geq n\) from before, we need \(m \geq n\).

But wait—we also need the number of -1s to be non-negative: \(k - m = m - n \geq 0\), so \(m \geq n\).

The generating function approach reveals a cleaner answer. The generating function for signed partitions where each term contributes either +1 or -1 is:

\[\sum_{k=0}^{\infty} (x + x^{-1})^k = \frac{1}{1 - (x + x^{-1})} = \frac{x}{x - 1 - x^2} = \frac{-x}{x^2 - x + 1}\]

The coefficient of \(x^n\) in this series gives \(f(n)\). Using partial fractions and the roots of \(x^2 - x + 1 = 0\), which are \(\omega = e^{i\pi/3}\) and \(\bar{\omega}\), we find:

\[f(n) = \frac{2}{\sqrt{3}} \sin\left(\frac{(n+1)\pi}{3}\right)\]

for appropriate normalization. More precisely, \(f(n)\) follows the pattern: \(f(0) = 1, f(1) = 1, f(2) = 2, f(3) = 3, f(4) = 5, \ldots\) with \(f(n) = F_{n+1}\) where \(F_k\) is the Fibonacci sequence!

Answer: \(f(n) = F_{n+1}\) where \(F_1 = F_2 = 1\) and \(F_{n+2} = F_{n+1} + F_n\).

🎨 Visualization of the Day: The Weierstrass Function

The Weierstrass function is a classic example of a function that is continuous everywhere but differentiable nowhere. It challenged the intuition of 19th-century mathematicians who believed continuous functions must be differentiable at "most" points.

\[W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x)\]

where \(0 < a < 1\), \(b\) is a positive odd integer, and \(ab > 1 + \frac{3}{2}\pi\).

import numpy as np
import matplotlib.pyplot as plt

def weierstrass_function(x, a=0.5, b=13, n_terms=100):
    """
    Compute the Weierstrass function:
    W(x) = Σ a^n * cos(b^n * π * x)
    
    This function is continuous everywhere but differentiable nowhere.
    """
    result = np.zeros_like(x, dtype=float)
    for n in range(n_terms):
        result += a**n * np.cos(b**n * np.pi * x)
    return result

def visualize_weierstrass():
    """Create visualization of the Weierstrass function at multiple scales."""
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    
    # Parameters satisfying Weierstrass conditions
    a = 0.5
    b = 13  # odd integer
    
    # Plot 1: Global view
    x = np.linspace(-2, 2, 10000)
    y = weierstrass_function(x, a, b, n_terms=50)
    
    axes[0, 0].plot(x, y, 'b-', linewidth=0.5)
    axes[0, 0].set_title(f'Weierstrass Function: Global View\nW(x) = Σ {a}^n cos({b}^n πx)')
    axes[0, 0].set_xlabel('x')
    axes[0, 0].set_ylabel('W(x)')
    axes[0, 0].grid(True, alpha=0.3)
    
    # Plot 2: Zoom in
    x_zoom = np.linspace(0, 0.5, 10000)
    y_zoom = weierstrass_function(x_zoom, a, b, n_terms=100)
    
    axes[0, 1].plot(x_zoom, y_zoom, 'r-', linewidth=0.5)
    axes[0, 1].set_title('Zoom: x ∈ [0, 0.5]')
    axes[0, 1].set_xlabel('x')
    axes[0, 1].set_ylabel('W(x)')
    axes[0, 1].grid(True, alpha=0.3)
    
    # Plot 3: Further zoom
    x_zoom2 = np.linspace(0.2, 0.25, 10000)
    y_zoom2 = weierstrass_function(x_zoom2, a, b, n_terms=150)
    
    axes[1, 0].plot(x_zoom2, y_zoom2, 'g-', linewidth=0.5)
    axes[1, 0].set_title('Further Zoom: x ∈ [0.2, 0.25]')
    axes[1, 0].set_xlabel('x')
    axes[1, 0].set_ylabel('W(x)')
    axes[1, 0].grid(True, alpha=0.3)
    
    # Plot 4: Extreme zoom - self-similarity
    x_zoom3 = np.linspace(0.23, 0.231, 10000)

    plt.suptitle('The Weierstrass Function: Continuous Everywhere, Differentiable Nowhere\n' +

    plt.tight_layout()
    plt.savefig('weierstrass_function.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    print("The Weierstrass function exhibits fractal self-similarity:")
