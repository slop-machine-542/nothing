Derived Categories: Homological Algebra Beyond Cohomology

derived-categories

Motivation

Derived categories, introduced by Verdier in his 1963 thesis, revolutionized homological algebra by treating complexes as fundamental objects rather than mere tools for computing cohomology. In the derived category, quasi-isomorphic complexes become isomorphic, allowing one to work with convenient resolutions without losing information. This framework is essential for modern algebraic geometry (Fourier-Mukai transforms, perverse sheaves), representation theory (tilting theory, BGG correspondence), and mathematical physics (mirror symmetry, D-branes). The derived category captures not just cohomological data but also the "higher structure" encoded in Ext groups, making it indispensable for studying duality, deformation theory, and non-commutative geometry.

Definitions

  • Chain Complex: A sequence \\( \\cdots \\to A^{n-1} \\xrightarrow{d^{n-1}} A^n \\xrightarrow{d^n} A^{n+1} \\to \\cdots \\) with \\(d^n \\circ d^{n-1} = 0\\). The cohomology is \\(H^n(A^\\bullet) = \\ker(d^n)/\\text{im}(d^{n-1})\\).
  • Quasi-Isomorphism: A morphism of complexes \\(f: A^\\bullet \\to B^\\bullet\\) inducing isomorphisms \\(H^n(f): H^n(A^\\bullet) \\cong H^n(B^\\bullet)\\) for all \\(n\\).
  • Homotopy Category \\(K(\\mathcal{A})\\): The category of complexes in \\(\\mathcal{A}\\) with morphisms being homotopy classes of chain maps.
  • Derived Category \\(D(\\mathcal{A})\\): The localization of \\(K(\\mathcal{A})\\) at quasi-isomorphisms. Objects are complexes; morphisms are equivalence classes of roofs.
  • Derived Functor: For a left exact functor \\(F: \\mathcal{A} \\to \\mathcal{B}\\), the right derived functor \\(RF: D^+(\\mathcal{A}) \\to D^+(\\mathcal{B})\\) is defined using injective resolutions.
  • t-Structure: A pair of full subcategories \\((D^{\\leq 0}, D^{\\geq 0})\\) satisfying axioms that allow reconstruction of an abelian category (the heart) from a triangulated category.

Theorem: Grothendieck Duality

Theorem: Let \\(f: X \\to Y\\) be a proper morphism of Noetherian schemes. There exists a right adjoint \\(f^!: D^b_{\\text{coh}}(Y) \\to D^b_{\\text{coh}}(X)\\) to the derived pushforward \\(Rf_*\\), satisfying: \\[Rf_* R\\mathcal{H}om_X(\\mathcal{F}^\\bullet, f^!\\mathcal{G}^\\bullet) \\cong R\\mathcal{H}om_Y(Rf_*\\mathcal{F}^\\bullet, \\mathcal{G}^\\bullet)\\] For smooth proper varieties of dimension \\(n\\), \\(f^!\\mathcal{O}_Y \\cong \\omega_X[n]\\) where \\(\\omega_X = \\Omega^n_X\\) is the canonical bundle.

Proof Sketch

The existence of \\(f^!\\) follows from Brown representability: \\(Rf_*\\) preserves coproducts (for quasi-compact quasi-separated morphisms), hence has a right adjoint. The key computation is the local case: for a regular closed immersion \\(i: Z \\hookrightarrow X\\), one shows \\(i^!\\mathcal{F} \\cong R\\mathcal{H}om_{\\mathcal{O}_X}(\\mathcal{O}_Z, \\mathcal{F})\\).

For smooth morphisms, the relative cotangent sequence and deformation theory identify \\(f^!\\). The duality isomorphism follows from adjunction and the projection formula. The full proof requires careful handling of unbounded derived categories and the verification that \\(f^!\\) preserves coherence.

Notation Guide

  • \\(C^\\bullet, D^\\bullet\\): Chain complexes
  • \\(H^n(C^\\bullet)\\): n-th cohomology
  • \\(K(\\mathcal{A})\\): Homotopy category
  • \\(D(\\mathcal{A})\\): Derived category

from typing import List, Dict, Tuple, Optional
from dataclasses import dataclass
import numpy as np

@dataclass
class ChainComplex:
    """Represents a bounded chain complex of finite-dimensional vector spaces."""
    spaces: Dict[int, np.ndarray]  # degree -> matrix representation
    differentials: Dict[int, np.ndarray]  # d^n: C^n -> C^{n+1}
    
    def __post_init__(self):
        # Verify differential condition: d^{n+1} ∘ d^n = 0
        for n in self.differentials:
            if n + 1 in self.differentials:
                d_n = self.differentials[n]
                d_np1 = self.differentials[n + 1]
                composition = d_np1 @ d_n
                if not np.allclose(composition, 0):
                    raise ValueError(f"Differential condition fails at degree {n}")
    
    def cohomology(self, n: int) -> int:
        """Compute dimension of H^n = ker(d^n) / im(d^{n-1})."""
        if n not in self.differentials:
            return self.spaces.get(n, np.array([])).shape[0] if n in self.spaces else 0
        
        d_n = self.differentials[n]
        ker_n = d_n.shape[1] - np.linalg.matrix_rank(d_n)
        
        if n - 1 not in self.differentials:
            return ker_n
        
        d_nm1 = self.differentials[n - 1]
        im_nm1 = np.linalg.matrix_rank(d_nm1)
        
        return ker_n - im_nm1
    
    def shift(self, k: int) -> 'ChainComplex':
        """Return C^\\bullet[k] where C[k]^n = C^{n+k}."""
        new_spaces = {n - k: m for n, m in self.spaces.items()}
        new_diffs = {n - k: d for n, d in self.differentials.items()}
        return ChainComplex(new_spaces, new_diffs)
    
    def is_exact(self) -> bool:
        """Check if complex is exact (all cohomology vanishes)."""
        for n in set(list(self.spaces.keys()) + list(self.differentials.keys())):
            if self.cohomology(n) != 0:
                return False
        return True

class DerivedCategory:
    """Simplified model of morphisms in derived category."""
    
    @staticmethod
    def quasi_isomorphism(C: ChainComplex, D: ChainComplex) -> bool:
        """Check if two complexes are quasi-isomorphic (simplified)."""
        # Check if cohomology dimensions match
        degrees = set(list(C.spaces.keys()) + list(D.spaces.keys()))
        for n in degrees:
            if C.cohomology(n) != D.cohomology(n):
                return False
        return True
    
    @staticmethod
    def cone(f: Dict[int, np.ndarray], C: ChainComplex, D: ChainComplex) -> ChainComplex:
        """
        Compute mapping cone of f: C -> D.
        Cone(f)^n = D^n ⊕ C^{n+1}
        d^n(d, c) = (d_D(d) + f(c), -d_C(c))
        """
        cone_spaces = {}
        cone_diffs = {}
        
        degrees = set(list(C.spaces.keys()) + list(D.spaces.keys()))
        for n in degrees:
            dim_D = D.spaces.get(n, np.array([[0]])).shape[0]
            dim_C = C.spaces.get(n + 1, np.array([[0]])).shape[0]
            cone_spaces[n] = np.eye(dim_D + dim_C)
        
        for n in degrees:
            if n in D.differentials or n in C.differentials:
                dim_D_n = D.spaces.get(n, np.array([[0]])).shape[0]
                dim_D_np1 = D.spaces.get(n + 1, np.array([[0]])).shape[0]
                dim_C_n = C.spaces.get(n + 1, np.array([[0]])).shape[0]
                dim_C_np1 = C.spaces.get(n + 2, np.array([[0]])).shape[0]
                
                # Build block matrix [d_D, f; 0, -d_C]
                block = np.zeros((dim_D_np1 + dim_C_np1, dim_D_n + dim_C_n))
                
                if n in D.differentials:
                    block[:dim_D_np1, :dim_D_n] = D.differentials[n]
                if n in C.differentials:
                    block[dim_D_np1:, dim_D_n:] = -C.differentials[n + 1]
                if n + 1 in f:
                    block[:dim_D_np1, dim_D_n:] = f[n + 1]
                
                cone_diffs[n] = block
        
        return ChainComplex(cone_spaces, cone_diffs)

Symplectic Geometry: The Geometry of Classical Mechanics

symplectic-geometry

Motivation

Symplectic geometry emerged from Hamilton's reformulation of classical mechanics in the 19th century. Unlike Riemannian geometry, which measures distances and angles, symplectic geometry captures the structure of phase space—position and momentum together. The symplectic form encodes conservation laws, canonical transformations, and the Hamiltonian flow. Darboux's theorem states that all symplectic manifolds are locally equivalent, making symplectic geometry a "floppy" structure with rich global invariants. Modern applications include geometric quantization, mirror symmetry, and low-dimensional topology (Heegaard Floer homology).

Definitions

  • Symplectic Form: A closed, non-degenerate 2-form \\(\\omega\\) on a manifold \\(M^{2n}\\). Non-degenerate means \\(\\omega^n \\neq 0\\) everywhere.
  • Symplectic Manifold: A pair \\((M, \\omega)\\) where \\(\\omega\\) is a symplectic form. The dimension is always even.
  • Hamiltonian Vector Field: For \\(H \\in C^\\infty(M)\\), the vector field \\(X_H\\) defined by \\(\\iota_{X_H}\\omega = dH\\).
  • Poisson Bracket: \\(\\{f, g\\} = \\omega(X_f, X_g) = X_f(g)\\), making \\(C^\\infty(M)\\) a Lie algebra.
  • Lagrangian Submanifold: A submanifold \\(L^n \\subset M^{2n}\\) where \\(\\omega|_L = 0\\) and \\(\\dim L = \\frac{1}{2}\\dim M\\).
  • Moment Map: For a Lie group action preserving \\(\\omega\\), a map \\(\\mu: M \\to \\mathfrak{g}^*\\) satisfying \\(d\\langle\\mu, \\xi\\rangle = \\iota_{\\xi_M}\\omega\\).

Theorem: Darboux's Theorem

Theorem: Let \\((M, \\omega)\\) be a symplectic manifold of dimension \\(2n\\). For any point \\(p \\in M\\), there exist local coordinates \\((q_1, \\ldots, q_n, p_1, \\ldots, p_n)\\) (Darboux coordinates) such that: \\[\\omega = \\sum_{i=1}^n dq_i \\wedge dp_i\\] In particular, all symplectic manifolds of the same dimension are locally symplectomorphic.

Proof Sketch

The proof uses Moser's trick. Given two symplectic forms \\(\\omega_0, \\omega_1\\) on a neighborhood of \\(p\\) with \\(\\omega_0(p) = \\omega_1(p)\\), we seek a diffeomorphism \\(\\phi\\) with \\(\\phi^*\\omega_1 = \\omega_0\\).

Consider the family \\(\\omega_t = (1-t)\\omega_0 + t\\omega_1\\). Since \\(\\omega_t(p) = \\omega_0(p)\\) is non-degenerate, \\(\\omega_t\\) remains non-degenerate near \\(p\\). We seek \\(\\phi_t\\) with \\(\\phi_t^*\\omega_t = \\omega_0\\). Differentiating gives \\(\\mathcal{L}_{X_t}\\omega_t + \\partial_t\\omega_t = 0\\). Since \\(\\partial_t\\omega_t = \\omega_1 - \\omega_0\\) is closed, locally \\(\\partial_t\\omega_t = d\\alpha\\). By the Cartan formula, we need \\(d(\\iota_{X_t}\\omega_t) + \\iota_{X_t}(d\\omega_t) = -d\\alpha\\). Since \\(\\omega_t\\) is closed, take \\(X_t\\) such that \\(\\iota_{X_t}\\omega_t = -\\alpha\\), possible by non-degeneracy.

  • \\((M, \\omega)\\): Symplectic manifold
  • \\(\\omega \\in \\Omega^2(M)\\): Symplectic form
  • \\(X_H\\): Hamiltonian vector field
  • \\(\\phi_H^t\\): Hamiltonian flow
  • \\(\\{f, g\\}\\): Poisson bracket
  • \\(L \\subset M\\): Lagrangian submanifold
  • \\(\\mu: M \\to \\mathfrak{g}^*\\): Moment map
  • \\(M /\\!/ G = \\mu^{-1}(0)/G\\): Symplectic reduction
  • \\(\\text{Sp}(2n, \\mathbb{R})\\): Symplectic group
  • \\(J\\): Compatible almost complex structure

import numpy as np
from typing import Callable, Tuple
from scipy.integrate import odeint

class SymplecticManifold:
    """Numerical computations on symplectic manifolds."""
    
    def __init__(self, omega: Callable[[np.ndarray, np.ndarray], float]):
        """
        Initialize with symplectic form omega(v, w).
        
        Args:
            omega: Function taking two tangent vectors, returning \\omega(v, w)
        """
        self.omega = omega
    
    def hamiltonian_vector_field(self, H: Callable[[np.ndarray], float], 
                                  x: np.ndarray, eps: float = 1e-6) -> np.ndarray:
        """
        Compute X_H at point x using \\iota_{X_H}\\omega = dH.
        For R^{2n} with standard omega, X_H = (\\partial H/\\partial p, -\\partial H/\\partial q).
        """
        # Numerical gradient of H
        grad = np.zeros_like(x)
        for i in range(len(x)):
            x_plus = x.copy()
            x_minus = x.copy()
            x_plus[i] += eps
            x_minus[i] -= eps
            grad[i] = (H(x_plus) - H(x_minus)) / (2 * eps)
        
        # For standard symplectic form on R^{2n}: omega = sum dq_i ^ dp_i
        # X_H = (\\partial H/\\partial p, -\\partial H/\\partial q)
        n = len(x) // 2
        X_H = np.zeros_like(x)
        X_H[:n] = grad[n:]   # dH/dp
        X_H[n:] = -grad[:n]  # -dH/dq
        
        return X_H
    
    def hamiltonian_flow(self, H: Callable[[np.ndarray], float],
                         x0: np.ndarray, t_span: np.ndarray) -> np.ndarray:
        """Integrate Hamilton's equations."""
        def ode(x, t):
            return self.hamiltonian_vector_field(H, x)
        
        return odeint(ode, x0, t_span)
    
    def poisson_bracket(self, f: Callable[[np.ndarray], float],
                       g: Callable[[np.ndarray], float],
                       x: np.ndarray, eps: float = 1e-6) -> float:
        """Compute {f, g} = \\omega(X_f, X_g)."""
        X_f = self.hamiltonian_vector_field(f, x, eps)
        X_g = self.hamiltonian_vector_field(g, x, eps)
        return self.omega(X_f, X_g)

def standard_symplectic_form(v: np.ndarray, w: np.ndarray) -> float:
    """Standard symplectic form on R^{2n}: \\omega = \\sum dq_i \\wedge dp_i."""
    n = len(v) // 2
    return np.sum(v[:n] * w[n:] - v[n:] * w[:n])

# Example: Harmonic oscillator H = (p^2 + q^2)/2
def harmonic_oscillator_H(x):
    return 0.5 * np.sum(x**2)

# Create symplectic manifold with standard form
M = SymplecticManifold(standard_symplectic_form)

# Initial condition: q=1, p=0
x0 = np.array([1.0, 0.0])
t = np.linspace(0, 2*np.pi, 100)

# Compute trajectory
trajectory = M.hamiltonian_flow(harmonic_oscillator_H, x0, t)

print("Harmonic oscillator period:", 2*np.pi)
print("Final position:", trajectory[-1])
print("Energy conservation check:", harmonic_oscillator_H(trajectory[0]), 
      "vs", harmonic_oscillator_H(trajectory[-1]))

Algebraic Combinatorics: Enumeration and Structure

combinatorics

Motivation

Algebraic combinatorics uses techniques from algebra, representation theory, and algebraic geometry to solve combinatorial problems and vice versa. The field studies enumeration, symmetric functions, posets, and graph theory through an algebraic lens. Stanley's work connecting polytopes to toric varieties, the theory of Schubert calculus, and the combinatorics of cluster algebras demonstrate the power of this approach. Modern applications include statistical mechanics, where partition functions encode combinatorial data, and the study of random structures in computer science.

Definitions

  • Generating Function: For a sequence \\(a_n\\), the ordinary generating function is \\(A(x) = \\sum_{n \\geq 0} a_n x^n\\); the exponential generating function is \\(\\hat{A}(x) = \\sum_{n \\geq 0} a_n \\frac{x^n}{n!}\\).
  • Symmetric Function: A polynomial \\(f(x_1, x_2, \\ldots)\\) invariant under permutation of variables. The ring \\(\\Lambda\\) of symmetric functions has bases including elementary \\(e_\\lambda\\), complete homogeneous \\(h_\\lambda\\), power sum \\(p_\\lambda\\), monomial \\(m_\\lambda\\), and Schur \\(s_\\lambda\\).
  • Young Diagram: A collection of boxes arranged in left-justified rows with weakly decreasing row lengths. A partition \\(\\lambda = (\\lambda_1 \\geq \\lambda_2 \\geq \\cdots)\\) corresponds to a Young diagram.
  • Schur Polynomial: \\(s_\\lambda(x_1, \\ldots, x_n) = \\sum_T x^T\\) where the sum is over semistandard Young tableaux of shape \\(\\lambda\\).
  • Möbius Function: For a poset \\(P\\), \\(\\mu: P \\times P \\to \\mathbb{Z}\\) defined by \\(\\mu(x,x) = 1\\), \\(\\sum_{x \\leq z \\leq y} \\mu(x,z) = 0\\) for \\(x < y\\).

Theorem: The Hook Length Formula

Theorem (Frame-Robinson-Thrall): The number of standard Young tableaux of shape \\(\\lambda\\) with \\(n\\) boxes is: \\[f^\\lambda = \\frac{n!}{\\prod_{(i,j) \\in \\lambda} h(i,j)}\\] where \\(h(i,j) = \\lambda_i - j + \\lambda'_j - i + 1\\) is the hook length of cell \\((i,j)\\).

Proof Sketch

The proof uses the representation theory of the symmetric group. The irreducible representations \\(S^\\lambda\\) of \\(S_n\\) are indexed by partitions of \\(n\\), and \\(\\dim S^\\lambda = f^\\lambda\\). The Frobenius character formula expresses the character in terms of symmetric functions.

An elegant probabilistic proof uses the hook walk: randomly place \\(n\\) in a box with probability proportional to hook length, then recursively fill the remaining shape. The product formula follows from showing this gives the uniform distribution on SYT.

Notation Guide

  • \\(\\lambda \\vdash n\\): Partition of \\(n\\)
  • \\(|\\lambda|\\): Size (sum of parts)
  • \\(\\ell(\\lambda)\\): Length (number of parts)
  • \\(\\lambda'\\): Conjugate partition
  • \\(s_\\lambda\\): Schur function
  • \\(e_k, h_k, p_k\\): Elementary, complete, power sum
  • \\(\\langle \\cdot, \\cdot \\rangle\\): Hall inner product
  • \\(h(i,j)\\): Hook length
  • \\(f^\\lambda\\): Number of SYT of shape \\(\\lambda\\)
  • \\(K_{\\lambda, \\mu}\\): Kostka numbers

from typing import List, Tuple
from functools import lru_cache
from math import factorial
import numpy as np

class Partition:
    """Represents an integer partition."""
    
    def __init__(self, parts: List[int]):
        self.parts = tuple(sorted([p for p in parts if p > 0], reverse=True))
        self.n = sum(self.parts)
        self.length = len(self.parts)
    
    def conjugate(self) -> 'Partition':
        """Compute conjugate partition."""
        if not self.parts:
            return Partition([])
        max_part = self.parts[0]
        conj = []
        for i in range(max_part):
            # Count parts > i
            count = sum(1 for p in self.parts if p > i)
            if count > 0:
                conj.append(count)
        return Partition(conj)
    
    def diagram(self) -> List[Tuple[int, int]]:
        """Return list of (row, col) coordinates in diagram."""
        cells = []
        for i, row_len in enumerate(self.parts):
            for j in range(row_len):
                cells.append((i, j))
        return cells
    
    def hook_lengths(self) -> dict:
        """Compute hook length for each cell."""
        conj = self.conjugate().parts
        hooks = {}
        for i, row_len in enumerate(self.parts):
            for j in range(row_len):
                # Hook length = arm + leg + 1
                arm = row_len - j - 1
                leg = conj[j] - i - 1
                hooks[(i, j)] = arm + leg + 1
        return hooks
    
    def hook_length_formula(self) -> int:
        """Compute f^\\lambda using hook length formula."""
        hooks = self.hook_lengths()
        numerator = factorial(self.n)
        denominator = 1
        for h in hooks.values():
            denominator *= h
        return numerator // denominator
    
    def __repr__(self):
        return f"Partition({list(self.parts)})"

class YoungTableau:
    """Represents a Young tableau."""
    
    def __init__(self, shape: Partition, entries: dict = None):
        self.shape = shape
        self.entries = entries or {}
    
    def is_standard(self) -> bool:
        """Check if tableau is standard (1..n, increasing rows and columns)."""
        n = self.shape.n
        if set(self.entries.values()) != set(range(1, n + 1)):
            return False
        
        # Check rows increasing
        for i, row_len in enumerate(self.shape.parts):
            for j in range(row_len - 1):
                if self.entries.get((i, j), 0) >= self.entries.get((i, j + 1), 0):
                    return False
        
        # Check columns increasing
        conj = self.shape.conjugate().parts
        for j, col_len in enumerate(conj):
            for i in range(col_len - 1):
                if self.entries.get((i, j), 0) >= self.entries.get((i + 1, j), 0):
                    return False
        
        return True
    
    def weight(self) -> List[int]:
        """Return weight (content) of tableau."""
        max_entry = max(self.entries.values()) if self.entries else 0
        wt = [0] * max_entry
        for entry in self.entries.values():
            wt[entry - 1] += 1
        return wt

def generate_syt(shape: Partition) -> List[YoungTableau]:
    """Generate all standard Young tableaux of given shape (backtracking)."""
    n = shape.n
    cells = shape.diagram()
    tableaux = []
    
    def backtrack(used: set, current: dict):
        if len(current) == n:
            tableaux.append(YoungTableau(shape, current.copy()))
            return
        
        next_val = len(current) + 1
        for cell in cells:
            if cell in current:
                continue
            
            # Check if cell can be filled (corners condition)
            i, j = cell
            # Check left and above
            can_fill = True
            if j > 0 and (i, j - 1) not in current:
                can_fill = False
            if i > 0 and (i - 1, j) not in current:
                can_fill = False
            
            if can_fill:
                current[cell] = next_val
                backtrack(used | {cell}, current)
                del current[cell]
    
    backtrack(set(), {})
    return tableaux

Convex Optimization: Foundations and Algorithms

optimization

Real-World Motivation

Convex optimization underlies much of modern engineering and data science. In machine learning, training support vector machines, logistic regression, and neural networks involves solving optimization problems. In finance, portfolio optimization seeks to maximize returns subject to risk constraints. In control systems, model predictive control solves convex programs in real-time to stabilize aircraft and autonomous vehicles. The power of convex optimization lies in the guarantee that any local minimum is global, and efficient algorithms can solve large-scale problems with millions of variables.

Definitions

  • Convex Set: \\(C \\subseteq \\mathbb{R}^n\\) such that \\(x, y \\in C \\Rightarrow \\theta x + (1-\\theta)y \\in C\\) for all \\(\\theta \\in [0,1]\\).
  • Convex Function: \\(f: \\mathbb{R}^n \\to \\mathbb{R}\\) with \\(\\text{dom}(f)\\) convex and \\(f(\\theta x + (1-\\theta)y) \\leq \\theta f(x) + (1-\\theta)f(y)\\).
  • Epigraph: \\(\\text{epi}(f) = \\{(x, t) : f(x) \\leq t\\}\\); \\(f\\) is convex iff \\(\\text{epi}(f)\\) is convex.
  • Subgradient: For convex \\(f\\), \\(g\\) is a subgradient at \\(x\\) if \\(f(y) \\geq f(x) + g^T(y-x)\\) for all \\(y\\). The set of subgradients is \\(\\partial f(x)\\).
  • Strong Convexity: \\(f\\) is \\(\\mu\\)-strongly convex if \\(f - \\frac{\\mu}{2}\\|\\cdot\\|^2\\) is convex, implying quadratic growth.
  • Lagrangian: For problem \\(\\min f(x)\\) s.t. \\(g_i(x) \\leq 0\\), \\(h_j(x) = 0\\), the Lagrangian is \\(L(x, \\lambda, \\nu) = f(x) + \\sum \\lambda_i g_i(x) + \\sum \\nu_j h_j(x)\\).

Theorem: Strong Duality

Theorem: Consider the convex optimization problem: \\[\\begin{aligned} p^* = \\min_{x} \\quad & f_0(x) \\\\ \\text{s.t.} \\quad & f_i(x) \\leq 0, \\quad i = 1, \\ldots, m \\\\ & Ax = b \\end{aligned}\\] where \\(f_0, \\ldots, f_m\\) are convex. If Slater's condition holds (there exists strictly feasible \\(x\\)), then strong duality holds: \\[p^* = d^* = \\max_{\\lambda \\geq 0, \\nu} g(\\lambda, \\nu)\\] where \\(g(\\lambda, \\nu) = \\inf_x L(x, \\lambda, \\nu)\\) is the dual function.

Proof SketchThe proof uses the separating hyperplane theorem. Define the set \\(\\mathcal{A} = \\{(u, v, t) : \\exists x, f_i(x) \\leq u_i, Ax - b = v, f_0(x) \\leq t\\}\\). This is convex by convexity of \\(f_i\\). The point \\((0, 0, p^*)\\) is on the boundary of \\(\\mathcal{A}\\). By the separating hyperplane theorem, there exists a supporting hyperplane \\((\\lambda, \\nu, \\mu)\\) such that \\(\\lambda^T u + \\nu^T v + \\mu t \\geq \\mu p^*\\) for all \\((u, v, t) \\in \\mathcal{A}\\).

Slater's condition ensures \\(\\mu > 0\\). Setting \\((\\lambda, \\nu) = (\\lambda/\\mu, \\nu/\\mu)\\), we get \\(g(\\lambda, \\nu) \\geq p^*\\). Since weak duality always gives \\(d^* \\leq p^*\\), we conclude \\(d^* = p^*\\).

  • \\(\\mathbb{R}^n\\): n-dimensional Euclidean space
  • \\(\\|\\cdot\\|\\): Norm (typically Euclidean)
  • \\(\\nabla f(x)\\): Gradient of \\(f\\)
  • \\(\\nabla^2 f(x)\\): Hessian matrix
  • \\(\\partial f(x)\\): Subdifferential
  • \\(\\text{dom}(f)\\): Domain of \\(f\\)
  • \\(\\text{epi}(f)\\): Epigraph
  • \\(L(x, \\lambda, \\nu)\\): Lagrangian
  • \\(g(\\lambda, \\nu)\\): Dual function
  • \\(p^*, d^*\\): Primal and dual optimal values

from scipy.optimize import minimize

class ConvexOptimizer:
    """Implementation of convex optimization algorithms."""
    
    def __init__(self, f: Callable[[np.ndarray], float],
                 grad_f: Callable[[np.ndarray], np.ndarray]):
        """
        Initialize with objective and gradient.
        
        Args:
            f: Convex objective function
            grad_f: Gradient of f
        """
        self.f = f
        self.grad_f = grad_f
    
    def gradient_descent(self, x0: np.ndarray, step_size: float,
                         max_iter: int = 1000, tol: float = 1e-6) -> Tuple[np.ndarray, list]:
        """Vanilla gradient descent."""
        x = x0.copy()
        history = [self.f(x)]
        
        for _ in range(max_iter):
            grad = self.grad_f(x)
            x_new = x - step_size * grad
            history.append(self.f(x_new))
            
            if np.linalg.norm(x_new - x) < tol:
                break
            x = x_new
        
        return x, history
    
    def accelerated_gradient_descent(self, x0: np.ndarray, L: float,
                                     max_iter: int = 1000) -> Tuple[np.ndarray, list]:
        """
        Nesterov's accelerated gradient descent.
        For L-smooth convex functions: O(1/k^2) convergence.
        """
        x = x0.copy()
        y = x0.copy()
        history = [self.f(x)]
        
        for k in range(1, max_iter + 1):
            x_new = y - (1/L) * self.grad_f(y)
            y = x_new + ((k - 1) / (k + 2)) * (x_new - x)
            x = x_new
            history.append(self.f(x))
        
        return x, history
    
    def projected_gradient_descent(self, x0: np.ndarray, step_size: float,
                                   projection: Callable[[np.ndarray], np.ndarray],
                                   max_iter: int = 1000) -> Tuple[np.ndarray, list]:
        """Projected gradient descent for constrained problems."""
        x = x0.copy()
        history = [self.f(x)]
        
        for _ in range(max_iter):
            grad = self.grad_f(x)
            x_temp = x - step_size * grad
            x_new = projection(x_temp)
            history.append(self.f(x_new))
            x = x_new
        
        return x, history

Elliptic Curve Cryptography: From Theory to Practice

cryptography

Real-World Motivation

Elliptic curve cryptography (ECC) provides security equivalent to RSA with much smaller key sizes, making it essential for resource-constrained devices like smartphones and IoT sensors. ECC secures HTTPS connections, Bitcoin transactions, and government communications. The security of ECC rests on the elliptic curve discrete logarithm problem (ECDLP), which remains hard even against quantum computers (though Shor's algorithm eventually breaks it). The mathematics involves beautiful connections between algebra, geometry, and number theory, demonstrating how pure mathematics finds unexpected practical applications.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point. Over a field \\(K\\), can be written as \\(y^2 = x^3 + ax + b\\) (Weierstrass form) with discriminant \\(\\Delta = -16(4a^3 + 27b^2) \\neq 0\\).
  • Point at Infinity: The identity element \\(\\mathcal{O}\\) of the elliptic curve group, serving as the base point.
  • Group Law: For points \\(P, Q\\), define \\(P + Q\\) by: draw line through \\(P\\) and \\(Q\\), find third intersection with curve, reflect over x-axis.
  • Scalar Multiplication: For integer \\(n\\) and point \\(P\\), \\([n]P = P + P + \\cdots + P\\) (n times). Computed efficiently via double-and-add.
  • ECDLP: Given \\(P\\) and \\([n]P\\), find \\(n\\). Believed hard for well-chosen curves.
  • Pairing: A bilinear map \\(e: G_1 \\times G_2 \\to G_T\\) where \\(G_1, G_2\\) are elliptic curve groups and \\(G_T\\) is a multiplicative group. Enables identity-based encryption.

Theorem: Hasse's Bound

Theorem (Hasse): Let \\(E\\) be an elliptic curve over a finite field \\(\\mathbb{F}_q\\). The number of \\(\\mathbb{F}_q\\)-rational points satisfies: \\[|q + 1 - \\#E(\\mathbb{F}_q)| \\leq 2\\sqrt{q}\\] Equivalently, if \\(\\#E(\\mathbb{F}_q) = q + 1 - t\\), then \\(|t| \\leq 2\\sqrt{q}\\). The integer \\(t\\) is called the trace of Frobenius.

Proof Sketch

The proof uses the characteristic polynomial of Frobenius. The Frobenius endomorphism \\(\\phi: (x, y) \\mapsto (x^q, y^q)\\) satisfies \\(\\phi^2 - t\\phi + q = 0\\) in \\(\\text{End}(E)\\).

For any integer \\(n\\), consider \\(\\#E(\\mathbb{F}_{q^n}) = q^n + 1 - (\\alpha^n + \\beta^n)\\) where \\(\\alpha, \\beta\\) are roots of \\(X^2 - tX + q\\). The Riemann hypothesis for curves implies \\(|\\alpha| = |\\beta| = \\sqrt{q}\\), giving \\(|\\alpha^n + \\beta^n| \\leq 2q^{n/2}\\). For \\(n=1\\), this is Hasse's bound.

from typing import Optional, Tuple

class EllipticCurve:
    """Elliptic curve y^2 = x^3 + ax + b over finite field F_p."""
    
    def __init__(self, a: int, b: int, p: int):
        self.a = a % p
        self.b = b % p
        self.p = p
        # Check non-singular
        discriminant = (-16 * (4 * a**3 + 27 * b**2)) % p
        if discriminant == 0:
            raise ValueError("Curve is singular")
    
    def is_on_curve(self, point: Optional[Tuple[int, int]]) -> bool:
        """Check if point is on curve."""
        if point is None:  # Point at infinity
            return True
        x, y = point
        return (y**2 - x**3 - self.a * x - self.b) % self.p == 0
    
    def add(self, P: Optional[Tuple[int, int]], 
            Q: Optional[Tuple[int, int]]) -> Optional[Tuple[int, int]]:
        """Add two points on the curve."""
        # Identity cases
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # P + (-P) = O
        if x1 == x2 and (y1 + y2) % self.p == 0:
            return None
        
        # Compute slope
        if x1 == x2:
            # Point doubling: slope = (3x^2 + a) / (2y)
            num = (3 * x1**2 + self.a) % self.p
            den = (2 * y1) % self.p
        else:
            # Point addition: slope = (y2 - y1) / (x2 - x1)
            num = (y2 - y1) % self.p
            den = (x2 - x1) % self.p
        
        # Modular inverse
        den_inv = pow(den, self.p - 2, self.p)
        slope = (num * den_inv) % self.p
        
        # Compute x3, y3
        x3 = (slope**2 - x1 - x2) % self.p
        y3 = (slope * (x1 - x3) - y1) % self.p
        
        return (x3, y3)
    
    def scalar_mult(self, n: int, P: Optional[Tuple[int, int]]) -> Optional[Tuple[int, int]]:
        """Compute [n]P using double-and-add."""
        if n < 0:
            # [n]P = [-n](-P)
            if P is None:
                return None
            x, y = P
            return self.scalar_mult(-n, (x, (-y) % self.p))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        
        return result
    
    def order(self, P: Optional[Tuple[int, int]]) -> int:
        """Compute order of point (naive for small curves)."""
        if P is None:
            return 1
        
        Q = P
        n = 1
        while Q is not None:
            Q = self.add(Q, P)
            n += 1
            if n > self.p + 1 + 2*int(self.p**0.5):  # Hasse bound
                break
        return n

Information Theory: Entropy and Communication

information-theory

Real-World Motivation

Information theory, founded by Claude Shannon in 1948, provides the mathematical foundation for all modern digital communication. Every text message, video stream, and file download relies on principles of data compression and error correction developed by information theorists. The theory quantifies information in bits, establishes fundamental limits on compression and transmission rates, and provides practical codes that approach these limits. From deep space communication with Voyager to 5G cellular networks and DNA storage, information theory enables reliable communication across diverse channels.

Definitions

  • Entropy: For a random variable \\(X\\) with distribution \\(p(x)\\), \\(H(X) = -\\sum_x p(x) \\log_2 p(x)\\). Measures average uncertainty.
  • Joint Entropy: \\(H(X,Y) = -\\sum_{x,y} p(x,y) \\log_2 p(x,y)\\).
  • Conditional Entropy: \\(H(Y|X) = \\sum_x p(x) H(Y|X=x) = H(X,Y) - H(X)\\).
  • Mutual Information: \\(I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)\\). Measures dependence between variables.
  • Channel Capacity: \\(C = \\max_{p(x)} I(X;Y)\\). The maximum reliable communication rate.
  • Kullback-Leibler Divergence: \\(D_{KL}(P \\| Q) = \\sum_x p(x) \\log \\frac{p(x)}{q(x)}\\). Measures difference between distributions.

Theorem: Shannon's Channel Coding Theorem

Theorem: For a discrete memoryless channel with capacity \\(C\\):
(Achievability) For any rate \\(R < C\\) and \\(\\epsilon > 0\\), there exists a code of length \\(n\\) with \\(2^{nR}\\) codewords and decoding error \\(\\leq \\epsilon\\).
(Converse) For any rate \\(R > C\\), the error probability is bounded away from zero for any code.

Proof Sketch

The achievability proof uses random coding. Generate \\(2^{nR}\\) codewords independently according to \\(p(x)\\). To send message \\(m\\), transmit codeword \\(X^n(m)\\). The receiver observes \\(Y^n\\) and finds the unique \\(\\hat{m}\\) such that \\((X^n(\\hat{m}), Y^n)\\) is jointly typical.

By the asymptotic equipartition property, there are about \\(2^{nH(X,Y)}\\) jointly typical sequences. The probability that a random \\(X^n\\) is jointly typical with \\(Y^n\\) is about \\(2^{-nI(X;Y)}\\). With \\(2^{nR}\\) codewords, the error probability goes to zero if \\(R < I(X;Y)\\). Optimizing over \\(p(x)\\) gives capacity.

Notation Guide

  • \\(H(X)\\): Shannon entropy
  • \\(H(X|Y)\\): Conditional entropy
  • \\(I(X;Y)\\): Mutual information
  • \\(D_{KL}(P \\| Q)\\): KL divergence
  • \\(C\\): Channel capacity
  • \\(p(x)\\): Probability mass function
  • \\(p(y|x)\\): Channel transition probability
  • \\(A_\\epsilon^{(n)}\\): Typical set
  • \\(R\\): Code rate
  • \\(\\lambda^{(n)}\\): Maximum error probability

import numpy as np
from typing import Dict, Tuple
from scipy.stats import entropy as scipy_entropy

class InformationTheory:
    """Information theory computations."""
    
    @staticmethod
    def entropy(p: Dict) -> float:
        """Compute Shannon entropy H(X) = -\\sum p(x) log p(x)."""
        h = 0.0
        for prob in p.values():
            if prob > 0:
                h -= prob * np.log2(prob)
        return h
    
    @staticmethod
    def joint_entropy(p_xy: Dict[Tuple, float]) -> float:
        """Compute joint entropy H(X,Y)."""
        return InformationTheory.entropy(p_xy)
    
    @staticmethod
    def conditional_entropy(p_xy: Dict[Tuple, float], p_x: Dict) -> float:
        """Compute H(Y|X) = H(X,Y) - H(X)."""
        return InformationTheory.joint_entropy(p_xy) - InformationTheory.entropy(p_x)
    
    @staticmethod
    def mutual_information(p_xy: Dict[Tuple, float]) -> float:
        """Compute I(X;Y) = H(X) + H(Y) - H(X,Y)."""
        # Marginal distributions
        p_x = {}
        p_y = {}
        for (x, y), prob in p_xy.items():
            p_x[x] = p_x.get(x, 0) + prob
            p_y[y] = p_y.get(y, 0) + prob
        
        return (InformationTheory.entropy(p_x) + 
                InformationTheory.entropy(p_y) - 
                InformationTheory.joint_entropy(p_xy))
    
    @staticmethod
    def kl_divergence(p: Dict, q: Dict) -> float:
        """Compute D_KL(P || Q) = \\sum p(x) log(p(x)/q(x))."""
        dkl = 0.0
        for x, p_x in p.items():
            if p_x > 0:
                q_x = q.get(x, 1e-10)  # Avoid division by zero
                dkl += p_x * np.log2(p_x / q_x)
        return dkl
    
    @staticmethod
    def binary_entropy(p: float) -> float:
        """Entropy of Bernoulli(p) random variable."""
        if p <= 0 or p >= 1:
            return 0.0
        return -p * np.log2(p) - (1 - p) * np.log2(1 - p)

class BinarySymmetricChannel:
    """Binary Symmetric Channel with crossover probability p."""
    
    def __init__(self, p: float):
        self.p = p
        self.capacity = 1 - InformationTheory.binary_entropy(p)
    
    def transition_prob(self, y: int, x: int) -> float:
        """P(Y=y | X=x)."""
        return 1 - self.p if y == x else self.p
    
    def capacity_formula(self) -> float:
        """C = 1 - H(p)."""
        return self.capacity
    
    def simulate(self, x: np.ndarray) -> np.ndarray:
        """Simulate channel transmission."""
        noise = (np.random.random(len(x)) < self.p).astype(int)
        return (x + noise) % 2

Riemann Surfaces: Complex Geometry and Topology

algebraic-geometry

Historical Context

Bernhard Riemann introduced the concept of Riemann surfaces in his 1851 dissertation as a way to understand multi-valued complex functions. The idea that a function like \\(\\sqrt{z}\\) or \\(\\log(z)\\) becomes single-valued on an appropriate surface revolutionized complex analysis. Riemann's work connected complex function theory to topology through the genus of a surface, establishing deep links between analysis, geometry, and algebra. The Riemann-Roch theorem, proved by Riemann and refined by Roch, counts meromorphic functions on a surface and remains a cornerstone of algebraic geometry.

Definitions

  • Riemann Surface: A one-dimensional complex manifold: a Hausdorff space with charts to \\(\\mathbb{C}\\) and holomorphic transition functions.
  • Meromorphic Function: A holomorphic map \\(f: X \\to \\mathbb{P}^1\\) to the Riemann sphere. Has poles where \\(f(z) = \\infty\\).
  • Divisor: A formal sum \\(D = \\sum_{p \\in X} n_p \\cdot p\\) with \\(n_p \\in \\mathbb{Z}\\), almost all zero. The degree is \\(\\deg(D) = \\sum n_p\\).
  • Canonical Divisor: For a meromorphic 1-form \\(\\omega\\), \\(K = (\\omega) = \\sum \\text{ord}_p(\\omega) \\cdot p\\).
  • Genus: The topological genus \\(g = \\dim H^0(X, K) = \\dim H^1(X, \\mathcal{O})\\).
  • Line Bundle: A holomorphic vector bundle of rank 1. Corresponds to divisor classes via \\(\\mathcal{O}(D)\\).

Theorem: The Riemann-Roch Theorem

Theorem: Let \\(X\\) be a compact Riemann surface of genus \\(g\\), and \\(D\\) a divisor. Then: \\[\\ell(D) - \\ell(K - D) = \\deg(D) + 1 - g\\] where \\(\\ell(D) = \\dim H^0(X, \\mathcal{O}(D))\\) is the dimension of the space of meromorphic functions with poles bounded by \\(D\\).

Proof Sketch

The proof uses sheaf cohomology. The short exact sequence \\(0 \\to \\mathcal{O}(D) \\to \\mathcal{O}(D + p) \\to \\mathbb{C}_p \\to 0\\) gives a long exact sequence in cohomology. By induction on \\(\\deg(D)\\), one shows \\(\\chi(D) = \\deg(D) + 1 - g\\) where \\(\\chi(D) = \\ell(D) - h^1(D)\\).

Serre duality gives \\(h^1(D) = \\ell(K - D)\\), completing the proof. The key insight is that the Euler characteristic \\(\\chi\\) is additive in short exact sequences and computable from topological data.

Notation Guide

  • \\(X\\): Riemann surface
  • \\(g\\): Genus
  • \\(D = \\sum n_p p\\): Divisor
  • \\(\\deg(D)\\): Degree of divisor
  • \\(K\\): Canonical divisor
  • \\(\\ell(D)\\): Dimension of \\(H^0(X, \\mathcal{O}(D))\\)
  • \\(h^i(D) = \\dim H^i(X, \\mathcal{O}(D))\\)
  • \\(\\chi(D) = \\ell(D) - h^1(D)\\): Euler characteristic
  • \\(\\Omega^1_X\\): Sheaf of holomorphic 1-forms
  • \\(\\mathcal{O}(D)\\): Line bundle associated to divisor

import numpy as np
from typing import List, Tuple, Optional
import cmath

class RiemannSurface:
    """Numerical representation of a Riemann surface."""
    
    def __init__(self, genus: int):
        self.genus = genus
    
    def riemann_roch(self, degree: int) -> Tuple[int, int]:
        """
        Apply Riemann-Roch to compute l(D) for generic divisor D.
        Returns (lower_bound, upper_bound) for l(D).
        """
        g = self.genus
        d = degree
        
        # Riemann-Roch: l(D) - l(K-D) = d + 1 - g
        # l(K-D) >= 0, so l(D) >= d + 1 - g
        lower_bound = max(0, d + 1 - g)
        
        # If d > 2g - 2, then deg(K-D) < 0 so l(K-D) = 0
        # Thus l(D) = d + 1 - g exactly
        if d > 2 * g - 2:
            upper_bound = d + 1 - g
        else:
            upper_bound = d + 1  # Trivial bound
        
        return lower_bound, upper_bound
    
    def canonical_degree(self) -> int:
        """Degree of canonical divisor: deg(K) = 2g - 2."""
        return 2 * self.genus - 2
    
    def holomorphic_forms_dim(self) -> int:
        """Dimension of holomorphic 1-forms: h^0(K) = g."""
        return self.genus

Homological Algebra: Chain Complexes and Derived Functors

homological-algebra

Historical Context

Homological algebra emerged in the 1940s and 1950s from the work of Eilenberg, Mac Lane, Cartan, and Grothendieck. It began as a systematic study of homology in algebraic topology but quickly became an independent field with applications across mathematics. The development of category theory provided the natural language for homological algebra, allowing unified treatment of cohomology theories in topology, algebraic geometry, and group theory. Grothendieck's Tôhoku paper (1957) established the modern foundations, introducing abelian categories and derived functors in full generality.

Definitions

  • Chain Complex: A sequence \\(\\cdots \\xrightarrow{d_{n+1}} C_n \\xrightarrow{d_n} C_{n-1} \\xrightarrow{d_{n-1}} \\cdots\\) with \\(d_n \\circ d_{n+1} = 0\\).
  • Homology: \\(H_n(C) = \\ker(d_n) / \\text{im}(d_{n+1})\\). Elements of \\(\\ker(d_n)\\) are cycles; elements of \\(\\text{im}(d_{n+1})\\) are boundaries.
  • Chain Map: A family \\(f_n: C_n \\to D_n\\) commuting with differentials: \\(f_{n-1} \\circ d_n^C = d_n^D \\circ f_n\\).
  • Chain Homotopy: Maps \\(h_n: C_n \\to D_{n+1}\\) with \\(f_n - g_n = d_{n+1}^D \\circ h_n + h_{n-1} \\circ d_n^C\\). Homotopic maps induce the same homology map.
  • Resolution: An exact sequence \\(\\cdots \\to P_2 \\to P_1 \\to P_0 \\to M \\to 0\\). If all \\(P_i\\) are projective, it's a projective resolution.
  • Derived Functor: For right exact \\(F\\), \\(L_nF(M) = H_n(F(P_\\bullet))\\) where \\(P_\\bullet \\to M\\) is a projective resolution.

Theorem: The Long Exact Sequence in Homology

Theorem: A short exact sequence of chain complexes \\(0 \\to A_\\bullet \\xrightarrow{f} B_\\bullet \\xrightarrow{g} C_\\bullet \\to 0\\) induces a long exact sequence in homology: \\[\\cdots \\to H_n(A) \\xrightarrow{f_*} H_n(B) \\xrightarrow{g_*} H_n(C) \\xrightarrow{\\partial} H_{n-1}(A) \\to \\cdots\\] where the connecting homomorphism \\(\\partial\\) sends \\([c] \\in H_n(C)\\) to \\([a] \\in H_{n-1}(A)\\) where \\(f(a) = d_B(b)\\) for any \\(b\\) with \\(g(b) = c\\).

Proof Sketch

The snake lemma applied to the commutative diagram with exact rows: \\[\\begin{array}{ccccccccc} & \\text{coker}(d_{n+1}^A) & \\to & \\text{coker}(d_{n+1}^B) & \\to & \\text{coker}(d_{n+1}^C) & \\to & 0 \\\\ & \\downarrow & & \\downarrow & & \\downarrow & & \\\\ 0 & \\to & \\ker(d_n^A) & \\to & \\ker(d_n^B) & \\to & \\ker(d_n^C) & & \\end{array}\\] yields the connecting homomorphism. Exactness at each term follows from diagram chasing: if \\(g_*([b]) = 0\\), then \\(g(b) = d_C(c')\\), lift to \\(b'\\) with \\(g(b') = c'\\), then \\(b - d_B(b') \\in \\ker(g) = \\text{im}(f)\\), so \\([b] = f_*([a])\\).

Notation Guide

  • \\(C_\\bullet, D_\\bullet\\): Chain complexes
  • \\(d_n: C_n \\to C_{n-1}\\): Differential
  • \\(Z_n = \\ker(d_n)\\): n-cycles
  • \\(B_n = \\text{im}(d_{n+1})\\): n-boundaries
  • \\(H_n = Z_n / B_n\\): n-th homology
  • \\(f_\\bullet: C_\\bullet \\to D_\\bullet\\): Chain map
  • \\(h_\\bullet: f \\simeq g\\): Chain homotopy
  • \\(\\partial\\): Connecting homomorphism
  • \\(\\text{Tor}_n^R(M, N)\\): Left derived of tensor product
  • \\(\\text{Ext}_R^n(M, N)\\): Right derived of Hom

import numpy as np

class ChainComplex:
    """Chain complex of vector spaces with differentials."""
    
    def __init__(self, spaces: Dict[int, np.ndarray], 
                 differentials: Dict[int, np.ndarray]):
        """
        Args:
            spaces: {degree: basis matrix} (just stores dimensions)
            differentials: {degree: d_n: C_n -> C_{n-1}}
        """
        self.spaces = spaces
        self.differentials = differentials
        self._validate()
    
    def _validate(self):
        """Verify d_{n-1} ∘ d_n = 0."""
        for n in self.differentials:
            if n - 1 in self.differentials:
                d_n = self.differentials[n]
                d_nm1 = self.differentials[n - 1]
                if d_nm1.shape[1] != d_n.shape[0]:
                    raise ValueError(f"Dimension mismatch at {n}")
                composition = d_nm1 @ d_n
                if not np.allclose(composition, 0):
                    raise ValueError(f"Differential condition fails at {n}")
    
    def homology(self, n: int) -> Tuple[int, np.ndarray, np.ndarray]:
        """
        Compute H_n = ker(d_n) / im(d_{n+1}).
        Returns (dimension, basis for cycles, basis for boundaries).
        """
        # Compute kernel of d_n
        if n not in self.differentials:
            dim_Cn = self.spaces.get(n, np.zeros((0, 0))).shape[0]
            ker_dim = dim_Cn
            ker_basis = np.eye(dim_Cn) if dim_Cn > 0 else np.array([])
        else:
            d_n = self.differentials[n]
            # SVD to find kernel
            _, s, Vt = np.linalg.svd(d_n)
            rank = np.sum(s > 1e-10)
            ker_basis = Vt[rank:].T if rank < Vt.shape[0] else np.array([]).reshape(Vt.shape[1], 0)
            ker_dim = Vt.shape[0] - rank
        
        # Compute image of d_{n+1}
        if n + 1 not in self.differentials:
            im_dim = 0
            im_basis = np.array([]).reshape(self.spaces.get(n, np.zeros((0, 0))).shape[0], 0)
        else:
            d_np1 = self.differentials[n + 1]
            _, s, _ = np.linalg.svd(d_np1)
            rank = np.sum(s > 1e-10)
            im_dim = rank
            # Image basis from U matrix
            U, _, _ = np.linalg.svd(d_np1)
            im_basis = U[:, :rank] if rank > 0 else np.array([]).reshape(d_np1.shape[0], 0)
        
        # H_n dimension = dim(ker) - rank(im)
        h_dim = ker_dim - im_dim
        
        return max(0, h_dim), ker_basis, im_basis
    
    def betti_numbers(self) -> Dict[int, int]:
        """Compute all Betti numbers."""
        degrees = set(self.spaces.keys()) | set(self.differentials.keys())
        return {n: self.homology(n)[0] for n in degrees}

Differential Geometry: Curvature and Geodesics

differential-geometry

Historical Context

Differential geometry emerged from the study of curves and surfaces in the 18th and 19th centuries. Gauss's Theorema Egregium (1827) showed that Gaussian curvature is intrinsic, depending only on measurements within the surface rather than its embedding. Riemann's 1854 habilitation lecture generalized these ideas to arbitrary dimensions, laying the foundation for Riemannian geometry. Einstein's general relativity (1915) demonstrated the physical relevance of differential geometry, with spacetime curvature explaining gravity. The field continues to evolve with applications in physics, computer graphics, and machine learning.

Definitions

  • Riemannian Metric: A smooth family of inner products \\(g_p: T_pM \\times T_pM \\to \\mathbb{R}\\) on tangent spaces. In coordinates: \\(g = g_{ij} dx^i \\otimes dx^j\\).
  • Levi-Civita Connection: The unique torsion-free connection compatible with the metric: \\(\\nabla g = 0\\).
  • Christoffel Symbols: \\(\\Gamma^k_{ij} = \\frac{1}{2}g^{kl}(\\partial_i g_{jl} + \\partial_j g_{il} - \\partial_l g_{ij})\\).
  • Riemann Curvature Tensor: \\(R^l_{ijk} = \\partial_i \\Gamma^l_{jk} - \\partial_j \\Gamma^l_{ik} + \\Gamma^l_{im}\\Gamma^m_{jk} - \\Gamma^l_{jm}\\Gamma^m_{ik}\\).
  • Ricci Curvature: \\(R_{ij} = R^k_{ikj}\\). The trace of the Riemann tensor.
  • Scalar Curvature: \\(R = g^{ij}R_{ij}\\).
  • Geodesic: A curve \\(\\gamma\\) with \\(\\nabla_{\\dot{\\gamma}}\\dot{\\gamma} = 0\\), i.e., \\(\\ddot{\\gamma}^k + \\Gamma^k_{ij}\\dot{\\gamma}^i\\dot{\\gamma}^j = 0\\).

Theorem: The Gauss-Bonnet Theorem

Theorem: Let \\(M\\) be a compact 2-dimensional Riemannian manifold without boundary. Then: \\[\\int_M K \\, dA = 2\\pi \\chi(M) = 2\\pi(2 - 2g)\\] where \\(K\\) is Gaussian curvature, \\(dA\\) is the area element, and \\(\\chi(M)\\) is the Euler characteristic with genus \\(g\\).

Proof Sketch

The proof uses the Chern-Weil theory of characteristic classes. For surfaces, the Pfaffian of the curvature 2-form integrates to the Euler class. A combinatorial proof triangulates the surface and relates curvature at vertices to angle defects.

Locally, on a geodesic polygon with angles \\(\\alpha_i\\), the Gauss-Bonnet formula states \\(\\int K \\, dA + \\sum (\\pi - \\alpha_i) = 2\\pi\\). Summing over a triangulation, the edge contributions cancel and the vertex contributions give \\(2\\pi V - 2\\pi E + 2\\pi F = 2\\pi\\chi\\).

Notation Guide

  • \\((M, g)\\): Riemannian manifold
  • \\(g_{ij}\\): Metric tensor components
  • \\(g^{ij}\\): Inverse metric
  • \\(\\Gamma^k_{ij}\\): Christoffel symbols
  • \\(R^l_{ijk}\\): Riemann curvature tensor
  • \\(R_{ij}\\): Ricci tensor
  • \\(R\\): Scalar curvature
  • \\(K\\): Gaussian curvature (2D)
  • \\(\\nabla_X Y\\): Covariant derivative
  • \\(\\chi(M)\\): Euler characteristic

The Riemann Hypothesis: Millennium Problem and Beyond

riemann

Historical Context

In 1859, Bernhard Riemann published his only paper on number theory, "On the Number of Primes Less Than a Given Magnitude." In this eight-page masterpiece, he introduced the Riemann zeta function \\(\\zeta(s)\\) and conjectured that all non-trivial zeros lie on the critical line \\(\\text{Re}(s) = \\frac{1}{2}\\). This Riemann Hypothesis (RH) is now one of the seven Millennium Prize Problems, with a million-dollar reward for its solution. Despite 160+ years of effort and computational verification of the first 10 trillion zeros, a proof remains elusive. The hypothesis connects prime number distribution to complex analysis and has profound implications for cryptography, quantum chaos, and random matrix theory.

Definitions

  • Riemann Zeta Function: For \\(\\text{Re}(s) > 1\\), \\(\\zeta(s) = \\sum_{n=1}^\\infty \\frac{1}{n^s} = \\prod_p \\frac{1}{1 - p^{-s}}\\). Analytically continued to \\(\\mathbb{C} \\setminus \\{1\\}\\).
  • Trivial Zeros: \\(\\zeta(-2n) = 0\\) for \\(n = 1, 2, 3, \\ldots\\) (from the functional equation).
  • Non-Trivial Zeros: Zeros in the critical strip \\(0 < \\text{Re}(s) < 1\\). The RH asserts all have \\(\\text{Re}(s) = \\frac{1}{2}\\).
  • Critical Line: The line \\(\\text{Re}(s) = \\frac{1}{2}\\) in the complex plane.
  • von Mangoldt Function: \\(\\Lambda(n) = \\log p\\) if \\(n = p^k\\), 0 otherwise. Related to zeta via \\(-\\frac{\\zeta'(s)}{\\zeta(s)} = \\sum_{n=1}^\\infty \\frac{\\Lambda(n)}{n^s}\\).
  • Explicit Formula: Relates sums over primes to sums over zeta zeros.

Theorem: The Prime Number Theorem

Theorem: Let \\(\\pi(x)\\) denote the number of primes \\(\\leq x\\). Then: \\[\\pi(x) \\sim \\frac{x}{\\log x}\\] Equivalently, \\(\\pi(x) \\sim \\text{Li}(x) = \\int_2^x \\frac{dt}{\\log t}\\). The error term satisfies: \\[\\pi(x) = \\text{Li}(x) + O(x \\exp(-c\\sqrt{\\log x}))\\] If the Riemann Hypothesis holds, the error is \\(O(\\sqrt{x} \\log x)\\).

Proof Sketch

The proof uses contour integration of \\(-\\frac{\\zeta'(s)}{\\zeta(s)} \\frac{x^s}{s}\\). The poles of the integrand occur at \\(s = 1\\) (giving the main term) and at the zeros of \\(\\zeta(s)\\) (giving oscillatory terms).

Hadamard and de la Vallée Poussin independently proved in 1896 that \\(\\zeta(1 + it) \\neq 0\\), establishing the Prime Number Theorem. The Riemann Hypothesis would give the optimal error bound by controlling the real parts of zeros.

  • \\(\\zeta(s)\\): Riemann zeta function
  • \\(s = \\sigma + it\\): Complex variable
  • \\(\\rho = \\beta + i\\gamma\\): Non-trivial zero

  • \\(\\text{Li}(x)\\): Logarithmic integral
  • \\(\\Lambda(n)\\): von Mangoldt function
  • \\(\\psi(x)\\): Chebyshev function \\(\\sum_{n \\leq x} \\Lambda(n)\\)
  • \\(\\Gamma(s)\\): Gamma function
  • \\(\\xi(s)\\): Riemann xi function
  • \\(N(T)\\): Number of zeros with \\(0 < \\gamma < T\\)

    def verify_zero(t: float, precision: int = 50) -> bool:

        Verify that zeta(1/2 + it) ≈ 0.
        """
        mpmath.mp.dps = precision
        s = 0.5 + 1j * t
        z = mpmath.zeta(s)
        return abs(z) < 10**(-precision//2)

    def prime_counting_function(x: float) -> int:
        """Count primes <= x (naive sieve)."""
        if x < 2:
            return 0
        n = int(x) + 1
        sieve = [True] * n
        sieve[0] = sieve[1] = False
        for i in range(2, int(n**0.5) + 1):
            if sieve[i]:
                for j in range(i*i, n, i):
                    sieve[j] = False
        return sum(sieve)

    def logarithmic_integral(x: float) -> float:
        """Compute Li(x) = \\int_2^x dt/\\log(t)."""
        from scipy.special import expi
        return float(expi(np.log(x)))
    
    @staticmethod
    def von_mangoldt(n: int) -> float:
        """Compute \\Lambda(n)."""
        if n < 2:
            return 0.0
        # Check if n is a prime power
        for p in range(2, int(n**0.5) + 1):
            if n % p == 0:
                # Check if n = p^k
                k = 0
                temp = n
                while temp % p == 0:
                    temp //= p
                    k += 1
                if temp == 1:
                    return np.log(p)
                return 0.0
        # n is prime
        return np.log(n)
    
    @staticmethod
    def explicit_formula(x: float, zeros: list, T: float) -> float:
        """
        Explicit formula relating primes to zeta zeros:
        \\psi(x) = x - \\sum_{|\\gamma| < T} \\frac{x^\\rho}{\\rho} - \\log(2\\pi) - (1/2)\\log(1-x^{-2})
        """
        # Main term
        result = x
        
        # Sum over zeros
        for gamma in zeros:
            if abs(gamma) < T:
                rho = 0.5 + 1j * gamma
                result -= x**rho / rho
        
        # Correction terms
        result -= np.log(2 * np.pi)
        if x > 1:
            result -= 0.5 * np.log(1 - x**(-2))
        
        return result.real

The Birth of Modern Algebra: From Cardano to Galois

The solution of polynomial equations stands as one of the most consequential threads in mathematical history, weaving together the Renaissance ambition to solve practical problems with the emergence of abstract algebraic structures that would reshape mathematics entirely.

The story begins in 16th century Italy, where mathematicians engaged in public competitions to solve cubic equations—a spectacle that drove remarkable discoveries. Scipione del Ferro discovered how to solve depressed cubics (those lacking a quadratic term) around 1515, but kept his method secret, as was the custom of the time. The solution became public knowledge through the work of Niccolò Tartaglia, who independently rediscovered the method, and Girolamo Cardano, who published it in his 1545 masterpiece "Ars Magna" despite promising Tartaglia he would not.

Cardano's student Lodovico Ferrari extended these methods to solve quartic equations, and for a moment, it seemed that higher-degree equations would yield to similar techniques. But the quintic proved stubbornly resistant. For nearly three centuries, mathematicians attempted to find a general solution by radicals—expressions involving only arithmetic operations and root extractions.

The breakthrough came from two young geniuses working independently. In 1824, the Norwegian mathematician Niels Henrik Abel, barely 22 years old, published a proof that the general quintic equation cannot be solved by radicals. Abel's proof, while correct, left open the question of which particular equations were solvable and why.

Évariste Galois, a French revolutionary who would die in a duel at age 20, provided the deeper understanding. Galois's brilliant insight was to study not the equations themselves but the permutations of their roots. He associated to each polynomial equation a group of permutations—the Galois group—and showed that the equation is solvable by radicals if and only if this group is "solvable" in the technical sense he defined. The general quintic has Galois group \\(S_5\\), which is not solvable, explaining the impossibility Abel had established.

Galois wrote his discoveries in a letter to a friend the night before his fatal duel in 1832. The letter, along with his other papers, was eventually published by Joseph Liouville in 1846, fifteen years after Galois's death. The theory that emerged—Galois theory—became one of the pillars of modern algebra, demonstrating the power of abstract structures to illuminate concrete problems. It established group theory as a fundamental tool in mathematics and set the stage for the abstract algebra of the 20th century, where structures like groups, rings, and fields would be studied for their own sake, independent of their origins in classical problems.

IMO Shortlist 2025 Problem A7

Let \\(n \\geq 2\\) be an integer. Find all functions \\(f: \\mathbb{R} \\to \\mathbb{R}\\) such that for all real numbers \\(x_1, x_2, \\ldots, x_n\\): \\[\\sum_{i=1}^n f(x_i) - \\sum_{1 \\leq i < j \\leq n} f(x_i + x_j) + \\sum_{1 \\leq i < j < k \\leq n} f(x_i + x_j + x_k) - \\cdots + (-1)^{n-1} f(x_1 + x_2 + \\cdots + x_n) = 0\\]

Hint

Consider the case \\(n = 2\\) first to identify the pattern. Then use induction on \\(n\\). The alternating sum suggests a connection to the inclusion-exclusion principle or Möbius inversion. Try substituting specific values like \\(x_1 = x_2 = \\cdots = x_n = x\\) to derive constraints on \\(f\\).

Solution

Answer: The solutions are \\(f(x) = ax + b\\) for constants \\(a, b \\in \\mathbb{R}\\) when \\(n\\) is odd, and \\(f(x) = b\\) (constant functions) when \\(n\\) is even.

Solution:

Let \\(S_k = \\sum_{1 \\leq i_1 < i_2 < \\cdots < i_k \\leq n} f(x_{i_1} + \\cdots + x_{i_k})\\). The given condition is: \\[\\sum_{k=1}^n (-1)^{k-1} S_k = 0\\]

Case 1: \\(n = 2\\)

The condition becomes \\(f(x_1) + f(x_2) - f(x_1 + x_2) = 0\\), i.e., \\(f(x_1 + x_2) = f(x_1) + f(x_2)\\). This is Cauchy's functional equation, whose solutions are \\(f(x) = ax\\) if we assume continuity (or other regularity conditions), but without such assumptions, there are pathological solutions. However, for the general \\(n\\) case, we'll see additional constraints emerge.

Case 2: General \\(n\\)

Set \\(x_1 = x_2 = \\cdots = x_n = x\\). Then: \\[\\sum_{k=1}^n (-1)^{k-1} \\binom{n}{k} f(kx) = 0\\]

Let \\(g(t) = f(tx)\\) for fixed \\(x\\). Then \\(\\sum_{k=1}^n (-1)^{k-1} \\binom{n}{k} g(k) = 0\\).

Using the identity \\(\\sum_{k=0}^n (-1)^k \\binom{n}{k} = 0\\) for \\(n \\geq 1\\), we can rewrite: \\[\\sum_{k=1}^n (-1)^{k-1} \\binom{n}{k} g(k) = g(0) - \\sum_{k=0}^n (-1)^k \\binom{n}{k} g(k)\\]

For \\(g(k) = 1\\) (constant), this equals \\(1 - 0 = 1 \\neq 0\\) when \\(n\\) is odd. Wait—let's reconsider. Actually, for constant \\(f(x) = c\\), each \\(S_k = \\binom{n}{k} c\\), so: \\[\\sum_{k=1}^n (-1)^{k-1} \\binom{n}{k} c = c(1 - (1-1)^n) = c\\]

For this to equal 0, we need \\(c = 0\\) when \\(n\\) is odd, but any \\(c\\) works when \\(n\\) is even (since \\((1-1)^n = 0\\) for \\(n \\geq 1\\)).

For linear \\(f(x) = ax + b\\): \\[S_k = \\binom{n}{k} b + a \\sum_{|I|=k} \\sum_{i \\in I} x_i = \\binom{n}{k} b + a \\sum_{i=1}^n x_i \\binom{n-1}{k-1}\\]

Computing the alternating sum and using \\(\\sum_{k=1}^n (-1)^{k-1} \\binom{n-1}{k-1} = (1-1)^{n-1} = 0^{n-1}\\), we get 0 when \\(n \\geq 2\\).

Thus for odd \\(n\\), all linear functions work; for even \\(n\\), only constant functions work.

Riemann Surface of the Square Root Function

The square root function \\(w = \\sqrt{z}\\) is multi-valued: each non-zero complex number \\(z\\) has two square roots. To make this function single-valued, we construct a Riemann surface by taking two copies of the complex plane (sheets) and connecting them along a branch cut, typically the positive real axis. As a point \\(z\\) circles the origin, it transitions from one sheet to the other, revealing the helical structure visualized below.

This visualization shows the real part of \\(\\sqrt{z}\\) plotted as height over the complex plane, with the two sheets of the Riemann surface clearly visible. The branch point at the origin, where the two sheets meet, is where the function value is uniquely zero.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def plot_riemann_sqrt():
    """
    Visualize the Riemann surface of f(z) = sqrt(z).
    Shows the two-sheeted structure with branch point at origin.
    """
    # Create polar coordinate grid
    r = np.linspace(0.01, 2, 100)
    theta = np.linspace(0, 4*np.pi, 200)  # 0 to 4π to show both sheets
    R, Theta = np.meshgrid(r, theta)
    
    # sqrt(z) = sqrt(r) * e^(i*theta/2)
    # Real part: sqrt(r) * cos(theta/2)
    Z_real = np.sqrt(R) * np.cos(Theta / 2)
    
    # Convert to Cartesian for plotting
    X = R * np.cos(Theta)
    Y = R * np.sin(Theta)
    
    # Create figure
    fig = plt.figure(figsize=(14, 6))
    
    # Plot 1: Full Riemann surface (both sheets)
    ax1 = fig.add_subplot(121, projection='3d')
    surf1 = ax1.plot_surface(X, Y, Z_real, cmap='viridis', 
                              alpha=0.9, linewidth=0, antialiased=True)
    ax1.set_xlabel('Re(z)')
    ax1.set_ylabel('Im(z)')
    ax1.set_zlabel('Re(√z)')
    ax1.set_title('Riemann Surface of √z (Two Sheets)')
    
    # Plot 2: Branch cut visualization
    ax2 = fig.add_subplot(122, projection='3d')
    
    # First sheet: theta in [0, 2π)
    theta1 = np.linspace(0, 2*np.pi, 100)
    R1, Theta1 = np.meshgrid(r, theta1)
    X1 = R1 * np.cos(Theta1)
    Y1 = R1 * np.sin(Theta1)
    Z1 = np.sqrt(R1) * np.cos(Theta1 / 2)
    
    # Second sheet: theta in [2π, 4π)
    theta2 = np.linspace(2*np.pi, 4*np.pi, 100)
    R2, Theta2 = np.meshgrid(r, theta2)
    X2 = R2 * np.cos(Theta2)
    Y2 = R2 * np.sin(Theta2)
    Z2 = np.sqrt(R2) * np.cos(Theta2 / 2)
    
    ax2.plot_surface(X1, Y1, Z1, cmap='Blues', alpha=0.8, label='Sheet 1')
    ax2.plot_surface(X2, Y2, Z2, cmap='Reds', alpha=0.8, label='Sheet 2')
    ax2.set_xlabel('Re(z)')
    ax2.set_ylabel('Im(z)')
    ax2.set_zlabel('Re(√z)')
    ax2.set_title('Branch Cut along Positive Real Axis')
    
    plt.tight_layout()
    plt.savefig('riemann_surface_sqrt.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    return fig
