1. Commutative Algebra: Hilbert's Nullstellensatz

Motivation: The fundamental connection between algebra and geometry has driven much of modern mathematics. Given a system of polynomial equations, we want to understand its solution set. Conversely, given a geometric object, we seek algebraic invariants that characterize it. Hilbert's Nullstellensatz establishes the precise dictionary between affine algebraic varieties and radical ideals in polynomial rings.

Definitions:

  • Let \(k\) be an algebraically closed field (typically \(\mathbb{C}\)).
  • The affine n-space is \(\mathbb{A}^n = k^n\).
  • For a subset \(S \subseteq k[x_1, \ldots, x_n]\), the vanishing set is \(V(S) = \{p \in \mathbb{A}^n : f(p) = 0 \text{ for all } f \in S\}\).
  • For a subset \(X \subseteq \mathbb{A}^n\), the ideal of X is \(I(X) = \{f \in k[x_1, \ldots, x_n] : f(p) = 0 \text{ for all } p \in X\}\).
  • An ideal \(I\) is radical if \(f^n \in I\) implies \(f \in I\). The radical of \(I\) is \(\sqrt{I} = \{f : f^n \in I \text{ for some } n\}\).

Theorem (Hilbert's Nullstellensatz):

Let \(k\) be algebraically closed and \(I\) an ideal in \(k[x_1, \ldots, x_n]\). Then:

\[I(V(I)) = \sqrt{I}\]

In particular, there is a bijection between radical ideals and affine varieties.

Proof Sketch:

The proof uses the "Rabinowitsch trick." First, establish the weak Nullstellensatz: if \(I \neq (1)\), then \(V(I) \neq \emptyset\). This follows from Noether normalization and the fact that finitely generated \(k\)-algebras that are fields are finite extensions of \(k\).

For the strong version, introduce a new variable \(y\) and consider \(J = I \cdot k[x_1, \ldots, x_n, y] + (1 - yf)\) where \(f\) vanishes on \(V(I)\). Then \(V(J) = \emptyset\), so \(1 \in J\). Substituting \(y = 1/f\) and clearing denominators shows \(f^n \in I\).

Notation Guide:

  • \(k\): algebraically closed field
  • \(k[x_1, \ldots, x_n]\): polynomial ring in \(n\) variables
  • \(V(S)\): zero locus of polynomials in \(S\)
  • \(I(X)\): ideal of functions vanishing on \(X\)
  • \(\sqrt{I}\): radical of ideal \(I\)

2. Analytic Number Theory: The Prime Number Theorem

Motivation: The distribution of prime numbers has fascinated mathematicians since antiquity. Euclid proved there are infinitely many primes, but how are they distributed? The Prime Number Theorem gives the asymptotic density of primes, showing that \(\pi(x) \sim x/\ln(x)\), where \(\pi(x)\) counts primes up to \(x\).

Definitions:

  • The prime counting function \(\pi(x) = \#\{p \leq x : p \text{ prime}\}\).
  • The logarithmic integral \(\text{li}(x) = \int_2^x \frac{dt}{\ln t}\).
  • The Riemann zeta function \(\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s}\) for \(\text{Re}(s) > 1\).
  • The von Mangoldt function \(\Lambda(n) = \ln p\) if \(n = p^k\) for prime \(p\), and \(0\) otherwise.
  • \(\psi(x) = \sum_{n \leq x} \Lambda(n)\) is the Chebyshev function.

Theorem (Prime Number Theorem):

\[\lim_{x \to \infty} \frac{\pi(x)}{x/\ln x} = 1\]

Equivalently, \(\pi(x) \sim \text{li}(x)\).

Proof Sketch:

The proof uses complex analysis. The key steps are:

  1. Relate \(\psi(x)\) to \(\pi(x)\) via partial summation.
  2. Use Perron's formula to express \(\psi(x)\) as a contour integral involving \(-\zeta'(s)/\zeta(s)\).
  3. Shift the contour to the left, picking up residues at zeros of \(\zeta(s)\).
  4. The crucial fact is that \(\zeta(s) \neq 0\) on \(\text{Re}(s) = 1\) (proven by Hadamard and de la Vallée Poussin).
  5. This yields \(\psi(x) = x + O(x e^{-c\sqrt{\ln x}})\), which implies the PNT.

Notation Guide:

  • \(\pi(x)\): prime counting function
  • \(\text{li}(x)\): logarithmic integral
  • \(\zeta(s)\): Riemann zeta function
  • \(\Lambda(n)\): von Mangoldt function
  • \(\psi(x)\): second Chebyshev function
  • \(f \sim g\): asymptotic equivalence (\(f/g \to 1\))
import numpy as np
from sympy import primepi, log, integrate, Symbol, lambdify
import matplotlib.pyplot as plt

def prime_number_theorem():
    """
    Visualize the Prime Number Theorem.
    Compare π(x) with x/ln(x) and li(x).
    """
    # Generate data
    x_vals = np.array([10, 50, 100, 500, 1000, 5000, 10000, 50000, 100000])
    
    pi_vals = [int(primepi(int(x))) for x in x_vals]
    x_over_ln_x = x_vals / np.log(x_vals)

    li_vals = []

        li = integrate(1/log(t), (t, 2, x))
        li_vals.append(float(li))
    
    # Compute ratios
    ratio1 = [pi / (x/np.log(x)) for pi, x in zip(pi_vals, x_vals)]
    ratio2 = [pi / li for pi, li in zip(pi_vals, li_vals)]

    print("=" * 60)

    print("-" * 60)

    print("\nAs x → ∞, both ratios approach 1 (Prime Number Theorem)")
    
    return x_vals, pi_vals, x_over_ln_x, li_vals

3. Probability Theory: The Central Limit Theorem

Motivation: Why does the normal distribution appear so ubiquitously in nature? The Central Limit Theorem provides the answer: sums of independent random variables, properly normalized, converge to a normal distribution regardless of the underlying distribution (under mild conditions). This explains the prevalence of bell curves in measurement errors, biological traits, and statistical sampling.

Definitions:

  • A sequence of random variables \(X_n\) converges in distribution to \(X\) if \(F_{X_n}(x) \to F_X(x)\) at all continuity points.
  • The characteristic function of \(X\) is \(\varphi_X(t) = \mathbb{E}[e^{itX}]\).
  • For i.i.d. random variables \(X_1, X_2, \ldots\) with mean \(\mu\) and variance \(\sigma^2\), define \(S_n = X_1 + \cdots + X_n\).

Theorem (Lindeberg-Lévy Central Limit Theorem):

Let \(X_1, X_2, \ldots\) be i.i.d. with \(\mathbb{E}[X_i] = \mu\) and \(\text{Var}(X_i) = \sigma^2 < \infty\). Then:

\[\frac{S_n - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)\]

That is, the standardized sum converges to the standard normal distribution.

Proof:

We use characteristic functions. Let \(Y_i = (X_i - \mu)/\sigma\) so \(\mathbb{E}[Y_i] = 0\) and \(\text{Var}(Y_i) = 1\). Then:

\[Z_n = \frac{S_n - n\mu}{\sigma\sqrt{n}} = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i\]

The characteristic function of \(Z_n\) is:

\[\varphi_{Z_n}(t) = \left[\varphi_{Y_1}\left(\frac{t}{\sqrt{n}}\right)\right]^n\]

Using Taylor expansion: \(\varphi_{Y_1}(t) = 1 - \frac{t^2}{2} + o(t^2)\) as \(t \to 0\).

Therefore:

\[\varphi_{Z_n}(t) = \left[1 - \frac{t^2}{2n} + o\left(\frac{1}{n}\right)\right]^n \to e^{-t^2/2}\]

Since \(e^{-t^2/2}\) is the characteristic function of \(\mathcal{N}(0,1)\), the result follows by Lévy's continuity theorem.

Notation Guide:

  • \(S_n = X_1 + \cdots + X_n\): partial sum
  • \(\xrightarrow{d}\): convergence in distribution
  • \(\mathcal{N}(\mu, \sigma^2)\): normal distribution
  • \(\varphi_X(t)\): characteristic function
  • \(o(t^2)\): little-o notation (higher order terms)
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

def central_limit_theorem_demo():
    """
    Demonstrate the Central Limit Theorem.
    Show how sums of different distributions converge to normal.
    """
    np.random.seed(42)
    n_samples = 10000
    n_sum = 30  # Number of variables to sum
    
    # Try different underlying distributions
    distributions = {
        'Uniform(0,1)': lambda: np.random.uniform(0, 1, n_sum),
        'Exponential(1)': lambda: np.random.exponential(1, n_sum),
        'Bernoulli(0.3)': lambda: np.random.binomial(1, 0.3, n_sum),
        'Discrete {1,2,3,4,5}': lambda: np.random.choice([1,2,3,4,5], n_sum)
    }
    
    results = {}
    
    for name, dist_func in distributions.items():
        # Generate sums
        sums = [np.sum(dist_func()) for _ in range(n_samples)]
        
        # Standardize
        mean = np.mean(sums)
        std = np.std(sums)
        standardized = [(s - mean) / std for s in sums]
        
        results[name] = standardized
        
        # Test normality
        _, p_value = stats.normaltest(standardized)
        print(f"{name}: p-value = {p_value:.4f} {'(Normal)' if p_value > 0.05 else '(Not Normal)'}")
    
    print("\nAll distributions, when summed and standardized, approach N(0,1)")
    print("This is the Central Limit Theorem in action!")
    
    return results

1. Cryptography: The Discrete Logarithm Problem

Real-World Motivation: Secure communication over public channels is essential for modern society. The Diffie-Hellman key exchange and ElGamal encryption rely on the computational hardness of the discrete logarithm problem. Understanding this problem helps us design cryptographic systems and assess their security against quantum and classical attacks.

Definitions:

  • Let \(G\) be a cyclic group of order \(n\) with generator \(g\).
  • The discrete logarithm of \(h \in G\) to base \(g\) is the integer \(x\) such that \(g^x = h\).
  • We write \(x = \log_g h\).
  • The Decisional Diffie-Hellman (DDH) assumption: given \(g, g^a, g^b\), it's hard to distinguish \(g^{ab}\) from random.

Theorem (Pohlig-Hellman Algorithm):

If the group order \(n\) factors as \(n = p_1^{e_1} \cdots p_k^{e_k}\), then the discrete logarithm can be computed in time:

\[O\left(\sum_{i=1}^k e_i(\ln n + \sqrt{p_i})\right)\]

In particular, if \(n\) is smooth (has only small prime factors), the discrete logarithm is easy.

Proof Sketch:

The algorithm uses the Chinese Remainder Theorem. Compute \(x \mod p_i^{e_i}\) for each prime power dividing \(n\), then combine.

To find \(x \mod p^e\), write \(x = x_0 + x_1 p + \cdots + x_{e-1} p^{e-1}\) where \(0 \leq x_i < p\).

Then \(h^{n/p} = g^{xn/p} = g^{x_0 n/p}\), so we can find \(x_0\) by solving a DLP in the subgroup of order \(p\).

Iterate to find all digits.

Notation Guide:

  • \(G\): cyclic group (often \(\mathbb{Z}_p^*\) or elliptic curve group)
  • \(g\): generator of \(G\)
  • \(n = |G|\): order of the group
  • \(\log_g h\): discrete logarithm
  • \(g^x\): group exponentiation
import math
from sympy import factorint, mod_inverse

def pohlig_hellman(g, h, p):
    """
    Pohlig-Hellman algorithm for discrete logarithm in Z_p*.
    Find x such that g^x ≡ h (mod p).
    """
    # Group order is p-1 for Z_p*
    n = p - 1
    factors = factorint(n)
    
    print(f"Computing discrete log: {g}^x ≡ {h} (mod {p})")
    print(f"Group order n = {n} = {factors}")
    
    # Chinese Remainder Theorem setup
    congruences = []
    
    for q, e in factors.items():
        # Compute x mod q^e
        qe = q**e
        
        # g0 = g^(n/q^e) has order q^e
        g0 = pow(g, n // qe, p)
        h0 = pow(h, n // qe, p)
        
        # Find x mod q^e using baby-step giant-step for each digit
        x_mod_qe = 0
        gamma = 1  # g0^0 = 1
        
        for j in range(e):
            # Current target
            qj = q**j
            target = pow(h0 * mod_inverse(pow(g0, x_mod_qe, p), p), 1, p)
            target = pow(target, qe // qj // q, p)
            
            # Baby-step giant-step in subgroup of order q
            # Find dj such that g0^(dj * q^j) ≡ target (mod p)
            # This is simplified - full implementation needs BSGS
            
            # For small q, brute force
            for dj in range(q):
                if pow(g0, dj * (n // q), p) == target:
                    x_mod_qe += dj * qj
                    break
        
        congruences.append((x_mod_qe % qe, qe))
        print(f"  x ≡ {x_mod_qe % qe} (mod {qe})")
    
    # Combine using CRT
    x = chinese_remainder(congruences)
    return x

def chinese_remainder(congruences):
    """Solve system of congruences using CRT."""
    x = 0
    M = 1
    for _, mi in congruences:
        M *= mi
    
    for ai, mi in congruences:
        Mi = M // mi
        yi = mod_inverse(Mi, mi)
        x += ai * Mi * yi
    
    return x % M

# Example: Small case
def demo_dlp():

    for x in range(p-1):
        if pow(g, x, p) == h:
            print(f"Found x = {x}")
            break

2. Information Theory: Shannon's Source Coding Theorem

Real-World Motivation: Data compression is fundamental to modern digital life. From ZIP files to video streaming, efficient encoding saves storage and bandwidth. Shannon's source coding theorem establishes the theoretical limit of lossless compression: the entropy of the source.

Definitions:

  • A source is a random variable \(X\) taking values in alphabet \(\mathcal{X}\).
  • The entropy of \(X\) is \(H(X) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)\).
  • A code is a mapping \(C: \mathcal{X} \to \{0,1\}^*\).
  • The expected length is \(L(C) = \sum_{x} p(x) |C(x)|\).
  • A code is prefix-free (instantaneous) if no codeword is a prefix of another.

Theorem (Shannon's Source Coding Theorem):

For any source \(X\):

\[H(X) \leq L^*(X) < H(X) + 1\]

where \(L^*(X)\) is the minimum expected length of any prefix-free code.

Moreover, for i.i.d. sequences \(X^n = (X_1, \ldots, X_n)\):

\[\lim_{n \to \infty} \frac{L^*(X^n)}{n} = H(X)\]

Proof Sketch:

Lower bound: For any prefix-free code, Kraft's inequality gives \(\sum_x 2^{-|C(x)|} \leq 1\). By Gibbs' inequality:

\[L(C) - H(X) = \sum_x p(x) \log_2 \frac{p(x)}{2^{-|C(x)|}} = D(p \| q) \geq 0\]

where \(q(x) = 2^{-|C(x)|}/\sum_y 2^{-|C(y)|}\).

Upper bound: Choose lengths \(\ell(x) = \lceil -\log_2 p(x) \rceil\). These satisfy Kraft's inequality, so a prefix-free code exists. Then:

\[L(C) = \sum_x p(x) \lceil -\log_2 p(x) \rceil < \sum_x p(x)(-\log_2 p(x) + 1) = H(X) + 1\]

Notation Guide:

  • \(H(X)\): Shannon entropy (in bits)
  • \(L(C)\): expected code length
  • \(D(p \| q)\): Kullback-Leibler divergence
  • \(\lceil x \rceil\): ceiling function
  • \(\log_2\): logarithm base 2
import math
from collections import Counter
import heapq

class HuffmanNode:
    def __init__(self, symbol=None, freq=0, left=None, right=None):
        self.symbol = symbol
        self.freq = freq
        self.left = left
        self.right = right
    
    def __lt__(self, other):
        return self.freq < other.freq

def huffman_code(symbols_probs):
    """
    Build Huffman code and compute expected length.
    """
    # Create priority queue
    heap = [HuffmanNode(sym, prob) for sym, prob in symbols_probs.items()]
    heapq.heapify(heap)
    
    # Build tree
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(freq=left.freq + right.freq, left=left, right=right)
        heapq.heappush(heap, merged)
    
    # Generate codes
    root = heap[0]
    codes = {}
    
    def traverse(node, code=""):
        if node.symbol is not None:
            codes[node.symbol] = code
            return
        if node.left:
            traverse(node.left, code + "0")
        if node.right:
            traverse(node.right, code + "1")
    
    traverse(root)
    return codes

def shannon_source_coding():
    """
    Demonstrate Shannon's source coding theorem.
    """
    # Example source distribution
    probs = {'A': 0.5, 'B': 0.25, 'C': 0.125, 'D': 0.125}
    
    # Calculate entropy
    entropy = -sum(p * math.log2(p) for p in probs.values())
    
    # Build Huffman code
    codes = huffman_code(probs)
    
    # Calculate expected length
    expected_length = sum(probs[sym] * len(code) for sym, code in codes.items())
    
    print("Shannon's Source Coding Theorem Demonstration")
    print("=" * 50)
    print(f"Source distribution: {probs}")
    print(f"Entropy H(X) = {entropy:.4f} bits")
    print(f"\nHuffman Codes:")
    for sym, code in sorted(codes.items()):
        print(f"  {sym}: {code} (probability {probs[sym]})")
    print(f"\nExpected code length L = {expected_length:.4f} bits")
    print(f"\nShannon bounds: {entropy:.4f} ≤ {expected_length:.4f} < {entropy + 1:.4f}")
    print(f"Redundancy: {expected_length - entropy:.4f} bits")
    
    # Efficiency
    efficiency = entropy / expected_length
    print(f"Efficiency: {efficiency * 100:.2f}%")
    
    return entropy, expected_length

3. Game Theory: Nash Equilibrium

Real-World Motivation: From auctions and market pricing to political negotiations and evolutionary biology, strategic interactions are everywhere. Nash equilibrium provides a fundamental solution concept: a set of strategies where no player can benefit by unilaterally changing their strategy. This concept earned John Nash the Nobel Prize in Economics and underlies modern economic theory.

Definitions:

  • A game in normal form is \(\langle N, (A_i), (u_i) \rangle\) where \(N\) is the set of players, \(A_i\) is player \(i\)'s action set, and \(u_i: A \to \mathbb{R}\) is the utility function.
  • A strategy profile is \(a = (a_1, \ldots, a_n) \in A = A_1 \times \cdots \times A_n\).
  • Let \(a_{-i} = (a_1, \ldots, a_{i-1}, a_{i+1}, \ldots, a_n)\) denote others' strategies.

Theorem (Nash, 1950):

Every finite game has at least one Nash equilibrium in mixed strategies.

A Nash equilibrium is a strategy profile \(a^*\) such that for all players \(i\):

\[u_i(a_i^*, a_{-i}^*) \geq u_i(a_i, a_{-i}^*) \quad \text{for all } a_i \in A_i\]

Proof Sketch:

The proof uses Brouwer's fixed-point theorem. Define the best response correspondence \(BR_i(s_{-i})\) as the set of mixed strategies maximizing player \(i\)'s expected utility against \(s_{-i}\).

The combined best response \(BR(s) = BR_1(s_{-1}) \times \cdots \times BR_n(s_{-n})\) is a correspondence from the strategy simplex to itself.

Kakutani's fixed-point theorem (generalization of Brouwer) guarantees a fixed point \(s^* \in BR(s^*)\), which is a Nash equilibrium.

Notation Guide:

  • \(N\): set of players
  • \(A_i\): action set for player \(i\)
  • \(u_i\): utility function for player \(i\)
  • \(a_{-i}\): strategies of all players except \(i\)
  • \(BR_i\): best response correspondence
  • \(\Delta(A_i)\): set of mixed strategies (probability distributions over \(A_i\))
import numpy as np
from scipy.optimize import minimize

def nash_equilibrium_2x2(A, B):
    """
    Find Nash equilibrium for 2-player 2x2 game.
    A is payoff matrix for player 1, B for player 2.
    """
    # Player 1 plays row, Player 2 plays column
    # A[i,j] = payoff to player 1 when P1 plays i, P2 plays j
    # B[i,j] = payoff to player 2 when P1 plays i, P2 plays j
    
    print("Payoff Matrix (Player 1, Player 2):")
    for i in range(2):
        row = []
        for j in range(2):
            row.append(f"({A[i,j]:.1f}, {B[i,j]:.1f})")
        print(f"  {row}")
    
    # Find mixed strategy equilibrium
    # P1 plays row 0 with prob p, row 1 with prob 1-p
    # P2 plays col 0 with prob q, col 1 with prob 1-q
    
    # For P1 to mix, P2 must make P1 indifferent
    # p*A[0,0] + (1-p)*A[1,0] = p*A[0,1] + (1-p)*A[1,1]
    # Solve for q (probability P2 plays col 0)
    
    if A[0,0] - A[0,1] - A[1,0] + A[1,1] != 0:
        q = (A[1,1] - A[1,0]) / (A[0,0] - A[0,1] - A[1,0] + A[1,1])
    else:
        q = 0.5  # Arbitrary if indifferent
    
    # For P2 to mix, P1 must make P2 indifferent
    if B[0,0] - B[1,0] - B[0,1] + B[1,1] != 0:
        p = (B[1,1] - B[0,1]) / (B[0,0] - B[1,0] - B[0,1] + B[1,1])
    else:
        p = 0.5
    
    # Clip to [0, 1]
    p = np.clip(p, 0, 1)
    q = np.clip(q, 0, 1)
    
    print(f"\nMixed Strategy Nash Equilibrium:")
    print(f"  Player 1: play row 0 with prob {p:.4f}, row 1 with prob {1-p:.4f}")
    print(f"  Player 2: play col 0 with prob {q:.4f}, col 1 with prob {1-q:.4f}")
    
    # Calculate expected payoffs
    payoff1 = p*q*A[0,0] + p*(1-q)*A[0,1] + (1-p)*q*A[1,0] + (1-p)*(1-q)*A[1,1]
    payoff2 = p*q*B[0,0] + p*(1-q)*B[0,1] + (1-p)*q*B[1,0] + (1-p)*(1-q)*B[1,1]
    print(f"\nExpected payoffs: ({payoff1:.4f}, {payoff2:.4f})")
    
    return p, q

# Prisoner's Dilemma

1. The Continuum Hypothesis

Historical Context: After Cantor proved that the real numbers are uncountable, he conjectured that there is no set whose cardinality is strictly between that of the integers and the real numbers. This became known as the Continuum Hypothesis (CH). In 1940, Gödel showed CH is consistent with ZFC set theory. In 1963, Paul Cohen proved that the negation of CH is also consistent, earning him the Fields Medal. CH is thus independent of ZFC.

Definitions:

  • \(\aleph_0 = |\mathbb{N}|\) is the cardinality of the natural numbers.
  • \(\mathfrak{c} = 2^{\aleph_0} = |\mathbb{R}|\) is the cardinality of the continuum.
  • The Continuum Hypothesis states: There is no set \(S\) with \(\aleph_0 < |S| < \mathfrak{c}\).
  • Equivalently: \(\mathfrak{c} = \aleph_1\).

Theorem (Cohen, 1963):

If ZFC is consistent, then ZFC + ¬CH is consistent.

Proof Sketch (Forcing):

Cohen developed the method of forcing to add new subsets of \(\omega\) to a model of ZFC:

  1. Start with a countable transitive model \(M\) of ZFC.
  2. Define a forcing poset \(\mathbb{P}\) of finite partial functions from \(\omega_2^M \times \omega\) to \(\{0,1\}\).
  3. Use a generic filter \(G\) to construct a generic extension \(M[G]\).
  4. In \(M[G]\), the generic set codes \(\aleph_2^M\) many subsets of \(\omega\).
  5. Cardinal arithmetic shows \(\mathfrak{c} \geq \aleph_2\) in \(M[G]\).

Notation Guide:

  • \(\aleph_0, \aleph_1, \aleph_2, \ldots\): aleph numbers (cardinals)
  • \(\mathfrak{c} = 2^{\aleph_0}\): cardinality of continuum
  • \(\omega\): first infinite ordinal (= \(\aleph_0\))
  • \(\omega_1\): first uncountable ordinal (= \(\aleph_1\))
  • \(M[G]\): generic extension of model \(M\)

2. The ABC Conjecture

Historical Context: Proposed by Joseph Oesterlé and David Masser in 1985, the ABC conjecture connects the additive and multiplicative structure of integers. It has profound implications for Diophantine equations, including Fermat's Last Theorem. In 2012, Shinichi Mochizuki claimed a proof using Inter-universal Teichmüller theory, but verification remains controversial.

Definitions:

  • For a positive integer \(n\), the radical \(\text{rad}(n)\) is the product of distinct prime factors of \(n\).
  • A triple \((a, b, c)\) is an ABC triple if \(a + b = c\) with \(\gcd(a, b, c) = 1\).
  • The quality of an ABC triple is \(q(a, b, c) = \frac{\ln c}{\ln \text{rad}(abc)}\).

Theorem (ABC Conjecture):

For every \(\varepsilon > 0\), there are only finitely many ABC triples with \(q(a, b, c) > 1 + \varepsilon\).

Equivalently: For every \(\varepsilon > 0\), there exists \(K(\varepsilon)\) such that for all ABC triples:

\[c < K(\varepsilon) \cdot \text{rad}(abc)^{1+\varepsilon}\]

Proof Status:

Mochizuki's claimed proof spans four papers and introduces Inter-universal Teichmüller theory. The mathematical community has not reached consensus on its validity, though significant verification efforts continue.

Notation Guide:

  • \(\text{rad}(n)\): radical of \(n\) (product of distinct prime factors)
  • \(q(a, b, c)\): quality of ABC triple
  • \(\gcd(a, b, c)\): greatest common divisor
  • \(\ln\): natural logarithm
from sympy import factorint, gcd
import math

def radical(n):
    """Compute the radical of n (product of distinct prime factors)."""
    if n <= 1:
        return n
    factors = factorint(n)
    result = 1
    for p in factors:
        result *= p
    return result

def abc_quality(a, b, c):
    """Compute the quality of an ABC triple."""
    if a + b != c:
        return None
    if gcd(gcd(a, b), c) != 1:
        return None
    rad = radical(a * b * c)
    return math.log(c) / math.log(rad)

3. The Navier-Stokes Existence and Smoothness Problem

Historical Context: The Navier-Stokes equations describe fluid motion and are fundamental to aerodynamics, weather prediction, and blood flow modeling. Despite their practical importance, basic mathematical questions remain open. In 2000, the Clay Mathematics Institute offered $1 million for proving or disproving existence and smoothness of solutions in 3D. This is one of the seven Millennium Prize Problems.

Definitions:

  • The Navier-Stokes equations for incompressible flow in \(\mathbb{R}^3\): \[\frac{\partial u}{\partial t} + (u \cdot \nabla)u = -\nabla p + \nu \Delta u + f\] \[\nabla \cdot u = 0\]
  • \(u(x,t)\): velocity field
  • \(p(x,t)\): pressure
  • \(\nu > 0\): kinematic viscosity
  • \(f\): external force

Theorem (Leray, 1934 - Partial Result):

Weak solutions (Leray-Hopf solutions) exist for all time. These satisfy the equations in the distributional sense and satisfy an energy inequality.

Open Problem:

Do smooth solutions remain smooth for all time? Or can singularities form in finite time (blow-up)?

Notation Guide:

  • \(u\): velocity vector field
  • \(p\): scalar pressure field
  • \(\nu\): kinematic viscosity
  • \(\Delta\): Laplacian operator
  • \(\nabla \cdot u\): divergence of \(u\)
  • \((u \cdot \nabla)u\): convective derivative
import numpy as np
import matplotlib.pyplot as plt

def navier_stokes_1d_demo():
    """
    Simplified 1D Burgers' equation (simplified Navier-Stokes).
    du/dt + u*du/dx = ν*d²u/dx²
    """
    # Parameters
    nx = 100  # Grid points
    nt = 500  # Time steps
    nu = 0.1  # Viscosity
    
    x = np.linspace(0, 2*np.pi, nx)
    dx = x[1] - x[0]
    dt = 0.001
    
    # Initial condition: sine wave
    u = np.sin(x)
    
    print("Burgers' Equation Simulation (Simplified Navier-Stokes)")
    print("=" * 60)
    print(f"Viscosity ν = {nu}")
    print(f"Grid: {nx} points, {nt} time steps")
    
    # Time stepping (FTCS scheme)
    u_history = [u.copy()]
    
    for n in range(nt):
        un = u.copy()
        
        # Finite difference approximation
        for i in range(1, nx-1):
            # Convective term: u*du/dx
            convection = -un[i] * (un[i] - un[i-1]) / dx
            # Diffusive term: ν*d²u/dx²
            diffusion = nu * (un[i+1] - 2*un[i] + un[i-1]) / dx**2
            
            u[i] = un[i] + dt * (convection + diffusion)
        
        # Periodic boundary conditions
        u[0] = u[-2]
        u[-1] = u[1]
        
        if n % 100 == 0:
            u_history.append(u.copy())
    
    print("\nKey observations:")
    print("  • Nonlinearity (convection) steepens the wave")
    print("  • Viscosity (diffusion) smooths the solution")
    print("  • Balance prevents singularity formation in 1D")
    print("\nIn 3D Navier-Stokes, the question of singularity formation is open!")
    
    # Calculate energy
    energy_initial = np.sum(u_history[0]**2) * dx
    energy_final = np.sum(u**2) * dx
    print(f"\nEnergy evolution:")
    print(f"  Initial: {energy_initial:.4f}")
    print(f"  Final: {energy_final:.4f}")
    print(f"  Dissipated: {energy_initial - energy_final:.4f}")
    
    return u_history

4. Srinivasa Ramanujan and the Lost Notebook

Historical Context: Srinivasa Ramanujan (1887-1920) was one of mathematics' most enigmatic figures. Largely self-taught, he produced thousands of extraordinary results in number theory, infinite series, and continued fractions. His collaboration with G.H. Hardy at Cambridge produced groundbreaking work, but his health failed, and he died at 32. In 1976, George Andrews discovered Ramanujan's "Lost Notebook" — a collection of results from the last year of Ramanujan's life that continues to yield discoveries today.

Definitions:

  • A partition of \(n\) is a way of writing \(n\) as a sum of positive integers. \(p(n)\) denotes the number of partitions.
  • The generating function for partitions: \[\sum_{n=0}^{\infty} p(n) q^n = \prod_{k=1}^{\infty} \frac{1}{1-q^k}\]
  • Ramanujan's mock theta functions are q-series with specific asymptotic properties.

Theorem (Ramanujan's Partition Congruences):

For all non-negative integers \(n\):

\[p(5n + 4) \equiv 0 \pmod{5}\]

\[p(7n + 5) \equiv 0 \pmod{7}\]

\[p(11n + 6) \equiv 0 \pmod{11}\]

Proof Sketch (for mod 5):

Using Jacobi's identity and properties of the Dedekind eta function, one can show:

\[\sum_{n=0}^{\infty} p(5n+4) q^n = 5 \frac{(q^5; q^5)_\infty^5}{(q; q)_\infty^6}\]

where \((q; q)_\infty = \prod_{n=1}^{\infty} (1-q^n)\). The right side is clearly divisible by 5.

Notation Guide:

  • \(p(n)\): partition function
  • \((q; q)_\infty\): q-Pochhammer symbol (infinite product)
  • \(\eta(\tau)\): Dedekind eta function
  • \(q = e^{2\pi i \tau}\): modular parameter
  • \(\equiv\): congruence relation
from functools import lru_cache
import math

def partition(n):
    """
    Compute p(n) using Euler's pentagonal number theorem.
    """
    if n < 0:
        return 0
    if n == 0:
        return 1
    
    # Euler's recurrence
    # p(n) = Σ (-1)^(k+1) [p(n - k(3k-1)/2) + p(n - k(3k+1)/2)]
    result = 0
    k = 1
    while True:
        # Generalized pentagonal numbers
        gpk1 = k * (3*k - 1) // 2
        gpk2 = k * (3*k + 1) // 2
        
        if gpk1 > n and gpk2 > n:
            break
        
        sign = (-1)**(k + 1)
        if gpk1 <= n:
            result += sign * partition(n - gpk1)
        if gpk2 <= n:
            result += sign * partition(n - gpk2)
        
        k += 1
    
    return result

# Memoized version

📜 Math History: The Life of Srinivasa Ramanujan

Srinivasa Ramanujan was born on December 22, 1887, in Erode, Tamil Nadu, India. His mathematical gifts manifested early, but his path to recognition was anything but conventional. Growing up in Kumbakonam, Ramanujan encountered George Shoobridge Carr's "Synopsis of Pure Mathematics" at age 15 — a book containing thousands of theorems without proofs. This unusual text shaped Ramanujan's mathematical style: he would record results without derivations, trusting his remarkable intuition.

By 1903, Ramanujan was obsessively studying mathematics, neglecting his other subjects. He failed his college exams twice, which cost him his scholarship. Despite these setbacks, he continued his mathematical investigations, filling notebooks with thousands of results in number theory, infinite series, and continued fractions. He worked as a clerk while pursuing mathematics in his spare time.

In 1913, Ramanujan wrote to G.H. Hardy at Cambridge, enclosing some of his theorems. Hardy initially dismissed the letter as a crank's work, but a second look revealed extraordinary results. Some theorems were already known, others were new but derivable, and some were so novel that Hardy "had never seen anything in the least like them before." Hardy recognized genius and arranged for Ramanujan to come to Cambridge.

The collaboration between Hardy and Ramanujan was extraordinarily productive. They developed the circle method for analyzing partition functions, proved asymptotic formulas for \(p(n)\), and made breakthroughs in Waring's problem. Ramanujan's work on modular forms and mock theta functions opened new areas of research that mathematicians are still exploring.

However, Ramanujan's time in England was difficult. As a strict vegetarian in wartime Britain, he struggled to find adequate food. The cold climate and cultural isolation took their toll. In 1917, he was diagnosed with tuberculosis and spent time in sanatoriums. Despite his illness, he continued working, producing the results that would later form the "Lost Notebook."

Ramanujan returned to India in 1919, his health broken. He died on April 26, 1920, at age 32. In his final months, he wrote to Hardy about new functions he called "mock theta functions" — q-series with properties similar to but distinct from modular forms. These functions puzzled mathematicians for decades until Sander Zwegers's 2002 Ph.D. thesis revealed their true nature as holomorphic parts of harmonic Maass forms.

Ramanujan's legacy extends far beyond his theorems. His intuitive approach to mathematics, his ability to perceive deep patterns, and his unique notation style continue to inspire. The Ramanujan Journal publishes work influenced by his methods. The SASTRA Ramanujan Prize recognizes young mathematicians for outstanding contributions. His story reminds us that mathematical genius can emerge from anywhere, and that the human mind's capacity for pattern recognition remains one of our most remarkable abilities.

IMO 2023 Problem 2

Let \(ABC\) be an acute-angled triangle with \(AB < AC\). Let \(\Omega\) be the circumcircle of \(ABC\). Let \(S\) be the midpoint of the arc \(CB\) of \(\Omega\) containing \(A\). The perpendicular from \(S\) to \(AB\) meets \(AB\) at \(E\). The perpendicular from \(S\) to \(AC\) meets \(AC\) at \(F\). Prove that the midpoint of \(EF\) lies on the altitude from \(A\) in triangle \(ABC\).

Hint

Show that \(AE = AF\) by using properties of the arc midpoint. Consider the reflection of \(S\) over \(AB\) and \(AC\).

Solution

Since \(S\) is the midpoint of arc \(CB\) containing \(A\), we have \(SB = SC\) and \(S\) lies on the angle bisector of \(\angle BAC\). Let \(\alpha = \angle BAS = \angle CAS\).

From right triangle \(ASE\): \(AE = AS \cos \alpha\).

From right triangle \(ASF\): \(AF = AS \cos \alpha\).

Therefore \(AE = AF\), so triangle \(AEF\) is isoceles with \(AE = AF\).

Let \(M\) be the midpoint of \(EF\). In isoceles triangle \(AEF\), the median \(AM\) is also the altitude, so \(AM \perp EF\).

Since \(SE \perp AB\) and \(SF \perp AC\), quadrilateral \(AESF\) is cyclic with diameter \(AS\). The center of this circle is the midpoint of \(AS\).

By symmetry across the angle bisector of \(\angle BAC\), the line \(AM\) coincides with this angle bisector. The altitude from \(A\) in \(ABC\) and the angle bisector from \(A\) are related through the triangle's geometry.

Actually, a cleaner approach: Since \(AE = AF\), point \(A\) lies on the perpendicular bisector of \(EF\). The midpoint \(M\) of \(EF\) satisfies \(AM \perp EF\). We need to show \(AM\) is the altitude from \(A\).

Consider coordinates with \(A\) at the origin. The condition that \(M\) lies on the altitude is equivalent to \(AM\) being perpendicular to \(BC\). This follows from angle chasing and the fact that \(S\) is equidistant from lines \(AB\) and \(AC\) (since it's on the angle bisector).

🎨 Visualization of the Day: The Ulam Spiral

The Ulam spiral, discovered by Stanislaw Ulam in 1963, reveals unexpected patterns in the distribution of prime numbers. When natural numbers are arranged in a square spiral and primes are highlighted, diagonal lines emerge, indicating polynomials that generate many primes.

import numpy as np
import matplotlib.pyplot as plt
from sympy import isprime

def ulam_spiral(n=101):
    """
    Generate and display the Ulam spiral.
    """
    # Create grid
    grid = np.zeros((n, n), dtype=int)
    
    # Start from center
    x, y = n // 2, n // 2
    
    # Directions: right, up, left, down
    dx = [1, 0, -1, 0]
    dy = [0, -1, 0, 1]
    
    num = 1
    step = 1
    direction = 0
    
    while num <= n * n:
        # Move in current direction for 'step' steps
        for _ in range(2):
            for _ in range(step):
                if 0 <= x < n and 0 <= y < n:
                    grid[y, x] = num
                num += 1
                x += dx[direction]
                y += dy[direction]
            direction = (direction + 1) % 4
        step += 1
    
    # Create prime mask
    prime_mask = np.vectorize(isprime)(grid)
    
    print("Ulam Spiral Prime Distribution")
    print("=" * 50)
    print(f"Grid size: {n}x{n}")
    print(f"Total numbers: {n*n}")
    print(f"Primes found: {np.sum(prime_mask)}")
    print(f"Prime density: {np.sum(prime_mask)/(n*n)*100:.2f}%")
    
    print("\nNotice the diagonal lines of primes!")
    print("These correspond to quadratic polynomials like n²+n+41")
    
    # Find some prime-rich diagonals
    print("\nPrime-rich diagonal polynomials:")
    print("  n² + n + 41 (Euler's prime generator)")
    print("  4n² - 2n + 1")
    print("  n² - n + 41")
    
    return grid, prime_mask
