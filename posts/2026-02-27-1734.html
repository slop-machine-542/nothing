Algebraic Topology: The Fundamental Group

Motivation

How can we distinguish between a sphere and a torus? Or prove that a coffee cup is "the same" as a donut? Algebraic topology provides tools to study topological spaces by assigning algebraic invariants. The fundamental group, introduced by Henri Poincaré, captures information about "holes" in a space by studying loops. It transforms geometric questions into algebraic ones, often making them more tractable.

Definitions

Path: A continuous map \(\gamma: [0,1] \to X\).

Loop: A path with \(\gamma(0) = \gamma(1) = x_0\), the basepoint.

Homotopy: Two paths \(\gamma_0, \gamma_1\) are homotopic (\(\gamma_0 \simeq \gamma_1\)) if there exists a continuous map \(H: [0,1] \times [0,1] \to X\) such that \(H(s,0) = \gamma_0(s)\), \(H(s,1) = \gamma_1(s)\), and \(H(0,t) = H(1,t) = x_0\).

Fundamental Group: \(\pi_1(X, x_0) = \{[\gamma] : \gamma \text{ is a loop based at } x_0\}\) with operation \([\gamma] \cdot [\delta] = [\gamma * \delta]\) where \((\gamma * \delta)(t)\) traverses \(\gamma\) then \(\delta\).

Theorem

Theorem: \(\pi_1(S^1) \cong \mathbb{Z}\)

Proof: We use the covering space \(\mathbb{R} \to S^1\) given by \(t \mapsto e^{2\pi i t}\).

Define the winding number map \(w: \pi_1(S^1, 1) \to \mathbb{Z}\) by lifting a loop \(\gamma\) to a path \(\tilde{\gamma}: [0,1] \to \mathbb{R}\) with \(\tilde{\gamma}(0) = 0\), then setting \(w([\gamma]) = \tilde{\gamma}(1)\).

Well-defined: If \(\gamma \simeq \delta\), the homotopy lifts to a homotopy in \(\mathbb{R}\) between lifts, so \(\tilde{\gamma}(1) = \tilde{\delta}(1)\).

Homomorphism: The lift of \(\gamma * \delta\) is the concatenation of the lift of \(\gamma\) (starting at 0) and the lift of \(\delta\) (starting at \(\tilde{\gamma}(1)\)). Thus \(w([\gamma * \delta]) = \tilde{\gamma}(1) + \tilde{\delta}(1) = w([\gamma]) + w([\delta])\).

Surjective: For any \(n \in \mathbb{Z}\), the loop \(\gamma_n(t) = e^{2\pi i n t}\) has winding number \(n\).

Injective: If \(w([\gamma]) = 0\), then \(\tilde{\gamma}\) is a loop in \(\mathbb{R}\). Since \(\mathbb{R}\) is simply connected, \(\tilde{\gamma} \simeq \text{const}\), so \(\gamma \simeq \text{const}\).

Notation Guide

  • \(X\): topological space
  • \(x_0\): basepoint in \(X\)
  • \(\pi_1(X, x_0)\): fundamental group
  • \([\gamma]\): homotopy class of path \(\gamma\)
  • \(S^1\): unit circle
  • \(\simeq\): homotopy equivalence
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Circle

def compute_winding_number(path, center=(0, 0)):
    """
    Compute the winding number of a closed path around a center point.
    Path should be an array of shape (N, 2) with the last point = first point.
    """
    # Translate to center
    translated = path - np.array(center)
    
    # Compute angles
    angles = np.arctan2(translated[:, 1], translated[:, 0])
    
    # Unwrap angles to handle branch cuts
    angles = np.unwrap(angles)
    
    # Winding number is total angle change divided by 2π
    winding = (angles[-1] - angles[0]) / (2 * np.pi)
    return round(winding)

Differential Geometry: Gaussian Curvature

Motivation

How curved is a surface? Unlike curves, which have a single curvature, surfaces curve differently in different directions. A saddle curves "up" in one direction and "down" in another. Gaussian curvature captures this intrinsic property—it can be computed by a two-dimensional creature living on the surface, without reference to the ambient space. The Gauss-Bonnet theorem connects this local curvature to global topology.

Definitions

Surface: A 2-dimensional manifold embedded in \(\mathbb{R}^3\), locally parameterized by \(\mathbf{r}(u,v)\).

First Fundamental Form: \(I = E\,du^2 + 2F\,du\,dv + G\,dv^2\) where \(E = \mathbf{r}_u \cdot \mathbf{r}_u\), \(F = \mathbf{r}_u \cdot \mathbf{r}_v\), \(G = \mathbf{r}_v \cdot \mathbf{r}_v\).

Second Fundamental Form: \(II = L\,du^2 + 2M\,du\,dv + N\,dv^2\) where \(L = \mathbf{r}_{uu} \cdot \mathbf{n}\), \(M = \mathbf{r}_{uv} \cdot \mathbf{n}\), \(N = \mathbf{r}_{vv} \cdot \mathbf{n}\), and \(\mathbf{n}\) is the unit normal.

Gaussian Curvature: \(K = \frac{LN - M^2}{EG - F^2}\)

Mean Curvature: \(H = \frac{EN + GL - 2FM}{2(EG - F^2)}\)

Theorem

Theorema Egregium (Gauss): Gaussian curvature is an intrinsic property of the surface—it depends only on the first fundamental form (the metric), not on how the surface is embedded in \(\mathbb{R}^3\).

Proof Sketch: The key insight is that \(K\) can be expressed using only the Christoffel symbols, which depend only on \(E, F, G\) and their derivatives. The Brioschi formula gives:

\[K = \frac{1}{(EG-F^2)^2}\left(\begin{vmatrix} -\frac{1}{2}E_{vv} + F_{uv} - \frac{1}{2}G_{uu} & \frac{1}{2}E_u & F_u - \frac{1}{2}E_v \\ F_v - \frac{1}{2}G_u & E & F \\ \frac{1}{2}G_v & F & G \end{vmatrix} - \begin{vmatrix} 0 & \frac{1}{2}E_v & \frac{1}{2}G_u \\ \frac{1}{2}E_v & E & F \\ \frac{1}{2}G_u & F & G \end{vmatrix}\right)\]

Since this expression involves only \(E, F, G\) and their derivatives, \(K\) is intrinsic.

Notation Guide

  • \(\mathbf{r}(u,v)\): parameterization of surface
  • \(E, F, G\): coefficients of first fundamental form
  • \(L, M, N\): coefficients of second fundamental form
  • \(K\): Gaussian curvature
  • \(H\): mean curvature
  • \(\mathbf{n}\): unit normal vector
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def gaussian_curvature_sphere(R):
    """Gaussian curvature of sphere of radius R is constant 1/R²"""
    return 1 / R**2

def gaussian_curvature_torus(R, r, u, v):
    """
    Torus parameterized as:
    x = (R + r*cos(v)) * cos(u)
    y = (R + r*cos(v)) * sin(u)  
    z = r * sin(v)
    where R > r is major radius, r is minor radius
    """
    return np.cos(v) / (r * (R + r * np.cos(v)))

def gaussian_curvature_saddle(a, b, x, y):
    """
    Hyperbolic paraboloid z = x²/a² - y²/b²
    K = -4/(a²b²(1 + 4x²/a⁴ + 4y²/b⁴)²)
    """
    denom = 1 + 4*x**2/a**4 + 4*y**2/b**4
    return -4 / (a**2 * b**2 * denom**2)

Harmonic Analysis: The Fourier Transform

Motivation

Can any function be decomposed into simple oscillations? This question, originating in the study of heat diffusion, led to one of mathematics' most powerful tools. The Fourier transform reveals the frequency content of signals, transforming differential equations into algebraic ones. It underlies modern signal processing, quantum mechanics, and data compression.

Definitions

Fourier Transform: For \(f \in L^1(\mathbb{R})\), \(\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} dx\)

Inverse Fourier Transform: \(f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\)

Schwartz Space \(\mathcal{S}(\mathbb{R})\): Space of rapidly decreasing smooth functions where \(\sup_{x} |x^\alpha D^\beta f(x)| < \infty\) for all \(\alpha, \beta\).

Plancherel's Theorem: The Fourier transform extends to an isometry on \(L^2(\mathbb{R})\): \(\|\hat{f}\|_{L^2} = \|f\|_{L^2}\)

Theorem

Fourier Inversion Theorem: If \(f \in L^1(\mathbb{R})\) and \(\hat{f} \in L^1(\mathbb{R})\), then:

\[f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\]

almost everywhere. If \(f\) is also continuous, equality holds everywhere.

Proof: Consider the Gaussian \(G_t(x) = \frac{1}{\sqrt{4\pi t}} e^{-x^2/(4t)}\) with \(\widehat{G_t}(\xi) = e^{-4\pi^2 t \xi^2}\).

Define \(f_t = f * G_t\). By properties of convolution, \(\widehat{f_t} = \hat{f} \cdot \widehat{G_t}\).

Since \(G_t\) is an approximate identity, \(f_t \to f\) in \(L^1\) as \(t \to 0\).

By the Fourier inversion formula for Gaussians (which follows from direct computation):

\[f_t(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{-4\pi^2 t \xi^2} e^{2\pi i x \xi} d\xi\]

As \(t \to 0\), the dominated convergence theorem applies (since \(\hat{f} \in L^1\)):

\[f(x) = \lim_{t \to 0} f_t(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\]

Notation Guide

  • \(\hat{f}(\xi)\): Fourier transform of \(f\)
  • \(\xi\): frequency variable
  • \(L^1(\mathbb{R})\): integrable functions
  • \(L^2(\mathbb{R})\): square-integrable functions
  • \(\mathcal{S}(\mathbb{R})\): Schwartz space
  • \(*\): convolution
import numpy as np
import matplotlib.pyplot as plt

def dft(x):
    """Discrete Fourier Transform"""
    N = len(x)
    n = np.arange(N)
    k = n.reshape((N, 1))
    M = np.exp(-2j * np.pi * k * n / N)
    return np.dot(M, x)

def fft(x):
    """Fast Fourier Transform (Cooley-Tukey)"""
    x = np.asarray(x, dtype=float)
    N = len(x)
    
    if N <= 1:
        return x
    elif N % 2 != 0:
        # Fall back to DFT for odd lengths
        return dft(x)
    
    X_even = fft(x[::2])
    X_odd = fft(x[1::2])
    factor = np.exp(-2j * np.pi * np.arange(N) / N)
    
    return np.concatenate([
        X_even + factor[:N//2] * X_odd,
        X_even + factor[N//2:] * X_odd
    ])

Convex Optimization: Gradient Descent and Convergence

Motivation

From training neural networks to portfolio optimization, finding the minimum of a function is a ubiquitous problem. When the function is convex, we have strong guarantees about finding global optima. Gradient descent, the workhorse of modern machine learning, iteratively follows the direction of steepest descent. Understanding its convergence properties is essential for practical applications.

Definitions

Convex Function: \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if for all \(x, y\) and \(\lambda \in [0,1]\):

\[f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)\]

L-smooth: \(f\) is L-smooth if \(\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|\) for all \(x, y\).

\(\mu\)-strongly Convex: \(f\) is \(\mu\)-strongly convex if:

\[f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2\]

Gradient Descent: \(x_{k+1} = x_k - \eta \nabla f(x_k)\)

Theorem

Convergence of Gradient Descent: Let \(f\) be L-smooth and convex, with minimizer \(x^*\). If \(\eta \leq \frac{1}{L}\), then:

\[f(x_k) - f(x^*) \leq \frac{\|x_0 - x^*\|^2}{2\eta k}\]

If \(f\) is also \(\mu\)-strongly convex, then:

\[\|x_k - x^*\|^2 \leq \left(1 - \frac{\mu}{L}\right)^k \|x_0 - x^*\|^2\]

Proof (convex case): By L-smoothness:

\[f(x_{k+1}) \leq f(x_k) + \nabla f(x_k)^T(x_{k+1}-x_k) + \frac{L}{2}\|x_{k+1}-x_k\|^2\]

Substituting \(x_{k+1} - x_k = -\eta \nabla f(x_k)\):

\[f(x_{k+1}) \leq f(x_k) - \eta\|\nabla f(x_k)\|^2 + \frac{L\eta^2}{2}\|\nabla f(x_k)\|^2\]

With \(\eta \leq 1/L\):

\[f(x_{k+1}) \leq f(x_k) - \frac{\eta}{2}\|\nabla f(x_k)\|^2\]

By convexity, \(f(x_k) - f(x^*) \leq \nabla f(x_k)^T(x_k - x^*)\). Combining and telescoping gives the result.

Notation Guide

  • \(f\): objective function
  • \(\nabla f\): gradient of \(f\)
  • \(L\): Lipschitz constant of gradient
  • \(\mu\): strong convexity parameter
  • \(\eta\): step size (learning rate)
  • \(\kappa = L/\mu\): condition number
import numpy as np
import matplotlib.pyplot as plt

def gradient_descent(f, grad_f, x0, eta, max_iter=1000, tol=1e-6):
    """
    Vanilla gradient descent.
    f: objective function
    grad_f: gradient function
    x0: initial point
    eta: step size
    """
    x = x0.copy()
    history = [x.copy()]
    values = [f(x)]
    
    for k in range(max_iter):
        gradient = grad_f(x)
        x = x - eta * gradient
        history.append(x.copy())
        values.append(f(x))
        
        if np.linalg.norm(gradient) < tol:
            break
    
    return x, np.array(history), np.array(values)

def heavy_ball(f, grad_f, x0, eta, beta, max_iter=1000, tol=1e-6):
    """
    Heavy ball (momentum) method: 
    x_{k+1} = x_k - eta*grad_f(x_k) + beta*(x_k - x_{k-1})
    """
    x = x0.copy()
    x_prev = x.copy()
    history = [x.copy()]
    values = [f(x)]
    
    for k in range(max_iter):
        gradient = grad_f(x)
        x_new = x - eta * gradient + beta * (x - x_prev)
        x_prev, x = x, x_new
        history.append(x.copy())
        values.append(f(x))
        
        if np.linalg.norm(gradient) < tol:
            break
    
    return x, np.array(history), np.array(values)

# Test on a quadratic: f(x,y) = 0.5*(ax² + by²) with a >> b (ill-conditioned)

    return 0.5 * (a * x[0]**2 + b * x[1]**2)

    return np.array([a * x[0], b * x[1]])

x0 = np.array([5.0, 5.0])

# Plot

Financial Mathematics: The Black-Scholes Model

Motivation

How much is an option worth? This question, seemingly narrow, led to a revolution in finance and the 1997 Nobel Prize in Economics. The Black-Scholes model provides a theoretical price for European options by modeling stock prices as geometric Brownian motion. The key insight is that options can be perfectly hedged, eliminating risk, which determines their fair price.

Definitions

Geometric Brownian Motion: \(dS_t = \mu S_t dt + \sigma S_t dW_t\) where \(S_t\) is the stock price, \(\mu\) is drift, \(\sigma\) is volatility, and \(W_t\) is Brownian motion.

European Call Option: Right to buy stock at strike price \(K\) at maturity \(T\). Payoff: \(\max(S_T - K, 0)\).

Risk-Neutral Measure: Probability measure \(\mathbb{Q}\) under which discounted asset prices are martingales.

Greeks: Sensitivities of option price to parameters—Delta (\(\partial V/\partial S\)), Gamma (\(\partial^2 V/\partial S^2\)), Theta (\(\partial V/\partial t\)), Vega (\(\partial V/\partial \sigma\)).

Theorem

Black-Scholes Formula: The price of a European call option is:

\[C(S, t) = S N(d_1) - K e^{-r(T-t)} N(d_2)\]

where:

\[d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}\]

\[d_2 = d_1 - \sigma\sqrt{T-t}\]

and \(N(x)\) is the standard normal CDF.

Proof Sketch: Under the risk-neutral measure \(\mathbb{Q}\), \(dS_t = rS_t dt + \sigma S_t dW_t^{\mathbb{Q}}\). By Itô's lemma, \(\ln(S_t)\) is normally distributed:

\[\ln(S_T) \sim \mathcal{N}\left(\ln(S) + (r - \sigma^2/2)(T-t), \sigma^2(T-t)\right)\]

The option price is the discounted expected payoff:

\[C = e^{-r(T-t)} \mathbb{E}^{\mathbb{Q}}[\max(S_T - K, 0)]\]

Computing this expectation by integrating over the log-normal distribution yields the formula.

Notation Guide

  • \(S\): current stock price
  • \(K\): strike price
  • \(T\): maturity time
  • \(r\): risk-free interest rate
  • \(\sigma\): volatility
  • \(N(x)\): standard normal CDF
  • \(d_1, d_2\): auxiliary variables
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

def black_scholes_call(S, K, T, r, sigma):
    """
    Black-Scholes price for European call option.
    S: current stock price
    K: strike price
    T: time to maturity (years)
    r: risk-free rate
    sigma: volatility
    """
    if T <= 0:
        return max(S - K, 0)
    
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return call_price

def black_scholes_put(S, K, T, r, sigma):
    """Black-Scholes price for European put option (put-call parity)."""
    call = black_scholes_call(S, K, T, r, sigma)
    return call + K * np.exp(-r * T) - S

def monte_carlo_option(S, K, T, r, sigma, n_sims=100000):
    """Monte Carlo simulation for European call option."""
    # Simulate stock prices at maturity under risk-neutral measure
    Z = np.random.standard_normal(n_sims)
    S_T = S * np.exp((r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    
    # Discounted expected payoff
    payoff = np.maximum(S_T - K, 0)
    price = np.exp(-r * T) * np.mean(payoff)
    
    # Standard error
    se = np.exp(-r * T) * np.std(payoff) / np.sqrt(n_sims)
    
    return price, se

Signal Processing: The Sampling Theorem

Motivation

How fast must we sample a continuous signal to perfectly reconstruct it? This question, answered by Claude Shannon and others, underlies all digital audio, images, and video. The Nyquist-Shannon sampling theorem establishes that a bandlimited signal can be perfectly recovered from samples taken at twice its maximum frequency—no information is lost in the digitization process.

Definitions

Bandlimited Signal: A signal \(f(t)\) is bandlimited with bandwidth \(B\) if \(\hat{f}(\xi) = 0\) for \(|\xi| > B\).

Sampling: The operation \(f[n] = f(nT_s)\) where \(T_s\) is the sampling period and \(f_s = 1/T_s\) is the sampling rate.

Nyquist Rate: \(f_N = 2B\), the minimum sampling rate for perfect reconstruction.

Sinc Function: \(\text{sinc}(x) = \frac{\sin(\pi x)}{\pi x}\)

Theorem

Nyquist-Shannon Sampling Theorem: Let \(f\) be a continuous signal bandlimited to \([-B, B]\). If \(f_s > 2B\), then:

\[f(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \cdot \text{sinc}\left(\frac{t - nT_s}{T_s}\right)\]

where the series converges uniformly.

Proof: Since \(\hat{f}\) is supported on \([-B, B]\) and \(f_s > 2B\), the copies of \(\hat{f}\) shifted by multiples of \(f_s\) don't overlap. The Fourier transform of the sampled signal is:

\[\widehat{f_s}(\xi) = f_s \sum_{n=-\infty}^{\infty} \hat{f}(\xi - nf_s)\]

To recover \(f\), apply an ideal lowpass filter (rectangular window) in frequency domain:

\[\hat{f}(\xi) = \widehat{f_s}(\xi) \cdot \frac{1}{f_s} \mathbf{1}_{[-B,B]}(\xi)\]

Taking the inverse Fourier transform:

\[f(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \cdot \text{sinc}\left(\frac{t - nT_s}{T_s}\right)\]

since the inverse Fourier transform of the rectangular window is the sinc function.

Notation Guide

  • \(f(t)\): continuous-time signal
  • \(f[n]\): discrete-time samples
  • \(T_s\): sampling period
  • \(f_s = 1/T_s\): sampling rate
  • \(B\): bandwidth
  • \(f_N = 2B\): Nyquist rate
  • \(\text{sinc}(x) = \sin(\pi x)/(\pi x)\)
import numpy as np
import matplotlib.pyplot as plt

def sinc_interp(x, s, t):
    """
    Sinc interpolation.
    x: sample values
    s: sample times
    t: interpolation times
    """
    T = s[1] - s[0]  # Sampling period
    return np.sum(x[:, None] * np.sinc((t[None, :] - s[:, None]) / T), axis=0)

def sample_signal(t, f, fs):
    """Sample continuous signal f at rate fs."""
    T = 1 / fs
    n = np.arange(int(np.min(t) / T), int(np.max(t) / T) + 1)
    s = n * T
    x = f(s)
    return s, x

The Four Color Theorem

Historical Context

In 1852, Francis Guthrie noticed that he could color any map of England's counties with just four colors, with no adjacent regions sharing the same color. He asked his brother Frederick, who was a student of Augustus De Morgan, if this was always true. De Morgan posed the problem to the mathematical community, and it became one of the most famous unsolved problems in mathematics.

The theorem resisted proof for over a century. In 1879, Alfred Kempe published a proof that was accepted for 11 years until Percy Heawood found a flaw in 1890. Heawood proved the five color theorem but couldn't extend it to four. Finally, in 1976, Kenneth Appel and Wolfgang Haken proved the theorem using a computer to check 1,936 unavoidable configurations. This was the first major theorem proved with extensive computer assistance, sparking debate about the nature of mathematical proof.

Definitions

Planar Graph: A graph that can be drawn on a plane without edge crossings.

Proper Coloring: Assignment of colors to vertices such that no adjacent vertices share the same color.

Chromatic Number \(\chi(G)\): The minimum number of colors needed for a proper coloring of graph \(G\).

Dual Graph: Given a map, its dual graph has a vertex for each region and edges connecting adjacent regions.

Theorem

Four Color Theorem: Every planar graph has chromatic number at most 4. Equivalently, any map can be colored with at most four colors such that no adjacent regions share the same color.

Key Lemma (Unavoidable Set): Every planar map contains at least one of a specific set of configurations.

Key Lemma (Reducibility): Each configuration in the unavoidable set is "reducible"—it cannot appear in a minimal counterexample.

Proof Approach (Appel-Haken):

  1. Show that every planar map contains one of 1,936 specific configurations (unavoidability).
  2. Show that each configuration is reducible—if a minimal counterexample exists, it cannot contain any of these configurations.
  3. These two facts together imply no counterexample exists.

Notation Guide

  • \(G = (V, E)\): graph with vertices \(V\) and edges \(E\)
  • \(\chi(G)\): chromatic number of \(G\)
  • \(\Delta(G)\): maximum degree of \(G\)
  • \(K_n\): complete graph on \(n\) vertices

    """Check if a coloring is valid (no adjacent vertices share color)."""
    for u in graph:

def greedy_color(graph, order=None):
    """
    Greedy graph coloring algorithm.
    Returns a coloring (not necessarily optimal).
    """
    if order is None:
        order = list(graph.keys())
    
    coloring = {}
    for v in order:
        # Find smallest color not used by neighbors
        used = {coloring.get(n) for n in graph[v] if n in coloring}
        color = 0
        while color in used:
            color += 1
        coloring[v] = color
    
    return coloring

Fermat's Last Theorem

Historical Context

Around 1637, Pierre de Fermat wrote in the margin of his copy of Diophantus's Arithmetica: "I have discovered a truly marvelous proof of this, which this margin is too narrow to contain." The "this" was the statement that the equation \(a^n + b^n = c^n\) has no solutions in positive integers for \(n > 2\).

For 358 years, the theorem resisted proof. Fermat himself proved the case \(n = 4\). Euler proved \(n = 3\), Dirichlet and Legendre proved \(n = 5\), and Lamé proved \(n = 7\). Kummer's work on ideal numbers handled many cases but not all. The final proof came in 1994 when Andrew Wiles, building on the work of many mathematicians and using sophisticated tools from algebraic geometry and number theory, finally proved the theorem.

Definitions

Fermat Equation: \(x^n + y^n = z^n\) for integers \(x, y, z, n\) with \(n \geq 3\).

Elliptic Curve: A smooth cubic curve of the form \(y^2 = x^3 + ax + b\).

Modular Form: A complex analytic function on the upper half-plane satisfying certain transformation properties under the modular group.

Taniyama-Shimura Conjecture: Every elliptic curve over \(\mathbb{Q}\) is modular (arises from a modular form).

Theorem

Fermat's Last Theorem: For any integer \(n > 2\), there are no positive integers \(a, b, c\) such that:

\[a^n + b^n = c^n\]

Proof Approach (Wiles):

  1. Suppose Fermat's equation has a solution for some prime \(p > 2\).
  2. Frey (1984) showed this would give an elliptic curve (the Frey curve) with very unusual properties.
  3. Ribet (1986) proved that such a curve cannot be modular (epsilon conjecture).
  4. Wiles (1994) proved the Taniyama-Shimura conjecture for semistable elliptic curves, showing all such curves are modular.
  5. Contradiction: the Frey curve exists but cannot be modular. Therefore, no solution exists.

Notation Guide

  • \(x, y, z\): integer variables in Fermat's equation
  • \(n\): exponent (\(n \geq 3\))
  • \(E_{a,b,c}\): Frey curve associated to potential solution
  • \(\Delta\): discriminant of elliptic curve
  • \(N\): conductor of elliptic curve
import numpy as np
import matplotlib.pyplot as plt

def check_fermat(n, max_val=100):
    """
    Check for counterexamples to Fermat's Last Theorem.
    Searches for a^n + b^n = c^n with a, b, c ≤ max_val.
    """
    solutions = []
    for a in range(1, max_val + 1):
        for b in range(a, max_val + 1):  # b >= a to avoid duplicates
            c_n = a**n + b**n
            c = round(c_n ** (1/n))
            
            # Check nearby integers (floating point issues)
            for c_test in range(max(c-2, 1), c+3):
                if c_test**n == c_n:
                    solutions.append((a, b, c_test))
    
    return solutions

def frey_curve(a, b, c, n):
    """
    Construct the Frey curve associated to a potential Fermat solution.
    E: y^2 = x(x - a^n)(x + b^n)
    """
    # The curve has the form y^2 = x^3 + Ax + B
    # Expanding: x(x - a^n)(x + b^n) = x^3 + (b^n - a^n)x^2 - a^n b^n x
    A = -a**n * b**n
    B = 0
    # Note: This is a simplified version for demonstration
    return A, B

The P vs NP Problem

Historical Context

The P vs NP problem, one of the seven Millennium Prize Problems, asks whether every problem whose solution can be quickly verified can also be quickly solved. It was first formulated by Stephen Cook in 1971 and independently by Leonid Levin. The problem has profound implications for cryptography, optimization, artificial intelligence, and our understanding of computation itself.

If P = NP, then problems like factoring large numbers, protein folding, and theorem proving would have efficient algorithms, revolutionizing mathematics and computer science. If P ≠ NP, as most mathematicians believe, then certain problems are inherently difficult, providing the foundation for modern cryptography.

Definitions

P (Polynomial time): Decision problems solvable by a deterministic Turing machine in time polynomial in the input size.

NP (Nondeterministic Polynomial time): Decision problems where a proposed solution can be verified in polynomial time.

NP-Complete: A problem in NP to which every problem in NP can be reduced in polynomial time. If any NP-complete problem is in P, then P = NP.

Polynomial Reduction: Problem A reduces to B if any instance of A can be transformed to an instance of B in polynomial time, preserving the answer.

Theorem

Cook-Levin Theorem: SAT (satisfiability of Boolean formulas) is NP-complete.

Proof Sketch:

  1. SAT is in NP: Given a truth assignment, verify it satisfies the formula in polynomial time.
  2. SAT is NP-hard: For any problem L in NP, there's a nondeterministic Turing machine M that decides L in polynomial time.
  3. Construct a Boolean formula that encodes: "M accepts input x in time p(|x|)."
  4. The formula is satisfiable iff M accepts x.
  5. This reduction shows any NP problem reduces to SAT.

Notation Guide

  • \(P\): class of polynomial-time solvable problems
  • \(NP\): class of polynomial-time verifiable problems
  • \(NPC\): class of NP-complete problems
  • \(SAT\): Boolean satisfiability problem
  • \(\leq_p\): polynomial-time reducibility
import itertools
import time

def sat_solver_naive(formula, variables):
    """
    Naive SAT solver: try all possible assignments.
    Returns (satisfiable, assignment) or (False, None).
    """
    n = len(variables)
    
    for assignment_bits in itertools.product([False, True], repeat=n):
        assignment = dict(zip(variables, assignment_bits))
        
        try:
            if eval(formula, {"__builtins__": {}}, assignment):
                return True, assignment
        except:
            pass
    
    return False, None

def sat_solver_dpll(clauses, assignment=None):
    """
    DPLL algorithm - a more efficient SAT solver.
    clauses: list of lists, where each inner list is a clause (disjunction of literals)
    assignment: current partial assignment
    """
    if assignment is None:
        assignment = {}
    
    # Simplify clauses based on current assignment
    new_clauses = []
    for clause in clauses:
        new_clause = []
        satisfied = False
        
        for lit in clause:
            var = lit.strip('~')
            if var in assignment:
                val = assignment[var] if not lit.startswith('~') else not assignment[var]
                if val:
                    satisfied = True
                    break
                # else: literal is false, skip it
            else:
                new_clause.append(lit)
        
        if not satisfied:
            if not new_clause:  # Empty clause - contradiction
                return False, None
            new_clauses.append(new_clause)
    
    # All clauses satisfied
    if not new_clauses:
        return True, assignment
    
    # Unit propagation
    for clause in new_clauses:
        if len(clause) == 1:
            lit = clause[0]
            var = lit.strip('~')
            val = not lit.startswith('~')
            return sat_solver_dpll(new_clauses, {**assignment, var: val})
    
    # Pure literal elimination (simplified)
    
    # Choose a variable and branch
    var = new_clauses[0][0].strip('~')
    
    # Try True
    result, assign = sat_solver_dpll(new_clauses, {**assignment, var: True})
    if result:
        return True, assign
    
    # Try False
    return sat_solver_dpll(new_clauses, {**assignment, var: False})

Emmy Noether: Symmetry and Conservation

Historical Context

Emmy Noether (1882-1935) was one of the most influential mathematicians of the 20th century, despite facing severe discrimination as a Jewish woman in Germany. David Hilbert and Felix Klein invited her to Göttingen in 1915, where she proved the theorem connecting symmetries to conservation laws—work that underlies modern theoretical physics.

Albert Einstein wrote of her: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began." Her work on abstract algebra revolutionized the field, and Noetherian rings remain fundamental in algebraic geometry and commutative algebra.

Definitions

Lagrangian: A function \(L(q, \dot{q}, t)\) where \(q\) represents generalized coordinates and \(\dot{q}\) their time derivatives.

Action: \(S = \int L\, dt\), the integral of the Lagrangian over time.

Symmetry: A transformation that leaves the action invariant.

Noether Charge: A conserved quantity associated with a continuous symmetry.

Theorem

Noether's Theorem: Every differentiable symmetry of the action of a physical system has a corresponding conservation law.

Mathematical Statement: If the Lagrangian is invariant under a continuous transformation \(q_i \to q_i + \epsilon \psi_i(q, \dot{q}, t)\), then:

\[Q = \sum_i \frac{\partial L}{\partial \dot{q}_i} \psi_i\]

is conserved: \(\frac{dQ}{dt} = 0\).

Proof Sketch:

  1. Consider a variation \(\delta q_i = \epsilon \psi_i\) with \(\epsilon\) infinitesimal.
  2. The change in Lagrangian is \(\delta L = \epsilon \sum_i \left(\frac{\partial L}{\partial q_i} \psi_i + \frac{\partial L}{\partial \dot{q}_i} \dot{\psi}_i\right)\).
  3. Using the Euler-Lagrange equations \(\frac{\partial L}{\partial q_i} = \frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i}\):
    4. \[\delta L = \epsilon \frac{d}{dt}\sum_i \frac{\partial L}{\partial \dot{q}_i} \psi_i = \epsilon \frac{dQ}{dt}\]
  4. If the action is invariant (\(\delta L = 0\)), then \(\frac{dQ}{dt} = 0\).

Notation Guide

  • \(L\): Lagrangian
  • \(q_i\): generalized coordinates
  • \(\dot{q}_i\): time derivatives of coordinates
  • \(p_i = \frac{\partial L}{\partial \dot{q}_i}\): conjugate momentum
  • \(Q\): Noether charge (conserved quantity)
  • \(\epsilon\): infinitesimal parameter
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

def simulate_noether_examples():
    """
    Demonstrate Noether's theorem with physical examples.
    """
    
    # Example 1: Free particle (translation symmetry -> momentum conservation)
    def free_particle(t, y):
        """y = [x, v]"""
        return [y[1], 0]  # dx/dt = v, dv/dt = 0
    
    # Example 2: Central force (rotation symmetry -> angular momentum conservation)
    def central_force(t, y):
        """y = [x, y, vx, vy]"""
        x, y_pos, vx, vy = y
        r = np.sqrt(x**2 + y_pos**2)
        # Inverse square law: F = -k/r^2
        k = 1.0
        ax = -k * x / r**3
        ay = -k * y_pos / r**3
        return [vx, vy, ax, ay]
    
    # Simulate free particle
    t_span = (0, 10)
    t_eval = np.linspace(0, 10, 1000)
    
    # Free particle: momentum should be conserved
    y0_free = [0, 5]  # x=0, v=5
    sol_free = solve_ivp(free_particle, t_span, y0_free, t_eval=t_eval, method='RK45')
    
    momentum = sol_free.y[1]  # v is constant
    
    # Central force: angular momentum should be conserved
    y0_central = [1, 0, 0, 1]  # x=1, y=0, vx=0, vy=1 (circular-ish orbit)
    sol_central = solve_ivp(central_force, t_span, y0_central, t_eval=t_eval, method='RK45')
    
    x, y_pos = sol_central.y[0], sol_central.y[1]
    vx, vy = sol_central.y[2], sol_central.y[3]
    
    # Angular momentum L = x*vy - y*vx
    angular_momentum = x * vy - y_pos * vx
    
    # Energy for central force
    r = np.sqrt(x**2 + y_pos**2)
    energy = 0.5 * (vx**2 + vy**2) - 1/r
    
    return sol_free, momentum, sol_central, angular_momentum, energy

📜 Math History

The Development of Abstract Algebra

The 19th and early 20th centuries witnessed a profound transformation in mathematics: the shift from studying specific objects to studying abstract structures. This revolution, now called abstract algebra, changed how mathematicians think about equations, symmetries, and number systems.

The story begins with the search for solutions to polynomial equations. The quadratic formula was known to ancient Babylonians, and cubic and quartic formulas were discovered in 16th century Italy. But the quintic resisted all attempts. In 1824, Niels Henrik Abel proved that no general formula exists for quintic equations using radicals. Évariste Galois, tragically killed in a duel at age 20, provided the deeper explanation: solvability depends on the structure of the equation's symmetry group.

Galois's insight was revolutionary. He didn't study the equation itself but its group of symmetries—the permutations of roots that preserve algebraic relations. This shift from objects to their transformation groups became a template for modern mathematics. Richard Dedekind and Leopold Kronecker developed the theory of fields and rings, while Camille Jordan and Felix Klein extended group theory to geometry.

The culmination came with Emmy Noether and her school at Göttingen. Noether's 1921 paper "Idealtheorie in Ringbereichen" established the foundation of modern commutative algebra. Her abstract approach—studying rings through their ideals, modules through their homomorphisms—became the standard methodology. Van der Waerden's 1930 textbook "Moderne Algebra" codified this new approach, influencing generations of mathematicians.

The impact extended far beyond algebra. Noether's theorem connected symmetries to conservation laws, becoming fundamental to theoretical physics. Group theory found applications in crystallography, chemistry, and particle physics. Category theory, developed by Eilenberg and Mac Lane in the 1940s, pushed abstraction even further, providing a unified language for all of mathematics.

Today, abstract algebra underlies modern cryptography (RSA relies on properties of finite groups), coding theory, and computer science. The shift from computation to structure, from specific examples to general theory, remains one of mathematics' most powerful methodological advances.

🎯 Problem Corner

IMO 2006 Problem 3

Determine the least real number \(M\) such that the inequality

\[|ab(a^2 - b^2) + bc(b^2 - c^2) + ca(c^2 - a^2)| \leq M(a^2 + b^2 + c^2)^2\]

holds for all real numbers \(a\), \(b\), and \(c\).

💡 Hint

First, factor the expression inside the absolute value. Notice that the expression is cyclic and vanishes when any two variables are equal. This suggests a factorization involving \((a-b)(b-c)(c-a)\). After factoring, use symmetry to assume an ordering of variables and apply calculus or inequalities to find the maximum.

✅ Solution

Step 1: Factor the expression.

Let \(f(a,b,c) = ab(a^2 - b^2) + bc(b^2 - c^2) + ca(c^2 - a^2)\).

Notice that \(f(a,a,c) = a^2(a^2-a^2) + ac(a^2-c^2) + ca(c^2-a^2) = 0\).

Similarly, \(f(a,b,b) = f(a,b,a) = 0\). So \((a-b)(b-c)(c-a)\) divides \(f\).

By degree comparison, \(f(a,b,c) = k(a-b)(b-c)(c-a)(a+b+c)\) for some constant \(k\).

Checking with \(a=0, b=1, c=2\): \(f = 0 + 2(-3) + 0 = -6\) and \((-1)(-1)(2)(3) = 6\), so \(k = -1\).

Thus: \(f(a,b,c) = -(a-b)(b-c)(c-a)(a+b+c)\)

Step 2: By homogeneity, we can assume \(a^2 + b^2 + c^2 = 1\).

We need to maximize \(|(a-b)(b-c)(c-a)(a+b+c)|\) subject to \(a^2 + b^2 + c^2 = 1\).

Step 3: Use symmetry. Assume \(a \geq b \geq c\). By Lagrange multipliers or direct analysis, the maximum occurs when the variables are in arithmetic progression.

Let \(b = t\), \(a = t + d\), \(c = t - d\) for some \(d > 0\).

Then: \(a^2 + b^2 + c^2 = (t+d)^2 + t^2 + (t-d)^2 = 3t^2 + 2d^2 = 1\)

And: \((a-b)(b-c)(c-a)(a+b+c) = d \cdot d \cdot (-2d) \cdot 3t = -6td^3\)

Step 4: Maximize \(|6td^3|\) subject to \(3t^2 + 2d^2 = 1\).

Let \(u = t^2\) and \(v = d^2\), so \(3u + 2v = 1\).

We maximize \(36 u v^3\) subject to \(3u + 2v = 1\).

From the constraint: \(u = (1-2v)/3\).

Maximize: \(g(v) = 36 \cdot \frac{1-2v}{3} \cdot v^3 = 12v^3(1-2v)\) for \(0 \leq v \leq 1/2\).

Step 5: Find critical points.

\(g'(v) = 12[3v^2(1-2v) + v^3(-2)] = 12v^2[3(1-2v) - 2v] = 12v^2[3 - 8v] = 0\)

So \(v = 0\) or \(v = 3/8\).

At \(v = 3/8\): \(u = (1 - 3/4)/3 = 1/12\).

Maximum value: \(g(3/8) = 12 \cdot (27/512) \cdot (1/4) = 81/512\).

Step 6: Therefore, \(|f| \leq \sqrt{81/512} = 9/(16\sqrt{2}) = 9\sqrt{2}/32\).

So \(M = \frac{9\sqrt{2}}{32}\).

Verification: This is achieved when \(t^2 = 1/12\) and \(d^2 = 3/8\), i.e., \(t = 1/(2\sqrt{3})\) and \(d = \sqrt{3/8}\).

The values are \(a = \frac{1}{2\sqrt{3}} + \sqrt{\frac{3}{8}}\), \(b = \frac{1}{2\sqrt{3}}\), \(c = \frac{1}{2\sqrt{3}} - \sqrt{\frac{3}{8}}\).

The Mandelbrot Set

The Mandelbrot set is perhaps the most famous fractal in mathematics. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. The boundary of this set exhibits infinite complexity—zooming in reveals ever more intricate patterns that are self-similar but never exactly repeat.

The connection to complex dynamics and chaos theory makes the Mandelbrot set more than just a pretty picture. It demonstrates how simple iterative rules can generate astonishing complexity, a theme that recurs throughout mathematics from cellular automata to differential equations.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for point c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring: interpolate between iterations
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100):
    """Compute the Mandelbrot set over a rectangular region."""
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[abs(Z) <= 2] = max_iter
    return M
