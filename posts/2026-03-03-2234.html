🔬 Pure Math Deep-Dives

1. Symplectic Geometry: The Geometry of Classical Mechanics

Motivation

Symplectic geometry provides the mathematical framework for Hamiltonian mechanics. Unlike Riemannian geometry, which measures distances and angles, symplectic geometry measures areas in phase space. This seemingly simple structure has profound consequences, including the conservation of phase space volume (Liouville's theorem) and the existence of periodic orbits in mechanical systems.

Definitions

  • Symplectic Vector Space: A pair \( (V, \omega) \) where \( V \) is a vector space and \( \omega: V \times V \to \mathbb{R} \) is a non-degenerate skew-symmetric bilinear form.
  • Symplectic Manifold: A smooth manifold \( M \) equipped with a closed, non-degenerate 2-form \( \omega \in \Omega^2(M) \).
  • Hamiltonian Vector Field: For \( H: M \to \mathbb{R} \), the vector field \( X_H \) defined by \( \omega(X_H, \cdot) = dH \).
  • Symplectomorphism: A diffeomorphism \( \phi: M \to M \) preserving the symplectic form: \( \phi^*\omega = \omega \).

Theorem: Darboux's Theorem

Theorem (Darboux, 1882): Let \( (M, \omega) \) be a symplectic manifold of dimension \( 2n \). For any point \( p \in M \), there exist local coordinates \( (q_1, \ldots, q_n, p_1, \ldots, p_n) \) such that: \[ \omega = \sum_{i=1}^n dq_i \wedge dp_i \]

Proof Sketch

Step 1 (Linear Algebra): At any point, the symplectic form can be put in standard form by a linear change of coordinates (Gram-Schmidt for symplectic forms).

Step 2 (Moser's Trick): Consider the family of forms \( \omega_t = (1-t)\omega_0 + t\omega \), where \( \omega_0 \) is the standard form. Since \( \omega \) is closed and non-degenerate, these remain symplectic for small neighborhoods.

Step 3 (Poincaré Lemma): Since \( d\omega = d\omega_0 = 0 \), we have \( \omega - \omega_0 = d\alpha \) for some 1-form \( \alpha \) locally.

Step 4 (Flow Construction): Define a vector field \( X_t \) by \( \iota_{X_t}\omega_t = -\alpha \). The flow \( \phi_t \) of \( X_t \) satisfies \( \phi_t^*\omega_t = \omega_0 \), giving the required coordinate change at \( t = 1 \). ∎

Notation Guide

  • \( \omega \): Symplectic form (skew-symmetric, non-degenerate, closed)
  • \( (q, p) \): Canonical coordinates (position and momentum)
  • \( X_H \): Hamiltonian vector field generated by \( H \)
  • \( \iota_X \omega \): Interior product (contraction of \( \omega \) with \( X \))
  • \( \phi^* \omega \): Pullback of \( \omega \) by \( \phi \)
  • \( \wedge \): Wedge product of differential forms

import numpy as np
from typing import Callable, Tuple
import matplotlib.pyplot as plt
from scipy.integrate import odeint

class SymplecticForm:
    """Represents the standard symplectic form on R^{2n}."""
    
    def __init__(self, n: int):
        self.n = n
        # Standard symplectic matrix J = [[0, I], [-I, 0]]
        self.J = np.block([
            [np.zeros((n, n)), np.eye(n)],
            [-np.eye(n), np.zeros((n, n))]
        ])
    
    def apply(self, v: np.ndarray, w: np.ndarray) -> float:
        """Evaluate omega(v, w) = v^T J w"""
        return float(v.T @ self.J @ w)
    
    def hamiltonian_vector_field(self, H: Callable[[np.ndarray], float], 
                                   x: np.ndarray, eps: float = 1e-6) -> np.ndarray:
        """Compute X_H at point x. X_H = J^{-1} ∇H = -J ∇H"""
        grad = np.zeros(2 * self.n)
        for i in range(2 * self.n):
            x_plus = x.copy()
            x_minus = x.copy()
            x_plus[i] += eps
            x_minus[i] -= eps
            grad[i] = (H(x_plus) - H(x_minus)) / (2 * eps)
        return -self.J @ grad

# Example: Harmonic Oscillator
# H(q, p) = (p^2 + q^2) / 2
def harmonic_oscillator_hamiltonian(x: np.ndarray) -> float:
    q, p = x[0], x[1]
    return (p**2 + q**2) / 2

# Set up symplectic geometry
omega = SymplecticForm(n=1)

# Verify symplectic property: omega is skew-symmetric
v = np.array([1.0, 0.0])
w = np.array([0.0, 1.0])
print(f"omega(v, w) = {omega.apply(v, w)}")  # Should be 1
print(f"omega(w, v) = {omega.apply(w, v)}")  # Should be -1

# Compute Hamiltonian vector field at a point
x0 = np.array([1.0, 0.0])
X_H = omega.hamiltonian_vector_field(harmonic_oscillator_hamiltonian, x0)
print(f"X_H at (1, 0): {X_H}")

# Integrate Hamilton's equations
def hamiltonian_flow(x, t):
    return omega.hamiltonian_vector_field(harmonic_oscillator_hamiltonian, x)

t = np.linspace(0, 4*np.pi, 1000)
solution = odeint(hamiltonian_flow, [1.0, 0.0], t)

# Plot phase portrait
plt.figure(figsize=(10, 8))
plt.plot(solution[:, 0], solution[:, 1], 'b-', label='Trajectory', linewidth=2)

2. Algebraic Topology: Cohomology and the Cup Product

Motivation

Homology groups tell us about the "holes" in a space, but they don't capture how these holes interact. Cohomology not only provides a dual perspective but also carries a natural product structure—the cup product—that encodes the intersection theory of cycles.

Definitions

  • Singular Cochain: A linear functional on singular chains: \( C^n(X; R) = \text{Hom}(C_n(X), R) \).
  • Coboundary: \( \delta: C^n \to C^{n+1} \) defined by \( (\delta\phi)(\sigma) = \phi(\partial\sigma) \).
  • Cohomology Group: \( H^n(X; R) = \ker(\delta) / \text{im}(\delta) \).
  • Cup Product: For \( \alpha \in C^k \) and \( \beta \in C^l \), define \( (\alpha \smile \beta)(\sigma) = \alpha(\sigma|_{[v_0, \ldots, v_k]}) \cdot \beta(\sigma|_{[v_k, \ldots, v_{k+l}]}) \).

Theorem: Cup Product Structure of Projective Spaces

Theorem: The cohomology ring of complex projective space is: \[ H^*(\mathbb{C}P^n; \mathbb{Z}) \cong \mathbb{Z}[\alpha]/(\alpha^{n+1}) \] where \( \alpha \in H^2(\mathbb{C}P^n; \mathbb{Z}) \) is a generator.

Python Code

import numpy as np
from itertools import combinations
from typing import List, Set, Dict

class SimplicialComplex:
    """A simplicial complex represented as a list of simplices."""
    
    def __init__(self, simplices: List[Set[int]]):
        self.simplices = set()
        for simplex in simplices:
            simplex = frozenset(simplex)
            for r in range(len(simplex) + 1):
                for face in combinations(simplex, r):
                    self.simplices.add(frozenset(face))
        
        self.by_dim = {}
        for simplex in self.simplices:
            dim = len(simplex) - 1
            if dim not in self.by_dim:
                self.by_dim[dim] = set()
            self.by_dim[dim].add(simplex)
    
    def n_simplices(self, n: int) -> Set[frozenset]:
        return self.by_dim.get(n, set())

class CohomologyCalculator:
    """Compute simplicial cohomology and cup products with Z/2Z coefficients."""
    
    def __init__(self, complex: SimplicialComplex):
        self.complex = complex
    
    def cup_product(self, alpha: Dict[frozenset, int], beta: Dict[frozenset, int],
                    k: int, l: int) -> Dict[frozenset, int]:
        """Compute the cup product alpha ∪ beta."""
        result = {}
        for simplex in self.complex.n_simplices(k + l):
            vertices = sorted(simplex)
            front = frozenset(vertices[:k+1])
            back = frozenset(vertices[k:])
            
            if front in alpha and back in beta:
                result[simplex] = (alpha[front] * beta[back]) % 2
        return result

3. Operator Algebras: The Mathematics of Quantum Mechanics

Motivation

Operator algebras provide the rigorous mathematical foundation for quantum mechanics. While physicists often work with formal expressions involving operators, the theory of C*-algebras and von Neumann algebras puts these manipulations on solid ground.

Definitions

  • C*-Algebra: A Banach algebra \( A \) over \( \mathbb{C} \) with an involution \( *: A \to A \) satisfying \( \|a^*a\| = \|a\|^2 \).
  • Spectrum: For \( a \in A \), \( \sigma(a) = \{\lambda \in \mathbb{C} : a - \lambda I \text{ is not invertible}\} \).
  • State: A positive linear functional \( \phi: A \to \mathbb{C} \) with \( \|\phi\| = 1 \).

Theorem: Gelfand-Naimark Theorem

Theorem (Gelfand-Naimark, 1943): Every C*-algebra is isometrically *-isomorphic to a norm-closed *-subalgebra of \( \mathcal{B}(\mathcal{H}) \) for some Hilbert space \( \mathcal{H} \).

Python Code

import numpy as np
from scipy.linalg import eigvals

class CStarAlgebraElement:
    """Represents an element of M_n(C) - n×n complex matrices."""
    
    def __init__(self, matrix: np.ndarray):
        self.matrix = np.array(matrix, dtype=complex)
        self.n = self.matrix.shape[0]
    
    def __add__(self, other):
        return CStarAlgebraElement(self.matrix + other.matrix)
    
    def __mul__(self, other):
        return CStarAlgebraElement(self.matrix @ other.matrix)
    
    def star(self):
        """Involution: conjugate transpose"""
        return CStarAlgebraElement(self.matrix.conj().T)
    
    def norm(self) -> float:
        """C*-norm: operator norm (largest singular value)"""
        return np.linalg.norm(self.matrix, ord=2)
    
    def spectrum(self) -> np.ndarray:
        """Spectrum: eigenvalues of the matrix"""
        return eigvals(self.matrix)
    
    def is_self_adjoint(self, tol: float = 1e-10) -> bool:
        """Check if a = a*"""
        return np.allclose(self.matrix, self.matrix.conj().T, atol=tol)

class State:
    """A state on M_n(C) is given by a density matrix ρ."""
    
    def __init__(self, density_matrix: np.ndarray):
        self.rho = np.array(density_matrix, dtype=complex)
    
    def evaluate(self, a: CStarAlgebraElement) -> complex:
        """φ(a) = tr(ρa)"""
        return np.trace(self.rho @ a.matrix)
    
    def expectation(self, observable: CStarAlgebraElement) -> float:
        assert observable.is_self_adjoint()
        return float(np.real(self.evaluate(observable)))

# Example: Quantum mechanics of a spin-1/2 particle
Pauli_X = CStarAlgebraElement(np.array([[0, 1], [1, 0]]))
Pauli_Y = CStarAlgebraElement(np.array([[0, -1j], [1j, 0]]))
Pauli_Z = CStarAlgebraElement(np.array([[1, 0], [0, -1]]))

print("Pauli matrices (observables for spin-1/2):")
print(f"σ_x is self-adjoint: {Pauli_X.is_self_adjoint()}")
print(f"σ_y is self-adjoint: {Pauli_Y.is_self_adjoint()}")
print(f"σ_z is self-adjoint: {Pauli_Z.is_self_adjoint()}")

# Verify C*-identity: ||a*a|| = ||a||^2
for name, pauli in [("X", Pauli_X), ("Y", Pauli_Y), ("Z", Pauli_Z)]:
    lhs = (pauli.star() * pauli).norm()
    rhs = pauli.norm()**2
    print(f"C*-identity for σ_{name}: {np.isclose(lhs, rhs)}")

# Spectrum of Pauli matrices
print(f"\nSpectrum of σ_x: {Pauli_X.spectrum()}")
print(f"Spectrum of σ_z: {Pauli_Z.spectrum()}")

# Create state |0⟩⟨0|
psi_0 = np.array([[1], [0]])
rho_0 = psi_0 @ psi_0.conj().T
state_0 = State(rho_0)

print(f"\nState |0⟩: ⟨σ_z⟩ = {state_0.expectation(Pauli_Z):.3f}")
print(f"State |0⟩: ⟨σ_x⟩ = {state_0.expectation(Pauli_X):.3f}")

1. Fluid Dynamics: The Navier-Stokes Equations

Real-World Motivation

The Navier-Stokes equations describe the motion of viscous fluids, from blood flow in arteries to atmospheric circulation. Fundamental questions about their solutions remain unanswered—most notably whether smooth solutions always exist in three dimensions.

Definitions

  • Velocity Field: \( \mathbf{u}(\mathbf{x}, t) \in \mathbb{R}^3 \) describes the fluid velocity.
  • Pressure: \( p(\mathbf{x}, t) \in \mathbb{R} \) is the scalar pressure field.
  • Viscosity: \( \nu > 0 \) measures the fluid's resistance to shear.
  • Reynolds Number: \( \text{Re} = \frac{UL}{\nu} \), ratio of inertial to viscous forces.

Theorem: Energy Equality

Theorem: Let \( \mathbf{u} \) be a smooth solution of the Navier-Stokes equations on \( \mathbb{R}^3 \). Then: \[ \frac{d}{dt} \int_{\mathbb{R}^3} \frac{1}{2}|\mathbf{u}|^2 \, d\mathbf{x} = -\nu \int_{\mathbb{R}^3} |\nabla \mathbf{u}|^2 \, d\mathbf{x} \]

Python Code

import numpy as np
import matplotlib.pyplot as plt

class NavierStokes2D:
    """2D incompressible Navier-Stokes solver using projection method."""
    
    def __init__(self, N: int, L: float = 1.0, nu: float = 0.01):
        self.N = N
        self.L = L
        self.nu = nu
        self.dx = L / N
        self.dt = 0.001
        
        self.x = np.linspace(0, L, N)
        self.y = np.linspace(0, L, N)
        self.X, self.Y = np.meshgrid(self.x, self.y)
        
        self.u = np.zeros((N, N))
        self.v = np.zeros((N, N))
        self.p = np.zeros((N, N))
    
    def divergence(self, u: np.ndarray, v: np.ndarray) -> np.ndarray:
        du_dx = np.gradient(u, self.dx, axis=1)
        dv_dy = np.gradient(v, self.dx, axis=0)
        return du_dx + dv_dy
    
    def laplacian(self, f: np.ndarray) -> np.ndarray:
        return (np.roll(f, 1, axis=0) + np.roll(f, -1, axis=0) +
                np.roll(f, 1, axis=1) + np.roll(f, -1, axis=1) - 4*f) / self.dx**2
    
    def projection_step(self):
        div = self.divergence(self.u, self.v)
        phi = np.zeros_like(self.p)
        for _ in range(50):
            phi = (np.roll(phi, 1, axis=0) + np.roll(phi, -1, axis=0) +
                   np.roll(phi, 1, axis=1) + np.roll(phi, -1, axis=1) -
                   self.dx**2 * div) / 4
        
        dphi_dx = np.gradient(phi, self.dx, axis=1)
        dphi_dy = np.gradient(phi, self.dx, axis=0)
        self.u -= dphi_dx
        self.v -= dphi_dy
    
    def step(self):
        u_old, v_old = self.u.copy(), self.v.copy()
        
        lap_u = self.laplacian(u_old)
        lap_v = self.laplacian(v_old)
        
        self.u = u_old + self.dt * self.nu * lap_u
        self.v = v_old + self.dt * self.nu * lap_v
        
        self.u[0, :] = self.u[-1, :] = self.u[:, 0] = self.u[:, -1] = 0
        self.v[0, :] = self.v[-1, :] = self.v[:, 0] = self.v[:, -1] = 0
        
        self.projection_step()
    
    def vorticity(self) -> np.ndarray:
        dv_dx = np.gradient(self.v, self.dx, axis=1)
        du_dy = np.gradient(self.u, self.dx, axis=0)
        return dv_dx - du_dy
    
    def kinetic_energy(self) -> float:
        return 0.5 * np.sum(self.u**2 + self.v**2) * self.dx**2

2. Compressed Sensing: Sparse Recovery

Real-World Motivation

Compressed sensing revolutionized signal processing by showing that sparse signals can be recovered from far fewer measurements than the Nyquist-Shannon theorem would suggest. This has applications in MRI imaging, single-pixel cameras, and analog-to-information conversion.

Definitions

  • Sparse Signal: A signal \( \mathbf{x} \in \mathbb{R}^n \) with at most \( s \) non-zero entries.
  • Measurement Matrix: \( \mathbf{A} \in \mathbb{R}^{m \times n} \) with \( m \ll n \).
  • Restricted Isometry Property (RIP): \( \mathbf{A} \) satisfies RIP of order \( s \) if there exists \( \delta_s \in (0,1) \) such that: \[ (1-\delta_s)\|\mathbf{x}\|_2^2 \leq \|\mathbf{Ax}\|_2^2 \leq (1+\delta_s)\|\mathbf{x}\|_2^2 \] for all \( s \)-sparse \( \mathbf{x} \).

Theorem: Exact Recovery via Basis Pursuit

Theorem (Candès-Tao): If \( \mathbf{A} \) satisfies RIP of order \( 2s \) with \( \delta_{2s} < \sqrt{2} - 1 \), then for any \( s \)-sparse \( \mathbf{x} \), the solution \( \mathbf{x}^* \) of basis pursuit equals \( \mathbf{x} \).

Python Code

import numpy as np
from scipy.optimize import minimize

def generate_measurement_matrix(m: int, n: int) -> np.ndarray:
    """Generate a random Gaussian measurement matrix."""
    return np.random.randn(m, n) / np.sqrt(m)

def basis_pursuit(A: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Solve basis pursuit: minimize ||x||_1 subject to Ax = b."""
    n = A.shape[1]
    c = np.ones(2 * n)
    A_eq = np.hstack([A, -A])
    bounds = [(0, None) for _ in range(2 * n)]
    
    result = minimize(
        lambda x: np.dot(c, x),
        x0=np.ones(2 * n) / n,
        method='highs',
        constraints={'type': 'eq', 'fun': lambda x: A_eq @ x - b},
        bounds=bounds
    )
    
    x_split = result.x
    return x_split[:n] - x_split[n:]

def iterative_soft_thresholding(A: np.ndarray, b: np.ndarray,
                                 lambda_: float = 0.1,
                                 max_iter: int = 1000) -> np.ndarray:
    """Solve: minimize ||Ax - b||^2 + lambda * ||x||_1 using ISTA."""
    m, n = A.shape
    L = 2 * np.linalg.norm(A, ord=2)**2
    step_size = 1 / L
    
    x = np.zeros(n)
    for _ in range(max_iter):
        x_old = x.copy()
        grad = 2 * A.T @ (A @ x - b)
        y = x - step_size * grad
        x = np.sign(y) * np.maximum(np.abs(y) - lambda_ * step_size, 0)
        if np.linalg.norm(x - x_old) < 1e-6:
            break
    return x

# Example: Sparse signal recovery

m = 64
s = 10

support = np.random.choice(n, s, replace=False)
x_true[support] = np.random.randn(s) * 10

A = generate_measurement_matrix(m, n)
b = A @ x_true

x_bp = basis_pursuit(A, b)
x_ista = iterative_soft_thresholding(A, b, lambda_=0.01, max_iter=5000)

error_bp = np.linalg.norm(x_bp - x_true) / np.linalg.norm(x_true)
error_ista = np.linalg.norm(x_ista - x_true) / np.linalg.norm(x_true)

3. Portfolio Theory: Mean-Variance Optimization

Real-World Motivation

Modern Portfolio Theory, developed by Harry Markowitz in 1952, provides a mathematical framework for constructing investment portfolios that optimize the trade-off between expected return and risk.

Definitions

  • Portfolio: A vector \( \mathbf{w} \in \mathbb{R}^n \) where \( w_i \) is the weight of asset \( i \), with \( \sum_i w_i = 1 \).
  • Expected Return: \( \mu_p = \mathbf{w}^T \boldsymbol{\mu} \).
  • Portfolio Variance: \( \sigma_p^2 = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w} \).
  • Sharpe Ratio: \( S = \frac{\mu_p - r_f}{\sigma_p} \).

Theorem: Two-Fund Theorem

Theorem: Any portfolio on the efficient frontier can be constructed as a linear combination of any two distinct efficient portfolios.

Python Code

import numpy as np
from scipy.optimize import minimize

class PortfolioOptimizer:
    """Mean-variance portfolio optimization."""
    
    def __init__(self, returns: np.ndarray):
        self.returns = returns
        self.n_assets = returns.shape[1]
        self.mu = np.mean(returns, axis=0) * 12  # Annualize
        self.Sigma = np.cov(returns.T) * 12
    
    def portfolio_return(self, weights: np.ndarray) -> float:
        return float(np.dot(weights, self.mu))
    
    def portfolio_volatility(self, weights: np.ndarray) -> float:
        return np.sqrt(weights.T @ self.Sigma @ weights)
    
    def sharpe_ratio(self, weights: np.ndarray, risk_free_rate: float = 0.02) -> float:
        ret = self.portfolio_return(weights)
        vol = self.portfolio_volatility(weights)
        return (ret - risk_free_rate) / vol if vol > 1e-10 else -np.inf
    
    def min_variance_portfolio(self) -> np.ndarray:
        n = self.n_assets
        result = minimize(
            lambda w: self.portfolio_volatility(w)**2,
            np.ones(n)/n, method='SLSQP',
            bounds=[(0, 1) for _ in range(n)],
            constraints={'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        )
        return result.x
    
    def max_sharpe_portfolio(self, risk_free_rate: float = 0.02) -> np.ndarray:
        n = self.n_assets
        result = minimize(
            lambda w: -self.sharpe_ratio(w, risk_free_rate),
            np.ones(n)/n, method='SLSQP',
            bounds=[(0, 1) for _ in range(n)],
            constraints={'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        )
        return result.x

1. Hilbert's Tenth Problem: The Undecidability of Diophantine Equations

Historical Context

In 1900, David Hilbert presented 23 problems that would shape mathematics in the 20th century. The tenth asked for an algorithm to determine whether a given Diophantine equation has integer solutions. Seventy years later, Yuri Matiyasevich proved that no such algorithm exists.

Definitions

  • Diophantine Equation: A polynomial equation \( P(x_1, \ldots, x_n) = 0 \) where we seek integer solutions.
  • Diophantine Set: A set \( S \subseteq \mathbb{N} \) is Diophantine if there exists a polynomial \( P \) such that \( a \in S \iff \exists x_1, \ldots, x_n : P(a, x_1, \ldots, x_n) = 0 \).
  • Recursively Enumerable (r.e.): A set that can be listed by an algorithm.

Theorem: Matiyasevich's Theorem (DPRM Theorem)

Theorem (Matiyasevich, 1970): Every recursively enumerable set is Diophantine. Consequently, there is no algorithm to decide whether an arbitrary Diophantine equation has integer solutions.

from typing import Tuple, Optional
import numpy as np

def solve_diophantine_linear(a: int, b: int, c: int) -> Optional[Tuple[int, int]]:
    """Solve linear Diophantine equation: ax + by = c."""
    def extended_gcd(a: int, b: int) -> Tuple[int, int, int]:
        if b == 0:
            return (a, 1, 0)
        g, x1, y1 = extended_gcd(b, a % b)
        x = y1
        y = x1 - (a // b) * y1
        return (g, x, y)
    
    g, x0, y0 = extended_gcd(a, b)
    
    if c % g != 0:
        return None
    
    scale = c // g
    return (x0 * scale, y0 * scale)

def pell_solutions(D: int, n_solutions: int = 5) -> list:
    """Find solutions to Pell's equation: x^2 - Dy^2 = 1."""
    if int(np.sqrt(D))**2 == D:
        return []
    
    sqrt_D = np.sqrt(D)
    m, d, a = 0, 1, int(sqrt_D)
    
    p_prev, p_curr = 1, a
    q_prev, q_curr = 0, 1
    
    solutions = []
    
    while len(solutions) < n_solutions:
        if p_curr**2 - D * q_curr**2 == 1:
            solutions.append((p_curr, q_curr))
        
        m = d * a - m
        d = (D - m * m) // d
        a = int((sqrt_D + m) // d)
        
        p_prev, p_curr = p_curr, a * p_curr + p_prev
        q_prev, q_curr = q_curr, a * q_curr + q_prev
    
    return solutions

2. Mihăilescu's Theorem (Catalan's Conjecture)

Historical Context

In 1844, Eugène Catalan conjectured that 8 and 9 are the only consecutive perfect powers. This deceptively simple statement resisted proof for over 150 years until Preda Mihăilescu proved it in 2002.

Definitions

  • Perfect Power: A positive integer of the form \( x^n \) where \( x > 0 \) and \( n > 1 \).
  • Wieferich Pair: Primes \( p, q \) such that \( p^{q-1} \equiv 1 \pmod{q^2} \) and \( q^{p-1} \equiv 1 \pmod{p^2} \).

Theorem: Mihăilescu's Theorem

Theorem (Mihăilescu, 2002): The only solution to \[ x^p - y^q = 1 \] in integers \( x, y > 0 \) and primes \( p, q > 1 \) is \( x = 3, p = 2, y = 2, q = 3 \).

Python Code

import numpy as np
from typing import List, Tuple

def is_perfect_power(n: int) -> Tuple[bool, int, int]:
    """Check if n is a perfect power. Returns (is_power, base, exponent)."""
    if n < 2:
        return (False, 0, 0)
    
    max_exp = int(np.log2(n)) + 1
    for exp in range(2, max_exp + 1):
        base = round(n ** (1/exp))
        for b in [base - 1, base, base + 1]:
            if b > 0 and b ** exp == n:
                return (True, b, exp)
    return (False, 0, 0)

def find_consecutive_powers(limit: int = 10000) -> List[Tuple[int, int, int, int, int]]:
    """Find consecutive perfect powers."""
    powers = set()
    power_info = {}
    
    for base in range(2, int(np.sqrt(limit)) + 1):
        power = base * base
        exp = 2
        while power <= limit:
            if power not in powers:
                powers.add(power)
                power_info[power] = (base, exp)
            power *= base
            exp += 1
    
    consecutive = []
    sorted_powers = sorted(powers)
    
    for i in range(len(sorted_powers) - 1):
        if sorted_powers[i+1] - sorted_powers[i] == 1:
            y, q = power_info[sorted_powers[i]]
            x, p = power_info[sorted_powers[i+1]]
            consecutive.append((x, p, y, q, sorted_powers[i+1]))
    
    return consecutive

3. The Banach-Tarski Paradox

Historical Context

In 1924, Stefan Banach and Alfred Tarski proved a theorem that seems to defy intuition: a solid ball in 3-dimensional space can be decomposed into finitely many pieces and reassembled into two identical copies of the original ball.

Definitions

  • Isometry: A distance-preserving transformation of Euclidean space.
  • Equidecomposable: Two sets \( A \) and \( B \) are equidecomposable if there exist finite partitions that can be mapped to each other by isometries.
  • Paradoxical Decomposition: A decomposition of a set into disjoint subsets that can be rearranged to form two copies of the original.

Theorem: Banach-Tarski Paradox

Theorem (Banach-Tarski, 1924): Given a solid ball in \( \mathbb{R}^3 \), there exists a decomposition of the ball into finitely many disjoint subsets which can be reassembled using only rigid motions to form two identical copies of the original ball.

        c, s = np.cos(theta), np.sin(theta)

                        break
                if is_new:
                    new_elements.append(new_elem)
                    elements.append(new_elem)
        current = new_elements

4. The Navier-Stokes Millennium Problem

Historical Context

In 2000, the Clay Mathematics Institute offered $1 million prizes for solutions to seven Millennium Prize Problems. One concerns the Navier-Stokes equations: whether solutions remain smooth for all time given smooth initial conditions.

The Problem Statement

Problem (Navier-Stokes): In three dimensions, given smooth initial data for the incompressible Navier-Stokes equations, do there exist smooth solutions that persist for all time? Or can singularities form in finite time?

What We Know

  • 2D Case: In two dimensions, smooth solutions exist for all time.
  • Weak Solutions: In 3D, weak solutions exist globally in time.
  • Partial Regularity: The singular set has Hausdorff dimension at most 1.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

def vorticity_equation_1d():
    """Simplified 1D model of vorticity dynamics."""
    # Burgers' equation as a toy model: u_t + u*u_x = ν*u_xx
    
    nx = 256
    L = 2 * np.pi
    x = np.linspace(0, L, nx, endpoint=False)
    dx = L / nx
    nu = 0.01
    
    u = np.sin(x)
    
    def dudt(u, t):
        u_hat = np.fft.fft(u)
        k = np.fft.fftfreq(nx, dx) * 2 * np.pi
        ux_hat = 1j * k * u_hat
        uxx_hat = -(k**2) * u_hat
        ux = np.fft.ifft(ux_hat).real
        uxx = np.fft.ifft(uxx_hat).real
        return -u * ux + nu * uxx
    
    t_span = np.linspace(0, 2, 500)
    solution = odeint(dudt, u, t_span)
    
    max_gradients = []
    for i, t in enumerate(t_span):
        u_t = solution[i]
        max_gradients.append(np.max(np.abs(np.gradient(u_t, dx))))
    
    return x, t_span, solution, max_gradients

📜 Math History: The Development of Modern Probability Theory

The modern theory of probability emerged from the intersection of gambling, insurance, and mathematics in the 17th century. While games of chance had been analyzed since antiquity, the first rigorous mathematical treatment came from a correspondence between Blaise Pascal and Pierre de Fermat in 1654.

The problem that sparked this exchange was the "problem of points": how should the stakes be divided if a game is interrupted before completion? Pascal and Fermat developed different methods—Pascal using recursion and the arithmetic triangle (now Pascal's triangle), Fermat using combinatorics—but arrived at the same answer. Their correspondence established the foundations of mathematical expectation.

Christiaan Huygens published the first book on probability theory in 1657, "De Ratiociniis in Ludo Aleae" (On Reasoning in Games of Chance). This introduced the concept of expectation and solved several problems that would become classics, including the gambler's ruin problem.

The 18th century saw rapid development. Jacob Bernoulli's "Ars Conjectandi" (1713) proved the law of large numbers, showing that empirical frequencies converge to theoretical probabilities. Abraham de Moivre discovered the normal distribution as an approximation to the binomial distribution and proved the first central limit theorem.

Pierre-Simon Laplace brought probability to maturity in the early 19th century. His "Théorie Analytique des Probabilités" (1812) synthesized existing results and introduced new methods, including the Laplace transform and the method of least squares.

The 20th century brought two major revolutions. First, measure theory provided a rigorous foundation through the work of Émile Borel, Henri Lebesgue, and especially Andrey Kolmogorov. His 1933 axioms defined probability as a measure on a sigma-algebra, unifying discrete and continuous probability.

Second, the development of stochastic calculus by Kiyoshi Itô (1940s-1950s) provided tools for analyzing random processes that evolve continuously in time. This proved essential for mathematical finance, where Robert Merton and Fischer Black used it to derive their option pricing formula in 1973.

Today, probability theory stands as one of the most active areas of mathematics, with applications ranging from machine learning to statistical physics, from genetics to financial engineering.

🧩 Problem Corner

Putnam Competition Problem

Problem: Let \( f: \mathbb{R} \to \mathbb{R} \) be a function such that \[ f(x^2 + yf(z)) = xf(x) + zf(y) \] for all real numbers \( x, y, z \). Find all possible values of \( f(2024) \).

💡 Hint

Start by finding \( f(0) \) by setting appropriate values. Then try to determine if \( f \) is linear. Consider what happens when you set \( x = 0 \) or \( y = 0 \).

✅ Solution

Step 1: Setting \( x = 0 \) gives \( f(yf(z)) = zf(y) \). Setting \( y = 0 \) gives \( f(0) = zf(0) \) for all \( z \), so \( f(0) = 0 \).

Step 2: Setting \( y = 0 \) in the original equation: \( f(x^2) = xf(x) \).

Step 3: From Step 1 with \( y = 1 \): \( f(f(z)) = zf(1) \). This shows \( f \) is injective.

Step 4: From \( f(x^2) = xf(x) \), replacing \( x \) with \( -x \): \( f(-x) = -f(x) \), so \( f \) is odd.

Step 5: From \( f(f(z)) = zf(1) \) and the original equation, we derive \( f(u + v) = f(u) + f(v) \) for appropriate domains. Combined with oddness, this gives Cauchy's equation.

Step 6: Substituting \( f(x) = cx \) into the original equation yields \( c^2 = c \), so \( c = 0 \) or \( c = 1 \).

Answer: The possible values are \( f(2024) = 0 \) or \( f(2024) = 2024 \).

📊 Visualization of the Day: Phase Portraits of Dynamical Systems

A phase portrait is a geometric representation of the trajectories of a dynamical system in the phase plane. It provides a complete qualitative picture of the system's behavior, showing fixed points, limit cycles, and the flow of trajectories.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

def van_der_pol(xy, t, mu=1.0):
    """Van der Pol oscillator: x' = y, y' = μ(1-x²)y - x"""
    x, y = xy
    return [y, mu * (1 - x**2) * y - x]

def plot_phase_portrait(mu=1.0):
    """Generate phase portrait for Van der Pol oscillator"""
    x = np.linspace(-3, 3, 20)
    y = np.linspace(-3, 3, 20)
    X, Y = np.meshgrid(x, y)
    
    U = Y
    V = mu * (1 - X**2) * Y - X
    
    M = np.sqrt(U**2 + V**2)
    M[M == 0] = 1
    U, V = U/M, V/M
    
    plt.figure(figsize=(10, 8))
    plt.quiver(X, Y, U, V, M, cmap='viridis', alpha=0.6)
    
    t = np.linspace(0, 20, 2000)
    initial_conditions = [[0.1, 0.1], [2, 0], [-2, 0], [0, 2], [0, -2]]
    
    for ic in initial_conditions:
        sol = odeint(van_der_pol, ic, t, args=(mu,))
        plt.plot(sol[:, 0], sol[:, 1], 'b-', alpha=0.7, linewidth=1.5)
        plt.scatter([ic[0]], [ic[1]], color='red', s=50, zorder=5)
    
    plt.xlabel('x', fontsize=12)
    plt.ylabel('y', fontsize=12)
    plt.title(f'Van der Pol Oscillator Phase Portrait (μ={mu})', fontsize=14)
    plt.grid(True, alpha=0.3)
    plt.axis('equal')
    plt.xlim(-3, 3)
    plt.ylim(-3, 3)
    plt.tight_layout()
    plt.savefig('phase_portrait.png', dpi=150)
    plt.close()
