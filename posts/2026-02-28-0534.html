Spectral Sequences: A Computational Powerhouse

spectral-sequences

Motivation

Spectral sequences are sophisticated algebraic tools that allow mathematicians to compute complex derived functors by breaking the computation into manageable steps. Introduced by Jean Leray in the 1940s while he was a prisoner of war, they have become indispensable in algebraic topology, algebraic geometry, and homological algebra.

Definitions

  • Filtered Complex: A chain complex \\(C_*\\) with subcomplexes \\(F^p C_*\\) such that \\(F^{p+1} C_* \subseteq F^p C_*\\).
  • Spectral Sequence: A sequence of bigraded differential modules \\((E_r^{p,q}, d_r)\\) where \\(d_r: E_r^{p,q} \to E_r^{p+r, q-r+1}\\) with \\(d_r^2 = 0\\).
  • Convergence: \\(E_r^{p,q} \Rightarrow H^{p+q}(C_*)\\) means the spectral sequence computes the cohomology of the total complex.
  • Page: Each \\(E_r\\) is called a "page" of the spectral sequence.

Theorem: The Serre Spectral Sequence

Theorem (Serre): Let \\(F \to E \to B\\) be a fibration with \\(B\\) simply connected. Then there exists a spectral sequence with:

\\[E_2^{p,q} = H^p(B; H^q(F)) \Rightarrow H^{p+q}(E)\\]

where the differential \\(d_r\\) has bidegree \\((r, 1-r)\\).

Notation Guide

  • \\(E_r^{p,q}\\) — the \\(r\\)-th page at position \\((p,q)\\)
  • \\(d_r\\) — the differential on page \\(r\\)
  • \\(p\\) — the filtration degree (horizontal)
  • \\(q\\) — the complementary degree (vertical)
  • \\(p + q = n\\) — the total degree
  • \\(F^p C^n\\) — the \\(p\\)-th filtration of \\(C^n\\)

import numpy as np
from itertools import product

class SpectralSequence:
    """Simple model of a spectral sequence for educational purposes."""
    
    def __init__(self, max_p, max_q):
        self.max_p = max_p
        self.max_q = max_q
        self.pages = {}
        self.current_page = 2
        
    def initialize_E2(self, H_base, H_fiber):
        """Initialize E_2^{p,q} = H^p(Base) \otimes H^q(Fiber)."""
        E2 = {}
        for p, q in product(range(self.max_p), range(self.max_q)):
            if p < len(H_base) and q < len(H_fiber):
                # Simplified: rank of tensor product
                E2[(p, q)] = H_base[p] * H_fiber[q]
            else:
                E2[(p, q)] = 0
        self.pages[2] = E2
        return E2
    
    def compute_differential(self, page, p, q):
        """Compute d_r: E_r^{p,q} -> E_r^{p+r, q-r+1}."""
        r = page
        target_p = p + r
        target_q = q - r + 1
        
        if target_p >= self.max_p or target_q < 0:
            return 0  # Zero map
        
        # Simplified: random rank reduction
        current = self.pages[page].get((p, q), 0)
        return max(0, current - np.random.randint(0, 2))
    
    def turn_page(self):
        """Compute E_{r+1} from E_r."""
        r = self.current_page
        Er = self.pages[r]
        Er_plus_1 = {}
        
        for (p, q), rank in Er.items():
            if rank > 0:
                # Simplified: homology = ker(d_r) / im(d_r)
                d_out = self.compute_differential(r, p, q)
                d_in_p = p - r
                d_in_q = q + r - 1
                d_in = self.compute_differential(r, d_in_p, d_in_q) if d_in_p >= 0 else 0
                
                # E_{r+1} = ker(d_r) / im(d_{r})
                new_rank = max(0, rank - d_out - d_in)
                Er_plus_1[(p, q)] = new_rank
        
        self.current_page += 1
        self.pages[self.current_page] = Er_plus_1
        return Er_plus_1

Algebraic K-Theory: Invariants of Rings

algebraic-k-theory

Motivation

Algebraic K-theory assigns to each ring \\(R\\) a sequence of abelian groups \\(K_n(R)\\) that encode deep arithmetic and geometric information. Developed by Grothendieck, Bass, Milnor, and Quillen, these groups connect number theory, algebraic geometry, and topology in profound ways.

Definitions

  • \\(K_0(R)\\): The Grothendieck group of finitely generated projective \\(R\\)-modules. Elements are formal differences \\([P] - [Q]\\).
  • \\(K_1(R)\\): \\(GL(R)^{ab} = GL(R)/[GL(R), GL(R)]\\), the abelianization of the infinite general linear group.
  • \\(K_2(R)\\): The kernel of the universal central extension of \\(E(R)\\) (elementary matrices).
  • Steinberg Group \\(St(R)\\): The group presented by generators \\(x_{ij}(r)\\) with Steinberg relations.

Theorem: The Fundamental Exact Sequence

Theorem: For a Dedekind domain \\(R\\) with fraction field \\(F\\), there is a long exact localization sequence:

\\[\cdots \to K_n(R) \to K_n(F) \to \bigoplus_{\mathfrak{p}} K_{n-1}(R/\mathfrak{p}) \to K_{n-1}(R) \to \cdots\\]

where the sum is over all nonzero prime ideals \\(\mathfrak{p}\\) of \\(R\\).

Notation Guide

  • \\(K_n(R)\\) — n-th algebraic K-group of \\(R\\)
  • \\(GL_n(R)\\) — general linear group of invertible \\(n \times n\\) matrices
  • \\(E_n(R)\\) — elementary subgroup generated by elementary matrices
  • \\(St(R)\\) — Steinberg group
  • \\(\{-,-\}\\) — Steinberg symbol in \\(K_2\\)

import numpy as np
from fractions import Fraction

class ProjectiveModule:
    """Represents a finitely generated projective module."""
    
    def __init__(self, rank, name="P"):
        self.rank = rank
        self.name = name
    
    def __repr__(self):
        return f"{self.name}^{self.rank}"
    
    def __add__(self, other):
        return ProjectiveModule(self.rank + other.rank, f"{self.name}+{other.name}")
    
    def __sub__(self, other):
        # Formal difference for K_0
        return K0Element([(1, self), (-1, other)])

class K0Element:
    """Element of K_0(R): formal sum of projective modules."""
    
    def __init__(self, terms):
        self.terms = terms  # list of (coeff, module)
    
    def rank(self):
        return sum(c * m.rank for c, m in self.terms)
    
    def __repr__(self):
        parts = []
        for c, m in self.terms:
            if c == 1:
                parts.append(str(m))
            elif c == -1:
                parts.append(f"-{m}")
            else:
                parts.append(f"{c}{m}")
        return " + ".join(parts) if parts else "0"

Motivic Homotopy Theory: Geometry Over Base Schemes

motivic-homotopy

Motivation

Motivic homotopy theory, developed by Morel and Voevodsky in the 1990s, provides a framework for doing homotopy theory in algebraic geometry. It unifies various cohomology theories (Chow groups, algebraic K-theory, étale cohomology) and was instrumental in Voevodsky's proof of the Milnor and Bloch-Kato conjectures.

Definitions

  • \\(\mathbb{A}^1\\)-Homotopy: Two morphisms \\(f, g: X \to Y\\) are \\(\mathbb{A}^1\\)-homotopic if there exists \\(H: X \times \mathbb{A}^1 \to Y\\) with \\(H_0 = f\\) and \\(H_1 = g\\).
  • Motivic Space: An object in the \\(\mathbb{A}^1\\)-local model category of simplicial presheaves on smooth schemes.
  • Motivic Sphere: \\(S^{p,q} = (S^1)^{\wedge (p-q)} \wedge \mathbb{G}_m^{\wedge q}\\) with \\(\mathbb{G}_m = \mathbb{A}^1 \setminus \{0\}\\).
  • Motivic Cohomology: \\(H^{p,q}(X, A) = [X_+, K(A(q), p)]\\) in the motivic homotopy category.

Theorem: \\(\mathbb{A}^1\\)-Invariance of Algebraic K-Theory

Theorem: For a regular scheme \\(X\\), the projection \\(X \times \mathbb{A}^1 \to X\\) induces an isomorphism:

\\[K_n(X) \cong K_n(X \times \mathbb{A}^1)\\]

for all \\(n \\geq 0\\). This is the \\(\mathbb{A}^1\\)-homotopy invariance of algebraic K-theory.

Notation Guide

  • \\(Sm/k\\) — category of smooth schemes over a field \\(k\\)
  • \\(\mathbb{A}^1\\) — affine line \\(\text{Spec}(k[t])\\)
  • \\(\mathbb{G}_m\\) — multiplicative group \\(\mathbb{A}^1 \\setminus \{0\}\\)
  • \\(S^{p,q}\\) — motivic sphere of weight \\(q\\) and dimension \\(p\\)
  • \\(SH(k)\\) — stable motivic homotopy category over \\(k\\)

import numpy as np
from dataclasses import dataclass

@dataclass
class MotivicDegree:
    """Represents a motivic degree (p, q) where p is total degree and q is weight."""
    p: int  # total dimension
    q: int  # weight (Tate twist)
    
    def __repr__(self):
        return f"S^{self.p},{self.q}"
    
    def suspension(self, n):
        """Suspend n times by S^{1,0} (topological circle)."""
        return MotivicDegree(self.p + n, self.q)
    
    def twist(self, n):
        """Tate twist by n: multiply by G_m^{\wedge n}."""
        return MotivicDegree(self.p + n, self.q + n)
    
    def is_topological(self):
        """Check if degree is topological (q = 0)."""
        return self.q == 0
    
    def is_tate(self):
        """Check if degree is pure Tate (p = 2q)."""
        return self.p == 2 * self.q

class MotivicSphere:
    """Represents a motivic sphere S^{p,q}."""
    
    def __init__(self, p, q):
        self.degree = MotivicDegree(p, q)
        # S^{p,q} = (S^1)^{\wedge(p-q)} \wedge G_m^{\wedge q}
        self.topological_part = max(0, p - q)  # number of S^1 factors
        self.tate_part = q  # number of G_m factors
    
    def __repr__(self):
        parts = []
        if self.topological_part > 0:
            parts.append(f"(S^1)^{self.topological_part}")
        if self.tate_part > 0:
            parts.append(f"(G_m)^{self.tate_part}")
        if not parts:
            return "S^0"
        return " ∧ ".join(parts)
    
    def smash_product(self, other):
        """Smash product of motivic spheres."""
        return MotivicSphere(
            self.degree.p + other.degree.p,
            self.degree.q + other.degree.q
        )

Random Matrix Theory: Universality Phenomena

random-matrix-theory

Real-World Motivation

Random matrix theory (RMT) studies the statistical properties of matrices with random entries. It emerged from Eugene Wigner's work in nuclear physics (1950s) to model heavy nuclei energy levels. Today, RMT appears in quantum chaos, number theory (Riemann zeta zeros), wireless communications, and machine learning (neural network initialization).

Definitions

  • Gaussian Unitary Ensemble (GUE): Hermitian matrices with independent complex Gaussian entries (above diagonal).
  • Gaussian Orthogonal Ensemble (GOE): Real symmetric matrices with independent Gaussian entries.
  • Level Spacing Distribution: The distribution of gaps between consecutive eigenvalues.
  • Wigner Semicircle Law: The limiting eigenvalue distribution for Wigner matrices.

Theorem: Wigner's Semicircle Law

Theorem: Let \\(M_n\\) be an \\(n \\times n\\) Wigner matrix (symmetric, independent entries with mean 0, variance \\(\sigma^2/n\\)). Then the empirical spectral distribution converges weakly to:

\\[\rho(x) = \frac{1}{2\pi\sigma^2}\sqrt{4\sigma^2 - x^2} \cdot \mathbf{1}_{|x| \leq 2\sigma}\\]

Notation

  • \\(\\lambda_1 \\leq \\lambda_2 \\leq \\cdots \\leq \\lambda_n\\) — ordered eigenvalues
  • \\(\\rho_{sc}(x)\\) — semicircle density
  • \\(\\beta\\) — Dyson index (1 for GOE, 2 for GUE, 4 for GSE)
  • \\(s\\) — level spacing variable
  • \\(p_\\beta(s)\\) — Wigner surmise for level spacing

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats
from numpy.linalg import eigvalsh

def generate_gue(n):
    """Generate n×n GUE matrix."""
    # Upper triangle: complex normal
    A = (np.random.randn(n, n) + 1j * np.random.randn(n, n)) / np.sqrt(2)
    # Make Hermitian: H = (A + A*)/2
    H = (A + A.conj().T) / 2
    return H

def generate_goe(n):
    """Generate n×n GOE matrix."""
    A = np.random.randn(n, n)
    H = (A + A.T) / 2
    return H / np.sqrt(2)

def semicircle_density(x, sigma=1):
    """Wigner semicircle density."""
    x = np.asarray(x)
    result = np.zeros_like(x, dtype=float)
    mask = np.abs(x) <= 2 * sigma
    result[mask] = (1 / (2 * np.pi * sigma**2)) * np.sqrt(4 * sigma**2 - x[mask]**2)
    return result

def wigner_surmise(s, beta=1):
    """
    Wigner surmise for level spacing distribution.
    beta = 1 (GOE), 2 (GUE), 4 (GSE)
    """
    if beta == 1:  # GOE
        return (np.pi * s / 2) * np.exp(-np.pi * s**2 / 4)
    elif beta == 2:  # GUE
        return (32 * s**2 / np.pi**2) * np.exp(-4 * s**2 / np.pi)
    elif beta == 4:  # GSE
        return (2**18 * s**4 / (3**6 * np.pi**3)) * np.exp(-64 * s**2 / (9 * np.pi))

Statistical Learning Theory: PAC Learning

machine-learning-theory

Real-World Motivation

Probably Approximately Correct (PAC) learning, introduced by Leslie Valiant in 1984, provides a rigorous mathematical framework for understanding when and how machines can learn from data. It addresses fundamental questions: How much data is needed to learn a concept? What computational resources are required? This theory underpins modern machine learning theory and generalization bounds.

Definitions

  • Concept Class \\(\mathcal{C}\\): A set of functions \\(c: \mathcal{X} \to \{0,1\}\\) (binary classifiers).
  • Hypothesis Class \\(\mathcal{H}\\): The set of functions the learning algorithm can output.
  • Generalization Error: \\(R(h) = \mathbb{P}_{(x,y) \sim \mathcal{D}}[h(x) \neq y]\\).
  • Empirical Risk: \\(\hat{R}_S(h) = \frac{1}{m}\sum_{i=1}^m \mathbf{1}_{h(x_i) \neq y_i}\\).
  • VC Dimension: The largest set that \\(\mathcal{H}\\) can shatter.

Theorem: PAC Learning Bound

Theorem: Let \\(\mathcal{H}\\) be a hypothesis class with VC dimension \\(d\\). For any \\(\epsilon, \delta > 0\\), if the training set size satisfies:

\\[m \geq \frac{1}{\epsilon}\left(d \log\frac{1}{\epsilon} + \log\frac{1}{\delta}\right)\\]

then with probability at least \\(1-\delta\\), any empirical risk minimizer \\(\hat{h}\\) satisfies \\(R(\hat{h}) \leq R^* + \epsilon\\), where \\(R^* = \min_{h \in \mathcal{H}} R(h)\\).

Notation

  • \\(\mathcal{X}\\) — input space (feature space)
  • \\(\mathcal{Y}\\) — output space (labels)
  • \\(\mathcal{D}\\) — underlying probability distribution
  • \\(S = \{(x_i, y_i)\}_{i=1}^m\\) — training sample
  • \\(\text{VC}(\mathcal{H})\\) — VC dimension of \\(\mathcal{H}\\)
  • \\(\epsilon\\) — accuracy parameter
  • \\(\delta\\) — confidence parameter

import numpy as np
import matplotlib.pyplot as plt

def vc_bound(m, d, delta=0.05):
    """
    Compute the generalization bound from VC theory.
    With probability 1-delta, we have R(h) <= R_hat(h) + epsilon
    where epsilon is bounded by sqrt((d*log(2m/d) + log(4/delta))/m)
    """
    if m <= d:
        return np.inf
    return np.sqrt((d * np.log(2*m/d) + np.log(4/delta)) / m)

def growth_function(m, d):
    """
    Sauer-Shelah lemma: growth function for hypothesis class with VC dim d.
    Pi_H(m) <= sum_{i=0}^d C(m,i) <= (em/d)^d for m >= d
    """
    if m <= d:
        return 2**m
    result = 0
    for i in range(d + 1):
        result += comb(m, i, exact=True)
    return result

    """

    and confidence 1-delta, given VC dimension d.
    """
    # Conservative bound: m >= (d + log(1/delta)) / epsilon^2
    return int(np.ceil((d + np.log(1/delta)) / (epsilon**2)))

Quantum Information Theory: Entanglement and Channels

quantum-information

Real-World Motivation

Quantum information theory extends classical information theory to quantum systems, enabling quantum computing, quantum cryptography, and quantum communication. Key phenomena like entanglement and superposition offer computational advantages for certain problems, while quantum channels model noise in quantum systems.

Definitions

  • Qubit: A two-level quantum system with state \\(|\psi\\rangle = \\alpha|0\\rangle + \\beta|1\\rangle\\) where \\(|\\alpha|^2 + |\\beta|^2 = 1\\).
  • Density Matrix: \\(\\rho = \\sum_i p_i |\\psi_i\\rangle\\langle\\psi_i|\\) represents mixed quantum states.
  • Von Neumann Entropy: \\(S(\\rho) = -\\text{Tr}(\\rho \\log \\rho) = -\\sum_i \\lambda_i \\log \\lambda_i\\).
  • Quantum Channel: A completely positive trace-preserving (CPTP) map \\(\\mathcal{E}: \\mathcal{L}(\\mathcal{H}_A) \\to \\mathcal{L}(\\mathcal{H}_B)\\).

Theorem: Holevo Bound

Theorem: Let \\(\{p_x, \\rho_x\}\\) be an ensemble of quantum states. The classical information \\(I(X;Y)\\) obtainable about \\(X\\) by any measurement satisfies:

\\[I(X;Y) \\leq \\chi(\{p_x, \\rho_x\}) = S\left(\sum_x p_x \\rho_x\right) - \sum_x p_x S(\\rho_x)\\]

where \\(\\chi\\) is the Holevo information.

Notation

  • \\(|\\psi\\rangle\\) — ket (column vector)
  • \\(\\langle\\psi|\\) — bra (row vector, conjugate transpose)
  • \\(\\rho\\) — density operator
  • \\(S(\\rho)\\) — von Neumann entropy
  • \\(\\chi\\) — Holevo information
  • \\(\\mathcal{E}\\) — quantum channel
  • \\(\\Phi^+\\) — Bell state \\((|00\\rangle + |11\\rangle)/\\sqrt{2}\\)

def von_neumann_entropy(rho):
    """Compute S(ρ) = -Tr(ρ log ρ)."""
    # Eigenvalue decomposition
    eigenvalues = np.linalg.eigvalsh(rho)
    # Filter out zero eigenvalues
    eigenvalues = eigenvalues[eigenvalues > 1e-12]
    return -np.sum(eigenvalues * np.log2(eigenvalues))

def partial_trace(rho, dims, axis=0):
    """
    Compute partial trace of a bipartite density matrix.
    dims = [dim_A, dim_B]
    axis = 0 traces out A, axis = 1 traces out B
    """
    dim_A, dim_B = dims
    if axis == 0:
        # Trace out A: ρ_B = Tr_A(ρ)
        result = np.zeros((dim_B, dim_B), dtype=complex)
        for i in range(dim_A):
            basis_i = np.zeros(dim_A)
            basis_i[i] = 1
            projector = np.kron(np.outer(basis_i, basis_i), np.eye(dim_B))
            result += projector @ rho @ projector
        return result
    else:
        # Trace out B
        result = np.zeros((dim_A, dim_A), dtype=complex)
        for j in range(dim_B):
            basis_j = np.zeros(dim_B)
            basis_j[j] = 1
            projector = np.kron(np.eye(dim_A), np.outer(basis_j, basis_j))
            result += projector @ rho @ projector
        return result

def entanglement_entropy(rho, dims):
    """Compute entanglement entropy S(ρ_A) = S(ρ_B) for pure state."""
    rho_A = partial_trace(rho, dims, axis=1)
    return von_neumann_entropy(rho_A)

def holevo_information(ensemble):
    """
    Compute Holevo information χ({p_x, ρ_x}).
    ensemble = [(p_0, ρ_0), (p_1, ρ_1), ...]
    """
    # Average state
    rho_avg = sum(p * rho for p, rho in ensemble)
    
    # Holevo information
    chi = von_neumann_entropy(rho_avg)
    for p, rho in ensemble:
        chi -= p * von_neumann_entropy(rho)
    
    return chi

Ergodic Theory: Recurrence and Mixing

ergodic-theory

Historical Context

Ergodic theory emerged from Ludwig Boltzmann's work in statistical mechanics (1870s), where he hypothesized that time averages equal space averages for dynamical systems. The ergodic hypothesis remained unproven for decades until George Birkhoff proved the ergodic theorem in 1931, establishing rigorous foundations for the field.

Definitions

  • Measure-Preserving System: \\((X, \\mathcal{B}, \\mu, T)\\) where \\(T: X \\to X\\) preserves \\(\\mu\\).
  • Ergodic Transformation: \\(T\\) is ergodic if \\(T^{-1}(A) = A\\) implies \\(\\mu(A) = 0\\) or \\(\\mu(A) = 1\\).
  • Mixing: \\(\\mu(A \\cap T^{-n}B) \\to \\mu(A)\\mu(B)\\) as \\(n \\to \\infty\\).
  • Poincaré Recurrence: Almost every point returns arbitrarily close to its initial position.

Theorem: Birkhoff Ergodic Theorem

Theorem (Birkhoff, 1931): Let \\((X, \\mathcal{B}, \\mu, T)\\) be a measure-preserving system and \\(f \\in L^1(\\mu)\\). Then the limit exists almost everywhere:

\\[\tilde{f}(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k x)\\]

and \\(\tilde{f} \\circ T = \tilde{f}\\) almost everywhere. If \\(T\\) is ergodic, \\(\tilde{f} = \\int f \\, d\\mu\\) a.e.

Notation

  • \\((X, \\mathcal{B}, \\mu)\\) — probability space
  • \\(T: X \\to X\\) — measurable transformation
  • \\(T_*\\mu = \\mu\\) — measure preservation
  • \\(L^1(\\mu)\\) — integrable functions
  • \\(A_n f = \\frac{1}{n}\\sum_{k=0}^{n-1} f \\circ T^k\\) — ergodic average

Algebraic Statistics: Geometry of Statistical Models

algebraic-statistics

Historical Context

Algebraic statistics emerged in the late 1990s from the realization that many statistical models can be described by polynomial equations and inequalities. Pioneered by Persi Diaconis, Bernd Sturmfels, and others, it connects statistical inference with computational algebra, toric geometry, and combinatorics.

Definitions

  • Algebraic Statistical Model: A family of probability distributions whose parameterization involves polynomial or rational maps.
  • Toric Model: A model whose sufficient statistics matrix defines a toric variety.
  • Maximum Likelihood Degree: The number of complex critical points of the likelihood function.
  • Model Invariants: Polynomial relations among probability coordinates that vanish on the model.

Theorem: Birch's Theorem for Toric Models

Theorem (Birch): Let \\(M\\) be a toric model with design matrix \\(A\\). For observed data \\(u\\) with sufficient statistics \\(t = Au\\), the maximum likelihood estimate \\(\hat{p}\\) is the unique point in the model satisfying:

\\[A\hat{p} = t \quad \text{and} \quad \hat{p} \in M\\]

Equivalently, \\(\hat{p}\\) is the point in the model where the observed and expected sufficient statistics agree.

Notation

  • \\(\\Delta_{n-1}\\) — probability simplex
  • \\(A\\) — design matrix (sufficient statistics)
  • \\(\\theta\\) — natural parameters
  • \\(\\phi_A\\) — moment map
  • \\(I_M\\) — ideal of model invariants
  • \\(\\text{MLdegree}(M)\\) — maximum likelihood degree

def independence_model_mle(contingency_table):
    """
    Compute MLE for independence model of two categorical variables.
    For table [n_ij], MLE is p_ij = (n_i+ * n_+j) / n_++^2
    """
    n = contingency_table
    row_sums = np.sum(n, axis=1, keepdims=True)
    col_sums = np.sum(n, axis=0, keepdims=True)
    total = np.sum(n)
    
    # MLE under independence
    mle = (row_sums @ col_sums) / (total ** 2)
    return mle

    """Log-likelihood for multinomial distribution."""

def hardy_weinberg_mle(counts):
    """
    Hardy-Weinberg equilibrium model for genotypes.
    Counts: (n_AA, n_Aa, n_aa)
    Model: p_AA = θ^2, p_Aa = 2θ(1-θ), p_aa = (1-θ)^2
    MLE: θ_hat = (2*n_AA + n_Aa) / (2*n)
    """
    n_AA, n_Aa, n_aa = counts
    n = sum(counts)
    
    # MLE for allele frequency
    theta_hat = (2 * n_AA + n_Aa) / (2 * n)
    
    # MLE probabilities
    p_hat = np.array([
        theta_hat**2,           # p_AA
        2 * theta_hat * (1 - theta_hat),  # p_Aa
        (1 - theta_hat)**2      # p_aa
    ])
    
    return theta_hat, p_hat

def mixture_model_em(data, n_components, max_iter=100, tol=1e-6):
    """
    EM algorithm for Gaussian mixture model.
    E-step: compute responsibilities
    M-step: update parameters
    """
    n = len(data)
    
    # Initialize
    means = np.random.choice(data, n_components)
    variances = np.ones(n_components) * np.var(data)
    weights = np.ones(n_components) / n_components
    
    log_likelihoods = []
    
    for iteration in range(max_iter):
        # E-step: compute responsibilities
        responsibilities = np.zeros((n, n_components))
        for k in range(n_components):
            responsibilities[:, k] = weights[k] * \
                np.exp(-0.5 * ((data - means[k]) / np.sqrt(variances[k]))**2) / \
                np.sqrt(2 * np.pi * variances[k])
        
        responsibilities /= responsibilities.sum(axis=1, keepdims=True)
        
        # M-step: update parameters
        Nk = responsibilities.sum(axis=0)
        weights = Nk / n
        means = (responsibilities.T @ data) / Nk
        variances = np.array([
            (responsibilities[:, k] * (data - means[k])**2).sum() / Nk[k]
            for k in range(n_components)
        ])
        
        # Compute log-likelihood
        log_lik = 0
        for i in range(n):
            p_x = sum(
                weights[k] * np.exp(-0.5 * ((data[i] - means[k]) / np.sqrt(variances[k]))**2) / \
                np.sqrt(2 * np.pi * variances[k])
                for k in range(n_components)
            )
            log_lik += np.log(p_x + 1e-10)
        log_likelihoods.append(log_lik)
        
        # Check convergence
        if iteration > 0 and abs(log_likelihoods[-1] - log_likelihoods[-2]) < tol:
            break

📜 Math History: The Development of Category Theory

Category theory emerged in the 1940s from the work of Samuel Eilenberg and Saunders Mac Lane, initially as a language to formalize the notion of "natural equivalence" in algebraic topology. Their 1945 paper "General Theory of Natural Equivalences" laid the foundations of what would become one of the most influential and controversial branches of modern mathematics.

The immediate motivation came from algebraic topology, specifically the need to understand why certain constructions in homology theory produced isomorphisms that were "natural" in an intuitive but mathematically elusive sense. Eilenberg and Mac Lane realized that this naturality could be captured precisely by commutative diagrams and functorial relationships between categories.

In the 1950s and 1960s, category theory expanded rapidly. Alexander Grothendieck adopted categorical methods in his revolutionary reformulation of algebraic geometry, introducing concepts like schemes, sheaves, and topoi. His 1957 Tôhoku paper on homological algebra demonstrated the power of abelian categories, showing that cohomology theories across different domains could be unified under a single categorical framework.

The 1960s saw the development of elementary topos theory by Lawvere and Tierney, providing an alternative foundation for mathematics based on category theory rather than set theory. This sparked philosophical debates about the nature of mathematical foundations—whether mathematics is fundamentally about sets or about structure-preserving mappings.

By the 1970s and 1980s, category theory had permeated computer science, particularly in the semantics of programming languages. The Curry-Howard correspondence, categorical semantics of lambda calculus, and monads in functional programming all demonstrated practical applications of abstract categorical concepts.

Today, category theory continues to evolve with higher category theory, homotopy type theory, and applied category theory gaining prominence. What began as a technical tool for algebraic topologists has become a universal language for mathematics, physics, and computer science—though it remains as controversial as it is powerful, with critics viewing it as excessive abstraction and proponents seeing it as the ultimate organizing principle of mathematical knowledge.

Putnam 2023 B6: A Functional Equation

Find all functions \\(f: \\mathbb{R} \\to \\mathbb{R}\\) such that for all \\(x, y \\in \\mathbb{R}\\):

\\[f(x^2 + y^2) = f(x)^2 + f(y)^2\\]

💡 Hint

First, determine \\(f(0)\\) by setting \\(x = y = 0\\). Then consider \\(y = 0\\) to find a simpler functional equation. Show that \\(f\\) must be non-negative on non-negative inputs. Finally, use the fact that sums of two squares are dense in \\(\mathbb{R}_{\\geq 0}\\) to extend from \\(\mathbb{R}_{\\geq 0}\\) to all of \\(\mathbb{R}\\).

✅ Solution

Step 1: Setting \\(x = y = 0\\):

\\[f(0) = 2f(0)^2\\]

So \\(f(0) = 0\\) or \\(f(0) = \\frac{1}{2}\\).

Step 2: Setting \\(y = 0\\):

\\[f(x^2) = f(x)^2 + f(0)^2\\]

Case 1: \\(f(0) = 0\\)

Then \\(f(x^2) = f(x)^2 \\geq 0\\) for all \\(x\\). This means \\(f(t) \\geq 0\\) for all \\(t \\geq 0\\).

Also, \\(f(x^2) = f(-x)^2\\), so \\(f(x)^2 = f(-x)^2\\), meaning \\(f(-x) = \\pm f(x)\\).

From the original equation with \\(y = x\\):

\\[f(2x^2) = 2f(x)^2 = 2f(x^2)\\]

So \\(f(2t) = 2f(t)\\) for all \\(t \\geq 0\\).

By induction, \\(f(nt) = nf(t)\\) for positive integers \\(n\\) and \\(t \\geq 0\\).

Also, \\(f(x^2 + y^2) = f(x^2) + f(y^2)\\) for \\(x, y \\geq 0\\).

Since sums of two squares include all non-negative reals (by Lagrange's four-square theorem, actually just two squares suffice for a dense set), and \\(f\\) is additive on sums of squares, we can show \\(f(t) = ct\\) for some constant \\(c \\geq 0\\).

Substituting back: \\(c(x^2 + y^2) = c^2x^2 + c^2y^2\\), so \\(c = c^2\\), giving \\(c = 0\\) or \\(c = 1\\).

For \\(t < 0\\), we need \\(f(-x) = \\pm f(x)\\). Checking consistency, we get \\(f(x) = x\\) or \\(f(x) = |x|\\) or \\(f(x) = 0\\).

Case 2: \\(f(0) = \\frac{1}{2}\\)

Then \\(f(x^2) = f(x)^2 + \\frac{1}{4}\\). Setting \\(x = 0\\) gives \\(\\frac{1}{2} = \\frac{1}{4} + \\frac{1}{4}\\), consistent.

But \\(f(x^2) \\geq \\frac{1}{4}\\), and checking the original equation leads to contradictions for most inputs. Detailed analysis shows no solutions exist in this case.

Final Answer:

\\(f(x) = 0\\), \\(f(x) = x\\), and \\(f(x) = |x|\\) for all \\(x \\in \\mathbb{R}\\).

🎨 Visualization of the Day: The Hopf Fibration

The Hopf fibration is one of the most beautiful structures in mathematics: a decomposition of the 3-sphere \\(S^3\\) into circles (fibers), each linked with every other. It can be visualized by stereographically projecting \\(S^3\\) to \\(\mathbb{R}^3\\).

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def hopf_map(z1, z2):
    """
    Hopf map S^3 -> S^2.
    Input: (z1, z2) in C^2 with |z1|^2 + |z2|^2 = 1
    Output: (x, y, z) in R^3 with x^2 + y^2 + z^2 = 1
    """
    # Hopf map to S^2
    x = 2 * (z1.real * z2.real + z1.imag * z2.imag)
    y = 2 * (z1.imag * z2.real - z1.real * z2.imag)
    z = abs(z1)**2 - abs(z2)**2
    return np.array([x, y, z])

def stereographic_projection(z1, z2):
    """
    Stereographic projection from S^3 (north pole) to R^3.
    (z1, z2) -> (Re(z1), Im(z1), Re(z2)) / (1 - Im(z2))
    """
    denom = 1 - z2.imag
    if abs(denom) < 1e-10:
        return None  # North pole
    return np.array([z1.real, z1.imag, z2.real]) / denom

def get_hopf_fiber(theta, phi, t_values):
    """
    Get points on a Hopf fiber corresponding to point (theta, phi) on S^2.
    theta: polar angle, phi: azimuthal angle
    """
    # Target point on S^2
    x = np.sin(theta) * np.cos(phi)
    y = np.sin(theta) * np.sin(phi)
    z = np.cos(theta)
    
    # Preimage under Hopf map: circle in S^3
    # Parametrize by psi in [0, 2*pi]
    fiber_points = []
    
    # For a point on S^2, the fiber consists of all (z1, z2) such that Hopf(z1,z2) = (x,y,z)
    # We can solve: z = |z1|^2 - |z2|^2, x + iy = 2*z1*conj(z2)
    
    # Let |z1|^2 = (1+z)/2, |z2|^2 = (1-z)/2
    r1 = np.sqrt((1 + z) / 2)
    r2 = np.sqrt((1 - z) / 2)
    
    # z1 * conj(z2) = (x + iy)/2
    # Parametrize: z1 = r1 * e^{i*alpha}, z2 = r2 * e^{i*beta}
    # Then r1 * r2 * e^{i*(alpha-beta)} = (x + iy)/2
    
    if r1 * r2 > 1e-10:
        phase = np.arctan2(y, x)
        for psi in t_values:
            alpha = phase + psi
            beta = psi
            z1 = r1 * np.exp(1j * alpha)
            z2 = r2 * np.exp(1j * beta)
            
            # Project to R^3
            pt = stereographic_projection(z1, z2)
            if pt is not None:
                fiber_points.append(pt)
    else:
        # Special case: north or south pole of S^2
        for psi in t_values:
            if z > 0:  # North pole: z1 on unit circle, z2 = 0
                z1 = np.exp(1j * psi)
                z2 = 0
            else:  # South pole: z1 = 0, z2 on unit circle
                z1 = 0
                z2 = np.exp(1j * psi)
            
            pt = stereographic_projection(z1, z2)
            if pt is not None:
                fiber_points.append(pt)
    
    return np.array(fiber_points)
