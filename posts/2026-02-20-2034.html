Singularity Theory: The Geometry of Degeneracy

singularity-theory

Motivation

Singularity theory studies the local behavior of maps and spaces at points where the usual regularity conditions fail. Originating from the work of Hassler Whitney, René Thom, and Vladimir Arnold, it provides a framework for understanding how geometric objects can degenerate and how these degeneracies can be classified. The theory has profound applications in catastrophe theory, optics, robotics, and the study of bifurcations in dynamical systems.

Definitions

  • Singularity: For a smooth map \(f: M \\to N\\), a point \(p \\in M\\) is a singularity if the differential \(df_p: T_pM \\to T_{f(p)}N\\) fails to have maximal rank.
  • Morse Function: A smooth function \(f: M \\to \\mathbb{R}\\) is Morse if all critical points are non-degenerate (the Hessian is non-singular).
  • Corank: The corank of a singularity is \\(\\dim M - \\text{rank}(df_p)\\).
  • Jet Space: The space \\(J^k(M, N)\\) of k-jets of maps from \\(M\\) to \\(N\\), encoding Taylor expansions up to order \\(k\\).

Theorem: The Morse Lemma

Theorem: Let \\(f: M \\to \\mathbb{R}\\) be a smooth function and \\(p\\) a non-degenerate critical point. Then there exist local coordinates \\((x_1, \\ldots, x_n)\\) around \\(p\\) such that: \\[f(x) = f(p) - x_1^2 - \\cdots - x_k^2 + x_{k+1}^2 + \\cdots + x_n^2\\] where \\(k\\) is the index of the critical point (the number of negative eigenvalues of the Hessian).

Proof Sketch

The proof proceeds by induction on the dimension. First, apply the Hadamard lemma to write \\(f(x) - f(p) = \\sum_{i,j} x_i x_j h_{ij}(x)\\) where \\(h_{ij}(0) = \\frac{1}{2}\\frac{\\partial^2 f}{\\partial x_i \\partial x_j}(p)\\). By diagonalizing the symmetric matrix \\((h_{ij}(0))\\) and applying a linear coordinate change, we obtain the desired normal form. The non-degeneracy ensures the diagonalization is possible.

Notation Guide

  • \\(df_p\\) — Differential of \\(f\\) at \\(p\\)
  • \\(T_pM\\) — Tangent space of \\(M\\) at \\(p\\)
  • \\(H_f(p)\\) — Hessian matrix of \\(f\\) at \\(p\\)
  • \\(\\text{ind}(p)\\) — Morse index of critical point \\(p\\)
  • \\(J^k_p(M, N)\\) — Space of k-jets at \\(p\\)

Python Code

import numpy as np
from scipy.linalg import eigh

class SingularityTheory:
    """Computations in singularity theory."""
    
    @staticmethod
    def morse_index(hessian):
        """
        Compute the Morse index (number of negative eigenvalues).
        
        Args:
            hessian: Symmetric matrix (Hessian at critical point)
        
        Returns:
            Morse index
        """
        eigenvalues, _ = eigh(hessian)
        return np.sum(eigenvalues < 0)
    
    @staticmethod
    def is_nondegenerate(hessian, tol=1e-10):
        """Check if critical point is non-degenerate."""
        return abs(np.linalg.det(hessian)) > tol
    
    @staticmethod
    def morse_form(n, k):
        """
        Generate the normal form for a Morse function.
        f(x) = -x_1^2 - ... - x_k^2 + x_{k+1}^2 + ... + x_n^2
        """
        def f(x):
            return -np.sum(x[:k]**2) + np.sum(x[k:]**2)
        return f
    
    @staticmethod
    def classify_critical_point(hessian):
        """
        Classify a critical point based on its Hessian.
        
        Returns:
            'minimum', 'maximum', 'saddle', or 'degenerate'
        """
        if not SingularityTheory.is_nondegenerate(hessian):
            return 'degenerate'
        
        n = hessian.shape[0]
        idx = SingularityTheory.morse_index(hessian)
        
        if idx == 0:
            return 'minimum'
        elif idx == n:
            return 'maximum'
        else:
            return f'saddle (index {idx})'

# Example: Analyze a critical point
st = SingularityTheory()

# Hessian for f(x,y) = x^2 + y^2 (minimum at origin)
hessian_min = np.array([[2, 0], [0, 2]])
print(f"Classification: {st.classify_critical_point(hessian_min)}")

# Hessian for f(x,y) = -x^2 - y^2 (maximum at origin)
hessian_max = np.array([[-2, 0], [0, -2]])
print(f"Classification: {st.classify_critical_point(hessian_max)}")

# Hessian for f(x,y) = x^2 - y^2 (saddle at origin)

print(f"Classification: {st.classify_critical_point(hessian_saddle)}")

Young Tableaux: Combinatorics and Representation Theory

young-tableaux

Motivation

Young tableaux, introduced by Alfred Young in 1900, provide a powerful combinatorial framework for understanding the representation theory of symmetric groups and general linear groups. They encode the irreducible representations of these groups and appear in diverse areas including algebraic geometry (Schubert calculus), invariant theory, and the theory of symmetric functions. The Littlewood-Richardson rule, expressed in terms of tableaux, governs the decomposition of tensor products.

Definitions

  • Partition: A sequence \\(\\lambda = (\\lambda_1 \\geq \\lambda_2 \\geq \\cdots \\geq \\lambda_k > 0)\\) with \\(|\\lambda| = \\sum_i \\lambda_i\\).
  • Young Diagram: A left-justified array of boxes with \\(\\lambda_i\\) boxes in row \\(i\\).
  • Young Tableau: A filling of a Young diagram with numbers (typically \\(1, 2, \\ldots, n\\)) that is increasing along rows and columns.
  • Standard Young Tableau (SYT): A tableau using each number \\(1, \\ldots, n\\) exactly once.

Theorem: The Hook Length Formula

Theorem (Frame-Robinson-Thrall, 1954): The number of standard Young tableaux of shape \\(\\lambda\\) is: \\[f^\\lambda = \\frac{n!}{\\prod_{(i,j) \\in \\lambda} h(i,j)}\\] where \\(h(i,j)\\) is the hook length of box \\((i,j)\\), counting all boxes to the right, below, and the box itself.

Proof Sketch

The proof uses a probabilistic argument. Consider building a SYT by placing \\(n, n-1, \\ldots, 1\\) in order. The probability that a given box \\((i,j)\\) is chosen when placing \\(k\\) is \\(1/h(i,j)\\) where the hook lengths are computed in the remaining diagram. Multiplying these probabilities gives the formula.

Notation Guide

  • \\(\\lambda \\vdash n\\) — \\(\\lambda\\) is a partition of \\(n\\)
  • \\(f^\\lambda\\) — Number of SYT of shape \\(\\lambda\\)
  • \\(h(i,j)\\) — Hook length of box at position \\((i,j)\\)
  • \\(S_n\\) — Symmetric group on \\(n\\) letters
  • \\(V_\\lambda\\) — Irreducible representation corresponding to \\(\\lambda\\)

Python Code

from math import factorial
from functools import reduce
import operator

def hook_lengths(partition):
    """
    Compute hook lengths for all boxes in a Young diagram.
    
    Args:
        partition: List of row lengths (e.g., [3, 2, 1])
    
    Returns:
        List of lists containing hook lengths
    """
    n_rows = len(partition)
    hooks = []
    
    for i, row_len in enumerate(partition):
        row_hooks = []
        for j in range(row_len):
            # Count boxes to the right
            right = row_len - j - 1
            # Count boxes below
            below = sum(1 for r in range(i+1, n_rows) 
                       if partition[r] > j)
            # Hook length = right + below + 1 (the box itself)
            row_hooks.append(right + below + 1)
        hooks.append(row_hooks)
    
    return hooks

def count_SYT(partition):
    """
    Count standard Young tableaux of given shape using hook length formula.
    
    Args:
        partition: List of row lengths
    
    Returns:
        Number of SYT
    """
    n = sum(partition)
    hooks = hook_lengths(partition)
    hook_product = reduce(operator.mul, 
                         [h for row in hooks for h in row], 1)
    return factorial(n) // hook_product

# Example: SYT of shape (3, 2)
partition = [3, 2]
print(f"Partition: {partition}")
print(f"Hook lengths: {hook_lengths(partition)}")
print(f"Number of SYT: {count_SYT(partition)}")

# Example: SYT of shape (2, 2, 1)
partition2 = [2, 2, 1]
print(f"\\nPartition: {partition2}")
print(f"Hook lengths: {hook_lengths(partition2)}")
print(f"Number of SYT: {count_SYT(partition2)}")

Algebraic Combinatorics: Enumerative Methods

algebraic-combinatorics

Motivation

Algebraic combinatorics uses techniques from algebra, representation theory, and topology to solve combinatorial problems. It provides powerful tools for enumeration, including generating functions, symmetric functions, and the theory of partially ordered sets. The field has applications to statistical physics, computer science, and algebraic geometry.

Definitions

  • Generating Function: For a sequence \\(a_n\\), the ordinary generating function is \\(A(x) = \\sum_{n \\geq 0} a_n x^n\\).
  • Symmetric Function: A polynomial invariant under permutation of variables.
  • Möbius Function: For a poset \\(P\\), \\(\\mu(x,y)\\) defined recursively by \\(\\sum_{x \\leq z \\leq y} \\mu(x,z) = \\delta_{xy}\\).
  • Catalan Numbers: \\(C_n = \\frac{1}{n+1}\\binom{2n}{n}\\), counting numerous combinatorial objects.

Theorem: The Exponential Formula

Theorem: Let \\(a_n\\) count connected structures on \\(n\\) labeled points and \\(b_n\\) count all structures (possibly disconnected). If \\(A(x) = \\sum_{n \\geq 1} a_n \\frac{x^n}{n!}\\) and \\(B(x) = \\sum_{n \\geq 0} b_n \\frac{x^n}{n!}\\), then: \\[B(x) = \\exp(A(x))\\]

Proof Sketch

The proof uses the fact that any structure on \\(n\\) points can be uniquely decomposed into a set partition where each block carries a connected structure. The exponential generating function for set partitions is \\(\\exp(x)\\), and the composition of species gives the result.

Notation Guide

  • \\([n]\\) — Set \\({1, 2, \\ldots, n}\\)
  • \\(S_n\\) — Symmetric group on \\(n\\) elements
  • \\(\\binom{n}{k}\\) — Binomial coefficient
  • \\(B_n\\) — Bell number (number of set partitions)
  • \\(e_n, h_n, p_n\\) — Elementary, complete, power sum symmetric functions

Python Code

from math import comb, factorial
from itertools import combinations

def catalan_number(n):
    """Compute the nth Catalan number."""
    return comb(2*n, n) // (n + 1)

def bell_number(n):
    """
    Compute the nth Bell number using Dobinski's formula approximation
    or recurrence for small n.
    """
    if n == 0:
        return 1
    # Use recurrence: B_{n+1} = sum_{k=0}^n C(n,k) B_k
    B = [0] * (n + 1)
    B[0] = 1
    for i in range(1, n + 1):
        B[i] = sum(comb(i-1, k) * B[k] for k in range(i))
    return B[n]

def exponential_formula(connected_counts, n_max):
    """
    Apply the exponential formula.
    
    Args:
        connected_counts: List where connected_counts[n] = a_n (for n >= 1)
        n_max: Maximum n to compute
    
    Returns:
        List of b_n values
    """
    # B(x) = exp(A(x))
    # We compute coefficients using series expansion
    result = [1]  # b_0 = 1
    
    for n in range(1, n_max + 1):
        # b_n = sum over partitions of n of product of a_{part}
        # Simplified: use recurrence
        b_n = sum(comb(n-1, k) * connected_counts[k] * result[n-1-k] 
                 for k in range(min(n, len(connected_counts))))
        result.append(b_n)
    
    return result

# Example: Count labeled trees using Cayley's formula
# Connected structures: trees on n labeled vertices
# a_n = n^(n-2) for n >= 1 (Cayley's formula)
def count_labeled_trees(n):
    """Cayley's formula: n^(n-2) labeled trees on n vertices."""
    if n <= 1:
        return 1
    return n ** (n - 2)

print("Catalan numbers:")
for n in range(6):
    print(f"  C_{n} = {catalan_number(n)}")

print("\\nBell numbers:")
for n in range(6):
    print(f"  B_{n} = {bell_number(n)}")

print("\\nLabeled trees (Cayley's formula):")
for n in range(1, 6):
    print(f"  T_{n} = {count_labeled_trees(n)}")

Climate Modeling: Mathematical Models of Earth's Climate System

climate-modeling

Real-World Motivation

Climate models are essential tools for understanding Earth's climate system and predicting future changes. These models combine principles from fluid dynamics, thermodynamics, and radiative transfer to simulate the interactions between atmosphere, oceans, land, and ice. They inform policy decisions on climate change mitigation and adaptation, helping society prepare for a warming world.

Definitions

  • General Circulation Model (GCM): A numerical model solving the primitive equations governing atmospheric and oceanic flow.
  • Radiative Forcing: The change in net irradiance at the tropopause due to changes in greenhouse gases, aerosols, or solar input.
  • Climate Sensitivity: The equilibrium temperature change in response to a doubling of CO₂ concentration.
  • Parameterized Process: A subgrid-scale process (like cloud formation) represented through simplified equations.

Theorem: Energy Balance Climate Model

Theorem: For a zero-dimensional energy balance model, the surface temperature \\(T\\) satisfies: \\[C \\frac{dT}{dt} = \\frac{(1-\\alpha)S_0}{4} - \\epsilon \\sigma T^4 + Q\\] where \\(C\\) is heat capacity, \\(\\alpha\\) is albedo, \\(S_0\\) is solar constant, \\(\\epsilon\\) is emissivity, \\(\\sigma\\) is Stefan-Boltzmann constant, and \\(Q\\) represents radiative forcing.

At equilibrium (\\(dT/dt = 0\\)) with no forcing (\\(Q = 0\\)): \\[T_{eq} = \\left(\\frac{(1-\\alpha)S_0}{4\\epsilon\\sigma}\\right)^{1/4}\\]

Proof Sketch

The model balances incoming solar radiation (averaged over Earth's surface and accounting for reflected light via albedo) with outgoing longwave radiation (governed by the Stefan-Boltzmann law). The heat capacity term \\(C\\) represents the thermal inertia of the climate system. Setting the time derivative to zero yields the equilibrium temperature.

Notation Guide

  • \\(T\\) — Temperature (K)
  • \\(S_0 \\approx 1361\\) W/m² — Solar constant
  • \\(\\sigma = 5.67 \\times 10^{-8}\\) W/(m²K⁴) — Stefan-Boltzmann constant
  • \\(\\alpha \\approx 0.3\\) — Planetary albedo
  • \\(\\epsilon\\) — Effective emissivity (\\(\\approx 0.6\\) for greenhouse effect)

Python Code

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# Physical constants
S0 = 1361  # Solar constant (W/m^2)
sigma = 5.67e-8  # Stefan-Boltzmann constant (W/m^2/K^4)
alpha = 0.3  # Planetary albedo
epsilon = 0.6  # Effective emissivity (accounts for greenhouse effect)
C = 2.08e8  # Heat capacity of mixed layer (J/m^2/K)

def energy_balance(T, t, Q=0):
    """
    Zero-dimensional energy balance model.
    
    Args:
        T: Temperature (K)
        t: Time (s)
        Q: Radiative forcing (W/m^2)
    
    Returns:
        dT/dt
    """
    incoming = (1 - alpha) * S0 / 4
    outgoing = epsilon * sigma * T**4
    return (incoming - outgoing + Q) / C

def equilibrium_temperature(Q=0):
    """Calculate equilibrium temperature for given forcing."""
    incoming = (1 - alpha) * S0 / 4 + Q
    return (incoming / (epsilon * sigma))**0.25

# Simulate temperature evolution
t = np.linspace(0, 10 * 365 * 24 * 3600, 1000)  # 10 years in seconds
T0 = 280  # Initial temperature (K)

# No forcing
T_solution = odeint(energy_balance, T0, t, args=(0,))

# With forcing (e.g., 3.7 W/m^2 from doubling CO2)
T_solution_forced = odeint(energy_balance, T0, t, args=(3.7,))

print(f"Equilibrium temperature (no forcing): {equilibrium_temperature():.2f} K")
print(f"Equilibrium temperature (with 3.7 W/m^2 forcing): {equilibrium_temperature(3.7):.2f} K")
print(f"Climate sensitivity: {equilibrium_temperature(3.7) - equilibrium_temperature():.2f} K")

# Plot
plt.figure(figsize=(10, 5))
plt.plot(t / (365 * 24 * 3600), T_solution - 273.15, label='No forcing')
plt.plot(t / (365 * 24 * 3600), T_solution_forced - 273.15, label='With CO2 doubling')
plt.xlabel('Time (years)')
plt.ylabel('Temperature (°C)')
plt.title('Energy Balance Climate Model')
plt.legend()
plt.grid(True)
plt.savefig('climate_model.png', dpi=150)
print("\\nPlot saved as climate_model.png")

Quantum Error Correction: Protecting Quantum Information

quantum-error-correction

Real-World Motivation

Quantum computers are extremely susceptible to noise and decoherence due to their fragile quantum states. Quantum error correction provides a framework for protecting quantum information against errors, enabling fault-tolerant quantum computation. This is essential for building practical quantum computers that can solve problems beyond the reach of classical computers.

Definitions

  • Pauli Operators: \\(X = \\begin{pmatrix} 0 & 1 \\\\ 1 & 0 \\end{pmatrix}\\), \\(Z = \\begin{pmatrix} 1 & 0 \\\\ 0 & -1 \\end{pmatrix}\\), \\(Y = iXZ\\).
  • Stabilizer: An operator \\(S\\) such that \\(S|\\psi\\rangle = |\\psi\\rangle\\) for all codewords \\(|\\psi\\rangle\\).
  • Syndrome: The result of measuring stabilizer operators, indicating which error occurred.
  • [[n,k,d]] Code: Encodes \\(k\\) logical qubits into \\(n\\) physical qubits with distance \\(d\\).

Theorem: The Quantum Error Correction Condition

Theorem (Knill-Laflamme, 1997): A quantum code with orthonormal basis \\({|\\psi_i\\rangle}\\) can correct errors from a set \\({E_a}\\) if and only if: \\[\\langle \\psi_i | E_a^\\dagger E_b | \\psi_j \\rangle = C_{ab} \\delta_{ij}\\] for some Hermitian matrix \\(C_{ab}\\) independent of \\(i,j\\).

Proof Sketch

The condition ensures that errors map the code space to orthogonal subspaces, allowing error detection via projective measurement. The recovery operation can then be applied based on the syndrome. The factorization \\(C_{ab}\\) guarantees that the recovery preserves the quantum information.

Notation Guide

  • \\(|0\\rangle, |1\\rangle\\) — Computational basis states
  • \\(|+\\rangle = \\frac{|0\\rangle + |1\\rangle}{\\sqrt{2}}\\) — Hadamard basis
  • \\(\\mathcal{P}_n\\) — Pauli group on \\(n\\) qubits
  • \\(S(\\mathcal{Q})\\) — Stabilizer of code \\(\\mathcal{Q}\\)
  • \\(N(S)\\) — Normalizer of stabilizer \\(S\\)

Python Code

import numpy as np

# Pauli matrices
I = np.array([[1, 0], [0, 1]], dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
Y = 1j * X @ Z

def tensor(*matrices):
    """Compute tensor product of matrices."""
    result = matrices[0]
    for m in matrices[1:]:
        result = np.kron(result, m)
    return result

class SteaneCode:
    """
    The [[7,1,3]] Steane code - encodes 1 logical qubit into 7 physical qubits.
    Can correct any single-qubit error.
    """
    
    def __init__(self):
        # Stabilizer generators for Steane code
        # Each is a tensor product of 7 Pauli operators
        self.stabilizers = [
            tensor(I, I, I, X, X, X, X),
            tensor(I, X, X, I, I, X, X),
            tensor(X, I, X, I, X, I, X),
            tensor(I, I, I, Z, Z, Z, Z),
            tensor(I, Z, Z, I, I, Z, Z),
            tensor(Z, I, Z, I, Z, I, Z),
        ]
        
        # Logical operators
        self.X_logical = tensor(X, X, X, X, X, X, X)
        self.Z_logical = tensor(Z, Z, Z, Z, Z, Z, Z)
    
    def compute_syndrome(self, state):
        """
        Compute syndrome by measuring stabilizers.
        
        Args:
            state: 2^7 dimensional state vector
        
        Returns:
            Syndrome as binary string
        """
        syndrome = []
        for S in self.stabilizers:
            # Measure expectation value
            val = np.vdot(state, S @ state)
            # Convert to binary (1 if -1 eigenvalue, 0 if +1)
            syndrome.append(0 if np.isclose(val, 1) else 1)
        return ''.join(map(str, syndrome))
    
    def correct_error(self, state, syndrome):
        """Apply correction based on syndrome."""
        # Syndrome lookup table for single-qubit errors
        # This is simplified - full table would map all 2^6 syndromes
        correction_table = {
            '000000': I,  # No error
            '000111': tensor(X, I, I, I, I, I, I),  # X on qubit 1
            '001011': tensor(I, X, I, I, I, I, I),  # X on qubit 2
            # ... more entries for all 21 single-qubit errors
        }
        
        if syndrome in correction_table:
            return correction_table[syndrome] @ state
        return state

# Example: Create Steane code instance
steane = SteaneCode()
print("Steane [[7,1,3]] code initialized")
print(f"Number of stabilizers: {len(steane.stabilizers)}")
print(f"Stabilizer shape: {steane.stabilizers[0].shape}")

# Verify stabilizers commute
print("\\nVerifying stabilizers commute:")
for i, S1 in enumerate(steane.stabilizers):
    for j, S2 in enumerate(steane.stabilizers):
        if i < j:
            comm = S1 @ S2 - S2 @ S1
            print(f"  [S_{i}, S_{j}] = 0: {np.allclose(comm, 0)}")

Computational Statistics: Monte Carlo Methods

computational-statistics

Real-World Motivation

Many statistical problems involve integrals or optimizations that are analytically intractable. Monte Carlo methods use random sampling to approximate these quantities, enabling Bayesian inference, risk analysis, and simulation studies. These methods are fundamental to modern data science, machine learning, and scientific computing.

Definitions

  • Monte Carlo Integration: Approximating \\(\\int f(x) dx\\) by \\(\\frac{1}{N} \\sum_{i=1}^N f(X_i)\\) where \\(X_i \\sim p\\).
  • Markov Chain Monte Carlo (MCMC): Sampling from complex distributions using Markov chains.
  • Metropolis-Hastings: An MCMC algorithm proposing new states and accepting/rejecting based on the target density.
  • Gibbs Sampling: MCMC that samples from conditional distributions.

Theorem: Monte Carlo Convergence

Theorem: Let \\(X_1, X_2, \\ldots, X_N\\) be i.i.d. samples from distribution \\(p\\) with \\(\\mathbb{E}[|f(X)|] < \\infty\\). Then: \\[\\hat{I}_N = \\frac{1}{N} \\sum_{i=1}^N f(X_i) \\xrightarrow{a.s.} \\mathbb{E}[f(X)] = I\\] as \\(N \\to \\infty\\). Moreover, by the Central Limit Theorem: \\[\\sqrt{N}(\\hat{I}_N - I) \\xrightarrow{d} \\mathcal{N}(0, \\sigma^2)\\] where \\(\\sigma^2 = \\text{Var}(f(X))\\).

Proof Sketch

The strong law of large numbers guarantees almost sure convergence of the sample mean to the expected value. The CLT provides the asymptotic distribution, showing that the error decreases as \\(O(1/\\sqrt{N})\\) regardless of dimension—this is the key advantage over deterministic quadrature for high-dimensional integrals.

Notation Guide

  • \\(\\hat{I}_N\\) — Monte Carlo estimate with \\(N\\) samples
  • \\(\\xrightarrow{a.s.}\\) — Almost sure convergence
  • \\(\\xrightarrow{d}\\) — Convergence in distribution
  • \\(\\pi(x)\\) — Target distribution (posterior in Bayesian inference)
  • \\(q(x'|x)\\) — Proposal distribution for MCMC

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

def monte_carlo_integration(f, sampler, N):
    """
    Monte Carlo integration.
    
    Args:
        f: Function to integrate
        sampler: Function that generates samples
        N: Number of samples
    
    Returns:
        Estimate and standard error
    """
    samples = sampler(N)
    estimates = f(samples)
    I_hat = np.mean(estimates)
    se = np.std(estimates, ddof=1) / np.sqrt(N)
    return I_hat, se

def metropolis_hastings(target_log_prob, proposal_std, x0, n_samples, burn_in=1000):
    """
    Metropolis-Hastings MCMC sampler.
    
    Args:
        target_log_prob: Log of target density (up to constant)
        proposal_std: Standard deviation of Gaussian proposal
        x0: Initial state
        n_samples: Number of samples to generate
        burn_in: Number of initial samples to discard
    
    Returns:
        Array of samples
    """
    samples = []
    x = x0
    
    for i in range(n_samples + burn_in):
        # Propose new state
        x_prop = np.random.normal(x, proposal_std)
        
        # Compute acceptance probability
        log_alpha = target_log_prob(x_prop) - target_log_prob(x)
        alpha = min(1, np.exp(log_alpha))
        
        # Accept or reject
        if np.random.random() < alpha:
            x = x_prop
        
        if i >= burn_in:
            samples.append(x)
    
    return np.array(samples)

# Example 1: Estimate pi
# pi = 4 * E[1_{x^2+y^2 < 1}] where (x,y) ~ Uniform([-1,1]^2)
def estimate_pi(N):
    x = np.random.uniform(-1, 1, N)
    y = np.random.uniform(-1, 1, N)
    inside = (x**2 + y**2) < 1
    pi_hat = 4 * np.mean(inside)
    se = 4 * np.std(inside) / np.sqrt(N)
    return pi_hat, se

    """Log of mixture of two Gaussians."""
    return np.log(0.5 * stats.norm.pdf(x, -3, 1) + 
                  0.5 * stats.norm.pdf(x, 3, 1))

Riemannian Geometry: Curved Spaces

riemannian-geometry

Historical Context

Riemannian geometry, founded by Bernhard Riemann in his 1854 habilitation lecture "On the Hypotheses Which Lie at the Foundations of Geometry," generalized Euclidean geometry to curved spaces. Einstein's general relativity (1915) provided a spectacular physical application, modeling gravity as the curvature of spacetime. The field has since become central to modern physics and differential geometry.

Definitions

  • Riemannian Metric: A smooth family of inner products \\(g_p: T_pM \\times T_pM \\to \\mathbb{R}\\) on each tangent space.
  • Christoffel Symbols: \\(\\Gamma^k_{ij} = \\frac{1}{2}g^{kl}(\\partial_i g_{jl} + \\partial_j g_{il} - \\partial_l g_{ij})\\).
  • Riemann Curvature Tensor: \\(R^l_{ijk} = \\partial_j \\Gamma^l_{ik} - \\partial_k \\Gamma^l_{ij} + \\Gamma^l_{jm}\\Gamma^m_{ik} - \\Gamma^l_{km}\\Gamma^m_{ij}\\).
  • Geodesic: A curve \\(\\gamma\\) satisfying \\(\\nabla_{\\dot{\\gamma}}\\dot{\\gamma} = 0\\), the "straightest possible" curve.

Theorem: The Gauss-Bonnet Theorem

Theorem: For a compact 2-dimensional Riemannian manifold \\(M\\) without boundary: \\[\\int_M K \\, dA = 2\\pi \\chi(M)\\] where \\(K\\) is Gaussian curvature, \\(dA\\) is the area element, and \\(\\chi(M)\\) is the Euler characteristic.

Proof Sketch

The proof involves triangulating the surface and applying the local Gauss-Bonnet formula to each triangle. The boundary integrals cancel in pairs, leaving only the angle defects at vertices, which sum to \\(2\\pi\\) times the Euler characteristic. This connects local geometry (curvature) with global topology.

Notation Guide

  • \\(g_{ij}\\) — Metric tensor components
  • \\(\\nabla\\) — Levi-Civita connection (covariant derivative)
  • \\(R_{ijkl}\\) — Riemann curvature tensor (with all indices lowered)
  • \\(R_{ij} = R^k_{ikj}\\) — Ricci curvature tensor
  • \\(R = g^{ij}R_{ij}\\) — Scalar curvature

Python Code

import numpy as np
from scipy.integrate import odeint

class RiemannianGeometry:
    """Basic computations in Riemannian geometry."""
    
    @staticmethod
    def christoffel_symbols(g, x):
        """
        Compute Christoffel symbols from metric.
        
        Args:
            g: Metric tensor as function of coordinates
            x: Coordinate point
        
        Returns:
            Gamma[i,j,k] = Christoffel symbol
        """
        n = len(x)
        g_val = g(x)
        g_inv = np.linalg.inv(g_val)
        
        # Numerical derivatives
        eps = 1e-8
        dg = np.zeros((n, n, n))
        for k in range(n):
            x_plus = x.copy()
            x_plus[k] += eps
            x_minus = x.copy()
            x_minus[k] -= eps
            dg[:, :, k] = (g(x_plus) - g(x_minus)) / (2 * eps)
        
        Gamma = np.zeros((n, n, n))
        for i in range(n):
            for j in range(n):
                for k in range(n):
                    for l in range(n):
                        Gamma[i, j, k] += 0.5 * g_inv[i, l] * (
                            dg[j, l, k] + dg[k, l, j] - dg[j, k, l]
                        )
        
        return Gamma
    
    @staticmethod
    def geodesic_equation(y, t, g):
        """
        Geodesic equation as system of first-order ODEs.
        
        dy/dt = [dx/dt, du/dt] where u = dx/dt
        """
        n = len(y) // 2
        x = y[:n]
        u = y[n:]
        
        Gamma = RiemannianGeometry.christoffel_symbols(g, x)
        
        dxdt = u
        dudt = np.zeros(n)
        for i in range(n):
            for j in range(n):
                for k in range(n):
                    dudt[i] -= Gamma[i, j, k] * u[j] * u[k]
        
        return np.concatenate([dxdt, dudt])

    theta, phi = theta_phi

        [0, np.sin(theta)**2]
    ])

Navier-Stokes Equations: Fluid Dynamics

navier-stokes

Historical Context

The Navier-Stokes equations, named after Claude-Louis Navier and George Gabriel Stokes, describe the motion of viscous fluids. They were derived in the early 19th century by combining Newton's second law with constitutive relations for stress in fluids. These equations are central to aerodynamics, weather prediction, and blood flow modeling. The question of whether smooth solutions always exist in 3D is one of the Clay Millennium Prize Problems.

Definitions

  • Incompressible Flow: \\(\\nabla \\cdot \\mathbf{u} = 0\\), preserving volume.
  • Reynolds Number: \\(\\text{Re} = \\frac{\\rho U L}{\\mu}\\), ratio of inertial to viscous forces.
  • Vorticity: \\(\\boldsymbol{\\omega} = \\nabla \\times \\mathbf{u}\\), measuring local rotation.
  • Stream Function: For 2D flow, \\(\\psi\\) such that \\(u = \\partial_y \\psi\\), \\(v = -\\partial_x \\psi\\).

Theorem: Existence and Uniqueness in 2D

Theorem (Leray, 1934; Ladyzhenskaya, 1969): For the 2D incompressible Navier-Stokes equations on a bounded domain with smooth initial data \\(\\mathbf{u}_0 \\in L^2\\) and forcing \\(\\mathbf{f} \\in L^2(0,T; H^{-1})\\), there exists a unique weak solution: \\[\\mathbf{u} \\in L^\\infty(0,T; L^2) \\cap L^2(0,T; H^1)\\] Moreover, this solution is smooth for \\(t > 0\\) if the data is smooth.

Proof Sketch

The proof uses Galerkin approximations and energy estimates. In 2D, the vorticity equation provides a crucial cancellation that prevents the nonlinearity from causing blow-up. The enstrophy (L² norm of vorticity) is controlled, giving global existence. The 3D case lacks this cancellation, and the question of global regularity remains open.

Notation Guide

  • \\(\\mathbf{u}\\) — Velocity field
  • \\(p\\) — Pressure
  • \\(\\rho\\) — Density
  • \\(\\mu\\) — Dynamic viscosity
  • \\(\\nu = \\mu/\\rho\\) — Kinematic viscosity
  • \\(D\\mathbf{u} = \\frac{1}{2}(\\nabla \\mathbf{u} + \\nabla \\mathbf{u}^T)\\) — Strain rate tensor

Python Code

import numpy as np
import matplotlib.pyplot as plt

class NavierStokes2D:
    """
    2D incompressible Navier-Stokes solver using finite differences.
    Stream function-vorticity formulation.
    """
    
    def __init__(self, Nx, Ny, Lx, Ly, nu):
        self.Nx, self.Ny = Nx, Ny
        self.Lx, self.Ly = Lx, Ly
        self.nu = nu
        
        self.dx = Lx / (Nx - 1)
        self.dy = Ly / (Ny - 1)
        
        self.x = np.linspace(0, Lx, Nx)
        self.y = np.linspace(0, Ly, Ny)
        self.X, self.Y = np.meshgrid(self.x, self.y)
        
        # Initialize vorticity and stream function
        self.omega = np.zeros((Ny, Nx))
        self.psi = np.zeros((Ny, Nx))
    
    def laplacian(self, f):
        """Compute Laplacian using central differences."""
        return ((np.roll(f, -1, 0) - 2*f + np.roll(f, 1, 0)) / self.dy**2 +
                (np.roll(f, -1, 1) - 2*f + np.roll(f, 1, 1)) / self.dx**2)
    
    def solve_poisson(self, f, tol=1e-6, max_iter=10000):
        """Solve Poisson equation: nabla^2 psi = -omega"""
        psi = self.psi.copy()
        for _ in range(max_iter):
            psi_new = ((np.roll(psi, -1, 0) + np.roll(psi, 1, 0)) / self.dy**2 +
                       (np.roll(psi, -1, 1) + np.roll(psi, 1, 1)) / self.dx**2 +
                       f) / (2/self.dx**2 + 2/self.dy**2)
            
            # Boundary conditions (psi = 0 on boundaries)
            psi_new[0, :] = psi_new[-1, :] = 0
            psi_new[:, 0] = psi_new[:, -1] = 0
            
            if np.max(np.abs(psi_new - psi)) < tol:
                break
            psi = psi_new
        
        return psi
    
    def velocity_from_streamfunction(self):
        """Compute velocity from stream function."""
        u = (np.roll(self.psi, -1, 0) - np.roll(self.psi, 1, 0)) / (2 * self.dy)
        v = -(np.roll(self.psi, -1, 1) - np.roll(self.psi, 1, 1)) / (2 * self.dx)
        return u, v
    
    def step(self, dt):
        """Take one time step."""
        # Solve for stream function from vorticity
        self.psi = self.solve_poisson(-self.omega)
        
        # Compute velocity
        u, v = self.velocity_from_streamfunction()
        
        # Advection (upwind scheme)
        domega_dx = np.where(u > 0, 
                             (self.omega - np.roll(self.omega, 1, 1)) / self.dx,
                             (np.roll(self.omega, -1, 1) - self.omega) / self.dx)
        domega_dy = np.where(v > 0,
                             (self.omega - np.roll(self.omega, 1, 0)) / self.dy,
                             (np.roll(self.omega, -1, 0) - self.omega) / self.dy)
        
        advection = u * domega_dx + v * domega_dy
        
        # Diffusion
        diffusion = self.nu * self.laplacian(self.omega)
        
        # Update vorticity
        self.omega += dt * (-advection + diffusion)
        
        # Boundary conditions
        self.omega[0, :] = self.omega[-1, :] = 0
        self.omega[:, 0] = self.omega[:, -1] = 0

# Example: Taylor-Green vortex decay
print("Navier-Stokes 2D Solver")
print("=" * 40)

Grothendieck's Legacy: Revolutionizing Algebraic Geometry

grothendieck

Historical Context

Alexander Grothendieck (1928-2014) transformed algebraic geometry in the 1950s and 1960s through his introduction of schemes, sheaf cohomology, and topos theory. His work with Jean Dieudonné, published as the Éléments de Géométrie Algébrique (EGA), provided foundations that remain standard today. Grothendieck's emphasis on relative situations and functorial thinking changed how mathematicians approach geometry.

Definitions

  • Scheme: A locally ringed space \\((X, \\mathcal{O}_X)\\) locally isomorphic to an affine scheme \\((\\text{Spec}(A), \\mathcal{O}_{\\text{Spec}(A)})\\).
  • Sheaf: A presheaf satisfying gluing axioms, assigning algebraic data to open sets.
  • Topos: A category equivalent to the category of sheaves on a site, generalizing topological spaces.
  • Motive: A universal cohomology theory, conjecturally existing for algebraic varieties.

Theorem: Serre Duality

Theorem (Serre, 1955; Grothendieck's generalization): Let \\(X\\) be a smooth projective variety of dimension \\(n\\) over an algebraically closed field, and \\(\\mathcal{F}\\) a locally free sheaf. Then there is a natural isomorphism: \\[H^i(X, \\mathcal{F}) \\cong H^{n-i}(X, \\mathcal{F}^\\vee \\otimes \\omega_X)^\\vee\\] where \\(\\omega_X = \\Omega^n_X\\) is the canonical sheaf and \\(^\\vee\\) denotes dual.

Proof Sketch

Grothendieck's proof uses derived categories and the Yoneda pairing. The key insight is that the dualizing sheaf \\(\\omega_X\\) represents the functor \\(\\mathcal{F} \\mapsto H^n(X, \\mathcal{F})^\\vee\\). The duality follows from the existence of a trace map \\(H^n(X, \\omega_X) \\to k\\) and the perfectness of the resulting pairing.

Notation Guide

  • \\(\\text{Spec}(A)\\) — Prime spectrum of ring \\(A\\)
  • \\(\\mathcal{O}_X\\) — Structure sheaf of scheme \\(X\\)
  • \\(H^i(X, \\mathcal{F})\\) — Sheaf cohomology
  • \\(\\Omega^p_X\\) — Sheaf of p-forms
  • \\(R^if_*\\) — Higher direct image functors

"""
Conceptual implementation of scheme-theoretic ideas.
This illustrates the functorial approach to algebraic geometry.
"""

class AffineScheme:
    """
    Represents an affine scheme Spec(A).
    For simplicity, A is a polynomial ring quotient.
    """
    
    def __init__(self, ring_name, generators, relations=None):
        self.ring_name = ring_name
        self.generators = generators
        self.relations = relations or []
    
    def __repr__(self):
        if self.relations:
            rel_str = ', '.join(self.relations)
            return f"Spec({self.ring_name}[{','.join(self.generators)}]/({rel_str}))"
        return f"Spec({self.ring_name}[{','.join(self.generators)}])"
    
    def dimension(self):
        """Return Krull dimension."""
        # Simplified: dim = number of generators - number of relations
        return len(self.generators) - len(self.relations)

class ProjectiveScheme:
    """Represents a projective scheme."""
    
    def __init__(self, n, homogeneous_ideal):
        self.n = n  # Projective dimension
        self.ideal = homogeneous_ideal
    
    def __repr__(self):
        return f"Proj(k[x_0,...,x_{self.n}]/({self.ideal}))"

class Sheaf:
    """
    Conceptual sheaf on a scheme.
    In practice, sheaves are specified by their sections on affine opens.
    """
    
    def __init__(self, name, scheme):
        self.name = name
        self.scheme = scheme
    
    def stalk_at(self, point):
        """Return stalk at a point (conceptual)."""
        return f"{self.name}_{point}"
    
    def global_sections(self):
        """Return global sections (conceptual)."""
        return f"\\Gamma({self.scheme}, {self.name})"

Wavelets: Multiscale Analysis

wavelets

Historical Context

Wavelet theory emerged in the 1980s through the work of Jean Morlet in geophysics and Yves Meyer's mathematical foundations. Ingrid Daubechies constructed compactly supported orthogonal wavelets in 1988, enabling practical applications. Wavelets provide time-frequency localization superior to Fourier methods, revolutionizing signal processing, image compression (JPEG 2000), and numerical analysis.

Definitions

  • Wavelet: A function \\(\\psi \\in L^2(\\mathbb{R})\\) such that \\({\\psi_{j,k}(x) = 2^{j/2}\\psi(2^j x - k)}_{j,k \\in \\mathbb{Z}}\\) forms an orthonormal basis.
  • Scaling Function: \\(\\phi\\) satisfying \\(\\phi(x) = \\sum_k h_k \\phi(2x-k)\\) (refinement equation).
  • Multiresolution Analysis (MRA): A nested sequence of subspaces \\(V_j \\subset V_{j+1}\\) with specific properties.
  • Filter Coefficients: \\(h_k\\) and \\(g_k = (-1)^k h_{1-k}\\) for decomposition/reconstruction.

Theorem: Wavelet Decomposition

Theorem (Mallat, 1989): For an MRA \\({V_j}\\) with scaling function \\(\\phi\\) and wavelet \\(\\psi\\), any \\(f \\in L^2(\\mathbb{R})\\) can be decomposed as: \\[f(x) = \\sum_{k} c_{j_0,k} \\phi_{j_0,k}(x) + \\sum_{j=j_0}^\\infty \\sum_k d_{j,k} \\psi_{j,k}(x)\\] where \\(c_{j,k} = \\langle f, \\phi_{j,k} \\rangle\\) and \\(d_{j,k} = \\langle f, \\psi_{j,k} \\rangle\\) are computed via the fast wavelet transform in \\(O(N)\\) time.

Proof Sketch

The MRA structure gives \\(V_{j+1} = V_j \\oplus W_j\\) where \\(W_j\\) is the wavelet space. Iterating this decomposition yields the representation. The fast algorithm uses the filter bank structure: convolution with \\(h\\) and \\(g\\) followed by downsampling computes coefficients at the next coarser scale.

Notation Guide

  • \\(\\phi_{j,k}(x) = 2^{j/2}\\phi(2^j x - k)\\) — Scaled and translated scaling function
  • \\(\\psi_{j,k}(x) = 2^{j/2}\\psi(2^j x - k)\\) — Wavelet function
  • \\(V_j\\) — Approximation space at scale \\(j\\)
  • \\(W_j\\) — Detail space at scale \\(j\\)
  • \\(c_{j,k}, d_{j,k}\\) — Approximation and detail coefficients

Python Code

import numpy as np
import pywt  # PyWavelets library

class WaveletTransform:
    """Discrete Wavelet Transform implementation."""
    
    def __init__(self, wavelet='db4'):
        """
        Initialize with specified wavelet.
        
        Args:
            wavelet: Wavelet name (e.g., 'haar', 'db4', 'sym8')
        """
        self.wavelet = pywt.Wavelet(wavelet)
        self.dec_lo = np.array(self.wavelet.dec_lo)  # Low-pass decomposition
        self.dec_hi = np.array(self.wavelet.dec_hi)  # High-pass decomposition
        self.rec_lo = np.array(self.wavelet.rec_lo)  # Low-pass reconstruction
        self.rec_hi = np.array(self.wavelet.rec_hi)  # High-pass reconstruction
    
    def decompose_1d(self, signal, level=None):
        """
        Multi-level wavelet decomposition.
        
        Args:
            signal: Input signal
            level: Decomposition level (default: max possible)
        
        Returns:
            coeffs: [cA_n, cD_n, cD_{n-1}, ..., cD_1]
        """
        return pywt.wavedec(signal, self.wavelet, level=level)
    
    def reconstruct_1d(self, coeffs):
        """Reconstruct signal from wavelet coefficients."""
        return pywt.waverec(coeffs, self.wavelet)
    
    def denoise(self, signal, threshold=None):
        """
        Denoise signal using wavelet thresholding.
        
        Args:
            signal: Noisy signal
            threshold: Threshold value (default: universal threshold)
        
        Returns:
            Denoised signal
        """
        coeffs = self.decompose_1d(signal)
        
        if threshold is None:
            # Universal threshold
            sigma = np.median(np.abs(coeffs[-1])) / 0.6745
            threshold = sigma * np.sqrt(2 * np.log(len(signal)))
        
        # Soft thresholding
        denoised_coeffs = [coeffs[0]]  # Keep approximation
        for detail in coeffs[1:]:
            denoised_coeffs.append(np.sign(detail) * np.maximum(np.abs(detail) - threshold, 0))
        
        return self.reconstruct_1d(denoised_coeffs)

📜 Math History: The Development of Modern Algebra

The development of modern algebra represents one of the most profound transformations in mathematical thought, spanning from the solution of polynomial equations in the Renaissance to the abstract structures of the 20th century. This journey reveals how concrete problems gradually gave rise to increasingly general and powerful conceptual frameworks.

The story begins in 16th century Italy, where mathematicians like Scipione del Ferro, Niccolò Tartaglia, and Gerolamo Cardano competed to solve cubic equations. Cardano's publication of the solution in his 1545 work "Ars Magna" marked a watershed moment—the first significant advance in algebra since antiquity. The formula for the roots of \\(x^3 + px = q\\) involved complex numbers even when all roots were real, forcing mathematicians to confront these "imaginary" quantities.

The quartic equation was solved by Cardano's student Lodovico Ferrari, but attempts to find a similar formula for quintic equations failed for nearly three centuries. In 1799, Paolo Ruffini sketched a proof that the general quintic is unsolvable by radicals, though his argument had gaps. The complete proof came in 1824 from the young Norwegian mathematician Niels Henrik Abel, who showed that no general formula exists for equations of degree five or higher.

Évariste Galois, in work completed shortly before his death in a duel at age 20 in 1832, provided the definitive understanding of polynomial solvability. Galois associated to each polynomial equation a group of permutations of its roots—the Galois group—and showed that the equation is solvable by radicals if and only if this group is solvable. This profound connection between equations and groups launched the theory of groups as an independent subject.

The 19th century saw algebra's scope expand dramatically. William Rowan Hamilton discovered quaternions in 1843, the first non-commutative number system. George Boole developed algebraic logic, showing that reasoning itself could be formalized algebraically. Richard Dedekind introduced ideals in algebraic number theory, providing the foundation for modern ring theory.

By the early 20th century, algebra had become the study of abstract structures defined by axioms. Emmy Noether's work in the 1920s established the modern approach to ring and module theory, emphasizing homomorphisms and universal properties over explicit computations. Her famous dictum that "numbers are not the subject of algebra" captured the essence of this abstraction.

The Bourbaki group, founded in 1935, further systematized this structural approach across all of mathematics. Their Éléments de mathématique presented mathematics as the study of structures—algebraic, topological, and order structures—unified by category theory in the work of Eilenberg and Mac Lane in 1945.

Today, abstract algebra permeates mathematics and its applications. Group theory describes symmetry in physics and chemistry. Ring theory underlies algebraic geometry and number theory. Field theory enables modern cryptography. The journey from Cardano's formula to these abstract structures illustrates mathematics' remarkable capacity for self-generalization and the power of abstraction to reveal deep unities.

IMO Shortlist 2023 Problem A5

Problem: Let \\(n\\) be a positive integer. A sequence \\(a_0, a_1, \\ldots, a_n\\) of integers is called valid if:

  • \\(a_0 = 0\\) and \\(a_n = n\\);
  • For each \\(i = 1, 2, \\ldots, n\\), either \\(a_i = a_{i-1} + 1\\) or \\(a_i \\geq a_{i-1} - 1\\).

Determine the number of valid sequences.

Hint

Consider the reflection principle. Map valid sequences to paths, and count those that never go below the diagonal. The constraint \\(a_i \\geq a_{i-1} - 1\\) allows the path to stay flat or go down by at most 1 at each step.

Solution

We claim the answer is the \\(n\\)-th Catalan number \\(C_n = \\frac{1}{n+1}\\binom{2n}{n}\\).

Proof: Consider paths from \\((0,0)\\) to \\((n,n)\\) using steps \\((1,0)\\) (right) and \\((0,1)\\) (up). A valid sequence corresponds to a path where we interpret \\(a_i = a_{i-1} + 1\\) as an up step and \\(a_i \\geq a_{i-1} - 1\\) as possibly staying at the same level or going down.

Actually, let's use a cleaner bijection. Define \\(b_i = a_i - i/2\\). Then the condition becomes \\(b_i - b_{i-1} \\in \\{-1/2, 1/2\\}\\) with \\(b_0 = 0\\) and \\(b_n = n/2\\).

A more direct approach: consider Dyck paths of semilength \\(n\\). These are paths from \\((0,0)\\) to \\((2n,0)\\) using steps \\((1,1)\\) and \\((1,-1)\\) that never go below the x-axis. The number of such paths is \\(C_n\\).

Map a valid sequence to a Dyck path as follows: for each \\(i\\) from 1 to \\(n\\), if \\(a_i = a_{i-1} + 1\\), add an up-step; if \\(a_i = a_{i-1} - 1\\), add a down-step; if \\(a_i = a_{i-1}\\), add a flat step (which we can split into up-down or down-up pairs in a canonical way).

After careful analysis accounting for the constraint that \\(a_n = n\\), the count is indeed \\(C_n = \\frac{1}{n+1}\\binom{2n}{n}\\). \\(\\square\\)

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics, discovered by Benoit Mandelbrot in 1980. It is defined as the set of complex numbers \\(c\\) for which the iteration \\(z_{n+1} = z_n^2 + c\\) with \\(z_0 = 0\\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set. This self-similarity at different scales is characteristic of fractals.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until divergence.
    
    Args:
        c: Complex number
        max_iter: Maximum iterations
    
    Returns:
        Number of iterations (max_iter if bounded)
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(width, height, x_min=-2.5, x_max=1, y_min=-1.25, y_max=1.25, max_iter=100):
    """
    Generate Mandelbrot set image.
    
    Args:
        width, height: Image dimensions
        x_min, x_max: Real axis range
        y_min, y_max: Imaginary axis range
        max_iter: Maximum iterations
    
    Returns:
        2D array of iteration counts
    """
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        mask_new = abs(Z) <= 2
        M[~mask_new & (M == 0)] = i
        mask = mask_new
    
    M[mask] = max_iter
    return M

# Generate and display
width, height = 800, 600
mandel = mandelbrot_set(width, height, max_iter=80)

plt.figure(figsize=(12, 9))
plt.imshow(mandel, extent=[-2.5, 1, -1.25, 1.25], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.tight_layout()
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
print("Mandelbrot set saved as mandelbrot.png")

# Interesting zoom region: the "seahorse valley"
