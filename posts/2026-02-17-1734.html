Spectral Graph Theory: Eigenvalues and Graph Structure

Motivation

Spectral graph theory connects linear algebra with combinatorics by studying graphs through the eigenvalues of matrices associated with them. This approach has revolutionized network analysis, clustering algorithms, and the study of expander graphs with applications in computer science and beyond.

Definitions

Adjacency Matrix: For a graph \(G = (V, E)\) with \(n\) vertices, the adjacency matrix \(A\) is the \(n \times n\) matrix where \(A_{ij} = 1\) if \(\{i,j\} \in E\) and \(0\) otherwise.

Laplacian Matrix: \(L = D - A\) where \(D\) is the diagonal degree matrix with \(D_{ii} = \deg(v_i)\).

Normalized Laplacian: \(\mathcal{L} = D^{-1/2} L D^{-1/2} = I - D^{-1/2} A D^{-1/2}\).

Spectral Gap: The difference \(\lambda_2 - \lambda_1\) between the first and second eigenvalues of the Laplacian.

Theorem (Cheeger's Inequality)

For any connected graph \(G\) with normalized Laplacian eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\):

\[\frac{\lambda_2}{2} \leq \phi(G) \leq \sqrt{2\lambda_2}\]

where \(\phi(G)\) is the Cheeger constant (isoperimetric number), measuring the "bottleneckedness" of the graph.

Proof Sketch

Lower bound: For any subset \(S\), the Rayleigh quotient of the indicator vector gives \(\lambda_2 \leq \frac{x^T L x}{x^T x} = \frac{|\partial S|}{|S|} + \frac{|\partial S|}{|V \setminus S|}\). Optimizing over \(S\) yields \(\lambda_2 \leq 2\phi(G)\).

Upper bound: Given the eigenvector \(v_2\) for \(\lambda_2\), sweep through level sets to find a cut with conductance at most \(\sqrt{2\lambda_2}\).

Notation Guide

  • \(A\) — Adjacency matrix
  • \(L\) — Laplacian matrix
  • \(\lambda_i\) — \(i\)-th eigenvalue
  • \(\phi(G)\) — Cheeger constant
  • \(\partial S\) — Edge boundary of set \(S\)

import numpy as np
import networkx as nx
from scipy.sparse.linalg import eigsh

def spectral_clustering(G, k=2):
    """
    Perform spectral clustering on graph G.
    Returns cluster assignments for each node.
    """
    # Compute normalized Laplacian
    L = nx.normalized_laplacian_matrix(G).astype(float)
    
    # Compute first k eigenvectors
    eigenvalues, eigenvectors = eigsh(L, k=k, which='SM')
    
    # Use k-means on the eigenvector embedding
    from sklearn.cluster import KMeans
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = kmeans.fit_predict(eigenvectors)
    
    return labels, eigenvalues

def cheeger_constant(G):
    """Estimate the Cheeger constant of a graph."""
    n = G.number_of_nodes()
    min_conductance = float('inf')
    
    for size in range(1, n // 2 + 1):
        for nodes in itertools.combinations(G.nodes(), size):
            S = set(nodes)
            boundary = nx.edge_boundary(G, S)
            vol_S = sum(G.degree(v) for v in S)
            vol_comp = sum(G.degree(v) for v in G.nodes() if v not in S)
            if vol_S > 0 and vol_comp > 0:
                conductance = len(boundary) / min(vol_S, vol_comp)
                min_conductance = min(min_conductance, conductance)
    
    return min_conductance

Homotopy Groups: The Fundamental Invariants of Topology

Motivation

Homotopy groups classify topological spaces by studying continuous deformations of spheres into the space. While homology groups are computable, homotopy groups capture finer geometric information and remain an active area of research with deep connections to algebraic geometry and mathematical physics.

Definitions

Homotopy: Two continuous maps \(f, g: X \to Y\) are homotopic if there exists a continuous map \(H: X \times [0,1] \to Y\) with \(H(x,0) = f(x)\) and \(H(x,1) = g(x)\).

nth Homotopy Group: \(\pi_n(X, x_0)\) is the set of homotopy classes of maps \((S^n, s_0) \to (X, x_0)\) with group operation given by concatenation (for \(n \geq 1\)).

Simply Connected: A space is simply connected if \(\pi_1(X) = 0\).

Theorem (Hurewicz Isomorphism)

If \(X\) is \((n-1)\)-connected (i.e., \(\pi_k(X) = 0\) for \(k < n\)), then the Hurewicz homomorphism \(h: \pi_n(X) \to H_n(X; \mathbb{Z})\) is an isomorphism.

Proof Sketch

The Hurewicz map sends a homotopy class \([f]\) to the homology class of the pushforward of the fundamental class of \(S^n\). For simply connected spaces, one constructs an inverse by representing homology classes by maps from spheres, using the fact that in the simply connected case, homotopy classes correspond to homology classes.

Notation Guide

  • \(\pi_n(X, x_0)\) — nth homotopy group
  • \(S^n\) — n-dimensional sphere
  • \([f]\) — Homotopy class of map \(f\)
  • \(h\) — Hurewicz homomorphism
  • \(\simeq\) — Homotopic to

def fundamental_group_approximation(points, base_point_idx=0, n_loops=100):
    """
    Approximate the fundamental group of a point cloud.
    This is a simplified demonstration using persistent homology concepts.
    """
    n = len(points)
    distances = cdist(points, points)
    
    # Build Rips complex at varying scales
    def build_graph(epsilon):
        adjacency = (distances <= epsilon).astype(int)
        np.fill_diagonal(adjacency, 0)
        return adjacency
    
    # Find cycles using BFS
    def find_cycles(adjacency, max_length=6):
        cycles = []
        n = len(adjacency)
        
        for start in range(n):
            # BFS to find shortest cycles through start
            visited = {start: [start]}
            queue = [start]
            
            while queue and len(visited) < max_length * n:
                current = queue.pop(0)
                path = visited[current]
                
                if len(path) > 1:
                    # Check if we can return to start
                    if adjacency[current, start] == 1 and len(path) >= 3:
                        cycles.append(path + [start])
                
                if len(path) < max_length:
                    for neighbor in range(n):
                        if adjacency[current, neighbor] == 1 and neighbor not in visited:
                            visited[neighbor] = path + [neighbor]
                            queue.append(neighbor)
        
        return cycles
    
    # Analyze at different scales
    betti_1_estimates = []
    for eps in np.linspace(0.1, 2.0, 20):
        adj = build_graph(eps)
        cycles = find_cycles(adj)
        # Simplified: count independent cycles
        betti_1_estimates.append(len(cycles) // 3)
    
    return betti_1_estimates

p-adic Numbers: Analytic Number Theory in a Non-Archimedean World

Motivation

The p-adic numbers, introduced by Hensel in the late 19th century, provide an alternative completion of the rational numbers. Unlike the real numbers which measure "distance from zero," p-adic numbers measure divisibility by a prime \(p\), leading to a rich theory with applications in number theory, algebraic geometry, and even physics.

Definitions

p-adic Valuation: For a prime \(p\) and integer \(n\), \(\nu_p(n)\) is the highest power of \(p\) dividing \(n\). For \(x = a/b \in \mathbb{Q}\), \(\nu_p(x) = \nu_p(a) - \nu_p(b)\).

p-adic Absolute Value: \(|x|_p = p^{-\nu_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\).

p-adic Numbers: \(\mathbb{Q}_p\) is the completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\). Elements have unique expansions \(x = \sum_{k=m}^{\infty} a_k p^k\) where \(a_k \in \{0, 1, \ldots, p-1\}\).

p-adic Integers: \(\mathbb{Z}_p = \{x \in \mathbb{Q}_p : |x|_p \leq 1\}\).

Theorem (Hensel's Lemma)

Let \(f(x) \in \mathbb{Z}_p[x]\) and suppose there exists \(\alpha_0 \in \mathbb{Z}_p\) such that:

\[|f(\alpha_0)|_p < |f'(\alpha_0)|_p^2\]

Then there exists a unique \(\alpha \in \mathbb{Z}_p\) such that \(f(\alpha) = 0\) and \(|\alpha - \alpha_0|_p < |f'(\alpha_0)|_p\).

Proof Sketch

The proof uses Newton's method in the p-adic setting. Define \(\alpha_{n+1} = \alpha_n - \frac{f(\alpha_n)}{f'(\alpha_n)}\). The condition ensures that \(|f(\alpha_n)|_p \to 0\) and \(\{\alpha_n\}\) is Cauchy, hence converges to a root.

Notation Guide

  • \(\nu_p(x)\) — p-adic valuation
  • \(|x|_p\) — p-adic absolute value
  • \(\mathbb{Q}_p\) — Field of p-adic numbers
  • \(\mathbb{Z}_p\) — Ring of p-adic integers
  • \(\mathbb{C}_p\) — Completion of algebraic closure of \(\mathbb{Q}_p\)

class PAdicNumber:
    """
    Represents a p-adic number with finite precision.
    Stores expansion: sum of a_k * p^k for k >= min_exp
    """
    def __init__(self, p, coefficients, min_exp=0):
        self.p = p
        self.coeffs = coefficients  # List of digits
        self.min_exp = min_exp
        self.precision = len(coefficients)
    
    def valuation(self):
        """Return the p-adic valuation."""
        for i, c in enumerate(self.coeffs):
            if c != 0:
                return self.min_exp + i
        return float('inf')
    
    def norm(self):
        """Return the p-adic absolute value."""
        v = self.valuation()
        if v == float('inf'):
            return 0
        return self.p ** (-v)
    
    def __add__(self, other):
        """Add two p-adic numbers."""
        assert self.p == other.p
        min_e = min(self.min_exp, other.min_exp)
        max_prec = max(self.min_exp + len(self.coeffs),
                       other.min_exp + len(other.coeffs)) - min_e
        
        result = []
        carry = 0
        for i in range(max_prec):
            exp = min_e + i
            a = self.coeffs[exp - self.min_exp] if self.min_exp <= exp < self.min_exp + len(self.coeffs) else 0
            b = other.coeffs[exp - other.min_exp] if other.min_exp <= exp < other.min_exp + len(other.coeffs) else 0
            s = a + b + carry
            result.append(s % self.p)
            carry = s // self.p
        
        return PAdicNumber(self.p, result, min_e)
    
    def __repr__(self):
        terms = []
        for i, c in enumerate(self.coeffs):
            exp = self.min_exp + i
            if c != 0:
                if exp == 0:
                    terms.append(str(c))
                elif exp == 1:
                    terms.append(f"{c}*{self.p}")
                else:
                    terms.append(f"{c}*{self.p}^{exp}")
        return " + ".join(terms) if terms else "0"

def hensel_lift(f, df, x0, p, n_iterations=5):
    """
    Hensel lifting: given approximate root x0 mod p, lift to root in Z_p.
    f: function, df: derivative, x0: initial approximation
    """
    x = x0
    for i in range(n_iterations):
        fx = f(x)
        dfx = df(x)
        if dfx % p == 0:
            break
        # Newton iteration: x_{n+1} = x_n - f(x_n)/f'(x_n)
        x = (x - fx * pow(dfx, -1, p**(i+2))) % p**(i+2)
    return x

Optimal Transport: From Monge to Machine Learning

Real-World Motivation

Optimal transport theory, originating with Monge's 1781 problem of moving earth efficiently, has found modern applications in economics (matching theory), computer graphics (morphing), machine learning (Wasserstein GANs), and medical imaging (registration). It provides a geometrically meaningful way to compare probability distributions.

Definitions

Pushforward Measure: For a map \(T: X \to Y\) and measure \(\mu\) on \(X\), the pushforward \(T_\#\mu\) is defined by \((T_\#\mu)(A) = \mu(T^{-1}(A))\).

Monge Problem: Given \(\mu, \nu\) on spaces \(X, Y\) and cost \(c: X \times Y \to \mathbb{R}_+\), find \(T\) minimizing \(\int_X c(x, T(x)) \, d\mu(x)\) subject to \(T_\#\mu = \nu\).

Kantorovich Relaxation: Minimize \(\int_{X \times Y} c(x,y) \, d\gamma(x,y)\) over couplings \(\gamma \in \Pi(\mu, \nu)\), where \(\Pi(\mu, \nu)\) contains all joint distributions with marginals \(\mu\) and \(\nu\).

Wasserstein Distance: \(W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int |x-y|^p \, d\gamma\right)^{1/p}\).

Theorem (Kantorovich Duality)

For the cost \(c(x,y) = |x-y|^p\) with \(p \geq 1\):

\[W_p^p(\mu, \nu) = \sup_{\phi, \psi} \left\{\int \phi \, d\mu + \int \psi \, d\nu : \phi(x) + \psi(y) \leq |x-y|^p\right\}\]

Equivalently, using the c-transform: \(W_p^p(\mu, \nu) = \sup_{\phi} \left\{\int \phi \, d\mu + \int \phi^c \, d\nu\right\}\) where \(\phi^c(y) = \inf_x (|x-y|^p - \phi(x))\).

Proof Sketch

The proof uses Fenchel-Rockafellar duality. The primal (Kantorovich) is a linear program over measures. The dual variables \((\phi, \psi)\) act as Lagrange multipliers for the marginal constraints. Strong duality holds under mild conditions, and the optimal \(\phi\) is called the Kantorovich potential.

Notation Guide

  • \(\Pi(\mu, \nu)\) — Set of couplings (transport plans)
  • \(T_\#\mu\) — Pushforward measure
  • \(W_p\) — p-Wasserstein distance
  • \(\phi^c\) — c-transform of \(\phi\)
  • \(\gamma\) — Optimal transport plan

Python Code

import numpy as np
from scipy.optimize import linprog
from scipy.spatial.distance import cdist

def discrete_optimal_transport(mu, nu, C):
    """
    Solve discrete optimal transport using linear programming.
    
    Parameters:
    - mu: Source distribution (length m)
    - nu: Target distribution (length n)
    - C: Cost matrix (m x n)
    
    Returns:
    - Optimal transport plan gamma
    - Optimal cost
    """
    m, n = len(mu), len(nu)
    
    # Flatten cost matrix for objective
    c = C.flatten()
    
    # Equality constraints: marginals must match
    # Row sums = mu, column sums = nu
    A_eq = np.zeros((m + n, m * n))
    
    # Row constraints
    for i in range(m):
        A_eq[i, i*n:(i+1)*n] = 1
    
    # Column constraints
    for j in range(n):
        for i in range(m):
            A_eq[m + j, i*n + j] = 1
    
    b_eq = np.concatenate([mu, nu])
    
    # Non-negativity bounds
    bounds = [(0, None) for _ in range(m * n)]
    
    # Solve
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    gamma = result.x.reshape(m, n)
    return gamma, result.fun

def sinkhorn_knopp(mu, nu, C, epsilon=0.1, max_iter=1000):
    """
    Entropic regularization for optimal transport using Sinkhorn iterations.
    Much faster than LP for large problems.
    """
    m, n = len(mu), len(nu)
    K = np.exp(-C / epsilon)
    
    u = np.ones(m)
    v = np.ones(n)
    
    for _ in range(max_iter):
        u = mu / (K @ v)
        v = nu / (K.T @ u)
    
    gamma = np.diag(u) @ K @ np.diag(v)
    cost = np.sum(gamma * C)
    return gamma, cost

Quantum Error Correction: Protecting Information in a Noisy World

Real-World Motivation

Quantum computers are exquisitely sensitive to environmental noise, with decoherence times measured in microseconds. Quantum error correction (QEC) enables fault-tolerant quantum computation by encoding logical qubits into multiple physical qubits. The surface code, in particular, has emerged as the leading candidate for practical QEC.

Definitions

Pauli Operators: \(I = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\), \(X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\), \(Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}\), \(Y = iXZ\).

Stabilizer Group: For a quantum code, the stabilizer group \(\mathcal{S}\) is an abelian subgroup of the Pauli group (not containing \(-I\)). The code space is the simultaneous +1 eigenspace of all stabilizers.

[[n,k,d]] Code: Encodes \(k\) logical qubits into \(n\) physical qubits with distance \(d\) (can correct \(\lfloor(d-1)/2\rfloor\) errors).

Surface Code: A topological code defined on a 2D lattice where stabilizers are plaquette (Z-type) and star (X-type) operators.

Theorem (Quantum Error Correction Condition)

A quantum code with projector \(P\) onto the code space can correct errors from set \(\mathcal{E}\) if and only if:

\[P E_i^\dagger E_j P = \alpha_{ij} P\]

for all \(E_i, E_j \in \mathcal{E}\), where \(\alpha_{ij}\) is a Hermitian matrix.

Proof Sketch

The condition ensures that different errors map the code space to orthogonal subspaces (detectable) or act identically within the code space (correctable without distinguishing logical states). The recovery operation can be constructed using the projectors onto these orthogonal subspaces.

Notation Guide

  • \(\mathcal{S}\) — Stabilizer group
  • \(N(\mathcal{S})\) — Normalizer of stabilizer group
  • \([[n,k,d]]\) — Code parameters
  • \(\bar{X}, \bar{Z}\) — Logical Pauli operators
  • \(d\) — Code distance

import numpy as np

# Pauli matrices
I = np.array([[1, 0], [0, 1]], dtype=complex)
X = np.array([[0, 1], [1, 0]], dtype=complex)
Z = np.array([[1, 0], [0, -1]], dtype=complex)
Y = 1j * X @ Z

def tensor_product(ops):
    """Compute tensor product of a list of operators."""
    result = ops[0]
    for op in ops[1:]:
        result = np.kron(result, op)
    return result

def steane_code_stabilizers():
    """
    Generate stabilizers for the [[7,1,3]] Steane code.
    The Steane code encodes 1 logical qubit into 7 physical qubits.
    """
    # Steane code stabilizers (X-type and Z-type)
    # Each stabilizer is a weight-4 Pauli operator
    
    stabilizers = []
    
    # X-type stabilizers
    S1_X = tensor_product([X, X, X, X, I, I, I])
    S2_X = tensor_product([X, X, I, I, X, X, I])
    S3_X = tensor_product([X, I, X, I, X, I, X])
    
    # Z-type stabilizers
    S1_Z = tensor_product([Z, Z, Z, Z, I, I, I])
    S2_Z = tensor_product([Z, Z, I, I, Z, Z, I])
    S3_Z = tensor_product([Z, I, Z, I, Z, I, Z])
    
    stabilizers = [S1_X, S2_X, S3_X, S1_Z, S2_Z, S3_Z]
    return stabilizers

def syndrome_measurement(state, stabilizers):
    """
    Measure syndrome by computing expectation values of stabilizers.
    Returns syndrome bits (0 for +1 eigenvalue, 1 for -1 eigenvalue).
    """
    syndrome = []
    for S in stabilizers:
        # Expectation value <ψ|S|ψ>
        exp_val = np.vdot(state, S @ state).real
        # Round to nearest eigenvalue
        if abs(exp_val - 1) < 0.1:
            syndrome.append(0)
        elif abs(exp_val + 1) < 0.1:
            syndrome.append(1)
        else:
            syndrome.append(None)  # Indeterminate
    return syndrome

def apply_pauli_error(state, error_type, qubit, n_qubits=7):
    """Apply a Pauli error to a specific qubit."""
    ops = [I] * n_qubits
    ops[qubit] = error_type
    error_op = tensor_product(ops)
    return error_op @ state

def steane_code_encoder():
    """
    Create the encoding circuit for the Steane code.
    Returns the encoding unitary (simplified representation).
    """
    # The logical |0> state is the simultaneous +1 eigenstate
    # of all stabilizers with even parity of X operators
    
    # For simulation, we construct the logical |0> directly
    # It's the uniform superposition of all even-weight X-basis states
    # that satisfy the stabilizer constraints
    
    logical_zero = np.zeros(2**7, dtype=complex)
    
    # States that satisfy all Z-stabilizers (even number of 1s in each support)
    # and have even overall parity
    for i in range(2**7):
        bits = [(i >> j) & 1 for j in range(7)]
        
        # Check Z-stabilizer constraints (even parity on supports)
        if (sum(bits[j] for j in range(4)) % 2 != 0):  # S1_Z
            continue
        if (bits[0] + bits[1] + bits[4] + bits[5]) % 2 != 0:  # S2_Z
            continue
        if (bits[0] + bits[2] + bits[4] + bits[6]) % 2 != 0:  # S3_Z
            continue
        
        logical_zero[i] = 1
    
    # Normalize
    logical_zero = logical_zero / np.linalg.norm(logical_zero)
    return logical_zero

Reinforcement Learning: The Mathematics of Optimal Decision Making

Real-World Motivation

Reinforcement learning (RL) has achieved superhuman performance in games (Go, chess, poker), robotics, autonomous driving, and resource management. At its core, RL solves the problem of sequential decision-making under uncertainty, combining dynamic programming, optimization theory, and statistical learning.

Definitions

Markov Decision Process (MDP): A tuple \((\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)\) where \(\mathcal{S}\) is the state space, \(\mathcal{A}\) the action space, \(\mathcal{P}(s'|s,a)\) transition probabilities, \(\mathcal{R}(s,a)\) reward function, and \(\gamma \in [0,1)\) discount factor.

Policy: \(\pi(a|s)\) is the probability of taking action \(a\) in state \(s\).

Value Function: \(V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R_t \mid S_0 = s, \pi\right]\).

Q-Function: \(Q^\pi(s,a) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R_t \mid S_0 = s, A_0 = a, \pi\right]\).

Optimal Value: \(V^*(s) = \sup_\pi V^\pi(s)\).

Theorem (Bellman Optimality)

The optimal value function \(V^*\) is the unique solution to:

\[V^*(s) = \max_{a \in \mathcal{A}} \left\{\mathcal{R}(s,a) + \gamma \sum_{s'} \mathcal{P}(s'|s,a) V^*(s')\right\}\]

Equivalently for Q-functions:

\[Q^*(s,a) = \mathcal{R}(s,a) + \gamma \sum_{s'} \mathcal{P}(s'|s,a) \max_{a'} Q^*(s', a')\]

Proof Sketch

The Bellman operator \(\mathcal{T}\) defined by the right-hand side is a contraction in the sup norm (by \(\gamma < 1\)). By the Banach fixed-point theorem, it has a unique fixed point. This fixed point must be \(V^*\) because: (1) any optimal policy achieves the max, and (2) the fixed point represents the best achievable value from each state.

Notation Guide

  • \(\mathcal{S}, \mathcal{A}\) — State and action spaces
  • \(\mathcal{P}(s'|s,a)\) — Transition probability
  • \(\gamma\) — Discount factor
  • \(V^\pi, Q^\pi\) — Value and action-value functions
  • \(\mathcal{T}\) — Bellman operator

import numpy as np

class GridWorldMDP:
    """
    A simple grid world MDP for demonstrating RL algorithms.
    """
    def __init__(self, size=4, gamma=0.95):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4  # up, down, left, right
        self.gamma = gamma
        
        # Define transition dynamics and rewards
        self.P = np.zeros((self.n_states, self.n_actions, self.n_states))
        self.R = np.zeros((self.n_states, self.n_actions))
        
        # Goal state (bottom-right corner)
        self.goal = self.n_states - 1
        
        for s in range(self.n_states):
            row, col = s // size, s % size
            
            for a in range(4):
                # Determine next state
                next_row, next_col = row, col
                if a == 0:  # up
                    next_row = max(0, row - 1)
                elif a == 1:  # down
                    next_row = min(size - 1, row + 1)
                elif a == 2:  # left
                    next_col = max(0, col - 1)
                elif a == 3:  # right
                    next_col = min(size - 1, col + 1)
                
                next_s = next_row * size + next_col
                self.P[s, a, next_s] = 1.0
                
                # Reward: +1 for reaching goal, small penalty otherwise
                if next_s == self.goal and s != self.goal:
                    self.R[s, a] = 1.0
                else:
                    self.R[s, a] = -0.01  # Small step penalty

def value_iteration(mdp, theta=1e-6, max_iter=1000):
    """
    Value iteration algorithm for finding optimal policy.
    """
    V = np.zeros(mdp.n_states)
    
    for i in range(max_iter):
        delta = 0
        for s in range(mdp.n_states):
            v = V[s]
            # Bellman optimality update
            Q_s = np.zeros(mdp.n_actions)
            for a in range(mdp.n_actions):
                Q_s[a] = mdp.R[s, a] + mdp.gamma * np.sum(mdp.P[s, a, :] * V)
            V[s] = np.max(Q_s)
            delta = max(delta, abs(v - V[s]))
        
        if delta < theta:
            print(f"Value iteration converged after {i+1} iterations")
            break
    
    # Extract optimal policy
    policy = np.zeros(mdp.n_states, dtype=int)
    for s in range(mdp.n_states):
        Q_s = np.zeros(mdp.n_actions)
        for a in range(mdp.n_actions):
            Q_s[a] = mdp.R[s, a] + mdp.gamma * np.sum(mdp.P[s, a, :] * V)
        policy[s] = np.argmax(Q_s)
    
    return V, policy

def q_learning(mdp, n_episodes=1000, alpha=0.1, epsilon=0.1):
    """
    Q-learning: model-free RL algorithm.
    """
    Q = np.zeros((mdp.n_states, mdp.n_actions))
    
    for episode in range(n_episodes):
        s = 0  # Start state
        
        while s != mdp.goal:
            # Epsilon-greedy action selection
            if np.random.random() < epsilon:
                a = np.random.randint(mdp.n_actions)
            else:
                a = np.argmax(Q[s, :])
            
            # Simulate transition
            next_s = np.random.choice(mdp.n_states, p=mdp.P[s, a, :])
            r = mdp.R[s, a]
            
            # Q-learning update
            Q[s, a] = Q[s, a] + alpha * (r + mdp.gamma * np.max(Q[next_s, :]) - Q[s, a])
            
            s = next_s
    
    # Extract policy
    policy = np.argmax(Q, axis=1)
    V = np.max(Q, axis=1)
    
    return Q, V, policy

def policy_iteration(mdp, max_iter=100):
    """
    Policy iteration: alternate between policy evaluation and improvement.
    """
    policy = np.random.randint(0, mdp.n_actions, size=mdp.n_states)
    V = np.zeros(mdp.n_states)
    
    for i in range(max_iter):
        # Policy evaluation
        theta = 1e-6
        while True:
            delta = 0
            for s in range(mdp.n_states):
                v = V[s]
                a = policy[s]
                V[s] = mdp.R[s, a] + mdp.gamma * np.sum(mdp.P[s, a, :] * V)
                delta = max(delta, abs(v - V[s]))
            if delta < theta:
                break
        
        # Policy improvement
        policy_stable = True
        for s in range(mdp.n_states):
            old_action = policy[s]
            Q_s = np.zeros(mdp.n_actions)
            for a in range(mdp.n_actions):
                Q_s[a] = mdp.R[s, a] + mdp.gamma * np.sum(mdp.P[s, a, :] * V)
            policy[s] = np.argmax(Q_s)
            if old_action != policy[s]:
                policy_stable = False
        
        if policy_stable:
            print(f"Policy iteration converged after {i+1} iterations")
            break
    
    return V, policy

Arithmetic Geometry: The Weil Conjectures

Historical Context

André Weil formulated his famous conjectures in 1949, proposing deep connections between the number of points on algebraic varieties over finite fields and the topology of corresponding complex varieties. Their proof by Deligne in 1974 was a landmark achievement, earning him the Fields Medal.

Definitions

Variety over \(\mathbb{F}_q\): The set of solutions to polynomial equations with coefficients in the finite field with \(q\) elements.

Zeta Function: \(Z(X, t) = \exp\left(\sum_{n=1}^{\infty} N_n \frac{t^n}{n}\right)\) where \(N_n\) counts points over \(\mathbb{F}_{q^n}\).

Theorem (Weil Conjectures, proved by Deligne)

For a smooth projective variety \(X\) of dimension \(d\) over \(\mathbb{F}_q\):

  1. Rationality: \(Z(X, t)\) is a rational function of \(t\).
  2. Functional Equation: \(Z(X, q^{-d}/t) = \pm q^{dE/2} t^E Z(X, t)\) where \(E\) is the Euler characteristic.
  3. Riemann Hypothesis: The zeros and poles of \(Z(X, t)\) lie on circles \(|t| = q^{-i/2}\) for \(i = 0, 1, \ldots, 2d\).

Notation Guide

  • \(\mathbb{F}_q\) — Finite field with \(q\) elements
  • \(N_n\) — Number of points over \(\mathbb{F}_{q^n}\)
  • \(Z(X, t)\) — Zeta function of variety \(X\)
  • \(H^i_{\text{ét}}\) — Étale cohomology groups

Geometric Group Theory: Hyperbolic Groups

Historical Context

Mikhail Gromov's 1987 paper "Hyperbolic Groups" revolutionized infinite group theory by importing geometric ideas. A finitely generated group is hyperbolic if its Cayley graph satisfies a thin triangle condition, generalizing the geometry of classical hyperbolic space.

Definitions

Cayley Graph: For group \(G\) with generating set \(S\), vertices are group elements, edges connect \(g\) to \(gs\) for \(s \in S\).

\(\delta\)-Hyperbolic Space: A geodesic metric space where any geodesic triangle is \(\delta\)-thin: each side is contained in the \(\delta\)-neighborhood of the union of the other two sides.

Hyperbolic Group: A finitely generated group whose Cayley graph is \(\delta\)-hyperbolic for some \(\delta \geq 0\).

Theorem (Gromov)

A hyperbolic group has a well-defined boundary at infinity \(\partial G\). The action of \(G\) on \(\partial G\) is:

  1. Properly discontinuous on the triple space \(\partial G \times \partial G \times \partial G\)
  2. Cocompact on the space of distinct pairs

Moreover, the boundary is a compact metrizable space.

Notation Guide

  • \(\Gamma(G, S)\) — Cayley graph
  • \(\delta\) — Hyperbolicity constant
  • \(\partial G\) — Gromov boundary
  • \((x|y)_w\) — Gromov product

class HyperbolicGroup:
    """
    Represents a group and checks hyperbolicity properties.
    Example: Free groups are 0-hyperbolic (trees).
    """
    def __init__(self, generators, relators=None):
        self.generators = generators
        self.relators = relators or []
        self.inv_map = {g: g+'⁻¹' for g in generators}
        for g in generators:
            self.inv_map[g+'⁻¹'] = g
    
    def reduce_word(self, word):
        """Reduce a word by canceling adjacent inverse pairs."""
        stack = []
        for letter in word:
            if stack and self.inv_map.get(stack[-1]) == letter:
                stack.pop()
            else:
                stack.append(letter)
        return ''.join(stack)
    
    def geodesic_metric(self, word1, word2):
        """
        Distance in the Cayley graph equals length of reduced word
        representing word1⁻¹ * word2.
        """
        # For free groups, this is just the length after reduction
        inv_w1 = ''.join(reversed([self.inv_map[c] for c in word1]))
        product = self.reduce_word(inv_w1 + word2)
        return len(product)
    
    def gromov_product(self, x, y, w):
        """
        (x|y)_w = (1/2)(d(x,w) + d(y,w) - d(x,y))
        Measures how long geodesics from w to x and w to y stay together.
        """
        d_xw = self.geodesic_metric(x, w)
        d_yw = self.geodesic_metric(y, w)
        d_xy = self.geodesic_metric(x, y)
        return 0.5 * (d_xw + d_yw - d_xy)
    
    def check_thin_triangle(self, a, b, c, delta):
        """
        Check if triangle with vertices a, b, c is delta-thin.
        In a delta-hyperbolic space, each side is in delta-neighborhood
        of the union of other two sides.
        """
        # Compute side lengths
        ab = self.geodesic_metric(a, b)
        bc = self.geodesic_metric(b, c)
        ca = self.geodesic_metric(c, a)
        
        # For a tree (0-hyperbolic), this is always satisfied
        # For general groups, we'd need to enumerate paths

        # In delta-hyperbolic space: (x|y)_w >= min((x|z)_w, (y|z)_w) - delta
        w = ''  # Identity
        xy_w = self.gromov_product(a, b, w)
        xz_w = self.gromov_product(a, c, w)
        yz_w = self.gromov_product(b, c, w)
        
        return xy_w >= min(xz_w, yz_w) - delta

Symplectic Geometry: The Geometry of Classical Mechanics

Historical Context

Symplectic geometry emerged from Hamilton's reformulation of classical mechanics in the 1830s. The modern geometric formulation, developed in the mid-20th century, reveals deep structures: symplectic manifolds have no local invariants (Darboux's theorem), yet possess rich global topology. Gromov's 1985 work on pseudoholomorphic curves revolutionized the field.

Definitions

Symplectic Form: A closed, non-degenerate 2-form \(\omega\) on a manifold \(M^{2n}\). Non-degenerate means \(\omega^n \neq 0\) everywhere.

Hamiltonian Vector Field: For \(H: M \to \mathbb{R}\), the vector field \(X_H\) satisfies \(\iota_{X_H}\omega = -dH\).

Poisson Bracket: \(\{f, g\} = \omega(X_f, X_g) = X_f(g)\).

Lagrangian Submanifold: A submanifold \(L^n \subset M^{2n}\) where \(\omega|_L = 0\) and \(\dim L = n\).

Theorem (Darboux)

Near any point on a symplectic manifold \((M, \omega)\), there exist coordinates \((q_1, \ldots, q_n, p_1, \ldots, p_n)\) such that:

\[\omega = \sum_{i=1}^n dq_i \wedge dp_i\]

Equivalently, all symplectic manifolds of the same dimension are locally symplectomorphic to \((\mathbb{R}^{2n}, \omega_0)\).

Proof Sketch

The proof uses Moser's trick: given two symplectic forms \(\omega_0, \omega_1\) with \([\omega_0] = [\omega_1]\) in cohomology, the linear interpolation \(\omega_t = (1-t)\omega_0 + t\omega_1\) remains non-degenerate. One constructs a time-dependent vector field whose flow pulls back \(\omega_t\) to \(\omega_0\).

Notation Guide

  • \(\omega\) — Symplectic form
  • \(X_H\) — Hamiltonian vector field
  • \(\{f, g\}\) — Poisson bracket
  • \(\iota_X\) — Interior product (contraction)
  • \(L\) — Lagrangian submanifold

import numpy as np
from scipy.integrate import solve_ivp

class SymplecticSystem:
    """
    Represents a Hamiltonian system on R^{2n} with standard symplectic form.
    Coordinates: (q, p) where q, p are each n-dimensional.
    """
    def __init__(self, n):
        self.n = n
    
    def hamiltonian(self, state):
        """Override this with specific Hamiltonian."""
        q, p = state[:self.n], state[self.n:]
        return 0.5 * np.sum(p**2)  # Free particle
    
    def hamiltonian_vector_field(self, state):
        """
        Compute X_H using Hamilton's equations:
        dq/dt = ∂H/∂p, dp/dt = -∂H/∂q
        """
        eps = 1e-8
        q, p = state[:self.n], state[self.n:]
        
        # ∂H/∂p (numerical gradient)
        dH_dp = np.zeros(self.n)
        for i in range(self.n):
            p_plus = p.copy()
            p_plus[i] += eps
            dH_dp[i] = (self.hamiltonian(np.concatenate([q, p_plus])) - 
                       self.hamiltonian(state)) / eps
        
        # ∂H/∂q
        dH_dq = np.zeros(self.n)
        for i in range(self.n):
            q_plus = q.copy()
            q_plus[i] += eps
            dH_dq[i] = (self.hamiltonian(np.concatenate([q_plus, p])) - 
                       self.hamiltonian(state)) / eps
        
        # Hamilton's equations
        dq_dt = dH_dp
        dp_dt = -dH_dq
        
        return np.concatenate([dq_dt, dp_dt])
    
    def poisson_bracket(self, f, g, state):
        """
        Compute {f, g} = ∂f/∂q · ∂g/∂p - ∂f/∂p · ∂g/∂q
        """
        eps = 1e-8
        n = self.n
        
        # Gradients of f
        df_dq = np.zeros(n)
        df_dp = np.zeros(n)
        for i in range(n):
            state_plus = state.copy()
            state_plus[i] += eps
            df_dq[i] = (f(state_plus) - f(state)) / eps
            
            state_plus = state.copy()
            state_plus[n + i] += eps
            df_dp[i] = (f(state_plus) - f(state)) / eps
        
        # Gradients of g
        dg_dq = np.zeros(n)
        dg_dp = np.zeros(n)
        for i in range(n):
            state_plus = state.copy()
            state_plus[i] += eps
            dg_dq[i] = (g(state_plus) - g(state)) / eps
            
            state_plus = state.copy()
            state_plus[n + i] += eps
            dg_dp[i] = (g(state_plus) - g(state)) / eps
        
        return np.dot(df_dq, dg_dp) - np.dot(df_dp, dg_dq)
    
    def integrate(self, state0, t_span, t_eval):
        """Integrate Hamilton's equations."""
        def ode(t, y):
            return self.hamiltonian_vector_field(y)
        
        sol = solve_ivp(ode, t_span, state0, t_eval=t_eval, method='RK45')
        return sol

        # Potential energy
        V = -(self.m1 + self.m2) * self.g * self.L1 * np.cos(theta1) - self.m2 * self.g * self.L2 * np.cos(theta2)
        
        return T + V

Combinatorial Optimization: The Traveling Salesman Problem

Historical Context

The Traveling Salesman Problem (TSP) is one of the most studied problems in optimization. First formulated in the 1800s, it became a canonical NP-hard problem in the 1970s. Despite its computational difficulty, sophisticated exact and approximate algorithms can solve instances with thousands of cities.

Definitions

TSP: Given \(n\) cities with pairwise distances \(d_{ij}\), find a permutation \(\sigma\) minimizing \(\sum_{i=1}^{n} d_{\sigma(i), \sigma(i+1)}\) where \(\sigma(n+1) = \sigma(1)\).

Metric TSP: Distances satisfy triangle inequality: \(d_{ij} \leq d_{ik} + d_{kj}\).

Christofides Algorithm: A 3/2-approximation for metric TSP combining minimum spanning trees with minimum weight perfect matching.

Theorem (Christofides, 1976)

For metric TSP, the Christofides algorithm produces a tour with cost at most \(3/2 \cdot OPT\), where \(OPT\) is the optimal tour length.

Proof Sketch

  1. Compute MST \(T\): \(c(T) \leq OPT\) (deleting any edge from optimal tour gives a spanning tree).
  2. Let \(O\) be odd-degree vertices in \(T\). \(|O|\) is even.
  3. Find minimum perfect matching \(M\) on \(O\): \(c(M) \leq OPT/2\) (by shortcutting optimal tour on \(O\)).
  4. \(T \cup M\) is Eulerian; shortcut to get Hamiltonian cycle with cost \(\leq c(T) + c(M) \leq 3OPT/2\).

Notation Guide

  • \(d_{ij}\) — Distance between cities i and j
  • \(OPT\) — Optimal tour cost
  • \(T\) — Minimum spanning tree
  • \(M\) — Minimum weight perfect matching
  • \(O\) — Set of odd-degree vertices

Python Code

import numpy as np
import networkx as nx
from scipy.spatial.distance import pdist, squareform

def christofides_tsp(points):
    """
    Christofides algorithm for metric TSP.
    Returns a tour with cost at most 3/2 * OPT.
    """
    n = len(points)
    
    # Compute distance matrix
    dist_matrix = squareform(pdist(points, metric='euclidean'))
    
    # Step 1: Compute Minimum Spanning Tree
    G = nx.Graph()
    for i in range(n):
        for j in range(i+1, n):
            G.add_edge(i, j, weight=dist_matrix[i, j])
    
    mst = nx.minimum_spanning_tree(G)
    mst_cost = mst.size(weight='weight')
    print(f"MST cost: {mst_cost:.4f}")
    
    # Step 2: Find odd-degree vertices in MST
    odd_vertices = [v for v in mst.nodes() if mst.degree(v) % 2 == 1]
    print(f"Odd degree vertices: {odd_vertices}")
    
    # Step 3: Minimum weight perfect matching on odd vertices
    odd_subgraph = G.subgraph(odd_vertices)
    matching = nx.algorithms.matching.min_weight_matching(
        odd_subgraph, weight='weight'
    )
    matching_cost = sum(dist_matrix[u, v] for u, v in matching)
    print(f"Matching cost: {matching_cost:.4f}")
    
    # Step 4: Combine MST and matching to get Eulerian multigraph
    multigraph = nx.MultiGraph()
    for u, v, data in mst.edges(data=True):
        multigraph.add_edge(u, v, weight=data['weight'])
    for u, v in matching:
        multigraph.add_edge(u, v, weight=dist_matrix[u, v])
    
    # Step 5: Find Eulerian circuit
    eulerian_circuit = list(nx.eulerian_circuit(multigraph))
    
    # Step 6: Shortcut to get Hamiltonian cycle
    visited = set()
    tour = []
    for u, v in eulerian_circuit:
        if u not in visited:
            tour.append(u)
            visited.add(u)
    tour.append(tour[0])  # Complete the cycle
    
    # Compute tour cost
    tour_cost = sum(dist_matrix[tour[i], tour[i+1]] for i in range(len(tour)-1))
    
    return tour, tour_cost, mst_cost + matching_cost

def two_opt_tsp(points, initial_tour=None, max_iterations=1000):
    """
    2-opt local search improvement for TSP.
    """
    n = len(points)
    dist_matrix = squareform(pdist(points, metric='euclidean'))
    
    if initial_tour is None:
        tour = list(range(n)) + [0]
    else:
        tour = initial_tour.copy()
    
    def tour_cost(tour):
        return sum(dist_matrix[tour[i], tour[i+1]] for i in range(len(tour)-1))
    
    improved = True
    iteration = 0
    
    while improved and iteration < max_iterations:
        improved = False
        iteration += 1
        
        for i in range(1, n-1):
            for j in range(i+1, n):
                # Try reversing segment [i:j]
                new_tour = tour[:i] + tour[i:j+1][::-1] + tour[j+1:]
                
                # Compute cost difference (faster than full recalculation)
                old_edges = (dist_matrix[tour[i-1], tour[i]] + 
                           dist_matrix[tour[j], tour[j+1]])
                new_edges = (dist_matrix[tour[i-1], tour[j]] + 
                           dist_matrix[tour[i], tour[j+1]])
                
                if new_edges < old_edges:
                    tour = new_tour
                    improved = True
                    break
            if improved:
                break
    
    return tour, tour_cost(tour)

def nearest_neighbor_tsp(points):
    """Greedy nearest neighbor heuristic."""
    n = len(points)
    dist_matrix = squareform(pdist(points, metric='euclidean'))
    
    unvisited = set(range(1, n))
    tour = [0]
    current = 0
    
    while unvisited:
        nearest = min(unvisited, key=lambda x: dist_matrix[current, x])
        tour.append(nearest)
        unvisited.remove(nearest)
        current = nearest
    
    tour.append(0)  # Return to start
    cost = sum(dist_matrix[tour[i], tour[i+1]] for i in range(len(tour)-1))
    
    return tour, cost

📜 Math History: The Birth of Abstract Algebra

The 19th century witnessed the transformation of algebra from the study of equations to the study of algebraic structures. This revolution began with the work of Évariste Galois (1811–1832), whose short but brilliant career fundamentally changed how mathematicians think about symmetry and solutions to polynomial equations.

Galois developed his theory while still a teenager, showing that the solvability of a polynomial equation by radicals depends on the structure of its associated permutation group. His work, submitted to the Paris Academy of Sciences, was initially rejected and lost. Galois died in a duel at age 20, leaving behind a letter to his friend Auguste Chevalier outlining his mathematical ideas. It was only through the efforts of Liouville in 1846 that Galois's work was finally published and recognized.

The abstract group concept emerged gradually. Cauchy studied permutation groups extensively, while Cayley attempted to define groups axiomatically in 1854. The modern definition—sets with associative binary operations, identity elements, and inverses—crystallized in the work of Weber, von Dyck, and others in the 1880s.

Concurrently, the study of rings and ideals developed from number theory. Kummer introduced "ideal numbers" in 1847 to restore unique factorization in cyclotomic fields, attempting to prove Fermat's Last Theorem. Dedekind refined this into the theory of ideals in 1871, and Noether's abstract treatment in the 1920s completed the transformation of ring theory into its modern form.

By the early 20th century, the structural approach championed by van der Waerden's "Moderne Algebra" (1930) had become standard. Algebra was no longer merely about solving equations—it was the study of abstract structures and the homomorphisms between them, a perspective that would dominate 20th-century mathematics.

🎯 Problem Corner

Problem: A Number Theory Challenge (Putnam 2021)

Let \(P(x)\) be a polynomial with integer coefficients such that \(P(0) = 0\) and \(\frac{P(n)}{n}\) is an integer for all positive integers \(n\). Prove that \(P(x)\) has the form \(P(x) = xQ(x)\) where \(Q(x)\) is a polynomial with integer coefficients.

💡 Hint

Consider the polynomial \(Q(x) = P(x)/x\). You need to show that \(Q(n)\) is an integer for all integers \(n\). Use the fact that a polynomial that takes integer values at all integers can be expressed as a \(\mathbb{Z}\)-linear combination of binomial coefficients.

✅ Solution

Step 1: Since \(P(0) = 0\), we can write \(P(x) = xQ(x)\) for some polynomial \(Q(x)\) with rational coefficients. We need to show that \(Q(x)\) has integer coefficients.

Step 2: The condition states that \(P(n)/n = Q(n)\) is an integer for all positive integers \(n\). So \(Q(n) \in \mathbb{Z}\) for all \(n \in \mathbb{Z}^+\).

Step 3: Any polynomial \(Q(x)\) with rational coefficients that takes integer values at all integers can be written as:

\[Q(x) = \sum_{k=0}^{d} a_k \binom{x}{k}\]

where \(a_k \in \mathbb{Z}\) and \(\binom{x}{k} = \frac{x(x-1)\cdots(x-k+1)}{k!}\).

Step 4: The binomial coefficient polynomials \(\binom{x}{k}\) form a basis for polynomials that map integers to integers. Since \(Q(n) \in \mathbb{Z}\) for all \(n \in \mathbb{Z}^+\), the coefficients \(a_k\) in this expansion must be integers.

Step 5: Now, \(P(x) = xQ(x) = x \sum_{k=0}^{d} a_k \binom{x}{k}\). We can rewrite:

\[x\binom{x}{k} = x \cdot \frac{x(x-1)\cdots(x-k+1)}{k!} = (k+1) \cdot \frac{x(x-1)\cdots(x-k+1)x}{(k+1)!} = (k+1)\binom{x}{k+1} \cdot \frac{x}{x-k}\]

A cleaner approach: Note that \(x\binom{x}{k} = (k+1)\binom{x}{k+1} + k\binom{x}{k}\) is not quite right. Instead:

\[x\binom{x}{k} = (k+1)\binom{x+1}{k+1} - k\binom{x}{k}\]

Actually, the simplest approach is to verify directly that if \(Q(x) = \sum a_k \binom{x}{k}\) with \(a_k \in \mathbb{Z}\), then \(P(x) = xQ(x)\) has integer coefficients when expanded in the standard basis. This follows from the fact that \(x\binom{x}{k}\) is a polynomial with integer coefficients (it's \(\frac{x^2(x-1)\cdots(x-k+1)}{k!}\) which can be shown to have integer coefficients by induction).

Conclusion: Therefore, \(P(x) = xQ(x)\) where \(Q(x)\) has integer coefficients when expressed in the binomial basis, which implies the standard coefficients are also integers.

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) with \(z_0 = 0\) remains bounded. It exhibits infinite complexity at all scales and is perhaps the most famous fractal in mathematics.

Mathematical Properties

  • The main cardioid corresponds to parameters where the iteration converges to a fixed point.
  • Each bulb attached to the cardioid corresponds to parameters with attracting cycles of different periods.
  • The boundary has Hausdorff dimension 2, making it a space-filling curve in a limiting sense.
  • The Mandelbrot set is connected (proved by Douady and Hubbard in the 1980s).

Python Code

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for a given c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring: interpolate between iterations
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=800, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    M = np.zeros((height, width))
    for i in range(height):
        for j in range(width):
            M[i, j] = mandelbrot(C[i, j], max_iter)
    
    return M
