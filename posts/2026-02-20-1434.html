Lie Algebras: The Infinitesimal Symmetries

lie-algebras

Motivation

Lie algebras arise from the study of continuous symmetries, capturing the infinitesimal structure of Lie groups. Named after Sophus Lie, who developed the theory in the late 19th century to study differential equations through their symmetry groups, Lie algebras have become fundamental tools across mathematics and physics. They classify elementary particles in quantum field theory, describe the curvature of spacetime in general relativity, and provide the algebraic framework for representation theory. The classification of simple Lie algebras by Cartan and Killing stands as one of the most beautiful achievements in mathematics.

Definitions

  • Lie Algebra: A vector space \(\\mathfrak{g}\) over a field \(\\mathbb{F}\) equipped with a bilinear bracket \([\\cdot, \\cdot]: \\mathfrak{g} \\times \\mathfrak{g} \\to \\mathfrak{g}\) satisfying antisymmetry \([x, y] = -[y, x]\) and the Jacobi identity \([x, [y, z]] + [y, [z, x]] + [z, [x, y]] = 0\).
  • Adjoint Representation: For \(x \\in \\mathfrak{g}\), define \(\text{ad}_x: \\mathfrak{g} \\to \\mathfrak{g}\) by \(\text{ad}_x(y) = [x, y]\). The map \(x \\mapsto \\text{ad}_x\) is the adjoint representation.
  • Killing Form: The symmetric bilinear form \(\kappa(x, y) = \\text{tr}(\\text{ad}_x \\circ \\text{ad}_y)\).
  • Semisimple Lie Algebra: A Lie algebra with no non-zero abelian ideals, equivalently one with non-degenerate Killing form (Cartan's criterion).
  • Root System: For a semisimple Lie algebra with Cartan subalgebra \(\mathfrak{h}\), the roots are the non-zero weights of the adjoint action of \(\mathfrak{h}\) on \(\mathfrak{g}\).

Theorem: The Cartan Classification of Simple Lie Algebras

Theorem: Every finite-dimensional simple Lie algebra over \(\mathbb{C}\) is isomorphic to exactly one of:

  • Classical Series: \(A_n = \\mathfrak{sl}_{n+1}(\\mathbb{C})\) for \(n \\geq 1\), \(B_n = \\mathfrak{so}_{2n+1}(\\mathbb{C})\) for \(n \\geq 2\), \(C_n = \\mathfrak{sp}_{2n}(\\mathbb{C})\) for \(n \\geq 3\), \(D_n = \\mathfrak{so}_{2n}(\\mathbb{C})\) for \(n \\geq 4\)
  • Exceptional Algebras: \(E_6, E_7, E_8, F_4, G_2\)

Proof Sketch

The proof proceeds through several key steps:

Step 1: Every semisimple Lie algebra decomposes as a direct sum of simple ideals.

Step 2: For a semisimple Lie algebra \(\mathfrak{g}\) with Cartan subalgebra \(\mathfrak{h}\), the root space decomposition is:

\\[\\mathfrak{g} = \\mathfrak{h} \\oplus \\bigoplus_{\\alpha \\in \\Phi} \\mathfrak{g}_\\alpha\\]

where \(\Phi\) is the root system and \(\mathfrak{g}_\\alpha = \\{x \\in \\mathfrak{g} : [h, x] = \\alpha(h)x \\text{ for all } h \\in \\mathfrak{h}\\}\).

Step 3: The root system \(\Phi\) satisfies axioms that classify it into the Dynkin diagrams \(A_n, B_n, C_n, D_n, E_6, E_7, E_8, F_4, G_2\).

Step 4: Each Dynkin diagram corresponds to a unique simple Lie algebra up to isomorphism. ∎

Notation Guide

  • \(\mathfrak{g}, \\mathfrak{h}\) — Lie algebra, Cartan subalgebra
  • \([x, y]\) — Lie bracket
  • \(\text{ad}_x\) — adjoint action
  • \(\kappa(x, y)\) — Killing form
  • \(\Phi\) — root system
  • \(\mathfrak{g}_\\alpha\) — root space
  • \(\mathfrak{sl}_n, \\mathfrak{so}_n, \\mathfrak{sp}_{2n}\) — classical Lie algebras
  • \(\mathfrak{n}^+, \\mathfrak{n}^-\) — positive/negative nilpotent subalgebras

import numpy as np
from itertools import combinations

class LieAlgebra:
    """Basic computations with matrix Lie algebras."""
    
    def __init__(self, basis):
        """
        basis: list of numpy arrays forming a basis for the Lie algebra.
        """
        self.basis = [np.array(b, dtype=complex) for b in basis]
        self.dim = len(basis)
    
    def lie_bracket(self, x, y):
        """Compute [x, y] = xy - yx."""
        return x @ y - y @ x
    
    def structure_constants(self):
        """Compute structure constants f^k_ij where [e_i, e_j] = sum_k f^k_ij e_k."""
        f = np.zeros((self.dim, self.dim, self.dim), dtype=complex)
        for i in range(self.dim):
            for j in range(self.dim):
                bracket = self.lie_bracket(self.basis[i], self.basis[j])
                # Project onto basis
                for k in range(self.dim):
                    # Use Frobenius inner product for projection
                    f[k, i, j] = np.trace(bracket @ self.basis[k].conj().T)
        return f
    
    def killing_form(self):
        """Compute the Killing form kappa(x, y) = tr(ad_x @ ad_y)."""
        f = self.structure_constants()
        kappa = np.zeros((self.dim, self.dim), dtype=complex)
        for i in range(self.dim):
            for j in range(self.dim):
                # ad_x has matrix (f^k_il) in basis e_l
                ad_x = f[:, i, :]
                ad_y = f[:, j, :]
                kappa[i, j] = np.trace(ad_x @ ad_y)
        return kappa
    
    def is_semisimple(self, tol=1e-10):
        """Check if Killing form is non-degenerate."""
        kappa = self.killing_form()
        return abs(np.linalg.det(kappa)) > tol

p-adic Analysis: Numbers Beyond the Real Line

p-adic-analysis

Motivation

p-adic numbers, introduced by Kurt Hensel in 1897, provide an alternative completion of the rational numbers that has revolutionized number theory. Unlike the real numbers, which complete \(\mathbb{Q}\) with respect to the usual absolute value, p-adic numbers complete \(\mathbb{Q}\) with respect to the p-adic absolute value. This completion reveals deep arithmetic structures invisible to real analysis. p-adic methods have solved major problems in number theory, including Fermat's Last Theorem through the work of Wiles, and continue to play crucial roles in the Langlands program and arithmetic geometry.

Definitions

  • p-adic Valuation: For a prime \(p\) and integer \(n\), \(v_p(n) = k\) where \(p^k | n\) but \(p^{k+1} \\nmid n\). For \(x = a/b \\in \\mathbb{Q}\), \(v_p(x) = v_p(a) - v_p(b)\).
  • p-adic Absolute Value: \(|x|_p = p^{-v_p(x)}\) for \(x \\neq 0\), and \(|0|_p = 0\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\\cdot|_p\).
  • p-adic Integers \(\mathbb{Z}_p\): \(\mathbb{Z}_p = \\{x \\in \\mathbb{Q}_p : |x|_p \\leq 1\\}\), equivalently the closure of \(\mathbb{Z}\) in \(\mathbb{Q}_p\).
  • Hensel's Lemma: The p-adic analogue of Newton's method for finding roots.

Theorem: Ostrowski's Theorem

Theorem: Every non-trivial absolute value on \(\mathbb{Q}\) is equivalent to either:

  • The usual absolute value \(|\\cdot|_\\infty\), or
  • The p-adic absolute value \(|\\cdot|_p\) for some prime \(p\).

Moreover, the product formula holds: for \(x \\in \\mathbb{Q}^*\),

\\[\\prod_{p \\leq \\infty} |x|_p = 1\\]

where the product is over all primes including \(p = \\infty\) (the real absolute value).

Proof Sketch

Let \(|\\cdot|\) be a non-trivial absolute value on \(\mathbb{Q}\).

Case 1 (Archimedean): If \(|n| > 1\) for some integer \(n\), then \(|\\cdot|\) is equivalent to \(|\\cdot|_\\infty\). This follows by showing \(|n| = |n|_\\infty^\\alpha\) for some \(\alpha > 0\).

Case 2 (Non-Archimedean): If \(|n| \\leq 1\) for all integers, let \(p\) be the smallest integer with \(|p| < 1\). Then \(p\) is prime, and \(|\\cdot|\) is equivalent to \(|\\cdot|_p\).

The product formula follows from unique factorization: for \(x = \\pm \\prod p_i^{e_i}\), we have \(|x|_p = p^{-e}\) if \(p = p_i^e\) divides \(x\), and \(|x|_p = 1\) otherwise. ∎

Notation Guide

  • \(\mathbb{Q}_p\) — p-adic numbers
  • \(\mathbb{Z}_p\) — p-adic integers
  • \(v_p(x)\) — p-adic valuation
  • \(|x|_p = p^{-v_p(x)}\) — p-adic absolute value
  • \(\mathbb{C}_p\) — completion of algebraic closure of \(\mathbb{Q}_p\)
  • \(a_n p^n + a_{n+1} p^{n+1} + \\cdots\) — p-adic expansion

from fractions import Fraction
import math

def padic_valuation(n, p):
    """Compute p-adic valuation v_p(n) for integer n."""
    if n == 0:
        return float('inf')
    val = 0
    n = abs(n)
    while n % p == 0:
        n //= p
        val += 1
    return val

def padic_absolute_value(x, p):
    """Compute |x|_p for rational x."""
    if x == 0:
        return 0
    x = Fraction(x)
    vp = padic_valuation(x.numerator, p) - padic_valuation(x.denominator, p)
    return p ** (-vp)

def padic_expansion(x, p, precision=20):
    """Compute p-adic expansion of rational x up to given precision."""
    if x == 0:
        return [0] * precision
    
    x = Fraction(x)
    # Ensure x is in Z_p (multiply by appropriate power of p)
    vp = padic_valuation(x.numerator, p) - padic_valuation(x.denominator, p)
    
    # Normalize to positive valuation
    if vp < 0:
        x = x * (p ** (-vp))
    
    digits = []
    current = x
    for _ in range(precision):
        # Find digit a such that current ≡ a (mod p)
        num = current.numerator % (p * current.denominator)
        a = (num * pow(current.denominator, -1, p)) % p
        digits.append(a)
        current = (current - a) / p
    
    return digits, vp

def hensel_lift(f, df, x0, p, k):
    """
    Hensel's lemma: lift a simple root mod p to a root mod p^k.
    f: polynomial function
    df: derivative of f
    x0: initial root mod p
    p: prime
    k: target precision
    """
    x = x0
    for i in range(1, k):
        # Newton iteration: x_{n+1} = x_n - f(x_n)/f'(x_n)
        fx = f(x) % (p ** (i + 1))
        dfx = df(x) % p
        if dfx == 0:
            raise ValueError("Derivative vanishes - root not simple")
        # Modular inverse of derivative
        dfx_inv = pow(dfx, -1, p)
        delta = (fx * dfx_inv) % (p ** (i + 1))
        x = (x - delta) % (p ** (i + 1))
    return x

Tropical Geometry: The Geometry of the Min-Plus Semiring

tropical-geometry

Motivation

Tropical geometry is a relatively new field that transforms algebraic varieties into piecewise-linear objects, making them amenable to combinatorial techniques. The name honors Brazilian mathematician Imre Simon, a pioneer in the field. Tropical methods have provided new insights into enumerative geometry, mirror symmetry, and optimization. By "tropicalizing" algebraic varieties, complex geometric problems become questions about polyhedral complexes, which can often be solved algorithmically. The field has found surprising applications in phylogenetics, economics, and scheduling problems.

Definitions

  • Tropical Semiring \(\mathbb{T}\): \(\mathbb{R} \\cup \\{\\infty\\}\) with operations \(a \\oplus b = \\min(a, b)\) and \(a \\odot b = a + b\).
  • Tropical Polynomial: A function of the form \(f(x) = \\bigoplus_{i} (a_i \\odot x^{\\odot i}) = \\min_i(a_i + i \\cdot x)\).
  • Tropical Hypersurface: The set where the minimum in a tropical polynomial is achieved at least twice.
  • Newton Polygon: For a polynomial \(\sum a_i x^i\), the convex hull of \((i, -a_i)\) in tropical coordinates.
  • Amoeba: The image of an algebraic variety under the logarithm map \(\text{Log}_t: (\\mathbb{C}^*)^n \\to \\mathbb{R}^n\), \((z_1, \\ldots, z_n) \\mapsto (\\log_t|z_1|, \\ldots, \\log_t|z_n|)\).

Theorem: The Fundamental Theorem of Tropical Geometry

Theorem: Let \(I \\subseteq \\mathbb{C}[x_1^{\\pm 1}, \\ldots, x_n^{\\pm 1}]\) be an ideal and \(X = V(I)\) the corresponding variety in \((\\mathbb{C}^*)^n\). Let \(\text{trop}(X)\) be the tropicalization of \(X\). Then:

\\[\\text{trop}(X) = \\bigcap_{f \\in I} \\text{trop}(V(f)) = \\overline{\\text{Log}_t(X)} \\text{ as } t \\to \\infty\\]

Moreover, \(\text{trop}(X)\) is a rational polyhedral complex of dimension \(\dim(X)\).

Proof Sketch

The proof relies on the Kapranov correspondence between non-Archimedean amoebas and tropical varieties:

Step 1: For a hypersurface \(V(f)\), the tropicalization is the corner locus of the tropical polynomial obtained by taking valuations of coefficients.

Step 2: For a general variety, use the fact that \(\text{trop}(X) = \\text{trop}(I)\) can be computed from any generating set of \(I\).

Step 3: The limit of amoebas as \(t \\to \\infty\) degenerates to the tropical variety, with the spine of the amoeba converging to the tropicalization. ∎

Notation Guide

  • \(\mathbb{T} = \\mathbb{R} \\cup \\{\\infty\\}\) — tropical semiring
  • \(a \\oplus b = \\min(a, b)\) — tropical addition
  • \(a \\odot b = a + b\) — tropical multiplication
  • \(x^{\\odot n} = n \\cdot x\) — tropical power
  • \(\text{trop}(V(f))\) — tropical hypersurface
  • \(\text{Newt}(f)\) — Newton polygon/polytope

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial import ConvexHull

class TropicalGeometry:
    """Basic tropical geometry computations."""
    
    @staticmethod
    def tropical_add(a, b):
        """Tropical addition: min(a, b)."""
        return min(a, b)
    
    @staticmethod
    def tropical_mult(a, b):
        """Tropical multiplication: a + b."""
        return a + b
    
    @staticmethod
    def tropical_polyval(coeffs, x):
        """
        Evaluate tropical polynomial.
        coeffs: list of (exponent, coefficient) pairs
        f(x) = min_i(coeff_i + exponent_i * x)
        """
        return min(c + e * x for e, c in coeffs)
    
    @staticmethod
    def tropical_hypersurface_1d(coeffs, x_range, num_points=1000):
        """
        Find tropical hypersurface (points where min is achieved twice).
        Returns points where the tropical polynomial is non-differentiable.
        """
        x_vals = np.linspace(x_range[0], x_range[1], num_points)
        y_vals = [TropicalGeometry.tropical_polyval(coeffs, x) for x in x_vals]
        
        # Find points where derivative changes (non-smooth points)
        hypersurface = []
        for i in range(1, len(x_vals) - 1):
            left_slope = (y_vals[i] - y_vals[i-1]) / (x_vals[i] - x_vals[i-1])
            right_slope = (y_vals[i+1] - y_vals[i]) / (x_vals[i+1] - x_vals[i])
            if abs(left_slope - right_slope) > 0.01:
                hypersurface.append(x_vals[i])
        
        return x_vals, y_vals, hypersurface
    
    @staticmethod
    def newton_polygon(coeffs):
        """
        Compute Newton polygon vertices.
        coeffs: list of (exponent, coefficient) pairs
        Returns vertices of upper convex hull of (exponent, -coefficient).
        """
        points = np.array([[e, -c] for e, c in coeffs])
        hull = ConvexHull(points)
        return points[hull.vertices]

Control Theory: The Mathematics of Feedback

control-theory

Real-World Motivation

Control theory provides the mathematical framework for steering dynamical systems toward desired behaviors. From autopilot systems in aircraft to insulin pumps for diabetes management, control systems permeate modern technology. The field emerged from the study of mechanical governors in the 19th century and matured during World War II with the development of fire control systems. Today, control theory underlies robotics, autonomous vehicles, power grid management, and economic policy design. The mathematical tools—ranging from differential equations to optimization and machine learning—enable the design of systems that maintain stability, track references, and reject disturbances.

Definitions

  • State-Space Representation: A system \(\dot{x} = Ax + Bu\), \(y = Cx + Du\) where \(x\) is the state, \(u\) is the control input, and \(y\) is the output.
  • Controllability: The system is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists a control input steering \(x_0\) to \(x_f\) in finite time.
  • Observability: The system is observable if the initial state can be determined from the output history.
  • Stability: A system is asymptotically stable if all eigenvalues of \(A\) have negative real parts.
  • Transfer Function: For a linear time-invariant system, \(G(s) = C(sI - A)^{-1}B + D\).

Theorem: The Pole Placement Theorem

Theorem: Consider the linear system \(\dot{x} = Ax + Bu\) with \(x \\in \\mathbb{R}^n\), \(u \\in \\mathbb{R}^m\). Let \((A, B)\) be controllable. Then for any monic polynomial \(p(s) = s^n + a_{n-1}s^{n-1} + \\cdots + a_0\) of degree \(n\), there exists a state feedback matrix \(K \\in \\mathbb{R}^{m \\times n}\) such that the closed-loop system \(\dot{x} = (A - BK)x\) has characteristic polynomial \(p(s)\).

Proof Sketch

For single-input systems (\(m = 1\)):

Step 1: Transform to controllable canonical form using the controllability matrix \(\mathcal{C} = [B, AB, \\ldots, A^{n-1}B]\).

Step 2: In canonical form, \(A - BK\) has a companion matrix structure where the last row contains the coefficients of the characteristic polynomial.

Step 3: Choose \(K\) to match the desired coefficients.

For multi-input systems, use the fact that controllability implies the existence of a vector \(v\) such that \((A, Bv)\) is controllable. ∎

Notation Guide

  • \(x \\in \\mathbb{R}^n\) — state vector
  • \(u \\in \\mathbb{R}^m\) — control input
  • \(y \\in \\mathbb{R}^p\) — output
  • \(A, B, C, D\) — system matrices
  • \(\mathcal{C} = [B, AB, \\ldots, A^{n-1}B]\) — controllability matrix
  • \(\mathcal{O} = [C^T, (CA)^T, \\ldots, (CA^{n-1})^T]^T\) — observability matrix
  • \(K\) — state feedback gain
  • \(L\) — observer gain

class ControlSystem:
    """Linear time-invariant control system analysis and design."""
    
    def __init__(self, A, B, C=None, D=None):
        self.A = np.array(A, dtype=float)
        self.B = np.array(B, dtype=float)
        self.n = self.A.shape[0]
        self.m = self.B.shape[1]
        
        self.C = np.eye(self.n) if C is None else np.array(C, dtype=float)
        self.D = np.zeros((self.C.shape[0], self.m)) if D is None else np.array(D, dtype=float)
    
    def controllability_matrix(self):
        """Compute the controllability matrix."""
        C = self.B
        for i in range(1, self.n):
            C = np.hstack([C, np.linalg.matrix_power(self.A, i) @ self.B])
        return C
    
    def is_controllable(self, tol=1e-10):
        """Check if system is controllable."""
        C = self.controllability_matrix()
        return np.linalg.matrix_rank(C, tol=tol) == self.n
    
    def observability_matrix(self):
        """Compute the observability matrix."""
        O = self.C
        for i in range(1, self.n):
            O = np.vstack([O, self.C @ np.linalg.matrix_power(self.A, i)])
        return O
    
    def is_observable(self, tol=1e-10):
        """Check if system is observable."""
        O = self.observability_matrix()
        return np.linalg.matrix_rank(O, tol=tol) == self.n
    
    def poles(self):
        """Return system poles (eigenvalues of A)."""
        return eig(self.A)[0]
    
    def is_stable(self):
        """Check if system is asymptotically stable."""
        return all(np.real(self.poles()) < 0)
    
    def lqr(self, Q, R):
        """
        Solve LQR problem: minimize integral(x'Qx + u'Ru)dt.
        Returns optimal gain K and solution P of Riccati equation.
        """
        P = solve_continuous_are(self.A, self.B, Q, R)
        K = np.linalg.solve(R, self.B.T @ P)
        return K, P
    
    def simulate(self, x0, t, u_func=None):
        """Simulate system with initial condition x0."""
        if u_func is None:
            u_func = lambda t, x: np.zeros(self.m)
        
        def dynamics(x, t):
            u = u_func(t, x)
            return self.A @ x + self.B @ u
        
        return odeint(dynamics, x0, t)

Signal Processing: The Mathematics of Information

signal-processing

Real-World Motivation

Signal processing is the mathematical foundation of modern communication, from wireless networks to medical imaging. It provides the tools to extract information from noisy data, compress audio and video, and enable technologies like GPS and MRI. The field draws on Fourier analysis, linear algebra, probability, and optimization to design algorithms that filter, transform, and analyze signals. Applications span telecommunications, radar, speech recognition, financial forecasting, and neuroscience. The fast Fourier transform (FFT), one of the most important algorithms of the 20th century, exemplifies how elegant mathematics enables transformative technology.

Definitions

  • Discrete Signal: A sequence \(x[n]\) for \(n \\in \\mathbb{Z}\), often representing sampled continuous signals.
  • Discrete Fourier Transform (DFT): For a finite sequence \(x[0], \\ldots, x[N-1]\), the DFT is \(X[k] = \\sum_{n=0}^{N-1} x[n] e^{-i 2\\pi kn/N}\).
  • Convolution: \((x * h)[n] = \\sum_{m=-\\infty}^{\\infty} x[m] h[n-m]\).
  • Linear Time-Invariant (LTI) System: A system characterized by its impulse response \(h[n]\), with output \(y = x * h\).
  • Z-Transform: \(X(z) = \\sum_{n=-\\infty}^{\\infty} x[n] z^{-n}\).

Theorem: The Sampling Theorem

Theorem (Nyquist-Shannon): Let \(x(t)\) be a continuous-time signal bandlimited to \([-B, B]\), i.e., its Fourier transform \(\hat{x}(\\xi) = 0\) for \(|\\xi| > B\). If \(x(t)\) is sampled at rate \(f_s > 2B\) (the Nyquist rate), then \(x(t)\) can be perfectly reconstructed from its samples \(x[n] = x(n/f_s)\) via:

\\[x(t) = \\sum_{n=-\\infty}^{\\infty} x[n] \\text{sinc}(f_s t - n)\\]

where \(\text{sinc}(x) = \\frac{\\sin(\\pi x)}{\\pi x}\).

Proof Sketch

Step 1: The sampled signal can be written as \(x_s(t) = x(t) \\cdot \\sum_{n} \\delta(t - nT)\) where \(T = 1/f_s\).

Step 2: In the frequency domain, sampling creates copies of the spectrum at multiples of \(f_s\): \(\hat{x}_s(\\xi) = f_s \\sum_{k} \\hat{x}(\\xi - kf_s)\).

Step 3: If \(f_s > 2B\), these copies don't overlap (no aliasing).

Step 4: Apply an ideal low-pass filter with cutoff \(f_s/2\) to recover \(\hat{x}(\\xi)\), which corresponds to sinc interpolation in time. ∎

Notation Guide

  • \(x[n], X[k]\) — discrete signal and its DFT
  • \(\\hat{x}(\\xi)\) — continuous Fourier transform
  • \(h[n]\) — impulse response
  • \(H(e^{i\\omega})\) — frequency response
  • \(f_s\) — sampling frequency
  • \(\\omega = 2\\pi f/f_s\) — normalized digital frequency
  • \(\text{sinc}(x)\) — normalized sinc function

    def dft(x):
        """Compute DFT using numpy's FFT."""
        return fft(x)
    
    @staticmethod
    def idft(X):
        """Compute inverse DFT."""
        return ifft(X)
    
    @staticmethod
    def convolve(x, h):
        """Linear convolution of two signals."""
        return np.convolve(x, h, mode='full')
    
    @staticmethod
    def circular_convolve(x, h):
        """Circular convolution (for signals of same length)."""
        N = len(x)
        X = fft(x)
        H = fft(h)
        return ifft(X * H).real
    
    @staticmethod
    def fir_filter(x, h):
        """Apply FIR filter with impulse response h."""
        return np.convolve(x, h, mode='same')
    
    @staticmethod
    def sinc_interp(x, t, t_new):
        """
        Sinc interpolation for reconstructing continuous signal.
        x: samples at integer times
        t: original sample times
        t_new: new times for interpolation
        """
        T = t[1] - t[0]  # Sampling period
        y = np.zeros_like(t_new)
        for i, ti in enumerate(t_new):
            y[i] = np.sum(x * np.sinc((ti - t) / T))
        return y
    
    @staticmethod
    def design_lowpass(fc, N, fs=1.0):
        """
        Design FIR lowpass filter using window method.
        fc: cutoff frequency
        N: filter order (number of taps)
        fs: sampling frequency
        """
        n = np.arange(N)
        h = np.sinc(2 * fc / fs * (n - (N-1)/2))
        # Apply Hamming window
        window = 0.54 - 0.46 * np.cos(2 * np.pi * n / (N-1))
        h = h * window
        # Normalize for unity gain at DC
        h = h / np.sum(h)
        return h

Climate Modeling: The Mathematics of Earth's Systems

climate-modeling

Real-World Motivation

Climate modeling represents one of the most ambitious applications of applied mathematics, combining fluid dynamics, thermodynamics, chemistry, and biology to understand Earth's climate system. These models inform policy decisions affecting billions of people, from emission targets to adaptation strategies. The mathematics involves solving partial differential equations on spheres, handling multiple time scales from seconds to millennia, and quantifying uncertainty in predictions. Climate models have successfully reproduced past climate changes and project future warming with increasing confidence, demonstrating the power of mathematical modeling to address existential challenges.

Definitions

  • General Circulation Model (GCM): A numerical model solving the primitive equations of atmospheric and oceanic dynamics on a discretized globe.
  • Primitive Equations: The Navier-Stokes equations simplified for large-scale geophysical flows, including hydrostatic balance and shallow atmosphere approximations.
  • Climate Sensitivity: The equilibrium temperature change in response to a doubling of CO₂, typically denoted \(\Delta T_{2\\times}\).
  • Earth System Model (ESM): A GCM coupled with representations of biogeochemical cycles (carbon, nitrogen), vegetation, and ice sheets.
  • Ensemble Forecasting: Running multiple simulations with perturbed initial conditions to quantify prediction uncertainty.

Theorem: Energy Balance Climate Model

Theorem: Consider the zero-dimensional energy balance model:

\\[C \\frac{dT}{dt} = Q(1 - \\alpha(T)) - \\epsilon(T)\\sigma T^4\\]

where \(C\) is heat capacity, \(Q\) is incoming solar radiation, \(\alpha(T)\) is albedo, \(\epsilon(T)\) is emissivity, and \(\sigma\) is the Stefan-Boltzmann constant. Under appropriate conditions on \(\alpha\) and \(\epsilon\), this model admits multiple equilibrium solutions corresponding to different climate states (snowball Earth, ice-free Earth, and intermediate states).

Proof Sketch

At equilibrium, \(\frac{dT}{dt} = 0\), so:

\\[Q(1 - \\alpha(T)) = \\epsilon(T)\\sigma T^4\\]

Step 1: The left side \(S(T) = Q(1 - \\alpha(T))\) is a step-like function: high albedo (low absorption) at low temperatures (ice-covered), low albedo at high temperatures.

Step 2: The right side \(I(T) = \\epsilon(T)\\sigma T^4\) is increasing and convex.

Step 3: Depending on parameters, \(S(T)\) and \(I(T)\) can intersect at 1, 2, or 3 points, giving rise to multiple equilibria.

Step 4: Stability analysis shows the intermediate equilibrium is unstable (a saddle point), while the cold and warm states are stable attractors. ∎

Notation Guide

  • \(T\) — temperature (K)
  • \(C\) — heat capacity (J/m²K)
  • \(Q = S_0(1 - \\alpha)/4\) — absorbed solar radiation
  • \(S_0 \\approx 1361\) W/m² — solar constant
  • \(\alpha\) — planetary albedo
  • \(\epsilon\) — effective emissivity
  • \(\sigma = 5.67 \\times 10^{-8}\) W/m²K⁴ — Stefan-Boltzmann constant
  • \(\Delta T_{2\\times}\) — climate sensitivity

        return np.where(T < T_ice, alpha_ice, alpha_ocean)

        dT/dt = (Q*(1-alpha) - epsilon*sigma*T^4) / C

        if albedo_func is None:
            alpha = 0.3
        else:
            alpha = albedo_func(T)
        
        absorbed = Q * (1 - alpha)
        emitted = epsilon * self.sigma * T**4
        return (absorbed - emitted) / C

        diff = absorbed - emitted

Noncommutative Geometry: Space Beyond Points

noncommutative-geometry

Historical Context

Noncommutative geometry, pioneered by Alain Connes in the 1980s, extends the correspondence between spaces and algebras to situations where the algebra of functions is noncommutative. Classically, Gelfand duality establishes that compact Hausdorff spaces correspond to commutative C*-algebras. Connes realized that many "singular" spaces—quotients by bad equivalence relations, leaf spaces of foliations, spaces of Penrose tilings—are better described by noncommutative algebras. The theory has profound applications to the Standard Model of particle physics, where Connes and collaborators showed that the Higgs mechanism emerges naturally from a noncommutative geometric framework.

Definitions

  • C*-Algebra: A Banach algebra \(\mathcal{A}\) with involution * satisfying \(|a^*a| = |a|^2\).
  • Spectral Triple: A triple \((\\mathcal{A}, \\mathcal{H}, D)\) where \(\mathcal{A}\) acts on Hilbert space \(\mathcal{H}\) and \(D\) is an unbounded self-adjoint operator with compact resolvent.
  • Dirac Operator: The operator \(D\) in a spectral triple, generalizing the classical Dirac operator.
  • Connes' Distance Formula: For a spectral triple, the distance between states \(\phi, \\psi\) is:

\\[d(\\phi, \\psi) = \\sup\\{|\\phi(a) - \\psi(a)| : a \\in \\mathcal{A}, \\|[D, a]\\| \\leq 1\\}\\]

Theorem: Gelfand-Naimark Duality

Theorem: The category of compact Hausdorff spaces with continuous maps is contravariantly equivalent to the category of commutative unital C*-algebras with *-homomorphisms. The equivalence is given by:

  • Space \(X \\mapsto\) C*-algebra \(C(X)\) of continuous functions
  • C*-algebra \(\mathcal{A} \\mapsto\) space \(\text{Spec}(\\mathcal{A})\) of maximal ideals

Proof Sketch

Step 1: For a compact Hausdorff space \(X\), \(C(X)\) is a commutative C*-algebra with sup norm and pointwise operations.

Step 2: For a commutative C*-algebra \(\mathcal{A}\), the spectrum \(\text{Spec}(\\mathcal{A})\) (maximal ideals with weak* topology) is compact Hausdorff.

Step 3: The Gelfand transform \(\\hat{a}(\\chi) = \\chi(a)\) for \(\\chi \\in \\text{Spec}(\\mathcal{A})\) gives an isomorphism \(\mathcal{A} \\cong C(\\text{Spec}(\\mathcal{A}))\).

Step 4: Continuous maps \(X \\to Y\) correspond to *-homomorphisms \(C(Y) \\to C(X)\) via pullback. ∎

Notation Guide

  • \(C(X)\) — C*-algebra of continuous functions on X
  • \(\mathcal{A}, \\mathcal{B}\) — C*-algebras
  • \(\text{Spec}(\\mathcal{A})\) — spectrum (space of characters)
  • \((\\mathcal{A}, \\mathcal{H}, D)\) — spectral triple
  • \([D, a] = Da - aD\) — commutator
  • \(\Omega_D^1(\\mathcal{A})\) — Connes' differential forms

import numpy as np
from scipy.linalg import expm

class NoncommutativeGeometry:
    """Basic computations for finite noncommutative geometries."""
    
    def __init__(self, algebra_dim, hilbert_dim):
        """
        Initialize finite spectral triple.
        algebra_dim: dimension of matrix algebra (e.g., 2 for M_2(C))
        hilbert_dim: dimension of Hilbert space
        """
        self.n = algebra_dim
        self.N = hilbert_dim
    
    def matrix_algebra_basis(self):
        """Generate basis for M_n(C) as matrices."""
        basis = []
        for i in range(self.n):
            for j in range(self.n):
                E = np.zeros((self.n, self.n), dtype=complex)
                E[i, j] = 1
                basis.append(E)
        return basis
    
    def dirac_operator_random(self, hermitian=True):
        """Generate a random Dirac operator."""
        D = np.random.randn(self.N, self.N) + 1j * np.random.randn(self.N, self.N)
        if hermitian:
            D = (D + D.conj().T) / 2
        return D
    
    def commutator(self, D, a):
        """Compute [D, a] = Da - aD for operator a acting on Hilbert space."""
        # Extend a to Hilbert space (simplified: tensor with identity)
        if self.N % self.n != 0:
            raise ValueError("Hilbert dimension must be multiple of algebra dimension")
        
        k = self.N // self.n
        a_extended = np.kron(a, np.eye(k))
        return D @ a_extended - a_extended @ D
    
    def connes_distance(self, D, phi, psi, algebra_basis, num_samples=100):
        """
        Approximate Connes' distance between states phi and psi.
        d(phi, psi) = sup{|phi(a) - psi(a)| : ||[D, a]|| <= 1}
        """
        max_dist = 0
        
        for _ in range(num_samples):
            # Random element in algebra
            coeffs = np.random.randn(len(algebra_basis))
            a = sum(c * b for c, b in zip(coeffs, algebra_basis))
            
            # Compute commutator norm
            comm = self.commutator(D, a)
            comm_norm = np.linalg.norm(comm, 2)
            
            if comm_norm > 1e-10:
                # Normalize so ||[D, a]|| = 1
                a = a / comm_norm
                
                # Compute distance
                dist = abs(np.trace((phi - psi) @ a))
                max_dist = max(max_dist, dist)
        
        return max_dist
    
    def spectral_action(self, D, f, Lambda):
        """
        Compute spectral action Tr(f(D/Lambda)).
        f: cutoff function
        Lambda: cutoff scale
        """
        eigenvalues = np.linalg.eigvalsh(D)
        return np.sum(f(eigenvalues / Lambda))

Arithmetic Geometry: Numbers and Spaces United

Historical Context

Arithmetic geometry emerged from the study of Diophantine equations—polynomial equations seeking integer or rational solutions. Fermat's Last Theorem, which states that \(x^n + y^n = z^n\) has no non-trivial integer solutions for \(n > 2\), stood as the most famous unsolved problem in mathematics for over 350 years until Andrew Wiles proved it in 1994 using sophisticated tools from algebraic geometry and modular forms. The proof exemplifies the modern approach: translating number-theoretic problems into geometric ones, studying them over various fields and rings, and using cohomology theories to extract arithmetic information.

Definitions

  • Diophantine Equation: A polynomial equation \(f(x_1, \\ldots, x_n) = 0\) where solutions are sought in integers or rationals.
  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point, with equation \(y^2 = x^3 + ax + b\) (affine form).
  • Mordell-Weil Group: The group of rational points on an elliptic curve, denoted \(E(\\mathbb{Q})\).
  • L-function: A generating function encoding arithmetic information, defined as an Euler product over primes.
  • Scheme: A locally ringed space locally isomorphic to the spectrum of a ring, Grothendieck's generalization of algebraic varieties.

Theorem: The Mordell-Weil Theorem

Theorem: Let \(E\) be an elliptic curve over a number field \(K\). Then the group of \(K\)-rational points \(E(K)\) is a finitely generated abelian group:

\\[E(K) \\cong E(K)_{\\text{tors}} \\times \\mathbb{Z}^r\\]

where \(E(K)_{\\text{tors}}\) is the finite torsion subgroup and \(r \\geq 0\) is the rank of \(E\).

Proof Sketch

The proof uses the method of infinite descent:

Step 1 (Weak Mordell-Weil): Show that \(E(K)/2E(K)\) is finite. This uses Galois cohomology and the Kummer sequence.

Step 2 (Height Function): Define a height function \(h: E(K) \\to \\mathbb{R}_{\\geq 0}\) measuring the complexity of points.

Step 3: Show that for any point \(P\), there exists a point \(Q\) with \(2Q = P + R\) where \(R\) comes from a finite set, and \(h(Q) < h(P)\) if \(h(P)\) is large.

Step 4: This descent implies that a finite set of generators suffices. ∎

Notation Guide

  • \(E\) — elliptic curve
  • \(E(K)\) — K-rational points
  • \(r\) — rank of elliptic curve
  • \(h(P)\) — canonical height of point P
  • \(\\text{Reg}(E/K)\) — regulator (determinant of height pairing)
  • \(L(E, s)\) — L-function of elliptic curve
  • \(\\text{Sel}_2(E/K)\) — 2-Selmer group

from fractions import Fraction

class EllipticCurve:
    """Elliptic curve y^2 = x^3 + ax + b over Q."""
    
    def __init__(self, a, b):
        self.a = Fraction(a)
        self.b = Fraction(b)
        self.discriminant = -16 * (4 * self.a**3 + 27 * self.b**2)
        if self.discriminant == 0:
            raise ValueError("Curve is singular")
    
    def is_on_curve(self, P):
        """Check if point P = (x, y) is on the curve."""
        if P is None:  # Point at infinity
            return True
        x, y = P
        return y**2 == x**3 + self.a * x + self.b
    
    def add(self, P, Q):
        """Add two points on the elliptic curve."""
        # Handle point at infinity
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        if x1 == x2:
            if y1 == -y2:
                return None  # P + (-P) = O
            # Point doubling
            m = (3 * x1**2 + self.a) / (2 * y1)
        else:
            # Point addition
            m = (y2 - y1) / (x2 - x1)
        
        x3 = m**2 - x1 - x2
        y3 = m * (x1 - x3) - y1
        
        return (x3, y3)
    
    def negate(self, P):
        """Negate a point: -(x, y) = (x, -y)."""
        if P is None:
            return None
        x, y = P
        return (x, -y)
    
    def multiply(self, n, P):
        """Compute n*P using double-and-add."""
        if n == 0:
            return None
        if n < 0:
            return self.multiply(-n, self.negate(P))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        
        return result
    
    def rational_points_bounded(self, bound):
        """Find rational points with bounded denominator."""
        points = [None]  # Point at infinity
        
        for q in range(1, bound + 1):
            for p in range(-bound * q, bound * q + 1):
                x = Fraction(p, q)
                rhs = x**3 + self.a * x + self.b
                if rhs >= 0:
                    y_sq = rhs
                    # Check if y_sq is a perfect square
                    y_num = int(y_sq.numerator)
                    y_den = int(y_sq.denominator)
                    y_num_sqrt = int(math.isqrt(y_num))
                    y_den_sqrt = int(math.isqrt(y_den))
                    if y_num_sqrt * y_num_sqrt == y_num and y_den_sqrt * y_den_sqrt == y_den:
                        y = Fraction(y_num_sqrt, y_den_sqrt)
                        points.append((x, y))
                        if y != 0:
                            points.append((x, -y))
        
        return points
    
    def naive_height(self, P):
        """Compute naive logarithmic height of point."""
        if P is None:
            return 0
        x, y = P
        return math.log(max(abs(x.numerator), abs(x.denominator)))

Mirror Symmetry: Duality in String Theory

mirror-symmetry

Historical Context

Mirror symmetry emerged from string theory in the late 1980s when physicists noticed that Calabi-Yau manifolds come in pairs with "mirrored" properties. Candelas, de la Ossa, Green, and Parkes made headlines in 1991 when they used mirror symmetry to predict the number of rational curves on the quintic threefold—a problem that had stumped algebraic geometers. Their predictions were later mathematically proven, launching mirror symmetry as a major research area. The phenomenon connects seemingly unrelated areas: complex geometry on one side, symplectic geometry on the other, with deep implications for enumerative geometry and theoretical physics.

Definitions

  • Calabi-Yau Manifold: A compact Kähler manifold with trivial canonical bundle and vanishing first Chern class, admitting Ricci-flat metrics.
  • Hodge Numbers: Dimensions \(h^{p,q} = \\dim H^{p,q}(X)\) of Dolbeault cohomology, satisfying mirror symmetry \(h^{p,q}(X) = h^{n-p,q}(X^\\vee)\).
  • Gromov-Witten Invariants: Counts of curves meeting certain conditions in a symplectic manifold.
  • Yukawa Coupling: A triple product on cohomology encoding the variation of Hodge structure.
  • Mirror Map: A coordinate transformation relating the complex moduli of \(X\) to the Kähler moduli of \(X^\\vee\).

Theorem: Mirror Symmetry for the Quintic Threefold

Theorem (Candelas et al., 1991): Let \(X\) be the quintic threefold (degree 5 hypersurface in \(\mathbb{P}^4\)). Its mirror \(X^\\vee\) has Hodge diamond:

        1
      0   0
    0  101  0
  1  1    1  1
    0  101  0
      0   0
        1

Mirror symmetry predicts the genus-zero Gromov-Witten invariants \(n_d\) (counts of degree-\(d\) rational curves) via the Picard-Fuchs equation on the complex moduli of \(X^\\vee\).

Proof Sketch

The proof strategy involves several key steps:

Step 1 (Periods): Compute periods of the holomorphic 3-form on \(X^\\vee\) satisfying the Picard-Fuchs equation.

Step 2 (Mirror Map): The mirror map \(q = e^{2\\pi i t(z)}\) relates complex structure parameter \(z\) to Kähler parameter \(t\).

Step 3 (Yukawa Coupling): The normalized Yukawa coupling has expansion:

\\[K_{ttt} = 5 + \\sum_{d=1}^\\infty n_d \\frac{d^3 q^d}{1 - q^d}\\]

Step 4: Extract Gromov-Witten invariants \(n_d\) from this expansion. ∎

Notation Guide

  • \(X, X^\\vee\) — mirror pair of Calabi-Yau manifolds
  • \(h^{p,q}\) — Hodge numbers
  • \(\chi = \\sum (-1)^{p+q} h^{p,q}\) — Euler characteristic
  • \(n_d\) — genus-zero Gromov-Witten invariant (degree d)
  • \(\Omega\) — holomorphic volume form
  • \(K_{ttt}\) — Yukawa coupling
  • \(q = e^{2\\pi i t}\) — mirror map coordinate

    """Computational aspects of mirror symmetry."""
    
    @staticmethod
    def quintic_period(z, n_terms=100):
        """
        Fundamental period of the quintic mirror.
        Phi_0(z) = sum_{n=0}^infty (5n)!/(n!)^5 * z^n
        """
        result = 0
        for n in range(n_terms):
            if z == 0 and n > 0:
                continue
            coeff = math.factorial(5*n) / (math.factorial(n)**5)
            result += coeff * (z ** n)
        return result
    
    @staticmethod
    def quintic_period_log(z, n_terms=100):
        """
        Logarithmic period (contains the mirror map).
        Phi_1(z) = Phi_0(z) * log(z) + sum a_n z^n
        """
        phi0 = MirrorSymmetry.quintic_period(z, n_terms)
        
        # The logarithmic correction
        correction = 0
        for n in range(1, n_terms):
            # Coefficients involve harmonic numbers
            H_n = sum(1/k for k in range(1, 5*n+1)) - sum(1/k for k in range(1, n+1))
            coeff = math.factorial(5*n) / (math.factorial(n)**5) * H_n
            correction += coeff * (z ** n)
        
        return phi0 * np.log(z) + correction
    
    @staticmethod
    def mirror_map(z):
        """

        """
        phi0 = MirrorSymmetry.quintic_period(z)

Random Matrix Theory: Universality in Statistics

random-matrix-theory

Historical Context

Random matrix theory (RMT) originated in Eugene Wigner's 1950s work on nuclear physics, where he modeled complex quantum systems by assuming their Hamiltonians were random matrices. Remarkably, statistical properties of energy level spacings in heavy nuclei matched predictions from random matrices, revealing a deep universality principle. Since then, RMT has found applications in number theory (distribution of zeros of the Riemann zeta function), quantum chaos, wireless communications, financial mathematics, and machine learning. The field demonstrates how randomness can reveal structure in complex systems.

Definitions

  • Gaussian Ensembles: Random matrices with entries drawn from Gaussian distributions: GOE (real symmetric), GUE (complex Hermitian), GSE (quaternion self-dual).
  • Level Spacing Distribution: The distribution of gaps between consecutive eigenvalues.
  • Semicircle Law: For a large GUE matrix, the eigenvalue density converges to \(\rho(\\lambda) = \\frac{1}{2\\pi}\\sqrt{4 - \\lambda^2}\) on \([-2, 2]\).
  • Tracy-Widom Distribution: The limiting distribution of the largest eigenvalue in certain random matrix ensembles.
  • Sine Kernel: The correlation kernel for eigenvalues in the bulk: \(K(x, y) = \\frac{\\sin(\\pi(x-y))}{\\pi(x-y)}\).

Theorem: Wigner's Semicircle Law

Theorem: Let \(M_N\) be an \(N \\times N\) Wigner matrix (real symmetric with i.i.d. entries above diagonal, variance \(\sigma^2/N\)). Then the empirical spectral distribution converges almost surely to the semicircle distribution:

\\[\\mu_N = \\frac{1}{N} \\sum_{i=1}^N \\delta_{\\lambda_i} \\xrightarrow{N \\to \\infty} \\mu_{sc}\\]

where \(\mu_{sc}\) has density:

\\[\\frac{d\\mu_{sc}}{d\\lambda} = \\frac{1}{2\\pi\\sigma^2}\\sqrt{4\\sigma^2 - \\lambda^2} \\cdot \\mathbf{1}_{[-2\\sigma, 2\\sigma]}(\\lambda)\\]

Proof Sketch

The proof uses the method of moments:

Step 1: Show that \(\frac{1}{N}\\text{Tr}(M_N^k) \\to \\int \\lambda^k d\\mu_{sc}(\\lambda)\) for all \(k\).

Step 2: Expand the trace as \(\frac{1}{N}\\sum_{i_1, \\ldots, i_k} M_{i_1 i_2} M_{i_2 i_3} \\cdots M_{i_k i_1}\).

Step 3: Only certain paths contribute in the limit—those corresponding to Catalan numbers.

Step 4: The Catalan numbers \(C_k = \\frac{1}{k+1}\\binom{2k}{k}\) are the moments of the semicircle distribution. ∎

Notation Guide

  • GOE, GUE, GSE — Gaussian orthogonal/unitary/symplectic ensembles
  • \(\lambda_i\) — eigenvalues
  • \(\rho(\\lambda)\) — eigenvalue density
  • \(s = \\lambda_{i+1} - \\lambda_i\) — level spacing
  • \(P(s)\) — level spacing distribution
  • \(F_2(t)\) — Tracy-Widom distribution (GUE)
  • \(K_N(x, y)\) — correlation kernel

class RandomMatrixTheory:
    """Random matrix theory computations."""
    
    @staticmethod
    def generate_goe(N, sigma=1.0):
        """Generate N×N GOE matrix (real symmetric)."""
        A = np.random.randn(N, N)
        M = (A + A.T) / np.sqrt(2)
        # Scale for semicircle on [-2*sigma, 2*sigma]
        return M * sigma / np.sqrt(N)
    
    @staticmethod
    def generate_gue(N, sigma=1.0):
        """Generate N×N GUE matrix (complex Hermitian)."""
        A = (np.random.randn(N, N) + 1j * np.random.randn(N, N)) / np.sqrt(2)
        M = (A + A.conj().T) / 2
        return M * sigma * np.sqrt(2) / np.sqrt(N)
    
    @staticmethod
    def semicircle_pdf(x, sigma=1.0):
        """Semicircle probability density."""
        x = np.array(x)
        result = np.zeros_like(x, dtype=float)
        mask = np.abs(x) < 2 * sigma
        result[mask] = (1 / (2 * np.pi * sigma**2)) * np.sqrt(4 * sigma**2 - x[mask]**2)
        return result
    
    @staticmethod
    def wigner_surmise(s, beta=1):
        """
        Wigner surmise for level spacing distribution.
        beta = 1 (GOE), 2 (GUE), 4 (GSE)
        """
        a = np.pi / 4
        if beta == 2:
            a = 4 / np.pi
        elif beta == 4:
            a = 64 / (9 * np.pi)
        
        C = 2 * (a ** (beta/2 + 1)) / gamma(beta/2 + 1)
        return C * (s ** beta) * np.exp(-a * s**2)
    
    @staticmethod
    def level_spacings(eigenvalues):
        """Compute consecutive level spacings."""
        sorted_eig = np.sort(eigenvalues)
        spacings = np.diff(sorted_eig)
        # Normalize by mean spacing
        return spacings / np.mean(spacings)
    
    @staticmethod
    def unfolded_spectrum(eigenvalues):
        """
        Unfold spectrum by fitting cumulative density.
        Returns spacings with mean 1.
        """
        sorted_eig = np.sort(eigenvalues)
        N = len(sorted_eig)
        
        # Fit semicircle cumulative
        x = np.linspace(-2, 2, 1000)
        cdf = np.zeros_like(sorted_eig)
        for i, lam in enumerate(sorted_eig):
            if lam < -2:
                cdf[i] = 0
            elif lam > 2:
                cdf[i] = N
            else:
                # Approximate integral of semicircle
                idx = np.searchsorted(x, lam)
                cdf[i] = N * idx / len(x)
        
        # Spacings in unfolded variable
        unfolded_spacings = np.diff(cdf)
        return unfolded_spacings / np.mean(unfolded_spacings)

He manipulated infinite series with a confidence that often preceded rigorous justification, trusting his instinct for correct results. This style, while occasionally leading to errors that later analysts would correct, generated vast territories of new mathematics. Laplace reportedly advised: "Read Euler, read Euler, he is the master of us all."

Even in blindness, Euler's productivity increased. He dictated to assistants, performing complex calculations mentally while his sons and students wrote. His work on lunar theory, completed during this period, solved a problem that had defeated Newton. Euler died in Russia in 1783, active to the end, having shaped mathematics more profoundly than any individual before or since.

Putnam-Style Problem: Irrationality and Series

Problem: Let \(\alpha\) be an irrational number in \((0, 1)\). Define a sequence by \(a_0 = 0\), \(a_1 = 1\), and for \(n \\geq 2\):

\\[a_n = \\begin{cases} a_{n-1} + a_{n-2} & \\text{if } \\{n\\alpha\\} < \\frac{1}{2} \\\\ a_{n-1} - a_{n-2} & \\text{if } \\{n\\alpha\\} \\geq \\frac{1}{2} \\end{cases}\\]

where \(\{x\\}\) denotes the fractional part of \(x\). Prove that the sequence \((a_n)\) is unbounded.

Hint

Consider the behavior of the sequence along subsequences where \(\{n\\alpha\\}\) stays in one region. Use the fact that for irrational \(\alpha\), the sequence \(\{n\\alpha\\}\) is equidistributed in \([0,1]\). Analyze what happens when you have long runs of the same case.

Solution

Solution: We prove by contradiction that \((a_n)\) is unbounded.

Suppose \((a_n)\) is bounded. Since \(a_n\) are integers (by induction), the sequence takes only finitely many values. Therefore, there exist indices \(m < n\) such that \((a_{m-1}, a_m) = (a_{n-1}, a_n)\).

Consider the "state" of the system as \((a_{k-1}, a_k, \\{k\\alpha\\})\). The transition depends only on \(\{(k+1)\\alpha\\}\).

By Weyl's equidistribution theorem, since \(\alpha\) is irrational, the sequence \(\{n\\alpha\\}\) is uniformly distributed in \([0,1]\). This means that for any \(\epsilon > 0\), there exist arbitrarily long runs where \(\{n\\alpha\\} < 1/2\) and arbitrarily long runs where \(\{n\\alpha\\} \\geq 1/2\).

During a run of \(k\) consecutive steps where \(\{n\\alpha\\} < 1/2\), the recurrence is \(a_n = a_{n-1} + a_{n-2}\), the Fibonacci recurrence. Starting from any positive values, this grows exponentially.

More precisely, if we have a run of length \(k\) in the "addition" regime starting from \((a_{m-1}, a_m)\) with both positive, then:

\\[a_{m+j} \\geq F_j \\cdot \\min(a_{m-1}, a_m)\\]

where \(F_j\) is the \(j\)-th Fibonacci number.

Since Fibonacci numbers grow without bound, and equidistribution guarantees arbitrarily long runs in either regime, the sequence cannot remain bounded.

The only way to prevent exponential growth would be to have \(a_{n-1}\) and \(a_{n-2}\) with opposite signs during long addition runs. But the subtraction regime \((a_n = a_{n-1} - a_{n-2})\) tends to reduce magnitudes when signs differ. The interplay between these regimes, combined with equidistribution, forces unbounded growth. ∎

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of mathematics' most iconic visualizations—a fractal boundary in the complex plane that exhibits infinite complexity at every scale. Defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) (starting from \(z_0 = 0\)) remains bounded, the Mandelbrot set reveals profound connections between iteration, chaos, and geometry.

The set's boundary is a connected, simply connected compact set with Hausdorff dimension 2, yet its boundary has infinite length. Every point in the interior corresponds to a connected filled Julia set, while points outside correspond to disconnected Julia sets. The Mandelbrot set serves as a "catalog" of all possible quadratic Julia sets.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for point c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring using log-log scale
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """Compute the Mandelbrot set on a grid."""
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    M = np.zeros((height, width))
    for i in range(height):
        for j in range(width):
            M[i, j] = mandelbrot(C[i, j], max_iter)
    
    return M

# Create custom colormap
def create_colormap():
    """Create a beautiful colormap for the Mandelbrot set."""
    colors = [
        (0.0, 0.0, 0.2),   # Deep blue (interior)
        (0.0, 0.0, 0.5),   # Blue
        (0.0, 0.4, 1.0),   # Light blue
        (0.0, 0.8, 1.0),   # Cyan
        (0.4, 1.0, 0.4),   # Green
        (1.0, 1.0, 0.0),   # Yellow
        (1.0, 0.6, 0.0),   # Orange
        (1.0, 0.0, 0.0),   # Red
        (0.5, 0.0, 0.0),   # Dark red
        (0.0, 0.0, 0.0),   # Black (high iteration)
    ]
    return LinearSegmentedColormap.from_list("mandelbrot", colors)

print("Generating Mandelbrot set...")
M = mandelbrot_set(width=800, height=800, max_iter=100)
