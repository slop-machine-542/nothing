Algebraic Graph Theory: Spectra and Symmetry

algebraic-graph-theory

Motivation

Algebraic graph theory bridges the discrete world of graphs with the continuous tools of linear algebra and group theory. By associating matrices with graphs and studying their eigenvalues, we unlock powerful techniques for understanding network structure, connectivity, and symmetry. This field has applications ranging from chemistry (Hückel molecular orbital theory) to computer science (expander graphs and network design) to coding theory.

Definitions

  • Adjacency Matrix: For a graph \(G\) with vertices \(v_1, \ldots, v_n\), the adjacency matrix \(A\) is defined by \(A_{ij} = 1\) if \((v_i, v_j)\) is an edge, and \(0\) otherwise.
  • Laplacian Matrix: \(L = D - A\) where \(D\) is the diagonal degree matrix with \(D_{ii} = \deg(v_i)\).
  • Graph Spectrum: The multiset of eigenvalues of the adjacency matrix (or Laplacian).
  • Graph Automorphism: A permutation of vertices preserving adjacency. The set of all automorphisms forms the automorphism group \(\text{Aut}(G)\).
  • Distance-Regular Graph: A graph where the number of vertices at distance \(j\) from \(u\) and distance \(k\) from \(v\) depends only on \(d(u,v)\) and \(j, k\).

Theorem: Spectral Characterization of Bipartite Graphs

Theorem: A graph \(G\) is bipartite if and only if its adjacency spectrum is symmetric about zero. That is, if \(\lambda\) is an eigenvalue with multiplicity \(m\), then so is \(-\lambda\).

Proof

(\(\Rightarrow\)): If \(G\) is bipartite with bipartition \(V = X \cup Y\), define a diagonal matrix \(S\) with \(S_{ii} = 1\) for \(v_i \in X\) and \(S_{ii} = -1\) for \(v_i \in Y\). Then \(SAS = -A\), so if \(Av = \lambda v\), then \(A(Sv) = S(-Av) = -\lambda(Sv)\). Thus eigenvalues come in \(\pm\) pairs.

(\(\Leftarrow\)): If the spectrum is symmetric about zero, then \(\text{tr}(A^k) = 0\) for all odd \(k\). The trace counts closed walks, so there are no odd-length closed walks. This implies no odd cycles, hence \(G\) is bipartite. ∎

Notation Guide

  • \(A(G)\) — adjacency matrix of graph \(G\)
  • \(L(G)\) — Laplacian matrix
  • \(\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_n\) — eigenvalues of adjacency matrix
  • \(\mu_1 \leq \mu_2 \leq \cdots \leq \mu_n\) — eigenvalues of Laplacian
  • \(\chi_G(\lambda) = \det(\lambda I - A)\) — characteristic polynomial
  • \(\text{Aut}(G)\) — automorphism group
  • \(d(u,v)\) — graph distance between vertices

import numpy as np
import networkx as nx
from scipy.linalg import eigh
import matplotlib.pyplot as plt

class AlgebraicGraphTheory:
    """Tools for algebraic graph theory computations."""
    
    def __init__(self, G):
        """Initialize with a NetworkX graph."""
        self.G = G
        self.n = G.number_of_nodes()
        self.A = nx.adjacency_matrix(G).toarray()
        self.L = nx.laplacian_matrix(G).toarray()
        self._compute_spectra()
    
    def _compute_spectra(self):
        """Compute adjacency and Laplacian spectra."""
        self.adj_eigenvals, self.adj_eigenvecs = eigh(self.A)
        self.lap_eigenvals, self.lap_eigenvecs = eigh(self.L)
        # Sort adjacency descending, Laplacian ascending
        idx_adj = np.argsort(self.adj_eigenvals)[::-1]
        idx_lap = np.argsort(self.lap_eigenvals)
        self.adj_eigenvals = self.adj_eigenvals[idx_adj]
        self.adj_eigenvecs = self.adj_eigenvecs[:, idx_adj]
        self.lap_eigenvals = self.lap_eigenvals[idx_lap]
        self.lap_eigenvecs = self.lap_eigenvecs[:, idx_lap]
    
    def is_bipartite_spectral(self):
        """Check bipartiteness using spectral symmetry."""
        eigenvals = np.round(self.adj_eigenvals, decimals=10)
        for lam in eigenvals:
            if lam != 0:
                # Check if -lam is also an eigenvalue with same multiplicity
                count_lam = np.sum(np.abs(eigenvals - lam) < 1e-10)
                count_neg = np.sum(np.abs(eigenvals + lam) < 1e-10)
                if count_lam != count_neg:
                    return False
        return True
    
    def spectral_gap(self):
        """Return the spectral gap (algebraic connectivity)."""
        return self.lap_eigenvals[1]  # Second smallest eigenvalue
    
    def cheeger_estimate(self):
        """Estimate Cheeger constant using spectral gap."""
        lambda_2 = self.spectral_gap()
        d_max = max(dict(self.G.degree()).values())
        # Cheeger inequality: phi^2 / 2 <= lambda_2 <= 2 * phi
        return np.sqrt(2 * lambda_2) / 2

Morse Theory: Topology Through Critical Points

morse-theory

Motivation

Morse theory, developed by Marston Morse in the 1920s, reveals the deep connection between the critical points of smooth functions on manifolds and the topology of those manifolds. By studying how the topology of level sets changes as we vary the function value, we can compute topological invariants like Betti numbers and Euler characteristic. This technique has found applications in dynamical systems, quantum field theory (instanton calculus), and data analysis (persistent homology).

Definitions

  • Morse Function: A smooth function \(f: M \to \mathbb{R}\) on a manifold where all critical points are non-degenerate (Hessian is non-singular).
  • Critical Point: A point \(p \in M\) where \(df_p = 0\) (gradient vanishes).
  • Index of a Critical Point: The number of negative eigenvalues of the Hessian matrix at \(p\), denoted \(\text{ind}(p)\).
  • Sublevel Set: \(M^a = f^{-1}((-\infty, a])\).
  • Handle Attachment: Passing a critical point of index \(k\) corresponds to attaching a \(k\)-handle \(\mathbb{D}^k \times \mathbb{D}^{n-k}\).

Theorem: Morse Inequalities

Theorem: Let \(f\) be a Morse function on a compact manifold \(M\) and let \(c_k\) be the number of critical points of index \(k\). Let \(b_k = \dim H_k(M; \mathbb{R})\) be the Betti numbers. Then:

\[c_k \geq b_k\]

and the stronger Morse inequalities:

\[\sum_{i=0}^{k} (-1)^{k-i} c_i \geq \sum_{i=0}^{k} (-1)^{k-i} b_i\]

with equality when \(k = n = \dim M\).

Proof Sketch

The proof analyzes how homology changes when passing a critical point. Between critical values, the sublevel sets are diffeomorphic. At a critical point of index \(k\), the relative homology \(H_*(M^{a+\epsilon}, M^{a-\epsilon})\) is concentrated in degree \(k\). This gives the Morse complex, a chain complex whose homology equals the singular homology of \(M\). The inequalities follow from the rank-nullity theorem applied to boundary operators. ∎

Notation Guide

  • \(M\) — smooth manifold
  • \(f: M \to \mathbb{R}\) — Morse function
  • \(\text{Crit}(f)\) — set of critical points
  • \(\text{ind}(p)\) — Morse index of critical point \(p\)
  • \(H_k(M)\) — \(k\)-th homology group
  • \(b_k = \dim H_k(M)\) — \(k\)-th Betti number
  • \(c_k\) — number of index-\(k\) critical points
  • \(\chi(M) = \sum (-1)^k b_k\) — Euler characteristic

import numpy as np
from scipy.optimize import minimize
from scipy.linalg import eigh

class MorseTheory:
    """Basic Morse theory computations on 2D surfaces."""
    
    def __init__(self, f, grad_f, hess_f):
        """
        Initialize with function and its derivatives.
        f: function taking (x, y) array
        grad_f: gradient function
        hess_f: Hessian function returning 2x2 matrix
        """
        self.f = f
        self.grad_f = grad_f
        self.hess_f = hess_f
    
    def find_critical_points(self, grid_range=(-2, 2), n_points=100):
        """Find approximate critical points on a grid."""
        x = np.linspace(grid_range[0], grid_range[1], n_points)
        y = np.linspace(grid_range[0], grid_range[1], n_points)
        X, Y = np.meshgrid(x, y)
        
        critical_points = []
        for i in range(n_points):
            for j in range(n_points):
                point = np.array([X[i,j], Y[i,j]])
                grad = self.grad_f(point)
                if np.linalg.norm(grad) < 0.1:  # Approximate critical
                    # Refine with Newton
                    result = minimize(
                        lambda p: np.linalg.norm(self.grad_f(p)),
                        point, method='BFGS'
                    )
                    if result.success and np.linalg.norm(self.grad_f(result.x)) < 1e-6:
                        # Check if new
                        is_new = True
                        for cp in critical_points:
                            if np.linalg.norm(result.x - cp['point']) < 0.1:
                                is_new = False
                                break
                        if is_new:
                            hess = self.hess_f(result.x)
                            eigenvals = eigh(hess)[0]
                            index = np.sum(eigenvals < 0)
                            critical_points.append({
                                'point': result.x,
                                'value': self.f(result.x),
                                'index': index,
                                'hessian': hess,
                                'eigenvals': eigenvals
                            })
        return critical_points
    
    def morse_polynomial(self, critical_points):
        """Compute Morse polynomial."""
        max_index = max(cp['index'] for cp in critical_points)
        coeffs = [0] * (max_index + 1)
        for cp in critical_points:
            coeffs[cp['index']] += 1
        return coeffs
    
    def check_morse_inequalities(self, critical_points, betti_numbers):
        """Verify Morse inequalities given Betti numbers."""
        c = self.morse_polynomial(critical_points)
        inequalities_satisfied = True
        
        for k in range(len(c)):
            lhs = sum((-1)**(k-i) * c[i] for i in range(k+1))
            rhs = sum((-1)**(k-i) * betti[i] for i in range(min(k+1, len(betti))))
            if lhs < rhs:
                inequalities_satisfied = False
            print(f"k={k}: Σ(-1)^{k-i}c_i = {lhs} ≥ Σ(-1)^{k-i}b_i = {rhs}")
        
        return inequalities_satisfied

Operator Algebras: Noncommutative Topology

operator-algebras

Motivation

Operator algebras emerged from quantum mechanics, where observables are represented by operators on Hilbert spaces. The work of von Neumann and Murray in the 1930s revealed deep connections between algebra, analysis, and topology. C*-algebras provide a noncommutative generalization of function algebras, while von Neumann algebras capture the structure of quantum systems. This field bridges pure mathematics and mathematical physics, with applications to knot theory, quantum field theory, and dynamical systems.

Definitions

  • C*-Algebra: A Banach algebra \(\mathcal{A}\) over \(\mathbb{C}\) with an involution \(*: \mathcal{A} \to \mathcal{A}\) satisfying \(\|a^*a\| = \|a\|^2\).
  • Von Neumann Algebra: A *-subalgebra of \(B(H)\) (bounded operators on Hilbert space) that is closed in the weak operator topology and contains the identity.
  • Spectrum: For \(a \in \mathcal{A}\), \(\sigma(a) = \{\lambda \in \mathbb{C} : a - \lambda I \text{ not invertible}\}\).
  • State: A positive linear functional \(\phi: \mathcal{A} \to \mathbb{C}\) with \(\|\phi\| = 1\).
  • GNS Construction: A method to represent a C*-algebra as operators on a Hilbert space from a state.

Theorem: Gelfand-Naimark Theorem

Theorem: Every C*-algebra is isometrically *-isomorphic to a norm-closed *-subalgebra of \(B(H)\) for some Hilbert space \(H\).

Proof Sketch

For commutative C*-algebras, the Gelfand transform provides an isomorphism to \(C_0(X)\) for some locally compact Hausdorff space \(X\). For the general case, one uses the GNS construction: for each state \(\phi\), define a semi-inner product \(\langle a, b \rangle_\phi = \phi(b^*a)\), quotient by null vectors, and complete to get a Hilbert space \(H_\phi\). The direct sum of all such representations over all states gives the desired embedding into \(B(H)\). ∎

Notation Guide

  • \(\mathcal{A}, \mathcal{B}\) — C*-algebras
  • \(a^*\) — adjoint of element \(a\)
  • \(\|a\|\) — norm in the C*-algebra
  • \(B(H)\) — bounded operators on Hilbert space
  • \(\sigma(a)\) — spectrum of \(a\)
  • \(\mathcal{S}(\mathcal{A})\) — state space
  • \(\pi_\phi\) — GNS representation from state \(\phi\)
  • \(\Omega_\phi\) — cyclic vector in GNS construction

import numpy as np
from scipy.linalg import expm, logm, sqrtm

class CStarAlgebra:
    """
    Finite-dimensional C*-algebra represented as matrix algebra.
    In finite dimensions, all C*-algebras are direct sums of matrix algebras.
    """
    
    def __init__(self, matrices):
        """
        Initialize with list of matrices forming the algebra.
        matrices: list of numpy arrays
        """
        self.elements = matrices
        self.dimension = len(matrices)
        self.n = matrices[0].shape[0]  # Matrix size
    
    def is_c_star(self, tol=1e-10):
        """Check if the algebra satisfies C*-algebra axioms."""
        # Check closure under addition, multiplication, scalar mult
        # Check *-operation (conjugate transpose)
        # Check C*-identity: ||a*a|| = ||a||^2
        
        for a in self.elements:
            a_star = a.conj().T
            # Check a* is in algebra (approximately)
            found = False
            for b in self.elements:
                if np.allclose(a_star, b, atol=tol):
                    found = True
                    break
            if not found:
                return False
            
            # Check C*-identity
            norm_a = np.linalg.norm(a, ord=2)
            norm_a_star_a = np.linalg.norm(a_star @ a, ord=2)
            if abs(norm_a_star_a - norm_a**2) > tol:
                return False
        
        return True
    
    def spectrum(self, a):
        """Compute spectrum (eigenvalues) of element a."""
        return np.linalg.eigvals(a)
    
    def spectral_radius(self, a):
        """Compute spectral radius."""
        return max(abs(lam) for lam in self.spectrum(a))
    
    def functional_calculus(self, a, f):
        """
        Apply function f to element a via functional calculus.
        f: function to apply to eigenvalues
        """
        eigenvals, eigenvecs = np.linalg.eigh(a)
        # f(a) = U diag(f(lambda_i)) U*
        f_eigenvals = np.array([f(lam) for lam in eigenvals])
        return eigenvecs @ np.diag(f_eigenvals) @ eigenvecs.conj().T

class MatrixCStar:
    """Concrete implementation: full matrix algebra M_n(C)."""
    
    def __init__(self, n):
        self.n = n
    
    def commutator(self, a, b):
        """Lie bracket [a, b] = ab - ba."""
        return a @ b - b @ a
    
    def state_from_density(self, rho, a):
        """
        Evaluate state given by density matrix rho on element a.
        phi(a) = tr(rho * a)
        """
        return np.trace(rho @ a)
    
    def is_state(self, rho):
        """Check if rho is a valid density matrix (positive, trace 1)."""
        # Check Hermitian
        if not np.allclose(rho, rho.conj().T):
            return False
        # Check positive semidefinite
        eigenvals = np.linalg.eigvalsh(rho)
        if np.any(eigenvals < -1e-10):
            return False
        # Check trace 1
        if abs(np.trace(rho) - 1) > 1e-10:
            return False
        return True
    
    def pure_state(self, psi, a):
        """
        Evaluate pure state |psi⟩⟨psi| on element a.
        phi(a) = ⟨psi|a|psi⟩
        """
        return np.vdot(psi, a @ psi)

Biostatistics: Statistical Methods for Life Sciences

biostatistics

Real-World Motivation

Biostatistics applies statistical methods to biological and medical research, from clinical trials to epidemiology to genetics. With the explosion of genomic data and personalized medicine, biostatistical methods have become essential for understanding disease mechanisms, evaluating treatments, and making public health decisions. Key applications include survival analysis (time-to-event data), longitudinal studies (repeated measurements), and causal inference from observational studies.

Definitions

  • Survival Function: \(S(t) = P(T > t)\) where \(T\) is time to event.
  • Hazard Function: \(h(t) = \lim_{\Delta t \to 0} \frac{P(t \leq T < t + \Delta t \mid T \geq t)}{\Delta t}\).
  • Kaplan-Meier Estimator: Non-parametric estimate \(\hat{S}(t) = \prod_{t_i \leq t} (1 - \frac{d_i}{n_i})\) where \(d_i\) events and \(n_i\) at risk at time \(t_i\).
  • Hazard Ratio: Ratio of hazard functions between two groups.
  • Log-Rank Test: Non-parametric test comparing survival curves between groups.

Theorem: Properties of Kaplan-Meier Estimator

Theorem: Under independent censoring and assuming the censoring times are independent of survival times, the Kaplan-Meier estimator \(\hat{S}(t)\) is:

  1. Consistent: \(\hat{S}(t) \xrightarrow{p} S(t)\) as \(n \to \infty\)
  2. Asymptotically normal: \(\sqrt{n}(\hat{S}(t) - S(t)) \xrightarrow{d} N(0, \sigma^2(t))\)

where the asymptotic variance is given by Greenwood's formula.

Proof Sketch

The Kaplan-Meier estimator can be written as a product of independent Bernoulli proportions. Taking logarithms converts the product to a sum. By the delta method and martingale theory for counting processes, the asymptotic normality follows. Greenwood's formula estimates the variance as:

\[\widehat{\text{Var}}(\hat{S}(t)) = \hat{S}(t)^2 \sum_{t_i \leq t} \frac{d_i}{n_i(n_i - d_i)}\]

∎

Notation Guide

  • \(T\) — survival time (time to event)
  • \(C\) — censoring time
  • \(X = \min(T, C)\) — observed time
  • \(\delta = \mathbf{1}_{T \leq C}\) — event indicator
  • \(S(t)\) — survival function
  • \(H(t)\) — cumulative hazard function
  • \(h(t)\) — hazard function
  • \(n_i\) — number at risk just before \(t_i\)
  • \(d_i\) — number of events at \(t_i\)

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

class SurvivalAnalysis:
    """Survival analysis methods for biostatistics."""
    
    def __init__(self, times, events):
        """
        Initialize with survival data.
        times: array of observed times
        events: array of event indicators (1=event, 0=censored)
        """
        self.times = np.array(times)
        self.events = np.array(events)
        self.n = len(times)
    
    def kaplan_meier(self):
        """Compute Kaplan-Meier survival estimate."""
        # Sort by time
        idx = np.argsort(self.times)
        t_sorted = self.times[idx]
        e_sorted = self.events[idx]
        
        # Unique event times
        unique_times = np.unique(t_sorted[e_sorted == 1])
        
        km_times = [0]
        km_survival = [1.0]
        
        S = 1.0
        for t in unique_times:
            at_risk = np.sum(t_sorted >= t)
            events_at_t = np.sum((t_sorted == t) & (e_sorted == 1))
            
            if at_risk > 0:
                S *= (1 - events_at_t / at_risk)
                km_times.append(t)
                km_survival.append(S)
        
        return np.array(km_times), np.array(km_survival)
    
    def greenwood_variance(self):
        """Compute Greenwood's variance estimate."""
        km_times, km_survival = self.kaplan_meier()
        
        variances = []
        for i, t in enumerate(km_times[1:], 1):
            # Sum of d_j / (n_j * (n_j - d_j)) for t_j <= t
            idx = np.argsort(self.times)
            t_sorted = self.times[idx]
            e_sorted = self.events[idx]
            
            unique_times = np.unique(t_sorted[e_sorted == 1])
            unique_times = unique_times[unique_times <= t]
            
            sum_term = 0
            for t_j in unique_times:
                n_j = np.sum(t_sorted >= t_j)
                d_j = np.sum((t_sorted == t_j) & (e_sorted == 1))
                if n_j > d_j:
                    sum_term += d_j / (n_j * (n_j - d_j))
            
            var = (km_survival[i]**2) * sum_term
            variances.append(var)
        
        return km_times[1:], np.array(variances)
    
    def log_rank_test(self, other):
        """
        Perform log-rank test comparing two survival curves.
        Returns: test statistic, p-value
        """
        # Combine all unique times
        all_times = np.unique(np.concatenate([
            self.times[self.events == 1],
            other.times[other.events == 1]
        ]))
        
        O1 = E1 = V = 0
        
        for t in all_times:
            # Group 1
            n1 = np.sum(self.times >= t)
            o1 = np.sum((self.times == t) & (self.events == 1))
            
            # Group 2
            n2 = np.sum(other.times >= t)
            o2 = np.sum((other.times == t) & (other.events == 1))
            
            # Combined
            n = n1 + n2
            o = o1 + o2
            
            if n > 0 and o > 0:
                E1 += n1 * o / n
                O1 += o1
                V += (n1 * n2 * o * (n - o)) / (n**2 * (n - 1))
        
        chi2 = (O1 - E1)**2 / V if V > 0 else 0
        p_value = 1 - stats.chi2.cdf(chi2, df=1)
        
        return chi2, p_value

Auction Theory: Strategic Bidding and Market Design

auction-theory

Real-World Motivation

Auction theory, a branch of game theory, studies how people behave in auction markets and how to design rules that achieve desired outcomes. From the FCC's spectrum auctions (raising hundreds of billions) to Google Ads and eBay, auctions allocate trillions of dollars of resources annually. The 2020 Nobel Prize in Economics recognized Paul Milgrom and Robert Wilson for their work on auction theory and the design of new auction formats, including the simultaneous multiple round auction used worldwide for spectrum licenses.

Definitions

  • Private Values: Each bidder knows their own valuation but not others'.
  • Common Values: The item has an objective value unknown to all bidders.
  • First-Price Sealed Bid: Bidders submit sealed bids; highest bid wins and pays their bid.
  • Second-Price (Vickrey) Auction: Highest bid wins but pays the second-highest bid.
  • English Auction: Open ascending price; last bidder wins at final price.
  • Dutch Auction: Open descending price; first bidder to accept wins.

Theorem: Revenue Equivalence Theorem

Theorem: Consider an auction with \(n\) risk-neutral bidders with independent private values drawn from the same continuous distribution. Any auction mechanism that:

  1. Always awards the item to the bidder with highest value, and
  2. Gives a bidder with the lowest possible value zero expected payoff

yields the same expected revenue to the seller.

Proof Sketch

Let \(U_i(v)\) be bidder \(i\)'s expected payoff with value \(v\). By the envelope theorem, \(U_i'(v) = Q_i(v)\) where \(Q_i(v)\) is the probability of winning. Integrating: \(U_i(v) = U_i(\underline{v}) + \int_{\underline{v}}^{v} Q_i(t) dt\). Condition (2) gives \(U_i(\underline{v}) = 0\). Expected payment is \(v \cdot Q_i(v) - U_i(v) = v \cdot Q_i(v) - \int_{\underline{v}}^{v} Q_i(t) dt\). This depends only on the allocation rule \(Q_i\), not the payment rule. ∎

Notation Guide

  • \(v_i\) — private value of bidder \(i\)
  • \(b_i\) — bid of bidder \(i\)
  • \(F(v)\) — CDF of value distribution
  • \(f(v)\) — PDF of value distribution
  • \(Q_i(b)\) — probability of winning with bid \(b\)
  • \(P_i(b)\) — expected payment with bid \(b\)
  • \(U_i(v, b)\) — expected utility of bidding \(b\) with value \(v\)
  • \(\beta(v)\) — bidding strategy (equilibrium)

import numpy as np
from scipy import integrate
from scipy.optimize import minimize_scalar

class AuctionTheory:
    """Auction theory computations and simulations."""
    
    def __init__(self, n_bidders, value_dist='uniform', v_max=1):
        """
        Initialize auction model.
        n_bidders: number of bidders
        value_dist: 'uniform' or 'exponential'
        v_max: maximum value (for uniform)
        """
        self.n = n_bidders
        self.dist = value_dist
        self.v_max = v_max
    
    def first_price_equilibrium(self, v):
        """
        Equilibrium bidding strategy for first-price sealed bid.
        For uniform[0,1]: b(v) = (n-1)/n * v
        """
        if self.dist == 'uniform':
            return (self.n - 1) / self.n * v
        else:
            raise NotImplementedError
    
    def expected_revenue_first_price(self):
        """Expected revenue in first-price auction."""
        if self.dist == 'uniform':
            # E[max value] * (n-1)/n = (n-1)/(n+1) * v_max * (n-1)/n
            # Actually: E[second highest] = (n-1)/(n+1) for uniform[0,1]
            return (self.n - 1) / (self.n + 1) * self.v_max
        else:
            raise NotImplementedError
    
    def expected_revenue_second_price(self):
        """Expected revenue in second-price (Vickrey) auction."""
        # Revenue = second highest value = expected (n-1)th order statistic
        if self.dist == 'uniform':
            return (self.n - 1) / (self.n + 1) * self.v_max
        else:
            raise NotImplementedError
    
    def simulate_auction(self, n_simulations=10000, auction_type='first_price'):
        """Simulate auction and compute statistics."""
        revenues = []
        efficiencies = []
        
        for _ in range(n_simulations):
            # Draw values
            if self.dist == 'uniform':
                values = np.random.uniform(0, self.v_max, self.n)
            else:
                values = np.random.exponential(1, self.n)
            
            # Generate bids
            if auction_type == 'first_price':
                bids = [self.first_price_equilibrium(v) for v in values]
            elif auction_type == 'second_price':
                bids = values  # Truthful bidding is dominant strategy
            else:
                raise ValueError("Unknown auction type")
            
            # Determine winner
            winner = np.argmax(bids)
            winning_bid = bids[winner]
            
            # Determine payment
            if auction_type == 'first_price':
                payment = winning_bid
            elif auction_type == 'second_price':
                # Second highest bid
                sorted_bids = np.sort(bids)[::-1]
                payment = sorted_bids[1] if self.n > 1 else 0
            
            revenues.append(payment)
            
            # Efficiency: did highest value bidder win?
            highest_value = np.argmax(values)
            efficiencies.append(winner == highest_value)
        
        return {
            'mean_revenue': np.mean(revenues),
            'std_revenue': np.std(revenues),
            'efficiency': np.mean(efficiencies)
        }
    
    def optimal_reserve_price(self, cost=0):
        """
        Compute optimal reserve price for seller.
        For uniform[0,1]: r* = (1 + c) / 2 where c is seller's cost
        """
        if self.dist == 'uniform':
            return (1 + cost) / 2
        else:
            # Numerical optimization
            def expected_profit(r):
                # P(at least one bid >= r) * E[max bid | max >= r]
                prob_sale = 1 - r**self.n
                if prob_sale == 0:
                    return 0
                # Expected payment with reserve r
                # This is complex; simplified here
                return -prob_sale * (r - cost)  # Negative for minimization
            
            result = minimize_scalar(expected_profit, bounds=(0, self.v_max), method='bounded')
            return result.x

Quantum Groups: Deformations of Symmetry

quantum-groups

Real-World Motivation

Quantum groups emerged from theoretical physics in the 1980s as deformations of Lie groups and enveloping algebras. They provide the algebraic framework for quantum integrable systems, topological quantum field theory, and quantum computing. In condensed matter physics, quantum groups describe anyonic statistics in fractional quantum Hall systems. In knot theory, they yield powerful invariants like the Jones polynomial. Their rich structure connects representation theory, low-dimensional topology, and quantum information.

Definitions

  • Hopf Algebra: An algebra \(H\) with multiplication \(m\), unit \(\eta\), comultiplication \(\Delta: H \to H \otimes H\), counit \(\epsilon\), and antipode \(S: H \to H\) satisfying axioms.
  • Quantum Group \(U_q(\mathfrak{g})\): A deformation of the universal enveloping algebra of Lie algebra \(\mathfrak{g}\) with parameter \(q\).
  • R-Matrix: An invertible element \(R \in H \otimes H\) satisfying the Yang-Baxter equation.
  • Quasitriangular: A Hopf algebra with universal R-matrix satisfying \(\tau \circ \Delta(h) = R \Delta(h) R^{-1}\).
  • Drinfeld-Jimbo Quantum Group: Specific presentation with generators \(E_i, F_i, K_i^{\pm 1}\) and \(q\)-Serre relations.

Theorem: Universal R-Matrix and Yang-Baxter Equation

Theorem: For a quasitriangular Hopf algebra \((H, R)\), the R-matrix satisfies the quantum Yang-Baxter equation:

\[R_{12} R_{13} R_{23} = R_{23} R_{13} R_{12}\]

in \(H \otimes H \otimes H\), where \(R_{12} = R \otimes 1\), \(R_{23} = 1 \otimes R\), etc.

Proof Sketch

The proof uses the defining property of the R-matrix and coassociativity. From \((\Delta \otimes \text{id})(R) = R_{13} R_{23}\) and \((\text{id} \otimes \Delta)(R) = R_{13} R_{12}\), and the fact that \(\Delta\) is an algebra homomorphism, we compute both sides of the YBE. The equality follows from the hexagon axioms of quasitriangular structure. ∎

Notation Guide

  • \(U_q(\mathfrak{g})\) — quantum enveloping algebra
  • \(E_i, F_i, K_i\) — Chevalley generators
  • \(q\) — deformation parameter
  • \([n]_q = \frac{q^n - q^{-n}}{q - q^{-1}}\) — \(q\)-number
  • \([n]_q! = [n]_q [n-1]_q \cdots [1]_q\) — \(q\)-factorial
  • \(R\) — universal R-matrix
  • \(\Delta\) — coproduct
  • \(S\) — antipode
  • \(\tau(a \otimes b) = b \otimes a\) — flip map

class QuantumGroups:
    """Computations related to quantum groups, focusing on U_q(sl_2)."""
    
    def __init__(self, q):
        """Initialize with deformation parameter q."""
        self.q = q
        self.q_inv = 1 / q
    
    def q_number(self, n):
        """Compute [n]_q = (q^n - q^{-n}) / (q - q^{-1})."""
        if abs(self.q - self.q_inv) < 1e-10:
            return n  # Classical limit q -> 1
        return (self.q**n - self.q_inv**n) / (self.q - self.q_inv)
    
    def q_factorial(self, n):
        """Compute [n]_q! = [n]_q [n-1]_q ... [1]_q."""
        result = 1
        for k in range(1, n + 1):
            result *= self.q_number(k)
        return result
    
    def q_binomial(self, n, k):
        """Compute q-binomial coefficient."""
        if k < 0 or k > n:
            return 0
        return self.q_factorial(n) / (self.q_factorial(k) * self.q_factorial(n - k))
    
    def sl2_generators(self, spin):
        """
        Matrix representation of U_q(sl_2) generators for given spin.
        Returns E, F, K as matrices.
        """
        dim = int(2 * spin + 1)
        
        # Basis |j, m⟩ where m = -j, -j+1, ..., j
        E = np.zeros((dim, dim), dtype=complex)
        F = np.zeros((dim, dim), dtype=complex)
        K = np.zeros((dim, dim), dtype=complex)
        
        for idx, m in enumerate(np.arange(-spin, spin + 1)):
            # K|m⟩ = q^m |m⟩
            K[idx, idx] = self.q ** m
            
            # E|m⟩ = sqrt([j-m]_q [j+m+1]_q) |m+1⟩
            if m < spin:
                coeff_E = np.sqrt(self.q_number(spin - m) * self.q_number(spin + m + 1))
                E[idx, idx + 1] = coeff_E
            
            # F|m⟩ = sqrt([j+m]_q [j-m+1]_q) |m-1⟩
            if m > -spin:
                coeff_F = np.sqrt(self.q_number(spin + m) * self.q_number(spin - m + 1))
                F[idx, idx - 1] = coeff_F
        
        return E, F, K
    
    def check_relations(self, E, F, K):
        """Verify U_q(sl_2) defining relations."""
        # K E K^{-1} = q^2 E
        rel1 = K @ E @ np.linalg.inv(K) - self.q**2 * E
        
        # K F K^{-1} = q^{-2} F
        rel2 = K @ F @ np.linalg.inv(K) - self.q_inv**2 * F
        
        # [E, F] = (K - K^{-1}) / (q - q^{-1})
        rel3 = E @ F - F @ E - (K - np.linalg.inv(K)) / (self.q - self.q_inv)
        
        return {
            'KEK_inv': np.linalg.norm(rel1),
            'KFK_inv': np.linalg.norm(rel2),
            'EF_commutator': np.linalg.norm(rel3)
        }
    
    def r_matrix_6j(self, j1, j2, j3, j12, j23, J):
        """
        Compute 6j symbol for quantum group (q-6j symbol).
        This encodes recoupling coefficients.
        """
        # Simplified computation for Racah-Wigner q-6j
        # Full formula involves q-factorials and is quite complex
        
        # Check triangle conditions
        def check_triangle(a, b, c):
            return (abs(a - b) <= c <= a + b) and (a + b + c) % 1 == 0
        
        if not (check_triangle(j1, j2, j12) and check_triangle(j12, j3, J) and
                check_triangle(j2, j3, j23) and check_triangle(j1, j23, J)):
            return 0
        
        # Simplified: return classical 6j as approximation
        # Full q-6j requires more sophisticated computation
        return self._classical_6j(j1, j2, j3, j12, j23, J)
    
    def _classical_6j(self, j1, j2, j3, j12, j23, J):
        """Classical 6j symbol (Racah coefficient)."""
        # Wigner's 6j formula
        from math import factorial

            """Triangle coefficient."""
            return factorial(int(a + b - c)) * factorial(int(a - b + c)) * \

Geometric Measure Theory: Measuring Irregular Sets

geometric-measure-theory

Historical Context

Geometric measure theory emerged in the early 20th century from attempts to solve the Plateau problem—finding surfaces of minimal area spanning given boundaries. Traditional calculus struggled with irregular sets like fractals and surfaces with singularities. The field was founded by Henri Lebesgue, developed by Besicovitch in his work on Kakeya sets, and revolutionized by Herbert Federer and Wendell Fleming in the 1960s with the theory of currents. Today it provides the rigorous foundation for the calculus of variations, minimal surface theory, and analysis on singular spaces.

Definitions

  • Hausdorff Measure: For \(s \geq 0\), \(\mathcal{H}^s(A) = \lim_{\delta \to 0} \inf \{\sum_i (\text{diam } U_i)^s : A \subseteq \bigcup_i U_i, \text{diam } U_i < \delta\}\).
  • Hausdorff Dimension: \(\dim_H(A) = \inf\{s : \mathcal{H}^s(A) = 0\} = \sup\{s : \mathcal{H}^s(A) = \infty\}\).
  • Rectifiable Set: A set that can be covered (up to measure zero) by countably many Lipschitz images of \(\mathbb{R}^k\).
  • Current: A functional on differential forms generalizing oriented submanifolds.
  • Mass of a Current: \(\mathbf{M}(T) = \sup\{T(\omega) : \|\omega\| \leq 1\}\).

Theorem: Structure Theorem for Sets of Finite Perimeter

Theorem (De Giorgi): Let \(E \subseteq \mathbb{R}^n\) be a set of finite perimeter. Then:

  1. The reduced boundary \(\partial^* E\) is \((n-1)\)-rectifiable.
  2. For \(\mathcal{H}^{n-1}\)-a.e. \(x \in \partial^* E\), the blow-up of \(E\) at \(x\) converges to a half-space.
  3. The Gauss-Green formula holds: \(\int_E \text{div } X = \int_{\partial^* E} X \cdot \nu_E \, d\mathcal{H}^{n-1}\).

Proof Sketch

The proof uses the blow-up technique: at almost every boundary point, zooming in reveals a flat limit. The key estimate shows that the excess (deviation from flatness) controls the perimeter. Combining this with a covering argument yields rectifiability. The Gauss-Green formula follows by approximation with smooth sets and the coarea formula. ∎

Notation Guide

  • \(\mathcal{H}^s\) — \(s\)-dimensional Hausdorff measure
  • \(\dim_H(A)\) — Hausdorff dimension
  • \(\mathcal{L}^n\) — Lebesgue measure on \(\mathbb{R}^n\)
  • \(P(E)\) — perimeter of set \(E\)
  • \(\partial^* E\) — reduced boundary
  • \(\nu_E\) — measure-theoretic outer normal
  • \(\mathbf{M}(T)\) — mass of current \(T\)
  • \(\mathcal{D}_k(U)\) — space of \(k\)-currents in \(U\)

import numpy as np
from scipy.spatial.distance import pdist, squareform

class GeometricMeasureTheory:
    """Computations in geometric measure theory."""
    
    def __init__(self):
        pass
    
    def hausdorff_measure_estimate(self, points, s, delta=None):
        """
        Estimate s-dimensional Hausdorff measure of a point set.
        Uses covering by balls of radius < delta.
        """
        if delta is None:
            # Use minimum distance as delta
            if len(points) < 2:
                return 0
            dists = pdist(points)
            delta = np.min(dists[dists > 0]) / 2
        
        # Greedy covering
        uncovered = set(range(len(points)))
        cover_sum = 0
        
        while uncovered:
            # Pick a point
            i = min(uncovered)
            uncovered.remove(i)
            
            # Find all points within delta
            ball = []
            for j in list(uncovered):
                if np.linalg.norm(points[i] - points[j]) < delta:
                    ball.append(j)
            
            for j in ball:
                uncovered.remove(j)
            
            cover_sum += (2 * delta)**s
        
        return cover_sum
    
    def box_counting_dimension(self, points, n_scales=20):
        """
        Estimate box-counting (Minkowski) dimension of point set.
        """
        # Find bounding box
        min_coords = np.min(points, axis=0)
        max_coords = np.max(points, axis=0)
        size = np.max(max_coords - min_coords)
        
        dims = []
        scales = []
        
        for k in range(1, n_scales + 1):
            epsilon = size / k
            scales.append(epsilon)
            
            # Count boxes of size epsilon containing points
            # Grid-based counting
            grid_coords = np.floor((points - min_coords) / epsilon).astype(int)
            unique_boxes = len(set(map(tuple, grid_coords)))
            dims.append(unique_boxes)
        
        # Fit log(N) vs log(1/epsilon)
        log_scales = np.log(1 / np.array(scales))
        log_counts = np.log(np.array(dims))
        
        # Linear regression
        coeffs = np.polyfit(log_scales, log_counts, 1)
        return coeffs[0], scales, dims
    
    def minkowski_content_estimate(self, points, epsilon_values):
        """
        Estimate Minkowski content: lim_{eps->0} Vol(A_eps) / (omega_{n-d} * eps^{n-d})
        """
        contents = []
        
        for eps in epsilon_values:
            # Compute epsilon-parallel set volume
            # For discrete points, this is union of balls
            # Approximate by counting grid cells
            min_coords = np.min(points, axis=0) - eps
            max_coords = np.max(points, axis=0) + eps
            
            grid_size = eps / 2  # Finer grid
            grid_shape = np.ceil((max_coords - min_coords) / grid_size).astype(int)
            
            # Mark cells within eps of any point
            occupied = np.zeros(grid_shape, dtype=bool)
            
            for p in points:
                grid_p = np.floor((p - min_coords) / grid_size).astype(int)
                # Mark neighborhood
                for dx in range(-2, 3):
                    for dy in range(-2, 3):
                        idx = grid_p + np.array([dx, dy])
                        if np.all(idx >= 0) and np.all(idx < grid_shape):
                            cell_center = min_coords + (idx + 0.5) * grid_size
                            if np.linalg.norm(cell_center - p) < eps:
                                occupied[tuple(idx)] = True
            
            volume = np.sum(occupied) * (grid_size ** points.shape[1])
            contents.append(volume)
        
        return epsilon_values, contents

            local_scale = np.mean(dists[nearest])
            local_dims.append(local_scale)
        
        # If locally k-dimensional, variance should be small
        return np.std(local_dims) / np.mean(local_dims) < epsilon

Hyperbolic Geometry: The Geometry of Negative Curvature

hyperbolic-geometry

Historical Context

For over 2000 years, Euclid's parallel postulate was seen as a necessary truth. Attempts to prove it from other axioms failed until the 19th century when Bolyai, Lobachevsky, and Gauss independently discovered that consistent geometries exist where the parallel postulate fails. Hyperbolic geometry—where infinitely many parallels to a line pass through a point not on the line—was initially controversial but gained acceptance through models by Beltrami, Klein, and Poincaré. Today it appears in Einstein's general relativity, complex analysis, and the geometry of three-manifolds.

Definitions

  • Poincaré Disk Model: Points inside unit disk \(\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}\) with metric \(ds^2 = \frac{4|dz|^2}{(1-|z|^2)^2}\).
  • Poincaré Half-Plane Model: Upper half-plane \(\mathbb{H} = \{z : \text{Im}(z) > 0\}\) with metric \(ds^2 = \frac{|dz|^2}{(\text{Im } z)^2}\).
  • Geodesic: Shortest path; in \(\mathbb{D}\), these are circular arcs perpendicular to boundary.
  • Ideal Point: Point on the boundary at infinity (unit circle for \(\mathbb{D}\)).
  • Hyperbolic Distance: \(d(z,w) = 2\tanh^{-1}\left|\frac{z-w}{1-\bar{z}w}\right|\) in disk model.

Theorem: Gauss-Bonnet for Hyperbolic Triangles

Theorem: In hyperbolic geometry, the area of a triangle with angles \(\alpha, \beta, \gamma\) is:

\[\text{Area}(\Delta) = \pi - (\alpha + \beta + \gamma)\]

In particular, the angle sum is always less than \(\pi\), and the defect equals the area.

Proof

Consider the upper half-plane model. A triangle with one vertex at infinity (ideal triangle) has angle sum 0, and its area can be computed directly as \(\pi\). For a general triangle, extend sides to meet the boundary at infinity, forming an ideal triangle containing the original. The area formula follows by subtracting the areas of the three "excess" ideal triangles. The general formula follows from the fact that area is additive and invariant under isometries. ∎

Notation Guide

  • \(\mathbb{H}^n\) — hyperbolic \(n\)-space
  • \(\mathbb{D}\) — Poincaré disk
  • \(ds^2\) — Riemannian metric
  • \(d(z,w)\) — hyperbolic distance
  • \(\kappa = -1\) — Gaussian curvature
  • \(\text{Isom}(\mathbb{H}^n)\) — isometry group
  • \(\partial \mathbb{H}^n\) — boundary at infinity
  • \(\text{PSL}(2, \mathbb{R})\) — group of orientation-preserving isometries

    def disk_to_halfplane(self, z):
        """Convert from disk model to half-plane model."""
        if abs(z) >= 1:
            return np.inf
        return 1j * (1 + z) / (1 - z)
    
    def halfplane_to_disk(self, w):
        """Convert from half-plane model to disk model."""
        if np.isinf(w):
            return 1
        return (w - 1j) / (w + 1j)
    
    def hyperbolic_distance_disk(self, z1, z2):
        """Hyperbolic distance in Poincaré disk."""
        # d = 2 * atanh(|(z1-z2)/(1-conj(z1)*z2)|)
        num = abs(z1 - z2)
        den = abs(1 - np.conj(z1) * z2)
        return 2 * np.arctanh(num / den)
    
    def hyperbolic_distance_halfplane(self, w1, w2):
        """Hyperbolic distance in upper half-plane."""
        # d = arcosh(1 + |w1-w2|^2 / (2*Im(w1)*Im(w2)))
        num = abs(w1 - w2)**2
        den = 2 * w1.imag * w2.imag
        return np.arccosh(1 + num / den)
    
    def geodesic_disk(self, z1, z2, n_points=100):
        """
        Compute geodesic between two points in disk model.
        Returns points along the geodesic.
        """
        if abs(z1 - z2) < 1e-10:
            return np.array([z1])
        
        # Geodesics are circular arcs orthogonal to unit circle
        # Or diameters if z1, z2 are collinear with origin
        
        # Check if on same diameter
        if abs(z1 * np.conj(z2) - np.conj(z1) * z2) < 1e-10:
            # Straight line through origin
            t = np.linspace(0, 1, n_points)
            return z1 + t * (z2 - z1)
        
        # Find circle orthogonal to unit circle passing through z1, z2
        # Center lies on radical axis
        x1, y1 = z1.real, z1.imag
        x2, y2 = z2.real, z2.imag
        
        # Circle: (x-a)^2 + (y-b)^2 = r^2
        # Orthogonal to unit circle: a^2 + b^2 = r^2 + 1
        # Passes through z1, z2
        
        # Solve for center (a, b)
        A = np.array([[2*x1, 2*y1, -1],
                      [2*x2, 2*y2, -1],
                      [0, 0, -1]])
        b_vec = np.array([x1**2 + y1**2 - 1, x2**2 + y2**2 - 1, -1])
        
        try:
            sol = np.linalg.solve(A, b_vec)
            a, b, c = sol
            r = np.sqrt(a**2 + b**2 - c)
            
            # Parametrize arc
            theta1 = np.arctan2(y1 - b, x1 - a)
            theta2 = np.arctan2(y2 - b, x2 - a)
            
            # Choose shorter arc
            if abs(theta2 - theta1) > np.pi:
                if theta2 > theta1:
                    theta1 += 2*np.pi
                else:
                    theta2 += 2*np.pi
            
            theta = np.linspace(theta1, theta2, n_points)
            return a + r * np.cos(theta) + 1j * (b + r * np.sin(theta))
        except np.linalg.LinAlgError:
            # Fall back to straight line
            t = np.linspace(0, 1, n_points)
            return z1 + t * (z2 - z1)
    
    def triangle_area(self, z1, z2, z3):
        """Compute area of hyperbolic triangle using Gauss-Bonnet."""
        # Area = π - (α + β + γ)
        angles = self.triangle_angles(z1, z2, z3)
        return np.pi - sum(angles)
    
    def triangle_angles(self, z1, z2, z3):
        """Compute angles of hyperbolic triangle."""
        angles = []
        vertices = [z1, z2, z3]
        
        for i in range(3):
            a, b, c = vertices[i], vertices[(i+1)%3], vertices[(i+2)%3]
            
            # Compute angle at vertex a
            # Using hyperbolic law of cosines
            A = self.hyperbolic_distance_disk(b, c)
            B = self.hyperbolic_distance_disk(a, c)
            C = self.hyperbolic_distance_disk(a, b)
            
            # cos(α) = (cosh(B)cosh(C) - cosh(A)) / (sinh(B)sinh(C))
            cos_alpha = (np.cosh(B)*np.cosh(C) - np.cosh(A)) / (np.sinh(B)*np.sinh(C))
            cos_alpha = np.clip(cos_alpha, -1, 1)
            angles.append(np.arccos(cos_alpha))
        
        return angles
    
    def mobius_transform(self, z, a, b, c, d):
        """Apply Möbius transformation (az+b)/(cz+d)."""
        if abs(c*z + d) < 1e-10:
            return np.inf
        return (a*z + b) / (c*z + d)
    
    def isometry_disk(self, z, theta, phi):
        """Apply isometry: rotation by theta then hyperbolic translation."""
        # Rotation
        w = z * np.exp(1j * theta)
        # Translation along real axis by phi
        t = np.tan(phi / 2)
        return (w + t) / (1 + t*w)

Topos Theory: Generalized Spaces and Logic

topos-theory

Historical Context

Topos theory emerged from algebraic geometry in the 1960s through the work of Grothendieck and his student Verdier, who needed a general notion of "space" for cohomology theories. In the 1970s, Lawvere and Tierney realized that Grothendieck's definition could be simplified and that toposes provided a foundation for mathematics alternative to set theory. A topos is simultaneously a generalized topological space and a universe of sets with its own internal logic. This duality has made topos theory influential in logic, theoretical computer science, and even physics (where it offers approaches to quantum gravity).

Definitions

  • Category: A collection of objects and morphisms with composition and identities.
  • Functor: A structure-preserving map between categories.
  • Presheaf: A functor \(P: \mathcal{C}^{\text{op}} \to \mathbf{Set}\).
  • Sheaf: A presheaf satisfying a gluing condition for compatible local data.
  • Topos: A category \(\mathcal{E}\) equivalent to the category of sheaves on a site, or equivalently, a category with finite limits, power objects, and a subobject classifier.
  • Subobject Classifier: An object \(\Omega\) classifying subobjects via characteristic morphisms.

Theorem: Mitchell-Bénabou Language

Theorem: Every topos \(\mathcal{E}\) has an internal logic (the Mitchell-Bénabou language) that allows interpreting higher-order logic. Formulas in this language can be interpreted as subobjects of objects in \(\mathcal{E}\), and the topos satisfies intuitionistic logic.

Proof Sketch

The key construction is the subobject classifier \(\Omega\) with universal monomorphism \(\text{true}: 1 \to \Omega\). For any subobject \(m: A \hookrightarrow B\), there exists a unique characteristic map \(\chi_m: B \to \Omega\) with \(m\) as the pullback of \(\text{true}\) along \(\chi_m\). Logical operations correspond to operations on \(\Omega\): conjunction to intersection, disjunction to union, implication to the Heyting algebra structure. Quantifiers use the adjunctions between inverse image and dependent product/sum functors. ∎

Notation Guide

  • \(\mathcal{E}\) — topos (category)
  • \(\mathbf{Set}\) — category of sets
  • \(\text{Sh}(\mathcal{C}, J)\) — category of sheaves on site \((\mathcal{C}, J)\)
  • \(\Omega\) — subobject classifier
  • \(\top: 1 \to \Omega\) — truth value "true"
  • \([\![\phi]\!]\) — interpretation of formula \(\phi\) as subobject
  • \(\Omega^A\) or \(PA\) — power object of \(A\)
  • \(\mathcal{E}(A, B)\) — hom-set (or hom-object)

Georg Cantor: The Architect of Infinity

cantor

Historical Context

Georg Cantor (1845–1918) created set theory, revolutionizing mathematics by introducing rigorous methods for handling infinity. His diagonal argument showed that the real numbers are uncountable, establishing different sizes of infinity. The continuum hypothesis—whether there's a set with cardinality strictly between the integers and reals—became the first problem on Hilbert's famous 1900 list. Cantor faced severe criticism from contemporaries like Kronecker, suffered mental health crises, and died in poverty. Yet his work became the foundation of modern mathematics, from analysis to topology to logic.

Definitions

  • Cardinality: Two sets have the same cardinality if there exists a bijection between them.
  • Countable: A set with the same cardinality as the natural numbers \(\mathbb{N}\).
  • Uncountable: A set that is not countable; e.g., \(\mathbb{R}\).
  • Power Set: \(\mathcal{P}(A)\) is the set of all subsets of \(A\).
  • Continuum Hypothesis (CH): There is no set with cardinality strictly between \(|\mathbb{N}|\) and \(|\mathbb{R}|\).
  • Aleph Numbers: \(\aleph_0 = |\mathbb{N}|\), \(\aleph_1\) is the next cardinal, etc.

Theorem: Cantor's Theorem

Theorem: For any set \(A\), there is no surjection from \(A\) onto its power set \(\mathcal{P}(A)\). In particular, \(|A| < |\mathcal{P}(A)|\).

Proof (Diagonal Argument)

Suppose \(f: A \to \mathcal{P}(A)\) is any function. Define \(B = \{x \in A : x \notin f(x)\}\). Then \(B \in \mathcal{P}(A)\), but for any \(y \in A\), if \(y \in f(y)\) then \(y \notin B\), and if \(y \notin f(y)\) then \(y \in B\). Thus \(B \neq f(y)\) for all \(y\), so \(f\) is not surjective. ∎

Notation Guide

  • \(|A|\) or \(\#A\) — cardinality of set \(A\)
  • \(\aleph_0\) — cardinality of natural numbers
  • \(\mathfrak{c} = 2^{\aleph_0}\) — cardinality of continuum
  • \(\mathcal{P}(A)\) — power set of \(A\)
  • \(\omega\) — first infinite ordinal
  • \(\omega_1\) — first uncountable ordinal
  • \(\beth_0 = \aleph_0, \beth_{\alpha+1} = 2^{\beth_\alpha}\) — beth numbers

The Development of Modern Algebra: From Equations to Structures

The transformation of algebra from a discipline concerned with solving equations to one studying abstract structures represents one of the most profound shifts in mathematical thinking. This evolution, spanning roughly 1830 to 1930, fundamentally changed what it meant to "do algebra" and laid the foundation for modern mathematics.

The story begins with the work of Évariste Galois (1811–1832), whose short life belied his immense influence. Galois developed his theory to understand why general polynomial equations of degree five and higher cannot be solved by radicals. His insight was revolutionary: instead of studying the equation itself, study the group of permutations of its roots that preserve algebraic relations. This group—the Galois group—encodes all information about solvability. Galois wrote his ideas in a feverish burst before his fatal duel at age 20; they were published posthumously by Liouville in 1846 and gradually recognized as transformative.

Meanwhile, William Rowan Hamilton's 1843 discovery of quaternions shattered assumptions about number systems. Hamilton had sought to extend complex numbers to three dimensions; after years of struggle, he realized that four dimensions were necessary, with the crucial sacrifice of commutativity. His famous act of carving the fundamental equations into Brougham Bridge in Dublin marked the birth of noncommutative algebra. Quaternions found applications in mechanics and, much later, computer graphics, but their deeper significance was philosophical: the rules of algebra could be modified.

The late 19th century saw the emergence of abstract structural thinking. Richard Dedekind introduced ideals in algebraic number theory, providing a substitute for unique factorization in rings of algebraic integers. His 1871 supplement to Dirichlet's lectures on number theory presented mathematics with a new level of abstraction—focusing on the properties of structures rather than specific representations. This approach influenced the next generation profoundly.

The early 20th century witnessed the axiomatization of algebra. David Hilbert's work on foundations, Ernst Steinitz's 1910 theory of fields, and the development of ring theory by Fraenkel and Noether created the modern framework. Emmy Noether's 1921 paper "Ideal Theory in Rings" established the general theory of commutative rings, while her work with Emil Artin and others developed what we now call modern algebra.

Noether's influence extended through her students and collaborators. Van der Waerden's 1930 "Modern Algebra" codified the new approach for a generation. The book's organization—groups, rings, fields, modules, vector spaces—became the standard structure of algebra courses. By 1930, algebra had been transformed from the study of polynomial equations to the study of algebraic structures and their homomorphisms, a perspective that would dominate 20th-century mathematics.

Problem: A Functional Equation

Source: Putnam Competition (inspired)

Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all \(x, y \in \mathbb{R}\):

\[f(x^2 + y) = f(x)^2 + f(y)\]

💡 Hint

Start by finding \(f(0)\). Then consider what happens when \(y = 0\) and when \(x = 0\). Show that either \(f(x) = 0\) for all \(x\), or \(f(0) = 0\) and explore the consequences. Consider the behavior on non-negative reals first.

✅ Solution

Step 1: Find \(f(0)\). Setting \(x = y = 0\):

\[f(0) = f(0)^2 + f(0)\]

This gives \(f(0)^2 = 0\), so \(f(0) = 0\).

Step 2: Setting \(y = 0\):

\[f(x^2) = f(x)^2 + f(0) = f(x)^2\]

So \(f(x^2) = f(x)^2 \geq 0\) for all \(x\).

Step 3: Setting \(x = 0\):

\[f(y) = f(0)^2 + f(y) = f(y)\]

This is consistent but gives no new information.

Step 4: From \(f(x^2) = f(x)^2\), we have \(f(t) \geq 0\) for all \(t \geq 0\).

Step 5: For \(a, b \geq 0\), we can write \(a = x^2, b = y\) (assuming \(y \geq 0\)):

\[f(a + b) = f(x^2 + y) = f(x)^2 + f(y) = f(a) + f(b)\]

So \(f\) satisfies Cauchy's equation on \([0, \infty)\).

Step 6: Since \(f(x) \geq 0\) for \(x \geq 0\), the solution to Cauchy's equation is \(f(x) = cx\) for some constant \(c \geq 0\).

Step 7: From \(f(x^2) = f(x)^2\):

\[cx^2 = (cx)^2 = c^2 x^2\]

This gives \(c = c^2\), so \(c = 0\) or \(c = 1\).

Step 8: For \(c = 0\): \(f(x) = 0\) for all \(x\). Check: \(0 = 0 + 0\) ✓

For \(c = 1\): \(f(x) = x\) for \(x \geq 0\). For \(x < 0\), use the original equation with appropriate choices.

Setting \(y = -x^2\) (for any \(x\)):

\[f(0) = f(x)^2 + f(-x^2)\]

\[0 = f(x)^2 + f(-x^2)\]

Since \(-x^2 \leq 0\), if \(f(t) = t\) for all \(t\), then:

\[0 = x^2 + (-x^2) = 0\] ✓

Conclusion: The solutions are \(f(x) = 0\) for all \(x\), and \(f(x) = x\) for all \(x\). ∎

The Mandelbrot Set: Boundary of Chaos

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) (starting with \(z_0 = 0\)) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever-finer detail, with miniature copies of the whole set appearing at all scales.

The set connects to many areas of mathematics: complex dynamics, Kleinian groups, and renormalization theory. The main cardioid and bulbs correspond to regions where the iteration has attracting cycles of different periods. The boundary is where the dynamics transitions from stable to chaotic.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute Mandelbrot iteration for complex number c.
    Returns the number of iterations until escape, or max_iter.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """
    Compute the Mandelbrot set on a grid.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M

def mandelbrot_smooth(c, max_iter=100):
    """
    Compute smooth coloring value using normalized iteration count.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            # Smooth iteration count
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(2)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter
