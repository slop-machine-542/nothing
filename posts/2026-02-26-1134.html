Elliptic Curves: The Unity of Algebra, Geometry, and Number Theory

Motivation: Elliptic curves are among the most fascinating objects in mathematics, appearing at the intersection of algebra, geometry, analysis, and number theory. They played a central role in Andrew Wiles's proof of Fermat's Last Theorem and form the foundation of modern elliptic curve cryptography. The study of elliptic curves reveals deep connections between the discrete world of Diophantine equations and the continuous world of complex analysis.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point (the identity). Over a field \(K\) with characteristic \(\neq 2, 3\), it can be written in Weierstrass form: \(y^2 = x^3 + ax + b\) where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Group Law: The points on an elliptic curve form an abelian group under the chord-tangent law: three collinear points sum to zero (the point at infinity).
  • j-invariant: \(j(E) = 1728 \frac{4a^3}{4a^3 + 27b^2}\) classifies elliptic curves up to isomorphism over algebraically closed fields.
  • Endomorphism Ring: \(\text{End}(E)\) consists of regular maps from \(E\) to itself that preserve the group structure.

Theorem: Mordell-Weil Theorem

Theorem: Let \(E\) be an elliptic curve over a number field \(K\). Then the group of \(K\)-rational points \(E(K)\) is a finitely generated abelian group: \[E(K) \cong E(K)_{\text{tors}} \oplus \mathbb{Z}^r\] where \(E(K)_{\text{tors}}\) is the finite torsion subgroup and \(r\) is the rank of \(E\).

Proof Sketch: The proof uses a descent argument. First, one shows that \(E(K)/2E(K)\) is finite (the weak Mordell-Weil theorem) using the theory of heights and properties of the multiplication-by-\(m\) map. The height function \(h: E(K) \to \mathbb{R}_{\geq 0}\) measures the arithmetic complexity of points and satisfies key properties: there are only finitely many points of bounded height, and \(h(2P) = 4h(P) + O(1)\). Combining the weak theorem with properties of the height function yields the full result through an infinite descent argument.

Notation Guide

  • \(E\): Elliptic curve
  • \(\mathcal{O}\): Point at infinity (identity element)
  • \(E[n]\): n-torsion subgroup (points of order dividing n)
  • \(\hat{h}\): Canonical height (Néron-Tate height)
  • \(L(E,s)\): L-function of the elliptic curve

import numpy as np
import matplotlib.pyplot as plt
from fractions import Fraction

class EllipticCurve:
    """
    Elliptic curve in short Weierstrass form: y^2 = x^3 + ax + b
    """
    def __init__(self, a, b):
        self.a = a
        self.b = b
        self.discriminant = -16 * (4 * a**3 + 27 * b**2)
        if self.discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
    
    def j_invariant(self):
        """Compute the j-invariant of the curve."""
        return 1728 * (4 * self.a**3) / (4 * self.a**3 + 27 * self.b**2)
    
    def is_on_curve(self, x, y):
        """Check if point (x,y) lies on the curve."""
        return y**2 == x**3 + self.a * x + self.b
    
    def point_add(self, P, Q):
        """
        Add two points on the curve using the group law.
        P, Q are tuples (x, y) or None for point at infinity.
        """
        # Point at infinity is None
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # P + (-P) = O
        if x1 == x2 and y1 == -y2:
            return None
        
        # Compute slope
        if x1 == x2 and y1 == y2:
            # Point doubling: tangent slope
            if y1 == 0:
                return None  # Vertical tangent
            m = (3 * x1**2 + self.a) / (2 * y1)
        else:
            # Point addition: chord slope
            m = (y2 - y1) / (x2 - x1)
        
        # Compute new point
        x3 = m**2 - x1 - x2
        y3 = m * (x1 - x3) - y1
        
        return (x3, y3)
    
    def scalar_mult(self, n, P):
        """Compute n*P using double-and-add algorithm."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.scalar_mult(-n, (x, -y))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.point_add(result, addend)
            addend = self.point_add(addend, addend)
            n >>= 1
        
        return result
    
    def plot_curve(self, x_range=(-3, 3), num_points=1000):
        """Plot the elliptic curve over real numbers."""
        x = np.linspace(x_range[0], x_range[1], num_points)
        y_squared = x**3 + self.a * x + self.b
        
        # Only plot where y^2 >= 0
        mask = y_squared >= 0
        x_pos = x[mask]
        y_pos = np.sqrt(y_squared[mask])
        
        fig, ax = plt.subplots(figsize=(10, 8))
        ax.plot(x_pos, y_pos, 'b-', linewidth=1.5, label='$y = +\\sqrt{x^3 + ax + b}$')
        ax.plot(x_pos, -y_pos, 'b-', linewidth=1.5, label='$y = -\\sqrt{x^3 + ax + b}$')
        ax.axhline(y=0, color='k', linewidth=0.5)
        ax.axvline(x=0, color='k', linewidth=0.5)
        ax.set_xlabel('x')
        ax.set_ylabel('y')
        ax.set_title(f'Elliptic Curve: $y^2 = x^3 + {self.a}x + {self.b}$')
        ax.legend()
        ax.grid(True, alpha=0.3)
        ax.set_aspect('equal')
        return fig

Lie Algebras: The Infinitesimal Structure of Symmetry

Motivation: Lie algebras arise naturally as the infinitesimal generators of continuous symmetries. They provide a linearization of Lie groups, transforming difficult nonlinear problems about group elements into tractable linear algebra problems about tangent vectors. From the angular momentum operators in quantum mechanics to the gauge symmetries of particle physics, Lie algebras encode the fundamental symmetries of nature.

Definitions

  • Lie Algebra: A vector space \(\mathfrak{g}\) over a field \(F\) equipped with a bilinear operation \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) called the Lie bracket satisfying:
    • Antisymmetry: \([X, Y] = -[Y, X]\)
    • Jacobi identity: \([X, [Y, Z]] + [Y, [Z, X]] + [Z, [X, Y]] = 0\)
  • Adjoint Representation: \(\text{ad}_X(Y) = [X, Y]\), a linear map from \(\mathfrak{g}\) to itself.
  • Killing Form: \(\kappa(X, Y) = \text{tr}(\text{ad}_X \circ \text{ad}_Y)\), a symmetric bilinear form that classifies semisimple Lie algebras.
  • Semisimple: A Lie algebra with no non-zero abelian ideals; equivalently, its Killing form is non-degenerate (Cartan's criterion).

Theorem: Cartan's Criterion for Semisimplicity

Theorem: A finite-dimensional Lie algebra \(\mathfrak{g}\) over a field of characteristic zero is semisimple if and only if its Killing form \(\kappa\) is non-degenerate.

Proof Sketch: (\(\Rightarrow\)) If \(\mathfrak{g}\) is semisimple, let \(\mathfrak{r} = \{X \in \mathfrak{g} : \kappa(X, Y) = 0 \text{ for all } Y\}\) be the radical of \(\kappa\). One shows \(\mathfrak{r}\) is a solvable ideal using properties of the adjoint representation and the fact that \(\text{tr}(AB) = 0\) for all \(B\) implies \(\text{ad}_X\) is nilpotent. Since \(\mathfrak{g}\) is semisimple, \(\mathfrak{r} = 0\).

(\(\Leftarrow\)) If \(\kappa\) is non-degenerate, let \(\mathfrak{a}\) be an abelian ideal. For \(X \in \mathfrak{a}\) and \(Y \in \mathfrak{g}\), \(\text{ad}_X \circ \text{ad}_Y\) maps \(\mathfrak{g}\) into \(\mathfrak{a}\) and \(\mathfrak{a}\) to 0, so \(\text{tr}(\text{ad}_X \circ \text{ad}_Y) = 0\). Thus \(X\) is in the radical, so \(X = 0\) and \(\mathfrak{a} = 0\).

Notation Guide

  • \(\mathfrak{g}, \mathfrak{h}\): Lie algebras (Fraktur font)
  • \([X, Y]\): Lie bracket
  • \(\text{ad}_X\): Adjoint operator
  • \(\kappa\) or \(B\): Killing form
  • \(\mathfrak{sl}(n)\): Special linear Lie algebra (traceless matrices)
  • \(\mathfrak{so}(n)\): Special orthogonal Lie algebra (skew-symmetric matrices)

import numpy as np
from itertools import combinations

class LieAlgebra:
    """
    Represents a Lie algebra with structure constants.
    """
    def __init__(self, structure_constants):
        """
        Initialize with structure constants f^k_{ij} where [e_i, e_j] = sum_k f^k_{ij} e_k
        structure_constants: 3D array of shape (dim, dim, dim)
        """
        self.f = np.array(structure_constants)
        self.dim = self.f.shape[0]
        self._validate()
    
    def _validate(self):
        """Check Jacobi identity and antisymmetry."""
        # Antisymmetry: f^k_{ij} = -f^k_{ji}
        for i in range(self.dim):
            for j in range(self.dim):
                for k in range(self.dim):
                    assert abs(self.f[k, i, j] + self.f[k, j, i]) < 1e-10, \
                        f"Antisymmetry violated at ({i},{j},{k})"
        
        # Jacobi identity
        for i in range(self.dim):
            for j in range(self.dim):
                for k in range(self.dim):
                    lhs = np.zeros(self.dim)
                    for l in range(self.dim):
                        lhs += (self.f[l, i, j] * self.f[:, l, k] +
                                self.f[l, j, k] * self.f[:, l, i] +
                                self.f[l, k, i] * self.f[:, l, j])
                    assert np.allclose(lhs, 0), f"Jacobi violated at ({i},{j},{k})"
    
    def bracket(self, X, Y):
        """Compute Lie bracket [X, Y]."""
        X, Y = np.array(X), np.array(Y)
        result = np.zeros(self.dim)
        for k in range(self.dim):
            for i in range(self.dim):
                for j in range(self.dim):
                    result[k] += self.f[k, i, j] * X[i] * Y[j]
        return result
    
    def ad(self, X):
        """Compute adjoint representation ad_X as a matrix."""
        X = np.array(X)
        result = np.zeros((self.dim, self.dim))
        for i in range(self.dim):
            for j in range(self.dim):
                for k in range(self.dim):
                    result[i, j] += self.f[i, j, k] * X[k]
        return result
    
    def killing_form(self, X, Y):
        """Compute Killing form κ(X, Y) = tr(ad_X ∘ ad_Y)."""
        ad_X = self.ad(X)
        ad_Y = self.ad(Y)
        return np.trace(ad_X @ ad_Y)
    
    def killing_matrix(self):
        """Compute the Killing form as a matrix κ_{ij} = κ(e_i, e_j)."""
        K = np.zeros((self.dim, self.dim))
        basis = np.eye(self.dim)
        for i in range(self.dim):
            for j in range(self.dim):
                K[i, j] = self.killing_form(basis[i], basis[j])
        return K
    
    def is_semisimple(self):
        """Check semisimplicity using Cartan's criterion."""
        K = self.killing_matrix()
        return abs(np.linalg.det(K)) > 1e-10

def so3_lie_algebra():
    """
    Create the Lie algebra so(3) of 3x3 skew-symmetric matrices.
    Basis: e_1 = L_x, e_2 = L_y, e_3 = L_z (angular momentum operators)
    [L_i, L_j] = ε_{ijk} L_k
    """
    # Structure constants: f^k_{ij} = ε_{ijk} (Levi-Civita)
    f = np.zeros((3, 3, 3))
    epsilon = np.zeros((3, 3, 3))
    epsilon[0, 1, 2] = epsilon[1, 2, 0] = epsilon[2, 0, 1] = 1
    epsilon[0, 2, 1] = epsilon[2, 1, 0] = epsilon[1, 0, 2] = -1
    
    for i in range(3):
        for j in range(3):
            for k in range(3):
                f[k, i, j] = epsilon[i, j, k]
    
    return LieAlgebra(f)

Homological Algebra: Measuring the Failure of Exactness

Motivation: Homological algebra emerged from algebraic topology as a tool to measure how far a sequence of maps deviates from being exact. It provides a unified framework for understanding derived functors, cohomology theories, and obstruction theory. The language of chain complexes, homology, and derived categories has become essential across mathematics, from algebraic geometry to representation theory.

Definitions

  • Chain Complex: A sequence of modules \(\cdots \xrightarrow{d_{n+1}} C_n \xrightarrow{d_n} C_{n-1} \xrightarrow{d_{n-1}} \cdots\) with \(d_n \circ d_{n+1} = 0\) (i.e., \(\text{im}(d_{n+1}) \subseteq \ker(d_n)\)).
  • Homology: \(H_n(C) = \ker(d_n) / \text{im}(d_{n+1})\), measuring the "holes" at position \(n\).
  • Exact Sequence: A chain complex with \(H_n(C) = 0\) for all \(n\), i.e., \(\text{im}(d_{n+1}) = \ker(d_n)\).
  • Chain Map: A collection of maps \(f_n: C_n \to D_n\) commuting with differentials: \(f_{n-1} \circ d_n^C = d_n^D \circ f_n\).
  • Quasi-isomorphism: A chain map inducing isomorphisms on all homology groups.

Theorem: The Long Exact Sequence in Homology

Theorem: Given a short exact sequence of chain complexes \(0 \to A \xrightarrow{f} B \xrightarrow{g} C \to 0\), there exists a natural long exact sequence in homology: \[\cdots \xrightarrow{\partial} H_n(A) \xrightarrow{f_*} H_n(B) \xrightarrow{g_*} H_n(C) \xrightarrow{\partial} H_{n-1}(A) \xrightarrow{f_*} \cdots\]

Proof Sketch: The connecting homomorphism \(\partial: H_n(C) \to H_{n-1}(A)\) is constructed via the snake lemma. Given \([c] \in H_n(C)\), lift to \(b \in B_n\) with \(g(b) = c\). Then \(d(b) \in \ker(g) = \text{im}(f)\), so \(d(b) = f(a)\) for unique \(a \in A_{n-1}\). One verifies \(a\) is a cycle and \([a]\) is independent of choices. Exactness at each position follows from careful diagram chasing using the exactness of the original short exact sequence.

Notation Guide

  • \(C_\bullet\) or \(C_*\): Chain complex
  • \(d_n\) or \(\partial_n\): Differential/boundary map
  • \(Z_n = \ker(d_n)\): Cycles
  • \(B_n = \text{im}(d_{n+1})\): Boundaries
  • \(H_n = Z_n / B_n\): Homology
  • \(f_*\): Induced map on homology

Python Implementation

import numpy as np
from typing import List, Callable, Tuple

class ChainComplex:
    """
    Finite chain complex of vector spaces.
    """
    def __init__(self, dimensions: List[int], differentials: List[np.ndarray]):
        """
        Initialize chain complex.
        
        Args:
            dimensions: List of dimensions [dim(C_0), dim(C_1), ..., dim(C_n)]
            differentials: List of matrices for d_1, d_2, ..., d_n
                          where d_i: C_i -> C_{i-1}
        """
        self.dimensions = dimensions
        self.differentials = [np.array(d) for d in differentials]
        self._validate()
    
    def _validate(self):
        """Verify d^2 = 0."""
        for i, d in enumerate(self.differentials):
            if i + 1 < len(self.differentials):
                d_next = self.differentials[i + 1]
                # Check d_i ∘ d_{i+1} = 0
                composition = d @ d_next
                if not np.allclose(composition, 0):
                    raise ValueError(f"d_{i} ∘ d_{i+1} ≠ 0 at position {i}")
    
    def homology(self, n: int) -> Tuple[int, np.ndarray]:
        """
        Compute n-th homology group.
        Returns (rank, basis matrix).
        """
        if n < 0 or n >= len(self.dimensions):
            return 0, np.array([])
        
        # Get boundary maps
        d_n = self.differentials[n] if n < len(self.differentials) else np.zeros((self.dimensions[n-1], self.dimensions[n]))
        d_n_plus_1 = self.differentials[n + 1] if n + 1 < len(self.differentials) else np.zeros((self.dimensions[n], 0))
        
        # Compute kernel of d_n
        if d_n.size == 0:
            Z_n = np.eye(self.dimensions[n])
        else:
            _, _, Vt = np.linalg.svd(d_n)
            rank = np.linalg.matrix_rank(d_n)
            Z_n = Vt[rank:].T  # Kernel basis
        
        # Compute image of d_{n+1}
        if d_n_plus_1.size == 0:
            B_n = np.zeros((self.dimensions[n], 0))
        else:
            U, s, _ = np.linalg.svd(d_n_plus_1)
            rank = np.linalg.matrix_rank(d_n_plus_1)
            B_n = U[:, :rank]  # Image basis
        
        # H_n = Z_n / B_n
        if Z_n.size == 0:
            return 0, np.array([])
        
        # Project Z_n onto orthogonal complement of B_n
        if B_n.size == 0:
            H_n_basis = Z_n
        else:
            # Gram-Schmidt to find complement
            combined = np.hstack([B_n, Z_n])
            Q, _ = np.linalg.qr(combined)
            H_n_basis = Q[:, B_n.shape[1]:]
        
        rank = H_n_basis.shape[1] if H_n_basis.size > 0 else 0
        return rank, H_n_basis
    
    def betti_numbers(self) -> List[int]:
        """Compute all Betti numbers."""
        return [self.homology(n)[0] for n in range(len(self.dimensions))]
    
    def euler_characteristic(self) -> int:
        """Compute Euler characteristic: χ = Σ (-1)^n dim(C_n) = Σ (-1)^n b_n."""
        return sum((-1)**n * dim for n, dim in enumerate(self.dimensions))

    """

Elliptic Curve Cryptography: Securing the Digital World

Real-World Motivation: Modern cryptography relies on mathematical problems that are computationally hard to solve. While RSA depends on integer factorization, elliptic curve cryptography (ECC) relies on the elliptic curve discrete logarithm problem (ECDLP). ECC offers equivalent security to RSA with much smaller key sizes—making it ideal for mobile devices, IoT, and blockchain applications. Bitcoin, Ethereum, and TLS all use ECC.

Definitions

  • ECDLP: Given points \(P\) and \(Q = nP\) on an elliptic curve over a finite field \(\mathbb{F}_q\), find the integer \(n\).
  • Base Point: A publicly agreed point \(G\) on the curve with large prime order \(n\).
  • Key Pair: Private key \(d \in [1, n-1]\), public key \(Q = dG\).
  • ECDSA: Elliptic Curve Digital Signature Algorithm for signing messages.
  • Curve25519: A specific elliptic curve designed by Daniel Bernstein for fast, secure Diffie-Hellman key exchange.

Theorem: Hasse's Bound

Theorem: Let \(E\) be an elliptic curve over a finite field \(\mathbb{F}_q\) with \(q\) elements. Then the number of \(\mathbb{F}_q\)-rational points satisfies: \[|q + 1 - \#E(\mathbb{F}_q)| \leq 2\sqrt{q}\]

Proof Sketch: The proof uses the Frobenius endomorphism \(\phi: (x, y) \mapsto (x^q, y^q)\). The key identity is \(\#E(\mathbb{F}_q) = \deg(1 - \phi)\). The characteristic polynomial of \(\phi\) acting on the Tate module is \(T^2 - aT + q\) where \(a = q + 1 - \#E(\mathbb{F}_q)\). By properties of the Weil pairing, the roots have absolute value \(\sqrt{q}\), giving \(|a| \leq 2\sqrt{q}\).

Notation

  • \(\mathbb{F}_q\): Finite field with \(q = p^n\) elements
  • \(\#E(\mathbb{F}_q)\): Number of points on curve over \(\mathbb{F}_q\)
  • \(nP\): Scalar multiplication (point added to itself n times)
  • \(O\): Point at infinity (identity)

class FiniteField:
    """Integers modulo p."""
    def __init__(self, value, p):
        self.p = p
        self.value = value % p
    
    def __add__(self, other):
        return FiniteField((self.value + other.value) % self.p, self.p)
    
    def __sub__(self, other):
        return FiniteField((self.value - other.value) % self.p, self.p)
    
    def __mul__(self, other):
        return FiniteField((self.value * other.value) % self.p, self.p)
    
    def __pow__(self, exp):
        return FiniteField(pow(self.value, exp, self.p), self.p)
    
    def __truediv__(self, other):
        # Multiply by modular inverse
        inv = pow(other.value, self.p - 2, self.p)
        return FiniteField((self.value * inv) % self.p, self.p)
    
    def __eq__(self, other):
        return self.value == other.value
    
    def __repr__(self):
        return f"{self.value}"

class ECPoint:
    """Point on elliptic curve over finite field."""
    def __init__(self, x, y, a, b, p, infinity=False):
        self.x = x if isinstance(x, FiniteField) else FiniteField(x, p)
        self.y = y if isinstance(y, FiniteField) else FiniteField(y, p)
        self.a = a
        self.b = b
        self.p = p
        self.infinity = infinity
        
        if not infinity:
            # Verify point is on curve
            lhs = self.y ** 2
            rhs = self.x ** 3 + self.a * self.x + self.b
            assert lhs.value == rhs.value, "Point not on curve"
    
    def __add__(self, other):
        if self.infinity:
            return other
        if other.infinity:
            return self
        
        # Point at infinity cases
        if self.x == other.x and self.y.value == (-other.y.value) % self.p:
            return ECPoint(0, 0, self.a, self.b, self.p, infinity=True)
        
        # Compute slope
        if self.x == other.x and self.y == other.y:
            # Point doubling
            num = 3 * self.x ** 2 + self.a
            den = 2 * self.y
        else:
            # Point addition
            num = other.y - self.y
            den = other.x - self.x
        
        m = num / den
        
        x3 = m ** 2 - self.x - other.x
        y3 = m * (self.x - x3) - self.y
        
        return ECPoint(x3, y3, self.a, self.b, self.p)
    
    def __rmul__(self, n):
        """Scalar multiplication using double-and-add."""
        result = ECPoint(0, 0, self.a, self.b, self.p, infinity=True)
        addend = self
        
        while n > 0:
            if n & 1:
                result = result + addend
            addend = addend + addend
            n >>= 1
        
        return result
    
    def __repr__(self):
        if self.infinity:
            return "O (point at infinity)"
        return f"({self.x}, {self.y})"

Computational Fluid Dynamics: The Navier-Stokes Equations

Real-World Motivation: The Navier-Stokes equations govern the motion of fluids—from blood flow in arteries to weather patterns and aircraft design. Despite their importance, fundamental questions about their solutions remain unanswered, making them one of the seven Millennium Prize Problems. Understanding and approximating these equations is crucial for engineering, climate modeling, and medicine.

Definitions

  • Incompressible Navier-Stokes: For velocity field \(\mathbf{u}(\mathbf{x}, t)\) and pressure \(p(\mathbf{x}, t)\): \[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u} + \mathbf{f}\] \[\nabla \cdot \mathbf{u} = 0\]
  • Reynolds Number: \(\text{Re} = \frac{UL}{\nu}\), the ratio of inertial to viscous forces, determining flow regime.
  • Vorticity: \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\), measuring local rotation.
  • Stream Function: For 2D incompressible flow, \(\psi\) such that \(u = \partial_y \psi\), \(v = -\partial_x \psi\).

Theorem: Energy Dissipation

Theorem: For solutions of the incompressible Navier-Stokes equations in a domain \(\Omega\) with no-slip boundary conditions, the kinetic energy \(E(t) = \frac{1}{2}\int_\Omega |\mathbf{u}|^2 d\mathbf{x}\) satisfies: \[\frac{dE}{dt} = -\nu \int_\Omega |\nabla \mathbf{u}|^2 d\mathbf{x} + \int_\Omega \mathbf{u} \cdot \mathbf{f} d\mathbf{x}\]

Proof: Multiply the momentum equation by \(\mathbf{u}\) and integrate: \[\int_\Omega \mathbf{u} \cdot \frac{\partial \mathbf{u}}{\partial t} d\mathbf{x} + \int_\Omega \mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] d\mathbf{x} = -\frac{1}{\rho}\int_\Omega \mathbf{u} \cdot \nabla p d\mathbf{x} + \nu \int_\Omega \mathbf{u} \cdot \nabla^2 \mathbf{u} d\mathbf{x}\] The nonlinear term vanishes via integration by parts and incompressibility. The pressure term integrates to zero using \(\nabla \cdot \mathbf{u} = 0\). Integration by parts on the viscous term gives \(-\nu \int |\nabla \mathbf{u}|^2\).

Notation

  • \(\mathbf{u}\): Velocity vector field
  • \(p\): Pressure
  • \(\rho\): Density
  • \(\nu\): Kinematic viscosity
  • \(\nabla^2\): Laplacian operator

import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import diags, kron, eye
from scipy.sparse.linalg import spsolve

class NavierStokes2D:
    """
    2D incompressible Navier-Stokes solver using projection method.
    """
    def __init__(self, Nx, Ny, Lx=1.0, Ly=1.0, nu=0.01, dt=0.001):
        self.Nx, self.Ny = Nx, Ny
        self.Lx, self.Ly = Lx, Ly
        self.nu = nu
        self.dt = dt
        
        self.dx = Lx / Nx
        self.dy = Ly / Ny
        
        # Staggered grid
        self.x = np.linspace(0, Lx, Nx)
        self.y = np.linspace(0, Ly, Ny)
        self.X, self.Y = np.meshgrid(self.x, self.y)
        
        # Velocity fields
        self.u = np.zeros((Ny, Nx))  # x-velocity
        self.v = np.zeros((Ny, Nx))  # y-velocity
        self.p = np.zeros((Ny, Nx))  # pressure
    
    def laplacian(self, f):
        """Compute Laplacian using central differences."""
        return ((np.roll(f, -1, 0) - 2*f + np.roll(f, 1, 0)) / self.dy**2 +
                (np.roll(f, -1, 1) - 2*f + np.roll(f, 1, 1)) / self.dx**2)
    
    def divergence(self, u, v):
        """Compute divergence."""
        du_dx = (np.roll(u, -1, 1) - np.roll(u, 1, 1)) / (2*self.dx)
        dv_dy = (np.roll(v, -1, 0) - np.roll(v, 1, 0)) / (2*self.dy)
        return du_dx + dv_dy
    
    def advection(self, u, v):
        """Compute advection terms using upwinding."""
        # du/dt + u*du/dx + v*du/dy
        du_dx = np.where(u > 0,
                        (u - np.roll(u, 1, 1)) / self.dx,
                        (np.roll(u, -1, 1) - u) / self.dx)
        du_dy = np.where(v > 0,
                        (u - np.roll(u, 1, 0)) / self.dy,
                        (np.roll(u, -1, 0) - u) / self.dy)
        
        dv_dx = np.where(u > 0,
                        (v - np.roll(v, 1, 1)) / self.dx,
                        (np.roll(v, -1, 1) - v) / self.dx)
        dv_dy = np.where(v > 0,
                        (v - np.roll(v, 1, 0)) / self.dy,
                        (np.roll(v, -1, 0) - v) / self.dy)
        
        adv_u = u * du_dx + v * du_dy
        adv_v = u * dv_dx + v * dv_dy
        
        return adv_u, adv_v
    
    def step(self):
        """One time step using projection method."""
        # Step 1: Predictor (momentum equation without pressure)
        adv_u, adv_v = self.advection(self.u, self.v)
        
        u_star = self.u - self.dt * adv_u + self.dt * self.nu * self.laplacian(self.u)
        v_star = self.v - self.dt * adv_v + self.dt * self.nu * self.laplacian(self.v)
        
        # Step 2: Pressure correction (solve Poisson equation)
        div = self.divergence(u_star, v_star)
        
        # Simple iterative solver for pressure Poisson equation
        for _ in range(50):
            self.p = 0.25 * (np.roll(self.p, -1, 0) + np.roll(self.p, 1, 0) +
                            np.roll(self.p, -1, 1) + np.roll(self.p, 1, 1) -
                            self.dx**2 * div / self.dt)
        
        # Step 3: Corrector
        dp_dx = (np.roll(self.p, -1, 1) - np.roll(self.p, 1, 1)) / (2*self.dx)
        dp_dy = (np.roll(self.p, -1, 0) - np.roll(self.p, 1, 0)) / (2*self.dy)
        
        self.u = u_star - self.dt * dp_dx
        self.v = v_star - self.dt * dp_dy
        
        # Boundary conditions (no-slip walls)
        self.u[0, :] = self.u[-1, :] = 0
        self.u[:, 0] = self.u[:, -1] = 0
        self.v[0, :] = self.v[-1, :] = 0
        self.v[:, 0] = self.v[:, -1] = 0
    
    def vorticity(self):
        """Compute vorticity (curl of velocity)."""
        dv_dx = (np.roll(self.v, -1, 1) - np.roll(self.v, 1, 1)) / (2*self.dx)
        du_dy = (np.roll(self.u, -1, 0) - np.roll(self.u, 1, 0)) / (2*self.dy)
        return dv_dx - du_dy
    
    def plot(self):
        """Visualize the flow field."""
        fig, axes = plt.subplots(1, 2, figsize=(14, 6))
        
        # Velocity field
        speed = np.sqrt(self.u**2 + self.v**2)
        strm = axes[0].streamplot(self.X, self.Y, self.u, self.v, 
                                   color=speed, cmap='viridis', density=2)
        axes[0].set_xlabel('x')
        axes[0].set_ylabel('y')
        axes[0].set_title('Velocity Field')
        axes[0].set_aspect('equal')
        plt.colorbar(strm.lines, ax=axes[0], label='Speed')
        
        # Vorticity
        vort = self.vorticity()
        im = axes[1].imshow(vort, extent=[0, self.Lx, 0, self.Ly], 
                           origin='lower', cmap='RdBu_r', vmin=-5, vmax=5)
        axes[1].set_xlabel('x')
        axes[1].set_ylabel('y')
        axes[1].set_title('Vorticity')
        axes[1].set_aspect('equal')
        plt.colorbar(im, ax=axes[1], label='Vorticity')
        
        plt.tight_layout()
        return fig

Convex Optimization: The Foundation of Modern Machine Learning

Real-World Motivation: Convex optimization problems can be solved efficiently and reliably, making them the backbone of modern machine learning, signal processing, and control systems. From training support vector machines to portfolio optimization and compressed sensing, convex optimization provides guaranteed global solutions with polynomial-time algorithms. The development of interior-point methods and disciplined convex programming has made these tools accessible to practitioners.

Definitions

  • Convex Set: A set \(C\) where for all \(x, y \in C\) and \(\theta \in [0,1]\): \(\theta x + (1-\theta)y \in C\).
  • Convex Function: A function \(f\) where \(f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)\).
  • Epigraph: \(\text{epi}(f) = \{(x, t) : f(x) \leq t\}\); \(f\) is convex iff its epigraph is convex.
  • Subgradient: For convex \(f\), \(g\) is a subgradient at \(x\) if \(f(y) \geq f(x) + g^T(y-x)\) for all \(y\).
  • Lagrangian: For problem \(\min_x f(x)\) subject to \(h_i(x) = 0\), \(g_j(x) \leq 0\): \[L(x, \lambda, \nu) = f(x) + \sum_i \lambda_i h_i(x) + \sum_j \nu_j g_j(x)\]

Theorem: Strong Duality for Convex Problems

Theorem: Consider the convex optimization problem: \[\begin{align*} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \leq 0, \quad i = 1, \ldots, m \\ & Ax = b \end{align*}\] where \(f_0, \ldots, f_m\) are convex. If Slater's condition holds (there exists strictly feasible \(x\)), then strong duality holds: \(p^* = d^*\), where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Proof Sketch: The proof uses the separating hyperplane theorem. Consider the set \(\mathcal{A} = \{(u, v, t) : \exists x, f_i(x) \leq u_i, Ax - b = v, f_0(x) \leq t\}\) and the point \((0, 0, p^*)\). Since \((0, 0, p^*)\) is on the boundary of \(\mathcal{A}\), there exists a separating hyperplane. Slater's condition ensures the normal vector has the correct structure to derive the dual problem with zero duality gap.

Notation

  • \(\nabla f\): Gradient of \(f\)
  • \(\partial f\): Subdifferential (set of subgradients)
  • \(f^*\): Convex conjugate \(f^*(y) = \sup_x (y^T x - f(x))\)
  • \(p^*, d^*\): Primal and dual optimal values
  • \(\mathcal{L}\): Lagrangian

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

class ConvexOptimizer:
    """
    Collection of convex optimization algorithms.
    """
    
    @staticmethod
    def gradient_descent(f, grad_f, x0, step_size=0.1, max_iter=1000, tol=1e-6):
        """
        Gradient descent for smooth convex functions.
        
        Args:
            f: objective function
            grad_f: gradient function
            x0: initial point
            step_size: learning rate
        """
        x = np.array(x0, dtype=float)
        trajectory = [x.copy()]
        
        for _ in range(max_iter):
            gradient = grad_f(x)
            x_new = x - step_size * gradient
            trajectory.append(x_new.copy())
            
            if np.linalg.norm(x_new - x) < tol:
                break
            x = x_new
        
        return x, np.array(trajectory)
    
    @staticmethod
    def proximal_gradient(f, grad_f, prox_g, x0, step_size=0.1, max_iter=1000, tol=1e-6):
        """
        Proximal gradient descent for f + g where f is smooth.
        
        prox_g: proximal operator of g
        """
        x = np.array(x0, dtype=float)
        trajectory = [x.copy()]
        
        for _ in range(max_iter):
            # Gradient step on f
            y = x - step_size * grad_f(x)
            # Proximal step on g
            x_new = prox_g(y, step_size)
            trajectory.append(x_new.copy())
            
            if np.linalg.norm(x_new - x) < tol:
                break
            x = x_new
        
        return x, np.array(trajectory)
    
    @staticmethod
    def lasso_proximal(X, y, lambda_reg, max_iter=1000):
        """
        Solve LASSO: min ||Xw - y||^2 + lambda * ||w||_1
        using proximal gradient descent.
        """
        n, d = X.shape
        
        # Smooth part: f(w) = ||Xw - y||^2
        def grad_f(w):
            return 2 * X.T @ (X @ w - y)
        
        # Non-smooth part: g(w) = lambda * ||w||_1
        # Proximal operator: soft thresholding
        def prox_g(w, step_size):
            return np.sign(w) * np.maximum(np.abs(w) - lambda_reg * step_size, 0)
        
        # Lipschitz constant of gradient
        L = 2 * np.linalg.norm(X, ord=2)**2
        step_size = 1 / L
        
        w = np.zeros(d)
        return ConvexOptimizer.proximal_gradient(
            lambda w: np.sum((X @ w - y)**2),
            grad_f, prox_g, w, step_size, max_iter
        )
    
    @staticmethod
    def newton_method(f, grad_f, hess_f, x0, max_iter=100, tol=1e-8):
        """
        Newton's method for twice-differentiable convex functions.
        """
        x = np.array(x0, dtype=float)
        trajectory = [x.copy()]
        
        for _ in range(max_iter):
            gradient = grad_f(x)
            hessian = hess_f(x)
            
            # Newton step: solve H * delta = -grad
            delta = np.linalg.solve(hessian, -gradient)
            x_new = x + delta
            trajectory.append(x_new.copy())
            
            if np.linalg.norm(delta) < tol:
                break
            x = x_new
        
        return x, np.array(trajectory)

Knot Theory: The Mathematics of Entanglement

Historical Context: Knot theory began with Lord Kelvin's 1867 proposal that atoms were knotted vortices in the ether—different knots corresponding to different elements. While this physical model proved incorrect, it sparked intense mathematical interest. By the early 20th century, mathematicians like Kurt Reidemeister and James Alexander developed systematic methods to classify knots. The field exploded in the 1980s when Vaughan Jones discovered the Jones polynomial, connecting knot theory to statistical mechanics and quantum groups.

Definitions

  • Knot: An embedding of \(S^1\) into \(\mathbb{R}^3\) (or \(S^3\)), considered up to ambient isotopy.
  • Link: An embedding of multiple disjoint circles.
  • Reidemeister Moves: Three local moves (I, II, III) that generate all ambient isotopies of knot diagrams.
  • Knot Invariant: A quantity that remains unchanged under Reidemeister moves.
  • Crossing Number: The minimum number of crossings in any diagram of the knot.
  • Seifert Surface: An orientable surface whose boundary is the knot.

Theorem: Reidemeister's Theorem

Theorem: Two knot diagrams represent the same knot (are ambient isotopic) if and only if one can be transformed into the other by a finite sequence of Reidemeister moves and planar isotopies.

Proof Sketch: The proof relates knot diagrams to generic projections of knots. An ambient isotopy of a knot can be approximated by a sequence of small deformations. Generically, such deformations only affect the diagram locally. The three Reidemeister moves correspond to the three ways crossings can be created, destroyed, or rearranged during such deformations: (I) adding/removing a kink, (II) sliding one strand over/under another, and (III) sliding a strand over/under a crossing.

Notation Guide

  • \(K, L\): Knots and links
  • \(c(K)\): Crossing number
  • \(\Delta_K(t)\): Alexander polynomial
  • \(V_K(q)\): Jones polynomial
  • \(g(K)\): Genus (minimum genus of Seifert surface)

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class Knot:
    """Represents a mathematical knot and computes invariants."""
    
    def __init__(self, crossings, signs):
        """
        Initialize from Gauss code.
        crossings: list of crossing labels
        signs: dict mapping crossing label to +1 (over) or -1 (under)
        """
        self.crossings = crossings
        self.signs = signs
        self.n_crossings = len(set(abs(c) for c in crossings))
    
    @staticmethod
    def trefoil():
        """Create the trefoil knot (simplest non-trivial knot)."""
        # Gauss code for trefoil
        crossings = [1, -2, 3, -1, 2, -3]
        signs = {1: 1, 2: 1, 3: 1}  # All positive crossings
        return Knot(crossings, signs)
    
    @staticmethod
    def figure_eight():
        """Create the figure-eight knot (only knot with crossing number 4)."""
        crossings = [1, -2, 3, -4, -1, 2, -3, 4]
        signs = {1: 1, 2: -1, 3: 1, 4: -1}
        return Knot(crossings, signs)
    
    def writhe(self):
        """Compute writhe (sum of crossing signs)."""
        return sum(self.signs.values())
    
    def alexander_polynomial(self, t):
        """
        Compute Alexander polynomial at t.
        For trefoil: Δ(t) = t - 1 + t^(-1)
        """
        # Simplified computation for common knots
        if self.n_crossings == 3 and self.writhe() == 3:
            # Trefoil
            return t - 1 + 1/t
        elif self.n_crossings == 4:
            # Figure-eight
            return -t + 3 - 1/t
        return None
    
    def parametric_3d(self, resolution=1000):
        """
        Generate 3D parametric representation.
        Uses Fourier knots for smooth representation.
        """
        t = np.linspace(0, 2*np.pi, resolution)
        
        if self.n_crossings == 3:
            # Trefoil parametric equations
            x = np.sin(t) + 2*np.sin(2*t)
            y = np.cos(t) - 2*np.cos(2*t)
            z = -np.sin(3*t)
        elif self.n_crossings == 4:
            # Figure-eight
            x = (2 + np.cos(2*t)) * np.cos(3*t)
            y = (2 + np.cos(2*t)) * np.sin(3*t)
            z = np.sin(4*t)
        else:
            # Generic torus knot
            p, q = 2, self.n_crossings
            x = (2 + np.cos(q*t)) * np.cos(p*t)
            y = (2 + np.cos(q*t)) * np.sin(p*t)
            z = np.sin(q*t)
        
        return x, y, z
    
    def plot_3d(self, ax=None):
        """Plot the knot in 3D."""
        if ax is None:
            fig = plt.figure(figsize=(10, 10))
            ax = fig.add_subplot(111, projection='3d')
        
        x, y, z = self.parametric_3d()
        
        # Color by arc length for visual effect
        colors = plt.cm.viridis(np.linspace(0, 1, len(x)))
        
        for i in range(len(x) - 1):
            ax.plot([x[i], x[i+1]], [y[i], y[i+1]], [z[i], z[i+1]], 
                   color=colors[i], linewidth=2)
        
        ax.set_xlabel('X')
        ax.set_ylabel('Y')
        ax.set_zlabel('Z')
        ax.set_title(f'Knot with {self.n_crossings} crossings (Writhe: {self.writhe()})')
        
        return ax

Analytic Number Theory: The Distribution of Primes

Historical Context: The study of primes dates back to Euclid's proof of their infinitude, but the modern era began with Gauss and Legendre's conjectures about their distribution. In 1859, Bernhard Riemann's seminal paper introduced the zeta function as a tool for studying primes, connecting analysis and number theory in revolutionary ways. The Prime Number Theorem, proved independently by Hadamard and de la Vallée Poussin in 1896, confirmed Gauss's intuition. Today, the Riemann Hypothesis remains the most important unsolved problem in mathematics.

Definitions

  • Prime Counting Function: \(\pi(x) = \#\{p \leq x : p \text{ prime}\}\).
  • Logarithmic Integral: \(\text{li}(x) = \int_2^x \frac{dt}{\ln t}\), Gauss's approximation to \(\pi(x)\).
  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s} = \prod_p \frac{1}{1-p^{-s}}\) for \(\text{Re}(s) > 1\).
  • Möbius Function: \(\mu(n) = (-1)^k\) if \(n\) is a product of \(k\) distinct primes, 0 if \(n\) has a squared prime factor.
  • Von Mangoldt Function: \(\Lambda(n) = \ln p\) if \(n = p^k\), 0 otherwise.

Theorem: The Prime Number Theorem

Theorem: The number of primes less than or equal to \(x\) satisfies: \[\pi(x) \sim \frac{x}{\ln x} \sim \text{li}(x)\] Equivalently, \(\lim_{x \to \infty} \frac{\pi(x) \ln x}{x} = 1\).

Proof Sketch: The proof uses complex analysis and the Riemann zeta function. The key steps are:

  1. Relate \(\pi(x)\) to \(\psi(x) = \sum_{n \leq x} \Lambda(n)\) via partial summation.
  2. Express \(\psi(x)\) as a contour integral involving \(-\zeta'(s)/\zeta(s)\).
  3. Show \(\zeta(s)\) has no zeros on \(\text{Re}(s) = 1\) (the critical step).
  4. Evaluate the contour integral, showing the main contribution comes from the pole at \(s = 1\).
The absence of zeros on the critical line \(\text{Re}(s) = 1\) ensures the error term is controlled.

Notation Guide

  • \(\pi(x)\): Prime counting function
  • \(\psi(x), \theta(x)\): Chebyshev functions
  • \(\zeta(s)\): Riemann zeta function
  • \(\rho\): Non-trivial zero of \(\zeta(s)\)
  • \(f \sim g\): Asymptotic equivalence

import numpy as np

from scipy.integrate import quad

class PrimeNumberTheory:
    """Tools for exploring the distribution of primes."""
    
    @staticmethod
    def sieve_of_eratosthenes(n):
        """Generate all primes up to n."""
        sieve = np.ones(n + 1, dtype=bool)
        sieve[0:2] = False
        for i in range(2, int(np.sqrt(n)) + 1):
            if sieve[i]:
                sieve[i*i:n+1:i] = False
        return np.where(sieve)[0]
    
    @staticmethod
    def pi(x, primes=None):
        """Prime counting function π(x)."""
        if primes is None:
            primes = PrimeNumberTheory.sieve_of_eratosthenes(int(x) + 1)
        return np.sum(primes <= x)
    
    @staticmethod
    def logarithmic_integral(x):
        """li(x) = ∫₂^x dt/ln(t)."""
        if x <= 2:
            return 0
        result, _ = quad(lambda t: 1/np.log(t), 2, x, limit=100)
        return result
    
    @staticmethod
    def riemann_approximation(x):
        """Riemann's R(x) approximation."""
        # R(x) = Σ μ(n)/n * li(x^(1/n))
        result = 0
        for n in range(1, 50):  # Truncate series
            # Möbius function
            mu = PrimeNumberTheory.mobius(n)
            if mu != 0:
                result += mu / n * PrimeNumberTheory.logarithmic_integral(x**(1/n))
        return result
    
    @staticmethod
    def mobius(n):
        """Compute Möbius function μ(n)."""
        if n == 1:
            return 1
        factors = PrimeNumberTheory.factorize(n)
        # Check for squared prime factor
        for p, exp in factors.items():
            if exp > 1:
                return 0
        return (-1)**len(factors)
    
    @staticmethod
    def factorize(n):
        """Return prime factorization as dict {p: exponent}."""
        factors = {}
        d = 2
        while d * d <= n:
            while n % d == 0:
                factors[d] = factors.get(d, 0) + 1
                n //= d
            d += 1
        if n > 1:
            factors[n] = factors.get(n, 0) + 1
        return factors
    
    @staticmethod
    def von_mangoldt(n):
        """Von Mangoldt function Λ(n)."""
        if n <= 1:
            return 0
        factors = PrimeNumberTheory.factorize(n)
        if len(factors) == 1:
            p = list(factors.keys())[0]
            return np.log(p)
        return 0
    
    @staticmethod
    def chebyshev_psi(x):
        """Chebyshev function ψ(x) = Σ_{n≤x} Λ(n)."""
        return sum(PrimeNumberTheory.von_mangoldt(n) for n in range(1, int(x) + 1))
    
    @staticmethod
    def zeta_zeros_approx(n_zeros=10):
        """
        Approximate first few non-trivial zeros of ζ(s).

        """
        # First few actual zeros on critical line Re(s) = 1/2

            37.586178, 40.918719, 43.327073, 48.005151, 49.773832
        ]
        return np.array(known_zeros[:n_zeros])

Algebraic Number Theory: Beyond the Rationals

Historical Context: Algebraic number theory emerged from attempts to prove Fermat's Last Theorem. In the 1840s, Ernst Kummer discovered that unique factorization fails in certain cyclotomic fields, leading him to introduce ideal numbers—precursors to the modern concept of ideals. Richard Dedekind later systematized this into the theory of ideals and algebraic integers. The field flourished in the 20th century with class field theory and the Langlands program, connecting number theory to representation theory and algebraic geometry.

Definitions

  • Algebraic Number: A complex number \(\alpha\) that is a root of a non-zero polynomial with rational coefficients.
  • Algebraic Integer: A root of a monic polynomial with integer coefficients.
  • Number Field: A finite extension \(K/\mathbb{Q}\), of the form \(\mathbb{Q}(\alpha)\) for some algebraic number \(\alpha\).
  • Ring of Integers: \(\mathcal{O}_K = \{\alpha \in K : \alpha \text{ is an algebraic integer}\}\).
  • Ideal: A subset \(I \subseteq \mathcal{O}_K\) closed under addition and under multiplication by elements of \(\mathcal{O}_K\).
  • Class Group: \(\text{Cl}(K) = \text{Frac}(\mathcal{O}_K) / \text{Principal ideals}\), measuring failure of unique factorization.

Theorem: Finiteness of the Class Group

Theorem: For any number field \(K\), the class group \(\text{Cl}(K)\) is finite.

Proof Sketch: The proof uses Minkowski's geometry of numbers. One shows:

  1. Every ideal class contains an integral ideal with bounded norm.
  2. There are only finitely many ideals with norm \(\leq B\) for any bound \(B\).
Specifically, Minkowski's bound states that every ideal class contains an ideal \(I\) with: \[N(I) \leq \frac{n!}{n^n}\left(\frac{4}{\pi}\right)^{r_2} \sqrt{|d_K|}\] where \(n = [K:\mathbb{Q}]\), \(r_2\) is the number of complex embeddings, and \(d_K\) is the discriminant.

Notation Guide

  • \(K, L\): Number fields
  • \(\mathcal{O}_K\): Ring of integers
  • \(N(I)\): Norm of an ideal
  • \(d_K\): Discriminant of \(K\)
  • \(h_K = |\text{Cl}(K)|\): Class number
  • \(\mathfrak{p}, \mathfrak{q}\): Prime ideals (Fraktur font)

import numpy as np
import sympy as sp
from sympy import sqrt, Rational, Poly, symbols

class QuadraticField:
    """
    Quadratic number field Q(√d) where d is squarefree.
    """
    def __init__(self, d):
        self.d = d
        self.squarefree = self._is_squarefree(abs(d))
        if not self.squarefree:
            raise ValueError(f"{d} is not squarefree")
        
        # Determine ring of integers
        if self.d % 4 == 1:
            # O_K = Z[(1+√d)/2]
            self.integral_basis = [1, (1 + sqrt(d))/2]
            self.discriminant = d
        else:
            # O_K = Z[√d]
            self.integral_basis = [1, sqrt(d)]
            self.discriminant = 4 * d
    
    def _is_squarefree(self, n):
        """Check if n is squarefree."""
        if n <= 1:
            return False
        i = 2
        while i * i <= n:
            if n % (i * i) == 0:
                return False
            i += 1
        return True
    
    def norm(self, a, b):
        """
        Compute norm of a + b√d (or a + b(1+√d)/2 if d ≡ 1 mod 4).
        N(a + b√d) = (a + b√d)(a - b√d) = a² - db²
        """
        if self.d % 4 == 1:
            # a + b(1+√d)/2
            # = (2a + b)/2 + (b/2)√d
            alpha = (2*a + b) / 2
            beta = b / 2
            return alpha**2 - self.d * beta**2
        else:
            return a**2 - self.d * b**2
    
    def trace(self, a, b):
        """Trace of a + b√d."""
        if self.d % 4 == 1:
            return 2*a + b
        else:
            return 2*a
    
    def is_integer(self, a, b):
        """Check if a + b√d is an algebraic integer."""
        if self.d % 4 == 1:
            # Must be of form m + n(1+√d)/2
            # a + b√d = m + n/2 + (n/2)√d
            # So b = n/2, a = m + n/2 = m + b
            # n = 2b must be integer, m = a - b must be integer
            return b.is_integer and (a - b).is_integer if hasattr(b, 'is_integer') else (2*b == int(2*b) and (a - b) == int(a - b))
        else:
            return a.is_integer and b.is_integer if hasattr(a, 'is_integer') else (a == int(a) and b == int(b))
    
    def minkowski_bound(self):
        """Compute Minkowski bound for class number."""
        from sympy import factorial, pi, sqrt as sym_sqrt, Abs
        
        if self.d > 0:
            # Real quadratic field
            r2 = 0
        else:
            # Imaginary quadratic field
            r2 = 1
        
        n = 2  # Degree
        bound = (factorial(n) / n**n) * (4/pi)**r2 * sym_sqrt(Abs(self.discriminant))
        return bound
    
    def units(self):
        """
        Return fundamental unit for real quadratic fields.
        For imaginary quadratic, only roots of unity.
        """
        if self.d < 0:
            # Imaginary: only roots of unity
            if self.d == -1:
                return [1, -1, sp.I, -sp.I]  # Gaussian integers
            elif self.d == -3:
                omega = (-1 + sqrt(-3))/2
                return [omega**k for k in range(6)]
            else:
                return [1, -1]
        else:
            # Real: find fundamental unit using continued fractions
            # Simplified: return minimal solution to x² - dy² = ±1
            x, y = self._solve_pell()
            return x + y*sqrt(self.d)
    
    def _solve_pell(self):
        """Find minimal solution to x² - dy² = ±1."""
        # Simplified brute force for small d
        limit = 1000
        for x in range(2, limit):
            y_squared = (x**2 - 1) / self.d
            if y_squared > 0:
                y = int(np.sqrt(y_squared))
                if y * y == y_squared:
                    return x, y
        return None, None
    
    def factorization_info(self):
        """Information about factorization in this field."""
        info = {
            'd': self.d,
            'discriminant': self.discriminant,
            'minkowski_bound': float(self.minkowski_bound()),
            'integral_basis': self.integral_basis
        }
        return info

Category Theory: The Mathematics of Structure

Historical Context: Category theory was invented by Samuel Eilenberg and Saunders Mac Lane in 1945 to formalize natural transformations in algebraic topology. What began as a technical tool quickly revealed itself as a unifying language for mathematics. Alexander Grothendieck revolutionized algebraic geometry using categorical methods in the 1960s. Today, category theory influences not only pure mathematics but also computer science (type theory, functional programming), logic, and physics (topological quantum field theory).

Definitions

  • Category: Consists of objects and morphisms (arrows) satisfying:
    • Composition: If \(f: A \to B\) and \(g: B \to C\), then \(g \circ f: A \to C\)
    • Associativity: \(h \circ (g \circ f) = (h \circ g) \circ f\)
    • Identity: For each object \(A\), there exists \(\text{id}_A: A \to A\)
  • Functor: A structure-preserving map between categories, taking objects to objects and morphisms to morphisms.
  • Natural Transformation: A morphism between functors, assigning to each object a morphism satisfying a commutativity condition.
  • Universal Property: A characterization of an object by its relationship to all other objects (e.g., products, coproducts).
  • Adjoint Functors: Functors \(F: \mathcal{C} \to \mathcal{D}\) and \(G: \mathcal{D} \to \mathcal{C}\) with a natural isomorphism \(\text{Hom}_\mathcal{D}(F(X), Y) \cong \text{Hom}_\mathcal{C}(X, G(Y))\).

Theorem: The Yoneda Lemma

Theorem: Let \(\mathcal{C}\) be a locally small category, \(F: \mathcal{C}^{op} \to \mathbf{Set}\) a functor, and \(A\) an object of \(\mathcal{C}\). Then there is a natural isomorphism: \[\text{Nat}(\text{Hom}(-, A), F) \cong F(A)\]

Proof Sketch: The isomorphism sends a natural transformation \(\alpha: \text{Hom}(-, A) \Rightarrow F\) to \(\alpha_A(\text{id}_A) \in F(A)\). Conversely, given \(x \in F(A)\), define \(\alpha_B(f) = F(f)(x)\) for \(f: B \to A\). One verifies these are inverse and natural in \(F\). The Yoneda lemma implies that an object is determined (up to isomorphism) by its relationships to other objects—an object is "known by its friends."

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\): Categories (calligraphic)
  • \(\text{Hom}(A, B)\) or \(\mathcal{C}(A, B)\): Morphisms from \(A\) to \(B\)
  • \(F, G, H\): Functors
  • \(\alpha, \beta, \gamma\): Natural transformations
  • \(\Rightarrow\): Natural transformation between functors
  • \(\dashv\): Adjoint relationship

from typing import TypeVar, Generic, Callable, Dict, Set
from dataclasses import dataclass
from functools import reduce

# Type variables for objects and morphisms
O = TypeVar('O')
M = TypeVar('M')

class Category:
    """
    Abstract base class for categories.
    A category consists of objects and morphisms with composition.
    """
    def __init__(self, name):
        self.name = name
        self.objects: Set = set()
        self.morphisms: Dict[tuple, list] = {}  # (src, tgt) -> list of morphisms
    
    def add_object(self, obj):
        self.objects.add(obj)
        return obj
    
    def add_morphism(self, src, tgt, name, func=None):
        if (src, tgt) not in self.morphisms:
            self.morphisms[(src, tgt)] = []
        self.morphisms[(src, tgt)].append((name, func))
        return (name, src, tgt)
    
    def compose(self, f, g):
        """Compose morphisms f: A->B and g: B->C to get g∘f: A->C."""
        f_name, f_src, f_tgt = f
        g_name, g_src, g_tgt = g
        assert f_tgt == g_src, "Target of f must match source of g"
        
        def composed_func(x):
            return g[2](f[2](x)) if f[2] and g[2] else None
        
        return (f"{g_name}∘{f_name}", f_src, g_tgt)
    
    def identity(self, obj):
        """Identity morphism on an object."""
        return (f"id_{obj}", obj, obj, lambda x: x)

class Functor:
    """
    Functor between categories.
    Maps objects to objects and morphisms to morphisms.
    """
    def __init__(self, name, source, target, obj_map, morph_map):
        self.name = name
        self.source = source
        self.target = target
        self.obj_map = obj_map
        self.morph_map = morph_map
    
    def map_object(self, obj):
        return self.obj_map.get(obj, obj)
    
    def map_morphism(self, morph):
        return self.morph_map.get(morph[0], morph)
    
    def apply(self, obj_or_morph):
        if obj_or_morph in self.source.objects:
            return self.map_object(obj_or_morph)
        return self.map_morphism(obj_or_morph)

class SetCategory(Category):
    """
    The category of sets, Set.
    Objects are sets, morphisms are functions.
    """
    def __init__(self):
        super().__init__("Set")
    
    def hom(self, A, B):
        """Return all functions from A to B (for finite sets)."""
        if len(A) == 0:
            return [lambda x: None]
        
        # Generate all possible functions
        import itertools
        functions = []
        for values in itertools.product(B, repeat=len(A)):
            func_dict = dict(zip(A, values))
            functions.append(lambda x, d=func_dict: d.get(x))
        return functions
    
    def product(self, A, B):
        """Categorical product is Cartesian product."""
        return {(a, b) for a in A for b in B}
    
    def coproduct(self, A, B):
        """Categorical coproduct is disjoint union."""
        return {('left', a) for a in A} | {('right', b) for b in B}

class MonoidCategory(Category):
    """
    A monoid viewed as a category with one object.
    Morphisms are elements of the monoid.
    """
    def __init__(self, name, elements, operation, identity_elem):
        super().__init__(f"Monoid({name})")
        self.obj = "*"
        self.objects.add(self.obj)
        self.elements = elements
        self.operation = operation
        self.identity_elem = identity_elem
        
        for e in elements:
            self.add_morphism(self.obj, self.obj, e)
    
    def compose(self, f, g):
        """Composition is the monoid operation."""
        f_name = f[0]
        g_name = g[0]
        result = self.operation(g_name, f_name)  # Note order: g∘f
        return (result, self.obj, self.obj)

📜 Math History

Leonhard Euler: The Master of Us All

Born in Basel, Switzerland in 1707, Leonhard Euler would become the most prolific mathematician in history, publishing over 800 papers and books across virtually every mathematical discipline known in his time. His collected works, the Opera Omnia, fill more than 70 volumes, and his influence on mathematics remains immeasurable.

Euler's early education was guided by his father, a pastor with mathematical interests, and by Johann Bernoulli, one of the leading mathematicians of the age. Despite this promising start, Euler's career nearly took a different path when his father insisted he study theology. It was Bernoulli who intervened, convincing Euler's father that his son's mathematical talents were extraordinary.

In 1727, Euler joined the St. Petersburg Academy of Sciences in Russia, beginning a period of extraordinary productivity. He lost sight in his right eye in 1738, possibly from observing the sun during astronomical calculations. Undeterred, he continued his work with even greater intensity. In 1741, he moved to Berlin at the invitation of Frederick the Great, though the relationship with the king—who preferred philosophers to mathematicians—proved strained.

Euler returned to St. Petersburg in 1766, by which time cataracts had begun to cloud his remaining eye. Within a few years, he was completely blind. Remarkably, this disability seemed only to increase his output. With the help of assistants and his phenomenal memory—he could recite the entire Aeneid from memory—Euler produced nearly half of his total works after losing his sight.

Among Euler's countless contributions, several stand out for their lasting importance. He introduced the notation \(f(x)\) for functions, \(e\) for the base of natural logarithms, \(i\) for \(\sqrt{-1}\), and \(\pi\) for the ratio of circumference to diameter—essentially creating the language of modern mathematics. His formula \(e^{i\theta} = \cos \theta + i \sin \theta\), which yields the identity \(e^{i\pi} + 1 = 0\), is often cited as the most beautiful equation in mathematics, unifying the five most important constants.

Euler's work on the seven bridges of Königsberg founded graph theory and topology. His solution to the Basel problem—showing that \(\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}\)—opened new avenues in analysis. The Euler-Lagrange equation became the foundation of the calculus of variations. In mechanics, Euler's equations describe the motion of rigid bodies. In number theory, his work on the totient function and the product formula for the zeta function laid groundwork for future developments.

Euler worked until the very end of his life. On September 18, 1783, he spent the morning calculating the orbit of the newly discovered planet Uranus. After lunch, while playing with his grandson, he suffered a stroke and died with the words "I die" on his lips. The St. Petersburg Academy continued to publish his papers for nearly 50 years after his death.

Laplace reportedly advised students: "Read Euler, read Euler, he is the master of us all." This tribute captures what makes Euler's work so enduring—his ability to find deep connections between seemingly unrelated areas, his clarity of exposition, and his inexhaustible creativity. Where other mathematicians might solve a problem, Euler would solve it, generalize it, find special cases, discover applications, and develop new methods—all in a single paper.

Putnam-Style Problem: A Determinant Identity

Problem: Let \(A\) be an \(n \times n\) matrix with entries \(a_{ij} = \min(i, j)\). Prove that: \[\det(A) = 1\]

Hint

Consider the matrix \(B\) where \(b_{ij} = a_{ij} - a_{i,j-1}\) (with \(a_{i0} = 0\)). Show that \(B\) is lower triangular with a simple structure. Alternatively, try row operations: subtract row \(i-1\) from row \(i\) for \(i = n, n-1, \ldots, 2\).

Solution

We use row operations to transform \(A\) into an upper triangular matrix with 1s on the diagonal.

The matrix \(A\) looks like: \[A = \begin{pmatrix} 1 & 1 & 1 & \cdots & 1 \\ 1 & 2 & 2 & \cdots & 2 \\ 1 & 2 & 3 & \cdots & 3 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & 2 & 3 & \cdots & n \end{pmatrix}\]

Perform the following row operations for \(i = n, n-1, \ldots, 2\): replace row \(i\) with row \(i\) minus row \(i-1\).

For row 2 minus row 1: \[(1, 2, 2, \ldots, 2) - (1, 1, 1, \ldots, 1) = (0, 1, 1, \ldots, 1)\]

For row 3 minus row 2: \[(1, 2, 3, \ldots, 3) - (1, 2, 2, \ldots, 2) = (0, 0, 1, \ldots, 1)\]

In general, for row \(i\) minus row \(i-1\):

  • Entries 1 to \(i-1\): \(\min(i, j) - \min(i-1, j) = j - j = 0\)
  • Entries \(i\) to \(n\): \(\min(i, j) - \min(i-1, j) = i - (i-1) = 1\)

After all operations, the matrix becomes: \[\begin{pmatrix} 1 & 1 & 1 & \cdots & 1 \\ 0 & 1 & 1 & \cdots & 1 \\ 0 & 0 & 1 & \cdots & 1 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \cdots & 1 \end{pmatrix}\]

This is an upper triangular matrix with all diagonal entries equal to 1. Therefore: \[\det(A) = 1 \cdot 1 \cdot \ldots \cdot 1 = 1\]

Alternative approach: One can verify that \(A = LL^T\) where \(L\) is the lower triangular matrix with all entries on and below the diagonal equal to 1. Since \(\det(L) = 1\), we have \(\det(A) = \det(L)^2 = 1\).

The Mandelbrot Set: A Window into Complex Dynamics

The Mandelbrot set is perhaps the most famous fractal in mathematics, discovered by Benoit Mandelbrot in 1980. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set. The set is connected (proved by Douady and Hubbard), and its boundary has Hausdorff dimension 2.

The visualization below uses escape-time coloring: points are colored based on how quickly the iteration escapes to infinity. The cardioid and circular bulbs correspond to regions where the iteration converges to attracting cycles of different periods.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for a given c.
    Returns max_iter if the point doesn't escape.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=800, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    # Create grid of complex numbers
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        escaped = np.abs(Z) > 2
        M[escaped & (M == 0)] = i
        mask &= ~escaped
    
    M[mask] = max_iter
    return M
