1. Complex Analysis: Cauchy's Integral Theorem

Introduction

Complex analysis is the study of functions of complex numbers. Despite its name, it reveals profound connections between algebra, geometry, and analysis. The theory of complex differentiable (holomorphic) functions is remarkably rich and has applications throughout mathematics and physics.

Cauchy's Integral Theorem is the cornerstone of complex analysis. It states that the integral of a holomorphic function around a closed contour is zero, provided the function has no singularities inside. This seemingly simple result has far-reaching consequences.

Notation Guide

  • \(\mathbb{C}\) — the complex plane
  • \(z = x + iy\) — a complex number with real part \(x\) and imaginary part \(y\)
  • \(\bar{z} = x - iy\) — complex conjugate
  • \(|z| = \sqrt{x^2 + y^2}\) — modulus (absolute value)
  • \(\gamma\) — a curve (path) in the complex plane
  • \(\oint_\gamma f(z)\,dz\) — contour integral around closed curve \(\gamma\)
  • \(f'(z)\) — complex derivative of \(f\) at \(z\)
  • \(\partial D\) — boundary of domain \(D\)
Cauchy's Integral Theorem

Let \(D\) be a simply connected open subset of \(\mathbb{C}\). Let \(f: D \to \mathbb{C}\) be a holomorphic function (complex differentiable at every point in \(D\)). If \(\gamma\) is a closed, piecewise smooth curve in \(D\), then:

\[\oint_\gamma f(z)\,dz = 0\]

Proof (using Green's Theorem)

Step 1: Write \(f(z) = u(x,y) + iv(x,y)\) where \(z = x + iy\), and \(dz = dx + i\,dy\).

Step 2: Expand the integral:

\[\oint_\gamma f(z)\,dz = \oint_\gamma (u + iv)(dx + i\,dy) = \oint_\gamma (u\,dx - v\,dy) + i\oint_\gamma (v\,dx + u\,dy)\]

Step 3: Apply Green's theorem to both real integrals. Green's theorem states:

\[\oint_\gamma (P\,dx + Q\,dy) = \iint_R \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dx\,dy\]

where \(R\) is the region enclosed by \(\gamma\).

Step 4: For the first integral with \(P = u, Q = -v\):

\[\oint_\gamma (u\,dx - v\,dy) = \iint_R \left(-\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\right) dx\,dy\]

Step 5: For the second integral with \(P = v, Q = u\):

\[\oint_\gamma (v\,dx + u\,dy) = \iint_R \left(\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y}\right) dx\,dy\]

Step 6: Since \(f\) is holomorphic, it satisfies the Cauchy-Riemann equations:

\[\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}\]

Step 7: Substituting the Cauchy-Riemann equations:

\[-\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y} = \frac{\partial u}{\partial y} - \frac{\partial u}{\partial y} = 0\]

\[\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y} = \frac{\partial u}{\partial x} - \frac{\partial u}{\partial x} = 0\]

Step 8: Both double integrals vanish, so:

\[\oint_\gamma f(z)\,dz = 0 + i \cdot 0 = 0\] ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy import integrate

def complex_quadrature(func, a, b, **kwargs):
    """
    Numerical integration of a complex-valued function.
    """
    def real_func(x):
        return np.real(func(x))
    def imag_func(x):
        return np.imag(func(x))
    
    real_integral = integrate.quad(real_func, a, b, **kwargs)
    imag_integral = integrate.quad(imag_func, a, b, **kwargs)
    return real_integral[0] + 1j*imag_integral[0]

def contour_integral(func, curve, t_range):
    """
    Compute contour integral ∫_γ f(z) dz where γ is parameterized by t.
    
    Parameters:
        func: complex-valued function f(z)
        curve: function that returns z(t) for parameter t
        t_range: tuple (t_start, t_end)
    """
    def integrand(t):
        z = curve(t)
        dz_dt = (curve(t + 1e-8) - curve(t - 1e-8)) / (2e-8)
        return func(z) * dz_dt
    
    result, _ = integrate.quad(lambda t: np.real(integrand(t)), t_range[0], t_range[1])
    result_imag, _ = integrate.quad(lambda t: np.imag(integrand(t)), t_range[0], t_range[1])
    return result + 1j * result_imag

2. Real Analysis: The Bolzano-Weierstrass Theorem

Introduction

Real analysis provides the rigorous foundation for calculus. It studies the properties of real numbers, sequences, and functions, addressing questions about limits, continuity, and convergence that are often glossed over in introductory courses.

The Bolzano-Weierstrass Theorem is a fundamental result about sequences in \(\mathbb{R}^n\). It states that every bounded sequence has a convergent subsequence. This theorem is crucial for proving the existence of solutions to many problems in analysis.

Notation Guide

  • \(\mathbb{R}^n\) — n-dimensional Euclidean space
  • \(\{x_n\}_{n=1}^\infty\) — a sequence of points
  • \(x_{n_k}\) — a subsequence (indices \(n_1 < n_2 < n_3 < \cdots\))
  • \(\|x\|\) — Euclidean norm: \(\sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}\)
  • \(B(x, r)\) — open ball of radius \(r\) centered at \(x\)
  • \(\lim_{k \to \infty} x_{n_k} = L\) — the subsequence converges to limit \(L\)
Bolzano-Weierstrass Theorem

Every bounded sequence in \(\mathbb{R}^n\) has a convergent subsequence.

More precisely: If \(\{x_k\}_{k=1}^\infty\) is a sequence in \(\mathbb{R}^n\) such that \(\|x_k\| \leq M\) for all \(k\) and some \(M > 0\), then there exists a subsequence \(\{x_{k_j}\}_{j=1}^\infty\) and a point \(x \in \mathbb{R}^n\) such that:

\[\lim_{j \to \infty} x_{k_j} = x\]

Proof (for \(\mathbb{R}\), using the Nested Interval Property)

Step 1: Let \(\{x_n\}\) be a bounded sequence in \(\mathbb{R}\). Then there exists an interval \([a_1, b_1]\) containing all terms of the sequence.

Step 2: Bisect \([a_1, b_1]\) into two subintervals: \([a_1, (a_1+b_1)/2]\) and \([(a_1+b_1)/2, b_1]\).

Step 3: At least one of these subintervals contains infinitely many terms of the sequence. Choose such an interval and call it \([a_2, b_2]\). Select \(x_{n_2} \in [a_2, b_2]\) with \(n_2 > n_1\).

Step 4: Continue inductively. At step \(k\), bisect \([a_k, b_k]\) and choose the half containing infinitely many terms as \([a_{k+1}, b_{k+1}]\). Select \(x_{n_{k+1}} \in [a_{k+1}, b_{k+1}]\) with \(n_{k+1} > n_k\).

Step 5: We obtain a nested sequence of intervals:

\[[a_1, b_1] \supseteq [a_2, b_2] \supseteq [a_3, b_3] \supseteq \cdots\]

with \(b_k - a_k = (b_1 - a_1)/2^{k-1} \to 0\).

Step 6: By the Nested Interval Property, \(\bigcap_{k=1}^\infty [a_k, b_k] = \{x\}\) for some unique point \(x\).

Step 7: Since \(x_{n_k} \in [a_k, b_k]\) for all \(k\), we have \(|x_{n_k} - x| \leq b_k - a_k \to 0\).

Therefore, \(\lim_{k \to \infty} x_{n_k} = x\). ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def extract_convergent_subsequence(sequence, epsilon=1e-6):
    """
    Extract a convergent subsequence from a bounded sequence using bisection method.
    Returns the subsequence and its limit.
    """
    n = len(sequence)
    if n == 0:
        return np.array([]), None
    
    # Find bounding box
    min_val = np.min(sequence)
    max_val = np.max(sequence)
    
    subsequence = []
    indices = []
    
    # Bisection method
    current_interval = (min_val, max_val)
    available_indices = set(range(n))
    
    while len(available_indices) > 0 and current_interval[1] - current_interval[0] > epsilon:
        mid = (current_interval[0] + current_interval[1]) / 2
        
        # Count points in each half
        left_indices = [i for i in available_indices if current_interval[0] <= sequence[i] < mid]
        right_indices = [i for i in available_indices if mid <= sequence[i] <= current_interval[1]]
        
        # Choose the half with more points
        if len(left_indices) >= len(right_indices):
            if len(left_indices) > 0:
                idx = min(left_indices)
                subsequence.append(sequence[idx])
                indices.append(idx)
                available_indices.remove(idx)
                current_interval = (current_interval[0], mid)
            else:
                break
        else:
            if len(right_indices) > 0:
                idx = min(right_indices)
                subsequence.append(sequence[idx])
                indices.append(idx)
                available_indices.remove(idx)
                current_interval = (mid, current_interval[1])
            else:
                break
    
    limit = (current_interval[0] + current_interval[1]) / 2
    return np.array(subsequence), limit, indices

3. Algebraic Geometry: Bézout's Theorem

Introduction

Algebraic geometry studies the solutions of polynomial equations. It connects algebra (the equations) with geometry (the shapes they define) and topology (the properties preserved under continuous deformation).

Bézout's Theorem is a fundamental result about the intersection of algebraic curves. It states that two curves of degrees \(m\) and \(n\) intersect in exactly \(mn\) points (counting multiplicities and points at infinity), assuming they have no common components.

Notation Guide

  • \(\mathbb{P}^2\) — the projective plane (extends affine plane with points at infinity)
  • \(V(f)\) — the variety (zero set) of polynomial \(f\)
  • \(\deg(f)\) — degree of polynomial \(f\)
  • \(I(P, f \cap g)\) — intersection multiplicity at point \(P\)
  • \([x:y:z]\) — homogeneous coordinates in projective space
  • \(\mathbb{A}^2\) — the affine plane \(\mathbb{C}^2\) or \(\mathbb{R}^2\)
Bézout's Theorem

Let \(C\) and \(D\) be two projective plane curves of degrees \(m\) and \(n\) respectively, defined over an algebraically closed field (e.g., \(\mathbb{C}\)). If \(C\) and \(D\) have no common component, then:

\[\sum_{P \in C \cap D} I(P, C \cap D) = m \cdot n\]

where \(I(P, C \cap D)\) is the intersection multiplicity at point \(P\).

Proof Sketch (using resultants)

Step 1: Work in projective space \(\mathbb{P}^2\) with homogeneous coordinates \([X:Y:Z]\). A curve of degree \(d\) is defined by a homogeneous polynomial of degree \(d\).

Step 2: Let \(F(X,Y,Z) = 0\) and \(G(X,Y,Z) = 0\) define curves of degrees \(m\) and \(n\). Dehomogenize by setting \(Z = 1\) to work in the affine plane: \(f(x,y) = F(x,y,1)\), \(g(x,y) = G(x,y,1)\).

Step 3: The resultant \(\text{Res}_y(f, g)\) is a polynomial in \(x\) obtained by eliminating \(y\). It vanishes precisely when \(f\) and \(g\) have a common root in \(y\) for that value of \(x\).

Step 4: The degree of \(\text{Res}_y(f, g)\) in \(x\) is at most \(mn\). This counts the number of intersection points (with multiplicity) in the affine plane.

Step 5: Points at infinity correspond to solutions with \(Z = 0\). The line at infinity \(Z = 0\) intersects \(C\) in at most \(m\) points and \(D\) in at most \(n\) points.

Step 6: Careful analysis of multiplicities shows the total count equals \(mn\). The key is that the resultant has degree exactly \(mn\) when curves have no common component. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

def intersect_curves(f, g, x_range=(-3, 3), y_range=(-3, 3), n_points=100):
    """
    Find intersection points of two curves f(x,y) = 0 and g(x,y) = 0.
    Uses numerical methods.
    """
    # Create grid
    x = np.linspace(x_range[0], x_range[1], n_points)
    y = np.linspace(y_range[0], y_range[1], n_points)
    X, Y = np.meshgrid(x, y)
    
    # Evaluate functions
    F = f(X, Y)
    G = g(X, Y)
    
    # Find approximate intersections
    intersections = []
    tolerance = 0.1
    
    for i in range(n_points-1):
        for j in range(n_points-1):
            # Check if both functions change sign in this cell
            f_vals = [F[i,j], F[i+1,j], F[i,j+1], F[i+1,j+1]]
            g_vals = [G[i,j], G[i+1,j], G[i,j+1], G[i+1,j+1]]
            
            if (max(f_vals) > 0 and min(f_vals) < 0 and 
                max(g_vals) > 0 and min(g_vals) < 0):
                # Use midpoint as initial guess
                x0 = (X[i,j] + X[i+1,j+1]) / 2
                y0 = (Y[i,j] + Y[i+1,j+1]) / 2
                
                # Refine using fsolve
                def equations(vars):
                    x, y = vars
                    return [f(x, y), g(x, y)]
                
                try:
                    sol = fsolve(equations, [x0, y0])
                    # Check if it's a new intersection
                    is_new = True
                    for px, py in intersections:
                        if abs(sol[0] - px) < 0.01 and abs(sol[1] - py) < 0.01:
                            is_new = False
                            break
                    if is_new:
                        intersections.append((sol[0], sol[1]))
                except:
                    pass
    
    return intersections

1. Statistics: The Central Limit Theorem

Introduction

The Central Limit Theorem (CLT) is one of the most important results in probability and statistics. It explains why the normal distribution appears so frequently in nature and why it serves as the foundation for much of statistical inference.

The theorem states that the sum (or average) of a large number of independent, identically distributed random variables will be approximately normally distributed, regardless of the underlying distribution of the individual variables.

Notation Guide

  • \(X_1, X_2, \ldots, X_n\) — independent, identically distributed (i.i.d.) random variables
  • \(\mu = \mathbb{E}[X_i]\) — expected value (mean)
  • \(\sigma^2 = \text{Var}(X_i)\) — variance
  • \(\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i\) — sample mean
  • \(S_n = \sum_{i=1}^n X_i\) — sample sum
  • \(\xrightarrow{d}\) — convergence in distribution
  • \(\mathcal{N}(\mu, \sigma^2)\) — normal distribution with mean \(\mu\) and variance \(\sigma^2\)
The Central Limit Theorem

Let \(X_1, X_2, \ldots\) be a sequence of i.i.d. random variables with \(\mathbb{E}[X_i] = \mu\) and \(\text{Var}(X_i) = \sigma^2 < \infty\). Define:

\[Z_n = \frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} = \frac{S_n - n\mu}{\sigma\sqrt{n}}\]

Then as \(n \to \infty\):

\[Z_n \xrightarrow{d} \mathcal{N}(0, 1)\]

Equivalently, for any real \(z\):

\[\lim_{n \to \infty} P(Z_n \leq z) = \Phi(z) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^z e^{-t^2/2} dt\]

Proof (using characteristic functions)

Step 1: The characteristic function of a random variable \(X\) is \(\phi_X(t) = \mathbb{E}[e^{itX}]\).

Step 2: For \(Z_n = \frac{S_n - n\mu}{\sigma\sqrt{n}}\), we compute its characteristic function:

\[\phi_{Z_n}(t) = \mathbb{E}\left[\exp\left(it \cdot \frac{S_n - n\mu}{\sigma\sqrt{n}}\right)\right]\]

Step 3: Since the \(X_i\) are i.i.d.:

\[\phi_{Z_n}(t) = \left(\mathbb{E}\left[\exp\left(\frac{it(X_1 - \mu)}{\sigma\sqrt{n}}\right)\right]\right)^n\]

Step 4: Let \(Y = \frac{X_1 - \mu}{\sigma}\), so \(\mathbb{E}[Y] = 0\) and \(\text{Var}(Y) = 1\). Then:

\[\phi_{Z_n}(t) = \left(\phi_Y\left(\frac{t}{\sqrt{n}}\right)\right)^n\]

Step 5: Using Taylor expansion around 0:

\[\phi_Y(s) = 1 + is\mathbb{E}[Y] - \frac{s^2}{2}\mathbb{E}[Y^2] + o(s^2) = 1 - \frac{s^2}{2} + o(s^2)\]

Step 6: Substituting \(s = t/\sqrt{n}\):

\[\phi_{Z_n}(t) = \left(1 - \frac{t^2}{2n} + o(1/n)\right)^n\]

Step 7: As \(n \to \infty\), using \(\lim_{n \to \infty}(1 + a/n)^n = e^a\):

\[\lim_{n \to \infty} \phi_{Z_n}(t) = e^{-t^2/2}\]

Step 8: This is the characteristic function of \(\mathcal{N}(0,1)\). By the continuity theorem for characteristic functions, \(Z_n \xrightarrow{d} \mathcal{N}(0,1)\). ∎

Python Implementation

import numpy as np

def demonstrate_clt(distribution, params, n_samples, n_trials, title):
    """
    Demonstrate CLT by sampling means from a distribution.
    """
    sample_means = []
    for _ in range(n_trials):
        samples = distribution(*params, size=n_samples)
        sample_means.append(np.mean(samples))
    
    return np.array(sample_means)

2. Differential Equations: Picard-Lindelöf Theorem

Introduction

Differential equations describe how quantities change over time or space. They are fundamental to physics, engineering, biology, and economics. Before attempting to solve a differential equation, it's crucial to know whether a solution exists and whether it's unique.

The Picard-Lindelöf Theorem (also known as the Cauchy-Lipschitz theorem) provides conditions under which an initial value problem has a unique solution.

Notation Guide

  • \(y' = \frac{dy}{dt}\) — derivative of \(y\) with respect to \(t\)
  • \(f(t, y)\) — a function defining the differential equation
  • \(y(t_0) = y_0\) — initial condition
  • \(R = [t_0 - a, t_0 + a] \times [y_0 - b, y_0 + b]\) — rectangle in the \(ty\)-plane
  • \(L\) — Lipschitz constant
  • \(C^0\) — continuous functions
  • \(C^1\) — continuously differentiable functions
Picard-Lindelöf Existence and Uniqueness Theorem

Consider the initial value problem:

\[y' = f(t, y), \quad y(t_0) = y_0\]

If \(f(t, y)\) and \(\frac{\partial f}{\partial y}\) are continuous in a rectangle \(R\) containing \((t_0, y_0)\), then there exists a unique solution \(y(t)\) defined on some interval \(|t - t_0| < h\).

More precisely, if \(f\) is continuous on \(R\) and Lipschitz continuous in \(y\) with constant \(L\):

\[|f(t, y_1) - f(t, y_2)| \leq L|y_1 - y_2|\]

for all \((t, y_1), (t, y_2) \in R\), then the solution exists and is unique on \([t_0 - h, t_0 + h]\) where:

\[h = \min\left(a, \frac{b}{M}\right), \quad M = \max_{(t,y) \in R} |f(t,y)|\]

Proof (Picard Iteration)

Step 1: Convert the IVP to an integral equation:

\[y(t) = y_0 + \int_{t_0}^t f(s, y(s))\,ds\]

Step 2: Define the Picard iteration scheme:

\[y_0(t) = y_0\]

\[y_{n+1}(t) = y_0 + \int_{t_0}^t f(s, y_n(s))\,ds\]

Step 3: Show that \(\{y_n\}\) is well-defined on \([t_0 - h, t_0 + h]\). By induction, if \(|y_n(t) - y_0| \leq b\), then:

\[|y_{n+1}(t) - y_0| \leq \int_{t_0}^t |f(s, y_n(s))|\,ds \leq M|t - t_0| \leq Mh \leq b\]

Step 4: Show \(\{y_n\}\) is Cauchy using the Lipschitz condition. This implies convergence to a unique solution. ∎

def picard_iteration(f, y0, t0, t, n_iterations=5):
    """
    Compute Picard iterates for y' = f(t,y), y(t0) = y0.
    """
    iterates = [np.full_like(t, y0)]
    
    for n in range(n_iterations):
        y_prev = iterates[-1]
        y_next = np.zeros_like(t)
        for i, ti in enumerate(t):
            if ti == t0:
                y_next[i] = y0
            else:
                s = np.linspace(t0, ti, 100)
                y_interp = np.interp(s, t, y_prev)
                integrand = f(s, y_interp)
                y_next[i] = y0 + np.trapz(integrand, s)
        iterates.append(y_next)
    
    return iterates

3. Optimization: Gradient Descent Convergence

Introduction

Optimization is the study of finding the minimum or maximum of functions. It's essential in machine learning, economics, engineering, and operations research. Gradient descent is one of the most fundamental optimization algorithms.

For convex functions with certain properties, gradient descent is guaranteed to converge to the global minimum at a predictable rate.

Notation Guide

  • \(f: \mathbb{R}^n \to \mathbb{R}\) — objective function to minimize
  • \(\nabla f(x)\) — gradient of \(f\) at \(x\)
  • \(x^*\) — optimal solution (minimizer)
  • \(f^* = f(x^*)\) — optimal value
  • \(\eta\) — learning rate (step size)
  • \(L\) — Lipschitz constant of the gradient
  • \(\mu\) — strong convexity parameter
  • \(\kappa = L/\mu\) — condition number
Gradient Descent Convergence for L-Smooth Convex Functions

Let \(f: \mathbb{R}^n \to \mathbb{R}\) be convex and differentiable, with \(L\)-Lipschitz continuous gradient:

\[\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|\]

Using gradient descent with fixed step size \(\eta \leq 1/L\):

\[x_{k+1} = x_k - \eta \nabla f(x_k)\]

we have:

\[f(x_k) - f^* \leq \frac{\|x_0 - x^*\|^2}{2\eta k} = O\left(\frac{1}{k}\right)\]

Proof

Step 1: From \(L\)-smoothness:

\[f(y) \leq f(x) + \nabla f(x)^T(y-x) + \frac{L}{2}\|y-x\|^2\]

Step 2: Apply with \(y = x_{k+1}\), \(x = x_k\), using \(x_{k+1} - x_k = -\eta \nabla f(x_k)\):

\[f(x_{k+1}) \leq f(x_k) - \eta\left(1 - \frac{L\eta}{2}\right)\|\nabla f(x_k)\|^2\]

Step 3: With \(\eta \leq 1/L\), we get \(f(x_{k+1}) \leq f(x_k) - \frac{\eta}{2}\|\nabla f(x_k)\|^2\).

Step 4: By convexity and telescoping, we obtain the result. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def gradient_descent(f, grad_f, x0, learning_rate, n_iterations):
    """
    Vanilla gradient descent.
    """
    x = x0.copy()
    history = {'x': [x.copy()], 'f': [f(x)], 'grad_norm': [np.linalg.norm(grad_f(x))]}
    
    for _ in range(n_iterations):
        gradient = grad_f(x)
        x = x - learning_rate * gradient
        history['x'].append(x.copy())
        history['f'].append(f(x))
        history['grad_norm'].append(np.linalg.norm(grad_f(x)))
    
    return x, history

1. The Riemann Hypothesis

Introduction

The Riemann Hypothesis, posed by Bernhard Riemann in 1859, is one of the seven Millennium Prize Problems with a $1 million reward for its solution. It concerns the distribution of prime numbers and the zeros of the Riemann zeta function.

The hypothesis states that all non-trivial zeros of the zeta function have real part equal to 1/2. This seemingly simple statement, if proven, would have profound implications for number theory.

Notation Guide

  • \(\zeta(s)\) — Riemann zeta function
  • \(s = \sigma + it\) — complex variable
  • \(\Re(s) = \sigma\) — real part of \(s\)
  • \(\Im(s) = t\) — imaginary part of \(s\)
  • \(\Gamma(s)\) — Gamma function (generalization of factorial)
  • \(\pi(x)\) — prime counting function
  • \(\text{Li}(x)\) — logarithmic integral
The Riemann Hypothesis

The non-trivial zeros of the Riemann zeta function \(\zeta(s)\) all have real part equal to \(\frac{1}{2}\).

Equivalently: If \(\zeta(s) = 0\) with \(0 < \Re(s) < 1\), then \(\Re(s) = \frac{1}{2}\).

The line \(\Re(s) = \frac{1}{2}\) is called the critical line.

Functional Equation of the Zeta Function

The Riemann zeta function satisfies the functional equation:

\[\zeta(s) = 2^s \pi^{s-1} \sin\left(\frac{\pi s}{2}\right) \Gamma(1-s) \zeta(1-s)\]

2. The Navier-Stokes Existence and Smoothness Problem

Introduction

The Navier-Stokes equations describe the motion of incompressible fluids. Despite their widespread use in engineering and physics, fundamental mathematical questions about their solutions remain unanswered. This is one of the seven Millennium Prize Problems.

Notation Guide

  • \(u(x,t)\) — velocity field
  • \(p(x,t)\) — pressure field
  • \(\nu\) — kinematic viscosity
  • \(\nabla \cdot u = 0\) — incompressibility condition
  • \(\Delta u\) — Laplacian of \(u\)
  • \((u \cdot \nabla)u\) — convective derivative
Navier-Stokes Equations (Incompressible)

For an incompressible fluid in \(\mathbb{R}^3\) or \(\mathbb{T}^3\):

\[\frac{\partial u}{\partial t} + (u \cdot \nabla)u = \nu \Delta u - \nabla p + f\]

\[\nabla \cdot u = 0\]

with initial condition \(u(x, 0) = u_0(x)\) where \(\nabla \cdot u_0 = 0\).

Energy Equality

For smooth solutions of the Navier-Stokes equations on \(\mathbb{T}^3\) with \(f = 0\):

\[\frac{1}{2}\frac{d}{dt}\|u(t)\|_{L^2}^2 + \nu\|\nabla u(t)\|_{L^2}^2 = 0\]

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.fft import fftn, ifftn, fftfreq

def solve_navier_stokes_2d_spectral(N=64, dt=0.001, nu=0.001, T=1.0):
    """
    Solve 2D Navier-Stokes using spectral method (Fourier space).
    """
    # Grid
    x = np.linspace(0, 2*np.pi, N, endpoint=False)
    y = np.linspace(0, 2*np.pi, N, endpoint=False)
    X, Y = np.meshgrid(x, y)
    
    # Wavenumbers
    kx = fftfreq(N, 1/N) * 2 * np.pi
    ky = fftfreq(N, 1/N) * 2 * np.pi
    KX, KY = np.meshgrid(kx, ky)
    K2 = KX**2 + KY**2
    K2[0, 0] = 1.0
    
    # Initial condition: Taylor-Green vortex
    u = np.sin(X) * np.cos(Y)
    v = -np.cos(X) * np.sin(Y)
    
    n_steps = int(T / dt)
    history = {'u': [u.copy()], 'v': [v.copy()], 't': [0]}
    
    for step in range(n_steps):
        # Transform to Fourier space
        u_hat = fftn(u)
        v_hat = fftn(v)
        
        # Compute derivatives spectrally
        ux = np.real(ifftn(1j * KX * u_hat))
        uy = np.real(ifftn(1j * KY * u_hat))
        vx = np.real(ifftn(1j * KX * v_hat))
        vy = np.real(ifftn(1j * KY * v_hat))
        
        # Nonlinear terms
        nonlinear_u = -(u * ux + v * uy)
        nonlinear_v = -(u * vx + v * vy)
        
        # Transform nonlinear terms
        nonlinear_u_hat = fftn(nonlinear_u)
        nonlinear_v_hat = fftn(nonlinear_v)
        
        # Projection to divergence-free space
        div_nonlinear_hat = 1j * KX * nonlinear_u_hat + 1j * KY * nonlinear_v_hat
        p_hat = div_nonlinear_hat / K2
        
        nonlinear_u_hat -= 1j * KX * p_hat
        nonlinear_v_hat -= 1j * KY * p_hat
        
        # Time stepping (semi-implicit)
        u_hat_new = (u_hat + dt * nonlinear_u_hat) / (1 + nu * dt * K2)
        v_hat_new = (v_hat + dt * nonlinear_v_hat) / (1 + nu * dt * K2)
        
        u = np.real(ifftn(u_hat_new))
        v = np.real(ifftn(v_hat_new))
        
        if step % 100 == 0:
            history['u'].append(u.copy())
            history['v'].append(v.copy())
            history['t'].append((step + 1) * dt)
    
    return X, Y, history

3. P vs NP

Introduction

The P vs NP problem asks whether every problem whose solution can be quickly verified by a computer can also be quickly solved by a computer. It is one of the seven Millennium Prize Problems and is considered the most important open problem in theoretical computer science.

Notation Guide

  • \(\mathcal{P}\) — class of problems solvable in polynomial time
  • \(\mathcal{NP}\) — class of problems with polynomial-time verifiable certificates
  • \(\mathcal{NPC}\) — NP-complete problems
  • \(O(n^k)\) — polynomial time complexity
  • \(O(2^n)\) — exponential time complexity
Cook-Levin Theorem

The Boolean satisfiability problem (SAT) is NP-complete.

That is:

  1. SAT is in NP (given a satisfying assignment, it can be verified in polynomial time)
  2. Every problem in NP can be reduced to SAT in polynomial time

Python Implementation

import itertools
import time

def brute_force_sat(formula, n_vars):
    """
    Solve SAT by brute force (exponential time).
    """
    for assignment in itertools.product([False, True], repeat=n_vars):
        if formula(assignment):
            return assignment
    return None

def verify_sat(formula, assignment):
    """
    Verify a SAT solution (polynomial time).
    """
    return formula(assignment)

# Example SAT formula
def example_sat(assignment):
    """
    (x1 OR x2) AND (NOT x1 OR x3) AND (x2 OR NOT x3)
    """
    x1, x2, x3 = assignment
    return (x1 or x2) and (not x1 or x3) and (x2 or not x3)

4. Fractals: The Mandelbrot Set

Introduction

Fractals are geometric shapes that exhibit self-similarity at different scales. They often have intricate structures and non-integer dimensions. The Mandelbrot set is perhaps the most famous fractal, named after mathematician Benoit Mandelbrot.

The Mandelbrot set is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

Notation Guide

  • \(M\) — the Mandelbrot set
  • \(f_c(z) = z^2 + c\) — the quadratic polynomial
  • \(f_c^n(z)\) — n-fold iteration of \(f_c\)
  • \(K_c\) — filled Julia set for parameter \(c\)
  • \(\partial M\) — boundary of the Mandelbrot set
  • \(\mathbb{C}\) — complex plane
Definition of the Mandelbrot Set

The Mandelbrot set is defined as:

\[M = \{c \in \mathbb{C} : \sup_{n \geq 0} |f_c^n(0)| < \infty\}\]

where \(f_c(z) = z^2 + c\) and \(f_c^n\) denotes the n-fold composition of \(f_c\).

Equivalently, \(c \in M\) if and only if the sequence defined by \(z_0 = 0\) and \(z_{n+1} = z_n^2 + c\) remains bounded.

Escape Criterion

If \(|z_n| > 2\) for some \(n\), then the orbit \(\{z_k\}\) escapes to infinity.

Therefore:

\[M \subseteq \{c \in \mathbb{C} : |c| \leq 2\}\]

More precisely, if \(|c| > 2\), then \(c \notin M\).

Proof of Escape Criterion

Step 1: Suppose \(|z_n| > \max(2, |c|)\). Then:

\[|z_{n+1}| = |z_n^2 + c| \geq |z_n|^2 - |c| \u003e |z_n|^2 - |z_n| = |z_n|(|z_n| - 1)\]

Step 2: Since \(|z_n| > 2\), we have \(|z_n| - 1 > 1\), so:

\[|z_{n+1}| > |z_n| \cdot 1 = |z_n|\]

Step 3: Moreover, \(|z_{n+1}| > |z_n|^2 - |c| \u003e 2|z_n| - |c| > |z_n|\) when \(|z_n| > |c|\).

Step 4: The sequence \(|z_n|\) grows at least exponentially, so \(|z_n| \to \infty\). ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for a given c.
    Returns max_iter if the point doesn't escape.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=800, height=800, max_iter=100):
    """
    Compute the Mandelbrot set on a grid.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    M = np.zeros((height, width), dtype=int)
    for i in range(height):
        for j in range(width):
            M[i, j] = mandelbrot(C[i, j], max_iter)
    
    return M, X, Y
