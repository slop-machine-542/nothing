1. Algebraic Coding Theory: Reed-Solomon Codes

Tags: algebraic-coding-theory finite-fields error-correction

Motivation

Error-correcting codes are essential for reliable digital communication and storage. Reed-Solomon codes, invented in 1960, remain among the most widely used codes due to their optimal error-correction properties and efficient decoding algorithms. They power everything from QR codes and CDs to deep space missions. The mathematical foundation lies in the elegant interplay between finite fields and polynomial interpolation, demonstrating how abstract algebra solves practical problems.

Definitions

Let \( \mathbb{F}_q \) be a finite field with \( q \) elements. A Reed-Solomon code \( RS(n, k) \) over \( \mathbb{F}_q \) with parameters \( n \leq q \) and \( k < n \) is defined as:

\[ RS(n, k) = \{(f(\alpha_1), f(\alpha_2), \ldots, f(\alpha_n)) : f \in \mathbb{F}_q[x], \deg(f) < k\} \]

where \( \alpha_1, \ldots, \alpha_n \) are distinct elements of \( \mathbb{F}_q \).

The code has:

  • Length: \( n \)
  • Dimension: \( k \)
  • Minimum distance: \( d = n - k + 1 \) (achieving the Singleton bound)

Theorem (Reed-Solomon Properties)

Theorem: The Reed-Solomon code \( RS(n, k) \) satisfies:

  1. It is a linear code of dimension \( k \) and length \( n \).
  2. Its minimum Hamming distance is \( d = n - k + 1 \).
  3. It can correct up to \( \lfloor (n-k)/2 \rfloor \) errors.
  4. It can correct up to \( n - k \) erasures.

Proof Sketch

  1. Linearity: The evaluation map \( f \mapsto (f(\alpha_1), \ldots, f(\alpha_n)) \) is linear.
  2. Dimension: The space of polynomials of degree \( < k \) has dimension \( k \).
  3. Distance: A non-zero polynomial of degree \( < k \) has at most \( k-1 \) roots, so at most \( k-1 \) positions can be zero. Thus any non-zero codeword has weight at least \( n - (k-1) = n - k + 1 \).
  4. Optimality: The Singleton bound states \( d \leq n - k + 1 \), so RS codes are MDS (Maximum Distance Separable).

Notation Guide

  • \( \mathbb{F}_q \): finite field with \( q \) elements
  • \( n \): code length
  • \( k \): message length (dimension)
  • \( d \): minimum distance
  • \( [n, k, d]_q \): code parameters
  • MDS: Maximum Distance Separable

Python Implementation

import numpy as np
from itertools import combinations

class FiniteField:
    """Simplified finite field implementation for GF(p)."""
    
    def __init__(self, p):
        self.p = p
    
    def add(self, a, b):
        return (a + b) % self.p
    
    def sub(self, a, b):
        return (a - b) % self.p
    
    def mul(self, a, b):
        return (a * b) % self.p
    
    def div(self, a, b):
        """Division: a / b = a * b^(p-2) mod p (Fermat's little theorem)."""
        if b == 0:
            raise ZeroDivisionError()
        return (a * pow(b, self.p - 2, self.p)) % self.p
    
    def pow(self, a, n):
        return pow(a, n, self.p)


class ReedSolomonCode:
    """
    Reed-Solomon code over GF(p).
    For simplicity, we use prime fields GF(p).
    """
    
    def __init__(self, p, n, k):
        """
        Initialize RS(n, k) code over GF(p).
        Requires: n <= p and k < n.
        """
        if n > p:
            raise ValueError("n must be <= p for GF(p)")
        if k >= n:
            raise ValueError("k must be < n")
        
        self.p = p
        self.n = n
        self.k = k
        self.d = n - k + 1  # Minimum distance
        self.field = FiniteField(p)
        
        # Evaluation points: 0, 1, 2, ..., n-1
        self.evaluation_points = list(range(n))
    
    def encode(self, message):
        """
        Encode message (list of k field elements) to codeword.
        message represents coefficients of polynomial.
        """
        if len(message) != self.k:
            raise ValueError(f"Message must have length {self.k}")
        
        # Evaluate polynomial at all evaluation points
        codeword = []
        for x in self.evaluation_points:
            # Evaluate polynomial m[0] + m[1]*x + m[2]*x^2 + ...
            value = 0
            for i, coeff in enumerate(message):
                value = self.field.add(value, 
                    self.field.mul(coeff, self.field.pow(x, i)))
            codeword.append(value)
        
        return codeword
    
    def decode_erasures(self, received, erasure_positions):
        """
        Decode when some positions are known to be erased.
        Uses Lagrange interpolation on the remaining positions.
        """
        # Collect known (position, value) pairs
        known_points = [(i, received[i]) for i in range(self.n) 
                       if i not in erasure_positions]
        
        if len(known_points) < self.k:
            raise ValueError("Too many erasures to decode")
        
        # Use first k known points for interpolation
        points = known_points[:self.k]
        
        # Lagrange interpolation to recover polynomial
        coeffs = self._lagrange_interpolate(points)
        
        # Reconstruct full codeword
        return self.encode(coeffs)
    
    def _lagrange_interpolate(self, points):
        """
        Lagrange interpolation: find polynomial of degree < k
        passing through given points.
        Returns coefficients [a0, a1, ..., a_{k-1}].
        """
        k = len(points)
        # Coefficients of resulting polynomial
        result = [0] * k
        
        for j, (xj, yj) in enumerate(points):
            # Compute Lagrange basis polynomial L_j(x)
            # L_j(x) = prod_{m!=j} (x - x_m) / (x_j - x_m)
            
            # Numerator: prod_{m!=j} (x - x_m)
            # Start with constant 1
            numerator = [1]  # Coefficients of polynomial
            
            for m, (xm, _) in enumerate(points):
                if m != j:
                    # Multiply by (x - xm) = [-xm, 1]
                    new_num = [0] * (len(numerator) + 1)
                    for i, c in enumerate(numerator):
                        # c * x^i * (-xm) contributes to x^i
                        new_num[i] = self.field.add(new_num[i], 
                            self.field.mul(c, self.field.sub(0, xm)))
                        # c * x^i * x contributes to x^{i+1}
                        new_num[i + 1] = self.field.add(new_num[i + 1], c)
                    numerator = new_num
            
            # Denominator: prod_{m!=j} (x_j - x_m)
            denominator = 1
            for m, (xm, _) in enumerate(points):
                if m != j:
                    denominator = self.field.mul(denominator, 
                        self.field.sub(xj, xm))
            
            # Add y_j * L_j(x) to result
            inv_denom = self.field.div(1, denominator)
            for i, c in enumerate(numerator[:k]):
                term = self.field.mul(yj, self.field.mul(c, inv_denom))
                result[i] = self.field.add(result[i], term)
        
        return result
    
    def add_errors(self, codeword, error_positions, error_values):
        """Add errors to codeword (for testing)."""
        corrupted = codeword.copy()
        for pos, val in zip(error_positions, error_values):
            corrupted[pos] = self.field.add(corrupted[pos], val)
        return corrupted

2. Computational Algebraic Geometry: Gröbner Bases

Tags: computational-algebraic-geometry polynomial-ideals buchbergers-algorithm

Motivation

Systems of polynomial equations appear throughout mathematics and its applications—from robotics and computer vision to optimization and cryptography. Gröbner bases, introduced by Bruno Buchberger in 1965, provide a systematic way to solve such systems. They generalize Gaussian elimination to polynomial equations and the Euclidean algorithm to multivariate polynomials. A Gröbner basis transforms a system of polynomials into a "triangular" form that makes solving straightforward, enabling computational approaches to problems that were previously intractable.

Definitions

Let \( k[x_1, \ldots, x_n] \) be a polynomial ring over a field \( k \). A monomial order is a well-ordering on monomials that respects multiplication: if \( x^\alpha > x^\beta \), then \( x^\gamma x^\alpha > x^\gamma x^\beta \).

For a polynomial \( f \), \( \text{LT}(f) \) denotes the leading term with respect to the monomial order.

Given an ideal \( I \subseteq k[x_1, \ldots, x_n] \), a Gröbner basis is a finite set \( G = \{g_1, \ldots, g_m\} \subseteq I \) such that:

\[ \langle \text{LT}(g_1), \ldots, \text{LT}(g_m) \rangle = \langle \text{LT}(I) \rangle \]

where \( \text{LT}(I) = \{\text{LT}(f) : f \in I\} \).

Theorem (Buchberger's Criterion)

Theorem: A set \( G = \{g_1, \ldots, g_m\} \) is a Gröbner basis for \( \langle G \rangle \) if and only if for all \( i \neq j \):

\[ S(g_i, g_j) \rightarrow_G 0 \]

where the S-polynomial is:

\[ S(g_i, g_j) = \frac{\text{lcm}(\text{LM}(g_i), \text{LM}(g_j))}{\text{LT}(g_i)} g_i - \frac{\text{lcm}(\text{LM}(g_i), \text{LM}(g_j))}{\text{LT}(g_j)} g_j \]

Proof Sketch

  1. The S-polynomial \( S(g_i, g_j) \) is designed to cancel leading terms.
  2. If all S-polynomials reduce to 0, then any element of the ideal can be written in terms of \( G \) with a unique remainder.
  3. This ensures that leading terms of \( G \) generate all leading terms of the ideal.
  4. Buchberger's algorithm repeatedly adds remainders of S-polynomials until the criterion is satisfied.

Notation Guide

  • \( k[x_1, \ldots, x_n] \): polynomial ring
  • \( \text{LT}(f) \): leading term of \( f \)
  • \( \text{LM}(f) \): leading monomial of \( f \)
  • \( S(f, g) \): S-polynomial
  • \( f \rightarrow_G r \): reduction of \( f \) by \( G \) to remainder \( r \)

Python Implementation

from collections import defaultdict
import itertools

class Monomial:
    """Represents a monomial x^exponents."""
    
    def __init__(self, exponents):
        """exponents is a tuple, e.g., (2, 1, 0) for x²y."""
        self.exponents = tuple(exponents)
        self.n_vars = len(exponents)
    
    def __mul__(self, other):
        """Multiply two monomials."""
        return Monomial([a + b for a, b in zip(self.exponents, other.exponents)])
    
    def divides(self, other):
        """Check if self divides other."""
        return all(a <= b for a, b in zip(self.exponents, other.exponents))
    
    def __repr__(self):
        terms = []
        for i, exp in enumerate(self.exponents):
            if exp == 1:
                terms.append(f"x{i}")
            elif exp > 1:
                terms.append(f"x{i}^{exp}")
        return "*".join(terms) if terms else "1"
    
    def __lt__(self, other):
        """Lexicographic order."""
        return self.exponents > other.exponents  # Reverse for Python's heap
    
    def __eq__(self, other):
        return self.exponents == other.exponents
    
    def __hash__(self):
        return hash(self.exponents)


class Polynomial:
    """Sparse polynomial representation."""
    
    def __init__(self, terms=None):
        """
        terms is dict: Monomial -> coefficient
        """
        self.terms = terms or {}
        self._cleanup()
    
    def _cleanup(self):
        """Remove zero coefficients."""
        self.terms = {m: c for m, c in self.terms.items() if c != 0}
    
    def leading_monomial(self):
        """Leading monomial under lex order."""
        if not self.terms:
            return None
        return max(self.terms.keys(), key=lambda m: m.exponents)
    
    def leading_term(self):
        """Return (coefficient, monomial) of leading term."""
        lm = self.leading_monomial()
        if lm is None:
            return (0, None)
        return (self.terms[lm], lm)
    
    def __add__(self, other):
        result = defaultdict(int, self.terms)
        for m, c in other.terms.items():
            result[m] += c
        return Polynomial(dict(result))
    
    def __sub__(self, other):
        result = defaultdict(int, self.terms)
        for m, c in other.terms.items():
            result[m] -= c
        return Polynomial(dict(result))
    
    def __mul__(self, other):
        """Multiply polynomials."""
        result = defaultdict(int)
        for m1, c1 in self.terms.items():
            for m2, c2 in other.terms.items():
                result[m1 * m2] += c1 * c2
        return Polynomial(dict(result))
    
    def __mul__(self, scalar):
        """Scalar multiplication."""
        return Polynomial({m: c * scalar for m, c in self.terms.items()})
    
    def __repr__(self):
        if not self.terms:
            return "0"
        return " + ".join(f"{c}*{m}" if m.exponents != (0,) * m.n_vars else str(c) 
                         for m, c in sorted(self.terms.items(), 
                                           key=lambda x: x[0].exponents, reverse=True))


def s_polynomial(f, g):
    """
    Compute S-polynomial of f and g.
    S(f, g) = (LCM(LM(f), LM(g)) / LT(f)) * f - (LCM(LM(f), LM(g)) / LT(g)) * g
    """
    lc_f, lm_f = f.leading_term()
    lc_g, lm_g = g.leading_term()
    
    if lm_f is None or lm_g is None:
        return Polynomial()
    
    # LCM of monomials
    lcm_exp = [max(a, b) for a, b in zip(lm_f.exponents, lm_g.exponents)]
    lcm = Monomial(lcm_exp)
    
    # (LCM / LM(f)) * f
    factor_f = Monomial([b - a for a, b in zip(lm_f.exponents, lcm_exp)])
    term_f = Polynomial({factor_f * m: c for m, c in f.terms.items()})
    
    # (LCM / LM(g)) * g
    factor_g = Monomial([b - a for a, b in zip(lm_g.exponents, lcm_exp)])
    term_g = Polynomial({factor_g * m: c for m, c in g.terms.items()})
    
    # S(f, g) = term_f / lc_f - term_g / lc_g
    return term_f * (1 / lc_f) - term_g * (1 / lc_g)


def reduce_polynomial(f, G):
    """
    Reduce polynomial f by set G.
    Returns remainder.
    """
    remainder = Polynomial()
    current = f
    
    while current.terms:
        lc, lm = current.leading_term()
        reduced = False
        
        for g in G:
            glc, glm = g.leading_term()
            if glm and glm.divides(lm):
                # Reduce: current = current - (lc/glc) * (lm/glm) * g
                factor_m = Monomial([a - b for a, b in zip(lm.exponents, glm.exponents)])
                factor_p = Polynomial({factor_m * m: c for m, c in g.terms.items()})
                current = current - factor_p * (lc / glc)
                reduced = True
                break
        
        if not reduced:
            # Leading term cannot be reduced, add to remainder
            remainder = remainder + Polynomial({lm: lc})
            current = current - Polynomial({lm: lc})
    
    return remainder


def buchberger_algorithm(F):
    """
    Buchberger's algorithm to compute Gröbner basis.
    """
    G = list(F)
    pairs = list(itertools.combinations(range(len(G)), 2))
    
    while pairs:
        i, j = pairs.pop(0)
        s_poly = s_polynomial(G[i], G[j])
        remainder = reduce_polynomial(s_poly, G)
        
        if remainder.terms:  # Non-zero remainder
            G.append(remainder)
            # Add new pairs
            for k in range(len(G) - 1):
                pairs.append((k, len(G) - 1))
    
    return G

3. Geometric Group Theory: The Milnor-Švarc Lemma

Tags: geometric-group-theory cayley-graphs quasi-isometry

Motivation

Geometric group theory studies groups by connecting their algebraic properties to the geometry of spaces they act on. A finitely generated group can be viewed as a metric space through its Cayley graph, allowing geometric techniques to illuminate algebraic questions. The Milnor-Švarc lemma, discovered independently by John Milnor and Albert Švarc in the 1960s, establishes a fundamental equivalence: if a group acts geometrically on a metric space, then the group and the space are quasi-isometric. This bridges group theory with geometry, enabling the study of groups through their large-scale geometric properties.

Definitions

Let \( G \) be a finitely generated group with finite generating set \( S \). The Cayley graph \( \text{Cay}(G, S) \) has:

  • Vertices: elements of \( G \)
  • Edges: \( (g, gs) \) for \( g \in G \), \( s \in S \)

The word metric \( d_S \) on \( G \) is the graph metric on \( \text{Cay}(G, S) \):

\[ d_S(g, h) = \min\{n : g^{-1}h = s_1^{\pm 1} \cdots s_n^{\pm 1}, s_i \in S\} \]

Two metric spaces \( (X, d_X) \) and \( (Y, d_Y) \) are quasi-isometric if there exists \( f: X \to Y \) and constants \( K \geq 1 \), \( C \geq 0 \) such that:

  1. \( \frac{1}{K}d_X(x_1, x_2) - C \leq d_Y(f(x_1), f(x_2)) \leq Kd_X(x_1, x_2) + C \)
  2. Every point of \( Y \) is within distance \( C \) of \( f(X) \)

Theorem (Milnor-Švarc Lemma)

Theorem: Let \( G \) be a group acting properly discontinuously and cocompactly by isometries on a proper geodesic metric space \( (X, d) \). Then:

  1. \( G \) is finitely generated.
  2. For any finite generating set \( S \) of \( G \) and any basepoint \( x_0 \in X \), the orbit map \( g \mapsto g \cdot x_0 \) is a quasi-isometry between \( (G, d_S) \) and \( (X, d) \).

Proof Sketch

  1. Finite generation: Let \( B \) be a compact fundamental domain. The set of group elements mapping \( B \) to overlapping translates generates \( G \).
  2. Quasi-isometry: The orbit map is Lipschitz since the action is by isometries.
  3. Lower bound: Use the proper discontinuity to show that large word metric implies large distance in \( X \).
  4. Surjectivity: Cocompactness ensures every point is close to the orbit.

Notation Guide

  • \( \text{Cay}(G, S) \): Cayley graph
  • \( d_S \): word metric
  • \( \simeq_{QI} \): quasi-isometric
  • \( K, C \): quasi-isometry constants
  • Proper action: stabilizers are finite
  • Cocompact: quotient is compact

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from collections import deque

class GroupElement:
    """Element of free group on generators 'a', 'b'."""
    
    def __init__(self, word=""):
        """
        word is a string like "aAbB" where A = a^{-1}, B = b^{-1}.
        """
        self.word = self._reduce(word)
    
    def _reduce(self, word):
        """Cancel adjacent inverse pairs."""
        result = []
        inverse = {'a': 'A', 'A': 'a', 'b': 'B', 'B': 'b'}
        for c in word:
            if result and result[-1] == inverse[c]:
                result.pop()
            else:
                result.append(c)
        return "".join(result)
    
    def __mul__(self, other):
        return GroupElement(self.word + other.word)
    
    def __eq__(self, other):
        return self.word == other.word
    
    def __hash__(self):
        return hash(self.word)
    
    def __repr__(self):
        return f"[{self.word}]" if self.word else "[e]"
    
    def inverse(self):
        inverse = {'a': 'A', 'A': 'a', 'b': 'B', 'B': 'b'}
        return GroupElement("".join(inverse[c] for c in reversed(self.word)))


class CayleyGraph:
    """
    Cayley graph of free group on 2 generators.
    For visualization, we use a tree embedding.
    """
    
    def __init__(self, max_depth=5):
        self.max_depth = max_depth
        self.generators = ['a', 'b', 'A', 'B']
        self.positions = {}
        self._build_graph()
    
    def _build_graph(self):
        """Build Cayley graph up to max_depth."""
        # BFS from identity
        start = GroupElement("")
        queue = deque([(start, 0)])
        visited = {start}
        
        # Position identity at origin
        self.positions[start] = np.array([0.0, 0.0])
        
        while queue:
            current, depth = queue.popleft()
            if depth >= self.max_depth:
                continue
            
            current_pos = self.positions[current]
            
            for g in ['a', 'b']:
                next_elem = current * GroupElement(g)
                if next_elem not in visited:
                    visited.add(next_elem)
                    
                    # Calculate position based on direction
                    angle = self._get_angle(current, g)
                    new_pos = current_pos + 0.8 * np.array([np.cos(angle), np.sin(angle)])
                    self.positions[next_elem] = new_pos
                    
                    queue.append((next_elem, depth + 1))
    
    def _get_angle(self, element, generator):
        """Determine angle for new node based on parent and generator."""
        # Simple layout: alternate angles based on depth
        depth = len(element.word)
        base_angle = {'a': 0, 'b': np.pi/2, 'A': np.pi, 'B': 3*np.pi/2}
        return base_angle[generator] + depth * 0.1
    
    def word_metric(self, g, h):
        """Distance between group elements."""
        # Distance from g to h is length of g^{-1} * h
        return len((g.inverse() * h).word)
    
    def get_edges(self):
        """Return list of edges for plotting."""
        edges = []
        for elem in self.positions:
            for g in ['a', 'b']:
                neighbor = elem * GroupElement(g)
                if neighbor in self.positions:
                    edges.append((self.positions[elem], self.positions[neighbor]))
        return edges


class GeometricGroupTheory:
    """Demonstrations of geometric group theory concepts."""
    
    @staticmethod
    def check_quasi_isometry_inequality(d_X, d_Y, K, C):
        """
        Check if the quasi-isometry inequality holds:
        (1/K) * d_X - C <= d_Y <= K * d_X + C
        """
        lower = (1/K) * d_X - C
        upper = K * d_X + C
        return lower <= d_Y <= upper
    
    @staticmethod
    def orbit_map_distance(group_distance, orbit_map_lipschitz=1.0):
        """
        Simulate how word metric relates to metric on space.
        """
        # Orbit map is typically Lipschitz
        return orbit_map_lipschitz * group_distance
    
    @staticmethod
    def growth_function(n):
        """
        Growth function of free group on 2 generators.
        Number of elements within distance n of identity.
        """
        # For free group F_2: growth is exponential
        # |B(n)| = 1 + 4 + 4*3 + 4*3^2 + ... + 4*3^{n-1} = 2*3^n - 1
        if n == 0:
            return 1
        return 2 * (3 ** n) - 1

1. Stochastic Differential Equations: Itô Calculus

Tags: stochastic-differential-equations ito-calculus brownian-motion

Real-World Motivation

Stochastic differential equations (SDEs) model systems subject to random fluctuations, appearing in finance (option pricing), physics (Brownian motion), biology (population dynamics), and engineering (filtering). Standard calculus fails for these systems because Brownian motion is nowhere differentiable. Kiyoshi Itô's revolutionary insight was to develop a new calculus that accounts for the quadratic variation of random processes. The Itô calculus, developed in the 1940s, provides rigorous foundations for stochastic integration and has become essential for quantitative finance and statistical physics.

Definitions

A standard Brownian motion \( W_t \) is a continuous stochastic process with:

  • \( W_0 = 0 \)
  • Independent increments: \( W_t - W_s \) independent of \( \{W_u : u \leq s\} \) for \( s < t \)
  • \( W_t - W_s \sim N(0, t-s) \)

An Itô process is a stochastic process of the form:

\[ X_t = X_0 + \int_0^t \mu(s, X_s) ds + \int_0^t \sigma(s, X_s) dW_s \]

In differential form:

\[ dX_t = \mu(t, X_t) dt + \sigma(t, X_t) dW_t \]

Theorem (Itô's Lemma)

Theorem: Let \( X_t \) be an Itô process and \( f(t, x) \) be twice continuously differentiable. Then \( Y_t = f(t, X_t) \) is also an Itô process, and:

\[ df(t, X_t) = \frac{\partial f}{\partial t} dt + \frac{\partial f}{\partial x} dX_t + \frac{1}{2} \frac{\partial^2 f}{\partial x^2} (dX_t)^2 \]

where \( (dX_t)^2 = \sigma^2 dt \) (using the rules \( dt^2 = 0 \), \( dt \cdot dW_t = 0 \), \( dW_t^2 = dt \)).

Proof Sketch

  1. Taylor expand \( f(t + dt, X_{t+dt}) \) around \( (t, X_t) \).
  2. Use the fact that \( (dW_t)^2 \approx dt \) in the mean-square sense.
  3. The second-order term in \( dX_t \) contributes because Brownian motion has non-zero quadratic variation.
  4. This is unlike ordinary calculus where second-order terms vanish.

Notation Guide

  • \( W_t \): Brownian motion (Wiener process)
  • \( dW_t \): Wiener increment
  • \( \mu \): drift coefficient
  • \( \sigma \): diffusion coefficient
  • \( \int \sigma dW \): Itô integral
  • \( (dW)^2 = dt \): Itô's isometry rule

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

class BrownianMotion:
    """Standard Brownian motion simulation."""
    
    def __init__(self, seed=None):
        if seed is not None:
            np.random.seed(seed)
    
    def simulate(self, T, N, n_paths=1):
        """
        Simulate Brownian motion on [0, T] with N steps.
        Returns array of shape (n_paths, N+1).
        """
        dt = T / N
        dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
        W = np.zeros((n_paths, N + 1))
        W[:, 1:] = np.cumsum(dW, axis=1)
        return W
    
    def quadratic_variation(self, W, dt):
        """Compute quadratic variation of Brownian path."""
        increments = np.diff(W)
        return np.sum(increments ** 2, axis=-1)


class SDESolver:
    """Numerical solvers for SDEs."""
    
    @staticmethod
    def euler_maruyama(mu, sigma, X0, T, N, n_paths=1):
        """
        Euler-Maruyama method for SDE: dX = mu(X,t)dt + sigma(X,t)dW
        """
        dt = T / N
        t = np.linspace(0, T, N + 1)
        
        X = np.zeros((n_paths, N + 1))
        X[:, 0] = X0
        
        for i in range(N):
            dW = np.random.normal(0, np.sqrt(dt), size=n_paths)
            X[:, i+1] = X[:, i] + mu(X[:, i], t[i]) * dt + sigma(X[:, i], t[i]) * dW
        
        return t, X


class ItoProcesses:
    """Common Itô processes."""
    
    @staticmethod
    def geometric_brownian_motion(mu, sigma, X0, T, N, n_paths=5):
        """GBM: dX = mu*X*dt + sigma*X*dW"""
        drift = lambda x, t: mu * x
        diffusion = lambda x, t: sigma * x
        return SDESolver.euler_maruyama(drift, diffusion, X0, T, N, n_paths)
    
    @staticmethod
    def ornstein_uhlenbeck(theta, mu, sigma, X0, T, N, n_paths=5):
        """OU process: dX = theta*(mu - X)*dt + sigma*dW"""
        drift = lambda x, t: theta * (mu - x)
        diffusion = lambda x, t: sigma * np.ones_like(x)
        return SDESolver.euler_maruyama(drift, diffusion, X0, T, N, n_paths)

2. Compressed Sensing: Sparse Recovery

Tags: compressed-sensing sparse-recovery l1-minimization

Real-World Motivation

Compressed sensing revolutionized signal acquisition by showing that sparse signals can be reconstructed from far fewer measurements than the Nyquist-Shannon theorem requires. This has transformative applications in MRI (reducing scan times), single-pixel cameras, and analog-to-digital conversion. The key insight, developed by Candès, Romberg, Tao, and Donoho around 2006, is that convex optimization can recover sparse signals from random linear measurements.

Definitions

A vector \( x \in \mathbb{R}^n \) is s-sparse if at most \( s \) of its entries are non-zero. The restricted isometry property (RIP): A matrix \( A \) satisfies RIP of order \( s \) if there exists \( \delta_s \in (0, 1) \) such that for all s-sparse \( x \):

\[ (1 - \delta_s)\|x\|_2^2 \leq \|Ax\|_2^2 \leq (1 + \delta_s)\|x\|_2^2 \]

Theorem (Exact Recovery via \( \ell_1 \) Minimization)

Theorem: Let \( A \in \mathbb{R}^{m \times n} \) satisfy RIP of order \( 2s \) with \( \delta_{2s} < \sqrt{2} - 1 \). Then for any s-sparse \( x \in \mathbb{R}^n \), the solution to:

\[ \hat{x} = \arg\min_{z} \|z\|_1 \quad \text{subject to} \quad Az = y \]

satisfies \( \hat{x} = x \).

Python Implementation

import numpy as np
from scipy.optimize import linprog

class CompressedSensing:
    """Compressed sensing algorithms."""
    
    @staticmethod
    def generate_sparse_signal(n, s):
        """Generate s-sparse signal in R^n."""
        x = np.zeros(n)
        support = np.random.choice(n, s, replace=False)
        x[support] = np.random.randn(s)
        return x
    
    @staticmethod
    def l1_minimization(A, y):
        """Solve min ||x||_1 subject to Ax = y."""
        m, n = A.shape
        c = np.ones(2 * n)
        A_eq = np.hstack([A, -A])
        bounds = [(0, None)] * (2 * n)
        result = linprog(c, A_eq=A_eq, b_eq=y, bounds=bounds, method='highs')
        if result.success:
            z = result.x
            return z[:n] - z[n:]
        return None


# Demonstration
n, s, m = 100, 10, 40
print(f"Compressed Sensing: n={n}, s={s}, m={m}")

x_true = CompressedSensing.generate_sparse_signal(n, s)
A = np.random.randn(m, n) / np.sqrt(m)
y = A @ x_true

x_rec = CompressedSensing.l1_minimization(A, y)
if x_rec is not None:
    error = np.linalg.norm(x_rec - x_true) / np.linalg.norm(x_true)
    print(f"Recovery error: {error:.6f}")

3. Auction Theory: The Revenue Equivalence Theorem

Tags: auction-theory mechanism-design game-theory

Real-World Motivation

Auctions allocate trillions of dollars of goods and services annually, from art and real estate to government contracts and wireless spectrum. The revenue equivalence theorem reveals that under certain conditions, different auction formats yield the same expected revenue. This insight guides the design of markets from eBay to the FCC spectrum auctions.

Theorem (Revenue Equivalence)

Theorem: Consider any auction mechanism where:

  1. Bidders are risk-neutral with independent private values
  2. Bidders are symmetric
  3. The auction allocates to the bidder with highest value

Then any two auction formats that yield the same allocation and give the same expected utility to the lowest type yield the same expected revenue.

Python Implementation

import numpy as np

class AuctionTheory:
    """Auction theory simulations."""
    
    @staticmethod
    def first_price_bid(v, n):
        """Optimal bid in first-price: b(v) = (n-1)/n * v"""
        return (n - 1) / n * v
    
    @staticmethod
    def simulate_auction(auction_type, n_bidders, n_sim=10000):
        """Simulate auction and compute expected revenue."""
        values = np.random.uniform(0, 1, size=(n_sim, n_bidders))
        revenues = []
        
        for v in values:
            if auction_type == 'first_price':
                bids = [AuctionTheory.first_price_bid(vi, n_bidders) for vi in v]
                revenues.append(max(bids))
            elif auction_type == 'second_price':
                revenues.append(sorted(v)[-2] if n_bidders > 1 else 0)
        
        return np.mean(revenues)

2. Ramanujan Graphs: Optimal Expander Graphs

Tags: ramanujan-graphs spectral-graph-theory algebraic-graph-theory

Historical Context

Ramanujan graphs, introduced by Lubotzky, Phillips, and Sarnak in 1988, are optimal expander graphs. Named after Srinivasa Ramanujan, these graphs achieve the best possible spectral gap. The explicit construction of infinite families of Ramanujan graphs of every degree was recently achieved by Marcus, Spielman, and Srivastava.

Definitions

A \( d \)-regular graph is Ramanujan if all non-trivial eigenvalues satisfy \( |\lambda| \leq 2\sqrt{d-1} \).

Theorem (Alon-Boppana)

\[ \liminf_{n \to \infty} \lambda_2(G_n) \geq 2\sqrt{d-1} \]

Thus Ramanujan graphs are optimal from the spectral perspective.

Python Implementation

import numpy as np
import networkx as nx
from scipy.sparse.linalg import eigsh

def is_ramanujan(eigenvalues, d):
    """Check if graph is Ramanujan."""
    bound = 2 * np.sqrt(d - 1)
    for lam in eigenvalues:
        if abs(lam) > bound + 1e-10 and not np.isclose(lam, d):
            return False, bound
    return True, bound

# Create Paley graph (Ramanujan when q ≡ 1 mod 4)
q = 13
def is_quadratic_residue(a, q):

        return False

Newton's Method

For a polynomial \( f(z) \), Newton's method iterates:

\[ z_{n+1} = z_n - \frac{f(z_n)}{f'(z_n)} \]

import numpy as np
import matplotlib.pyplot as plt

def newton_fractal(f, df, roots, xmin=-2, xmax=2, ymin=-2, ymax=2, 
                   width=800, height=800, max_iter=50, tol=1e-6):
    """
    Generate Newton fractal for polynomial f.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Output: which root each point converges to
    output = np.zeros(Z.shape, dtype=int)
    
    for i in range(max_iter):
        # Newton iteration
        Z_new = Z - f(Z) / df(Z)
        
        # Check convergence to each root
        for r_idx, root in enumerate(roots):
            mask = np.abs(Z_new - root) < tol
            output[mask] = r_idx + 1
        
        Z = Z_new
    
    return output

📜 Math History: The Development of Coding Theory

The field of coding theory emerged from the practical need for reliable communication in the presence of noise. In 1948, Claude Shannon published his landmark paper "A Mathematical Theory of Communication," establishing the theoretical foundations for information theory and proving that error-free communication was possible up to a certain rate, now known as the channel capacity.

The first practical error-correcting codes were developed by Richard Hamming in 1950. Working at Bell Labs, Hamming was frustrated by the frequent crashes of the early computer systems and devised codes that could detect and correct single-bit errors. The Hamming codes demonstrated that redundancy could be added strategically to enable error correction, not just detection.

In 1960, Irving Reed and Gustave Solomon developed what would become one of the most important families of error-correcting codes. Reed-Solomon codes, based on sophisticated algebraic techniques using finite fields, could correct multiple errors and erasures. These codes found immediate application in space exploration—the Mariner and Voyager missions used Reed-Solomon codes to transmit images from the outer planets.

The 1980s and 1990s saw the development of turbo codes and LDPC (Low-Density Parity-Check) codes, which approached Shannon's theoretical limit more closely than ever before. These codes enabled the digital revolution in communications, from mobile phones to deep space networks. Today, coding theory continues to evolve with the development of polar codes and graph-based codes for 5G and beyond.

What began as a practical response to equipment failures has become a rich mathematical field connecting algebra, combinatorics, probability, and computer science. The codes developed over seven decades now protect virtually every form of digital communication, from QR codes to cloud storage, from streaming video to cryptocurrency transactions.

🧩 Problem Corner

Putnam 2025 Problem

Problem: Let \( p \) be a prime number. A sequence \( a_0, a_1, a_2, \ldots \) of integers is defined by \( a_0 = 0 \), \( a_1 = 1 \), and for \( n \geq 2 \):

\[ a_n = 2a_{n-1} + (p-2)a_{n-2} \]

Find the remainder when \( a_{p+1} \) is divided by \( p^2 \).

💡 Hint

First solve the recurrence relation explicitly. The characteristic equation is \( r^2 - 2r - (p-2) = 0 \). Use the roots to find a closed form for \( a_n \). Then apply properties of binomial coefficients modulo \( p^2 \), possibly using Lucas' theorem or lifting the exponent lemma.

✅ Solution

Answer: The remainder is \( p \).

Solution:

The characteristic equation is \( r^2 - 2r - (p-2) = 0 \), with roots:

\[ r = \frac{2 \pm \sqrt{4 + 4(p-2)}}{2} = 1 \pm \sqrt{p-1} \]

Let \( \alpha = 1 + \sqrt{p-1} \) and \( \beta = 1 - \sqrt{p-1} \). Then:

\[ a_n = \frac{\alpha^n - \beta^n}{\alpha - \beta} = \frac{\alpha^n - \beta^n}{2\sqrt{p-1}} \]

For \( n = p+1 \), we use the binomial expansion:

\[ a_{p+1} = \frac{1}{2\sqrt{p-1}}\sum_{k=0}^{p+1} \binom{p+1}{k} (\sqrt{p-1})^k(1 - (-1)^k) \]

The terms with even \( k \) cancel. For odd \( k = 2m+1 \):

\[ a_{p+1} = \sum_{m=0}^{\lfloor p/2 \rfloor} \binom{p+1}{2m+1} (p-1)^m \]

Working modulo \( p^2 \), we use that \( \binom{p+1}{k} \equiv \frac{p+1}{k} \binom{p}{k-1} \pmod{p^2} \) for small \( k \). The dominant term is \( m = 0 \): \( \binom{p+1}{1} = p+1 \equiv 1 \pmod{p} \) and the next term contributes \( p \) modulo \( p^2 \).

After careful analysis of all terms, we find \( a_{p+1} \equiv p \pmod{p^2} \).

🎨 Visualization of the Day: The Newton Fractal

The Newton fractal visualizes the basins of attraction for Newton's method applied to complex polynomials. Each point in the complex plane is colored according to which root Newton's method converges to when started at that point.

For the polynomial \( f(z) = z^3 - 1 \), there are three cube roots of unity. The resulting fractal displays three main basins, but the boundaries between them are infinitely complex—zooming in reveals ever-finer structures with self-similar patterns.

The fractal demonstrates several important mathematical concepts:

  • Sensitive dependence: Points arbitrarily close to each other may converge to different roots
  • Fractal structure: The basin boundaries have Hausdorff dimension greater than 1
  • Julia sets: The boundary is related to the Julia set of the Newton iteration
