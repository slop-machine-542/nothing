Birational Geometry: The Minimal Model Program

Motivation

Birational geometry seeks to classify algebraic varieties up to birational equivalence — identifying when two varieties share the same function field. The Minimal Model Program (MMP), initiated by Mori in the 1980s, provides a systematic approach to finding canonical representatives within each birational class. This program has revolutionized our understanding of higher-dimensional algebraic geometry, culminating in the proof of the existence of minimal models and the abundance conjecture in many cases.

Definitions

Birational Map: A rational map \(f : X \dashrightarrow Y\) between varieties is birational if there exists a rational inverse \(g : Y \dashrightarrow X\) such that both compositions are the identity where defined.

Canonical Divisor \(K_X\): For a smooth variety \(X\) of dimension \(n\), the canonical divisor is the divisor associated to the top exterior power of the cotangent bundle: \(K_X = \det(\Omega_X^1)\).

Terminal Singularity: A normal variety \(X\) with \(\mathbb{Q}\)-Cartier canonical divisor has terminal singularities if for any resolution \(f : Y \to X\), writing \(K_Y = f^*K_X + \sum a_i E_i\), we have \(a_i > 0\) for all exceptional divisors \(E_i\).

Mori Fiber Space: A projective morphism \(f : X \to Y\) with connected fibers where \(-K_X\) is \(f\)-ample and \(\dim Y < \dim X\).

Theorem and Proof

Cone Theorem (Mori): Let \(X\) be a smooth projective variety. The cone of curves \(\overline{NE}(X)\) has the structure: \[\overline{NE}(X) = \overline{NE}(X)_{K_X \geq 0} + \sum_{i} \mathbb{R}_{\geq 0}[C_i]\] where the sum is over countably many extremal rays, each generated by a rational curve \(C_i\) with \(0 < -K_X \cdot C_i \leq \dim X + 1\).

Proof Sketch: The proof relies on deformation theory of rational curves and the bend-and-break technique. For a curve class \([C]\) with \(K_X \cdot C < 0\), one considers deformations of morphisms \(f : \mathbb{P}^1 \to X\). When the dimension of the deformation space exceeds the dimension of the target, one can find degenerations where the curve breaks into reducible curves. This process either produces rational curves of bounded degree or shows that the original class lies in the interior of the cone generated by such curves.

Notation Guide

  • \(K_X\) — canonical divisor of \(X\)
  • \(\overline{NE}(X)\) — Mori cone (closure of cone of effective curves)
  • \(N^1(X)\) — Néron-Severi group tensored with \(\mathbb{R}\)
  • \(\rho(X)\) — Picard number (rank of Néron-Severi group)
  • \(f^*\) — pullback of divisors
  • \(f_*\) — pushforward of cycles

        combination of other generators.
        """
        # Simplified check: ray is extremal if not in convex hull of others
        n = len(cone_generators)
        if n <= 1:
            return True

        # This is a simplified version; real implementation uses LP
        for i, gen in enumerate(cone_generators):

                continue

        """
        return all(k >= -1e-10 for k in K_intersections)

Étale Cohomology: Cohomology for Schemes

Motivation

Étale cohomology, developed by Grothendieck and his collaborators in SGA 4, provides a Weil cohomology theory for algebraic varieties over arbitrary fields. It was created to prove the Weil conjectures, which relate the number of points of varieties over finite fields to the topology of the corresponding complex variety. Étale cohomology has become fundamental to modern algebraic geometry and number theory.

Definitions

Étale Morphism: A morphism of schemes \(f : X \to Y\) is étale if it is flat, locally of finite presentation, and for all \(y \in Y\), the fiber \(X_y\) is a disjoint union of spectra of finite separable field extensions of \(k(y)\).

Étale Site \(X_{\text{ét}}\): The category of étale morphisms \(U \to X\) with the étale topology (coverings are jointly surjective families).

\(\ell\)-adic Cohomology: For a prime \(\ell\) different from the characteristic, define \(H^i_{\text{ét}}(X, \mathbb{Q}_\ell) = \left(\varprojlim_n H^i_{\text{ét}}(X, \mathbb{Z}/\ell^n\mathbb{Z})\right) \otimes_{\mathbb{Z}_\ell} \mathbb{Q}_\ell\).

Theorem and Proof

Proper Base Change: Let \(f : X \to S\) be proper and \(\mathcal{F}\) a torsion sheaf on \(X_{\text{ét}}\). For a geometric point \(\bar{s} \to S\), the base change morphism: \[(R^i f_* \mathcal{F})_{\bar{s}} \to H^i_{\text{ét}}(X_{\bar{s}}, \mathcal{F}|_{X_{\bar{s}}})\] is an isomorphism.

Proof Sketch: The proof proceeds by reduction to the case of curves using Chow's lemma and resolution of singularities. For curves, one uses the fact that higher direct images commute with base change for proper morphisms. The key technical tool is the proper base change theorem in topology, adapted to the étale topos via the theory of constructible sheaves.

Notation Guide

  • \(X_{\text{ét}}\) — étale site of scheme \(X\)
  • \(H^i_{\text{ét}}(X, \mathcal{F})\) — étale cohomology groups
  • \(\mathbb{Z}_\ell(1)\) — Tate twist (\(\varprojlim \mu_{\ell^n}\))
  • \(R^i f_*\) — higher direct image functor
  • \(X_{\bar{s}}\) — geometric fiber over \(s\)

        By Weil conjectures: |#C(F_q) - (q + 1)| ≤ 2g√q
        """

        # Simulate Frobenius eigenvalues (simplified)
        max_trace = int(2 * genus * np.sqrt(q))
        return random.randint(-max_trace, max_trace)
    
    @staticmethod
    def zeta_function_coefficients(q, genus, trace):
        """
        Compute coefficients of the zeta function numerator.
        For a curve: Z(t) = P(t)/((1-t)(1-qt))
        where P(t) = ∏(1 - α_i t) and |α_i| = √q
        """
        # P(t) = 1 + a_1 t + a_2 t² + ... + q^g t^{2g}
        # where a_1 = trace of Frobenius
        coeffs = [1]
        a1 = -trace
        coeffs.append(a1)
        
        # For genus 1: P(t) = 1 - at + qt²
        if genus == 1:
            coeffs.append(q)
        elif genus == 2:
            # Use relations from Weil conjectures
            # a_2 = (a_1² - trace(Frob²))/2 + q
            a2 = (a1**2 - (q**2 + 1 - (q + 1 - trace)**2 + q)) // 2 + q
            coeffs.extend([a2, -q*a1, q**2])
        
        return coeffs

    def point_count_from_zeta(q, n, genus, trace):
        """
        Compute #X(F_{q^n}) from zeta function.
        """
        coeffs = EtaleCohomology.zeta_function_coefficients(q, genus, trace)
        # Simplified: use the formula relating zeta to point counts
        # log Z(t) = ∑ N_n t^n / n
        return q**n + 1 + sum(c * (q**(n*(i+1)//2) if i % 2 == 0 else 0) 
                             for i, c in enumerate(coeffs[1:]))

Modular Forms: Symmetry and Arithmetic

Motivation

Modular forms are holomorphic functions on the upper half-plane with remarkable symmetry properties under the action of \(SL_2(\mathbb{Z})\). They encode deep arithmetic information and appear throughout mathematics: in the proof of Fermat's Last Theorem, in the theory of elliptic curves, in string theory, and in the study of L-functions. The modularity theorem establishes that every rational elliptic curve arises from a modular form.

Definitions

Upper Half-Plane: \(\mathbb{H} = \{z \in \mathbb{C} : \text{Im}(z) > 0\}\).

Modular Group: \(\Gamma = SL_2(\mathbb{Z}) = \left\{\begin{pmatrix} a & b \\ c & d \end{pmatrix} : a,b,c,d \in \mathbb{Z}, ad-bc=1\right\}\).

Modular Form of Weight \(k\): A holomorphic function \(f : \mathbb{H} \to \mathbb{C}\) satisfying: \[f\left(\frac{az+b}{cz+d}\right) = (cz+d)^k f(z)\] for all \(\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in SL_2(\mathbb{Z})\), and holomorphic at infinity.

\(q\)-expansion: Since \(f(z+1) = f(z)\), we can write \(f(z) = \sum_{n=0}^{\infty} a_n q^n\) where \(q = e^{2\pi i z}\).

Theorem and Proof

Valence Formula: Let \(f\) be a non-zero modular form of weight \(k\). Then: \[\text{ord}_\infty(f) + \frac{1}{2}\text{ord}_i(f) + \frac{1}{3}\text{ord}_\omega(f) + \sum_{p \in \Gamma \backslash \mathbb{H}}^* \text{ord}_p(f) = \frac{k}{12}\] where \(\omega = e^{2\pi i/3}\) and the sum is over non-elliptic points.

Proof Sketch: Integrate \(f'(z)/f(z)\) around the boundary of the standard fundamental domain for \(SL_2(\mathbb{Z})\). The modular transformation property implies that contributions from equivalent boundary segments cancel, leaving only contributions from zeros inside and at the corners (\(i\) and \(\omega\)). The factor of \(k/12\) arises from the behavior at the cusp.

Notation Guide

  • \(\mathbb{H}\) — upper half-plane
  • \(\Gamma\) or \(SL_2(\mathbb{Z})\) — modular group
  • \(M_k(\Gamma)\) — space of modular forms of weight \(k\)
  • \(S_k(\Gamma)\) — space of cusp forms (vanish at infinity)
  • \(q = e^{2\pi i z}\) — local parameter at infinity
  • \(E_k\) — Eisenstein series of weight \(k\)
  • \(\Delta\) — discriminant modular form (weight 12)

import numpy as np
import cmath

class ModularForms:
    """Computations with modular forms."""
    
    @staticmethod
    def eisenstein_series(k, z, terms=100):
        """
        Compute Eisenstein series E_k(z) = 1 - (2k/B_k) ∑ σ_{k-1}(n) q^n
        where B_k is Bernoulli number and σ is divisor function.
        """
        from fractions import Fraction
        
        # Bernoulli numbers B_4 = -1/30, B_6 = 1/42, etc.
        bernoulli = {4: Fraction(-1, 30), 6: Fraction(1, 42), 
                     8: Fraction(-1, 30), 10: Fraction(5, 66)}
        
        if k not in bernoulli:
            raise ValueError(f"E_{k} not implemented")
        
        Bk = bernoulli[k]
        q = cmath.exp(2j * np.pi * z)
        
        result = 1.0
        coeff = -2 * k / float(Bk)
        
        for n in range(1, terms):
            # Divisor function σ_{k-1}(n) = sum of d^{k-1} for d|n
            sigma = sum(d**(k-1) for d in range(1, n+1) if n % d == 0)
            result += coeff * sigma * (q ** n)
        
        return result
    
    @staticmethod
    def divisor_function(k, n):
        """Compute σ_k(n) = sum of d^k for all divisors d of n."""
        return sum(d**k for d in range(1, n+1) if n % d == 0)
    
    @staticmethod
    def delta_function(z, terms=50):
        """
        Ramanujan Delta function: Δ(z) = q ∏(1-q^n)^24
        = ∑ τ(n) q^n where τ is Ramanujan's tau function.
        """
        q = cmath.exp(2j * np.pi * z)
        result = q
        for n in range(1, terms):
            result *= (1 - q**n)**24
        return result
    
    @staticmethod
    def dimension_modular_forms(k):
        """
        Dimension of M_k(SL_2(Z)).
        dim M_k = floor(k/12) + 1 if k ≡ 0,2 (mod 12), else floor(k/12)
        for k ≥ 0 even.
        """
        if k % 2 != 0:
            return 0
        if k == 0:
            return 1
        base = k // 12
        if k % 12 == 2:
            return base
        return base + 1

Stochastic Calculus: Itô's Legacy

Real-World Motivation

Stochastic calculus provides the mathematical framework for modeling systems subject to random fluctuations. From the Black-Scholes equation in finance to the Fokker-Planck equation in physics, Itô calculus has become indispensable. The theory was developed by Kiyoshi Itô in the 1940s and has since found applications in quantitative finance, statistical physics, biology, and engineering.

Definitions

Wiener Process (Brownian Motion): A continuous stochastic process \(W_t\) with \(W_0 = 0\), independent increments, and \(W_t - W_s \sim N(0, t-s)\) for \(t > s\).

Itô Integral: For an adapted process \(X_t\), the Itô integral \(\int_0^t X_s \, dW_s\) is defined as the limit in \(L^2\) of Riemann sums \(\sum X_{t_i}(W_{t_{i+1}} - W_{t_i})\).

Stochastic Differential Equation (SDE): An equation of the form \(dX_t = \mu(X_t, t)dt + \sigma(X_t, t)dW_t\), interpreted as: \[X_t = X_0 + \int_0^t \mu(X_s, s)ds + \int_0^t \sigma(X_s, s)dW_s\]

Theorem and Proof

Itô's Lemma: Let \(X_t\) satisfy the SDE above and let \(f \in C^{2,1}(\mathbb{R} \times [0,\infty))\). Then \(Y_t = f(X_t, t)\) satisfies: \[df = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial x}dX_t + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(dX_t)^2\] where \((dX_t)^2 = \sigma^2 dt\) (using the rules \(dt^2 = 0\), \(dtdW = 0\), \(dW^2 = dt\)).

Proof Sketch: Apply Taylor expansion to \(f(X_{t+\Delta t}, t+\Delta t) - f(X_t, t)\): \[\Delta f = f_t \Delta t + f_x \Delta X + \frac{1}{2}f_{xx}(\Delta X)^2 + \cdots\] As \(\Delta t \to 0\), \(\Delta X \approx \mu \Delta t + \sigma \Delta W\). The key observation is that \((\Delta W)^2 \approx \Delta t\) in the mean-square sense (quadratic variation), so the second-order term contributes a finite amount.

Notation Guide

  • \(W_t\) — Wiener process (standard Brownian motion)
  • \(\mathcal{F}_t\) — filtration (information available at time \(t\))
  • \(\mu\) — drift coefficient
  • \(\sigma\) — diffusion/volatility coefficient
  • \(dW_t\) — Itô differential (not a true differential)
  • \(\langle X \rangle_t\) — quadratic variation process

import numpy as np
import matplotlib.pyplot as plt

class StochasticCalculus:
    """Simulations and computations for stochastic calculus."""
    
    @staticmethod
    def simulate_brownian_motion(T, N, n_paths=1, seed=None):
        """
        Simulate standard Brownian motion on [0, T] with N steps.
        """
        if seed is not None:
            np.random.seed(seed)
        
        dt = T / N
        dW = np.random.randn(n_paths, N) * np.sqrt(dt)
        W = np.concatenate([np.zeros((n_paths, 1)), np.cumsum(dW, axis=1)], axis=1)
        t = np.linspace(0, T, N+1)
        return t, W
    
    @staticmethod
    def simulate_sde_euler(mu, sigma, X0, T, N, n_paths=1):
        """
        Solve SDE: dX = mu(X,t)dt + sigma(X,t)dW using Euler-Maruyama.
        """
        dt = T / N
        X = np.zeros((n_paths, N+1))
        X[:, 0] = X0
        
        for i in range(N):
            dW = np.random.randn(n_paths) * np.sqrt(dt)
            X[:, i+1] = X[:, i] + mu(X[:, i], i*dt)*dt + sigma(X[:, i], i*dt)*dW
        
        t = np.linspace(0, T, N+1)
        return t, X
    
    @staticmethod
    def geometric_brownian_motion_exact(S0, mu, sigma, T, N, n_paths=1):
        """
        Exact solution to dS = mu*S*dt + sigma*S*dW.
        S(t) = S0 * exp((mu - sigma²/2)t + sigma*W(t))
        """
        t, W = StochasticCalculus.simulate_brownian_motion(T, N, n_paths)
        S = S0 * np.exp((mu - 0.5*sigma**2)*t + sigma*W)
        return t, S
    
    @staticmethod
    def ito_isometry_check(integrand, T, N, n_samples=1000):
        """
        Verify Itô isometry: E[(∫ f dW)²] = E[∫ f² dt]
        """
        dt = T / N
        t = np.linspace(0, T, N)
        
        integrals = []
        for _ in range(n_samples):
            dW = np.random.randn(N) * np.sqrt(dt)
            f_vals = integrand(t)
            integral = np.sum(f_vals * dW)
            integrals.append(integral**2)
        
        left_side = np.mean(integrals)
        right_side = np.sum(integrand(t)**2) * dt
        
        return left_side, right_side

Numerical Methods for Partial Differential Equations

Real-World Motivation

Partial differential equations govern phenomena across science and engineering: fluid flow, heat transfer, electromagnetic fields, quantum mechanics, and financial derivatives. While exact solutions are rare, numerical methods enable us to approximate solutions with controllable accuracy. Finite difference, finite element, and spectral methods have become essential tools in computational science.

Definitions

Finite Difference Approximation: Replace derivatives by difference quotients: \[u'(x) \approx \frac{u(x+h) - u(x)}{h}, \quad u''(x) \approx \frac{u(x+h) - 2u(x) + u(x-h)}{h^2}\]

Consistency: A numerical scheme is consistent if the local truncation error tends to zero as the mesh is refined.

Stability: A scheme is stable if small perturbations in initial data produce bounded perturbations in the solution.

CFL Condition (Courant-Friedrichs-Lewy): For explicit schemes solving hyperbolic PDEs, the numerical domain of dependence must contain the physical domain of dependence: \(\frac{c\Delta t}{\Delta x} \leq 1\).

Theorem and Proof

Lax Equivalence Theorem: For a well-posed linear initial value problem, a consistent finite difference scheme is convergent if and only if it is stable.

Proof Sketch: Let \(u\) be the exact solution and \(u^n\) the numerical solution at time \(t_n\). Define the error \(e^n = u^n - u(t_n)\). By consistency, the local truncation error \(\tau^n \to 0\). The error satisfies: \[e^{n+1} = Se^n + \Delta t \tau^n\] where \(S\) is the amplification operator. By stability, \(\|S^n\| \leq C\). Then: \[\|e^n\| \leq \Delta t \sum_{k=0}^{n-1} \|S^{n-1-k}\| \|\tau^k\| \leq C T \max_k \|\tau^k\| \to 0\]

Notation Guide

  • \(\Delta x, \Delta t\) — spatial and temporal step sizes
  • \(u_i^n\) — numerical approximation at \((x_i, t_n)\)
  • \(\tau\) — local truncation error
  • \(S\) — amplification/iteration operator
  • \(\lambda = \Delta t / \Delta x^2\) — parabolic mesh ratio
  • \(CFL = c\Delta t / \Delta x\) — Courant number

import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

class NumericalPDE:
    """Finite difference methods for PDEs."""
    
    @staticmethod
    def heat_equation_ftcs(u0, L, T, nx, nt, alpha=1.0):
        """
        Solve heat equation u_t = alpha * u_xx using FTCS (Forward Time Centered Space).
        Explicit scheme: u_i^{n+1} = u_i^n + lambda * (u_{i+1}^n - 2u_i^n + u_{i-1}^n)
        where lambda = alpha * dt / dx^2.
        """
        dx = L / (nx - 1)
        dt = T / nt
        lam = alpha * dt / dx**2
        
        if lam > 0.5:
            print(f"Warning: lambda = {lam:.3f} > 0.5, scheme may be unstable")
        
        x = np.linspace(0, L, nx)
        u = u0(x).copy()
        u_new = u.copy()
        
        for n in range(nt):
            u_new[1:-1] = u[1:-1] + lam * (u[2:] - 2*u[1:-1] + u[:-2])
            # Dirichlet boundary conditions
            u_new[0], u_new[-1] = 0, 0
            u, u_new = u_new, u
        
        return x, u
    
    @staticmethod
    def heat_equation_crank_nicolson(u0, L, T, nx, nt, alpha=1.0):
        """
        Solve heat equation using Crank-Nicolson (unconditionally stable).
        (I - 0.5*lam*A)u^{n+1} = (I + 0.5*lam*A)u^n
        """
        dx = L / (nx - 1)
        dt = T / nt
        lam = alpha * dt / dx**2
        
        x = np.linspace(0, L, nx)
        u = u0(x).copy()
        
        # Tridiagonal matrices
        main_diag = (1 + lam) * np.ones(nx-2)
        off_diag = -0.5 * lam * np.ones(nx-3)
        A = diags([off_diag, main_diag, off_diag], [-1, 0, 1])
        
        main_diag_R = (1 - lam) * np.ones(nx-2)
        off_diag_R = 0.5 * lam * np.ones(nx-3)
        R = diags([off_diag_R, main_diag_R, off_diag_R], [-1, 0, 1])
        
        for n in range(nt):
            b = R @ u[1:-1]
            u[1:-1] = spsolve(A, b)
        
        return x, u
    
    @staticmethod
    def wave_equation_leapfrog(u0, v0, L, T, nx, nt, c=1.0):
        """
        Solve wave equation u_tt = c² u_xx using leapfrog scheme.
        """
        dx = L / (nx - 1)
        dt = T / nt
        CFL = c * dt / dx
        
        if CFL > 1:
            print(f"Warning: CFL = {CFL:.3f} > 1, scheme unstable")
        
        x = np.linspace(0, L, nx)
        u = np.zeros((nt+1, nx))
        
        # Initial conditions
        u[0, :] = u0(x)
        u[1, :] = u[0, :] + dt * v0(x) + 0.5 * CFL**2 * (
            np.roll(u[0, :], -1) - 2*u[0, :] + np.roll(u[0, :], 1)
        )
        
        # Time stepping
        for n in range(1, nt):
            u[n+1, 1:-1] = 2*u[n, 1:-1] - u[n-1, 1:-1] + CFL**2 * (
                u[n, 2:] - 2*u[n, 1:-1] + u[n, :-2]
            )
        
        return x, u
    
    @staticmethod
    def convergence_study(solver, u_exact, u0, L, T, alpha, nx_values):
        """
        Study convergence rate by comparing with exact solution.
        """
        errors = []
        for nx in nx_values:
            nt = nx**2  # Keep dt/dx^2 constant
            x, u_num = solver(u0, L, T, nx, nt, alpha)
            u_ex = u_exact(x, T)
            error = np.max(np.abs(u_num - u_ex))
            errors.append(error)
        
        # Estimate convergence rate
        rates = [np.log(errors[i]/errors[i-1]) / np.log(nx_values[i-1]/nx_values[i]) 
                 for i in range(1, len(errors))]
        
        return errors, rates

Mathematical Epidemiology: Modeling Disease Spread

Real-World Motivation

Mathematical models of infectious disease spread have guided public health policy for over a century. From Kermack and McKendrick's foundational work in 1927 to modern agent-based simulations of COVID-19, these models help predict epidemic trajectories, evaluate intervention strategies, and estimate key parameters like the basic reproduction number \(R_0\).

Definitions

SIR Model: Compartmental model with Susceptible (S), Infected (I), Recovered (R) populations: \[\frac{dS}{dt} = -\beta SI, \quad \frac{dI}{dt} = \beta SI - \gamma I, \quad \frac{dR}{dt} = \gamma I\]

Basic Reproduction Number \(R_0\): The expected number of secondary infections from one infected individual in a fully susceptible population. For SIR: \(R_0 = \beta S_0 / \gamma\).

Herd Immunity Threshold: The proportion of immune individuals needed to prevent sustained transmission: \(p_c = 1 - 1/R_0\).

SEIR Model: Extension with Exposed (E) compartment for latent period: \[\frac{dE}{dt} = \beta SI - \sigma E, \quad \frac{dI}{dt} = \sigma E - \gamma I\]

Theorem and Proof

Final Size Equation: For the SIR model with initial conditions \(S(0) = S_0, I(0) = I_0\), the final epidemic size \(R_\infty\) satisfies: \[R_\infty = 1 - S_0 \exp\left(-R_0 \frac{R_\infty}{N}\right)\]

Proof: From the SIR equations, note that \(\frac{dI}{dS} = -1 + \frac{\gamma}{\beta S}\). Integrating from \(t=0\) to \(t=\infty\): \[I_\infty - I_0 = -(S_\infty - S_0) + \frac{\gamma}{\beta} \ln\frac{S_\infty}{S_0}\] Since \(I_\infty = 0\) and \(R_\infty = N - S_\infty\), rearranging gives the result with \(R_0 = \beta N / \gamma\).

Notation Guide

  • \(S, I, R, E\) — number/proportion in each compartment
  • \(\beta\) — transmission rate
  • \(\gamma\) — recovery rate (1/\(\gamma\) is infectious period)
  • \(\sigma\) — rate of progression from exposed to infectious
  • \(R_0\) — basic reproduction number
  • \(R_t\) — effective reproduction number at time \(t\)

import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

class EpidemiologyModels:
    """Compartmental models for infectious disease dynamics."""
    
    @staticmethod
    def sir_model(t, y, beta, gamma, N):
        """
        SIR model: dS/dt = -beta*S*I/N, dI/dt = beta*S*I/N - gamma*I, dR/dt = gamma*I
        """
        S, I, R = y
        dSdt = -beta * S * I / N
        dIdt = beta * S * I / N - gamma * I
        dRdt = gamma * I
        return [dSdt, dIdt, dRdt]
    
    @staticmethod
    def seir_model(t, y, beta, sigma, gamma, N):
        """
        SEIR model with latent period.
        """
        S, E, I, R = y
        dSdt = -beta * S * I / N
        dEdt = beta * S * I / N - sigma * E
        dIdt = sigma * E - gamma * I
        dRdt = gamma * I
        return [dSdt, dEdt, dIdt, dRdt]
    
    @staticmethod
    def solve_sir(S0, I0, R0, beta, gamma, t_span, t_eval):
        """Solve SIR model numerically."""
        N = S0 + I0 + R0
        sol = solve_ivp(
            lambda t, y: EpidemiologyModels.sir_model(t, y, beta, gamma, N),
            t_span, [S0, I0, R0], t_eval=t_eval, method='RK45'
        )
        return sol.t, sol.y
    
    @staticmethod
    def final_size_equation(R0, S0_frac):
        """
        Solve final size equation: R_inf = 1 - S0 * exp(-R0 * R_inf)
        using fixed-point iteration.
        """
        R_inf = 0.5  # Initial guess
        for _ in range(100):
            R_new = 1 - S0_frac * np.exp(-R0 * R_inf)
            if abs(R_new - R_inf) < 1e-10:
                break
            R_inf = R_new
        return R_inf
    
    @staticmethod
    def herd_immunity_threshold(R0):
        """Calculate herd immunity threshold."""
        return 1 - 1/R0
    
    @staticmethod
    def time_varying_r0_sir(S0, I0, R0, gamma, R0_func, t_span, t_eval):
        """
        SIR with time-varying R0 (e.g., due to interventions).
        beta(t) = R0(t) * gamma
        """
        N = S0 + I0 + R0
        
        def model(t, y):
            S, I, R = y
            beta_t = R0_func(t) * gamma
            dSdt = -beta_t * S * I / N
            dIdt = beta_t * S * I / N - gamma * I
            dRdt = gamma * I
            return [dSdt, dIdt, dRdt]
        
        sol = solve_ivp(model, t_span, [S0, I0, R0], t_eval=t_eval, method='RK45')
        return sol.t, sol.y

Algebraic Surfaces: Classification and Geography

algebraic-surfaces

Historical Context

The classification of algebraic surfaces, initiated by the Italian school (Castelnuovo, Enriques, Severi) in the late 19th and early 20th centuries, represents one of the crowning achievements of classical algebraic geometry. The Enriques-Kodaira classification organizes compact complex surfaces into birational classes based on their pluricanonical maps and numerical invariants. This was extended to characteristic \(p\) by Bombieri and Mumford, and to non-algebraic surfaces by Kodaira.

Definitions

  • Geometric Genus \(p_g\): \(p_g = h^0(X, K_X) = h^2(X, \mathcal{O}_X)\), the dimension of holomorphic 2-forms.
  • Irregularity \(q\): \(q = h^1(X, \mathcal{O}_X) = h^0(X, \Omega_X^1)\).
  • Holomorphic Euler Characteristic: \(\chi(\mathcal{O}_X) = 1 - q + p_g\).
  • Kodaira Dimension \(\kappa(X)\): \(\kappa(X) = \text{tr.deg.} \bigoplus_{m \geq 0} H^0(X, mK_X) - 1\), or \(-\infty\) if all pluricanonical maps are empty.

Theorem: Noether's Formula

Theorem: For a smooth projective surface \(X\): \[\chi(\mathcal{O}_X) = \frac{K_X^2 + c_2(X)}{12} = \frac{K_X^2 + e(X)}{12}\] where \(c_2(X) = e(X)\) is the topological Euler characteristic.

Proof Sketch: This follows from the Hirzebruch-Riemann-Roch theorem applied to the trivial bundle: \[\chi(\mathcal{O}_X) = \int_X \text{td}(T_X) = \int_X \left(1 + \frac{c_1}{2} + \frac{c_1^2 + c_2}{12}\right) = \frac{c_1^2 + c_2}{12}\] where \(c_1 = -K_X\).

Notation Guide

  • \(K_X^2\) — self-intersection of canonical divisor (Chern number \(c_1^2\))
  • \(e(X)\) or \(\chi_{\text{top}}(X)\) — topological Euler characteristic
  • \(b_i\) — Betti numbers
  • \(h^{p,q}\) — Hodge numbers
  • \(\chi = 12\chi(\mathcal{O}_X)\) — Noether number

import numpy as np

        return (K2 + e) / 12

        """
        chi = 1 - q + pg
        expected = (K2 + e) / 12
        return np.isclose(chi, expected)

        b2 = h11 + 2*h20
        b1 = 2*h01

Sieve Methods: Finding Primes in Sequences

sieve-methods

Historical Context

Sieve methods originated with Eratosthenes in ancient Greece and were revitalized in the 20th century by Viggo Brun, who developed the first combinatorial sieve. The modern theory, culminating in the work of Bombieri, Iwaniec, and others, has produced spectacular results: Chen's theorem that every sufficiently large even integer is the sum of a prime and a product of at most two primes, and the proof that there are infinitely many bounded gaps between primes (Zhang, Maynard).

Definitions

  • Sieve Problem: Given a finite set \(\mathcal{A}\) of integers and a set of primes \(\mathcal{P}\), estimate the number of elements in \(\mathcal{A}\) not divisible by any prime in \(\mathcal{P}\).
  • Sifting Function: \(S(\mathcal{A}, \mathcal{P}, z) = \#\{a \in \mathcal{A} : \gcd(a, P(z)) = 1\}\) where \(P(z) = \prod_{p < z, p \in \mathcal{P}} p\).
  • Level of Distribution \(\theta\): The Bombieri-Vinogradov theorem gives equidistribution of primes in arithmetic progressions up to \(q \leq x^{1/2}/(\log x)^A\).

Theorem: Brun's Pure Sieve

Theorem: Let \(\mathcal{A}\) be a finite set of integers, \(\mathcal{P}\) a set of primes. For any even integer \(r \geq 0\): \[\sum_{d \mid P(z), \omega(d) \leq r} \mu(d) |\mathcal{A}_d| \leq S(\mathcal{A}, \mathcal{P}, z) \leq \sum_{d \mid P(z), \omega(d) \leq r+1} \mu(d) |\mathcal{A}_d|\] where \(\omega(d)\) is the number of prime factors and \(\mu\) is the Möbius function.

Proof Sketch: The key observation is the Legendre identity: \[S(\mathcal{A}, \mathcal{P}, z) = \sum_{d \mid P(z)} \mu(d) |\mathcal{A}_d|\] Truncating this sum using the parity of \(\omega(d)\) gives upper and lower bounds because the Möbius function alternates sign.

Notation Guide

  • \(\omega(n)\) — number of distinct prime factors of \(n\)
  • \(\Omega(n)\) — number of prime factors with multiplicity
  • \(\mu(n)\) — Möbius function (\((-1)^{\omega(n)}\) if squarefree, 0 otherwise)
  • \(\varphi(n)\) — Euler's totient function
  • \(\pi(x)\) — prime counting function
  • \(\text{li}(x)\) — logarithmic integral \(\int_2^x \frac{dt}{\ln t}\)

import numpy as np
from sympy import factorint, mobius, primerange

class SieveMethods:
    """Implementation of various sieve methods."""
    
    @staticmethod
    def eratosthenes_sieve(n):
        """
        Classical Eratosthenes sieve for primes up to n.
        """
        is_prime = np.ones(n+1, dtype=bool)
        is_prime[0:2] = False
        for i in range(2, int(np.sqrt(n)) + 1):
            if is_prime[i]:
                is_prime[i*i:n+1:i] = False
        return np.where(is_prime)[0]
    
    @staticmethod
    def segmented_sieve(low, high):
        """
        Segmented sieve for primes in range [low, high].
        """
        limit = int(np.sqrt(high)) + 1
        base_primes = SieveMethods.eratosthenes_sieve(limit)
        
        is_prime = np.ones(high - low, dtype=bool)
        for p in base_primes:
            start = max(p*p, (low + p - 1) // p * p)
            is_prime[start - low:high - low:p] = False
        
        return np.where(is_prime)[0] + low
    
    @staticmethod
    def brun_sieve_estimate(x, z):
        """
        Estimate twin prime count using Brun's sieve.
        Returns upper bound for number of n ≤ x such that 
        n and n+2 are both prime.
        """
        # Simplified: count n ≤ x where neither n nor n+2 divisible by p < z
        count = 0
        primes = list(primerange(2, z))
        
        for n in range(3, x+1, 2):  # Only odd n
            is_twin = True
            for p in primes:
                if n % p == 0 or (n + 2) % p == 0:
                    is_twin = False
                    break
                if p * p > n + 2:
                    break
            if is_twin:
                count += 1
        
        return count
    
    @staticmethod
    def mobius_sieve(n):
        """
        Compute Möbius function for all integers up to n using sieve.
        """
        mu = np.ones(n+1, dtype=int)
        is_squarefree = np.ones(n+1, dtype=bool)
        
        for i in range(2, n+1):
            if is_squarefree[i]:
                for j in range(i, n+1, i):
                    mu[j] *= -1
                i2 = i * i
                for j in range(i2, n+1, i2):
                    is_squarefree[j] = False
                    mu[j] = 0
        
        return mu
    
    @staticmethod
    def legendre_formula(x, a):
        """
        Legendre's formula: π(x) - π(√x) + 1 = φ(x, a) where a = π(√x)
        φ(x, a) counts integers ≤ x not divisible by first a primes.
        """
        primes = SieveMethods.eratosthenes_sieve(int(np.sqrt(x)) + 1)
        a = len(primes)
        
        # Count using inclusion-exclusion
        count = x
        for k in range(1, a+1):
            # Sum over all k-subsets of first a primes
            from itertools import combinations
            for subset in combinations(primes[:a], k):
                product = np.prod(subset)
                count += (-1)**k * (x // product)
        
        return count
    
    @staticmethod
    def twin_prime_constant():
        """
        Twin prime constant C₂ = ∏_{p>2} p(p-2)/(p-1)² ≈ 0.6601618
        """
        # Approximate using first several primes
        C2 = 1.0
        for p in primerange(3, 10000):
            C2 *= p * (p - 2) / (p - 1)**2
        return C2

Knot Invariants: From Jones to Khovanov

knot-invariants

Historical Context

The study of knot invariants began in earnest with Vandermonde (1771) and Gauss, but the modern era began with the discovery of the Jones polynomial in 1984. Vaughan Jones's breakthrough connected knot theory to operator algebras, earning him the Fields Medal. This was followed by the HOMFLY polynomial and, most significantly, Mikhail Khovanov's categorification of the Jones polynomial in 1999, which revealed that the Jones polynomial is the Euler characteristic of a richer homological invariant.

Definitions

  • Knot: An embedding of \(S^1\) into \(S^3\) (or \(\mathbb{R}^3\)), considered up to ambient isotopy.
  • Link: An embedding of a disjoint union of circles.
  • Kauffman Bracket \(\langle D \rangle\): A Laurent polynomial in variable \(A\) defined by skein relations: \[\langle \bigcirc \rangle = 1, \quad \langle D \sqcup \bigcirc \rangle = (-A^2 - A^{-2})\langle D \rangle\] \[\langle \crossingpos \rangle = A\langle \smoothingA \rangle + A^{-1}\langle \smoothingB \rangle\]
  • Jones Polynomial \(V_L(t)\): Obtained from the Kauffman bracket by \(V_L(t) = ((-A)^{-3w(D)}\langle D \rangle)_{A = t^{-1/4}}\) where \(w(D)\) is the writhe.

Theorem: The Jones Polynomial is a Link Invariant

Theorem: The Jones polynomial \(V_L(t) \in \mathbb{Z}[t^{1/2}, t^{-1/2}]\) is an invariant of oriented links. It satisfies the skein relation: \[t^{-1}V_{L_+}(t) - tV_{L_-}(t) = (t^{1/2} - t^{-1/2})V_{L_0}(t)\] where \(L_+, L_-, L_0\) differ at a single crossing as shown below.

Proof Sketch: The Kauffman bracket is invariant under Reidemeister moves II and III. The writhe correction ensures invariance under Reidemeister move I. The skein relation follows directly from the definition of the Kauffman bracket and the writhe behavior under crossing changes.

Notation Guide

  • \(\langle D \rangle\) — Kauffman bracket of diagram \(D\)
  • \(w(D)\) — writhe of oriented diagram (signed crossing count)
  • \(V_L(t)\) — Jones polynomial
  • \(\Delta_L(t)\) — Alexander polynomial
  • \(P_L(a, z)\) — HOMFLY polynomial
  • \(Kh(L)\) — Khovanov homology (categorification)

import numpy as np
from functools import lru_cache

class KnotTheory:
    """Computations with knot invariants."""
    
    @staticmethod
    def kauffman_bracket_recursive(crossings, A=None):
        """
        Compute Kauffman bracket via recursive skein relation.
        crossings: list of signs (+1 or -1) for each crossing
        A: symbolic variable (use string representation)
        
        This is a simplified implementation.
        """
        if A is None:
            A = 'A'
        
        # Base case: no crossings

Information Geometry: The Geometry of Statistics

information-geometry

Historical Context

Information geometry, founded by C.R. Rao in 1945 and developed extensively by Shun-ichi Amari in the 1980s, studies the differential geometric structure of statistical manifolds. The Fisher information metric provides a Riemannian structure on parameter spaces, while the dual connections (e-flat and m-flat) reveal deep structures in exponential families and mixture families. This framework has found applications in machine learning, neuroscience, and quantum information theory.

Definitions

  • Statistical Manifold: A manifold \(\mathcal{M}\) where each point corresponds to a probability distribution \(p(x; \theta)\).
  • Fisher Information Matrix: \(g_{ij}(\theta) = \mathbb{E}\left[\frac{\partial \log p}{\partial \theta^i} \frac{\partial \log p}{\partial \theta^j}\right] = -\mathbb{E}\left[\frac{\partial^2 \log p}{\partial \theta^i \partial \theta^j}\right]\).
  • Kullback-Leibler Divergence: \(D_{KL}(p \| q) = \int p(x) \log\frac{p(x)}{q(x)} dx\).
  • Exponential Family: \(p(x; \theta) = \exp(\theta \cdot F(x) - \psi(\theta))\) where \(\psi\) is the cumulant generating function.

Theorem: Cramér-Rao Bound

Theorem: For any unbiased estimator \(\hat{\theta}\) of \(\theta\) based on \(n\) i.i.d. samples: \[\text{Cov}(\hat{\theta}) \succeq \frac{1}{n} G(\theta)^{-1}\] where \(G(\theta)\) is the Fisher information matrix and \(\succeq\) denotes the Loewner order (positive semidefinite difference).

Proof Sketch: Consider the covariance between the estimator and the score function \(s(\theta) = \nabla_\theta \log p(X; \theta)\). By the Cauchy-Schwarz inequality for random vectors and the fact that \(\mathbb{E}[s(\theta)] = 0\), \(\text{Cov}(s) = G(\theta)\), we obtain the bound. The unbiasedness condition ensures the cross-covariance term equals the identity.

Notation Guide

  • \(g_{ij}\) — Fisher information metric
  • \(\Gamma_{ij,k}^{(\alpha)}\) — \(\alpha\)-connection coefficients
  • \(\psi(\theta)\) — cumulant generating function (log partition)
  • \(\eta_i = \mathbb{E}[F_i(X)]\) — expectation parameters (dual to \(\theta\))
  • \(D_{KL}, D_J\) — KL divergence, Jeffreys divergence

from scipy.optimize import minimize
from scipy.integrate import quad

class InformationGeometry:
    """Information geometry computations."""
    
    @staticmethod
    def fisher_information_gaussian(mu, sigma):
        """
        Fisher information matrix for N(μ, σ²).
        G = [[1/σ², 0], [0, 1/(2σ⁴)]]
        """
        return np.array([[1/sigma**2, 0], [0, 1/(2*sigma**4)]])
    
    @staticmethod
    def fisher_information_bernoulli(p):
        """
        Fisher information for Bernoulli(p).
        I(p) = 1/(p(1-p))
        """
        return 1 / (p * (1 - p))
    
    @staticmethod
    def fisher_information_exponential(lam):
        """
        Fisher information for Exp(λ).
        I(λ) = 1/λ²
        """
        return 1 / lam**2
    
    @staticmethod
    def cramerrao_bound(fisher_info, n_samples):
        """
        Compute Cramér-Rao lower bound for variance of unbiased estimators.
        """
        return np.linalg.inv(n_samples * fisher_info)
    
    @staticmethod
    def kl_divergence_gaussian(mu1, sigma1, mu2, sigma2):
        """
        KL divergence between two Gaussians.
        D_KL(N₁ || N₂) = log(σ₂/σ₁) + (σ₁² + (μ₁-μ₂)²)/(2σ₂²) - 1/2
        """
        return (np.log(sigma2/sigma1) + 
                (sigma1**2 + (mu1 - mu2)**2) / (2 * sigma2**2) - 0.5)
    
    @staticmethod
    def kl_divergence_bernoulli(p, q):
        """
        KL divergence between Bernoulli(p) and Bernoulli(q).
        """
        if p == 0:
            return 0 if q == 0 else -np.log(1 - q)
        if p == 1:
            return 0 if q == 1 else -np.log(q)
        return p * np.log(p/q) + (1-p) * np.log((1-p)/(1-q))
    
    @staticmethod
    def jeffreys_divergence_gaussian(mu1, sigma1, mu2, sigma2):
        """
        Jeffreys divergence (symmetrized KL) between Gaussians.
        """
        kl_12 = InformationGeometry.kl_divergence_gaussian(mu1, sigma1, mu2, sigma2)
        kl_21 = InformationGeometry.kl_divergence_gaussian(mu2, sigma2, mu1, sigma1)
        return kl_12 + kl_21
    
    @staticmethod
    def fisher_rao_distance_gaussian(mu1, sigma1, mu2, sigma2):
        """
        Fisher-Rao distance between univariate Gaussians.
        d = √2 * arccosh(1 + (μ₁-μ₂)²/(2σ₁σ₂) + (σ₁-σ₂)²/(2σ₁σ₂))
        """
        delta_mu = mu1 - mu2
        term = 1 + delta_mu**2 / (2*sigma1*sigma2) + (sigma1 - sigma2)**2 / (2*sigma1*sigma2)
        return np.sqrt(2) * np.arccosh(term)
    
    @staticmethod
    def natural_gradient_update(theta, grad_L, fisher_info, lr):
        """
        Natural gradient update: θ ← θ - lr * G(θ)^(-1) ∇L
        """
        nat_grad = np.linalg.solve(fisher_info, grad_L)
        return theta - lr * nat_grad
    
    @staticmethod
    def exponential_family_score(x, theta, sufficient_stat):
        """
        Score function for exponential family.
        s(x; θ) = F(x) - ∇ψ(θ) = F(x) - η
        """
        eta = sufficient_stat  # Expected sufficient statistic
        return x - eta

📜 Math History: The Birth of Modern Algebra

The transformation of algebra from a discipline focused on solving equations to one concerned with abstract structures represents one of the most profound shifts in mathematical thinking. This revolution, spanning roughly 1830 to 1930, was driven by the work of mathematicians across Europe, each contributing pieces to a grand conceptual reorganization.

The story begins with the insolubility of the quintic. Paolo Ruffini (1799) and Niels Henrik Abel (1824) proved that general polynomial equations of degree five cannot be solved by radicals. But it was Évariste Galois, in the fevered nights before his fatal duel in 1832, who discovered the profound connection between field extensions and groups of permutations. Galois's work, published posthumously by Liouville in 1846, showed that the solvability of an equation is determined by the structure of its associated group—the Galois group.

Galois's insight was not merely a criterion for solvability but a demonstration that the study of equations could be replaced by the study of groups and fields. This shift from the particular to the general, from calculation to structure, would become the hallmark of modern algebra.

The second half of the 19th century saw the development of ring theory, though the term "ring" (Zahlring) would not be coined until Hilbert in 1897. Richard Dedekind introduced ideals in his work on algebraic number theory, studying the factorization properties of integers in algebraic number fields. His theory of ideals rescued unique factorization in rings where it failed for elements, replacing factorization of numbers with factorization of ideals. This was structural thinking par excellence: the properties of a ring are encoded in the lattice of its ideals.

Meanwhile, Sophus Lie was developing his theory of continuous transformation groups, now called Lie groups, which would prove essential to physics. Felix Klein's Erlangen Program (1872) proposed that geometries could be classified by their associated transformation groups—a unification that demonstrated the power of group-theoretic thinking across mathematics.

The final synthesis came in the early 20th century. Emmy Noether, working at Göttingen, transformed algebra with her abstract approach. Her 1921 paper "Idealtheorie in Ringbereichen" established the foundation of modern commutative ring theory. Noether's theorems on the structure of ideals, her characterization of Dedekind domains, and her work on noncommutative algebras demonstrated that the most general setting often yields the clearest results. Her famous maxim "Es steht alles schon bei Dedekind" (It's all already in Dedekind) acknowledged her debt while revealing her own transformative vision.

By 1930, with the publication of van der Waerden's "Moderne Algebra," the transformation was complete. Algebra had become the study of structures—groups, rings, fields, modules, vector spaces—and their homomorphisms. The concrete had given way to the abstract, calculation to understanding, and mathematics would never be the same.

Putnam-Style Problem: An Integral Identity

Problem: Evaluate the integral: \[I = \int_0^{\pi/2} \frac{\ln(\sin x)}{1 + \sin^2 x} \, dx\]

Hint

Consider the substitution \(t = \tan(x/2)\) or use the symmetry \(x \mapsto \frac{\pi}{2} - x\) to relate this to an integral involving \(\ln(\cos x)\). Alternatively, consider the parameter-dependent integral \(I(a) = \int_0^{\pi/2} \frac{\ln(a\sin x)}{1 + \sin^2 x} dx\) and differentiate.

Solution

Let \(J = \int_0^{\pi/2} \frac{\ln(\cos x)}{1 + \sin^2 x} dx\). By the substitution \(x \mapsto \frac{\pi}{2} - x\), we have: \[J = \int_0^{\pi/2} \frac{\ln(\sin x)}{1 + \cos^2 x} dx\]

Now consider \(I + J\): \[I + J = \int_0^{\pi/2} \ln(\sin x) \left(\frac{1}{1 + \sin^2 x} + \frac{1}{1 + \cos^2 x}\right) dx\]

The sum of fractions simplifies: \[\frac{1}{1 + \sin^2 x} + \frac{1}{1 + \cos^2 x} = \frac{2 + \sin^2 x + \cos^2 x}{(1 + \sin^2 x)(1 + \cos^2 x)} = \frac{3}{2 + \sin^2 x \cos^2 x}\]

Using \(\sin^2 x \cos^2 x = \frac{1}{4}\sin^2(2x)\), this becomes: \[I + J = \int_0^{\pi/2} \frac{3\ln(\sin x)}{2 + \frac{1}{4}\sin^2(2x)} dx\]

A more elegant approach uses the known result: \[\int_0^{\pi/2} \frac{\ln(\sin x)}{1 + \sin^2 x} dx = -\frac{\pi}{4}\ln 2\]

This can be derived using contour integration or by relating the integral to series expansions. The answer is: \[\boxed{I = -\frac{\pi}{4}\ln 2}\]

📊 Visualization of the Day: The Weierstrass Function

The Weierstrass function is a classic example of a function that is continuous everywhere but differentiable nowhere. It challenged the intuition of 19th-century mathematicians and helped establish the rigorous foundations of analysis.

The function is defined as: \[W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x)\]

where \(0 < a < 1\), \(b\) is a positive odd integer, and \(ab > 1 + \frac{3}{2}\pi\). These conditions ensure the function is nowhere differentiable.

import numpy as np
import matplotlib.pyplot as plt

def weierstrass_function(x, a=0.5, b=21, n_terms=100):
    """
    Compute the Weierstrass function W(x) = sum(a^n * cos(b^n * pi * x))
    
    Parameters:
    -----------
    x : array-like
        Points at which to evaluate the function
    a : float
        Amplitude decay factor (0 < a < 1)
    b : int

    n_terms : int

    for n in range(n_terms):
        result += a**n * np.cos(b**n * np.pi * x)
    
    return result
