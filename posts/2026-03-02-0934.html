1. Spectral Theory: The Power of Eigenvalues

Motivation

Spectral theory studies the eigenvalues and eigenvectors of linear operators. It provides deep insights into the structure of operators and has applications in quantum mechanics, differential equations, and data analysis.

Definitions

Let \(H\) be a Hilbert space and \(T: H \to H\) a bounded linear operator.

  • Resolvent Set: \(\rho(T) = \{\lambda \in \mathbb{C} : (T - \lambda I)^{-1} \text{ exists and is bounded}\}\).
  • Spectrum: \(\sigma(T) = \mathbb{C} \setminus \rho(T)\).
  • Eigenvalue: \(\lambda\) is an eigenvalue if \(Tx = \lambda x\) for some non-zero \(x \in H\).
  • Point Spectrum: The set of all eigenvalues of \(T\).

Theorem: Spectral Theorem for Compact Self-Adjoint Operators

Theorem: Let \(T\) be a compact self-adjoint operator on a separable Hilbert space \(H\). Then there exists an orthonormal basis \(\{e_n\}\) of \(H\) consisting of eigenvectors of \(T\), with corresponding real eigenvalues \(\{\lambda_n\}\) such that \(\lambda_n \to 0\). Moreover:

\[Tx = \sum_{n=1}^{\infty} \lambda_n \langle x, e_n \rangle e_n\]

Proof

Step 1: Show that \(T\) has at least one eigenvalue. Since \(T\) is self-adjoint, \(\|T\| = \sup_{\|x\|=1} |\langle Tx, x \rangle|\). By compactness, this supremum is attained, yielding an eigenvector.

Step 2: Let \(H_1 = \text{span}\{e_1\}^{\perp}\). Then \(T(H_1) \subseteq H_1\), and \(T|_{H_1}\) is compact and self-adjoint. Repeat to obtain eigenvectors \(e_2, e_3, \ldots\).

Step 3: If the process terminates, \(T\) has finite rank. Otherwise, \(|\lambda_n| \to 0\) by compactness. The eigenvectors form a basis for \(\overline{\text{ran}(T)}\). ∎

Notation Guide

  • \(\sigma(T)\): Spectrum of \(T\)
  • \(\sigma_p(T)\): Point spectrum (eigenvalues)
  • \(\rho(T)\): Resolvent set
  • \(R_\lambda(T) = (T - \lambda I)^{-1}\): Resolvent operator

Python Code

import numpy as np
from scipy.linalg import eigh

def spectral_decomposition(A):
    """Compute spectral decomposition of symmetric matrix."""
    # For symmetric matrices, eigenvalues are real
    eigenvalues, eigenvectors = eigh(A)
    
    # Sort by absolute value (descending)
    idx = np.argsort(np.abs(eigenvalues))[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    return eigenvalues, eigenvectors

# Example: Compact operator approximation
n = 50
x = np.linspace(0, 1, n)
# Integral operator with kernel K(x,y) = min(x,y)
K = np.minimum.outer(x, x)
K = K / n  # Discretization

eigenvalues, eigenvectors = spectral_decomposition(K)

print(f"Top 5 eigenvalues: {eigenvalues[:5]}")
print(f"Eigenvalues decay to zero: {eigenvalues[-5:]}")

# Reconstruct operator
A_reconstructed = eigenvectors @ np.diag(eigenvalues) @ eigenvectors.T
print(f"Reconstruction error: {np.linalg.norm(K - A_reconstructed):.2e}")

2. Operator Theory: The Fredholm Alternative

Motivation

The Fredholm alternative characterizes the solvability of linear equations involving compact perturbations of the identity. It generalizes the finite-dimensional fact that a square matrix equation \(Ax = b\) has a solution if and only if \(b\) is orthogonal to the null space of \(A^*\).

Definitions

  • Fredholm Operator: A bounded operator \(T\) with finite-dimensional kernel and cokernel, and closed range.
  • Index: \(\text{ind}(T) = \dim(\ker T) - \dim(\text{coker } T)\).
  • Compact Operator: An operator mapping bounded sets to relatively compact sets.

Theorem: Fredholm Alternative

Theorem: Let \(K\) be a compact operator on a Hilbert space \(H\). Then for \(T = I - K\):

\[\text{Either: } Tx = y \text{ has a unique solution for every } y \in H,\]

\[\text{Or: } \ker T \neq \{0\}, \text{ in which case } Tx = y \text{ has a solution iff } y \perp \ker T^*.\]

Notation Guide

  • \(\ker T\): Kernel (null space) of \(T\)
  • \(\text{ran } T\): Range of \(T\)
  • \(T^*\): Adjoint of \(T\)
  • \(\mathcal{K}(H)\): Space of compact operators on \(H\)

Python Code

import numpy as np
from scipy.linalg import lu_factor, lu_solve

def fredholm_alternative_demo():
    """Demonstrate Fredholm alternative for finite-dimensional case."""
    # Create a nearly singular matrix (I - K where K is almost identity)
    n = 5
    K = 0.9 * np.eye(n) + 0.1 * np.random.randn(n, n) / n
    T = np.eye(n) - K
    
    # Check kernel
    _, s, _ = np.linalg.svd(T)
    rank = np.sum(s > 1e-10)
    kernel_dim = n - rank
    
    print(f"Matrix T = I - K")
    print(f"Singular values: {s}")
    print(f"Rank: {rank}, Kernel dimension: {kernel_dim}")
    
    # Try to solve Tx = y
    y = np.random.randn(n)
    
    if kernel_dim == 0:
        # Unique solution exists
        x = np.linalg.solve(T, y)
        residual = np.linalg.norm(T @ x - y)
        print(f"Unique solution exists. Residual: {residual:.2e}")
    else:
        # Check solvability condition
        # y must be orthogonal to kernel of T^*
        _, s_adj, Vh = np.linalg.svd(T.T)
        kernel_adj = Vh[-kernel_dim:].T
        projection = kernel_adj.T @ y
        print(f"Solvability check (should be ~0): {np.linalg.norm(projection):.2e}")

3. Harmonic Analysis: The Fourier Transform

Motivation

The Fourier transform decomposes functions into their frequency components, revealing hidden structure in signals and enabling powerful analytical techniques for differential equations.

Definitions

  • Fourier Transform: \(\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} dx\).
  • Inverse Transform: \(f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\).
  • Schwartz Space \(\mathcal{S}\): Space of rapidly decreasing smooth functions.

Theorem: Plancherel's Theorem

Theorem: The Fourier transform extends to a unitary operator on \(L^2(\mathbb{R})\). Specifically, for \(f \in L^2(\mathbb{R})\):

\[\|\hat{f}\|_{L^2} = \|f\|_{L^2}\]

Proof

First prove for \(f \in \mathcal{S}\). Let \(g(x) = \overline{\hat{f}(-x)}\). Then:

\[\|f\|_{L^2}^2 = \int f(x) \overline{f(x)} dx = \int f(x) \hat{g}(x) dx\]

By the multiplication-convolution duality:

\[= \int \hat{f}(\xi) g(\xi) d\xi = \int \hat{f}(\xi) \overline{\hat{f}(\xi)} d\xi = \|\hat{f}\|_{L^2}^2\]

Since \(\mathcal{S}\) is dense in \(L^2\), the result extends. ∎

Python Code

import numpy as np
import matplotlib.pyplot as plt

def demonstrate_plancherel():
    """Verify Plancherel's theorem numerically."""
    # Create a test function
    x = np.linspace(-10, 10, 1000)
    f = np.exp(-x**2) * np.cos(3*x)  # Gaussian modulated by cosine
    
    # Compute L2 norm in spatial domain
    dx = x[1] - x[0]
    l2_spatial = np.sqrt(np.sum(np.abs(f)**2) * dx)
    
    # Compute Fourier transform
    f_hat = np.fft.fftshift(np.fft.fft(np.fft.ifftshift(f))) * dx
    xi = np.fft.fftshift(np.fft.fftfreq(len(x), dx))
    dxi = xi[1] - xi[0]
    
    # Compute L2 norm in frequency domain
    l2_freq = np.sqrt(np.sum(np.abs(f_hat)**2) * dxi)
    
    print(f"L2 norm (spatial): {l2_spatial:.6f}")
    print(f"L2 norm (frequency): {l2_freq:.6f}")
    print(f"Relative error: {abs(l2_spatial - l2_freq) / l2_spatial:.2e}")
    
    return x, f, xi, f_hat

x, f, xi, f_hat = demonstrate_plancherel()

# Plot
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].plot(x, f)
axes[0].set_title('Spatial Domain')
axes[0].set_xlabel('x')
axes[1].plot(xi, np.abs(f_hat))
axes[1].set_title('Frequency Domain (Magnitude)')
axes[1].set_xlabel('ξ')
plt.tight_layout()
plt.savefig('fourier_plancherel.png', dpi=150)
plt.show()

1. Optimization: Convex Optimization and Duality

Motivation

Convex optimization problems have the remarkable property that any local minimum is also a global minimum. This makes them tractable both theoretically and computationally, with applications in machine learning, control, and economics.

Definitions

  • Convex Set: \(C\) is convex if \(tx + (1-t)y \in C\) for all \(x, y \in C\) and \(t \in [0,1]\).
  • Convex Function: \(f\) is convex if \(f(tx + (1-t)y) \leq tf(x) + (1-t)f(y)\).
  • Lagrangian: For constraints \(g_i(x) \leq 0\), \(h_j(x) = 0\): \(\mathcal{L}(x, \lambda, \nu) = f(x) + \sum \lambda_i g_i(x) + \sum \nu_j h_j(x)\).

Theorem: Strong Duality

Theorem: For a convex optimization problem satisfying Slater's condition (existence of a strictly feasible point):

\[p^* = d^*\]

where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Notation Guide

  • \(p^*\): Primal optimal value
  • \(d^*\): Dual optimal value
  • \(\mathcal{L}\): Lagrangian
  • \(g(\lambda, \nu) = \inf_x \mathcal{L}(x, \lambda, \nu)\): Dual function

Python Code

import numpy as np
from scipy.optimize import minimize, linprog

def convex_optimization_demo():
    """Demonstrate convex optimization with duality."""
    # Problem: minimize (x-2)^2 + (y-3)^2 subject to x + y <= 5, x >= 0, y >= 0
    
    # Objective
    def objective(x):
        return (x[0] - 2)**2 + (x[1] - 3)**2
    
    # Gradient
    def grad(x):
        return np.array([2*(x[0] - 2), 2*(x[1] - 3)])
    
    # Constraints: x + y <= 5
    cons = ({'type': 'ineq', 'fun': lambda x: 5 - x[0] - x[1]})
    bounds = [(0, None), (0, None)]
    
    # Solve
    result = minimize(objective, [0, 0], method='SLSQP', 
                     bounds=bounds, constraints=cons)
    
    print(f"Optimal solution: x = {result.x}")
    print(f"Optimal value: {result.fun:.6f}")
    
    # Compute dual variable (Lagrange multiplier for inequality)
    # At optimum: grad(f) + lambda * grad(g) = 0
    # grad(g) = [-1, -1] for constraint 5 - x - y >= 0
    lambda_dual = -grad(result.x)[0]  # From KKT conditions
    print(f"Dual variable λ ≈ {lambda_dual:.4f}")
    
    return result

result = convex_optimization_demo()

2. Machine Learning: Kernel Methods

Motivation

Kernel methods allow linear algorithms to operate in high-dimensional feature spaces without explicitly computing the coordinates of the data in that space. This "kernel trick" is fundamental to support vector machines and Gaussian processes.

Definitions

  • Kernel Function: \(k(x, y) = \langle \phi(x), \phi(y) \rangle\) for some feature map \(\phi\).
  • Positive Definite: \(k\) is positive definite if \(\sum_{i,j} c_i c_j k(x_i, x_j) \geq 0\) for all choices of \(c_i, x_i\).
  • Reproducing Kernel Hilbert Space (RKHS): A Hilbert space of functions where point evaluation is continuous.

Theorem: Mercer's Theorem

Theorem: Let \(k: [a,b] \times [a,b] \to \mathbb{R}\) be a continuous, symmetric, positive definite kernel. Then there exists an orthonormal basis \(\{\phi_n\}\) of \(L^2([a,b])\) and non-negative eigenvalues \(\{\lambda_n\}\) such that:

\[k(x, y) = \sum_{n=1}^{\infty} \lambda_n \phi_n(x) \phi_n(y)\]

where the series converges absolutely and uniformly.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from sklearn import svm

3. Probability: Large Deviations Theory

Motivation

Large deviations theory studies the exponential decay rates of probabilities of rare events. It provides precise asymptotics for tail probabilities and has applications in statistical mechanics, finance, and information theory.

Definitions

  • Cumulant Generating Function: \(\Lambda(t) = \log \mathbb{E}[e^{tX}]\).
  • Rate Function: \(\Lambda^*(x) = \sup_t (tx - \Lambda(t))\), the Legendre-Fenchel transform.
  • Large Deviation Principle: A sequence \((\mu_n)\) satisfies LDP with rate \(I\) if \(\limsup \frac{1}{n} \log \mu_n(C) \leq -\inf_C I\) for closed \(C\).

Theorem: Cramér's Theorem

Theorem: Let \(X_1, X_2, \ldots\) be i.i.d. with cumulant generating function \(\Lambda(t)\). Let \(S_n = X_1 + \cdots + X_n\). Then for any \(a > \mathbb{E}[X_1]\):

\[\lim_{n \to \infty} \frac{1}{n} \log P(S_n/n \geq a) = -\Lambda^*(a)\]

Notation Guide

  • \(\Lambda(t)\): Cumulant generating function
  • \(\Lambda^*(x)\): Rate function (Legendre transform)
  • \(S_n\): Partial sum of random variables
  • \(\mu_n\): Law of \(S_n/n\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def cramer_theorem_demo():
    """Demonstrate Cramér's theorem for Bernoulli variables."""
    # X_i ~ Bernoulli(p)
    p = 0.3
    
    # Cumulant generating function: Lambda(t) = log(pe^t + 1-p)
    def Lambda(t):
        return np.log(p * np.exp(t) + (1 - p))
    
    # Rate function: Lambda*(x) = x*log(x/p) + (1-x)*log((1-x)/(1-p))
    def rate_function(x):
        # KL divergence between Bernoulli(x) and Bernoulli(p)
        result = np.zeros_like(x)
        mask = (x > 0) & (x < 1)
        result[mask] = x[mask] * np.log(x[mask] / p) + \
                      (1 - x[mask]) * np.log((1 - x[mask]) / (1 - p))
        return result
    
    # Simulate and estimate tail probabilities
    n_values = [10, 50, 100, 500]
    a = 0.5  # Threshold (greater than mean p=0.3)
    
    fig, axes = plt.subplots(1, 2, figsize=(12, 4))
    
    # Plot rate function
    x = np.linspace(0.01, 0.99, 100)
    axes[0].plot(x, rate_function(x), 'b-', linewidth=2)
    axes[0].axvline(p, color='r', linestyle='--', label=f'Mean = {p}')
    axes[0].axvline(a, color='g', linestyle='--', label=f'Threshold = {a}')
    axes[0].set_xlabel('x')
    axes[0].set_ylabel('Λ*(x)')
    axes[0].set_title('Rate Function')
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)
    
    # Verify Cramér's theorem
    n_list = []
    empirical_rates = []
    theoretical_rate = rate_function(np.array([a]))[0]
    
    for n in n_values:
        # Monte Carlo estimate
        n_samples = 100000
        samples = np.random.binomial(n, p, n_samples) / n
        prob = np.mean(samples >= a)
        empirical_rate = -np.log(prob) / n if prob > 0 else np.inf
        
        n_list.append(n)
        empirical_rates.append(empirical_rate)
        print(f"n={n:4d}: Empirical rate = {empirical_rate:.4f}, "
              f"Theoretical = {theoretical_rate:.4f}")
    
    axes[1].plot(n_list, empirical_rates, 'bo-', label='Empirical')
    axes[1].axhline(theoretical_rate, color='r', linestyle='--', 
                   label=f'Theoretical: {theoretical_rate:.4f}')
    axes[1].set_xlabel('n')
    axes[1].set_ylabel('-log(P)/n')
    axes[1].set_title("Cramér's Theorem Verification")
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('large_deviations.png', dpi=150)
    plt.show()

1. Abel's Theorem on Power Series

Motivation

Abel's theorem addresses a subtle question: if a power series converges at the boundary of its disk of convergence, what can we say about the behavior of the function there? This result has profound implications for analytic continuation.

Definitions

  • Power Series: \(\sum_{n=0}^{\infty} a_n z^n\) with radius of convergence \(R\).
  • Abel Summation: A method to assign values to divergent series.
  • Stolz Sector: A region approaching a boundary point non-tangentially.

Theorem: Abel's Limit Theorem

Theorem: If \(\sum_{n=0}^{\infty} a_n\) converges to \(S\), then:

\[\lim_{x \to 1^-} \sum_{n=0}^{\infty} a_n x^n = S\]

Proof

Let \(s_n = \sum_{k=0}^{n} a_k\) and \(f(x) = \sum a_n x^n\). By summation by parts:

\[f(x) = (1-x) \sum_{n=0}^{\infty} s_n x^n\]

Given \(\epsilon > 0\), choose \(N\) such that \(|s_n - S| < \epsilon\) for \(n \geq N\). Split:

\[f(x) - S = (1-x)\sum_{n=0}^{N-1}(s_n-S)x^n + (1-x)\sum_{n=N}^{\infty}(s_n-S)x^n\]

The first term \(\to 0\) as \(x \to 1^-\). The second is bounded by \(\epsilon\). ∎

Python Code

import numpy as np
import matplotlib.pyplot as plt

def abel_theorem_demo():
    """Demonstrate Abel's theorem with alternating harmonic series."""
    # Series: sum (-1)^(n+1)/n = log(2)
    # Power series: f(x) = sum (-1)^(n+1) x^n / n = log(1+x)
    
    def f(x, N=1000):
        """Partial sum of power series."""
        n = np.arange(1, N+1)
        return np.sum((-1)**(n+1) * x**n / n)
    
    # True value
    S = np.log(2)
    print(f"Series sum: log(2) = {S:.10f}")
    
    # Evaluate f(x) as x approaches 1 from below
    x_vals = np.linspace(0, 0.999, 100)
    f_vals = [f(x) for x in x_vals]
    
    plt.figure(figsize=(10, 6))
    plt.plot(x_vals, f_vals, 'b-', linewidth=2, label='f(x) = Σ(-1)^(n+1)x^n/n')
    plt.axhline(S, color='r', linestyle='--', label=f'log(2) = {S:.6f}')
    plt.xlabel('x')
    plt.ylabel('f(x)')
    plt.title("Abel's Theorem: lim_{x→1^-} f(x) = Σ(-1)^(n+1)/n")
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.xlim([0, 1])
    plt.savefig('abel_theorem.png', dpi=150)
    plt.show()
    
    print(f"f(0.99) = {f(0.99):.10f}")

2. Galois Theory: The Insolvability of the Quintic

Motivation

Galois theory provides a profound connection between field extensions and group theory. Its most famous application is proving that there is no general formula for solving polynomial equations of degree 5 or higher using radicals.

Definitions

  • Galois Group: \(\text{Gal}(L/K)\) is the group of field automorphisms of \(L\) fixing \(K\).
  • Solvable Group: A group with a chain of subgroups where each quotient is abelian.
  • Radical Extension: Obtained by adjoining \(n\)-th roots.

Theorem: Abel-Ruffini Theorem

Theorem: The general polynomial equation of degree \(n \geq 5\) is not solvable by radicals.

Proof Sketch

Step 1: The Galois group of the general degree-\(n\) polynomial is \(S_n\).

Step 2: For \(n \geq 5\), \(S_n\) is not solvable (the alternating group \(A_n\) is simple and non-abelian).

Step 3: A polynomial is solvable by radicals iff its Galois group is solvable.

Conclusion: The general quintic has Galois group \(S_5\), which is not solvable. ∎

Python Code

import numpy as np
from itertools import permutations

def galois_demo():
    """Demonstrate properties of symmetric groups relevant to Galois theory."""
    # S_3 is solvable (can solve cubic)
    # S_5 is not solvable (cannot solve general quintic)
    
    def alternating_group(n):
        """Generate alternating group A_n (even permutations)."""
        elements = list(permutations(range(n)))
        def sign(p):
            # Compute sign of permutation
            inversions = sum(1 for i in range(n) for j in range(i+1, n) 
                           if p[i] > p[j])
            return 1 if inversions % 2 == 0 else -1
        return [p for p in elements if sign(p) == 1]
    
    for n in [3, 4, 5]:
        A_n = alternating_group(n)
        S_n_size = np.math.factorial(n)
        A_n_size = len(A_n)
        
        print(f"n = {n}:")
        print(f"  |S_{n}| = {S_n_size}")
        print(f"  |A_{n}| = {A_n_size}")
        print(f"  A_{n} is simple: {n >= 5}")
        print(f"  S_{n} is solvable: {n < 5}")
        print()
    
    # Demonstrate that quintic has no radical solution
    print("Consequence: The general polynomial of degree n ≥ 5")
    print("cannot be solved by radicals because S_n is not solvable.")

3. Fourier Analysis: The Uncertainty Principle

Motivation

The Heisenberg uncertainty principle in quantum mechanics has a mathematical counterpart in Fourier analysis: a function and its Fourier transform cannot both be sharply localized. This fundamental limit has implications in signal processing and quantum mechanics.

Definitions

  • Variance: \(\sigma_f^2 = \int x^2 |f(x)|^2 dx - \left(\int x |f(x)|^2 dx\right)^2\).
  • Fourier Transform: \(\hat{f}(\xi) = \int f(x) e^{-2\pi i x \xi} dx\).

Theorem: Heisenberg Uncertainty Principle

Theorem: For \(f \in L^2(\mathbb{R})\) with \(\|f\|_{L^2} = 1\):

\[\sigma_f^2 \cdot \sigma_{\hat{f}}^2 \geq \frac{1}{16\pi^2}\]

Equality holds for Gaussian functions.

Proof

Assume \(\int x |f(x)|^2 dx = 0\) and \(\int \xi |\hat{f}(\xi)|^2 d\xi = 0\) (centered).

By the Cauchy-Schwarz inequality:

\[\left|\int x f(x) \overline{f'(x)} dx\right|^2 \leq \int x^2 |f(x)|^2 dx \cdot \int |f'(x)|^2 dx\]

Integration by parts gives \(\int x f \overline{f'} = -\frac{1}{2}\|f\|_{L^2}^2\).

By Plancherel: \(\|f'\|_{L^2} = 2\pi \|\xi \hat{f}\|_{L^2}\).

Combining: \(\frac{1}{4} \leq \sigma_f^2 \cdot 4\pi^2 \sigma_{\hat{f}}^2\). ∎

def uncertainty_principle_demo():

        # Normalize
        norm = np.sqrt(np.sum(np.abs(f)**2) * dx)
        f = f / norm

        mean_x = np.sum(x * np.abs(f)**2) * dx
        var_x = np.sum((x - mean_x)**2 * np.abs(f)**2) * dx

        f_hat = np.fft.fftshift(np.fft.fft(np.fft.ifftshift(f))) * dx
        xi = np.fft.fftshift(np.fft.fftfreq(len(x), dx))
        dxi = xi[1] - xi[0]
        
        # Normalize Fourier transform
        norm_f_hat = np.sqrt(np.sum(np.abs(f_hat)**2) * dxi)
        f_hat = f_hat / norm_f_hat
        
        # Variance in frequency domain
        mean_xi = np.sum(xi * np.abs(f_hat)**2) * dxi
        var_xi = np.sum((xi - mean_xi)**2 * np.abs(f_hat)**2) * dxi
        
        return var_x, var_xi, var_x * var_xi, f_hat, xi
    
    # Test functions

4. The Legacy of Srinivasa Ramanujan

Historical Context

Srinivasa Ramanujan (1887–1920) was an Indian mathematician who, with almost no formal training, made extraordinary contributions to number theory, infinite series, and continued fractions. His collaboration with G.H. Hardy at Cambridge produced some of the most remarkable results in 20th-century mathematics.

Ramanujan's Master Theorem

Theorem: If \(f(x) = \sum_{k=0}^{\infty} \frac{\phi(k)}{k!}(-x)^k\) for some function \(\phi\) satisfying certain conditions, then:

\[\int_0^{\infty} x^{s-1} f(x) dx = \Gamma(s) \phi(-s)\]

The Rogers-Ramanujan Identities

Identity 1:

\[\sum_{n=0}^{\infty} \frac{q^{n^2}}{(1-q)(1-q^2)\cdots(1-q^n)} = \prod_{n=0}^{\infty} \frac{1}{(1-q^{5n+1})(1-q^{5n+4})}\]

Identity 2:

\[\sum_{n=0}^{\infty} \frac{q^{n(n+1)}}{(1-q)(1-q^2)\cdots(1-q^n)} = \prod_{n=0}^{\infty} \frac{1}{(1-q^{5n+2})(1-q^{5n+3})}\]

📜 Math History

The Birth of Modern Algebra: From Cardano to Galois

The story of algebra's transformation from a collection of problem-solving techniques to a sophisticated abstract theory spans nearly four centuries. In 1545, Gerolamo Cardano published "Ars Magna," presenting solutions to cubic and quartic equations—achievements attributed to Scipione del Ferro, Niccolò Tartaglia, and Lodovico Ferrari. These formulas, expressed in radical form, seemed to promise that similar solutions might exist for equations of any degree.

The quest for a quintic formula occupied mathematicians for nearly three centuries. Joseph-Louis Lagrange, in his 1770 treatise, analyzed the structure of resolvent equations and introduced the concept of permutations of roots—a crucial step toward group theory. Paolo Ruffini, in 1799, made the first serious attempt to prove the impossibility of solving the general quintic by radicals, though his proof had gaps.

Niels Henrik Abel, a Norwegian mathematician who died at age 26, provided the first complete proof of the insolvability of the quintic in 1824. Abel's proof established that no general formula exists, but it did not fully characterize which specific equations could be solved. This deeper understanding came from Évariste Galois, who, in his brief life (1811–1832), created a theory that connected field extensions to group theory in a profound way.

Galois's key insight was to associate to each polynomial equation a group of permutations of its roots—the Galois group. He proved that an equation is solvable by radicals if and only if its Galois group is solvable—a concept he defined. The symmetric group \(S_5\), which is the Galois group of the general quintic, is not solvable, explaining why no general formula exists.

Galois wrote down his theory the night before his fatal duel in 1832. His manuscripts, initially rejected as incomprehensible, were eventually published by Joseph Liouville in 1846. The theory revolutionized algebra, shifting focus from finding solutions to understanding structure. By the end of the 19th century, the abstract concepts of groups, rings, and fields had become central to mathematics, establishing the foundation for modern algebra.

🎯 Problem Corner

Putnam-Style Problem: A Series Evaluation

Problem: Evaluate the sum:

\[\sum_{n=1}^{\infty} \frac{1}{n^2 + n}\]

Click for Hint

Use partial fraction decomposition: \(\frac{1}{n^2+n} = \frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}\). This creates a telescoping series.

Click for Solution

Solution: We decompose:

\[\frac{1}{n^2+n} = \frac{1}{n(n+1)} = \frac{A}{n} + \frac{B}{n+1}\]

Solving: \(1 = A(n+1) + Bn = (A+B)n + A\), so \(A = 1\) and \(B = -1\).

Therefore:

\[\sum_{n=1}^{\infty} \frac{1}{n^2+n} = \sum_{n=1}^{\infty}\left(\frac{1}{n} - \frac{1}{n+1}\right)\]

The partial sum is:

\[S_N = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{N} - \frac{1}{N+1}\right) = 1 - \frac{1}{N+1}\]

Taking the limit:

\[\sum_{n=1}^{\infty} \frac{1}{n^2+n} = \lim_{N \to \infty} S_N = 1\]

∎

The Weierstrass Function: Continuous Everywhere, Differentiable Nowhere

The Weierstrass function is a classic counterexample in analysis. It is continuous everywhere but differentiable nowhere—a function that challenged the intuition of mathematicians in the 19th century who believed continuous functions must be smooth "almost everywhere."

The function is defined as:

\[W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x)\]

where \(0 < a < 1\), \(b\) is a positive odd integer, and \(ab > 1 + \frac{3}{2}\pi\).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def weierstrass_function(x, a=0.5, b=15, N=50):
    """
    Compute the Weierstrass function.
    
    Parameters:
    -----------
    x : array-like
        Input values
    a : float
        Amplitude decay (0 < a < 1)
    b : int
        Frequency multiplier (odd integer)
    N : int
        Number of terms in series
    """
    result = np.zeros_like(x)
    for n in range(N):
        result += a**n * np.cos(b**n * np.pi * x)
    return result
