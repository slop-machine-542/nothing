1. Symplectic Geometry: The Geometry of Hamiltonian Mechanics

Motivation: Classical mechanics can be formulated in two equivalent ways: Newton's force-based approach and the variational principles of Lagrange and Hamilton. The Hamiltonian formulation reveals a deep geometric structure—symplectic geometry—that underlies all of classical mechanics. This geometry, characterized by a closed non-degenerate 2-form, provides the natural language for mechanics and has profound connections to quantum physics, representation theory, and low-dimensional topology.

Definitions:

  • A symplectic vector space is a pair \((V, \omega)\) where \(V\) is a vector space and \(\omega: V \times V \to \mathbb{R}\) is a bilinear form that is skew-symmetric (\(\omega(v,w) = -\omega(w,v)\)) and non-degenerate (if \(\omega(v,w) = 0\) for all \(w\), then \(v = 0\))
  • A symplectic manifold \((M, \omega)\) is a smooth manifold \(M\) with a closed, non-degenerate 2-form \(\omega\) (i.e., \(d\omega = 0\))
  • The Hamiltonian vector field \(X_H\) for a function \(H: M \to \mathbb{R}\) is defined by \(\iota_{X_H}\omega = dH\), or equivalently \(\omega(X_H, Y) = dH(Y)\) for all vector fields \(Y\)
  • The Poisson bracket of two functions is \(\{f, g\} = \omega(X_f, X_g) = df(X_g)\)

Theorem (Darboux): Let \((M, \omega)\) be a symplectic manifold of dimension \(2n\). For any point \(p \in M\), there exist local coordinates \((q_1, \ldots, q_n, p_1, \ldots, p_n)\) called Darboux coordinates such that: \[\omega = \sum_{i=1}^n dq_i \wedge dp_i\] In these coordinates, the Hamiltonian equations take the canonical form: \[\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}\]

Proof: The proof proceeds by induction using Moser's trick. First, one shows that any symplectic form can be put in standard form at a single point by linear algebra. Then, working in a neighborhood, one constructs a vector field whose flow pulls back the given symplectic form to the standard form. The key is the Poincaré lemma: since \(\omega\) is closed, locally \(\omega = d\theta\) for some 1-form \(\theta\). The Moser flow is generated by a vector field \(X_t\) satisfying \(\iota_{X_t}\omega_t = \theta_0 - \theta_1\) where \(\omega_t = (1-t)\omega_0 + t\omega_1\). The non-degeneracy of \(\omega\) ensures \(X_t\) exists and the flow provides the required coordinate change. \(\square\)

Notation Guide:

  • \(\omega\) — Symplectic form (closed, non-degenerate 2-form)
  • \(X_H\) — Hamiltonian vector field generated by \(H\)
  • \(\iota_X\omega\) — Interior product (contraction of \(\omega\) with \(X\))
  • \(\{f, g\}\) — Poisson bracket
  • \(T^*Q\) — Cotangent bundle (canonical symplectic manifold)
  • \(Sp(2n, \mathbb{R})\) — Symplectic group
# Symplectic Geometry: Hamiltonian Mechanics
import numpy as np
from scipy.integrate import odeint

class SymplecticManifold:
    """
    Symplectic manifold with canonical coordinates (q, p).
    omega = sum(dq_i ∧ dp_i)
    """
    
    def __init__(self, n_dof):
        """
        n_dof: number of degrees of freedom
        """
        self.n = n_dof
        # Standard symplectic matrix J = [[0, I], [-I, 0]]
        self.J = np.block([
            [np.zeros((n_dof, n_dof)), np.eye(n_dof)],
            [-np.eye(n_dof), np.zeros((n_dof, n_dof))]
        ])
    
    def hamiltonian_vector_field(self, H_func, state):
        """
        Compute Hamiltonian vector field X_H at state (q, p).
        X_H = J · ∇H
        """
        q, p = state[:self.n], state[self.n:]
        
        # Numerical gradient of H
        eps = 1e-8
        grad_H = np.zeros(2 * self.n)
        
        for i in range(2 * self.n):
            state_plus = state.copy()
            state_plus[i] += eps
            state_minus = state.copy()
            state_minus[i] -= eps
            grad_H[i] = (H_func(state_plus) - H_func(state_minus)) / (2 * eps)
        
        return self.J @ grad_H
    
    def poisson_bracket(self, f_func, g_func, state):
        """
        Compute {f, g} = ω(X_f, X_g) = df(X_g)
        """
        X_f = self.hamiltonian_vector_field(f_func, state)
        X_g = self.hamiltonian_vector_field(g_func, state)
        
        # {f, g} = sum(df/dq_i · dg/dp_i - df/dp_i · dg/dq_i)
        df = np.zeros(2 * self.n)
        dg = np.zeros(2 * self.n)
        eps = 1e-8
        
        for i in range(2 * self.n):
            s_plus = state.copy()
            s_plus[i] += eps
            s_minus = state.copy()
            s_minus[i] -= eps
            df[i] = (f_func(s_plus) - f_func(s_minus)) / (2 * eps)
            dg[i] = (g_func(s_plus) - g_func(s_minus)) / (2 * eps)
        
        return df @ self.J @ dg

2. Lie Theory: Symmetries and Their Algebras

Motivation: Symmetry is one of the most powerful organizing principles in mathematics and physics. Lie theory provides the mathematical framework for continuous symmetries—those that can be built up from infinitesimal transformations. From the rotation groups of classical mechanics to the gauge symmetries of the Standard Model, Lie groups and their associated Lie algebras encode the structure of continuous symmetries in a way that connects algebra, geometry, and analysis.

Definitions:

  • A Lie group \(G\) is a smooth manifold that is also a group, where the group operations (multiplication and inversion) are smooth maps
  • The Lie algebra \(\mathfrak{g}\) of a Lie group \(G\) is the tangent space at the identity, equipped with the Lie bracket \([X, Y]\) defined via the commutator of left-invariant vector fields
  • The exponential map \(\exp: \mathfrak{g} \to G\) sends a Lie algebra element to the time-1 flow of the corresponding left-invariant vector field
  • The adjoint representation \(\text{Ad}: G \to GL(\mathfrak{g})\) is defined by \(\text{Ad}_g(X) = gXg^{-1}\) (for matrix groups)

Theorem (Lie Group-Lie Algebra Correspondence): There is a one-to-one correspondence between:

  1. Finite-dimensional real Lie algebras \(\mathfrak{g}\)
  2. Simply connected Lie groups \(G\)
Given a Lie algebra \(\mathfrak{g}\), there exists a unique (up to isomorphism) simply connected Lie group \(G\) with \(\text{Lie}(G) = \mathfrak{g}\). For any Lie group \(H\) with \(\text{Lie}(H) = \mathfrak{g}\), there is a covering map \(G \to H\).

Proof Sketch: The proof uses Ado's theorem (every finite-dimensional Lie algebra has a faithful finite-dimensional representation) to embed \(\mathfrak{g}\) into \(\mathfrak{gl}(n, \mathbb{R})\). The exponential map then generates a subgroup of \(GL(n, \mathbb{R})\) whose Lie algebra is \(\mathfrak{g}\). The simply connected cover of this group gives the desired \(G\). The uniqueness follows from the fact that any homomorphism of Lie algebras lifts uniquely to a homomorphism of the corresponding simply connected Lie groups. \(\square\)

Notation Guide:

  • \(\mathfrak{g}\) — Lie algebra of Lie group \(G\)
  • \([X, Y]\) — Lie bracket
  • \(\exp(X)\) — Exponential map
  • \(\text{ad}_X(Y) = [X, Y]\) — Adjoint action of Lie algebra
  • \(\text{Ad}_g\) — Adjoint action of Lie group
  • \(\mathfrak{so}(n), \mathfrak{su}(n), \mathfrak{sl}(n)\) — Classical Lie algebras
# Lie Theory: SO(3) and so(3)
import numpy as np

class LieAlgebra_so3:
    """
    The Lie algebra so(3) of skew-symmetric 3x3 matrices.
    so(3) ≅ (R³, ×) with [X, Y] = X × Y (cross product)
    """
    
    # Basis elements as 3x3 matrices
    L1 = np.array([[0, 0, 0], [0, 0, -1], [0, 1, 0]])   # Rotation about x
    L2 = np.array([[0, 0, 1], [0, 0, 0], [-1, 0, 0]])   # Rotation about y
    L3 = np.array([[0, -1, 0], [1, 0, 0], [0, 0, 0]])   # Rotation about z
    basis = [L1, L2, L3]
    
    @staticmethod
    def vector_to_matrix(v):
        """Convert vector v = (v1, v2, v3) to skew-symmetric matrix."""
        v1, v2, v3 = v
        return np.array([
            [0, -v3, v2],
            [v3, 0, -v1],
            [-v2, v1, 0]
        ])
    
    @staticmethod
    def matrix_to_vector(M):
        """Convert skew-symmetric matrix to vector."""
        return np.array([M[2, 1], M[0, 2], M[1, 0]])
    
    @staticmethod
    def lie_bracket(X, Y):
        """Lie bracket [X, Y] = XY - YX."""
        return X @ Y - Y @ X
    
    @staticmethod
    def cross_product_bracket(v, w):
        """so(3) bracket as cross product: [v, w] = v × w."""
        return np.cross(v, w)

class LieGroup_SO3:
    """
    The Lie group SO(3) of proper rotation matrices.
    """
    
    @staticmethod
    def exp_so3(omega):
        """
        Exponential map from so(3) to SO(3).
        Rodrigues' rotation formula:
        exp([ω]) = I + sin(|ω|)/|ω| · [ω] + (1-cos(|ω|))/|ω|² · [ω]²
        """
        theta = np.linalg.norm(omega)
        if theta < 1e-10:
            return np.eye(3)
        
        omega_hat = LieAlgebra_so3.vector_to_matrix(omega)
        omega_hat_squared = omega_hat @ omega_hat
        
        R = (np.eye(3) + 
             np.sin(theta) / theta * omega_hat + 
             (1 - np.cos(theta)) / (theta**2) * omega_hat_squared)
        return R
    
    @staticmethod
    def log_SO3(R):
        """
        Logarithm map from SO(3) to so(3).
        Inverse of exponential map.
        """
        # Check trace condition
        trace = np.trace(R)
        if trace >= 3 - 1e-10:
            return np.zeros(3)
        
        if trace <= -1 + 1e-10:
            # Special case: rotation by π
            # Find axis from symmetric part
            for i in range(3):
                if R[i, i] > -1 + 1e-10:
                    axis = np.array([R[0, i], R[1, i], R[2, i]])
                    axis[i] += 1
                    axis = axis / np.linalg.norm(axis)
                    return np.pi * axis
        
        # General case
        theta = np.arccos((trace - 1) / 2)
        omega_hat = (theta / (2 * np.sin(theta))) * (R - R.T)
        return LieAlgebra_so3.matrix_to_vector(omega_hat)
    
    @staticmethod
    def is_rotation_matrix(R, tol=1e-10):
        """Check if R is a valid rotation matrix."""
        orthogonality = np.allclose(R @ R.T, np.eye(3), atol=tol)
        determinant = np.abs(np.linalg.det(R) - 1) < tol
        return orthogonality and determinant

3. Algebraic Combinatorics: Symmetric Functions and Young Tableaux

Motivation: The theory of symmetric functions connects representation theory, algebraic geometry, and combinatorics in remarkable ways. Young tableaux, seemingly simple arrangements of numbers in boxes, encode deep information about the symmetric group, general linear groups, and the geometry of Grassmannians. This interplay between combinatorial objects and algebraic structures has become one of the most vibrant areas of modern mathematics.

Definitions:

  • A partition \(\lambda = (\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_k > 0)\) of \(n\) is a weakly decreasing sequence of positive integers summing to \(n\)
  • A Young diagram is a left-justified array of boxes with \(\lambda_i\) boxes in row \(i\)
  • A Young tableau of shape \(\lambda\) is a filling of the Young diagram with positive integers. It is standard if entries are \(1, \ldots, n\) each used once, increasing along rows and down columns
  • The Schur function \(s_\lambda(x_1, \ldots, x_n)\) is defined by: \[s_\lambda = \sum_T x^T\] where the sum is over all semistandard tableaux of shape \(\lambda\) and \(x^T = \prod_i x_i^{\text{(number of i's in T)}}\)

Theorem (Hook Length Formula): The number of standard Young tableaux of shape \(\lambda\) is: \[f^\lambda = \frac{n!}{\prod_{\text{boxes } b} h(b)}\] where \(h(b)\) is the hook length of box \(b\) (number of boxes to the right in the same row, plus boxes below in the same column, plus 1 for the box itself).

Proof: The original proof by Frame, Robinson, and Thrall uses a probabilistic argument. Consider a random filling of the diagram with \(1, \ldots, n\). The probability that it is a standard tableau can be computed in two ways. Alternatively, one can use the representation theory of the symmetric group: \(f^\lambda\) is the dimension of the irreducible representation \(V_\lambda\), and the hook length formula follows from the Weyl dimension formula for \(S_n\). A beautiful bijective proof was given by Novelli, Pak, and Stoyanovskii using the jeu de taquin. \(\square\)

Notation Guide:

  • \(\lambda \vdash n\) — \(\lambda\) is a partition of \(n\)
  • \(|\lambda| = n\) — Size of partition
  • \(\lambda'\) — Conjugate partition (transpose diagram)
  • \(s_\lambda\) — Schur function
  • \(f^\lambda\) — Number of standard Young tableaux of shape \(\lambda\)
  • \(h(b)\) — Hook length of box \(b\)
# Algebraic Combinatorics: Young Tableaux and Symmetric Functions
from functools import lru_cache
from math import factorial
import numpy as np

class Partition:
    """Represents a partition of an integer."""
    
    def __init__(self, parts):
        """
        parts: list of parts in weakly decreasing order
        """
        self.parts = tuple(sorted(parts, reverse=True))
        self.n = sum(self.parts)
    
    def __repr__(self):
        return f"Partition({list(self.parts)})"
    
    def diagram(self):
        """Print ASCII representation of Young diagram."""
        for row_len in self.parts:
            print("□ " * row_len)
    
    def conjugate(self):
        """Conjugate (transpose) partition."""
        if not self.parts:
            return Partition([])
        # Number of parts in conjugate = size of first part
        conj_parts = []
        for i in range(self.parts[0]):
            # Count parts >= i+1
            count = sum(1 for p in self.parts if p >= i + 1)
            if count > 0:
                conj_parts.append(count)
        return Partition(conj_parts)
    
    def hook_lengths(self):
        """
        Compute hook lengths for all boxes.
        Returns list of lists with same shape as diagram.
        """
        hooks = []
        for i, row_len in enumerate(self.parts):
            row_hooks = []
            for j in range(row_len):
                # Hook length = boxes to right + boxes below + 1
                right = row_len - j - 1
                below = sum(1 for p in self.parts[i+1:] if p > j)
                row_hooks.append(right + below + 1)
            hooks.append(row_hooks)
        return hooks
    
    def hook_length_formula(self):
        """
        Compute number of standard Young tableaux using hook length formula.
        f^λ = n! / ∏ hook lengths
        """
        hooks = self.hook_lengths()
        product = 1
        for row in hooks:
            for h in row:
                product *= h
        return factorial(self.n) // product

class YoungTableau:
    """Represents a Young tableau (filling of Young diagram)."""
    
    def __init__(self, shape, filling):
        """
        shape: Partition object
        filling: list of lists with the filling
        """
        self.shape = shape
        self.filling = filling
    
    def is_standard(self):
        """Check if tableau is standard (1..n, increasing rows and columns)."""
        n = self.shape.n
        entries = []
        
        # Check row and column increasing
        for i, row in enumerate(self.filling):
            for j, val in enumerate(row):
                entries.append(val)
                # Check row increasing
                if j > 0 and row[j-1] >= val:
                    return False
                # Check column increasing
                if i > 0 and j < len(self.filling[i-1]) and self.filling[i-1][j] >= val:
                    return False
        
        # Check all entries 1..n appear exactly once
        return sorted(entries) == list(range(1, n+1))
    
    def __repr__(self):
        lines = []
        for row in self.filling:
            lines.append(" ".join(f"{x:2d}" for x in row))
        return "\n".join(lines)

def generate_standard_tableaux(shape):
    """
    Generate all standard Young tableaux of given shape.
    Backtracking algorithm.
    """
    n = shape.n
    parts = list(shape.parts)
    
    # Initialize empty diagram
    diagram = [[None] * p for p in parts]
    
    def is_valid_partial():
        """Check if current partial filling is valid."""
        for i, row in enumerate(diagram):
            for j, val in enumerate(row):
                if val is None:
                    continue
                # Check row
                if j > 0 and row[j-1] is not None and row[j-1] >= val:
                    return False
                # Check column
                if i > 0 and j < len(diagram[i-1]) and diagram[i-1][j] is not None and diagram[i-1][j] >= val:
                    return False
        return True
    
    tableaux = []
    
    def backtrack(k):
        if k > n:
            # Make a copy and add to results
            tableaux.append(YoungTableau(shape, [row[:] for row in diagram]))
            return
        
        # Try placing k in each valid position
        for i, row in enumerate(diagram):
            for j in range(len(row)):
                if row[j] is None:
                    row[j] = k
                    if is_valid_partial():
                        backtrack(k + 1)
                    row[j] = None
    
    backtrack(1)
    return tableaux

def schur_function_monomial(shape, variables):
    """
    Compute Schur function s_λ(x₁, ..., xₙ) as sum over semistandard tableaux.
    For demonstration, we compute a single monomial contribution.
    """
    # A semistandard tableau allows repeats, strictly increasing down columns
    # weakly increasing across rows
    n = len(variables)
    
    # For small shapes, enumerate semistandard tableaux
    # This is a simplified version
    parts = list(shape.parts)
    
    def generate_semistandard(max_val):
        """Generate semistandard tableaux with entries ≤ max_val."""
        diagram = [[None] * p for p in parts]
        
        def is_valid_partial():
            for i, row in enumerate(diagram):
                for j, val in enumerate(row):
                    if val is None:
                        continue
                    # Weakly increasing along rows
                    if j > 0 and row[j-1] is not None and row[j-1] > val:
                        return False
                    # Strictly increasing down columns
                    if i > 0 and j < len(diagram[i-1]) and diagram[i-1][j] is not None and diagram[i-1][j] >= val:
                        return False
            return True
        
        tableaux = []
        
        def backtrack(pos):
            if pos == sum(parts):
                tableaux.append([row[:] for row in diagram])
                return
            
            # Find next empty position
            for i, row in enumerate(diagram):
                for j in range(len(row)):
                    if row[j] is None:
                        # Determine valid range for this position
                        min_val = 1
                        if j > 0 and row[j-1] is not None:
                            min_val = row[j-1]
                        if i > 0 and j < len(diagram[i-1]) and diagram[i-1][j] is not None:
                            min_val = max(min_val, diagram[i-1][j] + 1)
                        
                        for val in range(min_val, max_val + 1):
                            row[j] = val
                            if is_valid_partial():
                                backtrack(pos + 1)
                            row[j] = None
                        return
        
        backtrack(0)
        return tableaux
    
    ss_tableaux = generate_semistandard(len(variables))
    
    # Compute sum of monomials
    result = {}
    for t in ss_tableaux:
        # Count occurrences of each number
        counts = {}
        for row in t:
            for val in row:
                counts[val] = counts.get(val, 0) + 1
        
        # Form monomial
        monomial = tuple(counts.get(i+1, 0) for i in range(len(variables)))
        result[monomial] = result.get(monomial, 0) + 1
    
    return result

1. Information Theory: Entropy and Channel Capacity

Real-World Motivation: In the digital age, information is the fundamental currency of communication. Claude Shannon's information theory, developed in 1948, provides the mathematical foundation for understanding how information can be efficiently encoded, transmitted, and decoded. From compression algorithms (ZIP, JPEG) to error-correcting codes (used in satellites and QR codes) to the design of communication networks, information theory has become indispensable to modern technology.

Definitions:

  • The entropy of a discrete random variable \(X\) with probability mass function \(p(x)\) is: \[H(X) = -\sum_{x} p(x) \log_2 p(x)\] measured in bits. It represents the average uncertainty or information content.
  • The joint entropy \(H(X,Y)\) and conditional entropy \(H(Y|X)\) are defined similarly using joint and conditional distributions
  • Mutual information \(I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)\) measures the information shared between two variables
  • The channel capacity of a communication channel is \(C = \max_{p(x)} I(X;Y)\), the maximum mutual information over input distributions

Theorem (Shannon's Channel Coding Theorem): For a discrete memoryless channel with capacity \(C\), any rate \(R < C\) is achievable: for any \(\epsilon > 0\) and sufficiently large \(n\), there exists a code with \(2^{nR}\) codewords of length \(n\) such that the probability of decoding error is less than \(\epsilon\). Conversely, if \(R > C\), the error probability is bounded away from zero.

Proof Sketch: The proof uses random coding. Generate \(2^{nR}\) codewords independently according to the capacity-achieving distribution \(p(x)\). For decoding, use joint typicality: decode received sequence \(y^n\) to the unique codeword \(x^n\) such that \((x^n, y^n)\) is jointly typical. The asymptotic equipartition property ensures that typical sequences have probability approaching 1. The probability of error vanishes because at rates below capacity, the number of codewords grows slower than the number of distinguishable channel outputs. \(\square\)

Notation Guide:

  • \(H(X)\) — Shannon entropy (in bits if log base 2)
  • \(H(X|Y)\) — Conditional entropy
  • \(I(X;Y)\) — Mutual information
  • \(D(p \| q)\) — Kullback-Leibler divergence (relative entropy)
  • \(C\) — Channel capacity
  • \(A_\epsilon^{(n)}\) — Set of jointly typical sequences

import numpy as np
from scipy.stats import entropy as scipy_entropy

class InformationTheory:
    """Information theory computations."""
    
    @staticmethod
    def entropy(p, base=2):
        """
        Compute Shannon entropy H(X) = -Σ p(x) log p(x).
        
        Parameters:
        -----------
        p : array-like
            Probability distribution (should sum to 1)
        base : int
            Logarithm base (2 for bits, e for nats)
        """
        p = np.array(p)
        p = p[p > 0]  # Remove zeros
        if base == 2:
            return -np.sum(p * np.log2(p))
        elif base == np.e:
            return -np.sum(p * np.log(p))
        else:
            return -np.sum(p * np.log(p) / np.log(base))
    
    @staticmethod
    def joint_entropy(p_xy):
        """
        Compute joint entropy H(X,Y) from joint distribution.
        p_xy should be a 2D array where p_xy[i,j] = P(X=i, Y=j)
        """
        p_xy = np.array(p_xy)
        p_xy = p_xy[p_xy > 0]
        return -np.sum(p_xy * np.log2(p_xy))
    
    @staticmethod
    def conditional_entropy(p_xy):
        """
        Compute H(Y|X) from joint distribution p(x,y).
        H(Y|X) = H(X,Y) - H(X)
        """
        p_xy = np.array(p_xy)
        p_x = np.sum(p_xy, axis=1)  # Marginal of X
        H_XY = InformationTheory.joint_entropy(p_xy)
        H_X = InformationTheory.entropy(p_x)
        return H_XY - H_X
    
    @staticmethod
    def mutual_information(p_xy):
        """
        Compute I(X;Y) = H(X) + H(Y) - H(X,Y).
        """
        p_xy = np.array(p_xy)
        p_x = np.sum(p_xy, axis=1)
        p_y = np.sum(p_xy, axis=0)
        H_X = InformationTheory.entropy(p_x)
        H_Y = InformationTheory.entropy(p_y)
        H_XY = InformationTheory.joint_entropy(p_xy)
        return H_X + H_Y - H_XY
    
    @staticmethod
    def kl_divergence(p, q):
        """
        Compute KL divergence D(p || q) = Σ p(x) log(p(x)/q(x)).
        """
        p, q = np.array(p), np.array(q)
        mask = (p > 0) & (q > 0)
        return np.sum(p[mask] * np.log2(p[mask] / q[mask]))

class BinarySymmetricChannel:
    """
    Binary Symmetric Channel (BSC) with crossover probability p.
    X ∈ {0, 1}, Y ∈ {0, 1}
    P(Y ≠ X) = p
    """
    
    def __init__(self, crossover_prob):
        self.p = crossover_prob
    
    def capacity(self):
        """
        Capacity of BSC is 1 - H(p) where H(p) is binary entropy.
        Achieved by uniform input distribution.
        """
        H_p = InformationTheory.entropy([self.p, 1 - self.p])
        return 1 - H_p
    
    def mutual_info(self, input_prob):
        """
        Compute I(X;Y) for given input distribution.
        input_prob = P(X=0)
        """
        q = input_prob
        p = self.p
        
        # Joint distribution
        # P(X=0, Y=0) = q(1-p), P(X=0, Y=1) = qp
        # P(X=1, Y=0) = (1-q)p, P(X=1, Y=1) = (1-q)(1-p)
        p_xy = np.array([
            [q * (1 - p), q * p],
            [(1 - q) * p, (1 - q) * (1 - p)]
        ])
        
        return InformationTheory.mutual_information(p_xy)
    
    def optimal_input(self):
        """Return optimal input distribution (always uniform for BSC)."""
        return 0.5

2. Control Theory: Stability and Optimal Control

Real-World Motivation: From autopilot systems in aircraft to the cruise control in your car, from robotic manipulators to power grid stabilization, control theory provides the mathematical framework for making systems behave as desired. It combines differential equations, linear algebra, and optimization to design controllers that can steer systems toward goals while maintaining stability in the face of disturbances and uncertainties.

Definitions:

  • A linear time-invariant (LTI) system has the form: \[\dot{x} = Ax + Bu, \quad y = Cx + Du\] where \(x\) is the state, \(u\) is the control input, and \(y\) is the output
  • The system is asymptotically stable if all eigenvalues of \(A\) have negative real parts (for continuous time) or magnitude less than 1 (for discrete time)
  • A system is controllable if the controllability matrix \(\mathcal{C} = [B \ AB \ A^2B \ \cdots \ A^{n-1}B]\) has full rank
  • The Linear Quadratic Regulator (LQR) finds the control that minimizes \(J = \int_0^\infty (x^T Q x + u^T R u) dt\)

Theorem (Lyapunov Stability): The system \(\dot{x} = Ax\) is asymptotically stable if and only if there exists a positive definite matrix \(P\) satisfying the Lyapunov equation: \[A^T P + PA = -Q\] for some positive definite matrix \(Q\). In this case, \(V(x) = x^T P x\) serves as a Lyapunov function, with \(\dot{V}(x) = -x^T Q x < 0\) for \(x \neq 0\).

Proof: (Sufficiency) If such \(P\) exists, define \(V(x) = x^T P x\). Then \(V > 0\) for \(x \neq 0\) and: \[\dot{V} = \dot{x}^T P x + x^T P \dot{x} = x^T A^T P x + x^T P A x = x^T(A^T P + PA)x = -x^T Q x < 0\] By Lyapunov's direct method, the origin is asymptotically stable. (Necessity) If \(A\) is stable, the integral \(P = \int_0^\infty e^{A^T t} Q e^{At} dt\) converges. Differentiating \(e^{A^T t} Q e^{At}\) and integrating from 0 to \(\infty\) gives the Lyapunov equation. \(\square\)

Notation Guide:

  • \(x \in \mathbb{R}^n\) — State vector
  • \(u \in \mathbb{R}^m\) — Control input
  • \(A, B, C, D\) — System matrices
  • \(\mathcal{C}\) — Controllability matrix
  • \(Q, R\) — LQR weight matrices (positive definite)
  • \(P\) — Solution to Lyapunov or Riccati equation
# Control Theory: Stability and Optimal Control
import numpy as np
from scipy import linalg
from scipy.integrate import odeint

class LinearSystem:
    """Linear Time-Invariant (LTI) system: dx/dt = Ax + Bu."""
    
    def __init__(self, A, B, C=None, D=None):
        self.A = np.array(A)
        self.B = np.array(B) if B is not None else None
        self.n = self.A.shape[0]  # State dimension
        self.m = self.B.shape[1] if self.B is not None else 0
        
        self.C = np.array(C) if C is not None else np.eye(self.n)
        self.D = np.array(D) if D is not None else np.zeros((self.C.shape[0], self.m))
    
    def eigenvalues(self):
        """Return eigenvalues of A."""
        return np.linalg.eigvals(self.A)
    
    def is_stable(self):
        """Check if system is asymptotically stable (all Re(λ) < 0)."""
        eigs = self.eigenvalues()
        return np.all(np.real(eigs) < 0)
    
    def controllability_matrix(self):
        """Compute controllability matrix [B AB A²B ... A^(n-1)B]."""
        if self.B is None:
            return None
        
        C = [self.B]
        for i in range(1, self.n):
            C.append(np.linalg.matrix_power(self.A, i) @ self.B)
        return np.hstack(C)
    
    def is_controllable(self):
        """Check if system is controllable."""
        C = self.controllability_matrix()
        if C is None:
            return False
        return np.linalg.matrix_rank(C) == self.n
    
    def solve_lyapunov(self, Q=None):
        """
        Solve Lyapunov equation A^T P + PA = -Q.
        Returns P (positive definite if A is stable).
        """
        if Q is None:
            Q = np.eye(self.n)
        
        # Use scipy's Lyapunov solver
        P = linalg.solve_continuous_lyapunov(self.A.T, -Q)
        return P
    
    def lqr_controller(self, Q, R):
        """
        Design LQR controller.
        Solves: min ∫(x^T Q x + u^T R u)dt
        Returns gain matrix K where u = -Kx.
        """
        # Solve Continuous Algebraic Riccati Equation (CARE)
        # A^T P + PA - PBR^{-1}B^T P + Q = 0
        P = linalg.solve_continuous_are(self.A, self.B, Q, R)
        
        # Optimal gain: K = R^{-1} B^T P
        K = np.linalg.inv(R) @ self.B.T @ P
        
        return K, P
    
    def simulate(self, x0, t, u_func=None):
        """
        Simulate system with initial condition x0.
        u_func: function u(t, x) giving control input
        """
        def dynamics(x, t):
            dx = self.A @ x
            if self.B is not None and u_func is not None:
                u = u_func(t, x)
                dx = dx + self.B @ u
            return dx
        
        return odeint(dynamics, x0, t)

3. Random Matrix Theory: Universality and the Semicircle Law

Real-World Motivation: Random matrix theory (RMT) originated in nuclear physics, where Eugene Wigner used random matrices to model the energy levels of heavy nuclei. Today, RMT has found applications in quantum chaos, number theory (spacing of zeta zeros), wireless communications (MIMO systems), machine learning (neural network initialization), and finance (correlation matrices). The field reveals universal statistical patterns that emerge when matrices are large, regardless of the specific distribution of their entries.

Definitions:

  • The Gaussian Orthogonal Ensemble (GOE) consists of real symmetric matrices with independent (up to symmetry) Gaussian entries: \(H_{ij} \sim N(0, 1/n)\) for \(i \neq j\) and \(H_{ii} \sim N(0, 2/n)\)
  • The empirical spectral distribution (ESD) of a matrix with eigenvalues \(\lambda_1, \ldots, \lambda_n\) is \(\mu_n = \frac{1}{n} \sum_{i=1}^n \delta_{\lambda_i}\)
  • The level spacing distribution describes the gaps between consecutive eigenvalues
  • The Wigner semicircle distribution has density \(\rho(x) = \frac{1}{2\pi} \sqrt{4 - x^2}\) for \(|x| \leq 2\)

Theorem (Wigner's Semicircle Law): Let \(H_n\) be an \(n \times n\) Wigner matrix (real symmetric with i.i.d. entries above the diagonal, mean 0, variance \(\sigma^2/n\)). As \(n \to \infty\), the empirical spectral distribution converges weakly to the semicircle distribution: \[\mu_n \xrightarrow{w} \mu_{sc}\] where \(\mu_{sc}\) has density \(\frac{1}{2\pi\sigma^2} \sqrt{4\sigma^2 - x^2}\) on \([-2\sigma, 2\sigma]\).

Proof Sketch: The proof uses the method of moments. One shows that the expected moments of \(\mu_n\) converge to the moments of the semicircle distribution. The key combinatorial observation is that in the expansion of \(\mathbb{E}[\text{tr}(H_n^k)]\), only certain pairings of matrix entries contribute in the limit. These correspond to Catalan paths, and the Catalan numbers \(C_m = \frac{1}{m+1}\binom{2m}{m}\) are the moments of the semicircle. Concentration inequalities then show that the random moments concentrate around their means. \(\square\)

Notation Guide:

  • GOE, GUE, GSE — Gaussian Orthogonal/Unitary/Symplectic Ensembles
  • \(\mu_n\) — Empirical spectral distribution
  • \(\mu_{sc}\) — Semicircle distribution
  • \(\rho(x)\) — Spectral density
  • \(s\) — Level spacing variable (normalized)
  • \(p(s)\) — Level spacing distribution
# Random Matrix Theory: Wigner's Semicircle Law

class WignerMatrix:
    """
    Wigner random matrix ensemble.
    """
    
    def __init__(self, n, ensemble='GOE'):
        """
        n: matrix size
        ensemble: 'GOE' (real symmetric), 'GUE' (complex Hermitian)
        """
        self.n = n
        self.ensemble = ensemble
    
    def generate(self):
        """Generate a random matrix from the ensemble."""
        if self.ensemble == 'GOE':
            # Real symmetric: upper triangle ~ N(0, 1/n), diagonal ~ N(0, 2/n)
            A = np.random.randn(self.n, self.n) / np.sqrt(self.n)
            H = (A + A.T) / np.sqrt(2)
            return H
        elif self.ensemble == 'GUE':
            # Complex Hermitian
            A = (np.random.randn(self.n, self.n) + 1j * np.random.randn(self.n, self.n)) / np.sqrt(2 * self.n)
            H = (A + A.conj().T) / np.sqrt(2)
            return H
        else:
            raise ValueError(f"Unknown ensemble: {self.ensemble}")
    
    def eigenvalues(self, n_samples=1):
        """Generate eigenvalues from n_samples matrices."""
        all_eigs = []
        for _ in range(n_samples):
            H = self.generate()
            eigs = np.linalg.eigvalsh(H)  # For Hermitian matrices
            all_eigs.extend(eigs)
        return np.array(all_eigs)

def semicircle_pdf(x, R=2):
    """
    Semicircle probability density function.
    ρ(x) = (2/(πR²)) √(R² - x²) for |x| ≤ R
    """
    result = np.zeros_like(x, dtype=float)
    mask = np.abs(x) <= R
    result[mask] = (2 / (np.pi * R**2)) * np.sqrt(R**2 - x[mask]**2)
    return result

def semicircle_moment(k, R=2):
    """
    Compute k-th moment of semicircle distribution.
    M_k = 0 for odd k
    M_k = C_{k/2} (R/2)^k for even k, where C_m is Catalan number
    """
    if k % 2 == 1:
        return 0
    m = k // 2
    # Catalan number C_m = (2m)! / ((m+1)! m!)
    from math import factorial
    catalan = factorial(2*m) // (factorial(m+1) * factorial(m))
    return catalan * (R/2)**k

def wigner_surmise(s, beta=1):
    """
    Wigner surmise for nearest-neighbor spacing distribution.
    beta=1: GOE, beta=2: GUE, beta=4: GSE
    p(s) = a s^β exp(-b s²)
    """
    if beta == 1:  # GOE
        a, b = np.pi/2, np.pi/4
    elif beta == 2:  # GUE

        a, b = 2**18/(3**6 * np.pi**3), 64/(9*np.pi)
    else:
        raise ValueError("beta must be 1, 2, or 4")
    
    return a * s**beta * np.exp(-b * s**2)

1. Nonstandard Analysis: Infinitesimals Made Rigorous

Historical Context: Calculus was originally developed by Newton and Leibniz using infinitesimals—quantities that are infinitely small yet nonzero. While this approach yielded correct results, it lacked rigorous foundations, leading Bishop Berkeley to deride infinitesimals as "ghosts of departed quantities." In the 19th century, Cauchy, Weierstrass, and others replaced infinitesimals with the \(\epsilon\)-\(\delta\) definition of limits. But in 1961, Abraham Robinson used model theory to show that infinitesimals could be made rigorous after all, creating nonstandard analysis—a powerful alternative foundation for calculus and analysis.

Definitions:

  • An ultrafilter \(\mathcal{U}\) on a set \(I\) is a collection of subsets of \(I\) that is closed under finite intersections, upward closed, and for every \(A \subseteq I\), either \(A \in \mathcal{U}\) or \(I \setminus A \in \mathcal{U}\)
  • The ultrapower \(\mathbb{R}^* = \mathbb{R}^I / \mathcal{U}\) consists of equivalence classes of sequences where two sequences are equivalent if they agree on a set in \(\mathcal{U}\)
  • A hyperreal \([x_n] \in \mathbb{R}^*\) is infinitesimal if \(\lim_{\mathcal{U}} x_n = 0\), and finite if \(|x_n|\) is bounded on a set in \(\mathcal{U}\)
  • The standard part function \(\text{st}: \text{fin}(\mathbb{R}^*) \to \mathbb{R}\) maps a finite hyperreal to the unique real number infinitely close to it

Theorem (Transfer Principle): Every first-order statement about \(\mathbb{R}\) is true if and only if the corresponding statement about \(\mathbb{R}^*\) is true. More precisely, for any first-order formula \(\phi(x_1, \ldots, x_n)\) and any hyperreals \(a_1, \ldots, a_n\): \[\mathbb{R} \models \phi(\text{st}(a_1), \ldots, \text{st}(a_n)) \iff \mathbb{R}^* \models \phi(a_1, \ldots, a_n)\] when all quantities are defined.

Proof: The transfer principle follows from Łoś's theorem on ultraproducts. By construction, the ultrapower \(\mathbb{R}^*\) is elementarily equivalent to \(\mathbb{R}\) for first-order statements. The key insight is that first-order properties are preserved under ultraproducts. For any first-order sentence \(\phi\), we have: \[\mathbb{R}^* \models \phi \iff \{i : \mathbb{R} \models \phi\} \in \mathcal{U}\] Since \(\phi\) is either true in all copies of \(\mathbb{R}\) or in none, and \(\mathcal{U}\) contains either \(\emptyset\) or \(I\) but not both, the result follows. \(\square\)

Notation Guide:

  • \(\mathbb{R}^*\) — Hyperreal numbers
  • \(\epsilon, \delta\) — Infinitesimals (often \(\epsilon > 0\), \(\epsilon \approx 0\))
  • \(H, K\) — Infinite hyperreals
  • \(x \approx y\) — Infinitely close: \(x - y\) is infinitesimal
  • \(\text{st}(x)\) — Standard part of finite hyperreal \(x\)
  • \(*f\) — Nonstandard extension of function \(f\)

2. Combinatorial Game Theory: Nim, Sprague-Grundy, and Beyond

Historical Context: Combinatorial game theory emerged from the analysis of impartial games like Nim, where both players have the same available moves. The Sprague-Grundy theorem, proved independently by Roland Sprague in 1935 and Patrick Grundy in 1939, showed that every impartial game is equivalent to a Nim heap. This unified theory was later extended by John Conway in the 1970s to partizan games (where players have different moves), leading to the theory of surreal numbers and the analysis of games like Go and Chess.

Definitions:

  • An impartial game is one where the available moves depend only on the position, not on which player is moving
  • The mex (minimum excludant) of a set of non-negative integers is the smallest non-negative integer not in the set: \(\text{mex}(S) = \min\{n \in \mathbb{N} : n \notin S\}\)
  • The Sprague-Grundy value (or nimber) of a position is \(g(P) = \text{mex}\{g(Q) : Q \text{ is a follower of } P\}\)
  • The nim-sum of two numbers is their bitwise XOR: \(a \oplus b\)

Theorem (Sprague-Grundy): Every impartial game is equivalent to a Nim heap. Specifically, if \(G\) is an impartial game with Sprague-Grundy value \(g(G)\), then \(G\) is equivalent to a Nim heap of size \(g(G)\). For the disjunctive sum of games \(G + H\), the Sprague-Grundy value is: \[g(G + H) = g(G) \oplus g(H)\] where \(\oplus\) denotes nim-sum (bitwise XOR).

Proof: We prove by induction on the game tree. For the base case, a terminal position has no followers, so its mex is 0, equivalent to an empty Nim heap. For the inductive step, assume the theorem holds for all followers of \(G\). The Sprague-Grundy value \(g(G)\) is defined as the mex of SG-values of followers. By induction, each follower is equivalent to a Nim heap of its SG-value. The key observation is that from a Nim heap of size \(n\), one can move to any heap of size \(0, 1, \ldots, n-1\). Since mex chooses the smallest excluded value, the equivalence holds. For disjunctive sums, the XOR property follows from analyzing the possible moves in the combined game. \(\square\)

Notation Guide:

  • \(g(G)\) or \(\mathcal{G}(G)\) — Sprague-Grundy value (nimber)
  • \(\text{mex}(S)\) — Minimum excludant
  • \(a \oplus b\) — Nim-sum (bitwise XOR)
  • \(*n\) — Nim heap of size \(n\)
  • \(G + H\) — Disjunctive sum of games
  • \(P\)-position — Previous player wins (\(g = 0\))
  • \(N\)-position — Next player wins (\(g \neq 0\))

from functools import lru_cache

class ImpartialGame:
    """Base class for impartial games."""
    
    def followers(self, position):
        """Return list of positions reachable in one move."""
        raise NotImplementedError
    
    @lru_cache(maxsize=None)
    def grundy(self, position):
        """
        Compute Sprague-Grundy value using recursive definition:
        g(P) = mex{g(Q) : Q is a follower of P}
        """
        follower_values = {self.grundy(f) for f in self.followers(position)}
        return mex(follower_values)
    
    def is_p_position(self, position):
        """P-position: previous player wins (g = 0)."""
        return self.grundy(position) == 0
    
    def is_n_position(self, position):
        """N-position: next player wins (g ≠ 0)."""
        return self.grundy(position) != 0

def mex(s):
    """Minimum excludant: smallest non-negative integer not in set."""
    i = 0
    while i in s:
        i += 1
    return i

def nim_sum(*values):
    """Compute nim-sum (bitwise XOR) of values."""
    result = 0
    for v in values:
        result ^= v
    return result

class Nim(ImpartialGame):
    """
    Nim game: multiple heaps, remove any positive number from one heap.
    """
    
    def followers(self, position):
        """
        Position is a tuple of heap sizes.
        Followers: reduce any one heap.
        """
        followers = []
        for i, heap in enumerate(position):
            for remove in range(1, heap + 1):
                new_heap = heap - remove
                new_position = position[:i] + (new_heap,) + position[i+1:]
                # Remove empty heaps for canonical form
                new_position = tuple(h for h in new_position if h > 0)
                followers.append(new_position)
        return followers
    
    def grundy(self, position):
        """
        For Nim, g(heaps) = heap₁ ⊕ heap₂ ⊕ ... ⊕ heapₙ
        """
        return nim_sum(*position) if position else 0

class SubtractionGame(ImpartialGame):

        self.S = subtraction_set
    
    def followers(self, n):

class Kayles(ImpartialGame):
    """
    Kayles: bowling pin game. Remove 1 or 2 adjacent pins.
    Position represented as tuple of contiguous pin groups.
    """
    
    def followers(self, position):
        """
        Position is tuple of group sizes.
        Can remove 1 pin from any group, or 2 adjacent pins.
        """
        followers = []
        position = list(position)
        
        for i, group in enumerate(position):
            # Remove one pin
            for j in range(group):
                # Removing pin j splits group into left and right parts
                left = j
                right = group - j - 1
                new_pos = position[:i] + [g for g in [left, right] if g > 0] + position[i+1:]
                followers.append(tuple(sorted(new_pos)))
            
            # Remove two adjacent pins
            for j in range(group - 1):
                left = j
                right = group - j - 2
                new_pos = position[:i] + [g for g in [left, right] if g > 0] + position[i+1:]
                followers.append(tuple(sorted(new_pos)))
        
        # Remove duplicates
        return list(set(followers))

def nim_winning_move(position):
    """
    Find a winning move in Nim.
    If g ≠ 0, find heap and amount to reduce to make g = 0.
    """
    g = nim.grundy(position)
    if g == 0:
        return None  # Losing position
    
    for i, heap in enumerate(position):
        # New heap size should be heap ⊕ g
        new_heap = heap ^ g
        if new_heap < heap:
            return i, heap - new_heap

📜 Math History: The Birth of Modern Probability

While gambling is as old as civilization itself, the mathematical theory of probability emerged remarkably late in human history. The ancient Greeks, despite their mathematical sophistication, never developed a theory of chance—Aristotle believed that events were either determined by necessity or left to chance, with the latter being fundamentally unknowable. The Romans had a word for luck (fortuna) but no mathematics to describe it.

The breakthrough came in 1654, when the French nobleman Antoine Gombaud, Chevalier de Méré, posed a problem to Blaise Pascal about the fair division of stakes in an interrupted game of chance. This seemingly simple question launched a correspondence between Pascal and Pierre de Fermat that created the foundations of probability theory. Their exchange, conducted through letters, established the concepts of expected value and the multiplication rule for independent events.

Christiaan Huygens, visiting Paris in 1655, learned of these developments and published the first book on probability, De Ratiociniis in Ludo Aleae (On Reasoning in Games of Chance), in 1657. Huygens introduced the concept of expectation and solved problems that are still taught in introductory probability courses today.

The field advanced rapidly in the following decades. Jakob Bernoulli's Ars Conjectandi (The Art of Conjecturing), published posthumously in 1713, proved the first version of the law of large numbers—the theoretical justification for using observed frequencies to estimate probabilities. Abraham de Moivre, in his 1718 Doctrine of Chances, derived the normal approximation to the binomial distribution, a precursor to the central limit theorem.

The 19th and 20th centuries saw probability transform from a tool for gamblers into a rigorous mathematical discipline. Andrey Kolmogorov's 1933 axiomatization, using measure theory, placed probability on the same rigorous footing as the rest of mathematics. This foundation enabled the explosion of applications in statistics, physics, economics, and computer science that characterizes the modern era.

Today, probability theory underlies machine learning algorithms, financial models, quantum mechanics, and our understanding of genetic inheritance. From Pascal and Fermat's letters about dice games has emerged a mathematical language for uncertainty that shapes virtually every aspect of modern science and technology.

Phase portraits provide a geometric visualization of dynamical systems, showing how trajectories evolve in state space. The following Python code generates phase portraits for various dynamical systems, revealing their qualitative behavior.

# Phase Portrait Visualization for Dynamical Systems
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import FancyArrowPatch

def phase_portrait_2d(f, xlim, ylim, n_points=20, ax=None):
    """
    Generate phase portrait for 2D system dx/dt = f(x, y).
    
    Parameters:
    -----------
    f : callable
        Function f(t, Y) where Y = [x, y], returns [dx/dt, dy/dt]
    xlim, ylim : tuples
        (min, max) for x and y axes
    n_points : int
        Number of grid points in each direction
    """
    if ax is None:
        fig, ax = plt.subplots(figsize=(10, 8))
    
    x = np.linspace(xlim[0], xlim[1], n_points)
    y = np.linspace(ylim[0], ylim[1], n_points)
    X, Y = np.meshgrid(x, y)
    
    # Compute derivatives
    DX = np.zeros_like(X)
    DY = np.zeros_like(Y)
    
    for i in range(n_points):
        for j in range(n_points):
            dY = f(0, [X[i, j], Y[i, j]])
            DX[i, j] = dY[0]
            DY[i, j] = dY[1]
    
    # Normalize arrows
    M = np.sqrt(DX**2 + DY**2)
    M[M == 0] = 1
    DX_norm = DX / M
    DY_norm = DY / M
    
    # Plot vector field
    ax.quiver(X, Y, DX_norm, DY_norm, M, cmap='viridis', 
              scale=30, width=0.003, alpha=0.8)
    
    # Plot some trajectories
    from scipy.integrate import odeint
    
    # Starting points for trajectories
    np.random.seed(42)
    n_traj = 15
    x0s = np.random.uniform(xlim[0], xlim[1], n_traj)
    y0s = np.random.uniform(ylim[0], ylim[1], n_traj)
    
    t = np.linspace(0, 10, 1000)
    
    for x0, y0 in zip(x0s, y0s):
        sol = odeint(lambda y, t: f(t, y), [x0, y0], t)

    ax.set_xlim(xlim)
    ax.set_ylim(ylim)
    ax.set_xlabel('x')
    ax.set_ylabel('y')
    ax.set_title('Phase Portrait')
    ax.grid(True, alpha=0.3)
    
    return ax
