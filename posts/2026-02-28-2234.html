p-adic Analysis: Hensel's Lemma and Local-Global Principles

p-adic-analysis

Motivation

p-adic numbers, introduced by Kurt Hensel in 1897, provide an alternative way to complete the rational numbers. Unlike the real numbers, which arise from completing \(\mathbb{Q}\) with respect to the usual absolute value, p-adic numbers come from completing with respect to the p-adic absolute value. This completion reveals deep arithmetic structures and gives rise to powerful tools like Hensel's lemma, which allows lifting solutions from modular arithmetic to p-adic solutions.

Definitions

  • p-adic Valuation: For a prime \(p\) and nonzero integer \(n\), \(\nu_p(n)\) is the highest power of \(p\) dividing \(n\). For \(x = a/b \in \mathbb{Q}^\times\), \(\nu_p(x) = \nu_p(a) - \nu_p(b)\).
  • p-adic Absolute Value: \(|x|_p = p^{-\nu_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).
  • p-adic Integers \(\mathbb{Z}_p\): \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\}\), the closed unit ball in \(\mathbb{Q}_p\).

Theorem: Hensel's Lemma

Theorem (Hensel's Lemma): Let \(f(x) \in \mathbb{Z}_p[x]\) be a polynomial and suppose there exists \(\alpha_0 \in \mathbb{Z}_p\) such that:

\[|f(\alpha_0)|_p < |f'(\alpha_0)|_p^2\]

Then there exists a unique \(\alpha \in \mathbb{Z}_p\) such that \(f(\alpha) = 0\) and \(|\alpha - \alpha_0|_p < |f'(\alpha_0)|_p\).

Simple Version: If \(f(a) \equiv 0 \pmod{p}\) and \(f'(a) \not\equiv 0 \pmod{p}\) for some \(a \in \mathbb{Z}\), then there exists a unique \(\alpha \in \mathbb{Z}_p\) such that \(f(\alpha) = 0\) and \(\alpha \equiv a \pmod{p}\).

Proof Sketch

The proof uses Newton's method in the p-adic setting. Define the iteration:

\[\alpha_{n+1} = \alpha_n - \frac{f(\alpha_n)}{f'(\alpha_n)}\]

One shows by induction that \(|f(\alpha_n)|_p \to 0\) and \((\alpha_n)\) is Cauchy, hence converges to a root \(\alpha\). The strong triangle inequality (\(|x + y|_p \leq \max(|x|_p, |y|_p)\)) ensures rapid convergence.

Notation Guide

  • \(p\) — Prime number
  • \(\nu_p(x)\) — p-adic valuation of \(x\)
  • \(|x|_p\) — p-adic absolute value
  • \(\mathbb{Q}_p\) — Field of p-adic numbers
  • \(\mathbb{Z}_p\) — Ring of p-adic integers
  • \(f'(x)\) — Formal derivative of polynomial \(f\)

Python Code: p-adic Arithmetic and Hensel's Lemma

import math

def p_adic_valuation(n: int, p: int) -> int:
    """Compute ν_p(n), the p-adic valuation of n."""
    if n == 0:
        return float('inf')
    count = 0
    while n % p == 0:
        n //= p
        count += 1
    return count

def p_adic_abs(x: int, p: int) -> float:
    """Compute |x|_p = p^(-ν_p(x))."""
    if x == 0:
        return 0.0
    return p ** (-p_adic_valuation(x, p))

def hensel_lift(f, df, a: int, p: int, k: int) -> int:
    """
    Lift a solution of f(x) ≡ 0 (mod p) to a solution mod p^k using Hensel's lemma.
    """
    if f(a) % p != 0:
        raise ValueError(f"f({a}) ≡ {f(a) % p} (mod {p}), not 0")
    if df(a) % p == 0:
        raise ValueError(f"f'({a}) ≡ 0 (mod {p}), Hensel's lemma doesn't apply")
    
    x = a
    current_power = 1
    
    while current_power < k:
        current_power *= 2
        if current_power > k:
            current_power = k
        
        fx = f(x)
        dfx = df(x)
        
        inv_dfx = pow(dfx, -1, p ** current_power)
        x = (x - fx * inv_dfx) % (p ** current_power)
    
    return x

# Example: Find square root of 2 in 7-adic integers
def f(x):
    return x * x - 2

def df(x):
    return 2 * x

p = 7
a = 3  # Initial solution: 3^2 = 9 ≡ 2 (mod 7)

print("Hensel's Lemma: Lifting √2 in 7-adic integers")
print(f"Initial solution: x ≡ {a} (mod {p})")

# Lift to higher powers
for k in range(1, 11):
    solution = hensel_lift(f, df, a, p, k)
    mod = p ** k
    print(f"x ≡ {solution} (mod {mod})")

Algebraic Graph Theory: Spectral Graph Theory and the Matrix-Tree Theorem

algebraic-graph-theory

Motivation

Algebraic graph theory uses linear algebra and group theory to study graphs. By associating matrices to graphs (adjacency, Laplacian), we unlock powerful tools from linear algebra. The eigenvalues of these matrices reveal deep structural properties of graphs, from connectivity to expansion properties. The Matrix-Tree Theorem, a cornerstone result, connects the Laplacian spectrum to the number of spanning trees.

Definitions

  • Adjacency Matrix \(A\): For a graph \(G = (V, E)\), \(A_{ij} = 1\) if \((i,j) \in E\), else \(0\).
  • Degree Matrix \(D\): Diagonal matrix with \(D_{ii} = \deg(i)\).
  • Laplacian Matrix \(L\): \(L = D - A\).
  • Spanning Tree: A subgraph that is a tree containing all vertices of \(G\).

Theorem: Matrix-Tree Theorem (Kirchhoff)

Theorem (Matrix-Tree): Let \(G\) be a connected graph with Laplacian matrix \(L\). Let \(L'\) be any cofactor of \(L\) (obtained by deleting any row and the corresponding column). Then:

\[\tau(G) = \det(L')\]

where \(\tau(G)\) is the number of spanning trees of \(G\).

Spectral Version: If \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\) are the eigenvalues of \(L\), then:

\[\tau(G) = \frac{1}{n} \lambda_2 \lambda_3 \cdots \lambda_n\]

Notation Guide

  • \(G = (V, E)\) — Graph with vertex set \(V\) and edge set \(E\)
  • \(A\) — Adjacency matrix
  • \(D\) — Degree matrix
  • \(L = D - A\) — Laplacian matrix
  • \(\tau(G)\) — Number of spanning trees
  • \(\lambda_i\) — Eigenvalues of \(L\)

Python Code: Spectral Graph Analysis

import numpy as np

def laplacian_matrix(adj_matrix):
    """Compute the Laplacian matrix L = D - A."""
    degrees = np.sum(adj_matrix, axis=1)
    D = np.diag(degrees)
    return D - adj_matrix

def count_spanning_trees(laplacian):
    """Count spanning trees using Kirchhoff's Matrix-Tree Theorem."""
    n = laplacian.shape[0]
    if n <= 1:
        return 1
    L_reduced = laplacian[:-1, :-1]
    return round(np.linalg.det(L_reduced))

# Example: Complete graph K_4
n = 4
K4 = np.ones((n, n)) - np.eye(n)
L_K4 = laplacian_matrix(K4)

eigenvalues = np.linalg.eigvalsh(L_K4)
print(f"K_4 Eigenvalues: {np.sort(eigenvalues)}")

trees = count_spanning_trees(L_K4)
print(f"Spanning trees: {trees}")
print(f"Cayley's formula: {n**(n-2)}")

Spectral Sequences in Homological Algebra

spectral-sequences

Motivation

Spectral sequences are powerful computational tools in algebraic topology and homological algebra. They provide a systematic way to compute complex derived functors by breaking the computation into manageable steps. First introduced by Jean Leray in the 1940s while studying sheaf cohomology, spectral sequences have become indispensable in algebraic geometry, algebraic topology, and representation theory.

Definitions

  • Spectral Sequence: A sequence \((E^r, d^r)_{r \geq r_0}\) of bigraded modules \(E^r = \bigoplus_{p,q} E^r_{p,q}\) with differentials \(d^r: E^r_{p,q} \to E^r_{p-r, q+r-1}\) such that \(E^{r+1} = H(E^r, d^r)\).
  • Convergence: A spectral sequence converges to \(H_*\) (written \(E^r_{p,q} \Rightarrow H_{p+q}\)) if there exists a filtration on \(H_*\) such that \(E^\infty_{p,q} \cong F_p H_{p+q} / F_{p-1} H_{p+q}\).

Theorem: Leray-Serre Spectral Sequence

Theorem (Leray-Serre): Let \(F \to E \to B\) be a fibration with \(B\) simply connected and \(F\) connected. Then there exists a first-quadrant cohomology spectral sequence with:

\[E_2^{p,q} = H^p(B; H^q(F; R)) \Rightarrow H^{p+q}(E; R)\]

where \(R\) is a coefficient ring. The differential has bidegree \((r, 1-r)\).

Notation Guide

  • \(E^r_{p,q}\) — Page \(r\), position \((p,q)\) of the spectral sequence
  • \(d^r\) — Differential on page \(r\)
  • \(E^\infty_{p,q}\) — Limit term
  • \(F_p H_n\) — Filtration on the target homology
  • \(\Rightarrow\) — Convergence notation

Network Science: Centrality Measures and Community Detection

network-science

Real-World Motivation

Networks pervade modern life: social networks, the internet, biological neural networks, power grids, and transportation systems. Understanding which nodes are most important (centrality) and how networks organize into communities is crucial for applications ranging from viral marketing to epidemiology.

Definitions

  • Degree Centrality: \(C_D(v) = \deg(v)\), the number of connections.
  • Betweenness Centrality: \(C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}\).
  • Eigenvector Centrality: The centrality of a node is proportional to the sum of centralities of its neighbors: \(\lambda x = Ax\).
  • PageRank: \(x_i = \alpha \sum_j A_{ji} \frac{x_j}{L(j)} + \frac{1-\alpha}{N}\).

Theorem: PageRank Convergence

Theorem: For a strongly connected directed graph and damping factor \(\alpha \in (0, 1)\), the PageRank vector is the unique stationary distribution of the Markov chain with transition matrix \(P = \alpha D^{-1}A + \frac{1-\alpha}{N} \mathbf{1}\mathbf{1}^T\). The power iteration converges geometrically with rate \(\alpha\).

Notation Guide

  • \(G = (V, E)\) — Graph
  • \(A\) — Adjacency matrix
  • \(\alpha\) — Damping factor (typically 0.85)
  • \(\sigma_{st}\) — Number of shortest paths from \(s\) to \(t\)

Stochastic Calculus: Itô's Lemma and the Black-Scholes Model

stochastic-calculus

Real-World Motivation

Financial markets are inherently random, with asset prices fluctuating unpredictably. Stochastic calculus provides the mathematical framework for modeling these random processes and pricing financial derivatives. The Black-Scholes-Merton model, which earned its creators the 1997 Nobel Prize in Economics, uses stochastic differential equations to derive fair prices for options.

Definitions

  • Wiener Process (Brownian Motion): A continuous-time stochastic process \(W_t\) with \(W_0 = 0\), independent increments, and \(W_t - W_s \sim \mathcal{N}(0, t-s)\).
  • Itô Process: \(dX_t = \mu_t dt + \sigma_t dW_t\).
  • European Call Option: Payoff: \(\max(S_T - K, 0)\).

Theorem: Itô's Lemma

Theorem (Itô's Lemma): Let \(X_t\) be an Itô process with \(dX_t = \mu_t dt + \sigma_t dW_t\), and let \(f(t, x)\) be twice continuously differentiable. Then \(Y_t = f(t, X_t)\) satisfies:

\[df = \left(\frac{\partial f}{\partial t} + \mu_t \frac{\partial f}{\partial x} + \frac{1}{2} \sigma_t^2 \frac{\partial^2 f}{\partial x^2}\right) dt + \sigma_t \frac{\partial f}{\partial x} dW_t\]

Theorem: Black-Scholes Formula

Theorem (Black-Scholes): The price of a European call option is:

\[C = S_0 N(d_1) - Ke^{-rT} N(d_2)\]

where \(d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}\) and \(d_2 = d_1 - \sigma\sqrt{T}\).

Notation Guide

  • \(W_t\) — Wiener process
  • \(\mu\) — Drift coefficient
  • \(\sigma\) — Volatility
  • \(N(x)\) — Standard normal CDF
  • \(r\) — Risk-free rate

Queueing Theory: The M/M/1 Queue and Little's Law

queuing-theory

Real-World Motivation

Queueing theory studies the behavior of waiting lines and is essential for designing efficient service systems. From call centers and hospital emergency rooms to computer networks and manufacturing systems, queues are ubiquitous.

Definitions

  • M/M/1 Queue: Poisson arrivals, exponential service times, 1 server.
  • Traffic Intensity: \(\rho = \lambda/\mu\). For stability, \(\rho < 1\).
  • Little's Law: \(L = \lambda W\).

Theorem: M/M/1 Steady-State Distribution

Theorem: For an M/M/1 queue with \(\rho = \lambda/\mu < 1\):

\[P_n = (1-\rho)\rho^n, \quad L = \frac{\rho}{1-\rho}, \quad W = \frac{1}{\mu - \lambda}\]

Theorem: Little's Law

Theorem (Little's Law): For any stable queueing system in steady state: \(L = \lambda W\).

Notation Guide

  • \(\lambda\) — Arrival rate
  • \(\mu\) — Service rate
  • \(\rho\) — Traffic intensity
  • \(L\) — Average number in system
  • \(W\) — Average time in system

Set Theory: Forcing and the Continuum Hypothesis

set-theory

Historical Context

The Continuum Hypothesis (CH), proposed by Georg Cantor in 1878, states that there is no set whose cardinality is strictly between that of the integers and the real numbers. In 1940, Kurt Gödel proved that CH is consistent with ZFC. Then in 1963, Paul Cohen proved that the negation of CH is also consistent with ZFC, making CH independent of the standard axioms of set theory. Cohen's revolutionary technique, called forcing, has become one of the most important tools in modern set theory.

Definitions

  • Continuum Hypothesis (CH): \(2^{\aleph_0} = \aleph_1\).
  • Forcing: A method for constructing models of set theory by adding new "generic" sets.

Theorem: Independence of CH

Theorem (Cohen, 1963; Gödel, 1940): CH is independent of ZFC. Neither CH nor ¬CH can be proved from the axioms of ZFC (assuming ZFC is consistent).

Notation Guide

  • \(\aleph_0\) — Cardinality of natural numbers
  • \(\aleph_1\) — First uncountable cardinal
  • \(\mathfrak{c} = 2^{\aleph_0}\) — Cardinality of the continuum
  • \(M[G]\) — Forcing extension

Topos Theory: A Categorical Foundation for Mathematics

topos-theory

Historical Context

Topos theory emerged from the work of Alexander Grothendieck in algebraic geometry during the 1960s. Later, William Lawvere and Myles Tierney realized that Grothendieck's definition could be axiomatized categorically, leading to elementary topos theory.

Definitions

  • Elementary Topos: A category \(\mathcal{E}\) with: (1) all finite limits, (2) exponentials, (3) a subobject classifier \(\Omega\).
  • Subobject Classifier: An object \(\Omega\) with a morphism \(\text{true}: 1 \to \Omega\) classifying monomorphisms.

Theorem: Fundamental Properties

Theorem: Every elementary topos is cartesian closed, has all finite colimits, and the subobject classifier \(\Omega\) is an internal Heyting algebra, giving intuitionistic internal logic.

Notation Guide

  • \(\mathcal{E}\) — Elementary topos
  • \(\Omega\) — Subobject classifier
  • \(Y^X\) — Exponential (function object)

Complex Dynamics: The Mandelbrot Set and Julia Sets

complex-dynamics

Historical Context

Complex dynamics studies the iteration of analytic functions. The field has roots in the work of Pierre Fatou and Gaston Julia in the early 20th century. In the late 1970s, Benoit Mandelbrot discovered and popularized the Mandelbrot set—a set of extraordinary complexity arising from the simple iteration \(z \mapsto z^2 + c\).

Definitions

  • Julia Set \(J_c\): The boundary of the filled Julia set \(K_c = \{z : f_c^n(z) \not\to \infty\}\) where \(f_c(z) = z^2 + c\).
  • Mandelbrot Set \(M\): \(\{c \in \mathbb{C} : J_c \text{ is connected}\}\).

Theorem: Connectivity of Julia Sets

Theorem (Fatou-Julia): The Julia set \(J_c\) is connected if and only if the orbit of the critical point \(0\) is bounded. The Julia set is a Cantor set if and only if the orbit of \(0\) escapes to infinity.

Theorem (Douady-Hubbard): The Mandelbrot set \(M\) is connected.

Notation Guide

  • \(f_c(z) = z^2 + c\) — Quadratic polynomial
  • \(J_c\) — Julia set for parameter \(c\)
  • \(M\) — Mandelbrot set

Arithmetic Dynamics: Heights and Canonical Heights

arithmetic-dynamics

Historical Context

Arithmetic dynamics blends number theory with dynamical systems. The field gained momentum in the 1990s through the work of Silverman, Call, and others who developed the theory of canonical heights—a tool that measures the arithmetic complexity of points in dynamical systems.

Definitions

  • Weil Height: For \(x = a/b \in \mathbb{Q}\), \(h(x) = \log\max(|a|, |b|)\).
  • Canonical Height: \(\hat{h}_\phi(P) = \lim_{n \to \infty} \frac{h(\phi^n(P))}{d^n}\) for a morphism \(\phi\) of degree \(d\).

Theorem: Properties of Canonical Height

Theorem (Call-Silverman): The canonical height satisfies: (1) \(\hat{h}_\phi(\phi(P)) = d \cdot \hat{h}_\phi(P)\), (2) Northcott property, (3) \(\hat{h}_\phi(P) = 0\) iff \(P\) is preperiodic.

Notation Guide

  • \(h(P)\) — Weil height
  • \(\hat{h}_\phi(P)\) — Canonical height
  • \(\phi^n\) — n-fold iterate

📜 Math History: The Development of Modern Set Theory

The late 19th and early 20th centuries witnessed a profound transformation in the foundations of mathematics, driven largely by the development of set theory. Georg Cantor's groundbreaking work on infinite sets, beginning in the 1870s, opened up entirely new realms of mathematical inquiry while simultaneously exposing deep paradoxes that would challenge mathematicians for generations.

Cantor's initial motivation came from studying trigonometric series, but his investigations soon led him to consider the nature of infinity itself. He proved that the set of real numbers is strictly larger than the set of natural numbers—a result that shocked the mathematical community. The existence of different sizes of infinity, which Cantor called "transfinite" cardinal numbers, contradicted the prevailing view that infinity was merely a potential concept rather than an actual mathematical object.

The Continuum Hypothesis, which Cantor formulated in 1878, asked whether there exists a set whose cardinality is strictly between that of the integers and the real numbers. Cantor spent years attempting to prove this hypothesis, suffering periods of depression during his quest. The problem would remain open for nearly a century, ultimately proving to be independent of the standard axioms of set theory.

The early 20th century brought both consolidation and crisis. Ernst Zermelo's 1908 axiomatization of set theory provided a rigorous foundation, later refined by Abraham Fraenkel and Thoralf Skolem into what we now call Zermelo-Fraenkel set theory (ZF). However, this period also saw the discovery of paradoxes—most notably Russell's paradox, which showed that naive set comprehension leads to contradictions.

Kurt Gödel's incompleteness theorems of 1931 demonstrated fundamental limitations of any sufficiently powerful formal system. Yet Gödel also made positive contributions to set theory: in 1940, he proved that the Continuum Hypothesis is consistent with ZFC (ZF with the Axiom of Choice). This showed that CH cannot be disproved from the standard axioms.

The final resolution came in 1963 when Paul Cohen, then a young mathematician at Stanford, developed the technique of forcing. This revolutionary method allowed Cohen to prove that the negation of CH is also consistent with ZFC, establishing that CH is independent of the standard axioms. Cohen's work earned him the Fields Medal in 1966—the only Fields Medal ever awarded for work in mathematical logic.

Forcing has since become one of the most important tools in set theory, enabling the construction of models with diverse properties. It has been used to establish the independence of numerous statements from ZFC, including the Axiom of Choice itself (relative to ZF). The technique has found applications throughout mathematics, from topology to analysis.

Today, set theory continues to evolve. Large cardinal axioms, which assert the existence of extremely large infinite cardinals, provide a hierarchy of increasingly strong extensions of ZFC. Inner model theory and descriptive set theory offer deep insights into the structure of definable sets of real numbers. The search for new axioms that might resolve CH and other independent statements remains an active area of research, with connections to physics, computer science, and philosophy.

🎯 Problem Corner

IMO Shortlist 2005 Problem N5

Problem: Let \(a\), \(b\) be positive integers such that \(a^n + n\) divides \(b^n + n\) for all positive integers \(n\). Prove that \(a = b\).

Hint

Consider what happens when \(n = a^k - a\) for large \(k\). Show that if \(a < b\), you can find an \(n\) that violates the divisibility condition.

Solution

Assume without loss of generality that \(a \leq b\). Suppose for contradiction that \(a < b\).

Choose a prime \(p\) such that \(p > b\). By Dirichlet's theorem on arithmetic progressions, there are infinitely many primes of the form \(p = ka + 1\). Let \(n = p - a\), so \(n \equiv -a \pmod{p}\) and thus \(a + n \equiv 0 \pmod{p}\).

This means \(a^n + n \equiv 0 + n \equiv -a \pmod{p}\). Actually, let's try a different approach.

Let \(n = a^k - a\) for large \(k\). Then \(a^n + n = a^{a^k - a} + a^k - a\).

Note that \(a^n + n = a^{a^k - a} + a^k - a\). For this to divide \(b^n + n\), we need:

\[a^{a^k - a} + a^k - a \mid b^{a^k - a} + a^k - a\]

For large \(k\), the term \(a^{a^k - a}\) dominates. If \(a < b\), then \(b^{a^k - a}\) grows much faster than \(a^{a^k - a}\), but we need divisibility.

Consider \(n = p - a\) where \(p\) is a large prime. Then \(a^n + n = a^{p-a} + p - a\). By Fermat's Little Theorem, \(a^{p-a} \equiv a^{-a} \pmod{p}\) (if \(p \nmid a\)).

A cleaner approach: Let \(p\) be a prime with \(p > \max(a, b)\) and \(p \nmid a\). Choose \(n = p(a-1)\). Then:

\[a^n + n = a^{p(a-1)} + p(a-1) \equiv 1 + p(a-1) \pmod{p^2}\]

using the lifting the exponent lemma or properties of orders.

Actually, the standard solution uses: Let \(p\) be a prime divisor of \(b - a\). Choose \(n = p^k - a\) for large \(k\). Then \(a + n = p^k\), so \(p^k \mid a^n + n\).

We need \(p^k \mid b^n + n\) as well. But \(b^n + n = b^{p^k - a} + p^k - a\). Since \(b \equiv a \pmod{p}\), we have \(b^{p^k - a} \equiv a^{p^k - a} \pmod{p}\).

For large \(k\), one can show this leads to a contradiction unless \(a = b\).

The complete rigorous proof requires careful analysis of \(p\)-adic valuations and the Lifting The Exponent (LTE) lemma.

📊 Visualization of the Day: p-adic Integers as Fractals

The p-adic integers have a remarkable topological structure that can be visualized as a fractal tree. Unlike real numbers, which form a continuum, p-adic numbers have a totally disconnected topology where each open ball is also closed.

The visualization shows the 2-adic integers \(\mathbb{Z}_2\) as an infinite binary tree. Each node at level \(n\) represents a congruence class modulo \(2^n\). The root represents \(\mathbb{Z}_2\) itself. The two children of each node represent the two possible extensions to the next level of precision.

This tree structure reflects the ultrametric property: every point in a ball is its center. In \(\mathbb{Z}_2\), the ball of radius \(1/2^n\) around any point contains exactly \(2^n\) elements, forming a complete binary subtree.

Python Code: Visualizing p-adic Tree Structure

import matplotlib.pyplot as plt
import matplotlib.patches as patches

def draw_padic_tree(ax, x, y, width, height, level, max_level, p=2):
    """
    Draw p-adic integer tree visualization.
    """
    if level > max_level:
        return
    
    # Draw node
    circle = patches.Circle((x, y), height/10, fill=True, 
                             facecolor='lightblue', edgecolor='navy')
    ax.add_patch(circle)
    
    if level < max_level:
        # Draw p children
        child_width = width / p
        for i in range(p):
            child_x = x - width/2 + child_width * (i + 0.5)
            child_y = y - height
            
            # Draw edge
            ax.plot([x, child_x], [y, child_y], 'navy', linewidth=1)
            
            # Recursively draw child
            draw_padic_tree(ax, child_x, child_y, child_width, height, 
                          level + 1, max_level, p)

# Create visualization
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# 2-adic tree
ax1 = axes[0]
