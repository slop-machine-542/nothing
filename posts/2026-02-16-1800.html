Pure Math Deep-Dives

1. Cauchy-Riemann Equations and Analyticity

Motivation: What makes complex differentiability so much stronger than real differentiability? The Cauchy-Riemann equations reveal the hidden structure.

Definitions

  • Complex derivative:\(f'(z) = \lim_{h \to 0} \frac{f(z+h) - f(z)}{h}\)
  • Analytic (holomorphic):\(f\) is differentiable at every point in a neighborhood
  • Entire: Analytic on all of \(\mathbb{C}\)

Theorem (Cauchy-Riemann)

For \(f(z) = u(x,y) + iv(x,y)\) with \(z = x + iy\), if \(f\) is differentiable at \(z_0\), then:

\[\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}\]

Conversely, if these hold and partials are continuous, then \(f\) is differentiable.

Proof

Taking \(h = \Delta x\) (real): \[f'(z) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x}\] Taking \(h = i\Delta y\) (purely imaginary): \[f'(z) = -i\frac{\partial u}{\partial y} + \frac{\partial v}{\partial y}\] Equating real and imaginary parts gives the Cauchy-Riemann equations. \(\square\)

Notation Guide

  • \(\frac{\partial f}{\partial \bar{z}} = 0\): Cauchy-Riemann in complex form
  • \(\Delta u = 0\): Laplace's equation (harmonic functions)
  • \(\mathbb{H}\): Upper half-plane

Python Code

import numpy as np
import matplotlib.pyplot as plt

def check_cauchy_riemann(u, v, x, y, dx=1e-6, dy=1e-6):
    """
    Numerically verify Cauchy-Riemann equations at point (x, y).
    u, v are functions of (x, y).
    """
    # Partial derivatives
    du_dx = (u(x + dx, y) - u(x, y)) / dx
    du_dy = (u(x, y + dy) - u(x, y)) / dy
    dv_dx = (v(x + dx, y) - v(x, y)) / dx
    dv_dy = (v(x, y + dy) - v(x, y)) / dy
    
    # Cauchy-Riemann equations
    cr1 = np.abs(du_dx - dv_dy)
    cr2 = np.abs(du_dy + dv_dx)
    
    return {
        'du_dx': du_dx,
        'dv_dy': dv_dy,
        'du_dy': du_dy,
        'dv_dx': dv_dx,
        'cr1_error': cr1,
        'cr2_error': cr2,
        'satisfied': cr1 < 1e-4 and cr2 < 1e-4
    }

# Example: f(z) = z^2 = (x^2 - y^2) + i(2xy)
def u_z2(x, y):
    return x**2 - y**2

def v_z2(x, y):
    return 2*x*y

result = check_cauchy_riemann(u_z2, v_z2, 1.0, 2.0)
print("Cauchy-Riemann check for f(z) = z^2 at (1, 2):")
print(f"du/dx = {result['du_dx']:.4f}, dv/dy = {result['dv_dy']:.4f}")
print(f"du/dy = {result['du_dy']:.4f}, dv/dx = {result['dv_dx']:.4f}")
print(f"CR satisfied: {result['satisfied']}")

# Example: f(z) = |z|^2 = x^2 + y^2 (NOT analytic)
def u_abs_sq(x, y):
    return x**2 + y**2

def v_abs_sq(x, y):
    return 0

result2 = check_cauchy_riemann(u_abs_sq, v_abs_sq, 1.0, 2.0)
print("\nCauchy-Riemann check for f(z) = |z|^2 at (1, 2):")
print(f"CR satisfied: {result2['satisfied']} (expected: False)")

2. Cauchy's Integral Theorem and Formula

Motivation: The values of an analytic function inside a region are completely determined by its values on the boundary—a remarkable rigidity property.

Definitions

  • Contour integral:\(\oint_\gamma f(z) dz\)
  • Simply connected:\(\gamma\) can be continuously contracted to a point
  • Winding number:\(n(\gamma, a) = \frac{1}{2\pi i}\oint_\gamma \frac{dz}{z-a}\)

Theorem (Cauchy's Integral Formula)

If \(f\) is analytic inside and on a simple closed contour \(\gamma\), then for \(a\) inside \(\gamma\):

\[f(a) = \frac{1}{2\pi i} \oint_\gamma \frac{f(z)}{z-a} dz\]

Moreover: \[f^{(n)}(a) = \frac{n!}{2\pi i} \oint_\gamma \frac{f(z)}{(z-a)^{n+1}} dz\]

Proof Sketch

Consider a small circle \(C_r\) around \(a\). By deformation of contours: \[\oint_\gamma \frac{f(z)}{z-a}dz = \oint_{C_r} \frac{f(z)}{z-a}dz\] As \(r \to 0\), \(f(z) \to f(a)\) uniformly, so: \[\oint_{C_r} \frac{f(z)}{z-a}dz \approx f(a)\oint_{C_r} \frac{dz}{z-a} = 2\pi i f(a)\]

Python Code

import numpy as np

def contour_integral(f, gamma, t_range, n_points=10000):
    """
    Numerically compute contour integral of f along gamma.
    gamma: function mapping t to complex point
    """
    t = np.linspace(t_range[0], t_range[1], n_points)
    dt = t[1] - t[0]
    
    z = gamma(t)
    dz = np.gradient(z, dt)
    
    integral = np.trapezoid(f(z) * dz, t)
    return integral

# Verify Cauchy's integral formula for f(z) = z^2
# Circle of radius R centered at origin
def circle(t, R=1, center=0):
    return center + R * np.exp(2j * np.pi * t)

def f(z):
    return z**2

# Integral of f(z)/(z-a) around circle
# Should equal 2*pi*i * f(a) for a inside
def integrand_factory(a):
    return lambda z: f(z) / (z - a)

# Test with a = 0.5 (inside unit circle)
a = 0.5
integral = contour_integral(integrand_factory(a), lambda t: circle(t, R=1), (0, 1))
theoretical = 2j * np.pi * f(a)

print(f"Numerical integral: {integral:.6f}")
print(f"Theoretical value:  {theoretical:.6f}")
print(f"Error: {abs(integral - theoretical):.2e}")

# Test with a = 2 (outside unit circle) - should be ~0
a = 2.0
integral = contour_integral(integrand_factory(a), lambda t: circle(t, R=1), (0, 1))
print(f"\nFor a outside: {integral:.2e} (should be ~0)")

3. Residue Theory

Motivation: How do we compute difficult real integrals? Residue theory provides a powerful method by relating them to complex contour integrals.

Definitions

  • Isolated singularity:\(f\) analytic in punctured disk \(0 < |z-a| < r\)
  • Laurent series:\(f(z) = \sum_{n=-\infty}^{\infty} c_n (z-a)^n\)
  • Residue:\(\text{Res}(f, a) = c_{-1}\)
  • Simple pole:\(f(z) = \frac{g(z)}{z-a}\) with \(g(a) \neq 0\)

Theorem (Residue Theorem)

If \(f\) is analytic inside and on a simple closed contour \(\gamma\) except for isolated singularities \(a_1, \ldots, a_n\) inside \(\gamma\), then:

\[\oint_\gamma f(z) dz = 2\pi i \sum_{k=1}^n \text{Res}(f, a_k)\]

Proof Sketch

Deform \(\gamma\) to small circles around each singularity. By Cauchy's theorem, the integral equals the sum of integrals around each small circle. Each such integral equals \(2\pi i \cdot c_{-1} = 2\pi i \cdot \text{Res}(f, a_k)\). \(\square\)

Python Code

import numpy as np
from scipy import integrate

def compute_residue_simple_pole(f, g, a, h=1e-8):
    """
    Compute residue at simple pole a where f(z) = g(z)/(z-a).
    Res(f, a) = g(a).
    """
    return g(a)

def compute_residue_laurent(f, a, R=0.1, n_points=10000):
    """
    Compute residue using integral formula.
    Res(f, a) = (1/2πi) ∮ f(z) dz around a.
    """
    theta = np.linspace(0, 2*np.pi, n_points)
    z = a + R * np.exp(1j * theta)
    dz = 1j * R * np.exp(1j * theta) * (theta[1] - theta[0])
    
    integral = np.trapezoid(f(z), theta) * 1j * R
    residue = integral / (2j * np.pi)
    return residue

# Example: f(z) = 1/(z^2 + 1) = 1/((z-i)(z+i))
# Poles at z = i and z = -i
def f_example(z):
    return 1 / (z**2 + 1)

# Residue at z = i
def g_i(z):
    return 1 / (z + 1j)
residue_i = compute_residue_simple_pole(f_example, g_i, 1j)
print(f"Residue at z = i: {residue_i:.6f}")
print(f"Expected: -i/2 = {-0.5j:.6f}")

# Residue at z = -i
def g_minus_i(z):
    return 1 / (z - 1j)
residue_minus_i = compute_residue_simple_pole(f_example, g_minus_i, -1j)
print(f"Residue at z = -i: {residue_minus_i:.6f}")
print(f"Expected: i/2 = {0.5j:.6f}")

# Verify using numerical integration
residue_i_num = compute_residue_laurent(f_example, 1j, R=0.5)
print(f"\nNumerical verification at z = i: {residue_i_num:.6f}")

1. Conformal Mapping and Applications

Real-world motivation: Conformal maps preserve angles and transform harmonic functions to harmonic functions, making them invaluable for solving Laplace's equation in complex geometries.

Definitions

  • Conformal map:\(f\) is analytic with \(f'(z) \neq 0\) (preserves angles)
  • Harmonic function:\(\Delta u = 0\)
  • Riemann Mapping Theorem: Any simply connected domain (not \(\mathbb{C}\)) can be conformally mapped to the unit disk

Theorem (Preservation of Harmonic Functions)

If \(u\) is harmonic and \(f\) is analytic, then \(u \circ f\) is harmonic.

Proof

Locally, \(u = \text{Re}(g)\) for some analytic \(g\). Then \(u \circ f = \text{Re}(g \circ f)\), which is the real part of an analytic function, hence harmonic. \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mobius_transform(z, a, b, c, d):
    """
    Möbius transformation: f(z) = (az + b) / (cz + d).
    """
    return (a * z + b) / (c * z + d)

def joukowsky_transform(z):
    """
    Joukowsky transform: maps circle to airfoil shape.
    f(z) = z + 1/z
    """
    return z + 1/z

def visualize_conformal_map(f, z_range=(-2, 2), n_grid=50):

2. Signal Processing and the Fourier Transform

Real-world motivation: The Fourier transform decomposes signals into frequencies, enabling compression, filtering, and spectral analysis. Complex analysis provides the theoretical foundation.

Definitions

  • Fourier transform:\(\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x)e^{-2\pi i x \xi} dx\)
  • Z-transform:\(X(z) = \sum_{n=-\infty}^{\infty} x[n]z^{-n}\)
  • Region of Convergence (ROC):\(\{z : X(z) \text{ converges}\}\)

Theorem (Paley-Wiener)

A function \(f\) is the Fourier transform of a compactly supported function if and only if it extends to an entire function of exponential type satisfying \(|f(z)| \leq Ce^{2\pi R|Im(z)|}\).

Python Code

import numpy as np
import matplotlib.pyplot as plt
from numpy.fft import fft, fftfreq, ifft

def analyze_signal_fft(signal, sample_rate):
    """
    Perform FFT analysis of a signal.
    """
    n = len(signal)
    freqs = fftfreq(n, 1/sample_rate)
    spectrum = fft(signal)
    
    return freqs[:n//2], np.abs(spectrum)[:n//2]

def design_lowpass_filter(cutoff, num_taps=101, sample_rate=1.0):
    """
    Design FIR lowpass filter using window method.
    """
    # Ideal sinc filter
    n = np.arange(num_taps) - (num_taps - 1) / 2
    h = np.sinc(2 * cutoff * n / sample_rate)
    
    # Apply window
    window = np.hanning(num_taps)
    h = h * window
    
    # Normalize
    h = h / np.sum(h)
    
    return h

# Example: Analyze a signal with multiple frequencies
sample_rate = 1000
t = np.linspace(0, 1, sample_rate)
signal = (np.sin(2*np.pi*50*t) +    # 50 Hz
          0.5*np.sin(2*np.pi*120*t) +  # 120 Hz
          0.3*np.sin(2*np.pi*300*t))   # 300 Hz

# Add noise
signal_noisy = signal + 0.5*np.random.randn(len(t))

# FFT analysis
freqs, spectrum = analyze_signal_fft(signal_noisy, sample_rate)

plt.figure(figsize=(12, 8))

3. Control Theory and Stability Analysis

Real-world motivation: Control systems—from autopilots to chemical process controllers—require stability analysis. The Nyquist criterion uses complex analysis to determine stability.

Definitions

  • Transfer function:\(G(s) = \frac{Y(s)}{U(s)}\), ratio of Laplace transforms
  • Pole:\(s\) where \(G(s) = \infty\) (denominator roots)
  • BIBO stable: All poles in left half-plane (Re(s) < 0)
  • Nyquist contour:\(\Gamma\) encircling right half-plane

Theorem (Nyquist Stability Criterion)

\[N = P - Z\]

where \(N\) is the number of clockwise encirclements of -1 by \(G(\Gamma)\), \(P\) is the number of open-loop poles in RHP, and \(Z\) is the number of closed-loop poles in RHP.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy import signal

def nyquist_plot(G, omega=np.logspace(-2, 2, 1000)):
    """
    Generate Nyquist plot for transfer function G.
    G: scipy.signal.TransferFunction or callable
    """
    if isinstance(G, signal.TransferFunction):
        s = 1j * omega
        G_omega = np.polyval(G.num, s) / np.polyval(G.den, s)
    else:
        G_omega = G(1j * omega)
    
    plt.figure(figsize=(10, 8))
    
    # Plot Nyquist curve
    plt.plot(G_omega.real, G_omega.imag, 'b-', label='Nyquist curve')
    plt.plot(G_omega.real, -G_omega.imag, 'b--', alpha=0.5, label='Mirror image')
    
    # Plot critical point
    plt.plot(-1, 0, 'r+', markersize=15, label='Critical point (-1, 0)')
    
    # Unit circle for reference
    theta = np.linspace(0, 2*np.pi, 100)
    plt.plot(np.cos(theta), np.sin(theta), 'g--', alpha=0.3, label='Unit circle')
    
    plt.axhline(y=0, color='k', linewidth=0.5)
    plt.axvline(x=0, color='k', linewidth=0.5)
    plt.axis('equal')
    plt.grid(True)
    plt.xlabel('Real(G)')
    plt.ylabel('Imag(G)')
    plt.title('Nyquist Plot')
    plt.legend()
    
    plt.savefig('nyquist_plot.png', dpi=150)
    plt.show()
    
    return G_omega

def analyze_stability(num, den):
    """
    Analyze stability of transfer function.
    """
    # Find poles
    poles = np.roots(den)
    
    # Check if all poles in LHP
    is_stable = np.all(poles.real < 0)
    
    # Gain and phase margins
    sys = signal.TransferFunction(num, den)
    omega, mag, phase = signal.bode(sys)
    
    return {
        'poles': poles,
        'is_stable': is_stable,
        'omega': omega,
        'magnitude': mag,
        'phase': phase
    }

# Example: Second-order system
# G(s) = 1 / (s^2 + 2ζs + 1) with ζ = 0.5 (underdamped)
zeta = 0.5
num = [1]
den = [1, 2*zeta, 1]

analysis = analyze_stability(num, den)
print(f"Poles: {analysis['poles']}")
print(f"System is stable: {analysis['is_stable']}")

# Nyquist plot
sys = signal.TransferFunction(num, den)
nyquist_plot(sys)

# Bode plot
plt.figure(figsize=(10, 6))
plt.subplot(211)
plt.semilogx(analysis['omega'], analysis['magnitude'])
plt.title('Bode Plot')
plt.ylabel('Magnitude [dB]')
plt.grid(True)

plt.subplot(212)
plt.semilogx(analysis['omega'], analysis['phase'])
plt.xlabel('Frequency [rad/s]')
plt.ylabel('Phase [degrees]')
plt.grid(True)

plt.tight_layout()
plt.savefig('bode_plot.png', dpi=150)
plt.show()

1. The Riemann Mapping Theorem

Historical context: Riemann stated this theorem in his 1851 PhD thesis, but his proof had gaps. Carathéodory and Koebe gave rigorous proofs around 1912. The theorem remains one of the most profound results in complex analysis.

Definitions

  • Simply connected:\(\mathbb{C} \setminus U\) is connected
  • Conformal equivalence:\(f: U \to V\) bijective and conformal
  • Automorphism group:\(\text{Aut}(U)\) = conformal self-maps of \(U\)

Theorem (Riemann Mapping Theorem)

Any simply connected proper subset \(U \subsetneq \mathbb{C}\) is conformally equivalent to the unit disk \(\mathbb{D}\).

Proof Sketch

Normalize so \(a \in U\) maps to 0. Consider the family \(\mathcal{F}\) of injective analytic functions \(f: U \to \mathbb{D}\) with \(f(a) = 0\). Show \(\mathcal{F}\) is normal (Montel's theorem). Use a maximizing sequence for \(|f'(a)|\) and show the limit is the desired conformal map. \(\square\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

def schwarz_christoffel_disk_to_polygon(n_vertices=5):
    """
    Schwarz-Christoffel transformation from disk to regular polygon.
    Approximate implementation.
    """
    # For regular n-gon, prevertices are roots of unity
    # S-C integral: f(z) = A + C ∫ ∏(w - z_k)^{α_k - 1} dw
    
    def sc_transform(z, n):
        """Approximate S-C transform for regular n-gon."""
        # Simplified: use power series approximation
        result = z
        for k in range(1, 5):
            result += 0.1 * z**(k*n + 1) / (k*n + 1)
        return result
    
    return sc_transform

def visualize_riemann_map():
    """
    Visualize a simple conformal map to demonstrate RMT.
    """
    # Map upper half-plane to unit disk
    # f(z) = (z - i) / (z + i)
    
    x = np.linspace(-5, 5, 100)
    y = np.linspace(0.1, 5, 50)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Cayley transform: H -> D
    W = (Z - 1j) / (Z + 1j)
    
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))
    
    # Upper half-plane
    axes[0].plot(X, Y, 'b-', alpha=0.3)
    axes[0].plot(X.T, Y.T, 'r-', alpha=0.3)
    axes[0].axhline(y=0, color='k', linewidth=2)
    axes[0].set_xlim(-5, 5)
    axes[0].set_ylim(-1, 5)
    axes[0].set_aspect('equal')
    axes[0].set_title('Upper Half-Plane')
    axes[0].set_xlabel('Re(z)')
    axes[0].set_ylabel('Im(z)')
    
    # Unit disk
    axes[1].plot(W.real, W.imag, 'b-', alpha=0.3)
    axes[1].plot(W.real.T, W.imag.T, 'r-', alpha=0.3)
    circle = np.exp(1j * np.linspace(0, 2*np.pi, 100))

2. Elliptic Functions and Modular Forms

Historical context: Elliptic integrals arose from attempts to calculate arc lengths of ellipses. Abel and Jacobi inverted these integrals in the 1820s, creating elliptic function theory. Modular forms emerged from the study of elliptic functions and became central to modern number theory, culminating in Wiles's proof of Fermat's Last Theorem.

Definitions

  • Elliptic function: Doubly periodic meromorphic function
  • Weierstrass ℘-function:\(\wp(z) = \frac{1}{z^2} + \sum_{\omega \neq 0} \left(\frac{1}{(z-\omega)^2} - \frac{1}{\omega^2}\right)\)
  • Modular discriminant:\(\Delta(\tau) = g_2^3 - 27g_3^2\)
  • Dedekind eta function:\(\eta(\tau) = e^{\pi i \tau/12} \prod_{n=1}^{\infty}(1 - e^{2\pi i n \tau})\)

Theorem (Modularity of the Discriminant)

\[\Delta\left(\frac{a\tau + b}{c\tau + d}\right) = (c\tau + d)^{12}\Delta(\tau)\]

for \(\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in SL_2(\mathbb{Z})\).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def weierstrass_p(z, omega1=1, omega2=1j, n_terms=50):
    """
    Approximate Weierstrass p-function.
    p(z) = 1/z^2 + sum_{omega != 0} [1/(z-omega)^2 - 1/omega^2]
    """
    # Generate lattice points
    lattice_points = []
    for m in range(-n_terms, n_terms+1):
        for n in range(-n_terms, n_terms+1):
            if m == 0 and n == 0:
                continue
            omega = m * omega1 + n * omega2
            lattice_points.append(omega)
    
    # Compute series
    result = 1 / z**2 if z != 0 else np.inf
    for omega in lattice_points:
        if abs(z - omega) > 1e-10:
            result += 1 / (z - omega)**2 - 1 / omega**2
    
    return result

def j_invariant(tau, n_terms=20):
    """
    Compute modular j-invariant j(τ).
    j(τ) = 1728 * g2^3 / (g2^3 - 27*g3^2)
    """
    # Compute Eisenstein series
    g2 = 0
    g3 = 0
    for m in range(-n_terms, n_terms+1):
        for n in range(-n_terms, n_terms+1):
            if m == 0 and n == 0:
                continue
            omega = m + n * tau
            g2 += 1 / omega**4
            g3 += 1 / omega**6
    
    g2 = 60 * g2
    g3 = 140 * g3
    
    delta = g2**3 - 27 * g3**2
    if abs(delta) > 1e-10:
        j = 1728 * g2**3 / delta
    else:
        j = np.inf
    
    return j

3. Value Distribution Theory (Nevanlinna Theory)

Historical context: Rolf Nevanlinna developed his theory of meromorphic functions in the 1920s, providing a quantitative refinement of Picard's theorem. The theory became fundamental to complex dynamics and has recent connections to Diophantine approximation (Vojta's dictionary).

Definitions

  • Characteristic function:\(T(r, f) = m(r, f) + N(r, f)\)
  • Proximity function:\(m(r, a) = \frac{1}{2\pi} \int_0^{2\pi} \log^+\left|\frac{1}{f(re^{i\theta}) - a}\right| d\theta\)
  • Counting function:\(N(r, a)\) = weighted count of \(a\)-points

Theorem (First Main Theorem)

\[m(r, a) + N(r, a) = T(r, f) + O(1)\]

4. Complex Dynamics and the Mandelbrot Set

Historical context: Julia and Fatou studied iteration of rational functions in the 1910s-20s. The subject was revived in the 1980s with computer visualizations. Mandelbrot's eponymous set, introduced in 1980, became an icon of chaos theory and popular mathematics.

Definitions

  • Julia set:\(J(f) = \partial\{z : f^n(z) \not\to \infty\}\)

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot_set(xmin=-2.5, xmax=1.5, ymin=-2, ymax=2, 
                   width=800, height=800, max_iter=100):
    """
    Compute Mandelbrot set.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j * Y
    
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[mask] = i
    
    return M

def julia_set(c=-0.7 + 0.27015j, xmin=-2, xmax=2, ymin=-2, ymax=2,
              width=800, height=800, max_iter=100):
    """
    Compute Julia set for f(z) = z^2 + c.
    """
    x = np.linspace(xmin, xmax, width)

Math History

Complex numbers emerged from the algebraic need to solve cubic equations. Cardano's "Ars Magna" (1545) presented methods that produced square roots of negative numbers as intermediate steps, even when final answers were real. Bombelli's "L'Algebra" (1572) first systematically treated these quantities, but they remained suspect until the geometric interpretation emerged.

Wallis, Argand, Gauss, and Wessel independently discovered that complex numbers could be represented as points in a plane—the complex plane. Gauss's proof of the Fundamental Theorem of Algebra (1799) demonstrated the power of complex methods. Cauchy's work in the 1810s-50s established the foundations of complex analysis: his integral theorem, integral formula, and residue calculus transformed the field.

The late 19th century brought Riemann's geometric approach and Weierstrass's emphasis on power series. Riemann surfaces unified multi-valued functions, while the uniformization theorem connected complex analysis to differential geometry. The 20th century saw complex analysis influence number theory (modular forms, L-functions), algebraic geometry (sheaves, cohomology), and physics (conformal field theory, string theory).

Today, complex analysis remains essential across mathematics and its applications. The Riemann Hypothesis, perhaps the most famous unsolved problem in mathematics, concerns the zeros of the Riemann zeta function—a central object in complex analysis. From pure mathematics to signal processing, fluid dynamics to quantum field theory, the magic of complex numbers continues to reveal deep connections and provide powerful tools.

Problem Corner

Problem (Putnam 2014 A4): Let \(n\) be a positive integer. Show that \[\int_0^{2\pi} \cos(x)\cos(2x)\cdots\cos(nx) \, dx = \frac{\pi}{2^{n-1}}\] where the left-hand side is interpreted as the number of ways to choose a subset of \(\{1, 2, \ldots, n\}\) with sum equal to half the total sum.

Hint

Use the identity \(\cos(kx) = \frac{e^{ikx} + e^{-ikx}}{2}\) and convert to a contour integral around the unit circle.

Solution

Using Euler's formula: \[\cos(kx) = \frac{e^{ikx} + e^{-ikx}}{2}\]

The product becomes: \[\prod_{k=1}^n \cos(kx) = \frac{1}{2^n} \prod_{k=1}^n (e^{ikx} + e^{-ikx}) = \frac{1}{2^n} \sum_{S \subseteq [n]} e^{ix(\sum_{k \in S} k - \sum_{k \notin S} k)}\]

Let \(\sigma = \sum_{k=1}^n k = \frac{n(n+1)}{2}\). Then: \[\sum_{k \in S} k - \sum_{k \notin S} k = 2\sum_{k \in S} k - \sigma\]

So the integral becomes: \[\frac{1}{2^n} \sum_{S \subseteq [n]} \int_0^{2\pi} e^{ix(2\sum_{k \in S} k - \sigma)} dx\]

The integral is \(2\pi\) when \(2\sum_{k \in S} k = \sigma\) (i.e., when the subset sum equals half the total), and 0 otherwise.

For the total sum to have a subset equal to half, we need \(\sigma\) to be even, i.e., \(n(n+1)/2\) even, which happens when \(n \equiv 0, 3 \pmod{4}\).

When such subsets exist, let \(N\) be their count. The answer is \(\frac{2\pi N}{2^n} = \frac{\pi N}{2^{n-1}}\).

It can be shown that \(N = 1\) when the condition is satisfied, giving \(\boxed{\dfrac{\pi}{2^{n-1}}}\) for \(n \equiv 0, 3 \pmod{4}\) and \(0\) otherwise.

import numpy as np
import matplotlib.pyplot as plt

def visualize_complex_exponential():
    """
    Visualize the complex exponential function.
    """
    # Create grid in z-plane
    x = np.linspace(-2, 2, 100)
    y = np.linspace(-2*np.pi, 2*np.pi, 200)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Apply exponential
    W = np.exp(Z)
    
    fig, axes = plt.subplots(2, 2, figsize=(14, 12))
    
    # Original grid
    ax1 = axes[0, 0]
    for y_val in np.linspace(-2*np.pi, 2*np.pi, 9):
        ax1.plot(x, [y_val]*len(x), 'b-', alpha=0.5)
    for x_val in np.linspace(-2, 2, 9):
        ax1.plot([x_val]*len(y), y, 'r-', alpha=0.5)
    ax1.set_xlim(-2.5, 2.5)
    ax1.set_ylim(-7, 7)
    ax1.set_aspect('equal')
    ax1.set_title('z-plane: Grid Lines')
    ax1.set_xlabel('Re(z)')
    ax1.set_ylabel('Im(z)')
    
    # Image under exp
    ax2 = axes[0, 1]
    for y_val in np.linspace(-2*np.pi, 2*np.pi, 9):
        z_line = x + 1j * y_val
        w_line = np.exp(z_line)
        ax2.plot(w_line.real, w_line.imag, 'b-', alpha=0.5)
    for x_val in np.linspace(-2, 2, 9):
        z_line = x_val + 1j * y
        w_line = np.exp(z_line)
        ax2.plot(w_line.real, w_line.imag, 'r-', alpha=0.5)
    ax2.set_xlim(-8, 8)
    ax2.set_ylim(-8, 8)
    ax2.set_aspect('equal')
    ax2.set_title('w-plane: w = e^z')
    ax2.set_xlabel('Re(w)')
    ax2.set_ylabel('Im(w)')
    
    # Domain coloring of exp(z)
    ax3 = axes[1, 0]
    magnitude = np.abs(W)
    phase = np.angle(W)
    
    # Use HSV coloring: hue = phase, value = magnitude
    from matplotlib.colors import hsv_to_rgb
    hsv = np.zeros((*W.shape, 3))
    hsv[:, :, 0] = (phase + np.pi) / (2 * np.pi)  # Hue
    hsv[:, :, 1] = 1  # Saturation
    hsv[:, :, 2] = np.tanh(magnitude / 5)  # Value
    rgb = hsv_to_rgb(hsv)
    
    ax3.imshow(rgb, extent=[-2, 2, -2*np.pi, 2*np.pi], origin='lower', aspect='auto')
    ax3.set_title('Domain Coloring of e^z')
    ax3.set_xlabel('Re(z)')
    ax3.set_ylabel('Im(z)')
    
    # Magnitude surface
    ax4 = axes[1, 1]
    contour = ax4.contourf(X, Y, np.log(magnitude + 1), levels=20, cmap='viridis')
    plt.colorbar(contour, ax=ax4, label='log|e^z|')
    ax4.set_title('log|e^z| = Re(z)')
    ax4.set_xlabel('Re(z)')
    ax4.set_ylabel('Im(z)')
    
    plt.tight_layout()
    plt.savefig('complex_exponential.png', dpi=150)
    plt.show()
