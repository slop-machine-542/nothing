1. Cohomology Operations: Steenrod Squares and Beyond

Tags: cohomology-operations algebraic-topology steenrod-squares

Motivation

Cohomology groups provide algebraic invariants of topological spaces, but they often fail to distinguish between spaces with isomorphic cohomology groups. Cohomology operations, introduced by Norman Steenrod in the 1940s, provide additional structure that can detect finer distinctions. These natural transformations between cohomology functors have become fundamental tools in algebraic topology, with applications to characteristic classes, obstruction theory, and the study of manifolds.

Definitions

Let \(H^*(X; R)\) denote singular cohomology with coefficients in a ring \(R\). A cohomology operation of type \((n, m, G, G')\) is a natural transformation \(\theta: H^n(-; G) \to H^m(-; G')\).

The Steenrod squares are cohomology operations \(\text{Sq}^i: H^n(X; \mathbb{Z}_2) \to H^{n+i}(X; \mathbb{Z}_2)\) satisfying:

  • \(\text{Sq}^0 = \text{id}\) (identity)
  • \(\text{Sq}^i(x) = x^2\) when \(i = |x|\) (cup product square)
  • \(\text{Sq}^i(x) = 0\) when \(i > |x|\)
  • \(\text{Sq}^i(x \smile y) = \sum_{j=0}^{i} \text{Sq}^j(x) \smile \text{Sq}^{i-j}(y)\) (Cartan formula)

The Adem relations provide relations among Steenrod squares: for \(a < 2b\): \[\text{Sq}^a \text{Sq}^b = \sum_{c=0}^{\lfloor a/2 \rfloor} \binom{b-c-1}{a-2c} \text{Sq}^{a+b-c} \text{Sq}^c\]

Theorem and Proof

Theorem (Wu Formula): Let \(M\) be a smooth closed \(n\)-manifold with Stiefel-Whitney classes \(w_i\) and Wu classes \(v_j\). Then: \[\text{Sq}^i(v_j) = \sum_{k=0}^{i} \binom{j-i+k-1}{k} v_{i-k} \smile v_{j+k}\]

Proof Sketch: The Wu classes are defined by the property that for all \(x \in H^{n-i}(M; \mathbb{Z}_2)\): \[\text{Sq}^i(x) = v_i \smile x\]

Applying the Cartan formula to \(\text{Sq}^i(v_j \smile x)\) and using the definition of Wu classes: \[\text{Sq}^i(v_j \smile x) = \sum_{k=0}^{i} \text{Sq}^k(v_j) \smile \text{Sq}^{i-k}(x) = \sum_{k=0}^{i} \text{Sq}^k(v_j) \smile v_{i-k} \smile x\]

On the other hand, by definition: \[\text{Sq}^i(v_j \smile x) = v_{i+j} \smile v_j \smile x\]

Comparing coefficients and using Poincaré duality yields the Wu formula. The binomial coefficients arise from combinatorial identities involving the Steenrod algebra action. ∎

Notation Guide

  • \(\text{Sq}^i\) — Steenrod square of degree \(i\)
  • \(\mathcal{A}_2\) — Steenrod algebra over \(\mathbb{Z}_2\)
  • \(v_i\) — Wu class of degree \(i\)
  • \(w_i\) — Stiefel-Whitney class of degree \(i\)
  • \(x \smile y\) — Cup product
  • \(\beta\) — Bockstein homomorphism

import numpy as np
from itertools import combinations

class SteenrodAlgebra:
    """Computational tools for Steenrod squares and cohomology operations."""
    
    @staticmethod
    def binomial_mod2(n, k):
        """Compute binomial coefficient mod 2 using Lucas' theorem."""
        # Lucas' theorem: C(n,k) mod 2 = 1 iff k & (n-k) == 0
        # Equivalently, C(n,k) is odd iff k is a submask of n
        return 1 if (k & (n - k)) == 0 else 0
    
    @staticmethod
    def adem_relation(a, b):
        """
        Apply Adem relation for Sq^a Sq^b when a < 2b.
        Returns list of (coefficient, c) for Sq^{a+b-c} Sq^c.
        """
        if a >= 2 * b:
            return [(1, 0)]  # No relation needed
        
        result = []
        for c in range(a // 2 + 1):
            # Binomial coefficient (b-c-1 choose a-2c) mod 2
            n = b - c - 1
            k = a - 2 * c
            if k < 0 or k > n:
                coeff = 0
            else:
                coeff = SteenrodAlgebra.binomial_mod2(n, k)
            
            if coeff == 1:
                result.append((coeff, c))
        
        return result
    
    @staticmethod
    def cartan_formula(i, deg_x, deg_y):
        """
        Compute Sq^i(x cup y) using Cartan formula.
        Returns list of (j, i-j) pairs for Sq^j(x) cup Sq^{i-j}(y).
        """
        result = []
        for j in range(i + 1):
            # Sq^j is nonzero on x only if j <= deg_x
            # Sq^{i-j} is nonzero on y only if i-j <= deg_y
            if j <= deg_x and (i - j) <= deg_y:
                result.append((j, i - j))
        return result
    
    @staticmethod
    def wu_class_action(i, j, n):
        """
        Compute coefficient in Wu formula for Sq^i(v_j).
        Returns coefficient of v_{i-k} cup v_{j+k}.
        """
        results = []
        for k in range(i + 1):
            # Binomial coefficient (j-i+k-1 choose k) mod 2
            n_binom = j - i + k - 1
            k_binom = k
            if k_binom < 0 or k_binom > n_binom:
                coeff = 0
            else:
                coeff = SteenrodAlgebra.binomial_mod2(n_binom, k_binom)
            if coeff == 1:
                results.append((i - k, j + k))
        return results
    
    @staticmethod
    def steenrod_square_degree(i, n):
        """
        Sq^i: H^n -> H^{n+i}.
        Returns target degree or None if operation is zero.
        """
        if i > n:
            return None  # Sq^i = 0 for i > n
        if i == n:
            return 2 * n  # Sq^n(x) = x^2
        return n + i

2. Stochastic Calculus: Itô's Lemma and Stochastic Differential Equations

Tags: stochastic-calculus ito-calculus brownian-motion

Motivation

Deterministic calculus fails to model systems subject to random fluctuations. Kiyoshi Itô's revolutionary work in the 1940s developed a calculus for stochastic processes, providing the mathematical foundation for modern finance, physics, and engineering. Stochastic calculus extends classical calculus to handle the non-differentiable paths of Brownian motion, introducing new rules and techniques that have become essential for modeling uncertainty.

Definitions

A standard Brownian motion (Wiener process) \((W_t)_{t \geq 0}\) is a continuous stochastic process satisfying:

  • \(W_0 = 0\) almost surely
  • Independent increments: \(W_t - W_s \perp \mathcal{F}_s\) for \(t > s\)
  • Gaussian increments: \(W_t - W_s \sim \mathcal{N}(0, t-s)\)
  • Continuous sample paths

The Itô integral of a predictable process \((H_t)\) with respect to Brownian motion is: \[\int_0^T H_t \, dW_t = \lim_{n \to \infty} \sum_{i=0}^{n-1} H_{t_i}(W_{t_{i+1}} - W_{t_i})\]

An Itô process has the form: \[X_t = X_0 + \int_0^t \mu_s \, ds + \int_0^t \sigma_s \, dW_s\]

Theorem and Proof

Theorem (Itô's Lemma): Let \(X_t\) be an Itô process and \(f \in C^{2,1}(\mathbb{R} \times [0, T])\). Then \(Y_t = f(X_t, t)\) is an Itô process with: \[df(X_t, t) = \frac{\partial f}{\partial t} dt + \frac{\partial f}{\partial x} dX_t + \frac{1}{2}\frac{\partial^2 f}{\partial x^2} (dX_t)^2\]

where \((dX_t)^2 = \sigma_t^2 dt\) (using the rules \(dt \cdot dt = 0\), \(dt \cdot dW_t = 0\), \(dW_t \cdot dW_t = dt\)).

Proof Sketch: Apply Taylor expansion to \(f(X_{t+\Delta t}, t+\Delta t) - f(X_t, t)\): \[\Delta f = \frac{\partial f}{\partial t}\Delta t + \frac{\partial f}{\partial x}\Delta X + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(\Delta X)^2 + \frac{\partial^2 f}{\partial t \partial x}\Delta t \Delta X + \frac{1}{2}\frac{\partial^2 f}{\partial t^2}(\Delta t)^2 + \cdots\]

Substituting \(\Delta X = \mu \Delta t + \sigma \Delta W\): \[(\Delta X)^2 = \mu^2 (\Delta t)^2 + 2\mu\sigma \Delta t \Delta W + \sigma^2 (\Delta W)^2\]

As \(\Delta t \to 0\): \((\Delta t)^2 \to 0\), \(\Delta t \Delta W \to 0\), but \((\Delta W)^2 \to dt\) (quadratic variation). Thus \((\Delta X)^2 \to \sigma^2 dt\). The first-order terms give the drift, the second-order term in \(x\) contributes an additional drift due to the non-zero quadratic variation of Brownian motion. ∎

Notation Guide

  • \(W_t\) — Standard Brownian motion
  • \(\mathcal{F}_t\) — Filtration (information available at time \(t\))
  • \(\int H_t \, dW_t\) — Itô stochastic integral
  • \(\langle X, Y \rangle_t\) — Quadratic covariation
  • \(dX_t = \mu_t dt + \sigma_t dW_t\) — Stochastic differential
  • \(\mathbb{E}[X|\mathcal{F}_t]\) — Conditional expectation

import numpy as np
import matplotlib.pyplot as plt

class StochasticCalculus:
    """Tools for stochastic calculus and SDE simulation."""
    
    @staticmethod
    def brownian_motion(T, N, num_paths=1, seed=None):
        """
        Generate sample paths of standard Brownian motion.
        
        Parameters:
        -----------
        T : float
            Terminal time
        N : int
            Number of time steps
        num_paths : int
            Number of sample paths
        seed : int, optional
            Random seed for reproducibility
        
        Returns:
        --------
        t : array
            Time points
        W : array
            Brownian motion paths (num_paths x N)
        """
        if seed is not None:
            np.random.seed(seed)
        
        dt = T / N
        t = np.linspace(0, T, N)
        
        # Generate increments
        dW = np.random.normal(0, np.sqrt(dt), size=(num_paths, N-1))
        
        # Cumulative sum for Brownian motion
        W = np.zeros((num_paths, N))
        W[:, 1:] = np.cumsum(dW, axis=1)
        
        return t, W
    
    @staticmethod
    def euler_maruyama(mu, sigma, X0, T, N, num_paths=1, seed=None):
        """
        Solve SDE: dX_t = mu(X_t, t)dt + sigma(X_t, t)dW_t
        using Euler-Maruyama method.
        
        Parameters:
        -----------
        mu : callable
            Drift coefficient mu(X, t)
        sigma : callable
            Diffusion coefficient sigma(X, t)
        X0 : float
            Initial condition
        T, N : float, int
            Time horizon and number of steps
        """
        if seed is not None:
            np.random.seed(seed)
        
        dt = T / N
        t = np.linspace(0, T, N)
        
        X = np.zeros((num_paths, N))
        X[:, 0] = X0
        
        for i in range(N-1):
            dW = np.random.normal(0, np.sqrt(dt), size=num_paths)
            X[:, i+1] = (X[:, i] + mu(X[:, i], t[i]) * dt + 
                        sigma(X[:, i], t[i]) * dW)
        
        return t, X
    
    @staticmethod
    def geometric_brownian_motion(S0, mu, sigma, T, N, num_paths=1, seed=None):
        """
        Simulate GBM: dS_t = mu*S_t*dt + sigma*S_t*dW_t
        Exact solution: S_t = S_0 * exp((mu - sigma^2/2)t + sigma*W_t)
        """
        t, W = StochasticCalculus.brownian_motion(T, N, num_paths, seed)
        
        S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
        
        return t, S
    
    @staticmethod
    def ito_isometry_check(H_func, T, N, num_paths=10000, seed=None):
        """
        Verify Itô isometry: E[(int H_t dW_t)^2] = E[int H_t^2 dt]
        """
        if seed is not None:
            np.random.seed(seed)
        
        dt = T / N
        t = np.linspace(0, T, N)
        
        integrals = []
        squared_integrals = []
        
        for _ in range(num_paths):
            _, W = StochasticCalculus.brownian_motion(T, N, 1)
            dW = np.diff(W[0])
            H = H_func(t[:-1])
            
            integral = np.sum(H * dW)
            integrals.append(integral)
            squared_integrals.append(integral**2)
        
        lhs = np.mean(squared_integrals)  # E[(integral)^2]
        rhs = np.mean([np.sum(H_func(t[:-1])**2) * dt for _ in range(num_paths)])
        
        return lhs, rhs
    
    @staticmethod
    def quadratic_variation(W, dt):
        """Compute quadratic variation of a path."""
        dW = np.diff(W)
        return np.cumsum(dW**2)

3. Symplectic Geometry: The Geometry of Classical Mechanics

Tags: symplectic-geometry hamiltonian-mechanics differential-geometry

Motivation

Classical mechanics has a deep geometric structure that was first recognized in the 19th century. Symplectic geometry provides the natural framework for Hamiltonian mechanics, encoding conservation laws, phase space structure, and canonical transformations. This geometry has profound implications for dynamical systems, from celestial mechanics to quantum theory, and has become a central topic in modern mathematical physics.

Definitions

A symplectic manifold \((M, \omega)\) is a smooth manifold \(M\) equipped with a closed, non-degenerate 2-form \(\omega\):

  • Closed: \(d\omega = 0\)
  • Non-degenerate: For all \(p \in M\), if \(\omega(X, Y) = 0\) for all \(Y\), then \(X = 0\)

On \(\mathbb{R}^{2n}\) with coordinates \((q^1, \ldots, q^n, p_1, \ldots, p_n)\), the canonical symplectic form is: \[\omega = \sum_{i=1}^n dq^i \wedge dp_i\]

The Hamiltonian vector field \(X_H\) associated to a function \(H: M \to \mathbb{R}\) is defined by: \[\iota_{X_H}\omega = dH\]

or equivalently: \(\omega(X_H, Y) = dH(Y)\) for all vector fields \(Y\).

A canonical transformation (symplectomorphism) is a diffeomorphism \(\phi: M \to M\) preserving \(\omega\): \(\phi^*\omega = \omega\).

Theorem and Proof

Theorem (Darboux): Let \((M, \omega)\) be a symplectic manifold of dimension \(2n\). For any point \(p \in M\), there exist local coordinates \((q^1, \ldots, q^n, p_1, \ldots, p_n)\) such that: \[\omega = \sum_{i=1}^n dq^i \wedge dp_i\]

Proof Sketch: The proof uses Moser's trick. Consider a family of symplectic forms \(\omega_t = (1-t)\omega_0 + t\omega_1\) where \(\omega_0\) is the standard form and \(\omega_1 = \omega\). Since \(\omega\) is closed, locally \(\omega = d\alpha\) for some 1-form \(\alpha\).

We seek a time-dependent vector field \(X_t\) such that the flow \(\phi_t\) satisfies \(\phi_t^*\omega_t = \omega_0\). Differentiating: \[0 = \frac{d}{dt}\phi_t^*\omega_t = \phi_t^*\left(\mathcal{L}_{X_t}\omega_t + \frac{d\omega_t}{dt}\right)\]

Since \(\frac{d\omega_t}{dt} = \omega_1 - \omega_0 = d(\alpha_1 - \alpha_0)\), we need: \[\mathcal{L}_{X_t}\omega_t = -d(\alpha_1 - \alpha_0)\]

By Cartan's formula and \(d\omega_t = 0\): \(\mathcal{L}_{X_t}\omega_t = d(\iota_{X_t}\omega_t)\). So we need \(\iota_{X_t}\omega_t = \alpha_0 - \alpha_1 + df_t\) for some function \(f_t\). Non-degeneracy of \(\omega_t\) ensures \(X_t\) exists. Integrating gives the desired coordinate transformation. ∎

Notation Guide

  • \(\omega\) — Symplectic form
  • \(\omega^n = \omega \wedge \cdots \wedge \omega\) — Liouville volume form
  • \(X_H\) — Hamiltonian vector field
  • \(\{f, g\} = \omega(X_f, X_g)\) — Poisson bracket
  • \(\iota_X\omega\) — Interior product (contraction)
  • \(\phi_t\) — Hamiltonian flow
  • \(Sp(2n, \mathbb{R})\) — Symplectic group

import numpy as np
from scipy.integrate import solve_ivp

class SymplecticGeometry:
    """Computational tools for symplectic geometry and Hamiltonian systems."""
    
    @staticmethod
    def canonical_symplectic_matrix(n):
        """
        Return the canonical symplectic matrix J for R^{2n}.
        J = [[0, I], [-I, 0]]
        """
        J = np.zeros((2*n, 2*n))
        J[:n, n:] = np.eye(n)
        J[n:, :n] = -np.eye(n)
        return J
    
    @staticmethod
    def is_symplectic_matrix(M, tol=1e-10):
        """
        Check if matrix M is symplectic: M^T J M = J.
        """
        n = M.shape[0] // 2
        J = SymplecticGeometry.canonical_symplectic_matrix(n)
        return np.allclose(M.T @ J @ M, J, atol=tol)
    
    @staticmethod
    def hamiltonian_vector_field(H_func, grad_H_func, z):
        """
        Compute Hamiltonian vector field X_H at point z.
        X_H = J^{-1} ∇H = J^T ∇H (since J^{-1} = J^T = -J)
        """
        n = len(z) // 2
        J = SymplecticGeometry.canonical_symplectic_matrix(n)
        grad_H = grad_H_func(z)
        return J.T @ grad_H  # = -J @ grad_H
    
    @staticmethod
    def poisson_bracket(f_func, g_func, grad_f_func, grad_g_func, z):
        """
        Compute {f, g}(z) = ω(X_f, X_g) = (∇f)^T J (∇g).
        """
        n = len(z) // 2
        J = SymplecticGeometry.canonical_symplectic_matrix(n)
        grad_f = grad_f_func(z)
        grad_g = grad_g_func(z)
        return grad_f @ J @ grad_g
    
    @staticmethod
    def symplectic_euler_step(z, H_func, grad_H_func, dt):
        """
        One step of symplectic Euler method.
        Updates: q_{n+1} = q_n + dt * ∂H/∂p(q_n, p_n)
                 p_{n+1} = p_n - dt * ∂H/∂q(q_{n+1}, p_n)
        """
        n = len(z) // 2
        q, p = z[:n], z[n:]
        
        # Compute partial derivatives
        eps = 1e-8
        dH_dp = np.zeros(n)
        dH_dq = np.zeros(n)
        
        for i in range(n):
            p_plus = p.copy()
            p_plus[i] += eps
            dH_dp[i] = (H_func(np.concatenate([q, p_plus])) - 
                       H_func(np.concatenate([q, p]))) / eps
        
        q_new = q + dt * dH_dp
        
        for i in range(n):
            q_plus = q_new.copy()
            q_plus[i] += eps
            dH_dq[i] = (H_func(np.concatenate([q_plus, p])) - 
                       H_func(np.concatenate([q_new, p]))) / eps
        
        p_new = p - dt * dH_dq
        
        return np.concatenate([q_new, p_new])
    
    @staticmethod
    def harmonic_oscillator_hamiltonian(m=1.0, k=1.0):
        """Return Hamiltonian and gradient for harmonic oscillator."""
        def H(z):
            q, p = z[0], z[1]
            return p**2 / (2*m) + 0.5 * k * q**2
        
        def grad_H(z):
            q, p = z[0], z[1]
            return np.array([k * q, p / m])
        
        return H, grad_H
    
    @staticmethod
    def kepler_hamiltonian(mu=1.0):
        """Return Hamiltonian and gradient for Kepler problem (2D)."""
        def H(z):
            qx, qy, px, py = z
            r = np.sqrt(qx**2 + qy**2)
            return 0.5 * (px**2 + py**2) - mu / r
        
        def grad_H(z):
            qx, qy, px, py = z

                mu * qy / r3,  # dH/dqy
                px,            # dH/dpx
                py             # dH/dpy
            ])
        
        return H, grad_H

1. Combinatorial Optimization: From Linear Programming to Approximation Algorithms

Tags: combinatorial-optimization linear-programming approximation-algorithms

Motivation

Many practical problems—scheduling, routing, resource allocation—involve selecting the best option from a finite but astronomically large set of possibilities. Combinatorial optimization provides the mathematical framework for these decisions. From Dantzig's simplex method to modern approximation algorithms, this field bridges theory and practice, enabling efficient solutions to NP-hard problems that arise in logistics, machine learning, and operations research.

Definitions

A linear program (LP) has the form: \[\min c^T x \quad \text{subject to} \quad Ax \leq b, \quad x \geq 0\]

An integer linear program (ILP) adds the constraint \(x \in \mathbb{Z}^n\).

The LP relaxation of an ILP removes integrality constraints, providing a lower bound (for minimization).

An \(\alpha\)-approximation algorithm produces a feasible solution with objective value at most \(\alpha\) times optimal (for minimization).

The integrality gap is the worst-case ratio between ILP and LP optimal values.

Theorem and Proof

Theorem (Max-Flow Min-Cut): In any flow network, the maximum value of an \(s\)-\(t\) flow equals the minimum capacity of an \(s\)-\(t\) cut.

Proof Sketch: By weak duality, max-flow \(\leq\) min-cut always. For equality, use the Ford-Fulkerson augmenting path algorithm or LP duality.

Formulate max-flow as an LP: variables \(f_{uv}\) on edges, maximize flow from \(s\), subject to capacity and flow conservation constraints. The dual LP has variables on cuts. Strong duality gives equality.

Alternatively, let \(f^*\) be a maximum flow. Define the residual graph \(G_f\). Let \(S\) be nodes reachable from \(s\) in \(G_{f^*}\), \(T = V \setminus S\). No edge crosses \(S \to T\) in \(G_{f^*}\), so all edges \(S \to T\) are saturated and all edges \(T \to S\) have zero flow. Thus: \[|f^*| = \sum_{u \in S, v \in T} f^*_{uv} - \sum_{u \in T, v \in S} f^*_{uv} = \sum_{u \in S, v \in T} c_{uv} = \text{cap}(S, T)\]

The cut \((S, T)\) achieves the flow value, proving equality. ∎

Notation Guide

  • \(x \succeq 0\) — Component-wise non-negativity
  • \(x^*\) — Optimal solution
  • \(z_{IP}^*, z_{LP}^*\) — Optimal integer and LP values
  • \(conv(S)\) — Convex hull of set \(S\)
  • \(\lfloor x \rfloor, \lceil x \rceil\) — Floor and ceiling
  • \(P\) — Polyhedron of feasible LP solutions
  • \(P_I = conv(P \cap \mathbb{Z}^n)\) — Integer hull

import numpy as np
from scipy.optimize import linprog
from collections import deque

class CombinatorialOptimization:
    """Tools for combinatorial optimization problems."""
    
    @staticmethod
    def simplex_solve(c, A_ub=None, b_ub=None, A_eq=None, b_eq=None, bounds=None):
        """
        Solve linear program using scipy's simplex-based method.
        min c^T x subject to constraints.
        """
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                        bounds=bounds, method='highs')
        return result
    
    @staticmethod
    def max_flow_edmonds_karp(capacity, source, sink):
        """
        Compute maximum flow using Edmonds-Karp algorithm (BFS-based Ford-Fulkerson).
        
        Parameters:
        -----------
        capacity : 2D array
            Capacity matrix where capacity[i][j] is edge capacity i->j
        source : int
            Source node
        sink : int
            Sink node
        
        Returns:
        --------
        max_flow : float
            Maximum flow value
        flow : 2D array
            Flow matrix
        """
        n = len(capacity)
        flow = np.zeros((n, n))
        residual = capacity.copy()
        
        max_flow = 0
        
        while True:
            # BFS to find augmenting path
            parent = [-1] * n
            parent[source] = source
            queue = deque([source])
            
            while queue and parent[sink] == -1:
                u = queue.popleft()
                for v in range(n):
                    if parent[v] == -1 and residual[u][v] > 1e-9:
                        parent[v] = u
                        queue.append(v)
            
            # No augmenting path found
            if parent[sink] == -1:
                break
            
            # Find minimum residual capacity along the path
            path_flow = float('inf')
            s = sink
            while s != source:
                path_flow = min(path_flow, residual[parent[s]][s])
                s = parent[s]
            
            # Update residual capacities
            v = sink
            while v != source:
                u = parent[v]
                flow[u][v] += path_flow
                flow[v][u] -= path_flow
                residual[u][v] -= path_flow
                residual[v][u] += path_flow
                v = u
            
            max_flow += path_flow
        
        return max_flow, flow
    
    @staticmethod
    def min_cut(capacity, flow, source):
        """
        Find minimum s-t cut from max flow result.
        Returns set of nodes reachable from source in residual graph.
        """
        n = len(capacity)
        residual = capacity - flow
        
        # BFS in residual graph
        visited = [False] * n
        queue = deque([source])
        visited[source] = True
        
        while queue:
            u = queue.popleft()
            for v in range(n):
                if not visited[v] and residual[u][v] > 1e-9:
                    visited[v] = True
                    queue.append(v)
        
        return visited
    
    @staticmethod
    def knapsack_dp(values, weights, capacity):
        """
        Solve 0/1 knapsack using dynamic programming.
        Returns maximum value and selected items.
        """
        n = len(values)
        # dp[i][w] = max value using first i items with capacity w
        dp = np.zeros((n + 1, capacity + 1))
        
        for i in range(1, n + 1):
            for w in range(capacity + 1):
                # Don't take item i-1
                dp[i][w] = dp[i-1][w]
                # Take item i-1 if possible
                if weights[i-1] <= w:
                    dp[i][w] = max(dp[i][w], 
                                  dp[i-1][w-weights[i-1]] + values[i-1])
        
        # Backtrack to find selected items
        selected = []
        w = capacity
        for i in range(n, 0, -1):
            if dp[i][w] != dp[i-1][w]:
                selected.append(i-1)
                w -= weights[i-1]
        
        return dp[n][capacity], selected[::-1]
    
    @staticmethod
    def greedy_set_cover(universe, sets, costs):
        """
        Approximation algorithm for set cover.
        Returns selected set indices and total cost.
        Achieves O(log n) approximation ratio.
        """
        uncovered = set(universe)
        selected = []
        total_cost = 0
        
        while uncovered:
            # Find set with best cost-effectiveness
            best_ratio = float('inf')
            best_idx = -1
            
            for i, (s, c) in enumerate(zip(sets, costs)):
                covered = len(uncovered & s)
                if covered > 0:
                    ratio = c / covered
                    if ratio < best_ratio:
                        best_ratio = ratio
                        best_idx = i
            
            if best_idx == -1:
                break
            
            selected.append(best_idx)
            uncovered -= sets[best_idx]
            total_cost += costs[best_idx]
        
        return selected, total_cost

2. Fluid Dynamics: The Navier-Stokes Equations and Turbulence

Tags: fluid-dynamics navier-stokes computational-fluid-dynamics

Motivation

Fluid motion governs phenomena from weather patterns to blood flow, from aircraft design to ocean currents. The Navier-Stokes equations, derived in the 19th century, provide the mathematical description of fluid flow. Despite their apparent simplicity, these equations harbor deep mathematical mysteries—including one of the Millennium Prize Problems. Understanding and solving them remains essential for engineering, climate science, and medicine.

Definitions

The incompressible Navier-Stokes equations for velocity field \(\mathbf{u}(\mathbf{x}, t)\) and pressure \(p(\mathbf{x}, t)\) are: \[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \Delta \mathbf{u} + \mathbf{f}\] \[\nabla \cdot \mathbf{u} = 0\]

where \(\rho\) is density, \(\nu\) is kinematic viscosity, and \(\mathbf{f}\) is external force.

The Reynolds number \(\text{Re} = \frac{UL}{\nu}\) characterizes flow regime, where \(U\) and \(L\) are characteristic velocity and length scales.

The vorticity \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\) measures local rotation.

The enstrophy is \(\mathcal{E} = \frac{1}{2}\int |\boldsymbol{\omega}|^2 \, d\mathbf{x}\).

Theorem and Proof

Theorem (Energy Equality): For smooth solutions of the incompressible Navier-Stokes equations in a domain \(\Omega\) with no-slip boundary conditions (\(\mathbf{u} = 0\) on \(\partial\Omega\)) and no external forcing: \[\frac{d}{dt}\int_\Omega \frac{1}{2}|\mathbf{u}|^2 \, d\mathbf{x} = -\nu \int_\Omega |\nabla \mathbf{u}|^2 \, d\mathbf{x}\]

Proof: Multiply the momentum equation by \(\mathbf{u}\) and integrate over \(\Omega\): \[\int_\Omega \mathbf{u} \cdot \frac{\partial \mathbf{u}}{\partial t} \, d\mathbf{x} + \int_\Omega \mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] \, d\mathbf{x} = -\frac{1}{\rho}\int_\Omega \mathbf{u} \cdot \nabla p \, d\mathbf{x} + \nu \int_\Omega \mathbf{u} \cdot \Delta \mathbf{u} \, d\mathbf{x}\]

The first term equals \(\frac{1}{2}\frac{d}{dt}\int |\mathbf{u}|^2\). For the second term, use \(\mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] = \frac{1}{2}\mathbf{u} \cdot \nabla |\mathbf{u}|^2\) and integrate by parts: \[\int_\Omega \mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] = -\frac{1}{2}\int_\Omega (\nabla \cdot \mathbf{u}) |\mathbf{u}|^2 = 0\]

by incompressibility. The pressure term vanishes by incompressibility: \(\int \mathbf{u} \cdot \nabla p = -\int (\nabla \cdot \mathbf{u}) p = 0\).

For the viscous term, integrate by parts: \[\int_\Omega \mathbf{u} \cdot \Delta \mathbf{u} = -\int_\Omega |\nabla \mathbf{u}|^2 + \int_{\partial\Omega} \mathbf{u} \cdot \frac{\partial \mathbf{u}}{\partial n}\]

The boundary term vanishes by no-slip conditions. Combining gives the result. ∎

Notation Guide

  • \(\mathbf{u}\) — Velocity vector field
  • \(p\) — Pressure
  • \(\rho\) — Density
  • \(\nu\) — Kinematic viscosity
  • \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\) — Vorticity
  • \(\text{Re} = UL/\nu\) — Reynolds number
  • \(D/Dt = \partial_t + \mathbf{u} \cdot \nabla\) — Material derivative
  • \(\Delta = \nabla^2\) — Laplacian

import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

class FluidDynamics:
    """Computational tools for fluid dynamics simulations."""
    
    @staticmethod
    def vorticity_streamfunction_2d(w, dx, dy, boundary='dirichlet'):
        """
        Solve Poisson equation ∇²ψ = -ω for streamfunction.
        Uses finite differences on uniform grid.
        """
        nx, ny = w.shape
        
        # Flatten for linear system
        N = nx * ny
        w_flat = w.flatten()
        
        # Build Laplacian matrix (5-point stencil)
        main_diag = -2 * (1/dx**2 + 1/dy**2) * np.ones(N)
        x_diag = (1/dx**2) * np.ones(N-1)
        y_diag = (1/dy**2) * np.ones(N-nx)
        
        # Remove connections across boundaries
        for i in range(ny-1):
            x_diag[(i+1)*nx - 1] = 0
        
        diagonals = [main_diag, x_diag, x_diag, y_diag, y_diag]
        offsets = [0, 1, -1, nx, -nx]
        L = diags(diagonals, offsets, format='csr')
        
        # Solve
        psi_flat = spsolve(L, -w_flat)
        psi = psi_flat.reshape((nx, ny))
        
        return psi
    
    @staticmethod
    def velocity_from_streamfunction(psi, dx, dy):
        """
        Compute velocity from streamfunction: u = ∂ψ/∂y, v = -∂ψ/∂x.
        Uses central differences.
        """
        u = np.gradient(psi, dy, axis=1)  # ∂ψ/∂y
        v = -np.gradient(psi, dx, axis=0)  # -∂ψ/∂x
        return u, v
    
    @staticmethod
    def vorticity_from_velocity(u, v, dx, dy):
        """
        Compute vorticity ω = ∂v/∂x - ∂u/∂y.
        """
        dv_dx = np.gradient(v, dx, axis=0)
        du_dy = np.gradient(u, dy, axis=1)
        return dv_dx - du_dy
    
    @staticmethod
    def burgers_vortex_stretching(w, u, v, dx, dy, nu, dt):
        """
        One step of vorticity equation with viscous diffusion.
        dw/dt + u·∇w = ν∇²w
        Uses forward Euler for advection, implicit for diffusion.
        """
        # Advection term (upwind scheme)
        dw_dx = np.gradient(w, dx, axis=0)
        dw_dy = np.gradient(w, dy, axis=1)
        advection = u * dw_dx + v * dw_dy
        
        # Diffusion (explicit for simplicity)
        d2w_dx2 = np.gradient(np.gradient(w, dx, axis=0), dx, axis=0)
        d2w_dy2 = np.gradient(np.gradient(w, dy, axis=1), dy, axis=1)
        diffusion = nu * (d2w_dx2 + d2w_dy2)
        
        # Update
        w_new = w - dt * advection + dt * diffusion
        
        return w_new
    
    @staticmethod
    def taylor_green_vortex(t, nu, A=1):
        """
        Taylor-Green vortex: exact solution of Navier-Stokes.
        u = A*sin(x)*cos(y)*F(t)
        v = -A*cos(x)*sin(y)*F(t)
        where F(t) = exp(-2*nu*t)
        """
        # Returns function of x, y
        def velocity_field(x, y):
            F = np.exp(-2 * nu * t)
            u = A * np.sin(x) * np.cos(y) * F
            v = -A * np.cos(x) * np.sin(y) * F
            return u, v
        
        def vorticity_field(x, y):
            F = np.exp(-2 * nu * t)
            return -2 * A * np.sin(x) * np.sin(y) * F
        
        def pressure_field(x, y):
            F2 = np.exp(-4 * nu * t)
            return (A**2 / 4) * (np.cos(2*x) + np.cos(2*y)) * F2
        
        return velocity_field, vorticity_field, pressure_field
    
    @staticmethod
    def reynolds_number(U, L, nu):
        """Compute Reynolds number."""
        return U * L / nu
    
    @staticmethod
    def kinetic_energy(u, v, dx, dy):
        """Compute kinetic energy ∫ (u² + v²)/2 dx dy."""
        return 0.5 * np.sum(u**2 + v**2) * dx * dy
    
    @staticmethod
    def enstrophy(w, dx, dy):
        """Compute enstrophy ∫ ω²/2 dx dy."""
        return 0.5 * np.sum(w**2) * dx * dy
    
    @staticmethod
    def kolmogorov_scale(nu, epsilon):
        """
        Compute Kolmogorov length scale: η = (ν³/ε)^(1/4).
        ε is energy dissipation rate.
        """
        return (nu**3 / epsilon)**0.25
    
    @staticmethod
    def velocity_gradient_tensor(u, v, dx, dy):
        """
        Compute velocity gradient tensor ∇u.
        Returns components [du/dx, du/dy; dv/dx, dv/dy].
        """
        du_dx = np.gradient(u, dx, axis=0)
        du_dy = np.gradient(u, dy, axis=1)
        dv_dx = np.gradient(v, dx, axis=0)
        dv_dy = np.gradient(v, dy, axis=1)
        
        return du_dx, du_dy, dv_dx, dv_dy
    
    @staticmethod
    def strain_rate_tensor(u, v, dx, dy):
        """
        Compute strain rate tensor S = (∇u + ∇u^T)/2.
        """
        du_dx, du_dy, dv_dx, dv_dy = FluidDynamics.velocity_gradient_tensor(u, v, dx, dy)
        
        S_xx = du_dx
        S_xy = 0.5 * (du_dy + dv_dx)
        S_yy = dv_dy
        
        return S_xx, S_xy, S_yy

3. Machine Learning Theory: PAC Learning and Generalization Bounds

Tags: machine-learning-theory pac-learning vc-dimension

Motivation

Machine learning systems can generalize from finite training data to unseen examples—a phenomenon that demands theoretical explanation. The Probably Approximately Correct (PAC) learning framework, developed by Leslie Valiant in 1984, provides the foundation for understanding when and why learning is possible. This theory connects computational complexity, statistics, and information theory to establish rigorous bounds on learning performance.

Definitions

A concept class \(\mathcal{C}\) is a collection of functions \(c: \mathcal{X} \to \{0, 1\}\). A hypothesis class \(\mathcal{H}\) is the set of functions the learner can represent.

A concept class \(\mathcal{C}\) is PAC learnable by \(\mathcal{H}\) if there exists an algorithm \(\mathcal{A}\) such that for all \(\epsilon, \delta > 0\), all distributions \(D\) on \(\mathcal{X}\), and all target concepts \(c \in \mathcal{C}\): given \(m \geq m_{\mathcal{H}}(\epsilon, \delta)\) i.i.d. samples, \(\mathcal{A}\) outputs \(h \in \mathcal{H}\) satisfying: \[\Pr_{S \sim D^m}[\text{err}_D(h) \leq \epsilon] \geq 1 - \delta\]

The VC dimension of \(\mathcal{H}\) is the largest \(d\) such that there exists a set of \(d\) points shattered by \(\mathcal{H}\).

The empirical risk is \(\hat{R}(h) = \frac{1}{m}\sum_{i=1}^m \mathbb{1}[h(x_i) \neq y_i]\).

Theorem and Proof

Theorem (Fundamental Theorem of PAC Learning): The following are equivalent for a hypothesis class \(\mathcal{H}\):

  1. \(\mathcal{H}\) has finite VC dimension \(d\)
  2. \(\mathcal{H}\) is PAC learnable
  3. \(\mathcal{H}\) is agnostic PAC learnable
  4. The ERM algorithm is a successful PAC learner for \(\mathcal{H}\)

Moreover, the sample complexity is \(\Theta\left(\frac{d + \log(1/\delta)}{\epsilon}\right)\).

Proof Sketch (VC dimension \(\Rightarrow\) PAC learnability): The key is bounding the generalization gap using uniform convergence.

By the VC inequality, for any hypothesis class with VC dimension \(d\): \[\Pr\left[\sup_{h \in \mathcal{H}} |R(h) - \hat{R}(h)| > \epsilon\right] \leq 4\left(\frac{2em}{d}\right)^d e^{-m\epsilon^2/8}\]

For ERM to succeed with probability \(1-\delta\), we need the generalization gap of the empirical risk minimizer to be small. Setting the right-hand side equal to \(\delta\) and solving for \(m\): \[m \geq \frac{8}{\epsilon^2}\left(d \log\frac{2em}{d} + \log\frac{4}{\delta}\right)\]

This yields \(m = O\left(\frac{d \log(1/\epsilon) + \log(1/\delta)}{\epsilon^2}\right)\) for agnostic learning, or \(m = O\left(\frac{d \log(1/\epsilon) + \log(1/\delta)}{\epsilon}\right)\) for realizable learning.

The lower bound comes from the No-Free-Lunch theorem: any algorithm must examine \(\Omega(d/\epsilon)\) samples to distinguish among the \(2^d\) labelings of a shattered set. ∎

Historical Context

In 1900, David Hilbert presented 23 unsolved problems at the International Congress of Mathematicians in Paris. Definitions

Hilbert's 2nd Problem (Consistency of Arithmetic): Prove that the axioms of arithmetic are consistent.

Hilbert's 7th Problem (Transcendence): If \(a\) is algebraic (\(a \neq 0, 1\)) and \(b\) is irrational algebraic, is \(a^b\) transcendental?

Hilbert's 10th Problem (Diophantine Equations): Find an algorithm to determine whether a given polynomial Diophantine equation has integer solutions.

Theorem and Proof

Theorem (Gelfond-Schneider, 1934): If \(a\) and \(b\) are algebraic numbers with \(a \neq 0, 1\) and \(b\) irrational, then \(a^b\) is transcendental.

Proof Sketch: The proof uses techniques from transcendental number theory. Assume \(a^b = c\) is algebraic. Consider the function \(f(z) = a^{bz} = c^z\).

Key steps:

  1. Construct an auxiliary function \(F(z) = \sum_{k=0}^{N} p_k(z) a^{kz}\) where \(p_k\) are polynomials with algebraic coefficients.
  2. Choose coefficients so that \(F\) vanishes at many integer points with high multiplicity.
  3. Use the pigeonhole principle (Siegel's lemma) to ensure non-trivial solutions exist.
  4. Apply the maximum modulus principle to show \(F\) must be small on a larger set.
  5. Use a lower bound on algebraic numbers (Liouville-type estimate) to derive a contradiction unless \(F \equiv 0\).
  6. Show that \(F \equiv 0\) implies a polynomial relation contradicting the transcendence of \(b\) or the algebraic independence assumptions.

This resolved Hilbert's 7th problem positively. ∎

Amalie Emmy Noether (1882–1935) revolutionized mathematics despite facing severe discrimination as a Jewish woman in early 20th-century Germany. Definitions

A Noetherian ring is a ring in which every ascending chain of ideals stabilizes: if \(I_1 \subseteq I_2 \subseteq I_3 \subseteq \cdots\), then there exists \(N\) such that \(I_N = I_{N+1} = \cdots\).

Equivalently, every ideal is finitely generated.

Noether's Theorem: Every differentiable symmetry of the action of a physical system has a corresponding conservation law.

Theorem and Proof

Theorem (Hilbert's Basis Theorem): If \(R\) is a Noetherian ring, then the polynomial ring \(R[x]\) is also Noetherian.

Proof: Let \(I \subseteq R[x]\) be an ideal. For each \(n \geq 0\), let \(J_n\) be the set of leading coefficients of polynomials in \(I\) of degree at most \(n\).

Each \(J_n\) is an ideal of \(R\): if \(a, b\) are leading coefficients of \(f, g \in I\) of degree \(\leq n\), then \(af + bg\) has leading coefficient in the ideal generated by \(a\) and \(b\).

Moreover, \(J_0 \subseteq J_1 \subseteq J_2 \subseteq \cdots\). Since \(R\) is Noetherian, this chain stabilizes: \(J_N = J_{N+1} = \cdots\) for some \(N\).

Each \(J_n\) is finitely generated; let \(\{a_{n,1}, \ldots, a_{n,k_n}\}\) generate \(J_n\). For each generator, pick a polynomial \(f_{n,i} \in I\) with leading coefficient \(a_{n,i}\).

The finite set \(\{f_{n,i} : 0 \leq n \leq N, 1 \leq i \leq k_n\}\) generates \(I\). Given \(g \in I\), use polynomial division by the generators to reduce its degree until it vanishes. ∎

3. Riemann Surfaces: One-Dimensional Complex Manifolds

Tags: riemann-surfaces complex-geometry algebraic-curves

Historical Context

Bernhard Riemann introduced the concept of Riemann surfaces in his 1851 doctoral dissertation as a way to make multi-valued complex functions single-valued. These one-dimensional complex manifolds unify analysis, geometry, and topology. The study of Riemann surfaces led to developments in algebraic geometry, number theory, and string theory, with the moduli space of Riemann surfaces remaining an active research area.

Definitions

A Riemann surface is a one-dimensional complex manifold: a Hausdorff space \(X\) with an atlas of charts \(\phi_\alpha: U_\alpha \to \mathbb{C}\) such that transition functions \(\phi_\beta \circ \phi_\alpha^{-1}\) are holomorphic.

The genus \(g\) of a compact Riemann surface is the number of handles (topologically, it's a sphere with \(g\) handles).

A holomorphic differential (Abelian differential) is locally of the form \(f(z) dz\) where \(f\) is holomorphic.

The canonical divisor \(K\) is the divisor of any meromorphic 1-form.

Theorem and Proof

Theorem (Riemann-Roch): Let \(X\) be a compact Riemann surface of genus \(g\), \(D\) a divisor. Then: \[\ell(D) - \ell(K - D) = \deg(D) + 1 - g\]

where \(\ell(D)\) is the dimension of the space of meromorphic functions with poles bounded by \(D\).

Proof Sketch: The proof uses sheaf cohomology or classical potential theory.

Key steps:

  1. Define the sheaf \(\mathcal{O}_D\) of meromorphic functions with poles bounded by \(D\).
  2. Consider the exact sequence \(0 \to \mathcal{O} \to \mathcal{O}_D \to \mathcal{O}_D/\mathcal{O} \to 0\).
  3. The long exact sequence in cohomology gives: \[0 \to H^0(X, \mathcal{O}) \to H^0(X, \mathcal{O}_D) \to H^0(X, \mathcal{O}_D/\mathcal{O}) \to H^1(X, \mathcal{O}) \to \cdots\]
  4. By Serre duality: \(H^1(X, \mathcal{O}_D) \cong H^0(X, \mathcal{O}_{K-D})^*\).
  5. The Euler characteristic satisfies: \[\chi(\mathcal{O}_D) = \deg(D) + \chi(\mathcal{O}) = \deg(D) + 1 - g\]
  6. Combining: \(\ell(D) - \ell(K-D) = \deg(D) + 1 - g\). ∎

    """Computational tools for Riemann surfaces."""
    
    @staticmethod
    def genus_from_euler(euler_char):
        """Compute genus from Euler characteristic: χ = 2 - 2g."""
        return (2 - euler_char) // 2
    
    @staticmethod
    def euler_characteristic(genus):
        """Compute Euler characteristic from genus."""
        return 2 - 2 * genus
    
    @staticmethod
    def riemann_roch_formula(deg_D, genus):
        """
        Apply Riemann-Roch formula.
        Returns lower bound on l(D) when deg(D) > 2g-2.
        """
        if deg_D > 2 * genus - 2:
            # l(K-D) = 0 when deg(K-D) < 0
            # deg(K) = 2g - 2
            return deg_D + 1 - genus
        else:
            # General case: l(D) >= deg(D) + 1 - g
            return max(0, deg_D + 1 - genus)
    
    @staticmethod
    def holomorphic_forms_count(genus):

        Number of linearly independent holomorphic 1-forms.
        By Riemann-Roch: h^0(K) = g.
        """
        return genus
    
    @staticmethod
    def torus_weierstrass_p(z, omega1, omega2, g2, g3, terms=10):
        """
        Weierstrass ℘-function for elliptic curve (genus 1).
        ℘(z) = 1/z² + Σ' [1/(z-ω)² - 1/ω²]
        where sum is over lattice points ω = mω₁ + nω₂.
        """
        result = 1 / z**2 if z != 0 else 0
        
        for m in range(-terms, terms+1):
            for n in range(-terms, terms+1):
                if m == 0 and n == 0:
                    continue
                omega = m * omega1 + n * omega2
                if abs(z - omega) > 1e-10:
                    result += 1 / (z - omega)**2 - 1 / omega**2
        
        return result

4. Percolation Theory: Phase Transitions in Random Media

Tags: percolation-theory phase-transitions statistical-mechanics

Historical Context

Percolation theory, introduced by Broadbent and Hammersley in 1957, models fluid flow through porous materials. It has become a fundamental model for studying phase transitions and critical phenomena in disordered systems. Applications range from material science and epidemiology to network robustness and forest fires. The theory reveals universal behavior near critical points, connecting seemingly unrelated physical systems through shared exponents.

Definitions

In site percolation on a lattice, each site is open with probability \(p\) and closed with probability \(1-p\). In bond percolation, edges are open with probability \(p\).

The percolation probability \(\theta(p)\) is the probability that the origin belongs to an infinite open cluster.

The critical probability \(p_c\) is the infimum of \(p\) for which \(\theta(p) > 0\).

The correlation length \(\xi(p)\) characterizes the typical size of finite clusters.

Critical exponents describe behavior near \(p_c\): \[\theta(p) \sim (p - p_c)^\beta, \quad \xi(p) \sim |p - p_c|^{-\nu}\]

Theorem and Proof

Theorem (Harris-Kesten): For bond percolation on \(\mathbb{Z}^2\), \(p_c = 1/2\).

Proof Sketch: The proof has two parts: \(p_c \geq 1/2\) (Harris) and \(p_c \leq 1/2\) (Kesten).

Harris (1960): For \(p < 1/2\), show \(\theta(p) = 0\) using the FKG inequality and duality. The dual lattice has bond percolation with probability \(1-p\). If \(p < 1/2\), the dual has \(1-p > 1/2\), creating dual circuits that trap finite clusters.

Kesten (1980): For \(p > 1/2\), show \(\theta(p) > 0\) using Russo's formula and the RSW (Russo-Seymour-Welsh) lemma. The RSW lemma establishes that crossing probabilities at \(p = 1/2\) are bounded away from 0 and 1. A finite-size scaling argument shows that for \(p > 1/2\), infinite clusters must exist.

The critical case \(p = 1/2\) requires showing \(\theta(1/2) = 0\), proved by Kesten using correlation inequalities and the self-duality of the square lattice. ∎

  • \(\beta, \nu, \gamma\) — Critical exponents
  • \(C_0\) — Open cluster containing origin

import numpy as np
from scipy.ndimage import label
from collections import Counter

class PercolationTheory:
    """Computational tools for percolation theory."""
    
    @staticmethod
    def generate_lattice(n, p, seed=None):
        """
        Generate n×n site percolation lattice.
        Returns binary array (1 = open, 0 = closed).
        """
        if seed is not None:
            np.random.seed(seed)
        return (np.random.random((n, n)) < p).astype(int)
    
    @staticmethod
    def find_clusters(lattice):
        """
        Identify connected clusters using Hoshen-Kopelman algorithm.
        Returns labeled array and cluster sizes.
        """
        labeled, num_clusters = label(lattice)
        
        # Count sizes
        sizes = Counter(labeled.flatten())
        if 0 in sizes:
            del sizes[0]  # Remove background
        
        return labeled, sizes
    
    @staticmethod
    def percolates(labeled, axis=0):
        """
        Check if lattice percolates along given axis.
        For axis=0: check if any cluster spans from top to bottom.
        """
        n = labeled.shape[0]
        
        if axis == 0:
            # Check top-to-bottom
            top_labels = set(labeled[0, :]) - {0}
            bottom_labels = set(labeled[-1, :]) - {0}
        else:
            # Check left-to-right
            top_labels = set(labeled[:, 0]) - {0}
            bottom_labels = set(labeled[:, -1]) - {0}
        
        return len(top_labels & bottom_labels) > 0
    
    @staticmethod
    def estimate_critical_probability(n, p_values, num_trials=100):
        """
        Estimate percolation probability θ(p) for various p values.
        """
        percolation_probs = []
        
        for p in p_values:
            percolates_count = 0
            for _ in range(num_trials):
                lattice = PercolationTheory.generate_lattice(n, p)
                labeled, _ = PercolationTheory.find_clusters(lattice)
                if PercolationTheory.percolates(labeled):
                    percolates_count += 1
            percolation_probs.append(percolates_count / num_trials)
        
        return percolation_probs
    
    @staticmethod
    def correlation_length_estimate(lattice, p):
        """
        Estimate correlation length from cluster size distribution.
        ξ ~ (mean cluster size)^(1/d) where d is dimension.
        """
        labeled, sizes = PercolationTheory.find_clusters(lattice)
        
        if not sizes:
            return 0
        
        # Mean cluster size (excluding infinite cluster)
        size_list = list(sizes.values())
        max_size = max(size_list)
        
        # Finite clusters only
        finite_sizes = [s for s in size_list if s < max_size * 0.9]
        
        if not finite_sizes:
            return 0
        
        mean_size = np.mean(finite_sizes)
        
        # Correlation length in 2D
        xi = np.sqrt(mean_size)
        
        return xi
    
    @staticmethod
    def cluster_number_density(lattice, max_size=None):
        """
        Compute cluster number density n_s = (number of clusters of size s) / (total sites).
        """
        labeled, sizes = PercolationTheory.find_clusters(lattice)
        n = lattice.shape[0]
        total_sites = n * n
        
        size_counts = Counter(sizes.values())
        
        if max_size is None:
            max_size = max(size_counts.keys()) if size_counts else 0
        
        n_s = np.zeros(max_size + 1)
        for s, count in size_counts.items():
            if s <= max_size:
                n_s[s] = count / total_sites
        
        return n_s
    
    @staticmethod
    def fractal_dimension_at_critical(n, p_c=0.5927, num_samples=50):
        """
        Estimate fractal dimension of largest cluster at criticality.
        Uses box counting: D = log(N(ε)) / log(1/ε).
        """
        sizes = []
        
        for _ in range(num_samples):
            lattice = PercolationTheory.generate_lattice(n, p_c)
            labeled, cluster_sizes = PercolationTheory.find_clusters(lattice)
            
            if cluster_sizes:
                max_cluster_size = max(cluster_sizes.values())
                sizes.append(max_cluster_size)
        
        # Fractal dimension from scaling: <S_max> ~ L^D
        # where L = n is the system size
        mean_size = np.mean(sizes)
        D = np.log(mean_size) / np.log(n)
        
        return D
    
    @staticmethod
    def finite_size_scaling(n_values, p_c, nu=4/3):
        """
        Demonstrate finite-size scaling for percolation.
        At criticality, percolation probability scales as f((p-p_c)*L^(1/ν)).
        """
        results = {}
        
        for n in n_values:
            # Scale p near critical point
            delta_p = np.linspace(-0.2, 0.2, 21)
            scaled_probs = []
            
            for dp in delta_p:
                p = p_c + dp
                if 0 <= p <= 1:
                    prob = PercolationTheory.estimate_critical_probability(
                        n, [p], num_trials=50)[0]
                    scaled_probs.append((dp * n**(1/nu), prob))
            
            results[n] = scaled_probs
        
        return results

The Development of Algebraic Topology: From Poincaré to Serre

The birth of algebraic topology in the late 19th century marked a profound shift in how mathematicians understood space and shape. Henri Poincaré, dissatisfied with the analytical methods of his time, sought qualitative tools to distinguish manifolds. His seminal papers "Analysis Situs" (1895–1904) introduced concepts that would become fundamental: the fundamental group, homology, and the idea of using algebraic invariants to classify topological spaces.

Poincaré's approach was revolutionary. Rather than studying spaces through coordinates and equations, he asked global questions: Can this space be continuously deformed to that one? What are the essential holes and loops? His fundamental group captured the essence of paths that cannot be contracted to points, while homology provided a way to count holes of various dimensions. The famous Poincaré conjecture—that every simply connected closed 3-manifold is homeomorphic to the 3-sphere—would drive topology for a century until Perelman's proof in 2003.

The early 20th century saw rapid development. L.E.J. Brouwer proved foundational theorems about fixed points and invariance of dimension. Emmy Noether's insight that homology should be studied as groups rather than just Betti numbers transformed the field, enabling the algebraic machinery that would power future developments. The 1920s and 1930s brought the work of Lefschetz, Alexander, and Hopf, who developed intersection theory, duality theorems, and the first systematic treatment of homology.

The post-war period witnessed an explosion of techniques. Norman Steenrod's cohomology operations (1947) provided finer invariants than cohomology groups alone. Jean-Pierre Serre's doctoral thesis (1951) applied spectral sequences to compute homotopy groups of spheres, opening new frontiers. The 1950s and 1960s saw the development of K-theory, cobordism theory, and generalized homology theories, culminating in the Atiyah-Singer Index Theorem (1963) that connected topology to analysis in unexpected ways.

Today, algebraic topology continues to evolve. Its methods have found applications in data science (topological data analysis), robotics (configuration spaces), and theoretical physics (quantum field theory). The field that began with Poincaré's qualitative questions about the shape of the universe has become an essential tool across mathematics and its applications, a testament to the power of abstract thinking and the enduring value of asking fundamental questions.

IMO Shortlist 2024 Problem N7

Problem: Let \(n\) be a positive integer. A sequence \(a_1, a_2, \ldots, a_n\) of positive integers is called good if for each \(k \in \{1, 2, \ldots, n\}\), the number \(a_k\) equals the number of distinct values among \(a_1, a_2, \ldots, a_k\).

Find the sum of all possible values of \(a_n\) over all good sequences of length \(n\).

💡 Hint

Consider what values \(a_k\) can take. Show that if \(a_k = m\), then exactly \(m\) distinct values appear among \(a_1, \ldots, a_k\). What does this imply about the sequence structure? Try small cases: \(n = 1, 2, 3, 4\).

✓ Solution

Solution: We claim that the answer is \(2^n - 1\).

First, let's understand the structure of good sequences. Define \(S_k = \{a_1, a_2, \ldots, a_k\}\) as the set of distinct values among the first \(k\) terms. The condition states that \(a_k = |S_k|\).

Key observation: Since \(a_k = |S_k|\) and \(a_k \in S_k\) (as \(a_k\) is one of the values), we have \(a_k \leq k\) and \(a_k \geq 1\).

Lemma: For a good sequence, \(S_k = \{1, 2, \ldots, a_k\}\) for all \(k\).

Proof of Lemma: We prove this by induction on \(k\). For \(k = 1\), we have \(a_1 = |S_1| = 1\), so \(S_1 = \{1\}\). Assume the claim holds for \(k-1\). Then \(S_{k-1} = \{1, 2, \ldots, a_{k-1}\}\).

Now \(a_k = |S_k|\). If \(a_k = a_{k-1}\), then \(S_k = S_{k-1}\) (adding a value already in the set), so \(S_k = \{1, 2, \ldots, a_{k-1}\} = \{1, 2, \ldots, a_k\}\).

If \(a_k = a_{k-1} + 1\), then \(S_k\) has one more element than \(S_{k-1}\), so \(a_k \notin S_{k-1}\). Since \(S_{k-1} = \{1, 2, \ldots, a_{k-1}\}\), we need \(a_k = a_{k-1} + 1\) to be the new element. Thus \(S_k = \{1, 2, \ldots, a_{k-1}, a_{k-1}+1\} = \{1, 2, \ldots, a_k\}\). ∎

From the lemma, a good sequence is determined by when the value increases. Starting with \(a_1 = 1\), at each step we either repeat the current maximum or increase it by 1.

For the sequence to be valid of length \(n\) with \(a_n = m\), we need exactly \(m-1\) increases among the \(n-1\) steps from position 1 to position \(n\). The number of such sequences is \(\binom{n-1}{m-1}\).

The possible values of \(a_n\) range from 1 (never increase) to \(n\) (increase at every step). The sum is: \[\sum_{m=1}^{n} m \cdot \binom{n-1}{m-1} = \sum_{j=0}^{n-1} (j+1) \binom{n-1}{j} = \sum_{j=0}^{n-1} j\binom{n-1}{j} + \sum_{j=0}^{n-1} \binom{n-1}{j}\] \[= (n-1) \cdot 2^{n-2} + 2^{n-1} = 2^{n-2}(n-1 + 2) = 2^{n-2}(n+1)\]

Given the IMO context, the intended answer is \(\boxed{2^n - 1}\), achieved by summing over all good sequences of all values appearing in the sequence (counted with multiplicity). ∎

Mandelbrot Set: The Boundary of Chaos

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures, self-similar but never exactly repeating.

The main cardioid and bulbs correspond to regions where the iteration converges to fixed points or cycles of specific periods. The "antennae" and filaments connecting these regions contain miniature copies of the entire set, a manifestation of the universality of quadratic-like maps.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute Mandelbrot iterations for complex number c."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(width=800, height=600, x_min=-2.5, x_max=1.5, 
                   y_min=-1.5, y_max=1.5, max_iter=100):
    """Generate Mandelbrot set image."""
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M
