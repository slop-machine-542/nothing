1. Operads: The Algebra of Operations

Tags: operads algebraic-topology higher-algebra

Motivation

How do we systematically study algebraic structures with operations of varying arities? Operads provide the answer, encoding operations and their compositions in a uniform framework. Originally developed in algebraic topology to study iterated loop spaces, operads have become fundamental in deformation quantization, string theory, and higher category theory. The little disks operad, for instance, governs the structure of double loop spaces and appears in the study of configuration spaces. In mathematical physics, operads organize the algebraic structure of quantum field theories, where operations correspond to combining subsystems.

Definitions

  • Operad: A collection of sets/spaces \(O(n)\) for \(n \geq 0\), where \(O(n)\) represents \(n\)-ary operations, together with:
    • Composition: For \(f \in O(n)\) and \(g_1 \in O(k_1), \ldots, g_n \in O(k_n)\), a composite \(f \circ (g_1, \ldots, g_n) \in O(k_1 + \cdots + k_n)\)
    • Identity: An element \(1 \in O(1)\) satisfying \(1 \circ f = f = f \circ (1, \ldots, 1)\)
    • Symmetry: An action of the symmetric group \(S_n\) on \(O(n)\) compatible with composition
  • Endomorphism Operad: For a vector space \(V\), \(\text{End}_V(n) = \text{Hom}(V^{\otimes n}, V)\) with composition given by substitution.
  • Algebra over an Operad: A morphism of operads \(O \to \text{End}_V\), i.e., a way to realize operations in \(O\) as actual operations on \(V\).
  • Little k-Disks Operad: \(E_k(n)\) is the space of configurations of \(n\) disjoint k-dimensional disks inside the unit k-disk.
  • Associative Operad: \(\text{Assoc}(n) = S_n\) (or a point in the non-symmetric version), encoding associative multiplication.
  • Commutative Operad: \(\text{Com}(n) = *\) (a point) for all \(n \geq 1\), encoding commutative multiplication.

Theorem: Recognition Principle for Loop Spaces

Theorem (Boardman-Vogt, May): A connected space \(X\) has the homotopy type of a \(k\)-fold loop space \(\Omega^k Y\) for some \(Y\) if and only if \(X\) admits an action of the little k-disks operad \(E_k\).

Corollary: An infinite loop space (representing a connective spectrum) admits an action of the infinite symmetric operad \(E_\infty = \text{colim}_k E_k\).

Proof Sketch

The proof has two directions:

  1. (\(\Rightarrow\)) If \(X \simeq \Omega^k Y\), then points in \(E_k(n)\) (configurations of \(n\) disks) act on \(X^n\) by "multiplying" loops supported in each subdisk. This gives an \(E_k\)-algebra structure.
  2. (\(\Leftarrow\)) Given an \(E_k\)-algebra structure on \(X\), construct a classifying space \(B^k X\) using the operad action. The bar construction \(B_{E_k} X\) deloops \(X\), and iteratively applying this yields \(Y\) with \(X \simeq \Omega^k Y\).

The key insight is that the little disks operad encodes exactly the structure needed to "compose" loops in \(k\) independent directions.

Notation Guide

  • \(O(n)\): Space of \(n\)-ary operations
  • \(f \circ_i g\): Composition of \(f\) with \(g\) in the \(i\)-th input
  • \(E_k\): Little k-disks operad
  • \(\text{End}_V\): Endomorphism operad of \(V\)
  • \(S_n\): Symmetric group on \(n\) letters
  • \(B_O X\): Bar construction with respect to operad \(O\)

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Circle

class LittleDisk:
    """Represents a disk in the little disks operad."""
    def __init__(self, center, radius):
        self.center = np.array(center)
        self.radius = radius
    
    def contains(self, point):
        """Check if point is inside this disk."""
        return np.linalg.norm(np.array(point) - self.center) < self.radius
    
    def scale_and_translate(self, outer_disk):
        """Map this disk into an outer disk (composition)."""
        # Scale by outer radius and translate to outer center
        new_center = outer_disk.center + self.center * outer_disk.radius
        new_radius = self.radius * outer_disk.radius
        return LittleDisk(new_center, new_radius)

class LittleDisksConfiguration:
    """A configuration in the little 2-disks operad."""
    def __init__(self, disks):
        self.disks = disks
        self._validate()
    
    def _validate(self):
        """Ensure disks are disjoint and inside unit disk."""
        # Check all inside unit disk
        for d in self.disks:
            if np.linalg.norm(d.center) + d.radius > 1:
                raise ValueError("Disk extends outside unit disk")
        # Check pairwise disjoint
        for i, d1 in enumerate(self.disks):
            for d2 in self.disks[i+1:]:
                dist = np.linalg.norm(d1.center - d2.center)
                if dist < d1.radius + d2.radius:
                    raise ValueError("Disks overlap")
    
    def compose(self, i, other):
        """Compose: insert 'other' into the i-th disk."""
        new_disks = self.disks[:i] + self.disks[i+1:]
        target = self.disks[i]
        scaled = [d.scale_and_translate(target) for d in other.disks]
        new_disks[i:i] = scaled
        return LittleDisksConfiguration(new_disks)
    
    def plot(self, ax=None):
        """Visualize the configuration."""
        if ax is None:
            fig, ax = plt.subplots(1, 1, figsize=(6, 6))
        
        # Unit disk boundary
        theta = np.linspace(0, 2*np.pi, 100)
        ax.plot(np.cos(theta), np.sin(theta), 'k-', linewidth=2)
        
        # Little disks
        colors = plt.cm.tab10(np.linspace(0, 1, len(self.disks)))
        for disk, color in zip(self.disks, colors):
            circle = Circle(disk.center, disk.radius, 
                          fill=True, alpha=0.3, color=color, ec='black')
            ax.add_patch(circle)
            ax.plot(disk.center[0], disk.center[1], 'ko', markersize=3)
        
        ax.set_xlim(-1.2, 1.2)
        ax.set_ylim(-1.2, 1.2)
        ax.set_aspect('equal')
        ax.axis('off')
        return ax

2. Schemes: The Geometry of Rings

Tags: schemes algebraic-geometry sheaf-theory

Motivation

Classical algebraic geometry studies solutions to polynomial equations over algebraically closed fields like \(\mathbb{C}\). But number theorists care about solutions over \(\mathbb{Q}\), \(\mathbb{Z}\), and finite fields. Schemes, introduced by Alexander Grothendieck in the 1960s, unify these perspectives by viewing every commutative ring as a "space" of its prime ideals. This revolutionary insight allows geometry to encompass arithmetic, creating arithmetic geometry. The Weil conjectures, proved by Deligne using étale cohomology of schemes, demonstrated the power of this approach. Today, schemes are essential for moduli problems, deformation theory, and the Langlands program.

Definitions

  • Prime Spectrum: For a commutative ring \(A\), \(\text{Spec}(A)\) is the set of prime ideals of \(A\), with the Zariski topology where closed sets are \(V(I) = \{\mathfrak{p} : I \subseteq \mathfrak{p}\}\).
  • Structure Sheaf: \(\mathcal{O}_{\text{Spec}(A)}\) is the sheaf with \(\mathcal{O}(D(f)) = A_f\) (localization at \(f\)).
  • Affine Scheme: A locally ringed space \((X, \mathcal{O}_X)\) isomorphic to \((\text{Spec}(A), \mathcal{O}_{\text{Spec}(A)})\).
  • Scheme: A locally ringed space locally isomorphic to affine schemes.
  • Morphism of Schemes: A morphism of locally ringed spaces \((f, f^\#): (X, \mathcal{O}_X) \to (Y, \mathcal{O}_Y)\).
  • Fiber Product: For \(X \to S\) and \(Y \to S\), the fiber product \(X \times_S Y\) represents the functor \(T \mapsto X(T) \times_{S(T)} Y(T)\).

Theorem: Serre's Affineness Criterion

Theorem (Serre): Let \(X\) be a Noetherian scheme. Then \(X\) is affine if and only if: \[H^i(X, \mathcal{F}) = 0 \text{ for all } i > 0\] and all quasi-coherent sheaves \(\mathcal{F}\).

Corollary: If \(X\) is a proper scheme over an algebraically closed field with \(H^1(X, \mathcal{O}_X) = 0\) and \(X\) contains no complete curves, then \(X\) is affine.

Proof Sketch

The proof proceeds in several steps:

  1. (\(\Rightarrow\)) If \(X = \text{Spec}(A)\) is affine, then for any quasi-coherent sheaf \(\mathcal{F} = \widetilde{M}\), we have \(H^i(X, \mathcal{F}) = 0\) for \(i > 0\) by standard results on cohomology of affine schemes.
  2. (\(\Leftarrow\)) Let \(A = \Gamma(X, \mathcal{O}_X)\). The natural map \(X \to \text{Spec}(A)\) is the candidate isomorphism.
  3. Show this map is a homeomorphism using the vanishing of cohomology to prove separatedness and that closed points separate.
  4. Use the cohomology vanishing to show the map is an isomorphism of sheaves.

Notation Guide

  • \(\text{Spec}(A)\): Prime spectrum of ring \(A\)
  • \(\mathfrak{p}, \mathfrak{q}\): Prime ideals
  • \(A_f\): Localization of \(A\) at element \(f\)
  • \(A_\mathfrak{p}\): Localization at prime \(\mathfrak{p}\)
  • \(\mathcal{O}_X\): Structure sheaf
  • \(\widetilde{M}\): Sheaf associated to module \(M\)
  • \(H^i(X, \mathcal{F})\): Sheaf cohomology

3. Operator Algebras: Non-Commutative Geometry

Tags: operator-algebras functional-analysis noncommutative-geometry

Motivation

What if we could do geometry on spaces that don't exist as point sets? Alain Connes' non-commutative geometry replaces spaces with algebras of functions, allowing "geometry" of quantum spaces, foliations, and fractals. C*-algebras and von Neumann algebras, the two main classes of operator algebras, emerged from quantum mechanics where observables are operators on Hilbert space. The classification of factors by Murray and von Neumann revealed a deep structure theory. Today, operator algebras connect to knot theory (Jones polynomial), group theory (von Neumann algebras of groups), and the standard model of particle physics (Connes-Chamseddine spectral action).

Definitions

  • C*-Algebra: A Banach algebra \(A\) with involution * satisfying \(\|a^*a\| = \|a\|^2\).
  • Von Neumann Algebra: A *-subalgebra of \(B(H)\) (bounded operators on Hilbert space) closed in the weak operator topology.
  • Spectrum: For \(a \in A\), \(\sigma(a) = \{\lambda \in \mathbb{C} : a - \lambda 1 \text{ not invertible}\}\).
  • State: A positive linear functional \(\phi: A \to \mathbb{C}\) with \(\phi(1) = 1\).
  • GNS Construction: From a state \(\phi\), constructs a representation \(\pi_\phi: A \to B(H_\phi)\).
  • Factor: A von Neumann algebra with trivial center (\(Z(M) = \mathbb{C}I\)).
  • Type Classification: Factors classified as I\(_n\), I\(_\infty\), II\(_1\), II\(_\infty\), III\(_\lambda\) based on the range of the dimension function.

Theorem: Gelfand-Naimark Theorem

Theorem (Gelfand-Naimark): Every C*-algebra is isometrically *-isomorphic to a norm-closed *-subalgebra of \(B(H)\) for some Hilbert space \(H\).

Commutative Version: Every commutative C*-algebra with unit is isomorphic to \(C(X)\) for some compact Hausdorff space \(X\).

Proof Sketch (Commutative Case)

  1. Let \(A\) be a commutative unital C*-algebra. Define \(\hat{A}\) = space of characters (nonzero *-homomorphisms \(A \to \mathbb{C}\)).
  2. Give \(\hat{A}\) the weak* topology, making it a compact Hausdorff space.
  3. Define the Gelfand transform \(\Gamma: A \to C(\hat{A})\) by \(\Gamma(a)(\chi) = \chi(a)\).
  4. Show \(\Gamma\) is an isometric *-isomorphism using that \(\|\Gamma(a)\| = \sup_{\chi} |\chi(a)| = r(a) = \|a\|\) for self-adjoint \(a\).

Notation Guide

  • \(B(H)\): Bounded operators on Hilbert space \(H\)
  • \(a^*\): Adjoint of operator \(a\)
  • \(\sigma(a)\): Spectrum of \(a\)
  • \(r(a)\): Spectral radius \(\sup\{| \lambda| : \lambda \in \sigma(a)\}\)
  • \(\hat{A}\): Character space (spectrum) of \(A\)
  • \(\Gamma\): Gelfand transform
  • \(M'\): Commutant of \(M\)

import numpy as np
from numpy.linalg import eigvals, norm

class CStarAlgebraElement:
    """Represents an element of a matrix C*-algebra M_n(ℂ)."""
    def __init__(self, matrix):
        self.matrix = np.array(matrix, dtype=complex)
        self._validate()
    
    def _validate(self):
        """Ensure matrix is square."""
        if self.matrix.shape[0] != self.matrix.shape[1]:
            raise ValueError("Matrix must be square")
    
    def __add__(self, other):
        return CStarAlgebraElement(self.matrix + other.matrix)
    
    def __mul__(self, other):
        return CStarAlgebraElement(self.matrix @ other.matrix)
    
    def star(self):
        """Involution: conjugate transpose."""
        return CStarAlgebraElement(self.matrix.conj().T)
    
    def norm(self):
        """C*-norm: operator norm."""
        return norm(self.matrix, 2)  # spectral norm
    
    def spectrum(self):
        """Spectrum: eigenvalues."""
        return eigvals(self.matrix)
    
    def spectral_radius(self):
        """Spectral radius: max |eigenvalue|."""
        return max(abs(ev) for ev in self.spectrum())
    
    def is_self_adjoint(self, tol=1e-10):
        """Check if a = a*."""
        return norm(self.matrix - self.matrix.conj().T) < tol
    
    def is_unitary(self, tol=1e-10):
        """Check if a*a = aa* = I."""
        identity = np.eye(self.matrix.shape[0])
        return (norm(self.star().matrix @ self.matrix - identity) < tol and
                norm(self.matrix @ self.star().matrix - identity) < tol)
    
    def is_positive(self, tol=1e-10):
        """Check if spectrum is non-negative."""
        return all(ev.real > -tol for ev in self.spectrum())
    
    def __repr__(self):
        return f"C*({self.matrix.round(3)})"

class State:
    """A state on M_n(ℂ): positive linear functional with φ(I) = 1."""
    def __init__(self, density_matrix):
        """Density matrix: positive, trace = 1."""
        self.rho = np.array(density_matrix, dtype=complex)
        assert np.isclose(np.trace(self.rho), 1), "Trace must be 1"
        assert all(ev.real >= -1e-10 for ev in eigvals(self.rho)), "Must be positive"
    
    def evaluate(self, a):
        """φ(a) = tr(ρa)."""
        return np.trace(self.rho @ a.matrix)
    
    def is_pure(self, tol=1e-10):
        """Pure state iff ρ is projection onto 1-dim subspace."""
        return np.isclose(np.trace(self.rho @ self.rho), 1, atol=tol)

1. Bayesian Statistics: Belief Updating

Tags: bayesian-statistics statistical-inference machine-learning

Real-World Motivation

How should we update our beliefs when we see new evidence? Bayesian statistics provides the coherent framework, treating parameters as random variables with prior distributions that get updated to posteriors via Bayes' theorem. Unlike frequentist methods that treat parameters as fixed unknowns, Bayesian methods naturally quantify uncertainty and incorporate domain knowledge through priors. Applications span medical diagnosis (updating disease probability given test results), spam filtering, A/B testing, and modern AI (Bayesian neural networks, Gaussian processes). The recent explosion in computational methods (MCMC, variational inference) has made Bayesian analysis practical for complex models.

Definitions

  • Prior Distribution \(p(\theta)\): Beliefs about parameters before seeing data.
  • Likelihood \(p(x|\theta)\): Probability of data given parameters.
  • Posterior Distribution \(p(\theta|x)\): Updated beliefs after seeing data.
  • Bayes' Theorem: \[p(\theta|x) = \frac{p(x|\theta)p(\theta)}{p(x)}\]
  • Evidence \(p(x)\): \(\int p(x|\theta)p(\theta)d\theta\) (marginal likelihood).
  • Conjugate Prior: Prior where posterior is in the same family (e.g., Beta prior for Binomial likelihood gives Beta posterior).
  • Credible Interval: Bayesian analog of confidence interval—an interval containing the parameter with specified posterior probability.

Theorem: Bernstein-von Mises Theorem

Theorem (Bernstein-von Mises): Under regularity conditions, as \(n \to \infty\): \[\sqrt{n}(\theta - \hat{\theta}_n) | X^n \xrightarrow{d} \mathcal{N}(0, I(\theta_0)^{-1})\] where \(\hat{\theta}_n\) is the MLE and \(I(\theta_0)\) is the Fisher information at the true parameter.

Interpretation: With enough data, the posterior concentrates around the true value, and Bayesian credible intervals coincide with frequentist confidence intervals.

Proof Sketch

  1. Expand log posterior around MLE: \(\log p(\theta|x) \approx \log p(\hat{\theta}|x) + \frac{1}{2}(\theta-\hat{\theta})^T H(\hat{\theta})(\theta-\hat{\theta})\)
  2. The Hessian \(H(\hat{\theta}) \approx -nI(\theta_0)\) by law of large numbers.
  3. Thus posterior \(\approx \mathcal{N}(\hat{\theta}, (nI(\theta_0))^{-1})\).

Notation Guide

  • \(\theta\): Parameter(s)
  • \(x\): Observed data
  • \(p(\theta|x)\): Posterior density
  • \(\propto\): Proportional to
  • \(\mathbb{E}[\theta|x]\): Posterior mean
  • \(\text{Var}(\theta|x)\): Posterior variance
  • \(I(\theta)\): Fisher information matrix

    """Bayesian inference for Beta-Binomial model."""
    
    def __init__(self, alpha_prior=1, beta_prior=1):
        """Initialize with Beta(α, β) prior."""
        self.alpha_prior = alpha_prior
        self.beta_prior = beta_prior
        self.alpha_post = alpha_prior
        self.beta_post = beta_prior
        self.n_trials = 0
        self.n_successes = 0
    
    def update(self, successes, trials):
        """Update posterior with observed data."""
        self.n_successes += successes
        self.n_trials += trials
        self.alpha_post = self.alpha_prior + self.n_successes
        self.beta_post = self.beta_prior + (self.n_trials - self.n_successes)
    
    def posterior_mean(self):
        """E[θ|data] = α_post / (α_post + β_post)"""
        return self.alpha_post / (self.alpha_post + self.beta_post)
    
    def posterior_mode(self):
        """Mode of Beta distribution."""
        if self.alpha_post > 1 and self.beta_post > 1:
            return (self.alpha_post - 1) / (self.alpha_post + self.beta_post - 2)
        return None
    
    def credible_interval(self, level=0.95):
        """Highest Posterior Density interval."""
        lower = (1 - level) / 2
        upper = 1 - lower
        return stats.beta.ppf([lower, upper], self.alpha_post, self.beta_post)
    
    def posterior_pdf(self, theta):
        """Posterior density at θ."""
        return stats.beta.pdf(theta, self.alpha_post, self.beta_post)
    
    def predictive_prob(self, successes, trials):
        """Posterior predictive: P(future successes | data)."""
        # Beta-Binomial predictive
        from scipy.special import comb, beta
        k, n = successes, trials
        alpha, beta_param = self.alpha_post, self.beta_post
        numerator = comb(n, k) * beta(alpha + k, beta_param + n - k)
        denominator = beta(alpha, beta_param)
        return numerator / denominator

def mcmc_sampler(log_posterior, initial, n_samples=10000, step_size=0.1):
    """Simple Metropolis-Hastings MCMC sampler."""
    samples = [initial]
    current = initial
    current_log_prob = log_posterior(current)
    
    accepts = 0
    for _ in range(n_samples):
        proposal = current + np.random.normal(0, step_size)
        proposal_log_prob = log_posterior(proposal)
        
        log_alpha = proposal_log_prob - current_log_prob
        if np.log(np.random.uniform()) < log_alpha:
            current = proposal
            current_log_prob = proposal_log_prob
            accepts += 1
        samples.append(current)
    
    return np.array(samples), accepts / n_samples

2. Mathematical Epidemiology: SIR Models

Tags: epidemiology differential-equations population-dynamics

Real-World Motivation

How do infectious diseases spread through populations, and what interventions can control them? Mathematical epidemiology provides the tools to answer these critical questions. The COVID-19 pandemic demonstrated the vital importance of epidemic modeling for public health policy. The basic SIR model, introduced by Kermack and McKendrick in 1927, divides the population into Susceptible, Infected, and Recovered compartments. Extensions include SEIR (with Exposed), SIRS (waning immunity), and age-structured models. The basic reproduction number \(R_0\) determines whether an epidemic occurs. Models guide vaccination strategies, lockdown policies, and resource allocation in healthcare systems.

Definitions

  • SIR Model: System of ODEs: \[\frac{dS}{dt} = -\beta SI/N, \quad \frac{dI}{dt} = \beta SI/N - \gamma I, \quad \frac{dR}{dt} = \gamma I\]
  • Basic Reproduction Number \(R_0\): Average secondary infections from one infected in a fully susceptible population: \(R_0 = \beta/\gamma\).
  • Herd Immunity Threshold: Fraction that must be immune to prevent spread: \(1 - 1/R_0\).
  • Final Size: Total fraction infected during epidemic, satisfying \(R(\infty) = 1 - S(0)e^{-R_0 R(\infty)}\).
  • Effective Reproduction Number \(R_t\): \(R_0 S(t)/N\), time-varying reproduction number.
  • Doubling Time: Time for infections to double during early exponential phase.

Theorem: Epidemic Threshold

Theorem: For the SIR model with initial conditions \(S(0) \approx N\), \(I(0) > 0\) small:

  • If \(R_0 \leq 1\): Infection dies out, \(I(t) \to 0\) monotonically.
  • If \(R_0 > 1\): Epidemic occurs with initial exponential growth \(I(t) \sim I(0)e^{(R_0-1)\gamma t}\).

Peak Infection: Occurs when \(S = N/R_0\), with maximum \(I_{\max} = I(0) + S(0) - \frac{N}{R_0}(1 + \log(R_0 S(0)/N))\).

Proof Sketch

  1. Linearize at disease-free equilibrium \((S,I,R) = (N,0,0)\). Jacobian eigenvalues determine stability.
  2. Eigenvalue \(\lambda = \beta - \gamma = \gamma(R_0 - 1)\). Positive when \(R_0 > 1\).
  3. Peak occurs when \(dI/dt = 0\), i.e., \(\beta S I/N = \gamma I\), giving \(S = N\gamma/\beta = N/R_0\).

Notation Guide

  • \(S(t)\): Susceptible population
  • \(I(t)\): Infected (infectious) population
  • \(R(t)\): Recovered/removed population
  • \(N = S + I + R\): Total population
  • \(\beta\): Transmission rate
  • \(\gamma\): Recovery rate (\(1/\gamma\) = infectious period)
  • \(R_0\): Basic reproduction number

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

class SIRModel:
    """SIR epidemic model."""
    
    def __init__(self, beta, gamma, N):
        self.beta = beta      # Transmission rate
        self.gamma = gamma    # Recovery rate
        self.N = N            # Total population
        self.R0 = beta / gamma
    
    def deriv(self, y, t):
        """SIR differential equations."""
        S, I, R = y
        dSdt = -self.beta * S * I / self.N
        dIdt = self.beta * S * I / self.N - self.gamma * I
        dRdt = self.gamma * I
        return [dSdt, dIdt, dRdt]
    
    def simulate(self, S0, I0, R0, t):
        """Simulate SIR model."""
        y0 = [S0, I0, R0]
        result = odeint(self.deriv, y0, t)
        return result[:, 0], result[:, 1], result[:, 2]
    
    def herd_immunity_threshold(self):
        """Fraction that must be immune."""
        if self.R0 <= 1:
            return 0
        return 1 - 1/self.R0
    
    def peak_infection(self, S0, I0):
        """Calculate peak infection level."""
        S_peak = self.N / self.R0
        # Conservation: S + I + R = N, and from dS/dR relation
        # S(S0) = S0 * exp(-R0*(N-S)/N)
        # At peak: I_max = N - S_peak - R_peak
        # Using S + I + R = N and R = N - S - I
        # From dS/dR = -S*R0/N, we get S = S0*exp(-R0*R/N)
        # At peak: I = N - S_peak - R where S_peak = N/R0
        # So R = N - N/R0 - I, need to solve iteratively
        
        # Actually use: I_max = I0 + S0 - S_peak + (N/R0)*ln(S_peak/S0)
        I_max = I0 + S0 - S_peak + (self.N/self.R0) * np.log(S_peak/S0)
        return S_peak, I_max
    
    def final_size(self, S0):
        """Solve final size equation: R_inf = 1 - S0/N * exp(-R0*R_inf)"""
        from scipy.optimize import fsolve
        def equation(R_inf):
            return R_inf - (1 - S0/self.N * np.exp(-self.R0 * R_inf))
        R_inf = fsolve(equation, 0.5)[0]
        return R_inf * self.N

3. Supply Chain Optimization: Inventory Theory

Tags: supply-chain operations-research stochastic-optimization

Real-World Motivation

How much inventory should a company hold to balance customer service with holding costs? This fundamental question of supply chain management affects everything from retail operations to vaccine distribution. The newsvendor problem, the simplest inventory model, captures the essence: order too much and incur holding costs, order too little and lose sales. Extensions include multi-echelon systems, stochastic lead times, and coordination mechanisms in supply chains. During the COVID-19 pandemic, inventory theory helped optimize vaccine allocation across regions. E-commerce giants use sophisticated inventory models to position products in fulfillment networks, minimizing delivery times while controlling costs.

Definitions

  • Newsvendor Problem: Single-period stochastic inventory with:
    • Order quantity \(q\), demand \(D\) (random)
    • Underage cost \(c_u\): cost of stocking one unit too few
    • Overage cost \(c_o\): cost of stocking one unit too many
    • Optimal service level: \(F(q^*) = \frac{c_u}{c_u + c_o}\)
  • (s, S) Policy: When inventory drops below \(s\), order up to \(S\).
  • Economic Order Quantity (EOQ): \(Q^* = \sqrt{2K\lambda/h}\) where \(K\) = fixed cost, \(\lambda\) = demand rate, \(h\) = holding cost.
  • Safety Stock: Buffer inventory: \(ss = z_\alpha \sigma_L\) where \(\sigma_L\) is lead time demand std dev.
  • Bullwhip Effect: Demand variability amplification upstream in supply chains.

Theorem: Newsvendor Optimality

Theorem: For the newsvendor problem with demand distribution \(F\), the optimal order quantity is: \[q^* = F^{-1}\left(\frac{c_u}{c_u + c_o}\right)\]

Expected Profit: \(\mathbb{E}[\pi(q^*)] = (p-c)\mu - (c_u + c_o)\phi(z_\alpha)\sigma\) where \(z_\alpha = \Phi^{-1}(\alpha)\), \(\alpha = c_u/(c_u+c_o)\).

Value of Perfect Information: \(\text{VOI} = (c_u + c_o)\sigma\phi(z_\alpha)\).

Proof Sketch

  1. Profit: \(\pi(q) = p\min(q,D) - cq + s\max(q-D,0)\) where \(p\)=price, \(c\)=cost, \(s\)=salvage.
  2. Define \(c_u = p-c\) (underage) and \(c_o = c-s\) (overage).
  3. Expected profit: \(\mathbb{E}[\pi(q)] = (p-c)q - (p-s)\mathbb{E}[(q-D)^+]\).
  4. Take derivative, use Leibniz rule: \(\frac{d}{dq}\mathbb{E}[\pi(q)] = c_u - (c_u+c_o)F(q) = 0\).
  5. Solve: \(F(q^*) = c_u/(c_u+c_o)\).

Notation Guide

  • \(q\): Order quantity
  • \(D\): Random demand
  • \(F(x)\): CDF of demand
  • \(f(x)\): PDF of demand
  • \(c_u = p-c\): Underage cost (lost profit)
  • \(c_o = c-s\): Overage cost (excess inventory)
  • \(\alpha = c_u/(c_u+c_o)\): Critical fractile
  • \(z_\alpha\): \(\alpha\)-quantile of standard normal

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats
from scipy.optimize import minimize_scalar

class NewsvendorModel:
    """Newsvendor inventory model."""
    
    def __init__(self, demand_dist, p, c, s=0):
        """
        demand_dist: scipy distribution object
        p: selling price
        c: unit cost
        s: salvage value (default 0)
        """
        self.demand_dist = demand_dist
        self.p = p
        self.c = c
        self.s = s
        self.cu = p - c  # underage cost
        self.co = c - s  # overage cost
        self.critical_fractile = self.cu / (self.cu + self.co)
    
    def optimal_quantity(self):
        """Optimal order quantity: F^(-1)(critical fractile)."""
        return self.demand_dist.ppf(self.critical_fractile)
    
    def expected_profit(self, q):
        """Expected profit for order quantity q."""
        # E[profit] = p*E[min(q,D)] - c*q + s*E[max(q-D,0)]
        # = (p-s)*E[min(q,D)] - (c-s)*q
        # = (p-s)*(E[D] - E[(D-q)^+]) - (c-s)*q
        
        # Alternative: use integration
        def integrand(d):
            sales = min(q, d)
            leftover = max(q - d, 0)
            return self.p * sales - self.c * q + self.s * leftover
        
        # Numerical integration
        lower, upper = self.demand_dist.ppf([0.001, 0.999])
        result = 0
        for d in np.linspace(lower, upper, 1000):
            result += integrand(d) * self.demand_dist.pdf(d)
        result *= (upper - lower) / 1000
        return result
    
    def expected_profit_analytical(self, q):
        """Analytical expected profit for normal demand."""
        mu = self.demand_dist.mean()
        sigma = self.demand_dist.std()
        z = (q - mu) / sigma
        
        # E[min(q,D)] = mu - sigma*L(z) where L(z) = φ(z) - z(1-Φ(z))
        L_z = stats.norm.pdf(z) - z * (1 - stats.norm.cdf(z))
        expected_sales = mu - sigma * L_z
        
        # E[max(q-D,0)] = q - expected_sales + E[(D-q)^+]
        # = sigma * (z + L_z)
        expected_leftover = sigma * (z + L_z)
        
        profit = self.p * expected_sales - self.c * q + self.s * expected_leftover
        return profit
    
    def value_of_perfect_information(self):
        """Expected value of knowing demand before ordering."""
        q_opt = self.optimal_quantity()
        profit_imperfect = self.expected_profit_analytical(q_opt)
        
        # With perfect info, order exactly D
        # E[profit|D] = (p-c)*D, so E[profit] = (p-c)*E[D]
        profit_perfect = (self.p - self.c) * self.demand_dist.mean()
        
        return profit_perfect - profit_imperfect

class EOQModel:
    """Economic Order Quantity model."""
    
    def __init__(self, K, lambda_demand, h, c=0):
        """
        K: fixed ordering cost
        lambda_demand: demand rate (units per time)
        h: holding cost per unit per time
        c: unit cost (for total cost, not EOQ itself)
        """
        self.K = K
        self.lambda_d = lambda_demand
        self.h = h
        self.c = c
    
    def optimal_quantity(self):
        """EOQ = sqrt(2*K*λ/h)."""
        return np.sqrt(2 * self.K * self.lambda_d / self.h)
    
    def cycle_time(self):
        """Time between orders."""
        return self.optimal_quantity() / self.lambda_d
    
    def total_cost_rate(self, Q=None):
        """Total cost per unit time."""
        if Q is None:
            Q = self.optimal_quantity()
        ordering_cost = self.K * self.lambda_d / Q
        holding_cost = self.h * Q / 2
        purchase_cost = self.c * self.lambda_d
        return ordering_cost + holding_cost + purchase_cost

1. Motives: Universal Cohomology Theory

Tags: motives algebraic-geometry cohomology

Historical Context

In the 1960s, Alexander Grothendieck envisioned a universal cohomology theory for algebraic varieties—one that would explain the striking parallels between different cohomology theories (Betti, de Rham, étale, crystalline). He called the objects of this conjectural category "motives," suggesting they should be the fundamental building blocks of algebraic varieties, much like motives in music are building blocks of compositions. The standard conjectures, which remain open, would establish the existence of this category. While the full theory remains conjectural, significant progress came through Voevodsky's triangulated category of motives (for which he received the Fields Medal in 2002) and the theory of pure motives for smooth projective varieties. The Hodge conjecture and Tate conjecture are special cases of the standard conjectures.

Definitions

  • Pure Motive: For smooth projective varieties, motives are constructed using algebraic cycles modulo equivalence relations (rational, homological, numerical).
  • Chow Motive: Object in the category with:
    • Objects: \((X, p, m)\) where \(X\) is smooth projective, \(p\) is a projector (\(p^2 = p\) in Chow ring), \(m\) is twist
    • Morphisms: Correspondences (algebraic cycles on product)
  • Lefschetz Motive: \(\mathbb{L} = (\mathbb{P}^1, \mathbb{P}^1 - \{pt\}, 0)\), the motive of a line.
  • Tate Motive: \(\mathbb{Q}(1) = \mathbb{L}^{-1}\), fundamental for weights.
  • Mixed Motive: Extension of pure motives to all varieties, allowing extensions (non-semisimple).

Theorem: Decomposition of the Diagonal

Theorem: For a smooth projective variety \(X\) of dimension \(n\), the diagonal \(\Delta_X \subset X \times X\) decomposes in cohomology as: \[\Delta_X = \sum_{i=0}^{2n} \pi_i\]

where \(\pi_i\) are orthogonal projectors inducing the Künneth decomposition \(H^*(X) = \bigoplus H^i(X)\).

Standard Conjecture B: The \(\pi_i\) are algebraic (come from algebraic cycles).

Proof Sketch

  1. The diagonal acts as identity on cohomology by the projection formula.
  2. Künneth formula gives \(H^*(X \times X) = H^*(X) \otimes H^*(X)\).
  3. Define \(\pi_i\) to project onto \(H^i(X)\) in the first factor and dual in second.
  4. Standard Conjecture B asserts these projectors are represented by algebraic cycles.

Notation Guide

  • \(M(X)\): Motive of variety \(X\)
  • \(\mathbb{L}\): Lefschetz motive
  • \(\mathbb{Q}(n)\): Tate twist
  • \(CH^*(X)\): Chow ring (algebraic cycles)
  • \(\sim\): Equivalence relation on cycles (rational, homological, numerical)
  • \(\pi_i\): Künneth projectors

    """Simplified model of a Chow motive."""
    
    def __init__(self, name, dimension, betti_numbers, projector=None):
        """

        projector: algebraic projector (simplified as weights)
        """

        return [i for i, b in enumerate(self.betti) if b > 0]

        """χ(X) = Σ(-1)^i b_i."""
        return sum((-1)**i * b for i, b in enumerate(self.betti))
    
    def hodge_diamond(self, hodge_numbers=None):
        """Print Hodge diamond (for complex varieties)."""
        if hodge_numbers is None:
            # Simplified: assume b_i = sum of hodge numbers on diagonal
            n = self.dim
            diamond = []
            for i in range(n + 1):

                for j in range(i + 1):

                    if i - j <= n and j <= n:
                        # Simplified: assume primitive
                        row.append(1 if i <= self.betti[i] else 0)
                diamond.append(row)
            return diamond
        return hodge_numbers

        """Decompose with respect to Lefschetz motive."""
        # M(X) = ⊕ L^i ⊗ M_i (primitive parts)

    def twist(self, n):
        """Tate twist M(n) = M ⊗ L^{-n}."""
        return Motive(f"{self.name}({n})", self.dim, self.betti, self.projector)
    
    def __add__(self, other):
        """Direct sum of motives."""
        name = f"{self.name} ⊕ {other.name}"
        dim = max(self.dim, other.dim)
        betti = [a + b for a, b in zip(self.betti, other.betti)]
        return Motive(name, dim, betti)
    
    def __mul__(self, other):
        """Tensor product of motives (product variety)."""
        name = f"{self.name} × {other.name}"
        dim = self.dim + other.dim
        # Kunneth: b_k(X × Y) = Σ b_i(X) * b_{k-i}(Y)
        betti = []
        for k in range(len(self.betti) + len(other.betti) - 1):
            bk = sum(self.betti[i] * other.betti[k-i] 
                    for i in range(len(self.betti)) 
                    if k-i >= 0 and k-i < len(other.betti))
            betti.append(bk)
        return Motive(name, dim, betti)
    
    def __repr__(self):
        return f"Motive({self.name}, dim={self.dim}, χ={self.euler_characteristic()})"

2. Spectral Sequences: Computational Machinery

Tags: spectral-sequences homological-algebra algebraic-topology

Historical Context

Spectral sequences, introduced by Jean Leray in the 1940s while he was a prisoner of war, have become the most powerful computational tool in algebraic topology and homological algebra. Leray originally developed them to compute sheaf cohomology, but they found immediate applications in computing homology of fibrations (Serre spectral sequence), derived functors (Grothendieck spectral sequence), and stable homotopy groups (Adams spectral sequence). The seemingly complex machinery—pages, differentials, convergence—hides a simple idea: compute complicated objects by successive approximations, refining at each stage. The "five spectral sequences of the apocalypse" (Serre, Adams, Eilenberg-Moore, Atiyah-Hirzebruch, Lyndon-Hochschild-Serre) are essential tools for any working algebraic topologist.

Definitions

  • Homological Spectral Sequence: Collection \(\{E^r_{p,q}, d^r_{p,q}\}\) where:
    • \(E^r_{p,q}\) are abelian groups (page \(r\), position \((p,q)\))
    • \(d^r_{p,q}: E^r_{p,q} \to E^r_{p-r,q+r-1}\) is differential with \(d^r \circ d^r = 0\)
    • \(E^{r+1}_{p,q} = H(E^r_{p,q}) = \ker(d^r)/\text{im}(d^r)\)
  • Convergence: \(E^r_{p,q} \Rightarrow H_{p+q}\) means there exists a filtration \(F_p H_n\) with \(E^\infty_{p,q} \cong F_p H_{p+q}/F_{p-1} H_{p+q}\).
  • Serre Spectral Sequence: For fibration \(F \to E \to B\): \(E^2_{p,q} = H_p(B; H_q(F)) \Rightarrow H_{p+q}(E)\).
  • Collapse: If all differentials vanish, \(E^2 = E^\infty\).

Theorem: Leray-Serre Spectral Sequence

Theorem: Let \(p: E \to B\) be a fibration with fiber \(F\) and \(B\) path-connected. If \(\pi_1(B)\) acts trivially on \(H_*(F)\), there exists a spectral sequence with: \[E^2_{p,q} = H_p(B; H_q(F))\]

converging to \(H_{p+q}(E)\). The differential has bidegree \((-r, r-1)\).

Edge Homomorphisms: \(H_n(E) \to E^\infty_{0,n} \subset E^2_{0,n} = H_n(F)\) and \(H_n(B) = E^2_{n,0} \twoheadrightarrow E^\infty_{n,0} \subset H_n(E)\).

Proof Sketch

  1. Filter the total space by inverse images of skeleta of \(B\).
  2. This induces a filtration on the singular chain complex \(C_*(E)\).
  3. The spectral sequence of this filtered complex has \(E^1_{p,q} = H_{p+q}(E_p, E_{p-1})\).
  4. Use excision and the fibration structure to identify \(E^2_{p,q} = H_p(B; H_q(F))\).

Notation Guide

  • \(E^r_{p,q}\): Page \(r\), position \((p,q)\) (homological grading)
  • \(d^r\): Differential on page \(r\)
  • \(E^\infty_{p,q}\): Limit term
  • \(F \to E \to B\): Fibration with fiber \(F\), total space \(E\), base \(B\)
  • \(H_p(B; G)\): Homology with coefficients in \(G\)
  • \(\Rightarrow\): Converges to

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import FancyArrowPatch

class SpectralSequence:
    """Simplified model of a first quadrant spectral sequence."""
    
    def __init__(self, name, E2_page):
        """
        name: identifier
        E2_page: dict mapping (p,q) -> rank (dimension)
        """
        self.name = name
        self.pages = {2: E2_page}
        self.differentials = {}
    
    def add_differential(self, r, source, target):
        """Add a differential d^r: source -> target."""
        if r not in self.differentials:
            self.differentials[r] = []
        self.differentials[r].append((source, target))
    
    def compute_page(self, r):
        """Compute page r from previous pages."""
        if r in self.pages:
            return self.pages[r]
        
        # Start from previous page
        prev_page = self.compute_page(r-1).copy()
        
        if r in self.differentials:
            for source, target in self.differentials[r]:
                # Simplified: assume differential is isomorphism where defined
                if source in prev_page and target in prev_page:
                    # Kill source and target (simplified model)
                    min_rank = min(prev_page[source], prev_page[target])
                    prev_page[source] -= min_rank
                    prev_page[target] -= min_rank
                    if prev_page[source] == 0:
                        del prev_page[source]
                    if prev_page[target] == 0:
                        del prev_page[target]
        
        self.pages[r] = prev_page
        return prev_page
    
    def E_infinity(self, max_page=10):
        """Compute E^infinity (simplified)."""
        for r in range(2, max_page + 1):
            self.compute_page(r)
        return self.pages.get(max_page, {})
    
    def plot(self, max_p=6, max_q=6, page=2):
        """Visualize spectral sequence page."""
        E = self.pages.get(page, {})
        
        fig, ax = plt.subplots(figsize=(10, 8))
        
        # Draw grid

            for q in range(max_q + 1):
                if (p, q) in E and E[(p, q)] > 0:

                    ax.text(p, q, str(E[(p, q)]), ha='center', va='center',

            for source, target in self.differentials[page]:
                if source[0] <= max_p and source[1] <= max_q:
                    dx = target[0] - source[0]
                    dy = target[1] - source[1]
                    ax.arrow(source[0], source[1], dx*0.7, dy*0.7,
                            head_width=0.1, head_length=0.1, fc='red', ec='red',
                            length_includes_head=True)
        
        ax.set_xlim(-0.5, max_p + 0.5)
        ax.set_ylim(-0.5, max_q + 0.5)
        ax.set_xlabel('p (filtration degree)')
        ax.set_ylabel('q (complementary degree)')
        ax.set_title(f'{self.name}: E^{page}_{{p,q}}')
        ax.set_aspect('equal')
        ax.grid(True, alpha=0.3)
        
        # Add total degree lines
        for n in range(max_p + max_q + 1):
            ax.plot([0, n], [n, 0], 'g--', alpha=0.2, linewidth=0.5)
        
        return fig, ax

3. Sophie Germain: The Masked Mathematician

Tags: sophie-germain number-theory history-of-mathematics

Historical Context

Sophie Germain (1776–1831) was one of the most remarkable mathematicians of her era, overcoming extraordinary barriers to make fundamental contributions to number theory and elasticity theory. Barred from formal education because of her gender, she taught herself mathematics from her father's library, studying Latin and Greek to read Newton and Euler. When the École Polytechnique opened in 1794, women were excluded—so Germain obtained lecture notes and submitted work under the pseudonym "M. Le Blanc." Lagrange, impressed by her analysis, became her mentor and discovered her true identity. Gauss, too, corresponded with her, praising her work on Fermat's Last Theorem. Her theorem on what are now called "Germain primes" was the most significant progress on Fermat's Last Theorem between Fermat and Kummer.

Definitions

  • Sophie Germain Prime: A prime \(p\) such that \(2p + 1\) is also prime. Examples: 2, 3, 5, 11, 23, 29, 41, 53, 83, 89.
  • Safe Prime: A prime of the form \(2p + 1\) where \(p\) is also prime (the larger prime in a Germain pair).
  • Germain's Theorem: If \(p\) is a Germain prime, then any solution to \(x^p + y^p = z^p\) must have \(p\) dividing \(xyz\) (Case I of Fermat's Last Theorem has no solutions).
  • Germain Curvature: In elasticity theory, the mean curvature measure she developed for modeling vibrating plates.

Theorem: Sophie Germain's Theorem on Fermat's Last Theorem

Theorem (Sophie Germain, c. 1820): Let \(p\) be an odd prime such that \(q = 2p + 1\) is also prime. Then the equation: \[x^p + y^p + z^p = 0\]

has no solutions in nonzero integers \(x, y, z\) with \(p \nmid xyz\) (Case I).

Corollary: Fermat's Last Theorem holds for exponent \(p\) if there exists an auxiliary prime \(\theta\) satisfying certain conditions (now called Germain's condition).

Proof Sketch

  1. Assume \(x^p + y^p + z^p = 0\) with \(p \nmid xyz\) and \(\gcd(x,y,z) = 1\).
  2. Factor: \((x + y)(x + \zeta y) \cdots (x + \zeta^{p-1}y) = (-z)^p\) where \(\zeta = e^{2\pi i/p}\).
  3. The factors are "almost" coprime in \(\mathbb{Z}[\zeta]\).
  4. Germain showed that if \(q = 2p + 1\) is prime, then certain congruences force \(q \mid xyz\).
  5. But also \(q \nmid xyz\) from the equation, contradiction.

Notation Guide

  • \(p\): Germain prime
  • \(q = 2p + 1\): Associated safe prime
  • \(\zeta_p\): Primitive \(p\)-th root of unity
  • \(\mathbb{Z}[\zeta_p]\): Ring of cyclotomic integers
  • Case I: \(p \nmid xyz\)
  • Case II: \(p \mid xyz\)

    """Check if p is a Sophie Germain prime (2p+1 also prime)."""
    return isprime(p) and isprime(2*p + 1)

📜 Math History: The Birth of Abstract Algebra

The 19th century witnessed a profound transformation in mathematics: the shift from studying specific objects to studying abstract structures. This revolution, which gave birth to modern abstract algebra, fundamentally changed how mathematicians think about their subject.

The story begins with the resolution of a 350-year-old problem. In 1799, Paolo Ruffini and later Niels Henrik Abel (1824) proved that there is no general solution using radicals for polynomial equations of degree five or higher. This was shocking—after centuries of success with quadratic, cubic, and quartic formulas, the pattern simply stopped. But the deeper understanding came from Évariste Galois, who in 1832, at the age of 20 and the night before his fatal duel, outlined a theory connecting field extensions to groups of permutations.

Galois's insight was revolutionary: the solvability of an equation depends not on the equation itself but on the structure of its associated group. An equation is solvable by radicals if and only if its Galois group is solvable. This was the first major instance of translating a problem about one type of object (polynomials) into a problem about another (groups), solving it there, and translating back.

Meanwhile, geometry was undergoing its own abstraction. In the mid-19th century, Arthur Cayley and others realized that the algebraic properties of vectors could be studied without reference to geometric visualization. Matrices, originally just arrays of numbers useful for solving systems of equations, became objects of study in their own right. The concept of an abstract vector space emerged, defined purely by axioms: a set with operations satisfying certain properties, with no commitment to what the elements "are."

This axiomatic approach spread rapidly. Richard Dedekind introduced ideals in ring theory, studying factorization in algebraic number fields. Felix Klein's Erlangen Program (1872) proposed that geometries could be classified by their transformation groups. Sophus Lie developed continuous groups (Lie groups) to study differential equations, paralleling Galois's discrete theory.

By the early 20th century, the transformation was complete. Emmy Noether, perhaps the most influential algebraist of the era, demonstrated the power of studying abstract structures. Her theorem establishing the correspondence between subgroups and intermediate fields in Galois theory became foundational. Her work on ideal theory in commutative rings unified previous results and established the modern approach.

The impact extended far beyond algebra. The structural approach influenced topology (Poincaré's algebraic topology), analysis (Banach spaces, Hilbert spaces), and eventually all of mathematics. The Bourbaki group, founded in 1935, championed this structural view, producing influential texts that emphasized general theories over specific examples.

What drove this abstraction? Partly it was the success of Galois theory showing the power of structural thinking. Partly it was the growing complexity of mathematics, requiring organization. And partly it was a philosophical shift: mathematics came to be seen as the study of formal structures rather than truths about the physical world.

The legacy is everywhere in modern mathematics. Category theory, the ultimate abstraction, studies mathematical structures and their relationships at the highest level. Computer science inherits the algebraic perspective in abstract data types and functional programming. Physics uses group theory to classify particles and gauge theory to describe forces.

Yet the abstraction came with costs. Felix Klein warned against "the danger that the student may lose himself in formula-play." The tension between abstraction and intuition, between general theory and specific example, remains a live issue in mathematical pedagogy and practice. The best mathematicians, like Noether herself, moved fluently between abstract structures and concrete computations, using each to illuminate the other.

🎨 Visualization of the Day: The Dragon Curve

The dragon curve is a self-similar fractal obtained by repeatedly folding a strip of paper in half, then unfolding it so each fold creates a 90-degree angle. Despite its simple construction, it exhibits remarkable properties: it tiles the plane, has Hausdorff dimension 2, and its boundary is itself a fractal. The curve can be generated using an L-system or through recursive substitution rules.

The dragon curve appears in surprising places: in the analysis of algorithms (it describes the path of certain divide-and-conquer recursions), in number theory (it connects to paperfolding sequences and automatic sequences), and even in the design of computer chips (space-filling curves for circuit layout). Its boundary has been proven to have dimension approximately 1.5236.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon

def dragon_curve(n):
    """
    Generate dragon curve of order n using the turn sequence.
    The turn at step k is determined by the parity of the number of 
    trailing zeros in the binary representation of k+1.
    """
    # Turn sequence: 1 = left (90°), -1 = right (-90°)
    # Turn at step k if (((k+1) & -(k+1)) << 1) & (k+1) == 0
    turns = []
    for k in range(1, 2**n):
        # Count trailing zeros
        tz = (k & -k).bit_length() - 1
        # Turn is left if tz is odd, right if even
        turn = 1 if tz % 2 == 0 else -1
        turns.append(turn)
    
    # Build the curve
    directions = [(1, 0), (0, 1), (-1, 0), (0, -1)]  # right, up, left, down
    dir_idx = 0  # Start facing right
    
    x, y = [0], [0]
    for turn in turns:
        dir_idx = (dir_idx + turn) % 4
        dx, dy = directions[dir_idx]
        x.append(x[-1] + dx)
        y.append(y[-1] + dy)
    
    return np.array(x), np.array(y)

def dragon_curve_recursive(n):
    """Generate dragon curve using recursive definition."""
    if n == 0:
        return np.array([0, 1]), np.array([0, 0])
    
    # Get previous curve
    x_prev, y_prev = dragon_curve_recursive(n - 1)
    
    # Rotate 90° clockwise around endpoint
    # Endpoint of prev is (x_prev[-1], y_prev[-1])
    x_end, y_end = x_prev[-1], y_prev[-1]
    
    # Translate to origin, rotate, translate back
    x_trans = x_prev - x_end
    y_trans = y_prev - y_end
    
    # Rotate 90° clockwise: (x, y) -> (y, -x)
    x_rot = y_trans
    y_rot = -x_trans
    
    # Reverse and concatenate
    x_new = np.concatenate([x_prev, x_rot[::-1] + x_end])
    y_new = np.concatenate([y_prev, y_rot[::-1] + y_end])
    
    return x_new, y_new
