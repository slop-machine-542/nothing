🔬 Pure Math Deep-Dives

Galois Theory: The Symmetry of Equations

Motivation

Why can we solve quadratic, cubic, and quartic equations by radicals, but not general quintic equations? The answer lies in the hidden symmetry of polynomial equations. Évariste Galois discovered that the solvability of a polynomial is determined by the structure of a group associated with its roots—the Galois group.

Definitions

Field Extension: If \(F\) and \(E\) are fields with \(F \subseteq E\), we call \(E/F\) a field extension. The degree \([E:F]\) is the dimension of \(E\) as a vector space over \(F\).

Galois Group: For a field extension \(E/F\), the Galois group \(\text{Gal}(E/F)\) is the group of field automorphisms of \(E\) that fix \(F\) pointwise.

Theorem (Fundamental Theorem of Galois Theory)

Let \(E/F\) be a Galois extension with Galois group \(G = \text{Gal}(E/F)\). There is a bijective correspondence between intermediate fields \(K\) with \(F \subseteq K \subseteq E\) and subgroups \(H \leq G\).

Theorem (Insolvability of the Quintic)

The general polynomial of degree \(n \geq 5\) is not solvable by radicals.

# Galois Theory Example: Analyzing polynomial roots
import sympy as sp
from sympy import symbols

x = symbols('x')

# Quadratic: x^2 - 2 = 0
print("QUADRATIC: x² - 2 = 0")
print("Roots: ±√2")
print("Splitting field: ℚ(√2)")
print("Degree: [ℚ(√2):ℚ] = 2")
print("Galois group: ℤ/2ℤ")
print("Solvable by radicals: YES")

# Quintic: x^5 - x + 1 = 0
print("\nQUINTIC: x⁵ - x + 1 = 0")
print("Galois group: S₅ (order 120)")
print("S₅ is NOT solvable (A₅ is simple)")
print("Solvable by radicals: NO")

Ergodic Theory: The Statistics of Dynamical Systems

Motivation

When can we understand the long-term behavior of a dynamical system by studying its statistical properties? Ergodic theory, born from Boltzmann's work in statistical mechanics, provides the answer. It studies measure-preserving transformations and asks when time averages equal space averages.

Definitions

Measure-Preserving System: A quadruple \((X, \mathcal{B}, \mu, T)\) where \((X, \mathcal{B}, \mu)\) is a probability space and \(T: X \to X\) preserves measure.

Ergodicity: A system is ergodic if every invariant measurable set has measure 0 or 1.

Theorem (Birkhoff's Ergodic Theorem)

Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(f \in L^1(\mu)\). Then the time average \(\hat{f}(x) = \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x))\) exists almost everywhere, and if the system is ergodic, \(\hat{f}(x) = \int_X f \, d\mu\) a.e.

import numpy as np

# Circle rotation: T_α(x) = x + α (mod 1)
# Ergodic iff α is irrational

alpha = np.sqrt(2) - 1  # irrational
x0 = 0.1

# Generate orbit
orbit = []
x = x0
for _ in range(10000):
    orbit.append(x)
    x = (x + alpha) % 1

# Check uniform distribution
intervals = np.linspace(0, 1, 11)
counts = np.histogram(orbit, bins=intervals)[0]
frequencies = counts / len(orbit)

print("Uniform distribution check:")
print(f"Expected: 0.1 for each interval")
print(f"Observed: {frequencies}")
print(f"Max deviation: {np.max(np.abs(frequencies - 0.1)):.4f}")

Random Matrix Theory: Universality in the Spectrum

Motivation

Why do the energy levels of heavy nuclei, the zeros of the Riemann zeta function, and the eigenvalues of large random matrices all exhibit the same statistical patterns? Random matrix theory reveals a profound universality.

Theorem (Wigner's Semicircle Law)

Let \(M_n\) be an \(n \times n\) Wigner matrix. Then the empirical spectral distribution converges to the semicircle distribution: \[\mu_{sc}(dx) = \frac{1}{2\pi} \sqrt{4 - x^2} \, \mathbf{1}_{|x| \leq 2} \, dx\]

import numpy as np
import matplotlib.pyplot as plt

def generate_wigner_matrix(n):
    """Generate a random Wigner matrix (GOE)."""
    A = np.random.randn(n, n)
    M = (A + A.T) / np.sqrt(2 * n)
    return M

def semicircle_density(x):
    """Semicircle probability density function."""
    density = np.zeros_like(x)
    mask = np.abs(x) <= 2
    density[mask] = (1 / (2 * np.pi)) * np.sqrt(4 - x[mask]**2)
    return density

# Generate eigenvalues
n = 2000
M = generate_wigner_matrix(n)
eigenvalues = np.linalg.eigvalsh(M)

# Plot histogram vs semicircle
plt.hist(eigenvalues, bins=50, density=True, alpha=0.7, label='Empirical')
x = np.linspace(-2.2, 2.2, 500)
plt.plot(x, semicircle_density(x), 'r-', linewidth=2, label='Semicircle')
plt.xlabel('Eigenvalue')
plt.ylabel('Density')
plt.legend()
plt.title(f'Wigner Semicircle Law (n={n})')
plt.savefig('semicircle.png')
print("Semicircle law verified!")

Epidemiological Models: The SIR Framework

Real-World Motivation

How do infectious diseases spread through populations? The SIR model, developed by Kermack and McKendrick in 1927, provides the foundational framework for understanding disease dynamics.

Definitions

\(S(t)\): fraction susceptible, \(I(t)\): fraction infected, \(R(t)\): fraction recovered. Basic reproduction number: \(R_0 = \beta/\gamma\).

Theorem (Final Size Relation)

\[R_\infty = 1 - e^{-R_0 R_\infty}\] 
import numpy as np
from scipy.integrate import odeint

def sir_model(y, t, beta, gamma):
    S, I, R = y
    dSdt = -beta * S * I
    dIdt = beta * S * I - gamma * I
    dRdt = gamma * I
    return [dSdt, dIdt, dRdt]

# Parameters
beta, gamma = 0.3, 0.1  # R0 = 3
S0, I0, R0 = 0.99, 0.01, 0.0
t = np.linspace(0, 160, 1000)

# Solve
solution = odeint(sir_model, [S0, I0, R0], t, args=(beta, gamma))
S, I, R = solution.T

print(f"Peak infection: {np.max(I):.1%}")
print(f"Final epidemic size: {R[-1]:.1%}")
print(f"Herd immunity threshold: {1 - 1/(beta/gamma):.1%}")

Climate Dynamics: Energy Balance Models

Real-World Motivation

How do we predict Earth's future climate? Simple energy balance models capture essential features of the climate system and predict multiple equilibrium states.

Theorem (Multiple Equilibria)

The nonlinear ice-albedo feedback can create multiple stable climate states for the same solar forcing.

import numpy as np
from scipy.optimize import fsolve

SIGMA = 5.67e-8  # Stefan-Boltzmann constant
S0 = 1361  # Solar constant

def equilibrium_temperature(epsilon=0.6):
    """Find equilibrium temperatures."""
    def net_flux(T, alpha_ice=0.6, alpha_water=0.3, T_c=273):
        alpha = alpha_ice if T < T_c else alpha_water
        incoming = (1 - alpha) * S0 / 4
        outgoing = epsilon * SIGMA * T**4
        return incoming - outgoing
    
    # Find zeros
    T_range = np.linspace(200, 350, 1000)
    equilibria = []
    for T_guess in [230, 280, 310]:
        T_eq = fsolve(net_flux, T_guess)[0]
        if all(abs(T_eq - e) > 5 for e in equilibria):
            equilibria.append(T_eq)
    
    return equilibria

equilibria = equilibrium_temperature()
print("Equilibrium temperatures:")
for T in equilibria:
    state = "ICE-COVERED" if T < 273 else "ICE-FREE"
    print(f"  T = {T:.1f} K ({state})")

Modern Portfolio Theory: Mean-Variance Optimization

Real-World Motivation

How should an investor allocate capital among risky assets? Harry Markowitz's 1952 mean-variance optimization framework revolutionized finance by quantifying the trade-off between expected return and risk.

Theorem (Two-Fund Theorem)

Any portfolio on the efficient frontier can be constructed as a linear combination of any two distinct efficient portfolios.

import numpy as np
from scipy.optimize import minimize

# Asset parameters
assets = ['Stocks', 'Bonds', 'Real Estate', 'Commodities']
mu = np.array([0.10, 0.04, 0.07, 0.05])  # Expected returns
Sigma = np.array([
    [0.04, 0.005, 0.015, 0.02],
    [0.005, 0.01, 0.005, 0.002],
    [0.015, 0.005, 0.0225, 0.01],
    [0.02, 0.002, 0.01, 0.0625]
])

# Minimum variance portfolio
def portfolio_variance(w):
    return w @ Sigma @ w

constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
bounds = [(0, 1)] * 4
result = minimize(portfolio_variance, [0.25]*4, 
                  method='SLSQP', bounds=bounds, constraints=constraints)

w_gmv = result.x
print("Global Minimum Variance Portfolio:")
for asset, w in zip(assets, w_gmv):
    print(f"  {asset}: {w:.2%}")
print(f"Expected return: {w_gmv @ mu:.2%}")
print(f"Volatility: {np.sqrt(w_gmv @ Sigma @ w_gmv):.2%}")

🌟 Special Topics

Knot Theory: The Topology of Embeddings

Historical Context

Knot theory began in the 19th century with Lord Kelvin's vortex atom hypothesis. Peter Guthrie Tait created the first knot tables in the 1870s. Vaughan Jones discovered his polynomial invariant in 1984, connecting knot theory to statistical mechanics.

Theorem (Reidemeister's Theorem)

Two knot diagrams represent equivalent knots if and only if one can be transformed into the other by a finite sequence of Reidemeister moves.

Theorem (Alexander Polynomial)

Every knot has a well-defined Alexander polynomial \(\Delta_K(t)\), a knot invariant computable from any diagram.

Graph Theory: Coloring and Structure

Historical Context

The four color problem launched graph theory as a mathematical discipline in 1852. The four color theorem was finally proved in 1976 by Appel and Haken using computer assistance.

Theorem (Four Color Theorem)

Every planar graph has chromatic number at most 4.

Theorem (Five Color Theorem)

Every planar graph has chromatic number at most 5.

Combinatorics: The Art of Counting

Historical Context

Combinatorics has ancient roots in games of chance. Pascal and Fermat's 1654 correspondence laid foundations for probability theory. Paul Erdős embodied the collaborative spirit of modern combinatorics.

Theorem (Catalan Numbers)

\[C_n = \frac{1}{n+1}\binom{2n}{n}\]

Theorem (Euler's Pentagonal Number Theorem)

\[\prod_{n=1}^{\infty}(1-x^n) = \sum_{k=-\infty}^{\infty}(-1)^k x^{k(3k-1)/2}\]

Hilbert's Tenth Problem: The Undecidability of Diophantine Equations

Historical Context

In 1900, David Hilbert asked for an algorithm to determine whether any given Diophantine equation has integer solutions. In 1970, Yuri Matiyasevich proved that no such algorithm exists.

Theorem (Matiyasevich's Theorem)

There is no algorithm that can determine whether an arbitrary Diophantine equation has integer solutions.

Theorem (MRDP Theorem)

Every recursively enumerable set is Diophantine.

📜 Math History: Évariste Galois (1811–1832)

Évariste Galois was born on October 25, 1811, in Bourg-la-Reine, France. His mathematical genius emerged early, but his life was tragically brief and tumultuous. At age 17, he published his first paper on continued fractions. His magnum opus—the theory connecting field extensions to group theory—was written in a feverish burst of creativity before his fatal duel at age 20.

Galois's story is one of the most romantic in mathematics. He submitted his work to the Paris Academy three times. The first submission was lost by Cauchy. The second was lost by Fourier. The third was rejected by Poisson, who found the arguments insufficiently rigorous. Galois spent the night before his duel, on May 29, 1832, frantically writing down his mathematical ideas, annotating the margins with desperate pleas: "I have no time, I have no time."

The theory that emerged from these notes transformed algebra. Galois established a correspondence between field extensions and groups, allowing questions about solvability of equations to be translated into questions about group structure. The insolvability of the quintic—proven by Abel and Ruffini—became a corollary of the fact that the symmetric group \(S_5\) is not solvable.

Galois's work was not fully appreciated until Liouville published it in 1846, fourteen years after his death. By then, the abstract conception of groups that Galois had pioneered was being developed by Cauchy, Cayley, and others. Today, Galois theory is a cornerstone of modern algebra, essential not just for understanding polynomial equations but for algebraic number theory, algebraic geometry, and beyond.

🎯 Problem Corner

Problem: IMO 2023 Shortlist N5

Find all positive integers \(n\) such that \(n\) divides \(2^n + 1\).

Hint

Consider the smallest prime divisor of \(n\). Use Fermat's Little Theorem and properties of multiplicative order.

Solution

We claim that \(n = 1\) and \(n = 3^k\) for \(k \geq 0\) are the only solutions.

First, verify that \(n = 1\) works: \(1 | 2^1 + 1 = 3\). For \(n = 3^k\), we use LTE (Lifting the Exponent Lemma): \(v_3(2^{3^k} + 1) = v_3(2+1) + v_3(3^k) = 1 + k\), so \(3^k | 2^{3^k} + 1\).

Now suppose \(n > 1\) and \(n | 2^n + 1\). Let \(p\) be the smallest prime divisor of \(n\). Then \(2^n \equiv -1 \pmod{p}\), so \(2^{2n} \equiv 1 \pmod{p}\). Let \(d = \text{ord}_p(2)\). Then \(d | 2n\) but \(d \nmid n\), so \(v_2(d) = v_2(2n) = 1\). By Fermat's Little Theorem, \(d | p-1\). Thus \(p \equiv 1 \pmod{2}\), i.e., \(p\) is odd.

Since \(d | p-1\) and \(v_2(d) = 1\), we have \(d\) is even. Write \(d = 2m\). Then \(2^m \equiv -1 \pmod{p}\). Since \(d | 2n\), we have \(m | n\). If \(m > 1\), let \(q\) be a prime divisor of \(m\). Then \(q | n\) and \(q \leq m < d \leq p-1 < p\), contradicting minimality of \(p\). Thus \(m = 1\) and \(d = 2\), giving \(p | 2^2 - 1 = 3\), so \(p = 3\).

Therefore all prime divisors of \(n\) equal 3, so \(n = 3^k\).

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the function \(f_c(z) = z^2 + c\) does not diverge when iterated from \(z = 0\).

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until divergence."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
plt.show()
print("Mandelbrot set visualization saved!")
