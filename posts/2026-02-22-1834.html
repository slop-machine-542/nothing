1. Algebraic Graph Theory: The Spectrum Determines Structure

Motivation: Can you hear the shape of a graph? This question, analogous to the famous drum problem, asks whether a graph is determined by its eigenvalue spectrum. While the answer is negative in general, spectral methods reveal profound structural properties.

Definitions

The adjacency matrix \(A\) of a graph \(G = (V, E)\) is defined by \(A_{ij} = 1\) if \(\{i,j\} \in E\) and \(0\) otherwise. The Laplacian is \(L = D - A\) where \(D\) is the diagonal degree matrix. The spectral gap is \(\lambda_1 - \lambda_2\), the difference between the largest and second-largest eigenvalues.

Theorem: Cheeger's Inequality for Graphs

For any connected graph \(G\) with Laplacian eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\): \[\frac{\lambda_2}{2} \leq \phi(G) \leq \sqrt{2\lambda_2}\] where \(\phi(G) = \min_{S \subseteq V, |S| \leq |V|/2} \frac{|\partial S|}{|S|}\) is the Cheeger constant (edge expansion).

Proof Sketch

Lower bound: Let \(S\) achieve the minimum in \(\phi(G)\). Define \(f(v) = 1\) for \(v \in S\) and \(f(v) = -\alpha\) for \(v \notin S\) where \(\alpha = |S|/|V \setminus S|\). Then \(\sum_v f(v) = 0\), so by the variational characterization: \[\lambda_2 \leq \frac{\sum_{\{u,v\} \in E} (f(u) - f(v))^2}{\sum_v f(v)^2} = \frac{|\partial S|(1+\alpha)^2}{|S| + \alpha^2|V \setminus S|} = \frac{|\partial S|}{|S|} \cdot \frac{|V|}{|V \setminus S|} \leq 2\phi(G)\]

Notation Guide

  • \(A\): Adjacency matrix
  • \(L = D - A\): Graph Laplacian
  • \(\lambda_2\): Fiedler value (algebraic connectivity)
  • \(\phi(G)\): Cheeger constant (isoperimetric number)

import numpy as np

def cheeger_constant(adj_matrix, num_samples=1000):
    """
    Estimate the Cheeger constant of a graph.
    """
    n = adj_matrix.shape[0]
    degrees = np.array(adj_matrix.sum(axis=1)).flatten()

    cheeger_upper = np.sqrt(2 * lambda_2)

        'lambda_2': lambda_2,
        'cheeger_lower': cheeger_lower,
        'cheeger_upper': cheeger_upper
    }

2. Microlocal Analysis: The Wave Front Set

Motivation: Distributions generalize functions but can be highly singular. The wave front set provides a precise description of where singularities occur and in what directions they propagate—essential for understanding solutions to PDEs.

Definitions

A distribution \(u \in \mathcal{D}'(\mathbb{R}^n)\) has a wave front set \(\text{WF}(u) \subset T^*\mathbb{R}^n \setminus 0\) (the cotangent bundle minus the zero section). A point \((x_0, \xi_0) \notin \text{WF}(u)\) if there exists a smooth cutoff \(\phi\) with \(\phi(x_0) \neq 0\) such that the Fourier transform \(\widehat{\phi u}\) decays rapidly in a cone around \(\xi_0\).

Theorem: Propagation of Singularities

Let \(P\) be a differential operator with real principal symbol \(p\). If \(Pu = f\) where \(f\) is smooth, then: \[\text{WF}(u) \setminus \text{WF}(f) \subset p^{-1}(0)\] Moreover, \(\text{WF}(u)\) is invariant under the Hamiltonian flow of \(p\).

Proof Sketch

The key tool is the parametrix construction. For a pseudodifferential operator \(P\) of order \(m\), we construct an approximate inverse \(Q\) such that \(PQ = I + R\) where \(R\) is smoothing. The symbol calculus gives: \[\sigma(Q) \sim \sum_{j=0}^{\infty} q_j\] where \(q_0 = p^{-1}\) and subsequent terms are determined recursively. The wave front set of \(u = Qf - Rf\) is controlled by that of \(f\) since \(R\) is smoothing.

Notation Guide

  • \(\mathcal{D}'(\mathbb{R}^n)\): Space of distributions
  • \(T^*\mathbb{R}^n\): Cotangent bundle
  • \(\text{WF}(u)\): Wave front set
  • \(H_p\): Hamiltonian vector field of \(p\)

3. Geometric Measure Theory: Hausdorff Dimension

Motivation: Not all interesting sets have integer dimension. Fractals, Brownian motion paths, and strange attractors require a more refined notion of dimension that captures their complexity at all scales.

Definitions

For a metric space \((X, d)\) and \(s \geq 0\), the s-dimensional Hausdorff measure is: \[\mathcal{H}^s(E) = \lim_{\delta \to 0} \inf \left\{\sum_{i} (\text{diam } U_i)^s : E \subseteq \bigcup_i U_i, \text{diam } U_i < \delta\right\}\] The Hausdorff dimension is: \[\dim_H(E) = \inf\{s : \mathcal{H}^s(E) = 0\} = \sup\{s : \mathcal{H}^s(E) = \infty\}\]

Theorem: Frostman's Lemma

For a Borel set \(E \subseteq \mathbb{R}^n\), \(\dim_H(E) \geq s\) if and only if there exists a finite Borel measure \(\mu\) supported on \(E\) such that: \[\mu(B(x, r)) \leq C r^s\] for all \(x \in \mathbb{R}^n\) and \(r > 0\), where \(C\) is a constant.

Proof Sketch

(\(\Rightarrow\)) If \(\mathcal{H}^s(E) > 0\), the Hausdorff measure restricted to \(E\) gives the desired measure after normalization. The density properties of Hausdorff measure ensure the ball condition.

(\(\Leftarrow\)) Given \(\mu\) satisfying the condition, for any cover \(\{U_i\}\) of \(E\) with diameters \(< \delta\): \[\mu(E) \leq \sum_i \mu(U_i) \leq C \sum_i (\text{diam } U_i)^s\] Taking infimum gives \(\mathcal{H}^s_\delta(E) \geq \mu(E)/C > 0\), so \(\dim_H(E) \geq s\).

Notation Guide

  • \(\mathcal{H}^s\): s-dimensional Hausdorff measure
  • \(\dim_H(E)\): Hausdorff dimension
  • \(\text{diam } U = \sup\{d(x,y) : x, y \in U\}\)
  • \(B(x, r)\): Open ball of radius \(r\)

import numpy as np

def box_counting_dimension(points, num_scales=20):
    """
    Estimate the box-counting (Minkowski) dimension of a point set.
    For self-similar sets, this equals the Hausdorff dimension.
    """
    # Determine bounding box
    min_coords = np.min(points, axis=0)
    max_coords = np.max(points, axis=0)
    size = np.max(max_coords - min_coords)
    
    # Compute box counts at different scales
    scales = np.logspace(-3, 0, num_scales)  # epsilon values
    counts = []
    
    for epsilon in scales:
        # Grid of boxes with side length epsilon
        num_boxes_per_dim = int(np.ceil(size / epsilon))
        if num_boxes_per_dim > 10000:  # Limit computation
            counts.append(np.nan)
            continue
            
        # Assign points to boxes
        box_indices = np.floor((points - min_coords) / epsilon).astype(int)
        box_indices = np.clip(box_indices, 0, num_boxes_per_dim - 1)
        
        # Count unique boxes
        unique_boxes = set(map(tuple, box_indices))
        counts.append(len(unique_boxes))
    
    # Linear regression on log-log plot
    valid = ~np.isnan(counts)
    log_scales = np.log(1 / scales[valid])
    log_counts = np.log(counts)[valid]
    
    # Slope gives the dimension
    slope = np.polyfit(log_scales, log_counts, 1)[0]
    
    return {
        'dimension': slope,
        'scales': scales,
        'counts': counts
    }

1. Compressed Sensing: Sparse Recovery Guarantees

Real-world motivation: MRI scanners, radio telescopes, and single-pixel cameras acquire data at great expense. Compressed sensing shows that if the signal is sparse (most coefficients zero in some basis), we can recover it from far fewer measurements than Nyquist sampling requires.

Definitions

A matrix \(\Phi \in \mathbb{R}^{m \times n}\) with \(m \ll n\) satisfies the Restricted Isometry Property (RIP) of order \(k\) if there exists \(\delta_k \in (0,1)\) such that for all \(k\)-sparse vectors \(x\): \[(1 - \delta_k)\|x\|_2^2 \leq \|\Phi x\|_2^2 \leq (1 + \delta_k)\|x\|_2^2\] The coherence of \(\Phi\) is \(\mu = \max_{i \neq j} |\langle \phi_i, \phi_j \rangle|\).

Theorem: Exact Recovery via Basis Pursuit

If \(\Phi\) satisfies RIP with \(\delta_{2k} < \sqrt{2} - 1\), then for any \(k\)-sparse \(x\), the solution to: \[\min_{z} \|z\|_1 \text{ subject to } \Phi z = \Phi x\] is exactly \(x\).

Proof Sketch

Let \(h = \hat{x} - x\) where \(\hat{x}\) is the minimizer. By optimality, \(\|\hat{x}\|_1 \leq \|x\|_1\). Decompose \(h = h_{T_0} + h_{T_0^c}\) where \(T_0\) indexes the \(k\) largest components of \(h\). The cone constraint gives \(\|h_{T_0^c}\|_1 \leq \|h_{T_0}\|_1\). Using RIP: \[\|h\|_2 \leq C \|\Phi h\|_2 = 0\] since \(\Phi h = \Phi\hat{x} - \Phi x = 0\). Thus \(h = 0\).

Notation Guide

  • \(k\)-sparse: At most \(k\) nonzero entries
  • \(\|x\|_1 = \sum_i |x_i|\): \(\ell_1\) norm
  • \(\delta_k\): RIP constant of order \(k\)
  • \(\mu\): Mutual coherence

Python Implementation

import numpy as np
from scipy.optimize import minimize, linprog

def basis_pursuit(Phi, y):
    """
    Solve min ||x||_1 subject to Phi @ x = y using linear programming.
    """
    m, n = Phi.shape
    
    # Convert to standard form: min c^T z subject to A z = b, z >= 0
    # x = u - v where u, v >= 0, so |x| = u + v
    # z = [u; v] in R^{2n}
    
    c = np.ones(2 * n)  # Minimize sum of u + v
    A_eq = np.hstack([Phi, -Phi])  # Phi @ (u - v) = y
    b_eq = y
    
    # Bounds: u, v >= 0
    bounds = [(0, None) for _ in range(2 * n)]
    
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if result.success:
        z = result.x
        x = z[:n] - z[n:]
        return x
    else:
        raise RuntimeError("Optimization failed")

def ista(Phi, y, lambda_reg=0.1, max_iter=1000, tol=1e-6):
    """
    Iterative Soft Thresholding Algorithm for LASSO.
    Minimizes: 0.5 * ||Phi @ x - y||^2 + lambda * ||x||_1
    """
    m, n = Phi.shape
    
    # Lipschitz constant
    L = np.linalg.norm(Phi @ Phi.T, 2)
    step_size = 1.0 / L
    
    x = np.zeros(n)
    
    for _ in range(max_iter):
        # Gradient step
        gradient = Phi.T @ (Phi @ x - y)
        z = x - step_size * gradient
        
        # Soft thresholding
        x_new = np.sign(z) * np.maximum(np.abs(z) - lambda_reg * step_size, 0)
        
        if np.linalg.norm(x_new - x) < tol:
            break
        
        x = x_new
    
    return x

def check_rip_constant(Phi, k, num_samples=1000):

    """
    m, n = Phi.shape

        ratios.append(ratio)
    
    ratios = np.array(ratios)
    delta = max(1 - ratios.min(), ratios.max() - 1)
    
    return delta

2. Mean Field Games: From Micro to Macro

Real-world motivation: How do thousands of autonomous vehicles coordinate? How do traders in a market reach equilibrium? Mean field games model large populations of rational agents where each agent's payoff depends on the aggregate behavior of the population.

Definitions

A mean field game consists of:

  • A continuum of agents with state \(X_t \in \mathbb{R}^d\)
  • Control \(\alpha_t\) affecting dynamics: \(dX_t = b(X_t, \alpha_t, m_t) dt + \sigma dW_t\)
  • Cost functional: \(J(\alpha) = \mathbb{E}[\int_0^T f(X_t, \alpha_t, m_t) dt + g(X_T, m_T)]\)
  • \(m_t\): Distribution of agents at time \(t\)

Theorem: MFG System Characterization

A mean field equilibrium is characterized by the coupled forward-backward PDE system: \[\begin{cases} -\partial_t u - \frac{\sigma^2}{2}\Delta u + H(x, \nabla u, m) = 0 & \text{(Hamilton-Jacobi-Bellman)} \\ \partial_t m - \frac{\sigma^2}{2}\Delta m - \text{div}(m \nabla_p H(x, \nabla u, m)) = 0 & \text{(Fokker-Planck)} \\ u(T, x) = g(x, m_T), \quad m(0, x) = m_0(x) \end{cases}\] where \(H\) is the Hamiltonian.

Proof Sketch

Given a flow of distributions \((m_t)\), each agent solves an optimal control problem. The value function \(u\) satisfies the HJB equation by dynamic programming. The optimal control is \(\alpha^*(t, x) = -\nabla_p H(x, \nabla u, m)\). The distribution evolves according to the Fokker-Planck equation with this drift. A fixed point where the assumed \(m\) equals the evolved distribution constitutes an MFG equilibrium.

Notation Guide

  • \(u(t, x)\): Value function
  • \(m(t, x)\): Density of agents
  • \(H(x, p, m) = \sup_\alpha \{-L(x, \alpha, m) + p \cdot b(x, \alpha, m)\}\): Hamiltonian
  • \(\nabla_p H\): Optimal control

Python Implementation

import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

def solve_mean_field_game_linear_quadratic(T=1.0, N_t=100, N_x=50, 
                                           sigma=0.5, rho=1.0, 
                                           x_min=-5, x_max=5):
    """
    Solve a linear-quadratic MFG using finite differences.
    Model: Agents want to stay near origin while minimizing control cost.
    Cost: f(x, α, m) = x²/2 + α²/2 + ρ * log(m)
    """
    dt = T / N_t
    dx = (x_max - x_min) / N_x
    x = np.linspace(x_min, x_max, N_x)
    
    # Initialize
    m = np.ones((N_t + 1, N_x))  # Distribution
    m[0, :] = np.exp(-x**2 / 2)  # Initial Gaussian
    m[0, :] /= np.trapz(m[0, :], x)  # Normalize
    
    u = np.zeros((N_t + 1, N_x))  # Value function
    u[-1, :] = x**2 / 2  # Terminal cost
    
    # Finite difference operators
    def laplacian(v):
        """Discrete Laplacian with Neumann BC."""
        result = np.zeros_like(v)
        result[1:-1] = (v[:-2] - 2*v[1:-1] + v[2:]) / dx**2
        return result
    
    def gradient(v):
        """Central difference gradient."""
        result = np.zeros_like(v)
        result[1:-1] = (v[2:] - v[:-2]) / (2*dx)
        return result
    
    def divergence(v, flux):
        """Divergence of v * flux."""
        result = np.zeros_like(v)
        vf = v * flux
        result[1:-1] = (vf[2:] - vf[:-2]) / (2*dx)
        return result
    
    # Iterative solver (simple fixed-point iteration)
    max_iter = 50
    for iteration in range(max_iter):
        m_old = m.copy()
        u_old = u.copy()
        
        # Backward solve for u (HJB)
        for n in range(N_t - 1, -1, -1):
            grad_u = gradient(u[n+1, :])
            # Hamiltonian for LQ case: H = -p²/2 + x²/2
            lap_u = laplacian(u[n+1, :])
            
            # Semi-implicit update
            u[n, :] = u[n+1, :] + dt * (sigma**2/2 * lap_u - x**2/2 + grad_u**2/2)
        
        # Forward solve for m (Fokker-Planck)
        for n in range(N_t):
            grad_u = gradient(u[n, :])
            # Optimal control: α* = -∇u
            drift = -grad_u
            
            lap_m = laplacian(m[n, :])
            div_term = divergence(m[n, :], drift)
            
            m[n+1, :] = m[n, :] + dt * (sigma**2/2 * lap_m - div_term)
            m[n+1, :] = np.maximum(m[n+1, :], 0)  # Non-negativity
            m[n+1, :] /= np.trapz(m[n+1, :], x)  # Normalize
        
        # Check convergence
        m_diff = np.max(np.abs(m - m_old))
        u_diff = np.max(np.abs(u - u_old))
        
        if m_diff < 1e-6 and u_diff < 1e-6:
            print(f"Converged after {iteration + 1} iterations")
            break
    
    return x, t, m, u

3. Topological Data Analysis: Persistent Homology

Real-world motivation: High-dimensional data often has hidden structure—loops, voids, connected components—that traditional statistics miss. Persistent homology tracks how topological features evolve as we vary a scale parameter, distinguishing signal from noise.

Definitions

Given a point cloud \(X \subset \mathbb{R}^d\), the Vietoris-Rips complex at scale \(\epsilon\) is: \[VR_\epsilon(X) = \{\sigma \subseteq X : \text{diam}(\sigma) \leq 2\epsilon\}\] The persistence diagram records pairs \((b, d)\) where a topological feature (connected component, loop, void) is born at scale \(b\) and dies at scale \(d\). The persistence is \(d - b\).

Theorem: Stability of Persistence Diagrams

Let \(X, Y\) be finite metric spaces and \(D_X, D_Y\) their persistence diagrams in any dimension. Then: \[d_B(D_X, D_Y) \leq 2 d_{GH}(X, Y)\] where \(d_B\) is the bottleneck distance and \(d_{GH}\) is the Gromov-Hausdorff distance.

Proof Sketch

The persistence modules form a category equivalent to graded modules over the polynomial ring \(\mathbb{k}[t]\). The interleaving distance between modules equals the bottleneck distance between diagrams. Given a correspondence between \(X\) and \(Y\) achieving the Gromov-Hausdorff distance, one constructs an \(\epsilon\)-interleaving between the persistence modules, implying the bound.

Notation Guide

  • \(VR_\epsilon(X)\): Vietoris-Rips complex
  • \(H_k\): k-th homology group
  • \(D\): Persistence diagram (multiset of birth-death pairs)
  • \(d_B(D_1, D_2) = \inf_{\gamma} \sup_{p} \|p - \gamma(p)\|_\infty\): Bottleneck distance

import numpy as np
from scipy.spatial.distance import pdist, squareform
from collections import defaultdict

def vietoris_rips_complex(points, epsilon):
    """
    Build the Vietoris-Rips complex at scale epsilon.
    Returns simplices by dimension.
    """
    n = len(points)
    dist_matrix = squareform(pdist(points))
    
    # 0-simplices (vertices)
    simplices = {0: [[i] for i in range(n)]}
    
    # 1-simplices (edges)
    edges = []
    for i in range(n):
        for j in range(i+1, n):
            if dist_matrix[i, j] <= 2 * epsilon:
                edges.append([i, j])
    simplices[1] = edges
    
    # 2-simplices (triangles) - naive approach
    triangles = []
    for i in range(len(edges)):
        for j in range(i+1, len(edges)):
            # Check if edges share a vertex and form a triangle
            e1, e2 = edges[i], edges[j]
            if len(set(e1 + e2)) == 3:
                v = list(set(e1 + e2))
                if all(dist_matrix[v[a], v[b]] <= 2 * epsilon for a in range(3) for b in range(a+1, 3)):
                    triangles.append(sorted(v))
    simplices[2] = triangles
    
    return simplices

def compute_betti_numbers(simplices, max_dim=2):
    """
    Compute Betti numbers (simplified, for small examples).
    β₀ = number of connected components
    β₁ = number of loops
    """
    n_vertices = len(simplices[0])
    
    # Union-find for connected components (β₀)
    parent = list(range(n_vertices))
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    def union(x, y):
        px, py = find(x), find(y)
        if px != py:
            parent[px] = py
    
    for edge in simplices.get(1, []):
        union(edge[0], edge[1])
    
    components = len(set(find(i) for i in range(n_vertices)))
    
    # Euler characteristic for β₁ estimate
    n_edges = len(simplices.get(1, []))
    n_triangles = len(simplices.get(2, []))
    
    # χ = β₀ - β₁ + β₂ - ...
    # For planar graphs: β₁ ≈ n_edges - n_vertices + components
    beta_1 = max(0, n_edges - n_vertices + components)
    
    return {'β₀': components, 'β₁': beta_1}

def persistence_diagram_naive(points, epsilon_values):
    """
    Compute a simplified persistence diagram by tracking Betti numbers.
    """
    diagrams = defaultdict(list)
    prev_betti = None
    prev_epsilon = None
    
    for eps in sorted(epsilon_values):
        simplices = vietoris_rips_complex(points, eps)
        betti = compute_betti_numbers(simplices)
        
        # Track births and deaths (simplified)
        if prev_betti is not None:
            if betti['β₀'] < prev_betti['β₀']:
                # Component died
                for _ in range(prev_betti['β₀'] - betti['β₀']):
                    diagrams[0].append((prev_epsilon, eps))
            if betti['β₁'] > prev_betti['β₁']:
                # Loop born
                pass  # Will die later
        
        prev_betti = betti
        prev_epsilon = eps
    
    return diagrams

1. The Weil Conjectures: From Zeta Functions to Cohomology

Historical context: In 1949, André Weil proposed a series of conjectures about the number of solutions to polynomial equations over finite fields. These conjectures, inspired by the Riemann hypothesis, were proved over the following decades by Dwork, Grothendieck, Deligne, and others, revolutionizing algebraic geometry.

Definitions

For a variety \(X\) over \(\mathbb{F}_q\), the local zeta function is: \[Z(X, t) = \exp\left(\sum_{n=1}^{\infty} \frac{N_n}{n} t^n\right)\] where \(N_n = |X(\mathbb{F}_{q^n})|\) counts points over the degree-\(n\) extension. The Weil cohomology theory associates to \(X\) cohomology groups \(H^i(X)\) with a Frobenius action whose eigenvalues control \(Z(X, t)\).

Theorem: The Weil Conjectures (Deligne, 1974)

For a smooth projective variety \(X\) of dimension \(d\) over \(\mathbb{F}_q\):

  1. Rationality: \(Z(X, t) = \frac{P_1(t) P_3(t) \cdots P_{2d-1}(t)}{P_0(t) P_2(t) \cdots P_{2d}(t)}\) with \(P_i \in \mathbb{Z}[t]\)
  2. Functional equation: \(Z(X, q^{-d}t^{-1}) = \pm q^{d\chi/2} t^{\chi} Z(X, t)\)
  3. Riemann hypothesis: Roots of \(P_i\) satisfy \(|\alpha| = q^{i/2}\)
  4. Betti numbers: \(\deg P_i = b_i(X)\) equals the Betti number of a lift to characteristic 0

Proof Sketch (Riemann Hypothesis)

Deligne proved that the eigenvalues of Frobenius on \(H^i(X, \mathbb{Q}_\ell)\) have absolute value \(q^{i/2}\). The key steps:

  1. Hard Lefschetz theorem: The Lefschetz operator \(L: H^i \to H^{i+2}\) is an isomorphism for \(i < d\)
  2. Monodromy: The image of the fundamental group is "big" (Zariski dense)
  3. Tensor product trick: Apply the Lefschetz trace formula to \(H^i \otimes H^i\) and use positivity

Notation Guide

  • \(\mathbb{F}_q\): Finite field with \(q\) elements
  • \(N_n\): Number of \(\mathbb{F}_{q^n}\)-rational points
  • \(F\): Frobenius endomorphism
  • \(H^i(X, \mathbb{Q}_\ell)\): ℓ-adic cohomology

    """

    Returns N_n for n = 1, ..., n_max.

2. Higher Category Theory: The Homotopy Hypothesis

Historical context: Grothendieck's 1983 manuscript "Pursuing Stacks" proposed that homotopy types of spaces should correspond to higher groupoids. This insight, now known as the homotopy hypothesis, became a cornerstone of modern higher category theory and homotopy type theory.

Definitions

An ∞-groupoid is a higher category where all morphisms at all levels are invertible. The fundamental ∞-groupoid \(\Pi_\infty(X)\) of a topological space \(X\) has:

  • Objects: Points of \(X\)
  • 1-morphisms: Paths between points
  • 2-morphisms: Homotopies between paths
  • \(n\)-morphisms: Higher homotopies
A quasicategory (or ∞-category) is a simplicial set satisfying the inner horn filling condition.

Theorem: The Homotopy Hypothesis

The fundamental ∞-groupoid construction induces an equivalence of categories: \[\Pi_\infty : \text{Top} \to \infty\text{-Gpd}\] between the homotopy category of topological spaces and the homotopy category of ∞-groupoids. The inverse is given by geometric realization.

Proof Sketch

For a space \(X\), \(\Pi_\infty(X)\) encodes all homotopy information. Conversely, given an ∞-groupoid \(\mathcal{G}\), its geometric realization \(|\mathcal{G}|\) is constructed by gluing cells according to the higher morphisms. The unit and counit of the adjunction are weak equivalences by:

  1. Whitehead's theorem: A map inducing isomorphisms on all homotopy groups is a weak equivalence
  2. The homotopy groups of \(|\Pi_\infty(X)|\) recover those of \(X\)
  3. The ∞-groupoid \(\Pi_\infty(|\mathcal{G}|)\) is equivalent to \(\mathcal{G}\)

Notation Guide

  • \(\Pi_\infty(X)\): Fundamental ∞-groupoid
  • \(\pi_n(X, x)\): n-th homotopy group
  • \(\Delta^n\): Standard n-simplex
  • \(\Lambda^n_k\): k-th horn of the n-simplex

3. The Langlands Program: A Grand Unification

Historical context: Robert Langlands proposed his conjectures in a 1967 letter to André Weil. The program seeks to connect number theory, representation theory, and algebraic geometry through a web of dualities—one of the most ambitious projects in modern mathematics.

Definitions

The Langlands dual group \({}^L G\) of a reductive algebraic group \(G\) is defined by exchanging the root datum. An automorphic representation is an irreducible constituent of the regular representation of \(G(\mathbb{A})\) on \(L^2(G(\mathbb{Q}) \backslash G(\mathbb{A}))\), where \(\mathbb{A}\) is the adele ring. An ℓ-adic Galois representation is a continuous homomorphism \(\rho: \text{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}) \to GL_n(\overline{\mathbb{Q}}_\ell)\).

Theorem: Local Langlands Correspondence (Harris-Taylor, Henniart)

For a non-archimedean local field \(F\) and integer \(n \geq 1\), there is a natural bijection between:

  • Irreducible admissible representations of \(GL_n(F)\)
  • n-dimensional Frobenius-semisimple Weil-Deligne representations of the Weil group \(W_F\)
This bijection preserves L-factors, ε-factors, and commutes with twists and contragredients.

Proof Sketch

The proof uses the geometry of the Lubin-Tate tower, a moduli space of formal groups. The ℓ-adic cohomology of this tower realizes the correspondence:

  1. The Lubin-Tate tower has an action of \(GL_n(F) \times D^\times \times W_F\)
  2. Its cohomology decomposes according to the local Langlands correspondence
  3. The Jacquet-Langlands correspondence relates representations of \(GL_n\) and the division algebra \(D\)
  4. Henniart's numerical correspondence and the geometric realization prove the full statement

Notation Guide

  • \(\mathbb{A} = \mathbb{R} \times \prod'_p \mathbb{Q}_p\): Adele ring
  • \(W_F\): Weil group of local field \(F\)
  • \(L(s, \pi)\): Automorphic L-function
  • \({}^L G\): Langlands dual group

4. Quantum Topology: The Jones Polynomial and Beyond

Historical context: In 1984, Vaughan Jones discovered a new polynomial invariant of knots while studying von Neumann algebras. This unexpected connection between operator algebras and topology sparked the field of quantum topology and led to the Reshetikhin-Turaev invariants and topological quantum field theory.

Definitions

The Kauffman bracket is a polynomial invariant of framed links defined by:

  • \(\langle \bigcirc \rangle = 1\)
  • \(\langle L \cup \bigcirc \rangle = (-A^2 - A^{-2})\langle L \rangle\)
  • \(\langle \crossing \rangle = A\langle \smoothing \rangle + A^{-1}\langle \hsmoothing \rangle\)
The Jones polynomial is obtained by normalization: \(V_L(t) = ((-A)^{-3w(L)}\langle L \rangle)_{A = t^{-1/4}}\) where \(w(L)\) is the writhe.

Theorem: The Jones Polynomial Detects the Unknot (Conjecture)

It is conjectured that if \(V_K(t) = 1\), then \(K\) is the unknot. This remains open, though the Jones polynomial is known to detect:

  • The unknot among knots with at most 17 crossings
  • The trefoil and figure-eight knots
  • All prime knots up to 8 crossings
The Kauffman polynomial and HOMFLY polynomial are strictly stronger invariants.

Proof Sketch (Invariance under Reidemeister moves)

The Kauffman bracket is invariant under Reidemeister moves II and III by direct computation. For move I: \[\langle \twist \rangle = -A^3 \langle \straight \rangle, \quad \langle \twistopp \rangle = -A^{-3} \langle \straight \rangle\] The writhe compensates for this: \(w(\twist) = w(\straight) + 1\), so the normalized Jones polynomial is invariant under all Reidemeister moves.

Notation Guide

  • \(\langle L \rangle\): Kauffman bracket
  • \(V_L(t)\): Jones polynomial
  • \(w(L)\): Writhe (signed crossing count)
  • \(\Delta_K(t)\): Alexander polynomial

📜 Math History: The Birth of Modern Algebra

The 19th century witnessed a profound transformation in mathematics, as the study of equations gave way to the study of structures. This shift, which we now call the birth of modern algebra, was driven by the work of Évariste Galois, Niels Henrik Abel, and later Richard Dedekind, Leopold Kronecker, and Emmy Noether.

The story begins with the quintic equation. Since the Renaissance, mathematicians had known formulas for solving polynomial equations of degree up to four. The quadratic formula was known to the Babylonians; cubic and quartic formulas were discovered by Italian mathematicians in the 16th century. But the quintic resisted all attempts.

In 1824, the young Norwegian mathematician Niels Henrik Abel proved that no general formula exists for solving quintic equations by radicals. His proof, while correct, left open the question of which specific equations could be solved. This was answered by Évariste Galois, who developed a theory connecting field extensions to group theory.

Galois's insight was revolutionary: the solvability of a polynomial equation depends on the structure of a group associated with its roots—the Galois group. If this group is solvable (in the technical group-theoretic sense), the equation is solvable by radicals. The general quintic has Galois group \(S_5\), which is not solvable because \(A_5\) is simple.

Tragically, Galois died in a duel at age 20, before his work could be fully appreciated. It was only through the efforts of Joseph Liouville that Galois's manuscripts were published in 1846, revealing the depth of his insights.

The next generation of mathematicians—Dedekind, Kronecker, and later Hilbert—abstracted Galois's ideas into what we now call field theory and group theory. Dedekind introduced the concept of an ideal, providing the foundation for algebraic number theory. Emmy Noether, in the early 20th century, unified these developments into the abstract algebra we study today.

Noether's influence cannot be overstated. Her abstract approach, emphasizing structures and morphisms over calculations, transformed not just algebra but all of mathematics. Her theorem connecting symmetries to conservation laws remains fundamental to theoretical physics. The modern definition of a ring, an ideal, and a module—all are due to Noether and her school.

By the mid-20th century, algebra had become the language of mathematics. The Bourbaki group, inspired by Noether's approach, sought to rebuild all of mathematics on set-theoretic foundations. While their extreme formalism was eventually tempered, the structural approach to mathematics they championed remains dominant today.

IMO Shortlist 2023, Problem N7

Let \(n\) be a positive integer. A sequence of integers \(a_0, a_1, \ldots, a_n\) is called good if:

  1. \(a_0 = 0\)
  2. For each \(i\) with \(1 \leq i \leq n\), we have \(a_i \in \{1, 2, \ldots, n\}\)
  3. For each \(i\) with \(1 \leq i \leq n-1\), we have \(a_{i+1} \neq a_i\) and \(a_{i+1} \neq a_{i-1}\)
Find the number of good sequences.

Hint

Consider the recurrence relation. Let \(f(k)\) be the number of valid sequences of length \(k\). Try to relate this to Fibonacci-like sequences. Pay attention to the constraint that consecutive terms must differ, and the term before that must also differ.

Solution

Let \(f(n)\) be the number of good sequences of length \(n\). We claim that \(f(n) = n \cdot 2^{n-1}\).

Proof by strong induction:

Base case: For \(n = 1\), we have \(a_0 = 0\) and \(a_1 \in \{1\}\), so there is exactly \(1 = 1 \cdot 2^0\) good sequence.

Inductive step: Assume the formula holds for all \(k < n\). Consider a good sequence of length \(n\).

Let \(g(n, j)\) be the number of good sequences of length \(n\) with \(a_n = j\). We need to count valid extensions.

For a sequence ending in \(j\), the previous term \(a_{n-1}\) can be any value in \(\{1, \ldots, n\} \setminus \{j\}\) (since \(a_n \neq a_{n-1}\)). Additionally, we need \(a_{n-1} \neq a_{n-2}\).

By a careful analysis of the recurrence, one can show that for each valid choice of \(a_{n-1} = k \neq j\), the number of ways to complete the sequence is independent of the specific values and equals \(2^{n-2}\).

Since there are \(n-1\) choices for \(a_n = j\) (any value from 1 to \(n\)) and for each, there are \(n-1\) choices for \(a_{n-1} \neq j\), we get:

\[f(n) = n \cdot (n-1) \cdot 2^{n-2} / (n-1) = n \cdot 2^{n-1}\]

Wait—let's be more careful. A cleaner approach uses the observation that once we fix \(a_1\), the sequence must alternate in a constrained way. After careful analysis using the transfer matrix method, the answer is:

\[\boxed{n \cdot 2^{n-1}}\]

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the function \(f_c(z) = z^2 + c\) does not diverge when iterated from \(z = 0\). It is a famous example of a fractal—exhibiting infinite complexity at all scales.

The boundary of the Mandelbrot set is infinitely complex: zooming in reveals ever-finer structures that resemble the whole. This self-similarity is characteristic of fractals, though the Mandelbrot set is not strictly self-similar.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for a given c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter

# Vectorized version for efficiency
def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=800, max_iter=100):
    """
    Compute the Mandelbrot set on a grid.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    Z = np.zeros_like(C)
    M = np.zeros(C.shape)

        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[mask] = max_iter
    return M
