Cohomology Operations and the Steenrod Algebra

algebraic-topology

Motivation

Cohomology operations provide additional structure on cohomology groups that can distinguish spaces with identical cohomology rings. The Steenrod operations, discovered by Norman Steenrod in the 1940s, are the most important stable cohomology operations.

Definitions

  • Cohomology Operation: A natural transformation \\(H^n(-; G) \\to H^m(-; H)\\) between cohomology functors.
  • Steenrod Square: Operations \\(\\text{Sq}^i: H^n(X; \\mathbb{Z}_2) \\to H^{n+i}(X; \\mathbb{Z}_2)\\) satisfying specific axioms.
  • Steenrod Algebra \\(\\mathcal{A}_2\\): The graded algebra generated by Steenrod squares modulo the Adem relations.

Theorem: The Adem Relations

Theorem (Adem): For \\(a < 2b\\), the Steenrod squares satisfy: \\[\\text{Sq}^a \\text{Sq}^b = \\sum_{j=0}^{\\lfloor a/2 \\rfloor} \\binom{b-j-1}{a-2j} \\text{Sq}^{a+b-j} \\text{Sq}^j\\]

Notation Guide

  • \\(\\text{Sq}^i\\): Steenrod square of degree \\(i\\)
  • \\(\\mathcal{A}_2\\): Mod-2 Steenrod algebra
  • \\(\\binom{n}{k}\\): Binomial coefficient mod 2

Martingales and the Optional Stopping Theorem

stochastic-processes

Motivation

Martingales model fair games and appear throughout probability theory. The optional stopping theorem tells us when we can stop a martingale and still preserve its expected value — crucial for gambling strategies and financial mathematics.

Definitions

  • Filtration: An increasing sequence \\(\\{\\mathcal{F}_n\\}\\) of \\(\\sigma\\)-algebras.
  • Martingale: A stochastic process \\(M_n\\) where \\(\\mathbb{E}[M_{n+1} | \\mathcal{F}_n] = M_n\\).
  • Stopping Time: A random variable \\(\\tau\\) such that \\(\\{\\tau \\leq n\\} \\in \\mathcal{F}_n\\) for all \\(n\\).

Theorem: Optional Stopping Theorem

Theorem: Let \\(M_n\\) be a martingale and \\(\\tau\\) a bounded stopping time. Then: \\[\\mathbb{E}[M_\\tau] = \\mathbb{E}[M_0]\\]

Notation Guide

  • \\(\\mathbb{E}[X | \\mathcal{F}]\\): Conditional expectation
  • \\(\\mathcal{F}_n\\): Information available at time \\(n\\)
  • \\(M_\\tau\\): Process stopped at time \\(\\tau\\)

Python Code

import numpy as np

def simulate_martingale(num_paths=10000, num_steps=100):
    """
    Simulate simple symmetric random walk (a martingale)
    and test optional stopping theorem
    """
    # Simple random walk: M_n = sum of +/- 1
    steps = 2 * np.random.binomial(1, 0.5, (num_paths, num_steps)) - 1
    paths = np.cumsum(steps, axis=1)
    paths = np.column_stack([np.zeros(num_paths), paths])  # M_0 = 0
    
    return paths

def stopping_time_hit_boundary(paths, boundary):
    """First time |M_n| hits boundary"""
    num_paths = paths.shape[0]
    stopping_times = np.full(num_paths, paths.shape[1] - 1)
    
    for i in range(num_paths):
        hit = np.where(np.abs(paths[i, :]) >= boundary)[0]
        if len(hit) > 0:
            stopping_times[i] = hit[0]
    
    return stopping_times

# Test optional stopping theorem
np.random.seed(42)
paths = simulate_martingale(num_paths=50000, num_steps=200)
stopping_times = stopping_time_hit_boundary(paths, boundary=5)

# Values at stopping time
stopped_values = np.array([paths[i, int(stopping_times[i])] 
                          for i in range(len(paths))])

print(f"E[M_tau] ≈ {np.mean(stopped_values):.4f}")  # Should be close to 0
print(f"E[M_0] = 0")
print(f"Mean stopping time: {np.mean(stopping_times):.2f}")

# Gambler's ruin: probability of hitting +a before -b
def gamblers_ruin_probability(a, b):
    """Probability of hitting +a before -b for simple random walk"""
    return b / (a + b)

print(f"\\nGambler's ruin: P(hit +10 before -5) = {gamblers_ruin_probability(10, 5):.4f}")

Discrete Geometry: The Sylvester-Gallai Theorem

discrete-geometry

Motivation

The Sylvester-Gallai theorem answers a seemingly simple question: given a finite set of points in the plane, not all collinear, must there exist a line passing through exactly two of them? This innocent-sounding result has deep connections to combinatorial geometry and algebraic complexity.

Definitions

  • Ordinary Line: A line containing exactly two points from a given set.
  • Configuration: A finite set of points in \\(\\mathbb{R}^2\\).
  • Non-collinear: Not all points lie on a single line.

Theorem: Sylvester-Gallai

Theorem: Let \\(S\\) be a finite set of points in \\(\\mathbb{R}^2\\), not all collinear. Then there exists at least one ordinary line — a line containing exactly two points of \\(S\\).

Notation Guide

  • \\(\\binom{n}{2}\\): Number of point pairs
  • \\(t_k\\): Number of lines containing exactly \\(k\\) points
  • \\(\\text{ord}(S)\\): Number of ordinary lines in configuration \\(S\\)

Python Code

import numpy as np
from collections import defaultdict
from fractions import Fraction

def count_collinear_triples(points):
    """Count triples of collinear points"""
    n = len(points)
    count = 0
    lines = defaultdict(set)
    
    for i in range(n):
        for j in range(i+1, n):
            # Line through points[i] and points[j]
            x1, y1 = points[i]
            x2, y2 = points[j]
            
            # Represent line as ax + by = c with integer coefficients
            a = y2 - y1
            b = x1 - x2
            c = x1*y2 - x2*y1
            
            # Normalize
            if a < 0 or (a == 0 and b < 0):
                a, b, c = -a, -b, -c
            
            g = np.gcd(np.gcd(abs(a), abs(b)), abs(c))
            if g > 0:
                a, b, c = a//g, b//g, c//g
            
            lines[(a, b, c)].add(i)
            lines[(a, b, c)].add(j)
    
    # Count ordinary lines
    ordinary = 0
    for line, pts in lines.items():
        if len(pts) == 2:
            ordinary += 1
    
    return ordinary, len(lines)

Portfolio Optimization and the Efficient Frontier

mathematical-finance

Real-World Motivation

Harry Markowitz's modern portfolio theory (1952) revolutionized investment management by quantifying the trade-off between risk and return. The efficient frontier represents optimal portfolios that maximize expected return for a given level of risk.

Definitions

  • Portfolio Return: \\(R_p = \\sum_i w_i R_i\\) where \\(w_i\\) are weights summing to 1.
  • Portfolio Variance: \\(\\sigma_p^2 = \\mathbf{w}^T \\Sigma \\mathbf{w}\\) where \\(\\Sigma\\) is the covariance matrix.
  • Sharpe Ratio: \\(S = \\frac{\\mathbb{E}[R_p] - R_f}{\\sigma_p}\\) measuring risk-adjusted return.

Theorem: Two-Fund Separation

Theorem: Any portfolio on the efficient frontier can be constructed as a linear combination of two distinct efficient portfolios (the "two-fund theorem").

Notation Guide

  • \\(\\mu\\): Vector of expected returns
  • \\(\\Sigma\\): Covariance matrix
  • \\(\\mathbf{1}\\): Vector of ones
  • \\(\\gamma\\): Risk aversion parameter

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

def portfolio_optimization(returns, cov_matrix, risk_free_rate=0.02):
    """
    Compute efficient frontier using Markowitz optimization
    """
    n_assets = len(returns)
    
    def portfolio_return(weights):
        return np.dot(weights, returns)
    
    def portfolio_volatility(weights):
        return np.sqrt(np.dot(weights.T, np.dot(cov_matrix, weights)))
    
    def negative_sharpe(weights):
        p_return = portfolio_return(weights)
        p_vol = portfolio_volatility(weights)
        return -(p_return - risk_free_rate) / p_vol
    
    # Constraints: weights sum to 1
    constraints = {'type': 'eq', 'fun': lambda x: np.sum(x) - 1}
    bounds = tuple((0, 1) for _ in range(n_assets))
    
    # Maximize Sharpe ratio
    initial_guess = np.array([1/n_assets] * n_assets)
    result = minimize(negative_sharpe, initial_guess, 
                     method='SLSQP', bounds=bounds, constraints=constraints)
    
    optimal_weights = result.x
    optimal_return = portfolio_return(optimal_weights)
    optimal_vol = portfolio_volatility(optimal_weights)
    
    return optimal_weights, optimal_return, optimal_vol

# Example with 3 assets
np.random.seed(42)
returns = np.array([0.10, 0.12, 0.08])  # Expected returns
cov_matrix = np.array([
    [0.04, 0.02, 0.01],
    [0.02, 0.05, 0.015],
    [0.01, 0.015, 0.03]
])

weights, exp_return, volatility = portfolio_optimization(returns, cov_matrix)
print("Optimal Portfolio (Max Sharpe):")
print(f"Weights: {weights}")
print(f"Expected Return: {exp_return:.4f} ({exp_return*100:.2f}%)")
print(f"Volatility: {volatility:.4f} ({volatility*100:.2f}%)")
print(f"Sharpe Ratio: {(exp_return - 0.02)/volatility:.4f}")

# Generate efficient frontier
def efficient_frontier(returns, cov_matrix, n_points=100):
    n_assets = len(returns)
    target_returns = np.linspace(returns.min(), returns.max(), n_points)
    
    efficient_portfolios = []
    for target in target_returns:
        # Minimize variance subject to target return
        def portfolio_var(weights):
            return np.dot(weights.T, np.dot(cov_matrix, weights))
        
        constraints = [
            {'type': 'eq', 'fun': lambda x: np.sum(x) - 1},
            {'type': 'eq', 'fun': lambda x: np.dot(x, returns) - target}
        ]
        bounds = tuple((0, 1) for _ in range(n_assets))
        
        result = minimize(portfolio_var, np.array([1/n_assets]*n_assets),
                         method='SLSQP', bounds=bounds, constraints=constraints)
        
        if result.success:
            vol = np.sqrt(portfolio_var(result.x))
            efficient_portfolios.append((vol, target))
    
    return efficient_portfolios

frontier = efficient_frontier(returns, cov_matrix)
vols, rets = zip(*frontier)

Compressed Sensing: Sparse Recovery via L1 Minimization

signal-processing

Real-World Motivation

Compressed sensing revolutionized signal acquisition by showing that sparse signals can be reconstructed from far fewer measurements than the Nyquist-Shannon theorem requires. Applications include MRI imaging, single-pixel cameras, and radar systems.

Definitions

  • Sparse Signal: A signal with most coefficients equal to zero.
  • Measurement Matrix \\(\\Phi\\): An \\(m \\times n\\) matrix with \\(m \\ll n\\).
  • Restricted Isometry Property (RIP): \\(\\Phi\\) preserves distances between sparse vectors.

Theorem: Exact Recovery via L1 Minimization

Theorem (Candès-Tao): If \\(\\Phi\\) satisfies RIP of order \\(2s\\) with constant \\(\\delta_{2s} < \\sqrt{2} - 1\\), then any \\(s\\)-sparse vector \\(x\\) can be exactly recovered by solving: \\[\\min \\|z\\|_1 \\text{ subject to } \\Phi z = y\\]

Notation Guide

  • \\(\\|x\\|_0\\): Number of non-zero entries (pseudo-norm)
  • \\(\\|x\\|_1 = \\sum_i |x_i|\\): L1 norm promoting sparsity
  • \\(\\|x\\|_2\\): Euclidean norm

Python Code

import numpy as np
from scipy.optimize import minimize
from scipy.linalg import hadamard

def basis_pursuit(Phi, y):
    """
    Solve min ||x||_1 subject to Phi @ x = y
    Using scipy's optimization (simplified version)
    """
    m, n = Phi.shape
    
    # L1 minimization via linear programming formulation
    # min sum(t_i) subject to -t <= x <= t, Phi*x = y
    
    from scipy.optimize import linprog
    
    # Variables: [x_1, ..., x_n, t_1, ..., t_n]
    c = np.concatenate([np.zeros(n), np.ones(n)])
    
    # Equality constraints: Phi @ x = y
    A_eq = np.hstack([Phi, np.zeros((m, n))])
    
    # Inequality constraints: x <= t, -x <= t
    A_ub = np.vstack([
        np.hstack([np.eye(n), -np.eye(n)]),
        np.hstack([-np.eye(n), -np.eye(n)])
    ])
    b_ub = np.zeros(2*n)
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, 
                     A_eq=A_eq, b_eq=y, method='highs')
    
    return result.x[:n]

def iterative_hard_thresholding(Phi, y, sparsity, max_iter=100):
    """
    IHT algorithm for sparse recovery (faster than L1 for large problems)
    """
    m, n = Phi.shape
    x = np.zeros(n)
    
    # Step size
    mu = 0.9 / np.linalg.norm(Phi, ord=2)**2
    
    for _ in range(max_iter):
        # Gradient descent step
        x = x + mu * Phi.T @ (y - Phi @ x)
        
        # Hard thresholding: keep only k largest components
        indices = np.argsort(np.abs(x))[-sparsity:]
        x_new = np.zeros(n)
        x_new[indices] = x[indices]
        x = x_new
        
        if np.linalg.norm(y - Phi @ x) < 1e-6:
            break
    
    return x

# Test compressed sensing

Graph Neural Networks and Spectral Methods

machine-learning

Real-World Motivation

Graph Neural Networks (GNNs) extend deep learning to non-Euclidean data like social networks, molecules, and knowledge graphs. Spectral methods connect GNNs to harmonic analysis on graphs, providing theoretical foundations and practical architectures.

Definitions

  • Graph Laplacian: \\(L = D - A\\) where \\(D\\) is degree matrix, \\(A\\) is adjacency.
  • Spectral Convolution: \\(x * y = U((U^T x) \\odot (U^T y))\\) where \\(U\\) contains Laplacian eigenvectors.
  • Message Passing: \\(h_v^{(l+1)} = \\sigma(\\sum_{u \\in \\mathcal{N}(v)} W^{(l)} h_u^{(l)})\\)

Theorem: Spectral Graph Convolutions

Theorem: A spectral convolution on a graph can be approximated by Chebyshev polynomials of the normalized Laplacian, avoiding full eigendecomposition: \\[x * y \\approx \\sum_{k=0}^{K} \\theta_k T_k(\\tilde{L}) x\\] where \\(T_k\\) are Chebyshev polynomials.

Notation Guide

  • \\(\\tilde{L} = 2L/\\lambda_{\\max} - I\\): Normalized Laplacian
  • \\(T_k\\): Chebyshev polynomial of first kind
  • \\(\\theta_k\\): Learnable filter parameters

Python Code

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import eigsh

def normalized_laplacian(adj):
    """Compute normalized graph Laplacian"""
    n = adj.shape[0]
    degrees = np.array(adj.sum(axis=1)).flatten()
    D_inv_sqrt = np.diag(1.0 / np.sqrt(degrees + 1e-8))
    I = np.eye(n)
    L = I - D_inv_sqrt @ adj @ D_inv_sqrt
    return L

def chebyshev_polynomials(L, K):
    """Compute Chebyshev polynomials up to order K"""
    n = L.shape[0]
    T = [np.eye(n), L]  # T_0 = I, T_1 = L
    
    for k in range(2, K+1):
        T.append(2 * L @ T[k-1] - T[k-2])
    
    return T

class GraphConvolution:
    """Simple spectral graph convolution layer"""
    
    def __init__(self, input_dim, output_dim, K=3):
        self.K = K
        self.theta = np.random.randn(K, input_dim, output_dim) * 0.1
    
    def forward(self, X, adj):
        """
        X: node features (n x input_dim)
        adj: adjacency matrix
        """
        L = normalized_laplacian(adj)
        T = chebyshev_polynomials(L, self.K)
        
        # Spectral convolution
        out = np.zeros((X.shape[0], self.theta.shape[2]))
        for k in range(self.K):
            out += T[k] @ X @ self.theta[k]
        
        return np.maximum(out, 0)  # ReLU activation

Arithmetic Dynamics: The Mandelbrot Set and Julia Sets

arithmetic-dynamics

Historical Context

Arithmetic dynamics, emerging in the 1990s, studies the number-theoretic properties of dynamical systems. It connects complex dynamics (Mandelbrot, Julia) with Diophantine geometry, asking questions like: what are the rational periodic points of a polynomial map?

Definitions

  • Julia Set: The boundary of the set of points with bounded orbits under iteration.
  • Mandelbrot Set: The set of complex \\(c\\) for which \\(f_c(z) = z^2 + c\\) has connected Julia set.
  • Canonical Height: A measure of arithmetic complexity of points under iteration.

Theorem: Uniform Boundedness Conjecture

Theorem (Morton-Silverman): For a rational map \\(\\phi: \\mathbb{P}^N \\to \\mathbb{P}^N\\) of degree \\(d \\geq 2\\) defined over a number field \\(K\\), there exists a bound \\(B(N, d, [K:Q])\\) such that \\(\\phi\\) has at most \\(B\\) preperiodic points in \\(\\mathbb{P}^N(K)\\).

Notation Guide

  • \\(f^n\\): \\(n\\)-fold composition of \\(f\\)
  • \\(\\hat{h}_\\phi\\): Canonical height associated to \\(\\phi\\)
  • \\(\\text{Per}(\\phi)\\): Set of periodic points

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2):
    """Compute Mandelbrot iterations for complex c"""
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            return n
        z = z*z + c
    return max_iter

def julia_set(c, width=800, height=600, max_iter=100, 
              x_min=-2, x_max=2, y_min=-1.5, y_max=1.5):
    """Compute Julia set for f(z) = z^2 + c"""
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j*Y
    
    iterations = np.zeros(Z.shape, dtype=int)
    mask = np.ones(Z.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + c
        mask_new = abs(Z) < 2
        iterations[~mask & mask_new] = i
        mask = mask_new
    
    return iterations

def compute_mandelbrot_set(width=800, height=600, max_iter=100):
    """Compute the Mandelbrot set"""
    x_min, x_max = -2.5, 1
    y_min, y_max = -1.25, 1.25
    
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    iterations = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        mask = abs(Z) <= 2
        iterations[~mask & (iterations == 0)] = i

    return iterations

Geometric Group Theory: Hyperbolic Groups

geometric-group-theory

Historical Context

Mikhail Gromov's 1987 paper "Hyperbolic Groups" revolutionized group theory by importing geometric concepts. A group is hyperbolic if its Cayley graph satisfies a thin triangle condition — negative curvature at the large scale.

Definitions

  • Cayley Graph: Graph with group elements as vertices, generators as edges.
  • \\(\\delta\\)-Hyperbolic: All geodesic triangles are \\(\\delta\\)-thin (each side in \\(\\delta\\)-neighborhood of union of other two).
  • Word Metric: Distance between \\(g, h\\) is length of shortest word representing \\(g^{-1}h\\).

Theorem: Linear Isoperimetric Inequality

Theorem (Gromov): A finitely presented group is hyperbolic if and only if it satisfies a linear isoperimetric inequality: there exists \\(K > 0\\) such that any word \\(w\\) representing the identity has area \\(\\text{Area}(w) \\leq K \\cdot |w|\\).

Notation Guide

  • \\(|w|\\): Word length
  • \\(\\partial P\\): Boundary of a van Kampen diagram
  • \\(|\\partial P|\\): Perimeter
  • \\(||P||\\): Area (number of 2-cells)

Python Code

from collections import deque
import numpy as np

class HyperbolicGroup:
    """
    Representation of a hyperbolic group (free group as example)
    """
    def __init__(self, generators):
        self.generators = set(generators)
        self.inverses = {g: g.upper() if g.islower() else g.lower() 
                        for g in generators}
        self.inverses.update({v: k for k, v in self.inverses.items()})
    
    def reduce(self, word):
        """Reduce word by canceling adjacent inverse pairs"""
        stack = []
        for char in word:
            if stack and stack[-1] == self.inverses.get(char):
                stack.pop()
            else:
                stack.append(char)
        return ''.join(stack)
    
    def multiply(self, w1, w2):
        """Multiply two group elements"""
        return self.reduce(w1 + w2)
    
    def word_metric(self, g, h):
        """Distance between group elements"""
        return len(self.reduce(self.reduce(g) + self.inverses_word(h)))
    
    def inverses_word(self, word):
        """Inverse of a word"""
        return ''.join(self.inverses[c] for c in reversed(word))
    
    def geodesic(self, g, h):
        """A geodesic (shortest path) from g to h"""
        # In free group, reduced word is unique geodesic
        return self.reduce(self.inverses_word(g) + h)

def triangle_thinness(group, a, b, c):
    """
    Check how 'thin' the triangle with vertices a, b, c is
    Returns max distance from a point on one side to the union of other two sides
    """
    # Get geodesic sides
    side_ab = group.geodesic(a, b)
    side_bc = group.geodesic(b, c)
    side_ca = group.geodesic(c, a)
    
    # In hyperbolic groups, triangles are uniformly thin
    # For free groups (trees), triangles are 0-thin (degenerate)
    
    # Build paths
    def path_vertices(start, word):
        """List vertices along geodesic from start following word"""
        verts = [start]
        current = start
        for char in word:
            current = group.multiply(current, char)
            verts.append(current)
        return verts
    
    path_ab = path_vertices(a, side_ab)
    path_bc = path_vertices(b, side_bc)
    path_ca = path_vertices(c, side_ca)
    
    # For free groups, any triangle has a 'center' where all three sides meet
    # This is the Gromov product
    return {
        'side_ab': side_ab,
        'side_bc': side_bc,
        'side_ca': side_ca,
        'path_ab': path_ab,
        'path_bc': path_bc,
        'path_ca': path_ca
    }

# Gromov product
def gromov_product(group, a, b, c):
    """
    (b . c)_a = 1/2 * (d(a,b) + d(a,c) - d(b,c))
    Measures how close b and c are 'as seen from' a
    """
    d_ab = group.word_metric(a, b)
    d_ac = group.word_metric(a, c)
    d_bc = group.word_metric(b, c)
    return (d_ab + d_ac - d_bc) // 2

Algebraic K-Theory: K₀ and Projective Modules

algebraic-k-theory

Historical Context

Algebraic K-theory, founded by Grothendieck in the late 1950s for his proof of the Grothendieck-Riemann-Roch theorem, assigns to each ring a sequence of abelian groups \\(K_n(R)\\) encoding deep structural information about modules over \\(R\\).

Definitions

  • Projective Module: A module \\(P\\) such that there exists \\(Q\\) with \\(P \\oplus Q\\) free.
  • \\(K_0(R)\\): The Grothendieck group of finitely generated projective \\(R\\)-modules.
  • Stably Free: \\(P\\) is stably free if \\(P \\oplus R^n \\cong R^m\\) for some \\(m, n\\).

Theorem: Serre's Conjecture (Quillen-Suslin)

Theorem (Quillen-Suslin, 1976): Every finitely generated projective module over a polynomial ring \\(k[x_1, \\ldots, x_n]\\) (for \\(k\\) a field) is free.

Notation Guide

  • \\([P]\\): Class of projective module \\(P\\) in \\(K_0\\)
  • \\(\\tilde{K}_0(R)\\): Reduced K-theory (cokernel of \\(\\mathbb{Z} \\to K_0(R)\\))
  • \\(\\text{Pic}(R)\\): Picard group of rank-1 projectives

Symplectic Geometry and Moment Maps

symplectic-geometry

Historical Context

Symplectic geometry emerged from Hamiltonian mechanics in the 19th century but was formalized as a geometric discipline in the 1960s. The moment map, connecting group actions to conserved quantities, generalizes Noether's theorem from physics.

Definitions

  • Symplectic Form: Closed, non-degenerate 2-form \\(\\omega\\).
  • Hamiltonian Vector Field: \\(X_H\\) defined by \\(\\iota_{X_H}\\omega = dH\\).
  • Moment Map: \\(\\mu: M \\to \\mathfrak{g}^*\\) such that \\(d\\langle \\mu, \\xi \\rangle = \\iota_{\\xi_M}\\omega\\).

Theorem: Marsden-Weinstein Reduction

Theorem: Let \\(\\mu: M \\to \\mathfrak{g}^*\\) be the moment map for a Hamiltonian \\(G\\)-action. If \\(\\xi \\in \\mathfrak{g}^*\\) is a regular value and \\(G\\) acts freely on \\(\\mu^{-1}(\\xi)\\), then \\(M_\\xi = \\mu^{-1}(\\xi)/G\\) is a symplectic manifold with form \\(\\omega_\\xi\\) satisfying \\(\\pi^*\\omega_\\xi = i^*\\omega\\).

Notation Guide

  • \\(\\iota_X\\omega\\): Interior product (contraction)
  • \\(\\xi_M\\): Vector field on \\(M\\) generated by \\(\\xi \\in \\mathfrak{g}\\)
  • \\(M_\\xi\\): Reduced space (symplectic quotient)

import numpy as np
from scipy.integrate import odeint

class SymplecticManifold:
    """
    Simplified symplectic structure on R^{2n} with standard form
    omega = sum_i dq^i ^ dp_i
    """
    def __init__(self, n):
        self.n = n  # Number of degrees of freedom
        self.dim = 2 * n
    
    def symplectic_form_matrix(self):
        """
        Standard symplectic form as matrix:
        omega = [[0, I], [-I, 0]]
        """
        n = self.n
        omega = np.zeros((2*n, 2*n))
        omega[:n, n:] = np.eye(n)
        omega[n:, :n] = -np.eye(n)
        return omega
    
    def hamiltonian_vector_field(self, H_grad):
        """
        Given gradient of Hamiltonian, compute Hamiltonian vector field
        X_H = omega^{-1} * dH
        """
        omega = self.symplectic_form_matrix()
        omega_inv = np.linalg.inv(omega)
        return omega_inv @ H_grad
    
    def poisson_bracket(self, f_grad, g_grad):
        """
        {f, g} = omega(X_f, X_g) = df^T * omega^{-1} * dg
        """
        omega = self.symplectic_form_matrix()
        omega_inv = np.linalg.inv(omega)
        return f_grad @ omega_inv @ g_grad

def hamiltonian_dynamics(H_func, grad_H_func, z0, t_span, n_dof):
    """
    Integrate Hamilton's equations
    dz/dt = X_H(z)
    """
    M = SymplecticManifold(n_dof)
    omega_inv = np.linalg.inv(M.symplectic_form_matrix())
    
    def rhs(z, t):
        grad_H = grad_H_func(z)
        return omega_inv @ grad_H
    
    solution = odeint(rhs, z0, t_span)
    return solution

📜 Math History

The Birth of Modern Algebra: Emmy Noether and Abstract Structures

The transformation of algebra from a discipline concerned with solving equations to one studying abstract structures is largely the achievement of one remarkable mathematician: Emmy Noether (1882–1935). Working in Göttingen during the 1920s, Noether fundamentally redefined what algebra could be.

Before Noether, algebra was primarily about manipulating symbols to solve polynomial equations. The very word "algebra" derives from al-Khwarizmi's 9th-century treatise on solving linear and quadratic equations. Even in the 19th century, when Galois introduced his theory connecting polynomial solvability to group structure, the focus remained on equations.

Noether changed this perspective entirely. In her seminal 1921 paper "Idealtheorie in Ringbereichen" (Ideal Theory in Ring Domains), she showed that studying the abstract properties of rings and ideals — independent of any particular representation — yielded powerful and general theorems. Her ascending chain condition, now called the Noetherian condition, provided a finiteness criterion that allowed her to prove that every ideal in a polynomial ring has a finite basis.

This was not merely a technical advance. Noether's approach demonstrated that the abstract structure of a ring (its lattice of ideals, its modules, its homomorphisms) contained more essential information than any concrete presentation. Her famous dictum — "es steht alles schon bei Dedekind" (it's all already in Dedekind) — acknowledged her debt to Richard Dedekind's structural approach to algebraic number theory, while her work went far beyond.

The influence of Noether's structural approach extended far beyond ring theory. Her students and collaborators — including Bartel van der Waerden, whose 1930 "Moderne Algebra" became the definitive text, and Emil Artin, who extended her methods to field theory — spread her vision throughout mathematics. By the mid-20th century, the "modern algebra" that Noether pioneered had become standard, influencing topology (via homological algebra), algebraic geometry (via sheaf theory), and even physics (via Noether's theorem connecting symmetries to conservation laws).

Noether's career also illustrates the barriers faced by women in mathematics. Despite her revolutionary contributions, she worked without pay at Göttingen for years, and was dismissed by the Nazi regime in 1933 because she was Jewish. She spent her final two years at Bryn Mawr College in the United States, where she died unexpectedly in 1935. Albert Einstein wrote in her obituary: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began."

Problem: A Functional Equation

Difficulty: ★★★☆☆ (Intermediate)

Find all functions \\(f: \\mathbb{R} \\to \\mathbb{R}\\) such that for all \\(x, y \\in \\mathbb{R}\\):

\\[f(x^2 + y) = f(x)^2 + f(y)\\]
Hint

Start by finding \\(f(0)\\). Then consider what happens when \\(y = 0\\) and when \\(x = 0\\). Show that \\(f\\) must be non-negative on \\([0, \\infty)\\) and explore the consequences for \\(f(x^2)\\).

Solution

Step 1: Setting \\(x = y = 0\\):

\\(f(0) = f(0)^2 + f(0)\\), so \\(f(0)^2 = 0\\), hence \\(f(0) = 0\\).

Step 2: Setting \\(y = 0\\):

\\(f(x^2) = f(x)^2 + f(0) = f(x)^2 \\geq 0\\).

So \\(f\\) is non-negative on \\([0, \\infty)\\).

Step 3: Setting \\(x = 0\\):

\\(f(y) = f(0)^2 + f(y) = f(y)\\). This gives no new information.

Step 4: For any \\(t \\geq 0\\), we can write \\(t = x^2\\) for \\(x = \\sqrt{t}\\). Then:

\\(f(t) = f(\\sqrt{t})^2\\).

Step 5: Now, \\(f(x^2 + y) = f(x)^2 + f(y) = f(x^2) + f(y)\\).

Letting \\(u = x^2 \\geq 0\\), we have \\(f(u + y) = f(u) + f(y)\\) for all \\(u \\geq 0\\) and all \\(y\\).

Step 6: For \\(u, v \\geq 0\\): \\(f(u + v) = f(u) + f(v)\\).

Combined with \\(f(t) \\geq 0\\) for \\(t \\geq 0\\), this implies \\(f(x) = cx\\) for \\(x \\geq 0\\) for some constant \\(c \\geq 0\\).

Step 7: From \\(f(x^2) = f(x)^2\\):

For \\(x \\geq 0\\): \\(cx^2 = (cx)^2 = c^2x^2\\), so \\(c = c^2\\), meaning \\(c = 0\\) or \\(c = 1\\).

Step 8: Case \\(c = 0\\):

Then \\(f(x) = 0\\) for \\(x \\geq 0\\). From \\(f(x^2) = f(x)^2 = 0\\), this is consistent.

For any \\(y\\), choose \\(x\\) large so \\(x^2 + y \\geq 0\\). Then \\(0 = f(x^2 + y) = f(x)^2 + f(y) = f(y)\\).

So \\(f(x) = 0\\) for all \\(x\\).

Step 9: Case \\(c = 1\\):

Then \\(f(x) = x\\) for \\(x \\geq 0\\). For \\(x < 0\\), use \\(f(x^2) = f(x)^2\\):

\\(x^2 = f(x)^2\\), so \\(f(x) = x\\) or \\(f(x) = -x\\).

If \\(f(a) = -a\\) for some \\(a < 0\\), then for any \\(y\\):

\\(f(a^2 + y) = f(a)^2 + f(y) = a^2 + f(y)\\).

Since \\(a^2 > 0\\), we have \\(f(a^2 + y) = a^2 + y\\) if \\(a^2 + y \\geq 0\\).

So \\(a^2 + y = a^2 + f(y)\\), giving \\(f(y) = y\\) for all \\(y \\geq -a^2\\).

For \\(y < 0\\) with \\(a^2 + y \\geq 0\\): \\(f(y) = y\\).

But \\(f(a) = -a \\neq a\\) (since \\(a < 0\\)), contradiction.

Therefore \\(f(x) = x\\) for all \\(x\\).

Answer: The solutions are \\(f(x) = 0\\) and \\(f(x) = x\\).

The Lorenz Attractor: Deterministic Chaos

The Lorenz system, introduced by Edward Lorenz in 1963, is a simplified model of atmospheric convection that exhibits deterministic chaos. The iconic butterfly-shaped attractor demonstrates how simple deterministic equations can produce unpredictable behavior.

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def lorenz_system(state, t, sigma=10, rho=28, beta=8/3):
    """
    Lorenz system of ODEs
    dx/dt = sigma * (y - x)
    dy/dt = x * (rho - z) - y
    dz/dt = x * y - beta * z
    """
    x, y, z = state
    dxdt = sigma * (y - x)
    dydt = x * (rho - z) - y
    dzdt = x * y - beta * z
    return [dxdt, dydt, dzdt]

# Time array
t = np.linspace(0, 50, 10000)

# Initial conditions (small perturbation)
state0 = [1.0, 1.0, 1.0]

# Solve ODE
solution = odeint(lorenz_system, state0, t)
x, y, z = solution[:, 0], solution[:, 1], solution[:, 2]

# Create 3D plot
fig = plt.figure(figsize=(12, 9))
ax = fig.add_subplot(111, projection='3d')

# Plot with color gradient based on time
colors = plt.cm.viridis(np.linspace(0, 1, len(t)))
for i in range(len(t)-1):
    ax.plot(x[i:i+2], y[i:i+2], z[i:i+2], 
            color=colors[i], linewidth=0.5, alpha=0.8)

ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('Lorenz Attractor: σ=10, ρ=28, β=8/3')

plt.tight_layout()
plt.savefig('lorenz_attractor.png', dpi=150, bbox_inches='tight')
plt.show()

# Demonstrate sensitive dependence on initial conditions
print("Sensitive Dependence on Initial Conditions:")
print("="*50)

state0_perturbed = [1.0001, 1.0, 1.0]  # Tiny perturbation
solution2 = odeint(lorenz_system, state0_perturbed, t)

# Compute divergence
divergence = np.sqrt(np.sum((solution - solution2)**2, axis=1))
print(f"Initial separation: {divergence[0]:.6f}")
print(f"Separation at t=10: {divergence[1000]:.6f}")
print(f"Separation at t=20: {divergence[2000]:.6f}")
print(f"Separation at t=30: {divergence[4000]:.6f}")

# Estimate Lyapunov exponent
log_div = np.log(divergence[10:1000] + 1e-10)
lyapunov = np.polyfit(t[10:1000], log_div, 1)[0]
print(f"\\nEstimated largest Lyapunov exponent: {lyapunov:.4f}")
print("(Positive exponent indicates chaos)")

# Find approximate attractor dimensions
print(f"\\nAttractor statistics:")
print(f"X range: [{x.min():.2f}, {x.max():.2f}]")
print(f"Y range: [{y.min():.2f}, {y.max():.2f}]")
print(f"Z range: [{z.min():.2f}, {z.max():.2f}]")

# Fixed points
print(f"\\nFixed points:")
print(f"(0, 0, 0) - unstable")
print(f"(±√(β(ρ-1)), ±√(β(ρ-1)), ρ-1) = (±{np.sqrt(8/3 * 27):.2f}, ±{np.sqrt(8/3 * 27):.2f}, 27)")

The Lorenz attractor demonstrates several key features of chaotic systems:

  • Sensitive dependence: Nearby trajectories diverge exponentially (positive Lyapunov exponent ≈ 0.906)
  • Deterministic: The system's evolution is completely determined by its equations and initial conditions
  • Bounded: Despite the chaos, trajectories remain within the attractor's bounds
  • Fractal structure: The attractor has a complex, self-similar structure with non-integer dimension (~2.06)

💬 Quote of the Day

"The essence of mathematics lies in its freedom."

— Georg Cantor

Cantor's famous declaration, made in his 1883 "Grundlagen einer allgemeinen Mannigfaltigkeitslehre" (Foundations of a General Theory of Manifolds), was a defense of his theory of infinite sets against the fierce criticism it received from contemporaries like Kronecker. The quote captures a profound truth: mathematics progresses not by adherence to preconceived notions of what is "legitimate," but by following the logical consequences of well-defined concepts wherever they lead. Cantor's willingness to embrace actual infinity — rejected by most mathematicians since Aristotle — opened entire new realms of mathematics, from set theory to topology to measure theory. His freedom to imagine different sizes of infinity, embodied in his theorem that there are more real numbers than natural numbers, remains one of the most beautiful and counterintuitive results in all of mathematics.
