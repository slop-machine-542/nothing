p-adic Analysis: When Distance Gets Weird

p-adic-analysis

Motivation

What if large numbers were considered "closer" to zero than small ones? p-adic analysis, introduced by Kurt Hensel in 1897, develops calculus based on an alternative notion of absolute value where a number is small if it's divisible by a high power of a prime p. This seemingly strange idea has profound applications in number theory (local-global principles, Diophantine equations), algebraic geometry (étale cohomology), and even physics (p-adic string theory, quantum mechanics). The p-adic numbers form a complete metric space, but one where every point in an open ball is its center, and all triangles are isosceles.

Definitions

  • p-adic Valuation: For a prime p and nonzero integer n, \(v_p(n)\) is the highest power of p dividing n. For \(n = p^k \cdot m\) with \(p \nmid m\), we have \(v_p(n) = k\).
  • p-adic Absolute Value: \(|n|_p = p^{-v_p(n)}\) for \(n \neq 0\), and \(|0|_p = 0\). Larger powers of p give smaller absolute values.
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\). Elements can be written as Laurent series \(\sum_{k=N}^{\infty} a_k p^k\) with \(a_k \in \{0, 1, \ldots, p-1\}\).
  • p-adic Integers \(\mathbb{Z}_p\): The unit ball \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\}\), consisting of series with no negative powers of p.
  • Ostrowski's Theorem: Every nontrivial absolute value on \(\mathbb{Q}\) is equivalent to either the usual absolute value or a p-adic absolute value.

Theorem: Hensel's Lemma

Theorem (Hensel's Lemma): Let \(f(x) \in \mathbb{Z}_p[x]\) be a polynomial. If there exists \(a_0 \in \mathbb{Z}_p\) such that:

\[|f(a_0)|_p < |f'(a_0)|_p^2\]

then there exists a unique \(a \in \mathbb{Z}_p\) such that \(f(a) = 0\) and \(|a - a_0|_p < |f'(a_0)|_p\).

Simple Version: If \(f(a_0) \equiv 0 \pmod{p}\) and \(f'(a_0) \not\equiv 0 \pmod{p}\), then there exists \(a \in \mathbb{Z}_p\) with \(a \equiv a_0 \pmod{p}\) and \(f(a) = 0\).

Proof Sketch

The proof uses Newton's method in the p-adic setting. Define the sequence:

\[a_{n+1} = a_n - \frac{f(a_n)}{f'(a_n)}\]

One shows by induction that \(|f(a_n)|_p \to 0\) and \(|a_{n+1} - a_n|_p \to 0\), with the limit satisfying \(f(a) = 0\). The key is that the strong triangle inequality \(|x + y|_p \leq \max(|x|_p, |y|_p)\) allows precise control of the convergence.

Notation Guide

  • \(v_p(x)\): p-adic valuation (exponent of p in factorization)
  • \(|x|_p = p^{-v_p(x)}\): p-adic absolute value
  • \(\mathbb{Q}_p\): Field of p-adic numbers
  • \(\mathbb{Z}_p\): Ring of p-adic integers
  • \(\mathbb{Z}_p^\times\): Group of p-adic units (elements with \(|x|_p = 1\))
  • \(a \equiv b \pmod{p^n}\): Means \(|a - b|_p \leq p^{-n}\)

from fractions import Fraction

def padic_valuation(n, p):
    """Compute the p-adic valuation v_p(n) for integer n."""
    if n == 0:
        return float('inf')
    n = abs(n)
    val = 0
    while n % p == 0:
        n //= p
        val += 1
    return val

def padic_absolute_value(n, p):
    """Compute the p-adic absolute value |n|_p."""
    if n == 0:
        return 0
    return p ** (-padic_valuation(n, p))

Algebraic Graph Theory: Spectra and Symmetry

algebraic-graph-theory

Motivation

How can linear algebra reveal hidden structure in networks? Algebraic graph theory uses tools from linear algebra and group theory to study graphs. By encoding a graph as a matrix (adjacency matrix, Laplacian), we can apply spectral methods to understand connectivity, expansion, clustering, and symmetry. This field connects graph theory to representation theory, harmonic analysis, and even quantum computing. Applications include network analysis, error-correcting codes, the design of robust computer networks, and understanding molecular structure in chemistry.

Definitions

  • Adjacency Matrix \(A\): For a graph \(G = (V, E)\), \(A_{ij} = 1\) if \((i,j) \in E\), and \(0\) otherwise. For weighted graphs, \(A_{ij}\) equals the edge weight.
  • Degree Matrix \(D\): Diagonal matrix with \(D_{ii} = \deg(i)\), the degree of vertex \(i\).
  • Laplacian Matrix \(L\): \(L = D - A\). The normalized Laplacian is \(\mathcal{L} = D^{-1/2} L D^{-1/2}\).
  • Graph Spectrum: The multiset of eigenvalues of \(A\) or \(L\), denoted \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\).
  • Algebraic Connectivity: The second-smallest eigenvalue of \(L\), denoted \(\lambda_2\) or \(a(G)\). It measures how well-connected the graph is.
  • Graph Automorphism: A permutation \(\sigma\) of vertices such that \((i,j) \in E\) iff \((\sigma(i), \sigma(j)) \in E\). The set of all automorphisms forms the automorphism group \(\text{Aut}(G)\).

Theorem: The Matrix-Tree Theorem

Theorem (Kirchhoff's Matrix-Tree Theorem): Let \(G\) be a connected graph with Laplacian matrix \(L\). Let \(L'\) be any cofactor of \(L\) (obtained by deleting any row and the corresponding column). Then:

\[\det(L') = \tau(G)\]

where \(\tau(G)\) is the number of spanning trees of \(G\).

Corollary: The number of spanning trees can also be expressed as:

\[\tau(G) = \frac{1}{n} \lambda_2 \lambda_3 \cdots \lambda_n\]

where \(0 = \lambda_1 < \lambda_2 \leq \cdots \leq \lambda_n\) are the eigenvalues of \(L\).

Proof Sketch

The proof uses the Cauchy-Binet formula and the fact that the Laplacian can be written as \(L = BB^T\) where \(B\) is the (oriented) incidence matrix. Each term in the expansion of \(\det(L')\) corresponds to a choice of \(n-1\) edges, and nonzero terms correspond exactly to spanning trees. The eigenvalue formula follows from the fact that the characteristic polynomial of \(L\) has the form \(\det(L - \lambda I) = -\lambda \prod_{i=2}^{n}(\lambda_i - \lambda)\), and comparing coefficients.

Notation Guide

  • \(G = (V, E)\): Graph with vertex set \(V\) and edge set \(E\)
  • \(n = |V|\): Number of vertices
  • \(m = |E|\): Number of edges
  • \(A\): Adjacency matrix
  • \(D\): Degree matrix
  • \(L = D - A\): Laplacian matrix
  • \(\lambda_i\): i-th eigenvalue (usually ordered)
  • \(\tau(G)\): Number of spanning trees
  • \(\text{Aut}(G)\): Automorphism group

import numpy as np

def adjacency_matrix(edges, n):
    """Create adjacency matrix from edge list."""
    A = np.zeros((n, n))
    for i, j in edges:
        A[i][j] = A[j][i] = 1
    return A

def laplacian_matrix(A):
    """Compute Laplacian from adjacency matrix."""
    D = np.diag(np.sum(A, axis=1))
    return D - A

def count_spanning_trees(L):
    """Count spanning trees using Matrix-Tree theorem."""
    L_reduced = L[:-1, :-1]
    return round(np.linalg.det(L_reduced))

# Cycle graph C_n
def cycle_graph(n):
    return [(i, (i+1) % n) for i in range(n)]

# Petersen graph
def petersen_graph():
    inner = [(i, (i+2) % 5) for i in range(5)]
    outer = [(i+5, ((i+1) % 5) + 5) for i in range(5)]
    spokes = [(i, i+5) for i in range(5)]
    return inner + outer + spokes

print("Algebraic Graph Theory: Spectral Analysis")
print("=" * 50)

Complex Analysis: The Magic of Analytic Functions

complex-analysis

Motivation

Why are functions of a complex variable so special? Complex analysis, pioneered by Cauchy, Riemann, and Weierstrass in the 19th century, studies functions that are differentiable in the complex plane. Remarkably, this single condition—complex differentiability—implies an extraordinary richness of structure: power series expansions, contour integrals, residue theory, and conformal mappings. Complex analysis provides powerful tools for evaluating real integrals, solving differential equations, and studying prime numbers. It underlies much of modern physics, from quantum mechanics to fluid dynamics, and has deep connections to algebraic geometry and number theory.

Definitions

  • Holomorphic/Analytic Function: A function \(f: U \to \mathbb{C}\) (where \(U \subseteq \mathbb{C}\) is open) is holomorphic at \(z_0\) if the limit \(\lim_{z \to z_0} \frac{f(z) - f(z_0)}{z - z_0}\) exists. Equivalently, \(f\) satisfies the Cauchy-Riemann equations.
  • Cauchy-Riemann Equations: Writing \(f(z) = u(x,y) + iv(x,y)\) where \(z = x + iy\), holomorphicity requires: \(\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}\) and \(\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}\).
  • Contour Integral: For a curve \(\gamma: [a,b] \to \mathbb{C}\) and continuous \(f\): \(\int_\gamma f(z) dz = \int_a^b f(\gamma(t)) \gamma'(t) dt\).
  • Residue: If \(f\) has an isolated singularity at \(z_0\), the residue is \(\text{Res}(f, z_0) = \frac{1}{2\pi i} \oint_{|z-z_0|=\epsilon} f(z) dz\), the coefficient of \((z-z_0)^{-1}\) in the Laurent expansion.
  • Meromorphic Function: Holomorphic except at isolated poles (singularities where \(|f(z)| \to \infty\)).

Theorem: The Residue Theorem

Theorem (Cauchy's Residue Theorem): Let \(U\) be a simply connected domain and \(\gamma\) a positively oriented, simple closed contour in \(U\). If \(f\) is meromorphic in \(U\) with poles \(z_1, z_2, \ldots, z_n\) inside \(\gamma\), then:

\[\oint_\gamma f(z) dz = 2\pi i \sum_{k=1}^{n} \text{Res}(f, z_k)\]

Corollary (Argument Principle): If \(f\) is meromorphic in and on \(\gamma\), then:

\[\frac{1}{2\pi i} \oint_\gamma \frac{f'(z)}{f(z)} dz = N - P\]

where \(N\) is the number of zeros and \(P\) is the number of poles inside \(\gamma\), counted with multiplicity.

Proof Sketch

Deform the contour \(\gamma\) into small circles around each singularity. By Cauchy's theorem, the integral over \(\gamma\) equals the sum of integrals around these small circles. Near each pole \(z_k\), write the Laurent series \(f(z) = \sum_{n=-\infty}^{\infty} a_n (z-z_k)^n\). Only the \(n = -1\) term contributes to the integral, giving \(2\pi i \cdot a_{-1} = 2\pi i \cdot \text{Res}(f, z_k)\).

Notation Guide

  • \(z = x + iy = re^{i\theta}\): Complex number in Cartesian/polar form
  • \(\bar{z} = x - iy\): Complex conjugate
  • \(|z| = \sqrt{x^2 + y^2} = \sqrt{z\bar{z}}\): Modulus
  • \(\text{Re}(z) = x\), \(\text{Im}(z) = y\): Real and imaginary parts
  • \(f'(z)\) or \(\frac{df}{dz}\): Complex derivative
  • \(\oint\): Contour integral over closed curve
  • \(\text{Res}(f, z_0)\): Residue of \(f\) at \(z_0\)

Python Code

import numpy as np
from scipy import integrate

def contour_integral(f, gamma, dgamma, t_start, t_end, n_points=1000):
    """Compute contour integral of f along curve gamma(t)."""
    t = np.linspace(t_start, t_end, n_points)
    dt = (t_end - t_start) / n_points
    integral = 0
    for ti in t:
        z = gamma(ti)
        dz = dgamma(ti) * dt
        integral += f(z) * dz
    return integral

Reinforcement Learning: Mathematics of Learning from Experience

reinforcement-learning

Motivation

How can an agent learn optimal behavior through trial and error? Reinforcement learning (RL) studies how intelligent agents ought to take actions in an environment to maximize cumulative reward. Rooted in dynamic programming and optimal control theory, RL has achieved remarkable successes: from mastering Go and chess to controlling robots and optimizing data center cooling. The mathematical foundations involve Markov decision processes, Bellman equations, and convergence analysis of learning algorithms. RL represents a beautiful intersection of probability theory, optimization, and machine learning.

Definitions

  • Markov Decision Process (MDP): A tuple \((\mathcal{S}, \mathcal{A}, P, R, \gamma)\) where \(\mathcal{S}\) is the state space, \(\mathcal{A}\) is the action space, \(P(s'|s,a)\) is the transition probability, \(R(s,a)\) is the reward function, and \(\gamma \in [0,1)\) is the discount factor.
  • Policy \(\pi\): A mapping from states to actions (deterministic) or probability distributions over actions (stochastic).
  • Value Function \(V^\pi(s)\): The expected cumulative reward starting from state \(s\) and following policy \(\pi\): \(V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t) \mid s_0 = s\right]\).
  • Q-Function \(Q^\pi(s,a)\): The expected cumulative reward starting from state \(s\), taking action \(a\), then following \(\pi\).
  • Optimal Value Function \(V^*(s)\): \(V^*(s) = \max_\pi V^\pi(s)\). The optimal Q-function is \(Q^*(s,a) = \max_\pi Q^\pi(s,a)\).

Theorem: The Bellman Optimality Equations

Theorem (Bellman Optimality): The optimal value function \(V^*\) is the unique solution to:

\[V^*(s) = \max_{a \in \mathcal{A}} \left\{ R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'|s,a) V^*(s') \right\}\]

Equivalently, for the Q-function:

\[Q^*(s,a) = R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'|s,a) \max_{a'} Q^*(s', a')\]

Theorem (Convergence of Value Iteration): Define the Bellman operator \(\mathcal{T}\) by \((\mathcal{T}V)(s) = \max_a \{R(s,a) + \gamma \sum_{s'} P(s'|s,a)V(s')\}\). Then \(\mathcal{T}\) is a contraction with factor \(\gamma\), and iterating \(V_{k+1} = \mathcal{T}V_k\) converges to \(V^*\) exponentially fast.

Proof Sketch (Contraction)

For any two value functions \(V_1, V_2\):

\[\|\mathcal{T}V_1 - \mathcal{T}V_2\|_\infty \leq \gamma \|V_1 - V_2\|_\infty\]

This follows because the max of a sum is at most the sum of maxes, and the transition probabilities sum to 1. By the Banach fixed-point theorem, iterating \(\mathcal{T}\) converges to a unique fixed point, which must be \(V^*\).

Notation Guide

  • \(\mathcal{S}\): State space
  • \(\mathcal{A}\): Action space
  • \(P(s'|s,a)\): Transition probability
  • \(R(s,a)\): Expected immediate reward
  • \(\gamma\): Discount factor
  • \(\pi(a|s)\): Policy (probability of action a in state s)
  • \(V^\pi(s)\): Value function for policy \(\pi\)
  • \(Q^\pi(s,a)\): Action-value function
  • \(\mathcal{T}\): Bellman optimality operator

import numpy as np

class GridWorld:
    """Simple grid world MDP."""
    def __init__(self, size=4):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4  # up, down, left, right
        self.gamma = 0.9
        self.rewards = np.zeros(self.n_states)
        self.rewards[-1] = 1.0  # Goal state
        
    def get_transition(self, s, a):
        """Get next state for (s, a)."""
        row, col = s // self.size, s % self.size
        moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        dr, dc = moves[a]
        new_row = max(0, min(self.size - 1, row + dr))
        new_col = max(0, min(self.size - 1, col + dc))
        return new_row * self.size + new_col
    
    def value_iteration(self, tol=1e-6, max_iter=1000):
        """Solve for optimal value function."""
        V = np.zeros(self.n_states)
        for iteration in range(max_iter):
            V_new = np.zeros(self.n_states)
            for s in range(self.n_states):
                if s == self.n_states - 1:
                    continue
                Q_values = [self.rewards[s] + self.gamma * V[self.get_transition(s, a)] 
                           for a in range(self.n_actions)]
                V_new[s] = max(Q_values)
            if np.max(np.abs(V_new - V)) < tol:
                print(f"Converged after {iteration + 1} iterations")
                break
            V = V_new
        return V
    
    def extract_policy(self, V):
        """Extract optimal policy from value function."""
        policy = np.zeros(self.n_states, dtype=int)
        for s in range(self.n_states):
            if s == self.n_states - 1:
                continue
            Q_values = [self.rewards[s] + self.gamma * V[self.get_transition(s, a)] 
                       for a in range(self.n_actions)]
            policy[s] = np.argmax(Q_values)
        return policy

# Create and solve grid world
env = GridWorld(size=4)
print("Reinforcement Learning: Value Iteration")
print("=" * 50)

V_optimal = env.value_iteration()
policy = env.extract_policy(V_optimal)

print("\nOptimal Value Function:")
V_grid = V_optimal.reshape((env.size, env.size))
print(V_grid.round(3))

print("\nOptimal Policy (0=↑, 1=↓, 2=←, 3=→):")
policy_grid = policy.reshape((env.size, env.size))
print(policy_grid)

Mathematical Epidemiology: Modeling Disease Spread

mathematical-epidemiology

Motivation

How do infectious diseases spread through populations, and how can we control them? Mathematical epidemiology uses dynamical systems to model disease transmission, predict outbreaks, and evaluate intervention strategies. The field dates back to Daniel Bernoulli's 1760 work on smallpox vaccination, but modern epidemiology was founded by Kermack and McKendrick in 1927 with their SIR model. These models inform public health policy, guide vaccine distribution, and help us understand emerging infectious diseases.

Definitions

  • SIR Model: Divides population into Susceptible (S), Infected (I), and Recovered (R) compartments. Governed by: \(\frac{dS}{dt} = -\beta SI/N\), \(\frac{dI}{dt} = \beta SI/N - \gamma I\), \(\frac{dR}{dt} = \gamma I\).
  • Basic Reproduction Number \(R_0\): The expected number of secondary cases produced by a single infected individual in a completely susceptible population. For SIR: \(R_0 = \beta/\gamma\).
  • Herd Immunity Threshold: The proportion of population that must be immune to prevent sustained transmission: \(1 - 1/R_0\).
  • SEIR Model: Extension with Exposed (E) compartment for latent period.

Theorem: Final Size Relation

Theorem (Final Size Relation): For the SIR model with initial conditions \(S(0) = S_0\), \(I(0) = I_0\), \(R(0) = 0\), and \(S_0 + I_0 = N\), the final epidemic size \(R_\infty = \lim_{t \to \infty} R(t)\) satisfies:

\[R_\infty = N - S_0 \exp\left(-R_0 \frac{R_\infty}{N}\right)\]

where \(R_0 = \beta/\gamma\).

Corollary: An epidemic occurs (i.e., \(R_\infty > 0\)) if and only if \(R_0 > 1\) and \(S_0/N > 1/R_0\).

Notation Guide

  • \(S(t)\): Number of susceptible individuals
  • \(I(t)\): Number of infected individuals
  • \(R(t)\): Number of recovered/removed individuals
  • \(N = S + I + R\): Total population
  • \(\beta\): Transmission rate
  • \(\gamma\): Recovery rate
  • \(R_0 = \beta/\gamma\): Basic reproduction number

Python Code

import numpy as np
from scipy.integrate import odeint

def sir_model(y, t, beta, gamma, N):
    """SIR model differential equations."""
    S, I, R = y
    dSdt = -beta * S * I / N
    dIdt = beta * S * I / N - gamma * I
    dRdt = gamma * I
    return [dSdt, dIdt, dRdt]

def final_size_relation(R0, s0=1.0):
    """Solve final size equation."""
    from scipy.optimize import fsolve
    def equation(r_inf):
        return r_inf - (1 - s0 * np.exp(-R0 * r_inf))
    return fsolve(equation, 0.5)[0]

# Parameters
N = 1000000
I0 = 100
R0_values = [2.5, 4.0, 6.0]
gamma = 1/10

print("Mathematical Epidemiology: SIR Model")
print("=" * 50)

for R0 in R0_values:
    beta = R0 * gamma
    t = np.linspace(0, 160, 1600)
    y0 = [N - I0, I0, 0]
    solution = odeint(sir_model, y0, t, args=(beta, gamma, N))
    S, I, R = solution.T
    
    peak_idx = np.argmax(I)
    r_inf = final_size_relation(R0)
    
    print(f"\nR₀ = {R0}:")
    print(f"  Peak infections: {I[peak_idx]:.0f} at day {t[peak_idx]:.1f}")
    print(f"  Final epidemic size: {r_inf*100:.1f}%")
    print(f"  Herd immunity threshold: {(1-1/R0)*100:.1f}%")

Convex Optimization: The Mathematics of Efficient Decision-Making

optimization

Motivation

Why are some optimization problems "easy" while others are computationally intractable? Convex optimization deals with minimizing convex functions over convex sets, a class of problems that can be solved efficiently and reliably at scale. This field provides the mathematical foundation for machine learning, signal processing, control systems, finance, and engineering design. The key insight is that convexity ensures local optima are global.

Definitions

  • Convex Set: A set \(C\) is convex if for all \(x, y \in C\) and \(\theta \in [0,1]\): \(\theta x + (1-\theta)y \in C\).
  • Convex Function: A function \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if for all \(x, y\) and \(\theta \in [0,1]\): \(f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)\).
  • Convex Optimization Problem: \(\min_{x} f_0(x)\) subject to \(f_i(x) \leq 0\) for \(i = 1, \ldots, m\) and \(h_j(x) = 0\) for \(j = 1, \ldots, p\), where \(f_0, f_1, \ldots, f_m\) are convex and \(h_j\) are affine.
  • Lagrangian: \(\mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)\) where \(\lambda_i \geq 0\).

Theorem: First-Order Optimality Condition

Theorem: Let \(f\) be convex and differentiable. Then \(x^*\) minimizes \(f\) over a convex set \(C\) if and only if:

\[\nabla f(x^*)^T (y - x^*) \geq 0 \quad \text{for all } y \in C\]

Corollary (Unconstrained): For unconstrained convex optimization, \(x^*\) is optimal iff \(\nabla f(x^*) = 0\).

Theorem (Gradient Descent Convergence): For an \(L\)-smooth convex function \(f\), gradient descent with step size \(\eta \leq 1/L\) satisfies:

\[f(x_k) - f(x^*) \leq \frac{\|x_0 - x^*\|^2}{2\eta k}\]

Notation Guide

  • \(f: \mathbb{R}^n \to \mathbb{R}\): Objective function
  • \(C \subseteq \mathbb{R}^n\): Feasible set
  • \(\nabla f(x)\): Gradient of \(f\) at \(x\)
  • \(\nabla^2 f(x)\): Hessian matrix
  • \(\|\cdot\|\): Norm (usually Euclidean)
  • \(\lambda, \nu\): Lagrange multipliers
  • \(L\): Lipschitz constant of gradient

Python Code

import numpy as np

def gradient_descent(f, grad_f, x0, step_size=0.01, max_iter=1000, tol=1e-6):
    """Simple gradient descent for convex optimization."""
    x = x0.copy()
    for k in range(max_iter):
        gradient = grad_f(x)
        x_new = x - step_size * gradient
        if np.linalg.norm(x_new - x) < tol:
            print(f"Converged after {k+1} iterations")
            break
        x = x_new
    return x

# Example: Quadratic function f(x) = 0.5 * x^T A x - b^T x
n = 10
A = np.random.randn(n, n)
A = A.T @ A + 0.1 * np.eye(n)  # Ensure positive definite
b = np.random.randn(n)

def quadratic(x):
    return 0.5 * x @ A @ x - b @ x

def grad_quadratic(x):
    return A @ x - b

x_opt = np.linalg.solve(A, b)
x_gd = gradient_descent(quadratic, grad_quadratic, np.zeros(n), 
                        step_size=0.01, max_iter=500)

print("Convex Optimization: Gradient Descent")
print("=" * 50)
print(f"True solution error: {np.linalg.norm(x_gd - x_opt):.2e}")
print(f"Function value gap: {quadratic(x_gd) - quadratic(x_opt):.2e}")

Matroid Theory: The Algebra of Independence

matroid-theory

Historical Context

Matroid theory was introduced by Hassler Whitney in 1935 as a common generalization of linear independence in vector spaces and independence in graphs. Whitney sought to understand why these seemingly different concepts shared so many properties. The theory was further developed by Saunders Mac Lane and later by Tutte, Rado, and others. Matroids have found applications in combinatorial optimization (greedy algorithms), coding theory, network flows, and algorithm design.

Definitions

  • Matroid: A pair \(M = (E, \mathcal{I})\) where \(E\) is a finite ground set and \(\mathcal{I} \subseteq 2^E\) is a collection of independent sets satisfying: (I1) \(\emptyset \in \mathcal{I}\); (I2) If \(A \in \mathcal{I}\) and \(B \subseteq A\), then \(B \in \mathcal{I}\); (I3) If \(A, B \in \mathcal{I}\) and \(|A| < |B|\), then there exists \(x \in B \setminus A\) such that \(A \cup \{x\} \in \mathcal{I}\).
  • Basis: A maximal independent set. All bases have the same cardinality, called the rank of the matroid.
  • Rank Function: \(r(A) = \max\{|I| : I \subseteq A, I \in \mathcal{I}\}\).
  • Circuit: A minimal dependent set.

Theorem: The Matroid Greedy Algorithm

Theorem: Let \(M = (E, \mathcal{I})\) be a matroid with weight function \(w: E \to \mathbb{R}_+\). The greedy algorithm (repeatedly add the heaviest element that maintains independence) returns a maximum-weight basis.

Converse (Rado-Edmonds): If \((E, \mathcal{I})\) is an independence system where the greedy algorithm always finds an optimal solution for all weight functions, then it is a matroid.

Python Code

class Matroid:
    """Abstract base class for matroids."""
    def __init__(self, ground_set):
        self.E = set(ground_set)
    
    def is_independent(self, subset):
        raise NotImplementedError
    
    def greedy_max_weight_basis(self, weights):
        """Find maximum weight basis using greedy algorithm."""
        sorted_elements = sorted(self.E, key=lambda e: weights[e], reverse=True)
        basis = set()
        for e in sorted_elements:
            trial = basis | {e}
            if self.is_independent(trial):
                basis = trial
        return basis

class UniformMatroid(Matroid):
    """Uniform matroid U_{n,r}."""
    def __init__(self, n, r):
        super().__init__(range(n))
        self.r = r
    def is_independent(self, subset):
        return len(subset) <= self.r

# Example
U = UniformMatroid(n=5, r=3)
weights = {i: 10 - i for i in range(5)}
basis = U.greedy_max_weight_basis(weights)
print(f"Greedy max weight basis: {basis}")
print(f"Total weight: {sum(weights[e] for e in basis)}")

Non-Standard Analysis: Infinitesimals Made Rigorous

non-standard-analysis

Historical Context

Calculus was originally developed by Newton and Leibniz using intuitive notions of "infinitesimal" quantities. These concepts were criticized by Berkeley as "ghosts of departed quantities," leading to the epsilon-delta formalism of Weierstrass. In 1961, Abraham Robinson revolutionized analysis by using mathematical logic to construct a rigorous framework for infinitesimals.

Definitions

  • Hyperreals \({}^*\mathbb{R}\): An ordered field extension of \(\mathbb{R}\) containing infinite and infinitesimal elements.
  • Infinitesimal: \(\varepsilon \in {}^*\mathbb{R}\) is infinitesimal if \(|\varepsilon| < r\) for all positive real \(r\).
  • Standard Part (st): For finite \(x\), \(\text{st}(x)\) is the unique real number infinitely close to \(x\).
  • Transfer Principle: Every first-order statement true in \(\mathbb{R}\) is true in \({}^*\mathbb{R}\).

Theorem: The Standard Part Principle

Theorem: Every finite hyperreal \(x\) is infinitely close to a unique real number, called its standard part \(\text{st}(x)\).

Theorem (Characterization of Limits): For a function \(f: \mathbb{R} \to \mathbb{R}\) and \(L \in \mathbb{R}\):

\[\lim_{x \to a} f(x) = L \iff \text{for all } x \approx a \text{ with } x \neq a, \text{ we have } {}^*f(x) \approx L\]

Higher Category Theory: Beyond Composition

higher-category-theory

Historical Context

Category theory, introduced by Eilenberg and Mac Lane in 1945, provided a unified language for mathematics. Higher category theory emerged from the realization that many mathematical structures involve not just morphisms between objects, but "morphisms between morphisms" (2-morphisms), and so on. This need arose naturally in algebraic topology, mathematical physics, and algebraic geometry.

Definitions

  • Bicategory (Weak 2-Category): Like a category, but composition of 1-morphisms is associative only up to coherent 2-isomorphism.
  • 2-Morphism: A "morphism between morphisms."
  • ∞-Category: A higher category with morphisms of all dimensions.
  • Homotopy Hypothesis: ∞-groupoids are equivalent to topological spaces up to homotopy.

Theorem: The Homotopy Hypothesis

Theorem (Grothendieck's Homotopy Hypothesis): There is an equivalence of categories between:

  1. The category of homotopy n-types (spaces with trivial homotopy groups above dimension n)
  2. The category of n-groupoids (n-categories where all k-morphisms for k > 0 are invertible)

Algebraic Number Theory: Numbers as Symmetries

algebraic-number-theory

Historical Context

Algebraic number theory emerged from attempts to prove Fermat's Last Theorem. In the 19th century, Kummer discovered that unique factorization fails in certain number fields, leading him to invent ideal numbers (now called ideals). Dedekind later provided the modern foundation using ideals. Today, algebraic number theory is central to modern cryptography and the Langlands program.

Definitions

  • Number Field: A finite extension \(K/\mathbb{Q}\).
  • Ring of Integers \(\mathcal{O}_K\): The integral closure of \(\mathbb{Z}\) in \(K\).
  • Class Group \(\text{Cl}(K)\): The group of fractional ideals modulo principal ideals. Measures the failure of unique factorization.

Theorem: Unique Factorization of Ideals

Theorem (Dedekind, 1871): Let \(K\) be a number field with ring of integers \(\mathcal{O}_K\). Every nonzero proper ideal of \(\mathcal{O}_K\) factors uniquely (up to ordering) as a product of prime ideals.

Theorem (Finiteness of Class Number): The class group \(\text{Cl}(K)\) is finite.

📜 Math History

The Birth of Abstract Algebra: From Equations to Structures

The 19th century witnessed a profound transformation in mathematics: the shift from studying specific objects and equations to studying abstract structures and their relationships. This revolution, which we now call abstract algebra, fundamentally changed how mathematicians think about their subject.

The story begins with the search for solutions to polynomial equations. Mathematicians had known the quadratic formula since antiquity, and Italian mathematicians of the Renaissance discovered formulas for cubic and quartic equations. But the quintic equation resisted all attempts. In 1799, Ruffini claimed that the general quintic could not be solved by radicals, but his proof had gaps. It was Niels Henrik Abel who, in 1824, provided the first complete proof of the insolubility of the quintic.

Évariste Galois, tragically killed in a duel at age 20 in 1832, transformed Abel's negative result into a beautiful positive theory. Galois saw that the solvability of an equation was determined by the structure of a group—now called its Galois group—associated with the equation's roots. This was revolutionary: the solvability of an equation, a property of numbers, was determined by the abstract structure of a group.

Galois' ideas were nearly lost; his memoir was rejected by the Paris Academy, and he wrote his mathematical testament the night before his fatal duel. It was only through the efforts of Liouville that Galois' work was published in 1846, fourteen years after his death.

Meanwhile, other strands of algebra were developing. In England, Boole was algebraizing logic. In Germany, Kummer and Dedekind were developing ideal theory to rescue unique factorization in number fields. The concept of a field emerged from the work of Dedekind, Kronecker, and Weber.

The modern axiomatic approach crystallized in the early 20th century. Weber's 1895 textbook presented groups, fields, and rings systematically. Emmy Noether, working in Göttingen in the 1920s, became the driving force behind abstract algebra. Her famous dictum "es steht alles schon bei Dedekind" (it's all already in Dedekind) acknowledged her debt to her predecessor while her work went far beyond. Noether's abstract approach—studying rings and ideals in full generality rather than just number fields—transformed algebra.

Van der Waerden's 1930 "Moderne Algebra," based on Noether's lectures and Emil Artin's notes, became the definitive text. It presented algebra as the study of algebraic structures defined by axioms, with theorems following from these axioms by pure logic. This structural approach, which we take for granted today, was revolutionary at the time.

The development of abstract algebra illustrates a profound shift in mathematical thinking: from the particular to the general, from computation to structure, from objects to the relationships between them. This shift would influence all of mathematics in the 20th century, from topology to algebraic geometry to mathematical logic.

🎯 Problem Corner

Putnam 2024 B6: A Problem in Complex Analysis

Problem: Let \(f\) be a function that is analytic in the unit disk \(\{z \in \mathbb{C} : |z| < 1\}\) and continuous on its closure. Suppose that \(|f(z)| = 1\) whenever \(|z| = 1\). Prove that \(f\) is a finite Blaschke product, i.e., there exist complex numbers \(a_1, a_2, \ldots, a_n\) with \(|a_j| < 1\) and a real number \(\theta\) such that:

\[f(z) = e^{i\theta} \prod_{j=1}^{n} \frac{z - a_j}{1 - \overline{a_j}z}\]

Hint

Consider the zeros of \(f\) inside the unit disk. Use the maximum modulus principle and the fact that \(|f(z)| = 1\) on the boundary to show there are only finitely many zeros. Then construct a Blaschke product with the same zeros and show that the ratio is constant.

Solution

Step 1: First, we show that \(f\) has only finitely many zeros in the unit disk. Suppose \(f\) has infinitely many zeros. By the Bolzano-Weierstrass theorem, they would have an accumulation point in the closed unit disk. If the accumulation point is inside the disk, then \(f \equiv 0\) by the identity theorem, contradicting \(|f(z)| = 1\) on the boundary. If the accumulation point is on the boundary, continuity and the condition \(|f(z)| = 1\) on the boundary give a contradiction.

Step 2: Let \(a_1, \ldots, a_n\) be the zeros of \(f\) (counted with multiplicity). Define:

\[B(z) = \prod_{j=1}^{n} \frac{z - a_j}{1 - \overline{a_j}z}\]

This is a finite Blaschke product. Note that \(|B(z)| = 1\) for \(|z| = 1\) since each factor has modulus 1 on the unit circle.

Step 3: Consider \(g(z) = f(z)/B(z)\). This function is analytic in the unit disk (the zeros of \(B\) cancel those of \(f\)) and continuous on the closure. Moreover, \(|g(z)| = 1\) for \(|z| = 1\).

Step 4: By the maximum modulus principle, \(|g(z)| \leq 1\) for \(|z| \leq 1\). Applying the same argument to \(1/g\) (which is also analytic and has modulus 1 on the boundary), we get \(|g(z)| \geq 1\). Therefore \(|g(z)| = 1\) for all \(|z| \leq 1\).

Step 5: A nonvanishing analytic function with constant modulus must be constant (by the open mapping theorem, or by Cauchy-Riemann). Thus \(g(z) = e^{i\theta}\) for some real \(\theta\), giving:

\[f(z) = e^{i\theta} B(z) = e^{i\theta} \prod_{j=1}^{n} \frac{z - a_j}{1 - \overline{a_j}z}\]

This completes the proof. ∎

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate patterns, self-similar structures, and miniature copies of the whole set. Despite this complexity, the set is connected (proved by Douady and Hubbard in the 1980s).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until escape."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid of complex numbers
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
M = np.vectorize(mandelbrot)(C, max_iter=80)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(M, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.show()

# Zoom into a interesting region
xmin, xmax = -0.75, -0.74
ymin, ymax = 0.1, 0.11
x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y
M_zoom = np.vectorize(mandelbrot)(C, max_iter=200)

plt.figure(figsize=(10, 10))
plt.imshow(M_zoom, extent=[xmin, xmax, ymin, ymax], 
           cmap='plasma', origin='lower', interpolation='bilinear')
plt.title('Mandelbrot Set Zoom')
