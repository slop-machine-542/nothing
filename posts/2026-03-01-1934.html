1. Algebraic Combinatorics: The Robinson-Schensted-Knuth Correspondence

The RSK correspondence is a profound bijection between matrices with non-negative integer entries and pairs of semistandard Young tableaux of the same shape. This connection bridges combinatorics with representation theory.

Motivation: Understanding the representation theory of the symmetric group requires understanding its connection to combinatorics. The RSK correspondence provides an explicit combinatorial construction of irreducible representations.

Definitions:

  • A Young diagram of shape \( \lambda = (\lambda_1, \lambda_2, \ldots, \lambda_k) \) with \( \lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_k \geq 0 \) is a collection of boxes arranged in left-justified rows.
  • A semistandard Young tableau (SSYT) of shape \( \lambda \) is a filling of the Young diagram with positive integers that are weakly increasing along rows and strictly increasing down columns.
  • The insertion algorithm (row insertion) places a new element into the first row, bumping the smallest element larger than it to the next row, continuing recursively.

Theorem (RSK Correspondence): There is a bijection between \( n \times n \) matrices \( A = (a_{ij}) \) with non-negative integer entries summing to \( N \), and pairs \( (P, Q) \) of semistandard Young tableaux of the same shape with \( N \) boxes, where \( P \) has entries from \( \{1, \ldots, n\} \) and \( Q \) has entries from \( \{1, \ldots, n\} \).

Proof Sketch: Given matrix \( A \), create a two-line array with \( a_{ij} \) copies of \( \binom{j}{i} \). Scan left to right, inserting the top elements using the row insertion algorithm to build \( P \), while recording where new boxes appear in \( Q \). The inverse algorithm reconstructs \( A \) from the pair \( (P, Q) \).

Notation Guide:

  • \( \lambda \vdash n \): partition of \( n \)
  • \( \text{SSYT}(\lambda) \): set of semistandard Young tableaux of shape \( \lambda \)
  • \( P \leftarrow x \): insertion of element \( x \) into tableau \( P \)
# RSK Correspondence Implementation
def row_insert(P, x):
    """Insert x into tableau P using row insertion."""
    if not P:
        return [[x]], (0, 0)
    
    row = 0
    while row < len(P):
        # Find the smallest element > x in this row
        inserted = False
        for j in range(len(P[row])):
            if P[row][j] > x:
                # Bump this element
                bumped = P[row][j]
                P[row][j] = x
                x = bumped
                row += 1
                inserted = True
                break
        if not inserted:
            # x goes at the end of this row
            P[row].append(x)
            return P, (row, len(P[row]) - 1)
    
    # Need a new row
    P.append([x])
    return P, (len(P) - 1, 0)

def rsk(matrix):
    """
    Compute RSK correspondence for a matrix.
    Returns (P, Q) tableaux.
    """
    n = len(matrix)
    P = []  # Insertion tableau
    Q = []  # Recording tableau
    
    # Create two-line array
    entries = []
    for i in range(n):
        for j in range(n):
            for _ in range(matrix[i][j]):
                entries.append((i + 1, j + 1))  # (row, value)
    
    # Sort by first element, then second
    entries.sort()
    
    for idx, (row, val) in enumerate(entries):
        P, pos = row_insert(P, val)
        # Record in Q
        r, c = pos
        while len(Q) <= r:
            Q.append([])
        while len(Q[r]) <= c:
            Q[r].append(0)
        Q[r][c] = idx + 1
    
    return P, Q

print("Recording tableau Q:", Q)

2. Noncommutative Algebra: The Jacobson Density Theorem

The Jacobson Density Theorem is a fundamental result in the theory of noncommutative rings, generalizing the Wedderburn-Artin theorem and providing deep insight into the structure of primitive rings.

Motivation: Understanding simple modules over noncommutative rings requires understanding the relationship between the ring and its endomorphism ring. The density theorem shows that primitive rings act "densely" on their simple modules.

Definitions:

  • A ring \( R \) is primitive if it has a faithful simple left module.
  • For a division ring \( D \), \( \text{End}_D(V) \) denotes the ring of \( D \)-linear endomorphisms of a right \( D \)-vector space \( V \).
  • A subring \( R \subseteq \text{End}_D(V) \) is dense if for every finite-dimensional subspace \( W \subseteq V \) and every \( D \)-linear map \( f: W \to V \), there exists \( r \in R \) such that \( r|_W = f \).

Theorem (Jacobson Density Theorem): Let \( R \) be a primitive ring with faithful simple left module \( M \). Let \( D = \text{End}_R(M) \) (a division ring by Schur's lemma). Then \( M \) is a right \( D \)-vector space, and the natural map \( R \to \text{End}_D(M) \) has dense image.

Proof Sketch: Let \( W \subseteq M \) be finite-dimensional over \( D \) with basis \( \{w_1, \ldots, w_n\} \). By induction on \( n \), we show that for any \( v_1, \ldots, v_n \in M \), there exists \( r \in R \) with \( rw_i = v_i \). The key step uses the primitivity of \( R \) and the simplicity of \( M \) to construct elements with prescribed actions.

Notation Guide:

  • \( \text{End}_R(M) \): endomorphism ring of \( R \)-module \( M \)
  • \( D\text{-dim}(V) \): dimension of \( V \) as a right \( D \)-vector space
  • \( J(R) \): Jacobson radical of \( R \)

3. Algebraic Cycles: The Hodge Conjecture

The Hodge Conjecture is one of the seven Millennium Prize Problems, connecting algebraic geometry with complex differential geometry through the study of algebraic cycles.

Motivation: On a complex projective variety, which cohomology classes come from algebraic subvarieties? The Hodge conjecture provides a precise criterion in terms of Hodge theory.

Definitions:

  • A Hodge structure of weight \( n \) is a finite-dimensional \( \mathbb{Q} \)-vector space \( V \) with a decomposition \( V \otimes \mathbb{C} = \bigoplus_{p+q=n} V^{p,q} \) where \( \overline{V^{p,q}} = V^{q,p} \).
  • The Hodge filtration is \( F^p = \bigoplus_{p' \geq p} V^{p', n-p'} \).
  • A class \( [\alpha] \in H^{2k}(X, \mathbb{Q}) \) is a Hodge class if its image in \( H^{2k}(X, \mathbb{C}) \) lies in \( H^{k,k}(X) \).
  • An algebraic cycle is a formal linear combination of irreducible subvarieties.

Theorem (Hodge Conjecture - Statement): Let \( X \) be a smooth complex projective variety. Every Hodge class in \( H^{2k}(X, \mathbb{Q}) \cap H^{k,k}(X) \) is a rational linear combination of classes of algebraic cycles of codimension \( k \).

Known Cases:

  • Lefschetz (1,1)-Theorem: The Hodge conjecture holds for \( k = 1 \). This is equivalent to the statement that every line bundle with vanishing first Chern class is algebraically equivalent to zero.
  • Abelian Varieties: The Hodge conjecture is known for certain classes of abelian varieties, particularly those with complex multiplication.
  • Flag Varieties: True for projective spaces and Grassmannians (where all cohomology is algebraic).

Notation Guide:

  • \( H^{p,q}(X) \): Dolbeault cohomology, the space of harmonic forms of type \( (p,q) \)
  • \( \text{CH}^k(X) \): Chow group of codimension-\( k \) cycles modulo rational equivalence
  • \( cl: \text{CH}^k(X) \otimes \mathbb{Q} \to H^{2k}(X, \mathbb{Q}) \): cycle class map
# Hodge theory computations on complex tori

    Compute Hodge diamond of an n-dimensional complex torus.
    For a torus C^n/Lambda, H^{p,q} = C^{(n choose p)(n choose q)}

    from math import comb

1. Monte Carlo Methods: Markov Chain Monte Carlo

MCMC methods revolutionized Bayesian computation by allowing sampling from complex, high-dimensional distributions that are intractable with direct methods.

Real-World Motivation: Bayesian inference often requires computing posterior distributions of the form \( p(\theta | x) \propto p(x | \theta) p(\theta) \). The normalizing constant involves an intractable integral. MCMC provides a way to sample from this distribution without knowing the normalizing constant.

Definitions:

  • A Markov chain is a stochastic process where the future state depends only on the present: \( P(X_{n+1} | X_n, X_{n-1}, \ldots) = P(X_{n+1} | X_n) \).
  • A chain is irreducible if any state can be reached from any other state.
  • A chain is aperiodic if the return times to any state have gcd 1.
  • A distribution \( \pi \) is stationary if \( \pi P = \pi \) where \( P \) is the transition matrix.

Theorem (Metropolis-Hastings): Let \( \pi(x) \) be a target density (known up to normalization). Let \( q(y|x) \) be a proposal distribution. Define the acceptance probability: \[ \alpha(x, y) = \min\left(1, \frac{\pi(y) q(x|y)}{\pi(x) q(y|x)}\right) \] The Markov chain with transitions: propose \( y \sim q(\cdot|x) \), accept with probability \( \alpha(x,y) \), otherwise stay at \( x \), has stationary distribution \( \pi \).

Proof Sketch: Verify detailed balance: \( \pi(x) P(x \to y) = \pi(y) P(y \to x) \). For \( x \neq y \): \[ \pi(x) q(y|x) \alpha(x,y) = \pi(x) q(y|x) \min\left(1, \frac{\pi(y)q(x|y)}{\pi(x)q(y|x)}\right) = \min(\pi(x)q(y|x), \pi(y)q(x|y)) \] which is symmetric in \( x \) and \( y \).

Notation Guide:

  • \( \pi(x) \): target (posterior) density
  • \( q(y|x) \): proposal density
  • \( \alpha(x,y) \): acceptance probability
  • \( \tau_{\text{mix}} \): mixing time of the chain
# Metropolis-Hastings MCMC implementation
import numpy as np
import matplotlib.pyplot as plt

def metropolis_hastings(target_log_prob, proposal_sampler, proposal_log_prob, 
                        x0, n_samples, burn_in=1000):
    """
    Metropolis-Hastings MCMC sampler.
    
    Parameters:
    -----------
    target_log_prob : callable
        Log of target density (up to constant)
    proposal_sampler : callable
        Function that samples from q(·|x)
    proposal_log_prob : callable
        Log of proposal density q(y|x)
    x0 : array
        Initial state
    n_samples : int
        Number of samples to generate
    burn_in : int
        Number of initial samples to discard
    """
    samples = []
    x = x0
    n_accepted = 0
    
    for i in range(n_samples + burn_in):
        # Propose new state
        y = proposal_sampler(x)
        
        # Compute acceptance probability
        log_alpha = (target_log_prob(y) + proposal_log_prob(x, y) - 
                     target_log_prob(x) - proposal_log_prob(y, x))
        alpha = min(1, np.exp(log_alpha))
        
        # Accept or reject
        if np.random.random() < alpha:
            x = y
            n_accepted += 1
        
        if i >= burn_in:
            samples.append(x.copy())
    
    acceptance_rate = n_accepted / (n_samples + burn_in)
    return np.array(samples), acceptance_rate

2. Time Series Analysis: ARIMA Models

ARIMA (AutoRegressive Integrated Moving Average) models provide a powerful framework for understanding and forecasting time series data, from stock prices to weather patterns.

Real-World Motivation: Financial markets, climate data, and economic indicators all exhibit temporal dependencies. ARIMA captures these through autoregressive and moving average components, while differencing handles non-stationarity.

Definitions:

  • A process \( \{X_t\} \) is weakly stationary if \( E[X_t] = \mu \) (constant), \( \text{Var}(X_t) = \sigma^2 \) (constant), and \( \text{Cov}(X_t, X_{t+h}) = \gamma(h) \) depends only on lag \( h \).
  • The autocorrelation function (ACF) is \( \rho(h) = \gamma(h)/\gamma(0) \).
  • The partial autocorrelation function (PACF) at lag \( h \) is the correlation between \( X_t \) and \( X_{t+h} \) after removing the effect of \( X_{t+1}, \ldots, X_{t+h-1} \).

ARIMA(p,d,q) Model: After \( d \) differences \( \nabla^d X_t \), the process follows: \[ \phi(B) \nabla^d X_t = \theta(B) \varepsilon_t \] where \( \phi(B) = 1 - \phi_1 B - \cdots - \phi_p B^p \) is the AR polynomial, \( \theta(B) = 1 + \theta_1 B + \cdots + \theta_q B^q \) is the MA polynomial, and \( B \) is the backshift operator: \( B X_t = X_{t-1} \).

Theorem (Stationarity of AR(p)): The AR(p) process \( \phi(B)X_t = \varepsilon_t \) is stationary if and only if all roots of \( \phi(z) = 0 \) lie outside the unit circle (\( |z| > 1 \)).

Proof Sketch: Write \( X_t = \phi(B)^{-1} \varepsilon_t \). For this to converge (in mean square), the power series expansion of \( 1/\phi(z) \) must converge for \( |z| \leq 1 \), which requires roots outside the unit circle.

Notation Guide:

  • \( B \): backshift operator
  • \( \nabla = 1 - B \): differencing operator
  • \( \phi(B) \): autoregressive polynomial
  • \( \theta(B) \): moving average polynomial
  • \( \varepsilon_t \sim WN(0, \sigma^2) \): white noise
# ARIMA model simulation and estimation
import numpy as np
import matplotlib.pyplot as plt

def simulate_arma(phi, theta, sigma, n, burn_in=1000):
    """
    Simulate ARMA(p,q) process.
    
    Parameters:
    -----------
    phi : array
        AR coefficients (phi[0] corresponds to phi_1)
    theta : array
        MA coefficients (theta[0] corresponds to theta_1)
    sigma : float
        Standard deviation of white noise
    n : int
        Number of observations to generate
    """
    p = len(phi)
    q = len(theta)
    
    # Total samples including burn-in
    N = n + burn_in
    
    # Generate white noise
    eps = np.random.normal(0, sigma, N)
    
    # Initialize
    X = np.zeros(N)
    
    # Simulate
    for t in range(max(p, q), N):
        # AR part
        ar_part = sum(phi[i] * X[t - i - 1] for i in range(p)) if p > 0 else 0
        
        # MA part
        ma_part = sum(theta[i] * eps[t - i - 1] for i in range(q)) if q > 0 else 0
        
        X[t] = ar_part + ma_part + eps[t]
    
    return X[burn_in:]

def difference_series(X, d=1):
    """Apply d-th order differencing."""
    result = X.copy()
    for _ in range(d):
        result = np.diff(result)
    return result

def acf(X, max_lag=20):
    """Compute sample autocorrelation function."""
    n = len(X)
    X_centered = X - np.mean(X)
    gamma0 = np.sum(X_centered**2) / n
    
    acf_vals = []
    for h in range(max_lag + 1):
        if h == 0:
            acf_vals.append(1.0)
        else:
            gamma_h = np.sum(X_centered[:-h] * X_centered[h:]) / n
            acf_vals.append(gamma_h / gamma0)
    
    return np.array(acf_vals)

def pacf(X, max_lag=20):
    """Compute sample partial autocorrelation using Yule-Walker."""
    acf_vals = acf(X, max_lag)
    pacf_vals = [1.0]
    
    for k in range(1, max_lag + 1):
        # Solve Yule-Walker equations
        R = np.array([[acf_vals[abs(i-j)] for j in range(k)] for i in range(k)])
        r = acf_vals[1:k+1]
        phi = np.linalg.solve(R, r)
        pacf_vals.append(phi[-1])
    
    return np.array(pacf_vals)

3. Computational Algebra: Gröbner Bases

Gröbner bases provide a computational foundation for polynomial ideal theory, enabling algorithmic solutions to problems in algebraic geometry, robotics, and automated theorem proving.

Real-World Motivation: Systems of polynomial equations arise in robotics (inverse kinematics), computer vision (structure from motion), and cryptography (algebraic attacks). Gröbner bases transform these systems into triangular form, making them solvable.

Definitions:

  • A monomial order is a total order on monomials that respects multiplication: if \( x^\alpha > x^\beta \), then \( x^\gamma x^\alpha > x^\gamma x^\beta \).
  • The leading term \( LT(f) \) of a polynomial is its largest monomial with respect to the chosen order.
  • A Gröbner basis for an ideal \( I \) is a set \( G = \{g_1, \ldots, g_m\} \subseteq I \) such that \( \langle LT(I) \rangle = \langle LT(g_1), \ldots, LT(g_m) \rangle \).
  • The S-polynomial of \( f \) and \( g \) is: \[ S(f, g) = \frac{x^\gamma}{LT(f)} f - \frac{x^\gamma}{LT(g)} g \] where \( x^\gamma = \text{lcm}(LM(f), LM(g)) \).

Theorem (Buchberger's Criterion): A set \( G = \{g_1, \ldots, g_m\} \) is a Gröbner basis for \( I = \langle G \rangle \) if and only if for all \( i \neq j \), the remainder of \( S(g_i, g_j) \) on division by \( G \) is zero.

Proof Sketch: (\(\Rightarrow\)) If \( G \) is a Gröbner basis, then \( S(g_i, g_j) \in I \), so its leading term is divisible by some \( LT(g_k) \). The division algorithm reduces it to zero.

(\(\Leftarrow\)) If all S-polynomials reduce to zero, then any \( f \in I \) can be written as \( f = \sum h_i g_i \). Among all such representations, choose one minimizing \( \max_i LM(h_i g_i) \). If \( LM(f) \) is not divisible by any \( LT(g_i) \), the S-polynomial condition ensures we can find a representation with smaller maximum, contradiction.

Notation Guide:

  • \( k[x_1, \ldots, x_n] \): polynomial ring over field \( k \)
  • \( LT(f) \): leading term of \( f \)
  • \( LM(f) \): leading monomial of \( f \)
  • \( \langle G \rangle \): ideal generated by set \( G \)

from collections import defaultdict

class Monomial:
    """Represents a monomial x^exp where exp is a tuple."""
    def __init__(self, exp):
        self.exp = tuple(exp)
        self.n_vars = len(exp)
    
    def __mul__(self, other):
        return Monomial([a + b for a, b in zip(self.exp, other.exp)])
    
    def divides(self, other):
        """Check if self divides other."""
        return all(a <= b for a, b in zip(self.exp, other.exp))
    
    def __lt__(self, other):
        """Lexicographic order."""
        return self.exp > other.exp  # Reverse for descending
    
    def __eq__(self, other):
        return self.exp == other.exp
    
    def __hash__(self):
        return hash(self.exp)
    
    def __repr__(self):
        terms = []
        for i, e in enumerate(self.exp):
            if e == 1:
                terms.append(f"x{i}")
            elif e > 1:
                terms.append(f"x{i}^{e}")
        return "*".join(terms) if terms else "1"
    
    def lcm(self, other):
        """Least common multiple."""
        return Monomial([max(a, b) for a, b in zip(self.exp, other.exp)])

class Polynomial:
    """Sparse polynomial representation."""
    def __init__(self, terms=None):
        # terms: dict of Monomial -> coefficient
        self.terms = terms or {}
    
    def lt(self):
        """Leading term (monomial, coeff) w.r.t. lex order."""
        if not self.terms:
            return None, 0
        max_mono = max(self.terms.keys())
        return max_mono, self.terms[max_mono]
    
    def lm(self):
        """Leading monomial."""
        return self.lt()[0]
    
    def lc(self):
        """Leading coefficient."""
        return self.lt()[1]
    
    def __add__(self, other):
        result = Polynomial(self.terms.copy())
        for mono, coeff in other.terms.items():
            result.terms[mono] = result.terms.get(mono, 0) + coeff
            if result.terms[mono] == 0:
                del result.terms[mono]
        return result
    
    def __sub__(self, other):
        return self + (-1) * other
    
    def __mul__(self, other):
        if isinstance(other, (int, float)):
            return Polynomial({m: c * other for m, c in self.terms.items()})
        result = Polynomial()
        for m1, c1 in self.terms.items():
            for m2, c2 in other.terms.items():
                m = m1 * m2
                result.terms[m] = result.terms.get(m, 0) + c1 * c2
        return result
    
    def __rmul__(self, other):
        return self * other
    
    def __repr__(self):
        if not self.terms:
            return "0"
        return " + ".join(f"{c}*{m}" if m.exp != (0,) * m.n_vars else str(c) 
                         for m, c in sorted(self.terms.items(), reverse=True))

def s_polynomial(f, g):
    """Compute S-polynomial of f and g."""
    lm_f, lc_f = f.lm(), f.lc()
    lm_g, lc_g = g.lm(), g.lc()
    
    gamma = lm_f.lcm(lm_g)
    
    term1 = Polynomial({gamma: 1}) * f * (1 / lc_f)
    term2 = Polynomial({gamma: 1}) * g * (1 / lc_g)
    
    # Adjust for actual LCM computation
    factor_f = Polynomial({Monomial([gamma.exp[i] - lm_f.exp[i] 
                                     for i in range(len(gamma.exp))]): 1})
    factor_g = Polynomial({Monomial([gamma.exp[i] - lm_g.exp[i] 
                                     for i in range(len(gamma.exp))]): 1})
    
    return factor_f * f * (1/lc_f) - factor_g * g * (1/lc_g)

def reduce(f, G):
    """Reduce f modulo G (simplified)."""
    result = Polynomial(f.terms.copy())
    
    changed = True
    while changed:
        changed = False
        lt_result = result.lm()
        
        if lt_result is None:
            break
        
        for g in G:
            lt_g = g.lm()
            if lt_g and lt_g.divides(lt_result):
                # Reduce
                factor = Polynomial({Monomial([lt_result.exp[i] - lt_g.exp[i] 
                                               for i in range(len(lt_result.exp))]): 
                                     result.lc() / g.lc()})
                result = result - factor * g
                changed = True
                break
    
    return result

def buchberger(F):
    """Buchberger's algorithm (simplified)."""
    G = list(F)
    pairs = [(i, j) for i in range(len(G)) for j in range(i + 1, len(G))]
    
    while pairs:
        i, j = pairs.pop(0)
        s = s_polynomial(G[i], G[j])
        r = reduce(s, G)
        
        if r.terms:  # Non-zero remainder
            for k in range(len(G)):
                pairs.append((k, len(G)))
            G.append(r)
    
    return G

1. The Birch and Swinnerton-Dyer Conjecture

One of the seven Millennium Prize Problems, the BSD conjecture connects the arithmetic of elliptic curves with their analytic properties.

Historical Context: Bryan Birch and Peter Swinnerton-Dyer formulated this conjecture in the 1960s based on extensive computer calculations. They observed a remarkable pattern: the rank of the Mordell-Weil group (the number of independent rational points) seemed to match the order of vanishing of the L-function at s=1.

Definitions:

  • An elliptic curve over \( \mathbb{Q} \) is a smooth projective curve of genus 1 with a rational point, given by a Weierstrass equation \( y^2 = x^3 + ax + b \) with \( 4a^3 + 27b^2 \neq 0 \).
  • The Mordell-Weil group \( E(\mathbb{Q}) \) is the group of rational points on \( E \), which is finitely generated: \( E(\mathbb{Q}) \cong E(\mathbb{Q})_{\text{tors}} \times \mathbb{Z}^r \).
  • The L-function of \( E \) is defined by an Euler product: \[ L(E, s) = \prod_{p \nmid N} \frac{1}{1 - a_p p^{-s} + p^{1-2s}} \prod_{p \mid N} \frac{1}{1 - a_p p^{-s}} \] where \( N \) is the conductor and \( a_p = p + 1 - \#E(\mathbb{F}_p) \).
  • The Tate-Shafarevich group \( Ш(E/\mathbb{Q}) \) measures the failure of the Hasse principle.

Conjecture (BSD): Let \( E \) be an elliptic curve over \( \mathbb{Q} \).

  1. The L-function \( L(E, s) \) has an analytic continuation to \( s = 1 \).
  2. The order of vanishing of \( L(E, s) \) at \( s = 1 \) equals the rank \( r \) of \( E(\mathbb{Q}) \).
  3. The leading coefficient is: \[ L^{(r)}(E, 1)/r! = \frac{\Omega_E \cdot \text{Reg}_E \cdot \#Ш(E/\mathbb{Q}) \cdot \prod_p c_p}{\#E(\mathbb{Q})_{\text{tors}}^2} \]

Known Results:

  • Coates-Wiles (1977): If \( E \) has complex multiplication and \( L(E, 1) \neq 0 \), then \( r = 0 \).
  • Gross-Zagier (1986), Kolyvagin (1988): If \( L(E, s) \) has order of vanishing \( \leq 1 \) at \( s = 1 \), then the conjecture holds.

Notation Guide:

  • \( r \): analytic rank (order of vanishing of L-function)
  • \( \Omega_E \): real period of \( E \)
  • \( \text{Reg}_E \): regulator of \( E \) (height pairing matrix determinant)
  • \( c_p \): Tamagawa numbers at bad primes

def elliptic_curve_points_mod_p(a, b, p):
    """
    Count points on y^2 = x^3 + ax + b over F_p.
    Includes point at infinity.
    """
    count = 1  # Point at infinity
    for x in range(p):
        rhs = (x**3 + a*x + b) % p

        if rhs == 0:

    return count

2. Hilbert's Tenth Problem

The question of algorithmic solvability of Diophantine equations, resolved by Matiyasevich building on work of Davis, Putnam, and Robinson.

Historical Context: At the 1900 International Congress of Mathematicians, David Hilbert posed 23 problems that would shape 20th-century mathematics. The tenth asked for an algorithm to determine whether a given Diophantine equation has integer solutions. Seventy years later, Yuri Matiyasevich proved that no such algorithm exists.

Definitions:

  • A Diophantine equation is a polynomial equation \( P(x_1, \ldots, x_n) = 0 \) where integer solutions are sought.
  • A set \( S \subseteq \mathbb{N} \) is Diophantine if there exists a polynomial \( P \) such that \( a \in S \iff \exists x_1, \ldots, x_n : P(a, x_1, \ldots, x_n) = 0 \).
  • A relation \( R \subseteq \mathbb{N}^k \) is recursively enumerable (r.e.) if it can be listed by a Turing machine.

Theorem (MRDP Theorem): A set \( S \subseteq \mathbb{N} \) is Diophantine if and only if it is recursively enumerable.

Corollary (Undecidability of Hilbert's Tenth): There is no algorithm that, given a Diophantine equation, decides whether it has integer solutions.

Proof Sketch: The proof uses the existence of a universal recursively enumerable set. By MRDP, this universal set is Diophantine, meaning there exists a polynomial \( U \) such that: \[ (e, n) \in U \iff \exists x_1, \ldots, x_m : U(e, n, x_1, \ldots, x_m) = 0 \] If Hilbert's tenth were decidable, we could decide membership in any r.e. set, contradicting the undecidability of the halting problem.

Key Ingredient (Matiyasevich): The Fibonacci sequence is Diophantine. Specifically, there exists a polynomial \( P \) such that: \[ y = F_{2x} \iff \exists z_1, \ldots, z_m : P(x, y, z_1, \ldots, z_m) = 0 \] where \( F_n \) is the nth Fibonacci number. This exponential growth property allows encoding arbitrary computation.

Notation Guide:

  • \( \exists^{\infty} \): "there exist infinitely many"
  • MRDP: Matiyasevich-Robinson-Davis-Putnam
  • \( D_n \): the set of Diophantine equations with \( n \) unknowns

    if n < 0:

def pell_solutions(D, max_x=1000):
    """
    Find solutions to Pell's equation x^2 - D*y^2 = 1.
    Returns list of (x, y) solutions.
    """
    solutions = []
    for x in range(2, max_x):
        y_squared = (x*x - 1) / D
        if y_squared > 0 and is_perfect_square(int(y_squared)):
            y = int(math.isqrt(int(y_squared)))
            if x*x - D*y*y == 1:
                solutions.append((x, y))
    return solutions

def is_fibonacci(n):

    Check if n is a Fibonacci number.
    n is Fibonacci iff 5n^2 + 4 or 5n^2 - 4 is a perfect square.
    """
    if n < 0:
        return False
    return is_perfect_square(5*n*n + 4) or is_perfect_square(5*n*n - 4)

3. The Poincaré Conjecture and Perelman's Proof

The only solved Millennium Prize Problem, resolved by Grigori Perelman using Ricci flow, a technique that deforms the geometry of a manifold.

Historical Context: Henri Poincaré posed the foundational question in topology: what characterizes the 3-sphere? The conjecture stood for nearly a century until Perelman's breakthrough papers in 2002-2003, building on Hamilton's Ricci flow program. Perelman famously declined both the Fields Medal and the Millennium Prize.

Definitions:

  • A 3-manifold is a topological space locally homeomorphic to \( \mathbb{R}^3 \).
  • A manifold is simply connected if every loop can be continuously contracted to a point (trivial fundamental group).
  • The 3-sphere \( S^3 \) is the set of points in \( \mathbb{R}^4 \) at distance 1 from the origin.
  • Ricci flow is the geometric evolution equation: \[ \frac{\partial g}{\partial t} = -2 \text{Ric}(g) \] where \( g \) is the Riemannian metric and \( \text{Ric} \) is the Ricci curvature tensor.

Theorem (Poincaré Conjecture, proved by Perelman): Every simply connected, closed 3-manifold is homeomorphic to \( S^3 \).

Key Elements of Perelman's Proof:

  1. Ricci Flow: Start with any Riemannian metric on the 3-manifold and evolve it. In 2D, this always converges to constant curvature (Hamilton, Chow). In 3D, singularities can form.
  2. Surgery: When singularities form (neck pinching), cut out the singular region and cap it with 3-balls, then continue the flow.
  3. Entropy Functional: Perelman introduced the \(\mathcal{W}\)-entropy: \[ \mathcal{W}(g, f, \tau) = \int_M \left[ \tau(R + |\nabla f|^2) + f - n \right] (4\pi\tau)^{-n/2} e^{-f} dV \] This is monotonic under Ricci flow and detects "cigar solitons" that would obstruct convergence.
  4. Reduced Volume: A monotone quantity that controls the geometry at all scales.

Theorem (Geometrization, also proved by Perelman): Every closed 3-manifold can be decomposed into pieces, each admitting one of eight geometric structures (Thurston's geometries).

Notation Guide:

  • \( \text{Ric}_{ij} \): Ricci curvature tensor
  • \( R \): scalar curvature
  • \( \pi_1(M) \): fundamental group of \( M \)
  • \( \mathcal{W} \): Perelman's entropy functional

4. The ABC Conjecture

A profound statement about the relationship between the additive and multiplicative structure of integers, with far-reaching implications in number theory.

Historical Context: Proposed by David Masser and Joseph Oesterlé in 1985, the ABC conjecture emerged from studies of elliptic curves and the Mason-Stothers theorem (the polynomial analogue). Despite its simple statement, it implies many famous theorems and conjectures, including Fermat's Last Theorem for sufficiently large exponents.

Definitions:

  • For a positive integer \( n \), the radical \( \text{rad}(n) \) is the product of distinct prime factors of \( n \).
  • An ABC triple is a triple of coprime positive integers \( (a, b, c) \) with \( a + b = c \).
  • The quality of an ABC triple is \( q(a, b, c) = \frac{\log c}{\log \text{rad}(abc)} \).

Conjecture (ABC): For every \( \varepsilon > 0 \), there are only finitely many ABC triples with \( q(a, b, c) > 1 + \varepsilon \).

Equivalent Formulation: For every \( \varepsilon > 0 \), there exists \( K(\varepsilon) \) such that for all coprime positive integers \( a, b, c \) with \( a + b = c \): \[ c < K(\varepsilon) \cdot \text{rad}(abc)^{1+\varepsilon} \]

Implications:

  • Fermat's Last Theorem: The ABC conjecture implies that \( x^n + y^n = z^n \) has only finitely many solutions for \( n \geq 4 \).
  • Wieferich Primes: There are infinitely many non-Wieferich primes.

def prime_factors(n):
    """Return set of distinct prime factors of n."""
    factors = set()
    d = 2

def radical(n):
    """Compute rad(n) = product of distinct prime factors."""
    factors = prime_factors(n)
    result = 1
    for p in factors:

    return result

def gcd(a, b):
    """Compute GCD using Euclidean algorithm."""
    while b:
        a, b = b, a % b

def abc_quality(a, b, c):
    """Compute quality q(a,b,c) = log(c) / log(rad(abc))."""
    if a + b != c:

    if gcd(a, b) != 1 or gcd(a, c) != 1 or gcd(b, c) != 1:
        return None

📜 Math History: The Development of Modern Logic

The 19th and early 20th centuries witnessed a transformation in the foundations of mathematics, driven by the need for rigor and the discovery of paradoxes in naive set theory. This period saw the birth of mathematical logic as a distinct discipline, with profound implications for philosophy, computer science, and mathematics itself.

George Boole (1815-1864) laid the groundwork with his algebraic approach to logic. In The Laws of Thought (1854), Boole showed that logical reasoning could be reduced to algebraic manipulation. His system, Boolean algebra, assigned numerical values to propositions and defined operations corresponding to AND, OR, and NOT. Though Boole's system had limitations—it didn't fully capture quantified statements—it demonstrated that logic could be treated mathematically.

Gottlob Frege (1848-1925) took the decisive step toward modern predicate logic. In his Begriffsschrift (1879), Frege introduced a formal system with quantifiers, variables, and a precise syntax for expressing mathematical propositions. His goal was ambitious: to show that arithmetic could be derived from purely logical principles (logicism). Frege's system was powerful enough to express complex mathematical statements, but it contained a fatal flaw.

In 1902, Bertrand Russell discovered a paradox in Frege's system. Consider the set of all sets that do not contain themselves. Does this set contain itself? Either answer leads to a contradiction. Russell's paradox, along with similar paradoxes discovered by Cantor and Burali-Forti, showed that naive set theory was inconsistent.

The crisis prompted several responses. Ernst Zermelo (1908) proposed an axiomatization of set theory (later refined by Fraenkel and Skolem into ZFC) that avoided the paradoxes by restricting comprehension. Bertrand Russell and Alfred North Whitehead developed type theory in their monumental Principia Mathematica (1910-1913), where sets are arranged in a hierarchy and a set can only contain elements of lower type.

David Hilbert championed a different approach: formalism. Rather than seeking a foundation in logic or intuition, Hilbert proposed treating mathematics as the manipulation of symbols according to formal rules. He hoped to prove the consistency of mathematics using only finitary methods—a program that would ensure the reliability of mathematical reasoning.

Hilbert's program was dealt a devastating blow by Kurt Gödel in 1931. Gödel's incompleteness theorems showed that any consistent formal system strong enough to encode arithmetic contains statements that cannot be proved or disproved within the system. Moreover, such a system cannot prove its own consistency. Gödel's theorems placed fundamental limits on what could be achieved with formal systems.

Despite—or perhaps because of—these limitations, mathematical logic flourished. Alonzo Church and Alan Turing independently defined computability in the 1930s, establishing the theoretical foundations of computer science. Alfred Tarski developed model theory, the study of the relationship between formal languages and their interpretations. Abraham Robinson introduced nonstandard analysis, legitimizing infinitesimals through model-theoretic techniques.

Today, mathematical logic spans diverse areas: proof theory studies the structure of formal proofs; model theory explores the connections between syntax and semantics; computability theory classifies problems by their computational difficulty; and set theory continues to investigate the foundations of infinity. The legacy of the foundational crisis is a deeper understanding of the nature of mathematical truth and the tools to explore it.

IMO 2023 Problem 2

Let \( \mathbb{R}^+ \) denote the set of positive real numbers. Find all functions \( f: \mathbb{R}^+ \to \mathbb{R}^+ \) such that for all \( x, y \in \mathbb{R}^+ \): \[ f(xy + f(x)) = xf(y) + 2 \]

💡 Hint

Try to show that \( f \) is injective. Then, find a way to express \( f(x) \) in terms of \( x \) by making clever substitutions. Consider what happens when you set \( y \) such that \( xy + f(x) \) takes a convenient form.

✅ Solution

Step 1: Injectivity

Suppose \( f(a) = f(b) \). Setting \( x = a \) and \( x = b \) with the same \( y \): \[ f(ay + f(a)) = af(y) + 2 \] \[ f(by + f(b)) = bf(y) + 2 \]

Since \( f(a) = f(b) \), if we can find \( y \) such that \( ay + f(a) = by + f(b) \), we get \( af(y) = bf(y) \). For \( y \) where \( f(y) \neq 0 \) (always true in \( \mathbb{R}^+ \)), we get \( a = b \).

Step 2: Finding the form

Set \( x = 1 \): \( f(y + f(1)) = f(y) + 2 \).

This suggests \( f \) grows linearly. Let's try \( f(x) = cx + d \).

Substituting: \[ c(xy + cx + d) + d = x(cy + d) + 2 \] \[ cxy + c^2x + cd + d = cxy + dx + 2 \]

Comparing: \( c^2 = d \) and \( cd + d = 2 \).

From \( c^2 = d \): \( c^3 + c^2 = 2 \), so \( c^3 + c^2 - 2 = 0 \).

Factoring: \( (c-1)(c^2 + 2c + 2) = 0 \). Since \( c > 0 \), we have \( c = 1 \), so \( d = 1 \).

Step 3: Verification

Check \( f(x) = x + 1 \): \[ f(xy + x + 1) = xy + x + 1 + 1 = xy + x + 2 \] \[ xf(y) + 2 = x(y + 1) + 2 = xy + x + 2 \] ✓

Answer: \( f(x) = x + 1 \) is the unique solution.

import numpy as np
import matplotlib.pyplot as plt
from scipy.special import zeta

def plot_zeta_critical_line(t_max=50, n_points=10000):
    """
    Plot zeta(1/2 + it) for t in [0, t_max].
    Zeros occur where the curve passes through origin.
    """
    t = np.linspace(0, t_max, n_points)
    s = 0.5 + 1j * t
    
    # Compute zeta (using analytic continuation)
    zeta_vals = np.array([zeta(complex(0.5, ti)) for ti in t])

    ax1 = axes[0, 0]
    ax1.plot(zeta_vals.real, zeta_vals.imag, linewidth=0.5, alpha=0.7)
    ax1.scatter([0], [0], color='red', s=50, zorder=5, label='Origin')
    ax1.set_xlabel('Re(ζ(1/2 + it))')
    ax1.set_ylabel('Im(ζ(1/2 + it))')
    ax1.set_title('Zeta Function on Critical Line (Parametric)')
    ax1.legend()
    ax1.grid(True, alpha=0.3)
    ax1.axis('equal')
    
    # Plot 2: Real part vs t
    ax2 = axes[0, 1]
    ax2.plot(t, zeta_vals.real, linewidth=0.7)
    ax2.axhline(y=0, color='r', linestyle='--', alpha=0.5)

    ax3.set_xlabel('t')
    ax3.set_ylabel('Im(ζ(1/2 + it))')
    ax3.set_title('Imaginary Part of ζ(1/2 + it)')
    ax3.grid(True, alpha=0.3)
