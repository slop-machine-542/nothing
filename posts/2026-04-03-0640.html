🔬 Pure Math Deep-Dives

Spectral Sequences

Motivation: Spectral sequences are powerful computational tools in algebraic topology that allow us to compute homology and cohomology groups via successive approximations.

Definitions:

A spectral sequence consists of: 1. A sequence of bigraded modules $E_r^{p,q}$ for $r \geq 2$ 2. Differentials $d_r: E_r^{p,q} \to E_r^{p+r, q-r+1}$ with $d_r^2 = 0$ 3. Isomorphisms $E_{r+1}^{p,q} \cong \ker(d_r)/\text{im}(d_r)$

Theorem (Convergence of Spectral Sequences):

For a first quadrant spectral sequence with $E_2^{p,q} \Rightarrow H^{p+q}(X)$, if $E_r^{p,q} = E_{r+1}^{p,q}$ for all $r \geq r_0$, then $E_\infty^{p,q}$ is the associated graded of a filtration on $H^{p+q}(X)$.

Proof Sketch:

The proof proceeds by analyzing the degree constraints on the differentials and showing that beyond a certain page, all differentials vanish for dimensional reasons.

Higher Homotopy Groups

Motivation: While the fundamental group captures one-dimensional holes (loops), higher homotopy groups extend this to n-dimensional spheres. These groups provide finer invariants for distinguishing topological spaces.

Definitions:

For a pointed space $(X, x_0)$, the n-th homotopy group is: $\pi_n(X, x_0) = [(S^n, s_0), (X, x_0)]$ The group operation is defined via concatenation of maps for $n \geq 2$. For $n \geq 2$, $\pi_n(X, x_0)$ is abelian.

Theorem (Homotopy Exact Sequence of a Pair):

For a pair $(X, A)$ with basepoint $x_0 \in A$, there is a long exact sequence: $\cdots \to \pi_{n+1}(X, A) \xrightarrow{\partial} \pi_n(A) \xrightarrow{i_*} \pi_n(X) \xrightarrow{j_*} \pi_n(X, A) \xrightarrow{\partial} \pi_{n-1}(A) \to \cdots$

Proof Sketch:

The boundary map $\partial$ takes a relative homotopy class to its restriction to the equator. Exactness at each term follows from the homotopy extension property.

# Computing homotopy groups for spheres (known results)
def pi_n_sm(n, m):

    elif n < m:
        return "0 (trivial)"
    elif n == m + 1 and m >= 2:
        return "Z/2Z"
    else:
        return "Complex finite group"

Étale Cohomology

Motivation: Étale cohomology provides a cohomology theory for algebraic varieties that generalizes singular cohomology for complex manifolds, working over any base field.

Definitions:

The étale site $X_{et}$ of a scheme $X$ has: - Objects: Étale morphisms $U \to X$ - Morphisms: $X$-morphisms between étale schemes - Coverings: Families of jointly surjective étale morphisms The étale cohomology $H^i_{et}(X, \mathcal{F})$ is the right derived functor of the global sections functor on the étale site.

Theorem (Comparison Theorem):

If $X$ is a smooth scheme over $\mathbb{C}$, then $H^i_{et}(X, \mathbb{Z}/n) \cong H^i_{sing}(X^{an}, \mathbb{Z}/n)$ where $X^{an}$ is the associated complex analytic space.

Proof Sketch:

The proof uses the proper base change theorem and reduces to checking that étale cohomology agrees with singular cohomology for points.

Optimal Transport

Motivation: Optimal transport studies the most efficient way to transport mass from one distribution to another, with applications in economics, machine learning, and PDEs.

Definitions:

The Wasserstein distance $W_p$ between probability measures $\mu$ and $\nu$ is: $W_p(\mu, \nu) = \left(\inf_{\pi \in \Pi(\mu, \nu)} \int d(x,y)^p d\pi(x,y)\right)^{1/p}$ where $\Pi(\mu, \nu)$ is the set of couplings (joint distributions with marginals $\mu$ and $\nu$).

Theorem (Kantorovich Duality):

$W_1(\mu, \nu) = \sup_{||f||_{Lip} \leq 1} \int f d(\mu - \nu)$ where the supremum is over 1-Lipschitz functions.

Proof Sketch:

This follows from the Fenchel-Rockafellar duality theorem applied to the optimal transport problem.

Compressed Sensing

Motivation: Compressed sensing allows the recovery of sparse signals from far fewer samples than required by the Nyquist-Shannon theorem, with applications in MRI, imaging, and signal processing.

Definitions:

A vector $x \in \mathbb{R}^n$ is s-sparse if at most $s$ entries are nonzero. The restricted isometry property (RIP) holds for a matrix $A$ if there exists $\delta_s \in (0,1)$ such that: $(1-\delta_s)||x||^2 \leq ||Ax||^2 \leq (1+\delta_s)||x||^2$ for all $s$-sparse $x$.

Theorem (Exact Recovery via L1 Minimization):

If $A$ satisfies RIP of order $2s$ with $\delta_{2s} < \sqrt{2}-1$, then the solution to $\min ||x||_1$ subject to $Ax = b$ equals the sparsest solution.

Proof Sketch:

The proof uses duality and shows that the RIP ensures the null space property holds, which is necessary and sufficient for exact recovery.

import numpy as np
from sklearn.linear_model import Lasso

# Generate sparse signal
n, s = 1000, 10
x = np.zeros(n)
x[np.random.choice(n, s, replace=False)] = np.random.randn(s)

# Measurement matrix (Gaussian)
m = 200  # Number of measurements
A = np.random.randn(m, n) / np.sqrt(m)
b = A @ x

# L1 recovery
lasso = Lasso(alpha=0.001, fit_intercept=False)
lasso.fit(A, b)
x_recovered = lasso.coef_

# Recovery error
error = np.linalg.norm(x - x_recovered) / np.linalg.norm(x)
print(f"Recovery error: {error:.4f}")

Neural Network Theory

Motivation: Understanding the mathematical foundations of deep learning helps explain why neural networks generalize well despite having massive capacity.

Definitions:

The Neural Tangent Kernel (NTK) at initialization: $\Theta(x, x') = \mathbb{E}_{\theta}\left[\nabla_\theta f(x; \theta) \cdot \nabla_\theta f(x'; \theta)\right]$ In the infinite width limit, neural network training becomes kernel regression with the NTK.

Theorem (Universal Approximation):

A feedforward network with a single hidden layer containing a finite number of neurons can approximate continuous functions on compact subsets of $\mathbb{R}^n$ arbitrarily well.

Proof Sketch:

The proof uses the Hahn-Banach theorem and shows that if a function cannot be approximated, there exists a nonzero signed measure that annihilates all neural network functions.

Tropical Geometry

Motivation: Tropical geometry studies algebraic varieties over the tropical semiring (min-plus algebra), providing combinatorial tools for understanding classical algebraic geometry.

Definitions:

The tropical semiring is $\mathbb{R} \cup \{\infty\}$ with operations: $\oplus = \min$ and $\odot = +$ A tropical polynomial is: $f(x) = \min_{i}(a_i + \langle b_i, x \rangle)$

Theorem (Fundamental Theorem of Tropical Geometry):

The tropical variety of an ideal $I$ equals the corner locus of the tropicalization of polynomials in $I$.

Proof Sketch:

The proof uses the Kapranov's theorem and shows that the non-archimedean amoeba equals the tropical variety.

The Weil Conjectures

Motivation: The Weil conjectures relate the number of points on algebraic varieties over finite fields to the topology of the corresponding complex variety.

Definitions:

For a variety $X$ over $\mathbb{F}_q$, the zeta function is: $Z(X, t) = \exp\left(\sum_{n=1}^\infty \frac{#X(\mathbb{F}_{q^n})}{n} t^n\right)$ The Weil conjectures predicted that $Z(X, t)$ satisfies a functional equation, has zeros on circles of specific radii, and is related to cohomology.

Theorem (Riemann Hypothesis for Varieties over Finite Fields):

The eigenvalues of Frobenius on $H^i_{et}(X, \mathbb{Q}_\ell)$ have absolute value $q^{i/2}$.

Proof Sketch:

Deligne's proof uses the Hard Lefschetz theorem and a clever inductive argument on the dimension of the variety.

# Example: Counting points on elliptic curves
# y^2 = x^3 + ax + b over F_p

def count_points(a, b, p):
    count = 1  # Point at infinity
    for x in range(p):
        rhs = (x**3 + a*x + b) % p
        # Count square roots
        for y in range(p):
            if (y*y) % p == rhs:
                count += 1
    return count

# Hasse's theorem: |#E(F_p) - (p + 1)| <= 2*sqrt(p)
p = 17
a, b = 2, 3

📜 Math History

Andrew Wiles and Fermat's Last Theorem

In 1994, Andrew Wiles proved Fermat's Last Theorem, which states that $a^n + b^n = c^n$ has no solutions in positive integers for $n > 2$. Wiles proved a special case of the modularity theorem, establishing that every semistable elliptic curve is modular. The proof connects elliptic curves, modular forms, and Galois representations, demonstrating deep relationships between seemingly unrelated areas of mathematics.

Competition Problem

Problem: Let $p$ be a prime with $p \equiv 1 \pmod 4$. Prove that the sum of quadratic residues modulo $p$ equals $\frac{p-1}2$.

Hint

Use properties of the Legendre symbol and the fact that $\sum_{a=1}^{p-1} \left(\frac{a}{p}\right) = 0$.

Solution

Let $S$ be the sum of quadratic residues. Since there are $(p-1)/2$ nonzero quadratic residues and $(p-1)/2$ non-residues, and the sum of all residues from 1 to $p-1$ is $p(p-1)/2$, we can use the fact that quadratic residues are symmetric and pair up to sum to $p$. The Mandelbrot Set

The Mandelbrot set is defined as the set of complex numbers $c$ for which the function $f_c(z) = z^2 + c$ does not diverge when iterated from $z = 0$.

The boundary of the Mandelbrot set is a fractal with Hausdorff dimension 2. It exhibits intricate structures at all scales, with miniature copies of the full set appearing throughout.

# Mandelbrot set computation
import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid
width, height = 800, 600
xmin, xmax = -2.5, 1
ymin, ymax = -1.25, 1.25

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute
M = np.vectorize(mandelbrot)(C)

plt.figure(figsize=(12, 8))
plt.imshow(M, extent=[xmin, xmax, ymin, ymax], cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('The Mandelbrot Set')
plt.xlabel('Real')
plt.ylabel('Imaginary')
plt.show()
