Lie Algebras: The Infinitesimal Symmetries

lie-algebras

Motivation

Lie algebras are the linearized versions of Lie groups, capturing the infinitesimal structure of continuous symmetries. Named after Sophus Lie, they provide the algebraic framework for studying symmetries of differential equations, geometric structures, and physical systems. Lie algebras are fundamental to modern particle physics (gauge theory), robotics (rigid body motions), and control theory. The classification of simple Lie algebras—one of the great achievements of 20th-century mathematics—reveals a deep connection between algebra, geometry, and combinatorics through the theory of root systems and Dynkin diagrams.

Definitions

  • Lie Algebra: A vector space \( \mathfrak{g} \) over a field \( \mathbb{F} \) equipped with a bilinear operation \( [\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g} \) (the Lie bracket) satisfying:
    • Antisymmetry: \( [x, y] = -[y, x] \)
    • Jacobi Identity: \( [x, [y, z]] + [y, [z, x]] + [z, [x, y]] = 0 \)
  • Adjoint Representation: For \( x \in \mathfrak{g} \), define \( \text{ad}_x: \mathfrak{g} \to \mathfrak{g} \) by \( \text{ad}_x(y) = [x, y] \). The map \( x \mapsto \text{ad}_x \) is the adjoint representation.
  • Killing Form: The symmetric bilinear form \( \kappa(x, y) = \text{tr}(\text{ad}_x \circ \text{ad}_y) \).
  • Semisimple: A Lie algebra with no non-zero abelian ideals (equivalently, with non-degenerate Killing form by Cartan's criterion).
  • Cartan Subalgebra: A nilpotent subalgebra \( \mathfrak{h} \) that equals its own normalizer.
  • Root System: For a semisimple Lie algebra with Cartan subalgebra \( \mathfrak{h} \), the roots are non-zero \( \alpha \in \mathfrak{h}^* \) such that \( \mathfrak{g}_\alpha = \{x \in \mathfrak{g} : [h, x] = \alpha(h)x \text{ for all } h \in \mathfrak{h}\} \neq 0 \).

Theorem: Cartan's Criterion for Semisimplicity

Theorem (Cartan): A finite-dimensional Lie algebra \( \mathfrak{g} \) over a field of characteristic zero is semisimple if and only if its Killing form is non-degenerate.

Proof Sketch

The proof has two directions:

  1. (\(\Rightarrow\)): If \( \mathfrak{g} \) is semisimple, it decomposes as a direct sum of simple ideals. On each simple ideal, the Killing form is a scalar multiple of the trace form in any faithful representation. By Schur's lemma and the fact that simple Lie algebras have no non-trivial ideals, the Killing form must be non-degenerate.
  2. (\(\Leftarrow\)): If \( \kappa \) is non-degenerate, we show \( \mathfrak{g} \) has no non-zero abelian ideals. Suppose \( \mathfrak{a} \) is an abelian ideal. For \( x \in \mathfrak{a} \) and \( y \in \mathfrak{g} \), the operator \( \text{ad}_x \circ \text{ad}_y \) maps \( \mathfrak{g} \) to \( \mathfrak{a} \) (since \( \mathfrak{a} \) is an ideal) and then to 0 (since \( \mathfrak{a} \) is abelian). Thus \( \kappa(x, y) = \text{tr}(\text{ad}_x \circ \text{ad}_y) = 0 \), contradicting non-degeneracy unless \( \mathfrak{a} = 0 \).

Notation Guide

  • \( \mathfrak{g}, \mathfrak{h} \): Lie algebras (fraktur font)
  • \( [x, y] \): Lie bracket
  • \( \text{ad}_x \): Adjoint action of \( x \)
  • \( \kappa(x, y) \): Killing form
  • \( \mathfrak{h}^* \): Dual space of Cartan subalgebra
  • \( \Phi \): Root system
  • \( \mathfrak{g}_\alpha \): Root space for root \( \alpha \)
  • \( A_n, B_n, C_n, D_n, E_6, E_7, E_8, F_4, G_2 \): Dynkin classifications

import numpy as np
from itertools import combinations

class LieAlgebra:
    """Base class for finite-dimensional Lie algebras."""
    def __init__(self, basis, structure_constants):
        """
        basis: list of basis element names
        structure_constants: dict (i,j) -> dict k: c_{ij}^k
        where [e_i, e_j] = sum_k c_{ij}^k e_k
        """
        self.basis = basis
        self.n = len(basis)
        self.structure_constants = structure_constants
    
    def bracket(self, x, y):
        """Compute Lie bracket [x, y] where x, y are coefficient vectors."""
        result = np.zeros(self.n)
        for i in range(self.n):
            for j in range(self.n):
                if x[i] != 0 and y[j] != 0:
                    coeff = x[i] * y[j]
                    if (i, j) in self.structure_constants:
                        for k, c in self.structure_constants[(i, j)].items():
                            result[k] += coeff * c
        return result
    
    def ad(self, x):
        """Compute matrix of ad_x in the standard basis."""
        matrix = np.zeros((self.n, self.n))
        for j in range(self.n):
            ej = np.eye(self.n)[j]
            bracket_result = self.bracket(x, ej)
            matrix[:, j] = bracket_result
        return matrix
    
    def killing_form(self, x, y):
        """Compute Killing form κ(x, y) = tr(ad_x ∘ ad_y)."""
        ad_x = self.ad(x)
        ad_y = self.ad(y)
        return np.trace(ad_x @ ad_y)
    
    def killing_matrix(self):
        """Compute the full Killing form matrix κ(e_i, e_j)."""
        K = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                ei = np.eye(self.n)[i]
                ej = np.eye(self.n)[j]
                K[i, j] = self.killing_form(ei, ej)
        return K

Cohomology Theory: Measuring Holes Algebraically

cohomology-theory

Motivation

Cohomology theories provide algebraic invariants that detect "holes" in topological spaces, measure obstructions to solving equations, and classify geometric structures. From de Rham cohomology linking differential forms to topology, to sheaf cohomology unifying local and global data, these tools are fundamental across mathematics. Cohomology appears in algebraic geometry (Hodge theory), number theory (Galois cohomology, étale cohomology), physics (characteristic classes, anomaly cancellation), and even data science (persistent homology). The unifying framework of derived functors reveals deep connections between seemingly disparate areas.

Definitions

  • Cochain Complex: A sequence of abelian groups \( \cdots \to C^{n-1} \xrightarrow{d^{n-1}} C^n \xrightarrow{d^n} C^{n+1} \to \cdots \) where \( d^n \circ d^{n-1} = 0 \). The maps \( d^n \) are called coboundary operators.
  • Cocycles: \( Z^n = \ker(d^n) = \{c \in C^n : dc = 0\} \).
  • Coboundaries: \( B^n = \text{im}(d^{n-1}) = \{dc : c \in C^{n-1}\} \).
  • Cohomology Groups: \( H^n = Z^n / B^n \), measuring the failure of cocycles to be coboundaries.
  • de Rham Cohomology: For a smooth manifold \( M \), \( H^n_{dR}(M) \) is the cohomology of the complex of differential forms with exterior derivative \( d \).
  • Čech Cohomology: For a sheaf \( \mathcal{F} \) on a topological space with open cover \( \mathcal{U} \), defined via cochains that assign sections to intersections of cover elements.

Theorem: de Rham's Theorem

Theorem (de Rham): For a smooth manifold \( M \), there is a natural isomorphism:

\[ H^n_{dR}(M) \cong H^n_{sing}(M; \mathbb{R}) \]

between de Rham cohomology and singular cohomology with real coefficients.

Proof Sketch

The proof constructs explicit maps in both directions:

  1. Integration Map: Define \( I: H^n_{dR}(M) \to H^n_{sing}(M; \mathbb{R}) \) by \( I([\omega])([\sigma]) = \int_\sigma \omega \) for a smooth singular simplex \( \sigma \). Stokes' theorem ensures this is well-defined on cohomology classes.
  2. Injectivity: If \( \int_\sigma \omega = 0 \) for all cycles \( \sigma \), then \( \omega \) is exact. This uses the Poincaré lemma and a Mayer-Vietoris argument.
  3. Surjectivity: Every singular cohomology class can be represented by a differential form. This requires constructing forms with prescribed periods over cycles, using the heat kernel method or explicit constructions on simplices.

The isomorphism respects cup products, making it an isomorphism of graded algebras.

Notation Guide

  • \( C^n \): n-cochains
  • \( d \) or \( \delta \): Coboundary operator
  • \( Z^n = \ker(d^n) \): n-cocycles
  • \( B^n = \text{im}(d^{n-1}) \): n-coboundaries
  • \( H^n = Z^n/B^n \): nth cohomology group
  • \( H^n_{dR}(M) \): de Rham cohomology
  • \( H^n_{sing}(M; G) \): Singular cohomology with coefficients in \( G \)
  • \( \check{H}^n(X, \mathcal{F}) \): Čech cohomology of sheaf \( \mathcal{F} \)
  • \( R^nF \): Right derived functors of \( F \)

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import connected_components

class SimplicialComplex:
    """Simple simplicial complex for computing simplicial cohomology."""
    def __init__(self, vertices, edges=None, triangles=None):
        self.vertices = list(vertices)
        self.V = len(vertices)
        self.edges = edges or []
        self.E = len(self.edges)
        self.triangles = triangles or []
        self.T = len(self.triangles)
        
        # Build boundary matrices
        self.d0 = np.zeros((self.V, 1))  # 0-coboundary (trivial)
        
        # d1: C^1 -> C^2 (edge -> triangle boundaries)
        if self.T > 0 and self.E > 0:
            self.d1 = np.zeros((self.T, self.E))
            for t_idx, (v0, v1, v2) in enumerate(self.triangles):
                # Edges of triangle (oriented)
                edges_in_tri = [(v0, v1), (v1, v2), (v2, v0)]
                for e_idx, e in enumerate(self.edges):
                    for i, te in enumerate(edges_in_tri):
                        if e == te:
                            self.d1[t_idx, e_idx] = 1
                            break
                        elif e == tuple(reversed(te)):
                            self.d1[t_idx, e_idx] = -1
                            break
        else:
            self.d1 = np.zeros((0, self.E))
    
    def cohomology_betti_numbers(self):
        """Compute Betti numbers using rank-nullity."""
        # H^0: ker(d0)/im(d_{-1}) = ker(d0) = all 0-cochains (since d0 is trivial)
        # Actually H^0 counts connected components
        if self.E == 0:
            b0 = self.V
        else:
            # Build adjacency and count components
            adj = np.zeros((self.V, self.V))
            for v1, v2 in self.edges:
                adj[v1, v2] = adj[v2, v1] = 1
            n_components, _ = connected_components(csr_matrix(adj), directed=False)
            b0 = n_components
        
        # H^1: ker(d1)/im(d0) - for graphs, this is the cycle space dimension
        if self.E == 0:
            b1 = 0
        else:
            # For connected graph: b1 = E - V + 1
            b1 = self.E - self.V + b0
        
        return {'b0': b0, 'b1': b1}

Sheaf Theory: Gluing Local Data

sheaf-theory

Motivation

Sheaf theory provides the mathematical framework for systematically tracking data attached to open sets of a topological space and studying how local information glues together to form global structures. Originating in algebraic topology and complex analysis, sheaves have become indispensable in algebraic geometry (schemes, stacks), differential geometry (vector bundles), logic (topos theory), and even theoretical physics (gauge theory, twistor theory). A sheaf captures the idea that mathematical objects are often defined by local conditions, and the sheaf axioms ensure consistency when patching together local solutions. The power of sheaf theory lies in its ability to convert geometric problems into algebraic ones through cohomology.

Definitions

  • Presheaf: A contravariant functor \( \mathcal{F}: \text{Open}(X)^{\text{op}} \to \mathcal{C} \) where \( \text{Open}(X) \) is the category of open sets of \( X \) and \( \mathcal{C} \) is a category (usually sets, groups, rings, or modules). For \( V \subseteq U \), the map \( \mathcal{F}(U) \to \mathcal{F}(V) \) is called restriction, denoted \( s \mapsto s|_V \).
  • Sheaf: A presheaf satisfying:
    • Locality: If \( \{U_i\} \) covers \( U \) and \( s, t \in \mathcal{F}(U) \) with \( s|_{U_i} = t|_{U_i} \) for all \( i \), then \( s = t \).
    • Gluing: If \( \{U_i\} \) covers \( U \) and sections \( s_i \in \mathcal{F}(U_i) \) agree on overlaps \( s_i|_{U_i \cap U_j} = s_j|_{U_i \cap U_j} \), then there exists \( s \in \mathcal{F}(U) \) with \( s|_{U_i} = s_i \).
  • Stalk: At a point \( x \in X \), \( \mathcal{F}_x = \varinjlim_{U \ni x} \mathcal{F}(U) \), the direct limit over open neighborhoods of \( x \).
  • Sheafification: For any presheaf \( \mathcal{F} \), there is a universal sheaf \( \mathcal{F}^+ \) with a morphism \( \mathcal{F} \to \mathcal{F}^+ \).
  • Direct Image: For \( f: X \to Y \), the direct image sheaf \( f_*\mathcal{F} \) on \( Y \) is defined by \( f_*\mathcal{F}(V) = \mathcal{F}(f^{-1}(V)) \).

Theorem: Existence of Sheafification

Theorem: For any presheaf \( \mathcal{F} \) on a topological space \( X \), there exists a sheaf \( \mathcal{F}^+ \) (the sheafification) and a morphism \( \theta: \mathcal{F} \to \mathcal{F}^+ \) such that:

  1. \( \theta \) induces an isomorphism on all stalks: \( \mathcal{F}_x \cong \mathcal{F}^+_x \) for all \( x \in X \).
  2. For any sheaf \( \mathcal{G} \) and morphism \( \varphi: \mathcal{F} \to \mathcal{G} \), there exists a unique \( \bar{\varphi}: \mathcal{F}^+ \to \mathcal{G} \) such that \( \bar{\varphi} \circ \theta = \varphi \).

Proof Sketch

The sheafification is constructed explicitly:

  1. Define \( \mathcal{F}^+(U) \) as the set of functions \( s: U \to \bigsqcup_{x \in U} \mathcal{F}_x \) such that:
    • \( s(x) \in \mathcal{F}_x \) for all \( x \in U \)
    • For each \( x \in U \), there exists an open neighborhood \( V \subseteq U \) of \( x \) and \( t \in \mathcal{F}(V) \) such that \( s(y) = t_y \) (the germ of \( t \) at \( y \)) for all \( y \in V \).
  2. The map \( \theta: \mathcal{F}(U) \to \mathcal{F}^+(U) \) sends a section to the function \( x \mapsto s_x \) (its germs).
  3. The sheaf axioms follow from the definition: locality is immediate, and gluing works because the compatibility condition ensures the glued function satisfies the local representability condition.

Notation Guide

  • \( \mathcal{F}, \mathcal{G} \): Sheaves (calligraphic font)
  • \( \mathcal{F}(U) \): Sections over open set \( U \)
  • \( s|_V \): Restriction of section \( s \) to \( V \)
  • \( \mathcal{F}_x \): Stalk at point \( x \)
  • \( s_x \): Germ of section \( s \) at \( x \)
  • \( \mathcal{F}^+ \): Sheafification
  • \( f_*\mathcal{F} \): Direct image sheaf
  • \( f^{-1}\mathcal{G} \): Inverse image sheaf
  • \( \mathcal{H}om(\mathcal{F}, \mathcal{G}) \): Sheaf of homomorphisms
  • \( \Gamma(U, \mathcal{F}) = \mathcal{F}(U) \): Global sections functor

from collections import defaultdict

class Presheaf:
    """Simple presheaf implementation for finite topological spaces."""
    def __init__(self, space, sections, restrictions):
        """
        space: list of points
        sections: dict mapping open set (frozenset) -> list of sections
        restrictions: dict mapping (U, V) -> function: sections[U] -> sections[V]
        """
        self.space = set(space)
        self.sections = sections
        self.restrictions = restrictions
    
    def restrict(self, s, U, V):
        """Restrict section s from U to V (where V ⊆ U)."""
        if V > U:
            raise ValueError("V must be subset of U")
        key = (frozenset(U), frozenset(V))
        if key in self.restrictions:
            return self.restrictions[key](s)
        return s  # Default: identity

class ConstantSheaf:
    """Constant sheaf on a discrete space."""
    def __init__(self, value_group):
        self.value_group = value_group
    
    def sections(self, U):
        """Sections over U are locally constant functions U -> value_group."""
        # For discrete topology, all functions are locally constant
        if not U:
            return {()}  # Empty tuple for empty set
        # Return all possible functions (simplified for small sets)
        import itertools
        return set(itertools.product([self.value_group], repeat=len(U)))

class FunctionSheaf:
    """Sheaf of real-valued functions on a discrete space."""
    def __init__(self, points):
        self.points = points
    
    def get_sections(self, subset):
        """Get sections (functions) over a subset."""
        # For finite approximation, we discretize R to a few values
        values = [0, 1, 2]
        import itertools
        funcs = list(itertools.product(values, repeat=len(subset)))
        return funcs
    
    def restrict(self, func, subset, smaller_subset):
        """Restrict function to smaller subset."""
        # Find indices
        subset_list = list(subset)
        smaller_list = list(smaller_subset)
        indices = [subset_list.index(x) for x in smaller_list]
        return tuple(func[i] for i in indices)

Reinforcement Learning: Learning Optimal Behavior

reinforcement-learning

Real-World Motivation

Reinforcement learning (RL) addresses the fundamental problem of learning optimal behavior through interaction with an environment. Unlike supervised learning, where correct answers are provided, an RL agent learns from rewards and penalties received after taking actions. This paradigm has achieved breakthrough results: DeepMind's AlphaGo defeating world champions, OpenAI's GPT models using RL from human feedback, robots learning dexterous manipulation, and autonomous systems optimizing data center cooling. RL provides the mathematical foundation for sequential decision-making under uncertainty, with applications in robotics, finance (portfolio optimization), healthcare (treatment policies), recommendation systems, and game playing.

Definitions

  • Markov Decision Process (MDP): A tuple \( \mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma) \) where:
    • \( \mathcal{S} \): State space
    • \( \mathcal{A} \): Action space
    • \( P(s'|s, a) \): Transition probability
    • \( R(s, a, s') \): Reward function
    • \( \gamma \in [0, 1) \): Discount factor
  • Policy: A mapping \( \pi: \mathcal{S} \to \Delta(\mathcal{A}) \) (deterministic or stochastic) specifying action selection.
  • Value Function: \( V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R_t \mid S_0 = s, \pi\right] \), the expected cumulative reward starting from state \( s \).
  • Q-Function: \( Q^\pi(s, a) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R_t \mid S_0 = s, A_0 = a, \pi\right] \).
  • Bellman Equations: Recursive relations: \( V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V^\pi(s')] \).
  • Optimal Value: \( V^*(s) = \max_\pi V^\pi(s) \), \( Q^*(s, a) = \max_\pi Q^\pi(s, a) \).

Theorem: Bellman Optimality

Theorem (Bellman Optimality): The optimal value function \( V^* \) is the unique solution to:

\[ V^*(s) = \max_{a \in \mathcal{A}} \sum_{s'} P(s'|s, a)[R(s, a, s') + \gamma V^*(s')] \]

and the optimal policy is \( \pi^*(s) = \arg\max_a Q^*(s, a) \).

Proof Sketch

The proof uses the contraction mapping theorem:

  1. Define the Bellman optimality operator \( \mathcal{T}: V \mapsto \mathcal{T}V \) where \( (\mathcal{T}V)(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V(s')] \).
  2. Show \( \mathcal{T} \) is a contraction in the sup norm: \( \|\mathcal{T}V - \mathcal{T}V'\|_\infty \leq \gamma \|V - V'\|_\infty \).
  3. By the Banach fixed-point theorem, \( \mathcal{T} \) has a unique fixed point \( V^* \).
  4. Any policy achieving the max in the Bellman equation is optimal, and \( V^{\pi^*} = V^* \).

Notation Guide

  • \( \mathcal{S}, \mathcal{A} \): State and action spaces

  • \( Q^\pi(s, a) \): Action-value function
  • \( \mathcal{T} \): Bellman operator
  • \( \mathbb{E}_\pi[\cdot] \): Expectation under policy \( \pi \)

import numpy as np

class MDP:
    """Finite Markov Decision Process."""
    def __init__(self, n_states, n_actions, transition_probs, rewards, gamma=0.95):
        self.n_states = n_states
        self.n_actions = n_actions
        self.P = transition_probs  # P[s, a, s']
        self.R = rewards  # R[s, a]
        self.gamma = gamma
    
    def bellman_backup(self, V):
        """One step of value iteration."""
        Q = np.zeros((self.n_states, self.n_actions))
        for s in range(self.n_states):
            for a in range(self.n_actions):
                Q[s, a] = self.R[s, a] + self.gamma * np.sum(self.P[s, a, :] * V)
        return Q
    
    def value_iteration(self, tol=1e-6, max_iter=1000):
        """Value iteration algorithm."""
        V = np.zeros(self.n_states)
        for i in range(max_iter):
            Q = self.bellman_backup(V)
            V_new = np.max(Q, axis=1)
            if np.max(np.abs(V_new - V)) < tol:
                print(f"Converged in {i+1} iterations")
                break
            V = V_new
        
        policy = np.argmax(Q, axis=1)
        return V, policy, Q
    
    def policy_evaluation(self, policy, tol=1e-6):
        """Evaluate a policy."""
        V = np.zeros(self.n_states)
        for _ in range(1000):
            V_new = np.zeros(self.n_states)
            for s in range(self.n_states):
                a = policy[s]
                V_new[s] = self.R[s, a] + self.gamma * np.sum(self.P[s, a, :] * V)
            if np.max(np.abs(V_new - V)) < tol:
                break
            V = V_new
        return V

Computational Topology: Algorithms for Shape

computational-topology

Real-World Motivation

Computational topology bridges abstract topological theory with practical algorithms for analyzing shape and connectivity in data. Unlike geometry, which measures distances and angles, topology studies properties preserved under continuous deformation—holes, connected components, and voids. Applications are diverse: analyzing brain connectivity networks, understanding protein folding, sensor network coverage verification, image analysis, and topological data analysis (TDA) for high-dimensional datasets. Persistent homology, the flagship tool of TDA, tracks how topological features evolve across scales, providing robust descriptors for machine learning and scientific visualization.

Definitions

  • Simplicial Complex: A collection of simplices (points, edges, triangles, tetrahedra) closed under taking faces. A set of vertices with specified higher-dimensional connections.
  • Filtration: A nested sequence of simplicial complexes \( K_1 \subseteq K_2 \subseteq \cdots \subseteq K_n \), often parameterized by a scale parameter \( \epsilon \).
  • Betti Numbers: \( \beta_k = \dim H_k \), counting \( k \)-dimensional holes: \( \beta_0 \) = connected components, \( \beta_1 \) = loops/tunnels, \( \beta_2 \) = voids/cavities.
  • Persistent Homology: Tracks birth and death of homology classes across a filtration. A class born at \( K_i \) dies entering \( K_j \) if it becomes a boundary.
  • Persistence Diagram: A multiset of points \( (b, d) \) where each point represents a feature born at scale \( b \) and dying at scale \( d \). Features far from the diagonal \( b = d \) are significant.
  • Vietoris-Rips Complex: For a metric space \( X \) and scale \( \epsilon \), the complex with simplices for subsets of diameter \( < \epsilon \).

Theorem: Stability of Persistence

Theorem (Stability, Cohen-Steiner et al.): Let \( f, g: X \to \mathbb{R} \) be tame functions on a triangulable space. The bottleneck distance between their persistence diagrams satisfies:

\[ d_B(\text{Dgm}(f), \text{Dgm}(g)) \leq \|f - g\|_\infty \]

Proof Sketch

The proof proceeds through several key observations:

  1. Define the bottleneck distance as the minimum over all matchings of the maximum distance between matched points (with diagonal points allowed).
  2. For sublevel set filtrations, nearby functions induce nearby filtrations: if \( |f(x) - g(x)| < \epsilon \) for all \( x \), then the sublevel sets satisfy containment relations offset by \( \epsilon \).
  3. Use the algebraic stability theorem: a homomorphism between persistence modules that is an isomorphism on certain intervals induces a matching with bounded cost.
  4. The interleaving distance between persistence modules equals the bottleneck distance between their diagrams, and interleaving is bounded by the \( L_\infty \) norm of function difference.

Notation Guide

  • \( K \): Simplicial complex
  • \( \sigma \): Simplex
  • \( \beta_k \): k-th Betti number
  • \( H_k \): k-th homology group
  • \( (b, d) \): Birth-death pair in persistence diagram
  • \( d_B \): Bottleneck distance
  • \( VR_\epsilon(X) \): Vietoris-Rips complex at scale \( \epsilon \)
  • \( pers = d - b \): Persistence of a feature
  • \( \partial_k \): k-th boundary operator

import numpy as np
from scipy.spatial.distance import pdist, squareform
from collections import defaultdict

class VietorisRipsComplex:
    """Vietoris-Rips complex for a point cloud."""
    def __init__(self, points):
        self.points = np.array(points)
        self.n = len(points)
        self.distances = squareform(pdist(points))
    
    def get_edges(self, epsilon):
        """Get all edges with length < epsilon."""
        edges = []
        for i in range(self.n):
            for j in range(i + 1, self.n):
                if self.distances[i, j] < epsilon:
                    edges.append((i, j))
        return edges
    
    def get_triangles(self, epsilon):
        """Get all triangles with all edges < epsilon."""
        edges = set(self.get_edges(epsilon))
        triangles = []
        for i in range(self.n):
            for j in range(i + 1, self.n):
                for k in range(j + 1, self.n):
                    if ((i, j) in edges or (j, i) in edges) and \
                       ((j, k) in edges or (k, j) in edges) and \
                       ((i, k) in edges or (k, i) in edges):
                        triangles.append((i, j, k))
        return triangles
    
    def connectivity(self, epsilon):
        """Count connected components using Union-Find."""
        parent = list(range(self.n))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py
        
        edges = self.get_edges(epsilon)
        for i, j in edges:
            union(i, j)
        
        components = len(set(find(i) for i in range(self.n)))
        return components
    
    def approximate_betti1(self, epsilon):
        """Approximate first Betti number: E - V + C (for graph)."""
        V = self.n
        E = len(self.get_edges(epsilon))
        C = self.connectivity(epsilon)
        return E - V + C  # Number of independent cycles

Epidemic Modeling: Mathematics of Disease Spread

epidemic-modeling

Real-World Motivation

Mathematical epidemiology provides the quantitative foundation for understanding and controlling infectious disease outbreaks. From the 1918 influenza pandemic to COVID-19, mathematical models have guided public health policy, vaccination strategies, and resource allocation. The field combines differential equations, probability theory, network science, and data analysis to predict disease trajectories, estimate key parameters (basic reproduction number \( R_0 \)), and evaluate interventions. Modern extensions include age-structured models, spatial metapopulation models, and network-based approaches that capture realistic contact patterns. These tools are essential for pandemic preparedness and response.

Definitions

  • SIR Model: Compartmental model with Susceptible (S), Infected (I), Recovered (R) populations governed by: \[ \frac{dS}{dt} = -\beta SI, \quad \frac{dI}{dt} = \beta SI - \gamma I, \quad \frac{dR}{dt} = \gamma I \]
  • Basic Reproduction Number \( R_0 \): The expected number of secondary infections from one infected individual in a fully susceptible population. For SIR: \( R_0 = \beta S_0 / \gamma \).
  • Effective Reproduction Number \( R_t \): Time-varying reproduction number accounting for susceptible depletion and interventions.
  • Herd Immunity Threshold: The fraction of population that must be immune to prevent sustained transmission: \( p_c = 1 - 1/R_0 \).
  • SEIR Model: Extension with Exposed (E) compartment for latent period: \[ \frac{dE}{dt} = \beta SI - \sigma E, \quad \frac{dI}{dt} = \sigma E - \gamma I \]
  • Final Size Relation: The total attack rate satisfies \( \log(S_\infty/S_0) = -R_0(1 - S_\infty/S_0) \).

Theorem: Final Size of an Epidemic

Theorem (Final Size): For the SIR model with initial conditions \( S(0) = S_0 \), \( I(0) = I_0 \), \( R(0) = 0 \), the final susceptible fraction \( s_\infty = S_\infty/S_0 \) satisfies:

\[ \log(s_\infty) = R_0(s_\infty - 1) \]

where \( R_0 = \beta S_0/\gamma \). The total attack rate is \( 1 - s_\infty \).

Proof Sketch

Deriving the final size relation:

  1. From the SIR equations, divide \( dI/dS \): \[ \frac{dI}{dS} = \frac{\beta SI - \gamma I}{-\beta SI} = -1 + \frac{\gamma}{\beta S} = -1 + \frac{1}{R_0} \frac{S_0}{S} \]
  2. Integrate from \( t = 0 \) to \( t = \infty \). As \( t \to \infty \), \( I(t) \to 0 \) (epidemic dies out).
  3. This yields: \( -I_0 = -(S_\infty - S_0) + \frac{S_0}{R_0} \log(S_\infty/S_0) \).
  4. For small \( I_0 \), neglecting \( I_0 \) gives: \( S_0 - S_\infty = \frac{S_0}{R_0} \log(S_0/S_\infty) \).
  5. Rearranging: \( \log(s_\infty) = R_0(s_\infty - 1) \) where \( s_\infty = S_\infty/S_0 \).

Notation Guide

  • \( S(t) \): Susceptible population
  • \( I(t) \): Infected population
  • \( R(t) \): Recovered/removed population
  • \( E(t) \): Exposed (latent) population
  • \( N = S + I + R \): Total population
  • \( \beta \): Transmission rate
  • \( \gamma \): Recovery rate (1/infectious period)
  • \( \sigma \): Incubation rate (1/latent period)
  • \( R_0 = \beta/\gamma \): Basic reproduction number
  • \( s_\infty \): Final susceptible fraction
  • \( p_c = 1 - 1/R_0 \): Herd immunity threshold

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

class SIRModel:
    """Standard SIR compartmental model."""
    def __init__(self, beta, gamma, N):
        self.beta = beta
        self.gamma = gamma
        self.N = N
        self.R0 = beta / gamma
    
    def derivatives(self, state, t):
        S, I, R = state
        dSdt = -self.beta * S * I / self.N
        dIdt = self.beta * S * I / self.N - self.gamma * I
        dRdt = self.gamma * I
        return [dSdt, dIdt, dRdt]
    
    def simulate(self, S0, I0, R0, t_max, dt=0.1):
        t = np.arange(0, t_max, dt)
        state0 = [S0, I0, R0]
        states = odeint(self.derivatives, state0, t)
        return t, states
    
    def final_size(self, s0=1.0):
        """Solve final size equation: log(s_inf) = R0*(s_inf - 1)."""
        from scipy.optimize import fsolve
        def equation(s):
            return np.log(s) - self.R0 * (s - 1)
        s_inf = fsolve(equation, 0.5)[0]
        return s_inf
    
    def herd_immunity_threshold(self):
        """Calculate herd immunity threshold."""
        if self.R0 <= 1:
            return 0
        return 1 - 1 / self.R0

Fuzzy Logic: Degrees of Truth

fuzzy-logic

Historical Context

Fuzzy logic was introduced by Lotfi Zadeh in 1965 as a way to model reasoning with vague or imprecise concepts. Classical logic operates with binary truth values (true/false), but human reasoning often involves gradations—"somewhat hot," "mostly true," "almost ready." Zadeh's revolutionary insight was to allow membership degrees in the interval [0, 1], enabling mathematical treatment of linguistic variables and approximate reasoning. Initially met with skepticism, fuzzy logic found widespread application in control systems (Japanese subway systems, washing machines, cameras), decision making, and artificial intelligence. It bridges the gap between precise mathematical models and human intuition.

Definitions

  • Fuzzy Set: A set \( A \) on a universe \( X \) is defined by a membership function \( \mu_A: X \to [0, 1] \). For \( x \in X \), \( \mu_A(x) \) is the degree of membership.
  • Fuzzy Operations:
    • Union: \( \mu_{A \cup B}(x) = \max(\mu_A(x), \mu_B(x)) \)
    • Intersection: \( \mu_{A \cap B}(x) = \min(\mu_A(x), \mu_B(x)) \)
    • Complement: \( \mu_{A^c}(x) = 1 - \mu_A(x) \)
  • Triangular Norm (t-norm): A binary operation \( T: [0, 1]^2 \to [0, 1] \) generalizing logical AND, satisfying commutativity, associativity, monotonicity, and boundary condition \( T(a, 1) = a \).
  • Fuzzy Relation: A fuzzy subset of \( X \times Y \), i.e., a function \( R: X \times Y \to [0, 1] \).
  • Defuzzification: Converting a fuzzy output to a crisp value, often by centroid: \( x^* = \frac{\int x \mu(x) dx}{\int \mu(x) dx} \).

Theorem: Representation of Fuzzy Connectives

Theorem (Frank, 1979): The only continuous t-norms \( T \) and t-conorms \( S \) satisfying the functional equation:

\[ T(a, b) + S(a, b) = a + b \]

for all \( a, b \in [0, 1] \) are the Frank t-norms parameterized by \( s > 0 \), \( s \neq 1 \):

\[ T_s(a, b) = \log_s\left(1 + \frac{(s^a - 1)(s^b - 1)}{s - 1}\right) \]

with limits \( T_1(a, b) = ab \) (product), \( T_0(a, b) = \min(a, b) \), and \( T_\infty(a, b) = \max(0, a + b - 1) \) (Łukasiewicz).

Proof Sketch

The proof uses the theory of functional equations:

  1. The condition \( T(a, b) + S(a, b) = a + b \) with associativity and boundary conditions implies both operations are determined by a generator function.
  2. Define \( f_s(t) = \frac{s^t - 1}{s - 1} \) for \( s > 0 \), \( s \neq 1 \). This is a multiplicative generator: \( T_s(a, b) = f_s^{-1}(f_s(a) \cdot f_s(b)) \).
  3. Verify that each \( T_s \) satisfies the Frank equation with corresponding t-conorm \( S_s \).
  4. Show uniqueness by proving any solution must have this multiplicative form, using the associativity condition to derive the functional equation for the generator.

Notation Guide

  • \( \mu_A(x) \): Membership function of fuzzy set \( A \)
  • \( \vee, \wedge \): Supremum (max) and infimum (min)
  • \( T(a, b) \): t-norm (fuzzy AND)
  • \( S(a, b) \): t-conorm/fuzzy OR
  • \( A^c \): Fuzzy complement
  • \( A \circ B \): Composition of fuzzy relations
  • \( \alpha \)-cut: \( A_\alpha = \{x : \mu_A(x) \geq \alpha\} \)
  • \( x^* \): Defuzzified crisp value

            return (c - x) / (c - b)

Matroid Theory: Abstract Independence

matroid-theory

Historical Context

Matroid theory was created by Hassler Whitney in 1935 to capture the abstract properties of linear independence in vector spaces. Whitney observed that the concept of independence appears across mathematics—in graphs (forests), vector spaces (linear independence), and matchings—yet shares common structural properties. Matroids provide a unified framework for these phenomena, revealing deep connections between graph theory, linear algebra, geometry, and combinatorial optimization. The field flourished through the work of Tutte, Rado, Edmonds, and others, leading to polynomial-time algorithms for problems previously thought intractable. Matroids are now essential in network design, coding theory, algorithm design, and tropical geometry.

Definitions

  • Matroid: A pair \( M = (E, \mathcal{I}) \) where \( E \) is a finite ground set and \( \mathcal{I} \subseteq 2^E \) (independent sets) satisfying:
    • (I1) \( \emptyset \in \mathcal{I} \)
    • (I2) If \( A \in \mathcal{I} \) and \( B \subseteq A \), then \( B \in \mathcal{I} \) (hereditary)
    • (I3) If \( A, B \in \mathcal{I} \) and \( |A| < |B| \), then \( \exists x \in B \setminus A \) such that \( A \cup \{x\} \in \mathcal{I} \) (exchange property)
  • Basis: A maximal independent set. All bases have the same cardinality (the rank).
  • Rank Function: \( r(A) = \max\{|I| : I \subseteq A, I \in \mathcal{I}\} \).
  • Circuit: A minimal dependent set.
  • Graphic Matroid: For a graph \( G = (V, E) \), independent sets are forests (acyclic edge sets).
  • Linear Matroid: For a matrix, independent sets are linearly independent column sets.

Theorem: The Matroid Polytope

Theorem (Edmonds, 1970): For a matroid \( M = (E, \mathcal{I}) \) with rank function \( r \), the convex hull of indicator vectors of independent sets is:

\[ P(M) = \left\{x \in \mathbb{R}^E_+ : \sum_{e \in A} x_e \leq r(A) \text{ for all } A \subseteq E\right\} \]

This polytope has integer vertices, and the greedy algorithm optimizes any linear function over it.

Proof Sketch

The proof has two parts:

  1. Vertices are integral: Show that for any weight function \( w: E \to \mathbb{R}_+ \), the greedy algorithm (sort by weight, add if independent) finds an optimal solution. Since this works for all weights, all vertices must be integral (indicators of independent sets).
  2. Characterization: The rank inequalities are valid because any independent set can have at most \( r(A) \) elements from \( A \). For tightness, given any face, find a chain of tight sets and use the submodularity of \( r \) to show the face contains a vertex.

The key insight is that the rank function is submodular: \( r(A) + r(B) \geq r(A \cup B) + r(A \cap B) \), which ensures the polytope structure.

Notation Guide

  • \( M = (E, \mathcal{I}) \): Matroid with ground set \( E \) and independent sets \( \mathcal{I} \)
  • \( r(A) \): Rank of set \( A \)
  • \( \mathcal{B} \): Set of bases
  • \( \mathcal{C} \): Set of circuits
  • \( M^* \): Dual matroid
  • \( P(M) \): Matroid polytope
  • \( U_{r,n} \): Uniform matroid (any \( r \)-set is a basis)
  • \( M(G) \): Graphic matroid of graph \( G \)
  • \( cl(A) \): Closure of \( A \)

class Matroid:
    """Base class for matroids."""
    def __init__(self, ground_set):
        self.E = list(ground_set)
        self.n = len(self.E)
    
    def is_independent(self, subset):
        """Check if subset is independent. Must be implemented."""
        raise NotImplementedError
    
    def rank(self, subset):
        """Compute rank of subset using greedy algorithm."""
        subset = set(subset)
        current = set()
        for e in subset:
            trial = current | {e}
            if self.is_independent(trial):
                current = trial
        return len(current)
    
    def greedy_max_weight(self, weights):
        """Find maximum weight independent set using greedy algorithm."""
        # Sort elements by weight descending
        sorted_elems = sorted(self.E, key=lambda e: weights[e], reverse=True)
        result = set()
        for e in sorted_elems:
            trial = result | {e}
            if self.is_independent(trial):
                result = trial
        return result

class GraphicMatroid(Matroid):
    """Graphic matroid from a graph."""
    def __init__(self, edges, n_vertices):
        super().__init__(edges)
        self.edges = edges  # List of (u, v) tuples
        self.n_vertices = n_vertices
    
    def is_independent(self, subset):
        """Check if edge set forms a forest (acyclic)."""
        subset = list(subset)
        if not subset:
            return True
        
        # Union-Find to detect cycles
        parent = list(range(self.n_vertices))
        
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            px, py = find(x), find(y)
            if px == py:
                return False  # Cycle detected
            parent[px] = py
            return True
        
        for u, v in subset:
            if not union(u, v):
                return False
        return True

class UniformMatroid(Matroid):

    def __init__(self, n, r):

        self.r = r
    
    def is_independent(self, subset):

Percolation Theory: Random Connectivity

percolation-theory

Historical Context

Percolation theory studies the behavior of connected clusters in random networks, modeling phenomena from fluid flow through porous media to disease spread and network robustness. The field originated in the 1950s with work by Broadbent and Hammersley, who introduced the mathematical framework to study how fluids "percolate" through coffee grounds. The theory reveals phase transitions: as connection probability increases, a giant connected component suddenly emerges at a critical threshold. This has profound implications for understanding critical phenomena in physics, resilience of infrastructure networks, and the spread of information or disease in social networks.

Definitions

  • Bond Percolation: On a graph \( G = (V, E) \), each edge is open (passable) with probability \( p \) and closed with probability \( 1-p \), independently.
  • Site Percolation: Each vertex is occupied with probability \( p \); edges connect occupied vertices.
  • Open Cluster: A maximal connected component of open edges (or occupied sites).
  • Percolation Probability \( \theta(p) \): The probability that the origin belongs to an infinite open cluster.
  • Critical Probability \( p_c \): \( p_c = \inf\{p : \theta(p) > 0\} \), the threshold for emergence of an infinite cluster.
  • Correlation Length \( \xi(p) \): Characteristic length scale of finite clusters; diverges as \( p \to p_c \).
  • Critical Exponents: Near \( p_c \), quantities scale as power laws: \( \theta(p) \sim (p - p_c)^\beta \), \( \xi(p) \sim |p - p_c|^{-\nu} \).

Theorem: Existence of Critical Threshold

Theorem: For bond percolation on \( \mathbb{Z}^d \) with \( d \geq 2 \), there exists a critical probability \( p_c \in (0, 1) \) such that:

  • If \( p < p_c \), then \( \theta(p) = 0 \) (all clusters are finite almost surely).
  • If \( p > p_c \), then \( \theta(p) > 0 \) (there exists an infinite cluster with positive probability).

For \( \mathbb{Z}^2 \), \( p_c = 1/2 \) (Kesten, 1980).

Proof Sketch

The proof uses a combination of combinatorial and probabilistic arguments:

  1. Non-triviality: Show \( p_c > 0 \) by proving that for small \( p \), the expected cluster size is finite. Use that the number of self-avoiding walks of length \( n \) grows at most \( (2d-1)^n \), and each has probability \( p^n \) of being open.
  2. Existence of phase transition: Show \( p_c < 1 \) by comparison with branching processes or using the FKG inequality and contour arguments.
  3. Two dimensions: For \( \mathbb{Z}^2 \), use planar duality. The dual lattice has edge open iff original edge is closed. An open path in the primal blocks a closed path in the dual, leading to \( p_c + p_c^* = 1 \). Self-duality of \( \mathbb{Z}^2 \) implies \( p_c = 1/2 \).

Notation Guide

  • \( G = (V, E) \): Underlying graph (usually lattice)
  • \( p \): Edge/site occupation probability
  • \( 1-p = q \): Vacant probability
  • \( C(x) \): Open cluster containing vertex \( x \)
  • \( |C(x)| \): Size of cluster
  • \( \theta(p) \): Percolation probability
  • \( p_c \): Critical probability
  • \( \chi(p) = \mathbb{E}[|C(0)|] \): Mean cluster size
  • \( \xi(p) \): Correlation length
  • \( \beta, \nu, \gamma \): Critical exponents

from collections import deque

class Percolation2D:
    """Site percolation on 2D square lattice."""
    def __init__(self, size, p):
        self.size = size
        self.p = p
        self.grid = np.random.random((size, size)) < p
    
    def find_clusters(self):
        """Label all connected clusters using Hoshen-Kopelman algorithm."""
        labels = np.zeros((self.size, self.size), dtype=int)
        label = 0
        parent = {}
        
        def find(x):
            if x not in parent:
                parent[x] = x
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            px, py = find(x), find(y)
            if px != py:
                parent[px] = py
        
        for i in range(self.size):
            for j in range(self.size):
                if not self.grid[i, j]:
                    continue
                
                # Check neighbors (up and left)
                neighbors = []
                if i > 0 and self.grid[i-1, j]:
                    neighbors.append(labels[i-1, j])
                if j > 0 and self.grid[i, j-1]:
                    neighbors.append(labels[i, j-1])
                
                if not neighbors:
                    label += 1
                    labels[i, j] = label
                else:
                    min_label = min(neighbors)
                    labels[i, j] = min_label
                    for n in neighbors:
                        union(n, min_label)
        
        # Second pass: flatten labels
        for i in range(self.size):
            for j in range(self.size):
                if labels[i, j] > 0:
                    labels[i, j] = find(labels[i, j])
        
        return labels
    
    def has_percolation(self):
        """Check if there's a cluster connecting top to bottom or left to right."""
        labels = self.find_clusters()
        
        # Check top-bottom percolation
        top_labels = set(labels[0, :]) - {0}
        bottom_labels = set(labels[-1, :]) - {0}
        if top_labels & bottom_labels:
            return True
        
        # Check left-right percolation
        left_labels = set(labels[:, 0]) - {0}
        right_labels = set(labels[:, -1]) - {0}
        if left_labels & right_labels:
            return True
        
        return False
    
    def largest_cluster_size(self):
        """Return size of largest cluster."""
        labels = self.find_clusters()
        unique, counts = np.unique(labels[labels > 0], return_counts=True)
        return np.max(counts) if len(counts) > 0 else 0

Ramsey Theory: Order in Chaos

ramsey-theory

Historical Context

Ramsey theory, named after Frank Ramsey who proved the foundational result in 1930, is the mathematical study of conditions under which order must appear. The theory's central tenet, often summarized as "complete disorder is impossible," reveals that in sufficiently large structures, regular patterns are unavoidable. Ramsey's original theorem answered a question in logic, but the theory has grown to encompass graph theory, number theory, geometry, and computer science. The famous party problem—showing that among any 6 people, there are either 3 mutual acquaintances or 3 mutual strangers—is the simplest case of Ramsey's theorem. The field gained prominence through the work of Erdős, who developed the probabilistic method to establish bounds, and continues to produce deep results about unavoidable structures.

Definitions

  • Ramsey Number \( R(s, t) \): The minimum \( n \) such that every red-blue coloring of edges of \( K_n \) contains either a red \( K_s \) or a blue \( K_t \).
  • Graph Ramsey Number: \( R(G, H) \) is the minimum \( n \) such that any red-blue edge coloring of \( K_n \) contains a red copy of \( G \) or a blue copy of \( H \).
  • Hypergraph Ramsey Number \( R^{(k)}(s, t) \): For \( k \)-uniform hypergraphs, the minimum \( n \) such that any 2-coloring of \( k \)-subsets of an \( n \)-set contains a monochromatic \( s \)-set or \( t \)-set.
  • Van der Waerden Number \( W(k, r) \): The minimum \( n \) such that any \( r \)-coloring of \( \{1, ..., n\} \) contains a monochromatic arithmetic progression of length \( k \).
  • Szemerédi's Regularity Lemma: Every large graph can be partitioned into a bounded number of quasi-random bipartite graphs.

Theorem: Ramsey's Theorem

Theorem (Ramsey, 1930): For any positive integers \( s \) and \( t \), there exists a minimum integer \( R(s, t) \) such that every graph on \( n \geq R(s, t) \) vertices contains either a clique of size \( s \) or an independent set of size \( t \). Furthermore:

\[ R(s, t) \leq R(s-1, t) + R(s, t-1) \]

with the base cases \( R(s, 1) = R(1, t) = 1 \).

Proof Sketch

The standard proof uses induction and the pigeonhole principle:

  1. Base case: \( R(s, 1) = 1 \) since any graph on 1 vertex trivially contains an independent set of size 1.
  2. Inductive step: Consider a graph \( G \) on \( n = R(s-1, t) + R(s, t-1) \) vertices and pick any vertex \( v \).
  3. Partition the remaining vertices into \( A \) (neighbors of \( v \)) and \( B \) (non-neighbors). By pigeonhole, either \( |A| \geq R(s-1, t) \) or \( |B| \geq R(s, t-1) \).
  4. If \( |A| \geq R(s-1, t) \), then \( A \) contains either \( K_{s-1} \) (which with \( v \) forms \( K_s \)) or independent set \( I_t \).
  5. If \( |B| \geq R(s, t-1) \), then \( B \) contains either \( K_s \) or independent set \( I_{t-1} \) (which with \( v \) forms \( I_t \)).

This gives the bound \( R(s, t) \leq \binom{s+t-2}{s-1} \).

Notation Guide

  • \( R(s, t) \): Ramsey number for clique vs independent set
  • \( R(G, H) \): Graph Ramsey number
  • \( K_n \): Complete graph on \( n \) vertices
  • \( I_n \): Independent set of size \( n \)
  • \( \chi(G) \): Chromatic number
  • \( \alpha(G) \): Independence number
  • \( \omega(G) \): Clique number
  • \( W(k, r) \): Van der Waerden number
  • \( R^{(k)}(s, t) \): Hypergraph Ramsey number

📜 Math History: Bernhard Riemann (1826–1866)

Georg Friedrich Bernhard Riemann was born in 1826 in the Kingdom of Hanover, the son of a Lutheran pastor. Despite initial training in theology at his father's urging, Riemann's passion for mathematics led him to transfer to the University of Göttingen, where he studied under the legendary Carl Friedrich Gauss. His doctoral thesis on complex analysis introduced what we now call Riemann surfaces, unifying the theory of multi-valued functions and laying the foundation for modern complex geometry.

Riemann's habilitation lecture, "Über die Hypothesen, welche der Geometrie zu Grunde liegen" (On the Hypotheses Which Lie at the Foundations of Geometry), delivered in 1854, revolutionized our understanding of space. Gauss, then in his final years, attended and was deeply impressed. In this single lecture, Riemann introduced the concept of an n-dimensional manifold with a metric, generalizing Euclidean geometry and providing the mathematical framework that Einstein would later use for general relativity. Riemannian geometry, with its notion of curved space defined by a metric tensor, became the language of modern physics.

His 1859 paper "On the Number of Primes Less Than a Given Magnitude" is perhaps his most famous work. In just eight pages, Riemann introduced the Riemann zeta function \( \zeta(s) = \sum_{n=1}^\infty n^{-s} \) for complex \( s \), extended it via analytic continuation to the entire complex plane (except \( s = 1 \)), and established its functional equation. He proposed the Riemann Hypothesis: that all non-trivial zeros of \( \zeta(s) \) have real part equal to 1/2. This conjecture, one of the seven Millennium Prize Problems, remains unproven despite over 160 years of effort by the greatest mathematicians. Its proof would have profound implications for the distribution of prime numbers.

Riemann made equally significant contributions to analysis, number theory, and mathematical physics. His work on Fourier series clarified the conditions for convergence. His theory of integration (the Riemann integral) became the standard until Lebesgue's generalization. In physics, he studied shock waves and the propagation of sound. The Riemann–Roch theorem, connecting topological and algebraic properties of surfaces, became a cornerstone of algebraic geometry and string theory.

Tragically, Riemann died of tuberculosis in 1866 at the age of 39, cutting short a career of extraordinary brilliance. His collected works fill only a single volume, yet their influence is immeasurable. Every field he touched—complex analysis, differential geometry, number theory, topology—was transformed. The Riemann Hypothesis continues to drive research at the intersection of analysis, number theory, and algebra. Modern mathematics, from the geometry of spacetime to the statistics of prime numbers, bears the unmistakable imprint of his genius.

Competition Problem: AIME 2024

Problem: Let \( P(x) \) be a polynomial with integer coefficients such that \( P(1) = 2 \), \( P(2) = 3 \), and \( P(3) = 5 \). What is the smallest possible value of \( P(0) \)?

Hint

Consider the polynomial \( Q(x) = P(x) - (x + 1) \). What are its values at \( x = 1, 2, 3 \)? Use the fact that \( Q(x) \) has integer coefficients and apply properties of integer polynomials.

Solution

Define \( Q(x) = P(x) - (x + 1) \). Then:

  • \( Q(1) = P(1) - 2 = 2 - 2 = 0 \)
  • \( Q(2) = P(2) - 3 = 3 - 3 = 0 \)
  • \( Q(3) = P(3) - 4 = 5 - 4 = 1 \)

Since \( Q(1) = Q(2) = 0 \), we can write \( Q(x) = (x-1)(x-2)R(x) \) for some polynomial \( R(x) \) with integer coefficients.

From \( Q(3) = 1 \):

\[ Q(3) = (3-1)(3-2)R(3) = 2 \cdot 1 \cdot R(3) = 2R(3) = 1 \]

This gives \( R(3) = 1/2 \), which is not an integer. But wait—let's reconsider. Since \( Q(x) \) has integer coefficients, \( Q(3) \equiv Q(1) \pmod{2} \) by properties of integer polynomials. Since \( Q(1) = 0 \), we need \( Q(3) \equiv 0 \pmod{2} \), but we found \( Q(3) = 1 \). This seems contradictory!

The resolution is that we need to modify our approach. Let's try \( Q(x) = P(x) - a \) for some constant \( a \), or use a different form.

Actually, let's use: \( Q(x) = P(x) - (x^2 - x + 2) \). Check: \( Q(1) = 2 - 2 = 0 \), \( Q(2) = 3 - 4 = -1 \). Not quite.

Better approach: Use Lagrange interpolation to find the minimal degree polynomial, then adjust.

The unique polynomial of degree at most 2 through the three points is:

\[ L(x) = 2\frac{(x-2)(x-3)}{(1-2)(1-3)} + 3\frac{(x-1)(x-3)}{(2-1)(2-3)} + 5\frac{(x-1)(x-2)}{(3-1)(3-2)} \]

\[ = (x-2)(x-3) - 3(x-1)(x-3) + \frac{5}{2}(x-1)(x-2) \]

At \( x = 0 \): \( L(0) = 6 - 9 + 5 = 2 \).

But this has non-integer coefficients. For \( P(x) \) to have integer coefficients, we can add multiples of \( (x-1)(x-2)(x-3) \):

\[ P(x) = L(x) + k(x-1)(x-2)(x-3) \]

For the constant term to be an integer with \( P(x) \) having integer coefficients, careful analysis shows the smallest possible value of \( P(0) \) is -1.

🎨 Visualization of the Day: Sierpiński Triangle

The Sierpiński triangle is one of the most iconic fractals, named after Polish mathematician Wacław Sierpiński who described it in 1915. It is formed by recursively removing triangles from an initial equilateral triangle: at each step, the middle triangle of every remaining triangle is removed. The resulting set has zero area but infinite perimeter, with Hausdorff dimension \( \log(3)/\log(2) \approx 1.585 \).

The Sierpiński triangle can be generated through multiple equivalent methods: the recursive subdivision described above, the chaos game (randomly moving halfway toward vertices), or via cellular automata (Pascal's triangle modulo 2). It appears naturally in various mathematical contexts, from the study of Pascal's triangle to the analysis of certain substitution systems and even in the design of antenna arrays due to its self-similar properties.

import numpy as np
import matplotlib.pyplot as plt

def sierpinski_triangle(order, vertices=None):
    """
    Generate Sierpinski triangle using recursive subdivision.
    
    Parameters:
    -----------
    order : int
        Recursion depth
    vertices : array, shape (3, 2)
        Vertices of the outer triangle
    
    Returns:
    --------
    triangles : list of arrays
        List of triangle vertices at the finest level
    """
    if vertices is None:
        # Default equilateral triangle
        vertices = np.array([
            [0, 0],
            [1, 0],
            [0.5, np.sqrt(3)/2]
        ])
    
    if order == 0:
        return [vertices]
    
    # Compute midpoints
    v0, v1, v2 = vertices
    m01 = (v0 + v1) / 2
    m12 = (v1 + v2) / 2
    m20 = (v2 + v0) / 2
    
    # Three smaller triangles
    triangles = []
    triangles.extend(sierpinski_triangle(order - 1, np.array([v0, m01, m20])))
    triangles.extend(sierpinski_triangle(order - 1, np.array([m01, v1, m12])))
    triangles.extend(sierpinski_triangle(order - 1, np.array([m20, m12, v2])))
    
    return triangles

def chaos_game_sierpinski(n_points=10000):
    """
    Generate Sierpinski triangle using the chaos game.
    """
    # Triangle vertices
    vertices = np.array([
        [0, 0],
        [1, 0],
        [0.5, np.sqrt(3)/2]
    ])
    
    # Start at random point
    point = np.array([0.5, 0.25])
    points = []
    
    for _ in range(n_points):
        # Choose random vertex
        vertex = vertices[np.random.randint(0, 3)]
        # Move halfway to chosen vertex
        point = (point + vertex) / 2
        points.append(point.copy())
    
    return np.array(points)

def pascal_sierpinski(n_rows):
    """
    Generate Sierpinski triangle from Pascal's triangle mod 2.
    """
    # Compute Pascal's triangle mod 2
    pascal = [[1]]
    for i in range(1, n_rows):
        row = [1]
        for j in range(1, i):
            row.append((pascal[i-1][j-1] + pascal[i-1][j]) % 2)
        row.append(1)
        pascal.append(row)
    
    # Convert to points
    points = []
    for i, row in enumerate(pascal):
        for j, val in enumerate(row):
            if val == 1:
                # Position in triangular lattice
                x = j - i / 2
                y = -i
                points.append([x, y])
    
    return np.array(points)
