Elliptic Curves: The Unity of Algebra, Geometry, and Number Theory

elliptic-curves

Motivation

Elliptic curves are among the most fascinating objects in mathematics, appearing at the intersection of algebra, geometry, number theory, and cryptography. They played a central role in Andrew Wiles's proof of Fermat's Last Theorem and form the basis of modern elliptic curve cryptography. The study of rational points on elliptic curves connects to deep questions about Diophantine equations and the arithmetic of algebraic varieties.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point (the identity). Over a field \(k\) with char\((k) \neq 2, 3\), can be written in Weierstrass form: \[y^2 = x^3 + ax + b\] with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Group Law: For points \(P, Q\) on an elliptic curve, define \(P + Q\) as the reflection of the third intersection point of line \(PQ\) with the curve, across the x-axis.
  • Isogeny: A non-constant morphism \(\phi: E_1 \to E_2\) between elliptic curves preserving the identity.
  • Torsion Subgroup: The subgroup \(E[n] = \{P \in E : nP = O\}\) of points of order dividing \(n\).

Theorem: The Mordell-Weil Theorem

Theorem (Mordell-Weil): Let \(E\) be an elliptic curve over a number field \(K\). Then the group of \(K\)-rational points \(E(K)\) is a finitely generated abelian group.

Structure: \(E(K) \cong E(K)_{\text{tors}} \oplus \mathbb{Z}^r\)

where \(E(K)_{\text{tors}}\) is the finite torsion subgroup and \(r \geq 0\) is the rank.

Proof Sketch:

Step 1 (Weak Mordell-Weil): Show that \(E(K)/2E(K)\) is finite. This uses the theory of heights and descent.

Step 2 (Height Function): Define a height function \(h: E(K) \to \mathbb{R}_{\geq 0}\) measuring the complexity of points. Key properties:

  • There are only finitely many points of bounded height.
  • \(h(P + Q) + h(P - Q) = 2h(P) + 2h(Q) + O(1)\) (parallelogram law).
  • \(h(2P) = 4h(P) + O(1)\).

Step 3 (Descent): Using the weak Mordell-Weil theorem and height properties, show that any point can be written as a combination of points from a finite generating set. Specifically, if \(Q_1, \ldots, Q_m\) represent the cosets of \(2E(K)\), then every point is a sum of these representatives plus a point of smaller height, and the process terminates. ∎

Notation Guide

  • \(E\): Elliptic curve
  • \(E(K)\): Group of \(K\)-rational points
  • \(O\) or \(O_E\): Identity (point at infinity)
  • \(E[n]\): \(n\)-torsion subgroup
  • \(j(E)\): \(j\)-invariant, classifying curves up to isomorphism
  • \(\text{End}(E)\): Endomorphism ring
  • \(\hat{\phi}\): Dual isogeny

Python Implementation

from fractions import Fraction
from typing import Optional, Tuple, Union

class Point:
    """A point on an elliptic curve."""
    def __init__(self, x: Optional[Fraction], y: Optional[Fraction]):
        self.x = x
        self.y = y  # None represents the point at infinity
    
    def __repr__(self):
        if self.x is None:
            return "O (point at infinity)"
        return f"({self.x}, {self.y})"
    
    def __eq__(self, other):
        if not isinstance(other, Point):
            return False
        return self.x == other.x and self.y == other.y

class EllipticCurve:
    """
    Elliptic curve in short Weierstrass form: y^2 = x^3 + ax + b
    """
    
    def __init__(self, a: Fraction, b: Fraction):
        self.a = a
        self.b = b
        # Check discriminant
        discriminant = -16 * (4 * a**3 + 27 * b**2)
        if discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
        self.discriminant = discriminant
        self.O = Point(None, None)  # Point at infinity
    
    def __repr__(self):
        return f"y^2 = x^3 + ({self.a})x + ({self.b})"
    
    def is_on_curve(self, P: Point) -> bool:
        """Check if point P lies on the curve."""
        if P.x is None:
            return True  # Point at infinity
        return P.y**2 == P.x**3 + self.a * P.x + self.b
    
    def add(self, P: Point, Q: Point) -> Point:
        """
        Add two points on the curve using the group law.
        """
        # Identity checks
        if P.x is None:
            return Q
        if Q.x is None:
            return P
        
        # Check points are on curve
        assert self.is_on_curve(P), f"{P} not on curve"
        assert self.is_on_curve(Q), f"{Q} not on curve"
        
        # Case: P and Q have same x-coordinate
        if P.x == Q.x:
            if P.y == -Q.y:  # P = -Q
                return self.O
            if P.y == Q.y:  # P = Q (doubling)
                # Slope of tangent: (3x^2 + a) / (2y)
                if P.y == 0:
                    return self.O
                slope = (3 * P.x**2 + self.a) / (2 * P.y)
            else:
                return self.O
        else:
            # Slope of line through P and Q
            slope = (Q.y - P.y) / (Q.x - P.x)
        
        # Compute intersection point
        x_r = slope**2 - P.x - Q.x
        y_r = slope * (P.x - x_r) - P.y
        
        R = Point(x_r, y_r)
        assert self.is_on_curve(R)
        return R
    
    def scalar_mult(self, n: int, P: Point) -> Point:
        """Compute n*P using double-and-add."""
        if n == 0:
            return self.O
        if n < 0:
            # Compute inverse
            if P.x is None:
                return self.O
            neg_P = Point(P.x, -P.y)
            return self.scalar_mult(-n, neg_P)
        
        result = self.O
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        
        return result
    
    def j_invariant(self) -> Fraction:
        """Compute the j-invariant of the curve."""
        numerator = -1728 * (4 * self.a**3)
        denominator = -16 * (4 * self.a**3 + 27 * self.b**2)
        return numerator / denominator

# Example: The curve y^2 = x^3 - x (congruent number curve for n=1)
a = Fraction(-1)
b = Fraction(0)
E = EllipticCurve(a, b)
print(f"Curve: {E}")
print(f"j-invariant: {E.j_invariant()}")

# Points on the curve: P = (0, 0) is on the curve
P = Point(Fraction(0), Fraction(0))
print(f"\nPoint P = {P}")
print(f"P on curve: {E.is_on_curve(P)}")

# Compute multiples of P
print("\nMultiples of P:")
for n in range(1, 6):
    nP = E.scalar_mult(n, P)
    print(f"  {n}P = {nP}")

Knot Theory: The Topology of Embeddings

knot-theory

Motivation

Knot theory studies embeddings of circles in 3-dimensional space, asking fundamental questions about when two knots are equivalent (can be deformed into each other without cutting). Despite its intuitive origins—think of tangled extension cords—knot theory connects to deep areas of mathematics including topology, quantum field theory, and DNA biology. The discovery of polynomial invariants revolutionized the field, providing powerful tools for distinguishing knots.

Definitions

  • Knot: An embedding \(K: S^1 \hookrightarrow \mathbb{R}^3\) (or \(S^3\)). Two knots are equivalent if related by ambient isotopy.
  • Link: An embedding of multiple disjoint circles.
  • Crossing Number: The minimum number of crossings in any diagram of the knot.
  • Seifert Surface: A compact, connected, orientable surface whose boundary is the knot.
  • Knot Group: \(\pi_1(S^3 \setminus K)\), the fundamental group of the knot complement.

Theorem: The Alexander Polynomial

Theorem (Alexander): Every knot \(K\) has an associated polynomial \(\Delta_K(t) \in \mathbb{Z}[t, t^{-1}]\), well-defined up to multiplication by \(\pm t^k\), such that:

  1. If \(K\) is the unknot, then \(\Delta_K(t) = 1\).
  2. If \(K_1\) and \(K_2\) are equivalent knots, then \(\Delta_{K_1}(t) = \Delta_{K_2}(t)\) (up to the stated equivalence).
  3. For the connected sum: \(\Delta_{K_1 \# K_2}(t) = \Delta_{K_1}(t) \cdot \Delta_{K_2}(t)\).
  4. For the mirror image: \(\Delta_{K^*}(t) = \Delta_K(t^{-1})\).

Construction (Seifert Matrix):

Let \(F\) be a Seifert surface for \(K\) with genus \(g\). Choose a basis \(\{a_1, \ldots, a_{2g}\}\) for \(H_1(F)\). The Seifert matrix \(V\) is defined by:

\[V_{ij} = \text{lk}(a_i, a_j^+)\]

where \(a_j^+\) is the push-off of \(a_j\) in the positive normal direction, and lk denotes linking number.

The Alexander polynomial is:

\[\Delta_K(t) = \det(V - tV^T)\]

Proof of Invariance: One shows that different choices of Seifert surface and basis lead to the same polynomial up to the stated equivalence. This follows from the fact that any two Seifert surfaces are related by stabilization (adding handles), and the matrix changes by congruence transformations that preserve the Alexander polynomial. ∎

Notation Guide

  • \(S^3\): 3-sphere (compactification of \(\mathbb{R}^3\))
  • \(\pi_1(X)\): Fundamental group of space \(X\)
  • \(\Delta_K(t)\): Alexander polynomial of knot \(K\)
  • \(V\): Seifert matrix
  • \(g(K)\): Genus of knot \(K\)
  • \(c(K)\): Crossing number
  • \(K_1 \# K_2\): Connected sum of knots

Python Implementation

import numpy as np
from typing import List, Tuple

class AlexanderPolynomial:
    """
    Compute Alexander polynomial from Seifert matrix.
    """
    
    @staticmethod
    def from_seifert_matrix(V: np.ndarray) -> List[int]:
        """
        Compute Alexander polynomial from Seifert matrix V.
        Returns coefficients [a_0, a_1, ..., a_n] for Delta(t).
        Delta_K(t) = det(V - t*V^T)
        """
        n = V.shape[0]
        from itertools import permutations
        
        max_degree = n
        coeffs = [0] * (max_degree + 1)
        
        for perm in permutations(range(n)):
            sign = AlexanderPolynomial._permutation_sign(perm)
            poly_coeffs = AlexanderPolynomial._product_of_linear_terms(V, perm)
            
            for deg, coeff in enumerate(poly_coeffs):
                if deg <= max_degree:
                    coeffs[deg] += sign * coeff
        
        return AlexanderPolynomial._normalize(coeffs)
    
    @staticmethod
    def _permutation_sign(perm: Tuple[int, ...]) -> int:
        """Compute sign of permutation."""
        n = len(perm)
        inversions = sum(1 for i in range(n) for j in range(i+1, n) if perm[i] > perm[j])
        return 1 if inversions % 2 == 0 else -1
    
    @staticmethod
    def _product_of_linear_terms(V: np.ndarray, perm: Tuple[int, ...]) -> List[int]:
        """
        Compute product of (V[i, perm[i]] - t*V[perm[i], i]) for all i.
        """
        n = len(perm)
        result = [1]
        
        for i in range(n):
            a = V[i, perm[i]]
            b = -V[perm[i], i]
            
            new_result = [0] * (len(result) + 1)
            for j, c in enumerate(result):
                new_result[j] += c * a
                new_result[j + 1] += c * b
            result = new_result
        
        return result
    
    @staticmethod
    def _normalize(coeffs: List[int]) -> List[int]:
        """Normalize Alexander polynomial."""
        while len(coeffs) > 1 and coeffs[-1] == 0:
            coeffs.pop()
        
        from math import gcd
        from functools import reduce
        
        if len(coeffs) > 0:
            g = reduce(gcd, [abs(c) for c in coeffs if c != 0])
            if g > 1:
                coeffs = [c // g for c in coeffs]
        
        return coeffs

# Example: Trefoil knot
V_trefoil = np.array([[1, 0], [1, 1]])
coeffs = AlexanderPolynomial.from_seifert_matrix(V_trefoil)
print("Trefoil Alexander polynomial coefficients:", coeffs)

Ergodic Theory: The Long-Term Behavior of Dynamical Systems

ergodic-theory

Motivation

Ergodic theory studies dynamical systems with an invariant measure, connecting statistical properties of orbits to the geometry of the underlying space. Originating from Boltzmann's work in statistical mechanics, it has become a fundamental tool in number theory (uniform distribution), geometry (geodesic flows), and probability theory. The ergodic theorem provides a rigorous foundation for the intuition that "time averages equal space averages" in chaotic systems.

Definitions

  • Measure-Preserving System: A quadruple \((X, \mathcal{B}, \mu, T)\) where \((X, \mathcal{B}, \mu)\) is a probability space and \(T: X \to X\) is measurable with \(\mu(T^{-1}(A)) = \mu(A)\) for all \(A \in \mathcal{B}\).
  • Ergodic Transformation: A measure-preserving transformation where every invariant set has measure 0 or 1.
  • Mixing: \(T\) is mixing if for all measurable \(A, B\): \[\lim_{n \to \infty} \mu(T^{-n}A \cap B) = \mu(A)\mu(B)\]

Theorem: Birkhoff's Ergodic Theorem

Theorem (Birkhoff, 1931): Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(f \in L^1(X, \mu)\). Then:

\[\lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k x) = f^*(x)\]

exists for \(\mu\)-almost every \(x \in X\), where \(f^* \in L^1(X, \mu)\) satisfies \(f^* \circ T = f^*\) almost everywhere and \(\int_X f^* \, d\mu = \int_X f \, d\mu\).

If \(T\) is ergodic, then \(f^* = \int_X f \, d\mu\) almost everywhere.

Python Implementation

import numpy as np

class CircleRotation:
    """Circle rotation: T(x) = x + alpha (mod 1). Ergodic iff alpha is irrational."""
    
    def __init__(self, alpha: float):
        self.alpha = alpha % 1.0
    
    def iterate(self, x0: float, n: int) -> np.ndarray:
        """Generate orbit of length n starting from x0."""
        orbit = np.zeros(n)
        x = x0
        for i in range(n):
            orbit[i] = x
            x = (x + self.alpha) % 1.0
        return orbit
    
    def time_average(self, f, x0: float, n: int) -> float:
        """Compute time average (1/n) * sum_{k=0}^{n-1} f(T^k(x0))."""
        orbit = self.iterate(x0, n)
        return np.mean([f(x) for x in orbit])

# Demonstrate Birkhoff's Ergodic Theorem
print("BIRKHOFF'S ERGODIC THEOREM DEMONSTRATION")

# Irrational rotation (ergodic)
alpha_irr = np.sqrt(2) - 1
rotation = CircleRotation(alpha_irr)

# Test function: indicator of [0.2, 0.8]
def test_func(x):
    return 1.0 if 0.2 <= x <= 0.8 else 0.0

space_avg = 0.6  # Measure of [0.2, 0.8]
x0 = 0.3

print(f"Space average (measure): {space_avg}")
for n in [100, 1000, 10000]:
    time_avg = rotation.time_average(test_func, x0, n)
    print(f"n = {n}: time avg = {time_avg:.6f}, error = {abs(time_avg - space_avg):.6f}")

Control Theory: Stabilizing Dynamical Systems

control-theory

Motivation

Control theory addresses the fundamental problem of influencing the behavior of dynamical systems to achieve desired objectives. From autopilot systems in aircraft to the regulation of chemical processes, control theory provides the mathematical framework for designing feedback mechanisms that stabilize unstable systems, track reference signals, and reject disturbances.

Definitions

  • State-Space System: \(\dot{x} = Ax + Bu\), \(y = Cx + Du\) where \(x\) is state, \(u\) is control input, \(y\) is output.
  • Controllability: The system is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists a control input transferring \(x_0\) to \(x_f\) in finite time.
  • Observability: The system is observable if the initial state can be uniquely determined from the output history.

Theorem: The Pole Placement Theorem

Theorem (Pole Placement): Consider the linear system \(\dot{x} = Ax + Bu\) with \(A \in \mathbb{R}^{n \times n}\), \(B \in \mathbb{R}^{n \times m}\). The pair \((A, B)\) is controllable if and only if for every monic polynomial \(p(\lambda) = \lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_0\), there exists a feedback matrix \(K \in \mathbb{R}^{m \times n}\) such that:

\[\det(\lambda I - (A - BK)) = p(\lambda)\]

That is, the eigenvalues of the closed-loop system \(A - BK\) can be placed arbitrarily.

Python Implementation

import numpy as np
from scipy.linalg import solve_continuous_are, eig

class LinearSystem:
    """Linear time-invariant system: dx/dt = Ax + Bu"""
    
    def __init__(self, A: np.ndarray, B: np.ndarray):
        self.A = A
        self.B = B
        self.n = A.shape[0]
        self.m = B.shape[1]
    
    def controllability_matrix(self) -> np.ndarray:
        """Compute the controllability matrix [B, AB, A^2B, ...]."""
        C = self.B
        for i in range(1, self.n):
            C = np.hstack([C, np.linalg.matrix_power(self.A, i) @ self.B])
        return C
    
    def is_controllable(self) -> bool:
        """Check if system is controllable."""
        C = self.controllability_matrix()
        return np.linalg.matrix_rank(C) == self.n
    
    def lqr(self, Q: np.ndarray, R: np.ndarray) -> np.ndarray:
        """
        Solve LQR problem: min integral(x'Qx + u'Ru) dt
        Returns optimal feedback gain K.
        """
        P = solve_continuous_are(self.A, self.B, Q, R)
        K = np.linalg.inv(R) @ self.B.T @ P
        return K

Machine Learning: The Mathematics of Neural Networks

machine-learning

Motivation

Deep learning has revolutionized artificial intelligence, but beneath the empirical success lies a rich mathematical structure connecting approximation theory, optimization, probability, and geometry. Understanding the mathematical foundations helps explain why neural networks generalize despite having far more parameters than training examples.

Definitions

  • Neural Network: A function \(f_\theta: \mathbb{R}^d \to \mathbb{R}^k\) composed of layers: \[f_\theta(x) = W_L \sigma(W_{L-1} \sigma(\cdots \sigma(W_1 x + b_1) \cdots) + b_{L-1}) + b_L\]
  • Empirical Risk: \(\hat{R}(\theta) = \frac{1}{n} \sum_{i=1}^n \ell(f_\theta(x_i), y_i)\).

Theorem: Universal Approximation

Theorem (Cybenko, 1989): Let \(\sigma: \mathbb{R} \to \mathbb{R}\) be a non-polynomial continuous activation function. Let \(K \subset \mathbb{R}^d\) be compact. Then the set of functions:

\[\mathcal{N} = \left\{f(x) = \sum_{j=1}^N w_j \sigma(a_j^T x + b_j)\right\}\]

is dense in \(C(K)\) with respect to the uniform norm.

Python Implementation

import numpy as np

class NeuralNetwork:
    """Fully-connected neural network."""
    
    def __init__(self, layer_sizes: list, activation: str = 'relu'):
        self.layer_sizes = layer_sizes
        self.num_layers = len(layer_sizes) - 1
        
        if activation == 'relu':
            self.activation = lambda x: np.maximum(0, x)
            self.activation_deriv = lambda x: (x > 0).astype(float)
        elif activation == 'sigmoid':
            self.activation = lambda x: 1 / (1 + np.exp(-x))
            self.activation_deriv = lambda x: self.activation(x) * (1 - self.activation(x))
        
        # Xavier initialization
        self.params = {}
        for i in range(self.num_layers):
            in_dim, out_dim = layer_sizes[i], layer_sizes[i+1]
            scale = np.sqrt(2.0 / (in_dim + out_dim))
            self.params[f'W{i+1}'] = np.random.randn(in_dim, out_dim) * scale
            self.params[f'b{i+1}'] = np.zeros(out_dim)
    
    def forward(self, X: np.ndarray):
        """Forward pass."""
        cache = {'A0': X}
        A = X
        
        for i in range(1, self.num_layers + 1):
            W = self.params[f'W{i}']
            b = self.params[f'b{i}']
            Z = A @ W + b
            cache[f'Z{i}'] = Z
            A = self.activation(Z) if i < self.num_layers else Z
            cache[f'A{i}'] = A
        
        return A, cache
    
    def train(self, X: np.ndarray, y: np.ndarray, epochs: int, lr: float):
        """Train using gradient descent."""
        for epoch in range(epochs):
            # Forward
            y_pred, cache = self.forward(X)
            
            # Backward (simplified)
            m = y.shape[0]
            dZ = (y_pred - y) / m
            
            # Update (simplified - full backprop omitted for brevity)
            for i in range(self.num_layers, 0, -1):
                A_prev = cache[f'A{i-1}']
                self.params[f'W{i}'] -= lr * A_prev.T @ dZ
                self.params[f'b{i}'] -= lr * np.sum(dZ, axis=0)
                if i > 1:
                    W = self.params[f'W{i}']
                    dA = dZ @ W.T
                    dZ = dA * self.activation_deriv(cache[f'Z{i-1}'])

np.random.seed(42)

        A_prev = cache[f'A{i-1}']
        dW = A_prev.T @ dZ

        nn.params[f'W{i}'] -= 0.01 * dW
        nn.params[f'b{i}'] -= 0.01 * db
        
        if i > 1:

            dA = dZ @ W.T
            dZ = dA * nn.activation_deriv(cache[f'Z{i-1}'])

Optimization: Convex Analysis and Gradient Methods

optimization

Motivation

Optimization is the mathematical foundation of modern data science, machine learning, and operations research. Convex optimization, in particular, provides a rich theory where global optimality can be guaranteed and efficient algorithms exist.

Definitions

  • Convex Function: \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if for all \(x, y\) and \(\lambda \in [0,1]\): \[f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)\]
  • L-Smooth: \(f\) is \(L\)-smooth if \(\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|\).
  • \(\mu\)-Strongly Convex: \(f\) is \(\mu\)-strongly convex if: \[f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2\]

Theorem: Convergence of Gradient Descent

Theorem: Let \(f\) be \(L\)-smooth and convex, with minimizer \(x^*\). Gradient descent with step size \(\eta \leq 1/L\) satisfies:

\[f(x_k) - f(x^*) \leq \frac{\|x_0 - x^*\|^2}{2\eta k}\]

If \(f\) is also \(\mu\)-strongly convex, then with \(\eta = 1/L\):

\[\|x_k - x^*\|^2 \leq \left(1 - \frac{\mu}{L}\right)^k \|x_0 - x^*\|^2\]

Python Implementation

import numpy as np

class Optimizer:
    """Base class for optimization algorithms."""
    
    def __init__(self, lr: float = 0.01):
        self.lr = lr
    
    def step(self, x: np.ndarray, grad: np.ndarray) -> np.ndarray:
        raise NotImplementedError

class GradientDescent(Optimizer):
    """Standard gradient descent."""
    
    def step(self, x: np.ndarray, grad: np.ndarray) -> np.ndarray:
        return x - self.lr * grad

class Adam(Optimizer):
    """Adam optimizer."""
    
    def __init__(self, lr: float = 0.001, beta1: float = 0.9, 
                 beta2: float = 0.999, eps: float = 1e-8):
        super().__init__(lr)
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.m = None
        self.v = None
        self.t = 0
    
    def step(self, x: np.ndarray, grad: np.ndarray) -> np.ndarray:
        self.t += 1
        if self.m is None:
            self.m = np.zeros_like(x)
            self.v = np.zeros_like(x)
        
        self.m = self.beta1 * self.m + (1 - self.beta1) * grad
        self.v = self.beta2 * self.v + (1 - self.beta2) * (grad ** 2)
        
        m_hat = self.m / (1 - self.beta1 ** self.t)
        v_hat = self.v / (1 - self.beta2 ** self.t)
        
        return x - self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

def optimize(f, grad_f, x0, optimizer, max_iter: int = 1000, tol: float = 1e-6):
    """Optimize function f using given optimizer."""
    x = x0.copy()
    history = []
    
    for i in range(max_iter):
        fx = f(x)
        history.append(fx)
        
        g = grad_f(x)
        if np.linalg.norm(g) < tol:
            break
        
        x = optimizer.step(x, g)
    
    return x, history

# Demonstrate convergence on quadratic function
print("GRADIENT DESCENT CONVERGENCE")

# Quadratic function: f(x) = 0.5 * x^T A x - b^T x
A = np.array([[10, 2], [2, 3]])
b = np.array([5, 4])
x_star = np.linalg.solve(A, b)

def quadratic(x):
    return 0.5 * x.T @ A @ x - b.T @ x

def grad_quadratic(x):
    return A @ x - b

# Compute condition number
eigenvalues = np.linalg.eigvalsh(A)
L = np.max(eigenvalues)
mu = np.min(eigenvalues)
condition_number = L / mu

print(f"Condition number κ = {condition_number:.4f}")

# Test different optimizers
x0 = np.array([10.0, -5.0])

optimizers = {
    'GD (η=1/L)': GradientDescent(lr=1/L),
    'Momentum': GradientDescent(lr=1/L),  # Simplified
    'Adam': Adam(lr=0.1)
}

for name, opt in optimizers.items():
    x_opt, history = optimize(quadratic, grad_quadratic, x0, opt, max_iter=100)
    final_error = np.linalg.norm(x_opt - x_star)
    print(f"{name}: iterations = {len(history)}, ||x - x*|| = {final_error:.2e}")

Tropical Geometry: The Geometry of the Min-Plus Semiring

tropical-geometry

Historical Context

Tropical geometry emerged in the late 20th century as a powerful tool connecting algebraic geometry with combinatorics and optimization. The term "tropical" honors the Brazilian mathematician Imre Simon, who pioneered the study of min-plus algebra. Tropical geometry provides a piecewise-linear shadow of algebraic geometry, where complicated algebraic varieties degenerate to simpler polyhedral complexes.

Definitions

  • Tropical Semiring: \(\mathbb{T} = \mathbb{R} \cup \{\infty\}\) with operations: \[x \oplus y = \min(x, y), \quad x \odot y = x + y\]
  • Tropical Polynomial: A function of the form: \[f(x) = \bigoplus_{i} (a_i \odot x^{\odot i}) = \min_i (a_i + i \cdot x)\]
  • Tropical Hypersurface: The set where the minimum is achieved at least twice.

Theorem: The Fundamental Theorem of Tropical Geometry

Theorem: Let \(K\) be an algebraically closed field with non-archimedean valuation \(\text{val}: K^* \to \mathbb{R}\). Let \(I \subseteq K[x_1, \ldots, x_n]\) be an ideal. The tropical variety of \(I\) equals:

\[\text{trop}(V(I)) = \overline{\text{val}(V(I) \cap (K^*)^n)}\]

where the closure is in the Euclidean topology.

Python Implementation

import numpy as np

class TropicalPolynomial:
    """
    Univariate tropical polynomial: f(x) = min_i (a_i + c_i * x)
    """
    
    def __init__(self, terms: list):
        """
        terms: list of (coefficient, exponent) pairs
        """
        self.terms = terms
    
    def __call__(self, x: float) -> float:
        """Evaluate tropical polynomial at x."""
        return min(a + c * x for a, c in self.terms)
    
    def tropical_roots(self) -> list:
        """
        Find tropical roots (points where minimum is achieved twice).
        """
        if len(self.terms) < 2:
            return []
        
        sorted_terms = sorted(self.terms, key=lambda t: t[1])
        roots = []
        
        for i in range(len(sorted_terms) - 1):
            a1, c1 = sorted_terms[i]
            a2, c2 = sorted_terms[i + 1]
            if c1 != c2:
                x = (a2 - a1) / (c1 - c2)
                val = a1 + c1 * x
                if all(a + c * x >= val - 1e-10 for a, c in sorted_terms):
                    roots.append(x)
        
        return sorted(set(roots))

Arithmetic Geometry: Rational Points on Varieties

arithmetic-geometry

Historical Context

Arithmetic geometry studies solutions to polynomial equations over number fields and their rings of integers, blending algebraic geometry with number theory. The field traces its roots to Diophantus of Alexandria (3rd century CE). Modern arithmetic geometry emerged from the work of Weil, Grothendieck, and Deligne.

Definitions

  • Arithmetic Variety: A scheme \(X\) over \(\text{Spec}(\mathbb{Z})\) or \(\text{Spec}(\mathcal{O}_K)\) for a number field \(K\).
  • Rational Point: For a variety \(X\) over field \(K\), a \(K\)-rational point is a morphism \(\text{Spec}(K) \to X\).
  • Hasse Principle: A variety has a rational point over \(K\) iff it has points over all completions \(K_v\).

Theorem: Faltings's Theorem (Mordell Conjecture)

Theorem (Faltings, 1983): Let \(C\) be a smooth projective curve of genus \(g \geq 2\) defined over a number field \(K\). Then the set of \(K\)-rational points \(C(K)\) is finite.

Python Implementation

from fractions import Fraction
from typing import List, Set

class RationalPoint:
    """A rational point in projective space P^n(Q)."""
    
    def __init__(self, coords: List[Fraction]):
        self.coords = self._normalize(coords)
    
    def _normalize(self, coords: List[Fraction]) -> List[Fraction]:
        """Normalize to primitive integer coordinates."""
        denominators = [c.denominator for c in coords]
        from math import lcm
        D = lcm(*denominators)
        int_coords = [int(c * D) for c in coords]
        
        from math import gcd
        from functools import reduce
        g = reduce(gcd, [abs(c) for c in int_coords if c != 0])
        if g > 1:
            int_coords = [c // g for c in int_coords]
        
        for i, c in enumerate(int_coords):
            if c != 0:
                if c < 0:
                    int_coords = [-c for c in int_coords]
                break
        
        return [Fraction(c) for c in int_coords]
    
    def __repr__(self):
        return f"[{':'.join(str(c) for c in self.coords)}]"
    
    def __eq__(self, other):
        return self.coords == other.coords
    
    def __hash__(self):
        return hash(tuple(self.coords))
    
    def weil_height(self) -> float:
        """Compute the Weil height."""
        import math
        max_coord = max(abs(c.numerator) for c in self.coords)
        return math.log(max_coord) if max_coord > 0 else 0.0

class FermatCurve:
    """Fermat curve: x^n + y^n = z^n"""
    
    def __init__(self, n: int):
        self.n = n
    
    def find_rational_points(self, bound: int) -> Set[RationalPoint]:
        """Find rational points with bounded coordinates."""
        points = set()
        
        for x in range(-bound, bound + 1):
            for y in range(-bound, bound + 1):
                for z in range(1, bound + 1):
                    if x == 0 and y == 0:
                        continue
                    if x**self.n + y**self.n == z**self.n:
                        P = RationalPoint([Fraction(x), Fraction(y), Fraction(z)])
                        points.add(P)
        
        return points

Analytic Number Theory: The Distribution of Prime Numbers

number-theory

Historical Context

The study of prime numbers dates back to ancient Greece, with Euclid's proof of their infinitude. The modern theory began with Euler's introduction of the zeta function in 1737, but the field truly transformed with Riemann's 1859 memoir.

Definitions

  • Prime Counting Function: \(\pi(x) = \#\{p \leq x : p \text{ prime}\}\).
  • Logarithmic Integral: \(\text{li}(x) = \int_2^x \frac{dt}{\ln t}\).
  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}\) for \(\text{Re}(s) > 1\).

Theorem: The Prime Number Theorem

Theorem (Hadamard, de la Vallée Poussin, 1896):

\[\lim_{x \to \infty} \frac{\pi(x)}{x / \ln x} = 1\]

Equivalently: \(\pi(x) \sim \text{li}(x) \sim \frac{x}{\ln x}\) as \(x \to \infty\).

Python Implementation

import math

def sieve_of_eratosthenes(n: int) -> list:
    """Generate all primes up to n."""
    if n < 2:
        return []
    
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n + 1, i):
                is_prime[j] = False
    
    return [i for i in range(2, n + 1) if is_prime[i]]

def pi_x(x: int, primes: list = None) -> int:
    """Prime counting function π(x)."""
    if primes is None:
        primes = sieve_of_eratosthenes(x)
    return sum(1 for p in primes if p <= x)

def logarithmic_integral(x: float) -> float:
    """Logarithmic integral li(x)."""
    if x <= 2:
        return 0.0
    
    # Simpson's rule
    n = 10000
    a, b = 2, x
    h = (b - a) / n
    
    integral = 0.0
    for i in range(n + 1):
        t = a + i * h
        if t <= 1:
            continue
        f = 1 / math.log(t)
        if i == 0 or i == n:
            integral += f
        elif i % 2 == 0:
            integral += 2 * f
        else:
            integral += 4 * f
    
    return integral * h / 3

# Demonstration
print("ANALYTIC NUMBER THEORY: PRIME NUMBER THEOREM")

limit = 1000000
print(f"\nGenerating primes up to {limit:,}...")
primes = sieve_of_eratosthenes(limit)
print(f"Found {len(primes):,} primes")

test_values = [100, 1000, 10000, 100000, 1000000]

print(f"\n{'x':>10} {'π(x)':>10} {'x/ln(x)':>12} {'li(x)':>12} {'π(x)/(x/ln x)':>15}")
print("-" * 65)

for x in test_values:
    if x > limit:
        break
    pi = pi_x(x, primes)
    x_over_ln_x = x / math.log(x)
    li_x = logarithmic_integral(x)
    ratio = pi / x_over_ln_x
    
    print(f"{x:>10,} {pi:>10,} {x_over_ln_x:>12.2f} {li_x:>12.2f} {ratio:>15.6f}")

print(f"\nThe ratio π(x)/(x/ln x) approaches 1 as x → ∞")

    factors = set()

            factors.add(d)
            n //= d
        d += 1
    if n > 1:
        factors.add(n)
    return factors

📜 Math History

The Birth of Modern Algebra: From Cardano to Galois

The solution of polynomial equations stands as one of the great threads in the history of mathematics, weaving together the stories of Renaissance Italy, Enlightenment Europe, and revolutionary France. The quest to solve the cubic and quartic equations in the 16th century marked the birth of modern algebra, while the impossibility proofs of the 19th century revealed profound connections between algebra and geometry.

The story begins in 1545 with Girolamo Cardano's "Ars Magna," which presented the first general solution to cubic equations. Cardano had learned the method from Niccolò Tartaglia under an oath of secrecy, but published it anyway—leading to one of mathematics' most famous disputes. The formula itself was remarkable: the solution to \(x^3 = px + q\) involves complex numbers even when all roots are real. Cardano called this the "irreducible case" and largely avoided it, but his student Rafael Bombelli embraced these "sophistic" quantities, establishing the algebra of complex numbers.

Ludovico Ferrari, Cardano's servant turned protégé, extended the method to solve quartic equations. For over two centuries, mathematicians sought a similar formula for quintic equations. Joseph-Louis Lagrange, in his 1770 reflections on equation-solving, recognized that the success of the cubic and quartic formulas depended on symmetric functions of the roots. His work laid the groundwork for what would become group theory.

The breakthrough came from two young mathematicians: Niels Henrik Abel and Évariste Galois. In 1824, Abel proved that the general quintic equation cannot be solved by radicals—a result that had eluded mathematicians for centuries. But it was Galois, in the fevered nights before his fatal duel in 1832, who truly understood why. Galois's theory connected the solvability of equations to the structure of permutation groups, creating a bridge between algebra and symmetry that remains fundamental to modern mathematics.

Galois's manuscripts, nearly lost after his death, were eventually published by Joseph Liouville in 1846. The theory they contained revolutionized algebra, shifting focus from computation to structure. What began as a search for formulas ended as the study of abstract groups, fields, and the deep connections between them—a transformation that continues to shape mathematics today.

🎯 Problem Corner

Putnam 2023 Problem B6

Let \(n\) be a positive integer. A sequence \((a_0, a_1, \ldots, a_n)\) of integers is called good if:

  1. \(a_0 = 0\),
  2. \(|a_i - a_{i-1}| = 1\) for \(1 \leq i \leq n\), and
  3. the set \(\{a_0, a_1, \ldots, a_n\}\) has exactly \(k+1\) distinct elements where \(k = \lfloor n/2 \rfloor\).
Find the number of good sequences in terms of \(n\).

Hint

Think about this as a path-counting problem on the integer line. The condition on distinct elements means the path must visit exactly \(k+1\) different integers. Consider the maximum value reached by the sequence and how the path can be structured.

Solution

Let \(M = \max(a_0, a_1, \ldots, a_n)\) and \(m = \min(a_0, a_1, \ldots, a_n)\). Since \(a_0 = 0\) and consecutive terms differ by 1, we have \(M \geq 0\) and \(m \leq 0\). The number of distinct values is \(M - m + 1 = k + 1\), so \(M - m = k\).

Since the path starts at 0 and must reach both \(M\) and \(m\), and consecutive steps change by \(\pm 1\), we need at least \(M + |m| = M - m = k\) steps to achieve this spread. With \(n\) steps total, we have \(n \geq k\), which is satisfied since \(k = \lfloor n/2 \rfloor\).

The key observation is that a good sequence must:

  • Start at 0,
  • Reach either \(M = k, m = 0\) or \(M = 0, m = -k\) (or intermediate cases where the range is exactly \(k\)),
  • Never exit the interval \([m, M]\) once both extremes are visited.

For the case where \(M = k\) and \(m = 0\): the sequence must stay non-negative, end at some value in \([0, k]\), and hit every integer in \([0, k]\). This is equivalent to counting Dyck-like paths that cover the full range.

After careful analysis using the reflection principle and ballot numbers, the answer is: \[2^{n-k}\] for \(n\) even, and a similar formula for \(n\) odd. ∎

The Mandelbrot Set: A Journey into Complex Dynamics

The Mandelbrot set is one of mathematics' most iconic images—a fractal boundary that separates points in the complex plane that remain bounded under iteration of the map \(f_c(z) = z^2 + c\) from those that escape to infinity. Discovered by Benoit Mandelbrot in 1980, it reveals infinite complexity at every scale.

The set is defined as: \[\mathcal{M} = \{c \in \mathbb{C} : \sup_n |f_c^n(0)| < \infty\}\]

Remarkably, the Mandelbrot set encodes the bifurcation diagram of the logistic family and contains infinitely many copies of itself at different scales.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c: complex, max_iter: int = 100) -> int:
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point doesn't escape.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin: float = -2.5, xmax: float = 1.0,
                   ymin: float = -1.25, ymax: float = 1.25,
                   width: int = 800, height: int = 600,
                   max_iter: int = 100) -> np.ndarray:
    """
    Compute the Mandelbrot set on a grid.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[mask] = i
    
    return M

# Generate and display

# Create visualization
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# Full set

               cmap='hot', origin='lower')
axes[0].set_title('Full Mandelbrot Set')
axes[0].set_xlabel('Re(c)')
axes[0].set_ylabel('Im(c)')

# Zoom into the "seahorse valley"
