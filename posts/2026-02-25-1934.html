Sheaf Cohomology

Motivation: Sheaf cohomology provides a unified framework for understanding local-to-global problems in geometry and topology. It generalizes the Čech cohomology of open covers and connects to de Rham cohomology, singular cohomology, and algebraic geometry.

Definitions

  • Sheaf: A sheaf \( \mathcal{F} \) on a topological space \( X \) assigns to each open set \( U \subseteq X \) an abelian group \( \mathcal{F}(U) \) (called sections), with restriction maps satisfying locality and gluing axioms.
  • Stalk: The stalk at \( x \in X \) is \( \mathcal{F}_x = \varinjlim_{U \ni x} \mathcal{F}(U) \), the direct limit over open neighborhoods.
  • Injective Resolution: An exact sequence \( 0 \to \mathcal{F} \to \mathcal{I}^0 \to \mathcal{I}^1 \to \mathcal{I}^2 \to \cdots \) where each \( \mathcal{I}^i \) is an injective sheaf.

Theorem: Existence of Sheaf Cohomology

For any sheaf \( \mathcal{F} \) on a paracompact Hausdorff space \( X \), there exist functors \( H^i(X, \mathcal{F}) \) for \( i \geq 0 \) such that:

  1. \( H^0(X, \mathcal{F}) = \Gamma(X, \mathcal{F}) \) (global sections)
  2. Short exact sequences of sheaves induce long exact sequences in cohomology
  3. If \( \mathcal{I} \) is injective, then \( H^i(X, \mathcal{I}) = 0 \) for \( i > 0 \)

Proof Sketch: Define \( H^i(X, \mathcal{F}) = H^i(\Gamma(X, \mathcal{I}^\bullet)) \) where \( \mathcal{I}^\bullet \) is an injective resolution. The properties follow from homological algebra: property (1) from left-exactness of global sections, property (2) from the snake lemma applied to short exact sequences of resolutions, and property (3) from the definition using injective resolutions.

Notation Guide

  • \( \mathcal{F} \) — a sheaf of abelian groups
  • \( \Gamma(X, \mathcal{F}) \) or \( H^0(X, \mathcal{F}) \) — global sections
  • \( H^i(X, \mathcal{F}) \) — sheaf cohomology groups
  • \( \mathcal{F}_x \) — stalk at point \( x \)
  • \( \varinjlim \) — direct limit (colimit)

import numpy as np
from itertools import combinations

def sheaf_cohomology_simplicial(vertex_count, edges, coefficients='Z'):
    """
    Compute simplicial cohomology as a toy model for sheaf cohomology.
    
    Parameters:
    -----------
    vertex_count : int
        Number of vertices
    edges : list of tuples
        List of edges (i, j) with i < j
    coefficients : str
        'Z' for integers, 'Z2' for Z/2Z
    
    Returns:
    --------
    dict with Betti numbers
    """
    # Build boundary matrices
    # d_0: C^0 -> C^1 (vertex to edge)
    d0 = np.zeros((len(edges), vertex_count), dtype=int)
    for i, (v1, v2) in enumerate(edges):
        d0[i, v1] = 1
        d0[i, v2] = -1
    
    if coefficients == 'Z2':
        d0 = d0 % 2
    
    # Compute ranks (over Q for Z, over F2 for Z2)
    rank_d0 = np.linalg.matrix_rank(d0)
    
    # H^0 = ker(d_0), dimension = nullity of d0
    # For connected graph: dim H^0 = 1
    dim_C0 = vertex_count
    dim_H0 = dim_C0 - rank_d0
    
    # H^1 = C^1 / im(d_0), dimension = dim C^1 - rank(d0)
    dim_C1 = len(edges)
    dim_H1 = dim_C1 - rank_d0
    
    # Euler characteristic
    euler = dim_H0 - dim_H1
    
    return {
        'betti_0': dim_H0,
        'betti_1': dim_H1,
        'euler_characteristic': euler,
        'rank_d0': rank_d0
    }

The Atiyah-Singer Index Theorem

Motivation: The index theorem connects analysis (solutions to differential equations) with topology (characteristic classes). It generalizes classical results like the Riemann-Roch theorem and provides deep insights into the relationship between local and global properties of manifolds.

Definitions

  • Elliptic Operator: A differential operator \( D: \Gamma(E) \to \Gamma(F) \) between vector bundles whose principal symbol \( \sigma(D) \) is invertible for all non-zero cotangent vectors.
  • Analytic Index: \( \text{ind}(D) = \dim \ker D - \dim \text{coker} D \)
  • Topological Index: Defined via K-theory and the Chern character, involving the Todd class of the tangent bundle.

Theorem: Atiyah-Singer Index Theorem

For an elliptic differential operator \( D \) on a compact oriented manifold \( M \):

\[ \text{ind}(D) = \int_M \text{ch}(E) \cdot \text{td}(TM) \cdot \text{ch}(\sigma(D))^{-1} \]

where \( \text{ch} \) is the Chern character and \( \text{td} \) is the Todd class.

Special Case (Gauss-Bonnet): For the de Rham operator, this reduces to:

\[ \chi(M) = \frac{1}{2\pi} \int_M K \, dA \]

where \( \chi(M) \) is the Euler characteristic and \( K \) is Gaussian curvature.

Notation Guide

  • \( D \) — elliptic differential operator
  • \( \text{ind}(D) \) — Fredholm index
  • \( \text{ch}(E) \) — Chern character of bundle \( E \)
  • \( \text{td}(TM) \) — Todd class of tangent bundle
  • \( \sigma(D) \) — principal symbol

import numpy as np

def euler_characteristic_surface(genus, boundary_components=0, cones=0):
    """
    Compute Euler characteristic for surfaces using classification.
    
    For a compact surface:
    χ = 2 - 2g - b  (orientable, no cones)
    χ = 2 - k - b   (non-orientable, k = crosscaps)
    
    Parameters:
    -----------
    genus : int
        Genus (number of handles for orientable, crosscaps for non-orientable)
    boundary_components : int
        Number of boundary circles
    cones : int
        Number of cone points (for orbifolds)
    
    Returns:
    --------
    int : Euler characteristic
    """
    # Orientable case
    chi = 2 - 2 * genus - boundary_components
    
    # For orbifold: each cone of order n contributes (1/n - 1)
    # Simplified: assume all cones have order 2
    chi += cones * (-0.5)
    
    return chi

def index_dolbeault(genus):
    """
    Index of Dolbeault operator on Riemann surface of genus g.
    By Riemann-Roch: dim H^0(L) - dim H^1(L) = deg(L) + 1 - g
    
    For trivial line bundle: index = 1 - g
    """
    return 1 - genus

Class Field Theory

Motivation: Class field theory describes all abelian extensions of a number field (or local field) in terms of intrinsic data of the field itself. It generalizes the Kronecker-Weber theorem and provides the foundation for modern algebraic number theory.

Definitions

  • Ray Class Group: For a modulus \( \mathfrak{m} \), the ray class group \( \text{Cl}_\mathfrak{m}(K) \) generalizes the ideal class group by incorporating information about ramification at infinite places.
  • Artin Map: A homomorphism \( \psi_{L/K}: \text{Cl}_\mathfrak{m}(K) \to \text{Gal}(L/K) \) for abelian extensions \( L/K \).
  • Conductor: The minimal modulus \( \mathfrak{f}(L/K) \) such that \( L \) is contained in the ray class field of \( \mathfrak{f} \).

Theorem: Artin Reciprocity

Let \( L/K \) be an abelian extension of number fields. There exists a modulus \( \mathfrak{m} \) divisible by all ramified primes such that the Artin map induces an isomorphism:

\[ \text{Cl}_\mathfrak{m}(K) / N_{L/K}(\text{Cl}_\mathfrak{m}(L)) \cong \text{Gal}(L/K) \]

Existence Theorem: For every modulus \( \mathfrak{m} \) and every subgroup \( H \subseteq \text{Cl}_\mathfrak{m}(K) \), there exists a unique abelian extension \( L/K \) with \( \text{Gal}(L/K) \cong \text{Cl}_\mathfrak{m}(K)/H \).

Notation Guide

  • \( K, L \) — number fields with \( L/K \) extension
  • \( \text{Gal}(L/K) \) — Galois group
  • \( \mathfrak{m} \) — modulus (formal product of primes)
  • \( \text{Cl}_\mathfrak{m}(K) \) — ray class group
  • \( \left( \frac{L/K}{\mathfrak{p}} \right) \) — Artin symbol

import math

def kronecker_symbol(a, n):
    """
    Compute the Kronecker symbol (a/n), generalization of Legendre symbol.
    Used in quadratic reciprocity and class field theory for Q.
    """
    if n == 1:
        return 1
    if n == 0:
        return 0 if abs(a) != 1 else 1
    if n == -1:
        return -1 if a < 0 else 1
    
    # Factor out powers of 2
    v2 = 0
    while n % 2 == 0:
        n //= 2
        v2 += 1
    
    result = 1
    
    # Handle factor of 2
    if v2 > 0:
        if a % 2 == 0:
            result = 0
        else:
            # (2/a) = (-1)^((a²-1)/8)
            result = (-1) ** ((a*a - 1) // 8)
            if v2 > 1:
                result **= v2
    
    # Odd part - use quadratic reciprocity
    a = a % n
    while a != 0:
        while a % 2 == 0:
            a //= 2
            # (2/n) = (-1)^((n²-1)/8)
            result *= (-1) ** ((n*n - 1) // 8)
        
        # Quadratic reciprocity: (a/n)(n/a) = (-1)^((a-1)(n-1)/4)
        result *= (-1) ** ((a - 1) * (n - 1) // 4)
        a, n = n % a, a
    
    return result if n == 1 else 0

Generative Adversarial Networks (GANs)

Real-World Motivation: GANs have revolutionized computer vision, enabling realistic image synthesis, style transfer, and data augmentation. They represent a game-theoretic approach to learning generative models, with applications in art, medicine, and scientific simulation.

Definitions

  • Generator \( G \): Maps latent noise \( z \sim p_z \) to data space: \( G(z; \theta_g) \)
  • Discriminator \( D \): Outputs probability that input is real: \( D(x; \theta_d) \in [0,1] \)
  • Value Function: The two-player minimax game: \[ \min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}} [\log D(x)] + \mathbb{E}_{z \sim p_z} [\log(1 - D(G(z)))] \]

Theorem: Global Optimality

For a fixed generator \( G \), the optimal discriminator is:

\[ D^*_G(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)} \]

The global minimum of the virtual training criterion is achieved if and only if \( p_g = p_{\text{data}} \), at which point the value is \( -\log 4 \).

Proof Sketch: For fixed \( G \), maximize: \[ V(G, D) = \int p_{\text{data}}(x) \log D(x) + p_g(x) \log(1 - D(x)) \, dx \]

Pointwise maximization gives \( D^*_G \). Substituting back: \[ C(G) = -\log 4 + 2 \cdot JSD(p_{\text{data}} \| p_g) \]

where \( JSD \) is the Jensen-Shannon divergence, minimized (at 0) iff \( p_g = p_{\text{data}} \).

Notation Guide

  • \( p_{\text{data}} \) — data distribution
  • \( p_g \) — generator distribution
  • \( p_z \) — prior on latent space
  • \( JSD(P \| Q) \) — Jensen-Shannon divergence
  • \( \theta_g, \theta_d \) — network parameters

def generator_loss(d_fake):
    """
    Non-saturating generator loss: -log(D(G(z)))
    More stable than original log(1-D(G(z)))
    """
    return -np.mean(np.log(d_fake + 1e-8))

def discriminator_loss(d_real, d_fake):
    """
    Discriminator loss: -log(D(x)) - log(1-D(G(z)))
    """
    return -np.mean(np.log(d_real + 1e-8) + np.log(1 - d_fake + 1e-8))

def js_divergence(p, q):
    """
    Jensen-Shannon divergence between distributions p and q.
    JSD(P||Q) = 0.5*KL(P||M) + 0.5*KL(Q||M) where M = 0.5*(P+Q)
    """
    m = 0.5 * (p + q)
    # Avoid log(0)
    p_safe = np.clip(p, 1e-10, 1)
    q_safe = np.clip(q, 1e-10, 1)
    m_safe = np.clip(m, 1e-10, 1)
    
    kl_p = np.sum(p * np.log(p_safe / m_safe))
    kl_q = np.sum(q * np.log(q_safe / m_safe))
    
    return 0.5 * (kl_p + kl_q)

    """
    Optimal discriminator D*(x) = p_data(x) / (p_data(x) + p_g(x))

    return p_data / (p_data + p_g + 1e-10)

Mean Field Games

Real-World Motivation: Mean field games model strategic interactions among a large number of small agents. Applications include traffic flow, crowd dynamics, economics (market equilibrium), and energy systems (smart grids). The theory provides tractable approximations when agent count approaches infinity.

Definitions

  • Mean Field: The distribution \( m(t, x) \) of agents over state space at time \( t \).
  • Value Function: \( u(t, x) \) represents the optimal cost-to-go for an agent at position \( x \) and time \( t \).
  • Hamiltonian: \( H(x, \nabla u, m) = \inf_\alpha \{ L(x, \alpha) + \alpha \cdot \nabla u \} \) where \( L \) is the running cost.

Theorem: MFG System

The Nash equilibrium of the mean field game is characterized by the coupled PDE system:

\[ -\partial_t u - \nu \Delta u + H(x, \nabla u, m) = 0, \quad u(T, x) = g(x, m(T)) \]

\[ \partial_t m - \nu \Delta m - \text{div}(m \nabla_p H(x, \nabla u, m)) = 0, \quad m(0, x) = m_0(x) \]

Interpretation: The first equation (backward) is the Hamilton-Jacobi-Bellman equation for optimal control. The second equation (forward) is the Fokker-Planck equation describing mass transport under the optimal feedback control.

Notation Guide

  • \( u(t, x) \) — value function
  • \( m(t, x) \) — mean field (agent density)
  • \( H \) — Hamiltonian
  • \( \nu \) — viscosity/diffusion coefficient
  • \( \nabla_p H \) — gradient of H with respect to momentum

import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

def solve_linear_quadratic_mfg(T, dt, dx, nu, sigma, r):
    """
    Solve linear-quadratic mean field game.
    
    Model:
    - Dynamics: dX_t = α_t dt + σ dW_t
    - Cost: E[∫(α²/2 + r(X - m̄)²/2)dt + g(X_T)]
    
    Parameters:
    -----------
    T : float
        Terminal time
    dt : float
        Time step
    dx : float
        Space step
    nu : float
        Viscosity (σ²/2)
    sigma : float
        Noise intensity
    r : float
        Running cost coefficient
    
    Returns:
    --------
    t, x, u, m : time grid, space grid, value function, mean field
    """
    # Grids
    t = np.arange(0, T + dt, dt)
    x_max = 5.0
    x = np.arange(-x_max, x_max + dx, dx)
    nt, nx = len(t), len(x)
    
    # Initialize
    u = np.zeros((nt, nx))
    m = np.zeros((nt, nx))
    
    # Initial distribution (Gaussian)
    m[0, :] = np.exp(-x**2 / 0.5) / np.sqrt(np.pi * 0.5)
    m[0, :] = m[0, :] / (np.sum(m[0, :]) * dx)
    
    # Terminal cost
    u[-1, :] = x**2 / 2  # g(x) = x²/2
    
    # Finite difference operators
    def laplacian(v, dx):
        """Discrete Laplacian with Neumann BC"""
        result = np.zeros_like(v)
        result[1:-1] = (v[2:] - 2*v[1:-1] + v[:-2]) / dx**2
        return result
    
    def gradient(v, dx):
        """Central difference gradient"""
        result = np.zeros_like(v)
        result[1:-1] = (v[2:] - v[:-2]) / (2*dx)
        return result
    
    def divergence(vm, dx):
        """Divergence of m * v"""
        result = np.zeros_like(vm)
        result[1:-1] = (vm[2:] - vm[:-2]) / (2*dx)
        return result
    
    # Backward solve for u (HJB)
    for i in range(nt - 2, -1, -1):
        # Current mean field at time i
        m_current = m[i, :]
        m_mean = np.sum(x * m_current) * dx / (np.sum(m_current) * dx)
        
        # Hamiltonian for LQ case: H = -|∇u|²/2 + r(x - m̄)²/2
        du_dx = gradient(u[i+1, :], dx)
        hamiltonian = -0.5 * du_dx**2 + 0.5 * r * (x - m_mean)**2
        
        # HJB: -∂u/∂t = νΔu - H
        lap_u = laplacian(u[i+1, :], dx)
        u[i, :] = u[i+1, :] - dt * (nu * lap_u - hamiltonian)
    
    # Forward solve for m (Fokker-Planck)
    for i in range(nt - 1):
        du_dx = gradient(u[i, :], dx)
        
        # Optimal control: α* = -∇u
        alpha = -du_dx
        
        # Fokker-Planck: ∂m/∂t = νΔm - div(m α)
        lap_m = laplacian(m[i, :], dx)
        div_m_alpha = divergence(m[i, :] * alpha, dx)
        
        m[i+1, :] = m[i, :] + dt * (nu * lap_m - div_m_alpha)
        m[i+1, :] = np.maximum(m[i+1, :], 0)  # Non-negativity
        m[i+1, :] = m[i+1, :] / (np.sum(m[i+1, :]) * dx)  # Normalize
    
    return t, x, u, m

Compressed Sensing

Real-World Motivation: Compressed sensing enables recovery of sparse signals from far fewer measurements than traditional Nyquist sampling requires. Applications include MRI imaging (faster scans), single-pixel cameras, and efficient data acquisition in sensor networks.

Definitions

  • Sparsity: A signal \( x \in \mathbb{R}^n \) is \( k \)-sparse if it has at most \( k \) non-zero entries.
  • Measurement Matrix: \( A \in \mathbb{R}^{m \times n} \) with \( m \ll n \), satisfying the Restricted Isometry Property (RIP).
  • RIP: Matrix \( A \) satisfies RIP of order \( k \) if there exists \( \delta_k \in (0,1) \) such that: \[ (1 - \delta_k) \|x\|_2^2 \leq \|Ax\|_2^2 \leq (1 + \delta_k) \|x\|_2^2 \]
    • for all \( k \)-sparse \( x \).

Theorem: Exact Recovery via \( \ell_1 \) Minimization

Let \( A \) satisfy RIP of order \( 2k \) with \( \delta_{2k} < \sqrt{2} - 1 \). Then for any \( k \)-sparse \( x \), the solution \( x^* \) to:

\[ \min_{z} \|z\|_1 \quad \text{subject to} \quad Az = Ax \]

satisfies \( x^* = x \).

Noisy Case: If \( y = Ax + e \) with \( \|e\|_2 \leq \epsilon \), then the solution to:

\[ \min_{z} \|z\|_1 \quad \text{subject to} \quad \|Az - y\|_2 \leq \epsilon \]

satisfies \( \|x^* - x\|_2 \leq C_0 \epsilon + C_1 \|x - x_k\|_1 / \sqrt{k} \) where \( x_k \) is the best \( k \)-term approximation.

Notation Guide

  • \( x \in \mathbb{R}^n \) — signal (sparse)
  • \( A \in \mathbb{R}^{m \times n} \) — measurement matrix
  • \( y = Ax \) — measurements
  • \( \|x\|_0 \) — number of non-zero entries (pseudonorm)
  • \( \|x\|_1 = \sum_i |x_i| \) — \( \ell_1 \) norm
  • \( \delta_k \) — RIP constant

import numpy as np
from scipy.optimize import minimize

def generate_rip_matrix(m, n, matrix_type='gaussian'):
    """
    Generate a measurement matrix satisfying RIP with high probability.
    
    Parameters:
    -----------
    m : int
        Number of measurements
    n : int
        Signal dimension
    matrix_type : str
        'gaussian' or 'bernoulli'
    
    Returns:
    --------
    A : (m, n) array
        Normalized measurement matrix
    """
    if matrix_type == 'gaussian':
        A = np.random.randn(m, n) / np.sqrt(m)
    elif matrix_type == 'bernoulli':
        A = np.random.choice([-1, 1], size=(m, n)) / np.sqrt(m)
    else:
        raise ValueError("Unknown matrix type")
    
    return A

def l1_minimization(A, y, epsilon=None):
    """
    Solve basis pursuit or basis pursuit denoising.
    
    min ||x||_1 subject to Ax = y (or ||Ax - y||_2 <= epsilon)
    """
    m, n = A.shape
    
    # Objective: L1 norm
    def objective(x):
        return np.sum(np.abs(x))
    
    if epsilon is None:
        # Basis pursuit: equality constraint
        cons = {'type': 'eq', 'fun': lambda x: A @ x - y}
        result = minimize(objective, np.zeros(n), method='SLSQP', 
                         constraints=cons, options={'maxiter': 1000})
    else:
        # Basis pursuit denoising: inequality constraint
        cons = {'type': 'ineq', 'fun': lambda x: epsilon - np.linalg.norm(A @ x - y)}
        result = minimize(objective, np.zeros(n), method='SLSQP', 
                         constraints=cons, options={'maxiter': 1000})
    
    return result.x

def iterative_hard_thresholding(A, y, k, max_iter=100, tol=1e-6):
    """
    IHT for compressed sensing.
    Simple and fast alternative to L1 minimization.
    """
    m, n = A.shape
    x = np.zeros(n)
    
    # Step size
    mu = 0.9 / np.linalg.norm(A.T @ A, 2)
    
    for _ in range(max_iter):
        # Gradient step
        x_new = x + mu * A.T @ (y - A @ x)
        
        # Hard thresholding: keep only k largest
        idx = np.argsort(np.abs(x_new))[-k:]
        x_new = np.zeros(n)
        x_new[idx] = x_new[idx]
        
        if np.linalg.norm(x_new - x) < tol:
            break
        x = x_new
    
    return x

def check_rip_constant(A, k, num_samples=1000):
    """
    Estimate RIP constant by sampling sparse vectors.
    """
    n = A.shape[1]
    ratios = []
    
    for _ in range(num_samples):
        # Generate random k-sparse vector
        x = np.zeros(n)
        idx = np.random.choice(n, k, replace=False)
        x[idx] = np.random.randn(k)
        x = x / np.linalg.norm(x)
        
        # Compute ||Ax||²
        ratio = np.linalg.norm(A @ x)**2
        ratios.append(ratio)
    
    ratios = np.array(ratios)
    delta = max(1 - np.min(ratios), np.max(ratios) - 1)
    
    return delta, np.min(ratios), np.max(ratios)

The Weil Conjectures

Historical Context: André Weil formulated these conjectures in 1949 based on patterns he observed in counting points on algebraic varieties over finite fields. They proposed a deep connection between the number of solutions to polynomial equations over finite fields and the topology of corresponding complex varieties. The conjectures were proved by Dwork (rationality), Grothendieck (functional equation), and Deligne (Riemann hypothesis analog), revolutionizing algebraic geometry.

Definitions

  • Zeta Function: For a variety \( X \) over \( \mathbb{F}_q \): \[ Z(X, t) = \exp\left(\sum_{n=1}^\infty \frac{\#X(\mathbb{F}_{q^n})}{n} t^n\right) \]
  • Betti Numbers: Topological invariants \( b_i \) counting independent cycles in each dimension.
  • Frobenius Endomorphism: The map \( F: X \to X \) defined by \( F(x) = x^q \) on coordinates.

Theorem: The Weil Conjectures (Deligne, 1974)

For a smooth projective variety \( X \) of dimension \( d \) over \( \mathbb{F}_q \):

  1. Rationality: \( Z(X, t) \) is a rational function of \( t \)
  2. Functional Equation: \( Z(X, q^{-d}t^{-1}) = \pm q^{d\chi/2} t^{\chi} Z(X, t) \) where \( \chi \) is the Euler characteristic
  3. Riemann Hypothesis Analog: Writing \[ Z(X, t) = \frac{P_1(t) P_3(t) \cdots P_{2d-1}(t)}{P_0(t) P_2(t) \cdots P_{2d}(t)} \]
    4. the roots of \( P_i \) have absolute value \( q^{-i/2} \).
  4. Betti Numbers: The degree of \( P_i \) equals the \( i \)-th Betti number of the complex variety.

Notation Guide

  • \( \mathbb{F}_q \) — finite field with \( q \) elements
  • \( \#X(\mathbb{F}_{q^n}) \) — number of points over extension field
  • \( Z(X, t) \) — zeta function (generating function)
  • \( P_i(t) \) — characteristic polynomial of Frobenius on \( H^i \)
  • \( b_i \) — Betti numbers

def count_points_projective_space(n, q):
    """
    Count points in P^n(F_q).
    #P^n(F_q) = (q^{n+1} - 1) / (q - 1) = 1 + q + q^2 + ... + q^n
    """
    return sum(q**i for i in range(n + 1))

def count_points_elliptic_curve(a, b, q):
    """
    Count points on elliptic curve y^2 = x^3 + ax + b over F_q.
    Includes point at infinity.
    """
    count = 1  # Point at infinity
    
    for x in range(q):
        # Right hand side
        rhs = (x**3 + a*x + b) % q
        
        # Count square roots
        # In F_q, y^2 = c has 1 + χ(c) solutions where χ is Legendre symbol
        if rhs == 0:
            count += 1  # One solution: y = 0
        elif pow(rhs, (q - 1) // 2, q) == 1:
            count += 2  # Two solutions
        # else: no solutions
    
    return count

def zeta_function_elliptic_curve(a, b, q, max_n=10):
    """
    Compute zeta function coefficients for elliptic curve.
    
    For elliptic curve E over F_q:
    Z(E, t) = (1 - at + qt^2) / ((1-t)(1-qt))
    
    where a = q + 1 - #E(F_q)
    """
    N1 = count_points_elliptic_curve(a, b, q)
    a_coeff = q + 1 - N1
    
    # Zeta function: Z(t) = (1 - at + qt^2) / ((1-t)(1-qt))
    # Series expansion
    coeffs = []
    for n in range(1, max_n + 1):
        # N_n = q^n + 1 - (α^n + β^n) where α, β are roots of T^2 - aT + q
        # Use recurrence: S_n = a*S_{n-1} - q*S_{n-2} with S_0 = 2, S_1 = a
        if n == 1:
            S_n = a_coeff
        else:
            # α^n + β^n
            S_prev2, S_prev1 = 2, a_coeff
            for _ in range(2, n + 1):
                S_n = a_coeff * S_prev1 - q * S_prev2
                S_prev2, S_prev1 = S_prev1, S_n
        
        N_n = q**n + 1 - S_n
        coeffs.append(N_n)
    
    return a_coeff, coeffs

def verify_weil_bound(a, b, q):
    """
    Verify the Hasse-Weil bound: |q + 1 - N| <= 2√q
    """
    N = count_points_elliptic_curve(a, b, q)
    a_coeff = q + 1 - N
    bound = 2 * int(np.sqrt(q))
    
    return abs(a_coeff) <= bound, a_coeff, bound

Perfectoid Spaces

Historical Context: Introduced by Peter Scholze in 2012, perfectoid spaces revolutionized p-adic geometry by providing a framework to compare characteristic p and characteristic 0 geometries. This "tilting" correspondence solved long-standing problems and led to Scholze's Fields Medal in 2018. The theory has transformed arithmetic geometry and has applications to the Langlands program.

Definitions

  • Perfectoid Field: A complete non-archimedean field \( K \) with residue characteristic \( p \), such that the Frobenius is surjective on \( \mathcal{O}_K/p \).
  • Tilt: For a perfectoid field \( K \), its tilt \( K^\flat \) is a perfect field of characteristic \( p \) with \( |K^\flat| = |K| \).
  • Perfectoid Algebra: A Banach \( K \)-algebra \( A \) such that the subalgebra of power-bounded elements is uniform and the Frobenius is surjective on \( A^\circ/p \).

Theorem: Tilting Equivalence

Let \( K \) be a perfectoid field. There is an equivalence of categories:

\[ \{\text{Perfectoid spaces over } K\} \longleftrightarrow \{\text{Perfectoid spaces over } K^\flat\} \]

Given by \( X \mapsto X^\flat \), where the underlying topological spaces are homeomorphic and the structure sheaves are related via:

\[ \mathcal{O}_{X^\flat}^+(U^\flat) = \varprojlim_{x \mapsto x^p} \mathcal{O}_X^+(U) \]

Key Corollary: For any perfectoid algebra \( A \) over \( K \), there is a multiplicative map \( \sharp: A^\flat \to A \) inducing an isomorphism of topological spaces \( \text{Spa}(A, A^+) \cong \text{Spa}(A^\flat, A^{+\flat}) \).

Notation Guide

  • \( K \) — perfectoid field
  • \( K^\flat \) — tilt (characteristic \( p \))
  • \( \mathcal{O}_K \) — ring of integers
  • \( A^\circ \) — power-bounded elements
  • \( \sharp \) — untilt map
  • \( \text{Spa}(A, A^+) \) — adic spectrum

Monstrous Moonshine

Historical Context: In 1978, John McKay noticed that 196884 (coefficient in the j-function expansion) equals 196883 + 1, where 196883 is the dimension of the smallest non-trivial representation of the Monster group. This bizarre connection between modular functions and the largest sporadic simple group seemed like "moonshine" (nonsense) until Richard Borcherds proved it in 1992 using vertex operator algebras, earning him a Fields Medal.

Definitions

  • Monster Group \( \mathbb{M} \): The largest sporadic simple group, of order: \[ |\mathbb{M}| = 2^{46} \cdot 3^{20} \cdot 5^9 \cdot 7^6 \cdot 11^2 \cdot 13^3 \cdot 17 \cdot 19 \cdot 23 \cdot 29 \cdot 31 \cdot 41 \cdot 47 \cdot 59 \cdot 71 \]
  • j-function: The modular function with Fourier expansion: \[ j(\tau) = q^{-1} + 744 + 196884q + 21493760q^2 + \cdots \]
    • where \( q = e^{2\pi i \tau} \).
  • Vertex Operator Algebra (VOA): An algebraic structure encoding two-dimensional conformal field theory, with the Monster VOA \( V^\natural \) having Monster symmetry.

Theorem: Monstrous Moonshine (Borcherds)

There exists a vertex operator algebra \( V^\natural = \bigoplus_{n=-1}^\infty V_n \) such that:

  1. \( \text{Aut}(V^\natural) \cong \mathbb{M} \) (the Monster group)
  2. The graded dimension equals the j-function: \[ \sum_{n=-1}^\infty \dim(V_n) q^n = j(\tau) - 744 \]
  3. For each element \( g \in \mathbb{M} \) of order \( n \), the McKay-Thompson series \[ T_g(\tau) = \sum_{k=-1}^\infty \text{Tr}(g|_{V_k}) q^k \]
    4. is a Hauptmodul for a genus zero subgroup of \( SL_2(\mathbb{R}) \).

Notation Guide

  • \( \mathbb{M} \) — Monster group
  • \( j(\tau) \) — modular j-function
  • \( q = e^{2\pi i \tau} \) — nome
  • \( V^\natural \) — Monster vertex operator algebra
  • \( T_g(\tau) \) — McKay-Thompson series
  • \( \text{Tr}(g|_{V_k}) \) — character value

Arithmetic Dynamics

Historical Context: Arithmetic dynamics emerged in the 1990s as a field combining number theory and dynamical systems. Pioneers like Silverman and Morton studied how rational maps act on algebraic varieties over number fields. The field gained prominence with the proof of the Uniform Boundedness Conjecture for preperiodic points and connections to the abc conjecture.

Definitions

  • Dynamical System: A map \( f: X \to X \) on a variety, with iteration \( f^n = f \circ \cdots \circ f \).
  • Preperiodic Point: A point \( P \) such that \( f^{n+m}(P) = f^n(P) \) for some \( n, m \geq 1 \).
  • Canonical Height: For a morphism \( f: \mathbb{P}^N \to \mathbb{P}^N \) of degree \( d \geq 2 \): \[ \hat{h}_f(P) = \lim_{n \to \infty} \frac{h(f^n(P))}{d^n} \]
    • where \( h \) is the Weil height.

Theorem: Northcott's Theorem on Heights

Let \( f: \mathbb{P}^N \to \mathbb{P}^N \) be a morphism of degree \( d \geq 2 \) defined over a number field \( K \). Then:

  1. A point \( P \in \mathbb{P}^N(\overline{K}) \) is preperiodic if and only if \( \hat{h}_f(P) = 0 \).
  2. For any bound \( B \), the set \( \{P \in \mathbb{P}^N(K) : \hat{h}_f(P) \leq B\} \) is finite.
  3. The set of \( K \)-rational preperiodic points is finite.

Uniform Boundedness Conjecture: There exists a bound \( B(d, D) \) such that for any degree \( d \) morphism \( f: \mathbb{P}^1 \to \mathbb{P}^1 \) over a degree \( D \) number field, the number of preperiodic points is at most \( B(d, D) \).

Notation Guide

  • \( f^n \) — n-th iterate
  • \( \hat{h}_f \) — canonical height with respect to \( f \)
  • \( h \) — Weil logarithmic height
  • \( \text{Prep}(f) \) — set of preperiodic points
  • \( \mathbb{P}^N(K) \) — projective space over field \( K \)

def find_preperiodic_points(c, grid_size=100, bound=2):
    """
    Find approximate preperiodic points by looking for bounded orbits.
    
    For the quadratic family f_c(z) = z^2 + c, preperiodic points
    are contained in the filled Julia set.
    """
    x = np.linspace(-bound, bound, grid_size)
    y = np.linspace(-bound, bound, grid_size)

    Z = X + 1j*Y

    julia = np.zeros((grid_size, grid_size))

def canonical_height_approx(z, c, n_iter=20):
    """
    Approximate the canonical height for the quadratic map.
    
    For f(z) = z^2 + c, the canonical height is:
    ĥ(z) = lim_{n→∞} h(f^n(z)) / 2^n
    
    where h is the Weil height (approximated by log^+|z|).
    """
    heights = []
    current = z
    
    for n in range(n_iter):
        # Weil height approximation
        h_n = max(0, np.log(abs(current))) if abs(current) > 1 else 0
        heights.append(h_n / (2**n))
        
        current = current**2 + c
        
        # If orbit escapes, height grows
        if abs(current) > 1000:
            break
    
    return heights[-1] if heights else 0

    """

    The Mandelbrot set is the set of c for which 0 has bounded orbit

    return M

📜 Math History

The Development of Modern Algebra: From Galois to Noether

The 19th and early 20th centuries witnessed a profound transformation in how mathematicians understood algebra. This revolution began with the tragic figure of Évariste Galois (1811–1832), who, in his brief life, fundamentally changed our understanding of polynomial equations.

Galois's insight was to associate a group to each polynomial—the group of symmetries of its roots. This Galois group encodes information about whether the polynomial can be solved by radicals. His famous theorem states that a polynomial is solvable by radicals if and only if its Galois group is solvable. Galois wrote down these ideas the night before his fatal duel at age 20; they were published posthumously by Liouville in 1846.

The next major advance came from Richard Dedekind (1831–1916), who introduced the concept of an ideal in his work on algebraic number theory. Dedekind's approach to restoring unique factorization in rings of integers of number fields was revolutionary: instead of factoring numbers, he factored ideals. This shift from elements to sets of elements marked a crucial step toward abstraction.

David Hilbert (1862–1943) synthesized and extended these ideas in his famous Zahlbericht (1897), a report on algebraic number theory that would guide the field for decades. Hilbert's axiomatic approach and his emphasis on structural properties over computational ones influenced the next generation profoundly.

The culmination of this development came with Emmy Noether (1882–1935). Noether's 1921 paper "Idealtheorie in Ringbereichen" established the general theory of ideals in commutative rings. She introduced the ascending chain condition, defining what we now call Noetherian rings—rings where every ideal is finitely generated. This condition, seemingly technical, captured the essential finiteness property needed for much of algebraic geometry and number theory.

Noether's influence extended far beyond her theorems. At Göttingen and later at Bryn Mawr, she trained a generation of mathematicians in her structural approach. Her famous dictum—"es steht alles schon bei Dedekind" (it's all already in Dedekind)—revealed both her modesty and her commitment to uncovering deep structural principles.

The transformation was complete: algebra had shifted from the study of equations and specific number systems to the study of abstract structures—groups, rings, fields, ideals—defined by axioms and studied through their homomorphisms and universal properties. This structural approach, pioneered by Noether and her school, became the dominant paradigm of 20th-century mathematics.

IMO Shortlist 2024 Problem

Problem: Let \( n \geq 2 \) be an integer. Find all functions \( f: \mathbb{R} \to \mathbb{R} \) such that for all real numbers \( x \) and \( y \),

\[ f(x^n + f(y)) = f(x)^n + y \]

💡 Hint

First show that \( f \) is bijective. Then find \( f(0) \) by substituting specific values. Consider what happens when you compare \( f(f(y)) \) with \( y \) plus some constant.

✅ Solution

Step 1: Show \( f \) is bijective.

Injectivity: Suppose \( f(a) = f(b) \). Then for any \( x \):

\[ f(x^n + f(a)) = f(x)^n + a \]

\[ f(x^n + f(b)) = f(x)^n + b \]

Since \( f(a) = f(b) \), the left sides are equal, so \( a = b \).

Surjectivity: The right side \( f(x)^n + y \) can take any real value by varying \( y \), so \( f \) is surjective.

Step 2: Find \( f(0) \).

Since \( f \) is surjective, there exists \( c \) with \( f(c) = 0 \). Setting \( x = c \) in the original equation:

\[ f(c^n + f(y)) = y \]

This shows \( f(f(y)) = y - c^n \) after substituting appropriately.

Step 3: Determine the form of \( f \).

Setting \( y = c \) in the original: \( f(x^n) = f(x)^n + c \).

Setting \( x = 0 \): \( f(f(y)) = f(0)^n + y \).

Comparing with \( f(f(y)) = y - c^n \), we get \( f(0)^n = -c^n \).

For odd \( n \): \( f(0) = -c \). For even \( n \): careful analysis shows \( c = 0 \).

Step 4: Verify \( f(x) = x \) for all \( x \).

With \( c = 0 \), we have \( f(0) = 0 \) and \( f(f(y)) = y \).

From \( f(x^n) = f(x)^n \) and injectivity, we deduce \( f(x) = x \) for all \( x \geq 0 \).

Using \( f(f(y)) = y \), this extends to all real \( x \).

Verification: \( f(x^n + f(y)) = x^n + y = f(x)^n + y \). ✓

Answer: The unique solution is \( f(x) = x \) for all \( x \in \mathbb{R} \).

The Apollonian Gasket

The Apollonian gasket is a fractal generated by recursively filling the interstices between mutually tangent circles. Starting with three mutually tangent circles, Descartes' theorem determines the fourth. The pattern continues infinitely, creating a beautiful structure with deep connections to number theory, hyperbolic geometry, and the theory of Kleinian groups.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Circle
from matplotlib.collections import PatchCollection

def descartes_theorem(k1, k2, k3):
    """
    Given curvatures of three mutually tangent circles,
    find the curvature of the fourth (Descartes' Theorem).
    
    If four circles have curvatures k1, k2, k3, k4:
    (k1 + k2 + k3 + k4)^2 = 2(k1^2 + k2^2 + k3^2 + k4^2)
    
    Solving for k4:
    k4 = k1 + k2 + k3 ± 2*sqrt(k1*k2 + k2*k3 + k3*k1)
    """
    sum_k = k1 + k2 + k3
    product_sum = k1*k2 + k2*k3 + k3*k1
    
    if product_sum < 0:
        return None, None
    
    k4_plus = sum_k + 2*np.sqrt(product_sum)
    k4_minus = sum_k - 2*np.sqrt(product_sum)
    
    return k4_plus, k4_minus

def circle_from_three(c1, c2, c3, k4):
    """
    Find the center of the fourth circle given three circles
    and the curvature of the fourth.
    
    Uses complex numbers for elegant computation.
    """
    # Unpack circles (x, y, curvature)
    x1, y1, k1 = c1
    x2, y2, k2 = c2
    x3, y3, k3 = c3
    
    # Complex representation
    z1 = complex(x1, y1)
    z2 = complex(x2, y2)
    z3 = complex(x3, y3)
    
    # Curvatures as complex for formula
    k1c, k2c, k3c, k4c = complex(k1), complex(k2), complex(k3), complex(k4)
    
    # Descartes' formula for centers
    # z4 = (z1*k1 + z2*k2 + z3*k3 ± 2*sqrt(k1*k2*z1*z2 + ...)) / k4
    
    # Simplified: use the fact that z_i * k_i are "curvature-centers"
    zk1 = z1 * k1c
    zk2 = z2 * k2c
    zk3 = z3 * k3c
    
    sum_zk = zk1 + zk2 + zk3
    
    # The cross term
    cross = k1c*k2c*z1*z2 + k2c*k3c*z2*z3 + k3c*k1c*z3*z1
    
    if abs(cross) < 1e-10:
        return None
    
    sqrt_cross = np.sqrt(cross)
    
    z4_plus = (sum_zk + 2*sqrt_cross) / k4c
    z4_minus = (sum_zk - 2*sqrt_cross) / k4c
    
    return z4_plus, z4_minus

def apollonian_gasket(c1, c2, c3, c4, depth=4):
    """
    Generate Apollonian gasket by recursively adding circles.
    
    Parameters:
    -----------
    c1, c2, c3, c4 : tuples (x, y, curvature)
        Four mutually tangent circles
    depth : int
        Recursion depth
    
    Returns:
    --------
    list of circles (x, y, radius)
    """
    circles = []
    
    def add_circle(c):
        x, y, k = c
        r = abs(1/k) if k != 0 else float('inf')
        circles.append((x, y, r))
    
    def recurse(a, b, c, d, n):
        if n == 0:
            return
        
        # Add the new circle
        add_circle(d)
        
        # Generate three new circles by replacing each of a, b, c with d
        k1, k2, k3, k4 = a[2], b[2], c[2], d[2]
        
        # For each triple (d, b, c), (a, d, c), (a, b, d), find the new circle
        for new_triple in [(d, b, c), (a, d, c), (a, b, d)]:
            t1, t2, t3 = new_triple
            k_new_plus, k_new_minus = descartes_theorem(t1[2], t2[2], t3[2])
            
            if k_new_minus is not None:
                # Find the center
                centers = circle_from_three(t1, t2, t3, k_new_minus)
                if centers:
                    z_new = centers[0] if abs(centers[0]) < abs(centers[1]) else centers[1]
                    new_circle = (z_new.real, z_new.imag, k_new_minus)
                    
                    # Check if circle is valid (not too small, not duplicate)
                    if abs(k_new_minus) < 1000 and abs(k_new_minus) > 0.1:
                        recurse(t1, t2, t3, new_circle, n-1)
    
    # Add initial circles
    for c in [c1, c2, c3, c4]:
        add_circle(c)
    
    # Start recursion from each initial circle
    recurse(c1, c2, c3, c4, depth)
    
    return circles
