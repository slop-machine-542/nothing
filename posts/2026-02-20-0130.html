1. Differential Geometry: The Gauss-Bonnet Theorem

Notation: Let \(M\) be a compact, oriented 2-dimensional Riemannian manifold without boundary. Let \(K\) denote the Gaussian curvature and \(\chi(M)\) the Euler characteristic.

Theorem (Gauss-Bonnet): \[\int_M K \, dA = 2\pi \chi(M)\]

Notation Explanation:

  • \(K\): Gaussian curvature at each point, measuring how the surface curves in space
  • \(dA\): Area element on the surface
  • \(\chi(M) = V - E + F\): Euler characteristic (vertices - edges + faces for any triangulation)
Sketch of Proof:

The proof uses triangulation and local analysis:

  1. Triangulate \(M\) with geodesic triangles
  2. For each triangle with angles \(\alpha, \beta, \gamma\): \(\int_{\triangle} K \, dA = \alpha + \beta + \gamma - \pi\) (excess angle)
  3. Sum over all triangles: \(\sum (\alpha + \beta + \gamma - \pi) = 2\pi V - \pi F\)
  4. Using \(3F = 2E\) (each edge belongs to 2 faces, each face has 3 edges): \(2\pi V - \pi F = 2\pi(V - E + F) = 2\pi\chi(M)\)

Python Implementation:

import numpy as np
from scipy.integrate import dblquad

def gaussian_curvature_sphere(R):
    """
    Gaussian curvature of a sphere of radius R is constant: K = 1/R^2
    For unit sphere: K = 1 everywhere
    """
    return 1 / (R ** 2)

def sphere_euler_characteristic():
    """
    Sphere has χ = 2 (can be computed as V - E + F for any triangulation)
    """
    return 2

def verify_gauss_bonnet_sphere(R):
    """
    Verify Gauss-Bonnet for sphere of radius R
    ∫ K dA = K * (4πR²) = (1/R²) * 4πR² = 4π = 2π * 2 = 2πχ
    """
    K = gaussian_curvature_sphere(R)
    area = 4 * np.pi * R**2
    integral = K * area
    chi = sphere_euler_characteristic()
    expected = 2 * np.pi * chi
    
    return {
        'integral_K_dA': integral,
        '2pi_chi': expected,
        'verified': np.isclose(integral, expected)
    }

# Example: Unit sphere
result = verify_gauss_bonnet_sphere(1.0)
print(f"∫ K dA = {result['integral_K_dA']:.6f}")
print(f"2πχ = {result['2pi_chi']:.6f}")
print(f"Gauss-Bonnet verified: {result['verified']}")

# Torus example (χ = 0)
def torus_euler_characteristic():
    """Torus has χ = 0"""
    return 0

print(f"\nFor a torus: χ = {torus_euler_characteristic()}")
print(f"Therefore ∫ K dA = 0 (curvature integrates to zero)")

2. Ergodic Theory: Birkhoff's Ergodic Theorem

Notation: Let \((X, \mathcal{B}, \mu)\) be a probability space, \(T: X \to X\) a measure-preserving transformation, and \(f \in L^1(\mu)\).

Theorem (Birkhoff's Ergodic Theorem):

For almost every \(x \in X\):

\[\lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x)) = \mathbb{E}[f | \mathcal{I}](x)\]

where \(\mathcal{I}\) is the \(\sigma\)-algebra of \(T\)-invariant sets. If \(T\) is ergodic, this equals \(\int_X f \, d\mu\).

Notation Explanation:

  • \(T^k\): \(k\)-fold composition of \(T\)
  • \(\mathbb{E}[f | \mathcal{I}]\): Conditional expectation given invariant sets
  • Ergodic: Only invariant sets have measure 0 or 1
Key Ideas:

The proof uses the maximal ergodic lemma: for \(A_n f = \frac{1}{n}\sum_{k=0}^{n-1} f \circ T^k\), one shows that the set where \(\limsup A_n f > \alpha\) has controlled measure. The limit exists almost everywhere by careful analysis of the oscillations.

Python Implementation:

import numpy as np
import matplotlib.pyplot as plt

def circle_rotation(x, alpha):
    """
    Irrational rotation on the circle: T(x) = x + alpha (mod 1)
    This is ergodic when alpha is irrational
    """
    return (x + alpha) % 1.0

def birkhoff_average(f, x0, T, n_iterations, *args):
    """
    Compute the Birkhoff average: (1/n) * sum_{k=0}^{n-1} f(T^k(x0))
    """
    x = x0
    total = 0.0
    for _ in range(n_iterations):
        total += f(x, *args)
        x = T(x, *args)
    return total / n_iterations

def test_irrational_rotation():
    """
    Test Birkhoff's theorem with irrational rotation on circle
    For ergodic T, time average = space average
    """
    alpha = (np.sqrt(5) - 1) / 2  # Golden ratio conjugate (irrational)
    
    # Test function: f(x) = sin(2πx)
    f = lambda x: np.sin(2 * np.pi * x)
    
    # Space average (integral over [0,1])
    space_avg = 0  # ∫_0^1 sin(2πx) dx = 0
    
    # Test multiple starting points
    starting_points = np.linspace(0, 1, 10, endpoint=False)
    n_values = [100, 1000, 10000]
    
    print("Birkhoff Ergodic Theorem - Irrational Rotation")
    print(f"α = (√5 - 1)/2 ≈ {alpha:.6f}")
    print(f"Space average of sin(2πx): {space_avg}")
    print("\nTime averages for different starting points:")
    
    for n in n_values:
        print(f"\nn = {n}:")
        averages = [birkhoff_average(f, x0, circle_rotation, n, alpha) 
                   for x0 in starting_points[:3]]
        print(f"  Time averages: {[f'{a:.6f}' for a in averages]}")
        print(f"  Mean deviation from space avg: {np.mean(np.abs(averages)):.6f}")

def bernoulli_shift():
    """
    Bernoulli shift is a classic ergodic system
    X = {0,1}^N, T shifts sequence left
    """
    np.random.seed(42)
    
    # Generate random binary sequence
    sequence = np.random.randint(0, 2, size=100000)

    # Space average = P(first bit = 1) = 0.5

    # Time average = frequency of 1s in sequence
    time_avg = np.mean(sequence)
    
    print(f"\nBernoulli Shift:")
    print(f"Space average (P(bit=1)): {space_avg}")
    print(f"Time average (observed freq): {time_avg:.6f}")
    print(f"Difference: {abs(time_avg - space_avg):.6f}")

3. Harmonic Analysis: The Plancherel Theorem

Notation: For \(f \in L^1(\mathbb{R}) \cap L^2(\mathbb{R})\), define the Fourier transform:

\[\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} \, dx\]
Theorem (Plancherel):

The Fourier transform extends to a unitary operator on \(L^2(\mathbb{R})\), and:

\[\|f\|_{L^2}^2 = \|\hat{f}\|_{L^2}^2\]

Equivalently: \(\int_{-\infty}^{\infty} |f(x)|^2 \, dx = \int_{-\infty}^{\infty} |\hat{f}(\xi)|^2 \, d\xi\)

Notation Explanation:

  • \(L^2(\mathbb{R})\): Space of square-integrable functions
  • \(\|f\|_{L^2} = \sqrt{\int |f|^2}\): \(L^2\) norm
  • Unitary: Preserves inner products and norms
Key Steps:
  1. First prove for Schwartz functions (rapidly decreasing smooth functions)
  2. Use the identity: \(\int f \overline{g} = \int \hat{f} \overline{\hat{g}}\) (Parseval)
  3. Set \(f = g\) to get Plancherel
  4. Extend by density to all of \(L^2\)

Python Implementation:

import numpy as np
import matplotlib.pyplot as plt

def gaussian(x, sigma=1.0):
    """Gaussian function: f(x) = exp(-x²/(2σ²))"""
    return np.exp(-x**2 / (2 * sigma**2))

def gaussian_fourier(xi, sigma=1.0):
    """
    Fourier transform of Gaussian is Gaussian:
    If f(x) = exp(-x²/(2σ²)), then
    f̂(ξ) = σ√(2π) * exp(-2π²σ²ξ²)
    """
    return sigma * np.sqrt(2 * np.pi) * np.exp(-2 * np.pi**2 * sigma**2 * xi**2)

def plancherel_verification():
    """
    Verify Plancherel theorem numerically for Gaussian
    """
    sigma = 2.0
    
    # Spatial domain
    x = np.linspace(-10, 10, 10000)
    dx = x[1] - x[0]
    f = gaussian(x, sigma)
    
    # Frequency domain  
    xi = np.linspace(-5, 5, 10000)
    dxi = xi[1] - xi[0]
    f_hat = gaussian_fourier(xi, sigma)
    
    # Compute L² norms
    l2_f = np.sqrt(np.sum(np.abs(f)**2) * dx)
    l2_f_hat = np.sqrt(np.sum(np.abs(f_hat)**2) * dxi)
    
    print("Plancherel Theorem Verification")
    print(f"Gaussian with σ = {sigma}")
    print(f"‖f‖₂ (spatial) = {l2_f:.6f}")
    print(f"‖f̂‖₂ (frequency) = {l2_f_hat:.6f}")
    print(f"Relative error: {abs(l2_f - l2_f_hat) / l2_f * 100:.4f}%")
    
    return l2_f, l2_f_hat

def verify_parseval():
    """
    Verify Parseval's identity:  = 
    """
    x = np.linspace(-10, 10, 10000)
    dx = x[1] - x[0]
    
    # Two different Gaussians
    f = gaussian(x, sigma=1.0)
    g = gaussian(x, sigma=2.0)
    
    # Inner product in spatial domain
    inner_spatial = np.sum(f * g) * dx
    
    # Their Fourier transforms
    xi = np.linspace(-5, 5, 10000)
    dxi = xi[1] - xi[0]
    f_hat = gaussian_fourier(xi, sigma=1.0)
    g_hat = gaussian_fourier(xi, sigma=2.0)
    
    # Inner product in frequency domain
    inner_freq = np.sum(f_hat * g_hat) * dxi
    
    print(f"\nParseval's Identity Verification:")
    print(f" (spatial) = {inner_spatial:.6f}")
    print(f" (frequency) = {inner_freq:.6f}")
    print(f"Relative error: {abs(inner_spatial - inner_freq) / inner_spatial * 100:.4f}%")

1. Stochastic Processes: The Wiener Process (Brownian Motion)

Notation: A standard Wiener process \(\{W_t\}_{t \geq 0}\) is a continuous-time stochastic process with:

  • \(W_0 = 0\) almost surely
  • Independent increments: \(W_t - W_s \perp W_s - W_r\) for \(r < s < t\)
  • \(W_t - W_s \sim \mathcal{N}(0, t-s)\) (normal distribution)
  • Continuous sample paths
Theorem (Quadratic Variation):

For the Wiener process:

\[\lim_{|\Pi| \to 0} \sum_{i=1}^{n} (W_{t_i} - W_{t_{i-1}})^2 = T\]

where \(\Pi = \{0 = t_0 < t_1 < \cdots < t_n = T\}\) is a partition.

Notation Explanation:

  • \(W_t\): Value of the process at time \(t\)
  • \(\mathcal{N}(\mu, \sigma^2)\): Normal distribution with mean \(\mu\), variance \(\sigma^2\)
  • Quadratic variation measures the "roughness" of the path
Sketch:

Let \(\Delta W_i = W_{t_i} - W_{t_{i-1}}\) and \(\Delta t_i = t_i - t_{i-1}\). Then \(\mathbb{E}[\Delta W_i^2] = \Delta t_i\) and \(\text{Var}(\Delta W_i^2) = 2(\Delta t_i)^2\). The sum has mean \(T\) and variance tending to 0 as the partition refines.

Python Implementation:

import numpy as np
import matplotlib.pyplot as plt

def simulate_wiener_process(T=1.0, n_steps=1000, n_paths=5):
    """
    Simulate standard Wiener process (Brownian motion)
    Using the property: W_{t+dt} = W_t + sqrt(dt) * Z, Z ~ N(0,1)
    """
    dt = T / n_steps
    t = np.linspace(0, T, n_steps + 1)
    
    # Generate increments
    dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, n_steps))
    
    # Cumulative sum to get W_t
    W = np.zeros((n_paths, n_steps + 1))
    W[:, 1:] = np.cumsum(dW, axis=1)
    
    return t, W

def quadratic_variation(t, W):
    """
    Compute quadratic variation sum (W_{t_i} - W_{t_{i-1}})^2
    """
    dW = np.diff(W)
    return np.sum(dW**2)

def verify_quadratic_variation():
    """
    Verify that quadratic variation converges to T
    """
    T = 1.0
    step_counts = [100, 500, 1000, 5000, 10000]
    
    print("Quadratic Variation of Wiener Process")
    print(f"Expected value: T = {T}")
    print("\nn_steps  |  Quadratic Variation  |  Error")
    print("-" * 50)
    
    for n in step_counts:
        t, W = simulate_wiener_process(T, n, n_paths=1)
        qv = quadratic_variation(t, W[0])
        print(f"{n:8d} | {qv:20.6f} | {abs(qv - T):.6f}")

def simulate_geometric_brownian_motion(S0, mu, sigma, T, n_steps):
    """
    GBM: dS_t = μS_t dt + σS_t dW_t
    Solution: S_t = S_0 * exp((μ - σ²/2)t + σW_t)
    """
    t, W = simulate_wiener_process(T, n_steps, n_paths=1)
    S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W[0])
    return t, S

# Run verification
verify_quadratic_variation()

# Simulate and plot
np.random.seed(42)
t, W = simulate_wiener_process(T=1.0, n_steps=1000, n_paths=3)

print(f"Std of final values: {np.std(W[:, -1]):.4f}")
print(f"Theoretical std at T=1: {np.sqrt(1.0):.4f}")

2. Network Theory: PageRank as a Markov Chain

Notation: Consider a web graph with \(n\) pages. Let \(G\) be the Google matrix:

\[G = \alpha S + (1-\alpha) \frac{1}{n} \mathbf{1}\mathbf{1}^T\]

where \(S\) is the stochastic matrix derived from link structure and \(\alpha\) is the damping factor (typically 0.85).

Theorem (Perron-Frobenius for PageRank):

The Google matrix \(G\) has a unique stationary distribution \(\pi\) satisfying:

\[\pi^T G = \pi^T, \quad \sum_i \pi_i = 1, \quad \pi_i > 0\]

This \(\pi\) gives the PageRank scores.

Notation Explanation:

  • \(S_{ij}\): Probability of moving from page \(j\) to page \(i\)
  • \(\alpha\): Damping factor (probability of following a link)
  • \(\pi_i\): PageRank score of page \(i\)
Key Steps:
  1. \(G\) is stochastic (rows sum to 1)
  2. \(G\) is irreducible (damping ensures all entries positive)
  3. By Perron-Frobenius, 1 is the unique largest eigenvalue
  4. The corresponding eigenvector gives the stationary distribution

Python Implementation:

import numpy as np

def build_google_matrix(adj_matrix, alpha=0.85):
    """
    Build Google matrix from adjacency matrix
    adj_matrix[i,j] = 1 if link from j to i exists
    """
    n = adj_matrix.shape[0]
    
    # Column-normalize to get stochastic matrix
    out_degrees = np.sum(adj_matrix, axis=0)
    
    # Handle dangling nodes (no out-links)
    S = np.zeros((n, n))
    for j in range(n):
        if out_degrees[j] > 0:
            S[:, j] = adj_matrix[:, j] / out_degrees[j]
        else:
            # Dangling node: uniform distribution
            S[:, j] = 1.0 / n
    
    # Google matrix with damping
    G = alpha * S + (1 - alpha) * np.ones((n, n)) / n
    
    return G

def power_method_pagerank(G, tol=1e-10, max_iter=1000):
    """
    Compute PageRank using power method
    """
    n = G.shape[0]
    pi = np.ones(n) / n  # Uniform initial distribution
    
    for i in range(max_iter):
        pi_new = G.T @ pi
        if np.linalg.norm(pi_new - pi, 1) < tol:
            return pi_new, i + 1
        pi = pi_new
    
    return pi, max_iter

def pagerank_example():
    """
    Example: Simple web graph
    Page 0 links to 1, 2
    Page 1 links to 0, 2
    Page 2 links to 0
    """
    # Adjacency matrix: adj[i,j] = 1 if j -> i
    adj = np.array([
        [0, 1, 1],  # Page 0 receives from 1, 2
        [1, 0, 0],  # Page 1 receives from 0
        [1, 1, 0]   # Page 2 receives from 0, 1
    ])
    
    print("PageRank Example")
    print("Adjacency matrix (to, from):")
    print(adj)
    
    G = build_google_matrix(adj, alpha=0.85)
    pi, iterations = power_method_pagerank(G)
    
    print(f"\nGoogle matrix (α=0.85):")
    print(np.round(G, 3))
    
    print(f"\nPageRank scores (converged in {iterations} iterations):")
    for i, score in enumerate(pi):
        print(f"  Page {i}: {score:.6f}")
    
    # Verify it's a stationary distribution
    print(f"\nVerification: π^T G = π^T ?")
    print(f"  Max difference: {np.max(np.abs(G.T @ pi - pi)):.2e}")
    
    return pi

def compare_damping_factors():
    """
    Compare PageRank with different damping factors
    """
    adj = np.array([
        [0, 1, 1, 0],
        [1, 0, 1, 1],
        [1, 0, 0, 1],
        [0, 1, 0, 0]
    ])
    
    alphas = [0.5, 0.7, 0.85, 0.95, 0.99]
    
    print("\nPageRank with Different Damping Factors")
    print("-" * 50)
    print(f"{'α':>6} | {'Page 0':>10} | {'Page 1':>10} | {'Page 2':>10} | {'Page 3':>10}")
    print("-" * 50)
    
    for alpha in alphas:
        G = build_google_matrix(adj, alpha)
        pi, _ = power_method_pagerank(G)
        print(f"{alpha:>6.2f} | {pi[0]:>10.6f} | {pi[1]:>10.6f} | {pi[2]:>10.6f} | {pi[3]:>10.6f}")

3. Cryptography: RSA Encryption

Notation: Let \(n = pq\) where \(p, q\) are distinct primes. Choose \(e\) such that \(\gcd(e, \phi(n)) = 1\) where \(\phi(n) = (p-1)(q-1)\). Compute \(d\) such that \(ed \equiv 1 \pmod{\phi(n)}\).

Theorem (RSA Correctness):

For any message \(m\) with \(0 \leq m < n\):

\[(m^e)^d \equiv m \pmod{n}\]

That is, decrypting an encrypted message recovers the original.

Notation Explanation:

  • \(\phi(n)\): Euler's totient function (count of integers \(< n\) coprime to \(n\))
  • Public key: \((n, e)\)
  • Private key: \((n, d)\)
  • Encryption: \(c = m^e \mod n\)
  • Decryption: \(m = c^d \mod n\)
Proof:

We need to show \(m^{ed} \equiv m \pmod{n}\). Since \(ed \equiv 1 \pmod{\phi(n)}\), we have \(ed = 1 + k\phi(n)\) for some \(k\).

Case 1: \(\gcd(m, n) = 1\). By Euler's theorem: \(m^{\phi(n)} \equiv 1 \pmod{n}\), so \(m^{ed} = m \cdot (m^{\phi(n)})^k \equiv m \pmod{n}\).

Case 2: \(\gcd(m, n) \neq 1\). WLOG assume \(p | m\). Then \(m^{ed} \equiv 0 \equiv m \pmod{p}\). For \(q\): either \(q | m\) (trivial) or \(\gcd(m, q) = 1\), in which case Euler's theorem applies. By CRT, \(m^{ed} \equiv m \pmod{n}\).

Python Implementation:

import random
from math import gcd

def mod_exp(base, exp, mod):
    """
    Efficient modular exponentiation using binary method
    Computes (base^exp) % mod
    """
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        exp = exp >> 1
        base = (base * base) % mod
    return result

def extended_gcd(a, b):
    """
    Extended Euclidean algorithm
    Returns (g, x, y) such that ax + by = g = gcd(a, b)
    """
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return (g, x, y)

def mod_inverse(a, m):
    """
    Compute modular inverse of a modulo m
    Returns x such that (a * x) % m = 1
    """
    g, x, _ = extended_gcd(a, m)
    if g != 1:
        raise ValueError("Modular inverse does not exist")
    return (x % m + m) % m

def generate_rsa_keys(p, q):
    """
    Generate RSA key pair from primes p and q
    """
    n = p * q
    phi = (p - 1) * (q - 1)
    
    # Choose e (commonly 65537 = 2^16 + 1)
    e = 65537
    if gcd(e, phi) != 1:
        # Find suitable e
        for e in range(3, phi, 2):
            if gcd(e, phi) == 1:
                break
    
    # Compute d
    d = mod_inverse(e, phi)
    
    return {
        'public': (n, e),
        'private': (n, d),
        'phi': phi
    }

def rsa_encrypt(message, public_key):
    """Encrypt message using public key"""
    n, e = public_key
    return mod_exp(message, e, n)

def rsa_decrypt(ciphertext, private_key):
    """Decrypt ciphertext using private key"""
    n, d = private_key
    return mod_exp(ciphertext, d, n)

def rsa_demo():
    """
    Demonstrate RSA encryption/decryption
    """
    # Small primes for demonstration
    p = 61
    q = 53
    
    print("RSA Encryption Demo")
    print(f"Primes: p = {p}, q = {q}")
    
    keys = generate_rsa_keys(p, q)
    n, e = keys['public']
    _, d = keys['private']
    
    print(f"n = p × q = {n}")
    print(f"φ(n) = (p-1)(q-1) = {keys['phi']}")
    print(f"Public key: (n={n}, e={e})")
    print(f"Private key: (n={n}, d={d})")
    
    # Test with a message
    message = 42
    print(f"\nOriginal message: {message}")
    
    ciphertext = rsa_encrypt(message, keys['public'])
    print(f"Encrypted: {ciphertext}")
    
    decrypted = rsa_decrypt(ciphertext, keys['private'])
    print(f"Decrypted: {decrypted}")
    
    print(f"\nVerification: {message} == {decrypted} ? {message == decrypted}")
    
    # Verify the math: m^(ed) mod n = m
    verification = mod_exp(message, e * d, n)
    print(f"m^(ed) mod n = {verification}")

def rsa_text_demo():
    """
    Encrypt/decrypt a text message
    """

    # Convert back to text

    char2 = chr(decrypted_num % 256)
    print(f"Decrypted text: '{char1}{char2}'")

1. Homology: Simplicial Homology and the Betti Numbers

Notation: For a simplicial complex \(K\), define the chain groups \(C_n(K)\) as the free abelian group generated by \(n\)-simplices. The boundary operator \(\partial_n: C_n \to C_{n-1}\) satisfies \(\partial_{n-1} \circ \partial_n = 0\).

Theorem (Homology Groups):

The \(n\)-th homology group is:

\[H_n(K) = \frac{\ker(\partial_n)}{\text{im}(\partial_{n+1})}\]

The \(n\)-th Betti number is \(\beta_n = \text{rank}(H_n(K))\), counting \(n\)-dimensional "holes."

Notation Explanation:

  • \(C_n(K)\): Group of \(n\)-chains (formal sums of \(n\)-simplices)
  • \(\partial_n\): Boundary operator
  • \(\ker(\partial_n)\): \(n\)-cycles (closed chains)
  • \(\text{im}(\partial_{n+1})\): \(n\)-boundaries (boundaries of chains)
Key Property:

The fundamental relation \(\partial^2 = 0\) ensures \(\text{im}(\partial_{n+1}) \subseteq \ker(\partial_n)\), making the quotient well-defined. Intuitively, homology measures cycles that are not boundaries—topological "holes."

Python Implementation:

import numpy as np
from itertools import combinations

class SimplicialComplex:
    """
    Simple implementation of simplicial homology
    """
    def __init__(self, simplices):
        """
        simplices: list of tuples representing simplices
        e.g., [(0,), (1,), (2,), (0,1), (1,2), (0,2)] for a triangle
        """
        self.simplices = sorted(simplices, key=len)
        self.max_dim = max(len(s) - 1 for s in simplices) if simplices else -1
        
    def get_simplices(self, dim):
        """Get all simplices of dimension dim"""
        return [s for s in self.simplices if len(s) == dim + 1]
    
    def boundary_matrix(self, dim):
        """
        Compute boundary matrix ∂_dim: C_dim -> C_{dim-1}
        """
        if dim == 0:
            return np.zeros((1, len(self.get_simplices(0))))
        
        n_simplices = self.get_simplices(dim)
        n_minus_1 = self.get_simplices(dim - 1)
        
        if not n_simplices or not n_minus_1:
            return np.zeros((len(n_minus_1), len(n_simplices)))
        
        # Map simplices to indices
        idx_map = {s: i for i, s in enumerate(n_minus_1)}
        
        matrix = np.zeros((len(n_minus_1), len(n_simplices)), dtype=int)
        
        for j, simplex in enumerate(n_simplices):
            # Boundary is alternating sum of faces
            for i, v in enumerate(simplex):
                face = tuple(simplex[:i] + simplex[i+1:])
                if face in idx_map:
                    matrix[idx_map[face], j] = (-1)**i
        
        return matrix
    
    def betti_numbers(self):
        """
        Compute Betti numbers using rank-nullity theorem
        β_n = dim(ker ∂_n) - dim(im ∂_{n+1})
        """
        betti = []
        
        for dim in range(self.max_dim + 1):
            d_n = self.boundary_matrix(dim)
            d_n_plus_1 = self.boundary_matrix(dim + 1)
            
            # Rank of boundary operators
            rank_d_n = np.linalg.matrix_rank(d_n) if d_n.size > 0 else 0
            rank_d_n_plus_1 = np.linalg.matrix_rank(d_n_plus_1) if d_n_plus_1.size > 0 else 0
            
            # Number of n-simplices
            n_simplices = len(self.get_simplices(dim))
            
            # β_n = dim(C_n) - rank(∂_n) - rank(∂_{n+1})
            beta = n_simplices - rank_d_n - rank_d_n_plus_1
            betti.append(max(0, beta))
        
        return betti

2. Modular Forms: The Modular Discriminant

Notation: Let \(\mathbb{H} = \{z \in \mathbb{C} : \text{Im}(z) > 0\}\) be the upper half-plane. A modular form of weight \(k\) satisfies:

\[f\left(\frac{az + b}{cz + d}\right) = (cz + d)^k f(z)\]

for all \(\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in SL_2(\mathbb{Z})\).

Theorem (Modular Discriminant):

The modular discriminant \(\Delta(z)\) is a cusp form of weight 12:

\[\Delta(z) = (2\pi)^{12} q \prod_{n=1}^{\infty} (1 - q^n)^{24} = \sum_{n=1}^{\infty} \tau(n) q^n\]

where \(q = e^{2\pi i z}\) and \(\tau(n)\) is the Ramanujan tau function.

Notation Explanation:

  • \(SL_2(\mathbb{Z})\): Special linear group over integers (\(ad - bc = 1\))
  • \(q\)-expansion: Fourier expansion in \(q = e^{2\pi i z}\)
  • Cusp form: Vanishes at cusps (\(q \to 0\))
Key Properties:
  1. \(\Delta(z) = g_2(z)^3 - 27g_3(z)^2\) where \(g_2, g_3\) are Eisenstein series
  2. \(\Delta(z) \neq 0\) on \(\mathbb{H}\) (fundamental for the theory)
  3. Ramanujan conjecture: \(|\tau(p)| \leq 2p^{11/2}\) for prime \(p\) (proved by Deligne)

Python Implementation:

import numpy as np
import cmath

def compute_delta(z, n_terms=50):
    """
    Compute modular discriminant Δ(z) via q-expansion
    Δ(z) = (2π)^12 * q * ∏(1-q^n)^24
    """
    q = cmath.exp(2j * np.pi * z)
    
    # Compute product
    product = 1.0
    for n in range(1, n_terms + 1):
        product *= (1 - q**n)**24
    
    delta = (2 * np.pi)**12 * q * product
    return delta

def ramanujan_tau(n_max, n_product_terms=100):
    """
    Compute Ramanujan tau function values
    τ(n) are coefficients in Δ(z) = Σ τ(n) q^n
    """
    # Using Euler's pentagonal theorem for computation
    # τ(n) can be computed from the generating function
    
    # Initialize
    tau = [0] * (n_max + 1)
    tau[0] = 0  # No constant term
    
    # Use recurrence from the product formula
    # ∏(1-q^n)^24 has known expansion
    # We'll use a direct approach for small n
    
    # Known values of tau function
    known_tau = {
        1: 1, 2: -24, 3: 252, 4: -1472, 5: 4830,
        6: -6048, 7: -16744, 8: 84480, 9: -113643, 10: -115920
    }
    
    for n, val in known_tau.items():
        if n <= n_max:
            tau[n] = val
    
    return tau

def verify_multiplicative_property():
    """
    Verify that τ(mn) = τ(m)τ(n) when gcd(m,n) = 1
    (Ramanujan proved τ is multiplicative)
    """
    tau = ramanujan_tau(20)
    
    print("Ramanujan Tau Function - Multiplicative Property")

    print(f"τ(2) × τ(3) = {tau[2] * tau[3]}")
    print(f"Multiplicative: {tau[6] == tau[2] * tau[3]}")
    
    print(f"\nτ(2) = {tau[2]}, τ(5) = {tau[5]}")
    print(f"τ(10) = {tau[10]}")
    print(f"τ(2) × τ(5) = {tau[2] * tau[5]}")
    print(f"Multiplicative: {tau[10] == tau[2] * tau[5]}")

def compute_eisenstein_series(z, k, n_terms=50):
    """
    Eisenstein series G_k(z) = Σ_{(m,n)≠(0,0)} (mz + n)^{-k}
    For k ≥ 4 even
    """
    q = cmath.exp(2j * np.pi * z)
    
    # Normalized Eisenstein series
    # E_k(z) = 1 - (2k/B_k) Σ σ_{k-1}(n) q^n
    # where B_k are Bernoulli numbers
    
    result = 1.0
    for n in range(1, n_terms + 1):
        sigma = sum(d**(k-1) for d in range(1, n+1) if n % d == 0)
        result -= (2*k / bernoulli(k)) * sigma * q**n
    
    return result

def bernoulli(n):
    """First few Bernoulli numbers"""
    bernoulli_vals = {
        0: 1, 1: -1/2, 2: 1/6, 4: -1/30, 6: 1/42,
        8: -1/30, 10: 5/66, 12: -691/2730
    }
    return bernoulli_vals.get(n, 0)

def delta_from_eisenstein(z):
    """
    Δ(z) = g_2(z)^3 - 27*g_3(z)^2
    where g_2 = 60*G_4, g_3 = 140*G_6
    """
    # This is a simplified version
    # In practice, use the q-expansion for computation
    q = cmath.exp(2j * np.pi * z)
    
    # Approximate with first few terms
    delta_approx = (2*np.pi)**12 * (q - 24*q**2 + 252*q**3 - 1472*q**4)
    
    return delta_approx

3. Dynamical Systems: The Logistic Map and Chaos

Notation: The logistic map is defined by:

\[x_{n+1} = r x_n (1 - x_n)\]

where \(r \in [0, 4]\) is the growth parameter and \(x_n \in [0, 1]\).

Theorem (Period-Doubling Cascade):

As \(r\) increases from 3 to approximately 3.57, the logistic map undergoes a sequence of period-doubling bifurcations. The bifurcation values \(r_n\) satisfy:

\[\lim_{n \to \infty} \frac{r_n - r_{n-1}}{r_{n+1} - r_n} = \delta \approx 4.669...\]

where \(\delta\) is Feigenbaum's constant, universal for a large class of maps.

Notation Explanation:

  • Fixed point: \(x^* = f(x^*)\)
  • Period-\(n\) orbit: \(f^n(x) = x\) but \(f^k(x) \neq x\) for \(k < n\)
  • \(\delta\): Feigenbaum constant (universal across many dynamical systems)
Stability Analysis:

For a fixed point \(x^*\), linearize: \(f(x^* + \epsilon) \approx f(x^*) + f'(x^*)\epsilon\). The fixed point is stable if \(|f'(x^*)| < 1\).

For the logistic map: \(f'(x) = r(1 - 2x)\). At \(x^* = 1 - 1/r\) (non-zero fixed point), \(f'(x^*) = 2 - r\). Stability lost when \(r = 3\), leading to period-2 orbit.

import numpy as np
import matplotlib.pyplot as plt

def logistic_map(x, r):
    """Logistic map: f(x) = r*x*(1-x)"""
    return r * x * (1 - x)

def iterate_logistic(x0, r, n_iterations, n_discard=100):
    """
    Iterate logistic map, discarding transient behavior
    """
    x = x0
    # Discard transient
    for _ in range(n_discard):
        x = logistic_map(x, r)
    
    # Collect values
    values = []
    for _ in range(n_iterations):
        x = logistic_map(x, r)
        values.append(x)
    
    return values

def find_fixed_points(r):
    """
    Find fixed points of logistic map
    x = rx(1-x) => x = 0 or x = 1 - 1/r
    """
    if r <= 1:
        return [0]
    else:
        return [0, 1 - 1/r]

    """

def compute_lyapunov(r, n=10000):
    """
    Compute Lyapunov exponent: λ = lim (1/n) Σ log|f'(x_i)|
    Positive λ indicates chaos
    """
    x = 0.5  # Initial condition
    
    # Discard transient
    for _ in range(1000):
        x = logistic_map(x, r)
    
    # Compute sum
    total = 0
    for _ in range(n):
        x = logistic_map(x, r)
        total += np.log(abs(r * (1 - 2*x)))
    
    return total / n

4. Category Theory: Limits and Universal Properties

Notation: A category \(\mathcal{C}\) consists of objects and morphisms with composition and identity. A diagram \(D: \mathcal{J} \to \mathcal{C}\) is a functor from an index category.

Theorem (Universal Property of Limits):

A limit of diagram \(D\) is an object \(\lim D\) together with projections \(\pi_j: \lim D \to D(j)\) such that for any cone \((C, \{c_j: C \to D(j)\})\) over \(D\), there exists a unique morphism \(u: C \to \lim D\) making all triangles commute:

\[\pi_j \circ u = c_j \quad \text{for all } j\]

Notation Explanation:

  • Cone: Object with morphisms to all objects in the diagram, commuting with diagram arrows
  • \(\pi_j\): Projection morphisms from the limit
  • Universal property: The limit is the "most efficient" cone
Uniqueness:

Suppose \((L, \{\pi_j\})\) and \((L', \{\pi'_j\})\) are both limits. By universal property, there exist unique \(u: L' \to L\) and \(v: L \to L'\). Then \(u \circ v: L \to L\) satisfies \(\pi_j \circ (u \circ v) = \pi_j\), so \(u \circ v = \text{id}_L\) by uniqueness. Similarly \(v \circ u = \text{id}_{L'}\). Hence \(L \cong L'\).

Python Implementation:

"""
Category Theory: Limits in the Category of Sets

We'll implement some basic constructions to illustrate limits:
- Terminal object (limit of empty diagram)
- Product (limit of discrete diagram)
- Equalizer (limit of parallel arrows)
- Pullback (limit of cospan)
"""

class SetObject:
    """Represents a set (object in Set category)"""
    def __init__(self, elements, name=None):
        self.elements = set(elements)
        self.name = name or f"Set({len(elements)})"
    
    def __repr__(self):
        return self.name

class Morphism:
    """Represents a function between sets"""
    def __init__(self, source, target, mapping, name=None):
        self.source = source
        self.target = target
        self.mapping = mapping  # dict: source element -> target element
        self.name = name or "f"
    
    def apply(self, x):
        return self.mapping.get(x)
    
    def compose(self, other):
        """Compose: self ∘ other"""
        if other.target != self.source:
            raise ValueError("Cannot compose: target mismatch")
        new_mapping = {x: self.apply(other.apply(x)) for x in other.source.elements}
        return Morphism(other.source, self.target, new_mapping, f"{self.name}∘{other.name}")

def terminal_object():
    """
    Terminal object in Set: singleton set {*}
    Universal property: For any set A, there exists unique morphism A -> {*}
    """
    term = SetObject(['*'], name='1')
    
    print("Terminal Object in Set")
    print("-" * 40)
    print(f"Terminal object: {term}")
    print("Universal property: For any set A, there's a unique function A -> 1")
    
    # Example
    A = SetObject(['a', 'b', 'c'], name='A')
    unique_map = {x: '*' for x in A.elements}
    f = Morphism(A, term, unique_map, '!')
    print(f"\nExample: Unique morphism from {A} to {term}")
    for x in A.elements:
        print(f"  {x} ↦ {f.apply(x)}")
    
    return term

def product(A, B):
    """
    Product A × B in Set with projections π₁, π₂
    Universal property: For any C with f: C -> A, g: C -> B, 
    there exists unique : C -> A×B
    """
    # Product is Cartesian product
    prod_elements = [(a, b) for a in A.elements for b in B.elements]
    AxB = SetObject(prod_elements, name=f'{A.name}×{B.name}')
    
    # Projections
    pi1_mapping = {(a, b): a for a, b in prod_elements}
    pi2_mapping = {(a, b): b for a, b in prod_elements}
    pi1 = Morphism(AxB, A, pi1_mapping, 'π₁')
    pi2 = Morphism(AxB, B, pi2_mapping, 'π₂')
    
    return AxB, pi1, pi2

def equalizer(f, g):
    """
    Equalizer of f, g: A -> B
    Is the subset {a ∈ A : f(a) = g(a)} with inclusion map
    """
    if f.source != g.source or f.target != g.target:
        raise ValueError("Morphisms must be parallel")
    
    A = f.source
    B = f.target
    
    # Equalizer object: elements where f and g agree
    eq_elements = [a for a in A.elements if f.apply(a) == g.apply(a)]
    Eq = SetObject(eq_elements, name='Eq(f,g)')
    
    # Inclusion morphism
    incl_mapping = {a: a for a in eq_elements}
    incl = Morphism(Eq, A, incl_mapping, 'incl')
    
    return Eq, incl

    f = Morphism(A, B, f_mapping, 'f')

        print(f"  g(incl({a})) = g({a}) = {g.apply(a)}")

def pullback(f, g):
    """
    Pullback of A --f--> C <--g-- B
    Is {(a,b) ∈ A×B : f(a) = g(b)}
    """
    A, B, C = f.source, g.source, f.target
    
    if f.target != g.target:
        raise ValueError("Morphisms must have common target")
    
    # Pullback elements
    pb_elements = [(a, b) for a in A.elements for b in B.elements 
                   if f.apply(a) == g.apply(b)]
    P = SetObject(pb_elements, name='A×_C B')
    
    # Projections
    p1_mapping = {(a, b): a for a, b in pb_elements}
    p2_mapping = {(a, b): b for a, b in pb_elements}
    p1 = Morphism(P, A, p1_mapping, 'p₁')
    p2 = Morphism(P, B, p2_mapping, 'p₂')
    
    return P, p1, p2

def demonstrate_pullback():
    """Demonstrate pullback construction"""
    A = SetObject(['a1', 'a2', 'a3'], name='A')
    B = SetObject(['b1', 'b2'], name='B')
    C = SetObject(['c1', 'c2'], name='C')
    
    f_mapping = {'a1': 'c1', 'a2': 'c2', 'a3': 'c1'}
    g_mapping = {'b1': 'c1', 'b2': 'c2'}
    f = Morphism(A, C, f_mapping, 'f')
    g = Morphism(B, C, g_mapping, 'g')
    
    P, p1, p2 = pullback(f, g)
    
    print("\nPullback in Set")
    print("-" * 40)
    print(f"f: A -> C: {f_mapping}")
    print(f"g: B -> C: {g_mapping}")
    print(f"\nPullback A ×_C B = {P.elements}")
    print("(Pairs (a,b) where f(a) = g(b))")
    
    print(f"\nVerification: f ∘ p₁ = g ∘ p₂")
    for elem in P.elements:
        a, b = elem
        print(f"  f(p₁({elem})) = f({a}) = {f.apply(a)}")
        print(f"  g(p₂({elem})) = g({b}) = {g.apply(b)}")

📜 Math History

The Birth of Modern Geometry: 19th Century Transformations

1820s-1830s: Non-Euclidean Geometry

Janos Bolyai and Nikolai Lobachevsky independently discovered that Euclid's parallel postulate could be replaced, leading to hyperbolic geometry. This shattered the 2000-year belief that Euclidean geometry was the only possible description of space.

1854: Riemann's Habilitation Lecture

Bernhard Riemann's lecture "On the Hypotheses Which Lie at the Foundations of Geometry" introduced the concept of a manifold and Riemannian metric. This work laid the foundation for general relativity and modern differential geometry.

1870s-1880s: Felix Klein's Erlangen Program

Klein proposed that geometry should be classified by transformation groups. This unified approach connected Euclidean, projective, and non-Euclidean geometries under the framework of group theory.

1895: Poincaré's Analysis Situs

Henri Poincaré founded algebraic topology, introducing concepts like homology and the fundamental group. His work on the three-body problem also led to the beginnings of dynamical systems theory.

Legacy: These 19th-century developments transformed mathematics from a study of fixed structures to the study of spaces, transformations, and invariants—concepts that now permeate every branch of mathematics and physics.
