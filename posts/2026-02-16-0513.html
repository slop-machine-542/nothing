1. Functional Analysis: The Hahn-Banach Theorem

Introduction

Functional analysis is the study of infinite-dimensional vector spaces and the linear functions defined on them. It emerged in the early 20th century to provide a rigorous foundation for calculus of variations, differential equations, and quantum mechanics.

The Hahn-Banach Theorem is arguably the most important theorem in functional analysis. It states that a bounded linear functional defined on a subspace can be extended to the entire space without increasing its norm. This seemingly simple result has profound consequences throughout analysis.

Notation Guide

  • \\(X\\) — a normed vector space over \\(\\mathbb{R}\\) or \\(\\mathbb{C}\\)
  • \\(X^*\\) — the dual space of continuous linear functionals on \\(X\\)
  • \\(\\|f\\| = \\sup_{\\|x\\|=1}|f(x)|\\) — the operator norm
  • \\(p: X \\to \\mathbb{R}\\) — a sublinear functional (satisfies \\(p(x+y) \\leq p(x) + p(y)\\) and \\(p(\\alpha x) = \\alpha p(x)\\) for \\(\\alpha \\geq 0\\))
  • \\(M \\subseteq X\\) — a subspace of \\(X\\)
Hahn-Banach Theorem (Real Version)

Let \\(X\\) be a real vector space, \\(p: X \\to \\mathbb{R}\\) a sublinear functional, \\(M \\subseteq X\\) a subspace, and \\(f: M \\to \\mathbb{R}\\) a linear functional satisfying \\(f(x) \\leq p(x)\\) for all \\(x \\in M\\).

Then there exists a linear extension \\(F: X \\to \\mathbb{R}\\) such that:

\\[F|_M = f \\quad \\text{and} \\quad F(x) \\leq p(x) \\text{ for all } x \\in X\\]

Proof Sketch (by Zorn's Lemma)

Step 1: Consider the set \\(\\mathcal{P}\\) of all pairs \\((N, g)\\) where \\(N\\) is a subspace containing \\(M\\) and \\(g: N \\to \\mathbb{R}\\) extends \\(f\\) with \\(g(x) \\leq p(x)\\) on \\(N\\).

Step 2: Define a partial order: \\((N_1, g_1) \\leq (N_2, g_2)\\) if \\(N_1 \\subseteq N_2\\) and \\(g_2|_{N_1} = g_1\\).

Step 3: Show every chain has an upper bound (take unions), so by Zorn's Lemma, a maximal element \\((N_{max}, F)\\) exists.

Step 4: Prove \\(N_{max} = X\\) by contradiction: if \\(y \\in X \\setminus N_{max}\\), extend \\(F\\) to \\(\\text{span}(N_{max} \\cup \\{y\\})\\) by defining:

\\[F(x + \\alpha y) = F(x) + \\alpha c\\]

where \\(c\\) is carefully chosen to maintain \\(F \\leq p\\).

Step 5: The key constraint is that for all \\(x_1, x_2 \\in N_{max}\\):

\\[F(x_1) - p(x_1 - y) \\leq c \\leq p(x_2 + y) - F(x_2)\\]

Such a \\(c\\) exists because \\(F(x_1) + F(x_2) = F(x_1 + x_2) \\leq p(x_1 + x_2) \\leq p(x_1 - y) + p(x_2 + y)\\).

Python Implementation: Norm Computation

import numpy as np
from scipy.optimize import linprog

def hahn_banach_extension(subspace_basis, functional_values, point, norm_type='l2'):
    """
    Compute the norm of a linear functional using Hahn-Banach duality.
    
    For a subspace M with basis {v1, ..., vk} and functional f defined by
    f(vi) = ci, find the operator norm of f.
    
    Args:
        subspace_basis: List of basis vectors (each a numpy array)
        functional_values: Values of f on each basis vector
        point: Point at which to evaluate the extension
        norm_type: 'l1', 'l2', or 'linf'
    
    Returns:
        Dictionary with norm and extension information
    """
    # Convert to matrix form
    V = np.column_stack(subspace_basis)
    c = np.array(functional_values)
    
    # The norm of f is the minimum norm of any extension
    # For finite dimensions, this can be computed via optimization
    
    if norm_type == 'l2':
        # For L2 norm: ||f|| = sqrt(c^T (V^T V)^{-1} c)
        gram_matrix = V.T @ V
        try:
            norm = np.sqrt(c @ np.linalg.solve(gram_matrix, c))
        except np.linalg.LinAlgError:
            # Use pseudoinverse for numerical stability
            norm = np.sqrt(c @ np.linalg.lstsq(gram_matrix, c, rcond=None)[0])
        
        return {
            'operator_norm': norm,
            'gram_matrix': gram_matrix,
            'functional_values': c
        }
    
    elif norm_type == 'l1':
        # L1 norm requires linear programming
        n = len(point)
        # Minimize ||x||_1 subject to V^T x = c
        # This is a standard basis pursuit problem
        c_obj = np.ones(2 * n)  # For x = u - v where u, v >= 0
        A_eq = np.hstack([V.T, -V.T])
        b_eq = c
        bounds = [(0, None) for _ in range(2 * n)]
        
        result = linprog(c_obj, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
        return {
            'operator_norm': result.fun if result.success else None,
            'solution': result.x[:n] - result.x[n:] if result.success else None
        }

2. Algebraic Topology: Simplicial Homology

Introduction

Algebraic topology uses algebraic tools to study topological spaces. While the fundamental group captures 1-dimensional "holes," homology groups capture holes of all dimensions in a systematic way.

Simplicial homology is the most concrete version, defined for spaces built from simplices (points, line segments, triangles, tetrahedra, etc.). It counts \\(n\\)-dimensional cycles that are not boundaries of \\((n+1)\\)-dimensional objects.

Notation Guide

  • \\(\\Delta^n\\) — the standard n-simplex
  • \\(C_n(K)\\) — the group of n-chains (formal sums of n-simplices)
  • \\(\\partial_n: C_n \\to C_{n-1}\\) — the boundary operator
  • \\(Z_n = \\ker(\\partial_n)\\) — n-cycles (chains with zero boundary)
  • \\(B_n = \\text{im}(\\partial_{n+1})\\) — n-boundaries
  • \\(H_n(K) = Z_n / B_n\\) — the nth homology group
  • \\(\\beta_n = \\text{rank}(H_n)\\) — the nth Betti number
Fundamental Property of the Boundary Operator

For any simplicial complex \\(K\\):

\\[\\partial_{n-1} \\circ \\partial_n = 0\\]

Equivalently: \\(\\text{im}(\\partial_{n+1}) \\subseteq \\ker(\\partial_n)\\), so boundaries are always cycles.

Proof

Step 1: It suffices to check on a single simplex. Let \\(\\sigma = [v_0, v_1, \\ldots, v_n]\\).

Step 2: The boundary is:

\\[\\partial_n(\\sigma) = \\sum_{i=0}^{n} (-1)^i [v_0, \\ldots, \\hat{v}_i, \\ldots, v_n]\\]

where \\(\\hat{v}_i\\) means omit vertex \\(v_i\\).

Step 3: Apply \\(\\partial_{n-1}\\):

\\[\\partial_{n-1}(\\partial_n(\\sigma)) = \\sum_{i=0}^{n} (-1)^i \\partial_{n-1}([v_0, \\ldots, \\hat{v}_i, \\ldots, v_n])\\]

Step 4: Each face \\([v_0, \\ldots, \\hat{v}_i, \\ldots, \\hat{v}_j, \\ldots, v_n]\\) appears exactly twice:

  • Once when omitting \\(v_i\\) first (from the outer sum), then \\(v_j\\) (from the inner), with sign \\((-1)^i \\cdot (-1)^{j-1}\\)
  • Once when omitting \\(v_j\\) first, then \\(v_i\\), with sign \\((-1)^j \\cdot (-1)^i\\)

Step 5: These signs are opposite: \\((-1)^{i+j-1} + (-1)^{i+j} = 0\\). All terms cancel pairwise. \\(\\square\\)

Homology of the 2-Sphere

For the 2-sphere \\(S^2\\):

\\[H_n(S^2) \\cong \\begin{cases} \\mathbb{Z} & n = 0, 2 \\\\ 0 & n = 1 \\\\ 0 & n \\geq 3 \\end{cases}\\]

The Betti numbers are \\(\\beta_0 = 1\\) (connected), \\(\\beta_1 = 0\\) (no 1-d holes), \\(\\beta_2 = 1\\) (one 2-d void).

import numpy as np
from itertools import combinations
from collections import defaultdict

class SimplicialComplex:
    """A simplicial complex represented by its maximal simplices."""
    
    def __init__(self, maximal_simplices):
        """
        Args:
            maximal_simplices: List of lists/tuples, each representing a simplex
        """
        self.maximal = [tuple(sorted(s)) for s in maximal_simplices]
        self.simplices = self._generate_all_simplices()
    
    def _generate_all_simplices(self):
        """Generate all faces of all dimensions."""
        all_simplices = defaultdict(set)
        for simplex in self.maximal:
            for r in range(1, len(simplex) + 1):
                for face in combinations(simplex, r):
                    all_simplices[r - 1].add(face)
        return {dim: sorted(list(simplices)) for dim, simplices in all_simplices.items()}
    
    def boundary_matrix(self, n):
        """Compute the boundary matrix ∂_n: C_n → C_{n-1}."""
        if n not in self.simplices or (n - 1) not in self.simplices:
            return np.zeros((0, 0))
        
        n_simplices = self.simplices[n]
        n_minus_1_simplices = self.simplices[n - 1]
        
        # Create index mapping
        idx_map = {s: i for i, s in enumerate(n_minus_1_simplices)}
        
        rows = len(n_minus_1_simplices)
        cols = len(n_simplices)
        matrix = np.zeros((rows, cols), dtype=int)
        
        for j, simplex in enumerate(n_simplices):
            for i, vertex in enumerate(simplex):
                face = simplex[:i] + simplex[i+1:]
                if face in idx_map:
                    matrix[idx_map[face], j] = (-1) ** i
        
        return matrix
    
    def homology_rank(self, n):
        """Compute the nth Betti number using rank-nullity."""
        if n not in self.simplices:
            return 0
        
        # H_n = ker(∂_n) / im(∂_{n+1})
        # β_n = dim(ker ∂_n) - dim(im ∂_{n+1})
        #     = dim(C_n) - rank(∂_n) - rank(∂_{n+1})
        
        d_n = self.boundary_matrix(n)
        d_n_plus_1 = self.boundary_matrix(n + 1)
        
        rank_d_n = np.linalg.matrix_rank(d_n)
        rank_d_n_plus_1 = np.linalg.matrix_rank(d_n_plus_1)
        dim_C_n = len(self.simplices.get(n, []))
        
        return dim_C_n - rank_d_n - rank_d_n_plus_1

3. Combinatorics: Ramsey Theory

Introduction

Ramsey theory is a branch of combinatorics that studies conditions under which order must appear. Its central philosophy: complete disorder is impossible. In any sufficiently large system, there must exist structured subsystems.

The classic example: in any group of six people, there are either three mutual acquaintances or three mutual strangers. This is \\(R(3,3) = 6\\).

Notation Guide

  • \\(R(s, t)\\) — the Ramsey number: minimum \\(n\\) such that any 2-coloring of \\(K_n\\) edges contains a red \\(K_s\\) or blue \\(K_t\\)
  • \\(K_n\\) — the complete graph on \\(n\\) vertices
  • \\(\\binom{n}{k}\\) — binomial coefficient, number of \\(k\\)-subsets of an \\(n\\)-set
  • \\(\\chi\\) — chromatic number
Ramsey's Theorem (Graph Version)

For any positive integers \\(s, t \\geq 2\\), there exists a least positive integer \\(R(s, t)\\) such that every edge-coloring of the complete graph \\(K_n\\) with \\(n \\geq R(s, t)\\) vertices (using red and blue) contains either:

  • A red complete subgraph \\(K_s\\), or
  • A blue complete subgraph \\(K_t\\)
Proof (by induction on \\(s + t\\))

Base case: \\(R(2, t) = t\\) and \\(R(s, 2) = s\\). Trivial: any edge coloring of \\(K_t\\) either has a red edge (giving red \\(K_2\\)) or is entirely blue (giving blue \\(K_t\\)).

Inductive step: Assume \\(R(s-1, t)\\) and \\(R(s, t-1)\\) exist. We'll show:

\\[R(s, t) \\leq R(s-1, t) + R(s, t-1)\\]

Step 1: Let \\(n = R(s-1, t) + R(s, t-1)\\) and consider any 2-coloring of \\(K_n\\). Pick any vertex \\(v\\).

Step 2: Let \\(R\\) be the set of vertices connected to \\(v\\) by red edges, \\(B\\) by blue edges. Then \\(|R| + |B| = n - 1 = R(s-1, t) + R(s, t-1) - 1\\).

Step 3: By pigeonhole principle, either \\(|R| \\geq R(s-1, t)\\) or \\(|B| \\geq R(s, t-1)\\).

Step 4: If \\(|R| \\geq R(s-1, t)\\): The subgraph on \\(R\\) contains either:

  • Red \\(K_{s-1}\\): together with \\(v\\), forms red \\(K_s\\)
  • Blue \\(K_t\\): we're done

Step 5: Similarly if \\(|B| \\geq R(s, t-1)\\).

Step 6: This gives the recurrence \\(R(s, t) \\leq R(s-1, t) + R(s, t-1)\\), completing the induction. \\(\\square\\)

Upper Bound

\\[R(s, t) \\leq \\binom{s+t-2}{s-1}\\]

In particular: \\(R(s, s) \\leq \\binom{2s-2}{s-1} \\sim \\frac{4^{s-1}}{\\sqrt{\\pi(s-1)}}\\)

import numpy as np
from itertools import combinations
import networkx as nx

def ramsey_upper_bound(s, t):
    """
    Compute the upper bound R(s,t) ≤ C(s+t-2, s-1) using the recurrence.
    """
    from math import comb
    return comb(s + t - 2, s - 1)

def check_ramsey_property(n, s, t, coloring):
    """
    Check if a given edge coloring of K_n has red K_s or blue K_t.
    
    Args:
        n: number of vertices
        s: size of red clique to find
        t: size of blue clique to find
        coloring: dict mapping edges (i,j) to 'red' or 'blue'
    
    Returns:
        (has_red_Ks, has_blue_Kt, red_clique, blue_clique)
    """
    # Build adjacency matrices
    red_edges = set()
    blue_edges = set()
    
    for (i, j), color in coloring.items():
        if color == 'red':
            red_edges.add((min(i,j), max(i,j)))
        else:
            blue_edges.add((min(i,j), max(i,j)))
    
    # Check for red K_s
    red_clique = None
    for vertices in combinations(range(n), s):
        if all((min(v1,v2), max(v1,v2)) in red_edges 
               for v1, v2 in combinations(vertices, 2)):
            red_clique = vertices
            break
    
    # Check for blue K_t
    blue_clique = None
    for vertices in combinations(range(n), t):
        if all((min(v1,v2), max(v1,v2)) in blue_edges 
               for v1, v2 in combinations(vertices, 2)):
            blue_clique = vertices
            break
    
    return (red_clique is not None, blue_clique is not None, 
            red_clique, blue_clique)

1. Numerical Analysis: Newton-Raphson Method

Introduction

The Newton-Raphson method is one of the most powerful techniques for finding roots of nonlinear equations. It uses local linear approximation to iteratively converge to a solution with quadratic convergence rate.

Notation Guide

  • \\(f: \\mathbb{R}^n \\to \\mathbb{R}^n\\) — a differentiable function
  • \\(Df(x)\\) or \\(J_f(x)\\) — the Jacobian matrix of \\(f\\) at \\(x\\)
  • \\(x^*\\) — a root: \\(f(x^*) = 0\\)
  • \\(e_k = x_k - x^*\\) — the error at iteration \\(k\\)
  • \\(O(\\cdot)\\) — big-O notation for convergence rates
Newton-Raphson Iteration

Given \\(f: \\mathbb{R}^n \\to \\mathbb{R}^n\\) and initial guess \\(x_0\\), the Newton iteration is:

\\[x_{k+1} = x_k - [Df(x_k)]^{-1}f(x_k)\\]

Equivalently: solve \\(Df(x_k) \\Delta x = -f(x_k)\\) for \\(\\Delta x\\), then \\(x_{k+1} = x_k + \\Delta x\\).

Local Quadratic Convergence

Let \\(f\\) be twice continuously differentiable with \\(f(x^*) = 0\\). If \\(Df(x^*)\\) is invertible and \\(x_0\\) is sufficiently close to \\(x^*\\), then:

\\[\\|x_{k+1} - x^*\\| \\leq C\\|x_k - x^*\\|^2\\]

for some constant \\(C > 0\\). The number of correct digits roughly doubles each iteration.

Proof of Quadratic Convergence

Step 1: Taylor expand \\(f\\) around \\(x_k\\):

\\[f(x^*) = f(x_k) + Df(x_k)(x^* - x_k) + O(\\|x^* - x_k\\|^2)\\]

Since \\(f(x^*) = 0\\):

\\[0 = f(x_k) + Df(x_k)(x^* - x_k) + O(\\|e_k\\|^2)\\]

Step 2: The Newton update gives:

\\[x_{k+1} = x_k - [Df(x_k)]^{-1}f(x_k)\\]

Step 3: Compute the new error:

\\[e_{k+1} = x_{k+1} - x^* = x_k - x^* - [Df(x_k)]^{-1}f(x_k)\\]

\\[= e_k - [Df(x_k)]^{-1}f(x_k)\\]

Step 4: From Step 1: \\(f(x_k) = -Df(x_k)e_k + O(\\|e_k\\|^2)\\)

So: \\(e_{k+1} = e_k - [Df(x_k)]^{-1}(-Df(x_k)e_k + O(\\|e_k\\|^2))\\)

\\[= e_k + e_k - [Df(x_k)]^{-1}O(\\|e_k\\|^2) = O(\\|e_k\\|^2)\\)

Step 5: More precisely, using Lipschitz continuity of \\(Df\\):

\\[\\|e_{k+1}\\| \\leq \\frac{1}{2}\\|[Df(x^*)]^{-1}\\| \\cdot L \\cdot \\|e_k\\|^2\\]

where \\(L\\) is the Lipschitz constant of \\(Df\\). \\(\\square\\)

Python Implementation

import numpy as np
from scipy.optimize import fsolve
import matplotlib.pyplot as plt

def newton_raphson(f, df, x0, tol=1e-10, max_iter=100, verbose=False):
    """
    Newton-Raphson method for solving f(x) = 0.
    
    Args:
        f: Function R^n → R^n
        df: Jacobian of f
        x0: Initial guess
        tol: Convergence tolerance
        max_iter: Maximum iterations
        verbose: Print iteration details
    
    Returns:
        (root, converged, iterations, history)
    """
    x = np.array(x0, dtype=float)
    history = [x.copy()]
    
    for i in range(max_iter):
        fx = f(x)
        Dfx = df(x)
        
        # Solve Df(x) * delta = -f(x)
        try:
            delta = np.linalg.solve(Dfx, -fx)
        except np.linalg.LinAlgError:
            # Use least squares if singular
            delta = np.linalg.lstsq(Dfx, -fx, rcond=None)[0]
        
        x_new = x + delta
        history.append(x_new.copy())
        
        if verbose:
            print(f"Iter {i+1}: x = {x_new}, ||f(x)|| = {np.linalg.norm(f(x_new)):.2e}")
        
        if np.linalg.norm(delta) < tol:
            return x_new, True, i+1, history
        
        x = x_new
    
    return x, False, max_iter, history

2. Cryptography: The RSA Algorithm

Introduction

RSA (Rivest-Shamir-Adleman) is one of the first public-key cryptosystems and is widely used for secure data transmission. Its security relies on the practical difficulty of factoring the product of two large prime numbers.

Notation Guide

  • \\(p, q\\) — large prime numbers (kept secret)
  • \\(n = pq\\) — the RSA modulus (public)
  • \\(\\phi(n) = (p-1)(q-1)\\) — Euler's totient function
  • \\(e\\) — public exponent, \\(\\gcd(e, \\phi(n)) = 1\\)
  • \\(d\\) — private exponent, \\(ed \\equiv 1 \\pmod{\\phi(n)}\\)
  • \\(m\\) — message (plaintext)
  • \\(c = m^e \\pmod{n}\\) — ciphertext
RSA Correctness

For any message \\(m\\) with \\(0 \\leq m < n\\):

\\[(m^e)^d \\equiv m \\pmod{n}\\]

That is, decrypting the encrypted message recovers the original.

Proof

Step 1: Since \\(ed \\equiv 1 \\pmod{\\phi(n)}\\), we have \\(ed = 1 + k\\phi(n)\\) for some integer \\(k\\).

Step 2: We need to show \\(m^{ed} \\equiv m \\pmod{n}\\), i.e., \\(m^{1+k\\phi(n)} \\equiv m \\pmod{n}\\).

Step 3: By the Chinese Remainder Theorem, it suffices to show:

\\[m^{ed} \\equiv m \\pmod{p} \\quad \\text{and} \\quad m^{ed} \\equiv m \\pmod{q}\\]

Step 4: Consider \\(\\pmod{p}\\). If \\(p \\nmid m\\), then \\(m \\equiv 0\\) and trivially \\(m^{ed} \\equiv 0 \\equiv m\\).

Step 5: If \\(p \\nmid\\!\\!\\!\\backslash \\, m\\), by Fermat's Little Theorem: \\(m^{p-1} \\equiv 1 \\pmod{p}\\).

Step 6: Since \\(\\phi(n) = (p-1)(q-1)\\):

\\[m^{ed} = m^{1+k\\phi(n)} = m \\cdot (m^{p-1})^{k(q-1)} \\equiv m \\cdot 1^{k(q-1)} \\equiv m \\pmod{p}\\]

Step 7: Same argument applies \\(\\pmod{q}\\). By CRT, \\(m^{ed} \\equiv m \\pmod{n}\\). \\(\\square\\)

Euler's Theorem (used in RSA)

If \\(\\gcd(a, n) = 1\\), then:

\\[a^{\\phi(n)} \\equiv 1 \\pmod{n}\\]

where \\(\\phi(n)\\) counts integers from \\(1\\) to \\(n\\) that are coprime to \\(n\\).

Python Implementation

import random
from math import gcd

def is_prime(n, k=10):
    """Miller-Rabin primality test."""
    if n < 2: return False
    if n in (2, 3): return True
    if n % 2 == 0: return False
    
    # Write n-1 as 2^r * d
    r, d = 0, n - 1
    while d % 2 == 0:
        r += 1
        d //= 2
    
    for _ in range(k):
        a = random.randrange(2, n - 1)
        x = pow(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(r - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False
    return True

def generate_prime(bits):
    """Generate a random prime with specified bit length."""
    while True:
        n = random.getrandbits(bits) | 1 | (1 << (bits - 1))
        if is_prime(n):
            return n

def mod_inverse(a, m):
    """Compute modular inverse using extended Euclidean algorithm."""
    def extended_gcd(a, b):
        if b == 0:
            return a, 1, 0
        g, x1, y1 = extended_gcd(b, a % b)
        x = y1
        y = x1 - (a // b) * y1
        return g, x, y
    
    g, x, _ = extended_gcd(a % m, m)
    if g != 1:
        raise ValueError("Modular inverse does not exist")
    return (x % m + m) % m

class RSA:
    """RSA encryption/decryption implementation."""
    
    def __init__(self, key_bits=512):
        """Generate RSA key pair."""
        # Generate two distinct primes
        self.p = generate_prime(key_bits // 2)
        self.q = generate_prime(key_bits // 2)
        while self.q == self.p:
            self.q = generate_prime(key_bits // 2)
        
        self.n = self.p * self.q
        self.phi = (self.p - 1) * (self.q - 1)
        
        # Choose public exponent (common choices: 3, 17, 65537)
        self.e = 65537
        while gcd(self.e, self.phi) != 1:
            self.e += 2
        
        # Compute private exponent
        self.d = mod_inverse(self.e, self.phi)
        
        print(f"Generated RSA-{key_bits} keys")
        print(f"  n = {self.n}... ({self.n.bit_length()} bits)")
        print(f"  e = {self.e}")
    
    def public_key(self):
        """Return public key (e, n)."""
        return (self.e, self.n)
    
    def private_key(self):
        """Return private key (d, n)."""
        return (self.d, self.n)
    
    def encrypt(self, message, public_key=None):
        """Encrypt a message (integer or string)."""
        if public_key is None:
            public_key = self.public_key()
        e, n = public_key
        
        if isinstance(message, str):
            # Convert string to integer
            message_bytes = message.encode('utf-8')
            m = int.from_bytes(message_bytes, 'big')
        else:
            m = message
        
        if m >= n:
            raise ValueError("Message too long for this key")
        
        return pow(m, e, n)
    
    def decrypt(self, ciphertext):
        """Decrypt ciphertext to recover message."""
        m = pow(ciphertext, self.d, self.n)
        
        # Try to convert back to string
        try:
            byte_length = (m.bit_length() + 7) // 8
            message_bytes = m.to_bytes(byte_length, 'big')
            return message_bytes.decode('utf-8')
        except:
            return m
    
    def sign(self, message):
        """Sign a message using private key."""
        if isinstance(message, str):
            message_bytes = message.encode('utf-8')
            m = int.from_bytes(message_bytes, 'big')
        else:
            m = message
        return pow(m, self.d, self.n)
    
    def verify(self, message, signature, public_key=None):
        """Verify a signature using public key."""
        if public_key is None:
            public_key = self.public_key()
        e, n = public_key
        
        if isinstance(message, str):
            message_bytes = message.encode('utf-8')
            m = int.from_bytes(message_bytes, 'big')
        else:
            m = message
        
        return pow(signature, e, n) == m % n

3. Mathematical Biology: Lotka-Volterra Predator-Prey Model

Introduction

The Lotka-Volterra equations describe the dynamics of biological systems in which two species interact, one as a predator and one as prey. Developed independently by Alfred Lotka (1925) and Vito Volterra (1926), these equations are foundational in mathematical ecology.

Notation Guide

  • \\(x(t)\\) — prey population at time \\(t\\)
  • \\(y(t)\\) — predator population at time \\(t\\)
  • \\(\\alpha\\) — prey growth rate (in absence of predators)
  • \\(\\beta\\) — predation rate coefficient
  • \\(\\gamma\\) — predator death rate (in absence of prey)
  • \\(\\delta\\) — predator efficiency (converting prey to offspring)
  • \\(\\dot{x} = dx/dt\\) — time derivative
Lotka-Volterra Equations

\\[\\begin{aligned} \\dot{x} &= \\alpha x - \\beta xy = x(\\alpha - \\beta y) \\\\ \\dot{y} &= \\delta xy - \\gamma y = y(\\delta x - \\gamma) \\end{aligned}\\]

Equilibrium Points

The system has two equilibrium points:

  • Trivial equilibrium: \\((0, 0)\\) — extinction of both species
  • Coexistence equilibrium: \\((x^*, y^*) = \\left(\\frac{\\gamma}{\\delta}, \\frac{\\alpha}{\\beta}\\right)\\)
Proof of Coexistence Equilibrium

Step 1: Set \\(\\dot{x} = 0\\):

\\[x(\\alpha - \\beta y) = 0\\]

So either \\(x = 0\\) or \\(y = \\alpha/\\beta\\).

Step 2: Set \\(\\dot{y} = 0\\):

\\[y(\\delta x - \\gamma) = 0\\]

So either \\(y = 0\\) or \\(x = \\gamma/\\delta\\).

Step 3: For coexistence, we need \\(x > 0\\) and \\(y > 0\\), giving:

\\[x^* = \\frac{\\gamma}{\\delta}, \\quad y^* = \\frac{\\alpha}{\\beta}\\]

Step 4: At this point, both populations remain constant. \\(\\square\\)

Conserved Quantity

The function:

\\[H(x, y) = \\delta x - \\gamma \\ln x + \\beta y - \\alpha \\ln y\\]

is conserved along trajectories, i.e., \\(dH/dt = 0\\). This implies periodic oscillations.

Proof

\\[\\frac{dH}{dt} = \\frac{\\partial H}{\\partial x}\\dot{x} + \\frac{\\partial H}{\\partial y}\\dot{y}\\]

\\[= \\left(\\delta - \\frac{\\gamma}{x}\\right)x(\\alpha - \\beta y) + \\left(\\beta - \\frac{\\alpha}{y}\\right)y(\\delta x - \\gamma)\\]

\\[= (\\delta x - \\gamma)(\\alpha - \\beta y) + (\\beta y - \\alpha)(\\delta x - \\gamma)\\]

\\[= (\\delta x - \\gamma)(\\alpha - \\beta y) - (\\alpha - \\beta y)(\\delta x - \\gamma) = 0\\]

\\(\\square\\)

1. Birch and Swinnerton-Dyer Conjecture

Introduction

The Birch and Swinnerton-Dyer conjecture relates the algebraic properties of elliptic curves to their analytic properties. It is one of the seven Millennium Prize Problems with a $1 million reward for its solution.

An elliptic curve is a smooth cubic curve of the form \\(y^2 = x^3 + ax + b\\). The rational points on such curves form a finitely generated abelian group (Mordell's Theorem).

Notation Guide

  • \\(E\\) — an elliptic curve over \\(\\mathbb{Q}\\)
  • \\(E(\\mathbb{Q})\\) — the group of rational points on \\(E\\)
  • \\(r = \\text{rank}(E(\\mathbb{Q}))\\) — the rank of the curve
  • \\(L(E, s)\\) — the L-function of the elliptic curve
  • \\(\\text{Sha}\\) — the Tate-Shafarevich group (measures failure of local-to-global principle)
  • \\(R_E\\) — the regulator (measures "size" of generators)
Birch and Swinnerton-Dyer Conjecture (Weak Form)

The order of vanishing of \\(L(E, s)\\) at \\(s = 1\\) equals the rank of \\(E(\\mathbb{Q})\\):

\\[\\text{ord}_{s=1} L(E, s) = \\text{rank}(E(\\mathbb{Q}))\\]

BSD Conjecture (Strong Form)

The Taylor expansion of \\(L(E, s)\\) at \\(s = 1\\) is:

\\[L(E, s) \\sim \\frac{\\Omega_E \\cdot \\text{Reg}_E \\cdot \\#\\text{Sha}(E) \\cdot \\prod_p c_p}{\\#E(\\mathbb{Q})_{\\text{tors}}^2} \\cdot (s-1)^r\\]

where the product is over primes of bad reduction and \\(c_p\\) are Tamagawa numbers.

What is Known

  • Coates-Wiles (1977): If \\(r = 0\\), then \\(L(E, 1) \\neq 0\\) (for curves with complex multiplication)
  • Gross-Zagier (1986): If \\(L(E, 1) = 0\\) but \\(L'(E, 1) \\neq 0\\), then \\(r \\geq 1\\)
  • Kolyvagin (1989): If \\(L(E, 1) \\neq 0\\), then \\(r = 0\\) and \\(\\#\\text{Sha} < \\infty\\)
  • For rank 0 and 1 curves, the conjecture is essentially proved

import numpy as np
import matplotlib.pyplot as plt

class EllipticCurve:
    """
    Elliptic curve y² = x³ + ax + b over Q.
    """
    def __init__(self, a, b):
        self.a = a
        self.b = b
        # Check discriminant
        discriminant = -16 * (4*a**3 + 27*b**2)
        if discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
        self.discriminant = discriminant
    
    def rhs(self, x):
        """Right hand side: x³ + ax + b"""
        return x**3 + self.a * x + self.b
    
    def plot(self, x_range=(-3, 3), num_points=1000):
        """Plot the real points of the curve."""
        x = np.linspace(x_range[0], x_range[1], num_points)
        y_sq = self.rhs(x)
        
        # Only plot where y² ≥ 0
        mask = y_sq >= 0
        x_pos = x[mask]
        y_pos = np.sqrt(y_sq[mask])
        
        plt.figure(figsize=(10, 8))
        plt.plot(x_pos, y_pos, 'b-', linewidth=2, label='$y = +\\sqrt{x^3 + ax + b}$')
        plt.plot(x_pos, -y_pos, 'b-', linewidth=2, label='$y = -\\sqrt{x^3 + ax + b}$')
        plt.axhline(y=0, color='k', linewidth=0.5)
        plt.axvline(x=0, color='k', linewidth=0.5)
        plt.grid(True, alpha=0.3)
        plt.xlabel('x')
        plt.ylabel('y')
        plt.title(f'Elliptic Curve: $y^2 = x^3 + {self.a}x + {self.b}$')
        plt.axis('equal')
        plt.legend()
        return plt
    
    def point_addition(self, P, Q):
        """
        Add two points on the curve using the chord-tangent method.
        Returns None for the point at infinity.
        """
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # Point doubling
        if abs(x1 - x2) < 1e-10:
            if abs(y1 + y2) < 1e-10 or abs(y1) < 1e-10:
                return None  # Point at infinity
            # Tangent slope
            m = (3*x1**2 + self.a) / (2*y1)
        else:
            # Chord slope
            m = (y2 - y1) / (x2 - x1)
        
        x3 = m**2 - x1 - x2
        y3 = m*(x1 - x3) - y1
        
        return (x3, y3)
    
    def scalar_multiply(self, n, P):
        """Compute n*P using double-and-add."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.scalar_multiply(-n, (x, -y))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.point_addition(result, addend)
            addend = self.point_addition(addend, addend)
            n >>= 1
        
        return result
    
    def find_rational_points(self, bound=50):
        """Find rational points with small denominators."""
        points = [None]  # Point at infinity
        
        for p in range(-bound, bound + 1):
            for q in range(1, bound + 1):
                if np.gcd(abs(p), q) != 1:
                    continue
                x = p / q
                y_sq = self.rhs(x)
                if y_sq >= 0:
                    y = np.sqrt(y_sq)
                    if abs(y - round(y)) < 1e-10:
                        y_int = int(round(y))
                        if y_int != 0:
                            points.append((x, y_int))
                            points.append((x, -y_int))
                        else:
                            points.append((x, 0))
        
        return list(set(points))

2. The Hodge Conjecture

Introduction

The Hodge conjecture is a major unsolved problem in algebraic geometry and complex geometry. It relates the algebraic topology of a non-singular complex algebraic variety to its subvarieties.

In simple terms: Which cohomology classes come from algebraic subvarieties?

Notation Guide

  • \\(X\\) — a non-singular complex projective variety
  • \\(H^k(X, \\mathbb{Q})\\) — the k-th cohomology group with rational coefficients
  • \\(H^{p,q}(X)\\) — the \\((p,q)\\)-component of the Hodge decomposition
  • \\(H^{k,k}(X, \\mathbb{Q}) = H^{2k}(X, \\mathbb{Q}) \\cap H^{k,k}(X)\\) — Hodge classes
  • \\(Z \\subseteq X\\) — an algebraic subvariety of codimension \\(k\\)
  • \\([Z] \\in H^{2k}(X, \\mathbb{Q})\\) — the cohomology class of \\(Z\\)
Hodge Decomposition Theorem

For a compact Kähler manifold \\(X\\):

\\[H^k(X, \\mathbb{C}) = \\bigoplus_{p+q=k} H^{p,q}(X)\\]

where \\(H^{p,q}(X)\\) consists of cohomology classes representable by differential forms of type \\((p,q)\\).

Moreover: \\(\\overline{H^{p,q}(X)} = H^{q,p}(X)\\)

The Hodge Conjecture

Let \\(X\\) be a non-singular complex projective variety. Then every Hodge class \\(\\alpha \\in H^{k,k}(X, \\mathbb{Q})\\) is a rational linear combination of cohomology classes of algebraic cycles:

\\[\\alpha = \\sum_i c_i [Z_i]\\]

where \\(Z_i \\subseteq X\\) are algebraic subvarieties of codimension \\(k\\) and \\(c_i \\in \\mathbb{Q}\\).

What is Known

  • \\(k = 0\\): Trivially true (\\(H^0(X, \\mathbb{Q}) = \\mathbb{Q}\\))
  • \\(k = 1\\): True (Lefschetz theorem on \\((1,1)\\)-classes, 1924)
  • \\(k = \\dim(X) - 1\\): True (follows from hard Lefschetz)
  • Abelian varieties: Known for some classes
  • General case: Wide open

Why It Matters

The Hodge conjecture provides a bridge between:

  • Topology: Cohomology classes (continuous, analytic objects)
  • Algebraic Geometry: Subvarieties (discrete, algebraic objects)

If true, it would mean that certain analytic invariants can be computed purely algebraically.

3. Yang-Mills Theory and Mass Gap

Introduction

Yang-Mills theory is the foundation of the Standard Model of particle physics. It describes gauge fields (like the electromagnetic field) with non-abelian gauge groups. The Yang-Mills existence and mass gap problem is another Millennium Prize Problem.

Notation Guide

  • \\(G\\) — a compact Lie group (gauge group, e.g., \\(SU(3)\\) for QCD)
  • \\(\\mathfrak{g}\\) — the Lie algebra of \\(G\\)
  • \\(A_\\mu: \\mathbb{R}^4 \\to \\mathfrak{g}\\) — the gauge potential (connection)
  • \\(F_{\\mu\\nu} = \\partial_\\mu A_\\nu - \\partial_\\nu A_\\mu + [A_\\mu, A_\\nu]\\) — field strength (curvature)
  • \\(\\mathcal{L} = \\frac{1}{4g^2} \\text{Tr}(F_{\\mu\\nu}F^{\\mu\\nu})\\) — Yang-Mills Lagrangian
  • \\(\\Delta\\) — the mass gap (lowest energy above vacuum)
Yang-Mills Action

The action functional for Yang-Mills theory on \\(\\mathbb{R}^4\\) is:

\\[S_{YM}(A) = \\frac{1}{2g^2} \\int_{\\mathbb{R}^4} \\text{Tr}(F_{\\mu\\nu}F^{\\mu\\nu}) \\, d^4x\\]

where \\(g\\) is the coupling constant and the trace is in the adjoint representation.

Yang-Mills Equations

The Euler-Lagrange equations (equations of motion) are:

\\[D_\\mu F^{\\mu\\nu} = 0\\]

where \\(D_\\mu = \\partial_\\mu + [A_\\mu, \\cdot]\\) is the covariant derivative.

Along with the Bianchi identity:

\\[D_\\lambda F_{\\mu\\nu} + D_\\mu F_{\\nu\\lambda} + D_\\nu F_{\\lambda\\mu} = 0\\]

The Mass Gap Problem

For pure Yang-Mills theory on \\(\\mathbb{R}^4\\) with compact gauge group \\(G\\):

  1. Prove that the quantum theory exists and has a positive mass gap \\(\\Delta > 0\\)
  2. The mass gap means the lightest particle has mass \\(\\Delta > 0\\)

For \\(G = SU(3)\\) (Quantum Chromodynamics), this explains why the strong force is short-ranged despite being mediated by massless gluons.

Why This Matters

  • Confinement: The mass gap is related to quark confinement in QCD
  • Mathematical rigor: Constructing quantum field theories rigorously is a major challenge
  • Physics: Explains why nuclear forces have finite range

What is Known

  • 2D Yang-Mills: Solved (no mass gap in the same sense)
  • Lattice Yang-Mills: Existence proved, mass gap established numerically
  • Continuum 4D: Open problem

import numpy as np
import matplotlib.pyplot as plt

class LatticeYangMills:
    """
    2D U(1) lattice gauge theory (simplified model).
    
    In lattice gauge theory, the gauge field lives on links between sites.
    For U(1), the link variable is a phase: U_{ij} = e^{iθ_{ij}}.
    """
    
    def __init__(self, L, beta):
        """
        Args:
            L: Lattice size (L x L)
            beta: Inverse coupling constant (1/g²)
        """
        self.L = L
        self.beta = beta
        # Link variables: theta_x[i,j] is horizontal link at (i,j)
        #                 theta_y[i,j] is vertical link at (i,j)
        self.theta_x = np.random.uniform(-np.pi, np.pi, (L, L))
        self.theta_y = np.random.uniform(-np.pi, np.pi, (L, L))
    
    def plaquette(self, i, j):
        """
        Compute the plaquette (minimal loop) at site (i,j).
        Plaquette = θ_x(i,j) + θ_y(i+1,j) - θ_x(i,j+1) - θ_y(i,j)
        """
        ip1 = (i + 1) % self.L
        jp1 = (j + 1) % self.L
        
        return (self.theta_x[i, j] + self.theta_y[ip1, j] 
                - self.theta_x[i, jp1] - self.theta_y[i, j])
    
    def action(self):
        """Compute the Wilson action S = -β Σ Re(plaquette)."""
        total = 0
        for i in range(self.L):
            for j in range(self.L):
                total += np.cos(self.plaquette(i, j))
        return -self.beta * total
    
    def heat_bath_update(self, num_sweeps=1):
        """
        Perform heat bath updates (Metropolis algorithm).
        """
        for _ in range(num_sweeps * self.L * self.L):
            # Randomly choose a link
            is_x = np.random.random() < 0.5
            i = np.random.randint(0, self.L)
            j = np.random.randint(0, self.L)
            
            # Compute staple (sum of plaquettes containing this link)
            if is_x:
                staple = self._staple_x(i, j)
                old_theta = self.theta_x[i, j]
            else:
                staple = self._staple_y(i, j)
                old_theta = self.theta_y[i, j]
            
            # Metropolis update
            new_theta = np.random.uniform(-np.pi, np.pi)
            delta_S = -self.beta * (np.cos(new_theta + staple) - np.cos(old_theta + staple))
            
            if delta_S < 0 or np.random.random() < np.exp(-delta_S):
                if is_x:
                    self.theta_x[i, j] = new_theta
                else:
                    self.theta_y[i, j] = new_theta
    
    def _staple_x(self, i, j):
        """Compute staple for horizontal link at (i,j)."""
        im1 = (i - 1) % self.L
        jp1 = (j + 1) % self.L
        
        # Two plaquettes contain this link
        staple1 = (self.theta_y[i, j] - self.theta_x[i, jp1] - self.theta_y[im1, j])
        staple2 = -(self.theta_y[i, j] - self.theta_x[im1, jp1] - self.theta_y[im1, j])
        
        # Return the angle of the sum of staples
        return np.arctan2(np.sin(staple1) + np.sin(staple2), 
                         np.cos(staple1) + np.cos(staple2))
    
    def _staple_y(self, i, j):
        """Compute staple for vertical link at (i,j)."""
        ip1 = (i + 1) % self.L
        jm1 = (j - 1) % self.L
        
        staple1 = -(self.theta_x[i, j] + self.theta_y[ip1, jm1] - self.theta_x[i, jm1])
        staple2 = (self.theta_x[ip1, jm1] + self.theta_y[ip1, j] - self.theta_x[i, j])
        
        return np.arctan2(np.sin(staple1) + np.sin(staple2), 
                         np.cos(staple1) + np.cos(staple2))
    
    def wilson_loop(self, r, t):
        """
        Compute r x t Wilson loop (rectangular loop).
        This measures the potential between static charges.
        """
        # Average over all starting positions
        loops = []
        for i0 in range(self.L):
            for j0 in range(self.L):
                loop = 0
                i, j = i0, j0
                # Go right r steps
                for _ in range(r):
                    loop += self.theta_x[i, j]
                    i = (i + 1) % self.L
                # Go up t steps
                for _ in range(t):
                    loop += self.theta_y[i, j]
                    j = (j + 1) % self.L
                # Go left r steps
                for _ in range(r):
                    i = (i - 1) % self.L
                    loop -= self.theta_x[i, j]
                # Go down t steps
                for _ in range(t):
                    j = (j - 1) % self.L
                    loop -= self.theta_y[i, j]
                
                loops.append(np.cos(loop))
        
        return np.mean(loops)
    
    def topological_charge(self):
        """
        Compute the topological charge (instanton number).
        Q = (1/2π) Σ plaquette mod 2π
        """
        total = 0
        for i in range(self.L):
            for j in range(self.L):
                plaq = self.plaquette(i, j)
                # Map to [-π, π]
                while plaq > np.pi:
                    plaq -= 2*np.pi
                while plaq < -np.pi:
                    plaq += 2*np.pi
                total += plaq
        return total / (2 * np.pi)

4. The Poincaré Conjecture (Solved!)

Introduction

The Poincaré conjecture, posed by Henri Poincaré in 1904, was one of the most famous problems in topology. It was the first of the seven Millennium Prize Problems to be solved. Grigori Perelman proved it in 2002-2003, declining both the Fields Medal (2006) and the $1 million prize.

Notation Guide

  • \\(S^n\\) — the n-dimensional sphere
  • \\(M^n\\) — a closed (compact, no boundary) n-manifold
  • \\(\\pi_k(X)\\) — the k-th homotopy group of \\(X\\)
  • \\(\\cong\\) — homeomorphic (topologically equivalent)
  • Simply connected: \\(\\pi_1(X) = 0\\) (every loop can be contracted)
The Poincaré Conjecture

Every closed, simply connected 3-manifold is homeomorphic to the 3-sphere \\(S^3\\).

Equivalently: If a 3-dimensional space has the property that every loop can be continuously tightened to a point, then that space is just the 3-sphere (possibly deformed).

Generalized Poincaré Conjecture

Every closed n-manifold that is homotopy equivalent to \\(S^n\\) is homeomorphic to \\(S^n\\).

  • n = 1, 2: Known classically
  • n ≥ 5: Proved by Smale (1961, Fields Medal)
  • n = 4: Proved by Freedman (1982, Fields Medal)
  • n = 3: Proved by Perelman (2002-2003)

Perelman's Proof Strategy

Perelman proved the conjecture as a corollary of the Geometrization Conjecture (Thurston) using Ricci flow:

  1. Ricci Flow: A process that evolves the metric of a manifold according to:

    \\[\\frac{\\partial g_{ij}}{\\partial t} = -2R_{ij}\\]

    where \\(R_{ij}\\) is the Ricci curvature tensor. This is like heat flow for geometry.

  2. Singularities: The flow can develop singularities (pinching, bubbling)
  3. Surgery: Perelman showed how to perform "surgery" to remove singularities and continue the flow
  4. Result: Any 3-manifold can be decomposed into pieces with uniform geometry
Thurston's Geometrization Conjecture (Proved by Perelman)

Every closed 3-manifold can be decomposed (by cutting along spheres and tori) into pieces, each of which admits one of eight geometric structures:

  1. Spherical geometry (\\(S^3\\))
  2. Euclidean geometry (\\(\\mathbb{R}^3\\))
  3. Hyperbolic geometry (\\(\\mathbb{H}^3\\))
  4. And five others (\\(S^2 \\times \\mathbb{R}\\), \\(\\mathbb{H}^2 \\times \\mathbb{R}\\), Nil, Sol, \\(\\widetilde{SL}(2, \\mathbb{R})\\))

from mpl_toolkits.mplot3d import Axes3D

def stereographic_projection_3d(x, y, z, w):
    """
    Stereographic projection of S³ to R³.
    S³ is {(x,y,z,w) : x² + y² + z² + w² = 1}
    Project from (0,0,0,1) to the w=0 hyperplane.
    """
    if abs(w - 1) < 1e-10:
        return None  # Point at infinity
    return (x / (1 - w), y / (1 - w), z / (1 - w))

    """

    (t, φ, θ) ↦ (cos t · e^{iφ}, sin t · e^{iθ})

    x = np.cos(t) * np.cos(phi)
    y = np.cos(t) * np.sin(phi)
    z = np.sin(t) * np.cos(theta)
    w = np.sin(t) * np.sin(theta)
    return x, y, z, w
