Riemann Surfaces: Geometry of Complex Functions

Motivation

How can we understand multi-valued complex functions like the logarithm or square root? Riemann's revolutionary insight was to construct surfaces on which these functions become single-valued. A Riemann surface is a one-dimensional complex manifold that provides the natural domain for analytic functions.

Definitions

Riemann Surface: A connected one-dimensional complex manifold. Formally, a Hausdorff topological space \(X\) with charts \(\{(U_\alpha, \phi_\alpha)\}\) where \(\phi_\alpha: U_\alpha \to \mathbb{C}\) are homeomorphisms with holomorphic transition maps.

Genus: The number of "holes" in a compact Riemann surface. Topologically, a compact Riemann surface of genus \(g\) is a sphere with \(g\) handles.

Theorem (Riemann-Roch)

Let \(X\) be a compact Riemann surface of genus \(g\), and let \(D\) be a divisor. Then: \[\ell(D) - \ell(K - D) = \deg(D) + 1 - g\]

Python Code

import numpy as np
import matplotlib.pyplot as plt

# Riemann surface for sqrt(z)
# Two-sheeted cover branched at 0 and infinity

r = np.linspace(0.1, 2, 50)
theta = np.linspace(0, 4*np.pi, 200)
R, Theta = np.meshgrid(r, theta)

Z_real = np.sqrt(R) * np.cos(Theta / 2)

fig = plt.figure(figsize=(14, 6))
ax1 = fig.add_subplot(121, projection='3d')

Spectral Theory: The Eigenvalue Landscape

Motivation

What can we learn about an operator by studying its spectrum? Spectral theory generalizes eigenvalues from finite-dimensional linear algebra to infinite-dimensional spaces. It underlies quantum mechanics, where observables correspond to self-adjoint operators.

Definitions

Spectrum: For a linear operator \(T\), the spectrum \(\sigma(T)\) consists of all \(\lambda\) such that \((T - \lambda I)^{-1}\) does not exist as a bounded operator.

Self-Adjoint: \(T = T^*\), meaning \(\langle Tx, y \rangle = \langle x, Ty \rangle\).

Theorem (Spectral Theorem)

Let \(T\) be a bounded self-adjoint operator on a separable Hilbert space. Then there exists a measure space \((X, \mu)\) and unitary \(U\) such that \(UTU^{-1}\) is a multiplication operator.

Python Code

import numpy as np
from scipy.linalg import eigh

# Discrete Laplacian
n = 100
L = np.diag(-2*np.ones(n)) + np.diag(np.ones(n-1), 1) + np.diag(np.ones(n-1), -1)

eigenvalues, eigenvectors = eigh(L)
print(f"First 10 eigenvalues: {eigenvalues[:10]}")

Measure Theory: The Foundation of Integration

Motivation

Why can't we integrate all functions? Riemann integration fails for functions with too many discontinuities. Lebesgue's measure theory provides a robust foundation for integration.

Definitions

σ-Algebra: A collection \(\mathcal{F}\) closed under complements and countable unions.

Measure: \(\mu: \mathcal{F} \to [0, \infty]\) with \(\mu(\emptyset) = 0\) and countable additivity.

Theorem (Monotone Convergence)

If \(0 \leq f_n \leq f_{n+1} \to f\), then \(\int f_n \to \int f\).

Python Code

import numpy as np
from scipy import integrate

# Demonstrate monotone convergence
# f_n(x) = min(x^(-1/2), n) → f(x) = x^(-1/2)

x = np.linspace(0.001, 1, 1000)
for n in [1, 5, 20, 100]:
    f_n = np.minimum(x**(-0.5), n)
    integral = integrate.simpson(f_n, x)
    print(f"n={n}: ∫f_n = {integral:.4f}")
# Converges to 2.0

Neural Networks: Universal Approximation

Real-World Motivation

Why can neural networks approximate virtually any function? The universal approximation theorem provides the theoretical foundation.

Theorem (Universal Approximation)

Let \(\sigma\) be non-polynomial continuous. For any compact \(K\) and continuous \(f: K \to \mathbb{R}\), there exists a neural network \(\hat{f}\) such that \(\sup|f - \hat{f}| < \epsilon\).

Python Code

import numpy as np

class NeuralNetwork:
    def __init__(self, sizes):
        self.weights = [np.random.randn(sizes[i], sizes[i+1]) 
                        for i in range(len(sizes)-1)]
    
    def relu(self, z):
        return np.maximum(0, z)
    
    def forward(self, X):
        a = X
        for w in self.weights[:-1]:
            a = self.relu(np.dot(a, w))
        return np.dot(a, self.weights[-1])

p-adic Numbers: An Alternative Number System

Historical Context

p-adic numbers were introduced by Kurt Hensel in 1897. While reals complete \(\mathbb{Q}\) with respect to \(|\cdot|_\infty\), p-adics complete with respect to \(|\cdot|_p\).

Definitions

\(|x|_p = p^{-v_p(x)}\) where \(v_p(n)\) is the highest power of \(p\) dividing \(n\).

Theorem (Ostrowski)

Every non-trivial absolute value on \(\mathbb{Q}\) is equivalent to \(|\cdot|_\infty\) or \(|\cdot|_p\).

Python Code

def p_adic_valuation(n, p):
    if n == 0:
        return float('inf')
    v = 0
    while n % p == 0:
        n //= p
        v += 1
    return v

def p_adic_abs(x, p):
    from fractions import Fraction
    frac = Fraction(x)
    v = p_adic_valuation(frac.numerator, p) - p_adic_valuation(frac.denominator, p)
    return p ** (-v)

Topos Theory: Categorical Logic

Historical Context

Topos theory emerged from Grothendieck's work in algebraic geometry. It provides a framework for intuitionistic logic.

Definitions

Topos: A category with finite limits, exponentials, and a subobject classifier \(\Omega\).

Theorem (Fundamental Theorem)

If \(\mathcal{E}\) is a topos and \(X \in \mathcal{E}\), then \(\mathcal{E}/X\) is also a topos.

Surreal Numbers: The Ultimate Number System

Historical Context

Surreal numbers were discovered by John Conway in the 1970s. They include all reals, all ordinals, infinitesimals, and infinite numbers.

Definitions

\(x = \{X_L | X_R\}\) where all \(X_L < X_R\).

Theorem (Conway)

The surreal numbers form an ordered field containing all reals and ordinals.

📜 Math History: Alexander Grothendieck (1928–2014)

Alexander Grothendieck stands as one of the most revolutionary mathematicians in history. Born in Berlin on March 28, 1928, his early life was marked by displacement and survival. His father died at Auschwitz in 1942, while Alexander and his mother survived as refugees in France.

From 1958 to 1970, Grothendieck worked at the IHÉS, producing his magnum opus. With Dieudonné, he created the "Éléments de Géométrie Algébrique" (EGA) and directed the "Séminaire de Géométrie Algébrique" (SGA). These works rebuilt algebraic geometry from its foundations.

In 1970, at the height of his powers, Grothendieck abruptly left mathematics for political activism. He declined the Fields Medal in 1966. He lived as a recluse in the Pyrenees from 1991 until his death in 2014.

Grothendieck's legacy extends far beyond his theorems. He taught mathematicians to think in terms of universal properties and relative situations. His emphasis on morphisms over objects transformed mathematics.

🎯 Problem Corner

Problem: Putnam 2022 B6

Let \(n\) be a positive integer. Determine the number of functions \(f: \{1, 2, \ldots, n\} \to \{1, 2, \ldots, n\}\) such that \(f(f(x)) = f(x)\) for all \(x\).

Hint

The condition means \(f\) acts as the identity on its image. Choose the image, then define \(f\) on remaining elements.

Solution

The answer is \(\sum_{k=1}^{n} \binom{n}{k} k^{n-k}\).

Reasoning: The condition means \(f(y) = y\) for all \(y\) in the image. For image size \(k\): choose which \(k\) elements (\(\binom{n}{k}\) ways), then map the remaining \(n-k\) elements to the image (\(k^{n-k}\) ways).

📊 Visualization of the Day: Riemann Surface of sqrt(z)

The Riemann surface of \(w = \sqrt{z}\) is a two-sheeted cover of the complex plane, branched at \(z = 0\) and \(z = \infty\). As you travel around the origin once, you move from one sheet to the other.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# Create Riemann surface for sqrt(z)
r = np.linspace(0.01, 2, 50)
theta = np.linspace(0, 4*np.pi, 200)
R, Theta = np.meshgrid(r, theta)

# Two sheets of sqrt
Z_real = np.sqrt(R) * np.cos(Theta / 2)
X = R * np.cos(Theta)
Y = R * np.sin(Theta)

fig = plt.figure(figsize=(14, 6))
