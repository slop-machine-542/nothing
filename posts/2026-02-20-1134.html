Ramsey Theory: Order in Chaos

ramsey-theory

Motivation

Ramsey theory embodies the philosophy that complete disorder is impossible. In any sufficiently large structure, regular patterns must emerge. The classic example: among any six people, there are either three mutual acquaintances or three mutual strangers.

Definitions

  • Ramsey Number \(R(s, t)\): The smallest \(n\) such that every 2-coloring of the edges of \(K_n\) contains either a red \(K_s\) or a blue \(K_t\).
  • Van der Waerden Number \(W(k, r)\): The smallest \(n\) such that any \(r\)-coloring contains a monochromatic arithmetic progression of length \(k\).
  • Schur Number \(S(r)\): The largest \(n\) such that \\(\\{1, 2, \\ldots, n\\}\\) can be \(r\)-colored without a monochromatic solution to \(x + y = z\).

Theorem: Ramsey's Theorem

Theorem: For any positive integers \(s\) and \(t\), the Ramsey number \(R(s, t)\) is finite. Moreover:

\\[R(s, t) \\leq R(s-1, t) + R(s, t-1)\\]

Python Code

class RamseyTheory:
    def __init__(self):
        self.ramsey_bounds = {(1, t): 1 for t in range(1, 20)}
        self.ramsey_bounds.update({(s, 1): 1 for s in range(1, 20)})
        self.ramsey_bounds[(2, t)] = t
        self.ramsey_bounds[(s, 2)] = s
    
    def ramsey_upper_bound(self, s, t):
        if (s, t) in self.ramsey_bounds:
            return self.ramsey_bounds[(s, t)]
        bound = self.ramsey_upper_bound(s-1, t) + self.ramsey_upper_bound(s, t-1)
        self.ramsey_bounds[(s, t)] = bound
        return bound

rt = RamseyTheory()
print(f"R(3,3) <= {rt.ramsey_upper_bound(3, 3)}")

The Mandelbrot Set Boundary

The Mandelbrot set is defined as the set of complex numbers \(c\) for which the iteration \\(z_{n+1} = z_n^2 + c\\) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate patterns.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Generate grid
x = np.linspace(-2.5, 1.5, 1000)
y = np.linspace(-1.5, 1.5, 1000)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot
M = np.vectorize(mandelbrot)(C)

plt.figure(figsize=(12, 8))
plt.imshow(M, extent=[-2.5, 1.5, -1.5, 1.5], cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
