Elliptic Curves and the Mordell-Weil Theorem

Motivation

Elliptic curves are among the most fascinating objects in mathematics, lying at the intersection of number theory, algebraic geometry, and complex analysis. They played a central role in Andrew Wiles's proof of Fermat's Last Theorem and form the foundation of modern elliptic curve cryptography. The study of rational points on elliptic curves connects deep questions about Diophantine equations with the structure of abelian varieties.

Definitions

Elliptic Curve: A smooth projective curve of genus 1 with a specified base point (the identity). Over a field \(K\) of characteristic not 2 or 3, an elliptic curve can be written in Weierstrass form: \[E : y^2 = x^3 + ax + b\] where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\) ensures smoothness.

Group Law: The points on an elliptic curve form an abelian group with the point at infinity \(\mathcal{O}\) as identity. For points \(P\) and \(Q\), their sum \(P + Q\) is defined geometrically: draw the line through \(P\) and \(Q\), find the third intersection point with the curve, then reflect across the x-axis.

Torsion Subgroup: The subgroup \(E(K)_{tors}\) of points of finite order in \(E(K)\).

Theorem and Proof

Mordell-Weil Theorem: Let \(E\) be an elliptic curve over a number field \(K\). Then the group of \(K\)-rational points \(E(K)\) is a finitely generated abelian group: \[E(K) \cong E(K)_{tors} \times \mathbb{Z}^r\] where \(r\) is the rank of \(E\) over \(K\).

Proof Sketch: The proof has two main components. First, the "weak Mordell-Weil theorem" shows that \(E(K)/2E(K)\) is finite. This uses Galois cohomology and properties of the 2-descent map. Second, one constructs a height function \(h: E(K) \to \mathbb{R}_{\geq 0}\) satisfying: (1) For any \(M > 0\), the set \(\{P \in E(K) : h(P) \leq M\}\) is finite. (2) \(h(P + Q) + h(P - Q) = 2h(P) + 2h(Q) + O(1)\) (parallelogram law). (3) \(h(2P) = 4h(P) + O(1)\). These properties allow a descent argument: starting from a set of coset representatives for \(E(K)/2E(K)\), one can generate all of \(E(K)\) by repeatedly halving points.

Notation Guide

  • \(E\) — elliptic curve
  • \(\mathcal{O}\) — point at infinity (identity element)
  • \(E(K)\) — group of \(K\)-rational points
  • \(E[n]\) — \(n\)-torsion subgroup (points of order dividing \(n\))
  • \(j(E)\) — \(j\)-invariant (classifies curves up to isomorphism over \(\overline{K}\))
  • \(\hat{h}\) — canonical height (Néron-Tate height)
  • \(L(E/K, s)\) — Hasse-Weil \(L\)-function

import numpy as np
import matplotlib.pyplot as plt

class EllipticCurve:
    """Elliptic curve in short Weierstrass form: y^2 = x^3 + ax + b"""
    
    def __init__(self, a, b):
        self.a = a
        self.b = b
        # Check smoothness
        discriminant = -16 * (4*a**3 + 27*b**2)
        if discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
        self.discriminant = discriminant
    
    def is_on_curve(self, x, y):
        """Check if point (x, y) lies on the curve."""
        return y**2 == x**3 + self.a*x + self.b
    
    def add(self, P, Q):
        """Add two points on the curve."""
        if P is None: return Q
        if Q is None: return P
        x1, y1 = P
        x2, y2 = Q
        
        if x1 == x2 and y1 != y2:
            return None  # Point at infinity
        
        if x1 == x2:
            # Point doubling: tangent slope
            m = (3*x1**2 + self.a) / (2*y1)
        else:
            # Point addition: secant slope
            m = (y2 - y1) / (x2 - x1)
        
        x3 = m**2 - x1 - x2
        y3 = m*(x1 - x3) - y1
        return (x3, y3)
    
    def scalar_mult(self, n, P):
        """Compute n*P using double-and-add."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.scalar_mult(-n, (x, -y))
        
        result = None
        addend = P
        while n:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        return result
    
    def plot(self, x_range=(-3, 3), n_points=1000):
        """Plot the real points of the curve."""
        x = np.linspace(x_range[0], x_range[1], n_points)
        y_squared = x**3 + self.a*x + self.b
        
        # Only plot where y^2 >= 0
        mask = y_squared >= 0
        x_pos = x[mask]
        y_pos = np.sqrt(y_squared[mask])
        
        plt.figure(figsize=(10, 8))
        plt.plot(x_pos, y_pos, 'b-', linewidth=2, label='$y = \\sqrt{x^3 + ax + b}$')
        plt.plot(x_pos, -y_pos, 'b-', linewidth=2, label='$y = -\\sqrt{x^3 + ax + b}$')
        plt.axhline(y=0, color='k', linewidth=0.5)
        plt.axvline(x=0, color='k', linewidth=0.5)
        plt.grid(True, alpha=0.3)
        plt.xlabel('x')
        plt.ylabel('y')
        plt.title(f'Elliptic Curve: $y^2 = x^3 + {self.a}x + {self.b}$')
        plt.legend()
        plt.axis('equal')
        return plt

Category Theory: Universal Properties and Functors

Motivation

Category theory, founded by Samuel Eilenberg and Saunders Mac Lane in the 1940s, provides a unifying framework for mathematics. Rather than studying individual mathematical objects, category theory studies the relationships (morphisms) between objects. This shift in perspective reveals deep structural similarities across algebra, topology, logic, and computer science.

Definitions

Category: A category \(\mathcal{C}\) consists of: (1) A class \(\mathrm{Ob}(\mathcal{C})\) of objects (2) For each pair of objects \(A, B\), a set \(\mathrm{Hom}(A, B)\) of morphisms (3) A composition operation \(\circ : \mathrm{Hom}(B, C) \times \mathrm{Hom}(A, B) \to \mathrm{Hom}(A, C)\) satisfying associativity and identity axioms.

Functor: A functor \(F : \mathcal{C} \to \mathcal{D}\) is a mapping that sends objects to objects and morphisms to morphisms, preserving composition and identities.

Natural Transformation: For functors \(F, G : \mathcal{C} \to \mathcal{D}\), a natural transformation \(\eta : F \Rightarrow G\) assigns to each object \(X\) a morphism \(\eta_X : F(X) \to G(X)\) such that for all \(f : X \to Y\): \[\eta_Y \circ F(f) = G(f) \circ \eta_X\]

Theorem and Proof

Yoneda Lemma: Let \(\mathcal{C}\) be a locally small category, \(F : \mathcal{C}^{op} \to \mathbf{Set}\) a functor, and \(A \in \mathcal{C}\). Then: \[\mathrm{Nat}(\mathrm{Hom}(-, A), F) \cong F(A)\] Moreover, this isomorphism is natural in both \(A\) and \(F\).

Proof Sketch: Given a natural transformation \(\alpha : \mathrm{Hom}(-, A) \Rightarrow F\), evaluate at \(A\) to get \(\alpha_A : \mathrm{Hom}(A, A) \to F(A)\). The image of \(\mathrm{id}_A\) gives an element \(x_\alpha \in F(A)\). Conversely, given \(x \in F(A)\), define \(\alpha_X(f) = F(f)(x)\) for \(f : X \to A\). One verifies these constructions are inverse to each other and natural.

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\) — categories
  • \(\mathrm{Ob}(\mathcal{C})\) — class of objects
  • \(\mathrm{Hom}_{\mathcal{C}}(A, B)\) or \(A \to B\) — hom-set of morphisms
  • \(F : \mathcal{C} \to \mathcal{D}\) — functor
  • \(\eta : F \Rightarrow G\) — natural transformation
  • \(\mathcal{C}^{op}\) — opposite category
  • \(\mathbf{Set}\) — category of sets

from typing import TypeVar, Generic, Callable, Dict, Set
from functools import reduce

T = TypeVar('T')
U = TypeVar('U')
V = TypeVar('V')

class Category:
    """Base class for a category."""
    
    def __init__(self, name: str):
        self.name = name
        self.objects: Set = set()
        self.morphisms: Dict = {}  # (source, target) -> set of morphisms
    
    def add_object(self, obj):
        self.objects.add(obj)
    
    def add_morphism(self, source, target, morphism, name: str = None):
        if (source, target) not in self.morphisms:
            self.morphisms[(source, target)] = []
        self.morphisms[(source, target)].append((morphism, name))
    
    def compose(self, f, g):
        """Compose morphisms: g ∘ f (apply f then g)."""
        return lambda x: g(f(x))

class Functor:
    """Functor between categories."""
    
    def __init__(self, name: str, source: Category, target: Category):
        self.name = name
        self.source = source
        self.target = target
        self.object_map: Dict = {}
        self.morphism_map: Dict = {}
    
    def map_object(self, obj, image):
        self.object_map[obj] = image
    
    def map_morphism(self, morph, image):
        self.morphism_map[morph] = image
    
    def __call__(self, obj):
        return self.object_map.get(obj)

class PowerSetFunctor(Functor):
    """The contravariant power set functor."""
    
    def __init__(self):
        super().__init__("P", FinSet, FinSet)
    
    def apply_to_object(self, n: int) -> int:
        """P({0,...,n-1}) has 2^n elements."""
        return 2 ** n
    
    def apply_to_morphism(self, f: Callable, source_n: int, target_n: int):
        """Given f: A -> B, returns f^{-1}: P(B) -> P(A)."""
        # For finite sets represented by integers, this is a simplification
        def preimage(subset_mask: int) -> int:
            # subset_mask represents a subset of {0,...,target_n-1}
            result = 0
            for i in range(source_n):
                # Check if f(i) is in subset
                fi = f(i) if i < source_n else 0
                if fi < target_n and (subset_mask >> fi) & 1:
                    result |= (1 << i)
            return result
        return preimage

Galois Theory: The Correspondence Between Fields and Groups

Motivation

Galois theory, developed by Évariste Galois in the early 19th century, provides a profound connection between field theory and group theory. This correspondence allows us to study the solvability of polynomial equations by examining the structure of associated groups. Galois's work resolved centuries-old questions about the solvability of polynomial equations by radicals.

Definitions

Field Extension: If \(F\) and \(E\) are fields with \(F \subseteq E\), we call \(E/F\) a field extension. The degree \([E:F]\) is the dimension of \(E\) as an \(F\)-vector space.

Galois Group: For a field extension \(E/F\), the Galois group \(\mathrm{Gal}(E/F)\) is the group of field automorphisms of \(E\) that fix \(F\) pointwise: \[\mathrm{Gal}(E/F) = \{\sigma \in \mathrm{Aut}(E) : \sigma|_F = \mathrm{id}_F\}\]

Galois Extension: A finite extension \(E/F\) is Galois if \(E\) is the splitting field of a separable polynomial over \(F\). Equivalently, \(|\mathrm{Gal}(E/F)| = [E:F]\).

Theorem and Proof

Fundamental Theorem of Galois Theory: Let \(E/F\) be a finite Galois extension with Galois group \(G = \mathrm{Gal}(E/F)\). There is an inclusion-reversing bijection: \[\{\text{intermediate fields } K : F \subseteq K \subseteq E\} \longleftrightarrow \{\text{subgroups } H \leq G\}\] given by \(K \mapsto \mathrm{Gal}(E/K)\) and \(H \mapsto E^H\) (the fixed field of \(H\)). Moreover: (1) \([E:K] = |\mathrm{Gal}(E/K)|\) and \([K:F] = [G : \mathrm{Gal}(E/K)]\) (2) \(K/F\) is Galois iff \(\mathrm{Gal}(E/K) \trianglelefteq G\), in which case \(\mathrm{Gal}(K/F) \cong G/\mathrm{Gal}(E/K)\).

Proof Sketch: The key ingredients are: (1) Artin's theorem: If \(H\) is a finite group of automorphisms of \(E\), then \([E:E^H] = |H|\). (2) For a Galois extension, the fixed field of \(\mathrm{Gal}(E/K)\) is exactly \(K\). The correspondence follows by showing both compositions are identity maps. The normality condition follows from the fact that conjugate subgroups correspond to conjugate intermediate fields under the action of \(G\).

Notation Guide

  • \(E/F\) — field extension (E over F)
  • \([E:F]\) — degree of extension
  • \(\mathrm{Gal}(E/F)\) — Galois group
  • \(E^H\) — fixed field of subgroup \(H\)
  • \(F(\alpha)\) — smallest field containing \(F\) and \(\alpha\)
  • \(\overline{F}\) — algebraic closure of \(F\)

Optimal Transport: From Monge to Machine Learning

Real-World Motivation

Optimal transport theory, originating with Gaspard Monge in 1781 and revolutionized by Leonid Kantorovich in the 1940s, studies the most efficient way to move mass from one distribution to another. Today it finds applications in economics (matching markets), computer vision (image registration), machine learning (Wasserstein GANs), and biology (cell trajectory analysis).

Definitions

Monge Problem: Given probability measures \(\mu\) on \(X\) and \(\nu\) on \(Y\), and a cost function \(c : X \times Y \to \mathbb{R}_+\), find a transport map \(T : X \to Y\) minimizing: \[\int_X c(x, T(x)) \, \mathrm{d}\mu(x)\] subject to \(T_\#\mu = \nu\) (pushforward condition).

Kantorovich Relaxation: Find a coupling \(\gamma \in \Pi(\mu, \nu)\) (joint distribution with marginals \(\mu, \nu\)) minimizing: \[\int_{X \times Y} c(x, y) \, \mathrm{d}\gamma(x, y)\]

Wasserstein Distance: For \(p \geq 1\), the \(p\)-Wasserstein distance is: \[W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int d(x, y)^p \, \mathrm{d}\gamma\right)^{1/p}\]

Theorem and Proof

Kantorovich Duality: For appropriate cost functions \(c\): \[\inf_{\gamma \in \Pi(\mu, \nu)} \int c \, \mathrm{d}\gamma = \sup_{\phi, \psi} \left\{\int \phi \, \mathrm{d}\mu + \int \psi \, \mathrm{d}\nu : \phi(x) + \psi(y) \leq c(x, y)\right\}\]

Proof Sketch: The duality follows from convex analysis. The left side is a linear optimization problem over the convex set \(\Pi(\mu, \nu)\). By the Fenchel-Rockafellar duality theorem, this equals the supremum over dual variables. The constraint \(\phi(x) + \psi(y) \leq c(x, y)\) arises from requiring that the dual functional be bounded above.

Notation Guide

  • \(\mu, \nu\) — probability measures
  • \(\Pi(\mu, \nu)\) — set of couplings (transport plans)
  • \(T_\#\mu\) — pushforward of \(\mu\) by \(T\)
  • \(c(x, y)\) — cost of transporting unit mass from \(x\) to \(y\)
  • \(W_p(\mu, \nu)\) — \(p\)-Wasserstein distance
  • \(\phi, \psi\) — Kantorovich potentials (dual variables)

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import linprog

def discrete_optimal_transport(mu, nu, C):
    """
    Solve discrete optimal transport using linear programming.
    
    Parameters:
    - mu: source distribution (m probabilities)
    - nu: target distribution (n probabilities)
    - C: cost matrix (m x n)
    
    Returns:
    - gamma: optimal transport plan
    - cost: optimal transport cost
    """
    m, n = len(mu), len(nu)
    
    # Flatten gamma to a vector
    c = C.flatten()
    
    # Equality constraints: row sums = mu, column sums = nu
    A_eq = np.zeros((m + n, m * n))
    b_eq = np.concatenate([mu, nu])
    
    # Row constraints
    for i in range(m):
        A_eq[i, i*n:(i+1)*n] = 1
    
    # Column constraints
    for j in range(n):
        for i in range(m):
            A_eq[m + j, i*n + j] = 1
    
    # Solve
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=(0, None), method='highs')
    gamma = result.x.reshape(m, n)
    
    return gamma, result.fun

def wasserstein_distance(mu, nu, C, p=1):
    """Compute p-Wasserstein distance."""
    gamma, cost = discrete_optimal_transport(mu, nu, C)
    if p == 1:
        return cost
    else:
        return cost ** (1/p)

Compressed Sensing: Sparse Recovery from Few Measurements

Real-World Motivation

Compressed sensing, developed by Candès, Romberg, Tao, and Donoho around 2006, revolutionized signal processing by showing that sparse signals can be recovered from far fewer measurements than the Nyquist-Shannon theorem would suggest. Applications include MRI imaging (faster scans), single-pixel cameras, and efficient data compression.

Definitions

Sparse Signal: A vector \(\mathbf{x} \in \mathbb{R}^n\) is \(k\)-sparse if at most \(k\) of its entries are non-zero. The sparsity is measured by \(\|\mathbf{x}\|_0 = |\{i : x_i \neq 0\}|\).

Measurement Matrix: A matrix \(\mathbf{A} \in \mathbb{R}^{m \times n}\) with \(m \ll n\) that maps the signal to measurements \(\mathbf{y} = \mathbf{A}\mathbf{x}\).

Restricted Isometry Property (RIP): A matrix \(\mathbf{A}\) satisfies RIP of order \(k\) with constant \(\delta_k\) if for all \(k\)-sparse \(\mathbf{x}\): \[(1 - \delta_k)\|\mathbf{x}\|_2^2 \leq \|\mathbf{A}\mathbf{x}\|_2^2 \leq (1 + \delta_k)\|\mathbf{x}\|_2^2\]

Theorem and Proof

Exact Recovery Theorem: If \(\mathbf{A}\) satisfies RIP of order \(2k\) with \(\delta_{2k} < \sqrt{2} - 1\), then the solution to: \[\min_{\mathbf{z}} \|\mathbf{z}\|_1 \quad \text{subject to} \quad \mathbf{A}\mathbf{z} = \mathbf{y}\] is exactly the \(k\)-sparse signal \(\mathbf{x}\).

Proof Sketch: Let \(\mathbf{x}^*\) be the \(\ell_1\)-minimizer and \(\mathbf{h} = \mathbf{x}^* - \mathbf{x}\). Since both satisfy the measurements, \(\mathbf{A}\mathbf{h} = 0\). The key insight is that \(\ell_1\)-minimization promotes sparsity through the geometry of the \(\ell_1\)-ball (diamond in 2D). The RIP ensures that \(\mathbf{A}\) approximately preserves distances for sparse vectors, preventing distinct sparse signals from being mapped to similar measurements. The condition on \(\delta_{2k}\) guarantees that the null space of \(\mathbf{A}\) cannot contain vectors that decrease the \(\ell_1\)-norm, forcing \(\mathbf{h} = 0\).

Notation Guide

  • \(\|\mathbf{x}\|_0\) — sparsity (number of non-zero entries)
  • \(\|\mathbf{x}\|_1 = \sum_i |x_i|\) — \(\ell_1\)-norm (promotes sparsity)
  • \(\|\mathbf{x}\|_2\) — Euclidean norm
  • \(\mathbf{A}\) — measurement matrix (\(m \times n\), \(m \ll n\))
  • \(\delta_k\) — RIP constant of order \(k\)
  • \(\mathbf{y}\) — measurements (\(m\)-dimensional)

import matplotlib.pyplot as plt

def generate_sparse_signal(n, k):
    """Generate a k-sparse signal of length n."""
    x = np.zeros(n)
    support = np.random.choice(n, k, replace=False)
    x[support] = np.random.randn(k) * 10
    return x, support

def generate_measurement_matrix(m, n, matrix_type='gaussian'):
    """Generate an m x n measurement matrix."""
    if matrix_type == 'gaussian':
        A = np.random.randn(m, n) / np.sqrt(m)
    elif matrix_type == 'bernoulli':
        A = np.random.choice([-1, 1], size=(m, n)) / np.sqrt(m)
    return A

def omp(A, y, k, tol=1e-6):
    """
    Orthogonal Matching Pursuit for sparse recovery.
    
    Parameters:
    - A: measurement matrix
    - y: measurements
    - k: sparsity level
    - tol: convergence tolerance
    
    Returns:
    - x: recovered signal
    - support: estimated support
    """
    m, n = A.shape
    x = np.zeros(n)
    residual = y.copy()
    support = []
    
    for _ in range(k):
        # Find column most correlated with residual
        correlations = np.abs(A.T @ residual)
        correlations[support] = 0  # Exclude already selected
        new_index = np.argmax(correlations)
        support.append(new_index)
        
        # Solve least squares on selected support
        A_S = A[:, support]
        x_S = np.linalg.lstsq(A_S, y, rcond=None)[0]
        
        # Update residual
        residual = y - A_S @ x_S
        
        if np.linalg.norm(residual) < tol:
            break
    
    x[support] = x_S
    return x, support

def basis_pursuit(A, y):
    """L1 minimization using Lasso (approximation)."""
    # Lasso: min ||y - Ax||^2 + alpha * ||x||_1
    # For basis pursuit, we use small alpha
    lasso = Lasso(alpha=0.001, fit_intercept=False, max_iter=10000)
    lasso.fit(A, y)
    return lasso.coef_

Reinforcement Learning and Markov Decision Processes

Real-World Motivation

Reinforcement learning (RL) addresses the problem of learning optimal behavior through interaction with an environment. From game-playing AI (AlphaGo, AlphaZero) to robotics control and autonomous systems, RL provides a mathematical framework for sequential decision-making under uncertainty. The formal foundation rests on Markov Decision Processes and dynamic programming.

Definitions

Markov Decision Process (MDP): A tuple \(\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma)\) where: - \(\mathcal{S}\) is the state space - \(\mathcal{A}\) is the action space - \(P(s'|s,a)\) is the transition probability - \(R(s,a)\) is the reward function - \(\gamma \in [0,1)\) is the discount factor

Policy: A mapping \(\pi : \mathcal{S} \to \Delta(\mathcal{A})\) specifying the probability of taking each action in each state.

Value Function: The expected cumulative reward starting from state \(s\) and following policy \(\pi\): \[V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t) \,\middle|\, s_0 = s, \pi\right]\]

Theorem and Proof

Bellman Optimality Equation: The optimal value function \(V^*\) satisfies: \[V^*(s) = \max_{a \in \mathcal{A}} \left\{R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'|s,a) V^*(s')\right\}\]

Proof Sketch: The proof uses the principle of optimality. At state \(s\), the optimal action \(a^*\) maximizes the immediate reward plus the discounted expected value of the next state. By definition of optimality, the continuation value must itself be optimal, leading to the recursive structure. Uniqueness follows from the contraction mapping property of the Bellman operator \(T\) defined by the right-hand side. For \(\gamma < 1\), \(T\) is a contraction in the sup norm, guaranteeing a unique fixed point by the Banach fixed-point theorem.

Notation Guide

  • \(\mathcal{S}, \mathcal{A}\) — state and action spaces
  • \(P(s'|s,a)\) — transition probability
  • \(R(s,a)\) — expected reward
  • \(\gamma\) — discount factor
  • \(\pi(a|s)\) — policy (probability of action \(a\) in state \(s\))
  • \(V^\pi(s)\) — state value function
  • \(Q^\pi(s,a)\) — action-value function
  • \(V^*(s), Q^*(s,a)\) — optimal value functions

import numpy as np
import matplotlib.pyplot as plt

class GridWorldMDP:
    """A simple grid world MDP."""
    
    def __init__(self, size=4, gamma=0.9):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4  # up, down, left, right
        self.gamma = gamma
        
        # Actions: 0=up, 1=down, 2=left, 3=right
        self.deltas = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # Terminal states (goal and trap)
        self.goal = (size-1, size-1)
        self.trap = (size//2, size//2)
        
        # Initialize transition probabilities and rewards
        self.P = np.zeros((self.n_states, self.n_actions, self.n_states))
        self.R = np.zeros((self.n_states, self.n_actions))
        
        self._build_mdp()
    
    def _state_to_pos(self, s):
        return (s // self.size, s % self.size)
    
    def _pos_to_state(self, pos):
        return pos[0] * self.size + pos[1]
    
    def _build_mdp(self):
        for s in range(self.n_states):
            pos = self._state_to_pos(s)
            
            # Check if terminal
            if pos == self.goal or pos == self.trap:
                continue
            
            for a in range(self.n_actions):
                # Calculate next position
                next_pos = (pos[0] + self.deltas[a][0], 
                           pos[1] + self.deltas[a][1])
                
                # Boundary check
                if not (0 <= next_pos[0] < self.size and 0 <= next_pos[1] < self.size):
                    next_pos = pos  # Stay in place
                
                next_s = self._pos_to_state(next_pos)
                self.P[s, a, next_s] = 1.0
                
                # Rewards
                if next_pos == self.goal:
                    self.R[s, a] = 1.0
                elif next_pos == self.trap:
                    self.R[s, a] = -1.0
                else:
                    self.R[s, a] = -0.01  # Small step cost
    
    def value_iteration(self, theta=1e-6, max_iter=1000):
        """Value iteration algorithm."""
        V = np.zeros(self.n_states)
        
        for i in range(max_iter):
            V_new = np.zeros(self.n_states)
            
            for s in range(self.n_states):
                # Check terminal
                pos = self._state_to_pos(s)
                if pos == self.goal:
                    V_new[s] = 0
                elif pos == self.trap:
                    V_new[s] = 0
                else:
                    # Bellman optimality
                    q_values = []
                    for a in range(self.n_actions):
                        q = self.R[s, a] + self.gamma * np.sum(self.P[s, a] * V)
                        q_values.append(q)
                    V_new[s] = max(q_values)
            
            if np.max(np.abs(V - V_new)) < theta:
                print(f"Value iteration converged in {i+1} iterations")
                break
            
            V = V_new
        
        # Extract policy
        policy = np.zeros(self.n_states, dtype=int)
        for s in range(self.n_states):
            pos = self._state_to_pos(s)
            if pos == self.goal or pos == self.trap:
                continue
            
            q_values = []
            for a in range(self.n_actions):
                q = self.R[s, a] + self.gamma * np.sum(self.P[s, a] * V)
                q_values.append(q)
            policy[s] = np.argmax(q_values)
        
        return V, policy
    
    def visualize(self, V, policy):
        """Visualize value function and policy."""
        fig, axes = plt.subplots(1, 2, figsize=(12, 5))
        
        # Value function heatmap
        V_grid = V.reshape(self.size, self.size)
        im = axes[0].imshow(V_grid, cmap='RdYlGn', origin='upper')
        axes[0].set_title('Optimal Value Function V*(s)')
        axes[0].set_xlabel('Column')

        # Add values

            for j in range(self.size):
                text = axes[0].text(j, i, f'{V_grid[i, j]:.2f}',
                                   ha="center", va="center", color="black")
        
        plt.colorbar(im, ax=axes[0])
        
        # Policy arrows
        axes[1].set_xlim(-0.5, self.size - 0.5)
        axes[1].set_ylim(-0.5, self.size - 0.5)
        axes[1].set_aspect('equal')
        axes[1].invert_yaxis()
        axes[1].set_title('Optimal Policy π*(s)')
        axes[1].set_xlabel('Column')
        axes[1].set_ylabel('Row')
        
        # Draw grid

            axes[1].axvline(i - 0.5, color='gray', linewidth=0.5)

Class Field Theory: The Crown Jewel of Algebraic Number Theory

Historical Context

Class field theory, developed by Takagi, Artin, and Hasse in the early 20th century, represents one of the greatest achievements in algebraic number theory. It provides a complete description of all abelian extensions of a number field in terms of intrinsic data from the base field. Hilbert's 12th problem asked for explicit generation of such extensions, and class field theory provides the theoretical framework.

Definitions

Ray Class Group: For a modulus \(\mathfrak{m}\) of a number field \(K\), the ray class group \(Cl_\mathfrak{m}(K)\) generalizes the ideal class group by incorporating information about archimedean places and higher ramification.

Artin Map: For an abelian extension \(L/K\), the Artin map \(\psi_{L/K} : I_K \to \mathrm{Gal}(L/K)\) sends prime ideals to Frobenius elements, extending multiplicatively to all fractional ideals.

Conductor: The minimal modulus \(\mathfrak{f}(L/K)\) such that the Artin map factors through the ray class group \(Cl_\mathfrak{f}(K)\).

Theorem and Proof

Artin Reciprocity Law: Let \(L/K\) be an abelian extension with conductor \(\mathfrak{f}\). The Artin map induces an isomorphism: \[Cl_\mathfrak{f}(K) / N_{L/K}(Cl_\mathfrak{f}(L)) \cong \mathrm{Gal}(L/K)\]

Proof Sketch: The proof proceeds through several stages. First, one establishes the existence of the Artin map and shows it is a homomorphism. The key step is proving the global norm index equality: \([I_K : K^\times \cdot N_{L/K}(I_L)] = [L:K]\). This requires deep results including the first and second inequalities of global class field theory. The first inequality (\(\geq\)) follows from properties of the Artin map and the second (\(\leq\)) from cohomological methods or analytic techniques involving \(L\)-functions.

Notation Guide

  • \(K, L\) — number fields
  • \(\mathcal{O}_K\) — ring of integers of \(K\)
  • \(I_K\) — group of fractional ideals
  • \(Cl(K)\) — ideal class group
  • \(\mathfrak{m}\) — modulus (formal product of primes)
  • \(\left(\frac{L/K}{\mathfrak{p}}\right)\) — Artin symbol (Frobenius at \(\mathfrak{p}\))
  • \(\mathfrak{f}(L/K)\) — conductor of the extension

Noncommutative Geometry: Spaces from Algebras

Historical Context

Noncommutative geometry, pioneered by Alain Connes in the 1980s, extends the correspondence between geometric spaces and commutative algebras to the noncommutative setting. Gelfand's theorem establishes that compact Hausdorff spaces correspond to commutative C*-algebras. Connes asked: what "space" corresponds to a noncommutative algebra? The answer has profound implications for quantum physics, foliation theory, and number theory.

Definitions

C*-Algebra: A Banach algebra \(\mathcal{A}\) over \(\mathbb{C}\) with an involution \(*\) satisfying \(\|a^*a\| = \|a\|^2\).

Spectral Triple: A triple \((\mathcal{A}, \mathcal{H}, D)\) where: - \(\mathcal{A}\) is an algebra represented on Hilbert space \(\mathcal{H}\) - \(D\) is a self-adjoint operator (Dirac operator) with compact resolvent - The commutator \([D, a]\) is bounded for all \(a \in \mathcal{A}\)

Noncommutative Torus: The algebra \(\mathcal{A}_\theta\) generated by unitaries \(U, V\) satisfying \(VU = e^{2\pi i \theta} UV\). For irrational \(\theta\), this is a simple C*-algebra with no classical counterpart.

Theorem and Proof

Connes' Reconstruction Theorem: A commutative spectral triple satisfying certain axioms (orientation, Poincaré duality, etc.) corresponds to a smooth compact oriented spin manifold.

Proof Sketch: The algebra \(\mathcal{A}\) reconstructs the manifold as a topological space via its spectrum. The Dirac operator \(D\) encodes the metric through Connes' distance formula: \[d(p, q) = \sup\{|a(p) - a(q)| : a \in \mathcal{A}, \|[D, a]\| \leq 1\}\] The smooth structure is recovered from the Dixmier trace of operators involving \(D\). The axioms ensure the reconstructed space satisfies all properties of a spin manifold.

Notation Guide

  • \(\mathcal{A}\) — C*-algebra (noncommutative "space")
  • \(\mathcal{H}\) — Hilbert space of "spinors"
  • \(D\) — Dirac operator
  • \([D, a] = Da - aD\) — commutator
  • \(\mathcal{A}_\theta\) — noncommutative torus
  • \(\mathrm{Tr}_\omega\) — Dixmier trace
  • \(\Omega_D(\mathcal{A})\) — differential forms in NCG

import numpy as np
import matplotlib.pyplot as plt

class NoncommutativeTorus:
    """
    Finite-dimensional approximation of the noncommutative torus.
    Represented as matrices satisfying the Heisenberg relation.
    """
    
    def __init__(self, theta, n=50):
        """
        Parameters:
        - theta: deformation parameter (irrational for truly NC)
        - n: matrix dimension (finite approximation)
        """
        self.theta = theta
        self.n = n
        self.U, self.V = self._construct_generators()
    
    def _construct_generators(self):
        """Construct unitary generators U, V with VU = e^{2πiθ} UV."""
        # U is diagonal (clock operator)
        k = np.arange(self.n)
        U = np.diag(np.exp(2j * np.pi * k / self.n))
        
        # V is shift operator with twist
        V = np.zeros((self.n, self.n), dtype=complex)
        for i in range(self.n):
            j = (i + 1) % self.n
            phase = np.exp(2j * np.pi * self.theta * i / self.n)
            V[i, j] = phase
        
        return U, V
    
    def verify_relation(self):
        """Verify that VU = e^{2πiθ} UV (approximately for finite n)."""
        lhs = self.V @ self.U
        rhs = np.exp(2j * np.pi * self.theta) * self.U @ self.V
        error = np.linalg.norm(lhs - rhs)
        return error
    
    def create_element(self, coefficients):
        """
        Create an algebra element from Fourier coefficients.
        a = Σ_{m,n} c_{m,n} U^m V^n
        """
        result = np.zeros((self.n, self.n), dtype=complex)
        for (m, n), coeff in coefficients.items():
            U_m = np.linalg.matrix_power(self.U, m)
            V_n = np.linalg.matrix_power(self.V, n)
            result += coeff * U_m @ V_n
        return result
    
    def trace(self, a):
        """Normalized trace: τ(a) = (1/n) Tr(a)."""
        return np.trace(a) / self.n
    
    def spectrum(self, a):
        """Compute spectrum of element a."""
        eigenvalues = np.linalg.eigvals(a)
        return np.sort(eigenvalues)

Mirror Symmetry: A Duality in String Theory

Historical Context

Mirror symmetry emerged from string theory in the late 1980s when physicists observed that certain Calabi-Yau manifolds come in pairs with "mirrored" properties. Candelas and collaborators made a stunning prediction about curve-counting on the quintic threefold using mirror symmetry, later verified mathematically. This launched a rich interaction between physics and algebraic geometry.

Definitions

Calabi-Yau Manifold: A compact Kähler manifold \(X\) with trivial canonical bundle (\(K_X \cong \mathcal{O}_X\)) and \(H^i(X, \mathcal{O}_X) = 0\) for \(0 < i < \dim X\).

Hodge Numbers: For a Calabi-Yau threefold, the Hodge diamond has \(h^{1,1}\) and \(h^{2,1}\) as independent parameters. Mirror symmetry exchanges these: \[h^{1,1}(X) = h^{2,1}(\check{X}), \quad h^{2,1}(X) = h^{1,1}(\check{X})\]

Gromov-Witten Invariants: Counts of holomorphic curves in a Calabi-Yau manifold, defined via virtual fundamental classes on moduli spaces of stable maps.

Theorem and Proof

Mirror Theorem (Givental, Lian-Liu-Yau): For the quintic threefold \(X \subset \mathbb{P}^4\), the generating function of genus-zero Gromov-Witten invariants satisfies a Picard-Fuchs equation derived from the mirror family.

Proof Sketch: The proof uses localization techniques on moduli spaces of stable maps. The key insight is that certain Hodge-theoretic data on the mirror \(\check{X}\) (periods of the holomorphic 3-form) encode the Gromov-Witten invariants of \(X\). The Picard-Fuchs equation for the periods is derived from the variation of Hodge structure on the mirror family. The mirror map relates the complex moduli of \(\check{X}\) to the Kähler moduli of \(X\).

Notation Guide

  • \(X, \check{X}\) — mirror pair of Calabi-Yau manifolds
  • \(h^{p,q}\) — Hodge numbers
  • \(\omega\) — holomorphic volume form
  • \(\Omega\) — Kähler form
  • \(N_g^d\) — genus-\(g\), degree-\(d\) Gromov-Witten invariant
  • \(F_g\) — genus-\(g\) free energy
  • \(\mathcal{M}_{0,n}(X, \beta)\) — moduli of stable maps

p-adic Hodge Theory: Period Rings and Comparison Theorems

Historical Context

p-adic Hodge theory, developed by Fontaine, Faltings, and others in the 1980s, studies the relationship between p-adic étale cohomology and other cohomology theories (de Rham, crystalline) for varieties over p-adic fields. It provides the framework for understanding p-adic Galois representations and has become essential in modern number theory, including the proof of Fermat's Last Theorem.

Definitions

p-adic Period Rings: Fontaine constructed several rings that interpolate between different cohomology theories: - \(\mathbb{B}_{HT}\) (Hodge-Tate): relates to Hodge decomposition - \(\mathbb{B}_{dR}\) (de Rham): relates to de Rham cohomology - \(\mathbb{B}_{cris}\) (crystalline): relates to crystalline cohomology - \(\mathbb{B}_{st}\) (semi-stable): extends to semi-stable reduction

de Rham Representation: A p-adic Galois representation \(V\) is de Rham if \(\dim_K (\mathbb{B}_{dR} \otimes_{\mathbb{Q}_p} V)^{G_K} = \dim_{\mathbb{Q}_p} V\).

Crystalline Representation: A representation is crystalline if it is de Rham and the action of \(G_K\) factors through the quotient \(G_K \to \mathrm{Gal}(K^{ur}/K)\).

Theorem and Proof

de Rham Comparison Theorem: Let \(X\) be a smooth proper variety over a p-adic field \(K\). There is a canonical isomorphism: \[H^n_{\acute{e}t}(X_{\overline{K}}, \mathbb{Q}_p) \otimes_{\mathbb{Q}_p} \mathbb{B}_{dR} \cong H^n_{dR}(X/K) \otimes_K \mathbb{B}_{dR}\]

Proof Sketch: The proof uses the theory of almost étale extensions and Faltings' almost purity theorem. One constructs a pro-étale cover of \(X\) and studies the cohomology of the associated perfectoid space. The key insight is that the pro-étale topology provides a bridge between the étale and de Rham worlds. The period ring \(\mathbb{B}_{dR}\) emerges as the completion of a certain localization along the kernel of Fontaine's map \(\theta\).

Notation Guide

  • \(K\) — p-adic field (finite extension of \(\mathbb{Q}_p\))
  • \(G_K = \mathrm{Gal}(\overline{K}/K)\) — absolute Galois group
  • \(\mathbb{C}_K\) — completion of algebraic closure
  • \(\mathbb{B}_{dR}, \mathbb{B}_{cris}, \mathbb{B}_{st}\) — period rings
  • \(D_{dR}(V) = (\mathbb{B}_{dR} \otimes V)^{G_K}\) — filtered K-vector space
  • \(\mathbf{D}_{pst}\) — potentially semi-stable functor

📜 Math History: The Development of Modern Number Theory

The evolution of number theory from a collection of isolated puzzles to a sophisticated branch of modern mathematics spans millennia and reflects the broader development of mathematical thought. Ancient civilizations — the Babylonians, Egyptians, and Greeks — grappled with questions about integers, primes, and Diophantine equations, laying the groundwork for what would become one of mathematics' deepest and most influential fields.

The Greek mathematician Diophantus of Alexandria, writing around 250 CE, compiled his "Arithmetica" — a work that would inspire mathematicians for over fifteen centuries. His problems, seeking integer and rational solutions to polynomial equations, defined the field of Diophantine analysis. When Pierre de Fermat scribbled his famous marginal note in 1637, claiming to have a proof that the equation \(x^n + y^n = z^n\) has no nontrivial integer solutions for \(n > 2\), he initiated a quest that would drive number theory's development for 358 years.

The 18th century saw the systematic development of number theory through the work of Euler, Lagrange, and Legendre. Euler's introduction of analytic methods — connecting the distribution of primes to the behavior of the zeta function — opened entirely new approaches. His identity \(\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\) revealed deep connections between number theory and analysis that would flower in the following century.

Carl Friedrich Gauss, in his 1801 masterpiece "Disquisitiones Arithmeticae," transformed number theory from a collection of results into a systematic discipline. His theory of quadratic forms, the law of quadratic reciprocity, and the foundations of algebraic number theory established the field's modern character. The study of cyclotomy — division of the circle — led him to profound insights about constructible polygons and laid groundwork for later developments in class field theory.

The 19th century witnessed the birth of algebraic number theory through the work of Kummer, Dedekind, and Kronecker. Kummer's ideal numbers, developed to address the failure of unique factorization in cyclotomic fields, were refined by Dedekind into the modern theory of ideals. This algebraic approach provided the framework for understanding Fermat's Last Theorem and established connections between number theory and abstract algebra that persist today.

The 20th century brought revolutionary developments: class field theory, the Weil conjectures, and ultimately the proof of Fermat's Last Theorem by Andrew Wiles in 1995. Wiles's proof synthesized techniques from elliptic curves, modular forms, and Galois representations — demonstrating how modern number theory transcends traditional boundaries. The Langlands program, emerging in the late 1960s, proposes a vast web of conjectures connecting number theory, representation theory, and algebraic geometry, suggesting that we have only begun to understand the deep structures underlying the integers.

🎯 Problem Corner

Putnam 2023 Problem B6

Let \(n\) be a positive integer. A signed binary representation of \(n\) is a finite sequence \(a_0, a_1, \ldots, a_m\) with \(a_m \neq 0\) such that each \(a_i \in \{-1, 0, 1\}\) and: \[n = \sum_{i=0}^{m} a_i 2^i\]

Define the weight of such a representation as \(\sum_{i=0}^{m} |a_i|\).

Prove that among all signed binary representations of \(n\), there is a unique one with minimal weight.

💡 Hint

Consider the non-adjacent form (NAF) where no two consecutive digits are non-zero. Show that the NAF exists, is unique, and has minimal weight. Use a greedy algorithm: repeatedly replace patterns like \(0,1,1\) with \(1,0,-1\).

✅ Solution

Existence and Uniqueness of NAF:

We prove that the Non-Adjacent Form (NAF) — where no two consecutive digits are non-zero — exists, is unique, and has minimal weight.

Algorithm: Starting from the least significant digit, if we see a pattern \(\ldots, 0, 1, 1, \ldots\) or \(\ldots, 0, -1, -1, \ldots\), replace it with \(\ldots, 1, 0, -1, \ldots\) or \(\ldots, -1, 0, 1, \ldots\) respectively. This reduces the number of adjacent non-zero digits.

Termination: Each replacement reduces the sum of positions of non-zero digits, so the process terminates.

Uniqueness: Suppose two different NAFs represent the same number. Consider the least significant position where they differ. The difference in values at that position must be compensated by higher positions, but the NAF constraint prevents this.

Minimal Weight: Any representation can be transformed to NAF without increasing weight. The key observation is that replacing \(0,1,1\) with \(1,0,-1\) preserves the value (since \(2^i + 2^{i+1} = 2^{i+2} - 2^i\)) and does not increase weight (\(2 \to 2\)).

Therefore, the NAF is the unique minimal weight representation. ∎
