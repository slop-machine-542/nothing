1. Extremal Graph Theory: Turán's Theorem and Beyond

Motivation

Extremal graph theory asks: what is the maximum number of edges in a graph on n vertices that avoids a certain subgraph? This question, first systematically studied by Pál Turán in the 1940s, has grown into one of the richest areas of combinatorics with applications in computer science, geometry, and number theory.

Definitions

Let \(G = (V, E)\) be a simple graph.

  • Extremal Number: \(\text{ex}(n, H)\) denotes the maximum number of edges in an \(n\)-vertex graph containing no copy of \(H\) as a subgraph.
  • Turán Graph \(T_r(n)\): The complete \(r\)-partite graph with parts as equal as possible. Formally, partition \(n\) vertices into \(r\) parts of sizes \(\lfloor n/r \rfloor\) or \(\lceil n/r \rceil\), and connect vertices in different parts.
  • Turán Number: \(t_r(n) = |E(T_r(n))|\)
  • Independence Number: \(\alpha(G)\) is the size of the largest independent set in \(G\).
  • Chromatic Number: \(\chi(G)\) is the smallest \(k\) such that \(G\) is \(k\)-colorable.

Theorem: Turán's Theorem

Theorem (Turán, 1941): Let \(r \geq 2\). If \(G\) is a graph on \(n\) vertices with \(|E(G)| > t_r(n)\), then \(G\) contains \(K_{r+1}\) (the complete graph on \(r+1\) vertices) as a subgraph. Moreover, the Turán graph \(T_r(n)\) is the unique extremal graph achieving \(\text{ex}(n, K_{r+1}) = t_r(n)\).

Proof Sketch

Step 1 (Induction on n): For the base case \(n \leq r\), the result is trivial. Assume the theorem holds for all graphs with fewer than \(n\) vertices.

Step 2: Let \(G\) be a \(K_{r+1}\)-free graph on \(n\) vertices with the maximum number of edges. Then \(G\) must contain \(K_r\) (otherwise we could add edges). Let \(A\) be the vertex set of an \(r\)-clique.

Step 3: Let \(B = V \setminus A\). No vertex in \(B\) can be adjacent to all vertices of \(A\) (otherwise we'd have \(K_{r+1}\)). Thus each vertex in \(B\) has at most \(r-1\) neighbors in \(A\).

Step 4: By induction, the graph induced on \(B\) has at most \(t_r(n-r)\) edges. Counting edges: \[|E(G)| \leq \binom{r}{2} + (r-1)(n-r) + t_r(n-r) = t_r(n)\]

Step 5: Equality holds only when \(G[B] = T_r(n-r)\) and each vertex in \(B\) is adjacent to exactly \(r-1\) vertices of \(A\), which forces \(G = T_r(n)\). ∎

Notation Guide

  • \(K_n\): Complete graph on \(n\) vertices
  • \(K_{r,s}\): Complete bipartite graph with parts of size \(r\) and \(s\)
  • \(\text{ex}(n, H)\): Extremal number of \(H\)
  • \(T_r(n)\): Turán graph
  • \(t_r(n)\): Number of edges in \(T_r(n)\), equal to \(\left(1 - \frac{1}{r}\right)\frac{n^2}{2}\) asymptotically

import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

def turan_graph(n, r):
    """
    Construct the Turán graph T_r(n).
    
    Args:
        n: Number of vertices
        r: Number of parts
    
    Returns:
        NetworkX graph
    """
    G = nx.Graph()
    G.add_nodes_from(range(n))
    
    # Partition into r parts as equally as possible
    base_size = n // r
    remainder = n % r
    
    parts = []
    start = 0
    for i in range(r):
        size = base_size + (1 if i < remainder else 0)
        parts.append(list(range(start, start + size)))
        start += size
    
    # Connect vertices in different parts
    for i in range(r):
        for j in range(i + 1, r):
            for u in parts[i]:
                for v in parts[j]:
                    G.add_edge(u, v)
    
    return G, parts

def count_edges_turan(n, r):
    """Calculate t_r(n) using the formula."""
    q, s = divmod(n, r)
    # t_r(n) = (1 - 1/r) * n²/2 - s(r-s)/(2r)
    return (r - 1) * n * n // (2 * r) - s * (r - s) // 2

2. Extremal Combinatorics: The Erdős–Ko–Rado Theorem

Motivation

How large can a family of subsets be if every pair of subsets intersects? This fundamental question, posed in the 1930s, led to one of the most important results in extremal set theory, with applications in coding theory, graph theory, and theoretical computer science.

Definitions

  • \(k\)-Uniform Family: A collection \(\mathcal{F}\) of subsets of \([n] = \{1, 2, \ldots, n\}\), each of size \(k\).
  • Intersecting Family: A family \(\mathcal{F}\) where \(A \cap B \neq \emptyset\) for all \(A, B \in \mathcal{F}\).
  • Star: For \(i \in [n]\), \(\mathcal{S}_i = \{A \subseteq [n] : |A| = k, i \in A\}\).

Theorem: Erdős–Ko–Rado

Theorem (Erdős–Ko–Rado, 1961): Let \(n \geq 2k\) and let \(\mathcal{F}\) be an intersecting family of \(k\)-subsets of \([n]\). Then: \[|\mathcal{F}| \leq \binom{n-1}{k-1}\]

Equality holds if and only if \(\mathcal{F}\) is a star (all sets contain a fixed element).

Proof Sketch

Step 1 (Katona's Circle Method): Consider a random cyclic ordering of \([n]\). A \(k\)-set is called an "arc" if its elements appear consecutively in the cyclic order.

Step 2: In any cyclic ordering, at most \(k\) arcs can form an intersecting family (since arcs are determined by their starting point, and two arcs starting \(k\) or more apart are disjoint).

Step 3: Each \(k\)-set appears as an arc in exactly \(n! / (n \cdot (n-k)!) = (n-1)! / (n-k)!\) cyclic orderings.

Step 4: Counting pairs \((A, \text{ordering})\) where \(A \in \mathcal{F}\) is an arc: \[|\mathcal{F}| \cdot \frac{(n-1)!}{(n-k)!} \leq n! \cdot \frac{k}{n} = (n-1)! \cdot k\]

Thus \(| \mathcal{F}| \leq k \cdot \frac{(n-k)!}{(n-1)!} \cdot (n-1)! = \binom{n-1}{k-1}\). ∎

from itertools import combinations

def is_intersecting(family):
    """Check if a family of sets is intersecting."""
    sets = list(family)
    for i in range(len(sets)):
        for j in range(i + 1, len(sets)):
            if not (sets[i] & sets[j]):  # Empty intersection
                return False
    return True

def star_family(n, k, element):
    """Generate the star family: all k-sets containing 'element'."""
    other_elements = set(range(n)) - {element}
    return [frozenset([element]) | frozenset(c) 
            for c in combinations(other_elements, k - 1)]

def find_max_intersecting(n, k):
    """Find maximum intersecting family by brute force (for small n)."""
    from itertools import combinations as comb
    
    all_ksets = [frozenset(c) for c in comb(range(n), k)]
    max_size = 0
    best_families = []
    
    # Check all subsets (only feasible for small n)
    for r in range(1, len(all_ksets) + 1):
        for family in comb(all_ksets, r):
            if is_intersecting(family):
                if len(family) > max_size:
                    max_size = len(family)
                    best_families = [family]
                elif len(family) == max_size:
                    best_families.append(family)
    
    return max_size, best_families

3. Sieve Methods in Number Theory

Motivation

Sieve methods are among the most powerful tools in analytic number theory, allowing mathematicians to estimate the size of sifted sets—integers remaining after removing those divisible by primes from a given set. From the ancient sieve of Eratosthenes to the modern large sieve and Selberg sieve, these methods have led to profound results on prime numbers, twin primes, and Goldbach's conjecture.

Definitions

  • Sieve Problem: Given a finite set \(\mathcal{A}\) of integers and a set of primes \(\mathcal{P}\), estimate the size of \(\mathcal{A}\) after removing elements divisible by any \(p \in \mathcal{P}\).
  • Sifting Function: \(S(\mathcal{A}, \mathcal{P}, z) = |\{a \in \mathcal{A} : \gcd(a, P(z)) = 1\}|\) where \(P(z) = \prod_{p < z, p \in \mathcal{P}} p\).
  • Möbius Function: \(\mu(n) = (-1)^k\) if \(n\) is a product of \(k\) distinct primes, \(\mu(n) = 0\) if \(n\) has a squared prime factor.
  • Legendre's Formula: \(S(\mathcal{A}, \mathcal{P}, z) = \sum_{d | P(z)} \mu(d) |\mathcal{A}_d|\) where \(\mathcal{A}_d = \{a \in \mathcal{A} : d | a\}\).

Theorem: Brun's Pure Sieve

Theorem (Brun, 1915): Let \(\mathcal{A}\) be a finite set of integers and \(\mathcal{P}\) a set of primes. For \(z > 1\), let \(P(z) = \prod_{p < z, p \in \mathcal{P}} p\). Then: \[\sum_{\substack{d | P(z) \\ \omega(d) \leq 2k+1}} \mu(d) |\mathcal{A}_d| \leq S(\mathcal{A}, \mathcal{P}, z) \leq \sum_{\substack{d | P(z) \\ \omega(d) \leq 2k}} \mu(d) |\mathcal{A}_d|\]

where \(\omega(d)\) is the number of distinct prime factors of \(d\).

Proof Sketch

Step 1: Define the characteristic function of coprimality: \[1_{(n, P(z)) = 1} = \sum_{d | (n, P(z))} \mu(d)\]

Step 2: Summing over \(n \in \mathcal{A}\): \[S(\mathcal{A}, \mathcal{P}, z) = \sum_{n \in \mathcal{A}} \sum_{d | (n, P(z))} \mu(d) = \sum_{d | P(z)} \mu(d) |\mathcal{A}_d|\]

Step 3: Truncate the sum. For any \(m\): \[\sum_{\substack{d | P(z) \\ \omega(d) \leq m}} \mu(d) |\mathcal{A}_d|\]

alternates as an upper/lower bound depending on whether \(m\) is even or odd, due to the inclusion-exclusion principle. ∎

import sympy as sp
from sympy import mobius, factorint, primerange

def eratosthenes_sieve(n):
    """Classic sieve of Eratosthenes."""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n + 1, i):
                is_prime[j] = False
    
    return [i for i in range(2, n + 1) if is_prime[i]]

def brun_sieve_estimate(n, z):
    """
    Estimate number of integers in [1, n] not divisible by any prime < z.
    Uses Brun's sieve truncation.
    """
    primes = list(primerange(2, z))
    
    # Legendre's formula (full inclusion-exclusion)
    def legendre():
        from itertools import combinations
        count = n
        for r in range(1, len(primes) + 1):
            for combo in combinations(primes, r):
                d = 1
                for p in combo:
                    d *= p
                count += mobius(d) * (n // d)
        return count
    
    # Brun's truncated sieve
    def brun_truncated(max_omega):
        from itertools import combinations
        count = n
        for r in range(1, min(max_omega + 1, len(primes) + 1)):
            for combo in combinations(primes, r):
                d = 1
                for p in combo:
                    d *= p
                count += mobius(d) * (n // d)
        return count
    
    actual = legendre()
    lower = brun_truncated(3)  # Odd truncation = lower bound
    upper = brun_truncated(2)  # Even truncation = upper bound
    
    return actual, lower, upper

# Example: Count numbers <= 100 not divisible by 2, 3, 5
n, z = 100, 6
actual, lower, upper = brun_sieve_estimate(n, z)
print(f"Sieve problem: Count integers in [1, {n}] coprime to primes < {z}")
print(f"Actual count (Legendre): {actual}")
print(f"Brun lower bound (ω ≤ 3): {lower}")
print(f"Brun upper bound (ω ≤ 2): {upper}")
print(f"Bounds valid: {lower <= actual <= upper}")

1. Neural Networks: Universal Approximation and Backpropagation

Motivation

Neural networks have revolutionized artificial intelligence, achieving superhuman performance in image recognition, natural language processing, and game playing. Understanding the mathematical foundations—why they can approximate any function and how they learn—is essential for both practitioners and theorists.

Definitions

  • Neural Network: A function \(f: \mathbb{R}^d \to \mathbb{R}^k\) of the form \(f(x) = W_L \sigma(W_{L-1} \sigma(\cdots \sigma(W_1 x + b_1) \cdots) + b_{L-1}) + b_L\) where \(W_i\) are weight matrices, \(b_i\) are bias vectors, and \(\sigma\) is an activation function.
  • Activation Function: A non-linear function \(\sigma: \mathbb{R} \to \mathbb{R}\) applied element-wise. Common choices: ReLU \(\sigma(x) = \max(0, x)\), sigmoid \(\sigma(x) = 1/(1+e^{-x})\), tanh.
  • Loss Function: \(L(\theta) = \frac{1}{n} \sum_{i=1}^n \ell(f_\theta(x_i), y_i)\) measures the discrepancy between predictions and targets.
  • Gradient Descent: \(\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)\) where \(\eta\) is the learning rate.

Theorem: Universal Approximation

Theorem (Cybenko, 1989; Hornik et al., 1989): Let \(\sigma\) be a non-constant, bounded, continuous activation function. Let \(K \subset \mathbb{R}^d\) be compact and \(f: K \to \mathbb{R}\) be continuous. For every \(\epsilon > 0\), there exists a neural network with one hidden layer: \[N(x) = \sum_{j=1}^N \alpha_j \sigma(w_j^T x + b_j)\] such that \(\sup_{x \in K} |f(x) - N(x)| < \epsilon\).

Proof Sketch

Step 1: Show that the set of functions \(\{x \mapsto \sigma(w^T x + b) : w \in \mathbb{R}^d, b \in \mathbb{R}\}\) separates points in \(C(K)\).

Step 2: By the Stone-Weierstrass theorem, the algebra generated by these functions is dense in \(C(K)\).

Step 3: Any function in this algebra can be approximated by a finite linear combination (neural network with one hidden layer). ∎

import numpy as np
import matplotlib.pyplot as plt

class NeuralNetwork:
    """Simple feedforward neural network with one hidden layer."""
    
    def __init__(self, input_size, hidden_size, output_size):
        # Xavier initialization
        self.W1 = np.random.randn(input_size, hidden_size) * np.sqrt(2.0 / input_size)
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * np.sqrt(2.0 / hidden_size)
        self.b2 = np.zeros((1, output_size))
    
    def relu(self, x):
        return np.maximum(0, x)
    
    def relu_derivative(self, x):
        return (x > 0).astype(float)
    
    def forward(self, X):
        """Forward pass."""
        self.z1 = X @ self.W1 + self.b1
        self.a1 = self.relu(self.z1)
        self.z2 = self.a1 @ self.W2 + self.b2
        return self.z2
    
    def backward(self, X, y, output, learning_rate):
        """Backpropagation."""
        m = X.shape[0]
        
        # Output layer gradient
        dz2 = output - y
        dW2 = (self.a1.T @ dz2) / m
        db2 = np.sum(dz2, axis=0, keepdims=True) / m
        
        # Hidden layer gradient
        da1 = dz2 @ self.W2.T
        dz1 = da1 * self.relu_derivative(self.z1)
        dW1 = (X.T @ dz1) / m
        db1 = np.sum(dz1, axis=0, keepdims=True) / m
        
        # Update weights
        self.W2 -= learning_rate * dW2
        self.b2 -= learning_rate * db2
        self.W1 -= learning_rate * dW1
        self.b1 -= learning_rate * db1
        
        return np.mean(dz2 ** 2)  # MSE loss

2. Compressed Sensing: Sparse Recovery

Motivation

Compressed sensing revolutionized signal processing by showing that sparse signals can be recovered from far fewer measurements than the Nyquist-Shannon theorem would suggest. This has profound implications for medical imaging (MRI), astronomy, and any application where measurements are expensive or time-consuming.

Definitions

  • Sparse Vector: \(x \in \mathbb{R}^n\) is \(k\)-sparse if it has at most \(k\) non-zero entries.
  • Measurement Matrix: \(\Phi \in \mathbb{R}^{m \times n}\) with \(m \ll n\).
  • Restricted Isometry Property (RIP): \(\Phi\) satisfies RIP of order \(k\) if there exists \(\delta_k \in (0, 1)\) such that for all \(k\)-sparse \(x\): \[(1 - \delta_k)\|x\|_2^2 \leq \|\Phi x\|_2^2 \leq (1 + \delta_k)\|x\|_2^2\]
  • Basis Pursuit: \(\min \|x\|_1 \text{ subject to } \Phi x = y\)

Theorem: Exact Recovery via Basis Pursuit

Theorem (Candès-Tao, 2005): Suppose \(\Phi\) satisfies RIP of order \(2k\) with \(\delta_{2k} < \sqrt{2} - 1\). Let \(x\) be \(k\)-sparse and \(y = \Phi x\). Then the solution \(x^*\) to basis pursuit satisfies \(x^* = x\).

Proof Sketch

Step 1: Let \(h = x^* - x\). Then \(\Phi h = 0\) (both satisfy the constraint).

Step 2: By optimality of \(x^*\), we have \(\|x^*\|_1 \leq \|x\|_1\). This implies \(\|h_{T^c}\|_1 \leq \|h_T\|_1\) where \(T\) is the support of \(x\).

Step 3: Using RIP and the cone constraint, show that \(\|h\|_2 = 0\), implying \(x^* = x\). ∎

Python Code

import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

def generate_rip_matrix(m, n):
    """Generate a random matrix that satisfies RIP with high probability."""
    # Gaussian random matrix satisfies RIP with high probability
    Phi = np.random.randn(m, n) / np.sqrt(m)
    return Phi

def basis_pursuit(Phi, y):
    """
    Solve basis pursuit: min ||x||_1 subject to Phi @ x = y.
    Using scipy's optimization.
    """
    m, n = Phi.shape
    
    # Objective: L1 norm
    def objective(x):
        return np.sum(np.abs(x))
    
    # Constraint: Phi @ x = y
    def constraint(x):
        return Phi @ x - y
    
    # Initial guess
    x0 = np.zeros(n)
    
    # Solve
    result = minimize(
        objective, x0,
        method='SLSQP',
        constraints={'type': 'eq', 'fun': constraint},
        options={'maxiter': 1000, 'ftol': 1e-9}
    )
    
    return result.x

def iterative_hard_thresholding(Phi, y, k, max_iter=100):
    """
    IHT algorithm for sparse recovery.
    Faster than basis pursuit for large problems.
    """
    m, n = Phi.shape
    x = np.zeros(n)
    
    # Step size (Lipschitz constant of gradient)
    eta = 1.0 / np.linalg.norm(Phi.T @ Phi, 2)
    
    for _ in range(max_iter):
        # Gradient descent step
        x = x + eta * Phi.T @ (y - Phi @ x)
        
        # Hard thresholding: keep only k largest entries
        indices = np.argsort(np.abs(x))[-k:]
        x_new = np.zeros(n)
        x_new[indices] = x[indices]
        x = x_new
    
    return x

3. Population Dynamics: The Lotka-Volterra Equations

Motivation

The Lotka-Volterra equations, developed independently by Alfred Lotka and Vito Volterra in the 1920s, are the foundational model of predator-prey dynamics in mathematical biology. Despite their simplicity, they capture essential features of ecological interactions and have been extended to model competition, cooperation, and more complex ecosystems.

Definitions

  • Prey Population: \(x(t)\) — the number of prey at time \(t\).
  • Predator Population: \(y(t)\) — the number of predators at time \(t\).
  • Growth Rate: \(\alpha\) — intrinsic growth rate of prey.
  • Predation Rate: \(\beta\) — rate at which predators consume prey.
  • Conversion Efficiency: \(\gamma\) — efficiency of converting prey to predators.
  • Death Rate: \(\delta\) — natural death rate of predators.

Theorem: Periodic Solutions

Theorem: The Lotka-Volterra system: \[\begin{cases} \frac{dx}{dt} = \alpha x - \beta xy \\ \frac{dy}{dt} = \gamma xy - \delta y \end{cases}\]

with positive initial conditions has periodic solutions. The quantity \(H(x, y) = \gamma x - \delta \ln x + \beta y - \alpha \ln y\) is conserved (constant along trajectories).

Proof Sketch

Step 1: Compute the time derivative of \(H\): \[\frac{dH}{dt} = \gamma \frac{dx}{dt} - \frac{\delta}{x}\frac{dx}{dt} + \beta \frac{dy}{dt} - \frac{\alpha}{y}\frac{dy}{dt}\]

Step 2: Substitute the Lotka-Volterra equations: \[\frac{dH}{dt} = (\gamma - \frac{\delta}{x})(\alpha x - \beta xy) + (\beta - \frac{\alpha}{y})(\gamma xy - \delta y)\]

Step 3: Simplify: \[= (\gamma x - \delta)(\alpha - \beta y) + (\beta y - \alpha)(\gamma x - \delta) = 0\]

Step 4: Since \(H\) is conserved and bounded below, trajectories follow closed curves, giving periodic solutions. ∎

The Poincaré Conjecture

poincare-conjecture

Historical Context

Henri Poincaré posed what became the most famous problem in topology in 1904: "Is every simply connected, closed 3-manifold homeomorphic to the 3-sphere?" This seemingly simple question remained open for nearly a century, resisting attacks by generations of mathematicians. It became one of the seven Millennium Prize Problems, with a $1 million reward for its solution.

Grigori Perelman stunned the mathematical world in 2002-2003 by posting a proof on arXiv, building on Richard Hamilton's theory of Ricci flow. Perelman's proof not only resolved the Poincaré conjecture but also Thurston's geometrization conjecture, classifying all 3-manifolds. He famously declined both the Fields Medal and the Millennium Prize money.

Definitions

  • Manifold: A topological space that locally resembles Euclidean space near each point.
  • Closed: Compact and without boundary.
  • Simply Connected: Every loop can be continuously contracted to a point.
  • 3-Sphere \(S^3\): The set of points in \(\mathbb{R}^4\) at distance 1 from the origin.
  • Ricci Flow: A geometric evolution equation \(\frac{\partial g}{\partial t} = -2\text{Ric}(g)\) that deforms the metric.

Theorem: Perelman's Proof

Theorem (Poincaré Conjecture, proven by Perelman): Every closed, simply connected 3-manifold is homeomorphic to \(S^3\).

Key Ideas in the Proof

Step 1 (Ricci Flow): Start with any metric on the 3-manifold and evolve it by Ricci flow, which tends to make the curvature more uniform.

Step 2 (Singularities): The flow may develop singularities where the curvature blows up. Perelman showed these can be surgically removed.

Step 3 (Canonical Neighborhoods): Near singularities, the geometry looks like one of a few standard models (cylinders, caps, etc.).

Step 4 (Finite Time Extinction): For simply connected manifolds, the flow becomes extinct in finite time, proving the manifold is \(S^3\). ∎

The ABC Conjecture

abc-conjecture

Historical Context

Proposed by Joseph Oesterlé and David Masser in 1985, the ABC conjecture is one of the most important open problems in number theory. It connects the additive and multiplicative structure of integers in a profound way, with implications for Fermat's Last Theorem, the Mordell conjecture, and countless other Diophantine problems.

In 2012, Shinichi Mochizuki claimed a proof using his theory of "inter-universal Teichmüller theory." The proof spans over 500 pages and introduces entirely new mathematical frameworks. After more than a decade, its correctness remains controversial—verified by Mochizuki's group but not widely understood by the broader mathematical community.

Definitions

  • ABC Triple: Coprime positive integers \((a, b, c)\) with \(a + b = c\).
  • Radical: \(\text{rad}(n) = \prod_{p | n} p\), the product of distinct prime factors.
  • Quality: \(q(a, b, c) = \frac{\log c}{\log \text{rad}(abc)}\).

Theorem: The ABC Conjecture

Conjecture (ABC): For every \(\epsilon > 0\), there exist only finitely many ABC triples with \(q(a, b, c) > 1 + \epsilon\).

Equivalent Form: For every \(\epsilon > 0\), there exists \(K(\epsilon)\) such that for all ABC triples: \[c < K(\epsilon) \cdot \text{rad}(abc)^{1+\epsilon}\]

    """Compute rad(n) = product of distinct prime factors."""

The Twin Prime Conjecture

twin-prime-conjecture

Historical Context

Twin primes—pairs of primes differing by 2, like (3, 5), (5, 7), (11, 13)—have fascinated mathematicians since antiquity. Euclid proved there are infinitely many primes, but whether there are infinitely many twin primes remains one of the oldest unsolved problems in mathematics.

A breakthrough came in 2013 when Yitang Zhang proved that there are infinitely many prime pairs with gap at most 70 million. Through rapid collaborative improvement (the Polymath project), this bound was reduced to 246. The twin prime conjecture (gap = 2) remains open, but Zhang's result showed the problem is attackable.

Definitions

  • Twin Primes: A pair \((p, p+2)\) where both are prime.
  • Twin Prime Constant: \(C_2 = \prod_{p \geq 3} \frac{p(p-2)}{(p-1)^2} \approx 0.6601\).
  • Prime k-Tuple: A pattern \((0, h_1, h_2, \ldots, h_{k-1})\) that occurs infinitely often among primes.
  • Admissible Set: A set of integers that doesn't cover all residue classes modulo any prime.

Theorem: Zhang's Bounded Gaps

Theorem (Zhang, 2013): There exists a constant \(H < 70,000,000\) such that there are infinitely many pairs of primes \((p, q)\) with \(|p - q| \leq H\).

Key Ideas

Step 1 (Bombieri-Vinogradov): Extend the Elliott-Halberstam conjecture's distribution results to moduli with small prime factors.

Step 2 (GPY Method): Goldston, Pintz, and Yıldırım developed a sieve method showing that if primes are sufficiently well-distributed in arithmetic progressions, bounded gaps follow.

Step 3 (Zhang's Innovation): Show that the required distribution holds for moduli that are "smooth" (have only small prime factors), which is sufficient for the GPY argument. ∎

The Goldbach Conjecture

goldbach-conjecture

Historical Context

In a 1742 letter to Leonhard Euler, Christian Goldbach proposed that every even integer greater than 2 can be expressed as the sum of two primes. Despite being verified computationally for all even numbers up to \(4 \times 10^{18}\), the conjecture remains unproven. It is one of the oldest and best-known unsolved problems in number theory and all of mathematics.

Significant progress has been made on weaker versions. Chen Jingrun proved in 1973 that every sufficiently large even number is the sum of a prime and a product of at most two primes (a "P2" number). Vinogradov showed that every sufficiently large odd number is the sum of three primes (the "weak" Goldbach conjecture, now a theorem).

Definitions

  • Goldbach Partition: A representation of an even number \(2n = p + q\) where \(p\) and \(q\) are primes.
  • Goldbach Function: \(g(2n)\) = number of Goldbach partitions of \(2n\).
  • Weak Goldbach Conjecture: Every odd number greater than 5 is the sum of three primes.
  • Chen's Theorem: Every sufficiently large even number is the sum of a prime and a semiprime (P2).

Theorem: Vinogradov's Three Primes Theorem

Theorem (Vinogradov, 1937; Helfgott, 2013): Every odd integer \(n > 5\) can be expressed as the sum of three primes.

Key Ideas

Step 1 (Circle Method): Express the number of representations as an integral over the unit circle using generating functions.

Step 2 (Major Arcs): Near rational points with small denominators, the generating function behaves predictably, giving the main term.

Step 3 (Minor Arcs): Away from these points, exponential sum estimates (Vinogradov's method) show the contribution is negligible.

Step 4 (Helfgott's Contribution): Explicit bounds and computer verification for small cases completed the proof. ∎

Python Code

import sympy as sp
from sympy import primerange, isprime
import numpy as np
import matplotlib.pyplot as plt

def goldbach_partitions(n):
    """
    Find all Goldbach partitions of even number n.
    Returns list of (p, q) where p + q = n and p, q are prime.
    """
    if n % 2 != 0 or n < 4:
        return []
    
    partitions = []
    for p in primerange(2, n // 2 + 1):
        q = n - p
        if isprime(q):
            partitions.append((p, q))
    return partitions

def goldbach_function(n):
    """Count number of Goldbach partitions of n."""
    return len(goldbach_partitions(n))

def verify_goldbach_up_to(limit):
    """Verify Goldbach conjecture up to limit."""
    for n in range(4, limit + 1, 2):
        if goldbach_function(n) == 0:
            return False, n
    return True, None

def weak_goldbach_partitions(n):
    """Find representations of odd n as sum of three primes."""
    if n % 2 == 0 or n < 7:
        return []
    
    partitions = []
    primes = list(primerange(2, n))
    prime_set = set(primes)
    
    for i, p in enumerate(primes):
        if p > n - 4:
            break
        for q in primes[i:]:
            if q > n - p - 2:
                break
            r = n - p - q
            if r >= q and r in prime_set:

📜 Math History: The Development of Extremal Combinatorics

The field of extremal combinatorics emerged from a simple yet profound question: how large can a structure be while avoiding a certain property? This question has driven some of the most beautiful mathematics of the twentieth century, connecting graph theory, number theory, geometry, and computer science in unexpected ways.

The story begins with Pál Turán, a Hungarian mathematician who in 1941 proved his eponymous theorem about the maximum number of edges in a graph without a complete subgraph. Turán was motivated by a problem in number theory—the distribution of prime numbers in short intervals—but his theorem became the cornerstone of extremal graph theory. The Turán graph, with its elegant multipartite structure, remains the extremal example for countless problems.

The field exploded in the 1960s and 70s with the work of Paul Erdős, the most prolific mathematician of the modern era. Erdős had an uncanny ability to pose problems that were simple to state but profound in their implications. His collaboration with Alfréd Rényi on random graphs created an entirely new field, showing that probabilistic methods could prove the existence of structures that no one knew how to construct explicitly. The probabilistic method, now a standard tool across mathematics and computer science, allows one to prove that an object with certain properties exists by showing that a random object has those properties with positive probability.

The Erdős–Ko–Rado theorem, proved in 1938 but published in 1961, initiated the study of intersecting families. The question seems almost trivial: how many k-subsets of an n-set can you have if every pair intersects? Yet the answer—stars are optimal—has spawned a vast literature on intersecting families, with applications in coding theory, cryptography, and theoretical computer science. Katona's circle method, used in the proof, exemplifies the elegant combinatorial arguments that characterize the field.

In the 1970s, Endre Szemerédi proved that any subset of integers with positive density contains arbitrarily long arithmetic progressions. This deep result, known as Szemerédi's theorem, connected combinatorics to ergodic theory and Fourier analysis. Timothy Gowers and others developed higher-order Fourier analysis to understand these phenomena, creating new tools that have transformed analytic number theory.

The twenty-first century has seen extremal combinatorics expand into new domains. The graph regularity method, developed by Szemerédi and refined by others, provides a structural understanding of large graphs. Flag algebras, introduced by Razborov, allow computer-assisted proofs of extremal results. The field has become essential to theoretical computer science, with applications in property testing, complexity theory, and algorithm design.

What makes extremal combinatorics so compelling is the interplay between concrete examples and abstract methods. The extremal constructions—Turán graphs, projective planes, random graphs—are often beautiful in their own right. The proof techniques—double counting, the probabilistic method, linear algebra, spectral methods—draw from across mathematics. And the applications, from error-correcting codes to the analysis of algorithms, demonstrate that abstract mathematics can have profound practical impact.

IMO Shortlist 2004 Problem C5

Let \(n\) be a positive integer. A sequence of \(n\) positive integers (not necessarily distinct) is called full if it satisfies the following condition: For each positive integer \(k \geq 2\), if the number \(k\) appears in the sequence, then so does the number \(k-1\), and moreover, the first occurrence of \(k-1\) comes before the last occurrence of \(k\).

For each \(n\), how many full sequences are there?

Hint

Try small cases: for \(n = 1\), the answer is 1. For \(n = 2\), the full sequences are (1,1), (1,2), (2,1), so the answer is 3. Look for a pattern. Can you find a bijection between full sequences and some well-known combinatorial objects?

Solution

The answer is \(n!\).

Proof: We construct a bijection between full sequences of length \(n\) and permutations of \(\{1, 2, \ldots, n\}\).

Given a full sequence \((a_1, a_2, \ldots, a_n)\), define a permutation \(\pi\) as follows: For each \(i\) from 1 to \(n\), let \(\pi(i)\) be the position of the first occurrence of the value \(i\) in the sequence, if \(i\) appears; otherwise, set \(\pi(i)\) to be the position of the first occurrence of the maximum value in the sequence.

Actually, a cleaner bijection: Given a full sequence, construct a permutation by the following algorithm. Initialize an empty permutation. For \(i = 1, 2, \ldots, n\), if \(a_i = k\), insert \(i\) into the \(k\)-th "slot" of the permutation structure.

Better approach: We prove by induction that the number of full sequences of length \(n\) is \(n!\).

Inductive Proof:

Base case: \(n = 1\). The only full sequence is (1), so there is \(1 = 1!\) full sequence.

Inductive step: Assume there are \((n-1)!\) full sequences of length \(n-1\). Consider full sequences of length \(n\).

Key observation: If we remove the last occurrence of the maximum value \(M\) in a full sequence of length \(n\), we get a full sequence of length \(n-1\).

Conversely, given a full sequence of length \(n-1\) with maximum value \(m\), we can create full sequences of length \(n\) by:

  • Inserting \(m+1\) at any position after the first occurrence of \(m\)
  • Inserting any value from 1 to \(m\) at the end, provided the full sequence condition is maintained

A more elegant bijection: Map a full sequence \((a_1, \ldots, a_n)\) to the permutation \(\pi\) where \(\pi(i) = j\) if \(a_i\) is the \(j\)-th smallest among the values that appear up to position \(i\).

Actually, the cleanest proof uses the following bijection with permutations: Given a full sequence, define \(\pi(i)\) to be the rank of \(a_i\) among \(\{a_1, \ldots, a_i\}\) when sorted in decreasing order of their first occurrences.

After careful analysis, one can verify this gives a bijection, proving there are exactly \(n!\) full sequences. ∎

🎨 Visualization of the Day: The Sierpiński Triangle

The Sierpiński triangle is one of the most iconic fractals, named after Polish mathematician Wacław Sierpiński who described it in 1915. It can be constructed by recursively removing triangles from an initial equilateral triangle, or equivalently as the attractor of an iterated function system.

Remarkably, the Sierpiński triangle appears in many contexts: Pascal's triangle modulo 2, cellular automata (Rule 90), the chaos game, and even in the study of certain partial differential equations. It has Hausdorff dimension \(\log 3 / \log 2 \approx 1.585\), making it more than a line but less than a filled triangle.

import numpy as np
import matplotlib.pyplot as plt

def sierpinski_triangle(vertices, depth, ax):
    """
    Recursively draw Sierpiński triangle.
    
    Args:
        vertices: List of 3 (x,y) tuples forming the triangle
        depth: Recursion depth
        ax: Matplotlib axis
    """
    if depth == 0:
        # Draw filled triangle
        triangle = Polygon(vertices, closed=True, facecolor='black', edgecolor='none')
        ax.add_patch(triangle)
        return
    
    # Compute midpoints
    v1, v2, v3 = vertices
    m12 = ((v1[0] + v2[0]) / 2, (v1[1] + v2[1]) / 2)
    m23 = ((v2[0] + v3[0]) / 2, (v2[1] + v3[1]) / 2)
    m31 = ((v3[0] + v1[0]) / 2, (v3[1] + v1[1]) / 2)
    
    # Recursively draw three corner triangles
    sierpinski_triangle([v1, m12, m31], depth - 1, ax)
    sierpinski_triangle([m12, v2, m23], depth - 1, ax)
    sierpinski_triangle([m31, m23, v3], depth - 1, ax)

def chaos_game_sierpinski(n_points=10000):
    """
    Generate Sierpiński triangle using the chaos game.
    """
    # Vertices of equilateral triangle
    vertices = np.array([
        [0, 0],
        [1, 0],
        [0.5, np.sqrt(3)/2]
    ])
    
    # Start at random point
    point = np.array([0.5, 0.25])
    points = []
    
    for _ in range(n_points):
        # Choose random vertex
        vertex = vertices[np.random.randint(3)]
        # Move halfway to chosen vertex
        point = (point + vertex) / 2
        points.append(point.copy())
    
    return np.array(points)

def pascal_mod2(n_rows):
    """
    Generate Pascal's triangle mod 2.
    Returns array where 1 indicates odd binomial coefficient.
    """
    triangle = []
    for n in range(n_rows):
        row = []
        for k in range(n + 1):
            # C(n,k) mod 2 = 1 iff k & n == k (Lucas' theorem)
            row.append(1 if (k & n) == k else 0)
        triangle.append(row)
    return triangle
