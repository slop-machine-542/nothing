Forcing and the Continuum Hypothesis

set-theory

Motivation

In 1878, Georg Cantor asked whether there exists a set whose cardinality is strictly between that of the natural numbers and the real numbers. This question, the Continuum Hypothesis (CH), became the first problem on Hilbert's famous list of 23 unsolved problems in 1900. Paul Cohen's method of forcing, developed in 1963, proved that CH is independent of the standard axioms of set theory (ZFC), demonstrating the profound limitations and flexibility of axiomatic foundations.

Definitions

  • Cardinality: Two sets have the same cardinality if there exists a bijection between them.
  • Continuum Hypothesis (CH): There is no set \(S\) such that \(\aleph_0 < |S| < 2^{\aleph_0}\).
  • Partial Order (Poset): A set \(P\) with a reflexive, antisymmetric, transitive relation \(\leq\).
  • Generic Filter: A subset \(G \subseteq P\) that is upward closed, directed, and meets every dense subset in the ground model.
  • Forcing Extension: A model \(M[G]\) obtained by adjoining a generic filter \(G\) to a countable transitive model \(M\).

Theorem: Cohen's Forcing Theorem

Theorem (Cohen, 1963): If \(M\) is a countable transitive model of ZFC and \(\mathbb{P} = \text{Fin}(\omega_2^M \times \omega, 2)\) is the forcing notion of finite partial functions from \(\omega_2^M \times \omega\) to \(\{0,1\}\), then the generic extension \(M[G]\) satisfies ZFC + \(2^{\aleph_0} = \aleph_2\). In particular, CH fails in \(M[G]\).

Notation Guide

  • \(\aleph_0\): Cardinality of the natural numbers
  • \(\aleph_1\): The first uncountable cardinal
  • \(2^{\aleph_0}\): Cardinality of the continuum (real numbers)
  • \(M\): Ground model (countable transitive model of ZFC)
  • \(M[G]\): Forcing extension by generic filter \(G\)
  • \(p \Vdash \varphi\): Condition \(p\) forces statement \(\varphi\)

import itertools
from typing import Set, Tuple, Dict, List

class FinitePartialFunction:
    """
    Represents a finite partial function, the basic building block of Cohen forcing.
    In Cohen forcing, conditions are finite partial functions from ω×ω to {0,1}.
    """
    def __init__(self, mapping: Dict[Tuple[int, int], int] = None):
        self.mapping = mapping or {}
        self.domain = set(self.mapping.keys())
    
    def __le__(self, other):
        """Extension ordering: p ≤ q iff p extends q (p has more information)"""
        for key, val in other.mapping.items():
            if key not in self.mapping or self.mapping[key] != val:
                return False
        return True
    
    def is_compatible(self, other):
        """Two conditions are compatible if they agree on their common domain."""
        common = self.domain & other.domain
        return all(self.mapping[k] == other.mapping[k] for k in common)
    
    def union(self, other):
        """Return the union if compatible, else None."""
        if not self.is_compatible(other):
            return None
        new_map = {**self.mapping, **other.mapping}
        return FinitePartialFunction(new_map)
    
    def __repr__(self):
        items = sorted(self.mapping.items())
        return f"FPF({items})"

Interval Exchange Transformations

dynamical-systems

Motivation

Interval exchange transformations (IETs) are piecewise isometries of the interval that arise naturally in the study of polygonal billiards, measured foliations on surfaces, and Teichmüller theory. They provide a rich class of dynamical systems that exhibit behaviors ranging from periodic to uniquely ergodic. The study of IETs connects number theory, geometry, and ergodic theory in profound ways.

Definitions

  • Interval Exchange: A map \(T: [0,1) \to [0,1)\) that rearranges subintervals by translation.
  • Permutation Data: A pair \((\pi, \lambda)\) where \(\pi\) is a permutation and \(\lambda\) is a length vector.
  • Rauzy Induction: A renormalization procedure that induces \(T\) on a smaller interval.
  • Keane Condition: No iterate of a discontinuity hits another discontinuity (ensures minimality).
  • Uniquely Ergodic: There is exactly one invariant probability measure.

Theorem: Masur-Veech

Theorem (Masur 1982, Veech 1982): For almost every interval exchange transformation (with respect to Lebesgue measure on the simplex of length vectors), the transformation is uniquely ergodic. Specifically, if \(\pi\) is an irreducible permutation on \(d\) symbols, then the set of length vectors \(\lambda \in \Delta_{d-1}\) for which the IET is uniquely ergodic has full measure.

Notation Guide

  • \(I = [0,1)\): The unit interval
  • \(I_\alpha\): Subintervals partitioned by lengths \(\lambda_\alpha\)
  • \(\pi_0, \pi_1\): Two permutations describing the ordering
  • \(R\): Rauzy induction operator
  • \(\mathcal{R}\): Rauzy-Veech renormalization dynamics
  • \(\mu\): Invariant measure

import numpy as np
import matplotlib.pyplot as plt
from typing import List, Tuple, Callable

class IntervalExchange:
    """
    Interval Exchange Transformation (IET).
    
    An IET is defined by:
    - A length vector λ = (λ₁, ..., λ_d)
    - A permutation π that rearranges the intervals
    """
    def __init__(self, lengths: np.ndarray, permutation: List[int]):
        """
        Initialize IET.
        
        Args:
            lengths: Positive numbers summing to 1
            permutation: Permutation of [0, 1, ..., d-1]
        """
        self.lengths = np.array(lengths) / np.sum(lengths)  # Normalize
        self.permutation = permutation
        self.d = len(lengths)
        
        # Compute interval boundaries
        self.left_endpoints = np.concatenate([[0], np.cumsum(self.lengths)[:-1]])
        self.right_endpoints = np.cumsum(self.lengths)
        
        # Compute image interval boundaries
        self.image_lengths = self.lengths[np.argsort(self.permutation)]
        self.image_left = np.concatenate([[0], np.cumsum(self.image_lengths)[:-1]])
    
    def __call__(self, x: float) -> float:
        """Apply the IET to point x."""
        # Find which interval x belongs to
        for i in range(self.d):
            if self.left_endpoints[i] <= x < self.right_endpoints[i]:
                # Map to the permuted position
                offset = x - self.left_endpoints[i]
                return self.image_left[self.permutation[i]] + offset
        return 0.0  # Should not reach here for x in [0,1)
    
    def iterate(self, x: float, n: int) -> float:
        """Apply IET n times."""
        for _ in range(n):
            x = self.__call__(x)
        return x
    
    def orbit(self, x: float, n: int) -> np.ndarray:
        """Compute orbit of length n starting from x."""
        orb = np.zeros(n)
        orb[0] = x
        for i in range(1, n):
            orb[i] = self.__call__(orb[i-1])
        return orb
    
    def rauzy_induction(self) -> 'IntervalExchange':
        """
        Apply one step of Rauzy induction.
        
        Rauzy induction restricts the IET to the interval [0, 1 - min(λ_d, λ_{π⁻¹(d)}))
        """
        last_orig = self.lengths[-1]
        last_image_idx = np.where(np.array(self.permutation) == self.d - 1)[0][0]
        last_image = self.lengths[last_image_idx]
        
        if last_orig < last_image:
            # Type 0 (winner is last interval in domain)
            new_lengths = self.lengths.copy()
            new_lengths[last_image_idx] -= last_orig
            return IntervalExchange(new_lengths, self.permutation)
        else:
            # Type 1 (winner is last interval in range)
            new_lengths = self.lengths.copy()
            new_lengths[-1] -= last_image
            # Update permutation
            new_perm = self.permutation.copy()
            return IntervalExchange(new_lengths, new_perm)


def compute_rotation_number(iet: IntervalExchange, x0: float = 0.1, n_iter: int = 10000) -> float:
    """
    Compute the average displacement (rotation number analog).
    
    For an IET on [0,1), this measures the average 'drift' per iteration.
    """
    x = x0
    total_displacement = 0.0
    
    for _ in range(n_iter):
        x_new = iet(x)
        # Handle wrap-around
        disp = x_new - x
        total_displacement += disp
        x = x_new
    
    return total_displacement / n_iter


def unique_ergodicity_test(iet: IntervalExchange, n_bins: int = 50, n_iter: int = 10000) -> np.ndarray:
    """
    Test for unique ergodicity by checking if all orbits distribute uniformly.
    
    Returns the histogram of orbit points - should be approximately uniform
    for uniquely ergodic IETs.
    """
    histogram = np.zeros(n_bins)
    bin_edges = np.linspace(0, 1, n_bins + 1)
    
    # Sample multiple starting points
    n_samples = 20
    for i in range(n_samples):
        x0 = np.random.uniform(0, 1)
        orbit = iet.orbit(x0, n_iter)
        
        # Update histogram
        for x in orbit:
            bin_idx = int(x * n_bins)
            if bin_idx < n_bins:
                histogram[bin_idx] += 1
    
    # Normalize
    histogram = histogram / np.sum(histogram)
    return histogram

The Brunn-Minkowski Theory

convex-geometry

Motivation

The Brunn-Minkowski theory lies at the heart of convex geometry, connecting the volumes of convex bodies to their Minkowski sum. This theory provides powerful tools for proving isoperimetric inequalities and has profound applications in probability, functional analysis, and geometric tomography. The Brunn-Minkowski inequality, a cornerstone result, implies the classical isoperimetric inequality and the Prékopa-Leindler inequality in functional analysis.

Definitions

  • Convex Body: A compact convex subset of \(\mathbb{R}^n\) with non-empty interior.
  • Minkowski Sum: For sets \(A, B \subseteq \mathbb{R}^n\), define \(A + B = \{a + b : a \in A, b \in B\}\).
  • Scalar Multiplication: \(\lambda A = \{\lambda a : a \in A\}\) for \(\lambda \geq 0\).
  • Volume: The Lebesgue measure of a measurable set, denoted \(|A|\) or \(\text{Vol}_n(A)\).
  • Support Function: \(h_K(u) = \sup_{x \in K} \langle x, u \rangle\) for \(u \in S^{n-1}\).

Theorem: Brunn-Minkowski Inequality

Theorem: Let \(A\) and \(B\) be non-empty measurable sets in \(\mathbb{R}^n\). Then for all \(\lambda \in [0,1]\): \[|\lambda A + (1-\lambda)B|^{1/n} \geq \lambda|A|^{1/n} + (1-\lambda)|B|^{1/n}\] Equivalently: \[|A + B|^{1/n} \geq |A|^{1/n} + |B|^{1/n}\] Equality holds (for convex bodies) if and only if \(A\) and \(B\) are homothetic (equal up to translation and scaling).

Notation Guide

  • \(|A|\): Volume (Lebesgue measure) of set \(A\)
  • \(A + B\): Minkowski sum
  • \(\lambda A\): Scalar multiplication
  • \(h_K\): Support function of convex body \(K\)
  • \(S^{n-1}\): Unit sphere in \(\mathbb{R}^n\)
  • \(\langle \cdot, \cdot \rangle\): Standard inner product

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon
from scipy.spatial import ConvexHull
from typing import List, Tuple

def minkowski_sum_2d(A: np.ndarray, B: np.ndarray) -> np.ndarray:
    """
    Compute Minkowski sum of two 2D polygons.
    
    A and B are arrays of shape (n, 2) representing polygon vertices.
    Returns the vertices of A + B.
    """
    # All pairwise sums
    sums = []
    for a in A:
        for b in B:
            sums.append(a + b)
    
    sums = np.array(sums)
    
    # Compute convex hull
    if len(sums) > 2:
        hull = ConvexHull(sums)
        return sums[hull.vertices]
    return sums


def polygon_area(vertices: np.ndarray) -> float:
    """Compute area of polygon using shoelace formula."""
    n = len(vertices)
    area = 0.0
    for i in range(n):
        j = (i + 1) % n
        area += vertices[i, 0] * vertices[j, 1]
        area -= vertices[j, 0] * vertices[i, 1]
    return abs(area) / 2.0


def regular_polygon(n_sides: int, radius: float = 1.0) -> np.ndarray:
    """Generate vertices of regular n-gon."""
    angles = np.linspace(0, 2*np.pi, n_sides, endpoint=False)
    return radius * np.column_stack([np.cos(angles), np.sin(angles)])


def brunn_minkowski_check(A: np.ndarray, B: np.ndarray, n_lambda: int = 10) -> List[Tuple[float, float, float]]:
    """
    Verify Brunn-Minkowski inequality for various λ values.
    
    Returns list of (λ, LHS, RHS) where LHS = |λA + (1-λ)B|^(1/2)
    and RHS = λ|A|^(1/2) + (1-λ)|B|^(1/2)
    """
    vol_A = polygon_area(A)
    vol_B = polygon_area(B)
    
    results = []
    for lam in np.linspace(0, 1, n_lambda):
        # Compute λA + (1-λ)B
        A_scaled = lam * A
        B_scaled = (1 - lam) * B
        M_sum = minkowski_sum_2d(A_scaled, B_scaled)
        
        vol_sum = polygon_area(M_sum)
        
        lhs = np.sqrt(vol_sum)  # n=2, so 1/n = 1/2
        rhs = lam * np.sqrt(vol_A) + (1 - lam) * np.sqrt(vol_B)
        
        results.append((lam, lhs, rhs))
    
    return results


def isoperimetric_ratio(polygon: np.ndarray) -> float:
    """
    Compute isoperimetric ratio: 4πA / L²
    
    For a circle, this equals 1. For all other shapes, it's less than 1.
    """
    area = polygon_area(polygon)
    
    # Compute perimeter
    n = len(polygon)
    perimeter = 0.0
    for i in range(n):
        j = (i + 1) % n
        perimeter += np.linalg.norm(polygon[j] - polygon[i])
    
    return 4 * np.pi * area / (perimeter ** 2)

Compressed Sensing: Sparse Recovery

signal-processing

Real-World Motivation

Modern sensing systems often face a fundamental paradox: we want to acquire high-resolution data, but doing so requires expensive hardware, significant power consumption, and long acquisition times. Compressed sensing revolutionized this paradigm by showing that if a signal is sparse (or compressible) in some domain, we can reconstruct it from far fewer measurements than traditional Nyquist sampling would suggest. This has transformed MRI imaging, where scan times have been reduced from hours to minutes, and enabled single-pixel cameras that can image at wavelengths where detector arrays are prohibitively expensive.

Definitions

  • Sparsity: A vector \(x \in \mathbb{R}^n\) is \(k\)-sparse if at most \(k\) of its entries are non-zero.
  • Measurement Matrix: A matrix \(\Phi \in \mathbb{R}^{m \times n}\) with \(m \ll n\) that performs linear measurements \(y = \Phi x\).
  • Restricted Isometry Property (RIP): \(\Phi\) satisfies RIP of order \(k\) if \((1-\delta_k)\|x\|_2^2 \leq \|\Phi x\|_2^2 \leq (1+\delta_k)\|x\|_2^2\) for all \(k\)-sparse \(x\).
  • Basis Pursuit: The convex optimization \(\min \|x\|_1\) subject to \(y = \Phi x\).
  • Incoherence: The maximum inner product between columns of \(\Phi\) is small.

Theorem: Exact Recovery via Basis Pursuit

Theorem (Candès-Tao, 2005): Let \(x \in \mathbb{R}^n\) be \(k\)-sparse. If \(\Phi\) satisfies the RIP with \(\delta_{2k} < \sqrt{2} - 1\), then the solution \(x^*\) to the basis pursuit problem \[\min_{z \in \mathbb{R}^n} \|z\|_1 \quad \text{subject to} \quad \Phi z = y\] satisfies \(x^* = x\). Moreover, random matrices with i.i.d. Gaussian entries satisfy RIP with high probability when \(m \geq C k \log(n/k)\).

Notation Guide

  • \(x\): Original sparse signal in \(\mathbb{R}^n\)
  • \(y\): Measurements in \(\mathbb{R}^m\) where \(m \ll n\)
  • \(\Phi\): Measurement/sensing matrix
  • \(\|x\|_0\): Number of non-zero entries (pseudo-norm)
  • \(\|x\|_1 = \sum_i |x_i|\): L1 norm (convex relaxation of sparsity)
  • \(\delta_k\): RIP constant of order \(k\)

def generate_sparse_signal(n: int, k: int, amplitude: float = 1.0) -> np.ndarray:
    """
    Generate a k-sparse signal of length n.
    
    Args:
        n: Signal length
        k: Number of non-zero entries
        amplitude: Magnitude of non-zero entries
    
    Returns:
        k-sparse signal
    """
    x = np.zeros(n)
    support = np.random.choice(n, k, replace=False)
    x[support] = amplitude * np.random.randn(k)
    return x


def generate_measurement_matrix(m: int, n: int, matrix_type: str = 'gaussian') -> np.ndarray:
    """
    Generate measurement matrix for compressed sensing.
    
    Args:
        m: Number of measurements
        n: Signal dimension
        matrix_type: 'gaussian' or 'bernoulli'
    
    Returns:
        m × n measurement matrix
    """
    if matrix_type == 'gaussian':
        Phi = np.random.randn(m, n) / np.sqrt(m)
    elif matrix_type == 'bernoulli':
        Phi = np.random.choice([-1, 1], size=(m, n)) / np.sqrt(m)
    else:
        raise ValueError(f"Unknown matrix type: {matrix_type}")
    
    return Phi


def ista_reconstruction(y: np.ndarray, Phi: np.ndarray, 
                         lambda_param: float = 0.01,
                         max_iter: int = 1000,
                         tol: float = 1e-6) -> np.ndarray:
    """
    ISTA: Iterative Soft Thresholding Algorithm.
    
    Solves: min (1/2)||y - Phi @ x||² + lambda * ||x||_1
    """
    m, n = Phi.shape
    
    # Lipschitz constant
    L = np.linalg.norm(Phi, ord=2) ** 2
    step_size = 1.0 / L
    
    x = np.zeros(n)
    
    for _ in range(max_iter):
        # Gradient step
        grad = Phi.T @ (Phi @ x - y)
        x_temp = x - step_size * grad
        
        # Soft thresholding
        x_new = np.sign(x_temp) * np.maximum(np.abs(x_temp) - lambda_param * step_size, 0)
        
        # Check convergence
        if np.linalg.norm(x_new - x) < tol:
            break
        
        x = x_new
    
    return x


def omp_reconstruction(y: np.ndarray, Phi: np.ndarray, 
                       sparsity: int,
                       tol: float = 1e-6) -> np.ndarray:
    """
    Orthogonal Matching Pursuit (OMP) for sparse recovery.
    
    Greedy algorithm that selects atoms one at a time.
    """
    m, n = Phi.shape
    residual = y.copy()
    support = []
    
    for _ in range(sparsity):
        # Find atom most correlated with residual
        correlations = np.abs(Phi.T @ residual)
        new_atom = np.argmax(correlations)
        
        if new_atom in support:
            break
        
        support.append(new_atom)
        
        # Solve least squares on selected support
        Phi_S = Phi[:, support]
        x_S = np.linalg.lstsq(Phi_S, y, rcond=None)[0]
        
        # Update residual
        residual = y - Phi_S @ x_S
        
        if np.linalg.norm(residual) < tol:
            break
    
    # Construct full signal
    x = np.zeros(n)
    x[support] = x_S
    
    return x


def reconstruction_error(x_true: np.ndarray, x_recon: np.ndarray) -> dict:
    """Compute various error metrics."""
    return {
        'l2_relative': np.linalg.norm(x_true - x_recon) / np.linalg.norm(x_true),
        'l1_relative': np.linalg.norm(x_true - x_recon, 1) / np.linalg.norm(x_true, 1),
        'l_inf': np.linalg.norm(x_true - x_recon, np.inf),
        'support_recovery': np.sum((x_true != 0) == (np.abs(x_recon) > 1e-4)) / len(x_true)
    }

PageRank: The Mathematics of Web Search

network-analysis

Real-World Motivation

Before Google's PageRank algorithm, early search engines ranked pages primarily by counting keyword occurrences, making them vulnerable to manipulation through keyword stuffing. Larry Page and Sergey Brin's breakthrough was recognizing that the web's hyperlink structure itself contains valuable information about page importance. A link from page A to page B can be viewed as a vote of confidence, and pages that receive many votes from other important pages should themselves be considered important. This recursive definition, formalized as an eigenvector problem, became the mathematical foundation of Google's search engine and revolutionized information retrieval.

Definitions

  • Web Graph: A directed graph \(G = (V, E)\) where pages are vertices and links are edges.
  • Transition Matrix: Matrix \(P\) where \(P_{ij}\) is the probability of moving from page \(j\) to page \(i\).
  • Dangling Nodes: Pages with no outgoing links (handled by teleportation).
  • Teleportation: With probability \(\alpha\), follow a link; with probability \(1-\alpha\), jump to any page uniformly.
  • Google Matrix: \(G = \alpha P + (1-\alpha) \frac{1}{n} \mathbf{1}\mathbf{1}^T\) where \(\alpha \approx 0.85\).

Theorem: Existence and Uniqueness of PageRank

Theorem: Let \(G\) be the Google matrix with damping factor \(\alpha \in (0,1)\). Then: (1) \(G\) is a stochastic matrix with all positive entries, (2) By the Perron-Frobenius theorem, \(G\) has a unique stationary distribution \(\pi\) satisfying \(G\pi = \pi\), (3) This stationary distribution can be computed by the power iteration: \(\pi^{(k+1)} = G\pi^{(k)}\) converges to \(\pi\) for any initial probability vector \(\pi^{(0)}\).

Notation Guide

  • \(n\): Number of web pages
  • \(P\): Row-stochastic transition matrix
  • \(\alpha\): Damping factor (typically 0.85)
  • \(G\): Google matrix
  • \(\pi\): PageRank vector (stationary distribution)
  • \(\mathbf{1}\): Vector of all ones
  • \(PR(i)\): PageRank score of page \(i\)

import numpy as np
import networkx as nx
from typing import Dict, List, Tuple, Optional

class PageRank:
    """
    PageRank algorithm implementation.
    
    The PageRank of a page is the probability that a random surfer,
    following links with probability α and teleporting with probability
    (1-α), will be on that page at any given time.
    """
    def __init__(self, alpha: float = 0.85, max_iter: int = 100, tol: float = 1e-8):
        """
        Initialize PageRank calculator.
        
        Args:
            alpha: Damping factor (probability of following a link)
            max_iter: Maximum number of power iterations
            tol: Convergence tolerance
        """
        self.alpha = alpha
        self.max_iter = max_iter
        self.tol = tol
    
    def compute(self, adjacency_matrix: np.ndarray) -> np.ndarray:
        """
        Compute PageRank vector using power iteration.
        
        Args:
            adjacency_matrix: n×n adjacency matrix (A[i,j] = 1 if link j→i)
        
        Returns:
            PageRank vector π
        """
        n = adjacency_matrix.shape[0]
        
        # Build transition matrix
        out_degrees = np.sum(adjacency_matrix, axis=0)
        
        # Handle dangling nodes
        transition_matrix = np.zeros((n, n))
        for j in range(n):
            if out_degrees[j] > 0:
                transition_matrix[:, j] = adjacency_matrix[:, j] / out_degrees[j]
            else:
                transition_matrix[:, j] = 1.0 / n
        
        # Build Google matrix
        teleport_vector = np.ones(n) / n
        google_matrix = (self.alpha * transition_matrix + 
                        (1 - self.alpha) * np.outer(teleport_vector, np.ones(n)))
        
        # Power iteration
        pi = np.ones(n) / n
        
        for iteration in range(self.max_iter):
            pi_new = google_matrix @ pi
            
            diff = np.linalg.norm(pi_new - pi, 1)
            pi = pi_new
            
            if diff < self.tol:
                print(f"Converged after {iteration + 1} iterations")
                break
        
        return pi

Reinforcement Learning: The Mathematics of Optimal Decisions

machine-learning

Real-World Motivation

Reinforcement learning (RL) addresses the fundamental problem of learning optimal behavior through interaction with an environment. Unlike supervised learning, where correct answers are provided, an RL agent must discover which actions yield the most reward through trial and error. This framework has achieved remarkable successes: DeepMind's AlphaGo defeated world champions at Go, RL agents master complex video games from pixels alone, and robotic systems learn dexterous manipulation. The mathematical foundations—Markov decision processes, dynamic programming, and temporal difference learning—provide a rigorous framework for sequential decision-making under uncertainty.

Definitions

  • Markov Decision Process (MDP): Tuple \((S, A, P, R, \gamma)\) where \(S\) is states, \(A\) is actions, \(P(s'|s,a)\) is transition dynamics, \(R(s,a)\) is reward, and \(\gamma\) is discount factor.
  • Policy: A strategy \(\pi(a|s)\) specifying action probabilities in each state.
  • Value Function:\u003c/strong> \(V^\pi(s) = \mathbb{E}_\pi[\sum_{t=0}^\infty \gamma^t R_{t+1} | S_0 = s]\).
  • Q-Function:\u003c/strong> \(Q^\pi(s,a) = \mathbb{E}_\pi[\sum_{t=0}^\infty \gamma^t R_{t+1} | S_0 = s, A_0 = a]\).
  • Bellman Equation:\u003c/strong> \(V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^\pi(s')]\).

Theorem: Bellman Optimality

Theorem:\u003c/strong> For a finite MDP, there exists an optimal deterministic policy \(\pi^*\) such that \(V^{\pi^*}(s) \geq V^\pi(s)\) for all policies \(\pi\) and all states \(s\). The optimal value function \(V^*\) satisfies the Bellman optimality equation: \[V^*(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^*(s')]\] Furthermore, the optimal policy is given by \(\pi^*(s) = \arg\max_a Q^*(s,a)\) where \(Q^*(s,a) = \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^*(s')]\).

Notation Guide

  • \(S_t\): State at time \(t\)
  • \(A_t\): Action at time \(t\)
  • \(R_{t+1}\): Reward received after action \(A_t\)
  • \(\gamma \in [0,1]\): Discount factor
  • \(V^\pi(s)\): Expected return starting from state \(s\) under policy \(\pi\)
  • \(Q^\pi(s,a)\): Expected return starting from state \(s\), taking action \(a\), then following \(\pi\)
  • \(\mathbb{E}_\pi\): Expectation under policy \(\pi\)

import numpy as np
from typing import Dict, Tuple, List

class GridWorld:
    """
    Simple GridWorld environment for RL demonstration.
    
    Agent navigates a grid to reach a goal while avoiding obstacles.
    """
    def __init__(self, size: int = 5, goal: Tuple[int, int] = (4, 4),
                 obstacles: List[Tuple[int, int]] = None, slip_prob: float = 0.1):
        self.size = size
        self.goal = goal
        self.obstacles = set(obstacles or [])
        self.slip_prob = slip_prob
        
        # Actions: 0=Up, 1=Right, 2=Down, 3=Left
        self.actions = [0, 1, 2, 3]
        self.action_deltas = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        
        self.n_states = size * size
        self.n_actions = 4
        
        self.reset()
    
    def reset(self) -> int:
        """Reset to random non-goal, non-obstacle state."""
        while True:
            self.state = np.random.randint(0, self.n_states)
            row, col = self._to_coords(self.state)
            if (row, col) != self.goal and (row, col) not in self.obstacles:
                return self.state
    
    def _to_coords(self, state: int) -> Tuple[int, int]:
        """Convert state index to grid coordinates."""
        return (state // self.size, state % self.size)
    
    def _to_state(self, row: int, col: int) -> int:
        """Convert grid coordinates to state index."""
        return row * self.size + col
    
    def step(self, action: int) -> Tuple[int, float, bool]:
        """Take action, return (next_state, reward, done)."""
        row, col = self._to_coords(self.state)
        
        # Possible slip
        if np.random.random() < self.slip_prob:
            action = np.random.choice(self.actions)
        
        # Compute next position
        dr, dc = self.action_deltas[action]
        new_row, new_col = row + dr, col + dc
        
        # Check boundaries and obstacles
        if (0 <= new_row < self.size and 
            0 <= new_col < self.size and 
            (new_row, new_col) not in self.obstacles):
            row, col = new_row, new_col
        
        self.state = self._to_state(row, col)
        
        # Reward and termination
        if (row, col) == self.goal:
            return self.state, 1.0, True
        else:
            return self.state, -0.01, False


class ValueIteration:
    """Value Iteration algorithm for finding optimal policy."""
    def __init__(self, env: GridWorld, gamma: float = 0.95, theta: float = 1e-6):
        self.env = env
        self.gamma = gamma
        self.theta = theta
        self.V = np.zeros(env.n_states)
        self.policy = np.zeros(env.n_states, dtype=int)
    
    def run(self, max_iterations: int = 1000) -> Tuple[np.ndarray, np.ndarray]:
        """Run value iteration until convergence."""
        for iteration in range(max_iterations):
            delta = 0
            
            for s in range(self.env.n_states):
                v = self.V[s]
                
                # Bellman optimality update
                action_values = []
                for a in self.env.actions:
                    # Simulate transitions
                    q_value = 0
                    for _ in range(100):  # Monte Carlo estimate
                        self.env.state = s
                        s_next, r, done = self.env.step(a)
                        q_value += (r + self.gamma * self.V[s_next] * (not done)) / 100
                    action_values.append(q_value)
                
                self.V[s] = max(action_values) if action_values else 0
                delta = max(delta, abs(v - self.V[s]))
            
            if delta < self.theta:
                print(f"Value iteration converged after {iteration + 1} iterations")
                break
        
        # Extract optimal policy
        for s in range(self.env.n_states):
            action_values = []
            for a in self.env.actions:
                self.env.state = s
                s_next, r, done = self.env.step(a)
                q_value = r + self.gamma * self.V[s_next] * (not done)
                action_values.append(q_value)
            
            if action_values:
                self.policy[s] = np.argmax(action_values)
        
        return self.V, self.policy


class QLearning:
    """Q-Learning: Model-free RL algorithm."""
    def __init__(self, env: GridWorld, alpha: float = 0.1, gamma: float = 0.95,
                 epsilon: float = 0.1):
        self.env = env
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.Q = np.zeros((env.n_states, env.n_actions))
    
    def choose_action(self, state: int) -> int:
        """Epsilon-greedy action selection."""
        if np.random.random() < self.epsilon:
            return np.random.choice(self.env.actions)
        else:
            return np.argmax(self.Q[state])
    
    def learn(self, n_episodes: int = 1000) -> np.ndarray:
        """Learn Q-values through experience."""
        rewards_history = []
        
        for episode in range(n_episodes):
            state = self.env.reset()
            total_reward = 0
            done = False
            steps = 0
            
            while not done and steps < 100:
                action = self.choose_action(state)
                next_state, reward, done = self.env.step(action)
                
                # Q-learning update
                best_next_q = np.max(self.Q[next_state])
                td_target = reward + self.gamma * best_next_q * (not done)
                td_error = td_target - self.Q[state, action]
                self.Q[state, action] += self.alpha * td_error
                
                state = next_state
                total_reward += reward
                steps += 1
            
            rewards_history.append(total_reward)
            
            # Decay exploration
            self.epsilon = max(0.01, self.epsilon * 0.995)
        
        return np.array(rewards_history)
    
    def get_policy(self) -> np.ndarray:
        """Extract greedy policy from Q-values."""
        return np.argmax(self.Q, axis=1)
    
    def get_value_function(self) -> np.ndarray:
        """Get value function from Q-values."""
        return np.max(self.Q, axis=1)

The ABC Conjecture: Deep Connections in Number Theory

number-theory

Historical Context

The ABC conjecture, proposed by Joseph Oesterlé and David Masser in 1985, is one of the most important open problems in number theory. It connects the additive and multiplicative structures of integers in a profound way. The conjecture implies many famous theorems and other conjectures, including Fermat's Last Theorem for sufficiently large exponents, the Mordell conjecture (now Faltings' theorem), and the infinitude of non-Wieferich primes. In 2012, Shinichi Mochizuki claimed a proof using his theory of inter-universal Teichmüller theory, but the proof remains controversial and not widely accepted by the mathematical community.

Definitions

  • ABC Triple: Triple of coprime positive integers \((a, b, c)\) with \(a + b = c\).
  • Radical: For a positive integer \(n\), \(\text{rad}(n)\) is the product of distinct prime factors of \(n\).
  • Quality: \(q(a,b,c) = \frac{\log c}{\log(\text{rad}(abc))}\).
  • ABC Conjecture: For every \(\varepsilon > 0\), there are only finitely many ABC triples with \(q(a,b,c) > 1 + \varepsilon\).

Theorem: ABC Implies Fermat's Last Theorem (asymptotic)

Theorem:\u003c/strong> If the ABC conjecture holds, then for any \(\varepsilon > 0\), the equation \(x^n + y^n = z^n\) has no solutions in coprime positive integers for \(n \geq 6\) (in fact, for all sufficiently large \(n\)). Proof sketch: For a solution with exponent \(n\), we have \(\text{rad}(xyz) \leq xyz\). If \(x^n + y^n = z^n\), then \(z^n < \text{rad}(xyz)^{1+\varepsilon} \leq (xyz)^{1+\varepsilon} < z^{3(1+\varepsilon)/n} \cdot z^{3(1+\varepsilon)/n} \cdot z^{(1+\varepsilon)/n}\). For large \(n\), this leads to a contradiction.

Notation Guide

  • \(\text{rad}(n) = \prod_{p|n} p\): Product of distinct prime divisors
  • \(q(a,b,c)\): Quality of ABC triple
  • \(\varepsilon\): Small positive constant in the conjecture
  • \(K_\varepsilon\): Constant depending only on \(\varepsilon\)

    """
    Compute the radical of n: product of distinct prime factors.
    
    rad(n) = ∏ p where p | n and p is prime
    """
    if n <= 1:
        return n
    factors = factorint(n)
    result = 1
    for p in factors.keys():
        result *= p
    return result


def abc_quality(a: int, b: int, c: int) -> float:
    """
    Compute the quality of an ABC triple (a, b, c) where a + b = c.
    
    q(a,b,c) = log(c) / log(rad(abc))
    """
    if a + b != c:
        raise ValueError("a + b must equal c")
    if gcd(a, b) != 1:
        return 0.0  # Not a valid ABC triple
    
    rad_abc = radical(a * b * c)
    if rad_abc == 1:
        return 0.0
    
    return np.log(c) / np.log(rad_abc)

Monstrous Moonshine: The Voice of the Monster

Historical Context

In 1978, mathematician John McKay noticed a bizarre coincidence: the dimension of the smallest non-trivial irreducible representation of the Monster group, 196883, is almost exactly one less than the coefficient of \(q\) in the Fourier expansion of the \(j\)-invariant: 196884. This observation, initially dismissed as numerology, led to one of the most profound connections in mathematics: Monstrous Moonshine. The term was coined by Conway and Norton, who conjectured a deep relationship between the Monster group and modular functions. Richard Borcherds proved the conjecture in 1992, earning him a Fields Medal, by connecting it to vertex operator algebras and string theory.

Definitions

  • Monster Group \(\mathbb{M}\): The largest sporadic simple group, with order \(|\mathbb{M}| = 2^{46} \cdot 3^{20} \cdot 5^9 \cdot 7^6 \cdot 11^2 \cdot 13^3 \cdot 17 \cdot 19 \cdot 23 \cdot 29 \cdot 31 \cdot 41 \cdot 47 \cdot 59 \cdot 71\).
  • \(j\)-invariant: Modular function \(j(\tau) = q^{-1} + 744 + 196884q + 21493760q^2 + \cdots\) where \(q = e^{2\pi i \tau}\).
  • McKay's Observation: \(196884 = 1 + 196883\), where 196883 is the smallest non-trivial irreducible representation of \(\mathbb{M}\).
  • Vertex Operator Algebra (VOA): Algebraic structure underlying conformal field theory and moonshine.

Theorem: Monstrous Moonshine

Theorem (Borcherds, 1992): There exists a vertex operator algebra \(V^\natural\) (the "Monster module" or "Moonshine module") such that: (1) The automorphism group of \(V^\natural\) is the Monster group \(\mathbb{M}\), (2) The graded character of \(V^\natural\) equals the \(j\)-invariant: \[j(\tau) - 744 = \sum_{n=-1}^\infty \dim(V^\natural_n) q^n = q^{-1} + 196884q + 21493760q^2 + \cdots\] (3) This construction explains all the McKay-Thompson series and their connection to the conjugacy classes of \(\mathbb{M}\).

Notation Guide

  • \(\mathbb{M}\): The Monster simple group
  • \(j(\tau)\): Modular \(j\)-invariant
  • \(q = e^{2\pi i \tau}\): The nome, where \(\tau\) is in the upper half-plane
  • \(V^\natural\): The Moonshine vertex operator algebra
  • \(V^\natural_n\): Degree \(n\) component of the VOA
  • \(T_g(\tau)\): McKay-Thompson series for element \(g \in \mathbb{M}\)

Percolation Theory: Phase Transitions in Random Media

probability-theory

Historical Context

Percolation theory, introduced by Broadbent and Hammersley in 1957, models the flow of fluid through porous materials. The theory has since become a cornerstone of statistical mechanics and probability theory, describing phase transitions in disordered systems. It finds applications in diverse fields: understanding forest fires, modeling disease spread, analyzing network robustness, and studying conductivity in composite materials. The beauty of percolation lies in its simplicity—sites or bonds are randomly occupied with probability \(p\)—yet it exhibits rich critical behavior and universal properties that transcend specific microscopic details.

Definitions

  • Percolation Model: A lattice where each site (site percolation) or bond (bond percolation) is occupied with probability \(p\) independently.
  • Cluster: A maximal connected set of occupied sites/bonds.
  • Percolation Threshold \(p_c\): The critical probability above which an infinite cluster exists almost surely.
  • Order Parameter \(\theta(p)\): The probability that the origin belongs to an infinite cluster.
  • Correlation Length \(\xi(p)\): The typical size of finite clusters near criticality.

Theorem: Existence of Phase Transition

Theorem: For site percolation on \(\mathbb{Z}^d\) with \(d \geq 2\), there exists a critical probability \(p_c \in (0,1)\) such that: (1) For \(p < p_c\), all clusters are finite almost surely (\(\theta(p) = 0\)), (2) For \(p > p_c\), there exists a unique infinite cluster almost surely (\(\theta(p) > 0\)), (3) At \(p = p_c\), the system exhibits critical behavior with power-law correlations and fractal geometry.

Notation Guide

  • \(p\): Occupation probability
  • \(p_c\): Critical probability (percolation threshold)
  • \(\theta(p)\): Percolation probability (order parameter)
  • \(\xi(p)\): Correlation length
  • \(C(x)\): Cluster containing site \(x\)
  • \(\chi(p)\): Mean cluster size\u003c/li>
  • \(\nu, \beta, \gamma\): Critical exponents

import numpy as np
import matplotlib.pyplot as plt
from scipy.ndimage import label
from typing import Tuple, List, Dict

class Percolation2D:
    """
    2D Site Percolation on a square lattice.
    
    Each site is occupied with probability p independently.
    """
    def __init__(self, size: int, p: float):
        self.size = size
        self.p = p
        self.lattice = np.random.random((size, size)) < p
    
    def find_clusters(self) -> Tuple[np.ndarray, int]:
        """
        Identify connected clusters using Hoshen-Kopelman algorithm.
        
        Returns:
            labeled_array: Array with each site labeled by cluster ID
            num_clusters: Number of distinct clusters
        """
        # Use scipy's label function for 2D connectivity
        labeled_array, num_clusters = label(self.lattice)
        return labeled_array, num_clusters
    
    def has_spanning_cluster(self) -> bool:
        """
        Check if there exists a cluster spanning from left to right
        or from top to bottom.
        """
        labeled_array, _ = self.find_clusters()
        
        # Check left-right spanning
        left_labels = set(labeled_array[:, 0])
        right_labels = set(labeled_array[:, -1])
        
        # Remove background (label 0)
        left_labels.discard(0)
        right_labels.discard(0)
        
        if left_labels & right_labels:
            return True
        
        # Check top-bottom spanning
        top_labels = set(labeled_array[0, :])
        bottom_labels = set(labeled_array[-1, :])
        
        top_labels.discard(0)
        bottom_labels.discard(0)
        
        return bool(top_labels & bottom_labels)
    
    def largest_cluster_size(self) -> int:
        """Return the size of the largest cluster."""
        labeled_array, num_clusters = self.find_clusters()
        
        if num_clusters == 0:
            return 0
        
        sizes = np.bincount(labeled_array.ravel())[1:]  # Exclude background
        return np.max(sizes) if len(sizes) > 0 else 0
    
    def mean_cluster_size(self) -> float:
        """Return the mean cluster size (excluding infinite cluster)."""
        labeled_array, num_clusters = self.find_clusters()
        
        if num_clusters == 0:
            return 0
        
        sizes = np.bincount(labeled_array.ravel())[1:]
        return np.mean(sizes) if len(sizes) > 0 else 0


def estimate_percolation_threshold(size: int = 100, 
                                    n_trials: int = 100,
                                    n_points: int = 20) -> Dict:
    """
    Estimate the percolation threshold by finding where spanning
    probability crosses 0.5.
    """
    p_values = np.linspace(0.3, 0.8, n_points)
    spanning_probs = []
    
    for p in p_values:
        n_spanning = 0
        for _ in range(n_trials):
            perc = Percolation2D(size, p)
            if perc.has_spanning_cluster():
                n_spanning += 1
        spanning_probs.append(n_spanning / n_trials)
    
    # Find where spanning probability crosses 0.5
    spanning_probs = np.array(spanning_probs)
    above_half = np.where(spanning_probs >= 0.5)[0]
    
    if len(above_half) > 0:
        p_c_estimate = p_values[above_half[0]]
    else:
        p_c_estimate = None
    
    return {
        'p_values': p_values,
        'spanning_probs': spanning_probs,
        'p_c_estimate': p_c_estimate
    }

        results['spanning_prob'].append(spanning_count / n_samples)
    
    return results

📜 Math History: Leonhard Euler (1707–1783)

Leonhard Euler stands as one of the most prolific mathematicians in history, whose work fundamentally shaped nearly every branch of mathematics and physics. Born in Basel, Switzerland, in 1707, Euler's intellectual journey would take him across Europe and into the deepest realms of mathematical discovery, despite facing significant personal challenges including near-total blindness in his later years.

Euler's early education was directed by his father, a pastor who had studied mathematics under Jacob Bernoulli. This connection to the Bernoulli family proved transformative—at age 20, Euler moved to Russia to join the newly formed St. Petersburg Academy, where he worked alongside Daniel Bernoulli. The intellectual atmosphere of St. Petersburg, combined with the Bernoulli influence, catalyzed Euler's extraordinary productivity.

What distinguishes Euler from his contemporaries was not merely the volume of his work—though that was staggering, with over 800 books and papers published—but the clarity and accessibility of his mathematical writing. Euler had an uncanny ability to see connections between seemingly unrelated areas of mathematics. He unified analysis, geometry, and number theory in ways that revealed deep structural similarities.

Among Euler's most enduring contributions is his work on infinite series and the zeta function. In 1735, he solved the Basel problem, proving that \(\zeta(2) = \sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}\). This result, connecting the primes (through the Euler product formula) to \(\pi\), exemplified Euler's ability to bridge disparate mathematical realms. His introduction of the exponential function \(e^x\) and the famous formula \(e^{i\theta} = \cos\theta + i\sin\theta\) provided the foundation for complex analysis.

Euler's work in graph theory began with the Königsberg bridge problem in 1736, which he proved had no solution—establishing the first theorem of graph theory and initiating the field of topology. His work on the seven bridges problem demonstrated that mathematical insight could emerge from concrete, everyday questions.

In number theory, Euler extended Fermat's work, proving and generalizing many of Fermat's claims. He introduced the totient function \(\varphi(n)\), counting integers up to \(n\) that are coprime to \(n\), and proved Euler's theorem: \(a^{\varphi(n)} \equiv 1 \pmod{n}\) for coprime \(a\) and \(n\). This theorem underlies modern cryptography, including the RSA algorithm.

Perhaps most remarkably, Euler maintained his productivity even after losing sight in both eyes. His phenomenal memory and mental calculation abilities allowed him to continue producing mathematics at an extraordinary rate. He dictated papers to assistants, often working on several problems simultaneously—keeping one in his mind while another was being written down.

Euler died in Russia in 1783, having spent his final years in St. Petersburg. His legacy extends far beyond his theorems and formulas. The very notation we use today—\(e\) for the base of natural logarithms, \(i\) for the imaginary unit, \(\pi\) for the circle constant, \(\Sigma\) for summation, \(f(x)\) for functions—largely derives from Euler's innovations. He transformed mathematics from a collection of specific problems into a unified discipline, establishing patterns of thought that continue to guide mathematical research today.

Problem: AIME 2024

Let \(S\) be the set of positive integers \(n\) such that when \(n\) is written in base 10, the sum of its digits equals 2024. Find the remainder when the sum of all elements of \(S\) is divided by 1000.

Hint

Consider how many times each digit position contributes to the total sum. Think about generating functions or stars and bars with constraints.

Solution

We need to find the sum of all positive integers whose digits sum to 2024.

First, note that any such number can have at most 2024 digits (all 1s) and at least \(\lceil 2024/9 \rceil = 225\) digits (using as many 9s as possible).

For a number with \(k\) digits \(d_{k-1}d_{k-2}...d_1d_0\), the value is: \[n = \sum_{i=0}^{k-1} d_i \cdot 10^i\]

The sum of all such numbers is: \[\sum_{n \in S} n = \sum_{n \in S} \sum_{i=0}^{k-1} d_i \cdot 10^i = \sum_{i=0}^{\infty} 10^i \sum_{\substack{n \in S \\ \text{with digit } i}} d_i\]

By symmetry, for any fixed position \(i\), each digit \(d \in \{0, 1, ..., 9\}\) appears equally often in that position across all valid numbers (subject to the constraint that the sum of all digits is 2024).

Let \(N\) be the total count of valid numbers. For position \(i\), the sum of digits in that position across all numbers is: \[\sum_{\substack{n \in S \\ \text{digit } i}} d_i = \frac{N \cdot 2024}{k_{text{avg}}}\]

Actually, a cleaner approach: consider that for each valid number, we can think of distributing 2024 indistinguishable units into digit positions, where each position can hold at most 9 units.

Using generating functions, the count of solutions to \(d_0 + d_1 + ... + d_{k-1} = 2024\) with \(0 \leq d_i \leq 9\) is the coefficient of \(x^{2024}\) in \((1 + x + ... + x^9)^k = \left(\frac{1-x^{10}}{1-x}\right)^k\).

The sum of all numbers is the coefficient of \(x^{2024}\) in: \[\sum_{k=1}^{\infty} \sum_{\substack{d_0+...+d_{k-1}=2024 \\ 0 \leq d_i \leq 9}} \sum_{i=0}^{k-1} d_i \cdot 10^i\]

This equals: \[\sum_{i=0}^{\infty} 10^i \cdot [x^{2024}] \left(\frac{\partial}{\partial t}\left(\frac{1-(tx)^{10}}{1-tx}\right)^k\right)\bigg|_{t=1}\]

📊 Visualization of the Day: The Weierstrass Function

The Weierstrass function is a classic example of a function that is continuous everywhere but differentiable nowhere. It challenged the intuitive notion that continuous functions must be "smooth" at most points.

import numpy as np
import matplotlib.pyplot as plt

def weierstrass(x, a=0.5, b=3, n_terms=100):
    """
    Weierstrass function: W(x) = Σ a^n * cos(b^n * π * x)
    
    For 0 < a < 1 and ab > 1 + 3π/2, the function is continuous
    everywhere but differentiable nowhere.
    """
    result = np.zeros_like(x)
    for n in range(n_terms):
        result += a**n * np.cos((b**n) * np.pi * x)
    return result

# Parameters satisfying the Weierstrass conditions
a = 0.5  # 0 < a < 1
b = 7    # ab = 3.5 > 1 + 3π/2 ≈ 5.7... (actually need ab > 1 + 3π/2)
# Let's use b = 15 so ab = 7.5 > 5.7
b = 15

# Generate plot
x = np.linspace(-2, 2, 10000)
y = weierstrass(x, a, b, n_terms=50)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Full view
axes[0, 0].plot(x, y, 'b-', linewidth=0.5)
axes[0, 0].set_title('Weierstrass Function: Continuous, Nowhere Differentiable')
axes[0, 0].set_xlabel('x')
axes[0, 0].set_ylabel('W(x)')
axes[0, 0].grid(True, alpha=0.3)

# Zoom in progressively to show self-similarity
zoom_ranges = [(-1, 1), (-0.1, 0.1), (-0.01, 0.01)]
titles = ['Zoom: [-1, 1]', 'Zoom: [-0.1, 0.1]', 'Zoom: [-0.01, 0.01]']

for idx, ((xmin, xmax), title) in enumerate(zip(zoom_ranges, titles)):
    row, col = (idx + 1) // 2, (idx + 1) % 2
    
    x_zoom = np.linspace(xmin, xmax, 5000)
    y_zoom = weierstrass(x_zoom, a, b, n_terms=100)
    
    axes[row, col].plot(x_zoom, y_zoom, 'r-', linewidth=0.8)
    axes[row, col].set_title(title)
    axes[row, col].set_xlabel('x')
    axes[row, col].set_ylabel('W(x)')
    axes[row, col].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('weierstrass_function.png', dpi=150, bbox_inches='tight')
plt.show()

print("""
The Weierstrass function W(x) = Σ a^n cos(b^n π x) has remarkable properties:

1. CONTINUOUS: The series converges uniformly (by Weierstrass M-test),
   so W(x) is continuous.

2. NOWHERE DIFFERENTIABLE: For 0 < a < 1 and ab > 1 + 3π/2,
   the function has no derivative at any point.

3. SELF-SIMILAR: The function exhibits fractal-like behavior at all scales.
   Zooming in reveals similar complexity at every level.

4. HISTORICAL IMPACT: Before Weierstrass (1872), most mathematicians
   believed continuous functions must be differentiable except at
   isolated points. This function shattered that intuition.

5. FRACTAL DIMENSION: The graph has Hausdorff dimension > 1,
   making it a true fractal curve.
""")

What makes this visualization special: The Weierstrass function challenged 19th-century intuitions about continuity and differentiability. Unlike the smooth curves of elementary calculus, this function is jagged at every scale—zoom in anywhere, and you'll find the same level of complexity. It was one of the first examples of what we now call a fractal, predating Mandelbrot's formalization of fractal geometry by nearly a century.
