Algebraic Topology: Homotopy Groups

Motivation

How can we classify topological spaces up to continuous deformation? While homology groups capture "holes" of various dimensions, homotopy groups provide a finer invariant that captures the structure of continuous maps between spaces. The fundamental group, discovered by Poincaré, was the first homotopy invariant and launched algebraic topology as a field.

Definitions

Homotopy: Maps \(f, g: X \to Y\) are homotopic if there exists \(H: X \times [0,1] \to Y\) with \(H(x,0) = f(x)\) and \(H(x,1) = g(x)\).

n-th Homotopy Group: \(\pi_n(X, x_0)\) is the set of homotopy classes of maps \(f: (S^n, s_0) \to (X, x_0)\) with group operation given by concatenation (for \(n \geq 1\)).

Simply Connected: A space is simply connected if it is path-connected and \(\pi_1(X) = 0\).

Theorem (Hurewicz Isomorphism)

Let \(X\) be an \((n-1)\)-connected space (\(\pi_k(X) = 0\) for \(k < n\)). Then the Hurewicz map \(h: \pi_n(X) \to H_n(X)\) is an isomorphism, and \(H_k(X) = 0\) for \(k < n\).

Notation Guide

  • \(S^n\): n-dimensional sphere
  • \(\pi_n(X)\): n-th homotopy group
  • \(H_n(X)\): n-th singular homology group
  • \([f]\): homotopy class of map \(f\)
  • \(\Omega X\): loop space of \(X\)

Harmonic Analysis: Fourier Series and Transforms

Motivation

Can any function be decomposed into simple periodic components? Fourier's revolutionary insight was that virtually any function can be expressed as a superposition of sines and cosines. This decomposition underlies modern signal processing, quantum mechanics, and partial differential equations.

Definitions

Fourier Series: For \(f \in L^2([-\pi, \pi])\): \[f(x) = \sum_{n=-\infty}^{\infty} c_n e^{inx}\] where \(c_n = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(x) e^{-inx} dx\).

Fourier Transform: For \(f \in L^1(\mathbb{R})\): \[\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} dx\]

Plancherel's Theorem: The Fourier transform extends to a unitary operator on \(L^2(\mathbb{R})\), preserving inner products.

Theorem (Fourier Inversion)

If \(f\) and \(\hat{f}\) are integrable, then: \[f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\] almost everywhere.

Notation Guide

  • \(\hat{f}(\xi)\) or \(\mathcal{F}[f](\xi)\): Fourier transform
  • \(c_n\): Fourier coefficients
  • \(L^2(X)\): square-integrable functions
  • \(\langle f, g \rangle = \int f \bar{g}\): inner product
  • \(\|f\|_2 = \sqrt{\langle f, f \rangle}\): L² norm

def fourier_series_square_wave(x, n_terms):
    """

Stochastic Processes: Brownian Motion and Martingales

Motivation

How do we model random phenomena that evolve continuously in time? From stock prices to particle diffusion, stochastic processes provide the mathematical framework. Brownian motion, first observed by Robert Brown in 1827 and rigorously defined by Norbert Wiener in 1923, is the fundamental building block.

Definitions

Standard Brownian Motion: A stochastic process \((B_t)_{t \geq 0}\) such that:

  1. \(B_0 = 0\) almost surely
  2. Independent increments: \(B_t - B_s\) is independent of \(\mathcal{F}_s\) for \(t > s\)
  3. Stationary increments: \(B_t - B_s \sim N(0, t-s)\)
  4. Continuous sample paths

Martingale: A process \((M_t)\) adapted to a filtration \((\mathcal{F}_t)\) such that \(E[|M_t|] < \infty\) and \(E[M_t | \mathcal{F}_s] = M_s\) for \(s \leq t\).

Theorem (Martingale Convergence)

Let \((M_n)\) be a uniformly integrable martingale. Then \(M_n \to M_\infty\) almost surely and in \(L^1\).

Theorem (Itô's Lemma)

For \(f \in C^2\) and an Itô process \(X_t\): \[df(X_t) = f'(X_t) dX_t + \frac{1}{2} f''(X_t) d\langle X \rangle_t\]

Notation Guide

  • \(B_t\) or \(W_t\): Brownian motion (Wiener process)
  • \(\mathcal{F}_t\): filtration (information up to time t)
  • \(E[X | \mathcal{F}]\): conditional expectation
  • \(\langle X \rangle_t\): quadratic variation
  • \(dX_t = \mu dt + \sigma dB_t\): Itô process

Game Theory: Nash Equilibrium

Real-World Motivation

How do rational agents make decisions when their outcomes depend on others' choices? Game theory, pioneered by John von Neumann and John Nash, provides the framework. From auction design to nuclear deterrence, understanding strategic interaction is crucial.

Definitions

Normal Form Game: A triple \((N, (A_i)_{i \in N}, (u_i)_{i \in N})\) where \(N\) is the set of players, \(A_i\) is player \(i\)'s action set, and \(u_i: A \to \mathbb{R}\) is the payoff function.

Nash Equilibrium: A strategy profile \(\sigma^*\) such that no player can unilaterally deviate to improve their payoff: \[u_i(\sigma_i^*, \sigma_{-i}^*) \geq u_i(\sigma_i, \sigma_{-i}^*) \quad \forall \sigma_i, \forall i\]

Mixed Strategy: A probability distribution over pure strategies.

Theorem (Nash, 1950)

Every finite normal-form game has at least one Nash equilibrium in mixed strategies.

Notation Guide

  • \(N\): set of players
  • \(A_i\): action set for player \(i\)
  • \(a_{-i}\): actions of all players except \(i\)
  • \(\sigma_i\): mixed strategy for player \(i\)
  • \(\Delta(A_i)\): set of probability distributions on \(A_i\)
  • \(BR_i(\sigma_{-i})\): best response of player \(i\)

def find_nash_equilibrium_2x2(payoff_matrix_A, payoff_matrix_B):
    """
    Find Nash equilibrium for 2x2 bimatrix game.
    payoff_matrix_A[i,j] = payoff to player A when A plays i, B plays j
    """
    # For 2x2 games, we can solve analytically
    # Player A mixes with probability p of playing action 0
    # Player B mixes with probability q of playing action 0
    
    a00, a01 = payoff_matrix_A[0]
    a10, a11 = payoff_matrix_A[1]
    b00, b01 = payoff_matrix_B[0, 0], payoff_matrix_B[0, 1]
    b10, b11 = payoff_matrix_B[1, 0], payoff_matrix_B[1, 1]
    
    # Player A is indifferent when:
    # q*a00 + (1-q)*a01 = q*a10 + (1-q)*a11
    if (a00 - a01 - a10 + a11) != 0:
        q_star = (a11 - a01) / (a00 - a01 - a10 + a11)
    else:
        q_star = None
    
    # Player B is indifferent when:
    # p*b00 + (1-p)*b10 = p*b01 + (1-p)*b11
    if (b00 - b10 - b01 + b11) != 0:
        p_star = (b11 - b10) / (b00 - b10 - b01 + b11)
    else:
        p_star = None
    
    return p_star, q_star

Convex Optimization: Duality and Algorithms

Real-World Motivation

How do we find the best solution when the problem has structure? Convex optimization problems—where the objective and constraints are convex—can be solved efficiently and reliably. Applications span machine learning, control, finance, and engineering design.

Definitions

Convex Set: \(C\) is convex if \(x, y \in C \implies \theta x + (1-\theta)y \in C\) for all \(\theta \in [0,1]\).

Convex Function: \(f\) is convex if \(f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)\).

Lagrangian: For problem \(\min f(x)\) subject to \(g_i(x) \leq 0\), \(h_j(x) = 0\): \[L(x, \lambda, \nu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \nu_j h_j(x)\]

Theorem (Strong Duality)

For a convex problem satisfying Slater's condition (strict feasibility): \[p^* = d^*\] where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Theorem (KKT Conditions)

For convex problems with strong duality, \((x^*, \lambda^*, \nu^*)\) is optimal iff:

  1. Primal feasibility: \(g_i(x^*) \leq 0\), \(h_j(x^*) = 0\)
  2. Dual feasibility: \(\lambda_i^* \geq 0\)
  3. Complementary slackness: \(\lambda_i^* g_i(x^*) = 0\)
  4. Stationarity: \(\nabla_x L(x^*, \lambda^*, \nu^*) = 0\)

Notation Guide

  • \(\nabla f(x)\): gradient of \(f\) at \(x\)
  • \(\partial f(x)\): subdifferential (for non-smooth)
  • \(L(x, \lambda)\): Lagrangian
  • \(g(\lambda, \nu) = \inf_x L(x, \lambda, \nu)\): dual function
  • \(\text{prox}_{\lambda f}(v) = \arg\min_x (f(x) + \frac{1}{2\lambda}\|x-v\|^2)\): proximal operator

import numpy as np
from scipy.optimize import minimize

def gradient_descent(f, df, x0, lr=0.1, tol=1e-6, max_iter=1000):
    """
    Gradient descent for unconstrained convex optimization.
    x_{k+1} = x_k - lr * ∇f(x_k)
    """
    x = x0.copy()
    history = [f(x)]
    
    for _ in range(max_iter):
        grad = df(x)
        x_new = x - lr * grad
        history.append(f(x_new))
        
        if np.linalg.norm(x_new - x) < tol:
            break
        x = x_new
    
    return x, history

Signal Processing: Sampling and Reconstruction

Real-World Motivation

How do we convert continuous signals into digital form without losing information? The Nyquist-Shannon sampling theorem provides the fundamental limit. This underlies all digital audio, images, and communications systems.

Definitions

Sampling: Converting continuous signal \(x(t)\) to discrete sequence \(x[n] = x(nT_s)\) where \(f_s = 1/T_s\) is the sampling rate.

Aliasing: When high-frequency components fold into lower frequencies due to insufficient sampling.

Z-Transform: \(X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}\), generalization of Fourier transform for discrete signals.

Theorem (Nyquist-Shannon Sampling)

If \(x(t)\) is bandlimited to \([-B, B]\), then sampling at rate \(f_s > 2B\) allows perfect reconstruction: \[x(t) = \sum_{n=-\infty}^{\infty} x[nT_s] \text{sinc}\left(\frac{t - nT_s}{T_s}\right)\]

Notation Guide

  • \(f_s\): sampling frequency
  • \(T_s = 1/f_s\): sampling period
  • \(f_N = f_s/2\): Nyquist frequency
  • \(\text{sinc}(x) = \frac{\sin(\pi x)}{\pi x}\): sinc function
  • \(X(e^{i\omega})\): discrete-time Fourier transform

def sinc_interpolate(t_sampled, x_sampled, t_eval, fs):
    """
    Reconstruct continuous signal using sinc interpolation.
    x(t) = Σ x[n] · sinc((t - nT)/T)
    """
    T = 1 / fs
    result = np.zeros_like(t_eval)
    for n, (tn, xn) in enumerate(zip(t_sampled, x_sampled)):
        result += xn * np.sinc((t_eval - tn) / T)
    return result

Algebraic Curves: Elliptic Curves

Historical Context

Elliptic curves have been studied since the 19th century, but their importance in modern mathematics exploded in the last 50 years. Andrew Wiles's proof of Fermat's Last Theorem (1995) relied on the modularity of elliptic curves. Today, they underpin modern cryptography and number theory.

Definitions

Elliptic Curve: A smooth projective curve of genus 1 with a specified base point. Over a field \(K\) (characteristic \(\neq 2, 3\)): \[E: y^2 = x^3 + ax + b\] where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).

Group Law: Points on an elliptic curve form an abelian group with the point at infinity \(\mathcal{O}\) as identity. The sum \(P + Q\) is defined geometrically: draw line through \(P\) and \(Q\), find third intersection \(R\), then reflect over x-axis.

Theorem (Mordell-Weil)

The group of rational points \(E(\mathbb{Q})\) is finitely generated: \[E(\mathbb{Q}) \cong E(\mathbb{Q})_{\text{tors}} \oplus \mathbb{Z}^r\] where \(r\) is the rank and \(E(\mathbb{Q})_{\text{tors}}\) is the finite torsion subgroup.

Notation Guide

  • \(E(K)\): K-rational points on E
  • \(\mathcal{O}\): point at infinity (identity)
  • \([n]P\): n-fold addition of point P
  • \(j(E)\): j-invariant (classifies curves up to isomorphism)
  • \(\#E(\mathbb{F}_p)\): number of points over finite field

import numpy as np
import matplotlib.pyplot as plt

class EllipticCurve:
    """Elliptic curve y² = x³ + ax + b over real numbers."""
    
    def __init__(self, a, b):
        self.a = a
        self.b = b
        self.discriminant = -16 * (4*a**3 + 27*b**2)
        if self.discriminant == 0:
            raise ValueError("Curve is singular!")
    
    def is_on_curve(self, x, y):
        """Check if point (x,y) is on the curve."""
        return np.isclose(y**2, x**3 + self.a*x + self.b)
    
    def add_points(self, P, Q):
        """
        Add two points on the curve.
        P, Q are tuples (x, y) or None for point at infinity.
        """
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # Check if points are on curve
        assert self.is_on_curve(x1, y1), f"Point {P} not on curve"
        assert self.is_on_curve(x2, y2), f"Point {Q} not on curve"
        
        if x1 == x2 and y1 == -y2:
            return None  # Point at infinity
        
        # Calculate slope
        if x1 == x2 and y1 == y2:
            # Point doubling: λ = (3x₁² + a) / 2y₁
            lam = (3*x1**2 + self.a) / (2*y1)
        else:
            # Point addition: λ = (y₂ - y₁) / (x₂ - x₁)
            lam = (y2 - y1) / (x2 - x1)
        
        # Calculate result
        x3 = lam**2 - x1 - x2
        y3 = lam*(x1 - x3) - y1
        
        return (x3, y3)
    
    def scalar_mult(self, n, P):
        """Compute [n]P using double-and-add."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.scalar_mult(-n, (x, -y))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add_points(result, addend)
            addend = self.add_points(addend, addend)
            n >>= 1
        
        return result

Information Geometry: Statistical Manifolds

Historical Context

Information geometry, pioneered by C.R. Rao in 1945 and developed by Shun-ichi Amari in the 1980s, applies differential geometry to statistical models. It provides a natural framework for understanding parameter estimation, neural networks, and optimization on probability distributions.

Definitions

Statistical Manifold: A manifold \(\mathcal{M}\) where each point represents a probability distribution \(p(x; \theta)\) parameterized by \(\theta\).

Fisher Information Metric: The Riemannian metric on \(\mathcal{M}\) given by: \[g_{ij}(\theta) = E\left[\frac{\partial \log p(x;\theta)}{\partial \theta^i} \frac{\partial \log p(x;\theta)}{\partial \theta^j}\right]\]

Kullback-Leibler Divergence: \(D_{KL}(p \| q) = \int p(x) \log \frac{p(x)}{q(x)} dx\), which locally approximates the squared geodesic distance.

Theorem (Cramér-Rao Bound)

For any unbiased estimator \(\hat{\theta}\) of \(\theta\): \[\text{Cov}(\hat{\theta}) \succeq \frac{1}{n} I(\theta)^{-1}\] where \(I(\theta)\) is the Fisher information matrix. Equality is achieved by the maximum likelihood estimator asymptotically.

Notation Guide

  • \(g_{ij}\): Fisher information metric
  • \(\Gamma_{ij}^k\): Christoffel symbols (connection coefficients)
  • \(\nabla^{(e)}\), \(\nabla^{(m)}\): exponential and mixture connections
  • \(\alpha\)-divergence: family of divergences parameterized by \(\alpha\)
  • \(\mathcal{I}(\theta)\): Fisher information matrix

def euclidean_gradient(params):
    """Standard gradient."""
    eps = 1e-5
    grad = np.zeros(2)
    for i in range(2):
        params_plus = params.copy()
        params_plus[i] += eps
        params_minus = params.copy()
        params_minus[i] -= eps
        grad[i] = (negative_log_likelihood(params_plus) - 
                   negative_log_likelihood(params_minus)) / (2*eps)
    return grad

    I = fisher_information_gaussian(mu, sigma)
    
    # Natural gradient = I^{-1} ∇L
    grad_natural = np.linalg.solve(I, grad_euclid)

Finite Geometry: Projective Planes

Historical Context

Finite geometry emerged in the 19th century as geometers explored systems with finitely many points. Unlike Euclidean geometry, finite geometries have no continuity or metric structure—their beauty lies in pure combinatorics. They have applications in coding theory, cryptography, and design theory.

Definitions

Projective Plane of Order n: A set of points and lines satisfying:

  1. Any two distinct points lie on exactly one line
  2. Any two distinct lines meet at exactly one point
  3. There exist four points, no three collinear
  4. Every line contains exactly \(n+1\) points

Number of Points: A projective plane of order \(n\) has \(n^2 + n + 1\) points and \(n^2 + n + 1\) lines.

Theorem (Bruck-Ryser-Chowla)

If a projective plane of order \(n \equiv 1, 2 \pmod{4}\) exists, then \(n\) must be expressible as a sum of two squares.

Theorem (Existence)

Projective planes of order \(n = p^k\) (prime power) exist. The existence for other orders is unknown; in particular, order 12 is the smallest open case.

Notation Guide

  • \(PG(2, q)\): projective plane over finite field \(\mathbb{F}_q\)
  • \([x : y : z]\): homogeneous coordinates
  • \(q = n\): order of the plane
  • \(\mathbb{F}_q\): finite field with \(q\) elements

Leonhard Euler: The Master of Us All

Historical Context

Leonhard Euler (1707–1783) was the most prolific mathematician in history, publishing over 800 papers and books across virtually every mathematical field. Despite losing his sight, he continued working at an astonishing pace. His work established much of modern mathematical notation and terminology.

Major Contributions

  • Analysis: Introduced the concept of a function, popularized the notation \(f(x)\), and developed the calculus of variations
  • Number Theory: Proved Fermat's little theorem, connected the zeta function to primes
  • Graph Theory: Solved the Königsberg bridge problem, founding the field
  • Complex Analysis: Discovered the identity \(e^{i\theta} = \cos\theta + i\sin\theta\)
  • Notation: Introduced \(e\), \(i\), \(\pi\), \(\Sigma\), \(f(x)\), and modern trigonometric notation

Euler's Identity

Often called the most beautiful equation in mathematics: \[e^{i\pi} + 1 = 0\] This connects the five most important constants: 0, 1, \(e\), \(i\), and \(\pi\).

Theorem (Euler's Formula for Polyhedra)

For any convex polyhedron: \[V - E + F = 2\] where \(V\) is vertices, \(E\) is edges, and \(F\) is faces. This launched topology as a field.

Notation Guide

  • \(e = \sum_{n=0}^{\infty} \frac{1}{n!} \approx 2.71828...\): Euler's number
  • \(\gamma \approx 0.5772...\): Euler-Mascheroni constant
  • \(\varphi(n)\): Euler's totient function
  • \(\Gamma(z)\): Gamma function, extending factorial

# Euler's totient function
def euler_totient(n):
    """Compute φ(n), the count of integers ≤ n coprime to n."""
    result = n
    p = 2
    temp = n
    while p * p <= temp:
        if temp % p == 0:
            while temp % p == 0:
                temp //= p
            result -= result // p
        p += 1
    if temp > 1:
        result -= result // temp
    return result

📜 Math History

The Birth of Abstract Algebra: From Equations to Structures

The 19th century witnessed a profound transformation in mathematics: the shift from studying specific objects to studying abstract structures. This revolution, which gave birth to modern abstract algebra, began with the quest to solve polynomial equations and ended with the realization that the structure of symmetries matters more than the objects themselves.

The story begins with the work of Évariste Galois in the 1830s. Galois, a young French mathematician who would die in a duel at age 20, discovered that the solvability of a polynomial equation depends not on the coefficients themselves, but on the structure of a group associated with the equation's roots—the Galois group. This was the first time a group appeared as an abstract structure rather than a collection of permutations.

Galois's ideas were nearly lost—his papers were rejected by the Academy of Sciences, and it was only through the efforts of Joseph Liouville that they were published in 1846, fourteen years after Galois's death. By then, the mathematical world was ready for abstraction. Arthur Cayley, in 1854, defined groups axiomatically, explicitly stating that the nature of the group elements didn't matter—only how they combined.

The late 19th century saw the development of ring theory, field theory, and the axiomatic method. Richard Dedekind introduced ideals in ring theory to restore unique factorization in algebraic number fields. Emmy Noether, in the early 20th century, unified these developments with her abstract approach, showing that many results followed from general structural principles rather than specific calculations.

Noether's 1921 paper "Idealtheorie in Ringbereichen" revolutionized commutative algebra by establishing the ascending chain condition and showing that ideals in such rings have unique factorization into primary ideals. Her work at Göttingen attracted students from around the world, including future leaders like Bartel van der Waerden, whose 1930 textbook "Moderne Algebra" codified the abstract approach.

The abstraction that began with Galois and culminated with Noether changed mathematics forever. It demonstrated that understanding structure—groups, rings, fields, and their homomorphisms—provides deeper insight than manipulating specific equations. This structural viewpoint, now fundamental to all of mathematics, enabled the development of algebraic topology, algebraic geometry, and category theory in the 20th century.

🎯 Problem Corner

IMO Shortlist Problem

Problem: Let \(n\) be a positive integer. A sequence of integers \(a_0, a_1, \ldots, a_n\) is called good if it satisfies the following conditions:

  • \(a_0 = 0\) and \(a_n = n\)
  • For all \(i = 1, 2, \ldots, n\): \(a_i - a_{i-1} \in \{1, -1\}\)
  • For all \(i = 0, 1, \ldots, n\): \(a_i \geq 0\)

Determine the number of good sequences for a given \(n\).

💡 Hint

This problem is equivalent to counting Dyck paths of a certain type. Consider the relationship between the sequence values and the partial sums of \(\pm 1\) steps. The condition \(a_i \geq 0\) corresponds to the path staying above the x-axis. Use the reflection principle or Catalan numbers.

✅ Solution

Let \(s_i = a_i - a_{i-1} \in \{1, -1\}\) for \(i = 1, \ldots, n\). Then \(a_k = \sum_{i=1}^{k} s_i\).

From \(a_n = n\), we need exactly \(\frac{n+n}{2} = n\) steps of \(+1\) and \(\frac{n-n}{2} = 0\) steps of \(-1\). Wait—this gives only upward steps, which contradicts the need for the path to return to specific values.

Let me reconsider: we have \(a_n = n\) and \(a_0 = 0\), so the net change is \(n\). With steps of \(\pm 1\), we need \(\frac{n+k}{2}\) upward steps and \(\frac{n-k}{2}\) downward steps for some balance.

Actually, let \(u\) be the number of \(+1\) steps and \(d\) be the number of \(-1\) steps. Then:

  • \(u + d = n\) (total steps)
  • \(u - d = n\) (net change from 0 to n)

Solving: \(u = n\) and \(d = 0\). So all steps must be \(a_i - a_{i-1} = 1\), giving \(a_i = i\).

But we also need \(a_i \geq 0\) for all \(i\), which is satisfied since \(a_i = i \geq 0\).

Therefore, there is exactly one good sequence: \(a_i = i\) for all \(i\).

Note: This problem becomes more interesting if we change the endpoint condition. For example, if \(a_n = 0\) instead, we get the Catalan numbers counting Dyck paths.

Mandelbrot Set: The Boundary of Chaos

The Mandelbrot set is one of the most famous fractals in mathematics. It consists of all complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) (starting with \(z_0 = 0\)) remains bounded. The boundary of this set exhibits infinite complexity—zooming in reveals ever more intricate patterns that echo the whole.

The visualization below computes the escape time for each point in the complex plane, coloring points based on how quickly the iteration diverges. Points inside the set (black) remain bounded, while points outside are colored by their escape rate.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point is in (or appears to be in) the set.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(width=800, height=600, x_min=-2.5, x_max=1.5, 
                   y_min=-1.5, y_max=1.5, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        mask_new = abs(Z) <= 2
        M[~mask & mask_new] = i  # Just escaped
        mask = mask_new
    
    M[mask] = max_iter  # Never escaped
    return M
