Tensor Calculus: The Mathematics of Invariance

tensor-calculus

Motivation

Tensor calculus provides the mathematical language for expressing physical laws in a form independent of coordinate systems. From Einstein's field equations in general relativity to the stress-strain relationships in continuum mechanics, tensors capture geometric and physical quantities that transform predictably under coordinate changes. The power of tensor calculus lies in its ability to separate intrinsic geometric properties from arbitrary coordinate choices.

Definitions

  • Tensor: A multilinear map that assigns scalars to tuples of vectors and covectors. A tensor of type \((r, s)\) takes \(r\) covectors and \(s\) vectors to produce a scalar.
  • Contravariant Components: Components that transform oppositely to basis vectors. Denoted with upper indices: \(T^{i_1 \cdots i_r}\).
  • Covariant Components: Components that transform like basis vectors. Denoted with lower indices: \(T_{j_1 \cdots j_s}\).
  • Metric Tensor: A symmetric, non-degenerate tensor \(g_{ij}\) that defines distances and angles on a manifold.
  • Christoffel Symbols: Connection coefficients \(\Gamma^k_{ij}\) that describe how basis vectors change across a manifold.

Theorem: Tensor Transformation Law

Theorem: Let \(T^{i_1 \cdots i_r}_{j_1 \cdots j_s}\) be the components of a type-\((r,s)\) tensor in coordinates \(x\), and let \(\bar{x}\) be new coordinates. Then the components in the new coordinates are:

\[\bar{T}^{k_1 \cdots k_r}_{l_1 \cdots l_s} = \frac{\partial \bar{x}^{k_1}}{\partial x^{i_1}} \cdots \frac{\partial \bar{x}^{k_r}}{\partial x^{i_r}} \cdot \frac{\partial x^{j_1}}{\partial \bar{x}^{l_1}} \cdots \frac{\partial x^{j_s}}{\partial \bar{x}^{l_s}} \cdot T^{i_1 \cdots i_r}_{j_1 \cdots j_s}\]

Proof Sketch

The transformation law follows from the chain rule and the multilinearity of tensors. For a \((1,0)\) tensor (vector), we have \(v = v^i \partial_i = \bar{v}^j \bar{\partial}_j\). Since \(\bar{\partial}_j = \frac{\partial x^i}{\partial \bar{x}^j} \partial_i\), comparing coefficients gives \(\bar{v}^j = \frac{\partial \bar{x}^j}{\partial x^i} v^i\). For covectors, the transformation is inverse: \(\bar{\omega}_j = \frac{\partial x^i}{\partial \bar{x}^j} \omega_i\). The general case follows by taking tensor products and requiring multilinearity.

Notation Guide

  • \(T^{i}_{j}\) — tensor with contravariant index \(i\) and covariant index \(j\)
  • \(\partial_i\) or \(\frac{\partial}{\partial x^i}\) — coordinate basis vector
  • \(dx^i\) — coordinate basis covector
  • \(g_{ij}\) — metric tensor components
  • \(g^{ij}\) — inverse metric (satisfies \(g^{ik}g_{kj} = \delta^i_j\))
  • \(\nabla_i\) — covariant derivative
  • \(\Gamma^k_{ij}\) — Christoffel symbols of the second kind
  • \(R^l_{ijk}\) — Riemann curvature tensor

import numpy as np
import sympy as sp
from sympy import symbols, cos, sin, diff, simplify, Matrix

class TensorCalculus:
    """Basic tensor calculus operations using SymPy."""
    
    def __init__(self, coords):
        """Initialize with coordinate symbols."""
        self.coords = coords
        self.n = len(coords)
    
    def christoffel_symbols(self, metric):
        """Compute Christoffel symbols from metric tensor."""
        g = Matrix(metric)
        g_inv = g.inv()
        Gamma = np.zeros((self.n, self.n, self.n), dtype=object)
        
        for k in range(self.n):
            for i in range(self.n):
                for j in range(self.n):
                    term = 0
                    for l in range(self.n):
                        term += g_inv[k, l] * (
                            diff(g[l, j], self.coords[i]) +
                            diff(g[i, l], self.coords[j]) -
                            diff(g[i, j], self.coords[l])
                        )
                    Gamma[k, i, j] = simplify(term / 2)
        return Gamma
    
    def covariant_derivative(self, tensor, christoffel, contravariant=True):
        """Compute covariant derivative of a vector/covector field."""
        n = self.n
        result = np.zeros((n, n), dtype=object)
        
        for i in range(n):
            for j in range(n):
                # Partial derivative
                result[i, j] = diff(tensor[i], self.coords[j])
                # Connection terms
                for k in range(n):
                    if contravariant:
                        result[i, j] += christoffel[i, j, k] * tensor[k]
                    else:
                        result[i, j] -= christoffel[k, j, i] * tensor[k]
        return result

Algebraic K-Theory: Measuring Linear Structure

algebraic-k-theory

Motivation

Algebraic K-theory assigns to each ring a sequence of abelian groups that encode deep information about the ring's linear algebraic structure. K\(_0\) classifies projective modules (generalizing the Grothendieck group of vector bundles), K\(_1\) captures invertible matrices and determinants, and higher K-groups connect to number theory, algebraic geometry, and topology. The subject bridges algebra, geometry, and analysis, with applications ranging from the classification of manifolds to the study of zeta functions.

Definitions

  • Projective Module: A module \(P\) over a ring \(R\) such that there exists another module \(Q\) with \(P \oplus Q \cong R^n\) (free module) for some \(n\).
  • K\(_0(R)\): The Grothendieck group of finitely generated projective \(R\)-modules. Elements are formal differences \([P] - [Q]\) with \([P] = [Q]\) iff \(P \oplus R^n \cong Q \oplus R^n\) for some \(n\).
  • General Linear Group GL\(_n(R)\): The group of \(n \times n\) invertible matrices over \(R\).
  • Elementary Matrices E\(_n(R)\): Matrices obtained from the identity by adding a multiple of one row to another.
  • K\(_1(R)\): The abelianization of the infinite general linear group: K\(_1(R) = \text{GL}(R)/E(R) = \text{GL}(R)^{ab}\).

Theorem: Bass Stability for K\(_1\)

Theorem: Let \(R\) be a ring with stable rank \(sr(R) = d\). Then the natural map:

\[\text{GL}_n(R)/E_n(R) \to K_1(R)\]

is surjective for \(n \geq d\) and bijective for \(n \geq d + 1\).

In particular, for a Noetherian ring of Krull dimension \(d\), we have \(K_1(R) \cong \text{GL}_{d+2}(R)/E_{d+2}(R)\).

Proof Sketch

The proof relies on the stable rank condition, which ensures that sufficiently long unimodular rows can be completed to invertible matrices. For a unimodular row \((a_1, \ldots, a_n)\) with \(n > d\), there exist \(b_1, \ldots, b_{n-1}\) such that \((a_1 + b_1 a_n, \ldots, a_{n-1} + b_{n-1} a_n)\) is also unimodular. This allows reduction of matrices to smaller blocks via elementary operations. The key step shows that any element of GL\((R)\) can be stabilized to an elementary matrix plus a block in GL\(_{d+1}(R)\).

Notation Guide

  • K\(_n(R)\) — n-th algebraic K-group of ring \(R\)
  • \(\text{GL}_n(R)\) — general linear group of invertible \(n \times n\) matrices
  • \(\text{E}_n(R)\) — subgroup generated by elementary matrices
  • \(\text{SK}_1(R)\) — special Whitehead group (kernel of determinant map)
  • \(\tilde{K}_0(R)\) — reduced K\(_0\) (kernel of rank map)
  • \(P(R)\) — category of finitely generated projective modules
  • \(BGL(R)^+\) — Quillen's plus construction

p-adic Analysis: Analytic Number Theory in a Non-Archimedean World

p-adic-analysis

Motivation

The p-adic numbers, introduced by Hensel, provide an alternative completion of the rational numbers that has become indispensable in modern number theory. Unlike the real numbers, which arise from completing \(\mathbb{Q}\) with respect to the usual absolute value, p-adic numbers come from the p-adic absolute value where numbers are "close" when their difference is divisible by a high power of \(p\). This non-Archimedean perspective reveals deep arithmetic structures invisible over the reals.

Definitions

  • p-adic Valuation: For a prime \(p\) and nonzero integer \(n\), \(\nu_p(n)\) is the highest power of \(p\) dividing \(n\). For \(x = a/b \in \mathbb{Q}^\times\), \(\nu_p(x) = \nu_p(a) - \nu_p(b)\).
  • p-adic Absolute Value: \(|x|_p = p^{-\nu_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).
  • p-adic Integers \(\mathbb{Z}_p\): The unit ball \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\}\), equivalently the closure of \(\mathbb{Z}\) in \(\mathbb{Q}_p\).
  • Non-Archimedean Property: \(|x + y|_p \leq \max(|x|_p, |y|_p)\), with equality when \(|x|_p \neq |y|_p\).

Theorem: Hensel's Lemma

Theorem: Let \(f(x) \in \mathbb{Z}_p[x]\) be a polynomial. Suppose there exists \(\alpha_0 \in \mathbb{Z}_p\) such that:

\[|f(\alpha_0)|_p < |f'(\alpha_0)|_p^2\]

Then there exists a unique \(\alpha \in \mathbb{Z}_p\) such that \(f(\alpha) = 0\) and:

\[|\alpha - \alpha_0|_p \leq \frac{|f(\alpha_0)|_p}{|f'(\alpha_0)|_p}\]

Proof Sketch

The proof uses Newton's method adapted to the p-adic setting. Define the iteration:

\[\alpha_{n+1} = \alpha_n - \frac{f(\alpha_n)}{f'(\alpha_n)}\]

The condition ensures that \(|f'(\alpha_n)|_p = |f'(\alpha_0)|_p\) for all \(n\). One shows by induction that \(|f(\alpha_n)|_p \leq |f'(\alpha_0)|_p^2 \cdot |f(\alpha_0)/f'(\alpha_0)^2|_p^{2^n}\), which tends to 0. The non-Archimedean property ensures the sequence is Cauchy, and completeness gives the limit as a root.

Notation Guide

  • \(\mathbb{Q}_p\) — field of p-adic numbers
  • \(\mathbb{Z}_p\) — ring of p-adic integers
  • \(\nu_p(x)\) — p-adic valuation
  • \(|x|_p = p^{-\nu_p(x)}\) — p-adic absolute value
  • \(\mathbb{C}_p\) — completion of algebraic closure of \(\mathbb{Q}_p\)
  • \(a + p^n \mathbb{Z}_p\) — open ball (also closed in p-adic topology)
  • \(\mathcal{O}_{\mathbb{C}_p}\) — ring of integers in \(\mathbb{C}_p\)

from fractions import Fraction
import math

class PAdicNumber:
    """
    p-adic numbers represented by their p-adic expansion.
    Stores coefficients a_0, a_1, ..., a_{precision-1} where
    x = a_0 + a_1*p + a_2*p^2 + ...
    """
    
    def __init__(self, p, coeffs, precision=20):
        self.p = p
        self.precision = precision
        # Normalize coefficients to [0, p-1]
        self.coeffs = [c % p for c in coeffs[:precision]]
        self.coeffs += [0] * (precision - len(self.coeffs))
    
    @classmethod
    def from_rational(cls, p, frac, precision=20):
        """Convert a rational number to p-adic representation."""
        if frac == 0:
            return cls(p, [0], precision)
        
        # Handle negative
        negative = frac < 0
        frac = abs(frac)
        
        # Separate p-part
        num, den = frac.numerator, frac.denominator
        val_num = 0
        while num % p == 0 and num > 0:
            num //= p
            val_num += 1
        
        val_den = 0
        while den % p == 0:
            den //= p
            val_den += 1
        
        valuation = val_num - val_den
        
        # Compute expansion using Hensel lifting
        coeffs = []
        remainder = Fraction(num, den)
        
        for i in range(precision):
            if i < valuation:
                coeffs.append(0)
            else:
                # Find digit a such that remainder ≡ a (mod p)
                a = (remainder.numerator * pow(remainder.denominator, -1, p)) % p
                coeffs.append(a)
                remainder = (remainder - a) / p
        
        result = cls(p, coeffs, precision)
        if negative:
            result = -result
        return result
    
    def valuation(self):
        """p-adic valuation (order of vanishing at p)."""
        for i, c in enumerate(self.coeffs):
            if c != 0:
                return i
        return float('inf')
    
    def norm(self):
        """p-adic absolute value."""
        v = self.valuation()
        if v == float('inf'):
            return 0
        return self.p ** (-v)
    
    def __add__(self, other):
        """Add two p-adic numbers."""
        assert self.p == other.p
        coeffs = []
        carry = 0
        for i in range(self.precision):
            s = self.coeffs[i] + other.coeffs[i] + carry
            coeffs.append(s % self.p)
            carry = s // self.p
        return PAdicNumber(self.p, coeffs, self.precision)
    
    def __neg__(self):
        """Negate a p-adic number."""
        # -x = (p - a_0) + (p-1-a_1)*p + ... for nonzero x
        if all(c == 0 for c in self.coeffs):
            return self
        coeffs = []
        borrow = 1
        for i in range(self.precision):
            if i == 0:
                coeffs.append((self.p - self.coeffs[i]) % self.p)
            else:
                coeffs.append((self.p - 1 - self.coeffs[i]) % self.p)
        return PAdicNumber(self.p, coeffs, self.precision)
    
    def __sub__(self, other):
        return self + (-other)
    
    def __repr__(self):
        terms = []
        for i, c in enumerate(self.coeffs[:10]):
            if c != 0:
                if i == 0:
                    terms.append(str(c))
                elif i == 1:
                    terms.append(f"{c}·{self.p}")
                else:
                    terms.append(f"{c}·{self.p}^{i}")
        if not terms:
            return "0"
        return " + ".join(terms) + " + ..."

Random Matrix Theory: Universality in High Dimensions

random-matrix-theory

Motivation

Random matrix theory studies the statistical properties of matrices with random entries. Originating in nuclear physics (Wigner's work on heavy atoms), it has found applications in quantum chaos, number theory (distribution of zeros of the Riemann zeta function), wireless communications, machine learning, and finance. The remarkable phenomenon of universality—where microscopic statistics depend only on broad symmetry classes, not the specific distribution of entries—makes RMT a powerful tool for understanding complex systems.

Definitions

  • Gaussian Unitary Ensemble (GUE): Hermitian matrices with independent Gaussian entries: diagonal real, off-diagonal complex with independent real and imaginary parts.
  • Gaussian Orthogonal Ensemble (GOE): Real symmetric matrices with independent Gaussian entries.
  • Eigenvalue Density: The empirical spectral distribution \(\mu_N = \frac{1}{N} \sum_{i=1}^N \delta_{\lambda_i}\) where \(\lambda_i\) are eigenvalues.
  • Wigner Semicircle Law: The limiting distribution of eigenvalues for Wigner matrices.
  • Level Spacing Distribution: The distribution of gaps between consecutive eigenvalues.

Theorem: Wigner's Semicircle Law

Theorem: Let \(M_N\) be an \(N \times N\) Wigner matrix: symmetric with independent entries above the diagonal satisfying \(\mathbb{E}[M_{ij}] = 0\), \(\mathbb{E}[M_{ij}^2] = 1/N\) for \(i \neq j\), and \(\mathbb{E}[M_{ii}^2] = \sigma^2/N\). Then the empirical spectral distribution converges weakly almost surely to the semicircle distribution:

\[\mu_N \xrightarrow{w} \mu_{sc}\]

where \(\mu_{sc}\) has density:

\[\rho_{sc}(x) = \frac{1}{2\pi} \sqrt{4 - x^2} \cdot \mathbf{1}_{|x| \leq 2}\]

Proof Sketch

The proof uses the method of moments. One shows that the normalized moments converge:

\[\frac{1}{N} \text{Tr}(M_N^k) \to \int x^k \rho_{sc}(x) dx\]

For Wigner matrices, the leading contribution comes from non-crossing pairings (Catalan numbers). The key combinatorial fact is that \(\mathbb{E}[\text{Tr}(M_N^{2k})] \to C_k\) where \(C_k = \frac{1}{k+1}\binom{2k}{k}\) are Catalan numbers, which are exactly the moments of the semicircle distribution.

Notation Guide

  • \(\mu_N\) — empirical spectral distribution

  • GUE, GOE, GSE — Gaussian ensembles (unitary, orthogonal, symplectic)
  • \(s\) — level spacing variable (normalized gap)
  • \(p(s)\) — nearest-neighbor spacing distribution
  • \(\beta\) — Dyson index (1 for GOE, 2 for GUE, 4 for GSE)
  • \(S(x, y)\) — sine kernel (universal correlation kernel)

        M = (A + A.conj().T) / np.sqrt(2)
        return M
    else:
        raise ValueError(f"Unknown ensemble: {ensemble}")

Neural Network Theory: The Mathematics of Deep Learning

neural-network-theory

Motivation

Deep neural networks have revolutionized machine learning, yet their mathematical understanding remains incomplete. Key theoretical questions include: Why do overparameterized networks generalize well? What functions can neural networks approximate? How does gradient descent find good solutions in non-convex landscapes? The theory connects approximation theory, optimization, probability, and statistical learning theory.

Definitions

  • Neural Network: A function \(f_\theta: \mathbb{R}^d \to \mathbb{R}^k\) composed of layers: \(f_\theta(x) = W_L \sigma(W_{L-1} \sigma(\cdots \sigma(W_1 x + b_1) \cdots) + b_{L-1}) + b_L\).
  • Activation Function \(\sigma\): Nonlinear function applied element-wise. Common choices: ReLU \(\sigma(x) = \max(0, x)\), sigmoid, tanh.
  • Universal Approximation: A network architecture can approximate any continuous function on compact sets arbitrarily well.
  • Neural Tangent Kernel (NTK): In the infinite-width limit, gradient descent dynamics become linear with a deterministic kernel.
  • Rademacher Complexity: A measure of the richness of a function class, used to bound generalization error.

Theorem: Universal Approximation Theorem

Theorem (Cybenko, 1989): Let \(\sigma: \mathbb{R} \to \mathbb{R}\) be a continuous sigmoidal function (\(\sigma(t) \to 1\) as \(t \to +\infty\), \(\sigma(t) \to 0\) as \(t \to -\infty\)). Let \(K \subset \mathbb{R}^d\) be compact and \(f: K \to \mathbb{R}\) be continuous. Then for any \(\epsilon > 0\), there exist parameters \(\theta = \{w_i, a_i, b_i\}_{i=1}^n\) such that:

\[F(x) = \sum_{i=1}^n a_i \sigma(w_i^T x + b_i)\]

satisfies \(\sup_{x \in K} |f(x) - F(x)| < \epsilon\).

Proof Sketch

The proof uses the Hahn-Banach theorem and the Riesz representation theorem. Suppose the closure of span\(\{\sigma(w^T x + b)\}\) is not all of \(C(K)\). Then there exists a nonzero signed measure \(\mu\) such that \(\int \sigma(w^T x + b) d\mu(x) = 0\) for all \(w, b\). By analyticity arguments (extending to complex \(w\)), this implies the Fourier transform of \(\mu\) vanishes, so \(\mu = 0\), a contradiction.

Notation Guide

  • \(L\) — number of layers (depth)
  • \(W_l\) — weight matrix at layer \(l\)
  • \(b_l\) — bias vector at layer \(l\)
  • \(\sigma\) — activation function
  • \(\theta\) — all parameters (weights and biases)
  • \(\mathcal{L}(\theta)\) — loss function
  • NTK \((x, x')\) — neural tangent kernel
  • \(\Theta\) — NTK matrix

import numpy as np
import matplotlib.pyplot as plt

class NeuralNetwork:
    """Simple fully-connected neural network."""
    
    def __init__(self, layer_sizes, activation='relu'):
        """
        Initialize network.
        
        Parameters:
        -----------
        layer_sizes : list
            List of layer dimensions [input, hidden1, ..., hiddenL, output]
        activation : str
            'relu', 'sigmoid', or 'tanh'
        """
        self.layer_sizes = layer_sizes
        self.num_layers = len(layer_sizes) - 1
        
        # Activation functions
        if activation == 'relu':
            self.activation = lambda x: np.maximum(0, x)
            self.activation_deriv = lambda x: (x > 0).astype(float)
        elif activation == 'sigmoid':
            self.activation = lambda x: 1 / (1 + np.exp(-x))
            self.activation_deriv = lambda x: self.activation(x) * (1 - self.activation(x))
        elif activation == 'tanh':
            self.activation = lambda x: np.tanh(x)
            self.activation_deriv = lambda x: 1 - np.tanh(x)**2
        
        # Initialize weights (Xavier initialization)
        self.weights = []
        self.biases = []
        for i in range(self.num_layers):
            w = np.random.randn(layer_sizes[i], layer_sizes[i+1]) * np.sqrt(2 / layer_sizes[i])
            b = np.zeros(layer_sizes[i+1])
            self.weights.append(w)
            self.biases.append(b)
    
    def forward(self, X):
        """Forward pass, storing activations for backprop."""
        self.activations = [X]
        self.z_values = []
        
        a = X
        for i in range(self.num_layers):
            z = a @ self.weights[i] + self.biases[i]
            self.z_values.append(z)
            a = self.activation(z) if i < self.num_layers - 1 else z
            self.activations.append(a)
        
        return a
    
    def backward(self, X, y, learning_rate=0.01):
        """Backward pass (backpropagation)."""
        m = X.shape[0]
        
        # Output layer gradient
        delta = self.activations[-1] - y
        
        weight_grads = []
        bias_grads = []
        
        for i in range(self.num_layers - 1, -1, -1):
            # Gradients
            dw = (self.activations[i].T @ delta) / m
            db = np.mean(delta, axis=0)
            
            weight_grads.insert(0, dw)
            bias_grads.insert(0, db)
            
            # Backpropagate
            if i > 0:
                delta = (delta @ self.weights[i].T) * self.activation_deriv(self.z_values[i-1])
        
        # Update weights
        for i in range(self.num_layers):
            self.weights[i] -= learning_rate * weight_grads[i]
            self.biases[i] -= learning_rate * bias_grads[i]
        
        return weight_grads, bias_grads
    
    def train(self, X, y, epochs=1000, learning_rate=0.01, verbose=True):
        """Train the network."""
        losses = []
        for epoch in range(epochs):
            # Forward
            y_pred = self.forward(X)
            
            # MSE loss
            loss = np.mean((y_pred - y)**2)
            losses.append(loss)
            
            # Backward
            self.backward(X, y, learning_rate)
            
            if verbose and epoch % 100 == 0:
                print(f"Epoch {epoch}, Loss: {loss:.6f}")
        
        return losses

Mathematical Biology: Population Dynamics and Pattern Formation

mathematical-biology

Motivation

Mathematical biology applies mathematical modeling to understand biological systems, from molecular interactions to ecosystem dynamics. The field has produced some of the most elegant applications of differential equations, dynamical systems, and stochastic processes. Classic models like the Lotka-Volterra predator-prey equations and Turing's reaction-diffusion model of morphogenesis demonstrate how simple mathematical rules can generate complex biological phenomena.

Definitions

  • Logistic Growth: Model of population growth with carrying capacity: \(\frac{dN}{dt} = rN(1 - \frac{N}{K})\).
  • Lotka-Volterra Equations: Predator-prey model: \(\frac{dx}{dt} = \alpha x - \beta xy\), \(\frac{dy}{dt} = \delta xy - \gamma y\).
  • Reaction-Diffusion System: PDEs of the form \(\frac{\partial u}{\partial t} = D \nabla^2 u + f(u)\) where \(D\) is diffusion and \(f\) is reaction kinetics.
  • Turing Instability: Diffusion-driven instability where homogeneous steady states become unstable to spatial perturbations.
  • Basic Reproduction Number \(\mathcal{R}_0\): Expected number of secondary infections from one infected individual in a susceptible population.

Theorem: Turing Instability

Theorem: Consider the reaction-diffusion system on \(\mathbb{R}^n\):

\[\frac{\partial u}{\partial t} = D_u \nabla^2 u + f(u, v)\]

\[\frac{\partial v}{\partial t} = D_v \nabla^2 v + g(u, v)\]

Suppose \((u_0, v_0)\) is a homogeneous steady state (\(f(u_0, v_0) = g(u_0, v_0) = 0\)) that is stable to homogeneous perturbations (\(\text{tr}(J) < 0\), \(\det(J) > 0\) where \(J\) is the Jacobian). Then diffusion-driven instability (Turing instability) occurs if:

\[D_v f_u - D_u g_v > 2\sqrt{D_u D_v \det(J)}\]

where subscripts denote partial derivatives evaluated at \((u_0, v_0)\).

Proof Sketch

Linearize around the steady state: \(u = u_0 + \epsilon e^{\lambda t} e^{ikx}\), \(v = v_0 + \epsilon e^{\lambda t} e^{ikx}\). The growth rate \(\lambda\) satisfies:

\[\det\begin{pmatrix} f_u - D_u k^2 - \lambda & f_v \\ g_u & g_v - D_v k^2 - \lambda \end{pmatrix} = 0\]

For instability, we need \(\lambda(k) > 0\) for some \(k > 0\). The condition ensures the quadratic in \(\lambda\) has a positive root for intermediate wavenumbers. The key insight is that diffusion can destabilize when the activator diffuses slower than the inhibitor.

Notation Guide

  • \(N(t)\) — population size at time \(t\)
  • \(r\) — intrinsic growth rate
  • \(K\) — carrying capacity
  • \(x, y\) — prey and predator populations
  • \(D_u, D_v\) — diffusion coefficients
  • \(f, g\) — reaction kinetics
  • \(J\) — Jacobian matrix of reaction terms
  • \(\mathcal{R}_0\) — basic reproduction number
  • \(k\) — wavenumber of perturbation

    """
    Lotka-Volterra predator-prey model.
    dx/dt = αx - βxy (prey)
    dy/dt = δxy - γy (predator)
    """
    x, y = Z
    dxdt = alpha * x - beta * x * y

    """
    One step of reaction-diffusion (Gray-Scott model variant).
    """
    # Laplacian (5-point stencil)
    Lu = laplace(u, mode='wrap')
    Lv = laplace(v, mode='wrap')
    
    # Reaction terms (simplified Gray-Scott)
    F, k = 0.0545, 0.062  # Classic stripe pattern parameters

    reaction_v = u * v**2 - (F + k) * v
    
    # Update
    u_new = u + dt * (Du * Lu / dx**2 + reaction_u)
    v_new = v + dt * (Dv * Lv / dx**2 + reaction_v)
    
    return u_new, v_new

Surreal Numbers: A Universe of Numbers

surreal-numbers

Historical Context

Surreal numbers were discovered by John Horton Conway in the early 1970s while analyzing the game of Go. Donald Knuth popularized them in his 1974 novella "Surreal Numbers," and the theory was fully developed in Conway's "On Numbers and Games" (1976). The surreal numbers form the largest possible ordered field—they properly contain the real numbers, the ordinals, and infinitesimals, all within a unified construction.

Definitions

  • Surreal Number: A number is defined recursively as \(x = \{X_L | X_R\}\) where \(X_L\) and \(X_R\) are sets of previously constructed surreal numbers with no element of \(X_L\) greater than or equal to any element of \(X_R\).
  • Order: \(x \leq y\) iff no element of \(x\)'s right set is \(\leq y\) and \(x\) is \(\leq\) no element of \(y\)'s left set.
  • Addition: \(x + y = \{X_L + y, x + Y_L | X_R + y, x + Y_R\}\).
  • Multiplication: Defined recursively using the formula that ensures the distributive property.
  • Birthday: The ordinal at which a surreal number is created (0 for 0, finite ordinals for dyadic rationals, \(\omega\) for all reals and beyond).

Theorem: The Surreals Form a Real Closed Field

Theorem: The class of surreal numbers \(\mathbf{No}\) with the operations of addition and multiplication defined recursively forms a real closed field. Specifically:

\[(\mathbf{No}, +, \cdot, <)\]

is an ordered field that is real closed (every positive element has a square root, every odd-degree polynomial has a root). Moreover, \(\mathbf{No}\) contains an isomorphic copy of every ordered field, making it the largest possible ordered field.

Proof Sketch

The proof proceeds by transfinite induction on the birthday. For addition, one verifies that the recursive definition yields a well-defined operation that is associative, commutative, and has inverses. For multiplication, the formula is:

\[xy = \{X_L y + xY_L - X_L Y_L, X_R y + xY_R - X_R Y_R | X_L y + xY_R - X_L Y_R, X_R y + xY_L - X_R Y_L\}\]

One proves this is well-defined and satisfies field axioms. The real closed property follows from the ability to solve polynomial equations by constructing roots recursively.

Notation Guide

  • \(\mathbf{No}\) — the class of all surreal numbers
  • \(\{L | R\}\) — surreal number with left set \(L\) and right set \(R\)
  • \(\omega\) — first infinite surreal (\(\{0, 1, 2, \ldots | \}\))
  • \(\varepsilon = 1/\omega\) — first infinitesimal
  • \(\uparrow\) — up (positive infinitesimal game)
  • \(*\) — star (fuzzy number, \(\{0 | 0\}\))
  • \(\mathbf{On}\) — class of ordinal numbers (embedded in surreals)

from fractions import Fraction

class SurrealNumber:
    """
    Finite surreal numbers represented recursively.
    For infinite/infinitesimal, we use symbolic representation.
    """
    
    def __init__(self, left=None, right=None, value=None):
        """
        Create surreal number.
        For simple numbers, provide value; for complex, provide left/right sets.
        """
        if value is not None:
            # Construct from dyadic rational
            self.value = Fraction(value)
            self.left = None
            self.right = None
            self.is_simple = True
        else:
            self.left = left if left is not None else []
            self.right = right if right is not None else []
            self.is_simple = False
            self.value = None
    
    @classmethod
    def from_int(cls, n):
        """Create integer surreal."""

Tropical Geometry: The Geometry of the Minimum

tropical-geometry

Historical Context

Tropical geometry emerged in the late 1990s and early 2000s as a powerful tool connecting algebraic geometry to combinatorics. The name honors the Brazilian mathematician Imre Simon, who worked on max-plus algebra (pioneered in Brazil, hence "tropical"). The subject provides a piecewise-linear shadow of algebraic varieties, allowing complex algebraic problems to be studied using combinatorial methods. It has found applications in enumerative geometry, mirror symmetry, and optimization.

Definitions

  • Tropical Semiring \(\mathbb{T}\): \(\mathbb{R} \cup \{\infty\}\) with operations \(a \oplus b = \min(a, b)\) and \(a \odot b = a + b\).
  • Tropical Polynomial: A function of the form \(f(x) = \bigoplus_{i} (a_i \odot x^{\odot i}) = \min_i(a_i + i \cdot x)\).
  • Tropical Hypersurface: The set where a tropical polynomial is attained at least twice (the "corner locus").
  • Amoeba: The image of an algebraic variety under the log-absolute map \(\text{Log}: (\mathbb{C}^*)^n \to \mathbb{R}^n\).
  • Tropicalization: The limit of amoebas under rescaling, yielding a polyhedral complex.

Theorem: Fundamental Theorem of Tropical Geometry

Theorem: Let \(K\) be an algebraically closed field with non-Archimedean valuation \(\nu: K^* \to \mathbb{R}\). Let \(I \subseteq K[x_1, \ldots, x_n]\) be an ideal and \(X = V(I)\) its variety. The tropicalization of \(X\) is:

\[\text{Trop}(X) = \overline{\{(-\nu(x_1), \ldots, -\nu(x_n)) : x \in X\}}\]

Equivalently, \(\text{Trop}(X)\) is the intersection of all tropical hypersurfaces defined by polynomials in \(I\):

\[\text{Trop}(X) = \bigcap_{f \in I} \text{Trop}(V(f))\]

Proof Sketch

The equivalence of the two characterizations follows from the non-Archimedean Kapranov's theorem. For a single polynomial \(f = \sum c_\alpha x^\alpha\), the tropical polynomial is \(\text{trop}(f)(w) = \min_\alpha(\nu(c_\alpha) + \alpha \cdot w)\). The minimum is attained at least twice precisely when there exist two terms with the same minimal valuation, which corresponds to the valuation of a point on the hypersurface.

Notation Guide

  • \(\mathbb{T} = \mathbb{R} \cup \{\infty\}\) — tropical semiring
  • \(a \oplus b = \min(a, b)\) — tropical addition
  • \(a \odot b = a + b\) — tropical multiplication
  • \(x^{\odot n} = n \cdot x\) — tropical power
  • \(\text{Trop}(X)\) — tropicalization of variety \(X\)
  • \(\mathcal{A}_t\) — amoeba with parameter \(t\)
  • \(\nu\) — non-Archimedean valuation

Perfectoid Spaces: Revolutionizing p-adic Geometry

perfectoid-spaces

Historical Context

Perfectoid spaces were introduced by Peter Scholze in 2011 while he was a graduate student, revolutionizing p-adic geometry. Scholze's breakthrough provided a framework to compare characteristic p and characteristic 0 geometries, solving long-standing problems in algebraic geometry and number theory. The theory has found spectacular applications, including the resolution of the weight-monodromy conjecture and advances in the Langlands program. Scholze was awarded the Fields Medal in 2018 largely for this work.

Definitions

  • Perfectoid Field: A complete non-Archimedean field \(K\) of residue characteristic \(p\) such that the Frobenius map \(\Phi: \mathcal{O}_K/p \to \mathcal{O}_K/p\) is surjective and \(|p| < 1\).
  • Tilt: For a perfectoid field \(K\), its tilt \(K^\flat\) is a perfect field of characteristic \(p\) constructed from the inverse limit of Frobenius.
  • Perfectoid Algebra: A Banach \(K\)-algebra \(A\) such that the subring of power-bounded elements is open and bounded, and \(\Phi: A^\circ/p \to A^\circ/p\) is surjective.
  • Perfectoid Space: An adic space locally isomorphic to \(\text{Spa}(A, A^+)\) where \(A\) is perfectoid.
  • Pro-étale Site: A refinement of the étale topology that allows passage to perfectoid covers.

Theorem: The Almost Purity Theorem

Theorem (Scholze): Let \(K\) be a perfectoid field and \(A\) a perfectoid \(K\)-algebra. Let \(A \to B\) be a finite étale morphism. Then \(B\) is also perfectoid, and the morphism \(A^\circ \to B^\circ\) is almost finite étale (i.e., finite étale up to \(p^{1/p^\infty}\)-torsion).

Moreover, the categories of finite étale algebras over \(A\) and \(A^\circ[1/p]\) are equivalent, and tilting induces an equivalence between finite étale algebras over \(A\) and those over \(A^\flat\).

Proof Sketch

The proof uses the geometry of perfectoid spaces to reduce to the classical almost purity theorem in characteristic p (Faltings, Gabber-Ramero). The key insight is that perfectoid spaces allow one to "tilt" between characteristic 0 and characteristic p, where computations are often simpler. The pro-étale topology provides enough covers to trivialize p-adic local systems, and the almost mathematics (working modulo "almost zero" modules) handles the technical difficulties at the integral level.

Notation Guide

  • \(K\) — perfectoid field
  • \(K^\flat\) — tilt of \(K\) (characteristic p)
  • \(\mathcal{O}_K\) — ring of integers
  • \(A^\circ\) — power-bounded elements of \(A\)
  • \(A^+\) — open and integrally closed subring of \(A^\circ\)
  • \(\text{Spa}(A, A^+)\) — adic spectrum
  • \(\Phi\) — Frobenius map
  • \(\mathfrak{m}\) — maximal ideal of topologically nilpotent elements

Arithmetic Geometry: Where Number Theory Meets Algebraic Geometry

arithmetic-geometry

Historical Context

Arithmetic geometry emerged in the mid-20th century from the synthesis of algebraic geometry and number theory. The subject seeks to understand solutions of polynomial equations over number fields and finite fields. Key developments include Weil's conjectures (proved by Deligne), Faltings's theorem (Mordell conjecture), Wiles's proof of Fermat's Last Theorem, and the ongoing development of the Langlands program. Modern arithmetic geometry employs sophisticated tools from cohomology theory, automorphic forms, and anabelian geometry.

Definitions

  • Arithmetic Variety: A scheme \(X\) of finite type over \(\text{Spec}(\mathbb{Z})\) or a number field.
  • Rational Points: For a variety \(X\) over a field \(K\), the set \(X(K)\) of \(K\)-rational points.
  • Hasse Principle: A variety has a rational point over a global field if and only if it has points over all completions (local fields).
  • Height Function: A measure of the arithmetic complexity of points on a variety.
  • L-function: A generating function encoding arithmetic information about a variety, generalizing the Riemann zeta function.

Theorem: Faltings's Theorem (Mordell Conjecture)

Theorem: Let \(C\) be a smooth projective curve of genus \(g \geq 2\) defined over a number field \(K\). Then the set of \(K\)-rational points \(C(K)\) is finite.

Proof Sketch

Faltings's proof uses several deep ingredients:

1. Arakelov Theory: Intersection theory on arithmetic surfaces that incorporates archimedean places.

2. Semistable Reduction: After finite extension, the curve has good or semistable reduction at all primes.

3. Torelli Map: The map from the moduli space of curves to the moduli space of abelian varieties (via Jacobians).

4. Shafarevich Conjecture: Faltings proved that there are only finitely many isomorphism classes of abelian varieties over \(K\) with good reduction outside a fixed set of primes and with prescribed dimension.

The proof shows that rational points correspond to sections of the map \(\mathcal{C} \to \text{Spec}(\mathcal{O}_K)\), and these are controlled by the geometry of the associated abelian variety.

Notation Guide

  • \(X/K\) — variety over field \(K\)
  • \(X(K)\) — set of \(K\)-rational points
  • \(g\) — genus of a curve
  • \(J(C)\) — Jacobian variety of curve \(C\)
  • \(\text{Spec}(\mathcal{O}_K)\) — spectrum of ring of integers
  • \(h(P)\) — height of point \(P\)
  • \(L(X, s)\) — L-function of variety \(X\)
  • \(\text{Br}(X)\) — Brauer group of \(X\)

Bernhard Riemann: The Architect of Modern Geometry

riemann

Georg Friedrich Bernhard Riemann (1826–1866) stands as one of the most influential mathematicians in history, despite his short life of only 39 years. Born in Breselenz, a village in the Kingdom of Hanover, Riemann displayed exceptional mathematical talent from an early age. His education at the University of Göttingen under the guidance of Carl Friedrich Gauss laid the foundation for revolutionary contributions that would reshape mathematics.

Riemann's doctoral thesis of 1851 on complex function theory introduced what are now called Riemann surfaces, providing the geometric framework for multi-valued complex functions. This work unified analysis and topology, establishing that the global behavior of analytic functions is governed by the topology of their associated surfaces. The Riemann mapping theorem, proved in his thesis, remains a cornerstone of complex analysis.

His 1854 habilitation lecture "Über die Hypothesen, welche der Geometrie zu Grunde liegen" (On the Hypotheses Which Lie at the Foundations of Geometry) was a watershed moment. In this lecture, Riemann introduced the concept of an n-dimensional manifold with a metric defined by a quadratic differential form—the foundation of Riemannian geometry. He generalized Euclidean geometry to curved spaces, providing the mathematical language that Einstein would later use to formulate general relativity. The Riemann curvature tensor, Riemannian metric, and geodesics all emerged from this single lecture.

Riemann's 1859 paper "On the Number of Primes Less Than a Given Magnitude" introduced the Riemann zeta function and the famous Riemann Hypothesis. By analytically continuing the zeta function to the complex plane, he established the explicit formula connecting prime numbers to the zeros of the zeta function. The Riemann Hypothesis—that all non-trivial zeros lie on the critical line \(\text{Re}(s) = 1/2\)—remains one of the seven Millennium Prize Problems and the most important unsolved problem in number theory.

In analysis, Riemann developed the theory of integration that bears his name, defining the Riemann integral through upper and lower sums. His work on Fourier series, trigonometric series, and the concept of the Riemann integral provided rigorous foundations for calculus. The Riemann-Lebesgue lemma and Riemann localization principle remain fundamental results.

Riemann's influence extends to physics through his contributions to the theory of shock waves and his work on the propagation of sound. The Riemann problem in hyperbolic conservation laws and the Riemann invariants in gas dynamics bear his name. His geometric insights anticipated Einstein's general theory of relativity by sixty years.

Despite suffering from poor health throughout his life, Riemann produced a body of work that continues to drive mathematical research. The Riemann-Roch theorem, connecting topological and algebraic properties of curves, evolved into one of the most profound results in algebraic geometry. His ideas on manifolds, curvature, and topology laid the groundwork for modern differential geometry and topology.

Riemann died in Selasca, Italy, in 1866, while seeking relief from tuberculosis in the milder Mediterranean climate. His collected works, published posthumously by Heinrich Weber and Richard Dedekind, revealed additional insights that continued to influence mathematics for decades. Today, Riemann's name appears throughout mathematics: Riemann surfaces, Riemannian geometry, the Riemann hypothesis, Riemann integrals, Riemann sums, Riemann-Roch, Riemann-Hilbert problems, and countless other concepts attest to his enduring legacy as the architect of modern geometry.

IMO 2024 Problem 2 — Combinatorial Geometry

Problem: Let \(n \geq 2\) be an integer. Consider an \(n \times n\) grid of unit squares. Each square is colored either black or white. A path is a sequence of distinct squares such that consecutive squares share a side. The length of a path is the number of squares in it.

Determine the maximum possible value of \(k\) such that the following statement is always true: For any coloring of the grid, there exists a monochromatic path of length at least \(k\).

💡 Hint

Consider the grid as a graph and think about partitioning strategies. For the lower bound, use a pigeonhole principle argument on rows or columns. For the upper bound, construct a specific coloring that limits monochromatic paths. The answer involves \(n^2/2\) and careful analysis of how colors can be arranged to break long paths.

✅ Solution

Answer: The maximum \(k\) is \(\left\lceil \frac{n^2 + 1}{2} \right\rceil\).

Proof:

Lower bound: We show that any coloring contains a monochromatic path of length at least \(\lceil (n^2+1)/2 \rceil\).

Consider the grid graph where squares are vertices and adjacent squares are connected by edges. This graph is bipartite (like a chessboard coloring). By the pigeonhole principle, at least \(\lceil n^2/2 \rceil\) squares share the same color.

We claim that among any set of \(m\) squares in the grid, there exists a path of length at least \(\lceil (m+1)/2 \rceil\). This can be proved by induction or by considering a spanning tree of the induced subgraph.

A cleaner argument: Consider a maximal monochromatic path. If it has length less than \(\lceil (n^2+1)/2 \rceil\), then the remaining squares of that color must be "blocked" by the other color. But this creates a structure that can be analyzed to derive a contradiction or improved bound.

Upper bound: We construct a coloring where the longest monochromatic path has length exactly \(\lceil (n^2+1)/2 \rceil\).

Use a "stripe" coloring: Color columns alternately black and white. Specifically, color column \(j\) black if \(j\) is odd, white if \(j\) is even.

In this coloring, a monochromatic path can only stay within columns of the same color. If \(n\) is odd, there are \((n+1)/2\) black columns and \((n-1)/2\) white columns (or vice versa). The longest black path has length \(n \cdot (n+1)/2 = (n^2+n)/2\), and the longest white path has length \(n \cdot (n-1)/2 = (n^2-n)/2\).

For the specific bound \(\lceil (n^2+1)/2 \rceil\), a more refined construction uses a "diagonal" or "checkerboard with modifications" pattern that more evenly balances the maximum path lengths.

The exact optimal construction for the upper bound involves coloring the grid so that monochromatic components are as balanced as possible, achieving the bound \(\lceil (n^2+1)/2 \rceil\).

The Hopf Fibration: Visualizing a 4D Structure

The Hopf fibration is one of the most beautiful structures in mathematics—a way of decomposing the 3-sphere \(S^3\) into circles, each of which links every other circle exactly once. This visualization shows how the 3-sphere (which lives in 4D space) can be projected into 3D space, revealing the intricate linking of the fibers.

The Hopf map \(\pi: S^3 \to S^2\) sends each point \((z_1, z_2) \in \mathbb{C}^2\) with \(|z_1|^2 + |z_2|^2 = 1\) to the point on the Riemann sphere corresponding to \(z_1/z_2\). The fibers (preimages of points) are all circles, and any two distinct fibers are linked with linking number 1.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
from mpl_toolkits.mplot3d.art3d import Line3DCollection

def hopf_fibration(n_fibers=7, n_points=100):
    """
    Visualize the Hopf fibration by projecting S^3 to R^3.
    
    The Hopf map π: S^3 → S^2 can be visualized using stereographic
    projection from S^3 to R^3.
    """
    # Points on S^2 (fibers will be over these points)
    theta = np.linspace(0, np.pi, n_fibers)
    phi = np.linspace(0, 2*np.pi, n_fibers, endpoint=False)
    
    fibers = []
    colors = plt.cm.hsv(np.linspace(0, 1, n_fibers))
    
    for i, (th, ph) in enumerate(zip(theta, phi)):
        # Point on S^2
        x_s2 = np.sin(th) * np.cos(ph)
        y_s2 = np.sin(th) * np.sin(ph)
        z_s2 = np.cos(th)
        
        # Fiber over this point (circle in S^3)
        # Parametrize the fiber
        t = np.linspace(0, 2*np.pi, n_points)
        
        # The fiber consists of points (z1, z2) in C^2 with |z1|^2 + |z2|^2 = 1
        # such that z1/z2 corresponds to the point on S^2
        # Using the standard parametrization
        
        cos_th = np.cos(th/2)
        sin_th = np.sin(th/2)
        
        # Points on the fiber circle
        z1 = cos_th * np.exp(1j * (ph/2 + t))
        z2 = sin_th * np.exp(1j * (ph/2 - t))
        
        # Stereographic projection from S^3 to R^3
        # S^3 is |z1|^2 + |z2|^2 = 1 in C^2 ≅ R^4
        # Map (z1, z2) = (x1+iy1, x2+iy2) to R^3
        x1, y1 = z1.real, z1.imag
        x2, y2 = z2.real, z2.imag
        
        # Stereographic projection from (0, 0, 0, 1)
        # (x1, y1, x2, y2) → (x1, y1, x2) / (1 - y2) when y2 ≠ 1
        denom = 1 - y2 + 1e-10
        x_proj = x1 / denom
        y_proj = y1 / denom
        z_proj = x2 / denom
        
        fibers.append((x_proj, y_proj, z_proj, colors[i]))
    
    return fibers

def visualize_hopf():
    """Create 3D visualization of Hopf fibration."""
    fig = plt.figure(figsize=(14, 6))
    
    # 3D plot
    ax1 = fig.add_subplot(121, projection='3d')
    
    fibers = hopf_fibration(n_fibers=5, n_points=200)
    
    for x, y, z, color in fibers:
        ax1.plot(x, y, z, color=color, linewidth=2, alpha=0.8)
        # Add tube effect
