1. Representation Theory: Characters and the Orthogonality Relations

Motivation

Representation theory studies abstract algebraic structures by representing their elements as linear transformations of vector spaces. For finite groups, character theory — developed by Frobenius and Burnside at the turn of the 20th century — provides a powerful tool for analyzing group structure without explicitly constructing representations. The orthogonality relations for characters are fundamental results that enable the decomposition of representations into irreducibles.

Definitions

Let \(G\) be a finite group and \(\mathbb{C}\) the complex numbers.

  • Representation: A homomorphism \(\rho: G \to GL(V)\) where \(V\) is a complex vector space.
  • Character: The function \(\chi_\rho: G \to \mathbb{C}\) defined by \(\chi_\rho(g) = \text{tr}(\rho(g))\).
  • Class Function: A function \(f: G \to \mathbb{C}\) constant on conjugacy classes.
  • Irreducible Representation: A representation with no nontrivial invariant subspaces.
  • Inner Product on Class Functions: \(\langle f, h \rangle = \frac{1}{|G|} \sum_{g \in G} f(g) \overline{h(g)}\)

Theorem: Schur Orthogonality Relations

Theorem: Let \(\rho_1, \rho_2, \ldots, \rho_k\) be the irreducible representations of \(G\) with characters \(\chi_1, \chi_2, \ldots, \chi_k\).

First Orthogonality: For irreducible characters:

\[\langle \chi_i, \chi_j \rangle = \frac{1}{|G|} \sum_{g \in G} \chi_i(g) \overline{\chi_j(g)} = \begin{cases} 1 & i = j \\ 0 & i \neq j \end{cases}\]

Second Orthogonality: For conjugacy classes \(C_g\) and \(C_h\):

\[\sum_{i=1}^{k} \chi_i(g) \overline{\chi_i(h)} = \begin{cases} |C_G(g)| & C_g = C_h \\ 0 & \text{otherwise} \end{cases}\]

Proof Sketch

Step 1 (Schur's Lemma): If \(\rho: G \to GL(V)\) and \(\sigma: G \to GL(W)\) are irreducible representations and \(T: V \to W\) is a \(G\)-equivariant linear map, then either \(T = 0\) or \(T\) is an isomorphism. If \(\rho = \sigma\), then \(T = \lambda I\) for some scalar \(\lambda\).

Step 2: For any linear map \(L: V \to W\), define the averaging operator:

\[T = \frac{1}{|G|} \sum_{g \in G} \sigma(g)^{-1} L \rho(g)\]

This \(T\) is \(G\)-equivariant by construction.

Step 3: Apply Schur's Lemma. If \(\rho \not\cong \sigma\), then \(T = 0\). If \(\rho = \sigma\), then \(T = \frac{\text{tr}(L)}{\dim(V)} I\).

Step 4: Choose \(L\) to be the matrix with 1 in position \((j,i)\) and 0 elsewhere. Computing the trace relation yields the orthogonality formulas. ∎

Notation Guide

  • \(GL(V)\): General linear group of invertible linear operators on \(V\)
  • \(\chi_\rho\): Character of representation \(\rho\)
  • \(\text{tr}(A)\): Trace of matrix \(A\)
  • \(\langle f, h \rangle\): Inner product on class functions
  • \(C_G(g)\): Centralizer of \(g\) in \(G\)

import numpy as np
from itertools import product

class CharacterTheory:
    """Character theory computations for finite groups."""
    
    def __init__(self, group_elements, multiplication_table):
        """
        Initialize with group elements and Cayley table.
        
        Args:
            group_elements: List of group element labels
            multiplication_table: Dict mapping (g,h) to gh
        """
        self.elements = group_elements
        self.mult = multiplication_table
        self.n = len(group_elements)
        self.index = {g: i for i, g in enumerate(group_elements)}
    
    def conjugacy_classes(self):
        """Compute conjugacy classes of the group."""
        visited = set()
        classes = []
        
        for g in self.elements:
            if g in visited:
                continue
            
            # Conjugacy class of g: {hgh^{-1} : h in G}
            cl = set()
            for h in self.elements:
                hg = self.mult[(h, g)]
                hgh_inv = self.mult[(hg, self.inverse(h))]
                cl.add(hgh_inv)
            
            visited.update(cl)
            classes.append(sorted(cl))
        
        return classes
    
    def inverse(self, g):
        """Find inverse of g."""
        for h in self.elements:
            if self.mult[(g, h)] == self.elements[0]:  # identity
                return h
        return None
    
    def character_inner_product(self, chi1, chi2):
        """Compute inner product of two characters."""
        result = 0
        for g in self.elements:
            result += chi1[g] * np.conj(chi2[g])
        return result / self.n
    
    def is_irreducible(self, chi):
        """Check if character is irreducible using orthogonality."""
        return abs(self.character_inner_product(chi, chi) - 1.0) < 1e-10

2. Lie Algebras: The Killing Form and Cartan's Criteria

Motivation

Lie algebras, introduced by Sophus Lie in the late 19th century to study continuous symmetries, are vector spaces equipped with a bilinear Lie bracket operation. The structure theory of finite-dimensional complex semisimple Lie algebras, developed by Élie Cartan and Wilhelm Killing, provides a complete classification using root systems. The Killing form, a symmetric bilinear form defined via the adjoint representation, is the key tool for detecting semisimplicity.

Definitions

Let \(\mathfrak{g}\) be a finite-dimensional Lie algebra over \(\mathbb{C}\).

  • Lie Bracket: A bilinear map \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) satisfying antisymmetry and the Jacobi identity.
  • Adjoint Representation: \(\text{ad}_X(Y) = [X, Y]\) for \(X, Y \in \mathfrak{g}\).
  • Killing Form: \(\kappa(X, Y) = \text{tr}(\text{ad}_X \circ \text{ad}_Y)\).
  • Semisimple: A Lie algebra with no non-zero abelian ideals.
  • Nilpotent: A Lie algebra where the lower central series terminates.

Theorem: Cartan's Criteria

Theorem (Cartan's Semisimplicity Criterion): A finite-dimensional Lie algebra \(\mathfrak{g}\) over a field of characteristic zero is semisimple if and only if its Killing form is non-degenerate.

Theorem (Cartan's Solvability Criterion): A Lie algebra \(\mathfrak{g}\) is solvable if and only if \(\kappa([X, Y], Z) = 0\) for all \(X, Y, Z \in \mathfrak{g}\) (equivalently, \(\kappa\) vanishes on \([\mathfrak{g}, \mathfrak{g}]\)).

Proof Sketch (Semisimplicity)

(\(\Rightarrow\)) If \(\mathfrak{g}\) is semisimple, then \(\kappa\) is non-degenerate:

Let \(\mathfrak{r} = \{X \in \mathfrak{g} : \kappa(X, Y) = 0 \text{ for all } Y\}\) be the radical of \(\kappa\).

Step 1: Show \(\mathfrak{r}\) is an ideal. For \(R \in \mathfrak{r}\) and \(X \in \mathfrak{g}\):

\[\kappa([R, X], Y) = \kappa(R, [X, Y]) = 0\]

by associativity of the Killing form. Thus \([R, X] \in \mathfrak{r}\).

Step 2: By Cartan's solvability criterion, \(\mathfrak{r}\) is solvable.

Step 3: Since \(\mathfrak{g}\) is semisimple, it has no non-zero solvable ideals. Thus \(\mathfrak{r} = 0\).

(\(\Leftarrow\)) If \(\kappa\) is non-degenerate, then \(\mathfrak{g}\) is semisimple:

Step 4: Let \(\mathfrak{a}\) be an abelian ideal. For \(A \in \mathfrak{a}\) and \(X \in \mathfrak{g}\):

\[(\text{ad}_A \circ \text{ad}_X)^2(\mathfrak{g}) \subseteq \text{ad}_A(\mathfrak{a}) = 0\]

Step 5: Thus \(\text{ad}_A \circ \text{ad}_X\) is nilpotent, so \(\kappa(A, X) = \text{tr}(\text{ad}_A \circ \text{ad}_X) = 0\).

Step 6: By non-degeneracy, \(A = 0\). Hence \(\mathfrak{g}\) has no non-zero abelian ideals. ∎

Notation Guide

  • \(\mathfrak{g}\): Lie algebra (Fraktur g)
  • \(\text{ad}_X\): Adjoint action of \(X\)
  • \(\kappa(X, Y)\): Killing form
  • \([\mathfrak{g}, \mathfrak{g}]\): Derived algebra (span of all brackets)
  • \(\mathfrak{sl}_n\): Special linear Lie algebra (traceless matrices)

import numpy as np

class LieAlgebra:
    """Finite-dimensional Lie algebra with structure constants."""
    
    def __init__(self, basis, structure_constants):
        """
        Initialize Lie algebra.
        
        Args:
            basis: List of basis element labels
            structure_constants: Dict ((i,j), k) -> c_{ij}^k
        """
        self.basis = basis
        self.n = len(basis)
        self.c = structure_constants
    
    def ad_matrix(self, i):
        """Compute matrix of ad_{e_i} in the given basis."""
        # ad_{e_i}(e_j) = sum_k c_{ij}^k e_k
        mat = np.zeros((self.n, self.n))
        for j in range(self.n):
            for k in range(self.n):
                mat[k, j] = self.c.get(((i, j), k), 0)
        return mat
    
    def killing_form(self, i, j):
        """Compute Killing form κ(e_i, e_j) = tr(ad_{e_i} ∘ ad_{e_j})."""
        ad_i = self.ad_matrix(i)
        ad_j = self.ad_matrix(j)
        return np.trace(ad_i @ ad_j)
    
    def killing_matrix(self):
        """Return full Killing form matrix."""
        K = np.zeros((self.n, self.n))
        for i in range(self.n):
            for j in range(self.n):
                K[i, j] = self.killing_form(i, j)
        return K
    
    def is_semisimple(self):
        """Check semisimplicity via Cartan's criterion."""
        K = self.killing_matrix()
        det = np.linalg.det(K)
        return abs(det) > 1e-10  # Non-degenerate

3. Category Theory: Limits and Universal Properties

Motivation

Category theory, founded by Samuel Eilenberg and Saunders Mac Lane in the 1940s, provides a unified language for mathematics. The concept of a limit (and its dual, colimit) captures universal constructions across diverse mathematical contexts: products, intersections, inverse limits, and more. Understanding limits reveals deep structural similarities between algebra, topology, and logic.

Definitions

Let \(\mathcal{C}\) be a category and \(D: \mathcal{J} \to \mathcal{C}\) a diagram (functor from an index category).

  • Cone: An object \(C\) with morphisms \(\psi_j: C \to D(j)\) such that for all \(f: j \to k\) in \(\mathcal{J}\): \(D(f) \circ \psi_j = \psi_k\).
  • Limit: A universal cone \((L, \phi_j)\) such that for any cone \((C, \psi_j)\), there exists a unique \(u: C \to L\) with \(\phi_j \circ u = \psi_j\) for all \(j\).
  • Product: Limit over a discrete category (no non-identity morphisms).
  • Pullback: Limit over the category \(\bullet \to \bullet \leftarrow \bullet\).

Theorem: Limits are Unique up to Isomorphism

Theorem: If \((L, \phi_j)\) and \((L', \phi'_j)\) are both limits of the same diagram \(D: \mathcal{J} \to \mathcal{C}\), then there exists a unique isomorphism \(f: L \to L'\) such that \(\phi'_j \circ f = \phi_j\) for all \(j\).

Proof

Step 1: Since \((L, \phi_j)\) is a limit and \((L', \phi'_j)\) is a cone, by universality there exists a unique \(f: L' \to L\) with \(\phi_j \circ f = \phi'_j\).

Step 2: Similarly, there exists a unique \(g: L \to L'\) with \(\phi'_j \circ g = \phi_j\).

Step 3: Then \(\phi_j \circ (f \circ g) = \phi'_j \circ g = \phi_j = \phi_j \circ \text{id}_L\).

Step 4: By uniqueness in the universal property, \(f \circ g = \text{id}_L\).

Step 5: Similarly, \(g \circ f = \text{id}_{L'}\). Thus \(f\) is an isomorphism. ∎

Notation Guide

  • \(\mathcal{C}, \mathcal{D}, \mathcal{J}\): Categories (calligraphic letters)
  • \(\lim D\) or \(\lim_{\leftarrow} D_j\): Limit of diagram \(D\)
  • \(\prod_{j} D_j\): Product
  • \(D(f)\): Action of functor \(D\) on morphism \(f\)
  • \(\text{id}_C\): Identity morphism on object \(C\)

from dataclasses import dataclass
from typing import Dict, List, Callable, Any

@dataclass
class Object:
    """Object in a category (represented by a label and data)."""
    label: str
    data: Any = None

@dataclass  
class Morphism:
    """Morphism between objects."""
    source: str
    target: str
    func: Callable[[Any], Any]
    label: str = ""

class Category:
    """Simple category implementation."""
    
    def __init__(self, name):
        self.name = name
        self.objects: Dict[str, Object] = {}
        self.morphisms: Dict[str, Morphism] = {}
    
    def add_object(self, obj: Object):
        self.objects[obj.label] = obj
    
    def add_morphism(self, morph: Morphism):
        key = f"{morph.source}->{morph.target}:{morph.label}"
        self.morphisms[key] = morph

class SetCategory(Category):
    """Category of sets (simplified)."""
    
    def __init__(self):
        super().__init__("Set")
    
    def product(self, objects: List[Object]) -> Object:
        """
        Compute categorical product (Cartesian product in Set).
        
        Returns the product object and projection morphisms.
        """
        # Product is the Cartesian product
        product_data = tuple(obj.data for obj in objects)
        product_obj = Object(
            label=f"Prod({','.join(obj.label for obj in objects)})",
            data=product_data
        )
        
        # Projection morphisms
        projections = []
        for i, obj in enumerate(objects):
            def make_proj(idx):
                return lambda x: x[idx]
            
            proj = Morphism(
                source=product_obj.label,
                target=obj.label,
                func=make_proj(i),
                label=f"π_{i}"
            )
            projections.append(proj)
        
        return product_obj, projections
    
    def pullback(self, f: Morphism, g: Morphism) -> Object:
        """
        Compute pullback of f: A -> C and g: B -> C.
        
        Pullback = {(a,b) ∈ A × B : f(a) = g(b)}
        """
        A = self.objects[f.source]
        B = self.objects[g.source]
        C = self.objects[f.target]
        
        # Compute pullback set
        pullback_data = []
        for a in A.data if isinstance(A.data, (list, set, range)) else [A.data]:
            for b in B.data if isinstance(B.data, (list, set, range)) else [B.data]:
                if f.func(a) == g.func(b):
                    pullback_data.append((a, b))
        
        pullback_obj = Object(
            label=f"Pb({f.label},{g.label})",
            data=pullback_data
        )
        
        return pullback_obj

1. Convex Optimization: Duality Theory

Real-World Motivation

Convex optimization underlies modern machine learning, signal processing, control systems, and economics. Duality theory provides powerful tools for analyzing and solving optimization problems. The dual problem often has simpler structure, and strong duality guarantees that solving the dual yields the primal optimum — crucial for algorithms like support vector machines and portfolio optimization.

Definitions

Consider the primal convex optimization problem:

\[\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \leq 0, \quad i = 1, \ldots, m \\ & h_j(x) = 0, \quad j = 1, \ldots, p \end{aligned}\]

  • Lagrangian: \(L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)\)
  • Lagrange Dual Function: \(g(\lambda, \nu) = \inf_x L(x, \lambda, \nu)\)
  • Dual Problem: \(\max_{\lambda \geq 0, \nu} g(\lambda, \nu)\)
  • Strong Duality: Primal and dual optimal values are equal.
  • Slater's Condition: Strict feasibility implies strong duality for convex problems.

Theorem: Strong Duality under Slater's Condition

Theorem: Consider a convex optimization problem where \(f_0, f_1, \ldots, f_m\) are convex and \(h_1, \ldots, h_p\) are affine. If there exists a strictly feasible point (Slater's condition):

\[f_i(x) < 0 \text{ for } i = 1, \ldots, m, \quad h_j(x) = 0 \text{ for } j = 1, \ldots, p\]

then strong duality holds: \(p^* = d^*\), where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Proof Sketch

Step 1: Define the set \(\mathcal{A} = \{(u, v, t) : \exists x \text{ with } f_i(x) \leq u_i, h_j(x) = v_j, f_0(x) \leq t\}\).

Step 2: Show \(\mathcal{A}\) is convex (using convexity of \(f_i\) and affinity of \(h_j\)).

Step 3: The point \((0, 0, p^*)\) is on the boundary of \(\mathcal{A}\).

Step 4: By the separating hyperplane theorem, there exists \((\tilde{\lambda}, \tilde{\nu}, \mu) \neq 0\) such that:

\[\tilde{\lambda}^T u + \tilde{\nu}^T v + \mu t \geq \mu p^* \text{ for all } (u, v, t) \in \mathcal{A}\]

Step 5: Show \(\tilde{\lambda} \geq 0\) and \(\mu \geq 0\) (otherwise the LHS can be made arbitrarily negative).

Step 6: Under Slater's condition, \(\mu > 0\). Define \(\lambda = \tilde{\lambda}/\mu\), \(\nu = \tilde{\nu}/\mu\).

Step 7: The inequality becomes: \(\lambda^T u + \nu^T v + t \geq p^*\). Setting \(u_i = f_i(x)\), \(v_j = h_j(x)\), \(t = f_0(x)\):

\[L(x, \lambda, \nu) \geq p^*\]

Step 8: Thus \(g(\lambda, \nu) = \inf_x L(x, \lambda, \nu) \geq p^*\). Since weak duality gives \(g(\lambda, \nu) \leq p^*\), we have equality. ∎

Notation Guide

  • \(f_0\): Objective function
  • \(f_i\): Inequality constraint functions
  • \(h_j\): Equality constraint functions
  • \(\lambda_i\): Lagrange multipliers for inequalities (\(\lambda \geq 0\))
  • \(\nu_j\): Lagrange multipliers for equalities (unconstrained)
  • \(p^*, d^*\): Primal and dual optimal values

2. Machine Learning: PAC Learning Theory

Real-World Motivation

Probably Approximately Correct (PAC) learning, introduced by Leslie Valiant in 1984, provides the theoretical foundation for understanding when machine learning is possible. It formalizes the notion of "learning from examples" and gives precise bounds on the number of samples needed to learn a concept with high confidence. This framework explains why neural networks generalize and guides the design of learning algorithms.

Definitions

  • Concept Class \(\mathcal{C}\): A set of functions \(c: \mathcal{X} \to \{0, 1\}\).
  • Hypothesis Class \(\mathcal{H}\): The set of functions the learner can output.
  • Generalization Error: \(R(h) = \mathbb{P}_{x \sim \mathcal{D}}[h(x) \neq c(x)]\)
  • Empirical Risk: \(\hat{R}_S(h) = \frac{1}{m} \sum_{i=1}^m \mathbf{1}_{h(x_i) \neq c(x_i)}\)
  • PAC Learnable: \(\mathcal{C}\) is PAC learnable by \(\mathcal{H}\) if there exists algorithm \(A\) such that for all \(\epsilon, \delta > 0\), with probability \(\geq 1 - \delta\), \(R(A(S)) \leq \epsilon\) when \(m \geq m_{\mathcal{H}}(\epsilon, \delta)\).

Theorem: Finite Hypothesis Classes are PAC Learnable

Theorem: Let \(\mathcal{H}\) be a finite hypothesis class. Then \(\mathcal{H}\) is PAC learnable with sample complexity:

\[m_{\mathcal{H}}(\epsilon, \delta) \leq \left\lceil \frac{\log(|\mathcal{H}|/\delta)}{\epsilon} \right\rceil\]

Moreover, the ERM (Empirical Risk Minimization) algorithm that outputs \(\hat{h} = \arg\min_{h \in \mathcal{H}} \hat{R}_S(h)\) is a successful PAC learner.

Proof Sketch

Step 1: Define "bad" hypotheses: \(\mathcal{H}_B = \{h \in \mathcal{H} : R(h) > \epsilon\}\).

Step 2: For any bad hypothesis \(h \in \mathcal{H}_B\):

\[\mathbb{P}[\hat{R}_S(h) = 0] = (1 - R(h))^m \leq (1 - \epsilon)^m \leq e^{-\epsilon m}\]

Step 3: By union bound:

\[\mathbb{P}[\exists h \in \mathcal{H}_B : \hat{R}_S(h) = 0] \leq |\mathcal{H}_B| \cdot e^{-\epsilon m} \leq |\mathcal{H}| \cdot e^{-\epsilon m}\]

Step 4: We want this probability \(\leq \delta\). Solving:

\[|\mathcal{H}| \cdot e^{-\epsilon m} \leq \delta\]

\[m \geq \frac{\log(|\mathcal{H}|/\delta)}{\epsilon}\]

Step 5: With this many samples, with probability \(\geq 1 - \delta\), ERM outputs a hypothesis with \(R(\hat{h}) \leq \epsilon\). ∎

Notation Guide

  • \(\mathcal{X}\): Input space (instance space)
  • \(\mathcal{D}\): Distribution over \(\mathcal{X}\)
  • \(\epsilon\): Accuracy parameter
  • \(\delta\): Confidence parameter
  • \(m\): Sample size
  • ERM: Empirical Risk Minimization

3. Fluid Dynamics: The Navier-Stokes Equations

Real-World Motivation

The Navier-Stokes equations describe the motion of viscous fluids and are fundamental to weather prediction, aircraft design, blood flow modeling, and climate science. Despite their practical importance, fundamental questions about their solutions remain open — the existence and smoothness of solutions in three dimensions is one of the seven Millennium Prize Problems, with a $1 million reward for resolution.

Definitions

For an incompressible fluid with velocity field \(\mathbf{u}(\mathbf{x}, t)\) and pressure \(p(\mathbf{x}, t)\):

  • Incompressibility: \(\nabla \cdot \mathbf{u} = 0\)
  • Material Derivative: \(\frac{D\mathbf{u}}{Dt} = \frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u}\)
  • Reynolds Number: \(Re = \frac{\rho U L}{\mu}\) (ratio of inertial to viscous forces)
  • Vorticity: \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\)

Theorem: Energy Equality for Navier-Stokes

Theorem: Let \(\mathbf{u}\) be a smooth solution to the incompressible Navier-Stokes equations on \(\mathbb{R}^3\) with sufficiently fast decay at infinity:

\[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\nabla p + \nu \Delta \mathbf{u}, \quad \nabla \cdot \mathbf{u} = 0\]

Then the kinetic energy \(E(t) = \frac{1}{2} \int_{\mathbb{R}^3} |\mathbf{u}|^2 \, d\mathbf{x}\) satisfies:

\[\frac{dE}{dt} = -\nu \int_{\mathbb{R}^3} |\nabla \mathbf{u}|^2 \, d\mathbf{x}\]

In particular, \(E(t) \leq E(0)\) for all \(t > 0\) (energy dissipation).

Proof

Step 1: Multiply the Navier-Stokes equation by \(\mathbf{u}\):

\[\mathbf{u} \cdot \frac{\partial \mathbf{u}}{\partial t} + \mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] = -\mathbf{u} \cdot \nabla p + \nu \mathbf{u} \cdot \Delta \mathbf{u}\]

Step 2: Note that \(\mathbf{u} \cdot \frac{\partial \mathbf{u}}{\partial t} = \frac{1}{2} \frac{\partial}{\partial t}|\mathbf{u}|^2\).

Step 3: For the nonlinear term, using incompressibility:

\[\mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] = \sum_{i,j} u_i u_j \frac{\partial u_i}{\partial x_j} = \frac{1}{2} \sum_j u_j \frac{\partial}{\partial x_j}|\mathbf{u}|^2 = \frac{1}{2} (\mathbf{u} \cdot \nabla)|\mathbf{u}|^2\]

Step 4: The pressure term vanishes upon integration:

\[\int \mathbf{u} \cdot \nabla p = -\int p (\nabla \cdot \mathbf{u}) = 0\]

Step 5: For the viscous term:

\[\int \mathbf{u} \cdot \Delta \mathbf{u} = -\int |\nabla \mathbf{u}|^2\]

(integration by parts, assuming boundary terms vanish).

Step 6: Combining and integrating over space:

\[\frac{d}{dt} \int \frac{1}{2}|\mathbf{u}|^2 = -\nu \int |\nabla \mathbf{u}|^2\]

since the nonlinear term integrates to zero by incompressibility. ∎

Notation Guide

  • \(\mathbf{u}\): Velocity vector field
  • \(p\): Pressure scalar field
  • \(\nu\): Kinematic viscosity
  • \(\rho\): Fluid density
  • \(\nabla \cdot\): Divergence operator
  • \(\Delta\): Laplacian operator
  • \(\nabla \times\): Curl operator

    dv_dy = np.gradient(v, dy, axis=0)
    dp_dx = np.gradient(p, dx, axis=1)

    lu = laplace(u) / (dx * dy)

    u_new = u_star - dt * dp_dx
    v_new = v_star - dt * dp_dy

1. Knot Theory: The Jones Polynomial

Historical Context

In 1984, Vaughan Jones discovered a revolutionary new knot invariant while studying operator algebras — a stunning example of cross-fertilization between seemingly unrelated areas of mathematics. The Jones polynomial, and its generalization to the HOMFLY polynomial, transformed knot theory and led to Jones receiving the Fields Medal in 1990. The discovery also sparked interest in topological quantum field theory and quantum computing.

Definitions

  • Knot: An embedding of \(S^1\) into \(S^3\) (or \(\mathbb{R}^3\)).
  • Knot Diagram: A planar projection with over/under crossings indicated.
  • Reidemeister Moves: Three local moves that generate all ambient isotopies of knots.
  • Kauffman Bracket: A state-sum invariant of framed links related to the Jones polynomial.

Theorem: Existence and Uniqueness of the Jones Polynomial

Theorem: There exists a unique invariant \(V_L(t)\) of oriented links satisfying:

(1) Normalization: \(V_{\text{unknot}}(t) = 1\)

(2) Skein Relation: For three links differing only at one crossing:

\[t^{-1} V_{L_+}(t) - t V_{L_-}(t) = (t^{1/2} - t^{-1/2}) V_{L_0}(t)\]

where \(L_+\), \(L_-\), and \(L_0\) have positive, negative, and smoothed crossings respectively.

Proof Sketch (via Kauffman Bracket)

Step 1: Define the Kauffman bracket \(\langle D \rangle\) for unoriented diagrams by:

\[\langle \bigcirc \rangle = 1, \quad \langle D \cup \bigcirc \rangle = (-A^2 - A^{-2}) \langle D \rangle\]

\[\langle \ crossing \rangle = A \langle \ 0-smoothing \rangle + A^{-1} \langle \ \infty-smoothing \rangle\]

Step 2: Show the Kauffman bracket is invariant under Reidemeister moves II and III, and transforms predictably under move I.

Step 3: Define the writhe \(w(D)\) as the sum of signs of all crossings.

Step 4: The normalized bracket \(X(D) = (-A^3)^{-w(D)} \langle D \rangle\) is a knot invariant.

Step 5: Substitute \(A = t^{-1/4}\) to obtain the Jones polynomial \(V_L(t) = X(D)|_{A = t^{-1/4}}\). ∎

Notation Guide

  • \(V_L(t)\): Jones polynomial of link \(L\)
  • \(L_+, L_-, L_0\): Link diagrams differing at one crossing
  • \(\langle D \rangle\): Kauffman bracket
  • \(w(D)\): Writhe of diagram \(D\)
  • \(\bigcirc\): Unknot

2. Topological Quantum Field Theory

Historical Context

Topological Quantum Field Theory (TQFT) emerged from the work of Edward Witten in the late 1980s, who showed that the Jones polynomial could be understood through quantum field theory. This connection, for which Witten received the Fields Medal in 1990, revealed deep relationships between topology, quantum physics, and representation theory. TQFTs have since become important in condensed matter physics, quantum computing, and the study of manifold invariants.

Definitions

  • n-Dimensional TQFT: A symmetric monoidal functor \(Z: \text{Bord}_n \to \text{Vect}_{\mathbb{C}}\).
  • Bordism Category: Objects are closed \((n-1)\)-manifolds, morphisms are n-manifolds with boundary.
  • Monoidal Structure: Disjoint union on bordisms, tensor product on vector spaces.
  • Atiyah Axioms: The standard axioms defining a TQFT (functoriality, monoidality, etc.).

Theorem: 2D TQFTs are Commutative Frobenius Algebras

Theorem: There is an equivalence of categories between 2-dimensional TQFTs and commutative Frobenius algebras over \(\mathbb{C}\).

A Frobenius algebra is a finite-dimensional algebra with multiplication \(\mu: A \otimes A \to A\) and unit \(\eta: \mathbb{C} \to A\), together with a comultiplication \(\Delta: A \to A \otimes A\) and counit \(\varepsilon: A \to \mathbb{C}\), satisfying the Frobenius condition:

\[(\mu \otimes \text{id}) \circ (\text{id} \otimes \Delta) = \Delta \circ \mu = (\text{id} \otimes \mu) \circ (\Delta \otimes \text{id})\]

Proof Sketch

Step 1: In a 2D TQFT, the circle \(S^1\) maps to a vector space \(A = Z(S^1)\).

Step 2: The pair of pants cobordism gives multiplication \(\mu: A \otimes A \to A\) and comultiplication \(\Delta: A \to A \otimes A\).

Step 3: The cap gives the unit \(\eta: \mathbb{C} \to A\) and the cup gives the counit \(\varepsilon: A \to \mathbb{C}\).

Step 4: Topological invariance implies associativity, coassociativity, and the Frobenius condition.

Step 5: Conversely, any commutative Frobenius algebra defines a TQFT by cutting surfaces into pairs of pants, caps, and cups. ∎

Notation Guide

  • \(\text{Bord}_n\): Category of n-dimensional bordisms
  • \(Z\): TQFT functor
  • \(Z(M)\): Vector space assigned to manifold \(M\)
  • \(Z(W)\): Linear map assigned to cobordism \(W\)
  • \(\mu, \eta\): Multiplication and unit
  • \(\Delta, \varepsilon\): Comultiplication and counit

import numpy as np

class FrobeniusAlgebra:
    """
    Commutative Frobenius algebra (corresponds to 2D TQFT).
    
    For simplicity, we use matrix representations.
    """
    
    def __init__(self, dim, multiplication_matrix, metric):
        """
        Args:
            dim: Dimension of the algebra
            multiplication_matrix: m[i,j,k] = coefficient of e_k in e_i * e_j
            metric: Non-degenerate bilinear form (for Frobenius structure)
        """
        self.dim = dim
        self.m = multiplication_matrix  # Shape (dim, dim, dim)
        self.metric = metric  # Shape (dim, dim)
        self.inv_metric = np.linalg.inv(metric)
    
    def multiply(self, a, b):
        """Multiply two elements a, b (as coefficient vectors)."""
        result = np.zeros(self.dim)
        for k in range(self.dim):
            for i in range(self.dim):
                for j in range(self.dim):
                    result[k] += self.m[i, j, k] * a[i] * b[j]
        return result
    
    def comultiply(self, a):
        """Comultiplication using metric."""
        result = np.zeros((self.dim, self.dim))
        for i in range(self.dim):
            for j in range(self.dim):
                for k in range(self.dim):
                    for l in range(self.dim):
                        result[i, j] += self.m[i, j, k] * self.inv_metric[k, l] * a[l]
        return result
    
    def trace(self, a):
        """Counit / trace map."""
        return np.sum(a)

3. The Riemann Hypothesis: A Millennium Problem

Historical Context

Bernhard Riemann proposed his famous hypothesis in 1859 as part of his groundbreaking paper on the distribution of prime numbers. The conjecture states that all non-trivial zeros of the Riemann zeta function lie on the critical line \(\text{Re}(s) = \frac{1}{2}\). Despite over 160 years of effort by the greatest mathematicians, it remains unproven. Its resolution would have profound implications for number theory, and it is one of the seven Clay Mathematics Institute Millennium Prize Problems.

Definitions

  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s}\) for \(\text{Re}(s) > 1\), analytically continued to \(\mathbb{C} \setminus \{1\}\).
  • Trivial Zeros: \(s = -2, -4, -6, \ldots\) (from the functional equation).
  • Critical Line: The vertical line \(\text{Re}(s) = \frac{1}{2}\) in the complex plane.
  • Critical Strip: The region \(0 < \text{Re}(s) < 1\) where non-trivial zeros can occur.

Theorem: Functional Equation

Theorem: The Riemann zeta function satisfies the functional equation:

\[\zeta(s) = 2^s \pi^{s-1} \sin\left(\frac{\pi s}{2}\right) \Gamma(1-s) \zeta(1-s)\]

Equivalently, defining \(\xi(s) = \frac{1}{2} s(s-1) \pi^{-s/2} \Gamma\left(\frac{s}{2}\right) \zeta(s)\):

\[\xi(s) = \xi(1-s)\]

The function \(\xi(s)\) is entire and its zeros are precisely the non-trivial zeros of \(\zeta(s)\).

Proof Sketch

Step 1: Start from the theta function \(\theta(t) = \sum_{n=-\infty}^{\infty} e^{-\pi n^2 t}\).

Step 2: Using Poisson summation, prove the modular transformation: \(\theta(1/t) = \sqrt{t} \, \theta(t)\).

Step 3: Express \(\xi(s)\) as a Mellin transform:

\[\xi(s) = \frac{1}{2} \int_0^{\infty} t^{s/2-1} (\theta(t) - 1) \, dt - \frac{1}{s(1-s)}\]

Step 4: Split the integral at \(t = 1\) and apply the modular transformation to show symmetry under \(s \mapsto 1-s\). ∎

The Riemann Hypothesis

Conjecture (Riemann Hypothesis): All non-trivial zeros of \(\zeta(s)\) have real part equal to \(\frac{1}{2}\). That is, if \(\zeta(s) = 0\) and \(0 < \text{Re}(s) < 1\), then \(\text{Re}(s) = \frac{1}{2}\).

Notation Guide

  • \(\zeta(s)\): Riemann zeta function
  • \(\Gamma(s)\): Gamma function (analytic continuation of factorial)
  • \(\xi(s)\): Completed zeta function (entire)
  • \(\theta(t)\): Jacobi theta function
  • \(\rho\): Typical notation for a zero of \(\zeta(s)\)

4. Geometric Measure Theory: Fractal Dimensions

Historical Context

While mathematicians had studied pathological sets since the late 19th century (Cantor sets, Weierstrass functions), the systematic study of fractal geometry began with Felix Hausdorff's 1918 paper defining what we now call Hausdorff dimension. Benoit Mandelbrot's 1975 book "The Fractal Geometry of Nature" brought these ideas to widespread attention, showing that fractals model coastlines, clouds, and financial markets. Geometric measure theory, developed by Herbert Federer and others, provides rigorous tools for analyzing these complex sets.

Definitions

  • Hausdorff Measure: For \(s \geq 0\): \(\mathcal{H}^s(E) = \lim_{\delta \to 0} \inf\left\{\sum_i (\text{diam } U_i)^s : E \subseteq \bigcup_i U_i, \text{diam } U_i < \delta\right\}\)
  • Hausdorff Dimension: \(\dim_H(E) = \inf\{s : \mathcal{H}^s(E) = 0\} = \sup\{s : \mathcal{H}^s(E) = \infty\}\)
  • Box-Counting Dimension: \(\dim_B(E) = \lim_{\epsilon \to 0} \frac{\log N(\epsilon)}{\log(1/\epsilon)}\) where \(N(\epsilon)\) is the minimum number of boxes of size \(\epsilon\) needed to cover \(E\).
  • Self-Similarity: A set that can be decomposed into scaled copies of itself.

Theorem: Dimension of Self-Similar Sets

Theorem (Moran/Hutchinson): Let \(S_1, \ldots, S_m\) be similitudes (compositions of isometries and scalings) with contraction ratios \(r_1, \ldots, r_m\). If the open set condition holds (there exists open \(U\) with \(S_i(U) \subseteq U\) and \(S_i(U) \cap S_j(U) = \emptyset\) for \(i \neq j\)), then the unique non-empty compact invariant set \(E\) satisfying:

\[E = \bigcup_{i=1}^m S_i(E)\]

has Hausdorff and box-counting dimensions equal to the unique solution \(s\) of:

\[\sum_{i=1}^m r_i^s = 1\]

Proof Sketch

Step 1: By the contraction mapping theorem, there exists a unique compact invariant set \(E\).

Step 2 (Upper bound): Cover each \(S_i(E)\) by sets of diameter at most \(|r_i| \delta\). The \(s\)-dimensional measure satisfies:

\[\mathcal{H}^s_{|r_i|\delta}(S_i(E)) \leq |r_i|^s \mathcal{H}^s_\delta(E)\]

Step 3: Summing over all pieces:

\[\mathcal{H}^s_\delta(E) \leq \sum_{i=1}^m |r_i|^s \mathcal{H}^s_\delta(E) = \mathcal{H}^s_\delta(E)\]

where equality uses the dimension equation. This shows \(\mathcal{H}^s(E) < \infty\).

Step 4 (Lower bound): Using the open set condition and a mass distribution argument, show \(\mathcal{H}^s(E) > 0\). ∎

Notation Guide

  • \(\mathcal{H}^s\): s-dimensional Hausdorff measure
  • \(\dim_H\): Hausdorff dimension
  • \(\dim_B\): Box-counting dimension
  • \(\text{diam } U\): Diameter of set \(U\)
  • \(S_i\): Contraction similitudes
  • \(r_i\): Contraction ratios

    intervals = [(0.0, 1.0)]

def box_counting_dimension(points, min_box_size=0.001, max_box_size=0.5, n_sizes=20):

    box_sizes = np.logspace(np.log10(max_box_size), np.log10(min_box_size), n_sizes)
    counts = []

        y_bins = np.arange(0, 1 + box_size, box_size)

        count = np.sum(hist > 0)

    log_sizes = np.log(1 / box_sizes)
    log_counts = np.log(counts)
    
    # Fit line to estimate dimension

    estimated_dim = coeffs[0]
    
    print(f"\nBox-counting dimension estimate: {estimated_dim:.4f}")
    
    return box_sizes, counts, estimated_dim

📜 Math History: The Birth of Modern Algebra

The transformation of algebra from a collection of problem-solving techniques to a structural discipline is one of the most significant developments in mathematical history. This evolution, spanning roughly 1830 to 1930, fundamentally changed how mathematicians think about equations, numbers, and abstract structures.

The story begins with the work of Évariste Galois (1811–1832), whose short life belied his profound impact. Galois developed what we now call Galois theory to understand when polynomial equations could be solved by radicals. His insight was revolutionary: instead of focusing on individual equations, he studied the symmetry group of the roots. This shift from equations to structures would become the hallmark of modern algebra.

Tragically, Galois died in a duel at age 20, leaving behind manuscripts that took decades to be fully understood. When Liouville published Galois's work in 1846, it sparked a transformation in algebra. Mathematicians began to recognize that the group concept — the study of symmetry — was more fundamental than the equations themselves.

The next major figure was Richard Dedekind (1831–1916), who introduced ideals in algebraic number theory. While Kummer had developed "ideal numbers" to restore unique factorization in cyclotomic fields, Dedekind's abstract definition of an ideal as a subset of a ring was far more general. His approach emphasized structure over calculation, defining algebraic objects by their properties rather than their representations.

Solution:

We prove by induction that the maximum is \((n+1) \cdot 2^{n-2}\).

Removing the top circle and its incident edges splits the remaining triangle into two smaller triangles: a left triangle with rows \(2, 3, \ldots, k+1\) and a right triangle with rows \(2, 3, \ldots, n-k+1\) for some \(k\).

Let the red circle in row 1 be the top circle. Then all \(2^{n-1}\) ninja paths pass through a red circle. For the remaining rows, we can optimize recursively.

Alternatively, if the red circle in row \(i > 1\) is not on the "central" path, we get fewer paths. The optimal strategy places red circles to maximize coverage.

🎨 Visualization of the Day: Julia Sets

The Julia set is a fractal defined for each complex parameter \(c\). Unlike the Mandelbrot set (which lives in parameter space), each Julia set lives in dynamical space — showing the behavior of the iteration \(z_{n+1} = z_n^2 + c\) for different starting points \(z_0\).

The Julia set \(J_c\) is the boundary between points that escape to infinity under iteration and points that remain bounded. For some values of \(c\), the Julia set is connected (when \(c\) is in the Mandelbrot set); for others, it is a Cantor dust of disconnected points.

import numpy as np
import matplotlib.pyplot as plt

def julia_set(c, width=800, height=600, x_min=-2, x_max=2, y_min=-1.5, y_max=1.5, max_iter=100):
    """
    Compute and display the Julia set for parameter c.
    
    The Julia set is the boundary of the filled Julia set,
    consisting of points that don't escape to infinity under
    iteration of f(z) = z^2 + c.
    """
    # Create grid of complex numbers
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Initialize iteration count array
    iterations = np.zeros(Z.shape, dtype=int)
    
    # Points that haven't escaped yet
    mask = np.ones(Z.shape, dtype=bool)
    
    for i in range(max_iter):
        # Only iterate points that haven't escaped
        Z[mask] = Z[mask]**2 + c
        
        # Check escape condition (|z| > 2)
        escaped = np.abs(Z) > 2
        
        # Record iteration count for newly escaped points
        new_escape = escaped & mask
        iterations[new_escape] = i
        
        # Update mask
        mask &= ~escaped
        
        # Stop if all points have escaped
        if not np.any(mask):
            break
    
    # Points that never escaped are in the filled Julia set
    iterations[mask] = max_iter
    
    return iterations
