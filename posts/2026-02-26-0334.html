Elliptic Curves and the Mordell-Weil Theorem

Motivation

Elliptic curves are among the most fascinating objects in mathematics, connecting number theory, algebraic geometry, and complex analysis. They played a central role in Wiles's proof of Fermat's Last Theorem and form the foundation of modern cryptography. The study of rational points on elliptic curves leads to deep questions about the arithmetic of curves.

Definitions

Elliptic Curve: A smooth projective curve of genus 1 with a specified base point (the identity). Over a field \(K\) with characteristic not 2 or 3, every elliptic curve can be written in Weierstrass form: \[y^2 = x^3 + ax + b\] where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\) ensures smoothness.

Group Law: The points on an elliptic curve form an abelian group. Geometrically: given points \(P\) and \(Q\), draw the line through them (or tangent if \(P = Q\)), find the third intersection with the curve, and reflect over the x-axis to get \(P + Q\).

Rational Points: \(E(K)\) denotes the set of points with coordinates in the field \(K\).

Theorem and Proof

Mordell-Weil Theorem: Let \(E\) be an elliptic curve over a number field \(K\). Then the group of rational points \(E(K)\) is finitely generated. That is: \[E(K) \cong E(K)_{\text{tors}} \oplus \mathbb{Z}^r\] where \(E(K)_{\text{tors}}\) is the finite torsion subgroup and \(r\) is the rank.

Proof Sketch: The proof has two main parts. First, the "weak Mordell-Weil theorem" shows that \(E(K)/2E(K)\) is finite. This uses Galois cohomology and properties of the 2-descent map. Second, one constructs a height function \(\hat{h}: E(K) \to \mathbb{R}_{\geq 0}\) satisfying: (1) \(\hat{h}(P) = 0\) iff \(P\) is torsion, (2) \(\hat{h}(mP) = m^2\hat{h}(P)\), and (3) \(\{P : \hat{h}(P) \leq B\}\) is finite for all \(B\). These properties, combined with the finiteness of \(E(K)/2E(K)\), imply finite generation via a descent argument.

Notation Guide

  • \(E\) — elliptic curve (smooth cubic curve with a point)
  • \(E(K)\) — \(K\)-rational points on \(E\)
  • \(\mathcal{O}\) — point at infinity (identity element)
  • \(\hat{h}\) — canonical height (Néron-Tate height)
  • \(r\) — rank of the elliptic curve
  • \(E[n]\) — \(n\)-torsion points (kernel of multiplication by \(n\))

import numpy as np
import matplotlib.pyplot as plt

class EllipticCurve:
    """Elliptic curve in short Weierstrass form: y^2 = x^3 + ax + b"""
    
    def __init__(self, a, b):
        self.a = a
        self.b = b
        self.discriminant = -16 * (4*a**3 + 27*b**2)
        if self.discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
    
    def is_on_curve(self, x, y):
        """Check if point (x, y) lies on the curve."""
        return y**2 == x**3 + self.a*x + self.b
    
    def add(self, P, Q):
        """Add two points on the curve using the group law."""
        if P is None: return Q
        if Q is None: return P
        x1, y1 = P
        x2, y2 = Q
        
        if x1 == x2 and y1 != y2:
            return None  # Point at infinity
        
        if P == Q:
            # Tangent line: slope = (3x^2 + a) / (2y)
            if y1 == 0:
                return None
            m = (3*x1**2 + self.a) / (2*y1)
        else:
            # Secant line: slope = (y2 - y1) / (x2 - x1)
            m = (y2 - y1) / (x2 - x1)
        
        x3 = m**2 - x1 - x2
        y3 = m*(x1 - x3) - y1
        return (x3, y3)
    
    def multiply(self, P, n):
        """Compute n*P using double-and-add."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.multiply((x, -y), -n)
        
        result = None
        addend = P
        while n > 0:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        return result
    
    def plot(self, xlim=(-3, 3), ylim=(-4, 4)):
        """Plot the real points of the elliptic curve."""
        x = np.linspace(xlim[0], xlim[1], 1000)
        y_squared = x**3 + self.a*x + self.b
        
        # Only plot where y^2 >= 0
        mask = y_squared >= 0
        x_pos = x[mask]
        y_pos = np.sqrt(y_squared[mask])
        
        plt.figure(figsize=(10, 8))
        plt.plot(x_pos, y_pos, 'b-', linewidth=2, label='$y = +\\sqrt{x^3 + ax + b}$')
        plt.plot(x_pos, -y_pos, 'b-', linewidth=2, label='$y = -\\sqrt{x^3 + ax + b}$')
        plt.axhline(y=0, color='k', linewidth=0.5)
        plt.axvline(x=0, color='k', linewidth=0.5)
        plt.grid(True, alpha=0.3)
        plt.xlabel('x')
        plt.ylabel('y')
        plt.title(f'Elliptic Curve: $y^2 = x^3 + {self.a}x + {self.b}$')
        plt.legend()
        plt.xlim(xlim)
        plt.ylim(ylim)
        plt.axis('equal')
        return plt

Representation Theory of Finite Groups

Motivation

Representation theory studies abstract algebraic structures by representing their elements as linear transformations of vector spaces. This allows us to use linear algebra to understand groups, turning abstract symmetry into concrete matrices. It has applications in quantum mechanics, crystallography, harmonic analysis, and number theory.

Definitions

Representation: A representation of a group \(G\) over a field \(F\) is a homomorphism \(\rho: G \to GL(V)\) where \(V\) is a vector space over \(F\). This assigns to each \(g \in G\) an invertible linear transformation \(\rho(g)\).

Irreducible Representation: A representation is irreducible if it has no proper nontrivial invariant subspaces. Every representation decomposes as a direct sum of irreducibles (Maschke's theorem, for finite groups over \(\mathbb{C}\)).

Character: The character of a representation is \(\chi_\rho(g) = \text{tr}(\rho(g))\). Characters are class functions (constant on conjugacy classes) and completely determine the representation.

Theorem and Proof

Orthogonality Relations: Let \(G\) be a finite group with irreducible characters \(\chi_1, \ldots, \chi_k\). Then: \[\frac{1}{|G|} \sum_{g \in G} \chi_i(g) \overline{\chi_j(g)} = \delta_{ij}\] and for conjugacy classes \(C_1, C_2\): \[\sum_{\chi} \chi(C_1) \overline{\chi(C_2)} = \frac{|G|}{|C_1|} \delta_{C_1, C_2}\]

Proof Sketch: Define the inner product on class functions by \(\langle \chi, \psi \rangle = \frac{1}{|G|} \sum_g \chi(g)\overline{\psi(g)}\). Using Schur's lemma, one shows that matrix coefficients of inequivalent irreducibles are orthogonal. The key step is constructing projection operators \(P_i = \frac{\dim(V_i)}{|G|} \sum_g \overline{\chi_i(g)}\rho(g)\) that project onto the \(V_i\)-isotypic component. The orthogonality follows from the fact that these projections are orthogonal idempotents.

Notation Guide

  • \(\rho: G \to GL(V)\) — representation homomorphism
  • \(\chi_\rho\) or \(\chi_V\) — character of representation \(\rho\)
  • \(\hat{G}\) — set of irreducible representations of \(G\)
  • \(\text{Reg}_G\) — regular representation
  • \(\langle \chi, \psi \rangle\) — inner product of characters
  • \(\chi_{V \otimes W} = \chi_V \cdot \chi_W\) — character of tensor product

import numpy as np
from itertools import permutations

class SymmetricGroup:
    """Symmetric group S_n with representation theory."""
    
    def __init__(self, n):
        self.n = n
        self.elements = list(permutations(range(n)))
        self.size = len(self.elements)
    
    def compose(self, sigma, tau):
        """Compose permutations: (sigma ∘ tau)(i) = sigma(tau(i))"""
        return tuple(sigma[tau[i]] for i in range(self.n))
    
    def inverse(self, sigma):
        """Compute inverse permutation."""
        inv = [0] * self.n
        for i, j in enumerate(sigma):
            inv[j] = i
        return tuple(inv)
    
    def sign(self, sigma):
        """Sign of permutation using inversions."""
        inversions = sum(1 for i in range(self.n) for j in range(i+1, self.n) 
                        if sigma[i] > sigma[j])
        return (-1) ** inversions
    
    def regular_representation(self, g):
        """Matrix of left multiplication by g in the regular representation."""
        mat = np.zeros((self.size, self.size))
        for j, h in enumerate(self.elements):
            gh = self.compose(g, h)
            i = self.elements.index(gh)
            mat[i, j] = 1
        return mat
    
    def character_table(self):
        """Compute character table (for S_3 as example)."""
        if self.n == 3:
            # S_3 has 3 conjugacy classes: {e}, {(12), (13), (23)}, {(123), (132)}
            # 3 irreps: trivial, sign, standard (2-dim)
            return np.array([
                [1, 1, 1],      # trivial
                [1, -1, 1],     # sign
                [2, 0, -1]      # standard
            ])
        return None

def fourier_transform_on_group(G, f):
    """
    Fourier transform of function f: G -> C.
    For abelian groups: f_hat(chi) = sum_g f(g) * chi(g)
    """
    n = len(G.elements)
    # For cyclic group Z_n, characters are chi_k(j) = exp(2πijk/n)
    f_hat = []
    for k in range(n):
        coeff = sum(f[j] * np.exp(2j * np.pi * 1j * k * j / n) 
                   for j in range(n))
        f_hat.append(coeff / n)
    return f_hat

Knot Theory and the Jones Polynomial

Motivation

Knot theory studies embeddings of circles in 3-dimensional space. Despite its intuitive origins—tying knots in string—it leads to profound mathematics connecting topology, quantum field theory, and representation theory. The discovery of the Jones polynomial in 1984 revolutionized the field, connecting knots to statistical mechanics and quantum groups.

Definitions

Knot: An embedding of \(S^1\) into \(S^3\) (or \(\mathbb{R}^3\)). A link is an embedding of multiple disjoint circles.

Reidemeister Moves: Three local moves on knot diagrams that generate all ambient isotopies. Two knots are equivalent iff their diagrams are related by a sequence of Reidemeister moves.

Kauffman Bracket: A polynomial invariant of unoriented link diagrams defined by: \[\langle \bigcirc \rangle = 1\] \[\langle L \cup \bigcirc \rangle = (-A^2 - A^{-2})\langle L \rangle\] \[\langle \crossing \rangle = A\langle \smoothing \rangle + A^{-1}\langle \hsmoothing \rangle\]

Theorem and Proof

Existence of Jones Polynomial: For any oriented link \(L\), there exists a Laurent polynomial \(V_L(t) \in \mathbb{Z}[t^{1/2}, t^{-1/2}]\) such that: 1. \(V_{\text{unknot}}(t) = 1\) 2. \(t^{-1}V_{L_+} - tV_{L_-} = (t^{1/2} - t^{-1/2})V_{L_0}\) (skein relation)

Proof Sketch: Define the Kauffman bracket on diagrams. Show it is invariant under Reidemeister moves II and III. For Reidemeister I, the bracket transforms predictably. Define the writhe \(w(D) = \sum \text{signs of crossings}\). Then \(V_L(t) = ((-A)^{-3w(D)}\langle D \rangle)_{A = t^{-1/4}}\) is invariant under all Reidemeister moves. The skein relation follows from the Kauffman bracket's definition and the writhe correction.

Notation Guide

  • \(V_L(t)\) — Jones polynomial of link \(L\)
  • \(\langle D \rangle\) — Kauffman bracket of diagram \(D\)
  • \(w(D)\) — writhe of oriented diagram
  • \(L_+, L_-, L_0\) — links differing at one crossing (skein triple)
  • \(\Delta_L(t)\) — Alexander polynomial

Optimal Transport and Wasserstein Distances

Real-World Motivation

Optimal transport, originating with Monge in 1781 and Kantorovich in 1942, asks: what is the most efficient way to move a pile of dirt to fill a hole? This seemingly simple question has profound applications in economics (matching theory), machine learning (generative models like Wasserstein GANs), image processing, and partial differential equations.

Definitions

Monge Problem: Given probability measures \(\mu\) on \(X\) and \(\nu\) on \(Y\), find a transport map \(T: X \to Y\) minimizing: \[\int_X c(x, T(x)) \, d\mu(x)\] subject to \(T_\#\mu = \nu\) (pushforward condition).

Kantorovich Relaxation: Find a coupling \(\gamma \in \Pi(\mu, \nu)\) minimizing: \[\int_{X \times Y} c(x, y) \, d\gamma(x,y)\] where \(\Pi(\mu, \nu)\) is the set of joint distributions with marginals \(\mu\) and \(\nu\).

Wasserstein Distance: For \(p \geq 1\): \[W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int |x-y|^p \, d\gamma\right)^{1/p}\]

Theorem and Proof

Kantorovich Duality: For lower semicontinuous cost \(c\): \[\inf_{\gamma \in \Pi(\mu, \nu)} \int c \, d\gamma = \sup_{(\phi, \psi)} \left(\int \phi \, d\mu + \int \psi \, d\nu\right)\] where the supremum is over pairs satisfying \(\phi(x) + \psi(y) \leq c(x,y)\).

Proof Sketch: This is an infinite-dimensional linear programming duality. The constraint \(\gamma \in \Pi(\mu, \nu)\) can be written as linear constraints on \(\gamma\). The dual variables correspond to potentials \(\phi\) and \(\psi\). The constraint \(\phi(x) + \psi(y) \leq c(x,y)\) ensures the dual objective is a lower bound. Strong duality holds under mild conditions (e.g., \(c\) lower semicontinuous and \(\mu, \nu\) tight).

Notation Guide

  • \(\Pi(\mu, \nu)\) — set of couplings (transport plans)
  • \(T_\#\mu\) — pushforward measure: \((T_\#\mu)(A) = \mu(T^{-1}(A))\)
  • \(W_p\) — \(p\)-Wasserstein distance
  • \(\phi, \psi\) — Kantorovich potentials
  • \(c(x,y)\) — cost function (often \(|x-y|^p\))

def wasserstein_1d(mu, nu, x, y):
    """
    Compute 1-Wasserstein distance in 1D using CDFs.
    For 1D: W_1 = integral |F_mu(t) - F_nu(t)| dt
    """
    # Sort and compute CDFs
    mu_sorted = np.sort(mu)
    nu_sorted = np.sort(nu)
    
    # Empirical CDFs
    def ecdf(data, t):
        return np.mean(data <= t)
    
    # Grid for integration
    t_grid = np.linspace(min(mu.min(), nu.min()) - 1, 
                         max(mu.max(), nu.max()) + 1, 1000)
    
    F_mu = np.array([ecdf(mu, t) for t in t_grid])
    F_nu = np.array([ecdf(nu, t) for t in t_grid])
    
    W1 = np.trapz(np.abs(F_mu - F_nu), t_grid)
    return W1

def sinkhorn_knopp(mu, nu, C, reg=0.1, numItermax=1000):
    """
    Compute entropic-regularized optimal transport using Sinkhorn algorithm.
    
    Parameters:
    -----------
    mu, nu : source and target distributions (sum to 1)
    C : cost matrix
    reg : regularization parameter (epsilon)
    """
    K = np.exp(-C / reg)
    u = np.ones(len(mu))
    v = np.ones(len(nu))
    
    for i in range(numItermax):
        u = mu / (K @ v)
        v = nu / (K.T @ u)
        
        # Check convergence
        if i % 100 == 0:
            P = np.diag(u) @ K @ np.diag(v)
            err = np.linalg.norm(P.sum(axis=1) - mu)
            if err < 1e-6:
                break
    
    P = np.diag(u) @ K @ np.diag(v)
    return P

Compressed Sensing and Sparse Recovery

Real-World Motivation

Compressed sensing revolutionized signal processing by showing that sparse signals can be recovered from far fewer measurements than the Nyquist-Shannon theorem requires. Applications include MRI imaging (reducing scan time), single-pixel cameras, and efficient data acquisition in sensor networks. The key insight is that sparsity can substitute for bandwidth.

Definitions

Sparsity: A vector \(x \in \mathbb{R}^n\) is \(k\)-sparse if it has at most \(k\) nonzero entries. The \(\ell_0\) "norm" counts nonzero entries: \(\|x\|_0 = |\{i : x_i \neq 0\}|\).

Restricted Isometry Property (RIP): A matrix \(A\) satisfies RIP of order \(k\) with constant \(\delta_k\) if for all \(k\)-sparse \(x\): \[(1-\delta_k)\|x\|_2^2 \leq \|Ax\|_2^2 \leq (1+\delta_k)\|x\|_2^2\]

Basis Pursuit: The convex relaxation of sparse recovery: \[\min_x \|x\|_1 \text{ subject to } Ax = b\]

Theorem and Proof

Exact Recovery Theorem: If \(A\) satisfies RIP with \(\delta_{2k} < \sqrt{2} - 1\), then the solution to basis pursuit equals the sparsest solution to \(Ax = b\).

Proof Sketch: Let \(x^*\) be the true sparse solution and \(\hat{x}\) the basis pursuit solution. Define \(h = \hat{x} - x^*\). By optimality, \(\|\hat{x}\|_1 \leq \|x^*\|_1\). Decompose \(h\) into \(h_{T_0}\) (on support of \(x^*\)) and \(h_{T_0^c}\). The key inequality is \(\|h_{T_0^c}\|_1 \leq \|h_{T_0}\|_1\). Using RIP, one shows \(\|h\|_2 \leq C\|Ah\|_2 = 0\), so \(h = 0\) and \(\hat{x} = x^*\).

Notation Guide

  • \(\|x\|_0\) — sparsity (count of nonzero entries)
  • \(\|x\|_1 = \sum |x_i|\) — \(\ell_1\) norm (convex relaxation)
  • \(\|x\|_2 = \sqrt{\sum x_i^2}\) — Euclidean norm
  • \(\delta_k\) — RIP constant of order \(k\)
  • \(m \times n\) — measurement matrix dimensions (\(m \ll n\))

def basis_pursuit(A, b):
    """
    Solve min ||x||_1 subject to Ax = b using linear programming.
    
    Convert to LP: x = x+ - x- where x+, x- >= 0
    """
    m, n = A.shape
    
    # Objective: minimize sum(x+ + x-)
    c = np.ones(2 * n)
    
    # Equality constraints: A(x+ - x-) = b
    A_eq = np.hstack([A, -A])
    b_eq = b
    
    # Bounds: x+, x- >= 0
    bounds = [(0, None)] * (2 * n)
    
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if result.success:
        x = result.x[:n] - result.x[n:]
        return x
    else:
        return None

def iterative_hard_thresholding(A, b, k, max_iter=100):
    """
    IHT: simple greedy algorithm for sparse recovery.
    x_{t+1} = H_k(x_t + A^T(b - Ax_t))
    where H_k keeps only k largest entries.
    """
    n = A.shape[1]
    x = np.zeros(n)
    
    for _ in range(max_iter):
        # Gradient step
        x = x + 0.1 * A.T @ (b - A @ x)
        
        # Hard thresholding
        idx = np.argsort(np.abs(x))[-k:]
        x_new = np.zeros(n)
        x_new[idx] = x[idx]
        x = x_new
    
    return x

Random Matrix Theory and the Semicircle Law

Real-World Motivation

Random matrix theory studies the statistical properties of matrices with random entries. It emerged from Wigner's work on nuclear physics in the 1950s and has since found applications in quantum chaos, wireless communications, finance, machine learning, and number theory. The universality phenomenon—where local statistics are independent of the distribution of entries—is one of the deepest results in modern probability.

Definitions

Wigner Matrix: A Hermitian matrix \(H\) with independent (up to symmetry) entries where diagonal entries have variance \(\sigma^2\) and off-diagonal entries have variance \(\sigma^2/n\).

Empirical Spectral Distribution: For an \(n \times n\) matrix \(H\) with eigenvalues \(\lambda_1, \ldots, \lambda_n\): \[\mu_H = \frac{1}{n} \sum_{i=1}^n \delta_{\lambda_i}\]

Semicircle Distribution: The probability measure on \([-2\sigma, 2\sigma]\) with density: \[\rho_{sc}(x) = \frac{1}{2\pi\sigma^2}\sqrt{4\sigma^2 - x^2}\]

Theorem and Proof

Wigner's Semicircle Law: Let \(H_n\) be a sequence of Wigner matrices. As \(n \to \infty\), the empirical spectral distribution converges weakly almost surely to the semicircle distribution: \[\mu_{H_n} \xrightarrow{w} \rho_{sc}\]

Proof Sketch: The proof uses the method of moments. Compute \(\mathbb{E}[\text{tr}(H_n^k)]\) for each \(k\). By Wick's formula (for Gaussian entries) or combinatorial arguments, this counts certain paths. Only non-backtracking paths contribute in the limit. The moments of the semicircle are the Catalan numbers: \(m_{2k} = C_k = \frac{1}{k+1}\binom{2k}{k}\) and \(m_{2k+1} = 0\). Since the Catalan numbers determine a unique distribution, convergence follows.

Notation Guide

  • \(H\) or \(H_n\) — Wigner matrix (\(n \times n\) Hermitian)
  • \(\lambda_i\) — eigenvalues
  • \(\mu_H\) — empirical spectral distribution (ESD)
  • \(\rho_{sc}\) — semicircle density
  • \(C_k = \frac{1}{k+1}\binom{2k}{k}\) — Catalan numbers
  • \(m_k = \int x^k \rho_{sc}(x) dx\) — moments

    """

    -----------
    n : size of matrix
    sigma : scale parameter
    distribution : 'gaussian' or 'bernoulli'
    """

    elif distribution == 'bernoulli':

    H = (A + A.T) / np.sqrt(2)
    return H

def semicircle_density(x, sigma=1.0):
    """Density of semicircle distribution."""
    R = 2 * sigma
    density = np.zeros_like(x)
    mask = np.abs(x) < R
    density[mask] = (1 / (2 * np.pi * sigma**2)) * np.sqrt(R**2 - x[mask]**2)
    return density

def marchenko_pastur_density(x, gamma, sigma=1.0):
    """
    Marchenko-Pastur distribution for sample covariance matrices.
    gamma = n/p (aspect ratio)
    """
    lambda_plus = sigma**2 * (1 + np.sqrt(gamma))**2
    lambda_minus = sigma**2 * (1 - np.sqrt(gamma))**2
    
    density = np.zeros_like(x)
    mask = (x > lambda_minus) & (x < lambda_plus)
    
    density[mask] = (1 / (2 * np.pi * sigma**2 * gamma * x[mask])) * \
                    np.sqrt((lambda_plus - x[mask]) * (x[mask] - lambda_minus))
    return density

p-adic Numbers and Analysis

Historical Context

p-adic numbers were introduced by Kurt Hensel in 1897 as a way to bring algebraic techniques from power series into number theory. The analogy between \(\mathbb{Z}\) and \(\mathbb{F}_q[t]\) led Hensel to construct a completion of \(\mathbb{Q}\) with respect to the p-adic absolute value. This created an entirely new number system where "closeness" depends on divisibility rather than size.

Definitions

p-adic Absolute Value: For a prime \(p\) and nonzero integer \(n\), write \(n = p^k \cdot m\) where \(p \nmid m\). Then: \[|n|_p = p^{-k}, \quad |0|_p = 0\] Extended to \(\mathbb{Q}\) by \(|a/b|_p = |a|_p/|b|_p\).

p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\). Every element can be written as: \[x = \sum_{k=m}^{\infty} a_k p^k\] where \(a_k \in \{0, 1, \ldots, p-1\}\) and \(m \in \mathbb{Z}\).

p-adic Integers \(\mathbb{Z}_p\): The closed unit ball \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\}\).

Theorem and Proof

Ostrowski's Theorem: Every nontrivial absolute value on \(\mathbb{Q}\) is equivalent to either the standard absolute value \(|\cdot|_\infty\) or a p-adic absolute value \(|\cdot|_p\) for some prime \(p\).

Proof Sketch: Let \(|\cdot|\) be a nontrivial absolute value on \(\mathbb{Q}\). If \(|n| \leq 1\) for all integers \(n\), then by the archimedean property failing, there exists a smallest prime \(p\) with \(|p| < 1\). One shows \(|q| = 1\) for all other primes \(q\), so \(|\cdot|\) is equivalent to \(|\cdot|_p\). If \(|n| > 1\) for some \(n\), the absolute value is archimedean and equivalent to the standard one.

Notation Guide

  • \(|x|_p\) — p-adic absolute value
  • \(\mathbb{Q}_p\) — field of p-adic numbers
  • \(\mathbb{Z}_p\) — ring of p-adic integers
  • \(v_p(x)\) — p-adic valuation (exponent of \(p\))
  • \(\mathbb{A}_\mathbb{Q}\) — adele ring (restricted product of \(\mathbb{Q}_p\) and \(\mathbb{R}\))

import numpy as np
from fractions import Fraction

class PAdicNumber:
    """
    Simplified p-adic number representation.
    Stores a p-adic number as (prime p, list of digits, valuation).
    """
    
    def __init__(self, p, digits, valuation=0):
        self.p = p
        self.digits = list(digits)  # Coefficients a_0, a_1, a_2, ...
        self.valuation = valuation  # Starting power of p
    
    def __repr__(self):
        if len(self.digits) <= 5:
            terms = []
            for i, d in enumerate(self.digits):
                power = self.valuation + i
                if d != 0:
                    if power == 0:
                        terms.append(f"{d}")
                    elif power == 1:
                        terms.append(f"{d}*{self.p}")
                    else:
                        terms.append(f"{d}*{self.p}^{power}")
            return " + ".join(terms) if terms else "0"
        else:
            return f"{self.digits[0]} + {self.digits[1]}*{self.p} + ... (mod {self.p}^{len(self.digits)}"
    
    def to_rational_approx(self):
        """Convert to rational approximation."""
        result = 0
        for i, d in enumerate(self.digits):
            result += d * (self.p ** (self.valuation + i))
        return Fraction(result, 1)

def p_adic_expansion(n, p, precision=20):
    """
    Compute p-adic expansion of rational number n.
    For integers: standard base-p expansion.
    """
    if isinstance(n, Fraction):
        # Handle rational numbers
        num, den = n.numerator, n.denominator
        # Find valuation
        v_num = 0
        while num % p == 0 and num != 0:
            num //= p
            v_num += 1
        v_den = 0
        while den % p == 0 and den != 0:
            den //= p
            v_den += 1
        
        valuation = v_num - v_den
        # Compute digits using Hensel lifting
        digits = []
        x = (num * pow(den, -1, p**precision)) % (p**precision)
        for _ in range(precision):
            digits.append(x % p)
            x //= p
        return PAdicNumber(p, digits, valuation)
    else:
        # Integer case
        if n == 0:
            return PAdicNumber(p, [0])
        valuation = 0
        while n % p == 0 and n != 0:
            n //= p
            valuation += 1
        digits = []
        while n > 0 and len(digits) < precision:
            digits.append(n % p)
            n //= p
        return PAdicNumber(p, digits, valuation)

def p_adic_absolute_value(rational, p):
    """Compute p-adic absolute value of a rational number."""
    if rational == 0:
        return 0
    
    num, den = rational.numerator, rational.denominator
    # Compute p-adic valuation
    v_num = 0
    while num % p == 0 and num != 0:
        num //= p
        v_num += 1
    v_den = 0
    while den % p == 0 and den != 0:
        den //= p
        v_den += 1
    
    v_p = v_num - v_den
    return p ** (-v_p)

Category Theory: Functors, Natural Transformations, and Universal Properties

Historical Context

Category theory was invented by Samuel Eilenberg and Saunders Mac Lane in 1945 to formalize the notion of "natural" in algebraic topology. What began as a tool for organizing algebraic structures has become a unifying language across mathematics. The Yoneda lemma, adjoint functors, and the concept of universal properties have transformed how mathematicians think about structure.

Definitions

Category: A category \(\mathcal{C}\) consists of: - Objects: \(A, B, C, \ldots\) - Morphisms: \(\text{Hom}(A, B)\) for each pair of objects - Composition: associative operation \(\circ : \text{Hom}(B, C) \times \text{Hom}(A, B) \to \text{Hom}(A, C)\) - Identity: \(\text{id}_A \in \text{Hom}(A, A)\) for each object

Functor: A map \(F: \mathcal{C} \to \mathcal{D}\) preserving composition and identities.

Natural Transformation: A family of morphisms \(\eta_A: F(A) \to G(A)\) such that for all \(f: A \to B\): \[\eta_B \circ F(f) = G(f) \circ \eta_A\]

Theorem and Proof

Yoneda Lemma: Let \(F: \mathcal{C}^{op} \to \mathbf{Set}\) be a functor and \(A \in \mathcal{C}\). Then: \[\text{Nat}(\text{Hom}(-, A), F) \cong F(A)\] Moreover, this isomorphism is natural in both \(A\) and \(F\).

Proof Sketch: Given a natural transformation \(\eta: \text{Hom}(-, A) \to F\), evaluate at \(A\) to get \(\eta_A: \text{Hom}(A, A) \to F(A)\). Map \(\eta\) to \(\eta_A(\text{id}_A) \in F(A)\). Conversely, given \(x \in F(A)\), define \(\eta_B(f) = F(f)(x)\) for \(f: B \to A\). Naturality follows from functoriality. These maps are inverse to each other.

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\) — categories
  • \(\text{Hom}_{\mathcal{C}}(A, B)\) or \(A \to B\) — morphisms
  • \(F: \mathcal{C} \to \mathcal{D}\) — functor
  • \(\eta: F \Rightarrow G\) — natural transformation
  • \(\mathbf{Set}, \mathbf{Grp}, \mathbf{Vect}_k\) — concrete categories
  • \(\mathcal{C}^{op}\) — opposite category

class Morphism:
    """Represents a morphism in a category."""
    def __init__(self, name: str, domain: Any, codomain: Any, 
                 func: Callable = None):
        self.name = name
        self.domain = domain
        self.codomain = codomain
        self.func = func
    
    def __call__(self, x):
        if self.func:
            return self.func(x)
        raise NotImplementedError()
    
    def __rshift__(self, other):
        """Composition: f >> g = g ∘ f"""
        if self.codomain != other.domain:
            raise ValueError("Codomain mismatch")
        def composed(x):
            return other(self(x))
        return Morphism(f"{other.name} ∘ {self.name}", 
                       self.domain, other.codomain, composed)
    
    def __repr__(self):
        return f"{self.name}: {self.domain} → {self.codomain}"

class Category:
    """A small category (objects and morphisms)."""
    def __init__(self, name: str):
        self.name = name
        self.objects: Set[Any] = set()
        self.morphisms: Dict[tuple, Morphism] = {}
    
    def add_object(self, obj):
        self.objects.add(obj)
    
    def add_morphism(self, morph: Morphism):
        self.morphisms[(morph.domain, morph.codomain)] = morph
    
    def hom(self, A, B):
        """Get morphisms from A to B."""
        return self.morphisms.get((A, B))

class Functor:
    """A functor between categories."""
    def __init__(self, name: str, source: Category, target: Category,
                 obj_map: Dict, morph_map: Dict):
        self.name = name
        self.source = source
        self.target = target
        self.obj_map = obj_map
        self.morph_map = morph_map
    
    def __call__(self, obj_or_morph):
        if isinstance(obj_or_morph, Morphism):
            return self.morph_map.get(obj_or_morph)
        return self.obj_map.get(obj_or_morph)
    
    def __repr__(self):
        return f"Functor({self.name}): {self.source.name} → {self.target.name}"

class PowersetFunctor:
    """
    The covariant powerset functor P: Set → Set.
    - On objects: P(X) = power set of X
    - On morphisms: P(f: X → Y) = f_*: P(X) → P(Y) where f_*(S) = f(S)
    """
    
    @staticmethod
    def on_object(X: Set) -> Set:
        """Power set of X."""
        from itertools import chain, combinations
        return set(chain.from_iterable(combinations(X, r) 
                                       for r in range(len(X)+1)))
    
    @staticmethod
    def on_morphism(f: Callable[[Any], Any]) -> Callable[[Set], Set]:
        """Image map induced by f."""
        def image_map(S: Set) -> Set:
            return {f(x) for x in S}
        return image_map

Noncommutative Geometry and Spectral Triples

Historical Context

Noncommutative geometry, developed by Alain Connes in the 1980s, extends the correspondence between geometric spaces and commutative algebras to the noncommutative setting. Gelfand's theorem establishes that compact Hausdorff spaces correspond to commutative C*-algebras. Connes asked: what geometry is encoded by noncommutative algebras? The answer has led to breakthroughs in quantum physics, number theory, and the standard model of particle physics.

Definitions

C*-Algebra: A Banach algebra \(\mathcal{A}\) with an involution \(*\) satisfying \(\|a^*a\| = \|a\|^2\).

Spectral Triple: A triple \((\mathcal{A}, \mathcal{H}, D)\) where: - \(\mathcal{A}\) is a *-algebra represented on Hilbert space \(\mathcal{H}\) - \(D\) is an unbounded self-adjoint operator (Dirac operator) - \([D, a]\) is bounded for all \(a \in \mathcal{A}\)

Connes Distance: For states \(\phi, \psi\) on \(\mathcal{A}\): \[d(\phi, \psi) = \sup\{|\phi(a) - \psi(a)| : \|[D, a]\| \leq 1\}\]

Theorem and Proof

Connes' Reconstruction Theorem: For a compact spin Riemannian manifold \(M\), the spectral triple \((C^\infty(M), L^2(M, S), D)\) where \(D\) is the Dirac operator, completely determines \(M\) up to isometry.

Proof Sketch: The key insight is that the Dirac operator encodes the metric via the formula: \[d(x, y) = \sup\{|f(x) - f(y)| : \|[D, f]\| \leq 1\}\] where \(f\) acts by multiplication on spinors. This recovers the geodesic distance. The spectrum of \(D\) determines the volume form via the Dixmier trace. Together, these reconstruct the Riemannian structure.

Notation Guide

  • \(\mathcal{A}\) — C*-algebra (noncommutative "space")
  • \(\mathcal{H}\) — Hilbert space carrying the representation
  • \(D\) — Dirac operator (unbounded, self-adjoint)
  • \([D, a] = Da - aD\) — commutator (measuring "differentiability")
  • \(\sigma(a)\) — spectrum of operator \(a\)
  • \(\text{Tr}_\omega\) — Dixmier trace (noncommutative integral)

import numpy as np
from scipy.linalg import expm, eigvalsh
import matplotlib.pyplot as plt

class NoncommutativeTorus:
    """
    The noncommutative torus A_θ: C*-algebra generated by unitaries U, V
    with UV = e^{2πiθ}VU.
    """
    
    def __init__(self, theta, n=50):
        """
        theta: irrationality parameter (noncommutativity)
        n: matrix dimension for finite approximation
        """
        self.theta = theta
        self.n = n
        
        # Construct finite-dimensional approximation
        # U = shift operator, V = diagonal with phases
        self.U = np.zeros((n, n), dtype=complex)
        for i in range(n-1):
            self.U[i, i+1] = 1
        self.U[n-1, 0] = 1  # Periodic boundary
        
        self.V = np.diag([np.exp(2j * np.pi * theta * k / n) 
                          for k in range(n)])
    
    def verify_relation(self):
        """Verify UV = e^{2πiθ}VU approximately."""
        UV = self.U @ self.V
        VU = self.V @ self.U
        phase = np.exp(2j * np.pi * self.theta / self.n)
        error = np.linalg.norm(UV - phase * VU)
        return error
    
    def create_element(self, coefficients):
        """
        Create element from Fourier series: sum c_{m,n} U^m V^n
        coefficients: dict mapping (m, n) to complex coefficient
        """
        result = np.zeros((self.n, self.n), dtype=complex)
        U_pow = np.eye(self.n)
        
        # Precompute powers of U
        U_pows = [np.eye(self.n)]
        for _ in range(max((m for m, n in coefficients.keys()), default=0)):
            U_pows.append(U_pows[-1] @ self.U)
        
        V_pow = np.eye(self.n)
        max_n = max((n for m, n in coefficients.keys()), default=0)
        
        for n_power in range(max_n + 1):
            for (m_power, n_coeff), coeff in coefficients.items():
                if n_coeff == n_power:
                    # U^m V^n = e^{-2πiθmn} V^n U^m (careful with ordering)
                    phase = np.exp(-2j * np.pi * self.theta * m_power * n_power / self.n)
                    result += coeff * phase * U_pows[m_power] @ V_pow
            V_pow = V_pow @ self.V
        
        return result
    
    def dirac_operator(self, mass=0.1):
        """
        Construct a Dirac-type operator for the NC torus.
        D = ∂_1 + i∂_2 + mass term
        """
        # Derivatives: [∂_1, U] = U, [∂_1, V] = 0 (approximately)
        # Use finite difference approximation
        k = np.arange(self.n)
        eigenvalues = np.sqrt(k + mass**2)
        return np.diag(eigenvalues)

def spectral_action(D, f, Lambda):

    This is a key quantity in noncommutative geometry.
    """
    eigenvalues = eigvalsh(D)
    scaled = eigenvalues / Lambda
    return np.sum(f(scaled))

Ramsey Theory: Order from Chaos

Historical Context

Ramsey theory originated with Frank Ramsey's 1930 theorem proving that complete disorder is impossible in large structures. The field exploded in the 1930s with Erdős and Szekeres proving the party problem: among 6 people, there are always 3 mutual acquaintances or 3 mutual strangers. Ramsey theory now spans graph theory, number theory, geometry, and logic, embodying the principle that "complete disorder is impossible."

Definitions

Ramsey Number: \(R(s, t)\) is the smallest \(n\) such that every red-blue coloring of the edges of \(K_n\) contains either a red \(K_s\) or a blue \(K_t\).

Van der Waerden Number: \(W(k, r)\) is the smallest \(n\) such that every \(r\)-coloring of \(\{1, \ldots, n\}\) contains a monochromatic arithmetic progression of length \(k\).

Schur's Theorem: For any finite coloring of \(\mathbb{N}\), there exist monochromatic \(x, y, z\) with \(x + y = z\).

Theorem and Proof

Ramsey's Theorem (Graph Version): For all positive integers \(s, t\), the Ramsey number \(R(s, t)\) exists and satisfies: \[R(s, t) \leq R(s-1, t) + R(s, t-1)\]

Proof Sketch: Let \(n = R(s-1, t) + R(s, t-1)\). Consider any vertex \(v\) in a 2-colored \(K_n\). It has \(n-1\) neighbors, so either at least \(R(s-1, t)\) red edges or at least \(R(s, t-1)\) blue edges. In the first case, the red neighbors contain either a red \(K_{s-1}\) (giving red \(K_s\) with \(v\)) or a blue \(K_t\). The second case is symmetric. This gives the recurrence. Base cases: \(R(2, t) = t\) and \(R(s, 2) = s\).

Notation Guide

  • \(R(s, t)\) — Ramsey number for red \(K_s\) or blue \(K_t\)
  • \(K_n\) — complete graph on \(n\) vertices
  • \(W(k, r)\) — van der Waerden number
  • \(r_k(n)\) — size of largest subset of \(\{1, \ldots, n\}\) without \(k\)-term AP
  • \(\chi(G)\) — chromatic number of graph \(G\)

import numpy as np
import matplotlib.pyplot as plt
from itertools import combinations

class RamseyTheory:
    """Computational exploration of Ramsey theory."""
    
    @staticmethod
    def check_monochromatic_clique(adj_matrix, color, size):
        """
        Check if there's a monochromatic clique of given size and color.
        color: 0 or 1
        """
        n = len(adj_matrix)
        # Get subgraph of edges with the given color
        color_graph = (adj_matrix == color).astype(int)
        
        # Check all subsets of given size
        for subset in combinations(range(n), size):
            is_clique = True
            for i, j in combinations(subset, 2):
                if color_graph[i, j] == 0:
                    is_clique = False
                    break
            if is_clique:
                return True, subset
        return False, None
    
    @staticmethod
    def find_ramsey_certificate(n, s, t, max_attempts=1000):
        """
        Try to find a coloring of K_n with no red K_s and no blue K_t.
        Returns the coloring if found, None otherwise.
        """
        for attempt in range(max_attempts):
            # Random coloring
            adj = np.random.randint(0, 2, size=(n, n))
            adj = np.triu(adj, 1)  # Upper triangular
            adj = adj + adj.T      # Symmetric
            
            has_red, _ = RamseyTheory.check_monochromatic_clique(adj, 1, s)
            has_blue, _ = RamseyTheory.check_monochromatic_clique(adj, 0, t)
            
            if not has_red and not has_blue:
                return adj
        return None
    
    @staticmethod
    def van_der_waerden_check(coloring, k):
        """Check if coloring contains monochromatic k-term arithmetic progression."""
        n = len(coloring)
        for start in range(n):
            for diff in range(1, (n - start) // k + 1):
                ap = [start + i * diff for i in range(k)]
                if all(coloring[x] == coloring[start] for x in ap):
                    return True, ap
        return False, None
    
    @staticmethod
    def schur_partition(max_n, num_colors):
        """
        Find largest n such that [n] can be partitioned into num_colors 
        sum-free sets (no x + y = z in same set).
        """
        def is_sum_free(subset):
            s = set(subset)
            for x in subset:
                for y in subset:
                    if x + y in s:
                        return False
            return True
        
        # Greedy coloring attempt
        coloring = {}
        for n in range(1, max_n + 1):
            placed = False
            for color in range(num_colors):
                # Try placing n in this color
                color_set = [k for k, v in coloring.items() if v == color] + [n]
                if is_sum_free(color_set):
                    coloring[n] = color
                    placed = True
                    break
            if not placed:
                return n - 1, coloring
        return max_n, coloring

📜 Math History: The Development of Modern Algebra

The 19th century witnessed a profound transformation in mathematics, as the study of algebra shifted from solving equations to understanding abstract structures. This revolution, often called the "structural turn," began with the work of Évariste Galois and culminated in the axiomatic approach of Emmy Noether and her school.

In 1832, the twenty-year-old Évariste Galois lay dying from a duel wound. In his final hours, he wrote a letter to his friend Auguste Chevalier, sketching the connection between field extensions and groups of permutations. Galois had discovered that the solvability of a polynomial equation by radicals depends on the structure of its associated group—the Galois group. An equation is solvable by radicals if and only if its Galois group is solvable. This insight resolved centuries-old questions about the quintic equation, proving that general quintics cannot be solved by radicals.

Galois's work was nearly lost to history. His manuscripts were rejected or misunderstood by the Paris Academy, and only through the efforts of Liouville were they eventually published in 1846. By then, the seeds of modern algebra had been planted. In Germany, Richard Dedekind was developing the theory of ideals in rings of integers, seeking to restore unique factorization in algebraic number fields. His approach was structural: instead of asking whether a specific number is prime, he asked about the lattice of ideals containing it.

The late 19th century saw the emergence of group theory as an independent subject. Felix Klein's Erlangen Program of 1872 proposed that geometries could be classified by their transformation groups. Sophus Lie developed the theory of continuous transformation groups—now called Lie groups—to study differential equations. These developments showed that groups were not merely tools for studying equations but fundamental objects worthy of study in their own right.

The axiomatic approach reached its mature form in the early 20th century through the work of David Hilbert and Emmy Noether. Hilbert's Grundlagen der Geometrie (1899) showed that geometry could be built from purely logical axioms without appeal to intuition. Noether, who arrived in Göttingen in 1915, transformed algebra by emphasizing the importance of homomorphisms, ideals, and modules over calculations with explicit elements. Her famous theorem connecting symmetries and conservation laws in physics remains a cornerstone of theoretical physics.

By the 1930s, the structural approach had permeated all of mathematics. The publication of van der Waerden's Moderne Algebra in 1930 codified the new approach for a generation of mathematicians. Bourbaki's Éléments de mathématique, beginning in 1939, attempted to rebuild all of mathematics from set-theoretic foundations using the language of structures. Whether this program succeeded or went too far remains a subject of debate, but its influence on 20th-century mathematics is undeniable.

🎯 Problem Corner

Putnam Competition Problem (B5, 2003)

Problem: Let \(A, B,\) and \(C\) be equidistant points on the circumference of a circle of unit radius centered at \(O\), and let \(P\) be any point in the circle's interior. Let \(a, b, c\) be the distances from \(P\) to \(A, B, C\) respectively. Show that there exists a triangle with side lengths \(a, b, c\), and that its area depends only on the distance from \(P\) to \(O\).

💡 Hint

Use complex numbers with the circle as the unit circle. Place \(A, B, C\) at the cube roots of unity. Express \(a^2, b^2, c^2\) in terms of \(P\)'s complex coordinate. For the area, use Heron's formula and show that the expression simplifies to depend only on \(|P|\).

📖 Solution

Place \(O\) at the origin and let \(A, B, C\) be at \(1, \omega, \omega^2\) where \(\omega = e^{2\pi i/3}\). Let \(P\) be at complex coordinate \(z\) with \(|z| = r < 1\).

Then: \[a^2 = |z - 1|^2 = |z|^2 - z - \bar{z} + 1 = r^2 - 2\text{Re}(z) + 1\] \[b^2 = |z - \omega|^2 = r^2 - 2\text{Re}(\bar{\omega}z) + 1\] \[c^2 = |z - \omega^2|^2 = r^2 - 2\text{Re}(\omega z) + 1\]

To show a triangle exists, we verify the triangle inequalities. By symmetry, it suffices to check \(a + b > c\). Using the law of cosines in triangles \(OPA\) and \(OPB\), and noting that \(\angle APB = 120°\) when \(P = O\), continuity ensures the triangle inequality holds for all \(P\) in the disk.

For the area, use Heron's formula. Let \(s = (a+b+c)/2\). Then: \[16\cdot\text{Area}^2 = (a+b+c)(-a+b+c)(a-b+c)(a+b-c)\]

After extensive algebra (or using the formula for the area of a triangle given vertex coordinates), one finds: \[\text{Area} = \frac{3\sqrt{3}}{4}(1 - r^2)\]

This depends only on \(r = |OP|\), completing the proof. The maximum area \(\frac{3\sqrt{3}}{4}\) occurs at the center, and the area vanishes as \(P\) approaches the boundary.

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. It exhibits infinite complexity at all scales and connects to the bifurcation diagram of the logistic map.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for point c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring using log-log formula
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter
