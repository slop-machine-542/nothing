1. Riemannian Geometry: The Basics

Motivation

Riemannian geometry generalizes Euclidean geometry to curved spaces, providing the mathematical foundation for Einstein's general relativity. It allows us to measure distances, angles, and curvature on manifolds that locally resemble Euclidean space but may have complex global structure.

Definitions

Definition. A Riemannian manifold \((M, g)\) is a smooth manifold \(M\) equipped with a Riemannian metric \(g\), which is a smoothly varying inner product on each tangent space \(T_pM\).

In local coordinates \((x^1, \ldots, x^n)\), the metric is expressed as:

\[ds^2 = g_{ij} \, dx^i \, dx^j\]

where \(g_{ij} = g\left(\frac{\partial}{\partial x^i}, \frac{\partial}{\partial x^j}\right)\) are smooth functions.

Definition. The length of a curve \(\gamma: [a,b] \to M\) is:

\[L(\gamma) = \int_a^b \sqrt{g_{ij} \frac{d\gamma^i}{dt} \frac{d\gamma^j}{dt}} \, dt\]

Definition. The Levi-Civita connection \(\nabla\) is the unique torsion-free connection compatible with the metric, satisfying:

\[\nabla_k g_{ij} = 0\]

Theorem & Proof

Theorem. On any Riemannian manifold, there exists a unique Levi-Civita connection.

Proof Sketch. The connection coefficients (Christoffel symbols) are uniquely determined by:

\[\Gamma^k_{ij} = \frac{1}{2}g^{kl}\left(\partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij}\right)\]

These satisfy both metric compatibility and torsion-free conditions. ∎

Notation Guide

  • \(M\) — smooth manifold
  • \(g\) — Riemannian metric
  • \(T_pM\) — tangent space at point \(p\)
  • \(g_{ij}\) — metric tensor components
  • \(g^{ij}\) — inverse metric tensor
  • \(\Gamma^k_{ij}\) — Christoffel symbols
  • \(\nabla\) — covariant derivative

2. Gaussian Curvature

Motivation

Gaussian curvature measures how a surface curves in space. It is intrinsic—determinable by measurements within the surface itself—and fundamentally determines the geometry of two-dimensional manifolds.

Definitions

Definition. For a surface embedded in \(\mathbb{R}^3\), the Gaussian curvature at a point is:

\[K = \kappa_1 \cdot \kappa_2\]

where \(\kappa_1, \kappa_2\) are the principal curvatures (maximum and minimum normal curvatures).

Definition. In terms of the Riemann curvature tensor:

\[K = \frac{R_{1212}}{g_{11}g_{22} - g_{12}^2}\]

Theorem (Theorema Egregium). Gaussian curvature is intrinsic—it depends only on the metric \(g_{ij}\) and its derivatives, not on the embedding.

Example: Sphere of Radius \(R\)

For a sphere \(S^2(R)\), all normal curvatures equal \(1/R\), so:

\[K = \frac{1}{R} \cdot \frac{1}{R} = \frac{1}{R^2}\]

3. The Gauss-Bonnet Theorem

Motivation

The Gauss-Bonnet theorem connects local geometry (curvature) with global topology (Euler characteristic), revealing one of the deepest relationships in differential geometry.

Theorem

Gauss-Bonnet Theorem. For a compact, orientable surface \(M\) without boundary:

\[\int_M K \, dA = 2\pi \chi(M)\]

where \(\chi(M) = 2 - 2g\) is the Euler characteristic and \(g\) is the genus (number of "holes").

Proof Outline

The proof proceeds by triangulation:

  1. Triangulate \(M\) with geodesic triangles
  2. Apply the local Gauss-Bonnet formula to each triangle \(T\):
\[\int_T K \, dA + \sum_{i=1}^3 (\pi - \alpha_i) = 2\pi\]

where \(\alpha_i\) are interior angles.

  1. Sum over all triangles. Angle sums contribute \(2\pi V\), geodesic curvature terms cancel, and boundary terms vanish.
  2. Result: \(\int_M K \, dA = 2\pi(V - E + F) = 2\pi\chi(M)\). ∎

Significance

This theorem shows that the total curvature is a topological invariant. A sphere (\(\chi = 2\)) must have total curvature \(4\pi\), while a torus (\(\chi = 0\)) has total curvature zero.

1. The PageRank Algorithm

Motivation

PageRank, the foundation of Google's original search algorithm, uses eigenvector centrality to measure the importance of web pages based on the link structure of the internet.

Mathematical Model

Consider the web as a directed graph where pages are nodes and links are edges. Let \(N\) be the number of pages and \(L(p_j)\) the number of outbound links from page \(p_j\).

The PageRank \(PR(p_i)\) satisfies:

\[PR(p_i) = \frac{1-d}{N} + d \sum_{p_j \in B(p_i)} \frac{PR(p_j)}{L(p_j)}\]

where \(d \in (0,1)\) is the damping factor (typically \(d = 0.85\)) and \(B(p_i)\) is the set of pages linking to \(p_i\).

Matrix Formulation

Define the transition matrix \(P\) where \(P_{ji} = 1/L(p_j)\) if \(p_j\) links to \(p_i\), else 0. Then:

\[\mathbf{pr} = \frac{1-d}{N}\mathbf{1} + d P^T \mathbf{pr}\]

This is equivalent to finding the principal eigenvector of the Google matrix:

\[G = dP^T + \frac{1-d}{N}\mathbf{1}\mathbf{1}^T\]

Python Code

import numpy as np

def pagerank(adj_matrix, d=0.85, tol=1e-8, max_iter=1000):
    """
    Compute PageRank using power iteration.
    
    Parameters:
    -----------
    adj_matrix : numpy array
        Adjacency matrix where adj_matrix[i,j] = 1 if i links to j
    d : float
        Damping factor
    """
    N = adj_matrix.shape[0]
    
    # Create transition matrix (column stochastic)
    out_degrees = np.sum(adj_matrix, axis=1, keepdims=True)
    out_degrees[out_degrees == 0] = 1  # Handle dangling nodes
    P = adj_matrix.T / out_degrees  # Transpose for column stochastic
    
    # Initialize
    pr = np.ones(N) / N
    
    # Power iteration
    for _ in range(max_iter):
        pr_new = (1 - d) / N + d * P @ pr
        if np.linalg.norm(pr_new - pr) < tol:
            break
        pr = pr_new
    
    return pr

# Example: Small web graph
# Pages: 0, 1, 2, 3
# Links: 0→1, 0→2, 1→2, 1→3, 2→0, 3→2
adj = np.array([
    [0, 1, 1, 0],  # Page 0 links to 1, 2
    [0, 0, 1, 1],  # Page 1 links to 2, 3
    [1, 0, 0, 0],  # Page 2 links to 0
    [0, 0, 1, 0]   # Page 3 links to 2
])

pr = pagerank(adj)
print("PageRank values:", pr)
print("Ranking:", np.argsort(pr)[::-1])

2. Small World Networks

Motivation

The "small world" phenomenon—where most people are connected by short chains of acquaintances—was formalized by Watts and Strogatz (1998). Their model bridges regular lattices and random graphs.

The Watts-Strogatz Model

Start with a ring of \(N\) nodes, each connected to \(k\) nearest neighbors. With probability \(p\), rewire each edge to a random node.

Clustering coefficient (measure of local connectivity):

\[C = \frac{3(k-2)}{4(k-1)} \approx \frac{3}{4} \text{ for small } p\]

Average path length \(L(p)\) decreases rapidly with \(p\), while \(C(p)\) remains high for small \(p\).

Mathematical Properties

For the small-world regime (\(N \gg k \gg \ln N \gg 1\)):

\[L(p) \sim \frac{N}{k} f(pkN)\]

where \(f(x)\) is a scaling function. The characteristic path length scales logarithmically with \(N\) for random networks.

3. Centrality Measures

Motivation

Centrality measures identify the most important nodes in a network. Different applications require different notions of "importance."

Types of Centrality

Degree Centrality: Simply count connections.

\[C_D(v) = \frac{\deg(v)}{N-1}\]

Betweenness Centrality: Measures how often a node lies on shortest paths.

\[C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}\]

where \(\sigma_{st}\) is the number of shortest paths from \(s\) to \(t\), and \(\sigma_{st}(v)\) counts those passing through \(v\).

Eigenvector Centrality: A node is important if connected to important nodes.

\[\mathbf{x} = \frac{1}{\lambda} A \mathbf{x}\]

where \(A\) is the adjacency matrix and \(\lambda\) is the largest eigenvalue.

Closeness Centrality: Average distance to all other nodes.

\[C_C(v) = \frac{N-1}{\sum_{u \neq v} d(v,u)}\]

🎯 Special Topics: Surreal Numbers & Combinatorial Games

1. Construction of Surreal Numbers

Motivation

John Conway's surreal numbers, introduced in his book On Numbers and Games (1976), form a proper class containing all real numbers, all ordinal numbers, and infinitesimals. They are constructed recursively from nothing.

Definition

Definition. A surreal number is defined recursively as \(x = \{X_L | X_R\}\) where \(X_L\) and \(X_R\) are sets of previously constructed surreal numbers, with the condition that no element of \(X_L\) is \(\geq\) any element of \(X_R\).

Comparison: \(x \leq y\) iff no \(x^R \leq y\) and \(x \leq\) no \(y^L\).

Equality: \(x = y\) iff \(x \leq y\) and \(y \leq x\).

Construction by Birthdays

Day 0: \(0 = \{\,|\,\}\) (the empty game)

Day 1: \(1 = \{0|\,\}\), \(-1 = \{\,|0\}\)

Day 2: \(2 = \{1|\,\}\), \(\frac{1}{2} = \{0|1\}\), \(-2\), \(-\frac{1}{2}\)

Arithmetic Operations

Addition:

\[x + y = \{X_L + y, x + Y_L \,|\, X_R + y, x + Y_R\}\]

Negation:

\[-x = \{-X_R \,|\, -X_L\}\]

Multiplication: (more complex, defined recursively)

2. Combinatorial Game Theory

Motivation

Combinatorial Game Theory (CGT) analyzes two-player perfect-information games with no chance elements. Games decompose into sums of simpler components.

Definitions

A combinatorial game has:

  • Two players: Left and Right
  • Perfect information
  • No chance moves
  • Normal play convention: last player to move wins

Game Sum: Players move in exactly one component:

\[G + H = \{G^L + H, G + H^L \,|\, G^R + H, G + H^R\}\]

Outcome Classes

  • \(\mathcal{L}\): Left wins regardless of who moves first
  • \(\mathcal{R}\): Right wins regardless of who moves first
  • \(\mathcal{N}\): Next player wins (first player advantage)
  • \(\mathcal{P}\): Previous player wins (second player advantage)

3. Nimbers (Grundy Numbers)

Motivation

Nimbers provide a complete analysis of impartial games (where both players have the same moves). They were introduced by Sprague and Grundy independently in the 1930s.

Definition

Theorem (Sprague-Grundy). Every impartial game is equivalent to a Nim heap of some size.

The Grundy number (or nimber) of a position is:

\[G(P) = \text{mex}\{G(Q) : Q \text{ is reachable from } P\}\]

where \(\text{mex}\) (minimum excluded value) is the smallest non-negative integer not in the set.

Nim Sum

For game sums, Grundy numbers add under bitwise XOR:

\[G(P + Q) = G(P) \oplus G(Q)\]

Python Code

def mex(s):
    """Minimum excluded value."""
    m = 0
    while m in s:
        m += 1
    return m

def nim_sum(a, b):
    """Bitwise XOR (nim addition)."""
    return a ^ b

def grundy_nim(heap_sizes):
    """
    Calculate Grundy number for Nim position.
    Winning strategy: XOR of all heap sizes is non-zero.
    """
    result = 0
    for h in heap_sizes:
        result ^= h
    return result

# Example: Nim with heaps [3, 4, 5]
heaps = [3, 4, 5]
g = grundy_nim(heaps)
print(f"Grundy number: {g}")
print(f"First player wins: {g != 0}")

4. Hackenbush

Motivation

Hackenbush is the canonical example of a partisan combinatorial game. It provides geometric intuition for surreal numbers and demonstrates how games can have numerical values.

Rules

  • Draw a graph rooted at the "ground" (a horizontal line)
  • Edges are colored blue (Left), red (Right), or green (either)
  • On their turn, a player removes an edge of their color; any edges no longer connected to ground disappear
  • Last player to move wins

Values

A single blue edge above ground: value \(1\)

A single red edge above ground: value \(-1\)

A "stalk" of \(n\) blue edges: value \(n\)

The key insight: A position where Left has one blue edge and Right has one red edge both connected to ground has value:

\[\{1 \,|\, -1\} = 0\]

This is a second-player win!

Fascinating Values

A blue edge with a red edge above it: \(\{0 | 1\} = \frac{1}{2}\)

An infinite blue chain: value \(\omega\) (the first infinite ordinal)

📜 Math History: Bernhard Riemann (1826–1866)

Georg Friedrich Bernhard Riemann stands as one of the most influential mathematicians in history, despite a career cut tragically short by tuberculosis at age 39. Born in Breselenz, Hanover (now Germany), Riemann came from a modest Lutheran pastor's family and initially studied theology at the University of Göttingen to please his father. However, his fascination with mathematics, sparked by reading Legendre's Number Theory, led him to switch fields under the mentorship of Carl Friedrich Gauss.

Riemann's doctoral dissertation (1851) on complex function theory introduced what we now call Riemann surfaces—multi-sheeted surfaces that allow multi-valued functions like the complex logarithm to become single-valued. This geometric approach to analysis revolutionized the field and laid groundwork for modern topology. His habilitation lecture, "Über die Hypothesen, welche der Geometrie zu Grunde liegen" (On the Hypotheses Which Lie at the Foundations of Geometry), delivered in 1854, was nothing short of revolutionary. In this talk, Riemann generalized Euclidean geometry to spaces of arbitrary dimension with arbitrary curvature, introducing the concept of a manifold and the Riemannian metric. Einstein would later recognize this as exactly the mathematical framework needed for general relativity, some sixty years later.

In number theory, Riemann's 1859 paper "On the Number of Primes Less Than a Given Magnitude" introduced the Riemann zeta function and the famous Riemann Hypothesis—that all non-trivial zeros of \(\zeta(s)\) lie on the critical line \(\text{Re}(s) = \frac{1}{2}\). This conjecture remains one of the seven Millennium Prize Problems, with a million-dollar bounty for its resolution. The hypothesis connects the distribution of prime numbers to complex analysis in profound ways, and its proof would have far-reaching consequences for cryptography and number theory.

Riemann also made fundamental contributions to real analysis (the Riemann integral), differential equations (the Riemann problem), and mathematical physics. His work on shock waves and the Riemann-Roch theorem (connecting topology and algebraic geometry) continue to influence research today. Despite his short life and recurring health problems, Riemann's vision of geometry as the study of spaces with intrinsic structure transformed mathematics and physics, making him a true giant whose shoulders support much of modern science.

AIME-Level Problem

Problem. In triangle \(ABC\), \(AB = 13\), \(BC = 14\), and \(CA = 15\). Let \(D\), \(E\), and \(F\) be the feet of the altitudes from \(A\), \(B\), and \(C\) respectively. Find the area of triangle \(DEF\).

💡 Hint

First find the area of \(ABC\) using Heron's formula. Then recall that the orthic triangle (triangle formed by the feet of the altitudes) has area related to the original triangle's area and its circumradius. The key formula is:

\[[DEF] = 2R^2 \cos A \cos B \cos C \cdot \frac{[ABC]}{2R^2 \sin A \sin B \sin C} = [ABC] \cdot \frac{\cos A \cos B \cos C}{\sin A \sin B \sin C}\]

Or more simply: \([DEF] = [ABC](1 - \cos^2 A - \cos^2 B - \cos^2 C + 2\cos A \cos B \cos C)\).

✅ Solution

Step 1: Find the area of \(ABC\) using Heron's formula.

Semi-perimeter: \(s = \frac{13+14+15}{2} = 21\)

\[[ABC] = \sqrt{21 \cdot 8 \cdot 7 \cdot 6} = \sqrt{7056} = 84\]

Step 2: Find the circumradius \(R\).

\[R = \frac{abc}{4[ABC]} = \frac{13 \cdot 14 \cdot 15}{4 \cdot 84} = \frac{2730}{336} = \frac{65}{8}\]

Step 3: Use the formula for the orthic triangle area.

The vertices of the orthic triangle satisfy:

\[AE = c \cos A, \quad AF = b \cos A\]

Using the law of cosines:

\[\cos A = \frac{b^2+c^2-a^2}{2bc} = \frac{15^2+13^2-14^2}{2 \cdot 15 \cdot 13} = \frac{198}{390} = \frac{33}{65}\] \[\cos B = \frac{a^2+c^2-b^2}{2ac} = \frac{14^2+13^2-15^2}{2 \cdot 14 \cdot 13} = \frac{140}{364} = \frac{5}{13}\] \[\cos C = \frac{a^2+b^2-c^2}{2ab} = \frac{14^2+15^2-13^2}{2 \cdot 14 \cdot 15} = \frac{252}{420} = \frac{3}{5}\]

Step 4: Apply the orthic triangle area formula.

\[[DEF] = [ABC] \cdot 2\cos A \cos B \cos C\]

(This simplified formula holds for acute triangles.)

\[[DEF] = 84 \cdot 2 \cdot \frac{33}{65} \cdot \frac{5}{13} \cdot \frac{3}{5} = 84 \cdot 2 \cdot \frac{33 \cdot 3}{65 \cdot 13} = 84 \cdot \frac{198}{845}\] \[= \frac{16632}{845} = \frac{196}{5}\]

Wait—let's verify: \(16632/845 = 19.68...\) and \(196/5 = 39.2\). Let me recalculate.

Actually, the correct formula is:

\[[DEF] = [ABC] \cdot (1 - \cos^2 A - \cos^2 B - \cos^2 C + 2\cos A \cos B \cos C)\]

For acute triangles, this equals \([ABC] \cdot 2\cos A \cos B \cos C\) only when the triangle is right. Let's use:

\[[DEF] = \frac{2[ABC]^3}{a^2b^2c^2} \cdot (a^2+b^2+c^2) - ...\]

Alternative approach: The orthic triangle has sides \(a\cos A\), \(b\cos B\), \(c\cos C\) scaled appropriately. Actually:

\[EF = a \cos A = 14 \cdot \frac{33}{65} = \frac{462}{65}\]

Similarly for other sides. Using the formula:

\[[DEF] = [ABC] \cdot 2\cos A \cos B \cos C = 84 \cdot 2 \cdot \frac{33}{65} \cdot \frac{5}{13} \cdot \frac{3}{5}\] \[= 168 \cdot \frac{99}{845} = \frac{16632}{845}\]

Checking if this reduces: \(845 = 5 \cdot 13^2\), and \(16632 = 8 \cdot 2079 = 8 \cdot 9 \cdot 231 = 72 \cdot 231 = 72 \cdot 3 \cdot 77 = 216 \cdot 77 = 16632\). GCD\((16632, 845) = 1\).

Actually, the standard result is \([DEF] = 2R^2\sin(2A)\sin(2B)\sin(2C)\) or equivalently for acute triangles:

\[[DEF] = [ABC] \cdot \frac{r}{2R}\]

where \(r\) is the inradius. With \(r = [ABC]/s = 84/21 = 4\) and \(R = 65/8\):

\[[DEF] = 84 \cdot \frac{4}{2 \cdot 65/8} = 84 \cdot \frac{16}{65} = \frac{1344}{65}\]

Answer: \(\boxed{\dfrac{1344}{65}}\)

📊 Visualization of the Day

Gaussian curvature visualization on various surfaces. This Python code generates a 3D plot showing how curvature varies across a surface.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# Create a figure with multiple surfaces showing Gaussian curvature
def plot_surface_with_curvature():
    fig = plt.figure(figsize=(14, 4))
    
    # Surface 1: Sphere (constant positive curvature)
    ax1 = fig.add_subplot(131, projection='3d')
    u = np.linspace(0, 2 * np.pi, 50)
    v = np.linspace(0, np.pi, 50)
    u, v = np.meshgrid(u, v)
    r = 1
    x1 = r * np.sin(v) * np.cos(u)
    y1 = r * np.sin(v) * np.sin(u)
    z1 = r * np.cos(v)
    ax1.plot_surface(x1, y1, z1, cmap='Reds', alpha=0.8)
    ax1.set_title('Sphere: K = 1/R² > 0', fontsize=10)
    ax1.set_box_aspect([1,1,1])
    
    # Surface 2: Saddle (negative curvature)
    ax2 = fig.add_subplot(132, projection='3d')
    x2 = np.linspace(-2, 2, 50)
    y2 = np.linspace(-2, 2, 50)
    x2, y2 = np.meshgrid(x2, y2)
    z2 = x2**2 - y2**2  # Hyperbolic paraboloid
    ax2.plot_surface(x2, y2, z2, cmap='Blues', alpha=0.8)
    ax2.set_title('Saddle: K < 0', fontsize=10)
    ax2.set_box_aspect([1,1,0.5])
    
    # Surface 3: Cylinder (zero curvature)
    ax3 = fig.add_subplot(133, projection='3d')
    u3 = np.linspace(0, 2 * np.pi, 50)
    v3 = np.linspace(-1, 1, 50)
    u3, v3 = np.meshgrid(u3, v3)
    r3 = 1
    x3 = r3 * np.cos(u3)
    y3 = r3 * np.sin(u3)
    z3 = v3
    ax3.plot_surface(x3, y3, z3, cmap='Greens', alpha=0.8)
    ax3.set_title('Cylinder: K = 0', fontsize=10)
    ax3.set_box_aspect([1,1,1])
    
    plt.tight_layout()
    plt.savefig('gaussian_curvature.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    return fig
