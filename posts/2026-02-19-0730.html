1. Measure Theory and Lebesgue Integration

Measure theory provides the rigorous foundation for modern probability and analysis. It extends the notion of length, area, and volume to abstract spaces and pathological sets.

Theorem (Carathéodory Extension): Let \( \mathcal{A} \) be an algebra of subsets of \( X \) and \( \mu_0: \mathcal{A} \to [0, \infty] \) a premeasure. Then there exists a measure \( \mu \) on \( \sigma(\mathcal{A}) \) extending \( \mu_0 \). If \( \mu_0 \) is \( \sigma \)-finite, this extension is unique.
Proof Sketch: Define the outer measure \( \mu^*(E) = \inf\{\sum \mu_0(A_i) : E \subseteq \bigcup A_i, A_i \in \mathcal{A}\} \). A set \( E \) is Carathéodory measurable if \( \mu^*(A) = \mu^*(A \cap E) + \mu^*(A \cap E^c) \) for all \( A \). The collection of measurable sets forms a \( \sigma \)-algebra containing \( \mathcal{A} \), and \( \mu^* \) restricted to this \( \sigma \)-algebra is the desired measure.

Notation: A \( \sigma \)-algebra is closed under countable unions and complements. A measure satisfies \( \mu(\emptyset) = 0 \) and countable additivity: \( \mu(\bigcup E_i) = \sum \mu(E_i) \) for disjoint sets. The Lebesgue measure on \( \mathbb{R}^n \) extends the intuitive notion of volume.

# Python: Measure theory concepts and Lebesgue integration
import numpy as np
from scipy import integrate

def simple_function_integral(values, sets_measure):
    """
    Integral of a simple function: f = sum(a_i * 1_{E_i})
    Integral = sum(a_i * mu(E_i))
    """
    return sum(v * m for v, m in zip(values, sets_measure))

def lebesgue_approximation(f, a, b, n_partitions=1000):
    """
    Approximate Lebesgue integral by partitioning the range.
    Contrast with Riemann integration which partitions the domain.
    """
    # Sample function to find range
    x_samples = np.linspace(a, b, 10000)
    y_samples = f(x_samples)
    y_min, y_max = np.min(y_samples), np.max(y_samples)
    
    # Partition the range
    y_partitions = np.linspace(y_min, y_max, n_partitions)
    dy = (y_max - y_min) / n_partitions
    
    integral = 0
    for i in range(n_partitions):
        y_lower = y_partitions[i]
        y_upper = y_partitions[i + 1] if i + 1 < len(y_partitions) else y_max
        y_mid = (y_lower + y_upper) / 2
        
        # Measure of set where f is in [y_lower, y_upper)
        # Approximate by sampling
        in_range = ((y_samples >= y_lower) & (y_samples < y_upper))
        measure = np.mean(in_range) * (b - a)  # Approximate Lebesgue measure
        
        integral += y_mid * measure
    
    return integral

2. Spectral Theory of Operators

Spectral theory generalizes the eigenvalue decomposition of matrices to infinite-dimensional spaces. It underlies quantum mechanics, signal processing, and the study of differential equations.

Theorem (Spectral Theorem for Bounded Self-Adjoint Operators): Let \( H \) be a Hilbert space and \( T: H \to H \) a bounded self-adjoint operator. Then there exists a unique spectral measure \( E \) such that: \[ T = \int_{\sigma(T)} \lambda \, dE(\lambda) \] where \( \sigma(T) \) is the spectrum of \( T \). Moreover, \( T \) is unitarily equivalent to a multiplication operator on some \( L^2 \) space.
Proof Sketch: (1) Define the continuous functional calculus: for \( f \in C(\sigma(T)) \), define \( f(T) \) via polynomial approximation. (2) Use the Riesz representation theorem to extend to bounded Borel functions, obtaining the spectral measure \( E \). (3) For the multiplication operator representation, take \( \phi \in H \) cyclic for \( T \); then \( U: L^2(\sigma(T), \mu_\phi) \to H \) defined by \( U(f) = f(T)\phi \) is unitary and conjugates multiplication by \( \lambda \) to \( T \).

Notation: The spectrum \( \sigma(T) = \{\lambda : T - \lambda I \text{ is not invertible}\} \). An operator is self-adjoint if \( \langle Tx, y \rangle = \langle x, Ty \rangle \). The spectral measure \( E \) assigns projection operators to measurable sets.

# Python: Spectral theory and eigenvalue computations
import numpy as np
from numpy.linalg import eig, eigh, svd

def power_iteration(A, num_iterations=1000, tol=1e-10):
    """
    Power iteration to find dominant eigenvalue/vector.
    Converges to eigenvector for largest |eigenvalue|.
    """
    n = A.shape[0]
    v = np.random.randn(n)
    v = v / np.linalg.norm(v)
    
    for _ in range(num_iterations):
        Av = A @ v
        v_new = Av / np.linalg.norm(Av)
        
        if np.linalg.norm(v_new - v) < tol:
            break
        v = v_new
    
    # Rayleigh quotient for eigenvalue
    eigenvalue = (v @ A @ v) / (v @ v)
    return eigenvalue, v

def inverse_iteration(A, mu, num_iterations=100):
    """
    Inverse iteration to find eigenvalue closest to mu.
    """
    n = A.shape[0]
    v = np.random.randn(n)
    v = v / np.linalg.norm(v)
    
    for _ in range(num_iterations):
        # Solve (A - mu*I) w = v
        w = np.linalg.solve(A - mu * np.eye(n), v)
        v = w / np.linalg.norm(w)
    
    eigenvalue = (v @ A @ v) / (v @ v)
    return eigenvalue, v

def qr_algorithm(A, num_iterations=100):
    """
    QR algorithm for finding all eigenvalues.
    """
    n = A.shape[0]
    Ak = A.copy()
    
    for _ in range(num_iterations):
        Q, R = np.linalg.qr(Ak)
        Ak = R @ Q
    
    # Eigenvalues are on diagonal
    return np.diag(Ak)

3. Algebraic Combinatorics and Generating Functions

Generating functions encode sequences as coefficients of formal power series, transforming combinatorial problems into algebraic and analytic ones.

Theorem (Lagrange Inversion): Let \( \phi(u) \) be a formal power series with \( \phi(0) \neq 0 \). If \( y = x\phi(y) \), then the coefficient of \( x^n \) in \( y \) is: \[ [x^n]y = \frac{1}{n}[u^{n-1}]\phi(u)^n \] More generally, for any formal power series \( F \): \[ [x^n]F(y) = \frac{1}{n}[u^{n-1}]F'(u)\phi(u)^n \]
Proof: Consider the residue \( [x^n]y = \frac{1}{2\pi i} \oint \frac{y}{x^{n+1}} dx \). Substitute \( x = y/\phi(y) \), so \( dx = \frac{\phi(y) - y\phi'(y)}{\phi(y)^2} dy \). The contour transforms appropriately, and: \[ [x^n]y = \frac{1}{2\pi i} \oint \frac{y \cdot \phi(y)^{n+1}}{y^{n+1}} \cdot \frac{\phi(y) - y\phi'(y)}{\phi(y)^2} dy = \frac{1}{n}[y^{n-1}]\phi(y)^n \] by extracting the coefficient.

Notation: \( [x^n]f(x) \) denotes the coefficient of \( x^n \) in \( f \). The ordinary generating function (OGF) is \( F(x) = \sum a_n x^n \); the exponential generating function (EGF) is \( F(x) = \sum a_n \frac{x^n}{n!} \).

# Symbolic polynomial operations
def poly_mult(p, q, max_degree=None):
    """Multiply polynomials p and q."""
    result = {}
    for i, a in p.items():
        for j, b in q.items():
            if max_degree is None or i + j <= max_degree:
                result[i + j] = result.get(i + j, 0) + a * b
    return result

def poly_pow(p, n, max_degree):
    """Compute p^n truncated to max_degree."""
    if n == 0:
        return {0: 1}
    if n == 1:
        return {k: v for k, v in p.items() if k <= max_degree}
    
    half = poly_pow(p, n // 2, max_degree)
    result = poly_mult(half, half, max_degree)
    if n % 2 == 1:
        result = poly_mult(result, p, max_degree)
    return result

def extract_coeff(poly, n):
    """Extract coefficient of x^n."""
    return poly.get(n, 0)

def partition_number(n):
    """Compute p(n) using Euler's pentagonal theorem."""
    if n < 0:
        return 0
    if n == 0:
        return 1
    
    p = [0] * (n + 1)
    p[0] = 1
    
    for i in range(1, n + 1):
        total = 0
        k = 1
        while True:
            pent = k * (3*k - 1) // 2
            if pent > i:
                break
            sign = (-1)**(k + 1)
            total += sign * p[i - pent]
            
            pent = k * (3*k + 1) // 2
            if pent > i:
                break
            total += sign * p[i - pent]
            k += 1
        p[i] = total
    
    return p[n]

1. Representation Theory and Applications

Representation theory studies abstract algebraic structures by representing their elements as linear transformations of vector spaces. It bridges algebra, analysis, and physics.

Theorem (Maschke's Theorem): Let \( G \) be a finite group and \( F \) a field whose characteristic does not divide \( |G| \). Then every representation of \( G \) over \( F \) is completely reducible (semisimple). Equivalently, the group algebra \( F[G] \) is semisimple.
Proof: Given a subrepresentation \( W \subseteq V \), we construct a complementary invariant subspace. Let \( \pi: V \to W \) be any projection. Define \( \tilde{\pi}(v) = \frac{1}{|G|} \sum_{g \in G} g \cdot \pi(g^{-1} \cdot v) \). Then \( \tilde{\pi} \) is a \( G \)-equivariant projection. The kernel of \( \tilde{\pi} \) is a complementary invariant subspace, proving complete reducibility.

Notation: A representation is a homomorphism \( \rho: G \to GL(V) \). A subspace \( W \subseteq V \) is invariant if \( \rho(g)(W) \subseteq W \) for all \( g \in G \). An irreducible representation has no nontrivial invariant subspaces. The character \( \chi_\rho(g) = \text{tr}(\rho(g)) \) encodes representation data.

# Python: Representation theory computations
import numpy as np
from itertools import permutations

def regular_representation(group_elements):
    """
    Left regular representation of a finite group.
    Each group element acts by left multiplication.
    """
    n = len(group_elements)
    index = {g: i for i, g in enumerate(group_elements)}
    
    representations = {}
    for g in group_elements:
        # Matrix of left multiplication by g
        mat = np.zeros((n, n))
        for i, h in enumerate(group_elements):
            gh = tuple(g[i] for i in range(len(g))) if isinstance(g, tuple) else g * h
            # For permutation groups
            if isinstance(g, tuple) and isinstance(h, tuple):
                gh = tuple(g[h[i]-1] if h[i] <= len(g) else h[i] for i in range(len(h)))
            j = index.get(gh, i)  # Simplified
            mat[j, i] = 1
        representations[g] = mat
    
    return representations

def symmetric_group_s3():

def permutation_matrix(perm, n):
    """Matrix representing permutation."""
    P = np.zeros((n, n))
    for i, p in enumerate(perm):
        P[p-1, i] = 1
    return P

2. Numerical Linear Algebra and Iterative Methods

Modern scientific computing relies on efficient algorithms for solving large linear systems. Iterative methods are essential when direct methods are too expensive.

Theorem (Convergence of Conjugate Gradient): Let \( A \) be symmetric positive definite. The conjugate gradient method converges to the exact solution of \( Ax = b \) in at most \( n \) iterations (in exact arithmetic). The error satisfies: \[ \|x_k - x_*\|_A \leq 2 \left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^k \|x_0 - x_*\|_A \] where \( \kappa = \lambda_{\max}/\lambda_{\min} \) is the condition number and \( \|v\|_A = \sqrt{v^T A v} \).
Proof Sketch: CG constructs A-conjugate search directions \( \{p_i\} \) such that \( p_i^T A p_j = 0 \) for \( i \neq j \). The iterate \( x_k \) minimizes \( \|x - x_*\|_A \) over the Krylov subspace \( \mathcal{K}_k(A, b) = \text{span}\{b, Ab, A^2b, \ldots, A^{k-1}b\} \). The error bound follows from Chebyshev polynomial approximation: the error polynomial \( e_k(A) \) must satisfy \( e_k(0) = 1 \) and minimize \( \max_{\lambda \in \sigma(A)} |e_k(\lambda)| \).

Notation: A Krylov subspace is \( \mathcal{K}_k(A, r_0) = \text{span}\{r_0, Ar_0, A^2r_0, \ldots, A^{k-1}r_0\} \). The energy norm \( \|x\|_A = \sqrt{x^T A x} \). A-conjugate vectors satisfy \( p_i^T A p_j = 0 \).

# Python: Iterative methods for linear systems
import numpy as np

def conjugate_gradient(A, b, x0=None, max_iter=None, tol=1e-10):
    """
    Conjugate Gradient method for solving Ax = b.
    A must be symmetric positive definite.
    """
    n = len(b)
    if x0 is None:
        x = np.zeros(n)
    else:
        x = x0.copy()
    
    if max_iter is None:
        max_iter = n
    
    r = b - A @ x  # Residual
    p = r.copy()   # Search direction
    rs_old = np.dot(r, r)
    
    residuals = [np.sqrt(rs_old)]
    
    for i in range(max_iter):
        Ap = A @ p
        alpha = rs_old / np.dot(p, Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = np.dot(r, r)
        
        residuals.append(np.sqrt(rs_new))
        
        if np.sqrt(rs_new) < tol:
            break
        
        p = r + (rs_new / rs_old) * p
        rs_old = rs_new
    
    return x, residuals

def gmres(A, b, x0=None, max_iter=None, tol=1e-10):
    """
    GMRES (Generalized Minimal Residual) for general matrices.
    Minimizes ||Ax - b|| over Krylov subspace.
    """
    n = len(b)
    if x0 is None:
        x = np.zeros(n)
    else:
        x = x0.copy()
    
    if max_iter is None:
        max_iter = n
    
    r = b - A @ x
    beta = np.linalg.norm(r)
    
    # Arnoldi iteration to build orthonormal basis for Krylov subspace
    V = np.zeros((n, max_iter + 1))
    H = np.zeros((max_iter + 1, max_iter))
    
    V[:, 0] = r / beta
    
    residuals = [beta]
    
    for j in range(max_iter):
        # Arnoldi step
        w = A @ V[:, j]
        for i in range(j + 1):
            H[i, j] = np.dot(w, V[:, i])
            w = w - H[i, j] * V[:, i]
        
        H[j + 1, j] = np.linalg.norm(w)
        if H[j + 1, j] < tol:
            max_iter = j + 1
            break
        
        V[:, j + 1] = w / H[j + 1, j]
        
        # Solve least squares problem for y
        # Minimize ||beta*e_1 - H*y||
        e1 = np.zeros(j + 2)
        e1[0] = beta
        y, _, _, _ = np.linalg.lstsq(H[:j+2, :j+1], e1, rcond=None)
        
        # Compute residual
        x_new = x + V[:, :j+1] @ y
        residual = np.linalg.norm(b - A @ x_new)
        residuals.append(residual)
        
        if residual < tol:
            x = x_new
            break
    
    return x, residuals

def jacobi_iteration(A, b, x0=None, max_iter=1000, tol=1e-10):
    """Jacobi iteration: diagonal preconditioning."""
    n = len(b)
    if x0 is None:
        x = np.zeros(n)
    else:
        x = x0.copy()
    
    D = np.diag(np.diag(A))
    D_inv = np.diag(1.0 / np.diag(A))
    R = A - D
    
    residuals = []
    
    for _ in range(max_iter):
        x_new = D_inv @ (b - R @ x)
        residual = np.linalg.norm(b - A @ x_new)
        residuals.append(residual)
        
        if residual < tol:
            x = x_new
            break
        
        x = x_new
    
    return x, residuals

3. Optimal Control Theory

Optimal control seeks control strategies that minimize cost functions while satisfying dynamical constraints. It bridges calculus of variations, optimization, and dynamical systems.

Theorem (Pontryagin's Maximum Principle): Consider the optimal control problem: minimize \( J = \int_0^T L(x(t), u(t)) dt + \Phi(x(T)) \) subject to \( \dot{x} = f(x, u) \), \( x(0) = x_0 \). If \( u^* \) is optimal with trajectory \( x^* \), there exists a costate \( p(t) \) such that: \[ \dot{x}^* = f(x^*, u^*), \quad x^*(0) = x_0 \] \[ \dot{p} = -\frac{\partial H}{\partial x}, \quad p(T) = \frac{\partial \Phi}{\partial x}(x^*(T)) \] \[ u^*(t) = \arg\min_u H(x^*(t), p(t), u) \] where \( H(x, p, u) = L(x, u) + p^T f(x, u) \) is the Hamiltonian.
Proof Sketch: Introduce Lagrange multipliers \( p(t) \) for the dynamics constraint. The augmented cost is \( \tilde{J} = \Phi(x(T)) + \int_0^T [L + p^T(f - \dot{x})] dt \). Integration by parts gives \( \tilde{J} = \Phi(x(T)) - p(T)^T x(T) + p(0)^T x_0 + \int_0^T [H + \dot{p}^T x] dt \). Variation with respect to \( x \) yields the costate equation. The optimality condition follows from pointwise minimization of \( H \).

Notation: The Hamiltonian \( H = L + p^T f \) combines running cost and dynamics. The costate \( p \) is the Lagrange multiplier for the dynamics. Transversality conditions specify boundary conditions for \( p \).

# Python: Optimal control computations
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import minimize

def solve_lqr(A, B, Q, R, T, x0):
    """
    Solve Linear Quadratic Regulator (LQR) problem.
    Minimize: ∫(x^T Q x + u^T R u)dt + x(T)^T Q_f x(T)
    Subject to: dx/dt = Ax + Bu
    
    Solution involves solving Riccati differential equation backward.
    """
    n = A.shape[0]
    m = B.shape[1]
    
    # Solve differential Riccati equation backward
    # dP/dt = -A^T P - P A + P B R^{-1} B^T P - Q, P(T) = Q_f
    def riccati_ode(t, P_flat):
        P = P_flat.reshape(n, n)
        dP = -A.T @ P - P @ A + P @ B @ np.linalg.inv(R) @ B.T @ P - Q
        return dP.flatten()
    
    # Integrate backward from T to 0
    P_T = Q.flatten()  # Terminal cost
    sol = solve_ivp(riccati_ode, [T, 0], P_T, t_eval=np.linspace(T, 0, 100))
    
    return sol

def lqr_controller(A, B, Q, R, x0, T, dt=0.01):
    """
    Compute LQR optimal control and trajectory.
    """
    n = A.shape[0]
    m = B.shape[1]
    
    # Solve algebraic Riccati equation for infinite horizon
    from scipy.linalg import solve_continuous_are
    P = solve_continuous_are(A, B, Q, R)
    
    # Optimal feedback gain
    K = np.linalg.inv(R) @ B.T @ P
    
    # Simulate closed-loop system
    t = np.arange(0, T, dt)
    x = np.zeros((len(t), n))
    u = np.zeros((len(t), m))
    x[0] = x0
    
    for i in range(len(t) - 1):
        u[i] = -K @ x[i]
        dx = (A @ x[i] + B @ u[i]) * dt
        x[i + 1] = x[i] + dx
    
    u[-1] = -K @ x[-1]
    
    return t, x, u, K

1. Bayesian Statistics and MCMC

Bayesian statistics treats parameters as random variables with prior distributions, updating beliefs via Bayes' theorem. MCMC methods enable sampling from complex posterior distributions.

Theorem (Bayes' Theorem): Given prior \( \pi(\theta) \) and likelihood \( p(x|\theta) \), the posterior distribution is: \[ \pi(\theta|x) = \frac{p(x|\theta)\pi(\theta)}{\int p(x|\theta')\pi(\theta') d\theta'} \propto p(x|\theta)\pi(\theta) \]
Theorem (Metropolis-Hastings): Let \( q(\theta'|\theta) \) be a proposal distribution. Starting from \( \theta^{(0)} \), iterate: (1) Sample \( \theta' \sim q(\cdot|\theta^{(t)}) \). (2) Accept with probability \( \alpha = \min\left(1, \frac{\pi(\theta'|x)q(\theta^{(t)}|\theta')}{\pi(\theta^{(t)}|x)q(\theta'|\theta^{(t)})}\right) \). The resulting Markov chain converges to the posterior \( \pi(\theta|x) \).
Proof of Detailed Balance: The MH algorithm satisfies detailed balance with respect to \( \pi(\theta|x) \): \[ \pi(\theta|x)P(\theta \to \theta') = \pi(\theta'|x)P(\theta' \to \theta) \] where \( P \) is the transition kernel. This implies \( \pi \) is the stationary distribution. Convergence follows from ergodicity of the chain.

Notation: The prior \( \pi(\theta) \) encodes beliefs before seeing data. The posterior \( \pi(\theta|x) \) updates these beliefs. A conjugate prior yields a posterior in the same family as the prior.

# Python: Bayesian statistics and MCMC
import numpy as np
from scipy import stats

def metropolis_hastings(log_posterior, initial, n_samples, proposal_scale=0.1):
    """
    Metropolis-Hastings MCMC sampler.
    log_posterior: function computing log posterior (up to constant)
    initial: starting point
    """
    samples = [initial]
    current = initial
    current_log_prob = log_posterior(current)
    accepts = 0
    
    for _ in range(n_samples):
        # Propose new sample
        proposal = current + np.random.randn(len(current)) * proposal_scale
        proposal_log_prob = log_posterior(proposal)
        
        # Accept/reject
        log_alpha = proposal_log_prob - current_log_prob
        if np.log(np.random.rand()) < log_alpha:
            current = proposal
            current_log_prob = proposal_log_prob
            accepts += 1
        
        samples.append(current.copy())
    
    return np.array(samples), accepts / n_samples

def gibbs_sampler(conditional_samplers, initial, n_samples):
    """
    Gibbs sampler: sample from conditionals.
    conditional_samplers: list of functions, each samples one variable given others
    """
    samples = [initial]
    current = initial.copy()
    
    for _ in range(n_samples):
        for i, sampler in enumerate(conditional_samplers):
            current[i] = sampler(current, i)
        samples.append(current.copy())
    
    return np.array(samples)

2. Commutative Algebra and Algebraic Geometry

The correspondence between algebra and geometry, formalized in the work of Hilbert and Grothendieck, allows geometric problems to be solved algebraically and vice versa.

Theorem (Hilbert's Nullstellensatz): Let \( k \) be an algebraically closed field and \( I \subseteq k[x_1, \ldots, x_n] \) an ideal. Then \( I(V(I)) = \sqrt{I} \), where \( V(I) = \{x \in k^n : f(x) = 0 \text{ for all } f \in I\} \) and \( \sqrt{I} = \{f : f^m \in I \text{ for some } m\} \) is the radical.
Theorem (Hilbert's Basis Theorem): If \( R \) is a Noetherian ring, then \( R[x] \) is Noetherian. Consequently, \( k[x_1, \ldots, x_n] \) is Noetherian for any field \( k \).
Proof of Nullstellensatz (Weak Form): The weak form states that maximal ideals of \( k[x_1, \ldots, x_n] \) correspond to points: \( \mathfrak{m}_a = (x_1 - a_1, \ldots, x_n - a_n) \). Proof uses Noether normalization and the fact that finite field extensions of algebraically closed fields are trivial. The strong form follows by applying the weak form to the ideal \( (I, 1 - yf) \) in \( k[x_1, \ldots, x_n, y] \).

Notation: An ideal is radical if \( \sqrt{I} = I \). A ring is Noetherian if every ascending chain of ideals stabilizes (equivalently, every ideal is finitely generated). Affine space \( \mathbb{A}^n \) is \( k^n \) with the Zariski topology.

3. Information Geometry

Information geometry applies differential geometric techniques to probability and statistics, treating statistical manifolds as Riemannian manifolds with the Fisher information metric.

Theorem (Cramér-Rao Bound): Let \( \hat{\theta} \) be an unbiased estimator of \( \theta \) based on observations from \( p(x|\theta) \). Then: \[ \text{Cov}(\hat{\theta}) \succeq I(\theta)^{-1} \] where \( I(\theta) = E[\nabla_\theta \log p(x|\theta) \nabla_\theta \log p(x|\theta)^T] \) is the Fisher information matrix and \( \succeq \) denotes the Loewner order.
Theorem (Fisher Metric): The Fisher information matrix defines a Riemannian metric on the statistical manifold: \[ g_{ij}(\theta) = E\left[\frac{\partial \log p}{\partial \theta_i} \frac{\partial \log p}{\partial \theta_j}\right] = -E\left[\frac{\partial^2 \log p}{\partial \theta_i \partial \theta_j}\right] \] Geodesics with respect to this metric correspond to minimum discrimination paths.
Proof of Cramér-Rao: Let \( s = \nabla_\theta \log p(x|\theta) \) be the score function. Then \( E[s] = 0 \) and \( \text{Cov}(s) = I(\theta) \). For unbiased \( \hat{\theta} \), we have \( \text{Cov}(\hat{\theta}, s) = I \). The covariance matrix of \( (\hat{\theta}, s) \) is \( \begin{pmatrix} \text{Cov}(\hat{\theta}) & I \\ I & I(\theta) \end{pmatrix} \succeq 0 \). Schur complement gives \( \text{Cov}(\hat{\theta}) - I(\theta)^{-1} \succeq 0 \).

Notation: The score function \( s = \nabla \log p \) has mean zero. The Fisher metric makes the statistical manifold a Riemannian manifold. Amari's α-connections generalize the Levi-Civita connection.

# Python: Information geometry computations
import numpy as np
from scipy import stats
from scipy.optimize import minimize

def fisher_information_gaussian(mu, sigma):
    """
    Fisher information matrix for N(mu, sigma²).
    """
    # For Gaussian, Fisher information is:
    # I_mu,mu = 1/sigma²
    # I_sigma,sigma = 2/sigma²
    # I_mu,sigma = 0
    I = np.array([[1/sigma**2, 0],
                  [0, 2/sigma**2]])
    return I

def fisher_information_bernoulli(p):
    """Fisher information for Bernoulli(p)."""
    return 1 / (p * (1 - p))

def kl_divergence_gaussian(mu1, sigma1, mu2, sigma2):
    """KL divergence between two Gaussians."""
    return np.log(sigma2/sigma1) + (sigma1**2 + (mu1 - mu2)**2)/(2*sigma2**2) - 0.5

def natural_gradient(f, grad_f, theta0, fisher_fn, lr=0.01, n_iter=100):
    """
    Natural gradient descent using Fisher information.
    Update: theta_{t+1} = theta_t - lr * I(theta)^{-1} ∇f(theta)
    """
    theta = theta0.copy()
    trajectory = [theta.copy()]
    
    for _ in range(n_iter):
        grad = grad_f(theta)
        I = fisher_fn(theta[0], theta[1])
        I_inv = np.linalg.inv(I)
        
        # Natural gradient
        ng = I_inv @ grad
        theta = theta - lr * ng
        trajectory.append(theta.copy())
    
    return np.array(trajectory)

4. Arithmetic Geometry and Diophantine Equations

Arithmetic geometry studies solutions to polynomial equations over number fields and finite fields, connecting number theory with algebraic geometry.

Theorem (Mordell-Weil for Elliptic Curves): The group of rational points \( E(\mathbb{Q}) \) on an elliptic curve is finitely generated. That is, \( E(\mathbb{Q}) \cong \mathbb{Z}^r \oplus E(\mathbb{Q})_{\text{tors}} \) where \( r \) is the rank and the torsion subgroup is finite.
Theorem (Hasse-Weil Bound): Let \( E \) be an elliptic curve over \( \mathbb{F}_q \). Then: \[ |\#E(\mathbb{F}_q) - (q + 1)| \leq 2\sqrt{q} \] This bound is a consequence of the Riemann hypothesis for curves over finite fields, proved by Weil.
Proof Sketch (Hasse Bound): Let \( \phi: E \to E \) be the Frobenius endomorphism \( (x, y) \mapsto (x^q, y^q) \). Then \( \#E(\mathbb{F}_q) = \#\ker(1 - \phi) = \deg(1 - \phi) \). The degree map on endomorphisms is a positive definite quadratic form. Writing \( a = q + 1 - \#E(\mathbb{F}_q) \), the positivity of \( \deg(m + n\phi) \) for all integers \( m, n \) yields \( |a| \leq 2\sqrt{q} \).

Notation: An elliptic curve over a field \( k \) is a smooth projective curve of genus 1 with a distinguished point. The Frobenius map raises coordinates to the \( q \)-th power. The zeta function of a curve encodes point counts over all finite extensions.

# Python: Arithmetic geometry and elliptic curves over finite fields
import numpy as np

def mod_inverse(a, p):
    """Compute modular inverse using extended Euclidean algorithm."""
    def extended_gcd(a, b):
        if a == 0:
            return b, 0, 1
        gcd, x1, y1 = extended_gcd(b % a, a)
        x = y1 - (b // a) * x1
        y = x1
        return gcd, x, y
    
    _, x, _ = extended_gcd(a % p, p)
    return (x % p + p) % p

class EllipticCurveFiniteField:
    """Elliptic curve y² = x³ + ax + b over F_p."""
    
    def __init__(self, a, b, p):
        self.a = a
        self.b = b
        self.p = p
        
        # Check discriminant
        discriminant = (-16 * (4 * a**3 + 27 * b**2)) % p
        if discriminant == 0:
            raise ValueError("Curve is singular")
    
    def is_on_curve(self, x, y):
        """Check if point (x,y) is on curve."""
        if x is None and y is None:  # Point at infinity
            return True
        lhs = (y * y) % self.p
        rhs = (x**3 + self.a * x + self.b) % self.p
        return lhs == rhs
    
    def add_points(self, P, Q):
        """Add two points on the curve."""
        # Point at infinity is identity
        if P == (None, None):
            return Q
        if Q == (None, None):
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # P + (-P) = O
        if x1 == x2 and (y1 + y2) % self.p == 0:
            return (None, None)
        
        # Compute slope
        if x1 == x2:
            # Point doubling
            num = (3 * x1**2 + self.a) % self.p
            den = (2 * y1) % self.p
        else:
            # Distinct points
            num = (y2 - y1) % self.p
            den = (x2 - x1) % self.p
        
        slope = (num * mod_inverse(den, self.p)) % self.p
        
        x3 = (slope**2 - x1 - x2) % self.p
        y3 = (slope * (x1 - x3) - y1) % self.p
        
        return (x3, y3)
    
    def scalar_mult(self, k, P):
        """Compute k*P using double-and-add."""
        if k == 0:
            return (None, None)
        if k < 0:
            x, y = P
            neg_P = (x, (-y) % self.p)
            return self.scalar_mult(-k, neg_P)
        
        result = (None, None)
        addend = P
        
        while k > 0:
            if k & 1:
                result = self.add_points(result, addend)
            addend = self.add_points(addend, addend)
            k >>= 1
        
        return result
    
    def count_points(self):
        """Count points on curve over F_p (naive)."""
        count = 1  # Point at infinity
        for x in range(self.p):
            rhs = (x**3 + self.a * x + self.b) % self.p
            # Count square roots
            for y in range(self.p):
                if (y * y) % self.p == rhs:
                    count += 1
        return count

The Legacy of Andrey Kolmogorov

This week marks the anniversary of Andrey Kolmogorov's contributions to probability theory. In 1933, Kolmogorov published his foundational work axiomatizing probability using measure theory. This unified approach connected probability with analysis and set the stage for modern stochastic processes. His later work on turbulence, algorithmic complexity, and dynamical systems demonstrated extraordinary breadth.

The Development of Measure Theory

In the early 20th century, Henri Lebesgue revolutionized integration theory with his 1902 doctoral thesis. Dissatisfied with the limitations of Riemann integration, Lebesgue developed a theory based on measuring sets rather than partitioning intervals. This seemingly technical advance enabled the rigorous development of functional analysis, probability theory, and ergodic theory. The Lebesgue integral could handle limits of functions in ways the Riemann integral could not, making it indispensable for modern analysis.
