Field Theory: Understanding Algebraic Extensions

field-theory

Motivation

Field theory studies the structure of fields—sets where addition, subtraction, multiplication, and division (except by zero) behave as we expect. The theory emerged from attempts to understand when polynomial equations can be solved by radicals, leading to the magnificent edifice of Galois theory. Beyond its foundational role, field theory provides the foundation for algebraic geometry, number theory, and coding theory. The study of field extensions reveals deep connections between algebra and geometry, showing how geometric constructions relate to algebraic properties.

Definitions

  • Field: A set \(F\) with two operations \(+\) and \(\cdot\) satisfying field axioms: associativity, commutativity, distributivity, existence of identity elements (0 and 1), and existence of additive and multiplicative inverses.
  • Field Extension: If \(F \subseteq E\) are fields, we call \(E/F\) a field extension. The degree \([E:F]\) is the dimension of \(E\) as a vector space over \(F\).
  • Algebraic Element: An element \(\alpha \in E\) is algebraic over \(F\) if there exists a non-zero polynomial \(f(x) \in F[x]\) with \(f(\alpha) = 0\).
  • Minimal Polynomial: The monic polynomial of smallest degree in \(F[x]\) having \(\alpha\) as a root.
  • Splitting Field: An extension field where a given polynomial factors completely into linear factors.
  • Algebraic Closure: A field extension that is algebraically closed (every non-constant polynomial has a root) and algebraic over the base field.

Theorem: Tower Law

Theorem (Tower Law): Let \(F \subseteq K \subseteq E\) be field extensions. Then:

\[[E:F] = [E:K] \cdot [K:F]\]

In particular, if both \([E:K]\) and \([K:F]\) are finite, then so is \([E:F]\).

Proof

Let \(\{\alpha_1, \ldots, \alpha_m\}\) be a basis for \(K\) over \(F\) and \(\{\beta_1, \ldots, \beta_n\}\) be a basis for \(E\) over \(K\). We claim that \(\{\alpha_i \beta_j : 1 \leq i \leq m, 1 \leq j \leq n\}\) is a basis for \(E\) over \(F\).

Spanning: Let \(x \in E\). Since \(\{\beta_j\}\) spans \(E\) over \(K\):

\[x = \sum_{j=1}^{n} c_j \beta_j, \quad c_j \in K\]

Since \(\{\alpha_i\}\) spans \(K\) over \(F\), each \(c_j = \sum_{i=1}^{m} d_{ij} \alpha_i\) for \(d_{ij} \in F\). Substituting:

\[x = \sum_{j=1}^{n} \sum_{i=1}^{m} d_{ij} \alpha_i \beta_j\]

Linear Independence: Suppose \(\sum_{i,j} d_{ij} \alpha_i \beta_j = 0\). Then:

\[\sum_{j=1}^{n} \left(\sum_{i=1}^{m} d_{ij} \alpha_i\right) \beta_j = 0\]

By linear independence of \(\{\beta_j\}\) over \(K\), each inner sum equals zero. By linear independence of \(\{\alpha_i\}\) over \(F\), all \(d_{ij} = 0\).

Notation Guide

  • \(F[x]\) — polynomial ring over field \(F\)
  • \(F(\alpha)\) — smallest field containing \(F\) and \(\alpha\)
  • \(F[\alpha]\) — smallest ring containing \(F\) and \(\alpha\)
  • \([E:F]\) — degree of extension (dimension as vector space)
  • \(\overline{F}\) — algebraic closure of \(F\)
  • \(\text{Gal}(E/F)\) — Galois group of extension
  • \(\mathbb{F}_q\) — finite field with \(q = p^n\) elements

            raise ValueError(f"{d} is not squarefree")
    
    def multiply(self, a, b):
        """
        Multiply elements a = (a0, a1) and b = (b0, b1) 
        representing a0 + a1*sqrt(d) and b0 + b1*sqrt(d).
        """
        a0, a1 = a
        b0, b1 = b
        # (a0 + a1*sqrt(d)) * (b0 + b1*sqrt(d))
        # = a0*b0 + a0*b1*sqrt(d) + a1*b0*sqrt(d) + a1*b1*d
        # = (a0*b0 + a1*b1*d) + (a0*b1 + a1*b0)*sqrt(d)
        return (a0*b0 + a1*b1*self.d, a0*b1 + a1*b0)
    
    def add(self, a, b):
        """Add two elements component-wise."""
        return (a[0] + b[0], a[1] + b[1])
    
    def inverse(self, a):
        """Multiplicative inverse of a = (a0, a1)."""
        a0, a1 = a
        # 1/(a0 + a1*sqrt(d)) = (a0 - a1*sqrt(d))/(a0^2 - a1^2*d)
        denom = a0**2 - a1**2 * self.d
        if denom == 0:
            raise ValueError("Cannot invert zero")
        return (a0/denom, -a1/denom)
    
    def power(self, a, n):
        """Compute a^n by repeated squaring."""
        if n == 0:
            return (1, 0)
        if n < 0:
            a = self.inverse(a)
            n = -n
        result = (1, 0)
        base = a
        while n > 0:
            if n % 2 == 1:
                result = self.multiply(result, base)
            base = self.multiply(base, base)
            n //= 2
        return result

Point-Set Topology: The Foundation of Continuity

topology

Motivation

Topology studies properties of spaces that are preserved under continuous deformations—stretching, bending, and twisting, but not tearing or gluing. While geometry cares about distances and angles, topology cares about the more fundamental notion of "nearness." The abstraction from metric spaces to topological spaces revealed that continuity depends only on the structure of open sets, not on numerical measurements. This insight unified concepts from analysis, geometry, and algebra, creating a language that underlies modern mathematics from differential equations to algebraic geometry.

Definitions

  • Topological Space: A set \(X\) together with a collection \(\tau\) of subsets (called open sets) satisfying: \(\emptyset, X \in \tau\); arbitrary unions of open sets are open; finite intersections of open sets are open.
  • Closed Set: A set whose complement is open.
  • Neighborhood: A set containing an open set containing the point.
  • Basis: A collection \(\mathcal{B}\) of open sets such that every open set is a union of elements of \(\mathcal{B}\).
  • Continuous Function: \(f: X \to Y\) is continuous if the preimage of every open set in \(Y\) is open in \(X\).
  • Homeomorphism: A bijective continuous function with continuous inverse—spaces related by homeomorphisms are "the same" topologically.
  • Connected: A space that cannot be partitioned into two disjoint non-empty open sets.
  • Compact: Every open cover has a finite subcover.

Theorem: Extreme Value Theorem (Topological Version)

Theorem: Let \(X\) be a compact topological space and \(f: X \to \mathbb{R}\) be continuous (where \(\mathbb{R}\) has the standard topology). Then \(f\) attains its maximum and minimum values on \(X\).

Proof

We prove that \(f(X)\) is compact in \(\mathbb{R}\), hence closed and bounded.

Step 1: \(f(X)\) is compact. Let \(\{U_\alpha\}\) be an open cover of \(f(X)\). Then \(\{f^{-1}(U_\alpha)\}\) is an open cover of \(X\) (by continuity). Since \(X\) is compact, there exists a finite subcover \(\{f^{-1}(U_{\alpha_1}), \ldots, f^{-1}(U_{\alpha_n})\}\). Then \(\{U_{\alpha_1}, \ldots, U_{\alpha_n}\}\) covers \(f(X)\).

Step 2: In \(\mathbb{R}\), compact sets are closed and bounded (Heine-Borel). So \(f(X)\) is bounded.

Step 3: Since \(f(X)\) is closed and bounded, it contains its supremum and infimum. Let \(M = \sup f(X)\). For each \(n\), there exists \(x_n \in X\) with \(f(x_n) > M - 1/n\). The sequence \(\{f(x_n)\}\) converges to \(M\), and since \(f(X)\) is closed, \(M \in f(X)\). Thus \(f\) attains its maximum. The minimum follows similarly.

Notation Guide

  • \((X, \tau)\) — topological space with topology \(\tau\)
  • \(A^\circ\) — interior of set \(A\)
  • \(\overline{A}\) — closure of set \(A\)
  • \(\partial A\) — boundary of set \(A\)
  • \(A'\) — derived set (set of limit points)
  • \(X \cong Y\) — homeomorphic spaces
  • \(T_1, T_2, \ldots\) — separation axioms
  • \(\pi_1(X, x_0)\) — fundamental group

def is_open_in_r(interval, topology_type='standard'):
    """
    Check if an interval is open in the standard topology on R.
    interval: tuple (a, b) where a and b can be -inf, inf, or float
    """
    a, b = interval
    
    if topology_type == 'standard':
        # In standard topology, open intervals are (a, b)
        return a is not None and b is not None  # finite endpoints
    elif topology_type == 'lower_limit':
        # In lower limit topology, [a, b) is open
        return True  # All [a, b) are open
    return False

def closure(A, X, topology='standard'):
    """
    Compute closure of A in X.
    For finite approximation, A and X are sets of points.
    """
    # Closure = A union its limit points
    closure_set = set(A)
    
    for x in X:
        if x not in A:
            # Check if x is a limit point of A
            # In discrete approximation: x is limit point if every neighborhood contains A points
            is_limit = True
            for epsilon in [0.1, 0.05, 0.01]:
                neighborhood = {y for y in X if abs(y - x) < epsilon}
                if len(neighborhood.intersection(A)) == 0:
                    is_limit = False
                    break
            if is_limit:
                closure_set.add(x)
    
    return closure_set

def interior(A, X, topology='standard'):
    """
    Compute interior of A in X.
    x is in interior if some neighborhood of x is contained in A.
    """
    interior_set = set()
    
    for x in A:
        # Check if x has a neighborhood contained in A
        has_open_nbhd = False
        for epsilon in [0.5, 0.3, 0.1, 0.05]:
            neighborhood = {y for y in X if abs(y - x) < epsilon}
            if neighborhood.issubset(A):
                has_open_nbhd = True
                break
        if has_open_nbhd:
            interior_set.add(x)
    
    return interior_set

def boundary(A, X):
    """Boundary = closure(A) ∩ closure(X\A)"""
    cl_A = closure(A, X)
    cl_not_A = closure(X - A, X)
    return cl_A.intersection(cl_not_A)

def is_continuous_check(f, X, Y, epsilon=0.1):
    """
    Check if f: X -> Y is continuous at each point.
    For discrete approximation.
    """
    results = {}
    for x in X:
        fx = f(x)
        # Check: for neighborhood of fx, preimage contains neighborhood of x
        nbhd_fx = {y for y in Y if abs(y - fx) < epsilon}
        preimage = {z for z in X if f(z) in nbhd_fx}
        
        # Check if preimage contains a neighborhood of x
        nbhd_x = {z for z in X if abs(z - x) < epsilon}
        results[x] = nbhd_x.issubset(preimage)
    
    return results

Complex Analysis: The Magic of Analytic Functions

analysis

Motivation

Complex analysis studies functions of a complex variable, revealing a theory of remarkable beauty and power. Unlike real analysis, where differentiable functions can be badly behaved, complex differentiability imposes such strong constraints that analytic functions are essentially determined by their values on any small region. This rigidity, combined with the geometric richness of the complex plane, makes complex analysis indispensable in physics, engineering, and number theory. The residue theorem, in particular, provides a powerful tool for evaluating integrals that would be intractable by real methods.

Definitions

  • Holomorphic (Analytic): A function \(f: U \to \mathbb{C}\) is holomorphic at \(z_0\) if the limit \(\lim_{z \to z_0} \frac{f(z) - f(z_0)}{z - z_0}\) exists.
  • Entire Function: A function holomorphic on all of \(\mathbb{C}\).
  • Meromorphic: A function holomorphic except at isolated poles.
  • Cauchy-Riemann Equations: If \(f(z) = u(x,y) + iv(x,y)\), then \(f\) is holomorphic iff \(\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}\) and \(\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}\).
  • Residue: For a function with Laurent series \(f(z) = \sum_{n=-\infty}^{\infty} a_n (z-z_0)^n\), the residue at \(z_0\) is \(\text{Res}(f, z_0) = a_{-1}\).
  • Conformal Map: A holomorphic function with non-zero derivative, preserving angles locally.

Theorem: Cauchy's Integral Formula

Theorem: Let \(f\) be holomorphic inside and on a simple closed positively oriented contour \(\gamma\). Then for any point \(z_0\) inside \(\gamma\):

\[f(z_0) = \frac{1}{2\pi i} \oint_\gamma \frac{f(z)}{z - z_0} dz\]

Moreover, derivatives of all orders exist and:

\[f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_\gamma \frac{f(z)}{(z - z_0)^{n+1}} dz\]

Proof

We prove the formula for \(f(z_0)\). Consider a small circle \(\gamma_\epsilon\) of radius \(\epsilon\) around \(z_0\), contained in the interior of \(\gamma\). By deformation of contours:

\[\oint_\gamma \frac{f(z)}{z - z_0} dz = \oint_{\gamma_\epsilon} \frac{f(z)}{z - z_0} dz\]

Parameterize \(\gamma_\epsilon\) as \(z = z_0 + \epsilon e^{i\theta}\) for \(\theta \in [0, 2\pi]\). Then \(dz = i\epsilon e^{i\theta} d\theta\) and:

\[\oint_{\gamma_\epsilon} \frac{f(z)}{z - z_0} dz = \int_0^{2\pi} \frac{f(z_0 + \epsilon e^{i\theta})}{\epsilon e^{i\theta}} i\epsilon e^{i\theta} d\theta = i \int_0^{2\pi} f(z_0 + \epsilon e^{i\theta}) d\theta\]

As \(\epsilon \to 0\), by continuity of \(f\):

\[\lim_{\epsilon \to 0} i \int_0^{2\pi} f(z_0 + \epsilon e^{i\theta}) d\theta = i \cdot 2\pi \cdot f(z_0)\]

Therefore:

\[\oint_\gamma \frac{f(z)}{z - z_0} dz = 2\pi i \cdot f(z_0)\]

Notation Guide

  • \(\mathbb{C}\) — complex numbers
  • \(z = x + iy = re^{i\theta}\) — complex number representations
  • \(\overline{z} = x - iy\) — complex conjugate
  • \(|z| = \sqrt{x^2 + y^2}\) — modulus
  • \(\text{Re}(z), \text{Im}(z)\) — real and imaginary parts
  • \(\text{Res}(f, z_0)\) — residue of \(f\) at \(z_0\)
  • \(\oint\) — contour integral

Support Vector Machines: The Geometry of Classification

machine-learning

Real-World Motivation

Support Vector Machines (SVMs) are one of the most elegant and powerful tools in machine learning, used for classification and regression tasks. From email spam detection to medical diagnosis, SVMs find the optimal boundary between classes by focusing on the most informative data points—the support vectors. Unlike neural networks that can be black boxes, SVMs have a clear geometric interpretation: they find the hyperplane that maximizes the margin between classes, providing both good generalization and theoretical guarantees about performance.

Definitions

  • Hyperplane: In \(\mathbb{R}^n\), a hyperplane is defined by \(\{x : w \cdot x + b = 0\}\) where \(w\) is the normal vector and \(b\) is the bias.
  • Margin: The distance from the hyperplane to the nearest data point of either class. For a hyperplane \((w, b)\), the margin is \(\frac{2}{\|w\|}\).
  • Support Vectors: The data points that lie exactly on the margin boundaries; these are the only points that determine the optimal hyperplane.
  • Hard Margin: SVM that requires all training data to be correctly classified with margin at least 1.
  • Soft Margin: SVM that allows some misclassification via slack variables \(\xi_i\), trading off margin size against classification error.
  • Kernel Trick: Mapping data to a higher-dimensional space where it becomes linearly separable, without explicitly computing the mapping.

Theorem: SVM Optimization Problem

Theorem: The hard-margin SVM optimization problem is:

\[\min_{w,b} \frac{1}{2}\|w\|^2\]

subject to:

\[y_i(w \cdot x_i + b) \geq 1 \quad \text{for all } i\]

where \(y_i \in \{-1, +1\}\) are the class labels. The solution gives the maximum-margin hyperplane.

Proof Sketch

The distance from a point \(x_i\) to the hyperplane \(w \cdot x + b = 0\) is \(\frac{|w \cdot x_i + b|}{\|w\|}\). For correct classification with margin, we want:

\[\frac{y_i(w \cdot x_i + b)}{\|w\|} \geq \frac{1}{\|w\|}\]

Since scaling \((w, b)\) doesn't change the hyperplane, we can fix the functional margin to be at least 1, giving the constraints \(y_i(w \cdot x_i + b) \geq 1\).

The geometric margin is then \(\frac{1}{\|w\|}\), so maximizing the margin is equivalent to minimizing \(\|w\|^2\).

Notation Guide

  • \(x_i \in \mathbb{R}^d\) — feature vectors

import numpy as np
from scipy.optimize import minimize

class SimpleSVM:
    """Simplified SVM implementation."""
    def __init__(self, C=None):
        self.C = C
        self.alpha = None
        self.w = None
        self.b = None
    
    def fit(self, X, y):
        """Fit SVM using dual formulation."""
        n_samples, n_features = X.shape
        
        # Compute kernel matrix (linear)
        K = np.dot(X, X.T)
        
        # Dual objective
        def objective(alpha):
            return 0.5 * np.sum(alpha[:, None] * alpha[None, :] * 
                              y[:, None] * y[None, :] * K) - np.sum(alpha)
        
        # Constraints
        bounds = [(0, self.C) if self.C else (0, None) for _ in range(n_samples)]
        
        def eq_constraint(alpha):
            return np.dot(alpha, y)
        
        alpha0 = np.ones(n_samples) * 0.1
        
        result = minimize(
            objective, alpha0, method='SLSQP',
            bounds=bounds,
            constraints={'type': 'eq', 'fun': eq_constraint}
        )
        
        self.alpha = result.x
        self.w = np.sum(self.alpha[:, None] * y[:, None] * X, axis=0)
        
        # Compute b
        sv_mask = self.alpha > 1e-5
        self.b = np.mean(y[sv_mask] - np.dot(X[sv_mask], self.w))
    
    def predict(self, X):
        """Predict class labels."""
        return np.sign(np.dot(X, self.w) + self.b)

Maximum Likelihood Estimation: Finding the Most Probable Parameters

Real-World Motivation

Maximum Likelihood Estimation (MLE) is the workhorse of statistical inference, used everywhere from medical trials to financial modeling to machine learning. When we observe data and want to know what parameters most likely generated it, MLE provides the answer. The method, developed by Ronald Fisher in the early 20th century, has optimal properties: under mild conditions, MLEs are consistent, asymptotically normal, and efficient. From estimating the bias of a coin to fitting complex neural networks, MLE provides a principled framework for learning from data.

Definitions

  • Likelihood Function: For data \(x = (x_1, \ldots, x_n)\) and parameter \(\theta\), the likelihood is \(L(\theta | x) = P(x | \theta)\) viewed as a function of \(\theta\).
  • Log-Likelihood: \(\ell(\theta) = \log L(\theta)\), often easier to maximize due to products becoming sums.
  • Maximum Likelihood Estimator: \(\hat{\theta}_{MLE} = \arg\max_\theta L(\theta | x)\).
  • Score Function: \(s(\theta) = \nabla_\theta \ell(\theta)\), the gradient of the log-likelihood.
  • Fisher Information: \(I(\theta) = -\mathbb{E}[\nabla^2 \ell(\theta)]\), measuring the curvature of the likelihood surface.
  • Cramér-Rao Bound: Any unbiased estimator \(\hat{\theta}\) satisfies \(\text{Var}(\hat{\theta}) \geq \frac{1}{I(\theta)}\).

Theorem: Asymptotic Normality of MLE

Theorem: Under regularity conditions, as \(n \to \infty\):

\[\sqrt{n}(\hat{\theta}_{MLE} - \theta_0) \xrightarrow{d} \mathcal{N}(0, I(\theta_0)^{-1})\]

where \(\theta_0\) is the true parameter value and \(I(\theta_0)\) is the Fisher information matrix.

Notation Guide

  • \(L(\theta | x)\) — likelihood function
  • \(\ell(\theta)\) — log-likelihood
  • \(\hat{\theta}_{MLE}\) — maximum likelihood estimator
  • \(s(\theta) = \nabla \ell(\theta)\) — score function
  • \(I(\theta)\) — Fisher information
  • \(\xrightarrow{d}\) — convergence in distribution

            self.theta_mle = {
                'mu': np.mean(data), 
                'sigma': np.std(data, ddof=0)
            }

import numpy as np
from itertools import permutations
from scipy.spatial.distance import pdist, squareform

class TSPSolver:
    """Solvers for the Traveling Salesman Problem."""
    def __init__(self, points):
        self.points = points
        self.n = len(points)
        self.dist_matrix = squareform(pdist(points, 'euclidean'))
    
    def nearest_neighbor(self, start=0):
        """Greedy nearest neighbor heuristic."""
        unvisited = set(range(self.n))
        tour = [start]
        unvisited.remove(start)
        current = start
        
        while unvisited:
            nearest = min(unvisited, key=lambda x: self.dist_matrix[current, x])
            tour.append(nearest)
            unvisited.remove(nearest)
            current = nearest
        
        length = sum(self.dist_matrix[tour[i], tour[(i+1) % self.n]] 
                    for i in range(self.n))
        return tour, length

def knapsack_dp(values, weights, capacity):
    """Solve 0/1 Knapsack using dynamic programming."""
    n = len(values)
    dp = np.zeros((n + 1, capacity + 1), dtype=int)
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            dp[i, w] = dp[i-1, w]
            if weights[i-1] <= w:
                dp[i, w] = max(dp[i, w], 
                              dp[i-1, w - weights[i-1]] + values[i-1])
    
    return dp[n, capacity]

The Prime Number Theorem: The Distribution of Primes

Historical Context

The distribution of prime numbers has fascinated mathematicians for millennia. Euclid proved there are infinitely many primes around 300 BCE, but the question of how they are distributed remained mysterious. In 1792, Gauss (at age 15!) conjectured that the number of primes up to \(x\), denoted \(\pi(x)\), is approximately \(x/\log x\). This was independently proposed by Legendre. The Prime Number Theorem, proved independently by Hadamard and de la Vallée Poussin in 1896 using complex analysis, confirms this conjecture and stands as one of the great achievements of analytic number theory.

Definitions

  • Prime Counting Function: \(\pi(x) = \#\{p \leq x : p \text{ is prime}\}\)
  • Logarithmic Integral: \(\text{li}(x) = \int_2^x \frac{dt}{\log t}\), a better approximation to \(\pi(x)\)
  • Chebyshev Functions: \(\vartheta(x) = \sum_{p \leq x} \log p\) and \(\psi(x) = \sum_{p^k \leq x} \log p\)
  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^\infty n^{-s}\) for \(\text{Re}(s) > 1\)

Theorem: Prime Number Theorem

Theorem: As \(x \to \infty\):

\[\pi(x) \sim \frac{x}{\log x}\]

Equivalently:

\[\lim_{x \to \infty} \frac{\pi(x) \log x}{x} = 1\]

Notation Guide

  • \(\pi(x)\) — prime counting function
  • \(\text{li}(x)\) — logarithmic integral
  • \(\vartheta(x), \psi(x)\) — Chebyshev functions
  • \(\zeta(s)\) — Riemann zeta function
  • \(f(x) \sim g(x)\) — asymptotic equivalence
  • \(O(\cdot), o(\cdot)\) — big-O and little-o notation

def sieve_of_eratosthenes(n):
    """Generate all primes up to n."""
    is_prime = np.ones(n + 1, dtype=bool)
    is_prime[0:2] = False
    for i in range(2, int(np.sqrt(n)) + 1):
        if is_prime[i]:
            is_prime[i*i:n+1:i] = False
    return np.where(is_prime)[0]

    if primes is None:

    """Compute li(x) = ∫₂^x dt/log(t)."""

    return expi(np.log(x))

Historical Context

For over 2000 years, Euclid's Elements stood as the foundation of geometry. The fifth postulate—the parallel postulate—seemed more complex than the others, and mathematicians tried endlessly to prove it from the other axioms. In the early 19th century, Bolyai, Lobachevsky, and Gauss independently discovered that denying the parallel postulate leads to consistent, rich geometries. This breakthrough shattered the belief that Euclidean geometry was the only possible description of space, paving the way for Riemann's generalization and ultimately Einstein's theory of general relativity.

Definitions

  • Elliptic Geometry: Geometry on a sphere where lines are great circles. Any two lines intersect (no parallels exist).
  • Hyperbolic Geometry: Geometry where infinitely many lines through a point are parallel to a given line. Models include the Poincaré disk and upper half-plane.
  • Curvature:\(K\) Gaussian curvature measures how a surface deviates from being flat: \(K > 0\) (sphere), \(K = 0\) (plane), \(K < 0\) (hyperbolic).
  • Geodesic: The shortest path between two points on a surface; "straight lines" in non-Euclidean geometry.

Theorem: Gauss-Bonnet Theorem

Theorem: For a geodesic triangle \(T\) with angles \(\alpha, \beta, \gamma\) on a surface with constant curvature \(K\):

\[\alpha + \beta + \gamma = \pi + K \cdot \text{Area}(T)\]

In hyperbolic geometry (\(K = -1\)): \(\alpha + \beta + \gamma = \pi - \text{Area}(T) < \pi\).

def simple_random_walk(n_steps, dim=1, n_walks=1):
    """
    Generate simple random walk(s).
    """
    if dim == 1:
        steps = np.random.choice([-1, 1], size=(n_walks, n_steps))
        walks = np.cumsum(steps, axis=1)
        walks = np.hstack([np.zeros((n_walks, 1)), walks])
    else:
        # For higher dimensions, steps in each dimension
        walks = np.zeros((n_walks, n_steps + 1, dim))
        for d in range(dim):
            steps = np.random.choice([-1, 1], size=(n_walks, n_steps))
            walks[:, 1:, d] = np.cumsum(steps, axis=1)
    return walks

            origin_visits = np.all(walk[0] == 0, axis=1).sum()

    return returns / n_trials

Gödel's Incompleteness Theorems: The Limits of Formal Systems

logic

Historical Context

In 1931, Kurt Gödel published his incompleteness theorems, shattering the dreams of mathematicians like David Hilbert who sought a complete and consistent formalization of all mathematics. Gödel showed that in any sufficiently powerful formal system, there are true statements that cannot be proved within the system. This profound result revealed fundamental limitations of mathematical reasoning and had profound implications for philosophy of mathematics, computer science, and our understanding of truth and provability.

Definitions

  • Formal System: A set of axioms and inference rules for deriving theorems.
  • Consistent: A system is consistent if it cannot prove both a statement and its negation.
  • Complete: A system is complete if every true statement (in its language) can be proved.
  • Gödel Numbering: A scheme encoding formulas and proofs as natural numbers, allowing self-reference.
  • Provability Predicate: A formula \(\text{Prov}(n)\) expressing "the formula with Gödel number \(n\) is provable."

Theorem: Gödel's First Incompleteness Theorem

Theorem: Any consistent formal system \(F\) that is strong enough to encode basic arithmetic contains statements that are true but unprovable in \(F\). Specifically, there exists a statement \(G\) (the "Gödel sentence") such that:

\[F \nvdash G \quad \text{and} \quad F \nvdash \neg G\]

The Gödel sentence essentially says "I am not provable in \(F\)."

Proof Sketch

Step 1: Gödel numbering assigns a unique natural number to every formula and proof in the system.

Step 2: Using the diagonal lemma, construct a formula \(G\) that says "The formula with Gödel number \(g\) is not provable," where \(g\) is the Gödel number of \(G\) itself.

Step 3: If \(G\) were provable, the system would prove a false statement (since \(G\) claims unprovability), contradicting consistency.

Step 4: If \(\neg G\) were provable, then \(G\) would be provable (since \(\neg G\) says \(G\) is provable), again contradicting consistency.

Therefore, neither \(G\) nor \(\neg G\) is provable.

Notation Guide

  • \(F \vdash \phi\) — formula \(\phi\) is provable in system \(F\)
  • \(\ulcorner \phi \urcorner\) — Gödel number of formula \(\phi\)
  • \(\text{Prov}_F(n)\) — provability predicate for system \(F\)
  • \(G\) — Gödel sentence
  • \(\text{Con}(F)\) — consistency statement for system \(F\)
  • \(\omega\)-consistent — stronger form of consistency

📜 Math History: The Development of Abstract Algebra

The birth of abstract algebra in the 19th century represents one of the most profound shifts in mathematical thinking. Before this period, algebra was primarily about solving equations—finding unknown numbers that satisfied specific conditions. The quadratic formula, cubic and quartic equations, and the search for solutions to the quintic were the driving forces of algebraic research. But a series of revolutionary insights transformed algebra from the study of numbers and equations into the study of structure and symmetry.

The story begins with Évariste Galois (1811–1832), whose short but brilliant life changed mathematics forever. Working in isolation and under the shadow of his impending death in a duel, Galois developed what we now call Galois theory. He showed that the solvability of polynomial equations by radicals—expressions involving only arithmetic operations and roots—depended not on the specific coefficients but on the abstract structure of the equation's symmetries. This structure, captured in the "Galois group," revealed deep connections between fields and groups that would become foundational to modern mathematics.

Galois's ideas were revolutionary because they shifted attention from the objects being studied (numbers, equations) to the transformations that preserve their structure (symmetries, permutations). A polynomial equation of degree \(n\) has \(n\) roots, and the ways these roots can be permuted while preserving algebraic relations form a group. Galois showed that the equation is solvable by radicals if and only if this group has a special structure—it must be "solvable" in the technical sense. This explained why equations of degree 2, 3, and 4 are solvable (their groups are solvable) while the general quintic is not (its group, \(S_5\), is not solvable).

The torch was carried forward by mathematicians like Arthur Cayley, who in 1854 gave the first abstract definition of a group, and Richard Dedekind, who introduced the concept of an ideal in ring theory while studying algebraic numbers. Dedekind's work on algebraic number theory showed that unique factorization, which fails in general rings of algebraic integers, could be restored by working with ideals instead of individual numbers. This insight unified number theory and algebra, showing that the same abstract structures appeared across seemingly different domains.

The culmination of this development came with Emmy Noether (1882–1935), whose work in the early 20th century established the modern framework of abstract algebra. Noether's theorem—that every conservation law in physics corresponds to a symmetry—revealed deep connections between algebra and physics. Her abstract approach, emphasizing structures like rings, ideals, and modules over concrete computations, transformed how mathematicians think about algebra. The "modern algebra" that emerged from her work, codified in textbooks by van der Waerden, became the standard language for algebraic research.

The legacy of this transformation extends far beyond algebra itself. Category theory, developed in the 1940s by Eilenberg and Mac Lane, took the abstraction one step further, studying not just algebraic structures but the mappings between them. Representation theory connected abstract groups to linear transformations, providing tools for studying symmetry in physics and chemistry. Algebraic geometry, revolutionized by Grothendieck in the 1960s, used abstract algebra to study geometric objects defined by polynomial equations. Today, abstract algebra underlies cryptography, coding theory, computer graphics, and countless other applications. What began as a search for solutions to equations has become the study of structure itself—one of the most powerful and far-reaching developments in the history of mathematics.

🎯 Problem Corner

IMO 1988 Problem 6

Let \(a\) and \(b\) be positive integers such that \(ab + 1\) divides \(a^2 + b^2\). Show that:

\[\frac{a^2 + b^2}{ab + 1}\]

is the square of an integer.

💡 Hint

Consider the equation \(a^2 + b^2 = k(ab + 1)\) for a fixed positive integer \(k\). Assume \((a, b)\) is a solution with \(a \geq b\) and \(a + b\) minimal among all solutions for this \(k\). Show that there exists another solution \((b, c)\) with smaller sum, leading to a contradiction unless \(k\) is a perfect square. This technique is called "Vieta jumping."

📖 Solution

Suppose \(\frac{a^2 + b^2}{ab + 1} = k\) for some positive integer \(k\). We want to show \(k\) is a perfect square.

Consider the Diophantine equation:

\[a^2 - kba + b^2 - k = 0\]

View this as a quadratic in \(a\). If \((a, b)\) is a solution with \(a \geq b\), then by Vieta's formulas, there's another root \(a'\) satisfying:

\[a + a' = kb, \quad aa' = b^2 - k\]

So \(a' = kb - a = \frac{b^2 - k}{a}\).

We claim \(a'\) is a non-negative integer. It's clearly rational, and since \(a' = kb - a\), it's an integer. We need \(a' \geq 0\).

If \(a' < 0\), then \(aa' = b^2 - k < 0\), so \(k > b^2\). But then:

\[k = \frac{a^2 + b^2}{ab + 1} \leq \frac{a^2 + b^2}{b^2 + 1} < \frac{a^2}{b^2} + 1\]

For \(k > b^2\), we need \(a^2 > b^4\), i.e., \(a > b^2\). But then \(ab + 1 > b^3 + 1\) and \(a^2 + b^2 < a^2 + a = a(a+1)\), giving:

\[k = \frac{a^2 + b^2}{ab + 1} < \frac{a(a+1)}{b^3 + 1}\]

This leads to a contradiction for large \(a\). More directly, if \(a' < 0\), then \(b^2 - k = aa' < 0\), so \(k > b^2\). But:

\[k = \frac{a^2 + b^2}{ab + 1} \leq \frac{a^2 + a^2/b^2}{a \cdot b + 1} = \frac{a^2(1 + 1/b^2)}{ab + 1}\]

For \(a = b\), we get \(k = \frac{2b^2}{b^2 + 1} < 2\), so \(k = 1 = 1^2\).

For \(a > b\), if \(a' = 0\), then \(b^2 = k\), so \(k\) is a perfect square.

If \(a' > 0\), then \((b, a')\) is another solution with \(b + a' < a + b\) (since \(a' = \frac{b^2-k}{a} < \frac{b^2}{a} \leq b \leq a\)).

By infinite descent, we eventually reach a solution with \(a' = 0\), implying \(k = b^2\) is a perfect square. ∎

🎨 Visualization of the Day: The Lorenz Attractor

The Lorenz attractor is a set of chaotic solutions to the Lorenz system, a simplified mathematical model for atmospheric convection. Discovered by Edward Lorenz in 1963, it was one of the first examples of deterministic chaos—systems where deterministic rules produce unpredictable behavior.

The system is defined by three differential equations:

\[\frac{dx}{dt} = \sigma(y - x)\]

\[\frac{dy}{dt} = x(\rho - z) - y\]

\[\frac{dz}{dt} = xy - \beta z\]

With parameters \(\sigma = 10\), \(\rho = 28\), and \(\beta = 8/3\), the system exhibits chaotic behavior. Trajectories orbit around two "wings" of the attractor in a complex, never-repeating pattern that is highly sensitive to initial conditions—the famous "butterfly effect."

Python Code

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def lorenz_system(state, sigma=10, rho=28, beta=8/3):
    """
    Compute derivatives for the Lorenz system.
    """
    x, y, z = state
    dxdt = sigma * (y - x)
    dydt = x * (rho - z) - y
    dzdt = x * y - beta * z
    return np.array([dxdt, dydt, dzdt])

def runge_kutta_4(f, y0, t):
    """
    RK4 integration method.
    """
    n = len(t)
    y = np.zeros((n, len(y0)))
    y[0] = y0
    
    for i in range(n - 1):
        h = t[i+1] - t[i]
        k1 = f(y[i])
        k2 = f(y[i] + 0.5 * h * k1)
        k3 = f(y[i] + 0.5 * h * k2)
        k4 = f(y[i] + h * k3)
        y[i+1] = y[i] + (h / 6) * (k1 + 2*k2 + 2*k3 + k4)
    
    return y

def plot_lorenz_attractor():
    """
    Generate and plot the Lorenz attractor.
    """
    # Time array
    dt = 0.01
    t = np.arange(0, 50, dt)
    
    # Initial condition
    y0 = np.array([1, 1, 1])
    
    # Integrate
    trajectory = runge_kutta_4(lorenz_system, y0, t)
    
    # Create 3D plot
    fig = plt.figure(figsize=(12, 9))
    ax = fig.add_subplot(111, projection='3d')
    
    # Plot with color gradient based on time
    points = ax.scatter(trajectory[:, 0], trajectory[:, 1], trajectory[:, 2],
                       c=t, cmap='viridis', s=0.5, alpha=0.8)
    
    ax.set_xlabel('X')
    ax.set_ylabel('Y')
    ax.set_zlabel('Z')
    ax.set_title('Lorenz Attractor')
    
    plt.colorbar(points, label='Time')
    plt.tight_layout()
    plt.savefig('lorenz_attractor.png', dpi=150, bbox_inches='tight')
    
    return trajectory

# Demonstrate sensitivity to initial conditions
def butterfly_effect_demo():
    """
    Show how small changes in initial conditions lead to divergence.
    """
    dt = 0.01
    t = np.arange(0, 30, dt)
    
    # Two initial conditions with tiny difference
    y0_1 = np.array([1, 1, 1])
    y0_2 = np.array([1.001, 1, 1])  # 0.1% difference
    
    traj_1 = runge_kutta_4(lorenz_system, y0_1, t)
    traj_2 = runge_kutta_4(lorenz_system, y0_2, t)
    
    # Compute distance over time
    distance = np.sqrt(np.sum((traj_1 - traj_2)**2, axis=1))
    
    plt.figure(figsize=(10, 6))
    plt.semilogy(t, distance)
    plt.xlabel('Time')
    plt.ylabel('Distance between trajectories (log scale)')
    plt.title('Butterfly Effect: Sensitivity to Initial Conditions')
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.savefig('butterfly_effect.png', dpi=150, bbox_inches='tight')
    
    print(f"Initial distance: {distance[0]:.6f}")
    print(f"Distance at t=10: {distance[1000]:.2f}")
    print(f"Distance at t=20: {distance[2000]:.2f}")
    print(f"Distance at t=30: {distance[3000]:.2f}")
