1. Complex Analysis: Cauchy's Integral Theorem

Introduction

Complex analysis, the study of functions of a complex variable, is one of the most elegant and powerful branches of mathematics. Unlike real analysis, where differentiable functions can be poorly behaved, complex differentiability imposes remarkable constraints that lead to beautiful and useful theorems.

Cauchy's Integral Theorem is the cornerstone of complex analysis. It states that the integral of a holomorphic function around a closed contour is zero, provided the function is well-behaved inside. This seemingly simple result has profound consequences, including the ability to compute real integrals using complex methods.

Notation Guide

  • \ℂ\ — the field of complex numbers \a + bi\ where \a, b ∈ ℝ\ and \i2 = -1\
  • \f: U → ℂ\ — a complex-valued function on an open set \U ⊆ ℂ\
  • \f'(z)\ — the complex derivative: \\limh → 0 \f(z+h) - f(z)/h\
  • Holomorphic — complex differentiable at every point in a domain
  • \γ\ — a piecewise smooth closed curve (contour) in \ℂ\
  • \\oint_γ f(z)\\, dz\ — contour integral of \f\ around \γ\
Cauchy's Integral Theorem

Let \U ⊆ ℂ\ be a simply connected open set, and let \f: U → ℂ\ be holomorphic on \U\. If \γ\ is any piecewise smooth closed curve in \U\, then:

\

\oint_γ f(z)\\, dz = 0\

Proof (using Green's Theorem)

Step 1: Write \f(z) = u(x,y) + iv(x,y)\ where \z = x + iy\, and \u, v\ are real-valued functions.

Step 2: The complex derivative condition \f'(z)\ existing implies the Cauchy-Riemann equations:

\

\∂ u/∂ x = \∂ v/∂ y \quad and \quad \∂ u/∂ y = -\∂ v/∂ x\

Step 3: Write the contour integral as:

\

\oint_γ f(z)\\, dz = \oint_γ (u\\, dx - v\\, dy) + i\oint_γ (v\\, dx + u\\, dy)\

Step 4: Apply Green's Theorem to each real line integral.

Step 5: For the real part, using the Cauchy-Riemann equations, we get 0.

Step 6: Similarly, the imaginary part equals 0.

Therefore: Both real and imaginary parts are zero, so \\oint_γ f(z)\\, dz = 0\. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def contour_integral(func, center, radius, n=1000):
    """Compute contour integral around a circle."""
    t = np.linspace(0, 2*np.pi, n, endpoint=False)
    z = center + radius * np.exp(1j * t)
    dz = 1j * radius * np.exp(1j * t) * (2*np.pi / n)
    integrand = func(z)
    return np.sum(integrand * dz)

# Test Cauchy's theorem
print("Cauchy's Integral Theorem Verification")
print("=" * 60)

# Holomorphic functions
f1 = lambda z: z**2  # Entire
f2 = lambda z: np.exp(z)  # Entire

# Test with unit circle
center, radius = 0j, 1.0

print(f"\\nContour: Circle centered at {center} with radius {radius}")
print(f"∫ z² dz = {contour_integral(f1, center, radius):.2e} (should be ≈ 0)")
print(f"∫ e^z dz = {contour_integral(f2, center, radius):.2e} (should be ≈ 0)")

# Cauchy's Integral Formula
def cauchy_integral_formula(f, z0, center, radius, n=1000):
    """Compute f(z0) using Cauchy's Integral Formula."""
    t = np.linspace(0, 2*np.pi, n, endpoint=False)
    z = center + radius * np.exp(1j * t)
    dz = 1j * radius * np.exp(1j * t) * (2*np.pi / n)
    integrand = f(z) / (z - z0)
    return np.sum(integrand * dz) / (2j * np.pi)

# Test: f(z) = z³, compute f(0.5)
z0 = 0.5 + 0.3j
f = lambda z: z**3
computed = cauchy_integral_formula(f, z0, 0j, 1.0)
actual = f(z0)

print(f"\\nCauchy's Integral Formula:")
print(f"f(z) = z³, z₀ = {z0}")
print(f"Actual f(z₀) = {actual}")
print(f"Computed via Cauchy = {computed}")
print(f"Error = {abs(computed - actual):.2e}")

2. Graph Theory: Euler's Formula for Planar Graphs

Introduction

Graph theory, the study of networks of vertices connected by edges, has applications ranging from social networks to computer science to chemistry. One of the most beautiful and fundamental results is Euler's Formula, which relates the number of vertices, edges, and faces in any planar graph.

Notation Guide

  • \G = (V, E)\ — a graph with vertex set \V\ and edge set \E\
  • \|V|\ or \v\ — number of vertices
  • \|E|\ or \e\ — number of edges
  • \F\ or \f\ — number of faces (including the outer face)
  • Planar graph — can be drawn on a plane without edge crossings
Euler's Formula for Planar Graphs

For any connected planar graph \G\ drawn in the plane without edge crossings:

\

V - E + F = 2\

Proof (by induction on edges)

Base Case: A tree has \F = 1\ and \E = V - 1\. Thus:

\

V - (V - 1) + 1 = 2\

Inductive Step: Assume true for graphs with fewer than \E\ edges.

If \G\ contains a cycle, remove one edge \e\. The resulting graph has:

  • \V' = V\ (same vertices)
  • \E' = E - 1\ (one fewer edge)
  • \F' = F - 1\ (removing cycle edge merges two faces)

By induction: \V - (E-1) + (F-1) = V - E + F = 2\. ∎

Corollary: Edge Bound for Planar Graphs

For any simple connected planar graph with \V ≥ 3\:

\

E ≤ 3V - 6\

Python Implementation

import networkx as nx

print("Euler's Formula Verification")
print("=" * 60)

# Platonic solids as planar graphs
graphs = [
    ("Tetrahedron (K₄)", nx.complete_graph(4)),
    ("Cube", nx.cubical_graph()),
    ("Octahedron", nx.octahedral_graph()),
    ("Dodecahedron", nx.dodecahedral_graph()),
    ("Icosahedron", nx.icosahedral_graph()),
]

for name, G in graphs:
    V = G.number_of_nodes()
    E = G.number_of_edges()
    F = 2 - V + E  # From Euler's formula
    is_planar = nx.check_planarity(G)[0]
    
    print(f"\\n{name}:")
    print(f"  V = {V}, E = {E}, F = {F}")
    print(f"  V - E + F = {V - E + F}")
    print(f"  Planar: {is_planar}")
    print(f"  Edge bound (3V-6={3*V-6}): {E <= 3*V - 6}")

# K5 is non-planar
K5 = nx.complete_graph(5)
print(f"\\nK₅ (complete graph on 5 vertices):")
print(f"  V = {K5.number_of_nodes()}, E = {K5.number_of_edges()}")
print(f"  Planar: {nx.check_planarity(K5)[0]}")
print(f"  Edge bound check: E = {K5.number_of_edges()}, 3V-6 = {3*5 - 6}")

3. Measure Theory: The Lebesgue Integral

Introduction

Measure theory provides the rigorous foundation for modern analysis, probability, and many areas of mathematics. Developed by Henri Lebesgue in the early 20th century, it overcomes limitations of the Riemann integral by allowing integration of a much broader class of functions.

Notation Guide

  • \m(E)\ or \μ(E)\ — Lebesgue measure of set \E\
  • \∫E f\\, dμ\ — Lebesgue integral of \f\ over \E\
  • \χE\ — characteristic function of set \E\
  • Measurable set — a set for which Lebesgue measure is defined
  • \L1\ — space of Lebesgue integrable functions
The Monotone Convergence Theorem

Let \(fn)n=1^∞\ be a sequence of non-negative measurable functions with \fn ≤ fn+1\ a.e. Let \f = \limn → ∞ fn\. Then:

\

\limn → ∞ ∫ fn\\, dμ = ∫ f\\, dμ\

Proof Sketch

Step 1: Since \fn ≤ fn+1\, we have \∫ fn ≤ ∫ fn+1\, so the limit exists.

Step 2: Since \fn ≤ f\, we have \\lim ∫ fn ≤ ∫ f\.

Step 3: For the reverse inequality, use the definition of Lebesgue integral via simple functions.

Step 4: For any simple \s ≤ f\, show \\lim ∫ fn ≥ ∫ s\.

Step 5: Taking supremum over all such \s\ gives \\lim ∫ fn ≥ ∫ f\. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def monotone_convergence_demo():
    """
    Demonstrate Monotone Convergence Theorem.
    f_n(x) = floor(n*x)/n converges to f(x) = x on [0,1].
    """
    x = np.linspace(0, 1, 1000)
    
    print("Monotone Convergence Theorem Demonstration")
    print("=" * 60)
    print("f_n(x) = floor(n*x)/n converges to f(x) = x on [0,1]")
    print()
    
    n_values = [1, 2, 5, 10, 20, 50, 100]
    integrals = []
    
    for n in n_values:
        f_n = np.floor(n * x) / n
        integral = np.trapz(f_n, x)
        integrals.append(integral)
        print(f"n = {n:3d}: ∫f_n = {integral:.6f}")
    
    print(f"\\nLimit: ∫x dx = 0.5")
    print(f"Final approximation: {integrals[-1]:.6f}")
    print(f"Error: {abs(0.5 - integrals[-1]):.2e}")

monotone_convergence_demo()

1. Linear Algebra: Singular Value Decomposition (SVD)

Introduction

The Singular Value Decomposition (SVD) is arguably the most important matrix factorization in applied mathematics. It reveals the fundamental structure of any matrix and provides the foundation for principal component analysis, data compression, and numerical linear algebra.

Notation Guide

  • \A ∈ ℝm × n\ — an \m × n\ real matrix
  • \U ∈ ℝm × m\ — orthogonal matrix (\UT U = Im\)
  • \Σ ∈ ℝm × n\ — diagonal with \σ1 ≥ σ2 ≥ ⋯ ≥ 0\
  • \V ∈ ℝn × n\ — orthogonal matrix (\VT V = In\)
  • \σi\ — singular values of \A\
Singular Value Decomposition

Every matrix \A ∈ ℝm × n\ can be factored as:

\

A = UΣ VT\

Eckart-Young-Mirsky Theorem

Let \A = Σi=1r σi ui viT\. The best rank-\k\ approximation is:

\

Ak = Σi=1k σi ui viT\

with error \\\|A - Ak\\|2 = σk+1\.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

# Create test matrix
np.random.seed(42)
A = np.random.randn(100, 50)

# Compute SVD
U, S, Vt = np.linalg.svd(A, full_matrices=False)

print("Singular Value Decomposition Demo")
print("=" * 60)
print(f"Matrix shape: {A.shape}")
print(f"Number of singular values: {len(S)}")
print(f"Top 10 singular values: {S[:10].round(2)}")

# Low-rank approximation
k = 10
A_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]

error = np.linalg.norm(A - A_k, 'fro') / np.linalg.norm(A, 'fro')
print(f"\\nRank-{k} approximation error: {error:.4f}")

# Compression ratio
original = A.shape[0] * A.shape[1]
compressed = k * (A.shape[0] + 1 + A.shape[1])
print(f"Compression ratio: {original/compressed:.1f}x")

2. Differential Equations: Existence and Uniqueness

Introduction

Before attempting to solve an ODE, a fundamental question arises: does a solution exist, and if so, is it unique? The Picard-Lindelöf theorem provides elegant sufficient conditions.

Notation Guide

  • \\dy/dt = f(t, y)\ — first-order ODE
  • \y(t0) = y0\ — initial condition
  • Lipschitz condition: \|f(t, y1) - f(t, y2)| ≤ L|y1 - y2|\
  • \L\ — Lipschitz constant
Picard-Lindelöf Theorem

Consider \\dy/dt = f(t, y), \quad y(t0) = y0\. If \f\ is continuous in \t\ and Lipschitz in \y\, then there exists a unique solution locally.

Python Implementation

import numpy as np
from scipy.integrate import odeint

print("Picard-Lindelöf Theorem Demonstration")
print("=" * 60)

# Example 1: Linear ODE (unique solution guaranteed)
print("\\n1. dy/dt = -y, y(0) = 1")
print("   Solution: y(t) = e^(-t)")
print("   Lipschitz constant L = 1")

# Example 2: Non-Lipschitz ODE (multiple solutions possible)
print("\\n2. dy/dt = sqrt(|y|), y(0) = 0")
print("   Multiple solutions exist!")
print("   Reason: f(y) = sqrt(|y|) is NOT Lipschitz at y=0")

def f1(y, t):
    return -y

def f2(y, t):
    return np.sqrt(np.abs(y))

t = np.linspace(0, 2, 100)
y1 = odeint(f1, 1, t)

print("\\nNumerical solution for case 1 computed successfully.")
print("Unique solution guaranteed by Picard-Lindelöf.")

3. Optimization: Gradient Descent Convergence

Introduction

Gradient descent and its variants power modern machine learning. For convex functions with Lipschitz continuous gradients, gradient descent enjoys guaranteed convergence.

Notation Guide

  • \f: ℝn → ℝ\ — objective function
  • \∇ f(x)\ — gradient
  • \x^*\ — optimal solution
  • L-smooth: \\\|∇ f(x) - ∇ f(y)\\| ≤ L\\|x - y\\|\
  • \κ = L/μ\ — condition number
Convergence for L-Smooth Convex Functions

With step size \η = \1/L\:

\

f(xk) - f^* ≤ \2L\\|x0 - x^*\\|2/k\

This is \O(1/k)\ convergence.

Linear Convergence for Strongly Convex

If \f\ is \μ\-strongly convex and L-smooth:

\

f(xk) - f^* ≤ 1 - \1/κk (f(x0) - f^*)\

Python Implementation

import numpy as np

def gradient_descent(f, grad_f, x0, step_size, n_iterations):
    """Standard gradient descent."""
    x = x0.copy()
    history = []
    
    for k in range(n_iterations):
        history.append(f(x))
        grad = grad_f(x)
        x = x - step_size * grad
    
    return x, history

# Quadratic function: f(x) = 0.5 * x^T A x - b^T x
A = np.diag([1.0, 10.0])  # Condition number = 10
b = np.array([1.0, 2.0])

f = lambda x: 0.5 * x.T @ A @ x - b.T @ x
grad_f = lambda x: A @ x - b

x0 = np.array([5.0, 8.0])
L = 10.0  # Lipschitz constant
step_size = 1.0 / L

x_opt, history = gradient_descent(f, grad_f, x0, step_size, 100)

print("Gradient Descent Convergence")
print("=" * 60)
print(f"Condition number: κ = 10")
print(f"Initial f(x): {history[0]:.6f}")
print(f"Final f(x): {history[-1]:.6f}")
print(f"Optimal f*: {f(np.linalg.solve(A, b)):.6f}")

1. Surreal Numbers

Introduction

Conceived by John Conway and popularized by Donald Knuth, surreal numbers extend the real numbers to include infinite and infinitesimal quantities in a coherent framework.

Notation Guide

  • \\\L | R\\\ — surreal number notation
  • \ω\ — simplest infinite surreal
  • \\varepsilon\ — infinitesimal
  • Birthday — ordinal at which a surreal is created
Conway's Simplicity Theorem

If \L\ and \R\ are sets of surreals with every element of \L\ less than every element of \R\, then there exists a unique simplest surreal \x = \\L | R\\\ with \xL < x < xR\.

Python Implementation

class SurrealNumber:

    def __init__(self, value=None, name=None):
        self.value = value
        self.name = name
    
    def __repr__(self):
        return self.name if self.name else str(self.value)

# Basic surreal numbers
Zero = SurrealNumber(0, "0")

MinusOne = SurrealNumber(-1, "-1")
Half = SurrealNumber(0.5, "1/2")

2. Fractals: The Mandelbrot Set

Introduction

The Mandelbrot set, discovered by Benoit Mandelbrot in 1980, is perhaps the most famous fractal. Its boundary exhibits infinite complexity at every scale.

Notation Guide

  • \fc(z) = z2 + c\ — quadratic polynomial
  • \M = \\c : \supn |fcn(0)| < ∞\\\ — Mandelbrot set
  • Escape radius: \|z| > 2\ implies escape
Escape Criterion

If \|z| > \max(2, |c|)\, then \|fcn(z)| → ∞\. The Mandelbrot set is contained in \|c| ≤ 2\.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute Mandelbrot iterations for complex c."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Compute Mandelbrot set
width, height = 800, 600
xmin, xmax = -2.5, 1.0
ymin, ymax = -1.25, 1.25

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Vectorized computation
M = np.vectorize(mandelbrot)(C)

print("Mandelbrot Set")
print("=" * 60)
print(f"Grid: {width} x {height}")
print(f"Region: [{xmin}, {xmax}] x [{ymin}, {ymax}]")
print(f"Points in set (black): {np.sum(M == 100)} / {M.size}")

# The set is connected (theorem by Douady and Hubbard, 1980s)
print("\\nTheorem: The Mandelbrot set is connected.")

3. Chaos Theory: The Lorenz Attractor

Introduction

In 1963, Edward Lorenz discovered one of the first examples of deterministic chaos—a system governed by simple equations that exhibits unpredictable behavior. This led to the famous "butterfly effect."

Notation Guide

  • \σ\ — Prandtl number
  • \ρ\ — Rayleigh number
  • \β\ — geometric factor
  • \λ\ — Lyapunov exponent
The Lorenz System

\

\beginaligned ẋ &= σ(y - x) \\\\[4pt] ẏ &= x(ρ - z) - y \\\\[4pt] ż &= xy - β z \endaligned\

with classic parameters \σ = 10\, \ρ = 28\, \β = 8/3\.

Python Implementation

import numpy as np
from scipy.integrate import odeint

# Lorenz parameters
sigma, rho, beta = 10.0, 28.0, 8.0/3.0

def lorenz(state, t):
    """Lorenz system equations."""
    x, y, z = state
    dxdt = sigma * (y - x)
    dydt = x * (rho - z) - y
    dzdt = x * y - beta * z
    return [dxdt, dydt, dzdt]

# Initial conditions
state0 = [1.0, 1.0, 1.0]
t = np.linspace(0, 50, 5000)

# Solve
solution = odeint(lorenz, state0, t)
x, y, z = solution[:, 0], solution[:, 1], solution[:, 2]

print("Lorenz Attractor")
print("=" * 60)
print(f"Parameters: σ={sigma}, ρ={rho}, β={beta:.4f}")
print(f"Initial state: {state0}")
print(f"Final state: [{x[-1]:.4f}, {y[-1]:.4f}, {z[-1]:.4f}]")

# Demonstrate sensitive dependence
state0_perturbed = [1.0001, 1.0, 1.0]
solution2 = odeint(lorenz, state0_perturbed, t)
x2 = solution2[:, 0]

print(f"\\nSensitive dependence on initial conditions:")
print(f"Initial difference: 0.0001")
print(f"Difference at t=50: {abs(x[-1] - x2[-1]):.4f}")
print("\\nThis is the 'butterfly effect'!")

4. Game Theory: Nash Equilibrium

Introduction

Nash Equilibrium, named after John Nash, is a fundamental concept in game theory where no player can benefit by unilaterally changing their strategy. It revolutionized economics and earned Nash the 1994 Nobel Prize in Economics.

Notation Guide

  • \G = (N, (Si), (ui))\ — a game with players \N\, strategy sets \Si\, and utilities \ui\
  • \s-i\ — strategies of all players except \i\
  • \BRi(s-i)\ — best response of player \i\
  • Mixed strategy — probability distribution over pure strategies
Nash's Existence Theorem (1950)

Every finite game has at least one Nash equilibrium in mixed strategies.

Proof Sketch (via Brouwer Fixed-Point)

Step 1: Define the best response correspondence \BR\ mapping strategy profiles to sets of best responses.

Step 2: Show \BR\ is upper hemicontinuous with non-empty convex values.

Step 3: Apply Kakutani's fixed-point theorem (or Brouwer for smooth approximations).

Step 4: A fixed point of \BR\ is a Nash equilibrium. ∎

Python Implementation

import numpy as np
from scipy.optimize import minimize

print("Nash Equilibrium")
print("=" * 60)

# Prisoner's Dilemma payoff matrix
# (Player 1 payoff, Player 2 payoff)
#        C       D
# C   (3,3)   (0,5)
# D   (5,0)   (1,1)

payoff_p1 = np.array([[3, 0], [5, 1]])  # Player 1 payoff
payoff_p2 = np.array([[3, 5], [0, 1]])  # Player 2 payoff

print("\\nPrisoner's Dilemma:")
print("Player 1 payoff matrix:")
print(payoff_p1)
print("\\nPlayer 2 payoff matrix:")
print(payoff_p2)

print("\\nAnalysis:")
print("- If P2 cooperates: P1 gets 3 (C) vs 5 (D) → Defect")
print("- If P2 defects: P1 gets 0 (C) vs 1 (D) → Defect")
print("\\nNash Equilibrium: (Defect, Defect) with payoffs (1, 1)")
print("This is Pareto inefficient! (Cooperate, Cooperate) gives (3,3)")

# Verify Nash equilibrium
def expected_payoff(p1_strategy, p2_strategy, payoff):
    """Calculate expected payoff given mixed strategies."""
    return p1_strategy @ payoff @ p2_strategy

# Nash equilibrium: both defect with probability 1
nash_p1 = np.array([0, 1])  # [P(Cooperate), P(Defect)]
nash_p2 = np.array([0, 1])

print(f"\\nAt Nash equilibrium:")
print(f"P1 expected payoff: {expected_payoff(nash_p1, nash_p2, payoff_p1)}")
print(f"P2 expected payoff: {expected_payoff(nash_p1, nash_p2, payoff_p2)}")

# Verify neither can improve by deviating
defect_payoff_p1 = expected_payoff(np.array([0, 1]), nash_p2, payoff_p1)
cooperate_payoff_p1 = expected_payoff(np.array([1, 0]), nash_p2, payoff_p1)
print(f"\\nIf P1 deviates to Cooperate: payoff = {cooperate_payoff_p1}")
print(f"P1 cannot improve by deviating: {cooperate_payoff_p1 <= defect_payoff_p1}")
