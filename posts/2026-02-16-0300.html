Set Theory: The Continuum Hypothesis

Theorem (Cantor, 1878; Cohen, 1963): The Continuum Hypothesis (CH) is independent of ZFC axioms.

Statement: There is no set whose cardinality is strictly between that of the integers and the real numbers:

nexists S : |ℕ| < |S| < |ℝ|

Notation Explanation:

  • |A| denotes the cardinality (size) of set A
  • aleph0 = |ℕ| is the cardinality of countably infinite sets
  • c = |ℝ| = 2aleph0 is the cardinality of the continuum
  • CH asserts aleph1 = 2aleph0

Proof Sketch (Cohen's Forcing):

Cohen developed the method of forcing to prove CH cannot be proved from ZFC:

  1. Start with a countable transitive model M of ZFC
  2. Add aleph2M many new "generic" reals via forcing poset
  3. Show the extension M[G] satisfies ZFC + neg CH

import itertools

def is_countable_example():
    """
    Show that Q (rationals) is countable by enumeration
    """
    rationals = set()
    # Cantor pairing: enumerate Q+ using diagonal argument
    for n in range(1, 20):
        for p in range(1, n+1):
            q = n - p + 1
            if q > 0:
                rationals.add((p, q))
    
    print("First 20 positive rationals p/q:")
    for i, (p, q) in enumerate(sorted(rationals, key=lambda x: x[0]/x[1])[:20]):
        print(f"{i+1}: {p}/{q} = {p/q:.3f}")
    
    return len(rationals)

def power_set_cardinality(n):
    """
    |P(S)| = 2^|S| for finite sets
    This extends to infinite sets: |P(N)| = 2^aleph_0 = c
    """
    from itertools import combinations
    S = list(range(n))
    power_set = []
    for r in range(n+1):
        power_set.extend(combinations(S, r))
    return len(power_set)  # Returns 2^n

Lie Theory: The Exponential Map

Theorem: For a matrix Lie group G with Lie algebra g, the exponential map exp: g to G is a local diffeomorphism near 0.

Definition: For X in g (an n times n matrix):

exp(X) = sumk=0infty Xk/k!

Notation Explanation:

  • g = Te G is the tangent space at identity (Lie algebra)
  • [X, Y] = XY - YX is the Lie bracket
  • exp connects the linear Lie algebra to the curved Lie group

Baker-Campbell-Hausdorff Formula:

log(exp X cdot exp Y) = X + Y + 1/2[X,Y] + 1/12[X,[X,Y]] - 1/12[Y,[X,Y]] + cdots

Proof Sketch:

The differential of exp at 0 is the identity:

d(exp)0(X) = .d/dt|t=0 exp(tX) = X

By the inverse function theorem, exp is a local diffeomorphism.

Modular Forms: The j-invariant

Theorem: The j-invariant is a modular function that gives a bijection:

j: SL2(ℤ)backslashmathbbH xrightarrow≅ ℂ

where mathbbH is the upper half-plane.

Definition: For tau in mathbbH:

j(tau) = 1728 g2(tau)3/g2(tau)3 - 27g3(tau)2 = 1728 g2(tau)3/Delta(tau)

Notation Explanation:

  • g2(tau) = 60 sum(m,n) neq (0,0) (mtau + n)-4 is the Eisenstein series of weight 4
  • g3(tau) = 140 sum(m,n) neq (0,0) (mtau + n)-6 is the Eisenstein series of weight 6
  • Delta(tau) = g2(tau)3 - 27g3(tau)2 is the modular discriminant (weight 12 cusp form)
  • The factor 1728 normalizes j(i) = 1728

Modular Transformation: For gamma = beginpmatrix a & b \\ c & d endpmatrix in SL2(ℤ):

j(atau + b/ctau + d) = j(tau)

Python: Computing the j-invariant

import numpy as np
from scipy.special import ellipk

def compute_eisenstein_g2_g3(tau, terms=100):
    """
    Compute Eisenstein series g2 and g3 for tau in upper half-plane
    g2 = 60 * sum_{(m,n)!=(0,0)} (m*tau + n)^(-4)
    g3 = 140 * sum_{(m,n)!=(0,0)} (m*tau + n)^(-6)
    """
    g2 = 0.0
    g3 = 0.0
    
    for m in range(-terms, terms+1):
        for n in range(-terms, terms+1):
            if m == 0 and n == 0:
                continue
            denom = m*tau + n
            if abs(denom) < 1e-10:
                continue
            inv_pow = 1.0 / (denom**4)
            g2 += inv_pow
            g3 += inv_pow / (denom**2)  # (m*tau+n)^(-6)
    
    g2 *= 60
    g3 *= 140
    
    return g2, g3

def j_invariant(tau, terms=50):
    """
    Compute j(tau) = 1728 * g2^3 / (g2^3 - 27*g3^2)
    """
    g2, g3 = compute_eisenstein_g2_g3(tau, terms)
    
    delta = g2**3 - 27*g3**2
    
    if abs(delta) < 1e-10:
        return float('inf')  # Pole
    
    j = 1728 * g2**3 / delta
    return j

Spectral Theory: The Rayleigh Quotient

Theorem (Rayleigh-Ritz): For a self-adjoint operator A on a Hilbert space H, the Rayleigh quotient:

R(x) = langle Ax, x rangle/langle x, x rangle, quad x neq 0

attains its minimum at the smallest eigenvalue lambda1 and its maximum (if bounded) at the largest eigenvalue.

Notation Explanation:

  • langle cdot, cdot rangle denotes the inner product on H
  • sigma(A) denotes the spectrum of A
  • lambda1 leq lambda2 leq cdots are eigenvalues (if discrete)

Courant-Fischer Minimax Theorem:

lambdak = mindim V = k maxx in V, x neq 0 R(x) = maxdim W = n-k+1 minx in W, x neq 0 R(x)

Proof Sketch:

For self-adjoint A, there exists an orthonormal basis of eigenvectors \ei\ with Aei = lambdai ei. Expanding x = sum ci ei:

R(x) = sum lambdai |ci|2/sum |ci|2

This is a weighted average of eigenvalues, so lambda1 leq R(x) leq lambdan.

Python: Eigenvalue Computation via Rayleigh Quotient

import numpy as np
from scipy.linalg import eigh

def rayleigh_quotient(A, x):
    """
    Compute R(x) = (x^* A x) / (x^* x)
    For Hermitian A, this gives a value in [lambda_min, lambda_max]
    """
    x = np.array(x, dtype=complex)
    numerator = np.vdot(x, A @ x)  # x^* A x
    denominator = np.vdot(x, x)     # x^* x = ||x||^2
    return numerator / denominator

def power_iteration(A, num_iterations=100):
    """
    Power iteration finds the eigenvector for largest eigenvalue
    using the Rayleigh quotient for convergence testing
    """
    n = A.shape[0]
    x = np.random.randn(n)
    x = x / np.linalg.norm(x)
    
    for i in range(num_iterations):
        # y = Ax
        y = A @ x
        # Normalize
        x_new = y / np.linalg.norm(y)
        
        # Rayleigh quotient gives eigenvalue estimate
        rayleigh = rayleigh_quotient(A, x_new)
        
        if i % 10 == 0:
            print(f"Iteration {i}: eigenvalue estimate = {rayleigh:.6f}")
        
        if np.allclose(x, x_new, atol=1e-10):
            break
        x = x_new
    
    return rayleigh, x

def inverse_iteration(A, sigma, num_iterations=50):
    """
    Inverse iteration with shift finds eigenvalue closest to sigma
    Uses Rayleigh quotient iteration for acceleration
    """
    n = A.shape[0]
    x = np.random.randn(n)
    x = x / np.linalg.norm(x)
    
    for i in range(num_iterations):
        # Solve (A - sigma*I) y = x
        y = np.linalg.solve(A - sigma * np.eye(n), x)
        x_new = y / np.linalg.norm(y)
        
        # Update shift using Rayleigh quotient (Rayleigh quotient iteration)
        sigma = rayleigh_quotient(A, x_new)
        
        if i % 10 == 0:
            print(f"Iteration {i}: shift = {sigma:.6f}")
        
        x = x_new
    
    return sigma, x

Partial Differential Equations: The Heat Equation

Theorem: The fundamental solution to the heat equation on ℝn:

partial u/partial t = Delta u = sumi=1n partial2 u/partial xi2

is given by the heat kernel:

Phi(x, t) = 1/(4pi t)n/2 e-|x|2/(4t), quad t > 0

Notation Explanation:

  • Delta is the Laplacian operator
  • |x|2 = x12 + cdots + xn2 is the squared Euclidean norm
  • Phi is also called the Gaussian kernel or fundamental solution

Solution Formula: For initial condition u(x, 0) = g(x):

u(x, t) = intℝn Phi(x - y, t) g(y) \, dy = (Phi(cdot, t) * g)(x)

Proof that Phi satisfies the heat equation:

Direct computation shows:

partial Phi/partial t = (-n/2t + |x|2/4t2)Phi
Delta Phi = sumi=1n partial2 Phi/partial xi2 = (-n/2t + |x|2/4t2)Phi

Hence partialt Phi = Delta Phi.

Python: Heat Equation Simulation

import numpy as np
import matplotlib.pyplot as plt

def heat_kernel(x, t, n=1):
    """
    Fundamental solution of heat equation on R^n
    Phi(x,t) = (4*pi*t)^(-n/2) * exp(-|x|^2/(4t))
    """
    if t <= 0:
        return np.zeros_like(x)
    norm_sq = np.sum(x**2, axis=-1) if x.ndim > 1 else x**2
    return (4 * np.pi * t)**(-n/2) * np.exp(-norm_sq / (4*t))

def solve_heat_1d_fourier(u0, L, T, nx=100, nt=1000, alpha=1.0):
    """
    Solve 1D heat equation on [0,L] with Dirichlet BCs using FTCS
    u_t = alpha * u_xx
    """
    dx = L / (nx - 1)
    dt = T / nt
    
    # Stability condition: alpha * dt / dx^2 <= 0.5
    r = alpha * dt / dx**2
    if r > 0.5:
        print(f"Warning: r = {r:.3f} > 0.5, solution may be unstable")
    
    x = np.linspace(0, L, nx)
    u = u0(x).copy()
    
    # Time stepping
    for n in range(nt):
        u_new = u.copy()
        # FTCS scheme
        for i in range(1, nx-1):
            u_new[i] = u[i] + r * (u[i+1] - 2*u[i] + u[i-1])
        # Boundary conditions (Dirichlet: u=0 at boundaries)
        u_new[0] = 0
        u_new[-1] = 0
        u = u_new
    
    return x, u

def solve_heat_fundamental_solution(g, x, t, n=1):
    """
    Solve heat equation using convolution with heat kernel
    u(x,t) = integral Phi(x-y,t) * g(y) dy
    """
    dx = x[1] - x[0]
    u = np.zeros_like(x)
    
    for i, xi in enumerate(x):
        # Convolution integral
        kernel = heat_kernel(xi - x, t, n)
        u[i] = np.trapz(kernel * g, x)
    
    return u

Machine Learning Theory: PAC Learning

Theorem (PAC Learning Bound): For a hypothesis class H with finite VC dimension d, with probability at least 1 - delta, any hypothesis h in H consistent with m i.i.d. training examples has generalization error:

err(h) leq O(d log(m/d) + log(1/delta)/m)

Notation Explanation:

  • PAC = Probably Approximately Correct
  • VC dimension = Vapnik-Chervonenkis dimension (measure of hypothesis class complexity)
  • err(h) = P(h(X) neq Y) is the true error
  • err̂(h) is the empirical error on training data

VC Dimension Definition: The largest m such that H can shatter some set of m points:

VC(H) = max\m : exists S subseteq X, |S| = m, PiH(S) = 2m\

Sauer-Shelah Lemma: For m geq d = VC(H):

PiH(m) leq sumi=0d binommi leq (em/d)d

Python: VC Dimension and Generalization Bounds

import numpy as np
from itertools import combinations

def shatterable(points, hypothesis_class):
    """
    Check if hypothesis class can shatter the given points
    (realize all 2^m possible labelings)
    """
    m = len(points)
    for labeling in range(2**m):
        labels = [(labeling >> i) & 1 for i in range(m)]
        found = False
        for h in hypothesis_class:
            if all(h(points[i]) == labels[i] for i in range(m)):
                found = True
                break
        if not found:
            return False
    return True

def vc_dimension_1d_intervals():

    return 2

def sauer_shelah_bound(m, d):
    """
    Sauer-Shelah lemma: growth function bounded by (em/d)^d
    """
    import math
    if m <= d:
        return 2**m
    return int((math.e * m / d)**d)

def pac_sample_complexity(epsilon, delta, d):
    """
    Sample complexity for PAC learning:
    m >= (d + log(1/delta)) / epsilon
    
    More precise bound:
    m = O((d*log(1/epsilon) + log(1/delta))/epsilon)
    """
    import math
    # Simplified bound
    m_basic = (d + np.log(1/delta)) / epsilon
    # Tighter bound
    m_tight = (d * np.log(1/epsilon) + np.log(1/delta)) / epsilon
    return m_basic, m_tight

Coding Theory: Reed-Solomon Codes

Theorem: A Reed-Solomon code with parameters [n, k, d] over mathbbFq satisfies:

d = n - k + 1

achieving the Singleton bound (MDS code).

Construction: Let mathbbFq be a finite field with q > n. Choose distinct alpha1, ldots, alphan in mathbbFq. For message polynomial m(x) = m0 + m1 x + cdots + mk-1 xk-1:

RS(m) = (m(alpha1), m(alpha2), ldots, m(alphan))

Notation Explanation:

  • [n, k, d]: block length n, dimension k, minimum distance d
  • mathbbFq: finite field with q elements (q = pm)
  • MDS = Maximum Distance Separable
  • Can correct up to lfloor (d-1)/2 rfloor = lfloor (n-k)/2 rfloor errors

Decoding (Berlekamp-Welch): Given received word (r1, ldots, rn) with at most e errors, find polynomials N(x) and E(x) with deg(N) leq k-1+e, deg(E) = e such that:

N(alphai) = ri E(alphai) quad for all i

Then m(x) = N(x)/E(x).

import numpy as np

class FiniteField:
    """Simple implementation of GF(p) for prime p"""
    def __init__(self, p):
        self.p = p
    
    def add(self, a, b):
        return (a + b) % self.p
    
    def sub(self, a, b):
        return (a - b) % self.p
    
    def mul(self, a, b):
        return (a * b) % self.p
    
    def inv(self, a):
        """Multiplicative inverse using extended Euclidean algorithm"""
        if a == 0:
            raise ValueError("Zero has no inverse")
        def extended_gcd(a, b):
            if b == 0:
                return a, 1, 0
            g, x1, y1 = extended_gcd(b, a % b)
            return g, y1, x1 - (a // b) * y1
        
        g, x, _ = extended_gcd(a % self.p, self.p)
        return x % self.p
    
    def div(self, a, b):
        return self.mul(a, self.inv(b))

class ReedSolomon:
    """
    Reed-Solomon code [n, k] over GF(p)
    Message: k field elements -> Codeword: n field elements
    """
    def __init__(self, p, n, k, evaluation_points=None):
        self.ff = FiniteField(p)
        self.p = p
        self.n = n
        self.k = k
        
        if evaluation_points is None:
            # Use 0, 1, 2, ..., n-1 as evaluation points
            self.alpha = list(range(n))
        else:
            self.alpha = evaluation_points[:n]
        
        self.d = n - k + 1  # Minimum distance
        self.t = (n - k) // 2  # Error correction capability
    
    def encode(self, message):
        """
        Encode message [m_0, ..., m_{k-1}] as polynomial m(x)
        Return [m(alpha_0), ..., m(alpha_{n-1})]
        """
        codeword = []
        for a in self.alpha:
            # Evaluate m(a) = sum m_i * a^i
            val = 0
            power = 1
            for m in message:
                val = self.ff.add(val, self.ff.mul(m, power))
                power = self.ff.mul(power, a)
            codeword.append(val)
        return codeword
    
    def lagrange_interpolate(self, points, values):
        """
        Lagrange interpolation: find polynomial of degree < len(points)
        such that f(points[i]) = values[i]
        """
        k = len(points)
        # Result polynomial coefficients
        result = [0] * k
        
        for i in range(k):
            # Compute Lagrange basis polynomial L_i
            # L_i(x) = prod_{j!=i} (x - x_j) / (x_i - x_j)
            
            # Numerator: prod_{j!=i} (x - x_j)
            numer = [1]  # Start with constant 1
            for j in range(k):
                if i != j:
                    # Multiply by (x - x_j) = [-x_j, 1]
                    new_numer = [0] * (len(numer) + 1)
                    for deg, coeff in enumerate(numer):
                        # coeff * (-x_j)
                        new_numer[deg] = self.ff.add(new_numer[deg], 
                                                     self.ff.mul(coeff, self.ff.sub(0, points[j])))
                        # coeff * x
                        new_numer[deg + 1] = self.ff.add(new_numer[deg + 1], coeff)
                    numer = new_numer
            
            # Denominator: prod_{j!=i} (x_i - x_j)
            denom = 1
            for j in range(k):
                if i != j:
                    denom = self.ff.mul(denom, self.ff.sub(points[i], points[j]))
            
            # Add values[i] * L_i to result
            inv_denom = self.ff.inv(denom)
            for deg in range(len(numer)):
                coeff = self.ff.mul(numer[deg], self.ff.mul(values[i], inv_denom))
                result[deg] = self.ff.add(result[deg], coeff)
        
        return result
    
    def decode_berlekamp_welch(self, received):
        """
        Berlekamp-Welch decoding
        Can correct up to t = (n-k)//2 errors
        """
        # For simplicity, use direct interpolation if no errors
        # In practice, solve the BW linear system
        
        # Find k correct positions (brute force for demonstration)
        from itertools import combinations
        
        for correct_indices in combinations(range(self.n), self.k):
            points = [self.alpha[i] for i in correct_indices]
            values = [received[i] for i in correct_indices]
            
            # Interpolate polynomial
            poly = self.lagrange_interpolate(points, values)
            
            # Check if it matches on at least n-t positions
            matches = 0
            for i, a in enumerate(self.alpha):
                # Evaluate polynomial at a
                val = 0
                power = 1
                for coeff in poly:
                    val = self.ff.add(val, self.ff.mul(coeff, power))
                    power = self.ff.mul(power, a)
                
                if val == received[i]:
                    matches += 1
            
            if matches >= self.n - self.t:
                return poly
        
        return None  # Decoding failed

Matroid Theory: The Tutte Polynomial

Theorem: The Tutte polynomial TM(x, y) of a matroid M is a universal deletion-contraction invariant defined by:

TM(x, y) = begincases 1 & if M has no elements \\ x cdot TM/e(x, y) & if e is a coloop \\ y cdot TM setminus e(x, y) & if e is a loop \\ TM setminus e(x, y) + TM/e(x, y) & otherwise endcases

Notation Explanation:

  • M setminus e: deletion of element e
  • M / e: contraction of element e
  • Loop: element e with r(\e\) = 0
  • Coloop (isthmus): element e with r(E) = r(E setminus \e\) + 1
  • r(A): rank of set A in the matroid

Rank Generating Function:

TM(x, y) = sumA subseteq E (x-1)r(E) - r(A) (y-1)|A| - r(A)

Specializations:

  • TM(2, 1): number of spanning forests
  • TM(1, 2): number of spanning connected subgraphs
  • TM(2, 0): number of acyclic orientations
  • TM(0, 2): number of totally cyclic orientations
  • TM(1, 1): number of spanning trees (for graphs)

Python: Computing the Tutte Polynomial

from itertools import combinations

class Matroid:
    """
    Simple matroid representation using rank function
    For graphic matroids: rank(A) = n - c(A) where c(A) is number of components
    """
    def __init__(self, ground_set, rank_func):
        self.E = list(ground_set)
        self.rank = rank_func
        self.rE = rank_func(self.E)
    
    def delete(self, e):
        """Delete element e from matroid"""
        new_E = [x for x in self.E if x != e]
        def new_rank(A):
            return self.rank([x for x in A if x != e])
        return Matroid(new_E, new_rank)
    
    def contract(self, e):
        """Contract element e from matroid"""
        if e not in self.E:
            raise ValueError("Element not in ground set")
        
        new_E = [x for x in self.E if x != e]
        r_e = self.rank([e])
        
        def new_rank(A):
            # r_{M/e}(A) = r_M(A union {e}) - r_M({e})
            A_with_e = A + [e]
            return self.rank(A_with_e) - r_e
        
        return Matroid(new_E, new_rank)
    
    def is_loop(self, e):
        """e is a loop if r({e}) = 0"""
        return self.rank([e]) == 0
    
    def is_coloop(self, e):
        """e is a coloop if r(E) = r(E\\{e}) + 1"""
        E_without_e = [x for x in self.E if x != e]
        return self.rE == self.rank(E_without_e) + 1

def tutte_polynomial(M, memo=None):
    """
    Compute Tutte polynomial using deletion-contraction recurrence
    Returns dict mapping (i,j) to coefficient of x^i y^j
    """
    if memo is None:
        memo = {}
    
    # Create hashable key
    key = frozenset(M.E)
    if key in memo:
        return memo[key]
    
    # Base case: no elements
    if len(M.E) == 0:
        return {(0, 0): 1}
    
    # Choose an element
    e = M.E[0]
    
    if M.is_coloop(e):
        # T(M) = x * T(M/e)
        T_contract = tutte_polynomial(M.contract(e), memo)
        result = {(i+1, j): coeff for (i, j), coeff in T_contract.items()}
    elif M.is_loop(e):
        # T(M) = y * T(M\\e)
        T_delete = tutte_polynomial(M.delete(e), memo)
        result = {(i, j+1): coeff for (i, j), coeff in T_delete.items()}
    else:
        # T(M) = T(M\\e) + T(M/e)
        T_delete = tutte_polynomial(M.delete(e), memo)
        T_contract = tutte_polynomial(M.contract(e), memo)
        
        result = {}
        for (i, j), coeff in T_delete.items():
            result[(i, j)] = result.get((i, j), 0) + coeff
        for (i, j), coeff in T_contract.items():
            result[(i, j)] = result.get((i, j), 0) + coeff
    
    memo[key] = result
    return result

def graphic_matroid_from_edges(n_vertices, edges):
    """
    Create graphic matroid from graph with n vertices and list of edges
    Each edge is a tuple (u, v) where u, v are vertex indices
    """
    edge_labels = list(range(len(edges)))
    
    def rank_func(A):
        """Rank of edge set A in graphic matroid = n - c where c = number of connected components"""
        if not A:
            return 0
        
        # Build adjacency for subgraph induced by edges in A
        adj = [[] for _ in range(n_vertices)]
        for e_idx in A:
            u, v = edges[e_idx]
            adj[u].append(v)
            adj[v].append(u)
        
        # Count connected components using DFS
        visited = [False] * n_vertices
        components = 0
        
        for start in range(n_vertices):
            if not visited[start]:
                components += 1
                stack = [start]
                visited[start] = True
                while stack:
                    u = stack.pop()
                    for v in adj[u]:
                        if not visited[v]:
                            visited[v] = True
                            stack.append(v)
        
        # Rank = n - number of components
        # But we need to account for isolated vertices with no edges
        # Actually, rank only depends on edges present
        return n_vertices - components
    
    return Matroid(edge_labels, rank_func)

def print_tutte_polynomial(T):
    """Pretty print Tutte polynomial"""
    terms = []
    for (i, j), coeff in sorted(T.items()):
        if coeff == 0:
            continue
        term = ""
        if coeff != 1 or (i == 0 and j == 0):
            term += str(coeff)
        if i > 0:
            term += f"x^{i}" if i > 1 else "x"
        if j > 0:
            term += f"y^{j}" if j > 1 else "y"
        terms.append(term)
    return " + ".join(terms) if terms else "0"

Symplectic Geometry: The Moment Map

Theorem (Atiyah-Guillemin-Sternberg): Let (M, omega) be a compact connected symplectic manifold with a Hamiltonian torus action Tk curvearrowright M. The image of the moment map mu: M to (tk)^* ≅ ℝk is a convex polytope, the convex hull of the images of the fixed points.

Definition: For a Hamiltonian action of Lie group G on (M, omega), the moment map mu: M to g^* satisfies:

dlangle mu, xi rangle = iotaX_xi omega

for all xi in g, where X_xi is the vector field generated by xi.

Notation Explanation:

  • ω: symplectic form (closed, non-degenerate 2-form)
  • g: Lie algebra of G
  • g^*: dual Lie algebra
  • iotaX omega: interior product (contraction)
  • X_xi: fundamental vector field: X_xi(p) = .d/dt|t=0 exp(txi) cdot p

Equivariance: The moment map is G-equivariant:

mu(g cdot p) = Ad^*g mu(p)

Example: S1 action on ℂn:

eitheta cdot (z1, ldots, zn) = (eithetaz1, ldots, eithetazn)

with moment map:

mu(z) = 1/2sumj=1n |zj|2

class SymplecticTorusAction:
    """
    Hamiltonian torus action on C^n
    Moment map: mu(z) = (1/2) * (|z_1|^2, ..., |z_n|^2) for standard action
    """
    def __init__(self, weights=None):
        """
        weights: list of weight vectors for T^k action on C^n
        If None, use standard diagonal action
        """
        self.weights = weights
    
    def moment_map(self, z):
        """
        Compute moment map mu(z)
        For standard action: mu(z)_i = (1/2) * |z_i|^2
        """
        z = np.array(z)
        if self.weights is None:
            # Standard action
            return 0.5 * np.abs(z)**2
        else:
            # Weighted action
            result = []
            for w in self.weights:
                val = 0.5 * sum(w[i] * abs(z[i])**2 for i in range(len(z)))
                result.append(val)
            return np.array(result)
    
    def moment_map_image(self, n_samples=10000, max_radius=2):
        """
        Sample points and compute moment map image
        """
        if self.weights is not None and len(self.weights[0]) > 2:
            raise ValueError("Can only visualize in 2D")
        
        samples = []
        for _ in range(n_samples):
            # Random point in C^n (or C^2 for visualization)
            n = len(self.weights[0]) if self.weights else 2
            z = np.random.randn(n) + 1j * np.random.randn(n)
            z = z * max_radius / (np.linalg.norm(z) + 0.1)
            
            mu = self.moment_map(z)
            samples.append(mu)
        
        return np.array(samples)

Geometric Group Theory: Hyperbolic Groups

Theorem (Gromov): A finitely generated group Gamma is hyperbolic if and only if its Cayley graph satisfies the thin triangle condition: there exists delta geq 0 such that any side of a geodesic triangle is contained in the δ-neighborhood of the union of the other two sides.

Definition: A geodesic metric space (X, d) is δ-hyperbolic if for all geodesic triangles Delta = [x, y] cup [y, z] cup [z, x]:

[x, y] subseteq N_delta([y, z] cup [z, x])

where N_delta(A) denotes the δ-neighborhood of A.

Notation Explanation:

  • Gamma: finitely generated group
  • Cay(Gamma, S): Cayley graph with respect to generating set S
  • |g|: word length of g in Gamma with respect to S
  • partial Gamma: Gromov boundary (space of geodesic rays)

Linear Isoperimetric Inequality: For hyperbolic groups, any loop of length n in the Cayley graph can be filled with a disk of area O(n):

Area(w) leq C cdot |w|

for any word w representing the identity.

Python: Hyperbolicity in Cayley Graphs

from collections import deque, defaultdict

class CayleyGraph:
    """
    Cayley graph of a finitely presented group
    """
    def __init__(self, generators, relations=None, max_radius=10):
        """
        generators: list of generator labels
        relations: list of words equal to identity (optional, for verification)
        """
        self.generators = generators
        self.relations = relations or []
        self.max_radius = max_radius
        
        # Build graph up to max_radius
        self.vertices = {('', 0)}  # (reduced_word, distance_from_identity)
        self.edges = defaultdict(list)
        self._build_graph()
    
    def reduce_word(self, word):
        """
        Reduce word by canceling adjacent inverse pairs
        For free groups, this gives the unique reduced form
        """
        # Simple reduction: cancel xx^{-1} and x^{-1}x
        # Represent inverses as uppercase
        stack = []
        for char in word:
            if stack and self._are_inverses(stack[-1], char):
                stack.pop()
            else:
                stack.append(char)
        return ''.join(stack)
    
    def _are_inverses(self, a, b):
        """Check if a and b are inverses"""
        return (a.lower() == b.lower() and a != b) or \
               (a == b.lower() and a != b)
    
    def _build_graph(self):
        """Build Cayley graph up to max_radius using BFS"""
        queue = deque([('', 0)])
        visited = {''}
        
        while queue:
            word, dist = queue.popleft()
            if dist >= self.max_radius:
                continue
            
            for g in self.generators:
                # Multiply by generator
                new_word = self.reduce_word(word + g)
                
                if new_word not in visited:
                    visited.add(new_word)
                    queue.append((new_word, dist + 1))
                    self.vertices.add((new_word, dist + 1))
                
                # Add edge
                if new_word != word:
                    self.edges[word].append(new_word)
                    self.edges[new_word].append(word)
    
    def distance(self, word1, word2):
        """
        Word metric: distance from word1 to word2
        d(g, h) = |g^{-1}h|
        """
        # Compute g^{-1}h
        inv_g1 = self._inverse(word1)
        product = self.reduce_word(inv_g1 + word2)
        return len(product)
    
    def _inverse(self, word):
        """Compute inverse of word"""
        return ''.join(self._invert_char(c) for c in reversed(word))
    
    def _invert_char(self, c):
        """Invert a single character"""
        return c.upper() if c.islower() else c.lower()
    
    def geodesic(self, word1, word2):
        """
        Find a geodesic (shortest path) from word1 to word2
        Returns list of vertices
        """
        if word1 == word2:
            return [word1]
        
        # BFS for shortest path
        queue = deque([(word1, [word1])])
        visited = {word1}
        
        while queue:
            current, path = queue.popleft()
            
            for neighbor in self.edges[current]:
                if neighbor == word2:
                    return path + [neighbor]
                
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append((neighbor, path + [neighbor]))
        
        return None  # No path found

def thin_triangle_constant(cayley, num_triangles=100):
    """
    Estimate the thin triangle constant delta for a Cayley graph
    by sampling random geodesic triangles
    """
    vertices_list = [v for v, d in cayley.vertices if d < cayley.max_radius - 5]
    
    if len(vertices_list) < 3:
        return None
    
    max_delta = 0
    
    import random
    random.seed(42)
    
    for _ in range(num_triangles):
        # Sample three random vertices
        x, y, z = random.sample(vertices_list, 3)
        
        # Find geodesics
        xy = cayley.geodesic(x, y)
        yz = cayley.geodesic(y, z)
        zx = cayley.geodesic(z, x)
        
        if not all([xy, yz, zx]):
            continue
        
        # Check how thin the triangle is
        # For each point on xy, find distance to yz union zx
        delta_this_triangle = 0
        
        for p in xy:
            min_dist_to_other = float('inf')
            for q in yz + zx:
                dist = cayley.distance(p, q)
                min_dist_to_other = min(min_dist_to_other, dist)
            delta_this_triangle = max(delta_this_triangle, min_dist_to_other)
        
        max_delta = max(max_delta, delta_this_triangle)
    
    return max_delta

def free_group_rank_n(n, max_radius=8):
    """
    Free group F_n on n generators
    Cayley graph is a tree (4-regular for F_2)
    """
    generators = [chr(ord('a') + i) for i in range(n)]
    generators += [g.upper() for g in generators]  # Add inverses
    return CayleyGraph(generators, max_radius=max_radius)

def surface_group_genus_g(g, max_radius=6):
    """
    Surface group of genus g:
    
    
    For g >= 2, this is hyperbolic
    """
    generators = []
    for i in range(g):
        generators.extend([f'a{i}', f'b{i}'])
    generators += [c.upper() for c in generators]
    
    # The relation [a1,b1]...[ag,bg] = 1
    # where [a,b] = aba^{-1}b^{-1}
    
    return CayleyGraph(generators, max_radius=max_radius)
