1. Sylow's Theorems (Group Theory)

Sylow's theorems are fundamental results about the structure of finite groups, providing partial converses to Lagrange's theorem.

Sylow's First Theorem: Let \(G\) be a finite group with \(|G| = p^n \cdot m\) where \(p\) is prime and \(p \nmid m\). Then there exists a subgroup of order \(p^n\), called a Sylow \(p\)-subgroup.
Sylow's Second Theorem: All Sylow \(p\)-subgroups are conjugate to each other.
Sylow's Third Theorem: If \(n_p\) is the number of Sylow \(p\)-subgroups, then \(n_p \equiv 1 \pmod{p}\) and \(n_p \mid m\).
Key Idea of Proof (First Theorem): Uses induction and the class equation. Consider the action of \(G\) on itself by conjugation. The fixed points of this action are in the center \(Z(G)\). If \(p \mid |Z(G)|\), Cauchy's theorem gives an element of order \(p\), and we apply induction to the quotient. Otherwise, some conjugacy class has size not divisible by \(p\), and we apply induction to the centralizer.

Notation explained:

  • \(|G|\) — order (number of elements) of group \(G\)
  • \(p^n \parallel |G|\) — \(p^n\) is the highest power of \(p\) dividing \(|G|\)
  • \(n_p\) — number of Sylow \(p\)-subgroups
  • \(H \trianglelefteq G\) — \(H\) is a normal subgroup of \(G\)
# Python: Finding Sylow subgroups for small groups
from itertools import combinations

def sylow_info(group_order, p):
    """
    Calculate Sylow p-subgroup information.
    Returns (p^n, m, possible_n_p) where |G| = p^n * m
    """
    n = 0
    temp = group_order
    while temp % p == 0:
        n += 1
        temp //= p
    p_n = p ** n
    m = temp
    
    # n_p must satisfy: n_p ≡ 1 (mod p) and n_p | m
    possible_n_p = []
    for np in range(1, m + 1):
        if m % np == 0 and np % p == 1:
            possible_n_p.append(np)
    
    return p_n, m, possible_n_p

# Example: Group of order 12 = 2^2 * 3
print("Group of order 12:")

print(f"  Sylow 2-subgroups: order {p2}, possible n_2 = {np2}")
p3, m3, np3 = sylow_info(12, 3)
print(f"  Sylow 3-subgroups: order {p3}, possible n_3 = {np3}")

# Example: Group of order 30 = 2 * 3 * 5
print("\nGroup of order 30:")
for p in [2, 3, 5]:
    p_n, m, np = sylow_info(30, p)
    print(f"  Sylow {p}-subgroups: order {p_n}, possible n_{p} = {np}")

2. Heine-Borel Theorem (Real Analysis)

The Heine-Borel theorem characterizes compact subsets of Euclidean space, connecting the analytical notion of compactness to the topological one.

Heine-Borel Theorem: A subset \(S \subseteq \mathbb{R}^n\) is compact if and only if it is closed and bounded.
Proof (\(\Rightarrow\)): Compact implies closed and bounded.
Bounded: If \(S\) is unbounded, the open cover \(\{B(0, n) : n \in \mathbb{N}\}\) has no finite subcover.
Closed: Compact subsets of Hausdorff spaces are closed. \(\mathbb{R}^n\) is Hausdorff.
Proof (\(\Leftarrow\)): Closed and bounded implies compact.
Since \(S\) is bounded, \(S \subseteq [-M, M]^n\) for some \(M > 0\). The closed interval \([-M, M]\) is compact (by the Bolzano-Weierstrass theorem or direct proof). Finite products of compact spaces are compact (Tychonoff for finite products), so \([-M, M]^n\) is compact. Closed subsets of compact spaces are compact, so \(S\) is compact.

Notation explained:

  • \(S \subseteq \mathbb{R}^n\) — \(S\) is a subset of \(n\)-dimensional Euclidean space
  • \(B(0, n)\) — open ball centered at origin with radius \(n\)
  • Compact — every open cover has a finite subcover
  • Hausdorff — distinct points have disjoint neighborhoods

3. Residue Theorem (Complex Analysis)

The Residue Theorem is one of the most powerful tools in complex analysis, allowing the evaluation of complex integrals using local behavior at singularities.

Residue Theorem: Let \(f\) be analytic inside and on a simple closed contour \(C\), except for isolated singularities \(z_1, z_2, \ldots, z_n\) inside \(C\). Then: \[\oint_C f(z)\, dz = 2\pi i \sum_{k=1}^n \text{Res}(f, z_k)\]
Definition of Residue: If \(f\) has an isolated singularity at \(z_0\), the residue is: \[\text{Res}(f, z_0) = \frac{1}{2\pi i} \oint_{|z-z_0|=\epsilon} f(z)\, dz = a_{-1}\] where \(a_{-1}\) is the coefficient of \((z-z_0)^{-1}\) in the Laurent series expansion.
Proof Sketch: By Cauchy's theorem, deform \(C\) to small circles around each singularity. The integral over each small circle gives \(2\pi i\) times the residue. The sum follows from linearity of integration.

Notation explained:

  • \(\oint_C\) — contour integral around closed path \(C\)
  • \(\text{Res}(f, z_k)\) — residue of \(f\) at \(z_k\)
  • Laurent series — \(f(z) = \sum_{n=-\infty}^{\infty} a_n (z-z_0)^n\)
  • \(a_{-1}\) — coefficient of the \((z-z_0)^{-1}\) term
# Python: Computing residues and contour integrals
import numpy as np
from scipy import integrate
import cmath

def laurent_coeff(f, z0, n, epsilon=1e-6):
    """
    Compute the n-th Laurent coefficient using contour integration.
    a_n = (1/2πi) ∮ f(z)/(z-z0)^(n+1) dz
    """
    def integrand(theta):
        z = z0 + epsilon * cmath.exp(1j * theta)
        dz = 1j * epsilon * cmath.exp(1j * theta)
        return (f(z) / (z - z0)**(n + 1)) * dz
    
    result, _ = integrate.quad(lambda t: integrand(t).real, 0, 2*np.pi)
    result_imag, _ = integrate.quad(lambda t: integrand(t).imag, 0, 2*np.pi)
    return (result + 1j * result_imag) / (2 * np.pi * 1j)

def residue(f, z0, epsilon=1e-6):
    """Compute the residue of f at z0 (coefficient a_{-1})."""
    return laurent_coeff(f, z0, -1, epsilon)

# Example: f(z) = 1/z has residue 1 at z=0
f = lambda z: 1/z
print(f"Residue of 1/z at z=0: {residue(f, 0)}")

# Example: f(z) = 1/(z^2 + 1) = 1/((z-i)(z+i))
# Simple poles at z = i and z = -i
f2 = lambda z: 1/(z**2 + 1)
print(f"Residue of 1/(z^2+1) at z=i: {residue(f2, 1j)}")
print(f"Residue of 1/(z^2+1) at z=-i: {residue(f2, -1j)}")

# Verify: integral around both poles should be 2πi * (sum of residues)
def contour_integral(f, center, radius):
    """Compute ∮ f(z) dz around circle."""
    def integrand(theta):
        z = center + radius * cmath.exp(1j * theta)
        dz = 1j * radius * cmath.exp(1j * theta)
        return (f(z) * dz).real
    
    def integrand_imag(theta):
        z = center + radius * cmath.exp(1j * theta)
        dz = 1j * radius * cmath.exp(1j * theta)
        return (f(z) * dz).imag
    
    real_part, _ = integrate.quad(integrand, 0, 2*np.pi)
    imag_part, _ = integrate.quad(integrand_imag, 0, 2*np.pi)
    return real_part + 1j * imag_part

# Large circle enclosing both poles
integral = contour_integral(f2, 0, 2)
print(f"\nContour integral around |z|=2: {integral}")
print(f"2πi × (sum of residues): {2*np.pi*1j * (residue(f2, 1j) + residue(f2, -1j))}")

1. Kalman Filter (Estimation Theory)

The Kalman filter is an optimal recursive algorithm for estimating the state of a linear dynamic system from noisy measurements.

Kalman Filter Equations:
Prediction: \[\hat{x}_{k|k-1} = F_k \hat{x}_{k-1|k-1} + B_k u_k\] \[P_{k|k-1} = F_k P_{k-1|k-1} F_k^T + Q_k\] Update: \[K_k = P_{k|k-1} H_k^T (H_k P_{k|k-1} H_k^T + R_k)^{-1}\] \[\hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k (z_k - H_k \hat{x}_{k|k-1})\] \[P_{k|k} = (I - K_k H_k) P_{k|k-1}\]

Notation explained:

  • \(\hat{x}_{k|k-1}\) — predicted state estimate at time \(k\)
  • \(\hat{x}_{k|k}\) — updated state estimate
  • \(P\) — error covariance matrix
  • \(K_k\) — Kalman gain
  • \(F_k\) — state transition matrix
  • \(H_k\) — observation matrix
  • \(Q_k\) — process noise covariance
  • \(R_k\) — measurement noise covariance
# Python: Kalman Filter implementation
import numpy as np

class KalmanFilter:
    def __init__(self, F, B, H, Q, R, x0, P0):
        """
        Initialize Kalman Filter.
        
        F: State transition matrix
        B: Control input matrix  
        H: Observation matrix
        Q: Process noise covariance
        R: Measurement noise covariance
        x0: Initial state estimate
        P0: Initial error covariance
        """
        self.F = F
        self.B = B
        self.H = H
        self.Q = Q
        self.R = R
        self.x = x0
        self.P = P0
        
    def predict(self, u=None):
        """Prediction step."""
        # State prediction
        if u is not None:
            self.x = self.F @ self.x + self.B @ u
        else:
            self.x = self.F @ self.x
        # Covariance prediction
        self.P = self.F @ self.P @ self.F.T + self.Q
        return self.x, self.P
    
    def update(self, z):
        """Update step with measurement z."""
        # Innovation (measurement residual)
        y = z - self.H @ self.x
        # Innovation covariance
        S = self.H @ self.P @ self.H.T + self.R
        # Kalman gain
        K = self.P @ self.H.T @ np.linalg.inv(S)
        # State update
        self.x = self.x + K @ y
        # Covariance update (Joseph form for numerical stability)
        I_KH = np.eye(len(self.x)) - K @ self.H
        self.P = I_KH @ self.P @ I_KH.T + K @ self.R @ K.T
        return self.x, self.P

# Example: Tracking a moving object in 1D
# State: [position, velocity]
dt = 0.1  # time step
F = np.array([[1, dt],   # position += velocity * dt
              [0, 1]])   # velocity constant
B = np.array([[0.5*dt**2],  # acceleration affects position
              [dt]])         # acceleration affects velocity
H = np.array([[1, 0]])  # We only measure position

# Noise covariances
Q = np.array([[0.01, 0],
              [0, 0.001]])  # Process noise
R = np.array([[0.1]])       # Measurement noise

# Initial conditions
x0 = np.array([0, 1])  # Start at position 0, velocity 1
P0 = np.eye(2)

kf = KalmanFilter(F, B, H, Q, R, x0, P0)

# Simulate true trajectory with acceleration
np.random.seed(42)
true_positions = []
measurements = []
estimates = []

position, velocity = 0, 1
for k in range(100):
    # True dynamics with random acceleration
    acceleration = 0.05 + 0.02 * np.random.randn()
    velocity += acceleration * dt
    position += velocity * dt
    true_positions.append(position)
    
    # Noisy measurement
    measurement = position + 0.3 * np.random.randn()
    measurements.append(measurement)
    
    # Kalman filter
    kf.predict(u=np.array([acceleration]))
    x_est, _ = kf.update(np.array([measurement]))
    estimates.append(x_est[0])

print(f"Final measurement: {measurements[-1]:.3f}")

2. Principal Component Analysis (Dimensionality Reduction)

PCA is a fundamental technique for dimensionality reduction, finding the directions of maximum variance in data.

PCA Optimization Problem: Given data matrix \(X \in \mathbb{R}^{n \times d}\) (centered), find orthonormal vectors \(w_1, \ldots, w_k\) that maximize: \[\sum_{i=1}^k w_i^T \Sigma w_i\] where \(\Sigma = \frac{1}{n} X^T X\) is the covariance matrix.
PCA Solution: The optimal \(w_i\) are the eigenvectors of \(\Sigma\) corresponding to the \(k\) largest eigenvalues.
Proof Sketch: By the spectral theorem, \(\Sigma = Q \Lambda Q^T\) where \(Q\) is orthogonal and \(\Lambda = \text{diag}(\lambda_1, \ldots, \lambda_d)\) with \(\lambda_1 \geq \cdots \geq \lambda_d \geq 0\). For any unit vector \(w\), \(w^T \Sigma w = \sum_{i=1}^d \lambda_i (q_i^T w)^2 \leq \lambda_1\) by Cauchy-Schwarz, with equality when \(w = q_1\). Induction extends this to \(k\) dimensions.

Notation explained:

  • \(X \in \mathbb{R}^{n \times d}\) — data matrix with \(n\) samples, \(d\) features
  • \(\Sigma\) — covariance matrix
  • \(w_i\) — principal components (eigenvectors)
  • \(\lambda_i\) — eigenvalues (variance explained)
  • \(Q\) — matrix of eigenvectors
# Python: PCA from scratch and with sklearn
import numpy as np
import matplotlib.pyplot as plt

class PCA:
    def __init__(self, n_components):
        self.n_components = n_components
        self.components_ = None
        self.explained_variance_ = None
        self.mean_ = None
        
    def fit(self, X):
        # Center the data
        self.mean_ = np.mean(X, axis=0)
        X_centered = X - self.mean_
        
        # Compute covariance matrix
        n = X.shape[0]
        cov = (X_centered.T @ X_centered) / n
        
        # Eigendecomposition
        eigenvalues, eigenvectors = np.linalg.eigh(cov)
        
        # Sort by eigenvalue descending
        idx = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[idx]
        eigenvectors = eigenvectors[:, idx]
        
        # Store top k components
        self.components_ = eigenvectors[:, :self.n_components].T
        self.explained_variance_ = eigenvalues[:self.n_components]
        
        return self
    
    def transform(self, X):
        X_centered = X - self.mean_
        return X_centered @ self.components_.T
    
    def fit_transform(self, X):
        return self.fit(X).transform(X)

# Generate 2D data with clear principal directions
np.random.seed(42)
n_samples = 500

# Create correlated data
mean = [0, 0]
cov = [[3, 2], [2, 2]]  # Strong correlation
X = np.random.multivariate_normal(mean, cov, n_samples)

# Apply PCA
pca = PCA(n_components=2)
X_transformed = pca.fit_transform(X)

print("Principal Components:")
print(pca.components_)
print(f"\nExplained Variance: {pca.explained_variance_}")
print(f"Explained Variance Ratio: {pca.explained_variance_ / np.sum(pca.explained_variance_)}")

# Project to 1D and reconstruct
pca_1d = PCA(n_components=1)
X_1d = pca_1d.fit_transform(X)
X_reconstructed = X_1d @ pca_1d.components_ + pca_1d.mean_

print(f"\nReconstruction error (MSE): {np.mean((X - X_reconstructed)**2):.4f}")

3. Gradient Descent Convergence (Optimization)

Gradient descent is the workhorse of modern machine learning. Understanding its convergence properties is crucial.

Convergence of Gradient Descent: Let \(f: \mathbb{R}^d \to \mathbb{R}\) be convex and \(L\)-smooth (i.e., \(\|\nabla f(x) - \nabla f(y)\| \leq L\|x - y\|\)). With step size \(\eta \leq \frac{1}{L}\): \[f(x_T) - f(x^*) \leq \frac{\|x_0 - x^*\|^2}{2\eta T}\]
Strongly Convex Case: If \(f\) is also \(\mu\)-strongly convex, then: \[\|x_T - x^*\|^2 \leq \left(1 - \frac{\mu}{L}\right)^T \|x_0 - x^*\|^2\] The condition number is \(\kappa = L/\mu\).
Key Lemma: For \(L\)-smooth convex \(f\): \[f(y) \leq f(x) + \nabla f(x)^T(y-x) + \frac{L}{2}\|y-x\|^2\] Setting \(y = x - \frac{1}{L}\nabla f(x)\): \[f(y) \leq f(x) - \frac{1}{2L}\|\nabla f(x)\|^2\] This shows descent. Combining with convexity gives the rate.

Notation explained:

  • \(L\)-smooth — gradient is Lipschitz continuous with constant \(L\)
  • \(\mu\)-strongly convex — \(f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2\)
  • \(\eta\) — learning rate (step size)
  • \(x^*\) — optimal solution
  • \(\kappa = L/\mu\) — condition number
# Python: Gradient descent with convergence analysis
import numpy as np
import matplotlib.pyplot as plt

def gradient_descent(f, grad_f, x0, step_size, n_iterations, 
                     f_opt=None, x_opt=None):
    """
    Gradient descent with convergence tracking.
    
    Returns: trajectory, function values, distance to optimum
    """
    x = x0.copy()
    trajectory = [x.copy()]
    f_values = [f(x)]
    distances = [np.linalg.norm(x - x_opt)] if x_opt is not None else []
    
    for t in range(n_iterations):
        gradient = grad_f(x)
        x = x - step_size * gradient
        trajectory.append(x.copy())
        f_values.append(f(x))
        if x_opt is not None:
            distances.append(np.linalg.norm(x - x_opt))
    
    return np.array(trajectory), np.array(f_values), np.array(distances)

# Example: Quadratic function f(x) = 0.5 * x^T A x - b^T x
# Strongly convex when A is positive definite

np.random.seed(42)
d = 10

# Create ill-conditioned problem
A = np.diag([100, 50, 25, 10, 5, 2, 1, 0.5, 0.2, 0.1])
b = np.random.randn(d)

def f(x):
    return 0.5 * x.T @ A @ x - b.T @ x

def grad_f(x):
    return A @ x - b

# Optimal solution
x_opt = np.linalg.solve(A, b)
f_opt = f(x_opt)

# Condition number
L = np.max(np.diag(A))  # Largest eigenvalue
mu = np.min(np.diag(A))  # Smallest eigenvalue
kappa = L / mu
print(f"Condition number κ = {kappa:.1f}")
print(f"Theoretical convergence rate: (1 - 1/κ) = {1 - 1/kappa:.4f}")

# Run gradient descent
x0 = np.zeros(d)
step_size = 1 / L  # Optimal step size
n_iter = 500

traj, f_vals, dists = gradient_descent(f, grad_f, x0, step_size, n_iter, 
                                        f_opt, x_opt)

# Compare with theoretical rate
print(f"\nAfter {n_iter} iterations:")
print(f"Actual distance ratio: {dists[-1] / dists[0]:.6f}")
print(f"Theoretical bound: {(1 - mu/L)**n_iter:.6f}")

# Plot convergence
plt.figure(figsize=(12, 4))

plt.subplot(1, 3, 1)

plt.xlabel('Iteration')
plt.ylabel('f(x) - f*')
plt.title('Function Value Convergence')

plt.ylabel('||x - x*||')
plt.title('Distance to Optimum')
plt.grid(True)

# Compare with theoretical rate
 theoretical = dists[0] * (1 - mu/L)**np.arange(len(dists))

plt.savefig('gradient_descent.png', dpi=150)
print("\nConvergence plot saved!")

1. Euler's Formula for Planar Graphs

Euler's formula is a fundamental result connecting the vertices, edges, and faces of planar graphs.

Euler's Formula: For any connected planar graph drawn on a sphere (or plane): \[V - E + F = 2\] where \(V\) is vertices, \(E\) is edges, and \(F\) is faces (including the outer face).
Proof by Induction on Edges:
Base case: A tree has \(V\) vertices, \(V-1\) edges, and 1 face. So \(V - (V-1) + 1 = 2\). ✓

Inductive step: If the graph has a cycle, remove an edge from the cycle. This decreases \(E\) by 1 and \(F\) by 1 (merging two faces). The quantity \(V - E + F\) remains unchanged. By induction, it equals 2.

Notation explained:

  • \(V\) — number of vertices
  • \(E\) — number of edges
  • \(F\) — number of faces (regions bounded by edges)
  • Planar graph — can be drawn on a plane without edge crossings
# Python: Verify Euler's formula for planar graphs
import networkx as nx

def check_euler_formula(G):
    """Verify V - E + F = 2 for a planar graph."""
    if not nx.is_planar(G):
        return None
    
    V = G.number_of_nodes()
    E = G.number_of_edges()
    
    # For planar embedding, use networkx planar layout
    # Number of faces = E - V + 2 (from Euler's formula)
    # We can verify by computing the cycle basis
    F = E - V + 2  # Expected from Euler's formula
    
    euler_char = V - E + F
    return V, E, F, euler_char

# Test on various planar graphs
test_graphs = {
    "Triangle (C3)": nx.cycle_graph(3),
    "Square (C4)": nx.cycle_graph(4),
    "Complete graph K4": nx.complete_graph(4),
    "Cube graph": nx.hypercube_graph(3),
    "Petersen graph (non-planar)": nx.petersen_graph()
}

for name, G in test_graphs.items():
    result = check_euler_formula(G)
    if result is None:
        print(f"{name}: Not planar")
    else:
        V, E, F, euler = result
        print(f"{name}: V={V}, E={E}, F={F}, V-E+F={euler}")

# Create and verify a planar graph
G = nx.Graph()
G.add_edges_from([(0,1), (1,2), (2,0), (0,3), (3,4), (4,0)])  # Triangle with tail
V, E, F, euler = check_euler_formula(G)
print(f"\nCustom planar graph: V={V}, E={E}, F={F}, V-E+F={euler}")

2. Law of Large Numbers

The Law of Large Numbers is a cornerstone of probability theory, describing the convergence of sample averages.

Weak Law of Large Numbers: Let \(X_1, X_2, \ldots\) be i.i.d. random variables with \(\mathbb{E}[X_i] = \mu\) and \(\text{Var}(X_i) = \sigma^2 < \infty\). Then: \[\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{P} \mu\] That is, for any \(\epsilon > 0\): \(\lim_{n \to \infty} P(|\bar{X}_n - \mu| > \epsilon) = 0\).
Strong Law of Large Numbers: Under the same conditions: \[\bar{X}_n \xrightarrow{a.s.} \mu\] That is: \(P(\lim_{n \to \infty} \bar{X}_n = \mu) = 1\).
Proof of Weak LLN (using Chebyshev):
\(\mathbb{E}[\bar{X}_n] = \mu\) and \(\text{Var}(\bar{X}_n) = \frac{\sigma^2}{n}\).
By Chebyshev's inequality: \[P(|\bar{X}_n - \mu| \geq \epsilon) \leq \frac{\text{Var}(\bar{X}_n)}{\epsilon^2} = \frac{\sigma^2}{n\epsilon^2} \to 0\]

Notation explained:

  • i.i.d. — independent and identically distributed
  • \(\mathbb{E}[X]\) — expected value of \(X\)
  • \(\text{Var}(X)\) — variance of \(X\)
  • \(\bar{X}_n\) — sample mean of \(n\) observations
  • \(\xrightarrow{P}\) — convergence in probability
  • \(\xrightarrow{a.s.}\) — almost sure convergence
# Python: Demonstrating Law of Large Numbers
import numpy as np

    """

3. Cauchy-Schwarz Inequality

The Cauchy-Schwarz inequality is one of the most fundamental inequalities in mathematics, with applications across analysis, linear algebra, and probability.

Cauchy-Schwarz Inequality: In an inner product space, for any vectors \(u\) and \(v\): \[|\langle u, v \rangle| \leq \|u\| \cdot \|v\|\] Equality holds if and only if \(u\) and \(v\) are linearly dependent.
Proof: Consider \(w = u - \frac{\langle u, v \rangle}{\|v\|^2} v\). Then \(\langle w, v \rangle = 0\), so by Pythagoras: \[\|u\|^2 = \|w\|^2 + \left|\frac{\langle u, v \rangle}{\|v\|^2}\right|^2 \|v\|^2 \geq \frac{|\langle u, v \rangle|^2}{\|v\|^2}\] Rearranging gives the result. Equality when \(\|w\| = 0\), i.e., \(u \propto v\).

Notation explained:

  • \(\langle u, v \rangle\) — inner product of \(u\) and \(v\)
  • \(\|u\| = \sqrt{\langle u, u \rangle}\) — norm (length) of \(u\)
  • For \(\mathbb{R}^n\): \(\langle u, v \rangle = u^T v = \sum_{i=1}^n u_i v_i\)
  • For functions: \(\langle f, g \rangle = \int f(x)g(x)\, dx\)
# Python: Cauchy-Schwarz inequality verification
import numpy as np

def verify_cauchy_schwarz(u, v, inner_product=None):
    """
    Verify Cauchy-Schwarz inequality for given vectors.
    Returns ratio || / (||u|| ||v||) which should be ≤ 1.
    """
    if inner_product is None:
        # Standard Euclidean inner product
        inner = np.dot(u, v)
        norm_u = np.linalg.norm(u)
        norm_v = np.linalg.norm(v)
    else:
        inner = inner_product(u, v)
        norm_u = np.sqrt(inner_product(u, u))
        norm_v = np.sqrt(inner_product(v, v))
    
    lhs = abs(inner)
    rhs = norm_u * norm_v
    ratio = lhs / rhs if rhs > 0 else 0
    
    return {
        'inner_product': inner,
        'norm_u': norm_u,
        'norm_v': norm_v,
        'lhs': lhs,
        'rhs': rhs,
        'ratio': ratio,
        'satisfied': ratio <= 1 + 1e-10
    }

# Test 1: Random vectors in R^n
np.random.seed(42)
n = 100
u = np.random.randn(n)
v = np.random.randn(n)

result = verify_cauchy_schwarz(u, v)
print("Test 1: Random vectors in R^100")
print(f"  || = {result['lhs']:.4f}")
print(f"  ||u|| ||v|| = {result['rhs']:.4f}")
print(f"  Ratio = {result['ratio']:.6f} (should be ≤ 1)")

# Test 2: Linearly dependent vectors (equality case)
v_parallel = 2.5 * u
result2 = verify_cauchy_schwarz(u, v_parallel)
print("\nTest 2: Linearly dependent vectors")

# Test 3: Orthogonal vectors
v_orth = np.random.randn(n)
v_orth = v_orth - np.dot(v_orth, u) / np.dot(u, u) * u  # Gram-Schmidt
result3 = verify_cauchy_schwarz(u, v_orth)
print("\nTest 3: Orthogonal vectors")
print(f"   = {result3['inner_product']:.2e} (should be ≈ 0)")
print(f"  Ratio = {result3['ratio']:.6f} (should be ≈ 0)")

print("\nTest 4: Function space L²[0,1]")
def inner_product_L2(f, g, n=1000):
    """Approximate L² inner product:  = ∫₀¹ f(x)g(x) dx"""
    x = np.linspace(0, 1, n)
    return np.trapezoid(f(x) * g(x), x)

4. Cantor's Diagonal Argument

Cantor's diagonal argument is a revolutionary proof technique showing that some infinities are larger than others.

Cantor's Theorem: For any set \(A\), there is no surjection from \(A\) to its power set \(\mathcal{P}(A)\). In particular, \(|A| < |\mathcal{P}(A)|\).
Uncountability of \(\mathbb{R}\): The real numbers are uncountable. Specifically, \(|\mathbb{N}| < |\mathbb{R}|\).
Cantor's Diagonal Argument:
Suppose \(f: \mathbb{N} \to [0,1]\) is a bijection. Write each \(f(n)\) in decimal: \[\begin{align*} f(1) &= 0.d_{11}d_{12}d_{13}\ldots \\ f(2) &= 0.d_{21}d_{22}d_{23}\ldots \\ f(3) &= 0.d_{31}d_{32}d_{33}\ldots \\ &\vdots \end{align*}\] Construct \(x = 0.x_1x_2x_3\ldots\) where \(x_i \neq d_{ii}\) (e.g., \(x_i = 5\) if \(d_{ii} \neq 5\), else \(x_i = 6\)). Then \(x \neq f(n)\) for any \(n\), contradiction!

Notation explained:

  • \(\mathcal{P}(A)\) — power set (set of all subsets) of \(A\)
  • \(|A|\) — cardinality (size) of set \(A\)
  • \(\aleph_0 = |\mathbb{N}|\) — cardinality of natural numbers
  • \(\mathfrak{c} = |\mathbb{R}| = 2^{\aleph_0}\) — cardinality of continuum
  • Countable — can be put in bijection with \(\mathbb{N}\)
# Python: Demonstrating Cantor's diagonal argument
def cantor_diagonal(sequences):
    """
    Apply Cantor's diagonal argument to a list of binary sequences.
    Returns a new sequence that differs from each sequence at position i.
    """
    n = len(sequences)
    diagonal = []
    for i in range(n):
        # Flip the i-th bit of the i-th sequence
        bit = 1 - sequences[i][i] if i < len(sequences[i]) else 0
        diagonal.append(bit)
    return diagonal

def generate_binary_sequences(n, length):
    """Generate first n binary sequences of given length."""
    sequences = []
    for i in range(min(n, 2**length)):
        seq = [(i >> j) & 1 for j in range(length-1, -1, -1)]
        sequences.append(seq)
    return sequences

# Demonstration

# Apply diagonal argument
