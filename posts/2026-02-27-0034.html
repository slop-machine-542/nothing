Symplectic Geometry and Hamiltonian Mechanics

Motivation

Symplectic geometry provides the mathematical framework for classical mechanics, capturing the geometric structure underlying Hamilton's equations. Unlike Riemannian geometry which measures distances, symplectic geometry measures "area-like" quantities and preserves certain fundamental invariants. This field bridges differential geometry, topology, and physics, with applications ranging from celestial mechanics to quantum field theory.

Definitions

Symplectic Form: A closed, non-degenerate 2-form \( \omega \) on a smooth manifold \( M \). That is, \( d\omega = 0 \) and for all non-zero vectors \( v \), there exists \( w \) with \( \omega(v, w) \neq 0 \).

Symplectic Manifold: A pair \( (M, \omega) \) where \( M \) is a smooth manifold and \( \omega \) is a symplectic form. Necessarily, \( \dim M = 2n \) is even.

Hamiltonian Vector Field: For a Hamiltonian function \( H: M \to \mathbb{R} \), the vector field \( X_H \) is defined by \( \iota_{X_H}\omega = dH \), where \( \iota \) denotes interior product.

Theorem: Darboux's Theorem

Let \( (M, \omega) \) be a symplectic manifold of dimension \( 2n \). For any point \( p \in M \), there exist local coordinates \( (q_1, \ldots, q_n, p_1, \ldots, p_n) \) such that: \[\omega = \sum_{i=1}^{n} dq_i \wedge dp_i\]

Proof Sketch: The proof proceeds by induction on dimension. First, one shows that at any point, coordinates can be chosen so that \( \omega \) takes the standard form at that point. Then, using Moser's trick, one constructs a diffeomorphism that pulls back \( \omega \) to the standard form in a neighborhood. The key insight is that all symplectic manifolds are locally equivalent — there are no local invariants beyond the dimension. This contrasts sharply with Riemannian geometry where curvature provides local invariants.

Notation Guide

  • \( \omega \) — symplectic form
  • \( \wedge \) — wedge product of differential forms
  • \( \iota_X \) — interior product with vector field \( X \)
  • \( q_i, p_i \) — canonical (Darboux) coordinates
  • \( X_H \) — Hamiltonian vector field
  • \( \{f, g\} \) — Poisson bracket

Random Matrix Theory and Universality

Motivation

Random matrix theory studies the statistical properties of matrices with random entries. Remarkably, the eigenvalue distributions of large random matrices exhibit universal behavior independent of the specific distribution of entries. This universality appears in quantum physics, number theory, wireless communications, and even the distribution of zeros of the Riemann zeta function.

Definitions

Gaussian Unitary Ensemble (GUE): The set of \( n \times n \) Hermitian matrices with independent Gaussian entries on and above the diagonal, with probability density proportional to \( \exp(-\text{Tr}(H^2)/2) \).

Empirical Spectral Distribution: For a matrix \( H \) with eigenvalues \( \lambda_1, \ldots, \lambda_n \), the measure \( \mu_n = \frac{1}{n}\sum_{i=1}^{n} \delta_{\lambda_i} \).

Wigner Matrix: A Hermitian matrix with independent, identically distributed entries above the diagonal (subject to symmetry constraints), with zero mean and finite variance.

Theorem: Wigner's Semicircle Law

Let \( H_n \) be an \( n \times n \) Wigner matrix with entries having variance \( \sigma^2/n \). As \( n \to \infty \), the empirical spectral distribution converges weakly to the semicircle distribution: \[\mu_n \xrightarrow{w} \mu_{sc}\] where the semicircle density is: \[\rho_{sc}(x) = \frac{1}{2\pi\sigma^2}\sqrt{4\sigma^2 - x^2} \cdot \mathbf{1}_{|x| \leq 2\sigma}\]

Proof Sketch: The proof uses the method of moments. One shows that the expected moments of \( \mu_n \) converge to the moments of the semicircle distribution. For the \( k \)-th moment: \[\mathbb{E}\left[\frac{1}{n}\text{Tr}(H_n^k)\right] = \frac{1}{n}\sum_{i_1, \ldots, i_k} \mathbb{E}[H_{i_1 i_2} H_{i_2 i_3} \cdots H_{i_k i_1}]\] Only certain pairings (non-crossing partitions) contribute in the limit. The Catalan numbers emerge as the counting mechanism, and these are precisely the moments of the semicircle distribution.

Notation Guide

  • \( \text{GUE}(n) \) — Gaussian Unitary Ensemble
  • \( \mu_{sc} \) — semicircle distribution
  • \( \rho_{sc}(x) \) — semicircle density function
  • \( C_k \) — Catalan numbers
  • \( \xrightarrow{w} \) — weak convergence
  • \( \text{Tr} \) — matrix trace

import numpy as np
import matplotlib.pyplot as plt

class RandomMatrixTheory:
    """Demonstrate random matrix theory concepts."""
    
    @staticmethod
    def generate_gue(n):
        """Generate n×n GUE matrix."""
        # Upper triangular with complex Gaussian entries
        A = (np.random.randn(n, n) + 1j * np.random.randn(n, n)) / np.sqrt(2)
        # Make Hermitian: H = (A + A†)/2
        H = (A + A.conj().T) / 2
        return H
    
    @staticmethod
    def generate_wigner(n, sigma=1.0):
        """Generate n×n real symmetric Wigner matrix."""
        A = np.random.randn(n, n) * sigma / np.sqrt(n)
        H = (A + A.T) / np.sqrt(2)
        return H
    
    @staticmethod
    def semicircle_density(x, sigma=1.0):
        """Semicircle density function."""
        R = 2 * sigma
        mask = np.abs(x) <= R
        result = np.zeros_like(x)
        result[mask] = (1 / (2 * np.pi * sigma**2)) * np.sqrt(R**2 - x[mask]**2)
        return result
    
    @staticmethod
    def catalan_number(n):
        """Compute the n-th Catalan number."""
        from math import comb
        return comb(2*n, n) // (n + 1)

Algebraic Topology: Cohomology and Characteristic Classes

Motivation

Algebraic topology translates geometric problems into algebraic ones, making them amenable to computation. Cohomology provides a graded ring structure that captures more information than homology alone. Characteristic classes assign cohomology classes to vector bundles, measuring their "twistedness" and providing powerful invariants for distinguishing manifolds and bundles.

Definitions

Singular Cohomology: For a topological space \( X \), the cohomology groups \( H^n(X; G) \) are defined as the cohomology of the cochain complex \( C^n(X; G) = \text{Hom}(C_n(X), G) \) where \( C_n(X) \) is the singular chain group.

Cup Product: A bilinear map \( \smile : H^k(X) \times H^l(X) \to H^{k+l}(X) \) making cohomology into a graded ring.

Chern Classes: For a complex vector bundle \( E \to X \), the total Chern class \( c(E) = 1 + c_1(E) + c_2(E) + \cdots \) lives in \( H^*(X; \mathbb{Z}) \) and satisfies naturality, Whitney sum, and normalization axioms.

Theorem: Poincaré Duality

Let \( M \) be a closed, oriented \( n \)-manifold. There is an isomorphism: \[PD : H^k(M; \mathbb{Z}) \xrightarrow{\cong} H_{n-k}(M; \mathbb{Z})\] given by capping with the fundamental class \( [M] \in H_n(M) \). Moreover, the cup product pairing: \[H^k(M) \times H^{n-k}(M) \to H^n(M) \cong \mathbb{Z}\] is non-degenerate.

Proof Sketch: The proof proceeds by verifying the theorem for \( \mathbb{R}^n \) (trivial), then extending to open subsets of \( \mathbb{R}^n \) via Mayer-Vietoris sequences. The key step uses induction on the number of open sets in a good cover. For compact manifolds, one takes a limit over exhausting compact subsets. The non-degeneracy of the cup product follows from the fact that the intersection pairing on homology is non-degenerate for oriented manifolds.

Notation Guide

  • \( H^n(X; G) \) — cohomology with coefficients in \( G \)
  • \( \smile \) — cup product
  • \( c_i(E) \) — i-th Chern class of bundle \( E \)
  • \( [M] \) — fundamental class of manifold \( M \)
  • \( \cap \) — cap product
  • \( \chi(M) \) — Euler characteristic

Control Theory and the Linear Quadratic Regulator

Real-World Motivation

Control theory provides the mathematical foundation for autonomous systems, from spacecraft navigation to self-driving cars. The Linear Quadratic Regulator (LQR) is a cornerstone of optimal control, finding control inputs that minimize a quadratic cost function. This framework balances performance (reaching a target state) against effort (minimizing control energy), with applications in robotics, aerospace, and process control.

Definitions

State-Space System: A linear time-invariant system is described by: \[\dot{x}(t) = Ax(t) + Bu(t)\] where \( x \in \mathbb{R}^n \) is the state, \( u \in \mathbb{R}^m \) is the control input, \( A \) is the system matrix, and \( B \) is the input matrix.

Controllability: The pair \( (A, B) \) is controllable if the controllability matrix \( \mathcal{C} = [B \ AB \ A^2B \ \cdots \ A^{n-1}B] \) has full rank \( n \).

Cost Functional: The infinite-horizon LQR cost is: \[J = \int_0^{\infty} (x^T Q x + u^T R u) \, dt\] where \( Q \succeq 0 \) and \( R \succ 0 \) are weight matrices.

Theorem: LQR Optimal Control

For a controllable system \( (A, B) \), the optimal control minimizing \( J \) is given by state feedback: \[u^*(t) = -Kx(t)\] where \( K = R^{-1}B^T P \) and \( P \) is the unique positive semidefinite solution to the Algebraic Riccati Equation (ARE): \[A^T P + PA - PBR^{-1}B^T P + Q = 0\]

Proof Sketch: Using dynamic programming, one derives the Hamilton-Jacobi-Bellman equation for the value function \( V(x) = x^T P x \). The optimal control is found by minimizing the Hamiltonian with respect to \( u \), yielding \( u = -R^{-1}B^T \nabla V = -R^{-1}B^T P x \). Substituting back gives the ARE. Existence and uniqueness of the solution follow from controllability and observability assumptions via spectral factorization arguments.

Notation Guide

  • \( x(t) \) — state vector
  • \( u(t) \) — control input
  • \( A, B \) — system and input matrices
  • \( Q, R \) — state and control weight matrices
  • \( P \) — solution to Riccati equation
  • \( K \) — optimal gain matrix
  • \( \mathcal{C} \) — controllability matrix

import numpy as np
from scipy import linalg

class ControlTheory:
    """Demonstrate control theory concepts."""
    
    @staticmethod
    def solve_are(A, B, Q, R):
        """Solve the Algebraic Riccati Equation."""
        # scipy.linalg.solve_continuous_are(A, B, Q, R)
        P = linalg.solve_continuous_are(A, B, Q, R)
        return P
    
    @staticmethod
    def lqr_gain(A, B, Q, R):
        """Compute LQR optimal gain matrix K."""
        P = ControlTheory.solve_are(A, B, Q, R)
        K = np.linalg.inv(R) @ B.T @ P
        return K, P
    
    @staticmethod
    def is_controllable(A, B):
        """Check if (A, B) is controllable."""
        n = A.shape[0]
        C = B
        for i in range(1, n):
            C = np.hstack([C, np.linalg.matrix_power(A, i) @ B])
        return np.linalg.matrix_rank(C) == n
    
    @staticmethod
    def simulate_closed_loop(A, B, K, x0, t_span, dt=0.01):
        """Simulate closed-loop system with u = -Kx."""
        t = np.arange(0, t_span, dt)
        x = np.zeros((len(t), len(x0)))
        u = np.zeros((len(t), B.shape[1]))
        x[0] = x0
        
        A_cl = A - B @ K
        for i in range(1, len(t)):
            x[i] = x[i-1] + dt * (A_cl @ x[i-1])
            u[i-1] = -K @ x[i-1]
        u[-1] = -K @ x[-1]
        
        return t, x, u

Game Theory and Nash Equilibrium

Real-World Motivation

Game theory models strategic interactions where the outcome for each participant depends on the choices of all. From auction design and market mechanisms to evolutionary biology and political strategy, game theory provides a framework for analyzing rational decision-making. The Nash equilibrium concept, for which John Nash received the Nobel Prize, identifies stable strategy profiles where no player can benefit by unilaterally changing strategy.

Definitions

Normal Form Game: A game \( G = (N, (S_i)_{i \in N}, (u_i)_{i \in N}) \) where \( N \) is the set of players, \( S_i \) is player \( i \)'s strategy set, and \( u_i: S \to \mathbb{R} \) is the payoff function, with \( S = \prod_{i} S_i \).

Nash Equilibrium: A strategy profile \( s^* = (s_1^*, \ldots, s_n^*) \) is a Nash equilibrium if for all players \( i \) and all alternative strategies \( s_i \in S_i \): \[u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*)\] where \( s_{-i}^* \) denotes the strategies of all players except \( i \).

Mixed Strategy: A probability distribution \( \sigma_i \) over \( S_i \). The expected payoff is \( u_i(\sigma) = \mathbb{E}_{\sigma}[u_i(s)] \).

Theorem: Nash's Existence Theorem

Every finite normal-form game has at least one Nash equilibrium in mixed strategies.

Proof Sketch: Define the best-response correspondence \( BR_i(\sigma_{-i}) = \arg\max_{\sigma_i} u_i(\sigma_i, \sigma_{-i}) \). The product correspondence \( BR(\sigma) = \prod_i BR_i(\sigma_{-i}) \) maps the compact convex set of mixed strategy profiles to itself. By Kakutani's fixed-point theorem (which applies because payoffs are linear in mixed strategies, making best-response sets convex), \( BR \) has a fixed point. This fixed point is precisely a Nash equilibrium.

Notation Guide

  • \( N \) — set of players
  • \( S_i \) — strategy set for player \( i \)
  • \( u_i \) — payoff function for player \( i \)
  • \( s_{-i} \) — strategies of all players except \( i \)
  • \( \sigma_i \) — mixed strategy for player \( i \)
  • \( BR_i \) — best-response correspondence
  • \( \Delta(S_i) \) — set of probability distributions on \( S_i \)

import numpy as np
from scipy.optimize import minimize
from itertools import product

class GameTheory:
    """Demonstrate game theory concepts."""
    
    @staticmethod
    def expected_payoff(payoff_matrix, row_strategy, col_strategy):
        """Compute expected payoff for row player."""
        return row_strategy @ payoff_matrix @ col_strategy
    
    @staticmethod
    def nash_equilibrium_2x2(A, B):
        """
        Find Nash equilibrium for 2×2 bimatrix game.
        A is payoff matrix for row player, B for column player.
        """
        # Support enumeration for 2×2 games
        # Check pure strategy equilibria first
        equilibria = []
        
        for i in [0, 1]:
            for j in [0, 1]:
                # Check if (i, j) is a Nash equilibrium
                row_payoffs = A[:, j]
                col_payoffs = B[i, :]
                if row_payoffs[i] >= row_payoffs[1-i] and col_payoffs[j] >= col_payoffs[1-j]:
                    equilibria.append((np.array([1.0, 0.0]) if i == 0 else np.array([0.0, 1.0]),
                                     np.array([1.0, 0.0]) if j == 0 else np.array([0.0, 1.0])))
        
        # Check mixed strategy equilibrium
        # Row player indifferent: p*A[0,0] + (1-p)*A[1,0] = p*A[0,1] + (1-p)*A[1,1]
        # Solving for q (column player's strategy)
        denom_q = (B[0,0] - B[0,1] - B[1,0] + B[1,1])
        if abs(denom_q) > 1e-10:
            q = (B[1,1] - B[1,0]) / denom_q
            if 0 <= q <= 1:
                # Column player indifferent: q*A[0,0] + (1-q)*A[0,1] = q*A[1,0] + (1-q)*A[1,1]
                denom_p = (A[0,0] - A[0,1] - A[1,0] + A[1,1])
                if abs(denom_p) > 1e-10:
                    p = (A[1,1] - A[0,1]) / denom_p
                    if 0 <= p <= 1:
                        equilibria.append((np.array([p, 1-p]), np.array([q, 1-q])))
        
        return equilibria
    
    @staticmethod
    def prisoner_dilemma():
        """Return payoff matrices for Prisoner's Dilemma."""
        # Row player: Cooperate, Defect
        # Column player: Cooperate, Defect
        A = np.array([[-1, -3],   # Row player payoffs
                      [0, -2]])
        B = np.array([[-1, 0],    # Column player payoffs
                      [-3, -2]])
        return A, B

        A = np.array([[1, -1],
                      [-1, 1]])
        B = np.array([[-1, 1],
                      [1, -1]])
        return A, B

Computational Geometry: Voronoi Diagrams and Delaunay Triangulations

Real-World Motivation

Computational geometry develops algorithms for geometric problems, with applications in computer graphics, robotics, geographic information systems, and mesh generation. Voronoi diagrams partition space into regions closest to given sites, while Delaunay triangulations provide optimal triangulations avoiding skinny triangles. These structures are dual to each other and form the backbone of many spatial algorithms.

Definitions

Voronoi Diagram: For a set of sites \( P = \{p_1, \ldots, p_n\} \subset \mathbb{R}^d \), the Voronoi cell of \( p_i \) is: \[V(p_i) = \{x \in \mathbb{R}^d : \|x - p_i\| \leq \|x - p_j\| \text{ for all } j\}\]

Delaunay Triangulation: A triangulation of \( P \) such that no point lies inside the circumcircle of any triangle. Equivalently, the dual graph of the Voronoi diagram.

Empty Circle Property: A triangulation is Delaunay if and only if the circumcircle of each triangle contains no other points in its interior.

Theorem: Delaunay Triangulation Optimality

Among all triangulations of a point set in the plane, the Delaunay triangulation:

  1. Maximizes the minimum angle
  2. Minimizes the maximum circumradius
  3. Minimizes the roughness (integral of gradient squared) of piecewise-linear interpolation

Proof Sketch: The key is the local optimality property. An edge flip (replacing diagonal \( ac \) with \( bd \) in quadrilateral \( abcd \)) improves the triangulation if and only if \( d \) lies outside the circumcircle of \( \triangle abc \). Since Delaunay triangulations satisfy the empty circle property, no edge flip can improve them. The global optimality follows because any non-Delaunay triangulation can be improved by a sequence of edge flips, and this process terminates.

Notation Guide

  • \( V(p_i) \) — Voronoi cell of site \( p_i \)
  • \( \text{Vor}(P) \) — Voronoi diagram of point set \( P \)
  • \( \text{Del}(P) \) — Delaunay triangulation of \( P \)
  • \( C(p_i, p_j, p_k) \) — circumcircle of triangle
  • \( \text{inCircle}(a, b, c, d) \) — orientation test

import numpy as np

class ComputationalGeometry:
    """Demonstrate computational geometry concepts."""
    
    @staticmethod
    def circumcircle(p1, p2, p3):
        """
        Compute circumcircle of triangle p1, p2, p3.
        Returns (center, radius).
        """
        # Convert to homogeneous coordinates for robustness
        A = np.array([
            [p1[0], p1[1], 1],
            [p2[0], p2[1], 1],
            [p3[0], p3[1], 1]
        ])
        
        B = np.array([
            [p1[0]**2 + p1[1]**2, p1[1], 1],
            [p2[0]**2 + p2[1]**2, p2[1], 1],
            [p3[0]**2 + p3[1]**2, p3[1], 1]
        ])
        
        C = np.array([
            [p1[0]**2 + p1[1]**2, p1[0], 1],
            [p2[0]**2 + p2[1]**2, p2[0], 1],
            [p3[0]**2 + p3[1]**2, p3[0], 1]
        ])
        
        D = np.array([
            [p1[0]**2 + p1[1]**2, p1[0], p1[1]],
            [p2[0]**2 + p2[1]**2, p2[0], p2[1]],
            [p3[0]**2 + p3[1]**2, p3[0], p3[1]]
        ])
        
        det_A = np.linalg.det(A)
        if abs(det_A) < 1e-10:
            return None, None  # Points are collinear
        
        cx = np.linalg.det(B) / (2 * det_A)
        cy = -np.linalg.det(C) / (2 * det_A)
        
        center = np.array([cx, cy])
        radius = np.linalg.norm(center - p1)
        
        return center, radius
    
    @staticmethod
    def point_in_circumcircle(p, p1, p2, p3):
        """Check if point p is inside circumcircle of triangle p1,p2,p3."""
        center, radius = ComputationalGeometry.circumcircle(p1, p2, p3)
        if center is None:
            return False
        return np.linalg.norm(p - center) < radius - 1e-10
    
    @staticmethod
    def voronoi_cell_brute_force(site, sites, bounds=((0, 1), (0, 1)), n_grid=100):
        """
        Compute Voronoi cell by brute force sampling.
        Returns grid points in the cell.
        """
        x = np.linspace(bounds[0][0], bounds[0][1], n_grid)
        y = np.linspace(bounds[1][0], bounds[1][1], n_grid)
        X, Y = np.meshgrid(x, y)
        
        points = np.column_stack([X.ravel(), Y.ravel()])
        distances_to_site = np.linalg.norm(points - site, axis=1)
        
        in_cell = np.ones(len(points), dtype=bool)
        for other_site in sites:
            if np.allclose(other_site, site):
                continue
            distances_to_other = np.linalg.norm(points - other_site, axis=1)
            in_cell &= distances_to_site <= distances_to_other + 1e-10
        
        return points[in_cell]
    
    @staticmethod
    def minimum_angle_triangle(p1, p2, p3):
        """Compute minimum angle of triangle in degrees."""
        a = np.linalg.norm(p2 - p3)
        b = np.linalg.norm(p1 - p3)
        c = np.linalg.norm(p1 - p2)
        
        # Law of cosines
        cos_A = (b**2 + c**2 - a**2) / (2 * b * c)
        cos_B = (a**2 + c**2 - b**2) / (2 * a * c)
        cos_C = (a**2 + b**2 - c**2) / (2 * a * b)
        
        angles = [np.arccos(np.clip(cos_A, -1, 1)),
                  np.arccos(np.clip(cos_B, -1, 1)),
                  np.arccos(np.clip(cos_C, -1, 1))]
        
        return np.degrees(min(angles))

Set Theory: Forcing and the Continuum Hypothesis

Historical Context

Georg Cantor's creation of set theory in the late 19th century revolutionized mathematics by providing a foundation for all mathematical objects. However, his Continuum Hypothesis (CH) — that there is no set whose cardinality is strictly between that of the integers and the real numbers — resisted proof for decades. In 1963, Paul Cohen invented the method of forcing, proving that CH is independent of the standard ZFC axioms, a result for which he received the Fields Medal.

Definitions

Cardinal Arithmetic: For cardinals \( \kappa, \lambda \), we define \( \kappa + \lambda \), \( \kappa \cdot \lambda \), and \( \kappa^{\lambda} \) via set operations on representatives.

Continuum Hypothesis: \( 2^{\aleph_0} = \aleph_1 \), i.e., every uncountable subset of \( \mathbb{R} \) has cardinality \( \mathfrak{c} \).

Forcing: A method for constructing models of set theory. A forcing poset \( (\mathbb{P}, \leq) \) adds "generic" sets that satisfy desired properties while preserving the axioms of ZFC.

Theorem: Independence of CH

If ZFC is consistent, then both ZFC + CH and ZFC + ¬CH are consistent.

Proof Sketch: Gödel (1938) showed CH holds in the constructible universe \( L \), proving Con(ZFC) → Con(ZFC + CH). Cohen's forcing shows how to add \( \kappa \) many new subsets of \( \omega \) for any cardinal \( \kappa \), making \( 2^{\aleph_0} = \kappa \). The key is the countable chain condition (ccc), which ensures cardinals are preserved. By adding \( \aleph_2 \) many Cohen reals, we obtain a model where \( 2^{\aleph_0} = \aleph_2 \), hence ¬CH.

Notation Guide

  • \( \aleph_0 \) — cardinality of natural numbers
  • \( \aleph_1 \) — first uncountable cardinal
  • \( \mathfrak{c} = 2^{\aleph_0} \) — cardinality of continuum
  • \( \mathbb{P} \) — forcing poset
  • \( G \) — generic filter
  • \( M[G] \) — generic extension of model \( M \)

Model Theory: The Compactness Theorem

Historical Context

Model theory, the study of mathematical structures using the tools of formal logic, emerged in the mid-20th century through the work of Tarski, Robinson, and others. The compactness theorem, first proved by Gödel and later refined by Malcev, is a cornerstone result with profound consequences. It states that a set of first-order sentences has a model if and only if every finite subset has a model, connecting syntactic consistency with semantic existence.

Definitions

First-Order Language: A language \( \mathcal{L} \) consists of function symbols, relation symbols, and constant symbols, each with specified arities.

Structure: An \( \mathcal{L} \)-structure \( \mathcal{M} \) consists of a domain \( M \) and interpretations of all symbols in \( \mathcal{L} \).

Satisfaction: We write \( \mathcal{M} \models \varphi \) if the sentence \( \varphi \) is true in structure \( \mathcal{M} \).

Theorem: Compactness Theorem

Let \( T \) be a set of first-order sentences. Then \( T \) has a model if and only if every finite subset of \( T \) has a model.

Proof Sketch: The (⇒) direction is trivial. For (⇐), one approach uses ultraproducts: assuming every finite subset has a model, construct an ultraproduct of these models using an ultrafilter on the index set of finite subsets. Łoś's theorem ensures the ultraproduct satisfies all sentences in \( T \). Alternatively, one can use the completeness theorem: if \( T \) has no model, it is inconsistent, so some finite subset proves a contradiction.

Notation Guide

  • \( \mathcal{L} \) — first-order language
  • \( \mathcal{M}, \mathcal{N} \) — structures (models)
  • \( T \) — theory (set of sentences)
  • \( \models \) — satisfaction relation
  • \( \vdash \) — syntactic derivability
  • \( \prod_{\mathcal{U}} \mathcal{M}_i \) — ultraproduct

Proof Theory: Cut Elimination and Normalization

Historical Context

Proof theory, founded by David Hilbert as part of his program to establish the consistency of mathematics, studies proofs as mathematical objects in their own right. Gerhard Gentzen's sequent calculus and natural deduction systems (1934) provided structural insights into logical reasoning. His Hauptsatz (cut elimination theorem) showed that any proof can be transformed into a "cut-free" normal form, revealing the deep structure of logical derivations and providing tools for consistency proofs.

Definitions

Sequent: An expression \( \Gamma \vdash \Delta \) where \( \Gamma \) and \( \Delta \) are finite sets (or multisets) of formulas, meaning "the conjunction of \( \Gamma \) implies the disjunction of \( \Delta \)".

Cut Rule: From \( \Gamma \vdash \Delta, A \) and \( A, \Sigma \vdash \Pi \), infer \( \Gamma, \Sigma \vdash \Delta, \Pi \). The formula \( A \) is the "cut formula".

Cut-Free Proof: A proof in sequent calculus that does not use the cut rule. Cut-free proofs have the subformula property: every formula appearing in the proof is a subformula of the conclusion.

Theorem: Gentzen's Hauptsatz (Cut Elimination)

Any proof in sequent calculus can be effectively transformed into a cut-free proof of the same sequent.

Proof Sketch: The proof proceeds by induction on the complexity of cut formulas and the structure of proofs. Key steps: (1) Push cuts upward through the proof tree, (2) When a cut meets the introduction rules for its formula, eliminate it (e.g., cutting \( A \land B \) against its elimination reduces to cuts on \( A \) and \( B \)), (3) Handle contraction carefully using Gentzen's mix rule or similar techniques. The resulting cut-free proof may be exponentially larger but reveals the analytic content of the theorem.

Notation Guide

  • \( \Gamma, \Delta, \Sigma, \Pi \) — sequences/multisets of formulas
  • \( \vdash \) — turnstile (derivability)
  • \( \land, \lor, \to, \neg \) — logical connectives
  • \( \forall, \exists \) — quantifiers
  • \( \text{cut} \) — cut rule
  • \( \text{rk}(A) \) — rank (complexity) of formula \( A \)

        """
        Calculate complexity (rank) of a propositional formula.
        """
        if isinstance(formula, str):
            return 0  # Atomic formula
        
        op = formula[0]
        if op == '¬':

        elif op in ['∧', '∨', '→']:
            return 1 + max(ProofTheory.formula_complexity(formula[1]),
                          ProofTheory.formula_complexity(formula[2]))
        return 0
    
    @staticmethod
    def is_subformula(sub, formula):
        """Check if sub is a subformula of formula."""
        if sub == formula:

        if isinstance(formula, str):
            return False

        if op == '¬':
            return ProofTheory.is_subformula(sub, formula[1])
        elif op in ['∧', '∨', '→']:
            return (ProofTheory.is_subformula(sub, formula[1]) or
                   ProofTheory.is_subformula(sub, formula[2]))
        return False

Riemannian Geometry: The Gauss-Bonnet Theorem

Historical Context

The Gauss-Bonnet theorem represents one of the most profound connections between local and global geometry. Carl Friedrich Gauss discovered a special case for geodesic triangles on surfaces in 1827, showing that angular excess relates to curvature. Pierre Ossian Bonnet extended this to arbitrary curves in 1848. The modern formulation, connecting total curvature to topological invariants, emerged through the work of Walther von Dyck and others in the late 19th century, becoming a prototype for index theorems in the 20th century.

Definitions

Riemannian Metric: A smoothly varying inner product \( g_p : T_pM \times T_pM \to \mathbb{R} \) on each tangent space of a manifold \( M \).

Gaussian Curvature: For a surface, \( K = \kappa_1 \kappa_2 \) where \( \kappa_i \) are principal curvatures. Intrinsically, \( K = \frac{\langle R(\partial_1, \partial_2)\partial_2, \partial_1 \rangle}{\det(g)} \).

Euler Characteristic: For a compact surface, \( \chi(M) = V - E + F \) for any triangulation, or \( \chi(M) = 2 - 2g \) for an orientable surface of genus \( g \).

Theorem: Gauss-Bonnet

Let \( M \) be a compact, oriented Riemannian surface (possibly with boundary). Then: \[\int_M K \, dA + \int_{\partial M} k_g \, ds = 2\pi \chi(M)\] where \( K \) is Gaussian curvature, \( k_g \) is geodesic curvature of the boundary, and \( \chi(M) \) is the Euler characteristic.

Proof Sketch: The proof proceeds by triangulating the surface and applying the local Gauss-Bonnet formula to each triangle: \( \int_{\Delta} K \, dA + \sum_{i=1}^{3} (\pi - \alpha_i) = 2\pi \) where \( \alpha_i \) are interior angles. Summing over all triangles, the interior angle sums contribute \( \pi F \), while the geodesic curvature integrals along interior edges cancel. Using \( 3F = 2E \) (for closed surfaces), one obtains \( \int_M K \, dA = 2\pi(V - E + F) = 2\pi\chi(M) \).

Notation Guide

  • \( g \) — Riemannian metric
  • \( K \) — Gaussian curvature
  • \( k_g \) — geodesic curvature
  • \( dA \) — area element
  • \( ds \) — arc length element
  • \( \chi(M) \) — Euler characteristic
  • \( R \) — Riemann curvature tensor

import numpy as np

class RiemannianGeometry:
    """Demonstrate Riemannian geometry concepts."""
    
    @staticmethod
    def sphere_curvature_integrand(theta, phi, R=1):
        """
        Gaussian curvature of sphere of radius R is 1/R².
        Area element is R² sin(θ) dθ dφ.
        Product: (1/R²) · R² sin(θ) = sin(θ)
        """
        return np.sin(theta)
    
    @staticmethod
    def torus_curvature(major_radius, minor_radius, theta, phi):
        """
        Gaussian curvature of torus with radii R > r.
        K = cos(θ) / (r(R + r·cos(θ)))
        where θ is the angle around the small circle.
        """
        R, r = major_radius, minor_radius
        return np.cos(theta) / (r * (R + r * np.cos(theta)))
    
    @staticmethod
    def gauss_bonnet_sphere():
        """
        Verify Gauss-Bonnet for sphere S².
        ∫∫ K dA = 4π = 2π · χ(S²) = 2π · 2
        """
        # Numerical integration
        theta = np.linspace(0, np.pi, 100)
        phi = np.linspace(0, 2*np.pi, 100)
        d_theta = theta[1] - theta[0]
        d_phi = phi[1] - phi[0]
        
        integral = 0
        for t in theta:
            for p in phi:
                integral += RiemannianGeometry.sphere_curvature_integrand(t, p)
        
        integral *= d_theta * d_phi
        return integral
    
    @staticmethod
    def gauss_bonnet_torus(major_radius, minor_radius):
        """
        Verify Gauss-Bonnet for torus T².
        ∫∫ K dA = 0 = 2π · χ(T²) = 2π · 0
        """
        R, r = major_radius, minor_radius
        
        theta = np.linspace(0, 2*np.pi, 100)
        phi = np.linspace(0, 2*np.pi, 100)
        d_theta = theta[1] - theta[0]
        d_phi = phi[1] - phi[0]
        
        integral = 0
        for t in theta:
            for p in phi:
                K = RiemannianGeometry.torus_curvature(R, r, t, p)
                # Area element for torus
                dA = r * (R + r * np.cos(t)) * d_theta * d_phi
                integral += K * dA
        
        return integral
    
    @staticmethod
    def euler_characteristic_surface(genus, orientable=True):
        """
        Euler characteristic of closed surface.
        Orientable: χ = 2 - 2g
        Non-orientable: χ = 2 - g
        """
        if orientable:
            return 2 - 2 * genus
        else:
            return 2 - genus

📜 Math History: The Development of Calculus

The invention of calculus in the 17th century stands as one of the greatest achievements in human intellectual history, providing the mathematical language for describing change, motion, and continuous processes. While Isaac Newton and Gottfried Wilhelm Leibniz are traditionally credited as its independent inventors, the development of calculus was a gradual process building on centuries of mathematical work.

The ancient Greeks laid important foundations. Archimedes (c. 287–212 BCE) developed the method of exhaustion for computing areas and volumes, essentially using limiting processes to find the area of a parabolic segment and the volume of a sphere. His work on the quadrature of the parabola anticipated integral calculus by nearly two millennia. Similarly, Eudoxus's theory of proportions provided a rigorous framework for handling incommensurable quantities.

During the medieval period, Islamic mathematicians made crucial advances. Ibn al-Haytham (Alhazen, c. 965–1040) computed integrals of polynomial functions while studying optics. Sharaf al-Dīn al-Ṭūsī (c. 1135–1213) developed methods for finding maxima of functions, anticipating Fermat's work on optimization. The Kerala school in India, particularly Mādhava of Saṅgamagrāma (c. 1340–1425), discovered infinite series expansions for trigonometric functions, including what we now call the Madhava-Leibniz series for π/4.

In Europe, the 16th and early 17th centuries saw rapid progress. Johannes Kepler's laws of planetary motion (1609, 1619) demanded new mathematical tools for describing orbital mechanics. Bonaventura Cavalieri's principle (1635) provided a method for comparing volumes using infinitesimal slices. Pierre de Fermat developed techniques for finding tangents and maxima, essentially creating differential calculus for polynomials.

Isaac Newton began developing his "method of fluxions" around 1665–1666, during the plague years when Cambridge was closed. His approach was fundamentally kinematic: variables were "fluents" (flowing quantities) and their rates of change were "fluxions." Newton's notation (dots for time derivatives) reflected this physical interpretation. However, he kept much of his work unpublished for decades, sharing it only with close correspondents.

Gottfried Wilhelm Leibniz independently developed calculus in the 1670s, publishing his first account in 1684. His approach was more algebraic and notational, introducing the differential notation \( dx \) and \( dy \) and the integral sign \( \int \) (an elongated S for "summa"). Leibniz's notation proved more flexible and eventually became standard, though it took a century to fully displace Newton's fluxional notation in England.

The priority dispute between Newton and Leibniz, inflamed by their followers, raged from 1699 until Leibniz's death in 1716 and beyond. This controversy had lasting effects, isolating English mathematics from continental developments for generations. The Royal Society's investigation in 1712, presided over by Newton himself, unsurprisingly found in his favor.

The 18th century saw calculus applied with spectacular success to physics, particularly by the Bernoulli family, Leonhard Euler, and Joseph-Louis Lagrange. However, the foundations remained shaky. The use of infinitesimals was criticized by Bishop Berkeley as the "ghosts of departed quantities." It was not until the 19th century that Augustin-Louis Cauchy, Bernhard Bolzano, and later Karl Weierstrass provided rigorous definitions using limits, finally putting calculus on a firm logical foundation.

Problem: A Functional Equation from the IMO Shortlist

Find all functions \( f: \mathbb{R} \to \mathbb{R} \) such that for all real numbers \( x \) and \( y \): \[f(x^2 + f(y)) = y + f(x)^2\]

Hint

Start by investigating injectivity and surjectivity. Try substituting specific values like \( x = 0 \) and consider what happens when you swap \( x \) and \( y \) in various ways. Look for fixed points where \( f(a) = a \).

Solution

Step 1: Injectivity. Suppose \( f(a) = f(b) \). Setting \( x = 0 \) in the original equation: \[f(f(y)) = y + f(0)^2\] This shows \( f \) is bijective (both injective and surjective).

Step 2: Finding \( f(0) \). Let \( c = f(0) \). From \( f(f(y)) = y + c^2 \), setting \( y = 0 \): \[f(c) = c^2\] Setting \( x = 0, y = c \) in the original: \[f(c^2 + c) = c + c^2\] So \( c^2 + c \) is a fixed point.

Step 3: Finding the form. Setting \( y = 0 \) in the original: \[f(x^2 + c) = f(x)^2\] Since \( f \) is surjective, there exists \( a \) with \( f(a) = 0 \). Setting \( y = a \): \[f(x^2) = a + f(x)^2\]

Step 4: Determining \( a \) and \( c \). From \( f(x^2) = a + f(x)^2 \) and \( f(x^2 + c) = f(x)^2 \): \[f(x^2 + c) = f(x^2) - a\] Setting \( x = 0 \): \( f(c) = f(0) - a = c - a \). But \( f(c) = c^2 \), so \( c^2 = c - a \), giving \( a = c - c^2 \).

From \( f(f(0)) = 0 + c^2 \), we have \( f(c) = c^2 \). From \( f(f(c)) = c + c^2 \), and using \( f(f(y)) = y + c^2 \), this is consistent.

Step 5: Testing \( f(x) = x \). LHS: \( f(x^2 + y) = x^2 + y \). RHS: \( y + x^2 \). ✓

Step 6: Testing \( f(x) = -x \). LHS: \( f(x^2 - y) = -(x^2 - y) = y - x^2 \). RHS: \( y + (-x)^2 = y + x^2 \). ✗ (unless \( x = 0 \))

Step 7: Verification. We verify \( f(x) = x \) is the unique solution. From \( f(x^2) = a + f(x)^2 \) with \( a = 0 \) (since \( c = 0 \) from further analysis), we get \( f(x^2) = f(x)^2 \geq 0 \) for \( x \geq 0 \). Combined with bijectivity and the functional equation, this forces \( f(x) = x \) for all \( x \).

Answer: The unique solution is \( \boxed{f(x) = x} \).

🎨 Visualization of the Day: The Lorenz Attractor

The Lorenz attractor is a set of chaotic solutions to the Lorenz system, a simplified mathematical model for atmospheric convection. Discovered by Edward Lorenz in 1963, it was one of the first examples of deterministic chaos — a system whose future behavior is highly sensitive to initial conditions, yet completely determined by them.

The system is defined by three ordinary differential equations:

\[\begin{aligned} \frac{dx}{dt} &= \sigma(y - x) \\ \frac{dy}{dt} &= x(\rho - z) - y \\ \frac{dz}{dt} &= xy - \beta z \end{aligned}\]

where \( \sigma \) is the Prandtl number, \( \rho \) is the Rayleigh number, and \( \beta \) is a geometric factor. For the classic values \( \sigma = 10 \), \( \rho = 28 \), and \( \beta = 8/3 \), the system exhibits chaotic behavior with the famous "butterfly" shape.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class LorenzAttractor:
    """Generate and visualize the Lorenz attractor."""
    
    def __init__(self, sigma=10.0, rho=28.0, beta=8.0/3.0):
        self.sigma = sigma
        self.rho = rho
        self.beta = beta
    
    def lorenz_system(self, state, t):
        """Define the Lorenz system ODEs."""
        x, y, z = state
        dx_dt = self.sigma * (y - x)
        dy_dt = x * (self.rho - z) - y
        dz_dt = x * y - self.beta * z
        return np.array([dx_dt, dy_dt, dz_dt])
    
    def rk4_step(self, state, dt):
        """Single RK4 integration step."""
        k1 = self.lorenz_system(state, 0)
        k2 = self.lorenz_system(state + 0.5 * dt * k1, 0)
        k3 = self.lorenz_system(state + 0.5 * dt * k2, 0)
        k4 = self.lorenz_system(state + dt * k3, 0)
        return state + (dt / 6.0) * (k1 + 2*k2 + 2*k3 + k4)
    
    def integrate(self, initial_state, t_max, dt=0.01):
        """Integrate the Lorenz system."""
        n_steps = int(t_max / dt)
        trajectory = np.zeros((n_steps, 3))
        trajectory[0] = initial_state
        
        state = initial_state.copy()
        for i in range(1, n_steps):
            state = self.rk4_step(state, dt)
            trajectory[i] = state
        
        return trajectory
    
    def demonstrate_sensitivity(self, initial_state, perturbation, t_max):
        """Demonstrate sensitive dependence on initial conditions."""
        traj1 = self.integrate(initial_state, t_max)
        traj2 = self.integrate(initial_state + perturbation, t_max)
        
        # Calculate divergence
        distances = np.linalg.norm(traj1 - traj2, axis=1)
        return traj1, traj2, distances
