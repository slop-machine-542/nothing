Elliptic Curves: Arithmetic and Geometry United

elliptic-curves

Motivation

Elliptic curves are the meeting point of algebra, geometry, and number theory. They played a central role in Wiles's proof of Fermat's Last Theorem and form the foundation of modern cryptography. The study of their rational points connects to some of the deepest open problems in mathematics.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point \(O\). Over a field \(k\) with char\((k) \neq 2, 3\), given by the Weierstrass equation: \(y^2 = x^3 + ax + b\) with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Group Law: For points \(P, Q\) on \(E\), define \(P + Q\) as the reflection of the third intersection point of line \(PQ\) with \(E\) across the x-axis.
  • Mordell-Weil Group: The group \(E(k)\) of \(k\)-rational points on \(E\).
  • j-invariant: \(j(E) = -1728\frac{(4a)^3}{\Delta}\), classifying elliptic curves up to isomorphism over algebraically closed fields.

Theorem: Mordell-Weil Theorem

Theorem (Mordell 1922, Weil 1928): Let \(E\) be an elliptic curve over a number field \(K\). Then the group \(E(K)\) of \(K\)-rational points is a finitely generated abelian group:

\[E(K) \cong E(K)_{tors} \times \mathbb{Z}^r\]

where \(E(K)_{tors}\) is the finite torsion subgroup and \(r \geq 0\) is the rank.

Proof Sketch:

  1. Weak Mordell-Weil: Show \(E(K)/mE(K)\) is finite for some \(m \geq 2\) using Galois cohomology and Kummer theory.
  2. Height Function: Define a canonical height \(\hat{h}: E(K) \to \mathbb{R}_{\geq 0}\) satisfying \(\hat{h}(mP) = m^2\hat{h}(P)\).
  3. Descent: Use the height to show points of bounded height are finite, and apply descent to prove finite generation.

Notation Guide

  • \(E\) — elliptic curve
  • \(E(k)\) — group of \(k\)-rational points
  • \(O\) — point at infinity (identity element)
  • \(\Delta\) — discriminant
  • \(j(E)\) — j-invariant
  • \(\hat{h}\) — canonical (Néron-Tate) height

        self.b = b

Symplectic Geometry: The Geometry of Classical Mechanics

symplectic-geometry

Motivation

Symplectic geometry emerged from Hamiltonian mechanics as the natural geometric framework for studying phase space. Unlike Riemannian geometry which measures distances, symplectic geometry captures the structure of position-momentum pairs and conservation laws. It has become central to modern mathematical physics, from classical integrable systems to quantum field theory.

Definitions

  • Symplectic Form: A closed, non-degenerate 2-form \(\omega\) on a manifold \(M\), i.e., \(d\omega = 0\) and \(\omega^n \neq 0\) where \(\dim M = 2n\).
  • Symplectic Manifold: A pair \((M, \omega)\) where \(M\) is a smooth manifold and \(\omega\) is a symplectic form.
  • Hamiltonian Vector Field: For \(H \in C^\infty(M)\), the vector field \(X_H\) defined by \(\iota_{X_H}\omega = dH\).
  • Poisson Bracket: \(\{f, g\} = \omega(X_f, X_g) = X_f(g)\).

Theorem: Darboux's Theorem

Theorem (Darboux, 1882): Let \((M, \omega)\) be a symplectic manifold of dimension \(2n\). For any point \(p \in M\), there exist local coordinates \((q_1, \ldots, q_n, p_1, \ldots, p_n)\) (Darboux coordinates) such that:

\[\omega = \sum_{i=1}^n dq_i \wedge dp_i\]

In other words, every symplectic manifold is locally symplectomorphic to \((\mathbb{R}^{2n}, \omega_{std})\).

Proof Sketch:

  1. Use the non-degeneracy of \(\omega\) to construct a local frame.
  2. Apply Moser's trick: consider the linear interpolation \(\omega_t = (1-t)\omega_0 + t\omega_1\) between the standard form and the given form.
  3. Show the time-dependent vector field generating the isotopy exists using the closedness of \(\omega\).
  4. Conclude that a symplectomorphism exists in a neighborhood of \(p\).

Notation Guide

  • \((M, \omega)\) — symplectic manifold
  • \(\omega\) — symplectic form
  • \(X_H\) — Hamiltonian vector field
  • \(\{f, g\}\) — Poisson bracket
  • \(q_i, p_i\) — canonical (Darboux) coordinates
  • \(\iota_X\) — interior product (contraction)

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import FancyArrowPatch

def symplectic_form(v, w):
    """
    Standard symplectic form on R^{2n}.
    omega(v, w) = v^T J w where J = [0 I; -I 0]
    """
    n = len(v) // 2
    J = np.block([
        [np.zeros((n, n)), np.eye(n)],
        [-np.eye(n), np.zeros((n, n))]
    ])
    return v @ J @ w

def hamiltonian_vector_field(H_grad, x):
    """
    Compute Hamiltonian vector field X_H from gradient of H.
    X_H = J^{-1} ∇H = -J ∇H (since J^{-1} = -J)
    """
    n = len(x) // 2
    J = np.block([
        [np.zeros((n, n)), np.eye(n)],
        [-np.eye(n), np.zeros((n, n))]
    ])
    return -J @ H_grad

def harmonic_oscillator_hamiltonian(q, p, m=1, k=1):
    """Hamiltonian for harmonic oscillator: H = p^2/(2m) + k*q^2/2"""
    return p**2 / (2*m) + k * q**2 / 2

def harmonic_oscillator_flow(q0, p0, t, m=1, k=1):
    """
    Exact solution for harmonic oscillator.
    q(t) = q0*cos(ωt) + (p0/mω)*sin(ωt)
    p(t) = p0*cos(ωt) - mω*q0*sin(ωt)
    where ω = sqrt(k/m)
    """
    omega = np.sqrt(k / m)
    q_t = q0 * np.cos(omega * t) + (p0 / (m * omega)) * np.sin(omega * t)
    p_t = p0 * np.cos(omega * t) - m * omega * q0 * np.sin(omega * t)
    return q_t, p_t

p-adic Analysis: Numbers from a Different Perspective

p-adic-analysis

Motivation

p-adic numbers, introduced by Kurt Hensel in 1897, provide an alternative way to complete the rational numbers. While real numbers fill in the "gaps" between rationals using the usual absolute value, p-adic numbers fill gaps using divisibility by a prime \(p\). This leads to a number system where large integers are "small," with profound applications in number theory, algebraic geometry, and even physics.

Definitions

  • p-adic Valuation: For \(n \in \mathbb{Z}\), \(\nu_p(n) = k\) where \(p^k \mid n\) but \(p^{k+1} \nmid n\). For \(x = a/b \in \mathbb{Q}\), \(\nu_p(x) = \nu_p(a) - \nu_p(b)\).
  • p-adic Absolute Value: \(|x|_p = p^{-\nu_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).
  • p-adic Integers \(\mathbb{Z}_p\): \(\{x \in \mathbb{Q}_p : |x|_p \leq 1\}\), equivalently the closure of \(\mathbb{Z}\) in \(\mathbb{Q}_p\).

Theorem: Ostrowski's Theorem

Theorem (Ostrowski, 1916): Every non-trivial absolute value on \(\mathbb{Q}\) is equivalent to either:

  1. The usual absolute value \(|\cdot|_\infty\) (giving \(\mathbb{R}\)), or
  2. The p-adic absolute value \(|\cdot|_p\) for some prime \(p\) (giving \(\mathbb{Q}_p\)).

Moreover, the product formula holds: for \(x \in \mathbb{Q}^*\), \[\prod_{p \leq \infty} |x|_p = 1\]

Proof Sketch:

  1. Classify absolute values by whether they are Archimedean (\(|n|\) unbounded) or non-Archimedean (\(|n|\) bounded).
  2. For Archimedean: Show it must be equivalent to the standard absolute value.
  3. For non-Archimedean: The ultrametric inequality \(|x + y| \leq \max(|x|, |y|)\) holds. Show the absolute value is determined by the prime it "sees."
  4. The product formula follows from unique factorization in \(\mathbb{Z}\).

Notation Guide

  • \(\nu_p(x)\) — p-adic valuation
  • \(|x|_p = p^{-\nu_p(x)}\) — p-adic absolute value
  • \(\mathbb{Q}_p\) — field of p-adic numbers
  • \(\mathbb{Z}_p\) — ring of p-adic integers
  • \(\mathbb{C}_p\) — completion of algebraic closure of \(\mathbb{Q}_p\)

import math

def prime_factors(n):
    """Return prime factorization as dict {p: exponent}."""
    factors = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors

def p_adic_valuation(x, p):
    """Compute p-adic valuation of rational number x = a/b."""
    if x == 0:
        return float('inf')
    
    # Convert to fraction
    from fractions import Fraction
    frac = Fraction(x).limit_denominator()
    a, b = frac.numerator, frac.denominator
    
    # Valuation of numerator and denominator
    def val(n, p):
        if n == 0:
            return float('inf')
        count = 0
        while n % p == 0:
            n //= p
            count += 1
        return count
    
    return val(a, p) - val(b, p)

def p_adic_absolute_value(x, p):
    """Compute p-adic absolute value."""
    if x == 0:
        return 0
    return p ** (-p_adic_valuation(x, p))

def p_adic_expansion(x, p, precision=10):
    """
    Compute p-adic expansion of rational x.
    Returns coefficients [a_0, a_1, ..., a_n] where
    x = a_0 + a_1*p + a_2*p^2 + ...
    """
    from fractions import Fraction
    frac = Fraction(x).limit_denominator()
    
    # Work with numerator and denominator
    num, den = frac.numerator, frac.denominator
    
    # Make denominator coprime to p
    val_den = p_adic_valuation(den, p)
    den_p = p ** val_den
    den_rest = den // den_p
    
    # Invert den_rest mod p^precision
    mod = p ** precision
    try:
        den_inv = pow(den_rest, -1, mod)
    except ValueError:
        return None
    
    # Multiply numerator by inverse
    adjusted_num = (num * den_inv) % mod
    
    # Extract digits
    digits = []
    for i in range(precision):
        digit = adjusted_num % p
        digits.append(digit)
        adjusted_num //= p
    
    return digits

Optimal Transport: From Monge to Machine Learning

optimal-transport

Real-World Motivation

Optimal transport theory, initiated by Gaspard Monge in 1781, asks: what is the most efficient way to move a pile of sand into a hole? This seemingly simple question has profound applications in economics (resource allocation), computer vision (image registration), machine learning (generative models like Wasserstein GANs), and even biology (cell trajectories in developmental processes).

Definitions

  • Transport Plan: A measure \(\gamma\) on \(X \times Y\) with marginals \(\mu\) and \(\nu\), i.e., \(\gamma(A \times Y) = \mu(A)\) and \(\gamma(X \times B) = \nu(B)\).
  • Monge Problem: Minimize \(\int_X c(x, T(x)) \, d\mu(x)\) over transport maps \(T: X \to Y\) with \(T_\#\mu = \nu\).
  • Kantorovich Problem: Minimize \(\int_{X \times Y} c(x, y) \, d\gamma(x, y)\) over transport plans \(\gamma \in \Pi(\mu, \nu)\).
  • Wasserstein Distance: For \(p \geq 1\), \(W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int |x-y|^p \, d\gamma\right)^{1/p}\).

Theorem: Brenier's Polar Factorization

Theorem (Brenier, 1987): Let \(\mu, \nu\) be probability measures on \(\mathbb{R}^n\) with \(\mu\) absolutely continuous with respect to Lebesgue measure. Then:

  1. There exists a unique optimal transport map \(T\) for the quadratic cost \(c(x, y) = |x - y|^2/2\).
  2. This map is the gradient of a convex function: \(T = \nabla \varphi\) for some convex \(\varphi: \mathbb{R}^n \to \mathbb{R}\).
  3. The optimal plan is \(\gamma = (id \times \nabla \varphi)_\# \mu\).

Proof Sketch:

  1. Existence: Use the direct method of calculus of variations on the Kantorovich formulation.
  2. Uniqueness: The Kantorovich functional is strictly convex in a suitable sense.
  3. Structure: Use duality. The dual problem involves pairs of functions \((\varphi, \psi)\) with \(\varphi(x) + \psi(y) \leq c(x, y)\).
  4. For quadratic cost, the c-transform relates \(\varphi\) and \(\psi\), and optimality implies \(T = \nabla \varphi\).

Notation Guide

  • \(\mu, \nu\) — probability measures (source and target)
  • \(\Pi(\mu, \nu)\) — set of transport plans (couplings)
  • \(c(x, y)\) — cost function
  • \(T_\#\mu\) — pushforward measure: \((T_\#\mu)(A) = \mu(T^{-1}(A))\)
  • \(W_p\) — p-Wasserstein distance
  • \(\nabla \varphi\) — gradient of convex potential

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import linprog

def empirical_wasserstein_1d(samples1, samples2, p=1):
    """
    Compute 1-Wasserstein distance between empirical measures in 1D.
    For 1D, this reduces to L^p distance between CDFs.
    """
    # Sort samples
    s1 = np.sort(samples1)
    s2 = np.sort(samples2)
    
    # Compute empirical CDFs at combined points
    all_points = np.sort(np.concatenate([s1, s2]))
    
    cdf1 = np.searchsorted(s1, all_points, side='right') / len(s1)
    cdf2 = np.searchsorted(s2, all_points, side='right') / len(s2)
    
    # Wasserstein distance is L^p distance between CDFs
    if p == 1:
        # For p=1: integral of |CDF1 - CDF2|
        distances = np.diff(all_points, prepend=all_points[0])
        return np.sum(np.abs(cdf1 - cdf2) * distances)
    else:
        # General p
        return np.sum(np.abs(cdf1 - cdf2)**p * np.diff(all_points, prepend=all_points[0]))**(1/p)

def optimal_transport_1d_discrete(mu, nu, costs):
    """
    Solve discrete optimal transport using linear programming.
    mu: source distribution (n bins)
    nu: target distribution (m bins)
    costs: n x m cost matrix
    """
    n, m = len(mu), len(nu)
    
    # Flatten cost matrix to vector
    c = costs.flatten()
    
    # Equality constraints: marginals must match
    # Row sums = mu, column sums = nu
    A_eq = np.zeros((n + m, n * m))
    b_eq = np.concatenate([mu, nu])
    
    for i in range(n):
        for j in range(m):
            A_eq[i, i * m + j] = 1  # Row sum constraint
            A_eq[n + j, i * m + j] = 1  # Column sum constraint
    
    # Solve LP
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=(0, None), method='highs')
    
    if result.success:
        gamma = result.x.reshape(n, m)
        cost = result.fun
        return gamma, cost
    else:
        return None, None

Epidemiological Modeling: Mathematics of Disease Spread

epidemiological-modeling

Real-World Motivation

Mathematical epidemiology has never been more relevant. The COVID-19 pandemic demonstrated the critical importance of quantitative models for understanding disease dynamics, predicting healthcare burden, and evaluating intervention strategies. These models inform public health policy affecting millions of lives.

Definitions

  • SIR Model: Compartmental model with Susceptible (S), Infected (I), Recovered (R) populations governed by: \[\frac{dS}{dt} = -\beta SI, \quad \frac{dI}{dt} = \beta SI - \gamma I, \quad \frac{dR}{dt} = \gamma I\]
  • Basic Reproduction Number \(R_0\): Expected number of secondary infections from one infected individual in a fully susceptible population: \(R_0 = \beta S_0 / \gamma\).
  • Herd Immunity Threshold: The fraction of population that must be immune to prevent sustained transmission: \(1 - 1/R_0\).
  • SEIR Model: Extension with Exposed (E) compartment for latent period.

Theorem: Final Size Relation

Theorem: In the SIR model with initial conditions \(S(0) = S_0\), \(I(0) = I_0\), \(R(0) = 0\), the final epidemic size \(R_\infty = \lim_{t \to \infty} R(t)\) satisfies:

\[R_\infty = S_0\left(1 - e^{-R_0 \cdot R_\infty / N}\right)\]

where \(N = S_0 + I_0\) is the total population and \(R_0 = \beta N / \gamma\).

Proof Sketch:

  1. From the SIR equations, derive \(\frac{dI}{dS} = -1 + \frac{\gamma}{\beta S}\).
  2. Integrate from initial to final state: \(I_\infty - I_0 = -(S_\infty - S_0) + \frac{\gamma}{\beta}\ln\frac{S_\infty}{S_0}\).
  3. Since \(I_\infty = 0\) and \(R_\infty = N - S_\infty\), rearrange to get the implicit equation.
  4. Use conservation \(S + I + R = N\) to express in terms of \(R_\infty\).

Notation Guide

  • \(S(t)\) — susceptible population at time \(t\)
  • \(I(t)\) — infected (infectious) population
  • \(R(t)\) — recovered/removed population
  • \(\beta\) — transmission rate
  • \(\gamma\) — recovery rate (1/\(\gamma\) is mean infectious period)
  • \(R_0\) — basic reproduction number
  • \(N\) — total population

def sir_model(y, t, beta, gamma, N):
    """
    SIR model differential equations.
    y = [S, I, R]
    """
    S, I, R = y
    dSdt = -beta * S * I / N
    dIdt = beta * S * I / N - gamma * I
    dRdt = gamma * I
    return [dSdt, dIdt, dRdt]

def seir_model(y, t, beta, sigma, gamma, N):
    """
    SEIR model with exposed (latent) compartment.
    y = [S, E, I, R]
    sigma = 1/latent_period
    """
    S, E, I, R = y
    dSdt = -beta * S * I / N
    dEdt = beta * S * I / N - sigma * E
    dIdt = sigma * E - gamma * I
    dRdt = gamma * I
    return [dSdt, dEdt, dIdt, dRdt]

def solve_sir(S0, I0, R0, beta, gamma, t_max=160, dt=0.1):

    y0 = [S0, I0, R0]
    solution = odeint(sir_model, y0, t, args=(beta, gamma, N))
    return t, solution

    return R_inf - S0 * (1 - np.exp(-R0 * R_inf / N))

    """Compute final epidemic size numerically."""
    R_inf = fsolve(final_size_equation, N * 0.5, args=(R0, S0, N))[0]
    return R_inf

Compressed Sensing: Recovering Signals from Few Measurements

compressed-sensing

Real-World Motivation

Compressed sensing revolutionized signal processing by showing that sparse signals can be perfectly reconstructed from far fewer measurements than the Nyquist-Shannon theorem would suggest. Applications include MRI imaging (faster scans), single-pixel cameras, and efficient data compression. The 2010 IEEE Information Theory Society Paper Award recognized this breakthrough.

Definitions

  • Sparse Signal: A signal \(x \in \mathbb{R}^n\) with at most \(s\) non-zero entries: \(\|x\|_0 \leq s\).
  • Measurement Matrix: \(\Phi \in \mathbb{R}^{m \times n}\) with \(m \ll n\), used to obtain measurements \(y = \Phi x\).
  • Restricted Isometry Property (RIP): \(\Phi\) satisfies RIP of order \(s\) if there exists \(\delta_s \in (0, 1)\) such that for all \(s\)-sparse \(x\): \[(1 - \delta_s)\|x\|_2^2 \leq \|\Phi x\|_2^2 \leq (1 + \delta_s)\|x\|_2^2\]
  • Basis Pursuit: \(\ell_1\)-minimization: \(\min \|x\|_1\) subject to \(y = \Phi x\).

Theorem: Exact Recovery via Basis Pursuit

Theorem (Candès-Tao, 2005): Let \(\Phi \in \mathbb{R}^{m \times n}\) satisfy RIP of order \(2s\) with \(\delta_{2s} < \sqrt{2} - 1\). Then for any \(s\)-sparse signal \(x \in \mathbb{R}^n\), the solution \(\hat{x}\) to basis pursuit satisfies:

\[\hat{x} = x\]

That is, \(\ell_1\)-minimization exactly recovers the sparse signal.

Proof Sketch:

  1. Let \(h = \hat{x} - x\) be the recovery error. Show \(h\) lies in the null space of \(\Phi\).
  2. Use the RIP to show that vectors in the null space cannot be too concentrated on any small set of coordinates.
  3. Apply the optimality condition: \(\|\hat{x}\|_1 \leq \|x\|_1\).
  4. Combine with a cone constraint derived from RIP to show \(h = 0\).

Notation Guide

  • \(x \in \mathbb{R}^n\) — signal (unknown, to recover)
  • \(y \in \mathbb{R}^m\) — measurements
  • \(\Phi\) — measurement matrix (\(m \times n\))
  • \(\|x\|_0\) — number of non-zero entries ("\(\ell_0\) norm")
  • \(\|x\|_1 = \sum_i |x_i|\) — \(\ell_1\) norm
  • \(\delta_s\) — RIP constant of order \(s\)

import matplotlib.pyplot as plt
from scipy.optimize import minimize
from scipy.fft import dct, idct

def generate_sparse_signal(n, s):
    """Generate a random s-sparse signal in R^n."""
    x = np.zeros(n)
    # Random support
    support = np.random.choice(n, s, replace=False)
    # Random values (Gaussian)
    x[support] = np.random.randn(s)
    return x, support

def generate_measurement_matrix(m, n, matrix_type='gaussian'):
    """Generate a measurement matrix of size m x n."""
    if matrix_type == 'gaussian':
        # Gaussian random matrix (satisfies RIP with high probability)
        Phi = np.random.randn(m, n) / np.sqrt(m)
    elif matrix_type == 'bernoulli':
        # Bernoulli random matrix
        Phi = np.random.choice([-1, 1], size=(m, n)) / np.sqrt(m)
    return Phi

def basis_pursuit(y, Phi, method='l1'):
    """
    Solve basis pursuit: min ||x||_1 subject to Phi @ x = y.
    Using scipy.optimize with equality constraint.
    """
    m, n = Phi.shape
    
    # Objective: L1 norm (not differentiable, use approximation)
    def objective(x):
        return np.sum(np.abs(x))
    
    # Equality constraint: Phi @ x = y
    def constraint(x):
        return Phi @ x - y
    
    # Initial guess
    x0 = np.linalg.lstsq(Phi, y, rcond=None)[0]
    
    # Solve
    result = minimize(
        objective,
        x0,
        method='SLSQP',
        constraints={'type': 'eq', 'fun': constraint},
        options={'maxiter': 1000}
    )
    
    return result.x

def iterative_soft_thresholding(y, Phi, lambda_reg=0.1, max_iter=1000, tol=1e-6):
    """
    Iterative Soft Thresholding Algorithm (ISTA) for LASSO.
    Minimizes: 0.5 * ||y - Phi @ x||^2 + lambda * ||x||_1
    """
    m, n = Phi.shape
    x = np.zeros(n)
    
    # Lipschitz constant
    L = np.linalg.norm(Phi, 2)**2
    step_size = 1 / L
    
    for _ in range(max_iter):
        x_old = x.copy()
        
        # Gradient step
        grad = Phi.T @ (Phi @ x - y)
        z = x - step_size * grad
        
        # Soft thresholding
        x = np.sign(z) * np.maximum(np.abs(z) - lambda_reg * step_size, 0)
        
        if np.linalg.norm(x - x_old) < tol:
            break
    
    return x

Derived Categories: Homological Algebra Reimagined

derived-categories

Historical Context

Derived categories were introduced by Jean-Louis Verdier in his 1963 PhD thesis under Alexandre Grothendieck. The theory emerged from the need to properly handle derived functors in algebraic geometry. Grothendieck's duality theory required a framework where certain natural transformations became actual isomorphisms. Verdier's construction, formalized in SGA 4½, revolutionized homological algebra and has since become essential in algebraic geometry, representation theory, and mathematical physics (string theory and mirror symmetry).

Definitions

  • Chain Complex: A sequence \(\cdots \to A^{n-1} \xrightarrow{d^{n-1}} A^n \xrightarrow{d^n} A^{n+1} \to \cdots\) with \(d^n \circ d^{n-1} = 0\).
  • Quasi-Isomorphism: A chain map \(f: A^\bullet \to B^\bullet\) inducing isomorphisms on all cohomology groups: \(H^n(f): H^n(A^\bullet) \xrightarrow{\sim} H^n(B^\bullet)\).
  • Derived Category: The localization of the homotopy category of complexes at quasi-isomorphisms. Objects are complexes, morphisms are equivalence classes of roofs \(A^\bullet \leftarrow C^\bullet \to B^\bullet\).
  • Triangulated Structure: Distinguished triangles \(A \to B \to C \to A[1]\) generalizing short exact sequences.

Theorem: Grothendieck Duality

Theorem: Let \(f: X \to Y\) be a proper morphism of Noetherian schemes. There exists a right adjoint \(f^!: D^b_{coh}(Y) \to D^b_{coh}(X)\) to the derived pushforward \(\mathbf{R}f_*\), satisfying:

\[\mathbf{R}\mathcal{H}om_Y(\mathbf{R}f_*\mathcal{F}^\bullet, \mathcal{G}^\bullet) \cong \mathbf{R}f_*\mathbf{R}\mathcal{H}om_X(\mathcal{F}^\bullet, f^!\mathcal{G}^\bullet)\]

for \(\mathcal{F}^\bullet \in D^b_{coh}(X)\), \(\mathcal{G}^\bullet \in D^b_{coh}(Y)\).

Notation Guide

  • \(D(\mathcal{A})\) — derived category of abelian category \(\mathcal{A}\)
  • \(D^b(\mathcal{A})\) — bounded derived category
  • \([n]\) — shift functor: \(A[k]^i = A^{i+k}\)
  • \(\mathbf{R}F\) — right derived functor
  • \(\mathbf{L}F\) — left derived functor
  • \(Cone(f)\) — mapping cone of morphism \(f\)

import numpy as np

class ChainComplex:
    """
    Finite chain complex over real numbers.
    C_n -> C_{n+1} with d^2 = 0.
    """
    def __init__(self, spaces, differentials):
        """
        spaces: dict {degree: dimension}
        differentials: dict {degree: matrix mapping degree -> degree+1}
        """
        self.spaces = spaces
        self.differentials = differentials
        self._validate()
    
    def _validate(self):
        """Verify d^2 = 0."""
        for deg in self.differentials:
            if deg + 1 in self.differentials:
                d1 = self.differentials[deg]
                d2 = self.differentials[deg + 1]
                composition = d2 @ d1
                if not np.allclose(composition, 0):
                    raise ValueError(f"d^2 != 0 at degree {deg}")
    
    def cohomology(self, degree):
        """Compute cohomology at given degree."""
        if degree not in self.spaces:
            return 0
        
        # ker(d^n) / im(d^{n-1})
        d_n = self.differentials.get(degree, np.zeros((0, self.spaces[degree])))
        d_n_minus_1 = self.differentials.get(degree - 1, np.zeros((self.spaces[degree], 0)))
        
        # Rank-nullity
        rank_prev = np.linalg.matrix_rank(d_n_minus_1)
        rank_cur = np.linalg.matrix_rank(d_n)
        
        return self.spaces[degree] - rank_prev - (self.spaces.get(degree + 1, 0) - rank_cur)
    
    def euler_characteristic(self):
        """Compute Euler characteristic: sum (-1)^i dim H^i."""
        return sum((-1)**deg * self.spaces[deg] for deg in self.spaces)

def mapping_cone(f, C1, C2):
    """
    Compute mapping cone of chain map f: C1 -> C2.
    Cone(f)_n = C1_{n+1} ⊕ C2_n
    """
    cone_spaces = {}
    cone_diffs = {}
    
    all_degs = set(C1.spaces.keys()) | set(C2.spaces.keys())
    
    for deg in all_degs:
        dim1 = C1.spaces.get(deg + 1, 0)
        dim2 = C2.spaces.get(deg, 0)
        cone_spaces[deg] = dim1 + dim2
        
        # Differential matrix
        # [ -d1_{n+1}     0    ]
        # [ f_{n+1}    d2_n    ]
        d1 = C1.differentials.get(deg + 1, np.zeros((C1.spaces.get(deg + 2, 0), dim1)))
        d2 = C2.differentials.get(deg, np.zeros((dim2, C2.spaces.get(deg - 1, 0))))
        f_n = f.get(deg + 1, np.zeros((dim2, dim1)))
        
        top = np.hstack([-d1, np.zeros((d1.shape[0], dim2))]) if d1.size > 0 else np.zeros((0, dim1 + dim2))
        bottom = np.hstack([f_n, d2]) if d2.size > 0 or f_n.size > 0 else np.zeros((dim2, dim1 + dim2))
        
        if top.size > 0 and bottom.size > 0:
            cone_diffs[deg] = np.vstack([top, bottom])
        elif top.size > 0:
            cone_diffs[deg] = top
        elif bottom.size > 0:
            cone_diffs[deg] = bottom
    
    return ChainComplex(cone_spaces, cone_diffs)

Arithmetic Geometry: Where Number Theory Meets Algebraic Geometry

arithmetic-geometry

Historical Context

Arithmetic geometry emerged in the mid-20th century as mathematicians realized that geometric methods could solve Diophantine equations. The proof of the Mordell conjecture by Gerd Faltings in 1983 (earning him a Fields Medal) marked a watershed moment. Faltings showed that algebraic curves of genus at least 2 have only finitely many rational points. This result, combined with the subsequent proof of Fermat's Last Theorem by Andrew Wiles in 1994, demonstrated the power of the geometric approach to number theory.

Definitions

  • Arithmetic Variety: A scheme \(X\) of finite type over \(\text{Spec}(\mathbb{Z})\) or \(\text{Spec}(\mathcal{O}_K)\) for a number field \(K\).
  • Rational Point: For a variety \(X\) over a field \(k\), a \(k\)-rational point is a morphism \(\text{Spec}(k) \to X\), equivalently a solution to the defining equations in \(k\).
  • Height Function: A measure of the arithmetic complexity of a rational point. For \(P = [x_0 : \cdots : x_n] \in \mathbb{P}^n(\mathbb{Q})\) with coprime integers \(x_i\): \(H(P) = \max_i |x_i|\).
  • Hasse Principle: A variety has a rational point over \(\mathbb{Q}\) if and only if it has points over \(\mathbb{R}\) and over \(\mathbb{Q}_p\) for all primes \(p\).

Theorem: Faltings's Theorem (Mordell Conjecture)

Theorem (Faltings, 1983): Let \(C\) be a smooth projective curve of genus \(g \geq 2\) defined over a number field \(K\). Then the set of \(K\)-rational points \(C(K)\) is finite.

Key Ingredients:

  1. Arakelov Theory: Intersection theory on arithmetic surfaces, combining algebraic geometry over \(\mathbb{Z}\) with complex analytic methods.
  2. Semisimplicity of Tate Modules: Faltings proved that the Tate module of an abelian variety is semisimple as a Galois representation.
  3. Isogeny Theorem: Abelian varieties with isomorphic Tate modules are isogenous.
  4. Height Bounds: Parshin's trick reduces the Mordell conjecture to bounding heights, which Faltings achieved using Arakelov theory.

  • \(\mathcal{O}_K\) — ring of integers of number field \(K\)
  • \(X(K)\) — set of \(K\)-rational points
  • \(H(P)\) or \(h(P)\) — height of point \(P\)
  • \(T_\ell(A)\) — \(\ell\)-adic Tate module of abelian variety \(A\)
  • \(\text{Spec}(R)\) — prime spectrum of ring \(R\)
  • \(g(X)\) — genus of curve \(X\)

Analytic Number Theory: The Distribution of Primes

analytic-number-theory

Historical Context

The study of primes using analysis began with Euler's product formula in 1737, connecting the zeta function to primes. Dirichlet's 1837 proof of primes in arithmetic progressions using L-functions established the field. Riemann's 1859 memoir introduced the zeta function's complex-analytic properties and the famous hypothesis. The prime number theorem (proved independently by Hadamard and de la Vallée Poussin in 1896) showed \(\pi(x) \sim x/\ln x\), a triumph of complex analysis. Modern work, including the proof of the prime number theorem for arithmetic progressions and bounds on L-functions, continues to rely on sophisticated analytic techniques.

Definitions

  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^{\infty} n^{-s} = \prod_p (1 - p^{-s})^{-1}\) for \(\text{Re}(s) > 1\), analytically continued to \(\mathbb{C} \setminus \{1\}\).
  • Prime Counting Function: \(\pi(x) = \#\{p \leq x : p \text{ prime}\}\).
  • Chebyshev Functions: \(\vartheta(x) = \sum_{p \leq x} \ln p\) and \(\psi(x) = \sum_{n \leq x} \Lambda(n)\) where \(\Lambda(n)\) is the von Mangoldt function.
  • Dirichlet L-function: For character \(\chi \mod q\): \(L(s, \chi) = \sum_{n=1}^{\infty} \chi(n) n^{-s}\).

Theorem: The Prime Number Theorem

Theorem (Hadamard, de la Vallée Poussin, 1896): Let \(\pi(x)\) denote the number of primes less than or equal to \(x\). Then:

\[\lim_{x \to \infty} \frac{\pi(x)}{x / \ln x} = 1\]

Equivalently, \(\pi(x) \sim \text{Li}(x)\) where \(\text{Li}(x) = \int_2^x \frac{dt}{\ln t}\) is the logarithmic integral.

Proof Sketch (von Mangoldt's approach):

  1. Relate \(\psi(x)\) to the zeta function via \(-\frac{\zeta'(s)}{\zeta(s)} = \sum_{n=1}^{\infty} \Lambda(n) n^{-s}\).
  2. Use Perron's formula to express \(\psi(x)\) as a contour integral involving \(\zeta'/\zeta\).
  3. Shift the contour to the left, picking up residues at zeros of \(\zeta(s)\).
  4. The main term comes from the pole at \(s = 1\); error terms involve the zeros.
  5. Hadamard and de la Vallée Poussin proved \(\zeta(1 + it) \neq 0\) for all \(t \neq 0\), giving the result.

Notation Guide

  • \(\zeta(s)\) — Riemann zeta function
  • \(\pi(x)\) — prime counting function
  • \(\psi(x), \vartheta(x)\) — Chebyshev functions
  • \(\Lambda(n)\) — von Mangoldt function (\(\ln p\) if \(n = p^k\), 0 otherwise)
  • \(L(s, \chi)\) — Dirichlet L-function
  • \(\text{Li}(x)\) — logarithmic integral
  • \(\rho = \beta + i\gamma\) — non-trivial zero of \(\zeta(s)\)

def sieve_of_eratosthenes(n):
    """Generate all primes up to n using the Sieve of Eratosthenes."""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(np.sqrt(n)) + 1):
        if is_prime[i]:
            for j in range(i*i, n + 1, i):
                is_prime[j] = False
    return [i for i in range(2, n + 1) if is_prime[i]]

def prime_counting_function(x, primes):
    """Count primes <= x."""
    return sum(1 for p in primes if p <= x)

def logarithmic_integral(x):
    """Compute Li(x) = integral from 2 to x of dt/ln(t)."""
    if x <= 2:
        return 0
    result, _ = integrate.quad(lambda t: 1 / np.log(t), 2, x)
    return result

def chebyshev_theta(x, primes):
    """Compute theta(x) = sum_{p <= x} log(p)."""
    return sum(np.log(p) for p in primes if p <= x)

def chebyshev_psi(x, primes):
    """Compute psi(x) = sum_{p^k <= x} log(p)."""
    total = 0
    for p in primes:
        if p > x:
            break
        pk = p
        while pk <= x:
            total += np.log(p)
            pk *= p
    return total

def von_mangoldt(n, primes_set):
    """Compute the von Mangoldt function."""
    if n < 2:
        return 0
    # Check if n is a prime power
    for p in primes_set:
        if p > n:
            break
        pk = p
        while pk <= n:
            if pk == n:
                return np.log(p)
            pk *= p
    return 0

Homotopy Type Theory: Foundations for the 21st Century

homotopy-type-theory

Historical Context

Homotopy Type Theory (HoTT) emerged from a surprising connection between topology and type theory discovered by Steve Awodey, Michael Warren, and independently Vladimir Voevodsky around 2006-2009. Voevodsky, a Fields Medalist for his work on motivic homotopy theory, realized that Martin-Löf type theory has a natural homotopical interpretation. This led to the Univalent Foundations program, proposing a new foundation for mathematics based on type theory rather than set theory. The 2013 IAS Special Year on HoTT brought together leading researchers and produced the HoTT Book, making the subject accessible to a broad audience.

Definitions

  • Type: The basic notion in type theory, analogous to both sets and propositions. Elements of a type are called terms.
  • Identity Type: For \(a, b : A\), the type \(a =_A b\) (or \(\text{Id}_A(a, b)\)) represents paths/identifications between \(a\) and \(b\).
  • Homotopy Level (h-level): A hierarchy classifying types by their homotopical complexity. Sets are h-level 2, groupoids are h-level 3, etc.
  • Univalence Axiom: For types \(A, B\), the canonical map \((A = B) \to (A \simeq B)\) from paths to equivalences is itself an equivalence.
  • Higher Inductive Type (HIT): Types defined by generators for both points and paths, allowing direct construction of spaces like the circle \(S^1\).

Theorem: The Univalence Principle

Theorem (Voevodsky's Univalence Axiom): In Homotopy Type Theory with the univalence axiom, equivalent types are equal. Formally, for a universe \(\mathcal{U}\) and types \(A, B : \mathcal{U}\):

\[(A =_\mathcal{U} B) \simeq (A \simeq B)\]

where \(A \simeq B\) denotes the type of equivalences from \(A\) to \(B\).

Consequences:

  1. Structure Invariance: Isomorphic structures (groups, rings, etc.) are equal and satisfy the same properties.
  2. Function Extensionality: Functions are equal if they agree on all inputs, provable from univalence.
  3. Propositional Extensionality: Logically equivalent propositions are equal.
  4. Transport: Structures can be transported along equivalences.

Notation Guide

  • \(a : A\) — term \(a\) has type \(A\)
  • \(a =_A b\) or \(\text{Id}_A(a, b)\) — identity type (paths from \(a\) to \(b\))
  • \(\Sigma_{x:A} B(x)\) — dependent sum type (analogous to disjoint union)
  • \(\Pi_{x:A} B(x)\) — dependent product type (analogous to function space)
  • \(A \simeq B\) — type of equivalences
  • \(\mathcal{U}\) — universe of types
  • \(\text{isContr}(A)\), \(\text{isProp}(A)\), \(\text{isSet}(A)\) — h-level predicates

from typing import Callable, TypeVar, Generic, List

T = TypeVar('T')
U = TypeVar('U')

# Simulating HoTT concepts in Python

@dataclass
class Path:
    """
    Represents a path (identity) between two points.
    In HoTT: p : a =_A b
    """
    source: any
    target: any
    name: str = "path"
    
    def inverse(self):
        """Path reversal: p^{-1} : b = a"""
        return Path(self.target, self.source, f"{self.name}^{{-1}}")
    
    def concat(self, other: 'Path') -> 'Path':
        """Path concatenation: p · q : a = c given p : a = b, q : b = c"""
        if self.target != other.source:
            raise ValueError("Paths don't compose: target != source")
        return Path(self.source, other.target, f"{self.name}·{other.name}")

class Equivalence(Generic[T, U]):
    """
    Represents an equivalence between types (sets in this simulation).
    In HoTT: f : A ≃ B means f is an equivalence.
    """
    def __init__(self, forward: Callable[[T], U], backward: Callable[[U], T], 
                 name: str = "equiv"):
        self.forward = forward
        self.backward = backward
        self.name = name
    
    def compose(self, other: 'Equivalence[U, V]') -> 'Equivalence[T, V]':
        """Compose equivalences."""
        return Equivalence(
            lambda x: other.forward(self.forward(x)),
            lambda z: self.backward(other.backward(z)),
            f"{self.name}∘{other.name}"
        )

def transport(A: List[T], B: List[U], equiv: Equivalence[T, U], 
              property_A: Callable[[T], bool]) -> Callable[[U], bool]:
    """
    Transport a property along an equivalence.
    In HoTT: transport^P(p, a) : P(B) given p : A = B, a : P(A)
    """
    def property_B(y: U) -> bool:
        x = equiv.backward(y)
        return property_A(x)
    return property_B

📜 Math History: Carl Friedrich Gauss — The Prince of Mathematicians

Carl Friedrich Gauss (1777–1855) stands as one of the most influential mathematicians in history, often ranked alongside Archimedes and Newton. Born to humble parents in Brunswick, Germany, his prodigious mathematical talent was evident from an extraordinarily young age. The famous anecdote of the seven-year-old Gauss summing the integers from 1 to 100 in seconds—by pairing 1 with 100, 2 with 99, and so on, to obtain 50 pairs of 101—reveals both his computational brilliance and his instinct for elegant solutions.

Gauss's doctoral thesis, completed at the age of 21, contained the first rigorous proof of the Fundamental Theorem of Algebra, establishing that every non-constant polynomial with complex coefficients has at least one complex root. This result, which had eluded rigorous proof despite being widely believed, demonstrated Gauss's commitment to mathematical rigor that would characterize his entire career.

His 1801 masterpiece, Disquisitiones Arithmeticae, transformed number theory from a collection of isolated results into a systematic discipline. In it, Gauss introduced the concept of congruence, developed the theory of quadratic forms, and proved the law of quadratic reciprocity—a result he called the "golden theorem" and to which he returned throughout his life seeking new proofs. The book also contained his construction of the regular 17-gon with compass and straightedge, the first such construction discovered since antiquity, which convinced the young Gauss to pursue mathematics rather than philology.

Beyond pure mathematics, Gauss made foundational contributions to astronomy, geodesy, and physics. His calculation of the orbit of the asteroid Ceres, based on limited observational data, brought him international fame. In physics, he developed the theory of electromagnetism independently of Maxwell and, with Wilhelm Weber, invented one of the first electric telegraphs. His work on potential theory and differential geometry—the study of curved surfaces—laid groundwork for Einstein's general theory of relativity.

Gauss's personal motto, pauca sed matura (few but ripe), reflected his perfectionism. He published only a fraction of his discoveries, preferring to wait until his results were polished to his exacting standards. Much of his work was found in his extensive notebooks after his death, including anticipations of non-Euclidean geometry, elliptic functions, and the theory of functions of a complex variable. His influence extends through his students—most notably Bernhard Riemann—and through the mathematical culture of rigor and abstraction that he helped establish.

Putnam Competition Problem (1992 B5)

Let \(S\) be a set of \(n\) distinct real numbers. Let \(A_S\) be the set of all averages of pairs of distinct elements of \(S\). For a given \(n \geq 2\), what is the minimum possible number of elements in \(A_S\)?

Hint

Consider the case where \(S\) is an arithmetic progression. What is \(|A_S|\) in this case? Then show this is minimal by considering the smallest and largest elements of \(S\) and their averages.

Solution

Answer: The minimum is \(2n - 3\).

Proof:

Let \(S = \{x_1 < x_2 < \cdots < x_n\}\).

Upper bound: If \(S = \{1, 2, \ldots, n\}\), then \(A_S = \{\frac{3}{2}, 2, \frac{5}{2}, \ldots, \frac{2n-1}{2}\}\), which has \(2n - 3\) elements.

Lower bound: Consider the following averages involving the extreme elements:

  • \(\frac{x_1 + x_2}{2} < \frac{x_1 + x_3}{2} < \cdots < \frac{x_1 + x_n}{2}\) — this gives \(n-1\) distinct averages.
  • \(\frac{x_1 + x_n}{2} < \frac{x_2 + x_n}{2} < \cdots < \frac{x_{n-1} + x_n}{2}\) — this gives \(n-1\) distinct averages.

These two sets intersect only at \(\frac{x_1 + x_n}{2}\), giving at least \(2(n-1) - 1 = 2n - 3\) distinct elements in \(A_S\).

Therefore, the minimum is exactly \(2n - 3\).

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most recognizable fractals in mathematics, defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures that echo the whole.

The visualization below colors points based on how quickly the iteration escapes to infinity (if at all). Points in black belong to the Mandelbrot set itself.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until escape for point c."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(width=800, height=600, x_min=-2.5, x_max=1, y_min=-1.25, y_max=1.25, max_iter=100):
    """Generate the Mandelbrot set image."""
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M

# Generate and display
