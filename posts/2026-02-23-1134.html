1. Galois Theory: The Mathematics of Equation Solving

Motivation

Why can we solve quadratic equations with a formula, but not general quintic equations? Galois theory provides a profound answer by connecting field extensions to group theory, revealing that the solvability of polynomial equations depends on the structure of their symmetry groups.

Definitions

  • Field Extension: A field \(K\) containing a subfield \(F\) is called a field extension, denoted \(K/F\).
  • Splitting Field: The smallest field extension containing all roots of a polynomial.
  • Galois Group: For a field extension \(K/F\), the Galois group \(\text{Gal}(K/F)\) is the group of field automorphisms of \(K\) that fix \(F\) pointwise.
  • Solvable Group: A group with a composition series where all factor groups are abelian.

Theorem: Abel-Ruffini Theorem

There is no general algebraic solution using radicals for polynomial equations of degree five or higher.

Proof Sketch:

For the general quintic \(f(x) = x^5 + a_4x^4 + a_3x^3 + a_2x^2 + a_1x + a_0\), the Galois group over the coefficient field is the symmetric group \(S_5\). Since \(S_5\) is not solvable (its only nontrivial normal subgroup is \(A_5\), which is simple and non-abelian), the general quintic cannot be solved by radicals.

The key observation is that radicals correspond to cyclic extensions, and a tower of cyclic extensions yields a solvable Galois group. Since \(S_5\) is not solvable, no such tower exists.

Notation Guide

  • \(K/F\): Field extension
  • \([K:F]\): Degree of extension
  • \(\text{Gal}(K/F)\): Galois group
  • \(K^G\): Fixed field of group \(G\)

2. Measure Theory: The Foundation of Modern Integration

Motivation

The Riemann integral has limitations—it cannot handle functions with too many discontinuities and struggles with limits of integrals. Measure theory, developed by Lebesgue, provides a more robust framework for integration that overcomes these obstacles and forms the foundation of probability theory and functional analysis.

Definitions

  • \(\sigma\)-algebra: A collection \(\mathcal{F}\) of subsets of \(X\) containing \(X\), closed under complements and countable unions.
  • Measure: A function \(\mu: \mathcal{F} \to [0, \infty]\) with \(\mu(\emptyset) = 0\) and countable additivity.
  • Measurable Function: A function \(f: X \to \mathbb{R}\) where \(f^{-1}(B)\) is measurable for all Borel sets \(B\).
  • Lebesgue Integral: For simple functions \(\phi = \sum a_i \chi_{E_i}\), \(\int \phi \, d\mu = \sum a_i \mu(E_i)\), extended to general functions via limits.

Theorem: Monotone Convergence Theorem

Let \((f_n)\) be a sequence of non-negative measurable functions with \(f_n \leq f_{n+1}\) and \(f_n \to f\) pointwise. Then:

\[\lim_{n \to \infty} \int f_n \, d\mu = \int f \, d\mu\]

Proof:

Since \(f_n \leq f_{n+1} \leq f\), we have \(\int f_n \leq \int f_{n+1} \leq \int f\), so \(\lim \int f_n \leq \int f\).

For the reverse inequality, let \(s\) be a simple function with \(0 \leq s \leq f\). For \(\alpha \in (0, 1)\), define \(E_n = \{x : f_n(x) \geq \alpha s(x)\}\).

Then \(E_n \uparrow X\) and \(\int f_n \geq \int_{E_n} f_n \geq \alpha \int_{E_n} s\).

By continuity of measure, \(\int_{E_n} s \to \int s\), so \(\lim \int f_n \geq \alpha \int s\). Taking \(\alpha \to 1\) and supremum over \(s\) gives \(\lim \int f_n \geq \int f\).

Notation Guide

  • \(\mathcal{F}\): \(\sigma\)-algebra
  • \(\mu\): Measure
  • \(\int f \, d\mu\): Lebesgue integral
  • \(\chi_E\): Characteristic function of set \(E\)
  • \(\mathcal{L}^1\): Space of integrable functions

Python Implementation

import numpy as np
from scipy import integrate

def lebesgue_approximation(f, a, b, n_partitions=1000):
    """
    Approximate Lebesgue integral by partitioning the range.
    This demonstrates the key difference from Riemann integration.
    """
    # Sample function values
    x = np.linspace(a, b, 10000)
    y = f(x)
    
    # Partition the range [min(y), max(y)]
    y_min, y_max = np.min(y), np.max(y)
    y_partitions = np.linspace(y_min, y_max, n_partitions)
    dy = (y_max - y_min) / n_partitions
    
    integral_approx = 0
    for i in range(n_partitions):
        y_lower = y_partitions[i]
        y_upper = y_partitions[i+1] if i+1 < n_partitions else y_max
        y_mid = (y_lower + y_upper) / 2
        
        # Measure of set where f is in [y_lower, y_upper)
        mask = (y >= y_lower) & (y < y_upper)
        measure = np.sum(mask) * (b - a) / len(x)
        
        integral_approx += y_mid * measure
    
    return integral_approx

3. Algebraic Number Theory: Rings of Integers and Unique Factorization

Motivation

While the integers enjoy unique prime factorization, this property fails in many natural extensions. Algebraic number theory studies number fields and their rings of integers, developing tools like ideals to restore unique factorization and solve Diophantine equations like Fermat's Last Theorem.

Definitions

  • Number Field: A finite extension \(K/\mathbb{Q}\) of the rational numbers.
  • Ring of Integers: \(\mathcal{O}_K = \{x \in K : x \text{ is a root of a monic polynomial in } \mathbb{Z}[t]\}\).
  • Dedekind Domain: An integral domain where every nonzero proper ideal factors uniquely into prime ideals.
  • Class Number: The order of the ideal class group, measuring the failure of unique factorization.

Theorem: Dedekind's Unique Factorization of Ideals

In the ring of integers \(\mathcal{O}_K\) of a number field \(K\), every nonzero proper ideal \(\mathfrak{a}\) factors uniquely (up to ordering) as:

\[\mathfrak{a} = \mathfrak{p}_1^{e_1} \mathfrak{p}_2^{e_2} \cdots \mathfrak{p}_r^{e_r}\]

where \(\mathfrak{p}_i\) are distinct prime ideals and \(e_i \geq 1\).

Proof Sketch:

Existence: If \(\mathfrak{a}\) is not prime, find \(\mathfrak{a} = \mathfrak{bc}\) with proper factors. The norm \(N(\mathfrak{a}) = |\mathcal{O}_K/\mathfrak{a}|\) decreases, so this process terminates.

Uniqueness: If \(\mathfrak{p}_1 \cdots \mathfrak{p}_r = \mathfrak{q}_1 \cdots \mathfrak{q}_s\), then \(\mathfrak{p}_1 \supseteq \mathfrak{q}_1 \cdots \mathfrak{q}_s\). Since \(\mathfrak{p}_1\) is prime, \(\mathfrak{p}_1 \supseteq \mathfrak{q}_j\) for some \(j\). In a Dedekind domain, nonzero prime ideals are maximal, so \(\mathfrak{p}_1 = \mathfrak{q}_j\). Cancel and continue by induction.

Notation Guide

  • \(K/\mathbb{Q}\): Number field
  • \(\mathcal{O}_K\): Ring of integers
  • \(\mathfrak{p}, \mathfrak{q}\): Prime ideals (Fraktur script)
  • \(N(\mathfrak{a})\): Ideal norm
  • \(h_K\): Class number

1. Bayesian Inference: Updating Beliefs with Evidence

Real-World Motivation

How should we update our beliefs when we observe new data? Bayesian inference provides a principled framework for learning from evidence, with applications in medical diagnosis, spam filtering, machine learning, and scientific discovery. It allows us to quantify uncertainty and make optimal decisions under incomplete information.

Definitions

  • Prior Distribution \(p(\theta)\): Our beliefs about parameter \(\theta\) before observing data.
  • Likelihood \(p(x|\theta)\): The probability of observing data \(x\) given parameter \(\theta\).
  • Posterior Distribution \(p(\theta|x)\): Updated beliefs after observing data.
  • Evidence \(p(x)\): The marginal probability of the data.

Theorem: Bayes' Theorem

For parameters \(\theta\) and observed data \(x\):

\[p(\theta|x) = \frac{p(x|\theta) \cdot p(\theta)}{p(x)} = \frac{p(x|\theta) \cdot p(\theta)}{\int p(x|\theta') p(\theta') \, d\theta'}\]

Proof:

From the definition of conditional probability:

\[p(\theta|x) = \frac{p(\theta, x)}{p(x)} \quad \text{and} \quad p(x|\theta) = \frac{p(\theta, x)}{p(\theta)}\]

Therefore \(p(\theta, x) = p(x|\theta) \cdot p(\theta)\), and substituting:

\[p(\theta|x) = \frac{p(x|\theta) \cdot p(\theta)}{p(x)}\]

The denominator follows from the law of total probability.

Notation Guide

  • \(p(\theta)\): Prior probability density
  • \(p(x|\theta)\): Likelihood function
  • \(p(\theta|x)\): Posterior density
  • \(\propto\): "Proportional to" (ignoring normalizing constants)
  • \(\mathbb{E}[\theta|x]\): Posterior mean

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

def beta_binomial_update(alpha_prior, beta_prior, successes, trials):
    """
    Bayesian update for coin flip problem.
    Prior: Beta(α, β)
    Likelihood: Binomial(n, k)
    Posterior: Beta(α + k, β + n - k)
    """
    alpha_post = alpha_prior + successes
    beta_post = beta_prior + trials - successes
    return alpha_post, beta_post

# MCMC sampling with Metropolis-Hastings
def metropolis_hastings(log_posterior, initial, n_samples=10000, proposal_std=0.1):
    """
    Simple MCMC sampler for Bayesian inference.
    """
    samples = [initial]
    current = initial
    current_log_prob = log_posterior(current)
    
    for _ in range(n_samples):
        proposal = current + np.random.normal(0, proposal_std)
        proposal_log_prob = log_posterior(proposal)
        
        log_alpha = proposal_log_prob - current_log_prob
        if np.log(np.random.random()) < log_alpha:
            current = proposal
            current_log_prob = proposal_log_prob
        samples.append(current)
    
    return np.array(samples[1000:])  # Burn-in

data = np.random.normal(5, 1, 100)  # True mean = 5

def log_posterior(mu):
    if mu < -10 or mu > 15:  # Broad prior
        return -np.inf
    log_likelihood = np.sum(stats.norm.logpdf(data, mu, 1))
    log_prior = stats.norm.logpdf(mu, 0, 10)  # N(0, 10) prior
    return log_likelihood + log_prior

samples = metropolis_hastings(log_posterior, 0, n_samples=5000)

print(f"95% Credible interval: ({np.percentile(samples, 2.5):.3f}, {np.percentile(samples, 97.5):.3f})")

2. Network Science: Graph Theory for Complex Systems

Real-World Motivation

From social networks to the internet, from neural connections to power grids, complex systems can be modeled as networks. Network science applies graph theory to understand connectivity, information flow, resilience, and emergent phenomena in these systems, enabling us to design better infrastructure and predict system behavior.

Definitions

  • Graph \(G = (V, E)\): A set of vertices \(V\) connected by edges \(E\).
  • Degree \(k_i\): Number of edges connected to vertex \(i\).
  • Clustering Coefficient: For vertex \(i\), \(C_i = \frac{2e_i}{k_i(k_i-1)}\) where \(e_i\) is the number of edges between neighbors of \(i\).
  • Path Length: The number of edges in the shortest path between two vertices.
  • Adjacency Matrix \(A\): Matrix where \(A_{ij} = 1\) if vertices \(i\) and \(j\) are connected, 0 otherwise.

Theorem: Spectral Graph Theory — Fiedler's Theorem

For a connected graph \(G\) with Laplacian \(L = D - A\) (degree matrix minus adjacency matrix), let \(0 = \lambda_1 < \lambda_2 \leq \cdots \leq \lambda_n\) be the eigenvalues. The graph is connected if and only if \(\lambda_2 > 0\).

Furthermore, the algebraic connectivity \(\lambda_2\) satisfies:

\[\lambda_2 \leq \frac{n}{n-1} \min_{i \in V} k_i\]

Proof Sketch:

The Laplacian \(L\) is positive semi-definite with \(\lambda_1 = 0\) and eigenvector \(\mathbf{1}\) (all ones).

If \(G\) is disconnected with components \(S\) and \(\bar{S}\), then \(v = \mathbf{1}_S - \mathbf{1}_{\bar{S}}\) satisfies \(Lv = 0\), giving \(\lambda_2 = 0\).

Conversely, if \(\lambda_2 = 0\), the corresponding eigenvector is constant on connected components, implying disconnection.

The bound follows from the Courant-Fischer theorem and properties of the Rayleigh quotient.

Notation Guide

  • \(V\): Set of vertices (nodes)
  • \(E\): Set of edges
  • \(A\): Adjacency matrix
  • \(D\): Degree matrix (diagonal)
  • \(L = D - A\): Laplacian matrix
  • \(\lambda_2\): Fiedler value (algebraic connectivity)

# PageRank algorithm
def pagerank(G, alpha=0.85, max_iter=100, tol=1e-6):
    """
    Compute PageRank using power iteration.
    """
    n = G.number_of_nodes()
    M = nx.to_numpy_array(G, dtype=float)
    
    # Column-normalize
    out_degrees = M.sum(axis=0)
    out_degrees[out_degrees == 0] = 1  # Handle dangling nodes
    M = M / out_degrees
    
    # Power iteration
    v = np.ones(n) / n
    for _ in range(max_iter):
        v_new = alpha * M.dot(v) + (1 - alpha) / n
        if np.linalg.norm(v_new - v) < tol:
            break
        v = v_new
    
    return dict(zip(G.nodes(), v))

3. Optimal Transport: The Mathematics of Resource Allocation

Real-World Motivation

How do we efficiently move goods from suppliers to consumers? How do we compare probability distributions? Optimal transport theory, pioneered by Monge and Kantorovich, provides elegant solutions to these problems with applications in economics, machine learning (Wasserstein GANs), image processing, and physics.

Definitions

  • Transport Map: A measurable function \(T: X \to Y\) pushing measure \(\mu\) to \(\nu\), i.e., \(T_\#\mu = \nu\).
  • Monge Problem: Minimize \(\int_X c(x, T(x)) \, d\mu(x)\) over transport maps.
  • Kantorovich Relaxation: Minimize \(\int_{X \times Y} c(x, y) \, d\gamma(x, y)\) over couplings \(\gamma \in \Pi(\mu, \nu)\).
  • Wasserstein Distance: \(W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int d(x,y)^p \, d\gamma\right)^{1/p}\).

Theorem: Brenier's Theorem

Let \(\mu, \nu\) be probability measures on \(\mathbb{R}^n\) with \(\mu\) absolutely continuous with respect to Lebesgue measure. For the quadratic cost \(c(x, y) = \frac{1}{2}|x - y|^2\), there exists a unique optimal transport map \(T\) of the form:

\[T = \nabla \phi\]

where \(\phi: \mathbb{R}^n \to \mathbb{R}\) is a convex function. Moreover, \(T\) is the unique gradient of a convex function pushing \(\mu\) to \(\nu\).

Proof Sketch:

By Kantorovich duality, the optimal transport problem is equivalent to:

\[\sup_{\phi \text{ convex}} \int \phi \, d\mu + \int \phi^* \, d\nu\]

where \(\phi^*\) is the convex conjugate. The optimal coupling is concentrated on the graph of \(\nabla \phi\).

Uniqueness follows from the strict convexity of the cost function and the fact that gradients of convex functions are uniquely determined almost everywhere.

Notation Guide

  • \(\mu, \nu\): Probability measures
  • \(\Pi(\mu, \nu)\): Set of couplings (joint distributions with marginals \(\mu, \nu\))
  • \(T_\#\mu\): Pushforward measure
  • \(W_p\): p-Wasserstein distance
  • \(\nabla \phi\): Gradient of convex potential

def discrete_optimal_transport(mu, nu, C):
    """
    Solve discrete optimal transport using linear programming.
    
    Parameters:
    -----------
    mu : array of shape (m,) - source distribution
    nu : array of shape (n,) - target distribution
    C : array of shape (m, n) - cost matrix
    
    Returns:
    --------
    gamma : optimal coupling
    cost : optimal transport cost
    """
    m, n = len(mu), len(nu)
    
    # Flatten cost matrix
    c = C.flatten()
    
    # Equality constraints: marginals
    A_eq = np.zeros((m + n, m * n))
    
    # Row constraints (source)
    for i in range(m):
        A_eq[i, i*n:(i+1)*n] = 1
    
    # Column constraints (target)
    for j in range(n):
        for i in range(m):
            A_eq[m + j, i*n + j] = 1
    
    b_eq = np.concatenate([mu, nu])
    
    # Bounds: non-negative
    bounds = [(0, None) for _ in range(m * n)]
    
    # Solve
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    gamma = result.x.reshape(m, n)
    return gamma, result.fun

# Sinkhorn algorithm for entropic regularization
def sinkhorn(mu, nu, C, epsilon=0.1, max_iter=1000, tol=1e-6):
    """
    Sinkhorn-Knopp algorithm for entropic optimal transport.
    """
    K = np.exp(-C / epsilon)
    u = np.ones(len(mu))
    v = np.ones(len(nu))
    
    for _ in range(max_iter):
        u_prev = u
        u = mu / (K @ v)
        v = nu / (K.T @ u)
        
        if np.max(np.abs(u - u_prev)) < tol:
            break
    
    gamma = np.diag(u) @ K @ np.diag(v)
    cost = np.sum(gamma * C)
    return gamma, cost

1. The Riemann Hypothesis: The Crown Jewel of Mathematics

Historical Context

Bernhard Riemann proposed his famous hypothesis in 1859 as part of his paper "On the Number of Primes Less Than a Given Magnitude." He introduced the Riemann zeta function and conjectured that all its non-trivial zeros lie on the critical line \(\text{Re}(s) = \frac{1}{2}\). This remains one of the seven Millennium Prize Problems with a $1 million reward for its solution.

Definitions

  • Riemann Zeta Function: \(\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s}\) for \(\text{Re}(s) > 1\), analytically continued to \(\mathbb{C} \setminus \{1\}\).
  • Trivial Zeros: \(\zeta(-2n) = 0\) for \(n = 1, 2, 3, \ldots\)
  • Non-Trivial Zeros: Zeros in the critical strip \(0 < \text{Re}(s) < 1\).
  • Critical Line: The line \(\text{Re}(s) = \frac{1}{2}\) in the complex plane.

Theorem: The Prime Number Theorem

Let \(\pi(x)\) denote the number of primes less than or equal to \(x\). Then:

\[\pi(x) \sim \frac{x}{\log x}\]

Equivalently, \(\lim_{x \to \infty} \frac{\pi(x) \log x}{x} = 1\).

Proof Sketch:

The proof uses the Riemann zeta function and complex analysis. The key steps are:

  1. Relate \(\pi(x)\) to \(\psi(x) = \sum_{n \leq x} \Lambda(n)\) (Chebyshev function)
  2. Express \(\psi(x)\) via the explicit formula involving zeros of \(\zeta(s)\)
  3. Show that \(\psi(x) \sim x\) using the fact that \(\zeta(s) \neq 0\) for \(\text{Re}(s) = 1\)
  4. Convert back to \(\pi(x)\) via partial summation

The Riemann Hypothesis would give the optimal error term: \(|

  • \pi(x) - \text{Li}(x)| = O(\sqrt{x} \log x)\).

    • Notation Guide

    • \(\zeta(s)\): Riemann zeta function
    • \(\pi(x)\): Prime counting function
    • \(\text{Li}(x)\): Logarithmic integral \(\int_2^x \frac{dt}{\log t}\)
    • \(\Lambda(n)\): von Mangoldt function
    • \(\rho\): Non-trivial zero of \(\zeta(s)\)

    2. Category Theory: The Mathematics of Structure

    Historical Context

    Category theory was invented by Samuel Eilenberg and Saunders Mac Lane in 1945 to formalize the notion of "natural" transformations in algebraic topology. It has since grown into a unifying language for mathematics, revealing deep structural similarities across seemingly unrelated fields. It has also found applications in computer science (functional programming, type theory) and physics (topological quantum field theory).

    Definitions

    • Category \(\mathcal{C}\): Consists of objects \(\text{Ob}(\mathcal{C})\) and morphisms \(\text{Hom}(A, B)\) with composition and identity satisfying associativity and identity laws.
    • Functor: A structure-preserving map between categories, sending objects to objects and morphisms to morphisms.
    • Natural Transformation: A morphism between functors, satisfying a naturality condition.
    • Universal Property: A characterization of mathematical objects by their relationship to other objects, unique up to unique isomorphism.

    Theorem: Yoneda's Lemma

    Let \(\mathcal{C}\) be a locally small category, \(F: \mathcal{C}^{\text{op}} \to \mathbf{Set}\) a functor, and \(A \in \mathcal{C}\). Then:

    \[\text{Nat}(\text{Hom}(-, A), F) \cong F(A)\]

    naturally in both \(A\) and \(F\). In particular, objects are determined by their morphisms:

    \[\text{Hom}(-, A) \cong \text{Hom}(-, B) \implies A \cong B\]

    Proof:

    Given \(\alpha: \text{Hom}(-, A) \Rightarrow F\), define \(\Phi(\alpha) = \alpha_A(\text{id}_A) \in F(A)\).

    Given \(x \in F(A)\), define \(\Psi(x)_B: \text{Hom}(B, A) \to F(B)\) by \(f \mapsto F(f)(x)\).

    \(\Phi \circ \Psi = \text{id}\): For \(x \in F(A)\):

    \[\Phi(\Psi(x)) = \Psi(x)_A(\text{id}_A) = F(\text{id}_A)(x) = x\]

    \(\Psi \circ \Phi = \text{id}\): For \(\alpha: \text{Hom}(-, A) \Rightarrow F\) and \(f: B \to A\):

    \[\Psi(\Phi(\alpha))_B(f) = F(f)(\alpha_A(\text{id}_A)) = \alpha_B(\text{Hom}(f, A)(\text{id}_A)) = \alpha_B(f)\]

    where the middle equality uses naturality of \(\alpha\).

    Notation Guide

    • \(\mathcal{C}, \mathcal{D}\): Categories
    • \(\text{Ob}(\mathcal{C})\): Objects of category \(\mathcal{C}\)
    • \(\text{Hom}_{\mathcal{C}}(A, B)\): Morphisms from \(A\) to \(B\)
    • \(F: \mathcal{C} \to \mathcal{D}\): Functor
    • \(\alpha: F \Rightarrow G\): Natural transformation
    • \(\mathcal{C}^{\text{op}}\): Opposite category

    Historical Context

    In 1963, Michael Atiyah and Isadore Singer proved one of the most profound theorems in 20th-century mathematics. The index theorem connects the number of solutions to differential equations (analysis) with the topological structure of the underlying space. It generalizes classical results like the Riemann-Roch theorem and the Gauss-Bonnet theorem, and has become essential in modern physics, particularly string theory and gauge theory.

    Definitions

    • Elliptic Operator: A differential operator \(D\) whose principal symbol is invertible away from the zero section.
    • Index: \(\text{ind}(D) = \dim \ker D - \dim \text{coker} D = \dim \ker D - \dim \ker D^*\).
    • Chern Character: \(\text{ch}(E)\) — a characteristic class associated to a vector bundle.
    • Todd Class: \(\text{Td}(TM)\) — a characteristic class of the tangent bundle.

    Theorem: Atiyah-Singer Index Theorem

    Let \(D: \Gamma(E) \to \Gamma(F)\) be an elliptic differential operator between sections of vector bundles over a compact oriented manifold \(M\). Then:

    \[\text{ind}(D) = (-1)^{\dim M} \int_M \text{ch}(\sigma(D)) \wedge \text{Td}(TM \otimes \mathbb{C})\]

    where \(\sigma(D)\) is the symbol class in K-theory.

    Proof Strategy:

    The full proof is beyond our scope, but the key ideas are:

    1. Heat Kernel Method: Express the index using traces of heat operators:

    \[\text{ind}(D) = \text{Tr}(e^{-tD^*D}) - \text{Tr}(e^{-tDD^*})\]

    1. Asymptotic Expansion: As \(t \to 0\), the heat kernel has an expansion where the constant term gives a local formula for the index.
    2. K-Theory: The topological side is formulated in K-theory, making the index invariant under deformations.
    3. Cobordism Invariance: Show the formula is invariant under cobordism and verify on generators.

    Notation Guide

    • \(D\): Elliptic differential operator
    • \(\Gamma(E)\): Space of smooth sections of bundle \(E\)
    • \(\sigma(D)\): Principal symbol of \(D\)
    • \(\text{ch}(E)\): Chern character
    • \(\text{Td}(E)\): Todd class
    • \(K(M)\): K-theory of \(M\)

    Historical Context

    Mirror symmetry emerged from string theory in the late 1980s when physicists discovered that Calabi-Yau manifolds come in pairs where complex geometry on one side corresponds to symplectic geometry on the other. This led to spectacular mathematical predictions, including the computation of curve-counting invariants (Gromov-Witten invariants) that had eluded mathematicians. The field has since developed into a rich area connecting algebraic geometry, symplectic geometry, and theoretical physics.

    Definitions

    • Calabi-Yau Manifold: A compact Kähler manifold with trivial canonical bundle and vanishing first Chern class.
    • Hodge Numbers: \(h^{p,q} = \dim H^{p,q}(X)\), satisfying \(h^{p,q}(X) = h^{n-p,n-q}(\tilde{X})\) for mirror pairs.
    • Gromov-Witten Invariants: Counts of holomorphic curves in a manifold, related to periods on the mirror.
    • Period Integrals: \(\Pi_i = \int_{\gamma_i} \Omega\) where \(\Omega\) is the holomorphic volume form.

    Theorem: Mirror Symmetry (Hodge Diamond Flip)

    For a mirror pair of Calabi-Yau threefolds \((X, \tilde{X})\):

    \[h^{p,q}(X) = h^{3-p,q}(\tilde{X})\]

    In particular, the Hodge diamonds are related by a 90° rotation:

    \[ \begin{array}{ccccccc} & & & h^{0,0} & & & \\ & & h^{1,0} & & h^{0,1} & & \\ & h^{2,0} & & h^{1,1} & & h^{0,2} & \\ h^{3,0} & & h^{2,1} & & h^{1,2} & & h^{0,3} \\ & h^{3,1} & & h^{2,2} & & h^{1,3} & \\ & & h^{3,2} & & h^{2,3} & & \\ & & & h^{3,3} & & & \\ \end{array} \longleftrightarrow \begin{array}{ccccccc} & & & h^{0,0} & & & \\ & & h^{2,0} & & h^{2,1} & & \\ & h^{1,0} & & h^{1,1} & & h^{1,2} & \\ h^{0,0} & & h^{0,1} & & h^{0,2} & & h^{0,3} \\ & h^{0,1} & & h^{0,2} & & h^{0,3} & \\ & & h^{0,2} & & h^{0,3} & & \\ & & & h^{0,3} & & & \\ \end{array} \]

    • Complex moduli \(\leftrightarrow\) Kähler moduli
    • Period integrals \(\leftrightarrow\) Gromov-Witten invariants

    📜 Math History: The Birth of Modern Analysis

    The 19th century witnessed a profound transformation in mathematics, as the intuitive methods of calculus gave way to the rigorous foundations of modern analysis. This revolution was driven by mathematicians who recognized that the powerful techniques developed by Newton and Leibniz rested on shaky logical ground.

    Bernhard Bolzano (1781–1848) was among the first to identify the need for rigor. In 1817, he proved what we now call the Intermediate Value Theorem, not by appealing to geometric intuition, but by constructing a proof that would be valid even if we couldn't visualize the curve. His work on infinite sets and the concept of a limit laid groundwork that would only be appreciated decades later.

    Augustin-Louis Cauchy (1789–1857) transformed the teaching and practice of analysis. His textbooks established the epsilon-delta definitions of limits and continuity that remain standard today. Cauchy's insistence on rigorous proofs revealed paradoxes in earlier work—most famously, his "proof" that the limit of continuous functions is continuous, which was later shown to require uniform convergence.

    The true arithmetization of analysis, however, was achieved by Karl Weierstrass (1815–1897). Weierstrass constructed pathological functions that challenged mathematical intuition—functions continuous everywhere but differentiable nowhere. These examples demonstrated that geometric intuition could not be trusted, and that analysis must be built solely on the properties of real numbers.

    Weierstrass's program was completed by Richard Dedekind (1831–1916) and Georg Cantor (1845–1918), who provided rigorous constructions of the real numbers. Dedekind's "cuts" defined real numbers in terms of sets of rationals, while Cantor's Cauchy sequences provided an equivalent foundation. Cantor's subsequent work on set theory and the infinite opened new mathematical horizons while also revealing deep foundational questions.

    This period of rigor was not merely about pedantry—it enabled the development of modern mathematics. The precise definitions of convergence allowed for the creation of function spaces, functional analysis, and measure theory. The careful treatment of infinity led to set theory and the foundations of mathematics. What began as a quest to shore up calculus became the foundation of modern mathematical practice.

    Putnam 2024 Problem A6

    Let \(n\) be a positive integer. A sequence \((a_1, a_2, \ldots, a_n)\) of integers is called good if:

    1. \(1 \leq a_k \leq k\) for each \(k = 1, 2, \ldots, n\)
    2. The sum \(a_1 + a_2 + \cdots + a_n\) is even

    Let \(f(n)\) denote the number of good sequences. Find a closed-form expression for \(f(n)\).

    Hint

    Consider the generating function approach. First count all sequences satisfying condition (1), then use the fact that exactly half of them have even sum (with a small correction for small cases). Alternatively, find a recurrence relation by considering the last term.

    Solution

    Solution: We claim that \(f(n) = \frac{n! + 1}{2}\) for \(n \geq 1\).

    Step 1: Count all sequences satisfying condition (1).

    For each \(k\), there are exactly \(k\) choices for \(a_k\). So the total number of sequences satisfying (1) is:

    \[T(n) = 1 \cdot 2 \cdot 3 \cdots n = n!\]

    Step 2: Among these sequences, count those with even sum.

    Let \(E(n)\) be the number with even sum and \(O(n)\) be the number with odd sum. We have \(E(n) + O(n) = n!\).

    Consider the involution that flips the parity of \(a_n\): if \(a_n = k\), map to \(a_n' = k+1\) if \(k < n\), and to \(1\) if \(k = n\). This almost gives a bijection between even and odd sum sequences.

    More directly, we use generating functions. The generating function for the parity of sums is:

    \[\prod_{k=1}^{n} (x + x^2 + \cdots + x^k) = \prod_{k=1}^{n} x \cdot \frac{1-x^k}{1-x}\]

    Evaluating at \(x = 1\) and \(x = -1\):

    \[E(n) - O(n) = \prod_{k=1}^{n} (-1) \cdot \frac{1-(-1)^k}{1-(-1)} = \prod_{k=1}^{n} (-1) \cdot \frac{1-(-1)^k}{2}\]

    For even \(k\): factor equals \((-1) \cdot 0 = 0\)? No wait, let me reconsider.

    Actually, use a cleaner approach. Define:

    \[g(x) = \prod_{k=1}^{n} (1 + x + x^2 + \cdots + x^{k-1}) = \prod_{k=1}^{n} \frac{1-x^k}{1-x}\]

    Then \(E(n) = \frac{g(1) + g(-1)}{2}\) and \(O(n) = \frac{g(1) - g(-1)}{2}\).

    We have \(g(1) = n!\) (by continuity, or using L'Hôpital's rule).

    For \(g(-1)\):

    \[g(-1) = \prod_{k=1}^{n} \frac{1-(-1)^k}{2}\]

    When \(k\) is even: \(\frac{1-1}{2} = 0\)? No, that's wrong too. Let me be more careful.

    For even \(k = 2m\): numerator is \(1 - 1 = 0\). So \(g(-1) = 0\) for \(n \geq 2\)?

    Actually, I need to reconsider. The sum \(1 + x + \cdots + x^{k-1}\) at \(x = -1\) equals:

    • If \(k\) is odd: \(1 - 1 + 1 - \cdots + 1 = 1\)
    • If \(k\) is even: \(1 - 1 + 1 - \cdots - 1 = 0\)

    So for \(n \geq 2\), since we include \(k = 2\), we get \(g(-1) = 0\).

    Therefore \(E(n) = O(n) = \frac{n!}{2}\) for \(n \geq 2\).

    But wait, this gives non-integer for odd \(n\)! Let me recheck.

    Actually, the issue is that \(a_k\) ranges from \(1\) to \(k\), not \(0\) to \(k-1\). So the generating function is:

    \[h(x) = \prod_{k=1}^{n} (x + x^2 + \cdots + x^k) = x^n \prod_{k=1}^{n} \frac{1-x^k}{1-x}\]

    Then \(h(1) = n!\) and:

    \[h(-1) = (-1)^n \prod_{k=1}^{n} \frac{1-(-1)^k}{2}\]

    For \(k = 1\): \(\frac{1-(-1)}{2} = 1\)

    For \(k = 2\): \(\frac{1-1}{2} = 0\)

    So \(h(-1) = 0\) for \(n \geq 2\), meaning \(E(n) = O(n) = n!/2\).

    But this must be wrong because \(n!\) is odd when \(n = 1\). Let me check small cases:

    Verification:

    • \(n = 1\): Only sequence is \((1)\), sum = 1 (odd). So \(f(1) = 0\).
    • \(n = 2\): Sequences are \((1,1), (1,2), (2,1), (2,2)\). Sums: 2, 3, 3, 4. Even sums: 2, 4. So \(f(2) = 2\).

    My formula gives \(f(2) = 2!/2 = 1\), which is wrong!

    Let me recalculate. The generating function approach needs care. The correct answer is:

    \[f(n) = \left\lfloor \frac{n! + 1}{2} \right\rfloor\]

    Or equivalently: \(f(n) = \frac{n!}{2}\) for \(n \geq 2\) even, and \(f(n) = \frac{n!+1}{2}\) for \(n \geq 1\).

    Actually, checking: \(f(2) = 2\), and \((2!+1)/2 = 1.5\)... Let me recheck my enumeration.

    For \(n = 2\): \(a_1 \in \{1\}\), \(a_2 \in \{1, 2\}\).

    Sequences: \((1, 1)\) sum=2 (even) ✓, \((1, 2)\) sum=3 (odd) ✗

    So \(f(2) = 1\), not 2! My enumeration was wrong.

def hopf_map(p):
    """
    Hopf map S³ → S².
    Input: point p = (z1, z2) on S³ ⊂ ℂ², i.e., |z1|² + |z2|² = 1
    Output: point on S² ⊂ ℝ³
    """
    z1, z2 = p
    x1, y1 = z1.real, z1.imag
    x2, y2 = z2.real, z2.imag
    
    # Stereographic projection to R³ followed by Hopf map
    # Standard formula: (2Re(z1*conj(z2)), 2Im(z1*conj(z2)), |z1|² - |z2|²)
    w = z1 * np.conj(z2)
    X = 2 * w.real
    Y = 2 * w.imag
    Z = np.abs(z1)**2 - np.abs(z2)**2
    
    return np.array([X, Y, Z])

def hopf_fiber(theta, phi, t_values):
    """
    Generate points on a Hopf fiber.
    The fiber over (theta, phi) on S² is a circle in S³.
    """
    # Point on S²
    x = np.sin(theta) * np.cos(phi)
    y = np.sin(theta) * np.sin(phi)
    z = np.cos(theta)
    
    # Preimage under Hopf map is a circle
    # Parameterize the fiber
    sqrt_1_plus_z = np.sqrt((1 + z) / 2)
    sqrt_1_minus_z = np.sqrt((1 - z) / 2)
    
    fibers = []
    for t in t_values:
        # Points on the fiber circle
        z1 = sqrt_1_plus_z * np.exp(1j * (phi + t))
        z2 = sqrt_1_minus_z * np.exp(1j * t)
        
        # Stereographic projection from S³ to R³
        # (project from (0, 0, 0, 1))
        denom = 1 - z2.imag
        if abs(denom) > 1e-10:
            x3d = z1.real / denom
            y3d = z1.imag / denom
            z3d = z2.real / denom
            fibers.append([x3d, y3d, z3d])
    
    return np.array(fibers)

def stereographic_projection_s3(z1, z2):
    """
    Stereographic projection from S³ to R³.
    Project from (0, 0, 0, 1).
    """
    x1, y1 = z1.real, z1.imag
    x2, y2 = z2.real, z2.imag
    
    # S³: x1² + y1² + x2² + y2² = 1
    # Project from (0,0,0,1), i.e., where y2 = 1
    denom = 1 - y2
    if abs(denom) < 1e-10:
        return None
    
    X = x1 / denom
    Y = y1 / denom
    Z = x2 / denom
    
    return np.array([X, Y, Z])

def generate_hopf_fibers(n_fibers=10, n_points=100):
    """
    Generate multiple Hopf fibers for visualization.
    """
    t_values = np.linspace(0, 2*np.pi, n_points)
    all_fibers = []
    colors = []
    
    # Generate fibers over points on S²
    theta_values = np.linspace(0.1, np.pi - 0.1, n_fibers)
    phi_values = np.linspace(0, 2*np.pi, n_fibers, endpoint=False)
    
    color_map = plt.cm.hsv
    
    for i, theta in enumerate(theta_values):
        for j, phi in enumerate(phi_values):
            fiber = hopf_fiber(theta, phi, t_values)
            if len(fiber) > 0:
                all_fibers.append(fiber)
                colors.append(color_map((i * n_fibers + j) / (n_fibers**2)))
    
    return all_fibers, colors
