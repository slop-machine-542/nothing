Spectral Sequences: Computing the Uncomputable

spectral-sequences

Motivation

Many important invariants in algebraic topology, such as homotopy groups and certain cohomology rings, are notoriously difficult to compute directly. Spectral sequences provide a systematic framework for approximating these invariants through successive approximations. First introduced by Jean Leray in the 1940s, they have become indispensable tools in algebraic topology, algebraic geometry, and homological algebra.

Definitions

  • Filtered Complex: A chain complex \(C_*\) with subcomplexes \(F^pC_*\) such that \(F^{p+1}C_* \subseteq F^pC_*\).
  • Spectral Sequence: A sequence of bigraded differential modules \((E_r^{p,q}, d_r)\) where \(d_r: E_r^{p,q} \to E_r^{p+r, q-r+1}\) satisfies \(d_r^2 = 0\), and \(E_{r+1} = H(E_r, d_r)\).
  • Convergence: A spectral sequence converges to \(H^*\) if there exists a filtration on \(H^*\) such that \(E_\infty^{p,q} \cong F^pH^{p+q}/F^{p+1}H^{p+q}\).
  • First Quadrant: A spectral sequence with \(E_r^{p,q} = 0\) for \(p < 0\) or \(q < 0\).

Theorem: The Leray-Serre Spectral Sequence

Theorem: Let \(F \to E \xrightarrow{\pi} B\) be a fibration with \(B\) path-connected and \(\pi_1(B)\) acting trivially on \(H^*(F; R)\). Then there exists a first-quadrant cohomology spectral sequence with:

\[E_2^{p,q} = H^p(B; H^q(F; R)) \Rightarrow H^{p+q}(E; R)\]

The differential \(d_r\) has bidegree \((r, 1-r)\). If the coefficient ring \(R\) is a field, then \(E_2^{p,q} = H^p(B; R) \otimes_R H^q(F; R)\).

Proof Sketch

The proof constructs a filtration on the singular cochain complex \(C^*(E)\). For each \(p\), define:

\[F^pC^n(E) = \{\alpha \in C^n(E) : \alpha(\sigma) = 0 \text{ for all } \sigma: \Delta^n \to E \text{ with } \pi \circ \sigma(\Delta^{(p)}) \neq *\}\]

where \(\Delta^{(p)}\) is the \(p\)-skeleton. This filtration induces a spectral sequence via the standard construction. The \(E_2\) page is identified using the local coefficient system determined by the fibration. The trivial action of \(\pi_1(B)\) ensures the coefficients are constant.

Notation Guide

  • \(E_r^{p,q}\): The term at page \(r\), position \((p,q)\)
  • \(d_r\): Differential on page \(r\)
  • \(F^p\): Filtration degree \(p\)
  • \(\Rightarrow\): Converges to
  • \(H^p(B; \mathcal{L})\): Cohomology with local coefficients

import numpy as np
from typing import List, Tuple, Optional

class SpectralSequence:
    """
    Simplified model of a spectral sequence for educational purposes.
    """
    
    def __init__(self, E2_page: np.ndarray, max_page: int = 5):
        """
        Initialize with E2 page (p,q) grid.
        E2_page[p, q] gives the dimension of E2^{p,q}.
        """
        self.E = {2: E2_page.copy()}
        self.differentials = {}
        self.max_page = max_page
        self.dimensions = E2_page.shape
    
    def compute_differential(self, r: int, p: int, q: int) -> Optional[np.ndarray]:
        """
        Compute differential d_r: E_r^{p,q} -> E_r^{p+r, q-r+1}.
        Returns matrix representation or None if target is zero.
        """
        target_p, target_q = p + r, q - r + 1
        
        # Check bounds
        if target_p >= self.dimensions[0] or target_q < 0:
            return None
        
        source_dim = int(self.E[r][p, q])
        target_dim = int(self.E[r][target_p, target_q])
        
        if source_dim == 0 or target_dim == 0:
            return None
        
        # Simplified: random differential for demonstration
        # In practice, this would be computed from geometry
        np.random.seed(p * 1000 + q * 100 + r)
        d = np.random.randn(target_dim, source_dim) * 0.1
        
        return d
    
    def compute_page(self, r: int):
        """Compute E_{r+1} from E_r using the differential d_r."""
        if r in self.E and r + 1 in self.E:
            return  # Already computed
        
        if r not in self.E:
            self.compute_page(r - 1)
        
        E_r = self.E[r]
        E_next = np.zeros_like(E_r)
        
        max_p, max_q = self.dimensions
        
        for p in range(max_p):
            for q in range(max_q):
                if E_r[p, q] == 0:
                    continue
                
                # Compute d_r incoming and outgoing
                d_out = self.compute_differential(r, p, q)
                d_in = self.compute_differential(r, p - r, q + r - 1)
                
                # Simplified: dimension of homology
                # H = ker(d_out) / im(d_in)
                if d_out is None:
                    ker_dim = int(E_r[p, q])
                else:
                    ker_dim = max(0, int(E_r[p, q]) - np.linalg.matrix_rank(d_out))
                
                if d_in is not None:
                    im_dim = np.linalg.matrix_rank(d_in)
                    ker_dim = max(0, ker_dim - im_dim)
                
                E_next[p, q] = ker_dim
        
        self.E[r + 1] = E_next
    
    def converge(self):
        """Compute pages until convergence or max_page."""
        for r in range(2, self.max_page):
            self.compute_page(r)
            
            # Check for convergence
            if np.array_equal(self.E[r], self.E.get(r + 1, self.E[r])):
                print(f"Converged at page E_{r}")
                break
    
    def print_page(self, r: int):
        """Print the E_r page."""
        print(f"\nE_{r} page:")
        print(self.E.get(r, f"Page {r} not computed"))

Morse Theory: Topology Through Critical Points

morse-theory

Motivation

Morse theory provides a profound connection between the critical points of smooth functions on a manifold and the topology of that manifold. Developed by Marston Morse in the 1920s, it shows that the shape of a space can be understood by studying how smooth functions behave on it. This has applications ranging from the study of geodesics to the proof of the h-cobordism theorem and the classification of manifolds.

Definitions

  • Critical Point: For \(f: M \to \mathbb{R}\), a point \(p\) where \(df_p = 0\).
  • Hessian: At a critical point \(p\), the Hessian \(H_f(p)\) is the symmetric bilinear form on \(T_pM\) given by \(H_f(p)(X, Y) = X(Y(f))\).
  • Non-degenerate Critical Point: A critical point where the Hessian is non-singular.
  • Morse Index: The number of negative eigenvalues of the Hessian at a non-degenerate critical point.
  • Morse Function: A smooth function where all critical points are non-degenerate.

Theorem: The Morse Lemma

Theorem (Morse Lemma): Let \(f: M \to \mathbb{R}\) be smooth and \(p\) a non-degenerate critical point with Morse index \(\lambda\). Then there exist local coordinates \((x_1, \ldots, x_n)\) around \(p\) with \(x_i(p) = 0\) such that:

\[f(x) = f(p) - x_1^2 - \cdots - x_\lambda^2 + x_{\lambda+1}^2 + \cdots + x_n^2\]

In particular, non-degenerate critical points are isolated.

Proof Sketch

The proof uses the fundamental theorem of calculus twice. First, write:

\[f(x) - f(p) = \sum_i x_i g_i(x)\]

where \(g_i(x) = \int_0^1 \frac{\partial f}{\partial x_i}(tx) dt\). Since \(p\) is critical, \(g_i(0) = 0\), so we can write:

\[g_i(x) = \sum_j x_j h_{ij}(x)\]

giving \(f(x) - f(p) = \sum_{i,j} x_i x_j h_{ij}(x)\). The matrix \(h_{ij}(0)\) is the Hessian. By non-degeneracy and the spectral theorem, we can diagonalize, obtaining the desired form.

Theorem: The Fundamental Theorem of Morse Theory

Theorem: Let \(f: M \to \mathbb{R}\) be smooth and \(M^a = f^{-1}((-\infty, a])\). If \(f^{-1}([a, b])\) is compact and contains no critical points, then \(M^a\) is diffeomorphic to \(M^b\).

If \(f^{-1}([a, b])\) contains exactly one critical point of index \(\lambda\), then \(M^b\) is homotopy equivalent to \(M^a\) with a \(\lambda\)-cell attached.

Notation Guide

  • \(M^n\): Smooth manifold of dimension \(n\)
  • \(df_p\): Differential of \(f\) at \(p\)
  • \(H_f(p)\): Hessian of \(f\) at \(p\)
  • \(\lambda(p)\): Morse index of critical point \(p\)
  • \(M^a\): Sublevel set \(\{x \in M : f(x) \leq a\}\)
  • \(e^\lambda\): \(\lambda\)-dimensional cell (disk)

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize
from typing import List, Tuple, Callable

class MorseTheory:
    """
    Computational tools for Morse theory on manifolds.
    """
    
    @staticmethod
    def gradient(f: Callable, x: np.ndarray, eps: float = 1e-6) -> np.ndarray:
        """Numerical gradient of f at x."""
        n = len(x)
        grad = np.zeros(n)
        for i in range(n):
            x_plus = x.copy()
            x_minus = x.copy()
            x_plus[i] += eps
            x_minus[i] -= eps
            grad[i] = (f(x_plus) - f(x_minus)) / (2 * eps)
        return grad
    
    @staticmethod
    def hessian(f: Callable, x: np.ndarray, eps: float = 1e-5) -> np.ndarray:
        """Numerical Hessian of f at x."""
        n = len(x)
        hess = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                x_pp = x.copy()
                x_pm = x.copy()
                x_mp = x.copy()
                x_mm = x.copy()
                
                x_pp[i] += eps; x_pp[j] += eps
                x_pm[i] += eps; x_pm[j] -= eps
                x_mp[i] -= eps; x_mp[j] += eps
                x_mm[i] -= eps; x_mm[j] -= eps
                
                hess[i, j] = (f(x_pp) - f(x_pm) - f(x_mp) + f(x_mm)) / (4 * eps**2)
        return hess
    
    @staticmethod
    def find_critical_points(f: Callable, bounds: List[Tuple], 
                             grid_points: int = 20) -> List[np.ndarray]:
        """
        Find approximate critical points by grid search + refinement.
        """
        critical = []
        
        # Create grid
        ranges = [np.linspace(b[0], b[1], grid_points) for b in bounds]
        
        # Grid search for approximate critical points
        for x in ranges[0]:
            for y in ranges[1]:
                point = np.array([x, y])
                grad = MorseTheory.gradient(f, point)
                if np.linalg.norm(grad) < 0.1:
                    # Refine with Newton's method
                    result = minimize(lambda p: np.linalg.norm(
                        MorseTheory.gradient(f, p))**2, 
                        point, method='BFGS')
                    if result.success and np.linalg.norm(
                        MorseTheory.gradient(f, result.x)) < 1e-4:
                        critical.append(result.x)
        
        # Remove duplicates
        unique = []
        for c in critical:
            if not any(np.linalg.norm(c - u) < 0.01 for u in unique):
                unique.append(c)
        
        return unique
    
    @staticmethod
    def morse_index(f: Callable, x: np.ndarray) -> int:
        """Compute Morse index at critical point x."""
        H = MorseTheory.hessian(f, x)
        eigenvalues = np.linalg.eigvalsh(H)
        return np.sum(eigenvalues < -1e-6)
    
    @staticmethod
    def morse_polynomial(critical_points: List[np.ndarray], 
                         f: Callable) -> str:
        """
        Compute the Morse polynomial: M_t(f) = Σ t^{index(p)}.
        """
        indices = [MorseTheory.morse_index(f, p) for p in critical_points]
        from collections import Counter
        counts = Counter(indices)
        
        terms = []
        for idx in sorted(counts.keys()):
            if counts[idx] == 1:
                terms.append(f"t^{idx}")
            else:
                terms.append(f"{counts[idx]}t^{idx}")
        
        return " + ".join(terms)

Characteristic Classes: Measuring Obstructions

characteristic-classes

Motivation

Characteristic classes are cohomological invariants of vector bundles that measure how "twisted" the bundle is. They answer fundamental questions: When does a manifold admit a nowhere-vanishing vector field? When is a bundle trivial? First developed by Stiefel, Whitney, Pontryagin, and Chern, these classes have become essential tools in differential topology, algebraic geometry, and mathematical physics.

Definitions

  • Vector Bundle: A map \(\pi: E \to B\) where each fiber \(E_b = \pi^{-1}(b)\) has the structure of a vector space, locally trivial.
  • Chern Classes: For a complex vector bundle \(E \to M\), classes \(c_i(E) \in H^{2i}(M; \mathbb{Z})\) with \(c_0(E) = 1\).
  • Pontryagin Classes: For a real vector bundle, \(p_i(E) = (-1)^i c_{2i}(E \otimes \mathbb{C}) \in H^{4i}(M; \mathbb{Z})\).
  • Euler Class: For an oriented real rank \(2k\) bundle, \(e(E) \in H^{2k}(M; \mathbb{Z})\).
  • Total Chern Class: \(c(E) = 1 + c_1(E) + c_2(E) + \cdots\).

Theorem: Properties of Chern Classes

Theorem: Chern classes satisfy the following axioms:

  1. Naturality: For \(f: N \to M\), \(c(f^*E) = f^*c(E)\)
  2. Whitney Sum: \(c(E \oplus F) = c(E) \smile c(F)\)
  3. Normalization: For the tautological line bundle \(\gamma^1\) over \(\mathbb{C}P^1\), \(c_1(\gamma^1) = -\alpha\) where \(\alpha\) generates \(H^2(\mathbb{C}P^1; \mathbb{Z})\)

Moreover, these axioms uniquely determine Chern classes for all complex vector bundles.

Theorem: The Splitting Principle

Theorem (Splitting Principle): For any complex vector bundle \(E \to M\) of rank \(n\), there exists a space \(F(E)\) (the flag bundle) and a map \(p: F(E) \to M\) such that:

  1. \(p^*: H^*(M) \to H^*(F(E))\) is injective
  2. \(p^*E = L_1 \oplus \cdots \oplus L_n\) splits as a sum of line bundles

Consequently, \(c(E) = \prod_{i=1}^n (1 + x_i)\) where \(x_i = c_1(L_i)\).

Proof Sketch

The splitting principle is proved by iterating the projectivization construction. Given \(E\), form \(\mathbb{P}(E)\) with tautological line bundle \(S \subset \pi^*E\). This gives a quotient bundle \(Q = \pi^*E/S\) of rank \(n-1\). Repeat until the bundle splits completely. The injectivity follows from the Leray-Hirsch theorem.

Notation Guide

  • \(c_i(E)\): \(i\)-th Chern class of \(E\)
  • \(p_i(E)\): \(i\)-th Pontryagin class
  • \(e(E)\): Euler class
  • \(\gamma^n\): Tautological bundle over \(G_n(\mathbb{C}^\infty)\)
  • \(\mathbb{P}(E)\): Projectivization of bundle \(E\)

Python Implementation

import numpy as np
from typing import List, Tuple
from itertools import combinations

class CharacteristicClasses:
    """
    Computational tools for characteristic classes.
    """
    
    @staticmethod
    def chern_class_from_curvature(F: np.ndarray, k: int) -> complex:
        """
        Compute k-th Chern form from curvature matrix F.
        F is an n×n matrix of 2-forms (represented as complex numbers here).
        
        c_k(E) = (i/2π)^k * σ_k(F)
        where σ_k is the k-th elementary symmetric polynomial.
        """
        n = F.shape[0]
        
        # Compute elementary symmetric polynomial
        eigenvalues = np.linalg.eigvals(F)
        
        # σ_k = sum of all k-fold products
        if k == 0:
            return 1.0
        
        sigma_k = 0
        for combo in combinations(range(n), k):
            product = 1
            for i in combo:
                product *= eigenvalues[i]
            sigma_k += product
        
        coefficient = (1j / (2 * np.pi))**k
        return coefficient * sigma_k
    
    @staticmethod
    def total_chern_class(ranks: List[int], 
                          formal_roots: List[List[complex]]) -> List[complex]:
        """
        Compute total Chern class using splitting principle.
        
        Args:
            ranks: List of bundle ranks
            formal_roots: List of lists of formal roots (1st Chern classes of line bundles)
        
        Returns:
            List of Chern classes [c_0, c_1, ..., c_n]
        """
        result = [1]  # c_0 = 1
        
        for rank, roots in zip(ranks, formal_roots):
            # c(E) = ∏(1 + x_i) where x_i are formal roots
            new_result = result.copy()
            
            for k in range(1, rank + 1):
                # c_k contribution from this bundle
                c_k = 0
                for combo in combinations(range(len(roots)), k):
                    product = 1
                    for i in combo:
                        product *= roots[i]
                    c_k += product
                
                # Add to result using Whitney sum formula
                for j in range(len(result) - 1, -1, -1):
                    idx = j + k
                    if idx < len(new_result):
                        new_result[idx] += result[j] * c_k
                    elif idx == len(new_result):
                        new_result.append(result[j] * c_k)
            
            result = new_result
        
        return result
    
    @staticmethod
    def pontryagin_class_from_chern(c_classes: List[complex]) -> List[complex]:
        """
        Compute Pontryagin classes from Chern classes.
        p_k(E) = (-1)^k * c_{2k}(E ⊗ C)
        """
        p_classes = [1]  # p_0 = 1
        
        for k in range(1, len(c_classes) // 2 + 1):
            if 2 * k < len(c_classes):
                p_k = (-1)**k * c_classes[2 * k]
                p_classes.append(p_k)
        
        return p_classes
    
    @staticmethod
    def euler_class_from_pontryagin(p_classes: List[complex], 
                                    rank: int) -> complex:
        """
        Compute Euler class for oriented real bundle.
        For rank 2k: e(E)^2 = p_k(E)
        """
        if rank % 2 != 0:
            return 0  # Euler class vanishes for odd rank
        
        k = rank // 2
        if k < len(p_classes):
            # e(E) = ±√p_k(E)
            return np.sqrt(p_classes[k])
        return 0
    
    @staticmethod
    def chern_character(c_classes: List[complex]) -> List[complex]:
        """
        Compute Chern character from Chern classes.
        ch(E) = rank + c_1 + (c_1^2 - 2c_2)/2 + ...
        """
        if len(c_classes) <= 1:
            return c_classes.copy()
        
        rank = 1  # Assuming we start with normalized classes
        ch = [rank, c_classes[1]] if len(c_classes) > 1 else [rank]
        
        if len(c_classes) > 2:
            # ch_2 = (c_1^2 - 2c_2)/2
            ch_2 = (c_classes[1]**2 - 2 * c_classes[2]) / 2
            ch.append(ch_2)
        
        return ch

Partial Differential Equations: The Heat Equation and Maximum Principles

partial-differential-equations

Real-World Context

The heat equation models how temperature distributes in a medium over time, but its applications extend far beyond thermodynamics. It describes diffusion processes in finance (Black-Scholes), image processing (Gaussian smoothing), and even the evolution of genetic traits in populations. Understanding its properties provides insight into the behavior of parabolic PDEs more generally.

Definitions

  • Heat Equation: \(u_t = \Delta u = \sum_{i=1}^n \frac{\partial^2 u}{\partial x_i^2}\) on \(\Omega \times [0, T]\).
  • Parabolic Cylinder: The domain \(Q_T = \Omega \times (0, T]\) with parabolic boundary \(\partial_p Q_T = (\partial\Omega \times [0, T]) \cup (\Omega \times \{0\})\).
  • Classical Solution: A function \(u \in C^{2,1}(Q_T) \cap C(\overline{Q_T})\) satisfying the equation.
  • Fundamental Solution: \(\Phi(x, t) = (4\pi t)^{-n/2} e^{-|x|^2/(4t)}\) for \(t > 0\).

Theorem: The Maximum Principle

Theorem (Weak Maximum Principle): Let \(u\) be a classical solution of \(u_t = \Delta u\) in \(Q_T\). Then:

\[\max_{\overline{Q_T}} u = \max_{\partial_p Q_T} u\]

That is, the maximum temperature occurs either initially or on the boundary.

Strong Maximum Principle: If \(u\) attains its maximum at an interior point \((x_0, t_0)\) with \(t_0 > 0\), then \(u\) is constant on \(\overline{Q_{t_0}}\).

Proof Sketch

For the weak principle, consider \(v = u + \epsilon|x|^2\). At an interior maximum, \(v_t \geq 0\) and \(\Delta v \leq 0\), but \(v_t - \Delta v = u_t - \Delta u - 2n\epsilon = -2n\epsilon < 0\), a contradiction. Taking \(\epsilon \to 0\) gives the result.

The strong principle uses the mean value property for the heat equation: solutions satisfy an averaging property over heat balls.

Theorem: Uniqueness and Stability

Theorem: The initial-boundary value problem:

\[\begin{cases} u_t = \Delta u & \text{in } Q_T \\ u = g & \text{on } \partial\Omega \times [0, T] \\ u = h & \text{on } \Omega \times \{0\} \end{cases}\]

has at most one classical solution. Moreover, if \(u_1, u_2\) are solutions with data \((g_1, h_1)\) and \((g_2, h_2)\), then:

\[\max_{\overline{Q_T}} |u_1 - u_2| \leq \max\{\|g_1 - g_2\|_\infty, \|h_1 - h_2\|_\infty\}\]

Notation Guide

  • \(u_t = \partial u / \partial t\): Time derivative
  • \(\Delta\): Laplacian operator
  • \(Q_T\): Parabolic cylinder \(\Omega \times (0, T]\)
  • \(\partial_p Q_T\): Parabolic boundary
  • \(C^{2,1}\): Twice differentiable in space, once in time

import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import diags, kron, eye
from scipy.sparse.linalg import spsolve

class HeatEquationSolver:
    """
    Numerical solution of the heat equation using finite differences.
    """
    
    def __init__(self, L: float, T: float, nx: int, nt: int):
        """
        Initialize solver for [0, L] × [0, T].
        """
        self.L = L
        self.T = T
        self.nx = nx
        self.nt = nt
        
        self.dx = L / (nx - 1)
        self.dt = T / (nt - 1)
        self.x = np.linspace(0, L, nx)
        self.t = np.linspace(0, T, nt)
        
        # Stability parameter (should be <= 0.5 for explicit scheme)
        self.r = self.dt / (self.dx ** 2)
    
    def solve_explicit(self, u0: callable, 
                       bc_left: callable, bc_right: callable) -> np.ndarray:
        """
        Solve using explicit (forward Euler) scheme.
        u_j^{n+1} = u_j^n + r * (u_{j+1}^n - 2u_j^n + u_{j-1}^n)
        """
        if self.r > 0.5:
            print(f"Warning: r = {self.r:.3f} > 0.5, scheme may be unstable")
        
        u = np.zeros((self.nt, self.nx))
        
        # Initial condition
        u[0, :] = u0(self.x)
        
        # Time stepping
        for n in range(self.nt - 1):
            # Boundary conditions
            u[n, 0] = bc_left(self.t[n])
            u[n, -1] = bc_right(self.t[n])
            
            # Interior points
            for j in range(1, self.nx - 1):
                u[n+1, j] = u[n, j] + self.r * (
                    u[n, j+1] - 2*u[n, j] + u[n, j-1]
                )
            
            # Apply BC at new time level
            u[n+1, 0] = bc_left(self.t[n+1])
            u[n+1, -1] = bc_right(self.t[n+1])
        
        return u
    
    def solve_implicit(self, u0: callable,
                       bc_left: callable, bc_right: callable) -> np.ndarray:
        """
        Solve using implicit (backward Euler) scheme.
        Unconditionally stable.
        """
        u = np.zeros((self.nt, self.nx))
        
        # Initial condition
        u[0, :] = u0(self.x)
        
        # Build system matrix: (I + r*A)u^{n+1} = u^n
        main_diag = np.ones(self.nx - 2) * (1 + 2 * self.r)
        off_diag = np.ones(self.nx - 3) * (-self.r)
        A = diags([off_diag, main_diag, off_diag], [-1, 0, 1])
        
        for n in range(self.nt - 1):
            # RHS includes boundary contributions
            rhs = u[n, 1:-1].copy()
            rhs[0] += self.r * bc_left(self.t[n+1])
            rhs[-1] += self.r * bc_right(self.t[n+1])
            
            # Solve
            u[n+1, 1:-1] = spsolve(A, rhs)
            u[n+1, 0] = bc_left(self.t[n+1])
            u[n+1, -1] = bc_right(self.t[n+1])
        
        return u
    
    def fundamental_solution(self, x: np.ndarray, t: float, 
                            x0: float = 0) -> np.ndarray:
        """
        Compute fundamental solution Φ(x - x0, t).
        """
        if t <= 0:
            return np.zeros_like(x)
        
        return (4 * np.pi * t)**(-0.5) * np.exp(-(x - x0)**2 / (4 * t))
    
    def verify_maximum_principle(self, u: np.ndarray) -> bool:
        """
        Verify that solution satisfies maximum principle.
        """
        max_interior = np.max(u[1:, 1:-1])
        max_boundary = max(np.max(u[:, 0]), np.max(u[:, -1]), np.max(u[0, :]))
        
        return max_interior <= max_boundary + 1e-10

Random Graphs: The Erdős–Rényi Model

random-graphs

Real-World Context

Random graph theory, pioneered by Paul Erdős and Alfréd Rényi in the 1960s, provides a probabilistic framework for understanding network phenomena. From social networks to the internet, protein interactions to power grids, random graphs help us understand connectivity thresholds, phase transitions, and emergent properties in large networks. The theory has become essential in network science, epidemiology, and computer science.

Definitions

  • Erdős–Rényi Model \(G(n, p)\): A random graph on \(n\) vertices where each edge appears independently with probability \(p\).
  • Connectivity: A graph is connected if there is a path between every pair of vertices.
  • Giant Component: A connected component containing a positive fraction of all vertices.
  • Phase Transition: A sharp change in graph properties as a parameter crosses a threshold.
  • Chromatic Number: The minimum number of colors needed to color vertices so no adjacent vertices share a color.

Theorem: The Connectivity Threshold

Theorem: For \(G(n, p)\) with \(p = \frac{c \log n}{n}\):

  1. If \(c < 1\), then almost surely (a.s.) \(G(n, p)\) is disconnected
  2. If \(c > 1\), then a.s. \(G(n, p)\) is connected

Moreover, the sharp threshold for connectivity is \(p = \frac{\log n}{n}\).

Theorem: The Giant Component Phase Transition

Theorem: Let \(p = \frac{c}{n}\) for constant \(c\).

  1. If \(c < 1\), then a.s. all components have size \(O(\log n)\)
  2. If \(c = 1\), then a.s. the largest component has size \(\Theta(n^{2/3})\)
  3. If \(c > 1\), then a.s. there exists a unique giant component of size \(\alpha(c)n + o(n)\) where \(\alpha(c) > 0\) satisfies \(\alpha = 1 - e^{-c\alpha}\)

Proof Sketch (Giant Component)

The proof uses branching process approximation. Explore the graph via breadth-first search starting from a random vertex. The number of new neighbors discovered at each step is approximately Poisson\((c)\). For a branching process with mean offspring \(c\):

  • If \(c < 1\), the process dies out almost surely (finite components)
  • If \(c > 1\), the process survives with positive probability \(\alpha(c)\) (giant component)

The fixed point equation \(\alpha = 1 - e^{-c\alpha}\) comes from the extinction probability of the branching process.

Notation Guide

  • \(G(n, p)\): Erdős–Rényi random graph
  • \(L_1(G)\): Size of largest component
  • \(\omega(G)\): Clique number
  • \(\chi(G)\): Chromatic number
  • a.s.: Almost surely (probability \(\to 1\) as \(n \to \infty\))

import numpy as np
import matplotlib.pyplot as plt
from collections import deque
from typing import List, Set, Tuple

class RandomGraph:
    """
    Erdős–Rényi random graph G(n, p) with analysis tools.
    """
    
    def __init__(self, n: int, p: float):
        """Generate G(n, p) random graph."""
        self.n = n
        self.p = p
        
        # Generate adjacency matrix (upper triangular)
        self.adj = np.random.random((n, n)) < p
        self.adj = np.triu(self.adj, 1)  # No self-loops
        self.adj = self.adj + self.adj.T  # Symmetric
    
    def connected_components(self) -> List[Set[int]]:
        """Find all connected components using BFS."""
        visited = set()
        components = []
        
        for start in range(self.n):
            if start in visited:
                continue
            
            # BFS
            component = set()
            queue = deque([start])
            
            while queue:
                v = queue.popleft()
                if v in visited:
                    continue
                visited.add(v)
                component.add(v)
                
                # Add neighbors
                neighbors = np.where(self.adj[v])[0]
                for w in neighbors:
                    if w not in visited:
                        queue.append(w)
            
            components.append(component)
        
        return components
    
    def largest_component_size(self) -> int:
        """Size of largest connected component."""
        components = self.connected_components()
        return max(len(c) for c in components) if components else 0
    
    def is_connected(self) -> bool:
        """Check if graph is connected."""
        return self.largest_component_size() == self.n
    
    def degree_distribution(self) -> np.ndarray:
        """Return degree distribution."""
        degrees = np.sum(self.adj, axis=1)
        return degrees
    
    def clustering_coefficient(self) -> float:
        """Compute average clustering coefficient."""
        coeffs = []
        for v in range(self.n):
            neighbors = np.where(self.adj[v])[0]
            k = len(neighbors)
            if k < 2:
                continue
            
            # Count triangles
            triangles = 0
            for i in range(k):
                for j in range(i + 1, k):
                    if self.adj[neighbors[i], neighbors[j]]:
                        triangles += 1
            
            possible = k * (k - 1) / 2
            coeffs.append(triangles / possible)
        
        return np.mean(coeffs) if coeffs else 0
    
    @staticmethod
    def theoretical_giant_component_size(c: float) -> float:
        """
        Theoretical size of giant component for p = c/n.
        Returns α(c) where α = 1 - exp(-c*α).
        """
        if c <= 1:
            return 0
        
        # Solve α = 1 - exp(-c*α) by fixed-point iteration
        alpha = 0.5
        for _ in range(100):
            alpha_new = 1 - np.exp(-c * alpha)
            if abs(alpha_new - alpha) < 1e-10:
                break
            alpha = alpha_new
        
        return alpha

Machine Learning Theory: PAC Learning and VC Dimension

machine-learning-theory

Real-World Context

Modern machine learning systems can recognize faces, translate languages, and beat grandmasters at chess. But when can we trust these systems to generalize from training data to unseen examples? Probably Approximately Correct (PAC) learning theory, developed by Leslie Valiant in 1984, provides the mathematical foundation for understanding learnability. It quantifies how much data is needed for a learning algorithm to succeed with high probability.

Definitions

  • Concept Class \(\mathcal{C}\): A set of functions \(c: X \to \{0, 1\}\) (binary classifiers).
  • Hypothesis Class \(\mathcal{H}\): The set of functions the learning algorithm can output.
  • Empirical Risk: \(\hat{R}(h) = \frac{1}{m}\sum_{i=1}^m \mathbf{1}[h(x_i) \neq y_i]\) — error on training data.
  • True Risk: \(R(h) = \mathbb{P}[h(x) \neq c(x)]\) — error on the true distribution.
  • Shattering: A set \(S\) is shattered by \(\mathcal{H}\) if \(\mathcal{H}\) realizes all \(2^{|S|}\) labelings of \(S\).
  • VC Dimension: \(\text{VC}(\mathcal{H}) = \max\{|S| : S \text{ is shattered by } \mathcal{H}\}\).

Theorem: PAC Learnability

Theorem: A concept class \(\mathcal{C}\) is PAC learnable if there exists an algorithm \(\mathcal{A}\) such that for all:

  • Target concepts \(c \in \mathcal{C}\)
  • Distributions \(\mathcal{D}\) over \(X\)
  • Error parameters \(\epsilon, \delta > 0\)

Given \(m \geq m_{\mathcal{C}}(\epsilon, \delta)\) i.i.d. samples from \(\mathcal{D}\), \(\mathcal{A}\) outputs \(h\) such that:

\[\mathbb{P}[R(h) \leq \epsilon] \geq 1 - \delta\]

The sample complexity is polynomial in \(1/\epsilon\) and \(1/\delta\).

Theorem: The Fundamental Theorem of PAC Learning

Theorem: The following are equivalent:

  1. \(\mathcal{H}\) is PAC learnable
  2. \(\mathcal{H}\) has finite VC dimension
  3. The empirical risk minimizer (ERM) is a successful PAC learner

Moreover, the sample complexity satisfies:

\[\Omega\left(\frac{d + \log(1/\delta)}{\epsilon}\right) \leq m_{\mathcal{H}}(\epsilon, \delta) \leq O\left(\frac{d \log(1/\epsilon) + \log(1/\delta)}{\epsilon}\right)\]

where \(d = \text{VC}(\mathcal{H})\).

Proof Sketch

(Finite VC \(\Rightarrow\) PAC): The key is uniform convergence. Sauer's lemma shows that a class with VC dimension \(d\) can induce at most \(\sum_{i=0}^d \binom{m}{i} \leq (em/d)^d\) labelings on \(m\) points. Using the union bound over this finite set of effective hypotheses:

\[\mathbb{P}[\exists h \in \mathcal{H}: |R(h) - \hat{R}(h)| > \epsilon] \leq 4(2m)^d e^{-\epsilon^2 m/8}\]

Setting this \(\leq \delta\) and solving for \(m\) gives the sample complexity bound.

Notation Guide

  • \(\mathcal{C}, \mathcal{H}\): Concept and hypothesis classes
  • \(R(h)\): True/generalization error
  • \(\hat{R}(h)\): Empirical/training error
  • \(\text{VC}(\mathcal{H})\): VC dimension
  • \(\epsilon\): Accuracy parameter
  • \(\delta\): Confidence parameter

import numpy as np
import matplotlib.pyplot as plt
from typing import List, Callable, Tuple
from itertools import combinations

class PACLearning:
    """
    Tools for analyzing PAC learning and VC dimension.
    """
    
    @staticmethod
    def can_shatter(H: List[Callable], points: np.ndarray) -> bool:
        """
        Check if hypothesis class H can shatter the given points.
        H is a list of functions that take a point and return 0 or 1.
        """
        n = len(points)
        if n == 0:
            return True
        
        # Generate all 2^n possible labelings
        all_labelings = set()
        for h in H:
            labeling = tuple(h(p) for p in points)
            all_labelings.add(labeling)
        
        # Check if we have all possible labelings
        expected = 2 ** n
        return len(all_labelings) == expected
    
    @staticmethod
    def vc_dimension_1d(H: List[Callable], max_points: int = 10) -> int:
        """
        Compute VC dimension for 1D hypothesis class by brute force.
        """
        for n in range(1, max_points + 1):
            # Try many random point sets
            found_shattered = False
            
            for _ in range(100):  # Sample random configurations
                points = np.random.uniform(-10, 10, n)
                
                if PACLearning.can_shatter(H, points):
                    found_shattered = True
                    break
            
            if not found_shattered:
                return n - 1
        
        return max_points
    
    @staticmethod
    def sample_complexity_bound(vc_dim: int, epsilon: float, 
                                 delta: float) -> int:
        """
        Upper bound on sample complexity from VC theory.
        m = O((d log(1/ε) + log(1/δ)) / ε)
        """
        return int(np.ceil(
            (vc_dim * np.log(1/epsilon) + np.log(1/delta)) / epsilon
        ))
    
    @staticmethod
    def generalization_bound(vc_dim: int, m: int, delta: float) -> float:
        """
        Bound on generalization gap with probability 1 - δ.
        |R(h) - R_hat(h)| <= O(sqrt(d log(m/d) / m))
        """
        if m <= vc_dim:
            return 1.0
        
        return np.sqrt(vc_dim * np.log(m / vc_dim) / m) + np.sqrt(np.log(1/delta) / m)

Algebraic Surfaces: The Enriques-Kodaira Classification

algebraic-surfaces

Historical Context

The classification of algebraic surfaces represents one of the crowning achievements of the Italian school of algebraic geometry in the early 20th century. Led by Guido Castelnuovo, Federigo Enriques, and Francesco Severi, this work paralleled the classification of curves by Riemann and extended it to two dimensions. The complete classification, now called the Enriques-Kodaira classification, was achieved through the introduction of birational invariants like the geometric genus and irregularity. Kunihiko Kodaira's later work using sheaf cohomology and complex manifold theory provided the modern foundations and extended the classification to compact complex surfaces.

Definitions

  • Algebraic Surface: A two-dimensional algebraic variety, or equivalently, a complex manifold of complex dimension 2.
  • Canonical Bundle: \(K_S = \Lambda^2 T^*S\), the line bundle of holomorphic 2-forms.
  • Geometric Genus: \(p_g(S) = h^0(S, K_S) = \dim H^0(S, \mathcal{O}_S(K_S))\).
  • Irregularity: \(q(S) = h^1(S, \mathcal{O}_S) = h^0(S, \Omega_S^1)\).
  • Holomorphic Euler Characteristic: \(\chi(\mathcal{O}_S) = 1 - q + p_g\).
  • Kodaira Dimension: \(\kappa(S) = \limsup_{n \to \infty} \frac{\log h^0(S, nK_S)}{\log n}\), taking values \(-\infty, 0, 1, 2\).

Theorem: The Enriques-Kodaira Classification

Theorem: Minimal algebraic surfaces (those containing no \((-1)\)-curves) are classified by their Kodaira dimension:

\(\kappa = -\infty\): Rational or ruled surfaces

  • Rational: birational to \(\mathbb{P}^2\)
  • Ruled: birational to \(C \times \mathbb{P}^1\) for curve \(C\)

\(\kappa = 0\): Surfaces with trivial canonical class (up to finite cover)

  • Abelian surfaces: \(S = \mathbb{C}^2/\Lambda\)
  • K3 surfaces: \(K_S = 0\), \(q = 0\), \(p_g = 1\)
  • Enriques surfaces: \(2K_S = 0\), \(K_S \neq 0\)
  • Hyperelliptic surfaces: quotients of products of elliptic curves

\(\kappa = 1\): Elliptic surfaces — admit a fibration over a curve with elliptic fibers

\(\kappa = 2\): Surfaces of general type — the "generic" case with ample canonical bundle

Theorem: Noether's Formula

Theorem: For a minimal algebraic surface \(S\):

\[\chi(\mathcal{O}_S) = \frac{K_S^2 + e(S)}{12}\]

where \(e(S)\) is the topological Euler characteristic and \(K_S^2 = c_1(K_S)^2\) is the self-intersection of the canonical divisor.

Proof Sketch

Noether's formula follows from the Hirzebruch-Riemann-Roch theorem applied to the trivial line bundle:

\[\chi(\mathcal{O}_S) = \int_S \text{td}(T_S) = \int_S (1 + \frac{c_1}{2} + \frac{c_1^2 + c_2}{12}) = \frac{c_1^2 + c_2}{12}\]

where \(c_1 = -c_1(K_S)\) and \(c_2 = e(S)\) by Gauss-Bonnet.

Notation Guide

  • \(K_S\): Canonical bundle of \(S\)
  • \(p_g\): Geometric genus
  • \(q\): Irregularity
  • \(\kappa\): Kodaira dimension
  • \(K_S^2\): Self-intersection of canonical divisor
  • \(h^{p,q} = \dim H^q(S, \Omega^p)\): Hodge numbers

Ergodic Theory: Recurrence and Mixing

ergodic-theory

Historical Context

Ergodic theory emerged from statistical mechanics in the late 19th century. Ludwig Boltzmann hypothesized that the time average of a system's behavior equals its space average — the ergodic hypothesis. This would justify the use of probabilistic methods in physics. However, the hypothesis as originally stated is false for most systems. The modern theory, developed by George Birkhoff, John von Neumann, and Andrey Kolmogorov in the 1930s, places ergodicity in its proper mathematical context and reveals a rich hierarchy of dynamical behaviors from ergodicity to mixing to Bernoulli properties.

Definitions

  • Measure-Preserving System: A quadruple \((X, \mathcal{B}, \mu, T)\) where \((X, \mathcal{B}, \mu)\) is a probability space and \(T: X \to X\) is measurable with \(\mu(T^{-1}A) = \mu(A)\) for all \(A \in \mathcal{B}\).
  • Ergodic: \(T\) is ergodic if \(T^{-1}A = A\) implies \(\mu(A) \in \{0, 1\}\) (no non-trivial invariant sets).
  • Mixing: \(T\) is mixing if \(\lim_{n \to \infty} \mu(T^{-n}A \cap B) = \mu(A)\mu(B)\) for all measurable \(A, B\).
  • Weak Mixing: \(\lim_{N \to \infty} \frac{1}{N}\sum_{n=0}^{N-1}|\mu(T^{-n}A \cap B) - \mu(A)\mu(B)| = 0\).
  • Koopman Operator: \(U_T: L^2(X) \to L^2(X)\) defined by \(U_T f = f \circ T\).

Theorem: Poincaré Recurrence

Theorem: Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(A \in \mathcal{B}\) with \(\mu(A) > 0\). Then for almost every \(x \in A\), there exists \(n \geq 1\) such that \(T^n(x) \in A\).

In fact, almost every \(x \in A\) returns to \(A\) infinitely often.

Proof Sketch

Let \(B = A \setminus \bigcup_{n=1}^\infty T^{-n}A\) be the set of points in \(A\) that never return. The sets \(B, T^{-1}B, T^{-2}B, \ldots\) are pairwise disjoint (if \(T^{-i}x \in B\) and \(T^{-j}x \in B\) with \(i < j\), then \(T^{j-i}(T^{-j}x) = T^{-i}x \in B \subseteq A\), contradicting the definition of \(B\)).

Since \(T\) preserves measure, \(\mu(T^{-n}B) = \mu(B)\) for all \(n\). If \(\mu(B) > 0\), then \(\mu(\bigcup_{n=0}^\infty T^{-n}B) = \sum_{n=0}^\infty \mu(B) = \infty\), contradicting \(\mu(X) = 1\). Thus \(\mu(B) = 0\).

Theorem: Birkhoff's Ergodic Theorem

Theorem: Let \((X, \mathcal{B}, \mu, T)\) be measure-preserving and \(f \in L^1(X)\). Then for almost every \(x \in X\):

\[\lim_{N \to \infty} \frac{1}{N}\sum_{n=0}^{N-1} f(T^n x) = \bar{f}(x)\]

where \(\bar{f} \in L^1(X)\) is \(T\)-invariant. If \(T\) is ergodic, then:

\[\bar{f}(x) = \int_X f \, d\mu \quad \text{a.e.}\]

Theorem: The Hierarchy

Theorem: The following implications hold:

\[\text{Bernoulli} \Rightarrow \text{K-mixing} \Rightarrow \text{Mixing} \Rightarrow \text{Weak Mixing} \Rightarrow \text{Ergodic}\]

None of these implications reverse in general.

Notation Guide

  • \((X, \mathcal{B}, \mu)\): Probability space
  • \(T: X \to X\): Measure-preserving transformation
  • \(L^2(X)\): Space of square-integrable functions
  • \(U_T\): Koopman operator
  • \(A_n f = \frac{1}{n}\sum_{i=0}^{n-1} f \circ T^i\): Ergodic average

import numpy as np
import matplotlib.pyplot as plt
from typing import Callable, Tuple

class ErgodicSystem:
    """
    Tools for analyzing measure-preserving dynamical systems.
    """
    
    def __init__(self, T: Callable, X_range: Tuple[float, float]):
        """
        Initialize with transformation T: X -> X.
        """
        self.T = T
        self.X_range = X_range
    
    def orbit(self, x0: float, n: int) -> np.ndarray:
        """Compute orbit of x0 for n steps."""
        orbit = [x0]
        x = x0
        for _ in range(n - 1):
            x = self.T(x)
            orbit.append(x)
        return np.array(orbit)
    
    def time_average(self, f: Callable, x0: float, n: int) -> float:
        """
        Compute time average: (1/n) Σ f(T^i(x0)).
        """
        orb = self.orbit(x0, n)
        return np.mean([f(x) for x in orb])
    
    def space_average(self, f: Callable, num_samples: int = 10000) -> float:
        """
        Compute space average via Monte Carlo.
        """
        samples = np.random.uniform(*self.X_range, num_samples)
        return np.mean([f(x) for x in samples])
    
    def correlation(self, f: Callable, g: Callable, 
                    n: int, num_samples: int = 1000) -> np.ndarray:
        """
        Compute correlation C_n(f,g) = ∫ f(T^n x) g(x) dx.
        """
        samples = np.random.uniform(*self.X_range, num_samples)
        
        correlations = []
        for i in range(n):
            T_i_samples = samples.copy()
            for _ in range(i):
                T_i_samples = np.array([self.T(x) for x in T_i_samples])
            
            corr = np.mean([f(T_x) * g(x) for T_x, x in zip(T_i_samples, samples)])
            correlations.append(corr)
        
        return np.array(correlations)
    
    def is_invariant(self, A: Callable, num_samples: int = 1000, 
                     tolerance: float = 0.01) -> bool:
        """
        Check if set A (indicator function) is approximately invariant.
        """
        samples = np.random.uniform(*self.X_range, num_samples)
        
        measure_A = np.mean([A(x) for x in samples])
        measure_TA = np.mean([A(self.T(x)) for x in samples])
        
        return abs(measure_A - measure_TA) < tolerance

Geometric Group Theory: The Word Problem and Cayley Graphs

geometric-group-theory

Historical Context

Geometric group theory emerged in the late 1980s through the work of Mikhail Gromov, who realized that algebraic properties of groups are deeply connected to the geometric properties of spaces on which they act. This field bridges group theory, topology, and geometry. A foundational problem is the word problem posed by Max Dehn in 1911: given a group presentation, decide whether a word represents the identity. While Dehn showed this is solvable for surface groups, Novikov and Boone proved in the 1950s that no general algorithm exists — the word problem is undecidable.

Definitions

  • Group Presentation: \(G = \langle S \mid R \rangle\) where \(S\) is a set of generators and \(R\) is a set of relators.
  • Word: A finite string in the generators and their inverses.
  • Word Problem: Given a word \(w\), decide if \(w =_G 1\) (represents the identity).
  • Cayley Graph: \(\Gamma(G, S)\) has vertices for group elements and edges \((g, gs)\) labeled by \(s \in S\).
  • Quasi-Isometry: A map \(f: X \to Y\) between metric spaces satisfying \(\frac{1}{K}d_X(x, x') - C \leq d_Y(f(x), f(x')) \leq Kd_X(x, x') + C\).
  • Hyperbolic Group: A group whose Cayley graph satisfies Gromov's thin triangle condition.

Theorem: The Milnor-Švarc Lemma

Theorem: Let \(G\) act properly discontinuously and cocompactly by isometries on a proper geodesic metric space \(X\). Then \(G\) is finitely generated and for any basepoint \(x_0 \in X\), the orbit map:

\[g \mapsto g \cdot x_0\]

is a quasi-isometry between \(G\) (with word metric) and \(X\).

Theorem: Growth of Groups

Theorem (Gromov): A finitely generated group has polynomial growth if and only if it is virtually nilpotent (contains a nilpotent subgroup of finite index).

The growth function \(\gamma(n) = |B(1, n)|\) (number of elements in ball of radius \(n\)) satisfies exactly one of:

  • Polynomial: \(\gamma(n) \sim n^d\)
  • Exponential: \(\gamma(n) \sim e^n\)
  • Intermediate: Super-polynomial but sub-exponential

Proof Sketch (Polynomial Growth)

Gromov's proof uses the asymptotic cone: rescale the metric by \(\epsilon_n \to 0\) and take a limit. Polynomial growth ensures the limit is a proper metric space. The isometry group of this limit acts transitively, and by the solution to Hilbert's fifth problem, this implies the group is a Lie group. The original group is then virtually nilpotent by the structure theory.

Notation Guide

  • \(\langle S \mid R \rangle\): Group presentation
  • \(\Gamma(G, S)\): Cayley graph
  • \(|w|\): Word length
  • \(d_S(g, h)\): Word metric distance
  • \(B(1, n)\): Ball of radius \(n\) in word metric
  • \(\gamma(n)\): Growth function

import numpy as np
from collections import deque, defaultdict
from typing import Set, Tuple, List, Dict

class FinitelyGeneratedGroup:
    """
    Representation of a finitely generated group.
    """
    
    def __init__(self, generators: List[str], relators: List[str] = None):
        """
        Initialize group with generators and relators.
        Generators: list of symbols (e.g., ['a', 'b'])
        Relators: list of words that equal identity (e.g., ['a^3', 'b^2', 'abab'])
        """
        self.generators = generators
        self.relators = relators or []
        self.generator_set = set(generators)
        self.inv_map = {g: g.upper() for g in generators}
        self.inv_map.update({g.upper(): g for g in generators})
    
    def reduce_word(self, word: str) -> str:
        """
        Reduce word by canceling adjacent inverse pairs.
        This is a simplified reduction (doesn't use relators).
        """
        stack = []
        for char in word:
            if stack and self.inv_map.get(char) == stack[-1]:
                stack.pop()  # Cancel
            else:
                stack.append(char)
        return ''.join(stack)
    
    def multiply(self, w1: str, w2: str) -> str:
        """Multiply two words."""
        return self.reduce_word(w1 + w2)
    
    def inverse(self, word: str) -> str:
        """Compute inverse of a word."""
        inv = ''.join(self.inv_map.get(c, c) for c in reversed(word))
        return self.reduce_word(inv)
    
    def word_length(self, word: str) -> int:
        """Length of reduced word."""
        return len(self.reduce_word(word))
    
    def cayley_ball(self, radius: int) -> Set[str]:
        """
        Compute ball of given radius in Cayley graph.
        Returns set of reduced words.
        """
        ball = {''}  # Identity
        frontier = {''}
        
        for r in range(radius):
            new_frontier = set()
            for word in frontier:
                for g in self.generators:
                    # Multiply by generator
                    new_word = self.multiply(word, g)
                    if new_word not in ball:
                        ball.add(new_word)
                        new_frontier.add(new_word)
                    
                    # Multiply by inverse
                    new_word = self.multiply(word, g.upper())
                    if new_word not in ball:
                        ball.add(new_word)
                        new_frontier.add(new_word)
            
            frontier = new_frontier
            if not frontier:
                break
        
        return ball
    
    def growth_function(self, max_radius: int) -> List[int]:
        """Compute growth function up to max_radius."""
        sizes = []
        ball = set()
        
        for r in range(max_radius + 1):
            if r == 0:
                ball = {''}
            else:
                # Expand by one layer
                new_ball = set(ball)
                for word in ball:
                    for g in self.generators:
                        new_word = self.multiply(word, g)
                        new_ball.add(new_word)
                        new_word = self.multiply(word, g.upper())
                        new_ball.add(new_word)
                ball = new_ball
            
            sizes.append(len(ball))
        
        return sizes

📜 Math History: The Birth of Abstract Algebra

The 19th century witnessed a profound transformation in mathematics that would reshape the entire discipline: the birth of abstract algebra. This revolution, spanning roughly from 1830 to 1900, moved mathematics away from the study of specific numbers and equations toward the study of general structures and their properties.

The story begins with Évariste Galois (1811–1832), whose work on the solvability of polynomial equations laid the foundations for group theory. Galois discovered that the symmetries of a polynomial's roots — what we now call its Galois group — determine whether the polynomial can be solved by radicals. His famous criterion states that a polynomial is solvable by radicals if and only if its Galois group is solvable. Tragically, Galois died in a duel at age 20, but his manuscripts, published posthumously by Joseph Liouville in 1846, would inspire generations of mathematicians.

Meanwhile, in England, Arthur Cayley and James Joseph Sylvester were developing the theory of matrices and invariant theory. Cayley's 1858 "Memoir on the Theory of Matrices" introduced matrix multiplication and the inverse matrix, while Sylvester's work on invariants provided tools that would later prove essential in representation theory.

The concept of an abstract group gradually emerged through the work of several mathematicians. Camille Jordan's 1870 "Traité des substitutions" systematized Galois theory and introduced the notion of composition series. Walther von Dyck, in 1882, gave the first general definition of a group in terms of generators and relations, explicitly moving beyond permutation groups.

Richard Dedekind made crucial contributions to ring theory and algebraic number theory. His introduction of ideals — building on the work of Ernst Kummer — provided the proper framework for understanding unique factorization in algebraic number fields. Dedekind's 1871 Supplement to Dirichlet's "Vorlesungen über Zahlentheorie" presented many concepts that would become standard: fields, rings, modules, and ideals.

The final synthesis came with the work of Emmy Noether (1882–1935), whose 1921 paper "Idealtheorie in Ringbereichen" revolutionized ring theory by emphasizing the ascending chain condition and the structural approach that would define modern algebra. Her famous declaration "Es steht alles schon bei Dedekind" ("It's all already in Dedekind") acknowledged her debt while demonstrating how she transformed existing ideas into a powerful general theory.

By the early 20th century, the transformation was complete. Mathematics had become the study of structures — groups, rings, fields, vector spaces — and the mappings between them. This structural viewpoint, championed by the Bourbaki group in the mid-20th century, remains the dominant paradigm in algebra today.

🎨 Visualization of the Day: The Lorenz Attractor

The Lorenz attractor is a set of chaotic solutions to the Lorenz system, a simplified mathematical model for atmospheric convection. First studied by Edward Lorenz in 1963, it became iconic in chaos theory for its butterfly-shaped pattern and sensitive dependence on initial conditions — the famous "butterfly effect."

The system is defined by three ordinary differential equations:

\[\frac{dx}{dt} = \sigma(y - x)\]

\[\frac{dy}{dt} = x(\rho - z) - y\]

\[\frac{dz}{dt} = xy - \beta z\]

With parameters \(\sigma = 10\), \(\rho = 28\), and \(\beta = 8/3\), the system exhibits chaotic behavior, with trajectories spiraling around two unstable equilibrium points in a complex, never-repeating pattern.

rho = 28.0
beta = 8.0 / 3.0

def lorenz(t, state):
    """
    Lorenz system differential equations.
    """
    x, y, z = state
    dxdt = sigma * (y - x)
    dydt = x * (rho - z) - y
    dzdt = x * y - beta * z
    return [dxdt, dydt, dzdt]
