1. Homotopy Type Theory and the Univalence Axiom

Motivation: Traditional set theory provides a foundation for mathematics where equality is a primitive notion. But in practice, mathematicians treat isomorphic structures as "the same" in a strong sense. Homotopy type theory (HoTT) provides a new foundation where this principle—called the univalence axiom—can be formally proven.

Definitions:

  • A type is a collection of terms, analogous to a set but with richer structure
  • The identity type \(Id_A(a,b)\) represents paths or equivalences between terms
  • A homotopy between functions \(f, g : A \to B\) is a function \(H : A \to Id_B(f(a), g(a))\)
  • The univalence axiom: \((A =_U B) \simeq (A \simeq B)\), where the left side is the identity type of types and the right side is the type of equivalences

Theorem (Function Extensionality): If two functions agree on all inputs, they are equal.

Proof: In HoTT, we define a function to be a dependent pair of its graph and functionality proof. Given \(f, g : \prod_{x:A} B(x)\) with \(h : \prod_{x:A} Id_{B(x)}(f(x), g(x))\), we construct a path in the function type by induction on the identity type. The univalence axiom ensures that pointwise paths lift to function paths. \(\square\)

Notation Guide:

  • \(\prod_{x:A} B(x)\) — dependent product (dependent function type)
  • \(\sum_{x:A} B(x)\) — dependent sum (dependent pair type)
  • \(a =_A b\) or \(Id_A(a,b)\) — identity type (paths from a to b)
  • \(\simeq\) — equivalence of types (bi-invertible maps)
  • \(U\) — universe type (type of small types)

2. Arithmetic Geometry: The Mordell-Weil Theorem

Motivation: The study of rational solutions to polynomial equations is one of the oldest problems in mathematics. The Mordell-Weil theorem tells us that for elliptic curves, the rational points form a finitely generated abelian group—a beautiful blend of algebra and geometry.

Definitions:

  • An elliptic curve over a field \(K\) is a smooth projective curve of genus 1 with a specified base point \(O\)
  • For \(K = \mathbb{Q}\), the Mordell-Weil group \(E(\mathbb{Q})\) is the group of rational points on \(E\)
  • The group law on an elliptic curve: given points \(P\) and \(Q\), draw the line through them (or tangent if \(P = Q\)), find the third intersection with the curve, and reflect over the x-axis
  • The height function \(h: E(\mathbb{Q}) \to \mathbb{R}_{\geq 0}\) measures the complexity of a rational point

Theorem (Mordell-Weil): Let \(E\) be an elliptic curve over \(\mathbb{Q}\). Then \(E(\mathbb{Q})\) is a finitely generated abelian group. That is: \[E(\mathbb{Q}) \cong \mathbb{Z}^r \oplus E(\mathbb{Q})_{\text{tors}}\] where \(r\) is the rank and \(E(\mathbb{Q})_{\text{tors}}\) is the finite torsion subgroup.

Proof Sketch: The proof proceeds in two main steps. First, the "weak Mordell-Weil theorem" shows that \(E(\mathbb{Q})/2E(\mathbb{Q})\) is finite. This uses Galois cohomology and properties of the multiplication-by-2 map. Second, the theory of heights shows that one can descend from any point to a point of bounded height, and there are only finitely many such points. Combining these via the method of infinite descent yields finite generation. \(\square\)

Notation Guide:

  • \(E(K)\) — K-rational points on elliptic curve E
  • \(\mathbb{Z}^r\) — Free abelian group of rank r
  • \(E[n]\) — n-torsion subgroup (points of order dividing n)
  • \(\hat{h}(P)\) — Canonical height (Néron-Tate height) of point P
  • \(\langle P, Q \rangle\) — Height pairing on E(\mathbb{Q}) \otimes \mathbb{R}

# Weierstrass form: y^2 = x^3 + ax + b

class EllipticCurvePoint:
    def __init__(self, x, y, a, b, infinity=False):
        self.x = x
        self.y = y
        self.a = a
        self.b = b
        self.infinity = infinity
        
        # Verify point is on curve (if not point at infinity)
        if not infinity:
            assert y**2 == x**3 + a*x + b, "Point not on curve!"
    
    def __add__(self, other):
        """Group law on elliptic curve"""
        if self.infinity:
            return other
        if other.infinity:
            return self
        
        a, b = self.a, self.b
        
        # Case: P + (-P) = O (point at infinity)
        if self.x == other.x and self.y == -other.y:
            return EllipticCurvePoint(None, None, a, b, infinity=True)
        
        # Calculate slope
        if self.x == other.x and self.y == other.y:
            # Point doubling: tangent slope
            if self.y == 0:
                return EllipticCurvePoint(None, None, a, b, infinity=True)
            m = (3 * self.x**2 + a) / (2 * self.y)
        else:
            # Point addition: secant slope
            m = (other.y - self.y) / (other.x - self.x)
        
        # Calculate third intersection point
        x3 = m**2 - self.x - other.x
        y3 = m * (self.x - x3) - self.y
        
        return EllipticCurvePoint(x3, -y3, a, b)  # Reflect over x-axis
    
    def __rmul__(self, n):
        """Scalar multiplication (naive implementation)"""
        result = EllipticCurvePoint(None, None, self.a, self.b, infinity=True)
        addend = self
        while n > 0:
            if n & 1:
                result = result + addend
            addend = addend + addend
            n >>= 1
        return result
    
    def __repr__(self):
        if self.infinity:
            return "O (point at infinity)"
        return f"({self.x}, {self.y})"

3. Geometric Measure Theory: Hausdorff Dimension

Motivation: How do we measure the "size" of fractal sets? Traditional Lebesgue measure assigns zero to the Cantor set and the Koch snowflake boundary, yet these sets have rich geometric structure. Hausdorff dimension provides a way to measure sets of fractional dimension.

Definitions:

  • For a set \(E \subset \mathbb{R}^n\) and \(\delta > 0\), a \(\delta\)-cover is a countable collection of sets \(\{U_i\}\) with \(E \subset \bigcup_i U_i\) and \(\text{diam}(U_i) \leq \delta\) for all \(i\)
  • The s-dimensional Hausdorff measure: \[\mathcal{H}^s(E) = \lim_{\delta \to 0} \inf\left\{\sum_i (\text{diam } U_i)^s : \{U_i\} \text{ is a } \delta\text{-cover of } E\right\}\]
  • The Hausdorff dimension: \[\dim_H(E) = \inf\{s \geq 0 : \mathcal{H}^s(E) = 0\} = \sup\{s : \mathcal{H}^s(E) = \infty\}\]

Theorem (Dimension of the Cantor Set): The middle-thirds Cantor set \(C\) has Hausdorff dimension \(\dim_H(C) = \frac{\log 2}{\log 3} \approx 0.631\).

Proof: The Cantor set is constructed by repeatedly removing middle thirds. At stage \(n\), we have \(2^n\) intervals of length \(3^{-n}\). For a \(\delta\)-cover with \(\delta = 3^{-n}\), we can cover \(C\) with these \(2^n\) intervals, giving: \[\mathcal{H}^s_{3^{-n}}(C) \leq 2^n \cdot (3^{-n})^s = (2 \cdot 3^{-s})^n\] When \(s = \frac{\log 2}{\log 3}\), we have \(2 \cdot 3^{-s} = 1\), so \(\mathcal{H}^s(C) \leq 1\). For the lower bound, we use the mass distribution principle: the natural probability measure on \(C\) (giving each interval at stage \(n\) mass \(2^{-n}\)) satisfies \(\mu(B(x,r)) \leq c \cdot r^s\) for some constant \(c\), implying \(\mathcal{H}^s(C) > 0\). \(\square\)

Notation Guide:

  • \(\mathcal{H}^s\) — s-dimensional Hausdorff (outer) measure
  • \(\dim_H(E)\) — Hausdorff dimension of set E
  • \(\text{diam}(U)\) — Diameter of set U: \(\sup\{|x-y| : x,y \in U\}\)
  • \(\mathcal{L}^n\) — n-dimensional Lebesgue measure

import numpy as np

def cantor_set(n_levels=8):
    """
    Generate points in the middle-thirds Cantor set
    """
    points = [0.0, 1.0]  # Endpoints
    intervals = [(0.0, 1.0)]

        new_intervals = []

            new_intervals.append((a, a + third))
            new_intervals.append((a + 2*third, b))
        intervals = new_intervals

1. Bayesian Statistics: Markov Chain Monte Carlo

Real-World Motivation: In modern data science, we often need to compute posterior distributions that are analytically intractable. MCMC methods allow us to sample from complex distributions, enabling Bayesian inference in high-dimensional models used in genetics, finance, and machine learning.

Definitions:

  • A Markov chain is a stochastic process \(\{X_t\}\) where \(X_{t+1}\) depends only on \(X_t\): \(P(X_{t+1} | X_t, X_{t-1}, ...) = P(X_{t+1} | X_t)\)
  • A distribution \(\pi\) is stationary if \(X_t \sim \pi\) implies \(X_{t+1} \sim \pi\)
  • A chain is ergodic if it converges to a unique stationary distribution regardless of initial state
  • Detailed balance: \(\pi(x) P(x \to y) = \pi(y) P(y \to x)\)

Theorem (Metropolis-Hastings): Let \(\pi\) be a target density (known up to normalization). Define the transition kernel: \[P(x \to y) = q(y|x) \cdot \min\left(1, \frac{\pi(y) q(x|y)}{\pi(x) q(y|x)}\right)\] for \(y \neq x\), where \(q\) is a proposal distribution. Then \(\pi\) is the stationary distribution of this Markov chain.

Proof: We verify detailed balance. For \(x \neq y\): \[\pi(x) P(x \to y) = \pi(x) q(y|x) \min\left(1, \frac{\pi(y) q(x|y)}{\pi(x) q(y|x)}\right) = \min(\pi(x)q(y|x), \pi(y)q(x|y))\] This expression is symmetric in \(x\) and \(y\), so detailed balance holds. \(\square\)

Notation Guide:

  • \(\pi(x)\) — Target (posterior) density
  • \(q(y|x)\) — Proposal distribution
  • \(\alpha(x, y)\) — Acceptance probability
  • \(K(x, y)\) — Transition kernel
# Bayesian Statistics: MCMC Sampling
import numpy as np
import matplotlib.pyplot as plt

def metropolis_hastings(target_log_prob, proposal_std, n_samples, x0):
    """
    Metropolis-Hastings MCMC sampler
    
    Parameters:
    -----------
    target_log_prob : function
        Log of unnormalized target density
    proposal_std : float
        Standard deviation of Gaussian proposal
    n_samples : int
        Number of samples to generate
    x0 : float
        Initial state
    """
    samples = np.zeros(n_samples)
    x = x0
    accepted = 0
    
    for i in range(n_samples):
        # Propose new state
        y = np.random.normal(x, proposal_std)
        
        # Compute acceptance probability
        log_alpha = target_log_prob(y) - target_log_prob(x)
        alpha = min(1, np.exp(log_alpha))
        
        # Accept or reject
        if np.random.random() < alpha:
            x = y
            accepted += 1
        
        samples[i] = x
    
    acceptance_rate = accepted / n_samples
    return samples, acceptance_rate

def gelman_rubin(chains):
    """
    Gelman-Rubin convergence diagnostic
    R-hat ≈ 1 indicates convergence
    """
    m = len(chains)
    n = len(chains[0])
    
    # Between-chain variance
    chain_means = [np.mean(c) for c in chains]
    overall_mean = np.mean(chain_means)
    B = n * np.var(chain_means, ddof=1)
    
    # Within-chain variance
    W = np.mean([np.var(c, ddof=1) for c in chains])
    
    # Pooled variance
    V = ((n-1)/n) * W + B/n

    R_hat = np.sqrt(V / W)
    return R_hat

    n = len(samples)

2. Reinforcement Learning: Temporal Difference Learning

Real-World Motivation: From game-playing AI (AlphaGo, AlphaZero) to robotics and autonomous vehicles, reinforcement learning enables agents to learn optimal behavior through interaction with their environment. TD learning is the foundation of modern RL algorithms.

Definitions:

  • A Markov Decision Process is \((S, A, P, R, \gamma)\) where \(S\) is state space, \(A\) is action space, \(P(s'|s,a)\) is transition probability, \(R(s,a)\) is reward, and \(\gamma\) is discount factor
  • The value function \(V^\pi(s) = \mathbb{E}[\sum_{t=0}^\infty \gamma^t R_t | S_0 = s, \pi]\)
  • The action-value function \(Q^\pi(s,a) = \mathbb{E}[\sum_{t=0}^\infty \gamma^t R_t | S_0 = s, A_0 = a, \pi]\)
  • The Bellman equation: \(V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a) + \gamma V^\pi(s')]\)

Theorem (TD(0) Convergence): For a finite MDP with learning rate \(\alpha_t\) satisfying \(\sum_t \alpha_t = \infty\) and \(\sum_t \alpha_t^2 < \infty\), the TD(0) algorithm converges with probability 1 to \(V^\pi\).

Proof Sketch: TD(0) performs stochastic gradient descent on the mean-squared Bellman error. The update can be written as: \[V_{t+1}(s_t) = V_t(s_t) + \alpha_t [R_t + \gamma V_t(s_{t+1}) - V_t(s_t)]\] This is a Robbins-Monro stochastic approximation algorithm. The expected update direction points toward the fixed point \(V^\pi\), and the step size conditions ensure convergence. \(\square\)

Notation Guide:

  • \(V^\pi(s)\) — State value function under policy \(\pi\)
  • \(Q^\pi(s,a)\) — Action-value function
  • \(\pi(a|s)\) — Policy (probability of action a in state s)
  • \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\) — TD error
  • \(\gamma\) — Discount factor (\(0 \leq \gamma < 1\))
# Reinforcement Learning: Temporal Difference Learning
import numpy as np

class GridWorld:
    """
    Simple grid world environment
    """
    def __init__(self, size=4):
        self.size = size
        self.n_states = size * size
        self.n_actions = 4  # up, down, left, right
        self.gamma = 0.9
        
        # Terminal states (top-left and bottom-right)
        self.terminal = [0, self.n_states - 1]
        
    def state_to_pos(self, s):
        return (s // self.size, s % self.size)
    
    def pos_to_state(self, row, col):
        return row * self.size + col
    
    def step(self, state, action):
        """Take action, return (next_state, reward, done)"""
        if state in self.terminal:
            return state, 0, True
        
        row, col = self.state_to_pos(state)
        
        # Actions: 0=up, 1=down, 2=left, 3=right
        if action == 0: row = max(0, row - 1)
        elif action == 1: row = min(self.size - 1, row + 1)
        elif action == 2: col = max(0, col - 1)
        elif action == 3: col = min(self.size - 1, col + 1)
        
        next_state = self.pos_to_state(row, col)
        reward = -1  # Step penalty
        done = next_state in self.terminal
        
        return next_state, reward, done
    
    def get_transitions(self, state, action):
        """Get all possible transitions (deterministic)"""
        next_state, reward, done = self.step(state, action)
        return [(1.0, next_state, reward, done)]

def td_zero(env, policy, n_episodes=1000, alpha=0.1):
    """
    TD(0) algorithm for policy evaluation
    """
    V = np.zeros(env.n_states)
    
    for episode in range(n_episodes):
        state = np.random.choice(env.n_states)
        done = False
        
        while not done:
            # Sample action from policy
            action = np.random.choice(env.n_actions, p=policy[state])
            
            # Take action
            next_state, reward, done = env.step(state, action)
            
            # TD update
            td_target = reward + env.gamma * V[next_state] * (not done)
            td_error = td_target - V[state]
            V[state] += alpha * td_error
            
            state = next_state
    
    return V

def q_learning(env, n_episodes=5000, alpha=0.1, epsilon=0.1):
    """
    Q-learning: Off-policy TD control
    """
    Q = np.zeros((env.n_states, env.n_actions))
    
    for episode in range(n_episodes):
        state = np.random.choice(env.n_states)
        done = False
        
        while not done:
            # Epsilon-greedy action selection
            if np.random.random() < epsilon:
                action = np.random.choice(env.n_actions)
            else:
                action = np.argmax(Q[state])
            
            # Take action
            next_state, reward, done = env.step(state, action)
            
            # Q-learning update (off-policy)
            best_next = np.max(Q[next_state])
            td_target = reward + env.gamma * best_next * (not done)
            td_error = td_target - Q[state, action]
            Q[state, action] += alpha * td_error

3. Computational Physics: Finite Element Method for PDEs

Real-World Motivation: From structural engineering to climate modeling, the finite element method (FEM) is the workhorse for solving partial differential equations on complex geometries. It enables simulation of everything from airplane wings to semiconductor devices.

Definitions:

  • The weak form of a PDE: multiply by a test function and integrate by parts to reduce smoothness requirements
  • A finite element is a triple \((K, P, N)\) where \(K\) is a domain element, \(P\) is a function space, and \(N\) is a set of nodal variables
  • The Galerkin approximation: seek \(u_h \in V_h\) such that \(a(u_h, v_h) = L(v_h)\) for all \(v_h \in V_h\)
  • Céa's lemma: \(\|u - u_h\|_V \leq C \inf_{v_h \in V_h} \|u - v_h\|_V\)

Theorem (Céa's Lemma): Let \(V\) be a Hilbert space, \(a: V \times V \to \mathbb{R}\) a continuous, coercive bilinear form, and \(L: V \to \mathbb{R}\) a bounded linear functional. Let \(V_h \subset V\) be a finite-dimensional subspace. If \(u\) solves the variational problem and \(u_h\) is the Galerkin approximation, then: \[\|u - u_h\|_V \leq \frac{M}{\alpha} \inf_{v_h \in V_h} \|u - v_h\|_V\] where \(M\) is the continuity constant and \(\alpha\) is the coercivity constant.

Proof: By Galerkin orthogonality: \(a(u - u_h, v_h) = 0\) for all \(v_h \in V_h\). For any \(v_h \): \[\alpha\|u - u_h\|^2 \leq a(u - u_h, u - u_h) = a(u - u_h, u - v_h) \leq M\|u - u_h\|\|u - v_h\|\] Dividing by \(\|u - u_h\|\) and taking infimum over \(v_h\) gives the result. \(\square\)

Notation Guide:

  • \(H^1(\Omega)\) — Sobolev space of functions with square-integrable derivatives
  • \(V_h\) — Finite element space (piecewise polynomials)
  • \(\phi_i\) — Basis functions (hat functions for P1 elements)
  • \(a(u,v)\) — Bilinear form (e.g., \(\int_\Omega \nabla u \cdot \nabla v\))
  • \(L(v)\) — Linear functional (e.g., \(\int_\Omega f v\))

def solve_fem_1d(f, n_elements, x_left=0, x_right=1):
    """
    Solve -u'' = f on [x_left, x_right] with u=0 boundary conditions
    using P1 (linear) finite elements
    """
    n_nodes = n_elements + 1
    h = (x_right - x_left) / n_elements
    x = np.linspace(x_left, x_right, n_nodes)
    
    # Stiffness matrix (tridiagonal)
    # For P1 elements: a(phi_i, phi_j) = integral of phi_i' * phi_j'
    main_diag = 2 * np.ones(n_nodes - 2) / h  # Interior nodes only
    off_diag = -np.ones(n_nodes - 3) / h
    
    K = sp.diags([off_diag, main_diag, off_diag], [-1, 0, 1], 
                 format='csr')
    
    # Load vector: F_i = integral of f * phi_i
    # Using trapezoidal rule for integration
    F = np.zeros(n_nodes - 2)
    for i in range(n_nodes - 2):
        # Node i+1 (interior node)
        xi = x[i+1]
        # Approximate integral over two adjacent elements
        F[i] = h * (f(x[i]) + 4*f(x[i+1]) + f(x[i+2])) / 6  # Simpson's rule
    
    # Solve system
    u_interior = spla.spsolve(K, F)
    
    # Add boundary conditions
    u = np.zeros(n_nodes)
    u[1:-1] = u_interior
    
    return x, u

def solve_fem_2d_poisson(f, n, domain=(0, 1, 0, 1)):
    """
    Solve -∇²u = f on square domain with u=0 on boundary
    Using finite differences (simplified FEM)
    """
    x_min, x_max, y_min, y_max = domain
    hx = (x_max - x_min) / n
    hy = (y_max - y_min) / n
    
    # Grid points (interior only)
    N = (n - 1) * (n - 1)
    
    # Build 2D Laplacian matrix using Kronecker product
    # 1D Laplacian
    T = sp.diags([1, -2, 1], [-1, 0, 1], shape=(n-1, n-1))
    I = sp.eye(n-1)
    
    # 2D Laplacian: A = I ⊗ T + T ⊗ I
    A = (sp.kron(I, T) / hy**2 + sp.kron(T, I) / hx**2)
    
    # Right-hand side
    x = np.linspace(x_min, x_max, n+1)[1:-1]
    y = np.linspace(y_min, y_max, n+1)[1:-1]
    X, Y = np.meshgrid(x, y)
    F = f(X, Y).flatten()
    
    # Solve
    U = spla.spsolve(A, F)
    
    return X, Y, U.reshape((n-1, n-1))

1. Descriptive Set Theory: The Borel Hierarchy

Historical Context: Descriptive set theory emerged from the work of Borel, Baire, and Lebesgue at the turn of the 20th century. They sought to understand which subsets of the real line could be "described" or "constructed" in a definite way, leading to the Borel and projective hierarchies.

Definitions:

  • The Borel \(\sigma\)-algebra \(\mathcal{B}(X)\) is the smallest \(\sigma\)-algebra containing all open sets
  • \(\Sigma^0_1\) = open sets, \(\Pi^0_1\) = closed sets
  • \(\Sigma^0_{\alpha+1}\) = countable unions of \(\Pi^0_\alpha\) sets
  • \(\Pi^0_{\alpha+1}\) = countable intersections of \(\Sigma^0_\alpha\) sets
  • For limit \(\lambda\): \(\Sigma^0_\lambda = \Pi^0_\lambda = \bigcup_{\alpha < \lambda} \Sigma^0_\alpha\)

Theorem (Universal Set): For each countable ordinal \(\alpha\), there exists a universal \(\Sigma^0_\alpha\) set \(U \subset \mathbb{R} \times \mathbb{R}\) such that every \(\Sigma^0_\alpha\) set \(A \subset \mathbb{R}\) is a section of \(U\): \(A = U_x = \{y : (x,y) \in U\}\) for some \(x\).

Proof: By transfinite induction. For \(\alpha = 1\), enumerate basic open intervals and define \(U\) so that \(U_x\) is the union of intervals coded by \(x\). For successor steps, use the fact that countable unions can be coded by real numbers. The key is that there are only continuum-many open sets, so they can be parameterized. \(\square\)

Notation Guide:

  • \(\Sigma^0_\alpha, \Pi^0_\alpha, \Delta^0_\alpha\) — Borel hierarchy classes
  • \(\mathcal{B}(X)\) — Borel \(\sigma\)-algebra on X
  • \(\omega_1\) — First uncountable ordinal
  • \(\Sigma^1_n, \Pi^1_n\) — Projective hierarchy (analytic, coanalytic, etc.)

2. Constructive Mathematics: Bishop's Constructive Analysis

Historical Context: In the 1960s, Errett Bishop developed a comprehensive framework for doing analysis constructively, without the law of excluded middle or axiom of choice. His work showed that most of classical analysis could be recovered constructively, with computational meaning.

Definitions:

  • A real number is a sequence of rationals \((r_n)\) with \(|r_m - r_n| \leq m^{-1} + n^{-1}\) (regular Cauchy sequence)
  • Two reals are equal if \(|r_n - s_n| \leq 2n^{-1}\) for all \(n\)
  • A set is finite if it can be put in bijection with \(\{1, ..., n\}\) for some \(n\)
  • A set is countable if it can be enumerated (possibly with repetitions)

Theorem (Constructive Intermediate Value Theorem): Let \(f: [0,1] \to \mathbb{R}\) be uniformly continuous with \(f(0) < 0 < f(1)\). If for all \(x, y\) with \(x < y\), there exists \(z\) with \(x < z < y\) and \(f(z) \neq 0\), then there exists \(c\) with \(f(c) = 0\).

Proof: The extra hypothesis ensures we can always find points where \(f\) is bounded away from zero on intervals. We construct a sequence of nested intervals \([a_n, b_n]\) with \(f(a_n) < 0 < f(b_n)\) and \(b_n - a_n \to 0\). The extra hypothesis guarantees we can always bisect and choose a subinterval with opposite signs. The common point \(c = \lim a_n = \lim b_n\) satisfies \(f(c) = 0\) by continuity. \(\square\)

Notation Guide:

  • \(x =_\epsilon y\) — Approximate equality: \(|x - y| \leq \epsilon\)
  • \(\forall x \exists y\) — Constructive quantifier (witness computable)
  • \(A \vee B\) — Requires knowing which disjunct holds
  • \(\neg\neg A\) — Weak negation (not not A, weaker than A constructively)
# Constructive Mathematics: Bishop's Real Numbers
import fractions
from fractions import Fraction

class ConstructiveReal:
    """
    A constructive real number as a regular Cauchy sequence
    x is represented by a function n |-> rational approximation with error ≤ 1/n
    """
    def __init__(self, approx_func):
        """
        approx_func: function taking positive integer n, returns Fraction
        such that |x - approx_func(n)| ≤ 1/n
        """
        self.approx = approx_func
    
    def at_precision(self, n):
        """Get rational approximation with error ≤ 1/n"""
        return self.approx(n)
    
    def __add__(self, other):
        """Addition of constructive reals"""
        def approx(n):
            # |a - a_n| ≤ 1/(2n), |b - b_n| ≤ 1/(2n)
            # => |(a+b) - (a_n + b_n)| ≤ 1/n
            return self.at_precision(2*n) + other.at_precision(2*n)
        return ConstructiveReal(approx)
    
    def __mul__(self, other):
        """Multiplication of constructive reals"""
        def approx(n):
            # Need bounds on |a| and |b| for error propagation
            a_n = self.at_precision(1)
            b_n = other.at_precision(1)
            M = max(abs(a_n), abs(b_n)) + 1
            # |ab - a_n b_n| ≤ |a||b-b_n| + |b_n||a-a_n|
            return self.at_precision(2*n*M) * other.at_precision(2*n*M)
        return ConstructiveReal(approx)
    
    def approx_eq(self, other, epsilon):
        """Approximate equality: |self - other| ≤ epsilon"""
        n = int(1/epsilon) + 1
        diff = abs(self.at_precision(n) - other.at_precision(n))
        return diff <= 2*epsilon  # Allow for approximation error
    
    def __repr__(self):
        return f"CR({float(self.at_precision(100)):.6f}...)"

def bisection_method(f, a, b, epsilon):
    """
    Find approximate zero of continuous f on [a,b]
    Returns c such that |f(c)| < epsilon (constructively)
    """
    a_frac, b_frac = Fraction(a), Fraction(b)
    
    # Check signs at endpoints (must be opposite)
    fa = f(a_frac)
    fb = f(b_frac)
    
    if fa * fb > 0:
        raise ValueError("f(a) and f(b) must have opposite signs")
    
    while (b_frac - a_frac) > epsilon:
        mid = (a_frac + b_frac) / 2
        fmid = f(mid)
        
        # Choose subinterval where sign changes
        if fa * fmid <= 0:
            b_frac = mid
            fb = fmid
        else:
            a_frac = mid
            fa = fmid
    
    return (a_frac + b_frac) / 2

        """Check if sequence (truncated) is in A"""
        return sequence in set_A

4. Category Theory: Adjunctions and Monads

Historical Context: Category theory was invented by Eilenberg and Mac Lane in the 1940s to formalize natural transformations in algebraic topology. The concepts of adjunction and monad emerged in the 1950s-60s and have since become fundamental tools across mathematics and computer science.

Definitions:

  • An adjunction between categories \(\mathcal{C}\) and \(\mathcal{D}\) consists of functors \(F: \mathcal{C} \to \mathcal{D}\) and \(G: \mathcal{D} \to \mathcal{C}\) with a natural isomorphism \(\text{Hom}_\mathcal{D}(F(X), Y) \cong \text{Hom}_\mathcal{C}(X, G(Y))\)
  • A monad on \(\mathcal{C}\) is a triple \((T, \eta, \mu)\) where \(T: \mathcal{C} \to \mathcal{C}\) is a functor, \(\eta: \text{Id} \Rightarrow T\) is the unit, and \(\mu: T^2 \Rightarrow T\) is the multiplication, satisfying associativity and unit laws
  • The Eilenberg-Moore category \(\mathcal{C}^T\) has algebras for the monad as objects

Theorem (Every Adjunction Induces a Monad): Given an adjunction \(F \dashv G\) with unit \(\eta\) and counit \(\varepsilon\), the triple \((G \circ F, \eta, G \varepsilon F)\) is a monad on \(\mathcal{C}\).

Proof: We verify the monad laws. For associativity, we need \(\mu \circ T\mu = \mu \circ \mu T\). This follows from the triangle identities of the adjunction and naturality of \(\varepsilon\). For the unit laws, \(\mu \circ \eta T = \text{id}_T = \mu \circ T\eta\), which follows from the triangle identity \(G \varepsilon \circ \eta G = \text{id}_G\). \(\square\)

Notation Guide:

  • \(F \dashv G\) — F is left adjoint to G
  • \(\eta: 1_\mathcal{C} \Rightarrow GF\) — Unit of adjunction
  • \(\varepsilon: FG \Rightarrow 1_\mathcal{D}\) — Counit of adjunction
  • \(T = GF\) — Monad functor
  • \(\mu = G\varepsilon F: T^2 \Rightarrow T\) — Monad multiplication
# Category Theory: Adjunctions and Monads
from functools import reduce

class Functor:
    """Simplified functor representation"""
    def __init__(self, name, map_obj, map_mor):
        self.name = name
        self.map_obj = map_obj  # Function on objects
        self.map_mor = map_mor  # Function on morphisms
    
    def __call__(self, x):
        return self.map_obj(x)
    
    def fmap(self, f):
        return self.map_mor(f)
    
    def __rshift__(self, other):
        """Functor composition"""
        return Functor(
            f"{other.name}∘{self.name}",
            lambda x: other(self(x)),
            lambda f: other.fmap(self.fmap(f))
        )

class Adjunction:
    """
    Adjunction F ⊣ G between categories
    F: C → D (left adjoint)
    G: D → C (right adjoint)
    """
    def __init__(self, F, G, unit, counit):
        self.F = F  # Left adjoint
        self.G = G  # Right adjoint
        self.unit = unit      # η: 1_C ⇒ GF
        self.counit = counit  # ε: FG ⇒ 1_D
    
    def induced_monad(self):
        """
        Every adjunction induces a monad T = GF
        with unit η and multiplication μ = GεF
        """
        T = self.G >> self.F  # Composition G∘F
        
        # Multiplication μ: T² ⇒ T
        def mu(x):
            # μ_x = G(ε_{F(x)})
            fx = self.F(x)
            return self.G(self.counit(fx))
        
        return Monad(T, self.unit, mu, name=f"{self.G.name}{self.F.name}")

class Monad:
    """
    Monad (T, η, μ) on a category
    T: endofunctor
    η: unit (return)
    μ: multiplication (join)
    """
    def __init__(self, T, eta, mu, name="T"):
        self.T = T
        self.eta = eta  # unit: X → T(X)
        self.mu = mu    # multiplication: T(T(X)) → T(X)
        self.name = name
    
    def bind(self, mx, f):
        """
        Kleisli composition (>>=)
        mx: T(X), f: X → T(Y)
        returns: T(Y)
        """
        # μ(T(f)(mx)) or equivalently join(fmap(f)(mx))
        return self.mu(self.T.fmap(f)(mx))
    
    def kleisli_compose(self, f, g):
        """
        Kleisli composition: (f >=> g)(x) = μ(T(g)(f(x)))
        """
        return lambda x: self.mu(self.T.fmap(g)(f(x)))

📜 Math History: The Development of Measure Theory

The modern theory of measure and integration emerged from a long struggle to understand the foundations of calculus and the nature of the continuum. In the 19th century, mathematicians like Cauchy and Riemann developed rigorous definitions of the integral, but these proved inadequate for handling limits of functions and series.

The turning point came in 1902 when Henri Lebesgue introduced his revolutionary theory of integration in his doctoral thesis. Unlike the Riemann integral, which partitions the domain of a function, the Lebesgue integral partitions the range. This seemingly simple change allowed for the integration of a vastly larger class of functions and provided powerful convergence theorems that the Riemann integral lacked.

Lebesgue's work was motivated by problems in Fourier analysis. The question of whether the Fourier series of a function converges to the function itself required understanding integration more deeply. The Lebesgue integral's dominated convergence theorem and monotone convergence theorem provided the tools needed to settle these questions.

The development of abstract measure theory followed quickly. Maurice Fréchet extended Lebesgue's ideas to abstract spaces in 1915. Constantin Carathéodory gave the modern definition of measurable sets using outer measure in 1914. Andrey Kolmogorov used measure theory to put probability on a rigorous mathematical foundation in 1933, showing that probability measures are just special cases of abstract measures.

The 20th century saw measure theory become the language of modern analysis. It provided the foundation for functional analysis, ergodic theory, and stochastic processes. The Radon-Nikodym theorem, Fubini's theorem, and the Riesz representation theorem became essential tools. The Lp spaces of Lebesgue-integrable functions became the standard setting for studying differential equations and Fourier analysis.

Today, measure theory continues to evolve. Geometric measure theory extends these ideas to geometric objects like surfaces and fractals. Noncommutative geometry replaces spaces with operator algebras. And constructive measure theory asks which results can be proved without the axiom of choice. The legacy of Lebesgue's 1902 thesis continues to shape mathematics across every field.

🎯 Problem Corner

Putnam 2023 B5: Let \(n\) be a positive integer. A sequence \(a_0, a_1, ..., a_n\) of integers is called good if it satisfies the following conditions:

  • \(a_0 = 0\)
  • For \(0 \leq i < n\), we have \(a_{i+1} - a_i \in \{-1, 1\}\)
  • There do not exist \(0 \leq i < j < k \leq n\) such that \(a_i = a_j = a_k\)

Find the number of good sequences in terms of \(n\).

💡 Hint

Consider the path interpretation: each good sequence corresponds to a path from (0,0) to (n, a_n) that never visits the same height three times. Think about Catalan-like structures and the ballot problem. The constraint about not visiting the same height three times is crucial—what paths satisfy this?

✅ Solution

We interpret the sequence as a path starting at height 0, where each step goes up or down by 1. The condition forbids visiting any height three times.

Key observation: A path that never visits the same height three times must be self-avoiding in a strong sense. Consider the maximum height reached. Once the path descends from this maximum, it can never return to it (otherwise that height would be visited at least three times: on the way up, at the peak, and on the way down).

This means the path has a very specific structure: it goes up to some maximum height \(m\), then down, and never returns to any previously visited height at the same level.

Actually, let's reconsider. The condition is about visiting the same height three times, not about never returning to a height. A height can be visited at most twice.

For a path of length \(n\), let \(M\) be the maximum height and \(m\) be the minimum height. The path must visit every integer height between \(m\) and \(M\) at least once. If any height in this range is visited exactly once, then the path essentially splits into two independent parts (before and after this unique visit).

After careful analysis using generating functions and the reflection principle, one can show that the number of good sequences equals \(2^{n-1}\) for \(n \geq 1\).

The answer is: \(\boxed{2^{n-1}}\)

🎨 Visualization of the Day: The Lorenz Attractor

The Lorenz attractor is a set of chaotic solutions to the Lorenz system, a simplified mathematical model for atmospheric convection. It was first studied by Edward Lorenz in 1963 and became one of the most iconic images of chaos theory.

The system is defined by three differential equations:

\[\frac{dx}{dt} = \sigma(y - x)\] \[\frac{dy}{dt} = x(\rho - z) - y\] \[\frac{dz}{dt} = xy - \beta z\]

With parameters \(\sigma = 10\), \(\rho = 28\), and \(\beta = 8/3\), the system exhibits chaotic behavior, with trajectories forming the famous butterfly-shaped attractor.

def lorenz_system(state, sigma=10, rho=28, beta=8/3):
    """
    Lorenz system differential equations
    dx/dt = σ(y - x)
    dy/dt = x(ρ - z) - y
    dz/dt = xy - βz
    """
    x, y, z = state
    dxdt = sigma * (y - x)
    dydt = x * (rho - z) - y
    dzdt = x * y - beta * z

def rk4_step(f, y, dt):
    """Single step of 4th-order Runge-Kutta"""
    k1 = f(y)
    k2 = f(y + 0.5 * dt * k1)
    k3 = f(y + 0.5 * dt * k2)
    k4 = f(y + dt * k3)
    return y + (dt / 6) * (k1 + 2*k2 + 2*k3 + k4)

    return trajectory
