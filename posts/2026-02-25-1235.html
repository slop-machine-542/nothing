Algebraic Topology: Simplicial Homology

Motivation

Homology theory provides a way to count holes of various dimensions in topological spaces. Unlike the fundamental group which captures one-dimensional holes (loops), homology captures higher-dimensional voids and is abelian (commutative), making it computationally tractable. It has become an essential tool in data analysis, robotics, and physics.

Definitions

Simplicial Complex: A collection \(K\) of simplices such that: (1) every face of a simplex in \(K\) is in \(K\), and (2) the intersection of any two simplices in \(K\) is a face of both.

Chain Complex: A sequence of abelian groups \(C_n\) connected by boundary homomorphisms \(\partial_n : C_n \to C_{n-1}\) satisfying \(\partial_{n-1} \circ \partial_n = 0\).

Homology Group: \(H_n(X) = \ker(\partial_n) / \text{im}(\partial_{n+1})\). Elements of \(\ker(\partial_n)\) are called cycles; elements of \(\text{im}(\partial_{n+1})\) are called boundaries.

Theorem and Proof

Theorem (Betti Numbers): For a finite simplicial complex \(K\), the \(n\)-th Betti number \(\beta_n = \dim H_n(K; \mathbb{Q})\) equals the number of \(n\)-dimensional holes in \(K\).

Proof Sketch: The rank-nullity theorem applied to the chain complex gives \(\beta_n = \text{rank}(Z_n) - \text{rank}(B_n)\) where \(Z_n = \ker(\partial_n)\) and \(B_n = \text{im}(\partial_{n+1})\). Geometrically, cycles that are not boundaries correspond to \(n\)-dimensional voids. For a triangulated torus, \(\beta_0 = 1\) (connected), \(\beta_1 = 2\) (two independent loops), \(\beta_2 = 1\) (the void inside). ∎

Notation Guide

  • \(C_n(K)\) — group of \(n\)-chains
  • \(\partial_n\) — boundary operator
  • \(H_n(K)\) — \(n\)-th homology group
  • \(\beta_n\) — \(n\)-th Betti number
  • \(\chi(K) = \sum (-1)^n \beta_n\) — Euler characteristic

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import spsolve

class SimplicialHomology:
    """Compute simplicial homology of simple complexes."""
    
    def __init__(self, simplices):
        """
        simplices: list of tuples, each tuple is a simplex
        """
        self.simplices = sorted(set(tuple(sorted(s)) for s in simplices))
        self.max_dim = max(len(s) - 1 for s in self.simplices)
        self._build_chain_complex()
    
    def _build_chain_complex(self):
        """Build boundary matrices for each dimension."""
        self.boundary_matrices = {}
        
        # Group simplices by dimension
        by_dim = {d: [] for d in range(self.max_dim + 1)}
        for s in self.simplices:
            by_dim[len(s) - 1].append(s)
        
        self.simplices_by_dim = by_dim
        
        # Build boundary matrices
        for d in range(1, self.max_dim + 1):
            if not by_dim[d] or not by_dim[d-1]:
                continue
            
            n_d = len(by_dim[d])
            n_dm1 = len(by_dim[d-1])
            
            # Create boundary matrix
            rows, cols, data = [], [], []
            for j, simplex in enumerate(by_dim[d]):
                # All faces of this simplex
                for i, face in enumerate(by_dim[d-1]):
                    if set(face).issubset(set(simplex)):
                        # Compute orientation
                        sign = self._orientation(simplex, face)
                        rows.append(i)
                        cols.append(j)
                        data.append(sign)
            
            self.boundary_matrices[d] = csr_matrix(
                (data, (rows, cols)), shape=(n_dm1, n_d)
            )
    
    def _orientation(self, simplex, face):
        """Compute orientation of face in simplex."""
        missing = set(simplex) - set(face)
        if len(missing) != 1:
            return 0
        missing_idx = simplex.index(list(missing)[0])
        return (-1) ** missing_idx
    
    def betti_numbers(self):
        """Compute Betti numbers using rank-nullity."""
        betti = []
        
        for d in range(self.max_dim + 1):
            if d == 0:
                # H_0: ker(∂_0) / im(∂_1)
                if 1 in self.boundary_matrices:
                    rank_im = np.linalg.matrix_rank(
                        self.boundary_matrices[1].toarray()
                    )
                else:
                    rank_im = 0
                n_0 = len(self.simplices_by_dim[0])
                beta_0 = n_0 - rank_im
                betti.append(beta_0)
            else:
                # H_d: ker(∂_d) / im(∂_{d+1})
                if d in self.boundary_matrices:
                    n_d = self.boundary_matrices[d].shape[1]
                    rank_ker = n_d - np.linalg.matrix_rank(
                        self.boundary_matrices[d].toarray()
                    )
                else:
                    rank_ker = len(self.simplices_by_dim[d]) if d in self.simplices_by_dim else 0
                
                if d + 1 in self.boundary_matrices:
                    rank_im = np.linalg.matrix_rank(
                        self.boundary_matrices[d + 1].toarray()
                    )
                else:
                    rank_im = 0
                
                betti.append(rank_ker - rank_im)
        
        return betti

Differential Geometry: Curvature of Surfaces

Motivation

Curvature measures how much a geometric object deviates from being flat. For surfaces embedded in \(\mathbb{R}^3\), Gaussian curvature provides profound insights: the Gauss-Bonnet theorem connects local curvature to global topology. This has applications in general relativity, computer graphics, and architectural design.

Definitions

First Fundamental Form: For a parametrized surface \(\mathbf{r}(u,v)\), the metric is \(I = E\,du^2 + 2F\,du\,dv + G\,dv^2\) where \(E = \mathbf{r}_u \cdot \mathbf{r}_u\), \(F = \mathbf{r}_u \cdot \mathbf{r}_v\), \(G = \mathbf{r}_v \cdot \mathbf{r}_v\).

Second Fundamental Form: \(II = L\,du^2 + 2M\,du\,dv + N\,dv^2\) where \(L = \mathbf{r}_{uu} \cdot \mathbf{n}\), \(M = \mathbf{r}_{uv} \cdot \mathbf{n}\), \(N = \mathbf{r}_{vv} \cdot \mathbf{n}\), and \(\mathbf{n}\) is the unit normal.

Gaussian Curvature: \(K = \frac{LN - M^2}{EG - F^2}\).

Theorem and Proof

Theorema Egregium (Gauss): Gaussian curvature is intrinsic — it depends only on the first fundamental form, not on the embedding in \(\mathbb{R}^3\).

Proof Sketch: Express \(K\) using Christoffel symbols which depend only on \(E, F, G\) and their derivatives. The Brioschi formula gives: \[K = \frac{1}{(EG-F^2)^2}\left(\det\begin{pmatrix} -\frac{1}{2}E_{vv} + F_{uv} - \frac{1}{2}G_{uu} & \frac{1}{2}E_u & F_u - \frac{1}{2}E_v \\ F_v - \frac{1}{2}G_u & E & F \\ \frac{1}{2}G_v & F & G \end{pmatrix} - \det\begin{pmatrix} 0 & \frac{1}{2}E_v & \frac{1}{2}G_u \\ \frac{1}{2}E_v & E & F \\ \frac{1}{2}G_u & F & G \end{pmatrix}\right)\] Since this involves only the metric coefficients, \(K\) is intrinsic. ∎

Notation Guide

  • \(E, F, G\) — coefficients of first fundamental form
  • \(L, M, N\) — coefficients of second fundamental form
  • \(K\) — Gaussian curvature
  • \(H = \frac{EN + GL - 2FM}{2(EG-F^2)}\) — mean curvature
  • \(\kappa_1, \kappa_2\) — principal curvatures

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class SurfaceCurvature:
    """Compute curvature for parametrized surfaces."""
    
    def __init__(self, r_func, u_range, v_range):
        """
        r_func: function(u, v) -> (x, y, z)
        """
        self.r = r_func
        self.u_range = u_range
        self.v_range = v_range
    
    def compute_fundamental_forms(self, u, v, h=1e-5):
        """Compute first and second fundamental forms at (u,v)."""
        # First derivatives
        r_u = (self.r(u + h, v) - self.r(u - h, v)) / (2 * h)
        r_v = (self.r(u, v + h) - self.r(u, v - h)) / (2 * h)
        
        # First fundamental form
        E = np.dot(r_u, r_u)
        F = np.dot(r_u, r_v)
        G = np.dot(r_v, r_v)
        
        # Normal vector
        n = np.cross(r_u, r_v)
        n = n / np.linalg.norm(n)
        
        # Second derivatives
        r_uu = (self.r(u + h, v) - 2 * self.r(u, v) + self.r(u - h, v)) / h**2
        r_vv = (self.r(u, v + h) - 2 * self.r(u, v) + self.r(u, v - h)) / h**2
        r_uv = (self.r(u + h, v + h) - self.r(u + h, v - h) 
                - self.r(u - h, v + h) + self.r(u - h, v - h)) / (4 * h**2)
        
        # Second fundamental form
        L = np.dot(r_uu, n)
        M = np.dot(r_uv, n)
        N = np.dot(r_vv, n)
        
        return (E, F, G), (L, M, N)
    
    def gaussian_curvature(self, u, v):
        """Compute Gaussian curvature K at (u,v)."""
        (E, F, G), (L, M, N) = self.compute_fundamental_forms(u, v)
        K = (L * N - M**2) / (E * G - F**2)
        return K
    
    def mean_curvature(self, u, v):
        """Compute mean curvature H at (u,v)."""
        (E, F, G), (L, M, N) = self.compute_fundamental_forms(u, v)
        H = (E * N + G * L - 2 * F * M) / (2 * (E * G - F**2))
        return H
    
    def principal_curvatures(self, u, v):
        """Compute principal curvatures."""
        K = self.gaussian_curvature(u, v)
        H = self.mean_curvature(u, v)
        # κ² - 2Hκ + K = 0
        discriminant = max(0, H**2 - K)
        k1 = H + np.sqrt(discriminant)
        k2 = H - np.sqrt(discriminant)
        return k1, k2
    
    def plot_curvature(self, resolution=50):
        """Plot surface colored by Gaussian curvature."""
        u = np.linspace(self.u_range[0], self.u_range[1], resolution)
        v = np.linspace(self.v_range[0], self.v_range[1], resolution)
        U, V = np.meshgrid(u, v)
        
        # Compute surface points
        X, Y, Z = [], [], []
        K_values = []
        
        for i in range(resolution):
            for j in range(resolution):
                point = self.r(U[i, j], V[i, j])
                X.append(point[0])
                Y.append(point[1])
                Z.append(point[2])
                K_values.append(self.gaussian_curvature(U[i, j], V[i, j]))
        
        X = np.array(X).reshape(resolution, resolution)
        Y = np.array(Y).reshape(resolution, resolution)
        Z = np.array(Z).reshape(resolution, resolution)
        K_values = np.array(K_values).reshape(resolution, resolution)
        
        fig = plt.figure(figsize=(12, 5))
        
        # Surface plot
        ax1 = fig.add_subplot(121, projection='3d')
        surf = ax1.plot_surface(X, Y, Z, facecolors=plt.cm.coolwarm(
            (K_values - K_values.min()) / (K_values.max() - K_values.min())
        ), alpha=0.9)
        ax1.set_title('Surface Colored by Gaussian Curvature')
        
        # Curvature heatmap
        ax2 = fig.add_subplot(122)
        im = ax2.imshow(K_values, extent=[self.u_range[0], self.u_range[1], 
                                           self.v_range[0], self.v_range[1]],
                        origin='lower', cmap='coolwarm')
        ax2.set_xlabel('u')
        ax2.set_ylabel('v')
        ax2.set_title('Gaussian Curvature Heatmap')
        plt.colorbar(im, ax=ax2)
        
        return fig

Representation Theory: Characters and Schur's Lemma

Motivation

Representation theory studies abstract algebraic structures by representing their elements as linear transformations of vector spaces. This allows us to use linear algebra to understand groups, making abstract symmetries concrete and computable. It has profound applications in quantum mechanics, crystallography, and harmonic analysis.

Definitions

Representation: A homomorphism \(\rho: G \to GL(V)\) where \(G\) is a group and \(V\) is a vector space. We write \(g \cdot v = \rho(g)(v)\).

Character: The character of a representation is \(\chi_\rho(g) = \text{tr}(\rho(g))\).

Irreducible Representation: A representation with no proper nonzero invariant subspaces.

Theorem and Proof

Schur's Lemma: Let \(\rho_1: G \to GL(V_1)\) and \(\rho_2: G \to GL(V_2)\) be irreducible representations over an algebraically closed field, and let \(T: V_1 \to V_2\) be an intertwining operator (\(T \circ \rho_1(g) = \rho_2(g) \circ T\) for all \(g \in G\)). Then:
(a) If \(\rho_1 \not\cong \rho_2\), then \(T = 0\).
(b) If \(\rho_1 = \rho_2\), then \(T = \lambda I\) for some scalar \(\lambda\).

Proof: (a) \(\ker(T)\) is \(G\)-invariant, so by irreducibility, \(\ker(T) = 0\) or \(V_1\). If \(\ker(T) = 0\), then \(T\) is injective. Similarly, \(\text{im}(T)\) is \(G\)-invariant, so \(\text{im}(T) = 0\) or \(V_2\). If \(\text{im}(T) = V_2\), then \(T\) is an isomorphism, contradicting \(\rho_1 \not\cong \rho_2\). Thus \(T = 0\).
(b) Since the field is algebraically closed, \(T\) has an eigenvalue \(\lambda\). Then \(T - \lambda I\) is an intertwining operator with nontrivial kernel. By (a) applied to this operator, \(T - \lambda I = 0\). ∎

Notation Guide

  • \(\rho, \sigma\) — representations
  • \(\chi_\rho\) — character of \(\rho\)
  • \(V^G = \{v \in V : g \cdot v = v \text{ for all } g \in G\}\) — invariant subspace
  • \(\langle \chi_1, \chi_2 \rangle = \frac{1}{|G|}\sum_{g \in G} \chi_1(g)\overline{\chi_2(g)}\) — inner product
  • \(\hat{G}\) — set of irreducible representations

import numpy as np
from itertools import product

class RepresentationTheory:
    """Basic representation theory computations."""
    
    def __init__(self, group_elements, multiplication_table):
        """
        group_elements: list of group elements (as indices 0, 1, 2, ...)
        multiplication_table: table[i][j] = index of element i * j
        """
        self.elements = group_elements
        self.mult = multiplication_table
        self.order = len(group_elements)
    
    def is_representation(self, matrices):
        """Check if matrices form a representation."""
        for i, g in enumerate(self.elements):
            for j, h in enumerate(self.elements):
                gh = self.mult[i][j]
                if not np.allclose(matrices[i] @ matrices[j], matrices[gh]):
                    return False
        return True
    
    def character(self, matrix_rep):
        """Compute character of a representation."""
        return np.array([np.trace(m) for m in matrix_rep])
    
    def character_inner_product(self, chi1, chi2):
        """Compute ⟨χ₁, χ₂⟩ = (1/|G|) Σ_g χ₁(g) χ₂(g)⁻¹."""
        return np.sum(chi1 * np.conj(chi2)) / self.order
    
    def is_irreducible(self, matrix_rep):
        """Check irreducibility using character inner product."""
        chi = self.character(matrix_rep)
        return np.isclose(self.character_inner_product(chi, chi), 1.0)
    
    def regular_representation(self):
        """Construct the regular representation."""
        n = self.order
        reg_rep = []
        for i in range(n):
            mat = np.zeros((n, n))
            for j in range(n):
                k = self.mult[i][j]
                mat[k, j] = 1
            reg_rep.append(mat)
        return reg_rep
    
    def decompose_regular(self, irreps):
        """Decompose regular representation into irreps."""
        reg = self.regular_representation()
        chi_reg = self.character(reg)
        
        multiplicities = {}
        for name, irrep in irreps.items():
            chi_irr = self.character(irrep)
            mult = int(round(self.character_inner_product(chi_reg, chi_irr)))
            if mult > 0:
                multiplicities[name] = mult
        
        return multiplicities

Support Vector Machines: Maximum Margin Classification

Real-World Motivation

Support Vector Machines (SVMs) are powerful supervised learning models for classification and regression. They find the optimal hyperplane that maximizes the margin between classes, providing good generalization. SVMs have been successfully applied to text categorization, image recognition, bioinformatics, and financial forecasting.

Definitions

Primal Problem: Given training data \(\{(\mathbf{x}_i, y_i)\}_{i=1}^n\) with \(\mathbf{x}_i \in \mathbb{R}^d\) and \(y_i \in \{-1, +1\}\), find \(\mathbf{w}, b\) minimizing: \[\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^n \max(0, 1 - y_i(\mathbf{w}^T\mathbf{x}_i + b))\]

Dual Problem: Maximize: \[\sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j K(\mathbf{x}_i, \mathbf{x}_j)\] subject to \(0 \leq \alpha_i \leq C\) and \(\sum_i \alpha_i y_i = 0\).

Kernel Function: \(K(\mathbf{x}, \mathbf{x}') = \phi(\mathbf{x})^T\phi(\mathbf{x}')\) where \(\phi\) maps to a higher-dimensional feature space.

Theorem and Proof

Theorem (Representer Theorem): The optimal solution to the SVM dual problem has the form \(\mathbf{w} = \sum_{i=1}^n \alpha_i y_i \phi(\mathbf{x}_i)\), where only support vectors (points with \(\alpha_i > 0\)) contribute.

Proof: By the KKT conditions, \(\alpha_i > 0\) implies \(y_i(\mathbf{w}^T\phi(\mathbf{x}_i) + b) = 1\) (points on the margin). The decision function is: \[f(\mathbf{x}) = \text{sign}\left(\sum_{i=1}^n \alpha_i y_i K(\mathbf{x}_i, \mathbf{x}) + b\right)\] Only points with \(\alpha_i > 0\) appear in the sum. ∎

Notation Guide

  • \(\mathbf{w}\) — weight vector (normal to hyperplane)
  • \(b\) — bias term
  • \(C\) — regularization parameter
  • \(\alpha_i\) — Lagrange multipliers
  • \(K(\mathbf{x}, \mathbf{x}')\) — kernel function
  • \(\phi\) — feature map

import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

class SupportVectorMachine:
    """Support Vector Machine with kernel methods."""
    
    def __init__(self, kernel='rbf', C=1.0, gamma=0.1):
        self.kernel = kernel
        self.C = C
        self.gamma = gamma
        self.alpha = None
        self.support_vectors = None
        self.support_labels = None
        self.b = 0
    
    def _kernel(self, x1, x2):
        """Compute kernel function."""
        if self.kernel == 'linear':
            return np.dot(x1, x2)
        elif self.kernel == 'rbf':
            return np.exp(-self.gamma * np.sum((x1 - x2)**2))
        elif self.kernel == 'poly':
            return (1 + np.dot(x1, x2))**3
        else:
            raise ValueError(f"Unknown kernel: {self.kernel}")
    
    def fit(self, X, y):
        """Train SVM using dual formulation."""
        n = len(X)
        self.X_train = X
        self.y_train = y
        
        # Compute kernel matrix
        K = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                K[i, j] = self._kernel(X[i], X[j])
        
        # Dual objective: maximize Σα - 1/2 ΣαᵢαⱼyᵢyⱼK(xᵢ,xⱼ)
        # Equivalent to minimize: 1/2 ΣαᵢαⱼyᵢyⱼK(xᵢ,xⱼ) - Σα
        def objective(alpha):
            return 0.5 * np.sum(alpha[:, None] * alpha[None, :] * 
                               y[:, None] * y[None, :] * K) - np.sum(alpha)
        
        # Constraints: 0 ≤ α ≤ C, Σαᵢyᵢ = 0
        constraints = [
            {'type': 'eq', 'fun': lambda a: np.dot(a, y)}
        ]
        bounds = [(0, self.C) for _ in range(n)]
        
        # Solve
        result = minimize(objective, np.zeros(n), method='SLSQP',
                         bounds=bounds, constraints=constraints)
        self.alpha = result.x
        
        # Identify support vectors
        sv_threshold = 1e-5
        sv_indices = np.where(self.alpha > sv_threshold)[0]
        self.support_vectors = X[sv_indices]
        self.support_labels = y[sv_indices]
        self.alpha_sv = self.alpha[sv_indices]
        
        # Compute bias
        # For any support vector with 0 < α < C: y(b + ΣαⱼyⱼK(xⱼ,x)) = 1
        margin_sv = np.where((self.alpha > sv_threshold) & 
                            (self.alpha < self.C - sv_threshold))[0]
        if len(margin_sv) > 0:
            i = margin_sv[0]
            self.b = y[i] - np.sum(self.alpha_sv * self.support_labels * 
                                   [self._kernel(self.support_vectors[j], X[i]) 
                                    for j in range(len(self.support_vectors))])
        else:
            self.b = 0
        
        return self
    
    def predict(self, X):
        """Predict labels for new data."""
        predictions = []
        for x in X:
            score = np.sum(self.alpha_sv * self.support_labels * 
                          [self._kernel(sv, x) for sv in self.support_vectors]) + self.b
            predictions.append(np.sign(score))
        return np.array(predictions)
    
    def decision_function(self, X):
        """Compute decision function values."""
        scores = []
        for x in X:
            score = np.sum(self.alpha_sv * self.support_labels * 
                          [self._kernel(sv, x) for sv in self.support_vectors]) + self.b
            scores.append(score)
        return np.array(scores)

Convex Optimization: Duality and Algorithms

Real-World Motivation

Convex optimization problems have the remarkable property that any local minimum is also a global minimum. This makes them tractable and reliable for large-scale applications. They appear in portfolio optimization, signal processing, machine learning, control systems, and engineering design. Modern solvers can handle problems with millions of variables.

Definitions

Convex Set: A set \(C\) is convex if for all \(\mathbf{x}, \mathbf{y} \in C\) and \(\theta \in [0,1]\): \[\theta \mathbf{x} + (1-\theta)\mathbf{y} \in C\]

Convex Function: A function \(f\) is convex if its domain is convex and for all \(\mathbf{x}, \mathbf{y}\) in the domain and \(\theta \in [0,1]\): \[f(\theta \mathbf{x} + (1-\theta)\mathbf{y}) \leq \theta f(\mathbf{x}) + (1-\theta)f(\mathbf{y})\]

Lagrangian: For the problem \(\min f_0(\mathbf{x})\) subject to \(f_i(\mathbf{x}) \leq 0\) and \(h_j(\mathbf{x}) = 0\): \[\mathcal{L}(\mathbf{x}, \lambda, \nu) = f_0(\mathbf{x}) + \sum_i \lambda_i f_i(\mathbf{x}) + \sum_j \nu_j h_j(\mathbf{x})\]

Theorem and Proof

Strong Duality Theorem: For a convex optimization problem with Slater's condition (existence of a strictly feasible point), the optimal primal value \(p^*\) equals the optimal dual value \(d^*\).

Proof Sketch: Consider the set \(\mathcal{A} = \{(u, v, t) : \exists \mathbf{x}, f_i(\mathbf{x}) \leq u_i, h_j(\mathbf{x}) = v_j, f_0(\mathbf{x}) \leq t\}\). This is convex. Define the supporting hyperplane to \(\mathcal{A}\) at \((0, 0, p^*)\). The hyperplane gives dual feasible \((\lambda, \nu, \mu)\) with \(\mu p^* = d^*\). Under Slater's condition, \(\mu > 0\), yielding strong duality. ∎

Notation Guide

  • \(f_0\) — objective function
  • \(f_i\) — inequality constraint functions
  • \(h_j\) — equality constraint functions
  • \(\lambda_i\) — Lagrange multipliers for inequalities
  • \(\nu_j\) — Lagrange multipliers for equalities
  • \(g(\lambda, \nu) = \inf_{\mathbf{x}} \mathcal{L}(\mathbf{x}, \lambda, \nu)\) — dual function
  • \(p^*, d^*\) — primal and dual optimal values

from scipy.optimize import minimize
import matplotlib.pyplot as plt

class ConvexOptimization:
    """Convex optimization problem formulations."""
    
    @staticmethod
    def quadratic_program(P, q, G=None, h=None, A=None, b=None):
        """
        Solve: minimize 1/2 x^T P x + q^T x
               subject to: Gx <= h, Ax = b
        """
        n = len(q)
        
        def objective(x):
            return 0.5 * x @ P @ x + q @ x
        
        def gradient(x):
            return P @ x + q
        
        constraints = []
        if G is not None and h is not None:
            constraints.append({'type': 'ineq', 'fun': lambda x: h - G @ x})
        if A is not None and b is not None:
            constraints.append({'type': 'eq', 'fun': lambda x: A @ x - b})
        
        result = minimize(objective, np.zeros(n), jac=gradient,
                         method='SLSQP', constraints=constraints)
        return result
    
    @staticmethod
    def portfolio_optimization(returns, cov_matrix, target_return=None, 
                               risk_aversion=1.0):
        """
        Markowitz portfolio optimization.
        minimize: risk_aversion * w^T Σ w - μ^T w
        subject to: sum(w) = 1, w >= 0
        """
        n = len(returns)
        
        def objective(w):
            risk = w @ cov_matrix @ w
            ret = returns @ w
            if target_return is not None:
                return risk  # Minimize risk for target return
            return risk_aversion * risk - ret
        
        constraints = [
            {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        ]
        
        if target_return is not None:
            constraints.append(
                {'type': 'eq', 'fun': lambda w: returns @ w - target_return}
            )
        
        bounds = [(0, None) for _ in range(n)]
        
        result = minimize(objective, np.ones(n)/n, method='SLSQP',
                         bounds=bounds, constraints=constraints)
        return result
    
    @staticmethod
    def lasso_regression(X, y, lambda_reg):
        """
        LASSO: minimize ||Xw - y||^2 + lambda * ||w||_1
        """
        n_features = X.shape[1]
        
        def objective(w):
            residual = X @ w - y
            return residual @ residual + lambda_reg * np.sum(np.abs(w))
        
        result = minimize(objective, np.zeros(n_features), method='Powell')
        return result
    
    @staticmethod
    def compute_dual_gap(primal_obj, dual_obj):
        """Compute duality gap."""
        if dual_obj == 0:
            return float('inf')
        return (primal_obj - dual_obj) / abs(dual_obj)

Number Theory in Cryptography: RSA and Beyond

Real-World Motivation

Modern cryptography relies heavily on number theory. The RSA algorithm, Diffie-Hellman key exchange, and elliptic curve cryptography all depend on computational hardness assumptions from number theory: factoring large integers and computing discrete logarithms. These systems secure internet communications, financial transactions, and sensitive data worldwide.

Definitions

RSA Setup: Choose primes \(p, q\), compute \(n = pq\) and \(\phi(n) = (p-1)(q-1)\). Choose \(e\) with \(\gcd(e, \phi(n)) = 1\), compute \(d \equiv e^{-1} \pmod{\phi(n)}\). Public key: \((n, e)\), Private key: \(d\).

Encryption: \(c = m^e \pmod{n}\)

Decryption: \(m = c^d \pmod{n}\)

Discrete Logarithm: Given \(g, h \in \mathbb{G}\) where \(\mathbb{G}\) is a cyclic group, find \(x\) such that \(g^x = h\).

Theorem and Proof

Theorem (RSA Correctness): For all \(m \in \{0, 1, \ldots, n-1\}\): \[(m^e)^d \equiv m \pmod{n}\]

Proof: Since \(ed \equiv 1 \pmod{\phi(n)}\), we have \(ed = 1 + k\phi(n)\) for some integer \(k\). By Euler's theorem, \(m^{\phi(n)} \equiv 1 \pmod{n}\) when \(\gcd(m, n) = 1\). Thus: \[m^{ed} = m^{1 + k\phi(n)} = m \cdot (m^{\phi(n)})^k \equiv m \pmod{n}\] For \(\gcd(m, n) \neq 1\), use the Chinese Remainder Theorem: verify separately mod \(p\) and mod \(q\). ∎

Notation Guide

  • \(n\) — RSA modulus
  • \(\phi(n)\) — Euler's totient function
  • \(e\) — encryption exponent
  • \(d\) — decryption exponent
  • \(m\) — message
  • \(c\) — ciphertext
  • \(\mathbb{Z}_n^*\) — multiplicative group modulo \(n\)

import numpy as np
from math import gcd
import secrets

class NumberTheoryCrypto:
    """Number-theoretic cryptography implementations."""
    
    @staticmethod
    def mod_exp(base, exp, mod):
        """Fast modular exponentiation."""
        result = 1
        base = base % mod
        while exp > 0:
            if exp & 1:
                result = (result * base) % mod
            base = (base * base) % mod
            exp >>= 1
        return result
    
    @staticmethod
    def extended_gcd(a, b):
        """Extended Euclidean algorithm."""
        if a == 0:
            return b, 0, 1
        gcd_val, x1, y1 = NumberTheoryCrypto.extended_gcd(b % a, a)
        x = y1 - (b // a) * x1
        y = x1
        return gcd_val, x, y
    
    @staticmethod
    def mod_inverse(a, m):
        """Compute modular inverse using extended Euclidean algorithm."""
        g, x, _ = NumberTheoryCrypto.extended_gcd(a % m, m)
        if g != 1:
            return None  # Inverse doesn't exist
        return (x % m + m) % m
    
    @staticmethod
    def miller_rabin(n, k=10):
        """Miller-Rabin primality test."""
        if n < 2:
            return False
        if n == 2 or n == 3:
            return True
        if n % 2 == 0:
            return False
        
        # Write n-1 as 2^r * d
        r, d = 0, n - 1
        while d % 2 == 0:
            r += 1
            d //= 2
        
        for _ in range(k):
            a = secrets.randbelow(n - 3) + 2
            x = NumberTheoryCrypto.mod_exp(a, d, n)
            
            if x == 1 or x == n - 1:
                continue
            
            for _ in range(r - 1):
                x = NumberTheoryCrypto.mod_exp(x, 2, n)
                if x == n - 1:
                    break
            else:
                return False
        
        return True
    
    @staticmethod
    def generate_prime(bits):
        """Generate a random prime of specified bit length."""
        while True:
            n = secrets.randbits(bits) | (1 << (bits - 1)) | 1
            if NumberTheoryCrypto.miller_rabin(n):
                return n
    
    class RSA:
        """RSA encryption scheme."""
        
        def __init__(self, key_size=512):
            self.key_size = key_size
            self._generate_keys()
        
        def _generate_keys(self):
            """Generate RSA key pair."""
            p = NumberTheoryCrypto.generate_prime(self.key_size // 2)
            q = NumberTheoryCrypto.generate_prime(self.key_size // 2)
            
            self.n = p * q
            self.phi = (p - 1) * (q - 1)
            
            # Common choice: e = 65537
            self.e = 65537
            while gcd(self.e, self.phi) != 1:
                self.e += 2
            
            self.d = NumberTheoryCrypto.mod_inverse(self.e, self.phi)
        
        def encrypt(self, message):
            """Encrypt message (as integer)."""
            if isinstance(message, str):
                message = int.from_bytes(message.encode(), 'big')
            return NumberTheoryCrypto.mod_exp(message, self.e, self.n)
        
        def decrypt(self, ciphertext):
            """Decrypt ciphertext."""
            return NumberTheoryCrypto.mod_exp(ciphertext, self.d, self.n)
        
        def get_public_key(self):
            return (self.n, self.e)
        
        def sign(self, message):
            """Sign message using private key."""
            if isinstance(message, str):
                message = int.from_bytes(message.encode(), 'big')
            return NumberTheoryCrypto.mod_exp(message, self.d, self.n)
        
        def verify(self, message, signature):
            """Verify signature using public key."""
            if isinstance(message, str):
                message = int.from_bytes(message.encode(), 'big')
            verified = NumberTheoryCrypto.mod_exp(signature, self.e, self.n)
            return verified == message

Leonhard Euler: The Master of Us All

Historical Context

Leonhard Euler (1707-1783) was the most prolific mathematician in history, publishing over 800 papers and books across virtually every mathematical field. Despite losing his sight, he continued to produce groundbreaking work. Euler introduced much of the modern mathematical notation including \(f(x)\) for functions, \(e\) for the base of natural logarithms, \(i\) for \(\sqrt{-1}\), and \(\Sigma\) for summation. His work laid foundations for analysis, number theory, graph theory, and topology.

Definitions

Euler's Formula: For any convex polyhedron: \(V - E + F = 2\) where \(V\) is vertices, \(E\) is edges, and \(F\) is faces.

Euler's Identity: \(e^{i\pi} + 1 = 0\), connecting five fundamental constants.

Euler's Totient Function: \(\phi(n)\) counts integers from \(1\) to \(n\) coprime to \(n\).

Theorem and Proof

Theorem (Euler's Formula for Planar Graphs): For any connected planar graph: \(V - E + F = 2\).

Proof: By induction on the number of edges. Base case: a tree has \(V = E + 1\) and \(F = 1\) (the exterior face), so \(V - E + F = (E+1) - E + 1 = 2\). Inductive step: if the graph contains a cycle, remove one edge from the cycle. This reduces both \(E\) and \(F\) by 1, preserving \(V - E + F\). Continue until a tree remains. ∎

The Central Limit Theorem: Universality in Probability

Historical Context

The Central Limit Theorem (CLT) is one of the most remarkable results in mathematics. First proved by de Moivre (1733) for binomial distributions and later generalized by Laplace and Lyapunov, it explains why the normal distribution appears so ubiquitously in nature. The theorem states that sums of independent random variables converge to a normal distribution, regardless of the original distributions (under mild conditions).

Definitions

Convergence in Distribution: A sequence of random variables \(X_n\) converges in distribution to \(X\) if \(\lim_{n \to \infty} F_{X_n}(x) = F_X(x)\) at all continuity points of \(F_X\).

Characteristic Function: \(\varphi_X(t) = \mathbb{E}[e^{itX}]\).

Theorem and Proof

Central Limit Theorem (Lindeberg-Lévy): Let \(X_1, X_2, \ldots\) be i.i.d. random variables with \(\mathbb{E}[X_i] = \mu\) and \(\text{Var}(X_i) = \sigma^2 < \infty\). Then: \[\frac{\bar{X}_n - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)\] where \(\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i\).

Proof Sketch: Let \(Z_i = (X_i - \mu)/\sigma\) and \(S_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Z_i\). The characteristic function of \(S_n\) is: \[\varphi_{S_n}(t) = \left(\varphi_{Z_1}\left(\frac{t}{\sqrt{n}}\right)\right)^n\] Using Taylor expansion: \(\varphi_{Z_1}(t) = 1 - \frac{t^2}{2} + o(t^2)\). Thus: \[\varphi_{S_n}(t) = \left(1 - \frac{t^2}{2n} + o(1/n)\right)^n \to e^{-t^2/2}\] which is the characteristic function of \(\mathcal{N}(0, 1)\). By Lévy's continuity theorem, convergence of characteristic functions implies convergence in distribution. ∎

Notation Guide

  • \(\xrightarrow{d}\) — convergence in distribution
  • \(\bar{X}_n\) — sample mean
  • \(\varphi_X(t)\) — characteristic function
  • \(\mathcal{N}(\mu, \sigma^2)\) — normal distribution
  • \(o(t^2)\) — little-o notation

import numpy as np
import matplotlib.pyplot as plt

class CentralLimitTheorem:
    """Demonstrate the Central Limit Theorem."""
    
    @staticmethod
    def demonstrate_clt(distribution, params, n_samples, n_trials):
        """
        Demonstrate CLT with various distributions.
        
        distribution: 'uniform', 'exponential', 'binomial', 'poisson'
        params: distribution parameters
        n_samples: number of samples to average
        n_trials: number of trials
        """
        samples = []
        
        for _ in range(n_trials):
            if distribution == 'uniform':
                data = np.random.uniform(params[0], params[1], n_samples)
            elif distribution == 'exponential':
                data = np.random.exponential(params[0], n_samples)
            elif distribution == 'binomial':
                data = np.random.binomial(params[0], params[1], n_samples)
            elif distribution == 'poisson':
                data = np.random.poisson(params[0], n_samples)
            elif distribution == 'bernoulli':
                data = np.random.binomial(1, params[0], n_samples)
            else:
                raise ValueError(f"Unknown distribution: {distribution}")
            
            samples.append(np.mean(data))
        
        return np.array(samples)
    
    @staticmethod
    def plot_clt_convergence(distribution, params, sample_sizes, n_trials=10000):
        """Plot convergence to normal distribution."""
        fig, axes = plt.subplots(2, 2, figsize=(12, 10))
        axes = axes.flatten()

            samples = CentralLimitTheorem.demonstrate_clt(
                distribution, params, n, n_trials
            )
            
            # Standardize
            mean = np.mean(samples)
            std = np.std(samples)
            standardized = (samples - mean) / std
            
            ax = axes[idx]
            ax.hist(standardized, bins=50, density=True, alpha=0.7, 
                   label=f'n={n}')
            
            # Overlay standard normal
            x = np.linspace(-4, 4, 100)
            ax.plot(x, stats.norm.pdf(x), 'r-', linewidth=2, label='N(0,1)')
            
            ax.set_title(f'Sample Size n={n}')
            ax.set_xlabel('Standardized Sample Mean')
            ax.set_ylabel('Density')
            ax.legend()
            ax.grid(True, alpha=0.3)

        return fig
    
    @staticmethod
    def berry_ess_bound(n, rho, sigma):
        """
        Berry-Esseen theorem: bound on convergence rate.
        |F_n(x) - Φ(x)| ≤ C * ρ / (σ³ * √n)
        where C ≈ 0.4748 (best known constant)
        """
        C = 0.4748
        return C * rho / (sigma**3 * np.sqrt(n))
    
    @staticmethod
    def kl_divergence_normal(samples):
        """Estimate KL divergence from standard normal."""
        # Fit normal to samples
        mu = np.mean(samples)
        sigma = np.std(samples)
        
        # KL(N(μ,σ²) || N(0,1)) = 0.5 * (σ² + μ² - 1 - log(σ²))
        kl = 0.5 * (sigma**2 + mu**2 - 1 - np.log(sigma**2))
        return kl

Generating Functions: The Bridge Between Combinatorics and Analysis

Historical Context

Generating functions were systematically developed by Abraham de Moivre and Leonhard Euler in the 18th century. They provide a powerful technique for solving counting problems by encoding sequences as coefficients of power series. This allows combinatorial problems to be solved using tools from calculus and complex analysis.

Definitions

Ordinary Generating Function (OGF): For a sequence \((a_n)_{n \geq 0}\): \[A(x) = \sum_{n=0}^\infty a_n x^n\]

Exponential Generating Function (EGF): \[\hat{A}(x) = \sum_{n=0}^\infty a_n \frac{x^n}{n!}\]

Convolution: The product of OGFs corresponds to convolution: if \(C(x) = A(x)B(x)\), then \(c_n = \sum_{k=0}^n a_k b_{n-k}\).

Theorem and Proof

Theorem (Catalan Numbers): The number of valid parenthesizations of \(n+1\) factors is: \[C_n = \frac{1}{n+1}\binom{2n}{n}\]

Proof via Generating Functions: The recurrence is \(C_n = \sum_{k=0}^{n-1} C_k C_{n-1-k}\) with \(C_0 = 1\). Let \(C(x) = \sum_{n=0}^\infty C_n x^n\). Then: \[C(x) = 1 + xC(x)^2\] Solving: \(C(x) = \frac{1 - \sqrt{1-4x}}{2x}\). Using the generalized binomial theorem: \[C(x) = \sum_{n=0}^\infty \frac{1}{n+1}\binom{2n}{n} x^n\] ∎

Notation Guide

  • \([x^n]A(x)\) — coefficient of \(x^n\) in \(A(x)\)
  • \(C_n\) — Catalan numbers
  • \(B_n\) — Bell numbers
  • \(p(n)\) — partition function

import numpy as np
from fractions import Fraction
import sympy as sp

class GeneratingFunctions:
    """Combinatorics using generating functions."""
    
    @staticmethod
    def catalan_numbers(n_max):
        """Generate Catalan numbers using closed form."""
        catalan = []
        for n in range(n_max + 1):
            c = sp.binomial(2*n, n) // (n + 1)
            catalan.append(int(c))
        return catalan
    
    @staticmethod
    def fibonacci_gf(n_max):
        """
        Fibonacci: F(x) = x / (1 - x - x²)
        Coefficient of x^n gives F_n
        """
        x = sp.Symbol('x')
        F = x / (1 - x - x**2)
        
        # Expand as series
        series = sp.series(F, x, 0, n_max + 1)
        return series
    
    @staticmethod
    def partition_function(n_max):
        """
        Partition function p(n): number of ways to write n as sum of positive integers.
        Generating function: P(x) = Π (1 - x^k)^(-1)
        """
        # Dynamic programming approach
        p = [0] * (n_max + 1)
        p[0] = 1
        
        for k in range(1, n_max + 1):
            for n in range(k, n_max + 1):
                p[n] += p[n - k]
        
        return p
    
    @staticmethod
    def bell_numbers(n_max):
        """
        Bell numbers: number of partitions of a set.
        EGF: B(x) = exp(exp(x) - 1)
        """
        bell = [1]  # B_0 = 1
        
        for n in range(1, n_max + 1):
            # B_{n+1} = Σ C(n,k) B_k
            total = 0
            for k in range(n):
                total += sp.binomial(n - 1, k) * bell[k]
            bell.append(int(total))
        
        return bell
    
    @staticmethod
    def convolution(a, b, n_max):
        """Compute convolution of two sequences."""
        c = []
        for n in range(min(n_max + 1, len(a) + len(b) - 1)):
            cn = sum(a[k] * b[n - k] for k in range(n + 1) 
                    if k < len(a) and n - k < len(b))
            c.append(cn)
        return c
    
    @staticmethod
    def binomial_theorem_gf(n):
        """
        (1 + x)^n = Σ C(n,k) x^k
        """
        return [sp.binomial(n, k) for k in range(n + 1)]
    
    @staticmethod
    def derangements(n_max):
        """
        Number of permutations with no fixed points.
        !n = n! Σ (-1)^k / k!
        """
        der = []
        for n in range(n_max + 1):
            d = int(round(np.math.factorial(n) * 
                         sum((-1)**k / np.math.factorial(k) 
                             for k in range(n + 1))))
            der.append(d)
        return der

The Dragon Curve: A Space-Filling Fractal

Historical Context

The dragon curve (also known as the Harter-Heighway dragon or Jurassic Park fractal) was first investigated by NASA physicists John Heighway, Bruce Banks, and William Harter in the 1960s. It appeared prominently in Michael Crichton's novel "Jurassic Park" where iterations of the curve appeared between chapters, with the caption "The Dragon Curve"—though the curve itself predates the book by decades.

Definitions

Dragon Curve: A self-similar fractal obtained by repeatedly folding a strip of paper in half, then unfolding it so each fold creates a 90-degree angle.

L-System: A parallel rewriting system that generates the curve:
Axiom: FX
Rules: X → X+YF+, Y → −FX−Y

Fractal Dimension: The Hausdorff dimension of the dragon curve is 2, meaning it is space-filling in the limit.

Theorem and Proof

Theorem (Self-Similarity): The dragon curve can be decomposed into two copies of itself, each scaled by \(1/\sqrt{2}\) and rotated by 45°.

Proof: Consider the construction: start with a segment. Replace it with two segments at right angles, each of length \(1/\sqrt{2}\) times the original. The two new segments form the legs of an isosceles right triangle with the original as hypotenuse. Each iteration produces two copies of the previous curve, rotated and scaled. In the limit, this gives the self-similarity property with two pieces, each scaled by \(1/\sqrt{2}\). The similarity dimension satisfies \(2 \cdot (1/\sqrt{2})^d = 1\), giving \(d = 2\). ∎

Notation Guide

  • \(D_n\) — dragon curve of order \(n\)
  • F — move forward
  • +, − — turn left/right by 90°
  • X, Y — non-drawing symbols for recursion
  • \(N = 2^n\) — number of segments in order-\(n\) curve

import numpy as np
import matplotlib.pyplot as plt

class DragonCurve:
    """Generate and visualize the dragon curve fractal."""
    
    def __init__(self):
        self.directions = {
            'N': np.array([0, 1]),
            'E': np.array([1, 0]),
            'S': np.array([0, -1]),
            'W': np.array([-1, 0])
        }
        self.turn_right = {'N': 'E', 'E': 'S', 'S': 'W', 'W': 'N'}
        self.turn_left = {'N': 'W', 'W': 'S', 'S': 'E', 'E': 'N'}
    
    def generate_sequence(self, n):
        """
        Generate the turn sequence for dragon curve of order n.
        Uses the property: D_{n+1} = D_n + 1 + reverse(complement(D_n))
        where 1 = right turn, complement swaps L/R.
        """
        if n == 0:
            return []
        
        sequence = []
        for i in range(1, 2**n):
            # The i-th turn is right if i & -i == i (i is power of 2)
            # Actually: count trailing zeros in binary representation
            turn = self._get_turn(i)
            sequence.append(turn)
        
        return sequence
    
    def _get_turn(self, i):
        """Determine turn direction at step i."""
        # Count trailing zeros
        k = 0
        while i % 2 == 0:
            i //= 2
            k += 1
        # Right turn if k ≡ 0 (mod 2), left turn otherwise
        return 'R' if k % 2 == 0 else 'L'
    
    def generate_points(self, n):
        """Generate the points of the dragon curve."""
        turns = self.generate_sequence(n)
        
        # Start at origin, facing East
        points = [np.array([0, 0])]
        direction = 'E'
        
        for turn in turns:
            if turn == 'R':
                direction = self.turn_right[direction]
            else:
                direction = self.turn_left[direction]
            
            new_point = points[-1] + self.directions[direction]
            points.append(new_point)
        
        return np.array(points)
    
    def plot(self, n, figsize=(10, 10), color_by_progression=True):
        """Plot the dragon curve of order n."""
        points = self.generate_points(n)
        
        fig, ax = plt.subplots(figsize=figsize)

                ax.plot([points[i, 0], points[i+1, 0]], 
                       [points[i, 1], points[i+1, 1]], 
                       color=color, linewidth=1.5)
        else:
            ax.plot(points[:, 0], points[:, 1], 'b-', linewidth=1)
        
        ax.set_aspect('equal')
        ax.axis('off')
        ax.set_title(f'Dragon Curve (Order {n}, {len(points)-1} segments)')
        
        return fig
    
    def plot_iterations(self, max_n=5, figsize=(15, 3)):
        """Plot multiple iterations side by side."""
        fig, axes = plt.subplots(1, max_n + 1, figsize=figsize)
        
        for n, ax in enumerate(axes):
            points = self.generate_points(n)
            ax.plot(points[:, 0], points[:, 1], 'b-', linewidth=1.5)
            ax.set_aspect('equal')
            ax.axis('off')
            ax.set_title(f'n={n}')
        
        plt.tight_layout()
        return fig
    
    def compute_fractal_dimension(self, max_n=12):
        """
        Estimate fractal dimension using box counting.
        """
        dimensions = []
        
        for n in range(1, max_n + 1):
            points = self.generate_points(n)
            
            # Bounding box
            x_min, x_max = points[:, 0].min(), points[:, 0].max()
            y_min, y_max = points[:, 1].min(), points[:, 1].max()
            
            # Box counting with different box sizes
            box_counts = []
            box_sizes = []
            
            for k in range(1, min(n + 1, 8)):
                box_size = 2**(-k)
                nx = int(np.ceil((x_max - x_min) / box_size))
                ny = int(np.ceil((y_max - y_min) / box_size))
                
                # Count occupied boxes
                occupied = set()
                for point in points:
                    bx = int((point[0] - x_min) / box_size)
                    by = int((point[1] - y_min) / box_size)
                    occupied.add((bx, by))
                
                box_counts.append(len(occupied))
                box_sizes.append(box_size)
            
            # Estimate dimension from slope
            if len(box_counts) > 1:
                log_counts = np.log(box_counts)
                log_sizes = np.log(1 / np.array(box_sizes))
                slope = np.polyfit(log_sizes, log_counts, 1)[0]
                dimensions.append(slope)
        
        return dimensions
    
    def area_estimate(self, n):
        """Estimate area covered by the dragon curve."""
        points = self.generate_points(n)
        
        # Use shoelace formula for polygon area
        x = points[:, 0]
        y = points[:, 1]
        
        area = 0.5 * abs(np.dot(x[:-1], y[1:]) - np.dot(y[:-1], x[1:]))
        return area

📜 Math History: The Development of Analysis

The development of mathematical analysis represents one of the great intellectual achievements of human civilization. From the intuitive methods of Archimedes to the rigorous foundations of the 19th century, the story of analysis is one of progressively refining our understanding of continuity, limits, and infinity.

The calculus of Newton and Leibniz in the late 17th century provided powerful tools for understanding motion and change. Newton developed his "method of fluxions" primarily for physics—understanding planetary motion and gravitational attraction. Leibniz, independently, created a notation (\(\frac{dy}{dx}\) and \(\int\)) that proved remarkably flexible and is still used today. Both recognized that integration and differentiation are inverse operations, what we now call the Fundamental Theorem of Calculus.

However, the early calculus relied heavily on intuitive notions of "infinitesimals"—quantities that were treated as both nonzero and zero in different parts of calculations. Bishop Berkeley famously criticized these as "ghosts of departed quantities." The lack of rigorous foundations led to paradoxes and errors that troubled mathematicians for over a century.

The 19th century brought the arithmetization of analysis. Cauchy provided the first rigorous definitions of limit, continuity, and convergence. Bolzano proved the intermediate value theorem using what we would now recognize as a completeness property of the real numbers. But it was Weierstrass who finally banished infinitesimals entirely, replacing them with the \(\epsilon-\delta\) definitions that students learn today.

The construction of the real numbers by Dedekind (using cuts) and Cantor (using Cauchy sequences) provided a solid foundation. Cantor's work on set theory and the infinite, while initially controversial, became essential for modern analysis. The discovery that there are different sizes of infinity—countable and uncountable—revolutionized mathematics.

🎯 Problem Corner

Putnam 2024 Problem B2

Let \(n\) be a positive integer. A sequence \(a_0, a_1, \ldots, a_n\) of integers is called admissible if it satisfies:

  • \(a_0 = 0\) and \(a_n = n\)
  • For each \(i\) with \(1 \leq i \leq n\), we have \(a_i \in \{a_{i-1}, a_{i-1} + 1\}\)
  • There does not exist \(i < j\) such that \(a_i = a_j\) and \(a_{i+1} = a_{j+1} = a_i + 1\)

Determine the number of admissible sequences.

💡 Hint

Consider the connection to Catalan numbers. Try small cases: n = 1, 2, 3, 4, 5. The condition forbids certain patterns—can you characterize which sequences are allowed?

✅ Solution

The answer is the Catalan number \(C_n = \frac{1}{n+1}\binom{2n}{n}\).

Explanation: The admissible sequences are in bijection with Dyck paths of length \(2n\). A Dyck path is a path from \((0,0)\) to \((2n, 0)\) using steps \((1,1)\) (up) and \((1,-1)\) (down) that never goes below the x-axis.

The bijection: Given an admissible sequence, construct a path where we go up at step \(i\) if \(a_i = a_{i-1} + 1\) and down if \(a_i = a_{i-1}\). The condition on forbidden patterns ensures the path stays non-negative.

First few values: \(C_1 = 1, C_2 = 2, C_3 = 5, C_4 = 14, C_5 = 42\).

🎨 Visualization of the Day: The Dragon Curve

The dragon curve is a self-similar fractal obtained by repeatedly folding a strip of paper in half, then unfolding it so each fold creates a 90-degree angle. It has Hausdorff dimension 2, meaning it is space-filling in the limit, and it never crosses itself.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def dragon_curve(n):
    """Generate dragon curve of order n."""
    # Generate turn sequence
    turns = []
    for i in range(1, 2**n):
        # Count trailing zeros
        k = 0
        temp = i
        while temp % 2 == 0:
            temp //= 2
            k += 1
        turns.append('R' if k % 2 == 0 else 'L')
    
    # Generate points
    directions = {'N': [0, 1], 'E': [1, 0], 'S': [0, -1], 'W': [-1, 0]}
    right = {'N': 'E', 'E': 'S', 'S': 'W', 'W': 'N'}
    left = {'N': 'W', 'W': 'S', 'S': 'E', 'E': 'N'}
    
    points = [[0, 0]]
    direction = 'E'
    
    for turn in turns:
        direction = right[direction] if turn == 'R' else left[direction]
        new_point = [points[-1][0] + directions[direction][0],
                     points[-1][1] + directions[direction][1]]
        points.append(new_point)
    
    return np.array(points)

# Plot dragon curves of different orders
fig, axes = plt.subplots(2, 3, figsize=(15, 10))
axes = axes.flatten()

for idx, n in enumerate([1, 2, 3, 5, 7, 10]):
    points = dragon_curve(n)
    ax = axes[idx]
    
    # Color gradient
    for i in range(len(points) - 1):
        color = plt.cm.viridis(i / len(points))
        ax.plot([points[i, 0], points[i+1, 0]], 
                [points[i, 1], points[i+1, 1]], 
                color=color, linewidth=1.5)
    
    ax.set_aspect('equal')
    ax.axis('off')
    ax.set_title(f'Dragon Curve (Order {n})', fontsize=12)

plt.tight_layout()
plt.savefig('dragon_curve.png', dpi=150, bbox_inches='tight')
plt.show()

print("As n → ∞, the dragon curve fills space (Hausdorff dimension = 2)")
