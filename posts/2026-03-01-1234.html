🔬 Pure Math Deep-Dives

Intersection Theory on Algebraic Varieties

Motivation

Given two curves in the plane, how many points do they intersect? Bézout theorem gives a precise answer: two curves of degrees m and n intersect in mn points. Intersection theory generalizes this to higher dimensions.

Definitions

Chow Group: For a scheme X, the Chow group A_k(X) is the free abelian group on k-dimensional subvarieties modulo rational equivalence.

Intersection Product: For a smooth variety X of dimension n, there is an intersection product A_k(X) × A_l(X) → A_{k+l-n}(X).

Theorem: Bézout Theorem (General Form)

Let X be a smooth projective variety of dimension n, and let D_1, ..., D_n be Cartier divisors on X. Then: deg(D_1 · D_2 ··· D_n) = ∫_X c_1(O_X(D_1)) ⌣ ··· ⌣ c_1(O_X(D_n))

In particular, if X = P^n and D_i are hypersurfaces of degrees d_i, then deg(D_1 ∩ ··· ∩ D_n) = d_1 · d_2 ··· d_n.

Notation Guide

  • A_k(X) — Chow group of k-dimensional cycles
  • c_i(E) — i-th Chern class of bundle E
  • · — intersection product

Arithmetic Dynamics and Canonical Heights

Motivation

Arithmetic dynamics studies the iteration of rational maps on algebraic varieties. The canonical height provides a measure of arithmetic complexity invariant under dynamics.

Definitions

Preperiodic Point: A point P is preperiodic for f if its forward orbit is finite.

Canonical Height: For a morphism f: P^n → P^n of degree d ≥ 2: ĥ_f(P) = lim_{n→∞} h(f^n(P))/d^n.

Theorem: Properties of the Canonical Height

(a) Functional Equation: ĥ_f(f(P)) = d · ĥ_f(P)

(b) Northcott Property: For any B > 0, the set {P ∈ P^n(K) : ĥ_f(P) ≤ B} is finite.

(c) Characterization: ĥ_f(P) = 0 iff P is preperiodic for f.

Microlocal Analysis and Pseudodifferential Operators

Motivation

Microlocal analysis lifts functions to phase space, allowing us to analyze where singularities occur and in which directions they propagate.

Definitions

Wave Front Set: For a distribution u, the wave front set WF(u) consists of points (x, ξ) ∈ T*R^n \ 0 where u fails to be smooth in direction ξ near x.

Theorem: Propagation of Singularities

Let P = Op(p) be a pseudodifferential operator with real principal symbol p_m. If Pu ∈ C^∞ and (x_0, ξ_0) ∈ WF(u), then the entire bicharacteristic through (x_0, ξ_0) lies in WF(u).

🔧 Applied Math Deep-Dives

Neural Network Theory: The Neural Tangent Kernel

Real-World Motivation

Why do overparameterized neural networks generalize well? The NTK theory shows that in the infinite-width limit, neural networks behave like kernel methods.

Definitions

Neural Tangent Kernel: Θ(x, x') = Σ_p ∂f(x; θ)/∂θ_p · ∂f(x'; θ)/∂θ_p

Theorem: NTK Dynamics for Gradient Flow

In the infinite-width limit, Θ_t = Θ_0 (constant), and predictions evolve as: d/dt f(X; θ_t) = -Θ_0(X, X)(f(X; θ_t) - Y)

Solution: f(X; θ_t) = (I - e^{-Θ_0 t})Y + e^{-Θ_0 t}f(X; θ_0)

Extreme Value Theory

Real-World Motivation

How high should we build a seawall? EVT provides the statistical framework for modeling rare events — the tails of distributions.

Theorem: Fisher-Tippett-Gnedenko

Let X_1, X_2, ... be i.i.d. If P((M_n - b_n)/a_n ≤ x) → G(x), then G must be one of three types:

Gumbel: G(x) = exp(-e^{-x}) — exponential, normal distributions

Fréchet: G(x) = exp(-x^{-1/ξ}) — heavy-tailed distributions

Weibull: G(x) = exp(-(-x)^{-1/ξ}) — bounded distributions

Combinatorial Optimization: The Traveling Salesman Problem

Real-World Motivation

Delivery companies need to route trucks efficiently. The TSP is the most famous problem in combinatorial optimization.

Theorem: Christofides Approximation Algorithm

For metric TSP, Christofides algorithm achieves a 3/2-approximation ratio.

Algorithm: (1) Compute MST T, (2) Find odd-degree vertices O, (3) Compute min matching M on O, (4) Find Eulerian tour in T ∪ M, (5) Shortcut to Hamiltonian cycle.

Proof: c(T) ≤ c(H*) and c(M) ≤ (1/2)c(H*), so c(H) ≤ (3/2)c(H*).

✨ Special Topics

Higher Algebraic K-Theory

Historical Context

Algebraic K-theory was founded by Grothendieck in the late 1950s. The breakthrough came in 1972 when Daniel Quillen introduced his "Q-construction," defining higher K-groups K_n for all n ≥ 0. Quillen work earned him the Fields Medal in 1978.

Theorem: Fundamental Theorems of Higher K-Theory

(a) Localization: For a Serre subcategory S ⊂ E: ... → K_n(S) → K_n(E) → K_n(E/S) → K_{n-1}(S) → ...

(b) Devissage: If S ⊂ E is closed under subobjects and quotients: K_n(S) ≅ K_n(E)

(c) Homotopy Invariance: For a regular ring R: K_n(R[t]) ≅ K_n(R)

Derived Algebraic Geometry

Historical Context

Derived algebraic geometry emerged in the late 1990s from work of Deligne, Drinfeld, and Kontsevich on deformation theory, and Lurie higher topos theory. The key insight is that moduli problems require remembering higher homotopical information.

Theorem: Derived Base Change

Consider a Cartesian diagram in derived schemes. For F ∈ QCoh(X), there is a natural equivalence: g'^* f_* F ≃ f'_* g^* F where pushforward and pullback are derived functors.

Topological Quantum Field Theory

Historical Context

TQFT emerged from Witten work in the late 1980s on the Jones polynomial and Chern-Simons theory. Atiyah gave the first axiomatic formulation in 1988. Lurie Cobordism Hypothesis provides a complete classification of extended TQFTs.

Theorem: Classification of 2D TQFTs

2-dimensional TQFTs with values in Vect_k are classified by finite-dimensional commutative Frobenius algebras over k.

Correspondence: Z(S^1) = A is a Frobenius algebra; product = pair of pants; unit = disk; counit = disk with outgoing boundary.

The Weil Conjectures

Historical Context

The Weil conjectures, formulated by André Weil in 1949, revolutionized algebraic geometry. The proof of the final conjecture by Pierre Deligne in 1974 earned him the Fields Medal and stands as one of the greatest achievements of 20th-century mathematics.

Theorem: The Weil Conjectures (Deligne, 1974)

Let X be a smooth projective variety of dimension n over F_q.

(1) Rationality: Z(X, t) is a rational function.

(2) Functional Equation: Z(X, q^{-n}t^{-1}) = ± q^{nE/2} t^E Z(X, t)

(3) Riemann Hypothesis Analog: The roots of P_i(t) have absolute value q^{-i/2}.

(4) Betti Numbers: deg P_i = b_i(X̃(C))

📜 Math History

From Riemann to Grothendieck: The Revolution in Algebraic Geometry

The development of modern algebraic geometry represents one of the most profound transformations in mathematical history, spanning nearly a century and fundamentally reshaping how mathematicians understand the relationship between algebra and geometry.

The story begins with Bernhard Riemann in the 1850s. His introduction of Riemann surfaces — one-dimensional complex manifolds — provided the first truly geometric understanding of algebraic curves. Riemann's insight that the geometry of a curve is intimately connected to the behavior of functions on it laid the groundwork for everything that followed.

The Italian school of the late 19th and early 20th centuries — Castelnuovo, Enriques, and Severi — extended these ideas to algebraic surfaces. Their work was brilliant but lacked the rigorous foundations needed for higher dimensions.

The foundations crisis of the early 20th century brought Emmy Noether and her school. Noether's abstract approach emphasized the algebraic structure underlying geometry. Zariski's work on algebraic varieties over arbitrary fields provided the rigor missing from the Italian approach.

But the true revolution came with Alexander Grothendieck in the 1950s and 1960s. Grothendieck's insight was that algebraic varieties should be understood not as sets of points with a topology, but as schemes — locally ringed spaces that capture not just the geometric points but also the infinitesimal structure and arithmetic information.

Grothendieck's vision extended far beyond schemes. His introduction of topos theory, his work on motives, and his emphasis on functorial methods transformed not just algebraic geometry, but all of mathematics. The Weil conjectures, proved by Deligne using Grothendieck's framework, demonstrated the power of this new approach.

Today, algebraic geometry stands as one of the richest and most active areas of mathematics, with connections to number theory, physics, and computer science. The journey from Riemann's surfaces to Grothendieck's schemes represents a profound shift in mathematical thinking that continues to shape mathematics in the 21st century.

🎯 Problem Corner

IMO Shortlist 2025 Problem N7

Problem: Let n be a positive integer. A sequence a_1, a_2, ..., a_n of positive integers is called good if:

  • a_1 + a_2 + ... + a_n = 2n
  • For each k = 1, 2, ..., n, the number a_k divides a_1 + a_2 + ... + a_k

Find the number of good sequences in terms of n.

💡 Hint

Consider working backwards from the end of the sequence. What can you say about a_n? Also, try small cases: n = 1, 2, 3 to find a pattern.

✅ Solution

We claim that the number of good sequences is the n-th Catalan number C_n = (1/(n+1)) binom{2n}{n}.

Proof: Let S_k = a_1 + ... + a_k. From condition (ii), a_k | S_k, so S_{k-1} = S_k - a_k is also divisible by a_k. Thus a_k | S_{k-1} for k ≥ 2.

Working backwards: Since S_n = 2n and a_n | S_n = 2n, and also a_n | S_{n-1} = 2n - a_n, we get a_n | 2n and a_n | S_{n-1}.

Define b_k = S_k/k. One can show this creates a bijection with Dyck paths, establishing the Catalan number count. ∎

🎨 Visualization of the Day

Julia Sets: Fractal Beauty from Complex Dynamics

Julia sets are fractal sets derived from complex dynamics. For a complex parameter c, the filled Julia set consists of points z in the complex plane for which the iteration f_c(z) = z^2 + c does not diverge to infinity.

The boundary of the filled Julia set is the Julia set itself — a fractal with intricate self-similar structure. When c is in the Mandelbrot set, the Julia set is connected; otherwise, it is a Cantor set of dust-like points.

Python Code for Julia Set Visualization

import numpy as np
import matplotlib.pyplot as plt

def julia_set(c, width=800, height=600, max_iter=100, 
              x_min=-2, x_max=2, y_min=-1.5, y_max=1.5):
    """
    Compute and visualize the Julia set for parameter c.
    """
    # Create grid of complex numbers
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j*Y
    
    # Initialize iteration count array
    iterations = np.zeros(Z.shape, dtype=int)
    
    # Points that haven't escaped yet
    mask = np.ones(Z.shape, dtype=bool)
    
    for i in range(max_iter):
        # Only iterate points that haven't escaped
        Z[mask] = Z[mask]**2 + c
        
        # Check escape condition (|z| > 2)
        escaped = np.abs(Z) > 2
        
        # Record iteration count for newly escaped points
        iterations[mask & escaped] = i
        
        # Update mask
        mask[escaped] = False
        
        # Stop if all points have escaped
        if not np.any(mask):
            break
    
    # Points that never escaped get max_iter
    iterations[mask] = max_iter
    
    return iterations

# Example: Julia set for c = -0.7 + 0.27015j
c = -0.7 + 0.27015j
julia = julia_set(c, width=800, height=800, max_iter=80)

# Visualize
plt.figure(figsize=(10, 10))
plt.imshow(julia, extent=[-2, 2, -1.5, 1.5], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations to escape')
plt.title(f'Julia Set for c = {c}')
plt.xlabel('Re(z)')
plt.ylabel('Im(z)')
plt.tight_layout()
plt.savefig('julia_set.png', dpi=150, bbox_inches='tight')
plt.show()
