Geometric Group Theory: Cayley Graphs and the Word Problem

geometric-group-theory

Motivation

Geometric group theory emerged from the insight that algebraic properties of groups can be understood through their geometric actions. By constructing spaces on which groups act, we can translate algebraic questions into geometric ones. This approach, pioneered by Mikhail Gromov in the 1980s, has revolutionized group theory, providing solutions to long-standing problems and revealing deep connections between group theory, topology, and geometry.

Definitions

  • Cayley Graph: For a group \(G\) with generating set \(S\), the Cayley graph \(\text{Cay}(G, S)\) has vertices corresponding to group elements and edges \((g, gs)\) for \(g \in G, s \in S\).
  • Word Metric: The distance \(d_S(g, h)\) is the length of the shortest word in \(S \cup S^{-1}\) representing \(g^{-1}h\).
  • Quasi-Isometry: A map \(f: X \to Y\) between metric spaces is a quasi-isometry if there exist constants \(K \geq 1\) and \(C \geq 0\) such that: \[\frac{1}{K}d_X(x, x') - C \leq d_Y(f(x), f(x')) \leq Kd_X(x, x') + C\] and every point of \(Y\) is within distance \(C\) of the image.
  • Hyperbolic Group: A group whose Cayley graph is Gromov hyperbolic—any triangle is uniformly thin.

Theorem: The Milnor-Švarc Lemma

Theorem (Milnor-Švarc): Let \(G\) be a group acting properly discontinuously and cocompactly by isometries on a proper geodesic metric space \(X\). Then \(G\) is finitely generated, and for any finite generating set \(S\), the orbit map \(g \mapsto g \cdot x_0\) is a quasi-isometry between \((G, d_S)\) and \(X\).

Proof Sketch

Fix a basepoint \(x_0 \in X\). Let \(D\) be the diameter of a fundamental domain for the action. Define \(S = \{g \in G : d_X(x_0, gx_0) \leq 2D + 1\}\). This set generates \(G\) because any point in the orbit can be connected to \(x_0\) by a path that intersects translates of the fundamental domain. The orbit map is Lipschitz by construction. The lower bound follows from proper discontinuity: points far apart in the group must map to points far apart in \(X\).

Notation Guide

  • \(d_S\): Word metric with respect to generating set \(S\)
  • \(|g|_S\): Word length of \(g\) in generators \(S\)
  • \(\partial G\): Gromov boundary of a hyperbolic group
  • \(\langle S | R \rangle\): Group presentation with generators \(S\) and relations \(R\)
  • \(\cong_{QI}\): Quasi-isometric

Spectral Graph Theory: Eigenvalues and Graph Structure

spectral-graph-theory

Motivation

Spectral graph theory studies the relationship between the eigenvalues of matrices associated with graphs and the structural properties of those graphs. This field, pioneered by chemists studying molecular vibrations and developed by mathematicians like Fan Chung, provides powerful tools for understanding networks, designing algorithms, and proving combinatorial results. The eigenvalues encode information about connectivity, expansion, random walks, and more.

Definitions

  • Adjacency Matrix: For a graph \(G = (V, E)\), the adjacency matrix \(A\) is defined by \(A_{ij} = 1\) if \((i,j) \in E\) and \(0\) otherwise.
  • Laplacian Matrix: \(L = D - A\) where \(D\) is the diagonal degree matrix with \(D_{ii} = \deg(i)\).
  • Normalized Laplacian: \(\mathcal{L} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}AD^{-1/2}\).
  • Spectral Gap: The difference \(\lambda_2 - \lambda_1\) between the first and second eigenvalues of the Laplacian (for connected graphs, \(\lambda_1 = 0\)).
  • Expander Graph: A sparse graph with strong connectivity properties, characterized by a large spectral gap.

Theorem: Cheeger's Inequality

Theorem (Cheeger): Let \(G\) be a finite connected graph with normalized Laplacian eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\). Let \(h(G)\) be the Cheeger constant (isoperimetric number): \[h(G) = \min_{S \subseteq V, |S| \leq |V|/2} \frac{|E(S, \bar{S})|}{|S|}\] Then: \[\frac{h(G)^2}{2} \leq \lambda_2 \leq 2h(G)\]

Proof Sketch

The upper bound follows by using the indicator function of a set \(S\) as a test function in the Rayleigh quotient for \(\lambda_2\). The lower bound is more involved: given an eigenfunction for \(\lambda_2\), one performs a sweep cut—partitioning vertices based on the median value of the eigenfunction—and shows that some cut has expansion controlled by \(\lambda_2\).

Notation Guide

  • \(A\): Adjacency matrix
  • \(L\): (Combinatorial) Laplacian
  • \(\mathcal{L}\): Normalized Laplacian
  • \(\lambda_i\): Eigenvalues (typically ordered)
  • \(h(G)\): Cheeger constant (isoperimetric number)
  • \(\phi(S) = |E(S, \bar{S})| / \min(\text{vol}(S), \text{vol}(\bar{S}))\): Conductance

import numpy as np
import networkx as nx
from scipy.linalg import eigh
import matplotlib.pyplot as plt

class SpectralGraphTheory:
    """Spectral graph theory computations."""
    
    @staticmethod
    def normalized_laplacian(G):
        """Compute the normalized Laplacian matrix."""
        A = nx.adjacency_matrix(G).astype(float).toarray()
        degrees = np.array([G.degree(i) for i in G.nodes()])
        D_inv_sqrt = np.diag(1.0 / np.sqrt(degrees + 1e-10))
        I = np.eye(len(G))
        return I - D_inv_sqrt @ A @ D_inv_sqrt
    
    @staticmethod
    def spectral_gap(G):
        """Compute the spectral gap (second smallest eigenvalue)."""
        L = SpectralGraphTheory.normalized_laplacian(G)
        eigenvalues = np.linalg.eigvalsh(L)
        eigenvalues = np.sort(eigenvalues)
        return eigenvalues[1] if len(eigenvalues) > 1 else 0
    
    @staticmethod
    def fiedler_vector(G):
        """Compute the Fiedler vector (eigenvector for λ₂)."""
        L = SpectralGraphTheory.normalized_laplacian(G)
        eigenvalues, eigenvectors = eigh(L)
        return eigenvectors[:, 1]  # Second eigenvector
    
    @staticmethod
    def spectral_partition(G):
        """Partition graph using Fiedler vector (spectral clustering)."""
        fiedler = SpectralGraphTheory.fiedler_vector(G)
        nodes = list(G.nodes())
        # Partition by median
        median = np.median(fiedler)
        partition_1 = [nodes[i] for i in range(len(nodes)) if fiedler[i] < median]
        partition_2 = [nodes[i] for i in range(len(nodes)) if fiedler[i] >= median]
        return partition_1, partition_2

Arithmetic Dynamics: Dynamics on Algebraic Varieties

arithmetic-dynamics

Motivation

Arithmetic dynamics is a relatively new field that combines techniques from dynamical systems and number theory. It studies the iteration of rational maps on algebraic varieties, asking questions about periodic points, preperiodic points, and the arithmetic structure of orbits. This field has seen explosive growth since the 1990s, with connections to Diophantine geometry, complex dynamics, and even the abc conjecture.

Definitions

  • Rational Map: A morphism \(\phi: \mathbb{P}^n \to \mathbb{P}^n\) defined by homogeneous polynomials of the same degree.
  • Periodic Point: A point \(P\) such that \(\phi^n(P) = P\) for some \(n > 0\). The smallest such \(n\) is the period.
  • Preperiodic Point: A point whose forward orbit under \(\phi\) is finite (eventually maps to a periodic cycle).
  • Canonical Height: For a morphism \(\phi: \mathbb{P}^1 \to \mathbb{P}^1\) of degree \(d \geq 2\), the canonical height is: \[\hat{h}_\phi(P) = \lim_{n \to \infty} \frac{h(\phi^n(P))}{d^n}\] where \(h\) is the Weil height.
  • Julia Set: (In complex dynamics) The boundary of the set of points with bounded orbits; carries the chaotic dynamics.

Theorem: Uniform Boundedness Conjecture (Morton-Silverman)

Conjecture (Morton-Silverman, 1994): Let \(K/\mathbb{Q}\) be a number field of degree \(D\), and let \(\phi: \mathbb{P}^N \to \mathbb{P}^N\) be a morphism of degree \(d \geq 2\) defined over \(K\). Then there exists a constant \(B(D, N, d)\) such that \(\phi\) has at most \(B(D, N, d)\) preperiodic points in \(\mathbb{P}^N(K)\).

Theorem (Merel, 1996 for elliptic curves; partial results in higher dimensions): The conjecture holds for Lattès maps (rational maps coming from elliptic curves).

Proof Sketch for Lattès Case

Lattès maps arise from multiplication-by-\(m\) on elliptic curves. Preperiodic points correspond to torsion points on the elliptic curve. Merel's theorem on the uniform boundedness of torsion for elliptic curves over number fields of fixed degree directly implies the result for Lattès maps.

Notation Guide

  • \(\phi^n\): n-th iterate of \(\phi\)
  • \(\text{Per}(\phi)\): Set of periodic points
  • \(\text{PrePer}(\phi)\): Set of preperiodic points
  • \(\hat{h}_\phi\): Canonical height with respect to \(\phi\)
  • \(\mathbb{P}^n(K)\): Projective n-space over field \(K\)
  • \(h(P)\): Weil logarithmic height

import numpy as np
import matplotlib.pyplot as plt
from fractions import Fraction

class ArithmeticDynamics:
    """Arithmetic dynamics computations over Q."""
    
    def __init__(self, numerator_coeffs, denominator_coeffs):
        """
        Define a rational map φ(x) = num(x)/den(x).
        Coeffs are from highest to lowest degree.
        """
        self.num = np.poly1d(numerator_coeffs)
        self.den = np.poly1d(denominator_coeffs)
        self.degree = max(len(numerator_coeffs), len(denominator_coeffs)) - 1
    
    def iterate(self, x, n):
        """Compute φ^n(x)."""
        result = x
        for _ in range(n):
            num_val = self.num(result)
            den_val = self.den(result)
            if den_val == 0:
                return float('inf')  # Pole
            result = num_val / den_val
        return result
    
    def orbit(self, x, max_iter=100):
        """Compute the orbit of x until cycle detection or max_iter."""
        seen = {}
        orbit = []
        current = x
        
        for i in range(max_iter):
            if current in seen:
                # Found a cycle
                cycle_start = seen[current]
                return orbit[:cycle_start], orbit[cycle_start:]
            seen[current] = i
            orbit.append(current)
            
            num_val = self.num(current)
            den_val = self.den(current)
            if den_val == 0:
                return orbit, [float('inf')]
            current = num_val / den_val
        
        return orbit, []
    
    def weil_height(self, x):
        """Compute the Weil height h(x) = log max(|p|, |q|) for x = p/q in lowest terms."""
        if x == 0:
            return 0
        if not isinstance(x, Fraction):
            # Approximate
            return max(0, np.log(abs(x)))
        
        p, q = abs(x.numerator), abs(x.denominator)
        return np.log(max(p, q))

Queueing Theory: Modeling Waiting Lines

queueing-theory

Real-World Motivation

Queueing theory, pioneered by A.K. Erlang in the early 1900s for telephone networks, now underpins modern telecommunications, computer systems, healthcare scheduling, and supply chain management. When you wait for a webpage to load, a customer service representative, or an emergency room doctor, queueing theory provides the mathematical framework to predict wait times, optimize staffing, and design efficient systems.

Definitions

  • Kendall's Notation: A queue is denoted A/B/c/K/N/D where:
    • A: Arrival process (M = Markovian/Poisson, D = Deterministic, G = General)
    • B: Service time distribution
    • c: Number of servers
    • K: System capacity (optional)
    • N: Population size (optional)
    • D: Queue discipline (optional, default FIFO)
  • Traffic Intensity: \(\rho = \lambda / (c\mu)\) where \(\lambda\) is arrival rate and \(\mu\) is service rate. System is stable when \(\rho < 1\).
  • Little's Law: \(L = \lambda W\) where \(L\) is average number in system, \(W\) is average time in system.

Theorem: Pollaczek-Khinchine Formula

Theorem (Pollaczek-Khinchine): For an M/G/1 queue (Poisson arrivals, general service time, single server) with service time having mean \(1/\mu\) and variance \(\sigma^2\), the expected number of customers in the system is: \[L = \rho + \frac{\rho^2(1 + \mu^2\sigma^2)}{2(1-\rho)}\] where \(\rho = \lambda/\mu\).

Proof Sketch

The proof uses the concept of residual service time. When a customer arrives, the expected remaining service time of the customer in service (if any) is \(\frac{\mathbb{E}[S^2]}{2\mathbb{E}[S]}\) by the inspection paradox. Combining this with the probability of finding the server busy (\(\rho\)) and applying the PASTA property (Poisson Arrivals See Time Averages) yields the formula.

Notation Guide

  • \(\lambda\): Arrival rate (customers per unit time)
  • \(\mu\): Service rate (customers per unit time)
  • \(\rho = \lambda/\mu\): Traffic intensity
  • \(L\): Average number of customers in system
  • \(L_q\): Average number of customers in queue
  • \(W\): Average time in system
  • \(W_q\): Average time in queue

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import expon, norm

class QueueingTheory:
    """Queueing theory calculations and simulations."""
    
    @staticmethod
    def mm1_metrics(lam, mu):
        """
        Compute exact metrics for M/M/1 queue.
        lam: arrival rate, mu: service rate
        """
        rho = lam / mu
        if rho >= 1:
            return None  # Unstable
        
        L = rho / (1 - rho)
        Lq = rho**2 / (1 - rho)
        W = 1 / (mu - lam)
        Wq = rho / (mu - lam)
        
        return {
            'rho': rho,
            'L': L,
            'Lq': Lq,
            'W': W,
            'Wq': Wq
        }
    
    @staticmethod
    def mg1_pk_formula(lam, mu, sigma):
        """
        Pollaczek-Khinchine formula for M/G/1.
        sigma: standard deviation of service time
        """
        rho = lam / mu
        if rho >= 1:
            return None
        
        Cs2 = (mu * sigma)**2  # Squared coefficient of variation
        Lq = (rho**2 * (1 + Cs2)) / (2 * (1 - rho))
        L = rho + Lq
        Wq = Lq / lam
        W = Wq + 1/mu
        
        return {
            'rho': rho,
            'L': L,
            'Lq': Lq,
            'W': W,
            'Wq': Wq
        }
    
    @staticmethod
    def mm1_simulation(lam, mu, T=10000, seed=None):
        """
        Simulate M/M/1 queue using event-driven simulation.
        """
        if seed:
            np.random.seed(seed)
        
        # Generate arrival and service times
        interarrivals = expon(scale=1/lam).rvs(int(T * lam * 2))
        service_times = expon(scale=1/mu).rvs(int(T * lam * 2))
        
        arrival_times = np.cumsum(interarrivals)
        arrival_times = arrival_times[arrival_times < T]
        n_customers = len(arrival_times)
        service_times = service_times[:n_customers]
        
        # Compute departure times
        departure_times = np.zeros(n_customers)
        for i in range(n_customers):
            if i == 0:
                departure_times[i] = arrival_times[i] + service_times[i]
            else:
                departure_times[i] = max(arrival_times[i], departure_times[i-1]) + service_times[i]
        
        # Compute metrics
        wait_times = departure_times - arrival_times - service_times
        system_times = departure_times - arrival_times
        
        return {
            'mean_wait': np.mean(wait_times),
            'mean_system_time': np.mean(system_times),
            'mean_queue_length': np.sum(wait_times) / T,
            'utilization': np.sum(service_times) / T
        }

Portfolio Optimization: Modern Portfolio Theory

portfolio-optimization

Real-World Motivation

Modern Portfolio Theory (MPT), developed by Harry Markowitz in 1952, revolutionized investment management by providing a mathematical framework for diversification. Rather than selecting individual stocks based on expected returns alone, MPT considers the covariance structure of returns to construct portfolios that optimize the risk-return tradeoff. This work earned Markowitz the 1990 Nobel Prize in Economics and remains foundational in quantitative finance.

Definitions

  • Portfolio Return: \(R_p = \sum_{i=1}^n w_i R_i = \mathbf{w}^T \mathbf{R}\) where \(\mathbf{w}\) are portfolio weights.
  • Portfolio Variance: \(\sigma_p^2 = \mathbf{w}^T \Sigma \mathbf{w}\) where \(\Sigma\) is the covariance matrix of returns.
  • Efficient Frontier: The set of portfolios that maximize expected return for a given level of risk (variance).
  • Sharpe Ratio: \(S = \frac{\mathbb{E}[R_p] - R_f}{\sigma_p}\) where \(R_f\) is the risk-free rate.
  • Tangency Portfolio: The portfolio on the efficient frontier with maximum Sharpe ratio.

Theorem: Two-Fund Separation Theorem

Theorem (Two-Fund Separation): Under the assumptions of mean-variance analysis, any efficient portfolio can be constructed as a linear combination of any two distinct efficient portfolios. In particular, all investors hold a combination of the risk-free asset and the tangency portfolio.

Proof Sketch

The efficient frontier is characterized by solving a quadratic optimization problem. The set of solutions forms a one-dimensional curve in weight space. Any point on a line segment can be expressed as a convex combination of two endpoints. Since the optimization is quadratic with linear constraints, the efficient frontier is a parabola in mean-variance space, and any point on it can be reached by combining two portfolios on it.

Notation Guide

  • \(\mathbf{w}\): Vector of portfolio weights
  • \(\mathbf{\mu}\): Vector of expected returns
  • \(\Sigma\): Covariance matrix of returns
  • \(\sigma_p^2 = \mathbf{w}^T \Sigma \mathbf{w}\): Portfolio variance
  • \(\gamma\): Risk aversion parameter
  • \(R_f\): Risk-free rate

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

class PortfolioOptimization:
    """Modern Portfolio Theory implementation."""
    
    def __init__(self, expected_returns, cov_matrix, risk_free_rate=0.02):
        """
        expected_returns: vector of expected returns
        cov_matrix: covariance matrix
        risk_free_rate: annual risk-free rate
        """
        self.mu = np.array(expected_returns)
        self.Sigma = np.array(cov_matrix)
        self.n_assets = len(expected_returns)
        self.rf = risk_free_rate
    
    def portfolio_return(self, weights):
        """Expected portfolio return."""
        return np.dot(weights, self.mu)
    
    def portfolio_variance(self, weights):
        """Portfolio variance."""
        return np.dot(weights, np.dot(self.Sigma, weights))
    
    def portfolio_volatility(self, weights):
        """Portfolio volatility (standard deviation)."""
        return np.sqrt(self.portfolio_variance(weights))
    
    def sharpe_ratio(self, weights):
        """Sharpe ratio of portfolio."""
        excess_return = self.portfolio_return(weights) - self.rf
        return excess_return / self.portfolio_volatility(weights)
    
    def min_variance_portfolio(self):
        """Find minimum variance portfolio."""
        constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        bounds = [(0, 1) for _ in range(self.n_assets)]
        x0 = np.ones(self.n_assets) / self.n_assets
        
        result = minimize(self.portfolio_variance, x0,
                         method='SLSQP', bounds=bounds, constraints=constraints)
        return result.x
    
    def max_sharpe_portfolio(self):
        """Find tangency portfolio (maximum Sharpe ratio)."""
        def neg_sharpe(w):
            return -self.sharpe_ratio(w)
        
        constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
        bounds = [(0, 1) for _ in range(self.n_assets)]
        x0 = np.ones(self.n_assets) / self.n_assets
        
        result = minimize(neg_sharpe, x0,
                         method='SLSQP', bounds=bounds, constraints=constraints)
        return result.x
    
    def efficient_frontier(self, n_points=100):
        """Compute efficient frontier."""
        min_var_weights = self.min_variance_portfolio()
        max_return_weights = np.zeros(self.n_assets)
        max_return_weights[np.argmax(self.mu)] = 1
        
        target_returns = np.linspace(
            self.portfolio_return(min_var_weights),
            self.portfolio_return(max_return_weights),
            n_points
        )
        
        efficient_portfolios = []
        for target in target_returns:
            constraints = [
                {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
                {'type': 'eq', 'fun': lambda w: self.portfolio_return(w) - target}
            ]
            bounds = [(0, 1) for _ in range(self.n_assets)]
            x0 = min_var_weights
            
            result = minimize(self.portfolio_variance, x0,
                            method='SLSQP', bounds=bounds, constraints=constraints)
            if result.success:
                efficient_portfolios.append({
                    'return': target,
                    'volatility': self.portfolio_volatility(result.x),
                    'weights': result.x
                })
        
        return efficient_portfolios

Epidemiological Modeling: The SIR Model and Beyond

epidemiological-modeling

Real-World Motivation

Mathematical epidemiology has never been more relevant than in recent years. The SIR model, developed by Kermack and McKendrick in 1927, provides the foundation for understanding disease spread. These models inform public health policy, vaccination strategies, and pandemic preparedness. The COVID-19 pandemic demonstrated both the power and limitations of mathematical modeling in real-time decision-making.

Definitions

  • SIR Model: Divides population into Susceptible (S), Infected (I), and Recovered (R) compartments: \[\frac{dS}{dt} = -\beta SI, \quad \frac{dI}{dt} = \beta SI - \gamma I, \quad \frac{dR}{dt} = \gamma I\]
  • Basic Reproduction Number: \(R_0 = \frac{\beta S_0}{\gamma}\), the expected number of secondary infections from one infected individual in a fully susceptible population.
  • Herd Immunity Threshold: The fraction of population that must be immune to prevent sustained transmission: \(f_c = 1 - \frac{1}{R_0}\).
  • Final Epidemic Size: The total fraction infected over the course of the epidemic, satisfying: \[R_\infty = 1 - e^{-R_0 R_\infty}\]

Theorem: Threshold Theorem

Theorem (Kermack-McKendrick Threshold): For the SIR model with initial conditions \(S(0) = S_0, I(0) = I_0, R(0) = 0\):

  1. If \(R_0 \leq 1\), the disease dies out: \(I(t) \to 0\) as \(t \to \infty\).
  2. If \(R_0 > 1\), an epidemic occurs: \(I(t)\) initially increases, reaches a maximum when \(S = \gamma/\beta = 1/R_0\), then decreases to 0.
The final size \(R_\infty\) satisfies \(R_\infty = 1 - S_0 e^{-R_0 R_\infty/S_0}\).

Proof Sketch

From the SIR equations, \(\frac{dI}{dS} = -1 + \frac{\gamma}{\beta S}\). Integrating gives \(I + S - \frac{\gamma}{\beta}\ln S = \text{const}\). Since \(I \geq 0\), we have \(S - \frac{\gamma}{\beta}\ln S \geq \text{const}\). The maximum of \(I\) occurs when \(\frac{dI}{dt} = 0\), i.e., when \(S = \gamma/\beta\). For an epidemic to occur, we need \(I\) to initially increase, requiring \(\beta S_0 I_0 > \gamma I_0\), i.e., \(R_0 > 1\).

Notation Guide

  • \(S(t)\): Fraction of population susceptible
  • \(I(t)\): Fraction infected
  • \(R(t)\): Fraction recovered/removed
  • \(\beta\): Infection rate (contact rate × transmission probability)
  • \(\gamma\): Recovery rate (1/infectious period)
  • \(R_0 = \beta/\gamma\): Basic reproduction number
  • \(N = S + I + R\): Total population (normalized to 1)

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint
from scipy.optimize import fsolve

class EpidemiologicalModels:
    """Epidemiological model implementations."""
    
    @staticmethod
    def sir_model(y, t, beta, gamma):
        """
        SIR model differential equations.
        y = [S, I, R]
        """
        S, I, R = y
        dSdt = -beta * S * I
        dIdt = beta * S * I - gamma * I
        dRdt = gamma * I
        return [dSdt, dIdt, dRdt]
    
    @staticmethod
    def solve_sir(S0, I0, R0, beta, gamma, t_max=100, n_points=1000):
        """Solve SIR model numerically."""
        t = np.linspace(0, t_max, n_points)
        y0 = [S0, I0, R0]
        solution = odeint(EpidemiologicalModels.sir_model, y0, t, args=(beta, gamma))
        return t, solution
    
    @staticmethod
    def R0(beta, gamma):
        """Basic reproduction number."""
        return beta / gamma
    
    @staticmethod
    def herd_immunity_threshold(R0):
        """Herd immunity threshold."""
        return 1 - 1/R0
    
    @staticmethod
    def final_size_equation(R_inf, R0):
        """Final size equation: R_inf = 1 - exp(-R0 * R_inf)"""
        return R_inf - (1 - np.exp(-R0 * R_inf))
    
    @staticmethod
    def final_epidemic_size(R0):
        """Solve for final epidemic size."""
        R_inf = fsolve(EpidemiologicalModels.final_size_equation, 0.5, args=(R0,))[0]
        return R_inf

Matroid Theory: Abstract Independence

matroid-theory

Historical Context

Matroid theory was introduced by Hassler Whitney in 1935 as a common generalization of linear independence in vector spaces and independence in graphs. The theory was further developed by Saunders Mac Lane and later by Gian-Carlo Rota and others. Today, matroids connect graph theory, linear algebra, combinatorial optimization, and even algebraic geometry through the theory of tropical geometry.

Definitions

  • Matroid: A pair \((E, \mathcal{I})\) where \(E\) is a finite ground set and \(\mathcal{I} \subseteq 2^E\) satisfies:
    1. \(\emptyset \in \mathcal{I}\) (non-empty)
    2. If \(A \in \mathcal{I}\) and \(B \subseteq A\), then \(B \in \mathcal{I}\) (hereditary)
    3. If \(A, B \in \mathcal{I}\) and \(|A| < |B|\), then \(\exists x \in B \setminus A\) such that \(A \cup \{x\} \in \mathcal{I}\) (exchange)
  • Rank Function: \(r(A) = \max\{|I| : I \subseteq A, I \in \mathcal{I}\}\)
  • Basis: A maximal independent set. All bases have the same cardinality \(r(E)\).
  • Circuit: A minimal dependent set.
  • Graphic Matroid: For a graph \(G = (V, E)\), the independent sets are forests (acyclic edge sets).

Theorem: The Matroid Polytope Theorem

Theorem (Edmonds): Let \(M = (E, \mathcal{I})\) be a matroid with rank function \(r\). The matroid polytope \(P_M\) is the convex hull of characteristic vectors of independent sets: \[P_M = \text{conv}\{\chi_I : I \in \mathcal{I}\}\] This polytope is characterized by: \[P_M = \{x \in \mathbb{R}_+^E : x(A) \leq r(A) \text{ for all } A \subseteq E\}\]

Proof Sketch

The proof uses the greedy algorithm characterization. For any weight function \(w: E \to \mathbb{R}_+\), the greedy algorithm (sort by weight, add if independent) finds a maximum weight independent set. This implies that the linear program \(\max\{w^T x : x(A) \leq r(A), x \geq 0\}\) has an integral optimal solution for all \(w\), which by total unimodularity arguments gives the polytope description.

Notation Guide

  • \(E\): Ground set
  • \(\mathcal{I}\): Collection of independent sets
  • \(r(A)\): Rank of set \(A\)
  • \(\mathcal{B}\): Set of bases
  • \(\mathcal{C}\): Set of circuits
  • \(\chi_I\): Characteristic vector of set \(I\)

import numpy as np
import networkx as nx
from itertools import combinations

class MatroidTheory:
    """Basic matroid theory operations."""
    
    def __init__(self, ground_set, independent_sets):
        """
        ground_set: list of elements
        independent_sets: list of frozensets representing independent sets
        """
        self.E = set(ground_set)
        self.I = set(independent_sets)
        # Verify matroid axioms (simplified check)
    
    def rank(self, A):
        """Compute rank of set A."""
        A = set(A)
        max_size = 0
        for I in self.I:
            if I.issubset(A):
                max_size = max(max_size, len(I))
        return max_size
    
    def is_independent(self, A):
        """Check if A is independent."""
        return frozenset(A) in self.I
    
    @staticmethod
    def graphic_matroid(G):
        """
        Create graphic matroid from NetworkX graph.
        Independent sets are forests (acyclic edge sets).
        """
        E = list(G.edges())
        I = [frozenset()]  # Empty set is independent
        
        # Check all subsets for being forests
        for r in range(1, len(E) + 1):
            for edges in combinations(range(len(E)), r):
                edge_set = [E[i] for i in edges]
                # Create subgraph with these edges
                H = nx.Graph()
                H.add_nodes_from(G.nodes())
                H.add_edges_from(edge_set)
                # Check if forest (no cycles)
                try:
                    cycles = nx.find_cycle(H)
                    is_forest = False
                except nx.NetworkXNoCycle:
                    is_forest = True
                
                if is_forest:
                    I.append(frozenset(edges))
        
        return MatroidTheory(range(len(E)), I)

Percolation Theory: Phase Transitions in Random Media

percolation-theory

Historical Context

Percolation theory was introduced by Broadbent and Hammersley in 1957 to model the flow of fluid through porous media. The model is remarkably simple—sites or bonds on a lattice are randomly declared open or blocked—yet it exhibits rich behavior including phase transitions and critical phenomena. The theory has found applications in physics, materials science, epidemiology, network resilience, and even the study of social influence.

Definitions

  • Site Percolation: Each site of a lattice is open with probability \(p\) and closed with probability \(1-p\), independently.
  • Bond Percolation: Each bond (edge) of a lattice is open with probability \(p\).
  • Cluster: A maximal connected set of open sites (or bonds).
  • Percolation Probability: \(\theta(p) = \mathbb{P}_p(\text{origin is in an infinite cluster})\).
  • Critical Probability: \(p_c = \inf\{p : \theta(p) > 0\}\), the threshold above which an infinite cluster exists.

Theorem: Existence of Phase Transition

Theorem: For site percolation on \(\mathbb{Z}^d\) with \(d \geq 2\):

  1. There exists a critical probability \(p_c \in (0, 1)\).
  2. For \(p < p_c\), all clusters are finite almost surely.
  3. For \(p > p_c\), there exists a unique infinite cluster almost surely.
For the 2D square lattice, \(p_c^{\text{site}} \approx 0.5927\) and \(p_c^{\text{bond}} = 0.5\) (exact).

Proof Sketch

The proof uses a Peierls argument. For small \(p\), the expected number of clusters of size \(n\) containing the origin decays exponentially, implying all clusters are finite. For large \(p\) near 1, comparison with supercritical branching processes shows infinite clusters exist. The uniqueness of the infinite cluster (for \(p > p_c\)) follows from the Burton-Keane argument using translation invariance and the finite energy property.

Notation Guide

  • \(\mathbb{Z}^d\): d-dimensional integer lattice
  • \(p\): Occupation probability
  • \(p_c\): Critical probability
  • \(\theta(p)\): Percolation probability
  • \(\chi(p)\): Mean cluster size
  • \(C_0\): Cluster containing the origin
  • \(\xi(p)\): Correlation length

        labeled_array, num_features = label(lattice)

        """Check if there's a cluster spanning left-right or top-bottom."""
        labeled, _ = PercolationTheory.find_clusters(lattice)
        
        # Check left-right spanning
        left_labels = set(labeled[:, 0])
        right_labels = set(labeled[:, -1])
        if left_labels & right_labels - {0}:
            return True
        
        # Check top-bottom spanning
        top_labels = set(labeled[0, :])
        bottom_labels = set(labeled[-1, :])
        if top_labels & bottom_labels - {0}:
            return True
        
        return False

                if PercolationTheory.has_spanning_cluster(lattice):
                    count += 1
            spanning_probs.append(count / n_trials)
        return spanning_probs

        """Estimate correlation length from cluster sizes."""
        labeled, num_features = PercolationTheory.find_clusters(lattice)
        cluster_sizes = []
        for i in range(1, num_features + 1):
            size = np.sum(labeled == i)
            cluster_sizes.append(size)
        
        if len(cluster_sizes) == 0:
            return 0
        
        # Correlation length ~ sqrt(mean cluster size)
        mean_size = np.mean(cluster_sizes)
        return np.sqrt(mean_size)

Quantum Computing: Shor's Algorithm

quantum-computing

Historical Context

In 1994, Peter Shor at Bell Labs discovered a quantum algorithm that could factor integers in polynomial time, providing an exponential speedup over the best known classical algorithms. This result had profound implications for cryptography, as RSA encryption relies on the difficulty of factoring. Shor's algorithm demonstrated that quantum computers, if built at sufficient scale, could break widely-used encryption schemes. This discovery catalyzed massive investment in quantum computing research.

Definitions

  • Qubit: A quantum bit, represented as a unit vector in \(\mathbb{C}^2\): \(|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\) where \(|\alpha|^2 + |\beta|^2 = 1\).
  • Quantum Gate: Unitary operations on qubits. Key gates include:
    • Hadamard: \(H = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\)
    • Phase: \(S = \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix}\)
    • CNOT: Controlled-NOT on two qubits
  • Quantum Fourier Transform (QFT): The quantum analog of the discrete Fourier transform, implementable with \(O(n^2)\) gates on \(n\) qubits (vs \(O(n2^n)\) classically).
  • Period Finding: Given \(f: \mathbb{Z}_N \to \mathbb{Z}_N\), find the smallest \(r\) such that \(f(x + r) = f(x)\) for all \(x\).

Theorem: Shor's Algorithm

Theorem (Shor, 1994): There exists a quantum algorithm that, given an integer \(N\), finds a non-trivial factor of \(N\) with probability at least \(1/2\) using \(O((\log N)^3)\) quantum gates and \(O(\log N)\) qubits.

Algorithm Overview:

  1. Classical reduction: To factor \(N\), it suffices to find the order of a random element \(a\) modulo \(N\) (the smallest \(r\) with \(a^r \equiv 1 \pmod{N}\)).
  2. Quantum period finding: Use QFT to find the period of \(f(x) = a^x \mod N\).
  3. Classical post-processing: Use continued fractions to extract the period from the quantum measurement.
  4. If \(r\) is even and \(a^{r/2} \not\equiv -1 \pmod{N}\), then \(\gcd(a^{r/2} \pm 1, N)\) gives a factor.

Proof Sketch

The quantum algorithm creates a superposition \(\frac{1}{\sqrt{q}}\sum_{x=0}^{q-1}|x\rangle|a^x \mod N\rangle\). Measuring the second register collapses the first to a superposition of values with the same function value: \(\frac{1}{\sqrt{m}}\sum_{j=0}^{m-1}|x_0 + jr\rangle\). Applying QFT transforms this into a state peaked at multiples of \(q/r\). Measuring gives a value close to \(kq/r\) for some \(k\), from which \(r\) can be extracted using continued fractions.

Notation Guide

  • \(|0\rangle, |1\rangle\): Computational basis states
  • \(|\psi\rangle\): General quantum state
  • \(\otimes\): Tensor product
  • \(H^{\otimes n}\): Hadamard transform on n qubits
  • \(QFT_N\): Quantum Fourier transform modulo \(N\)
  • \(\text{ord}_N(a)\): Multiplicative order of \(a\) modulo \(N\)

import numpy as np
import matplotlib.pyplot as plt
from math import gcd, log2, ceil

class QuantumComputing:
    """Classical simulation of quantum computing concepts."""
    
    @staticmethod
    def modular_exponentiation(a, x, N):
        """Compute a^x mod N efficiently."""
        result = 1
        a = a % N
        while x > 0:
            if x & 1:
                result = (result * a) % N
            a = (a * a) % N
            x >>= 1
        return result
    
    @staticmethod
    def find_order_classical(a, N):
        """Classically find the order of a modulo N."""
        if gcd(a, N) != 1:
            return None
        
        x = 1
        for r in range(1, N):
            x = (x * a) % N
            if x == 1:
                return r
        return None
    
    @staticmethod
    def continued_fraction(x, max_terms=20):
        """Compute continued fraction expansion of x."""
        terms = []
        for _ in range(max_terms):
            a = int(x)
            terms.append(a)
            if abs(x - a) < 1e-10:
                break
            x = 1 / (x - a)
        return terms
    
    @staticmethod
    def convergents(terms):
        """Compute convergents from continued fraction terms."""
        convergents_list = []
        for i in range(len(terms)):
            num, den = 1, 0
            for t in reversed(terms[:i+1]):
                num, den = t * num + den, num
            convergents_list.append((num, den))
        return convergents_list
    
    @staticmethod
    def shors_algorithm_classical(N, max_attempts=10):
        """
        Classical simulation of Shor's algorithm.
        Returns a non-trivial factor of N or None.
        """
        if N % 2 == 0:
            return 2
        
        for _ in range(max_attempts):
            # Step 1: Choose random a coprime to N
            a = np.random.randint(2, N)
            g = gcd(a, N)
            if g > 1:
                return g
            
            # Step 2: Find order of a (classically simulated)
            r = QuantumComputing.find_order_classical(a, N)
            if r is None or r % 2 != 0:
                continue
            
            # Step 3: Check if a^(r/2) ≡ -1 (mod N)
            a_r_half = QuantumComputing.modular_exponentiation(a, r // 2, N)
            if a_r_half == N - 1:
                continue
            
            # Step 4: Compute factors
            factor1 = gcd(a_r_half - 1, N)
            factor2 = gcd(a_r_half + 1, N)
            
            if factor1 > 1 and factor1 < N:
                return factor1
            if factor2 > 1 and factor2 < N:
                return factor2
        
        return None
    
    @staticmethod
    def quantum_fourier_transform_matrix(N):
        """Generate the N×N QFT matrix."""
        omega = np.exp(2j * np.pi / N)
        F = np.array([[omega**(i*j) for j in range(N)] for i in range(N)])
        return F / np.sqrt(N)

The Four Color Theorem

four-color-theorem

Historical Context

The Four Color Conjecture, posed by Francis Guthrie in 1852, asked whether any map could be colored with just four colors such that no adjacent regions share the same color. Despite its simple statement, the problem resisted proof for over a century. Alfred Kempe published an incorrect proof in 1879 that stood for 11 years. Finally, in 1976, Kenneth Appel and Wolfgang Haken proved the theorem using a computer to check 1,936 unavoidable configurations—a proof that was controversial at the time for its reliance on computational verification.

Definitions

  • Planar Graph: A graph that can be drawn on a plane without edge crossings.
  • Proper Coloring: An assignment of colors to vertices such that adjacent vertices have different colors.
  • Chromatic Number: \(\chi(G)\), the minimum number of colors needed for a proper coloring.
  • Dual Graph: For a map, the dual graph has a vertex for each region and edges connecting adjacent regions.
  • Unavoidable Set: A set of configurations such that every planar map contains at least one of them.
  • Reducible Configuration: A configuration that cannot appear in a minimal counterexample to the Four Color Theorem.

Theorem: The Four Color Theorem

Theorem (Appel-Haken, 1976; Robertson-Sanders-Seymour-Thomas, 1997): Every planar graph has chromatic number at most 4. Equivalently, every map can be colored with at most 4 colors such that no adjacent regions have the same color.

Proof Approach

The proof uses the method of discharging:

  1. Assume a minimal counterexample exists (a planar graph requiring 5 colors with minimum vertices).
  2. Assign "charge" to vertices based on degree: \(ch(v) = 6 - \deg(v)\).
  3. By Euler's formula, total charge is 12.
  4. Redistribute charge according to discharging rules.
  5. Show that every planar graph contains a reducible configuration from the unavoidable set.
  6. Since reducible configurations cannot appear in minimal counterexamples, no counterexample exists.

Notation Guide

  • \(\chi(G)\): Chromatic number of graph \(G\)
  • \(\Delta(G)\): Maximum degree of \(G\)
  • \(\delta(G)\): Minimum degree of \(G\)
  • \(V, E, F\): Vertices, edges, faces of a planar graph
  • \(ch(v)\): Charge of vertex \(v\)

import numpy as np
import networkx as nx
import matplotlib.pyplot as plt
from itertools import permutations

class FourColorTheorem:
    """Four color theorem demonstrations and algorithms."""
    
    @staticmethod
    def is_valid_coloring(G, coloring):
        """Check if a coloring is valid (no adjacent vertices share color)."""
        for u, v in G.edges():
            if coloring.get(u) == coloring.get(v):
                return False
        return True
    
    @staticmethod
    def greedy_coloring(G, order=None):
        """
        Greedy coloring algorithm.
        Returns a coloring using at most Δ(G) + 1 colors.
        """
        coloring = {}
        nodes = order if order else list(G.nodes())
        
        for node in nodes:
            # Find colors used by neighbors
            neighbor_colors = {coloring.get(n) for n in G.neighbors(node) if n in coloring}
            # Assign smallest available color
            color = 0
            while color in neighbor_colors:
                color += 1
            coloring[node] = color
        
        return coloring
    
    @staticmethod
    def welsh_powell_coloring(G):
        """Welsh-Powell coloring: order by descending degree."""
        nodes = sorted(G.nodes(), key=lambda n: G.degree(n), reverse=True)
        return FourColorTheorem.greedy_coloring(G, nodes)
    
    @staticmethod
    def backtrack_coloring(G, max_colors=4):
        """Backtracking algorithm to find coloring with at most max_colors."""
        nodes = list(G.nodes())
        coloring = {}
        
        def backtrack(index):
            if index == len(nodes):
                return True
            
            node = nodes[index]
            neighbor_colors = {coloring.get(n) for n in G.neighbors(node) if n in coloring}
            
            for color in range(max_colors):
                if color not in neighbor_colors:
                    coloring[node] = color
                    if backtrack(index + 1):
                        return True
                    del coloring[node]
            
            return False
        
        if backtrack(0):
            return coloring
        return None
    
    @staticmethod
    def create_map_graph():
        """Create a sample map-like planar graph."""
        G = nx.Graph()
        # Create a graph resembling a map with regions
        edges = [
            (0, 1), (0, 2), (0, 3),  # Center region 0
            (1, 2), (1, 4), (1, 5),  # Region 1
            (2, 3), (2, 4), (2, 6),  # Region 2
            (3, 6), (3, 7),          # Region 3
            (4, 5), (4, 6),          # Region 4
            (5, 7), (6, 7)           # Regions 5, 6, 7
        ]
        G.add_edges_from(edges)
        return G

📜 Math History: Emmy Noether and the Birth of Modern Algebra

Amalie Emmy Noether (1882–1935) was one of the most influential mathematicians of the 20th century, despite facing extraordinary obstacles as a Jewish woman in early 20th-century Germany. Her work transformed the landscape of abstract algebra and had profound implications for physics.

Born in Erlangen, Germany, to a family of mathematicians, Noether initially faced significant barriers to academic employment. Women were not officially permitted to habilitate (earn the right to teach at universities) in Prussia. It was only through the intervention of David Hilbert and Felix Klein that she was able to lecture at Göttingen—initially under Hilbert's name.

Noether's 1921 paper "Idealtheorie in Ringbereichen" (Ideal Theory in Ring Domains) revolutionized commutative algebra. She introduced the ascending chain condition, defining what we now call Noetherian rings—rings in which every ascending chain of ideals stabilizes. This condition, seemingly technical, captured the essential finiteness properties needed for many algebraic structures. Today, nearly every ring studied in algebraic geometry and number theory is Noetherian.

Her work on representation theory and invariant theory was equally groundbreaking. Noether's theorem in physics, which she proved in 1915, established a fundamental connection between symmetries and conservation laws: every continuous symmetry of a physical system corresponds to a conserved quantity. This theorem underlies modern theoretical physics, from classical mechanics to quantum field theory.

In 1933, the Nazi regime dismissed Noether from her position. She emigrated to the United States, joining Bryn Mawr College and the Institute for Advanced Study. Her sudden death in 1935 from complications following surgery cut short a remarkable career. Albert Einstein wrote in her obituary: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began."

Noether's legacy extends far beyond her theorems. She pioneered the abstract, axiomatic approach that defines modern algebra, influencing generations of mathematicians including Emil Artin, Bartel van der Waerden (whose "Modern Algebra" textbook spread her approach), and countless others. Her emphasis on structural properties over computational manipulation fundamentally changed how mathematics is done.

IMO Shortlist Problem: Functional Equation

Problem: Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all real numbers \(x, y\): \[f(xf(y) + f(x)) = 2f(x) + xy\]

Hint

First, try to find \(f(0)\) by substituting specific values. Then investigate injectivity and surjectivity. Consider what happens when you set \(x = 1\).

Solution

Step 1: Let \(P(x, y)\) denote the assertion \(f(xf(y) + f(x)) = 2f(x) + xy\).

Step 2: From \(P(1, y)\): \(f(f(y) + f(1)) = 2f(1) + y\).

This shows \(f\) is bijective (the right side covers all reals).

Step 3: Since \(f\) is surjective, there exists \(a\) such that \(f(a) = 0\).

From \(P(a, y)\): \(f(af(y)) = ay\).

Step 4: From \(P(x, a)\): \(f(f(x)) = 2f(x) + ax\).

Step 5: From \(P(1, a)\): \(f(f(1)) = 2f(1) + a\).

But from Step 4 with \(x = 1\): \(f(f(1)) = 2f(1) + a\). ✓

Step 6: Let's find \(a\). From \(P(a, a)\): \(f(0) = a^2\).

Step 7: From \(P(x, 0)\) using \(f(0) = a^2\): \[f(xf(0) + f(x)) = 2f(x)\] \[f(a^2 x + f(x)) = 2f(x)\]

Step 8: From Step 4: \(f(f(x)) = 2f(x) + ax\).

If we can show \(f(x) = cx + d\), we can solve. Let's try \(f(x) = cx\).

Step 9: Substituting \(f(x) = cx\): \[c(x \cdot cy + cx) = 2cx + xy\] \[c^2xy + c^2x = 2cx + xy\]

For this to hold for all \(x, y\):

  • Coefficient of \(xy\): \(c^2 = 1\), so \(c = \pm 1\)
  • Coefficient of \(x\): \(c^2 = 2c\), so \(c = 0\) or \(c = 2\)

No solution of form \(f(x) = cx\).

Step 10: Try \(f(x) = x + c\): \[xf(y) + f(x) + c = x(y+c) + x + c + c = xy + cx + x + 2c\] \[2f(x) + xy = 2(x+c) + xy = 2x + 2c + xy\]

Need: \(xy + cx + x + 2c = 2x + 2c + xy\)

So: \(cx + x = 2x\), giving \(c = 1\).

Verification: \(f(x) = x + 1\): \[f(x(y+1) + x + 1) = f(xy + x + x + 1) = xy + 2x + 1 + 1 = xy + 2x + 2\] \[2f(x) + xy = 2(x+1) + xy = 2x + 2 + xy\] ✓

Answer: The unique solution is \(\boxed{f(x) = x + 1}\).

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of mathematics' most iconic images—a fractal boundary between bounded and unbounded orbits under iteration of the complex quadratic map \(f_c(z) = z^2 + c\). Discovered by Benoit Mandelbrot in 1980, it reveals infinite complexity at every scale.

A point \(c\) is in the Mandelbrot set if the sequence starting at \(z = 0\) remains bounded under repeated application of \(f_c\). The boundary of this set exhibits self-similarity: zooming in reveals copies of the whole set, along with intricate filaments and miniature galaxies of structure.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point is in the set (doesn't escape).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M
