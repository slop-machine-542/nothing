Knot Theory: The Mathematics of Entanglement

Motivation

Knot theory studies closed loops embedded in three-dimensional space. What began as a Victorian attempt to classify atoms has evolved into a rich field connecting topology, algebra, and physics. Knot invariants help distinguish different entanglements and have surprising applications in DNA biology, polymer chemistry, and quantum field theory.

Definitions

Knot: A smooth embedding of the circle \( S^1 \) into \(\mathbb{R}^3\) (or \(S^3\)).

Link: A finite disjoint union of knots.

Ambient Isotopy: Two knots \(K_1\) and \(K_2\) are equivalent if there exists a continuous deformation of \(\mathbb{R}^3\) taking \(K_1\) to \(K_2\).

Knot Invariant: A quantity assigned to knots that is unchanged under ambient isotopy.

Theorem: The Jones Polynomial is a Knot Invariant

For any oriented link \(L\), there exists a unique Laurent polynomial \(V_L(t) \in \mathbb{Z}[t^{1/2}, t^{-1/2}]\) satisfying:

1. Normalization: \(V_O(t) = 1\) for the unknot \(O\).

2. Skein relation: For three links \(L_+, L_-, L_0\) differing only at a single crossing: \[ t^{-1} V_{L_+}(t) - t V_{L_-}(t) = (t^{1/2} - t^{-1/2}) V_{L_0}(t) \]

Notation Guide

  • \(S^1\) — unit circle
  • \(S^3\) — 3-sphere (compactification of \(\mathbb{R}^3\))
  • \(V_L(t)\) — Jones polynomial of link \(L\)
  • \(\mathbb{Z}[t^{1/2}, t^{-1/2}]\) — Laurent polynomials in \(t^{1/2}\)

class KnotDiagram:
    """
    Representation of a knot diagram with crossings.
    """
    def __init__(self, crossings, signs):
        """
        crossings: list of (over, under) strand pairs
        signs: list of +1 or -1 for each crossing
        """
        self.crossings = crossings
        self.signs = signs
        self.n_crossings = len(crossings)
    
    def writhe(self):
        """Calculate writhe (sum of crossing signs)."""
        return sum(self.signs)
    
    def kauffman_bracket(self, A):
        """
        Compute Kauffman bracket polynomial (simplified version).
        A is the formal variable.
        """
        # Simplified implementation using state sum
        # For a full implementation, use specialized libraries
        n = self.n_crossings
        states = list(product([0, 1], repeat=n))
        
        result = 0
        for state in states:
            # Count loops in the resolution
            loops = self._count_loops(state)
            power = sum(s * self.signs[i] for i, s in enumerate(state))
            result += A**power * (-A**2 - A**(-2))**(loops - 1)
        
        return result
    
    def _count_loops(self, state):
        """Count number of loops in a given state."""
        # Simplified: actual implementation requires tracing strands
        return len(state) // 2 + 1
    
    def jones_polynomial(self, t):
        """
        Compute Jones polynomial from Kauffman bracket.
        """
        A = t**(-1/4)
        bracket = self.kauffman_bracket(A)
        writhe = self.writhe()
        return (-A**3)**(-writhe) * bracket

Ergodic Theory: Long-Term Behavior of Dynamical Systems

Motivation

Ergodic theory studies dynamical systems from a statistical perspective, asking: what fraction of time does a system spend in different regions of phase space? Originating in statistical mechanics, it has become essential for understanding chaotic systems, number theory (via continued fractions), and even information theory.

Definitions

Measure-Preserving System: A probability space \((X, \mathcal{B}, \mu)\) with a measurable map \(T: X \to X\) such that \(\mu(T^{-1}(A)) = \mu(A)\) for all measurable \(A\).

Ergodic: A measure-preserving system is ergodic if the only invariant measurable sets have measure 0 or 1. Equivalently, time averages equal space averages.

Mixing: Stronger than ergodicity: \(\lim_{n \to \infty} \mu(T^{-n}(A) \cap B) = \mu(A)\mu(B)\).

Theorem: Birkhoff's Ergodic Theorem

Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(f \in L^1(\mu)\). Then for almost every \(x \in X\): \[ \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x)) = \mathbb{E}[f | \mathcal{I}](x) \] where \(\mathcal{I}\) is the \(\sigma\)-algebra of invariant sets. If \(T\) is ergodic: \[ \lim_{n \to \infty} \frac{1}{n} \sum_{k=0}^{n-1} f(T^k(x)) = \int_X f \, d\mu \]

Notation Guide

  • \(L^1(\mu)\) — space of integrable functions
  • \(\mathbb{E}[f | \mathcal{I}]\) — conditional expectation
  • \(T^k\) — k-fold composition of \(T\)
  • \(\sigma\)-algebra — collection of measurable sets

import numpy as np
import matplotlib.pyplot as plt

class CircleRotation:
    """
    Circle rotation: T(x) = x + alpha (mod 1)
    Ergodic iff alpha is irrational.
    """
    def __init__(self, alpha):
        self.alpha = alpha % 1.0
        self.irrational = self._check_irrational()
    
    def _check_irrational(self):
        """Check if alpha is irrational (heuristic)."""
        # Check continued fraction convergents
        from fractions import Fraction
        f = Fraction(self.alpha).limit_denominator(1000)
        return abs(float(f) - self.alpha) < 1e-10
    
    def iterate(self, x0, n):
        """Generate n iterates starting from x0."""
        orbit = np.zeros(n)
        x = x0
        for i in range(n):
            orbit[i] = x
            x = (x + self.alpha) % 1.0
        return orbit
    
    def time_average(self, f, x0, n):
        """
        Compute time average of function f along orbit.
        f should be a function accepting values in [0,1].
        """
        orbit = self.iterate(x0, n)
        return np.mean(f(orbit))
    
    def space_average(self, f, n_samples=10000):
        """Compute space average by uniform sampling."""
        samples = np.random.uniform(0, 1, n_samples)
        return np.mean(f(samples))

    """

Algebraic Number Theory: The Arithmetic of Number Fields

Motivation

Algebraic number theory extends the study of integers to larger number systems called number fields. It provides the framework for understanding Diophantine equations, Fermat's Last Theorem, and modern cryptography. The theory of ideals, developed by Dedekind, resolved the failure of unique factorization in these extended settings.

Definitions

Number Field: A finite extension \(K/\mathbb{Q}\). The degree \([K:\mathbb{Q}]\) is the dimension of \(K\) as a \(\mathbb{Q}\)-vector space.

Ring of Integers: \(\mathcal{O}_K = \{x \in K : x \text{ is integral over } \mathbb{Z}\}\), the integral closure of \(\mathbb{Z}\) in \(K\).

Ideal: An additive subgroup \(I \subseteq \mathcal{O}_K\) such that \(\mathcal{O}_K \cdot I \subseteq I\).

Prime Ideal: A proper ideal \(\mathfrak{p}\) such that \(ab \in \mathfrak{p}\) implies \(a \in \mathfrak{p}\) or \(b \in \mathfrak{p}\).

Theorem: Dedekind's Unique Factorization of Ideals

Every nonzero proper ideal in \(\mathcal{O}_K\) factors uniquely (up to ordering) as a product of prime ideals: \[ I = \mathfrak{p}_1^{e_1} \mathfrak{p}_2^{e_2} \cdots \mathfrak{p}_r^{e_r} \] where the \(\mathfrak{p}_i\) are distinct prime ideals and \(e_i \geq 1\).

Notation Guide

  • \(K/\mathbb{Q}\) — field extension
  • \([K:\mathbb{Q}]\) — degree of extension
  • \(\mathcal{O}_K\) — ring of integers
  • \(\mathfrak{p}, \mathfrak{q}\) — prime ideals (Gothic letters)

import numpy as np
from fractions import Fraction

class QuadraticField:
    """
    Quadratic field Q(sqrt(d)) where d is squarefree.
    """
    def __init__(self, d):
        self.d = d
        if int(np.sqrt(abs(d)))**2 == abs(d):
            raise ValueError("d must be squarefree")
        self.discriminant = self._compute_discriminant()
    
    def _compute_discriminant(self):
        """Compute field discriminant."""
        d = self.d
        if d % 4 == 1:
            return d
        else:
            return 4 * d
    
    def ring_of_integers_basis(self):
        """
        Return basis for ring of integers.
        For d ≡ 1 (mod 4): {1, (1+√d)/2}
        Otherwise: {1, √d}
        """
        if self.d % 4 == 1:
            return [(1, 0), (Fraction(1,2), Fraction(1,2))]
        else:
            return [(1, 0), (0, 1)]
    
    def norm(self, a, b):
        """
        Norm of a + b√d is (a + b√d)(a - b√d) = a² - db².
        """
        return a**2 - self.d * b**2
    
    def trace(self, a, b):
        """
        Trace of a + b√d is (a + b√d) + (a - b√d) = 2a.
        """
        return 2 * a
    
    def multiply(self, x, y):
        """
        Multiply two elements x = (a,b), y = (c,d) 
        representing a + b√d and c + d√d.
        """
        a, b = x
        c, d = y
        # (a + b√d)(c + d√d) = (ac + bd*d) + (ad + bc)√d
        return (a*c + b*d*self.d, a*d + b*c)
    
    def is_unit(self, a, b):
        """Check if element is a unit (norm = ±1)."""
        return abs(self.norm(a, b)) == 1
    
    def fundamental_unit(self, max_iter=1000):
        """
        Find fundamental unit for real quadratic field (d > 0).
        Uses continued fractions of sqrt(d).
        """
        if self.d < 0:
            # For imaginary quadratic, only roots of unity
            if self.d == -1:
                return [(0, 1), (-1, 0)]  # i, -1
            elif self.d == -3:
                return [(Fraction(-1,2), Fraction(1,2))]  # primitive 6th root
            else:
                return [(-1, 0)]  # only -1
        
        # For real quadratic, find minimal solution to x² - dy² = ±1
        from math import isqrt
        d = self.d
        m, d_exp, a0 = 0, 1, isqrt(d)
        if a0 * a0 == d:
            return None
        
        period = []
        seen = {}
        while (m, d_exp, a0) not in seen:
            seen[(m, d_exp, a0)] = len(period)
            m = d_exp * a0 - m
            d_exp = (d - m * m) // d_exp
            a0 = (isqrt(d) + m) // d_exp
            period.append(a0)
        
        # Fundamental unit from convergent
        # Simplified: return first solution
        for y in range(1, max_iter):
            x_sq = 1 + d * y * y
            x = isqrt(x_sq)
            if x * x == x_sq:
                return (x, y)
            x_sq = -1 + d * y * y
            if x_sq > 0:
                x = isqrt(x_sq)
                if x * x == x_sq:
                    return (x, y)
        return None

Control Theory: Stabilizing Dynamical Systems

Motivation

Control theory provides the mathematical framework for steering dynamical systems toward desired behaviors. From autopilot systems to insulin pumps, from power grids to robotic arms, control theory enables precise manipulation of complex systems. The field combines differential equations, optimization, and linear algebra.

Definitions

State-Space System: \(\dot{x} = Ax + Bu\), \(y = Cx + Du\) where \(x\) is state, \(u\) is input, \(y\) is output.

Controllability: The system is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists an input \(u(t)\) steering \(x_0\) to \(x_f\).

Observability: The system is observable if the initial state can be determined from the output history.

Stability: The system is asymptotically stable if all eigenvalues of \(A\) have negative real parts.

Theorem: Pole Placement

If \((A, B)\) is controllable, then for any desired set of eigenvalues \(\{\lambda_1, \ldots, \lambda_n\}\) (closed under complex conjugation), there exists a feedback matrix \(K\) such that \(A - BK\) has exactly these eigenvalues. The system \(\dot{x} = (A - BK)x\) is stabilized by the control law \(u = -Kx\).

Notation Guide

  • \(A \in \mathbb{R}^{n \times n}\) — state matrix
  • \(B \in \mathbb{R}^{n \times m}\) — input matrix
  • \(C \in \mathbb{R}^{p \times n}\) — output matrix
  • \(\mathcal{C} = [B \ AB \ A^2B \ \cdots \ A^{n-1}B]\) — controllability matrix

Python Code

import numpy as np
from scipy.linalg import solve_continuous_are, eig, expm
import matplotlib.pyplot as plt

class LinearSystem:
    """
    Linear time-invariant system: dx/dt = Ax + Bu, y = Cx + Du
    """
    def __init__(self, A, B, C=None, D=None):
        self.A = np.array(A, dtype=float)
        self.B = np.array(B, dtype=float)
        self.n = self.A.shape[0]  # state dimension
        self.m = self.B.shape[1]  # input dimension
        
        self.C = np.eye(self.n) if C is None else np.array(C, dtype=float)
        self.D = np.zeros((self.C.shape[0], self.m)) if D is None else np.array(D, dtype=float)
        self.p = self.C.shape[0]  # output dimension
    
    def controllability_matrix(self):
        """Compute the controllability matrix."""
        C = self.B
        for i in range(1, self.n):
            C = np.hstack([C, np.linalg.matrix_power(self.A, i) @ self.B])
        return C
    
    def is_controllable(self, tol=1e-10):
        """Check if system is controllable."""
        C = self.controllability_matrix()
        return np.linalg.matrix_rank(C, tol=tol) == self.n
    
    def observability_matrix(self):
        """Compute the observability matrix."""
        O = self.C
        for i in range(1, self.n):
            O = np.vstack([O, self.C @ np.linalg.matrix_power(self.A, i)])
        return O
    
    def is_observable(self, tol=1e-10):
        """Check if system is observable."""
        O = self.observability_matrix()
        return np.linalg.matrix_rank(O, tol=tol) == self.n
    
    def eigenvalues(self):
        """Return eigenvalues of A."""
        return eig(self.A)[0]
    
    def is_stable(self):
        """Check if system is asymptotically stable."""
        return np.all(np.real(self.eigenvalues()) < 0)
    
    def lqr_controller(self, Q, R):
        """
        Design LQR controller minimizing ∫(x'Qx + u'Ru)dt.
        Returns gain matrix K where u = -Kx.
        """
        # Solve Algebraic Riccati Equation: A'P + PA - PBR^(-1)B'P + Q = 0
        P = solve_continuous_are(self.A, self.B, Q, R)
        K = np.linalg.solve(R, self.B.T @ P)
        return K, P
    
    def simulate(self, x0, u_func, t_span, dt=0.01):
        """
        Simulate system with given input function.
        u_func: function taking (t, x) and returning control input
        """
        t = np.arange(t_span[0], t_span[1], dt)
        n_steps = len(t)
        
        x = np.zeros((self.n, n_steps))
        y = np.zeros((self.p, n_steps))
        u = np.zeros((self.m, n_steps))
        
        x[:, 0] = x0
        y[:, 0] = self.C @ x0
        
        for i in range(n_steps - 1):
            u[:, i] = u_func(t[i], x[:, i])
            # Euler integration (simple)
            dx = self.A @ x[:, i] + self.B @ u[:, i]
            x[:, i+1] = x[:, i] + dt * dx
            y[:, i+1] = self.C @ x[:, i+1] + self.D @ u[:, i]
        
        u[:, -1] = u_func(t[-1], x[:, -1])
        return t, x, y, u

class InvertedPendulum(LinearSystem):
    """
    Linearized inverted pendulum on a cart.
    State: [cart_position, pendulum_angle, cart_velocity, pendulum_angular_velocity]
    """
    def __init__(self, M=1.0, m=0.1, l=0.5, g=9.81):
        """
        M: cart mass
        m: pendulum mass
        l: pendulum length
        g: gravity
        """
        self.M, self.m, self.l, self.g = M, m, l, g
        
        # Linearized dynamics around upright position
        denom = M + m
        A = np.array([
            [0, 0, 1, 0],
            [0, 0, 0, 1],
            [0, -m*g/denom, 0, 0],
            [0, (M+m)*g/(denom*l), 0, 0]
        ])
        
        B = np.array([
            [0],
            [0],

Network Science: Graph Structure and Dynamics

Motivation

Network science studies complex systems as interconnected collections of nodes and edges. From social networks to power grids, from neural connections to the internet, understanding network structure reveals how information, diseases, and behaviors spread. The field combines graph theory, statistical physics, and data science.

Definitions

Graph: A pair \(G = (V, E)\) where \(V\) is a set of vertices and \(E \subseteq V \times V\) is a set of edges.

Adjacency Matrix: For a graph with \(n\) vertices, \(A\) is the \(n \times n\) matrix where \(A_{ij} = 1\) if \((i,j) \in E\), 0 otherwise.

Degree: \(k_i = \sum_j A_{ij}\), the number of connections of vertex \(i\).

Clustering Coefficient: \(C_i = \frac{\text{number of triangles through } i}{\binom{k_i}{2}}\), measuring local connectivity.

Theorem: Spectral Gap and Expansion

For a \(d\)-regular graph with adjacency matrix eigenvalues \(d = \lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_n\), the spectral gap \(\lambda_1 - \lambda_2\) controls expansion:

For any subset \(S \subseteq V\) with \(|S| \leq n/2\): \[ \frac{e(S, \bar{S})}{|S|} \geq \frac{d - \lambda_2}{2} \] where \(e(S, \bar{S})\) is the number of edges between \(S\) and its complement.

Notation Guide

  • \(V\) — vertex set
  • \(E\) — edge set
  • \(A\) — adjacency matrix
  • \(L = D - A\) — Laplacian matrix (D is degree matrix)
  • \(\lambda_2\) — second smallest eigenvalue of \(L\) (algebraic connectivity)

import numpy as np
import matplotlib.pyplot as plt
from collections import deque

class Graph:
    """
    Undirected graph represented by adjacency matrix.
    """
    def __init__(self, n):
        self.n = n
        self.A = np.zeros((n, n), dtype=int)
    
    def add_edge(self, i, j):
        """Add undirected edge between vertices i and j."""
        self.A[i, j] = 1
        self.A[j, i] = 1
    
    def degree(self, i):
        """Degree of vertex i."""
        return np.sum(self.A[i, :])
    
    def degree_sequence(self):
        """Return sorted degree sequence."""
        degrees = np.sum(self.A, axis=1)
        return np.sort(degrees)[::-1]
    
    def clustering_coefficient(self, i):
        """Local clustering coefficient of vertex i."""
        neighbors = np.where(self.A[i, :] == 1)[0]
        k = len(neighbors)
        if k < 2:
            return 0.0
        
        # Count edges between neighbors
        edges_between = 0
        for j in range(k):
            for l in range(j+1, k):
                if self.A[neighbors[j], neighbors[l]] == 1:
                    edges_between += 1
        
        return 2 * edges_between / (k * (k - 1))
    
    def global_clustering(self):
        """Global clustering coefficient (transitivity)."""
        coeffs = [self.clustering_coefficient(i) for i in range(self.n)]
        return np.mean(coeffs)
    
    def shortest_path(self, source, target):
        """BFS shortest path."""
        queue = deque([(source, [source])])
        visited = {source}
        
        while queue:
            node, path = queue.popleft()
            if node == target:
                return path
            
            for neighbor in np.where(self.A[node, :] == 1)[0]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append((neighbor, path + [neighbor]))
        
        return None  # No path
    
    def average_path_length(self, sample_size=None):
        """Average shortest path length."""
        if sample_size is None:
            sample_size = self.n
        
        total_length = 0
        count = 0
        for _ in range(sample_size):
            i, j = np.random.choice(self.n, 2, replace=False)
            path = self.shortest_path(i, j)
            if path is not None:
                total_length += len(path) - 1
                count += 1
        
        return total_length / count if count > 0 else float('inf')
    
    def laplacian(self):
        """Compute Laplacian matrix L = D - A."""
        D = np.diag(np.sum(self.A, axis=1))
        return D - self.A
    
    def spectral_gap(self):
        """Compute spectral gap (algebraic connectivity)."""
        L = self.laplacian()
        eigenvalues = np.sort(np.linalg.eigvalsh(L))
        return eigenvalues[1] if len(eigenvalues) > 1 else 0
    
    def eigenvector_centrality(self, iterations=100):
        """Compute eigenvector centrality."""
        x = np.ones(self.n) / self.n
        for _ in range(iterations):
            x = self.A @ x
            x = x / np.linalg.norm(x)
        return x
    
    def betweenness_centrality(self):
        """Compute betweenness centrality (simplified)."""
        betweenness = np.zeros(self.n)
        
        for s in range(self.n):
            for t in range(s+1, self.n):
                path = self.shortest_path(s, t)
                if path is not None:
                    for node in path[1:-1]:  # Exclude endpoints
                        betweenness[node] += 1
        
        return betweenness

class RandomGraph:

    def erdos_renyi(n, p):
        """Generate Erdős-Rényi G(n,p) random graph."""
        G = Graph(n)

            for j in range(i+1, n):

    def barabasi_albert(n, m):
        """
        Generate Barabási-Albert preferential attachment graph.
        n: total number of nodes
        m: number of edges to attach from new node
        """
        G = Graph(n)
        
        # Start with m connected nodes
        for i in range(m):
            for j in range(i+1, m):
                G.add_edge(i, j)
        
        # Add remaining nodes with preferential attachment
        degrees = np.array([G.degree(i) for i in range(m)])
        
        for new_node in range(m, n):
            # Select m nodes to connect to, with probability proportional to degree
            probs = degrees / np.sum(degrees)
            targets = np.random.choice(new_node, size=m, replace=False, p=probs)
            
            for target in targets:
                G.add_edge(new_node, target)
            
            degrees = np.append(degrees, m)
            for t in targets:
                degrees[t] += 1
        
        return G

Machine Learning: Optimization and Generalization

Motivation

Machine learning algorithms learn patterns from data to make predictions. The mathematical foundations involve optimization (finding model parameters), probability (quantifying uncertainty), and functional analysis (understanding what functions can be learned). Understanding these foundations helps explain why neural networks work and when they fail.

Definitions

Hypothesis Space: The set \(\mathcal{H}\) of functions from which the learning algorithm selects a model.

Empirical Risk: \(\hat{R}(f) = \frac{1}{n} \sum_{i=1}^n \ell(f(x_i), y_i)\), the average loss on training data.

Expected Risk: \(R(f) = \mathbb{E}_{(x,y) \sim P}[\ell(f(x), y)]\), the true performance on the data distribution.

Rademacher Complexity: A measure of the richness of \(\mathcal{H}\), used to bound generalization error.

Theorem: Uniform Convergence

With probability at least \(1-\delta\) over the training data of size \(n\), for all \(f \in \mathcal{H}\): \[ R(f) \leq \hat{R}(f) + 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\log(1/\delta)}{2n}} \] where \(\mathfrak{R}_n(\mathcal{H})\) is the Rademacher complexity of the hypothesis space.

Notation Guide

  • \(\mathcal{H}\) — hypothesis space
  • \(\ell\) — loss function
  • \(\hat{R}\) — empirical risk
  • \(R\) — expected risk
  • \(\mathfrak{R}_n(\mathcal{H})\) — Rademacher complexity

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification, make_moons
from sklearn.model_selection import train_test_split

class GradientDescent:
    """
    Gradient descent optimization for machine learning.
    """
    def __init__(self, learning_rate=0.01, max_iter=1000, tol=1e-6):
        self.lr = learning_rate
        self.max_iter = max_iter
        self.tol = tol
        self.history = {'loss': [], 'params': []}
    
    def optimize(self, loss_fn, grad_fn, x0):
        """
        Minimize loss_fn starting from x0.
        loss_fn: function to minimize
        grad_fn: gradient of loss_fn
        """
        x = np.array(x0, dtype=float)
        
        for i in range(self.max_iter):
            loss = loss_fn(x)
            grad = grad_fn(x)
            
            self.history['loss'].append(loss)
            self.history['params'].append(x.copy())
            
            # Check convergence
            if np.linalg.norm(grad) < self.tol:
                break
            
            # Gradient step
            x = x - self.lr * grad
        
        return x

class LinearRegression:
    """
    Linear regression with gradient descent.
    """
    def __init__(self, fit_intercept=True):
        self.fit_intercept = fit_intercept
        self.weights = None
        self.bias = None
    
    def fit(self, X, y, method='analytic', **kwargs):
        """
        Fit linear regression.
        method: 'analytic' or 'gradient_descent'
        """
        n, d = X.shape
        
        if self.fit_intercept:
            X_aug = np.column_stack([np.ones(n), X])
        else:
            X_aug = X
        
        if method == 'analytic':
            # Normal equation: (X'X)^(-1) X'y
            self.weights = np.linalg.solve(X_aug.T @ X_aug, X_aug.T @ y)
        else:
            # Gradient descent
            gd = GradientDescent(**kwargs)
            
            def loss(w):
                return np.mean((X_aug @ w - y)**2) / 2
            
            def grad(w):
                return X_aug.T @ (X_aug @ w - y) / n
            
            w0 = np.zeros(X_aug.shape[1])
            self.weights = gd.optimize(loss, grad, w0)
        
        if self.fit_intercept:
            self.bias = self.weights[0]
            self.weights = self.weights[1:]
        
        return self
    
    def predict(self, X):
        """Make predictions."""
        if self.fit_intercept:
            return X @ self.weights + self.bias
        return X @ self.weights
    
    def score(self, X, y):
        """R² score."""
        y_pred = self.predict(X)
        ss_res = np.sum((y - y_pred)**2)
        ss_tot = np.sum((y - np.mean(y))**2)
        return 1 - ss_res / ss_tot

class LogisticRegression:
    """
    Logistic regression for binary classification.
    """
    def __init__(self, fit_intercept=True, regularization=0.0):
        self.fit_intercept = fit_intercept
        self.reg = regularization
        self.weights = None
        self.bias = None
    
    def _sigmoid(self, z):
        """Sigmoid function."""
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
    
    def fit(self, X, y, max_iter=1000, lr=0.1):
        """Fit using gradient descent."""
        n, d = X.shape
        
        if self.fit_intercept:
            X_aug = np.column_stack([np.ones(n), X])
            w = np.zeros(d + 1)
        else:
            X_aug = X
            w = np.zeros(d)
        
        for _ in range(max_iter):
            # Predictions
            z = X_aug @ w
            p = self._sigmoid(z)
            
            # Gradient with L2 regularization
            grad = X_aug.T @ (p - y) / n + self.reg * w
            
            # Update
            w -= lr * grad
        
        if self.fit_intercept:
            self.bias = w[0]
            self.weights = w[1:]
        else:
            self.weights = w
        
        return self
    
    def predict_proba(self, X):
        """Predict probabilities."""
        if self.fit_intercept:
            z = X @ self.weights + self.bias
        else:
            z = X @ self.weights
        return self._sigmoid(z)
    
    def predict(self, X):
        """Predict classes."""
        return (self.predict_proba(X) >= 0.5).astype(int)
    
    def score(self, X, y):
        """Accuracy."""
        return np.mean(self.predict(X) == y)

class NeuralNetwork:
    """
    Simple 2-layer neural network.
    """
    def __init__(self, hidden_size=10, learning_rate=0.1, max_iter=1000):
        self.hidden_size = hidden_size
        self.lr = learning_rate
        self.max_iter = max_iter
        self.W1 = None
        self.b1 = None
        self.W2 = None
        self.b2 = None
    
    def _relu(self, z):
        return np.maximum(0, z)
    
    def _relu_deriv(self, z):
        return (z > 0).astype(float)
    
    def _sigmoid(self, z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
    
    def fit(self, X, y):
        """Train using backpropagation."""
        n, d = X.shape
        
        # Initialize weights
        self.W1 = np.random.randn(d, self.hidden_size) * 0.01
        self.b1 = np.zeros(self.hidden_size)
        self.W2 = np.random.randn(self.hidden_size, 1) * 0.01
        self.b2 = 0
        
        y = y.reshape(-1, 1)
        
        for i in range(self.max_iter):
            # Forward pass
            z1 = X @ self.W1 + self.b1
            a1 = self._relu(z1)
            z2 = a1 @ self.W2 + self.b2
            a2 = self._sigmoid(z2)
            
            # Backward pass
            dz2 = a2 - y
            dW2 = a1.T @ dz2 / n
            db2 = np.sum(dz2) / n
            
            da1 = dz2 @ self.W2.T
            dz1 = da1 * self._relu_deriv(z1)
            dW1 = X.T @ dz1 / n
            db1 = np.sum(dz1, axis=0) / n
            
            # Update
            self.W2 -= self.lr * dW2
            self.b2 -= self.lr * db2
            self.W1 -= self.lr * dW1
            self.b1 -= self.lr * db1
        
        return self
    
    def predict(self, X):
        """Predict classes."""
        z1 = X @ self.W1 + self.b1
        a1 = self._relu(z1)
        z2 = a1 @ self.W2 + self.b2
        a2 = self._sigmoid(z2)
        return (a2 >= 0.5).astype(int).flatten()
    
    def score(self, X, y):
        """Accuracy."""
        return np.mean(self.predict(X) == y)

Topological Data Analysis: Persistent Homology

Motivation

Topological data analysis (TDA) uses techniques from algebraic topology to understand the shape of data. Persistent homology tracks how topological features (connected components, holes, voids) appear and disappear as we vary a scale parameter, providing robust descriptors of complex data structures.

Definitions

Simplicial Complex: A collection of simplices (points, edges, triangles, tetrahedra) closed under taking faces.

Vietoris-Rips Complex: For a metric space \(X\) and scale \(\epsilon\), the VR complex has a simplex for every finite subset of \(X\) with diameter \(\leq \epsilon\).

Persistent Homology: Tracks homology classes (connected components, cycles, voids) across a filtration of simplicial complexes.

Barcode: A graphical representation of persistence, where each interval represents a topological feature's lifetime.

Theorem: Stability of Persistence

Let \(X\) and \(Y\) be finite metric spaces with persistence diagrams \(D_X\) and \(D_Y\). Then: \[ d_B(D_X, D_Y) \leq 2 \cdot d_{GH}(X, Y) \] where \(d_B\) is the bottleneck distance and \(d_{GH}\) is the Gromov-Hausdorff distance. This shows small perturbations in data cause small changes in persistence.

Notation Guide

  • \(H_k(X)\) — k-th homology group
  • \(\beta_k = \dim H_k\) — k-th Betti number
  • \(VR_\epsilon(X)\) — Vietoris-Rips complex at scale \(\epsilon\)
  • \(d_B\) — bottleneck distance between diagrams

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import pdist, squareform
from collections import defaultdict

class Simplex:
    """Represents a simplex as a frozenset of vertices."""
    def __init__(self, vertices):
        self.vertices = frozenset(vertices)
        self.dimension = len(vertices) - 1
    
    def __hash__(self):
        return hash(self.vertices)
    
    def __eq__(self, other):
        return self.vertices == other.vertices
    
    def faces(self):
        """Return all faces of dimension one less."""
        if self.dimension == 0:
            return []
        return [Simplex(self.vertices - {v}) for v in self.vertices]

class VietorisRipsComplex:
    """
    Vietoris-Rips complex from point cloud data.
    """
    def __init__(self, points, max_epsilon=None):
        self.points = np.array(points)
        self.n_points = len(points)
        self.distances = squareform(pdist(points))
        
        if max_epsilon is None:
            max_epsilon = np.max(self.distances)
        self.max_epsilon = max_epsilon
    
    def build_complex(self, epsilon):
        """
        Build VR complex at scale epsilon.
        Returns set of simplices.
        """
        simplices = set()
        
        # Add 0-simplices (vertices)
        for i in range(self.n_points):
            simplices.add(Simplex({i}))
        
        # Add higher-dimensional simplices
        # A simplex exists if all pairwise distances <= epsilon
        def can_form_simplex(vertices):
            for i in vertices:
                for j in vertices:
                    if i < j and self.distances[i, j] > epsilon:
                        return False
            return True
        
        # Add edges (1-simplices)
        for i in range(self.n_points):
            for j in range(i+1, self.n_points):
                if self.distances[i, j] <= epsilon:
                    simplices.add(Simplex({i, j}))
        
        # Add triangles (2-simplices)
        for i in range(self.n_points):
            for j in range(i+1, self.n_points):
                for k in range(j+1, self.n_points):
                    if can_form_simplex({i, j, k}):
                        simplices.add(Simplex({i, j, k}))
        
        return simplices
    
    def get_filtration(self, n_steps=20):
        """
        Get filtration of complexes at increasing scales.
        """
        epsilons = np.linspace(0, self.max_epsilon, n_steps)
        filtration = []
        for eps in epsilons:
            filtration.append((eps, self.build_complex(eps)))
        return filtration

class PersistentHomology:
    """
    Simplified persistent homology computation.
    Tracks connected components (0-dimensional homology).
    """
    def __init__(self, vr_complex):
        self.vr = vr_complex
    
    def compute_zero_persistence(self):
        """
        Compute 0-dimensional persistence (connected components).
        Returns list of (birth, death) pairs.
        """
        filtration = self.vr.get_filtration(n_steps=50)
        
        persistence_pairs = []
        
        # Track when each point first appears (always at epsilon=0)
        for i in range(self.vr.n_points):
            persistence_pairs.append((0, None))  # (birth, death)
        
        # Track connected components as epsilon increases
        prev_components = None
        
        for eps, simplices in filtration:
            # Find connected components
            components = self._find_components(simplices)
            
            if prev_components is not None:
                # Check for merges
                for i, comp in enumerate(components):
                    # Find which previous components merged into this one
                    prev_indices = [j for j, pc in enumerate(prev_components) 
                                   if any(v in pc for v in comp)]
                    if len(prev_indices) > 1:
                        # Components merged; earlier ones "die"
                        for idx in prev_indices[1:]:
                            if persistence_pairs[idx][1] is None:
                                persistence_pairs[idx] = (persistence_pairs[idx][0], eps)
            
            prev_components = components
        
        # Components that never die die at infinity (use max_epsilon)
        for i, (birth, death) in enumerate(persistence_pairs):
            if death is None:
                persistence_pairs[i] = (birth, self.vr.max_epsilon)
        
        return persistence_pairs
    
    def _find_components(self, simplices):
        """Find connected components from edge set."""
        # Build adjacency list from edges
        adj = defaultdict(set)
        for s in simplices:
            if s.dimension == 1:  # Edge
                v1, v2 = list(s.vertices)
                adj[v1].add(v2)
                adj[v2].add(v1)
        
        # BFS to find components
        visited = set()
        components = []
        
        for v in range(self.vr.n_points):
            if v not in visited:
                component = []
                queue = [v]
                visited.add(v)
                
                while queue:
                    node = queue.pop(0)
                    component.append(node)
                    for neighbor in adj[node]:
                        if neighbor not in visited:
                            visited.add(neighbor)
                            queue.append(neighbor)
                
                components.append(set(component))
        
        return components
    
    def plot_persistence_diagram(self, persistence_pairs):
        """Plot persistence diagram."""
        births = [p[0] for p in persistence_pairs]
        deaths = [p[1] for p in persistence_pairs]
        
        plt.figure(figsize=(8, 8))
        plt.scatter(births, deaths, s=50, alpha=0.6)
        
        # Diagonal line
        max_val = max(max(births), max(deaths))

        plt.xlabel('Birth')
        plt.ylabel('Death')
        plt.title('0-Dimensional Persistence Diagram')
        plt.legend()
        plt.grid(True, alpha=0.3)
        
        return plt

        plt.figure(figsize=(10, 6))

        plt.title('Persistence Barcode (0-dimensional)')
        plt.grid(True, alpha=0.3)
        
        return plt

Graph Theory: Extremal Problems

Motivation

Extremal graph theory asks: what is the maximum or minimum number of edges in a graph satisfying certain constraints? These questions have deep connections to combinatorics, geometry, and computer science. The field began with Mantel's theorem in 1907 and flourished with Turán's and Ramsey's contributions.

Definitions

Extremal Number: \(\text{ex}(n, H)\) is the maximum number of edges in an \(n\)-vertex graph not containing \(H\) as a subgraph.

Turán Graph: \(T_r(n)\) is the complete \(r\)-partite graph with parts as equal as possible.

Independence Number: \(\alpha(G)\) is the size of the largest set of vertices with no edges between them.

Theorem: Turán's Theorem

For any integer \(r \geq 2\), if \(G\) is a graph on \(n\) vertices with no \((r+1)\)-clique, then: \[ |E(G)| \leq |E(T_r(n))| \] with equality if and only if \(G \cong T_r(n)\).

The Turán graph \(T_r(n)\) has approximately \((1 - \frac{1}{r})\frac{n^2}{2}\) edges.

Notation Guide

  • \(\text{ex}(n, H)\) — extremal number
  • \(T_r(n)\) — Turán graph
  • \(K_r\) — complete graph on \(r\) vertices
  • \(\alpha(G)\) — independence number

import numpy as np
import matplotlib.pyplot as plt
from itertools import combinations

class ExtremalGraph:
    """
    Tools for extremal graph theory.
    """
    @staticmethod
    def turan_graph(n, r):
        """
        Construct Turán graph T_r(n): complete r-partite graph
        with parts as equal as possible.
        """
        # Determine part sizes
        base_size = n // r
        remainder = n % r
        
        parts = []
        vertex = 0
        for i in range(r):
            size = base_size + (1 if i < remainder else 0)
            parts.append(list(range(vertex, vertex + size)))
            vertex += size
        
        # Build adjacency matrix
        A = np.zeros((n, n), dtype=int)
        for i, part1 in enumerate(parts):
            for j, part2 in enumerate(parts):
                if i != j:  # Connect different parts
                    for u in part1:
                        for v in part2:
                            A[u, v] = 1
                            A[v, u] = 1
        
        return A, parts
    
    @staticmethod
    def count_edges(A):
        """Count edges in graph (undirected)."""
        return np.sum(A) // 2
    
    @staticmethod
    def has_clique(A, k):
        """Check if graph contains k-clique (brute force)."""
        n = A.shape[0]
        for vertices in combinations(range(n), k):
            is_clique = True
            for i, j in combinations(vertices, 2):
                if A[i, j] == 0:
                    is_clique = False
                    break
            if is_clique:
                return True
        return False
    
    @staticmethod
    def independence_number(A):
        """Find independence number (size of maximum independent set)."""
        n = A.shape[0]
        max_ind = 0
        
        # Try all subsets (exponential - only for small graphs)
        for size in range(n, 0, -1):
            for vertices in combinations(range(n), size):
                is_independent = True
                for i, j in combinations(vertices, 2):
                    if A[i, j] == 1:
                        is_independent = False
                        break
                if is_independent:
                    return size
        return 0
    
    @staticmethod
    def ramsey_number_lower_bound(s, t, iterations=1000):
        """
        Probabilistic lower bound for R(s,t).
        Returns graph with no s-clique and no t-independent set.
        """
        n = s + t  # Start with guess
        
        for _ in range(iterations):
            # Try random graph
            p = 0.5
            A = (np.random.random((n, n)) < p).astype(int)
            A = np.triu(A, 1)  # Upper triangle
            A = A + A.T  # Symmetric
            
            if not ExtremalGraph.has_clique(A, s):
                if ExtremalGraph.independence_number(A) < t:
                    return A, n
            
            n += 1
            if n > s + t + 10:
                break
        
        return None, None

Combinatorial Optimization: The Traveling Salesman Problem

Motivation

The Traveling Salesman Problem (TSP) asks for the shortest possible route visiting each city exactly once and returning to the origin. Despite its simple statement, TSP is NP-hard and has driven advances in optimization, linear programming, and approximation algorithms. It has practical applications in logistics, circuit design, and DNA sequencing.

Definitions

TSP Instance: A complete graph \(K_n\) with edge weights \(w: E \to \mathbb{R}_{\geq 0}\).

Tour: A Hamiltonian cycle in \(K_n\), visiting each vertex exactly once.

Optimal Tour: A tour with minimum total weight.

Metric TSP: Edge weights satisfy the triangle inequality: \(w(i,j) + w(j,k) \geq w(i,k)\).

Theorem: Christofides' Approximation Algorithm

For metric TSP, Christofides' algorithm produces a tour with cost at most \(1.5\) times optimal:

1. Compute minimum spanning tree \(T\).

2. Let \(O\) be the set of odd-degree vertices in \(T\).

3. Find minimum-weight perfect matching \(M\) on \(O\).

4. Form Eulerian multigraph from \(T \cup M\).

5. Shortcut to obtain Hamiltonian cycle.

The resulting tour satisfies: \(c(\text{tour}) \leq 1.5 \cdot c(\text{OPT})\).

Notation Guide

  • \(K_n\) — complete graph on n vertices
  • \(w(i,j)\) — weight of edge (i,j)
  • MST — minimum spanning tree
  • \(O\) — set of odd-degree vertices

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import pdist, squareform

class TSP:
    """
    Traveling Salesman Problem solvers.
    """
    def __init__(self, points):
        """
        points: array of (x, y) coordinates
        """
        self.points = np.array(points)
        self.n = len(points)
        self.distances = squareform(pdist(points))
    
    def nearest_neighbor(self, start=0):
        """
        Greedy nearest neighbor heuristic.
        """
        tour = [start]
        unvisited = set(range(self.n)) - {start}
        current = start
        total_cost = 0
        
        while unvisited:
            next_city = min(unvisited, key=lambda x: self.distances[current, x])
            total_cost += self.distances[current, next_city]
            tour.append(next_city)
            unvisited.remove(next_city)
            current = next_city
        
        # Return to start
        total_cost += self.distances[current, start]
        tour.append(start)
        
        return tour, total_cost
    
    def two_opt(self, tour, max_iterations=1000):
        """
        2-opt local search improvement.
        """
        tour = tour[:-1]  # Remove return to start
        improved = True
        iteration = 0
        
        while improved and iteration < max_iterations:
            improved = False
            iteration += 1
            
            for i in range(self.n - 1):
                for j in range(i + 2, self.n):
                    # Check if swapping edges (i,i+1) and (j,j+1) helps
                    # New edges: (i,j) and (i+1,j+1)
                    old_cost = (self.distances[tour[i], tour[i+1]] + 
                               self.distances[tour[j], tour[(j+1) % self.n]])
                    new_cost = (self.distances[tour[i], tour[j]] + 
                               self.distances[tour[i+1], tour[(j+1) % self.n]])
                    
                    if new_cost < old_cost:
                        # Reverse segment between i+1 and j
                        tour[i+1:j+1] = reversed(tour[i+1:j+1])
                        improved = True
        
        # Close the tour
        tour.append(tour[0])
        cost = self.tour_cost(tour)
        return tour, cost
    
    def tour_cost(self, tour):
        """Calculate total cost of tour."""
        cost = 0
        for i in range(len(tour) - 1):
            cost += self.distances[tour[i], tour[i+1]]
        return cost
    
    def mst_cost(self):
        """
        Compute Minimum Spanning Tree using Prim's algorithm.
        Returns total weight and edge list.
        """
        in_mst = [False] * self.n
        key = [float('inf')] * self.n
        parent = [-1] * self.n
        
        key[0] = 0
        total_weight = 0
        edges = []
        
        for _ in range(self.n):
            # Find minimum key vertex not in MST
            u = min((i for i in range(self.n) if not in_mst[i]), 
                   key=lambda x: key[x])
            
            in_mst[u] = True
            total_weight += key[u]
            
            if parent[u] != -1:
                edges.append((parent[u], u))
            
            # Update keys
            for v in range(self.n):
                if not in_mst[v] and self.distances[u, v] < key[v]:
                    key[v] = self.distances[u, v]
                    parent[v] = u
        
        return total_weight, edges
    
    def christofides(self):
        """
        Christofides' 1.5-approximation algorithm.
        Simplified implementation.
        """
        # Step 1: Compute MST
        mst_weight, mst_edges = self.mst_cost()
        
        # Step 2: Find odd-degree vertices
        degree = [0] * self.n
        for u, v in mst_edges:
            degree[u] += 1
            degree[v] += 1
        
        odd_vertices = [i for i in range(self.n) if degree[i] % 2 == 1]
        
        # Step 3: Minimum weight perfect matching on odd vertices
        # Simplified: use greedy matching
        matching = []
        unmatched = set(odd_vertices)
        while len(unmatched) > 1:
            u = unmatched.pop()
            v = min(unmatched, key=lambda x: self.distances[u, x])
            unmatched.remove(v)
            matching.append((u, v))
        
        # Step 4 & 5: Form Eulerian tour and shortcut
        # Simplified: use nearest neighbor on the combined graph
        tour, cost = self.nearest_neighbor()
        
        # Lower bound: MST weight is ≤ OPT
        lower_bound = mst_weight
        
        return tour, cost, lower_bound
    
    def plot_tour(self, tour, title="TSP Tour"):
        """Visualize the tour."""
        plt.figure(figsize=(10, 10))
        
        # Plot points
        plt.scatter(self.points[:, 0], self.points[:, 1], s=100, c='red', zorder=3)
        
        # Plot tour
        for i in range(len(tour) - 1):
            u, v = tour[i], tour[i+1]
            plt.plot([self.points[u, 0], self.points[v, 0]],
                    [self.points[u, 1], self.points[v, 1]],
                    'b-', linewidth=1, alpha=0.7)
        
        # Label cities
        for i, (x, y) in enumerate(self.points):
            plt.annotate(str(i), (x, y), textcoords="offset points", 
                        xytext=(5, 5), fontsize=10)
        
        plt.title(title)
        plt.xlabel('x')
        plt.ylabel('y')
        plt.axis('equal')
        plt.grid(True, alpha=0.3)
        
        return plt

Information Geometry: The Geometry of Probability

Motivation

Information geometry studies the differential geometric structure of families of probability distributions. The Fisher information metric defines a Riemannian geometry on statistical manifolds, providing insights into parameter estimation, machine learning, and statistical inference. It reveals deep connections between statistics, information theory, and geometry.

Definitions

Statistical Manifold: A family of probability distributions \(S = \{p(x; \theta)\}\) parameterized by \(\theta \in \Theta \subseteq \mathbb{R}^n\).

Fisher Information Matrix: \[ g_{ij}(\theta) = \mathbb{E}\left[\frac{\partial \log p(x;\theta)}{\partial \theta_i} \frac{\partial \log p(x;\theta)}{\partial \theta_j}\right] \]

Kullback-Leibler Divergence: \[ D_{KL}(p \| q) = \int p(x) \log \frac{p(x)}{q(x)} dx \]

Theorem: Cramér-Rao Bound

For any unbiased estimator \(\hat{\theta}\) of \(\theta\) based on \(n\) i.i.d. samples: \[ \text{Cov}(\hat{\theta}) \geq \frac{1}{n} g^{-1}(\theta) \] where \(g(\theta)\) is the Fisher information matrix. The variance of any unbiased estimator is bounded below by the inverse Fisher information.

Notation Guide

  • \(g_{ij}\) — Fisher information metric
  • \(\Gamma_{ij}^k\) — Christoffel symbols (connection)
  • \(D_{KL}\) — Kullback-Leibler divergence
  • \(I(\theta)\) — Fisher information

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm, beta
from scipy.integrate import quad

class InformationGeometry:
    """
    Information geometry calculations for probability distributions.
    """
    @staticmethod
    def fisher_information_gaussian_mean(sigma):
        """
        Fisher information for mean of Gaussian with known variance.
        I(μ) = 1/σ²
        """
        return 1.0 / (sigma ** 2)
    
    @staticmethod
    def fisher_information_gaussian_variance(mu):
        """
        Fisher information for variance of Gaussian with known mean.
        I(σ²) = 1/(2σ⁴)
        """
        # Returns function of sigma
        return lambda sigma: 1.0 / (2 * sigma ** 4)
    
    @staticmethod
    def kl_divergence_gaussian(mu1, sigma1, mu2, sigma2):
        """
        KL divergence between two Gaussians.
        D_KL(N(μ₁,σ₁²) || N(μ₂,σ₂²))
        """
        return (np.log(sigma2 / sigma1) + 
                (sigma1**2 + (mu1 - mu2)**2) / (2 * sigma2**2) - 0.5)
    
    @staticmethod
    def kl_divergence_beta(a1, b1, a2, b2, n_points=1000):
        """
        Numerical KL divergence between Beta distributions.
        """
        # Use numerical integration
        def integrand(x):
            if x <= 0 or x >= 1:
                return 0
            p1 = beta.pdf(x, a1, b1)
            p2 = beta.pdf(x, a2, b2)
            if p1 == 0 or p2 == 0:
                return 0
            return p1 * np.log(p1 / p2)
        
        result, _ = quad(integrand, 0, 1, limit=100)
        return result

class NaturalGradient:
    """
    Natural gradient descent using Fisher information.
    """
    def __init__(self, learning_rate=0.01):
        self.lr = learning_rate
    
    def step_gaussian_mean(self, mu, sigma, gradient):
        """
        Natural gradient step for Gaussian mean.
        Update: μ ← μ - η · g^(-1) · ∇ = μ - η · σ² · ∇
        """
        fisher_inv = sigma ** 2  # Inverse Fisher information
        return mu - self.lr * fisher_inv * gradient
    
    def step_gaussian_variance(self, mu, sigma, gradient):
        """
        Natural gradient step for Gaussian variance.
        """
        fisher_inv = 2 * sigma ** 4  # Inverse Fisher information
        sigma_new_sq = sigma**2 - self.lr * fisher_inv * gradient
        return np.sqrt(max(sigma_new_sq, 1e-6))

The Development of Modern Probability Theory

Probability theory, now a cornerstone of mathematics with applications spanning from quantum physics to finance, had surprisingly humble origins in gambling and games of chance. The formal development of probability as a mathematical discipline began in 1654 when the French mathematician Blaise Pascal received a letter from Antoine Gombaud, Chevalier de Méré, a gambler seeking advice on a dice problem. This correspondence between Pascal and Pierre de Fermat laid the foundations for mathematical probability.

The early problems they tackled seem simple today: How many throws of two dice are needed for the probability of getting double sixes to exceed 50%? What is the fair division of stakes in an interrupted game? Yet these questions required new mathematical tools. Pascal developed his famous triangle, and both mathematicians established the basic principles of counting and expectation.

Christiaan Huygens published the first book on probability theory in 1657, "De Ratiociniis in Ludo Aleae" (On Reasoning in Games of Chance). Jacob Bernoulli's "Ars Conjectandi" (The Art of Conjecturing), published posthumously in 1713, introduced the law of large numbers and elevated probability from gambling calculations to a tool for understanding uncertainty in general.

The 18th and 19th centuries saw probability applied to demography, astronomy, and the social sciences. Abraham de Moivre discovered the normal distribution as an approximation to the binomial. Laplace developed Bayesian inference and applied probability to celestial mechanics. The field gained mathematical rigor through the work of Chebyshev, Markov, and Lyapunov in Russia, who established the central limit theorem and founded the study of stochastic processes.

The modern axiomatic foundation was laid by Andrey Kolmogorov in 1933. His "Grundbegriffe" defined probability as a measure on a sigma-algebra, unifying discrete and continuous probability and connecting the field to measure theory. This axiomatization allowed probability to flourish as a rigorous mathematical discipline while maintaining its connections to applications.

Today, probability theory underlies machine learning, statistical physics, financial mathematics, and information theory. The journey from Pascal's gambling problems to modern stochastic calculus illustrates how practical questions can drive profound mathematical development, and how abstract foundations can enable unforeseen applications centuries later.

Putnam Competition Problem (B5, 2003)

Let \(n\) be a positive integer. Let \(f_n\) be the number of sequences of length \(n\) consisting of 0s and 1s such that the sequence does not contain three consecutive 0s and does not contain three consecutive 1s. Find a recurrence relation for \(f_n\) and compute \(f_{10}\).

Hint

Consider the last one or two terms of valid sequences. Define auxiliary sequences based on how the sequence ends: let \(a_n\) be the number of valid sequences of length \(n\) ending in a single 0, \(b_n\) ending in double 0s, and similarly for 1s.

Solution

Let us define:

  • \(a_n^{(0)}\) = number of valid sequences of length \(n\) ending in exactly one 0
  • \(a_n^{(00)}\) = number of valid sequences of length \(n\) ending in exactly two 0s
  • \(a_n^{(1)}\) = number of valid sequences of length \(n\) ending in exactly one 1
  • \(a_n^{(11)}\) = number of valid sequences of length \(n\) ending in exactly two 1s

The recurrence relations are:

\(a_n^{(0)} = a_{n-1}^{(1)} + a_{n-1}^{(11)}\) (append 0 to sequences ending in 1)

\(a_n^{(00)} = a_{n-1}^{(0)}\) (append 0 to sequences ending in single 0)

\(a_n^{(1)} = a_{n-1}^{(0)} + a_{n-1}^{(00)}\) (append 1 to sequences ending in 0)

\(a_n^{(11)} = a_{n-1}^{(1)}\) (append 1 to sequences ending in single 1)

Base case: \(a_1^{(0)} = a_1^{(1)} = 1\), others are 0.

The Lorenz Attractor: Deterministic Chaos

The Lorenz system, introduced by Edward Lorenz in 1963, is a simplified model of atmospheric convection. It consists of three ordinary differential equations that exhibit chaotic solutions for certain parameter values. The famous "butterfly" shape of the Lorenz attractor has become an iconic image of chaos theory.

The system is defined by:

\[ \frac{dx}{dt} = \sigma(y - x) \] \[ \frac{dy}{dt} = x(\rho - z) - y \] \[ \frac{dz}{dt} = xy - \beta z \]

where \(\sigma\) is the Prandtl number, \(\rho\) is the Rayleigh number, and \(\beta\) is a geometric factor. For \(\sigma = 10, \rho = 28, \beta = 8/3\), the system exhibits chaotic behavior with sensitive dependence on initial conditions.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class LorenzSystem:
    """
    Lorenz system: dx/dt = σ(y-x), dy/dt = x(ρ-z)-y, dz/dt = xy-βz
    """
    def __init__(self, sigma=10.0, rho=28.0, beta=8.0/3.0):
        self.sigma = sigma
        self.rho = rho
        self.beta = beta
    
    def derivative(self, state):
        """Compute derivatives."""
        x, y, z = state
        dx = self.sigma * (y - x)
        dy = x * (self.rho - z) - y
        dz = x * y - self.beta * z
        return np.array([dx, dy, dz])
    
    def integrate(self, initial_state, t_span, dt=0.01):
        """
        Integrate using 4th-order Runge-Kutta.
        """
        t = np.arange(t_span[0], t_span[1], dt)
        n_steps = len(t)
        
        trajectory = np.zeros((n_steps, 3))
        trajectory[0] = initial_state
        
        for i in range(n_steps - 1):
            state = trajectory[i]
            
            # RK4
            k1 = self.derivative(state)
            k2 = self.derivative(state + 0.5 * dt * k1)
            k3 = self.derivative(state + 0.5 * dt * k2)
            k4 = self.derivative(state + dt * k3)
            
            trajectory[i+1] = state + (dt/6) * (k1 + 2*k2 + 2*k3 + k4)
        
        return t, trajectory
    
    def plot_attractor(self, initial_state=(1, 1, 1), t_span=(0, 50), 
                       dt=0.01, figsize=(12, 10)):
        """
        Plot the Lorenz attractor.
        """
        t, traj = self.integrate(initial_state, t_span, dt)
        
        fig = plt.figure(figsize=figsize)
        
        # 3D plot
        ax = fig.add_subplot(221, projection='3d')
        ax.plot(traj[:, 0], traj[:, 1], traj[:, 2], 
                linewidth=0.5, alpha=0.8, color='blue')
        ax.set_xlabel('X')
        ax.set_ylabel('Y')
        ax.set_zlabel('Z')
        ax.set_title('Lorenz Attractor (3D)')
        
        # XY projection
        ax2 = fig.add_subplot(222)
        ax2.plot(traj[:, 0], traj[:, 1], linewidth=0.5, alpha=0.8)
        ax2.set_xlabel('X')
        ax2.set_ylabel('Y')
        ax2.set_title('XY Projection')
        ax2.grid(True, alpha=0.3)
        
        # XZ projection
        ax3 = fig.add_subplot(223)
        ax3.plot(traj[:, 0], traj[:, 2], linewidth=0.5, alpha=0.8)
        ax3.set_xlabel('X')
        ax3.set_ylabel('Z')
        ax3.set_title('XZ Projection')
        ax3.grid(True, alpha=0.3)
        
        # Time series of X
        ax4 = fig.add_subplot(224)
        ax4.plot(t, traj[:, 0], linewidth=0.8)
        ax4.set_xlabel('Time')
        ax4.set_ylabel('X')
        ax4.set_title('Time Series of X')
        ax4.grid(True, alpha=0.3)
        
        plt.tight_layout()
        return fig
    
    def demonstrate_sensitivity(self, initial_states, t_span=(0, 30), dt=0.01):
        """
        Demonstrate sensitive dependence on initial conditions.
        """
        fig, axes = plt.subplots(1, 2, figsize=(14, 5))
        
        colors = ['blue', 'red', 'green', 'orange']
        trajectories = []
        
        for i, init in enumerate(initial_states):
            t, traj = self.integrate(init, t_span, dt)
            trajectories.append(traj)
            
            # 3D plot
            axes[0].plot(traj[:, 0], traj[:, 1], traj[:, 2], 
                        linewidth=0.5, alpha=0.7, color=colors[i % len(colors)],
                        label=f'Start {i+1}')
        
        axes[0].set_xlabel('X')
        axes[0].set_ylabel('Y')
        axes[0].set_title('Multiple Trajectories')
        axes[0].legend()
        
        # Distance between trajectories
        if len(trajectories) >= 2:
            dist = np.sqrt(np.sum((trajectories[0] - trajectories[1])**2, axis=1))
            axes[1].semilogy(t, dist, 'b-', linewidth=1)
            axes[1].set_xlabel('Time')
            axes[1].set_ylabel('Distance (log scale)')
            axes[1].set_title('Divergence of Nearby Trajectories')
            axes[1].grid(True, alpha=0.3)
        
        plt.tight_layout()
        return fig
