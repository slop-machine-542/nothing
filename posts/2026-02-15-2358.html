1. Topology: The Brouwer Fixed-Point Theorem

Introduction

Topology studies properties of spaces that remain unchanged under continuous deformations—stretching, bending, but not tearing or gluing. Imagine a coffee cup morphing into a donut: they're topologically equivalent because both have exactly one hole.

The Brouwer Fixed-Point Theorem is one of topology's most elegant results. It states that if you stir a cup of coffee and let it settle, at least one point ends up exactly where it started. More formally: any continuous function mapping a closed disk to itself must have at least one fixed point.

Notation Guide

  • \(D^n\) — the closed n-dimensional unit disk: all points in \(\mathbb{R}^n\) with \(\|x\| \leq 1\)
  • \(\partial D^n\) or \(S^{n-1}\) — the boundary of the disk, the \((n-1)\)-dimensional sphere
  • \(f: X \to Y\) — a function from space \(X\) to space \(Y\)
  • \(C^0\) — continuous (no jumps or breaks)
  • \(x^*\) — a fixed point where \(f(x^*) = x^*\)
Brouwer Fixed-Point Theorem

Let \(D^n = \{x \in \mathbb{R}^n : \|x\| \leq 1\}\) be the closed unit disk in \(\mathbb{R}^n\). For any continuous function \(f: D^n \to D^n\), there exists at least one point \(x^* \in D^n\) such that:

\[f(x^*) = x^*\]

Proof (by contradiction, for n = 2)

Step 1: Assume \(f: D^2 \to D^2\) has no fixed points, so \(f(x) \neq x\) for all \(x \in D^2\).

Step 2: Define a retraction. For each \(x\), draw a ray from \(f(x)\) through \(x\). This ray intersects the boundary circle \(S^1\) at a unique point \(r(x)\).

Step 3: This defines a continuous map \(r: D^2 \to S^1\) where \(r(x) = x\) for all \(x \in S^1\) (i.e., \(r\) is a retraction).

Step 4: Let \(i: S^1 \hookrightarrow D^2\) be the inclusion map. The composition \(r \circ i = \text{id}_{S^1}\).

Step 5: Apply the fundamental group functor \(\pi_1\):

\[\pi_1(r) \circ \pi_1(i) = \pi_1(\text{id}_{S^1}) = \text{id}_{\pi_1(S^1)}\]

Step 6: We know \(\pi_1(S^1) = \mathbb{Z}\) and \(\pi_1(D^2) = 0\) (trivial group, since \(D^2\) is contractible).

Step 7: So we have: \(\mathbb{Z} \xrightarrow{\pi_1(i)} 0 \xrightarrow{\pi_1(r)} \mathbb{Z}\) composing to \(\text{id}_{\mathbb{Z}}\).

Step 8: But the only homomorphism \(0 \to \mathbb{Z}\) sends everything to 0, so this composition cannot equal the identity on \(\mathbb{Z}\). Contradiction!

Therefore, our assumption was false, and \(f\) must have a fixed point. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

def find_fixed_point(f, n=2, initial_guess=None):
    """
    Numerically find a fixed point of f: D^n -> D^n.
    
    Parameters:
        f: function taking array of shape (n,) and returning array of shape (n,)
        n: dimension
        initial_guess: starting point for search
    
    Returns:
        Fixed point x* where f(x*) = x*
    """
    if initial_guess is None:
        initial_guess = np.zeros(n)
    
    # Define g(x) = f(x) - x, find root
    def g(x):
        return f(x) - x
    
    fixed_point = fsolve(g, initial_guess)
    return fixed_point

# Example: A continuous map from disk to disk
def example_map(x):
    """
    A continuous function D^2 -> D^2.
    Maps (x,y) to a point inside the unit disk.
    """
    # A simple contraction-like map
    result = np.array([
        0.5 * x[0] + 0.3 * x[1],
        -0.2 * x[0] + 0.4 * x[1] + 0.1
    ])
    # Ensure it stays in disk (normalize if needed)
    norm = np.linalg.norm(result)
    if norm > 1:
        result = result / norm * 0.99
    return result

# Find fixed point

2. Number Theory: Fermat's Little Theorem

Introduction

Number theory, the "queen of mathematics," studies the properties of integers. Despite its ancient origins, it underpins modern cryptography—including the RSA algorithm securing internet communications.

Fermat's Little Theorem (not to be confused with his Last Theorem) provides a powerful tool for working with modular arithmetic. It reveals a beautiful periodicity in powers of integers modulo a prime.

Notation Guide

  • \(p\) — a prime number (only divisible by 1 and itself)
  • \(a\) — an integer with \(\gcd(a, p) = 1\) (coprime to \(p\))
  • \(a \equiv b \pmod{p}\) — \(a\) and \(b\) have the same remainder when divided by \(p\)
  • \(\mathbb{Z}_p^*\) — the multiplicative group of integers modulo \(p\)
  • \(\phi(n)\) — Euler's totient function, counting integers up to \(n\) coprime to \(n\)
Fermat's Little Theorem

Let \(p\) be a prime number and \(a\) be an integer such that \(p \nmid a\) (i.e., \(\gcd(a, p) = 1\)). Then:

\[a^{p-1} \equiv 1 \pmod{p}\]

Equivalently: \(a^p \equiv a \pmod{p}\) for any integer \(a\).

Proof (using group theory)

Step 1: Consider the multiplicative group \(\mathbb{Z}_p^* = \{1, 2, \ldots, p-1\}\) with multiplication modulo \(p\).

Step 2: This group has order \(p-1\) (contains \(p-1\) elements).

Step 3: For any \(a \in \mathbb{Z}_p^*\), consider the cyclic subgroup generated by \(a\):

\[\langle a \rangle = \{a^1, a^2, a^3, \ldots, a^k = 1\}\]

Step 4: By Lagrange's theorem, the order of any subgroup divides the order of the group. So \(|\langle a \rangle| \mid (p-1)\).

Step 5: Let \(d = |\langle a \rangle|\). Then \(a^d = 1\), and since \(d \mid (p-1)\), we can write \(p-1 = d \cdot m\) for some integer \(m\).

Step 6: Therefore:

\[a^{p-1} = a^{d \cdot m} = (a^d)^m = 1^m = 1\]

Hence \(a^{p-1} \equiv 1 \pmod{p}\). ∎

Alternative Proof (Combinatorial)

Proof (counting necklaces)

Step 1: Consider necklaces made of \(p\) beads, each bead one of \(a\) colors.

Step 2: Total necklaces (ignoring rotation): \(a^p\).

Step 3: Necklaces with all beads the same color are unchanged by rotation. There are \(a\) such monochromatic necklaces.

Step 4: For any other necklace, rotating by one position gives a different coloring (since \(p\) is prime). So non-monochromatic necklaces come in groups of \(p\) (orbits under rotation).

Step 5: Therefore: \(a^p = a + p \cdot k\) for some integer \(k\).

Step 6: Rearranging: \(a^p - a = p \cdot k\), so \(a^p \equiv a \pmod{p}\). ∎

Python Implementation

def mod_exp(base, exp, mod):
    """
    Compute (base^exp) % mod using fast exponentiation.
    Time complexity: O(log exp)
    """
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:  # If exp is odd
            result = (result * base) % mod
        exp = exp >> 1    # Divide exp by 2
        base = (base * base) % mod
    return result

def fermat_little_theorem(a, p):
    """
    Verify Fermat's Little Theorem: a^(p-1) ≡ 1 (mod p)
    for prime p and a not divisible by p.
    """
    if p == 1:
        return False
    
    # Check if p is prime (simple check)
    for i in range(2, int(p**0.5) + 1):
        if p % i == 0:
            raise ValueError(f"{p} is not prime")
    
    if a % p == 0:
        raise ValueError(f"{a} is divisible by {p}")
    
    result = mod_exp(a, p - 1, p)
    return result == 1

def mod_inverse(a, p):
    """
    Compute a^(-1) mod p using Fermat's Little Theorem.
    Only works when p is prime.
    a^(-1) ≡ a^(p-2) (mod p)

    return mod_exp(a, p - 2, p)

3. Abstract Algebra: Lagrange's Theorem

Introduction

Abstract algebra studies algebraic structures like groups, rings, and fields. These structures capture patterns that appear across all of mathematics—from symmetries of geometric objects to solutions of polynomial equations.

A group is a set with a binary operation satisfying four axioms: closure, associativity, identity, and inverses. Lagrange's Theorem reveals a fundamental constraint on the structure of finite groups: the size of any subgroup must divide the size of the whole group.

Notation Guide

  • \(G\) — a group (set with operation satisfying group axioms)
  • \(H \leq G\) — \(H\) is a subgroup of \(G\)
  • \(|G|\) — the order of \(G\) (number of elements)
  • \(gH = \{gh : h \in H\}\) — a left coset of \(H\) in \(G\)
  • \([G : H]\) — the index of \(H\) in \(G\) (number of distinct cosets)
  • \(e\) — the identity element of the group
Lagrange's Theorem

Let \(G\) be a finite group and \(H\) be a subgroup of \(G\). Then the order of \(H\) divides the order of \(G\):

\[|H| \mid |G|\]

Equivalently: \(|G| = |H| \cdot [G : H]\), where \([G : H]\) is the index of \(H\) in \(G\).

Proof

Step 1 (Define Cosets): For each \(g \in G\), define the left coset:

\[gH = \{gh : h \in H\}\]

Step 2 (Cosets Partition G): We claim the cosets partition \(G\) (every element is in exactly one coset).

Proof of claim: For any \(g \in G\), we have \(g = ge \in gH\), so every element is in some coset.

Now suppose \(g_1H \cap g_2H \neq \emptyset\). Then there exist \(h_1, h_2 \in H\) with \(g_1h_1 = g_2h_2\).

This gives \(g_1 = g_2h_2h_1^{-1}\), so for any \(h \in H\):

\[g_1h = g_2h_2h_1^{-1}h \in g_2H\]

Thus \(g_1H \subseteq g_2H\). By symmetry, \(g_2H \subseteq g_1H\), so \(g_1H = g_2H\).

Step 3 (All Cosets Have Equal Size): Define \(\phi: H \to gH\) by \(\phi(h) = gh\). This is a bijection:

  • Injective: If \(gh_1 = gh_2\), then \(h_1 = h_2\) by left cancellation.
  • Surjective: Every element of \(gH\) has the form \(gh\) for some \(h \in H\).

Therefore \(|gH| = |H|\) for all \(g \in G\).

Step 4 (Count): Let \([G : H] = k\) be the number of distinct cosets. Since cosets partition \(G\) and each has size \(|H|\):

\[|G| = k \cdot |H| = [G : H] \cdot |H|\]

Therefore \(|H|\) divides \(|G|\). ∎

Python Implementation

from itertools import product
import numpy as np

class Group:
    """
    Simple representation of a finite group using Cayley table.
    """
    def __init__(self, elements, operation_table):
        """
        elements: list of element labels
        operation_table: |G| x |G| matrix where table[i][j] = index of (element_i * element_j)
        """
        self.elements = list(elements)
        self.n = len(elements)
        self.table = operation_table
        self.element_to_idx = {e: i for i, e in enumerate(elements)}
    
    def op(self, a, b):
        """Group operation a * b"""
        i = self.element_to_idx[a]
        j = self.element_to_idx[b]
        return self.elements[self.table[i][j]]
    
    def is_subgroup(self, subset):
        """Check if subset forms a subgroup"""
        subset = set(subset)
        # Check closure
        for a in subset:
            for b in subset:
                if self.op(a, b) not in subset:
                    return False
        # Check inverses
        for a in subset:
            found_inverse = False
            for b in subset:
                if self.op(a, b) == self.elements[0]:  # Assuming first element is identity
                    found_inverse = True
                    break
            if not found_inverse:
                return False
        return True
    
    def cosets(self, subgroup):
        """Compute left cosets of subgroup"""
        cosets = []
        used = set()
        for g in self.elements:
            if g in used:
                continue
            coset = {self.op(g, h) for h in subgroup}
            cosets.append(coset)
            used.update(coset)
        return cosets

def cyclic_group(n):
    """Create cyclic group Z_n"""
    elements = list(range(n))
    # table[i][j] = (i + j) % n
    table = [[(i + j) % n for j in range(n)] for i in range(n)]
    return Group(elements, table)

def symmetric_group(n):
    """Create symmetric group S_n (permutations of n elements)"""
    from itertools import permutations
    elements = list(permutations(range(n)))
    
    def compose(p, q):
        """Compose permutations: (p ∘ q)(i) = p(q(i))"""
        return tuple(p[q[i]] for i in range(n))
    
    element_to_idx = {e: i for i, e in enumerate(elements)}
    table = [[element_to_idx[compose(elements[i], elements[j])] 
              for j in range(len(elements))] 
             for i in range(len(elements))]
    
    return Group(elements, table)

1. The Collatz Conjecture

Introduction

The Collatz conjecture is one of mathematics' most notorious unsolved problems. Lothar Collatz posed it in 1937, and despite its simple statement, it has resisted proof for nearly 90 years.

The conjecture asks: starting from any positive integer, if you repeatedly apply the rule "if even, divide by 2; if odd, multiply by 3 and add 1," do you always eventually reach 1?

Notation Guide

  • \(f(n)\) — the Collatz function: \(f(n) = n/2\) if \(n\) even, \(3n+1\) if \(n\) odd
  • \(C(n)\) — the total stopping time (number of steps to reach 1)
  • \(T^k(n)\) — the k-th iterate of the function applied to \(n\)
  • \(\sigma(n)\) — the stopping time (steps to reach a value less than \(n\))
Total Stopping Time Bound (Tao, 2019)

Almost all Collatz orbits attain almost bounded values. More precisely, for any function \(f: \mathbb{N} \to \mathbb{R}^+\) with \(f(n) \to \infty\) as \(n \to \infty\):

\[\lim_{N \to \infty} \frac{1}{N} \left|\{n \leq N : \min_{k \geq 0} T^k(n) < f(n)\}\right| = 1\]

This means that for 99% of starting values (in a logarithmic density sense), the orbit eventually reaches a value smaller than any slowly growing function.

Proof Sketch (Probabilistic Heuristic)

Step 1: Model the Collatz process probabilistically. For a random odd number, \(3n+1\) is even, and the expected number of divisions by 2 is:

\[\mathbb{E}[\text{divisions}] = \sum_{k=1}^{\infty} \frac{1}{2^k} \cdot k = 2\]

Step 2: So on average, an odd number \(n\) maps to roughly \((3n+1)/4 \approx 3n/4\).

Step 3: Since \(3/4 < 1\), the "expected value" of the sequence decreases geometrically.

Step 4: Formally, consider the logarithm. For odd \(n\):

\[\log((3n+1)/2^k) = \log(3n+1) - k\log(2)\]

Step 5: With probability \(1/2^k\), we divide by \(2^k\). The expected change is:

\[\mathbb{E}[\Delta \log n] = \log(3) - \log(2) \cdot \sum_{k=1}^{\infty} \frac{k}{2^k} = \log(3) - 2\log(2) = \log(3/4) < 0\]

This negative drift suggests convergence. ∎

Python Implementation

def collatz(n):
    """
    Generate the Collatz sequence starting from n.
    """
    sequence = [n]
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        sequence.append(n)
    return sequence

def total_stopping_time(n):
    """Number of steps to reach 1."""
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        steps += 1
    return steps

def max_value(n):
    """Maximum value reached in the Collatz sequence."""
    max_val = n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        max_val = max(max_val, n)
    return max_val

2. The Prime Number Theorem

Introduction

Prime numbers are the atoms of arithmetic—every integer factors uniquely into primes. Yet their distribution among the integers has fascinated mathematicians for millennia.

The Prime Number Theorem (PNT), proved independently by Hadamard and de la Vallée Poussin in 1896, reveals the asymptotic density of primes. It states that the number of primes up to \(x\) is approximately \(x/\ln(x)\).

Notation Guide

  • \(\pi(x)\) — the prime-counting function: number of primes ≤ \(x\)
  • \(\ln(x)\) or \(\log(x)\) — natural logarithm
  • \(\text{Li}(x)\) — logarithmic integral: \(\int_2^x \frac{dt}{\ln t}\)
  • \(f(x) \sim g(x)\) — asymptotic equivalence: \(\lim_{x \to \infty} f(x)/g(x) = 1\)
  • \(\zeta(s)\) — Riemann zeta function
The Prime Number Theorem

Let \(\pi(x)\) denote the number of prime numbers less than or equal to \(x\). Then:

\[\pi(x) \sim \frac{x}{\ln x}\]

Equivalently:

\[\lim_{x \to \infty} \frac{\pi(x)}{x / \ln x} = 1\]

A more precise form uses the logarithmic integral:

\[\pi(x) \sim \text{Li}(x) = \int_2^x \frac{dt}{\ln t}\]

Proof Sketch (via Complex Analysis)

Step 1: Define the von Mangoldt function:

\[\Lambda(n) = \begin{cases} \ln p & \text{if } n = p^k \text{ for prime } p \\ 0 & \text{otherwise} \end{cases}\]

Step 2: The key is to study \(\psi(x) = \sum_{n \leq x} \Lambda(n)\), the Chebyshev function. One can show \(\psi(x) \sim x\) implies PNT.

Step 3: Using the identity:

\[-\frac{\zeta'(s)}{\zeta(s)} = \sum_{n=1}^{\infty} \frac{\Lambda(n)}{n^s}\]

Step 4: Apply Perron's formula to relate \(\psi(x)\) to a contour integral:

\[\psi(x) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \left(-\frac{\zeta'(s)}{\zeta(s)}\right) \frac{x^s}{s} ds\]

Step 5: The poles of \(-\zeta'(s)/\zeta(s)\) are at \(s = 1\) (residue 1) and at zeros of \(\zeta(s)\). The Riemann Hypothesis concerns these zeros.

Step 6: Hadamard and de la Vallée Poussin proved \(\zeta(s) \neq 0\) for \(\text{Re}(s) = 1\), which is sufficient to show the main term comes from the pole at \(s = 1\), giving \(\psi(x) \sim x\). ∎

3. Goldbach's Conjecture

Introduction

In 1742, Christian Goldbach wrote to Leonhard Euler proposing that every even integer greater than 2 can be expressed as the sum of two primes. Euler believed it true but couldn't prove it. Despite extensive computational verification, the conjecture remains unproven.

The weak (or odd) Goldbach conjecture—every odd number greater than 5 is the sum of three primes—was proven by Harald Helfgott in 2013.

Notation Guide

  • \(G(n)\) — number of ways to write even \(n\) as sum of two primes
  • \(r_2(n)\) — number of representations of \(n\) as sum of two primes
  • \(\Lambda(n)\) — von Mangoldt function
  • \(\prod_{p|n}\) — product over primes dividing \(n\)
Chen's Theorem (1966)

Every sufficiently large even integer \(n\) can be written as the sum of:

  • A prime, and
  • A product of at most two primes (a semiprime)

This is denoted as "1 + 2" in the context of Goldbach-like problems.

Proof Sketch of Chen's Theorem

Step 1: Define the sieving function. For even \(n\), let:

\[D(n) = \{p : p \leq n, n - p \text{ is prime or semiprime}\}\]

Step 2: Use the circle method. The number of representations is:

\[r(n) = \int_0^1 S(\alpha)^2 e(-n\alpha) d\alpha\]

where \(S(\alpha) = \sum_{p \leq n} e(p\alpha)\) and \(e(x) = e^{2\pi i x}\).

Step 3: Decompose the integral into major and minor arcs. On major arcs (near rationals with small denominator), use analytic properties of Dirichlet L-functions.

Step 4: On minor arcs, bound \(|S(\alpha)|\) using exponential sum estimates (Vinogradov's method).

Step 5: Chen's innovation: a weighted sieve that handles the "semiprime" condition. The key is the sieve identity:

\[S(\mathcal{A}, \mathcal{P}, z) = S(\mathcal{A}, \mathcal{P}, w) - \sum_{w \leq p < z} S(\mathcal{A}_p, \mathcal{P}, p)\]

Step 6: Careful estimation shows the main term dominates the error, proving infinitely many representations of the form \(p + P_2\) where \(P_2\) has at most two prime factors. ∎

def goldbach_asymptotic(n):
    """
    Hardy-Littlewood conjectured asymptotic for G(n):
    G(n) ~ 2 * C_2 * n / (ln n)^2 * prod_{p|n, p>2} (p-1)/(p-2)
    where C_2 is the twin prime constant.
    """
    import math
    
    # Twin prime constant
    C2 = 0.6601618158468695739278121100145557784326233602847334133
    
    # Product over odd prime divisors of n
    prod = 1.0
    temp = n
    p = 3
    while p * p <= temp:
        if temp % p == 0:
            prod *= (p - 1) / (p - 2)
            while temp % p == 0:
                temp //= p
        p += 2
    if temp > 2:
        prod *= (temp - 1) / (temp - 2)
    
    return 2 * C2 * n / (math.log(n)**2) * prod

def is_semiprime(n, primes_set):
    """Check if n is a semiprime (product of exactly 2 primes)."""
    for p in primes_set:
        if p * p > n:
            break
        if n % p == 0:
            q = n // p
            if q in primes_set and q >= p:
                return True
    return False

        if is_semiprime(n - p, primes_set):
            reps.append(p)
    return reps

4. p-adic Numbers

Introduction

The p-adic numbers, introduced by Kurt Hensel in 1897, provide an alternative way to complete the rational numbers. While real numbers fill in the "gaps" between rationals using the usual absolute value, p-adic numbers use a different notion of "closeness" based on divisibility by a prime \(p\).

In the p-adic world, two numbers are close if their difference is divisible by a high power of \(p\). This leads to counterintuitive properties: in the 2-adics, the sequence \(2^n\) converges to 0!

Notation Guide

  • \(\mathbb{Q}_p\) — the field of p-adic numbers
  • \(\mathbb{Z}_p\) — the ring of p-adic integers
  • \(|x|_p\) — p-adic absolute value: \(|p^n \cdot a/b|_p = p^{-n}\) where \(p \nmid ab\)
  • \(v_p(x)\) — p-adic valuation: the highest power of \(p\) dividing \(x\)
  • \(\nu_p(n!)\) — exponent of highest power of \(p\) dividing \(n!\)
Ostrowski's Theorem

Every non-trivial absolute value on \(\mathbb{Q}\) is equivalent to either:

  1. The usual absolute value \(|\cdot|_\infty\) (giving \(\mathbb{R}\)), or
  2. The p-adic absolute value \(|\cdot|_p\) for some prime \(p\) (giving \(\mathbb{Q}_p\)).

More precisely, if \(|\cdot|\) is a non-trivial absolute value on \(\mathbb{Q}\) satisfying the triangle inequality, then either:

  • \(|x| = |x|_\infty^c\) for some \(c > 0\), or
  • \(|x| = |x|_p^c\) for some prime \(p\) and \(c > 0\).
Proof of Ostrowski's Theorem

Step 1: Let \(|\cdot|\) be a non-trivial absolute value on \(\mathbb{Q}\). Consider \(|n|\) for integers \(n\).

Case 1: Suppose \(|n| \leq 1\) for all integers \(n\).

Since the absolute value is non-trivial, there exists some integer with \(|n| < 1\). Let \(p\) be the smallest positive integer with \(|p| < 1\).

Step 2: We claim \(p\) is prime. If \(p = ab\) with \(1 < a, b < p\), then by minimality, \(|a| = |b| = 1\), so \(|p| = |a||b| = 1\), contradiction.

Step 3: For any integer \(n\) not divisible by \(p\), we can write \(1 = an + bp\) for some integers \(a, b\) (Bezout). Then:

\[1 = |1| = |an + bp| \leq |an| + |bp| = |a||n| + |b||p|\]

Since \(|a|, |b| \leq 1\) and \(|p| < 1\), we get \(|n| = 1\).

Step 4: For any rational \(x = p^k \cdot a/b\) where \(p \nmid ab\):

\[|x| = |p|^k \cdot |a|/|b| = |p|^k\]

Setting \(c = -\log|p|/\log(p) > 0\), we get \(|x| = |x|_p^c\).

Case 2: Suppose \(|n| > 1\) for some integer \(n\). One can show this forces \(|n| = |n|_\infty^c\) for some \(c\). ∎

Legendre's Formula (p-adic valuation of factorial)

For a prime \(p\) and positive integer \(n\):

\[\nu_p(n!) = \sum_{k=1}^{\infty} \left\lfloor \frac{n}{p^k} \right\rfloor = \frac{n - s_p(n)}{p-1}\]

where \(s_p(n)\) is the sum of digits of \(n\) in base \(p\).

Proof of Legendre's Formula

Step 1: Among \(1, 2, \ldots, n\), exactly \(\lfloor n/p \rfloor\) are divisible by \(p\).

Step 2: Among these, exactly \(\lfloor n/p^2 \rfloor\) are divisible by \(p^2\), contributing an additional factor of \(p\).

Step 3: Continuing, the total power of \(p\) in \(n!\) is:

\[\nu_p(n!) = \sum_{k=1}^{\infty} \left\lfloor \frac{n}{p^k} \right\rfloor\]

Step 4: For the digit sum formula, write \(n = a_0 + a_1 p + a_2 p^2 + \cdots\) in base \(p\).

Step 5: Then:

\[\left\lfloor \frac{n}{p} \right\rfloor = a_1 + a_2 p + a_3 p^2 + \cdots\]

\[\left\lfloor \frac{n}{p^2} \right\rfloor = a_2 + a_3 p + \cdots\]

\[\vdots\]

Step 6: Summing:

\[\sum_{k \geq 1} \left\lfloor \frac{n}{p^k} \right\rfloor = a_1 + a_2(1+p) + a_3(1+p+p^2) + \cdots\]

\[= \sum_{j \geq 1} a_j \frac{p^j - 1}{p-1} = \frac{1}{p-1}\left(\sum_{j \geq 0} a_j p^j - \sum_{j \geq 0} a_j\right)\]

\[= \frac{n - s_p(n)}{p-1}\] ∎

Python Implementation

from fractions import Fraction
import math

def p_adic_valuation(n, p):
    """
    Compute the p-adic valuation v_p(n).
    This is the highest power of p dividing n.
    For n = 0, returns infinity (represented as None).
    """
    if n == 0:
        return float('inf')
    
    n = abs(n)
    val = 0
    while n % p == 0:
        n //= p
        val += 1
    return val

def p_adic_absolute_value(x, p):
    """
    Compute the p-adic absolute value |x|_p.
    For x = p^n * (a/b) where p doesn't divide ab:
    |x|_p = p^(-n)
    """
    if x == 0:
        return 0
    
    # Convert to fraction
    if isinstance(x, (int, float)):
        x = Fraction(x).limit_denominator()
    
    # v_p(x) = v_p(numerator) - v_p(denominator)
    v_p = p_adic_valuation(x.numerator, p) - p_adic_valuation(x.denominator, p)
    return p ** (-v_p)

def p_adic_distance(x, y, p):
    """Compute the p-adic distance |x - y|_p."""
    return p_adic_absolute_value(x - y, p)

def p_adic_expansion(x, p, precision=20):
    """
    Compute the p-adic expansion of a rational number x.
    Returns coefficients [a0, a1, a2, ...] where
    x = a0 + a1*p + a2*p^2 + ... (mod p^precision)
    """
    if x == 0:
        return [0] * precision
    
    if isinstance(x, (int, float)):
        x = Fraction(x).limit_denominator()
    
    # Ensure x is a p-adic integer (|x|_p <= 1)
    # If not, we need to multiply by appropriate power of p
    v_p = p_adic_valuation(x.numerator, p) - p_adic_valuation(x.denominator, p)
    
    coeffs = []
    current = x
    
    for _ in range(precision):
        # Find a0 such that x ≡ a0 (mod p)
        # a0 = x mod p, in range [0, p-1]
        if isinstance(current, Fraction):
            # Convert to integer mod p
            inv_denom = pow(current.denominator, -1, p)
            a0 = (current.numerator * inv_denom) % p
        else:
            a0 = int(current) % p
        
        coeffs.append(a0)
        current = (current - a0) / p
    
    return coeffs

def legendre_formula(n, p):
    """
    Compute v_p(n!) using Legendre's formula.
    v_p(n!) = sum_{k=1}^∞ floor(n / p^k)
    """
    val = 0
    power = p
    while power <= n:
        val += n // power
        power *= p
    return val

def digit_sum(n, p):
    """Sum of digits of n in base p."""
    s = 0
    while n > 0:
        s += n % p
        n //= p
    return s

def legendre_formula_digit_sum(n, p):
    """
    Alternative form: v_p(n!) = (n - s_p(n)) / (p - 1)
    where s_p(n) is the sum of digits of n in base p.
    """
    return (n - digit_sum(n, p)) // (p - 1)

# Hensel's Lemma demonstration
def hensel_lift(f, df, x0, p, k):
    """
    Hensel's Lemma: Lift a solution mod p to mod p^k.
    f: polynomial function
    df: derivative of f
    x0: initial solution where f(x0) ≡ 0 (mod p) and f'(x0) ≢ 0 (mod p)
    """
    x = x0
    for i in range(1, k):
        # Newton iteration: x_{n+1} = x_n - f(x_n)/f'(x_n)
        correction = (f(x) // p**i) * pow(df(x), -1, p)
        x = x - correction * p**i
    return x
