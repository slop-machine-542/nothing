1. Complex Analysis: Cauchy's Integral Theorem

Introduction

Complex analysis is the study of functions of a complex variable. Unlike real analysis, where functions can be differentiable yet pathological, complex differentiability imposes extraordinary rigidity. A function that is complex differentiable just once in a neighborhood is automatically infinitely differentiable and analytic.

Cauchy's Integral Theorem is the cornerstone of complex analysis. It states that the integral of a holomorphic function around a closed contour is zero, provided there are no singularities inside.

Notation Guide

  • ℂ — the field of complex numbers
  • f: U to ℂ — a complex-valued function
  • γ — a contour (piecewise smooth curve)
  • oint_gamma f(z)\, dz — the contour integral
  • Holomorphic — complex differentiable

Cauchy's Integral Theorem

Let U subseteq ℂ be simply connected, and let f: U to ℂ be holomorphic. If γ is a piecewise smooth, simple closed curve in U, then:

oint_gamma f(z)\, dz = 0

Proof (using Green's Theorem)

Write f(z) = u(x,y) + iv(x,y). The integral becomes:

oint_gamma (u\, dx - v\, dy) + ioint_gamma (v\, dx + u\, dy)

By Green's theorem and the Cauchy-Riemann equations partial u/partial x = partial v/partial y and partial u/partial y = -partial v/partial x, both integrals vanish. ∎

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def complex_line_integral(f, gamma, dgamma, t_range, n_points=1000):
    """
    Compute the complex line integral ∫_γ f(z) dz numerically.
    
    Notation: ∫_γ f(z) dz = ∫_a^b f(γ(t)) γ'(t) dt
    """
    t = np.linspace(t_range[0], t_range[1], n_points)
    dt = (t_range[1] - t_range[0]) / n_points
    
    integrand = f(gamma(t)) * dgamma(t)
    integral = np.trapezoid(integrand, t)
    return integral

# Verify Cauchy's theorem
r = 1.0
gamma = lambda t: r * np.exp(1j * t)
dgamma = lambda t: 1j * r * np.exp(1j * t)

# Holomorphic functions: integral should be 0
f = lambda z: z**2
result = complex_line_integral(f, gamma, dgamma, (0, 2*np.pi))
print(f"∮ z² dz = {result}")  # Should be ≈ 0

# Non-holomorphic: f(z) = 1/z has pole at 0
f_pole = lambda z: 1/z
result = complex_line_integral(f_pole, gamma, dgamma, (0, 2*np.pi))
print(f"∮ (1/z) dz = {result}")  # Should be ≈ 2πi

2. Algebraic Geometry: Bézout's Theorem

Introduction

Algebraic geometry is the study of solutions to polynomial equations. Bézout's Theorem is a fundamental result counting the intersections of algebraic curves. It states that two curves of degrees m and n intersect in exactly mn points (counting multiplicities).

Notation Guide

  • ℙn — complex projective n-space
  • V(f) — the vanishing locus of polynomial f
  • deg(f) — degree of polynomial f
  • Ip(C1, C2) — intersection multiplicity at point p

Bézout's Theorem

Let C1 and C2 be projective plane curves of degrees m and n with no common component. Then:

sump in C1 cap C2 Ip(C1, C2) = m cdot n

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

# Example: Line (degree 1) and Circle (degree 2)
# Expected: 1 * 2 = 2 intersection points

# Line: y = x
# Circle: x² + y² = 1
# Substituting: 2x² = 1 → x = ±1/√2

x_int = np.array([1/np.sqrt(2), -1/np.sqrt(2)])
y_int = x_int
print(f"Line and Circle intersections: ({x_int[0]:.4f}, {y_int[0]:.4f}) and ({x_int[1]:.4f}, {y_int[1]:.4f})")

# Visualize
fig, ax = plt.subplots(figsize=(8, 8))
theta = np.linspace(0, 2*np.pi, 100)
ax.plot(np.cos(theta), np.sin(theta), 'b-', linewidth=2, label='Circle')
x_line = np.linspace(-1.5, 1.5, 100)
ax.plot(x_line, x_line, 'r-', linewidth=2, label='Line')
ax.plot(x_int, y_int, 'go', markersize=10, label='Intersections (2)')
ax.set_aspect('equal')
ax.legend()
ax.set_title('Bézout: deg 1 × deg 2 = 2 points')
plt.savefig('bezout_theorem.png', dpi=150)

3. Differential Geometry: The Gauss-Bonnet Theorem

Introduction

The Gauss-Bonnet Theorem connects local geometry (curvature) to global topology. It states that the total Gaussian curvature of a compact surface equals 2pi times its Euler characteristic.

Notation Guide

  • S — a smooth, compact, oriented surface
  • K — Gaussian curvature
  • chi(S) = V - E + F — Euler characteristic
  • dA — area element

The Gauss-Bonnet Theorem

Let S be a compact, oriented surface without boundary. Then:

intS K\, dA = 2pi chi(S)

Python Implementation

import numpy as np

# Sphere (genus 0): χ = 2, K = 1/R² constant
R = 1.0
K_sphere = 1 / R**2
area_sphere = 4 * np.pi * R**2
total_curvature = K_sphere * area_sphere  # = 4π
chi_sphere = 2
expected = 2 * np.pi * chi_sphere  # = 4π

print(f"Sphere: ∫K dA = {total_curvature:.4f}, 2πχ = {expected:.4f}")
print(f"Verification: {np.isclose(total_curvature, expected)}")

# Torus (genus 1): χ = 0
# Total curvature = 0 (positive on outside, negative on inside)
chi_torus = 0
print(f"\nTorus: χ = {chi_torus}, so ∫K dA = 0")

1. Statistics: The Central Limit Theorem

Introduction

The Central Limit Theorem (CLT) explains why the normal distribution appears everywhere in nature. It states that the sum of a large number of independent, identically distributed random variables approaches a normal distribution.

Notation Guide

  • X1, X2, ldots, Xn — i.i.d. random variables
  • mu = mathbbE[Xi] — expected value
  • sigma2 = Var(Xi) — variance
  • X̄n = 1/nsumi=1n Xi — sample mean
  • N(mu, sigma2) — normal distribution

The Central Limit Theorem

Let X1, X2, ldots be i.i.d. with mean μ and variance sigma2＜infty. Then:

fracX̄n - musigma/√(n) xrightarrowd N(0, 1)

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Demonstrate CLT for uniform distribution
n_samples = 30
n_trials = 10000

sample_means = []
for _ in range(n_trials):
    samples = np.random.uniform(0, 1, n_samples)
    sample_means.append(np.mean(samples))

# Standardize: (X̄ - μ) / (σ/√n)
# For Uniform[0,1]: μ = 0.5, σ² = 1/12
standardized = (np.array(sample_means) - 0.5) / (1/np.sqrt(12) / np.sqrt(n_samples))

# Plot
plt.hist(standardized, bins=50, density=True, alpha=0.7, edgecolor='black')
x = np.linspace(-4, 4, 100)
plt.plot(x, stats.norm.pdf(x, 0, 1), 'r-', linewidth=2, label='N(0,1)')
plt.xlabel('Standardized Sample Mean')
plt.ylabel('Density')
plt.title(f'CLT: Uniform Distribution, n={n_samples}')
plt.legend()
plt.savefig('central_limit_theorem.png', dpi=150)

2. Differential Equations: Picard-Lindelöf Theorem

Introduction

Before solving a differential equation, we must ask: does a solution exist? Is it unique? The Picard-Lindelöf Theorem provides conditions guaranteeing both.

Notation Guide

  • dy/dt = f(t, y) — first-order ODE
  • y(t0) = y0 — initial condition
  • L — Lipschitz constant
  • (Ty)(t) = y0 + intt0t f(s, y(s))\, ds — Picard operator

Picard-Lindelöf Existence and Uniqueness Theorem

Let f be continuous and Lipschitz in y with constant L. Then for any (t0, y0), there exists epsilon > 0 such that the IVP:

dy/dt = f(t, y), quad y(t0) = y0

has a unique solution on [t0 - epsilon, t0 + epsilon].

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

def picard_iteration(f, y0, t0, t_end, n_iterations=10, n_points=100):
    """
    Picard iteration: y_{n+1}(t) = y0 + ∫_{t0}^{t} f(s, y_n(s)) ds
    """
    t = np.linspace(t0, t_end, n_points)
    dt = t[1] - t[0]
    
    y = np.full_like(t, y0)
    
    for _ in range(n_iterations):
        f_values = f(t, y)
        integral = np.cumsum(f_values) * dt
        y = y0 + integral
    
    return t, y

# Example: dy/dt = y, y(0) = 1
# Solution: y(t) = e^t
f = lambda t, y: y
y0 = 1
t, y_approx = picard_iteration(f, y0, 0, 2, n_iterations=10)
y_exact = np.exp(t)

print(f"Approximate y(2) = {y_approx[-1]:.6f}")
print(f"Exact y(2) = e² = {y_exact[-1]:.6f}")

3. Linear Algebra: Singular Value Decomposition

Introduction

The Singular Value Decomposition (SVD) decomposes any matrix into a product of rotations and scalings. It is fundamental to data science, powering PCA, recommendation systems, and image compression.

Notation Guide

  • A = USigma VT — SVD decomposition
  • U, V — orthogonal matrices
  • Sigma — diagonal matrix of singular valuessigma1 geq sigma2 geq cdots
  • \|A\|F — Frobenius norm

Singular Value Decomposition

Let A in ℝm times n. Then there exist orthogonal U, V such that:

A = USigma VT

where Sigma = diag(sigma1, ldots, sigmar) with r = rank(A).

Eckart-Young-Mirsky Theorem

The best rank-k approximation to A is Ak = sumi=1k sigmai ui viT with error \|A - Ak\|F2 = sumi=k+1r sigmai2.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

# Create test matrix
np.random.seed(42)
A = np.random.randn(5, 3)

# Compute SVD
U, s, Vt = np.linalg.svd(A, full_matrices=True)

print(f"Singular values: {s}")

# Reconstruct A
Sigma = np.zeros_like(A, dtype=float)
for i in range(len(s)):
    Sigma[i, i] = s[i]
A_reconstructed = U @ Sigma @ Vt
print(f"Reconstruction error: {np.linalg.norm(A - A_reconstructed):.2e}")

# Low-rank approximation
k = 2
A_k = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
error = np.linalg.norm(A - A_k, 'fro')**2
theory_error = np.sum(s[k:]**2)
print(f"Approximation error: {error:.6f}")
print(f"Theoretical error: {theory_error:.6f}")

1. The Riemann Hypothesis

Introduction

The Riemann Hypothesis is the most famous unsolved problem in mathematics. It states that all non-trivial zeros of the Riemann zeta function have real part equal to 1/2.

Notation Guide

  • zeta(s) = sumn=1infty 1/ns — Riemann zeta function
  • s = sigma + it — complex variable
  • rho = beta + igamma — non-trivial zero

The Riemann Hypothesis

All non-trivial zeros of zeta(s) satisfy Re(s) = 1/2.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.special import gamma

def zeta_critical_line(t):
    """
    Approximate Z(t) = ζ(1/2 + it) using Riemann-Siegel formula.
    """
    # Riemann-Siegel theta function
    theta = np.imag(np.log(gamma(1/4 + 1j*t/2))) - t*np.log(np.pi)/2
    
    N = int(np.sqrt(t / (2*np.pi)))
    if N < 1:
        N = 1
    
    Z = sum(np.cos(theta - t*np.log(n)) / np.sqrt(n) for n in range(1, N+1))
    return 2 * Z

# Plot Z(t) on critical line
t = np.linspace(0, 50, 1000)
Z = [zeta_critical_line(ti) for ti in t]

plt.figure(figsize=(12, 5))
plt.plot(t, Z, 'b-', linewidth=1)
plt.axhline(y=0, color='r', linestyle='--', alpha=0.5)
plt.xlabel('t')
plt.ylabel('Z(t)')
plt.title('Riemann Zeta Function on Critical Line')
plt.grid(True, alpha=0.3)
plt.savefig('riemann_hypothesis.png', dpi=150)

2. P vs NP

Introduction

The P vs NP problem asks whether every problem whose solution can be quickly verified can also be quickly solved. It is one of the seven Millennium Prize Problems.

Notation Guide

  • P — polynomial time solvable
  • NP — polynomial time verifiable
  • NPC — NP-complete (hardest problems)
  • O(f(n)) — big-O notation

Cook-Levin Theorem

SAT (Boolean satisfiability) is NP-complete.

Python Implementation

import itertools

def brute_force_sat(formula, n_vars):
    """
    Solve SAT by trying all 2^n assignments.
    Time: O(2^n * |formula|)
    """
    for assignment in itertools.product([True, False], repeat=n_vars):
        satisfied = True
        for clause in formula:
            clause_satisfied = any(
                (assignment[abs(l)-1] if l > 0 else not assignment[abs(l)-1])
                for l in clause
            )
            if not clause_satisfied:
                satisfied = False
                break
        if satisfied:
            return True, assignment
    return False, None

# Example: (x1 OR x2) AND (NOT x1 OR x2)
formula = [[1, 2], [-1, 2]]
sat, sol = brute_force_sat(formula, 2)
print(f"Satisfiable: {sat}, Solution: x1={sol[0]}, x2={sol[1] if sol else None}")

3. The Navier-Stokes Existence and Smoothness Problem

Introduction

The Navier-Stokes equations describe fluid motion. The Clay Millennium Problem asks: in 3D, do solutions always exist and remain smooth, or can singularities form?

Notation Guide

  • u(x, t) — velocity field
  • p(x, t) — pressure
  • nu — viscosity
  • Delta — Laplacian

Navier-Stokes Equations (Incompressible)

fracpartial upartial t + (u cdot nabla)u = nu Delta u - nabla p + f

nabla cdot u = 0

Python Implementation

import numpy as np
import matplotlib.pyplot as plt

# 1D Burgers' equation (simplified model): u_t + u*u_x = ν*u_xx
nx = 256
nu = 0.01
dx = 2*np.pi / nx
dt = 0.001

x = np.linspace(0, 2*np.pi, nx, endpoint=False)
u_sol = np.sin(x)  # Initial condition

# Time stepping with spectral method
for n in range(1000):
    u_hat = np.fft.fft(u_sol)
    k = np.fft.fftfreq(nx, dx) * 2 * np.pi
    
    # Derivatives in Fourier space
    u_x = np.fft.ifft(1j * k * u_hat).real
    u_xx = np.fft.ifft(-k**2 * u_hat).real
    
    # Forward Euler
    u_sol = u_sol - dt * u_sol * u_x + dt * nu * u_xx

plt.plot(x, u_sol)
plt.xlabel('x')
plt.ylabel('u(x,t)')
plt.title('Burgers Equation Solution')
plt.savefig('burgers_equation.png', dpi=150)

4. Surreal Numbers

Introduction

Surreal numbers, discovered by John Conway, form the largest possible ordered field. They include all real numbers, all ordinals, and infinitely more.

Notation Guide

  • \L | R\ — surreal number with left set L, right set R
  • ω — first infinite surreal
  • varepsilon — infinitesimal surreals

Definition of Surreal Numbers

If L, R are sets of surreals with no element of L geq any element of R, then \L | R\ is a surreal number.

Examples: 0 = \\ |\ \, 1 = \0 |\ \, 1/2 = \0 | 1\, omega = \0, 1, 2, ldots |\ \

Python Implementation

class SurrealNumber:
    """
    Simplified surreal number implementation.
    Notation: {L | R}
    """
    def __init__(self, left=None, right=None, value=None):
        self.left = frozenset(left or [])
        self.right = frozenset(right or [])
        self.value = value
    
    def __repr__(self):
        if self.value is not None:
            return f"Surreal({self.value})"
        return f"Surreal({set(self.left)} | {set(self.right)})"
    
    @staticmethod
    def zero():
        return SurrealNumber(value=0)
    
    @staticmethod
    def one():
        return SurrealNumber(left={SurrealNumber.zero()}, value=1)
    
    @staticmethod
    def half():
        return SurrealNumber(
            left={SurrealNumber.zero()},
            right={SurrealNumber.one()},
            value=0.5
        )

# Create basic surreals
zero = SurrealNumber.zero()
one = SurrealNumber.one()
half = SurrealNumber.half()

print(f"0 = {zero}")
print(f"1 = {one}")
print(f"1/2 = {half}")
