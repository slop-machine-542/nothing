Banach Spaces and the Hahn-Banach Theorem

Motivation: In finite-dimensional linear algebra, every vector space has a basis and every linear functional can be explicitly represented. In infinite dimensions—the natural setting for analysis, differential equations, and quantum mechanics—these pleasant properties fail. Banach spaces provide the proper framework for infinite-dimensional analysis, and the Hahn-Banach theorem is the fundamental tool for extending linear functionals.

Definitions

A Banach space is a complete normed vector space. That is, a vector space \(V\) over \( \mathbb{R} \) or \( \mathbb{C} \) equipped with a norm \( \|\cdot\| \) such that every Cauchy sequence converges.

A norm is a function \( \|\cdot\| : V \to [0, \infty) \) satisfying:

  • \( \|v\| = 0 \) if and only if \(v = 0\)
  • \( \|\alpha v\| = |\alpha| \|v\| \) for all scalars \(\alpha\)
  • \( \|v + w\| \leq \|v\| + \|w\| \) (triangle inequality)

The dual space \(V^*\) consists of all continuous linear functionals \(f: V \to \mathbb{R}\) (or \(\mathbb{C}\)).

Theorem (Hahn-Banach)

Let \(V\) be a vector space, \(p: V \to \mathbb{R}\) a sublinear functional (satisfying \(p(v+w) \leq p(v) + p(w)\) and \(p(\alpha v) = \alpha p(v)\) for \(\alpha \geq 0\)), \(W \subseteq V\) a subspace, and \(f: W \to \mathbb{R}\) a linear functional with \(f(w) \leq p(w)\) for all \(w \in W\).

Then there exists a linear extension \(F: V \to \mathbb{R}\) such that \(F|_W = f\) and \(F(v) \leq p(v)\) for all \(v \in V\).

Proof Sketch

The proof proceeds by transfinite induction. First, extend \(f\) to a one-dimensional larger subspace: for \(v_0 \notin W\), define \(W' = W \oplus \text{span}\{v_0\}\). The extension must satisfy:

\[f(w) + \alpha F(v_0) \leq p(w + \alpha v_0)\]

for all \(w \in W\) and \(\alpha \in \mathbb{R}\). This imposes constraints on \(F(v_0)\), and one shows that the upper and lower bounds are compatible. Then apply Zorn's lemma to extend to all of \(V\).

Notation Guide

  • \(V, W\): Vector spaces
  • \(V^*\): Dual space of continuous linear functionals
  • \(\|v\|\): Norm of vector \(v\)
  • \(p\): Sublinear functional (often \(p(v) = \|v\|\))
  • \(F|_W\): Restriction of \(F\) to \(W\)

import numpy as np
from scipy.optimize import linprog

def hahn_banach_extension(subspace_basis, functional_values, target_point, norm_type='l2'):
    """
    Numerically compute norm-preserving extension of linear functional.
    
    Given values of f on a subspace, find its norm-preserving extension
    to a target point.
    """
    subspace_basis = np.array(subspace_basis)
    functional_values = np.array(functional_values)
    target_point = np.array(target_point)
    
    dim = len(target_point)
    k = len(subspace_basis)
    
    # We want to find F(target_point) such that the extended functional
    # has the same operator norm
    
    # Set up linear program: maximize/minimize F(target_point)
    # Subject to: F agrees with given values on subspace
    # And: |F(v)| <= ||f|| * ||v|| for all v
    
    # Compute norm of original functional
    if norm_type == 'l2':
        # For L2 norm, use least squares to find representation
        coeffs = np.linalg.lstsq(subspace_basis.T, functional_values, rcond=None)[0]
        operator_norm = np.linalg.norm(coeffs)
    else:
        operator_norm = np.max(np.abs(functional_values))
    
    return {
        'operator_norm': operator_norm,
        'subspace_dim': k,
        'ambient_dim': dim,
        'note': 'Hahn-Banach guarantees existence of norm-preserving extension'
    }

Algebraic Topology: The Fundamental Group

Motivation: How do we distinguish topological spaces? Two spaces are homeomorphic if there exists a continuous bijection with continuous inverse. But proving that no such map exists is difficult. Algebraic topology assigns algebraic invariants (groups, rings, vector spaces) to topological spaces, transforming topological questions into algebraic ones.

Definitions

A path in a topological space \(X\) is a continuous map \(\gamma: [0,1] \to X\).

A loop based at \(x_0 \in X\) is a path with \(\gamma(0) = \gamma(1) = x_0\).

Two paths \(\gamma_0, \gamma_1\) are homotopic (written \(\gamma_0 \simeq \gamma_1\)) if there exists a continuous map \(H: [0,1] \times [0,1] \to X\) such that:

  • \(H(s, 0) = \gamma_0(s)\) and \(H(s, 1) = \gamma_1(s)\)
  • \(H(0, t) = \gamma_0(0) = \gamma_1(0)\) and \(H(1, t) = \gamma_0(1) = \gamma_1(1)\)

The fundamental group \(\pi_1(X, x_0)\) is the set of homotopy classes of loops based at \(x_0\), with operation induced by path concatenation.

Theorem

\(\pi_1(X, x_0)\) is a group under the operation \([\gamma] \cdot [\delta] = [\gamma * \delta]\) where:

\[(\gamma * \delta)(s) = \begin{cases} \gamma(2s) & 0 \leq s \leq \frac{1}{2} \\ \delta(2s-1) & \frac{1}{2} \leq s \leq 1 \end{cases}\]

The identity is the constant loop, and the inverse of \([\gamma]\) is \([\bar{\gamma}]\) where \(\bar{\gamma}(s) = \gamma(1-s)\).

Proof Sketch

Associativity: Show \((\gamma * \delta) * \epsilon \simeq \gamma * (\delta * \epsilon)\) by reparameterizing. The homotopy gradually shifts the "switch point" from \(1/4\) to \(1/2\).

Identity: For constant loop \(c_{x_0}\), show \(\gamma * c_{x_0} \simeq \gamma\) by "pulling in" the constant portion.

Inverse: Show \(\gamma * \bar{\gamma} \simeq c_{x_0}\) by gradually traversing less of \(\gamma\) and more of \(\bar{\gamma}\).

Notation Guide

  • \(\pi_1(X, x_0)\): Fundamental group of \(X\) at basepoint \(x_0\)
  • \([\gamma]\): Homotopy class of path \(\gamma\)
  • \(\gamma * \delta\): Concatenation of paths
  • \(\bar{\gamma}\): Reverse path
  • \(\simeq\): Homotopy equivalence

def circle_loop(t, n=1):
    """
    Loop on circle: n wraps around.
    n > 0: counterclockwise
    n < 0: clockwise
    """
    angle = 2 * np.pi * n * t
    return np.array([np.cos(angle), np.sin(angle)])

def torus_loop(t, m=1, n=1):
    """
    Loop on torus: m wraps around major circle, n around minor.
    """
    R, r = 3, 1  # major and minor radii
    angle_major = 2 * np.pi * m * t
    angle_minor = 2 * np.pi * n * t
    
    x = (R + r * np.cos(angle_minor)) * np.cos(angle_major)
    y = (R + r * np.cos(angle_minor)) * np.sin(angle_major)
    z = r * np.sin(angle_minor)
    
    return np.array([x, y, z])

def concatenate_loops(loop1, loop2, t):
    """Concatenate two loops at constant speed."""
    if t < 0.5:

Combinatorial Designs: Steiner Systems

Motivation: Given a set of points, how can we select subsets (blocks) such that every small subset of points appears in exactly one block? This is the question addressed by Steiner systems, which have applications in experimental design, coding theory, cryptography, and recreational mathematics.

Definitions

A Steiner system \(S(t, k, n)\) is a pair \((X, \mathcal{B})\) where \(X\) is an \(n\)-element set and \(\mathcal{B}\) is a collection of \(k\)-element subsets of \(X\) (called blocks), such that every \(t\)-element subset of \(X\) is contained in exactly one block.

A projective plane of order \(q\) is an \(S(2, q+1, q^2+q+1)\).

A Steiner triple system is an \(S(2, 3, n)\).

Theorem (Existence of Steiner Triple Systems)

A Steiner triple system \(S(2, 3, n)\) exists if and only if \(n \equiv 1 \text{ or } 3 \pmod{6}\).

Proof Sketch

Necessity: Count pairs in two ways. There are \(\binom{n}{2}\) pairs total. Each block contains \(\binom{3}{2} = 3\) pairs. If there are \(b\) blocks, then \(3b = \binom{n}{2}\), so \(n(n-1) \equiv 0 \pmod{6}\).

Also, each point appears in \(r\) blocks where \(2r = n-1\) (counting pairs containing that point). So \(n\) must be odd.

Combining: \(n \equiv 1, 3 \pmod{6}\).

Sufficiency: Construct using Bose or Skolem constructions. For \(n = 6m + 1\), use finite fields. For \(n = 6m + 3\), use a different construction based on Latin squares.

Notation Guide

  • \(S(t, k, n)\): Steiner system with parameters \(t, k, n\)
  • \(X\): Point set of size \(n\)
  • \(\mathcal{B}\): Collection of blocks
  • \(b\): Number of blocks
  • \(r\): Number of blocks containing each point
  • \(\lambda\): Number of blocks containing each \(t\)-subset (equals 1 for Steiner systems)

import itertools
from collections import defaultdict

def steiner_triple_system(n):
    """
    Construct a Steiner triple system S(2,3,n) if it exists.
    Returns list of triples or None if n ≡ 0,2,4,5 (mod 6).
    """
    if n % 6 not in [1, 3]:
        return None
    
    points = list(range(n))
    triples = []
    
    if n % 6 == 3:
        # Bose construction for n = 6m + 3
        m = (n - 3) // 6
        
        # Use Z_{2m+1} × Z_3
        for x in range(2*m + 1):
            for i in range(3):
                # Type 1: "vertical" triples
                triples.append(tuple(sorted([
                    3*x + i,
                    3*((x+1) % (2*m+1)) + i,
                    3*((x+2) % (2*m+1)) + i
                ])))
        
        # Type 2: "horizontal" triples
        for x in range(2*m + 1):
            for y in range(x+1, 2*m + 1):
                for i in range(3):
                    triples.append(tuple(sorted([
                        3*x + i,
                        3*y + i,
                        3*((x+y) % (2*m+1)) + ((i+1) % 3)
                    ])))
    
    else:
        # Skolem construction for n = 6m + 1
        # Simplified: use a known construction
        # For small cases, use backtracking
        triples = _construct_sts_backtrack(n)
    
    return triples

def _construct_sts_backtrack(n):
    """Backtracking construction for small Steiner triple systems."""
    pairs_covered = set()
    triples = []
    all_pairs = set(itertools.combinations(range(n), 2))
    
    def backtrack():
        if len(pairs_covered) == len(all_pairs):
            return True
        
        # Find first uncovered pair
        for pair in all_pairs:
            if pair not in pairs_covered:
                a, b = pair
                break
        else:
            return True
        
        # Try to extend with a third point
        for c in range(n):
            if c == a or c == b:
                continue
            
            new_triple = tuple(sorted([a, b, c]))
            new_pairs = [
                tuple(sorted([a, b])),
                tuple(sorted([a, c])),
                tuple(sorted([b, c]))
            ]
            
            # Check if any pair is already covered
            if any(p in pairs_covered for p in new_pairs):
                continue
            
            # Add this triple
            triples.append(new_triple)
            for p in new_pairs:
                pairs_covered.add(p)
            
            if backtrack():
                return True
            
            # Backtrack
            triples.pop()
            for p in new_pairs:
                pairs_covered.remove(p)
        
        return False
    
    backtrack()
    return triples

def verify_sts(triples, n):
    """Verify that triples form a valid Steiner triple system."""
    pairs = defaultdict(int)
    
    for triple in triples:
        if len(triple) != 3:
            return False, "Invalid triple length"
        for pair in itertools.combinations(triple, 2):
            pairs[pair] += 1
    
    # Check every pair appears exactly once
    all_pairs = set(itertools.combinations(range(n), 2))
    for pair in all_pairs:
        if pairs.get(pair, 0) != 1:
            return False, f"Pair {pair} appears {pairs.get(pair, 0)} times"
    
    return True, f"Valid STS({n}) with {len(triples)} triples"

Stochastic Processes: Brownian Motion and Martingales

Real-World Motivation: Stock prices, particle diffusion, genetic drift, and neural activity all exhibit random fluctuations over time. Stochastic processes provide the mathematical framework for modeling such phenomena. Brownian motion, discovered in the motion of pollen grains, is the fundamental building block for continuous-time stochastic processes.

Definitions

A stochastic process is a collection of random variables \(\{X_t\}_{t \in T}\) indexed by time.

A filtration \(\{\mathcal{F}_t\}\) is an increasing family of \(\sigma\)-algebras representing information available at time \(t\).

A process \(\{X_t\}\) is a martingale with respect to \(\{\mathcal{F}_t\}\) if:

  • \(X_t\) is integrable for all \(t\)
  • \(X_t\) is adapted to \(\mathcal{F}_t\) (measurable with respect to available information)
  • \(\mathbb{E}[X_t | \mathcal{F}_s] = X_s\) for all \(s \leq t\) (fair game property)

Standard Brownian motion \(\{B_t\}_{t \geq 0}\) is a stochastic process with:

  • \(B_0 = 0\)
  • Independent increments: \(B_t - B_s\) independent of \(\{B_u : u \leq s\}\) for \(s < t\)
  • Stationary increments: \(B_t - B_s \sim N(0, t-s)\)
  • Continuous sample paths

Theorem (Martingale Property of Brownian Motion)

Standard Brownian motion is a martingale. Moreover, \(B_t^2 - t\) and \(\exp(\theta B_t - \frac{1}{2}\theta^2 t)\) are also martingales.

Proof Sketch

For Brownian motion itself:

\[\mathbb{E}[B_t | \mathcal{F}_s] = \mathbb{E}[B_t - B_s + B_s | \mathcal{F}_s] = \mathbb{E}[B_t - B_s] + B_s = 0 + B_s = B_s\]

For \(B_t^2 - t\):

\[\mathbb{E}[B_t^2 | \mathcal{F}_s] = \mathbb{E}[(B_t - B_s + B_s)^2 | \mathcal{F}_s]\] \[= \mathbb{E}[(B_t - B_s)^2] + 2B_s\mathbb{E}[B_t - B_s] + B_s^2\] \[= (t-s) + 0 + B_s^2\]

So \(\mathbb{E}[B_t^2 - t | \mathcal{F}_s] = B_s^2 - s\).

Notation Guide

  • \(\mathbb{E}[X | \mathcal{F}]\): Conditional expectation
  • \(\mathcal{F}_t\): Filtration (information up to time \(t\))
  • \(B_t\) or \(W_t\): Brownian motion / Wiener process
  • \(N(\mu, \sigma^2)\): Normal distribution
  • \(\langle X \rangle_t\): Quadratic variation

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T=1.0, N=1000, n_paths=5):
    """
    Simulate standard Brownian motion paths.
    
    Parameters:
    -----------
    T : float
        Final time
    N : int
        Number of time steps
    n_paths : int
        Number of paths to simulate
    """
    dt = T / N
    t = np.linspace(0, T, N+1)
    
    # Generate increments
    dB = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
    
    # Cumulative sum for Brownian paths
    B = np.zeros((n_paths, N+1))
    B[:, 1:] = np.cumsum(dB, axis=1)
    
    return t, B

def simulate_geometric_brownian_motion(S0, mu, sigma, T=1.0, N=1000, n_paths=5):
    """
    Simulate geometric Brownian motion (used in Black-Scholes model).
    
    dS_t = mu * S_t * dt + sigma * S_t * dB_t
    
    Solution: S_t = S_0 * exp((mu - sigma²/2)t + sigma * B_t)
    """
    t, B = simulate_brownian_motion(T, N, n_paths)
    
    S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * B)
    
    return t, S

def verify_martingale_property(n_samples=10000):
    """
    Verify the martingale property empirically.
    
    For a martingale: E[X_t | F_s] = X_s
    We check: E[B_t - B_s] = 0 and E[B_t^2 - t | F_s] = B_s^2 - s
    """
    T, s, t = 1.0, 0.3, 0.7
    N = 1000
    dt = T / N
    
    # Simulate many paths
    n_s = int(s * N)
    n_t = int(t * N)
    
    B_s_samples = []
    B_t_samples = []
    
    for _ in range(n_samples):
        dB = np.random.normal(0, np.sqrt(dt), N)
        B = np.concatenate([[0], np.cumsum(dB)])
        B_s_samples.append(B[n_s])
        B_t_samples.append(B[n_t])
    
    B_s_samples = np.array(B_s_samples)
    B_t_samples = np.array(B_t_samples)
    
    # Check martingale property
    increment_mean = np.mean(B_t_samples - B_s_samples)
    increment_var = np.var(B_t_samples - B_s_samples)
    
    # Check B_t^2 - t martingale
    M_s = B_s_samples**2 - s
    M_t = B_t_samples**2 - t
    M_increment_mean = np.mean(M_t - M_s)
    
    print("Martingale Verification:")
    print(f"  E[B_t - B_s] = {increment_mean:.6f} (should be ≈ 0)")
    print(f"  Var(B_t - B_s) = {increment_var:.6f} (should be ≈ {t-s:.4f})")
    print(f"  E[(B_t²-t) - (B_s²-s)] = {M_increment_mean:.6f} (should be ≈ 0)")
    
    return {
        'increment_mean': increment_mean,
        'increment_var': increment_var,
        'martingale_diff': M_increment_mean
    }

Cryptography: Elliptic Curve Cryptography

Real-World Motivation: Secure communication over the internet relies on cryptographic protocols that are computationally hard to break. Elliptic curve cryptography (ECC) provides the same security as RSA with much smaller key sizes, making it ideal for mobile devices and embedded systems. ECC powers Bitcoin, Ethereum, TLS/SSL, and many other security protocols.

Definitions

An elliptic curve over a field \(K\) is the set of points \((x, y) \in K^2\) satisfying the Weierstrass equation:

\[y^2 = x^3 + ax + b\]

where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\) (ensuring the curve is non-singular), together with a point at infinity \(\mathcal{O}\).

The group law on elliptic curve points is defined geometrically:

  • Identity: \(P + \mathcal{O} = \mathcal{O} + P = P\)
  • Inverse: If \(P = (x, y)\), then \(-P = (x, -y)\)
  • Addition: For \(P \neq Q\), draw line through \(P\) and \(Q\); it intersects the curve at a third point \(R\); then \(P + Q = -R\)
  • Doubling: For \(P = Q\), use the tangent line at \(P\)

Theorem (Elliptic Curve Group)

The set of points on an elliptic curve, with the operation defined above, forms an abelian group.

Proof Sketch

Associativity is the difficult part. One approach uses the divisor class group: points on the curve correspond to divisors modulo principal divisors. The geometric group law matches the divisor class group operation.

Commutativity follows from the symmetry of the line construction.

Closure requires verifying that the algebraic formulas for addition always yield a point on the curve.

Explicit Formulas

For \(P = (x_1, y_1)\) and \(Q = (x_2, y_2)\) with \(P \neq -Q\):

If \(P \neq Q\):

\[\lambda = \frac{y_2 - y_1}{x_2 - x_1}\]

If \(P = Q\):

\[\lambda = \frac{3x_1^2 + a}{2y_1}\]

Then:

\[x_3 = \lambda^2 - x_1 - x_2\] \[y_3 = \lambda(x_1 - x_3) - y_1\]

Notation Guide

  • \(E(K)\): Elliptic curve over field \(K\)
  • \(\mathcal{O}\): Point at infinity (identity element)
  • \([n]P\): Scalar multiplication (adding \(P\) to itself \(n\) times)
  • \(\#E(\mathbb{F}_p)\): Number of points on curve over finite field
  • \(a, b\): Curve parameters in Weierstrass equation

class EllipticCurve:
    """
    Elliptic curve over a finite field F_p.
    Curve equation: y² = x³ + ax + b (mod p)
    """
    
    def __init__(self, a, b, p):
        self.a = a
        self.b = b
        self.p = p
        
        # Check non-singularity
        discriminant = (-16 * (4 * a**3 + 27 * b**2)) % p
        if discriminant == 0:
            raise ValueError("Curve is singular")
    
    def is_on_curve(self, point):
        """Check if point is on the curve."""
        if point is None:  # Point at infinity
            return True
        x, y = point
        return (y * y - (x**3 + self.a * x + self.b)) % self.p == 0
    
    def add(self, P, Q):
        """Add two points on the curve."""
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # P + (-P) = O
        if x1 == x2 and (y1 + y2) % self.p == 0:
            return None
        
        # Compute slope
        if x1 == x2:  # Point doubling
            # λ = (3x₁² + a) / (2y₁)
            num = (3 * x1 * x1 + self.a) % self.p
            den = (2 * y1) % self.p
        else:  # Point addition
            # λ = (y₂ - y₁) / (x₂ - x₁)
            num = (y2 - y1) % self.p
            den = (x2 - x1) % self.p
        
        # Modular inverse of denominator
        den_inv = pow(den, -1, self.p)
        lam = (num * den_inv) % self.p
        
        # x₃ = λ² - x₁ - x₂
        x3 = (lam * lam - x1 - x2) % self.p
        
        # y₃ = λ(x₁ - x₃) - y₁
        y3 = (lam * (x1 - x3) - y1) % self.p
        
        return (x3, y3)
    
    def multiply(self, n, P):
        """Compute n*P using double-and-add algorithm."""
        if n == 0 or P is None:
            return None
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            n >>= 1
        
        return result
    
    def generate_keypair(self):
        """Generate ECC key pair."""
        import random
        
        # Find a base point (simplified: try random points)
        G = None
        for x in range(self.p):
            rhs = (x**3 + self.a * x + self.b) % self.p
            y = pow(rhs, (self.p + 1) // 4, self.p)  # Tonelli-Shank for p ≡ 3 (mod 4)
            if (y * y) % self.p == rhs:
                G = (x, y)
                break
        
        if G is None:
            raise ValueError("Could not find base point")
        
        # Private key: random scalar
        d = random.randint(1, self.p - 1)
        
        # Public key: d * G
        Q = self.multiply(d, G)
        
        return {
            'private_key': d,
            'public_key': Q,
            'base_point': G
        }

Optimization: Convex Analysis and Duality

Real-World Motivation: From training neural networks to designing efficient supply chains, optimization problems arise everywhere. Convex optimization problems—where the objective and constraints have special geometric properties—can be solved efficiently and reliably. Duality theory provides certificates of optimality and sensitivity analysis.

Definitions

A set \(C \subseteq \mathbb{R}^n\) is convex if for all \(x, y \in C\) and \(\theta \in [0,1]\):

\[\theta x + (1-\theta)y \in C\]

A function \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if its epigraph is a convex set, equivalently if for all \(x, y\) and \(\theta \in [0,1]\):

\[f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)\]

The conjugate function of \(f\) is:

\[f^*(y) = \sup_{x} \{y^T x - f(x)\}\]

The Lagrangian for the problem \(\min_x f(x)\) subject to \(g_i(x) \leq 0\), \(h_j(x) = 0\) is:

\[L(x, \lambda, \nu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \nu_j h_j(x)\]

Theorem (Strong Duality for Convex Problems)

For a convex optimization problem satisfying Slater's condition (existence of a strictly feasible point), strong duality holds:

\[p^* = d^*\]

where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Proof Sketch

Define the value function \(p(u, v)\) as the optimal value when constraints are perturbed by \((u, v)\). This function is convex.

Under Slater's condition, \(p\) is proper and there exists a non-vertical supporting hyperplane to its epigraph at the origin. The slope of this hyperplane gives optimal dual variables.

The dual function \(g(\lambda, \nu) = \inf_x L(x, \lambda, \nu)\) is always concave, and weak duality \(d^* \leq p^*\) always holds.

Notation Guide

  • \(f^*\): Convex conjugate (Fenchel-Legendre transform)
  • \(L(x, \lambda, \nu)\): Lagrangian
  • \(\lambda, \nu\): Lagrange multipliers (dual variables)
  • \(g(\lambda, \nu)\): Dual function
  • \(p^*, d^*\): Primal and dual optimal values
  • \(\nabla f(x)\): Gradient of \(f\) at \(x\)

Hilbert Spaces and Quantum Mechanics

Historical Context: In the early 20th century, physicists struggled to make mathematical sense of quantum mechanics. Heisenberg's matrix mechanics and Schrödinger's wave mechanics seemed like different theories until von Neumann showed they were equivalent representations of the same underlying structure: Hilbert space. His 1932 book "Mathematische Grundlagen der Quantenmechanik" established the rigorous mathematical framework that underpins quantum theory to this day.

Definitions

A Hilbert space is a complete inner product space. That is, a vector space \(\mathcal{H}\) equipped with an inner product \(\langle \cdot, \cdot \rangle\) such that the induced norm \(\|v\| = \sqrt{\langle v, v \rangle}\) makes \(\mathcal{H}\) complete.

An operator \(A: \mathcal{H} \to \mathcal{H}\) is self-adjoint if \(\langle Av, w \rangle = \langle v, Aw \rangle\) for all \(v, w\).

A projection is an operator \(P\) satisfying \(P^2 = P\) and \(P^* = P\).

Theorem (Spectral Theorem for Self-Adjoint Operators)

Let \(A\) be a bounded self-adjoint operator on a Hilbert space \(\mathcal{H}\). Then there exists a unique projection-valued measure \(E\) such that:

\[A = \int_{\sigma(A)} \lambda \, dE(\lambda)\]

where \(\sigma(A)\) is the spectrum of \(A\).

Proof Sketch

The proof uses the continuous functional calculus. For polynomials \(p\), define \(p(A)\) in the obvious way. Extend to continuous functions by density (Weierstrass approximation). The map \(f \mapsto \langle f(A)v, v \rangle\) defines a positive linear functional, hence a measure by Riesz representation. This gives the spectral measure.

Notation Guide

  • \(\mathcal{H}\): Hilbert space
  • \(\langle v, w \rangle\): Inner product (conjugate linear in second argument)
  • \(\|v\|\): Norm induced by inner product
  • \(A^*\): Adjoint of operator \(A\)
  • \(\sigma(A)\): Spectrum of \(A\)
  • \(E(\Delta)\): Spectral projection for Borel set \(\Delta\)

def spectral_decomposition(matrix):
    """
    Compute spectral decomposition of a Hermitian matrix.
    
    For finite-dimensional Hilbert spaces (ℂ^n), the spectral theorem
    reduces to diagonalization: A = Σ λ_i |v_i⟩⟨v_i|
    """
    # Ensure matrix is Hermitian
    if not np.allclose(matrix, matrix.conj().T):
        raise ValueError("Matrix must be Hermitian")
    
    # Compute eigenvalues and eigenvectors
    eigenvalues, eigenvectors = np.linalg.eigh(matrix)
    
    return {
        'eigenvalues': eigenvalues,
        'eigenvectors': eigenvectors,
        'spectral_projections': [
            eigenvalues[i] * np.outer(eigenvectors[:, i], eigenvectors[:, i].conj())
            for i in range(len(eigenvalues))
        ]
    }

def quantum_state_evolution(H, psi0, t):
    """
    Simulate quantum state evolution under Hamiltonian H.
    
    Schrödinger equation: iℏ dψ/dt = Hψ
    Solution: ψ(t) = exp(-iHt/ℏ) ψ(0)
    """
    # Set ℏ = 1 for simplicity
    hbar = 1.0
    
    # Spectral decomposition
    eigvals, eigvecs = np.linalg.eigh(H)
    
    # Initial state in eigenbasis
    coeffs = eigvecs.conj().T @ psi0
    
    # Time evolution: each eigencomponent picks up phase exp(-iEt/ℏ)
    evolved_coeffs = coeffs * np.exp(-1j * eigvals * t / hbar)
    
    # Transform back
    psi_t = eigvecs @ evolved_coeffs
    
    return psi_t

Algebraic Number Theory: The Class Group

Historical Context: In the 19th century, mathematicians sought to extend unique factorization from the integers to more general number systems. Kummer discovered that unique factorization fails in many rings of integers of number fields, but he found that ideals could be uniquely factored into prime ideals. Dedekind later formalized this theory and introduced the class group, which measures the failure of unique factorization. This theory laid the groundwork for modern algebraic number theory.

Definitions

A number field \(K\) is a finite extension of \(\mathbb{Q}\). Its ring of integers \(\mathcal{O}_K\) consists of elements integral over \(\mathbb{Z}\).

A fractional ideal is an \(\mathcal{O}_K\)-submodule \(I \subseteq K\) such that \(\alpha I \subseteq \mathcal{O}_K\) for some \(\alpha \in K^*\).

Two fractional ideals \(I, J\) are equivalent if \(I = (\alpha)J\) for some principal ideal \((\alpha)\).

The class group \(Cl(K)\) is the group of fractional ideals modulo principal ideals.

Theorem (Finiteness of Class Number)

The class group \(Cl(K)\) is finite. Its order \(h_K = |Cl(K)|\) is called the class number.

Proof Sketch

The proof uses Minkowski's geometry of numbers. Every ideal class contains an integral ideal with norm bounded by the Minkowski bound:

\[M_K = \frac{n!}{n^n} \left(\frac{4}{\pi}\right)^{r_2} \sqrt{|d_K|}\]

where \(n = [K:\mathbb{Q}]\), \(r_2\) is the number of complex embeddings, and \(d_K\) is the discriminant. Since there are only finitely many ideals with bounded norm, the class group is finite.

Notation Guide

  • \(K\): Number field
  • \(\mathcal{O}_K\): Ring of integers
  • \(I, J, \mathfrak{p}\): Ideals (prime ideals often written \(\mathfrak{p}\))
  • \([I]\): Ideal class of \(I\)
  • \(Cl(K)\) or \(Pic(\mathcal{O}_K)\): Class group
  • \(h_K\): Class number
  • \(N(I)\): Norm of ideal \(I\)

def discriminant_quadratic(d):
    """
    Compute discriminant of Q(√d).
    
    For squarefree d:
    - If d ≡ 1 (mod 4): discriminant = d
    - Otherwise: discriminant = 4d
    """
    if d % 4 == 1:
        return d
    else:
        return 4 * d

def minkowski_bound_quadratic(d):
    """
    Compute Minkowski bound for Q(√d).
    
    For real quadratic (d > 0): M = ½√|discriminant|
    For imaginary quadratic (d < 0): M = (2/π)√|discriminant|
    """
    disc = discriminant_quadratic(d)
    if d > 0:
        return 0.5 * np.sqrt(abs(disc))
    else:
        return (2 / np.pi) * np.sqrt(abs(disc))

def prime_decomposition_quadratic(p, d):
    """
    Determine how prime p decomposes in Q(√d).
    
    Returns: 'inert', 'split', or 'ramified'
    """
    disc = discriminant_quadratic(d)
    
    # Legendre symbol (disc/p)
    if p == 2:
        # Special case for p=2
        if disc % 8 in [1, 5]:
            return 'split' if disc % 8 == 1 else 'inert'
        else:
            return 'ramified'
    
    # For odd p, use quadratic reciprocity
    leg = pow(disc, (p - 1) // 2, p)
    if leg == 0:
        return 'ramified'
    elif leg == 1:
        return 'split'
    else:
        return 'inert'

def class_number_estimate(d):
    """
    Estimate class number for Q(√d) using Minkowski bound.
    
    The class number is the number of ideal classes.
    """
    M = minkowski_bound_quadratic(d)
    disc = discriminant_quadratic(d)
    
    # Find primes up to M
    def sieve(n):
        is_prime = [True] * (n + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(n**0.5) + 1):
            if is_prime[i]:
                for j in range(i*i, n+1, i):
                    is_prime[j] = False
        return [i for i, p in enumerate(is_prime) if p]
    
    primes = sieve(int(M) + 1)
    
    # Analyze decomposition of each prime
    decomposition = {}
    for p in primes:
        decomposition[p] = prime_decomposition_quadratic(p, d)
    
    return {
        'd': d,
        'discriminant': disc,
        'minkowski_bound': M,
        'relevant_primes': primes,
        'decomposition': decomposition,
        'note': 'Class number equals number of ideal classes'
    }

Differential Geometry: Curvature and the Gauss-Bonnet Theorem

Historical Context: Gauss's "Theorema Egregium" (remarkable theorem) of 1827 showed that the Gaussian curvature of a surface is intrinsic—it can be determined by measurements within the surface itself, without reference to the ambient space. Bonnet later connected this curvature to topology. The Gauss-Bonnet theorem, one of the most beautiful results in mathematics, relates the total curvature of a surface to its Euler characteristic, forging a deep connection between geometry and topology.

Definitions

For a surface \(S\) with Riemannian metric, the Gaussian curvature \(K\) at a point measures how much the surface deviates from being flat.

The geodesic curvature \(k_g\) of a curve on the surface measures how much the curve deviates from being a geodesic.

The Euler characteristic of a compact surface is \(\chi(S) = V - E + F\) for any triangulation.

Theorem (Gauss-Bonnet)

For a compact oriented surface \(S\) with boundary \(\partial S\):

\[\int_S K \, dA + \int_{\partial S} k_g \, ds = 2\pi \chi(S)\]

For a closed surface (no boundary):

\[\int_S K \, dA = 2\pi \chi(S)\]

Proof Sketch

The proof proceeds by triangulation. For a single geodesic triangle on the surface, the Gauss-Bonnet formula for triangles states:

\[\int_\Delta K \, dA = \alpha + \beta + \gamma - \pi\]

where \(\alpha, \beta, \gamma\) are the interior angles. Summing over all triangles in a triangulation, the angle excesses sum to \(2\pi V - \pi F\) (using that angles around interior vertices sum to \(2\pi\)). Combining with \(3F = 2E\) for a triangulation gives the result.

Notation Guide

  • \(K\): Gaussian curvature
  • \(k_g\): Geodesic curvature
  • \(dA\): Area element
  • \(ds\): Arc length element
  • \(\chi(S)\): Euler characteristic
  • \(V, E, F\): Vertices, edges, faces of triangulation

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def sphere_curvature(R=1.0):
    """
    Gaussian curvature of sphere of radius R.
    K = 1/R² everywhere.
    """
    K = 1 / R**2
    area = 4 * np.pi * R**2
    total_curvature = K * area
    
    return {
        'curvature': K,
        'area': area,
        'total_curvature': total_curvature,
        'euler_characteristic': total_curvature / (2 * np.pi),
        'expected_euler': 2
    }

def torus_curvature(major_radius=3, minor_radius=1):
    """
    Gaussian curvature of torus.
    
    Parametrization:
    x = (R + r cos(v)) cos(u)
    y = (R + r cos(v)) sin(u)
    z = r sin(v)
    
    K = cos(v) / (r(R + r cos(v)))
    """
    R, r = major_radius, minor_radius
    
    # Total curvature integrates to 0
    # Positive curvature on outer half, negative on inner half
    
    # Compute numerically
    u = np.linspace(0, 2*np.pi, 100)
    v = np.linspace(0, 2*np.pi, 100)
    U, V = np.meshgrid(u, v)
    
    # Gaussian curvature
    K = np.cos(V) / (r * (R + r * np.cos(V)))
    
    # Area element
    E = (R + r * np.cos(V))**2
    F = 0
    G = r**2
    dA = np.sqrt(E * G - F**2)
    
    # Numerical integration
    total_K = np.trapz(np.trapz(K * dA, u), v)
    
    return {
        'total_curvature': total_K,
        'euler_characteristic': total_K / (2 * np.pi),
        'expected_euler': 0
    }

def hyperbolic_plane_curvature():
    """
    Poincaré disk model of hyperbolic plane.
    K = -1 everywhere.
    """
    K = -1
    # Area is infinite, but for a compact quotient (surface of genus g >= 2):
    # χ = 2 - 2g, so ∫K dA = 2π(2-2g) = 4π(1-g)
    
    return {
        'curvature': K,
        'note': 'Hyperbolic plane has constant negative curvature'
    }

def angle_excess_triangle(curvature_type='sphere', side_length=1.0):
    """
    Compute angle excess for a geodesic triangle.
    
    On sphere: angle sum > π, excess proportional to area
    On plane: angle sum = π
    On hyperbolic plane: angle sum < π, defect proportional to area
    """
    if curvature_type == 'sphere':
        # For unit sphere, geodesic triangles are spherical triangles
        # Area = α + β + γ - π (angle excess)
        # For equilateral triangle with side a: area = 3α - π
        # where cos(a) = cos²(α) / (1 - cos(α)) for unit sphere
        
        # Approximate for small triangles
        a = side_length
        area_approx = a**2 * np.sqrt(3) / 4  # Euclidean area
        angle_excess = area_approx  # For unit sphere, K=1
        
        angle_sum = np.pi + angle_excess
        each_angle = angle_sum / 3
        
        return {
            'angle_sum': angle_sum,
            'angle_excess': angle_excess,
            'each_angle_deg': np.degrees(each_angle),
            'euclidean_angle_deg': 60
        }
    
    elif curvature_type == 'hyperbolic':
        # Angle defect instead of excess
        a = side_length
        # For hyperbolic plane with K = -1
        angle_defect = a**2 * np.sqrt(3) / 4  # Area = |angle defect|
        angle_sum = np.pi - angle_defect
        
        return {
            'angle_sum': angle_sum,
            'angle_defect': angle_defect,
            'each_angle_deg': np.degrees(angle_sum / 3),
            'euclidean_angle_deg': 60
        }
    
    else:  # flat
        return {
            'angle_sum': np.pi,
            'angle_excess': 0,
            'each_angle_deg': 60
        }

The Legacy of Niels Henrik Abel

Historical Context: Niels Henrik Abel (1802–1829) was a Norwegian mathematician who made groundbreaking contributions despite living in poverty and dying at age 26. His work on elliptic functions, algebraic equations, and infinite series laid foundations for modern mathematics. The Abel Prize, established in 2002, is now considered the Nobel Prize of mathematics.

Abel's most famous result is the impossibility of solving the general quintic equation by radicals. While quadratic, cubic, and quartic equations have formulas involving roots, Abel proved that no such formula exists for degree 5 and higher. This resolved a problem that had puzzled mathematicians for centuries.

His work on elliptic functions was equally revolutionary. Abel discovered that these functions, which generalize trigonometric functions, have a double periodicity when extended to complex numbers. This insight opened the door to the theory of complex multiplication and modern algebraic geometry.

Abel's theorem on power series established conditions for the continuity of the sum at the boundary of the disk of convergence. The result, that if \(\sum a_n\) converges then \(\sum a_n x^n \to \sum a_n\) as \(x \to 1^-\), is a cornerstone of analysis.

Despite his short life, Abel's influence is immense. The terms "abelian group," "abelian variety," and "abelian integral" honor his legacy. His insistence on rigorous proof and his deep insights into algebraic structures anticipated the development of abstract algebra by nearly a century.

📜 Math History: The Development of Abstract Algebra

The 19th century witnessed a profound transformation in mathematics: the shift from studying specific objects to studying abstract structures. This revolution, which became known as abstract algebra, changed the very nature of mathematical thinking and laid the groundwork for modern mathematics.

The story begins with the solution of polynomial equations. The quadratic formula was known to ancient Babylonians, and Renaissance mathematicians discovered formulas for cubic and quartic equations. But the quintic equation resisted all attempts. In 1799, Ruffini claimed a proof of impossibility, but it had gaps. Abel provided the first complete proof in 1824, showing that the general quintic cannot be solved by radicals.

Galois, working in the years before his death in 1832 at age 20, discovered the deeper reason: the solvability of an equation depends on the structure of its associated group of permutations. Galois's theory connected field extensions to groups, providing a complete criterion for solvability. His work, published posthumously by Liouville in 1846, was initially met with skepticism but eventually recognized as revolutionary.

The concept of a group itself evolved gradually. Cauchy studied permutation groups in the 1810s, and Cayley attempted a general definition in 1854. But the modern axiomatic definition emerged only in the 1880s through the work of von Dyck and Weber. Similarly, the concept of a field developed from number theory and algebraic geometry, with Dedekind and Kronecker contributing key ideas.

Emmy Noether brought this development to its culmination in the 1920s. Her abstract approach, emphasizing structural properties over computational techniques, transformed algebra. Noether's theorem connecting symmetries to conservation laws is fundamental to physics, while her work on rings and ideals provided the foundation for modern algebraic geometry.

The abstraction that characterized algebra spread to other fields. Topology, functional analysis, and category theory all emerged from this new way of thinking. The Bourbaki group, founded in 1935, sought to reformulate all of mathematics along structural lines. While their influence has waned, the structural approach they championed remains dominant.

This historical development reveals a profound shift: mathematics became the study of patterns and structures rather than specific quantities. The power of this abstraction is that a theorem proved once for an abstract structure applies to all its instances—whether numbers, polynomials, symmetries, or geometric transformations. This unity, glimpsed by Galois and fully realized by Noether, is one of the great achievements of human thought.

Problem: A Functional Equation

Source: Putnam Competition Style

Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all \(x, y \in \mathbb{R}\):

\[f(x^2 + y) = f(x)^2 + f(y)\]

💡 Hint

Start by finding \(f(0)\). Then consider what happens when \(y = 0\) and when \(x = 0\). Try to determine if \(f\) must be non-negative on non-negative inputs.

✅ Solution

Step 1: Find \(f(0)\).

Setting \(x = y = 0\):

\[f(0) = f(0)^2 + f(0)\]

This gives \(f(0)^2 = 0\), so \(f(0) = 0\).

Step 2: Find \(f(x^2)\).

Setting \(y = 0\):

\[f(x^2) = f(x)^2 + f(0) = f(x)^2\]

So \(f(x^2) = f(x)^2 \geq 0\). This means \(f(t) \geq 0\) for all \(t \geq 0\).

Step 3: Determine \(f\) on non-negative reals.

Setting \(x = 0\):

\[f(y) = f(0)^2 + f(y) = f(y)\]

This is consistent but gives no new information.

Step 4: Show \(f\) is additive on non-negative reals.

For \(a, b \geq 0\), we can write \(a = x^2\) for some \(x\). Then:

\[f(a + b) = f(x^2 + b) = f(x)^2 + f(b) = f(x^2) + f(b) = f(a) + f(b)\]

Step 5: Extend to all reals.

From \(f(x^2) = f(x)^2\), we have \(f((-x)^2) = f(-x)^2 = f(x)^2\), so \(f(-x) = \pm f(x)\).

For any \(y\), setting \(x = 1\):

\[f(1 + y) = f(1)^2 + f(y)\]

Let \(c = f(1) = f(1)^2\), so \(c = 0\) or \(c = 1\).

Case 1: \(c = 0\).

Then \(f(1) = 0\), and by additivity on \(\mathbb{R}_{\geq 0}\), we get \(f(x) = 0\) for all \(x \geq 0\).

For \(y < 0\), choose \(x\) large enough that \(x^2 + y \geq 0\). Then:

\[0 = f(x^2 + y) = f(x)^2 + f(y) = 0 + f(y)\]

So \(f(y) = 0\). Thus \(f(x) = 0\) for all \(x\).

Case 2: \(c = 1\).

Then \(f(1) = 1\), and by additivity on \(\mathbb{R}_{\geq 0}\), we get \(f(x) = x\) for all rational \(x \geq 0\).

Since \(f(x^2) = f(x)^2\), we have \(f(x) \geq 0\) for \(x \geq 0\), so \(f\) is non-decreasing on \(\mathbb{R}_{\geq 0}\).

Combined with additivity, this implies \(f(x) = x\) for all \(x \geq 0\).

For \(y < 0\), using \(f(x^2) = f(x)^2\):

\[f(y) = f((-y) + 2y) = f((-y)) + f(2y) = -y + 2f(y)\]

Wait—let's be more careful. For any \(x\):

\[f(x^2 + y) = f(x)^2 + f(y) = f(x^2) + f(y)\]

So \(f(a + y) = f(a) + f(y)\) for all \(a \geq 0\) and all \(y\).

For \(y < 0\), choose \(a > -y\). Then \(a + y > 0\), so:

\[f(a + y) = a + y = f(a) + f(y) = a + f(y)\]

Thus \(f(y) = y\) for all \(y < 0\) as well.

Answer: The solutions are \(f(x) = 0\) for all \(x\), and \(f(x) = x\) for all \(x\).

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is perhaps the most famous fractal in mathematics. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) with \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set. Despite this complexity, the Mandelbrot set is connected (proved by Douady and Hubbard in the 1980s).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point doesn't escape.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[mask] = i
    
    return M

def plot_mandelbrot(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25,
                    width=800, height=800, max_iter=100, cmap='hot'):
    """
    Create a visualization of the Mandelbrot set.
    """
    M = mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter)
    
    fig, ax = plt.subplots(figsize=(10, 10))
    
    im = ax.imshow(M, extent=[xmin, xmax, ymin, ymax], 
                   cmap=cmap, origin='lower', interpolation='bilinear')
    
    ax.set_xlabel('Re(c)')
    ax.set_ylabel('Im(c)')
    ax.set_title('Mandelbrot Set')
    
    plt.colorbar(im, ax=ax, label='Iterations to escape')
    
    return fig

def zoom_sequence():
    """

    """
