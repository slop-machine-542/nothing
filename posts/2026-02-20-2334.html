Algebraic Coding Theory: Reed-Solomon Codes

algebraic-coding-theory

Motivation

Algebraic coding theory studies error-correcting codes using algebraic methods. Reed-Solomon codes, invented in 1960 by Irving Reed and Gustave Solomon, are among the most widely used error-correcting codes. They power technologies from CDs and DVDs to QR codes, deep space communication, and modern storage systems. The beauty of Reed-Solomon codes lies in their elegant algebraic construction using polynomials over finite fields.

Definitions

  • Finite Field \(\mathbb{F}_q\): A field with \(q = p^n\) elements, where \(p\) is prime. Arithmetic is performed modulo an irreducible polynomial.
  • Reed-Solomon Code \(RS(n, k)\): A linear code of length \(n\) and dimension \(k\) over \(\mathbb{F}_q\) (where \(n \leq q\)).
  • Generator Polynomial: For a primitive element \(\alpha\) of \(\mathbb{F}_q\), the generator is \(g(x) = \prod_{i=0}^{n-k-1}(x - \alpha^i)\).
  • Minimum Distance: The Reed-Solomon code has minimum distance \(d = n - k + 1\), achieving the Singleton bound.
  • Evaluation Map: A message polynomial \(m(x)\) of degree \(< k\) is encoded as \((m(\alpha_1), m(\alpha_2), \ldots, m(\alpha_n))\).

Theorem: Error Correction Capability

Theorem: A Reed-Solomon code \(RS(n, k)\) over \(\mathbb{F}_q\) can correct up to \(t = \lfloor (n-k)/2 \rfloor\) errors and up to \(n - k\) erasures. The code has parameters \([n, k, n-k+1]_q\), making it a Maximum Distance Separable (MDS) code.

Proof Sketch

The proof relies on the properties of polynomial interpolation. A nonzero polynomial of degree \(< k\) can have at most \(k-1\) roots. Therefore, two distinct codewords (evaluations of different polynomials) can agree in at most \(k-1\) positions, giving minimum distance \(n - (k-1) = n - k + 1\). For decoding, the Berlekamp-Massey algorithm or Peterson's algorithm can efficiently correct errors by finding the error locator polynomial.

Notation Guide

  • \(\mathbb{F}_q\) — Finite field with \(q\) elements
  • \(\alpha\) — Primitive element of the field
  • \([n, k, d]_q\) — Linear code parameters: length, dimension, distance, field size
  • \(g(x)\) — Generator polynomial
  • \(m(x)\) — Message polynomial
  • \(t\) — Error correction capability
  • MDS — Maximum Distance Separable

import numpy as np
from numpy.polynomial import polynomial as P

class ReedSolomonCode:
    """
    Reed-Solomon error-correcting code over GF(2^m).
    Uses Berlekamp-Massey for decoding.
    """
    def __init__(self, n, k, field_exp=8):
        """
        Initialize RS(n, k) code over GF(2^field_exp).
        n: code length
        k: message length
        """
        self.n = n
        self.k = k
        self.field_exp = field_exp
        self.q = 2 ** field_exp
        self.t = (n - k) // 2  # Error correction capability
        
        # Primitive polynomial for GF(2^8): x^8 + x^4 + x^3 + x^2 + 1
        self.prim_poly = 0x11d
        
    def gf_mult(self, a, b):
        """Multiply two elements in GF(2^8)."""
        result = 0
        for i in range(8):
            if b & 1:
                result ^= a
            hi_bit = a & 0x80
            a <<= 1
            if hi_bit:
                a ^= 0x1d  # Reduce by primitive polynomial
            b >>= 1
        return result & 0xff
    
    def gf_pow(self, a, n):
        """Compute a^n in GF(2^8)."""
        result = 1
        for _ in range(n):
            result = self.gf_mult(result, a)
        return result
    
    def encode(self, message):
        """
        Encode message using Reed-Solomon.
        Simplified: evaluate polynomial at n points.
        """
        # Pad message to length k
        m = list(message) + [0] * (self.k - len(message))
        m = m[:self.k]
        
        # Evaluate polynomial at points 0, 1, ..., n-1
        codeword = []
        for i in range(self.n):
            val = 0
            for j, coeff in enumerate(m):
                val ^= self.gf_mult(coeff, self.gf_pow(i, j))
            codeword.append(val)
        
        return codeword
    
    def add_errors(self, codeword, error_positions, error_values):
        """Add errors to codeword at specified positions."""
        received = codeword.copy()
        for pos, val in zip(error_positions, error_values):
            received[pos] ^= val  # XOR for addition in GF(2^8)
        return received
    
    def syndrome(self, received):
        """Compute syndrome polynomial."""
        synd = []
        for i in range(1, 2*self.t + 1):
            s = 0
            for j, r in enumerate(received):
                s ^= self.gf_mult(r, self.gf_pow(j, i))
            synd.append(s)
        return synd
    
    def info(self):
        """Display code parameters."""
        print(f"Reed-Solomon Code RS({self.n}, {self.k})")
        print(f"Field: GF(2^{self.field_exp})")
        print(f"Minimum distance: {self.n - self.k + 1}")
        print(f"Error correction: up to {self.t} errors")
        print(f"Rate: {self.k}/{self.n} = {self.k/self.n:.3f}")

Fourier Analysis: From Series to Transforms

fourier-analysis

Motivation

Fourier analysis decomposes functions into superpositions of waves, revealing the frequency content hidden in signals. Developed by Joseph Fourier in the early 19th century to study heat conduction, it has become fundamental to modern science and engineering. From signal processing and quantum mechanics to number theory and partial differential equations, Fourier analysis provides a powerful lens for understanding periodic and oscillatory phenomena.

Definitions

  • Fourier Series: For a periodic function \(f\) on \([-\pi, \pi]\): \[f(x) = \sum_{n=-\infty}^{\infty} \hat{f}(n) e^{inx}\] where \(\hat{f}(n) = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(x) e^{-inx} dx\).
  • Fourier Transform: For \(f \in L^1(\mathbb{R})\): \[\hat{f}(\xi) = \int_{-\infty}^{\infty} f(x) e^{-2\pi i x \xi} dx\]
  • Convolution: \((f * g)(x) = \int_{-\infty}^{\infty} f(y)g(x-y)dy\)
  • Plancherel's Theorem: The Fourier transform extends to a unitary operator on \(L^2(\mathbb{R})\), preserving the inner product.

Theorem: The Fourier Inversion Formula

Theorem: If \(f \in L^1(\mathbb{R})\) and \(\hat{f} \in L^1(\mathbb{R})\), then for almost every \(x\): \[f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi\] Moreover, if \(f\) is continuous, this holds for all \(x\).

Proof Sketch

The proof uses an approximation argument. Define the Gaussian \(G_t(x) = (4\pi t)^{-1/2}e^{-x^2/(4t)}\) with Fourier transform \(\hat{G}_t(\xi) = e^{-4\pi^2 t \xi^2}\). Consider \(f * G_t\), which converges to \(f\) as \(t \to 0\). By the convolution theorem: \[f * G_t(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) \hat{G}_t(\xi) e^{2\pi i x \xi} d\xi\] As \(t \to 0\), \(\hat{G}_t(\xi) \to 1\), and dominated convergence yields the inversion formula.

Notation Guide

  • \(\hat{f}(n)\) or \(\hat{f}(\xi)\) — Fourier coefficient/transform
  • \(e^{ix} = \cos x + i\sin x\) — Complex exponential
  • \(L^1(\mathbb{R})\) — Integrable functions
  • \(L^2(\mathbb{R})\) — Square-integrable functions
  • \(f * g\) — Convolution
  • \(\mathcal{F}\) — Fourier transform operator
  • \(\mathcal{F}^{-1}\) — Inverse Fourier transform

import numpy as np
import matplotlib.pyplot as plt
from numpy.fft import fft, ifft, fftshift, ifftshift, fftfreq

class FourierAnalyzer:
    """
    Fourier analysis tools for signal processing.
    """
    def __init__(self, sample_rate):
        self.sample_rate = sample_rate
        self.dt = 1.0 / sample_rate
    
    def dft(self, signal):
        """
        Discrete Fourier Transform (naive implementation).
        For production, use numpy.fft.fft instead.
        """
        N = len(signal)
        n = np.arange(N)
        k = n.reshape((N, 1))
        M = np.exp(-2j * np.pi * k * n / N)
        return np.dot(M, signal)
    
    def analyze_signal(self, signal, duration):
        """
        Perform complete Fourier analysis of a signal.
        """
        N = len(signal)
        t = np.linspace(0, duration, N, endpoint=False)
        
        # Compute FFT using NumPy's optimized implementation
        fft_result = fft(signal)
        frequencies = fftfreq(N, self.dt)
        
        # Shift for visualization
        fft_shifted = fftshift(fft_result)
        freq_shifted = fftshift(frequencies)
        
        # Power spectrum
        power = np.abs(fft_shifted)**2
        
        return {
            'time': t,
            'signal': signal,
            'frequencies': freq_shifted,
            'fft': fft_shifted,
            'power': power,
            'magnitude': np.abs(fft_shifted),
            'phase': np.angle(fft_shifted)
        }
    
    def reconstruct(self, fft_result):
        """Reconstruct signal from FFT (inverse transform)."""
        return np.real(ifft(fft_result))
    
    def convolution_theorem_demo(self, f, g):
        """
        Demonstrate the convolution theorem:
        F(f * g) = F(f) · F(g)
        """
        # Direct convolution
        conv_direct = np.convolve(f, g, mode='same')
        
        # Via FFT (circular convolution)
        F_f = fft(f)
        F_g = fft(g)
        conv_fft = ifft(F_f * F_g)
        
        return conv_direct, conv_fft

Differential Algebra: Algebraic Study of Differential Equations

differential-algebra

Motivation

Differential algebra studies algebraic structures equipped with differentiation operations. Founded by Joseph Ritt in the 1930s and developed by Ellis Kolchin, it provides an algebraic framework for understanding differential equations analogous to how algebraic geometry studies polynomial equations. Key applications include determining when differential equations have closed-form solutions, symbolic integration algorithms, and the study of differential Galois theory.

Definitions

  • Differential Ring: A ring \(R\) with a derivation \(\delta: R \to R\) satisfying \(\delta(a+b) = \delta(a) + \delta(b)\) and \(\delta(ab) = a\delta(b) + \delta(a)b\) (Leibniz rule).
  • Differential Ideal: An ideal \(I\) of a differential ring such that \(\delta(I) \subseteq I\).
  • Differential Field: A field that is a differential ring. Examples include \(\mathbb{C}(t)\) with \(\delta = d/dt\).
  • Differentially Closed Field: A differential field where every system of differential polynomial equations with a solution in some extension has a solution in the field itself.
  • Ritt's Characteristic Set: An algorithmic method for decomposing differential algebraic varieties into irreducible components.

Theorem: Ritt's Nullstellensatz for Differential Fields

Theorem: Let \(K\) be a differential field of characteristic zero and \(I\) a radical differential ideal in \(K\{y_1, \ldots, y_n\}\) (the differential polynomial ring). Then: \[I = \bigcap_{P \supseteq I} P\] where the intersection is over all prime differential ideals containing \(I\). Equivalently, if \(f\) vanishes on all solutions of \(I\), then some power of \(f\) belongs to \(I\).

Proof Sketch

The proof uses the theory of characteristic sets. For a differential polynomial \(f\), one constructs a characteristic set for the ideal \(I\). Using pseudo-division with respect to this characteristic set, one shows that if \(f\) vanishes on all solutions, then \(f\) must be in the radical of \(I\). The key technical tool is Ritt's reduction algorithm, which extends polynomial division to the differential setting.

Notation Guide

  • \(\delta\) or \('\) — Derivation operator
  • \(K\{y\}\) — Differential polynomial ring in \(y\) over \(K\)
  • \(y^{(n)}\) — nth derivative of \(y\)
  • \([S]\) — Differential ideal generated by set \(S\)
  • \(\{S\}\) — Radical differential ideal
  • \(\text{rank}(f)\) — Rank of differential polynomial (for ordering)
  • \(\text{sat}(A)\) — Saturated ideal of characteristic set \(A\)

from sympy import *

class DifferentialAlgebra:
    """
    Tools for differential algebra computations.
    Uses SymPy for symbolic differentiation.
    """
    def __init__(self, variables, derivation_variable):
        """
        Initialize with list of dependent variables and derivation variable.
        """
        self.vars = variables
        self.t = derivation_variable
        self.derivatives = {}
        
    def diff_poly(self, poly, var=None):
        """
        Compute derivative of a differential polynomial.
        If var is None, differentiate with respect to the derivation variable.
        """
        if var is None:
            return diff(poly, self.t)
        return diff(poly, var)
    
    def differential_ideal_membership(self, poly, generators, max_order=3):
        """
        Check if polynomial is in the differential ideal generated by 'generators'.
        This is a simplified version - full algorithm uses characteristic sets.
        """
        # Extend generators with their derivatives
        extended = list(generators)
        for _ in range(max_order):
            new_derivs = [self.diff_poly(g) for g in extended[-len(generators):]]
            extended.extend(new_derivs)
        
        # Check if poly is in the algebraic ideal (simplified)
        # In practice, use Groebner bases or characteristic sets
        for g in extended:
            if simplify(poly / g).is_number:
                return True
        return False
    
    def separant(self, poly, y):
        """
        The separant of a differential polynomial is the partial derivative
        with respect to the highest derivative of y appearing in poly.
        """
        # Find highest derivative of y in poly
        highest = None
        for order in range(10, -1, -1):
            deriv = y.diff(self.t, order)
            if poly.has(deriv):
                highest = deriv
                break
        
        if highest is None:
            return 0
        return diff(poly, highest)
    
    def initial(self, poly, y):
        """
        The initial is the leading coefficient when poly is viewed
        as a polynomial in the highest derivative of y.
        """
        highest = None
        for order in range(10, -1, -1):
            deriv = y.diff(self.t, order)
            if poly.has(deriv):
                highest = deriv
                break
        
        if highest is None:
            return poly
        
        # Get coefficient of highest power
        poly_expanded = expand(poly)
        return poly_expanded.coeff(highest, degree(poly_expanded, highest))

Computational Geometry: Convex Hulls and Voronoi Diagrams

computational-geometry

Motivation

Computational geometry studies algorithms for geometric problems, with applications in computer graphics, robotics, geographic information systems, and machine learning. Two fundamental structures—the convex hull and the Voronoi diagram—appear throughout these applications. The convex hull captures the "shape" of a point set, while Voronoi diagrams partition space based on proximity to input points.

Definitions

  • Convex Hull: The smallest convex set containing a given set of points \(P\). Denoted \(\text{conv}(P)\).
  • Voronoi Cell: For a site \(p_i\) in a set \(P = \{p_1, \ldots, p_n\}\): \[V(p_i) = \{x \in \mathbb{R}^d : \|x - p_i\| \leq \|x - p_j\| \text{ for all } j\}\]
  • Delaunay Triangulation: The dual graph of the Voronoi diagram. Two sites are connected if their Voronoi cells share a face.
  • Empty Circle Property: A triangulation is Delaunay if and only if the circumcircle of each triangle contains no other sites in its interior.

Theorem: Delaunay Triangulation Optimality

Theorem: Among all triangulations of a planar point set, the Delaunay triangulation:

  1. Maximizes the minimum angle (avoids skinny triangles)
  2. Minimizes the maximum circumradius
  3. Minimizes the integral of the gradient squared of any piecewise-linear interpolant

Proof Sketch

For the angle optimality: Consider two triangles forming a convex quadrilateral. If the diagonal is not Delaunay (violates empty circle), flipping it increases the minimum of the six angles in the quadrilateral. Since there are finitely many triangulations and each flip strictly improves the angle vector (in lexicographic order), the Delaunay triangulation is the unique global optimum.

Notation Guide

  • \(\text{conv}(P)\) — Convex hull of point set \(P\)
  • \(V(p_i)\) — Voronoi cell of site \(p_i\)
  • \(\partial V(p_i)\) — Boundary of Voronoi cell
  • \(DT(P)\) — Delaunay triangulation of \(P\)
  • \(O(n \log n)\) — Time complexity of optimal algorithms
  • \(h\) — Number of points on convex hull

import numpy as np
from scipy.spatial import ConvexHull, Voronoi, Delaunay
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon
from matplotlib.collections import PatchCollection

class ComputationalGeometry:
    """
    Computational geometry algorithms and visualizations.
    """
    def __init__(self, points):
        """
        Initialize with a set of points.
        points: array of shape (n, 2) for 2D points
        """
        self.points = np.array(points)
        self.n = len(points)
    
    def convex_hull_graham_scan(self):
        """
        Compute convex hull using Graham scan algorithm.
        Returns indices of hull vertices in counterclockwise order.
        """
        # Find lowest point (and leftmost if tie)
        start_idx = np.lexsort((self.points[:, 0], self.points[:, 1]))[0]
        start = self.points[start_idx]
        
        # Sort by polar angle with respect to start
        def polar_angle(p):
            return np.arctan2(p[1] - start[1], p[0] - start[0])
        
        sorted_indices = sorted(
            [i for i in range(self.n) if i != start_idx],
            key=lambda i: (polar_angle(self.points[i]), 
                          np.linalg.norm(self.points[i] - start))
        )
        
        # Graham scan
        hull = [start_idx]
        for idx in sorted_indices:
            while len(hull) >= 2:
                p1 = self.points[hull[-2]]
                p2 = self.points[hull[-1]]
                p3 = self.points[idx]
                # Cross product
                cross = (p2[0] - p1[0]) * (p3[1] - p1[1]) - (p2[1] - p1[1]) * (p3[0] - p1[0])
                if cross <= 0:  # Non-left turn, pop
                    hull.pop()
                else:
                    break
            hull.append(idx)
        
        return hull
    
    def voronoi_diagram(self):
        """Compute Voronoi diagram using scipy."""
        return Voronoi(self.points)
    
    def delaunay_triangulation(self):
        """Compute Delaunay triangulation using scipy."""
        return Delaunay(self.points)
    
    def in_convex_hull(self, query_point):
        """
        Check if query point is inside convex hull using linear programming.
        """
        hull = ConvexHull(self.points)
        # Point is inside if it's on the same side of all hull facets
        equations = hull.equations
        return all(np.dot(eq[:2], query_point) + eq[2] <= 1e-10 
                  for eq in equations)
    
    def closest_site(self, query_point):
        """Find closest site to query point (brute force)."""
        distances = np.linalg.norm(self.points - query_point, axis=1)
        return np.argmin(distances), np.min(distances)

Stochastic Differential Equations: Modeling Randomness

stochastic-differential-equations

Motivation

Stochastic differential equations (SDEs) extend ordinary differential equations by incorporating random noise, typically modeled as Brownian motion. They are essential for modeling systems with inherent uncertainty: financial markets, biological populations, physical systems with thermal fluctuations, and neural activity. The Itô calculus developed for SDEs has become fundamental to mathematical finance and stochastic control.

Definitions

  • Wiener Process (Brownian Motion): A stochastic process \(W_t\) with \(W_0 = 0\), continuous paths, independent increments, and \(W_t - W_s \sim \mathcal{N}(0, t-s)\).
  • Itô SDE: \(dX_t = \mu(X_t, t)dt + \sigma(X_t, t)dW_t\), interpreted as: \[X_t = X_0 + \int_0^t \mu(X_s, s)ds + \int_0^t \sigma(X_s, s)dW_s\]
  • Itô Integral: For adapted process \(H_t\): \(\int_0^t H_s dW_s = \lim \sum H_{t_i}(W_{t_{i+1}} - W_{t_i})\)
  • Quadratic Variation: \(\langle W \rangle_t = t\), leading to the rule \((dW_t)^2 = dt\).

Theorem: Itô's Lemma

Theorem: Let \(X_t\) satisfy \(dX_t = \mu_t dt + \sigma_t dW_t\) and let \(f \in C^{2,1}(\mathbb{R} \times [0, T])\). Then: \[df(X_t, t) = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial x}dX_t + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(dX_t)^2\] Or equivalently: \[df = \left(\frac{\partial f}{\partial t} + \mu\frac{\partial f}{\partial x} + \frac{\sigma^2}{2}\frac{\partial^2 f}{\partial x^2}\right)dt + \sigma\frac{\partial f}{\partial x}dW_t\]

Proof Sketch

Apply Taylor expansion to \(f(X_{t+\Delta t}, t+\Delta t) - f(X_t, t)\): \[\Delta f = f_t \Delta t + f_x \Delta X + \frac{1}{2}f_{xx}(\Delta X)^2 + \cdots\] Substitute \(\Delta X = \mu \Delta t + \sigma \Delta W\) and use \((\Delta W)^2 \approx \Delta t\) (quadratic variation). Higher order terms vanish as \(\Delta t \to 0\).

Notation Guide

  • \(W_t\) — Wiener process (Brownian motion)
  • \(dW_t\) — Infinitesimal Brownian increment
  • \(\mu\) — Drift coefficient
  • \(\sigma\) — Diffusion/volatility coefficient
  • \(\mathcal{F}_t\) — Filtration (information available at time \(t\))
  • \(\mathbb{E}[\cdot|\mathcal{F}_t]\) — Conditional expectation
  • \(\langle X \rangle_t\) — Quadratic variation process

import numpy as np
import matplotlib.pyplot as plt

class StochasticCalculus:
    """
    Stochastic differential equations and Itô calculus.
    """
    def __init__(self, seed=None):
        if seed is not None:
            np.random.seed(seed)
    
    def brownian_motion(self, T, N, n_paths=1):
        """
        Generate Brownian motion paths.
        T: final time
        N: number of time steps
        n_paths: number of independent paths
        """
        dt = T / N
        dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
        W = np.zeros((n_paths, N + 1))
        W[:, 1:] = np.cumsum(dW, axis=1)
        t = np.linspace(0, T, N + 1)
        return t, W
    
    def geometric_brownian_motion(self, S0, mu, sigma, T, N, n_paths=1):
        """
        Simulate Geometric Brownian Motion: dS = mu*S*dt + sigma*S*dW
        Solution: S_t = S_0 * exp((mu - sigma^2/2)*t + sigma*W_t)
        """
        t, W = self.brownian_motion(T, N, n_paths)
        drift = (mu - 0.5 * sigma**2) * t
        diffusion = sigma * W
        S = S0 * np.exp(drift + diffusion)
        return t, S
    
    def ornstein_uhlenbeck(self, X0, theta, mu, sigma, T, N, n_paths=1):
        """
        Simulate Ornstein-Uhlenbeck process: dX = theta*(mu - X)*dt + sigma*dW
        Mean-reverting process used in interest rate modeling.
        """
        dt = T / N
        X = np.zeros((n_paths, N + 1))
        X[:, 0] = X0
        
        for i in range(N):
            dW = np.random.normal(0, np.sqrt(dt), size=n_paths)
            X[:, i+1] = X[:, i] + theta * (mu - X[:, i]) * dt + sigma * dW
        
        t = np.linspace(0, T, N + 1)
        return t, X
    
    def euler_maruyama(self, mu_func, sigma_func, X0, T, N, n_paths=1):
        """
        General Euler-Maruyama method for SDEs.
        mu_func: drift function mu(X, t)
        sigma_func: diffusion function sigma(X, t)
        """
        dt = T / N
        X = np.zeros((n_paths, N + 1))
        X[:, 0] = X0
        t = np.linspace(0, T, N + 1)
        
        for i in range(N):
            dW = np.random.normal(0, np.sqrt(dt), size=n_paths)
            X[:, i+1] = (X[:, i] + mu_func(X[:, i], t[i]) * dt + 
                        sigma_func(X[:, i], t[i]) * dW)
        
        return t, X
    
    def ito_integral(self, integrand_func, T, N, n_paths=1):
        """
        Compute Itô integral: int_0^T integrand_func(W_t, t) dW_t
        """
        dt = T / N
        t = np.linspace(0, T, N + 1)
        _, W = self.brownian_motion(T, N, n_paths)
        
        integral = np.zeros(n_paths)
        for i in range(N):
            # Itô integral uses left endpoint (non-anticipating)
            H = integrand_func(W[:, i], t[i])
            dW = W[:, i+1] - W[:, i]
            integral += H * dW
        
        return integral

Quantum Information Theory: Entanglement and Communication

quantum-information-theory

Motivation

Quantum information theory extends classical information theory to quantum systems, revealing fundamental limits on information processing imposed by quantum mechanics. Key phenomena like superposition, entanglement, and the no-cloning theorem lead to capabilities impossible classically: quantum key distribution, quantum teleportation, and potentially quantum computing. The field bridges physics, computer science, and mathematics.

Definitions

  • Qubit: A two-level quantum system with state \(|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\) where \(|\alpha|^2 + |\beta|^2 = 1\).
  • Density Matrix: \(\rho = \sum_i p_i |\psi_i\rangle\langle\psi_i|\), representing mixed states.
  • Von Neumann Entropy: \(S(\rho) = -\text{Tr}(\rho \log \rho) = -\sum_i \lambda_i \log \lambda_i\) where \(\lambda_i\) are eigenvalues.
  • Entanglement: A bipartite state \(|\psi\rangle_{AB}\) is entangled if it cannot be written as \(|\phi\rangle_A \otimes |\chi\rangle_B\).
  • Quantum Channel: A completely positive trace-preserving (CPTP) map \(\mathcal{E}: \mathcal{L}(\mathcal{H}_A) \to \mathcal{L}(\mathcal{H}_B)\).

Theorem: Quantum Data Compression (Schumacher Compression)

Theorem: Consider a quantum source emitting states \(|\psi_i\rangle\) with probabilities \(p_i\), described by density matrix \(\rho = \sum_i p_i |\psi_i\rangle\langle\psi_i|\). For any \(\epsilon, \delta > 0\) and sufficiently large \(n\):

  1. There exists a compression scheme encoding \(n\) copies into \(n(S(\rho) + \delta)\) qubits with fidelity \(> 1 - \epsilon\)
  2. No scheme using fewer than \(n(S(\rho) - \delta)\) qubits can achieve fidelity approaching 1

The von Neumann entropy \(S(\rho)\) is the fundamental compression limit.

Proof Sketch

The proof uses the typical subspace theorem. For \(\rho^{\otimes n}\), most probability mass concentrates on the "typical subspace" of dimension \(\approx 2^{nS(\rho)}\). Projecting onto this subspace preserves fidelity while achieving compression. The converse follows from the monotonicity of quantum relative entropy under CPTP maps.

Notation Guide

  • \(|\psi\rangle\) — Quantum state (ket)
  • \(\langle\psi|\) — Dual vector (bra)
  • \(\langle\phi|\psi\rangle\) — Inner product (bracket)
  • \(|\psi\rangle\langle\phi|\) — Outer product
  • \(\rho\) — Density matrix
  • \(S(\rho)\) — Von Neumann entropy
  • \(I(A:B)\) — Quantum mutual information
  • \(\mathcal{H}\) — Hilbert space
  • \(\text{Tr}\) — Trace

Algebraic Graph Theory: Spectra and Structure

algebraic-graph-theory

Historical Context

Algebraic graph theory emerged in the mid-20th century as mathematicians recognized that linear algebra provides powerful tools for understanding graph structure. The field was pioneered by chemists (Hückel, 1930s) studying molecular orbitals and developed by mathematicians like Hoffman, Cvetković, and Godsil. The eigenvalues of graph matrices reveal structural properties invisible to combinatorial methods alone.

Definitions

  • Adjacency Matrix \(A\): \(A_{ij} = 1\) if vertices \(i\) and \(j\) are adjacent, 0 otherwise.
  • Degree Matrix \(D\): Diagonal matrix with \(D_{ii} = \deg(v_i)\).
  • Laplacian \(L\): \(L = D - A\).
  • Normalized Laplacian: \(\mathcal{L} = D^{-1/2}LD^{-1/2}\).
  • Graph Spectrum: The multiset of eigenvalues of \(A\) or \(L\).
  • Cheeger Constant: \(h(G) = \min_{S \subseteq V, |S| \leq |V|/2} \frac{|\partial S|}{|S|}\).

Theorem: Cheeger Inequality

Theorem: Let \(G\) be a connected graph with normalized Laplacian eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\). Then: \[\frac{\lambda_2}{2} \leq h(G) \leq \sqrt{2\lambda_2}\] where \(h(G)\) is the Cheeger constant (isoperimetric number).

Proof Sketch

The lower bound follows from the variational characterization of \(\lambda_2\) via the Rayleigh quotient. For any set \(S\), the indicator function gives a test vector with Rayleigh quotient related to \(h(G)\). The upper bound uses a sweep cut: order vertices by the second eigenvector and find the best cut among prefixes. The conductance of this cut is bounded using Cauchy-Schwarz.

Notation Guide

  • \(G = (V, E)\) — Graph with vertex and edge sets
  • \(n = |V|\) — Number of vertices
  • \(m = |E|\) — Number of edges
  • \(A, L, \mathcal{L}\) — Adjacency, Laplacian, normalized Laplacian
  • \(\lambda_i\) — Eigenvalues (ordered)
  • \(\partial S\) — Edge boundary of set \(S\)
  • \(\text{vol}(S) = \sum_{v \in S} \deg(v)\) — Volume of vertex set

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import eigsh
import networkx as nx

class AlgebraicGraphTheory:
    """
    Algebraic graph theory: spectra and spectral clustering.
    """
    def __init__(self, adjacency_matrix):
        self.A = np.array(adjacency_matrix, dtype=float)
        self.n = self.A.shape[0]
        self.degrees = np.sum(self.A, axis=1)
        self.D = np.diag(self.degrees)
        self.L = self.D - self.A  # Unnormalized Laplacian
        
        # Normalized Laplacian
        D_inv_sqrt = np.diag(1.0 / np.sqrt(self.degrees + 1e-10))
        self.L_norm = D_inv_sqrt @ self.L @ D_inv_sqrt
    
    def spectrum(self, k=None, normalized=True):
        """
        Compute eigenvalues of Laplacian.
        k: number of eigenvalues (None for all)
        normalized: use normalized Laplacian
        """
        L = self.L_norm if normalized else self.L
        if k is None or k >= self.n:
            return np.linalg.eigvalsh(L)
        else:
            return eigsh(csr_matrix(L), k=k, which='SM', return_eigenvectors=False)
    
    def fiedler_vector(self):
        """
        Compute Fiedler vector (eigenvector for λ_2 of L).
        Used for spectral clustering and graph partitioning.
        """
        eigenvalues, eigenvectors = np.linalg.eigh(self.L)
        # Second smallest eigenvalue (index 1, since 0 is smallest)
        return eigenvalues[1], eigenvectors[:, 1]
    
    def spectral_clustering(self, k):
        """
        Perform spectral clustering into k clusters.
        """
        # Compute first k eigenvectors of normalized Laplacian
        eigenvalues, eigenvectors = np.linalg.eigh(self.L_norm)
        # Use eigenvectors 1 to k (skip 0 which is constant)
        embedding = eigenvectors[:, 1:k+1]
        
        # Normalize rows (for normalized cut)
        row_norms = np.linalg.norm(embedding, axis=1, keepdims=True)
        embedding = embedding / (row_norms + 1e-10)
        
        # K-means on the embedding
        from scipy.cluster.vq import kmeans2
        centroids, labels = kmeans2(embedding, k, minit='points')
        return labels
    
    def cheeger_constant(self):
        """
        Compute Cheeger constant (isoperimetric number).
        Exact computation is NP-hard; this is a greedy approximation.
        """
        n = self.n
        min_conductance = float('inf')
        
        # Try all subsets up to half size (exponential, so only for small graphs)
        if n > 20:
            print("Warning: Graph too large for exact Cheeger computation")
            return None
        
        from itertools import combinations
        for size in range(1, n // 2 + 1):
            for subset in combinations(range(n), size):
                S = set(subset)
                boundary = 0
                vol_S = sum(self.degrees[i] for i in S)
                for i in S:
                    for j in range(n):
                        if j not in S and self.A[i, j] > 0:
                            boundary += self.A[i, j]
                
                conductance = boundary / min(vol_S, sum(self.degrees) - vol_S)
                min_conductance = min(min_conductance, conductance)
        
        return min_conductance
    
    def effective_resistance(self, i, j):
        """
        Compute effective resistance between vertices i and j.
        R_eff(i,j) = (e_i - e_j)^T L^+ (e_i - e_j)
        where L^+ is the Moore-Penrose pseudoinverse.
        """
        L_pinv = np.linalg.pinv(self.L)
        e_i = np.zeros(self.n)
        e_i[i] = 1
        e_j = np.zeros(self.n)
        e_j[j] = 1
        return (e_i - e_j) @ L_pinv @ (e_i - e_j)

Riemannian Optimization: Optimization on Manifolds

riemannian-optimization

Historical Context

Riemannian optimization extends classical optimization to problems where the feasible set is a smooth manifold rather than Euclidean space. The field draws from differential geometry (Riemann, 1854; Cartan, 1920s) and optimization theory. Modern applications in machine learning—low-rank matrix completion, principal component analysis, and deep learning on manifolds—have driven renewed interest in the 21st century.

Definitions

  • Riemannian Manifold \((\mathcal{M}, g)\): A smooth manifold with a Riemannian metric \(g\) assigning an inner product to each tangent space.
  • Tangent Space \(T_x\mathcal{M}\): The vector space of tangent vectors at point \(x \in \mathcal{M}\).
  • Gradient: The unique vector \(\text{grad} f(x) \in T_x\mathcal{M}\) satisfying \(Df(x)[v] = \langle \text{grad} f(x), v \rangle_x\) for all \(v\).
  • Exponential Map: \(\text{Exp}_x(v)\) gives the endpoint of the geodesic starting at \(x\) with velocity \(v\).
  • Retraction: A first-order approximation to the exponential map, computationally cheaper.

Theorem: Convergence of Riemannian Gradient Descent

Theorem: Let \(f: \mathcal{M} \to \mathbb{R}\) be a geodesically convex function on a complete Riemannian manifold with sectional curvature bounded below by \(\kappa\). Assume \(f\) is \(L\)-smooth (gradient Lipschitz). Then Riemannian gradient descent with step size \(\eta \leq 1/L\) satisfies: \[f(x_k) - f^* \leq \frac{2L \cdot d(x_0, x^*)^2}{k}\] where \(d\) is the Riemannian distance.

Proof Sketch

The proof extends the Euclidean analysis using comparison theorems from Riemannian geometry. The key inequality relates the function decrease to the gradient norm: \[f(x_{k+1}) \leq f(x_k) - \frac{1}{2L}\|\text{grad} f(x_k)\|^2\] Geodesic convexity ensures that the distance to the optimum contracts appropriately, yielding the \(O(1/k)\) rate.

import numpy as np
from scipy.linalg import expm, logm, sqrtm

class RiemannianOptimization:
    """
    Riemannian optimization on matrix manifolds.
    Focus: Stiefel manifold (orthonormal frames).
    """
    def __init__(self, n, p):
        """
        Stiefel manifold St(n,p) = {X in R^{n×p} : X^T X = I_p}.
        """
        self.n = n
        self.p = p
    
    def project_to_stiefel(self, X):
        """
        Project matrix onto Stiefel manifold via QR decomposition.
        """
        Q, R = np.linalg.qr(X)
        # Ensure positive diagonal for uniqueness
        signs = np.sign(np.diag(R))
        signs[signs == 0] = 1
        return Q @ np.diag(signs)
    
    def tangent_space_projection(self, X, Z):
        """
        Project Z onto tangent space at X.
        T_X St(n,p) = {Z : X^T Z + Z^T X = 0} (skew-symmetric condition)
        """
        # Formula: P_X(Z) = Z - X * sym(X^T Z)
        sym = 0.5 * (X.T @ Z + Z.T @ X)
        return Z - X @ sym
    
    def retraction_qr(self, X, V):
        """
        QR retraction: R_X(V) = qf(X + V)
        where qf extracts the Q factor of QR decomposition.
        """
        return self.project_to_stiefel(X + V)
    
    def retraction_polar(self, X, V):
        """
        Polar retraction: R_X(V) = (X + V)(I + V^T V)^{-1/2}
        """
        Y = X + V
        return Y @ sqrtm(np.linalg.inv(Y.T @ Y))
    
    def riemannian_gradient(self, X, euclidean_gradient):
        """
        Convert Euclidean gradient to Riemannian gradient.
        grad f(X) = P_X(eucl_grad)
        """
        return self.tangent_space_projection(X, euclidean_gradient)
    
    def gradient_descent(self, f, grad_f, X0, step_size=0.01, max_iter=1000, tol=1e-6):
        """
        Riemannian gradient descent on Stiefel manifold.
        """
        X = X0.copy()
        history = [f(X)]
        
        for i in range(max_iter):
            # Compute Riemannian gradient
            eucl_grad = grad_f(X)
            riem_grad = self.riemannian_gradient(X, eucl_grad)
            
            # Check convergence
            grad_norm = np.linalg.norm(riem_grad)
            if grad_norm < tol:
                print(f"Converged at iteration {i}")
                break
            
            # Retraction step
            X = self.retraction_qr(X, -step_size * riem_grad)
            history.append(f(X))
        
        return X, history

        """

Definitions

  • Group Scheme: A scheme \(G\) over a base \(S\) with morphisms \(\mu: G \times_S G \to G\) (multiplication), \(\iota: G \to G\) (inverse), and \(e: S \to G\) (identity) satisfying group axioms.

  • Motive: A hypothetical object capturing the "essential" cohomology of algebraic varieties, proposed by Grothendieck as a universal cohomology theory.

Theorem: Cartier Duality

Theorem: Let \(G\) be a finite commutative group scheme over a field \(k\). Then the Cartier dual \(D(G) = \text{Hom}(G, \mathbb{G}_m)\) is also a finite commutative group scheme, and the natural map \(G \to D(D(G))\) is an isomorphism. This establishes a perfect duality: \[\text{FinCommGrpSch}_k^{\text{op}} \xrightarrow{\cong} \text{FinCommGrpSch}_k\]

Proof Sketch

The proof uses the structure theory of finite commutative group schemes. For étale group schemes, Cartier duality reduces to Pontryagin duality of finite groups. For connected (infinitesimal) group schemes, the duality exchanges Frobenius and Verschiebung morphisms. The general case follows from the decomposition into étale and connected components.

import numpy as np
from itertools import product

class FiniteGroupScheme:
    """
    Simplified model of finite commutative group schemes.
    Represents constant group schemes (discrete case).
    """
    def __init__(self, elements, operation_table, name="G"):
        """
        elements: list of group elements
        operation_table: dict mapping (g,h) to g*h
        """
        self.elements = elements
        self.op = operation_table
        self.name = name
        self.identity = self._find_identity()
    
    def _find_identity(self):
        for e in self.elements:
            if all(self.op[(e, g)] == g and self.op[(g, e)] == g 
                   for g in self.elements):
                return e
        return None
    
    def inverse(self, g):
        for h in self.elements:
            if self.op[(g, h)] == self.identity:
                return h
        return None
    
    def hom_to_gm(self, g):
        """
        Character of the group (homomorphism to multiplicative group).
        For cyclic groups, these are roots of unity.
        """
        # Simplified: return order of element
        order = 1
        current = g
        while current != self.identity:
            current = self.op[(current, g)]
            order += 1
        return np.exp(2j * np.pi / order)
    
    def cartier_dual(self):
        """
        Cartier dual: characters of the group.
        For finite abelian groups, dual is isomorphic to original.
        """
        # Compute character group
        characters = []
        for g in self.elements:
            chi_g = {h: self.hom_to_gm(self.op[(g, h)]) 
                    for h in self.elements}
            characters.append((g, chi_g))
        
        return characters
    
    def is_self_dual(self):
        """Check if group is isomorphic to its dual."""
        return len(self.elements) == len(self.cartier_dual())

Historical Context

John von Neumann (1903–1957) was a Hungarian-American mathematician whose contributions span quantum mechanics, functional analysis, game theory, computer science, and nuclear physics. Often called "the last of the great mathematicians," von Neumann possessed an extraordinary ability to translate between pure mathematics and practical applications. His work on operator algebras laid foundations for quantum field theory, while his design of the EDVAC established the stored-program computer architecture still used today.

Definitions

  • Factor: A von Neumann algebra with trivial center (only scalar multiples of identity). Factors are classified into types I, II, and III.
  • Minimax Theorem: For zero-sum games, \(\max_x \min_y f(x,y) = \min_y \max_x f(x,y)\) under appropriate conditions.
  • Cellular Automaton: A discrete model of computation with a grid of cells, each in a state, evolving according to local rules—von Neumann proved self-replicating machines were possible.

Theorem: Von Neumann's Minimax Theorem

Theorem: Let \(X \subseteq \mathbb{R}^n\) and \(Y \subseteq \mathbb{R}^m\) be compact convex sets, and let \(f: X \times Y \to \mathbb{R}\) be continuous and convex-concave (convex in \(x\) for fixed \(y\), concave in \(y\) for fixed \(x\)). Then: \[\max_{y \in Y} \min_{x \in X} f(x, y) = \min_{x \in X} \max_{y \in Y} f(x, y)\] This common value is called the value of the game.

Proof Sketch

The proof uses fixed-point theorems. One approach applies Brouwer's fixed-point theorem to the best-response correspondence. Alternatively, one can use the Hahn-Banach separation theorem to construct a separating hyperplane, showing that the max-min and min-max values cannot differ.

import numpy as np
from scipy.optimize import minimize, linprog
import matplotlib.pyplot as plt

class GameTheory:
    """
    Zero-sum games and minimax theorem demonstrations.
    """
    def __init__(self, payoff_matrix):
        """
        payoff_matrix: A[i,j] is payoff to row player when
        row player plays i and column player plays j.
        """
        self.A = np.array(payoff_matrix, dtype=float)
        self.m, self.n = self.A.shape
    
    def solve_row_player(self):
        """
        Solve for row player's optimal mixed strategy.
        Linear program: maximize v subject to:
        - sum_i p_i A[i,j] >= v for all j
        - sum_i p_i = 1, p_i >= 0
        """
        # Convert to standard form for linprog (minimization)
        # Variables: [p_1, ..., p_m, v]
        c = np.zeros(self.m + 1)
        c[-1] = -1  # Maximize v (minimize -v)
        
        # Constraints: A^T p >= v * 1
        A_ub = np.hstack([-self.A.T, np.ones((self.n, 1))])
        b_ub = np.zeros(self.n)
        
        # Equality: sum p_i = 1
        A_eq = np.zeros((1, self.m + 1))
        A_eq[0, :self.m] = 1
        b_eq = np.array([1])
        
        # Bounds: p_i >= 0, v unbounded
        bounds = [(0, None) for _ in range(self.m)] + [(None, None)]
        
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                        bounds=bounds, method='highs')
        
        p_opt = result.x[:self.m]
        v = result.x[-1]
        return p_opt, v
    
    def solve_column_player(self):
        """
        Solve for column player's optimal mixed strategy.
        By von Neumann's minimax theorem, this gives same value.
        """
        # Column player minimizes maximum payoff
        # Equivalent to solving row player's problem on -A^T
        game_T = GameTheory(-self.A.T)
        q_opt, v = game_T.solve_row_player()
        return q_opt, -v  # Negate because we flipped sign
    
    def verify_minimax(self):
        """Verify that max-min equals min-max."""
        _, v_row = self.solve_row_player()
        _, v_col = self.solve_column_player()
        return v_row, v_col, abs(v_row - v_col) < 1e-6
    
    def best_responses(self, row_strategy, col_strategy):
        """Compute best responses to given strategies."""
        # Row player's expected payoff against col_strategy
        row_payoffs = self.A @ col_strategy
        best_row = np.argmax(row_payoffs)
        
        # Column player minimizes row's payoff
        col_payoffs = row_strategy @ self.A
        best_col = np.argmin(col_payoffs)
        
        return best_row, best_col

📜 Math History: The Birth of Modern Algebra

The emergence of abstract algebra in the early 20th century represents one of the most profound transformations in mathematical thought. Where 19th-century algebra focused on solving equations and manipulating symbols, modern algebra studies the underlying structures—groups, rings, fields, and modules—that unify seemingly disparate mathematical phenomena.

This revolution had multiple origins. Évariste Galois's work on equation solvability, though written in the 1830s, was not fully appreciated until Joseph Liouville published it in 1846. Galois introduced the group as a tool for studying equations, showing that the solvability of a polynomial equation depends on the structure of its associated Galois group. This insight—that the structure of a mathematical object matters more than its specific representation—became a guiding principle.

In Germany, Richard Dedekind developed the theory of ideals in the 1870s, providing a foundation for algebraic number theory that transcended the particular properties of integers. Dedekind's emphasis on conceptual understanding over computational technique influenced the entire Göttingen school. David Hilbert's work on invariant theory and algebraic number theory further demonstrated the power of abstract methods.

The decisive shift came with Emmy Noether. In her 1921 paper "Idealtheorie in Ringbereichen," Noether established the general theory of ideals in commutative rings, identifying the ascending chain condition as the key property that makes factorization work. Her famous declaration "Es steht alles schon bei Dedekind" ("It's all already in Dedekind") understated her own revolutionary contribution: the recognition that specific examples should be understood as instances of general structures defined by axioms.

Noether's influence extended through her students and collaborators. Bartel van der Waerden's 1930 "Moderne Algebra" became the definitive textbook, presenting algebra as the study of structures rather than calculations. This structural view of mathematics, championed by the Bourbaki group in France, dominated 20th-century mathematics.

The impact extended far beyond algebra. Algebraic topology, developed by Poincaré and advanced by Noether's insight that Betti numbers should be understood as group invariants, became a powerful tool for studying geometric objects. Algebraic geometry was transformed by the introduction of abstract methods, culminating in Grothendieck's scheme theory. Even mathematical physics was transformed when Noether's 1918 theorem connected symmetries to conservation laws.

Today, abstract algebra underlies modern cryptography, coding theory, and computer science. The RSA cryptosystem relies on properties of finite groups; error-correcting codes use algebraic structures over finite fields; and the algorithms powering modern technology are analyzed using algebraic complexity theory. The abstract revolution that began with Galois and reached maturity with Noether continues to shape how we understand and apply mathematics.

🧩 Problem Corner

IMO Shortlist Problem

Problem: Let \(n\) be a positive integer. A sequence of integers \(a_0, a_1, \ldots, a_n\) is called good if it satisfies:

  1. \(a_0 = 0\) and \(a_n = n\)
  2. For all \(i = 1, 2, \ldots, n\): \(a_i - a_{i-1} \in \{1, 2\}\)

Determine the number of good sequences.

💡 Hint

Let \(f(n)\) be the number of good sequences ending at \(n\). Consider how many times the step of size 2 is used. If we use \(k\) steps of size 2, then we use \(n-2k\) steps of size 1, for a total of \(n-k\) steps. The number of such sequences is \(\binom{n-k}{k}\). Sum over valid \(k\).

📖 Solution

Solution: Let \(f(n)\) denote the number of good sequences ending at \(n\).

Consider the recurrence. The last step to reach \(n\) is either from \(n-1\) (step of size 1) or from \(n-2\) (step of size 2). Therefore: \[f(n) = f(n-1) + f(n-2)\]

With initial conditions \(f(0) = 1\) (empty sequence) and \(f(1) = 1\) (only sequence is 0, 1).

This is the Fibonacci recurrence! Therefore \(f(n) = F_{n+1}\) where \(F_1 = F_2 = 1\).

Alternative combinatorial proof: If a good sequence uses \(k\) steps of size 2, it uses \(n-2k\) steps of size 1, for \(n-k\) total steps. We choose which \(k\) of these \(n-k\) steps are size 2, giving \(\binom{n-k}{k}\) sequences. Summing over valid \(k\) (where \(0 \leq k \leq \lfloor n/2 \rfloor\)): \[f(n) = \sum_{k=0}^{\lfloor n/2 \rfloor} \binom{n-k}{k}\]

This sum is known to equal \(F_{n+1}\), which can be proven by induction using Pascal's identity.

Answer: The number of good sequences is \(F_{n+1}\), the \((n+1)\)-th Fibonacci number.

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set.

The visualization below demonstrates how to render the Mandelbrot set using Python:

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for point c.
    Returns the iteration count (normalized for smooth coloring).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > escape_radius:
            # Smooth coloring: interpolate between iterations
            log_zn = np.log(abs(z))
            nu = np.log(log_zn / np.log(escape_radius)) / np.log(2)
            return n + 1 - nu
        z = z*z + c
    return max_iter  # Did not escape (in set)

# Create grid of complex numbers
width, height = 800, 600
xmin, xmax = -2.5, 1.0
ymin, ymax = -1.25, 1.25

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandel = np.vectorize(mandelbrot)
M = mandel(C, max_iter=100)

# Create visualization
fig, ax = plt.subplots(figsize=(12, 9))
im = ax.imshow(M, extent=[xmin, xmax, ymin, ymax], 
               cmap='hot', origin='lower', interpolation='bilinear')
ax.set_xlabel('Re(c)')
ax.set_ylabel('Im(c)')
ax.set_title('The Mandelbrot Set')
plt.colorbar(im, label='Iterations to escape')
plt.tight_layout()
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
plt.show()

# Interesting facts about the Mandelbrot set
