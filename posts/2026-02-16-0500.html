1. Homotopy Theory: The Fundamental Group and Covering Spaces

Homotopy theory studies continuous deformations of spaces. The fundamental group \( \pi_1(X, x_0) \) captures the "holes" in a topological space.

Definition

For a topological space \( X \) with basepoint \( x_0 \), the fundamental group consists of homotopy classes of loops based at \( x_0 \):

\[ \pi_1(X, x_0) = \{[\gamma] : \gamma: [0,1] \to X, \gamma(0) = \gamma(1) = x_0\} \]

with group operation given by concatenation of paths.

Theorem: Seifert-van Kampen

Let \( X = U \cup V \) where \( U, V \) are open, path-connected sets with \( U \cap V \) path-connected and containing \( x_0 \). Then:

\[ \pi_1(X, x_0) \cong \pi_1(U, x_0) *_{\pi_1(U \cap V, x_0)} \pi_1(V, x_0) \]

This is the amalgamated free product.

Proof Sketch

Define homomorphisms \( \phi_U: \pi_1(U) \to \pi_1(X) \) and \( \phi_V: \pi_1(V) \to \pi_1(X) \) by inclusion. The universal property of pushouts gives a map from the amalgamated product. Surjectivity follows by subdividing loops into pieces in \( U \) or \( V \). Injectivity uses the homotopy lifting property.

import numpy as np
from typing import List, Tuple, Callable

class FundamentalGroupElement:
    """Represents an element of the fundamental group as a word in generators."""
    
    def __init__(self, word: List[Tuple[int, int]]):
        """
        word: list of (generator_index, exponent) pairs
        """
        self.word = self._reduce(word)
    
    def _reduce(self, word: List[Tuple[int, int]]) -> List[Tuple[int, int]]:
        """Reduce the word by canceling inverse pairs."""
        if not word:
            return []
        
        stack = []
        for gen, exp in word:
            if exp == 0:
                continue
            if stack and stack[-1][0] == gen:
                new_exp = stack[-1][1] + exp
                if new_exp == 0:
                    stack.pop()
                else:
                    stack[-1] = (gen, new_exp)
            else:
                stack.append((gen, exp))
        return stack
    
    def __mul__(self, other: 'FundamentalGroupElement') -> 'FundamentalGroupElement':
        """Group multiplication (concatenation)."""
        return FundamentalGroupElement(self.word + other.word)
    
    def inverse(self) -> 'FundamentalGroupElement':
        """Group inverse."""
        return FundamentalGroupElement([(g, -e) for g, e in reversed(self.word)])
    
    def __repr__(self):
        if not self.word:
            return "e (identity)"
        terms = []
        for g, e in self.word:
            if e == 1:
                terms.append(f"a{g}")
            elif e == -1:
                terms.append(f"a{g}^(-1)")
            else:
                terms.append(f"a{g}^{e}")
        return " ".join(terms)

2. K-Theory: Topological and Algebraic Invariants

K-theory assigns algebraic invariants (abelian groups) to topological spaces or rings. It was developed by Grothendieck in algebraic geometry and Atiyah-Hirzebruch in topology.

Definition: The Grothendieck Group

Given an abelian monoid \( (M, +) \), the Grothendieck group \( K(M) \) is the universal abelian group receiving a homomorphism from \( M \). Explicitly:

\[ K(M) = M \times M / \sim \]

where \( (m_1, n_1) \sim (m_2, n_2) \) iff there exists \( p \in M \) such that \( m_1 + n_2 + p = m_2 + n_1 + p \).

Theorem: Bott Periodicity

For the topological K-theory of a compact Hausdorff space \( X \):

\[ \tilde{K}^{-n}(X) \cong \tilde{K}^{-n-2}(X) \]

Equivalently, \( \tilde{K}(S^2 \wedge X) \cong \tilde{K}(X) \).

Proof Sketch

The proof uses the clutching construction for vector bundles over \( S^2 \times X \). The key insight is that vector bundles over \( S^2 \) are classified by their clutching function \( S^1 \to GL_n(\mathbb{C}) \), and \( \pi_1(GL_n(\mathbb{C})) \cong \mathbb{Z} \) stabilizes for large \( n \).

3. Random Matrix Theory: Wigner's Semicircle Law

Random matrix theory studies the statistical properties of matrices with random entries. It has applications in quantum physics, number theory, and machine learning.

Definition: Wigner Matrix

A Wigner matrix \( W_n \) is an \( n \times n \) Hermitian random matrix with:

  • Upper triangular entries: i.i.d. with mean 0, variance \( \sigma^2/n \)
  • Diagonal entries: i.i.d. with mean 0, variance \( 2\sigma^2/n \)
  • Lower triangular: determined by Hermiticity

Theorem: Wigner's Semicircle Law

As \( n \to \infty \), the empirical spectral distribution of \( W_n \) converges to:

\[ \mu_{sc}(dx) = \frac{1}{2\pi\sigma^2} \sqrt{4\sigma^2 - x^2} \, \mathbf{1}_{|x| \leq 2\sigma} \, dx \]

Proof Sketch (Moment Method)

The \( k \)-th moment of the semicircle distribution counts Catalan numbers:

\[ m_{2k} = \frac{1}{2k+1} \binom{2k}{k} \sigma^{2k}, \quad m_{2k+1} = 0 \]

These count the number of non-crossing pairings of \( 2k \) elements, which correspond to valid walks on the matrix structure.

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from typing import Tuple, List
from scipy import stats

def generate_wigner_matrix(n: int, sigma: float = 1.0) -> np.ndarray:
    """
    Generate a random Wigner matrix (Gaussian Unitary Ensemble).
    
    Args:
        n: Matrix size
        sigma: Standard deviation parameter
    
    Returns:
        n×n Hermitian random matrix
    """
    # Upper triangular part (excluding diagonal)
    upper = np.random.normal(0, sigma/np.sqrt(2*n), (n, n))
    
    # Make it symmetric/Hermitian
    W = upper + upper.T
    
    # Diagonal entries have variance σ²/n
    np.fill_diagonal(W, np.random.normal(0, sigma/np.sqrt(n), n))
    
    return W


def semicircle_pdf(x: np.ndarray, sigma: float = 1.0) -> np.ndarray:
    """
    The semicircle probability density function.
    
    ρ(x) = (1/(2πσ²)) * √(4σ² - x²) for |x| ≤ 2σ
    """
    R = 2 * sigma
    pdf = np.zeros_like(x)
    mask = np.abs(x) <= R
    pdf[mask] = (1 / (2 * np.pi * sigma**2)) * np.sqrt(R**2 - x[mask]**2)
    return pdf


def compute_eigenvalue_distribution(n: int, num_samples: int = 100, sigma: float = 1.0) -> np.ndarray:
    """
    Compute eigenvalues of multiple Wigner matrices.
    
    Args:
        n: Matrix size
        num_samples: Number of matrices to generate
        sigma: Standard deviation parameter
    
    Returns:
        Array of all eigenvalues
    """
    all_eigenvalues = []
    
    for _ in range(num_samples):
        W = generate_wigner_matrix(n, sigma)
        eigenvalues = np.linalg.eigvalsh(W)  # For Hermitian matrices
        all_eigenvalues.extend(eigenvalues)
    
    return np.array(all_eigenvalues)


def catalan_number(n: int) -> int:
    """
    Compute the n-th Catalan number: C_n = (1/(n+1)) * binom(2n, n)
    These count the moments of the semicircle distribution.
    """
    from math import comb
    return comb(2*n, n) // (n + 1)

1. Stochastic Calculus: Itô's Lemma

Stochastic calculus extends calculus to stochastic processes, particularly Brownian motion. It's essential for mathematical finance and physics.

Definition: Itô Process

An Itô process \( X_t \) satisfies:

\[ dX_t = \mu(X_t, t) \, dt + \sigma(X_t, t) \, dW_t \]

where \( W_t \) is standard Brownian motion, \( \mu \) is the drift, and \( \(sigma \) is the diffusion coefficient.

Theorem: Itô's Lemma

For a twice continuously differentiable function \( f(t, x) \):

\[ df(t, X_t) = \frac{\partial f}{\partial t} dt + \frac{\partial f}{\partial x} dX_t + \frac{1}{2} \frac{\partial^2 f}{\partial x^2} (dX_t)^2 \]

where \( (dW_t)^2 = dt \) (in the mean-square sense).

Proof Sketch

Taylor expand \( f(t + dt, X_{t+dt}) \) and use the quadratic variation of Brownian motion:

\[ \langle W \rangle_t = t \implies (dW_t)^2 = dt \]

The key insight is that Brownian motion has non-zero quadratic variation, unlike smooth functions.

Python Implementation

import numpy as np
from typing import Callable, Tuple
import matplotlib.pyplot as plt

class BrownianMotion:
    """Standard Brownian motion (Wiener process)."""
    
    def __init__(self, T: float = 1.0, N: int = 1000, seed: int = None):
        """
        Args:
            T: Time horizon
            N: Number of time steps
            seed: Random seed
        """
        if seed is not None:
            np.random.seed(seed)
        
        self.T = T
        self.N = N
        self.dt = T / N
        self.t = np.linspace(0, T, N + 1)
        
        # Generate Brownian motion: dW ~ N(0, dt)
        dW = np.random.normal(0, np.sqrt(self.dt), N)
        self.W = np.concatenate([[0], np.cumsum(dW)])
    
    def quadratic_variation(self) -> float:
        """Compute quadratic variation Σ(dW)²."""
        dW = np.diff(self.W)
        return np.sum(dW**2)


class ItoProcess:
    """General Itô process: dX = μ(X,t)dt + σ(X,t)dW"""
    
    def __init__(self, mu: Callable, sigma: Callable, X0: float = 0.0):
        """
        Args:
            mu: Drift function μ(X, t)
            sigma: Diffusion function σ(X, t)
            X0: Initial value
        """
        self.mu = mu
        self.sigma = sigma
        self.X0 = X0
    
    def simulate(self, T: float = 1.0, N: int = 1000, seed: int = None) -> Tuple[np.ndarray, np.ndarray]:
        """
        Simulate using Euler-Maruyama method.
        
        Returns:
            t: Time points
            X: Process values
        """
        if seed is not None:
            np.random.seed(seed)
        
        dt = T / N
        t = np.linspace(0, T, N + 1)
        
        X = np.zeros(N + 1)
        X[0] = self.X0
        
        for i in range(N):
            dW = np.random.normal(0, np.sqrt(dt))
            X[i+1] = X[i] + self.mu(X[i], t[i]) * dt + self.sigma(X[i], t[i]) * dW
        
        return t, X

def ito_lemma_verification():

2. Fluid Dynamics: The Navier-Stokes Equations

The Navier-Stokes equations describe the motion of viscous fluids. They are one of the Millennium Prize Problems — a correct solution to the existence and smoothness problem carries a $1 million prize.

The Equations

For an incompressible fluid with velocity field \( \mathbf{u}(\mathbf{x}, t) \) and pressure \( p(\mathbf{x}, t) \):

\[ \frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla) \mathbf{u} = -\frac{1}{\rho} \nabla p + \nu \Delta \mathbf{u} + \mathbf{f} \]

\[ \nabla \cdot \mathbf{u} = 0 \]

where \( \nu \) is kinematic viscosity and \( \mathbf{f} \) is external force.

Theorem: Energy Estimate

For solutions with no external force and appropriate boundary conditions:

\[ \frac{d}{dt} \int_{\Omega} \frac{1}{2} |\mathbf{u}|^2 \, d\mathbf{x} = -\nu \int_{\Omega} |\nabla \mathbf{u}|^2 \, d\mathbf{x} \leq 0 \]

This shows kinetic energy is dissipated by viscosity.

Proof Sketch

Multiply the momentum equation by \( \mathbf{u} \) and integrate. The nonlinear term vanishes due to incompressibility:

\[ \int (\mathbf{u} \cdot \nabla) \mathbf{u} \cdot \mathbf{u} \, d\mathbf{x} = \frac{1}{2} \int \mathbf{u} \cdot \nabla |\mathbf{u}|^2 \, d\mathbf{x} = -\frac{1}{2} \int |\mathbf{u}|^2 (\nabla \cdot \mathbf{u}) \, d\mathbf{x} = 0 \]

import numpy as np
from typing import Tuple
import matplotlib.pyplot as plt

class NavierStokes2D:
    """
    2D Incompressible Navier-Stokes solver using finite differences.
    
    Uses projection method: velocity prediction + pressure correction.
    """
    
    def __init__(self, nx: int = 64, ny: int = 64, Lx: float = 1.0, Ly: float = 1.0, 
                 nu: float = 0.01, dt: float = 0.001):
        """
        Args:
            nx, ny: Grid points in x and y
            Lx, Ly: Domain size
            nu: Kinematic viscosity
            dt: Time step
        """
        self.nx, self.ny = nx, ny
        self.Lx, self.Ly = Lx, Ly
        self.nu = nu
        self.dt = dt
        
        self.dx = Lx / (nx - 1)
        self.dy = Ly / (ny - 1)
        
        # Velocity fields
        self.u = np.zeros((ny, nx))  # x-velocity
        self.v = np.zeros((ny, nx))  # y-velocity
        
        # Pressure
        self.p = np.zeros((ny, nx))
        
    def laplacian(self, f: np.ndarray) -> np.ndarray:
        """5-point Laplacian stencil."""
        return ((np.roll(f, 1, axis=0) + np.roll(f, -1, axis=0) - 2*f) / self.dy**2 +
                (np.roll(f, 1, axis=1) + np.roll(f, -1, axis=1) - 2*f) / self.dx**2)
    
    def divergence(self, u: np.ndarray, v: np.ndarray) -> np.ndarray:
        """Compute divergence of velocity field."""
        du_dx = (np.roll(u, -1, axis=1) - np.roll(u, 1, axis=1)) / (2 * self.dx)
        dv_dy = (np.roll(v, -1, axis=0) - np.roll(v, 1, axis=0)) / (2 * self.dy)
        return du_dx + dv_dy
    
    def advection(self, u: np.ndarray, v: np.ndarray) -> Tuple[np.ndarray, np.ndarray]:
        """Compute (u·∇)u using upwinding."""
        # x-momentum advection
        du_dx = np.where(u > 0,
                        (u - np.roll(u, 1, axis=1)) / self.dx,
                        (np.roll(u, -1, axis=1) - u) / self.dx)
        du_dy = np.where(v > 0,
                        (u - np.roll(u, 1, axis=0)) / self.dy,
                        (np.roll(u, -1, axis=0) - u) / self.dy)
        
        # y-momentum advection
        dv_dx = np.where(u > 0,
                        (v - np.roll(v, 1, axis=1)) / self.dx,
                        (np.roll(v, -1, axis=1) - v) / self.dx)
        dv_dy = np.where(v > 0,
                        (v - np.roll(v, 1, axis=0)) / self.dy,
                        (np.roll(v, -1, axis=0) - v) / self.dy)
        
        adv_u = u * du_dx + v * du_dy
        adv_v = u * dv_dx + v * dv_dy
        
        return adv_u, adv_v
    
    def step(self):
        """Take one time step using projection method."""
        # Step 1: Predict intermediate velocity (ignore pressure)
        adv_u, adv_v = self.advection(self.u, self.v)
        
        u_star = self.u + self.dt * (-adv_u + self.nu * self.laplacian(self.u))
        v_star = self.v + self.dt * (-adv_v + self.nu * self.laplacian(self.v))
        
        # Apply boundary conditions (no-slip walls)
        u_star[0, :] = u_star[-1, :] = 0
        u_star[:, 0] = u_star[:, -1] = 0
        v_star[0, :] = v_star[-1, :] = 0
        v_star[:, 0] = v_star[:, -1] = 0
        
        # Step 2: Solve Poisson equation for pressure
        # ∇²p = (1/dt) ∇·u_star
        div = self.divergence(u_star, v_star)
        
        # Simple Jacobi iteration for Poisson equation
        for _ in range(50):
            self.p = ((np.roll(self.p, 1, axis=0) + np.roll(self.p, -1, axis=0)) / self.dy**2 +
                     (np.roll(self.p, 1, axis=1) + np.roll(self.p, -1, axis=1)) / self.dx**2 -
                     div / self.dt) / (2/self.dx**2 + 2/self.dy**2)
        
        # Step 3: Correct velocity to be divergence-free
        dp_dx = (np.roll(self.p, -1, axis=1) - np.roll(self.p, 1, axis=1)) / (2 * self.dx)
        dp_dy = (np.roll(self.p, -1, axis=0) - np.roll(self.p, 1, axis=0)) / (2 * self.dy)
        
        self.u = u_star - self.dt * dp_dx
        self.v = v_star - self.dt * dp_dy
        
        # Apply boundary conditions
        self.u[0, :] = self.u[-1, :] = 0
        self.u[:, 0] = self.u[:, -1] = 0
        self.v[0, :] = self.v[-1, :] = 0
        self.v[:, 0] = self.v[:, -1] = 0
    
    def kinetic_energy(self) -> float:
        """Compute total kinetic energy."""
        return 0.5 * np.sum(self.u**2 + self.v**2) * self.dx * self.dy
    
    def enstrophy(self) -> float:
        """Compute enstrophy (L² norm of vorticity)."""
        # Vorticity ω = ∂v/∂x - ∂u/∂y
        dv_dx = (np.roll(self.v, -1, axis=1) - np.roll(self.v, 1, axis=1)) / (2 * self.dx)
        du_dy = (np.roll(self.u, -1, axis=0) - np.roll(self.u, 1, axis=0)) / (2 * self.dy)
        vorticity = dv_dx - du_dy
        return np.sum(vorticity**2) * self.dx * self.dy

3. Optimization: Convex Analysis and Gradient Methods

Convex optimization provides efficient algorithms with global convergence guarantees. It's foundational to machine learning, control theory, and economics.

Definition: Convex Function

A function \( f: \mathbb{R}^n \to \mathbb{R} \) is convex if for all \( x, y \in \mathbb{R}^n \) and \( \theta \in [0,1] \):

\[ f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y) \]

Theorem: First-Order Condition

For a differentiable convex function \( f \):

\[ f(y) \geq f(x) + \nabla f(x)^T (y - x) \]

This means the function lies above all its tangent hyperplanes.

Theorem: Convergence of Gradient Descent

For an \( L \)-smooth convex function with optimal value \( f^* \), gradient descent with step size \( \eta \leq 1/L \) satisfies:

\[ f(x_k) - f^* \leq \frac{\|x_0 - x^*\|^2}{2\eta k} \]

Convergence is \( O(1/k) \) for convex functions, \( O(\rho^k) \) for strongly convex.

Proof Sketch

Using the descent lemma and convexity:

\[ f(x_{k+1}) \leq f(x_k) - \frac{1}{2L} \|\nabla f(x_k)\|^2 \]

Telescoping the sum and using convexity gives the rate.

import numpy as np
from typing import Callable, Tuple, List
import matplotlib.pyplot as plt

class GradientDescent:
    """Gradient descent optimizer with various step size strategies."""
    
    def __init__(self, step_size: str = 'constant', initial_lr: float = 0.1):
        """
        Args:
            step_size: 'constant', 'decay', or 'armijo'
            initial_lr: Initial learning rate
        """
        self.step_size_strategy = step_size
        self.lr = initial_lr
        self.history = []
    
    def optimize(self, f: Callable, grad_f: Callable, x0: np.ndarray,
                 max_iter: int = 1000, tol: float = 1e-6) -> Tuple[np.ndarray, List[float]]:
        """
        Minimize f using gradient descent.
        
        Returns:
            x_opt: Optimal point
            f_history: Function values at each iteration
        """
        x = x0.copy()
        f_history = [f(x)]
        
        for k in range(max_iter):
            g = grad_f(x)
            
            # Determine step size
            if self.step_size_strategy == 'constant':
                alpha = self.lr
            elif self.step_size_strategy == 'decay':
                alpha = self.lr / (1 + 0.01 * k)
            elif self.step_size_strategy == 'armijo':
                alpha = self._armijo_line_search(f, grad_f, x, g)
            else:
                alpha = self.lr
            
            # Update
            x_new = x - alpha * g
            f_new = f(x_new)
            
            f_history.append(f_new)
            
            # Check convergence
            if np.linalg.norm(g) < tol:
                break
            
            x = x_new
        
        return x, f_history
    
    def _armijo_line_search(self, f: Callable, grad_f: Callable, 
                           x: np.ndarray, g: np.ndarray,
                           c: float = 0.5, rho: float = 0.5) -> float:
        """Backtracking line search satisfying Armijo condition."""
        alpha = self.lr
        f_x = f(x)
        
        while f(x - alpha * g) > f_x - c * alpha * np.dot(g, g):
            alpha *= rho
            if alpha < 1e-10:
                break
        
        return alpha


class NesterovAcceleratedGradient:
    """Nesterov's accelerated gradient method (optimal for convex functions)."""
    
    def __init__(self, lr: float = 0.1):
        self.lr = lr
    
    def optimize(self, f: Callable, grad_f: Callable, x0: np.ndarray,
                 max_iter: int = 1000, tol: float = 1e-6) -> Tuple[np.ndarray, List[float]]:
        """
        Nesterov's accelerated gradient descent.
        Convergence: O(1/k²) for convex, O((1-√(μ/L))^k) for strongly convex.
        """
        x = x0.copy()
        y = x0.copy()
        f_history = [f(x)]
        
        for k in range(1, max_iter + 1):
            x_new = y - self.lr * grad_f(y)
            y = x_new + (k - 1) / (k + 2) * (x_new - x)
            
            f_history.append(f(x_new))
            
            if np.linalg.norm(grad_f(x_new)) < tol:
                break
            
            x = x_new
        
        return x_new, f_history

1. Tropical Geometry: The Geometry of the Min-Plus Semiring

Tropical geometry is a piecewise-linear version of algebraic geometry where the operations are \( \oplus = \min \) and \( \otimes = + \). It connects algebraic geometry to combinatorics and optimization.

The Tropical Semiring

The tropical semiring \( \mathbb{T} = \mathbb{R} \cup \{\infty\} \) has operations:

\[ x \oplus y = \min(x, y), \quad x \otimes y = x + y \]

The additive identity is \( \infty \), multiplicative identity is \( 0 \).

Theorem: Fundamental Theorem of Tropical Algebra

Every tropical polynomial \( f \in \mathbb{T}[x_1, \ldots, x_n] \) defines a piecewise-linear convex function. The tropical hypersurface \( V(f) \) consists of points where the minimum is achieved at least twice.

Proof Sketch

A tropical polynomial is a minimum of affine functions, hence convex and piecewise-linear. The hypersurface is the locus where the convex function is not smooth — exactly where the minimum is attained by multiple terms.

class TropicalNumber:
    """Element of the tropical semiring (min-plus algebra)."""
    
    def __init__(self, value: float):
        self.value = value if value != float('inf') else np.inf
    
    def __add__(self, other: 'TropicalNumber') -> 'TropicalNumber':
        """Tropical addition: min"""
        return TropicalNumber(min(self.value, other.value))
    
    def __mul__(self, other: 'TropicalNumber') -> 'TropicalNumber':
        """Tropical multiplication: +"""
        if self.value == np.inf or other.value == np.inf:
            return TropicalNumber(np.inf)
        return TropicalNumber(self.value + other.value)
    
    def __pow__(self, n: int) -> 'TropicalNumber':
        """Tropical power: n * x"""
        if self.value == np.inf:
            return TropicalNumber(np.inf)
        return TropicalNumber(n * self.value)
    
    def __repr__(self):
        if self.value == np.inf:
            return "∞"
        return f"{self.value:.3f}"


class TropicalPolynomial:
    """
    Tropical polynomial in n variables.
    
    f(x) = min_i (a_i + c_i1*x1 + c_i2*x2 + ... + c_in*xn)
    
    where a_i are coefficients and c_ij are exponents.
    """
    
    def __init__(self, terms: List[Tuple[float, List[int]]]):
        """
        Args:
            terms: List of (coefficient, exponents) pairs
                   Each term is a_i + c_i1*x1 + ... + c_in*xn
        """
        self.terms = terms
    
    def evaluate(self, x: np.ndarray) -> float:
        """Evaluate the tropical polynomial at point x."""
        values = []
        for coeff, exponents in self.terms:
            value = coeff + np.dot(exponents, x)
            values.append(value)
        return min(values)
    
    def __call__(self, x: np.ndarray) -> float:
        return self.evaluate(x)
    
    def gradient(self, x: np.ndarray) -> np.ndarray:
        """
        Subgradient at x (gradient of the active term).
        Returns the exponents of the term achieving the minimum.
        """
        values = []
        for coeff, exponents in self.terms:
            value = coeff + np.dot(exponents, x)
            values.append((value, exponents))
        
        min_value = min(v for v, _ in values)
        active_terms = [e for v, e in values if abs(v - min_value) < 1e-10]
        
        # Return the first active term's exponents
        return np.array(active_terms[0])
    
    def hypersurface(self, x_range: Tuple[float, float], 
                    y_range: Tuple[float, float], 
                    n_points: int = 200) -> np.ndarray:
        """
        Compute the tropical hypersurface (where min is achieved twice).
        Returns a mask indicating the hypersurface.
        """
        x = np.linspace(x_range[0], x_range[1], n_points)
        y = np.linspace(y_range[0], y_range[1], n_points)
        X, Y = np.meshgrid(x, y)
        
        hypersurface = np.zeros((n_points, n_points), dtype=bool)
        
        for i in range(n_points):
            for j in range(n_points):
                point = np.array([X[i, j], Y[i, j]])
                values = []
                for coeff, exponents in self.terms:
                    value = coeff + np.dot(exponents, point)
                    values.append(value)
                
                # Check if minimum is achieved at least twice
                min_val = min(values)
                count = sum(1 for v in values if abs(v - min_val) < 1e-6)
                hypersurface[i, j] = (count >= 2)
        
        return X, Y, hypersurface
    
    def __repr__(self):
        terms_str = []
        for coeff, exps in self.terms:
            var_parts = []
            for i, e in enumerate(exps):
                if e == 1:
                    var_parts.append(f"x{i}")
                elif e > 1:
                    var_parts.append(f"x{i}^{e}")
            if var_parts:
                terms_str.append(f"{coeff} + {' + '.join(var_parts)}")
            else:
                terms_str.append(str(coeff))
        return "min(" + ", ".join(terms_str) + ")"

2. Derived Categories: Homological Algebra at the Next Level

Derived categories were introduced by Verdier to unify cohomology theories. They allow working with complexes up to quasi-isomorphism, revealing deeper structures.

Definition: Chain Complex

A chain complex \( C^\bullet \) is a sequence of abelian groups with differentials \( d^n: C^n \to C^{n+1} \) satisfying \( d^{n+1} \circ d^n = 0 \):

\[ \cdots \xrightarrow{d^{n-1}} C^n \xrightarrow{d^n} C^{n+1} \xrightarrow{d^{n+1}} \cdots \]

Definition: Quasi-Isomorphism

A chain map \( f: C^\bullet \to D^\bullet \) is a quasi-isomorphism if it induces isomorphisms on all cohomology groups:

\[ H^n(f): H^n(C^\bullet) \xrightarrow{\cong} H^n(D^\bullet) \quad \text{for all } n \]

Theorem: The Derived Category

The derived category \( D(\mathcal{A}) \) of an abelian category \( \mathcal{A} \) is obtained from the homotopy category \( K(\mathcal{A}) \) by formally inverting all quasi-isomorphisms.

Proof Sketch (Construction)

Verdier's construction uses a calculus of fractions. Morphisms in \( D(\mathcal{A}) \) are equivalence classes of "roofs":

\[ C^\bullet \xleftarrow{qis} Z^\bullet \xrightarrow{f} D^\bullet \]

where the left arrow is a quasi-isomorphism. Two roofs are equivalent if they fit into a commutative diagram with another roof.

import numpy as np
from typing import List, Optional, Callable
from dataclasses import dataclass

@dataclass
class ChainComplex:
    """
    A bounded chain complex of finite-dimensional vector spaces.
    
    C^•: ... → C^{n-1} → C^n → C^{n+1} → ...
    """
    spaces: dict  # degree → dimension
    differentials: dict  # degree → matrix representation of d^n: C^n → C^{n+1}
    
    def __post_init__(self):
        """Verify that d^{n+1} ∘ d^n = 0 for all n."""
        for n in self.differentials:
            if n + 1 in self.differentials:
                d_n = self.differentials[n]
                d_n_plus_1 = self.differentials[n + 1]
                composition = d_n_plus_1 @ d_n
                if not np.allclose(composition, 0):
                    raise ValueError(f"d^{n+1} ∘ d^{n} ≠ 0 at degree {n}")
    
    def cohomology(self, n: int) -> tuple:
        """
        Compute H^n = ker(d^n) / im(d^{n-1}).
        
        Returns:
            (dimension, basis for ker/im quotient)
        """
        if n not in self.spaces:
            return (0, np.array([]))
        
        # Compute kernel of d^n
        if n in self.differentials:
            d_n = self.differentials[n]
            ker_n = null_space(d_n)
        else:
            ker_n = np.eye(self.spaces[n])
        
        # Compute image of d^{n-1}
        if n - 1 in self.differentials:
            d_n_minus_1 = self.differentials[n - 1]
            im_n_minus_1 = column_space(d_n_minus_1)
        else:
            im_n_minus_1 = np.zeros((self.spaces[n], 0))
        
        # H^n = ker(d^n) / im(d^{n-1})
        # Dimension = dim(ker) - dim(im ∩ ker) = dim(ker) - dim(im) if im ⊆ ker
        dim_ker = ker_n.shape[1] if ker_n.size > 0 else 0
        dim_im = im_n_minus_1.shape[1] if im_n_minus_1.size > 0 else 0
        
        dim_h = max(0, dim_ker - dim_im)
        
        return (dim_h, None)  # Simplified; full implementation needs quotient computation
    
    def all_cohomology(self) -> dict:
        """Compute cohomology in all degrees."""
        result = {}
        for n in self.spaces:
            result[n] = self.cohomology(n)[0]
        return result


def null_space(A: np.ndarray, tol: float = 1e-10) -> np.ndarray:
    """Compute orthonormal basis for null space of A."""
    U, S, Vh = np.linalg.svd(A)
    rank = np.sum(S > tol)
    null_dim = A.shape[1] - rank
    if null_dim == 0:
        return np.zeros((A.shape[1], 0))
    return Vh[rank:, :].T


def column_space(A: np.ndarray, tol: float = 1e-10) -> np.ndarray:
    """Compute orthonormal basis for column space of A."""
    U, S, _ = np.linalg.svd(A)
    rank = np.sum(S > tol)
    if rank == 0:
        return np.zeros((A.shape[0], 0))
    return U[:, :rank]


def chain_map(f: dict, source: ChainComplex, target: ChainComplex) -> bool:
    """
    Verify that f: C^• → D^• is a chain map.
    
    A chain map satisfies: f^{n+1} ∘ d_C^n = d_D^n ∘ f^n for all n.
    """
    for n in f:
        if n in source.differentials and n in target.differentials:
            left = f.get(n + 1, np.zeros((target.spaces.get(n+1, 0), source.spaces.get(n+1, 0))))
            if left.size == 0:
                continue
            left = left @ source.differentials[n]
            
            right = target.differentials[n] @ f[n]
            
            if not np.allclose(left, right):
                return False
    return True

def mapping_cone(f: dict, source: ChainComplex, target: ChainComplex) -> ChainComplex:
    """
    The mapping cone of a chain map f: C^• → D^•.
    
    Cone(f)^n = C^{n+1} ⊕ D^n
    d^n(c, d) = (-d_C(c), f(c) + d_D(d))
    """
    # Collect all degrees
    all_degrees = set()
    for n in source.spaces:
        all_degrees.add(n - 1)  # C^{n} contributes to degree n-1
    for n in target.spaces:
        all_degrees.add(n)
    
    spaces = {}
    differentials = {}
    
    for n in all_degrees:
        dim_c = source.spaces.get(n + 1, 0)
        dim_d = target.spaces.get(n, 0)
        spaces[n] = dim_c + dim_d
    
    # Construct differentials
    for n in all_degrees:
        dim_c_n = source.spaces.get(n + 1, 0)
        dim_c_n_plus_1 = source.spaces.get(n + 2, 0)
        dim_d_n = target.spaces.get(n, 0)
        dim_d_n_plus_1 = target.spaces.get(n + 1, 0)
        
        # Block matrix: [-d_C, 0; f, d_D]
        total_dim_source = dim_c_n + dim_d_n
        total_dim_target = dim_c_n_plus_1 + dim_d_n_plus_1
        
        d_n = np.zeros((total_dim_target, total_dim_source))
        
        # Top-left: -d_C^{n+1}: C^{n+1} → C^{n+2}
        if n + 1 in source.differentials:
            d_n[:dim_c_n_plus_1, :dim_c_n] = -source.differentials[n + 1]
        
        # Bottom-left: f^{n+1}: C^{n+1} → D^{n+1}
        if n + 1 in f:
            d_n[dim_c_n_plus_1:, :dim_c_n] = f[n + 1]
        
        # Bottom-right: d_D^n: D^n → D^{n+1}
        if n in target.differentials:
            d_n[dim_c_n_plus_1:, dim_c_n:] = target.differentials[n]
        
        differentials[n] = d_n
    
    return ChainComplex(spaces=spaces, differentials=differentials)

3. Arithmetic Geometry: Elliptic Curves over Finite Fields

Elliptic curves over finite fields combine number theory and algebraic geometry. They're crucial for cryptography (ECC) and the Birch-Swinnerton-Dyer conjecture.

Definition: Elliptic Curve over \( \mathbb{F}_p \)

An elliptic curve \( E \) over \( \mathbb{F}_p \) is given by a Weierstrass equation:

\[ y^2 = x^3 + ax + b \pmod{p} \]

with discriminant \( \Delta = -16(4a^3 + 27b^2) \not\equiv 0 \pmod{p} \).

Theorem: Hasse's Bound

For an elliptic curve \( E \) over \( \mathbb{F}_q \) where \( q = p^n \):

\[ |\#E(\mathbb{F}_q) - (q + 1)| \leq 2\sqrt{q} \]

The trace of Frobenius \( a_q = q + 1 - \#E(\mathbb{F}_q) \) satisfies \( |a_q| \leq 2\sqrt{q} \).

Proof Sketch

The Frobenius endomorphism \( \phi: (x, y) \mapsto (x^q, y^q) \) satisfies a characteristic polynomial. The degree formula gives \( \deg(\phi - 1) = q + 1 - \text{tr}(\phi) \), which equals \( \#E(\mathbb{F}_q) \). The Cauchy-Schwarz inequality bounds the trace.

import numpy as np
from typing import List, Tuple, Optional
from dataclasses import dataclass

@dataclass
class Point:
    """Point on an elliptic curve (or point at infinity)."""
    x: Optional[int]
    y: Optional[int]
    is_infinity: bool = False
    
    def __post_init__(self):
        if self.is_infinity:
            self.x = None
            self.y = None
    
    def __eq__(self, other):
        if not isinstance(other, Point):
            return False
        return (self.is_infinity and other.is_infinity) or \
               (self.x == other.x and self.y == other.y)
    
    def __repr__(self):
        if self.is_infinity:
            return "O (point at infinity)"
        return f"({self.x}, {self.y})"


class EllipticCurve:
    """Elliptic curve over a finite field F_p."""
    
    def __init__(self, a: int, b: int, p: int):
        """
        y² = x³ + ax + b (mod p)
        
        Args:
            a, b: Curve coefficients
            p: Prime field characteristic
        """
        self.a = a % p
        self.b = b % p
        self.p = p
        
        # Check non-singularity: 4a³ + 27b² ≠ 0 (mod p)
        discriminant = (4 * pow(self.a, 3, p) + 27 * pow(self.b, 2, p)) % p
        if discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
    
    def is_on_curve(self, P: Point) -> bool:
        """Check if point P lies on the curve."""
        if P.is_infinity:
            return True
        
        x, y = P.x % self.p, P.y % self.p
        left = (y * y) % self.p
        right = (pow(x, 3, self.p) + self.a * x + self.b) % self.p
        return left == right
    
    def add(self, P: Point, Q: Point) -> Point:
        """
        Add two points on the curve using the chord-tangent method.
        """
        # Handle identity
        if P.is_infinity:
            return Q
        if Q.is_infinity:
            return P
        
        x1, y1 = P.x % self.p, P.y % self.p
        x2, y2 = Q.x % self.p, Q.y % self.p
        
        # P + (-P) = O
        if x1 == x2 and (y1 + y2) % self.p == 0:
            return Point(None, None, is_infinity=True)
        
        # Compute slope
        if P == Q:
            # Tangent: λ = (3x₁² + a) / (2y₁)
            num = (3 * pow(x1, 2, self.p) + self.a) % self.p
            den = (2 * y1) % self.p
        else:
            # Chord: λ = (y₂ - y₁) / (x₂ - x₁)
            num = (y2 - y1) % self.p
            den = (x2 - x1) % self.p
        
        # Modular inverse of denominator
        try:
            den_inv = pow(den, -1, self.p)
        except ValueError:
            return Point(None, None, is_infinity=True)
        
        lam = (num * den_inv) % self.p
        
        # x₃ = λ² - x₁ - x₂
        x3 = (pow(lam, 2, self.p) - x1 - x2) % self.p
        
        # y₃ = λ(x₁ - x₃) - y₁
        y3 = (lam * (x1 - x3) - y1) % self.p
        
        return Point(x3, y3)
    
    def scalar_mult(self, k: int, P: Point) -> Point:
        """Compute kP using double-and-add."""
        if k < 0:
            # kP = (-k)(-P)
            neg_P = Point(P.x, (-P.y) % self.p if P.y else 0)
            return self.scalar_mult(-k, neg_P)
        
        result = Point(None, None, is_infinity=True)
        addend = P
        
        while k > 0:
            if k & 1:
                result = self.add(result, addend)
            addend = self.add(addend, addend)
            k >>= 1
        
        return result
    
    def all_points(self) -> List[Point]:
        """Enumerate all points on the curve (for small p)."""
        points = [Point(None, None, is_infinity=True)]
        
        for x in range(self.p):
            rhs = (pow(x, 3, self.p) + self.a * x + self.b) % self.p
            
            # Find y such that y² = rhs (mod p)
            for y in range(self.p):
                if (y * y) % self.p == rhs:
                    points.append(Point(x, y))
        
        return points
    
    def order(self) -> int:
        """Number of points on the curve (including point at infinity)."""
        return len(self.all_points())
    
    def hasse_bound(self) -> Tuple[int, int]:
        """Return Hasse bounds for the number of points."""
        q = self.p
        lower = q + 1 - int(2 * np.sqrt(q))
        upper = q + 1 + int(2 * np.sqrt(q))
        return lower, upper
    
    def frobenius_trace(self) -> int:
        """Compute the trace of Frobenius a_p = p + 1 - #E(F_p)."""
        return self.p + 1 - self.order()

4. AI and Mathematics: The First Proof Challenge

The intersection of AI and mathematics has become a major research frontier. The recent "First Proof" challenge represents a rigorous attempt to evaluate AI mathematical capabilities.

The Challenge Structure

The First Proof challenge, launched February 5, 2026, presented 10 original research-level lemmas to AI systems. Key features:

  • Problems created by 11 mathematicians including Fields Medalist Martin Hairer
  • Problems are original — cannot be found in training data
  • Solutions encrypted until challenge end (February 14, 2026)
  • No human mathematical input allowed

Results Summary

Of the submissions:

  • Only 2 AI-generated proofs were correct (problems 9 and 10)
  • Problem 9's solution already existed in literature
  • Problem 1 was "contaminated" (proof sketch existed online)
  • OpenAI claimed 6 "high probability correct" solutions, but holes were found

As mathematician Mohammed Abouzaid observed, successful AI proofs had "the flavor of 19th-century mathematics." The challenge highlights:

class ProofStatus(Enum):
    """Status of a proof verification attempt."""
    CORRECT = "correct"
    INCORRECT = "incorrect"
    UNVERIFIABLE = "unverifiable"
    SYNTAX_ERROR = "syntax_error"


@dataclass
class ProofStep:
    """A single step in a mathematical proof."""
    statement: str
    justification: str
    depends_on: List[int]  # Indices of previous steps this depends on
    
    def __repr__(self):
        return f"Step: {self.statement}\n  Justification: {self.justification}"


class ProofVerifier:
    """
    A simplified proof verification system.
    
    Real automated theorem proving (ATP) uses formal systems like
    Lean, Coq, or Isabelle. This is a toy example for illustration.
    """
    
    def __init__(self):
        self.axioms = set()
        self.theorems = {}
        self.definitions = {}
    
    def add_axiom(self, name: str, statement: str):
        """Add an axiom to the system."""
        self.axioms.add(name)
        self.theorems[name] = statement
    
    def add_definition(self, name: str, definition: str):
        """Add a definition."""
        self.definitions[name] = definition
    
    def verify_step(self, step: ProofStep, previous_steps: List[ProofStep]) -> ProofStatus:
        """
        Attempt to verify a single proof step.
        
        In a real system, this would use formal logic.
        Here we do simple pattern matching for demonstration.
        """
        statement = step.statement.lower()
        justification = step.justification.lower()
        
        # Check for common proof patterns
        valid_patterns = [
            "by definition",
            "by axiom",
            "by theorem",
            "by induction",
            "by contradiction",
            "by direct computation",
            "by substitution",
            "follows from"
        ]
        
        has_valid_justification = any(pat in justification for pat in valid_patterns)
        
        if not has_valid_justification:
            return ProofStatus.UNVERIFIABLE
        
        # Check if dependencies are valid
        for dep_idx in step.depends_on:
            if dep_idx < 0 or dep_idx >= len(previous_steps):
                return ProofStatus.SYNTAX_ERROR
        
        # In a real system, we would check logical validity here
        return ProofStatus.CORRECT
    
    def verify_proof(self, steps: List[ProofStep], theorem: str) -> Tuple[ProofStatus, List[str]]:
        """
        Verify a complete proof.
        
        Returns:
            (overall status, list of issues found)
        """
        issues = []
        
        for i, step in enumerate(steps):
            status = self.verify_step(step, steps[:i])
            if status == ProofStatus.INCORRECT:
                issues.append(f"Step {i+1}: Incorrect")
            elif status == ProofStatus.SYNTAX_ERROR:
                issues.append(f"Step {i+1}: Syntax error")
            elif status == ProofStatus.UNVERIFIABLE:
                issues.append(f"Step {i+1}: Unverifiable justification '{step.justification}'")
        
        # Check if theorem matches conclusion
        if steps:
            conclusion = steps[-1].statement
            # Simplified check
            if theorem.lower() not in conclusion.lower() and conclusion.lower() not in theorem.lower():
                issues.append("Final step does not match theorem statement")
        
        if issues:
            return ProofStatus.UNVERIFIABLE, issues
        
        return ProofStatus.CORRECT, []


class FirstProofProblem:

        correct = sum(1 for s in self.solutions if s['status'] == ProofStatus.CORRECT)
        total = len(self.solutions)
        return f"Problem {self.number}: {correct}/{total} correct"
