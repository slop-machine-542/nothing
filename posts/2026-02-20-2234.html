Homotopy Type Theory: A New Foundation for Mathematics

homotopy-type-theory

Motivation

Homotopy Type Theory (HoTT), developed by Vladimir Voevodsky and collaborators, offers a revolutionary new foundation for mathematics that unifies type theory with homotopy theory. Traditional foundations use set theory (ZFC), where equality is a proposition—either true or false. HoTT treats equality as a structure: the identity type \(a =_A b\) represents paths from \(a\) to \(b\), and higher identity types represent homotopies between paths. This perspective enables "synthetic homotopy theory"—proving topological results using type-theoretic methods without ever constructing topological spaces.

Definitions

  • Type: The basic objects of HoTT, analogous to sets but with richer structure. Types can be viewed as spaces, with elements as points.
  • Identity Type: For \(a, b : A\), the type \(a =_A b\) represents paths from \(a\) to \(b\). Elements of this type are witnesses of equality.
  • Path Induction: The principle that to prove a property for all paths, it suffices to prove it for the reflexivity path.
  • Univalence Axiom: For types \(A, B\), the canonical map \((A = B) \to (A \simeq B)\) is an equivalence. Equivalence of types implies equality.
  • Higher Inductive Type (HIT): Types defined by generators for both points and paths, allowing direct construction of spaces like the circle.

Theorem: The Fundamental Group of the Circle

Theorem: In HoTT, the circle \(S^1\) is defined as a higher inductive type with a base point \(\text{base} : S^1\) and a loop \(\text{loop} : \text{base} =_{S^1} \text{base}\). Then: \[\Omega(S^1, \text{base}) \equiv (\text{base} =_{S^1} \text{base}) \simeq \mathbb{Z}\] where the equivalence maps \(n : \mathbb{Z}\) to \(\text{loop}^n\) (the n-fold composition of loop with itself).

Proof Sketch

The proof uses the "encode-decode" method. Define a fibration \(\text{code} : S^1 \to \mathcal{U}\) by \(\text{code}(\text{base}) = \mathbb{Z}\) and transport along loop corresponds to successor. The encoding map sends a path \(p : \text{base} = x\) to the transported element. Decoding uses recursion on \(S^1\). These maps are shown to be inverses, establishing the equivalence. This proof is entirely constructive and computer-verifiable.

Notation Guide

  • \(a : A\) — Element \(a\) of type \(A\)
  • \(a =_A b\) — Identity type (paths from \(a\) to \(b\) in \(A\))
  • \(\text{refl}_a : a = a\) — Reflexivity path
  • \(p \cdot q\) — Path concatenation
  • \(p^{-1}\) — Path inverse
  • \(A \simeq B\) — Type equivalence (bi-invertible map)
  • \(\mathcal{U}\) — Universe of types

Higher Category Theory: Beyond Composition

higher-category-theory

Motivation

Higher category theory extends ordinary category theory by allowing morphisms between morphisms (2-morphisms), morphisms between 2-morphisms (3-morphisms), and so on. This framework is essential for modern algebraic topology, mathematical physics, and homotopy theory. Where ordinary categories capture "processes," higher categories capture "processes between processes," enabling the formalization of homotopy coherence and higher-dimensional algebraic structures.

Definitions

  • 2-Category: A category enriched over Cat. Objects, 1-morphisms (functors), and 2-morphisms (natural transformations) with horizontal and vertical composition.
  • \(\infty\)-Category: A higher category where all morphisms above some dimension are invertible (up to higher morphisms). Models include quasi-categories, complete Segal spaces, and simplicial categories.
  • Quasi-Category: A simplicial set satisfying the inner horn filling condition. Elements are "shapes" that can be composed.
  • Homotopy Coherence: The phenomenon where diagrams commute only up to specified higher isomorphisms, which themselves satisfy coherence conditions.

Theorem: The Homotopy Hypothesis

Theorem (Grothendieck, Baez-Dolan, Lurie): There is an equivalence of \((\infty, 1)\)-categories: \[\text{Spaces} \simeq \infty\text{-Groupoids}\] Specifically, the homotopy theory of spaces (topological spaces up to weak homotopy equivalence) is equivalent to the theory of weak \(\infty\)-groupoids (higher categories where all morphisms are invertible).

Proof Sketch

The equivalence is given by the fundamental \(\infty\)-groupoid construction. For a space \(X\), define \(\Pi_\infty(X)\) with:

  • Objects: Points of \(X\)
  • 1-Morphisms: Paths between points
  • 2-Morphisms: Homotopies between paths
  • n-Morphisms: Higher homotopies

Conversely, given an \(\infty\)-groupoid, its geometric realization yields a space. These functors form an equivalence of homotopy theories.

Notation Guide

  • \(\mathcal{C}\) — Higher category
  • \(\mathcal{C}(a, b)\) — Hom-\((n-1)\)-category from \(a\) to \(b\)
  • \(\circ_n\) — n-dimensional composition
  • \(\Delta^n\) — Standard n-simplex
  • \(\Lambda^n_k\) — k-th inner horn of the n-simplex
  • \(\mathcal{S}\) — \(\infty\)-category of spaces

from typing import List, Tuple, Callable
from dataclasses import dataclass

@dataclass
class Simplex:
    """Represents an n-simplex in a simplicial set."""
    dimension: int
    vertices: Tuple[int, ...]
    
    def face(self, i: int) -> 'Simplex':
        """Return the i-th face (remove vertex i)."""
        return Simplex(
            self.dimension - 1,
            self.vertices[:i] + self.vertices[i+1:]
        )
    
    def __repr__(self):
        return f"Δ^{self.dimension}{self.vertices}"

class QuasiCategory:
    """
    A quasi-category is a simplicial set where every inner horn 
    has a filler. This models an ∞-category.
    """
    def __init__(self):
        self.simplices: dict[int, List[Simplex]] = {0: [], 1: [], 2: []}
        self.morphisms: dict[Tuple[int, int], List[int]] = {}
    
    def add_object(self, obj_id: int):
        """Add a 0-simplex (object)."""
        self.simplices[0].append(Simplex(0, (obj_id,)))
    
    def add_morphism(self, source: int, target: int, morph_id: int):
        """Add a 1-simplex (morphism)."""
        self.simplices[1].append(Simplex(1, (source, target)))
        key = (source, target)
        if key not in self.morphisms:
            self.morphisms[key] = []
        self.morphisms[key].append(morph_id)
    
    def can_fill_inner_horn(self, n: int, k: int) -> bool:
        """
        Check if an inner horn Λ^n_k can be filled.
        For n=2, k=1: this is composability of morphisms.
        """
        if n == 2 and k == 1:
            # Inner horn Λ²₁ represents a composable pair (f, g)
            # where f: a→b and g: b→c
            # The filler is a 2-simplex giving the composite g∘f
            return True  # In a quasi-category, this always fills
        return False
    
    def compose(self, f: Tuple[int, int], g: Tuple[int, int]) -> Tuple[int, int]:
        """
        Given f: a→b and g: b→c, return the composite g∘f: a→c.
        In a quasi-category, composition is defined up to homotopy.
        """
        a, b1 = f
        b2, c = g
        if b1 != b2:
            raise ValueError("Morphisms not composable")
        return (a, c)  # The composite

class InfinityGroupoid:
    """
    An ∞-groupoid is an ∞-category where all morphisms 
    are invertible (up to higher morphisms).
    """
    def __init__(self, name: str):
        self.name = name
        self.objects = []
        self.morphisms = {}  # level -> list of morphisms
        self.inverses = {}  # track inverses at each level
    
    def add_object(self, obj):
        self.objects.append(obj)
        self.morphisms[0] = self.morphisms.get(0, []) + [obj]
    
    def add_morphism(self, level: int, source, target, invertible: bool = True):
        """
        Add an n-morphism. In an ∞-groupoid, all are invertible.
        """
        morph = (level, source, target)
        self.morphisms[level] = self.morphisms.get(level, []) + [morph]
        
        if invertible:
            # Record the inverse morphism
            inverse = (level, target, source)
            self.inverses[morph] = inverse
    
    def fundamental_groupoid(self, n: int = 1):
        """
        Truncate to the n-groupoid (forget higher morphisms).
        For n=1, this gives the ordinary fundamental groupoid.
        """
        return {
            "objects": self.objects,
            f"{n}-morphisms": self.morphisms.get(n, [])
        }

Arithmetic Dynamics: Number Theory Meets Dynamical Systems

arithmetic-dynamics

Motivation

Arithmetic dynamics is a relatively new field (emerging in the 1990s) that combines classical dynamical systems with number theory. It studies the iteration of rational maps over number fields and their reduction modulo primes. The field draws inspiration from complex dynamics (Fatou, Julia) and Diophantine geometry (Mordell, Weil), asking questions like: What are the arithmetic properties of periodic points? How does the orbit of a point behave under reduction?

Definitions

  • Rational Map: A morphism \(\phi: \mathbb{P}^N \to \mathbb{P}^N\) given by homogeneous polynomials of the same degree.
  • Orbit: For a point \(P\), its orbit is \(\mathcal{O}_\phi(P) = \{P, \phi(P), \phi^2(P), \ldots\}\).
  • Periodic Point: A point \(P\) with \(\phi^n(P) = P\) for some \(n > 0\). The minimal such \(n\) is the exact period.
  • Preperiodic Point: A point with finite orbit (eventually maps to a periodic cycle).
  • Canonical Height: A function \(\hat{h}_\phi: \mathbb{P}^N(\overline{\mathbb{Q}}) \to \mathbb{R}_{\geq 0}\) measuring arithmetic complexity.

Theorem: Uniform Boundedness of Preperiodic Points

Theorem (Morton-Silverman Conjecture, partial results): Let \(K\) be a number field of degree \(D\) and \(\phi: \mathbb{P}^N \to \mathbb{P}^N\) be a rational map of degree \(d \geq 2\). There exists a constant \(C(D, N, d)\) such that: \[\#\text{PrePer}(\phi, \mathbb{P}^N(K)) \leq C(D, N, d)\] This conjecture remains open even for quadratic polynomials over \(\mathbb{Q}\).

Proof Sketch (for special cases)

For polynomial maps \(\phi(z) = z^d + c\) over \(\mathbb{Q}\), the conjecture is related to the Uniform Boundedness Conjecture for torsion on abelian varieties via the theory of dynatomic curves. The proof strategy involves:

  1. Relating periodic points to rational points on dynatomic curves
  2. Applying Faltings' theorem (Mordell conjecture) on rational points
  3. Controlling the genus of dynatomic curves

Notation Guide

  • \(\phi^n\) — n-th iterate of \(\phi\)
  • \(\mathbb{P}^N(K)\) — N-dimensional projective space over field \(K\)
  • \(\text{Per}(\phi)\) — Set of periodic points
  • \(\text{PrePer}(\phi)\) — Set of preperiodic points
  • \(\hat{h}_\phi(P)\) — Canonical height of \(P\) with respect to \(\phi\)
  • \(\Phi_n^*(z)\) — n-th dynatomic polynomial

from fractions import Fraction
from typing import List, Set, Tuple, Optional

class RationalMap:
    """
    Represents a rational map φ: P¹ → P¹ over Q.
    For simplicity, we work with polynomials φ(z) = z^d + c.
    """
    def __init__(self, degree: int, c: Fraction):
        self.degree = degree
        self.c = c
    
    def __call__(self, z: Fraction) -> Fraction:
        """Apply the map: φ(z) = z^d + c."""
        return z ** self.degree + self.c
    
    def iterate(self, z: Fraction, n: int) -> Fraction:
        """Compute the n-th iterate φ^n(z)."""
        result = z
        for _ in range(n):
            result = self(result)
        return result
    
    def orbit(self, z: Fraction, max_iter: int = 100) -> List[Fraction]:
        """Compute the orbit of z up to max_iter steps."""
        result = [z]
        current = z
        for _ in range(max_iter):
            current = self(current)
            result.append(current)
            # Check for cycles (simplified)
            if current in result[:-1]:
                break
        return result
    
    def is_periodic(self, z: Fraction, max_period: int = 20) -> Optional[int]:
        """
        Check if z is periodic and return its period if so.
        Returns None if not periodic within max_period.
        """
        seen = {}
        current = z
        for n in range(max_period + 1):
            if current in seen:
                return n - seen[current]
            seen[current] = n
            current = self(current)
        return None
    
    def is_preperiodic(self, z: Fraction, max_iter: int = 50) -> bool:
        """
        Check if z is preperiodic (orbit eventually cycles).
        """
        seen = set()
        current = z
        for _ in range(max_iter):
            if current in seen:
                return True
            seen.add(current)
            current = self(current)
        return False
    
    def dynatomic_polynomial(self, n: int) -> List[Fraction]:
        """
        Compute the n-th dynatomic polynomial Φ*_n(z).
        Roots are points of exact period n.
        
        Φ*_n(z) = ∏_{d|n} (φ^d(z) - z)^μ(n/d)
        where μ is the Möbius function.
        """
        def mobius(n: int) -> int:
            """Compute the Möbius function."""
            if n == 1:
                return 1
            factors = []
            d = 2
            temp = n
            while d * d <= temp:
                while temp % d == 0:
                    factors.append(d)
                    temp //= d
                d += 1
            if temp > 1:
                factors.append(temp)
            # Check for square factors
            if len(factors) != len(set(factors)):
                return 0
            return (-1) ** len(factors)
        
        # For numerical exploration, we just return the formula structure
        divisors = [d for d in range(1, n + 1) if n % d == 0]
        return [(d, mobius(n // d)) for d in divisors]

Reinforcement Learning Theory: Mathematical Foundations of Sequential Decision Making

reinforcement-learning-theory

Motivation

Reinforcement Learning (RL) combines ideas from dynamic programming, optimal control, and statistical learning to solve sequential decision problems. The mathematical theory of RL provides convergence guarantees, sample complexity bounds, and optimality conditions for algorithms that learn to make decisions through interaction with an environment. This field has achieved remarkable successes in game playing (AlphaGo, AlphaZero), robotics, and autonomous systems.

Definitions

  • Markov Decision Process (MDP): A tuple \(\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma)\) where \(\mathcal{S}\) is the state space, \(\mathcal{A}\) the action space, \(P(s'|s,a)\) transition probabilities, \(R(s,a)\) reward function, and \(\gamma \in [0,1)\) the discount factor.
  • Policy \(\pi\): A mapping from states to actions (or action distributions). A stationary policy depends only on the current state.
  • Value Function: \(V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) \mid s_0 = s, \pi\right]\) is the expected cumulative reward starting from state \(s\) and following policy \(\pi\).
  • Q-Function: \(Q^\pi(s,a) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) \mid s_0 = s, a_0 = a, \pi\right]\).
  • Bellman Operators: \((\mathcal{T}^\pi V)(s) = R(s, \pi(s)) + \gamma \sum_{s'} P(s'|s, \pi(s)) V(s')\).

Theorem: Bellman Optimality and Policy Iteration Convergence

Theorem: For a finite MDP with discount factor \(\gamma < 1\):

  1. There exists a unique optimal value function \(V^*\) satisfying the Bellman optimality equation: \[V^*(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\right]\]
  2. There exists an optimal deterministic stationary policy \(\pi^*\).
  3. Policy iteration converges to \(\pi^*\) in at most \(|\mathcal{S}|^{|\mathcal{A}|}\) iterations.

Proof Sketch

The Bellman operator \(\mathcal{T}\) is a \(\gamma\)-contraction in the supremum norm on value functions. By the Banach fixed-point theorem, repeated application of \(\mathcal{T}\) converges to a unique fixed point \(V^*\). The greedy policy with respect to \(V^*\) is optimal. Policy iteration alternates between policy evaluation (solving linear equations) and policy improvement (taking the greedy action), with each iteration strictly improving the policy until convergence.

Notation Guide

  • \(\mathcal{S}, \mathcal{A}\) — State and action spaces
  • \(P(s'|s,a)\) — Transition probability
  • \(R(s,a)\) — Expected reward
  • \(\gamma\) — Discount factor
  • \(V^\pi, Q^\pi\) — Value and Q-functions under policy \(\pi\)
  • \(\mathcal{T}^\pi, \mathcal{T}^*\) — Bellman policy and optimality operators
  • \(\pi^*\) — Optimal policy

import numpy as np
from typing import Tuple, Dict, List

class MDP:
    """
    Finite Markov Decision Process.
    """
    def __init__(self, n_states: int, n_actions: int, 
                 transition: np.ndarray, reward: np.ndarray, gamma: float = 0.95):
        """
        Args:
            n_states: Number of states
            n_actions: Number of actions
            transition: P[s, a, s'] = probability of transitioning to s' from s taking a
            reward: R[s, a] = expected reward
            gamma: Discount factor
        """
        self.n_states = n_states
        self.n_actions = n_actions
        self.P = transition  # Shape: (S, A, S)
        self.R = reward      # Shape: (S, A)
        self.gamma = gamma
    
    def bellman_policy_operator(self, V: np.ndarray, policy: np.ndarray) -> np.ndarray:
        """
        Apply the Bellman policy operator: T^π V = R_π + γ P_π V
        
        Args:
            V: Value function (shape: S)
            policy: Policy matrix where policy[s, a] = π(a|s) (shape: S, A)
        
        Returns:
            New value function
        """
        # Expected reward under policy: R_π(s) = Σ_a π(a|s) R(s, a)
        R_pi = np.sum(policy * self.R, axis=1)
        
        # Expected next value: (P_π V)(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a) V(s')
        P_pi_V = np.sum(policy * np.sum(self.P * V, axis=2), axis=1)
        
        return R_pi + self.gamma * P_pi_V
    
    def bellman_optimality_operator(self, V: np.ndarray) -> np.ndarray:
        """
        Apply the Bellman optimality operator: (T* V)(s) = max_a [R(s,a) + γ Σ_{s'} P(s'|s,a) V(s')]
        """
        # Compute Q(s, a) = R(s, a) + γ Σ_{s'} P(s'|s,a) V(s')
        Q = self.R + self.gamma * np.sum(self.P * V, axis=2)
        
        # Take maximum over actions
        return np.max(Q, axis=1)
    
    def policy_evaluation(self, policy: np.ndarray, tol: float = 1e-6, max_iter: int = 1000) -> np.ndarray:
        """
        Evaluate a policy by solving (I - γ P_π) V = R_π.
        Uses iterative policy evaluation.
        """
        V = np.zeros(self.n_states)
        for _ in range(max_iter):
            V_new = self.bellman_policy_operator(V, policy)
            if np.max(np.abs(V_new - V)) < tol:
                break
            V = V_new
        return V
    
    def policy_improvement(self, V: np.ndarray) -> np.ndarray:
        """
        Greedy policy improvement: π'(s) = argmax_a Q(s, a).
        Returns a deterministic policy as a one-hot matrix.
        """
        Q = self.R + self.gamma * np.sum(self.P * V, axis=2)
        best_actions = np.argmax(Q, axis=1)
        
        policy = np.zeros((self.n_states, self.n_actions))
        policy[np.arange(self.n_states), best_actions] = 1.0
        return policy
    
    def policy_iteration(self, tol: float = 1e-6) -> Tuple[np.ndarray, np.ndarray]:
        """
        Policy iteration algorithm.
        Returns: (optimal_policy, optimal_value_function)
        """
        # Initialize with uniform random policy
        policy = np.ones((self.n_states, self.n_actions)) / self.n_actions
        
        for iteration in range(100):
            # Policy evaluation
            V = self.policy_evaluation(policy, tol)
            
            # Policy improvement
            new_policy = self.policy_improvement(V)
            
            # Check for convergence
            if np.allclose(policy, new_policy):
                print(f"Policy iteration converged in {iteration + 1} iterations")
                return new_policy, V
            
            policy = new_policy
        
        return policy, V
    
    def value_iteration(self, tol: float = 1e-6, max_iter: int = 1000) -> Tuple[np.ndarray, np.ndarray]:
        """
        Value iteration algorithm.
        Returns: (optimal_policy, optimal_value_function)
        """
        V = np.zeros(self.n_states)
        
        for iteration in range(max_iter):
            V_new = self.bellman_optimality_operator(V)
            if np.max(np.abs(V_new - V)) < tol:
                print(f"Value iteration converged in {iteration + 1} iterations")
                break
            V = V_new
        
        # Extract optimal policy
        policy = self.policy_improvement(V)
        return policy, V

Cryptographic Protocols: Zero-Knowledge and Secure Computation

cryptographic-protocols

Motivation

Cryptographic protocols enable secure computation and communication in the presence of adversaries. Zero-knowledge proofs allow one party to prove knowledge of a secret without revealing the secret itself. Secure multi-party computation lets parties compute a joint function on their private inputs without revealing those inputs. These protocols rely on deep mathematical foundations in number theory, complexity theory, and probability.

Definitions

  • Zero-Knowledge Proof: An interactive protocol where a prover \(P\) convinces a verifier \(V\) that a statement is true, without revealing any information beyond the truth of the statement.
  • Commitment Scheme: A two-phase protocol (commit, reveal) where a sender binds to a value without revealing it, then can later reveal the value.
  • Oblivious Transfer: A protocol where a sender transfers one of several messages to a receiver, but remains oblivious as to which message was received.
  • Homomorphic Encryption: An encryption scheme where operations on ciphertexts correspond to operations on plaintexts: \(E(a) \oplus E(b) = E(a + b)\).
  • Simulator: A probabilistic polynomial-time algorithm that generates transcripts indistinguishable from real protocol executions.

Theorem: The Schnorr Protocol is Honest-Verifier Zero-Knowledge

Theorem: The Schnorr protocol for proving knowledge of a discrete logarithm is:

  1. Complete: If the prover knows the witness, the verifier always accepts.
  2. Sound: A cheating prover can only succeed with negligible probability.
  3. Honest-Verifier Zero-Knowledge: There exists a simulator that, given the challenge, produces transcripts indistinguishable from real protocol runs.

Proof Sketch (Zero-Knowledge Property)

The Schnorr protocol proves knowledge of \(x\) such that \(y = g^x \pmod{p}\):

  1. Prover sends commitment \(t = g^r\) for random \(r\)
  2. Verifier sends challenge \(c\)
  3. Prover responds with \(s = r + cx\)
  4. Verifier checks \(g^s = t \cdot y^c\)

The simulator, knowing \(c\) in advance, picks random \(s\) and sets \(t = g^s / y^c\). The transcript \((t, c, s)\) has the same distribution as a real execution.

Notation Guide

  • \(G = \langle g \rangle\) — Cyclic group of prime order \(q\)
  • \(y = g^x\) — Public key, witness is discrete log \(x\)
  • \(\Sigma\)-protocol — Three-move honest-verifier ZK proof
  • \(\text{Com}(m; r)\) — Commitment to message \(m\) with randomness \(r\)
  • \(\text{Sim}\) — Simulator algorithm
  • \(\approx_c\) — Computationally indistinguishable

import hashlib
import secrets
from typing import Tuple, Optional

class SchnorrProtocol:
    """
    Schnorr protocol for proving knowledge of discrete logarithm.
    Proves knowledge of x such that y = g^x mod p, without revealing x.
    """
    def __init__(self, p: int, q: int, g: int):
        """
        Args:
            p: Large prime (modulus)
            q: Prime order of subgroup (q | p-1)
            g: Generator of subgroup of order q
        """
        self.p = p
        self.q = q
        self.g = g
    
    def _mod_exp(self, base: int, exp: int, mod: int) -> int:
        """Compute (base^exp) mod mod efficiently."""
        return pow(base, exp, mod)
    
    def generate_keypair(self) -> Tuple[int, int]:
        """Generate (private_key, public_key) pair."""
        x = secrets.randbelow(self.q)  # Private key
        y = self._mod_exp(self.g, x, self.p)  # Public key
        return x, y
    
    def prover_commit(self) -> Tuple[int, int]:
        """
        Prover's first message: commitment.
        Returns (r, t) where t = g^r mod p.
        """
        r = secrets.randbelow(self.q)  # Random nonce
        t = self._mod_exp(self.g, r, self.p)
        return r, t
    
    def verifier_challenge(self) -> int:
        """Verifier generates random challenge."""
        return secrets.randbelow(self.q)
    
    def prover_response(self, r: int, x: int, c: int) -> int:
        """
        Prover computes response s = r + c*x mod q.
        """
        return (r + c * x) % self.q
    
    def verifier_check(self, y: int, t: int, c: int, s: int) -> bool:
        """
        Verifier checks that g^s = t * y^c mod p.
        """
        lhs = self._mod_exp(self.g, s, self.p)
        rhs = (t * self._mod_exp(y, c, self.p)) % self.p
        return lhs == rhs
    
    def simulate_transcript(self, y: int, c: Optional[int] = None) -> Tuple[int, int, int]:
        """
        Simulator for honest-verifier zero-knowledge.
        Given challenge c (or random), produces indistinguishable transcript.
        """
        if c is None:
            c = secrets.randbelow(self.q)
        
        # Pick random s, then set t = g^s / y^c
        s = secrets.randbelow(self.q)
        y_c_inv = self._mod_exp(y, self.q - c, self.p)  # y^{-c} = y^{q-c}
        t = (self._mod_exp(self.g, s, self.p) * y_c_inv) % self.p
        
        return t, c, s


class PedersenCommitment:
    """
    Pedersen commitment scheme: information-theoretically hiding,
    computationally binding.
    """
    def __init__(self, p: int, q: int, g: int, h: int):
        """
        h = g^a for secret a (discrete log of h base g must be unknown).
        """
        self.p = p
        self.q = q
        self.g = g
        self.h = h
    
    def commit(self, m: int) -> Tuple[int, int]:
        """
        Commit to message m.
        Returns (r, C) where C = g^m * h^r mod p.
        """
        r = secrets.randbelow(self.q)
        C = (pow(self.g, m, self.p) * pow(self.h, r, self.p)) % self.p
        return r, C
    
    def verify(self, C: int, m: int, r: int) -> bool:
        """Verify that C is a commitment to m with opening r."""
        C_expected = (pow(self.g, m, self.p) * pow(self.h, r, self.p)) % self.p
        return C == C_expected
    
    def homomorphic_add(self, C1: int, C2: int) -> int:
        """
        Pedersen commitments are additively homomorphic:
        Com(m1; r1) * Com(m2; r2) = Com(m1+m2; r1+r2)
        """
        return (C1 * C2) % self.p

Mathematical Oncology: Modeling Cancer Dynamics and Treatment

mathematical-oncology

Motivation

Mathematical oncology applies quantitative methods to understand cancer initiation, progression, and treatment. Models range from differential equations describing tumor growth to stochastic processes capturing mutation accumulation and agent-based simulations of cellular interactions. These models help predict treatment outcomes, optimize therapy schedules, and understand mechanisms of resistance.

Definitions

  • Tumor Growth Models: Gompertz, logistic, and exponential growth models describing tumor volume dynamics.
  • Pharmacokinetics/Pharmacodynamics (PK/PD): Models relating drug dose to concentration (PK) and concentration to effect (PD).
  • Clonal Evolution: The process by which genetic heterogeneity arises through mutation and selection in tumors.
  • Tumor-Immune Interaction: Models describing the interplay between cancer cells and the immune system.
  • Angiogenesis: The formation of new blood vessels enabling tumor growth beyond diffusion limits.

Theorem: Norton-Simon Hypothesis and Dose Density

Theorem (Norton-Simon, 1970s): For tumors following Gompertzian growth, the rate of tumor regression is proportional to the rate of growth at the same tumor size. Mathematically: \[\frac{dV}{dt} = -k \cdot f(V) \quad \text{under treatment}\] where \(f(V)\) is the growth function. This implies that chemotherapy is most effective when tumors are growing fastest (smaller sizes), supporting dose-dense treatment strategies.

Proof Sketch

The Gompertz model describes tumor volume \(V(t)\) as: \[\frac{dV}{dt} = \alpha V \log\left(\frac{K}{V}\right)\] where \(K\) is carrying capacity. The Norton-Simon hypothesis assumes treatment kills a fraction of cells proportional to the growth rate. This leads to the prediction that frequent (dense) dosing at smaller tumor sizes is more effective than the same total dose given less frequently at larger sizes—a principle validated in clinical trials for breast cancer.

Notation Guide

  • \(V(t)\) — Tumor volume at time \(t\)
  • \(K\) — Carrying capacity (maximum possible tumor size)
  • \(\alpha, \beta\) — Growth and regression rate parameters
  • \(C(t)\) — Drug concentration
  • \(E_{max}\) — Maximum drug effect
  • \(EC_{50}\) — Drug concentration for half-maximal effect
  • \(N(t)\) — Number of cancer cells
  • \(T(t)\) — Immune cell population

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

class TumorGrowthModels:
    """Classical models of tumor growth dynamics."""
    
    @staticmethod
    def exponential_growth(N0: float, r: float, t: np.ndarray) -> np.ndarray:
        """Exponential growth: dN/dt = rN."""
        return N0 * np.exp(r * t)
    
    @staticmethod
    def logistic_growth(N0: float, K: float, r: float, t: np.ndarray) -> np.ndarray:
        """Logistic growth: dN/dt = rN(1 - N/K)."""
        return K / (1 + ((K - N0) / N0) * np.exp(-r * t))
    
    @staticmethod
    def gompertz_growth(N0: float, K: float, alpha: float, t: np.ndarray) -> np.ndarray:
        """
        Gompertz growth: dN/dt = alpha * N * log(K/N).
        Most widely used for solid tumors.
        """
        return K * np.exp(np.log(N0 / K) * np.exp(-alpha * t))
    
    @staticmethod
    def bertalanffy_growth(N0: float, alpha: float, beta: float, t: np.ndarray) -> np.ndarray:
        """
        von Bertalanffy growth: dN/dt = alpha * N^(2/3) - beta * N.
        Based on metabolic considerations.
        """
        # Approximate numerical solution
        def dN_dt(N, t):
            if N <= 0:
                return 0
            return alpha * (N ** (2/3)) - beta * N
        
        return odeint(dN_dt, N0, t).flatten()


class TreatmentModels:
    """Models for treatment effects on tumors."""
    
    @staticmethod
    def log_kill_model(N0: float, r: float, k: float, dose_times: list, 
                       t_max: float, dt: float = 0.1) -> tuple:
        """
        Log-kill model: each dose kills a constant fraction of cells.
        dN/dt = rN - k * N * sum(deltas at dose times)
        """
        t = np.arange(0, t_max, dt)
        N = np.zeros_like(t)
        N[0] = N0
        
        for i in range(1, len(t)):
            growth = r * N[i-1] * dt
            kill = 0
            if any(abs(t[i] - d) < dt/2 for d in dose_times):
                kill = k * N[i-1]  # Instant kill at dose time
            N[i] = N[i-1] + growth - kill
            if N[i] < 1:  # Minimum cell count
                N[i] = 1
        
        return t, N
    
    @staticmethod
    def norton_simon_gompertz(N0: float, K: float, alpha: float, 
                              treatment_times: list, efficacy: float,
                              t_max: float, dt: float = 0.1) -> tuple:
        """
        Norton-Simon model with Gompertz growth.
        Treatment effect proportional to growth rate.
        """
        t = np.arange(0, t_max, dt)
        N = np.zeros_like(t)
        N[0] = N0
        
        for i in range(1, len(t)):
            if N[i-1] <= 0:
                N[i] = 0
                continue
            
            # Gompertz growth rate
            growth_rate = alpha * N[i-1] * np.log(K / N[i-1])
            
            # Treatment effect (proportional to growth rate)
            treatment_effect = 0
            if any(abs(t[i] - tt) < dt/2 for tt in treatment_times):
                treatment_effect = efficacy * growth_rate
            
            dN = (growth_rate - treatment_effect) * dt
            N[i] = max(1, N[i-1] + dN)
        
        return t, N


class TumorImmuneModel:
    """
    Kuznetsov-Taylor model of tumor-immune interactions.
    """
    def __init__(self, alpha: float = 1.636, beta: float = 0.002,
                 gamma: float = 0.3743, delta: float = 0.3743,
                 mu: float = 0.00311, nu: float = 1):
        """
        Parameters for tumor (N) and immune (T) cells.
        """
        self.alpha = alpha  # Tumor growth rate
        self.beta = beta    # Tumor death by immune cells
        self.gamma = gamma  # Immune cell recruitment
        self.delta = delta  # Immune cell death
        self.mu = mu        # Immune cell inhibition by tumor
        self.nu = nu        # Baseline immune cell source
    
    def dynamics(self, state: np.ndarray, t: float) -> np.ndarray:
        """
        System of ODEs:
        dN/dt = alpha*N - beta*N*T
        dT/dt = gamma*N*T/(N + nu) - delta*T - mu*N*T
        """
        N, T = state
        if N < 0:
            N = 0
        if T < 0:
            T = 0
        
        dN = self.alpha * N - self.beta * N * T
        dT = self.gamma * N * T / (N + self.nu) - self.delta * T - self.mu * N * T
        
        return np.array([dN, dT])
    
    def simulate(self, N0: float, T0: float, t: np.ndarray) -> np.ndarray:
        """Simulate the tumor-immune system."""
        return odeint(self.dynamics, [N0, T0], t)

Srinivasa Ramanujan: The Man Who Knew Infinity

ramanujan

Historical Context

Srinivasa Ramanujan (1887–1920) was an Indian mathematical prodigy who, with almost no formal training, made extraordinary contributions to number theory, infinite series, and continued fractions. Growing up in Kumbakonam, Tamil Nadu, Ramanujan taught himself mathematics from a book by G.S. Carr. His genius was recognized by G.H. Hardy at Cambridge, leading to a legendary collaboration. Ramanujan's notebooks, filled with thousands of results without proofs, continue to inspire mathematicians today.

Definitions

  • Ramanujan Prime: The smallest integer \(R_n\) such that there are at least \(n\) primes between \(x/2\) and \(x\) for all \(x \geq R_n\).
  • Ramanujan Theta Function: \(f(a, b) = \sum_{n=-\infty}^{\infty} a^{n(n+1)/2} b^{n(n-1)/2}\), generalizing the Jacobi theta functions.
  • Mock Theta Functions: A class of q-series introduced by Ramanujan in his last letter to Hardy, now understood as holomorphic parts of harmonic Maass forms.
  • Taxicab Numbers: The smallest number expressible as the sum of two positive cubes in \(n\) distinct ways. \(1729 = 1^3 + 12^3 = 9^3 + 10^3\) is the famous Hardy-Ramanujan number.

Theorem: The Rogers-Ramanujan Identities

Theorem: The following identities hold: \[\sum_{n=0}^{\infty} \frac{q^{n^2}}{(1-q)(1-q^2)\cdots(1-q^n)} = \prod_{n=0}^{\infty} \frac{1}{(1-q^{5n+1})(1-q^{5n+4})}\] \[\sum_{n=0}^{\infty} \frac{q^{n^2+n}}{(1-q)(1-q^2)\cdots(1-q^n)} = \prod_{n=0}^{\infty} \frac{1}{(1-q^{5n+2})(1-q^{5n+3})}\]

Proof Sketch

The Rogers-Ramanujan identities have been proved in many ways: Rogers using q-series transformations, Schur via combinatorial arguments (partition identities), and Baxter in statistical mechanics (hard hexagon model). Modern proofs use vertex operator algebras and the theory of infinite-dimensional Lie algebras. The identities connect partition theory, modular forms, and exactly solvable models in physics.

Fermat's Last Theorem: From Marginal Note to Millennium

fermats-last-theorem

Historical Context

In 1637, Pierre de Fermat wrote in the margin of his copy of Diophantus's Arithmetica: "I have discovered a truly marvelous proof of this, which this margin is too narrow to contain." The theorem states that no three positive integers \(a, b, c\) satisfy \(a^n + b^n = c^n\) for any integer \(n > 2\). For 358 years, this remained the most famous unsolved problem in mathematics, until Andrew Wiles announced a proof in 1993, completed in 1995.

Definitions

  • Fermat Equation: \(x^n + y^n = z^n\) for integers \(n \geq 3\).
  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point, given by an equation \(y^2 = x^3 + ax + b\).
  • Modular Form: A holomorphic function on the upper half-plane satisfying specific transformation properties under the modular group.
  • Taniyama-Shimura Conjecture: Every elliptic curve over \(\mathbb{Q}\) is modular (admits a modular parametrization).
  • Galois Representation: A representation of the absolute Galois group on the torsion points of an elliptic curve.

Theorem: Fermat's Last Theorem (Wiles, 1995)

Theorem: For any integer \(n > 2\), there exist no positive integers \(a, b, c\) such that: \[a^n + b^n = c^n\]

Proof Sketch (Frey-Ribet-Wiles Strategy)

The proof follows a strategy proposed by Frey and Ribet:

  1. Frey's Construction: Assume a solution \(a^p + b^p = c^p\) exists for prime \(p \geq 5\). Construct the Frey elliptic curve: \[y^2 = x(x - a^p)(x + b^p)\]
  2. Ribet's Theorem: If the Taniyama-Shimura conjecture holds, then the Frey curve cannot be modular (its associated Galois representation is too wild).
  3. Wiles's Theorem: Prove that every semistable elliptic curve over \(\mathbb{Q}\) is modular.
  4. Contradiction: The Frey curve is semistable, so it must be modular. Contradiction! Therefore, no solution exists.

Notation Guide

  • \(E[p]\) — p-torsion points of elliptic curve \(E\)
  • \(\rho_{E,p}: G_\mathbb{Q} \to \text{GL}_2(\mathbb{F}_p)\) — Galois representation on p-torsion
  • \(f_E\) — Modular form associated to elliptic curve \(E\)
  • \(\mathbb{T}\) — Hecke algebra acting on modular forms
  • \(\mathcal{R}\) — Universal deformation ring of a Galois representation

        Returns coefficients (A, B) for short Weierstrass form y^2 = x^3 + Ax + B.

        y^2 = x(x - a^p)(x + b^p)

        ap, bp = a ** p, b ** p

        B = -ap * bp

Galois Theory: The Mathematics of Symmetry in Equations

galois-theory

Historical Context

Évariste Galois (1811–1832) developed the theory that now bears his name during his teens, scribbling his discoveries in a letter the night before his fatal duel at age 20. Galois theory establishes a profound connection between field extensions and group theory, providing a criterion for when polynomial equations can be solved by radicals. It resolved centuries-old questions about solvability of equations and laid the foundation for modern abstract algebra.

Definitions

  • Field Extension: A pair of fields \(F \subseteq E\) where the operations of \(F\) are restrictions of those in \(E\). Denoted \(E/F\).
  • Galois Group: For a field extension \(E/F\), \(\text{Gal}(E/F) = \{\sigma \in \text{Aut}(E) : \sigma|_F = \text{id}_F\}\).
  • Splitting Field: The smallest field extension containing all roots of a polynomial.
  • Normal Extension: An algebraic extension where every irreducible polynomial with one root in the extension splits completely.
  • Separable Extension: An algebraic extension where every element has a separable minimal polynomial (distinct roots).
  • Galois Extension: An extension that is both normal and separable.

Theorem: The Fundamental Theorem of Galois Theory

Theorem: Let \(E/F\) be a finite Galois extension with Galois group \(G = \text{Gal}(E/F)\). There is an inclusion-reversing bijection between:

  • Intermediate fields \(F \subseteq K \subseteq E\)
  • Subgroups \(H \leq G\)

Given by \(K \mapsto \text{Gal}(E/K)\) and \(H \mapsto E^H\) (the fixed field). Moreover:

  • \([E:K] = |\text{Gal}(E/K)|\) and \([K:F] = [G : \text{Gal}(E/K)]\)
  • \(K/F\) is Galois iff \(\text{Gal}(E/K) \trianglelefteq G\)
  • In this case, \(\text{Gal}(K/F) \cong G / \text{Gal}(E/K)\)

Proof Sketch

The proof proceeds in several stages:

  1. Show that for any subgroup \(H\), \([E : E^H] = |H|\) (Artin's theorem).
  2. Prove that the maps are inverses: \(\text{Gal}(E/E^H) = H\) and \(E^{\text{Gal}(E/K)} = K\).
  3. Establish the normality correspondence via the property that conjugate subgroups correspond to conjugate intermediate fields.
  4. The isomorphism for Galois subextensions follows from the restriction homomorphism.

Notation Guide

  • \([E:F]\) — Degree of field extension (dimension as vector space)
  • \(E^H = \{x \in E : \sigma(x) = x \text{ for all } \sigma \in H\}\) — Fixed field
  • \(F(\alpha)\) — Field obtained by adjoining \(\alpha\) to \(F\)
  • \(\text{Aut}(E)\) — Group of field automorphisms of \(E\)
  • \(H \trianglelefteq G\) — Normal subgroup

from fractions import Fraction
import itertools

class GaloisTheory:
    """
    Computational explorations of Galois theory concepts.
    Working with simple extensions and small degree polynomials.
    """
    
    @staticmethod
    def cyclotomic_polynomial(n: int, max_coeff: int = 100) -> List[int]:
        """
        Compute the n-th cyclotomic polynomial Φ_n(x).
        Φ_n(x) = ∏_{1≤k≤n, gcd(k,n)=1} (x - ζ_n^k)
        where ζ_n = e^{2πi/n} is a primitive n-th root of unity.
        """
        def mobius(n: int) -> int:
            if n == 1:
                return 1
            factors = []
            d = 2
            temp = n
            while d * d <= temp:
                while temp % d == 0:
                    factors.append(d)
                    temp //= d
                d += 1
            if temp > 1:
                factors.append(temp)
            if len(factors) != len(set(factors)):
                return 0
            return (-1) ** len(factors)
        
        # Φ_n(x) = ∏_{d|n} (x^d - 1)^μ(n/d)
        # We compute this by polynomial multiplication/division
        
        # Start with x^n - 1
        result = [0] * (n + 1)
        result[0] = -1
        result[n] = 1
        
        divisors = [d for d in range(1, n) if n % d == 0]
        
        for d in divisors:
            mu = mobius(n // d)
            if mu == -1:
                # Divide by (x^d - 1)
                divisor = [0] * (d + 1)
                divisor[0] = -1
                divisor[d] = 1
                result = GaloisTheory._poly_div(result, divisor)
            elif mu == 1:
                # Multiply by (x^d - 1)
                poly = [0] * (d + 1)
                poly[0] = -1
                poly[d] = 1
                result = GaloisTheory._poly_mul(result, poly)
        
        return result
    
    @staticmethod
    def _poly_mul(p1: List[int], p2: List[int]) -> List[int]:
        """Multiply two polynomials."""
        result = [0] * (len(p1) + len(p2) - 1)
        for i, c1 in enumerate(p1):
            for j, c2 in enumerate(p2):
                result[i + j] += c1 * c2
        return result
    
    @staticmethod
    def _poly_div(dividend: List[int], divisor: List[int]) -> List[int]:
        """Simplified polynomial division (for special cases)."""
        # This is a simplified version for cyclotomic polynomial computation
        result = dividend.copy()
        d = len(divisor) - 1
        for i in range(len(result) - 1, d - 1, -1):
            if result[i] != 0:
                factor = result[i]
                for j in range(d + 1):
                    result[i - j] -= factor * divisor[d - j]
        return result[:d]

        """
        Generate all permutations of n elements (the symmetric group S_n).
        """
        return list(itertools.permutations(range(n)))

        """
        Generate the alternating group A_n (even permutations).
        """
        def sign(perm: Tuple[int, ...]) -> int:
            """Compute the sign of a permutation."""
            inversions = 0
            for i in range(len(perm)):
                for j in range(i + 1, len(perm)):
                    if perm[i] > perm[j]:
                        inversions += 1
            return (-1) ** inversions
        
        return [p for p in GaloisTheory.symmetric_group_sn(n) if sign(p) == 1]

    def quadratic_field_discriminant(d: int) -> int:

        Discriminant of Q(√d).
        For Q(√d), the discriminant is:
        - d if d ≡ 1 (mod 4)
        - 4d if d ≡ 2,3 (mod 4)
        """
        d_squarefree = GaloisTheory._squarefree_part(d)
        if d_squarefree % 4 == 1:
            return d_squarefree
        else:
            return 4 * d_squarefree

        n = n if n >= 0 else -n
        result = 1

        """

    @staticmethod

        The Galois group of the n-th cyclotomic field Q(ζ_n)/Q.
        Gal(Q(ζ_n)/Q) ≅ (Z/nZ)^×
        """
        def euler_phi(n: int) -> int:
            """Euler's totient function."""
            result = n

📜 Math History: Emmy Noether — The Mother of Modern Algebra

emmy-noether

Amalie Emmy Noether (1882–1935) transformed the landscape of mathematics in the 20th century, earning recognition as the most important woman in the history of mathematics. Born into a Jewish family in Erlangen, Germany, she initially faced institutional barriers that prevented women from formally enrolling in university. Undeterred, Noether audited classes and eventually earned her doctorate in 1907 under Paul Gordan, completing a dissertation on invariant theory.

Noether's true revolution began when she moved to Göttingen in 1915 at the invitation of David Hilbert and Felix Klein. Despite resistance from university administrators who questioned the propriety of a female lecturer, she delivered lectures advertised under Hilbert's name. Her work during this period included two theorems that would become foundational for theoretical physics. The first Noether theorem established that every differentiable symmetry of the action of a physical system corresponds to a conservation law—connecting symmetries to conserved quantities like energy and momentum.

But it was in abstract algebra that Noether left her most enduring mark. She shifted the focus of algebra from computational manipulation of equations to the study of abstract structures. Her 1921 paper "Idealtheorie in Ringbereichen" (Theory of Ideals in Ring Domains) established the foundation of modern commutative ring theory, introducing the ascending chain condition that now defines Noetherian rings. This abstraction revealed deep connections between algebra, geometry, and number theory.

Noether's approach was revolutionary: rather than studying specific examples, she identified the essential properties that made theorems work. Her students and collaborators—including Bartel van der Waerden, whose "Moderne Algebra" codified her approach—spread her vision throughout the mathematical world. The "Noether school" at Göttingen became the center of algebraic research, attracting mathematicians from around the globe.

The rise of Nazi Germany forced Noether's emigration in 1933. She found refuge at Bryn Mawr College in Pennsylvania, where she continued teaching and research until her sudden death in 1935 from complications following surgery. Einstein wrote to the New York Times: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began."

Noether's legacy extends far beyond her theorems. She demonstrated that abstraction, properly wielded, reveals rather than obscures mathematical truth. Her emphasis on structures and mappings rather than calculations became the defining characteristic of 20th-century mathematics, influencing fields from algebraic topology to category theory. Today, the term "Noetherian" appears in virtually every branch of mathematics—a testament to the ubiquity of her vision.

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics, discovered by Benoit Mandelbrot in 1980. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set.

The visualization below uses escape-time coloring: points that escape to infinity are colored based on how quickly they escape, while points in the set are colored black.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c: complex, max_iter: int = 100) -> int:
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point is in (or appears to be in) the set.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z * z + c
    return max_iter

def mandelbrot_set(xmin: float = -2.5, xmax: float = 1.0,
                   ymin: float = -1.25, ymax: float = 1.25,
                   width: int = 800, height: int = 800,
                   max_iter: int = 100) -> np.ndarray:
    """
    Compute the Mandelbrot set over a rectangular region.
    
    Args:
        xmin, xmax: Range of real parts
        ymin, ymax: Range of imaginary parts
        width, height: Resolution
        max_iter: Maximum iterations per point
    
    Returns:
        2D array of iteration counts
    """
    # Create coordinate grids
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j * Y
    
    # Vectorized computation for efficiency
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask] ** 2 + C[mask]
        mask_new = abs(Z) < 2
        M[~mask_new & (M == 0)] = i
        mask = mask_new
    
    M[mask] = max_iter
    return M
