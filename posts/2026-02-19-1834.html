Morse Theory: Topology Through Critical Points

morse-theory

Motivation

How can we understand the shape of a mountain by studying its peaks, passes, and valleys? Morse theory, developed by Marston Morse in the 1920s, provides a profound connection between the critical points of smooth functions on a manifold and the topology of that manifold. This theory allows us to decompose complex spaces into simpler pieces (handles), compute topological invariants like Betti numbers, and prove deep results such as the existence of exotic spheres. Applications range from the study of geodesics in Riemannian geometry to the topology of Lie groups and symmetric spaces.

Definitions

  • Morse Function: A smooth function \(f: M \to \mathbb{R}\) on a manifold where all critical points are non-degenerate (the Hessian is non-singular).
  • Critical Point: A point \(p \in M\) where \(df_p = 0\), meaning all partial derivatives vanish.
  • Hessian: At a critical point \(p\), the Hessian is the symmetric bilinear form \(H_f(X, Y) = X(Y(f))\) on \(T_p M\).
  • Index of a Critical Point: The number of negative eigenvalues of the Hessian, counting the dimension of the "downward" directions.
  • Morse Lemma: Near a non-degenerate critical point of index \(k\), there exist coordinates where \(f = f(p) - x_1^2 - \cdots - x_k^2 + x_{k+1}^2 + \cdots + x_n^2\).
  • Sublevel Set: \(M^a = f^{-1}((-\infty, a])\), the region where \(f \leq a\).

Theorem: The Morse Inequalities

Theorem (Weak Morse Inequalities): Let \(f\) be a Morse function on a compact manifold \(M\) with \(c_k\) critical points of index \(k\). Let \(b_k = \dim H_k(M; \mathbb{R})\) be the Betti numbers. Then:

\[c_k \geq b_k \quad \text{for all } k\]

Theorem (Strong Morse Inequalities): For all \(m\):

\[\sum_{k=0}^{m} (-1)^{m-k} c_k \geq \sum_{k=0}^{m} (-1)^{m-k} b_k\]

with equality when \(m = n = \dim M\):

\[\sum_{k=0}^{n} (-1)^k c_k = \chi(M)\]

where \(\chi(M)\) is the Euler characteristic.

Proof Sketch

The proof analyzes how the topology of sublevel sets \(M^a\) changes as \(a\) crosses critical values. By the Morse lemma, passing a critical point of index \(k\) attaches a \(k\)-handle \(D^k \times D^{n-k}\) to the boundary. This changes the homology by adding a generator to \(H_k\) (and possibly removing one from \(H_{k-1}\) via the boundary map). The inequalities follow from comparing the number of handles to the dimensions of homology groups.

Notation Guide

  • \(M\): Smooth manifold
  • \(f: M \to \mathbb{R}\): Morse function
  • \(\text{Crit}(f)\): Set of critical points of \(f\)
  • \(\text{ind}(p)\): Index of critical point \(p\)
  • \(H_k(M)\): \(k\)-th homology group
  • \(b_k = \dim H_k(M)\): \(k\)-th Betti number
  • \(c_k\): Number of critical points of index \(k\)
  • \(M^a = f^{-1}((-\infty, a])\): Sublevel set
  • \(\chi(M) = \sum (-1)^k b_k\): Euler characteristic

Model Theory: Mathematical Logic Meets Algebra

model-theory

Motivation

What makes the real numbers special among all ordered fields? Model theory, a branch of mathematical logic, studies mathematical structures through the lens of the sentences that are true in them. It provides powerful tools to transfer results between different structures, classify theories by their complexity, and prove surprising connections between algebra and logic. Applications include Ax-Kochen's solution to Artin's conjecture on p-adic fields, Hrushovski's proof of the Mordell-Lang conjecture for function fields, and the development of o-minimal structures that tame wild geometric behavior.

Definitions

  • First-Order Language: A collection of symbols including constants, function symbols, relation symbols, logical connectives (\(\neg, \wedge, \vee, \to\)), quantifiers (\(\forall, \exists\)), and variables.
  • Structure: A set (universe) equipped with interpretations of the symbols in a given language.
  • Theory: A consistent set of sentences (formulas with no free variables) in a given language.
  • Model: A structure in which all sentences of a theory are true. We write \(M \models T\).
  • Elementary Equivalence: Structures \(M\) and \(N\) are elementarily equivalent (\(M \equiv N\)) if they satisfy the same sentences.
  • Elementary Substructure: \(M\) is an elementary substructure of \(N\) (\(M \prec N\)) if \(M \subseteq N\) and for all formulas \(\phi\) and all \(a \in M\): \(M \models \phi(a) \Leftrightarrow N \models \phi(a)\).
  • Quantifier Elimination: A theory has quantifier elimination if every formula is equivalent to a quantifier-free formula.

Theorem: The Compactness Theorem

Theorem (Compactness): A theory \(T\) has a model if and only if every finite subset of \(T\) has a model.

Corollary (Upward Löwenheim-Skolem): If a theory \(T\) has an infinite model, then it has models of every infinite cardinality.

Corollary (Downward Löwenheim-Skolem): If a theory \(T\) has an infinite model, then it has a countable model.

Theorem (Ax-Kochen): For each \(d \geq 1\), there exists \(p_0 = p_0(d)\) such that for all primes \(p > p_0\): every homogeneous polynomial of degree \(d\) over \(\mathbb{Q}_p\) in more than \(d^2\) variables has a nontrivial zero.

Proof Sketch (Compactness)

The compactness theorem follows from Gödel's completeness theorem: a theory is consistent (has no proof of contradiction) if and only if it has a model. Since proofs are finite, if every finite subset of \(T\) is consistent, then \(T\) itself is consistent, hence has a model. The Löwenheim-Skolem theorems follow by constructing models via Skolem functions or using the omitting types theorem.

Notation Guide

  • \(\mathcal{L}\): First-order language
  • \(M, N\): Structures (models)
  • \(|M|\): Universe (underlying set) of \(M\)
  • \(M \models \phi\): Structure \(M\) satisfies formula \(\phi\)
  • \(M \equiv N\): Elementary equivalence
  • \(M \prec N\): Elementary substructure
  • \(\text{Th}(M)\): Theory of \(M\) (all sentences true in \(M\))
  • \(\text{Diag}(M)\): Diagram of \(M\) (atomic diagram)
  • \(\text{acl}(A)\): Algebraic closure of set \(A\)

from itertools import product

def evaluate_propositional(formula, assignment):
    """
    Evaluate a simple propositional formula.
    Formula is a nested tuple: ('not', A), ('and', A, B), ('or', A, B), ('implies', A, B)
    or a variable name string.
    """
    if isinstance(formula, str):
        return assignment.get(formula, False)
    
    op = formula[0]
    if op == 'not':
        return not evaluate_propositional(formula[1], assignment)
    elif op == 'and':
        return evaluate_propositional(formula[1], assignment) and \
               evaluate_propositional(formula[2], assignment)
    elif op == 'or':
        return evaluate_propositional(formula[1], assignment) or \
               evaluate_propositional(formula[2], assignment)
    elif op == 'implies':
        return (not evaluate_propositional(formula[1], assignment)) or \
               evaluate_propositional(formula[2], assignment)
    return False

def is_satisfiable(formula, variables):
    """Check if a formula is satisfiable using truth tables."""
    for assignment in product([False, True], repeat=len(variables)):
        assign_dict = dict(zip(variables, assignment))
        if evaluate_propositional(formula, assign_dict):
            return True, assign_dict
    return False, None

def compactness_check(theory, variables):
    """
    Demonstrate compactness: if every finite subset is satisfiable,
    the whole theory is satisfiable (for finite theories).
    """
    from itertools import combinations
    
    # Check all finite subsets
    n = len(theory)

        for subset in combinations(theory, size):
            sat, _ = is_satisfiable(('and', subset[0], subset[1]) if len(subset) == 2 
                                   else subset[0], variables)
            if not sat:
                return False, subset
    
    # Whole theory is satisfiable

    # Combine all formulas with 'and'
    combined = theory[0]
    for f in theory[1:]:
        combined = ('and', combined, f)
    
    sat, model = is_satisfiable(combined, variables)
    return sat, model

Lie Theory: Symmetry and Differential Equations

lie-theory

Motivation

How can we solve differential equations using symmetry? Lie theory, founded by Sophus Lie in the late 19th century, connects continuous symmetries (Lie groups) to infinitesimal symmetries (Lie algebras). This powerful framework unifies geometry, algebra, and analysis, providing systematic methods for solving differential equations, classifying symmetries of physical systems, and understanding the structure of continuous groups. Applications span particle physics (gauge theories), robotics (configuration spaces), computer graphics (rigid body motions), and control theory.

Definitions

  • Lie Group: A smooth manifold \(G\) that is also a group, where multiplication and inversion are smooth maps.
  • Lie Algebra: A vector space \(\mathfrak{g}\) equipped with a bilinear bracket \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) satisfying antisymmetry \([X, Y] = -[Y, X]\) and the Jacobi identity \([X, [Y, Z]] + [Y, [Z, X]] + [Z, [X, Y]] = 0\).
  • Exponential Map: \(\exp: \mathfrak{g} \to G\) connects the Lie algebra to the Lie group via the matrix exponential for matrix groups.
  • Adjoint Representation: \(\text{Ad}: G \to GL(\mathfrak{g})\) defined by \(\text{Ad}_g(X) = gXg^{-1}\) for matrix groups.
  • Structure Constants: For a basis \(\{T_a\}\) of \(\mathfrak{g}\), \([T_a, T_b] = f_{ab}^c T_c\) where \(f_{ab}^c\) are the structure constants.
  • Simple Lie Algebra: A non-abelian Lie algebra with no non-trivial ideals. The simple Lie algebras over \(\mathbb{C}\) are classified by Dynkin diagrams \(A_n, B_n, C_n, D_n, E_6, E_7, E_8, F_4, G_2\).

Theorem: The Lie Group-Lie Algebra Correspondence

Theorem: There is a one-to-one correspondence between:

  1. Connected, simply connected Lie groups
  2. Finite-dimensional Lie algebras over \(\mathbb{R}\)

Given a Lie algebra \(\mathfrak{g}\), there exists a unique (up to isomorphism) simply connected Lie group \(\tilde{G}\) with Lie algebra \(\mathfrak{g}\). Every connected Lie group with Lie algebra \(\mathfrak{g}\) is a quotient of \(\tilde{G}\) by a discrete central subgroup.

Baker-Campbell-Hausdorff Formula: For \(X, Y\) sufficiently small:

\[\exp(X)\exp(Y) = \exp\left(X + Y + \frac{1}{2}[X, Y] + \frac{1}{12}[X, [X, Y]] - \frac{1}{12}[Y, [X, Y]] + \cdots\right)\]

Proof Sketch

The correspondence is established via Ado's theorem (every finite-dimensional Lie algebra has a faithful finite-dimensional representation) and the construction of the universal covering group. For a Lie algebra \(\mathfrak{g}\), one constructs the simply connected group as the quotient of the free group on \(\mathfrak{g}\) by relations encoding the Baker-Campbell-Hausdorff formula. The BCH formula itself is derived by comparing the Taylor expansion of \(\log(\exp(tX)\exp(tY))\).

Notation Guide

  • \(G\): Lie group
  • \(\mathfrak{g}\): Lie algebra of \(G\)
  • \(e\): Identity element of \(G\)
  • \(T_e G\): Tangent space at identity (identified with \(\mathfrak{g}\))
  • \([X, Y]\): Lie bracket
  • \(\exp(X)\) or \(e^X\): Exponential map
  • \(\text{Ad}_g\): Adjoint action of \(g \in G\)
  • \(\text{ad}_X\): Adjoint action of \(X \in \mathfrak{g}\) (\(\text{ad}_X(Y) = [X, Y]\))
  • \(f_{ab}^c\): Structure constants

Inverse Problems: From Effects to Causes

inverse-problems

Motivation

Can we see inside the human body without surgery? Can we locate an earthquake's epicenter from seismic readings? These are inverse problems: given observed data, we seek to determine the causes that produced them. Unlike direct problems (cause → effect), inverse problems are often ill-posed—solutions may not exist, may not be unique, or may be unstable to data perturbations. Regularization techniques and Bayesian methods provide frameworks for obtaining stable, meaningful solutions. Applications include medical imaging (CT, MRI, PET), geophysics (seismic inversion), non-destructive testing, and climate reconstruction.

Definitions

  • Forward Operator: \(F: X \to Y\) maps unknown parameters \(x \in X\) to observed data \(y = F(x) + \eta\) where \(\eta\) represents noise.
  • Inverse Problem: Given \(y\), find \(x\) such that \(F(x) \approx y\).
  • Well-Posed Problem (Hadamard): A problem is well-posed if: (1) a solution exists, (2) the solution is unique, (3) the solution depends continuously on data.
  • Ill-Posed Problem: A problem failing any of Hadamard's conditions. Most inverse problems are ill-posed.
  • Tikhonov Regularization: Minimize \(\|F(x) - y\|^2 + \alpha \|x\|^2\) where \(\alpha > 0\) is a regularization parameter.
  • Singular Value Decomposition (SVD): For linear \(F = A\), write \(A = U\Sigma V^T\) and regularize by filtering small singular values.

Theorem: Picard's Condition and Regularization

Theorem (Picard Condition): For a compact linear operator \(A: X \to Y\) with SVD \(\{u_n, v_n, \sigma_n\}\), the equation \(Ax = y\) has a solution if and only if:

\[\sum_{n=1}^{\infty} \frac{|\langle y, u_n \rangle|^2}{\sigma_n^2} < \infty\]

Tikhonov Regularization: The regularized solution is:

\[x_\alpha = \sum_{n=1}^{\infty} \frac{\sigma_n}{\sigma_n^2 + \alpha} \langle y, u_n \rangle v_n\]

Discrepancy Principle: Choose \(\alpha\) such that \(\|Ax_\alpha - y\| = \delta\) where \(\delta\) is the noise level.

Proof Sketch

The Picard condition ensures the series converges in \(X\). For Tikhonov regularization, one minimizes the functional \(J(x) = \|Ax - y\|^2 + \alpha\|x\|^2\). Taking the derivative and setting to zero yields \((A^*A + \alpha I)x = A^*y\). Expanding in the SVD basis gives the stated formula. The filter \(\sigma_n/(\sigma_n^2 + \alpha)\) dampens contributions from small singular values where noise dominates.

Notation Guide

  • \(X, Y\): Hilbert spaces (parameter and data spaces)
  • \(F: X \to Y\): Forward operator
  • \(A\): Linear forward operator
  • \(\sigma_n\): Singular values (\(\sigma_1 \geq \sigma_2 \geq \cdots \geq 0\))
  • \(u_n, v_n\): Left and right singular vectors
  • \(\alpha\): Regularization parameter
  • \(\delta\): Noise level
  • \(x^\dagger\): Minimum norm solution (Moore-Penrose inverse)

import numpy as np
from scipy.linalg import svd
import matplotlib.pyplot as plt

def deconvolution_1d(y, kernel_size=20, alpha=0.01):
    """
    Solve 1D deconvolution inverse problem using Tikhonov regularization.
    
    Forward problem: y = A @ x + noise
    where A is a convolution matrix (blurring operator)
    """
    n = len(y)
    
    # Create convolution matrix (Gaussian blur)
    sigma = 3
    t = np.arange(-kernel_size//2, kernel_size//2 + 1)
    kernel = np.exp(-t**2 / (2*sigma**2))
    kernel = kernel / np.sum(kernel)
    
    # Build convolution matrix A
    A = np.zeros((n, n))
    for i in range(n):
        for j, k in enumerate(t):
            idx = i + k
            if 0 <= idx < n:
                A[i, idx] = kernel[j]
    
    # Tikhonov regularization: (A^T A + αI) x = A^T y
    ATA = A.T @ A
    rhs = A.T @ y
    
    # Solve regularized system
    x_reg = np.linalg.solve(ATA + alpha * np.eye(n), rhs)
    
    return x_reg, A, kernel

Uncertainty Quantification: Measuring the Unknown

uncertainty-quantification

Motivation

How confident should we be in our computational predictions? Uncertainty Quantification (UQ) provides rigorous frameworks for propagating input uncertainties through mathematical models to quantify output uncertainty. In an era of complex simulations—from climate models to aircraft design—understanding the reliability of predictions is crucial for decision-making under uncertainty. UQ combines probability theory, statistics, numerical analysis, and domain science to answer questions like: What is the probability of failure? Which inputs contribute most to output uncertainty? How much should we trust our model?

Definitions

  • Aleatoric Uncertainty: Irreducible uncertainty due to inherent randomness in the system (e.g., quantum fluctuations, thermal noise).
  • Epistemic Uncertainty: Reducible uncertainty due to lack of knowledge (e.g., insufficient data, model inadequacy).
  • Forward UQ: Given input uncertainty, determine output uncertainty: \(Y = f(X)\) where \(X\) is random.
  • Inverse UQ: Given observations, infer input uncertainty (Bayesian calibration).
  • Monte Carlo Sampling: Estimate statistics by sampling: \(E[f(X)] \approx \frac{1}{N}\sum_{i=1}^N f(X_i)\).
  • Polynomial Chaos: Expand random output in orthogonal polynomials: \(Y = \sum_{k=0}^{\infty} y_k \Psi_k(\xi)\) where \(\xi\) are standard random variables.
  • Sobol Indices: Measure sensitivity: \(S_i = \frac{\text{Var}(E[Y|X_i])}{\text{Var}(Y)}\) is the first-order sensitivity of input \(i\).

Theorem: Polynomial Chaos Convergence

Theorem (Cameron-Martin): Let \(Y = f(\xi)\) where \(\xi\) is a Gaussian random vector and \(f\) has finite variance. Then \(f\) has a convergent expansion:

\[f(\xi) = \sum_{\alpha \in \mathcal{J}} c_\alpha H_\alpha(\xi)\]

where \(\{H_\alpha\}\) are multidimensional Hermite polynomials and \(\mathcal{J}\) is the set of multi-indices.

Variance Decomposition: \(\text{Var}(Y) = \sum_{|\alpha| > 0} c_\alpha^2 \alpha!\)

Sobol-Hoeffding Decomposition: For independent inputs, the variance decomposes as:

\[\text{Var}(Y) = \sum_i V_i + \sum_{i

where \(V_i = \text{Var}(E[Y|X_i])\) and \(V_{ij} = \text{Var}(E[Y|X_i, X_j]) - V_i - V_j\).

Proof Sketch

The Cameron-Martin theorem follows from the completeness of Hermite polynomials in \(L^2(\mathbb{R}^n, \gamma)\) where \(\gamma\) is Gaussian measure. The variance decomposition uses orthogonality: \(E[H_\alpha H_\beta] = \alpha! \delta_{\alpha\beta}\). The Sobol decomposition follows from the ANOVA (Analysis of Variance) decomposition of functions on product spaces, using the fact that conditional expectations project onto subspaces.

  • \(X, Y\): Random variables (input, output)
  • \(\xi\): Standard random variable (e.g., \(\mathcal{N}(0,1)\))
  • \(H_n(x)\): Hermite polynomial of degree \(n\)
  • \(c_\alpha\): Polynomial chaos coefficients
  • \(\Psi_k(\xi)\): Orthogonal polynomial basis
  • \(S_i, S_{ij}, S_T\): First-order, second-order, total Sobol indices
  • \(\mu_Y, \sigma_Y^2\): Mean and variance of output

def hermite_probabilist(n, x):
    """Probabilist's Hermite polynomials He_n(x)."""
    if n == 0:
        return np.ones_like(x)
    elif n == 1:
        return x
    else:
        H_prev2 = np.ones_like(x)
        H_prev1 = x
        for k in range(2, n + 1):
            H_curr = x * H_prev1 - (k - 1) * H_prev2
            H_prev2 = H_prev1
            H_prev1 = H_curr
        return H_curr

def polynomial_chaos_1d(f, xi_samples, max_degree=5):
    """
    Estimate Polynomial Chaos coefficients for Y = f(ξ) where ξ ~ N(0,1).
    Uses Monte Carlo integration.
    """
    y_samples = f(xi_samples)
    
    coefficients = []
    for k in range(max_degree + 1):
        # c_k = E[f(ξ) * He_k(ξ)] / E[He_k(ξ)^2]
        # For probabilist's Hermite: E[He_k^2] = k!
        He_k = hermite_probabilist(k, xi_samples)
        c_k = np.mean(y_samples * He_k) / factorial(k)
        coefficients.append(c_k)
    
    return np.array(coefficients)

def sobol_first_order(f, x1_samples, x2_samples):
    """
    Estimate first-order Sobol index S_i using Saltelli's method.
    S_i = Var(E[Y|X_i]) / Var(Y)
    """
    n = len(x1_samples)
    
    # Evaluate function at different sample combinations
    y_A = f(x1_samples)  # Base sample
    y_B = f(x2_samples)  # Complementary sample
    
    # Mixed samples: replace X_i from B into A
    # For 1D case, this is just y_B
    y_AB = y_B
    
    # Estimate S_i
    var_y = np.var(y_A, ddof=1)
    
    # E[Var(Y|X_i^c)] ≈ (1/N) Σ y_A * (y_AB - y_B)
    # S_i = 1 - E[Var(Y|X_i^c)] / Var(Y)
    conditional_var = np.mean(y_A * (y_AB - y_B))
    S_i = conditional_var / var_y
    
    return S_i, var_y

Network Science: The Mathematics of Connections

network-science

Motivation

Why do some viruses spread rapidly while others die out? How does Google rank web pages? Network science studies complex systems as networks—collections of nodes connected by edges—to reveal universal patterns and principles. From social networks to protein interactions, power grids to the internet, networks underlie countless natural and artificial systems. Mathematical tools from graph theory, statistical physics, and dynamical systems help us understand network formation, evolution, robustness, and function. This interdisciplinary field bridges pure mathematics with applications in epidemiology, sociology, computer science, and biology.

Definitions

  • Complex Network: A graph with non-trivial topological features not seen in simple random graphs (e.g., heavy-tailed degree distribution, clustering, community structure).
  • Degree Distribution \(P(k)\): The probability that a randomly chosen node has degree \(k\).
  • Scale-Free Network: A network with power-law degree distribution \(P(k) \sim k^{-\gamma}\) where \(2 < \gamma < 3\).
  • Small-World Property: Networks where the average shortest path length scales logarithmically with network size: \(L \sim \log N\).
  • Clustering Coefficient: \(C = \frac{3 \times \text{number of triangles}}{\text{number of connected triples}}\), measuring local density.
  • Centrality Measures: Metrics for node importance—degree centrality, betweenness centrality, eigenvector centrality, PageRank.
  • Epidemic Threshold: The critical transmission rate \(\beta_c\) above which an epidemic spreads: \(\beta_c = \frac{\langle k \rangle}{\langle k^2 \rangle}\) for configuration model networks.

Theorem: The Molloy-Reed Criterion

Theorem (Molloy-Reed): A random graph with degree distribution \(P(k)\) has a giant component if and only if:

\[\langle k^2 \rangle - 2\langle k \rangle > 0\]

Equivalently, when the mean excess degree \(\frac{\langle k^2 \rangle}{\langle k \rangle} - 1 > 1\).

Epidemic Threshold: For the SIS (susceptible-infected-susceptible) model on a configuration model network, the epidemic threshold is:

\[\beta_c = \frac{\mu \langle k \rangle}{\langle k^2 \rangle}\]

where \(\mu\) is the recovery rate. For scale-free networks with \(\gamma \leq 3\), \(\langle k^2 \rangle \to \infty\) and \(\beta_c \to 0\), meaning epidemics can spread at arbitrarily low transmission rates.

Proof Sketch

The Molloy-Reed criterion is derived using generating functions. Let \(G_0(x) = \sum_k P(k) x^k\) be the degree generating function and \(G_1(x) = G_0'(x)/G_0'(1)\) the excess degree distribution. The average component size reachable from a random node is related to \(H_1(1)\) where \(H_1(x)\) satisfies a self-consistency equation. A giant component exists when the derivative of the self-consistency map exceeds 1 at the fixed point, giving the condition \(\langle k^2 \rangle - 2\langle k \rangle > 0\).

Notation Guide

  • \(G = (V, E)\): Graph with vertices \(V\) and edges \(E\)
  • \(N = |V|\): Number of nodes
  • \(M = |E|\): Number of edges
  • \(k_i\): Degree of node \(i\)
  • \(\langle k \rangle = \frac{1}{N}\sum_i k_i\): Average degree
  • \(\langle k^2 \rangle\): Second moment of degree distribution
  • \(P(k)\): Degree distribution
  • \(C\): Clustering coefficient
  • \(L\): Average shortest path length
  • \(\beta\): Infection rate (epidemic models)
  • \(\mu\): Recovery rate

import numpy as np
import networkx as nx

def barabasi_albert_graph(n, m, seed=None):
    """
    Generate a Barabási-Albert preferential attachment network.
    Scale-free network with P(k) ~ k^(-3).
    """
    if seed is not None:
        np.random.seed(seed)
    
    # Start with m nodes forming a complete graph
    G = nx.complete_graph(m)
    
    # Add remaining nodes with preferential attachment
    for new_node in range(m, n):
        # Calculate attachment probabilities (proportional to degree)
        degrees = np.array([G.degree(i) for i in G.nodes()])
        probs = degrees / np.sum(degrees)
        
        # Select m nodes to connect to
        targets = np.random.choice(G.nodes(), size=m, replace=False, p=probs)
        
        for target in targets:
            G.add_edge(new_node, target)
    
    return G

def network_metrics(G):
    """Compute key network metrics."""
    degrees = [d for n, d in G.degree()]
    
    metrics = {
        'N': G.number_of_nodes(),
        'M': G.number_of_edges(),
        'avg_degree': np.mean(degrees),
        'second_moment': np.mean(np.array(degrees)**2),
        'clustering': nx.average_clustering(G),
        'avg_path_length': nx.average_shortest_path_length(G) if nx.is_connected(G) else np.inf,
        'max_degree': max(degrees),
        'min_degree': min(degrees)
    }
    
    # Molloy-Reed criterion
    metrics['molloy_reed'] = metrics['second_moment'] - 2 * metrics['avg_degree']
    metrics['has_giant_component'] = metrics['molloy_reed'] > 0
    
    return metrics

def sis_epidemic_simulation(G, beta, mu, steps=1000, initial_infected=0.1):
    """
    Simulate SIS epidemic on network.
    Returns fraction of infected nodes over time.
    """
    N = G.number_of_nodes()
    
    # Initialize: random fraction initially infected
    infected = np.random.rand(N) < initial_infected
    
    infection_history = [np.mean(infected)]
    
    for _ in range(steps):
        new_infected = infected.copy()
        
        for node in G.nodes():
            if infected[node]:
                # Recovery
                if np.random.rand() < mu:
                    new_infected[node] = False
            else:
                # Infection from neighbors
                neighbors = list(G.neighbors(node))
                if len(neighbors) > 0:
                    infected_neighbors = sum(infected[n] for n in neighbors)
                    infection_prob = 1 - (1 - beta)**infected_neighbors
                    if np.random.rand() < infection_prob:
                        new_infected[node] = True
        
        infected = new_infected
        infection_history.append(np.mean(infected))
    
    return infection_history

Cohomology: Measuring Holes Algebraically

cohomology

Historical Context

Cohomology theory emerged in the 1930s as an algebraic tool to study topological spaces. While homology counts holes directly, cohomology organizes this information into a ring structure with a natural product operation—the cup product. This additional structure makes cohomology a finer invariant than homology. The theory was developed by Alexander, Kolmogorov, and Whitney, building on earlier work by Poincaré and Noether. Cohomology has become fundamental in algebraic topology, algebraic geometry (sheaf cohomology, étale cohomology), and mathematical physics (characteristic classes, gauge theory).

Definitions

  • Cochain Complex: A sequence of abelian groups \(\cdots \to C^{n-1} \xrightarrow{d^{n-1}} C^n \xrightarrow{d^n} C^{n+1} \to \cdots\) where \(d^n \circ d^{n-1} = 0\).
  • Coboundary Operator: The map \(d^n: C^n \to C^{n+1}\) satisfying \(d^2 = 0\).
  • Cocycles: \(Z^n = \ker(d^n)\), the cochains with zero coboundary.
  • Coboundaries: \(B^n = \text{im}(d^{n-1})\), the cochains that are coboundaries of lower-degree cochains.
  • Cohomology Group: \(H^n = Z^n / B^n\), measuring the failure of cocycles to be coboundaries.
  • Cup Product: \(\smile: H^p(X) \times H^q(X) \to H^{p+q}(X)\) gives cohomology a ring structure.
  • de Rham Cohomology: For smooth manifolds, \(H_{dR}^n(M)\) is the cohomology of the complex of differential forms with exterior derivative.

Theorem: de Rham's Theorem

Theorem (de Rham): For a smooth manifold \(M\), there is a natural isomorphism:

\[H_{dR}^n(M) \cong H^n(M; \mathbb{R})\]

between de Rham cohomology and singular cohomology with real coefficients. The isomorphism sends a closed form \(\omega\) to the cohomology class of the integration map \([\sigma] \mapsto \int_\sigma \omega\).

Poincaré Duality: For a closed, oriented \(n\)-manifold \(M\):

\[H^k(M; \mathbb{R}) \cong H_{n-k}(M; \mathbb{R})\]

or equivalently \(H^k(M) \cong H^{n-k}(M)\) via the cup product pairing.

Proof Sketch

de Rham's theorem is proved by constructing a chain map from the de Rham complex to the singular cochain complex via integration of forms over simplices. The key step is showing this induces an isomorphism on cohomology, using the Mayer-Vietoris sequence and the fact that both theories satisfy the same axioms (homotopy invariance, excision, dimension axiom). Poincaré duality follows from the existence of a fundamental class \([M] \in H_n(M)\) and the non-degeneracy of the cap product pairing.

Notation Guide

  • \(C^n(X; G)\): \(n\)-cochains with coefficients in \(G\)
  • \(d\) or \(\delta\): Coboundary operator
  • \(Z^n(X)\): \(n\)-cocycles
  • \(B^n(X)\): \(n\)-coboundaries
  • \(H^n(X; G)\): \(n\)-th cohomology group
  • \(\alpha \smile \beta\): Cup product of cohomology classes
  • \(\Omega^n(M)\): Space of smooth \(n\)-forms
  • \(d\): Exterior derivative
  • \(H_{dR}^n(M)\): de Rham cohomology
  • \([M]\): Fundamental class

Schemes: The Geometry of Equations

schemes

Historical Context

The theory of schemes, introduced by Alexander Grothendieck in the late 1950s, revolutionized algebraic geometry by providing a unified framework that encompasses both classical algebraic varieties and arithmetic objects like the integers. Grothendieck's insight was to replace the classical notion of a variety (solutions to polynomial equations) with a locally ringed space that encodes not just points but also the algebraic structure of functions near each point. This abstraction allowed algebraic geometers to apply geometric intuition to number theory (arithmetic geometry), solve long-standing problems like the Weil conjectures (proved by Deligne), and develop tools that now permeate modern mathematics.

Definitions

  • Affine Scheme: For a commutative ring \(A\), \(\text{Spec}(A)\) is the set of prime ideals of \(A\) with the Zariski topology and structure sheaf \(\mathcal{O}_{\text{Spec}(A)}\).
  • Zariski Topology: Closed sets are \(V(I) = \{\mathfrak{p} \in \text{Spec}(A) : I \subseteq \mathfrak{p}\}\) for ideals \(I\).
  • Structure Sheaf: \(\mathcal{O}(D(f)) = A_f\) (localization of \(A\) at \(f\)).
  • Scheme: A locally ringed space \((X, \mathcal{O}_X)\) that is locally isomorphic to an affine scheme.
  • Morphism of Schemes: A morphism of locally ringed spaces \((f, f^\#): (X, \mathcal{O}_X) \to (Y, \mathcal{O}_Y)\).
  • Fiber Product: For schemes \(X \to S\) and \(Y \to S\), the fiber product \(X \times_S Y\) represents the functor \((X \times_S Y)(T) = X(T) \times_{S(T)} Y(T)\).

Theorem: The Equivalence of Categories

Theorem: There is an equivalence of categories between:

  1. The opposite category of commutative rings
  2. The category of affine schemes

Given by \(A \mapsto \text{Spec}(A)\) and \((X, \mathcal{O}_X) \mapsto \mathcal{O}_X(X)\).

Theorem (Fiber Products Exist): Fiber products exist in the category of schemes. For affine schemes:

\[\text{Spec}(A) \times_{\text{Spec}(R)} \text{Spec}(B) = \text{Spec}(A \otimes_R B)\]

Valuative Criterion: A morphism \(f: X \to Y\) is proper (resp. separated) if and only if for every valuation ring \(R\) with fraction field \(K\), the natural map \(X(R) \to X(K) \times_{Y(K)} Y(R)\) is bijective (resp. injective).

Proof Sketch

The equivalence of categories follows from the fact that ring homomorphisms \(\phi: A \to B\) induce continuous maps \(\text{Spec}(B) \to \text{Spec}(A)\) via \(\mathfrak{p} \mapsto \phi^{-1}(\mathfrak{p})\), and the structure sheaf construction is functorial. For fiber products, one verifies the universal property: maps from a scheme \(T\) to \(\text{Spec}(A \otimes_R B)\) correspond to pairs of compatible maps to \(\text{Spec}(A)\) and \(\text{Spec}(B)\).

Notation Guide

  • \(\text{Spec}(A)\): Spectrum of ring \(A\)
  • \(\mathfrak{p}, \mathfrak{q}\): Prime ideals
  • \(V(I)\): Vanishing set of ideal \(I\)
  • \(D(f) = \text{Spec}(A) \setminus V(f)\): Distinguished open
  • \(A_f\): Localization of \(A\) at \(f\)
  • \(A_\mathfrak{p}\): Localization at prime \(\mathfrak{p}\)
  • \(\mathcal{O}_X\): Structure sheaf
  • \(X \times_S Y\): Fiber product over \(S\)
  • \(\mathbb{A}^n_k = \text{Spec}(k[x_1, \ldots, x_n])\): Affine space
  • \(\mathbb{P}^n_k\): Projective space

Operads: Algebraic Structures of Structures

operads

Historical Context

Operads were introduced by Peter May in 1972 to systematically study iterated loop spaces and infinite loop spaces in algebraic topology. The concept crystallized ideas that were implicit in the work of Boardman, Vogt, and Stasheff on homotopy associativity. Operads provide a framework for encoding operations with multiple inputs and one output, along with rules for composing them. They have since found applications across mathematics: in deformation quantization (Kontsevich), vertex algebras, moduli spaces of curves, and the study of algebraic structures up to homotopy. The theory exemplifies the modern trend of studying not just objects but the operations that act on them.

Definitions

  • Operad: A collection of sets/spaces \(\mathcal{O}(n)\) for \(n \geq 0\) (operations with \(n\) inputs), with composition operations \(\circ_i: \mathcal{O}(m) \times \mathcal{O}(n) \to \mathcal{O}(m+n-1)\) and a symmetric group action \(S_n \times \mathcal{O}(n) \to \mathcal{O}(n)\), satisfying associativity, equivariance, and unit axioms.
  • Endomorphism Operad: For a vector space \(V\), \(\mathcal{E}nd_V(n) = \text{Hom}(V^{\otimes n}, V)\) with composition of multilinear maps.
  • Algebra over an Operad: A morphism of operads \(\mathcal{O} \to \mathcal{E}nd_V\), i.e., a way to realize operations in \(\mathcal{O}\) as actual operations on \(V\).
  • Associative Operad (Assoc): \(\text{Assoc}(n) = S_n\) (permutations), encoding all possible ways to multiply \(n\) elements.
  • Commutative Operad (Comm): \(\text{Comm}(n) = *\) (point), encoding commutative multiplication.
  • Little n-Discs Operad (\(\mathcal{D}_n\)): \(\mathcal{D}_n(k)\) is the space of embeddings of \(k\) disjoint discs into the unit disc in \(\mathbb{R}^n\).

Theorem: May's Recognition Principle

Theorem (May's Recognition Principle): A connected space \(X\) is (weakly homotopy equivalent to) an \(n\)-fold loop space \(\Omega^n Y\) for some \(Y\) if and only if \(X\) is a grouplike algebra over the little \(n\)-discs operad \(\mathcal{D}_n\).

Corollary: An infinite loop space (spectrum) is equivalent to a grouplike algebra over the infinite little discs operad (or the associative operad with appropriate coherence).

Kontsevich Formality: The Hochschild cochain complex of the algebra of functions on a smooth manifold is formal as a homotopy Gerstenhaber algebra, implying deformation quantization exists.

Proof Sketch

May's theorem is proved by constructing a classifying space \(B_n X\) for \(\mathcal{D}_n\)-algebras such that \(\Omega^n B_n X \simeq X\). The key is that the operad structure provides the coherence data needed to deloop. For the little discs operad, the composition corresponds to inserting discs into discs, and the grouplike condition ensures the induced monoid structure is invertible up to homotopy.

Notation Guide

  • \(\mathcal{O}, \mathcal{P}\): Operads
  • \(\mathcal{O}(n)\): Space of \(n\)-ary operations
  • \(f \circ_i g\): Composition of operation \(g\) into the \(i\)-th input of \(f\)
  • \(\gamma: \mathcal{O}(n) \times \mathcal{O}(k_1) \times \cdots \times \mathcal{O}(k_n) \to \mathcal{O}(k_1 + \cdots + k_n)\): Full composition
  • \(\mathbf{1} \in \mathcal{O}(1)\): Identity operation
  • \(\mathcal{E}nd_V\): Endomorphism operad
  • \(\mathcal{D}_n\): Little \(n\)-discs operad
  • \(\Omega^n X\): \(n\)-fold loop space

        """
        Partial composition: f ∘ᵢ g
        Insert g into the i-th input of f.

Lie Algebras: Infinitesimal Symmetries

lie-theory

Historical Context

Lie algebras emerged from Sophus Lie's study of continuous transformation groups in the late 19th century. The insight that the local structure of a Lie group is captured by its tangent space at the identity—equipped with the Lie bracket operation—revolutionized the study of symmetries. Wilhelm Killing and Élie Cartan classified simple Lie algebras over the complex numbers, discovering the exceptional algebras \(G_2, F_4, E_6, E_7, E_8\). This classification is one of the most beautiful achievements in mathematics, with connections to representation theory, differential geometry, and modern physics. Lie algebras provide the mathematical language for gauge theories in particle physics and the structure of spacetime symmetries.

Definitions

  • Lie Algebra: A vector space \(\mathfrak{g}\) with a bilinear bracket \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) satisfying:
    • Antisymmetry: \([x, y] = -[y, x]\)
    • Jacobi identity: \([x, [y, z]] + [y, [z, x]] + [z, [x, y]] = 0\)
  • Adjoint Representation: \(\text{ad}: \mathfrak{g} \to \text{End}(\mathfrak{g})\) defined by \(\text{ad}_x(y) = [x, y]\).
  • Killing Form: The symmetric bilinear form \(\kappa(x, y) = \text{tr}(\text{ad}_x \circ \text{ad}_y)\).
  • Semisimple Lie Algebra: A Lie algebra with no non-zero abelian ideals. Equivalently, the Killing form is non-degenerate (Cartan's criterion).
  • Cartan Subalgebra: A maximal abelian subalgebra \(\mathfrak{h} \subseteq \mathfrak{g}\) consisting of semisimple elements.
  • Root System: For a semisimple Lie algebra, the non-zero weights \(\alpha \in \mathfrak{h}^*\) of the adjoint action of \(\mathfrak{h}\) on \(\mathfrak{g}\).

Theorem: The Classification of Simple Lie Algebras

Theorem (Killing-Cartan Classification): Every finite-dimensional simple Lie algebra over \(\mathbb{C}\) is isomorphic to exactly one of:

  • Classical series: \(A_n = \mathfrak{sl}_{n+1}\) (\(n \geq 1\)), \(B_n = \mathfrak{so}_{2n+1}\) (\(n \geq 2\)), \(C_n = \mathfrak{sp}_{2n}\) (\(n \geq 3\)), \(D_n = \mathfrak{so}_{2n}\) (\(n \geq 4\))
  • Exceptional: \(G_2, F_4, E_6, E_7, E_8\)

Cartan's Criterion: A Lie algebra \(\mathfrak{g}\) is semisimple if and only if its Killing form is non-degenerate.

Weyl's Theorem: Every finite-dimensional representation of a semisimple Lie algebra is completely reducible (direct sum of irreducibles).

Proof Sketch

The classification proceeds by studying root systems—finite sets of vectors in Euclidean space satisfying specific geometric properties (reflection symmetry, integrality conditions). The root system of a semisimple Lie algebra determines the algebra up to isomorphism. Dynkin diagrams encode the geometry of simple roots, and their classification yields the list above. The exceptional algebras correspond to the exceptional Dynkin diagrams \(G_2, F_4, E_6, E_7, E_8\).

Notation Guide

  • \(\mathfrak{g}, \mathfrak{h}\): Lie algebras
  • \([x, y]\): Lie bracket
  • \(\text{ad}_x\): Adjoint action
  • \(\kappa(x, y)\): Killing form
  • \(\mathfrak{h}\): Cartan subalgebra
  • \(\Phi\): Root system
  • \(\alpha, \beta\): Roots (elements of \(\mathfrak{h}^*\))
  • \(\mathfrak{g}_\alpha\): Root space
  • \(\mathfrak{sl}_n, \mathfrak{so}_n, \mathfrak{sp}_{2n}\): Classical Lie algebras

import numpy as np
from itertools import product

def killing_form(structure_constants):
    """
    Compute the Killing form from structure constants f_{ij}^k.
    κ(X_i, X_j) = Σ_{k,l} f_{ik}^l * f_{jl}^k
    """
    dim = len(structure_constants)
    kappa = np.zeros((dim, dim))
    
    for i in range(dim):
        for j in range(dim):
            # ad_X_i in matrix form
            ad_i = np.zeros((dim, dim))
            for k in range(dim):
                for l in range(dim):
                    ad_i[k, l] = structure_constants[i][k][l]
            
            # ad_X_j in matrix form
            ad_j = np.zeros((dim, dim))
            for k in range(dim):
                for l in range(dim):
                    ad_j[k, l] = structure_constants[j][k][l]
            
            # κ(X_i, X_j) = tr(ad_X_i ∘ ad_X_j)
            kappa[i, j] = np.trace(ad_i @ ad_j)
    
    return kappa

def so3_structure_constants():
    """
    Structure constants for so(3).
    [L_i, L_j] = ε_{ijk} L_k
    """
    # Levi-Civita symbol
    def epsilon(i, j, k):
        if (i, j, k) in [(0, 1, 2), (1, 2, 0), (2, 0, 1)]:
            return 1
        elif (i, j, k) in [(0, 2, 1), (2, 1, 0), (1, 0, 2)]:
            return -1
        return 0
    
    dim = 3
    f = [[[0 for _ in range(dim)] for _ in range(dim)] for _ in range(dim)]
    
    for i, j, k in product(range(dim), repeat=3):
        f[i][j][k] = epsilon(i, j, k)
    
    return f

def check_jacobi(structure_constants):
    """Verify the Jacobi identity for given structure constants."""
    dim = len(structure_constants)
    
    # [X_i, [X_j, X_k]] + [X_j, [X_k, X_i]] + [X_k, [X_i, X_j]] = 0
    max_error = 0
    
    for i, j, k in product(range(dim), repeat=3):
        # [X_j, X_k] = Σ_m f_{jkm} X_m
        # [X_i, [X_j, X_k]] = Σ_m f_{jkm} [X_i, X_m] = Σ_{m,n} f_{jkm} f_{imn} X_n
        
        jacobi = np.zeros(dim)
        for n in range(dim):
            for m in range(dim):
                jacobi[n] += (structure_constants[j][k][m] * structure_constants[i][m][n] +
                             structure_constants[k][i][m] * structure_constants[j][m][n] +
                             structure_constants[i][j][m] * structure_constants[k][m][n])
        
        max_error = max(max_error, np.max(np.abs(jacobi)))
    
    return max_error

def cartan_criterion(kappa):
    """Check if Killing form is non-degenerate (semisimplicity)."""
    det = np.linalg.det(kappa)
    rank = np.linalg.matrix_rank(kappa)
    return det != 0, det, rank

The Birth of Modern Algebra: Emmy Noether and the Rise of Abstract Structures

The early 20th century witnessed a profound transformation in mathematics, as the field shifted from studying specific objects to studying abstract structures and their relationships. At the center of this revolution stood Emmy Noether, whose work laid the foundations for modern abstract algebra.

Born in 1882 into a mathematical family—her father Max Noether was a distinguished geometer—Emmy Noether faced significant obstacles as a woman in German academia. Despite earning her doctorate in 1907, she worked without pay for years at the University of Erlangen, where her father taught. In 1915, David Hilbert and Felix Klein invited her to Göttingen, the world's leading mathematical center. When faculty objected to a woman teaching, Hilbert reportedly responded: "I do not see that the sex of the candidate is an argument against her admission. After all, we are a university, not a bath house."

Noether's 1921 paper "Idealtheorie in Ringbereichen" (Theory of Ideals in Ring Domains) revolutionized algebra by establishing that every ideal in a polynomial ring over a field has a finite basis—the ascending chain condition that now defines Noetherian rings. This abstract approach, treating algebraic structures axiomatically, was radically new. Where earlier mathematicians studied particular systems like polynomials or integers, Noether studied rings, ideals, and modules in full generality.

Her influence extended far beyond algebra. In physics, Noether's theorem established that every differentiable symmetry of the action of a physical system corresponds to a conservation law—connecting time translation symmetry to energy conservation, spatial translation to momentum, and rotation to angular momentum. This theorem remains fundamental to modern theoretical physics.

When the Nazis came to power in 1933, Noether was dismissed from Göttingen due to her Jewish heritage. She emigrated to the United States, joining Bryn Mawr College and the Institute for Advanced Study. Her sudden death in 1935 from complications after surgery cut short a career that had already transformed mathematics. Albert Einstein wrote in her obituary: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began."

Noether's legacy lives on in every field of modern mathematics. The concepts of Noetherian rings, Noether normalization, and Noether's theorem are essential tools. More profoundly, her structural approach—studying morphisms, universal properties, and categorical relationships—became the dominant paradigm of 20th-century mathematics, influencing everything from algebraic geometry to topology to mathematical logic.

🧩 Problem Corner

Putnam Competition Problem (2023 B6)

Difficulty: ★★★★★

Problem: Let \(n\) be a positive integer. A sequence \((a_0, a_1, \ldots, a_n)\) of integers is called good if it satisfies the following conditions:

  • \(0 = a_0 < a_1 < a_2 < \cdots < a_n = 2n\)
  • For each \(k = 1, 2, \ldots, n\), the set \(\{a_k - a_{k-1}, a_{k+1} - a_k\}\) contains exactly one odd integer (where we define \(a_{n+1} = 2a_n - a_{n-1}\)).

Find the number of good sequences in terms of \(n\).

💡 Hint

Consider the differences \(d_k = a_k - a_{k-1}\). The condition implies that consecutive differences alternate between odd and even. Think about this as a path-counting problem on a grid, or relate it to Catalan-like structures. The answer involves the Fibonacci numbers.

✅ Solution

Answer: The number of good sequences is \(F_{2n+1}\), the \((2n+1)\)-th Fibonacci number (with \(F_1 = F_2 = 1\)).

Solution: Let \(d_k = a_k - a_{k-1}\) for \(k = 1, \ldots, n\). Then \(\sum_{k=1}^n d_k = 2n\). The condition says that for each \(k\), exactly one of \(d_k\) and \(d_{k+1}\) is odd (with \(d_{n+1} = a_{n+1} - a_n = 2a_n - a_{n-1} - a_n = a_n - a_{n-1} = d_n\)).

This means the parities of the differences must alternate: if \(d_1\) is odd, then \(d_2\) is even, \(d_3\) is odd, and so on. Since \(d_{n+1} = d_n\), we need the parity pattern to satisfy this consistency condition.

Case 1: \(n\) is odd. Then the parity pattern O, E, O, E, ..., O (ending in odd) satisfies \(d_{n+1} = d_n\) being odd. Each odd difference is at least 1, and each even difference is at least 2. With the constraint \(\sum d_k = 2n\), if we have \((n+1)/2\) odd positions and \((n-1)/2\) even positions, the minimum sum is \((n+1)/2 \cdot 1 + (n-1)/2 \cdot 2 = (n+1)/2 + n - 1 = (3n-1)/2\).

Case 2: \(n\) is even. The pattern must start with E to have \(d_n = d_{n+1}\) both even.

A more elegant approach uses a bijection with lattice paths. Define a path where steps correspond to the differences. The parity condition constrains the path to stay within certain bounds, and counting such paths yields the Fibonacci recurrence.

Specifically, let \(f(n)\) be the number of good sequences. One can show that \(f(n) = f(n-1) + f(n-2)\) with appropriate initial conditions, giving \(f(n) = F_{2n+1}\).

Morse Theory: Critical Points on a Torus

This visualization shows the height function on a torus, illustrating the four critical points of a Morse function: minimum (index 0), two saddles (index 1), and maximum (index 2). The sublevel sets change topology as we pass each critical value, demonstrating how Morse theory connects critical points to the topology of the manifold.

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
from matplotlib.colors import LightSource

def torus_parametric(theta, phi, R=3, r=1):
    """Parametric equations for a torus."""
    x = (R + r * np.cos(theta)) * np.cos(phi)
    y = (R + r * np.cos(theta)) * np.sin(phi)
    z = r * np.sin(theta)
    return x, y, z

def height_function(theta, phi, R=3, r=1):
    """Height function: f(θ, φ) = z-coordinate = r·sin(θ)"""
    return r * np.sin(theta)

# Create mesh
n = 100
theta = np.linspace(0, 2*np.pi, n)
phi = np.linspace(0, 2*np.pi, n)
Theta, Phi = np.meshgrid(theta, phi)

# Torus coordinates
X, Y, Z = torus_parametric(Theta, Phi)

# Height function values
height = height_function(Theta, Phi)

# Create figure with subplots
fig = plt.figure(figsize=(16, 6))

# Plot 1: 3D torus with height coloring
ax1 = fig.add_subplot(131, projection='3d')
ls = LightSource(azdeg=315, altdeg=45)
rgb = ls.shade(Z, plt.cm.viridis)
surf = ax1.plot_surface(X, Y, Z, facecolors=rgb, alpha=0.9, 
                         rstride=3, cstride=3, antialiased=True)
ax1.set_xlabel('X')
ax1.set_ylabel('Y')
ax1.set_zlabel('Z')
ax1.set_title('Torus with Height Function Coloring')

# Plot 2: Critical points marked
critical_points = [
    (0, np.pi/2, 'red', 'Max (idx 2)'),      # Maximum
    (np.pi, np.pi/2, 'blue', 'Saddle 1'),    # Saddle
    (np.pi, 3*np.pi/2, 'blue', 'Saddle 2'),  # Saddle
    (0, 3*np.pi/2, 'green', 'Min (idx 0)'),  # Minimum
]

ax2 = fig.add_subplot(132, projection='3d')
ax2.plot_surface(X, Y, Z, alpha=0.3, color='lightgray', 
                  rstride=5, cstride=5)

for th, ph, color, label in critical_points:
    x, y, z = torus_parametric(th, ph)
    ax2.scatter([x], [y], [z], color=color, s=200, label=label)

ax2.set_xlabel('X')
ax2.set_ylabel('Y')
ax2.set_zlabel('Z')
ax2.set_title('Critical Points of Height Function')
ax2.legend()

# Plot 3: Sublevel sets evolution
ax3 = fig.add_subplot(133)
levels = np.linspace(-1, 1, 9)
contour = ax3.contourf(Theta, Phi, height, levels=levels, cmap='RdYlBu_r')
ax3.contour(Theta, Phi, height, levels=levels, colors='black', linewidths=0.5)

# Mark critical points in 2D
for th, ph, color, label in critical_points:
    ax3.scatter([th], [ph], color=color, s=150, edgecolors='black', zorder=5)

ax3.set_xlabel('θ')
ax3.set_ylabel('φ')
ax3.set_title('Sublevel Sets (Height Contours)')
plt.colorbar(contour, ax=ax3, label='Height z = r·sin(θ)')

plt.tight_layout()
plt.savefig('morse_torus.png', dpi=150, bbox_inches='tight')
plt.show()

print("Visualization saved!")
print("\nKey observations:")
print("  - Red point: Maximum (index 2)")
print("  - Blue points: Saddles (index 1 each)")
print("  - Green point: Minimum (index 0)")
print("  - Sublevel sets change topology at each critical value")
