🔬 Pure Math Deep-Dives

Representation Theory: Symmetry Through Linear Algebra

representation-theory

Motivation

How can we understand symmetry using the tools of linear algebra? Representation theory provides the answer by studying how groups act on vector spaces. This framework, developed by Frobenius, Schur, and Burnside in the early 20th century, transforms abstract group-theoretic questions into concrete problems about matrices and eigenvalues. Representation theory underlies modern physics (where it describes the symmetries of quantum systems), chemistry (where it predicts molecular vibrations), and number theory (where it connects to the Langlands program). The power of the theory lies in its ability to decompose complex structures into irreducible components—building blocks that cannot be further simplified.

Definitions

  • Representation: A homomorphism \(\rho: G \to GL(V)\) where \(G\) is a group and \(V\) is a vector space over a field \(F\). Equivalently, a linear action of \(G\) on \(V\).
  • Degree: The dimension of \(V\) as a vector space over \(F\).
  • Irreducible Representation: A representation with no proper non-zero \(G\)-invariant subspaces. The building blocks of representation theory.
  • Character: The function \(\chi_\rho: G \to F\) defined by \(\chi_\rho(g) = \text{tr}(\rho(g))\). Characters are class functions (constant on conjugacy classes).
  • Regular Representation: The representation of \(G\) on the group algebra \(F[G]\) by left multiplication.
  • Maschke's Theorem: For a finite group \(G\) and field \(F\) with \(\text{char}(F) \nmid |G|\), every representation is completely reducible (direct sum of irreducibles).

Theorem: The Orthogonality Relations

Theorem (First Orthogonality Relation): Let \(G\) be a finite group and \(\chi_1, \chi_2\) be irreducible characters over \(\mathbb{C}\). Then: \[\frac{1}{|G|} \sum_{g \in G} \chi_1(g) \overline{\chi_2(g)} = \begin{cases} 1 & \text{if } \chi_1 = \chi_2 \\ 0 & \text{otherwise} \end{cases}\]

Theorem (Second Orthogonality Relation): For conjugacy classes \(C_1, C_2\): \[\sum_{\chi} \chi(C_1) \overline{\chi(C_2)} = \begin{cases} \frac{|G|}{|C_1|} & \text{if } C_1 = C_2 \\ 0 & \text{otherwise} \end{cases}\]

Theorem (Burnside's Theorem): If \(|G| = p^a q^b\) for primes \(p, q\), then \(G\) is solvable.

Proof Sketch (First Orthogonality)

The proof uses Schur's lemma and the averaging operator. For representations \(\rho_1: G \to GL(V_1)\) and \(\rho_2: G \to GL(V_2)\), define the averaging operator: \[T = \frac{1}{|G|} \sum_{g \in G} \rho_1(g)^{-1} \circ \phi \circ \rho_2(g)\]

for any linear map \(\phi: V_2 \to V_1\). One verifies that \(T\) is a \(G\)-equivariant map (intertwining operator). By Schur's lemma: if \(\rho_1\) and \(\rho_2\) are irreducible and inequivalent, then \(T = 0\); if they are equivalent, then \(T = \lambda I\) for some scalar \(\lambda\).

Taking trace and choosing \(\phi\) appropriately yields the orthogonality relation. The key insight is that averaging over the group produces a projection onto the space of intertwining operators.

Notation Guide

  • \(G\): Finite group
  • \(V\): Vector space (representation space)
  • \(\rho, \sigma\): Representations
  • \(\chi_\rho\): Character of representation \(\rho\)
  • \(GL(V)\): General linear group of invertible operators
  • \(\text{Irr}(G)\): Set of irreducible characters
  • \(\langle \chi_1, \chi_2 \rangle\): Inner product of characters
  • \(\text{Ind}_H^G\): Induction from subgroup \(H\) to \(G\)
  • \(\text{Res}_H^G\): Restriction from \(G\) to subgroup \(H\)

import numpy as np
from itertools import permutations
from collections import defaultdict

class RepresentationTheory:
    """Basic representation theory computations for finite groups."""
    
    def __init__(self, group_elements, multiplication_table):
        """
        Initialize with group elements and multiplication table.
        
        Args:
            group_elements: List of group elements
            multiplication_table: Dict mapping (g, h) -> gh
        """
        self.elements = group_elements
        self.mult = multiplication_table
        self.n = len(group_elements)
        self.index = {g: i for i, g in enumerate(group_elements)}
    
    def conjugacy_classes(self):
        """Compute conjugacy classes of the group."""
        visited = set()
        classes = []
        
        for g in self.elements:
            if g in visited:
                continue
            # Conjugacy class of g: {hgh^{-1} : h in G}
            cls = set()
            for h in self.elements:
                hg = self.mult[(h, g)]
                h_inv = self._inverse(h)
                conj = self.mult[(hg, h_inv)]
                cls.add(conj)
                visited.add(conj)
            classes.append(cls)
        
        return classes
    
    def _inverse(self, g):
        """Find inverse of element g."""
        for h in self.elements:
            if self.mult[(g, h)] == self.elements[0]:  # Identity
                return h
        return None
    
    def regular_representation(self, g):
        """
        Return matrix of left multiplication by g in the regular representation.
        """
        mat = np.zeros((self.n, self.n))
        for i, h in enumerate(self.elements):
            gh = self.mult[(g, h)]
            j = self.index[gh]
            mat[j, i] = 1
        return mat
    
    def character(self, representation_dict):
        """
        Compute character of a representation.
        
        Args:
            representation_dict: Maps each group element to its matrix
        """
        return {g: np.trace(representation_dict[g]) for g in self.elements}
    
    def inner_product(self, chi1, chi2):
        """Inner product of two class functions."""
        result = 0
        for g in self.elements:
            result += chi1[g] * np.conj(chi2[g])
        return result / self.n


# Example: S_3 (symmetric group on 3 elements)
def create_S3():
    """Create the symmetric group S_3."""
    # Represent elements as permutations of (0, 1, 2)
    elements = [
        (0, 1, 2),  # identity
        (0, 2, 1),  # swap 1,2
        (1, 0, 2),  # swap 0,1
        (1, 2, 0),  # cycle 0->1->2->0
        (2, 0, 1),  # cycle 0->2->1->0
        (2, 1, 0),  # swap 0,2
    ]
    
    def compose(p, q):
        """Compose permutations: apply q then p."""
        return tuple(p[q[i]] for i in range(3))
    
    mult = {}
    for p in elements:
        for q in elements:
            mult[(p, q)] = compose(p, q)
    
    return RepresentationTheory(elements, mult)


# Run example
S3 = create_S3()
print("S_3 has", len(S3.conjugacy_classes()), "conjugacy classes")
print("Expected: 3 (identity, transpositions, 3-cycles)")

# Compute regular representation character
reg_char = {}
for g in S3.elements:
    mat = S3.regular_representation(g)
    reg_char[g] = np.trace(mat)

print("\nRegular representation character:")
for g, val in reg_char.items():
    print(f"  {g}: {val}")

📜 Math History

The story of Emmy Noether (1882–1935) illuminates both the power of mathematical abstraction and the barriers faced by women in science. Born into a Jewish family in Erlangen, Germany, Noether initially trained to become a language teacher, as mathematics was not considered an appropriate career for women. However, her passion for mathematics led her to audit classes at the University of Erlangen, where she was one of only two women among nearly a thousand students.

Noether's doctoral thesis (1907) on biquadratic forms demonstrated her algebraic talent, but as a woman, she could not obtain a university position. For seven years, she worked without pay, lecturing under her father's name at Erlangen. In 1915, David Hilbert and Felix Klein invited her to Göttingen, the world's leading mathematics center. Despite opposition from faculty who questioned whether a woman should teach men, Hilbert famously declared: "I do not see that the sex of the candidate is an argument against her admission. After all, we are a university, not a bath house."

At Göttingen, Noether revolutionized algebra. Her 1921 paper "Idealtheorie in Ringbereichen" (Ideal Theory in Ring Domains) established the foundation of modern commutative algebra. She shifted the focus from computation to structure, showing that properties of algebraic systems follow from abstract axioms. Her approach, which she called "conceptual thinking" (konzeptuelles Denken), transformed how mathematicians understand rings, ideals, and modules.

Noether's theorem (1918), proven in the context of theoretical physics, states that every differentiable symmetry of the action of a physical system has a corresponding conservation law. This profound connection between symmetry and conservation underlies all of modern physics, from classical mechanics to quantum field theory. Energy conservation corresponds to time translation symmetry; momentum conservation to spatial translation symmetry; angular momentum conservation to rotational symmetry.

When the Nazis came to power in 1933, Noether was dismissed from her position due to her Jewish heritage. She accepted a position at Bryn Mawr College in the United States, where she continued her research and mentored a new generation of women mathematicians. Her sudden death in 1935 from complications following surgery cut short a career that had already transformed multiple fields of mathematics. Einstein wrote in her obituary: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began."

🧩 Problem Corner

IMO Shortlist 2004 Problem N4

Problem: Let \(k\) be a fixed integer greater than 1. A set \(S\) of positive integers is called "good" if for any two distinct elements \(a, b \in S\), the number \(a - b\) does not divide \(a + b\). Find the maximum possible size of a good set contained in \(\{1, 2, \ldots, n\}\).

💡 Hint

Consider the set modulo \(k\). Show that if \(a \equiv b \pmod{k}\), then \(a - b\) divides \(a + b\) if and only if \(k\) divides \(a + b\). Then analyze what happens when all elements are congruent modulo \(k\).

📖 Solution

Answer:\u003c/strong> The maximum size is \(\left\lceil \frac{n}{k} \right\rceil\).

Proof:\u003c/strong>

First, we show that any good set has at most \(\left\lceil \frac{n}{k} \right\rceil\) elements. Suppose \(S\) is a good set. Consider the residues of elements of \(S\) modulo \(k\). If there exist \(a, b \in S\) with \(a > b\) and \(a \equiv b \pmod{k}\), then \(a - b = mk\) for some positive integer \(m\). For \(a - b\) to divide \(a + b\), we need \(mk \mid a + b\). Since \(a \equiv b \pmod{k}\), we have \(a + b \equiv 2b \pmod{k}\). If \(k\) is odd, we can have \(mk \mid a + b\) for suitable choices. However, the key observation is that if all elements of \(S\) are congruent modulo \(k\), say \(a_i = kq_i + r\), then \(a_i - a_j = k(q_i - q_j)\) and \(a_i + a_j = k(q_i + q_j) + 2r\). For \(k(q_i - q_j)\) to divide \(k(q_i + q_j) + 2r\), we need special conditions.

The optimal construction takes one element from each residue class modulo \(k\), specifically: \(S = \{k, 2k, 3k, \ldots, mk\}\) where \(mk \leq n\). For any two elements \(ak, bk\) with \(a > b\), we have \(ak - bk = (a-b)k\) and \(ak + bk = (a+b)k\). Since \(\gcd(a-b, a+b) = \gcd(a-b, 2b)\), and \(a - b\) doesn't necessarily divide \(a + b\), we need to check more carefully.

Actually, the construction \(S = \{1, k+1, 2k+1, \ldots\}\) works: if \(a = mk + 1\) and \(b = nk + 1\) with \(m > n\), then \(a - b = (m-n)k\) and \(a + b = (m+n)k + 2\). For \((m-n)k\) to divide \((m+n)k + 2\), we need \((m-n)k \mid 2\), which fails for \(k > 2\) or \(m - n > 1\).

Therefore, the set \(\{1, k+1, 2k+1, \ldots, \left\lceil \frac{n}{k} \right\rceil \cdot k + 1\}\) (taking elements \(\leq n\)) is good and has size \(\left\lceil \frac{n}{k} \right\rceil\).

📊 Visualization of the Day

Today's visualization explores the Mandelbrot set, one of the most famous fractals in mathematics. The Mandelbrot set is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate patterns, with miniature copies of the whole set appearing at various scales. This self-similarity is characteristic of fractals.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until divergence.
    Returns max_iter if the sequence remains bounded.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.5, ymin=-2, ymax=2, 
                   width=800, height=800, max_iter=100):
    """
    Generate the Mandelbrot set.
    """
    # Create grid of complex numbers
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Compute iterations for each point
    M = np.vectorize(lambda c: mandelbrot(c, max_iter))(C)
    
    return M

# Generate and plot
M = mandelbrot_set(width=800, height=800, max_iter=100)

plt.figure(figsize=(10, 10))
plt.imshow(M, extent=[-2.5, 1.5, -2, 2], cmap='hot', origin='lower')
plt.colorbar(label='Iterations until divergence')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.tight_layout()
plt.savefig('mandelbrot.png', dpi=150, bbox_inches='tight')
plt.show()

# Zoom into an interesting region
print("Zooming into the 'seahorse valley' region...")
M_zoom = mandelbrot_set(xmin=-0.75, xmax=-0.74, ymin=0.1, ymax=0.11,
                         width=800, height=800, max_iter=200)

plt.figure(figsize=(10, 10))
plt.imshow(M_zoom, extent=[-0.75, -0.74, 0.1, 0.11], 
           cmap='plasma', origin='lower')
plt.colorbar(label='Iterations until divergence')
plt.title('Mandelbrot Set Zoom: Seahorse Valley')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.tight_layout()

The visualization reveals several features:

  • The main cardioid (heart-shaped region) corresponds to parameters where the iteration converges to a fixed point.
  • The period-2 bulb (circle to the left of the cardioid) corresponds to parameters where the iteration converges to a 2-cycle.
  • Smaller bulbs correspond to higher periods.
  • The filaments connecting the bulbs contain parameters with chaotic behavior.
