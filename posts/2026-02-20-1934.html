Cohomology Operations: Natural Transformations in Algebraic Topology

cohomology-operations

Motivation

Cohomology operations provide additional algebraic structure on cohomology groups that goes beyond the cup product. They are essential for distinguishing spaces with isomorphic cohomology rings and for computing stable homotopy groups of spheres. The study of cohomology operations led to the development of spectral sequences and generalized cohomology theories.

Definitions

  • Cohomology Operation: A natural transformation of functors \(H^n(-; G) \to H^m(-; H)\) between cohomology theories.
  • Stable Cohomology Operation: A family of operations \(\theta_n: H^n(-; G) \to H^{n+k}(-; H)\) commuting with suspension.
  • Steenrod Algebra \(\mathcal{A}_p\): The algebra of stable cohomology operations over \(\mathbb{Z}/p\mathbb{Z}\).

Theorem: The Structure of the Steenrod Algebra

Theorem: The mod 2 Steenrod algebra \(\mathcal{A}_2\) is the free associative algebra generated by the Steenrod squares \(Sq^i\) for \(i \geq 0\), modulo the Adem relations: \[Sq^a Sq^b = \sum_{j=0}^{\lfloor a/2 \rfloor} \binom{b-j-1}{a-2j} Sq^{a+b-j} Sq^j\] for \(a < 2b\), where \(Sq^0 = 1\).

Proof Sketch

The proof involves showing that the Adem relations generate all relations among Steenrod squares. This is done by:

  1. Constructing the Steenrod squares via the cup-i product structure on singular cochains.
  2. Verifying the Cartan formula: \(Sq^k(x \smile y) = \sum_{i+j=k} Sq^i(x) \smile Sq^j(y)\).
  3. Using the projective space \(\mathbb{RP}^\infty\) as a test space to show no further relations exist.

Notation Guide

  • \(Sq^i: H^n(X; \mathbb{Z}/2) \to H^{n+i}(X; \mathbb{Z}/2)\) — Steenrod square
  • \(x \smile y\) — Cup product of cohomology classes
  • \(\mathcal{A}_2\) — Mod 2 Steenrod algebra
  • \(\binom{n}{k}\) mod 2 — Binomial coefficient reduced modulo 2

class SteenrodAlgebra:
    """Computations in the mod 2 Steenrod algebra."""
    
    @staticmethod
    def binom_mod2(n, k):
        """Compute binomial coefficient mod 2 using Lucas's theorem."""
        # Lucas's theorem: C(n,k) mod 2 = 1 iff k & (n-k) == 0
        return 1 if (k & (n - k)) == 0 else 0
    
    @staticmethod
    def adem_relation(a, b):
        """
        Apply Adem relation: Sq^a Sq^b = sum_j C(b-j-1, a-2j) Sq^(a+b-j) Sq^j
        Returns list of (coefficient, (degree1, degree2)) pairs.
        """
        if a >= 2*b:
            return [(1, (a, b))]  # No relation applies
        
        result = []
        for j in range(a // 2 + 1):
            coeff = SteenrodAlgebra.binom_mod2(b - j - 1, a - 2*j)
            if coeff == 1:
                result.append((1, (a + b - j, j)))
        return result
    
    @staticmethod
    def sq(x, i, n):
        """
        Apply Sq^i to a cohomology class x in degree n.
        Returns the degree of the result: n + i.
        """
        return n + i

Characteristic Classes: Measuring the Twist of Vector Bundles

characteristic-classes

Motivation

Characteristic classes are cohomology classes associated to vector bundles that measure their topological complexity. They provide obstructions to the existence of sections, determine when bundles are trivial, and play a crucial role in the classification of manifolds. Chern classes, for instance, completely classify complex line bundles over a space.

Definitions

  • Vector Bundle: A fiber bundle where each fiber has the structure of a vector space and local trivializations are linear isomorphisms.
  • Chern Classes \(c_i(E)\): For a complex vector bundle \(E\) of rank \(n\), classes \(c_i(E) \in H^{2i}(X; \mathbb{Z})\) with \(c_0 = 1\) and \(c_i = 0\) for \(i > n\).
  • Total Chern Class: \(c(E) = c_0(E) + c_1(E) + \cdots + c_n(E)\).
  • Euler Class \(e(E)\): For an oriented real vector bundle of even rank, a class in \(H^n(X; \mathbb{Z})\) whose pullback to the sphere bundle generates the cohomology of each fiber.

Theorem: The Splitting Principle

Theorem: For any complex vector bundle \(E \to X\), there exists a space \(F(E)\) and a map \(f: F(E) \to X\) such that:

  1. \(f^*: H^*(X) \to H^*(F(E))\) is injective.
  2. \(f^*E\) splits as a direct sum of line bundles: \(f^*E \cong L_1 \oplus \cdots \oplus L_n\).

Consequently, \(c(f^*E) = \prod_{i=1}^n (1 + c_1(L_i))\).

Proof Sketch

The proof constructs \(F(E)\) as the flag bundle of \(E\), whose fiber over \(x \in X\) is the space of complete flags in \(E_x\). This bundle is built inductively by projectivizing \(E\) to get a line bundle quotient, then repeating on the kernel.

Notation Guide

  • \(c_i(E) \in H^{2i}(X; \mathbb{Z})\) — i-th Chern class
  • \(w_i(E) \in H^i(X; \mathbb{Z}/2)\) — i-th Stiefel-Whitney class
  • \(p_i(E) \in H^{4i}(X; \mathbb{Z})\) — i-th Pontryagin class
  • \(e(E) \in H^n(X; \mathbb{Z})\) — Euler class (for rank n bundle)

class CharacteristicClasses:
    """Computations with characteristic classes."""
    
    @staticmethod
    def chern_class_line_bundle(c1):
        """
        Total Chern class of a line bundle: c = 1 + c_1
        """
        return [1, c1]  # [c_0, c_1]
    
    @staticmethod
    def total_chern_direct_sum(cE, cF):
        """
        Whitney sum formula: c(E ⊕ F) = c(E) ∪ c(F)
        If c(E) = sum c_i(E) and c(F) = sum c_j(F),
        then c_k(E ⊕ F) = sum_{i+j=k} c_i(E) ∪ c_j(F)
        """
        max_degree = len(cE) + len(cF) - 2
        result = [0] * (max_degree + 1)
        result[0] = 1  # c_0 is always 1
        
        for i, ci in enumerate(cE):
            for j, cj in enumerate(cF):
                if i + j <= max_degree:
                    result[i + j] += ci * cj
        return result
    
    @staticmethod
    def chern_classes_projective_space(n):
        """
        Chern classes of CP^n.
        T(CP^n) ⊕ ε^1 = γ^* ⊕ ... ⊕ γ^* (n+1 times)
        where γ is the tautological line bundle.
        c(T(CP^n)) = (1 + a)^{n+1} / 1 = (1 + a)^{n+1}
        where a = c_1(γ^*) generates H^2(CP^n)
        """
        # c(CP^n) = (1 + a)^{n+1} = sum_{k=0}^{n+1} C(n+1,k) a^k
        # But c_{n+1} = 0 since dim CP^n = n, so we get n+1 terms
        from math import comb
        return [comb(n + 1, k) for k in range(n + 1)]
    
    @staticmethod
    def euler_characteristic_from_chern(n, c_n):
        """
        For a complex n-dimensional manifold,
        χ(M) = ∫_M c_n(TM)
        """
        return c_n

print(f"  Result: {c_sum}")

The Steenrod Algebra: Cohomology's Hidden Structure

steenrod-algebra

Motivation

The Steenrod algebra is the algebra of stable cohomology operations over \(\mathbb{Z}/p\mathbb{Z}\). It encodes deep information about the homotopy type of spaces and provides powerful tools for computing cobordism groups and stable homotopy groups. The Adams spectral sequence, which uses the Steenrod algebra as its input, remains one of the most effective methods for computing the stable homotopy groups of spheres.

Definitions

  • Steenrod Squares \(Sq^i\): Natural transformations \(Sq^i: H^n(X; \mathbb{Z}/2) \to H^{n+i}(X; \mathbb{Z}/2)\) satisfying specific axioms.
  • Steenrod Powers \(P^i\): The odd-primary analogues operating on \(\mathbb{Z}/p\) cohomology.
  • \(\mathcal{A}_p\)-Module: A graded vector space with an action of the Steenrod algebra satisfying the Adem relations.

Theorem: The Unstable Condition

Theorem: For a cohomology class \(x \in H^n(X; \mathbb{Z}/2)\), the Steenrod squares satisfy the unstable condition: \[Sq^i(x) = 0 \text{ for } i > n\] \[Sq^n(x) = x \smile x\]

Proof Sketch

The proof uses the construction of Steenrod squares via the cup-i products. For a cochain \(\alpha\) of degree \(n\), the cup-i products \(\alpha \cup_i \alpha\) are defined using the Alexander-Whitney diagonal approximation. The Steenrod square \(Sq^{n-i}(\alpha)\) is related to \(\alpha \cup_i \alpha\), and when \(i < 0\), this product vanishes, giving the unstable condition.

Notation Guide

  • \(Sq^i\) — Steenrod square of degree \(i\)
  • \(\mathcal{A}_2\) — Mod 2 Steenrod algebra
  • \(\mathcal{A}_p\) — Mod p Steenrod algebra
  • \(P^i\) — Steenrod reduced power (for odd \(p\))
  • \(\beta\) — Bockstein homomorphism

class SteenrodOperations:
    """Computations with Steenrod operations."""
    
    @staticmethod
    def unstable_check(x_degree, i):
        """
        Check if Sq^i(x) is possibly non-zero for x in degree n.
        Returns True if i <= n (unstable condition allows non-zero).
        """
        return i <= x_degree
    
    @staticmethod
    def top_square(x_degree):
        """
        Sq^n(x) = x ∪ x for x in degree n.
        Returns the degree of the result: 2n.
        """
        return 2 * x_degree
    
    @staticmethod
    def cartan_formula(sq_i, x_deg, y_deg):
        """
        Sq^k(x ∪ y) = sum_{i+j=k} Sq^i(x) ∪ Sq^j(y)
        Returns list of (i, j) pairs contributing to Sq^k.
        """
        # This shows which operations contribute
        pairs = []
        for i in range(sq_i + 1):
            j = sq_i - i
            if SteenrodOperations.unstable_check(x_deg, i) and \
               SteenrodOperations.unstable_check(y_deg, j):
                pairs.append((i, j))
        return pairs
    
    @staticmethod
    def wu_formula(k, n):
        """
        Wu formula relates Steenrod operations on Stiefel-Whitney classes.
        Sq^i(w_j) = sum_{t=0}^{i} C(j-i+t-1, t) w_{i-t} ∪ w_{j+t}
        """
        from math import comb
        terms = []
        for t in range(i + 1):
            coeff = comb(j - i + t - 1, t) % 2
            if coeff == 1:
                terms.append((i - t, j + t))
        return terms

Computational Fluid Dynamics: Numerical Solutions to Flow Problems

computational-fluid-dynamics

Motivation

Computational Fluid Dynamics (CFD) uses numerical methods to solve the equations governing fluid flow. It is essential in aerospace engineering, weather prediction, biomedical applications, and climate modeling. CFD bridges theoretical fluid mechanics with practical engineering design, enabling the simulation of complex flows that are impossible to study analytically.

Definitions

  • Navier-Stokes Equations: The governing equations for viscous, incompressible flow: \[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u}\] \[\nabla \cdot \mathbf{u} = 0\]
  • Reynolds Number: \(\text{Re} = \frac{UL}{\nu}\), the ratio of inertial to viscous forces.
  • Courant-Friedrichs-Lewy (CFL) Condition: A stability criterion for explicit time-stepping: \(\frac{u \Delta t}{\Delta x} \leq C\).

Theorem: Stability of the Heat Equation Discretization

Theorem: For the explicit finite difference scheme for the 1D heat equation \(u_t = \alpha u_{xx}\): \[\frac{u_j^{n+1} - u_j^n}{\Delta t} = \alpha \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{\Delta x^2}\] the scheme is stable if and only if the diffusion number satisfies: \[r = \frac{\alpha \Delta t}{\Delta x^2} \leq \frac{1}{2}\]

Proof Sketch

Using von Neumann stability analysis, substitute a Fourier mode \(u_j^n = g^n e^{ikj\Delta x}\) into the scheme. The amplification factor is: \[g = 1 - 4r \sin^2\left(\frac{k\Delta x}{2}\right)\] For stability, we require \(|g| \leq 1\) for all wavenumbers \(k\), which gives \(r \leq 1/2\).

Notation Guide

  • \(\mathbf{u}\) — Velocity vector field
  • \(p\) — Pressure
  • \(\rho\) — Density
  • \(\nu\) — Kinematic viscosity
  • \(\Delta t, \Delta x\) — Time and space discretization steps
  • \(u_j^n\) — Solution at grid point \(j\) and time step \(n\)

Python Code

import numpy as np
import matplotlib.pyplot as plt

class ComputationalFluidDynamics:
    """Simple CFD solvers for model problems."""
    
    @staticmethod
    def heat_equation_1d_explicit(u0, alpha, dx, dt, num_steps):
        """
        Solve 1D heat equation u_t = alpha * u_xx using explicit scheme.
        
        Parameters:
        -----------
        u0 : array
            Initial condition
        alpha : float
            Thermal diffusivity
        dx : float
            Spatial step
        dt : float
            Time step (must satisfy stability condition)
        num_steps : int
            Number of time steps
        
        Returns:
        --------
        u : array
            Solution at final time
        """
        u = u0.copy()
        r = alpha * dt / dx**2
        
        if r > 0.5:
            print(f"Warning: r = {r:.3f} > 0.5, scheme may be unstable!")
        
        n = len(u)
        for _ in range(num_steps):
            u_new = u.copy()
            # Interior points
            for j in range(1, n - 1):
                u_new[j] = u[j] + r * (u[j+1] - 2*u[j] + u[j-1])
            u = u_new
        
        return u
    
    @staticmethod
    def burgers_equation_1d(u0, nu, dx, dt, num_steps):
        """
        Solve 1D Burgers' equation u_t + u*u_x = nu * u_xx.
        Burgers' equation is a simplified model of the Navier-Stokes equations.
        """
        u = u0.copy()
        n = len(u)
        
        for _ in range(num_steps):
            u_new = u.copy()
            for j in range(1, n - 1):
                # Convective term (upwind for stability)
                if u[j] > 0:
                    conv = u[j] * (u[j] - u[j-1]) / dx
                else:
                    conv = u[j] * (u[j+1] - u[j]) / dx
                
                # Diffusive term
                diff = nu * (u[j+1] - 2*u[j] + u[j-1]) / dx**2
                
                u_new[j] = u[j] + dt * (-conv + diff)
            u = u_new
        
        return u
    
    @staticmethod
    def reynolds_number(U, L, nu):
        """Compute Reynolds number: Re = U*L/nu"""
        return U * L / nu
    
    @staticmethod
    def cfl_condition(u_max, dx, cfl_max=1.0):
        """Compute maximum stable time step from CFL condition."""
        return cfl_max * dx / u_max

# Example: Heat equation

# Initial condition: Gaussian
u0 = np.exp(-100 * (x - 0.5)**2)

# Stable time step

u_final = cfd.heat_equation_1d_explicit(u0, alpha, dx, dt, num_steps)

print(f"Heat equation solved with r = {alpha*dt/dx**2:.3f}")
print(f"Initial integral: {np.trapz(u0, x):.4f}")

Portfolio Optimization: Mean-Variance Analysis and Beyond

portfolio-optimization

Motivation

Portfolio optimization, pioneered by Harry Markowitz in 1952, provides a mathematical framework for constructing investment portfolios that balance expected return against risk. Modern portfolio theory uses optimization techniques from convex analysis and has been extended to incorporate transaction costs, market impact, and multiple risk measures.

Definitions

  • Expected Return: \(\mu = \mathbb{E}[R]\), the mean of asset returns.
  • Covariance Matrix: \(\Sigma_{ij} = \text{Cov}(R_i, R_j)\), measuring how assets move together.
  • Portfolio Return: \(R_p = w^T R = \sum_i w_i R_i\) where \(w_i\) are portfolio weights.
  • Portfolio Variance: \(\sigma_p^2 = w^T \Sigma w\).
  • Sharpe Ratio: \(S = \frac{\mu_p - r_f}{\sigma_p}\), risk-adjusted return.

Theorem: Markowitz Mean-Variance Optimization

Theorem: The portfolio weights \(w^*\) that minimize variance for a target return \(\mu_{target}\) solve: \[\min_w \frac{1}{2} w^T \Sigma w\] subject to: \[w^T \mu = \mu_{target}, \quad w^T \mathbf{1} = 1\]

The solution is: \[w^* = \frac{\mu_{target} - r_f}{\mu^T \Sigma^{-1} \mu - r_f \mathbf{1}^T \Sigma^{-1} \mu} \Sigma^{-1}(\mu - r_f \mathbf{1})\]

Proof Sketch

Using Lagrange multipliers for the constrained optimization: \[\mathcal{L} = \frac{1}{2} w^T \Sigma w - \lambda_1(w^T \mu - \mu_{target}) - \lambda_2(w^T \mathbf{1} - 1)\] Setting \(\nabla_w \mathcal{L} = 0\) yields \(\Sigma w = \lambda_1 \mu + \lambda_2 \mathbf{1}\). Solving for the multipliers using the constraints gives the result.

Notation Guide

  • \(w\) — Vector of portfolio weights
  • \(\mu\) — Vector of expected returns
  • \(\Sigma\) — Covariance matrix of returns
  • \(\sigma_p\) — Portfolio standard deviation (risk)
  • \(r_f\) — Risk-free rate
  • \(\lambda\) — Risk aversion parameter

Python Code

import numpy as np
from scipy.optimize import minimize

class PortfolioOptimization:
    """Mean-variance portfolio optimization."""
    
    def __init__(self, expected_returns, cov_matrix, risk_free_rate=0.02):
        """
        Parameters:
        -----------
        expected_returns : array
            Expected returns for each asset
        cov_matrix : 2D array
            Covariance matrix of returns
        risk_free_rate : float
            Risk-free rate
        """
        self.mu = np.array(expected_returns)
        self.Sigma = np.array(cov_matrix)
        self.rf = risk_free_rate
        self.n_assets = len(expected_returns)
    
    def portfolio_return(self, weights):
        """Expected portfolio return."""
        return np.dot(weights, self.mu)
    
    def portfolio_variance(self, weights):
        """Portfolio variance."""
        return np.dot(weights, np.dot(self.Sigma, weights))
    
    def portfolio_volatility(self, weights):
        """Portfolio volatility (standard deviation)."""
        return np.sqrt(self.portfolio_variance(weights))
    
    def sharpe_ratio(self, weights):
        """Sharpe ratio: (return - risk_free) / volatility"""
        ret = self.portfolio_return(weights)
        vol = self.portfolio_volatility(weights)
        return (ret - self.rf) / vol if vol > 0 else 0
    
    def minimum_variance_portfolio(self):
        """Find the minimum variance portfolio."""
        constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
        bounds = [(0, 1) for _ in range(self.n_assets)]
        x0 = np.ones(self.n_assets) / self.n_assets
        
        result = minimize(
            self.portfolio_variance,
            x0,
            method='SLSQP',
            bounds=bounds,
            constraints=constraints
        )
        return result.x
    
    def max_sharpe_portfolio(self):
        """Find the maximum Sharpe ratio portfolio."""
        def neg_sharpe(w):
            return -self.sharpe_ratio(w)
        
        constraints = [{'type': 'eq', 'fun': lambda w: np.sum(w) - 1}]
        bounds = [(0, 1) for _ in range(self.n_assets)]
        x0 = np.ones(self.n_assets) / self.n_assets
        
        result = minimize(
            neg_sharpe,
            x0,
            method='SLSQP',
            bounds=bounds,
            constraints=constraints
        )
        return result.x
    
    def efficient_frontier(self, n_points=50):
        """Compute the efficient frontier."""
        min_var_weights = self.minimum_variance_portfolio()
        min_var_return = self.portfolio_return(min_var_weights)
        
        max_sharpe_weights = self.max_sharpe_portfolio()
        max_return = self.portfolio_return(max_sharpe_weights)
        
        target_returns = np.linspace(min_var_return, max_return, n_points)
        efficient_portfolios = []
        
        for target in target_returns:
            constraints = [
                {'type': 'eq', 'fun': lambda w: np.sum(w) - 1},
                {'type': 'eq', 'fun': lambda w: self.portfolio_return(w) - target}
            ]
            bounds = [(0, 1) for _ in range(self.n_assets)]
            x0 = np.ones(self.n_assets) / self.n_assets
            
            result = minimize(
                self.portfolio_variance,
                x0,
                method='SLSQP',
                bounds=bounds,
                constraints=constraints
            )
            if result.success:
                efficient_portfolios.append({
                    'return': target,
                    'volatility': self.portfolio_volatility(result.x),
                    'weights': result.x
                })
        
        return efficient_portfolios

Mathematical Neuroscience: From Neurons to Networks

neuroscience-modeling

Motivation

Mathematical neuroscience uses differential equations, dynamical systems, and probability theory to understand how neurons generate electrical signals, how neural circuits process information, and how large-scale brain dynamics emerge from microscopic interactions. Models range from detailed biophysical descriptions to simplified phenomenological equations.

Definitions

  • Hodgkin-Huxley Model: A system of four coupled ODEs describing action potential generation: \[C_m \frac{dV}{dt} = I_{ext} - \bar{g}_{Na}m^3h(V - E_{Na}) - \bar{g}_K n^4(V - E_K) - g_L(V - E_L)\]
  • Membrane Potential \(V\): The voltage difference across the neuronal membrane.
  • Gating Variables \(m, h, n\): Probabilities of ion channel gates being open.
  • Firing Rate: The average number of spikes per unit time.

Theorem: Threshold for Action Potential Generation

Theorem: In the FitzHugh-Nagumo simplification of the Hodgkin-Huxley model: \[\frac{dv}{dt} = v - \frac{v^3}{3} - w + I\] \[\tau \frac{dw}{dt} = v + a - bw\] there exists a critical current \(I_c\) such that for \(I > I_c\), the system exhibits sustained oscillations (periodic firing), while for \(I < I_c\), the system settles to a stable rest state.

Proof Sketch

The proof uses bifurcation analysis. The nullclines of the system intersect at equilibrium points. As \(I\) increases, the fixed point changes stability through a Hopf bifurcation, giving rise to a limit cycle. The critical current \(I_c\) corresponds to the bifurcation point where the eigenvalues of the linearization cross the imaginary axis.

Notation Guide

  • \(V\) — Membrane potential (mV)
  • \(C_m\) — Membrane capacitance
  • \(g_{Na}, g_K, g_L\) — Conductances for sodium, potassium, leak currents
  • \(E_{Na}, E_K, E_L\) — Reversal potentials
  • \(m, h, n\) — Gating variables (activation and inactivation)
  • \(\tau\) — Time constant

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

class NeuroscienceModels:
    """Models of neuronal dynamics."""
    
    @staticmethod
    def hodgkin_huxley(state, t, I_ext):
        """
        Hodgkin-Huxley model for action potential generation.
        
        Parameters:
        -----------
        state : [V, m, h, n]
            Membrane potential and gating variables
        t : time
        I_ext : external current
        """
        V, m, h, n = state
        
        # Parameters (standard Hodgkin-Huxley)
        C_m = 1.0  # uF/cm^2
        g_Na = 120.0  # mS/cm^2
        g_K = 36.0
        g_L = 0.3
        E_Na = 50.0  # mV
        E_K = -77.0
        E_L = -54.387
        
        # Alpha and beta functions for gating variables
        alpha_m = 0.1 * (V + 40) / (1 - np.exp(-(V + 40) / 10))
        beta_m = 4.0 * np.exp(-(V + 65) / 18)
        alpha_h = 0.07 * np.exp(-(V + 65) / 20)
        beta_h = 1.0 / (1 + np.exp(-(V + 35) / 10))
        alpha_n = 0.01 * (V + 55) / (1 - np.exp(-(V + 55) / 10))
        beta_n = 0.125 * np.exp(-(V + 65) / 80)
        
        # Gating variable dynamics
        dmdt = alpha_m * (1 - m) - beta_m * m
        dhdt = alpha_h * (1 - h) - beta_h * h
        dndt = alpha_n * (1 - n) - beta_n * n
        
        # Ionic currents
        I_Na = g_Na * m**3 * h * (V - E_Na)
        I_K = g_K * n**4 * (V - E_K)
        I_L = g_L * (V - E_L)
        
        # Membrane potential equation
        dVdt = (I_ext - I_Na - I_K - I_L) / C_m
        
        return [dVdt, dmdt, dhdt, dndt]
    
    @staticmethod
    def fitzhugh_nagumo(state, t, I, a=0.7, b=0.8, tau=12.5):
        """
        FitzHugh-Nagumo model - simplified neuronal dynamics.
        
        dv/dt = v - v^3/3 - w + I
        tau * dw/dt = v + a - b*w
        """
        v, w = state
        dvdt = v - v**3 / 3 - w + I
        dwdt = (v + a - b * w) / tau
        return [dvdt, dwdt]
    
    @staticmethod
    def integrate_neuron(model, initial_state, t, **params):
        """Integrate a neuron model."""
        if model == 'hh':
            solution = odeint(NeuroscienceModels.hodgkin_huxley, 
                            initial_state, t, args=(params.get('I_ext', 10),))
        elif model == 'fn':
            solution = odeint(NeuroscienceModels.fitzhugh_nagumo,
                            initial_state, t, args=(params.get('I', 0.5),))
        return solution
    
    @staticmethod
    def firing_rate_threshold(I_values, model='fn'):
        """
        Determine firing rate as a function of input current.
        """
        firing_rates = []
        t = np.linspace(0, 200, 2000)
        
        for I in I_values:
            if model == 'fn':
                sol = odeint(NeuroscienceModels.fitzhugh_nagumo,
                           [0, 0], t, args=(I,))
                v = sol[:, 0]
                # Count spikes (threshold crossings)
                threshold = 0
                spikes = np.sum((v[:-1] < threshold) & (v[1:] >= threshold))
                firing_rate = spikes / (t[-1] / 1000)  # Hz
                firing_rates.append(firing_rate)
        
        return np.array(firing_rates)

Hodge Theory: Harmonic Forms and Algebraic Topology

hodge-theory

Historical Context

Hodge theory, developed by W.V.D. Hodge in the 1930s, provides a deep connection between analysis, topology, and algebraic geometry. Hodge's insight was that on a compact Riemannian manifold, every cohomology class has a unique harmonic representative—a differential form that is both closed and co-closed. This theorem has profound implications for understanding the topology of complex manifolds and varieties.

Definitions

  • Hodge Star \(*\): An operator \(*: \Omega^k(M) \to \Omega^{n-k}(M)\) satisfying \(\alpha \wedge *\beta = \langle \alpha, \beta \rangle \text{vol}\).
  • Co-differential \(\delta\): \(\delta = (-1)^{n(k+1)+1} * d *\), the adjoint of \(d\).
  • Laplacian \(\Delta\): \(\Delta = d\delta + \delta d\).
  • Harmonic Form: A form \(\omega\) with \(\Delta \omega = 0\).

Theorem: The Hodge Decomposition

Theorem: For a compact, oriented Riemannian manifold \((M, g)\), the space of differential k-forms decomposes orthogonally: \[\Omega^k(M) = \mathcal{H}^k(M) \oplus d\Omega^{k-1}(M) \oplus \delta\Omega^{k+1}(M)\] where \(\mathcal{H}^k(M)\) is the space of harmonic k-forms. Consequently: \[H^k_{dR}(M) \cong \mathcal{H}^k(M)\]

Proof Sketch

The proof relies on the ellipticity of the Laplacian and the theory of elliptic operators on compact manifolds. Key steps:

  1. Show that \(\Delta\) is a self-adjoint, elliptic operator.
  2. Use the Fredholm alternative: \(\text{ker}(\Delta) \cong \text{coker}(\Delta)\).
  3. Prove that a form is harmonic if and only if it is both closed and co-closed.
  4. Establish the orthogonal decomposition using the formal self-adjointness of \(d\) and \(\delta\).

Notation Guide

  • \(\Omega^k(M)\) — Space of smooth k-forms on M
  • \(\mathcal{H}^k(M)\) — Space of harmonic k-forms
  • \(d\) — Exterior derivative
  • \(\delta\) — Co-differential
  • \(*\) — Hodge star operator
  • \(\Delta\) — Hodge Laplacian

class HodgeTheory:
    """Computations related to Hodge theory on simplicial complexes."""
    
    @staticmethod
    def hodge_star_0d(volume_ratio):
        """
        Hodge star on 0-forms: maps functions to top-forms.
        In discrete setting: *f(v) = f(v) * vol(v)
        """
        return np.diag(volume_ratio)
    
    @staticmethod
    def discrete_laplacian_0d(adjacency, vertex_volumes):
        """
        Discrete Laplacian on 0-forms (graph Laplacian weighted by volumes).
        L = D - A where D is degree matrix, A is adjacency.
        """
        n = len(vertex_volumes)
        degree = np.sum(adjacency, axis=1)
        L = np.diag(degree) - adjacency
        # Weight by inverse volumes for Hodge Laplacian
        V_inv = np.diag(1.0 / vertex_volumes)
        return V_inv @ L
    
    @staticmethod
    def harmonic_0forms(laplacian, tolerance=1e-10):
        """
        Find harmonic 0-forms (constant functions on connected components).
        These correspond to eigenvectors with eigenvalue ~0.
        """
        eigenvalues, eigenvectors = np.linalg.eigh(laplacian)
        harmonic_mask = np.abs(eigenvalues) < tolerance
        return eigenvalues[harmonic_mask], eigenvectors[:, harmonic_mask]
    
    @staticmethod
    def betti_number_0(laplacian):
        """
        0-th Betti number = number of connected components
        = dimension of harmonic 0-forms
        """
        eigenvalues = np.linalg.eigvalsh(laplacian)
        return np.sum(np.abs(eigenvalues) < 1e-10)
    
    @staticmethod
    def hodge_decomposition_1d(edges, edge_values, vertex_volumes):
        """
        For a 1D simplicial complex (graph), decompose edge values into:
        - exact (gradient): df for some f
        - co-exact (curl): *dg for some g  
        - harmonic: both closed and co-closed
        """
        # Build edge-vertex incidence matrix

        n_vertices = len(vertex_volumes)

        # In practice, use proper boundary operators
        
        # For a tree, all 1-forms are exact
        # For a graph with cycles, harmonic forms correspond to cycles
        
        return {
            'exact': None,  # Would require solving for potential
            'coexact': None,
            'harmonic_dim': 1 if n_edges >= n_vertices else 0

Algebraic Cycles: Subvarieties and Their Equivalence

algebraic-cycles

Historical Context

The study of algebraic cycles dates back to the Italian school of algebraic geometry in the late 19th century, but it was codified into a systematic theory by Weil, Chow, and others in the mid-20th century. The Hodge conjecture and the Tate conjecture—two of the deepest open problems in mathematics—concern the relationship between algebraic cycles and cohomology classes.

Definitions

  • Algebraic Cycle: A formal finite sum \(\sum n_i [V_i]\) where \(V_i\) are irreducible subvarieties of codimension \(p\).
  • Rational Equivalence: Two cycles are rationally equivalent if they differ by the divisor of a rational function on a subvariety.
  • Chow Group \(CH^p(X)\): The group of codimension-\(p\) cycles modulo rational equivalence.
  • Cycle Class Map: \(cl: CH^p(X) \to H^{2p}(X, \mathbb{Z})\) sending a subvariety to its cohomology class.

Theorem: The Lefschetz (1,1) Theorem

Theorem: For a smooth projective variety \(X\) over \(\mathbb{C}\), the cycle class map \[Pic(X) = CH^1(X) \to H^2(X, \mathbb{Z}) \cap H^{1,1}(X)\] is an isomorphism. That is, every integral (1,1)-class is the class of a divisor.

Proof Sketch

The proof uses the exponential exact sequence: \[0 \to \mathbb{Z} \to \mathcal{O}_X \to \mathcal{O}_X^* \to 0\] Taking cohomology yields: \[H^1(X, \mathcal{O}_X^*) \to H^2(X, \mathbb{Z}) \to H^2(X, \mathcal{O}_X)\] The group \(H^1(X, \mathcal{O}_X^*)\) is the Picard group \(Pic(X)\). The image of \(Pic(X)\) in \(H^2(X, \mathbb{Z})\) is precisely \(H^2(X, \mathbb{Z}) \cap H^{1,1}(X)\) by Hodge theory.

Notation Guide

  • \(CH^p(X)\) — Chow group of codimension-p cycles
  • \([V]\) — Fundamental class of subvariety V
  • \(\sim_{rat}\) — Rational equivalence
  • \(Pic(X)\) — Picard group (line bundles / divisors)
  • \(H^{p,q}(X)\) — Hodge decomposition components

        intersect in d1*d2*d points (counted with multiplicity).
        """
        return curve1_degree * curve2_degree * surface_degree

    def chow_group_dim_codim1(genus):

        For a curve of genus g, Pic^0 has dimension g.
        """
        return genus

        is generated by algebraic cycles.

        - p = 0, n: trivial (always true)
        - p = 1, n: Lefschetz (1,1) theorem (true)
        - p = n-1, n: follows from hard Lefschetz
        """

            (1, 1),  # Curves

        ]

    def self_intersection_curve(genus, canonical_degree):

        C^2 = 2g - 2 - K.C (adjunction formula related)
        """
        return 2 * genus - 2

        Bezout's theorem: n hypersurfaces in P^n of degrees d1,...,dn
        intersect in d1*...*dn points (counted with multiplicity).
        """
        result = 1
        for d in degrees:
            result *= d
        return result

Motivic Homotopy Theory: A^1-Homotopy and Algebraic Geometry

motivic-homotopy

Historical Context

Motivic homotopy theory was founded by Fabien Morel and Vladimir Voevodsky in the 1990s. Voevodsky's development of this theory was crucial to his proof of the Milnor conjecture (later the norm residue isomorphism theorem), for which he received the Fields Medal in 2002. The theory provides a framework for doing homotopy theory in algebraic geometry, where the affine line \(\mathbb{A}^1\) plays the role of the unit interval.

Definitions

  • \(\mathbb{A}^1\)-Homotopy: Two morphisms \(f, g: X \to Y\) are \(\mathbb{A}^1\)-homotopic if there exists \(H: X \times \mathbb{A}^1 \to Y\) with \(H_0 = f\) and \(H_1 = g\).
  • Motivic Space: A simplicial presheaf on the category of smooth schemes.
  • Motivic Sphere: \(S^{p,q} = (S^1)^{\wedge (p-q)} \wedge \mathbb{G}_m^{\wedge q}\), where \(\mathbb{G}_m = \mathbb{A}^1 \setminus \{0\}\).
  • Motivic Cohomology: \(H^{p,q}_{\mathcal{M}}(X, \mathbb{Z}) = [X_+, S^{p,q} \wedge K(\mathbb{Z}(q), 2q)]\).

Theorem: The Motivic Degree

Theorem: (Morel) For a field \(k\), the motivic homotopy group \(\pi^{\mathbb{A}^1}_{0,0}(S^{0,0})\) is isomorphic to the Grothendieck-Witt ring \(GW(k)\) of quadratic forms over \(k\). The degree map \[\deg^{\mathbb{A}^1}: [S^{n,n}, S^{n,n}]^{\mathbb{A}^1} \to GW(k)\] is an isomorphism for \(n \geq 1\).

Proof Sketch

The proof uses the purity theorem and the geometric model for motivic spheres. Key steps:

  1. Show that endomorphisms of motivic spheres are generated by suspension and the Hopf map.
  2. Use the fact that \(\mathbb{A}^1\)-homotopy classes of maps to \(\mathbb{G}_m\) correspond to units in the field.
  3. Construct the degree map using the Thom isomorphism in motivic cohomology.
  4. Prove injectivity by analyzing the behavior on real and complex realizations.

Notation Guide

  • \(\mathbb{A}^1\) — Affine line
  • \(\mathbb{G}_m\) — Multiplicative group \(\mathbb{A}^1 \setminus \{0\}\)
  • \(S^{p,q}\) — Motivic sphere of weight (p,q)
  • \([X, Y]^{\mathbb{A}^1}\) — \(\mathbb{A}^1\)-homotopy classes of maps
  • \(GW(k)\) — Grothendieck-Witt ring
  • \(K(\mathbb{Z}(q), 2q)\) — Motivic Eilenberg-MacLane space

Alexander Grothendieck: Revolutionizing Modern Mathematics

grothendieck

Historical Context

Alexander Grothendieck (1928–2014) was one of the most influential mathematicians of the 20th century. His radical restructuring of algebraic geometry in the 1950s and 1960s, documented in the monumental EGA (Éléments de Géométrie Algébrique) series with Jean Dieudonné, introduced concepts that are now fundamental: schemes, sheaves, cohomology theories, and topos theory. His work unified number theory, algebraic geometry, and complex analysis.

Key Contributions

  • Schemes: Generalized algebraic varieties to allow "geometry over any ring."
  • Topos Theory: A categorical generalization of topological spaces and sheaves.
  • Étale Cohomology: A Weil cohomology theory for algebraic varieties over any field.
  • Grothendieck-Riemann-Roch: A far-reaching generalization of the classical Riemann-Roch theorem.
  • Motives: A conjectural universal cohomology theory for algebraic varieties.

Theorem: Grothendieck-Riemann-Roch

Theorem: Let \(f: X \to Y\) be a proper morphism of smooth quasi-projective varieties. Then for any coherent sheaf \(\mathcal{F}\) on \(X\): \[f_*(ch(\mathcal{F}) \cdot td(T_X)) = ch(f_!\mathcal{F}) \cdot td(T_Y)\] in the Chow group \(A(Y) \otimes \mathbb{Q}\), where \(ch\) is the Chern character, \(td\) is the Todd class, and \(f_!\) is the derived pushforward.

Proof Sketch

The proof proceeds by reduction to fundamental cases:

  1. Projection formula: For a projective bundle \(\mathbb{P}(E) \to X\).
  2. Closed immersion: Using the deformation to the normal cone.
  3. General case: Factor \(f\) as a closed immersion followed by a projection.

The key insight is that both sides define natural transformations from the Grothendieck group of coherent sheaves to Chow theory, and they agree on generators.

Notation Guide

  • \(ch(E)\) — Chern character of vector bundle E
  • \(td(E)\) — Todd class of E
  • \(f_!\) — Derived pushforward (alternating sum of higher direct images)
  • \(A(X)\) — Chow ring of X
  • \(K_0(X)\) — Grothendieck group of coherent sheaves

        ch(L) = exp(c1) = 1 + c1 + c1^2/2! + c1^3/3! + ...
        """

        for k in range(max_degree + 1):

            terms.append((k, coeff))

    def todd_class_dimension(dim):

        td = 1 + td_1 + td_2 + ... where td_k is in degree 2k.
        
        td_1 = c_1/2
        td_2 = (c_1^2 + c_2)/12
        td_3 = c_1*c_2/24
        """
        formulas = {
            0: "td_0 = 1",
            1: "td_1 = c_1/2",
            2: "td_2 = (c_1^2 + c_2)/12",
            3: "td_3 = c_1*c_2/24",
            4: "td_4 = (-c_1^4 + 4c_1^2*c_2 + 3c_2^2 + c_1*c_3 - c_4)/720"
        }
        return formulas.get(dim, f"td_{dim} (complex formula)")
    
    @staticmethod
    def grothendieck_riemann_roch_euler(chern_classes, dimension):
        """
        Compute Euler characteristic using GRR for a line bundle.
        χ(X, L) = ∫_X ch(L) · td(T_X)
        
        For a surface (dim 2):
        χ = (c_1(L)^2 - c_1(L)·K_X)/2 + χ(O_X)
        where K_X = -c_1(T_X) is the canonical divisor.
        """
        if dimension == 1:
            # Curve: χ = deg(L) + 1 - g
            c1 = chern_classes.get('c1_L', 0)
            g = chern_classes.get('genus', 0)
            return c1 + 1 - g
        elif dimension == 2:
            # Surface
            c1_L = chern_classes.get('c1_L', 0)
            c1_X = chern_classes.get('c1_X', 0)
            c2_X = chern_classes.get('c2_X', 0)
            chi_O = chern_classes.get('chi_O', 1)
            # χ = (c1(L)^2 - c1(L)·c1(X))/2 + chi(O_X)
            return (c1_L**2 - c1_L * c1_X) / 2 + chi_O
        return "Higher dimensions require more terms"
    
    @staticmethod
    def betti_number_hodge(hodge_numbers, k):
        """
        Compute Betti numbers from Hodge numbers.
        b_k = sum_{p+q=k} h^{p,q}
        """
        b_k = 0
        for p in range(k + 1):
            q = k - p
            if p < len(hodge_numbers) and q < len(hodge_numbers[p]):
                b_k += hodge_numbers[p][q]
        return b_k
    
    @staticmethod
    def signature_hodge(hodge_numbers, n):
        """
        Signature of a 2n-dimensional manifold from Hodge numbers.
        σ = sum_{p,q} (-1)^p h^{p,q}
        """
        signature = 0
        for p in range(n + 1):
            for q in range(n + 1):
                if p < len(hodge_numbers) and q < len(hodge_numbers[p]):
                    signature += ((-1)**p) * hodge_numbers[p][q]
        return signature

📜 Math History: The Birth of Modern Algebraic Geometry

The transformation of algebraic geometry from a subject focused on concrete equations and curves to a discipline built on abstract structures and general methods is one of the most remarkable stories in 20th-century mathematics. This revolution was driven by a small group of mathematicians working primarily in the 1940s through the 1960s, with Alexander Grothendieck as its central figure.

Before Grothendieck, algebraic geometry was dominated by the Italian school (Castelnuovo, Enriques, Severi) and later by Zariski and Weil. These mathematicians worked with algebraic varieties over the complex numbers or other fields, using geometric intuition and commutative algebra. However, the foundations were not entirely rigorous, and the theory lacked the flexibility to handle phenomena like reduction modulo p or families of varieties.

Grothendieck's insight was to replace varieties with schemes—locally ringed spaces that look locally like the spectrum of a ring. This seemingly technical change had profound consequences. Suddenly, one could do geometry over any ring, including finite fields, p-adic integers, and even rings of integers in number fields. The arithmetic of varieties became part of their geometry.

The development of sheaf theory and cohomology in this context was equally transformative. Grothendieck introduced étale cohomology to prove the Weil conjectures, which he completed with Pierre Deligne in 1974. This work connected the topology of complex varieties to the arithmetic of varieties over finite fields in ways that seemed miraculous.

The influence of Grothendieck's work extends far beyond algebraic geometry. His emphasis on universal properties, representable functors, and categorical thinking has shaped modern mathematics. The concept of a topos, developed with his student Michael Artin, provided a framework for cohomology theories and influenced logic and computer science. His ideas about motives—conjectural building blocks of cohomology—remain active research topics today.

By the time Grothendieck left mathematics in 1970, the landscape of the subject had been permanently altered. The abstract, structural approach he championed became the standard, enabling proofs of theorems that would have been inconceivable in the classical framework.

Putnam Competition Problem: Cohomology of a Product Space

Problem: Let \(X\) and \(Y\) be compact, connected, orientable manifolds of dimensions \(m\) and \(n\) respectively. Suppose \(H^*(X; \mathbb{Q})\) and \(H^*(Y; \mathbb{Q})\) are generated by degree-1 classes. Prove that the signature of the product manifold \(X \times Y\) is zero unless both \(m\) and \(n\) are divisible by 4.

💡 Hint

Use the Künneth formula to express the middle cohomology of \(X \times Y\) in terms of the cohomology of the factors. Then analyze the intersection form on each component. Remember that the signature is multiplicative for products when both dimensions are multiples of 4.

✅ Solution

Solution: The dimension of \(X \times Y\) is \(m + n\). For the signature to be potentially non-zero, we need \(m + n \equiv 0 \pmod{4}\).

By the Künneth formula: \[H^k(X \times Y) \cong \bigoplus_{i+j=k} H^i(X) \otimes H^j(Y)\]

Since all generators are in degree 1, the only non-zero cohomology groups are in degrees that are sums of 1s, i.e., all degrees from 0 to \(m\) for \(X\) and 0 to \(n\) for \(Y\).

The middle cohomology of \(X \times Y\) is in degree \((m+n)/2\). The cup product structure shows that the intersection form on \(H^{(m+n)/2}(X \times Y)\) decomposes as a sum of tensor products of forms from \(X\) and \(Y\).

When \(m \equiv 2 \pmod{4}\) and \(n \equiv 2 \pmod{4}\), we have \(m + n \equiv 0 \pmod{4}\), but the signature vanishes because the middle-dimensional forms pair off with opposite signs. Specifically, the contribution from \(H^{m/2}(X) \otimes H^{n/2}(Y)\) has signature \(\sigma(X)\sigma(Y)\), but when \(m/2\) and \(n/2\) are odd, these forms are isotropic.

Only when both \(m \equiv 0 \pmod{4}\) and \(n \equiv 0 \pmod{4}\) do we get a non-trivial signature, given by \(\sigma(X \times Y) = \sigma(X)\sigma(Y)\).

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def sphere_vector_field(theta, phi, field_type='dipole'):
    """
    Define vector fields on the sphere S^2.
    
    Parameters:
    -----------
    theta : array
        Azimuthal angle [0, 2π]
    phi : array  
        Polar angle [0, π]
    field_type : str
        'dipole', 'rotation', or 'hairy_ball'
    
    Returns:
    --------
    u, v, w : components of vector field in 3D
    """
    # Convert to Cartesian
    x = np.sin(phi) * np.cos(theta)
    y = np.sin(phi) * np.sin(theta)
    z = np.cos(phi)
    
    if field_type == 'dipole':
        # Dipole field: vectors point from south to north pole
        # This has two singularities (index +1 each)
        u = -x * z
        v = -y * z
        w = 1 - z**2
        
    elif field_type == 'rotation':
        # Rotation about z-axis
        # No singularities but not tangent everywhere
        u = -y
        v = x
        w = np.zeros_like(z)
        
    elif field_type == 'hairy_ball':
        # Attempt at a nowhere-zero field (impossible by Hairy Ball Theorem)
        # This will have singularities
        u = np.cos(theta) * np.cos(phi)
        v = np.sin(theta) * np.cos(phi)
        w = -np.sin(phi)
    
    # Project to tangent space (remove normal component)
    normal_x, normal_y, normal_z = x, y, z
    dot = u * normal_x + v * normal_y + w * normal_z
    u_tan = u - dot * normal_x
    v_tan = v - dot * normal_y
    w_tan = w - dot * normal_z
    
    return u_tan, v_tan, w_tan
