Geometric Measure Theory: Measuring the Unmeasurable

geometric-measure-theory

Motivation

How do we measure the area of a fractal curve, or the volume of a jagged surface? Geometric measure theory, developed by mathematicians like Besicovitch, Federer, and Almgren, extends classical measure theory to handle irregular geometric objects. It provides the rigorous framework for studying minimal surfaces, rectifiable sets, and the calculus of variations. Applications range from image processing and computer vision to the study of soap films, crystal growth, and the structure of singularities in partial differential equations.

Definitions

  • Hausdorff Measure: For a set \(A \subset \mathbb{R}^n\) and dimension \(s \geq 0\): \(\mathcal{H}^s(A) = \lim_{\delta \to 0} \inf \left\{\sum_i (\text{diam } U_i)^s : A \subset \bigcup_i U_i, \text{diam } U_i < \delta\right\}\).
  • Hausdorff Dimension: \(\dim_H(A) = \inf\{s : \mathcal{H}^s(A) = 0\} = \sup\{s : \mathcal{H}^s(A) = \infty\}\).
  • Rectifiable Set: A set that can be approximated by Lipschitz images of Euclidean spaces; has tangent planes almost everywhere.
  • Current: A generalized surface defined as a continuous linear functional on differential forms, extending the notion of integration over manifolds.
  • Varifold: A measure-theoretic generalization of a submanifold that records both position and tangent space information.

Theorem: The Coarea Formula

Theorem (Coarea Formula): Let \(f: \mathbb{R}^n \to \mathbb{R}^m\) be Lipschitz with \(n \geq m\), and let \(A \subset \mathbb{R}^n\) be measurable. Then:

\[\int_A Jf(x) \, dx = \int_{\mathbb{R}^m} \mathcal{H}^{n-m}(A \cap f^{-1}(y)) \, dy\]

where \(Jf(x) = \sqrt{\det(Df(x) \cdot Df(x)^T)}\) is the Jacobian determinant.

Special Case (Sard's Theorem): The set of critical values has measure zero.

Proof Sketch

The proof proceeds by approximating \(f\) with piecewise linear functions, for which the formula follows from Fubini's theorem. For the general case, one uses Rademacher's theorem (Lipschitz functions are differentiable almost everywhere) and the area formula for Lipschitz maps. The key insight is that the Jacobian measures how much the map distorts volume locally.

Notation Guide

  • \(\mathcal{H}^s\): s-dimensional Hausdorff measure
  • \(\dim_H(A)\): Hausdorff dimension of set \(A\)
  • \(Jf(x)\): Jacobian determinant of \(f\) at \(x\)
  • \(\text{Lip}(f)\): Lipschitz constant of \(f\)
  • \(\mathbf{M}(T)\): Mass of a current \(T\)
  • \(\partial T\): Boundary of a current

Operator Algebras: The Infinite-Dimensional Symphony

operator-algebras

Motivation

How do we study infinite-dimensional symmetries? Operator algebras, developed by von Neumann and Murray in the 1930s, provide the framework for understanding algebras of operators on Hilbert spaces. Originally motivated by quantum mechanics, the theory has grown into a vast field connecting functional analysis, topology, geometry, and quantum field theory. The classification of factors by Connes, using his revolutionary "injection of the hyperfinite" technique, remains one of the deepest achievements in 20th-century mathematics.

Definitions

  • C*-Algebra: A Banach *-algebra satisfying \(\|a^*a\| = \|a\|^2\) for all \(a\). Represents continuous functions on non-commutative spaces.
  • von Neumann Algebra: A *-subalgebra of \(\mathcal{B}(\mathcal{H})\) that is closed in the weak operator topology. Equivalently, equals its double commutant (von Neumann's bicommutant theorem).
  • Factor: A von Neumann algebra with trivial center \(\mathcal{Z}(M) = \mathbb{C}I\). Factors are classified as type I, II, or III.
  • Trace: A linear functional \(\tau: M \to \mathbb{C}\) with \(\tau(ab) = \tau(ba)\) and \(\tau(I) = 1\). Finite factors admit unique normal traces.
  • Tomita-Takesaki Theory: For a von Neumann algebra \(M\) with cyclic separating vector \(\Omega\), defines modular operator \(\Delta\) and modular automorphism group \(\sigma_t\).

Theorem: The Gelfand-Naimark-Segal (GNS) Construction

Theorem (GNS): Let \(A\) be a C*-algebra with a state \(\varphi\) (positive linear functional with \(\|\varphi\| = 1\)). Then there exists:

  1. A Hilbert space \(\mathcal{H}_\varphi\)
  2. A *-representation \(\pi_\varphi: A \to \mathcal{B}(\mathcal{H}_\varphi)\)
  3. A cyclic vector \(\Omega_\varphi \in \mathcal{H}_\varphi\) with \(\|\Omega_\varphi\| = 1\)

such that \(\varphi(a) = \langle \pi_\varphi(a)\Omega_\varphi, \Omega_\varphi \rangle\) for all \(a \in A\).

Proof Sketch

Define a sesquilinear form on \(A\) by \(\langle a, b \rangle_\varphi = \varphi(b^*a)\). This is positive semi-definite. Let \(N = \{a : \varphi(a^*a) = 0\}\) and form the quotient \(A/N\). Complete to get \(\mathcal{H}_\varphi\). The representation is defined by \(\pi_\varphi(a)[b] = [ab]\). The vector \(\Omega_\varphi = [I]\) is cyclic by construction.

Notation Guide

  • \(\mathcal{B}(\mathcal{H})\): Bounded operators on Hilbert space \(\mathcal{H}\)
  • \(M'\): Commutant of algebra \(M\)
  • \(M''\): Double commutant (bicommutant)
  • \(a^*\): Adjoint of operator \(a\)
  • \(\sigma(M)\): Spectrum of operator \(M\)
  • \(\|a\|_{op}\): Operator norm

Model Theory: Logic Meets Algebra

model-theory

Motivation

Can we understand algebraic structures through the lens of logic? Model theory, a branch of mathematical logic, studies the relationship between formal languages and their interpretations (models). It reveals deep connections between logic and algebra, geometry, and number theory. The work of Morley, Shelah, and Hrushovski has shown that model-theoretic techniques can solve concrete problems in algebraic geometry and diophantine geometry. Stability theory, o-minimality, and motivic integration are powerful tools that bridge the gap between abstract logic and concrete mathematics.

Definitions

  • Structure: A set \(M\) equipped with interpretations of function symbols, relation symbols, and constant symbols from a signature \(\mathcal{L}\).
  • Theory: A consistent set of sentences in a first-order language. \(\text{Th}(M)\) denotes the complete theory of structure \(M\).
  • Elementary Equivalence: \(M \equiv N\) if they satisfy the same sentences. Notation: \(M \models \varphi\) means \(M\) satisfies formula \(\varphi\).
  • Saturated Model: A model that realizes all types over small parameter sets. Provides a "rich" environment for constructing elements.
  • Stability: A theory is stable if no formula has the order property (cannot define arbitrary linear orders on infinite sets).
  • O-minimal Structure: A totally ordered structure where every definable set is a finite union of intervals and points.

Theorem: The Compactness Theorem

Theorem (Compactness): A set of first-order sentences \(\Sigma\) has a model if and only if every finite subset of \(\Sigma\) has a model.

Corollary (Löwenheim-Skolem): If a theory \(T\) has an infinite model, then it has models of every infinite cardinality.

Corollary: If a theory has arbitrarily large finite models, it has an infinite model.

Proof Sketch

The standard proof uses the completeness theorem: \(\Sigma\) is consistent iff every finite subset is consistent. Alternatively, one can use ultraproducts: if every finite subset has a model, construct an ultraproduct of these models using a non-principal ultrafilter on the index set. The resulting ultraproduct satisfies all of \(\Sigma\) by Łoś's theorem.

Notation Guide

  • \(M \models \varphi\): Structure \(M\) satisfies formula \(\varphi\)
  • \(M \equiv N\): Elementary equivalence
  • \(M \preceq N\): Elementary substructure
  • \(S_n(A)\): Space of complete \(n\)-types over parameter set \(A\)
  • \(\text{tp}(a/A)\): Type of element \(a\) over \(A\)
  • \(\text{acl}(A)\): Algebraic closure of \(A\)

from itertools import combinations

def evaluate_formula(structure, formula, assignment=None):
    """
    Simplified formula evaluator for finite structures.
    
    structure: dict with 'domain', 'relations', 'functions'
    formula: nested tuple representing logical formula
    assignment: dict mapping variables to domain elements
    """
    if assignment is None:
        assignment = {}
    
    op = formula[0]
    
    if op == 'atomic':
        # (atomic, relation_name, (terms...))
        rel_name = formula[1]
        terms = formula[2]
        # Evaluate terms to get elements
        elements = tuple(evaluate_term(structure, t, assignment) for t in terms)
        return elements in structure['relations'].get(rel_name, set())
    
    elif op == 'and':
        return all(evaluate_formula(structure, f, assignment) for f in formula[1:])
    
    elif op == 'or':
        return any(evaluate_formula(structure, f, assignment) for f in formula[1:])
    
    elif op == 'not':
        return not evaluate_formula(structure, formula[1], assignment)
    
    elif op == 'exists':
        var = formula[1]
        subformula = formula[2]
        for elem in structure['domain']:
            new_assignment = assignment.copy()
            new_assignment[var] = elem
            if evaluate_formula(structure, subformula, new_assignment):
                return True
        return False
    
    elif op == 'forall':
        var = formula[1]
        subformula = formula[2]
        for elem in structure['domain']:
            new_assignment = assignment.copy()
            new_assignment[var] = elem
            if not evaluate_formula(structure, subformula, new_assignment):
                return False
        return True

def evaluate_term(structure, term, assignment):
    """Evaluate a term to get a domain element."""
    if isinstance(term, str) and term.startswith('var_'):
        return assignment[term]
    elif isinstance(term, tuple):
        # Function application
        func_name = term[0]
        args = tuple(evaluate_term(structure, t, assignment) for t in term[1:])
        return structure['functions'][func_name][args]
    else:
        return term  # Constant

def check_compactness(structures, formula_set):
    """
    Check if every finite subset of formula_set is satisfiable
    by some structure in structures.
    """
    for r in range(1, len(formula_set) + 1):
        for subset in combinations(formula_set, r):
            satisfiable = False
            for struct in structures:
                if all(evaluate_formula(struct, f) for f in subset):
                    satisfiable = True
                    break
            if not satisfiable:
                return False, subset
    return True, None

def reachable(structure, start, end, max_depth=3):

    visited = set()
    queue = [(start, 0)]
    edges = structure['relations']['E']

        if depth >= max_depth:

                queue.append((b, depth + 1))
    return False

Stochastic Calculus: Randomness in Continuous Time

stochastic-calculus

Real-World Motivation

How do we model systems that evolve randomly over time? From stock prices and interest rates to particle diffusion and neural activity, stochastic calculus provides the mathematical language for continuous-time random processes. Developed by Itô in the 1940s, it extends calculus to handle Brownian motion and other stochastic processes. Applications include quantitative finance (Black-Scholes pricing), physics (Fokker-Planck equations), biology (population dynamics), and engineering (filtering and control).

Definitions

  • Wiener Process (Brownian Motion): A continuous-time stochastic process \(W_t\) with \(W_0 = 0\), independent increments, and \(W_t - W_s \sim \mathcal{N}(0, t-s)\) for \(t > s\).
  • Itô Integral: For adapted process \(H_t\): \(\int_0^T H_t \, dW_t = \lim_{n \to \infty} \sum_{i=0}^{n-1} H_{t_i}(W_{t_{i+1}} - W_{t_i})\).
  • Itô Process: \(X_t = X_0 + \int_0^t \mu_s \, ds + \int_0^t \sigma_s \, dW_s\), or in differential form: \(dX_t = \mu_t \, dt + \sigma_t \, dW_t\).
  • Quadratic Variation: \(\langle X \rangle_t = \lim_{\|P\| \to 0} \sum_{i}(X_{t_{i+1}} - X_{t_i})^2\). For Brownian motion, \(\langle W \rangle_t = t\).
  • Martingale: A process where \(\mathbb{E}[X_t | \mathcal{F}_s] = X_s\) for \(t > s\). The Itô integral of a bounded process is a martingale.

Theorem: Itô's Lemma

Theorem (Itô's Lemma): Let \(X_t\) be an Itô process and \(f \in C^{2,1}(\mathbb{R} \times [0, \infty))\). Then \(Y_t = f(X_t, t)\) is an Itô process with:

\[df(X_t, t) = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial x}dX_t + \frac{1}{2}\frac{\partial^2 f}{\partial x^2}(dX_t)^2\]

where \((dX_t)^2 = \sigma_t^2 dt\) using the rule \((dt)^2 = 0\), \(dt \cdot dW_t = 0\), \((dW_t)^2 = dt\).

Multi-dimensional Version: For \(f(X_t^{(1)}, \ldots, X_t^{(n)}, t)\):

\[df = \frac{\partial f}{\partial t}dt + \sum_i \frac{\partial f}{\partial x_i}dX_t^{(i)} + \frac{1}{2}\sum_{i,j} \frac{\partial^2 f}{\partial x_i \partial x_j}dX_t^{(i)}dX_t^{(j)}\]

Proof Sketch

Taylor expand \(f(X_{t+\Delta t}, t+\Delta t) - f(X_t, t)\) to second order. The key insight is that \((\Delta W_t)^2 \approx \Delta t\) in the mean-square sense, so we cannot drop the second-order term. Taking limits gives the extra "Itô correction" term \(\frac{1}{2}f''(X_t)\sigma_t^2 dt\).

Notation Guide

  • \(W_t\) or \(B_t\): Standard Brownian motion
  • \(\mathcal{F}_t\): Filtration (information available at time \(t\))
  • \(\mu_t\): Drift coefficient
  • \(\sigma_t\): Diffusion/volatility coefficient
  • \(\langle X \rangle_t\): Quadratic variation of \(X\)
  • \(\mathbb{E}[\cdot|\mathcal{F}_s]\): Conditional expectation

import numpy as np
import matplotlib.pyplot as plt

def simulate_brownian_motion(T=1.0, N=1000, num_paths=5, seed=None):
    """
    Simulate sample paths of standard Brownian motion.
    """
    if seed is not None:
        np.random.seed(seed)
    
    dt = T / N
    t = np.linspace(0, T, N+1)
    
    # Generate increments
    dW = np.random.normal(0, np.sqrt(dt), (num_paths, N))
    
    # Cumulative sum to get Brownian motion
    W = np.zeros((num_paths, N+1))
    W[:, 1:] = np.cumsum(dW, axis=1)
    
    return t, W

def simulate_geometric_brownian_motion(S0, mu, sigma, T=1.0, N=1000, num_paths=5, seed=None):
    """
    Simulate GBM: dS_t = mu*S_t*dt + sigma*S_t*dW_t
    Solution: S_t = S_0 * exp((mu - sigma^2/2)*t + sigma*W_t)
    """
    t, W = simulate_brownian_motion(T, N, num_paths, seed)
    
    # Exact solution
    S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
    
    return t, S

Optimal Transport: The Mathematics of Efficiency

optimal-transport

Real-World Motivation

What is the most efficient way to move a pile of sand to fill a hole? This seemingly simple question, posed by Monge in 1781, launched optimal transport theory. The field has exploded in recent decades, finding applications in economics (matching theory), machine learning (Wasserstein GANs), image processing (registration), and partial differential equations (gradient flows). The Wasserstein distance provides a natural metric on probability measures that captures the geometry of the underlying space, unlike total variation or KL divergence.

Definitions

  • Monge Problem: Given measures \(\mu\), \(\nu\) on spaces \(X\), \(Y\), find a map \(T: X \to Y\) minimizing \(\int_X c(x, T(x)) \, d\mu(x)\) subject to \(T_\#\mu = \nu\) (pushforward condition).
  • Kantorovich Relaxation: Find a coupling \(\gamma \in \Pi(\mu, \nu)\) minimizing \(\int_{X \times Y} c(x,y) \, d\gamma(x,y)\), where \(\Pi(\mu, \nu)\) is the set of joint distributions with marginals \(\mu\) and \(\nu\).
  • Wasserstein Distance: For \(p \geq 1\): \(W_p(\mu, \nu) = \left(\inf_{\gamma \in \Pi(\mu, \nu)} \int |x-y|^p \, d\gamma\right)^{1/p}\).
  • c-Concave Function: \(\varphi^c(y) = \inf_x (c(x,y) - \varphi(x))\). A function is c-concave if \(\varphi = \psi^c\) for some \(\psi\).
  • Brenier's Theorem: For quadratic cost \(c(x,y) = |x-y|^2/2\) with \(\mu\) absolutely continuous, the optimal map is the gradient of a convex function: \(T = \nabla \varphi\).

Theorem: The Kantorovich Duality

Theorem (Kantorovich Duality): For lower semi-continuous cost \(c \geq 0\):

\[\inf_{\gamma \in \Pi(\mu, \nu)} \int c \, d\gamma = \sup_{(\varphi, \psi) \in \Phi_c} \left(\int \varphi \, d\mu + \int \psi \, d\nu\right)\]

where \(\Phi_c = \{(\varphi, \psi) : \varphi(x) + \psi(y) \leq c(x,y)\}\).

Optimal Case: For quadratic cost, the supremum is achieved by a pair \((\varphi, \varphi^c)\) where \(\varphi\) is c-concave.

Proof Sketch

The proof uses convex analysis and the Fenchel-Rockafellar duality theorem. The constraint \(\gamma \in \Pi(\mu, \nu)\) is linear, and the objective is linear in \(\gamma\). The dual variables correspond to potentials \(\varphi\), \(\psi\) that enforce the marginal constraints. The key insight is that strong duality holds under mild conditions, allowing us to switch between the primal (transport plan) and dual (potential) formulations.

Notation Guide

  • \(\Pi(\mu, \nu)\): Set of couplings (transport plans)
  • \(T_\#\mu\): Pushforward measure \(\mu\) by map \(T\)
  • \(W_p\): p-Wasserstein distance
  • \(\varphi^c\): c-transform of \(\varphi\)
  • \(\partial^c \varphi\): c-superdifferential

import numpy as np
from scipy.optimize import linprog
from scipy.spatial.distance import cdist

def discrete_optimal_transport(mu, nu, cost_matrix):
    """
    Solve discrete optimal transport using linear programming.
    
    mu: source distribution (length m)
    nu: target distribution (length n)
    cost_matrix: m x n matrix of transport costs
    
    Returns optimal transport plan and total cost.
    """
    m, n = len(mu), len(nu)
    
    # Flatten cost matrix to vector
    c = cost_matrix.flatten()
    
    # Equality constraints: row sums = mu, column sums = nu
    A_eq = np.zeros((m + n, m * n))
    
    # Row constraints
    for i in range(m):
        A_eq[i, i*n:(i+1)*n] = 1
    
    # Column constraints
    for j in range(n):
        for i in range(m):
            A_eq[m + j, i*n + j] = 1
    
    b_eq = np.concatenate([mu, nu])
    
    # Bounds: non-negative
    bounds = [(0, None) for _ in range(m * n)]
    
    # Solve
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    
    if result.success:
        plan = result.x.reshape(m, n)
        return plan, result.fun
    else:
        raise ValueError("Optimization failed")

def sinkhorn_knopp(mu, nu, cost_matrix, epsilon=0.1, max_iter=1000, tol=1e-6):
    """
    Entropically regularized optimal transport using Sinkhorn iterations.
    Much faster for large problems.
    """
    K = np.exp(-cost_matrix / epsilon)
    
    u = np.ones_like(mu)
    v = np.ones_like(nu)
    
    for _ in range(max_iter):
        u_prev = u
        u = mu / (K @ v)
        v = nu / (K.T @ u)
        
        if np.max(np.abs(u - u_prev)) < tol:
            break
    
    plan = np.diag(u) @ K @ np.diag(v)
    cost = np.sum(plan * cost_matrix)
    
    return plan, cost

def wasserstein_1d(mu_samples, nu_samples, p=1):
    """
    Compute 1D Wasserstein distance using sorting (exact and fast).
    """
    mu_sorted = np.sort(mu_samples)
    nu_sorted = np.sort(nu_samples)
    
    # Empirical CDF
    n = len(mu_samples)
    m = len(nu_samples)
    
    # For equal sample sizes
    if n == m:
        return (np.sum(np.abs(mu_sorted - nu_sorted)**p) / n)**(1/p)
    
    # General case: use all quantiles
    quantiles = np.linspace(0, 1, max(n, m))
    mu_quantiles = np.interp(quantiles, np.linspace(0, 1, n), mu_sorted)
    nu_quantiles = np.interp(quantiles, np.linspace(0, 1, m), nu_sorted)
    
    return (np.sum(np.abs(mu_quantiles - nu_quantiles)**p) / len(quantiles))**(1/p)

Inverse Problems: Recovering the Unknown

inverse-problems

Real-World Motivation

How can we see inside the human body without surgery? How do we reconstruct ancient climates from ice core data? Inverse problems ask us to recover causes from observed effects. Unlike direct problems (given cause, find effect), inverse problems are often ill-posed: solutions may not exist, may not be unique, or may not depend continuously on data. Regularization techniques—Tikhonov, iterative, and Bayesian methods—provide stable approximations. Applications include medical imaging (CT, MRI), geophysics (seismic inversion), astronomy (image deblurring), and machine learning (training neural networks).

Definitions

  • Forward Operator: \(F: X \to Y\) maps unknown parameters \(x\) to observable data \(y = F(x) + \eta\) (with noise \(\eta\)).
  • Ill-Posed Problem (Hadamard): A problem where at least one of the following fails: existence, uniqueness, or stability of solutions.
  • Moore-Penrose Pseudoinverse: For linear \(A\), \(A^\dagger\) gives the minimum-norm least-squares solution.
  • Tikhonov Regularization: \(\hat{x}_\alpha = \arg\min_x \|Ax - y\|^2 + \alpha\|x\|^2\), with solution \(\hat{x}_\alpha = (A^TA + \alpha I)^{-1}A^Ty\).
  • Singular Value Decomposition (SVD): \(A = U\Sigma V^T\). Small singular values amplify noise; regularization filters them.

Theorem: Tikhonov Regularization Error Bound

Theorem: Let \(A: X \to Y\) be a compact linear operator between Hilbert spaces. For the Tikhonov-regularized solution \(\hat{x}_\alpha\) with exact data \(y = Ax^\dagger\):

\[\|\hat{x}_\alpha - x^\dagger\| \leq \sqrt{\alpha}\|x^\dagger\|\]

For noisy data \(y^\delta\) with \(\|y - y^\delta\| \leq \delta\):

\[\|\hat{x}_\alpha - x^\dagger\| \leq \frac{\delta}{2\sqrt{\alpha}} + \sqrt{\alpha}\|x^\dagger\|\]

Optimal Choice: \(\alpha \sim \delta\) gives convergence rate \(O(\sqrt{\delta})\).

Proof Sketch

Using the SVD \(A = U\Sigma V^T\), the regularized solution is \(\hat{x}_\alpha = V \text{diag}(\frac{\sigma_i}{\sigma_i^2 + \alpha}) U^T y\). The error decomposes into approximation error (from filtering small singular values) and propagated data error (amplified by \(1/\sigma_i\)). Balancing these via \(\alpha\) yields the optimal rate.

Notation Guide

  • \(A^\dagger\): Moore-Penrose pseudoinverse
  • \(\sigma_i\): Singular values of \(A\)
  • \(\alpha\): Regularization parameter
  • \(\delta\): Noise level
  • \(\mathcal{R}_\alpha\): Regularization operator
  • \(L\): Regularization operator (often \(L = I\) or derivative)

import numpy as np
from scipy.linalg import svd
import matplotlib.pyplot as plt

def tikhonov_regularization(A, y, alpha):
    """
    Solve min ||Ax - y||^2 + alpha*||x||^2 using normal equations.
    """
    n = A.shape[1]
    return np.linalg.solve(A.T @ A + alpha * np.eye(n), A.T @ y)

def tikhonov_svd(U, s, Vt, y, alpha):
    """
    Tikhonov using SVD: x = V * diag(s/(s^2 + alpha)) * U^T * y
    """
    filter_factors = s / (s**2 + alpha)
    return Vt.T @ (filter_factors * (U.T @ y))

def landweber_iteration(A, y, alpha=0.1, max_iter=100, x0=None):
    """
    Landweber iteration: x_{k+1} = x_k - alpha * A^T(A*x_k - y)
    """
    n = A.shape[1]
    if x0 is None:
        x = np.zeros(n)
    else:
        x = x0.copy()
    
    residuals = []
    for _ in range(max_iter):
        residual = A @ x - y
        x = x - alpha * A.T @ residual
        residuals.append(np.linalg.norm(residual))
    
    return x, residuals

def discrepancy_principle(A, y, delta, alphas):
    """
    Choose alpha such that ||Ax_alpha - y|| ≈ delta * tau (tau > 1)
    """
    U, s, Vt = svd(A, full_matrices=False)
    tau = 1.5  # Safety factor
    
    for alpha in sorted(alphas, reverse=True):
        x_alpha = tikhonov_svd(U, s, Vt, y, alpha)
        residual = np.linalg.norm(A @ x_alpha - y)
        if residual <= tau * delta:
            return alpha, x_alpha
    
    return alphas[-1], tikhonov_svd(U, s, Vt, y, alphas[-1])

Surreal Numbers: The Infinite and the Infinitesimal

surreal-numbers

Historical Context

In the 1970s, mathematician John Horton Conway discovered a remarkable number system while analyzing combinatorial games. Donald Knuth dubbed them "surreal numbers" in his 1974 novella, and the name stuck. The surreals form the largest possible ordered field: they contain all real numbers, all ordinal numbers, and infinitesimals smaller than any positive real. Remarkably, Conway constructed them using a simple recursive rule, and they satisfy all the field axioms. The theory connects game theory, set theory, and analysis in unexpected ways.

Definitions

  • Surreal Number: Defined recursively: if \(L\) and \(R\) are sets of previously constructed surreals with no element of \(L \geq\) any element of \(R\), then \(\{L | R\}\) is a surreal number.
  • Simplicity Rule: \(x = \{L | R\}\) is the simplest (earliest born) number between all elements of \(L\) and all elements of \(R\).
  • Ordering: \(x \leq y\) iff no element of \(x\)'s left set is \(\geq y\) and no element of \(y\)'s right set is \(\leq x\).
  • Addition: \(x + y = \{X_L + y, x + Y_L | X_R + y, x + Y_R\}\) where \(X_L\), \(X_R\) are left and right sets of \(x\).
  • Multiplication: Defined similarly with four terms in each set.
  • Birthday: The ordinal at which a surreal is constructed. Reals are born on day \(\omega\).

Theorem: The Surreals Form a Real Closed Field

Theorem (Conway): The class of surreal numbers \(\mathbf{No}\) forms a real closed field containing:

  • All real numbers (as \(\{q \in \mathbb{Q} : q < r\} | \{q \in \mathbb{Q} : q > r\}\))
  • All ordinal numbers (as \(\{0, 1, \ldots, \alpha - 1\} | \emptyset\))
  • Infinitesimals (as \(\{0\} | \{1/n : n \in \mathbb{N}\}\) = \(\varepsilon\))
  • Infinite numbers (as \(\{\mathbb{N}\} | \emptyset\) = \(\omega\))

Universality: Every ordered field embeds into \(\mathbf{No}\).

Proof Sketch

The proof proceeds by transfinite induction on birthdays. One verifies the field axioms: commutativity, associativity, distributivity, and existence of inverses. The key insight is Conway's simplicity theorem: if \(x = \{L | R\}\) and \(y\) is born earlier than \(x\) with \(L < y < R\), then \(x = y\). This ensures the recursive definitions are well-defined and terminate.

Notation Guide

  • \(\mathbf{No}\): The class of surreal numbers
  • \(\{L | R\}\): Surreal with left set \(L\) and right set \(R\)
  • \(\omega\): First infinite surreal (omega)
  • \(\varepsilon\): First infinitesimal (1/\(\omega\))
  • \(\uparrow\): Up (positive infinitesimal game)
  • \(*\): Star (fuzzy game: neither positive, negative, nor zero)

@total_ordering
class Surreal:
    """
    Simplified implementation of surreal numbers.
    Only handles numbers born on finite days (dyadic rationals).
    """
    _cache = {}
    
    def __new__(cls, left=None, right=None):
        # Canonical form for dyadic rationals
        if left is None and right is None:
            return cls._get_cached(0, 1)
        
        # Simplified: only handle basic cases
        # In full implementation, would use simplicity rule
        
        key = (tuple(left) if left else (), tuple(right) if right else ())
        if key not in cls._cache:
            instance = super().__new__(cls)
            cls._cache[key] = instance
        return cls._cache[key]
    
    @classmethod
    def _get_cached(cls, num, den):
        """Get cached dyadic rational."""
        key = (num, den)
        if key not in cls._cache:
            instance = super().__new__(cls)
            instance.num = num
            instance.den = den
            instance._is_dyadic = True
            cls._cache[key] = instance
        return cls._cache[key]
    
    def __init__(self, left=None, right=None):
        if not hasattr(self, 'num'):
            self.left = set(left) if left else set()
            self.right = set(right) if right else set()
            self._is_dyadic = False
    
    def __float__(self):
        if self._is_dyadic:
            return self.num / self.den
        # Approximate from left and right
        if hasattr(self, 'left') and self.left:
            return max(float(x) for x in self.left)
        return 0.0
    
    def __eq__(self, other):
        if isinstance(other, (int, float)):
            return abs(float(self) - other) < 1e-10
        if not isinstance(other, Surreal):
            return NotImplemented
        if self._is_dyadic and other._is_dyadic:

        # Find closest dyadic rational

            den //= 2

        return cls._get_cached(num, den)

Ramsey Theory: Order in Chaos

ramsey-theory

Historical Context

In 1930, Frank Ramsey proved a theorem about logical formulas that had a surprising combinatorial consequence: complete disorder is impossible. In any sufficiently large system, some structure must emerge. This launched Ramsey theory, which seeks the threshold where order becomes unavoidable. The classic example: at any party of six people, either three are mutual acquaintances or three are mutual strangers. Paul Erdős, the legendary Hungarian mathematician, made Ramsey theory central to combinatorics and offered prizes for solving several problems that remain open today.

Definitions

  • Ramsey Number \(R(s, t)\): The smallest \(n\) such that any 2-coloring of edges of \(K_n\) contains a red \(K_s\) or a blue \(K_t\).
  • Graph Ramsey Number \(R(G, H)\): Smallest \(n\) such that any red-blue edge coloring of \(K_n\) contains a red copy of \(G\) or blue copy of \(H\).
  • Van der Waerden Number \(W(k, r)\): Smallest \(n\) such that any \(r\)-coloring of \(\{1, \ldots, n\}\) contains a monochromatic arithmetic progression of length \(k\).
  • Hales-Jewett Number: Related to combinatorial lines in high-dimensional spaces.
  • Szemerédi's Regularity Lemma: Any large graph can be partitioned into a bounded number of quasi-random bipartite graphs.

Theorem: Ramsey's Theorem

Theorem (Ramsey, 1930): For any positive integers \(s\) and \(t\), the Ramsey number \(R(s, t)\) is finite. Moreover:

\[R(s, t) \leq R(s-1, t) + R(s, t-1)\]

with strict inequality if both terms on the right are even.

Bounds: \(2^{s/2} \leq R(s, s) \leq 4^{s}\)

Known Values: \(R(3, 3) = 6\), \(R(4, 4) = 18\), \(R(5, 5)\) is unknown (between 43 and 48).

Proof Sketch

The upper bound follows by induction. Consider a vertex \(v\) in a 2-colored \(K_n\). It has either at least \(R(s-1, t)\) red neighbors or at least \(R(s, t-1)\) blue neighbors. In the first case, by induction, the red neighbors contain a red \(K_{s-1}\) (which with \(v\) forms red \(K_s\)) or a blue \(K_t\). The second case is symmetric. The probabilistic method gives the lower bound: randomly color edges and show positive probability of avoiding monochromatic cliques.

Notation Guide

  • \(R(s, t)\): Ramsey number for cliques of sizes \(s\) and \(t\)
  • \(K_n\): Complete graph on \(n\) vertices
  • \(\chi\): Chromatic number
  • \(\alpha(G)\): Independence number of graph \(G\)
  • \(\omega(G)\): Clique number of graph \(G\)

Leonhard Euler: The Master of Us All

leonhard-euler

Historical Context

Leonhard Euler (1707–1783) was the most prolific mathematician in history, publishing over 800 papers and books across every mathematical discipline. Even after losing his sight, he continued to produce groundbreaking work at an astonishing pace. Euler introduced much of the notation we use today: \(e\), \(i\), \(\pi\), \(f(x)\), \(\sum\), and the trigonometric functions. His work spans number theory (the Euler product formula), graph theory (the Königsberg bridges), analysis (Euler's formula \(e^{i\theta} = \cos\theta + i\sin\theta\)), and mechanics. Laplace reportedly said: "Read Euler, read Euler, he is the master of us all."

Key Contributions

  • Euler's Formula: \(e^{i\theta} = \cos\theta + i\sin\theta\), unifying exponential and trigonometric functions.
  • Euler's Identity: \(e^{i\pi} + 1 = 0\), connecting five fundamental constants.
  • Euler Characteristic: \(\chi = V - E + F = 2\) for convex polyhedra, founding topology.
  • Euler Product: \(\sum_{n=1}^{\infty} \frac{1}{n^s} = \prod_p \frac{1}{1-p^{-s}}\), connecting primes to analysis.
  • Euler-Lagrange Equation: \(\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial \dot{q}} = 0\), founding variational mechanics.
  • Euler's Totient Function: \(\varphi(n) = n \prod_{p|n}(1 - 1/p)\), counting coprime residues.

Theorem: Euler's Formula for Polyhedra

Theorem: For any convex polyhedron (or more generally, any polyhedron homeomorphic to a sphere):

\[V - E + F = 2\]

where \(V\) is vertices, \(E\) is edges, and \(F\) is faces.

Generalization: For a surface of genus \(g\): \(V - E + F = 2 - 2g\).

Proof Sketch

Remove one face and flatten the polyhedron onto a plane, creating a planar graph. For trees (connected graphs without cycles), \(V = E + 1\) and \(F = 1\), so the formula holds. For graphs with cycles, remove edges from cycles one at a time, decreasing both \(E\) and \(F\) by 1, preserving \(V - E + F\). Eventually reaching a tree, we get \(V - E + F = 2\).

Notation Guide

  • \(e\): Euler's number, base of natural logarithm \(\approx 2.71828\)
  • \(i\): Imaginary unit, \(i^2 = -1\)
  • \(\pi\): Ratio of circumference to diameter \(\approx 3.14159\)
  • \(\gamma\): Euler-Mascheroni constant \(\approx 0.57721\)
  • \(\varphi(n)\): Euler's totient function
  • \(\Gamma(z)\): Gamma function, extending factorial

Hilbert Curve: Filling Space

hilbert-curve

Historical Context

In 1890, Giuseppe Peano constructed the first space-filling curve, shocking the mathematical community by showing that a continuous curve could fill an entire square. In 1891, David Hilbert published a simpler construction that now bears his name. These curves challenged intuitive notions of dimension and continuity. Today, Hilbert curves have practical applications in databases (spatial indexing), image processing, and computer graphics. They provide a way to map multi-dimensional data to one dimension while preserving locality—nearby points in 2D remain nearby in 1D.

Definitions

  • Space-Filling Curve: A continuous surjection \(\gamma: [0, 1] \to [0, 1]^n\). By Cantor's theorem, no bijection exists.
  • Hilbert Curve: A recursive construction where each iteration replaces line segments with scaled copies of the previous curve in specific orientations.
  • Moore Curve: A closed variant of the Hilbert curve.
  • Locality-Preserving: Points close in 1D parameter map to points close in 2D (though the converse fails).
  • Lebesgue Curve: Another space-filling curve with different locality properties.

Theorem: Properties of the Hilbert Curve

Theorem: The Hilbert curve \(H: [0, 1] \to [0, 1]^2\) satisfies:

  1. Continuity: \(H\) is uniformly continuous on \([0, 1]\).
  2. Surjectivity: \(H([0, 1]) = [0, 1]^2\).
  3. Hölder Continuity: \(|H(t) - H(s)| \leq C|t - s|^{1/2}\).
  4. Nowhere Differentiability: \(H\) is not differentiable anywhere.

Locality Bound: If \(|t - s| < 4^{-n}\), then \(|H(t) - H(s)| \leq 2^{-n}\).

Proof Sketch

The curve is defined as the uniform limit of polygonal approximations \(H_n\). Each \(H_n\) consists of \(4^n\) line segments. The sequence is Cauchy in the sup norm since \(\|H_{n+1} - H_n\|_\infty \leq 2^{-n}\). Uniform convergence preserves continuity. Surjectivity follows because the image is dense and compact. The Hölder exponent 1/2 is optimal—no space-filling curve can have Hölder exponent greater than 1/2.

Notation Guide

  • \(H_n\): nth approximation of Hilbert curve
  • \(d_2(p, q)\): Euclidean distance in \(\mathbb{R}^2\)
  • \(d_1(s, t)\): Distance in parameter space \([0, 1]\)
  • \(R_\theta\): Rotation by angle \(\theta\)

import numpy as np
import matplotlib.pyplot as plt

def hilbert_curve_2d(order):
    """
    Generate points of the 2D Hilbert curve of given order.
    Returns array of shape (4^order, 2) with coordinates in [0, 1].
    """
    # Number of points
    n_points = 4 ** order
    
    # Generate curve using bit manipulation
    points = np.zeros((n_points, 2))
    
    for i in range(n_points):
        x, y = 0, 0
        t = i
        for s in range(order):
            # Extract 2 bits at position 2s
            bits = (t >> (2 * s)) & 3
            
            # Apply Hilbert transformation
            if bits == 0:
                # Lower left: rotate and flip
                x_temp = x
                x = y
                y = x_temp
            elif bits == 1:
                # Lower right: shift up
                y += 2 ** s
            elif bits == 2:
                # Upper right: shift up and right
                x += 2 ** s
                y += 2 ** s
            elif bits == 3:
                # Upper left: rotate and flip, then shift right
                x_temp = x
                x = (2 ** s - 1) - y + 2 ** s
                y = (2 ** s - 1) - x_temp
        
        points[i] = [x, y]
    
    # Normalize to [0, 1]
    points /= (2 ** order - 1) if order > 0 else 1
    
    return points

def hilbert_curve_recursive(order, x0=0, y0=0, xi=1, xj=0, yi=0, yj=1):
    """
    Recursive construction of Hilbert curve.
    (xi, xj) and (yi, yj) define the orientation.
    """
    if order <= 0:
        return np.array([[x0, y0]])
    
    points = []
    
    # Recursive calls for four quadrants
    # Lower left (rotated -90°)
    points.extend(hilbert_curve_recursive(
        order - 1, x0, y0, yi//2, yj//2, xi//2, xj//2))
    
    # Lower right (translated)
    points.extend(hilbert_curve_recursive(
        order - 1, x0 + xi//2, y0 + xj//2, xi//2, xj//2, yi//2, yj//2))
    
    # Upper right (translated)
    points.extend(hilbert_curve_recursive(
        order - 1, x0 + xi//2 + yi//2, y0 + xj//2 + yj//2, 
        xi//2, xj//2, yi//2, yj//2))
    
    # Upper left (rotated +90°)
    points.extend(hilbert_curve_recursive(
        order - 1, x0 + xi//2 + yi, y0 + xj//2 + yj,
        -yi//2, -yj//2, -xi//2, -xj//2))
    
    return np.array(points)

def d2xy(n, d):
    """
    Convert 1D distance d to 2D coordinates (x, y) on Hilbert curve.
    n is the size of the grid (power of 2).
    """
    x, y = 0, 0
    t = d
    for s in range(int(np.log2(n))):
        bits = (t >> (2 * s)) & 3
        if bits == 0:
            x, y = y, x
        elif bits == 1:
            y += 2 ** s
        elif bits == 2:
            x += 2 ** s
            y += 2 ** s
        elif bits == 3:
            x, y = (2 ** s - 1) - y + 2 ** s, (2 ** s - 1) - x
    return x, y

def xy2d(n, x, y):
    """
    Convert 2D coordinates to 1D distance on Hilbert curve.
    """
    d = 0
    s = n // 2
    while s > 0:
        rx = 1 if (x & s) > 0 else 0
        ry = 1 if (y & s) > 0 else 0
        d += s * s * ((3 * rx) ^ ry)
        # Rotate
        if ry == 0:
            if rx == 1:
                x = n - 1 - x
                y = n - 1 - y
            x, y = y, x
        s //= 2
    return d

📜 Math History

The Development of Modern Analysis: From Newton to Lebesgue

The story of mathematical analysis is one of the great intellectual journeys in human history, spanning over three centuries and involving some of the greatest minds ever to contemplate the infinite. It began with the invention of calculus by Isaac Newton and Gottfried Wilhelm Leibniz in the late 17th century, though neither man could provide a rigorous foundation for their powerful new methods. Newton's fluxions and Leibniz's differentials worked spectacularly well—predicting planetary orbits, describing fluid flow, and solving optimization problems—but the logical basis remained mysterious. What exactly was an "infinitesimal" quantity?

The 18th century saw analysis flourish as a tool for physics, with Leonhard Euler and the Bernoulli family pushing the boundaries of what calculus could achieve. Yet the foundations grew increasingly troubling. Euler freely manipulated infinite series, sometimes obtaining correct results through dubious means. When Fourier announced in 1807 that arbitrary functions could be represented by trigonometric series, the mathematical community was forced to confront fundamental questions: What is a function? When does a series converge?

Augustin-Louis Cauchy provided the first rigorous answers in the 1820s, introducing the modern definitions of limit, continuity, and convergence. But Cauchy's work had gaps—he assumed uniform convergence without recognizing it, and his "proof" of the intermediate value theorem relied on geometric intuition. The true arithmetization of analysis came later in the 19th century through the work of Karl Weierstrass, who constructed pathological functions continuous everywhere but differentiable nowhere, and Richard Dedekind, who defined real numbers in terms of sets of rationals.

The final transformation came at the turn of the 20th century when Henri Lebesgue revolutionized integration theory. Riemann's integral, based on partitioning the domain, was inadequate for handling limits of functions. Lebesgue's approach—partitioning the range and measuring the resulting sets—created a theory where limits and integrals could be freely interchanged. This required a new theory of measure, developed in parallel by Lebesgue, Émile Borel, and others. The Lebesgue integral became the foundation of modern functional analysis, probability theory, and the study of partial differential equations.

Today, analysis continues to evolve. Non-standard analysis, developed by Abraham Robinson in the 1960s, finally gave rigorous meaning to infinitesimals. Distribution theory extended the notion of function to include objects like the Dirac delta. And the interplay between analysis and geometry—geometric measure theory, optimal transport, geometric analysis—remains one of the most active frontiers of mathematical research. The journey from Newton's fluxions to modern analysis demonstrates a fundamental pattern in mathematics: practical success drives theoretical development, and rigorous foundations enable even greater practical achievements.

🎯 Problem Corner

IMO Shortlist 2024 Problem N7

Let \(n\) be a positive integer. A sequence \(a_1, a_2, \ldots, a_n\) of positive integers is called good if:

  1. \(a_1 + a_2 + \cdots + a_n = 2n\)
  2. For each \(k = 1, 2, \ldots, n\), the sum of any \(k\) distinct terms of the sequence is at least \(2k - 1\).

Find the number of good sequences.

Hint

Consider what happens when you sort the sequence. The condition on sums of \(k\) terms suggests looking at the smallest \(k\) terms. If \(b_1 \leq b_2 \leq \cdots \leq b_n\) is the sorted sequence, the condition requires \(b_1 + b_2 + \cdots + b_k \geq 2k - 1\). Combine this with the total sum constraint.

Solution

Let \(b_1 \leq b_2 \leq \cdots \leq b_n\) be the sorted sequence. The condition that any \(k\) terms sum to at least \(2k-1\) is equivalent to \(b_1 + b_2 + \cdots + b_k \geq 2k - 1\) for all \(k\), since the sum of the \(k\) smallest terms is minimized.

We claim that all good sequences satisfy \(b_i \in \{1, 2, 3\}\) for all \(i\).

Proof: From \(b_1 \geq 2 \cdot 1 - 1 = 1\), we have \(b_1 \geq 1\). Since all \(a_i\) are positive integers, \(b_1 \geq 1\).

Suppose \(b_n \geq 4\). Then the sum of all terms is at least \(b_n + (n-1) \cdot 1 \geq 4 + n - 1 = n + 3\). For \(n \geq 3\), we need this to equal \(2n\), so \(n + 3 \leq 2n\), giving \(n \geq 3\). But more constraints come from the partial sums.

From \(b_1 + \cdots + b_k \geq 2k - 1\) and the total sum \(b_1 + \cdots + b_n = 2n\), we get:

\[b_{k+1} + \cdots + b_n = 2n - (b_1 + \cdots + b_k) \leq 2n - (2k - 1) = 2(n-k) + 1\]

Since \(b_{k+1} \geq b_k \geq \cdots \geq b_1\), we have \((n-k)b_{k+1} \leq 2(n-k) + 1\), so \(b_{k+1} \leq 2 + \frac{1}{n-k}\). For \(k \leq n-1\), this gives \(b_{k+1} \leq 2\) when \(n-k \geq 1\), or more carefully: \(b_{k+1} \leq 3\) for all relevant indices.

Actually, let's use a cleaner approach. Define \(c_i = b_i - 1\). Then \(c_i \geq 0\) and:

  • \(\sum c_i = \sum b_i - n = 2n - n = n\)
  • \(c_1 + \cdots + c_k \geq (2k-1) - k = k - 1\)

From \(c_1 + \cdots + c_k \geq k - 1\), we get \(c_1 \geq 0\) (always true) and the average of the first \(k\) values of \(c_i\) is at least \((k-1)/k\).

Also, \(c_{k+1} + \cdots + c_n = n - (c_1 + \cdots + c_k) \leq n - (k-1) = n - k + 1\).

Since \(c_{k+1} \geq c_k \geq \cdots \geq c_1\), we need \((n-k)c_{k+1} \leq n - k + 1\), so \(c_{k+1} \leq 1 + \frac{1}{n-k}\).

For \(k = n-1\): \(c_n \leq 2\), so \(b_n \leq 3\).

So all \(b_i \in \{1, 2, 3\}\). Let \(x\) be the count of 1s, \(y\) the count of 2s, \(z\) the count of 3s.

Constraints:

  • \(x + y + z = n\) (total count)
  • \(x + 2y + 3z = 2n\) (total sum)

From these: \(y + 2z = n\), so \(y = n - 2z\) and \(x = n - y - z = n - (n-2z) - z = z\).

So \(x = z\) and \(y = n - 2z\). We need \(y \geq 0\), so \(z \leq n/2\).

Now check the condition \(b_1 + \cdots + b_k \geq 2k - 1\). With \(x = z\) ones and \(z\) threes, and the rest twos:

If \(k \leq x = z\): sum of \(k\) smallest (all 1s) is \(k\). Need \(k \geq 2k - 1\), so \(k \leq 1\).

This fails for \(k = 2\) unless \(z \leq 1\) or we arrange carefully. Actually, we need to check if any valid arrangement exists.

For \(z = 0\): all entries are 2. Check: sum of \(k\) terms is \(2k \geq 2k - 1\). ✓

For \(z = 1\): one 1, one 3, rest 2s. Sorted: \(1, 2, 2, \ldots, 2, 3\).

\(b_1 = 1 \geq 1\) ✓

\(b_1 + b_2 = 3 \geq 3\) ✓

For \(k \geq 2\): sum is \(1 + 2(k-2) + 3 = 2k\) if we include the 3, or \(1 + 2(k-1) = 2k - 1\) if we don't. Both satisfy the bound.

For \(z \geq 2\): we have at least two 1s. Then \(b_1 + b_2 = 2 < 3 = 2 \cdot 2 - 1\). ✗

So only \(z = 0\) and \(z = 1\) work.

For \(z = 0\): all 2s. One sequence (all identical).

For \(z = 1\): one 1, one 3, \(n-2\) twos. Number of distinct sequences: \(n(n-1)\) (choose position for 1 and position for 3).

Answer: \(1 + n(n-1) = n^2 - n + 1\).

🎨 Visualization of the Day

Hilbert Curve Space-Filling Animation

The Hilbert curve is a continuous fractal space-filling curve that visits every point in a square grid. Unlike simple curves, it preserves locality—points that are close together along the curve remain close in 2D space. This property makes it invaluable for spatial indexing, image processing, and data visualization.

The visualization below shows how successive iterations of the Hilbert curve increasingly fill the unit square. Each order-\(n\) curve consists of \(4^n\) line segments, with the limit curve being continuous and surjective onto the square.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

def hilbert_curve(order):
    """Generate Hilbert curve points for given order."""
    n_points = 4 ** order
    points = np.zeros((n_points, 2))
    
    for i in range(n_points):
        x, y = 0, 0
        for s in range(order):
            bits = (i >> (2 * s)) & 3
            if bits == 0:
                x, y = y, x
            elif bits == 1:
                y += 2 ** s
            elif bits == 2:
                x += 2 ** s
                y += 2 ** s
            elif bits == 3:
                x, y = (2 ** s - 1) - y + 2 ** s, (2 ** s - 1) - x
        points[i] = [x, y]
    
    points /= (2 ** order - 1) if order > 0 else 1
    return points

# Create static visualization showing progression
fig, axes = plt.subplots(2, 3, figsize=(15, 10))
axes = axes.flatten()

colors = plt.cm.viridis(np.linspace(0, 1, 6))

for idx, order in enumerate([1, 2, 3, 4, 5, 6]):
    points = hilbert_curve(order)
    
    # Color gradient along the curve
    for i in range(len(points) - 1):
        color_intensity = i / (len(points) - 1)
        axes[idx].plot([points[i, 0], points[i+1, 0]], 
                      [points[i, 1], points[i+1, 1]],
                      color=plt.cm.plasma(color_intensity), 
                      linewidth=1.5 if order < 4 else 0.5)
    
    axes[idx].set_aspect('equal')
    axes[idx].set_title(f'Hilbert Curve Order {order}\n({4**order} points)', fontsize=12)
    axes[idx].axis('off')
    
    # Add start and end markers
    axes[idx].plot(points[0, 0], points[0, 1], 'go', markersize=8, label='Start')
    axes[idx].plot(points[-1, 0], points[-1, 1], 'ro', markersize=8, label='End')
