Homological Algebra: Measuring the Failure of Exactness

homological-algebra

Motivation

When does a functor preserve exact sequences? Homological algebra, developed in the 1940s and 1950s by Cartan, Eilenberg, and others, provides tools to measure the failure of exactness. Originally created to unify homology theories in algebraic topology, it has become fundamental across mathematics—from algebraic geometry (sheaf cohomology) to number theory (group cohomology, Galois cohomology) to representation theory (Ext and Tor functors). The key insight is that even when a functor destroys exactness, we can systematically track the damage through derived functors, connecting local data to global properties.

Definitions

  • Chain Complex: A sequence of modules and homomorphisms \( \cdots \xrightarrow{d_{n+1}} C_n \xrightarrow{d_n} C_{n-1} \xrightarrow{d_{n-1}} \cdots \) with \(d_n \circ d_{n+1} = 0\) (i.e., \(\text{im}(d_{n+1}) \subseteq \ker(d_n)\)).
  • Homology: \(H_n(C_\bullet) = \ker(d_n) / \text{im}(d_{n+1})\), measuring the failure of exactness at position \(n\).
  • Exact Sequence: A chain complex with all homology zero: \(\text{im}(d_{n+1}) = \ker(d_n)\) for all \(n\).
  • Short Exact Sequence (SES): \(0 \to A \xrightarrow{f} B \xrightarrow{g} C \to 0\) where \(f\) is injective, \(g\) is surjective, and \(\text{im}(f) = \ker(g)\).
  • Projective Module: A module \(P\) such that \(\text{Hom}(P, -)\) preserves surjections (equivalently, every surjection \(M \to P\) splits).
  • Injective Module: A module \(I\) such that \(\text{Hom}(-, I)\) preserves injections.
  • Derived Functors: For a right-exact functor \(F\), the left derived functors \(L_nF\) measure the failure of \(F\) to be left exact.

Theorem: The Long Exact Sequence in Homology

Theorem: Given a short exact sequence of chain complexes:

\[0 \to A_\bullet \xrightarrow{f} B_\bullet \xrightarrow{g} C_\bullet \to 0\]

there exists a natural long exact sequence in homology:

\[\cdots \to H_n(A) \xrightarrow{f_*} H_n(B) \xrightarrow{g_*} H_n(C) \xrightarrow{\partial} H_{n-1}(A) \xrightarrow{f_*} H_{n-1}(B) \to \cdots\]

where \(\partial\) is the connecting homomorphism defined by \(\partial([c]) = [a]\) where \(f(a) = d_B(b)\) for any \(b\) with \(g(b) = c\).

Proof Sketch

The proof uses the Snake Lemma applied to the commutative diagram of short exact sequences formed by the boundaries and cycles:

  1. Define \(Z_n = \ker(d_n)\) (cycles) and \(B_n = \text{im}(d_{n+1})\) (boundaries).
  2. From the SES of complexes, obtain SES: \(0 \to Z_n(A) \to Z_n(B) \to Z_n(C)\) and similar for boundaries.
  3. Apply the Snake Lemma to the diagram relating \(B_n\) to \(Z_n\).
  4. The connecting homomorphism \(\partial: H_n(C) \to H_{n-1}(A)\) is well-defined because different choices of lift differ by a boundary.
  5. Exactness at each term follows from diagram chasing.

Notation Guide

  • \(C_\bullet\) or \((C_n, d_n)\): Chain complex
  • \(H_n(C)\): n-th homology group
  • \(Z_n = \ker(d_n)\): n-cycles
  • \(B_n = \text{im}(d_{n+1})\): n-boundaries
  • \(f_*\): Induced map on homology
  • \(\partial\): Connecting homomorphism
  • \(\text{Ext}^n_R(M, N)\): n-th derived functor of \(\text{Hom}_R(M, -)\)
  • \(\text{Tor}_n^R(M, N)\): n-th derived functor of \(\otimes_R\)

import numpy as np
from typing import List, Callable, Tuple
from dataclasses import dataclass

@dataclass
class ChainComplex:
    """Represents a chain complex with boundary maps."""
    modules: List[int]  # Dimensions of each module (for matrix representation)
    boundary_maps: List[np.ndarray]  # d_n: C_n -> C_{n-1}
    
    def __post_init__(self):
        # Verify d_{n-1} ∘ d_n = 0
        for i, d in enumerate(self.boundary_maps[:-1]):
            d_next = self.boundary_maps[i + 1]
            composition = d_next @ d if d.size > 0 and d_next.size > 0 else np.array([[0]])
            if not np.allclose(composition, 0):
                raise ValueError(f"Boundary condition failed at position {i}")
    
    def cycles(self, n: int) -> np.ndarray:
        """Compute basis for n-cycles (kernel of d_n)."""
        if n >= len(self.boundary_maps):
            return np.eye(self.modules[n]) if n < len(self.modules) else np.array([])
        d = self.boundary_maps[n]
        if d.size == 0:
            return np.eye(self.modules[n])
        # Null space of d
        _, _, Vh = np.linalg.svd(d)
        rank = np.linalg.matrix_rank(d)
        return Vh[rank:].T if rank < d.shape[1] else np.array([]).reshape(d.shape[1], 0)
    
    def boundaries(self, n: int) -> np.ndarray:
        """Compute basis for n-boundaries (image of d_{n+1})."""
        if n + 1 >= len(self.boundary_maps):
            return np.array([]).reshape(self.modules[n] if n < len(self.modules) else 0, 0)
        d = self.boundary_maps[n + 1]
        if d.size == 0:
            return np.array([]).reshape(d.shape[0], 0)
        # Column space of d
        U, _, _ = np.linalg.svd(d)
        rank = np.linalg.matrix_rank(d)
        return U[:, :rank] if rank > 0 else np.array([]).reshape(d.shape[0], 0)
    
    def homology(self, n: int) -> int:
        """Compute dimension of n-th homology group."""
        if n >= len(self.modules):
            return 0
        Z = self.cycles(n)
        B = self.boundaries(n)
        dim_Z = Z.shape[1] if Z.size > 0 else self.modules[n]
        dim_B = B.shape[1] if B.size > 0 else 0
        return dim_Z - dim_B

Representation Theory: Symmetry in Linear Algebra

representation-theory

Motivation

How can we study abstract groups by their actions on vector spaces? Representation theory, founded by Frobenius and Burnside in the late 19th century, answers this by representing group elements as linear transformations. This allows us to use linear algebra—eigenvalues, traces, inner products—to understand group structure. Applications span quantum mechanics (where representations describe particle symmetries), harmonic analysis (Fourier series as representations of the circle group), crystallography, and number theory (Langlands program). The theory reveals that every representation decomposes into irreducible building blocks, classified by characters.

Definitions

  • Representation: A homomorphism \(\rho: G \to GL(V)\) where \(G\) is a group and \(V\) is a vector space. We write \(g \cdot v = \rho(g)(v)\).
  • Irreducible Representation: A representation with no nontrivial proper subrepresentations (no invariant subspaces other than \(\{0\}\) and \(V\)).
  • Character: \(\chi_\rho(g) = \text{tr}(\rho(g))\), a class function constant on conjugacy classes.
  • Regular Representation: \(G\) acts on \(\mathbb{C}[G]\) (the group algebra) by left multiplication. It decomposes as \(\bigoplus_i (\dim V_i) V_i\) over all irreps.
  • Maschke's Theorem: For finite groups over \(\mathbb{C}\), every representation is completely reducible (direct sum of irreducibles).
  • Schur's Lemma: Any homomorphism between irreducible representations is either zero or an isomorphism. If \(V\) is irreducible over \(\mathbb{C}\), then \(\text{End}_G(V) \cong \mathbb{C}\).

Theorem: Orthogonality of Characters

Theorem: Let \(G\) be a finite group with irreducible characters \(\chi_1, \ldots, \chi_k\). Then:

\[\frac{1}{|G|} \sum_{g \in G} \chi_i(g) \overline{\chi_j(g)} = \delta_{ij}\]

Equivalently, with conjugacy classes \(C_1, \ldots, C_k\):

\[\sum_{g \in G} \chi_i(g) \overline{\chi_j(g)} = |G| \delta_{ij}\]

Corollary: The number of irreducible representations equals the number of conjugacy classes.

Dimension Formula: \(\sum_{i=1}^k (\dim V_i)^2 = |G|\).

Proof Sketch

  1. Define the averaging operator \(P = \frac{1}{|G|} \sum_{g \in G} \rho(g)\) which projects onto the \(G\)-invariant subspace.
  2. For representations \(V\) and \(W\), \(\text{Hom}_G(V, W) = (\text{Hom}(V, W))^G\) (the invariant subspace).
  3. By Schur's Lemma, \(\dim \text{Hom}_G(V_i, V_j) = \delta_{ij}\).
  4. The character of \(\text{Hom}(V, W)\) is \(\chi_V(g^{-1}) \chi_W(g) = \overline{\chi_V(g)} \chi_W(g)\) for unitary representations.
  5. Apply the projection formula: \(\dim V^G = \frac{1}{|G|} \sum_{g \in G} \chi_V(g)\).

Notation Guide

  • \(\rho: G \to GL(V)\): Representation
  • \(\chi_\rho\) or \(\chi_V\): Character of representation
  • \(V^G\): Invariant subspace \(\{v \in V : g \cdot v = v \text{ for all } g\}\)
  • \(\text{Irr}(G)\): Set of irreducible representations
  • \(\langle \chi, \psi \rangle = \frac{1}{|G|} \sum_g \chi(g) \overline{\psi(g)}\): Inner product on class functions
  • \(V \otimes W\): Tensor product representation
  • \(V^*\): Dual representation
  • \(\text{Ind}_H^G(W)\): Induced representation

Dynamical Systems: Evolution and Chaos

dynamical-systems

Motivation

How do systems evolve over time? Dynamical systems theory, pioneered by Poincaré in his study of celestial mechanics, studies the long-term behavior of iterative processes and differential equations. From the stability of the solar system to the unpredictability of weather (the butterfly effect), from population dynamics to neural networks, dynamical systems provide the mathematical language for change. The field splits into discrete dynamics (iterations of maps) and continuous dynamics (flows from differential equations), unified by concepts like fixed points, periodic orbits, and attractors. Chaos theory reveals that simple deterministic systems can exhibit unpredictable behavior.

Definitions

  • Discrete Dynamical System: A map \(f: X \to X\) where \(X\) is a phase space. The orbit of \(x_0\) is \(\{f^n(x_0) : n \geq 0\}\).
  • Fixed Point: \(x^*\) such that \(f(x^*) = x^*\).
  • Periodic Point: \(x\) such that \(f^n(x) = x\) for some \(n > 0\). The smallest such \(n\) is the period.
  • Lyapunov Exponent: \(\lambda(x) = \lim_{n \to \infty} \frac{1}{n} \log \|Df^n(x)\|\), measuring the rate of separation of nearby orbits.
  • Attractor: A set \(A\) such that \(f(A) = A\) and orbits starting nearby converge to \(A\).
  • Chaos (Devaney): A system is chaotic if it is: (1) sensitive to initial conditions, (2) topologically transitive, and (3) has dense periodic points.
  • Flow: A family of maps \(\phi_t: X \to X\) satisfying \(\phi_0 = \text{id}\) and \(\phi_{s+t} = \phi_s \circ \phi_t\), typically generated by an ODE \(\dot{x} = v(x)\).

Theorem: The Hartman-Grobman Theorem

Theorem: Let \(x^*\) be a hyperbolic fixed point of a \(C^1\) diffeomorphism \(f: \mathbb{R}^n \to \mathbb{R}^n\) (meaning no eigenvalue of \(Df(x^*)\) has modulus 1). Then there exists a neighborhood \(U\) of \(x^*\) and a homeomorphism \(h: U \to h(U)\) such that:

\[h \circ f = Df(x^*) \circ h\]

That is, \(f\) is topologically conjugate to its linearization near \(x^*\).

Corollary: The stability of a hyperbolic fixed point is determined by the eigenvalues of the Jacobian.

Notation Guide

  • \(f^n\): n-fold composition of \(f\)
  • \(O(x_0)\): Orbit of \(x_0\)
  • \(Df(x)\): Jacobian matrix of \(f\) at \(x\)
  • \(W^s(x)\): Stable manifold (points converging to \(x\) forward)
  • \(W^u(x)\): Unstable manifold (points converging to \(x\) backward)
  • \(\lambda\): Lyapunov exponent
  • \(\phi_t\): Flow at time \(t\)
  • \(\dot{x} = dx/dt\): Time derivative
  • \(\Omega(f)\): Non-wandering set

import numpy as np

def logistic_map(r: float, x0: float, n: int) -> np.ndarray:
    """Iterate the logistic map: x_{n+1} = r * x_n * (1 - x_n)"""
    trajectory = np.zeros(n)
    x = x0
    for i in range(n):
        trajectory[i] = x
        x = r * x * (1 - x)
    return trajectory

def lyapunov_exponent_logistic(r: float, n: int = 10000) -> float:
    """Compute Lyapunov exponent for logistic map."""
    x = 0.5
    for _ in range(1000):  # Transient
        x = r * x * (1 - x)
    
    lyap_sum = 0
    for _ in range(n):
        x = r * x * (1 - x)
        lyap_sum += np.log(abs(r * (1 - 2 * x)))
    
    return lyap_sum / n

def henon_map(a: float = 1.4, b: float = 0.3, n: int = 10000):
    """Hénon map: x_{n+1} = 1 - a*x_n² + y_n, y_{n+1} = b * x_n"""
    x, y = np.zeros(n), np.zeros(n)
    x[0], y[0] = 0, 0
    
    for i in range(1, n):
        x[i] = 1 - a * x[i-1]**2 + y[i-1]
        y[i] = b * x[i-1]
    
    return x, y

def lorenz_system(sigma: float = 10, rho: float = 28, beta: float = 8/3,
                  dt: float = 0.01, n: int = 10000):
    """Lorenz system: dx/dt = σ(y - x), dy/dt = x(ρ - z) - y, dz/dt = xy - βz"""
    x, y, z = np.zeros(n), np.zeros(n), np.zeros(n)
    x[0], y[0], z[0] = 1, 1, 1
    
    for i in range(1, n):
        dx = sigma * (y[i-1] - x[i-1])
        dy = x[i-1] * (rho - z[i-1]) - y[i-1]
        dz = x[i-1] * y[i-1] - beta * z[i-1]
        
        x[i] = x[i-1] + dt * dx
        y[i] = y[i-1] + dt * dy
        z[i] = z[i-1] + dt * dz
    
    return x, y, z

Cryptography: The Mathematics of Secrets

cryptography

Real-World Motivation

How do we communicate securely in a world of eavesdroppers? Modern cryptography transforms number theory and abstract algebra into practical tools protecting everything from credit card transactions to state secrets. Public-key cryptography, invented by Diffie and Hellman in 1976, solved the key distribution problem that plagued classical cryptography. RSA relies on the difficulty of factoring large integers; elliptic curve cryptography offers equivalent security with smaller keys; lattice-based cryptography promises quantum resistance. The security of these systems rests on computational complexity—problems that are easy to verify but (believed to be) hard to solve.

Definitions

  • Symmetric Encryption: Same key for encryption and decryption (e.g., AES). Fast but requires secure key exchange.
  • Public-Key Encryption: Uses key pairs—public key for encryption, private key for decryption.
  • RSA: Based on the hardness of factoring \(n = pq\). Public key: \((n, e)\), private key: \(d\) where \(ed \equiv 1 \pmod{\phi(n)}\).
  • Elliptic Curve: Points \((x, y)\) satisfying \(y^2 = x^3 + ax + b\) over a finite field, forming a group under geometric addition.
  • Discrete Logarithm: Given \(g\) and \(g^x \pmod{p}\), find \(x\). Believed hard for large \(p\).
  • One-Way Function: Easy to compute, hard to invert. The foundation of computational security.

Theorem: Correctness of RSA

Theorem: Let \(n = pq\) where \(p, q\) are distinct primes. Let \(e\) satisfy \(\gcd(e, \phi(n)) = 1\) and \(d\) satisfy \(ed \equiv 1 \pmod{\phi(n)}\). Then for all \(m \in \mathbb{Z}_n\):

\[(m^e)^d \equiv m \pmod{n}\]

Proof: Since \(ed = 1 + k\phi(n) = 1 + k(p-1)(q-1)\):

\[m^{ed} = m^{1 + k(p-1)(q-1)} = m \cdot (m^{p-1})^{k(q-1)}\]

By Fermat's Little Theorem, if \(\gcd(m, p) = 1\), then \(m^{p-1} \equiv 1 \pmod{p}\), so \(m^{ed} \equiv m \pmod{p}\). If \(p | m\), both sides are 0. Similarly for \(q\). By CRT, \(m^{ed} \equiv m \pmod{n}\).

Notation Guide

  • \(\mathbb{Z}_n\): Integers modulo \(n\)
  • \(\mathbb{Z}_n^*\): Multiplicative group of units modulo \(n\)
  • \(\phi(n)\): Euler's totient function, \(|\mathbb{Z}_n^*|\)
  • \(a \equiv b \pmod{n}\): Congruence modulo \(n\)
  • \(a^{-1} \pmod{n}\): Modular multiplicative inverse
  • \(E_k(m)\), \(D_k(c)\): Encryption/decryption with key \(k\)
  • \(E(F_p)\): Elliptic curve over finite field \(\mathbb{F}_p\)
  • \(\#E\): Number of points on elliptic curve (group order)

import random
from math import gcd
from typing import Tuple, Optional

def mod_exp(base: int, exp: int, mod: int) -> int:
    """Fast modular exponentiation: base^exp mod mod"""
    result = 1
    base = base % mod
    while exp > 0:
        if exp & 1:
            result = (result * base) % mod
        base = (base * base) % mod
        exp >>= 1
    return result

def extended_gcd(a: int, b: int) -> Tuple[int, int, int]:
    """Extended Euclidean algorithm."""
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = extended_gcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)

def mod_inverse(a: int, m: int) -> Optional[int]:
    """Modular multiplicative inverse of a modulo m."""
    g, x, _ = extended_gcd(a % m, m)
    if g != 1:
        return None
    return (x % m + m) % m

def is_prime(n: int, k: int = 10) -> bool:
    """Miller-Rabin primality test."""
    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False
    
    r, d = 0, n - 1
    while d % 2 == 0:
        r += 1
        d //= 2
    
    for _ in range(k):
        a = random.randrange(2, n - 1)
        x = mod_exp(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(r - 1):
            x = mod_exp(x, 2, n)
            if x == n - 1:
                break
        else:
            return False
    return True

class RSA:
    """RSA public-key cryptosystem."""
    
    def __init__(self, key_size: int = 512):
        self.p = self._generate_prime(key_size // 2)
        self.q = self._generate_prime(key_size // 2)
        while self.q == self.p:
            self.q = self._generate_prime(key_size // 2)
        
        self.n = self.p * self.q
        self.phi = (self.p - 1) * (self.q - 1)
        
        self.e = 65537
        while gcd(self.e, self.phi) != 1:
            self.e += 2
        
        self.d = mod_inverse(self.e, self.phi)
    
    def _generate_prime(self, bits: int) -> int:
        while True:
            n = random.getrandbits(bits) | 1 | (1 << (bits - 1))
            if is_prime(n):
                return n
    
    def encrypt(self, message: int) -> int:
        return mod_exp(message, self.e, self.n)
    
    def decrypt(self, ciphertext: int) -> int:
        return mod_exp(ciphertext, self.d, self.n)

Fluid Dynamics: The Mathematics of Flow

fluid-dynamics

Real-World Motivation

From weather prediction to aircraft design, from blood flow in arteries to ocean currents, fluid dynamics describes how liquids and gases move. The Navier-Stokes equations, a system of nonlinear partial differential equations, govern all fluid motion. Despite their concise form, these equations harbor deep mysteries—the million-dollar Navier-Stokes existence and smoothness problem remains unsolved. Computational fluid dynamics (CFD) uses numerical methods to approximate solutions, enabling engineers to simulate flows that are too complex for analytical treatment. Turbulence, the chaotic motion at high Reynolds numbers, remains one of the last great unsolved problems in classical physics.

Definitions

  • Velocity Field: \(\mathbf{u}(\mathbf{x}, t)\), the velocity of fluid at position \(\mathbf{x}\) and time \(t\).
  • Pressure: \(p(\mathbf{x}, t)\), the force per unit area exerted by the fluid.
  • Density: \(\rho\), mass per unit volume. For incompressible flow, \(\rho\) is constant.
  • Viscosity: \(\mu\), a measure of fluid's resistance to deformation. Kinematic viscosity: \(\nu = \mu/\rho\).
  • Reynolds Number: \(\text{Re} = \frac{UL}{\nu}\), the ratio of inertial to viscous forces. Determines flow regime (laminar vs. turbulent).
  • Vorticity: \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\), measuring local rotation of fluid elements.
  • Stream Function: \(\psi\) such that \(u = \partial_y \psi\), \(v = -\partial_x \psi\) for 2D incompressible flow.

Theorem: Conservation Laws in Fluid Dynamics

Theorem (Navier-Stokes Equations): For an incompressible, viscous fluid:

\[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u} + \mathbf{f}\]

\[\nabla \cdot \mathbf{u} = 0\]

where \(\mathbf{f}\) represents external forces (e.g., gravity).

Euler Equations (inviscid, \(\nu = 0\)):

\[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \mathbf{f}\]

Kelvin's Circulation Theorem: For barotropic flow with conservative forces, circulation around a closed loop moving with the fluid is constant:

\[\frac{d}{dt} \oint_C \mathbf{u} \cdot d\mathbf{l} = 0\]

Notation Guide

  • \(\mathbf{u} = (u, v, w)\): Velocity vector field
  • \(\nabla = (\partial_x, \partial_y, \partial_z)\): Gradient operator
  • \(\nabla \cdot \mathbf{u}\): Divergence (measures expansion/compression)
  • \(\nabla \times \mathbf{u}\): Curl (vorticity)
  • \(\nabla^2\): Laplacian \(\partial_{xx} + \partial_{yy} + \partial_{zz}\)
  • \((\mathbf{u} \cdot \nabla)\mathbf{u}\): Convective (advective) derivative
  • \(D/Dt = \partial_t + \mathbf{u} \cdot \nabla\): Material derivative
  • \(\text{Re}\): Reynolds number
  • \(\boldsymbol{\omega}\): Vorticity vector

import numpy as np

def velocity_gradient(u: np.ndarray, v: np.ndarray, dx: float, dy: float):
    """Compute velocity gradient components using central differences."""
    dudx = np.gradient(u, dx, axis=1)
    dudy = np.gradient(u, dy, axis=0)
    dvdx = np.gradient(v, dx, axis=1)
    dvdy = np.gradient(v, dy, axis=0)
    return dudx, dudy, dvdx, dvdy

def vorticity_2d(u: np.ndarray, v: np.ndarray, dx: float, dy: float) -> np.ndarray:
    """Compute vorticity ω = ∂v/∂x - ∂u/∂y for 2D flow."""
    dudx, dudy, dvdx, dvdy = velocity_gradient(u, v, dx, dy)
    return dvdx - dudy

def divergence_2d(u: np.ndarray, v: np.ndarray, dx: float, dy: float) -> np.ndarray:
    """Compute divergence ∇·u = ∂u/∂x + ∂v/∂y."""
    dudx, dudy, dvdx, dvdy = velocity_gradient(u, v, dx, dy)
    return dudx + dvdy

Optimization: Finding the Best

optimization

Real-World Motivation

How do we make the best decisions given constraints? Optimization theory provides the mathematical framework for maximizing efficiency, minimizing cost, and finding optimal solutions across engineering, economics, machine learning, and operations research. Linear programming, developed by Kantorovich and Dantzig, revolutionized resource allocation. Convex optimization guarantees global optima for broad problem classes. Gradient descent and its variants power modern machine learning. From portfolio optimization to supply chain management, from training neural networks to designing bridges, optimization algorithms turn "what's best?" into computable answers.

Definitions

  • Optimization Problem: \(\min_{x \in \mathcal{X}} f(x)\) subject to \(g_i(x) \leq 0\), \(h_j(x) = 0\).
  • Convex Set: \(S\) is convex if \(x, y \in S \Rightarrow \lambda x + (1-\lambda)y \in S\) for all \(\lambda \in [0,1]\).
  • Convex Function: \(f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)\). For twice differentiable: \(\nabla^2 f \succeq 0\).
  • Lagrangian: \(\mathcal{L}(x, \lambda, \nu) = f(x) + \sum_i \lambda_i g_i(x) + \sum_j \nu_j h_j(x)\).
  • KKT Conditions: Necessary conditions for optimality: stationarity, primal feasibility, dual feasibility, complementary slackness.
  • Gradient Descent: \(x_{k+1} = x_k - \alpha_k \nabla f(x_k)\), moving in the direction of steepest descent.
  • Strong Duality: For convex problems under constraint qualifications, \(p^* = d^*\) (primal optimum equals dual optimum).

Theorem: Convex Optimization Duality

Theorem (Weak Duality): For any optimization problem:

\[d^* = \sup_{\lambda \geq 0, \nu} \inf_x \mathcal{L}(x, \lambda, \nu) \leq \inf_x \sup_{\lambda \geq 0, \nu} \mathcal{L}(x, \lambda, \nu) = p^*\]

where \(p^*\) is the primal optimal value and \(d^*\) is the dual optimal value.

Theorem (Strong Duality): For a convex optimization problem with Slater's condition (strict feasibility), strong duality holds:

\[d^* = p^*\]

KKT Conditions (for convex problems): \((x^*, \lambda^*, \nu^*)\) are optimal iff:

  • Stationarity: \(\nabla f(x^*) + \sum_i \lambda_i^* \nabla g_i(x^*) + \sum_j \nu_j^* \nabla h_j(x^*) = 0\)
  • Primal Feasibility: \(g_i(x^*) \leq 0\), \(h_j(x^*) = 0\)
  • Dual Feasibility: \(\lambda_i^* \geq 0\)
  • Complementary Slackness: \(\lambda_i^* g_i(x^*) = 0\)

Notation Guide

  • \(f(x)\): Objective function to minimize
  • \(g_i(x) \leq 0\): Inequality constraints
  • \(h_j(x) = 0\): Equality constraints
  • \(\mathcal{L}\): Lagrangian
  • \(\lambda_i\): Lagrange multipliers for inequalities
  • \(\nu_j\): Lagrange multipliers for equalities
  • \(\nabla f\): Gradient of \(f\)
  • \(\nabla^2 f\): Hessian matrix
  • \(p^*\): Primal optimal value
  • \(d^*\): Dual optimal value
  • \(\alpha_k\): Step size at iteration \(k\)

import numpy as np
from typing import Callable, Tuple, List

def gradient_descent(f: Callable[[np.ndarray], float],
                     grad_f: Callable[[np.ndarray], np.ndarray],
                     x0: np.ndarray,
                     alpha: float = 0.1,
                     max_iter: int = 1000,
                     tol: float = 1e-6) -> Tuple[np.ndarray, List[float]]:
    """Vanilla gradient descent."""
    x = x0.copy()
    history = [f(x)]
    
    for _ in range(max_iter):
        gradient = grad_f(x)
        x_new = x - alpha * gradient
        history.append(f(x_new))
        
        if np.linalg.norm(x_new - x) < tol:
            break
        x = x_new
    
    return x, history

def newtons_method(f: Callable[[np.ndarray], float],
                   grad_f: Callable[[np.ndarray], np.ndarray],
                   hess_f: Callable[[np.ndarray], np.ndarray],
                   x0: np.ndarray,
                   max_iter: int = 100,
                   tol: float = 1e-6) -> Tuple[np.ndarray, List[float]]:
    """Newton's method for optimization (uses second-order information)."""
    x = x0.copy()
    history = [f(x)]
    
    for _ in range(max_iter):
        grad = grad_f(x)
        hess = hess_f(x)
        
        # Solve H Δx = -∇f for Δx
        delta_x = np.linalg.solve(hess, -grad)
        x_new = x + delta_x
        history.append(f(x_new))
        
        if np.linalg.norm(delta_x) < tol:
            break
        x = x_new
    
    return x, history

# Rosenbrock function (banana function)
def rosenbrock(x: np.ndarray, a: float = 1, b: float = 100) -> float:
    """Global minimum at (a, a²) with value 0."""
    return (a - x[0])**2 + b * (x[1] - x[0]**2)**2

def rosenbrock_grad(x: np.ndarray, a: float = 1, b: float = 100) -> np.ndarray:
    dx0 = -2 * (a - x[0]) - 4 * b * x[0] * (x[1] - x[0]**2)
    dx1 = 2 * b * (x[1] - x[0]**2)
    return np.array([dx0, dx1])

def rosenbrock_hess(x: np.ndarray, b: float = 100) -> np.ndarray:
    return np.array([
        [2 + 12*b*x[0]**2 - 4*b*x[1], -4*b*x[0]],
        [-4*b*x[0], 2*b]
    ])

Tropical Geometry: Geometry Over the Min-Plus Semiring

tropical-geometry

Historical Context

Tropical geometry emerged in the late 1990s and early 2000s as a powerful tool connecting algebraic geometry to combinatorics. The name honors Brazilian mathematician Imre Simon, who pioneered the use of min-plus algebra, and the tradition of Brazilian mathematics. Tropical geometry studies algebraic varieties over the tropical semiring \((\mathbb{R} \cup \{\infty\}, \oplus, \odot)\) where \(a \oplus b = \min(a, b)\) and \(a \odot b = a + b\). Remarkably, classical algebraic varieties can be "tropicalized" into piecewise-linear objects called tropical varieties, which are often easier to analyze. Applications include enumerative geometry (Gromov-Witten invariants), mirror symmetry, and optimization.

Definitions

  • Tropical Semiring: \(\mathbb{T} = \mathbb{R} \cup \{\infty\}\) with operations \(a \oplus b = \min(a, b)\) and \(a \odot b = a + b\). Identity elements: \(\infty\) for \(\oplus\), 0 for \(\odot\).
  • Tropical Polynomial: \(p(x) = \bigoplus_{i} (a_i \odot x^{\odot i}) = \min_i(a_i + i \cdot x)\).
  • Tropical Hypersurface: The set where the minimum in a tropical polynomial is achieved at least twice.
  • Newton Polygon: For a polynomial \(\sum a_{ij} x^i y^j\), the convex hull of \(\{(i, j) : a_{ij} \neq 0\}\).
  • Amoeba: The image of an algebraic variety under the log map \(\text{Log}_t: (z_1, \ldots, z_n) \mapsto (\log_t|z_1|, \ldots, \log_t|z_n|)\).
  • Tropical Limit: As \(t \to \infty\), the amoeba converges to a tropical variety.

Theorem: Tropical Bézout's Theorem

Theorem: Two general tropical curves of degrees \(d_1\) and \(d_2\) intersect in exactly \(d_1 \cdot d_2\) points (counted with multiplicities).

Tropical Fundamental Theorem of Algebra: A tropical polynomial of degree \(d\) has exactly \(d\) roots (counted with multiplicities).

Correspondence Theorem: For a generic tropical curve of degree \(d\) and genus \(g\), the number of classical curves tropicalizing to it equals the number of ways to distribute integer lengths to the edges satisfying certain constraints.

Notation Guide

  • \(\mathbb{T}\): Tropical semiring
  • \(\oplus\): Tropical addition (min)
  • \(\odot\): Tropical multiplication (plus)
  • \(x^{\odot n}\): Tropical power (n·x)
  • \(V_{\text{trop}}(f)\): Tropical hypersurface of \(f\)
  • \(\text{Trop}(X)\): Tropicalization of variety \(X\)
  • \(\text{Newt}(f)\): Newton polygon/polytope of \(f\)
  • \(\mathcal{A}_t(V)\): Amoeba of variety \(V\) at base \(t\)

import numpy as np

def tropical_add(a: float, b: float) -> float:
    """Tropical addition: a ⊕ b = min(a, b)"""
    return min(a, b)

def tropical_mult(a: float, b: float) -> float:
    """Tropical multiplication: a ⊙ b = a + b"""
    return a + b

def tropical_pow(a: float, n: int) -> float:
    """Tropical power: a^⊙n = n·a"""
    return n * a

def tropical_polyval(coeffs, x: float) -> float:
    """
    Evaluate tropical polynomial.
    coeffs[i] is coefficient of x^⊙i
    p(x) = min_i (coeffs[i] + i*x)
    """
    values = [tropical_mult(coeffs[i], tropical_pow(x, i)) for i in range(len(coeffs))]
    return min(values)

def tropical_roots(coeffs):
    """
    Find tropical roots of polynomial.
    Roots occur where minimum is achieved at least twice.
    """
    n = len(coeffs) - 1
    roots = []
    
    # Roots are at points where lines coeffs[i] + i*x intersect
    for i in range(n):
        for j in range(i + 1, n + 1):
            if i != j:
                root = (coeffs[j] - coeffs[i]) / (i - j)
                val = coeffs[i] + i * root
                is_root = all(coeffs[k] + k * root >= val - 1e-10 for k in range(n + 1))
                if is_root and root not in roots:
                    roots.append(root)
    
    return sorted(roots)

def tropical_matrix_mult(A: np.ndarray, B: np.ndarray) -> np.ndarray:
    """
    Tropical matrix multiplication.
    (A ⊙ B)_ij = ⊕_k (A_ik ⊙ B_kj) = min_k (A_ik + B_kj)
    """
    n, m = A.shape
    _, p = B.shape
    result = np.zeros((n, p))
    
    for i in range(n):
        for j in range(p):
            result[i, j] = np.min(A[i, :] + B[:, j])
    
    return result

Quantum Groups: Symmetry in the Quantum World

quantum-groups

Historical Context

Quantum groups emerged in the 1980s from two independent directions: Vladimir Drinfeld and Michio Jimbo's work on quantum integrable systems, and the study of von Neumann algebras by Alain Connes and others. They are neither quantum nor groups, but rather deformations of universal enveloping algebras and coordinate rings of algebraic groups. The name reflects their origin in quantum inverse scattering theory. Quantum groups provide the algebraic framework for quantum topology (knot invariants, topological quantum field theories), statistical mechanics (Yang-Baxter equation), and noncommutative geometry. They embody the philosophy that classical structures have quantum deformations parameterized by a variable \(q\).

Definitions

  • Hopf Algebra: A bialgebra with an antipode map \(S: H \to H\) satisfying \(m \circ (S \otimes \text{id}) \circ \Delta = \eta \circ \varepsilon = m \circ (\text{id} \otimes S) \circ \Delta\).
  • Quantum Group \(U_q(\mathfrak{g})\): A deformation of the universal enveloping algebra of a Lie algebra \(\mathfrak{g}\), with generators \(E_i, F_i, K_i^{\pm 1}\) and \(q\)-deformed relations.
  • Yang-Baxter Equation: \(R_{12}R_{13}R_{23} = R_{23}R_{13}R_{12}\) for an \(R\)-matrix in \(H \otimes H\), ensuring consistency of quantum integrable systems.
  • Universal R-Matrix: An element \(R \in H \otimes H\) satisfying the Yang-Baxter equation and intertwining the coproduct with its opposite.
  • Quasitriangular Structure: A Hopf algebra with universal R-matrix, providing solutions to Yang-Baxter and representations of braid groups.
  • Drinfeld Double: A construction building a quasitriangular Hopf algebra from any finite-dimensional Hopf algebra.

Theorem: The Quantum Yang-Baxter Equation

Theorem: Let \(H\) be a quasitriangular Hopf algebra with universal R-matrix \(R\). Then \(R\) satisfies the quantum Yang-Baxter equation:

\[R_{12}R_{13}R_{23} = R_{23}R_{13}R_{12}\]

where \(R_{12} = R \otimes 1\), \(R_{23} = 1 \otimes R\), etc.

Corollary (Braid Group Representations): For any representation \(V\) of \(H\), the map:

\[\sigma_i \mapsto (\text{id}^{\otimes (i-1)} \otimes R \otimes \text{id}^{\otimes (n-i-1)}) \circ P_{i,i+1}\]

defines a representation of the braid group \(B_n\) on \(V^{\otimes n}\), where \(P\) is the flip operator.

Theorem (Drinfeld): The category of representations of a quantum group is a braided monoidal category.

Notation Guide

  • \(U_q(\mathfrak{g})\): Quantum group (quantized enveloping algebra)
  • \(E_i, F_i, K_i\): Chevalley generators
  • \(q\): Deformation parameter
  • \([n]_q = \frac{q^n - q^{-n}}{q - q^{-1}}\): Quantum integer
  • \(\Delta\): Coproduct
  • \(\varepsilon\): Counit
  • \(S\): Antipode
  • \(R\): Universal R-matrix
  • \(R_{ij}\): R-matrix acting on tensor factors \(i, j\)
  • \(\tau\) or \(P\): Flip operator \(v \otimes w \mapsto w \otimes v\)

def quantum_integer(n: int, q: float) -> float:
    """Quantum integer [n]_q = (q^n - q^(-n)) / (q - q^(-1))"""

        return float(n)
    return (q**n - q**(-n)) / (q - q**(-1))

def quantum_factorial(n: int, q: float) -> float:
    """Quantum factorial [n]!_q = [1]_q [2]_q ... [n]_q"""
    result = 1.0
    for k in range(1, n + 1):
        result *= quantum_integer(k, q)
    return result

    if k < 0 or k > n:
        return 0.0
    return quantum_factorial(n, q) / (quantum_factorial(k, q) * quantum_factorial(n - k, q))

Spectral Sequences: Computing the Hard Way

spectral-sequences

Historical Context

Spectral sequences, invented by Jean Leray in the 1940s while he was a prisoner of war, are one of the most powerful computational tools in algebraic topology and homological algebra. Leray developed them to study sheaf cohomology, but they have since found applications across mathematics—from computing homotopy groups of spheres to understanding the cohomology of fiber bundles. A spectral sequence is like a book: each page contains groups and differentials, and we "turn the page" by taking cohomology. With patience, we can read off the answer to complex computations. The Leray-Serre spectral sequence, the Atiyah-Hirzebruch spectral sequence, and the Adams spectral sequence are among the most famous.

Definitions

  • Spectral Sequence: A collection of bigraded groups \(\{E_{p,q}^r\}\) for \(r \geq r_0\) with differentials \(d^r: E_{p,q}^r \to E_{p-r, q+r-1}^r\) satisfying \(d^r \circ d^r = 0\), and isomorphisms \(E_{p,q}^{r+1} \cong H_{p,q}(E^r_{\bullet, \bullet}, d^r)\).
  • Convergence: A spectral sequence converges to \(H_*\) if there exists a filtration \(F_p H_n\) such that \(E^\infty_{p,q} \cong F_p H_{p+q} / F_{p-1} H_{p+q}\).
  • First Quadrant Spectral Sequence: \(E_{p,q}^r = 0\) unless \(p, q \geq 0\). These always converge.
  • Serre Spectral Sequence: For a fibration \(F \to E \to B\), there is a spectral sequence with \(E^2_{p,q} = H_p(B; H_q(F)) \Rightarrow H_{p+q}(E)\).
  • Collapse: The spectral sequence collapses at page \(r\) if all differentials \(d^s = 0\) for \(s \geq r\).

Theorem: The Leray-Serre Spectral Sequence

Theorem: Let \(p: E \to B\) be a fibration with fiber \(F\) over a path-connected base \(B\). If \(B\) is simply connected (or more generally, if \(\pi_1(B)\) acts trivially on \(H_*(F)\)), there exists a first-quadrant spectral sequence:

\[E^2_{p,q} = H_p(B; H_q(F)) \Rightarrow H_{p+q}(E)\]

with differential \(d^r: E^r_{p,q} \to E^r_{p-r, q+r-1}\).

Edge Homomorphisms: There are maps:

\[H_n(E) \twoheadrightarrow E^\infty_{n,0} \subset E^2_{n,0} = H_n(B)\]

\[H_n(F) = E^2_{0,n} \twoheadrightarrow E^\infty_{0,n} \hookrightarrow H_n(E)\]

Historical Context

Arithmetic geometry, the modern synthesis of number theory and algebraic geometry, emerged in the mid-20th century through the work of Weil, Grothendieck, and their successors. It studies solutions to polynomial equations over number fields and finite fields, using geometric intuition and tools. The field achieved prominence with Faltings' proof of the Mordell conjecture, Wiles' proof of Fermat's Last Theorem, and the development of the Langlands program. Central objects include elliptic curves, modular forms, Galois representations, and schemes. The interplay between local and global properties, encoded in the Langlands philosophy, reveals deep symmetries connecting analysis, geometry, and number theory.

Definitions

  • Arithmetic Variety: A scheme \(X\) of finite type over \(\text{Spec}(\mathbb{Z})\) or a number field \(K\).
  • Elliptic Curve: A smooth projective curve of genus 1 with a specified point (the identity). Over \(\mathbb{Q}\), can be written as \(y^2 = x^3 + ax + b\) with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Mordell-Weil Group: The group of rational points \(E(K)\) on an elliptic curve over a number field, which is finitely generated: \(E(K) \cong E(K)_{\text{tors}} \oplus \mathbb{Z}^r\).
  • L-function: For an elliptic curve over \(\mathbb{Q}\), \(L(E, s) = \prod_{p \nmid N} (1 - a_p p^{-s} + p^{1-2s})^{-1} \prod_{p \mid N} (\cdots)^{-1}\).
  • BSD Conjecture: The rank of \(E(\mathbb{Q})\) equals the order of vanishing of \(L(E, s)\) at \(s = 1\).
  • Modular Curve: \(X_0(N)\) parametrizes elliptic curves with a cyclic subgroup of order \(N\).

Theorem: The Mordell-Weil Theorem

Theorem (Mordell-Weil): Let \(E\) be an elliptic curve over a number field \(K\). Then the group of \(K\)-rational points \(E(K)\) is a finitely generated abelian group:

\[E(K) \cong E(K)_{\text{tors}} \oplus \mathbb{Z}^r\]

where \(E(K)_{\text{tors}}\) is the finite torsion subgroup and \(r\) is the rank of \(E\).

Theorem (Mazur): For elliptic curves over \(\mathbb{Q}\), the torsion subgroup is one of:

\[\mathbb{Z}/n\mathbb{Z} \text{ for } n \in \{1, 2, \ldots, 10, 12\} \text{ or } \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2n\mathbb{Z} \text{ for } n \in \{1, 2, 3, 4\}\]

Theorem (Faltings): A curve of genus \(g \geq 2\) over a number field has only finitely many rational points.

def elliptic_curve_points(a: int, b: int, p: int):
    """
    Count points on elliptic curve y² = x³ + ax + b over F_p.
    Returns list of (x, y) points including point at infinity.
    """
    points = []
    
    for x in range(p):
        rhs = (x**3 + a*x + b) % p
        # Find y such that y² ≡ rhs (mod p)
        for y in range(p):
            if (y * y) % p == rhs:
                points.append((x, y))
    
    # Include point at infinity
    return points, len(points) + 1

IMO Shortlist Problem

Let \(n\) be a positive integer. Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all real \(x, y\):

\[f(x + f(y)) = f(x) + y^n\]

Hint

First show that \(f\) is injective. Then find \(f(0)\) by setting \(x = 0\). Consider what happens when you substitute \(y = 0\) and compare with the original equation.

Solution

Step 1: Show \(f\) is injective. If \(f(a) = f(b)\), then \(f(x + f(a)) = f(x + f(b))\), so \(f(x) + a^n = f(x) + b^n\), giving \(a^n = b^n\). For odd \(n\), this implies \(a = b\). For even \(n\), we get \(|a| = |b|\).

Step 2: Set \(x = 0\): \(f(f(y)) = f(0) + y^n\).

Step 3: Set \(y = 0\): \(f(x + f(0)) = f(x)\). By injectivity (for odd \(n\)), \(f(0) = 0\).

Step 4: With \(f(0) = 0\), we have \(f(f(y)) = y^n\).

Step 5: Replace \(y\) with \(f(y)\) in the original: \(f(x + f(f(y))) = f(x) + f(y)^n\), so \(f(x + y^n) = f(x) + f(y)^n\).

Step 6: For odd \(n\), setting \(x = 0\) gives \(f(y^n) = f(y)^n\). Combined with Cauchy-type functional equation analysis, we get \(f(x) = x\) for all \(x\).

Answer: For odd \(n\), the unique solution is \(f(x) = x\). For even \(n\), there are no solutions (the condition \(f(f(y)) = y^n \geq 0\) contradicts surjectivity onto \(\mathbb{R}\)).

The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. It is a famous example of a fractal—exhibiting infinite complexity at all scales.

The boundary of the Mandelbrot set is connected, and the set itself is simply connected. It encodes information about the dynamics of all quadratic polynomials: the main cardioid corresponds to polynomials with an attracting fixed point, while the bulbs correspond to attracting cycles of various periods.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c: complex, max_iter: int = 100) -> int:
    """
    Compute the number of iterations until escape for point c.
    Returns max_iter if the point is in the Mandelbrot set.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin: float = -2.5, xmax: float = 1.0,
                   ymin: float = -1.25, ymax: float = 1.25,
                   width: int = 1000, height: int = 1000,
                   max_iter: int = 100) -> np.ndarray:
    """Generate the Mandelbrot set as a 2D array."""
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[mask] = i
    
    return M
