1. The Fundamental Theorem of Algebra

Every non-constant polynomial with complex coefficients has at least one complex root.

Theorem (Fundamental Theorem of Algebra): Let \(p(z) = a_n z^n + a_{n-1} z^{n-1} + \cdots + a_1 z + a_0\) be a polynomial of degree \(n \geq 1\) with complex coefficients \(a_k \in \mathbb{C}\) and \(a_n \neq 0\). Then there exists \(z_0 \in \mathbb{C}\) such that \(p(z_0) = 0\).
Proof Sketch (using Liouville's Theorem): Suppose \(p(z)\) has no roots. Then \(f(z) = 1/p(z)\) is entire (holomorphic on all of \(\mathbb{C}\)). As \(|z| \to \infty\), \(|p(z)| \to \infty\), so \(|f(z)| \to 0\). Thus \(f\) is bounded. By Liouville's Theorem, \(f\) is constant, implying \(p\) is constant — contradiction.

Notation explained:

  • \(\mathbb{C}\) — the set of complex numbers
  • \(a_k\) — coefficients of the polynomial
  • \(z_0\) — a root of the polynomial where \(p(z_0) = 0\)
  • Entire function — holomorphic (complex differentiable) on the entire complex plane

2. The Brouwer Fixed-Point Theorem

Every continuous function from a closed ball to itself has at least one fixed point.

Theorem (Brouwer Fixed-Point): Let \(B^n = \{x \in \mathbb{R}^n : \|x\| \leq 1\}\) be the closed unit ball in \(\mathbb{R}^n\). For any continuous function \(f: B^n \to B^n\), there exists \(x \in B^n\) such that \(f(x) = x\).
Proof Sketch (for n=1): For \(f: [0,1] \to [0,1]\) continuous, define \(g(x) = f(x) - x\). Then \(g(0) = f(0) \geq 0\) and \(g(1) = f(1) - 1 \leq 0\). By the Intermediate Value Theorem, there exists \(c \in [0,1]\) with \(g(c) = 0\), so \(f(c) = c\).

Notation explained:

  • \(B^n\) — the n-dimensional closed unit ball
  • \(\|x\|\) — the Euclidean norm of vector \(x\)
  • \(\mathbb{R}^n\) — n-dimensional Euclidean space
  • Fixed point — a point \(x\) where \(f(x) = x\)
import numpy as np
from scipy.optimize import fsolve

def brouwer_1d_demo():
    """Demonstrate Brouwer Fixed-Point Theorem in 1D"""
    # Any continuous f: [0,1] -> [0,1] has a fixed point

    def f1(x):
        return 0.5 + 0.3 * np.sin(2 * np.pi * x)
    
    def g1(x):
        return f1(x) - x  # we want g(x) = 0
    
    fixed_point = fsolve(g1, 0.5)[0]
    print(f"f(x) = 0.5 + 0.3*sin(2πx)")
    print(f"Fixed point: x = {fixed_point:.6f}")
    print(f"Verification: f({fixed_point:.6f}) = {f1(fixed_point):.6f}")
    
    # Example 2: f(x) = x^2 (maps [0,1] to [0,1])
    def f2(x):
        return x**2
    
    def g2(x):
        return f2(x) - x
    
    fixed_points = fsolve(g2, [0, 1])
    print(f"\nf(x) = x²")
    print(f"Fixed points: {fixed_points}")
    for fp in fixed_points:
        print(f"  f({fp:.6f}) = {f2(fp):.6f}")

3. Dirichlet's Theorem on Arithmetic Progressions

Every arithmetic progression with coprime first term and difference contains infinitely many primes.

Theorem (Dirichlet, 1837): If \(a\) and \(d\) are coprime positive integers (i.e., \(\gcd(a,d) = 1\)), then the arithmetic progression \(a, a+d, a+2d, a+3d, \ldots\) contains infinitely many prime numbers.
Key Ideas: The proof uses Dirichlet L-series \(L(s,\chi) = \sum_{n=1}^{\infty} \frac{\chi(n)}{n^s}\) where \(\chi\) is a Dirichlet character. One shows that \(L(1,\chi) \neq 0\) for non-principal characters, which implies the primes are equidistributed among residue classes modulo \(d\).

Notation explained:

  • \(\gcd(a,d)\) — greatest common divisor of \(a\) and \(d\)
  • \(a + nd\) — the nth term of the arithmetic progression
  • \(\chi\) — Dirichlet character (completely multiplicative periodic function)
  • \(L(s,\chi)\) — Dirichlet L-function, generalization of the Riemann zeta function
from sympy import isprime, gcd
import sympy as sp

def dirichlet_primes(a, d, limit=1000):
    """Find primes in arithmetic progression a, a+d, a+2d, ..."""
    if gcd(a, d) != 1:
        return []  # Dirichlet's theorem requires gcd(a,d) = 1
    
    primes = []
    n = 0
    term = a
    while term < limit:
        if isprime(term):
            primes.append(term)
        n += 1
        term = a + n * d
    return primes

1. The PageRank Algorithm

Google's foundational algorithm for ranking web pages using eigenvector computation.

Theorem (Perron-Frobenius): For a positive square matrix \(A\), there exists a unique largest real eigenvalue \(\lambda_{\max}\) with a corresponding eigenvector having all positive entries.
PageRank Formulation: Let \(G\) be the web graph with adjacency matrix \(A\) where \(A_{ij} = 1\) if page \(j\) links to page \(i\). The transition matrix is \(P_{ij} = \frac{A_{ij}}{\sum_k A_{kj}}\) (column stochastic). The PageRank vector \(\pi\) satisfies: \(\pi = \alpha P \pi + (1-\alpha) \frac{\mathbf{1}}{n}\) where \(\alpha\) is the damping factor (typically 0.85).

Notation explained:

  • \(A_{ij}\) — entry in row \(i\), column \(j\) of matrix \(A\)
  • \(\pi\) — PageRank vector (stationary distribution)
  • \(\alpha\) — damping factor, probability of following a link
  • \(\mathbf{1}/n\) — uniform distribution over all pages
import numpy as np

def pagerank(adj_matrix, alpha=0.85, tol=1e-8, max_iter=1000):
    """
    Compute PageRank using power iteration.
    
    Parameters:
    -----------
    adj_matrix : numpy array
        Adjacency matrix where adj_matrix[i,j] = 1 if j links to i
    alpha : float
        Damping factor (default 0.85)
    """
    n = adj_matrix.shape[0]
    
    # Create transition matrix (column stochastic)
    out_degrees = np.sum(adj_matrix, axis=0)
    # Handle dangling nodes (pages with no out-links)
    out_degrees[out_degrees == 0] = 1
    
    P = adj_matrix / out_degrees  # Transition matrix
    
    # Power iteration
    pi = np.ones(n) / n  # Uniform initial distribution
    
    for _ in range(max_iter):
        pi_new = alpha * P @ pi + (1 - alpha) / n
        if np.linalg.norm(pi_new - pi, 1) < tol:
            break
        pi = pi_new
    
    return pi

2. The Fast Fourier Transform

An efficient algorithm for computing the discrete Fourier transform in \(O(n \log n)\) time.

Theorem (Cooley-Tukey FFT): The Discrete Fourier Transform \(X_k = \sum_{n=0}^{N-1} x_n e^{-2\pi i k n / N}\) can be computed in \(O(N \log N)\) operations when \(N\) is a power of 2, using the divide-and-conquer decomposition: \[X_k = E_k + e^{-2\pi i k / N} O_k\] where \(E_k\) and \(O_k\) are the DFTs of even and odd indexed samples.
Complexity Analysis: Let \(T(N)\) be the complexity for size \(N\). The algorithm computes two DFTs of size \(N/2\) and combines them in \(O(N)\) time: \(T(N) = 2T(N/2) + O(N)\). By the Master Theorem, \(T(N) = O(N \log N)\).

Notation explained:

  • \(X_k\) — kth frequency component (complex number)
  • \(x_n\) — nth time-domain sample
  • \(e^{-2\pi i k n / N}\) — complex exponential (twiddle factor)
  • \(E_k, O_k\) — DFTs of even and odd indexed elements
import numpy as np

def fft(x):
    """
    Cooley-Tukey recursive FFT implementation.
    Assumes len(x) is a power of 2.
    """
    n = len(x)
    if n == 1:
        return x
    
    # Divide
    even = fft(x[0::2])
    odd = fft(x[1::2])
    
    # Combine
    result = np.zeros(n, dtype=complex)
    for k in range(n // 2):
        twiddle = np.exp(-2j * np.pi * k / n)
        result[k] = even[k] + twiddle * odd[k]
        result[k + n // 2] = even[k] - twiddle * odd[k]
    
    return result

3. Support Vector Machines and the Kernel Trick

A powerful classification method that finds optimal separating hyperplanes using quadratic programming.

Theorem (SVM Optimization): Given training data \(\{(x_i, y_i)\}_{i=1}^n\) with \(x_i \in \mathbb{R}^d\) and \(y_i \in \{-1, +1\}\), the optimal separating hyperplane is found by solving: \[\min_{w,b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \geq 1 \text{ for all } i\] The dual formulation uses the kernel matrix \(K_{ij} = \phi(x_i)^T \phi(x_j)\).
Karush-Kuhn-Tucker Conditions: The Lagrangian is \(\mathcal{L} = \frac{1}{2}\|w\|^2 - \sum_i \alpha_i[y_i(w^T x_i + b) - 1]\). Setting derivatives to zero: \(w = \sum_i \alpha_i y_i x_i\) and \(\sum_i \alpha_i y_i = 0\). The dual becomes maximizing \(\sum_i \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j K(x_i, x_j)\) subject to \(\alpha_i \geq 0\).

Notation explained:

  • \(w\) — weight vector normal to the hyperplane
  • \(b\) — bias term
  • \(\alpha_i\) — Lagrange multipliers (support vectors have \(\alpha_i > 0\))
  • \(K(x_i, x_j)\) — kernel function measuring similarity
  • \(\phi\) — feature map to higher dimensional space
import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

class SVM:
    """Simple SVM implementation using quadratic programming"""
    
    def __init__(self, kernel='linear', C=1.0, gamma=0.1):
        self.kernel = kernel
        self.C = C
        self.gamma = gamma
    
    def _kernel(self, x1, x2):
        """Compute kernel function"""
        if self.kernel == 'linear':
            return np.dot(x1, x2)
        elif self.kernel == 'rbf':
            return np.exp(-self.gamma * np.linalg.norm(x1 - x2)**2)
    
    def fit(self, X, y):
        """Train SVM using dual formulation"""
        n_samples = X.shape[0]
        
        # Compute kernel matrix
        K = np.zeros((n_samples, n_samples))
        for i in range(n_samples):
            for j in range(n_samples):
                K[i, j] = self._kernel(X[i], X[j])
        
        # Dual optimization objective
        def objective(alpha):
            return 0.5 * np.sum((alpha * y)[:, None] * (alpha * y)[None, :] * K) - np.sum(alpha)
        
        # Constraints: 0 <= alpha_i <= C, sum(alpha_i * y_i) = 0
        constraints = [{'type': 'eq', 'fun': lambda a: np.dot(a, y)}]
        bounds = [(0, self.C) for _ in range(n_samples)]
        
        result = minimize(objective, np.zeros(n_samples), 
                         method='SLSQP', bounds=bounds, constraints=constraints)
        
        self.alpha = result.x
        self.support_vectors = X[self.alpha > 1e-5]
        self.support_vector_labels = y[self.alpha > 1e-5]
        self.support_alphas = self.alpha[self.alpha > 1e-5]
        
        # Compute bias
        self.b = np.mean([
            y_i - sum(self.support_alphas[j] * self.support_vector_labels[j] * 
                     self._kernel(self.support_vectors[j], sv)
                     for j in range(len(self.support_alphas)))
            for sv, y_i in zip(self.support_vectors, self.support_vector_labels)
        ])
        
        return self
    
    def predict(self, X):
        """Predict class labels"""
        predictions = []
        for x in X:
            score = sum(
                self.support_alphas[i] * self.support_vector_labels[i] * 
                self._kernel(self.support_vectors[i], x)
                for i in range(len(self.support_alphas))
            ) + self.b
            predictions.append(np.sign(score))
        return np.array(predictions)

1. The Monster Group and Moonshine

The largest sporadic simple group and its mysterious connection to modular functions.

Theorem (Monstrous Moonshine, Borcherds 1992): The Monster group \(\mathbb{M}\) (order \(\approx 8 \times 10^{53}\)) is related to the modular function \(j(\tau)\) through the moonshine module \(V^\natural\). The graded dimension of \(V^\natural\) equals the \(q\)-expansion of \(j(\tau) - 744\).
Key Insight: McKay observed that \(196884 = 196883 + 1\), where \(196884\) is the coefficient of \(q^2\) in \(j(\tau)\) and \(196883\) is the dimension of the smallest non-trivial representation of the Monster. This coincidence led to the discovery of the moonshine module as a vertex operator algebra with Monster symmetry.

Notation explained:

  • \(\mathbb{M}\) — the Monster group, largest sporadic simple group
  • \(j(\tau)\) — Klein's modular j-function, \(\tau \in \mathbb{H}\) (upper half-plane)
  • \(V^\natural\) — the moonshine module (vertex operator algebra)
  • \(q = e^{2\pi i \tau}\) — the nome in modular function theory
import numpy as np
import cmath

def modular_j(tau, terms=50):
    """
    Compute the modular j-function j(tau).
    j(tau) = 1728 * g2(tau)^3 / (g2(tau)^3 - 27*g3(tau)^2)
    """
    # Compute Eisenstein series G2k
    def G2k(tau, k):
        result = 2 * (2*np.pi)**(2*k) * (-1)**(k+1) * np.math.factorial(2*k - 1)
        result /= (2*np.pi)**(2*k) * np.math.factorial(2*k - 1)
        # Add sum over lattice
        s = 0
        for m in range(-terms, terms+1):
            for n in range(-terms, terms+1):
                if m == 0 and n == 0:
                    continue
                s += 1 / (m + n*tau)**(2*k)
        return s
    
    # Simplified: use q-expansion
    q = cmath.exp(2j * np.pi * tau)
    
    # j(tau) = q^(-1) + 744 + 196884*q + 21493760*q^2 + ...
    j = 1/q + 744 + 196884*q + 21493760*q**2 + 864299970*q**3
    
    return j

2. Penrose Tilings and Aperiodic Order

Non-periodic tilings of the plane with remarkable mathematical properties.

Theorem (Penrose, 1974): The plane can be tiled using only two prototiles (kite and dart, or rhombuses) such that: (1) the tiling is aperiodic (no translational symmetry), (2) every finite patch appears infinitely often, and (3) the tiling exhibits five-fold rotational symmetry at certain points.
Substitution Method: The Penrose tiles can be constructed via substitution rules: each tile can be decomposed into smaller tiles of the same shape. The golden ratio \(\phi = (1+\sqrt{5})/2\) governs the scaling. The matching rules (colored arcs or bumps) enforce aperiodicity by preventing periodic configurations.

Notation explained:

  • \(\phi = \frac{1+\sqrt{5}}{2} \approx 1.618\) — the golden ratio
  • Aperiodic — no translation vector maps the tiling to itself
  • Prototiles — the basic tile shapes used
  • Substitution rule — decomposition of tiles into smaller copies
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon
from matplotlib.collections import PatchCollection

# Golden ratio
phi = (1 + np.sqrt(5)) / 2

def penrose_rhombus(n_iterations=4):
    """
    Generate Penrose tiling using rhombus substitution.
    Returns vertices of all tiles.
    """
    # Initial tiles: thin and thick rhombuses
    # Angles: 36° and 144° for thin, 72° and 108° for thick
    
    tiles = []
    
    # Start with a decagon of thick rhombuses
    for k in range(5):
        angle = 2 * np.pi * k / 5
        tiles.append(('thick', angle))
    
    # Substitution rules
    def substitute(tile_type, angle):
        """Apply substitution rule to a tile"""
        new_tiles = []
        if tile_type == 'thick':
            # Thick rhombus (72°, 108°) splits into:
            # 2 thick + 1 thin
            new_tiles.append(('thick', angle))
            new_tiles.append(('thick', angle + np.pi/5))
            new_tiles.append(('thin', angle + np.pi/10))
        else:  # thin
            # Thin rhombus (36°, 144°) splits into:
            # 1 thick + 1 thin
            new_tiles.append(('thick', angle))
            new_tiles.append(('thin', angle + np.pi/5))
        return new_tiles
    
    # Apply substitutions
    for _ in range(n_iterations):
        new_tiles = []
        for t, a in tiles:
            new_tiles.extend(substitute(t, a))
        tiles = new_tiles
    
    return tiles

def rhombus_vertices(tile_type, center, angle, size=1):
    """Get vertices of a rhombus tile"""
    if tile_type == 'thick':
        angles = [0, 2*np.pi/5, np.pi, 8*np.pi/5]  # 72° rhombus
    else:  # thin
        angles = [0, np.pi/5, np.pi, 6*np.pi/5]  # 36° rhombus
    
    vertices = []
    for a in angles:
        x = center[0] + size * np.cos(a + angle)
        y = center[1] + size * np.sin(a + angle)
        vertices.append([x, y])
    return vertices

print("=" * 40)

tiles = penrose_rhombus(n_iterations=3)
print(f"Number of tiles after 3 iterations: {len(tiles)}")

# Count tile types
thick_count = sum(1 for t, _ in tiles if t == 'thick')
thin_count = sum(1 for t, _ in tiles if t == 'thin')

3. The Collatz Conjecture

A deceptively simple unsolved problem in number theory.

Conjecture (Collatz, 1937): For any positive integer \(n\), the sequence defined by: \[f(n) = \begin{cases} n/2 & \text{if } n \equiv 0 \pmod{2} \\ 3n+1 & \text{if } n \equiv 1 \pmod{2} \end{cases}\] always reaches 1, regardless of the starting value.
Current Status: The conjecture has been verified by computer for all \(n < 2^{68}\). Various approaches have been attempted: probabilistic heuristics suggest convergence, but no general proof exists. The problem is known to be undecidable in certain generalizations.

Notation explained:

  • \(n \equiv 0 \pmod{2}\) — n is even (divisible by 2)
  • \(n \equiv 1 \pmod{2}\) — n is odd
  • The "3n+1" map — also called the Syracuse function
  • Total stopping time — number of steps to reach 1
def collatz(n):
    """Generate Collatz sequence starting from n"""
    sequence = [n]
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        sequence.append(n)
    return sequence

def total_stopping_time(n):
    """Count steps to reach 1"""
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        steps += 1
    return steps

def max_value(n):
    """Maximum value reached in Collatz sequence"""
    max_val = n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        max_val = max(max_val, n)
    return max_val

4. Tropical Geometry

A piecewise-linear version of algebraic geometry with applications to optimization.

Theorem (Tropical Fundamental Theorem): In tropical geometry, the semi-ring \((\mathbb{R} \cup \{-\infty\}, \oplus, \odot)\) with operations \(a \oplus b = \max(a,b)\) and \(a \odot b = a + b\) satisfies the distributive law. Tropical polynomials define piecewise-linear functions whose domains of linearity correspond to classical algebraic varieties under the logarithmic limit.
Distributivity: We verify \(a \odot (b \oplus c) = (a \odot b) \oplus (a \odot c)\): \[a \odot (b \oplus c) = a + \max(b,c) = \max(a+b, a+c) = (a \odot b) \oplus (a \odot c)\] This makes \((\mathbb{R} \cup \{-\infty\}, \oplus, \odot)\) a semi-ring.

Notation explained:

  • \(\oplus\) — tropical addition (maximum)
  • \(\odot\) — tropical multiplication (standard addition)
  • \(-\infty\) — tropical zero (identity for \(\oplus\))
  • \(0\) — tropical one (identity for \(\odot\))
import numpy as np
import matplotlib.pyplot as plt

# Tropical arithmetic
def trop_add(a, b):
    """Tropical addition: max(a, b)"""
    return max(a, b)

def trop_mul(a, b):
    """Tropical multiplication: a + b"""
    return a + b

def trop_pow(a, n):
    """Tropical power: a * n (standard multiplication)"""
    return a * n

# Tropical polynomial evaluation
def trop_poly(coeffs, x):
    """
    Evaluate tropical polynomial.
    coeffs[i] is coefficient of x^i (tropical)
    p(x) = max(coeffs[i] + i*x)
    """
    values = [trop_mul(coeffs[i], trop_pow(x, i)) for i in range(len(coeffs))]
    return max(values)

def evaluate_tropical_polynomial(coeffs, x_vals):
    """Evaluate tropical polynomial at multiple points"""
    return [trop_poly(coeffs, x) for x in x_vals]

# Tropical roots
def tropical_roots(coeffs):
    """
    Find tropical roots (points where polynomial is not differentiable).
    For p(x) = max(a_i + i*x), roots occur where a_i + i*x = a_j + j*x
    i.e., x = (a_j - a_i) / (i - j) for adjacent terms in the Newton polygon.
    """
    roots = []
    n = len(coeffs)
    for i in range(n):
        for j in range(i+1, n):
            if coeffs[i] != float('-inf') and coeffs[j] != float('-inf'):
                root = (coeffs[j] - coeffs[i]) / (j - i)
                # Verify it's actually a root
                val_i = coeffs[i] + i * root
                val_j = coeffs[j] + j * root
                if abs(val_i - val_j) < 1e-10:
                    # Check it's the maximum
                    is_root = True
                    for k in range(n):
                        if coeffs[k] != float('-inf'):
                            val_k = coeffs[k] + k * root
                            if val_k > val_i + 1e-10:
                                is_root = False
                                break
                    if is_root:
                        roots.append((root, val_i))
    return sorted(set(roots))

roots = tropical_roots(coeffs2)

# Application: shortest path (tropical matrix multiplication)
def trop_matrix_mult(A, B):
    """Tropical matrix multiplication: (A ⊙ B)_ij = max_k(A_ik + B_kj)"""
    n = A.shape[0]
    m = B.shape[1]
    p = A.shape[1]
    C = np.full((n, m), float('-inf'))
    for i in range(n):
        for j in range(m):
            for k in range(p):
                if A[i, k] != float('-inf') and B[k, j] != float('-inf'):
                    C[i, j] = max(C[i, j], A[i, k] + B[k, j])
    return C

Historical Highlight: The Development of Group Theory

Group theory emerged from the study of polynomial equations in the early 19th century. Évariste Galois (1811-1832) discovered that the solvability of polynomial equations by radicals depends on the structure of a group associated with the equation — now called the Galois group.

Though Galois died in a duel at age 20, his manuscripts introduced fundamental concepts: groups, normal subgroups, and the connection between field extensions and groups. His work remained obscure until Liouville published it in 1846.

By the late 19th century, mathematicians like Cayley, Frobenius, and Burnside developed representation theory, applying groups to geometry and physics. Today, group theory is essential in crystallography, quantum mechanics, and cryptography.
