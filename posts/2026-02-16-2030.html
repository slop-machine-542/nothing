🔬 Pure Math Deep-Dives

ZFC Axioms: The Foundation of Modern Mathematics

Zermelo-Fraenkel set theory with the Axiom of Choice (ZFC) is the standard foundation for virtually all of modern mathematics. The axioms are:

  1. Extensionality: Two sets are equal if and only if they have the same elements. \[ \forall A \, \forall B \, (\forall x \, (x \in A \leftrightarrow x \in B) \rightarrow A = B) \]
  2. Empty Set: There exists a set with no elements. \[ \exists \emptyset \, \forall x \, (x \notin \emptyset) \]
  3. Pairing: For any two sets, there exists a set containing exactly those two sets as elements.
  4. Union: For any set of sets, there exists a set containing all elements of the member sets.
  5. Power Set: For any set, there exists a set of all its subsets. \[ \forall A \, \exists P(A) \, \forall X \, (X \in P(A) \leftrightarrow X \subseteq A) \]
  6. Infinity: There exists an infinite set (specifically, a set containing the empty set and closed under the successor operation).
  7. Replacement: The image of a set under any definable function is a set.
  8. Foundation/Regularity: Every non-empty set contains an element disjoint from it (prevents infinite descending membership chains).
  9. Choice: For any collection of non-empty sets, there exists a choice function selecting one element from each set.

These nine axioms, first formulated in the early 20th century, provide a rigorous foundation that avoids the paradoxes (like Russell's paradox) that plagued naive set theory.

Ordinal Numbers: Counting Beyond the Finite

Ordinal numbers generalize the concept of "position in a sequence" to infinite sets. While cardinal numbers measure "how many," ordinals measure "which one."

The finite ordinals are just the natural numbers: \(0, 1, 2, 3, \ldots\). But after all finite ordinals comes the first infinite ordinal:

\[ \omega = \{0, 1, 2, 3, \ldots\} \]

This is the order type of the natural numbers. We can continue:

\[ \omega, \omega + 1, \omega + 2, \ldots, \omega \cdot 2, \ldots, \omega^2, \ldots, \omega^\omega, \ldots, \varepsilon_0, \ldots \]

Each ordinal \(\alpha\) has a successor \(\alpha + 1\). Ordinals that are not successors (except 0) are called limit ordinals—these include \(\omega, \omega \cdot 2, \omega^2\), etc.

Ordinals are crucial for transfinite induction, a proof technique that extends mathematical induction to well-ordered sets. If a property holds for 0, and is preserved under successors and limits, then it holds for all ordinals.

Cardinal Arithmetic: Measuring the Infinite

Cardinal numbers measure the size of sets. Two sets have the same cardinality if there exists a bijection between them.

Cantor's Theorem states that for any set \(A\), its power set \(P(A)\) has strictly greater cardinality:

\[ |A| < |P(A)| \]

This means there is no largest cardinal number—the hierarchy of infinities is endless.

For infinite cardinals, arithmetic behaves strangely:

  • \(\aleph_0 + \aleph_0 = \aleph_0\) (countable union of countable sets is countable)
  • \(\aleph_0 \cdot \aleph_0 = \aleph_0\)
  • \(2^{\aleph_0} = \mathfrak{c}\) (the cardinality of the continuum)

The Continuum Hypothesis (CH) asks whether there exists a cardinal strictly between \(\aleph_0\) and \(2^{\aleph_0}\). Gödel (1940) and Cohen (1963) proved that CH is independent of ZFC—it can neither be proved nor disproved from the standard axioms.

💹 Applied Math Deep-Dives: Financial Mathematics

The Black-Scholes Model

The Black-Scholes model, developed by Fischer Black, Myron Scholes, and Robert Merton in 1973, revolutionized the pricing of financial derivatives. It provides a theoretical estimate for the price of European-style options.

The model assumes:

  • The stock price follows geometric Brownian motion
  • No arbitrage opportunities exist
  • Constant risk-free interest rate \(r\)
  • Constant volatility \(\sigma\)
  • No dividends (in the basic model)

The Black-Scholes partial differential equation for a derivative \(V(S, t)\) is:

\[ \frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0 \]

For a European call option with strike price \(K\) and maturity \(T\), the solution is:

\[ C = S_0 N(d_1) - Ke^{-rT}N(d_2) \]

where:

\[ d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T} \]

and \(N(\cdot)\) is the cumulative distribution function of the standard normal distribution.

Option Pricing Theory

Options are financial contracts giving the holder the right (but not obligation) to buy (call) or sell (put) an asset at a predetermined price. Their pricing involves several key concepts:

Intrinsic value: For a call, \(\max(S - K, 0)\); for a put, \(\max(K - S, 0)\).

Time value: The additional value due to the possibility of favorable price movements before expiration.

The Greeks: Sensitivities of option prices to various parameters:

  • \(\Delta\) (Delta): \(\frac{\partial V}{\partial S}\) — sensitivity to underlying price
  • \(\Gamma\) (Gamma): \(\frac{\partial^2 V}{\partial S^2}\) — sensitivity of Delta
  • \(\Theta\) (Theta): \(\frac{\partial V}{\partial t}\) — time decay
  • \(\nu\) (Vega): \(\frac{\partial V}{\partial \sigma}\) — sensitivity to volatility
  • \(\rho\) (Rho): \(\frac{\partial V}{\partial r}\) — sensitivity to interest rates

These sensitivities allow traders to hedge their positions against various market movements.

Risk-Neutral Valuation

Risk-neutral valuation is a powerful technique that simplifies derivative pricing. The key insight: in a complete market with no arbitrage, there exists a unique probability measure (the risk-neutral measure \(\mathbb{Q}\)) under which all discounted asset prices are martingales.

This means we can price derivatives by:

  1. Calculating the expected payoff under \(\mathbb{Q}\)
  2. Discounting at the risk-free rate

The price of a European option with payoff \(H_T\) at time \(T\) is:

\[ V_0 = e^{-rT} \mathbb{E}^\mathbb{Q}[H_T] \]

Remarkably, this formula does not depend on the real-world drift of the underlying asset—only on the risk-free rate and volatility. This is because in the risk-neutral world, all assets are assumed to grow at the risk-free rate.

The transformation from the real-world measure \(\mathbb{P}\) to \(\mathbb{Q}\) is accomplished via the Girsanov theorem, which tells us how to change the drift of a Brownian motion while preserving its volatility structure.

🎨 Special Topics: Mathematical Art

Islamic Geometric Patterns

Islamic geometric art, flourishing from the 8th century onward, represents one of humanity's most sophisticated applications of mathematics to aesthetics. Forbidden from depicting living forms in religious contexts, Islamic artisans developed intricate geometric designs based on:

  • Constructible polygons: Regular polygons constructible with compass and straightedge (those with \(2^n \cdot p_1 \cdot p_2 \cdots p_k\) sides where \(p_i\) are distinct Fermat primes)
  • Symmetry groups: The 17 wallpaper groups, extensively used in tiling patterns
  • Radial symmetry: Star polygons like \(\{n/k\}\) (connect every \(k\)th vertex of an \(n\)-gon)

The famous girih tiles (five specific tile shapes) can generate complex quasiperiodic patterns that predate Western understanding of Penrose tilings by centuries. Recent research by Peter Lu and Paul Steinhardt revealed that medieval Islamic artisans had discovered quasi-crystalline patterns 500 years before their scientific discovery in the West.

Penrose Tilings

Discovered by Roger Penrose in 1974, Penrose tilings are non-periodic tilings of the plane using just two tile types (kites and darts, or rhombuses). Their remarkable properties include:

  • Aperiodicity: No translation symmetry—the pattern never repeats exactly
  • Self-similarity: The pattern contains copies of itself at different scales
  • Local isomorphism: Any finite patch appears infinitely often
  • Five-fold symmetry: Impossible in periodic crystals but present here

The tiling can be generated by inflation rules: each tile can be decomposed into smaller tiles of the same types. The ratio of areas follows the golden ratio \(\phi = \frac{1+\sqrt{5}}{2}\).

Penrose tilings have deep connections to:

  • Quasicrystals (discovered by Dan Shechtman, Nobel Prize 2011)
  • Projection from higher-dimensional lattices
  • The Fibonacci sequence and substitution systems

Voronoi Diagrams

Given a set of points (sites) in a plane, a Voronoi diagram partitions the plane into regions such that each region consists of all points closer to one particular site than to any other.

Formally, for sites \(P = \{p_1, p_2, \ldots, p_n\}\), the Voronoi cell \(V(p_i)\) is:

\[ V(p_i) = \{x \in \mathbb{R}^2 : d(x, p_i) \leq d(x, p_j) \text{ for all } j \neq i\} \]

The boundaries between cells are segments of perpendicular bisectors. Voronoi diagrams have applications in:

  • Computer graphics: Procedural texture generation, cell-based effects
  • Architecture: The "Voronoi sketch" aesthetic in modern design
  • Biology: Modeling cell structures, tissue growth patterns
  • Geography: Nearest-facility location problems
  • Art: Organic, cell-like patterns in generative art

Delaunay Triangulation

The Delaunay triangulation of a point set is the dual graph of its Voronoi diagram. It connects points whose Voronoi cells share an edge, creating a triangulation with a crucial property: no point lies inside the circumcircle of any triangle.

This "empty circumcircle" property maximizes the minimum angle in the triangulation, avoiding "skinny" triangles. The Delaunay triangulation:

  • Maximizes the minimum angle among all possible triangulations
  • Minimizes the maximum circumradius
  • Is unique (except when four or more points are cocircular)

The relationship between Voronoi diagrams and Delaunay triangulations creates beautiful dual structures: Voronoi vertices correspond to Delaunay triangles, Voronoi edges to Delaunay edges. This duality is fundamental in computational geometry and appears frequently in mathematical art.

📜 Math History: Georg Cantor and the Infinite

Georg Ferdinand Ludwig Philipp Cantor (1845–1918) was a German mathematician who created set theory, establishing the modern mathematical treatment of infinity. His work revolutionized mathematics, though it came at great personal cost.

Born in Saint Petersburg to a prosperous merchant family, Cantor moved to Germany at age eleven. He studied at the University of Berlin under luminaries including Karl Weierstrass and Leopold Kronecker. In 1869, he joined the faculty at the University of Halle, where he would spend his entire academic career.

Cantor's breakthrough came in the 1870s when he began investigating the uniqueness of trigonometric series representations. This led him to develop the theory of infinite sets. In 1874, he published his first revolutionary paper proving that the set of real numbers is uncountable—there are different sizes of infinity.

His diagonal argument, published in 1891, provided an elegant proof that the power set of any set has strictly greater cardinality. This established an endless hierarchy of infinities: \(\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}} < \cdots\).

Cantor introduced the concepts of cardinal and ordinal numbers for infinite sets. He defined \(\aleph_0\) as the cardinality of the natural numbers and developed the arithmetic of transfinite numbers. His continuum hypothesis—that there is no set whose cardinality is strictly between that of the integers and the real numbers—became one of the most famous problems in mathematics.

However, Cantor's work faced fierce opposition. Kronecker, his former teacher and one of the most powerful mathematicians in Germany, vehemently opposed Cantor's use of actual infinity, declaring that "God made the integers; all else is the work of man." This opposition blocked Cantor from obtaining a position at the more prestigious University of Berlin and contributed to his professional isolation.

The philosophical implications of Cantor's work were profound. He believed his mathematics revealed truths about God's infinite nature, corresponding with theologians about the religious significance of the actual infinite. He argued that the Absolute Infinite, which transcends all mathematical infinities, is identifiable with God.

Cantor suffered from depression and mental illness throughout his later life, with several nervous breakdowns. Modern scholars debate whether his illness was primarily biological or exacerbated by the hostile reception of his work. He died in 1918 at the Halle Nervenklinik, a sanatorium.

Today, Cantor is universally recognized as one of the greatest mathematicians in history. David Hilbert declared: "No one shall expel us from the paradise that Cantor has created for us." Set theory has become the foundation of modern mathematics, and his insights into infinity continue to inspire mathematicians, philosophers, and artists alike.

🧩 Problem Corner

Difficulty: AIME-level | Topic: Combinatorics / Set Theory

The Problem

Let \(S = \{1, 2, 3, \ldots, 12\}\). A subset \(A \subseteq S\) is called special if for any two elements \(x, y \in A\) with \(x < y\), the number \(y - x\) is not divisible by 3. Find the number of special subsets of \(S\).

💡 Hint

Partition \(S\) into residue classes modulo 3: \(S_0 = \{3, 6, 9, 12\}\), \(S_1 = \{1, 4, 7, 10\}\), \(S_2 = \{2, 5, 8, 11\}\). Note that if two elements are in the same residue class, their difference is divisible by 3. What does this tell you about how elements can be chosen from each class?

✅ Solution

Step 1: Partition \(S\) by residue mod 3:

  • \(S_0 = \{3, 6, 9, 12\}\) (4 elements)
  • \(S_1 = \{1, 4, 7, 10\}\) (4 elements)
  • \(S_2 = \{2, 5, 8, 11\}\) (4 elements)

Step 2: If \(x, y \in S_i\) for the same \(i\), then \(y - x \equiv 0 \pmod{3}\). So a special set can contain at most one element from each \(S_i\).

Step 3: What about elements from different residue classes? If \(x \in S_i\) and \(y \in S_j\) with \(i \neq j\), then \(y - x \not\equiv 0 \pmod{3}\). So any choice of at most one element from each \(S_i\) automatically satisfies the condition!

Step 4: For each \(S_i\), we can either choose no element or one of the 4 elements. So there are \(1 + 4 = 5\) choices for each \(S_i\).

Step 5: Total special subsets: \(5 \times 5 \times 5 = 125\).

But wait! This includes the empty set. The problem asks for "subsets" which typically includes the empty set. If we want non-empty special subsets: \(125 - 1 = 124\).

Answer: \(\boxed{125}\) (or 124 if excluding the empty set)

📊 Visualization of the Day: Penrose Tiling Generator

This Python code generates a Penrose tiling using the kite and dart substitution method, demonstrating the aperiodic structure and five-fold symmetry.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon
from matplotlib.collections import PatchCollection

# Golden ratio
PHI = (1 + np.sqrt(5)) / 2

def subdivide_kite(kite):
    """Subdivide a kite into smaller kites and darts."""
    A, B, C, D = kite  # A is the apex (36°), C is the concave vertex
    
    # Calculate subdivision points
    P = A + (B - A) / PHI
    Q = A + (D - A) / PHI
    
    # New kites and darts
    kite1 = [P, B, C, Q]  # New kite
    dart1 = [Q, C, D]     # New dart (triangle)
    dart2 = [P, Q, A]     # New dart (triangle)
    
    return [kite1], [dart1, dart2]

def subdivide_dart(dart):
    """Subdivide a dart into a kite and a dart."""
    A, B, C = dart  # B is the concave vertex (36° reentrant)
    
    # Calculate subdivision point
    P = B + (A - B) / PHI
    
    # New kite and dart
    kite1 = [P, C, B, P + (C - B)]  # Simplified
    dart1 = [A, P, B]
    
    return [kite1], [dart1]

# Alternative: Use the simpler rhombus approach
def penrose_rhombus(n_iterations=4):
    """
    Generate Penrose tiling using rhombus substitution.
    Returns vertices for plotting.
    """
    # Start with a regular decagon of thin rhombuses
    tiles = []
    
    # Generate initial wheel of 10 thin rhombuses
    for k in range(10):
        angle = k * np.pi / 5
        next_angle = (k + 1) * np.pi / 5
        
        # Thin rhombus vertices
        v0 = np.array([0, 0])
        v1 = np.array([np.cos(angle), np.sin(angle)])
        v2 = np.array([np.cos(angle) + np.cos(next_angle), 
                       np.sin(angle) + np.sin(next_angle)])
        v3 = np.array([np.cos(next_angle), np.sin(next_angle)])
        
        tiles.append(('thin', [v0, v1, v2, v3]))
    
    # Substitution rules
    for _ in range(n_iterations):
        new_tiles = []
        for tile_type, vertices in tiles:
            if tile_type == 'thin':
                # Subdivide thin rhombus
                A, B, C, D = vertices
                P = A + (C - A) / PHI
                new_tiles.append(('thin', [A, B, P, D]))
                new_tiles.append(('thin', [C, D, P, B]))
                new_tiles.append(('fat', [B, P, D]))
            else:
                # Subdivide fat rhombus (triangle representation)
                A, B, C = vertices
                P = B + (C - B) / PHI
                Q = B + (A - B) / PHI
                new_tiles.append(('fat', [A, Q, B]))
                new_tiles.append(('fat', [C, P, B]))
                new_tiles.append(('thin', [Q, B, P, (P+Q-B)]))
        tiles = new_tiles
    
    return tiles
