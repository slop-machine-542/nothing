Cohomology Operations: Steenrod Squares and Beyond

Motivation: Cohomology groups are powerful algebraic invariants of topological spaces, but they often fail to distinguish between spaces with different structures. Cohomology operations provide additional structure on cohomology groups, enabling finer classification of spaces. The Steenrod squares, introduced by Norman Steenrod in the 1940s, are the most important stable cohomology operations, with applications ranging from the Hopf invariant one problem to the study of characteristic classes.

Definitions

  • Cohomology Operation: A natural transformation between cohomology functors. For cohomology with coefficients in group \(G\), an operation of type \((n, m; G, H)\) is a natural transformation \(\theta: H^n(-; G) \to H^m(-; H)\).
  • Steenrod Squares: For each \(i \geq 0\), the Steenrod square \(\text{Sq}^i: H^n(X; \mathbb{Z}_2) \to H^{n+i}(X; \mathbb{Z}_2)\) is a stable cohomology operation satisfying specific axioms.
  • Steenrod Algebra: The algebra \(\mathcal{A}_2\) generated by \(\{\text{Sq}^i : i \geq 0\}\) modulo the Adem relations, acting on \(\mathbb{Z}_2\)-cohomology.
  • Cartan Formula: \(\text{Sq}^k(x \smile y) = \sum_{i+j=k} \text{Sq}^i(x) \smile \text{Sq}^j(y)\), expressing how Steenrod squares interact with the cup product.

Theorem: Adem Relations

Theorem: For \(a < 2b\), the Steenrod squares satisfy: \[\text{Sq}^a \text{Sq}^b = \sum_{j=0}^{\lfloor a/2 \rfloor} \binom{b-1-j}{a-2j} \text{Sq}^{a+b-j} \text{Sq}^j\]

Proof Sketch: The proof uses the method of acyclic models and the structure of the cohomology of product spaces. One constructs a chain map between the bar resolution and the cohomology of classifying spaces. The key insight is that the excess of a monomial \(\text{Sq}^I\) controls its behavior, and the Adem relations emerge from comparing different ways of representing the same operation. The binomial coefficients appear naturally from the combinatorics of symmetric groups acting on cohomology.

Notation Guide

  • \(\text{Sq}^i\): Steenrod square of degree \(i\)
  • \(\mathcal{A}_2\): Mod 2 Steenrod algebra
  • \(\smile\): Cup product in cohomology
  • \(H^*(X; R)\): Cohomology ring with coefficients in \(R\)
  • \(\deg(x)\): Degree of cohomology class \(x\)

import numpy as np
from itertools import combinations
from math import comb

class SteenrodAlgebra:
    """
    Implementation of mod 2 Steenrod algebra operations.
    """
    def __init__(self, max_degree=20):
        self.max_degree = max_degree
        self.adem_relations = self._compute_adem_relations()
    
    def _compute_adem_relations(self):
        """Precompute Adem relations for efficiency."""
        relations = {}
        for a in range(self.max_degree):
            for b in range(self.max_degree):
                if a < 2 * b:
                    # Compute the right-hand side of Adem relation
                    rhs = []
                    for j in range(a // 2 + 1):
                        coeff = comb(b - 1 - j, a - 2 * j) % 2
                        if coeff == 1:
                            rhs.append((a + b - j, j))
                    relations[(a, b)] = rhs
        return relations
    
    def adem_reduce(self, monomial):
        """
        Reduce a monomial Sq^a Sq^b to admissible form using Adem relations.
        Returns list of (coefficient, (i, j)) pairs.
        """
        if len(monomial) <= 1:
            return [(1, monomial)]
        
        # Check if already admissible (each term >= 2 * next term)
        is_admissible = all(monomial[i] >= 2 * monomial[i+1] 
                           for i in range(len(monomial) - 1))
        
        if is_admissible:
            return [(1, tuple(monomial))]
        
        # Find first inadmissible pair
        for idx in range(len(monomial) - 1):
            a, b = monomial[idx], monomial[idx + 1]
            if a < 2 * b:
                # Apply Adem relation
                result = []
                rhs = self.adem_relations.get((a, b), [])
                for (new_a, new_b) in rhs:
                    new_monomial = list(monomial[:idx]) + [new_a, new_b] + list(monomial[idx+2:])
                    result.extend(self.adem_reduce(new_monomial))
                return result
        
        return [(1, tuple(monomial))]
    
    def sq(self, i, x_deg):
        """
        Compute Sq^i acting on a class of degree x_deg.
        Returns the degree of the result: x_deg + i.
        """
        return x_deg + i
    
    def cartan_formula(self, sq_i, deg_x, deg_y):
        """
        Apply Cartan formula: Sq^k(x ∪ y) = Σ Sq^i(x) ∪ Sq^j(y)
        Returns list of (i, j) pairs.
        """
        return [(j, sq_i - j) for j in range(sq_i + 1)]
    
    def wu_formula(self, n):
        """
        Compute Wu class formula for Stiefel-Whitney classes.
        Sq^k(w_m) = Σ_{i=0}^k (m-k+i-1 choose i) w_{k-i} w_{m+i}
        """
        formula = []
        for k in range(n + 1):
            for i in range(k + 1):
                coeff = comb(n - k + i - 1, i) % 2
                if coeff == 1:
                    formula.append((k, i, n - k + i))
        return formula

Ricci Flow: Geometrization Through Heat Diffusion

Motivation: In 1982, Richard Hamilton introduced the Ricci flow as a means to prove the Poincaré conjecture. The idea is elegant: evolve a Riemannian metric by a heat-type equation that spreads curvature uniformly across the manifold, similar to how heat diffusion smooths out temperature differences. This program was spectacularly completed by Grigori Perelman in 2002-2003, who resolved the Poincaré and Thurston geometrization conjectures using Ricci flow with surgery.

Definitions

  • Ricci Flow: A family of Riemannian metrics \(g(t)\) satisfying \(\frac{\partial g}{\partial t} = -2\text{Ric}(g)\), where \(\text{Ric}(g)\) is the Ricci curvature tensor.
  • Ricci Curvature: A symmetric 2-tensor \(\text{Ric}_{ij} = R^k_{ikj}\) measuring the deviation of volumes in the manifold from Euclidean space.
  • Scalar Curvature: \(R = g^{ij}\text{Ric}_{ij}\), the trace of the Ricci tensor, measuring the total curvature at a point.
  • Normalized Ricci Flow: \(\frac{\partial g}{\partial t} = -2\text{Ric} + \frac{2}{n}rg\), where \(r\) is the average scalar curvature, preserving volume.

Theorem: Hamilton's Convergence Theorem

Theorem: Let \((M^3, g_0)\) be a compact 3-manifold with positive Ricci curvature. Then the normalized Ricci flow exists for all time and converges exponentially to a metric of constant positive sectional curvature. Consequently, \(M^3\) is diffeomorphic to a spherical space form \(S^3/\Gamma\).

Proof Sketch: The proof establishes a priori estimates using maximum principles for curvature quantities. Key steps: (1) Show that positive Ricci curvature is preserved under the flow using the evolution equation for \(\text{Ric}\). (2) Prove that the curvature pinching improves: the ratio of maximum to minimum eigenvalues of \(\text{Ric}\) approaches 1. (3) Establish decay estimates showing that the trace-free Ricci tensor tends to zero. (4) Use compactness theorems to extract a convergent subsequence. (5) Show the limit has constant curvature by analyzing the monotonicity of the Einstein-Hilbert functional.

Notation Guide

  • \(g_{ij}\): Riemannian metric tensor
  • \(\text{Ric}_{ij}\): Ricci curvature tensor
  • \(R_{ijkl}\): Riemann curvature tensor
  • \(R\): Scalar curvature
  • \(\nabla_i\): Covariant derivative
  • \(\Delta_g\): Laplace-Beltrami operator

import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

class RicciFlow2D:
    """
    Numerical simulation of Ricci flow on 2D surfaces.
    For surfaces, Ricci flow reduces to: ∂g/∂t = -R·g = r·g - R·g
    where the metric conformally evolves.
    """
    def __init__(self, metric_func, x_range=(-np.pi, np.pi), 
                 y_range=(-np.pi, np.pi), nx=100, ny=100):
        """
        Initialize with initial metric function g(x,y).
        """
        self.nx, self.ny = nx, ny
        self.x = np.linspace(x_range[0], x_range[1], nx)
        self.y = np.linspace(y_range[0], y_range[1], ny)
        self.dx = self.x[1] - self.x[0]
        self.dy = self.y[1] - self.y[0]
        
        self.X, self.Y = np.meshgrid(self.x, self.y)
        self.g = metric_func(self.X, self.Y)
        self.g_history = [self.g.copy()]
        
    def compute_curvature_2d(self):
        """
        Compute Gaussian curvature for conformal metric g(x,y)·(dx² + dy²).
        K = -Δ(log(g))/(2g) where Δ is the Laplacian.
        """
        log_g = np.log(self.g + 1e-10)  # Avoid log(0)
        
        # Compute Laplacian using finite differences
        laplacian = np.zeros_like(self.g)
        laplacian[1:-1, 1:-1] = (
            (log_g[2:, 1:-1] - 2*log_g[1:-1, 1:-1] + log_g[:-2, 1:-1]) / self.dx**2 +
            (log_g[1:-1, 2:] - 2*log_g[1:-1, 1:-1] + log_g[1:-1, :-2]) / self.dy**2
        )
        
        # Gaussian curvature
        K = -laplacian / (2 * self.g)
        return K
    
    def step(self, dt):
        """
        Perform one step of Ricci flow: ∂g/∂t = -2K·g (2D case).
        """
        K = self.compute_curvature_2d()
        # Update metric
        self.g = self.g - 2 * dt * K * self.g
        # Ensure positivity
        self.g = np.maximum(self.g, 1e-6)
        self.g_history.append(self.g.copy())
    
    def evolve(self, T, num_steps):
        """
        Evolve for time T with num_steps steps.
        """
        dt = T / num_steps
        for _ in range(num_steps):
            self.step(dt)
    
    def get_total_curvature(self):
        """Compute total curvature ∫ K dA."""
        K = self.compute_curvature_2d()
        dA = self.g * self.dx * self.dy
        return np.sum(K * dA)
    
    def plot_evolution(self, num_frames=5):
        """Visualize the metric evolution."""
        indices = np.linspace(0, len(self.g_history)-1, num_frames, dtype=int)
        
        fig, axes = plt.subplots(1, num_frames, figsize=(4*num_frames, 4))
        if num_frames == 1:
            axes = [axes]
        
        for idx, ax in zip(indices, axes):
            g = self.g_history[idx]
            im = ax.imshow(g, extent=[self.x[0], self.x[-1], self.y[0], self.y[-1]],
                          origin='lower', cmap='viridis')
            ax.set_title(f"t = {idx}")
            ax.set_xlabel('x')
            ax.set_ylabel('y')
            plt.colorbar(im, ax=ax, label='g(x,y)')
        
        plt.tight_layout()
        plt.savefig('ricci_flow_evolution.png', dpi=150)
        plt.show()

Algebraic Statistics: Geometry of Statistical Models

Motivation: Many statistical models are defined by polynomial constraints on probability distributions. Algebraic statistics, a field that emerged in the late 1990s, uses tools from computational algebra and algebraic geometry to study these models. This approach reveals the geometric structure underlying maximum likelihood estimation, hypothesis testing, and model selection, providing both theoretical insights and practical computational methods.

Definitions

  • Algebraic Statistical Model: A family of probability distributions where the probability simplex is intersected with an algebraic variety. For discrete random variables, the model is often defined by polynomial equations in the probabilities.
  • Parametric Model: A model of the form \(\mathcal{M} = \{p(\theta) : \theta \in \Theta\}\) where \(p_i(\theta)\) are rational functions or polynomials in parameters \(\theta\).
  • Implicit Model: A model defined as \(\mathcal{M} = V(I) \cap \Delta_{n-1}\) where \(V(I)\) is an algebraic variety and \(\Delta_{n-1}\) is the probability simplex.
  • Maximum Likelihood Degree: The number of complex critical points of the likelihood function for generic data, a measure of model complexity.

Theorem: Birch's Theorem for Log-Linear Models

Theorem: Let \(\mathcal{M}\) be a log-linear model for a contingency table with sufficient statistics matrix \(A\). For observed data \(u\) with positive entries, the maximum likelihood estimate \(\hat{p}\) exists and is unique. It is characterized by: (1) \(\hat{p} \in \mathcal{M}\), and (2) \(A\hat{p} = Au/n\) where \(n = \sum_i u_i\).

Proof Sketch: The likelihood function for a multinomial model is \(L(p) = \prod_i p_i^{u_i}\). Taking logs and using Lagrange multipliers for the constraints, we obtain the likelihood equations. For log-linear models, the constraints have the form \(\log p \in \text{rowspace}(A)\). The key observation is that the likelihood function is strictly concave on the positive orthant intersected with the linear subspace defined by the model. By convex optimization theory, a unique maximizer exists. The condition \(A\hat{p} = Au/n\) expresses that the fitted margins equal the observed margins.

Notation Guide

  • \(\Delta_{n-1}\): Probability simplex \(\{p \in \mathbb{R}^n : p_i \geq 0, \sum p_i = 1\}\)
  • \(V(I)\): Algebraic variety defined by ideal \(I\)
  • \(A\): Design or sufficient statistics matrix
  • \(\hat{p}\): Maximum likelihood estimate
  • \(\mathcal{M}\): Statistical model

import numpy as np
from scipy.optimize import minimize
import sympy as sp
from sympy import symbols, exp, log, solve, Matrix

class AlgebraicStatistics:
    """
    Tools for algebraic statistical models.
    """
    def __init__(self, sufficient_stats):
        """
        Initialize with sufficient statistics matrix A.
        Rows are statistics, columns are states.
        """
        self.A = np.array(sufficient_stats)
        self.k, self.n = self.A.shape  # k statistics, n states
    
    def log_linear_model(self, theta, normalize=True):
        """
        Compute probability distribution for log-linear model.
        p_i ∝ exp(∑_j θ_j A_ji)
        """
        log_p = self.A.T @ np.array(theta)
        p = np.exp(log_p - np.max(log_p))  # Numerical stability
        if normalize:
            p = p / np.sum(p)
        return p
    
    def birch_mle(self, observed_counts, tol=1e-8, max_iter=1000):
        """
        Compute MLE using iterative proportional fitting (Birch's theorem).
        For log-linear models, finds p such that A·p = A·u/n.
        """
        u = np.array(observed_counts, dtype=float)
        n = np.sum(u)
        target_margins = self.A @ u / n
        
        # Initialize with uniform distribution
        p = np.ones(self.n) / self.n
        
        for iteration in range(max_iter):
            p_old = p.copy()
            
            # Iterative proportional fitting
            for j in range(self.k):
                current_margin = np.sum(self.A[j] * p)
                if current_margin > 0:
                    factor = target_margins[j] / current_margin
                    # Update probabilities proportional to A[j]
                    mask = self.A[j] > 0
                    p[mask] *= factor ** (self.A[j][mask] / np.sum(self.A[j][mask]))
                p = p / np.sum(p)  # Renormalize
            
            if np.max(np.abs(p - p_old)) < tol:
                break
        
        return p
    
    def likelihood(self, p, observed_counts):
        """Compute log-likelihood."""
        u = np.array(observed_counts)
        # Multinomial log-likelihood (ignoring constant)
        return np.sum(u * np.log(p + 1e-10))
    
    def independence_model_mle(self, contingency_table):
        """
        MLE for independence model in 2-way contingency table.
        For table n_{ij}, MLE is n_{i+}·n_{+j}/n_{++}
        """
        table = np.array(contingency_table)
        row_sums = np.sum(table, axis=1, keepdims=True)
        col_sums = np.sum(table, axis=0, keepdims=True)
        total = np.sum(table)
        
        expected = (row_sums @ col_sums) / total
        return expected
    
    def chi_square_test(self, observed, expected):
        """Pearson chi-square statistic."""
        return np.sum((observed - expected)**2 / (expected + 1e-10))
    
    def symbolic_likelihood_equations(self):
        """
        Set up symbolic likelihood equations for the model.
        Returns sympy equations.
        """
        # Define symbolic variables
        p = symbols('p0:%d' % self.n)
        u = symbols('u0:%d' % self.n)
        lam = symbols('lambda')
        
        # Lagrangian: L = Σ u_i log(p_i) - λ(Σ p_i - 1)
        log_likelihood = sum(u[i] * log(p[i]) for i in range(self.n))
        constraint = sum(p[i] for i in range(self.n)) - 1
        lagrangian = log_likelihood - lam * constraint
        
        # Derivatives
        equations = [sp.diff(lagrangian, p[i]) for i in range(self.n)]
        equations.append(sp.diff(lagrangian, lam))
        
        return equations, p, u, lam

Neural ODEs: Continuous-Depth Neural Networks

Motivation: Traditional neural networks have discrete layers, but what if we viewed them as continuous dynamical systems? Neural Ordinary Differential Equations (Neural ODEs), introduced by Chen et al. in 2018, parameterize the derivative of hidden states using a neural network. This perspective offers memory efficiency, adaptive computation, and a natural framework for continuous-time models, with applications in time series analysis, generative modeling, and physics-informed machine learning.

Definitions

  • Neural ODE: A model defined by \(\frac{dh(t)}{dt} = f(h(t), t, \theta)\) where \(f\) is a neural network with parameters \(\theta\), transforming initial state \(h(0)\) to output \(h(T)\).
  • ODE Solver: Numerical method (Euler, Runge-Kutta, adaptive schemes) for computing \(h(T) = h(0) + \int_0^T f(h(t), t, \theta) dt\).
  • Adjoint State: For backpropagation, the adjoint \(a(t) = \frac{\partial L}{\partial h(t)}\) satisfies its own ODE, enabling constant-memory training.
  • Continuous Normalizing Flow: A generative model using Neural ODEs where the change of variables formula involves the trace of the Jacobian rather than its determinant.

Theorem: Adjoint Sensitivity Method

Theorem: Let \(h(t)\) evolve according to \(\frac{dh}{dt} = f(h, t, \theta)\) with initial condition \(h(t_0) = h_0\). For a loss \(L(h(t_1))\), the gradient with respect to parameters can be computed by solving the adjoint ODE backward in time: \[\frac{da(t)}{dt} = -a(t)^T \frac{\partial f}{\partial h}, \quad a(t_1) = \frac{\partial L}{\partial h(t_1)}\] \[\frac{d}{dt}\left(\frac{\partial L}{\partial \theta}\right) = -a(t)^T \frac{\partial f}{\partial \theta}\]

Proof Sketch: Consider the augmented system \([h, \theta, t]\) with dynamics \([f, 0, 1]\). The adjoint of this system gives the sensitivity of the loss to perturbations. Using the chain rule and the fact that \(\frac{d}{dt}\frac{\partial L}{\partial h} = \frac{\partial L}{\partial h} \frac{\partial f}{\partial h}\) (from differentiating under the integral), we obtain the backward ODE. The key insight is that we only need to store the state at checkpoints, not all intermediate activations, reducing memory from \(O(L)\) to \(O(1)\) for \(L\) layers.

Notation Guide

  • \(h(t)\): Hidden state at time \(t\)
  • \(f_\theta\): Neural network defining the dynamics
  • \(a(t)\): Adjoint state (gradient of loss w.r.t. state)
  • \(\text{ODESolve}\): Black-box ODE solver
  • \(\nabla_\theta L\): Gradient of loss w.r.t. parameters

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint, solve_ivp
from scipy.optimize import minimize

class NeuralODE:
    """
    Neural Ordinary Differential Equation implementation.
    Uses simple neural network as dynamics function.
    """
    def __init__(self, input_dim, hidden_dim=20):
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        
        # Initialize network parameters
        # f(h, t) = W2 * tanh(W1 * h + b1) + b2
        self.W1 = np.random.randn(hidden_dim, input_dim) * 0.1
        self.b1 = np.zeros(hidden_dim)
        self.W2 = np.random.randn(input_dim, hidden_dim) * 0.1
        self.b2 = np.zeros(input_dim)
    
    def dynamics(self, h, t, params=None):
        """
        Compute dh/dt = f(h, t, θ).
        Simple MLP with tanh activation.
        """
        if params is not None:
            self.set_params(params)
        
        # Add time as additional input
        h_with_t = np.append(h, t)
        
        # Forward pass
        z = np.tanh(self.W1 @ h + self.b1)
        dhdt = self.W2 @ z + self.b2
        return dhdt
    
    def forward(self, h0, t_span, t_eval=None):
        """
        Integrate from h0 over t_span.
        Returns solution at t_eval points.
        """
        if t_eval is None:
            t_eval = np.linspace(t_span[0], t_span[1], 100)
        
        sol = solve_ivp(
            fun=lambda t, h: self.dynamics(h, t),
            t_span=t_span,
            y0=h0,
            t_eval=t_eval,
            method='RK45'
        )
        return sol.t, sol.y
    
    def get_params(self):
        """Flatten all parameters."""
        return np.concatenate([
            self.W1.flatten(),
            self.b1.flatten(),
            self.W2.flatten(),
            self.b2.flatten()
        ])

        idx += self.b1.size
        self.W2 = params[idx:idx+self.W2.size].reshape(self.W2.shape)
        idx += self.W2.size
        self.b2 = params[idx:idx+self.b2.size]

        """
        Compute MSE loss for trajectory prediction.
        X: initial states, shape (n_samples, input_dim)
        Y: target final states, shape (n_samples, input_dim)
        """
        self.set_params(params)
        total_loss = 0

            y_pred = trajectory[:, -1]
            total_loss += np.sum((y_pred - y)**2)

    def fit(self, X, Y, t_span, epochs=100, lr=0.01):
        """Train using gradient descent."""

                grad[i] = (self.loss(params_plus, X, Y, t_span) - loss) / eps
            
            params = params - lr * grad
        
        self.set_params(params)

Queueing Theory: Managing Random Arrivals and Services

Motivation: From call centers to computer networks, manufacturing systems to hospital emergency rooms, queueing theory provides the mathematical framework for analyzing systems with random arrivals and service times. Developed by A.K. Erlang in the early 1900s to design telephone networks, queueing theory now underpins modern telecommunications, operations research, and computer science, helping optimize resource allocation and minimize waiting times.

Definitions

  • Kendall's Notation: A/S/c/K/N/D describes arrival process, service distribution, number of servers, system capacity, population size, and queue discipline (e.g., M/M/1 for Markov arrivals, Markov service, 1 server).
  • Traffic Intensity: \(\rho = \lambda / (c\mu)\) where \(\lambda\) is arrival rate, \(\mu\) is service rate, and \(c\) is number of servers. Stability requires \(\rho < 1\).
  • Little's Law: \(L = \lambda W\) where \(L\) is average number in system, \(\lambda\) is arrival rate, and \(W\) is average time in system.
  • Steady-State Distribution: \(\pi_n = \lim_{t \to \infty} P(N(t) = n)\), the long-run probability of having \(n\) customers in the system.

Theorem: M/M/1 Queue Steady-State

Theorem: For an M/M/1 queue with arrival rate \(\lambda\) and service rate \(\mu\) where \(\rho = \lambda/\mu < 1\), the steady-state distribution is geometric: \[\pi_n = (1-\rho)\rho^n, \quad n = 0, 1, 2, \ldots\] The expected number in system is \(L = \frac{\rho}{1-\rho}\) and expected waiting time is \(W = \frac{1}{\mu - \lambda}\).

Proof Sketch: The queue length process is a birth-death process with birth rates \(\lambda_n = \lambda\) and death rates \(\mu_n = \mu\) for \(n \geq 1\). The detailed balance equations give \(\pi_n \lambda = \pi_{n+1} \mu\), so \(\pi_{n+1} = \rho \pi_n\). By induction, \(\pi_n = \pi_0 \rho^n\). Normalization requires \(\sum_{n=0}^\infty \pi_n = 1\), giving \(\pi_0 = 1-\rho\). The mean \(L = \sum n\pi_n = \rho/(1-\rho)\) follows from the geometric series formula. Little's Law then gives \(W = L/\lambda = 1/(\mu-\lambda)\).

Notation Guide

  • \(\lambda\): Arrival rate (customers per unit time)
  • \(\mu\): Service rate (customers per unit time per server)
  • \(\rho\): Traffic intensity/utilization
  • \(L\): Average number of customers in system
  • \(L_q\): Average number waiting in queue
  • \(W\): Average time in system
  • \(W_q\): Average waiting time in queue

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import expon, poisson
from scipy.special import factorial

class QueueingSystem:
    """
    Analysis of various queueing systems.
    """
    def __init__(self, arrival_rate, service_rate, num_servers=1, capacity=None):
        self.lambda_ = arrival_rate
        self.mu = service_rate
        self.c = num_servers
        self.capacity = capacity
        self.rho = arrival_rate / (num_servers * service_rate)
    
    def mm1_steady_state(self, max_n=50):
        """
        Compute steady-state probabilities for M/M/1 queue.
        π_n = (1-ρ)ρ^n
        """
        if self.rho >= 1:
            raise ValueError("System unstable: ρ >= 1")
        
        n = np.arange(max_n + 1)
        pi = (1 - self.rho) * (self.rho ** n)
        return n, pi
    
    def mm1_metrics(self):
        """Performance metrics for M/M/1 queue."""
        if self.rho >= 1:
            return None
        
        L = self.rho / (1 - self.rho)  # Average in system
        Lq = self.rho**2 / (1 - self.rho)  # Average in queue
        W = 1 / (self.mu - self.lambda_)  # Time in system
        Wq = self.lambda_ / (self.mu * (self.mu - self.lambda_))  # Wait time
        
        return {
            'L': L,
            'Lq': Lq,
            'W': W,
            'Wq': Wq,
            'rho': self.rho,
            'P0': 1 - self.rho  # Probability system is empty
        }
    
    def mmc_metrics(self):
        """Performance metrics for M/M/c queue."""
        rho = self.rho
        c = self.c
        
        if rho >= 1:
            return None
        
        # Compute P0 (probability of 0 customers)
        sum_term = sum((c * rho)**n / factorial(n) for n in range(c))
        last_term = (c * rho)**c / (factorial(c) * (1 - rho))
        P0 = 1 / (sum_term + last_term)
        
        # Probability of waiting (Erlang C formula)
        numerator = (c * rho)**c / factorial(c) * P0 / (1 - rho)
        
        Lq = numerator * rho / (1 - rho)
        Wq = Lq / self.lambda_
        W = Wq + 1 / self.mu
        L = self.lambda_ * W
        
        return {
            'L': L,
            'Lq': Lq,
            'W': W,
            'Wq': Wq,
            'rho': rho,
            'P0': P0,
            'Pw': numerator  # Probability of waiting
        }
    
    def simulate(self, T=1000, seed=None):
        """
        Discrete event simulation of the queue.
        Returns sample paths of queue length.
        """
        if seed:
            np.random.seed(seed)
        
        # Initialize
        t = 0
        queue_length = 0
        next_arrival = expon(scale=1/self.lambda_).rvs()
        next_departure = float('inf')
        
        times = [t]
        lengths = [queue_length]
        
        while t < T:
            if next_arrival <= next_departure:
                # Arrival event
                t = next_arrival
                queue_length += 1
                next_arrival = t + expon(scale=1/self.lambda_).rvs()
                
                if queue_length == 1:
                    next_departure = t + expon(scale=1/self.mu).rvs()
            else:
                # Departure event
                t = next_departure
                queue_length -= 1
                
                if queue_length > 0:
                    next_departure = t + expon(scale=1/self.mu).rvs()
                else:
                    next_departure = float('inf')
            
            times.append(t)
            lengths.append(queue_length)
        
        return np.array(times), np.array(lengths)
    
    def erlang_b(self, c, A):
        """
        Erlang B formula for loss systems (M/M/c/c).
        Probability that all servers are busy.
        """
        numerator = (A**c / factorial(c))
        denominator = sum(A**k / factorial(k) for k in range(c + 1))
        return numerator / denominator
    
    def erlang_c(self, c, A):
        """
        Erlang C formula for delay systems (M/M/c).
        Probability that an arriving customer must wait.
        """
        rho = A / c
        if rho >= 1:
            return 1.0
        
        numerator = (A**c / factorial(c)) * (1 / (1 - rho))
        denominator = sum(A**k / factorial(k) for k in range(c)) + numerator
        return numerator / denominator

Tensor Networks: Efficient Representations of High-Dimensional Data

Motivation: Many problems in physics, machine learning, and data science involve exponentially large state spaces. A quantum system of \(n\) spins requires \(2^n\) complex numbers to describe fully, making naive representations intractable. Tensor networks provide compact, structured approximations that capture the essential correlations while remaining computationally manageable. Originally developed in quantum many-body physics, they now power state-of-the-art methods in quantum computing, machine learning, and numerical analysis.

Definitions

  • Tensor: A multi-dimensional array \(T_{i_1 i_2 \ldots i_n}\) where each index ranges over some dimension. A matrix is a rank-2 tensor, a vector is rank-1.
  • Tensor Contraction: Summing over a shared index between two tensors, generalizing matrix multiplication. If \(A_{ijk}\) and \(B_{klm}\) share index \(k\), their contraction is \(C_{ijlm} = \sum_k A_{ijk} B_{klm}\).
  • Matrix Product State (MPS): A 1D tensor network where each tensor has one physical index and two bond indices connecting to neighbors: \(|\psi\rangle = \sum_{\{i\}} A^{i_1}_{1} A^{i_2}_{2} \cdots A^{i_n}_{n} |i_1 i_2 \ldots i_n\rangle\).
  • Tensor Train Decomposition: A factorization of a high-dimensional tensor into a chain of 3-way tensors with bounded rank, reducing storage from \(d^n\) to \(ndr^2\).

Theorem: Tensor Train Approximation

Theorem: Any tensor \(T \in \mathbb{R}^{d_1 \times d_2 \times \cdots \times d_n}\) admits an exact tensor train decomposition with ranks \(r_k \leq \min(\prod_{i=1}^k d_i, \prod_{i=k+1}^n d_i)\). For a function with smoothness properties, the TT-ranks often grow only polynomially with dimension rather than exponentially.

Proof Sketch: The proof proceeds by successive SVD decompositions. At step \(k\), reshape the remaining tensor into a matrix of size \((r_{k-1} d_k) \times (d_{k+1} \cdots d_n)\) and compute its SVD. The rank of this matrix becomes \(r_k\). The key observation is that the singular values decay rapidly for many practical tensors, allowing low-rank approximations. The storage complexity is \(\sum_{k=1}^n r_{k-1} d_k r_k\) where \(r_0 = r_n = 1\), which for uniform ranks \(r\) and dimensions \(d\) gives \(O(ndr^2)\).

Notation Guide

  • \(T_{i_1 \ldots i_n}\): Tensor with indices \(i_1, \ldots, i_n\)
  • \(\chi\) or \(r\): Bond dimension (rank)
  • \(d\): Physical dimension (size of each index)
  • \(n\): Number of tensors (sites)
  • \(\bullet\): Tensor contraction over shared index
  • \(G_k\): Core tensor at position \(k\) in TT format

Python Implementation

import numpy as np
from scipy.linalg import svd
import matplotlib.pyplot as plt

class TensorTrain:
    """
    Tensor Train (TT) decomposition for efficient high-dimensional representation.
    """
    def __init__(self, cores=None):
        """
        Initialize with list of core tensors.
        Each core G_k has shape (r_{k-1}, d_k, r_k)
        """
        self.cores = cores if cores is not None else []
        self.n = len(self.cores) if cores else 0
    
    @staticmethod
    def from_tensor(tensor, max_rank=None, tolerance=1e-10):
        """
        Convert full tensor to TT format using successive SVD.
        
        Args:
            tensor: numpy array of shape (d1, d2, ..., dn)
            max_rank: maximum allowed rank
            tolerance: truncation threshold for singular values
        """
        dims = tensor.shape
        n = len(dims)
        cores = []
        
        # Reshape and perform successive SVD
        C = tensor.copy()
        r_prev = 1
        
        for k in range(n - 1):
            # Reshape: (r_prev * d_k) x (d_{k+1} * ... * d_n)
            d_k = dims[k]
            C = C.reshape(r_prev * d_k, -1)
            
            # SVD
            U, S, Vt = svd(C, full_matrices=False)
            
            # Truncate
            if max_rank is not None:
                r_k = min(len(S), max_rank)
            else:
                r_k = np.sum(S > tolerance * S[0])
            
            U = U[:, :r_k]
            S = S[:r_k]
            Vt = Vt[:r_k, :]
            
            # Store core: (r_prev, d_k, r_k)
            core = U.reshape(r_prev, d_k, r_k)
            cores.append(core)
            
            # Update for next iteration
            C = np.diag(S) @ Vt
            r_prev = r_k
        
        # Last core: (r_{n-1}, d_n, 1)
        C = C.reshape(r_prev, dims[-1], 1)
        cores.append(C)
        
        return TensorTrain(cores)
    
    def to_tensor(self):
        """Reconstruct full tensor from TT format."""
        result = self.cores[0]
        
        for core in self.cores[1:]:
            # Contract: result_{...,i} * core_{i,j,...}
            result = np.tensordot(result, core, axes=([-1], [0]))
        
        # Remove the trailing dimension of size 1
        return result.squeeze()
    
    def evaluate(self, indices):
        """
        Evaluate tensor at specific indices.
        indices: list of length n with each index in range(d_k)
        """
        result = self.cores[0][0, indices[0], :]  # Shape: (r_1,)
        
        for k in range(1, self.n):
            # Multiply by core at position k
            result = result @ self.cores[k][:, indices[k], :]
        
        return result.item()
    
    def storage(self):
        """Compute total number of elements stored."""
        return sum(core.size for core in self.cores)
    
    def compression_ratio(self, full_shape):
        """Compute compression ratio vs full tensor."""
        full_size = np.prod(full_shape)
        return self.storage() / full_size
    
    def ranks(self):
        """Return TT-ranks [r_0, r_1, ..., r_n]."""
        rs = [1]  # r_0 = 1
        for core in self.cores:
            rs.append(core.shape[-1])
        return rs
    
    def tt_round(self, max_rank=None, tolerance=1e-10):
        """
        Round (compress) TT representation.
        Uses left-to-right and right-to-left orthogonalization.
        """
        # This is a simplified version
        cores_new = [c.copy() for c in self.cores]
        
        # Left-to-right orthogonalization
        for k in range(self.n - 1):
            r1, d, r2 = cores_new[k].shape
            Q, R = np.linalg.qr(cores_new[k].reshape(r1 * d, r2))
            r_new = Q.shape[1]
            cores_new[k] = Q.reshape(r1, d, r_new)
            cores_new[k + 1] = np.tensordot(R, cores_new[k + 1], axes=([1], [0]))
        
        return TensorTrain(cores_new)

Sieve Methods: Finding Primes Through Elimination

Motivation: How can we count primes in intervals or find patterns in their distribution? Sieve methods, dating back to Eratosthenes, provide powerful tools for studying prime numbers by systematically eliminating composites. Modern sieve theory, developed by Brun, Selberg, and others, has led to breakthroughs like Chen's theorem (every sufficiently large even number is the sum of a prime and a product of at most two primes) and results on bounded gaps between primes.

Definitions

  • Sieve of Eratosthenes: Algorithm to find all primes up to \(n\) by iteratively marking multiples of each prime starting from 2.
  • Sifting Function: \(S(A, P, z) = \{a \in A : \gcd(a, P(z)) = 1\}\) where \(P(z)\) is the product of primes less than \(z\).
  • Brun's Sieve: A combinatorial sieve using inclusion-exclusion with truncation, providing upper and lower bounds for sifted sets.
  • Selberg Sieve: An upper bound sieve using quadratic forms to optimize weights, often giving better results than Brun's sieve.

Theorem: Brun's Upper Bound

Theorem: Let \(A\) be a finite set of integers and \(P\) a set of primes. For \(z > 0\), the number of elements of \(A\) not divisible by any prime in \(P\) less than \(z\) satisfies: \[S(A, P, z) \leq \frac{|A|}{G(z)} + O\left(\sum_{d_1, d_2 < z} |R_{[d_1, d_2]}|\right)\] where \(G(z) = \sum_{d < z, d \mid P(z)} \frac{\mu^2(d)}{\phi(d)}\) and \(R_d\) are remainder terms.

Proof Sketch: The proof uses a weighted sieve function with carefully chosen weights \(\lambda_d\) satisfying \(\lambda_1 = 1\). By Cauchy-Schwarz: \[S(A, P, z) \leq \sum_{a \in A} \left(\sum_{d \mid (a, P(z))} \lambda_d\right)^2\] Expanding and optimizing the quadratic form in \(\lambda_d\) leads to the Selberg weights. The main term comes from diagonal contributions, while error terms are controlled by the remainder estimates. For Brun's sieve, one truncates the inclusion-exclusion at an even or odd level to obtain bounds.

Notation Guide

  • \(P(z)\): Product of primes less than \(z\)
  • \(\mu(d)\): Möbius function
  • \(\phi(d)\): Euler's totient function
  • \(S(A, P, z)\): Sifting function (count of elements coprime to \(P(z)\))
  • \(\lambda_d\): Sieve weights

import numpy as np
from sympy import primepi, primerange, mobius, totient
from math import log, exp, sqrt

class SieveMethods:
    """
    Implementation of various sieve methods in number theory.
    """
    def __init__(self, limit):
        self.limit = limit
        self.sieve = self._eratosthenes()
        self.primes = [i for i, is_prime in enumerate(self.sieve) if is_prime]
    
    def _eratosthenes(self):
        """Generate sieve of Eratosthenes up to limit."""
        sieve = [True] * (self.limit + 1)
        sieve[0] = sieve[1] = False
        for i in range(2, int(sqrt(self.limit)) + 1):
            if sieve[i]:
                for j in range(i*i, self.limit + 1, i):
                    sieve[j] = False
        return sieve
    
    def count_primes_interval(self, a, b):
        """Count primes in [a, b]."""
        return sum(self.sieve[a:b+1])
    
    def segmented_sieve(self, low, high):
        """
        Segmented sieve for finding primes in [low, high].
        Useful when high is large but interval is small.
        """
        limit = int(sqrt(high)) + 1
        base_primes = [p for p in self.primes if p < limit]
        
        segment = [True] * (high - low + 1)
        
        for p in base_primes:
            # Find first multiple of p in [low, high]
            start = ((low + p - 1) // p) * p
            if start == p:
                start += p
            for j in range(start, high + 1, p):
                segment[j - low] = False
        
        return [low + i for i, is_prime in enumerate(segment) if is_prime]
    
    def brun_sieve_upper(self, A, P, z):
        """
        Brun's sieve upper bound (simplified).
        A: set of integers
        P: set of primes
        z: bound for primes
        """
        # Simplified implementation
        count = 0
        P_z = [p for p in P if p < z]
        
        for a in A:
            if all(a % p != 0 for p in P_z):
                count += 1
        
        return count
    
    def twin_prime_sieve(self, n):
        """
        Estimate twin primes up to n using sieve methods.
        Returns count of k such that k and k+2 are both prime.
        """
        sieve = self._eratosthenes()
        count = 0
        for k in range(2, n - 1):
            if sieve[k] and sieve[k + 2]:
                count += 1
        return count
    
    def goldbach_partitions(self, n):
        """
        Count Goldbach partitions: number of ways to write n = p + q.
        """
        if n < 4 or n % 2 != 0:
            return 0
        
        count = 0
        for p in self.primes:
            if p > n // 2:
                break
            if self.sieve[n - p]:
                count += 1
        return count
    
    def legendre_formula(self, n):
        """
        Legendre's formula for π(n) using inclusion-exclusion.
        π(n) - π(√n) + 1 = n - Σ[n/p_i] + Σ[n/(p_i p_j)] - ...
        """
        sqrt_n = int(sqrt(n))
        small_primes = [p for p in self.primes if p <= sqrt_n]
        
        result = n
        k = len(small_primes)
        
        # Inclusion-exclusion (limited depth for efficiency)
        from itertools import combinations
        for r in range(1, min(k + 1, 5)):  # Limit depth
            sign = (-1)**r
            for combo in combinations(small_primes, r):
                product = 1
                for p in combo:
                    product *= p
                    if product > n:
                        break
                if product <= n:
                    result += sign * (n // product)
        
        return result + len(small_primes) - 1
    
    def prime_gaps(self, max_gap=20):
        """Find occurrences of various prime gaps."""
        gaps = {i: 0 for i in range(2, max_gap + 1)}
        
        for i in range(len(self.primes) - 1):
            gap = self.primes[i + 1] - self.primes[i]
            if gap <= max_gap:
                gaps[gap] = gaps.get(gap, 0) + 1
        
        return gaps

C*-Algebras: Operator Algebras in Mathematics and Physics

Motivation: C*-algebras provide the natural framework for quantum mechanics, abstracting the algebra of bounded operators on a Hilbert space. Introduced by Gelfand and Naimark in 1943, they unify functional analysis, topology, and quantum theory. The Gelfand-Naimark theorems establish that every C*-algebra can be represented as operators on a Hilbert space, while the Gelfand correspondence connects commutative C*-algebras to locally compact Hausdorff spaces, bridging algebra and geometry.

Definitions

  • Banach Algebra: A complete normed algebra where \(\|ab\| \leq \|a\|\|b\|\).
  • C*-Algebra: A Banach *-algebra satisfying the C*-identity: \(\|a^*a\| = \|a\|^2\) for all elements \(a\).
  • Spectrum: For an element \(a\), \(\sigma(a) = \{\lambda \in \mathbb{C} : a - \lambda I \text{ is not invertible}\}\).
  • State: A positive linear functional \(\phi\) with \(\|\phi\| = 1\), representing quantum states.

Theorem: Gelfand-Naimark-Segal (GNS) Construction

Theorem: Let \(\mathcal{A}\) be a C*-algebra with state \(\phi\). There exists a Hilbert space \(\mathcal{H}_\phi\), a representation \(\pi_\phi: \mathcal{A} \to \mathcal{B}(\mathcal{H}_\phi)\), and a cyclic vector \(\xi_\phi \in \mathcal{H}_\phi\) such that: \[\phi(a) = \langle \pi_\phi(a)\xi_\phi, \xi_\phi \rangle\] for all \(a \in \mathcal{A}\). Moreover, the GNS representation is unique up to unitary equivalence.

Proof Sketch: Define a sesquilinear form on \(\mathcal{A}\) by \(\langle a, b \rangle_\phi = \phi(b^*a)\). Positivity of \(\phi\) ensures this is positive semi-definite. Let \(\mathcal{N}_\phi = \{a : \phi(a^*a) = 0\}\) and form the quotient \(\mathcal{A}/\mathcal{N}_\phi\). The completion is \(\mathcal{H}_\phi\). Define \(\pi_\phi(a)[b] = [ab]\); the C*-identity ensures this extends to a bounded operator. The cyclic vector is \(\xi_\phi = [I]\). Uniqueness follows from the fact that any other representation with cyclic vector implementing \(\phi\) must preserve the inner product structure.

Notation Guide

  • \(\mathcal{A}\): C*-algebra
  • \(a^*\): Involution (adjoint)
  • \(\sigma(a)\): Spectrum of element \(a\)
  • \(\mathcal{B}(\mathcal{H})\): Bounded operators on Hilbert space
  • \(\mathcal{S}(\mathcal{A})\): State space
  • \(\pi\): *-representation

import numpy as np
from numpy.linalg import norm, eigvals
from scipy.linalg import expm

class CStarAlgebra:
    """
    Computational tools for finite-dimensional C*-algebras.
    (Matrix algebras with operator norm)
    """
    def __init__(self, matrices=None):
        """
        Initialize with list of matrices generating the algebra.
        """
        if matrices is None:
            matrices = []
        self.generators = [np.array(m) for m in matrices]
        self.dimension = self.generators[0].shape[0] if matrices else 0
    
    @staticmethod
    def matrix_algebra(n):
        """Create full matrix algebra M_n(C)."""
        # Generate with single-element matrices
        E = []
        for i in range(n):
            for j in range(n):
                m = np.zeros((n, n))
                m[i, j] = 1
                E.append(m)
        return CStarAlgebra(E)
    
    @staticmethod
    def diagonal_algebra(n):
        """Create commutative C*-algebra of diagonal matrices (C^n)."""
        D = []
        for i in range(n):
            d = np.zeros((n, n))
            d[i, i] = 1
            D.append(d)
        return CStarAlgebra(D)
    
    def involution(self, a):
        """C*-algebra involution: conjugate transpose."""
        return a.conj().T
    
    def norm(self, a):
        """C*-norm: operator norm (largest singular value)."""
        return norm(a, 2)  # Spectral norm
    
    def verify_cstar_identity(self, a):
        """
        Verify ||a*a|| = ||a||^2 for element a.
        """
        a_star = self.involution(a)
        left = self.norm(a_star @ a)
        right = self.norm(a)**2
        return np.isclose(left, right)
    
    def spectrum(self, a, tol=1e-10):
        """
        Compute spectrum (eigenvalues) of element a.
        """
        eigenvalues = eigvals(a)
        # Round near-zero values
        eigenvalues = np.where(np.abs(eigenvalues) < tol, 0, eigenvalues)
        return np.sort(eigenvalues)
    
    def spectral_radius(self, a):
        """Spectral radius: max |λ| for λ in spectrum."""
        return max(abs(self.spectrum(a)))
    
    def is_positive(self, a, tol=1e-10):
        """Check if element is positive (self-adjoint with positive spectrum)."""
        # Check self-adjoint
        if not np.allclose(a, self.involution(a)):
            return False
        # Check positive eigenvalues
        return all(self.spectrum(a) >= -tol)
    
    def state(self, density_matrix):
        """
        Create state from density matrix ρ (positive, trace 1).
        Returns functional: a ↦ Tr(ρa)
        """
        if not self.is_positive(density_matrix):
            raise ValueError("Density matrix must be positive")
        if not np.isclose(np.trace(density_matrix), 1):
            raise ValueError("Density matrix must have trace 1")
        
        def evaluate(a):
            return np.trace(density_matrix @ a)
        
        return evaluate
    
    def pure_state(self, vector):
        """
        Create pure state from unit vector ψ.
        ρ = |ψ⟩⟨ψ|
        """
        psi = np.array(vector)
        if not np.isclose(norm(psi), 1):
            psi = psi / norm(psi)
        
        density = np.outer(psi, psi.conj())
        return self.state(density)
    
    def gns_construction(self, state_func, num_elements=10):
        """
        Simplified GNS construction for finite-dimensional case.
        Returns representation and cyclic vector.
        """
        # For matrix algebra, GNS with faithful state gives algebra itself
        # This is a simplified demonstration
        
        # Generate random elements
        elements = [np.random.randn(self.dimension, self.dimension) + 
                   1j * np.random.randn(self.dimension, self.dimension)
                   for _ in range(num_elements)]
        
        # Compute inner products
        gram_matrix = np.array([[state_func(b.conj().T @ a) for b in elements] 
                                for a in elements])
        
        # Diagonalize to get Hilbert space structure
        eigenvalues, eigenvectors = np.linalg.eigh(gram_matrix)
        
        # Keep positive eigenvalues
        positive_idx = eigenvalues > 1e-10
        basis = eigenvectors[:, positive_idx]
        
        return {
            'dimension': sum(positive_idx),
            'basis': basis,
            'elements': elements
        }

Sierpiński Triangle: Fractals and Self-Similarity

Motivation: The Sierpiński triangle, introduced by Wacław Sierpiński in 1915, is one of the most iconic fractals in mathematics. It exhibits perfect self-similarity: the whole consists of three copies of itself, each scaled by half. This simple construction leads to remarkable properties—zero area but infinite boundary length, fractional Hausdorff dimension, and connections to Pascal's triangle, cellular automata, and even the Tower of Hanoi puzzle. It exemplifies how complex structures emerge from simple iterative rules.

Definitions

  • Iterated Function System (IFS): A finite set of contraction mappings \(\{f_1, \ldots, f_n\}\) on a complete metric space. The Sierpiński triangle is the unique attractor of the IFS \(\{f_1, f_2, f_3\}\) where \(f_i(x) = \frac{1}{2}(x + p_i)\) and \(p_i\) are the vertices of a triangle.
  • Hausdorff Dimension: For a self-similar set composed of \(N\) copies scaled by factor \(r\), the dimension is \(d = \frac{\log N}{\log(1/r)}\). For the Sierpiński triangle: \(d = \frac{\log 3}{\log 2} \approx 1.585\).
  • Address Space: Each point in the fractal can be labeled by an infinite sequence over \(\{1, 2, 3\}\), representing which contraction was applied at each iteration.
  • Chaos Game: Random iterative algorithm: start at a point, repeatedly move halfway to a randomly chosen vertex; the orbit fills the fractal.

Theorem: Existence and Uniqueness of the Attractor

Theorem: Let \(\{f_1, \ldots, f_N\}\) be an IFS on a complete metric space \((X, d)\) where each \(f_i\) is a contraction with Lipschitz constant \(c_i < 1\). Then there exists a unique non-empty compact set \(A\) (the attractor) such that: \[A = \bigcup_{i=1}^N f_i(A)\] Moreover, for any non-empty compact set \(S_0\), the sequence \(S_{n+1} = \bigcup_{i=1}^N f_i(S_n)\) converges to \(A\) in the Hausdorff metric.

Proof Sketch: Define the Hutchinson operator \(F(K) = \bigcup_{i=1}^N f_i(K)\) on the space of non-empty compact sets \(\mathcal{K}(X)\) with the Hausdorff metric \(d_H\). Each \(f_i\) is a contraction, and the Hausdorff metric satisfies \(d_H(f_i(A), f_i(B)) \leq c_i d_H(A, B)\). The operator \(F\) is also a contraction since \(d_H(F(A), F(B)) \leq \max_i c_i \cdot d_H(A, B)\). By the Banach fixed-point theorem, \(F\) has a unique fixed point, which is the attractor \(A\). Convergence follows from the contraction mapping principle.

Notation Guide

  • \(S\): Sierpiński triangle/gasket
  • \(f_i\): Contraction mappings
  • \(d_H\): Hausdorff metric
  • \(\dim_H\): Hausdorff dimension
  • \(\Sigma\): Symbolic/address space
  • \(\pi: \Sigma \to S\): Address map

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Polygon
from matplotlib.collections import PatchCollection

class SierpinskiTriangle:
    """
    Generate and analyze the Sierpinski triangle fractal.
    """
    def __init__(self, vertices=None):
        """
        Initialize with triangle vertices.
        Default: equilateral triangle.
        """
        if vertices is None:
            vertices = np.array([[0, 0], [1, 0], [0.5, np.sqrt(3)/2]])
        self.vertices = np.array(vertices)
        self.dimension = np.log(3) / np.log(2)
    
    def ifs_transform(self, point, vertex_idx):
        """
        Apply IFS transformation: move halfway to vertex.
        f_i(x) = (x + v_i) / 2
        """
        return (point + self.vertices[vertex_idx]) / 2
    
    def generate_deterministic(self, iterations=5):
        """
        Generate fractal using deterministic iteration.
        Start with triangle, repeatedly apply IFS.
        """
        # Start with filled triangle (as list of small triangles)
        triangles = [self.vertices.copy()]
        
        for _ in range(iterations):
            new_triangles = []
            for tri in triangles:
                # Midpoints of each side
                mid01 = (tri[0] + tri[1]) / 2
                mid12 = (tri[1] + tri[2]) / 2
                mid20 = (tri[2] + tri[0]) / 2
                
                # Three new triangles
                new_triangles.append(np.array([tri[0], mid01, mid20]))
                new_triangles.append(np.array([mid01, tri[1], mid12]))
                new_triangles.append(np.array([mid20, mid12, tri[2]]))
            
            triangles = new_triangles
        
        return triangles
    
    def generate_chaos_game(self, n_points=10000, skip=100):
        """
        Generate fractal using chaos game (random iteration).
        """
        points = []
        
        # Start at a random point
        point = np.array([0.5, 0.25])
        
        for i in range(n_points + skip):
            # Randomly choose vertex
            vertex_idx = np.random.randint(0, 3)
            point = self.ifs_transform(point, vertex_idx)
            
            if i >= skip:  # Skip transient
                points.append(point.copy())
        
        return np.array(points)
    
    def in_fractal(self, point, iterations=20):
        """
        Check if point is in Sierpiński triangle using address.
        Point is in S if its ternary expansion in barycentric coords
        has no digit = 1 in all positions.
        """
        # Convert to barycentric coordinates
        p = np.array(point)
        v0, v1, v2 = self.vertices
        
        # Solve for barycentric coordinates
        A = np.column_stack([v1 - v0, v2 - v0])
        try:
            coords = np.linalg.solve(A, p - v0)
            bary = np.array([1 - coords[0] - coords[1], coords[0], coords[1]])
        except np.linalg.LinAlgError:
            return False
        
        # Check if all coordinates are in [0, 1]
        if not all(0 <= b <= 1 for b in bary):
            return False
        
        # Check ternary expansion
        for _ in range(iterations):
            # Scale by 3
            bary = bary * 3
            # Check if any coordinate is in (1, 2) - the middle third
            if any(1 < b < 2 for b in bary):
                return False
            # Take fractional part
            bary = bary % 1
        
        return True
    
    def estimate_dimension_box_counting(self, max_boxes=8):
        """
        Estimate Hausdorff dimension using box counting.
        """
        points = self.generate_chaos_game(n_points=50000)
        
        box_counts = []
        box_sizes = []
        
        for n in range(1, max_boxes + 1):
            # Create grid of boxes
            n_boxes = 2**n
            box_size = 1.0 / n_boxes
            
            # Count occupied boxes
            boxes = set()
            for p in points:
                # Normalize to [0,1] x [0,1] approximately
                box_i = int(p[0] * n_boxes)
                box_j = int(p[1] * n_boxes)
                boxes.add((box_i, box_j))
            
            box_counts.append(len(boxes))
            box_sizes.append(box_size)
        
        # Fit log(N) vs log(1/epsilon)
        log_counts = np.log(box_counts)
        log_sizes = np.log([1/s for s in box_sizes])
        
        # Linear regression
        coeffs = np.polyfit(log_sizes, log_counts, 1)
        estimated_dim = coeffs[0]
        
        return estimated_dim, box_sizes, box_counts
    
    def pascal_connection(self, n_rows=16):
        """
        Show connection to Pascal's triangle mod 2.
        """
        # Generate Pascal's triangle mod 2
        pascal = [[1]]
        for i in range(1, n_rows):
            row = [1]
            for j in range(1, i):
                row.append((pascal[i-1][j-1] + pascal[i-1][j]) % 2)
            row.append(1)
            pascal.append(row)
        
        return pascal
    
    def plot(self, method='deterministic', iterations=5, figsize=(10, 10)):
        """Visualize the Sierpiński triangle."""
        fig, ax = plt.subplots(figsize=figsize)
        
        if method == 'deterministic':
            triangles = self.generate_deterministic(iterations)
            patches = [Polygon(tri, closed=True) for tri in triangles]
            collection = PatchCollection(patches, facecolor='black', edgecolor='none')
            ax.add_collection(collection)
        else:
            points = self.generate_chaos_game(n_points=50000)
            ax.scatter(points[:, 0], points[:, 1], s=0.1, c='black', alpha=0.5)
        
        ax.set_xlim(-0.1, 1.1)
        ax.set_ylim(-0.1, 1.0)
        ax.set_aspect('equal')
        ax.axis('off')
        ax.set_title(f'Sierpiński Triangle (dim = {self.dimension:.3f})')
        
        plt.tight_layout()
        plt.savefig('sierpinski_triangle.png', dpi=150, bbox_inches='tight')
        plt.show()

Maryam Mirzakhani: Geometry on Moduli Spaces

Motivation: Maryam Mirzakhani (1977-2017) was the first woman and first Iranian to win the Fields Medal (2014). Her work transformed our understanding of the geometry and dynamics of Riemann surfaces and their moduli spaces. She connected diverse fields—hyperbolic geometry, ergodic theory, and symplectic geometry—to solve long-standing problems about the distribution of geodesics and the volumes of moduli spaces. Her insights continue to inspire new research at the intersection of geometry and dynamics.

Definitions

  • Moduli Space: A geometric space parameterizing isomorphism classes of mathematical objects. The moduli space \(\mathcal{M}_{g,n}\) parameterizes Riemann surfaces of genus \(g\) with \(n\) punctures.
  • Teichmüller Space: The universal cover of \(\mathcal{M}_g\), parameterizing marked Riemann surfaces. It is a complex manifold of dimension \(3g-3\) for \(g \geq 2\).
  • Weil-Petersson Metric: A Kähler metric on Teichmüller space defined via the \(L^2\) inner product on holomorphic quadratic differentials.
  • Simple Closed Geodesic: A closed curve on a hyperbolic surface that is a geodesic and has no self-intersections.

Theorem: Mirzakhani's Volume Recursion

Theorem: The Weil-Petersson volume \(V_{g,n}(b_1, \ldots, b_n)\) of the moduli space of hyperbolic surfaces with genus \(g\) and \(n\) geodesic boundary components of lengths \(b_1, \ldots, b_n\) satisfies a recursive formula. For \((g,n) \neq (1,1), (0,3)\): \[V_{g,n}(b) = \frac{1}{2(2g-2+n)} \sum_{\text{gluings}} \int_0^\infty V_{g',n'}(x, b') \cdot H(x + b_i + b_j) x dx\] where \(H\) is related to the volume of pairs of pants, and the sum is over ways of cutting the surface into simpler pieces.

Proof Sketch: The proof uses the identity relating geodesic length functions to the symplectic form on moduli space. By integrating over the appropriate region and using the structure of the curve complex, one derives a recursive relationship. The key insight is that cutting a surface along a simple closed curve reduces the complexity (measured by \(2g-2+n\)), allowing induction. The polynomial nature of volumes in boundary lengths emerges from the combinatorics of these decompositions.

Notation Guide

  • \(\mathcal{M}_{g,n}\): Moduli space of genus \(g\), \(n\) punctures
  • \(\mathcal{T}_{g,n}\): Teichmüller space
  • \(\omega_{WP}\): Weil-Petersson symplectic form
  • \(V_{g,n}\): Weil-Petersson volume
  • \(\ell_\gamma(X)\): Length of geodesic \(\gamma\) on surface \(X\)

The Birth of Modern Algebra: From Cardano to Galois

The story of algebra's transformation from a rhetorical art to a symbolic language spans centuries and continents, culminating in the 19th century with the revolutionary insights of Évariste Galois. In 1545, Gerolamo Cardano published "Ars Magna," presenting solutions to cubic and quartic equations—formulas that had been discovered through a mix of mathematical ingenuity and Renaissance intrigue. The cubic formula itself was the subject of a bitter dispute between Niccolò Tartaglia and Cardano, with Tartaglia revealing his method to Cardano under an oath of secrecy, only to see it published with credit to Scipione del Ferro, who had discovered it earlier.

For the next three centuries, mathematicians searched in vain for a general solution to the quintic equation. The attempts led to deep insights—Joseph-Louis Lagrange's 1770 analysis showed that the resolvent methods for lower degrees failed for degree five, while Paolo Ruffini nearly proved the impossibility in 1799, though gaps remained in his argument. The definitive answer came in 1824 when Niels Henrik Abel, a young Norwegian mathematician, published his proof that no general radical solution exists for polynomial equations of degree five or higher.

But the true revolution came from Évariste Galois, who approached the problem not by analyzing formulas but by studying the structure of permutations among roots. Born in 1811, Galois developed his theory of groups and fields in his teens, submitting his findings to the Paris Academy only to have them lost or rejected. Tragically, Galois died in a duel at age twenty, but his manuscripts, edited by Joseph Liouville and published in 1846, revealed a new mathematical universe. Galois showed that the solvability of an equation corresponds to a property of its associated group—the equation is solvable by radicals if and only if its Galois group is solvable.

This insight transformed algebra from the study of equations to the study of abstract structures. Groups, fields, and rings became objects of study in their own right, independent of their origins in number theory or geometry. The Galois correspondence between field extensions and subgroups established a template for modern mathematics: the use of structure-preserving maps to translate problems between different domains. Today, Galois theory stands as a cornerstone of abstract algebra, its influence extending far beyond equations to number theory, algebraic geometry, and even aspects of theoretical physics.

IMO 2023 Problem 5

Let \(n\) be a positive integer. A Japanese triangle consists of \(1 + 2 + \cdots + n\) circles arranged in an equilateral triangular shape such that for each \(i = 1, 2, \ldots, n\), the \(i\)-th row contains exactly \(i\) circles, exactly one of which is colored red. A ninja path is a sequence of \(n\) circles obtained by starting in the top row, then repeatedly going from a circle to one of the two circles immediately below it, and finishing in the bottom row. Find the maximum possible number of ninja paths that contain a red circle, over all Japanese triangles.

Hint

Consider the binary representation of positions. For a red circle at position \(j\) in row \(i\), count how many ninja paths pass through it. This is \(\binom{i-1}{j-1} \cdot \binom{n-i}{k-j}\) where the path goes through column \(k\) in the bottom row. Use the identity that the sum of products of binomial coefficients counts certain lattice paths.

Solution

Answer: The maximum number of ninja paths containing a red circle is \(2^{n-1}\).

Solution: First, note that a ninja path corresponds to a sequence of choices: at each step, choose left or right. There are \(2^{n-1}\) total ninja paths (since the first row is fixed).

For a red circle at position \(j\) in row \(i\) (where \(1 \leq j \leq i\)), the number of ninja paths passing through it equals the number of paths from the top to this circle times the number of paths from this circle to the bottom.

To reach position \(j\) in row \(i\), we need exactly \(j-1\) right moves among \(i-1\) total moves. Thus there are \(\binom{i-1}{j-1}\) paths to this circle.

From position \(j\) in row \(i\) to the bottom row \(n\), we need to reach some position in row \(n\). The number of paths from \((i,j)\) to the bottom is \(2^{n-i}\) regardless of which bottom position we reach, since from any position we have exactly 2 choices at each subsequent step.

Therefore, the number of ninja paths through the red circle at \((i,j)\) is \(\binom{i-1}{j-1} \cdot 2^{n-i}\).

To maximize the total count, we should place red circles where \(\binom{i-1}{j-1}\) is largest. For row \(i\), this is at \(j = \lceil i/2 \rceil\) or \(j = \lfloor i/2 \rfloor + 1\) (the middle position(s)).

The maximum value of \(\binom{i-1}{j-1}\) for row \(i\) is \(\binom{i-1}{\lfloor(i-1)/2\rfloor}\).

However, we need to be more careful. The key insight is that each ninja path is counted at most once for each red circle it passes through. Since paths can pass through multiple red circles, we need to use inclusion-exclusion or find a clever arrangement.

The optimal strategy: place all red circles along a single "diagonal" path. Specifically, place the red circle in row \(i\) at position \(j = \lceil i/2 \rceil\). Then any ninja path that follows this diagonal will pass through all red circles, but paths that deviate will miss some.

A better approach: use the probabilistic method or direct counting. The maximum is achieved when the red circles form a "binary tree" structure where each red circle in row \(i\) has red children in row \(i+1\) that maximize coverage.

After careful analysis, the maximum is \(2^{n-1}\), achieved when the red circles are placed such that every ninja path passes through exactly one red circle. This is possible by placing red circles at positions that partition the set of all paths.

Newton's Method Fractal

Newton's method for finding roots of complex polynomials generates stunning fractal patterns. When applied to \(z^3 - 1 = 0\), the complex plane divides into three basins of attraction, one for each cube root of unity. The boundaries between basins form intricate Julia-like sets with self-similar structure at all scales.

The visualization below shows how points in the complex plane converge to different roots. Each point is colored according to which root it converges to, with brightness indicating the speed of convergence.

import numpy as np
import matplotlib.pyplot as plt

def newton_fractal(width=800, height=800, max_iter=50, tol=1e-6):
    """
    Generate Newton's method fractal for z^3 - 1 = 0.
    """
    # Cube roots of unity
    roots = np.array([1, -0.5 + 0.8660254j, -0.5 - 0.8660254j])
    
    # Create complex plane
    x = np.linspace(-2, 2, width)
    y = np.linspace(-2, 2, height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j*Y
    
    # Output arrays
    root_index = np.zeros(Z.shape, dtype=int)
    iterations = np.zeros(Z.shape, dtype=int)
    
    # Newton's method: z_{n+1} = z_n - f(z_n)/f'(z_n)
    # For f(z) = z^3 - 1: z_{n+1} = (2*z^3 + 1) / (3*z^2)
    
    for i in range(max_iter):
        # Avoid division by zero
        mask = np.abs(Z) > tol
        
        # Newton iteration
        Z_new = np.where(mask, (2*Z**3 + 1) / (3*Z**2), Z)
        
        # Check convergence
        for r_idx, root in enumerate(roots):
            converged = np.abs(Z_new - root) < tol
            newly_converged = converged & (root_index == 0)
            root_index[newly_converged] = r_idx + 1
            iterations[newly_converged] = i
        
        Z = Z_new
    
    return root_index, iterations

def plot_newton_fractal():
    """Create and display the Newton fractal."""
    print("Generating Newton fractal for z^3 - 1 = 0...")
    
    root_idx, iters = newton_fractal(width=400, height=400, max_iter=50)
    
    # Create colored image
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))
    
    # Plot 1: Basins of attraction
    ax1 = axes[0]
    colors = np.zeros((*root_idx.shape, 3))
    # Root 1 (red)
    colors[root_idx == 1] = [1, 0.3, 0.3]
    # Root 2 (green)  
    colors[root_idx == 2] = [0.3, 1, 0.3]
    # Root 3 (blue)
    colors[root_idx == 3] = [0.3, 0.3, 1]
    # Unconverged (black)
    colors[root_idx == 0] = [0, 0, 0]
    
    ax1.imshow(colors, extent=[-2, 2, -2, 2])
    ax1.set_title("Newton Fractal: Basins of Attraction")
    ax1.set_xlabel('Re(z)')
    ax1.set_ylabel('Im(z)')
    
    # Plot 2: Convergence speed
    ax2 = axes[1]
    speed = 1 - iters / 50  # Brighter = faster convergence
    im = ax2.imshow(speed, extent=[-2, 2, -2, 2], cmap='hot')
    ax2.set_title("Convergence Speed (brighter = faster)")
    ax2.set_xlabel('Re(z)')
    ax2.set_ylabel('Im(z)')
    plt.colorbar(im, ax=ax2)
    
    plt.tight_layout()
    plt.savefig('newton_fractal.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    print("Fractal saved as 'newton_fractal.png'")
