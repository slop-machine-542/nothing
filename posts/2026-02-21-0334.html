Spectral Graph Theory: Eigenvalues and Graph Structure

spectral-graph-theory

Motivation

Spectral graph theory studies the relationship between the eigenvalues of matrices associated with graphs and the structural properties of those graphs. This field, pioneered by chemists studying molecular spectra and developed by mathematicians like Fan Chung and Bojan Mohar, provides powerful tools for understanding networks, designing algorithms, and proving combinatorial results. The eigenvalues of the Laplacian and adjacency matrices encode information about connectivity, expansion, random walks, and clustering.

Definitions

  • Adjacency Matrix \(A\): For a graph \(G = (V, E)\) with \(n\) vertices, \(A\) is the \(n \times n\) matrix where \(A_{ij} = 1\) if \((i,j) \in E\) and \(0\) otherwise.
  • Degree Matrix \(D\): A diagonal matrix where \(D_{ii} = \deg(v_i)\), the degree of vertex \(i\).
  • Combinatorial Laplacian \(L\): Defined as \(L = D - A\). This matrix is positive semi-definite.
  • Normalized Laplacian \(\mathcal{L}\): Defined as \(\mathcal{L} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}AD^{-1/2}\).
  • Graph Spectrum: The multiset of eigenvalues \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\) of the Laplacian.
  • Spectral Gap: The difference \(\lambda_2 - \lambda_1\). For connected graphs, \(\lambda_1 = 0\), so this is \(\lambda_2\).

Theorem: Cheeger's Inequality

Theorem: Let \(G\) be a finite connected graph and \(\lambda_2\) the second smallest eigenvalue of the normalized Laplacian. Let \(\phi(G)\) be the Cheeger constant (isoperimetric number): \[\phi(G) = \min_{S \subseteq V, |S| \leq |V|/2} \frac{|\partial S|}{\min(\text{vol}(S), \text{vol}(V \setminus S))}\] where \(\partial S\) is the edge boundary and \(\text{vol}(S) = \sum_{v \in S} \deg(v)\).

Then: \[\frac{\phi(G)^2}{2} \leq \lambda_2 \leq 2\phi(G)\]

Proof Sketch

The upper bound follows by using the characteristic vector of any set \(S\) as a test function in the Rayleigh quotient for \(\lambda_2\). For the lower bound, given an eigenvector \(v\) for \(\lambda_2\), one constructs a sweep cut: order vertices by \(v_i / \sqrt{\deg(i)}\) and find the minimum conductance cut among prefixes. The Dirichlet form \(\langle v, Lv \rangle\) controls the cut size, while the Rayleigh quotient provides the relationship to \(\lambda_2\). The square arises from comparing \(\ell_1\) and \(\ell_2\) norms via Cauchy-Schwarz.

Notation Guide

  • \(G = (V, E)\) — Graph with vertex set \(V\) and edge set \(E\)
  • \(A\) — Adjacency matrix
  • \(D\) — Degree matrix
  • \(L = D - A\) — Combinatorial Laplacian
  • \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\) — Eigenvalues of Laplacian
  • \(\phi(G)\) — Cheeger constant (isoperimetric number)
  • \(\partial S\) — Edge boundary of set \(S\)
  • \(\text{vol}(S)\) — Volume (sum of degrees) of \(S\)

Python Code

import numpy as np
import networkx as nx
from scipy.sparse import csgraph
from scipy.sparse.linalg import eigsh

def compute_graph_spectrum(G, normalized=True):
    """
    Compute the spectrum of a graph's Laplacian.
    """
    if normalized:
        L = nx.normalized_laplacian_matrix(G).astype(float)
    else:
        L = nx.laplacian_matrix(G).astype(float)
    
    n = G.number_of_nodes()
    if n <= 100:
        eigenvalues, eigenvectors = np.linalg.eigh(L.toarray())
    else:
        eigenvalues, eigenvectors = eigsh(L, k=min(10, n-1), which='SM')
    
    return eigenvalues, eigenvectors

def cheeger_constant(G):
    """
    Approximate the Cheeger constant of a graph.
    """
    L = nx.normalized_laplacian_matrix(G).astype(float)
    n = G.number_of_nodes()
    
    eigenvalues, eigenvectors = eigsh(L, k=2, which='SM')
    fiedler_vector = eigenvectors[:, 1]
    
    nodes = list(G.nodes())
    sorted_indices = np.argsort(fiedler_vector)
    
    min_conductance = float('inf')
    best_cut = None
    
    volumes = dict(G.degree())
    total_volume = sum(volumes.values())
    
    for i in range(1, n):
        S = set([nodes[idx] for idx in sorted_indices[:i]])
        
        boundary = 0
        vol_S = 0
        for v in S:
            vol_S += volumes[v]
            for u in G.neighbors(v):
                if u not in S:
                    boundary += 1
        
        if vol_S > 0 and vol_S < total_volume:
            conductance = boundary / min(vol_S, total_volume - vol_S)
            if conductance < min_conductance:
                min_conductance = conductance
                best_cut = S
    
    return min_conductance, best_cut, eigenvalues[1]

print(f"Cheeger's inequality: {phi**2/2:.4f} <= {lambda2:.4f} <= {2*phi:.4f}")

Ergodic Theory: The Long-Term Behavior of Dynamical Systems

ergodic-theory

Motivation

Ergodic theory, born from Boltzmann's work in statistical mechanics and formalized by Birkhoff and von Neumann, studies the long-term behavior of dynamical systems from a measure-theoretic perspective. It provides the mathematical foundation for understanding how time averages relate to space averages—a question fundamental to physics, probability, and number theory.

Definitions

  • Measure-Preserving System: A quadruple \((X, \mathcal{B}, \mu, T)\) where \((X, \mathcal{B}, \mu)\) is a probability space and \(T: X \to X\) is measurable with \(\mu(T^{-1}(A)) = \mu(A)\).
  • Ergodic Transformation: A measure-preserving transformation \(T\) is ergodic if the only invariant measurable sets have measure 0 or 1.
  • Time Average: For \(f \in L^1(\mu)\), the time average is \(\lim_{N \to \infty} \frac{1}{N} \sum_{n=0}^{N-1} f(T^n x)\).
  • Space Average: The integral \(\int_X f \, d\mu\).

Theorem: Birkhoff's Ergodic Theorem

Theorem: Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(f \in L^1(X, \mathcal{B}, \mu)\). Then the time average exists almost everywhere: \[\lim_{N \to \infty} \frac{1}{N} \sum_{n=0}^{N-1} f(T^n x) = f^*(x)\]

where \(f^* \in L^1(X, \mathcal{B}, \mu)\) satisfies \(f^* \circ T = f^*\) a.e. and \(\int_X f^* \, d\mu = \int_X f \, d\mu\). If \(T\) is ergodic, then \(f^* = \int_X f \, d\mu\) a.e.

Python Code

import numpy as np

def circle_rotation(x, alpha):
    """Irrational rotation on the circle: T(x) = x + alpha (mod 1)"""
    return (x + alpha) % 1.0

def doubling_map(x):
    """The doubling map: T(x) = 2x (mod 1)"""
    return (2 * x) % 1.0

def compute_time_average(f, T, x0, N, *args):
    """Compute the time average of f along the orbit of x0 under T."""
    orbit = np.zeros(N)
    averages = np.zeros(N)
    x = x0
    total = 0.0
    
    for n in range(N):
        x = T(x, *args) if args else T(x)
        orbit[n] = x
        total += f(x)
        averages[n] = total / (n + 1)
    
    return averages, orbit

# Test 1: Irrational rotation (ergodic)
N = 100000

print(f"Space average (should be 0): 0.0")
print(f"Difference: {abs(averages[-1] - 0.0):.8f}")

p-adic Analysis: Number Theory in a Non-Archimedean World

p-adic-analysis

Motivation

p-adic numbers, introduced by Kurt Hensel in the late 19th century, provide an alternative way to complete the rational numbers. Unlike the real numbers, which complete \(\mathbb{Q}\) using the usual absolute value, p-adic numbers use a metric based on divisibility by a prime \(p\). This non-Archimedean completion reveals deep arithmetic structures invisible to real analysis.

Definitions

  • p-adic Valuation \(\nu_p(n)\): For a nonzero integer \(n\), \(\nu_p(n) = k\) where \(p^k \mid n\) but \(p^{k+1} \nmid n\).
  • p-adic Absolute Value: \(|x|_p = p^{-\nu_p(x)}\) for \(x \neq 0\), and \(|0|_p = 0\).
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).
  • Non-Archimedean Property: \(|x + y|_p \leq \max(|x|_p, |y|_p)\).

Theorem: Ostrowski's Theorem

Theorem: Every nontrivial absolute value on \(\mathbb{Q}\) is equivalent to either the usual absolute value \(|\cdot|_{\infty}\) (giving \(\mathbb{R}\)), or the p-adic absolute value \(|\cdot|_p\) for some prime \(p\) (giving \(\mathbb{Q}_p\)). Moreover, the product formula holds: \(\prod_{p \leq \infty} |x|_p = 1\) for all nonzero \(x \in \mathbb{Q}\).

Python Code

def p_adic_valuation(n, p):
    """Compute the p-adic valuation of an integer n."""
    if n == 0:
        return float('inf')
    n = abs(n)
    k = 0
    while n % p == 0:
        n //= p
        k += 1
    return k

def p_adic_absolute_value(x, p):
    """Compute the p-adic absolute value of a rational number x."""
    if x == 0:
        return 0.0
    from fractions import Fraction
    frac = Fraction(x).limit_denominator(10000)
    a, b = frac.numerator, frac.denominator
    v = p_adic_valuation(a, p) - p_adic_valuation(b, p)
    return p ** (-v)

# Demonstrate p-adic properties
p = 5
print(f"p-adic Analysis for p = {p}")
print("\n1. p-adic Absolute Values:")
test_values = [1, 5, 25, 125, 625, 1/5, 1/25, 2/5, 3]
for x in test_values:
    print(f"   |{x}|_{p} = {p_adic_absolute_value(x, p):.6f}")

# Verify non-Archimedean property
x, y = 3, 2
left = p_adic_absolute_value(x + y, p)
right = max(p_adic_absolute_value(x, p), p_adic_absolute_value(y, p))
print(f"\n2. Non-Archimedean Property:")
print(f"   |x + y|_{p} = {left:.6f} ≤ max(|x|_{p}, |y|_{p}) = {right:.6f}")
print(f"   Satisfied: {left <= right}")

    product *= p_adic_absolute_value(x, prime)
product *= abs(x)

print(f"   ∏_p |x|_p · |x|_∞ = {product:.6f} (should be 1.0)")

Compressed Sensing: Recovering Signals from Few Measurements

compressed-sensing

Real-World Motivation

Traditional signal acquisition follows the Nyquist-Shannon sampling theorem: to perfectly reconstruct a signal, you must sample at twice its maximum frequency. But what if the signal is sparse? Compressed sensing, developed by Candès, Romberg, Tao, and Donoho around 2004, shows that sparse signals can be recovered from far fewer samples than Nyquist requires. This revolutionizes MRI scanning, single-pixel cameras, and sensor networks.

Definitions

  • Sparse Signal: A vector \(x \in \mathbb{R}^n\) is \(k\)-sparse if at most \(k\) entries are nonzero.
  • Measurement Matrix \(A\): An \(m \times n\) matrix where \(m \ll n\), used to acquire linear measurements \(y = Ax\).
  • Restricted Isometry Property (RIP): Matrix \(A\) satisfies RIP of order \(k\) if there exists \(\delta_k \in (0,1)\) such that for all \(k\)-sparse \(x\): \((1 - \delta_k)\|x\|_2^2 \leq \|Ax\|_2^2 \leq (1 + \delta_k)\|x\|_2^2\).
  • Basis Pursuit: The convex relaxation: \(\min \|x\|_1\) subject to \(Ax = y\).

Theorem: Exact Recovery via Basis Pursuit

Theorem: Let \(A\) be an \(m \times n\) matrix satisfying RIP of order \(2k\) with \(\delta_{2k} < \sqrt{2} - 1\). Let \(x \in \mathbb{R}^n\) be \(k\)-sparse and \(y = Ax\). Then the solution \(\hat{x}\) to basis pursuit satisfies \(\hat{x} = x\).

Python Code

import numpy as np
from scipy.optimize import linprog

def generate_sparse_signal(n, k):
    """Generate a k-sparse signal in R^n."""
    x = np.zeros(n)
    support = np.random.choice(n, k, replace=False)
    x[support] = np.random.randn(k)
    return x

def generate_measurement_matrix(m, n):
    """Generate a measurement matrix for compressed sensing."""
    return np.random.randn(m, n) / np.sqrt(m)

def basis_pursuit(A, y):
    """Solve basis pursuit: min ||x||_1 subject to Ax = y."""
    m, n = A.shape
    c = np.ones(2 * n)
    A_eq = np.hstack([A, -A])
    b_eq = y
    bounds = [(0, None) for _ in range(2 * n)]
    result = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    if result.success:
        uv = result.x
        return uv[:n] - uv[n:]
    raise RuntimeError("LP solver failed")

def omp(A, y, k):
    """Orthogonal Matching Pursuit (OMP) for sparse recovery."""
    m, n = A.shape
    residual = y.copy()
    support = []
    
    for _ in range(k):
        correlations = np.abs(A.T @ residual)
        new_index = np.argmax(correlations)
        if new_index not in support:
            support.append(new_index)
        A_S = A[:, support]
        x_S = np.linalg.lstsq(A_S, y, rcond=None)[0]
        residual = y - A_S @ x_S
    
    x = np.zeros(n)
    x[support] = x_S
    return x

# Demonstration
np.random.seed(42)
n, k, m = 256, 10, 64
x_true = generate_sparse_signal(n, k)
A = generate_measurement_matrix(m, n)
y = A @ x_true

print(f"Compressed Sensing Demonstration")
print(f"Signal dimension n = {n}, Sparsity k = {k}, Measurements m = {m}")
print(f"Undersampling ratio: {m/n:.2%}")
print(f"\nTrue signal has {np.count_nonzero(x_true)} nonzero entries")

# Recovery using OMP
x_omp = omp(A, y, k)
error_omp = np.linalg.norm(x_omp - x_true) / np.linalg.norm(x_true)
print(f"\nOMP Recovery:")
print(f"  Relative error: {error_omp:.6f}")
print(f"  Recovered sparsity: {np.count_nonzero(np.abs(x_omp) > 1e-6)}")

Epidemiological Modeling: The Mathematics of Disease Spread

epidemiological-modeling

Real-World Motivation

Mathematical epidemiology provides the foundation for understanding and controlling infectious disease outbreaks. From the 1918 influenza pandemic to COVID-19, mathematical models have guided public health interventions, predicted healthcare system strain, and evaluated vaccine strategies.

Definitions

  • SIR Model: \(\frac{dS}{dt} = -\beta SI/N, \frac{dI}{dt} = \beta SI/N - \gamma I, \frac{dR}{dt} = \gamma I\)
  • Basic Reproduction Number \(R_0\): \(R_0 = \beta/\gamma\), the expected number of secondary infections from one infected individual.
  • Herd Immunity Threshold: \(1 - 1/R_0\), the proportion of population that must be immune to prevent sustained transmission.

Theorem: Final Size Relation

Theorem: In the SIR model, the final epidemic size \(R_\infty\) satisfies: \(r_\infty = 1 - s_0 e^{-R_0 r_\infty}\) where \(r_\infty = R_\infty/N\) and \(s_0 = S_0/N\). This transcendental equation determines the total attack rate of the epidemic.

Python Code

import numpy as np
from scipy.integrate import odeint
from scipy.optimize import fsolve

def sir_model(y, t, beta, gamma, N):
    """SIR model differential equations."""
    S, I, R = y
    dSdt = -beta * S * I / N
    dIdt = beta * S * I / N - gamma * I
    dRdt = gamma * I
    return (dSdt, dIdt, dRdt)

def solve_sir(beta, gamma, N, I0, R0=0, t_max=160, dt=0.1):
    """Solve SIR model numerically."""
    S0 = N - I0 - R0
    y0 = (S0, I0, R0)
    t = np.arange(0, t_max, dt)
    solution = odeint(sir_model, y0, t, args=(beta, gamma, N))
    return t, *solution.T

def compute_R0(beta, gamma):
    """Compute basic reproduction number."""
    return beta / gamma

def herd_immunity_threshold(R0):
    """Compute herd immunity threshold."""
    return 1 - 1/R0

def final_size_relation(R0, s0=1.0):
    """Solve final size relation."""
    def equation(r_inf):
        return r_inf - (1 - s0 * np.exp(-R0 * r_inf))
    return fsolve(equation, 0.5)[0]

# Example simulation
N = 1000000
I0 = 100
gamma = 1/14  # 14-day infectious period
beta = 0.5
R0 = compute_R0(beta, gamma)

t, S, I, R = solve_sir(beta, gamma, N, I0)
peak_day = t[np.argmax(I)]
peak_infections = np.max(I)
total_infected = R[-1]

print("Epidemiological Modeling: SIR Model")
print(f"Population: {N:,}")
print(f"R_0 = {R0:.2f}")
print(f"Herd immunity threshold: {herd_immunity_threshold(R0):.1%}")
print(f"\nPeak infections: {peak_infections:,.0f} on day {peak_day:.0f}")
print(f"Total infected: {total_infected:,.0f} ({total_infected/N:.1%})")
print(f"Final size (theory): {final_size_relation(R0)*N:,.0f}")

Control Theory: From Steam Engines to Spacecraft

control-theory

Real-World Motivation

Control theory provides the mathematical framework for designing systems that regulate themselves. From James Watt's centrifugal governor (1788) to modern autopilots and insulin pumps, control systems are everywhere. The field unifies differential equations, linear algebra, and optimization to create feedback mechanisms.

Definitions

  • State-Space Representation: \(\dot{x}(t) = Ax(t) + Bu(t), y(t) = Cx(t) + Du(t)\)
  • Controllability: The pair \((A, B)\) is controllable if for any initial state \(x_0\) and target state \(x_f\), there exists a control \(u(t)\) that drives the system from \(x_0\) to \(x_f\) in finite time.
  • Observability: The pair \((A, C)\) is observable if the initial state can be uniquely determined from the output \(y(t)\).
  • Stability: The system is asymptotically stable if all eigenvalues of \(A\) have negative real parts.

Theorem: Pole Placement and Controllability

Theorem: For a single-input linear system \(\dot{x} = Ax + Bu\), the following are equivalent: (1) The system is controllable; (2) The controllability matrix \(\mathcal{C} = [B \ AB \ A^2B \ \cdots \ A^{n-1}B]\) has full rank \(n\); (3) For any set of desired eigenvalues, there exists a state feedback gain \(K\) such that \(A - BK\) has exactly these eigenvalues.

Python Code

import numpy as np
from scipy.integrate import odeint
from scipy.signal import place_poles
from scipy.linalg import solve_continuous_are

def check_controllability(A, B):
    """Check if (A, B) is controllable."""
    n = A.shape[0]
    C = B.copy()
    for i in range(1, n):
        C = np.hstack([C, np.linalg.matrix_power(A, i) @ B])
    rank = np.linalg.matrix_rank(C)
    return rank == n, rank, C

def lqr(A, B, Q, R):
    """Solve the continuous-time LQR problem."""
    P = solve_continuous_are(A, B, Q, R)
    K = np.linalg.solve(R, B.T @ P)
    return K, P

def simulate_closed_loop(A, B, K, x0, t):
    """Simulate closed-loop system with state feedback u = -Kx."""
    def closed_loop_dynamics(x, t):
        return A @ x - B @ K @ x
    return odeint(closed_loop_dynamics, x0, t)

# Double integrator example: Satellite position control
A = np.array([[0, 1], [0, 0]])
B = np.array([[0], [1]])

print("Control Theory: Double Integrator Example")
print(f"A = \n{A}")
print(f"B = \n{B}")

# Check controllability
is_c, rank_c, C_mat = check_controllability(A, B)
print(f"\nControllability matrix: \n{C_mat}")
print(f"Rank: {rank_c} (system is {'controllable' if is_c else 'NOT controllable'})")

# Design LQR controller
Q = np.array([[10, 0], [0, 1]])
R = np.array([[1]])
K_lqr, P = lqr(A, B, Q, R)
print(f"\nLQR gain K = {K_lqr[0]}")

# Simulate
x0 = np.array([1, 0])
t = np.linspace(0, 10, 1000)
x_lqr = simulate_closed_loop(A, B, K_lqr, x0, t)

print(f"\nSimulation from x0 = {x0}")
print(f"Final state: [{x_lqr[-1,0]:.4f}, {x_lqr[-1,1]:.4f}]")
print(f"Settling time (within 2%): {t[np.where(np.abs(x_lqr[:, 0]) > 0.02)[0][-1] + 1] if len(np.where(np.abs(x_lqr[:, 0]) > 0.02)[0]) > 0 else 0:.2f} seconds")

Tropical Geometry: Algebraic Geometry Over the Min-Plus Semiring

tropical-geometry

Historical Context

Tropical geometry emerged in the late 20th century from several independent sources: computer science (scheduling problems), optimization (network flows), and algebraic geometry. The name "tropical" honors Brazilian mathematician Imre Simon. The field gained prominence through Grigory Mikhalkin's work on enumerative geometry problems.

Definitions

  • Tropical Semiring \(\mathbb{T}\): \(\mathbb{R} \cup \{\infty\}\) with operations: \(x \oplus y = \min(x, y), x \odot y = x + y\)
  • Tropical Polynomial: \(f(x) = \min_i (a_i + i \cdot x)\)
  • Tropical Hypersurface: The set where a tropical polynomial is attained by at least two terms.

Theorem: Fundamental Theorem of Tropical Geometry

Theorem: For a polynomial \(f = \sum_{\alpha} c_\alpha x^\alpha\) over a field with non-Archimedean valuation, the tropical hypersurface \(\text{trop}(V(f))\) equals the corner locus of \(\text{trop}(f)\), and \(\text{trop}(V(f)) = \overline{\text{val}(V(f) \cap (K^*)^n)}\).

Python Code

import numpy as np

def tropical_line(a, b, x):
    """Tropical line: min(a + x, b)"""
    return np.minimum(a + x, b)

def tropical_quadratic(a, b, c, x):
    """Tropical quadratic: min(a + 2x, b + x, c)"""
    return np.minimum(np.minimum(a + 2*x, b + x), c)

Modular Forms: Symmetry at the Heart of Number Theory

modular-forms

Historical Context

Modular forms emerged from the study of elliptic functions in the 19th century. Ramanujan's 1916 paper on the tau function revealed their deep arithmetic significance. The connection between modular forms and elliptic curves—culminating in the Taniyama-Shimura-Weil conjecture proved by Wiles as part of Fermat's Last Theorem—revealed that modular forms encode profound arithmetic information.

Definitions

  • Modular Group \(\Gamma = SL(2, \mathbb{Z})\): The group of \(2 \times 2\) integer matrices with determinant 1, acting on the upper half-plane \(\mathbb{H}\) by \(\gamma(\tau) = \frac{a\tau + b}{c\tau + d}\).
  • Modular Form of Weight \(k\): A holomorphic function \(f: \mathbb{H} \to \mathbb{C}\) satisfying \(f(\gamma(\tau)) = (c\tau + d)^k f(\tau)\) for all \(\gamma \in SL(2, \mathbb{Z})\) and holomorphic at \(\infty\).
  • Cusp Form: A modular form with zero constant term: \(f(\tau) = \sum_{n=1}^{\infty} a_n q^n\) where \(q = e^{2\pi i \tau}\).

Theorem: The Modularity Theorem (Taniyama-Shimura-Weil)

Theorem: Every rational elliptic curve is modular. For every elliptic curve \(E\) over \(\mathbb{Q}\) with conductor \(N\), there exists a weight 2 cusp form \(f \in S_2(\Gamma_0(N))\) such that \(a_p = p + 1 - \#E(\mathbb{F}_p)\) for all primes \(p \nmid N\). Equivalently, \(L(E, s) = L(f, s)\).

Python Code

import numpy as np
import cmath

def compute_q(tau):
    """Compute q = exp(2πiτ)."""
    return cmath.exp(2j * np.pi * tau)

def dedekind_eta(tau, terms=100):
    """Compute the Dedekind eta function."""
    q = compute_q(tau)
    product = 1.0
    q_n = q
    for n in range(1, terms):
        product *= (1 - q_n)
        q_n *= q
        if abs(q_n) < 1e-15:
            break
    q_factor = cmath.exp(2j * np.pi * tau / 24)
    return q_factor * product

def modular_discriminant(tau, terms=50):
    """Compute the modular discriminant Δ(τ) = η(τ)^24."""
    eta = dedekind_eta(tau, terms)
    return eta**24

Information Theory: The Mathematical Foundations of Communication

information-theory

Historical Context

Information theory was born from Claude Shannon's seminal 1948 paper "A Mathematical Theory of Communication" at Bell Labs. His revolutionary insight was that information could be measured quantitatively, with entropy as the fundamental unit (the bit). This framework enabled the digital revolution, from compression algorithms to error-correcting codes to cryptography.

Definitions

  • Information Content: \(I(p) = -\log_2 p\) bits for an event with probability \(p\).
  • Entropy \(H(X)\): \(H(X) = -\sum_{x} p(x) \log_2 p(x)\), measuring uncertainty.
  • Mutual Information \(I(X; Y)\): \(H(X) - H(X|Y)\), measuring shared information.
  • Channel Capacity \(C\): \(C = \max_{p(x)} I(X; Y)\), the maximum reliable communication rate.

Theorem: Shannon's Noisy-Channel Coding Theorem

Theorem: For a discrete memoryless channel with capacity \(C\): (1) For any rate \(R < C\), there exist codes with arbitrarily small error probability; (2) For any rate \(R > C\), the error probability is bounded away from zero.

Python Code

import numpy as np

def binary_entropy(p):
    """Compute binary entropy H_2(p) = -p log p - (1-p) log(1-p)."""
    p = np.array(p)
    result = np.zeros_like(p, dtype=float)
    mask = (p > 0) & (p < 1)
    p_valid = p[mask]
    result[mask] = -p_valid * np.log2(p_valid) - (1 - p_valid) * np.log2(1 - p_valid)
    return result

def entropy_distribution(probs):
    """Compute Shannon entropy of a discrete distribution."""
    probs = np.array(probs)
    probs = probs[probs > 0]
    return -np.sum(probs * np.log2(probs))

def mutual_information(joint_prob):
    """Compute mutual information from joint probability distribution."""
    joint_prob = np.array(joint_prob)
    p_x = np.sum(joint_prob, axis=1)
    p_y = np.sum(joint_prob, axis=0)
    mi = 0.0
    for i in range(len(p_x)):
        for j in range(len(p_y)):
            if joint_prob[i, j] > 0:
                mi += joint_prob[i, j] * np.log2(joint_prob[i, j] / (p_x[i] * p_y[j]))
    return mi

📜 Math History: Carl Friedrich Gauss (1777–1855)

Carl Friedrich Gauss, known as the "Prince of Mathematicians," was born in Brunswick, Germany, in 1777. His mathematical talents were evident from an extraordinarily young age. According to legend, at age three he corrected an error in his father's payroll calculations. At age seven, he astounded his teacher by instantly computing the sum of integers from 1 to 100 by pairing terms (1+100, 2+99, etc.)—a technique now known as the Gaussian summation formula.

Gauss's doctoral dissertation (1799) contained the first rigorous proof of the Fundamental Theorem of Algebra, establishing that every non-constant polynomial equation has at least one complex root. This was a landmark achievement that had eluded mathematicians including Euler and Lagrange.

In 1801, Gauss published his magnum opus "Disquisitiones Arithmeticae," which systematized number theory and introduced concepts that would dominate the field for centuries. He proved the law of quadratic reciprocity (which he called the "golden theorem"), developed the theory of congruences, and laid the foundations for modern algebraic number theory. The book also contained his work on the constructibility of regular polygons—he showed that a regular 17-gon could be constructed with compass and straightedge, the first such discovery since antiquity.

Gauss made equally profound contributions to astronomy and physics. In 1801, he calculated the orbit of the dwarf planet Ceres from limited observational data, enabling astronomers to relocate it after it had disappeared behind the Sun. This achievement brought him international fame and led to his appointment as director of the Göttingen Observatory.

His mathematical contributions span virtually every field: differential geometry (theorema egregium), statistics (least squares method, Gaussian distribution), geodesy, magnetism, and optics. The Gaussian distribution—often called the normal distribution—pervades statistics and probability theory. The unit of magnetic flux density, the gauss, honors his work on terrestrial magnetism.

Gauss was famously meticulous about publishing only polished, rigorous results. His personal notebooks, examined after his death, revealed that he had anticipated many major mathematical developments—including non-Euclidean geometry, elliptic functions, and quaternions—decades before their official discovery. His motto was "few, but ripe" (pauca sed matura). This perfectionism, while ensuring the highest quality in his published work, meant that the mathematical world learned of many discoveries only posthumously.

He died in Göttingen in 1855, leaving a legacy that continues to shape mathematics today. The Gaussian integers, Gaussian curvature, Gaussian elimination, and countless other concepts bear his name—a testament to the breadth and depth of his contributions to human knowledge.

IMO Shortlist Problem: Graph Theory

Problem: Let \(G\) be a connected graph with \(n\) vertices and \(m\) edges. Prove that the number of spanning trees of \(G\) is at most \(\frac{1}{n}\left(\frac{2m}{n-1}\right)^{n-1}\), with equality if and only if \(G\) is a complete graph.

Show Hint

Use Kirchhoff's Matrix-Tree Theorem and consider the eigenvalues of the Laplacian matrix. Apply the AM-GM inequality to relate the product of non-zero eigenvalues to their arithmetic mean.

Show Solution

Solution:

By Kirchhoff's Matrix-Tree Theorem, the number of spanning trees \(\tau(G)\) equals \(\frac{1}{n}\lambda_1 \lambda_2 \cdots \lambda_{n-1}\) where \(0 = \lambda_0 \leq \lambda_1 \leq \cdots \leq \lambda_{n-1}\) are the eigenvalues of the Laplacian matrix \(L = D - A\).

We know that \(\sum_{i=1}^{n-1} \lambda_i = \text{tr}(L) = 2m\) (since the trace equals the sum of degrees).

By the AM-GM inequality: \[\lambda_1 \lambda_2 \cdots \lambda_{n-1} \leq \left(\frac{\lambda_1 + \lambda_2 + \cdots + \lambda_{n-1}}{n-1}\right)^{n-1} = \left(\frac{2m}{n-1}\right)^{n-1}\]

Therefore: \[\tau(G) = \frac{1}{n}\prod_{i=1}^{n-1} \lambda_i \leq \frac{1}{n}\left(\frac{2m}{n-1}\right)^{n-1}\]

Equality holds in AM-GM if and only if \(\lambda_1 = \lambda_2 = \cdots = \lambda_{n-1} = \frac{2m}{n-1}\).

For the complete graph \(K_n\), we have \(m = \binom{n}{2} = \frac{n(n-1)}{2}\), so \(\frac{2m}{n-1} = n\). The Laplacian of \(K_n\) has eigenvalues \(0\) (once) and \(n\) (with multiplicity \(n-1\)), confirming equality.

Conversely, if all non-zero Laplacian eigenvalues equal \(n\), then \(L = nI - J\) where \(J\) is the all-ones matrix. This is exactly the Laplacian of \(K_n\), completing the proof. ∎

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics, defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) with \(z_0 = 0\) remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity—zooming in reveals ever more intricate structures, including miniature copies of the entire set. Despite this complexity, the set is connected (proved by Douady and Hubbard in the 1980s).

Python Code to Generate the Mandelbrot Set

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until divergence for a given c.
    Returns the iteration count (normalized) for coloring.
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n / max_iter
        z = z*z + c
    return 1.0  # Did not diverge

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """
    Generate the Mandelbrot set as a 2D array.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[mask] = max_iter
    return M

# Generate and plot

plt.colorbar(label='Iterations')

plt.xlabel('Re(c)')
plt.ylabel('Im(c)')

plt.show()

  • The main cardioid corresponds to parameters where the iteration converges to a fixed point.
  • The period-2 bulb (the large circle to the left of the cardioid) corresponds to period-2 cycles.
  • Each smaller bulb corresponds to parameters with cycles of different periods.
  • The set is self-similar but not exactly self-similar—miniature copies are slightly distorted.
