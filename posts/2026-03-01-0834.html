Spectral Theory: The Harmonic Analysis of Operators

spectral-theory

Motivation

What can we know about a linear operator without explicitly computing its action on every vector? Spectral theory, born from Fourier's study of heat conduction and developed by Hilbert, von Neumann, and others, reveals that operators can be understood through their "eigenvalues" and "eigenvectors"—even when these don't exist in the classical sense. This framework underlies quantum mechanics, where observables correspond to operators and measurements to eigenvalues. Spectral theory connects algebra, analysis, and physics in profound ways, providing the mathematical foundation for everything from quantum field theory to signal processing.

Definitions

  • Resolvent Set: For a linear operator \(T\) on a Banach space \(X\), the resolvent set \(\rho(T)\) consists of all \(\lambda \in \mathbb{C}\) such that \((T - \lambda I)^{-1}\) exists as a bounded operator.
  • Spectrum: The complement \(\sigma(T) = \mathbb{C} \setminus \rho(T)\). The spectrum generalizes the notion of eigenvalues to infinite-dimensional spaces.
  • Point Spectrum: \(\lambda\) such that \(T - \lambda I\) is not injective (classical eigenvalues).
  • Continuous Spectrum: \(\lambda\) such that \(T - \lambda I\) is injective with dense range but not surjective.
  • Residual Spectrum: \(\lambda\) such that \(T - \lambda I\) is injective but range is not dense.
  • Spectral Radius: \(r(T) = \sup\{|\lambda| : \lambda \in \sigma(T)\}\)
  • Self-Adjoint Operator: On a Hilbert space, \(T\) is self-adjoint if \(T = T^*\), meaning \(\langle Tx, y \rangle = \langle x, Ty \rangle\) for all \(x, y\).

Theorem: The Spectral Theorem

Theorem (Spectral Theorem for Bounded Self-Adjoint Operators): Let \(T\) be a bounded self-adjoint operator on a Hilbert space \(\mathcal{H}\). Then there exists a unique spectral measure \(E\) (a projection-valued measure on the Borel \(\sigma\)-algebra of \(\sigma(T)\)) such that: \[T = \int_{\sigma(T)} \lambda \, dE(\lambda)\]

Corollary (Functional Calculus): For any continuous function \(f\) on \(\sigma(T)\), we can define: \[f(T) = \int_{\sigma(T)} f(\lambda) \, dE(\lambda)\]

Theorem (Spectral Radius Formula): For a bounded operator \(T\) on a Banach space: \[r(T) = \lim_{n \to \infty} \|T^n\|^{1/n}\]

Proof Sketch (Spectral Theorem)

The proof proceeds through several stages. First, one establishes the continuous functional calculus using the Gelfand transform on the C*-algebra generated by \(T\). This allows us to define \(f(T)\) for continuous functions \(f\). The key insight is that the map \(f \mapsto f(T)\) is an isometric *-isomorphism from \(C(\sigma(T))\) to the algebra generated by \(T\).

Next, one extends this to bounded Borel functions using the Riesz representation theorem. For each \(x, y \in \mathcal{H}\), the map \(f \mapsto \langle f(T)x, y \rangle\) defines a bounded linear functional on \(C(\sigma(T))\), hence a complex measure \(\mu_{x,y}\). The spectral measure \(E\) is then defined by \(\langle E(S)x, y \rangle = \mu_{x,y}(S)\) for Borel sets \(S\).

The spectral decomposition \(T = \int \lambda \, dE(\lambda)\) follows from approximating the identity function by simple functions. The uniqueness of \(E\) follows from its construction via the Riesz representation.

Notation Guide

  • \(\sigma(T)\): Spectrum of operator \(T\)
  • \(\rho(T)\): Resolvent set of \(T\)
  • \(r(T)\): Spectral radius of \(T\)
  • \(T^*\): Adjoint of operator \(T\)
  • \(E(S)\): Spectral projection associated with Borel set \(S\)
  • \(R_\lambda(T) = (T - \lambda I)^{-1}\): Resolvent operator
  • \(\mathcal{B}(\mathcal{H})\): Space of bounded operators on Hilbert space \(\mathcal{H}\)
  • \(C^*(T)\): C*-algebra generated by \(T\)

Python Code

import numpy as np
from numpy.linalg import eig, eigvals, norm
from scipy.linalg import expm, sqrtm
import matplotlib.pyplot as plt

class SpectralAnalyzer:
    """Tools for spectral analysis of matrices (finite-dimensional case)."""
    
    def __init__(self, matrix):
        self.A = np.array(matrix, dtype=complex)
        self.n = self.A.shape[0]
        self.eigenvalues, self.eigenvectors = eig(self.A)
        idx = np.argsort(self.eigenvalues.real)
        self.eigenvalues = self.eigenvalues[idx]
        self.eigenvectors = self.eigenvectors[:, idx]
    
    def spectral_radius(self):
        return np.max(np.abs(self.eigenvalues))
    
    def functional_calculus(self, f):
        f_eigenvalues = np.array([f(lam) for lam in self.eigenvalues])
        f_D = np.diag(f_eigenvalues)
        return self.eigenvectors @ f_D @ np.linalg.inv(self.eigenvectors)

# Example
A = np.array([[2, 1], [1, 2]], dtype=float)
analyzer = SpectralAnalyzer(A)
print(f"Spectral radius: {analyzer.spectral_radius():.4f}")
exp_A = analyzer.functional_calculus(np.exp)

Category Theory: The Yoneda Lemma

category-theory

Motivation

How can we understand a mathematical object by studying its relationships with other objects? The Yoneda lemma, proved by Nobuo Yoneda in 1954, provides a profound answer: an object is completely determined by its network of relationships (morphisms) to all other objects. This insight, seemingly abstract, has revolutionized modern mathematics, providing the foundation for algebraic geometry, homotopy theory, and theoretical computer science.

Definitions

  • Category: A category \(\mathcal{C}\) consists of a class of objects \(\text{Ob}(\mathcal{C})\), morphisms \(\text{Hom}(X, Y)\) for each pair of objects, composition, and identity morphisms.
  • Functor: A map \(F: \mathcal{C} \to \mathcal{D}\) preserving composition and identities.
  • Natural Transformation: A family of morphisms \(\alpha_X: F(X) \to G(X)\) satisfying naturality.
  • Hom-Functor: For fixed \(A\), \(h_A = \text{Hom}(-, A): \mathcal{C}^{\text{op}} \to \mathbf{Set}\).

Theorem: The Yoneda Lemma

Theorem (Yoneda Lemma): Let \(F: \mathcal{C}^{\text{op}} \to \mathbf{Set}\) be a functor and \(A \in \mathcal{C}\). There is a natural isomorphism: \[\text{Nat}(h_A, F) \cong F(A)\]

Corollary (Yoneda Embedding): The functor \(y: \mathcal{C} \to [\mathcal{C}^{\text{op}}, \mathbf{Set}]\) sending \(A \mapsto h_A\) is fully faithful.

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\): Categories
  • \(\text{Hom}(X, Y)\): Morphisms from \(X\) to \(Y\)
  • \(h_A = \text{Hom}(-, A)\): Representable presheaf
  • \(\text{Nat}(F, G)\): Natural transformations
  • \([\mathcal{C}, \mathcal{D}]\): Functor category

Elliptic Curves: Arithmetic and Geometry

elliptic-curves

Motivation

Why do certain Diophantine equations have finitely many solutions while others have infinitely many? Elliptic curves—smooth cubic curves with a distinguished point—provide a profound answer. These deceptively simple objects bridge number theory, algebraic geometry, and complex analysis. They played a central role in Wiles's proof of Fermat's Last Theorem and form the basis of modern cryptography.

Definitions

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point \(O\). Over a field \(K\) with char \(\neq 2, 3\), can be written in Weierstrass form: \(y^2 = x^3 + ax + b\) with discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\).
  • Group Law: The points \(E(K)\) form an abelian group with identity \(O\). For points \(P, Q\), the line through them intersects the curve at a third point \(R\); then \(P + Q\) is the reflection of \(R\) over the x-axis.
  • j-invariant: \(j(E) = 1728 \frac{4a^3}{4a^3 + 27b^2}\) classifies elliptic curves up to isomorphism.

Theorem: Mordell-Weil Theorem

Theorem (Mordell-Weil): Let \(E\) be an elliptic curve over a number field \(K\). Then \(E(K)\) is a finitely generated abelian group: \[E(K) \cong E(K)_{\text{tors}} \times \mathbb{Z}^r\]

where \(r\) is the rank of \(E\) over \(K\).

Theorem (Hasse Bound): For an elliptic curve \(E\) over a finite field \(\mathbb{F}_q\): \[|E(\mathbb{F}_q)| = q + 1 - a_q\] where \(|a_q| \leq 2\sqrt{q}\).

Notation Guide

  • \(E\): Elliptic curve
  • \(E(K)\): K-rational points of \(E\)
  • \(O\): Identity element (point at infinity)
  • \(j(E)\): j-invariant of \(E\)
  • \(r\): Rank of \(E(K)\)
  • \(E[n]\): n-torsion subgroup

Quantum Computing: The Mathematics of Qubits

quantum-computing

Real-World Motivation

Can we compute exponentially faster by harnessing quantum mechanics? Quantum computing promises to revolutionize cryptography, drug discovery, optimization, and machine learning by exploiting quantum superposition and entanglement. Shor's algorithm can factor integers in polynomial time—threatening RSA encryption—while Grover's algorithm provides quadratic speedup for unstructured search.

Definitions

  • Qubit: A quantum bit, represented as a unit vector in \(\mathbb{C}^2\). The state \(|\psi\rangle = \alpha|0\rangle + \beta|1\rangle\) where \(|\alpha|^2 + |\beta|^2 = 1\).
  • Hilbert Space: For \(n\) qubits, the state space is \((\mathbb{C}^2)^{\otimes n} \cong \mathbb{C}^{2^n}\).
  • Quantum Gate: A unitary operator \(U\) satisfying \(U^*U = UU^* = I\).
  • Pauli Matrices: Fundamental single-qubit gates: \[X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad Y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}, \quad Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}\]
  • Hadamard Gate: Creates superposition: \[H = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\]
  • Entanglement: A state is entangled if it cannot be written as a tensor product.

Theorem: Universal Quantum Computation

Theorem (Solovay-Kitaev): The gates \(\{H, T, \text{CNOT}\}\) form a universal gate set for quantum computation.

Theorem (No-Cloning): There is no quantum operation that can copy an arbitrary unknown quantum state.

Notation Guide

  • \(|\psi\rangle\): Quantum state (ket)
  • \(\langle\psi|\): Dual state (bra)
  • \(\otimes\): Tensor product
  • \(U^*\) or \(U^\dagger\): Adjoint
  • \(|0\rangle, |1\rangle\): Computational basis

Mathematical Epidemiology: SIR Models

epidemiology

Real-World Motivation

How do infectious diseases spread through populations, and how can we control them? The SIR model and its extensions form the foundation of mathematical epidemiology, connecting differential equations to real-world interventions like vaccination and social distancing.

Definitions

  • SIR Model: Compartmental model with Susceptible \(S(t)\), Infected \(I(t)\), and Recovered \(R(t)\).
  • Basic Reproduction Number (R₀): Average secondary infections from one infected individual: \(R_0 = \frac{\beta}{\gamma}\).
  • Transmission Rate (β): Rate of new infections through contact.
  • Recovery Rate (γ): Rate of recovery, with average infectious period \(1/\gamma\).
  • Herd Immunity Threshold: \(p_c = 1 - \frac{1}{R_0}\).

Theorem: Epidemic Threshold

Theorem (Epidemic Threshold): For the SIR model:

  • If \(R_0 \leq 1\), the disease dies out
  • If \(R_0 > 1\), an epidemic occurs

Theorem (Final Size Equation): Let \(s_\infty = S(\infty)/N\). Then: \[s_\infty = e^{-R_0(1 - s_\infty)}\]

Notation Guide

  • N: Total population size
  • S(t), I(t), R(t): Compartment sizes
  • β: Transmission rate
  • γ: Recovery rate
  • R₀: Basic reproduction number
  • p_c: Herd immunity threshold

Financial Mathematics: The Black-Scholes Model

financial-mathematics

Real-World Motivation

How can we price financial derivatives in a way that eliminates arbitrage opportunities? The Black-Scholes-Merton model, developed in 1973, revolutionized finance by providing a mathematical framework for option pricing. This work earned Merton and Scholes the 1997 Nobel Prize in Economics.

Definitions

  • Geometric Brownian Motion: \(dS_t = \mu S_t dt + \sigma S_t dW_t\) where \(\mu\) is drift, \(\sigma\) is volatility.
  • European Call Option: Right to buy at strike \(K\) at maturity \(T\). Payoff: \(\max(S_T - K, 0)\).
  • Risk-Neutral Measure: Probability measure \(\mathbb{Q}\) where discounted asset prices are martingales.
  • Greeks: Sensitivities: \(\Delta = \frac{\partial V}{\partial S}\), \(\Gamma = \frac{\partial^2 V}{\partial S^2}\), \(\Theta = \frac{\partial V}{\partial t}\), \(\nu = \frac{\partial V}{\partial \sigma}\).

Theorem: Black-Scholes Formula

Theorem (Black-Scholes PDE): The option price \(V(S, t)\) satisfies: \[\frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0\]

Theorem (Black-Scholes Formula): The price of a European call option is: \[C(S, t) = S N(d_1) - Ke^{-r(T-t)} N(d_2)\]

where \(d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}\) and \(d_2 = d_1 - \sigma\sqrt{T-t}\).

Theorem (Put-Call Parity): \(C - P = S - Ke^{-r(T-t)}\).

Notation Guide

  • \(S_t\): Stock price
  • \(K\): Strike price
  • \(T\): Maturity
  • \(r\): Risk-free rate
  • \(\sigma\): Volatility
  • \(N(x)\): Standard normal CDF
  • \(\Delta, \Gamma, \Theta, \nu\): Greeks

Ramsey Theory: Order from Chaos

ramsey-theory

Historical Context

How large must a structure be to guarantee the existence of a particular substructure? This question, first systematically studied by Frank Ramsey in 1928, led to a branch of mathematics that reveals unavoidable patterns in sufficiently large systems. Ramsey's theorem showed that complete disorder is impossible.

Definitions

  • Ramsey Number R(s, t): The smallest \(n\) such that any 2-coloring of \(K_n\) contains a red \(K_s\) or blue \(K_t\).
  • Complete Graph K_n: Graph with \(n\) vertices where every pair is connected.
  • Monochromatic Subgraph: Subgraph where all edges have the same color.

Theorem: Ramsey's Theorem

Theorem (Ramsey, 1930): For any \(s, t\), there exists \(R(s, t)\) such that every 2-coloring of \(K_{R(s,t)}\) contains a red \(K_s\) or blue \(K_t\).

Upper Bound: \(R(s, t) \leq \binom{s+t-2}{s-1}\)

Lower Bound (Erdős): \(R(s, s) \geq (1 + o(1)) \frac{s}{e\sqrt{2}} 2^{s/2}\)

Notation Guide

  • \(R(s, t)\): Ramsey number
  • \(K_n\): Complete graph on n vertices
  • \(\binom{n}{k}\): Binomial coefficient

Tropical Geometry: The Geometry of the Minimum

tropical-geometry

Historical Context

What happens to algebraic geometry when we replace addition with minimum and multiplication with addition? Tropical geometry, developed since the 1990s, transforms complex algebraic varieties into piecewise-linear objects while preserving essential geometric information.

Definitions

  • Tropical Semiring (\(\mathbb{T}\)):\u003c/strong> \(\mathbb{R} \cup \{\infty\}\) with \(a \oplus b = \min(a, b)\) and \(a \odot b = a + b\).
  • Tropical Polynomial: \(f(x) = \bigoplus_{i} (a_i \odot x^{\odot i}) = \min_i (a_i + i \cdot x)\).
  • Tropical Hypersurface: Set where minimum is attained by at least two terms.
  • Newton Polygon: Convex hull of points \((i, a_i)\) for polynomial coefficients.

Theorem: Tropical Curve Geometry

Theorem (Structure): A tropical plane curve is a finite weighted graph with:

  • Edges with rational slopes
  • Balancing condition at vertices
  • Positive integer edge weights

Theorem (Tropical Bezout): Two tropical curves of degrees \(d_1\) and \(d_2\) intersect in \(d_1 \cdot d_2\) points (counted with multiplicity).

Notation Guide

  • \(\mathbb{T}\): Tropical semiring
  • \(\oplus\): Tropical addition (minimum)
  • \(\odot\): Tropical multiplication (addition)
  • \(x^{\odot n}\): Tropical power (n·x)

Information Theory: Entropy and Communication

information-theory

Historical Context

Claude Shannon's 1948 paper "A Mathematical Theory of Communication" founded information theory by answering how much information can be transmitted reliably through a noisy channel. His concept of entropy measures uncertainty and provides fundamental limits for compression.

Definitions

  • Entropy: \(H(X) = -\sum_{x} p(x) \log_2 p(x)\) (average uncertainty, in bits).
  • Joint Entropy: \(H(X, Y) = -\sum_{x,y} p(x,y) \log_2 p(x,y)\).
  • Conditional Entropy: \(H(Y|X) = \sum_x p(x) H(Y|X=x)\).
  • Mutual Information: \(I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)\).
  • Channel Capacity: \(C = \max_{p(x)} I(X; Y)\).

Theorem: Shannon's Theorems

Theorem (Source Coding): A source with entropy \(H\) can be compressed to \(H + \epsilon\) bits per symbol, but not to \(H - \epsilon\), for any \(\epsilon > 0\).

Theorem (Noisy-Channel Coding): For a channel with capacity \(C\), reliable communication is possible at any rate \(R < C\), and impossible for \(R > C\).

Theorem (Data Processing Inequality): For a Markov chain \(X \to Y \to Z\): \(I(X; Z) \leq I(X; Y)\).

Notation Guide

  • \(H(X)\): Entropy of random variable X
  • \(H(X|Y)\): Conditional entropy
  • \(I(X; Y)\): Mutual information
  • \(D_{KL}(P \| Q)\): KL divergence
  • \(C\): Channel capacity
  • \(h(p)\): Binary entropy function

📜 Math History: The Development of Group Theory

The concept of a group, now fundamental to modern mathematics, emerged from three distinct sources in the 19th century: the theory of algebraic equations, geometry, and number theory. This convergence of ideas created one of the most powerful unifying concepts in mathematics.

The story begins with Évariste Galois (1811–1832), whose work on the solvability of polynomial equations laid the foundation for group theory. Galois discovered that the solvability of an equation by radicals depends on the structure of a group associated with the equation—now called the Galois group. In his famous letter written the night before his fatal duel, Galois sketched the connection between field extensions and groups, though his work remained obscure until Liouville published it in 1846.

Independently, geometry was being transformed. Augustin-Louis Cauchy developed the theory of permutations, introducing the notation and terminology still used today. Felix Klein's Erlangen Program of 1872 proposed that geometries could be classified by their transformation groups—a revolutionary idea that unified Euclidean, projective, and non-Euclidean geometries under a common framework.

The abstract definition of a group emerged gradually. Cayley's theorem (1854) showed that every group is isomorphic to a group of permutations. Heinrich Weber gave the first abstract definition in his 1882 textbook, and the modern axiomatic approach was established by the early 20th century through the work of von Dyck, Frobenius, and others.

The classification of finite simple groups, completed in 2004 after decades of work by hundreds of mathematicians, stands as one of the greatest achievements in the history of mathematics. This "enormous theorem" shows that all finite simple groups fall into 18 infinite families or are one of 26 sporadic groups—including the Monster group with approximately \(8 \times 10^{53}\) elements.

Today, group theory permeates every branch of mathematics and physics. It is essential for understanding symmetry in particle physics, crystallography, coding theory, and cryptography. The journey from Galois's night of frantic writing to the modern classification theorem illustrates how abstract mathematical concepts, developed for their intrinsic beauty, find profound applications across science.

🎯 Problem Corner

Putnam Competition Problem

Problem: Let \(n\) be a positive integer. Suppose that \(A\) is an \(n \times n\) matrix with real entries such that \(A^3 = A + I\), where \(I\) is the \(n \times n\) identity matrix. Prove that \(\det(A) > 0\).

Hint

Consider the eigenvalues of \(A\). What can you say about the polynomial \(p(x) = x^3 - x - 1\) and its roots? How does this relate to the determinant?

Solution

Step 1: Let \(\lambda\) be an eigenvalue of \(A\) with eigenvector \(v \neq 0\). Then: \[A^3 v = A v + v\] \[\lambda^3 v = \lambda v + v\] \[\lambda^3 - \lambda - 1 = 0\]

So every eigenvalue of \(A\) is a root of \(p(x) = x^3 - x - 1\).

Step 2: Analyze \(p(x) = x^3 - x - 1\). We have \(p'(x) = 3x^2 - 1\), which has roots at \(x = \pm 1/\sqrt{3}\). Evaluating: \[p(1/\sqrt{3}) = \frac{1}{3\sqrt{3}} - \frac{1}{\sqrt{3}} - 1 = \frac{1 - 3}{3\sqrt{3}} - 1 = -\frac{2}{3\sqrt{3}} - 1 < 0\] \[p(-1/\sqrt{3}) = -\frac{1}{3\sqrt{3}} + \frac{1}{\sqrt{3}} - 1 = \frac{-1 + 3}{3\sqrt{3}} - 1 = \frac{2}{3\sqrt{3}} - 1 < 0\]

Since \(p(x) \to +\infty\) as \(x \to +\infty\) and \(p(x) \to -\infty\) as \(x \to -\infty\), and \(p\) has a local maximum and minimum both below zero, \(p\) has exactly one real root \(r\) with \(r > 1\) (since \(p(1) = -1 < 0\) and \(p(2) = 5 > 0\)).

Step 3: The other two roots of \(p\) are complex conjugates \(\alpha\) and \(\bar{\alpha}\). Since \(p\) has real coefficients, if \(\alpha\) is a root, so is \(\bar{\alpha}\).

Step 4: By Vieta's formulas, the product of all roots is \(r \cdot \alpha \cdot \bar{\alpha} = 1\) (the constant term with sign). Since \(r > 0\) and \(\alpha \bar{\alpha} = |\alpha|^2 > 0\), we have \(r > 0\).

Step 5: The determinant is the product of eigenvalues (with algebraic multiplicities). Each eigenvalue is either \(r > 0\) or one of a complex conjugate pair \(\alpha, \bar{\alpha}\). The product of each conjugate pair is \(|\alpha|^2 > 0\). Therefore \(\det(A) > 0\). ∎

🎨 Visualization of the Day

Mandelbrot Set Exploration

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded. Its intricate boundary reveals infinite complexity at every scale.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute Mandelbrot iterations for complex number c."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid of complex numbers
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C)

# Visualization
plt.figure(figsize=(12, 9))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower', interpolation='bilinear')
plt.colorbar(label='Iterations')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.title('Mandelbrot Set')
plt.tight_layout()
plt.savefig('mandelbrot.png', dpi=150)
plt.show()
