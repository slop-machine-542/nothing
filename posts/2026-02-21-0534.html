Harmonic Analysis: From Fourier Series to Modern Applications

harmonic-analysis

Motivation

Harmonic analysis studies the representation of functions or signals as superpositions of basic waves. Originating from Fourier's study of heat conduction in the early 19th century, the field has grown to encompass Fourier series, Fourier transforms, and their generalizations to locally compact groups. The central insight—that complex functions can be decomposed into simpler oscillatory components—underlies modern signal processing, quantum mechanics, and number theory.

Definitions

  • Fourier Series: For a periodic function \(f\) on \([-\pi, \pi]\), the Fourier series is \(\sum_{n=-\infty}^{\infty} \hat{f}(n) e^{inx}\) where \(\hat{f}(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(x) e^{-inx} dx\).
  • Fourier Transform: For \(f \in L^1(\mathbb{R}^n)\), \(\hat{f}(\xi) = \int_{\mathbb{R}^n} f(x) e^{-2\pi i x \cdot \xi} dx\).
  • Convolution: \((f * g)(x) = \int f(y)g(x-y)dy\), which satisfies \(\widehat{f * g} = \hat{f} \cdot \hat{g}\).
  • Plancherel's Theorem: The Fourier transform extends to a unitary operator on \(L^2(\mathbb{R}^n)\).

Theorem: The Uncertainty Principle

Theorem (Heisenberg-Pauli-Weyl): For any \(f \in L^2(\mathbb{R})\) with \(\|f\|_2 = 1\): \[\left(\int_{-\infty}^{\infty} x^2 |f(x)|^2 dx\right) \left(\int_{-\infty}^{\infty} \xi^2 |\hat{f}(\xi)|^2 d\xi\right) \geq \frac{1}{16\pi^2}\] Equality holds if and only if \(f(x) = C e^{-ax^2}\) for some \(a > 0\).

Proof Sketch

Assume \(f\) is Schwartz (rapidly decreasing). Using integration by parts and the Cauchy-Schwarz inequality: \[\|f\|_2^2 = \int |f|^2 = -\int x \frac{d}{dx}|f|^2 = -2\text{Re}\int x \overline{f} f'\] By Cauchy-Schwarz: \(\|f\|_2^4 \leq 4 \int x^2 |f|^2 \int |f'|^2\). Since \(\widehat{f'}(\xi) = 2\pi i \xi \hat{f}(\xi)\), Plancherel gives \(\|f'\|_2^2 = 4\pi^2 \int \xi^2 |\hat{f}(\xi)|^2 d\xi\). Combining yields the result. Equality in Cauchy-Schwarz requires \(f'(x) = c x f(x)\), solved by Gaussians.

Notation Guide

  • \(\hat{f}, \mathcal{F}(f)\) — Fourier transform of \(f\)
  • \(f * g\) — Convolution
  • \(L^p(\mathbb{R}^n)\) — Lebesgue spaces
  • \(\mathcal{S}(\mathbb{R}^n)\) — Schwartz space
  • \(\mathcal{F}^{-1}\) — Inverse Fourier transform

import matplotlib.pyplot as plt
from numpy.fft import fft, ifft, fftshift, ifftshift, fftfreq

def fourier_series_coeffs(f, n_terms, period=2*np.pi):
    """Compute Fourier series coefficients for periodic function f."""
    N = 4 * n_terms
    x = np.linspace(0, period, N, endpoint=False)
    y = f(x)
    coeffs = fft(y) / N
    return coeffs[:n_terms]

def reconstruct_fourier(coeffs, x, period=2*np.pi):
    """Reconstruct function from Fourier coefficients."""
    result = np.zeros_like(x, dtype=complex)
    n = len(coeffs)
    for k in range(n):
        result += coeffs[k] * np.exp(2j * np.pi * k * x / period)
        if k > 0:
            result += np.conj(coeffs[k]) * np.exp(-2j * np.pi * k * x / period)
    return np.real(result)

def uncertainty_product(f, x, xi):
    """Compute the uncertainty product for a function."""
    dx = x[1] - x[0]
    dxi = xi[1] - xi[0]
    
    # Normalize
    norm_f = np.sqrt(np.trapz(np.abs(f)**2, x))
    f_norm = f / norm_f
    
    # Fourier transform
    f_hat = fftshift(fft(ifftshift(f_norm))) * np.sqrt(dx / (2*np.pi))
    f_hat_norm = f_hat / np.sqrt(np.trapz(np.abs(f_hat)**2, xi))
    
    # Variances
    x_mean = np.trapz(x * np.abs(f_norm)**2, x)
    xi_mean = np.trapz(xi * np.abs(f_hat_norm)**2, xi)
    
    var_x = np.trapz((x - x_mean)**2 * np.abs(f_norm)**2, x)
    var_xi = np.trapz((xi - xi_mean)**2 * np.abs(f_hat_norm)**2, xi)
    
    return var_x * var_xi

Approximation Theory: Best Approximations and Polynomial Interpolation

approximation-theory

Motivation

Approximation theory addresses how functions can be efficiently approximated using simpler functions, typically polynomials or rational functions. The field originated from practical needs in computation and has deep connections to functional analysis, harmonic analysis, and numerical analysis. Questions about the rate of approximation, optimal approximants, and the stability of approximation schemes remain active areas of research.

Definitions

  • Best Approximation: For a function \(f\) and a subspace \(S\), \(p^* \in S\) is a best approximation if \(\|f - p^*\| = \inf_{p \in S} \|f - p\|\).
  • Chebyshev Polynomials: \(T_n(x) = \cos(n \arccos x)\) for \(x \in [-1, 1]\), satisfying the recurrence \(T_{n+1}(x) = 2xT_n(x) - T_{n-1}(x)\).
  • Modulus of Continuity: \(\omega(f, \delta) = \sup_{|x-y| \leq \delta} |f(x) - f(y)|\).
  • Jackson's Theorem: Bounds the best polynomial approximation error in terms of smoothness.

Theorem: Chebyshev Equioscillation Theorem

Theorem: Let \(f \in C[a, b]\) and let \(P_n\) be the space of polynomials of degree at most \(n\). Then \(p^* \in P_n\) is the unique best uniform approximation to \(f\) if and only if there exist \(n + 2\) points \(a \leq x_0 < x_1 < \cdots < x_{n+1} \leq b\) such that: \[f(x_i) - p^*(x_i) = (-1)^i \sigma \|f - p^*\|_{\infty}, \quad i = 0, 1, \ldots, n+1\] where \(\sigma = \pm 1\). That is, the error equioscillates between \(\pm\|f - p^*\|_{\infty}\) at \(n+2\) points.

Proof Sketch

Necessity: If the error doesn't equioscillate at \(n+2\) points, we can construct a better approximation by adjusting the polynomial to reduce the maximum error.

Sufficiency: Suppose \(p^*\) equioscillates but \(q\) is a better approximation. Then \(p^* - q\) alternates in sign at the \(n+2\) equioscillation points, implying it has at least \(n+1\) zeros. But \(p^* - q\) has degree at most \(n\), so \(p^* = q\).

Notation Guide

  • \(P_n\) — Space of polynomials of degree \(\leq n\)
  • \(T_n(x)\) — Chebyshev polynomial of degree \(n\)
  • \(E_n(f)\) — Best approximation error: \(\inf_{p \in P_n} \|f - p\|_{\infty}\)
  • \(\omega(f, \delta)\) — Modulus of continuity
  • \(L_n\) — Lebesgue constant for interpolation

def best_uniform_approximation(f, n, a=-1, b=1):
    """Find best uniform polynomial approximation using Remez algorithm."""
    # Initial Chebyshev nodes
    x = chebyshev_nodes(n + 1, a, b)
    
    for iteration in range(50):
        # Solve linear system for polynomial coefficients and error
        A = np.zeros((n + 2, n + 2))
        for i in range(n + 2):
            for j in range(n + 1):
                A[i, j] = x[i]**j
            A[i, n + 1] = (-1)**i
        
        b_vec = f(x)
        try:
            sol = np.linalg.solve(A, b_vec)
        except np.linalg.LinAlgError:
            break
        
        coeffs = sol[:-1]
        E = sol[-1]
        
        # Find error extrema
        def error(x):
            return f(x) - np.polyval(coeffs[::-1], x)
        
        x_test = np.linspace(a, b, 1000)
        err_test = error(x_test)
        
        # Find approximate extrema
        extrema_idx = []
        for i in range(1, len(err_test) - 1):
            if (err_test[i] > err_test[i-1] and err_test[i] > err_test[i+1]) or \

        if len(extrema_idx) < n + 2:
            break
        
        # Update nodes
        x = np.sort(np.concatenate([[a], x_test[extrema_idx], [b]]))
        x = np.unique(np.clip(x, a, b))
        if len(x) > n + 2:
            x = np.linspace(a, b, n + 2)

def lebesgue_constant(n, nodes, a=-1, b=1):
    """Compute Lebesgue constant for given interpolation nodes."""
    x_test = np.linspace(a, b, 1000)
    L = np.zeros_like(x_test)
    
    for i in range(len(x_test)):
        x = x_test[i]
        lagrange_sum = 0
        for k in range(len(nodes)):
            # Lagrange basis polynomial
            L_k = 1
            for j in range(len(nodes)):
                if j != k:
                    L_k *= (x - nodes[j]) / (nodes[k] - nodes[j])
            lagrange_sum += abs(L_k)
        L[i] = lagrange_sum
    
    return np.max(L)

Knot Theory: Invariants and the Jones Polynomial

knot-theory

Motivation

Knot theory studies embeddings of circles in three-dimensional space. What began as a model for atoms in the 19th century has evolved into a rich field with connections to topology, quantum field theory, and molecular biology. The fundamental question—when are two knots equivalent?—remains computationally challenging, leading to the development of powerful invariants.

Definitions

  • Knot: An embedding of \(S^1\) into \(\mathbb{R}^3\) (or \(S^3\)).
  • Link: An embedding of disjoint circles into \(\mathbb{R}^3\).
  • Knot Diagram: A planar projection of a knot with over/under crossings indicated.
  • Reidemeister Moves: Three local moves that generate all ambient isotopies of knots.
  • Kauffman Bracket: A Laurent polynomial invariant of framed links defined by skein relations.

Theorem: The Jones Polynomial is a Knot Invariant

Theorem: There exists a unique invariant \(V_L(t)\) assigning to each oriented link \(L\) a Laurent polynomial in \(t^{1/2}\) satisfying:

  1. \(V_{\text{unknot}}(t) = 1\)
  2. The skein relation: \(t^{-1}V_{L_+}(t) - tV_{L_-}(t) = (t^{1/2} - t^{-1/2})V_{L_0}(t)\)

where \(L_+, L_-, L_0\) are links identical except at one crossing as shown:

\(L_+\): positive crossing, \(L_-\): negative crossing, \(L_0\): smoothed crossing.

Proof Sketch

The Jones polynomial can be constructed from the Kauffman bracket \(\langle L \rangle\) via: \[V_L(t) = (-A^{-3})^{w(L)} \langle L \rangle|_{A = t^{-1/4}}\] where \(w(L)\) is the writhe. The Kauffman bracket is defined by: \[\langle \bigcirc \rangle = 1, \quad \langle L \cup \bigcirc \rangle = (-A^2 - A^{-2})\langle L \rangle\] and the skein relation: \[\langle \crossing \rangle = A\langle \smoothing \rangle + A^{-1}\langle \hsmoothing \rangle\] Invariance under Reidemeister moves follows from direct computation.

Notation Guide

  • \(K, L\) — Knot or link
  • \(V_K(t)\) — Jones polynomial
  • \(\langle K \rangle\) — Kauffman bracket
  • \(w(K)\) — Writhe (signed crossing number)
  • \(\Delta_K(t)\) — Alexander polynomial
  • \(c(K)\) — Crossing number

Game Theory: Nash Equilibrium and Mechanism Design

game-theory

Motivation

Game theory provides a mathematical framework for analyzing strategic interactions among rational agents. From economics and political science to biology and computer science, game-theoretic concepts illuminate how individuals make decisions when their outcomes depend on others' choices. The Nash equilibrium, perhaps the most celebrated concept in game theory, predicts stable outcomes where no player can benefit by unilaterally changing strategy.

Definitions

  • Normal Form Game: A tuple \((N, (S_i)_{i \in N}, (u_i)_{i \in N})\) where \(N\) is the set of players, \(S_i\) is player \(i\)'s strategy set, and \(u_i: S \to \mathbb{R}\) is the payoff function.
  • Nash Equilibrium: A strategy profile \(s^* = (s_1^*, \ldots, s_n^*)\) such that for each player \(i\): \[u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*) \quad \forall s_i \in S_i\]
  • Mixed Strategy: A probability distribution over pure strategies.
  • Dominant Strategy: A strategy that is optimal regardless of opponents' choices.

Theorem: Nash's Existence Theorem

Theorem: Every finite normal-form game has at least one Nash equilibrium in mixed strategies. That is, for any game with finitely many players and finitely many pure strategies per player, there exists a mixed strategy profile where no player can improve their expected payoff by unilaterally deviating.

Proof Sketch

Define the best-response correspondence \(BR: \Delta \to \Delta\) where \(BR_i(\sigma_{-i}) = \arg\max_{\sigma_i} u_i(\sigma_i, \sigma_{-i})\). A Nash equilibrium is a fixed point of \(BR\). By Kakutani's fixed-point theorem:

  1. \(\Delta\) (the product of strategy simplexes) is compact and convex.
  2. \(BR(\sigma)\) is non-empty and convex for all \(\sigma\).
  3. \(BR\) has a closed graph.

Therefore, \(BR\) has a fixed point, which is a Nash equilibrium.

Notation Guide

  • \(N = \{1, 2, \ldots, n\}\) — Set of players
  • \(S_i\) — Strategy set for player \(i\)
  • \(S = S_1 \times \cdots \times S_n\) — Strategy profiles
  • \(s_{-i}\) — Strategies of all players except \(i\)
  • \(\Delta(S_i)\) — Mixed strategies for player \(i\)
  • \(u_i(s)\) — Payoff function for player \(i\)
  • \(BR_i\) — Best response correspondence

import numpy as np
from scipy.optimize import minimize
from itertools import product

class NormalFormGame:
    """Represents a finite normal-form game."""
    
    def __init__(self, payoff_matrices):
        """
        payoff_matrices: list of n-dimensional arrays, one per player
        """
        self.payoff_matrices = payoff_matrices
        self.n_players = len(payoff_matrices)
        self.n_strategies = payoff_matrices[0].shape
    
    def expected_payoff(self, player, strategies):
        """Compute expected payoff for player given mixed strategies."""
        # strategies is a list of probability distributions
        result = 0
        for pure_profile in product(*[range(n) for n in self.n_strategies]):
            prob = np.prod([strategies[i][pure_profile[i]] for i in range(self.n_players)])
            result += prob * self.payoff_matrices[player][pure_profile]
        return result
    
    def best_response(self, player, opponent_strategies):
        """Find best response for player against opponent strategies."""
        n = self.n_strategies[player]
        payoffs = []
        for s in range(n):
            strat = [np.zeros(self.n_strategies[i]) for i in range(self.n_players)]
            strat[player] = np.eye(n)[s]
            for i, opp_strat in enumerate(opponent_strategies):
                if i != player:
                    strat[i] = opp_strat
            payoffs.append(self.expected_payoff(player, strat))
        return np.argmax(payoffs)

Queueing Theory: From Erlang to Modern Networks

queueing-theory

Motivation

Queueing theory, initiated by A.K. Erlang in 1909 to design telephone networks, provides mathematical models for systems where demand exceeds immediate service capacity. Today it underpins the design of computer networks, call centers, manufacturing systems, and healthcare operations. The theory reveals fundamental trade-offs between resource utilization and waiting times.

Definitions

  • Kendall's Notation: A/S/c/K/N/D describes arrival process, service distribution, number of servers, system capacity, population size, and queue discipline.
  • Traffic Intensity: \(\rho = \lambda / (c\mu)\) where \(\lambda\) is arrival rate, \(\mu\) is service rate, and \(c\) is number of servers.
  • Little's Law: \(L = \lambda W\) where \(L\) is average number in system, \(\lambda\) is arrival rate, and \(W\) is average time in system.
  • Steady State: The long-run behavior where system statistics become time-independent.

Theorem: Pollaczek-Khinchine Formula

Theorem: For an M/G/1 queue (Poisson arrivals, general service, single server) with traffic intensity \(\rho = \lambda/\mu < 1\), the expected waiting time in the queue is: \[W_q = \frac{\lambda \overline{S^2}}{2(1-\rho)} = \frac{\rho}{\mu(1-\rho)} \cdot \frac{1 + C_s^2}{2}\] where \(\overline{S^2}\) is the second moment of service time and \(C_s^2 = \text{Var}(S)/E[S]^2\) is the squared coefficient of variation.

Proof Sketch

Using the embedded Markov chain at departure times, let \(W_n\) be the waiting time of the \(n\)-th customer. By the PASTA property (Poisson Arrivals See Time Averages), an arriving customer sees the time-average queue length. The waiting time equals the remaining service time of the customer in service plus the service times of all waiting customers. Taking expectations and using the fact that the residual service time has mean \(\overline{S^2}/(2E[S])\), we obtain the result.

Notation Guide

  • \(\lambda\) — Arrival rate
  • \(\mu\) — Service rate
  • \(\rho = \lambda/\mu\) — Traffic intensity
  • \(L\) — Average number in system
  • \(L_q\) — Average number in queue
  • \(W\) — Average time in system
  • \(W_q\) — Average waiting time in queue
  • \(P_n\) — Steady-state probability of \(n\) customers

import numpy as np
from scipy.stats import poisson, expon

class MM1Queue:
    """M/M/1 queue: Poisson arrivals, exponential service, 1 server."""
    
    def __init__(self, arrival_rate, service_rate):
        self.lambda_ = arrival_rate
        self.mu = service_rate
        self.rho = arrival_rate / service_rate
        if self.rho >= 1:
            raise ValueError("System unstable: rho >= 1")
    
    def steady_state_prob(self, n):
        """P_n = (1-rho) * rho^n"""
        return (1 - self.rho) * (self.rho ** n)
    
    def mean_in_system(self):
        """L = rho / (1 - rho)"""
        return self.rho / (1 - self.rho)
    
    def mean_in_queue(self):
        """L_q = rho^2 / (1 - rho)"""
        return (self.rho ** 2) / (1 - self.rho)
    
    def mean_time_in_system(self):
        """W = 1 / (mu - lambda)"""
        return 1 / (self.mu - self.lambda_)
    
    def mean_wait_in_queue(self):
        """W_q = rho / (mu - lambda)"""
        return self.rho / (self.mu - self.lambda_)

class MG1Queue:
    """M/G/1 queue: Poisson arrivals, general service, 1 server."""
    
    def __init__(self, arrival_rate, mean_service, var_service):
        self.lambda_ = arrival_rate
        self.E_S = mean_service
        self.Var_S = var_service
        self.mu = 1 / mean_service
        self.rho = arrival_rate * mean_service
        self.Cs_squared = var_service / (mean_service ** 2)
        if self.rho >= 1:
            raise ValueError("System unstable: rho >= 1")
    
    def mean_wait_in_queue(self):
        """Pollaczek-Khinchine formula."""
        return (self.rho / (self.mu * (1 - self.rho))) * (1 + self.Cs_squared) / 2
    
    def mean_time_in_system(self):
        return self.mean_wait_in_queue() + self.E_S
    
    def mean_in_queue(self):
        return self.lambda_ * self.mean_wait_in_queue()
    
    def mean_in_system(self):
        return self.lambda_ * self.mean_time_in_system()

class MMcQueue:
    """M/M/c queue: Poisson arrivals, exponential service, c servers."""
    
    def __init__(self, arrival_rate, service_rate, c):
        self.lambda_ = arrival_rate
        self.mu = service_rate
        self.c = c
        self.rho = arrival_rate / (c * service_rate)
        if self.rho >= 1:
            raise ValueError("System unstable: rho >= 1")
    
    def erlang_c_formula(self):
        """Probability all servers busy (Erlang C)."""
        c = self.c
        rho = self.rho
        lambda_mu = self.lambda_ / self.mu
        
        # Compute P_0
        sum_term = sum([(lambda_mu ** n) / np.math.factorial(n) for n in range(c)])
        last_term = ((lambda_mu ** c) / np.math.factorial(c)) * (1 / (1 - rho))
        P_0 = 1 / (sum_term + last_term)
        
        # Erlang C
        numerator = ((lambda_mu ** c) / np.math.factorial(c)) * (1 / (1 - rho))
        C = numerator * P_0
        return C
    
    def mean_wait_in_queue(self):
        C = self.erlang_c_formula()
        return C / (self.c * self.mu - self.lambda_)
    
    def mean_in_queue(self):
        return self.lambda_ * self.mean_wait_in_queue()

Option Pricing: The Black-Scholes-Merton Model

option-pricing

Motivation

The Black-Scholes-Merton model revolutionized financial markets by providing a theoretical framework for pricing options and other derivatives. The model shows that under certain assumptions, options can be perfectly hedged, eliminating risk. This insight earned Scholes and Merton the 1997 Nobel Prize in Economics (Black had passed away in 1995).

Definitions

  • European Call Option: The right to buy an asset at strike price \(K\) at maturity \(T\).
  • Payoff: \(\max(S_T - K, 0)\) for a call, \(\max(K - S_T, 0)\) for a put.
  • Geometric Brownian Motion: \(dS_t = \mu S_t dt + \sigma S_t dW_t\) where \(W_t\) is Brownian motion.
  • Risk-Neutral Measure: A probability measure under which all assets earn the risk-free rate.

Theorem: Black-Scholes Formula

Theorem: Under the Black-Scholes assumptions (no arbitrage, constant volatility \(\sigma\), risk-free rate \(r\)), the price of a European call option on a non-dividend-paying stock is: \[C = S_0 N(d_1) - Ke^{-rT} N(d_2)\] where: \[d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}\] and \(N(\cdot)\) is the standard normal CDF.

Proof Sketch

Consider a portfolio \(\Pi = V - \Delta S\) where \(V(S,t)\) is the option value. By Itô's lemma: \[dV = \frac{\partial V}{\partial t}dt + \frac{\partial V}{\partial S}dS + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2}dt\] Choosing \(\Delta = \frac{\partial V}{\partial S}\) eliminates the random component. The portfolio must earn the risk-free rate: \[d\Pi = r\Pi dt = r(V - \Delta S)dt\] Equating expressions yields the Black-Scholes PDE: \[\frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0\] With boundary condition \(V(S,T) = \max(S-K, 0)\), the solution is the Black-Scholes formula.

Notation Guide

  • \(S_t\) — Stock price at time \(t\)
  • \(K\) — Strike price
  • \(T\) — Time to maturity
  • \(r\) — Risk-free interest rate
  • \(\sigma\) — Volatility
  • \(N(x)\) — Standard normal CDF
  • \(\Delta = \frac{\partial V}{\partial S}\) — Delta (hedge ratio)
  • \(\Gamma = \frac{\partial^2 V}{\partial S^2}\) — Gamma
  • \(\Theta = \frac{\partial V}{\partial t}\) — Theta
  • \(\nu = \frac{\partial V}{\partial \sigma}\) — Vega

import numpy as np
from scipy.stats import norm
from scipy.optimize import brentq

def black_scholes_call(S, K, T, r, sigma):
    """
    Black-Scholes formula for European call option.
    
    Parameters:
    S: Current stock price
    K: Strike price
    T: Time to maturity (years)
    r: Risk-free rate
    sigma: Volatility
    """
    if T <= 0:
        return max(S - K, 0)
    
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    return call_price

def black_scholes_put(S, K, T, r, sigma):
    """Black-Scholes formula for European put option (put-call parity)."""
    call = black_scholes_call(S, K, T, r, sigma)
    return call - S + K * np.exp(-r * T)

def black_scholes_greeks(S, K, T, r, sigma):
    """Calculate option Greeks."""
    if T <= 0:
        return {'delta': 1.0 if S > K else 0.0, 'gamma': 0, 'theta': 0, 'vega': 0}
    
    d1 = (np.log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    delta = norm.cdf(d1)
    gamma = norm.pdf(d1) / (S * sigma * np.sqrt(T))
    theta = -(S * norm.pdf(d1) * sigma) / (2 * np.sqrt(T)) - r * K * np.exp(-r * T) * norm.cdf(d2)
    vega = S * norm.pdf(d1) * np.sqrt(T)
    
    return {'delta': delta, 'gamma': gamma, 'theta': theta, 'vega': vega}

def implied_volatility(S, K, T, r, market_price, option_type='call'):
    """Find implied volatility given market price."""
    def objective(sigma):
        if option_type == 'call':
            return black_scholes_call(S, K, T, r, sigma) - market_price
        else:
            return black_scholes_put(S, K, T, r, sigma) - market_price
    
    try:
        return brentq(objective, 0.001, 5.0)
    except ValueError:
        return None

def monte_carlo_option_price(S, K, T, r, sigma, n_simulations=100000, option_type='call'):
    """Price option using Monte Carlo simulation."""
    np.random.seed(42)
    Z = np.random.standard_normal(n_simulations)
    ST = S * np.exp((r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * Z)
    
    if option_type == 'call':
        payoffs = np.maximum(ST - K, 0)
    else:
        payoffs = np.maximum(K - ST, 0)
    
    price = np.exp(-r * T) * np.mean(payoffs)
    std_error = np.exp(-r * T) * np.std(payoffs) / np.sqrt(n_simulations)
    return price, std_error

Additive Combinatorics: Sumsets and Structure

additive-combinatorics

Motivation

Additive combinatorics studies the additive structure of sets, combining tools from combinatorics, harmonic analysis, and ergodic theory. The field gained prominence through Gowers' work on Szemerédi's theorem and Green and Tao's proof that primes contain arbitrarily long arithmetic progressions. It reveals deep connections between the algebraic and combinatorial properties of sets.

Definitions

  • Sumset: For sets \(A, B\), \(A + B = \{a + b : a \in A, b \in B\}\).
  • Difference Set: \(A - B = \{a - b : a \in A, b \in B\}\).
  • Doubling Constant: \(K = |A + A|/|A|\). Small doubling implies structure.
  • Freiman Homomorphism: A map \(\phi: A \to B\) preserving addition: \(\phi(a + b) = \phi(a) + \phi(b)\).
  • Bohr Set: A set of the form \(\{x : \|x \cdot \alpha_j\| \leq \epsilon_j\}\) for frequencies \(\alpha_j\).

Theorem: Freiman's Theorem

Theorem: Let \(A\) be a finite subset of an abelian group with small doubling: \(|A + A| \leq K|A|\). Then \(A\) is contained in a generalized arithmetic progression \(P\) of bounded rank and size: \[|P| \leq C(K)|A|\] where \(C(K)\) depends only on \(K\) (exponentially). Equivalently, \(A\) is a large subset of a low-dimensional coset progression.

Proof Sketch

The proof proceeds through several stages:

  1. Bogolyubov's Lemma: If \(A\) is dense in a group, then \(2A - 2A\) contains a large Bohr set.
  2. Ruzsa's Covering Lemma: If \(|X + B| \leq K|B|\), then \(X\) can be covered by few translates of \(B - B\).
  3. Structure of Bohr sets: Bohr sets contain large generalized arithmetic progressions.
  4. Iterative argument: Build the progression by iteratively controlling the structure of sumsets.

Notation Guide

  • \(A + B\) — Sumset
  • \(kA = A + A + \cdots + A\) (k times)
  • \(d(A)\) — Doubling constant \(|A+A|/|A|\)
  • \(E(A, B)\) — Additive energy: \(|\{(a,a',b,b') : a+b = a'+b'\}|\)
  • \(r_{A+B}(n)\) — Number of representations of \(n\) as \(a+b\)

    """Compute |A + A| / |A|."""
    AA = sumset(A, A)

def additive_energy(A, B=None):
    """
    Compute additive energy E(A,B) = |{(a,a',b,b') : a+b = a'+b'}|.
    Higher energy indicates more additive structure.
    """
    if B is None:
        B = A
    
    # Count representations
    from collections import Counter
    sums = Counter(a + b for a in A for b in B)
    
    # E(A,B) = sum_n r_{A+B}(n)^2
    energy = sum(count**2 for count in sums.values())
    return energy

def is_arithmetic_progression(A):
    """Check if A is an arithmetic progression."""
    if len(A) <= 2:
        return True
    sorted_A = sorted(A)
    d = sorted_A[1] - sorted_A[0]
    return all(sorted_A[i+1] - sorted_A[i] == d for i in range(len(sorted_A)-1))

def find_ap_structure(A):
    """Find the longest arithmetic progression contained in A."""
    sorted_A = sorted(A)
    n = len(sorted_A)
    
    best_length = 1
    best_ap = [sorted_A[0]]
    
    for i in range(n):
        for j in range(i+1, n):
            d = sorted_A[j] - sorted_A[i]
            if d == 0:
                continue
            ap = [sorted_A[i]]
            current = sorted_A[i]
            while current + d in A:
                current += d
                ap.append(current)
            if len(ap) > best_length:
                best_length = len(ap)
                best_ap = ap
    
    return best_ap

Extremal Graph Theory: Turán's Theorem and Beyond

extremal-graph-theory

Motivation

Extremal graph theory asks: how many edges can a graph have while avoiding a certain substructure? This seemingly simple question leads to deep mathematics connecting combinatorics, geometry, and algebra. Turán's theorem, the foundational result, determines the maximum number of edges in a graph without a complete subgraph \(K_r\).

Definitions

  • Turán Graph \(T(n, r)\): The complete \(r\)-partite graph with parts as equal as possible.
  • Extremal Number: \(\text{ex}(n, H) = \max\{e(G) : |V(G)| = n, H \not\subseteq G\}\).
  • Chromatic Number \(\chi(H)\): The smallest \(r\) such that \(H\) is \(r\)-colorable.
  • Erdős–Stone Theorem: Determines \(\text{ex}(n, H)\) asymptotically for all non-bipartite \(H\).

Theorem: Turán's Theorem

Theorem: For integers \(n \geq r \geq 2\), the maximum number of edges in an \(n\)-vertex graph containing no \(K_{r+1}\) is achieved by the Turán graph \(T(n, r)\): \[\text{ex}(n, K_{r+1}) = \left(1 - \frac{1}{r}\right)\frac{n^2}{2}\] for \(n\) divisible by \(r\). More precisely: \[t(n, r) = \left(1 - \frac{1}{r}\right)\frac{n^2 - s^2}{2} + \binom{s}{2}\] where \(s = n \mod r\). Furthermore, \(T(n, r)\) is the unique extremal graph.

Proof Sketch

Induction on \(n\): For the base case, verify directly. For the inductive step, let \(G\) be a \(K_{r+1}\)-free graph on \(n\) vertices with maximum edges. Then \(G\) contains a \(K_r\) (otherwise we could add edges). Let \(A\) be the vertices of this \(K_r\) and \(B = V \setminus A\).

Each vertex in \(B\) is adjacent to at most \(r-1\) vertices of \(A\) (else we get \(K_{r+1}\)). By induction, \(G[B]\) has at most \(t(n-r, r)\) edges. Counting edges: \[e(G) \leq \binom{r}{2} + (n-r)(r-1) + t(n-r, r) = t(n, r)\]

Notation Guide

  • \(e(G)\) — Number of edges in graph \(G\)
  • \(d(v)\) — Degree of vertex \(v\)
  • \(\delta(G), \Delta(G)\) — Minimum and maximum degree
  • \(T(n, r)\) — Turán graph
  • \(t(n, r)\) — Number of edges in \(T(n, r)\)
  • \(\text{ex}(n, H)\) — Extremal number

import numpy as np
import networkx as nx
from itertools import combinations

def turan_graph(n, r):
    """
    Construct the Turán graph T(n, r).
    Complete r-partite graph with parts as equal as possible.
    """
    G = nx.Graph()
    G.add_nodes_from(range(n))
    
    # Determine part sizes
    base_size = n // r
    remainder = n % r
    
    parts = []
    start = 0
    for i in range(r):
        size = base_size + (1 if i < remainder else 0)
        parts.append(list(range(start, start + size)))
        start += size
    
    # Add edges between different parts
    for i in range(r):
        for j in range(i + 1, r):
            for u in parts[i]:
                for v in parts[j]:
                    G.add_edge(u, v)
    
    return G, parts

def turan_number(n, r):
    """Calculate t(n, r), the number of edges in T(n, r)."""
    s = n % r
    q = n // r
    # t(n,r) = (1 - 1/r) * n²/2 - s(r-s)/(2r)
    return (r - 1) * (n**2 - s**2) / (2 * r) + s * (s - 1) / 2

def has_clique(G, k):
    """Check if G contains a k-clique using brute force."""
    for nodes in combinations(G.nodes(), k):
        if all(G.has_edge(u, v) for u, v in combinations(nodes, 2)):
            return True
    return False

def mantel_theorem_check(G):
    """
    Mantel's Theorem: Triangle-free graph on n vertices has at most n²/4 edges.
    Returns True if satisfied.
    """
    n = G.number_of_nodes()
    e = G.number_of_edges()
    return e <= n * n / 4

def zarankiewicz_problem(m, n, s, t):
    """
    Zarankiewicz problem: max edges in K_{s,t}-free bipartite graph.
    Upper bound: ex(m, n, K_{s,t}) ≤ (t-1)^{1/s}(n-s+1)m^{1-1/s} + (s-1)n
    """
    # Kővári–Sós–Turán theorem upper bound
    if s == 2:
        return int(np.sqrt(t - 1) * n * np.sqrt(m) + m)
    return None

Ergodic Ramsey Theory: Szemerédi's Theorem and Dynamics

ergodic-ramsey-theory

Motivation

Ergodic Ramsey theory applies tools from ergodic theory to combinatorial problems. Furstenberg's 1977 proof of Szemerédi's theorem via multiple recurrence was revolutionary, establishing a deep connection between the statistical behavior of dynamical systems and the existence of arithmetic structure in sets of integers. This approach has since been extended to prove numerous results in Ramsey theory.

Definitions

  • Measure-Preserving System: \((X, \mathcal{B}, \mu, T)\) where \(T: X \to X\) preserves \(\mu\).
  • Multiple Recurrence: For any measurable \(A\) with \(\mu(A) > 0\) and any \(k\), there exists \(n\) such that \(\mu(A \cap T^{-n}A \cap \cdots \cap T^{-kn}A) > 0\).
  • Uniform Recurrence: A point \(x\) is uniformly recurrent if for every neighborhood \(U\) of \(x\), the set of return times \(\{n : T^n x \in U\}\) has bounded gaps.
  • Correspondence Principle: Connects density of sets in integers to measure of sets in dynamical systems.

Theorem: Furstenberg's Multiple Recurrence Theorem

Theorem: Let \((X, \mathcal{B}, \mu, T)\) be a measure-preserving system and \(A \in \mathcal{B}\) with \(\mu(A) > 0\). For any integer \(k \geq 1\), there exists \(n > 0\) such that: \[\mu\left(A \cap T^{-n}A \cap T^{-2n}A \cap \cdots \cap T^{-kn}A\right) > 0\] Equivalently, there exists \(x \in X\) such that \(x, T^n x, T^{2n} x, \ldots, T^{kn} x \in A\).

Proof Sketch

The proof proceeds by induction on \(k\) and uses the structure theory of measure-preserving systems:

  1. Khintchine's Recurrence: For \(k=1\), Poincaré recurrence gives \(\mu(A \cap T^{-n}A) > 0\) for infinitely many \(n\).
  2. Compact Extensions: If the system is compact (almost periodic), multiple recurrence follows from uniform recurrence.
  3. Weak Mixing: For weak mixing systems, multiple averages converge to products.
  4. Structure Theorem: Any system is a weak mixing extension of a compact extension of a simpler system (the Furstenberg tower).

Notation Guide

  • \((X, \mathcal{B}, \mu, T)\) — Measure-preserving system
  • \(T^n\) — \(n\)-fold composition of \(T\)
  • \(L^2(X, \mu)\) — Hilbert space of square-integrable functions
  • \(U_T f = f \circ T\) — Koopman operator
  • \(\mathbb{E}(f|\mathcal{Y})\) — Conditional expectation

import numpy as np
from collections import defaultdict

def circle_rotation(theta, n_points=1000):
    """
    Circle rotation: T(x) = x + theta (mod 1).
    This is an ergodic measure-preserving system when theta is irrational.
    """
    X = np.linspace(0, 1, n_points, endpoint=False)
    return X

def apply_rotation(x, theta):
    """Apply rotation by theta (mod 1)."""
    return (x + theta) % 1

def poincare_recurrence(x0, theta, A_func, n_iterations=1000):
    """
    Demonstrate Poincaré recurrence: returns return times to set A.
    """
    x = x0
    return_times = []
    for n in range(1, n_iterations + 1):
        x = apply_rotation(x, theta)
        if A_func(x):
            return_times.append(n)
    return return_times

def multiple_recurrence_demo(theta, A_interval, k, n_iterations=5000):
    """
    Demonstrate multiple recurrence for circle rotation.
    Look for n such that x, T^n(x), T^{2n}(x), ..., T^{kn}(x) all in A.
    """
    a, b = A_interval
    
    def in_A(x):
        return a <= x < b
    
    # Sample starting points
    samples = np.random.uniform(0, 1, 100)
    results = []
    
    for x0 in samples:
        for n in range(1, n_iterations):
            all_in_A = True
            for j in range(k + 1):
                x_j = (x0 + j * n * theta) % 1
                if not in_A(x_j):
                    all_in_A = False
                    break
            if all_in_A:
                results.append((x0, n))
                break
    
    return results

def von_neumann_ergodic_average(f, T, x0, n_iterations):
    """
    Compute (1/N) * sum_{n=0}^{N-1} f(T^n(x))
    Converges to integral of f for ergodic systems.
    """
    x = x0
    total = 0
    for _ in range(n_iterations):
        total += f(x)
        x = T(x)
    return total / n_iterations

def correspondence_principle_demo(A_set, max_n=100):
    """
    Demonstrate the correspondence principle.
    A_set is a subset of {0, 1, ..., max_n-1}.
    """
    density = len(A_set) / max_n
    
    # Find arithmetic progressions in A
    aps_found = []
    for length in [3, 4]:
        for start in range(max_n):
            for diff in range(1, (max_n - start) // length + 1):
                ap = [start + i * diff for i in range(length)]
                if all(x in A_set for x in ap):
                    aps_found.append((length, ap))
    
    return density, aps_found

Math History: Alexander Grothendieck — The Revolution in Geometry

grothendieck

Biography

Alexander Grothendieck (1928–2014) was one of the most influential mathematicians of the 20th century. Born in Berlin to anarchist parents, he spent his childhood in France during World War II, hiding from the Nazis. After the war, he entered mathematics without formal training, quickly revolutionizing algebraic geometry.

At the Institut des Hautes Études Scientifiques (IHÉS) from 1958 to 1970, Grothendieck led a seminar that transformed mathematics. His work with Jean Dieudonné, published as the "Éléments de Géométrie Algébrique" (EGA), rebuilt algebraic geometry from its foundations. He received the Fields Medal in 1966 but refused to travel to Moscow to accept it in protest against Soviet militarism.

Revolutionary Contributions

  • Schemes: Grothendieck introduced schemes, generalizing algebraic varieties to allow nilpotents and work over any ring. This unified number theory and geometry.
  • Topos Theory: A topos is a category that behaves like the category of sets. Topos theory provides a foundation for mathematics alternative to set theory.
  • Étale Cohomology: Developed to prove the Weil conjectures (completed by Deligne), this brought topological methods to algebraic geometry over finite fields.
  • Descent Theory: A powerful technique for constructing global objects from local data.
  • Grothendieck-Riemann-Roch: A far-reaching generalization of the classical Riemann-Roch theorem.

The Grothendieck Philosophy

Grothendieck believed in finding the right level of generality. Rather than attacking problems directly, he sought the natural context in which they became simple. He described his approach as "rising to the appropriate level of generality where the phenomena become clear."

His work is characterized by:

  • Emphasis on relative situations (morphisms rather than objects)
  • Functorial thinking (focus on relationships between structures)
  • The search for universal properties
  • The use of nilpotents to capture infinitesimal information

Later Years and Mystique

In 1970, Grothendieck left the IHÉS upon discovering it received military funding. He became increasingly involved in pacifist and environmental causes. In 1991, he disappeared into the Pyrenees, living in isolation until his death in 2014.

His 1000-page autobiography "Récoltes et Semailles" (Harvests and Sowings) is a profound meditation on mathematics, creativity, and the mathematical community. It reveals a man who saw mathematics as a spiritual pursuit, a way of understanding the "nature of things."

Legacy

Grothendieck's influence extends far beyond algebraic geometry. His emphasis on abstract structures shaped modern mathematics. The proof of Fermat's Last Theorem by Wiles used Grothendieck's machinery. His ideas continue to influence number theory, mathematical physics, and even computer science.

Grothendieck remains a legendary figure—a mathematician who saw further than his contemporaries, who transformed his field so completely that it became unrecognizable, and who ultimately walked away from it all in pursuit of deeper truths.

Problem: An Inequality from the Putnam Competition

Difficulty: ★★★☆☆ (Intermediate-Advanced)

Let \(n\) be a positive integer and let \(x_1, x_2, \ldots, x_n\) be real numbers such that \(x_1 + x_2 + \cdots + x_n = 0\) and \(x_1^2 + x_2^2 + \cdots + x_n^2 = 1\). Find the maximum value of \(x_1 x_2 + x_2 x_3 + \cdots + x_{n-1} x_n + x_n x_1\).

💡 Hint

Consider the quadratic form \(Q(x) = \sum_{i=1}^n x_i x_{i+1}\) (with \(x_{n+1} = x_1\)). This can be written as \(x^T A x\) for a circulant matrix \(A\). Use Lagrange multipliers or analyze the eigenvalues of \(A\) subject to the constraints. The circulant structure means the eigenvectors are discrete Fourier modes.

📖 Solution

Solution: The maximum value is \(\cos(2\pi/n)\).

Method 1: Eigenvalue Analysis

The expression can be written as \(x^T A x\) where \(A\) is the circulant matrix with first row \((0, 1/2, 0, \ldots, 0, 1/2)\). The eigenvalues of a circulant matrix with first row \((c_0, c_1, \ldots, c_{n-1})\) are: \[\lambda_k = \sum_{j=0}^{n-1} c_j \omega^{jk}\] where \(\omega = e^{2\pi i/n}\) and \(k = 0, 1, \ldots, n-1\).

For our matrix, \(c_1 = c_{n-1} = 1/2\) and other \(c_j = 0\). Thus: \[\lambda_k = \frac{1}{2}\omega^k + \frac{1}{2}\omega^{(n-1)k} = \frac{1}{2}(\omega^k + \omega^{-k}) = \cos(2\pi k/n)\]

The eigenvalues are \(\cos(2\pi k/n)\) for \(k = 0, 1, \ldots, n-1\).

Constraint Analysis:

The constraint \(\sum x_i = 0\) means we restrict to the subspace orthogonal to \((1, 1, \ldots, 1)\), which is the eigenspace for eigenvalue \(\lambda_0 = 1\).

On this subspace, the maximum of \(x^T A x\) subject to \(\|x\|^2 = 1\) is the largest eigenvalue among \(\lambda_1, \ldots, \lambda_{n-1}\), which is \(\cos(2\pi/n)\).

Verification: The eigenvector for \(\lambda_1 = \cos(2\pi/n)\) is \((1, \omega, \omega^2, \ldots, \omega^{n-1})\). Taking real and imaginary parts gives real vectors achieving the maximum.

Bifurcation Diagram of the Logistic Map

The logistic map \(x_{n+1} = r x_n (1 - x_n)\) is a paradigmatic example of how simple nonlinear systems can exhibit complex behavior. As the parameter \(r\) increases, the system undergoes a period-doubling cascade to chaos. The following Python code generates the bifurcation diagram, showing the attracting set as a function of \(r\).

import numpy as np
import matplotlib.pyplot as plt

def logistic_map(r, x0, n_iterations=1000, n_plot=100):
    """
    Iterate the logistic map x_{n+1} = r * x_n * (1 - x_n).
    Return the last n_plot values (after transient).
    """
    x = x0
    # Transient
    for _ in range(n_iterations - n_plot):
        x = r * x * (1 - x)
    
    # Collect values
    values = []
    for _ in range(n_plot):
        x = r * x * (1 - x)
        values.append(x)
    
    return values

def bifurcation_diagram(r_min=2.5, r_max=4.0, n_r=2000, n_plot=100):
    """Generate bifurcation diagram for the logistic map."""
    fig, ax = plt.subplots(figsize=(12, 8))
    
    r_values = np.linspace(r_min, r_max, n_r)
    
    for r in r_values:
        values = logistic_map(r, x0=0.5, n_iterations=1000, n_plot=n_plot)
        ax.plot([r] * len(values), values, ',k', alpha=0.3, markersize=0.5)
    
    ax.set_xlabel('r', fontsize=12)
    ax.set_ylabel('x', fontsize=12)
    ax.set_title('Bifurcation Diagram of the Logistic Map', fontsize=14)
    ax.set_xlim(r_min, r_max)
    ax.set_ylim(0, 1)
    ax.grid(True, alpha=0.3)
    
    return fig, ax

def lyapunov_exponent(r, x0=0.5, n_iterations=10000):
    """
    Compute the Lyapunov exponent for the logistic map at parameter r.
    λ = lim (1/n) Σ log|f'(x_i)|
    """
    x = x0
    total = 0
    for _ in range(n_iterations):
        x = r * x * (1 - x)
        # f'(x) = r(1 - 2x)
        derivative = abs(r * (1 - 2 * x))
        if derivative > 0:
            total += np.log(derivative)
    
    return total / n_iterations

def plot_lyapunov(r_min=2.5, r_max=4.0, n_r=1000):
    """Plot Lyapunov exponent as a function of r."""
    fig, ax = plt.subplots(figsize=(12, 6))
    
    r_values = np.linspace(r_min, r_max, n_r)
    lyap_values = [lyapunov_exponent(r) for r in r_values]
    
    ax.plot(r_values, lyap_values, 'b-', linewidth=0.5)
    ax.axhline(y=0, color='r', linestyle='--', alpha=0.5)
    ax.set_xlabel('r', fontsize=12)
    ax.set_ylabel('Lyapunov Exponent λ', fontsize=12)
