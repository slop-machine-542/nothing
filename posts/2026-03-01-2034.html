Finite Fields and Primitive Elements

Motivation

Finite fields, also known as Galois fields, are fundamental structures in modern algebra with applications in cryptography, coding theory, and computer science. Understanding their structure, particularly the existence of primitive elements, is crucial for many practical algorithms including the Advanced Encryption Standard (AES) and error-correcting codes.

Definitions

A finite field \(\mathbb{F}_q\) is a field with \(q = p^n\) elements, where \(p\) is prime and \(n \geq 1\). The multiplicative group \(\mathbb{F}_q^* = \mathbb{F}_q \setminus \{0\}\) is cyclic of order \(q - 1\).

A primitive element of \(\mathbb{F}_q\) is a generator of the cyclic group \(\mathbb{F}_q^*\). Equivalently, \(\alpha \in \mathbb{F}_q^*\) is primitive if its multiplicative order is exactly \(q - 1\).

Theorem: Existence of Primitive Elements

Theorem: For every prime power \(q = p^n\), the multiplicative group \(\mathbb{F}_q^*\) is cyclic. In particular, \(\mathbb{F}_q\) has exactly \(\varphi(q-1)\) primitive elements, where \(\varphi\) is Euler's totient function.

Proof

Let \(\mathbb{F}_q^*\) have order \(q - 1\). For each divisor \(d\) of \(q - 1\), let \(\psi(d)\) denote the number of elements of order \(d\) in \(\mathbb{F}_q^*\).

Every element of \(\mathbb{F}_q^*\) has order dividing \(q - 1\), so:

\[\sum_{d \mid (q-1)} \psi(d) = q - 1\]

If there exists an element \(\alpha\) of order \(d\), then the cyclic subgroup \(\langle \alpha \rangle\) consists of all roots of \(x^d - 1 = 0\) in \(\mathbb{F}_q\). The elements of order exactly \(d\) in this subgroup are the generators, so there are \(\varphi(d)\) such elements.

Therefore \(\psi(d) \leq \varphi(d)\) for all \(d \mid (q-1)\), with equality if and only if there exists an element of order \(d\).

Since \(\sum_{d \mid (q-1)} \varphi(d) = q - 1 = \sum_{d \mid (q-1)} \psi(d)\), we must have \(\psi(d) = \varphi(d)\) for all \(d\).

In particular, \(\psi(q-1) = \varphi(q-1) > 0\), so primitive elements exist. ∎

Notation Guide

  • \(\mathbb{F}_q\) or \(GF(q)\): finite field with \(q\) elements
  • \(\mathbb{F}_q^*\): multiplicative group of nonzero elements
  • \(\text{ord}(\alpha)\): multiplicative order of \(\alpha\)
  • \(\varphi(n)\): Euler's totient function
  • \(\text{Tr}_{\mathbb{F}_{q^n}/\mathbb{F}_q}(x) = x + x^q + \cdots + x^{q^{n-1}}\): trace function

Algebraic Curves and the Riemann-Roch Theorem

Motivation

Algebraic curves form a bridge between algebra and geometry, connecting polynomial equations to geometric shapes. The Riemann-Roch theorem is one of the most important results in the theory of algebraic curves, providing a deep relationship between the topological genus of a curve and the dimensions of spaces of functions on it. This theorem has far-reaching consequences in number theory, cryptography (especially elliptic curve cryptography), and theoretical physics.

Definitions

An algebraic curve over a field \(k\) is a one-dimensional variety defined by polynomial equations. A smooth projective curve \(C\) of genus \(g\) is a compact Riemann surface (over \(\mathbb{C}\)) or its algebraic equivalent.

A divisor \(D = \sum_{P \in C} n_P P\) is a formal sum of points on \(C\) with integer coefficients, almost all zero. The degree of \(D\) is \(\deg(D) = \sum n_P\).

For a divisor \(D\), define:

\[L(D) = \{f \in k(C)^* : \text{div}(f) + D \geq 0\} \cup \{0\}\]

This is the space of functions with poles bounded by \(D\). Let \(\ell(D) = \dim_k L(D)\).

Theorem: Riemann-Roch

Theorem: Let \(C\) be a smooth projective curve of genus \(g\) over an algebraically closed field, and let \(K\) be a canonical divisor on \(C\). Then for any divisor \(D\):

\[\ell(D) - \ell(K - D) = \deg(D) + 1 - g\]

Proof Sketch

The proof proceeds in several stages:

Step 1: Show that for any divisor \(D\) and any point \(P\), the difference \(\ell(D + P) - \ell(D)\) is either 0 or 1. This follows from the exact sequence:

\[0 \to L(D) \to L(D + P) \to k \to \cdots\]

Step 2: Prove Riemann's inequality: \(\ell(D) \geq \deg(D) + 1 - g\) for all divisors \(D\) with \(\deg(D)\) sufficiently large. This is done by constructing explicit functions using the Weierstrass gap theorem.

Step 3: Define the genus as:

\[g = \dim_k H^1(C, \mathcal{O}_C)\]

and show that \(\ell(K) = g\) and \(\deg(K) = 2g - 2\).

Step 4: Apply Serre duality, which gives:

\[H^1(C, \mathcal{O}_C(D)) \cong H^0(C, \mathcal{O}_C(K - D))^*\]

This yields \(\ell(K - D) = h^1(D)\), and the Euler characteristic formula completes the proof. ∎

Notation Guide

  • \(k(C)\): function field of the curve \(C\)
  • \(\text{div}(f)\): divisor of the function \(f\)
  • \(K\): canonical divisor (divisor of a differential)
  • \(g\): genus (topological invariant, "number of holes")
  • \(H^i(C, \mathcal{F})\): sheaf cohomology groups
  • \(\mathcal{O}_C(D)\): line bundle associated to divisor \(D\)

class AlgebraicCurve:
    """Basic representation of an algebraic curve."""
    
    def __init__(self, equation, vars):
        """
        Initialize curve from equation F(x,y) = 0.
        
        Args:
            equation: sympy expression
            vars: tuple of variables (x, y)
        """
        self.eq = equation
        self.x, self.y = vars
        self.F = Poly(equation, self.x, self.y)
    
    def is_singular(self, point):
        """Check if point is singular (all partials vanish)."""
        x, y = self.x, self.y
        dx = sp.diff(self.eq, x).subs([(x, point[0]), (y, point[1])])
        dy = sp.diff(self.eq, y).subs([(x, point[0]), (y, point[1])])
        val = self.eq.subs([(x, point[0]), (y, point[1])])
        return val == 0 and dx == 0 and dy == 0
    
    def genus_plane_curve(self, degree):
        """
        Compute genus of smooth plane curve of given degree.
        Formula: g = (d-1)(d-2)/2
        """
        d = degree
        return (d - 1) * (d - 2) // 2
    
    def riemann_roch(self, deg_D):
        """
        Apply Riemann-Roch for divisor of degree deg_D.
        Returns lower bound for l(D).
        """
        g = self.genus_plane_curve(self.total_degree())
        # Riemann's inequality: l(D) >= deg(D) + 1 - g
        return max(0, deg_D + 1 - g)
    
    def total_degree(self):
        """Get total degree of defining polynomial."""
        return sp.degree(self.eq)

Group Cohomology and the Schur Multiplier

Motivation

Group cohomology provides a powerful framework for studying groups through the lens of homological algebra. The Schur multiplier, a particular cohomology group, measures the obstruction to projective representations lifting to linear representations and plays a crucial role in the classification of finite simple groups, quantum mechanics (where projective representations describe physical symmetries), and the theory of central extensions.

Definitions

Let \(G\) be a group and \(M\) a \(G\)-module (abelian group with \(G\)-action). The group cohomology \(H^n(G, M)\) is defined as the derived functor of the invariant functor \(M \mapsto M^G = \{m \in M : gm = m \text{ for all } g \in G\}\).

Explicitly, using the bar resolution, an n-cochain is a function \(f: G^n \to M\). The coboundary \(\delta^n: C^n \to C^{n+1}\) is:

\[\begin{aligned} (\delta^n f)(g_1, \ldots, g_{n+1}) = & g_1 \cdot f(g_2, \ldots, g_{n+1}) \\ & + \sum_{i=1}^n (-1)^i f(g_1, \ldots, g_i g_{i+1}, \ldots, g_{n+1}) \\ & + (-1)^{n+1} f(g_1, \ldots, g_n) \end{aligned}\]

Then \(H^n(G, M) = Z^n(G, M) / B^n(G, M)\) where \(Z^n = \ker(\delta^n)\) (cocycles) and \(B^n = \text{im}(\delta^{n-1})\) (coboundaries).

The Schur multiplier is \(M(G) = H^2(G, \mathbb{C}^*)\), classifying central extensions and projective representations.

Theorem: Universal Coefficient Theorem for Group Cohomology

Theorem: For a finite group \(G\) and trivial \(G\)-module \(M\), there is a split exact sequence:

\[0 \to \text{Ext}^1(H_{n-1}(G, \mathbb{Z}), M) \to H^n(G, M) \to \text{Hom}(H_n(G, \mathbb{Z}), M) \to 0\]

In particular, for \(M = \mathbb{C}^*\):

\[H^2(G, \mathbb{C}^*) \cong \text{Hom}(H_2(G, \mathbb{Z}), \mathbb{C}^*)\]

Proof Sketch

The proof uses the relationship between group cohomology and the cohomology of the classifying space \(BG\).

Step 1: For any group \(G\), there is a topological space \(BG\) (the classifying space) with \(\pi_1(BG) = G\) and \(\pi_n(BG) = 0\) for \(n > 1\). The homology of \(BG\) gives the group homology: \(H_n(G, \mathbb{Z}) = H_n(BG, \mathbb{Z})\).

Step 2: The universal coefficient theorem for spaces gives the short exact sequence for cohomology:

\[0 \to \text{Ext}^1(H_{n-1}(X), M) \to H^n(X, M) \to \text{Hom}(H_n(X), M) \to 0\]

Step 3: Apply this to \(X = BG\) and use the identification \(H^n(BG, M) = H^n(G, M)\).

Step 4: For \(M = \mathbb{C}^*\) (divisible group), \(\text{Ext}^1(-, \mathbb{C}^*) = 0\), giving the isomorphism \(H^2(G, \mathbb{C}^*) \cong \text{Hom}(H_2(G, \mathbb{Z}), \mathbb{C}^*)\). ∎

Notation Guide

  • \(C^n(G, M)\): group of n-cochains
  • \(Z^n(G, M)\): n-cocycles (\(\delta^n f = 0\))
  • \(B^n(G, M)\): n-coboundaries (\(f = \delta^{n-1}g\))
  • \(H^n(G, M) = Z^n/B^n\): n-th cohomology group
  • \(M(G) = H^2(G, \mathbb{C}^*)\): Schur multiplier
  • \(H_n(G, \mathbb{Z})\): group homology

class FiniteGroup:
    """Simple representation of a finite group using multiplication table."""
    
    def __init__(self, elements, mult_table, identity=0):
        """
        Args:
            elements: list of element labels
            mult_table: dict (i,j) -> k giving multiplication
            identity: index of identity element
        """
        self.elements = elements
        self.n = len(elements)
        self.mult = mult_table
        self.e = identity
        self.inv = self._compute_inverses()
    
    def _compute_inverses(self):
        """Compute inverse of each element."""
        inv = {}
        for i in range(self.n):
            for j in range(self.n):
                if self.mult[(i, j)] == self.e:
                    inv[i] = j
                    break
        return inv
    
    def multiply(self, g, h):
        return self.mult[(g, h)]
    
    def power(self, g, k):
        """Compute g^k."""
        result = self.e
        for _ in range(k):
            result = self.multiply(result, g)
        return result

def two_cocycle_condition(f, G):
    """
    Check if f: G x G -> C* is a 2-cocycle.
    Condition: f(g,h)f(gh,k) = f(g,hk)f(h,k) for all g,h,k
    """
    for g in range(G.n):
        for h in range(G.n):

Supply Chain Optimization and the Newsvendor Problem

Real-World Motivation

Supply chain optimization is critical for modern businesses, from retail giants like Amazon and Walmart to small e-commerce operations. The newsvendor problem is the simplest yet most fundamental model in inventory theory, capturing the essence of decision-making under uncertainty when facing uncertain demand. It applies to newspaper vendors, fashion retailers (who must order seasonal inventory before knowing demand), and even capacity planning in cloud computing.

Definitions

The newsvendor problem: A vendor must decide how much inventory \(Q\) to order before knowing the random demand \(D\). The cost structure is:

  • Unit cost: \(c\) (paid for each unit ordered)
  • Selling price: \(p > c\) (revenue per unit sold)
  • Salvage value: \(s < c\) (recovery value for unsold units)

The underage cost is \(C_u = p - c\) (cost of ordering one unit too few).

The overage cost is \(C_o = c - s\) (cost of ordering one unit too many).

The profit function is:

\[\pi(Q, D) = p \min(Q, D) + s \max(Q - D, 0) - cQ\]

Theorem: Critical Ratio Solution

Theorem: For continuous demand distribution \(F\), the optimal order quantity \(Q^*\) satisfies:

\[F(Q^*) = \frac{C_u}{C_u + C_o} = \frac{p - c}{p - s}\]

This is called the critical ratio or service level.

Proof

The expected profit is:

\[\mathbb{E}[\pi(Q, D)] = \mathbb{E}[p \min(Q, D) + s(Q - D)^+ - cQ]\]

Using \(\min(Q, D) = D - (D - Q)^+\) and noting that \((Q - D)^+ = 0\) when \(D > Q\):

\[= p\mathbb{E}[D] - p\mathbb{E}[(D - Q)^+] + s\mathbb{E}[(Q - D)^+] - cQ\]

Take the derivative with respect to \(Q\). Using the Leibniz integral rule:

\[\frac{d}{dQ}\mathbb{E}[(Q - D)^+] = P(D \leq Q) = F(Q)\] \[\frac{d}{dQ}\mathbb{E}[(D - Q)^+] = -P(D > Q) = -(1 - F(Q))\]

Therefore:

\[\frac{d}{dQ}\mathbb{E}[\pi(Q, D)] = -p(-(1 - F(Q))) + sF(Q) - c\] \[= p(1 - F(Q)) + sF(Q) - c\] \[= p - c - (p - s)F(Q)\]

Setting to zero:

\[F(Q^*) = \frac{p - c}{p - s} = \frac{C_u}{C_u + C_o}\]

The second derivative is \(-(p-s)f(Q) < 0\), confirming this is a maximum. ∎

Notation Guide

  • \(Q\): order quantity (decision variable)
  • \(D\): random demand with CDF \(F\)
  • \(c\): unit cost
  • \(p\): selling price
  • \(s\): salvage value
  • \(C_u = p - c\): underage cost
  • \(C_o = c - s\): overage cost
  • \(F(Q^*) = \frac{C_u}{C_u + C_o}\): critical ratio

Medical Imaging and the Radon Transform

Real-World Motivation

Computed Tomography (CT) scans have revolutionized medical diagnostics, allowing doctors to see inside the human body without surgery. The mathematical foundation of CT is the Radon transform, which relates the internal density of an object to its X-ray projections. Understanding this transform and its inversion is essential for image reconstruction algorithms that produce the detailed cross-sectional images used in modern medicine.

Definitions

Let \(f(x, y)\) be a function representing the attenuation coefficient of tissue at position \((x, y)\). The Radon transform \(\mathcal{R}f\) maps \(f\) to its line integrals along all possible lines:

\[(\mathcal{R}f)(\theta, s) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x, y) \delta(x \cos\theta + y \sin\theta - s) \, dx \, dy\]

Equivalently, parameterizing the line \(L(\theta, s)\) as:

\[x = s \cos\theta - t \sin\theta, \quad y = s \sin\theta + t \cos\theta\]

Then:

\[(\mathcal{R}f)(\theta, s) = \int_{-\infty}^{\infty} f(s\cos\theta - t\sin\theta, s\sin\theta + t\cos\theta) \, dt\]

The sinogram is the 2D representation of \((\mathcal{R}f)(\theta, s)\) as a function of \(\theta\) (projection angle) and \(s\) (detector position).

Theorem: Fourier Slice Theorem

Theorem: The 1D Fourier transform of the Radon transform with respect to \(s\) equals the 2D Fourier transform of \(f\) evaluated along a line through the origin:

\[\hat{(\mathcal{R}f)}(\theta, \sigma) = \hat{f}(\sigma \cos\theta, \sigma \sin\theta)\]

where \(\hat{f}(\xi, \eta) = \int_{\mathbb{R}^2} f(x, y) e^{-2\pi i(x\xi + y\eta)} dx dy\).

Proof

Starting from the definition of the Radon transform:

\[(\mathcal{R}f)(\theta, s) = \int_{-\infty}^{\infty} f(s\cos\theta - t\sin\theta, s\sin\theta + t\cos\theta) \, dt\]

Take the 1D Fourier transform with respect to \(s\):

\[\hat{(\mathcal{R}f)}(\theta, \sigma) = \int_{-\infty}^{\infty} (\mathcal{R}f)(\theta, s) e^{-2\pi i s \sigma} ds\] \[= \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(s\cos\theta - t\sin\theta, s\sin\theta + t\cos\theta) e^{-2\pi i s \sigma} dt \, ds\]

Make the change of variables:

\[x = s\cos\theta - t\sin\theta, \quad y = s\sin\theta + t\cos\theta\]

The Jacobian is 1 (rotation), and:

\[s = x\cos\theta + y\sin\theta\]

Therefore:

\[\hat{(\mathcal{R}f)}(\theta, \sigma) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x, y) e^{-2\pi i (x\cos\theta + y\sin\theta)\sigma} dx \, dy\] \[= \hat{f}(\sigma\cos\theta, \sigma\sin\theta)\]

This completes the proof. ∎

Notation Guide

  • \(f(x, y)\): object function (attenuation coefficient)
  • \(\mathcal{R}f\): Radon transform of \(f\)
  • \(\theta\): projection angle (0 to \(\pi\))
  • \(s\): detector position (signed distance from origin)
  • \(t\): parameter along the ray
  • \(\hat{f}(\xi, \eta)\): 2D Fourier transform
  • \(\hat{(\mathcal{R}f)}(\theta, \sigma)\): 1D Fourier transform of projection

import numpy as np
from scipy import ndimage
import matplotlib.pyplot as plt

def radon_transform(image, theta=None):
    """Compute Radon transform (sinogram) of an image."""
    if theta is None:
        theta = np.linspace(0, 180, max(20, image.shape[0] // 2), endpoint=False)
    
    n_angles = len(theta)
    n_detectors = image.shape[0]
    sinogram = np.zeros((n_angles, n_detectors))
    
    for i, angle in enumerate(theta):
        rotated = ndimage.rotate(image, angle, reshape=False, order=1)
        sinogram[i, :] = np.sum(rotated, axis=0)
    
    return sinogram, theta

def filtered_backprojection(sinogram, theta, output_size=None):
    """Filtered Backprojection (FBP) algorithm for CT reconstruction."""
    if output_size is None:
        output_size = sinogram.shape[1]
    
    n_angles, n_detectors = sinogram.shape
    freq = np.fft.fftfreq(n_detectors)
    f_filter = np.abs(freq)
    f_filter[0] = 0
    
    filtered_sinogram = np.zeros_like(sinogram)
    for i in range(n_angles):
        proj_fft = np.fft.fft(sinogram[i, :])
        filtered_fft = proj_fft * f_filter
        filtered_sinogram[i, :] = np.real(np.fft.ifft(filtered_fft))
    
    # Backprojection
    reconstruction = np.zeros((output_size, output_size))
    for i, angle in enumerate(theta):
        projection = np.tile(filtered_sinogram[i, :], (output_size, 1))
        rotated = ndimage.rotate(projection, -angle, reshape=False, order=1)
        reconstruction += rotated
    
    return reconstruction / n_angles

Auction Theory and Vickrey-Clarke-Groves Mechanisms

Real-World Motivation

Auction theory has become increasingly important with the rise of online advertising (Google Ads, Facebook), spectrum auctions (selling radio frequencies to telecom companies), and procurement auctions. The Vickrey-Clarke-Groves (VCG) mechanism is a cornerstone of mechanism design, providing a way to allocate resources efficiently while ensuring truthful bidding is a dominant strategy. Understanding VCG is essential for designing fair and efficient markets.

Definitions

Consider \(n\) agents and a set of possible outcomes \(X\). Each agent \(i\) has a valuation function \(v_i: X \to \mathbb{R}_+\) representing their value for each outcome.

A mechanism \((f, p)\) consists of:

  • An allocation rule \(f: V_1 \times \cdots \times V_n \to X\)
  • A payment rule \(p_i: V_1 \times \cdots \times V_n \to \mathbb{R}\) for each agent

The utility of agent \(i\) is:

\[u_i(\hat{v}_i, v_{-i}) = v_i(f(\hat{v}_i, v_{-i})) - p_i(\hat{v}_i, v_{-i})\]

A mechanism is strategyproof if truthful bidding is always optimal.

Theorem: VCG Mechanism

Theorem: The VCG mechanism with allocation rule:

\[f(v) = \arg\max_{x \in X} \sum_{i=1}^n v_i(x)\]

and payment rule:

\[p_i(v) = \max_{x \in X} \sum_{j \neq i} v_j(x) - \sum_{j \neq i} v_j(f(v))\]

is strategyproof and ensures individual rationality.

Proof

Let \(x^* = f(v_i, v_{-i})\) and \(\hat{x} = f(\hat{v}_i, v_{-i})\).

Utility from truthful reporting:

\[u_i(v_i, v_{-i}) = v_i(x^*) - \max_{x} \sum_{j \neq i} v_j(x) + \sum_{j \neq i} v_j(x^*)\] \[= \sum_{j=1}^n v_j(x^*) - \max_{x} \sum_{j \neq i} v_j(x)\]

Utility from deviation:

\[u_i(\hat{v}_i, v_{-i}) = \sum_{j=1}^n v_j(\hat{x}) - \max_{x} \sum_{j \neq i} v_j(x)\]

Since \(x^*\) maximizes social welfare:

\[\sum_{j=1}^n v_j(x^*) \geq \sum_{j=1}^n v_j(\hat{x})\]

Therefore \(u_i(v_i, v_{-i}) \geq u_i(\hat{v}_i, v_{-i})\). ∎

Notation Guide

  • \(n\): number of agents
  • \(X\): set of possible outcomes
  • \(v_i(x)\): agent \(i\)'s valuation for outcome \(x\)
  • \(v_{-i}\): valuations of all agents except \(i\)
  • \(f(v)\): allocation rule (social welfare maximizer)
  • \(p_i(v)\): payment by agent \(i\)
  • \(u_i\): utility of agent \(i\)

import numpy as np
from scipy.optimize import linear_sum_assignment

class VCGMechanism:
    """Vickrey-Clarke-Groves mechanism implementation."""
    
    def __init__(self, n_agents, n_items=None, valuations=None):
        self.n = n_agents
        self.m = n_items
        self.valuations = valuations or {}
    
    def compute_allocation(self, reported_vals):
        """Compute welfare-maximizing allocation."""
        if self.m is None or self.m == 1:
            winner = max(range(self.n), key=lambda i: reported_vals.get(i, 0))
            return {winner: 1}
        else:
            cost_matrix = -np.array([[reported_vals.get((i, j), 0) 
                                      for j in range(self.m)] 
                                     for i in range(self.n)])
            row_ind, col_ind = linear_sum_assignment(cost_matrix)
            return {i: j for i, j in zip(row_ind, col_ind)}
    
    def vcg_payments(self, reported_vals):
        """Compute VCG payments."""
        allocation = self.compute_allocation(reported_vals)
        payments = {}
        
        for i in range(self.n):
            welfare_others_actual = sum(
                reported_vals.get((j, allocation.get(j, -1)), 0)
                for j in range(self.n) if j != i
            )
            
            vals_without_i = {k: v for k, v in reported_vals.items() 
                             if k[0] != i}
            allocation_without_i = self.compute_allocation(vals_without_i)
            welfare_without_i = sum(
                reported_vals.get((j, allocation_without_i.get(j, -1)), 0)
                for j in range(self.n) if j != i
            )
            
            payments[i] = welfare_without_i - welfare_others_actual
        
        return payments, allocation

    def __init__(self, n_bidders):
        self.n = n_bidders

        other_bids = [bids[i] for i in bids if i != winner]
        payment = max(other_bids) if other_bids else 0
        return {winner: 1}, {winner: payment}

Zermelo-Fraenkel Set Theory and the Axiom of Choice

Historical Context

In the early 20th century, mathematicians discovered paradoxes in naive set theory, most famously Russell's paradox (1901). Ernst Zermelo (1908) and Abraham Fraenkel (1922) developed an axiomatic foundation for set theory, now known as ZFC (Zermelo-Fraenkel with Choice). This axiomatization provides a rigorous foundation for virtually all of modern mathematics, while the Axiom of Choice—perhaps the most controversial axiom—has profound and sometimes counterintuitive consequences.

Definitions

ZFC Axioms:

  1. Extensionality: Sets with the same elements are equal.
  2. Empty Set: There exists a set with no elements.
  3. Pairing: For any sets \(a, b\), there exists \(\{a, b\}\).
  4. Union: For any set \(x\), there exists \(\bigcup x\).
  5. Power Set: For any set \(x\), there exists \(\mathcal{P}(x)\).
  6. Infinity: There exists an infinite set.
  7. Replacement: The image of a set under a definable function is a set.
  8. Foundation: Every nonempty set has an \(\in\)-minimal element.
  9. Choice: Every collection of nonempty sets has a choice function.

Theorem: Well-Ordering Theorem

Theorem (Zermelo, 1904): Assuming the Axiom of Choice, every set can be well-ordered.

Proof Sketch

Let \(X\) be a set. By AC, there exists a choice function \(c\). Define by transfinite recursion:

\[x_\alpha = c(X \setminus \{x_\beta : \beta < \alpha\})\]

as long as the set is nonempty. This process terminates, giving a well-ordering. ∎

Notation Guide

  • \(\in\): elementhood relation
  • \(\mathcal{P}(X)\): power set of \(X\)
  • \(\bigcup x\): union of all elements of \(x\)
  • \(\omega\): first infinite ordinal
  • \(\aleph_0\): cardinality of natural numbers

        return cls(elements)

Gödel's Incompleteness Theorems

Historical Context

In 1900, David Hilbert posed the challenge of finding a complete and consistent set of axioms for all of mathematics. In 1931, Kurt Gödel shattered this dream with his incompleteness theorems, proving that any sufficiently powerful formal system cannot be both complete and consistent. This result ranks among the most profound in mathematical logic.

Definitions

A formal system \(\mathcal{F}\) consists of:

  • An alphabet of symbols
  • A grammar defining well-formed formulas
  • Axioms: a set of well-formed formulas
  • Inference rules for deriving theorems

A system is consistent if it cannot prove both a statement and its negation. It is complete if for every statement, either the statement or its negation is provable.

Theorem: First Incompleteness Theorem

Theorem (Gödel, 1931): Any consistent, recursively axiomatizable formal system \(\mathcal{F}\) that is sufficiently strong (can encode Peano arithmetic) is incomplete. There exists a statement \(G\) such that neither \(G\) nor \(\neg G\) is provable in \(\mathcal{F}\).

Proof Sketch

Step 1 (Gödel numbering): Assign a unique natural number \(\ulcorner \phi \urcorner\) to each formula \(\phi\).

Step 2 (Diagonal lemma): For any formula \(\psi(x)\), there exists a sentence \(\phi\) such that \(\mathcal{F} \vdash \phi \leftrightarrow \psi(\ulcorner \phi \urcorner)\).

Step 3 (Construction of G): Apply the diagonal lemma to \(\neg \text{Prov}(x)\) to obtain \(G\) such that \(G\) says "I am not provable."

Step 4 (Incompleteness): If \(\mathcal{F} \vdash G\), then \(G\) is false. If \(\mathcal{F} \vdash \neg G\), then \(G\) is true. Either way, inconsistency. ∎

Theorem: Second Incompleteness Theorem

Theorem (Gödel, 1931): If \(\mathcal{F}\) is a consistent, sufficiently strong formal system, then \(\mathcal{F}\) cannot prove its own consistency.

Notation Guide

  • \(\ulcorner \phi \urcorner\): Gödel number of formula \(\phi\)
  • \(\text{Prov}(n)\): provability predicate
  • \(G\): Gödel sentence
  • \(\mathcal{F} \vdash \phi\): \(\phi\) is provable in \(\mathcal{F}\)
  • \(\text{Con}(\mathcal{F})\): consistency statement

class FormalSystem:

        self.theorems.add(axiom)

The Navier-Stokes Existence and Smoothness Problem

Historical Context

The Navier-Stokes equations, formulated in the 19th century by Claude-Louis Navier and George Gabriel Stokes, describe the motion of viscous fluids. Despite their widespread use in engineering and physics, fundamental mathematical questions about their solutions remain unanswered. The question of whether smooth solutions always exist in three dimensions is one of the seven Millennium Prize Problems, with a $1 million prize offered by the Clay Mathematics Institute for its resolution.

Definitions

The incompressible Navier-Stokes equations in \(\mathbb{R}^3\) are:

\[\frac{\partial u}{\partial t} + (u \cdot \nabla)u = -\nabla p + \nu \Delta u + f\] \[\nabla \cdot u = 0\]

where \(u(x, t)\) is velocity, \(p(x, t)\) is pressure, \(\nu > 0\) is viscosity, and \(f\) is external force.

A solution is smooth if all derivatives exist and are continuous. A blow-up occurs if \(\|u(t)\| \to \infty\) as \(t \to T^*\) for finite \(T^*\).

Theorem: Leray-Hopf Weak Solutions

Theorem (Leray 1934, Hopf 1951): For initial data \(u_0 \in L^2(\mathbb{R}^3)\) with \(\nabla \cdot u_0 = 0\), there exists a weak solution \(u\) satisfying the energy inequality:

\[\frac{1}{2}\|u(t)\|_{L^2}^2 + \nu \int_0^t \|\nabla u(s)\|_{L^2}^2 ds \leq \frac{1}{2}\|u_0\|_{L^2}^2\]

Proof Sketch

The proof uses the Galerkin method:

Step 1: Approximate by finite-dimensional subspaces spanned by eigenfunctions of the Stokes operator.

Step 2: Establish uniform energy estimates. Multiplying by \(u\) and integrating:

\[\frac{1}{2}\frac{d}{dt}\|u\|_{L^2}^2 + \nu\|\nabla u\|_{L^2}^2 = \int f \cdot u\]

Step 3: Apply Gronwall's inequality for uniform bounds.

Step 4: Extract weakly convergent subsequence using Banach-Alaoglu.

Step 5: Pass to limit using compactness arguments. ∎

Notation Guide

  • \(u = (u_1, u_2, u_3)\): velocity vector field
  • \((u \cdot \nabla)u\): convective derivative
  • \(\nabla p\): pressure gradient
  • \(\Delta u\): Laplacian
  • \(\nabla \cdot u = 0\): incompressibility condition
  • \(L^2(\mathbb{R}^3)\): space of square-integrable functions
  • \(\|u\|_{L^2}\): L² norm

        self.dx = Lx / (Nx - 1)
        self.dy = Ly / (Ny - 1)
        
        self.x = np.linspace(0, Lx, Nx)
        self.y = np.linspace(0, Ly, Ny)
        self.X, self.Y = np.meshgrid(self.x, self.y)
        
        self.u = np.zeros((Ny, Nx))
        self.v = np.zeros((Ny, Nx))
        self.p = np.zeros((Ny, Nx))
    
    def laplacian(self, f):
        """Compute Laplacian using central differences."""
        lap = np.zeros_like(f)
        lap[1:-1, 1:-1] = (
            (f[1:-1, 2:] - 2*f[1:-1, 1:-1] + f[1:-1, :-2]) / self.dx**2 +
            (f[2:, 1:-1] - 2*f[1:-1, 1:-1] + f[:-2, 1:-1]) / self.dy**2
        )
        return lap
    
    def divergence(self, u, v):
        """Compute divergence of velocity field."""
        div = np.zeros_like(u)
        div[1:-1, 1:-1] = (
            (u[1:-1, 2:] - u[1:-1, :-2]) / (2*self.dx) +
            (v[2:, 1:-1] - v[:-2, 1:-1]) / (2*self.dy)
        )
        return div
    
    def convective_derivative(self, u, v, f):
        """Compute (u·∇)f."""
        dfdx = np.zeros_like(f)
        dfdy = np.zeros_like(f)
        dfdx[1:-1, 1:-1] = (f[1:-1, 2:] - f[1:-1, :-2]) / (2*self.dx)
        dfdy[1:-1, 1:-1] = (f[2:, 1:-1] - f[:-2, 1:-1]) / (2*self.dy)
        return u * dfdx + v * dfdy
    
    def solve_pressure_poisson(self, div_u):
        """Solve pressure Poisson equation using Jacobi iteration."""
        p = self.p.copy()
        rhs = div_u / self.dt
        
        for _ in range(50):
            p_new = p.copy()
            p_new[1:-1, 1:-1] = (
                (p[1:-1, 2:] + p[1:-1, :-2]) * self.dy**2 +
                (p[2:, 1:-1] + p[:-2, 1:-1]) * self.dx**2 -
                rhs[1:-1, 1:-1] * self.dx**2 * self.dy**2
            ) / (2 * (self.dx**2 + self.dy**2))
            
            # Boundary conditions
            p_new[0, :] = p_new[1, :]
            p_new[-1, :] = p_new[-2, :]
            p_new[:, 0] = p_new[:, 1]
            p_new[:, -1] = p_new[:, -2]
            
            p = p_new
        
        return p
    
    def step(self):
        """Take one time step using projection method."""
        u, v = self.u, self.v
        
        # Predictor
        conv_u = self.convective_derivative(u, v, u)
        conv_v = self.convective_derivative(u, v, v)
        
        lap_u = self.laplacian(u)
        lap_v = self.laplacian(v)
        
        u_star = u + self.dt * (-conv_u + self.nu * lap_u)
        v_star = v + self.dt * (-conv_v + self.nu * lap_v)
        
        # Solve pressure Poisson
        div_u_star = self.divergence(u_star, v_star)
        self.p = self.solve_pressure_poisson(div_u_star)
        
        # Corrector
        dpdx = np.zeros_like(self.p)
        dpdy = np.zeros_like(self.p)
        dpdx[1:-1, 1:-1] = (self.p[1:-1, 2:] - self.p[1:-1, :-2]) / (2*self.dx)
        dpdy[1:-1, 1:-1] = (self.p[2:, 1:-1] - self.p[:-2, 1:-1]) / (2*self.dy)
        
        self.u = u_star - self.dt * dpdx
        self.v = v_star - self.dt * dpdy
        
        # Boundary conditions (no-slip)
        self.u[0, :] = self.u[-1, :] = self.u[:, 0] = self.u[:, -1] = 0
        self.v[0, :] = self.v[-1, :] = self.v[:, 0] = self.v[:, -1] = 0
    
    def kinetic_energy(self):
        """Compute total kinetic energy."""
        return 0.5 * np.sum(self.u**2 + self.v**2) * self.dx * self.dy

The Goldbach Conjecture and Additive Number Theory

Historical Context

In 1742, Christian Goldbach wrote to Leonhard Euler proposing that every even integer greater than 2 can be expressed as the sum of two primes. Euler believed the conjecture to be true but could not prove it. Despite being verified computationally for all even numbers up to \(4 \times 10^{18}\), the conjecture remains unproven. It stands as one of the oldest and best-known unsolved problems in number theory.

Definitions

The Goldbach Conjecture states: Every even integer \(n > 2\) can be written as \(n = p + q\) where \(p\) and \(q\) are prime numbers.

The Weak Goldbach Conjecture states: Every odd integer \(n > 5\) can be written as \(n = p + q + r\) where \(p, q, r\) are primes. This was proven by Harald Helfgott in 2013.

Chen's Theorem (1973): Every sufficiently large even number can be written as the sum of either two primes, or a prime and a semiprime.

The Goldbach function \(g(n)\) counts the number of ways to write even \(n\) as a sum of two primes.

Theorem: Chen's Theorem

Theorem (Chen Jingrun, 1973): Every sufficiently large even integer \(n\) can be written as \(n = p + P_2\), where \(p\) is prime and \(P_2\) is either prime or a product of two primes.

Proof Sketch

Chen's proof uses sieve theory:

Step 1: Define candidates \(A = \{n - p : p \leq n, \, p \text{ prime}, \, (n-p, P(z)) = 1\}\).

Step 2: Apply weighted sieve to count elements with few prime factors.

Step 3: Use Jurkat-Richert sieve for lower bounds.

Step 4: Show elements with at most 2 prime factors contribute positively. ∎

Notation Guide

  • \(p, q, r\): prime numbers
  • \(P_2\): prime or semiprime
  • \(g(n)\): Goldbach partition function
  • \(\pi(x)\): prime counting function
  • \(P(z) = \prod_{p < z} p\): primorial
  • \(\mu(d)\): Möbius function
  • \(\varphi(n)\): Euler's totient function

📜 Math History: From Emmy Noether to Bourbaki — The Rise of Abstract Algebra

The early 20th century witnessed a profound transformation in mathematics, as the field shifted from concrete, calculation-oriented approaches to abstract, structural thinking. At the center of this revolution stood Emmy Noether, whose work laid the foundation for modern abstract algebra and influenced nearly every branch of mathematics.

Born in 1882 in Erlangen, Germany, Emmy Noether overcame significant barriers as a woman in mathematics to become one of the most influential mathematicians of the 20th century. Her 1921 paper "Idealtheorie in Ringbereichen" (Ideal Theory in Ring Domains) revolutionized the study of commutative rings by showing that every ideal has a unique factorization into primary ideals—a result now known as the Lasker-Noether theorem. This work established the conceptual framework that would dominate algebra for generations.

Noether's most profound insight was her realization that algebraic structures should be studied through their homomorphisms and relationships rather than through explicit calculations. Her famous dictum that "numbers, functions, and operations do not precede their relationships, but arise from them" captured the essence of this structural approach. This perspective, now taken for granted, was revolutionary at the time.

In 1930, Bartel van der Waerden published "Moderne Algebra," a textbook that synthesized Noether's lectures and Emil Artin's insights into a comprehensive exposition of abstract algebra. The book's approach—defining algebraic structures axiomatically and deriving their properties abstractly—became the standard paradigm. Van der Waerden's text went through numerous editions and translations, spreading the new abstract approach worldwide.

The influence of this abstract approach extended far beyond algebra. In 1935, the group of young French mathematicians who would become known as Nicolas Bourbaki began meeting to reformulate all of mathematics on rigorous, axiomatic foundations. Inspired by Noether's structural approach and Hilbert's formalism, Bourbaki aimed to present mathematics as a unified edifice built from set-theoretic foundations. Their "Éléments de mathématique," published from 1939 onward, became the definitive reference for generations of mathematicians.

The Bourbaki group's influence peaked in the 1950s and 1960s, when their emphasis on structure, generality, and rigor dominated mathematical research and education. While later generations would critique their excessive abstraction and neglect of geometry and applied mathematics, the Bourbaki project's impact on mathematical clarity and organization remains undeniable.

Emmy Noether's legacy extends through the generations of mathematicians she influenced. Her students included Max Deuring, Hans Fitting, and Otto Schilling. Her ideas influenced algebraists like Emil Artin, Wolfgang Krull, and Claude Chevalley, who in turn shaped the next generation. The structural approach she championed now permeates all of mathematics, from algebraic geometry to theoretical physics, where her famous theorem connecting symmetries and conservation laws remains fundamental.

The transformation from concrete to abstract mathematics, catalyzed by Noether and propagated by Bourbaki, represents one of the most significant shifts in mathematical thinking. It enabled the development of modern algebraic geometry, category theory, and much of contemporary mathematics. Today, as we navigate between abstraction and application, the tension between these approaches—embodied in the historical arc from Noether to Bourbaki—continues to shape mathematical practice.

IMO 2023 Problem 2 (Combinatorial Geometry)

Let \(n\) be a positive integer. A Japanese triangle consists of \(1 + 2 + \cdots + n\) circles arranged in an equilateral triangular shape such that for each \(i = 1, 2, \ldots, n\), the \(i\)-th row contains exactly \(i\) circles, exactly one of which is colored red. A ninja path is a sequence of \(n\) circles obtained by starting in the top row, then repeatedly going from a circle to one of the two circles immediately below it, and finishing in the bottom row.

Find the maximum possible number of ninja paths that contain at least one red circle, over all Japanese triangles.

Hint

Consider the binary representation of positions. Think about how many paths pass through a given circle, and how to place red circles to maximize coverage. The answer involves powers of 2.

Solution

The answer is \(2^n - 1\).

Proof:

First, note that the total number of ninja paths in any Japanese triangle of size \(n\) is \(2^{n-1}\), since at each of the \(n-1\) steps down the triangle, we have 2 choices.

For a circle in row \(i\) and position \(j\) (where \(1 \leq j \leq i\)), the number of ninja paths passing through it equals:

\[\binom{i-1}{j-1} \cdot 2^{n-i}\]

This is because there are \(\binom{i-1}{j-1}\) ways to reach that circle from the top, and \(2^{n-i}\) ways to continue to the bottom.

To maximize the number of paths containing at least one red circle, we should place red circles to cover as many distinct paths as possible. The optimal strategy is to place the red circle in row \(i\) at position \(j = 1\) (or symmetrically \(j = i\)) for all \(i\), creating a "staircase" pattern along the left edge.

With this placement, the number of paths containing at least one red circle is:

\[\sum_{i=1}^{n} 2^{n-i} = 2^n - 1\]

This is because the red circle in row \(i\) covers exactly \(2^{n-i}\) new paths (those that reach the left edge at row \(i\) for the first time).

To show this is optimal, note that any ninja path can contain at most one red circle from each row, and the paths form a binary tree structure. The maximum coverage is achieved when the red circles are placed to cover disjoint sets of paths, which the staircase arrangement accomplishes. ∎

The Lorenz System

\[\begin{aligned} \frac{dx}{dt} &= \sigma(y - x) \\ \frac{dy}{dt} &= x(\rho - z) - y \\ \frac{dz}{dt} &= xy - \beta z \end{aligned}\]
