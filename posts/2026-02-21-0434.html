Lattice Theory: Order and Structure

lattice-theory

Motivation

Lattice theory provides a unified framework for studying order and structure across mathematics. From the divisibility lattice of integers to the lattice of subspaces of a vector space, lattices appear everywhere. The theory was developed by Garrett Birkhoff and others in the 1930s as a generalization of Boolean algebras. Lattices connect algebra, logic, topology, and computer science, providing tools for understanding hierarchical structures and closure operations.

Definitions

  • Partially Ordered Set (Poset): A set \(P\) with a binary relation \(\leq\) that is reflexive, antisymmetric, and transitive.
  • Lattice: A poset in which every pair of elements has a least upper bound (join, denoted \(\vee\)) and a greatest lower bound (meet, denoted \(\wedge\)).
  • Complete Lattice: A lattice in which every subset has a join and a meet.
  • Distributive Lattice: A lattice satisfying \(a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)\) for all \(a, b, c\).
  • Modular Lattice: A lattice satisfying: if \(a \leq c\), then \(a \vee (b \wedge c) = (a \vee b) \wedge c\).
  • Boolean Algebra: A complemented distributive lattice with bounds 0 and 1.

Theorem: Birkhoff's Representation Theorem

Theorem: Every finite distributive lattice is isomorphic to the lattice of lower sets of its poset of join-irreducible elements. Equivalently, if \(L\) is a finite distributive lattice and \(J(L)\) is the set of join-irreducible elements of \(L\), then: \[L \cong \mathcal{O}(J(L))\] where \(\mathcal{O}(P)\) denotes the lattice of order ideals (lower sets) of poset \(P\).

Proof Sketch

Define a map \(\phi: L \to \mathcal{O}(J(L))\) by \(\phi(x) = \{j \in J(L) : j \leq x\}\). This map is order-preserving. To show it's an isomorphism:

  1. Injective: If \(\phi(x) = \phi(y)\), then \(x\) and \(y\) have the same join-irreducible elements below them. In a finite lattice, every element is the join of join-irreducibles below it, so \(x = y\).
  2. Surjective: For any order ideal \(I \subseteq J(L)\), let \(x = \bigvee I\). Then \(\phi(x) = I\) because if \(j \in J(L)\) with \(j \leq x\), distributivity implies \(j\) is below some element of \(I\), hence \(j \in I\).
  3. Preserves meets and joins: Direct verification using properties of order ideals.

Notation Guide

  • \(P, Q\) — Partially ordered sets (posets)
  • \(L\) — Lattice
  • \(a \vee b\) — Join (least upper bound) of \(a\) and \(b\)
  • \(a \wedge b\) — Meet (greatest lower bound) of \(a\) and \(b\)
  • \(\hat{0}, \hat{1}\) — Minimum and maximum elements
  • \(J(L)\) — Set of join-irreducible elements
  • \(M(L)\) — Set of meet-irreducible elements
  • \(\mathcal{O}(P)\) — Lattice of order ideals of \(P\)

class LatticeElement:
    """Represents an element in a finite lattice."""
    def __init__(self, name, join_irreducible=False):
        self.name = name
        self.join_irreducible = join_irreducible
        self.below = set()  # Elements below this one
        self.above = set()  # Elements above this one
    
    def __repr__(self):
        return self.name

class FiniteLattice:
    """Finite lattice with explicit meet and join operations."""
    
    def __init__(self, elements, order_relation):
        self.elements = {e.name: e for e in elements}
        self.order = order_relation
        self._compute_transitive_closure()
        self._identify_irreducibles()
    
    def _compute_transitive_closure(self):
        names = list(self.elements.keys())
        self.reachable = {a: set() for a in names}
        for a, b in self.order:
            self.reachable[a].add(b)
        for k in names:
            for i in names:
                if k in self.reachable[i]:
                    self.reachable[i].update(self.reachable[k])
    
    def leq(self, a, b):
        return b in self.reachable.get(a, set()) or a == b
    
    def join(self, a, b):
        upper_bounds = [n for n, e in self.elements.items() 
                       if self.leq(a, n) and self.leq(b, n)]
        for ub in upper_bounds:
            if all(self.leq(ub, other) for other in upper_bounds):
                return ub
        return None
    
    def meet(self, a, b):
        lower_bounds = [n for n, e in self.elements.items() 
                       if self.leq(n, a) and self.leq(n, b)]
        for lb in lower_bounds:
            if all(self.leq(other, lb) for other in lower_bounds):
                return lb
        return None
    
    def join_irreducibles(self):
        return {name for name, e in self.elements.items() 
                if e.join_irreducible}

Complex Analysis: The Riemann Mapping Theorem

complex-analysis

Motivation

Complex analysis reveals a profound dichotomy between the rigid behavior of holomorphic functions and the geometric flexibility of conformal mappings. Unlike real differentiable functions, complex differentiable (holomorphic) functions are infinitely differentiable, admit power series expansions, and satisfy remarkable global properties. The Riemann mapping theorem stands as one of the most beautiful results in mathematics: any simply connected proper subset of the complex plane (except the whole plane) can be conformally mapped to the unit disk.

Definitions

  • Holomorphic Function: A function \(f: U \to \mathbb{C}\) is holomorphic on open set \(U\) if the limit \(f'(z) = \lim_{h \to 0} \frac{f(z+h) - f(z)}{h}\) exists for all \(z \in U\).
  • Conformal Mapping: A holomorphic function with non-vanishing derivative, preserving angles and orientation locally.
  • Simply Connected: A domain where every closed curve can be continuously contracted to a point (no holes).
  • Schwarz Lemma: If \(f: \mathbb{D} \to \mathbb{D}\) is holomorphic with \(f(0) = 0\), then \(|f(z)| \leq |z|\) and \(|f'(0)| \leq 1\).

Theorem: Riemann Mapping Theorem

Theorem: Let \(U \subsetneq \mathbb{C}\) be a simply connected open set with \(U \neq \mathbb{C}\). Then for any \(z_0 \in U\), there exists a unique conformal bijection \(f: U \to \mathbb{D}\) (where \(\mathbb{D} = \{z : |z| < 1\}\)) such that: \[f(z_0) = 0 \quad \text{and} \quad f'(z_0) > 0\]

Proof Sketch

  1. Reduction: First map \(U\) to a bounded domain using a Möbius transformation.
  2. Normal Family: Consider the family \(\mathcal{F}\) of injective holomorphic functions \(f: U \to \mathbb{D}\) with \(f(z_0) = 0\). By Montel's theorem, this is a normal family.
  3. Extremal Problem: Maximize \(|f'(z_0)|\) over \(\mathcal{F}\). A maximizing function exists by compactness.
  4. Surjectivity: If \(g\) maximizes but is not surjective, one can construct \(h\) with larger derivative, contradicting maximality.
  5. Uniqueness: If \(f_1, f_2\) both satisfy the conditions, then \(f_2 \circ f_1^{-1}\) is an automorphism of \(\mathbb{D}\) fixing 0 with positive derivative, hence the identity.

Notation Guide

  • \(\mathbb{C}\) — Complex plane
  • \(\mathbb{D}\) — Unit disk \(\{z \in \mathbb{C} : |z| < 1\}\)
  • \(\mathbb{H}\) — Upper half-plane \(\{z : \text{Im}(z) > 0\}\)
  • \(f'(z)\) — Complex derivative
  • \(\text{Aut}(U)\) — Group of automorphisms of domain \(U\)

Lie Algebras: Structure and Classification

lie-algebras

Motivation

Lie algebras emerged from Sophus Lie's study of continuous transformation groups (Lie groups). They linearize the structure of Lie groups, making them more tractable while preserving essential geometric information. The exponential map connects Lie algebras to Lie groups, much as the logarithm connects multiplication to addition. Lie algebras classify the symmetries of differential equations, appear in the standard model of particle physics, and provide the framework for representation theory.

Definitions

  • Lie Algebra: A vector space \(\mathfrak{g}\) over a field \(F\) with a bilinear operation \([\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}\) (the Lie bracket) satisfying:
    • Antisymmetry: \([x, y] = -[y, x]\)
    • Jacobi identity: \([x, [y, z]] + [y, [z, x]] + [z, [x, y]] = 0\)
  • Adjoint Representation: \(\text{ad}_x(y) = [x, y]\), giving a representation \(\mathfrak{g} \to \mathfrak{gl}(\mathfrak{g})\).
  • Killing Form: \(\kappa(x, y) = \text{tr}(\text{ad}_x \circ \text{ad}_y)\), a symmetric bilinear form.
  • Semisimple: A Lie algebra with no non-zero abelian ideals (equivalently, Killing form is non-degenerate).

Theorem: Cartan's Criterion for Semisimplicity

Theorem: A finite-dimensional Lie algebra \(\mathfrak{g}\) over a field of characteristic zero is semisimple if and only if its Killing form \(\kappa\) is non-degenerate. That is: \[\mathfrak{g} \text{ is semisimple} \iff \forall x \neq 0, \exists y : \kappa(x, y) \neq 0\]

Proof Sketch

(\(\Rightarrow\)): Let \(\mathfrak{r} = \{x \in \mathfrak{g} : \kappa(x, y) = 0 \text{ for all } y\}\) be the radical of \(\kappa\). Then \(\mathfrak{r}\) is an ideal with \(\kappa|_\mathfrak{r} = 0\). By Cartan's solvability criterion, \(\mathfrak{r}\) is solvable. Since \(\mathfrak{g}\) is semisimple, \(\mathfrak{r} = 0\).

(\(\Leftarrow\)): Let \(\mathfrak{a}\) be an abelian ideal. For \(x \in \mathfrak{a}\) and \(y \in \mathfrak{g}\), \(\text{ad}_x \circ \text{ad}_y\) maps \(\mathfrak{g}\) to \(\mathfrak{a}\) and \(\mathfrak{a}\) to 0. Thus \((\text{ad}_x \circ \text{ad}_y)^2 = 0\), so \(\text{tr}(\text{ad}_x \circ \text{ad}_y) = 0\). Hence \(\kappa(x, y) = 0\) for all \(y\), so \(x = 0\) by non-degeneracy.

Notation Guide

  • \(\mathfrak{g}, \mathfrak{h}\) — Lie algebras (Fraktur font)
  • \([x, y]\) — Lie bracket
  • \(\text{ad}_x\) — Adjoint action of \(x\)
  • \(\kappa(x, y)\) — Killing form
  • \(\mathfrak{sl}_n\) — Special linear Lie algebra (trace-zero matrices)
  • \(\mathfrak{so}_n\) — Special orthogonal Lie algebra (skew-symmetric matrices)

import numpy as np
from itertools import product

class LieAlgebra:
    """Finite-dimensional Lie algebra with structure constants."""
    
    def __init__(self, structure_constants, basis_names=None):
        self.c = np.array(structure_constants)
        self.dim = self.c.shape[0]
        self.basis_names = basis_names or [f"e_{i}" for i in range(self.dim)]
        self._verify_jacobi()
    
    def _verify_jacobi(self):
        for i, j, k in product(range(self.dim), repeat=3):
            lhs = np.zeros(self.dim)
            lhs += self.bracket(self.basis(i), self.bracket(self.basis(j), self.basis(k)))
            lhs += self.bracket(self.basis(j), self.bracket(self.basis(k), self.basis(i)))
            lhs += self.bracket(self.basis(k), self.bracket(self.basis(i), self.basis(j)))
            if not np.allclose(lhs, 0):
                raise ValueError(f"Jacobi identity fails for {i},{j},{k}")
    
    def basis(self, i):
        v = np.zeros(self.dim)
        v[i] = 1
        return v
    
    def bracket(self, x, y):
        result = np.zeros(self.dim)
        for i in range(self.dim):
            for j in range(self.dim):
                result += x[i] * y[j] * self.c[i, j]
        return result
    
    def ad(self, x):
        mat = np.zeros((self.dim, self.dim))
        for j in range(self.dim):
            mat[:, j] = self.bracket(x, self.basis(j))
        return mat
    
    def killing_form(self, x, y):
        ad_x = self.ad(x)
        ad_y = self.ad(y)
        return np.trace(ad_x @ ad_y)
    
    def killing_matrix(self):
        K = np.zeros((self.dim, self.dim))
        for i in range(self.dim):
            for j in range(self.dim):
                K[i, j] = self.killing_form(self.basis(i), self.basis(j))
        return K
    
    def is_semisimple(self, tol=1e-10):
        K = self.killing_matrix()
        return abs(np.linalg.det(K)) > tol

def sl2_lie_algebra():
    """sl(2, C) with basis e, f, h and relations [h,e]=2e, [h,f]=-2f, [e,f]=h."""
    c = np.zeros((3, 3, 3))
    c[0, 1, 2] = 1; c[1, 0, 2] = -1  # [e, f] = h
    c[2, 0, 0] = 2; c[0, 2, 0] = -2  # [h, e] = 2e
    c[2, 1, 1] = -2; c[1, 2, 1] = 2  # [h, f] = -2f
    return LieAlgebra(c, ['e', 'f', 'h'])

sl2 = sl2_lie_algebra()
print("Lie Algebra sl(2):")
print(f"  Dimension: {sl2.dim}")
print(f"  Killing Form:\n{sl2.killing_matrix()}")
print(f"  Semisimple: {sl2.is_semisimple()}")

# Verify bracket relations

print(f"  [e, f] = h? {np.allclose(sl2.bracket(e, f), h)}")
print(f"  [h, e] = 2e? {np.allclose(sl2.bracket(h, e), 2*e)}")
print(f"  [h, f] = -2f? {np.allclose(sl2.bracket(h, f), -2*f)}")

Network Flow Algorithms: Maximum Flow and Minimum Cut

network-flow

Motivation

Network flow problems model the movement of commodities through a network—whether data through computer networks, traffic through road systems, or fluids through pipes. The maximum flow problem asks how much flow can be sent from a source to a sink, while the minimum cut problem asks for the cheapest way to disconnect the source from the sink. The max-flow min-cut theorem establishes that these two problems have the same optimal value, a result with profound implications for duality theory, linear programming, and combinatorial optimization.

Definitions

  • Flow Network: A directed graph \(G = (V, E)\) with capacity function \(c: E \to \mathbb{R}_{\geq 0}\), source \(s \in V\), and sink \(t \in V\).
  • Flow: A function \(f: E \to \mathbb{R}_{\geq 0}\) satisfying capacity constraints and flow conservation.
  • Value of Flow: \(|f| = \sum_{(s,v) \in E} f(s,v) - \sum_{(v,s) \in E} f(v,s)\).
  • s-t Cut: A partition \((S, T)\) of \(V\) with \(s \in S\) and \(t \in T\).
  • Capacity of Cut: \(c(S, T) = \sum_{(u,v) \in E: u \in S, v \in T} c(u,v)\).

Theorem: Max-Flow Min-Cut Theorem

Theorem: In any flow network, the maximum value of an \(s\)-\(t\) flow equals the minimum capacity of an \(s\)-\(t\) cut: \[\max_f |f| = \min_{(S,T)} c(S, T)\]

Proof Sketch

Weak Duality: For any flow \(f\) and cut \((S, T)\), \(|f| \leq c(S, T)\). All flow from \(s\) to \(t\) must cross the cut, and cannot exceed its capacity.

Strong Duality: When Ford-Fulkerson terminates, the residual graph has no \(s\)-\(t\) path. Let \(S\) be vertices reachable from \(s\) in the residual graph. Then all edges from \(S\) to \(T\) are saturated and all edges from \(T\) to \(S\) have zero flow. Thus \(|f| = c(S, T)\).

Notation Guide

  • \(G = (V, E)\) — Directed graph
  • \(c(u,v)\) — Capacity of edge \((u,v)\)
  • \(f(u,v)\) — Flow on edge \((u,v)\)
  • \(|f|\) — Value of flow
  • \(G_f\) — Residual graph
  • \((S, T)\) — s-t cut

Python Code

from collections import defaultdict, deque

class FlowNetwork:
    """Flow network with Ford-Fulkerson (Edmonds-Karp) implementation."""
    
    def __init__(self):
        self.graph = defaultdict(dict)
        self.edges = []
    
    def add_edge(self, u, v, capacity):
        self.graph[u][v] = capacity
        self.graph[v][u] = 0
        self.edges.append((u, v, capacity))
    
    def bfs_augmenting_path(self, s, t):
        parent = {s: None}
        queue = deque([s])
        while queue and t not in parent:
            u = queue.popleft()
            for v, cap in self.graph[u].items():
                if v not in parent and cap > 0:
                    parent[v] = u
                    queue.append(v)
        if t not in parent:
            return None, 0
        path = []
        v = t
        bottleneck = float('inf')
        while v != s:
            u = parent[v]
            path.append((u, v))
            bottleneck = min(bottleneck, self.graph[u][v])
            v = u
        return path[::-1], bottleneck
    
    def max_flow(self, s, t):
        flow = defaultdict(int)
        total_flow = 0
        while True:
            path, bottleneck = self.bfs_augmenting_path(s, t)
            if path is None:
                break
            for u, v in path:
                flow[(u, v)] += bottleneck
                flow[(v, u)] -= bottleneck
                self.graph[u][v] -= bottleneck
                self.graph[v][u] += bottleneck
            total_flow += bottleneck
        return total_flow, flow
    
    def min_cut(self, s):
        visited = set()
        queue = deque([s])
        while queue:
            u = queue.popleft()
            if u in visited:
                continue
            visited.add(u)
            for v, cap in self.graph[u].items():
                if cap > 0 and v not in visited:
                    queue.append(v)
        return visited, set(self.graph.keys()) - visited

# Example
network = FlowNetwork()
edges = [('s', 'a', 10), ('s', 'b', 5), ('a', 'b', 15), ('a', 'c', 10),
         ('b', 'd', 10), ('c', 'd', 5), ('c', 't', 10), ('d', 't', 10)]
for u, v, c in edges:
    network.add_edge(u, v, c)

max_flow_value, flow = network.max_flow('s', 't')
print(f"Maximum Flow: {max_flow_value}")
S, T = network.min_cut('s')
print(f"Minimum Cut: S={S}, T={T}")
print(f"Max-Flow Min-Cut Theorem verified: {max_flow_value == sum(c for u,v,c in edges if u in S and v in T)}")

Image Processing: PDE-Based Methods and the Heat Equation

image-processing

Motivation

Partial differential equations provide a powerful framework for image processing tasks including denoising, segmentation, and edge detection. The heat equation, the prototypical parabolic PDE, smooths images by diffusing intensity values. While linear diffusion blurs edges, nonlinear methods like Perona-Malik anisotropic diffusion preserve edges while removing noise.

Definitions

  • Image: A function \(u: \Omega \to \mathbb{R}\) where \(\Omega \subset \mathbb{R}^2\) is the image domain.
  • Heat Equation: \(\frac{\partial u}{\partial t} = \Delta u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2}\).
  • Perona-Malik Diffusion: \(\frac{\partial u}{\partial t} = \text{div}(g(|\nabla u|) \nabla u)\) where \(g(s) = \frac{1}{1 + (s/\lambda)^2}\).
  • Total Variation: \(\text{TV}(u) = \int_\Omega |\nabla u|\, dx\).

Theorem: Scale Space Properties of Linear Diffusion

Theorem: The solution \(u(x, y, t)\) to the heat equation with initial condition \(u(x, y, 0) = f(x, y)\) satisfies:

  1. Causality: No new level curves of constant intensity are created as \(t\) increases.
  2. Maximum Principle: \(\min f \leq u(x, y, t) \leq \max f\) for all \(t > 0\).
  3. Lyapunov Functionals: The \(L^p\) norms \(\|u(\cdot, t)\|_p\) are non-increasing in \(t\).

Notation Guide

  • \(u(x, y, t)\) — Image intensity at position \((x,y)\) and scale \(t\)
  • \(\nabla u\) — Gradient
  • \(\Delta u\) — Laplacian
  • \(\text{div}(\mathbf{v})\) — Divergence
  • \(|\nabla u|\) — Gradient magnitude

Python Code

import numpy as np

def heat_equation_diffusion(image, num_steps, dt=0.1):
    """Apply linear diffusion (heat equation) to image."""
    u = image.astype(float).copy()
    for _ in range(num_steps):
        laplacian = (np.roll(u, 1, axis=0) + np.roll(u, -1, axis=0) +
                     np.roll(u, 1, axis=1) + np.roll(u, -1, axis=1) - 4*u)
        u = u + dt * laplacian
    return u

def perona_malik_diffusion(image, num_steps, dt=0.1, lambda_param=10):
    """Perona-Malik anisotropic diffusion."""
    u = image.astype(float).copy()
    def diffusivity(grad_mag):
        return 1.0 / (1.0 + (grad_mag / lambda_param)**2)
    for _ in range(num_steps):
        grad_x = np.roll(u, -1, axis=1) - u
        grad_y = np.roll(u, -1, axis=0) - u
        grad_mag = np.sqrt(grad_x**2 + grad_y**2)
        g = diffusivity(grad_mag)
        flux_x = g * grad_x
        flux_y = g * grad_y
        div_flux = (flux_x - np.roll(flux_x, 1, axis=1) +
                    flux_y - np.roll(flux_y, 1, axis=0))
        u = u + dt * div_flux
    return u

def total_variation_denoising(image, lambda_tv=0.1, num_iter=100, dt=0.01):
    """Rudin-Osher-Fatemi total variation denoising."""
    u = image.astype(float).copy()
    f = image.astype(float).copy()
    eps = 1e-8
    for _ in range(num_iter):
        grad_x = np.roll(u, -1, axis=1) - u
        grad_y = np.roll(u, -1, axis=0) - u
        grad_mag = np.sqrt(grad_x**2 + grad_y**2 + eps)
        term_x = grad_x / grad_mag
        term_y = grad_y / grad_mag
        div_term = (term_x - np.roll(term_x, 1, axis=1) +
                    term_y - np.roll(term_y, 1, axis=0))
        u = u + dt * (div_term - lambda_tv * (u - f))
    return u

Supply Chain Optimization: Inventory Theory and the EOQ Model

supply-chain

Motivation

Supply chain optimization balances competing objectives: minimizing inventory costs while ensuring product availability. The economic order quantity (EOQ) model, developed by Ford W. Harris in 1913, provides the foundational insight that optimal ordering policies trade off fixed ordering costs against holding costs.

Definitions

  • Economic Order Quantity (EOQ): The order quantity that minimizes total inventory costs.
  • Holding Cost \(h\): Cost per unit per time period to store inventory.
  • Ordering Cost \(K\): Fixed cost incurred each time an order is placed.
  • Demand Rate \(D\): Units demanded per time period.
  • Critical Ratio: \(\frac{c_u}{c_u + c_o}\) where \(c_u\) is underage cost and \(c_o\) is overage cost.

Theorem: EOQ Optimality

Theorem: For the classical EOQ model with constant demand rate \(D\), fixed ordering cost \(K\), and holding cost \(h\) per unit per period: \[Q^* = \sqrt{\frac{2KD}{h}}\] The minimum total cost per period is \(C^* = \sqrt{2KDh}\).

Proof Sketch

Total cost: \(C(Q) = \frac{KD}{Q} + \frac{hQ}{2}\). Taking derivative and setting to zero: \[\frac{dC}{dQ} = -\frac{KD}{Q^2} + \frac{h}{2} = 0\] Solving: \(Q^2 = \frac{2KD}{h}\), so \(Q^* = \sqrt{\frac{2KD}{h}}\). The second derivative \(\frac{d^2C}{dQ^2} = \frac{2KD}{Q^3} > 0\) confirms this is a minimum.

Notation Guide

  • \(Q\) — Order quantity
  • \(Q^*\) — Optimal order quantity (EOQ)
  • \(D\) — Demand rate
  • \(K\) — Fixed ordering cost
  • \(h\) — Holding cost per unit per period
  • \(c_u\) — Underage cost
  • \(c_o\) — Overage cost

Python Code

import numpy as np
from scipy import stats

class EOQModel:
    """Economic Order Quantity model for inventory optimization."""
    
    def __init__(self, demand_rate, ordering_cost, holding_cost, unit_cost=0):
        self.D = demand_rate
        self.K = ordering_cost
        self.h = holding_cost
        self.c = unit_cost
    
    def optimal_quantity(self):
        return np.sqrt(2 * self.K * self.D / self.h)
    
    def total_cost(self, Q=None):
        if Q is None:
            Q = self.optimal_quantity()
        return (self.K * self.D) / Q + (self.h * Q) / 2 + self.c * self.D

class NewsvendorModel:
    """Newsvendor model for single-period stochastic inventory."""
    
    def __init__(self, underage_cost, overage_cost, demand_dist):
        self.c_u = underage_cost
        self.c_o = overage_cost
        self.demand_dist = demand_dist
    
    def critical_ratio(self):
        return self.c_u / (self.c_u + self.c_o)
    
    def optimal_quantity(self):
        return self.demand_dist.ppf(self.critical_ratio())

Ramsey Theory: Order in Chaos

ramsey-theory

Motivation

Ramsey theory embodies the principle that complete disorder is impossible. In any sufficiently large structure, ordered substructures must emerge. Frank Ramsey proved the foundational result in 1930: for any coloring of edges of a large enough complete graph, a monochromatic complete subgraph must appear.

Definitions

  • Ramsey Number \(R(s, t)\): The smallest \(n\) such that any 2-coloring of edges of \(K_n\) contains a red \(K_s\) or a blue \(K_t\).
  • Schur's Theorem: For any \(r\)-coloring of \(\{1, 2, \ldots, N\}\) with \(N \geq S(r)\), there exist monochromatic \(x, y, z\) with \(x + y = z\).
  • Van der Waerden's Theorem: For any coloring of integers, arbitrarily long monochromatic arithmetic progressions exist.

Theorem: Ramsey's Theorem (Graph Version)

Theorem: For any positive integers \(s\) and \(t\), there exists a least integer \(R(s, t)\) such that every graph on \(R(s, t)\) vertices contains either a clique of size \(s\) or an independent set of size \(t\). Moreover: \[R(s, t) \leq \binom{s + t - 2}{s - 1}\]

Proof Sketch

By induction on \(s + t\). Consider any vertex \(v\) in a 2-colored \(K_n\) with \(n = R(s-1, t) + R(s, t-1)\). Partition remaining vertices into \(A\) (red edges to \(v\)) and \(B\) (blue edges to \(v\)). Either \(|A| \geq R(s-1, t)\) or \(|B| \geq R(s, t-1)\). In the first case, \(A\) contains a red \(K_{s-1}\) (which with \(v\) forms red \(K_s\)) or a blue \(K_t\). The bound follows from the recurrence \(R(s, t) \leq R(s-1, t) + R(s, t-1)\).

Notation Guide

  • \(R(s, t)\) — Ramsey number
  • \(K_n\) — Complete graph on \(n\) vertices
  • \(W(k, r)\) — Van der Waerden number
  • \(S(r)\) — Schur number

import numpy as np
from itertools import combinations
from math import comb

def ramsey_upper_bound(s, t):
    """Compute the Erdős–Szekeres upper bound for R(s, t)."""
    return comb(s + t - 2, s - 1)

def check_ramsey_property(graph, s, t):
    """Check if graph has either a clique of size s or independent set of size t."""
    n = len(graph)
    for vertices in combinations(range(n), s):
        if all(graph[i][j] == 1 for i, j in combinations(vertices, 2)):
            return True, False
    for vertices in combinations(range(n), t):
        if all(graph[i][j] == 0 for i, j in combinations(vertices, 2)):
            return False, True
    return False, False

def find_counterexample(n, s, t, max_trials=10000):
    """Search for a coloring of K_n avoiding red K_s and blue K_t."""
    for _ in range(max_trials):
        graph = np.random.randint(0, 2, size=(n, n))
        graph = np.triu(graph, 1) + np.triu(graph, 1).T
        has_c, has_i = check_ramsey_property(graph, s, t)
        if not has_c and not has_i:
            return graph
    return None

Combinatorial Game Theory: Nim and the Sprague-Grundy Theorem

combinatorial-game-theory

Motivation

Combinatorial game theory studies perfect-information games with no chance elements. The game of Nim, analyzed by Charles Bouton in 1901, provides the foundation for understanding impartial games. The Sprague-Grundy theorem shows that every impartial game is equivalent to a Nim heap, with the Grundy number serving as a complete invariant.

Definitions

  • Impartial Game: A game where the available moves depend only on the position, not on which player is moving.
  • Nim-sum: The bitwise XOR of heap sizes, denoted \(a \oplus b\).
  • Grundy Number \(g(P)\): \(g(P) = \text{mex}\{g(Q) : P \to Q\}\) where mex is the minimum excludant.
  • \(P\)-position — Previous player wins (Grundy = 0)
  • \(N\)-position — Next player wins (Grundy > 0)

Theorem: Sprague-Grundy Theorem

Theorem: Every impartial game under normal play is equivalent to a Nim heap. If \(G_1, G_2, \ldots, G_n\) are impartial games with Grundy numbers \(g_1, g_2, \ldots, g_n\), then their disjunctive sum has Grundy number: \[g(G) = g_1 \oplus g_2 \oplus \cdots \oplus g_n\] A position is winning for the next player if and only if its Grundy number is non-zero.

Notation Guide

  • \(G, H\) — Games
  • \(G + H\) — Disjunctive sum
  • \(g(G)\) — Grundy number
  • \(a \oplus b\) — Nim-sum (bitwise XOR)
  • \(\text{mex}(S)\) — Minimum excludant

from functools import lru_cache

def nim_sum(heaps):
    """Compute the nim-sum (bitwise XOR) of heap sizes."""
    result = 0
    for h in heaps:
        result ^= h
    return result

def mex(s):
    """Minimum excludant: smallest non-negative integer not in s."""
    m = 0
    while m in s:
        m += 1
    return m

class NimGame:
    """Standard Nim game with multiple heaps."""
    
    def __init__(self, heaps):
        self.heaps = list(heaps)
    
    def grundy(self):
        return nim_sum(self.heaps)
    
    def find_winning_move(self):
        g = self.grundy()
        if g == 0:
            return None
        for i, h in enumerate(self.heaps):
            target = h ^ g
            if target < h:
                return (i, target)
        return None

@lru_cache(maxsize=None)
def kayles_grundy(n):
    """Grundy number for Kayles with n pins in a row."""
    if n == 0:
        return 0
    if n == 1:
        return 1
    reachable = set()
    for i in range(n):
        left, right = i, n - i - 1
        reachable.add(kayles_grundy(left) ^ kayles_grundy(right))
    for i in range(n - 1):
        left, right = i, n - i - 2
        reachable.add(kayles_grundy(left) ^ kayles_grundy(right))
    return mex(reachable)

The Probabilistic Method: Existence Through Randomness

probabilistic-method

Motivation

The probabilistic method, pioneered by Paul Erdős, proves the existence of mathematical objects by showing that a random construction produces the desired object with positive probability. This non-constructive approach has revolutionized combinatorics, graph theory, and theoretical computer science.

Definitions

  • Expectation Argument: If \(E[X] = \mu\), then there exists an outcome where \(X \geq \mu\) and one where \(X \leq \mu\).
  • Lovász Local Lemma (LLL): If events are mostly independent and not too probable, there's positive probability none occur.
  • Chernoff Bound: Exponential concentration for sums of independent random variables.

Theorem: Lovász Local Lemma (Symmetric Version)

Theorem: Let \(A_1, A_2, \ldots, A_n\) be events where each \(A_i\) is independent of all but at most \(d\) other events, and \(P(A_i) \leq p\). If \(ep(d+1) \leq 1\), then: \[P\left(\bigcap_{i=1}^n \overline{A_i}\right) > 0\]

Notation Guide

  • \(E[X]\) — Expected value
  • \(\text{Var}(X)\) — Variance
  • \(P(A)\) — Probability of event \(A\)
  • \(G(n, p)\) — Erdős–Rényi random graph

Python Code

import numpy as np
from math import e

def max_cut_randomized(n, edges, iterations=1000):
    """Find large cut using randomized approach (expected size ≥ |E|/2)."""
    best_cut = 0
    best_partition = None
    for _ in range(iterations):
        partition = np.random.randint(0, 2, n)
        cut_size = sum(1 for u, v in edges if partition[u] != partition[v])
        if cut_size > best_cut:
            best_cut = cut_size
            best_partition = partition
    return best_cut, best_partition

def find_large_independent_set(graph, iterations=1000):
    """Use probabilistic method to find large independent set."""
    n = len(graph)
    avg_degree = graph.sum(axis=1).mean()
    theoretical_bound = n / (2 * avg_degree + 1)
    best_set = []
    for _ in range(iterations):
        vertices = list(range(n))
        np.random.shuffle(vertices)
        independent_set = []
        used = set()
        for v in vertices:
            if v not in used:
                independent_set.append(v)
                used.add(v)
                for u in range(n):
                    if graph[v, u]:
                        used.add(u)
        if len(independent_set) > len(best_set):
            best_set = independent_set
    return best_set, theoretical_bound

Math History: Henri Poincaré — The Last Universalist

poincare

Biography

Henri Poincaré (1854–1912) stands as one of the most influential mathematicians and physicists in history. Born in Nancy, France, Poincaré displayed extraordinary intellectual gifts from an early age. Despite poor eyesight and motor coordination difficulties, he excelled academically, entering the École Polytechnique at age 18 and earning his doctorate in mathematics in 1879.

By age 32, he was elected to the French Academy of Sciences. His output was prodigious: over 500 papers and 30 books spanning virtually every field of mathematics and theoretical physics.

Contributions to Mathematics

  • Topology: Poincaré essentially created algebraic topology, introducing the fundamental group, homology, and the Poincaré duality theorem. His famous conjecture remained open for nearly a century until Grigori Perelman's proof in 2002-2003.
  • Dynamical Systems: His work on the three-body problem laid the foundations of chaos theory. He discovered sensitive dependence on initial conditions—the butterfly effect.
  • Automorphic Functions: Developed the theory of Fuchsian and Kleinian groups, connecting complex analysis, hyperbolic geometry, and group theory.

Contributions to Physics

  • Special Relativity: Independently of Einstein, Poincaré formulated the Lorentz transformations and recognized that the speed of light is a limiting velocity.
  • Quantum Theory: Poincaré was among the first to recognize the significance of quantum theory, attending the first Solvay Conference in 1911.

Philosophy of Science

Poincaré argued for conventionalism—the view that certain scientific principles are conventions chosen for their usefulness rather than discovered truths. He emphasized the role of intuition in mathematics. His famous statement that "mathematics is the art of giving the same name to different things" captures his view of mathematical creativity.

Legacy

Poincaré is often called "the last universalist" because he was perhaps the last mathematician to make fundamental contributions across the entire spectrum of mathematics. The Poincaré group, Poincaré lemma, Poincaré inequality, Poincaré-Hopf theorem, and countless other concepts bear his name. His collected works fill eleven volumes, a testament to one of humanity's greatest mathematical minds.

Problem: A Functional Equation from the IMO Shortlist

Difficulty: ★★★★☆ (Advanced)

Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all real numbers \(x\) and \(y\):

\[f(x + f(x + y)) + f(xy) = x + f(x + y) + yf(x)\]

💡 Hint

Start by investigating what happens when you set \(y = 0\). This should give you information about the behavior of \(f\) at specific points. Then try \(x = 0\) to learn more about the function's structure. Look for linear solutions of the form \(f(x) = ax + b\) and verify if they satisfy the equation.

📖 Solution

Solution: The only solutions are \(f(x) = x\) and \(f(x) = 2 - x\).

Step 1: Let \(P(x, y)\) denote the assertion \(f(x + f(x + y)) + f(xy) = x + f(x + y) + yf(x)\).

Step 2: From \(P(0, y)\): \(f(f(y)) + f(0) = f(y) + yf(0)\). If \(f(0) = 0\), then \(f(f(y)) = f(y)\).

Step 3: From \(P(x, 0)\): \(f(x + f(x)) + f(0) = x + f(x)\). If \(f(0) = 0\), then \(f(x + f(x)) = x + f(x)\).

Step 4: Assume \(f(x) = ax + b\). Substituting and comparing coefficients:

  • From \(xy\) terms: \(a = a\) ✓
  • From \(y\) terms: \(a^2 = a + b\)
  • From constants: \(ab + b = 0\), so \(b(a + 1) = 0\)

Case 1: \(b = 0\): Then \(a^2 = a\), so \(a = 0\) or \(a = 1\). Only \(a = 1\) works, giving \(f(x) = x\).

Case 2: \(a = -1\): Then \(1 = -1 + b\), so \(b = 2\). This gives \(f(x) = 2 - x\).

Both solutions can be verified by direct substitution into the original equation.

Phase Portraits of Dynamical Systems

Phase portraits provide a geometric visualization of dynamical systems, showing how trajectories evolve in phase space. The following Python code generates phase portraits for classic systems including the pendulum and the van der Pol oscillator.

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import odeint

def phase_portrait_2d(f, xlim, ylim, n_points=20, trajectories=None):
    """Create a 2D phase portrait for dx/dt = f(x, y)."""
    fig, ax = plt.subplots(figsize=(10, 8))
    
    x = np.linspace(xlim[0], xlim[1], n_points)
    y = np.linspace(ylim[0], ylim[1], n_points)
    X, Y = np.meshgrid(x, y)
    
    U, V = np.zeros(X.shape), np.zeros(Y.shape)
    for i in range(X.shape[0]):
        for j in range(X.shape[1]):
            u, v = f(X[i, j], Y[i, j])
            U[i, j], V[i, j] = u, v
    
    M = np.sqrt(U**2 + V**2)
    M[M == 0] = 1
    
    ax.quiver(X, Y, U/M, V/M, M, cmap='viridis', scale=30, width=0.003)
    
    if trajectories:
        t = np.linspace(0, 10, 1000)
        for x0, y0 in trajectories:
            sol = odeint(lambda z, t: list(f(z[0], z[1])), [x0, y0], t)
            ax.plot(sol[:, 0], sol[:, 1], 'r-', lw=2, alpha=0.7)
            ax.plot(x0, y0, 'ro', markersize=8)
    
    ax.set_xlim(xlim)
    ax.set_ylim(ylim)
    ax.set_aspect('equal')
    ax.grid(True, alpha=0.3)
    return fig, ax

# Example 1: Simple Pendulum

    ylim=(-3, 3),
    trajectories=[(2, 0), (3, 0), (0.5, 0)]
)
ax.set_title("Pendulum Phase Portrait")
ax.set_xlabel('Angle x')
ax.set_ylabel('Angular velocity y')
plt.savefig('pendulum_phase_portrait.png', dpi=150, bbox_inches='tight')

    return y, mu * (1 - x**2) * y - x
