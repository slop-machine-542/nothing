1. The Jordan Curve Theorem

A deceptively simple-sounding result in topology with a surprisingly difficult proof. The theorem states that any simple closed curve in the plane divides the plane into exactly two regions: an "inside" and an "outside."

Theorem (Jordan Curve Theorem): Let \(C\) be a simple closed curve in \(\mathbb{R}^2\) (a continuous injective image of \(S^1\)). Then \(\mathbb{R}^2 \setminus C\) consists of exactly two connected components: one bounded (the interior) and one unbounded (the exterior). Moreover, \(C\) is the boundary of each component.

Notation explanation:

  • \(S^1\) denotes the unit circle, the simplest closed curve
  • \(\mathbb{R}^2 \setminus C\) means the plane with the curve removed
  • A "connected component" is a maximal connected subset
Proof Sketch (Polygonal Case): For a polygonal Jordan curve, we can use the winding number. Define the winding number \(W(p)\) of a point \(p\) around the curve: \[W(p) = \frac{1}{2\pi} \oint_C d\theta\] where \(\theta\) is the angle from \(p\) to points on \(C\). The winding number is:
  • Constant on each connected component of \(\mathbb{R}^2 \setminus C\)
  • Zero for points far from \(C\) (the exterior)
  • \(\pm 1\) for points "inside" the curve
The difficulty lies in extending this to arbitrary continuous curves, which requires sophisticated tools from algebraic topology. 
import numpy as np
import matplotlib.pyplot as plt

def winding_number(point, curve_points):
    """
    Calculate the winding number of a point around a closed curve.
    
    Args:
        point: (x, y) coordinates of the point
        curve_points: Nx2 array of curve points (closed, counterclockwise)
    
    Returns:
        Winding number (integer)
    """
    x, y = point
    angles = np.arctan2(curve_points[:, 1] - y, curve_points[:, 0] - x)
    
    # Unwrap angles to handle branch cuts
    angles = np.unwrap(angles)
    
    # Winding number is total angle change divided by 2π
    total_change = angles[-1] - angles[0]
    return round(total_change / (2 * np.pi))

a, b = 3, 2  # semi-axes
ellipse = np.column_stack([a * np.cos(theta), b * np.sin(theta)])

# Test points
test_points = np.array([
    [0, 0],      # Inside
    [5, 0],      # Outside
    [2, 1],      # Inside
    [-4, 3]      # Outside
])

print("Jordan Curve Theorem - Winding Number Test")

    print(f"Point ({p[0]:.1f}, {p[1]:.1f}): Winding number = {w} → {location}")

2. Liouville's Theorem in Complex Analysis

A fundamental result showing that bounded entire functions must be constant. This theorem has profound implications and provides elegant proofs of the Fundamental Theorem of Algebra.

Theorem (Liouville): If \(f: \mathbb{C} \to \mathbb{C}\) is entire (holomorphic on all of \(\mathbb{C}\)) and bounded (\(|f(z)| \leq M\) for all \(z\)), then \(f\) is constant.

Notation explanation:

  • \(\mathbb{C}\) denotes the complex plane
  • "Entire" means complex differentiable everywhere
  • Holomorphic = complex differentiable in a neighborhood
Proof: Using Cauchy's integral formula for the derivative: \[f'(z) = \frac{1}{2\pi i} \oint_{|w-z|=R} \frac{f(w)}{(w-z)^2} dw\] Taking absolute values and using the bound \(|f(w)| \leq M\): \[|f'(z)| \leq \frac{1}{2\pi} \cdot \frac{M}{R^2} \cdot 2\pi R = \frac{M}{R}\] Since this holds for all \(R > 0\), letting \(R \to \infty\) gives \(|f'(z)| = 0\), so \(f'(z) = 0\) everywhere. Thus \(f\) is constant.

3. The Chinese Remainder Theorem

A cornerstone of number theory that establishes an isomorphism between rings of integers modulo composite numbers and products of rings modulo prime powers.

Theorem (Chinese Remainder Theorem): Let \(n_1, n_2, \ldots, n_k\) be pairwise coprime positive integers (\(\gcd(n_i, n_j) = 1\) for \(i \neq j\)), and let \(N = n_1 n_2 \cdots n_k\). Then the system of congruences: \[x \equiv a_1 \pmod{n_1}\] \[x \equiv a_2 \pmod{n_2}\] \[\vdots\] \[x \equiv a_k \pmod{n_k}\] has a unique solution modulo \(N\).
Proof (Constructive): Define \(N_i = N/n_i\). Since \(\gcd(N_i, n_i) = 1\), there exists \(y_i\) such that \(N_i y_i \equiv 1 \pmod{n_i}\) (by Bézout's identity). Then: \[x = \sum_{i=1}^k a_i N_i y_i\] satisfies all congruences because \(N_j \equiv 0 \pmod{n_i}\) for \(j \neq i\). 
import math

def extended_gcd(a, b):
    """Extended Euclidean algorithm."""
    if b == 0:
        return a, 1, 0
    g, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return g, x, y

def mod_inverse(a, m):
    """Find modular inverse of a modulo m."""
    g, x, _ = extended_gcd(a % m, m)
    if g != 1:
        return None  # Inverse doesn't exist
    return (x % m + m) % m

def chinese_remainder_theorem(remainders, moduli):
    """
    Solve system of congruences using CRT.
    
    Args:
        remainders: list of a_i values
        moduli: list of n_i values (must be pairwise coprime)
    
    Returns:
        Solution x modulo N (product of moduli)
    """
    N = 1
    for n in moduli:
        N *= n
    
    result = 0
    for a, n in zip(remainders, moduli):
        Ni = N // n
        yi = mod_inverse(Ni, n)
        result += a * Ni * yi
    
    return result % N

1. Singular Value Decomposition (SVD)

One of the most important matrix factorizations in applied mathematics, with applications in data compression, recommendation systems, and principal component analysis.

Theorem (SVD): For any real \(m \times n\) matrix \(A\), there exist orthogonal matrices \(U\) (\(m \times m\)) and \(V\) (\(n \times n\)) such that: \[A = U\Sigma V^T\] where \(\Sigma\) is an \(m \times n\) diagonal matrix with non-negative entries \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_{\min(m,n)} \geq 0\) called the singular values.

Notation explanation:

  • \(U\) contains left singular vectors (orthonormal)
  • \(V\) contains right singular vectors (orthonormal)
  • \(\sigma_i\) are the singular values (square roots of eigenvalues of \(A^TA\))
Proof Sketch: Consider \(A^TA\), which is symmetric positive semi-definite. By the spectral theorem: \[A^TA = V\Lambda V^T\] where \(V\) is orthogonal and \(\Lambda = \text{diag}(\lambda_1, \ldots, \lambda_n)\) with \(\lambda_i \geq 0\). Define \(\sigma_i = \sqrt{\lambda_i}\) and: \[U = AV\Sigma^{-1}\] One verifies that \(U\) is orthogonal and \(A = U\Sigma V^T\). 
import numpy as np
import matplotlib.pyplot as plt

def svd_compression_demo():
    """Demonstrate image compression using SVD."""
    # Create a test image (gradient + noise)
    np.random.seed(42)
    size = 100
    x = np.linspace(0, 4*np.pi, size)
    y = np.linspace(0, 4*np.pi, size)
    X, Y = np.meshgrid(x, y)
    
    # Synthetic image with structure
    image = np.sin(X) * np.cos(Y) + 0.3 * np.sin(2*X + Y)
    image += 0.1 * np.random.randn(size, size)
    
    # Compute SVD
    U, s, Vt = np.linalg.svd(image, full_matrices=False)
    
    print("Singular Value Decomposition Demo")
    print("=" * 50)
    print(f"Original matrix shape: {image.shape}")
    print(f"Number of singular values: {len(s)}")
    print(f"Top 10 singular values: {s[:10].round(2)}")
    print(f"Condition number: {s[0]/s[-1]:.2e}")
    
    # Compression at different ranks
    ranks = [5, 10, 20, 50]
    
    for rank in ranks:
        # Reconstruct using top k singular values
        U_k = U[:, :rank]
        s_k = s[:rank]
        Vt_k = Vt[:rank, :]
        
        compressed = U_k @ np.diag(s_k) @ Vt_k
        
        # Calculate compression ratio
        original_size = size * size
        compressed_size = rank * (size + 1 + size)
        ratio = original_size / compressed_size
        
        # Error
        mse = np.mean((image - compressed)**2)
        
        print(f"\nRank {rank}:")
        print(f"  Compression ratio: {ratio:.1f}x")
        print(f"  MSE: {mse:.6f}")
        print(f"  Storage: {compressed_size} vs {original_size}")

def low_rank_approximation_error():
    """Analyze approximation error vs rank."""
    # Create a matrix with known low-rank structure
    np.random.seed(123)
    m, n = 100, 80
    true_rank = 10
    
    # Low-rank matrix
    A = np.random.randn(m, true_rank) @ np.random.randn(true_rank, n)
    
    U, s, Vt = np.linalg.svd(A, full_matrices=False)
    
    print("\nLow-Rank Approximation Error Analysis")
    print("=" * 50)
    print(f"True rank of matrix: {true_rank}")
    
    frobenius_norm = np.sqrt(np.sum(s**2))
    
    for k in [5, 10, 15, 20, 50]:
        # Eckart-Young-Mirsky theorem
        # Best rank-k approximation error
        error = np.sqrt(np.sum(s[k:]**2))
        relative_error = error / frobenius_norm
        
        print(f"Rank {k:2d}: Frobenius error = {error:.4f}, Relative = {relative_error:.4f}")

2. The Heat Equation and Separation of Variables

The fundamental partial differential equation describing heat diffusion, with solutions revealing deep connections to Fourier analysis.

Theorem (Heat Equation Solution): For the initial-boundary value problem on \([0, L]\): \[\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}\] with \(u(0,t) = u(L,t) = 0\) and \(u(x,0) = f(x)\), the solution is: \[u(x,t) = \sum_{n=1}^{\infty} b_n \sin\left(\frac{n\pi x}{L}\right) e^{-\alpha(n\pi/L)^2 t}\] where \(b_n = \frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right)dx\).

Notation explanation:

  • \(\alpha\) is the thermal diffusivity constant
  • \(b_n\) are Fourier sine coefficients of initial condition
  • The exponential decay shows high frequencies dissipate faster
Proof (Separation of Variables): Assume \(u(x,t) = X(x)T(t)\). Substituting: \[X(x)T'(t) = \alpha X''(x)T(t)\] \[\frac{T'}{\alpha T} = \frac{X''}{X} = -\lambda\] This gives two ODEs: \(X'' + \lambda X = 0\) and \(T' + \alpha\lambda T = 0\). With boundary conditions \(X(0) = X(L) = 0\), we get eigenvalues \(\lambda_n = (n\pi/L)^2\) and eigenfunctions \(X_n(x) = \sin(n\pi x/L)\). The general solution is a superposition of these modes. 
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

def heat_equation_solution(x, t, alpha, L, f_coeffs, n_terms=50):
    """
    Compute solution to heat equation using Fourier series.
    
    Args:
        x: spatial points
        t: time
        alpha: thermal diffusivity
        L: domain length
        f_coeffs: function to compute Fourier coefficients
        n_terms: number of Fourier terms
    """
    u = np.zeros_like(x)
    for n in range(1, n_terms + 1):
        bn = f_coeffs(n, L)
        u += bn * np.sin(n * np.pi * x / L) * np.exp(-alpha * (n * np.pi / L)**2 * t)
    return u

# Example: Initial temperature is a "tent" function
def tent_coeffs(n, L):
    """Fourier sine coefficients for tent function centered at L/2."""
    # f(x) = 1 - |2x/L - 1| (triangle wave)
    # Coefficient: 8/(n²π²) * sin(nπ/2)
    return (8 / (n**2 * np.pi**2)) * np.sin(n * np.pi / 2)

3. Graph Laplacian and Spectral Clustering

The graph Laplacian matrix connects graph theory to linear algebra, enabling powerful algorithms for community detection and clustering.

Theorem (Graph Laplacian Properties): For a weighted graph \(G = (V, E, W)\) with adjacency matrix \(W\) and degree matrix \(D_{ii} = \sum_j W_{ij}\), the (unnormalized) Laplacian \(L = D - W\) satisfies:
  1. For any vector \(f \in \mathbb{R}^n\): \(f^TLf = \frac{1}{2}\sum_{i,j} W_{ij}(f_i - f_j)^2\)
  2. \(L\) is positive semi-definite with eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\)
  3. The multiplicity of eigenvalue 0 equals the number of connected components

Notation explanation:

  • \(W_{ij}\) = weight of edge between nodes \(i\) and \(j\)
  • \(D\) = diagonal degree matrix
  • \(f^TLf\) is the "smoothness" of function \(f\) on the graph
Proof of (1): \[f^TLf = f^TDf - f^TWf = \sum_i D_{ii}f_i^2 - \sum_{i,j} W_{ij}f_if_j\] \[= \sum_{i,j} W_{ij}f_i^2 - \sum_{i,j} W_{ij}f_if_j = \frac{1}{2}\sum_{i,j} W_{ij}(f_i - f_j)^2\] The last equality follows by symmetry \(W_{ij} = W_{ji}\). 
import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import kneighbors_graph

def compute_laplacian(adjacency):
    """Compute unnormalized graph Laplacian."""
    degree = np.sum(adjacency, axis=1)
    D = np.diag(degree)
    L = D - adjacency
    return L

def spectral_clustering(X, n_clusters, n_neighbors=10):
    """
    Perform spectral clustering on data X.
    
    Args:
        X: data matrix (n_samples x n_features)
        n_clusters: number of clusters
        n_neighbors: number of neighbors for graph construction
    
    Returns:
        cluster assignments
    """
    # Build k-nearest neighbors graph
    adjacency = kneighbors_graph(X, n_neighbors, mode='connectivity')
    adjacency = np.maximum(adjacency, adjacency.T)  # Make symmetric
    
    # Compute Laplacian
    L = compute_laplacian(adjacency.toarray())
    
    # Compute eigenvectors
    eigenvalues, eigenvectors = np.linalg.eigh(L)
    
    # Use first k eigenvectors (excluding the trivial one)
    embedding = eigenvectors[:, 1:n_clusters+1]
    
    # K-means on the spectral embedding
    from sklearn.cluster import KMeans
    kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
    return kmeans.fit_predict(embedding), eigenvalues, eigenvectors

1. The Isoperimetric Inequality

A beautiful geometric result stating that among all shapes with a given perimeter, the circle encloses the maximum area. This principle appears throughout mathematics and physics.

Theorem (Isoperimetric Inequality): For any simple closed curve \(\gamma\) in \(\mathbb{R}^2\) with length \(L\) enclosing area \(A\): \[4\pi A \leq L^2\] with equality if and only if \(\gamma\) is a circle.

Notation explanation:

  • \(L\) = perimeter (arc length of the curve)
  • \(A\) = enclosed area
  • The ratio \(L^2/A\) is minimized by the circle
Proof (Steiner Symmetrization Sketch): The proof uses the fact that symmetrization preserves area and does not increase perimeter. Given any convex body \(K\):
  1. Apply Steiner symmetrization about the x-axis: replace each vertical chord with a centered segment of the same length
  2. This preserves area and decreases (or preserves) perimeter
  3. Repeat for all directions; the limit is a disk
  4. Since the disk has \(L^2/A = 4\pi\), the inequality follows

def polygon_area(vertices):
    """Calculate area of polygon using shoelace formula."""
    x, y = vertices[:, 0], vertices[:, 1]
    return 0.5 * abs(np.dot(x, np.roll(y, 1)) - np.dot(y, np.roll(x, 1)))

def polygon_perimeter(vertices):
    """Calculate perimeter of polygon."""
    return np.sum(np.sqrt(np.sum((vertices - np.roll(vertices, 1, axis=0))**2, axis=1)))

    A = polygon_area(vertices)

2. Ramsey Theory: The Party Problem

Ramsey theory guarantees the existence of order in large enough structures. The classic "party problem" asks: how many people must attend a party to guarantee that either 3 mutual acquaintances or 3 mutual strangers exist?

Theorem (Ramsey's Theorem, R(3,3) case): In any group of 6 people, there exist either 3 mutual acquaintances or 3 mutual strangers. Equivalently: any 2-coloring of the edges of \(K_6\) contains a monochromatic \(K_3\).

Notation explanation:

  • \(K_n\) = complete graph on \(n\) vertices
  • \(R(s,t)\) = smallest \(n\) such that any red-blue edge coloring of \(K_n\) contains a red \(K_s\) or blue \(K_t\)
  • \(R(3,3) = 6\)
Proof that R(3,3) ≤ 6: Consider any vertex \(v\) in \(K_6\). It has 5 incident edges, so by pigeonhole principle, at least 3 are the same color (say red) to vertices \(a, b, c\). If any edge among \(\{a,b,c\}\) is red, we have a red triangle with \(v\). If all edges among \(\{a,b,c\}\) are blue, we have a blue triangle. R(3,3) > 5: The 5-cycle \(C_5\) with edges colored alternately shows \(K_5\) can be 2-colored without monochromatic triangles. 
import numpy as np
import itertools
import matplotlib.pyplot as plt

def has_monochromatic_triangle(adjacency, color):
    """
    Check if graph has a monochromatic triangle of given color.
    
    Args:
        adjacency: n x n matrix where 0=no edge, 1=red, 2=blue
        color: 1 for red, 2 for blue
    
    Returns:
        True if monochromatic triangle exists
    """
    n = len(adjacency)
    for i, j, k in itertools.combinations(range(n), 3):
        if (adjacency[i,j] == color and adjacency[j,k] == color and 
            adjacency[i,k] == color):
            return True
    return False

def find_ramsey_violation(n, max_trials=10000):
    """
    Try to find a 2-coloring of K_n without monochromatic triangles.
    
    Returns:
        (found_violation, coloring) where coloring is None if no violation found
    """
    for trial in range(max_trials):
        # Random coloring
        adjacency = np.zeros((n, n), dtype=int)
        for i in range(n):
            for j in range(i+1, n):
                adjacency[i,j] = adjacency[j,i] = np.random.randint(1, 3)
        
        if not has_monochromatic_triangle(adjacency, 1) and \
           not has_monochromatic_triangle(adjacency, 2):
            return True, adjacency
    
    return False, None

3. The Basel Problem and ζ(2)

Euler's famous solution to the Basel problem established the exact value of the sum of reciprocal squares, connecting number theory, analysis, and Fourier series.

Theorem (Basel Problem): \[\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\]

Notation explanation:

  • \(\zeta(s) = \sum_{n=1}^{\infty} n^{-s}\) is the Riemann zeta function
  • \(\zeta(2) = \pi^2/6\) is Apéry's constant for even values
Proof (Fourier Series Method): Consider \(f(x) = x^2\) on \([-\pi, \pi]\). Its Fourier series is: \[x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^{\infty} \frac{(-1)^n}{n^2}\cos(nx)\] Setting \(x = \pi\): \[\pi^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^{\infty} \frac{1}{n^2}\] Solving: \(\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\). 
import numpy as np
import matplotlib.pyplot as plt

def zeta_2_partial_sum(N):
    """Compute partial sum of 1/n² up to N terms."""
    return np.sum(1 / np.arange(1, N+1)**2)

def zeta_2_euler_transform(N):
    """Accelerated convergence using Euler transformation."""
    # Alternating series: sum (-1)^(n+1)/n² = π²/12
    alt_sum = np.sum([(-1)**(n+1) / n**2 for n in range(1, N+1)])
    # ζ(2) = 2 * (alternating sum of odd terms)
    return 2 * alt_sum

def zeta_2_riemann_sum(N):
    """Approximate using Riemann sum for ∫(1/x²) from 1 to ∞."""
    x = np.linspace(1, N, N)
    return np.sum(1 / x**2)

def zeta_2_euler_product(num_primes):
    """Compute ζ(2) using Euler product over first num_primes primes."""
    def sieve_primes(n):
        sieve = [True] * (n+1)
        sieve[0] = sieve[1] = False
        for i in range(2, int(n**0.5)+1):
            if sieve[i]:
                for j in range(i*i, n+1, i):
                    sieve[j] = False
        return [i for i, is_prime in enumerate(sieve) if is_prime]
    
    primes = sieve_primes(1000)[:num_primes]
    product = 1.0
    for p in primes:
        product *= 1 / (1 - 1/p**2)
    return product

4. Morse Theory and Topology

Morse theory studies the relationship between the critical points of smooth functions on manifolds and the topology of those manifolds, providing powerful tools for understanding shape.

Theorem (Morse Lemma): Let \(f: M \to \mathbb{R}\) be a smooth function on a manifold \(M\), and let \(p\) be a non-degenerate critical point (\(df_p = 0\) and Hessian is non-singular). Then there exist local coordinates \((x_1, \ldots, x_n)\) near \(p\) such that: \[f(x) = f(p) - x_1^2 - \cdots - x_\lambda^2 + x_{\lambda+1}^2 + \cdots + x_n^2\] where \(\lambda\) is the index of the critical point (number of negative eigenvalues of the Hessian).

Notation explanation:

  • \(df_p\) = differential of \(f\) at \(p\) (gradient in coordinates)
  • Hessian = matrix of second partial derivatives
  • Index \(\lambda\) = number of "downward" directions at the critical point
Theorem (Morse Inequalities): Let \(c_k\) be the number of critical points of index \(k\), and let \(b_k = \dim H_k(M)\) be the Betti numbers. Then: \[c_k \geq b_k\] and the alternating sum satisfies: \[\sum_{k=0}^n (-1)^k c_k = \sum_{k=0}^n (-1)^k b_k = \chi(M)\] where \(\chi(M)\) is the Euler characteristic. 
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def morse_function_2d(x, y, critical_points):
    """
    Construct a Morse function with specified critical points.
    
    Args:
        critical_points: list of (x, y, height, index) tuples
            index: 0 (min), 1 (saddle), 2 (max)
    
    Returns:
        Function value at (x, y)
    """
    z = np.zeros_like(x)
    for cx, cy, h, idx in critical_points:
        dx, dy = x - cx, y - cy
        r2 = dx**2 + dy**2
        if idx == 0:  # minimum
            z += h * np.exp(-r2) * (1 - 2*r2)
        elif idx == 2:  # maximum
            z -= h * np.exp(-r2) * (1 - 2*r2)
        else:  # saddle
            z += h * (dx**2 - dy**2) * np.exp(-r2/2)
    return z

def gradient_flow(x0, y0, f_func, dt=0.01, n_steps=1000):
    """
    Compute gradient flow from initial point.
    
    Returns:
        trajectory of points
    """
    traj = [(x0, y0)]
    x, y = x0, y0
    
    for _ in range(n_steps):
        # Numerical gradient
        eps = 0.001
        dx = (f_func(x+eps, y) - f_func(x-eps, y)) / (2*eps)
        dy = (f_func(x, y+eps) - f_func(x, y-eps)) / (2*eps)
        
        # Gradient descent
        x -= dt * dx
        y -= dt * dy
        traj.append((x, y))
        
        if dx**2 + dy**2 < 1e-10:
            break
    
    return np.array(traj)

# Numerical example
def hessian_2d(f, x, y, eps=1e-5):
    """Compute 2x2 Hessian numerically."""
    f_xx = (f(x+eps, y) - 2*f(x, y) + f(x-eps, y)) / eps**2
    f_yy = (f(x, y+eps) - 2*f(x, y) + f(x, y-eps)) / eps**2
    f_xy = (f(x+eps, y+eps) - f(x+eps, y-eps) - f(x-eps, y+eps) + f(x-eps, y-eps)) / (4*eps**2)
    return np.array([[f_xx, f_xy], [f_xy, f_yy]])

def classify_critical_point(f, x, y):
    """Classify a critical point using the Hessian."""
    H = hessian_2d(f, x, y)
    det = np.linalg.det(H)
    tr = np.trace(H)
    
    if det > 0:
        if tr > 0:
            return "minimum", 0
        else:
            return "maximum", 2
    elif det < 0:
        return "saddle", 1
    else:
        return "degenerate", -1

# Find critical points numerically
def find_critical_points(f, bounds=(-2, 2), grid_size=100):
    """Find approximate critical points on a grid."""
    x = np.linspace(bounds[0], bounds[1], grid_size)
    y = np.linspace(bounds[0], bounds[1], grid_size)
    X, Y = np.meshgrid(x, y)
    
    # Compute gradient magnitude
    eps = 0.01
    dfdx = (f(X+eps, Y) - f(X-eps, Y)) / (2*eps)
    dfdy = (f(X, Y+eps) - f(X, Y-eps)) / (2*eps)
    grad_mag = np.sqrt(dfdx**2 + dfdy**2)
    
    # Find local minima of gradient magnitude
    from scipy.ndimage import minimum_filter
    local_min = (grad_mag == minimum_filter(grad_mag, size=3))
    
    critical_points = []
    for i in range(1, grid_size-1):
        for j in range(1, grid_size-1):
            if local_min[i, j] and grad_mag[i, j] < 0.1:
                critical_points.append((X[i,j], Y[i,j]))
    
    return critical_points
