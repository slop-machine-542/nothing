🔬 Pure Math Deep-Dives

1. Homological Algebra: Spectral Sequences

Motivation

Spectral sequences are powerful computational tools in algebraic topology and homological algebra, invented by Jean Leray while he was a prisoner of war during World War II. They provide a systematic way to compute complex derived functors by breaking the computation into successive approximations. Today, spectral sequences are essential in algebraic geometry, algebraic topology, and representation theory.

Definitions

A spectral sequence is a sequence of bigraded differential modules \((E_r, d_r)\) where:

  • Each \(E_r\) is a bigraded module: \(E_r = \bigoplus_{p,q} E_r^{p,q}\)
  • The differential has bidegree: \(d_r: E_r^{p,q} \to E_r^{p+r, q-r+1}\)
  • \(E_{r+1} = H(E_r, d_r)\) (homology of the previous page)
  • Convergence: A spectral sequence converges to \(H^*\) if there exists a filtration on \(H^n\) with \(E_\infty^{p,q} \cong F^p H^{p+q} / F^{p+1} H^{p+q}\)

Theorem: Grothendieck Spectral Sequence

Theorem: Let \(\mathcal{A}, \mathcal{B}, \mathcal{C}\) be abelian categories with enough injectives, and let \(F: \mathcal{A} \to \mathcal{B}\) and \(G: \mathcal{B} \to \mathcal{C}\) be left exact functors such that \(F\) takes injective objects to \(G\)-acyclic objects. Then for every object \(A\) in \(\mathcal{A}\), there exists a convergent spectral sequence:

\[E_2^{p,q} = (R^p G)(R^q F)(A) \Rightarrow R^{p+q}(G \circ F)(A)\]

Proof Sketch

Step 1: Take an injective resolution \(0 \to A \to I^0 \to I^1 \to \cdots\) of \(A\).

Step 2: Apply \(F\) to get a complex \(F(I^\bullet)\). Since \(F\) is left exact, we have exactness at the beginning.

Step 3: Take a Cartan-Eilenberg resolution (double complex) of \(F(I^\bullet)\) and apply \(G\).

Step 4: The spectral sequence of the double complex has the desired \(E_2\) page. One filtration gives the LHS, the other gives the RHS. ∎

Notation Guide

  • \(E_r^{p,q}\): The module at page \(r\), position \((p,q)\)
  • \(d_r\): Differential on page \(r\)
  • \(R^n F\): The \(n\)-th right derived functor of \(F\)
  • \(H^n\): The \(n\)-th cohomology
  • \(\Rightarrow\): Converges to

Python Code

import numpy as np

class SpectralSequenceExample:
    """Demonstrate spectral sequence computation."""
    
    def __init__(self, base_cohomology, fiber_cohomology):
        self.base = base_cohomology
        self.fiber = fiber_cohomology
        self.max_p = max(base_cohomology.keys())
        self.max_q = max(fiber_cohomology.keys())
    
    def compute_E2_page(self):
        """Compute E_2 page of Serre spectral sequence."""
        print("Serre Spectral Sequence - E_2 Page")
        print("=" * 60)
        print("For F → E → B: E_2^{p,q} = H^p(B; H^q(F))")
        print()
        
        E2 = {}
        for p in range(self.max_p + 1):
            for q in range(self.max_q + 1):
                dim = self.base.get(p, 0) * self.fiber.get(q, 0)
                if dim > 0:
                    E2[(p, q)] = dim
        
        print("E_2^{p,q} dimensions:")
        for q in range(self.max_q, -1, -1):
            row = [str(E2.get((p, q), 0)) for p in range(self.max_p + 1)]
            print(f"q={q}: {' '.join(row)}")
        
        return E2

# Example: Hopf fibration S^1 → S^3 → S^2
print("Hopf Fibration: S^1 → S^3 → S^2")
base = {0: 1, 2: 1}  # H^*(S^2)
fiber = {0: 1, 1: 1}  # H^*(S^1)
ss = SpectralSequenceExample(base, fiber)

print("\nVerification: H^*(S^3) = R in degrees 0, 3")

2. Algebraic K-Theory

Motivation

Algebraic K-theory, founded by Alexander Grothendieck in the late 1950s and developed by Daniel Quillen and others, studies deep invariants of rings and categories. It connects algebra, topology, and number theory in profound ways.

Definitions

  • Grothendieck Group \(K_0(R)\): For a ring \(R\), \(K_0(R)\) is the Grothendieck group of the category of finitely generated projective \(R\)-modules.
  • Whitehead Group \(K_1(R)\): \(K_1(R) = GL(R)^{ab}\), where \(GL(R)\) is the infinite general linear group.

Theorem: Fundamental Theorem of Algebraic K-Theory

Theorem: For a regular ring \(R\):

\[K_i(R[t]) \cong K_i(R)\]

for all \(i \geq 0\). Moreover:

\[K_i(R[t, t^{-1}]) \cong K_i(R) \oplus K_{i-1}(R)\]

Proof Sketch

Step 1: Use the resolution theorem to reduce to the case of free modules.

Step 2: Apply the dévissage theorem to handle the structure of modules over polynomial rings.

Step 3: For regular rings, every finitely generated module has finite projective dimension, allowing reduction to projective modules.

Step 4: The localization sequence applied to \(R[t] \to R[t, t^{-1}]\) yields the second formula. ∎

Python Code

import sympy as sp

3. Continued Fractions and Diophantine Approximation

Motivation

Continued fractions provide the best rational approximations to real numbers. This ancient technique, studied by Euclid and developed by Euler, Lagrange, and Gauss, has profound applications in number theory, dynamical systems, and cryptography.

Definitions

  • Simple Continued Fraction: \(\alpha = [a_0; a_1, a_2, \ldots]\) where \(a_0 \in \mathbb{Z}\) and \(a_i \in \mathbb{Z}^+\).
  • Convergents: \(p_n/q_n = [a_0; a_1, \ldots, a_n]\).

Theorem: Best Approximation Theorem

Theorem: Let \(\alpha\) be irrational with convergents \(p_n/q_n\). Then:

\[\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}} < \frac{1}{a_{n+1} q_n^2}\]

Proof Sketch

Step 1: Establish the recurrence relations: \(p_n = a_n p_{n-1} + p_{n-2}\), \(q_n = a_n q_{n-1} + q_{n-2}\).

Step 2: Prove the determinant formula: \(p_n q_{n-1} - p_{n-1} q_n = (-1)^{n-1}\).

Step 3: Compute the error: \(\alpha - \frac{p_n}{q_n} = \frac{(-1)^n}{q_n(\alpha_{n+1} q_n + q_{n-1})}\).

Step 4: Since \(\alpha_{n+1} > a_{n+1}\), we get the bound. ∎

Python Code

import math
from fractions import Fraction

class ContinuedFractions:
    """Continued fraction computations."""
    
    @staticmethod
    def continued_fraction_expansion(x, max_terms=20):
        """Compute CF expansion [a_0; a_1, ..., a_n]."""
        cf = []
        current = x
        for _ in range(max_terms):
            a = int(current)
            cf.append(a)
            if abs(current - a) < 1e-15:
                break
            current = 1.0 / (current - a)
        return cf
    
    @staticmethod
    def convergents(cf):
        """Compute convergents p_n/q_n."""
        p_minus2, p_minus1 = 0, 1
        q_minus2, q_minus1 = 1, 0
        convergents_list = []
        for a in cf:
            p = a * p_minus1 + p_minus2
            q = a * q_minus1 + q_minus2
            convergents_list.append(Fraction(p, q))
            p_minus2, p_minus1 = p_minus1, p
            q_minus2, q_minus1 = q_minus1, q
        return convergents_list

# Example: Golden ratio
phi = (1 + math.sqrt(5)) / 2
cf = ContinuedFractions()
cf_phi = cf.continued_fraction_expansion(phi, 10)
print(f"φ = {cf_phi}")  # [1, 1, 1, 1, ...]
conv = cf.convergents(cf_phi)
print(f"Convergents: {conv[:5]}")  # Fibonacci ratios

1. Mathematical Control Theory

Real-World Motivation

Control theory is the mathematical study of how to influence the behavior of dynamical systems to achieve desired objectives. From autopilot systems in aircraft to insulin pumps for diabetics, control theory underpins modern technology.

Theorem: Kalman Controllability Theorem

Theorem: The system \(\dot{x} = Ax + Bu\) is controllable iff:

\[\mathcal{C} = [B \quad AB \quad A^2B \quad \cdots \quad A^{n-1}B]\]

has full rank \(n\).

Python Code

import numpy as np
from scipy.linalg import solve_continuous_are

class ControlTheory:
    @staticmethod
    def is_controllable(A, B):
        n = A.shape[0]
        C = B
        for i in range(1, n):
            C = np.hstack([C, np.linalg.matrix_power(A, i) @ B])
        return np.linalg.matrix_rank(C) == n
    
    @staticmethod
    def lqr_controller(A, B, Q, R):
        P = solve_continuous_are(A, B, Q, R)
        K = np.linalg.inv(R) @ B.T @ P
        return K, P

# Example
M, m, L, g = 1.0, 0.1, 0.5, 9.81
denom = M + m
A = np.array([[0, 1, 0, 0],
              [0, 0, -m*g/denom, 0],
              [0, 0, 0, 1],
              [0, 0, (M+m)*g/(denom*L), 0]])
B = np.array([[0], [1/denom], [0], [-1/(denom*L)]])

ctrl = ControlTheory()
print(f"Controllable: {ctrl.is_controllable(A, B)}")

2. Mathematical Finance: Black-Scholes Theory

Theorem: Black-Scholes Formula

\[C(S, t) = S N(d_1) - K e^{-r(T-t)} N(d_2)\]

Python Code

import numpy as np
from scipy.stats import norm

class BlackScholes:
    @staticmethod
    def call_price(S, K, T, r, sigma):
        d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
        d2 = d1 - sigma*np.sqrt(T)
        return S*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)

bs = BlackScholes()
print(f"Call price: ${bs.call_price(100, 100, 1.0, 0.05, 0.2):.2f}")

3. Mathematical Epidemiology: SIR Models

Theorem: SIR Dynamics

\[\frac{dS}{dt} = -\beta SI, \quad \frac{dI}{dt} = \beta SI - \gamma I, \quad \frac{dR}{dt} = \gamma I\]

An epidemic occurs iff \(R_0 = \frac{\beta N}{\gamma} > 1\).

Python Code

import numpy as np
from scipy.integrate import odeint

class EpidemicModels:
    @staticmethod
    def sir_model(y, t, beta, gamma, N):
        S, I, R = y
        dSdt = -beta * S * I / N
        dIdt = beta * S * I / N - gamma * I
        dRdt = gamma * I
        return [dSdt, dIdt, dRdt]
    
    @staticmethod
    def herd_immunity_threshold(R0):
        return 1 - 1/R0

model = EpidemicModels()
R0_val = 5.0
print(f"Herd immunity: {model.herd_immunity_threshold(R0_val)*100:.1f}%")

📜 Math History

The Development of Modern Algebra: From Equations to Structures

The transformation of algebra from a discipline focused on solving equations to one concerned with abstract structures represents one of the most profound shifts in mathematical thinking. This evolution, spanning roughly three centuries, fundamentally changed how mathematicians understand their subject.

The story begins in the 16th century with the Italian school of algebraists. Scipione del Ferro, Niccolò Tartaglia, and Gerolamo Cardano successively discovered methods for solving cubic equations, with Cardano publishing the formula in his Ars Magna (1545). Ludovico Ferrari extended these methods to quartic equations. These discoveries raised an urgent question: could quintic equations be solved by radicals?

The negative answer came in the early 19th century through the work of Paolo Ruffini, Niels Henrik Abel, and especially Évariste Galois. Galois's theory, developed in the years before his death in 1832 at age 20, introduced the revolutionary idea of studying equations through their symmetry groups. A polynomial equation is solvable by radicals if and only if its Galois group is solvable.

The 20th century saw the emergence of abstract algebra as we know it today. Emmy Noether's work in the 1920s established the modern axiomatic approach, emphasizing the study of algebraic structures—groups, rings, fields, and modules—in their own right rather than as tools for solving equations. This structural approach, further developed by mathematicians like Emil Artin and Bartel van der Waerden, became the dominant paradigm in algebra and influenced nearly every branch of mathematics.

Problem: AIME 2024

Let \(P\) be a point inside triangle \(ABC\) such that \(\angle PAB = \angle PBC = \angle PCA = \omega\). If \(AB = 13\), \(BC = 14\), and \(CA = 15\), find \(\tan(\omega)\).

Hint

Use the trigonometric form of Ceva's theorem and the fact that \(\cot(\omega) = \cot(A) + \cot(B) + \cot(C)\) for the Brocard angle.

Solution

By the trigonometric form of Ceva's theorem:

\[\frac{\sin(\omega)}{\sin(A-\omega)} \cdot \frac{\sin(\omega)}{\sin(B-\omega)} \cdot \frac{\sin(\omega)}{\sin(C-\omega)} = 1\]

For the Brocard angle, we have the identity:

\[\cot(\omega) = \cot(A) + \cot(B) + \cot(C)\]

Using the area formula, \(\cot(A) = \frac{b^2+c^2-a^2}{4K}\) where \(K\) is the area. For sides 13, 14, 15, we have \(K = 84\) (using Heron's formula).

Computing:

\[\cot(A) = \frac{15^2+13^2-14^2}{4 \cdot 84} = \frac{198}{336} = \frac{33}{56}\]

\[\cot(B) = \frac{14^2+15^2-13^2}{4 \cdot 84} = \frac{252}{336} = \frac{3}{4}\]

\[\cot(C) = \frac{13^2+14^2-15^2}{4 \cdot 84} = \frac{140}{336} = \frac{5}{12}\]

Therefore:

\[\cot(\omega) = \frac{33}{56} + \frac{3}{4} + \frac{5}{12} = \frac{99+126+70}{168} = \frac{295}{168}\]

So \(\tan(\omega) = \boxed{\frac{168}{295}}\).

The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics. It is defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until divergence."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Create grid
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Compute Mandelbrot set
mandelbrot_set = np.vectorize(mandelbrot)(C)

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(mandelbrot_set, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.show()
