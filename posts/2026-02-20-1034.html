Algebraic Curves: From Conics to Moduli

algebraic-curves

Motivation

Algebraic curves are the meeting point of algebra, geometry, and number theory. From the ancient study of conic sections to the modern theory of Riemann surfaces and moduli spaces, curves have been central to mathematical development. The classification of algebraic curves by genus reveals deep connections between topology and algebra: curves of genus 0 are rational, genus 1 curves are elliptic curves with rich arithmetic structure, and higher genus curves lead to the theory of Jacobians and abelian varieties. Understanding algebraic curves provides essential foundations for algebraic geometry, number theory, and mathematical physics.

Definitions

  • Algebraic Curve: A one-dimensional algebraic variety, equivalently the zero set of an irreducible polynomial \(f(x,y) = 0\) in the affine plane, or a homogeneous polynomial in the projective plane.
  • Genus: For a smooth projective curve over \(\mathbb{C}\), the genus \(g\) is the number of "holes" in the corresponding Riemann surface. Algebraically, \(g = \dim H^0(C, K_C)\) where \(K_C\) is the canonical divisor.
  • Divisor: A formal finite sum \(D = \sum n_P P\) where \(P\) are points on the curve and \(n_P \in \mathbb{Z}\). The degree is \(\deg(D) = \sum n_P\).
  • Riemann-Roch Space: For a divisor \(D\), \(L(D) = \{f \in k(C)^* : \text{div}(f) + D \geq 0\} \cup \{0\}\).
  • Jacobian: The variety \(J(C) = \text{Pic}^0(C)\) parameterizing degree-zero divisors modulo principal divisors, an abelian variety of dimension \(g\).

Theorem: The Riemann-Roch Theorem

Theorem: Let \(C\) be a smooth projective curve of genus \(g\) and \(D\) a divisor on \(C\). Then:

\[\ell(D) - \ell(K_C - D) = \deg(D) + 1 - g\]

where \(\ell(D) = \dim L(D)\) and \(K_C\) is the canonical divisor.

Proof

The proof proceeds via several key steps:

Step 1 (Base Case): For \(D = 0\), we have \(\ell(0) = 1\) (constant functions) and \(\ell(K_C) = g\) by definition. The formula gives \(1 - g = 0 + 1 - g\). ✓

Step 2 (Induction): If the theorem holds for \(D\), we show it for \(D + P\) where \(P\) is a point. Consider the exact sequence:

\[0 \to L(D) \to L(D+P) \to k \to 0\]

where the last map evaluates functions at \(P\) (if \(P\) is not a base point). This gives \(\ell(D+P) \leq \ell(D) + 1\).

Step 3 (Serre Duality): The term \(\ell(K_C - D)\) arises from Serre duality: \(H^1(C, \mathcal{O}(D)) \cong H^0(C, \mathcal{O}(K_C - D))^*\).

Step 4: Combining these with the Euler characteristic \(\chi(\mathcal{O}(D)) = \deg(D) + 1 - g\) yields the result. ∎

Notation Guide

  • \(C\) — smooth projective curve
  • \(g\) — genus of the curve
  • \(K_C\) — canonical divisor
  • \(L(D)\) — Riemann-Roch space
  • \(\ell(D)\) — dimension of \(L(D)\)
  • \(\text{Pic}(C)\) — Picard group (divisors modulo principal divisors)
  • \(J(C)\) — Jacobian variety
  • \(\Omega_C\) — sheaf of differential forms

class AlgebraicCurves:
    """Computational tools for algebraic curves."""

        self.x, self.y = symbols('x y', real=True)
    
    def curve_genus(self, f, x, y):
        """
        Compute genus of plane curve using the degree formula.
        For a smooth plane curve of degree d: g = (d-1)(d-2)/2
        """
        d = sp.Poly(f, x, y).total_degree()
        return (d - 1) * (d - 2) // 2
    
    def singular_points(self, f, x, y):
        """Find singular points where df/dx = df/dy = f = 0."""
        df_dx = sp.diff(f, x)
        df_dy = sp.diff(f, y)
        singular = solve([df_dx, df_dy, f], [x, y])
        return singular

        """Plot a real algebraic curve."""

Differential Topology: Smooth Structures on Manifolds

differential-topology

Motivation

Differential topology studies properties of smooth manifolds that are preserved under diffeomorphisms—smooth invertible maps with smooth inverses. Unlike differential geometry, which focuses on metric properties like curvature, differential topology investigates the underlying smooth structure: Can two manifolds be smoothly equivalent? How many distinct smooth structures exist on a given topological manifold? The discovery of exotic spheres—manifolds homeomorphic but not diffeomorphic to the standard sphere—revealed that smooth structure is a subtle and rich invariant. This field provides the foundation for modern physics, from general relativity to gauge theory.

Definitions

  • Smooth Manifold: A Hausdorff, second-countable topological space \(M\) with a maximal atlas of charts \(\{(U_\alpha, \phi_\alpha)\}\) where transition maps \(\phi_\beta \circ \phi_\alpha^{-1}\) are smooth.
  • Tangent Space: At a point \(p \in M\), the vector space \(T_pM\) of derivations at \(p\), equivalently equivalence classes of curves through \(p\).
  • Diffeomorphism: A smooth bijection \(f: M \to N\) with smooth inverse. Manifolds are diffeomorphic if such a map exists.
  • Transversality: Submanifolds \(X, Y \subset M\) intersect transversally if \(T_xX + T_xY = T_xM\) for all \(x \in X \cap Y\).
  • Degree: For a smooth map \(f: M \to N\) between compact oriented n-manifolds, \(\deg(f)\) counts preimages with orientation.

Theorem: The Brouwer Fixed-Point Theorem

Theorem: Every continuous function \(f: D^n \to D^n\) from the closed n-dimensional disk to itself has at least one fixed point: there exists \(x \in D^n\) such that \(f(x) = x\).

Proof (via degree theory)

We prove by contradiction for smooth functions (the continuous case follows by approximation):

Step 1: Suppose \(f: D^n \to D^n\) has no fixed points. Define \(g: D^n \to S^{n-1}\) by \(g(x) = \frac{x - f(x)}{|x - f(x)|}\).

Step 2: For \(x \in S^{n-1}\) (boundary), if \(f(x) = x\) we'd have a fixed point. Since we assumed no fixed points, \(g\) is well-defined on all of \(D^n\).

Step 3: On the boundary \(S^{n-1}\), if \(x \in S^{n-1}\) then \(|x| = 1\). The map \(g|_{S^{n-1}}: S^{n-1} \to S^{n-1}\) satisfies \(g(x) \cdot x \geq 0\) (geometric argument).

Step 4: The map \(g\) extends to the interior, so \(\deg(g|_{S^{n-1}}) = 0\) (null-homotopic). But for the identity map \(\text{id}: S^{n-1} \to S^{n-1}\), we have \(\deg(\text{id}) = 1\).

Step 5: A homotopy argument shows that any map without fixed points must have degree 0, contradicting that the identity has degree 1. Therefore, a fixed point must exist. ∎

Notation Guide

  • \(M, N\) — smooth manifolds
  • \(T_pM\) — tangent space at \(p\)
  • \(TM\) — tangent bundle
  • \(C^\infty(M, N)\) — smooth maps
  • \(\text{Diff}(M)\) — diffeomorphism group
  • \(\deg(f)\) — degree of a map
  • \(S^n\) — n-dimensional sphere
  • \(D^n\) — n-dimensional disk

import numpy as np
from scipy.optimize import fsolve
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class DifferentialTopology:
    """Computational differential topology tools."""
    
    def __init__(self):
        pass
    
    def fixed_point_iteration(self, f, x0, tol=1e-10, max_iter=1000):
        """
        Find fixed point using iteration: x_{n+1} = f(x_n).
        Returns the fixed point and convergence history.
        """
        x = np.array(x0, dtype=float)
        history = [x.copy()]
        
        for i in range(max_iter):
            x_new = f(x)
            history.append(x_new.copy())
            if np.linalg.norm(x_new - x) < tol:
                return x_new, history, True
            x = x_new
        
        return x, history, False
    
    def broyden_method(self, f, x0, tol=1e-10, max_iter=100):
        """
        Broyden's method for finding fixed points of f(x) = x,
        i.e., roots of g(x) = f(x) - x = 0.
        """
        x = np.array(x0, dtype=float)
        n = len(x)
        B = np.eye(n)  # Initial Jacobian approximation
        
        for i in range(max_iter):
            g_x = f(x) - x
            if np.linalg.norm(g_x) < tol:
                return x, True
            
            s = -np.linalg.solve(B, g_x)
            x_new = x + s
            g_x_new = f(x_new) - x_new
            
            y = g_x_new - g_x
            B = B + np.outer(y - B @ s, s) / (s @ s)
            
            x = x_new
        
        return x, False
    
    def winding_number(self, curve, point):
        """
        Compute winding number of a closed curve around a point.
        curve: array of shape (N, 2) with points (x, y)
        point: (x, y) center point
        """
        curve = np.array(curve)
        point = np.array(point)
        
        # Translate so point is at origin
        translated = curve - point
        
        # Compute angles
        angles = np.arctan2(translated[:, 1], translated[:, 0])
        
        # Unwrap to handle branch cuts
        angles = np.unwrap(angles)
        
        # Winding number is total change in angle divided by 2π
        total_change = angles[-1] - angles[0]
        return round(total_change / (2 * np.pi))
    
    def degree_from_winding(self, f, circle_points):
        """
        Estimate degree of map f: S^1 -> S^1 using winding number.
        """
        image_points = np.array([f(p) for p in circle_points])
        return self.winding_number(image_points, [0, 0])

Probability Theory: Measure-Theoretic Foundations

probability-theory

Motivation

Modern probability theory, founded by Kolmogorov in 1933, provides a rigorous mathematical framework for reasoning about uncertainty. By grounding probability in measure theory, we can handle complex sample spaces, uncountable events, and subtle limit theorems that elude elementary approaches. This foundation is essential for stochastic processes, mathematical finance, statistical learning theory, and quantum mechanics. The measure-theoretic approach reveals deep connections between probability and analysis, harmonic analysis, and functional analysis.

Definitions

  • Probability Space: A triple \((\Omega, \mathcal{F}, P)\) where \(\Omega\) is the sample space, \(\mathcal{F}\) is a \(\sigma\)-algebra of events, and \(P: \mathcal{F} \to [0,1]\) is a probability measure with \(P(\Omega) = 1\).
  • Random Variable: A measurable function \(X: \Omega \to \mathbb{R}\) such that \(X^{-1}(B) \in \mathcal{F}\) for all Borel sets \(B\).
  • Expectation: \(\mathbb{E}[X] = \int_\Omega X(\omega) dP(\omega)\), defined via Lebesgue integration.
  • Conditional Expectation: Given a sub-\(\sigma\)-algebra \(\mathcal{G} \subset \mathcal{F}\), \(\mathbb{E}[X|\mathcal{G}]\) is the unique \(\mathcal{G}\)-measurable random variable satisfying \(\int_G \mathbb{E}[X|\mathcal{G}] dP = \int_G X dP\) for all \(G \in \mathcal{G}\).
  • Convergence: Almost sure, in probability, in \(L^p\), and in distribution—each capturing different modes of stochastic convergence.

Theorem: The Strong Law of Large Numbers

Theorem: Let \(\{X_n\}_{n=1}^\infty\) be i.i.d. random variables with \(\mathbb{E}[|X_1|] < \infty\) and \(\mu = \mathbb{E}[X_1]\). Then:

\[\frac{S_n}{n} = \frac{X_1 + \cdots + X_n}{n} \xrightarrow{\text{a.s.}} \mu\]

as \(n \to \infty\), where "a.s." denotes almost sure convergence.

Proof (Sketch via Etemadi's Argument)

Step 1 (Truncation): Define \(Y_n = X_n \mathbf{1}_{\{|X_n| \leq n\}}\). By the Borel-Cantelli lemma and integrability, \(P(X_n \neq Y_n \text{ i.o.}) = 0\), so it suffices to prove SLLN for \(\{Y_n\}\).

Step 2: Let \(S_n' = Y_1 + \cdots + Y_n\). We show \(\frac{S_n' - \mathbb{E}[S_n']}{n} \to 0\) a.s.

Step 3 (Variance Bound): Using independence and the truncation:

\[\text{Var}\left(\frac{S_n'}{n}\right) = \frac{1}{n^2}\sum_{k=1}^n \text{Var}(Y_k) \leq \frac{1}{n^2}\sum_{k=1}^n \mathbb{E}[Y_k^2]\]

Step 4: By Fubini's theorem and integrability, \(\sum_{n=1}^\infty \frac{\mathbb{E}[Y_n^2]}{n^2} < \infty\).

Step 5: Apply Kolmogorov's convergence criterion: for independent mean-zero variables with \(\sum \frac{\text{Var}(Z_n)}{n^2} < \infty\), we have \(\sum \frac{Z_n}{n}\) converges a.s.

Step 6: By Kronecker's lemma, \(\frac{1}{n}\sum_{k=1}^n Z_k \to 0\) a.s. Finally, \(\frac{\mathbb{E}[S_n']}{n} \to \mu\) by dominated convergence. ∎

Notation Guide

  • \(\Omega\) — sample space
  • \(\mathcal{F}\) — \(\sigma\)-algebra of events
  • \(P\) — probability measure
  • \(\mathbb{E}[X]\) — expectation of \(X\)
  • \(\text{Var}(X)\) — variance of \(X\)
  • \(\xrightarrow{\text{a.s.}}\) — almost sure convergence
  • \(\xrightarrow{P}\) — convergence in probability
  • \(\xrightarrow{d}\) — convergence in distribution
  • \(\mathcal{L}(X)\) — law (distribution) of \(X\)

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

class ProbabilityTheory:
    """Computational probability theory tools."""
    
    def __init__(self, seed=None):
        if seed is not None:
            np.random.seed(seed)
    
    def strong_law_simulation(self, distribution, n_max=10000, n_trials=100):
        """
        Simulate Strong Law of Large Numbers.
        distribution: function that generates random samples
        """
        n_values = np.unique(np.logspace(1, np.log10(n_max), 100).astype(int))
        sample_means = np.zeros((n_trials, len(n_values)))
        
        for trial in range(n_trials):
            samples = distribution(n_max)
            for i, n in enumerate(n_values):
                sample_means[trial, i] = np.mean(samples[:n])
        
        return n_values, sample_means
    
    def empirical_cdf(self, samples):
        """Compute empirical CDF."""
        sorted_samples = np.sort(samples)
        n = len(sorted_samples)
        cdf = np.arange(1, n + 1) / n
        return sorted_samples, cdf
    
    def kolmogorov_smirnov(self, samples, theoretical_cdf):
        """
        Compute Kolmogorov-Smirnov statistic.
        """
        sorted_samples, emp_cdf = self.empirical_cdf(samples)
        theo_cdf = theoretical_cdf(sorted_samples)
        
        # KS statistic is max difference
        diff = np.abs(emp_cdf - theo_cdf)
        ks_stat = np.max(diff)
        
        return ks_stat
    
    def characteristic_function(self, t, samples):
        """
        Estimate characteristic function from samples.
        phi(t) = E[exp(itX)]
        """
        return np.mean(np.exp(1j * t * samples))
    
    def central_limit_visualization(self, distribution, sample_sizes=[1, 5, 30, 100], n_simulations=10000):
        """
        Visualize CLT: distribution of sample means approaches normal.
        """
        fig, axes = plt.subplots(2, 2, figsize=(12, 10))
        axes = axes.flatten()
        
        for idx, n in enumerate(sample_sizes):
            sample_means = []
            for _ in range(n_simulations):
                samples = distribution(n)
                sample_means.append(np.mean(samples))
            
            axes[idx].hist(sample_means, bins=50, density=True, alpha=0.7, color='blue')
            axes[idx].set_title(f'n = {n}')
            axes[idx].set_xlabel('Sample Mean')
            axes[idx].set_ylabel('Density')
            
            # Overlay normal approximation
            mu = np.mean(sample_means)
            sigma = np.std(sample_means)
            x = np.linspace(mu - 4*sigma, mu + 4*sigma, 100)
            axes[idx].plot(x, stats.norm.pdf(x, mu, sigma), 'r-', linewidth=2, label='Normal approx.')
            axes[idx].legend()
        
        plt.tight_layout()
        return fig

Numerical Analysis: Algorithms for Continuous Mathematics

numerical-analysis

Real-World Motivation

Numerical analysis bridges the gap between continuous mathematical models and discrete computational reality. From weather prediction and aircraft design to financial modeling and medical imaging, virtually every modern technology relies on numerical algorithms. The field addresses fundamental questions: How do we approximate continuous problems on finite computers? How accurate are these approximations? How can we ensure stability and efficiency? Understanding numerical analysis is essential for computational scientists, engineers, and data scientists who need to solve real-world problems that lack closed-form solutions.

Definitions

  • Condition Number: For a problem \(f\), \(\kappa = \frac{|\delta f| / |f|}{|\delta x| / |x|}\) measures sensitivity to input perturbations. Large \(\kappa\) indicates ill-conditioning.
  • Stability: An algorithm is stable if it produces nearly the right answer for nearly the right input. Backward stability means the computed result is the exact result for slightly perturbed input.
  • Convergence Order: An iterative method has order \(p\) if \(|e_{n+1}| \leq C|e_n|^p\) where \(e_n\) is the error at step \(n\).
  • Interpolation: Finding a function \(p\) from a given class (e.g., polynomials) such that \(p(x_i) = f(x_i)\) at specified nodes \(x_i\).
  • Quadrature: Numerical integration formulas of the form \(\int_a^b f(x) dx \approx \sum_{i=0}^n w_i f(x_i)\).

Theorem: Convergence of Newton's Method

Theorem: Let \(f: \mathbb{R} \to \mathbb{R}\) be \(C^2\) with \(f(r) = 0\) and \(f'(r) \neq 0\). If the initial guess \(x_0\) is sufficiently close to \(r\), then Newton's iteration:

\[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\]

converges quadratically to \(r\): \(|x_{n+1} - r| \leq C|x_n - r|^2\) for some constant \(C\).

Proof

Using Taylor's theorem with remainder:

\[0 = f(r) = f(x_n) + f'(x_n)(r - x_n) + \frac{f''(\xi_n)}{2}(r - x_n)^2\]

for some \(\xi_n\) between \(x_n\) and \(r\). Rearranging:

\[f(x_n) = f'(x_n)(x_n - r) - \frac{f''(\xi_n)}{2}(r - x_n)^2\]

Substituting into Newton's iteration:

\[x_{n+1} = x_n - \frac{f'(x_n)(x_n - r) - \frac{f''(\xi_n)}{2}(r - x_n)^2}{f'(x_n)}\]

\[= r + \frac{f''(\xi_n)}{2f'(x_n)}(r - x_n)^2\]

Therefore:

\[|x_{n+1} - r| = \left|\frac{f''(\xi_n)}{2f'(x_n)}\right||x_n - r|^2\]

By continuity of \(f'\) and \(f''\), if \(x_n\) is close enough to \(r\), we have \(|f''(\xi_n)| \leq M\) and \(|f'(x_n)| \geq m > 0\), giving quadratic convergence with \(C = M/(2m)\). ∎

    def newton_method(self, f, df, x0, tol=1e-10, max_iter=100, track_history=True):
        """
        Newton's method for finding roots of f(x) = 0.
        f: function
        df: derivative of f
        x0: initial guess
        """
        x = x0
        history = [x] if track_history else None
        
        for i in range(max_iter):
            fx = f(x)
            if abs(fx) < tol:
                return x, history, i, True
            
            dfx = df(x)
            if abs(dfx) < self.eps:
                return x, history, i, False
            
            x = x - fx / dfx
            if track_history:
                history.append(x)
        
        return x, history, max_iter, False
    
    def secant_method(self, f, x0, x1, tol=1e-10, max_iter=100):
        """Secant method (derivative-free alternative to Newton)."""
        history = [x0, x1]
        
        for i in range(max_iter):
            fx0, fx1 = f(x0), f(x1)
            if abs(fx1) < tol:
                return x1, history, i, True
            
            # Secant step
            x_new = x1 - fx1 * (x1 - x0) / (fx1 - fx0)
            x0, x1 = x1, x_new
            history.append(x_new)
        
        return x1, history, max_iter, False
    
    def lagrange_interpolation(self, x_points, y_points, x_eval):
        """
        Lagrange polynomial interpolation.
        """
        n = len(x_points)
        result = 0.0
        
        for i in range(n):
            # Compute Lagrange basis polynomial L_i(x)
            L_i = 1.0
            for j in range(n):
                if i != j:
                    L_i *= (x_eval - x_points[j]) / (x_points[i] - x_points[j])
            result += y_points[i] * L_i
        
        return result

        """
        Composite Simpson's rule for integration.
        """
        if n % 2 == 1:
            n += 1

        x = np.linspace(a, b, n + 1)
        y = f(x)
        
        # Simpson's rule: h/3 * [f(x_0) + 4*sum(f(x_odd)) + 2*sum(f(x_even)) + f(x_n)]
        integral = y[0] + y[-1]
        integral += 4 * np.sum(y[1:-1:2])
        integral += 2 * np.sum(y[2:-1:2])
        integral *= h / 3
        
        return integral
    
    def condition_number(self, A):
        """Compute 2-norm condition number of matrix A."""
        return np.linalg.cond(A, 2)

Cryptography: Mathematical Foundations of Security

cryptography

Real-World Motivation

Cryptography secures modern digital communication, from online banking and messaging to blockchain and cloud computing. The field rests on deep mathematical foundations: computational hardness assumptions from number theory and algebraic geometry ensure that breaking encryption is computationally infeasible. Public-key cryptography, introduced by Diffie and Hellman in 1976, revolutionized secure communication by enabling parties to establish shared secrets over public channels. Modern cryptographic protocols combine elegant mathematics with practical engineering to protect billions of daily transactions.

Definitions

  • One-Way Function: A function \(f\) that is easy to compute but hard to invert: given \(y = f(x)\), finding any \(x'\) with \(f(x') = y\) is computationally infeasible.
  • Discrete Logarithm: In a cyclic group \(G = \langle g \rangle\), given \(g\) and \(g^x\), finding \(x\) is the discrete logarithm problem (DLP).
  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point, forming a group under geometric addition.
  • Semantic Security: An encryption scheme is semantically secure if a ciphertext reveals no partial information about the plaintext (equivalently, IND-CPA security).
  • Zero-Knowledge Proof: A protocol where a prover convinces a verifier of a statement's truth without revealing any information beyond the statement's validity.

Theorem: Security of ElGamal Encryption

Theorem: ElGamal encryption is semantically secure under chosen-plaintext attack (IND-CPA) if and only if the Decisional Diffie-Hellman (DDH) assumption holds in the underlying group.

Proof (Sketch)

Setup: In a cyclic group \(G = \langle g \rangle\) of prime order \(q\), public key is \((g, h = g^x)\) where \(x\) is secret. To encrypt message \(m \in G\): choose random \(r\), output \((c_1, c_2) = (g^r, h^r \cdot m)\).

(⇒) DDH ⇒ IND-CPA: Suppose adversary \(\mathcal{A}\) breaks IND-CPA. We construct \(\mathcal{B}\) solving DDH. Given \((g, g^a, g^b, T)\), \(\mathcal{B}\) sets public key \((g, g^a)\) and challenges \(\mathcal{A}\) with ciphertext \((g^b, T \cdot m_b)\) for random bit \(b\).

If \(T = g^{ab}\), this is a valid encryption of \(m_b\). If \(T\) is random, \(T \cdot m_b\) is uniformly random, giving no information. \(\mathcal{A}\)'s advantage translates to DDH advantage.

(⇐) IND-CPA ⇒ DDH: If DDH fails, distinguisher for \((g, g^a, g^b, g^{ab})\) vs random can break ElGamal: given challenge ciphertext \((c_1, c_2)\), test if \((g, h, c_1, c_2/m_0)\) is DDH tuple. ∎

  • \(\mathbb{G}\) — cyclic group (often multiplicative)
  • \(g\) — generator of the group
  • \(q\) — prime order of the group
  • \(\mathbb{Z}_q\) — integers modulo \(q\)
  • \(\text{DLOG}_g(h)\) — discrete log of \(h\) base \(g\)
  • \(\text{Adv}^{\text{ind-cpa}}[\mathcal{A}]\) — IND-CPA advantage
  • \(\overset{\$}{\leftarrow}\) — uniformly random sampling
  • \(\text{negl}(\lambda)\) — negligible function

class Cryptography:
    """Cryptographic primitives and protocols."""
    
    def __init__(self):
        pass
    
    def mod_exp(self, base, exp, mod):
        """Fast modular exponentiation."""
        result = 1
        base = base % mod
        while exp > 0:
            if exp % 2 == 1:
                result = (result * base) % mod
            exp = exp >> 1
            base = (base * base) % mod
        return result
    
    def elgamal_keygen(self, p, g):
        """
        Generate ElGamal key pair.
        p: large prime
        g: generator of multiplicative group modulo p
        """
        x = np.random.randint(2, p-1)  # Private key
        h = self.mod_exp(g, x, p)       # Public key component
        return {'private': x, 'public': (p, g, h)}
    
    def elgamal_encrypt(self, public_key, m):
        """
        Encrypt message m using ElGamal.
        m must be in the group (1 < m < p)
        """
        p, g, h = public_key
        r = np.random.randint(2, p-1)  # Ephemeral randomness
        c1 = self.mod_exp(g, r, p)
        s = self.mod_exp(h, r, p)       # Shared secret
        c2 = (m * s) % p
        return (c1, c2)
    
    def elgamal_decrypt(self, private_key, public_key, ciphertext):
        """Decrypt ElGamal ciphertext."""
        p, g, h = public_key
        x = private_key
        c1, c2 = ciphertext
        s = self.mod_exp(c1, x, p)      # Recover shared secret
        s_inv = pow(s, -1, p)           # Modular inverse
        m = (c2 * s_inv) % p
        return m
    
    def diffie_hellman(self, p, g):
        """
        Diffie-Hellman key exchange.
        Returns shared secret and intermediate values.
        """
        # Alice's private key
        a = np.random.randint(2, p-1)
        A = self.mod_exp(g, a, p)       # Alice's public value
        
        # Bob's private key
        b = np.random.randint(2, p-1)
        B = self.mod_exp(g, b, p)       # Bob's public value
        
        # Shared secrets
        s_alice = self.mod_exp(B, a, p)
        s_bob = self.mod_exp(A, b, p)
        
        assert s_alice == s_bob, "Shared secrets must match!"
        return {'shared_secret': s_alice, 'A': A, 'B': B, 'a': a, 'b': b}
    
    def hash_to_group(self, message, p):
        """Hash a message to an element of Z_p^*."""
        h = hashlib.sha256(message.encode()).hexdigest()
        return (int(h, 16) % (p - 1)) + 1

Computational Geometry: Algorithms for Spatial Problems

computational-geometry

Real-World Motivation

Computational geometry develops efficient algorithms for geometric problems, with applications in computer graphics, robotics, geographic information systems, computer-aided design, and machine learning. From finding the closest pair of points in a dataset to computing Voronoi diagrams for facility location, geometric algorithms underpin modern technology. The field combines elegant mathematical insights with careful algorithmic analysis to solve problems that are both theoretically interesting and practically essential. Understanding computational geometry provides tools for solving spatial reasoning problems across science and engineering.

Definitions

  • Convex Hull: The smallest convex set containing a given set of points. For a set \(S\), \(\text{conv}(S) = \{\sum \lambda_i x_i : x_i \in S, \lambda_i \geq 0, \sum \lambda_i = 1\}\).
  • Voronoi Diagram: A partition of the plane into regions where each region consists of points closer to one site than to any other. For sites \(\{p_i\}\), \(V(p_i) = \{x : d(x, p_i) \leq d(x, p_j) \forall j\}\).
  • Delaunay Triangulation: The dual graph of the Voronoi diagram; a triangulation where no point lies inside the circumcircle of any triangle.
  • Arrangement: The subdivision of space induced by a collection of geometric objects (lines, curves, surfaces).
  • Geometric Duality: A transformation mapping points to lines and vice versa, preserving incidence relationships.

Theorem: Delaunay Triangulation Maximizes Minimum Angle

Theorem: Among all triangulations of a given set of points in the plane, the Delaunay triangulation maximizes the minimum angle. Equivalently, it minimizes the maximum circumradius of triangles.

Proof (via Edge Flipping)

Setup: Consider two adjacent triangles forming a convex quadrilateral. The diagonal can be flipped to produce an alternative triangulation.

Key Lemma: For a convex quadrilateral \(ABCD\), the diagonal \(AC\) is in the Delaunay triangulation if and only if \(D\) lies outside the circumcircle of \(\triangle ABC\) (equivalently, \(B\) lies outside the circumcircle of \(\triangle ADC\)).

Angle Comparison: Let \(\alpha, \beta, \gamma, \delta\) be the angles at vertices \(A, B, C, D\) when using diagonal \(AC\), and \(\alpha', \beta', \gamma', \delta'\) when using diagonal \(BD\). By the inscribed angle theorem:

\[\alpha + \beta + \gamma + \delta = \alpha' + \beta' + \gamma' + \delta' = 360°\]

Flip Condition: If \(D\) is inside the circumcircle of \(\triangle ABC\), then \(\angle ADB > \angle ACB\). Flipping to diagonal \(BD\) increases the minimum angle.

Termination: Each legal flip strictly increases the minimum angle. Since there are finitely many triangulations, the process terminates at the Delaunay triangulation, which locally and therefore globally maximizes the minimum angle. ∎

  • \(\text{inCircle}(a, b, c, d)\) — incircle test

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial import ConvexHull, Voronoi, Delaunay

class ComputationalGeometry:
    """Computational geometry algorithms."""
    
    def __init__(self):
        pass
    
    def orientation(self, p, q, r):
        """
        Compute orientation of ordered triplet (p, q, r).
        Returns:
            0 if collinear, 1 if clockwise, 2 if counterclockwise
        """
        val = (q[1] - p[1]) * (r[0] - q[0]) - (q[0] - p[0]) * (r[1] - q[1])
        if val == 0:
            return 0
        return 1 if val > 0 else 2
    
    def convex_hull_graham_scan(self, points):
        """
        Compute convex hull using Graham scan algorithm.
        Time complexity: O(n log n)
        """
        n = len(points)
        if n < 3:
            return points
        
        # Find bottom-most point
        ymin_idx = min(range(n), key=lambda i: (points[i][1], points[i][0]))
        points[0], points[ymin_idx] = points[ymin_idx], points[0]
        pivot = points[0]
        
        # Sort by polar angle with pivot
        def polar_angle(p):
            return np.arctan2(p[1] - pivot[1], p[0] - pivot[0])
        
        sorted_points = [pivot] + sorted(points[1:], key=polar_angle)
        
        # Graham scan
        hull = [sorted_points[0], sorted_points[1]]
        for i in range(2, len(sorted_points)):
            while len(hull) > 1 and self.orientation(hull[-2], hull[-1], sorted_points[i]) != 2:
                hull.pop()
            hull.append(sorted_points[i])
        
        return hull
    
    def closest_pair_divide_conquer(self, points):
        """
        Find closest pair of points using divide and conquer.
        Time complexity: O(n log n)
        """
        def closest_pair_recursive(px, py):
            n = len(px)
            if n <= 3:
                return self._brute_force_closest(px)
            
            mid = n // 2
            mid_point = px[mid]
            
            # Divide
            py_left = [p for p in py if p[0] <= mid_point[0]]
            py_right = [p for p in py if p[0] > mid_point[0]]
            
            dl = closest_pair_recursive(px[:mid], py_left)
            dr = closest_pair_recursive(px[mid:], py_right)
            
            d = min(dl, dr)
            
            # Conquer: check strip around midline
            strip = [p for p in py if abs(p[0] - mid_point[0]) < d]
            
            for i in range(len(strip)):
                for j in range(i + 1, min(i + 7, len(strip))):
                    if strip[j][1] - strip[i][1] >= d:
                        break
                    d = min(d, np.linalg.norm(np.array(strip[i]) - np.array(strip[j])))
            
            return d
        
        px = sorted(points, key=lambda p: p[0])
        py = sorted(points, key=lambda p: p[1])
        return closest_pair_recursive(px, py)
    
    def _brute_force_closest(self, points):
        """Brute force closest pair (for small n)."""
        n = len(points)
        min_dist = float('inf')
        for i in range(n):
            for j in range(i + 1, n):
                dist = np.linalg.norm(np.array(points[i]) - np.array(points[j]))
                min_dist = min(min_dist, dist)
        return min_dist
    
    def point_in_polygon(self, point, polygon):
        """
        Ray casting algorithm for point-in-polygon test.
        """
        x, y = point
        n = len(polygon)
        inside = False
        
        j = n - 1
        for i in range(n):
            xi, yi = polygon[i]
            xj, yj = polygon[j]
            
            if ((yi > y) != (yj > y)) and (x < (xj - xi) * (y - yi) / (yj - yi) + xi):
                inside = not inside
            j = i
        
        return inside

Geometric topology emerged from the study of surfaces and spaces in the late 19th century, with foundational work by Poincaré, Klein, and Dehn. Definitions

  • Manifold: A topological space locally homeomorphic to \(\mathbb{R}^n\), with compatible charts forming an atlas.
  • Fundamental Group: \(\pi_1(X, x_0)\) is the group of homotopy classes of loops based at \(x_0\), measuring the "holes" in \(X\).
  • Knot: An embedding \(K: S^1 \hookrightarrow S^3\). Two knots are equivalent if related by ambient isotopy.
  • Seifert Surface: A compact, oriented surface whose boundary is a given knot.
  • Hyperbolic Structure: A complete Riemannian metric of constant sectional curvature \(-1\).

Theorem: The Classification of Surfaces

Theorem: Every closed, connected, orientable surface is homeomorphic to exactly one of:

\[S^2 \text{ (sphere)} \quad \text{or} \quad T^2 \# \cdots \# T^2 \text{ (connected sum of } g \text{ tori)}\]

The integer \(g \geq 0\) is the genus, a complete invariant.

Proof (Sketch)

Step 1 (Triangulation): Every surface admits a triangulation (Rado, 1925). This reduces the problem to combinatorial topology.

Step 2 (Edge Identification): A surface can be represented as a polygon with edges identified in pairs. The standard forms are:

\[aa^{-1} \text{ (sphere)}, \quad a_1b_1a_1^{-1}b_1^{-1}\cdots a_gb_ga_g^{-1}b_g^{-1} \text{ (genus } g)\]

Step 3 (Normalization): Any polygon with edge identifications can be transformed to one of these standard forms using cut-and-paste operations.

Step 4 (Invariants): The Euler characteristic \(\chi = V - E + F = 2 - 2g\) distinguishes different genera. The fundamental group \(\pi_1 = \langle a_1, b_1, \ldots, a_g, b_g \mid \prod [a_i, b_i] = 1 \rangle\) also distinguishes surfaces. ∎

  • \(M \# N\) — connected sum
  • \(\langle S \mid R \rangle\) — group presentation
  • \([a, b] = aba^{-1}b^{-1}\) — commutator

Stochastic Processes: Randomness Evolving in Time

stochastic-processes

Historical Context

The mathematical theory of stochastic processes emerged in the early 20th century, with Bachelier's 1900 thesis on stock prices and Einstein's 1905 work on Brownian motion. Wiener provided the rigorous construction of Brownian motion in 1923, while Kolmogorov's 1931 foundations established the modern framework. Itô's stochastic calculus (1940s-50s) enabled rigorous treatment of random differential equations, revolutionizing mathematical finance and physics. Today, stochastic processes underpin everything from queueing theory and population genetics to machine learning and financial engineering.

Definitions

  • Stochastic Process: A collection of random variables \(\{X_t\}_{t \in T}\) indexed by time \(t\), defined on a probability space \((\Omega, \mathcal{F}, P)\).
  • Markov Property: The future is independent of the past given the present: \(P(X_{t+1} | X_t, X_{t-1}, \ldots) = P(X_{t+1} | X_t)\).
  • Martingale: A process where \(\mathbb{E}[X_{t+1} | \mathcal{F}_t] = X_t\), modeling fair games.
  • Brownian Motion: A continuous process with independent Gaussian increments: \(W_t - W_s \sim N(0, t-s)\).
  • Stochastic Differential Equation: \(dX_t = \mu(X_t, t)dt + \sigma(X_t, t)dW_t\), interpreted via Itô calculus.

Theorem: The Reflection Principle for Brownian Motion

Theorem: Let \(W_t\) be standard Brownian motion and \(M_t = \max_{0 \leq s \leq t} W_s\). For \(a > 0\):

\[P(M_t \geq a) = 2P(W_t \geq a) = 2(1 - \Phi(a/\sqrt{t}))\]

where \(\Phi\) is the standard normal CDF. Consequently, \(M_t \stackrel{d}{=} |W_t|\).

Proof

Setup: Define the stopping time \(\tau_a = \inf\{t \geq 0 : W_t = a\}\). We want \(P(M_t \geq a) = P(\tau_a \leq t)\).

Key Observation: By continuity of paths, if \(W_t > a\) then \(\tau_a < t\). Conversely, if \(\tau_a < t\), then by symmetry (the "reflection"), the path reflected after hitting \(a\) is equally likely.

Reflection Argument: Define the reflected process:

\[\tilde{W}_s = \begin{cases} W_s & s \leq \tau_a \\ 2a - W_s & s > \tau_a \end{cases}\]

By the strong Markov property, \(\tilde{W}\) is also Brownian motion.

Calculation:

\[P(M_t \geq a, W_t < a) = P(\tau_a \leq t, W_t < a)\]

By reflection, this equals \(P(\tau_a \leq t, \tilde{W}_t > a) = P(W_t > a)\) (since \(\tilde{W}_t > a\) iff \(W_t < a\) when \(\tau_a \leq t\)).

Also \(P(M_t \geq a, W_t \geq a) = P(W_t \geq a)\) (since \(W_t \geq a\) implies \(M_t \geq a\)).

Therefore: \(P(M_t \geq a) = P(M_t \geq a, W_t < a) + P(M_t \geq a, W_t \geq a) = 2P(W_t \geq a)\). ∎

Notation Guide

  • \(\{X_t\}_{t \geq 0}\) — stochastic process
  • \(\mathcal{F}_t\) — filtration (information up to time t)
  • \(W_t\) or \(B_t\) — Brownian motion
  • \(dW_t\) — Itô differential
  • \(\langle X \rangle_t\) — quadratic variation
  • \(\tau\) — stopping time
  • \(P_x\) — probability starting from x
  • \(\mathbb{E}_x\) — expectation starting from x

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

class StochasticProcesses:
    """Simulation and analysis of stochastic processes."""
    
    def __init__(self, seed=None):
        if seed is not None:
            np.random.seed(seed)
    
    def brownian_motion(self, T=1.0, N=1000, n_paths=1):
        """
        Simulate standard Brownian motion using random walk approximation.
        """
        dt = T / N
        dW = np.random.normal(0, np.sqrt(dt), size=(n_paths, N))
        W = np.zeros((n_paths, N + 1))
        W[:, 1:] = np.cumsum(dW, axis=1)
        t = np.linspace(0, T, N + 1)
        return t, W
    
    def geometric_brownian_motion(self, S0, mu, sigma, T=1.0, N=1000, n_paths=1):
        """
        Simulate geometric Brownian motion: dS = mu*S*dt + sigma*S*dW
        Solution: S_t = S_0 * exp((mu - sigma^2/2)*t + sigma*W_t)
        """
        t, W = self.brownian_motion(T, N, n_paths)
        S = S0 * np.exp((mu - 0.5 * sigma**2) * t + sigma * W)
        return t, S
    
    def ornstein_uhlenbeck(self, theta, mu, sigma, X0, T=1.0, N=1000, n_paths=1):
        """
        Simulate Ornstein-Uhlenbeck process: dX = theta*(mu - X)*dt + sigma*dW
        Mean-reverting process used in interest rate modeling.
        """
        dt = T / N
        X = np.zeros((n_paths, N + 1))
        X[:, 0] = X0
        
        for i in range(N):
            dW = np.random.normal(0, np.sqrt(dt), size=n_paths)
            X[:, i+1] = X[:, i] + theta * (mu - X[:, i]) * dt + sigma * dW
        
        t = np.linspace(0, T, N + 1)
        return t, X
    
    def reflection_principle_test(self, T=1.0, N=10000, n_simulations=10000, a=1.0):
        """
        Verify the reflection principle: P(M_t >= a) = 2*P(W_t >= a)
        """
        dt = T / N
        max_vals = []
        final_vals = []
        
        for _ in range(n_simulations):
            dW = np.random.normal(0, np.sqrt(dt), size=N)
            W = np.concatenate([[0], np.cumsum(dW)])
            max_vals.append(np.max(W))
            final_vals.append(W[-1])
        
        max_vals = np.array(max_vals)
        final_vals = np.array(final_vals)
        
        # Empirical probabilities
        P_M_ge_a = np.mean(max_vals >= a)
        P_W_ge_a = np.mean(final_vals >= a)
        
        # Theoretical
        P_W_ge_a_theory = 1 - norm.cdf(a / np.sqrt(T))
        P_M_ge_a_theory = 2 * P_W_ge_a_theory
        
        return {
            'empirical': {'P_M': P_M_ge_a, 'P_W': P_W_ge_a, 'ratio': P_M_ge_a / P_W_ge_a if P_W_ge_a > 0 else float('inf')},
            'theoretical': {'P_M': P_M_ge_a_theory, 'P_W': P_W_ge_a_theory, 'ratio': 2.0}
        }
    
    def hitting_time_simulation(self, a, n_simulations=1000, max_steps=10000):
        """
        Simulate hitting time tau_a = inf{t >= 0: W_t = a}
        """
        hitting_times = []
        dt = 0.001
        
        for _ in range(n_simulations):
            W = 0
            for step in range(max_steps):
                W += np.random.normal(0, np.sqrt(dt))
                if W >= a:
                    hitting_times.append(step * dt)
                    break
            else:
                hitting_times.append(None)  # Didn't hit
        
        return [t for t in hitting_times if t is not None]

Combinatorial Designs: Structured Configurations

combinatorial-designs

Historical Context

Combinatorial design theory traces its origins to recreational mathematics and statistical experiments. In 1782, Euler posed the famous "36 officers problem," asking whether six regiments of six officers each of six different ranks could be arranged in a 6×6 square so that no rank or regiment repeats in any row or column. This led to the theory of Latin squares and, ultimately, the proof that no such arrangement exists—a rare case of a negative solution to an existence problem. Design theory found practical application in the 20th century through R.A. Fisher's work on experimental design in statistics, and later in coding theory and cryptography.

Definitions

  • Block Design: A pair \((X, \mathcal{B})\) where \(X\) is a set of \(v\) points and \(\mathcal{B}\) is a collection of \(b\) subsets (blocks) of \(X\), each of size \(k\).
  • Balanced Incomplete Block Design (BIBD): A design where every pair of distinct points appears in exactly \(\lambda\) blocks. Parameters satisfy \(r(k-1) = \lambda(v-1)\) and \(bk = vr\).
  • Latin Square: An \(n \times n\) array where each symbol appears exactly once in each row and column.
  • Orthogonal Arrays: An array where, in any two columns, every ordered pair of symbols appears equally often.
  • Steiner System: A BIBD with \(\lambda = 1\), denoted \(S(t, k, v)\), where every \(t\)-subset of points is contained in exactly one block.

Theorem: Fisher's Inequality

Theorem: In any BIBD with \(v\) points and \(b\) blocks, if \(v > k\) (the design is incomplete), then \(b \geq v\).

Proof

Let \(A\) be the \(v \times b\) incidence matrix of the design, where \(A_{ij} = 1\) if point \(i\) is in block \(j\), and 0 otherwise.

Step 1: Compute \(AA^T\). The diagonal entries are \((AA^T)_{ii} = r\) (each point is in \(r\) blocks). Off-diagonal entries are \((AA^T)_{ij} = \lambda\) for \(i \neq j\) (each pair of points is in \(\lambda\) blocks).

Step 2: Therefore:

\[AA^T = (r - \lambda)I + \lambda J\]

where \(I\) is the identity and \(J\) is the all-ones matrix.

Step 3: The eigenvalues of \(AA^T\) are: \(r + \lambda(v-1)\) (once, eigenvector \((1,1,\ldots,1)\)) and \(r - \lambda\) (with multiplicity \(v-1\)).

Step 4: From the BIBD parameter relation \(r(k-1) = \lambda(v-1)\), we get \(r > \lambda\) (since \(v > k\)). Thus all eigenvalues of \(AA^T\) are positive, so \(AA^T\) is positive definite.

Step 5: Therefore \(\text{rank}(AA^T) = v\). Since \(\text{rank}(AA^T) \leq \text{rank}(A) \leq b\), we conclude \(v \leq b\). ∎

Notation Guide

  • \((v, b, r, k, \lambda)\) — BIBD parameters
  • \(S(t, k, v)\) — Steiner system
  • \(OA(N, k, s, t)\) — orthogonal array
  • \(A\) — incidence matrix
  • \(\text{PG}(n, q)\) — projective geometry
  • \(\text{AG}(n, q)\) — affine geometry
  • \(LS(n)\) — Latin square of order n

import numpy as np
import matplotlib.pyplot as plt
from itertools import combinations

class CombinatorialDesigns:
    """Combinatorial design construction and analysis."""
    
    def __init__(self):
        pass
    
    def generate_latin_square(self, n):
        """
        Generate a Latin square of order n using cyclic construction.
        """
        return [[(i + j) % n for j in range(n)] for i in range(n)]
    
    def is_latin_square(self, square):
        """Verify if a square is a Latin square."""
        n = len(square)
        for i in range(n):
            if set(square[i]) != set(range(n)):
                return False
            if set(square[j][i] for j in range(n)) != set(range(n)):
                return False
        return True
    
    def are_orthogonal(self, L1, L2):
        """
        Check if two Latin squares are orthogonal.
        All ordered pairs (L1[i][j], L2[i][j]) must be distinct.
        """
        n = len(L1)
        pairs = set()
        for i in range(n):
            for j in range(n):
                pair = (L1[i][j], L2[i][j])
                if pair in pairs:
                    return False
                pairs.add(pair)
        return True
    
    def steiner_triple_system(self, v):
        """
        Generate Steiner triple system S(2, 3, v) if it exists.
        Exists iff v ≡ 1 or 3 (mod 6)
        """
        if v % 6 not in [1, 3]:
            return None
        
        points = list(range(v))
        blocks = []
        
        # Bose construction for v = 6k + 3
        if v % 6 == 3:
            k = (v - 3) // 6
            # Points: (i, j) where i ∈ {0,1,2}, j ∈ Z_{2k+1}
            # Plus three special points
            for x in range(2*k + 1):
                for i in range(3):
                    # Type 1 blocks
                    blocks.append([
                        (i, x), 
                        ((i+1) % 3, x), 
                        ((i+2) % 3, x)
                    ])
            
            for x in range(2*k + 1):
                for y in range(x + 1, 2*k + 1):
                    for i in range(3):
                        # Type 2 blocks
                        blocks.append([
                            (i, x),
                            (i, y),
                            ((i+1) % 3, (x+y) // 2) if (x+y) % 2 == 0 else ((i+2) % 3, (x+y) // 2)
                        ])
        
        # Simplified: return all triples for small v
        if v <= 7:
            for triple in combinations(points, 3):
                blocks.append(list(triple))
            return points, blocks
        
        return points, blocks
    
    def fano_plane(self):
        """
        Return the Fano plane: S(2, 3, 7), the smallest Steiner triple system.
        """
        points = list(range(7))
        blocks = [
            [0, 1, 2],
            [0, 3, 4],
            [0, 5, 6],
            [1, 3, 5],
            [1, 4, 6],
            [2, 3, 6],
            [2, 4, 5]
        ]
        return points, blocks
    
    def verify_bibd(self, points, blocks, v, k, lambda_param):
        """Verify that a design is a BIBD with given parameters."""
        if len(points) != v:
            return False
        for block in blocks:
            if len(block) != k:
                return False
        
        # Check lambda condition
        for pair in combinations(points, 2):
            count = sum(1 for block in blocks if pair[0] in block and pair[1] in block)
            if count != lambda_param:
                return False
        return True

📜 Math History

Emmy Noether: The Mother of Modern Algebra

Amalie Emmy Noether (1882–1935) transformed the landscape of mathematics in the early 20th century, earning recognition as the most significant woman in the history of mathematics. Born into a Jewish family in Erlangen, Germany, Noether initially faced formidable barriers to academic employment due to her gender. Despite earning her doctorate in 1907 under Paul Gordan, she worked without pay at the University of Erlangen for seven years, officially supervising doctoral students while her father, a mathematics professor, served as the nominal advisor.

Her breakthrough came in 1915 when David Hilbert and Felix Klein invited her to the University of Göttingen, then the world's leading center for mathematical research. Hilbert famously defended her against those who opposed women faculty: "I do not see that the sex of the candidate is an argument against her admission. After all, we are a university, not a bath house." Even so, Noether lectured for four years under Hilbert's name before receiving an official appointment.

Noether's 1921 paper "Idealtheorie in Ringbereichen" (Theory of Ideals in Ring Domains) revolutionized algebra by establishing that every ideal in a polynomial ring over a field has a finite basis—the ascending chain condition that defines Noetherian rings. This work unified disparate results in algebraic number theory and algebraic geometry, providing the conceptual framework that would dominate 20th-century algebra. Her approach was radically abstract: where earlier mathematicians worked with explicit computations, Noether focused on structural properties and homomorphisms.

Her 1918 theorem connecting symmetries and conservation laws—now called Noether's Theorem—remains fundamental to modern physics. The theorem states that every differentiable symmetry of the action of a physical system has a corresponding conservation law. Energy conservation corresponds to time translation symmetry; momentum conservation to spatial translation symmetry; angular momentum conservation to rotational symmetry. This insight underpins the standard model of particle physics and general relativity.

Dismissed from Göttingen by the Nazi regime in 1933 due to her Jewish heritage, Noether emigrated to the United States, joining Bryn Mawr College and the Institute for Advanced Study. She died unexpectedly in 1935 following surgery, at the height of her powers. Einstein wrote in her obituary: "In the judgment of the most competent living mathematicians, Fräulein Noether was the most significant creative mathematical genius thus far produced since the higher education of women began." Her legacy lives on in every course on abstract algebra, in the Noetherian rings that bear her name, and in the structural approach to mathematics that she pioneered.

Putnam-Style Problem: Irrationality and Series

Problem: Let \(\alpha\) be an irrational number between 0 and 1. Define the sequence \(\{a_n\}\) by:

\[a_n = \sum_{k=1}^{n} \frac{\lfloor k\alpha \rfloor}{k(k+1)}\]

Prove that \(\lim_{n \to \infty} a_n\) exists and equals \(\alpha\).

Hint (click to reveal)

Use summation by parts (discrete integration by parts) and the fact that \(\sum_{k=1}^{n} \lfloor k\alpha \rfloor = n\lfloor n\alpha \rfloor - \sum_{k=1}^{n-1} k(\lfloor (k+1)\alpha \rfloor - \lfloor k\alpha \rfloor)\). Also recall that \(\sum_{k=1}^{\infty} \frac{1}{k(k+1)} = 1\).

Solution (click to reveal)

Solution:

We use summation by parts. Let \(b_k = \lfloor k\alpha \rfloor\) and \(c_k = \frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}\).

By summation by parts:

\[\sum_{k=1}^{n} b_k c_k = b_{n+1} \sum_{k=1}^{n} c_k - \sum_{k=1}^{n} (b_{k+1} - b_k) \sum_{j=1}^{k} c_j\]

Since \(\sum_{j=1}^{k} c_j = 1 - \frac{1}{k+1}\), we have:

\[a_n = \lfloor (n+1)\alpha \rfloor \left(1 - \frac{1}{n+1}\right) - \sum_{k=1}^{n} (\lfloor (k+1)\alpha \rfloor - \lfloor k\alpha \rfloor)\left(1 - \frac{1}{k+1}\right)\]

Note that \(\lfloor (k+1)\alpha \rfloor - \lfloor k\alpha \rfloor \in \{\lfloor \alpha \rfloor, \lfloor \alpha \rfloor + 1\} = \{0, 1\}\) since \(0 < \alpha < 1\).

Let \(S_n = \sum_{k=1}^{n} (\lfloor (k+1)\alpha \rfloor - \lfloor k\alpha \rfloor) = \lfloor (n+1)\alpha \rfloor\).

Then:

\[a_n = \lfloor (n+1)\alpha \rfloor - \frac{\lfloor (n+1)\alpha \rfloor}{n+1} - \lfloor (n+1)\alpha \rfloor + \sum_{k=1}^{n} \frac{\lfloor (k+1)\alpha \rfloor - \lfloor k\alpha \rfloor}{k+1}\]

\[= -\frac{\lfloor (n+1)\alpha \rfloor}{n+1} + \sum_{k=2}^{n+1} \frac{\lfloor k\alpha \rfloor - \lfloor (k-1)\alpha \rfloor}{k}\]

As \(n \to \infty\), \(\frac{\lfloor (n+1)\alpha \rfloor}{n+1} \to \alpha\). For the sum, note that \(\lfloor k\alpha \rfloor - \lfloor (k-1)\alpha \rfloor = 1\) when \(\{k\alpha\} < \{\alpha\}\) and 0 otherwise, where \(\{x\}\) is the fractional part. By Weyl's equidistribution theorem, this occurs with frequency \(\alpha\), so the sum converges to \(\alpha\). Therefore \(\lim_{n \to \infty} a_n = \alpha\). ∎

The Mandelbrot Set: Infinite Complexity from Simple Rules

The Mandelbrot set is perhaps the most famous fractal in mathematics, arising from the iteration of simple quadratic polynomials in the complex plane. For each complex number \(c\), we consider the sequence defined by \(z_0 = 0\) and \(z_{n+1} = z_n^2 + c\). The Mandelbrot set consists of all \(c\) for which this sequence remains bounded.

The boundary of the Mandelbrot set exhibits infinite complexity: zooming in reveals ever-finer structures that resemble the whole set (approximate self-similarity), yet each region contains unique features. The set is connected, but its boundary has Hausdorff dimension 2—maximally complex for a subset of the plane.

The visualization below colors points by how quickly the iteration escapes to infinity (if it does), creating the characteristic bands of color. Black points are those in the Mandelbrot set itself.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LogNorm

def mandelbrot(c, max_iter=100):
    """
    Compute the number of iterations until escape for a given c.
    Returns max_iter if the point doesn't escape (in the set).
    """
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """
    Compute the Mandelbrot set over a rectangular region.
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    M = np.zeros(C.shape, dtype=int)
    
    for i in range(max_iter):
        mask = np.abs(Z) <= 2
        Z[mask] = Z[mask]**2 + C[mask]
        M[~mask & (M == 0)] = i
    
    M[M == 0] = max_iter
    return M

# Create high-resolution visualization
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Full view

                        width=800, height=800, max_iter=100)
im1 = axes[0].imshow(M_full, extent=[-2.5, 1.0, -1.25, 1.25], 
                     cmap='hot', origin='lower', interpolation='bilinear')

axes[0].set_xlabel('Re(c)')
