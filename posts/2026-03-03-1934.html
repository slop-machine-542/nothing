1. Elliptic Curves: The Intersection of Algebra, Geometry, and Number Theory

Motivation

Elliptic curves are among the most fascinating objects in mathematics, connecting algebra, geometry, and number theory in profound ways. They played a central role in the proof of Fermat's Last Theorem and form the foundation of modern cryptographic systems. The study of elliptic curves reveals deep patterns in the arithmetic of rational numbers and provides a window into the Langlands program and the Birch and Swinnerton-Dyer conjecture, one of the Millennium Prize Problems.

Definitions

Let \(K\) be a field (typically \(\mathbb{Q}\), \(\mathbb{R}\), \(\mathbb{C}\), or a finite field \(\mathbb{F}_q\)).

  • Elliptic Curve: A smooth projective curve of genus 1 with a specified base point \(O\). Over a field of characteristic \(\neq 2, 3\), it can be written in Weierstrass form: \[E : y^2 = x^3 + ax + b\] where the discriminant \(\Delta = -16(4a^3 + 27b^2) \neq 0\) ensures smoothness.
  • Group Law: The points on \(E\) form an abelian group with identity \(O\) (the point at infinity). For points \(P\) and \(Q\), their sum \(P + Q\) is defined geometrically: draw the line through \(P\) and \(Q\), find the third intersection point \(R\) with \(E\), then reflect \(R\) over the x-axis.
  • j-invariant: \[j(E) = 1728 \cdot \frac{4a^3}{4a^3 + 27b^2}\] Two elliptic curves over an algebraically closed field are isomorphic if and only if they have the same j-invariant.
  • Torsion Subgroup: \(E(K)[n] = \{P \in E(K) : nP = O\}\), the points of order dividing \(n\).

Theorem: Mordell's Theorem

Theorem (Mordell, 1922): Let \(E\) be an elliptic curve over \(\mathbb{Q}\). Then the group of rational points \(E(\mathbb{Q})\) is finitely generated. That is: \[E(\mathbb{Q}) \cong E(\mathbb{Q})_{\text{tors}} \times \mathbb{Z}^r\] where \(E(\mathbb{Q})_{\text{tors}}\) is the finite torsion subgroup and \(r \geq 0\) is the rank of \(E\).

Proof Sketch

Step 1 (Height Function): Define a height function \(h: E(\mathbb{Q}) \to \mathbb{R}_{\geq 0}\) measuring the complexity of a point. For \(P = (x, y)\) with \(x = a/b\) in lowest terms, define: \[H(P) = \max(|a|, |b|), \quad h(P) = \log H(P)\]

Step 2 (Descent): Show there are only finitely many points of bounded height. This implies the torsion subgroup is finite.

Step 3 (Weak Mordell-Weil): Prove that \(E(\mathbb{Q})/2E(\mathbb{Q})\) is finite. This uses the theory of heights and the fact that the 2-descent map factors through a finite set.

Step 4 (Descent Lemma): If \(G\) is an abelian group such that \(G/2G\) is finite and there exists a height function with certain properties, then \(G\) is finitely generated.

Step 5: Apply the descent lemma to \(G = E(\mathbb{Q})\) to conclude it is finitely generated. ∎

Notation Guide

  • \(E(K)\): Group of \(K\)-rational points on \(E\)
  • \(O\): Identity element (point at infinity)
  • \(nP\): Point addition of \(P\) with itself \(n\) times
  • \(\Delta\): Discriminant of the Weierstrass equation
  • \(j(E)\): j-invariant of the elliptic curve
  • \(\text{rank}(E)\): Rank of the free part of \(E(\mathbb{Q})\)

import numpy as np
import matplotlib.pyplot as plt
from fractions import Fraction

class EllipticCurve:
    """
    Elliptic curve in short Weierstrass form: y^2 = x^3 + ax + b
    """
    
    def __init__(self, a, b):
        self.a = a
        self.b = b
        self.discriminant = -16 * (4 * a**3 + 27 * b**2)
        if self.discriminant == 0:
            raise ValueError("Curve is singular (discriminant = 0)")
    
    def j_invariant(self):
        """Compute the j-invariant of the curve."""
        return 1728 * (4 * self.a**3) / (4 * self.a**3 + 27 * self.b**2)
    
    def is_on_curve(self, x, y):
        """Check if point (x, y) lies on the curve."""
        if x is None and y is None:  # Point at infinity
            return True
        return y**2 == x**3 + self.a * x + self.b
    
    def add_points(self, P, Q):
        """
        Add two points on the curve using the group law.
        Points are tuples (x, y) or None for point at infinity.
        """
        # Handle identity element
        if P is None:
            return Q
        if Q is None:
            return P
        
        x1, y1 = P
        x2, y2 = Q
        
        # Handle P + (-P) = O
        if x1 == x2 and y1 == -y2:
            return None
        
        # Compute slope
        if P == Q:
            # Point doubling: tangent slope
            if y1 == 0:
                return None  # 2P = O when y1 = 0
            m = (3 * x1**2 + self.a) / (2 * y1)
        else:
            # Point addition: secant slope
            m = (y2 - y1) / (x2 - x1)
        
        # Compute resulting point
        x3 = m**2 - x1 - x2
        y3 = m * (x1 - x3) - y1
        
        return (x3, y3)
    
    def scalar_mult(self, n, P):
        """Compute nP using double-and-add algorithm."""
        if n == 0 or P is None:
            return None
        if n < 0:
            x, y = P
            return self.scalar_mult(-n, (x, -y))
        
        result = None
        addend = P
        
        while n > 0:
            if n & 1:
                result = self.add_points(result, addend)
            addend = self.add_points(addend, addend)
            n >>= 1
        
        return result
    
    def plot(self, x_range=(-3, 3), num_points=1000):
        """Plot the elliptic curve."""
        x = np.linspace(x_range[0], x_range[1], num_points)
        y_squared = x**3 + self.a * x + self.b
        
        # Only plot where y^2 >= 0
        mask = y_squared >= 0
        x_pos = x[mask]
        y_pos = np.sqrt(y_squared[mask])
        
        fig, ax = plt.subplots(figsize=(10, 8))
        ax.plot(x_pos, y_pos, 'b-', linewidth=2, label='$y = \\sqrt{x^3 + ax + b}$')
        ax.plot(x_pos, -y_pos, 'b-', linewidth=2, label='$y = -\\sqrt{x^3 + ax + b}$')
        ax.axhline(y=0, color='k', linewidth=0.5)
        ax.axvline(x=0, color='k', linewidth=0.5)
        ax.set_xlabel('x')
        ax.set_ylabel('y')
        ax.set_title(f'Elliptic Curve: $y^2 = x^3 + {self.a}x + {self.b}$')
        ax.grid(True, alpha=0.3)
        ax.legend()
        ax.set_aspect('equal')
        return fig, ax

# Example: The curve y^2 = x^3 - x + 1 (discriminant = -368 ≠ 0)

2. Modular Forms: Symmetries of the Complex Plane

Motivation

Modular forms are complex-analytic functions with remarkable symmetry properties that make them indispensable in number theory. They encode deep arithmetic information and connect seemingly unrelated areas of mathematics. The proof of Fermat's Last Theorem by Andrew Wiles established a profound connection between elliptic curves and modular forms, realizing a special case of the Langlands program. Modular forms also appear in string theory, coding theory, and the theory of partitions.

Definitions

Let \(\mathbb{H} = \{z \in \mathbb{C} : \text{Im}(z) > 0\}\) be the upper half-plane.

  • Modular Group: \(\text{SL}_2(\mathbb{Z}) = \left\{\begin{pmatrix} a & b \\ c & d \end{pmatrix} : a, b, c, d \in \mathbb{Z}, ad - bc = 1\right\}\)
  • Action on \(\mathbb{H}\): For \(\gamma = \begin{pmatrix} a & b \\ c & d \end{pmatrix} \in \text{SL}_2(\mathbb{Z})\) and \(z \in \mathbb{H}\): \[\gamma z = \frac{az + b}{cz + d}\]
  • Modular Form of Weight \(k\): A holomorphic function \(f: \mathbb{H} \to \mathbb{C}\) satisfying:
    1. \(f(\gamma z) = (cz + d)^k f(z)\) for all \(\gamma \in \text{SL}_2(\mathbb{Z})\)
    2. \(f\) is holomorphic at \(\infty\) (has a Fourier expansion with no negative terms)
  • Fourier Expansion: A modular form has an expansion: \[f(z) = \sum_{n=0}^{\infty} a_n q^n, \quad q = e^{2\pi i z}\]
  • Cusp Form: A modular form with \(a_0 = 0\) (vanishes at \(\infty\)).

Theorem: Dimension Formula

Theorem: Let \(M_k\) denote the space of modular forms of weight \(k\) for \(\text{SL}_2(\mathbb{Z})\) and \(S_k\) the subspace of cusp forms. Then: \[\dim M_k = \begin{cases} \lfloor k/12 \rfloor & k \equiv 2 \pmod{12} \\ \lfloor k/12 \rfloor + 1 & k \not\equiv 2 \pmod{12} \end{cases}\] for even \(k \geq 0\), and \(\dim M_k = 0\) for odd \(k\) or \(k < 0\).

Moreover, \(\dim S_k = \dim M_k - 1\) for \(k \geq 4\), and \(S_k = 0\) for \(k < 12\).

Proof Sketch

Step 1 (Valence Formula): For a non-zero modular form \(f\) of weight \(k\): \[\text{ord}_{\infty}(f) + \frac{1}{2}\text{ord}_i(f) + \frac{1}{3}\text{ord}_{\omega}(f) + \sum_{P \in \text{SL}_2(\mathbb{Z}) \backslash \mathbb{H}}^{*} \text{ord}_P(f) = \frac{k}{12}\] where \(\omega = e^{2\pi i/3}\) and the sum is over non-elliptic points.

Step 2: The valence formula constrains the possible zeros of modular forms. For \(k < 0\), the right side is negative, but the left side is non-negative, so \(M_k = 0\).

Step 3: For weight \(k = 2\), the valence formula gives a contradiction (no non-zero forms exist).

Step 4: Construct explicit generators: the Eisenstein series \(E_4\) and \(E_6\) generate the ring of modular forms. The dimension formula follows from understanding the relations between products of these generators. ∎

Notation Guide

  • \(\mathbb{H}\): Upper half-plane
  • \(\text{SL}_2(\mathbb{Z})\): Special linear group over integers
  • \(M_k\): Space of modular forms of weight \(k\)
  • \(S_k\): Space of cusp forms of weight \(k\)
  • \(q = e^{2\pi i z}\): The uniformizing parameter
  • \(E_k\): Eisenstein series of weight \(k\)
  • \(\Delta\): The modular discriminant (cusp form of weight 12)

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import hsv_to_rgb

def eisenstein_series(k, z, terms=100):
    """
    Compute Eisenstein series E_k(z) = 1 - (2k/B_k) * sum_{n=1}^∞ σ_{k-1}(n) q^n
    where q = e^{2πiz} and B_k are Bernoulli numbers.
    """
    from fractions import Fraction
    
    # Bernoulli numbers B_4 = -1/30, B_6 = 1/42, etc.
    bernoulli = {4: Fraction(-1, 30), 6: Fraction(1, 42), 
                 8: Fraction(-1, 30), 10: Fraction(5, 66), 12: Fraction(-691, 2730)}
    
    if k not in bernoulli:
        raise ValueError(f"Eisenstein series E_{k} not implemented")
    
    B_k = bernoulli[k]
    q = np.exp(2j * np.pi * z)
    
    # Sum of divisors function σ_{k-1}(n)
    def sigma(n, power):
        total = 0
        for d in range(1, int(np.sqrt(n)) + 1):
            if n % d == 0:
                total += d**power
                if d != n // d:
                    total += (n // d)**power
        return total
    
    # Compute Fourier series
    result = 1.0
    coeff = -2 * k / float(B_k)
    
    for n in range(1, terms + 1):
        result += coeff * sigma(n, k - 1) * (q ** n)
    
    return result

def modular_j_invariant(z, terms=50):
    """
    Compute the modular j-invariant: j(z) = 1728 * E_4(z)^3 / (E_4(z)^3 - E_6(z)^2)
    """
    E4 = eisenstein_series(4, z, terms)
    E6 = eisenstein_series(6, z, terms)
    
    numerator = 1728 * E4**3
    denominator = E4**3 - E6**2
    
    return numerator / denominator

def plot_modular_form_domain(func, x_range=(-1, 1), y_range=(0.1, 2), 
                              resolution=200, title="Modular Form"):
    """
    Plot a modular form on the upper half-plane.
    """
    x = np.linspace(x_range[0], x_range[1], resolution)
    y = np.linspace(y_range[0], y_range[1], resolution)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j * Y
    
    # Compute function values
    W = np.zeros_like(Z, dtype=complex)
    for i in range(resolution):
        for j in range(resolution):
            try:
                W[i, j] = func(Z[i, j])
            except:
                W[i, j] = np.nan
    
    # Plot magnitude as brightness, phase as hue
    magnitude = np.abs(W)
    phase = np.angle(W) / (2 * np.pi) + 0.5  # Map to [0, 1]
    
    # Log scale for magnitude
    log_mag = np.log1p(magnitude)
    log_mag = log_mag / np.nanmax(log_mag)
    
    # Create HSV image
    HSV = np.zeros((resolution, resolution, 3))
    HSV[:, :, 0] = phase
    HSV[:, :, 1] = 1.0
    HSV[:, :, 2] = log_mag
    
    RGB = hsv_to_rgb(HSV)
    
    fig, ax = plt.subplots(figsize=(12, 8))
    ax.imshow(RGB, extent=[x_range[0], x_range[1], y_range[0], y_range[1]], 
              origin='lower', aspect='auto')
    ax.set_xlabel('Re(z)')
    ax.set_ylabel('Im(z)')
    ax.set_title(title)
    
    return fig, ax

3. Representation Theory: The Algebra of Symmetry

Motivation

Representation theory studies abstract algebraic structures by representing their elements as linear transformations of vector spaces. This approach transforms abstract symmetry groups into concrete matrices, making them amenable to computational techniques. Representation theory is fundamental to quantum mechanics, where it classifies particles according to their symmetry properties, and to harmonic analysis, where it underlies the Fourier transform. Modern applications include computer graphics, crystallography, and the study of molecular vibrations.

Definitions

Let \(G\) be a group and \(V\) a vector space over a field \(F\) (typically \(\mathbb{C}\)).

  • Representation: A homomorphism \(\rho: G \to \text{GL}(V)\), where \(\text{GL}(V)\) is the group of invertible linear transformations of \(V\). The dimension of the representation is \(\dim(V)\).
  • Character: The function \(\chi_\rho: G \to F\) defined by \(\chi_\rho(g) = \text{tr}(\rho(g))\), the trace of the linear transformation.
  • Irreducible Representation: A representation with no non-trivial proper subrepresentations (no invariant subspaces other than \(\{0\}\) and \(V\)).
  • Regular Representation: The representation of \(G\) on the group algebra \(F[G]\) by left multiplication.
  • Direct Sum: For representations \((\rho_1, V_1)\) and \((\rho_2, V_2)\), their direct sum is \(\rho_1 \oplus \rho_2: G \to \text{GL}(V_1 \oplus V_2)\).

Theorem: Maschke's Theorem

Theorem (Maschke, 1899): Let \(G\) be a finite group and \(F\) a field whose characteristic does not divide \(|G|\). Then every representation of \(G\) over \(F\) is completely reducible. That is, every representation decomposes as a direct sum of irreducible representations.

Proof

Step 1: Let \((\rho, V)\) be a representation and \(W \subseteq V\) a subrepresentation. We need to find a complementary invariant subspace \(W'\) such that \(V = W \oplus W'\).

Step 2: Choose any projection \(\pi: V \to W\) (a linear map with \(\pi|_W = \text{id}_W\)).

Step 3: Average over the group to make it equivariant: \[\tilde{\pi}(v) = \frac{1}{|G|} \sum_{g \in G} \rho(g)^{-1} \pi(\rho(g)v)\]

Step 4: Verify that \(\tilde{\pi}\) is a \(G\)-equivariant projection: \[\tilde{\pi}(\rho(h)v) = \frac{1}{|G|} \sum_{g \in G} \rho(g)^{-1} \pi(\rho(gh)v) = \rho(h) \tilde{\pi}(v)\]

Step 5: Define \(W' = \ker(\tilde{\pi})\). Then \(V = W \oplus W'\) and \(W'\) is \(G\)-invariant. ∎

Notation Guide

  • \(\rho\): Representation homomorphism
  • \(\chi_\rho\): Character of representation \(\rho\)
  • \(\text{GL}(V)\): General linear group of \(V\)
  • \(V^G\): Subspace of \(G\)-invariant vectors
  • \(\text{Hom}_G(V, W)\): Space of \(G\)-equivariant linear maps
  • \(\hat{G}\): Set of irreducible representations of \(G\)

import numpy as np
from itertools import permutations

class FiniteGroupRepresentation:
    """
    Representation of a finite group as permutation matrices.
    """
    
    def __init__(self, group_elements, representation_dict):
        """
        Args:
            group_elements: List of group elements
            representation_dict: Dict mapping g to matrix rho(g)
        """
        self.elements = group_elements
        self.rho = representation_dict
        self.dimension = list(representation_dict.values())[0].shape[0]
    
    def character(self, g):
        """Compute character chi(g) = tr(rho(g))."""
        return np.trace(self.rho[g])
    
    def character_table(self):
        """Compute the character table (for abelian groups)."""
        table = {}
        for g in self.elements:
            table[g] = self.character(g)
        return table
    
    def is_irreducible(self):
        """
        Check if representation is irreducible using Schur's orthogonality:
         = (1/|G|) * sum |chi(g)|^2 = 1 iff irreducible
        """
        inner_product = sum(abs(self.character(g))**2 for g in self.elements) / len(self.elements)
        return np.isclose(inner_product, 1.0)
    
    def decompose(self):
        """
        Attempt to find invariant subspaces (simplified for small cases).
        """
        # Find common eigenvectors of all representation matrices
        # This is a simplified approach
        matrices = [self.rho[g] for g in self.elements]
        
        # For 2D representations, check if there's a common eigenvector
        if self.dimension == 2:
            # Compute eigenvectors of first non-identity element
            for g in self.elements:
                if not np.allclose(self.rho[g], np.eye(2)):
                    eigvals, eigvecs = np.linalg.eig(self.rho[g])
                    # Check if eigenvectors are preserved by all group elements
                    for v in eigvecs.T:
                        is_invariant = True
                        for h in self.elements:
                            w = self.rho[h] @ v
                            if not np.isclose(np.linalg.norm(np.cross(v, w)), 0):
                                is_invariant = False
                                break
                        if is_invariant:
                            return "Reducible: found 1D invariant subspace"
                    break
        
        return "Appears irreducible (no obvious invariant subspaces found)"

def symmetric_group_s3_representation():
    """
    Create the standard 2-dimensional representation of S_3.
    """
    # S_3 has 6 elements: identity, 3 transpositions, 2 3-cycles
    # Standard representation: action on {(x,y,z) : x+y+z=0} in R^3
    
    # Basis: e1 = (1, -1, 0), e2 = (1, 1, -2) (orthogonal to (1,1,1))
    # Permutations act by permuting coordinates
    
    representations = {}
    
    # Identity
    representations['e'] = np.eye(2)
    
    # Transposition (12): swaps first two coordinates
    # In our basis: e1 -> -e1, e2 -> e2 + e1
    representations['(12)'] = np.array([[-1, 1], [0, 1]], dtype=float)
    
    # Transposition (13)
    representations['(13)'] = np.array([[0, -1], [-1, 0]], dtype=float)
    
    # Transposition (23)
    representations['(23)'] = np.array([[1, 0], [1, -1]], dtype=float)
    
    # 3-cycle (123)
    representations['(123)'] = np.array([[0, -1], [1, -1]], dtype=float)
    
    # 3-cycle (132)
    representations['(132)'] = np.array([[-1, 1], [-1, 0]], dtype=float)
    
    elements = ['e', '(12)', '(13)', '(23)', '(123)', '(132)']
    return FiniteGroupRepresentation(elements, representations)

def cyclic_group_representation(n):
    """
    Create the regular representation of cyclic group Z_n.
    """
    # Regular representation: n x n permutation matrices
    representations = {}
    
    for k in range(n):
        # k-th power of generator: shift by k positions
        perm = [(i + k) % n for i in range(n)]
        matrix = np.zeros((n, n))
        for i, j in enumerate(perm):
            matrix[i, j] = 1
        representations[k] = matrix
    
    elements = list(range(n))
    return FiniteGroupRepresentation(elements, representations)

1. Convex Optimization: Foundations and Algorithms

Motivation

Convex optimization is the cornerstone of modern applied mathematics, providing efficient algorithms for problems in machine learning, signal processing, control systems, and economics. The key insight is that convex problems have no local minima that are not global minima, enabling polynomial-time algorithms with strong theoretical guarantees. From training neural networks to portfolio optimization, convex optimization techniques power much of today's computational infrastructure.

Definitions

Let \(f: \mathbb{R}^n \to \mathbb{R}\) be a function and \(C \subseteq \mathbb{R}^n\) a set.

  • Convex Set: \(C\) is convex if for all \(x, y \in C\) and \(\theta \in [0, 1]\): \[\theta x + (1-\theta)y \in C\]
  • Convex Function: \(f\) is convex if its domain is convex and for all \(x, y\) in the domain and \(\theta \in [0, 1]\): \[f(\theta x + (1-\theta)y) \leq \theta f(x) + (1-\theta)f(y)\]
  • Convex Optimization Problem: \[\begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \leq 0, \quad i = 1, \ldots, m \\ & h_j(x) = 0, \quad j = 1, \ldots, p \end{aligned}\] where \(f_0, f_1, \ldots, f_m\) are convex and \(h_j\) are affine.
  • Lagrangian: \(\mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)\)
  • Dual Function: \(g(\lambda, \nu) = \inf_x \mathcal{L}(x, \lambda, \nu)\)

Theorem: Strong Duality

Theorem (Strong Duality): Consider a convex optimization problem where Slater's condition holds (there exists a strictly feasible point). Let \(p^*\) be the optimal primal value and \(d^*\) be the optimal dual value. Then: \[p^* = d^*\] and the dual optimum is attained.

Proof Sketch

Step 1 (Weak Duality): For any feasible \(x\) and \(\lambda \geq 0\): \[g(\lambda, \nu) \leq \mathcal{L}(x, \lambda, \nu) \leq f_0(x)\] Thus \(d^* \leq p^*\) always holds.

Step 2 (Separating Hyperplane): Define the set: \[\mathcal{A} = \{(u, v, t) : \exists x, f_i(x) \leq u_i, h_j(x) = v_j, f_0(x) \leq t\}\] This is convex by convexity of the constraint and objective functions.

Step 3: The point \((0, 0, p^*)\) is on the boundary of \(\mathcal{A}\). By the supporting hyperplane theorem, there exists a separating hyperplane.

Step 4: Under Slater's condition, this hyperplane must be non-vertical, giving dual variables \((\lambda^*, \nu^*)\) with \(g(\lambda^*, \nu^*) = p^*\). ∎

Notation Guide

  • \(\text{dom}(f)\): Domain of function \(f\)
  • \(\nabla f(x)\): Gradient of \(f\) at \(x\)
  • \(\partial f(x)\): Subdifferential of \(f\) at \(x\)
  • \(f^*\): Convex conjugate of \(f\)
  • \(\Pi_C(x)\): Projection of \(x\) onto convex set \(C\)
  • \(\text{prox}_f(x)\): Proximal operator of \(f\)

Python Code

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

class ConvexOptimization:
    """
    Demonstration of convex optimization algorithms.
    """
    
    @staticmethod
    def gradient_descent(f, grad_f, x0, step_size=0.1, max_iter=1000, tol=1e-6):
        """
        Gradient descent for unconstrained convex optimization.
        """
        x = x0.copy()
        trajectory = [x.copy()]
        values = [f(x)]
        
        for i in range(max_iter):
            gradient = grad_f(x)
            x_new = x - step_size * gradient
            
            trajectory.append(x_new.copy())
            values.append(f(x_new))
            
            if np.linalg.norm(x_new - x) < tol:
                break
            
            x = x_new
        
        return x, np.array(trajectory), values
    
    @staticmethod
    def newton_method(f, grad_f, hess_f, x0, max_iter=100, tol=1e-6):
        """
        Newton's method for unconstrained optimization.
        """
        x = x0.copy()
        trajectory = [x.copy()]
        values = [f(x)]
        
        for i in range(max_iter):
            gradient = grad_f(x)
            hessian = hess_f(x)
            d = np.linalg.solve(hessian, -gradient)
            x_new = x + d
            trajectory.append(x_new.copy())
            values.append(f(x_new))
            
            if np.linalg.norm(d) < tol:
                break
            
            x = x_new
        
        return x, np.array(trajectory), values

2. Graph Neural Networks: Learning on Structured Data

Motivation

Graph Neural Networks (GNNs) extend deep learning to graph-structured data, enabling applications in social network analysis, molecular property prediction, recommendation systems, and traffic forecasting. Unlike traditional neural networks that operate on regular grids (images) or sequences (text), GNNs handle irregular relational structures. The key insight is to propagate information between connected nodes, learning representations that capture both local neighborhood structure and global graph properties.

Definitions

Let \(G = (V, E)\) be a graph with node features \(X \in \mathbb{R}^{|V| \times d}\).

  • Graph Convolution: A layer that updates node representations by aggregating information from neighbors: \[H^{(l+1)} = \sigma(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}H^{(l)}W^{(l)})\]
  • Message Passing: A general framework where each node aggregates messages from neighbors.
  • Graph Attention: Uses attention mechanisms to learn which neighbors are most important.

Theorem: Universal Approximation on Graphs

Theorem (Maron et al., 2019): Graph neural networks with sufficient layers and width can approximate any continuous function on graphs that is invariant to node permutations.

import numpy as np
import networkx as nx

class GraphNeuralNetwork:
    """Simple Graph Convolutional Network (GCN) implementation."""
    
    def __init__(self, input_dim, hidden_dim, output_dim, num_layers=2):
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.output_dim = output_dim
        self.num_layers = num_layers
        
        # Initialize weights
        self.weights = []
        dims = [input_dim] + [hidden_dim] * (num_layers - 1) + [output_dim]
        for i in range(len(dims) - 1):
            W = np.random.randn(dims[i], dims[i+1]) * np.sqrt(2.0 / dims[i])
            self.weights.append(W)
    
    def normalize_adjacency(self, A):
        """Compute normalized adjacency: D^{-1/2} (A + I) D^{-1/2}"""
        A_tilde = A + np.eye(A.shape[0])
        D = np.sum(A_tilde, axis=1)
        D_inv_sqrt = np.diag(1.0 / np.sqrt(D + 1e-8))
        return D_inv_sqrt @ A_tilde @ D_inv_sqrt
    
    def relu(self, x):
        return np.maximum(0, x)
    
    def forward(self, X, A):
        """Forward pass through GCN."""
        A_norm = self.normalize_adjacency(A)
        H = X
        for i, W in enumerate(self.weights[:-1]):
            H = A_norm @ H @ W
            H = self.relu(H)
        H = A_norm @ H @ self.weights[-1]
        return H

3. Network Flow: Maximum Flow and Minimum Cut

Motivation

Network flow problems model the movement of resources through a network with capacity constraints. 📜 Math History: The Development of Modern Algebra

The 19th century witnessed a profound transformation in mathematics, as the discipline shifted from a science of quantity and magnitude to a study of abstract structures. This revolution, often called the "arithmetization of mathematics," began with the work of mathematicians like Gauss, Cauchy, and Abel, but reached its full flowering in the hands of Galois, Riemann, and Cantor.

Evariste Galois, the young French mathematician who died in a duel at age 20, laid the foundations of group theory in his study of polynomial equations. His insight was that the solvability of an equation could be determined by examining the structure of a group associated with its roots—the Galois group. This connection between field extensions and groups, now called the Galois correspondence, remains one of the most elegant results in mathematics.

Meanwhile, the development of non-Euclidean geometry by Bolyai, Lobachevsky, and Riemann shattered the long-held belief that Euclidean geometry was the only possible description of physical space. Riemann's generalization of geometry to arbitrary dimensions, with his concept of a manifold equipped with a metric tensor, provided the mathematical framework that Einstein would later use for general relativity.

The late 19th century saw the arithmetization of analysis, as Cauchy, Weierstrass, and Dedekind developed rigorous foundations for calculus based on the real number system. Dedekind's construction of real numbers as "Dedekind cuts" of rational numbers, and Cantor's theory of infinite sets and transfinite numbers, opened new realms of mathematical inquiry.

By the early 20th century, the stage was set for the development of modern abstract algebra. Emmy Noether's work on ring theory and ideal theory unified disparate results in algebraic number theory and algebraic geometry. Her abstract approach, emphasizing structural properties over computational techniques, became the dominant paradigm in 20th-century mathematics.

🧩 Problem Corner

Putnam 2022 Problem B5

Problem: Let \(n\) be a positive integer. A sequence \((a_1, a_2, \ldots, a_n)\) of integers is called good if:

  • \(1 \leq a_k \leq k\) for each \(k = 1, 2, \ldots, n\)
  • If \(i < j\) and \(a_i = a_j\), then \(a_i = a_{i+1} = \cdots = a_j\)

Find the number of good sequences of length \(n\).

Hint

Consider the positions where the value changes. How many times can the value change? What constraints does this impose?

Solution

The answer is the \(n\)-th Catalan number \(C_n = \frac{1}{n+1}\binom{2n}{n}\).

Proof: A good sequence can be characterized by the positions where the value increases. Let \(1 = i_1 < i_2 < \cdots < i_k \leq n\) be the positions where \(a_{i_j} = j\) (the first occurrence of each new value). The constraints imply that if \(a_i = j\), then \(i \geq j\), and the value can only increase by 1 at each change point.

This structure corresponds bijectively to Dyck paths of length \(2n\), which are counted by the Catalan numbers. Specifically, map a good sequence to a path where we take an up-step when the value increases and a down-step when we reach the last occurrence of a value. The constraint that \(a_k \leq k\) ensures the path never goes below the x-axis.

Therefore, the number of good sequences of length \(n\) is \(C_n\). ∎

📊 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous fractals in mathematics, defined as the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) starting from \(z_0 = 0\) remains bounded.

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute the number of iterations until escape."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter
