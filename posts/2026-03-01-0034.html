Riemann Surfaces: Complex Geometry in One Dimension

Motivation

Riemann surfaces are one-dimensional complex manifolds that provide the natural setting for studying multi-valued complex functions. They emerged from Riemann's investigation of algebraic functions and their integrals, unifying complex analysis, algebraic geometry, and topology. Every compact Riemann surface is an algebraic curve, establishing a profound bridge between analysis and algebra.

Definitions

Riemann Surface: A one-dimensional connected complex manifold \(X\). Equivalently, a Hausdorff space with a holomorphic atlas \(\{(U_i, \phi_i)\}\) where \(\phi_i: U_i \to \mathbb{C}\) are homeomorphisms onto open subsets with holomorphic transition functions.

Meromorphic Function: A holomorphic map \(f: X \to \mathbb{P}^1\) to the Riemann sphere. Locally, \(f = g/h\) where \(g, h\) are holomorphic.

Genus: For a compact Riemann surface, the genus \(g\) is the number of "holes" in the surface, given by \(g = \frac{1}{2}\dim H^1(X, \mathbb{C})\).

Divisor: A formal finite sum \(D = \sum_{p \in X} n_p \cdot p\) where \(n_p \in \mathbb{Z}\). The degree is \(\deg(D) = \sum n_p\).

Theorem and Proof

Riemann-Roch Theorem: Let \(X\) be a compact Riemann surface of genus \(g\) and \(D\) a divisor. Then: \[\ell(D) - \ell(K - D) = \deg(D) + 1 - g\] where \(\ell(D) = \dim H^0(X, \mathcal{O}_D)\) and \(K\) is a canonical divisor.

Proof Sketch: The proof proceeds in several stages. First, one establishes the existence of meromorphic functions with prescribed poles (Mittag-Leffler problem). The key insight is to consider the exact sequence of sheaves \(0 \to \mathcal{O}_D \to \mathcal{O}_{D+p} \to \mathbb{C}_p \to 0\) and analyze the resulting long exact sequence in cohomology. The dimension \(\ell(D)\) can only increase by at most 1 when adding a point to \(D\). By Serre duality, \(H^1(X, \mathcal{O}_D) \cong H^0(X, \Omega_{-D})^*\), which gives \(\ell(K-D) = h^1(D)\). Combining these yields the formula.

Notation Guide

  • \(\mathcal{O}_X\) — structure sheaf of holomorphic functions
  • \(\Omega_X\) — sheaf of holomorphic 1-forms
  • \(K = \text{div}(\omega)\) — canonical divisor (for any non-zero meromorphic 1-form \(\omega\))
  • \(g = h^0(X, \Omega_X)\) — genus
  • \(\chi(\mathcal{F}) = \sum (-1)^i h^i(X, \mathcal{F})\) — Euler characteristic

import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

class RiemannSurface:
    """Model of a Riemann surface (torus example)."""
    
    def __init__(self, tau=1j):
        """
        Initialize complex torus C/(Z + tau*Z).
        tau: period ratio in upper half-plane
        """
        self.tau = tau
        self.g = 1  # Genus of torus
    
    def weierstrass_p(self, z, g2, g3, terms=20):
        """
        Weierstrass p-function: doubly periodic meromorphic function.
        p(z) = 1/z^2 + sum_{w≠0} [1/(z-w)^2 - 1/w^2]
        """
        result = 1/z**2 if z != 0 else 0
        
        # Sum over lattice points
        for m in range(-terms, terms+1):
            for n in range(-terms, terms+1):
                if m == 0 and n == 0:
                    continue
                w = m + n * self.tau
                result += 1/(z-w)**2 - 1/w**2
        
        return result
    
    def holomorphic_forms(self):
        """Return basis of holomorphic 1-forms."""
        # On a torus, dz is the unique (up to scalar) holomorphic 1-form
        return ["dz"]
    
    def riemann_roch(self, D_degree):
        """Apply Riemann-Roch for divisor of given degree."""
        g = self.g
        deg_D = D_degree
        
        # Riemann-Roch: l(D) - l(K-D) = deg(D) + 1 - g
        # For torus (g=1): l(D) - l(K-D) = deg(D)
        
        if deg_D > 0:
            # l(K-D) = 0 when deg(D) > 2g-2 = 0
            l_D = deg_D  # l(D) = deg(D) for deg(D) > 0
            l_K_minus_D = 0
        elif deg_D == 0:
            l_D = 1  # Only constants
            l_K_minus_D = 1
        else:
            l_D = 0
            l_K_minus_D = -deg_D
        
        return l_D, l_K_minus_D

Spectral Sequences: Computational Machinery in Homological Algebra

Motivation

Spectral sequences are powerful computational tools in algebraic topology and homological algebra that allow one to compute complex derived functors by successive approximations. They arise naturally in situations where we have a filtered complex or a double complex, providing a systematic way to organize and compute cohomology.

Definitions

Homological Spectral Sequence: A collection \(\{E^r_{p,q}\}_{r \geq a}\) of abelian groups with differentials \(d^r: E^r_{p,q} \to E^r_{p-r, q+r-1}\) satisfying \(d^r \circ d^r = 0\) and isomorphisms \(E^{r+1}_{p,q} \cong H(E^r_{p,q})\).

Convergence: A spectral sequence converges to \(H_*\) (written \(E^r_{p,q} \Rightarrow H_{p+q}\)) if there exists a filtration \(F_p H_n\) such that \(E^\infty_{p,q} \cong F_p H_{p+q}/F_{p-1} H_{p+q}\).

Leray-Serre Spectral Sequence: For a fibration \(F \to E \to B\) with \(B\) simply connected, there is a spectral sequence with \(E^2_{p,q} = H_p(B; H_q(F)) \Rightarrow H_{p+q}(E)\).

Theorem and Proof

Leray-Serre Theorem: Let \(p: E \to B\) be a fibration with fiber \(F\). If \(B\) is path-connected and \(\pi_1(B)\) acts trivially on \(H_*(F)\), then there exists a first-quadrant homology spectral sequence with: \[E^2_{p,q} = H_p(B; H_q(F; G)) \Rightarrow H_{p+q}(E; G)\] The differential \(d^r\) has bidegree \((-r, r-1)\).

Proof Sketch: The proof constructs a filtration on the singular chain complex \(C_*(E)\) using the skeletal filtration of \(B\). For each cell \(e^p_\alpha\) in \(B\), consider the preimage \(p^{-1}(e^p_\alpha) \cong e^p_\alpha \times F\). This gives a filtration \(F_p C_*(E) = C_*(p^{-1}(B^{(p)}))\). The associated spectral sequence has the claimed \(E^2\) page by analyzing the local coefficient system.

Notation Guide

  • \(E^r_{p,q}\) — page \(r\), position \((p,q)\) (homological grading)
  • \(E_r^{p,q}\) — cohomological spectral sequence
  • \(d^r\) — differential on page \(r\)
  • \(E^\infty_{p,q}\) — limiting term
  • \(\Rightarrow\) — converges to

import numpy as np

class SpectralSequence:
    """
    Simplified model of a spectral sequence computation.
    Example: Leray-Serre for trivial fibration S^1 -> S^1 x S^1 -> S^1
    """
    
    def __init__(self, base_betti, fiber_betti):
        """
        Initialize with Betti numbers of base and fiber.
        """
        self.base = base_betti  # List of Betti numbers for base
        self.fiber = fiber_betti  # List of Betti numbers for fiber
        self.E2 = self._compute_E2()
    
    def _compute_E2(self):
        """Compute E^2 page: E^2_{p,q} = H_p(Base) ⊗ H_q(Fiber)"""
        max_p = len(self.base)
        max_q = len(self.fiber)
        E2 = np.zeros((max_p, max_q), dtype=int)
        
        for p in range(max_p):
            for q in range(max_q):
                E2[p, q] = self.base[p] * self.fiber[q]
        
        return E2
    
    def compute_total_betti(self):
        """Compute Betti numbers of total space from E^∞."""
        # For product: E^2 = E^∞ (spectral sequence collapses)
        max_n = len(self.base) + len(self.fiber) - 2
        total_betti = np.zeros(max_n + 1, dtype=int)
        
        for p in range(len(self.base)):
            for q in range(len(self.fiber)):
                n = p + q
                if n <= max_n:
                    total_betti[n] += self.E2[p, q]
        
        return total_betti

Class Field Theory: The Crown Jewel of Algebraic Number Theory

Motivation

Class field theory describes the abelian extensions of number fields and function fields. It provides a complete classification of abelian extensions in terms of intrinsic data of the base field, establishing a profound correspondence between Galois groups and generalized ideal class groups.

Definitions

Ray Class Group: For a modulus \(\mathfrak{m}\) (formal product of primes), the ray class group \(Cl_\mathfrak{m}(K)\) is the quotient of fractional ideals coprime to \(\mathfrak{m}\) by principal ideals generated by elements \(\alpha \equiv 1 \pmod{\mathfrak{m}}\).

Artin Map: For an abelian extension \(L/K\) unramified outside \(\mathfrak{m}\), the Artin map \(\psi_{L/K}: Cl_\mathfrak{m}(K) \to \text{Gal}(L/K)\) sends a prime ideal \(\mathfrak{p}\) to the Frobenius element \(\sigma_\mathfrak{p}\).

Hilbert Class Field: The maximal unramified abelian extension \(H\) of \(K\). Its Galois group is isomorphic to the ideal class group: \(\text{Gal}(H/K) \cong Cl(K)\).

Theorem and Proof

Artin Reciprocity Law: Let \(L/K\) be an abelian extension of number fields and \(\mathfrak{m}\) a modulus divisible by all ramified primes. Then the Artin map induces an isomorphism: \[Cl_\mathfrak{m}(K)/N(C_\mathfrak{m}(L)) \cong \text{Gal}(L/K)\] where \(N\) denotes the norm map on ideals.

Proof Sketch: The proof has two main parts. First, one shows that the Artin map is surjective (this follows from the Čebotarev density theorem). The difficult part is showing the kernel equals the norm group. This uses analytic methods: the proof considers \(L\)-functions \(L(s, \chi)\) for characters \(\chi\) of the ray class group and shows that \(L(1, \chi) \neq 0\) for non-principal characters. This non-vanishing implies the equality of Dirichlet densities, which forces the kernel to be exactly the norm group.

Notation Guide

  • \(\mathfrak{m} = \mathfrak{m}_0 \cdot \mathfrak{m}_\infty\) — modulus (finite and infinite parts)
  • \(I_\mathfrak{m}(K)\) — ideals coprime to \(\mathfrak{m}\)
  • \(P_\mathfrak{m}(K)\) — principal ideals with generator \(\equiv 1 \pmod{\mathfrak{m}}\)
  • \(\left(\frac{L/K}{\mathfrak{p}}\right)\) — Artin symbol (Frobenius at \(\mathfrak{p}\))
  • \(h_K = |Cl(K)|\) — class number

def reduced_binary_forms(d):
    """
    Find reduced binary quadratic forms of discriminant -d.
    Each form ax^2 + bxy + cy^2 with b^2 - 4ac = -d, |b| <= a <= c.

                if c >= a:  # |b| <= a <= c
                    # Check reduced condition
                    if b < 0 or a < c or b <= a:
                        forms.append((a, b, c))
    
    return forms

Markov Decision Processes and Reinforcement Learning

Real-World Motivation

Reinforcement learning powers breakthroughs in game playing (AlphaGo, AlphaZero), robotics, autonomous vehicles, and resource management. At its mathematical foundation lies the theory of Markov Decision Processes (MDPs), which provides a rigorous framework for sequential decision-making under uncertainty.

Definitions

Markov Decision Process: A tuple \((\mathcal{S}, \mathcal{A}, P, R, \gamma)\) where: \(\mathcal{S}\) is the state space, \(\mathcal{A}\) is the action space, \(P(s'|s,a)\) is the transition probability, \(R(s,a)\) is the reward function, and \(\gamma \in [0,1)\) is the discount factor.

Policy: A mapping \(\pi: \mathcal{S} \to \Delta(\mathcal{A})\) giving the probability of actions in each state.

Value Function: \(V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) \mid s_0 = s, \pi\right]\)

Q-Function: \(Q^\pi(s,a) = \mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) \mid s_0 = s, a_0 = a, \pi\right]\)

Theorem and Proof

Bellman Optimality Equation: The optimal value function \(V^*\) satisfies: \[V^*(s) = \max_{a \in \mathcal{A}} \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \right]\] Moreover, \(V^*\) is the unique solution to this equation.

Proof Sketch: The proof uses the contraction mapping theorem. Define the Bellman optimality operator \(\mathcal{T}: \mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}^{|\mathcal{S}|}\) by \((\mathcal{T}V)(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a)V(s')]\). One shows \(\|\mathcal{T}V - \mathcal{T}V'\|_\infty \leq \gamma \|V - V'\|_\infty\), so \(\mathcal{T}\) is a contraction. By the Banach fixed-point theorem, \(\mathcal{T}\) has a unique fixed point, which is \(V^*\).

Notation Guide

  • \(\mathcal{S}, \mathcal{A}\) — state and action spaces
  • \(P(s'|s,a)\) — transition probability
  • \(\gamma\) — discount factor
  • \(V^\pi, Q^\pi\) — value and action-value functions under policy \(\pi\)
  • \(\pi^*\) — optimal policy

import numpy as np

class MarkovDecisionProcess:
    """
    Markov Decision Process with value iteration.
    Example: Grid world navigation.
    """
    
    def __init__(self, n_states, n_actions, transition, reward, gamma=0.95):
        self.n_states = n_states
        self.n_actions = n_actions
        self.P = transition  # P[s, a, s'] = probability
        self.R = reward      # R[s, a] = expected reward
        self.gamma = gamma
        self.V = np.zeros(n_states)
        self.policy = np.zeros(n_states, dtype=int)
    
    def bellman_operator(self, V):
        """Apply Bellman optimality operator."""
        new_V = np.zeros(self.n_states)
        for s in range(self.n_states):
            action_values = np.zeros(self.n_actions)
            for a in range(self.n_actions):
                # Q(s,a) = R(s,a) + γ * sum_s' P(s'|s,a) * V(s')
                action_values[a] = self.R[s, a] + self.gamma * np.sum(
                    self.P[s, a, :] * V
                )
            new_V[s] = np.max(action_values)
        return new_V
    
    def value_iteration(self, epsilon=1e-6, max_iter=1000):
        """Solve for optimal value function."""
        for i in range(max_iter):
            V_new = self.bellman_operator(self.V)
            if np.max(np.abs(V_new - self.V)) < epsilon:
                print(f"Converged in {i+1} iterations")
                break
            self.V = V_new
        
        # Extract optimal policy
        for s in range(self.n_states):
            action_values = np.zeros(self.n_actions)
            for a in range(self.n_actions):
                action_values[a] = self.R[s, a] + self.gamma * np.sum(
                    self.P[s, a, :] * self.V
                )
            self.policy[s] = np.argmax(action_values)
        
        return self.V, self.policy

Computational Fluid Dynamics: Numerical Solutions of the Navier-Stokes Equations

Real-World Motivation

Computational Fluid Dynamics (CFD) is essential in aerospace design, weather prediction, biomedical engineering, and climate modeling. The Navier-Stokes equations describe fluid motion but are notoriously difficult to solve analytically. Numerical methods provide practical approximations for engineering applications.

Definitions

Incompressible Navier-Stokes: For velocity field \(\mathbf{u}\) and pressure \(p\): \[\frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u} + \mathbf{f}\] \[\nabla \cdot \mathbf{u} = 0\]

Reynolds Number: \(Re = \frac{UL}{\nu}\) — ratio of inertial to viscous forces. Determines flow regime (laminar vs. turbulent).

Vorticity: \(\boldsymbol{\omega} = \nabla \times \mathbf{u}\) — measures local rotation in the fluid.

Theorem and Proof

Energy Stability (2D Case): For 2D incompressible Navier-Stokes on a periodic domain with no forcing, the kinetic energy \(E(t) = \frac{1}{2}\int |\mathbf{u}|^2 \, d\mathbf{x}\) satisfies: \[\frac{dE}{dt} = -\nu \int |\nabla \mathbf{u}|^2 \, d\mathbf{x} \leq 0\]

Proof: Multiply the Navier-Stokes equation by \(\mathbf{u}\) and integrate. The nonlinear term vanishes due to incompressibility: \[\int \mathbf{u} \cdot [(\mathbf{u} \cdot \nabla)\mathbf{u}] = \frac{1}{2}\int \mathbf{u} \cdot \nabla(|\mathbf{u}|^2) = -\frac{1}{2}\int (\nabla \cdot \mathbf{u})|\mathbf{u}|^2 = 0\] The pressure term vanishes similarly. What remains is \(\frac{dE}{dt} = -\nu \|\nabla \mathbf{u}\|_{L^2}^2\).

Notation Guide

  • \(\mathbf{u} = (u, v, w)\) — velocity field
  • \(p\) — pressure
  • \(\rho\) — density
  • \(\nu = \mu/\rho\) — kinematic viscosity
  • \(\nabla \cdot \mathbf{u} = 0\) — incompressibility condition

import numpy as np
import matplotlib.pyplot as plt

class NavierStokes2D:
    """
    2D Incompressible Navier-Stokes solver using finite differences.
    Stream-function vorticity formulation.
    """
    
    def __init__(self, nx, ny, Lx, Ly, nu):
        self.nx, self.ny = nx, ny
        self.dx, self.dy = Lx/nx, Ly/ny
        self.nu = nu  # Kinematic viscosity
        
        # Grids
        self.x = np.linspace(0, Lx, nx)
        self.y = np.linspace(0, Ly, ny)
        self.X, self.Y = np.meshgrid(self.x, self.y)
        
        # Vorticity and stream function
        self.omega = np.zeros((ny, nx))
        self.psi = np.zeros((ny, nx))
    
    def laplacian(self, f):
        """5-point Laplacian stencil."""
        return ((np.roll(f, -1, axis=1) - 2*f + np.roll(f, 1, axis=1)) / self.dx**2 +
                (np.roll(f, -1, axis=0) - 2*f + np.roll(f, 1, axis=0)) / self.dy**2)
    
    def poisson_solver(self, f, tol=1e-6, max_iter=1000):
        """Solve ∇²ψ = -ω using Jacobi iteration."""
        psi = self.psi.copy()
        for _ in range(max_iter):
            psi_new = 0.25 * (np.roll(psi, -1, axis=1) + np.roll(psi, 1, axis=1) +
                              np.roll(psi, -1, axis=0) + np.roll(psi, 1, axis=0) +
                              self.dx**2 * f)
            if np.max(np.abs(psi_new - psi)) < tol:
                break
            psi = psi_new
        return psi
    
    def vorticity_advection(self):
        """Compute advection term using centered differences."""
        # Velocity from stream function: u = ∂ψ/∂y, v = -∂ψ/∂x
        u = (np.roll(self.psi, -1, axis=0) - np.roll(self.psi, 1, axis=0)) / (2*self.dy)
        v = -(np.roll(self.psi, -1, axis=1) - np.roll(self.psi, 1, axis=1)) / (2*self.dx)
        
        # Advection: u·∇ω
        domega_dx = (np.roll(self.omega, -1, axis=1) - np.roll(self.omega, 1, axis=1)) / (2*self.dx)
        domega_dy = (np.roll(self.omega, -1, axis=0) - np.roll(self.omega, 1, axis=0)) / (2*self.dy)
        
        return u * domega_dx + v * domega_dy
    
    def step(self, dt):
        """Time step using forward Euler."""
        # Update vorticity
        advection = self.vorticity_advection()
        diffusion = self.nu * self.laplacian(self.omega)
        self.omega += dt * (-advection + diffusion)
        
        # Solve for stream function
        self.psi = self.poisson_solver(-self.omega)
    
    def velocity_field(self):
        """Compute velocity from stream function."""
        u = (np.roll(self.psi, -1, axis=0) - np.roll(self.psi, 1, axis=0)) / (2*self.dy)
        v = -(np.roll(self.psi, -1, axis=1) - np.roll(self.psi, 1, axis=1)) / (2*self.dx)
        return u, v

Reaction-Diffusion Systems and Pattern Formation

Real-World Motivation

Reaction-diffusion systems explain how patterns emerge in biological systems: animal coat markings, morphogenesis in development, and chemical oscillations. Alan Turing's 1952 paper "The Chemical Basis of Morphogenesis" showed that diffusion can destabilize uniform states and create spatial patterns — a counterintuitive result now central to mathematical biology.

Definitions

Reaction-Diffusion System: A system of PDEs of the form: \[\frac{\partial u}{\partial t} = D_u \nabla^2 u + f(u, v)\] \[\frac{\partial v}{\partial t} = D_v \nabla^2 v + g(u, v)\]

Turing Instability: A homogeneous steady state that is stable to homogeneous perturbations but unstable to certain spatial perturbations, leading to pattern formation.

Activator-Inhibitor: A system where one chemical promotes its own production and that of an inhibitor, which suppresses the activator.

Theorem and Proof

Turing's Instability Criterion: Consider a 2-component reaction-diffusion system with linearized reaction terms at a stable homogeneous steady state \((u_0, v_0)\). Define the Jacobian \(J\) and diffusion ratio \(d = D_v/D_u\). If \(\text{tr}(J) < 0\), \(\det(J) > 0\) (steady state stable), and: \[d \cdot f_u + g_v > 2\sqrt{d \cdot \det(J)}\] then there exist wave numbers \(k\) for which the steady state is unstable to spatial perturbations.

Proof Sketch: Linearize around \((u_0, v_0)\) and look for solutions of the form \(\mathbf{w}(\mathbf{x}, t) = \mathbf{w}_0 e^{\lambda t} e^{i\mathbf{k} \cdot \mathbf{x}}\). The growth rate \(\lambda\) satisfies a characteristic equation. For instability, we need \(\text{Re}(\lambda) > 0\) for some \(k\). The condition ensures the diffusion term can overcome the stabilizing reaction terms at intermediate wavelengths.

Notation Guide

  • \(u, v\) — concentrations of morphogens
  • \(D_u, D_v\) — diffusion coefficients
  • \(f, g\) — reaction kinetics
  • \(J = \begin{pmatrix} f_u & f_v \\ g_u & g_v \end{pmatrix}\) — Jacobian matrix
  • \(k\) — wave number of perturbation

        self.V += dt * dV

        self.U = np.clip(self.U, 0, 1)
        self.V = np.clip(self.V, 0, 1)

Mirror Symmetry: When Two Calabi-Yau Manifolds are "The Same"

Historical Context

Mirror symmetry emerged from string theory in the late 1980s when physicists noticed that Calabi-Yau manifolds come in pairs with "mirrored" properties. The phenomenon was formalized mathematically by Candelas, de la Ossa, Green, and Parkes in 1991, who used mirror symmetry to predict the number of rational curves on the quintic threefold — a prediction later verified mathematically.

Definitions

Calabi-Yau Manifold: A compact Kähler manifold \(X\) with trivial canonical bundle \(K_X \cong \mathcal{O}_X\) and \(H^i(X, \mathcal{O}_X) = 0\) for \(0 < i < \dim(X)\).

Hodge Numbers: \(h^{p,q}(X) = \dim H^q(X, \Omega_X^p)\). For a Calabi-Yau threefold, the Hodge diamond has \(h^{1,1}\) and \(h^{2,1}\) as independent parameters.

Mirror Pair: Calabi-Yau manifolds \(X\) and \(X^\vee\) are mirrors if \(h^{p,q}(X) = h^{3-p,q}(X^\vee)\). In particular, \(h^{1,1}(X) = h^{2,1}(X^\vee)\) and vice versa.

Theorem and Proof

Mirror Symmetry (Hodge Diamond Exchange): For a mirror pair of Calabi-Yau threefolds \((X, X^\vee)\), the Yukawa couplings on the complex moduli of \(X\) equal the Yukawa couplings on the Kähler moduli of \(X^\vee\).

Proof Sketch: The proof uses variations of Hodge structure. On the complex moduli of \(X\), the period integrals satisfy the Picard-Fuchs equations. The mirror map transforms these into the genus-zero Gromov-Witten invariants on \(X^\vee\). The key is the equality: \[\int_X \Omega \wedge \partial_{z_i} \partial_{z_j} \partial_{z_k} \Omega = \sum_{d} n_d \frac{q^d}{1 - q^d}\] where \(n_d\) are the Gopakumar-Vafa invariants (counting curves).

Notation Guide

  • \(h^{p,q}\) — Hodge numbers
  • \(\Omega\) — holomorphic volume form
  • \(\mathcal{M}_{cx}(X)\) — complex structure moduli
  • \(\mathcal{M}_{Käh}(X)\) — Kähler moduli
  • \(n_d\) — genus-zero BPS invariants

Motivic Integration: Geometric Integration Without Numbers

Historical Context

Motivic integration was introduced by Maxim Kontsevich in 1995 to prove that birationally equivalent Calabi-Yau manifolds have the same Hodge numbers. The theory was developed by Denef, Loeser, and others into a powerful tool for singularity theory, the Langlands program, and birational geometry.

Definitions

Arc Space: For a variety \(X\), the arc space \(\mathcal{L}(X)\) parametrizes germs of curves on \(X\). Formally, \(\mathcal{L}(X)(R) = X(R[[t]])\) for any ring \(R\).

Motivic Measure: A measure \(\mu\) on \(\mathcal{L}(X)\) taking values in the Grothendieck ring of varieties \(K_0(\text{Var}_k)[\mathbb{L}^{-1}]\), where \(\mathbb{L} = [\mathbb{A}^1]\).

Grothendieck Ring of Varieties: The free abelian group on isomorphism classes of varieties modulo the scissor relation \([X] = [U] + [Z]\) for closed \(Z \subset X\) with complement \(U\).

Theorem and Proof

Birational Invariance (Kontsevich): Let \(X\) and \(Y\) be smooth projective varieties that are birationally equivalent and have trivial canonical bundles. Then \([X] = [Y]\) in a suitable localization of the Grothendieck ring, implying they have the same Hodge numbers.

Proof Sketch: By the Weak Factorization Theorem, any birational map factors as a sequence of blow-ups and blow-downs with smooth centers. For a blow-up \(f: \tilde{X} \to X\) with center \(Z\) and exceptional divisor \(E\), one shows that the motivic measures of the arc spaces agree: \(\mu(\mathcal{L}(\tilde{X})) = \mu(\mathcal{L}(X))\). This follows from the change of variables formula in motivic integration, which relates the measures via the order of the Jacobian.

Notation Guide

  • \(\mathcal{L}_n(X)\) — space of n-jets (truncated arcs)
  • \(\mathcal{L}(X)\) — arc space (inverse limit of \(\mathcal{L}_n(X)\))
  • \(K_0(\text{Var}_k)\) — Grothendieck ring of varieties
  • \(\mathbb{L}\) — class of the affine line \([\mathbb{A}^1]\)
  • \(\text{ord}_t \omega\) — order of vanishing of a differential form

Higher Topos Theory: Sheaves in Homotopical Context

Historical Context

Higher topos theory, developed primarily by Jacob Lurie in the 2000s, extends the theory of Grothendieck toposes to the homotopical setting. While ordinary toposes encode intuitionistic logic and sheaf theory, \(\infty\)-toposes provide the natural setting for homotopy-coherent mathematics, higher stacks, and derived algebraic geometry.

Definitions

\(\infty\)-Category: A simplicial set satisfying the weak Kan condition (inner horns have fillers). Morphisms can be composed up to coherent homotopy.

\(\infty\)-Topos: An \(\infty\)-category that is an accessible left exact localization of a presheaf \(\infty\)-category \(PSh(\mathcal{C})\). Equivalently, it satisfies Giraud's axioms (in the \(\infty\)-categorical sense).

Object Classifier: In an \(\infty\)-topos \(\mathcal{X}\), there exists a universal object \(\mathcal{O}_\mathcal{X}\) such that objects of \(\mathcal{X}\) correspond to maps into \(\mathcal{O}_\mathcal{X}\).

Theorem and Proof

Giraud's Theorem for \(\infty\)-Topoi: An \(\infty\)-category \(\mathcal{X}\) is an \(\infty\)-topos if and only if it satisfies: 1. \(\mathcal{X}\) is presentable 2. Colimits are universal (pullback preserves colimits) 3. Coproducts are disjoint 4. Every groupoid object is effective (Čech descent)

Proof Sketch: The proof follows the classical case but requires careful homotopical analysis. The key insight is that condition (4) ensures that \(\mathcal{X}\) has "enough sheaves" — any object can be built from its cover via homotopy colimits. One constructs a site \(\mathcal{C}\) and shows that \(\mathcal{X}\) is equivalent to sheaves on \(\mathcal{C}\) with values in spaces (\(\infty\)-groupoids).

Notation Guide

  • \(\mathcal{S}\) — \(\infty\)-category of spaces (\(\infty\)-groupoids)
  • \(PSh(\mathcal{C}) = \text{Fun}(\mathcal{C}^{op}, \mathcal{S})\) — presheaf \(\infty\)-category
  • \(Sh(\mathcal{C})\) — sheaf \(\infty\)-category
  • \(\tau_{\leq n}\) — n-truncation functor
  • \(\text{Disc}(\mathcal{X})\) — discrete objects (0-truncated)

The Weil Conjectures: From Zeta Functions to Cohomology

Historical Context

In 1949, André Weil proposed a series of conjectures about the number of points on algebraic varieties over finite fields. These conjectures suggested a profound analogy between the arithmetic of varieties over finite fields and the topology of complex manifolds. The conjectures were proved by Dwork (rationality), Grothendieck (functional equation), and Deligne (Riemann hypothesis), revolutionizing algebraic geometry.

Definitions

Zeta Function: For a variety \(X\) over \(\mathbb{F}_q\): \[Z(X, t) = \exp\left(\sum_{m=1}^\infty \frac{\#X(\mathbb{F}_{q^m})}{m} t^m\right) = \prod_{x \in |X|} \frac{1}{1 - t^{\deg(x)}}\]

Frobenius Endomorphism: The map \(F: X \to X\) raising coordinates to the \(q\)-th power. Fixed points of \(F^m\) are exactly \(X(\mathbb{F}_{q^m})\).

Weil Cohomology: A cohomology theory for varieties over finite fields with properties analogous to singular cohomology: Poincaré duality, Künneth formula, cycle class map.

Theorem and Proof

Weil Conjectures (Deligne's Theorem, 1974): Let \(X\) be a smooth projective variety of dimension \(n\) over \(\mathbb{F}_q\). Then: 1. \(Z(X, t)\) is a rational function 2. \(Z(X, q^{-n}t^{-1}) = \pm q^{nE/2} t^E Z(X, t)\) where \(E\) is the Euler characteristic 3. \(Z(X, t) = \frac{P_1(t) P_3(t) \cdots P_{2n-1}(t)}{P_0(t) P_2(t) \cdots P_{2n}(t)}\) with \(P_i(t) = \prod_j (1 - \alpha_{ij}t)\) 4. \(|\alpha_{ij}| = q^{i/2}\) (Riemann hypothesis analog)

Proof Sketch: Grothendieck developed étale cohomology \(H^i_{\acute{e}t}(X, \mathbb{Q}_\ell)\) to provide the necessary cohomological framework. The Lefschetz trace formula gives \(\#X(\mathbb{F}_{q^m}) = \sum_{i=0}^{2n} (-1)^i \text{tr}(F^m | H^i_{\acute{e}t})\). Deligne's proof of the Riemann hypothesis uses deep results on monodromy, the Hard Lefschetz theorem, and estimates on exponential sums. The key is to show that the eigenvalues of Frobenius have the expected absolute value.

Notation Guide

  • \(\#X(\mathbb{F}_{q^m})\) — number of points over \(\mathbb{F}_{q^m}\)
  • \(F\) — Frobenius endomorphism
  • \(H^i_{\acute{e}t}(X, \mathbb{Q}_\ell)\) — \(\ell\)-adic étale cohomology
  • \(P_i(t) = \det(1 - tF | H^i_{\acute{e}t})\) — characteristic polynomial
  • \(\alpha_{ij}\) — eigenvalues of Frobenius

    Examples with elliptic curves and projective spaces.
    """
    
    def __init__(self, q):
        self.q = q  # Size of finite field
    
    def zeta_projective_space(self, n):
        """
        Zeta function of P^n over F_q.
        Z(P^n, t) = 1 / ((1-t)(1-qt)...(1-q^n t))
        """
        return f"1 / ∏_{{i=0}}^{n} (1 - q^{{i}} t)"
    
    def point_count_projective_space(self, n, m):
        """Number of F_{q^m}-points of P^n."""
        qm = self.q**m
        return sum(qm**i for i in range(n+1))
    
    def weil_polynomial_elliptic(self, a):
        """
        Weil polynomial for elliptic curve with trace a.
        P(T) = T^2 - aT + q
        """
        discriminant = a**2 - 4*self.q
        if discriminant >= 0:
            alpha1 = (a + np.sqrt(discriminant)) / 2
            alpha2 = (a - np.sqrt(discriminant)) / 2
        else:
            alpha1 = (a + 1j*np.sqrt(-discriminant)) / 2
            alpha2 = (a - 1j*np.sqrt(-discriminant)) / 2
        return alpha1, alpha2
    
    def verify_riemann_hypothesis(self, a):
        """Verify |α| = √q for elliptic curve."""
        alpha1, alpha2 = self.weil_polynomial_elliptic(a)
        abs1, abs2 = np.abs(alpha1), np.abs(alpha2)
        sqrt_q = np.sqrt(self.q)
        return np.isclose(abs1, sqrt_q) and np.isclose(abs2, sqrt_q)

📜 Math History: The Development of Category Theory

The emergence of category theory in the mid-twentieth century represents one of the most significant shifts in mathematical thinking since the development of set theory. What began as a language for organizing algebraic topology gradually evolved into a foundational framework that transcends individual mathematical disciplines.

The story begins in 1942-1945 when Samuel Eilenberg and Saunders Mac Lane, working at the intersection of algebraic topology and abstract algebra, introduced the basic concepts of categories, functors, and natural transformations. Their immediate motivation was to give precise meaning to the notion of "natural" isomorphisms in algebraic topology — a term that mathematicians had used intuitively but never rigorously defined.

The Eilenberg-Mac Lane collaboration produced two landmark papers. The first, "General Theory of Natural Equivalences" (1945), laid the categorical foundations. The second, on group extensions and cohomology, introduced what we now call \(\text{Ext}\) and \(\text{Tor}\) functors, demonstrating the computational power of the new language.

Initially, many mathematicians viewed category theory as merely a convenient language — "abstract nonsense" in the affectionate terminology of the field. However, the 1950s and 1960s saw the development of abelian categories (Buchsbaum, Grothendieck), sheaf theory, and topos theory, revealing that categories were not just organizational tools but carried substantial mathematical content.

Alexander Grothendieck's work revolutionized algebraic geometry through the categorical perspective. His Tôhoku paper (1957) established homological algebra in abelian categories, while his later work introduced schemes, topoi, and the six-functor formalism. The categorical viewpoint allowed Grothendieck to unify number theory, algebraic geometry, and complex analysis in ways previously unimaginable.

William Lawvere's 1963 Ph.D. thesis took category theory in a new direction by providing an elementary axiomatization of the category of sets. This led to topos theory, which showed that categories could serve as alternative foundations for mathematics, with internal logic that could be intuitionistic rather than classical.

By the turn of the millennium, higher category theory emerged, extending categorical thinking to homotopy-coherent structures. The work of Baez, Dolan, Lurie, and others showed that \(\infty\)-categories provide the natural language for modern algebraic topology, derived algebraic geometry, and mathematical physics.

Today, category theory permeates mathematics: representation theory, algebraic geometry, logic, computer science, and even aspects of mathematical physics all employ categorical methods. What began as a technical tool for algebraic topology has become a universal language for structural mathematics.

Putnam 2024 Problem B6

Let \(n\) be a positive integer. A function \(f: \{0, 1\}^n \to \{0, 1\}^n\) is called balanced if for every \(y \in \{0, 1\}^n\), the preimage \(f^{-1}(y)\) has exactly \(2^n / 2^n = 1\) element (i.e., \(f\) is a bijection).

A function is called linear if there exists an \(n \times n\) matrix \(A\) over \(\mathbb{F}_2\) and a vector \(b \in \{0, 1\}^n\) such that \(f(x) = Ax + b\) for all \(x\).

Determine the number of balanced linear functions \(f: \{0, 1\}^n \to \{0, 1\}^n\).

💡 Hint

A linear function \(f(x) = Ax + b\) is a bijection if and only if \(A\) is invertible. Count the number of invertible \(n \times n\) matrices over \(\mathbb{F}_2\) and multiply by the number of choices for \(b\).

✅ Solution

The answer is \(\boxed{2^n \cdot \prod_{k=0}^{n-1} (2^n - 2^k)}\).

Explanation:

For \(f(x) = Ax + b\) to be a bijection, \(A\) must be invertible over \(\mathbb{F}_2\).

The number of invertible \(n \times n\) matrices over \(\mathbb{F}_2\) is: \[|GL_n(\mathbb{F}_2)| = \prod_{k=0}^{n-1} (2^n - 2^k)\]

This counts ordered bases: first column can be any non-zero vector (\(2^n - 1\) choices), second column any vector not in the span of the first (\(2^n - 2\) choices), etc.

For each invertible \(A\), there are \(2^n\) choices for \(b\).

For \(n = 1\): \(2 \cdot (2-1) = 2\) functions (identity and flip).

For \(n = 2\): \(4 \cdot (4-1)(4-2) = 4 \cdot 6 = 24\) functions.

🎨 Visualization of the Day: Julia Sets

Julia sets are fractal boundaries associated with complex dynamical systems. For each complex parameter \(c\), the filled Julia set \(K_c\) consists of points in the complex plane whose orbits under \(f_c(z) = z^2 + c\) remain bounded. The boundary of \(K_c\) forms the Julia set \(J_c\).

The Mandelbrot set catalogs which Julia sets are connected: \(c\) is in the Mandelbrot set if and only if \(J_c\) is connected. This creates a beautiful dictionary between the parameter space (Mandelbrot) and dynamical spaces (Julia sets).

Python Code

import numpy as np
import matplotlib.pyplot as plt

def julia_set(c, xlim=(-2, 2), ylim=(-2, 2), width=800, height=800, max_iter=100):
    """
    Compute the Julia set for parameter c.
    Returns an array of iteration counts.
    """
    x = np.linspace(xlim[0], xlim[1], width)
    y = np.linspace(ylim[0], ylim[1], height)
    X, Y = np.meshgrid(x, y)
    Z = X + 1j*Y
    
    # Iteration count
    M = np.zeros(Z.shape, dtype=int)
    mask = np.ones(Z.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + c
        mask_new = np.abs(Z) <= 2
        M[~mask_new & (M == 0)] = i
        mask = mask_new
    
    M[mask] = max_iter
    return M

    Rough estimate of box-counting dimension.
