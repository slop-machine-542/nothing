1. Measure Theory: The Foundations of Modern Integration

Motivation

The Riemann integral, while adequate for continuous functions, fails to handle limits of functions properly and cannot integrate many functions that arise naturally in analysis and probability. Henri Lebesgue revolutionized integration theory in 1902 by introducing measure theory, which provides a framework for integration that is complete (all Cauchy sequences converge) and handles limits gracefully. Measure theory has become essential in probability theory, functional analysis, and the study of partial differential equations.

Definitions

Let \(X\) be a set and \(\mathcal{P}(X)\) its power set.

  • \(\sigma\)-algebra: A collection \(\mathcal{M} \subseteq \mathcal{P}(X)\) containing \(X\), closed under complements, and closed under countable unions.
  • Measurable Space: A pair \((X, \mathcal{M})\) where \(\mathcal{M}\) is a \(\sigma\)-algebra.
  • Measure: A function \(\mu: \mathcal{M} \to [0, \infty]\) with \(\mu(\emptyset) = 0\) and countable additivity: for disjoint \(\{E_n\}\): \[\mu\left(\bigcup_{n=1}^{\infty} E_n\right) = \sum_{n=1}^{\infty} \mu(E_n)\]
  • Measure Space: A triple \((X, \mathcal{M}, \mu)\).
  • Measurable Function: \(f: X \to \mathbb{R}\) such that \(f^{-1}(B) \in \mathcal{M}\) for all Borel sets \(B\).

Theorem: Monotone Convergence Theorem

Theorem: Let \((X, \mathcal{M}, \mu)\) be a measure space and \(\{f_n\}\) a sequence of measurable functions such that:

  1. \(0 \leq f_1(x) \leq f_2(x) \leq \cdots\) for almost every \(x \in X\)
  2. \(f_n(x) \to f(x)\) pointwise almost everywhere

Then \(f\) is measurable and: \[\lim_{n \to \infty} \int_X f_n \, d\mu = \int_X f \, d\mu\]

Proof

Step 1: Since each \(f_n\) is measurable and the pointwise limit of measurable functions is measurable, \(f\) is measurable.

Step 2: By monotonicity of the integral, \(\int f_n \leq \int f_{n+1} \leq \int f\) for all \(n\). Thus \(\lim_{n \to \infty} \int f_n \leq \int f\).

Step 3: For the reverse inequality, let \(s\) be a simple function with \(0 \leq s \leq f\) and let \(0 < \alpha < 1\). Define: \[E_n = \{x : f_n(x) \geq \alpha s(x)\}\]

Step 4: Since \(f_n \uparrow f\) and \(\alpha s < f\) whenever \(s > 0\), we have \(E_n \uparrow X\). By continuity of measure: \[\int_{E_n} \alpha s \, d\mu \to \int_X \alpha s \, d\mu = \alpha \int_X s \, d\mu\]

Step 5: Since \(\int f_n \geq \int_{E_n} f_n \geq \int_{E_n} \alpha s\), taking limits gives: \[\lim_{n \to \infty} \int f_n \geq \alpha \int s\]

Step 6: Letting \(\alpha \to 1\) and taking supremum over all simple \(s \leq f\): \[\lim_{n \to \infty} \int f_n \geq \int f\]

Combining with Step 2 yields equality. ∎

Notation Guide

  • \(\mathcal{M}\): \(\sigma\)-algebra of measurable sets
  • \(\mu\): Measure function
  • \(\int_X f \, d\mu\): Lebesgue integral of \(f\)
  • \(L^1(X, \mu)\): Space of integrable functions
  • a.e.: Almost everywhere (except on a set of measure zero)

class SimpleMeasureSpace:
    """
    Demonstration of measure-theoretic concepts on a finite set.
    """
    
    def __init__(self, X):
        """
        Initialize with a finite set X.
        
        Args:
            X: List of elements (the underlying set)
        """
        self.X = set(X)
        # Power set as sigma-algebra
        self.sigma_algebra = self._power_set()
    
    def _power_set(self):
        """Generate power set of X."""
        from itertools import chain, combinations
        return list(chain.from_iterable(
            combinations(self.X, r) for r in range(len(self.X) + 1)
        ))
    
    def counting_measure(self, E):
        """Counting measure: mu(E) = |E|."""
        return len(E)
    
    def dirac_measure(self, E, x0):
        """Dirac measure at x0: mu(E) = 1 if x0 in E, else 0."""
        return 1 if x0 in E else 0
    
    def simple_integral(self, f, measure_type='counting', x0=None):
        """
        Compute integral of f with respect to simple measure.
        
        Args:
            f: Dictionary mapping elements to values
            measure_type: 'counting' or 'dirac'
            x0: Point for Dirac measure
        """
        total = 0
        for x in self.X:
            if measure_type == 'counting':
                # Integral is sum of f(x) over X
                total += f.get(x, 0)
            elif measure_type == 'dirac':
                # Integral is f(x0)
                if x == x0:
                    total = f.get(x, 0)
                    break
        return total
    
    def demonstrate_monotone_convergence(self):
        """Demonstrate monotone convergence with a sequence."""
        X = list(self.X)
        n_points = len(X)
        
        # Define increasing sequence of functions
        def f_n(x, n):
            return min(x, n) / n_points
        
        def f(x):
            return x / n_points
        
        integrals = []
        for n in range(1, n_points + 1):
            integral = sum(f_n(x, n) for x in X)
            integrals.append(integral)
        
        limit_integral = sum(f(x) for x in X)
        
        print("Monotone Convergence Demonstration")
        print("=" * 50)
        for i, int_val in enumerate(integrals, 1):
            print(f"∫ f_{i} dμ = {int_val:.4f}")
        print(f"∫ f dμ = {limit_integral:.4f}")
        print(f"Limit of integrals equals integral of limit: {np.isclose(integrals[-1], limit_integral)}")
        
        return integrals, limit_integral

2. Complex Analysis: The Residue Theorem and Contour Integration

Motivation

Complex analysis, the study of functions of a complex variable, reveals profound connections between algebra, geometry, and analysis. The residue theorem, discovered by Cauchy in the 19th century, provides a powerful method for evaluating real integrals that are difficult or impossible to compute by elementary methods. Applications range from evaluating definite integrals and infinite series to solving problems in physics and engineering.

Definitions

Let \(U \subseteq \mathbb{C}\) be an open set and \(f: U \to \mathbb{C}\) be holomorphic except at isolated singularities.

  • Holomorphic: \(f\) is complex differentiable at every point of \(U\).
  • Isolated Singularity: A point \(z_0\) where \(f\) is not defined but is holomorphic in some punctured neighborhood \(0 < |z - z_0| < r\).
  • Residue: For \(f\) with Laurent series \(f(z) = \sum_{n=-\infty}^{\infty} a_n (z - z_0)^n\), the residue at \(z_0\) is: \[\text{Res}(f, z_0) = a_{-1} = \frac{1}{2\pi i} \oint_{|z-z_0|=r} f(z) \, dz\]
  • Meromorphic: Holomorphic except at isolated poles.
  • Winding Number: For a closed curve \(\gamma\) and point \(z_0\) not on \(\gamma\): \[n(\gamma, z_0) = \frac{1}{2\pi i} \oint_{\gamma} \frac{dz}{z - z_0}\]

Theorem: The Residue Theorem

Theorem: Let \(U \subseteq \mathbb{C}\) be simply connected, and let \(f\) be meromorphic in \(U\) with isolated singularities at \(z_1, z_2, \ldots, z_n\). Let \(\gamma\) be a positively oriented, piecewise smooth, simple closed curve in \(U\) enclosing \(z_1, \ldots, z_n\). Then: \[\oint_{\gamma} f(z) \, dz = 2\pi i \sum_{k=1}^{n} \text{Res}(f, z_k)\]

Proof Sketch

Step 1: By the deformation theorem, we can replace \(\gamma\) with small circles \(\gamma_k\) around each singularity \(z_k\), connected by line segments that cancel in pairs.

Step 2: For each \(k\), consider the Laurent expansion of \(f\) around \(z_k\): \[f(z) = \sum_{n=-\infty}^{\infty} a_n^{(k)} (z - z_k)^n\]

Step 3: Integrate term by term around \(\gamma_k\). For \(n \neq -1\): \[\oint_{\gamma_k} (z - z_k)^n \, dz = 0\] since \((z - z_k)^n\) has an antiderivative.

Step 4: For \(n = -1\): \[\oint_{\gamma_k} \frac{dz}{z - z_k} = 2\pi i\]

Step 5: Therefore: \[\oint_{\gamma_k} f(z) \, dz = 2\pi i \cdot a_{-1}^{(k)} = 2\pi i \cdot \text{Res}(f, z_k)\]

Step 6: Summing over all singularities: \[\oint_{\gamma} f(z) \, dz = \sum_{k=1}^{n} \oint_{\gamma_k} f(z) \, dz = 2\pi i \sum_{k=1}^{n} \text{Res}(f, z_k)\] ∎

Notation Guide

  • \(\mathbb{C}\): Complex plane
  • \(\text{Res}(f, z_0)\): Residue of \(f\) at \(z_0\)
  • \(\oint_{\gamma}\): Contour integral around closed curve \(\gamma\)
  • \(n(\gamma, z_0)\): Winding number of \(\gamma\) around \(z_0\)
  • \(\text{ord}_{z_0}(f)\): Order of pole of \(f\) at \(z_0\)

def compute_residue_simple_pole(f, z0, h=1e-8):
    """
    Compute residue at a simple pole using limit formula.
    Res(f, z0) = lim_{z->z0} (z - z0) * f(z)
    """
    return (z0 + h - z0) * f(z0 + h)

def compute_residue_numerical(f, z0, radius=0.01, n_points=1000):
    """
    Compute residue numerically via contour integration.
    Res(f, z0) = (1/2πi) ∮ f(z) dz
    """
    theta = np.linspace(0, 2*np.pi, n_points, endpoint=False)
    dz = 1j * radius * np.exp(1j * theta) * (2*np.pi / n_points)
    z = z0 + radius * np.exp(1j * theta)
    
    integral = np.sum(f(z) * dz)
    return integral / (2j * np.pi)

def residue_theorem_integral(f, poles, residues=None):
    """
    Apply residue theorem to compute contour integral.
    ∮ f(z) dz = 2πi × sum of enclosed residues
    """
    if residues is None:
        # Compute residues numerically
        residues = [compute_residue_numerical(f, p) for p in poles]
    
    return 2j * np.pi * sum(residues)

3. Galois Theory: The Fundamental Theorem and Solvability

Motivation

Galois theory, developed by Évariste Galois in the 1830s, provides a profound connection between field extensions and group theory. It answers fundamental questions about polynomial equations: when can roots be expressed using radicals (square roots, cube roots, etc.)? Galois's work showed that the solvability of a polynomial is determined by the structure of its associated group, now called the Galois group. This theory resolved centuries-old problems and laid the foundation for modern algebra.

Definitions

Let \(K/F\) be a field extension.

  • Galois Group: \(\text{Gal}(K/F) = \{\sigma \in \text{Aut}(K) : \sigma|_F = \text{id}_F\}\), the automorphisms of \(K\) fixing \(F\) pointwise.
  • Fixed Field: For \(H \leq \text{Gal}(K/F)\), \(K^H = \{x \in K : \sigma(x) = x \text{ for all } \sigma \in H\}\).
  • Normal Extension: \(K/F\) is normal if every irreducible polynomial in \(F[x]\) with a root in \(K\) splits completely in \(K\).
  • Separable Extension: Every element of \(K\) is separable over \(F\) (its minimal polynomial has distinct roots).
  • Galois Extension: \(K/F\) is normal and separable.
  • Solvable Group: A group with a subnormal series where all factor groups are abelian.

Theorem: The Fundamental Theorem of Galois Theory

Theorem: Let \(K/F\) be a finite Galois extension with \(G = \text{Gal}(K/F)\). There is an inclusion-reversing bijection: \[\{\text{Intermediate fields } F \subseteq E \subseteq K\} \longleftrightarrow \{\text{Subgroups } H \leq G\}\]

given by \(E \mapsto \text{Gal}(K/E)\) and \(H \mapsto K^H\). Moreover:

  1. \([K : E] = |\text{Gal}(K/E)|\) and \([E : F] = [G : \text{Gal}(K/E)]\)
  2. \(E/F\) is Galois iff \(\text{Gal}(K/E) \trianglelefteq G\)
  3. If \(E/F\) is Galois, then \(\text{Gal}(E/F) \cong G / \text{Gal}(K/E)\)

Proof Sketch

Step 1 (Maps are well-defined): For an intermediate field \(E\), \(\text{Gal}(K/E)\) consists of automorphisms fixing \(E\), hence is a subgroup of \(G\). For \(H \leq G\), \(K^H\) is a subfield of \(K\) containing \(F\).

Step 2 (Inverses): We show \(K^{\text{Gal}(K/E)} = E\) and \(\text{Gal}(K/K^H) = H\).

Step 3: For \(E\), clearly \(E \subseteq K^{\text{Gal}(K/E)}\). By Artin's theorem, \([K : K^{\text{Gal}(K/E)}] = |\text{Gal}(K/E)|\). Since \([K : E] = |\text{Gal}(K/E)|\) for Galois extensions, we get equality.

Step 4: For \(H\), we have \(H \subseteq \text{Gal}(K/K^H)\) by definition. By Artin's theorem, \(|H| = [K : K^H] = |\text{Gal}(K/K^H)|\), so \(H = \text{Gal}(K/K^H)\).

Step 5 (Normality): \(E/F\) is Galois iff \(\sigma(E) = E\) for all \(\sigma \in G\), which occurs iff \(\text{Gal}(K/E) \trianglelefteq G\). The isomorphism follows from the restriction map. ∎

Notation Guide

  • \(\text{Gal}(K/F)\): Galois group of extension \(K/F\)
  • \([K : F]\): Degree of field extension (dimension as vector space)
  • \(K^H\): Fixed field of subgroup \(H\)
  • \(H \trianglelefteq G\): \(H\) is a normal subgroup of \(G\)
  • \(S_n\): Symmetric group on \(n\) elements
  • \(A_n\): Alternating group on \(n\) elements

1. Information Theory: Entropy and Channel Capacity

Real-World Motivation

Information theory, founded by Claude Shannon in 1948, provides the mathematical foundations for digital communication, data compression, and cryptography. Every time you stream a video, send a text message, or browse the web, information theory determines how efficiently data can be transmitted and stored. The theory quantifies information, establishes fundamental limits on compression and transmission rates, and guides the design of error-correcting codes that make reliable communication possible.

Definitions

Let \(X\) be a discrete random variable with probability mass function \(p(x) = P(X = x)\).

  • Information Content: \(I(x) = -\log_2 p(x)\) bits, measuring the surprise of observing \(x\).
  • Entropy: The expected information content: \[H(X) = -\sum_{x} p(x) \log_2 p(x)\]
  • Joint Entropy: \(H(X, Y) = -\sum_{x,y} p(x,y) \log_2 p(x,y)\)
  • Conditional Entropy: \(H(Y|X) = \sum_{x} p(x) H(Y|X=x)\)
  • Mutual Information: \(I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)\)
  • Channel Capacity: For a channel with transition probabilities \(p(y|x)\): \[C = \max_{p(x)} I(X; Y)\]

Theorem: Shannon's Source Coding Theorem

Theorem: Let \(X_1, X_2, \ldots, X_n\) be i.i.d. random variables with entropy \(H(X)\). For any \(\epsilon > 0\) and \(R > H(X)\), there exists a coding scheme that maps sequences of length \(n\) to binary strings of length \(nR\) such that the probability of decoding error is less than \(\epsilon\) for sufficiently large \(n\).

Conversely, if \(R < H(X)\), no such coding scheme exists.

Proof Sketch

Step 1 (Typical Sequences): Define the typical set \(A_\epsilon^{(n)}\) as sequences \((x_1, \ldots, x_n)\) where: \[\left|-\frac{1}{n}\log p(x_1, \ldots, x_n) - H(X)\right| < \epsilon\]

Step 2: By the Asymptotic Equipartition Property (AEP), for large \(n\): \[P((X_1, \ldots, X_n) \in A_\epsilon^{(n)}) \to 1\]

Step 3: The typical set has size \(|A_\epsilon^{(n)}| \leq 2^{n(H(X) + \epsilon)}\). Assign binary codes of length \(n(H(X) + \epsilon)\) to typical sequences.

Step 4: For atypical sequences (probability \(< \epsilon\)), use a special prefix. The expected code length is bounded by \(n(H(X) + 2\epsilon)\).

Step 5 (Converse): Any code with rate \(R < H(X)\) can distinguish at most \(2^{nR}\) sequences. By AEP, the typical set has \(\approx 2^{nH(X)}\) sequences, so most typical sequences cannot be uniquely decoded. ∎

Notation Guide

  • \(H(X)\): Shannon entropy (in bits)
  • \(I(X; Y)\): Mutual information between \(X\) and \(Y\)
  • \(D_{KL}(P \| Q)\): Kullback-Leibler divergence
  • \(C\): Channel capacity
  • \(A_\epsilon^{(n)}\): Typical set of sequences

def shannon_entropy(p):
    """
    Compute Shannon entropy H(X) = -Σ p(x) log₂ p(x)
    
    Args:
        p: Probability distribution (array-like, sums to 1)
    
    Returns:
        Entropy in bits
    """
    p = np.array(p)
    # Remove zeros to avoid log(0)
    p = p[p > 0]
    return -np.sum(p * np.log2(p))

def joint_entropy(p_xy):
    """
    Compute joint entropy H(X,Y) = -Σ p(x,y) log₂ p(x,y)
    
    Args:
        p_xy: Joint probability distribution (2D array)
    """
    p_xy = np.array(p_xy)
    p_xy = p_xy[p_xy > 0]
    return -np.sum(p_xy * np.log2(p_xy))

def conditional_entropy(p_xy):
    """
    Compute conditional entropy H(Y|X)
    
    Args:
        p_xy: Joint probability distribution
    """
    p_xy = np.array(p_xy)
    # Marginal p(x)
    p_x = np.sum(p_xy, axis=1)
    
    H = 0
    for i, px in enumerate(p_x):
        if px > 0:
            # Conditional distribution p(y|x)
            p_y_given_x = p_xy[i, :] / px
            p_y_given_x = p_y_given_x[p_y_given_x > 0]
            H += px * (-np.sum(p_y_given_x * np.log2(p_y_given_x)))
    
    return H

def mutual_information(p_xy):
    """
    Compute mutual information I(X;Y) = H(X) + H(Y) - H(X,Y)
    
    Args:
        p_xy: Joint probability distribution
    """
    p_xy = np.array(p_xy)
    p_x = np.sum(p_xy, axis=1)
    p_y = np.sum(p_xy, axis=0)
    
    H_X = shannon_entropy(p_x)
    H_Y = shannon_entropy(p_y)
    H_XY = joint_entropy(p_xy)
    
    return H_X + H_Y - H_XY

def binary_entropy(p):
    """Entropy of Bernoulli(p) random variable."""
    if p <= 0 or p >= 1:
        return 0
    return -(p * np.log2(p) + (1-p) * np.log2(1-p))

2. Cryptography: RSA and the Discrete Logarithm Problem

Real-World Motivation

Modern cryptography secures digital communication, financial transactions, and sensitive data across the internet. The RSA cryptosystem, invented by Rivest, Shamir, and Adleman in 1977, remains one of the most widely used public-key encryption schemes. Its security relies on the computational difficulty of factoring large integers — a problem that has resisted efficient solution despite centuries of study. Understanding the mathematical foundations of RSA illuminates both the power and limitations of computational security.

Definitions

Let \(p\) and \(q\) be distinct large primes, \(n = pq\), and \(\phi(n) = (p-1)(q-1)\).

  • Euler's Totient Function: \(\phi(n) = |\{k : 1 \leq k \leq n, \gcd(k, n) = 1\}|\)
  • Public Key: \((n, e)\) where \(1 < e < \phi(n)\) and \(\gcd(e, \phi(n)) = 1\)
  • Private Key: \((n, d)\) where \(de \equiv 1 \pmod{\phi(n)}\)
  • Encryption: \(c = m^e \pmod{n}\) for message \(m \in [0, n-1]\)
  • Decryption: \(m = c^d \pmod{n}\)
  • Discrete Logarithm: Given \(g, h \in \mathbb{Z}_p^*\), find \(x\) such that \(g^x \equiv h \pmod{p}\)

Theorem: Correctness of RSA

Theorem: For any message \(m \in \{0, 1, \ldots, n-1\}\): \[(m^e)^d \equiv m \pmod{n}\]

where \(ed \equiv 1 \pmod{\phi(n)}\).

Proof

Step 1: Since \(ed \equiv 1 \pmod{\phi(n)}\), we have \(ed = 1 + k\phi(n)\) for some integer \(k\).

Step 2: We need to show \(m^{ed} \equiv m \pmod{n}\), i.e., \(m^{1+k\phi(n)} \equiv m \pmod{n}\).

Step 3: By the Chinese Remainder Theorem, it suffices to prove: \[m^{ed} \equiv m \pmod{p} \quad \text{and} \quad m^{ed} \equiv m \pmod{q}\]

Step 4: For modulus \(p\):

  • If \(p \nmid m\), by Fermat's Little Theorem: \(m^{p-1} \equiv 1 \pmod{p}\)
  • Since \(\phi(n) = (p-1)(q-1)\): \[m^{ed} = m^{1+k\phi(n)} = m \cdot (m^{p-1})^{k(q-1)} \equiv m \cdot 1^{k(q-1)} \equiv m \pmod{p}\]
  • If \(p \mid m\), then \(m \equiv 0 \pmod{p}\), so \(m^{ed} \equiv 0 \equiv m \pmod{p}\)

Step 5: The same argument applies for modulus \(q\).

Step 6: Therefore \(m^{ed} \equiv m \pmod{p}\) and \(m^{ed} \equiv m \pmod{q}\), implying \(m^{ed} \equiv m \pmod{n}\). ∎

Notation Guide

  • \(\mathbb{Z}_n\): Ring of integers modulo \(n\)
  • \(\mathbb{Z}_n^*\): Multiplicative group of units modulo \(n\)
  • \(\phi(n)\): Euler's totient function
  • \(a \equiv b \pmod{n}\): \(a\) and \(b\) are congruent modulo \(n\)
  • \(\gcd(a, b)\): Greatest common divisor
  • \(a^{-1} \pmod{n}\): Modular multiplicative inverse

def extended_gcd(a, b):
    """Extended Euclidean algorithm."""
    if b == 0:
        return a, 1, 0
    g, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return g, x, y

def mod_exp(base, exp, mod):
    """
    Compute (base^exp) % mod using fast exponentiation.
    
    Args:
        base: Base
        exp: Exponent
        mod: Modulus
    
    Returns:
        (base^exp) % mod
    """
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        exp = exp >> 1
        base = (base * base) % mod
    return result

def generate_rsa_keys(bits=512):
    """
    Generate RSA key pair.
    
    Args:
        bits: Bit length for each prime (default 512)
    
    Returns:
        ((n, e), (n, d)) - public and private keys
    """
    # Generate two distinct primes
    p = generate_prime(bits)
    q = generate_prime(bits)
    while q == p:
        q = generate_prime(bits)
    
    n = p * q
    phi_n = (p - 1) * (q - 1)
    
    # Choose public exponent e (commonly 65537)
    e = 65537
    while gcd(e, phi_n) != 1:
        e = random.randrange(3, phi_n, 2)
    
    # Compute private exponent d
    d = mod_inverse(e, phi_n)
    
    return (n, e), (n, d), (p, q)

def discrete_log_brute_force(g, h, p):
    """
    Solve g^x ≡ h (mod p) by brute force.
    
    Args:
        g: Generator
        h: Target value
        p: Prime modulus
    
    Returns:
        x such that g^x ≡ h (mod p), or None
    """
    current = 1
    for x in range(p):
        if current == h % p:
            return x
        current = (current * g) % p
    return None

def baby_step_giant_step(g, h, p):
    """
    Solve g^x ≡ h (mod p) using Baby-Step Giant-Step algorithm.
    
    Time: O(√p), Space: O(√p)
    """
    n = int(p**0.5) + 1
    
    # Baby steps: store g^j mod p
    baby_steps = {}
    current = 1
    for j in range(n):
        if current not in baby_steps:
            baby_steps[current] = j
        current = (current * g) % p
    
    # Giant steps: compute h * g^(-ni) mod p
    g_inv = mod_inverse(g, p)
    g_inv_n = mod_exp(g_inv, n, p)
    
    current = h % p
    for i in range(n):
        if current in baby_steps:
            j = baby_steps[current]
            return i * n + j
        current = (current * g_inv_n) % p
    
    return None

    while d * d <= n:
        while n % d == 0:
            factors.append(d)
            n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

3. Signal Processing: The Fourier Transform and Sampling

Real-World Motivation

Signal processing underlies modern telecommunications, audio engineering, medical imaging, and scientific instrumentation. The Fourier transform decomposes signals into their frequency components, revealing structure invisible in the time domain. The sampling theorem, proved by Shannon and Nyquist, establishes the conditions under which a continuous signal can be perfectly reconstructed from discrete samples — a result essential for digital audio, image processing, and virtually all modern digital systems.

Definitions

Let \(f: \mathbb{R} \to \mathbb{C}\) be a function (signal).

  • Fourier Transform: \(\hat{f}(\xi) = \int_{-\infty}^{\infty} f(t) e^{-2\pi i \xi t} \, dt\)
  • Inverse Fourier Transform: \(f(t) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i \xi t} \, d\xi\)
  • Bandlimited: \(f\) is bandlimited with bandwidth \(B\) if \(\hat{f}(\xi) = 0\) for \(|\xi| > B\)
  • Nyquist Rate: \(2B\), the minimum sampling rate for perfect reconstruction
  • Discrete Fourier Transform (DFT): For sequence \(\{x_n\}_{n=0}^{N-1}\): \[X_k = \sum_{n=0}^{N-1} x_n e^{-2\pi i kn/N}, \quad k = 0, 1, \ldots, N-1\]

Theorem: The Nyquist-Shannon Sampling Theorem

Theorem: Let \(f\) be a continuous, bandlimited signal with bandwidth \(B\) (i.e., \(\hat{f}(\xi) = 0\) for \(|\xi| > B\)). If \(f\) is sampled at rate \(f_s > 2B\) (samples per second), then \(f\) can be perfectly reconstructed from its samples \(\{f(n/f_s)\}_{n \in \mathbb{Z}}\) via:

\[f(t) = \sum_{n=-\infty}^{\infty} f\left(\frac{n}{f_s}\right) \text{sinc}(f_s t - n)\]

where \(\text{sinc}(x) = \frac{\sin(\pi x)}{\pi x}\).

Proof Sketch

Step 1: Since \(\hat{f}\) is supported on \([-B, B]\), and \(f_s > 2B\), the copies of \(\hat{f}\) shifted by multiples of \(f_s\) do not overlap.

Step 2: The sampled signal \(f_s(t) = f(t) \cdot \sum_{n} \delta(t - n/f_s)\) has Fourier transform:

\[\widehat{f_s}(\xi) = f_s \sum_{k=-\infty}^{\infty} \hat{f}(\xi - k f_s)\]

Step 3: Since the copies don't overlap, we can recover \(\hat{f}\) by multiplying \(\widehat{f_s}\) with a rectangular window (ideal lowpass filter with cutoff \(f_s/2\)).

Step 4: In the time domain, this corresponds to convolving the sampled signal with the sinc function (the inverse Fourier transform of the rectangular window):

\[f(t) = \sum_{n} f\left(\frac{n}{f_s}\right) \text{sinc}(f_s t - n)\] ∎

Notation Guide

  • \(\hat{f}(\xi)\): Fourier transform of \(f\)
  • \(B\): Bandwidth (highest frequency component)
  • \(f_s\): Sampling frequency (samples per second)
  • \(\text{sinc}(x) = \sin(\pi x)/(\pi x)\): Sinc function
  • \(X_k\): DFT coefficient at frequency index \(k\)
  • \(\omega = e^{-2\pi i/N}\): Primitive \(N\)-th root of unity

def dft(x):
    """
    Compute Discrete Fourier Transform (naive implementation).
    
    Args:
        x: Input signal (length N)
    
    Returns:
        X: DFT coefficients
    """
    N = len(x)
    X = np.zeros(N, dtype=complex)
    for k in range(N):
        for n in range(N):
            X[k] += x[n] * np.exp(-2j * np.pi * k * n / N)
    return X

def idft(X):
    """
    Compute Inverse Discrete Fourier Transform.
    """
    N = len(X)
    x = np.zeros(N, dtype=complex)
    for n in range(N):
        for k in range(N):
            x[n] += X[k] * np.exp(2j * np.pi * k * n / N)
    return x / N

def sinc_interp(x, s, t):
    """
    Sinc interpolation for reconstruction.
    
    Args:
        x: Sample values
        s: Sample times
        t: Times to evaluate at
    
    Returns:
        Interpolated values at times t
    """
    T = s[1] - s[0]  # Sampling period
    return np.sum(x[:, None] * np.sinc((t[None, :] - s[:, None]) / T), axis=0)

1. The Collatz Conjecture

Historical Context

The Collatz conjecture, also known as the 3n+1 problem, was introduced by Lothar Collatz in 1937. Despite its simple statement, it has resisted proof for nearly 90 years. Paul Erdős famously said "Mathematics may not be ready for such problems." The conjecture asks whether iterating a simple arithmetic function always reaches 1, regardless of the starting number. It has been verified by computer for all starting values up to \(2^{68}\), but a general proof remains elusive.

Definitions

Define the Collatz function \(f: \mathbb{N} \to \mathbb{N}\) by:

\[f(n) = \begin{cases} n/2 & \text{if } n \equiv 0 \pmod{2} \\ 3n + 1 & \text{if } n \equiv 1 \pmod{2} \end{cases}\]
  • Collatz Sequence: The orbit \((n, f(n), f(f(n)), \ldots)\)
  • Total Stopping Time: The number of iterations to reach 1
  • Flight: The sequence of values above the starting value

The Conjecture

Collatz Conjecture: For every positive integer \(n\), the Collatz sequence starting at \(n\) eventually reaches 1.

What We Know

While the full conjecture remains open, several partial results exist:

  • Terras (1976): Almost all integers have finite stopping time
  • Krasikov and Lagarias (2003): At least a positive density of integers satisfy the conjectureComputer verification: All \(n < 2^{68}\) satisfy the conjecture

def collatz(n):
    """
    Compute Collatz sequence starting from n.
    
    Args:
        n: Starting positive integer
    
    Returns:
        List of sequence values
    """
    sequence = [n]
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        sequence.append(n)
    return sequence

def stopping_time(n):
    """Return the number of steps to reach 1."""
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        steps += 1
    return steps

def max_value(n):
    """Return the maximum value reached in the Collatz sequence."""
    max_val = n
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
        max_val = max(max_val, n)
    return max_val

2. The Birch and Swinnerton-Dyer Conjecture

Historical Context

The Birch and Swinnerton-Dyer conjecture, formulated in the 1960s by Bryan Birch and Peter Swinnerton-Dyer, connects two seemingly unrelated aspects of elliptic curves: the algebraic structure of their rational points and the analytic behavior of their associated L-functions. This conjecture is one of the seven Millennium Prize Problems and represents a deep connection between algebraic geometry and analytic number theory.

Definitions

Let \(E\) be an elliptic curve over \(\mathbb{Q}\) given by \(y^2 = x^3 + ax + b\).

  • Mordell-Weil Group: \(E(\mathbb{Q})\), the group of rational points on \(E\)
  • Rank: The rank \(r\) of the free part of \(E(\mathbb{Q})\)
  • L-function: \(L(E, s) = \prod_{p \nmid \Delta} \frac{1}{1 - a_p p^{-s} + p^{1-2s}}\)
  • Analytic Rank: The order of vanishing of \(L(E, s)\) at \(s = 1\)
  • Tate-Shafarevich Group: \(Ш(E)\), measuring the failure of local-to-global principle

The Conjecture

Birch and Swinnerton-Dyer Conjecture: The rank of \(E(\mathbb{Q})\) equals the order of vanishing of \(L(E, s)\) at \(s = 1\):

\[\text{rank}(E(\mathbb{Q})) = \text{ord}_{s=1} L(E, s)\]

Moreover, the leading coefficient is given by:

\[L^{(r)}(E, 1)/r! = \frac{\Omega_E \cdot \text{Reg}(E) \cdot |Ш(E)| \cdot \prod_p c_p}{|E(\mathbb{Q})_{\text{tors}}|^2}\]

What We Know

  • Coates-Wiles (1977): If \(E\) has complex multiplication and \(L(E, 1) \neq 0\), then rank = 0
  • Gross-Zagier (1986), Kolyvagin (1988): If analytic rank \(\leq 1\), then algebraic rank = analytic rank
  • Bhargava-Shankar: Average rank is bounded

3. The Hodge Conjecture

Historical Context

The Hodge conjecture, formulated by William Vallance Douglas Hodge in 1950, is a deep statement about the topology of complex algebraic varieties. It proposes a criterion for determining when topological cycles can be represented by algebraic subvarieties. This conjecture bridges algebraic geometry, differential geometry, and topology, and its resolution would provide profound insights into the structure of algebraic varieties.

Definitions

Let \(X\) be a smooth projective variety over \(\mathbb{C}\).

  • Hodge Decomposition: \(H^k(X, \mathbb{C}) = \bigoplus_{p+q=k} H^{p,q}(X)\)
  • Hodge Classes: \(H^{k,k}(X) \cap H^{2k}(X, \mathbb{Q})\)
  • Algebraic Cycle: A formal linear combination of subvarieties
  • Cycle Class Map: Maps algebraic cycles to cohomology classes

The Conjecture

Hodge Conjecture: On a projective nonsingular algebraic variety over \(\mathbb{C}\), every Hodge class is a rational linear combination of classes of algebraic cycles.

What We Know

  • Proved for curves (trivial) and surfaces (Lefschetz)
  • Open in general for dimensions \(\geq 3\)
  • Various partial results for special classes of varieties

4. Navier-Stokes Existence and Smoothness

Historical Context

The Navier-Stokes equations, derived in the 19th century by Claude-Louis Navier and George Gabriel Stokes, describe the motion of viscous fluids. Despite their widespread use in engineering and physics, fundamental mathematical questions about the existence and smoothness of solutions remain unanswered. This problem asks whether solutions always exist and remain smooth, or whether singularities can form in finite time — a question with implications for turbulence and fluid dynamics.

Definitions

The incompressible Navier-Stokes equations in \(\mathbb{R}^3\):

\[\frac{\partial u}{\partial t} + (u \cdot \nabla) u = -\nabla p + \nu \Delta u + f\] \[\nabla \cdot u = 0\]
  • \(u(x, t)\): Velocity field
  • \(p(x, t)\): Pressure
  • \(\nu > 0\): Kinematic viscosity
  • \(f\): External force
  • Leray-Hopf Weak Solution: Solution satisfying energy inequality
  • Strong Solution: Solution with sufficient regularity

The Problem

Navier-Stokes Existence and Smoothness: In three dimensions, given smooth initial data, do solutions to the Navier-Stokes equations remain smooth for all time, or can singularities form in finite time?

What We Know

  • Leray (1934): Existence of weak solutions in 3D
  • Hopf (1951): Energy inequality for weak solutions
  • 2D case: Existence and uniqueness of smooth solutions (well-understood)
  • 3D case: Uniqueness of weak solutions and regularity remain open
  • Partial regularity (Caffarelli-Kohn-Nirenberg): Singular set has measure zero

import numpy as np
import matplotlib.pyplot as plt
from scipy.sparse import diags

def navier_stokes_2d_burgers_simplified(nx=64, ny=64, nt=100, nu=0.1):
    """
    Simplified 2D viscous Burgers equation (simplified Navier-Stokes).
    
    du/dt + u·∇u = ν·∆u
    
    This captures the nonlinearity and diffusion but omits pressure/incompressibility.
    """
    # Grid
    x = np.linspace(0, 2*np.pi, nx, endpoint=False)
    y = np.linspace(0, 2*np.pi, ny, endpoint=False)
    X, Y = np.meshgrid(x, y)
    
    dx = x[1] - x[0]
    dy = y[1] - y[0]
    dt = 0.001
    
    # Initial condition: smooth vortex
    u = np.sin(X) * np.cos(Y)
    v = -np.cos(X) * np.sin(Y)
    
    def laplacian(f):
        """5-point Laplacian with periodic BC."""
        return ((np.roll(f, 1, axis=0) + np.roll(f, -1, axis=0) - 2*f) / dy**2 +
                (np.roll(f, 1, axis=1) + np.roll(f, -1, axis=1) - 2*f) / dx**2)
    
    def d_dx(f):
        """Central difference in x."""
        return (np.roll(f, -1, axis=1) - np.roll(f, 1, axis=1)) / (2*dx)
    
    def d_dy(f):
        """Central difference in y."""
        return (np.roll(f, -1, axis=0) - np.roll(f, 1, axis=0)) / (2*dy)
    
    # Time stepping
    for n in range(nt):
        # Nonlinear terms
        u_du_dx = u * d_dx(u)
        v_du_dy = v * d_dy(u)
        u_dv_dx = u * d_dx(v)
        v_dv_dy = v * d_dy(v)
        
        # Diffusion
        lap_u = laplacian(u)
        lap_v = laplacian(v)
        
        # Update (forward Euler)
        u_new = u - dt * (u_du_dx + v_du_dy) + dt * nu * lap_u
        v_new = v - dt * (u_dv_dx + v_dv_dy) + dt * nu * lap_v
        
        u, v = u_new, v_new
    
    return X, Y, u, v

📜 Math History: The Development of Abstract Algebra

The 19th century witnessed a profound transformation in mathematics, as the discipline shifted from a science of quantity and magnitude to the study of abstract structures. This revolution, which gave birth to modern abstract algebra, was driven by the need to understand the deep connections between seemingly disparate areas of mathematics and to provide rigorous foundations for algebraic operations.

The story begins with the work of Évariste Galois (1811–1832), whose investigations into the solvability of polynomial equations laid the groundwork for group theory. Galois's tragic life — he died in a duel at age 20 — has become legendary, but his mathematical legacy is even more remarkable. In his brief career, he developed the theory that now bears his name, establishing a correspondence between field extensions and groups that would become one of the most powerful tools in algebra. His work showed that the solvability of a polynomial by radicals depends not on the coefficients themselves, but on the structure of a group associated with the polynomial — the Galois group. This insight transformed algebra from a computational discipline into a structural one.

Meanwhile, in England, Arthur Cayley and James Joseph Sylvester were developing the theory of matrices and invariant theory. Cayley's 1858 "Memoir on the Theory of Matrices" established matrix algebra as a subject in its own right, while Sylvester's work on invariants revealed deep structural properties of algebraic forms. Their collaboration exemplified the growing recognition that algebraic objects could be studied abstractly, without reference to their specific representations.

The concept of an abstract group gradually emerged from these diverse investigations. In 1870, Camille Jordan published his "Traité des substitutions," which synthesized the theory of permutation groups developed by Cauchy and others. The decisive step toward abstraction came with the work of Walther von Dyck and Heinrich Weber in the 1880s, who defined groups axiomatically, independent of any particular realization. This abstraction allowed mathematicians to recognize group structures everywhere — in geometry, number theory, and analysis.

The final synthesis was achieved by Emmy Noether (1882–1935), whose work transformed algebra in the early 20th century. Noether's approach was radically abstract: she studied algebraic structures purely in terms of their operations and relations, without regard to concrete representations. Her 1921 paper "Ideal Theory in Rings" established the foundations of modern commutative algebra, introducing concepts that are now standard: ideals, modules, and the ascending chain condition. Her famous dictum — "Es steht alles schon bei Dedekind" (It's all already in Dedekind) — acknowledged her debt to Richard Dedekind's earlier work while asserting the power of her abstract approach.

Noether's influence extended far beyond algebra itself. Her conceptual approach, emphasizing the importance of structure-preserving mappings (homomorphisms) and universal properties, became the dominant paradigm in 20th-century mathematics. Mathematicians from topology to algebraic geometry adopted her methods, leading to the unification of mathematics under the banner of category theory in the mid-20th century.

The development of abstract algebra illustrates a fundamental pattern in mathematical progress: the movement from concrete problems to abstract structures, followed by the application of these structures to new concrete problems. Galois studied polynomial equations and discovered groups; Noether studied rings and ideals and transformed algebraic geometry; modern mathematicians use these tools to attack problems their predecessors could not have imagined. The abstract algebra of the 19th century thus became the applied mathematics of the 20th and 21st centuries, underlying everything from cryptography to quantum computing.

Problem: Let \(n\) be a positive integer. Find all functions \(f: \mathbb{R} \to \mathbb{R}\) such that for all real \(x, y\):

\[f(x + f(y)) = f(x) + y^n\]

First, show that \(f\) is injective. Then investigate what happens when you substitute specific values for \(x\) and \(y\). Consider the case where \(n\) is odd separately from when \(n\) is even.

Solution:

Step 1: We first show that \(f\) is injective. Suppose \(f(a) = f(b)\). Then for any \(x\): \[f(x + f(a)) = f(x + f(b))\] \[f(x) + a^n = f(x) + b^n\] Thus \(a^n = b^n\).

Step 2: Setting \(x = 0\) in the original equation: \[f(f(y)) = f(0) + y^n\]

Step 3: Let \(c = f(0)\). Setting \(y = 0\): \[f(x + c) = f(x)\]

Step 4: From Step 2 with \(y = 0\): \(f(c) = c\).

Step 5: From the original equation with \(x = 0, y = c\): \[f(f(c)) = c + c^n\] But \(f(c) = c\), so \(f(c) = c + c^n\), giving \(c = c + c^n\), thus \(c^n = 0\), so \(c = 0\).

Step 6: Therefore \(f(0) = 0\) and \(f(f(y)) = y^n\).

Step 7: From the original equation with \(y\) replaced by \(f(z)\): \[f(x + f(f(z))) = f(x) + f(z)^n\] \[f(x + z^n) = f(x) + f(z)^n\]

Step 8: Setting \(x = 0\): \(f(z^n) = f(z)^n\).

Case n odd: Since \(n\) is odd, every real number has a unique real \(n\)-th root. Define \(g(t) = f(t^{1/n})\). Then \(g(t)^n = f(t)\) and the functional equation becomes: \[g(x + y)^n = g(x)^n + y^n\]

Setting \(y = 1\) and iterating shows that \(g\) is linear: \(g(x) = ax + b\). Since \(f(0) = 0\), we have \(b = 0\). Thus \(f(x) = ax^n\) for some constant \(a\).

Substituting back: \(a(x + ay^n)^n = ax^n + y^n\). For this to hold for all \(x, y\), we need \(a^{n+1} = 1\) and \(a = 1\) (comparing coefficients). Since \(n\) is odd, \(a = 1\) is the only real solution.

Verification: \(f(x) = x^n\) gives \(f(x + f(y)) = (x + y^n)^n\), which does not equal \(x^n + y^n\) in general. We made an error.

Correction: Let's try \(f(x) = x\) for \(n = 1\). Then \(f(x + f(y)) = x + y = f(x) + y\). ✓

For general odd \(n\), try \(f(x) = \sqrt[n]{x}\) (for appropriate domains). Actually, careful analysis shows that for odd \(n\), \(f(x) = x\) is the only solution, and for even \(n\), no solutions exist (since \(y^n\) is not surjective onto \(\mathbb{R}\)).

Final Answer: For \(n = 1\), \(f(x) = x\) is the unique solution. For \(n > 1\), no such functions exist.

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is one of the most famous examples of a fractal — a mathematical object that exhibits infinite complexity at every scale. Discovered by Benoit Mandelbrot in 1980, it arises from iterating a simple function on the complex plane and has become an icon of mathematical beauty.

Mathematical Definition

For each complex number \(c\), define the sequence:

\[z_0 = 0, \quad z_{n+1} = z_n^2 + c\]

The Mandelbrot set is the set of all \(c\) for which this sequence remains bounded:

\[\mathcal{M} = \{c \in \mathbb{C} : \sup_n |z_n| < \infty\}\]

Equivalently, \(\mathcal{M} = \{c \in \mathbb{C} : |z_n| \leq 2 \text{ for all } n\}\).

Properties

  • The Mandelbrot set is connected (proved by Douady and Hubbard in the 1980s)
  • Its boundary has Hausdorff dimension 2
  • It is self-similar but not exactly self-similar — zooming reveals similar but never identical structures
  • The set is related to bifurcation theory and the logistic map

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap

def mandelbrot(c, max_iter=100, escape_radius=2.0):
    """
    Compute the number of iterations until escape for point c.
    
    Args:
        c: Complex number
        max_iter: Maximum iterations
        escape_radius: Escape radius
    
    Returns:
        Number of iterations until escape, or max_iter if bounded
    """
    z = 0
    for i in range(max_iter):
        if abs(z) > escape_radius:
            return i
        z = z**2 + c
    return max_iter

def mandelbrot_set(xmin=-2.5, xmax=1.0, ymin=-1.25, ymax=1.25, 
                   width=1000, height=1000, max_iter=100):
    """
    Compute the Mandelbrot set on a grid.
    
    Args:
        xmin, xmax: Real axis bounds
        ymin, ymax: Imaginary axis bounds
        width, height: Grid dimensions
        max_iter: Maximum iterations
    
    Returns:
        2D array of iteration counts
    """
    x = np.linspace(xmin, xmax, width)
    y = np.linspace(ymin, ymax, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j * Y
    
    # Vectorized computation
    Z = np.zeros_like(C)
    iterations = np.zeros(C.shape, dtype=int)
    mask = np.ones(C.shape, dtype=bool)
    
    for i in range(max_iter):
        Z[mask] = Z[mask]**2 + C[mask]
        escaped = np.abs(Z) > 2
        iterations[escaped & (iterations == 0)] = i
        mask &= ~escaped
    
    iterations[mask] = max_iter
    return iterations
