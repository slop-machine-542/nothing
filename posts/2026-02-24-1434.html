Algebraic Curves and the Riemann-Roch Theorem

Motivation: Algebraic curves form a bridge between algebra and geometry, connecting polynomial equations to geometric shapes. The Riemann-Roch theorem is a cornerstone result that relates the number of independent functions with prescribed zeros and poles to the topology of the curve.

Definitions

  • Algebraic Curve: A one-dimensional algebraic variety, defined as the zero set of polynomial equations. Over an algebraically closed field, smooth projective curves correspond compact Riemann surfaces.
  • Divisor: A formal finite sum \(D = \sum_{P \in C} n_P P\) where \(n_P \in \mathbb{Z}\) and only finitely many are non-zero. The degree is \(\deg(D) = \sum n_P\).
  • Riemann Surface: A one-dimensional complex manifold. A compact Riemann surface of genus \(g\) has \(g\) "holes" topologically.
  • Canonical Divisor: The divisor of a differential form on the curve, denoted \(K\).

Theorem (Riemann-Roch)

Let \(C\) be a smooth projective curve of genus \(g\) over an algebraically closed field, and let \(D\) be a divisor on \(C\). Then:

\[\ell(D) - \ell(K - D) = \deg(D) + 1 - g\]

where \(\ell(D)\) denotes the dimension of the space of functions with poles bounded by \(D\).

Proof Sketch

The proof proceeds in several stages:

  1. Riemann's Inequality: First establish that \(\ell(D) \geq \deg(D) + 1 - g\) using the residue theorem and sheaf cohomology.
  2. Serre Duality: Show that \(H^1(C, \mathcal{O}_C(D)) \cong H^0(C, \mathcal{O}_C(K-D))^*\), relating cohomology groups.
  3. Exact Sequence: For any point \(P\), use the exact sequence \(0 \to \mathcal{O}_C(D-P) \to \mathcal{O}_C(D) \to k(P) \to 0\) to relate dimensions.
  4. Induction: Prove the formula by induction on \(\deg(D)\), using the fact that adding a point changes \(\ell(D)\) by at most 1.

Notation Guide

  • \(C\): smooth projective curve
  • \(g\): genus (topological invariant)
  • \(D\): divisor (formal sum of points)
  • \(\ell(D)\): dimension of \(H^0(C, \mathcal{O}_C(D))\)
  • \(K\): canonical divisor

    """
    Calculate the Riemann-Roch formula components.
    For large degree: l(D) = deg(D) + 1 - g
    """
    if deg_D >= 2*genus - 1:
        # Special case: D is non-special
        l_D = deg_D + 1 - genus
        l_K_minus_D = 0
    elif deg_D < 0:
        l_D = 0
        l_K_minus_D = (2*genus - 2) - deg_D + 1 - genus
    else:

        l_D = max(0, deg_D + 1 - genus)  # Lower bound
        l_K_minus_D = None
    
    rr_value = deg_D + 1 - genus
    
    return {
        'genus': genus,
        'deg_D': deg_D,
        'l_D_estimate': l_D,
        'l_K_minus_D': l_K_minus_D,
        'RR_rhs': rr_value
    }

Modular Forms and the Dimension Formula

Motivation: Modular forms are highly symmetric functions on the upper half-plane with deep connections to number theory, algebraic geometry, and string theory. They encode information about elliptic curves, partition functions, and even the monster group.

Definitions

  • Upper Half-Plane: \(\mathbb{H} = \{z \in \mathbb{C} : \text{Im}(z) > 0\}\)
  • Modular Group: \(\text{SL}_2(\mathbb{Z})\) acts on \(\mathbb{H}\) by \(z \mapsto \frac{az+b}{cz+d}\) where \(\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in \text{SL}_2(\mathbb{Z})\).
  • Modular Form of Weight \(k\): A holomorphic function \(f: \mathbb{H} \to \mathbb{C}\) satisfying \(f(\gamma z) = (cz+d)^k f(z)\) for all \(\gamma \in \text{SL}_2(\mathbb{Z})\), and holomorphic at infinity.
  • Cusp Form: A modular form that vanishes at infinity (\(a_0 = 0\) in its Fourier expansion).

Theorem (Dimension Formula)

Let \(M_k\) be the space of modular forms of weight \(k\) for \(\text{SL}_2(\mathbb{Z})\), and \(S_k\) the subspace of cusp forms. Then:

\[\dim M_k = \begin{cases} \lfloor k/12 \rfloor & k \equiv 2 \pmod{12} \\ \lfloor k/12 \rfloor + 1 & k \not\equiv 2 \pmod{12} \end{cases}\]

for \(k \geq 0\) even, and \(\dim M_k = 0\) for \(k < 0\) or \(k\) odd.

Proof Sketch

The proof uses the residue theorem applied to the logarithmic derivative of a modular form:

  1. Consider the fundamental domain for \(\text{SL}_2(\mathbb{Z})\) acting on \(\mathbb{H}\).
  2. For a non-zero modular form \(f\) of weight \(k\), integrate \(\frac{f'}{f}\) around the boundary of the fundamental domain.
  3. The valence formula gives: \(\sum_{P} \frac{\text{ord}_P(f)}{|\text{Stab}(P)|} = \frac{k}{12}\)
  4. Counting dimensions via Riemann-Roch on the modular curve \(X(1) = \mathbb{H}^*/\text{SL}_2(\mathbb{Z})\).

Notation Guide

  • \(M_k\): space of modular forms of weight \(k\)
  • \(S_k\): space of cusp forms of weight \(k\)
  • \(E_k\): Eisenstein series of weight \(k\)
  • \(\Delta\): discriminant modular form (weight 12)

Class Field Theory and Artin Reciprocity

Motivation: Class field theory provides a complete description of all abelian extensions of a number field. It represents one of the crowning achievements of algebraic number theory, connecting Galois theory with the arithmetic of the base field through the Artin reciprocity map.

Definitions

  • Number Field: A finite extension \(K/\mathbb{Q}\).
  • Ray Class Group: For a modulus \(\mathfrak{m}\), the ray class group \(Cl_{\mathfrak{m}}(K)\) generalizes the ideal class group.
  • Artin Map: For an abelian extension \(L/K\) and unramified prime \(\mathfrak{p}\), \(\left(\frac{L/K}{\mathfrak{p}}\right) \in \text{Gal}(L/K)\) is the Frobenius element.
  • Hilbert Class Field: The maximal unramified abelian extension of \(K\).

Theorem (Artin Reciprocity)

Let \(L/K\) be an abelian extension of number fields. There exists a modulus \(\mathfrak{m}\) (divisible by all ramified primes) such that the Artin map induces an isomorphism:

\[Cl_{\mathfrak{m}}(K)/N_{L/K}(Cl_{\mathfrak{m}}(L)) \cong \text{Gal}(L/K)\]

Proof Sketch

  1. Analytic Approach: Use L-functions and the Chebotarev density theorem to show the Artin map is surjective.
  2. First Inequality: Show \([Cl_{\mathfrak{m}}(K) : N(C_{\mathfrak{m}}(L))] \leq [L:K]\) using analytic methods.
  3. Second Inequality: Show \([Cl_{\mathfrak{m}}(K) : N(C_{\mathfrak{m}}(L))] \geq [L:K]\) using cohomology or Kummer theory.
  4. Existence: Construct the ray class field for each modulus using torsion points on Lubin-Tate formal groups (local) or CM theory (global).

Notation Guide

  • \(K, L\): number fields
  • \(\mathfrak{m}\): modulus (formal product of primes)
  • \(Cl_{\mathfrak{m}}(K)\): ray class group
  • \(\left(\frac{L/K}{\cdot}\right)\): Artin symbol

from sympy import factorint, isprime, primitive_root
from sympy.ntheory import n_order

def frobenius_symbol(p, f_poly, K_degree):
    """
    Compute Frobenius symbol for prime p in extension defined by f.
    Simplified version for quadratic fields.
    """
    # For Q(sqrt(d)), Legendre symbol (d/p) gives Frobenius
    # Returns: 1 (splits), -1 (inert), 0 (ramified)
    if p == 2:
        return 0  # Simplified
    
    # Example: Q(i) = Q(sqrt(-1))
    d = -1
    return pow(d, (p-1)//2, p) if p != 2 else 0

def legendre_symbol(a, p):
    """Compute Legendre symbol (a/p)"""
    if p == 2:
        return 0
    a = a % p
    if a == 0:
        return 0
    result = pow(a, (p-1)//2, p)
    return -1 if result == p-1 else result

Bayesian Statistics and Conjugate Priors

Real-World Context: Bayesian statistics provides a framework for updating beliefs in light of evidence. It's used in medical diagnosis, spam filtering, A/B testing, and machine learning. Conjugate priors allow for analytical tractability in Bayesian inference.

Definitions

  • Prior Distribution: \(p(\theta)\) represents beliefs about parameter \(\theta\) before seeing data.
  • Likelihood: \(p(x|\theta)\) is the probability of data given the parameter.
  • Posterior Distribution: \(p(\theta|x) = \frac{p(x|\theta)p(\theta)}{p(x)}\) by Bayes' theorem.
  • Conjugate Prior: A prior is conjugate to a likelihood if the posterior has the same functional form as the prior.

Theorem (Beta-Binomial Conjugacy)

If \(X|\theta \sim \text{Binomial}(n, \theta)\) and \(\theta \sim \text{Beta}(\alpha, \beta)\), then:

\[\theta|X=x \sim \text{Beta}(\alpha + x, \beta + n - x)\]

Proof

The posterior is proportional to likelihood times prior:

\[p(\theta|x) \propto \binom{n}{x} \theta^x (1-\theta)^{n-x} \cdot \frac{\theta^{\alpha-1}(1-\theta)^{\beta-1}}{B(\alpha, \beta)}\]

\[\propto \theta^{x+\alpha-1} (1-\theta)^{n-x+\beta-1}\]

This is the kernel of a \(\text{Beta}(\alpha+x, \beta+n-x)\) distribution.

Notation Guide

  • \(\theta\): parameter of interest
  • \(x\): observed data
  • \(B(\alpha, \beta)\): beta function (normalizing constant)
  • \(\Gamma\): gamma function

Python Implementation

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import beta, binom

def bayesian_coin_toss(n_tosses=100, n_heads=60, alpha_prior=1, beta_prior=1):
    """
    Bayesian inference for coin bias using Beta-Binomial model.
    """
    # Prior: Beta(alpha_prior, beta_prior)
    # Likelihood: Binomial(n_tosses, theta)
    # Posterior: Beta(alpha_prior + n_heads, beta_prior + n_tosses - n_heads)
    
    alpha_post = alpha_prior + n_heads
    beta_post = beta_prior + n_tosses - n_heads
    
    theta = np.linspace(0, 1, 1000)
    
    prior_pdf = beta.pdf(theta, alpha_prior, beta_prior)
    posterior_pdf = beta.pdf(theta, alpha_post, beta_post)
    
    # MAP estimate
    map_estimate = (alpha_post - 1) / (alpha_post + beta_post - 2)
    
    # 95% credible interval
    ci_lower = beta.ppf(0.025, alpha_post, beta_post)
    ci_upper = beta.ppf(0.975, alpha_post, beta_post)
    
    plt.figure(figsize=(12, 6))
    
    plt.subplot(1, 2, 1)
    plt.plot(theta, prior_pdf, 'b-', label=f'Prior: Beta({alpha_prior}, {beta_prior})', linewidth=2)
    plt.fill_between(theta, prior_pdf, alpha=0.3)
    plt.xlabel(r'$\theta$')
    plt.ylabel('Density')
    plt.title('Prior Distribution')
    plt.legend()
    plt.grid(True, alpha=0.3)
    
    plt.subplot(1, 2, 2)
    plt.plot(theta, posterior_pdf, 'r-', label=f'Posterior: Beta({alpha_post}, {beta_post})', linewidth=2)
    plt.fill_between(theta, posterior_pdf, alpha=0.3)
    plt.axvline(x=map_estimate, color='g', linestyle='--', label=f'MAP = {map_estimate:.3f}')
    plt.axvline(x=ci_lower, color='orange', linestyle=':', label=f'95% CI: [{ci_lower:.3f}, {ci_upper:.3f}]')
    plt.axvline(x=ci_upper, color='orange', linestyle=':')
    plt.xlabel(r'$\theta$')
    plt.ylabel('Density')
    plt.title(f'Posterior (observed {n_heads}/{n_tosses} heads)')
    plt.legend()
    plt.grid(True, alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('bayesian_inference.png', dpi=150)
    plt.show()

        'alpha_post': alpha_post,
        'beta_post': beta_post,
        'map_estimate': map_estimate,
        'ci_95': (ci_lower, ci_upper)

# Sequential updating
def sequential_bayesian(observations, alpha_init=1, beta_init=1):
    """Show how beliefs update sequentially"""
    alpha, beta_param = alpha_init, beta_init
    beliefs = [(alpha, beta_param)]
    
    for obs in observations:
        if obs == 1:  # heads
            alpha += 1
        else:  # tails
            beta_param += 1
        beliefs.append((alpha, beta_param))
    
    return beliefs

Network Flows and the Max-Flow Min-Cut Theorem

Real-World Context: Network flow algorithms power logistics optimization, computer network routing, image segmentation in computer vision, and matching problems in economics. The max-flow min-cut theorem is a fundamental result connecting optimization with graph structure.

Definitions

  • Flow Network: A directed graph \(G = (V, E)\) with source \(s\), sink \(t\), and capacity \(c(u,v) \geq 0\) for each edge.
  • Flow: A function \(f: E \to \mathbb{R}_{\geq 0}\) satisfying capacity constraints and flow conservation.
  • s-t Cut: A partition \((S, T)\) of \(V\) with \(s \in S\) and \(t \in T\). The capacity is \(c(S,T) = \sum_{u \in S, v \in T} c(u,v)\).

Theorem (Max-Flow Min-Cut)

In any flow network, the maximum value of an s-t flow equals the minimum capacity of an s-t cut:

\[\max |f| = \min_{(S,T)} c(S,T)\]

Proof Sketch (Ford-Fulkerson)

  1. Weak Duality: For any flow \(f\) and cut \((S,T)\), \(|f| \leq c(S,T)\). This follows since all flow must cross the cut.
  2. Augmenting Paths: If there exists an augmenting path (path with residual capacity), the flow can be increased.
  3. Termination: When no augmenting path exists, the residual graph partitions into reachable and unreachable sets, defining a minimum cut.
  4. Strong Duality: At termination, the flow value equals the cut capacity.

Notation Guide

  • \(G = (V, E)\): directed graph
  • \(c(u,v)\): edge capacity
  • \(f(u,v)\): flow on edge
  • \(|f|\): flow value
  • \(r(u,v) = c(u,v) - f(u,v)\): residual capacity

Python Implementation

from collections import defaultdict, deque

class FlowNetwork:
    def __init__(self):
        self.graph = defaultdict(dict)
        self.edges = []
    
    def add_edge(self, u, v, capacity):
        """Add edge with given capacity"""
        self.graph[u][v] = capacity
        self.graph[v][u] = 0  # Reverse edge
        self.edges.append((u, v, capacity))
    
    def bfs(self, source, sink, parent):
        """Find augmenting path using BFS"""
        visited = {source}
        queue = deque([source])
        
        while queue:
            u = queue.popleft()
            
            for v, capacity in self.graph[u].items():
                if v not in visited and capacity > 0:
                    visited.add(v)
                    parent[v] = u
                    if v == sink:
                        return True
                    queue.append(v)
        
        return False
    
    def ford_fulkerson(self, source, sink):
        """Compute max flow using Ford-Fulkerson"""
        parent = {}
        max_flow = 0
        
        # While there is an augmenting path
        while self.bfs(source, sink, parent):
            # Find minimum residual capacity along the path
            path_flow = float('inf')
            s = sink
            while s != source:
                path_flow = min(path_flow, self.graph[parent[s]][s])
                s = parent[s]
            
            # Update residual capacities
            v = sink
            while v != source:
                u = parent[v]
                self.graph[u][v] -= path_flow
                self.graph[v][u] += path_flow
                v = u
            
            max_flow += path_flow
            parent = {}
        
        return max_flow
    
    def min_cut(self, source):
        """Find minimum s-t cut using residual graph"""
        visited = set()
        queue = deque([source])
        visited.add(source)
        
        while queue:
            u = queue.popleft()
            for v, capacity in self.graph[u].items():
                if v not in visited and capacity > 0:
                    visited.add(v)
                    queue.append(v)
        
        return visited

# s ---> a ---> t
#  \         /
#   \15     /10
#    -> b ->

network.add_edge('b', 't', 10)

# The min cut should have capacity equal to max flow
min_cut_capacity = 0
for u in reachable:
    for v, cap in network.graph[u].items():
        if v not in reachable:
            original_cap = next((c for a, b, c in network.edges if a == u and b == v), 0)
            min_cut_capacity += original_cap

Cryptographic Protocols and Zero-Knowledge Proofs

Real-World Context: Zero-knowledge proofs allow one party to prove knowledge of a secret without revealing the secret itself. They're used in blockchain privacy (Zcash), secure authentication, and verifiable computation. The Schnorr protocol is a foundational example.

Definitions

  • Zero-Knowledge Proof: A protocol where a prover convinces a verifier of a statement's truth without revealing any information beyond the statement's validity.
  • Interactive Proof: A protocol with multiple rounds of communication between prover and verifier.
  • Discrete Logarithm: Given \(g\) and \(h = g^x \pmod{p}\), finding \(x\) is computationally hard.
  • Commitment: A value sent by the prover that binds them to a choice without revealing it.

Theorem (Schnorr Protocol Security)

The Schnorr identification protocol is:

  1. Complete: An honest prover is always accepted.
  2. Sound: A cheating prover succeeds with probability at most \(1/q\) (negligible).
  3. Zero-Knowledge: The verifier learns nothing beyond the prover's knowledge of \(x\).

Protocol Description

Public: Generator \(g\), prime \(p\), public key \(y = g^x \pmod{p}\)

Prover knows: Secret key \(x\)

  1. Prover chooses random \(r\), sends commitment \(t = g^r \pmod{p}\)
  2. Verifier sends challenge \(c \in \{0, 1, ..., q-1\}\)
  3. Prover sends response \(s = r + cx \pmod{q}\)
  4. Verifier checks: \(g^s \stackrel{?}{=} t \cdot y^c \pmod{p}\)

Notation Guide

  • \(p\): large prime
  • \(q\): prime divisor of \(p-1\)
  • \(g\): generator of subgroup of order \(q\)
  • \(x\): secret key
  • \(y = g^x\): public key

def fiat_shamir_signature(message, p, q, g, x):
    """Convert Schnorr to non-interactive signature using hash"""
    r = random.randint(1, q-1)
    t = pow(g, r, p)
    
    # Challenge derived from hash
    c = int(hashlib.sha256(f"{t}{message}".encode()).hexdigest(), 16) % q
    
    s = (r + c * x) % q
    
    return (t, s)

def verify_fiat_shamir(message, signature, p, q, g, y):
    """Verify non-interactive Schnorr signature"""
    t, s = signature
    c = int(hashlib.sha256(f"{t}{message}".encode()).hexdigest(), 16) % q
    
    lhs = pow(g, s, p)
    rhs = (t * pow(y, c, p)) % p
    
    return lhs == rhs

Derived Functors and Homological Algebra

Historical Context: Derived functors emerged from the study of sheaf cohomology in algebraic geometry (Grothendieck, 1957). They provide a systematic way to extend left or right exact functors to full long exact sequences, measuring the "obstruction" to exactness.

Definitions

  • Left Exact Functor: A functor \(F\) preserving kernels: \(0 \to A \to B \to C\) exact implies \(0 \to F(A) \to F(B) \to F(C)\) exact.
  • Injective Resolution: An exact sequence \(0 \to A \to I^0 \to I^1 \to I^2 \to \cdots\) with each \(I^n\) injective.
  • Right Derived Functors: \(R^nF(A) = H^n(F(I^\bullet))\) where \(I^\bullet\) is an injective resolution.
  • Ext: \(Ext^n_R(A,B) = R^nHom_R(A,-)(B)\), measuring extensions of modules.

Theorem (Long Exact Sequence)

For a short exact sequence \(0 \to A' \to A \to A'' \to 0\), there is a natural long exact sequence:

\[0 \to F(A') \to F(A) \to F(A'') \to R^1F(A') \to R^1F(A) \to R^1F(A'') \to R^2F(A') \to \cdots\]

Proof Sketch

  1. Horseshoe Lemma: Given injective resolutions of \(A'\) and \(A''\), construct one for \(A\).
  2. Snake Lemma: Apply to the resulting short exact sequence of complexes.
  3. Cohomology: The connecting homomorphism gives the long exact sequence.

Notation Guide

  • \(R^nF\): n-th right derived functor
  • \(L_nF\): n-th left derived functor
  • \(Ext^n\): derived functor of Hom
  • \(Tor_n\): derived functor of tensor product

Geometric Invariant Theory

Historical Context: Developed by David Mumford in the 1960s, Geometric Invariant Theory (GIT) provides a method for constructing quotients in algebraic geometry. It addresses the fundamental problem: when does the quotient of a variety by a group action exist as an algebraic variety?

Definitions

  • Group Action: An algebraic group \(G\) acts on a variety \(X\) via a morphism \(G \times X \to X\).
  • Invariant Ring: For a linear action of \(G\) on affine space \(\mathbb{A}^n\), the ring of invariants is \(k[x_1, ..., x_n]^G\).
  • Stable Point: A point with finite stabilizer and closed orbit of maximal dimension.
  • Semistable Point: A point for which some invariant polynomial is non-zero.

Theorem (Mumford's GIT)

Let \(G\) be a reductive group acting on a projective variety \(X\) with linearization \(L\). Then:

  1. The set of semistable points \(X^{ss}\) has a categorical quotient \(X^{ss} \to X//G\).
  2. The set of stable points \(X^s\) has a geometric quotient \(X^s \to X^s/G\).

Proof Sketch

  1. Hilbert's 14th Problem: For reductive \(G\), the invariant ring is finitely generated (Nagata, Haboush).
  2. Proj Construction: The quotient is constructed as \(\text{Proj}\) of the invariant ring.
  3. Luna's Slice Theorem: Local structure near stable points ensures the quotient is nice.

Notation Guide

  • \(X//G\): GIT quotient (categorical)
  • \(X^s\): stable locus
  • \(X^{ss}\): semistable locus
  • \(k[X]^G\): invariant ring

Pierre de Fermat and the Birth of Modern Number Theory

Historical Context: Pierre de Fermat (1607-1665) was a French lawyer and mathematician who made foundational contributions to number theory, probability theory, and analytic geometry. Working in isolation and communicating primarily through letters, he stated theorems without proof, challenging future generations of mathematicians.

Key Contributions

  • Fermat's Little Theorem: If \(p\) is prime and \(a\) is not divisible by \(p\), then \(a^{p-1} \equiv 1 \pmod{p}\).
  • Fermat's Last Theorem: The equation \(a^n + b^n = c^n\) has no solutions in positive integers for \(n > 2\) (proven by Wiles, 1994).
  • Method of Infinite Descent: A proof technique showing no minimal counterexample can exist.
  • Fermat Primes: Primes of the form \(2^{2^n} + 1\).

Theorem (Fermat's Little Theorem)

For a prime \(p\) and integer \(a\) with \(p \nmid a\):

\[a^{p-1} \equiv 1 \pmod{p}\]

Proof

Consider the set \(\{a, 2a, 3a, ..., (p-1)a\}\) modulo \(p\). These are all distinct and non-zero, so they are a permutation of \(\{1, 2, ..., p-1\}\). Therefore:

\[a \cdot 2a \cdot 3a \cdots (p-1)a \equiv 1 \cdot 2 \cdot 3 \cdots (p-1) \pmod{p}\]

\[a^{p-1}(p-1)! \equiv (p-1)! \pmod{p}\]

Since \((p-1)!\) is invertible modulo \(p\), we get \(a^{p-1} \equiv 1 \pmod{p}\).

Notation Guide

  • \(a \equiv b \pmod{n}\): congruence modulo \(n\)
  • \(a^{p-1}\): exponentiation
  • \((p-1)!\): factorial

The Sierpiński Triangle and Fractal Geometry

Historical Context: Named after Polish mathematician Wacław Sierpiński (1882-1969), the Sierpiński triangle is one of the most iconic fractals. It appears in diverse contexts: Pascal's triangle modulo 2, the chaos game, cellular automata (Rule 90), and even in the study of percolation.

Definitions

  • Sierpiński Triangle: The attractor of an iterated function system with three contractions, each scaling by 1/2 toward a vertex of an equilateral triangle.
  • Hausdorff Dimension: For the Sierpiński triangle: \(d = \frac{\log 3}{\log 2} \approx 1.585\).
  • Self-Similarity: The set is composed of three copies of itself, each scaled by 1/2.

Theorem (Dimension Formula)

The Hausdorff dimension of the Sierpiński triangle is:

\[\dim_H(S) = \frac{\log 3}{\log 2}\]

Proof

The Sierpiński triangle is the attractor of an IFS with three similitudes, each with ratio \(r = 1/2\). By the Moran formula for self-similar sets:

\[\sum_{i=1}^{3} r^d = 1\]

\[3 \cdot (1/2)^d = 1\]

\[d = \frac{\log 3}{\log 2}\]

Notation Guide

  • \(\dim_H\): Hausdorff dimension
  • \(N\): number of self-similar pieces
  • \(r\): scaling ratio
  • \(IFS\): iterated function system

    """
    Generate Pascal's triangle modulo 2 (Sierpiński pattern).
    """
    # Initialize
    triangle = [[1]]
    
    for i in range(1, n_rows):
        row = [1]
        for j in range(1, i):
            # Pascal's rule mod 2
            val = (triangle[i-1][j-1] + triangle[i-1][j]) % 2
            row.append(val)
        row.append(1)
        triangle.append(row)
    
    # Visualize
    fig, ax = plt.subplots(figsize=(12, 8))
    
    for i, row in enumerate(triangle):
        for j, val in enumerate(row):
            if val == 1:
                x = j - i/2
                y = -i
                ax.plot(x, y, 'bs', markersize=2)
    
    ax.set_aspect('equal')
    ax.axis('off')
    ax.set_title(f"Pascal's Triangle mod 2 ({n_rows} rows)")
    plt.tight_layout()
    plt.savefig('pascal_mod2.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    return triangle

def sierpinski_area(iteration):
    """
    Calculate area of Sierpiński triangle after n iterations.
    Initial area = sqrt(3)/4 (unit side length)
    Each iteration removes 1/4 of remaining area.
    """
    initial = np.sqrt(3) / 4
    return initial * (3/4)**iteration

📜 Math History: The Development of Abstract Algebra

The 19th century witnessed a profound transformation in mathematics: the shift from studying specific objects to studying abstract structures. This revolution, now called "abstract algebra," began with the work of Évariste Galois and culminated in Emmy Noether's axiomatic approach.

The story begins in 1832, when the young Évariste Galois, facing a fatal duel, spent his final night writing down his mathematical ideas. Galois had discovered that the solvability of polynomial equations by radicals depends not on the coefficients themselves, but on the structure of permutations of the roots that preserve algebraic relations. This "Galois group" was the first abstract group to be studied.

Galois's ideas were nearly lost—his manuscripts were rejected by the Paris Academy and only published posthumously by Liouville in 1846. When they finally emerged, mathematicians realized that the same abstract structure appeared in geometry (Klein, 1872), crystallography, and number theory.

By the late 19th century, mathematicians like Cayley, Frobenius, and Burnside were studying groups for their own sake. The concept of an abstract group—defined purely by axioms rather than as a group of permutations or transformations—crystallized around 1890.

The field's modern form owes much to Emmy Noether, who moved to Göttingen in 1915. Noether insisted on an axiomatic approach: rings, ideals, and modules should be defined by their properties, not by their elements. Her famous declaration "Es steht alles schon bei Dedekind" ("It's all already in Dedekind") acknowledged her debt to Richard Dedekind's ideal theory, while her own work went far beyond.

Noether's 1921 paper "Idealtheorie in Ringbereichen" established the foundation of modern commutative algebra. She introduced the ascending chain condition—now called "Noetherian"—and proved that every ideal in a Noetherian ring has a primary decomposition. Her students, including van der Waerden, spread her approach worldwide.

By 1930, when van der Waerden published his "Moderne Algebra," the transformation was complete. Algebra had become the study of structures—groups, rings, fields, modules—defined by axioms and studied through homomorphisms. This abstract approach would soon permeate all of mathematics, from topology to algebraic geometry, creating the modern mathematical landscape we know today.

IMO 2024 Problem 2

Let \(a_1, a_2, a_3, ...\) be an infinite sequence of positive integers. Suppose that for each positive integer \(n\), the number \(a_n\) equals the number of indices \(i\) such that \(a_i \leq n\). Prove that the sequence is uniquely determined and find an explicit formula for \(a_n\).

💡 Hint

Consider the function \(f(n) = a_n\). The condition says that \(f(n) = |\{i : f(i) \leq n\}|\). Try small cases: what is \(f(1)\)? Show that \(f\) must be non-decreasing and find where it jumps.

✅ Solution

Solution:

Let \(f(n) = a_n\). The condition states: \(f(n) = |\{i : f(i) \leq n\}|\).

Step 1: Show \(f\) is non-decreasing.

If \(m < n\), then \(\{i : f(i) \leq m\} \subseteq \{i : f(i) \leq n\}\), so \(f(m) \leq f(n)\).

Step 2: Determine \(f(1)\).

Since \(f(i) \geq 1\) for all \(i\), we have \(\{i : f(i) \leq 1\} = \{i : f(i) = 1\}\).

Let this set have size \(k\). Then \(f(1) = f(2) = ... = f(k) = 1\) and \(f(k+1) > 1\).

But \(f(k) = |\{i : f(i) \leq k\}| = k\) (since \(f(i) = 1 \leq k\) for \(i \leq k\)).

So \(k = 1\), meaning \(f(1) = 1\).

Step 3: Find the pattern.

From \(f(1) = 1\), we get \(|\{i : f(i) \leq 1\}| = 1\), so \(f(2) > 1\).

Since \(f(2) = |\{i : f(i) \leq 2\}|\) and \(f(1) = 1 \leq 2\), we need \(f(2) \geq 2\).

If \(f(2) = 2\), then \(|\{i : f(i) \leq 2\}| = 2\), so \(f(3) > 2\).

Step 4: Prove by induction that \(f(n) = n\) for all \(n\).

Base case: \(f(1) = 1\). ✓

Inductive step: Assume \(f(k) = k\) for all \(k \leq n\).

Then \(\{i : f(i) \leq n\} = \{1, 2, ..., n\}\), so \(f(n) = n\).

And \(f(n+1) = |\{i : f(i) \leq n+1\}| = n+1\) (since \(f(i) = i \leq n+1\) for \(i \leq n+1\)).

Therefore, the unique solution is \(a_n = n\) for all \(n\).

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the iteration \(z_{n+1} = z_n^2 + c\) (starting with \(z_0 = 0\)) remains bounded. Its boundary exhibits infinite complexity—zooming in reveals ever more intricate structures.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    """Compute Mandelbrot iterations for complex number c."""
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

def mandelbrot_set(width=800, height=600, x_min=-2.5, x_max=1.5, 
                    y_min=-1.5, y_max=1.5, max_iter=100):
    """Generate Mandelbrot set image."""
    x = np.linspace(x_min, x_max, width)
    y = np.linspace(y_min, y_max, height)
    X, Y = np.meshgrid(x, y)
    C = X + 1j*Y
    
    M = np.zeros((height, width))
    for i in range(height):
        for j in range(width):
            M[i, j] = mandelbrot(C[i, j], max_iter)
    
    return M

# Generate and display
M = mandelbrot_set(width=800, height=600, max_iter=100)

plt.figure(figsize=(12, 9))
plt.imshow(M, extent=[-2.5, 1.5, -1.5, 1.5], cmap='hot', origin='lower')
plt.colorbar(label='Iterations to escape')
plt.title('The Mandelbrot Set')
plt.xlabel('Re(c)')
