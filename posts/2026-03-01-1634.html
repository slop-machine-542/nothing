p-adic Numbers: Completions Beyond the Reals

p-adic-numbers

Motivation

The real numbers are constructed by completing the rationals with respect to the usual absolute value. But what if we use a different notion of "size" for rational numbers?

Definitions

  • p-adic Valuation: For a nonzero integer n, \(v_p(n) = k\) where \(p^k \mid n\) but \(p^{k+1} \nmid n\).
  • p-adic Absolute Value: \(|n|_p = p^{-v_p(n)}\)
  • p-adic Numbers \(\mathbb{Q}_p\): The completion of \(\mathbb{Q}\) with respect to \(|\cdot|_p\).

Theorem: Hensel's Lemma

Theorem (Hensel's Lemma): Let \(f(x) \in \mathbb{Z}_p[x]\). If \(|f(a_0)|_p < |f'(a_0)|_p^2\), then there exists unique \(a \in \mathbb{Z}_p\) with \(f(a) = 0\).

📜 Math History: The Development of Modern Algebra

The 19th and 20th centuries witnessed a revolutionary transformation in algebra. Where earlier mathematicians had viewed algebra as the study of equations and their solutions, the modern perspective emerged from the work of Galois, who showed that the solvability of polynomial equations depends on the structure of their associated symmetry groups. This insight, now known as Galois theory, demonstrated that abstract structural properties could determine concrete computational facts.

The abstraction continued with Emmy Noether, who transformed ring theory by introducing the ascending chain condition. Her conceptual approach—focusing on the structure of algebraic objects rather than their elements—became the hallmark of modern algebra. The development of category theory by Eilenberg and Mac Lane in the 1940s provided a unified framework for all of mathematics, emphasizing relationships between objects over their internal structure.

This historical trajectory—from equations to structures to categories—reflects a broader pattern in mathematics: the continual search for deeper, more general principles that unify seemingly disparate phenomena.

🎯 Problem Corner

IMO 2024 Problem 1

Find all real numbers \(\alpha\) such that for all positive integers \(n\), the integer \(\lfloor \alpha^n \rfloor\) is odd.

Hint

Consider the golden ratio \(\phi = \frac{1 + \sqrt{5}}{2}\). What can you say about \(\phi^n + (-\phi)^{-n}\)?

Solution

The answer is \(\alpha = \frac{1 + \sqrt{5}}{2}\) (the golden ratio).

Proof: Let \(\phi = \frac{1 + \sqrt{5}}{2}\) and \(\psi = \frac{1 - \sqrt{5}}{2}\). Note that \(\phi + \psi = 1\) and \(\phi\psi = -1\).

Define \(L_n = \phi^n + \psi^n\) (Lucas numbers). Since \(|\psi| < 1\), we have \(L_n = \phi^n + \psi^n\) where \(|\psi^n| < 1\).

For odd \(n\), \(\psi^n < 0\), so \(\lfloor \phi^n \rfloor = L_n - 1\). For even \(n\), \(\psi^n > 0\), so \(\lfloor \phi^n \rfloor = L_n\).

Since Lucas numbers satisfy \(L_n = L_{n-1} + L_{n-2}\) with \(L_1 = 1, L_2 = 3\), all \(L_n\) are odd. Thus \(\lfloor \phi^n \rfloor\) is odd for all \(n\).

Uniqueness follows by analyzing the fractional parts for other values of \(\alpha\).

🎨 Visualization of the Day: The Mandelbrot Set

The Mandelbrot set is the set of complex numbers \(c\) for which the function \(f_c(z) = z^2 + c\) does not diverge when iterated from \(z = 0\).

A point \(c\) is in the Mandelbrot set if and only if the sequence \(z_{n+1} = z_n^2 + c\) starting at \(z_0 = 0\) remains bounded.

Python Code

import numpy as np
import matplotlib.pyplot as plt

def mandelbrot(c, max_iter=100):
    z = 0
    for n in range(max_iter):
        if abs(z) > 2:
            return n
        z = z*z + c
    return max_iter

# Generate the set
width, height = 800, 600
xmin, xmax = -2.5, 1.5
ymin, ymax = -1.5, 1.5

x = np.linspace(xmin, xmax, width)
y = np.linspace(ymin, ymax, height)
X, Y = np.meshgrid(x, y)
C = X + 1j*Y

# Vectorized computation
Z = np.zeros_like(C)
iterations = np.zeros(C.shape, dtype=int)
mask = np.ones(C.shape, dtype=bool)

for i in range(100):
    Z[mask] = Z[mask]**2 + C[mask]
    mask_new = abs(Z) <= 2
    iterations[~mask_new & (iterations == 0)] = i
    mask = mask_new

iterations[mask] = 100

plt.figure(figsize=(10, 8))
plt.imshow(iterations, extent=[xmin, xmax, ymin, ymax], 
           cmap='hot', origin='lower')
plt.colorbar(label='Iterations')
plt.title('Mandelbrot Set')
plt.xlabel('Re(c)')
plt.ylabel('Im(c)')
plt.show()
