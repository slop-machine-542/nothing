Algebraic Number Theory: The Structure of Algebraic Integers

algebraic-number-theory

Motivation

Algebraic number theory emerged from attempts to prove Fermat's Last Theorem and understand deep properties of the integers. By studying number fields—finite extensions of the rational numbers—mathematicians discovered that unique factorization, which fails in general rings of integers, can be restored by working with ideals. This insight, pioneered by Kummer, Dedekind, and Kronecker, transformed number theory and laid the foundation for modern algebraic geometry and class field theory.

Definitions

  • Number Field: A finite field extension \(K/\mathbb{Q}\). Its degree is \([K:\mathbb{Q}] = \dim_{\mathbb{Q}} K\).
  • Ring of Integers: For a number field \(K\), the ring \(\mathcal{O}_K = \{x \in K : x \text{ is integral over } \mathbb{Z}\}\).
  • Integral Element: An element \(x\) is integral over \(\mathbb{Z}\) if it satisfies a monic polynomial with integer coefficients.
  • Ideal Class Group: The group \(\text{Cl}(K) = \text{Frac}(\mathcal{O}_K)/\text{Princ}(\mathcal{O}_K)\), measuring the failure of unique factorization.
  • Discriminant: For a basis \(\{\alpha_1, \ldots, \alpha_n\}\) of \(K/\mathbb{Q}\), \(\Delta_K = \det(\text{Tr}_{K/\mathbb{Q}}(\alpha_i\alpha_j))\).

Theorem: Finiteness of the Class Number

Theorem: For any number field \(K\), the ideal class group \(\text{Cl}(K)\) is a finite abelian group.

Proof Sketch:

  1. Every ideal class contains an integral ideal with norm bounded by the Minkowski bound:

\[ M_K = \frac{n!}{n^n}\left(\frac{4}{\pi}\right)^{r_2}\sqrt{|\Delta_K|} \]

  1. There are only finitely many ideals with bounded norm, as this bounds the prime ideals that can appear in their factorization.
  2. Since every class is represented by one of these finitely many ideals, the class group is finite.

Notation Guide

  • \(K/\mathbb{Q}\): Number field (finite extension)
  • \(\mathcal{O}_K\): Ring of integers of \(K\)
  • \(\mathfrak{p}, \mathfrak{q}\): Prime ideals (typically)
  • \(N(\mathfrak{a}) = [\mathcal{O}_K : \mathfrak{a}]\): Ideal norm
  • \(\text{Cl}(K)\): Ideal class group
  • \(r_1, r_2\): Number of real and complex embeddings
  • \(\Delta_K\): Discriminant of \(K\)

Functional Analysis: The Spectral Theorem for Bounded Operators

functional-analysis

Motivation

Functional analysis extends the methods of linear algebra to infinite-dimensional spaces, providing the mathematical foundation for quantum mechanics, partial differential equations, and signal processing. The spectral theorem, generalizing the diagonalization of Hermitian matrices, reveals that self-adjoint operators on Hilbert spaces can be "diagonalized" via projection-valued measures. This perspective, developed by Hilbert, von Neumann, and Stone, transformed our understanding of operators and their applications.

Definitions

  • Hilbert Space: A complete inner product space \(\mathcal{H}\) over \(\mathbb{C}\) (or \(\mathbb{R}\)).
  • Bounded Operator: A linear map \(T: \mathcal{H} \to \mathcal{H}\) with finite operator norm \(\|T\| = \sup_{\|x\|=1}\|Tx\|\).
  • Adjoint: The unique operator \(T^*\) satisfying \(\langle Tx, y \rangle = \langle x, T^*y \rangle\).
  • Self-Adjoint: \(T = T^*\), generalizing Hermitian matrices.
  • Spectrum: \(\sigma(T) = \{\lambda \in \mathbb{C} : T - \lambda I \text{ is not invertible}\}\).
  • Projection-Valued Measure: A measure \(E\) on \(\mathbb{R}\) taking values in orthogonal projections.

Theorem: Spectral Theorem for Bounded Self-Adjoint Operators

Theorem: Let \(T\) be a bounded self-adjoint operator on a Hilbert space \(\mathcal{H}\). Then there exists a unique projection-valued measure \(E\) on \(\sigma(T)\) such that:

\[ T = \int_{\sigma(T)} \lambda \, dE(\lambda) \]

Moreover, for any continuous function \(f\) on \(\sigma(T)\):

\[ f(T) = \int_{\sigma(T)} f(\lambda) \, dE(\lambda) \]

Proof Outline

  1. Define the continuous functional calculus: for \(f \in C(\sigma(T))\), define \(f(T)\) via polynomial approximation.
  2. Use the Riesz representation theorem to obtain the spectral measure \(E\).
  3. Verify that \(E\) satisfies the properties of a projection-valued measure.
  4. Show the integral representation holds and is unique.

Notation Guide

  • \(\mathcal{H}\): Hilbert space
  • \(\mathcal{B}(\mathcal{H})\): Space of bounded operators
  • \(T^*\): Adjoint of \(T\)
  • \(\sigma(T)\): Spectrum of \(T\)
  • \(E(\Delta)\): Spectral projection for Borel set \(\Delta\)
  • \(\langle \cdot, \cdot \rangle\): Inner product

import numpy as np
from scipy.linalg import eigh, expm

class SpectralTheorem:
    """Demonstrate spectral theorem for finite-dimensional case."""
    
    @staticmethod
    def spectral_decomposition(A):
        """
        Compute spectral decomposition A = Σ λᵢ Pᵢ
        Returns eigenvalues and projection matrices.
        """
        # For Hermitian matrices, eigenvalues are real
        eigenvalues, eigenvectors = eigh(A)
        
        n = A.shape[0]
        projections = []
        
        for i, lam in enumerate(eigenvalues):
            # Projection onto eigenspace: Pᵢ = vᵢ vᵢ*
            v = eigenvectors[:, i:i+1]
            P = v @ v.conj().T
            projections.append(P)
        
        return eigenvalues, projections, eigenvectors
    
    @staticmethod
    def functional_calculus(A, f):
        """
        Compute f(A) using spectral theorem.
        f: function to apply to eigenvalues
        """
        eigenvalues, eigenvectors = eigh(A)
        # f(A) = V diag(f(λ)) V*
        f_eigenvalues = np.array([f(lam) for lam in eigenvalues])
        return eigenvectors @ np.diag(f_eigenvalues) @ eigenvectors.conj().T
    
    @staticmethod
    def verify_decomposition(A):
        """Verify A = Σ λᵢ Pᵢ."""
        eigenvalues, projections, _ = SpectralTheorem.spectral_decomposition(A)
        reconstruction = sum(lam * P for lam, P in zip(eigenvalues, projections))
        return np.allclose(A, reconstruction)

Algebraic Topology: Cohomology and the Universal Coefficient Theorem

algebraic-topology

Motivation

Cohomology emerged as a natural dual to homology, providing a ring structure through the cup product that makes it a finer invariant. The universal coefficient theorem reveals the relationship between homology and cohomology, showing that cohomology is determined by homology together with the Ext functor. This connection, developed by Eilenberg and MacLane, is fundamental to understanding the algebraic structure of topological spaces.

Definitions

  • Cochain Complex: A sequence \(C^* = \{C^n, \delta^n\}\) with coboundary maps \(\delta^n: C^n \to C^{n+1}\) satisfying \(\delta^{n+1} \circ \delta^n = 0\).
  • Cohomology: \(H^n(C^*) = \ker(\delta^n) / \text{im}(\delta^{n-1})\).
  • Singular Cohomology: \(H^n(X; G) = H^n(\text{Hom}(C_*(X), G))\) for an abelian group \(G\).
  • Cup Product: A map \(\smile: H^p(X) \times H^q(X) \to H^{p+q}(X)\) making cohomology a graded ring.
  • Ext Functor: \(\text{Ext}_R^n(A, B)\) measures the failure of \(\text{Hom}_R(-, B)\) to be exact.

Theorem: Universal Coefficient Theorem for Cohomology

Theorem: For a topological space \(X\) and abelian group \(G\), there is a natural short exact sequence:

\[ 0 \to \text{Ext}(H_{n-1}(X), G) \to H^n(X; G) \to \text{Hom}(H_n(X), G) \to 0 \]

This sequence splits (non-canonically), giving:

\[ H^n(X; G) \cong \text{Hom}(H_n(X), G) \oplus \text{Ext}(H_{n-1}(X), G) \]

Proof Sketch

  1. Start with the chain complex \(C_*(X)\) of singular chains.
  2. Apply \(\text{Hom}(-, G)\) to get the cochain complex \(C^*(X; G)\).
  3. Use the algebraic universal coefficient theorem for chain complexes.
  4. The key is that \(\text{Hom}(-, G)\) is left exact but not right exact; the Ext term corrects for this.

Notation Guide

  • \(H_n(X)\): nth singular homology group
  • \(H^n(X; G)\): nth cohomology with coefficients in \(G\)
  • \(\delta\): Coboundary operator
  • \(\smile\): Cup product
  • \(\text{Ext}(A, B)\): Extension functor
  • \(C^*(X)\): Singular cochain complex

import numpy as np
from itertools import combinations

class SimplicialCohomology:
    """Compute simplicial cohomology for small complexes."""
    
    def __init__(self, simplices):
        """
        simplices: list of simplices, each as sorted tuple of vertices
        """
        self.simplices = [set(s) for s in simplices]
        self.max_dim = max(len(s) for s in simplices) - 1 if simplices else 0
        
    def chain_groups(self):
        """Return chain groups C_n (as lists of n-simplices)."""
        groups = [[] for _ in range(self.max_dim + 1)]
        for s in self.simplices:
            dim = len(s) - 1
            if dim >= 0:
                groups[dim].append(tuple(sorted(s)))
        return groups
    
    def boundary_matrix(self, n):
        """Compute boundary matrix ∂_n: C_n → C_{n-1}."""
        if n == 0:
            return np.zeros((1, len(self.chain_groups()[0])))
        
        n_simplices = self.chain_groups()[n]
        n_minus_1 = self.chain_groups()[n-1]
        
        if not n_simplices or not n_minus_1:
            return np.zeros((len(n_minus_1), len(n_simplices)))
        
        # Create index map
        idx_map = {s: i for i, s in enumerate(n_minus_1)}
        
        mat = np.zeros((len(n_minus_1), len(n_simplices)), dtype=int)
        for j, sigma in enumerate(n_simplices):
            for i in range(len(sigma)):
                # i-th face
                face = tuple(sigma[k] for k in range(len(sigma)) if k != i)
                if face in idx_map:
                    mat[idx_map[face], j] += (-1)**i
        return mat
    
    def cohomology_dim(self, n, field=2):
        """Compute dim H^n over given field (simplified)."""
        if n > self.max_dim:
            return 0
        
        d_n = self.boundary_matrix(n)
        d_n_plus_1 = self.boundary_matrix(n + 1) if n < self.max_dim else np.zeros((0, 0))
        
        # H^n = ker(d_{n+1}^T) / im(d_n^T)
        # dim H^n = dim ker(d_{n+1}^T) - dim im(d_n^T)
        
        rank_d_n = np.linalg.matrix_rank(d_n) if d_n.size > 0 else 0
        rank_d_n_plus_1 = np.linalg.matrix_rank(d_n_plus_1) if d_n_plus_1.size > 0 else 0
        
        dim_C_n = d_n.shape[0] if d_n.size > 0 else (d_n_plus_1.shape[1] if d_n_plus_1.size > 0 else 0)
        dim_ker = dim_C_n - rank_d_n_plus_1
        
        return dim_ker - rank_d_n

Numerical Analysis: Spectral Methods for Differential Equations

numerical-analysis

Real-World Motivation

Spectral methods provide exponentially accurate solutions to differential equations, making them indispensable for high-precision simulations in fluid dynamics, quantum mechanics, and weather prediction. Unlike finite difference methods that converge polynomially, spectral methods leverage global basis functions (Fourier, Chebyshev, Legendre) to achieve spectral convergence—error decays faster than any polynomial rate for smooth solutions. NASA's climate models, aircraft design simulations, and fusion energy research all rely on these techniques.

Definitions

  • Spectral Approximation: Approximating a function \(u(x)\) by a truncated series \(u_N(x) = \sum_{k=0}^{N} \hat{u}_k \phi_k(x)\).
  • Chebyshev Polynomials: \(T_n(x) = \cos(n \arccos x)\) for \(x \in [-1, 1]\), orthogonal with weight \((1-x^2)^{-1/2}\).
  • Gauss-Lobatto Points: Nodes \(x_j = \cos(\pi j/N)\) for \(j = 0, \ldots, N\), optimal for polynomial interpolation.
  • Spectral Convergence: Error \(\|u - u_N\| = O(N^{-m})\) for all \(m > 0\) (for smooth \(u\)).
  • Aliasing Error: Error from discretizing nonlinear terms on a finite grid.

Theorem: Spectral Accuracy of Chebyshev Interpolation

Theorem: Let \(u \in C^k([-1,1])\) have \(k\) continuous derivatives, and let \(I_N u\) be its Chebyshev interpolant at Gauss-Lobatto points. Then:

\[ \|u - I_N u\|_{L^\infty} \leq C N^{1/2-k} \|u^{(k)}\|_{L^2} \]

If \(u\) is analytic in a neighborhood of \([-1,1]\), the convergence is exponential:

\[ \|u - I_N u\|_{L^\infty} \leq C \rho^{-N} \]

for some \(\rho > 1\) depending on the size of the analyticity region.

Notation Guide

  • \(T_n(x)\): nth Chebyshev polynomial
  • \(\hat{u}_k\): Spectral coefficient
  • \(I_N u\): Degree-\(N\) interpolant of \(u\)
  • \(D_{ij}\): Spectral differentiation matrix
  • \(x_j = \cos(\pi j/N)\): Chebyshev nodes

import numpy as np
from numpy.polynomial.chebyshev import chebfit, chebval, chebdiff
import matplotlib.pyplot as plt

class SpectralMethods:
    """Spectral methods for differential equations."""
    
    @staticmethod
    def chebyshev_nodes(N):
        """Gauss-Lobatto Chebyshev nodes on [-1, 1]."""
        return np.cos(np.pi * np.arange(N + 1) / N)
    
    @staticmethod
    def chebyshev_differentiation_matrix(N):
        """
        Compute Chebyshev differentiation matrix D.
        D @ u gives du/dx at the nodes.
        """
        x = SpectralMethods.chebyshev_nodes(N)
        c = np.ones(N + 1)
        c[0] = 2
        c[N] = 2
        
        X = np.tile(x, (N + 1, 1))
        dX = X - X.T
        
        D = (c[:, None] / c[None, :]) / (dX + np.eye(N + 1))
        D = D - np.diag(D.sum(axis=1))
        
        return D
    
    @staticmethod
    def solve_bvp_spectral(f_func, N=32):
        """
        Solve u'' = f(x) on [-1, 1] with u(-1) = u(1) = 0.
        """
        x = SpectralMethods.chebyshev_nodes(N)
        D = SpectralMethods.chebyshev_differentiation_matrix(N)
        D2 = D @ D  # Second derivative matrix
        
        # Right-hand side
        f = f_func(x)
        
        # Apply boundary conditions: u(-1) = u(1) = 0
        # Modify first and last rows
        A = D2.copy()
        A[0, :] = 0
        A[0, 0] = 1  # u(-1) = 0
        A[N, :] = 0
        A[N, N] = 1  # u(1) = 0
        
        f[0] = 0
        f[N] = 0
        
        u = np.linalg.solve(A, f)
        return x, u
    
    @staticmethod
    def spectral_convergence_test(u_exact, N_values):
        """Test spectral convergence for interpolation."""
        errors = []
        for N in N_values:
            x = SpectralMethods.chebyshev_nodes(N)
            u = u_exact(x)
            
            # Chebyshev coefficients
            coeffs = np.polynomial.chebyshev.chebfit(x, u, N)
            
            # Evaluate at fine grid
            x_fine = np.linspace(-1, 1, 1000)
            u_interp = np.polynomial.chebyshev.chebval(x_fine, coeffs)
            u_true = u_exact(x_fine)
            
            error = np.max(np.abs(u_interp - u_true))
            errors.append(error)
        
        return errors

# Example: Solve u'' = -π² sin(πx) with exact solution u = sin(πx)

Bayesian Statistics: The Conjugate Prior Framework

bayesian-statistics

Real-World Motivation

Bayesian statistics provides a coherent framework for updating beliefs in light of evidence, with applications ranging from medical diagnosis to machine learning and financial forecasting. The conjugate prior framework offers analytical tractability: when the prior and likelihood are conjugate, the posterior has the same form as the prior. This elegance, pioneered by Bayes and Laplace, underpins modern probabilistic AI systems including spam filters, recommendation engines, and self-driving car perception.

Definitions

  • Prior Distribution \(p(\theta)\): Beliefs about parameters before observing data.
  • Likelihood \(p(x|\theta)\): Probability of data given parameters.
  • Posterior \(p(\theta|x)\): Updated beliefs via Bayes' theorem:

\[ p(\theta|x) = \frac{p(x|\theta)p(\theta)}{p(x)} \]

  • Conjugate Prior: A prior where posterior and prior belong to the same family.
  • Beta Distribution: Conjugate prior for binomial likelihood: \(\text{Beta}(\theta; \alpha, \beta) \propto \theta^{\alpha-1}(1-\theta)^{\beta-1}\).
  • Dirichlet Distribution: Conjugate prior for multinomial likelihood.

Theorem: Beta-Binomial Conjugacy

Theorem: Let \(\theta \sim \text{Beta}(\alpha, \beta)\) be the prior and \(X|\theta \sim \text{Binomial}(n, \theta)\) be the likelihood. Then the posterior is:

\[ \theta|X=k \sim \text{Beta}(\alpha + k, \beta + n - k) \]

Proof: By Bayes' theorem:

\[ p(\theta|k) \propto p(k|\theta)p(\theta) \propto \theta^k(1-\theta)^{n-k} \cdot \theta^{\alpha-1}(1-\theta)^{\beta-1} = \theta^{\alpha+k-1}(1-\theta)^{\beta+n-k-1} \]

This is the kernel of \(\text{Beta}(\alpha + k, \beta + n - k)\). ∎

Notation Guide

  • \(\theta\): Parameter (often probability)
  • \(\alpha, \beta\): Beta distribution parameters
  • \(p(\theta)\): Prior density
  • \(p(\theta|x)\): Posterior density
  • \(\propto\): Proportional to
  • \(\mathbb{E}[\theta|x]\): Posterior mean

import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

class BayesianInference:
    """Bayesian inference with conjugate priors."""
    
    @staticmethod
    def beta_binomial_update(alpha_prior, beta_prior, k_successes, n_trials):
        """
        Update Beta prior with Binomial likelihood.
        
        Parameters:
        -----------
        alpha_prior, beta_prior : float
            Beta prior parameters
        k_successes, n_trials : int
            Observed data
            
        Returns:
        --------
        alpha_post, beta_post : float
            Beta posterior parameters
        """
        alpha_post = alpha_prior + k_successes
        beta_post = beta_prior + n_trials - k_successes
        return alpha_post, beta_post
    
    @staticmethod
    def posterior_predictive_beta_binomial(alpha, beta, n_new):
        """
        Posterior predictive: P(X_new = k | data).
        This is the Beta-Binomial distribution.
        """
        from scipy.special import comb, beta as beta_func
        k_values = np.arange(n_new + 1)
        probs = np.array([
            comb(n_new, k) * beta_func(alpha + k, beta + n_new - k) / beta_func(alpha, beta)
            for k in k_values
        ])
        return k_values, probs
    
    @staticmethod
    def credible_interval(alpha, beta, level=0.95):
        """Compute credible interval for Beta distribution."""
        lower = stats.beta.ppf((1 - level) / 2, alpha, beta)
        upper = stats.beta.ppf((1 + level) / 2, alpha, beta)
        return lower, upper

Optimization Theory: Convex Optimization and Duality

optimization-theory

Real-World Motivation

Convex optimization provides the mathematical foundation for modern machine learning, signal processing, and engineering design. Unlike general optimization problems that may have spurious local minima, convex problems guarantee that any local minimum is global. This property, combined with efficient algorithms capable of solving problems with millions of variables, makes convex optimization indispensable for training support vector machines, portfolio optimization, and control system design. Companies like Google, Netflix, and Tesla rely on these techniques daily.

Definitions

  • Convex Set: \(C\) is convex if \(x, y \in C \Rightarrow \lambda x + (1-\lambda)y \in C\) for all \(\lambda \in [0,1]\).
  • Convex Function: \(f\) is convex if \(f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)\).
  • Convex Optimization Problem:

\[ \begin{aligned} \text{minimize} \quad & f_0(x) \\ \text{subject to} \quad & f_i(x) \leq 0, \quad i = 1, \ldots, m \\ & h_j(x) = 0, \quad j = 1, \ldots, p \end{aligned} \]

where \(f_0, f_1, \ldots, f_m\) are convex and \(h_j\) are affine.

  • Lagrangian: \(L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)\).

Theorem: Strong Duality for Convex Problems

Theorem (Strong Duality): For a convex optimization problem satisfying Slater's condition (existence of a strictly feasible point), the optimal primal value \(p^*\) equals the optimal dual value \(d^*\):

\[ p^* = d^* \]

where the dual problem is:

\[ d^* = \sup_{\lambda \geq 0, \nu} \inf_x L(x, \lambda, \nu) \]

KKT Conditions

For convex problems with strong duality, the following are necessary and sufficient for optimality:

  1. Primal feasibility: \(f_i(x) \leq 0\), \(h_j(x) = 0\)
  2. Dual feasibility: \(\lambda_i \geq 0\)
  3. Complementary slackness: \(\lambda_i f_i(x) = 0\)
  4. Stationarity: \(\nabla f_0(x) + \sum \lambda_i \nabla f_i(x) + \sum \nu_j \nabla h_j(x) = 0\)

Notation Guide

  • \(f_0(x)\): Objective function
  • \(f_i(x) \leq 0\): Inequality constraints
  • \(h_j(x) = 0\): Equality constraints
  • \(\lambda_i\): Lagrange multipliers for inequalities
  • \(\nu_j\): Lagrange multipliers for equalities
  • \(L(x, \lambda, \nu)\): Lagrangian
  • \(p^*, d^*\): Primal and dual optimal values

import numpy as np
from scipy.optimize import minimize
import cvxpy as cp

class ConvexOptimization:
    """Convex optimization examples and solvers."""
    
    @staticmethod
    def quadratic_program(Q, q, G=None, h=None, A=None, b=None):
        """
        Solve: minimize 0.5*x'*Q*x + q'*x
               subject to Gx <= h, Ax = b
        """
        n = Q.shape[0]
        x = cp.Variable(n)
        
        objective = cp.Minimize(0.5 * cp.quad_form(x, Q) + q.T @ x)
        
        constraints = []
        if G is not None and h is not None:
            constraints.append(G @ x <= h)
        if A is not None and b is not None:
            constraints.append(A @ x == b)
        
        problem = cp.Problem(objective, constraints)
        result = problem.solve()
        
        return x.value, result, problem.status
    
    @staticmethod
    def lasso_regression(X, y, lambda_reg):
        """
        LASSO: minimize ||Xw - y||^2 + lambda*||w||_1
        """
        n_features = X.shape[1]
        w = cp.Variable(n_features)
        
        objective = cp.Minimize(
            cp.sum_squares(X @ w - y) + lambda_reg * cp.norm(w, 1)
        )
        
        problem = cp.Problem(objective)
        result = problem.solve()
        
        return w.value, result
    
    @staticmethod
    def verify_kkt(Q, q, G, h, x_opt, lambda_opt):
        """Verify KKT conditions for QP."""
        # Stationarity: Qx + q + G^T lambda = 0
        stationarity = Q @ x_opt + q + G.T @ lambda_opt
        
        # Primal feasibility: Gx <= h
        primal_feas = np.all(G @ x_opt <= h + 1e-6)
        
        # Dual feasibility: lambda >= 0
        dual_feas = np.all(lambda_opt >= -1e-6)
        
        # Complementary slackness: lambda * (Gx - h) = 0
        slack = G @ x_opt - h
        comp_slack = np.allclose(lambda_opt * slack, 0, atol=1e-6)
        
        return {
            'stationarity': np.allclose(stationarity, 0, atol=1e-6),
            'primal_feasibility': primal_feas,
            'dual_feasibility': dual_feas,
            'complementary_slackness': comp_slack
        }

Representation Theory: Characters and the Peter-Weyl Theorem

representation-theory

Historical Context

Representation theory emerged from Frobenius's work on group determinants in the 1890s, providing a bridge between abstract groups and linear algebra. The theory was revolutionized by Schur's lemma and the development of character theory, which allows the decomposition of representations into irreducibles using only their traces. The Peter-Weyl theorem (1927) extended these ideas to compact groups, laying the foundation for harmonic analysis on groups and applications in quantum mechanics.

Definitions

  • Representation: A homomorphism \(\rho: G \to \text{GL}(V)\) where \(V\) is a vector space.
  • Character: \(\chi_\rho(g) = \text{tr}(\rho(g))\), a class function on \(G\).
  • Irreducible Representation: A representation with no nontrivial invariant subspaces.
  • Regular Representation: The action of \(G\) on \(L^2(G)\) by left translation.
  • Peter-Weyl Theorem: The matrix coefficients of irreducible representations form an orthonormal basis for \(L^2(G)\).

Theorem: Orthogonality of Characters

Theorem: For a finite group \(G\) with irreducible characters \(\chi_i\):

\[ \frac{1}{|G|} \sum_{g \in G} \chi_i(g) \overline{\chi_j(g)} = \delta_{ij} \]

Corollary: The number of irreducible representations equals the number of conjugacy classes.

Notation Guide

  • \(\rho: G \to \text{GL}(V)\): Representation
  • \(\chi_\rho\): Character of \(\rho\)
  • \(\hat{G}\): Set of irreducible representations
  • \(V^G\): Invariant subspace
  • \(L^2(G)\): Square-integrable functions on \(G\)

import numpy as np
from itertools import permutations

class RepresentationTheory:
    """Basic representation theory computations."""
    
    @staticmethod
    def regular_representation_matrix(g, n):
        """
        Matrix of left regular representation for permutation g in S_n.
        """
        # List all permutations
        all_perms = list(permutations(range(n)))
        perm_to_idx = {p: i for i, p in enumerate(all_perms)}
        
        N = len(all_perms)
        mat = np.zeros((N, N))
        
        for i, h in enumerate(all_perms):
            # Left multiplication: g * h
            gh = tuple(g[h[j]] for j in range(n))
            j = perm_to_idx[gh]
            mat[j, i] = 1
        
        return mat
    
    @staticmethod
    def character(rep_matrix):
        """Compute character (trace) of representation matrix."""
        return np.trace(rep_matrix)
    
    @staticmethod
    def is_irreducible(char, G_order, class_sizes):
        """
        Check if character is irreducible using orthogonality.
        For irreducible:  = 1
        """
        inner_product = sum(char[g]**2 for g in range(G_order)) / G_order
        return np.isclose(inner_product, 1.0)
    
    @staticmethod
    def fourier_transform_on_group(f, irreps):
        """
        Compute Fourier transform of function f on group G.
        f_hat(rho) = sum_g f(g) * rho(g)
        """
        transforms = {}
        for name, rho in irreps.items():
            G_size = len(rho)
            f_hat = sum(f[g] * rho[g] for g in range(G_size))
            transforms[name] = f_hat
        return transforms

Dynamical Systems: The Poincaré-Bendixson Theorem

dynamical-systems

Historical Context

The study of dynamical systems began with Newton's laws of motion, but the qualitative theory was pioneered by Poincaré in the late 19th century. Working on the three-body problem, Poincaré discovered that even simple deterministic systems can exhibit chaotic behavior. The Poincaré-Bendixson theorem, completed by Bendixson in 1901, provides one of the few general results about the long-term behavior of nonlinear systems in two dimensions, excluding chaos in planar flows.

Definitions

  • Dynamical System: A flow \(\phi_t: X \to X\) on a space \(X\) satisfying \(\phi_0 = \text{id}\) and \(\phi_{s+t} = \phi_s \circ \phi_t\).
  • \(\omega\)-Limit Set: For a trajectory \(\gamma\), \(\omega(\gamma) = \bigcap_{t \geq 0} \overline{\gamma([t, \infty))}\).
  • Fixed Point: \(x_0\) with \(\phi_t(x_0) = x_0\) for all \(t\).
  • Periodic Orbit: A trajectory \(\gamma\) with \(\gamma(t+T) = \gamma(t)\) for some \(T > 0\).
  • Planar Flow: A dynamical system on \(\mathbb{R}^2\) (or a 2D manifold).

Theorem: Poincaré-Bendixson

Theorem: Let \(\gamma^+\) be a positive semi-orbit of a \(C^1\) flow on \(\mathbb{R}^2\) that remains in a compact set. If \(\omega(\gamma^+)\) contains no fixed points, then \(\omega(\gamma^+)\) is a periodic orbit.

Corollary: In two dimensions, bounded trajectories approach either a fixed point, a periodic orbit, or a graph of fixed points connected by heteroclinic orbits.

Notation Guide

  • \(\phi_t(x)\): Flow at time \(t\) starting from \(x\)
  • \(\omega(\gamma)\): \(\omega\)-limit set
  • \(\dot{x} = f(x)\): Autonomous ODE
  • \(\nabla \cdot f\): Divergence
  • \(W^s(x_0), W^u(x_0)\): Stable and unstable manifolds

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

class DynamicalSystems:
    """Analysis of dynamical systems."""
    
    @staticmethod
    def van_der_pol(x, t, mu=1.0):
        """
        Van der Pol oscillator: classic example for Poincaré-Bendixson.
        x'' - mu*(1-x^2)*x' + x = 0
        """
        x1, x2 = x
        dx1 = x2
        dx2 = mu * (1 - x1**2) * x2 - x1
        return [dx1, dx2]
    
    @staticmethod
    def integrate_system(f, x0, t_span, args=()):
        """Integrate ODE system."""
        sol = odeint(f, x0, t_span, args=args)
        return sol
    
    @staticmethod
    def find_limit_cycle(f, x0_guess, t_max=100, tol=1e-6):
        """
        Find limit cycle by integrating and checking for periodicity.
        """
        t = np.linspace(0, t_max, 10000)
        sol = odeint(f, x0_guess, t)
        
        # Check if trajectory returns close to start
        for i in range(len(t)//2, len(t)):
            if np.linalg.norm(sol[i] - sol[0]) < tol:
                period = t[i]
                return sol[:i], period
        return sol, None
    
    @staticmethod
    def poincare_map(f, x0, section_func, t_max=100, n_crossings=10):
        """
        Compute Poincaré map on a section.
        section_func(x) = 0 defines the section.
        """
        t = np.linspace(0, t_max, 10000)
        sol = odeint(f, x0, t)
        
        # Find crossings
        section_values = np.array([section_func(x) for x in sol])
        crossings = []
        for i in range(len(section_values)-1):
            if section_values[i] < 0 and section_values[i+1] >= 0:
                crossings.append(sol[i+1])
        
        return np.array(crossings[:n_crossings])

Category Theory: Limits, Colimits, and Universal Properties

category-theory

Historical Context

Category theory was invented by Eilenberg and MacLane in 1945 to formalize the notion of "natural" transformations in algebraic topology. The theory quickly revealed deep structural connections across mathematics—products in sets, intersections in topology, and direct sums in linear algebra are all instances of limits. Grothendieck's work in algebraic geometry and Lawvere's in logic demonstrated that category theory provides a universal language for mathematics, unifying concepts that appear unrelated in concrete settings.

Definitions

  • Category \(\mathcal{C}\): Objects and morphisms with composition and identity.
  • Functor \(F: \mathcal{C} \to \mathcal{D}\): Structure-preserving map between categories.
  • Natural Transformation: A family of morphisms \(\alpha_X: F(X) \to G(X)\) compatible with the functors.
  • Limit: Universal cone over a diagram \(D: \mathcal{J} \to \mathcal{C}\).
  • Colimit: Universal cocone under a diagram.
  • Universal Property: A characterization of an object by its relationship to all other objects.

Theorem: Limits are Unique up to Isomorphism

Theorem: If \((L, \pi_j)\) and \((L', \pi'_j)\) are both limits of a diagram \(D: \mathcal{J} \to \mathcal{C}\), then there exists a unique isomorphism \(f: L \to L'\) such that \(\pi'_j \circ f = \pi_j\) for all \(j\).

Proof: By the universal property of limits, there exist unique morphisms \(f: L \to L'\) and \(g: L' \to L\) making the appropriate diagrams commute. The composition \(g \circ f: L \to L\) satisfies the same universal property as \(\text{id}_L\), so by uniqueness, \(g \circ f = \text{id}_L\). Similarly \(f \circ g = \text{id}_{L'}\). ∎

Notation Guide

  • \(\mathcal{C}, \mathcal{D}\): Categories
  • \(\text{Ob}(\mathcal{C})\): Objects of \(\mathcal{C}\)
  • \(\text{Hom}_{\mathcal{C}}(X, Y)\): Morphisms from \(X\) to \(Y\)
  • \(F: \mathcal{C} \to \mathcal{D}\): Functor
  • \(\alpha: F \Rightarrow G\): Natural transformation
  • \(\varprojlim D\): Limit of diagram \(D\)
  • \(\varinjlim D\): Colimit of diagram \(D\)

from typing import TypeVar, Generic, Callable, List
from dataclasses import dataclass

# Category theory concepts in Python (simplified)

T = TypeVar('T')
U = TypeVar('U')
V = TypeVar('V')

class CategoryTheory:
    """Demonstrate category theory concepts using Python types."""
    
    @staticmethod
    def product_projection(A: T, B: U) -> tuple:
        """
        Product A × B with projections π₁ and π₂.
        Universal property: given f: C → A and g: C → B,
        there exists unique : C → A × B.
        """
        class Product:
            def __init__(self, a: T, b: U):
                self.fst = a  # π₁
                self.snd = b  # π₂
            
            @staticmethod
            def universal(f: Callable[[V], T], g: Callable[[V], U]) -> Callable[[V], tuple]:
                """Universal morphism : C → A × B."""
                def pair(c: V) -> tuple:
                    return (f(c), g(c))
                return pair
        
        return Product
    
    @staticmethod
    def coproduct_injection(A: T, B: U) -> type:
        """
        Coproduct A + B (disjoint union) with injections i₁ and i₂.
        Universal property: given f: A → C and g: B → C,
        there exists unique [f,g]: A + B → C.
        """
        from typing import Union
        
        class Coproduct:
            @staticmethod
            def inl(a: T) -> Union[T, U]:
                return ('left', a)
            
            @staticmethod
            def inr(b: U) -> Union[T, U]:
                return ('right', b)
            
            @staticmethod
            def universal(f: Callable[[T], V], g: Callable[[U], V]) -> Callable[[Union[T, U]], V]:
                """Universal morphism [f, g]: A + B → C."""
                def case(x: Union[T, U]) -> V:
                    tag, val = x
                    return f(val) if tag == 'left' else g(val)
                return case
        
        return Coproduct
    
    @staticmethod
    def pullback(f: Callable[[T], V], g: Callable[[U], V]) -> type:
        """
        Pullback of f: A → C and g: B → C.
        P = {(a,b) : f(a) = g(b)}
        """
        @dataclass
        class Pullback:
            first: T
            second: U
            
            def __post_init__(self):
                # Verify pullback condition
                if f(self.first) != g(self.second):
                    raise ValueError("Pullback condition violated")
        
        return Pullback
    
    @staticmethod
    def natural_transformation_example():
        """
        Example: List is a functor from Set to Set.
        reverse: List → List is a natural transformation.
        """
        def list_functor_map(f: Callable[[T], U], lst: List[T]) -> List[U]:
            """Functorial action: map f over list."""
            return [f(x) for x in lst]
        
        def reverse_nat_trans(lst: List[T]) -> List[T]:
            """Natural transformation: reverse list."""
            return lst[::-1]
        
        # Naturality condition: reverse(fmap f xs) = fmap f (reverse xs)
        f = lambda x: x * 2
        xs = [1, 2, 3]
        
        left = reverse_nat_trans(list_functor_map(f, xs))
        right = list_functor_map(f, reverse_nat_trans(xs))
        
        return left == right, left, right

Riemannian Geometry: The Gauss-Bonnet Theorem

riemannian-geometry

Historical Context

The Gauss-Bonnet theorem represents one of the most profound connections between geometry and topology. Gauss proved a local version for geodesic triangles on surfaces in 1827, and Bonnet extended it in 1848. The modern formulation, generalizing to higher dimensions through Chern's intrinsic proof (1944), reveals that the total curvature of a manifold is a topological invariant. This theorem launched the field of characteristic classes and index theory, with applications ranging from general relativity to condensed matter physics.

Definitions

  • Riemannian Metric \(g\): Inner product \(g_p: T_pM \times T_pM \to \mathbb{R}\) on each tangent space.
  • Gaussian Curvature \(K\): For surfaces, \(K = \kappa_1 \kappa_2\) where \(\kappa_i\) are principal curvatures.
  • Euler Characteristic \(\chi(M)\): \(\chi(M) = \sum_{i=0}^n (-1)^i \dim H_i(M; \mathbb{R})\).
  • Geodesic Curvature \(k_g\): Curvature of a curve on a surface measured within the surface.
  • Pfaffian: A polynomial in matrix entries generalizing the determinant for skew-symmetric matrices.

Theorem: Gauss-Bonnet-Chern

Theorem (Classical Gauss-Bonnet): For a compact oriented surface \(M\) without boundary:

\[ \int_M K \, dA = 2\pi \chi(M) \]

Chern's Generalization: For a compact oriented Riemannian manifold \(M^{2n}\) of even dimension:

\[ \int_M \text{Pf}(\Omega) = (2\pi)^n \chi(M) \]

where \(\Omega\) is the curvature form and \(\text{Pf}\) is the Pfaffian.

Notation Guide

  • \((M, g)\): Riemannian manifold with metric \(g\)
  • \(K\): Gaussian curvature (2D) or sectional curvature
  • \(R_{ijkl}\): Riemann curvature tensor
  • \(\Omega^i_j\): Curvature 2-form
  • \(\text{Pf}(\Omega)\): Pfaffian of curvature form
  • \(\chi(M)\): Euler characteristic

        """
        Gaussian curvature of sphere: K = 1/R^2 (constant).
        Area element: dA = R^2 sin(θ) dθ dφ
        Integrand: K * dA = (1/R^2) * R^2 * sin(θ) = sin(θ)
        """
        return np.sin(theta)
    
    @staticmethod
    def torus_curvature(R, r, theta, phi):
        """
        Gaussian curvature of torus with major radius R, minor radius r.
        K = cos(φ) / (r * (R + r*cos(φ)))
        """
        return np.cos(phi) / (r * (R + r * np.cos(phi)))
    
    @staticmethod
    def torus_area_element(R, r, theta, phi):
        """Area element for torus."""
        return r * (R + r * np.cos(phi))
    
    @staticmethod
    def integrate_gauss_bonnet_surface(surface_type='sphere', params=None):
        """
        Verify Gauss-Bonnet: ∫ K dA = 2π χ
        """
        if surface_type == 'sphere':
            R = params.get('R', 1.0) if params else 1.0
            # ∫∫ sin(θ) dθ dφ = 4π
            # K = 1/R^2, so ∫ K dA = (1/R^2) * 4πR^2 = 4π = 2π * 2
            integral, _ = dblquad(
                lambda phi, theta: RiemannianGeometry.sphere_curvature_integrand(theta, phi, R),
                0, np.pi,  # theta: 0 to π
                0, 2*np.pi  # phi: 0 to 2π
            )
            chi = 2  # Sphere has χ = 2
            expected = 2 * np.pi * chi
            
        elif surface_type == 'torus':
            R = params.get('R', 2.0) if params else 2.0
            r = params.get('r', 1.0) if params else 1.0
            # For torus: ∫ K dA = 0 (since χ = 0)
            integrand = lambda phi, theta: (
                RiemannianGeometry.torus_curvature(R, r, theta, phi) * 
                RiemannianGeometry.torus_area_element(R, r, theta, phi)
            )
            integral, _ = dblquad(integrand, 0, 2*np.pi, 0, 2*np.pi)
            chi = 0  # Torus has χ = 0
            expected = 0
            
        return integral, expected, chi
    
    @staticmethod
    def euler_characteristic_genus(g):
        """Euler characteristic of orientable surface of genus g."""
        return 2 - 2*g
    
    @staticmethod
    def geodesic_curvature_circle_on_sphere(R, theta0):
        """
        Geodesic curvature of latitude circle at colatitude θ₀.
        k_g = cos(θ₀) / (R * sin(θ₀))
        """
        return np.cos(theta0) / (R * np.sin(theta0))

print(f"\nSphere S²:")
print(f"∫ K dA = {integral:.6f}")
print(f"2π χ = {expected:.6f}")
print(f"Euler characteristic χ = {chi}")
print(f"Match: {np.isclose(integral, expected)}")

📜 Math History

The Birth of Modern Algebra: Évariste Galois and the Resolution of Equations

The early 19th century witnessed a profound transformation in mathematics, driven by a young French revolutionary who would die before his twenty-first birthday. Évariste Galois (1811–1832) fundamentally changed how mathematicians understand equations, creating what we now call Galois theory—a bridge between field extensions and group theory that resolved questions that had puzzled mathematicians for centuries.

Galois's story is as dramatic as his mathematics. Born during the turbulent years of Napoleon's empire, he showed early mathematical brilliance but struggled with the rigid educational system of the École Polytechnique. His academic career was marked by repeated failures, political activism during the July Revolution of 1830, and imprisonment for his republican views. Yet in the months before his death in a duel—possibly over a romantic entanglement, possibly politically motivated—he wrote down his mathematical ideas in a letter to his friend Auguste Chevalier.

The central question Galois addressed was deceptively simple: why can we solve quadratic, cubic, and quartic equations by radicals (using only arithmetic operations and root extractions), but not general quintic equations? Mathematicians since the Renaissance had sought a formula for the quintic. Cardano published solutions for cubic and quartic equations in 1545, and for three centuries, the quintic resisted all attempts.

In 1799, Paolo Ruffini claimed to prove the impossibility of solving the general quintic by radicals, but his argument had gaps. Niels Henrik Abel provided the first complete proof in 1824, showing that no general formula exists. But Galois went far beyond impossibility—he provided a complete theory explaining exactly when equations are solvable.

Galois's insight was to associate a group—the Galois group—to each polynomial equation. This group encodes the symmetries among the roots. The equation is solvable by radicals if and only if this group is solvable, meaning it can be built from abelian groups through successive extensions. The symmetric group \(S_5\), which is the Galois group of the general quintic, is not solvable—its only nontrivial normal subgroup is the alternating group \(A_5\), which is simple and non-abelian.

Galois's work was not immediately recognized. His manuscripts were nearly lost, and it was only through the efforts of Joseph Liouville that they were published in 1846, fourteen years after Galois's death. By then, the mathematical world was ready for his ideas. The concept of a group, implicit in Galois's work, would become central to mathematics in the late 19th century, underlying geometry (Klein's Erlangen program), number theory, and eventually physics.

The legacy of Galois extends far beyond the theory of equations. His emphasis on structure and symmetry over computation anticipated the modern axiomatic approach to mathematics. The Galois correspondence between subfields and subgroups became a template for similar correspondences throughout mathematics. And his life—passionate, tragic, and brilliant—has inspired generations of mathematicians to see their subject as a domain of beauty and revolutionary possibility.

Use power of a point and properties of the nine-point circle. Consider the homothety centered at \(G\) (centroid) with ratio \(-1/2\) that maps the circumcircle to the nine-point circle.

Let \(A'\) be the reflection of \(A\) across \(M\), so \(A'\) lies on the circumcircle (since \(M\) is the midpoint of \(BC\) and \(ABA'C\) is a parallelogram).

Let \(H\) be the orthocenter. Since \(D\) is the foot of the altitude, \(H\) lies on \(AD\). The nine-point circle passes through \(D\) and \(M\).

Consider the homothety \(\phi\) centered at \(G\) (centroid) with ratio \(-1/2\). This maps \(A\) to the midpoint of \(BC\) (which is \(M\)), and maps the circumcircle \(\Omega\) to the nine-point circle.

Since \(DP \parallel AM\), and \(\phi\) maps \(AM\) to a line through \(M\) parallel to \(AM\), we have that \(\phi(P)\) lies on the line through \(M\) parallel to \(AM\).

The Hopf Fibration: Visualizing a 3-Sphere

The Hopf fibration is one of the most beautiful constructions in topology, revealing that the 3-sphere \(S^3\) can be decomposed into circles (fibers), each linked with every other. This visualization maps points from \(S^3 \subset \mathbb{C}^2\) to \(S^2\) via the Hopf map \((z_1, z_2) \mapsto (2\text{Re}(z_1\bar{z}_2), 2\text{Im}(z_1\bar{z}_2), |z_1|^2 - |z_2|^2)\). Each fiber is a great circle in \(S^3\), and nearby fibers are linked like strands in a rope.

Python Code

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def hopf_map(z1, z2):
    """
    Hopf map: S³ → S²
    Input: (z1, z2) with |z1|² + |z2|² = 1
    Output: (x, y, z) on S²
    """
    x = 2 * np.real(z1 * np.conj(z2))
    y = 2 * np.imag(z1 * np.conj(z2))
    z = np.abs(z1)**2 - np.abs(z2)**2
    return np.array([x, y, z])

def hopf_fiber(theta, phi_base, t):
    """
    Parameterize a single Hopf fiber.
    theta: determines which fiber (point on S²)
    phi_base: base angle
    t: parameter along fiber
    """
    # Point on S²
    x_s2 = np.sin(theta) * np.cos(phi_base)
    y_s2 = np.sin(theta) * np.sin(phi_base)
    z_s2 = np.cos(theta)
    
    # Lift to S³ (stereographic projection to R³ for visualization)
    # Fiber over (x_s2, y_s2, z_s2)
    psi = phi_base / 2
    chi = theta / 2
    
    z1 = np.cos(chi) * np.exp(1j * (t + psi))
    z2 = np.sin(chi) * np.exp(1j * t)
    
    # Stereographic projection from S³ to R³
    # (x1, y1, x2, y2) where z1 = x1 + iy1, z2 = x2 + iy2
    x1, y1 = np.real(z1), np.imag(z1)
    x2, y2 = np.real(z2), np.imag(z2)
    
    # Project from north pole (0,0,0,1)
    denom = 1 - y2
    if np.abs(denom) < 1e-10:
        return np.array([0, 0, 0])
    
    X = x1 / denom
    Y = y1 / denom
    Z = x2 / denom
    
    return np.array([X, Y, Z])

def visualize_hopf_fibration():
    """Create visualization of Hopf fibration."""
    fig = plt.figure(figsize=(14, 6))
    
    # Plot 1: Several fibers
    ax1 = fig.add_subplot(121, projection='3d')
    
    t = np.linspace(0, 2*np.pi, 200)
    colors = plt.cm.hsv(np.linspace(0, 1, 8))
    
    for i, theta in enumerate(np.linspace(0.3, np.pi-0.3, 8)):
        fiber_points = np.array([hopf_fiber(theta, 0, ti) for ti in t])
        # Clip extreme values
        fiber_points = np.clip(fiber_points, -10, 10)
        ax1.plot(fiber_points[:, 0], fiber_points[:, 1], 
                fiber_points[:, 2], color=colors[i], alpha=0.7, linewidth=2)
    
    ax1.set_title('Hopf Fibers in S³ (Stereographic Projection)')
    ax1.set_xlabel('X')
    ax1.set_ylabel('Y')
    ax1.set_zlabel('Z')
    
    # Plot 2: Base S² with fibers indicated
    ax2 = fig.add_subplot(122, projection='3d')
    
    u = np.linspace(0, 2*np.pi, 50)
    v = np.linspace(0, np.pi, 50)
    x = np.outer(np.cos(u), np.sin(v))
    y = np.outer(np.sin(u), np.sin(v))
    z = np.outer(np.ones(np.size(u)), np.cos(v))
    
    ax2.plot_surface(x, y, z, alpha=0.3, cmap='viridis')
    
    # Mark some fiber base points
    for theta in np.linspace(0.3, np.pi-0.3, 5):
        for phi in np.linspace(0, 2*np.pi, 5, endpoint=False):
            x_pt = np.sin(theta) * np.cos(phi)
            y_pt = np.sin(theta) * np.sin(phi)
            z_pt = np.cos(theta)
            ax2.scatter([x_pt], [y_pt], [z_pt], color='red', s=50)
    
    ax2.set_title('Base Space S² (Fibers over each point)')
    ax2.set_xlabel('X')
    ax2.set_ylabel('Y')
    ax2.set_zlabel('Z')
    
    plt.tight_layout()
    plt.savefig('hopf_fibration.png', dpi=150, bbox_inches='tight')
    plt.show()
    
    return fig
